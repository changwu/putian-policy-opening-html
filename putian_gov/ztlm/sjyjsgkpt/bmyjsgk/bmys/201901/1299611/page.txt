一、
部门主要职责
根据《中共莆田市委机构编制委员会关于印发科学技术局主要职责内设机构和人员编制规定的通知》（莆委编
[2011]17
号），主要职责是：
(
一
)
贯彻执行国家有关科学技术发展的法律法规和政策；起草并组织实施有关科技工作的政策和规范性文件。
(
二
)
编制全市中长期科技发展规划和年度计划并组织实施，提出全市科技发展重大布局和优先领域，组织实施基础研究、应用研究、开发研究、软科学研究等科技计划，负责统筹协调基础研究、前沿技术研究、重大社会公益性技术研究及关键技术、共性技术研究，牵头组织经济社会发展重要领域的关键技术攻关。
(
三
)
负责推进全市科技创新体系建设，拟订促进知识创新、技术创新建设的政策措施并组织实施。拟订科研条件保障规划和相关政策并组织实施，推进科技基础条件平台、科研基地、重点产业创新平台与创新基地建设和科技资源共享。
(
四
)
拟订全市各类科技计划并组织实施；会同有关部门拟订全市高新技术发展与产业化政策，指导高新技术产业化及应用技术的开发与推广；指导高新技术产业开发区建设。
(
五
)
拟订全市科技促进农村和社会发展的相关政策和措施并组织实施，促进以改善民生为重点的农村建设和社会建设。
(
六
)
拟订科技成果管理政策并组织实施
,
指导科技成果转化工作；会同有关部门拟订全市产学研结合的相关政策，组织相关重大科技成果应用示范，推动企业自主创新能力建设。
(
七
)
提出科技体制改革的政策和措施建议，牵头组织推进科技体制改革工作，审核相关科研机构的组建和调整，优化科研机构布局。
(
八
)
负责本部门预算中的科学技术经费预决算及经费使用的监督管理，会同有关部门提出科技资源合理配置的重大政策和措施建议，优化科技资源配置。
(
九

负责市科学技术奖评审的组织工作；会同有关部门拟订全市科技人才队伍建设规划，提出相关政策建议。
(

)

;
拟订促进技术市场、科技中介组织发展政策；负责相关科技评估、科技统计及与科技相关的知识产权等工作；承担莆田市国防动员委员会科技动员办公室的具体工作。

)
组织拟订对外科技合作与交流的政策措施
,
负责国际及港澳台地区的科技合作与交流，组织实施政府间及有关国际组织间的科技合作项目。

三、部门主要工作任务
2018
年，我们要深入学习党的十九大精神，全面贯彻落实国家、省、市的科技政策，要实现从“小局”到“大局”的转变，科技创新的依托力量要实现从“小众”到“大众”的转变，科技资源配置要实现从“小投入”到“大投入”的转变，主动适应新常态，大力实施创新驱动发展战略，加快建立以企业为主体、以市场为导向、产学研紧密结合的技术创新体系，培育一批综合竞争力强的高新技术企业和创新型企业，做大做强我市高新技术产业和战略性新兴产业，为打造宜居港城、建设美丽莆田做出新的贡献。
（一）以科技改革创新为动力，提高自主创新能力
一是培育新兴产业和提升传统产业。
将战略性新兴产业作为发展高新技术产业的重中之重，围绕
新一代信息技术、新材料、高端装备制造、节能环保、新能源、生物和医药、海洋高新技术、现代服务业、现代特色农业等
产业，有针对性的组织实施一批科技项目，开展核心关键技术的攻关和新产品研发，为加快新兴产业培育发展提供技术保障，积极争取国家和省级项目和经费，为科技型企业发展创造有利条件。
二是强化企业技术创新主体地位。
落实企业自主创新投入的所得税前抵扣政策，积鼓励和引导企业建立自主创新平台，或以企业为主体建立产学研技术创新联盟、知识产权联盟和产业联盟，鼓励企业实施知识产权战略，支持企业优先承担国家、省、市重大科技专项；积极开展创新型企业试点和高新技术企业认定工作，引导企业创新发展。
三是创新科技金融结合机制。
主动加强与金融机构的对接合作，疏通科技项目融资渠道，为科技型中小企业提供金融服务，落实好专利权质押贷款政策，并探索建立科技风险投资机制，助推科技中小微企业快速成长。
四是开展企业研发经费分段补助工作。
明确目标，强化实施监理，严格考核验收，建立项目绩效报告制度，以上年度企业研发投入为基数，对企业本年度的研发经费投入进行补助，次年度向企业兑现本年度的全部补助资金。企业获得预补助经费在当年获准的补助经费中予以扣除。
（二）以科技项目实施为重点，助推科技经济结合
认真贯彻落实国家、省和我市鼓励促进科技创新创业政策，充分调动全社会科技创新创业的积极性和创造性。
一是确保财政性科技投入稳定增长。
要逐年提高科技支出占财政支出的比重，确保本级财政科技经费支出增长幅度高于本级财政收入增长幅度。
二是落实税收优惠政策。
做好国家高新技术企业税收优惠政策和企业研发费加计扣除政策的落实工作，鼓励企业增加研发投入。建立相关部门联系沟通机制，规范流程，同时，加强对企业的培训，帮助企业改进内部管理，完善研发制度和财务制度，实现相关税收政策的无缝衔接。
三是落实各类专项补助资金。
对高层次人才引进、国家高新技术企业、工程技术研究中心、专利申报等，集中政府有限的政策资源支持科技创新，及时按出台的政策规定落实补助或奖励资金，逐步将奖励资助重点转移到科技创新和对地方经济社会的贡献质量上来。
四是完善科技项目管理体制机制。
提升科技管理能力。将过去以项目管理为主的项目型科技管理部门转变为以统筹科技资源为主的资源型科技管理部门，跳出单纯的项目管理，有效集聚和运用高校、科研院所、企业的科技资源，构建具有核心竞争力的区域创新体系。完善项目管理监督机制。科学设计、严格规范项目评审，确保评审结果的公正性。加强过程管理，落实项目承担单位的法人责任，加强项目中期评估、验收和档案管理。加强科技项目经费管理，提高经费使用效益。
五是积极促进科技成果转化。
继续推进我市与
中科院、清华大学、
天津大学、
厦门大学、华侨大学等高校科研院所的科技合作对接，
邀请
华侨大学专家服务团到我市参观调研，为双方下一步全面合作奠定基础。积极筹备建设中科院
STS
莆田分中心，促进中科院科技成果在我市转化和产业化。做好“一带一路”科技合作与交流工作，通过项目实施，引导企业与“一带一路”沿线国家开展合作与交流。落实科技成果有关政策，开展科技成果有关政策的宣传工作。
六是实施人才团队培养计划。
通过项目带动、资金支持、政策激励等方式，在优势领域培养一批专业知识结构和年龄结构合理、协作精神好、创新能力强的科技创新型人才团队。承接省科技领军人才、百人计划、杰出青年基金、博士后科研资助、科技创新团队和我市高层次创新创业人才引进等人才计划，培养引进高层次创新型人才和创新团队，着力推进人才培养引进与重大创新平台建设、重大项目实施的有机结合。
（三）以科技平台建设为支撑，加速创新资源集聚
大力支持企业建立重点（工程）实验室、博士后科研流动（工作）站、院士专家工作站、技术中心、工程研究中心等创新平台，促进创新要素向企业研发机构流动。做好中科院海西研究院莆田中心一期工程入驻的项目引进和招商工作，开展科技孵化工作，同时推进二期建设。鼓励和支持企业与高校、科研院所合作，共建企业研发平台，已建的科技创新平台要进一步规范建设标准，提质增效，充分发挥创新平台在聚集创新要素、关键技术攻关、新产品研发等重大科技项目实施中的骨干作用。鼓励和支持企事业单位、社会组织，按照专业化、市场化的要求，建立科技服务平台，不断改善服务条件，完善服务手段，创新服务机制，提升服务质量，以优质的服务推动科技创新，促进成果转化。认真落实省科技厅关于农业科技园建设的要求，按照“规划先行、定位准确、加强领导、完善机制”的基本要求，指导仙游县建设农业科技园区，助推现代农业发展。
（四）以科技服务民生为目的，促进社会和谐进步
一是深化可持续发展理念。
将科技作为支撑可持续发展的核心动力，减少经济社会发展对资源的过度依赖，积极探索创新驱动可持续发展的有效模式，重点面向生态建设和改善，综合运用各种生态新技术，促进环境保护、能源资源开发和高效清洁利用等，为我市生态安全绿色可持续发展提供科技支持。
二是深入实施民生科技计划。
重点在人口健康、资源环境和食品安全等领域实施一批民生科技项目。加强生态环境保护与大气、水等污染防治技术研发与应用。加强工业“三废”处理、生活垃圾处理等领域的技术攻关和示范，支撑生态文明建设；以农业科技特派员为依托，继续组织开展科技特派员农村基层创业服务活动，建立健全农村科技信息服务体系，对接省级服务平台，助推科技进村入户，使基层农民群众更直接、更有效地分享农业科技成果。
三是深入做好科技普及工作。
全面贯彻落实国务院《全民科学素质行动计划纲要》，弘扬科学精神，倡导科学方法，传播科学思想，普及科技知识，组织开展科普活动，增强活动的针对性和实效性，创新活动方式，更加突出群众性、社会性和经常性。
（五）以试点城市为抓手，构建知识产权工作体系
扎实推进国家知识产权试点城市建设，着力培育国家知识产权强县工程试点、知识产权优势企业、试点示范园区和知识产权普及教育试点学校；推行“市带县”专利行政执法模式，强化与工商、文化等相关知识产权部门的联合执法，实现专利行政执法“纵到底”、“横到边”；着力开展专利导航工作，重点做好“
1+10
”电子信息产业专利导航项目；推动鞋服、工艺美术、食品加工、电子商务等行业协会的知识产权牵头抓总工作；落实国家、省知识产权有关政策法规，落实产业、人才、贸易、科技等与知识产权相关政策，帮助企事业单位修订知识产权管理制度，重点推广国家知识产权管理规范。继续推进专利技术实施与产业化，着力落实《福建省专利运用行动计划实施方案（
2015
—
2017
）》；推进专利资本化，加大专利权质押贷款工作力度，切实帮助企业解决融资难、融资贵问题；推进专利市场化，深化专利技术推广运用，在专利交易、专利许可、专利评估、专利保险等方面取得实效；推进专利标准化，引导行业领军企业核心专利技术纳入行业技术标准；推进专利国际化。重点做好跨境电商企业海外专利预警，引导企业海外专利布局，为企业开拓国际市场保驾护航。
（六）以机关队伍建设为根本，提升科技管理公信力
一是学习党的十九大精神。
要组织引导党员干部原原本本、原汁原味、逐条逐句反复通读党的十九大报告和《中国共产党章程》，利用理论学习中心组专题会、支部党员大会、党小组会、讨论交流等形式，组织开展专题研讨，切实做到认真学、全面学、系统学、深入学、反复学，领悟贯穿其中的思想精髓和工作方法，更好地用以指导和推动事业发展。要大力弘扬马克思主义学风，坚持学用结合、学以致用，进一步加强以党的政治建设为统领的机关党的政治建设、思想建设、组织建设、作风建设、纪律建设，把制度建设贯穿其中，坚定不移推进机关全面从严治党，不断增强机关党建的政治领导力、思想引领力、群众组织力、社会号召力，为建设美丽中国的示范区提供可靠政治保证。
二是继续开展“两学一做”学习教育。
坚持深入基层，深入群众，把工作的着力点放到研究解决科技事业发展中的重大问题上来，放到研究解决制约科技发展的紧迫问题上来；脚踏实地，真抓实干，坚决反对作风漂浮，华而不实。
三是坚持廉洁从政。
自觉遵守廉洁从政的各项规定，要抓住科技经费使用中容易滋生腐败的源头问题，深入开展思想道德教育、法纪教育和艰苦奋斗、廉洁从政专题教育，从源头上预防腐败。四是创建学习型机关。加强自身建设，努力学业务，讲修养，提高干部综合素质，规范行政行为，提高工作效率，努力开创“学习型、创新型、和谐型”机关，使科技工作跃上新台阶。

十、名词解释
1.
财政拨款收入：指财政当年拨付的资金。
2.
事业收入：指事业单位开展专业业务活动及辅助活动所取得的收入。
3.
经营收入：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动取得的收入。
4.
其他收入：指除上述“财政拨款收入”、“事业收入”、“经营收入”等以外的收入。主要是按规定动用的售房收入、存款利息收入等。
5.
用事业基金弥补收支差额：指事业单位在当年的“财政拨款收入”、“事业收入”、“经营收入”、“其他收入”不足以安排当年支出的情况下，使用以前年度积累的事业基金（事业单位当年收支相抵后按国家规定提取、用于弥补以后年度收支差额的基金）弥补本年度收支缺口的资金。
6.
年初结转和结余：指以前年度尚未完成、结转到本年按有关规定继续使用的资金。
7.
结余分配：指事业单位按规定提取的职工福利基金、事业基金和缴纳的所得税，以及建设单位按规定应交回的基本建设竣工项目结余资金。
8.
年末结转和结余：指本年度或以前年度预算安排、因客观条件发生变化无法按原计划实施，需延迟到以后年度按有关规定继续使用的资金。
9.
基本支出：指为保障机构正常运转、完成日常工作任务而发生的人员支出和公用支出。
10.
项目支出：指在基本支出之外为完成特定行政任务和事业发展目标所发生的支出。
11.
经营支出：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动发生的支出。
12.
“三公”经费：纳入财政预决算管理的“三公”经费，是指使用财政拨款安排的因公出国（境）费、公务用车购置及运行费和公务接待费。其中，因公出国（境）费反映单位公务出国（境）的国际旅费、国外城市间交通费、住宿费、伙食费、培训费、公杂费等支出；公务用车购置及运行费，指单位公务用车购置费
(
含车辆购置税、牌照费
)
及燃料费、维修费、过桥过路费、保险费、安全奖励费用等支出，公务用车指车改后单位按规定保留的用于履行公务的机动车辆，包括领导干部用车、一般公务用车和执法执勤用车等；公务接待费反映单位按规定开支的各类公务接待（含外宾接待）支出。
13.
机关运行经费：为保障行政单位（含参照公务员法管理的事业单位）运行用于购买货物和服务的各项资金，包括办公及印刷费、邮电费、差旅费、会议费、福利费、日常维修费、专用材料及一般设备购置费、办公用房水电费、办公用房取暖费、办公用房物业管理费、公务用车运行维护费以及其他费用。
