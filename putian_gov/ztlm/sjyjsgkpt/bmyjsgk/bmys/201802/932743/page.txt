一、
部门主要职责
莆田市地震局
部门的主要职责是：
(
一
)
贯彻执行国家、省有关防震减灾法律、法规和规章；并依法监督、检查本行政区域内的防震减灾工作。根据市政府和省地震局的部署，编制、实施本地区的防震减灾发展规划和年度工作计划。
(
二
)
负责建立和管理地震监测预报工作体系，制定本行政区域地震监测预报方案，并组织实施；综合全市地震监测资料和预报信息，强化本市地震重点监视防御区的震情跟踪；管理全市地震监测台网
(
站
)
和群测群防工作，依法保护地震监测设施和地震观测环境；组织开展地震趋势会商。
(
三
)
负责建立地震震灾预防工作体系，归口管理城镇建设、经济开发区以及重大工程建设场地的地震安全性评价工作；指导和监督重大工程和重要设施的抗震设防。
(
四
)
会同有关部门建立和管理地震应急和紧急救援工作体系，制定并组织实施破坏性地震应急预案，检查监督各行业地震应急保障措施的落实。
(
五
)
负责防震减灾知识的宣传教育，普及地震和防震减灾知识，平息地震谣传、误传，提高全民防震减灾意识和抗震救灾、自救互救能力，并按照有关规定审核防震减灾宣传报道。
(
六
)
推进地震科学技术现代化，组织开展地震科学技术攻关及其成果的推广应用；开展地震应急、救援技术和装备的开发与应用；开展地震科学技术的对外交流与合作。
(
七
)
承担莆田市人民政府抗震救灾指挥部办事机构的职责，负责地震震情和灾情速报；会同有关部门组织地震灾害调查与地震灾害损失评估；提出地震灾区重建规划的意见。
(
八
)
指导全市各县
(
区
)
地震办公室防震减灾工作。
(
九
)
根据法律、法规赋予的职责，依法开展防震减灾行政执法工作，并承担本行政区域内的地震行政复议工作。

2018
年，
莆田市地震局
部门主要任务是：
2018
年，我局将
深入学习十九大和习近平总书记系列重要讲话精神，认真贯彻落实党的十九大精神，紧紧围绕习近平总书记在唐山考察时强调的“全面提高国家综合防灾减灾救灾能力”的要求，坚持“以预防为主，防御与救助相结合”的方针，全面深化改革，按照“透明地壳、解剖地震、韧性城乡、智慧服务”四大要求，加强防震减灾三大体系建设，积极争创国家防震减灾示范城市，为坚持绿色发展、打造宜居港城、建设美丽莆田、创建美丽中国的示范区提供更好的服务保障。围绕上述任务，重点抓好以下工作：
（一）加强监测预报工作
制定年度震情跟踪和特殊时段地震安全保障服务工作方案，落实地震短临跟踪工作措施，继续做好震情跟踪工作。做好
2
个地下流体观测台和
1
个砂层应变观测台的日常管理、维护工作，加强地震监测设施的建设与管理。组织召开地震趋势会商会，通过会商交流，提高会商资料质量和分析预报水平。加强“三网一员”管理，做好地震宏、微观异常现象调查核实工作，及时平息地震谣言。
（二）加强震害防御工作
按照国家行政审批制度改革的要求，建立抗震设防要求管理新机制。继续开展创建国家地震安全示范社区、企业、工程和防震减灾科普示范学校工作，各个县（区）至少推荐
2
个以上示范点，管委会推荐
1

1
种防震减灾科普宣传资料，建立
1

2000
多名网格员的防震减灾业务培训工作，深入开展防震减灾网格化管理平台建设。
（三）加强应急准备工作
更新应急基础数据库，健全应急指挥系统。对已有的地震应急预案实施动态管理，继续督促指导各级、各类地震应急预案制（修）订工作。通过各种形式的培训、演练提高救援队伍、地震现场工作队、志愿者队伍的应急救援能力。按照省地方标准，继续推进应急避难场所建设。组织对县区和指挥部成员单位的应急准备工作进行检查指导。
（四）加强党建和行政工作
认真落实党建工作责任制、
“
三会一课
”
制度，严格执行党风廉政建设各项制度。着眼改革创新，进一步健全干部管理制度，强化绩效管理，完善工作机制。加强对县区地震部门业务指导和技术支持，创造考察、学习、培训、交流等提高的机会。以开展文明单位、平安单位创建活动为抓手，继续做好各项综合性工作。

十、名词解释
1.
财政拨款收入：指财政当年拨付的资金。
2.
事业收入：指事业单位开展专业业务活动及辅助活动所取得的收入。
3.
经营收入：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动取得的收入。
4.
其他收入：指除上述
“
财政拨款收入
”
、
“
事业收入
”
、
“
经营收入
”
等以外的收入。主要是按规定动用的售房收入、存款利息收入等。
5.
用事业基金弥补收支差额：指事业单位在当年的
“
财政拨款收入
”
、
“
事业收入
”
、
“
经营收入
”
、
“
其他收入
”
不足以安排当年支出的情况下，使用以前年度积累的事业基金（事业单位当年收支相抵后按国家规定提取、用于弥补以后年度收支差额的基金）弥补本年度收支缺口的资金。
6.
年初结转和结余：指以前年度尚未完成、结转到本年按有关规定继续使用的资金。
7.
结余分配：指事业单位按规定提取的职工福利基金、事业基金和缴纳的所得税，以及建设单位按规定应交回的基本建设竣工项目结余资金。
8.
年末结转和结余：指本年度或以前年度预算安排、因客观条件发生变化无法按原计划实施，需延迟到以后年度按有关规定继续使用的资金。
9.
基本支出：指为保障机构正常运转、完成日常工作任务而发生的人员支出和公用支出。
10.
项目支出：指在基本支出之外为完成特定行政任务和事业发展目标所发生的支出。
11.
经营支出：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动发生的支出。
12.“
三公
”
经费：纳入财政预决算管理的
“
三公
”
经费，是指使用财政拨款安排的因公出国（境）费、公务用车购置及运行费和公务接待费。其中，因公出国（境）费反映单位公务出国（境）的国际旅费、国外城市间交通费、住宿费、伙食费、培训费、公杂费等支出；公务用车购置及运行费，指单位公务用车购置费
(
含车辆购置税、牌照费
)
及燃料费、维修费、过桥过路费、保险费、安全奖励费用等支出，公务用车指车改后单位按规定保留的用于履行公务的机动车辆，包括领导干部用车、一般公务用车和执法执勤用车等；公务接待费反映单位按规定开支的各类公务接待（含外宾接待）支出。
13.
机关运行经费：为保障行政单位（含参照公务员法管理的事业单位）运行用于购买货物和服务的各项资金，包括办公及印刷费、邮电费、差旅费、会议费、福利费、日常维修费、专用材料及一般设备购置费、办公用房水电费、办公用房取暖费、办公用房物业管理费、公务用车运行维护费以及其他费用。
