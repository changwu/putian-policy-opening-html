莆田市公安局关于市八届人大三次会议第1332号建议的答复

发布时间：2024-04-18 11:10
| | |
政策解读:

严国圣代表：

　　您提出的《关于加强部分道路交通设施建设和管理的建议》收悉，现答复如下：

　　一、关于重视红绿灯设计的标准化工作的建议

    针对您提出的对红绿灯设定标准进行统一的建议，当前我市红绿灯放行方式分为“直行和左转信号同时亮起”“直行和左转信号先亮其中一个”两种。“直行和左转信号同时亮起”放行方式较为简单，无需渠化专用左转、直行、右转车道，适用于出口道2车道以下且左转与直行流量匹配的情形。“直行和左转信号先亮其中一个的”放行方式能够单独控制左转、直行车流，做到更加精细化地管理交通。红绿灯的放行方式需要综合交叉口的道路条件、车道划分和流量数据分析等情况进行设定，如果红绿灯放行方式不能与交通流量相匹配，将会出现绿灯时间内车道空闲，浪费绿灯时间的现象。当前，受限于我市部分道路及路口条件，暂无法实现红绿灯放行方式统一。

　　二、关于完善道路基础设施的建议

　　市城市管理部门高度重视市政道路设施的管养工作，以常态化市政道路设施维护、强化道路安全隐患排查治理、市政道路品质提升为抓手，不断优化道路交通安全环境。一是持续推进常态化市政道路维护。2023年以来，对城区26条市政道路安全状况进行全面排查整治提升，共修补人行道约2200平方米，水泥路面约450平方米，沥青路面约4000平方米，补齐更换丢失破损井盖约90个，加装防坠网1600余个。二是开展城港大道秀屿段路面隐患整治。对该路段沥青路面破损进行修补，共修补面积约8万平方米，切实消除路面坑洞等安全隐患。三是有序推进市政道路品质提升。完成学园南街、胜利路、梅园路等城市主干道提升改造，处理病害路面约4.67万平方米，完成“白改黑”22万平方米，极大地提高了市民的出行环境。

　　我局交警支队高度重视道路交通安全设施的设置、管理及维护工作，制定了《莆田市公安局交警支队关于健全完善交通安全设施常态化巡查工作机制的通知》，建立完善了城乡主次干道、学校周边、景区道路的交通标志、标线等交通设施日常巡查排查机制，推动道路交通设施源头排查、多元化解的闭环管理。对巡查发现的问题属于交警部门职责的，立即组织维护队伍进行整改；属于其他职能部门职责的，提请道安平台督促整改。2023年以来共组织有关人员不定期深入各辖区道路进行集中巡查4批次，累计排查整改主次干道、学校周边等道路的各类交通设施问题427处，城区交通设施得到了有力的巩固。

　　三、关于优化道路掉头设置的建议

　　为进一步提高中心城区道路交通通行能力，有效缓解道路拥堵状况，我局交警支队对城区主要的掉头区拥堵路口进行排查摸底，并听取群众诉求及代表意见，采用优化路口布局、科学划分车道和“多车并行掉头区”等，优化调整中心城区道路的交通设施，保障城区道路通畅有序。如对东圳路与延寿路交叉口（即莆田学院附属医院路口）等路口车道分布进行优化调整，后置掉头区，引导车辆提前掉头，以减少待掉头车辆对左转车流的影响，调整后路口的通行效率有了明显提高。同时，为着力解决道路交叉口车辆占道掉头、妨碍正常行驶车辆通行致拥堵乱象，进一步提高路口的通行效率，我局交警支队根据日常监测数据分析研判、组织现场查勘测算，选择荔城红星美凯龙、城厢万达、北磨等3个路口施划“多车并行掉头区”，提高掉头车辆的通行效率，努力简化交通流线，减少交通延误，最大限度提升道路通行效能和交通组织精细化水平。

　　四、关于建设用户反馈APP平台的建议

　　为加强市政道路设施巡查养护工作，市城市管理局建立了城市运行管理服务平台（原数字城管平台），按照“两级监督、两级指挥”的组织模式运行，通过“信息采集-案件建立-任务派遣-问题处置-处置反馈-核查结案和考核评价”的基本流程对城市管理问题进行闭环管理，以“人工+智能车载”的方式开展网格化巡查、上报发现的问题，市、区两级平台在对相关问题进行受理、立案后，根据职能划分将案件分别派遣给市、区两级专业部门进行处置、反馈。今年以来，系统共采集道路破损、井盖问题、交通设施等问题2371件,已处置2266件，处置率为95.57%。

　　为倡导文明交通，争做文明交通参与人，共同营造安全、有序、畅通的良好交通环境，2017年起，我局交警支队在全市内组织开展“全民随手拍·晒交通陋习”活动，并在“莆田行”“莆田交警”微信公众号开辟了“全民随手拍”版块，其中包含了机动车违停、斑马线不礼让行人等9种交通违法行为可供群众举报，让广大市民一起参与交通违法整治，既提高了群众的参与度也为交通违法专项整治行动提供了便利。通过对网友举报提供的违法素材进行筛选核实，予以相应奖励，鼓励群众发挥监督作用，协同共治。为全面贯彻落实各项道路交通安全管理措施，推进隐患动态清零，精准治理交通顽症，确保道路交通安全形势持续平稳向好，今年4月份起，我局交警支队启动了道路安全隐患“全民随手拍”活动，鼓励全市广大交通参与者在日常生活中参与道路安全隐患排查，发挥熟悉道路情况的优势，及时发现全市道路交通安全隐患并以照片、视频的形式记录下来，上传发送到举报邮箱，由辖区交警部门对举报道路安全隐患问题的照片、视频进行筛选，核实后联系举报人予以整改反馈。目前该项工作正在有序推进中。
