关于市八届人大六次会议第1186号建议的答复

发布时间：2026-03-20 11:37
| | |
政策解读:

张庆荣代表：

    您提出的《关于通过地方立法放开农村建房限制、盘活土地资源的建议》(第1186 号)收悉，现答复如下：

衷心感谢您对我市农村住房建设管理及土地资源盘活工作的高度关注与鼎力支持！您的建议紧扣乡村振兴核心议题，精准戳中当前农村建房管理的痛点、堵点，兼具极强的针对性与前瞻性，为我市后续工作开展提供了重要参考。我市始终高度重视此类民生与发展议题，结合省、市现行政策要求及工作实际，系统研究出台配套举措，稳步推进各项工作，现已取得阶段性成效。

一、严守制度底线，严格对标上级要求

国家及省级法律法规对宅基地管理、耕地保护、权属界定等核心环节划定严格标准，明确要求从严审查集体经济组织成员资格，全面落实“一户一宅”、宅基地面积上限、建房层数管控等硬性规定，坚决守住土地公有制性质不改变、耕地红线不突破、农民利益不受损三条底线。同时，上级政策已对农村建房规划、审批、盘活等关键流程作出全面规范，为我市工作开展提供了清晰的制度遵循。

我市现行农村宅基地和建房管理政策严格对标省级框架，先后出台《莆田市人民政府关于进一步规范农村宅基地和建房管理的通知》、《莆田市人民政府办公室关于进一步强化农村建房审批与建设安全管理的通知》、《提升农村村民建房审批管理的若干措施（试行）》等一系列政策文件。这些政策既坚守制度刚性，又兼顾乡村发展实际需求，未出台任何突破上级管控要求的放宽类措施，确保政策执行不偏向、不走样、不打折。

二、优化规划管控，实现乡村规划全覆盖

我市积极指导各县区（管委会）立足本地实际，因地制宜推进村庄规划编制管理工作。通过综合运用村庄规划及乡村地区“通则式”规划技术管理规定，灵活保障村民合理建房空间需求。截至目前，全市已完成705个村庄规划批复，214个村庄纳入省“通则式”管理规定适用名单，全面实现乡村地区规划管理动态全覆盖，为农村建房合规落地提供坚实规划支撑。

三、精简审批流程，提升审批服务效能

 我市创新搭建农村建房审批管理平台，全面整合农业农村、自然资源、住建等多部门审批事项，实现农村建房“全程网办、阳光审批、精准监管、便民服务”。平台全程公开审批流程、办理时限及办理结果，主动接受社会监督，彻底解决以往审批流程繁琐、周期冗长、部门间信息壁垒等突出问题。目前，农村建房审批从申请到批复的办理时限已压缩至2个月内（涉及农转用审批的除外），审批效率与公开透明度显著提升，切实保障农民建房申请的便捷性与公平性。

四、创新建设模式，提高宅基地利用效率

针对宅基地资源紧张与闲置浪费并存的矛盾，我市于去年出台《提升农村村民建房审批管理的若干措施（试行）》，允许县（区）政府（管委会）在严格落实“一户一宅”政策、符合村庄规划、户建筑面积不超审批标准且保障建筑安全的前提下，探索多户联合建设多层住宅新模式。该模式有效提高宅基地容积率，实现土地资源集约节约利用。

同时，我市建立“奖励-承诺-惩罚”闭环管理机制，强化“建新拆旧”落实。明确将旧房拆除、宅基地复垦或复绿作为新建住宅审批的前置条件，同步推动旧宅基地盘活利用，推动闲置宅基地从“沉睡”走向“活化”。

五、坚持农民主体，推动乡村可持续发展

在旧宅基地盘活过程中，我市始终坚守农民主体地位，严禁强迫农民“上楼”、强制流转宅基地，所有盘活事项均需经村民会议或村民代表会议民主决策通过。此外，专门建立闲置宅基地盘活收益分配机制，确保收益主要用于农村基础设施建设、公共服务提升和农民社会保障，真正实现“盘活资源、惠及农民、反哺乡村”的良性循环，为乡村全面可持续发展筑牢根基。

 

再次感谢您对我市农村住房建设与土地资源盘活工作的关心与支持！恳请您继续关注我市乡村振兴工作，多提宝贵意见建议。我市将持续吸收借鉴优质建议，不断改进工作方法，推动农村住房条件持续改善、土地资源高效利用，为我市乡村全面振兴贡献更大力量。
