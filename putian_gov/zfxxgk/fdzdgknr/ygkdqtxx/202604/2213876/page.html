关于市八届人大六次会议第1338号建议办理情况的答复

发布时间：2026-04-24 10:44
| | |
政策解读:

吴锦程代表：

　　您提出的《关于以设施升级与师资赋能推进乡村学校体育帮扶的建议》（第1338号）收悉。感谢您对我市乡村学校体育教育和青少年健康成长的深切关怀与宝贵建议。您的建议立足我市乡村体育教育实际，既客观分析了当前“基础有保障、发展有潜力”的良好态势，又精准指出了设施不均衡、师资薄弱等短板，提出的升级体育设施、多维赋能师资等举措，具有很强的针对性和可操作性，现将办理情况答复如下：

　　一、完善学校体育设施

　　一是升级学校体育运动场地。近年来，市教育局按照省市为民办实事有关工作部署，积极开展学校体育场地新建改扩建项目，该项目作为我市完善学校体育设施、促进青少年校园足球发展的民生工程，共在全市范围内新建、改扩建足球场地15个，有效解决部分学校足球场地老旧及不足的问题。

　　二是推动体育场地资源共享。2023年以来，市教育局联合市体育局等6部门出台《莆田市学校体育场地向社会开放项目实施办法》，向社会开放129所学校体育场地，采用省、市、县（区）三级补助的方式，对学校体育场地设施进行升级改造，并按“有条件开放、限时限流管理”的要求，在保障学校正常的教育教学、训练竞赛、课外体育活动并确保学校安全管理等工作秩序不受影响的前提下向社会开放，进一步推动了全民健身生活化、普及化。

　　二、赋能学校师资队伍

　　一是开展送教下乡。送教送研下乡是我市推动优质体育教育资源下沉乡村学校的重要途径，近年来，依托全市中小学体育名师工作室开展送教下活动有力提升了乡村体育教师教学水平，以高中体育林伟名师工作室为例，两年多来，工作室成员赴帮扶学校开展送教送培活动21场，开设讲座17场，公开研讨课74节，组织技能训练和课题研讨11场次，通过持续的送教送培，工作室成员的示范引领作用得到充分发挥，帮扶乡村学校的体育教学水平也得到明显提升。

　　二是拓展培训模式。2025年7月，联合市体育局开展棒球教练员培训，来自全市20所棒垒球联动学校的40余名体育教师参加培训，培训采取“送课上门”模式，分别在涵区第三实验小学、秀屿区实验中学等学校开展，通过理论+实践相结合的方式全面提升参训教师的专业执教能力。2025年11月，莆田市中小学幼儿园新任教师见习期体育专项培训顺利开展，培训通过专题讲座与实践思考相结合的形式，邀请业内资深专家围绕体育教学设计核心要点与教师专业成长路径展开深度分享，助力新任教师夯实教学根基、明晰发展方向。通过不断拓展体育教师培训模式，有效了体育教师队伍的专业素养。

　　三、打造特色体育课程

　　一是推动民俗体育进课堂。充分发挥妈祖文化、南少林武术等地域特色文化资源优势，将传统民俗体育项目系统融入学校体育课程体系，实现文化传承与体育育人的深度融合。如郑美琼体育名师工作室将莆田学院原创的妈祖操进行改编，拍摄教学视频、集体备课、送教下乡，探索妈祖信俗文化与妈祖民俗体育进课堂的实践，建构结构化的体育大单元教学范式，经由核心素养导向下的目标设计，巧妙落实“学-练-赛”一体化教学；莆田哲理中学系统开发了《投壶》《八段锦·五禽戏》《竹竿舞》《舞狮》《妈祖功》《舞龙》等系列校本课程，构建了多元化的民俗体育体系，以莆仙红色资源为底色，以莆田抗倭历史为切入点，将爬刀梯、赤脚跑炭火、摆棕轿踏火等传统民俗体育项目引入课堂，形成了“红色+民俗+体育”的生动育人实践，让体育课既有“强筋骨”的实效，又有“铸精神”的深度；仙游县华侨中学自2019年起将二十四式简化太极拳引入校园，不仅设为每日课间操固定内容，还作为一门正式体育必修课程，实现强身健体与品格塑造的双重目标。

　　二是塑造特色体育品牌。市教育局以体教融合为抓手，大力推动“一校一品”向“一校多品”升级，构建起“基础体育课+特色体育项目+阳光体育活动”三位一体的教学体系，形成了特色鲜明、赛事健全、贯通培养的体育品牌发展格局。秀屿区推行“基础+特色+融合”三维体育课程，将“三大球”纳入义务教育必修内容，重点培育羽毛球、排球、棒垒球以及田径等特色项目，推行“项目进校园、教练进校园”模式，组织区少体校与10余所中小学签订合作协议，建立青少年训练基地，打造“一校一品、多校特色”发展格局；全省首创地市级校园足球联赛“莆超校园赛”，自2025年12月启动，累计开展135场精彩比拼，赛事覆盖全市350余所学校，3000多名球员参与选拔；联合市体育局印发《莆田市青少年足球和棒垒球人才贯通培养工作方案》，力争到2027年创建100所各级校园足球特色学校，实现中小学校足球运动全覆盖，同时明确46所足球人才贯通培养试点学校，构建“1+3+6”人才贯通培养模式，打通足球特长生升学通道。通过塑造特色的体育品牌，逐步形成了“校校有特色、班班有队伍、年年有联赛、人人都参与”的体育特色课程发展格局，有力促进了青少年体质健康和体育后备人才培养。

　　下一步，我们将持续加大对乡村学校的帮扶力度，持续推进乡村学校体育设施升级、加快构建城乡体育教育一体化发展格局，让更多乡村孩子在运动中强健体魄、锤炼意志、健康成长。

　　感谢您对我市教育事业的关心与支持！欢迎您继续提出宝贵意见和建议！
