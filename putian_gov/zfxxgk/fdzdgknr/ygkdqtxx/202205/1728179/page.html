关于市八届人大一次会议第0044号建议的答复

发布时间：2022-05-29 10:08
| | |
政策解读:

　　

郭旭代表：

　　您提出的《关于实施教育强市的建议》（第0044号）收悉，现答复如下：

　　为深入贯彻落实习近平总书记关于教育的重要论述，坚持教育优先发展战略，统筹推进各级各类教育高质量发展，全面建成教育强市，实现教育现代化。中共莆田市委 莆田市人民政府先后出台了《关于建设教育强市的决定》（莆委发〔2017〕12号）和《关于建设教育强市的实施意见》（莆委发〔2017〕18号）以及《“十四五”期间推进建设教育强市工作实施方案》（莆委发〔2021〕9号）等文件，全面实施教育强市战略。提出到2025年建成具有莆田特色、全省先进的现代教育体系，2035年全面实现教育现代化的战略规划。并明确铸魂育人工程、学校布局规划提升工程、基础教育提量促优工程、职业教育特色示范工程、校地融合发展工程、“三名”引领工程、教师发展支撑工程、智慧教育平台建设工程、经费投入保障工程、教育生态治理工程等教育“十大工程”，《实施方案》的出台，增强了全市教师信心和决心。对于你提出的建议，我们将重点做好以下几个方面的工作。

　　一、强化考核评价，落实师德第一标准

　　以习近平总书记关于师德师风建设的重要讲话精神为根本遵循，落实立德树人根本任务，把师德师风作为评价教师队伍素质的第一标准，强调教育者先受教育，严格制度规定。一是建立教师诚信教育制度和失信惩戒机制。将教师参与有偿补课，违规接受礼品、礼金、宴请，“庸教、懒教、怠教”等违规失信行为与评先评优、职称评聘、晋职晋级、绩效工资、岗位聘用以及名师名校长、学科带头人、骨干教师评选等挂钩，严格执行师德“零容忍”。二是引导全体教师加强师德修养。坚持用习近平新时代中国特色社会主义思想武装教师头脑，加强习近平总书记关于教育的重点论述的系统化、常态化学习，学懂弄通，凝聚思想。三是完善教师师德考核评价体系，建立健全监督机制。将师德考核摆在教师考核的首要位置，将教师师德表现作为年度考核、岗位聘任、职称评审、评优奖励的首要标准。四是开展教师先进事迹宣传工作，推出一批喜闻乐见、展现教师时代风貌的典型教师代表，发掘师德典型、讲好师德故事，注重引领感召，弘扬先进楷模，形成强大正能量。

　　二、严格准入标准，不断优化人才队伍结构

　　我市根据教育发展需要，按照教育的规律，逐年有计划地补充新任教师，形成合理的教师队伍梯队结构，促进教师队伍的健康成长。一是为招聘新任教师，市教育局严格按照省、市有关招聘文件精神和工作程序，贯彻“公开、平等、竞争、择优”的工作原则，严把教师招聘入口关。近五年，全市共招聘4986名新任教师，新任教师本科及以上学历比例从“十三五”期间的67.2%提高到2021年的90.4%，中小学各学段、学科和乡村教师紧缺状况得到改善，教师队伍梯队结构逐步优化。二是招聘中小学编外聘用教师和银发教师计划。2019年，根据市委、市政府《关于建设教育强市的实施意见》（莆委发〔2017〕18号）和市政府专题会议纪要《关于研究教育工作有关问题的纪要》（〔2019〕23号）精神和要求，市教育局、市编办、市人社局、市财政局印发《莆田市公办中小学、中等职业学校、特殊教育学校、幼儿园编外合同教师管理办法（试行）》（莆教〔2019〕41号），编外教师控制数按本级当年度教师编制总数的10%核定，每年核定一次。编外教师与公办教师同工同酬，其工资、绩效奖励、养老保险、生育保险、失业保险、医疗保险、工伤保险和住房公积金等纳入同级财政预算，以实际年收入作为基数缴纳企业职工养老保险，所需经费纳入同级财政预算。2020年招聘编外教师775名，2021年招聘编外教师510名。三是市教育局、市人社局、市财政局联合印发《莆田市银发教师教学计划实施方案（试行）》（莆教〔2020〕10号），充分利用退休教师优质资源，吸引优秀退休教育人才为我市教育发展贡献才智、经验和力量。2020年招聘银发教师147人，2021年招聘银发教师121人。

　　三、保障编制供给，提高编制使用效益

　　解决教师编制问题是稳定教师队伍的重要举措，合理配置教师编制直接关系到教育事业的健康发展。我市中小学教职工编制标准是市、县区两级编制部门根据《福建省人民政府办公厅关于印发<福建省乡村教师支持计划（2015－2020 年）实施办法>的通知》（闽政办〔2015〕155号）文件执行，2021年，市、县区编制部门依标足额核定教职工编制，全市现有编制34761个，教育行政部门统筹使用教职工编制，做好中小学教职工编制结构优化、动态调整，完善资源配置，逐步满足全市各级各类学校教育教学需要，更好保障基础教育优质均衡发展。

　　四、提高经济待遇，完善待遇保障长效机制

　　近年来，市委、市政府把教师工资收入落实情况列入议事日程，不断强化教师待保障，完善中小学教师待遇保障机制，积极部署，优先安排，保证教师工资按时足额发放，教师津补贴等福利待遇兑现并实现稳步增长，切实提高教师经济待遇。一是健全中小学教师工资长效联动机制，核定绩效工资总量时统筹考虑当地公务员实际收入水平，确保中小学教师平均工资收入水平不低于或高于当地公务员平均工资收入水平。二是完善教师收入分配激励机制，设立学校综合奖补资金。对全市各级各类公办学校增发一个月绩效工资总额给教育部门统筹使用。逐步实现全市公办中小学平安校园奖金、文明学校奖金、办学绩效奖金等福利待遇发放标准与同级机关事业单位同等待遇，所需经费列入同级财政年度预算，调动教师工作积极性。目前，全市大部分县区已发放中小学平安校园奖金、文明学校奖金。三是落实乡村教师生活补助。根据《福建省教育厅福建省财政厅福建省人力资源和社会保障厅关于提高乡村教师生活补助标准的通知》（闽教师〔2018〕53号）精神，乡村教师（含各地纳入的边远镇区）除享受乡镇工作补贴外，享受乡村教师生活补助。目前，莆田市乡村教师生活补助政策实现全覆盖，全市各县区乡村教师生活补助均已达到或超过每人每月500元标准，2021年全市享受生活补助的学校822所，享受生活补助的教师23285人，投入资金14053.67万元。四是免费体检和免费旅游门票。为了提升教师的职业幸福感，鼓励、支持各县区党委、政府要制定优惠政策，实行教师健康工程，按照公务员体检标准和办法，由同级财政安排教师每年体检专项资金，组织教师在县级以上医院进行免费体检。

　　五、注重岗位调整，拓宽教师晋升渠道

　　2018年，中央、省《关于全面深化新时代教师队伍建设改革的意见》相继发布，其中在关于深化中小学教师职称和考核评价制度改革问题中提出，适当提高中小学中级、高级教师岗位比例，畅通教师职业发展通道。为此，市人社局、市教育局出台《关于中小学幼儿园岗位结构比例调整的通知》（莆人社文〔2019〕109号），调整我市中小学幼儿园岗位设置结构比例控制标准，所有学段高级岗位比例提高10%。同时，对在农村学校任教累计满25年且仍在农村学校任教的教师，已取得中、高级专业技术职务，不占核准岗位数直接聘任相应等级起始级岗位。完全中学在编制内职称职数统筹使用，同一学校不同年段及学科之间职数调剂使用。

　　六、加强课后服务，满足学生多样化需求

　　为贯彻落实《中共中央办公厅 国务院办公厅关于进一步减轻义务教育阶段学生作业负担和校外培训负担的意见》（中办发〔2021〕40号）《福建省教育厅等八部门关于加快推进全省中小学课后服务扩面提质工作的通知》（闽教基〔2021〕33号）文件精神，结合我市实际，我局联合市财政局等十部门印发《莆田市关于进一步推进中小学生课后服务工作的实施意见》的通知》（莆教综〔2022〕68号），在全市推行课后服务。一是课后服务“5+2”模式，即学校每周5天都要开展课后服务，每天至少开展2小时，结束时间要与当地正常下班时间相衔接。鼓励学校实行弹性离校制度，分批设定课后服务结束时间，实现与家长接送时间“无缝衔接”。同时学校对参与课后服务的教师可实行“轮班”“弹性上下班”等制度。二是课后服务内容。即普通延时托管服务及特色集体活动服务两类。普通延时托管服务指以校内教师为主力，指导学生认真完成作业，对学习有困难的学生进行安全看护、补习辅导和答疑等基础服务。特色集体活动服务指结合学校办学特色和实际，鼓励学校既要充分利用本校教师资源又可通过外聘具有资质（有教师资格证或社会专业人员资质）的教师、志愿者或引进第三方机构的方式，开展丰富多彩的兴趣小组、社团活动及拓展训练等个性需求服务，努力满足学生的不同需求，为学有余力的学生拓展学习空间。如：组织开展阅读等德育类活动，做到“以读养德”；组织开展科技、乐器、美术、书画、陶艺、茶艺、编织、剪纸等技能类活动，做到“以技促能”；组织开展未成年人喜闻乐见、乐于参与的音乐、经典诵读、舞蹈、戏曲、戏剧、曲艺、军体、棋艺、武术、球类等文体类活动，做到“以乐促智”。

　　七、开展校际交流，全面提升教学质量

　　一是为了促进我市教育优质均衡发展，提升教育整体水平和质量，莆田市教育局出台了《关于在全市开展组建教育联盟、教育集团工作的通知》，在学校管理、队伍建设、教育教学、文化建设、特色办学等方面形成联动机制。截至目前，我市共兼有27个教育联盟，其中：普通高中教育联盟5个,普通初中教育联盟10个,小学联盟10个,职业学校联盟2个。二是组织教学开放活动。2019年，我市出台了《莆田市教育局关于规范中小学幼儿园教育教学开放活动的通知》（莆教综〔2019〕11号），进一步规范我市中小学、幼儿园教育教学开放活动组织管理，在此基础上选择一些优质的学校推荐承办省级教学开放活动，有效推动我市，乃至我省普通中学的校际交流工作。

　　八、推动标准化创建，促进教育均衡优质发展

　　引导学校优化内部管理， 深化教学改革，加强内涵建设，提升学校标准化建设和管理水平。目前，全市共484所学校通过省义务管理标准化学校建设评估，创建率达69.04%。开展教育教学质量评价，树立科学的教育评价导向，加强教学过程管理，促进开齐开足课程，提升教育教学质量，强化监测结果在各类考评中的应用，将监测成绩与学校内部绩效考评等正向激励相结合，鼓励学校和教师争优创先。

　　感谢您对教育工作的关心和支持!欢迎多提宝贵意见和建议！
