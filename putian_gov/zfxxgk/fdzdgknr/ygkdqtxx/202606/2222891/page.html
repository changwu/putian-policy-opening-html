关于市政协八届五次会议第20264019号提案办理情况的答复

发布时间：2026-06-24 17:21
| | |
政策解读:

董朝霞委员：

　　您提出的《关于科学规范使用电子黑板，守护中小学生视力健康的建议》（第20264019号）收悉。感谢您对我市儿童青少年视力健康工作的深切关怀和宝贵建议，您提出的“规范使用—健康环境—协同监管—教育引导”综合防护网构想，具有很强的针对性。经会同相关部门认真研究，现将办理情况答复如下：

　　一、控制电子设备使用时长，强化督导考核

　　一是建立分层使用时长标准。结合我市实际，研究制定分学段使用标准：小学阶段单节课电子设备连续使用时长不超过15分钟，初中不超过20分钟，高中不超过25分钟，要求使用电子产品开展教学时长原则上不超过教学总时长的30%，明确非必要教学环节不得依赖电子屏幕，严禁“满堂电灌”现象。

　　二是倡导混合式教学模式。鼓励教师将电子板书、传统板书、实验操作、小组讨论等多种教学手段有机结合，严禁以电子课件完全替代传统板书。严格控制通过电子屏幕布置和完成作业的比例，鼓励纸质阅读与实践性作业，切实减少学生近距离用眼负荷。

　　三是纳入教学考核督导。将电子设备规范使用情况纳入教师教学考核与督导范围，建立信息技术辅助教学工作的监管评价机制。通过“三评一测”（学生满意度测评、教师效能评估、家长意见征集、学业质量对比分析）及时调整优化电子资源使用方式。

　　二、优化教室视觉环境，增加体育锻炼时长

　　一是全面推进教室照明改造工程。近年来，市委市政府将实施近视防控教室照明改造工程列入为民办实事项目，改造项目严格遵循《中小学校教室采光和照明卫生标准》等技术规范，全市共改造照明条件不达标教室4808间，实现上课、课后、自习、多媒体教学等4种光照度场景切换，为保护学生视力筑牢了硬件基础。

　　二是推广护眼电子教学设备。严格落实《福建省中小学教育技术装备标准》，中小学新购电子黑板等显示设备应具备健康护眼、防蓝光、防眩光、无频闪、自动亮度调节等功能的要求，优先采购通过相关安全认证的设备。联合市场监管部门加强流通领域电子教学设备质量监管，对现有设备进行排查，对不达标或老旧设备及时维修或更换。

　　三是增加户外活动时间。督促开齐开足上好体育课，着力保障学生每天校内校外各１小时体育活动时间，鼓励有条件的学校学生校内户外活动时间增加到2小时。试点构建“N+1”阳光体育课程，每周增加1节体育课。印发《关于进一步优化课间活动管理促进中小学生健康成长的通知》，大部分学校延长课间时间至15分钟，引导所有学生在课间走出教室、走向户外，缓解学习和用眼压力。

　　三、加强科普宣传和健康培训

　　一是开展常态化视力监测。严格落实中小学生每学期不少于2次的视力定期筛查制度，建立完善学生近视筛查档案，依托莆田市第一医院和莆田眼科医院两个省级儿童青少年近视防控基地，开展数据监测和专业指导。

　　二是普及科学用眼知识。通过校园宣传栏、微信公众号、致家长一封信、主题班会等多种形式，向师生和家长普及“20-20-20”护眼法则等健康用眼知识，如每年3月、9月结合近视防控宣传教育月活动，邀请省级近视防控专家宣讲团进校宣讲，累计开展现场宣讲100余场次，直接受益师生达40余万人次。

　　三是发挥健康副校长作用。目前我市600余所中小学幼儿园均已配备健康副校长，从医疗卫生机构中选聘，具有丰富的医疗卫生工作经验。健康副校长与专家宣讲团协同配合，开展面向班主任、教师、校医、家长的日常视力健康管理工作培训，指导家校协作共同纠正不良用眼行为。

　　四、加强示范引领，推进城乡协同发展

　　一是倾斜支持农村学校改造。优先支持偏远乡村学校、薄弱学校，确保公办中小学校教室照明条件达标。通过“一地一策、一校一案”的原则，明确改造任务、资金保障和施工进度，确保农村学生同样享有健康的视觉环境。

　　二是建设“护眼智慧教室”示范校。借鉴先进地区经验，选择部分学校试点建设“护眼智慧教室”或“规范使用示范校”，探索教室光环境与电子设备协同优化的最佳实践。依托“国家中小学智慧教育平台”，共享优质课件资源库，为农村学校提供优质教学资源。

　　三是强化城乡结对帮扶。 组织城区骨干教师赴农村学校开展示范教学，指导农村学校规范电子设备使用。通过“专递课堂”等形式，实现城乡教学互动，让农村学生共享优质教育资源的同时，确保用眼健康。

　　下一步，市教育局将继续深入贯彻落实习近平总书记关于儿童青少年近视防控的重要指示精神，持续完善“规范使用—健康环境—协同监管—教育引导”的综合防护网，扎实推进教室照明改造、电子设备规范使用、视力监测干预等各项工作，有效减少电子黑板不当使用对学生视力的危害，切实守护好我市中小学生的“光明未来”。

　　再次感谢您对我市教育事业的关心与支持！欢迎您继续提出宝贵意见和建议。
