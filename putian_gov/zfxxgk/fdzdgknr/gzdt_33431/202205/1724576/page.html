关于市八届人大一次会议第0135号建议的答复

发布时间：2022-05-12 09:02
| | |
政策解读:
 林志萍代表：

您提出的《关于支持国家珠宝鉴定中心、抖音直播基地等项目落地秀屿的建议》已收悉，现答复如下：

近年来，为应对疫情影响，推动鞋服制造、商贸流通等企业转型升级，我市大力发展线上直播等新零售业态。

一是强化政策保障。为培育壮大直播电商等新业态、新模式，促进我市电子商务行业提质增优，我局出台《莆田市直播新业态发展三年行动计划（2020-2022年）》，大力实施直播新业态发展“662”工程，推进直播新业态与我市优势产业资源融合发展。同时，对直播电商基地规模达到国家级标准的综合性基地采取“一事一议”。

二是加强招商对接。为推动直播新业态助力秀屿珠宝产业转型升级，积极对接字节跳动集团，推动抖音金银珠宝直播基地落地上塘珠宝城。经对接和争取，北京字节跳动科技有限公司同意启动莆田市秀屿区上塘抖音直播基地的申报程序，并委派东北抖音直播基地，对接上塘银饰珠宝产业进行现场考察评估和交易数据测试，秀屿区商务局拨付专项资金支持直播基地测试项目。2021年，为借鉴学习鞍山市岫岩抖音直播基地招商运营模式、管理机制等，由我局分管领导带队，前往辽宁省鞍山市对接洽谈推进秀屿抖音直播基地。

三是紧抓行业发展。为加强直播电商企业抱团协作和引导行业规范有序发展，联动全市90余家直播企业，推动成立莆田电商直播协会。积极对接知名互联网平台、直播平台，推动直播新业态赋能鞋服、食品、工艺美术、金银珠宝等特色产业，借助“网红效应”助力产业发展、品牌塑造。已先后落地仙游抖音直播基地、莆田工艺美术电商直播产业基地、快手鞋业直播基地等产业带直播基地，其中仙游抖音直播基地已成为全国十大抖音产业带直播基地，位居全国第六大抖音珠宝文玩直播基地。
