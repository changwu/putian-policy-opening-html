关于市八届人大一次会议第0062号建议的答复

发布时间：2022-05-12 08:54
| | |
政策解读:
 林金阳代表：

您提出的《关于建设跨境电商平台区域运营中心及配套设施的建议》已收悉，现答复如下：

自2020年国务院批复设立中国（莆田）跨境电子商务综合试验区（以下简称综试区）以来，我市各级各部门抢抓政策机遇，市商务局作为综试区工作牵头单位，会同海关、人行、税务、邮政管理等部门积极推动各项试点政策落地实施，全市跨境电子商务实现较好发展。

一、完善政策体系。相继出台《促进电子商务加快发展若干措施》《加快跨境电子商务发展六条措施》等专项扶持政策，对跨境电商零售出口、品牌培育、物流服务、项目招商等予以支持，对电商运营、供应链管理、第三方专业服务等采用“一事一议”方式给予重点支持。

二、强化招商对接。加强与亚马逊、lazada、速卖通、TikTok等重点平台的招商对接，先后举办速卖通专场招商对接会、跨境电商峰会等行业公共活动。招商引进深圳央聚集团专业运营荔城区跨境电商专业园区，荔城区央聚跨境数字园区于2021年12月开园，落地跨境电商进口线上平台。

三、拓展物流通道。围绕我市跨境电商物流短板，积极引进云途物流、递四方物流、优源物流等跨境物流企业。加强与福州、泉州和厦门等省内主要空港、海港以及国内发达口岸的联动机制，对接周边空港航运包机资源，开通东南亚专线、美国专线、欧洲专线等跨境物流通道。2022年4月27日，莆田—厦门跨境电商转关货物成功首发，这是我市作为福州关区中首次实现跨境电商零售出口转关的城市，此次跨境电商转关货物成功的首发，正是依托莆田跨境电商综合试验区各项政策优势，借助莆田市跨境电商监管中心完善的设备基础和监管力量，实现了莆田跨境电商出口通道提效扩容的新突破，将进一步拓宽我市跨境电商出口通道，有利于我市跨境电商业务量回流。
