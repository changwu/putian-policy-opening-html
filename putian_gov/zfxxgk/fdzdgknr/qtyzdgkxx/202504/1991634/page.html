关于市八届人大五次会议第1175号建议的答复

发布时间：2025-04-23 17:31
| | |
政策解读:

余黎明代表：

　　《关于加强知产保护护航新质生产力发展的建议》（第1175号）由我单位会同莆田市中级人民法院、莆田市司法局办理，现将有关情况汇总答复如下：

　　近年来，我市各有关部门始终坚持以习近平新时代中国特色社会主义思想为指导，秉持“保护知识产权就是保护创新”的理念，深化体制机制创新，构建知识产权保护联动工作格局，取得了明显成效。您在议案中指出知识产权案件裁判尺度不一、知识产权纠纷源头治理薄弱、知识产权宣传力度不强等问题，并提出统一案件裁判尺度、扎实推进源头治理、加强宣传引导等建议，具有很强的针对性和建设性。

　　一、主要工作开展情况

　　（一）统一案件裁判尺度，精准把握法律适用边界。市法院不断加强对下业务指导，统一法律适用和案件裁判标准。2024年，共参加省法院知识产权审判业务培训1场次，通过法答网回复问题33个，开展知识产权司法审判数据会商分析3次。持续做好法答网答疑工作，及时解决审判一线难点问题。同时发挥数据会商机制作用，分析司法审判中存在的短板弱项。

　　（二）扎实推进源头治理，靠前化解矛盾纠纷。着力构建多元化纠纷解决机制，推动调解工作向基层下沉，依托“千所（司法所）万会（调解会）大调解”专项行动及全市400多支“蒲公英”普法志愿者队伍、12795名志愿者达人、12245名“法律明白人”等资源，充分发挥人民调解组织遍布城乡、人民调解员来自基层的传统优势，将知识产权纠纷化解在诉前，有力在源头减少诉讼增量。2024年，全市共有知识产权纠纷调解组织11家，调解员66名，其中专职调解员2名，兼职调解员64名。为方便企业就近维权，我市还在各县区知识产权密集型产业建立部分行业性知识产权人民调解委员会，健全完善专利纠纷处理机制，关口前移，及时受理专利权人的纠纷线索，四年多来，共办结专利权纠纷案件（含电商纠纷）264件，有效地保护专利权人的合法权益。此外，市市场监管局与市法院推广知识产权“行政调解+司法确认”解纷模式，调处纠纷22件。

　　（三）着力加大宣传力度，提升知识产权保护意识。市市场监管局及有关职能部门依托每年知识产权宣传周、专利周等活动，开展知识产权进机关、进企业、进园区、进学校、进社区等“五进”宣传活动，增强社会各界“尊重知识、崇尚创新、诚信守法、公平竞争”的知识产权意识。在市市场监管局网站开通了《专利法》第四次修改在线访谈、编印《知识产权基本知识读本》，先后主办或承办了“企事业知识产权实务培训班”、“全国专利信息实务培训班”等多场培训，建立知识产权远程教育平台莆田分站，推行“互联网+知识产权培训”，参训达2000多人次。2024年，市法院深入华峰华锦有限公司、百威雪津啤酒有限公司等企业送法问需6次，大力推进中小学知识产权教育，并同湄洲湾职业技术学院、莆田学院外国语学院等院校开展模拟法庭系列活动8场次。

　　二、下一步工作措施

　　下一步，我市各有关部门将加强联动，齐心协力加强知识产权保护，护航新质生产力发展。一是组织开展知识产权相关业务培训，发挥数据会商作用，分析司法审判中存在的短板，进一步提高知识产权调处、审判业务水平。二是持续推进知识产权纠纷源头治理工作，进一步加强知识产权维权调解机构的建设，强化知识产权矛盾纠纷摸排，完善联动协调工作机制，优化调解流程，提升案件纠纷化解效率，推进知识产权纠纷在诉前一揽子化解。三是持续强化知识产权宣传和保护力度，继续广泛深入宣传知识产权领域相关法律法规和政策，在全社会营造尊重知识产权、保护知识产权的浓厚氛围。为企业提供针对性的服务和指导，引导企业合规经营，激发市场主体活力，更好服务莆田绿色高质量发展。

　　衷心感谢您对知识产权工作的关注，希望继续关心和支持知识产权各项事业发展，对我们的工作提出宝贵的意见建议。
