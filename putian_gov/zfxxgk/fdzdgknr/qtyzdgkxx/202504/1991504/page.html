关于市八届人大五次会议第1224号建议的答复

发布时间：2025-04-22 17:37
| | |
政策解读:

林国梁代表：

　　《关于加强住宅小区电梯安全监管的建议》（第1224号）由我单位会同市城市管理局办理。现将有关情况汇总答复如下：

　　一、关于严格行业准入门槛方面

　　严格维保质量安全监管，过程保障电梯安全。严格维保准入把关。开展电梯维保的单位需取得特种设备生产许可证，该证由省特检院组织评审、省市场监管局核发。取得该证需在技术人员、施工设备、检测设备等方面满足基本条件要求。本市以外维保单位到我市开展维保业务按要求需到我市市场监管局备案，均按取证时的要求配备仪器设备和安排足够的维保人员，维保单位所维保的电梯人均不得超过35台。严肃查处违法违规行为。2024年，共完成电梯检验检测共计20699台，同时以购买服务方式开展电梯维护保养质量抽查346台,结合日常监管和投诉举报，共立案查处11起，同比提高83%，其中未按规范要求开展电梯维保业务的维保单位5起、使用检验不合格或未经检验电梯的使用单位6起。严密组织信用等级评定。根据省市场监管局相关通知要求，我局每年组织开展电梯维保质量安全信用等级评价。今年已完成2024年度我市电梯维保质量安全信用等级评价工作，综合常规监督检查、专项监督检查、定期检验检测、维保与运行质量监督抽查、投诉举报及媒体曝光、年度综合检查、应急救援、行政处罚和安全事故调查处理及智慧管理、机制创新、保险服务、公益服务等项目，根据考核记分结果确定年度电梯维保质量安全信用等级，评定工作涉及62家在莆开展维保业务的电梯维保单位。根据综合记分情况，维保单位确定A级的24家、B级的26家、C级的7家、D级的1家；因在综合考评检查时，尚未在莆田区域开展电梯维保业务，免于年度评价的4家，并将在我局官网上向社会公示考评情况。针对不同等级，采取不同的监管措施，约谈被评为C和D级的8家单位，进一步加强电梯维保监管，提升维保质量。

　　二、关于配齐专业人员力量方面

　　督促物业落实管理责任，专业管理保障安全。指导各县（区、管委会）物业主管部门督促受托管理电梯的物业服务企业按合同约定落实电梯安全管理责任，建立健全物业小区电梯安全管理制度和电梯故障应急预案。同时，结合日常检查、“双随机、一公开”抽查，强化监督检查频次，及时向社会公开监督检查结果，及时信息互动，增强推进合力，确保措施到位、责任到位、监管到位；对电梯安全主体责任落实不到位的物业企业，按物业企业信用评价办法落实相应的惩戒限制措施。并在春节、“五·一”、“十·一”、两会等重要节会期间和台风、暴雨等恶劣气候条件时期，加强电梯日常监管和安全隐患排查。结合电梯安全宣传周活动，入社区开展电梯使用安全宣传和电梯应急救援演练约116场次，积极宣贯《特种设备使用单位落实使用安全主体责任监督管理规定》，督促物业管理单位配齐特种设备安全总监和安全员，严格落实特种设备使用安全风险“日管控、周排查、月调度”管理制度，全面提升安全风险管控能力。2024年,在电梯日常监管和隐患排查整治专项行动中，共排查电梯使用单位3683家、维保单位62家，排查使用未登记电梯279台，排查整改隐患问题1085个，有效遏制电梯事故发生。

　　三、关于把好价格质量关方面

　　严谨制定维修指导价格。在之前电梯行业协会发布的《电梯零配件及维修工时费的通告》基础上，指导电梯行业协会开展调研，制定、修订电梯耗材相应的等级标准与指导价格，于2025年3月份发布《莆田市电梯行业协会关于公布主要电梯零部件及维修工时费的通知》，进一步使电梯维保耗材价格相对合理。

　　四、关于健全资金筹措机制方面

　　简化维修资金拨付流程，经费保障电梯安全。简化从其代管的住宅专项维修资金中审核拨付电梯大修改造更新费用的程序。指导各县（区、管委会）物业主管部门对住宅电梯应急维修（含更新、改造、修理)的资金申请，按照《福建省住房和城乡建设厅关于紧急情况下使用商品住宅专项维修资金有关事项的通知》（闽建房函〔2019〕39号)及时审核拨付。为维护维修资金所有者的合法权益，除老旧住宅电梯安全性能技术评估和保修期满后电梯的维修、改造、更新费用可以从维修资金专户列支外，对在用的住宅小区电梯购买安全责任和“养老”保险、配备视频监控设施、加装基于物联网的电梯远程监测装置等可从维修资金专户列支。

　　五、关于加强技术支撑指导方面

　　运用智慧电梯监管系统，数智赋能保障安全。为贯彻落实《福建省电梯安全管理条例》、《电梯使用管理单位安全管理规则》，确保民众乘梯安全，市市场监管局在省市场监管局的指导下和借鉴兄弟单位经验做法基础上，结合实际，开发了莆田市电梯安全智慧监管平台，平台推广运用以来，电梯安全监管工作高质推进。全市62家维保单位全部接入平台使用，已全覆盖采集全市2万余台电梯信息，实现区域内维保作业定位打卡及救援响应、维保、救援及故障解决的无纸化录入，对电梯的应急处置进行全程监控。目前已有9085台客梯通过物联网远程监测装置接入平台，远程监测电梯故障信息30.7万余条，实现对电梯在线实时监测。其次，电梯困人救援效率大幅提升。设立24小时电梯应急救援指挥中心，建立“值班全天候、跟踪全过程”的管理体系，形成以96196为纽带、维保单位救援为主、消防救援为兜底保障的应急处置模式，构建三级应急救援体系，即一级维保单位、二级网格应急救援队伍、三级119消防救援。目前，通过96196调度，电梯救援人员到达现场平均用时13分钟，比国家规定的30分钟缩短一半多，电梯接线同比下降31.2%，被困人员同比下降29.3%。

　　下一步，我局将会同市城市管理局持续开展电梯安全筑底行动，全面提升电梯维保工作质量；加强电梯日常监管，督促物业落实主体责任；持续加大电梯安全宣传工作，落实推进大规模设备更新决策部署，持续推进住宅老旧电梯更新改造，提升住宅电梯质量安全水平，确保电梯安全稳定运行。
