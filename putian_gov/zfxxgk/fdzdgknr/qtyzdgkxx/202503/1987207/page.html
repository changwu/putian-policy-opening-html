关于市八届人大五次会议第1132号建议的答复

发布时间：2025-03-25 15:49
| | |
政策解读:

郭明霞代表：

　　《关于加强预制菜食品安全的建议》（第1132号）由我单位会同莆田市发改委、莆田市工信局办理。现将有关情况汇总答复如下：

　　一、基本情况

　　2024年3月18日，国家六部门《关于加强预制菜食品安全监管 促进产业高质量发展的通知》明确了预制菜的定义，按照预制菜定义和范围，我市预制菜相关食品生产加工主要以速冻食品(速冻调制食品)为主，目前全市速冻食品（非主食类）生产企业有59家。

　　二、主要做法

　　（一）严把许可准入。按照《中华人民共和国食品安全法》及其实施条例、《食品生产许可管理办法》和《食品生产许可审查细则》等法律法规和食品安全标准，严格生产许可技术审查，把好食品生产许可准入关。通过严格审查企业生产环境、设施设备、生产工艺及人员资质，加强原料管控、生产控制和检验管理等，保障食品生产安全，促进行业健康发展。

　　（二）加强监督检查。一是强化食品生产环节监管。依照现有标准加强监督管理，始终将预制菜列为重点品种实施监督管理，将食品生产加工过程中的关键环节、食品添加剂使用、贮存运输等重点内容作为监管重点，通过日常检查、专项整治、调研指导等方式，对我市预制菜生产企业进行现场督促指导，落实问题整改闭环。2024年配合省市场监管部门，对亚明食品实施体系检查，帮助企业从14个方面提升质量控制能力。二是强化餐饮环节监管。按照《餐饮服务通用卫生规范》、《餐饮服务食品安全操作规范》等相关规定，加强对使用预制菜经营单位的指导、检查，规范其使用预制菜的加工制作过程，促进食品安全管控。同时，鼓励使用预制菜的经营单位做好告知工作，公示预制菜的使用信息，以保障消费者知情权、选择权。目前，全市学校食堂599个，9家校外供餐单位100%通过国家HACCP或ISO22000体系认证。学校食堂、校外供餐单位100%接入莆田市“互联网+明厨亮灶”智慧监管平台，其中9家学校食堂、2家校外供餐单位成功创建省级“互联网+明厨亮灶”示范单位，均已享受地方财政安排配套的经费支持。三是强化预制菜产品监督抽检。结合省、市、县三级食品生产企业产品监督抽检，对全市涉及菜肴制品、冷冻（冷藏）调制食品企业开展监督抽检，最大程度保障预制菜食品安全。2024年，市级共监督抽检预制菜食品54批次，合格率100%。

　　（三）落实主体责任。一是督促指导食品生产企业建立健全食品安全管理制度，配齐配全企业食品安全管理人员，细化“日管控、周排查、月调度”工作职责，依法查验食用农产品原料的承诺达标合格证等产品质量合格证明，严格食品添加剂使用，切实保障预制菜食品安全。二是督促销售、使用预制菜的经营单位严格进货查验，选择使用具有相关合法资质的预制菜供货者，规范预制菜贮存及使用过程。根据预制菜保存条件和保质期贮存，及时冷冻（藏）贮存采购的冷冻（藏）预制菜食品，减少食品的温度变化。冷冻（藏）食品出库后，应及时加工制作，缩短解冻后的高危易腐预制菜在常温下的存放时间。三是提升企业管理能力，指导我市易太食品建立实施HACCP体系，提升食品安全风险防控能力，并给予2万元HACCP体系建设经费补助。同时，强化食品安全管理人员抽查培训考核，截至2024年底，全市共有302家获证企业552人参加食品安全管理人员培训考核，合格552人，企业覆盖率、合格率均达100%。

　　（四）完善标准体系。一是引导标准构建。围绕预制食品产品类别、原料生产、产品供应、加工生产与食品营养及功能等方面，加快预制食品标准研制，鼓励支持预制食品生产企业参与制定国家标准和行业标准，为食品生产提供统一规范，确保食品安全。2024年，罗屿岛食品发布《罐装冷藏蟹肉》（国家标准）和SC/T 3115-2022《冻章鱼》（行业标准），新膳海洋食品发布《调制菜肴罐头》（行业标准），红太阳精品参与制定《即食海带制品质量通则》（GB/T 45170-2024）国家标准，亚明食品对接制定预制肉类菜肴、酱卤素肉等2个行业标准。二是鼓励标准制修订。针对当前预制菜行业还存在有关规范标准尚需进一步明确和完善等问题，鼓励我市企业、社会团体、科研院所等单位积极参与预制菜相关标准的制修订工作，按照《莆田市标准化工作专项补助经费管理办法》，对符合要求的标准给予经费补助。

　　（五）助力产业发展。一是做强产业规模。我市立足资源禀赋、产业优势，发展休闲食品、海产品、酒店菜肴等预制食品细分行业，建设预制食品生产研发基地、预制食品产业园，加快建设涵江食品产业园、秀屿鲍鱼科技产业园、城厢预制菜产业园，引导预制食品及配套产业链向园区聚集发展。2024年全市6个县区中，涵江区、秀屿区、城厢区等3个预制食品产业发展集聚区入选赛迪研究院2024中国预制菜产业基地百强候选库，且均位居前三十强。二是强化技术创新。鼓励预制食品生产企业通过技术创新、设备升级等提升食品安全保障能力。2024年，亮多多食品有限公司投资2亿元建设年产400万份预制食品生产线项目，扩建净化车间、冷库等并购置食品深加工生产设备，项目均已投产，进一步拓展企业产品及扩大产能。三是给予政策支持。大力支持我市预制菜产业发展，已将亚明食品、蛤老大食品、诚壹食品等预制菜龙头企业列入全市“白名单”企业清单，在行业主管部门扶持政策、政府性融资担保服务等资源方面给予倾斜，助力预制菜龙头企业做大做强。同时，积极承接国家一揽子增量政策，抢抓政策性资金机遇，指导预制菜龙头企业申报超长期特别国债、预算内资金，在企业设备更新改造、冷链仓储项目建设方面提供资金支持，已帮助亚明中餐标准化智能厂房改建技改项目获得资金补助2902万元。

　　三、下一步工作

　　下一步，我局将会同有关部门坚决落实“四个最严”要求，全力保障预制菜食品安全。一是持续加强食品生产许可，严格按照国家相关标准规定并结合食品原料、生产工艺等因素对预制菜实施分类许可，严把预制菜生产许可关口。二是进一步加强预制菜生产经营监管，重点检查预制菜生产经营企业进货查验、生产过程控制、贮藏运输等环节质量安全措施落实情况，对检查发现的问题，责令整改到位，形成监管闭环。三是组织开展预制菜监督抽检和风险监测，严防超范围超限量使用食品添加剂，严厉打击违法违规行为，切实保障预制菜食品安全。四是督促预制菜生产经营者落实食品安全主体责任，进一步压实企业主要负责人的“第一责任”和食品安全总监、食品安全员的管理责任，将“日管控、周排查、月调度”工作制度深度嵌入企业日常管理之中。五是将积极开展宣传教育工作，提高消费者的食品安全意识。同时，也将鼓励消费者积极参与食品安全监督工作，对发现的食品安全问题进行举报和投诉，共同维护预制菜市场的良好秩序。
