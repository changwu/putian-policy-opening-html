关于市八届人大一次会议第0107号建议的答复

发布时间：2022-05-24 10:42
| | |
政策解读:

郭雄新代表：

　　你提出的《关于支持仙游创建特色品牌的建议》收悉，现答复如下：

　　根据《中共福建省委 福建省人民政府关于开展质量提升行动加快建设质量强省的实施意见》(闽委发〔2018〕6号) ，对国家市场监督管理总局新认定的驰名商标省财政一次性给予30万元奖励的政策有效期限至2020年12月31日。根据《莆田市人民政府关于加快鞋业转型升级若干措施的通知》（莆政综〔2017〕89号）、《莆田市人民政府关于印发稳鞋企促升级新十条措施的通知》（莆政综〔2019〕55号），对新获评中国驰名商标的鞋业企业予以100万元奖励的政策有效期限至2020年12月31日。根据《莆田市人民政府关于降低企业成本促进民营经济健康发展若干措施的通知》（莆政综〔2018〕102号），对被认定为中国驰名商标的企业每件商标奖励50万元的政策有效期限至2020年12月31日。根据《中共福建省委 福建省人民政府关于开展质量提升行动加快建设质量强省的实施意见》(闽委发〔2018〕6号) ，省财政对新获得核准注册地理标志商标的注册人给予一次性奖励10万元的政策有效期限至2020年12月31日。根据《中共仙游县委 仙游县人民政府关于优化投资环境、加快业发展的实施意见》(仙委〔2012〕41号）和《仙游县人民政府关于推进工艺美术产业转型升级措施的通知》（仙政文〔2015〕125号)文件规定,仙游县对“当年度企业获得中国地理标志证明商标、中国驰名商标的企业，给予10万元奖励”的政策有效期限至2019年12月31日。综上，至2020年底，对我市及仙游县获得“中国驰名商标”和“地理标志证明商标”企业的奖励政策均已到期，目前尚无新的奖励政策。

　　下一步，我局将密切关注相关奖励政策变化情况，积极协调仙游县政府及其市场监管部门，充分发展职能作用，大力支持仙游创建特色品牌。一是要加强服务。积极了解建议省市出台驰名商标、地理标志优惠政策。二是要加强宣传。通过集中培训、走访座谈等形式，向重点企业开展普法宣传，精准了解企业商标品牌有关需求，加强商标运用指导，全面提升商标注册、运用、管理、保护、服务水平。三是要加强指导。探索成立以服务电商为重点的仙游京东数字经济产业园商标品牌指导站，指导重点产业创品牌、提品质。四是要地标助农。持续跟踪“仙游建青黛”“仙游九条贡茶”地理标志证明商标申请审核情况。五是要严打侵权。进一步认真学习贯彻习近平关于全面加强知识产权保护工作的重要讲话精神，开展驰名商标、涉外商标、地理标志商标、老字号商标品牌保护。

　　最后，非常感谢您对市场监督管理工作的关心和支持，敬请在今后工作中多提宝贵意见，继续给予支持与帮助。
