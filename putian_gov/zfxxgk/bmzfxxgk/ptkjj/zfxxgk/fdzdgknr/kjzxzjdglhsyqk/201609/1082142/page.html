发布时间：2016-09-09 00:00
| | |
政策解读:

各有关单位：

经研究，决定将“珍稀植物檀香高效栽培技术研究与应用”等40项科技项目经费（往年结转）下达给你们，年度科学技术经费102万元（见附表），经费通过市财政国库支付中心拨付。请按照相关要求，认真组织实施，专款专用，年终报送经费决算。
