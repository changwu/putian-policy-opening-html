莆田市科技局关于拟推荐申报2022年度省级科技特派员后补助项目公示的公告

发布时间：2022-04-21 09:39
| | |
政策解读:

 

 

根据《福建省科学技术厅 福建省财政厅关于组织申报2022年度省科技计划项目的通知》（闽科资〔2021〕33号）文件精神，现将拟推荐申报2022年度省级科技特派员后补助项目予以公示（具体项目见附件），公示时间为2022年4月22日至4月27日，如有异议，请在公示期内通过来电、来访等形式，向莆田市科学技术局反映情况，发表看法和意见。

公示电话：0594-2653932；来访来电时间：公示期间工作日上午8：00－12：00，下午2：30－5：30；接待科室：市科技局农村科；联系人：黄杰、曾瓈；单位地址：莆田市城厢区荔城中大道1366号国资大厦2501莆田市科学技术局。

贝类饵料微藻供给技术团队

宁波大学

福建省中灵农业发展有限公司

项目构建了一级到三级微藻培养系统应用到池塘饵料微藻群落调控中；建立了花蛤亲贝促熟技术、池塘催产技术、池塘浮游幼苗及稚贝培育高产技术；申报发明专利4项（其中2项已经获得授权），发表SCI学术论文4篇。
