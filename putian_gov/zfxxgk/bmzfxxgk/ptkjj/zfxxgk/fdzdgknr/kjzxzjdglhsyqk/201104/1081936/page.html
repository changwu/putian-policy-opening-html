关于下达2011年莆田市科技项目经费的通知

发布时间：2011-04-26 00:00
| | |
政策解读:

各有关单位：

经研究，决定将“台湾优质芒果品种引种研究与示范”等29项科技项目经费（往年结转）下达给你们，年度科学技术经费56.5万元（见附表），经费通过市财政国库支付中心拨付。请按照相关要求，认真组织实施，专款专用，年终报送经费决算。
