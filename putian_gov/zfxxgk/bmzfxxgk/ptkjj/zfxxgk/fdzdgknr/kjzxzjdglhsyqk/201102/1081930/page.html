关于组织市属单位申报2011年莆田市科技计划项目的通知

发布时间：2011-02-28 00:00
| | |
政策解读:

各有关单位：

2011年莆田市科技计划项目的安排，将围绕海峡西岸经济区建设对科技的需求和“十二五”开局之年的重大目标任务、依靠科技进步，加强经济社会发展中关键共性技术的研发，有效配置科技资源，着力增强自主创新能力。本批项目包括工业科技、农业科技和社会发展科技项目，面向市本级范围申报（含北岸、湄洲岛）。为做好项目申报工作，现将有关事项通知如下：

一、申报要求

1、申报单位必须是具有法人资格并具备科研开发能力和条件的在莆市属以上（含市属）企事业单位（参照公务员管理的事业单位除外）。包括高校、科研单位以及在市工商局、市税务直属分局和市民政局批准登记的企业和单位等。

2、已承担市科技计划项目的单位，2008-2010年有2项以上（含2项）项目到期未验收（评审）的，以及未报送《2010年莆田市科技计划项目执行情况表》和《科技计划项目经费活动表》的，不受理申报本批项目。

3、项目负责人应为实际主持研究工作的科技人员，政府公务人员不能作为项目负责人。项目负责人在项目结束时年龄原则上不超过60周岁，2008年以来主持的市科技计划项目（在研）数原则不超过1项

4、项目研发时间为2-3年。项目研发资金预算编制必须真实、可行，自筹资金要有实际的投入。

5、项目申报鼓励产学研结合，联合申报科技计划项目。鼓励和支持政府拨款、单位自筹和银行贷款等多渠道、多层次筹集经费。

二、申报程序

项目申报须提交《莆田市科技计划项目申请书》（2011年版）一式二份，申请书格式从莆田科技信息网www.ptsti.gov.cn首页“下载中心”栏目下载。湄洲湾北岸及湄洲岛管委会（社会事业局、经贸科）归口负责辖区内申报项目的审查推荐，并负责项目申报材料汇总报送；市属企事业单位项目申报材料经主管部门审查后直接报送。项目申报单位和推荐单位应当认真审查有关项目申报材料的真实性和完整性，并承担相应责任。

三、申报时间

项目申报材料于2011年3月17-18日送达市政府7号楼市发展服务中心三层科技窗口，逾期不予受理。窗口受理工作人员郭荔清，电话：13959566060。

四、其他事项

1、为提高项目申报质量和立项比例，项目申报推荐数限额为：莆田学院6项，莆田市第一医院、莆田学院附属医院、九五医院各5项，湄洲湾职业技术学院、莆田市农科所各3项，湄洲湾北岸和湄洲岛管委会各2项，其它单位各1项。

2、申报医学项目，应同时提交2010年6月30日以后出具的《科技查新报告》。

3、项目申报材料应符合本通知指定的支持领域（见附件），否则不予立项。
