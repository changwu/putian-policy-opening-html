莆田市科学技术局关于开展科技计划项目监督检查的通知

发布时间：2020-11-20 16:03
| | |
政策解读:

  各县（区、管委会）科技管理部门、局机关各科室、各有关单位：

根据市委巡察四组在全市优化营商环境暨“放管服”改革“回头看”集中巡察中对我局提出的反馈意见和局党组制定的巡察反馈问题整改方案，为加强对科技计划项目的监督检查，强化项目实施过程及结题管理，进一步提高科研经费使用效率和项目实施质量，经研究，决定开展科技计划项目检查。本次检查分为双随机抽查和专项监督检查两类，具体安排如下：

一、检查时间

2020年11-12月。

二、双随机检查

根据《莆田市科技计划项目管理办法》（莆市科〔2019〕136号）《莆田市科学技术局关于开展2020年双随机抽查工作的通知》（莆市科〔2020〕63号）和《莆田市科技计划项目监督工作暂行办法》（莆市科〔2020〕105号）等文件的有关规定执行。

（一）检查内容

1.承担单位项目组织管理情况；

2.任务书要求的科研进度进展情况；

3.资金使用情况等。

（二）检查范围

1.2017年立项以来（执行期不满一年的除外）国家级、省级、市级在研项目的20%由相关业务科室随机抽取进行检查。

2.除莆田学院（不含附属医院）外，按下放权限的在研及已验收项目的30%，由相关业务科室随机抽取进行检查。

（三）组织方式

由分管领导带队，相关业务科室牵头，随机抽取监督员参加，邀请驻市司法局纪检监察组参与。

（四）工作要求

1.相关业务科室及时组织开展检查，于12月15日前完成。

2.相关业务科室将在研项目执行情况存在问题，到期项目未结题原因及处置措施等作出书面总结，于12月20日前报资源配置与监督科。

三、专项监督检查

根据《莆田市科技计划项目监督工作暂行办法》（莆市科〔2020〕105号）等文件的有关规定执行。

（一）检查范围

1.2017年立项以来（执行期不满一年的除外）省、市区域重点项目按20%进行检查。

2.2017年至2020年12月底到期未结题省、市科技计划项目。

3.下放管理权限的项目，莆田学院（不含附属医院）全部项目，其他下放管理权限单位已结题的项目。

（二）组织方式

由局领导带队，资源配置与监督科牵头，各相关业务科室配合，邀请驻市司法局纪检监察组参与。

（三）其他要求

专项检查内容还包括了各业务科室、县区科技管理部门及市直相关主管部门对科技项目管理的履职情况等。

 

附件：1.双随机抽查名录

      2.专项监督检查名录
