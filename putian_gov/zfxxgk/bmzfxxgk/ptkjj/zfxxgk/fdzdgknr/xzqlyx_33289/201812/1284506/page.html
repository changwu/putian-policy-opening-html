莆田市科学技术局关于2018年度法治政府建设情况及2019年工作思路的报告

发布时间：2018-12-19 16:14
| | |
政策解读:

 

市政府：

根据中共中央、国务院印发的《法治政府建设实施纲要（2015-2020年）》和省、市关于法治政府建设的部署和要求，围绕贯彻落实党的十九大精神以及市委、市政府的部署，经认真对照《纲要》要求，现将2018年度我局推动依法行政建设法治政府暨贯彻落实《纲要》任务的完成情况，存在的困难和问题以及2019年工作思路报告如下：

一、2018年推动依法行政建设法治政府落实情况

(一)领导重视，组织协调各项工作

2018年，我局认真贯彻执行新修订的《中华人民共和国促进科技成果转化法》和国务院办公厅印发的《促进科技成果转移转化行动方案》，为了保证相关工作的顺利进行和落实，我局着重加强对此任务的领导，将其列入重要议事日程。局党组书记梁国镇局长高度重视，亲自部署，其他局领导分工协作抓进度，业务科室和直属单位依据职能具体抓落实，努力做好各项工作，依法行政建设法治政府，促进科技创新工作取得了明显成效。

（二）主要成效

1.科技项目带动，提升综合服务水平

坚持以项目带动为主线，强化科技项目聚集科技要素和对产业技术进步的引导推动作用，围绕我市产业发展，大力开展科技创新和协同攻关，组织企业申报国家、省级和市级各类科技计划项目，通过申报材料指导和把关做好服务，组织申报了一批技术含量高、产业化前景好的科研开发和成果转化项目，解决主导和支柱产业的关键共性技术，扶持知识技术密集、物质资源消耗少、成长潜力大、综合效益好的产业。今年共获得国家级和省级立项40项，获资助1983.59万元,争取到省对市研发投入分段补助2006万元。争取到国家、省级资金位居市政府部门第九位。2018年项目申报系统受理科技计划项目63项，进入专家技术论证有54项，确定调研名单46项。安排高新技术企业奖励690万元，省级重点实验室奖励经费60万元，省科技奖配套奖励资金12万元，科技企业孵化器（众创空间）新增孵化用房奖励资金29.39万元，安排往年结转项目经费203.6万元。进一步创新管理机制，激发创新创造活力，下放二所高校、三家三甲医院科技项目自主权，自行组织项目申报及立项评审。同时，加强科技项目实施全过程的管理，及时组织开展项目实施过程的监督检查，确保项目顺利实施，提高项目经费使用效率。

2.培育创新主体，提高科技创新能力

把增强企业自主创新能力作为提升产业层次、转变经济发展方式的重要抓手，大力培育高新技术企业和创新型企业，鼓励支持科技型企业研究开发新产品、新技术、新工艺，推广应用高新技术，提高企业的科技实力和产品的技术含量。举办2018年高新技术企业认定和研发费用税前加计扣除申报培训辅导培训班，100多家科技型企业参加。开展企业大走访活动，对95家科技型企业进行大走访、大调研，到企业宣传口径优惠政策，听取企业的意见建议，发放企业走访调查表，掌握企业发展中存在的困难和问题，鼓励企业加快科技创新研发平台建设，研究新技术，开发新产品，为企业科技创新、转型升级精准把脉。把拥有专利的企业和科技型企业作为重点服务对象，建立培育计划，进行重点跟踪服务。2018年，推荐上报36家国家级高企认定、33家省级高新技术企业备案、2家省级创新型企业、科技小巨人企业12家，推荐申报省级众创空间3家，认定市级众创空间1家，省科技企业孵化器备案 8家，至目前，全市共培育55家国家级高新技术企业、16家省级高新技术企业、40家省级创新型企业，科技小巨人企业69家、科技型中小企业入库共有50家，省、市众创空间分别达10家、5家,重点实验室10家。推荐2018年省科技小巨人领军企业申请享受研发费用加计扣除奖励，海安橡胶、恒达机电、宏业机械、华峰新材料等4家科技小巨人领军企业申请享受研发费用税前加计扣除奖励资金342.5万元。与清华大学联合开展研究生社会实践活动，18名清华大学博士生在我市11家科技型企业实践6周，先后参与涉及新能源、装备制造、电子信息、精密仪器等方面科研项目共23个课题，为实践单位解决技术难题18个，举办技术培训或专题讲座6场，培训技术人员150多人次，预计创造经济效益330多万元。

3.深化院地合作，促进成果对接与转化

今年以来已邀请50多名中科院专家来莆推介最新科研成果和征集急需解决的技术难题，与企业进行项目精准对接。目前已征集技术需求20项，成功对接项目13项，纳入省STS计划项目8项，获省科技厅项目经费资助450万元。4月份，中科院海西研究院专家组来莆调研。专家组先后考察了双方共建的莆田中心建设情况，调研华佳彩、海山机械、上海电气等21家重点企业，并召开产业座谈会，进一步增强院企双方全合作的意愿。6月份，在福州海峡项目成果交易会上，市政府与上中科院上海分院、省科技厅、海西研究院四方签订共建STS莆田分中心协议书，成为我省设区市中首个中科院STS二级分中心。中科院海西研究院莆田中心工程建设顺利推进，目前已完成投资1.33亿元，一号楼18层37321㎡（其中大楼建设面积27968㎡，地下室建设面积9353㎡）竣工正式投入使用。积极开展科技招商工作，目前已有9家企业研发机构入驻签约。二号楼12层总建筑面积13600㎡经完成招投标，争取年底前开工建设。中科院STS莆田分中心的成立和海西研究院莆田中心工程的建设将积极推动中科院相关科研成果在我市落地转化，为莆田产业发展提供稳定可持续的科技支撑，通过实施项目带动分中心的建设，形成以中心吸引人才集聚，以人才支持莆田产业发展的良性循环。

(三)主要做法

1.开展科技宣传，营造科技创新筑围

通过强化活动宣传，引导公众参与，进一步提高全民科技意识。1月份，参加文化科技卫生“三下乡”集中服务活动，免费发放环境保护、食品安全、防震减灾等科普小册子以及科技政策、农村适用技术、急救、消防等科普光盘等600多份，为群众开展科技咨询答疑、及科技政策宣传辅导等。5月份举办主题为“科技创新，强国富民”的科技活动周活动。活动周开幕式现场设置LED视频播放区、科普展板展示区、展台科普宣传及医疗咨询服务区、电动汽车互动体验区等，参加人员及群众近500人。活动周现场科普宣传及展示展销形象直观，内容丰富，生动有趣，得到广大群众的好评。9月份，开展全国科普日活动，主题是“创新引领时代，智慧点亮生活”，发放科普知识、环境保护、节能减排、质量安全等宣传材料，现场为群众开展科技咨询答疑、科技政策辅导等活动。通过科技宣传，弘扬科学精神，普及科技知识，进一步推动形成讲科学、爱科学、学科学、用科学的良好风尚，为营造加快推动自主创新、促进经济发展方式转变的良好社会氛围，使“携手建设科技创新型莆田”成为全民的自觉行动。

2.科技合作拉动成果转化的“引擎”作用充分发挥

积极借助中科院及国内知名高校、科研院所的科研力量，开展院（校）地合作，促进产学研结合。至目前我市已先后与中科院上海分院、成都分院、西安光机所、清华大学、同济大学、厦门大学等30多个高校、科研院所成功合作200多项，引进及来莆服务人才150多人，解决产业技术问题300多个，同时大力推进院士专家工作站。为加快促进中科院科研成果在莆田落地转化，市科技局与中科院上海分院、省科技厅、中科院海西研究院对接商讨，由四方共同建设中科院科技服务网络计划（简称STS计划）福建中心的莆田分中心，并在第16届海峡项目成果交易会上签订共建协议书，成为我省设市区市首个的中科院STS二级分中心。至目前，我市有8项STS项目获得省科技厅科技计划项目立项，获475万元资助。

3.强化科特员队伍建设，助力精准扶贫

召开全市科特派座谈会，贯彻全省科特派座谈会精神，解读省科特派管理办法的有关问题。认定市级科技特派员104人，推荐上报省级科技特派员109人。举办两期科特派员培训班，进行水产、食品加工、农业实用技术培训，培训人数73人。制定《关于深入推行科特派实施办法》《关于认定2018年莆田市科技特派员的通知》等政策文件，建立省级农业科技特派员示范基地，帮助农业企业提高创新能力，创立品牌，做大做强。做好精准扶贫工作。一是制定了精准扶贫精准脱贫工作和分工方案，建立精准扶贫精准脱贫联系制度，局领导联系一户贫困户，相关科室和各支部配合，摸清贫困户信息，按要求定期到户联系，填写《精准扶贫精准脱贫挂钩帮扶工作手册》，此外，今年我局和大洋乡琼峰村密切配合结对帮扶5户贫困户，筹集7900元入户慰问挂钩贫困户，帮扶到户，解决部分群众资金困难。二是制定了“科技助推精准扶贫”点题自查实施方案，以问题为导向，开展自查活动。三是实施科技精准扶贫项目，成立莆田市涵江区百叶溪养蜂专业合作社，帮助该合作社做好网上注册，做好科技扶贫项目《林下中华蜜蜂饲养关键技术开发》申报及相关材料，通过建立项目示范带动贫困村民脱贫致富模式，带动贫困户从事定点养蜂，通过养蜂增加收入实现脱贫

4.履行全面从严治党主体责任，为科技发展保驾护航

深入学习宣传贯彻习近平新时代中国特色社会主义思想和党的十九大精神，加强党对科技工作的全面领导，坚定不移落实全面从严治党政治责任，不断提高党的执政能力和领导水平，为科技创新改革和发展提供坚强政治保障。全面从严治党主体责任层层落实，政治建设、作风建设得到进一步加强。认真配合市委巡察二组对科技局党组的政治巡察，对巡察组反馈的问题认真梳理，不折不扣抓好巡察整改。监督执纪“四种形态”有效落实，反腐高压态势持续保持。基层党组织建设扎实推进，党支部主题党日活动、组织生活会、“三会一课”、民主评议、谈心谈话、党务公开等制度有效落实。认真贯彻落实市委“五抓五看”要求，党风廉政建设和反腐败教育经常化、制度化,严格执行述职述廉、诫勉谈话、函询和个人事项报告等制度，力在源头上预防腐败.深入开展“１＋X”专项督查和科技项目廉政风险排查等活动,把科技管理权力晒在阳光下、关在笼子里。自觉遵守廉洁从政的各项规定，抓住科技经费使用中容易滋生腐败的源头问题，深入开展思想道德教育、法纪教育和艰苦奋斗、廉洁从政专题教育，从源头上预防腐败。加强科技管理队伍建设，努力学业务，讲修养，提高干部综合素质，规范行政行为，提高工作效率，努力开创“学习型、创新型、和谐型”机关，使科技工作跃上新台阶。引导广大党员干部弘扬先进典型的优秀品质和崇高精神,全市科技系统昂扬向上、干事创业的氛围更加浓厚。

二、存在的困难

我局推动依法行政建设法治政府，促进科技创新工作科技创新工作中做了大量卓有成效的工作，虽然取得了较大的成绩和进步，但与市里的要求还是有不少的差距，存在着一些困难和问题：

（一）企业过多的追求快速利益

高科技成果往往研发周期长，体现的是长期的效益，而多数企业乐于寻求短平快、技术含量低的产品，过多的追求快速利益，不去投资需要转化过程的科研成果。对大多数中小企业来说，生存的压力迫使他们把主要精力放在寻求扩大现有产品销售市场，热衷于广告效应，只有在企业规模达到一定程度的情况下，才有可能去寻求技术合作伙伴（高校、研究所等）。

（二）中小企业的技术市场需求还不成熟  

大多数企业特别是中小型高新技术企业，发展的寿命太短，还没有形成规模时就由于各种因素而夭折了，形成不了企业对各类技术持续的需求。科技成果要顺利转化为高新技术产品，必须具备必要的资金和接受技术的能力、管理能力和市场开发能力等。目前，大量的中小企业的技术力量薄弱，生产条件落后，投资资金不足，因此在接受科技成果时常常困难重重。

（三）投资融资体系不健全

许多尚未形成规模的企业还没有一个完整的研发预算，资金投入更为有限，市场融资渠道很窄，数量也不足。有些企业即使意识到成果的市场价值，但因成果转化本身需要大量资金，企业受到经济实力的制约，最终科研成果也未能转化。要顺利地进行成果转化，必要的资金投入是不可缺少的，目前，资金缺乏成了成果转化过程中遇到的主要困难。比如中科中涵激光（福建）有限责任公司研发的激光设备因资金缺乏导致成果转化困难。

三、2019年工作思路

2019年，我们要将继续深入贯彻落实习近平新时代中国特色社会主义思想和党的十九大精神，推动依法行政建设法治政府，促进科技创新工作，大力实施创新驱动发展战略，加快建立以企业为主体、以市场为导向、产学研紧密结合的技术创新体系，培育一批综合竞争力强的高新技术企业和创新型企业。主要保障措施有如下三点：

（一）培育科技创新主体，不断推进科技与经济的结合

企业是科技创新的主体，坚持把研发机构建在企业，将人才工作重心转向企业，将科技创新政策落实到企业，将创新资源集聚到企业，将科技服务覆盖到企业，加快建立以企业为主体、市场为导向、产学研相结合的技术创新体系。大力培育成长潜力大、对产业发展有引领带动作用的科技型企业，发展壮大高新技术企业，建立以企业主导技术创新的体制机制，形成具有自主知识产权、自主品牌 和较强核心竞争力的创新型企业集群。要加快培育发展新兴产业。围绕打造电子信息、化工（纺织化纤）新材料千亿产业集群和医疗健康、高端装备、海洋五百亿产业集群，重点围绕新一代信息技术、节能环保、新能源、新材料、高端装备制造、生物与新医药等战略性新兴产业需求部署创新链，突破关键核心技术，抢占产业发展制高点。大力运用高新技术 成果改造传统产业，促其快速转型升级发展。瞄准国内空白、全国领先，依托产业龙头，实施精准施策，制定路线图，推动倍增发展。进一步挖掘符合条件的项目申报，有针对性地组织实施一批科技项目，开启核心关键核心关键技术的攻关和新产品研发，为加强新兴产业的培育发展提供技术支撑，促进企业真正成为技术创新决策、研发投入、科研组织和成果转化的主体，构建以高新技术产业为主导的现代产业体系。

（二）做好科技服务民生，促进社会和谐进步

一是深化可持续发展理念。将科技作为支撑可持续发展的核心动力，减少经济社会发展对资源的过度依赖，积极探索创新驱动可持续发展的有效模式，重点面向生态建设和改善，综合运用各种生态新技术，促进环境保护、能源资源开发和高效清洁利用等，为我市生态安全绿色可持续发展提供科技支持。二是深入实施民生科技计划。重点在人口健康、资源环境和食品安全等领域实施一批民生科技项目。加强生态环境保护与大气、水等污染防治技术研发与应用。加强工业“三废”处理、生活垃圾处理等领域的技术攻关和示范，支撑生态文明建设；组织开展科技特派员农村基层创新创业服务活动，建立健全农村科技信息服务体系，对接省级服务平台，助推科技进村入户，使基层农民群众更直接、更有效地分享农业科技成果。同时做好科技助力精准扶贫，包括制定精准脱贫方案、领导联系贫困户制度、科技项目支持扶贫工程等。三是深入做好科技普及工作。全面贯彻落实国务院《全民科学素质行动计划纲要》，弘扬科学精神，倡导科学方法，传播科学思想，普及科技知识，组织开展科普活动，增强活动的针对性和实效性，创新活动方式，更加突出群众性、社会性和经常性。

（三）做好科技服务民生，促进社会和谐进步

一是深化可持续发展理念。将科技作为支撑可持续发展的核心动力，减少经济社会发展对资源的过度依赖，积极探索创新驱动可持续发展的有效模式，重点面向生态建设和改善，综合运用各种生态新技术，促进环境保护、能源资源开发和高效清洁利用等，为我市生态安全绿色可持续发展提供科技支持。二是深入实施民生科技计划。重点在人口健康、资源环境和食品安全等领域实施一批民生科技项目。加强生态环境保护与大气、水等污染防治技术研发与应用。加强工业“三废”处理、生活垃圾处理等领域的技术攻关和示范，支撑生态文明建设；组织开展科技特派员农村基层创新创业服务活动，建立健全农村科技信息服务体系，对接省级服务平台，助推科技进村入户，使基层农民群众更直接、更有效地分享农业科技成果。同时做好科技助力精准扶贫，包括制定精准脱贫方案、领导联系贫困户制度、科技项目支持扶贫工程等。三是深入做好科技普及工作。全面贯彻落实国务院《全民科学素质行动计划纲要》，弘扬科学精神，倡导科学方法，传播科学思想，普及科技知识，组织开展科普活动，增强活动的针对性和实效性，创新活动方式，更加突出群众性、社会性和经常性。
