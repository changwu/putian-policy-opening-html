莆田市科学技术局关于2021年度市级科技计划项目申报指南的补充通知

发布时间：2021-05-28 08:51
| | |
政策解读:

 

 

各县(区、管委会)科技管理部门、市直各有关单位：

为落实中央和省、市科技工作会议部署，坚持新发展理念，深入实施创新驱动发展战略，推进国家创新型城市建设，市科技局下发了《莆田市科学技术局关于发布2021年度市科技计划项目和奖励性项目申报指南的通告》（莆市科〔2021〕21号）。鉴于省、市级科技计划项目申报时间重叠，存在项目交叉申报情况，部分类别申报数量不足等原因，为提高市级科技项目的覆盖面和受益面，激发企业创新创业热情，引导全市开展科技研发、技术攻关和技术成果转化应用，为实施强产业、兴城市“双轮”驱动和全方位推动高质量发展超越提供科技支撑，经研究，现就有关事项补充通知如下：

一、上述文件（莆市科〔2021〕21号）项目申报截止时间延长至2021年6月15日；区域重点类别“揭榜挂帅”重大技术需求(难题)表收集时间延长至2021年6月15日；各县(区、管委会)科技管理部门推荐时间延长至2021年6月21日；各县(区、管委会)科技管理部门推荐函报送市科技局的截止时间延长至2021年6月24日。

二、技术开发与应用计划类别增加项目范围。

三、其他事项仍按原通知内容执行。

科技计划项目指南（增加）

 

计划类别

项目范围(内容)

申报条件

技术开发

与应用

 

1、种植业种质资源保护与利用。高产、优质、抗逆、抗病虫的农林作物品种及种子（种苗）规模化制繁技术。新型高效安全新农药、新型高效环保肥料，栽培基质及相关关键技术示范。

2、养殖业种质资源保护与利用。畜禽、水产优良新品种规模化繁育技术及其配套的标准化健康养殖和质量控制技术。适应养殖新模式的畜牧、水产规模化的新设施、新装备,养殖废弃物资源化利用技术与装备。畜禽水产病害预防与生态防控技术,养殖动物新型蛋白源开发与高效饲料研制。

3、农产品深加工及食品安全技术研究。优质农产品为主要原料的健康新产品，农产品精深加工增值关键技术，农产品自动化加工设备开发，农作物加工剩余物综合利用技术,农产品综合利用技术与装备

4、适应农业生产过程的云计算、大数据和物联网技术应用，智能化、精准化作业装备开发与关键技术示范。

1、本市具有法人资格并具备科研开发能力和条件的企业或农村经济专业合作组织。

2、项目负责人应为企业、经济专业合作组织法人代表或者法人代表委托授权的全职企业内部人员。
