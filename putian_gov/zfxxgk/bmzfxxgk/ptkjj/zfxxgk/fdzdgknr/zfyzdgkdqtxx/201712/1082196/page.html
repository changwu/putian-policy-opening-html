莆田市科技局关于开展科技计划项目执行情况检查的通知

发布时间：2017-12-20 16:10
| | |
政策解读:

各县区科技局、北岸管委会商务局、市直各有关单位：

为加强对科技计划项目的监督检查，强化项目的结题管理，进一步提高科研经费使用效率和项目结题率，经研究，将组织对2015年以来立项的国家、省、市在研科技计划项目和2012年以来到期未结题项目进行检查，检查方法按照《关于推广随机抽查机制规范事中事后监管工作的实施方案》（莆市科[2017]94号）执行。

一、检查内容

检查科技计划项目实施及经费管理使用情况，包括项目实施是否符合国家、省的政策要求；经费使用是否合理有效、会计核算是否规范；项目配套经费是否到位；项目具体执行情况是否按照任务书进度的要求执行；县区科技管理部门对科技项目的监管是否到位等。

三、检查组成员组成

本次检查分二组进行，每组由局领导1人带队，计财科、工业科、农业科、社发科、成果科各1人组成。具体名单随机抽取产生，局机关纪委参与监督。

四、被检查项目及单位名单

2015年以来立项的国家、省、市在研科技计划项目（其中国家、省级项目资助经费30万元以上，市级项目资助10万元以上）随机抽取50%产生（附件1）及2012年以来到期未结题项目（附件2）。

五、检查要求

我局组织的这次检查，作为全面从严治党主体责任检查的重要组成部分，各县区科技局、各项目承担单位要高度重视这项工作，把检查工作做好做扎实。

1、县区科技局要指导辖区内各项目单位按照检查内容做好相关准备材料，并指定专人配合市局组织的专项检查，保证检查工作顺利进行。

2、各项目承担单位要自觉接受检查，对检查中发现的问题，能整改的要确定整改目标，制订整改措施，明确整改责任，切实整改到位。
