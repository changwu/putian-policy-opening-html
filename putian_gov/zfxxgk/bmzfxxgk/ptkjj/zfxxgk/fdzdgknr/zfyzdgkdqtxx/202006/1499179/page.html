莆田市科学技术局关于拟资助2020年市科技项目计划与经费公示的函

发布时间：2020-06-23 17:45
| | |
政策解读:

 

 

    根据《莆田市财政局关于印发〈莆田市市级财政专项资金管理办法〉的通知》（莆财预〔2017〕159号），莆田市科技项目计划与经费实行公示异议期制度，现将莆田市科技项目计划与经费2020年拟资助的21个项目进行公示。公示时间从2020年6月24日开始，公示期为7个自然日，公示期内社会各界如对公示的项目有异议，可以书面形式向市科技局提出。异议书应写明详细的异议理由，注明异议人的姓名、所在单位和详细地址及联系方式。

   受理异议单位：莆田市科技局资源配置与监督科、驻市司法局纪检监察组（邮编编码：351100）；公示电话：2655519、2678158。

 

   附件：莆田市科技项目计划与经费2020年拟资助安排表
