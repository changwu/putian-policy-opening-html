关于协助开展莆田市新型功能材料龙头企业技术需求调研工作的通知

发布时间：2020-11-09 14:56
| | |
政策解读:

 

各县区（管委会）科技主管部门：

为进一步深化中科院和莆田市的院地科技合作，深入调研莆田市新型功能材料产业发展现状及存在问题，了解莆田市新型功能材料龙头企业技术需求及行业关键共性技术需求，莆田市科技局定于2020年10月30日起组织STS莆田分中心、莆田产业技术研究院前往相关企业进行调研，请各县（区）、管委会科技部门予以配合，并通知相关企业做好调研准备。调研行程安排如下：

附件1

调研目的及内容

一、调研目的

为深化中科院与莆田市科技合作，研究编制《莆田市深化院地科技合作发展研究(2020－2022年）》，根据编制流程，需要系统调研莆田科技创新和产业发展顶层设计蓝图以及莆田科技和产业发展主体的发展意图，为科学、客观、合理地提出莆田市和中科院深化科技合作的发展建议提供一手数据资料。

二、调研方式和工作内容

走访企业：重点了解莆田市主导产业龙头企业关键核心技术攻关能力，以及企业“卡脖子”重大技术难题，引领性、前瞻性、颠覆性技术储备及研发任务，创新型平台建设规划，当前和中科院科技合作现状及想法，了解企业家对推进和中科院科技合作的相关建议和诉求。主要研讨四个方面问题：

（1）企业研发生产中亟需解决的关键技术需求有哪些？企业所属行业产业链所面临的共性行业关键问题有哪些？目前应对行业共性问题的解决方式是？

（2）企业每年的研发投入比例（及研发方向）？目前专门从事研发工作的人员比例？有没有专门设立研发部门？有没有用于研究的大型设备？企业是否承担过哪些国家级的研发项目？

（3）企业跟哪些中科院研究所开展了合作，跟莆田以外哪些院所合作较多？合作方式是技术入股、委托研发、合作研发、购买现有成果还是其他？这些形式哪些是比较常用的？

（4）企业对于和中科院科技合作有何诉求或建议？
