关于印发《莆田市科技局节能规划》的通知

发布时间：2009-03-31 00:00
| | |
政策解读:

各科室，直属各单位：

为贯彻落实《公共机构节能条例》（国务院令第531号）,根据《关于进一步加强公共机构节能工作的通知》（闽政管综[2009]45号）文件精神，结合我局实际，制定《莆田市科技局节能规划》，现印发给你们，请认真遵照执行。

 

莆田市科技局

二ＯＯ九年三月十七日

 

莆田市科技局节能规划

(2009—2010年)

 

为了深入学习实践科学发展观，全面贯彻落实《公共机构节能条例》和《节约能源法》，圆满完成我省“十一五”规划提出的节能目标任务，市科技局积极开展节能规划。节能是我国经济和社会发展的一项长远战略方针，也是当前一项极为紧迫的任务。公共机构节能是贯彻落实科学发展观，加快建设资源节约型、环境友好型社会的重要举措，也是公共机构加强自身建设、树立良好社会形象的必然要求。同时，公共机构带头节能，对于增强公众的节能意识，在全社会形成节能的良好氛围，具有积极的导向和示范作用。

一、指导思想

以邓小平理论、“三个代表”重要思想和实践科学发展观为指导，认真贯彻落实党的十七大精神，按照党中央、国务院关于建设节约型、环境友好型社会的要求，以《中华人民共和国节约能源法》、《公共机构节能条例》为依据，以提高公共机构能源利用效率为核心，以建设节约型机关为目标，加强领导、健全组织、强化管理、深化宣传，积极推进我局公共机构节能工作的开展，逐步改善公共机构用能现状，充分发挥公共机构在全社会节能工作中的示范作用。

二、基本原则

坚持不影响工作效率和干部职工生活质量的原则；坚持技术节能和管理节能相结合的原则；坚持突出重点、分类指导的原则；坚持约束与激励相结合的原则；坚持领导干部带头，全体干部职工共同参与的原则。

三、主要目标

2009年至2010年我局公共机构节能工作的主要目标：

（一）2009年工作目标

积极开展公共机构节能宣传、培养公共机构工作人员良好的节能意识和节能习惯；通过加强日常节能管理，推行低成本、无成本节能管理措施，提高能源利用效率，切实降低能源消耗；通过大力推进新能源和节能新技术、新产品的应用，加快用能设备的节能技术改造，提高用能设备能效。

( 二 ) 两年目标

通过不懈的努力，逐步完善公共机构节能制度，建立健全分级管理、职责明确；加强节能技改，全面完成公共机构节能灯具、节水型器具更换，电热水器、空调节能等改造工作。到2010年，初步形成科学的节能管理体系，保障公共机构节能工作持续、有效开展。

四、积极推广节能技术应用

抓好节能工作，加强技术节能是根本。只有不断推进科学技术在节能中的运用，才能保证节约的效能最大化。

1、加快用能设备节能改造。逐步淘汰高能耗的空调和计算机、打印机等用电设备；对耗能量大的空调、电热水器等用能设备，在综合考虑费效比的基础上，采用变频调速、无功补偿等节电技术，积极实行节能改造，提高能效水平。

2、积极应用节能新产品，大力开展公共机构“绿色照明”行动，逐步淘汰高能耗灯具，更换为节能灯具；楼梯、走廊、卫生间等公共场所的照明，安装节能灯。逐步更换公共机构办公区内的水龙头、洁具为节水型器具，杜绝跑、冒、滴、漏和长流水现象。2010年年底前，公共机构要完成节能灯具和节水型器具的更换或节能改造工作。

五、节能实施主体

根据《公共机构条例》(以下简称《条例》)第二条规定,全部或者部分使用财政资金的国家机关、事业单位和团体组织均为公共机构。节能实施主体:按照《条例》规定，我局切实加强节能工作，组织相关领导，对本部门、单位的节能工作全面整理，实行节能工作目标责任制。开展公共机构节能宣传、教育和培训，普及节能科技知识，提高大局意识，责任意识和依法节能意识，扎实抓好节能工作，努力实现我局公共机构节能规划的目标任务。

六、保障措施

为保证我局共机构节能工作的持续、有效实施，首先要加强组织领导，明确目标责任，构建工作网络，建立健全市级公共机构节能工作的组织管理体系。

1、建立和完善公共机构节能工作领导机构。根据《条例》规定和要求，进一步地完善节能组织机构，保障节能工作顺利进行。

2、构建公共机构节能工作网络。为保证节能工作的有效开展，我局公共机构依据单位性质实行有针对性的管理，构建起完善的节能工作网络，让节能工作做到细节化，规范化。

3、建立节能联络员管理体系，根据（国管办发〔2008〕49号）《关于报送公共机构节能工作联络员的通知》和福建省人民政府机关事务管理局《关于建立公共机构节能联络员制度的通知》(闽政管综〔2008〕260号)文件精神,各单位、部门相应建立节能联络员管理体系，形成从上到下，单位与部门之间的节能信息沟通与业务交流的关系，确保节能工作的联系制度化、正规化。

七、扎实开展节能宣传教育

公共机构节能的工作需要广大干部职工的共同参与，再好的技术需要人去使用，再好的制度需要人去遵守，再好的计划也需要人去落实。因此，广泛开展节能宣传教育，增强干部职工的节能意识和技能尤为重要。

1、加大节能宣传力度。结合实际，在我局有针对性地开展形式多样、内容丰富的节能宣传活动。经常宣传公共机构节能方针政策、法律法规和标准规范，及其在经济、社会发展中的示范作用和重要意义，引导干部职工正确认识国情，增强节能意识，增强能源节约的紧迫感和责任感，做到人人崇尚俭朴节约，形成浪费可耻、节约光荣的良好风尚。

2、做好节能培训工作。经常进行能源教育和日常节能技术、技巧培训，培养广大干部职工良好的用能、用水习惯，形成“人人节约、事事节约、处处节约”的良好氛围。

当前节能已成为我国经济和社会发展的一项长远战略方针，也是当前一项极为紧迫的任务。只有不断的提高节能意识，加强节能监督，形成良好的节能环境，保证每份能源都能用在实处。虽然在平常生活中还存在节能意识比较淡薄、节能管理体制不够健全、节能技术推广应用不够等因素，但我局领导充分意识到节能工作任重道远，公共机构要率先垂范、带头节约，充分发挥公共机构在全社会节能工作中的示范作用，为推进我市经济社会全面发展作出新的贡献。

二ＯＯ九年三月十七日
