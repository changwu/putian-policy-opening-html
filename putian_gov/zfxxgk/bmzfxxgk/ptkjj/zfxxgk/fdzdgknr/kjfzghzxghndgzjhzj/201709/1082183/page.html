莆田市科技局关于征集开展“一带一路”科技创新行动计划项目需求的通知

发布时间：2017-07-25 16:15
| | |
政策解读:

市直有关单位、高校、科研院所，各县区科技局：

为贯彻落实2017年5月14日习近平主席在“一带一路”国际合作高峰论坛上发出倡议：启动“一带一路”科技创新行动计划，开展科技人文交流、共建联合实验室、科技园区合作、技术转移4项行动。根据《福建省科学技术厅关于征集开展“一带一路”科技创新行动计划项目需求的通知》（闽科外〔2017〕1号）要求，推动我市与“一带一路”沿线国家在更广领域、更高层次上开展科技创新合作，现征集如下：

一、科技人文交流

(一)短期科研。各单位根据与沿线国家合作基础，分别提出计划接待沿线国家青年科学家来华的人数和批次（填报附件1）。科技部拟于近期开展相关计划征集，并将予以资助。

(二)培训班。分为官员、管理人员、技术人员培训和青年创新创业人员培训两类。各单位拟开展此项工作的计划需求（填报附件2）。

（三）科技创新智库交流。各单位与沿线国家建立科技创新政策沟通机制，拓展规划制定、政策研究等科技创新智库建设情况或需求（填报附件3）。

二、共建联合实验室

与沿线国家共建联合实验室或研发中心的情况或计划（填报附件4）。

三、科技园区合作

与沿线国家共建科技园、产业园、农业技术示范园、孵化器等各类园区的情况或计划（填报附件5）。

四、技术转移

各单位推荐与沿线国家开展双向技术转移工作的平台或中介服务机构。（填报附件6）。

五、重大科研合作项目

与沿线国家开展或拟开展的重大科研合作项目（填报附件7），我局将择优予以支持及推荐省科技厅。

六、科技企业“一带一路”国家市场服务需求

请组织相关企业填报“一带一路”国家市场服务需求调查表（填报附件8），可汇总报送也可请企业直接邮件报送。

请各单位于7月30日前将各附件汇总盖章后报送市科技局科技合作与成果科，并将电子版材料发送至以下电子邮箱。
