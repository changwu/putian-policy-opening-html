莆田市科技局关于征集第十七届“6·18”科技创新平台参展项目的函

发布时间：2019-04-19 10:49
| | |
政策解读:

 

各县（区）科技局、各有关单位：

    根据《福建省科技厅关于征集第十七届“6·18”科技创新平台参展项目的函》（闽科成函〔2019〕8号）的要求，现征集科技创新平台参展项目，详细征集范围和要求请登录福建科技厅网站（http://kjt.fujian.gov.cn/）通知公告查询。

请认真填报《“6·18”科技创新平台展示项目征集表》（见附件1），或《与我省企业合作省外国家级创新平台展示项目征集表》（见附件2），于5月3日前将电子表格以及3-5张项目图片（大小1M以上）发送至科技合作与成果科邮箱fufuxin2005@163.com。

附 件:1.《“6·18”科技创新平台展示项目征集表》

2.《与我省企业合作省外国家级创新平台展示

项目征集表》
