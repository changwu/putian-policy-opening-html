2006年度工作总结和2007年度工作思路

发布时间：2006-12-12 00:00
| | |
政策解读:

2006年，市科技局在市委市政府的领导下，围绕市委、市政府提出的“经济翻番、港城崛起”战略部署，树立和落实科学发展观，确立建设创新型城市的战略主导地位，认真做好我市科技发展工作，在科技创新、院地合作、三大科技发展工程、六大科技示范基地建设等方面，真抓实干，取得了一定成效。

一、2006年主要工作

（一）实施项目带动战略，全面提升科技竞争力

1、实施项目带动，促进科技事业发展。大力实施“项目带动，科技推进”战略，以项目带动推进科技创新，以科技创新强化项目带动，集中力量抓好科技项目的开发引进和科技成果的产业化工作。通过组织和指导实施科技项目，有效地推进了科技、经济和社会的协调快速发展。2006年新上国家火炬计划项目2项、星火计划项目4项，国家农业科技成果转化项目1项，科技部、财政部富民强县专项行动项目1项，国家自然科学基金1项，新上省科技计划重点项目24项；获得国家、省项目经费资助902万元。下达市级科技计划项目91项，安排经费687万元。2006年共获得专利授权156件，其中发明专利21件、实用新型专利53件、外观设计专利82件。实施高新技术项目，培育高新技术企业，加快我市高新技术产业化，使高新技术产业成为我市经济发展的新增长点和支柱产业。同时，把好科技计划项目立项关，在前期对项目充分调研考察的基础上，实行重点科技项目专家评审制度，根据《莆田市科技计划（重点）项目立项评审实施办法》，今年首次采用专家库随机抽取评审专家的办法，做到科学、公正，不断完善科技计划项目立项工作程序。

2、建设高新区，实现产业新跨越。通过落实和制定技术开发扶持政策、高新技术扶持政策、财税扶持政策等手段逐步引导企业加大科技开发的投入力度，促进建立技术创新机构，不断提高自主创新能力。高新区现有企业270家，其中：外资企业146家，产值超亿元企业16家，规模以上企87家，高新技术及技术先进型企业24家，电子及配套企业81家。目前，高新区内普通企业技术开发经费能够占到当年销售收入的1％，规模以上企业能够占到2-3％以上，高新技术企业则可占到5％以上。通过倡导企业重组、改造升级传统产业，积极发展高新技术产业、装备制造业、淘汰落后设备，区内企业先后完成技改投资15.32亿元。12家重点骨干企业建立了技术研发中心，与厦大、福大、福师大、莆田学院等高校建立长期合作关系，并有德信电子、华光电子、安特半导体等多家企业与中科院或境外企业达成技术成果对接，形成以龙头企业自主创新为主互动追赶式科研创新格局，企业研发意识不断增强，地域品牌创建不断进步。

3、寻求项目对接，促进科技成果转化。千方百计征集企业技术需求和难题，上报对接项目，组织企业参加6·18项目成果交易会和9·8投洽会。市科技局上报市政府对接项目30项，总投资82676万元，企业技术需求21项；上报省科技厅对接项目8项，总投资20459万元，企业技术需求15项，上报的这些项目成果对接、企业技术需求难题涉及我市30多家企事业单位生产过程遇到急需解决的技术难题，涵盖现代农业、电子信息、机械制造、食品加工、环保、化工等行业。组织10多家企事业单位有关人员参加“福建民营企业科技项目推介专场”和“海峡两岸科技中介服务论坛”等。项目成果12项参展。我市有7项省科技重大专项成果对接签约，总投资2.68亿元。

（二）创新发展特色，提高科技工作显示度

1、召开全市科技大会。 全国和全省科技大会的召开，为我市科技工作提出了明确的工作方向，创造了良好的发展机遇。2006年12月14日，有600多人参加的全市科学技术大会隆重召开，出台《增强自主创新能力建设创新型城市的决定》、《莆田市科学技术奖励暂行规定》、《莆田市“十一五”科技发展规划纲要》及《莆田市中长期（2006-2020年）科学技术发展规划纲要》四个文件，明确了我市建设创新型城市和今后十年科技工作的总体要求、目标任务和政策措施，是指导我市建设创新型城市的纲领性文件。会议决定力争2015年我市进入创新型城市行列，要增强自主创新能力，科技进步水平要显著提高，产业核心竞争力明显提升，高新技术产业迅速发展，科技创新环境和基础条件明显改善，创新人才队伍不断壮大，全社会科技投入大幅增加，科技创新能力达到全省中上水平。会上表彰了获得省科学技术奖获奖和市科技进步奖获奖项目、完成单位和主要完成人，并为首批市级企业技术中心授牌。

2、实施三大科技工程，建设六大科技基地。实施高新技术产业发展工程。把电子信息、生物技术与医药、新材料三大领域作为我市高新技术产业化发展重点；实施农业科技发展工程。实行资源开发和市场开发技术并举，应用农业高新技术改造传统产业，走农业可持续发展路子；实施可持续发展科技工程。以解决人口、资源、环境重大问题为出发点，以提高人民的生活质量为主线，以科技创新和体制创新为动力，以构建和谐社会为目标，进一步强化区域创新体系和科技综合服务体系建设，全面推进科技、经济、社会与环境的协调发展。六大科技示范基地已全部挂牌成立。国家级液晶显示（LCD）产业基地，目前基地入驻电子信息类企业已达82家，其中年产值超亿元企业6家，规模以上企业24家，高新技术及技术先进型企业20家，吸纳从业人员3万人，专业科技人员4000人；中俄科技合作（莆田）示范基地，目前，基地内的龙头企业“福建省安特半导体有限公司”已成功地引进俄罗斯的4英寸、6英寸集成电路芯片生产技术，并聚集相关生产配套、应用的电子企业家有62家。同时有俄罗斯的优质甜菜、甘蓝菜、仙菜、豇豆、白洋葱等十几个蔬菜品种在基地内“华林蔬菜有限公司”试种成功，创造出可观的农业效益，为进一步开展多领域中俄科技合作打下良好基础；中科院福建（莆田）航天育种种苗基地和食（药）用菌研究推广基地持续快速发展，现正研究中科院微生物所交接的30多个珍稀(药)食用菌品种的生物学特性，进行示范栽培，并初步筛选出秀珍菇高产优质菌株1个、经济性状好的灵芝系列品种3个，白色茶薪菇新品种进入出菇管理阶段；中科院（莆田）水产繁育基地和莆田名优果蔬出口基地，认真组织项目实施，扎实推进。

3、院地合作取得明显成效。院地合作有效地促进了中科院实施的知识创新工程、科学技术转移和地方经济实现可持续发展有机结合。12月18-21日，我市在北京成功召开中科院－莆田2006年项目对接会，与中科院新签订合作项目14项，总投资4亿多元，并与中科院就今后进一步加强院地合作工作达成了共识。目前我市共引进中科院科技项目73项、科研成果50多项，《纳米服装面料》、《锂电池自行车》、《无苯胶生产技术》、《航天育种项目技术合作》、《LCD用高端偏振片湿法拉伸技术》等30个成果已正式落地，科技项目目前已投产50项，这些项目涉及光机电、水产、农业、化工、食品、环保、纳米技术等七大领域，有些项目逐步形成产业化规模，年产值超过12亿元。同时建立长心麒麟菜、蔬菜航天育种、药（食）用菌研究推广等8个院地合作基地，每年可为农民增收2亿元，有力地促进了水产养殖、食用菌、果蔬种植业的健康发展。

（三）围绕发展主题，营造科技事业和谐环境。

1、迎接市人大《科技进步法》实施情况执法检查。迎接市人大执法检查组对我市贯彻实施《中华人民共和国科学技术进步法》和《福建省科学技术进步条例》情况进行执法检查，召开6场座谈会，实地视察多家科技先进单位或企业。执法检查组听取市政府和市科技局情况汇报后认为，近三年来，市委、市政府高度重视科技工作，市科技局当好参谋，协同县（区）、市直相关部门大力宣传《科技进步法》，将贯彻实施《科技进步法》贯穿于科技进步考核工作的全过程。各县（区）党政一把手亲自抓科技第一生产力，有效地解决了科技进步工作中的一些具体困难和实际问题。同时，充分发挥科技示范功能，大力推行产学研相结合，加强企业技术研究开发机构建设，极大地促进了农业产业化和高新技术产业化的发展，高新区的建设取得明显成效。充分体现了我市科技竞争的综合实力和科技进步工作的总体形象，是我市全社会重视科技、依靠科技、发展科技的共同结果。同时，市人大对我市科技工作存在的薄弱环节作出审议意见，我局为市政府代拟反馈意见。通过市人大的视察，极大地促进了《科技进步法》和《科技进步条例》在我市的贯彻实施。

2、提升全民科技素质，开展科技活动周活动。2006年科技活动周的主题是“自主创新，建设海西，加快湄洲湾港口城市建设”。活动包括开展社会主义新农村试点村建设的科普工作、禽流感防治技术培训、科技卫生服务进村入户、青少年科技传播行动暨百场科普讲座（报告）进百校、科教进社区、市科普事业发展研究会成立大会、科技进企业、科普挂图巡回展、走进信息时代专题科普、海峡西岸公众创新知识竞赛和走进新农村知识竞赛等活动。

（四）全面贯彻落实党风廉政、综治、民主评议政风行风、机关效能和计划生育等工作

1、市科技局贯彻落实中共中央颁发的《建立健全教育、制度、监督并重的惩治和预防腐败体系实施纲要》，建立学习党风廉政法规制度，定期进行党风党纪、廉政和社会主义荣辱观教育。履行管理和监督职责，建立完善管理和监督制约机制，对所辖部门、单位的党风廉政情况和领导班子、领导干部廉洁从政进行监督、检查和考核。贯彻党内监督各项制度，签订党风廉政建设责任书，规范干部廉洁从政行为，增强领导干部廉政勤政自觉性。

2、进一步贯彻落实《福建省社会治安综合治理工作纲要（试行）》，市委、市政府《关于加强社会治安防范工作的意见》和《关于开展建设“平安莆田”活动的实施意见》精神，市科技局与各科室、直属各单位层层签订责任书，并加强检查督导，促进责任书提出各项工作措施的落实。定期举行安全大检查，查找存在的安全隐患，督促各单位抓好整改。同时做好机要保密、机要、科技档案管理等工作。

3、把民主评议政风行风工作摆上重要的议事日程，营造良好氛围，共召开13次专题和相关会议研究评议政风行风工作。召开多场座谈会、专题会，征求意见。深入基层，明查暗访，指导县区政风行风评议工作。围绕选题评议，提出整改措施。狠抓整改落实，组织各单位认真开展整改和考评验收工作。在全市最后评比中我局总成绩名列前茅。

4、根据市科技局自身特点，把机关效能、政务公开融入科技工作中，制定《市科技局机关绩效评估指标体系》进行量化考评，客观、公正地对市科技局工作绩效进行评估，提高行政效能和工作效率。每季度在市级政务公开栏公开1期，对内公开包括财务、话费、接待、评优评先考勤等，答复人大、政协提案6件，做好件件有答复、有落实。

5、坚持以人为本，把服务贯穿于计生工作的全过程。抓好本单位干部职工的计划生育日常管理工作，落实各项规范化管理措施，做好计划生育、优生优育、健康等知识的宣传和普及，引导干部职工树立科学、文明、进步的婚育观念。把计划生育作为评先评优、资质评定等工作的重要条件之一。

2006年，市科技局取得了可喜的成绩，但也有不足之处，主要表现在：引导全市科技人员和科技力量发挥科技是第一生产力的机制和体制创新不够，科技自主创新能力不强，科技投入不足，科技条件尚差，科技支撑和引领社会经济发展的力度较弱等。

二、2007年工作要点

2007年市科技局紧紧围绕市委、市政府作出的《增强自主创新能力建设创新型城市的决定》以及《市政府工作报告》要求，着力推进创新型城市的建设进程，认真做好2005-2006年度全国科技进步考核及争创先进二连冠，继续实施三大科技工程，加快建设六大科技基地。开展院地科技合作，引进一批重大高新技术项目，开发一批具有自主知识产权的高科技产品，壮大高新技术产业。提高我市科技核心竞争力，推进自主创新成果产业化，组织评审科技进步奖，加大打假和防盗版力度，保护知识产权。为“经济翻番，港城崛起”提供有力的科技支撑。

（一）大力推进科技进步，争创全国科技进步先进城市二连冠

以创建全国科技进步先进城市为契机，按照全面、协调、可持续发展观的要求，紧密联系工作实际，找准推动科技进步和实现跨越发展的结合点，在前两轮创建工作的基础上，认真做好2005-2006年度科技进步考核验收并争取先进城市二连冠。

（二）实施“十一五”和中长期科技发展规划，建设创新型城市

坚持“自主创新，重点跨越，支撑发展，引领未来”的指导方针,确立我市增强自主创新能力、建设创新型城市的主导战略地位。实施“十一五”和中长期（2006-2020）科技发展规划，基本建立以企业为主体、政府为引导、市场化运作、产学研相结合，适应市场经济体制和科技自身发展规律、具有莆田特色的自主创新体系。从全局和战略高度出发，充分认识增强自主创新能力，建设创新型城市的重大意义，将其作为贯彻落实科学发展观的具体行动，作为推进发展模式转型的实际举措，采取切实有效的措施不断增强城市的持续创新能力和核心竞争力，到2015年进入创新型城市行列。

（三）发挥院士、专家和学者的重要作用，举办院士专家故乡行活动

充分发挥莆仙籍在外院士、专家、知名企业家的人才资源优势，架设在外人才与家乡的沟通桥梁，结合省委、省政府9月份举办的“院士八闽行”活动的契机，在我市举办一场院士专家故乡行活动，邀请有关院士、专家、企业家等来我市考察工业园区、相关企业和重点建设项目，促进我市有关部门、企业与院士、专家、知名企业家直接对话，寻找合作平台。

（四）引进和实施一批重大高新技术项目,开发高新科技产品

引进一批重大高技术项目，继续组织实施一批发展关联效应大、支撑产业升级作用显著的重大科技攻关项目，切实解决我市主导和支柱产业发展中的技术瓶颈和技术难题。掌握一批具有自主知识产权的关键技术，研制和开发一批有市场竞争力的高新技术产品，打造一批具有自主创新能力的创新型企业，形成一批具有核心竞争力的产业集群，造就一批科技水平高、在国内外具有知名度的优势企业和自主品牌。走出一条科技含量高、经济效益好、资源消耗低、环境污染少、人力资源优势得到充分发挥的新型工业化道路。

（五）继续实施三大科技发展工程，加快建设六大科技基地

实施高新技术产业发展工程。把电子信息、生物技术与医药、新材料三大领域作为我市高新技术产业化发展重点；实施农业科技发展工程。实行资源开发和市场开发技术并举，应用农业高新技术改造传统产业，走农业可持续发展路子；实施可持续发展科技工程。以解决人口、资源、环境重大问题为出发点，以构建和谐社会为目标，进一步强化区域创新体系和科技综合服务体系建设，全面推进科技、经济、社会与环境的协调发展。继续把六大科技基地建设作为今后重大科技工作任务，采取切实有效的措施，全面推进基地建设再上一个新台阶。对国家级液晶显示（LCD）产业基地、中俄科技合作（莆田）示范基地和中科院福建（莆田）航天育种种苗基地、中科院微生物所福建（药）食用菌研究推广基地，继续精心培育，巩固良好的发展势头，促其持续快速发展；中科院（莆田）水产繁育基地，要充分利用省科技专项计划项目的支持，认真组织、扎实推进。对莆田名优果蔬出口基地，集中力量，抓好基地项目实施。

(六)深化院地合作，筹备海西工业研究院莆田分院和引进大学前期调研

巩固加强多年来与中科院各研究所的科技合作关系，利用现有科技局科技服务平台与中科院技术转移中心服务平台对接，拓展合作领域，形成多层次、多形式、全方位的科技合作交流网络，实现院地合作交流，从以科技项目合作为主向科技经济一体化合作转变，加快科技成果转化，提升我市产业技术水平。与省物构所联合共建海西工业研究院莆田分院，在技术研发、科研服务、产业化等方面有效地整合科技资源，打造全新的科技创新平台。认真落实科教兴市的战略，做好引进一所知名大学的前期调研工作，力争把我市打造成科技和教育的强市。

（七）组织评审科技进步奖，奖励优秀科技人员

落实市委、市政府关于要千方百计培养人才、广开渠道吸纳人才、合理开发使用人才、创造条件留住人才的决策，组织专家评审莆田市第十二届（2005-2006年度）科学技术奖，通过评审奖励一批我市科技、经济和社会发展中作出突出贡献的科技成果和拔尖科技人才，形成尊重劳动、尊重知识、尊重人才、尊重创造的良好氛围，使优秀的科技人才脱颖而出。不断完善科技评价体系和奖励制度，使我市的科技成果转化步入高速发展的快车道。

(八) 加大执法力度，保护知识产权

认真贯彻实施知识产权法律法规，加大行政执法力度，积极参与市保护知识产权专项行动，推动建立健全跨部门的知识产权执法协作机制。建立健全适应新时期专利工作需要的工作体系，要健全市知识产权局的机构，争取尽快落实市知识产权局编制，增加人员和经费，充实专利工作队伍，搞好自身建设。积极推进技术创新，努力提高我市核心知识产权的数量和质量。进一步加强知识产权宣传工作，继续推动开展“保护知识产权宣传周”活动，普及知识产权保护知识，提高全民知识产权保护意识。

（九）整合科技资源，做好科技中心建设前期工作

按照市委专题会议的要求，抓紧整合资源，筹集资金，进行资产评估，作出初步设计方案，与相关单位通力合作、密切配合，加快科技中心前期建设。

（十）继续做好党建、党风廉政建设和反腐败、民主评议政风行风、综治、平安莆田、计划生育、精神文明、效能建设、绩效评估和党务政务公开等工作

1、贯彻落实中共中央、国务院、中纪委和市委、市政府及关于党风廉政建设的部署和要求，加强党风廉政建设，建立党风廉政建设责任制，严格执行廉洁自律各项规定，互相监督、互相支持。严格遵守“四大纪律八项要求”，树立社会主义荣辱观，执行领导干部廉洁自律各项规定和《中共莆田市委关于加强和改进作风建设的若干意见》，扎实抓好理论学习，加强廉政勤政建设。

2、按照市委、市政府关于创建“平安莆田”的总体要求，结合本单位具体情况，认真组织实施。积极支持和参加当地的社会治安综合治理工作。全面推进安全体系建设，健全和完善社会治安综合治理长效工作机制，切实做到社会治安综合治理、创建安全单位工作与科研、科技管理工作同计划、同部署、同检查、同评比，促进综治创安工作与其它工作同步开展。同时做好精神文明、保密和档案等工作。

3、坚持“单位负责，条条保证，以块为主，条块结合”的原则，抓好本单位的计生的日常管理工作的同时，为农村计生“三结合”工作给予支持，组织开展人口与计生科研活动，支持计生事业的稳定健康发展。切实做到责任到位，措施到位。要把执行、检查、监督、考核人口目标的责任落到实处，坚持实行“一票否决”、责任追究奖惩的制度。

4、抓好政务公开和机关效能工作。深化政务公开工作，实现政务活动全过程公开，加强监督检查力度，落实政务公开“五项制度”。加强机关效能建设，做到机关效能与行风评议相结合，提高行政效率。
