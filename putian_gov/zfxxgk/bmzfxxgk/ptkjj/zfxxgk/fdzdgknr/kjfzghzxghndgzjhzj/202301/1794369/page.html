莆田市科学技术局2022年政府信息公开工作年度报告

发布时间：2023-01-12 15:22
| | |
政策解读:

 

根据《中华人民共和国政府信息公开条例》（以下简称《条例》）以及《中华人民共和国政府信息公开工作年度报告格式》（国办公开办函〔2021〕30号）等有关规定，制定莆田市科学技术局2022年度政府信息公开工作年度报告。报告全文包括总体情况、主动公开政府信息情况、收到和处理政府信息公开申请情况、政府信息公开行政复议行政诉讼情况、存在的主要问题及改进情况、其他需要报告的事项等六个方面。本报告中所列数据的统计期限自2022年1月1日起至12月31日止，电子版可在莆田市人民政府网站政务公开专栏下载。如对报告有任何疑问，请与莆田市科学技术局办公室联系（地址：莆田市城厢区龙桥街道荔城中大道国资大厦2501#；邮编：351100；电话0594-2692593；电子邮箱: pt2692593@126.com）。

　　一、总体情况

2022年度，我局坚持以习近平新时代中国特色社会主义思想为指导，认真贯彻落实《条例》和市委、市政府统一部署，全面、深入、细致地做好政府信息公开工作，做好基础信息公开，加强政策解读，规范依申请公开答复，进一步推进政府信息公开透明，为政府和群众搭建了良好沟通平台。

（一）主动公开方面。2022年度我局主动公开政府信息32件，向市图书馆、市档案馆报送政府公开信息各32份。本年度重点公开了以下政府信息：机构设置、主要职能、人事任免4条；行政法规、规章和规范性文件类1条；科技发展规划、专项规划、年度计划、总结类0条；科技专项资金的管理和使用情况类3条；行政权力运行类2条；工作情况类8条；科技公益事业类8条；提案议案类办理3条；双随机抽查类2条；政府应主动公开的其他信息1条。

（二）依申请公开方面。设立了依申请公开栏目，上传了政府信息公开申请表，明确了受理机构、程序、办理时限。2022年度收到政府信息公开申请数量2件，皆在规定时限按照规定格式予以答复。

（三）政府信息管理方面。根据人事调整及时调整政府信息公开领导小组，及时召开会议专题研究部署政府信息公开工作。加强政府信息公开平台管理，健全信息发布制度年,信息公开前，严格按照“三审制”要求，层层把关，在法定期限内及时发布并实时更新法定主动公开内容。

（四）平台建设方面。2022年共刊发《科技创新》月刊12期，字数超过7.5万字。刊物坚持“立足新发展形势、贯彻新发展理念、融入新发展格局”的导向，重点围绕开展院地合作常态化对接、实施高新技术企业倍增计划、深入推行科技特派员制度等科技工作重点，全面系统地宣传我市最新科技政策、科技成果和科技进步等情况。依托莆田市乡村振兴综合服务平台（壶兰乡村），推广使用“莆田市科技特派员服务平台”，引导企业发布技术需求，并及时发布成果、人才、市场等方面信息，提供“菜单式”服务供给模式，实现了科技特派员在线管理、科技信息线上发布、农业技术线上指导等功能，进一步拓展政府信息公开工作的宣传渠道。

（五）监督保障方面。积极接受人大监督、行政监督、民主监督和舆论监督。成立了以局党组书记担任组长，分管办公室的副局长任副组长，各科室负责人为小组成员的信息公开领导小组，进一步强化政府信息公开工作领导。将政务公开工作纳入年度综合绩效考评，并细化任务目标，明确责任分工，把考核结果作为干部奖惩的重要依据，确保各项工作顺利开展。

五、存在的主要问题及改进情况

2022年我局政府信息公开工作存在公开渠道比较单一、移动新媒体应用较少等问题，在今后的工作中，我们将重点做好以下工作：一是加强新媒体运用。充分利用微信等大众，加大惠企政策宣传和工作情况公开力度。二是做好政府信息公开培训。结合工作实际，通过组织政府信息公开培训，进一步强化全局干部职工信息公开的意识和信息公开的质量，提升政府信息公开整体工作水平。

六、其他需要报告的事项

2022年未收取信息处理费。2022年我局政务公开工作要点总体落实情况：

（一）以公开助力保持社会和谐稳定方面。在局政府信息公开栏目下“科技信息公开”专题里发布疫情防控进展信息,及时回应社会关切；及时发布《莆田市级科技计划项目经费管理办法》等政策，并做好政策同步解读工作，及时转发《福建省科学与技术厅关于印发<福建省科技计划项目科研诚信管理办法（暂行）>的通知》，让政策为更多企事业知悉。

（二）提高政策公开质量方面。运用图文等形式对政策的背景依据、目标任务、主要内容、涉及范围等要素进行解读，并在政策解读材料中提供政策咨询方式；用好“12345热线”等平台，积极解答企业和群众的咨询，2022年我局共办理37件诉求件，答复率100%；积极配合做好“在线访谈”相关工作，2022年我局分管领导参加市政府网站在线访谈1次。

（三）夯实公开工作基础方面。成立政府信息公开保密审查领导小组，健全政府信息公开保密审查制度，遵循“先审查、后公开”和“一事一审”原则，依法依规对拟公开的政府信息做好保密审查；网站信息公开栏目依托市政府网站，全面支持互联网协议第6版；在政府信息公开指南中提供线上线下公开渠道、机构职能、各科室联系电话、地理位置等，为群众政府信息公开申请接收、政策咨询等服务提供窗口。 

（四）强化工作指导监督方面。完善政府信息公开考核评议、责任追究等制度，强化指导监督，坚持目标导向，以责任落实确保工作落实；逐条对照市级政府信息公开排查问题明细认真进行问题排查并落实整改，进一步提升政府信息公开质量，更好地回应社会关切。
