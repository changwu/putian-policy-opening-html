关于组织开展2011年度高新技术企业认定申报工作的通知

发布时间：2011-03-10 00:00
| | |
政策解读:

各县区科技局、高新区管委会：

根据省科技厅等四部门联合发布《关于组织开展2011年度高新技术企业认定工作的通知》（闽科高〔2011〕7号）要求，我省2011年度高新技术企业认定工作已全面开展。为做好我市高新技术企业认定推荐申报工作，现就有关具体事项通知如下：

一、加强组织申报工作

请各县区科技局、高新区管委会根据《福建省高新技术企业认定实施细则（试行）》（以下简称《实施细则》）中的申报要求，认真组织做好高新技术企业认定申报推荐工作。高新技术企业认定管理工作政策性强，各县区科技局、高新区管委会应配备骨干人员，做好宣传、发动、培训和服务工作，及时反映申报中存在的问题。

二、具体申报要求

（一）根据《高新技术企业认定管理办法》第一条、《国家税务总局关于企业所得税核定征收若干问题的通知》（国税函〔2009〕377号）和《关于高新技术企业认定有关事项的补充通知》（闽科高[2010]43号）等有关文件精神，2011年度所得税征收方式实行核定征收的企业，不能申报。

（二）企业根据《实施细则》第六条进行自我评价，认为符合认定条件的，按相关程序进行申报。

（三）企业按《实施细则》第八条要求准备申报材料后，先将申报纸质材料初稿（非正式打印）一式一份送往所属县区科技局、高新区管委会，各县区科技局、高新区管委会按有关文件要求对申报材料的完整性进行核对后，于2010年4月、6月、9月20日前将纸质材料和汇总清单（见附件3）送往市政府7号楼市行政服务中心三楼“科技”窗口。在市科技局高新科对申报材料核对后，企业可在管理工作网认定管理系统提交认定申请书，并将获得受理号的认定申请材料和相关附件一式七份送往市科技局高新科，再由我局汇总上报。申报材料装订要求见附件1。

申报企业另需上报《申报高新技术企业涉税相关情况表》（格式见附件2），及2010年度《企业所得税年度纳税申报表》（主表）和2011年最近一个季度《企业所得税季度预缴申报表》（主表）复印件。请各申报企业填写《企业研发项目经费和高新技术产品（服务）收入表》（见附件4），并将电子版发送至市科技局高新科邮箱：ptgxk@163.com。

（四）具有总、分支机构管理模式的企业，应如实将下属各分支机构销售收入、高新技术产品（服务）收入、科技人员、研发人员、员工人数等与高新技术企业认定有关的数据完整合并计入总机构。同时申报材料中，应对各个分支机构的基本情况、生产经营数据合并计算等情况作专项说明。

（五）企业取得高新技术企业资格后，生产经营情况发生变化的（包括新设、撤销或增设分支机构以及原有分支机构生产经营情况发生变化等等），应在十五日内向认定管理机构报告；变化后不符合《认定办法》规定条件的，应自当年起终止其高新技术企业资格。

三、有关注意事项

（一）关于核心自主知识产权

根据科技部、财政部和国家税务总局《关于认真做好2008年高新技术企业认定管理工作的通知》（国科发火〔2008〕705号）的要求，在计算企业拥有的核心自主知识产权时，企业近3年内（至申报日前）获得的核心自主知识产权均视为有效。对通过独占许可方式拥有的专利，独占许可协议需到省知识产权局备案。

（二）关于专项审计

1、测度企业研究开发费用强度是高新技术企业认定中的重要环节之一。企业应按规定如实填报研究开发活动（项目）情况表，同时应对包括直接研究开发活动和可以计入的间接研究开发活动所发生的费用进行如实、正确归集，并选择已在省科技厅网站www.fjkjt.gov.cn、省财政厅网站www.fjcz.gov.cn上公布的符合条件的中介机构进行高新技术企业认定专项审计。研发费用审计年度为2008－2010年，高新技术产品（服务）收入审计年度为2010年。

2、中介机构应依据《认定办法》和《工作指引》客观公正地对企业的研发费用和高新技术产品收入进行专项审计，出具审计报告。2011年符合条件的中介机构名单将于3月15日前公布。

（三）其它事项

1、有关高新技术企业认定管理的《认定办法》、《重点领域》、《工作指引》、《高新技术企业认定申请书》、专项审计指引、符合条件的中介机构名单等有关文件，均可以在省科技厅网站 “办事指南”中“高新技术企业认定”栏目内下载。企业可登录高新技术企业认定管理工作网：www.innocom.gov.cn进行注册、申报。本通知及附件内容可到莆田市科技信息网“本站公告”栏目内下载。

2、为做好高新技术企业的认定申报工作，省科技厅委托省高新技术企业创业服务中心在3月7日、5月9日、8月8日的下午3:00召开高新技术企业认定申报辅导班（免费），会期半天。地点：福建省高新技术创业园一楼报告厅（福州市工业路611号）。拟申请认定的企业，可组织企业技术部和财务部有关人员前往福州参加培训。如欲参加培训，请企业预先与市科技局工业科联系报名。企业在申报过程如有疑问，可向市科技局高新科咨询。
