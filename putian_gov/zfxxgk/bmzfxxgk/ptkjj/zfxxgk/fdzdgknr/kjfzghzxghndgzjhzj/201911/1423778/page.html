莆田市科学技术局关于组织申报2020年度鞋产业转型升级科技计划项目申报指南的通知

发布时间：2019-11-07 15:47
| | |
政策解读:

 

各有关单位：

   为支持我市鞋产业转型升级，引导全市开展鞋企科研攻关、开发和成果转化应用，推进我市高质量发展和美丽莆田建设，根据《莆田市人民政府关于印发稳鞋企促升级新十条措施的通知》（莆政综〔2019〕55号）要求，现将“莆田市2020年度鞋产业转型升级科技计划项目申报指南”有关事项通知如下，欢迎申报。                 

    一、申报范围和内容

   本次受理项目共两类：平台建设（产业技术研究院）、区域重点项目（专项），项目申报指南及申报代码详见附件。

    二、申报计划及立项

    1、本批鞋产业转型升级科技计划项目拟立项5个，其中鞋产业技术研究院1个，区域重点项目（专项）4个，每个项目资助经费不超过100万元。立项当年度补助资金不低于计划资助经费50%，验收通过后再拨付剩余资金。

2、项目研发起始时间为2019年10月1日，申报项目研发结束时间原则上不超过2022年9月30日。

    三、申报要求

1、项目申报单位必须是列入莆田市工业和信息化局《关于公布生产型鞋业“白名单”企业（第一批）的通知》（莆市工信运行〔2019〕240号）和莆田市商务局《关于公布商贸类鞋业“白名单”企业（第一批）的通知》（莆市商务〔2019〕207号）内的企业，且具备研发能力和条件的企、事业单位，鞋产业技术研究院可以是国有企事业单位。

2、已承担国家、省、市科技计划项目的第一承担单位，有1项以上（含1项）项目到期未验收（评审）的或近三年有项目被强制中止的，不能申报本批项目；以企业为第一承担单位的，在研市级科技计划项目累计不超过2个。

3、鞋产业技术研究院、区域重点两类项目，每个单位只能申报其中一类项目。申报单位近三年有不良记录，不能申报本批项目。

    4、政府公务人员不能作为项目负责人，项目负责人在项目结束时年龄原则上不超过60周岁。

5、项目负责人、技术负责人有到期未结题的各级科技计划项目或近三年有项目被强制中止的，不能申报本批项目。项目申报单位和项目负责人不得是失信被执行人。项目申报单位及项目负责人应遵循科研诚信原则，对所提供申报材料的真实性负责，并对虚假导致的后果承担责任。

6、要明确项目研究方式，有合作研发的项目应在附件中附上合作协议，协议内容应包括项目研究开发内容、分工及其知识产权权属等。

    7、申报的项目必须是具备前期科研基础且未立项过的项目。

    8、研发资金预算编制必须真实可信，自筹资金要有实际投入，资助经费未达到申请额度，差额部分由项目申报单位自筹解决。

9、项目申报内容应符合指南中规定的内容和领域范围，目标任务明确具体，并体现创新性。属于改进或改良的技术指标应量化可考核，在项目完成或评估时应该形成具有自主知识产权的技术成果，能够形成高价值专利。

10、因未按本通知要求申报，形式审查通不过的项目，不再受理补充材料。

11、申报产业技术研究院、区域重点项目（专项）须编制项目可行性研究报告（格式下载网址：http://xmgl.kjt.fujian.gov.cn/putian.do）。对2018年度研发投入，先提交书面承诺函（高新技术企业只需提供有效的高新技术企业证书），待项目评审后、立项审定前，补报专项审计报告（高新技术企业除外），逾期无法提供或达不到要求的不予立项。

12、申报时应同时提供申请书及附件（合作协议书、委托书、企业纳税证明等）。

     四、申报时间

本批项目网上申报时间为 2019年11月1日至2019年12月25日，推荐时间为2019年12月26日至2020年1月10日，申报单位未按期提交申请书的视为放弃申请，申报截止时间后将不能提交；在推荐起止时间内，县（区）科技管理部门将申报材料审核退回修改的，申报单位还可重新提交申报材料。通过审查的项目，由项目申报单位通过项目管理系统打印《莆田市科技计划项目申请书》及相关附件纸质材料一式二份，签字盖章后报送推荐部门汇总，由推荐部门在2020年1月 17日前将申报材料一式二份和推荐函并附申报项目汇总表（格式下载网址：http://xmgl.kjt.fujian.gov.cn/putian.do）寄送市科技局高新科，逾期不予受理。

网上申报流程为：申报用户登录莆田市科技计划项目信息管理系统(http://xmgl.kjt.fujian.gov.cn/putian.do──项目申报──起草项目申请书──选择项目类型──填报申请书──上传相关附件。申报单位未按期提交申请书的视为放弃申请，申报截止时间后将不能提交；在推荐截止时间前，推荐单位将申报材料审核退回修改的，申报单位还可重新提交申报材料。

     五、注意事项

1、县（区、管委会）科技管理部门、市直有关部门作为项目推荐部门应广泛宣传，公开征集，逐级遴选、择优推荐，不得内部指定、简单分配。

2、项目申报时间较长，各申报单位要认真选题，充分论证，特别是企业要结合生产经营实际确定研发内容，对自身技术力量不足的要与科研机构或院校开展合作，共同攻关。

3、各申报单位在具体申报中遇到问题请及时与市科技管理部门联系，咨询电话为：

    高新技术与工业科技科：2655395

资源配置与监督科：2655519

网上申报技术支持：2671285
