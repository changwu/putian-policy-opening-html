关于市政协八届一次会议第2022008号提案办理情况的答复

发布时间：2022-04-07 16:09
| | |
政策解读:
           

九三学社莆田市委员会：

贵委在莆田市政协八届一次会议上提出的《关于科技创新推动装备产业高质量发展的建议》及领导批示（NO：2022005）收悉。提案从“建设专业工业园促进产业聚集发展、产学研协同创新促进产业科技创新、推动工业互联网发展”等三个方面对我市装备产业高质量发展提出了中肯的建议，具有可操作性，对我市今后的装备产业发展具有很好的借鉴作用。现就贵委提出的建议答复如下：

一、围绕高质量发展开展的工作

（一）产业结构持续优化。我市装备产业结构逐步从层次较低、规模较小、布局分散向集群化、链条化、高端化发展。如在汽车零部件及配件制造产业方面，规模以上企业共15家，主要产品有汽车电机、灯具、轮胎、活塞环、汽车发动机供油器总成以及汽车用螺栓、轴承、齿轮等，产品门类较多，特别以电机和活塞环颇具特色。代表企业有东亚机械、仙游电机和宏业等企业。摩托车零部件及配件制造业以荣兴机械、东亚机械等企业为龙头，形成了产业集群，主营产品包括制动器总成、刹车盘（鼓/蹄/片）、变速器、变速器齿轮及轴等传动系统部件、发动机活塞环、发动机机体。在机床行业方面，我市具有一定的机床及配套制造产业基础，目前以威诺、森达、金浦、庆川、黑石等为代表，主要产品包括摇臂铣床、数控铣床、车铣复合加工中心、立式加工中心、电加工机床、数控木工刨床、铣床零部件和标准模架等产品。重点企业威诺的数控产品涵盖七轴龙门复合式加工中心专特产品、立式加工中心、五轴联动加工中心、斜床身车削加工中心等4大系列产品，产品技术国内领先。

目前全市共有87家规模以上装备工业企业，2021年完成产值382.2亿元，增幅42.2%（增速在全市八个产业中居首位）,占全市比重8.9%，拉动全市规模工业增加3个百分点,对全市规模工业贡献率22.9%。

（二）创新能力逐步增强。近年来，我市通过大力支持企业开展新技术、新工艺、新产品研究，推动科技资源要素进一步向优质企业集聚，不断提升研发创新能力，为产业集聚提供有力支撑，装备产品档次得到不断提升。云度新能源汽车已开发π1、π3两款车型，建成年产6.5万台新能源汽车生产线，形成了研发、生产、销售等一整套完整体系，截止2021年底，在全国累计销售新能源乘用车12653辆，目前在市里配套有佳通轮胎和永辉塑胶等本地上下游企业项目。海山机械有限公司主要生产高端环卫装备、应急抢险装备、大型铁路养护成套装备等高科技、高附加值产品，产品均为国内首创，技术达到国际领先水平，有着广阔的应用前景。目前装备产业规上企业24家R&D经费投入15.3456亿元，占研发投入的38%；认定高新技术企业26家，占总数的21.5%。

（三）工业园区不断壮大。我市自上世纪90年代启动工业园区建设，按照“工业园区化、园区产业化”的发展思路，不断优化园区产业方向，推动园区差异化错位发展，把园区打造成全市工业发展的先行区、示范区，逐步形成了以国家高新区为引领，各工业园区为支撑的园区发展格局。

2021年全市工业园区规模工业企业633家；全市工业园区完成规模工业产值2933亿元，比增14.2%。经过多年发展，园区已集聚形成了化工新材料、工艺美术、电子信息、装备、制鞋、木材加工等特色产业，成为全市工业经济发展的重要载体。高新区规划面积11.05平方公里，现有可利用面积9132亩，重点布局发展电子信息、高端装备制造、食品加工三大主导产业，主要龙头企业有华佳彩、云度新能源、百威雪津等，先后打造“国家火炬计划莆田液晶显示产业基地”、“莆田国家液晶显示高新技术产业化基地”、“莆田通用设备制造产业人才聚集基地”等；仙港工业园创建于2015年，规划面积4995.24公顷，现有可利用面积6111亩，主要布局发展鞋服纺织、汽车零配件、电子信息；秀屿临港工业园区创建于2009年，规划面积1450公顷。主要布局发展能源、石化钢铁等产业，主要龙头企业有上海电气风电设备、鞍钢、中海福建燃气发电等。

二、装备产业存在的问题

（一）经济总量小，产业水平不高，缺乏高附加值产品。从规模工业产值（现价）来看，我市装备制造业产值仅占全市规模以上总产值的8.9%，行业规模较小。产品多为中间配套型产品，多数企业主要以订单加工为主，以低附加值的金属制品、机械零配件、中低档数控机械设备为主，利润率偏低，缺乏高端精密机床、精密零部件、重型设备等高附加值产品。

（二）大型骨干企业少，难以形成以大企业为龙头的产业集群。大企业少，小企业也不多，而且布局分散，没有产生产业集聚效应，影响了莆田装备制造产业的整体市场竞争力。特别是从事整机生产的大企业少，例如，莆田的汽车摩托车制造行业的主要产品是汽车的电机和活塞环、摩托车制动蹄块等零配件，而不是整机。

（三）缺乏配套环境，产业配套能力较弱。未形成较完整的产业体系，缺少本地整机企业所需的铸锻件、零部件的生产供应配套能力，无法形成产业链与上下游协作关系。例如，铸造件是生产各种机械产品的重要配套产品，但目前莆田的很多铸造件都从外地采购，提高了当地机械制造企业的生产成本。配套能力不强使莆田市难以招来机械工业的大项目、好项目、高科技项目，也难以扶持本地龙头企业做大做强并进一步形成产业集群。

（四）专业技术与管理人才缺口较大。装备制造业的发展本质上正在由投资驱动逐步向技术创新驱动转变，而支持技术驱动的是相应的高素质人才。目前我市高素质、高水平的各类专门人才相对匮乏，一些技术水平要求较高的企业普遍反映近几年人才难招，人才很难留住，制约了我市装备制造产业的发展。

三、下一步推动装备产业高质量发展思路

装备制造业是未来制造业发展竞争的核心领域，是莆田市工业发展的重要支撑，也是产业转型升级的关键领域。虽然全市装备制造业取得一定的发展，但还存在细分领域规模较小、产业结构不尽合理、产业配套基础不强等问题，必须加大招商力度、培育关键企业、强化要素保障，全力推进装备制造业加快发展。

（一）发展目标

重点发展智能装备制造业，延伸汽车零部件等产业链，加快发展海洋工程装备、专用机械设备，打造高端装备制造基地。围绕新能源汽车、海上风电设备和数控机床等项目，引入战略投资合作，延伸拉长产业链，建设新能源汽车生产基地、海上风电产业基地。力争到2025年，产值超500亿元。

（二）发展路径

1.汽车行业。以新能源汽车项目为龙头，引进、带动电池、电机、电控“三电系统”、车身零部件和充电桩生产项目，加快研发轻量化材料应用，开发增程式驱动系统，与动力电池企业共同提升产品有效续航里程、电池循环使用寿命。规划建设新能源汽车配套产业园，以云度新能源汽车为龙头，引进战略投资，加大本地产业配套。联合高校科研院所，加大研发和检测能力投入。以荣兴机械、东亚机械、宏业精密机械为龙头，进一步拓展汽车配件产业链，构建整车企业和零部件供应商在线合作生产新机制，提高产业协作能力。

2.专用机械设备。以海山机械专用车为龙头，延伸发展道路污染清除、河道清淤、真空垃圾收集等专用环保设备，以及铁路、桥隧养护、电网架设等专用设备，加大在市政施工、道路维护、环境保护、灾害应急救援等领域的应用。围绕服务纺织、鞋业、家具加工等传统行业，培育发展纺织、制鞋、木工机械等专用设备。

3.机床及智能装备。以威诺数控、森达数控等为重点，提升高端数控机床制造水平，同时发展锻造、模具加工、焊接加工等协作配套产业，构建完善的协作配套体系。以此拉长产业链条，形成良好的配套环境，带动机床产业集聚发展。引进精密智能仪器仪表与试验设备、关键基础零部件、元器件及通用部件等，加快培育本市智能装备制造体系。

4.海洋工程装备。发挥港口、风电资源优势，主动承接上海等先进地区装备制造产业转移，培育发展海上风电、港口装备、深海养殖装备等海洋工程装备。

5.金属制品行业。以鞍钢冷轧、恒而达新材料、鼎盛等为龙头，加速研发精细金属制造技术、金属基复合新材料等，加快转型升级，拓展产品种类，提升产品质量，增强金属制品行业整体竞争力。

（三）工作重点

1.着力开展产业链招商。围绕新能源汽车整车生产、海山机械专用车、高端数控机床、恒而达复合新材料等重点项目，充分运用牌照资源、市场规模、核心技术、行业影响力等优势，分行业分区域实施产业链精准招商，持续对接引进战略投资合作和上下游企业落地配套。各工业园区要编制装备制造产业的招商手册，收集招商信息，主动走出去、迎进来，提高招商实效。仙游县依托仙港工业园，围绕现有的电机、汽车零部件等重点发展智能装备，开展以商招商，以企招商；涵江区依托兴化湾南岸装备制造产业园，围绕云度、威诺开展新能源汽车、数控设备等招商，引进战略合作者与云度、威诺合作；荔城区依托荔城经济开发区，围绕海山机械，引进抽吸车结构件、箱体、液压油缸、油泵、覆盖件等项目，同时考虑引入资本与海山机械合作，扩大环卫机械生产规模，吸引上游配套项目来莆投资；秀屿区依托莆头工业区，围绕海上风电、海洋工程装备、港口机械等项目对接上海电气集团等旗下项目来莆投资。

2.着力服务重点企业重点项目。深入一线主动服务、靠前服务、精准服务，通过媒体宣传、行业协会推荐等措施，帮助云度新能源、威诺数控、海山机械、恒而达等优势企业拓展市场，提升市场竞争力，促进生产要素向优势企业集中，实现快速发展。重点推进华峰纺织装备、恒而达高强韧性多金属复合新材料等项目建设。

3.着力做强做优重点龙头企业。聚焦新能源汽车、数控机床、环卫应急车辆等重点、优势行业，加快培育后备龙头企业，策划引进新的龙头企业，支持龙头企业实施兼并重组、引进战略投资、市场拓展、研发创新等。各工业园区确定若干个本园区装备龙头企业，围绕服务龙头、做强龙头的目标，对每一个行业龙头企业，确定“一个服务班子、一本推进手册、一套扶持办法”。对企业进行全方位会诊，找准制约企业发展的难点和瓶颈问题，集市、县（区）力量对症下药、精准发力、破解瓶颈。

4.着力推动企业创新发展。推动重大技术装备研制应用，提升产品附加值。实施“一业一策”、建立“一产业一研究院”等措施，帮助装备龙头企业承担国家、省重大科技计划项目。鼓励企业开展产学研合作，承担“卡脖子”装备、短板装备、前沿装备，加强关键核心技术研发攻关，研制首台（套）重大技术装备和智能制造装备，提升产品附加值，进一步增强企业核心竞争力。加大对创新性、重要性突出的首台套示范应用项目支持力度，加快创新型技术装备的推广应用。研究制定市级首台（套）重大技术装备发展的支持措施。

5.着力贯通上下游产业链。强化产业协作，促进优质生产要素集中集聚。推进本地企业配套，在电机、电子设备、机械件、结构件等领域，开展市内上下游产业链企业“手拉手”合作，建立装备产业创新联盟和统一采购入库，推动龙头企业与中小企业开展产能对接、供需对接等产业协作，促进上下游贯通，密切上下游产业关系。

非常感谢您对我市科技工作发展的关心和支持，提出很好的建议，对我们提高科技管理水平起到了积极的促进作用，恳请您今后继续关注我市科技工作，多提宝贵意见。
