关于市政协八届二次会议第2023002号提案办理情况的答复

发布时间：2023-07-26 15:58
| | |
政策解读:
 农工党莆田市委员会：

贵委提出的《关于推动我市农村发展绿色经济 助力乡村振兴的建议》（2023002号）已收悉，现将办理情况函复如下：

近年来，我市坚持走绿色科技兴农之路，坚持发展绿色科技产业、生态科技农业，努力实现经济效益、社会效益、生态效益的有机和谐统一，农业科技创新步入可持续发展的良性循环轨道。

一、科技项目支持

坚持通过科技项目推动，着力突破一批产业关键共性技术，引领农村经济走绿色发展之路。三年来，我市共实施省级和市级农业科技项目54项，资金资助金额1434万元。通过实施科技项目，充分调动各类经济实体开展科技研发的积极性，促进了农村绿色经济转型升级。例如：2022年实施省级星火科技项目“设施温室生态循环种养关键技术耦合与示范”，探索鱼菜共生系统中养殖废水调制液在无土栽培上的应用，研究出具有高经济效益的鱼菜共生系统的可持续发展模式，实现了养殖废水和养分再利用的科学方案，为我市绿色循环经济提供先进技术示范。

二、科技特派员服务

鼓励科技特派员围绕产业需求开展服务，助力乡村振兴、产业振兴。三年来，我市共选认省、市和区级科技特派员1500多名，其中服务第一产业科技特派员700多名，对接服务企业、合作社430家，开展各种形式的实用性培训250余场，培训群众近9000人次，引进新品种57个，推广新技术115项，充分发挥出科技特派员对农村科技创新的人才和智力支持作用。例如：2023年省级科技特派员团队开展“度尾文旦柚绿色生态综合栽培技术”服务，通过实施有机肥替代措施，开展病虫害生物和物理综合防治等文旦柚绿色、生态、高效栽培技术研究，为我市果业绿色发展提供了有益的创新示范，辐射带动区域内文旦柚产业绿色健康发展。

三、校地产学研合作

积极引导我市企业与福建农林大学、集美大学等高等院校联合开展产业关键技术、共性技术的研究和攻关。例如：我市企业与福建省农林大学联合开展“再生稻高产优质高效安全生产的技术体系研究与应用”技术研究，开展全程机械化再生稻高产群体建成及其与养分管理、水分管理等关键栽培技术关系研究，建立绿色生态示范基地500亩，解决了种植双季稻劳动力短缺和人力成本大幅度攀升的问题，取得了较好的社会效益和经济效益及环保生态效益；今年7月份，我局还与莆田学院环境与生物工程学院联合成立莆田市循环经济产业技术研究院，携手推动循环经济和绿色经济的转型升级，将为区域经济社会发展做出更大的贡献。

今后我们将认真按照提案提出的意见建议，加快推进农业绿色创新可持续发展，强化政策引领，保护生态环境、提升生态服务功能，转变农业发展方式，推动农业科技高质量发展，以农业绿色发展引领乡村振兴，构建人与自然和谐共生的农业创新发展格局。

一是项目推动农村绿色产业转型升级。大力实施农业创新科技项目，聚焦我市特色产业发展的科技需求，着力解决制约乡村振兴的关键技术研发、集成和成果转化，组织企事业单位积极申报和实施各级各类科技项目，开展成果转化和示范推广。

二是人才服务农村绿色经济发展。打好“科技特派员人才服务牌”，解决主导产业和特色产业科技发展希求，积极探索开展订单式服务、小分队精准服务、在线咨询服务等多元化基层服务模式。

三是产学研促进绿色经济融合发展。促进高校院所科技成果在莆转化落地，努力形成科技成果即创即推、即推即转的成果快速转化途径，提升产业核心竞争力。择优筛选出一批莆田农业特色产业急需的、生产上容易操作的农业科技成果。

以上是我局对贵委提案的答复意见。再次感谢贵党派对我们工作的关心和支持！希望今后继续关心关注我市科技事业发展情况，为我市创新驱动展积极建言献策！
