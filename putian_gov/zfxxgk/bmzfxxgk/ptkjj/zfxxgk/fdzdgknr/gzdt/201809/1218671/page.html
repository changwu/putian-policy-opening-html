关于市政协七届二次会议第2018034号提案办理情况的答复

发布时间：2018-09-19 09:30
| | |
政策解读:

                                  签发：梁国镇

                                  办理结果：A类

 

 

九三学社莆田市委员会：

你提出的“关于转变扶持莆田市企业科技创新能力方式的建议”的提案（第2018034号）收悉，现将办理情况函复如下：

 一、重点实施科技项目，已经发布的2018年市科技计划项目申报指南。

认真贯彻落实国家、省和我市鼓励促进科技创新创业政策，充分调动全社会科技创新创业的积极性和创造性，确保财政性科技投入稳定增长。要逐年提高科技支出占财政支出的比重，确保本级财政科技经费支出增长幅度高于本级财政收入增长幅度。创新财政科技资金投入方式。加强统筹协调，突出助优扶强，突出产学研合作，把财政科技资金向我市建有科研机构的重点优势骨干行业和企业倾斜，向创新型产业集群倾斜，进一步强化企业的技术创新主体地位，逐步建立主要由市场决定技术创新项目和经费分配、成果评价机制。2018年2月8日我局已经发布《莆田市科学技术局2018年度市科技计划项目和奖励性项目申报指南的通知》（莆市科〔2018〕15号），对符合条件的企业（单位）或项目等经论证调研后，经与市财政局会商后联合下达资助或奖励经费支持。

二、做好高新技术企业税收优惠政策和企业研发费加计扣除政策的落实工作，鼓励企业增加研发投入。

落实各类专项补助资金。对高层次人才引进、国家高新技术企业、工程技术研究中心等，集中政府有限的政策资源支持科技创新，及时按规定落实补助或奖励资金，逐步将奖励资助重点转移到科技创新和对地方经济社会的贡献质量上来。2018年3月20日莆田市科技局组织举办了2018年我市高新技术企业认定和研发费用税前加计扣除培训辅导班。这是省、市科技、税务部门联合开展的一次科技税收优惠政策宣讲活动，为推动我市今年的高企申报和研发费用税前加计扣除备案奠定了良好的基础。市科技局高新科、社发科、情报所负责人及工作人员和各县（区）科技局相关业务人员，我市相关企业科技、财务相关人员近130人参加此次培训。通过培训，一是促进我市企业对高企认定和企业研发费用税前加计扣除政策和研发费用归集和核算知识有了比较深入系统的认识和了解；二是提升了我市企业申报高企和研发费用税前加计扣除备案的信心和水平；三是有助于更多的企业充分享受企业研发费用税前加计扣除等创新激励税收优惠政策红利，进一步推动我市经济社会创新发展。

三、贯彻落实福建省企业研发费用投入分段补助实施办法的细化支持措施。

根据《福建省人民政府关于印发<福建省企业研发费用投入分段补助实施办法（试行）>的通知》（闽政〔2017〕8号）文件要求，企业年度研发费用投入补助，根据企业研发投入情况，对符合补助条件的采取后补助方式。一是基础补助：年度研发经费支出额不足1000万元的，按研发经费支出额的5%计算补助经费。年度研发经费支出额高于1000万元（含）、不足2000万元的，对其中1000万元给予50万元补助，超出1000万元的部分，按超出部分的4%计算补助经费。年度研发经费支出额高于2000万元（含）以上的，对其中2000万元给予90万元补助，超出2000万元的部分，按超出部分的2%计算补助经费；二是增长额补助：按照企业年度研发经费支出较上一年度增加额的6%计算；三是科技小巨人领军企业：在享受企业研发费用税前加计扣除政策的同时，财政对企业享受加计扣除政策实际减免的所得税额，给予同量资金奖励。奖励资金以该企业相应年度应缴纳企业所得税额的地方财政分成部分为上限。补助经费在提交补助申请的当年内一次性安排。企业在申报补助时不得重复申请。

四、优化环境为保障，倾心尽力，以环境优势筑人才优势。

扎实做好服务人才这篇“文章”。一是强化挂钩联系。落实市领导联系专家和优秀人才制度，19位市厅级领导干部挂钩联系94名院士专家和优秀人才，主动听取意见建议，帮助解决实际问题，不断提高人才荣誉感、认同感。出台《莆田市政府顾问团管理服务暂行办法》，从院士、高校教授、知名学者等对象中聘请29位专家组建市政府顾问团，下设宏观经济顾问组、产业发展顾问组、规划建设顾问组、社会法律顾问组，着力加强对全市经济社会发展各领域全局性、长期性、综合性问题的战略研究、对策研讨、咨询建议。实施“智汇莆田”专项行动，发挥148个莆田驻外党组织和60多个在外莆田商会作用，在设立驻京、驻沪、驻粤人才工作站和驻澳大利亚人才工作联络站的基础上，市外新设立驻香港人才联络站，市内新建立10个市级人才工作联系点，进一步延伸引才触角。建立完善莆籍在外人才信息库，收集在外人才信息3806人，启动建设莆籍名校优生“百骏”信息库，征集2011年至2017年“百骏人才”信息700多人，为开发莆籍在外人才提供数据支撑。二是强化团结凝聚。全省首家成立市级高层次人才交流协会，设立5000万元人才基金，首批吸纳340名来自工艺美术、医疗健康、电子信息、装备制造等领域的行业精英，其中博士学位的占20.59%、正高职称占21.47%。省委组织部杨国豪、各地市组织部长莅会指导。采取定期不定期举办主题沙龙、高峰论坛等活动，为人才搭建起联系互动、畅谈理想、共谋发展的交流平台。三是强化宣传引导。加大人才创业创新成果和先进事迹宣传力度，在湄洲日报、莆田网、微信微博等媒体平台刊发和转引人才报道1500多条，努力营造重才、爱才、留才的浓厚氛围。四是强化素质提升。以人才需求为导向，通过优化培训环境、举办特色培训班、开展人才交流活动等形式，为人才提高素质、增长才干提供平台。2017年，分领域开展工艺美术、农村实用、科技创新等各类培训182期，培训人数达30000余人。五是强化住房保障。实施人才安居工程，采取“实物配置+货币补助”相结合的方式，为人才营造温馨舒适的生活环境。积极筹建人才国际社区、国际学校、国际医院，集中配置优质高端的住房、教育、医疗资源。2017年在兴涵水都地块投资1.57亿元建设高端人才社区，10月份采取“限地价、竞自持”的土地出让方式，吸引企业参与人才房建设，为全省首例。

五、税法改革应由国家层面立法决定

有关科技创新税法的改革应该是上级税务部门乃至国家层面立法决定的，不是我们地方科技部门职能所能够决定的。
