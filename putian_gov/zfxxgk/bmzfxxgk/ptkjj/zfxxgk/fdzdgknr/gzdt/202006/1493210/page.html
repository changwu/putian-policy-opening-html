莆田市科学技术局关于开展2020年度福建省重点实验室（企业类）建设的通知

发布时间：2020-06-03 09:57
| | |
政策解读:

 

 

各（县）区科技管理部门、各有关单位：

   根据《福建省科学技术厅关于2020年度认定建设18家福建省重点实验室（企业类）的通知》（闽科专〔2020〕6号）的文件精神，经省厅研究评审，认定“福建高新面板重点实验室”等我市2家企业入选认定建设福建省重点实验室（具体名单详见附件1）。为确保省重点实验室的建设水平和质量，现将有关建设目标要求事项等通知如下：

   一、总体目标。请各认定建设的省重点实验室（企业类）进一步明确目标定位，凝练研究方向，加强科研队伍和科研条件建设，建设“开放、流动、联合、竞争”的运行机制，切实提升我省特色优势产业的应用基础研究和竞争前共性技术研究的影响力，提高原始创新能力，解决我省经济社会发展关键、共性及核心技术问题。

   二、申报时间及要求。各认定建设的省重点实验室（企业类）于2020年5月18日至6月8日登陆福建省科技创新平台及机构管理系统（http://xmgl.kjt.fujian.gov.cn/loginSignout.do），按有关要求填写《福建省重点实验室建设任务书》（样式见附件2）,经依托单位和业务主管部门审核后上报。纸质件待《福建省重点实验室建设任务书》商定审议后，一式5份盖章报送至市科技局成果与人才转化科（外国专家局）。

   三、建设期限及说明。省科技厅通知下发之日，各重点实验室即进入建设期（期限二年）。建设期满，省科技厅将组织专家开展考核验收工作，验收合格的予以正式授牌。

内容提纲

 

   一、实验室基本信息：实验室中英文名称，学科领域，依托单位负责人，建设地点。

   二、实验室研究方向、主要研究内容及预期研究目标：在分析本领域或本行业发展趋势和状况的基础上，结合本实验室已有工作基础，确立研究方向、主要研究内容和预期达到的研究目标。

   三、实验室主任简介，实验室人才队伍建设计划：实验室主任基本情况、主要研究领域和代表性研究成果简介，人才队伍结构的总体规划，现有队伍和人才（学术带头人）情况介绍，稳定培养、吸引人才的具体措施。

   四、学术委员会组成及工作机制：学术委员会职责，聘任主任、委员人选基本情况及支行管理机制。

   五、实验室建设与经费：实验室规模及研究单元的构成（结合研究内容和队伍设置阐述），现有科研条件（仪器设备、科研用房、配套设施）情况，仪器设备购置（研制）计划，建设经费概算与落实计划。

   六、实验室管理运行机制：实验室日常运行管理，人员聘用及流动，仪器设备管理与使用，开放合作设想。

   七、依托单位的支持（包括建设费和运行费计划）

   八、主管部门审查意见

   九、附件：

   1. 实验室固定人员名单（列出姓名、性别、出生年月、职称、研究方向或专业等主要信息）

   2. 实验室承担的重要科研项目清单

   3. 实验室现有主要仪器设备清单

   4. 实验室重要成果清单（含制定标准、专利、获奖、新产品、论文等）
