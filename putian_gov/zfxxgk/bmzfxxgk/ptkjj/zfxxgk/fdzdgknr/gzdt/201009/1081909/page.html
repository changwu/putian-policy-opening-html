市科技局关于加强值班工作的通知

发布时间：2010-09-17 00:00
| | |
政策解读:

各科室：

为贯彻落实市委“大干150天，打好六大战役”部署和市委杨书记在“六大战役”工作汇报会上的讲话精神，进一步改变工作作风，提升服务水平，形成我市跨越发展的良好氛围，根据莆政办明电[2010]34号文件要求，从本月起，局机关实行值班和领导带班制度，真正做到在岗在位、“白加黑”、“五加二”。市效能办将对值班带班情况进行效能督查。

我局值班带班工作具体要求为：一是落实24小时值班和领导带班制度，特别是节假日期间的值班工作（具体值班表见附件）；二是落实办公室文电、机要人员24小时值班制度，确保节假日期间文电、机要人员到位，渠道畅通；三是加强应急事件处理能力，及时应对各类突发事件，值班人员在值班期间出现问题和困难，要及时向带班领导报告。

二Ｏ一Ｏ年九月三日
