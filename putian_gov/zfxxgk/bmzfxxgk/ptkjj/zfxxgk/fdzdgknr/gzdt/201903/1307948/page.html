莆田市科学技术局关于组织参加第十七届中国国际人才交流大会的通知

发布时间：2019-03-19 10:08
| | |
政策解读:

 

 

各县（区）科技局，各有关单位：

根据《中共福建省委人才工作领导小组办公室 福建省外国（海外）专家局关于组织参加第十七届中国国际人才交流大会的通知》（闽外专〔2019〕5号）要求，组织有关企事业单位有需要国（境）外高端人才、智力和项目、技术或出国（境）培训的单位报名前往参会（具体详见附件），请做好相关报名工作，请于3月14日前将报名表格发于对外合作与成果科。

科室邮箱：fufuxin2005@163.com

省外国（海外）专家局关于组织参加第

十七届中国国际人才交流大会的通知

 

 

各设区市党委组织部、政府科技局，平潭综合实验区党群工作部、社会事业局，省直（中直）有关单位组织人事或科技、外事部门，有关企事业单位：

科技部（国家外专局）与深圳市政府定于2019年4月14日至15日在深圳召开第十七届中国国际人才交流大会。根据中国国际人才交流大会组委会《关于召开第十七届中国国际人才交流大会的通知》，为借助大会引智平台，引进我省经济社会发展急需的国（境）外高端人才、智力和项目、技术，省委人才工作领导小组办公室和省外国（海外）专家局决定组团参加第十七届中国国际人才交流大会。现将有关事项通知如下：

一、大会时间、地点  

时间：2019年4月14至15日（周日、周一）  

地点：深圳会展中心（深圳市福田中心区福华三路）。  

二、参会对象  

省直、中央在闽有关单位组织人事、科技和外事部门，各市、县（区）党委组织、政府科技部门，龙头企业、重点建设项目单位、重点产业和行业企事业单位，有关高校和科研机构、科技园区，以及其他对国（境）外人才、智力、项目、技术或出国（境）培训有需求的单位相关负责人。

三、活动安排  

各单位可根据实际需要自主选择参加第十七届中国国际人才交流大会设立的各板块主题活动，活动具体内容请登录大会官网www.ciep.gov.cn查询。根据我省实际情况，为做好国际人才交流大会参会活动，突出工作实效，我省将组建福建省代表团，统一组织相关单位参加活动。

（一）“福建馆”展览展示活动

省科技厅在大会主展区举办福建馆。福建馆展馆面积拟定108平方米，采用特装形式，以图文展板展示为主，通过电视墙播放人才宣传片，配合发放宣传手册、光碟，重点展览展示我省优秀引智成果，宣传我省招才引智政策和环境，推介我省重点企事业单位人才智力和项目技术需求，宣传福建引才引智政策，促进我省科技对外交流和人才智力的引进。

（二）中高端人才系列专场招聘会

大会将举办外籍人才招聘会、“智聘百强”名企招聘会、“智领未来”全国高校毕业生春季双选会、海归人才招聘会、“精英天下”中高级人才招聘会等中高端人才专场招聘会。

我省拟组织重点企事业单位在相关专场招聘会上设立招聘展位，推介我省人才需求，招聘我省急需人才。

（三）外国专家组织对接活动

设展方为经国家外专局备案的外国专家组织、国（境）外培训机构，同时大会还吸收一批国际知名专家组织、高层次人才机构参展参会。

我省拟组织对引进国外人才智力和派员出国（境）培训有需求的企事业单位与外国专家组织开展现场对接洽谈，促成双方项目合作，引进我省产业发展急需的国外高层次专家，为我省选派各类人才赴国（境）外培训建立优质培训渠道。

联系人：钟大华、芮麟娇

（四）科技高端服务活动

大会首次设立科技高端服务展示专区，引入含法律咨询、会计审计、知识产权、高端猎头、金融证券等领域的智力化、资本化、专业化的高端服务机构，为科技创新和国际人才交流合作提供全流程专业化服务。

我省拟组织科技类企事业单位参观科技高端服务展示专区，了解国际科技高端服务状况，与国际科技高端服务机构交流洽谈，推进我省科技产业服务水平。

联系人：张  莉、叶作林

（五）国际技术转移与创新合作活动

大会聚焦科技创新人才与创新创业项目引进，结合当前国际科技创新合作与产业发展的重点领域，设置青年创新创业论坛等专题峰会，同期展览展示与路演对接。

我省将争取组委会支持，拟在会前将邀请的高端外国专家和项目推介给我省有关单位，组织有对接意向的单位现场参加活动，与出席该活动的国内外知名专家学者对接，引进我省经济社会发展急需的先进技术和项目。

联系人：钟大华、芮麟娇

（六）人力资源服务机构活动

设展方包括国内外知名猎头公司、人力资源市场、劳务派遣和外包服务机构、人才测评机构、管理咨询公司等参展洽谈。同期举办人力资源服务业高峰论坛和系列颁奖活动。

我省拟组织闽台两地人力资源服务机构在亚太人力资源开发与服务博览会上设立展位，开展人力资源服务业合作交流活动，展示我省人力资源管理水平、人力资源服务特色产品，密切我省人力资源服务机构与国际知名人力资源机构合作，提升我省人力资源市场国际化水平。

（七）海归人才活动

大会将组织海外留学生组织、海外高端院校以及留学生个人、国内各地归国留学人员主管部门、留学生创业园及企业设展推介，宣传各类高层次人才计划、创业扶持政策，同期组织海归招聘会、海归博士项目路演、海归职业规划发展论坛等活动，为用人单位和留学回国人员打造对接合作平台。

我省将争取组委会支持，在交流大会召开前将大会邀请的海外留学人才及项目推介给我省有关企事业单位，增强对接洽谈活动的针对性。鼓励支持省内留学人员创业园和重点高校、科研机构设立展位，吸引留学人员落地我省创新创业。

联系人：王晓东

（八）教育科技活动和中国软件产业校企合作大会

大会将组织国内名校、科技类“独角兽”企业及上市公司、百强IT企业参会参展，共同搭建一个国际性的软件人才、项目、投资的交流平台。

我省拟组织省内高校以及软件产业单位和参会的高校和知名企业洽谈开展项目研发、人才联合培养、人才招聘等活动，借助该平台推动我省数字产业深化发展。

（九）其他活动

科技部（国家外专局）相关业务司局、中国国际人才交流协会、大会众多合作单位将在大会期间举办高层次外国专家座谈会、各类专题业务会议、国际人才市场对接交流会、高峰论坛、总裁峰会、科技创新和知识产权保护交易国际峰会、各类评选表彰等等活动。同时，本次大会还将搭建网上平台，通过大会网上大数据库和资源对接平台，吸引海内外资源开展引才引智项目对接交流。

四、报名与费用

（一）各设区市组织部、科技局，平潭综合实验区党群工作部、社会事业局负责组织本地区企事业单位的报名工作；省直、中直有关单位负责组织本部门及直属单位的报名工作。请于3月22日前汇总本地区、本部门参会报名表（附件1），通过电子邮件或传真形式报送省外国（海外）专家局。

（二）我省参会人员一般由大会组委会统一安排会议期间食宿交通等会务接待，大会组委会暂定的会务服务费标准参考附件2，会务服务费应在大会召开前直接向大会组委会缴纳，相关票据将在大会现场领取。经福建省代表团秘书处同意，我省参会人员也可自行安排参会期间食宿交通。

五、组织领导

成立第十七届中国国际人才交流大会福建省代表团，代表团团长由省科技厅领导担任，省人社厅、省委人才办、中国海峡人才市场和福建国际人才交流协会等有关领导任副团长，统筹领导我省组团参会工作。省委人才办负责我省组团参会工作的指导、协调，省外专局负责我省参会参展各项具体组织实施工作和我省代表团秘书处工作。

 六、其他事项

（一）抓紧做好参会单位的组织发动工作。中国国际人才交流大会是拓展我省高端招才引智渠道，是宣传推介我省人才政策的重要平台，是引进我省急需紧缺的国（境）外高层次人才智力的重要途径，各单位务必高度重视，按照工作部署，多渠道、多形式做好大会的宣传、组织和发动工作，确保完成组团参会的各项工作任务。  

（二）抓紧做好参会前的需求征集工作。为实现参会期间的有效对接，请各单位围绕我省重点产业、重点领域，面向我省重点企事业单位特别是龙头企业征集高层次和急需紧缺人才与项目需求，提出需求、引进计划，于3月15日前汇总后报送省外专局，作为我省在中国国际人才交流大会上重点推介和对接的内容。

（三）抓紧做好参会前的对接工作。今年的中国国际人才交流大会征集的国（境）外人才智力和项目技术将提前在大会官方网站发布，请各单位在会前随时关注大会官方网站发布的相关信息和更新，提前做好对接洽谈工作，提高参会实效性和针对性。
