莆田市科技局关于转发《福建省科学技术厅等五部门关于组织开展2021年福建省技术先进型服务企业认定工作的通知》的通知

发布时间：2021-05-31 10:56
| | |
政策解读:

 

 

各县（区）科技局、财政局、税务局、商务局、发改局，湄洲岛管委会经贸招商局、税务局、计财局，北岸管委会经信商务局、地税分局、发改局、财政局：

现将《福建省科技厅等五部门关于组织开展2021年福建省技术先进型服务企业认定工作的通知》（闽科高〔2021〕7号）转发给你们（文件从http://kjt.fujian.gov.cn/网站“通知公告”栏中下载），请认真按照通知要求积极组织申报，有关事项通知如下：

一、推荐申报程序和时间

各申报企业必须在受理截止时间（7月2日）前，在“全国技术先进型服务企业业务办理平台”（网址： http://tas.innocom.gov.cn，以下简称“技先平台”）上提交申报材料，并通知企业将网络打印的纸质申报上报各县（区、管委会）科技行政主管部门。

各县（区、管委会）科技部门会同财政、税务、商务及发改等部门对企业申报材料进行初审后汇总，于7月15日前将企业申报材料一式三份、纸质申报材料扫描光盘一式六份及《推荐申报技术先进型服务认定企业名单汇总表》（见附件1）和《企业技术先进型服务业务和离岸服务外包业务收入表》（见附件2）纸质材料一式两份及电子版上报市科技局高新科，同时抄送一份至所在地同级财政、税务、商务、发改等部门。

    二、其他事项

1.企业申报材料（详见闽科高〔2021〕7号）通知附件1顺序装订。

2.请各县（区、管委会）科技部门要与财政、税务、商务及发改部门加强沟通和联系，按照《认定管理办法》中的有关要求，充分了解掌握推荐申报的企业的整体发展状况，认真组织做好技术先进型服务企业认定申报推荐，同时要按时督促获得技术先进型服务企业做好年报填报、信息变更等工作。
