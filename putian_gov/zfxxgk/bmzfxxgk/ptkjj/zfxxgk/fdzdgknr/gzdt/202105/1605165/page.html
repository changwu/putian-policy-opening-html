莆田市科学技术局关于开展2020年度全市科普统计调查工作的通知

发布时间：2021-05-31 10:59
| | |
政策解读:

 

 

各县（区）科技管理部门、湄洲岛商务科技局、北岸工信商务局、莆田高新区管委会招商处，市直有关单位：

根据《福建省科学技术厅关于开展2020年度全省科普统计调查工作的通知》（闽科专函〔2021〕8号）要求，我局组织开展2020年度全市科普统计调查工作。现将有关事宜通知如下：

    一、科普统计调查材料报送时间及要求

1.请各县（区）科技管理部门、湄洲岛商务科技局、北岸工信商务局、莆田高新区管委会招商处、市直有关单位于2021年6月14日前，将经审核汇总的各县（区、管委会）或本部门的科普统计数据在线审核并提交。在线填报的科普统计调查表中，必须将“封面”中的“单位全称”“单位负责人”“填表人”等一并完整录入。

2.请各县（区）科技管理部门、湄洲岛商务科技局、北岸工信商务局、莆田高新区管委会招商处、市直有关单位于2021年6月14日前，提交一份本单位（部门）2020年科普抗疫工作总结（800-1000字），电子版发送至邮箱。

内容包括两部分，一是2020年各单位（部门）在抗疫过程中科普工作的总体表现；二是有重点、有特色的或有亮点的案例介绍（可以附照片或图片）。

二、科普统计的填报单位范围及职责

（一）市级单位填报单位范围及职责

1.市级单位：市委宣传部、市发改委、市教育局、市科技局、市工信局、市民族宗教局、市公安局、市民政局、市人社局、市自然资源局、市生态环境局、市住建局、市交通运输局、市水利局、市农业农村局、市文旅局、市卫健委、市应急局、市国资委、市林业局、市海洋渔业局、市市场监管局、市广电局、市体育局、市粮食局、市药监局、市气象局、市地震局、市农科所、市社科联、团市委、市总工会、市妇联、市科协、有关科研机构等。

2.市直单位填报职责：市直有关部门、有关科研机构负责本单位（部门）及其直属机构的科普统计、汇总。包括:向直属机构布置科普统计任务并建立相应的在线统计账号，对统计人员进行在线填报培训，审核数据；将本单位（部门）所有统计数据提交市科技局。

（二）县级单位填报单位范围及职责

1.县（区、管委会）级单位包含与市级单位相对应的部门。

2.县级单位填报职责：各县（区）科技管理部门、湄洲岛商务科技局、北岸工信商务局负责本辖区科普统计、汇总。包括：向本辖区同级有关部门布置科普统计任务并建立相应的在线统计账号，对统计人员进行培训，审核数据；将本辖区所有调查表提交市科技局。

三、科普统计调查在线填报表系统及科普统计操作步骤

2020年度全国科普统计工作实行数据在线填报，请各填报单位在中国科技情报网（http://kptj.chinainfo.org.cn）登录填报、审核、提交数据。

针对本省的使用说明将在福建省科普工作QQ群中发布（群号：496517566）。请各地、各部门负责具体科普统计的人员务必加入该群，以便交流培训。 

关于在线填报系统账号注册分配问题，为明确账号上下级对应统计逻辑关系，建议以上级分配下级账号为主，不建议自行注册。（详见使用说明，请至QQ群下载）。登录账号初始密码详见附件。
