关于转发福建省科技厅、省发改委、省工信厅、省财政厅《关于组织开展2020年科技小巨人领军企业遴选和认定工作的通知》的通知

发布时间：2020-02-17 11:19
| | |
政策解读:

各县（区）科技局、发改局、工信局、财政局，湄洲岛管委会经贸招商局、计财局，北岸管委会经信商务局、发改局、财政局：

   根据《福建省人民政府办公厅关于印发培育科技小巨人领军企业行动计划（2016-2020年）的通知》（闽政办〔2016〕18号）精神，现将省科技厅、发改委、工信厅、财政厅《关于组织开展2020年科技小巨人领军企业遴选和认定工作的通知》（闽科企〔2020〕1号）转发给你们，请认真贯彻执行。并就有关事项通知如下：

   一、2020年新增企业遴选

  （一）新增企业遴选要求

   科技小巨人领军企业遴选在符合《行动计划》遴选标准的基础上，还要着重把握以下几点：

   1.中小企业的划型标准按照工业和信息化部、国家统计局、国家发改委、财政部等四部委出台的《中小企业划型标准规定》（工信部联企业〔2011〕300号文）执行。

   2.应以新一代信息技术、高端装备制造、新能源汽车、生物与新医药、节能环保、新能源、新材料、海洋高新等战略新兴产业领域为重点。

   3.应遴选具有较强创新能力、良好发展潜力和后劲、良好市场前景，在当地行业内有代表性和领头示范作用的高成长科技型中小企业。

   4.2020年新增遴选的企业，其上年度营业收入、科技人员占比、资产负债率等以2019年数据为准；近3年是指2017至2019年，如企业注册成立未满3年的按实际年限计。

   （二）报送与认定程序

   1.2020年新增遴选的，由符合条件的企业填写《福建省科技小巨人领军企业申请书》（附件2）并提交相关附件材料。已入库企业无需再填报。

   2.各县（区）科技、发改、工信、财政部门（含管委会相关部门）科技、发改、工信、财政部门应按照当地人民政府工作部署，遴选确定培育名单（名单应含当地挂钩责任领导）。具体遴选办法由各地自行确定。

   3.培育名单经各县（区）人民政府（管委会）同意后，报送市科技小巨人领军企业培育工作联席会议办公室，联席会议具体事务由市科技局负责。

   4.市科技小巨人领军企业培育工作联席会议办公室对县（区、管委会）推荐上报的企业申报材料进行审查，有必要时可组织专家评审，并将审查结果提交联席会议审核研究。由联席会议提出拟推荐省科技小巨人领军企业培育名单，经市政府同意后报送省科技小巨人领军企业培育工作联席会议办公室。

   二、已入库培育企业信息收集报送

   1.已入库企业经培育发展，其规模若超过《中小企业划型标准规定》的中小企业上限的，仍视为符合遴选标准，继续留库培育。

   2.对极少数不符要求的企业可予以取消，报送附件3。

   3.企业名称变更和挂钩领导等重要情况变更，报送附件4。

   4.企业成长情况调查统计，报送附件5、附件6。

   三、报送时间和要求

   各县（区）人民政府（管委会）请于3月10日前向市科技局报送相关材料,包括：

   1.报送函；

   2.2020年新增福建省科技小巨人领军企业培育名单（纸质材料和电子文档，附件1）一式二份；

   3.福建省科技小巨人领军企业申请书（纸质材料和电子文档，附件2）一式二份；

   4.已入库福建省科技小巨人领军企业资格取消表（纸质材料和电子文档，附件3）一式二份；

   5.已入库福建省科技小巨人领军企业重要情况变更表（纸质材料和电子文档，附件4）一式二份；

   6.已入库福建省科技小巨人领军企业成长情况调查表（纸质材料和电子文档，附件5）一式二份；

   7.已入库福建省科技小巨人领军企业成长情况调查汇总表（纸质材料和电子文档，附件6）一式二份。
