莆田市科技局关于征集第十六届中国·海峡项目成果交易会参展项目和技术需求的通知

发布时间：2018-04-20 16:10
| | |
政策解读:
各县（区）科技局，各有关单位：

第十六届中国·海峡项目成果交易会（以下简称“6·18”）定于2018年6月17-21日在福州举行。根据《福建省科学技术厅关于征集第十六届中国·海峡项目成果交易会参展项目和技术需求的通知》（闽科成〔2018〕3号），省科技厅将组织科技项目成果展览展示等活动，现就征集参展项目和技术需求的有关事项通知如下：

一、展览展示项目

1、近年来组织实施的各类科技计划项目成果；

2、引进境内外成果在我省落地转化的重大科技项目；

3、重点领域科技创新项目。

原则上要求参展项目要有亮点、有实物或模型、应用性强、可推广。

二、技术需求

1、企业发展需解决的技术难题；

2、拟委托开发或共同研发的项目。

三、报送程序及要求

1、各县（区）科技局征集技术需求不少于15项。

2、请各填报单位登录莆田市科技信息网站“通知公告”栏目（网址http://www.ptsti.gov.cn），下载本 通知中的表格。展览展示项目填写《2018年展览展示项目征集表》(附件1)，技术需求填写《2018年技术需求征集表》（附件2），按表格要求将所需材料提交至各县（区）科技局。

3、各县（区）科技局汇总、审核受理项目和相关材料，并填写《2018年展览展示项目和技术需求汇总表》（附件3），于5月3日前将填报单位表格电子文档以及3-5张项目图片（大小1M以上）连同汇总表格一并发送至指定邮箱fufuxin2005@163.com；同时将纸质材料邮寄或传真至市科技局科技合作与成果科。确定参展参会的项目将另行通知。
