关于实施“三百工程”，开展科特派服务农村工作实施方案

发布时间：2009-05-11 00:00
| | |
政策解读:

 

 

 

 

 

 

 

根据莆农创办[2008]1号关于开展“实施三百工程、统筹城乡发展”活动的通知精神，为了做好百名科技人员开展科特派（下称科技服务团）服务“三农”工作，特制定本方案。

一、指导思想

以邓小平理论和“三个代表”重要思想为指导，认真贯彻落实科学发展观，按照“生产发展、生活宽裕、乡风文明、村容整洁、管理民主”的新农村建设总体要求，坚持“工业反哺农业、城市支持农村”的方针，着眼于城乡互动、力量整合。以发展农村经济为重点，提高农民素质为根本，引导人才、智力、技术、资金等资源流向农村、支持农业、服务农民，全面推进社会主义新农村建设。

二、组织机构

由科技服务团所在的成员单位组成“科技服务团工作”领导小组，各相关部门的分管领导任小组成员,领导小组下设办公室。办公室设在市科技局。负责科技服务团下乡服务的组织协调和日常工作。

三、服务团组成

服务团成员按照市委组织部和市创新办确定的名单（105名），分成八个服务组，归属八个成员单位实行动态管理，服务团成员保持相对稳定，可以根据工作需要和服务团成员的表现作适当的调整。

四、服务形式

服务团成员采取脱产、半脱产、定期、不定期等灵活的服务形式，可以采用电话咨询、网络服务、下乡巡回、技术培训、成果推广、进驻龙头企业等多种方式开展工作。每个成员单位设立服务电话，实行部门联动，归口负责。成员单位结合工作职能负责本行业技术需求，积极组织本部门所属科技人员开展科技服务，发挥好科技服务团成员的作用；市创新办、科技服务团领导小组办公室收集的技术服务需求，由科技服务团领导小组办公室协调组织科技下乡服务。遇到技术难题由市科技局牵头组织相关技术专家解决。

五、服务工作要求

每个服务团成员应带着“感情、责任”，发挥各自的专业特长，积极主动开展工作，经常深入基层一线调研了解，每年至少解决2项以上的技术问题，各成员单位负责所属服务团成员的服务情况统计和考核，按时向领导小组办公室报送科技服务团服务情况及相关报表（见附表），半年进行工作小结，年终进行工作总结。根据服务人员服务时间和服务成效，对一些不适宜继续服务的成员予以调换。

六、年度工作要点

1、3月份召开成员单位座谈会，研究制定年度工作。

2、定期、不定期召开成员单位联席会议，研究协调相关工作，总结经验。

3、5月份前举行科技特派员科技服务启动仪式。

4、各成员单位负责收集农村技术需求，填写服务项目计划表报送领导小组办公室安排阶段工作任务。

5、依托市科技情报所、市水科所，建立农村科技信息网络平台试点。

6、开展农村适用技术培训及科技下乡工作。

7、组织部分成员进驻产业化龙头企业，帮助企业建立研发中心，解决企业技术问题。

8、各个成员单位季度报表、半年小结、年终总结。

9、12月份在成员单位考评的基础上，填写上报科技特派员服务工作，情况统计表报送办公室，领导小组总结经验进行考评表彰。

七、考评奖惩

1、每年成员单位要对科技服务团成员的年度服务情况、服务成效进行考评、优秀予以适当奖励；并向领导小组建议推优候选人名单。

2、市科技服务团领导小组每年度组织一次评优工作，从各成员单位推荐的候选人员中评选，对被评为优秀的科技服务团成员予以精神奖励和适当的物质奖励。

3、连续两年评为优秀的科技服务团成员，所在部门应在职称评聘上优先考虑；对连续两年考核差的科技服务团成员，调整出科技服务团队伍，在职称评聘上给予暂缓。

八、服务保障

1、经费保障。由市财政局、创新办、科技局拨出一定资金，作为科技服务团活动专项经费。

2、工作保障。科技服务团成员所在单位必须保障科技服务人员的下乡服务时间和必要的工作条件，不得以本单位业务工作为由影响科技下乡服务。

3、政策保障：

3-1、科技服务团成员下乡开展服务，原单位的工资福利待遇不变，还可领取被服务对象的月生活补贴；

3-2、允许科技服务团成员技术入股、投资入股、参与企业盈利分红（具体参照省人民政府闽政[2007]30号文）；

3-3、表现优秀的科技服务团成员作为项目负责人申报的成果转化、生产推广等各类项目，相关部门给予优先立项支持；

3-4、科技服务团成员领衔开发科技项目，政府优先给予创新资金无偿资助或贷款贴息。

莆田市科技局科技特派员试点先行成效

 

莆田市科技特派员工作是以科技服务团的形式服务“三农”，目前已有105名科技人员分别在“三农”各条战线上开展服务工作，其中进驻农业产业化龙头企业长期服务的有10多人，深入农村开展科技培训的有30多人，不定期下乡开展科技咨询、技术指导，解决实际问题的年有一万多人次，他们充分发挥了科技特派员的作用，为建设新农村作出了突出的贡献。如：

一、莆田市水科所是莆田市科技局科技特派员试点单位，该所有中、高级技术人才12位，1位省百千万人才、2位市拔尖人才，已先后两名高级技术人员被选派到中科院挂职。2008年市科技局组织市水科所挑选八个具有丰富实践经验和讲授能力的中高级职称技术人员，组成科技特派员服务队伍，承担秀屿区新型农民科技培训工程，他们共撰写了35篇培训教材，并全部制成多媒体课件，以适应农民实际，满足农村需求为出发点，篇篇图文并茂，通俗易懂，从2008年6月10日开始，已完成对南日镇、埭头镇共26个自然村的新型农民科技培训，受训人次达一万人次，还为各村建立科技书屋，赠送科技书籍，征询技术需求，解决技术难题。新型农民科技培训工程取得明显的效果，受到农民的普遍欢迎，为新农村建设培训了一大批“有文化、懂技术、会管理”的新型农民。

二、福建莆田海源实业有限公司与中科院海洋所开展院地合作。共建中科院莆田水产良种繁育基地，市领导杨根生、张国胜、蔡尔申、张丽冰亲自参加挂牌仪式，给予极大的关注。莆田市科技局十分重视院地合作工作，组织市水科所长期选派两名科技特派员进驻海源公司，协助企业建立研发中心，利用省科技平台建设基金购买的半自动细菌分析仪等全套仪器设备，与海源公司共建水产病害防治站，科技特派员经常下乡巡诊，免费为全市水产养殖户开展病害防治技术服务；中科院莆田良种繁育基地现在年可提供全国花蛤苗种总量的1/2以上苗种，为全国沿海地区养殖供种，取得了巨大的社会和经济效果。

海源公司近几年来，在莆田市科技局及秀屿区海洋渔业局选派的科技特派员的帮助下， 2006年6月被福建省科技厅评为“科技重大专项科技富民工程示范单位”，2006年12月公司养殖基地被农业部列入“水产健康养殖示范区”，公司2008年被评为省级农业产业化龙头企业，入选福建省创新型试点企业。2009年该公司被省科技厅选定为福建省科技特派员创业示范基地。我市已有四家企业被省科技厅列入省科技特派员创业示范基地。
