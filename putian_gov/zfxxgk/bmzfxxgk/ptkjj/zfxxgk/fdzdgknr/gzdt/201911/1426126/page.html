莆田市科学技术局关于再次开展2019年莆田市科技创新领军人才和科技创业领军人才遴选工作的通知

发布时间：2019-11-07 10:21
| | |
政策解读:

 

各县区科技局、湄洲岛管委会经贸招商局、北岸管委会商务局，市直有关部门，高新区，高等院校，中央、省在莆单位：

    根据2019年10月30日市委人才办召开的市人才会议部署及有关领导指示，“为了让更多、更大范围的人才一起享受壶兰计划红利，让壶兰英才成员单位扩大申报范围，进行人才项目再发动、再申报、再选拔，并按项目下达的计划数1：2的数量重新推荐。”市科技创新领军人才计划数10个、市科技创业领军人才计划数10个。经研究，我局决定再次开展2019年莆田市科技创新领军人才和科技创业领军人才遴选工作。有关事项通知如下：

一、遴选范围与对象、遴选条件、遴选程序、申报材料

    遴选范围与对象、遴选条件、遴选程序、申报材料，按“莆田市科学技术局关于开展莆田市科技创新领军人才和科技创业领军人才遴选工作的通知”（莆市科﹝2019﹞80号）”要求，详见莆田市人民政府网站上的“莆田市科学技术局政府信息公开专栏”之“政府信息公开目录>科技公益事业”栏，该文件2019年7月26日已经公开。今年已经按照该文件申报过的就不需要再进行申报、推荐了。

    二、注意事项和要求

    为做好再次申报、再次推荐工作，相关遴选程序、申报材料的相关注意事项和要求，具体按照如下进行：

    （一）申报时间及要求

    遴选推荐工作实行书面公开申报，并采取自下而上逐级审核上报的方式进行。申报人登录“莆田市科学技术局政府信息公开专栏”（http://www.putian.gov.cn/zfxxgkzl/bmzfxxgk/ptkjj/zfxxgkzl/最新信息公开中）下载申报表，填报后提交至所在单位；所在单位负责核实本单位申报人材料，并根据遴选条件于11月5日前向县区科技局和市直主管部门推荐。

   （二）推荐时间及报送材料

    县区科技局和市直主管部门分别负责对申报推荐人选进行事先严格考察，审核申报人材料，征求同级工信、综治、环保、税务、市场监管等部门意见（注：申报科技创业领军人才还需法院部门的意见），并在一定范围内公示。县区科技局和市直主管部门应于11月8日前将公示无异议的申报人纸质材料（一式2份）和推荐函报送我局（同时发电子邮件）。
