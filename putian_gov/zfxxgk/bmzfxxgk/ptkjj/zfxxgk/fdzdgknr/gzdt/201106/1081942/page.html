莆田市科技局关于成立清理行政规范性文件工作领导小组的通知

发布时间：2011-06-27 00:00
| | |
政策解读:

 

市科技局各科室、直属各单位：

根据《莆田市人民政府办公室关于印发莆田市清理行政规范性文件工作方案的通知》（莆政办[2011]124号）的文件精神，经研究，决定成立莆田市科技局清理行政规范性文件工作领导小组，具体名单如下：

组 长：毛祥华

副组长：林若扬、林成龙、王金来

成 员：陈开平、曾瓈、李奕森、杨文水、傅福新、蔡振斌、

郑晓静、吴逸

下设办公室：

主 任：陈开平（兼）

成 员：林秀莺、陈晖伟
