关于组织市直属单位申报2010年市科技计划项目的通知

发布时间：2010-03-22 00:00
| | |
政策解读:

各有关单位：
2010年莆田市科技计划项目的安排，将紧紧围绕创新型城市建设需求和“十一五”科技发展规划，落实科学发展观，加强自主创新，集中力量解决经济社会发展中的关键性科技问题，促进科技成果转化应用和产业化。本批项目为主面向市本级范围申报（含北岸、湄洲岛）。为做好项目申报工作，请按照项目选题指南（见附件）认真组织申报，现将有关事项通知如下：
一、申报要求
1、申报单位必须是具备科研开发能力和条件的在莆市属以上（含市属）企事业单位（参照公务员管理的事业单位除外）。包括高校、科研开发机构以及在市工商局、市税务直属分局和市民政局批准登记的企业和单位等。
2、已承担市级科技计划项目的单位，2007-2009年有两项以上（含两项）项目到期未验收的，以及未按规定时间报送《2009年度莆田市科技计划项目执行情况表》和《科技计划项目经费活动表》的，不能申报本批项目。
3、项目负责人应为实际主持研究工作的科技人员，政府公务员不能作为项目负责人，项目负责人在项目结束时年龄原则上不超过60周岁，2007年以来立项主持的市级科技计划项目（在研）数原则上不超过1项。
4、项目实施期限为2—3年。项目研发资金预算编制必须真实、可行，要有实际的投入。
5、项目申报鼓励产学研结合，联合申报项目。鼓励和支持政府拨款、单位自筹和银行贷款等多渠道、多层次筹集经费。
二、申报程序
项目申报须提交《莆田市科技计划项目申请书》（2010年版）一式二份，申请书格式从莆田科技信息网下载，网址 http://www.ptsti.gov.cn/首页“下载中心”栏目。湄洲湾北岸及湄洲岛管委会（社会事业局、经贸科）归口负责辖区内申报项目的审查推荐，并负责项目申报材料汇总报送（应同时出具推荐报送函）；市属以上（含市属）企事业单位项目申报材料经主管部门审查后直接报送。项目申报单位和推荐单位应当认真审查有关项目申报材料的真实性和完整性，并承担相应责任。
三、申报时间
项目申报单位和项目推荐单位应于2010年4月29—30日将项目申报材料送达市政府7号楼市行政服务中心一层大厅科技窗口，逾期不再受理。窗口受理工作人员：郭荔清，电话：13959566060。
四、其他事项
1、下列单位的申报推荐数限额为：莆田学院6项，湄洲湾职业技术学院、莆田市农科所、莆田学院附属医院、莆田市第一医院、九五医院、湄洲湾北岸和湄洲岛管委会各3项，其他企（事）业单位各申报1项。
2、申报医学项目，应提交《科技查新报告》。成果推广项目需提交科技成果鉴定（评审）证明。
