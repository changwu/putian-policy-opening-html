莆田市科技·人才活动周组委会办公室关于报送2016年科技活动周活动项目的通知

发布时间：2016-04-27 00:00
| | |
政策解读:

各县(区)科技局、组织部、宣传部、科协，湄洲岛、北岸、高新区管委会，市直有关部门，有关高等院校、科研机构，各市级学会（协会、研究会）：

为全面贯彻党的十八大和十八届三中、四中、五中全会精神，深入贯彻习近平总书记系列重要讲话精神，坚持“五位一体”总体布局和“四个全面”战略布局，树立和贯彻创新、协调、绿色、开放、共享的发展理念，实施创新驱动发展战略，大力“普及科学知识，弘扬科学精神，提高全民科学素养”。根据科技部、中央宣传部、中国科协关于举办2016年科技活动周的通知(国科发政〔2016〕101号)，2016年科技活动周(简称科技周)活动时间定于2015年5月14日—21日在全国举行。本届科技周以“创新引领 共享发展”为主题。根据福建省科技人才活动周组委会办公室的活动要求，市科技·人才活动周组委会将会同各地、各有关部门在全市开展一系列群众性科技活动。为切实做好本届科技周的各项筹备工作，现将有关事项通知如下：

一、“创新引领 共享发展”为本届科技周主题。寓意创新是引领发展的第一动力，科技创新驱动经济和社会发展，改变着人们的生产和生活方式；科技创新创业成果为全国各族人民共享，助力全面建成小康社会，实现第二个百年奋斗目标，实现中华民族伟大复兴的中国梦。按照本届全国科技周的活动要求，宣传科技创新成果，开展特色科普活动，开放优质科技资源，倡导科学生活方式，进一步展示科技创新成就、大众创业万众创新成果，举办丰富多彩的群众性科技活动，激发科技创新热情，营造支持科技创新，提升公众科技意识和科学素养，促进科学发展的良好社会氛围。各县(区、管委会)、市直各有关部门要结合主题，突出区域特色和行业优势，精心组织开展活动。

二、市科技周组委会办公室设在市科技局，负责市科技周日常工作。各县(区、管委会)、市直各有关部门要高度重视科技周工作，安排专项经费，保障活动的顺利开展。各县(区、管委会)科技行政管理部门要主动承担科技周的组织工作，牵头成立相应的科技周组织机构，安排专人负责日常工作，与组织部、宣传部及科协密切配合，加强组织协调，广泛动员社会各界参与科技周的各项活动。

　　三、为集成各地各部门的活动资源，更有效地向公众和媒体宣传、介绍2016年科技周开展活动情况，请各县(区、管委会)、市直各有关部门组织有关单位、高等院校、科研机构等通过全国科技周网上系统（网址：kjhdz.actc.com.cn）在线填报《2016年科技活动周重点项目备案表》，申报截止时间为4月15日；同时将科技周活动的主要活动项目(包括电子文档)报送市科技局（E-mail：pt2693323@163.com）。各县(区、管委会)的活动项目由县(区)科技局、管委会科技行政管理部门收集汇总后统一报送。
