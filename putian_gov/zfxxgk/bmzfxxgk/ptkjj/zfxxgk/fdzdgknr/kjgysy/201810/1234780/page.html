莆田市科学技术局关于贯彻落实《关于进一步以用为导向产学研结合的实施意见》的意见

发布时间：2018-10-08 15:00
| | |
政策解读:

各县（区）科技局，市直有关部门，各高等院校，各有关单位：

为贯彻落实《福建省人民政府关于进一步加强以用为导向产学研结合的意见》（闽政〔2017〕48号）精神，全面实施创新驱动发展战略，推进以“用”为导向的产学研结合，加快构建适应经济发展新常态的科技成果转移转化长效机制，推进大众创业万众创新和建设美丽莆田，创建美丽中国示范区建设，结合我市实际，提出如下具体实施意见，请一并贯彻落实。

    一、实施产学研合作工程，鼓励联合科技攻关及科技成果转化

至2020年，围绕新型显示面板、集成电路、新材料、高端装备、食品医药以及高技术服务业等产业，推动100家企业与高校、科研机构建立长期稳定的产学研结合关系，联合科技攻关，实施200项科研项目，转化重大科技成果100项，提高企业自主创新能力。

二、 加强产业技术创新，建立产业技术创新战略联盟

围绕我市十大产业，依托龙头骨干企业，联合高校、科研院所组建产业技术创新战略联盟或产学研合作产业基地，开展产业前沿核心技术、关键共性技术的联合攻关，着力突破产业发展的技术瓶颈，形成一批具有自主知识产权的优势技术和具有自主品牌的目标产品。重点围绕建设美丽莆田的“一区、一中心、五品牌、九行动”开展产学研专题对接，形成一批产学研合作科技示范园区和产学研合作产业基地，促进产业集聚发展。到2020年，建成省级以上产业技术创新战略联盟5个。

三、 建立健全产学研结合机制

鼓励高校、科研机构建立行业技术开发基地、产学研“双创”平台等创新服务平台，加强产学研协同研发创新和产业重大关键技术、共性技术攻关，为中小企业提供技术创新服务。对高校、科研机构转让、许可专利给予奖励。对企业购买高校、科研机构科技成果、专利在获得省级给予补助基础上，我市给予1︰0.5的配套补助。

四、 推动产学研创新平台共建共享

支持国（境）内外高校、科研机构、企业集团等来莆创办或与在莆法人单位合作创办研发机构。鼓励高校、科研机构与企业共建重点实验室、工程研究中心、技术创新中心、企业技术中心等科技创新平台，开展研究开发、中试熟化和产业化开发。至2020年，建设省级以上科技创新平台50个。引导各类科技创新平台将科研基础设施、大型科研仪器、科技数据文献、科技成果等科技创新资源向社会开放。对高水平的研发机构，在获得省级给予补助基础上，我市给予1︰1的配套补助。推动东南新工科产业学院建设，力争五年内建成产教融合示范学校。

五、 深化院地合作广度深度

针对我市战略性新兴产业技术创新、传统产业转型升级、供给侧结构性改革和“美丽莆田”建设等领域的技术需求，深化与中国科学院等大院大所合作，推进福建省中科院STS（科技服务网络计划）莆田分中心建设。至2020年，组织实施20项中科院科技成果转化和产业化项目以及创新团队引进项目，为企业提供技术、人才等多种形式的服务，促进双方合作共赢。

六、构建科技中介服务体系，形成产学研合作的桥梁和纽带

加快“6·18”虚拟研究院高端纺织分院建设，提升国家技术转移海峡中心莆田分中心、中科院海西研究院莆田中心等平台的技术转移和创新服务功能，打造专业化产学研服务载体，加速科技成果引进消化吸收再创新。构建市知识产权运营中心，对接“知创福建”知识产权公共服务平台。实施专利导航产业发展创新计划，促进知识产权与产业发展深度融合。完善以企业需求为导向、高校和科研机构为源头、技术转移和成果转化服务为纽带、产学研相结合的技术市场服务体系。莆田学院和湄洲湾职业技术学院应当建立技术转移机构，支持各县（区）及工业园区、企业等建立技术转移机构，培育一批国家级、省级技术转移（示范）机构。大力发展技术市场，鼓励和支持企事业单位开展技术开发、技术转让、技术咨询、技术服务等技术交易活动。对促进技术交易业绩突出的技术转移服务机构给予补助。

七、保障措施

一是加强组织领导。市科技局会同市经信委、发改委、教育局、财政局等部门，加强对产学研结合和科技成果转移转化工作的统筹协调、督促检查，建立职责明确、分工负责的协调工作机制。二是强化多元投入。建立促进产学研结合和科技成果转移转化的激励机制，将产学研结合和科技成果转移转化情况作为财政资金对单位支持的重要依据。三是注重示范引导。各有关单位要引导全社会关心支持产学研结合和科技成果转移转化，及时总结推广可复制的经验和模式，营造良好社会氛围，进一步激发全社会参与产学研结合和科技成果转移转化的活力。

 

莆田市科学技术局

2018年9月19日
