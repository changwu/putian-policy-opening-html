莆田市科学技术局 中共莆田市委宣传部莆田市科学技术协会关于举办2017年莆田市科技活动周的通知

发布时间：2017-04-28 00:00
| | |
政策解读:

各县区科技局，湄洲岛管委会经贸招商局，北岸管委会商务局，高新区管委会办公室，各县区委(工委)宣传部，各县区科协，市直有关部门，有关高等院校、科研机构：

    根据省科技厅、省委宣传部、省科协《关于举办2017年科技活动周的通知》（闽科政〔2017〕4号）精神，市科技局、市委宣传部、市科协决定联合有关部门举办2017年莆田市科技活动周（以下简称市科技周）。现将有关事项通知如下。

一、活动时间和主题

2017年市科技周时间定为5月20日—27日举办，市科技周主现场活动时间、地点另行通知。围绕“科技强国 创新圆梦”主题，贯彻落实习近平总书记在全国科技创新大会上关于“科技创新、科学普及是实现创新发展的两翼，要把科学普及放在与科技创新同等重要位置”的重要指示，广泛开展丰富多彩的群众性科技活动，动员号召全市科技工作者和社会各界，积极投身建设世界科技强国的伟大实践；充分调动全社会科技资源服务于脱贫攻坚战，以科技创新驱动精准扶贫精准脱贫，让人民群众共享科技改革发展成果，提高获得感和幸福感，推动全面建成小康社会，为实现中华民族伟大复兴的中国梦和建设宜业宜商宜居美丽莆田奠定坚实的社会基础。

二、活动内容和形式

2017年全市科技活动周要深入实施创新驱动发展战略，全面落实《中华人民共和国科学技术普及法》、《中华人民共和国促进科技成果转化法》、《中华人民共和国科学技术进步法》、《国家中长期科学和技术发展规划纲要（2006—2020年）》、《福建省建设国家创新型省份实施方案》、《莆田市全民科学素质行动计划纲要实施方案（2016-2020年）》、《莆田市“十三五”科技发展和创新驱动专项规划》，突出科技精准扶贫脱贫取得的主要成就，突出科技成果转移转化带来的新技术、新产品和新产业，突出科技创新发展的新进展、新成效，着力提高全民科学意识和科学素养，使建设世界科技强国成为全民的自觉行动。重点突出以下4方面内容。

1. 宣传科技扶贫成就。通过展示科技精准扶贫脱贫、科技特派员等工作进展，农业科技园区等建设成效，集中宣传科技支撑精准扶贫脱贫的共同行动和主要成效，在全市形成科技界精准扶贫务实行动的良好氛围。

2. 举办特色科普活动。针对社会关切的食品安全、健康生活、质量标准提升、环境保护(含空气、水、土壤)、低碳节能、公共安全(含消防安全)、防震防灾减灾、应急避险等热点问题，尤其针对公众科技需求，举办各种体验性强、参与度大的科技、科普活动。面向少数民族、边远贫困地区和革命老区开展针对性强、趣味性高的公益科普活动。结合科技热点问题，组织专家进行通俗化讲解，促进公众理解科学、支持创新、参与创业。原则上要求各县(区、管委会)组织10人以上科学使者下基层，其他部门（单位）根据实际情况组织开展活动。

3. 开放优质科技资源。推进大科学装置、国家及省（重点）实验室、国家及省工程技术（研究）中心、重大科研试验场所等国家和省、市级各类高端科技资源向社会开放，激发公众特别是青少年的科学兴趣。各类科研机构、大学、高新技术企业和科技园区向社会开放，促进科技知识的宣传普及。各类科普场馆、科普基地向社会开放。流动式科普设施重点向少数民族、边远贫困地区和革命老区开展科普服务。

4. 营造创新文化氛围。结合实际，搭建科技服务社会的科普公共服务平台。充分发挥报纸、电视等主流媒体作用，加强科普宣传。积极倡导科学精神，引导广大科技工作者坚持国家至上、民族至上、人民至上，始终胸怀大局、心有大我，始终坚守正道、追求真理，自觉做践行和弘扬社会主义核心价值观的模范。积极培育创新文化，尊重创新创业人才，提升公众科学文化素养，为建设创新型城市营造良好环境。

三、有关要求

1.加强组织协调。各县(区、管委会)、市直各部门要高度重视科技周的组织工作，加强组织协调和资源统筹，有效调动各方面的积极性和创造性，认真编制活动方案，策划重点活动项目，精心组织开展活动。要贯彻落实中央八项规定，力戒形式主义，加强安全防范措施，着力在提高活动实效上下功夫，切实把科技周抓实办好。

2.制定活动方案。各县(区、管委会)、市直各部门要按照本次科技活动周的要求，尽快制定活动方案，精心策划重点项目，配合全国科技活动周组委会做好相关重点活动。请于2017年4月30日前，在全国科技活动周网上系统（网址：kjhdz.cstec.org.cn）填报《2017年科技活动周重点项目备案表》、《2017年参与开放活动的科研机构和大学备案表》；同时，报送纸质和电子版的《2017年莆田市科技活动周活动项目备案表》(见附件3)，纸质材料需加盖公章，一式一份。

3.强化宣传报道。各县(区、管委会)、市直各部门要加强对科技周的宣传报道，组织动员各级各类新闻媒体深入基层深度报道，及时全面地宣传丰富多彩的群众性科技活动。要重视发挥电视网络等媒体在科普宣传中的重要作用，提高科学传播速度和质量，扩大科技周的影响面和覆盖率，营造良好社会舆论氛围。

4.认真总结梳理。科技周结束后，各县(区、管委会)、市直各部门要对本届科技周的组织实施、主要内容、活动成效、典型案例等进行认真分析和梳理。各地由科技管理部门牵头，会同宣传部和科协，形成当地科技周工作总结报告（市直有关部门、高校、科研机构等形成本单位科技周工作总结报告），连同影像资料及媒体报道资料（其中视频时长请勿超过5分钟）、《2017年莆田市科技活动周活动情况统计表》(见附件1)、《2017年万名科学使者进社区（农村、企业、军营）活动人员信息表》(见附件2)，于2017年5月29日前报送市科技局。以上材料须同时报送纸质和电子版材料。

有关2017年市科技周的通知文件，也登载在莆田市科技信息网站（http://www.ptsti.gov.cn）上。
