莆田市科学技术局关于2020年市级STS计划配套拟立项与资助项目公示的函

发布时间：2020-12-09 17:53
| | |
政策解读:

    根据《莆田市财政局关于印发〈莆田市市级财政专项资金管理办法〉的通知》（莆财预〔2017〕159号）和莆田市科技项目计划与经费实行公示异议期制度，现将莆田市2020年市级STS计划配套拟立项和资助的10个项目进行公示。公示时间从2020年12月10日开始，公示期为7个自然日。公示期内社会各界如对公示的项目有异议，可以书面形式向市科技局提出。异议书应写明详细的异议理由，注明异议人的姓名、所在单位和详细地址及联系方式。

受理异议单位：莆田市科技局资源配置与监督科、市纪委驻市司法局纪检监察组。公示电话：2655519、2678158，邮编编码：351100。

 

附件：2020年莆田市STS计划配套拟立项与资助项目

 

 

                                                莆田市科学技术局

                                                                                2020年12月9日
