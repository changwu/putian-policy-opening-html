莆田市科学技术局关于2020年下半年市科技计划项目结题情况的通报

发布时间：2021-02-08 15:33
| | |
政策解读:

 

 

各县（区、管委会）科技管理部门、各有关单位，各业务科室：

现将2013年以来市科技计划项目结题情况及到期未结题项目清单进行通报，请按照《莆田市科技计划项目管理办法》（莆市科〔2019〕136号）和《关于加强我市科技领域科研诚信制度建设的实施意见》（莆市科〔2018〕167号）等规定，加强项目管理和到期未结题催办,采取有效措施提高项目结题率。对到期未结题项目的承担单位和项目负责人，取消其申报各类科技计划项目资格。对强制中止和强制撤销的项目，根据严重失信行为责任，将相关项目承担单位和负责人列入“黑名单”，并推送到信用信息系统平台，进行联合惩戒。

 

    附件：1.2013年以来项目结题情况汇总表

 

 2.2013年以来到期未结题项目清单
