| | |
政策解读:

 

各县（区）科技局、党委宣传部、卫生健康局、科协，湄洲岛管委会经贸招商局、北岸管委会商务局、高新区管委会招商处、党工委宣传部、卫生健康局，市直有关部门，有关高等院校、科研机构：

根据省科技厅、省委宣传部、省卫生健康委、省科协《关于举办2020年福建省科技活动周的通知》（闽科专〔2020〕8号）精神，市科技局、市委宣传部、市卫生健康委、市科协决定联合有关部门举办2020年莆田市科技活动周（以下简称市科技活动周）。现将有关事项通知如下。

一、活动时间

8月23日至29日。市科技活动周主场活动时间、地点将另行通知。

二、活动主题

科技战疫 创新强国

三、活动内容

深入学习贯彻习近平新时代中国特色社会主义思想，全面落实党的十九大和十九届二中、三中、四中全会精神，动员号召全市科技工作者、科普工作者、社会各界人士积极投身实施创新驱动发展战略、加快创新型城市建设的伟大实践；以科技战疫为重点，展示科学技术对战胜疫情的重要支撑作用和系列成果，展示科学普及在引导人民群众科学识疫、科学防疫中发挥的重要作用；以新发展理念为核心，展示科技创新对我市经济社会发展的重要支撑作用，展示科技创新在全面建成小康社会、满足人民群众美好生活需要、生态莆田建设中的显著成效；以科学普及与科技创新同等重要为主线，深入实施《中华人民共和国科学技术普及法》《福建省科学技术普及条例》，在全市范围内举办群众性科技活动，展示科学普及工作和科技活动周20年成效，全方位推动高质量发展超越，助力实现中华民族伟大复兴中国梦。

2020年全市科技活动周要全面贯彻落实《中华人民共和国宪法》《中华人民共和国促进科技成果转化法》《中华人民共和国科学技术进步法》《国家中长期科学和技术发展规划纲要（2006—2020年）》《福建省建设国家创新型省份实施方案》 《莆田市全民科学素质行动计划纲要实施方案（2016-2020年）》《莆田市“十三五”科技发展和创新驱动专项规划》等科技创新科普相关法律法规政策和文件；认真贯彻落实市委、市政府“突出开放招商 强化项目带动”的决策部署，突出科技创新支撑强国富民这条主线，统筹设计各项活动，助力全面建成小康社会和宜业宜商宜居美丽新莆田建设。重点突出以下4方面内容。

　　（一）展示科技战疫成效。展示药物、疫苗、溯源、传播途径、动物模型等科研攻关新进展；展示呼吸机、负压救护车等疫情防控新技术新装备；展示军民科技融合;展示科普工作在普及抗疫知识方法、助力复工复产等方面发挥的重要作用；宣传科技战疫先进典型，讲好一线抗疫故事。

（二）展示科技创新成就。展示科技重大专项成果，特别是人工智能、信息技术、生物技术等方面的新技术、新装备、新产品，彰显科技创新支撑经济高质量发展成效。推进重大科学工程、大科学装置、重点实验室、工程（技术）中心、科研机构和大学等科技资源向公众开放。展示科技活动周20年发展历程，特别是优秀科普作品、产品、展品及重大事项。

（三）体验美好生活活动。聚焦重点科技计划项目、重大科技专项成果，展示科技创新对改善和提升人民生活质量的显著成效。针对公众关注的科技热点，开展科普讲解、实验演示、示范传授等活动，普及基本科学知识和常用技术方法。广泛开展疫情防控、防毒禁毒、防爆反恐、防震防灾减灾、应急避险、消防安全、质量标准提升、生态环境保护(含空气、水、土壤等)、垃圾分类、低碳节能、食品安全、平安健康生活、艾滋病防控、无偿献血、公共安全和公共卫生等科普知识的宣传。面向青少年、劳动者、领导干部和公务员、部队官兵等公众多样化科技需求，举办互动性、参与性、体验性强的科技活动和丰富多彩的科普惠民活动。市科技活动周期间，原则上要求莆田学院、湄洲湾职业技术学院向社会开放2个以上公共实验室，市农科所等科研院所向社会开放1个公共实验室。

（四）科技助力脱贫攻坚。展示科技创新在全面建成小康社会中的重要作用。根据乡村振兴战略和脱贫攻坚战总要求，加强农村科普资源和科普能力建设，送科技下乡进村入户，提供精准技术帮扶活动。开展适合革命老区和少数民族特点的特色科普活动，提高广大农民的科技意识，助力科技扶贫、精准脱贫。市科技活动周期间，原则上要求各县(区、管委会)组织10人以上科技特派员下基层，其他部门（单位）根据实际情况组织开展活动。

四、有关要求

（一）加强组织协调。各县（区）科技管理部门、党委宣传部门、卫生健康部门、科协组织要高度重视，加强统筹协调和资源共享，充分发挥各级科普工作联席会议机制的作用，认真研究制定本县（区）本部门科技活动周实施方案，调动各方面的积极性和创造性，切实办好今年的科技活动周活动。请于2020年7月25日前，填报纸质和电子版的《2020年科技活动周重点项目备案表》（见附件1）《2020年参与开放活动的科研机构和大学备案表》（见附件2）。纸质材料需加盖公章，一式二份，报送市科技局。

（二）突出安全实效。各县（区）各部门要认真贯彻落实中央八项规定及其实施细则精神，严格执行国家和我省我市联防联控机制部署，加强疫情防控和防汛防台风等各项安全防范措施，防止聚集性感染及其他安全事件发生，切实提高科技活动周活动实效。（注：根据疫情发展形势，若届时无法组织相关实体活动，可举办网络科技活动周活动。请各县（区）各部门根据国家、省、市和各县（区）应对新型冠状病毒肺炎疫情联防联控机制统一安排，合理确定举办方式）

（三）强化宣传报道。各县（区）各部门要重视科技活动周的宣传报道工作，组织动员各类新闻媒体深入基层，及时全面准确地宣传科技活动周情况，扩大活动的影响力和覆盖面。重视发挥新媒体优势，充分利用大数据、云计算、人工智能等现代信息技术，采取微视频、微动漫、H5、VR、AR、MR等技术开展宣传，扩大科技活动周在全社会的传播效果。

（四）注重总结提高。科技活动周结束后，各县（区）各部门要对本届科技活动周的组织实施、主要内容、活动成效、典型案例等进行认真分析和梳理。各县（区）由相关县（区）科技管理部门牵头，会同宣传部、卫生健康委和科协，形成当地科技活动周工作总结报告（市直有关部门（单位）、高校、科研机构等形成本单位科技活动周工作总结报告），连同影像资料及媒体报道资料（其中视频时长请勿超过3分钟）于2020年9月4日前报送市科技局。以上材料须同时报送纸质和电子版材料。纸质材料需加盖公章，一式一份。

有关2020年市科技活动周的通知文件，将登载在莆田市人民政府网站“政务公开”-“政府信息公开专栏”-“部门信息公开”-“莆田市科技局”的“最新信息公开”栏上，同时通过政府内网发送至市级部门单位。
