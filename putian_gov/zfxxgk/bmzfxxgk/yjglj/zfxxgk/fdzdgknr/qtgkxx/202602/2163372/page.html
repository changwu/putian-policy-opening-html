莆田市应急管理局关于2025年法治政府建设年度报告

发布时间：2026-02-17 00:55
| | |

                                           莆应急〔2026〕10号


中共莆田市委、莆田市人民政府，福建省应急管理厅：

2025年，莆田市应急管理局在市委、市政府的坚强领导和市委依法治市办的有力指导下，坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实习近平法治思想，紧紧围绕“应急管理体系和能力现代化”目标，扎实推进法治政府建设各项工作，全力防范化解重大安全风险，为全市高质量发展营造了安全稳定的环境。现将有关工作报告如下：

一、2025年工作开展情况

（一）坚持立规明矩、权责法定，高位统筹应急法治建设。一是强化组织领导。局党委切实履行推进法治建设领导职责，将学习贯彻习近平法治思想作为重要议题，通过理论学习中心组学习、专题研讨等形式，深化法治理念。局主要领导亲自部署、定期研究法治重点工作，推动应急管理综合执法队伍改革，切实履行第一责任人职责。二是依法审慎决策。严格执行重大行政决策程序规定，聘用专业法律顾问，全年累计审核重大合同、文件26份，从源头防范决策风险；落实行政规范性文件合法性审核与定期清理机制，现行有效规范性文件16份，确保制度统一、权责清晰。三是提升队伍素质。将法治教育纳入干部教育培训整体规划，依托福建省干部网络学院等线上平台，组织全员学习安全生产、防灾减灾救灾等法律法规，人均完成培训36学时。突出实战导向，组织278名骨干赴省级基地参加地震地质灾害、水域救援等专业培训，开展市级综合应急演练3场，切实提升干部职工运用法治思维和法治方式应对风险、处置事件的能力。

（二）坚持减繁去苛、创新机制，优化应急管理政务服务。

一是夯实服务基础。严格落实审批服务事项“五级十五同”标准，对审批事项、办理内容、职责权限、政策依据、流程环节等核心要素进行全周期维护，从源头破解服务碎片化、流程不透明等问题，企业群众办事“有章可循、一目了然”，政务服务标准化水平显著提升。二是精简审批程序。推行危险化学品经营许可“批量变更”服务模式，全年办结2件、批量出证37份，累计减少企业35次申请次数、70份重复提交材料。贯彻“高效办成一件事”要求，对特种作业操作资格认定等事项实行“批量申请、合并受理”，年均减少企业线上办理300次、材料300份，审批效率显著提升。三是提升政务效能。推行“动态跟进、一办到底”服务机制，2025年共高效办结各类政务服务事项513件，办结率100%。其中，办理行政许可409件，行政确认104件；完成特种作业操作资格认定发证7354份，安全生产知识和管理能力考核合格发证945份，群众和企业满意度持续提升。

（三）坚持刚柔并济、惩教结合，提升安全监管执法效能。一是规范涉企检查。全面推行行政执法公示、全过程记录、重大执法决定法制审核“三项制度”，配套出台执法人员行为规范、着装管理规定等11项制度。严格执行年度监督检查计划，全面应用“双随机、一公开”监管，2025年按计划抽取检查企业40家。所有涉企行政检查均通过福建省“涉企执法平台”实施，建立执法记录“双平台”比对机制，累计比对数据1219条，有效杜绝“体外循环”，全市应急系统检查企业频率同比下降37.9%。二是创新监管方式。打造“智能式+说理式+清单式+帮扶式”四式联动执法模式，推广运用“闽企安”AI助手、无人机巡查、在线监测等非现场监管手段，实现“无处不在”的监管与“无事不扰”的平衡，2025年非现场监管占比大幅提高；现场向企业解读隐患危害、整改方法和法律要求，让企业从“被动接受处罚”转向“主动消除隐患”，执法投诉率下降95%，企业主动整改率达100%。三是严肃执法监督。扎实开展基层行政执法领域突出问题专项整治，全面梳理2022年以来案件线索，公开征集问题并拓宽投诉渠道。组织开展市级督查和县区交叉检查，督促整改问题18个；对2022至2024年行政复议案卷及2024年行政处罚案卷共123卷进行集中评查，通报并整改共性问题24个；严格落实生产安全事故调查处理制度，挂牌督办一般事故5起，依法追究相关单位和人员责任，维护法治严肃性。

（四）坚持底线思维、执政为民，筑牢公共安全应急防线。一是压实责任链条。推动将安全生产重大部署纳入市政府工作报告、领导干部政绩考核和离任交接清单。市委、市政府主要领导主持召开相关会议11次研究安全生产工作。创新建立安办、消安办、道安办“三办”融合与“周研判、月分析、季提示”常态化机制，全年发布各类风险提示函、督办单70余件，推动属地管理、部门监管责任落地。二是强化整治攻坚。以安全生产治本攻坚三年行动为总揽，扎实推进城镇燃气、电动自行车、危险化学品、有限空间等“一件事”全链条安全整治。全年累计排查企业1.81万家次，查改重大事故隐患869项，实施行政处罚1351.36万元，落实“一案双罚”20次，责令停产整顿16家，曝光约谈联合惩戒企业51家，保持严管高压态势。三是抓实应急处突。持续深化“1262”气象防汛响应联动，严格落实预警“叫应”和人员转移避险措施，全年安全转移群众7350人次，成功实现汛期台风暴雨防御“零死亡”。强化应急力量建设和物资保障，为58支队伍配备专业救援装备1629台（套），建成基层预警指挥服务站33个，创建全国综合减灾示范社区41个，城市安全韧性稳步增强。

（五）坚持普治并举、拓展阵地，营造浓厚应急法治氛围。一是打造普法矩阵。融合传统媒体与“两微一抖”等新媒体平台，开设《安全生产月》《治本攻坚三年行动》等专题专栏，全年累计发布安全科普、以案释法类作品1675条次，总点击量达8994.42万人次。加大执法案例公开曝光力度，全年公布典型执法案例9批次、涉及企业33家，强化警示震慑效应。二是开展主题宣传。结合“5·12”防灾减灾日、“安全生产月”等重要节点，广泛开展安全宣传“五进”活动。持续推进线下安全体验场所建设，投用安全文化主题公园、应急消防科普教育基地、“商渔共治”宣教基地等13个，通过场景化、互动式体验，提升公众安全法治意识和自救互救能力。三是推动社会共治。自觉接受人大依法监督和政协民主监督，办好人大代表建议5件、政协委员提案2件。聚焦群众急难愁盼问题，受理安全生产类举报520件，核实162件，发放举报奖励约6.66万元，办理12345群众诉求16件；动员全市14万余名网格长、单元长参与安全宣传与监督，凝聚起“人人讲安全、个个会应急”的社会共识。

二、存在问题

（一）行政执法系统冗余繁杂。应急管理系统承接了各级各部门组建的多个监管执法检查统计系统，国家、省、市各系统未实现数据共享，多头重复录入现象给基层工作造成不必要的负担。

（二）行政执法环境有待优化。强化安全监管指导服务、严格行政执法与优化营商环境之间的关系难以把握，涉企行政执法检查与专项监督检查之间的关系有待理顺，基层行政执法人员依法履职，严格查处安全生产违法行为有较大压力。

（三）行政执法标准有待统一。不同行业部门之间行政裁量权基准、技术规范要求不一致，基层执法人员和企业对执法要求的理解和执行存在困难。在日常监管过程中，各级行政执法监督机构之间联合会商不足，涉企行政执法诉求沟通机制不流畅，易导致企业无所适从，增加企业负担。

三、2026年法治政府建设工作安排

2026年，市应急管理局将继续坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平法治思想，全面落实市委、市政府关于法治政府建设的决策部署，重点抓好以下工作：

（一）筑牢法治根基，提升应急法治驱动力。围绕法治政府建设责任制落实，突出主要负责人履行法治建设第一责任人职责，切实履行法治建设重要组织者、推动者和实践者的职责，及时部署重要工作、过问重大问题、协调重点环节、督办重要任务，把应急管理、安全生产各项工作纳入法治化轨道。将法治能力作为干部选拔任用的重要参考，组织开展模拟法庭、案例研讨等活动，推动干部职工自觉养成办事依法、遇事找法、解决问题用法、化解矛盾靠法的思维习惯和行为方式，使法治真正成为应急管理工作的内在驱动和核心保障。

（二）规范权力运行，提升行政执法公信力。严格执行重大行政决策程序，完善局内重大决策事项清单，全面落实合法性审核、公平竞争审查、风险评估等要求；升级法律顾问参与机制，使其深度嵌入政策制定、合同审查、复杂案件处理等环节。全面修订莆田市应急管理行政处罚程序规定，细化从立案到结案各环节操作规范；推广“闽企安”AI助手功能，拓展其在风险智能研判、隐患自动识别、整改跟踪闭环等方面的应用。持续推进跨部门、跨区域协调联动执法检查机制，避免对同一企业的同一执法事项进行重复检查、多头检查。健全执法案卷季度评查、年度考评机制，引入第三方专家参与评查，定期公开典型执法案例和执法数据分析报告，主动接受社会监督，以公开促规范，以透明赢公信。优化法治化营商环境，加强和规范事中事后监管，健全涉企行政执法诉求沟通机制，依法保障各类市场主体合法权益。

（三）理清责任边界，提升安全监管执行力。以政府部门自身履责到位，带动企业主体责任落实，坚持每月分析、季度提示风险形势，持续厘清新兴业态和部门职能交叉领域监管责任，加强警示通报、约谈曝光、问题交办、挂牌督办、提级调查等手段运用，推动安全生产责任落实。圆满完成安全生产治本攻坚三年行动任务收官，持续深化危险化学品、非煤矿山、工贸、燃气、消防、道路交通、建筑施工等重点行业领域专项整治，推动“一件事”全链条整治延伸至新业态、新领域。健全应急管理法规标准和政策保障体系，针对鞋服、工艺美术等特色产业和“厂中厂”等薄弱环节，持续研究制定重点行业领域安全管理指南或标准，提升依法治安工作水平，推动企业加大安全投入，改造升级工艺设备，助力实体经济安全发展。

（四）依法应急处突，提升公共安全守护力。强化“两委三部”和各专项指挥部办公室统筹协调作用，依法依规压实各级防灾减灾救灾责任，补齐灾害防御应急短板，推动总体预案、专项预案修订，提升扁平化指挥、一体化协同效能；统筹做好台风暴雨、低温寒潮、山洪地质灾害防治与森林防灭火工作。完善重特大自然灾害灾情快速评估和应急物资紧急调拨机制，及时做好受灾群众紧急救助、过渡期安置和冬春生活救助，保障基本民生。完善应急救援队伍调用与补偿机制，保障社会应急力量依法有序参与救援，在突发事件处置中，严格依照法律规定和应急预案要求，实施交通管制、危险区域管控、物资征用等措施，确保应急处置工作高效有序、于法有据。

（五）创新普法载体，提升应急法治感染力。深入挖掘妈祖文化中“立德、行善、大爱”的精神内涵，将其融入“人民至上、生命至上”的应急价值观和法治实践，创作系列具有莆田特色的应急法治文化产品，打造莆田特色普法品牌；持续提升安全文化主题公园、应急科普教育基地等实体阵地的法治内涵和互动体验，提升全民应急法治文化认同。深化“网格+安全生产”模式，发挥网格员安全宣传、信息报告、劝导制止作用，健全社会有奖举报和企业内部隐患报告奖励“双管齐下”机制，鼓励社会监督和全民参与，壮大基层应急管理普法志愿者队伍，鼓励其开展公益性普法活动，凝聚“人人讲安全、个个会应急”的安全文化共识。
