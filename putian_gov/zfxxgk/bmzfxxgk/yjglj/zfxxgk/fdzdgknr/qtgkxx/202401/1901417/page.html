发布时间：2024-01-30 19:52
| | |

莆应急〔2024〕6号

 

 

本年度报告是根据《中华人民共和国政府信息公开条例》的要求，由莆田市应急管理局编制完成。报告由总体情况、主动公开政府信息情况、收到和处理政府信息公开申请情况、政府信息公开行政复议、行政诉讼情况、存在的主要问题及改进情况、其他需要报告的事项等六个部分组成。本报告中所列数据的统计时限自2023年1月1日起至2023年12月31日止。本报告的电子版可在我局网站政府信息公开——政府信息公开年报(http://mem.putian.gov.cn/zwgk/

zfxxgk/zfxxgknb/)上查看。如对本报告有疑问，请联系莆田市应急管理局办公室（地址：莆田市荔城中大道2169号市政府办公区西北侧市数字中心3楼409，邮编：351100，电话：0594-2298938，传真：0594-2339655）。

一、总体情况

（一）深化主动公开

快速、准确地通过局网站发布主动公开信息，便于群众及时、全面了解我局相关工作，持续推动政府信息主动公开目录的动态更新调整。2023年及时、主动向社会公开政府信息5条。

（二）规范依申请公开

认真落实依申请公开各项工作规定，健全完善政府信息公开申请登记、审核、办理、答复、归档的工作制度，畅通申请诉求渠道，严格按照法定时限答复，保障答复内容严谨、形式规范，同时做好答复书的送达及申请人的回访工作。2023年共收到依申请公开3件，均按时办结。

（三）强化信息管理

对照《政府信息公开条例》，认真梳理职责范围应当主动公开的政府信息，分类整理。制定政府信息公开责任清单，明确公开时限、责任科室，进一步细化工作任务，压实工作责任。完善信息发布审核制度，严格执行信息公开发布审核、保密审查制度，规范信息发布工作流程。开展现行有效行政规范性文件集中发布工作，公开现行有效行政规范性文件17件。

（四）加强栏目建设

进一步加强网站建设，优化栏目设置，对政府信息公开板块进行规范化调整。同时，定期对局网站政府信息公开栏目开展自查，及时整改测评发现问题。定期对局网站进行系统检测维护，及时排除故障隐患，保障网站稳定运行。

（五）健全保障机制

健全工作机构，落实专人进行资料收集、整理和发布工作，严格按照工作任务实施，高质量完成各项信息公开工作任务。健全督查机制，定期对政府信息公开工作开展监督检查，进一步增强对政府信息公开工作的监督，确保信息公开高效、规范。

五、存在的主要问题及改进情况

2023年，我局信息公开工作取得了一定成效，但工作中还存在一些不足，一是业务水平还有待提升；二是重点领域信息公开力度还有待加强；三是政策解读质量还有待提高。

下一步，我局将组织工作人员继续深入学习《政府信息公开条例》，进一步提高思想认识，加强业务知识学习，准确把握信息公开工作政策。积极参加信息公开各类培训，学习先进单位典型经验和创新做法，做好信息公开工作。继续抓好重点领域信息公开，围绕我局职能，加大重点领域信息公开力度。严格落实政策解读工作要求，运用图表图解、视频等多元化形式解读政策，切实增强解读效果，进一步提高我局信息公开水平。
