莆田市人民政府安委会关于2012年上半年全市安全生产目标责任制督查情况的通报

发布时间：2012-07-16 08:00
| | |

 

莆市安〔2012〕7号

 

各县（区）人民政府（管委会），市直有关单位：

根据莆田市人民政府《关于下达2012年安全生产目标管理责任的通知》（莆政综〔2012〕48号文件）和市政府安委会《关于开展2012年上半年安全生产责任制督查工作的通知》（莆安委明传〔2012〕1号）文件精神，2012年6月25日至7月2日，市政府安委会抽调有关部门领导和人员组成六个督查组，采取听取汇报、查阅资料、现场检查等形式，对各县（区）人民政府（管委会）和市直有关单位上半年安全生产目标责任制落实情况进行督查。现将督查情况通报如下：

一、2012年上半年全市安全生产工作情况

从督查情况看，2012年上半年，我市各级各有关部门在市委、市政府的正确领导下，在省政府安委会的具体指导下，以继续开展“安全生产年”和“责任落实年”为契机，以强化安全生产“一岗双责”和落实企业主体责任为抓手，着力推进企业安全生产标准化建设、“打非治违”专项行动和道路交通安全综合整治等各项活动，狠抓各项安全防范措施落实，取得了较好的成效，全市安全生产形势总体保持平稳态势。

（一）安全生产目标控制情况

1-6月份，全市共发生五大类生产安全事故581起，同比下降26.0%；死亡53人（占年度37.9%，全年控制目标为140人），同比下降33.8%；受伤556人，同比下降21.4%；直接经济损失421.08万元，同比下降27.6%。发生较大事故1起（占年度25.0%，全年控制目标为4起）、死亡3人，同比分别减少2起、6人。

1.行业（领域）安全生产情况

工矿商贸方面共发生生产安全事故3起，同比增加1起，上升50.0%；死亡4人，同比增加2人，上升100.0%。道路交通方面共发生生产安全事故438起，同比减少98起，下降18.3%；死亡48人，同比减少20人，下降29.4%。发生较大事故1起、死亡3人，去年同期未发生较大事故。火灾方面共发生生产安全事故135起，同比减少106起，下降44.0%；死亡1人，同比减少9人，下降90.0%。农业机械方面共发生生产安全事故5起，同比减少1起，下降16.7%；未造成人员死亡，同比持平。渔业船舶方面未发生生产安全事故，事故起数、死亡人数同比分别持平。水上交通方面（单列统计）共发生生产安全事故1起，同比减少1起，下降100%；未造成人员死亡（失踪），同比持平。

2.县（区、管委会）情况

仙游县共发生生产安全事故311起，同比减少79起，下降20.3%；死亡22人，同比减少10人，下降31.3%。发生较大事故1起、死亡3人，去年同期未发生较大事故。荔城区共发生事故70起，同比减少10起，下降12.5%；死亡6人，同比持平。城厢区共发生生产安全事故19起，同比减少16起，下降45.7%；死亡8人，同比持平。涵江区共发生生产安全事故91起，同比减少61起，下降40.1%；死亡8人，同比减少5人，下降38.5%。秀屿区共发生生产安全事故29起，同比减少14起，下降32.6%；死亡6人，同比减少4人，下降40.0%。湄洲岛管委会共发生生产安全事故7起，同比增加1起，上升16.7%；死亡2人，同比增加2人。北岸管委会共发生生产安全事故7起，同比减少9起，下降56.3%；未造成人员死亡，同比减少1人，下降100%。

（二）主要工作情况

从督查情况看，各级各部门和大部分企业都能重视安全生产工作，有效履职，强化监管，取得了较好的成效。主要措施和做法是：

一是强化组织领导，有效落实安全生产目标管理责任。各级各部门对安全生产工作十分重视，把安全生产工作摆在重要位置，将安全生产规划纳入经济社会发展规划中，定期召开安全生产工作会议，听取安全生产工作汇报，分析安全生产形势，部署阶段安全生产工作重点，切实加强领导，狠抓工作落实。各级领导带头落实责任制，层层签订安全生产责任书，确保了安全生产责任的层层落实。仙游、荔城、城厢、涵江、秀屿等县（区）调整了安全生产委员会成员，由县（区）长担任安委会主任，各部门正职为成员；秀屿区细化分解了考核指标和工作目标，建立了区、乡(镇)、村（居）、企业安全生产工作目标管理体系，并严格实行“一票否决”、领导约谈、督查通报、考核考评等制度，督促安全生产责任制落实；市教育局按学生数的万分之零点六比例进行分解，进一步明确了各县（区、管委会）教育部门和学校安全工作职责；市海洋与渔业局把渔船安全管理责任范围延伸到乡镇政府和村委会，形成渔船安全管理乡镇长、村长、船长的“三长”负责制。

二是有序推进，全面提升企业安全管理水平。各级各部门能按照市里的统一部署，成立领导机构，细化工作职责，通过召开现场会、典型引路、检查考评、宣传培训等方式，扎实推进企业安全生产标准化建设和“平安企业”创建活动，促使企业加快建立自我约束、自我完善、持续改进的安全生产管理长效机制，安全管理和事故防范能力有所增强。截至6月底，全市应参与标准化创建企业共有12620家，其中已参评企业11966家，覆盖率达94.8%；已完成自评企业10583家，自评率达83.9%；已完成评定企业7647家（其中二级达标1家），评定率达60.6%；全市已参与“平安企业”创建企业1486家，其中评为“平安企业”1338家，创建率达90.0%。涵江区将原有已授牌259家企业列入2012年“平安企业”创建滚动管理达标单位；荔城区出台了开展企业安标化创建的相关文件，组织对辖区内企业进行调查摸底，加强业务人员培训，精心组织培植典型，正有序、有效推进这项工作，三棵树涂料有限公司安标化建设评定为目前全市唯一一家二级单位，并得到国家、省领导的肯定；莆田电业局结合安标化工作，全面推广标准作业卡应用工作；中石化、中石油已完成安标化创建任务，所有加油站全部实现三级达标。

三是加大力度，全面消除各类安全隐患。各级各部门能建立健全日常巡查机制和隐患排查治理机制，扎实开展安全生产日常监管，深入开展安全生产“打非治违”专项行动，扎实推进道路交通安全综合整治、“清剿火患”行动等重点行业（领域）专项整治，排查整改各类安全隐患，严厉打击各类非法违法生产经营建设行为，有效预防和减少各类安全生产事故的发生。仙游县深入开展道路交通、消防火灾等专项整治，打击非法违法、治理纠正违章违规行为2.1万起，责令停产停业182家，关闭非法违法生产企业14家，行政拘留2人，罚款161.6万元；市质监局对特种设备制造、安装、充装、使用的现场监察率达到13.2%（全年要求15%）；市公安局交警支队先后部署开展春运、酒后驾驶、严重交通违法、涉牌涉证、城市交通秩序、货运车辆严重交通违法整治、校园及周边道路交通秩序整治等12个专项整治行动，查处各类交通违法34.7万起，集中销毁车辆829辆；市住建局重点开展建筑施工、燃气、物业管理、市政道路及附属设施、路灯及相关设施维护等5个专项整治；市水利局在汛期来临之前组织对各县区和直属单位的防汛备汛、安全隐患排查、危险源情况进行检查，并对10多家安全责任落实不到位的单位和个人给予处理；市公安局查处烟花爆竹案件26起，抓获涉案人员26人，收缴烟花爆竹成品8320件；市消防支队通过狠抓政府挂牌督办重大火灾隐患，深入开展“春雷”、“飓风”、 “清剿火患”等消防安全专项活动，全力消除火灾隐患；市农机总站在全市范围内联合开展报废多功能拖拉机专项整治活动，注销报废多功能拖拉机413台。

四是夯实基础，不断加大安全生产投入。各级各部门不断加大对安全生产领域基础设施建设和隐患整改等经费投入，引导和督促企业增加资金投入，改造生产设备，淘汰落后工艺，配套安全防护设施，改善安全生产条件，切实提高安全保障能力。同时，积极推进乡镇（街道）和村（居）安全监管队伍建设等基层基础工作，不断强化基层安全监管能力建设。涵江区建立了村级安全监管体系，积极推行消防、治安、联防为一体的队伍建设；秀屿区配备村（居）专（兼）职安全员196名，每月给予150元补贴，将安全监管网络延伸到村一级；市安监局和市公安局交警支队积极推进324国道和部分省道中间隔离防护栏设置工作；市交通运输局投入资金建成客运、出租、危货的GPS平台，并与交警部门全面实现GPS数据互联互通。

五是强化宣教，营造良好安全生产氛围。各级各部门能把安全生产宣传教育工作放在重要位置，以“安全生产月”、 安全社区创建、 “119消防活动日” 、“安康杯”等各项活动为载体，大力宣传安全生产法律、法规，倡导安全文化，推广安全经验，各县（区）政府（管委会）、各部门的安全监管责任意识、生产经营单位的安全生产主体责任意识普遍得到加强，全社会安全生产意识进一步提高。同时，各级各部门能结合实际，积极组织开展各类安全生产应急演练，锻炼应急队伍，检验应急预案，提升应急救援能力和水平。湄洲岛管委会利用轮渡公司、祖庙景区重点部位电子屏滚动宣传安全生产知识和标语；北岸管委会组织危险化学品、消防等不同行业不同领域的应急演练30多场次；市交通运输局结合“道路客运安全年”，共组织5场针对汛期、自然灾害、道路交通事故、危化品事故为主题的应急演练；莆田海事局共组织海上搜救行动4次，遇险人数28人，成功救助遇险人员28人，解救遇险船舶4艘，水上人命救助成功率达100%。

二、存在的主要问题

从督查情况看，上半年，各级各相关部门能围绕市政府下达的安全生产目标管理责任，做了大量卓有成效的工作，取得了较好的成效。但仍存在许多薄弱环节，安全生产形势依然不容乐观。主要表现在：

一是个别县（区、管委会）、行业（领域）安全生产事故控制指标超过市政府下达序时进度；

二是部分职能部门对安全监管职责不清晰，对一些关键环节的监管工作，存在着互相扯皮、推诿、推卸责任的问题，安全监管工作还存在盲点。部门之间缺乏有效的协调联动工作机制，导致个别领域安全监管力度不足；

三是部分单位虽然层层签订了安全生产责任书，但没有对基层单位责任制落实情况进行跟踪、监督、检查，工作浮在面上，没有落到实处；

四是个别县（区、管委会）、行业主管部门开展企业安全生产标准化建设活动力度不够，离要求尚有较大差距；

五是道路交通、消防、水上交通、建筑施工等重点行业和领域事故隐患仍然存在，非法生产经营的现象较多；

六是部分乡镇（街道）安全监管机构安全专职人员偏少，流动性大，业务能力有待提高，且工作经费欠缺，承接安全生产工作外的事务性工作较多，影响了正常的履职；

七是应急救援体系建设还不健全，部分应急预案长时间没有进行修订完善，应急预案演练未形成常态化。

三、下一步工作意见

当前我市正处在高温酷暑季度和主汛期，认真落实安全生产目标责任，抓好各项安全防范措施落实，有效遏制各类事故发生，显得尤为紧迫和重要。针对督查发现的主要问题，现就抓好下一步安全生产工作提出以下意见：

一要认真落实安全生产“一岗双责”规定。要继续抓好本地区、本部门安全生产“一岗双责”规定的落实，将责任细化到具体岗位、具体人员上，落实到企业和学校等层面，主动覆盖监管的盲区和死角，切实抓好监管责任的落实。

二要强化企业安全生产主体责任。要继续组织企业学习、宣传、贯彻国务院《通知》、省政府《意见》和市政府《实施意见》精神，持续推进企业主体责任落实。认真贯彻落实上级有关开展企业安标化工作的精神和要求，扎实推进企业安标化工作，确保实现今年企业安标化创建任务，不断提升企业安全生产管理水平。

三要全力开展“打非治违”专项行动。要继续按照职责分工和工作要求，集中力量，督促、指导本地区、本行业全面开展“打非治违”专项行动，依法严厉打击非法违法生产经营建设行为，认真抓好各类隐患整改落实工作，努力消除各类安全隐患，特别对已取缔关闭的场所，要采取措施加强巡查和严密监控，严防死灰复燃，确保真正打击、取缔到位。

四要进一步强化安全保障能力。要继续从资金、政策等方面加大各方安全生产投入，增强安全生产保障能力。要重视基层安全机构建设，落实乡镇（街道）一级安全监管机构的人员、经费和设施设备，并向村（居）一级延伸监管网络。加强乡镇安监站人员业务培训，规范文书使用，不断提高安监人员业务素质，并在经费投入和监管设施等方面提供保障，以适应日益繁重的安全监管任务的需要。

五要进一步强化安全宣传教育。要制定有针对性的宣传工作方案，多形式、多渠道、全方位地宣传安全生产的方针政策、法律法规，普及安全生产科普知识和自我防护常识，不断提高全民安全意识和素质。进一步落实安全生产举报制度，继续发动群众通过举报电话和举报信件等途径举报各类安全生产事故隐患信息，营造全社会关注、了解、参与安全生产工作的氛围。

有关县（区、管委会）和市直有关单位要抓好本次督查发现问题和安全隐患（见附件）的整改落实工作，并将整改落实情况于8月22日前报送市政府安办。联系人：陈文兴，办公电话：2330086，传真：2339655，邮箱地址：fjptajj@163.net。
