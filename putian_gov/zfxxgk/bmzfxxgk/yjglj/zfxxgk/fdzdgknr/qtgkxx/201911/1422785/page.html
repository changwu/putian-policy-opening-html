关于印发《莆田市安监局2017年度绩效管理工作方案》的通知

发布时间：2017-06-29 20:06
| | |

 

 

 

莆市安监〔2017〕84号

 

局各科室、直属事业单位：

根据《中共莆田市委办公室 莆田市人民政府办公室关于印发2017年度绩效管理工作方案的通知》（莆委办〔2017〕46号）精神，结合我局工作实际，经研究，现将《莆田市安监局2017年度绩效管理工作方案》印发给你们，请结合工作实际和岗位职责，认真贯彻执行。

 

                       莆田市安全生产监督管理局

                            2017年6月29日

 

 

 

 

 

 

 

 

 

 

 

莆田市安监局2017年度绩效管理工作方案

一、组织领导

根据人员变动，调整了局机关效能建设领导小组成员，组长由蔡国萍局长、范玉水书记担任，副组长由陈金晃、陈德全副局长担任，成员由各科室、直属事业单位负责人组成，下设办公室挂靠局办公室，由薛凤池任办公室主任。

二、考评对象

    局各科室、直属事业单位及全局干部职工。

三、考评内容

考评采取指标考核、公众评议、察访核验相结合的方式进行。重点考评各科室、直属事业单位贯彻落实市委、市政府的决策部署、2017年省政府工作主要任务、省政府“立项挂牌办理”任务、市政府工作主要任务、效能工作要点等情况，以及履职尽责、加强自身建设、推进改革创新等情况。  

    （一）指标考核

2018年1月上旬，局效能办组织开展指标核验（具体考核指标详见附件1），重点考核牵头负责的市委、市政府文件落实情况、履行职责情况、省对市绩效考评指标落实情况、依法行政、高效行政、民主行政、廉洁行政、成效显著、改革创新等12个方面内容。

    （二）公众评议

重点围绕各科室、直属事业单位（科级及以下干部）落实市委、市政府重点工作，维护群众利益、日常表现等情况，由局办公室适时开展。

    （三）正向激励

鼓励各科室、直属事业单位（科级及以下干部）结合实际创造性开展工作，卓有成效完成各项任务。受到上级通报表彰（表扬）以及在争取资金、任务落实、优化环境、增收减支、自查自纠等工作中取得显著成效的科室、直属事业单位（科级及以下干部），在年度绩效考评时给予激励加分。

（四）察访核验

局效能办结合日常工作计划、作风纪律等督查，不定期开展察访核验。察访核验采用明察暗访等方式，重点对各科室、直属事业单位（个人）开展“三比一看”活动、深化“马上就办”、简政放权、扶贫开发等情况，以及党政机关存在的为官不为、作风懈怠等突出问题和干部群众反映集中的重要问题，以及绩效指标完成和数据真实性、准确性等情况开展督查。

四、结果汇总与运用

1．考评结果分为优秀、良好、一般三个等次，其中0＜优秀等次比例≤30%，0＜一般等次比例≤10%，评为优秀等次的处级干部不能超过单位处级干部总数的30%；具体的考评办法另行制定。

2．符合下列情形之一的，直接评为优秀等次：

（1）受到正部级以上单位表彰（表扬）、推广或领导批示肯定。

（2）获省效能办绩效考评激励加分。

3. 出现下列情形之一的，不能评为优秀等次：

（1）年度请事假累计超过22个工作日。

（2）存在旷工问题。

4. 出现下列情形之一的，降低一个考评等次：

（1）受到党政纪责任追究、效能问责（如违纪违法问题不属于该干部在任现职科室期间发生的，则不影响现科室的考评等次确定）；

（2）不依法办事或不作为、乱作为，引发群体性事件，造成恶劣影响或严重后果的；

（3）社会治安综合治理工作出现严重问题，被一票否决的；

（4）生态文明建设工作中出现严重问题，发生重大以上环境污染事件，造成恶劣影响或严重后果的；

（5）发生重大以上安全生产（含食品安全）责任事故，造成恶劣影响或严重后果的。

（6）被上级查实或通报存在作风纪律问题。

（7）旷工超过5个工作日。

（8）在绩效管理工作中弄虚作假。

（三）结果运用

1. 通报考评结果。绩效考评结果在全局进行通报。

2. 挂钩考核评定。绩效考评结果作为单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。

3. 实行绩效奖励

（1）优秀等次、一般等次分别按照良好等次个人绩效奖金的1.2倍、0.5倍发放绩效奖金。

（2）凡受到党政纪责任追究、效能问责的人员，年度考核被评为不称职（不合格）的人员，被省委、省政府、省效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的单位人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假累计超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病事假超期人员标准的5倍减发绩效奖励。

4. 实施效能问责

（1）年度绩效考评结果为一般的干部（科级及以下干部），责成其向局机关效能建设领导小组提交书面整改措施。

（2）省、市效能督查发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫（含）以上处理，对科室负责人进行通报批评，存在突出问题的对局分管领导进行诫勉教育。

5．反馈整改。各科室、直属事业单位（科级及以下干部）要针对绩效考评中发现的问题，认真分析研究，查找薄弱环节，深刻剖析原因，制定整改措施，促进绩效提升。整改情况纳入下一年度绩效考评。

五、实施步骤

（一）制定方案，动员部署（2017年6月20日-6月30日）

    按照《2017年度莆田市绩效管理工作方案》要求，认真研究制定《莆田市安监局2017年度绩效管理工作方案》，明确目标任务和责任分工。组织全局干部职工认真学习绩效管理工作有关会议精神和文件规定，充分认识开展绩效管理工作的重要性和必要性，切实增强做好绩效管理工作的积极性和自觉性，扎实推动工作开展。

（二）组织实施，常态管理（2017年7月1日-12月31日）

    建立绩效目标工作台账，加强日常跟踪督促，推进工作落实到位。各科室、直属事业单位要对照《莆田市安监局绩效考核指标体系》（详见附件1）责任分工，认真设定各自负责落实指标的年度工作目标，注意日常相关资料的收集、分类和存档，并在每个月5日之前向局效能办报送各自负责指标的绩效目标工作台账（附件2）以及提升机关效能、工作绩效方面的文件通知和工作信息。对未按序时进度完成、进度不够明显的工作指标，要注意分析存在的问题及原因，及时采取有效措施加以推进，确保我局各项绩效工作指标保质保量完成。局效能办要及时汇总各科室绩效目标工作台账并公开。

（三）分析汇总，自我评估（2018年1月1日-1月8日）

    各科室、直属事业单位要对照绩效管理工作方案，全面系统地对各自负责落实指标工作进行自我评估和客观分析，认真收集相关迎检资料，并于2018年1月8日前报到局效能办。局效能办要收集、汇总各科室相关迎检材料，进行初步审核把关，形成全面、完善的迎检材料。

（四）迎接检查，完善提升（2018年1月8日-2月28日）

    根据市效能办的安排，认真做好绩效迎检工作。绩效考评检查结束后，根据考核组反馈的情况，各科室、直属事业单位要针对存在的问题和不足，及时进行深入分析，查找问题症结原因，制定整改措施，推动市安全生产工作水平进一步提升。

六、工作要求

（一）统一思想认识。树立正确的绩效价值观，把绩效管理作为行政管理的一项基本制度，增强主体责任意识，建立科学民主决策制、岗位责任制、服务承诺制、办事公开制、首问负责制、一次性告知制、限时办结制、否定报备制、责任追究制、社会评议制等制度，有力促进各项工作任务落到实处。各科室、直属事业单位负责人是本科室绩效管理工作第一责任人，对本科室（直属事业单位）的绩效管理工作负总责。全局上下要继续贯彻“马上就办”的工作作风，共同提升全局工作效能，共同维护全局良好形象，全力争取在全市绩效考评中取得优秀等次。

（二）强化统筹协调。局机关效能建设领导小组及其办公室要充分发挥组织协调作用，统筹协调相关科室，做好各个环节的衔接，提升整体工作合力。局机关效能建设领导小组办公室每季度要检查各科室完成绩效考评各项工作和绩效目标工作台账建设情况，及时发现问题，及时协调解决，确保绩效管理工作顺利开展。

（三）强化结果应用。各科室、直属事业要以严谨细致、务实求效的作风共同做好绩效管理工作，做到资料真实完整，数据准确可靠，台账规范有序。要坚决防止和克服形式主义，坚决制止马虎应付、弄虚作假现象。市效能办对我局考评情况将作为年度评先、评优主要依据之一。
