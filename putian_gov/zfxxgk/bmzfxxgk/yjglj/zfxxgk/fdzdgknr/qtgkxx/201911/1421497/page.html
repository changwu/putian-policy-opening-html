关于2008年上半年安全生产责任制暨百日督查专项行动督查情况的通报

发布时间：2008-08-08 08:00
| | |

 

莆市安〔2008〕19号

 

 

各县（区）人民政府（管委会），市直有关单位：

    根据《市政府安委会关于开展2008年上半年安全生产责任制暨百日督查专项行动督查工作的通知》（莆安委明传[2008]2号）精神，2008年7月14日—16日，市政府安委会组织6个督查组，由安委会部分成员单位领导带队，采取听取汇报、查阅资料、现场检查和核对控制指标等方法，对7个县（区、管委会）上半年安全生产责任制暨百日督查专项行动等工作落实情况进行了综合督查。市直相关单位也按要求开展了自查工作。现将有关情况通报如下：

    一、上半年全市安全生产基本情况

今年以来，我市各级各有关部门认真贯彻全国、全省和全市安全生产工作会议精神，紧紧围绕安全生产“隐患治理年”和“基层基础建设年”工作部署，建立健全安全生产责任体系，深入开展安全生产隐患排查治理和百日督查专项行动，加强宣传，落实责任，强化监管，不断夯实安全生产基层基础工作，全市安全生产保持了平稳的态势，为我市经济社会又好又快发展提供了良好的安全环境。

    （一）上半年安全生产控制目标落实情况

    1—6月，全市共发生各类生产安全事故771起、死亡89人、受伤679人，同比分别下降8.4%、18.3%、23.5%；直接经济损失301.14万元，同比上升38.9%。全市各类生产安全事故死亡89人，占省政府下达年度安全生产控制目标的48.4%；发生较大事故3起, 占省政府下达年度安全生产控制目标的75%。

    1、从重点行业或领域的情况看：1—6月，全市五个重点行业、领域中，道路交通、消防火灾、农业机械、渔业船舶类事故死亡人数同比均下降，并控制在序时控制目标进度内；工矿商贸事故死亡人数同比上升，超序时控制目标进度。

    工矿商贸事故死亡8人，同比增加4人，占年度控制目标80%；

    道路交通事故死亡79人，同比减少20人，下降20.2%，占年度控制目标47.9%；

    消防火灾死亡1人，同比减少2人，下降66.7%，占年度控制目标25%；

    农业机械死亡1人，同比减少2人，下降66.7%，占年度控制目标33.3%；

    渔业船舶没有发生事故，同比持平。

    2、从县（区、管委会）的情况看：仙游县各类事故死亡40人，同比减少4人，下降9.1%，占年度控制目标57.1%；荔城区五类事故死亡13人，同比减少1人，下降7.1%，占年度控制目标61.9%；城厢区各类事故死亡14人，同比持平，占年度控制目标56.0%；涵江区各类事故死亡15人，同比持平，占年度控制目标45.5%；秀屿区各类事故死亡10人，同比减少6人，下降37.5%，占年度控制目标47.6%；湄洲岛管委会各类事故死亡4人，同比增加3人，超过年度控制目标2人；北岸管委会各类事故死亡2人，占年度控制目标40.0%。

    （二）上半年安全生产各项工作落实情况

    从督查情况看，上半年我市各级各有关部门都能按照市委、市政府的部署和要求，认真抓好安全生产各项措施的落实，做了大量工作，取得了较好的成效。

    一是加强领导，严格落实安全责任。各级、各相关部门按照《莆田市人民政府关于下达2008年安全生产目标管理责任的通知》（莆政综[2008]25号）要求，由各级政府、部门主要领导与下级政府和相关部门层层签订责任书，将责任分解落实到具体单位、岗位和相关人员。并通过日常检查、指标通报、超标约谈、半年度督查等方法，促进安全生产责任制的有效落实。

    二是精心组织，扎实开展安全生产百日督查专项行动。自百日督查专项行动开展以来，各级各有关部门高度重视，按照省市的部署和要求，集中力量，全力以赴，大力推进百日督查专项行动，取得了较好的成效。4-6月份，全市各级政府组织509个督查组（市级12个、县区级18个、乡镇479个），出动人员2510人，督查单位6341个，发现问题及隐患8518条，已整改7171条。市直部门组织了67个督查组，出动人员351人，督查单位689个，发现问题及隐患466个，已整改421个。（1）领导重视，建立机构。各县区、市直各有关部门按照省、市政府的部署和要求，成立工作机构，明确责任。主要领导和分管领导都十分重视，或作出批示，或带队深入一线开展督查工作，如仙游县、涵江区、秀屿区的党政主要领导都对开展安全生产百日督查专项行动作出批示；仙游县、荔城区、秀屿区、城厢区政府主要领导亲自带队检查基层百日督查专项行动开展情况。各级领导的重视和率先垂范，有效地调动了全市各方面力量积极参与百日督查工作。（2）制订方案，层层部署。各级各有关部门能够按照《关于开展安全生产百日督查专项行动的通知》(莆政办明电〔2008〕31号)和《关于在重点行业领域开展安全生产百日督查专项行动的意见》(莆市安〔2008〕12号)，制订出台了工作方案，明确了督查目的、形式、内容、方法和职责分工。并层层召开各种形式会议进行动员部署，把工作要求贯彻落实到基层、企业和具体人员上，推动了百日督查工作的广泛、深入开展。 （3）强化督查，狠抓落实。各县区、市直各相关部门按照企业自查与部门抽查相结合、综合督查与专项督查相结合、督查行动与效能检查相结合的方式，全面深入开展百日督查专项行动，并对发现的问题进行通报。（4）突出重点，狠抓整改。各级各相关部门都把历次省、市安全检查、督查发现的隐患等作为重点进行督查，确保全面整改或防范到位。根据《莆田市重大事故隐患政府挂牌督办暂行办法的通知》（莆市安〔2008〕11号），对本辖区、本行业的重大隐患进行梳理，选择部分影响性较大的重大隐患进行挂牌督办，及时落实资金、责任人、整改期限、事故防范和应急救援措施，确保按期整改到位。目前，全市已挂牌督办重大隐患单位84家，已完成整改销案41家。其中县（区、管委会）政府挂牌的48家，已整改销案14家；市直部门挂牌的30家，已整改销案21家。（5）广泛宣传，形成氛围。各级各部门按照《关于做好安全生产百日督查专项行动宣传和信息工作的通知》（莆市安办〔2008〕13号）要求，及时召开各种会议进行动员、部署，并结合“安全生产月”，通过报纸、电视、广播等新闻媒体进行广泛宣传，把百日督查专项行动的精神和安全生产有关法律法规宣传到各行各业和广大农村中去。各县（区、管委会）都组织了“千百家企业保奥运安全承诺签名”活动。秀屿区党政主要领导亲自布置专项行动宣传工作，并由区政府领导带队在“五一”节前开展全面督查，向基层企业宣传百日督查专项行动。仙游县围绕安全生产百日督查专项行动，组织道路交通、消防安全宣传车深入镇、村巡回宣传。通过采取多种形式做好宣传工作，形成了浓厚的安全生产氛围。

    三是加大力度，夯实基层基础工作。今年是我省的安全生产“基层基础建设年”。我市各级各部门按照省里的部署，积极推进安全基层基础工作，取得了初步的成效。（1）强化安全基础设施建设。仙游县多方筹资3000多万元，全面启动区域内24座危桥改造，筹资近100万元用于完善交通标线、减速带、警示灯、视频监控等设施。秀屿区在预算外增拨了安全生产专项经费10万元，用于保障安全生产隐患排查治理、基层基础建设等工作经费；筹措资金350万元，购买5艘钢质渡船，用于更新埭头、南日等乡镇的老旧渡船；投入150多万元，用于治理道路交通路面安全隐患，增设临时红绿灯、闪烁灯及电子监控系统；增设了城市消防栓15个；多方筹集资金，购置了大吨位消防车4部；筹集50万元资金用于南日镇197个消防栓建设，在全省首家实现村村建设市政消防栓的乡镇。农机部门投入28万元引进两条拖拉机安全检测线，建立流动和固定两个检验线示范县区，并投入10万多元加强培训机构硬件建设，在全省率先实现拖拉机训练、考试场地水泥化。海洋渔业部门投入400多万元，建成了全市海上渔业安全应急指挥系统，对全市4178艘捕捞渔船和17个渔港、渔排进行实时监控。（2）强化基层安监机构建设。建立健全基层安监机构，目前我市54个乡镇（街道）都建立了安监机构，配备了安监人员；全面启动乡镇安全生产委托执法，目前全市共有36个乡镇实现了安全生产委托执法，有效地提升了基层安全监管水平；抓好制度建设，各级安监部门基本建立了会议制度、通报制度、督查制度、隐患排查治理制度、事故报告制度等，促进了安全管理规范化、制度化。（3）强化应急救援体系建设。各级各有关部门和高危行业的企业都编制了安全生产应急救援预案，建立了专业和非专业应急救援队伍，并在安全生产月期间积极开展了火灾、矿山救援、氯气泄露等应急演练活动。

    四是广泛宣传教育，努力营造安全工作氛围。各级各部门坚持把宣传教育摆到安全文化建设的高度，采取多种形式和途径，加强宣传教育，努力营造浓厚安全文化氛围。各县（区、管委会）和市直有关单位都组织开展了“安全生产月”活动，通过大型安全生产宣传咨询、安全生产图片展、安全生产知识竞赛、发送安全生产短信和送安全知识进企业、进社区、进学校等几十项宣传活动，大大增强了职工、群众的参与积极性，增强了全社会的安全意识。加强对特种作业人员和有关企业负责人、管理人员的培训考核，提升他们的安全管理水平。

    二、存在的主要问题

从督查的情况看，上半年，我市安全生产形势虽然总体保持稳定，但仍然存在不少问题和薄弱环节，主要表现在：

    一是安全生产责任制落实不够到位。部分县区、部门年初下达责任目标后，没有定期通报安全生产形势，没有组织半年度责任制督查，没有采取行之有效的措施督促责任制落实。督促行政“一把手”责任落实不到位，部分行政“一把手”安全生产工作履职报告没有受文单位、没有本人签字，安全生产形势通报没有及时抄送“一把手”，督促第一责任人责任的措施不到位。

    二是部分县（区、管委会）和行业（领域）事故死亡人数超控制目标。上半年，仙游县、城厢区、荔城区、湄洲岛各类生产安全事故死亡人数超序时控制目标；工矿商贸生产安全事故死亡人数超序时控制目标。

    三是安全生产基层基础还比较薄弱。部分乡镇对安全生产重视不够，安监机构人员配备不足，有的没有配备专职的安监人员，有的乡镇还不具备安全生产委托执法条件，安监站（所）工作条件差，缺乏必要的办公、执法装备。一些企业安全生产主体责任落实不到位，有的没有建立安全管理机构，没有配备专职的安全员，安全投入不够，隐患排查治理不到位，特别是对一些发现的隐患，没有采取措施加以整改或防范。

    四是隐患排查治理不够到位。个别地方政府、部门对安全生产工作重视不够，仅仅停留在会议和文件上，没有经常深入基层和生产一线检查督促工作，隐患排查不认真、不细致，对企业上报和本单位检查发现的安全隐患没有及时组织整改，对省市检查督查发现的问题和安全隐患跟踪落实不够，没有按照规定的时间整改到位，也没有及时反馈整改落实情况。“三合一”场所整改不够到位、回潮现象严重，打击整治还不够有力。危化品道路运输和乡镇渡口渡船、农村道路交通安全管理存在薄弱环节。

    五是全社会安全意识有待加强。安全教育还不够经常、普及，公民的安全意识还比较淡薄，违章、违规现象时有发生，非法生产、非法经营、非法建设和非法载客仍然比较突出。一些企业对职工安全教育和培训不到位，职工的安全意识不强，安全知识缺乏，安全防范意识和自我保护能力仍然较低，工伤事故多发，特别是农民工、外来工和流动人员的问题更为突出。

    三、下一步工作意见

    针对督查中发现的问题，下一步，必须重点抓好以下几项工作：

    一要完善制度，落实责任，严格目标管控。各级各有关部门要进一步完善安全生产责任考核、奖惩制度，继续强化安全生产责任制的落实，强化各级各部门行政正职的安全生产第一责任人的责任。要认真分析本地区、本单位安全生产形势，尤其是上半年安全生产控制目标超标的县（区、管委会）和部分重点行业（领域）要认真分析原因，查找薄弱环节和存在的问题，研究提出切实可行的对策措施，督促相关责任单位和企业落实好安全生产责任制，确保全年各项指标控制在市政府下达的控制目标范围内。

    二要加强组织领导，扎实开展百日督查“回头看”活动。根据市委、市政府领导的批示精神，我市决定从2008年8月1日至9月30日在全市范围内开展百日督查专项行动“回头看”活动。各级各部门要认真分析前一阶段百日督查取得的成效和存在的问题，对百日督查专项行动进行再动员、再部署、再检查、再落实，加强指挥调度，采取有效措施，扎实推进工作，确保督查工作达到“三个”100%，确保百日督查专项行动取得实效，确保奥运期间安全生产。

    三要强化隐患整改，严格落实重大隐患政府挂牌督办制度。各级各部门、各单位要组织相关人员加大对本单位安全生产工作的排查力度，对发现的隐患和问题要进行整改，特别是对历次省、市两级综合督查中发现的问题和安全隐患要采取切实可行的措施，按时整改到位。对重大事故隐患，要按照有关规定，实行政府和部门挂牌督办制度，加大整改力度，确保整改到位。

    四要采取措施，进一步抓好重点领域和薄弱环节。（1）加强道路交通安全监管。要进一步完善预防道路交通事故工作机制，要以治理车辆超速、长途客车超员、货车超载、摩托车非法载客、疲劳驾驶和无证驾驶为重点，整顿运输秩序；要采取有效措施，切实加强挂靠经营的安全生产工作，坚决取缔松散型的挂靠经营；要认真抓好省政府办公厅关于强化道路交通安全综合监管的12条意见和加强农村道路安全监管的8条措施的落实。（2）加强渡船渡口安全监管。相关县（区、管委会）、海事、交通等部门要采取措施，解决岛上群众出行的问题，在新的渡船尚未交付使用之前，做到既保证渡船渡口安全，又为群众出行提供方便。（3）加强危货运输的安全监管。我市危化品使用企业比较多，大部分为小企业，通过非危货运输车运输危化品的现象较为突出，一旦发生事故，将产生严重后果。要采取有力措施，规范危货运输，确保危货运输安全。

    五要加大力度，夯实安全生产基层基础。各级各部门要认真落实“基层基础建设年”各项工作，重视基层基础建设，加大安全投入，建立和完善各项制度和工作机制，改善安全基础设施。要继续强化安全专项整治，突出抓好重点行业领域的安全监管，特别是要加强道路交通、渡船渡口和危货运输的安全监管，采取有力措施，整顿和规范运输秩序，消除安全隐患。要督促企业落实安全生产主体责任，落实各项安全保障制度和措施，落实安全生产投入，落实安全管理机构和管理人员，提升企业安全生产水平。

    对今年以来省、市督查组督查发现的问题和隐患，相关县区、市直相关部门要认真整改，并及时反馈情况。有关整改落实情况请于8月31前书面报送市政府安办，联系人：薛凤池，电话：2330086，传真：2339655，邮箱地址：fjptajj@163.net。
