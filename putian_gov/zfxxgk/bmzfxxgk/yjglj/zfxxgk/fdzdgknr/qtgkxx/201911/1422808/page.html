关于开展治理商业贿赂专项工作的意见

发布时间：2006-05-10 08:00
| | |

 

莆市安监[2006]39号

 

 

 

 

局属各科室、监察大队：
    为认真贯彻落实中共中央办公厅、国务院办公厅《关于开展治理商业贿赂专项工作的意见》(以下简称《意见》)，进一步规范安全生产监管活动，推动反腐倡廉工作，根据《中共莆田市委办公室莆田市人民政府办公室印发关于开展治理商业贿赂专项工作实施方案的通知》(莆委办〔2006〕41号)的要求，结合我局实际，现就开展治理商业贿赂专项工作提出如下实施意见：

    一、认真学习领会《意见》精神，增强治理商业贿赂的政治责任感和工作紧迫感
    治理商业贿赂是维护广大人民群众切身利益、构建和谐社会的重要措施，是推进党风廉政建设和反腐败工作的重要内容。商业贿赂虽然发生在经营者的交易活动中，但也与政府机关及其工作人员滥用职权、以权谋私有关。商业贿赂不仅是消极腐败行为和经济犯罪滋生的一大源头，是经济社会的一大公害，而且直接毒害了我们的干部，影响党风、政风和行风。市委、市政府提出治理商业贿赂行为十分必要、十分及时，完全符合我局安全监管的实际。为此，我局要按照市委、市政府的统一部署，认真组织全体干部职工认真学习上级有关治理商业贿赂专项工作有关精神，落实中央第六次全会和国务院及省政府、省纪委廉政工作会议精神结合起来，在学习中结合本单位的实际，查找和分析产生商业贿赂的症结与原因。通过学习，充分认识治理和预防商业贿赂的重大意义，把思想统一到中央对治理商业贿赂的工作部署和要求上来。进一步增强治理商业贿赂的政治责任感和工作紧迫感，严格落实党风廉政建设责任制，加强对安全监管各项行政权力的监督制约，迅速推进治理商业贿赂专项工作深入开展。
    二、开展治理商业贿赂专项工作的总体要求和基本原则
    （一）总体要求是：以邓小平理论和“三个代表”重要思想为指导，依照《建立健全教育、制度、监督并重的惩治和预防腐败体系实施纲要》和市委贯彻落实《实施纲要》的具体意见和有关法律法规，统一部署，分类指导，突出重点，综合治理，强化监督，扎实有序地开展治理工作。通过专项治理，使全局干部职工普遍受到教育，错误观念得到纠正，行政权力得到规范，规章制度得到完善，有效预防和制止商业贿赂行为，努力构建行为规范、程序合法、监管到位、廉洁高效、制度健全的安全监管新格局，确保安全监管事业健康发展、安监人员健康成长。

    （二）基本原则是:1、坚持标本兼治，综合治理。既要立足当前，又要着眼长远，运用教育、经济、法律、行政等多种手段进行综合治理。一是与整顿规范监管秩序相结合；二是与机关效能监察工作相结合；三是与党风廉政建设和反腐败工作相结合；四是与推进建立长效机制相结合。2、紧密结合实际，突出重点。按照《意见》的要求，结合实际，有针对性地采取措施进行预防和治理。重点治理以下一些行为：在安全生产许可证、安全资格证等证照发放中搞权钱交易，滥用职权发证的行为；在安全生产过程中为非法行为充当“保护伞”或暗中支持庇护非法行为；在监管活动中违反职业道德和行政法规，影响公平竞争的不正当交易行为；利用职权参与或干预企事业单位和安全中介机构经营活动，谋取非法利益甚至索贿受贿的问题以及其他利益的商业贿赂行为等。通过治理和整改，逐步建立健全规章制度，不断铲除商业贿赂滋生蔓延的土壤和条件。3、坚持把握政策，维护大局。要从发展大局出发，坚持政治、经济和社会效果的统一，既要区分正常的公务活动、经济活动、商业交往与不正当交易行为的政策界限，又要区分违纪违规行为与违法犯罪的界限；既要治理商业贿赂，又要保持正常监管和生产经营秩序，促进经济发展。同时，要注意区分社会存在着的普遍现象与单位实际存在着的特殊问题的界限，区分由集体决策、内部规定规范的行为与个人行为的界限，积极稳妥地推进治理商业贿赂工作。
    三、开展治理商业贿赂专项工作的基本步骤
    分三个阶段开展专项治理工作：
    第一阶段：动员部署阶段(时间为4月下旬)
    工作重点：组织学习《意见》、《中共莆田市委办公室莆田市人民政府办公室印发关于开展治理商业贿赂专项工作实施方案的通知》，领会其精神实质，明确开展专项治理的总体要求、基本原则、治理重点和具体安排，制定工作方案。

    工作目标：统一思想，提高认识，明确责任，增强工作紧迫感。
    第二阶段：自查自纠阶段(时间为5月1日—8月31日)
    工作重点：1.进行自查（时间为5月1日-31日）。分析各科室、监察大队是否存在涉嫌商业贿赂问题；商业贿赂问题的表现形式及特点；是否存在产生商业贿赂问题在制度、体制上的隐患。2.单位自查和进行自纠（时间为6月—7月）。各科室、监察大队要采取切实可行的措施，认真开展自查。对查找出的一般性问题要限期进行纠正。对发现的违纪违法问题要及时报告并根据错误事实、情节轻重、影响大小和认识态度等，予以区分处理。对情节轻微的，以批评教育和自我纠正为主；对虽有问题，但能主动说清并认识错误的，依据有关规定从轻、减轻或免予处分；对普遍存在的问题，要注意从源头抓起，进行综合治理。3、重点检查（时间为8月1日—31日）。重点查处在安全监管中有无存在权钱交易的行为。具体是：在发放危化品安全生产许可证、矿山安全生产许可证、安全资格证等证照发放中有无搞权钱交易、滥用职权发证的问题；在安全生产监管理过程中有无为非法行为充当“保护伞”或暗中支持庇护非法行为；在监督检查管理中有无违反职业道德和安全生产法律、法规，谋取非法利益甚至索贿受贿的问题以及其他利益的商业贿赂行为等。
    工作目标：查清商业贿赂在本单位的表现形式，对存在的问题进行纠正，掌握可能产生问题的主要环节。
    各科室、监察大队要针对自查出的问题，认真分析安全监管中的薄弱环节和制度上的漏洞，研究提出整改措施。要求在8月30日前将有关自查自纠情况、整改措施等方面以书面形式上报局专项治理办公室。
    第三阶段：整改提高阶段(时间为9月—10月)
    工作目标：要求各科室、监察大队于10月30日前完成整改任务，进一步建立健全防治商业贿赂的相关制度，促进全体干部职工切实履行职责，加大监管力度。
    治理商业贿赂是一项复杂而艰巨的任务，既要集中时间开展专项治理，又要从长远出发常抓不懈。一要加强廉洁从政教育，对局全体干部职工要加强法律法规、纪律和职业道德教育，积极运用典型案例开展警示教育；二要强化内部管理，特别是对审批发证和财务等重点人员要强化管理，对审批发证、采购等重点工作要加强监管；三要建立健全规章制度，特别要完善财务会计制度，加强票据管理，减少现金交易；四要通过深化体制改革，从源头上防治商业贿赂。

    第五阶段：汇总报告（时间为11月）。11月中旬，将本单位自查情况、整改措施和整改成果书面报告市治理商业贿赂领导小组。

    四、切实加强对治理商业贿赂专项工作的组织领导
    为切实加强对治理商业贿赂专项工作的领导，局里成立了治理商业贿赂领导小组，由张志宏局长任组长，张宇副调研员、张元璋副局长任副组长，唐新裕、陈彩萍、佘国华、谢建英为成员。领导小组下设办公室，具体负责这项工作。

 

 

二OO六年五月十日
