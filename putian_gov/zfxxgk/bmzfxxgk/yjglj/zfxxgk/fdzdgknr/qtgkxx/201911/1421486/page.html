关于表彰2006年度全市安全生产工作先进个人的决定

发布时间：2007-02-25 08:00
| | |

 

莆政〔2007〕13号

 

各县（区）人民政府（管委会），市直有关单位：

    近年来，全市各级、各部门、各单位认真贯彻安全生产法律法规，围绕建立安全生产长效机制，强化责任，严格监管，扎实有效地开展工作，为促进全市经济发展和保持社会稳定做出了积极的贡献，并涌现出一批先进个人。为表彰先进，弘扬正气，决定授予谢云和等32人“2006年度安全生产工作先进个人”称号。

    希望受表彰的个人戒骄戒躁，再接再厉，为提升安全工作水平再立新功。同时也希望全市安全生产工作人员以先进个人为榜样，努力工作，勇于创新，为促进全市安全生产状况稳定好转做出新的更大的贡献。

    附件： 2006年度安全生产先进个人名单
