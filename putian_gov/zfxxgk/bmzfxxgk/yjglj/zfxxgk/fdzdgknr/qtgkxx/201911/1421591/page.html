莆田市人民政府安全生产委员会关于印发《安全生产百日攻坚促提升行动方案》的通知

发布时间：2018-11-22 11:44
| | |

 

 

 

 

 

 

莆市安〔2018〕14号

 

各县（区）人民政府（管委会），市政府安委会有关成员单位：

经市委、市政府研究，现将《安全生产百日攻坚促提升行动方案》印发给你们，请结合实际认真贯彻执行。

 

 

莆田市人民政府安全生产委员会

2018年11月16日     

（此件主动公开）

 

安全生产百日攻坚促提升行动方案

 

为进一步巩固安全生产“严排查、严整治、严监管”活动成效，推动“严整治、促提升”专项行动增效，全力推进安全生产整治攻坚，坚决遏制各类生产安全事故发生，根据《福建省人民政府安委会办公室关于深入学习贯彻落实全国安全生产工作视频会议精神切实做好岁末年初安全生产工作的通知》（闽安委办明电〔2018〕26号）文件精神，按照市委、市政府部署要求，决定在全市范围内组织开展安全生产百日攻坚促提升行动，现制定如下方案。

一、目标任务 

全面贯彻落实市委、市政府关于开展安全生产百日攻坚活动部署要求，以有效防范和坚决遏制各类生产安全事故为重点，强化特殊时期安全生产管控措施，着力解决影响当前安全生产突出问题和薄弱环节，提升安全生产工作水平，确保完成省政府下达2018年度安全生产控制目标任务，进一步促进全市安全生产形势稳定好转。

二、组织领导 

由市安委会负责安全生产百日攻坚促提升行动的组织实施，市安委会办公室负责日常具体工作。

三、时间安排

即日起至2019年2月底

四、重点工作 

（一）宣贯落实党政领导干部安全生产责任制。认真学习贯彻落实《地方党政领导干部安全生产责任制规定》《福建省党政领导干部安全生产责任制实施细则》，通过举办学习研讨、辅导讲座、专题讲座等多种形式，组织党政领导干部进行系统学习，切实增强政治意识、大局意识、核心意识、看齐意识，强化抓好《规定》《实施细则》贯彻落实的政治自觉和责任自觉。

牵头责任部门：各县（区）人民政府（管委会），市安委会成员单位。

（二）建立健全新业态安全监管工作机制。按照市政府第一季度防范重特大生产安全事故工作会议纪要，坚持“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”原则，由市直相关部门牵头组织研究，制定细化我市新能源、无人飞行器、早教机构、海上垂钓、大型商业综合体等新业态安全生产监管工作机制。

牵头责任部门：市经信委、市公安局、市教育局、市海洋与渔业局、市公安消防支队。

（三）持续深化重点行业领域专项整治。继续深入开展安全生产“严整治、促提升”专项行动，突出交通运输、电力、石油天然气长输管线、特种设备、民爆物品、道路交通、消防、农业机械、水利、渔业船舶、旅游、学校、文化娱乐场所、建筑施工、城镇燃气、海上交通、商贸市场、宗教活动场所、非煤矿山、危险化学品、烟花爆竹、涉氨制冷、涉爆粉尘、有限空间、醇基燃料等25个重点行业领域场所安全生产专项整治。

牵头责任部门：市交通运输局、市经信委、市质监局、市公安局、市公安局交警支队、市公安消防支队、市农业局、市水利局、市海洋与渔业局、市旅发委、市教育局、市文广局、市住建局、莆田海事局、市商务局、市民宗局、市安监局。

（四）持续加大安全生产监管执法力度。深入开展安全生产执法专项行动，突出重点领域重点单位、重点领域重点单位、重点部位重点环节，强化部门执法、联合执法、精准执法，实现对重点企业检查执法率达100%、对发现的安全生产违法行为依法查处率达100％、对检查发现存在安全生产问题企业的复查率达100％、对举报各类安全生产违法行为的核实查处率达100％，切实做到百日攻坚促提升期间行政处罚案件同比有较大的提升。

牵头责任部门：各县（区）人民政府（管委会），市安委会成员单位。

（五）强化重点时段安全生产管控保障。切实加强重大活动、元旦春节等重点时段安全生产管控保障，盯紧盯牢事故多发易发的地区、场所和行业领域，切实细化风险防范和隐患治理措施，摸排查清安全风险隐患点，集中力量进行整改，并强化重点时段安全巡查管控力度，落实专业人员及技术保障。密切关注灾害性天气、地质灾害预测预报和人流车流监测，加强部门间沟通联系、会商分析，第一时间发布预警信息，指导企业和社会公众做好防范应对。严格执行领导带班和重要岗位24小时值班制度，加强应急准备，确保发生紧急情况及时响应、及时处置，最大限度减少损失影响。

牵头责任部门：各县（区）人民政府（管委会），市安委会成员单位。

（六）认真开展安全生产问题隐患“回头看”。从严落实安全生产问题隐患整改责任，坚决杜绝安全生产领域各类督查检查查出问题隐患“表面整改”“虚假整改”等问题，对2018年以来本地区、本行业领域以及上级各类督查检查查出的隐患和问题整改落实情况进行“回头看”，逐项复查整改情况，并对涉及的企业安全生产情况进行一次全面检查。

牵头责任部门：各县（区）人民政府（管委会），市安委会成员单位。

（七）夯实安全生产基层基础能力。认真贯彻落实上级关于推进安全生产领域改革发展的系列文件及我市实施意见，按时完成2018年度51项安全生产领域改革发展重点任务。树立一批本地区、本行业领域双重预防机制标杆企业、试点企业（各县区不少于6家，管委会及市直各部门不少于2家），探索建立一整套可借鉴、可推广、可套用的企业安全生产风险管控和隐患排查治理双重预防机制。推动“网格化+安全生产”工作，完善安全网格化管理工作体系，打通安全监管最后一公里。

牵头责任部门：各县（区）人民政府（管委会），市安委会成员单位、市网格办。

（八）大力营造安全生产浓厚氛围。深入开展进企业、进学校、进机关、进社区、进农村、进家庭、进公共场所宣传活动，全面加强安全生产知识宣传教育和普及，切实增强社会公众安全法制观念和意识。建立并落实安全生产举报奖励机制，拓宽举报渠道，充分发挥群众监督作用。加强新闻媒体监督，定期曝光安全生产违法违规典型企业名单，县（区、管委会）每月曝光不少于1批次安全生产违法违规典型企业名单，市直部门行动期间曝光不少于2批次，形成有力震慑。

牵头责任部门：各县（区）人民政府（管委会），市安委会成员单位。

五、工作要求 

（一）加强组织领导。各县（区）人民政府（管委会）、市安委会成员单位要高度重视，切实加强安全生产百日攻坚促提升行动的组织领导，做到主要负责人亲自抓，分管负责人具体抓，多级联动，层层抓紧、抓实、抓好。要召开专题会议分析研判当前安全生产形势，制定切实可行的工作措施，全力确保完成各项任务。

（二）强化督导检查。各级党委、政府要把安全生产百日攻坚促提升行动纳入督查督办重要内容，强力推进本地区安全生产工作。市安委会将对行动开展情况进行督查，并在年终考核时一并进行考核。市安委会成员单位要加强监督检查，采取“四不两直”、暗查暗访、“双随机”等方式深入基层和生产一线进行督导检查，掌握本行业领域行动开展真实情况，及时发现问题，及时解决问题，确保活动取得实效。

（三）广泛宣传发动。各县（区）人民政府（管委会）、市安委会成员单位要充分利用电视、报纸等各种媒体，加大宣传和舆论监督力度，教育引导企业和广大职工增强做好安全生产百日攻坚促提升行动的主动性和自觉性。积极宣传先进典型，激励引导广大干部在安全生产工作中勤勉尽责、担当作为。

（四）加大问责力度。各县（区）人民政府（管委会）、市安委会成员单位要对本地区、本行业领域安全生产百日攻坚促提升行动工作开展消极应付、任务滞后的单位或个人，视情采取约谈提醒、诫勉谈话、通报批评、组织处理、纪律处分等措施，倒逼相关责任人把责任扛在肩上、抓在手上、放在心上。对行动期间发生的生产安全责任事故，切实从快、从严、从重查处，着力提升事故查处和警示教育力度。

 

 

 

 

 

 

 

 

 

 

 

 

 

抄送：省政府安办，市委办、市府办，各县（区、管委会）安办。
