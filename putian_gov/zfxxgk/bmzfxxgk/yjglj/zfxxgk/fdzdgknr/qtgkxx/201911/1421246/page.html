关于落实《省人大常委会会议对及执法检查报告的审议意见》的通知

发布时间：2012-08-03 08:00
| | |

 

莆市安〔2012〕8号

          

 

各县（区）人民政府（管委会），市直有关单位：

今年3-4月，省人大常委会执法检查组对我省贯彻实施《中华人民共和国安全生产法》和《福建省安全生产条例》（简称“一法一例”）的情况进行了检查。省人大常委会第三十次会议听取了省人大常委会副主任、执法检查组组长徐谦所作的《关于<中华人民共和国安全生产法>及<福建省安全生产条例>实施情况的检查报告》（以下简称《检查报告》），并形成了《关于省人大常委会会议对<中华人民共和国安全生产法>及<福建省安全生产条例>执法检查报告的审议意见》（闽常综〔2012〕1号）。

根据市政府领导重要批示精神，结合省政府安委会《关于落实省人大常委会会议对<中华人民共和国安全生产法>及<福建省安全生产条例>执法检查报告的审议意见的通知》（闽安委〔2012〕15号）文件要求，制定了我市《落实<省人大常委会安全生产“一法一例”执法检查报告及审议意见>主要任务分解方案》（以下简称《落实方案》）。请各县（区）人民政府（管委会）和市直有关单位认真履行安全生产“一岗双责”职责，结合本地区、本部门实际，对《落实方案》逐条进行研究，提出切实可行的贯彻意见和整改措施，并抓好组织落实。整改及组织落实情况请于8月9日前书面报送市政府安办，以便及时汇总上报省政府安办。

联系人：陈文兴，电话及传真：2330086
