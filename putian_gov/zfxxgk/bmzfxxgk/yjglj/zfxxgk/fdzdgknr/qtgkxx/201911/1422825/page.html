中共莆田市安全生产监督管理局支部委员会关于召开2018年上半年组织生活会的通知

发布时间：2018-06-05 17:27
| | |

莆市安监党支〔2018〕7号

 

 

局各科室、直属事业单位：

根据《中共莆田市委组织部关于开好2018年上半年基层党组织组织生活会的通知》（莆委组通〔2018〕21号）文件精神，为确保召开一次高质量的组织生活会，现将有关事项通知如下：

一、组织生活会主题

深入学习习近平新时代中国特色社会主义思想和党的十九大精神，结合“两学一做”学习教育常态化制度化，紧紧围绕市委提出的抓好实体经济、平台经济、城乡建设、改革开放、民生改善、社会治理等重点任务和当前村级组织换届选举等重点工作，员为坚持绿色发展，打造宜居港城，建设美丽莆田，创建美丽中国的示范区作出更大贡献。

二、会前准备工作

（一）认真组织学习研讨（2018年5月28日-6月12日）

结合“三会一课+主题党日活动”，采取领学宣讲、党课辅导、交流讨论等方式，组织党员集中学习习近平新时代中国特色社会主义思想和党章，学习习近平总书记对福建工作的重要指示精神，学习党的十九大、十九届二中、三中全会和省委十届四次、五次全会等中央、省委重大会议精神，学习贯彻市第七次党代会和市委七届四次、五次全会精神，进一步强化“四个意识”，增强“四个自信”，打牢开好组织生活会的思想基础。

（二）广泛听取意见建议（2018年5月28日-6月20日）

坚持发扬民主、开门纳谏，通过个别谈话、集体座谈等多种形式，听取党员在政治思想、组织、作风、纪律等方面，特别是在履职尽责、为民服务等方面存在突出问题的反映。党支部班子要深入征求党员群众意见，党支部书记要带头谈、带头听取意见，征求到的意见，要原汁原味反馈给党员本人。

（三）深入开展谈心谈话活动（2018年6月13日-6月22日）

党支部书记要与支委、支委之间、支委与支部党员至少开展1次谈心谈话，谈心谈话既要交流思想、沟通工作生活情况，也要相互听取意见，指出对方存在的问题和不足，真正把问题谈深谈透。

（四）严肃认真开展批评和自我批评（2018年6月26日）

全体党员要从思想、组织、作风、纪律等查摆问题，开展批评与自我批评。组织生活会上，党支部书记要报告半年来党支部工作情况，检查发现支部建设存在的问题，党支部书记要带头开展批评与自我批评，带动支委和党员积极开展自我批评。批评要本着对同志、对事业高度负责精神，直截了当，用事例说话，严禁隔靴搔痒、大而化之。

三、会议时间及地点

组织生活会于2018年6月26日上午9:00在市政府1号楼248室召开，会期半天，会议由市安监局党支部书记陈德全同志主持。

四、参加人员

全体党员出席会议，邀请市委组织部、市经信系统党委有关负责同志到会指导。

五、会议议程

1.陈德全同志对开好组织生活会提出要求，通报会前征求意见情况、谈心谈话情况和上一次组织生活会查摆问题整改落实情况等组织生活会有关准备工作情况；

2.陈德全同志代表党支部领导班子作对照检查发言；

3.陈德全同志作个人对照检查发言，其他党员逐个开展批评；

4.其他党员分党小组开展批评与自我批评；

5.到会指导的市委组织部、市经信系统党委有关负责同志有关负责同志讲话；

6.陈德全同志总结会议情况，对制定和落实领导班子整改方案、个人整改措施提出要求，并作表态发言。

7.民主评议党员、党员相互评议、群众评议党员。

六、抓好问题整改工作

坚持“问题导向”，针对征求的意见和会上查摆出来的问题，支部班子和每名党员要认真进行研究，按照“先急后缓、统筹兼顾、分步推进”的原则，制定整改任务书、时间表，提出具体的整改措施，并实行台帐式管理，整改到位一个、销号一个。
