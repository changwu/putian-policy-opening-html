莆田市安监局关于印发考勤、值班和请销假制度的通知

发布时间：2017-10-13 19:23
| | |

莆市安监〔2017〕134号

局各科室、直属事业单位：

经局务会议研究，现将《考勤、值班和请销假制度》印发给你们，请根据工作实际，认真贯彻执行。

 

 

                        莆田市安全生产监督管理局

                        2017年10月13日

 

 

考勤、值班和请销假制度

 

为进一步加强机关作风建设，树立“团结、廉政、务实、创新”的机关良好形象，营造优良的工作环境和工作秩序，加快建立办事高效、运转协调、行为规范、管理科学的机关管理体系，确保各项工作任务顺利完成，根据《国家公务员管理条例》和上级有关文件精神，特制定如下制度。

一、考勤制度

（一）严格遵守上、下班制度。上班时要坚守岗位，不得迟到、早退；工作时间不得无故串岗、离岗、上网玩游戏、炒股票，或从事与工作无关的活动。

（二）实行指纹签到、签退制度。因我局办公区域分散，根据实际情况和工作需要，为方便各科室、直属事业单位签到、签退，全体人员均可以在市政府办公区和“莆商中心”办公区签到、签退。上、下班时在考勤机上签到、签退，签到、签退必须在上、下班规定时间15分钟内完成，超过15分钟签到视为迟到，提前15分钟以上签退视为早退，未签到又未事先履行请假或报告手续的视为缺勤（缺勤半个工作日算1次）。如遇特殊情况不能按时上班或中途外出办事的，必须提前向科室负责人或分管领导请假（事后次日前应补办请假手续）。

（三）下乡、开会或参加其他公务活动签到签退问题。下乡、开会或参加其他公务活动未能签到签退，须将下乡审批单、会议通知文件或经分管领导证明的说明材料3个工作日内交给办公室备案。

（四）严格实行考勤督查制度。实行领导督查制度，一般采取上班后30分钟或中途对在岗情况进行抽查。凡未预先请假和报告离岗的，均视为缺勤。

（五）落实考勤统计公布制度。办公室每月第一周负责对上月考勤情况进行统计并汇总通报。

二、请销假制度

（六）严格请休假制度。凡病假、事假、年休假等休假时间均按有关规定严格执行，请假必须填写请假审批单，并逐级审批，送办公室备案。科员因事请假半个工作日的，由科室负责人审批；请假1个工作日的，由所在科室负责人签字，分管领导审批后送办公室备案；请假1个工作日（含）以上，由所在科室负责人和分管领导分别签字，报局主要领导审批。科室负责人请假半个工作日的，由分管领导审批并送办公室备案；请假1个工作日（含）以上的由分管领导签字后报主要领导审批并送办公室备案。各科室应根据工作实际情况，按相关规定有计划地安排好本科室人员的年休（原则上，上半年工作任务相对少，可以多安排，下半年度工作任务重，要少安排休假人员）。参加事故应急抢险或特殊情况加班的，经领导批准予以适当补休（事后也应补办请假审批单，并在3个工作日内送办公室备案）。按照市委办[2017]46号文件规定，年度请病假累计超过2个月或请事假超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员的按病事假超期人员标准的5倍减发绩效奖励。

三、值班制度

（七）实行24小时值班和带班制度。值班和带班实行AB岗，即1个主班和1个副班，平时由主班负责值班值守，遇有突发事件或工作需要，副班和相关人员接到通知后应及时赶到值班室，协助主班处理情况。局领导轮流带班，其他人员轮流值班，值班人员必须24小时在岗在位，保持24小时通讯畅通，确保值守工作正常运转。值班人员遇有急事或重要事情需要离岗，应商请副班替班，副班到位交接后主班方可离开。值班人员次日若无临时性任务，原则上可补休半天，但事后3个工作日内也要办理请假手续并送办公室备案。

四、奖惩措施

（八）每年度对考勤结果进行评定，干部职工的考勤情况作为个人年度考核和绩效奖励的依据之一，与年度评先评优和绩效奖金等奖惩挂钩。

（九）每月缺勤累计4次以下（不含）、无故旷工累计2天（不含），给予诫勉教育；每月缺勤累计6次以下（不含）、无故旷工累计3天（不含），予以通报批评，并作出书面检讨；每月缺勤累计8次以下（不含）、无故旷工累计4天（不含），给予效能告诫；全年累计缺勤20次（含）以上，无故旷工累计10天以上，年度考核直接定为基本称职或不称职；旷工或者无正当理由逾期不归连续超过15天，或者一年内累计超过30天的，予以辞退。

（十）上班时间不按规定要求，玩电脑游戏、上网聊天、炒股或从事与工作无关的事情，一经发现，予以通报批评，并作书面检讨；凡受到党政纪责任追究、效能问责的人员，年度考核被评为不称职（不合格）的人员，被省委、省政府、省效能办和市委、市政府、市效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的单位人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别发给80%、70%、50%绩效奖励）。

五、本制度从2017年11月1日起执行。

 

 

 

抄送：局领导。

莆田市安全生产监督管理局               2017年10月13日印发
