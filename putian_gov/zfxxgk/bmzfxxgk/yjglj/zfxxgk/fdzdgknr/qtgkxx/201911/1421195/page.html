转发关于进一步加强事故信息报告工作的通知

发布时间：2017-05-12 09:42
| | |

 

 

各县（区、管委会）安监局：

现将福建省安全生产监督管理局《转发国家安全监管总局办公厅关于进一步加强事故信息报告工作的通知》（闽安监明电〔2017〕4号）转发给你们，并就我市进一步规范生产安全事故报告工作提出以下要求，请一并抓好贯彻落实：

一、加强生产安全生产值班值守。各县（区、管委会）安监局要进一步完善值班值守制度，坚持领导带班，确保24小时信息畅通，对上级要求核报和群众反映的事故情况，要及时核实上报。一旦发生事故或紧急情况，要严格按照法律、法规和相关规定，及时、准确、规范上报，有关领导要及时赶赴现场组织抢险和处置，确保社会稳定。

二、规范生产安全事故联网直报。各县（区、管委会）安全监管部门接到生产安全事故报告后，要按照归口统计和联网直报有关工作要求，在向上级报告的同时由负责事故统计的信息员录入总局事故联网直报系统，完成事故初报，并及时补充完善事故初报信息形成续报。

三、健全事故信息报告奖惩机制。各县（区、管委会）安监部门要将生产安全事故报告和安全生产值班情况纳入年度安全生产工作考核内容，定期对未按规定进行事故信息报送的单位予以通报，并在年度考核中予以扣分；对迟报、漏报、谎报或者瞒报事故的有关单位和责任人要依法依规严肃问责。

 

 

 

莆田市安全生产监督管理局

2017年5月12日　　　　

（此件主动公开）

 

 

 

 

 

 

转发国家安全监管总局办公厅

关于进一步加强事故信息报告工作的通知

闽安监明电〔2017〕4号

 

各设区市、县（区）及平潭综合实验区安监局：

现将《国家安全监管总局办公厅关于进一步加强事故信息报告工作的通知》（安监总厅〔2017〕32号，以下简称《通知》）转发给你们，并提出以下意见，请一并抓好贯彻落实：

一、高度重视事故信息报告工作。今年是党的十九大召开之年,是新发展理念和供给侧结构性改革深化之年,也是全面贯彻落实《中共中央国务院关于推进安全生产领域改革发展的意见》开启之年,抓好事故信息报告，齐心协力扎实开展保稳定、护安全、促和谐工作的意义十分重大。各单位要严格按照《通知》规定要求，进一步加强生产安全事故信息报告工作，确保党的十九大、厦门金砖会晤等重要敏感时期安全稳定。

二、建立完善事故信息报告制度。各单位要建立健全事故信息报告和处置工作制度，畅通信息报送渠道，优化信息处置和流通环节，加强对值班人员培训，不断提高事故信息报送的及时性、准确性和完整性。要按照事故归口统计和联网直报工作要求，及时统计上报各类事故，特别要按时限要求做好联网直报工作。要进一步完善事故信息报告的方式和方法，强化制度落实，明确分管领导，明确报送责任，完善各种生产安全事故接报记录，建立事故信息接报登记台账，确保事故信息报送工作落到实处。

三、加强事故信息即时报告工作。县（区）安监局要强化首报意识，接到较大以上事故信息及矿山、化工、烟花爆竹、铁路、民航、地铁、城市燃气等重点行业领域和人员聚集场所的敏感事故信息，要在逐级报送的同时，10分钟内先后向省局值班室（电话：0591-87521854，传真：0591-87548643）和总局总值班室（电话：010-64463290，传真：010-64234662）报告。其中，工矿商贸一般事故（死亡1-2人）、较大涉险事故和容易引起社会关注的其它事故，要在逐级报送的同时，直接向省局值班室报告，直至厦门金砖会晤结束。

事故报告应当包括下列内容：1.事故发生的时间、地点、单位；2.事故的简要经过、伤亡人数；3.事故发生原因的初步判断；4.事故发后采取的措施及事故控制情况；5.事故报告单位。事故信息通过传真或网络报送后，须电话确认。

使用电话快报，应当包括下列内容：1.事故发生的时间、地点、单位；2.事故已经造成或者可能造成的伤亡人数（包括下落不明、涉险的人数）。

 

 

 

福建省安全生产监督管理局

2017年5月5日　　　　

国家安全监管总局办公厅关于

进一步加强事故信息报告工作的通知

安监总厅〔2017〕32号

 

各省、自治区、直辖市及新疆生产建设兵团安全生产监督管理局、各省级煤矿安全监察局：

根据中央办公厅、国务院办公厅关于加强和改进事故信息报告工作有关要求和国家安全监管总局领导同志的指示，为进一步加强生产安全事故（以下简称事故）信息报告工作，现将有关事项通知如下：

一、建立事故信息即时报告制度

地方各级安全监管部门、驻地煤矿安全监察机构（以下统称安全监管监察部门）要高度重视事故信息报告工作，按照各自职责报告事故信息。县级安全监管局、驻地煤矿安全监察分局是事故信息报告的责任主体，要强化首报意识，接到较大以上事故信息及矿山、化工、烟花爆竹、铁路、民航、地铁、城市燃气等重点行业领域和人员聚集场所的敏感事故信息，要在逐级报送的同时，10分钟内向总局总值班室报告（电话：010-64463290，传真：010-64234662）。

二、加强事故核实报告

各级安全监管监察部门负责同志要保持通信畅通，及时接听总局总值班室电话（010-64463290）。总局总值班室要求核报的信息，要按照时限要求反馈相关情况。原则上，电话反馈时间不得超过20分钟，对于明确要求报送书面信息的，反馈时间不得超过30分钟。

三、做好事故跟踪续报

加强事故跟踪调度，密切关注救援进展，及时续报事故情况。重特大事故、重大涉险事故、社会影响较大的事故及时续报抢救和处理情况，抢救持续时间较长的，要每天续报1次；总局领导同志对事故信息作出批示的，按照批示及时跟踪续报；事故伤亡人数、事故等级及救援情况发生变化的，要第一时间续报相关情况；处置结束后，要及时终报。

四、完善事故信息报告考评机制

建立完善事故信息报告情况每月通报制度，对事故信息报告工作成绩突出的单位和个人，给予表扬；事故信息报告制度不落实、报告不及时的，通报批评；对因迟报、瞒报等造成重大损失或影响的，依法依规严肃追究相关单位和人员责任。

 

 

国家安全监管总局办公厅

   2017年4月19日
