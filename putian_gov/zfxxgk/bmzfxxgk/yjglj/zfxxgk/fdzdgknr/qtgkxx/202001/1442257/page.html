莆田市应急管理局关于调整莆田市森林防灭火指挥部的通知

发布时间：2020-01-21 11:31
| | |

莆应急〔2020〕6号                    

 

 

 

各县（区）人民政府（管委会），市森林防灭火指挥部成员单位：

根据机构设置、人员变动情况和工作需要，经市政府同意，现将莆田市森林防火指挥部调整为莆田市森林防灭火指挥部（简称“市森防指”），并对组成单位和人员进行相应调整。现将调整后的名单通知如下：

总 指 挥：傅冬阳  市委常委、常务副市长

副总指挥：范玉水　市应急局局长

方宝昌  市林业局局长

陈金枝  市人民政府副秘书长

    唐辉煌  市公安局副局长           

成  员：周  蓉  市委宣传部四级调研员         

吴国清  市发改委副主任     

柯毓奇  市教育局副局长     

林忠新  市科技局调研员     

            陈俊杰  市工信局总工程师  

            薛严贤  市森林公安局局长     

刘兆阳  市民政局副局长        

刘  强  市财政局总会计师   

林仁淮  市自然资源局副局长   

            陈金表  市交通运输局总工程师 

            郑建腾  市农业农村局副局长

            林新钊  市文旅局副局长

            吴宗权  市卫健委副主任

吴国庆  市应急局副局长

            刘清林  市林业局副局长

            陈艺芳  市气象局总工程师

翁剑峰  市广播电视中心副主任

陈明洪  市通管办常务副主任 

顾  杰  武警第二机动总队第五支队副支队长

赵  磊  武警莆田支队参谋长

            吕建辉  市消防救援支队副参谋长

            张谊文  泉州市森林消防大队大队长

何裕荣  莆田军分区战备建设处副处长

            吴  竞  国网莆田供电公司副总经理

             

莆田市森林防灭火指挥部办公室（简称“市森防办”）设在市应急局，承担指挥部日常工作，办公室主任由市应急局局长范玉水兼任，市应急局副局长吴国庆兼任办公室常务副主任，市林业局副局长刘清林、市森林公安局局长薛严贤、市消防救援支队副参谋长吕建辉、泉州市森林消防大队大队长张谊文兼任办公室副主任。
