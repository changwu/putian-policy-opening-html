发布时间：2020-06-02 16:47
| | |

莆应急〔2020〕61号

 

各有关企业：

根据《中共莆田市委办公室、莆田市人民政府办公室关于印发<莆田市健全落实社会治安综合治理领导责任制奖惩实施办法>的通知》（莆委办发〔2017〕2号）精神，市应急管理局按照《关于修订莆田市平安企业创建考评验收标准的通知》（莆市安监〔2017〕156号）有关规定，牵头组织对全市有关企业2019年度开展平安企业创建活动进行检查考评，经综合评定，莆田市国有资产投资有限公司等25个企业为一类平安企业，莆田市粮食集团有限公司等61个企业为二类平安企业，福建中闽海上风电有限公司等53个企业为三类平安企业。

被评为平安企业的奖励问题，参照市级平安单位有关规定执行。

2019年度平安企业分类结果是对各参评企业开展平安建设（综治工作）成效的肯定，希望评为层次较高的企业要进一步创新机制，主动作为，总结创建经验，强化创建措施，全力推进平安建设（综治工作）再上新的台阶；评为层次较低的企业要认真剖析原因，学习先进，改进工作，力争来年平安建设（综治工作）取得新突破。

 

    附件：2019年度平安企业分类评定情况
