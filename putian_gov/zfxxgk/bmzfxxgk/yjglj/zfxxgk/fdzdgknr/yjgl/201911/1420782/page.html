关于开展公路隧道安全专项整治工作的通知

发布时间：2014-04-28 08:00
| | |

莆市安〔2014〕5号

 

 

各县（区）人民政府（管委会）安委会，市直有关部门：

为深刻吸取山西晋城“3.1”特别重大隧道交通事故教训，切实加强我市隧道安全管理，根据省政府安委会《福建省人民政府安全生产委员会关于开展公路隧道安全专项整治工作的通知》（闽安委〔2014〕5号）的精神，经研究，决定于2014年4月至8月在全市集中开展公路隧道（含高速公路隧道、普通公路隧道、城市道路隧道，下同）安全专项整治。现将有关事项通知如下：

一、工作目标

    认真贯彻省政府安委会公路隧道专项整治通知精神，按照全覆盖、零容忍、严执法、重实效的要求，明确职责分工，全面排查治理公路隧道安全隐患，认真解决存在的突出问题，严格落实各项防范措施，进一步提升隧道安全管理水平和应急处置能力，有效防范和遏制重特大事故的发生。

二、整治内容

（一）全面摸清我市公路隧道情况，开展隧道设施设备隐患排查，及时采取措施，消除各类隐患。结合道路实际状况，在公路隧道入口前增设和完善减速提醒装置、增设测速装置，严格控制车辆进入隧道时的速度。按设计规范要求完善隧道消防设施、灯光照明、应急停车道和限速、禁止超车交通警示标识及逃生通道、逃生指示标识等道路安全基础设施。并根据隧道具体情况，加装监控视频、声光报警、应急广播、应急按钮等装置，确保紧

急状态下隧道内人员能够第一时间获知危险信息，及时避险逃生。

    （二）严格公路隧道通行秩序管控，全面排查、评估公路隧道附近各类检查站、收费站等选址对隧道车辆快速通行的影响。对易造成隧道交通拥堵、导致事故发生的，要立即停用或撤掉。

    （三）建立健全各类公路隧道事故应急处置方案，完善隧道安全通行、隧道拥堵、特别是危化品运输事故应急处置穷案，做好相关部门之间、部门和地方政府之间预案的衔接，建立责任明晰、运转高效的应急联动机制，并进行应急演练。

三、职责分工

（一）各县（区、管委会）安办负责牵头协调本辖区公路隧道安全专项整治。

    （二）市交通运输局负责指导、督促本系统公路隧道安全专项整治。

    （三）市住建局负责指导、督促城市道路隧道安全专项整治。

    （四）市公安交警支队负责排查普通公路隧道、城市道路隧道路面以及隧道内外交通标志、标线等交通安全设施，及时通报相关管理单位进行整治，同时做好与相关部门、地方政府应急预案的衔接。

    （五）莆田高速交警支队负责排查高速公路隧道路面以及隧道内外交通标志、标线等交通安全设施，及时通报相关管理单位进行整治，同时做好与相关部门、地方政府应急预案的衔接。

（六）市公安局消防支队指导、督促公路隧道消防设施等整治，同时做好与相关部门、地方政府应急预案的衔接。

    （七）莆田高速公路部门负责完善高速公路隧道消防设施、灯光照明、应急停车道和限速、禁止超车交通警示标识及逃生通道、逃生警示标识等道路安全基础设施整治，同时做好与相关部门、地方政府应急预案的衔接。

四、实施步骤

公路隧道安全专项整治分三个阶段进行：

    （一）安排部署阶段：根据国务院安委办紧急通知和本通知精神，结合本地区、本部门实际，研究制定开展公路隧道安全专项整治工作方案，督促指导公路隧道管理单位认真落实，并于5月8日前将公路隧道安全专项整治工作方案报市政府安办。

（二）自查自纠阶段：7月8日前，各公路隧道管理单位按照专项整治要求，制定具体实施方案，全面摸清隧道安全状况，按照规范要求开展自查自纠，排查治理隐患；对一时难以整改到位的要制定整改计划，落实整治措施、资金和责任人，明确整改时间，加强整治期间的监控。排查治理情况报市政府安办和市行业主管部门（同时抄报本级政府安办和行业主管部门），各县（区、管委会）安办和市行业主管部门汇总后于7月11日前报市政府安办。

（三）督促检查阶段：7月11日至8月1日，各县（区、管委会）安办要组织人员对本辖区、本行业公路隧道专项整治情况开展督促检查。检查的主要内容：一是查落实国务院安委办明电〔2014〕4号紧急通知精神情况；二是查排查整治工作落实情况；三是查存在的问题和整改防范措施及应急措施制订落实情况。各级各部门专项整治开展情况和检查督促情况，请各县（区、管委会）安办和市行业主管部门于8月6日前报市政府安办。

    市政府安委会将于8月中旬组织督查组，对各级各部门专项整治工作开展情况进行专项督查。

    五、工作要求

（一）加强领导，落实责任。为切实加强公路隧道安全专项整治工作的领导，各县（区、管委会）安办和市行业主管部门要成立相应的领导小组，制定切实可行的专项整治方案，明确责任，落实工作分工，狠抓专项整治工作的落实。

（二）突出重点，强化督导。要加强专项整治工作的督促检查，做到排查不留死角、整改不留后患、工作不走过场。突出安全基础设施薄弱、安全管理制度不健全、存在重大安全隐患的公路隧道，特别是加大特长、长下坡隧道隐患排查整治力度，确保及时整治到位。对一时难以整治到位的重大安全隐患，要实行政府挂牌督办，做到整改责任、措施、资金、时限和预案“五落实”。

（三）立足当前，着眼长远。要以这次公路隧道安全专项整治为契机，切实消除当前严重威胁隧道安全的突出隐患，并落实治本之策，加强隧道安全管理的各项制度建设，建立长放机制，推动隧道安全管理水平和应急处置能力的提升。
