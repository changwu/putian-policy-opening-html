关于印发莆田市危险化学品重点企业专家指导服务工作方案的通知

发布时间：2019-04-09 09:01
| | |

 

 

 

 

 

莆市安办〔2019〕15号

 

 

 

各县(区）人民政府安委会，有关企业：

为深入贯彻落实国务院安办《关于开展危险化学品重点县专家指导服务工作的通知》（安委办〔2019〕1号），根据《福建省人民政府安委会办公室印发福建省危险化学品重点县专家指导服务工作方案的通知》（闽安委办〔2019〕14号）文件精神，结合我市危险化学品安全生产实际情况，我办组织制定了《莆田市危险化学品重点企业专家指导服务工作方案》，在全市危险化学品重点企业组织开展专家指导服务工作。现将方案印发给你们，请认真贯彻落实。

 

莆田市人民政府安全生产委员会办公室

2019年3月23日　　

 

莆田市危险化学品重点企业专家

指导服务工作方案

 

为深入贯彻落实《福建省人民政府安委会办公室印发福建省危险化学品重点县专家指导服务工作方案的通知》（闽安委办〔2019〕14号），深刻汲取今年一季度以来我省发生的几起危化品事故教训，深入推动危险化学品企业落实安全生产主体责任，有效管控危险化学品行业重大风险，消除重大隐患，遏制较大及以上和有重大社会影响的生产安全事故发生，持续促进全市危险化学品行业安全生产形势稳定好转，决定自2019年3月至2021年12月，在全市危险化学品生产、带储存设施经营企业（以下简称“重点企业”，名单见附件）开展为期3年的专家指导服务，特制定本方案。

一、工作目标

充分利用社会力量助力安全生产工作，指导帮助重点企业有效解决危险化学品安全生产工作中的突出问题，在摸清风险、找准问题、抓实措施的基础上，狠抓重点工作落实，推动企业落实安全生产主体责任，坚决防范和遏制事故发生。通过开展专家指导服务，带动重点企业提升危险化学品安全管理水平，为企业和地方政府监管部门培养一批高素质的安全管理与技术专家。

二、工作内容

（一）分类分级，按照安全状况对企业实施精准指导。仙游县、秀屿区两个省级重点县的危化品企业由省安办组织专家开展指导服务。其它危化品生产和带储存设施经营企业，由市安办负责组织专家开展指导服务。各县（区）要对照已经开展的风险辨识和隐患排查“双重预防机制”创建工作的分级结果，摸清各企业安全生产状况，调查评估因风险失控受影响的区域范围及风险值，分析诊断安全控制措施的充分性有效性，开展分级分类指导服务。

（二）突出重点，查找企业存在的安全生产共性问题及重大  风险。针对生产储存装置本质安全设计、总图布置、工艺操作(尤其是工艺报警、联锁的管理)、设备完好性管理、装置安全设施维护、特殊作业管理、变更管理、企业周边风险、应急处置方案、应急救援资源等方面存在的问题，提出整改建议意见。

（三）明确目标，推动企业提升安全生产科学化水平。按照《危险化学品安全管理条例》（国务院令第591号）、《危险化学品从业单位安全生产标准化评审标准》(安监总管三〔2011〕93号)、《国家安全监管总局关于加强化工过程安全管理的指导意见》(安监总管三〔2013〕88号)、《福建省安全生产监督管理局关于印发福建省遏制危险化学品和烟花爆竹重特大事故工作实施方案的通知》(闽安监管三〔2016〕60号)等法规政策、标准和规范性文件要求，指导企业深入推进安全生产标准化建设，构建风险分级管控与隐患排查治理双重预防机制，全面实施化工过程安全管理，提升企业安全生产科学化水平。

（四）加强安全教育培训，提升化工和危险化学品安全监管人员及企业安全管理人员能力。组织全市所有重点企业参加省安办在仙游县、秀屿区两个省级重点县开展的法规标准政策、安全领导力、风险管控、安全生产标准化、化工过程安全管理等教育培训活动，提升危险化学品监管人员及企业安全管理人员的专业能力。

（五)培育标杆，形成安全生产标杆企业和安全监管示范县区。从仙游、秀屿两个重点县中选择1-2家企业进行安全生产标杆企业培植(目标为安全生产标准化二级企业或化工过程安全管理示范企业)，以点带面，推动本地区提升化工和危险化学品企业安全管理水平。

通过省安办的重点辅导，培育1个安全监管示范县区，树立基层危险化学品安全监管典型，推动全市危险化学品安全监管工作上新台阶。

（六）推动化工和危险化学品企业加快转型升级。通过诊断排查，对列入搬迁或不符合国家产业政策(或生产技术处于淘汰或限制类产业类型)、管理差、安全设施投入严重不足、装置本质安全水平低、事故发生概率高、存在重大风险和隐患且整改无望的企业，提出关闭退出建议，推动危险化学品企业转型升级。

三、工作形式

（一）市应急局组织协调全市危险化学品专家指导服务工作。在省安办组织专家指导服务仙游、秀屿两个省级危险化学品重点县的基础上，通过政府购买服务的形式，借鉴省应急管理厅危险化学品重点县指导服务的内容、程序、要求等，从省、市危化品专家库中选取专业人员组成专家组，承担全市除仙游、秀屿外的危险化学品专家指导服务工作。

（二）指导服务实行专家组组长负责制。专家组确定1名专家担任组长。根据各县（区）报送的危险化学品企业信息与企业自查及整改情况，对全市9家重点企业开展指导服务。原则上，市安办对每家重点企业每年指导服务至少2次。对仙游县、秀屿区两个省级重点县，省安办将安排涉及安全管理、工艺安全、设备安全、仪表与电气、设计及总图、消防与应急等6个专业的专家组成专家组，选择2-3家涉及“两重点一重大”的企业开展指导服务。每个重点县每年指导服务至少2次，每次一周。组织全市重点企业参与省安办集中开展的若干次安全教育培训或分批次在重点县开展各类安全教育培训。

（三）指派专人配合专家开展指导服务工作。各县（区）要提供本辖区危险化学品企业的有关信息，配备安全监管执法人员和有关专家参与专家组相关活动，并提供必要的保障。

（四）组织企业参加省厅开展的总结评估和集中讲评。结合省应急管理厅开展的重点县指导服务集中讲评活动，组织各县（区）应急管理部门和所有危险化学品重点企业负责人参加。

四、工作要求

（一）加强组织领导。市安办将制定全市危险化学品专家指导服务工作安排，及时下发相关县（区）政府安委会和应急管理部门，指导重点企业开展工作。各相关县（区）应急管理部门要充分发挥安办的作用，积极配合做好相关工作。专家指导服务小组应及时将指导服务总结报告反馈市应急管理局和相关县（区）应急管理部门。各县（区）负责汇总各专家小组工作情况，及时上报市应急管理局。

（二）检查指导与服务并举。专家指导服务组应认真履行职责，坚持问题导向，高质量完成指导服务任务。在指导服务过程中应主动与企业充分交流沟通。在下达隐患整改清单时，应根据企业需求，为企业提供隐患整改的标准规范、政策文件等依据或技术咨询，促进企业高质量完成隐患整改工作。

（三）指导服务与执法并举。各县（区）应急管理局应加大执法力度，对经指导服务专家组签字确认的、而企业自查未发现的违法违规行为和重大隐患，应依法依规立案查处。对企业自查发现的、未完成整改但已按照隐患整改措施、资金、时限、责任人、预案“五落实”要求实施整改的，原则上不予处罚。

（四）强化隐患整改闭环管理。企业应履行隐患整改主体责任，对自查发现的隐患和指导服务专家组签发的隐患清单，要认真制定整改计划，按照“五落实”的要求，逐条逐项落实隐患整改措施，建立健全重大隐患整改“一患一档”，及时将整改完成情况报当地应急管理局。各县（区）应急管理局应督促企业按照规定的时间节点完成隐患整改闭环，并对重大隐患整改完成情况验收销号。专家指导服务小组在每次指导服务工作开展时，须首先对前次工作中发现的问题隐患整改情况进行核查，核查结果报市应急管理局。

（五）严守纪律要求。所有参与专家指导服务工作的人员应严格遵守中央八项规定精神，加强党风廉政建设，坚决反对形式主义和官僚主义；深入基层现场，坚持原则，敢于发现问题、指出问题，敢于动真碰硬，务求实效，努力推动危险化学品安全生产形势持续稳定好转。
