莆田市安全生产监督管理局关于2017年开展用人单位职业健康基础建设活动情况的通报

发布时间：2018-02-14 16:59
| | |

 

 

 

 

              

莆市安监〔2018〕15号

 

各县（区、管委会）安监局：

为全面落实用人单位职业病防治主体责任，切实提升职业健康管理水平，确保我市职业健康基础建设活动取得预期成效，根据《进一步推进用人单位职业卫生基础建设活动实施方案》（莆市安监〔2016〕22号）文件要求，近日，市局组织人员对各县（区、管委会）开展用人单位职业健康基础建设情况进行随机抽查。现将全市2017年职业健康基础建设完成情况和随机抽查情况通报如下：

一、目标任务完成情况

截止2017年，全市新增涉及职业病危害企业476家，已全部录入职业卫生监管系统，完成职业病危害项目申报336家。开展职业健康基础建设评定的用人单位556家，其中仙游县174家，荔城区131家，城厢区80家，涵江区126家，秀屿区42家，北岸2家，湄洲岛1家。                                

2018年1月份，市局组织人员对完成职业健康基础建设自评的10家用人单位进行随机抽查，确认A类企业1家，B类企业5家，C类企业2家，D类企业2家。

二、主要工作成效

（一）加大宣传，营造职业健康氛围。各县（区、管委会）能够高度重视，按照市局工作要求，细化和印发了工作实施方案，明确了创建对象、建设目标、时间节点、工作步骤和任务要求，加强领导，层层分解，落实责任到乡镇（街道）和具体科室。通过邀请专家授课、开展“宣传周”和“安全生产月”等活动，加大宣传力度，职业健康教育培训覆盖率不断提高，用人单位责任主体意识不断增强，员工自我防护、维权意识明显提高。两年多来，市、县（区、管委会）两级安监部门举办用人单位主要负责人、职业健康管理人员培训班46期，发放宣传册35000多份，共有10万多人（次）参加了各类培训，推动了用人单位主体责任落实，形成了企业主动、中介参与、部门监管、社会关注的浓厚氛围，有力推动了职业健康基础建设活动的开展。

（二）用人单位职业健康基础建设不断夯实。职业病危害项目申报扎实推进，绝大多数用人单位都能按照《进一步推进用人单位职业卫生基础建设活动实施方案》要求，建立职业病防治责任制度，建立健全职业健康管理机构，责任分工明确；作业场所在有可能产生职业病危害的设备醒目位置设置警示标识和中文警示说明；对作业场所能够按规定作相应职业病危害因素监测（评价）；对员工能够进行职业健康查体；大部分生产企业能够坚持有害无害分开，有毒无毒分开，作业区和生活区分开的原则；建立了劳动者职业健康监护档案，能够突出职业危害重点岗位的个体防护。

（三）重点行业领域专项治理取得初步成效。按照国家局、省局的统一部署，我市结合实际，积极开展“五类企业”和“汽车制造和铅蓄电池生产行业”尘毒危害专项治理工作尘毒危害专项整治工作，突出了陶瓷生产、耐火材料制造、水泥生产、石材加工和制鞋企业粉尘危害专项治理整治工作；突出了汽车制造和铅蓄电池生产行业等行业领域专项治理。对存在的职业健康管理制度、人员机构、工作场所职业危害因素控制、接触有毒有害因素的职工建立职业监护档案等问题，提出了具体的整改要求。两年来，全市开展职业健康执法检查、交叉检查579余家（次），发现隐患2650条，当场责令整改1285条、限期整改1365条，市、各县（区、管委会）安监部门下达执法文书近600份，对12家整改不到位的用人单位进行行政处罚43.23万元。

三、存在的主要问题

（一）工作推进不平衡。从本次随机抽查情况看，一是各县（区、管委会）完成自评的企业质量存在差距，普遍存在和自评分数不相符的情况，个别县（区、管委会）把关不严，未及时组织对完成自评的企业进行检查；二是个别县（区）未能按时完成市局下达的基础建设目标任务。

（二）台账建档不齐全。一是内容不全，未能按照评分标准建立台账，缺少职业病防护设施检修维护记录和重要岗位操作规程，部分职业健康管理制度和岗位操作规程制定不全或未结合实际修订；二是记录不全，接触职业病危害的从业人员基本情况建档记录不完整或更新不及时，职业监护档案未能建立完善；三是职业病危害项目申报未能及时更新。

（三）工作场所现场管理不到位。一是现场警示标识、告知卡、中文警示说明不足；二是防护措施不到位，职业病防护设施不完好或缺失，如制鞋企业生产车间通风设备人为关闭；个人防护用品佩戴不规范或不正确，甚至用医用或普通口罩代替防尘防毒口罩。

（四）职业病危害告知管理不规范。一是内容不规范，部分企业的职业病危害公告栏内容不全或与现场不符，劳动者合同告知内容与实际不符或未注明时间；二是设置不规范，公告栏未固定，未在办公区设置，未全覆盖存在职业病危害的工作场所。

四、下一步重点工作安排

针对我市职业健康基础建设中存在的问题，我们要进一步强化居安思危意识，重点解决好当前比较突出的问题，抓好几项工作：

（一）开展抽查，确保质量。各县（区、管委会）要对完成基础建设自评的企业，严格按照《进一步推进用人单位职业卫生基础建设活动实施方案》（莆市安监[2016]22号）要求对用人单位进行抽查和监督执法。并于每年12月10日前将年度工作总结以书面形式报市局。

（二）典型引领，示范带动。各县（区、管委会）要根据当地产业结构的特点，挑选2-3家不同行业、不同规模、不同职业病危害因素，且基础条件较好、职业病危害严重的用人单位进行试点示范建设，探索基础建设活动的开展方式、运行机制，着力打造一批典型示范单位，形成以点带面辐射作用，推进活动全面开展。

（三）强化执法、消除隐患。各县（区、管委会）要加大执法力度，对拒不开展职业健康基础建设活动和未按照标准实施的用人单位，要严格按照有关法律法规规定，依法给予行政处罚；情节严重的，应责令停止相关作业。对本次市局抽查的10家用人单位，各县（区、管委会）要及时下达整改指令书，督促用人单位落实整改消除隐患。并将整改情况于2018年3月15日前书面报送市局监管一科。（联系人：张玉栋，电话：2230918，邮箱171719363@qq.com）。
