关于开展全非煤矿山安全专项检查的通知

发布时间：2013-03-04 08:00
| | |

莆市安监〔2013〕12号

 

 

各县(区、管委会)安监局：

     为了加强非煤矿山安全监管，落实非煤矿山汛期前各项安全工作，根据省安监局《关于开展全省非煤矿山安全专项检查的通知》（闽安监管一〔2013〕19号）的要求，按照市局年度工作部署，经研究，决定在各地组织检查的基础上，市局组织有关专家进行抽查。现将有关事项通知如下：

      一、检查主要内容

        1、2012年—2015年金属非金属矿山整顿关闭工作落实和进展情况；

      2、汛期前安全防范和应急救援工作情况，是否配备必备的应急救援器材，制订事故应急救援预案和措施并定期进行演练等情况；

      3、露天矿山采场工作帮是否定期检查，露天边坡稳定性是否进行定期监测；排土场截洪、防洪和排水设施及防止泥石流措施是否落实；

 4、是否依照非煤矿山开采设计方案，规范非煤矿山开采行为；

5、是否未经设计乱采滥挖及未按设计建设和开采；

 6、爆破安全距离是否符合《爆破安全规程》要求；

7、是否建立健全露天矿山档案，所有矿山企业要在现场办公地点设立档案柜，露天矿山档案应包括以下内容：

    (1)《采矿许可证》(正、副本，正本墙上悬挂)；

    (2)《工商营业执照》(正、副本，正本墙上悬挂)；

    (3)《安全生产许可证》(正、副本，正本墙上悬挂)；

    (4)《生产单位主要负责人安全资格证》(正本或盖有聘任单位印章的复印件)；

    (5)《安全生产管理人员资格证》(正本或盖有聘任单位印章的复印件)；

    (6)《特种作业操作资格证》(正本或盖有聘任单位印章的复印件)；

    (7)企业安全生产各项规章制度：安全生产责任制度、安全目标管理制度、安全例会制度、安全检查制度、安全教育培训制度、设备管理制度、危险源管理制度、事故隐患排查与整改制度、安全技术措施审批制度、劳动保护用品管理制度、事故管理制度、应急管理制度、安全奖惩制度、安全生产档案管理制度等安全管理制度；

    (8)采掘作业规程、贯彻作业规程的记录和各工种操作规程；

    (9)设置安全生产管理机构，配备专、兼职安全生产管理人员相关文件；  

    (1O)从业人员接受安全生产教育和培训的档案和考试成绩表格及试卷；

    (11)从业人员工伤保险有关证明和资料；

    (12)矿山设计文本和附图；

    (13)实测的采场工程平面图；

    (14)设计审查和竣工验收批文；

    (15)安全检查记录、隐患整改情况记录；

    (16)相关部门印发的相关文件；

(17)其它相关文件、资料。   

     二、时间安排和检查方式

     在汛期前各县（区、管委会）安监局按照检查要求，对辖区范围内非煤矿山安全生产工作情况进行全面检查，各县（区、管委会）安监局检查面达100%。市局组织督查组对全市进行抽查，督查组由市局监管二科、市安全生产执法支队相关人员以及专家组成，省局视情况派员参加，时间从3月15日至3月30日，抽查面达50%以上。

     三、有关要求

     1、高度重视、加强领导。各级安监部门和非煤矿山企业要充分认识此次专项检查的重要意义，把专项检查作为推动后续工作契机，加强领导，认真做好排查和整改工作。检查结束后了，各县（区、管委会）安监局于4月2日前向市局监管二科提交一份检查工作情况书面报告，以便汇总通报。

     2、各县（区、管委会）安监部门要密切配合市督查组工作，并指派熟悉当地矿山情况的专业人员配合检查。

     3、市督查组到达各县（区、管委会）后，请当地安监局按照检查工作内容的要求提交一份书面工作汇报材料。

     4、市督查组应按照检查内容严格认真督查，检查中发现的问题由当地安监部门下达整改通知书，督促企业整改。
