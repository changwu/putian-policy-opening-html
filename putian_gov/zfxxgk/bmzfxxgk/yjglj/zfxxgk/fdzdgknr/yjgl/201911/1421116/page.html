莆田市人民政府安委会办公室关于保障省十三届人大一次会议和省政协十二届一次会议进一步加强安全生产工作的通知

发布时间：2018-02-06 15:24
| | |

                                 莆安办明电〔2018〕1号

 

 

各县（区）人民政府（管委会），市安委会有关成员单位：

根据福建省人民政府安委会办公室《关于保障省十三届人大一次会议和省政协十二届一次会议进一步加强安全生产工作的通知》（闽安委办〔2018〕6号）要求，贯彻落实1月12日全省第一季度防范重特大生产安全事故视频会议精神，结合1月3日全市第一季度防范重特大生产安全事故工作会议精神，现就保障省“两会”进一步加强安全生产工作的有关事项通知如下：

一、狠抓措施落实，强化政治自觉和责任自觉，。全省“两会”召开是全省人民政治生活中的一件大事，确保“两会”期间生产安全，是当前安全生产工作的一项重要任务。各级各部门要充分认识做好这一时期安全生产工作的重要意义，强化政治自觉和责任自觉，增强大局意识和责任意识，牢固树立安全发展理念，大力弘扬生命至上、安全第一的思想，严格按照“党政同责、一岗双责、齐抓共管、失职追责”的要求，全面落实地方属地管理、部门监管和企业主体责任，加强督促检查，层层传导压力，构建严密的安全生产责任制。要切实加强“两会”期间安全生产工作的组织领导，早研究、早部署，积极组织协调各方面力量，采取针对性措施，狠抓工作部署后的落实到位，坚决防范和遏制重特大事故发生，为全省“两会”营造良好的安全生产环境。

二、加大工作力度，深入开展大检查第三阶段工作。各级各部门要认真贯彻落实《莆田市安全生产大检查第三阶段实施方案》（莆市安办〔2017〕83号）要求，突出重点地区、重点领域、重点部位，抓好安全生产大检查第三阶段各项工作措施落实，及时化解管控各类安全风险，全面排查整治各类安全隐患，严防各类生产安全事故。要坚持问题导向，落实思想不松、标准不降、力度不减要求，持续按照企业自查、行业检查、政府督查的方法，深入开展对表监督检查，对检查发现问 题隐患要坚决查处、严格执法，依法落实“四个一律”“五个一批”要求。要认真开展事故隐患“清零”行动，对本地区发现的各类问题隐患，要层层建立整改清单，实行挂牌督办、限期整改；对逾期整改不落实的，该关闭的坚决关闭、该取缔的坚决取缔，并公开进行曝光，确保隐患及时消除。

三、强化事故预防，切实加强重点行业领域安全监管。各级各部门要切实非煤矿山、危险化学品、消防火灾、建筑施工、道路交通、渔业船舶、水上交通、特种设备、旅游休闲、油气管道、粉尘涉爆、涉氨制冷、烟花爆竹等重点行业领域安全监管，着力查大风险、除大隐患、防大事故。要统筹做好春运工作，加强对交通运输企业和重点车辆船舶的安全监管，严查超速、超员、超载、疲劳驾驶、非法载客以及违规冒险行车（船）等严重交通违法违规行为。要深入开展消防安全大排查大整治，加强对学校医院、宾馆饭店、集贸市场、公共娱乐场所等火灾风险隐患排查整治，做好森林防火工作，严防火灾事故发生。要严格落实大型群众性活动的安全防范措施，防止拥挤、踩踏等伤亡事故。要进一步严格落实烟花爆竹零售点“两关闭”“三严禁”和批发企业“六严禁”工作措施，做好中心城区烟花爆竹禁燃工作。

四、提升应急能力，切实做好事故防范各项工作。各级各部门要充分利用电视、广播、报纸等传统媒体和微博、微信、新闻客户端等新媒体，以及楼宇电视、户外视频、手机短信等广泛进行安全提示，提高广大群众和企业职工应急避险意识以及自救互救技能。进一步健全信息共享、协调联动机制，加强灾害性天气、地质灾害等预测预报和人流、车流监测，及时发布预警信息。要加强应急检查，落实救援队伍、装备、物资等应急资源，完善应急预案，强化应急演练，提高事故防范和应急处置能力。要加强值班值守，严格执行领导干部到岗带班、关键岗位24小时值班制度和事故信息报告制度，一旦发生事故或险情，要组织救援力量和装备物资快速响应、有效应对、妥善处置。要加强安全生产网络舆情监测，把握正确的舆论导向，加强舆情应对，及时回应社会关切，维护社会稳定。

 

莆田市人民政府安全生产委员会办公室

2018年1月19日
