转发福建省人民政府安委会关于安全生产标准化建设提升工程三年行动暗查暗访工作情况的通报

发布时间：2015-07-06 08:00
| | |

莆市安办〔2015〕45号

 

 

各县(区)人民政府（管委会)安办，市直有关单位：

现将《福建省人民政府安委会关于安全生产标准化建设提升工程三年行动暗查暗访工作情况的通报》（闽安委〔2015〕2号）转发给你们，请认真研究安标化建设提升工程三年行动存在的主要问题和下一步工作意见，并根据本地区和本行业、领域实际，制定工作计划，有序推进企业安全生产标准化建设提升工程三年行动，保质保量完成达标任务。

各县（区、管委会）在冶金、有色、建材、机械、轻工、纺织行业要分别培植示范企业，并将粉尘涉爆企业、涉氨制冷企业、涉及有限空间企业、劳动密集型加工企业列为重点。市直有关部门要在本行业、领域培植示范典型企业，引领本行业、领域的创建工作。

 

 

莆田市人民政府安全生产委员会办公室

2015年7月6日

 

闽安委〔2015〕2号

 

福建省人民政府安委会关于

安全生产标准化建设提升工程三年行动

暗查暗访工作情况的通报

 

各设区市人民政府、平潭综合实验区管委会，省人民政府有关部门、安委会各成员单位，中央驻闽有关机构，各央属、省属企业：

    为扎实、有效推进安全生产标准化建设提升工程三年行动，3月底至4月中旬，省政府安办组织专家，对各地开展安全生产标准化建设情况进行了暗查暗访，共抽查了10个设区市（平潭区）的30个县（市、区）共30个行业领域的50家达标示范单位。现将有关情况通报如下：

    一、总体情况

    从暗查暗访情况看，今年以来，金省各地、各有关单位持续推进安全生产标准化建设提升工程三年行动，工作总体进展顺利，安全生产标准化评定标准、考评方法、工作保障机制、激励约束政策措施基本健全。漳州市、厦门市、莆田市的工作总体水平较高，泉州市、宁德市、龙岩进展顺利，福州市、三明市、南平市、平潭综合实验区总体进展较慢；矿山、危险化学品、交通运输、地勘单位、电力、学校、星级饭店、水利、渔业船舶等行业领域工作质量总体较好。在各地、各有关单位的共同努力下，截至6月1日，共有30578家企事业单位达标、评审达标率46.6%，推动了企事业单位自主管理能力和本质安全水平的提高，促进了全省生产安全事故的持续下降。今年1-4月，全省各类生产安全事故起数、死亡人数同比分别下降14.3%、12.5%。

    二、存在的主要问题

    一是一些地方和部门领导对安全生产标准化工作重要性认识有差距，工作经费保障不足，宣传发动、激励约束等措施没有落实到位；

    二是个别部门指导推动力度不足，企业自创能力培育、考评管理、激励约束、中介机构监管等工作措施没有落实到位；

    三是有的地方和行业为了完成进度目标，核定的应达标企业少于实际数量，没有“全覆盖”。小微企业和个体工商户创建工作滞后；

    四是一些企事业单位对安全生产标准化建设不重视，“重达标、轻运行”。部分企业没有按照规定的“评定标准”开展创建提升工作，有的全部委托中介机构创建、应付了事，达标水平不高；

    五是一些开展达标创建有偿服务的中介机构、人员服务质量不高，有的甚至误导企业的创建工作。

    三、下一步工作意见

    各地、各有关单位要针对上述存在的问题，举一反三，认真查摆本地区、本行业领域工作中存在的问题，并于近期召开一次专题会议认真研究、予以解决。要全面落实省政府的决策部署和“3456”模式的要求，创新推进的方式方法，把各项工作措施落实到位，确保到年底全省应达标单位的评审达标率不少于65%，推动企事业单位不断提高自主管理能力和本质安全水平，促进全省安全生产形势持续稳定好转。

    一要提高思想认识。要把安全生产标准化建设作为贯彻落实新《安全生产法》，强化企业安全生产主体责任、提升企业安全基础管理水平和保障能力的主要抓手，增强推动创建提升工作的主动性和紧迫性。

    二要落实工作措施。要如实核定应达标单位基本情况，完善创建提升工作基础台账；健全完善评审工作机制，严格考评管理：

健全完善动态管理、分级分类监管工作机制，强化对未达标企业的重点指导和监管执法，以执法推动企业主动创建；综合运用经济政策、荣誉、信用等激励约束手段，用市场化的方式，调动企业自主创建的积极性和主动性；加强中介机构监管，依法严厉查处各类弄虚作假、欺诈等违规行为，提升企事业单位达标水平和创建提升工作质量。并组织个体工商户积极参与创建工作，提高安全生产水平。

    三要培育自创能力。要加强政策宣传，强化企事业单位主要负责人安全生产标准化建设的法定责任意识；提高安全生产标准化培训质量，培植一批示范单位并组织经验交流推广，使监管人员、企事业单位有关人员真正了解安全标准化，掌握创建方法，提高自创能力。各地在冶金、有色、建材、机械、轻工、纺织行业，要分别培植不少于3家的示范企业，并将粉尘涉爆企业、涉氨制冷企业、涉及有限空间作业、劳动密集型加工企业列为重点。省有关单位要在各设区市分别培植示范企业，引领本行业的创建工作。

    四要合力抓好工贸行业创建。要认真贯彻落实国家安监总局《关于深化工贸行业企业安全生产标准化建设的通知》安监总管四〔2015〕55号）精神，加强组织领导，落实工作经费，确定评审主管部门，健全完善部门联合协作的常态工作机制，扎实推进创建提升工作。

    五要自主开展创建。企事业单位要依法开展安全生产标准化建设，不断提升创建水平，全面提高全员的安全生产素质和能力，不断提升自主管理能力和本质安全水平，为安全生产形势持续稳定好转提供坚实保障。央属、省属企业要发挥排头兵作用，应用现代信息技术建立隐患自查自报系统和安全生产预警系统，带动全省企业实现本质安全。地址、联系人和电话报送省政府安办（联系人：尤志桂、郑航晓，联系电话：0591-87557092，传真：87511194）。
