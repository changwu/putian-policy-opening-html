关于“7·31”莆永高速公路莆田段A1合同段较大爆炸事故的通报

发布时间：2010-08-02 08:00
| | |

 

莆市安〔2010〕6号

 

 

各县（区）人民政府（管委会），市直有关部门：

    2010年7月31日下午1:45许，莆永高速公路莆田段A1合同段项目部四川路桥建设股份有限公司在忠门互通施工现场（主线桩号K6+100处）进行爆破调试作业时，福建高能爆破公司兴化分公司爆破员在炮孔已装好药后违规进行孔内雷管导通检测，引发爆炸，造成4人死亡。

    事故发生后，市委、市政府主要领导作出重要批示，要求立即组织力量开展救援并全力做好善后工作。梁建勇代市长、林光大副书记、李飞亭、李辉龙副市长带领安监、公安等有关部门及县区、管委会领导赶赴事故现场，组织救援和指导善后处理工作，并在现场召开会议，通报事故情况，并对加强全市安全生产工作提出要求。为深刻吸取事故教训，举一反三，遏制近期在建重点工程施工事故频发的势头，促进工程建设领域安全生产形势的好转，根据市委、市政府领导的重要批示精神和高温暴雨时期建筑施工安全生产工作特点，提出以下要求：

    一、加强企业安全生产工作。各级各有关部门要按照《国务院进一步加强企业安全生产工作的通知》（国发[2010]23号）要求，加大安全监管力度，扎实推进企事业单位安全生产主体责任“三年行动”和“平安企业”创建工作，落实企业安全生产主体责任,进一步规范企业生产经营行为，督促企业及时排查治理安全隐患，强化职工安全培训，对存在重大安全隐患的工程项目实行政府挂牌督办。重点工程主管部门要加强在建工程的日常安全监管，对拒不执行监管监察指令的企业，依法依规从重处罚，并将在建工程的安全管理纳入部门安全责任制考核内容。重点工程建设中需爆破的应由具有相应资质的爆破设计单位设计，报有关部门审批后，由具备相应爆破资质的施工单位进行，爆破作业人员应参加培训经考核并取得有关部门颁发的相应类别和作业范围、级别的安全作业证，持证上岗。

    二、强化重点工程安全生产专项整治。各级各有关部门要按照莆田市人民政府安全生产委员会《关于立即开展全市安全生产大检查的通知》（莆安委明电[2010]1号）和《关于进一步开展建筑施工安全隐患排查治理的通知》（莆市安办[2010]18号）要求，以近期高温暴雨环境下安全施工为重点，继续深化在建重点工程安全隐患排查治理工作，加大力度治理企业安全生产责任不落实，管理不到位；发现的事故隐患治理不坚决、不及时、不彻底等问题。各工程主管部门要从即日起至省运会闭幕期间，开展“百日安全”行动，精心布置、周密部署，坚决杜绝重特大事故的发生。市监察、安办、重点办等部门近期将开展全市在建重点工程安全生产督查行动，督查各县（区、管委会）在建重点工程的安全生产工作，检查市安办重点办《关于在建重点建设项目安全专项检查的通报》（莆市安办[2010] 25号）的落实情况。

    三、切实提高施工人员安全意识和应急能力。各级各有关部门要以“安全发展、预防为主”为主题，向工程项目单位广泛宣传安全生产法律法规。重点工程项目单位要深刻吸取“7.31”事故教训，举一反三，加强建筑施工企业主要负责人、安全员的安全资格管理，保证现场施工人员必要的安全教育和培训，提高施工人员的自我保护意识和安全技能，严禁特种作业人员无证上岗，杜绝“三违”作业现象和冒险作业行为，完善安全事故应急预案，加强施工现场应急演练。工程施工单位应在高温时段合理安排施工计划，尽可能不安排高危作业，并采取降温防暑措施，保证施工作业人员的身体健康。

    四、严格落实事故责任追究制度。各级各有关部门要按照“谁主管、谁负责”、“属地管理”和“四不放过”的原则，认真做好在建工程事故的调查处理工作，严肃追究有关责任单位和责任人的责任，严格事故报告制度，加大对事故发生后瞒报、逃匿行为的惩治力度，坚决杜绝迟报、谎报、漏报和瞒报等违法行为。

 

 

二〇一〇年八月二日
