关于开展落实企事业单位安全生产主体责任三年行动相关问题处理意见的通知

发布时间：2010-07-15 08:00
| | |

 

莆市安〔2010〕4号

 

 

各县（区）人民政府（管委会）安委会、市直相关部门，中央属、省属驻莆企事业、市属企业：

    去年以来，我市按照省政府的统一部署，积极推进落实企事业单位安全生产主体责任三年行动（以下简称“三年行动”），在各级、各相关部门和企事业单位的共同努力下，目前进展顺利，取得了较好的成效。但在实施过程中，也遇到一些困难和问题，以及需要进一步明确的事项，影响和制约了“三年行动”的顺利开展。为了进一步推进“三年行动”的深入开展，确保按时完成各项目标任务，根据闽安委会[2008]29号文件精神，经市政府领导同意，现将我市“三年行动”相关问题处理意见通知如下：

    一、关于职责分工调整问题

    为了便于与省直相关部门的工作衔接，根据闽安委 [2008]29号文件精神，对《莆田市人民政府安全生产委员会关于印发莆田市开展落实企事业安全生产主体责任活动的指导意见的通知》(莆市安[2009]5号)中规定的市经贸委、市消防武警支队、市药监局的职责分工作出调整，其他部门的职责分工保持不变。具体是：

    1、市经贸委：负责检查、指导、督促5万千瓦以上在建水电企业和电力运行、化工、医药、有色、冶金、通信、信息、建材、轻工、纺织、机械、民爆、（生产和销售）、军工、贸易企业的级别评定及隐患排查整改工作。

    2、市消防武警支队：协助有关部门检查、指导、督促人员密集场所的级别评定及隐患排查整改工作。

    3、市药监局：协助有关部门检查、指导、督促药品生产、经营、储存企业的级别评定及隐患排查整改工作。

    各相关部门要按照职责分工，认真履行职责，抓好各项工作的落实。其中，负责检查、指导、督促的部门要按照莆市安办[2009]10号文件规定的级别评定标准（总分1000分），抓好复核确定工作；协助、配合的部门要主动做好配合工作。

    二、关于中央属、省属驻莆企事业、市属企事业和外资企业级别评定流程调整问题

    为便于级别评定工作的组织实施和日常安全监管，根据“属地管理”、“谁主管、谁负责”原则，对莆市安[2009]5号和莆市安[2009]21号文件中规定的中央属、省属驻莆企事业、市属企事业和外资企业级别评定流程作出调整。具体是：

    1、关于中央属、省属驻莆企事业和市属企事业级别评定流程调整问题。中央属、省属驻莆企事业和市属企事业自评后，送市行业主管部门复核确定，评为A、D级的企业，由市行业主管部门报市政府安办确认。市政府安办将确认为A、D级的企事业，上报省政府安办，并反馈市行业主管部门。由市行业主管部门将级别评定结果报省行业主管部门和市政府安办备案，抄送对应的县（区、管委会）行业主管部门，并督促企事业抓好发现的安全隐患的整改落实。

    2、关于外资企业安全级别评定流程调整问题。外资企业级别评定工作由县（区）人民政府（管委会）具体组织实施，采取“企业自查自评，乡镇政府（街道办事处）初审分类，县级行业主管部门复核确认”的评定流程进行。外资企业级别评定流程按照莆市安[2009]21号文件附件6执行。

    三、关于级别评定工作落实问题

    我市自2009年开展这项工作以来，各级各相关部门和企事业单位十分重视，做了大量卓有成效的工作，取得了较好的成效。但从市政府领导和市政府安办多次督查的情况看，也存在较多的问题。如个别县（区、管委会）、市直相关部门没有引起足够重视，组织领导不力，宣传发动不够，措施办法不多，进度不够理想；较大部分企事业单位思想认识不到位，或没有按照要求开展自查自评工作，或随便应付了事，存在工作质量不高、流于形式的现象。上述存在的问题，已影响和制约企事业安全生产级别评定工作的有效开展。为此，根据省政府安委会的部署和要求，结合我市的实际，现就进一步抓好我市企事业安全生产级别评定工作落实提出以下几点要求：

    一要强化组织领导。各县（区）人民政府（管委会）、市直相关部门要高度重视这项工作，摆上重要议事日程，主要领导要经常过问，分管领导要具体抓，及时协调解决实施过程中遇到的困难和问题。要调整充实开展落实企事业安全生产主体责任活动机构的人员和力量，提供专项经费和工作条件，保障这项工作顺利开展。

    二要强化宣传培训。各县（区）人民政府（管委会）、市直相关部门要召开各种形式的部署会、交流会、现场会等，将省、市有关要求、规定等，传达贯彻到每一个企事业和职工群众，调动他们参与这项工作的积极性和主动性。同时，各县（区）人民政府（管委会）要通过层层举办各种形式的业务培训会，对乡镇（街道）、有关部门和企事业的具体负责人员进行业务培训；市行业主管部门要进一步细化专业分的评定标准，加强对县（区、管委会）行业主管部门的业务培训。通过业务培训，提高参与评定人员的素质，有效开展级别平和安全隐患排查整改工作。

    三要强化督促指导。各县（区）人民政府（管委会）要不定期组织人员，深入乡镇（街道）、有关部门和企事业单位，开展督促、检查、指导工作。对开展工作不力的、进度不理想的、要进行通报，并约谈其主要领导。尤其是乡镇（街道）所承担的工作任务较重，要采取包片负责制等做法，组织和动员一切力量，做好调查摸底，督促指导每个企事业单位开展级别自评，并做好初审分类工作。市直行业主管部门也要组织力量，深入各县（区、管委会）行业主管部门和企事业单位，开展督促指导工作。在开展督促指导工作过程中，要注意培植典型，并通过召开现场会等形式，发挥典型示范作用，以期收到事半功倍效果。

    四要强化奖惩约束。市政府安委会已将这项工作开展情况纳入年度安全生产责任制考评的一项重要内容，将在考评扣分、事故问责和评优评先等方面兑现奖惩机制。同时，各县（区、管委会）安办要将确定为A、C、D级的企事业单位名单函告相关部门和企事业开户银行。各级、各相关部门、单位要按照莆市安[2009]5号文件要求，在行政许可、项目审批和评优评先等方面兑现奖惩，以促进工作全面推进。

    五要强化基础工作。（1）及时报送统计数据和信息。各县（区、管委会）、市直相关行业主管部门要严格按照莆市安办[2010]36号文件规定，及时报送相关统计数据和信息，以及开展这项工作好的经验和做法。（2）规范建档。各县（区、管委会）、市直相关行业主管部门在复核时，建档做到存“申请表”、“企业级别评定标准”、“工商营业执照”、“企业负责人安全培训证书”、“责任书”、“应急救援预案”等六项内业资料（以上材料复印即可）。（3）做好隐患整改工作。对评定过程中发现的安全隐患，各县（区、管委会）、市直相关行业主管部门要及时督促相关企事业单位抓好整改，该挂牌督办要挂牌，该曝光的要曝光，该停业整顿就依法严格执行，确保整改工作落到实处。

                            

二〇一〇年七月十五日
