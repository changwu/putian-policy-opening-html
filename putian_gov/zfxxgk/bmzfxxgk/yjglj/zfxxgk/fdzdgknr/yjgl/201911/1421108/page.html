莆田市人民政府安委会办公室关于开展“两会”期间安全生产专项检查实施方案

发布时间：2017-03-02 13:06
| | |

内部明电

 

发往：见报头                         签批盖章：蔡国萍

等级：特提              部委号：莆安办明电〔2017〕7号

 

 

各县（区）人民政府（管委会）安委会，市直有关单位：

为确保全国“两会”期间我市安全生产形势持续稳定，根据《福建省人民政府安委会办公室关于立即开展全国“两会”期间安全生产专项检查的紧急通知》（闽安委办明电〔2017〕10号）以及《莆田市人民政府安委会办公室关于立即开展全国“两会”期间安全生产专项检查的紧急通知》（莆安办明电〔2017〕5号）文件要求，现结合我市实际情况，制定“两会”期间全市安全生产专项检查实施方案如下：

 一、目标任务

认真学习贯彻习近平总书记、李克强总理关于安全生产的重 要指示批示精神和系列讲话，按照国家、省、市关于做好全国“两会”期间安全生产工作部署，扎实做好全国“两会”期间安全生产专项检查工作，确保我市全国“两会”期间安全生产形势稳定。

二、检查时间

从即日起至全国“两会”结束。

三、检查内容

各级各部门要紧盯事故易发多发、高风险行业领域和薄弱环节，切实加强重点行业领域安全监管，按照安全生产执法计划和“双随机”工作要求，不间断开展执法检查和暗访暗查，及时发现解决各领域突出隐患问题，严厉打击非法违法生产经营建设行为。

（一）共性方面

1.宣传贯彻习近平总书记关于安全生产重要指示批示精神；

2.国家、省、市安全生产会议、文件精神贯彻落实情况；

3.全国“两会”期间安全生产工作部署情况；

4.安全生产教育培训情况；

5.关停企业的安全监管情况；

6.节后复产复工企业安全生产情况；

7.应急管理机构设置和人员、装备、设施配备和应急预案制定演练情况。

（二）重点行业领域方面

非煤矿山方面。按照“全覆盖、零容忍、严执法、重实效”的总体要求，以非煤矿山安全生产大检查和打非治违为手段，狠抓安全隐患排查整治，严打非煤矿山非法违法生产经营，防范和遏制非煤矿山企业各类生产安全事故发生。

危险化学品方面。切实加强危险化学品生产、储存、经营、运输、使用和废弃环节的安全监管工作，加强涉及“两重点一重大”企业安全检查及重点部位、重要岗位、重点人员的风险防控工作，强化工艺管理和日常巡查，严格落实防火、防冻、防爆、防泄漏、防中毒等安全措施。

烟花爆竹方面。要进一步严格落实烟花爆竹零售点“两关闭”“三严禁”和批发企业“六严禁”工作措施。切实做好储存、运输、销毁等环节的安全监督管理，严防因处置不当导致事故。针对未燃放的烟花爆竹可能留存在群众家中和销售点的情况，强化安全知识宣传教育，消除群众身边安全隐患。

交通运输方面。切实加强道路客运、危险品运输、大型货运车、校车、旅游车辆、农村面包车等重点车辆安全管控，严肃查处超速、超员、超载以及疲劳驾驶、无证无照行驶、非法载客等严重违法违规行为。加大“三品”检查力度，严禁旅客携带危险品进站上车。针对当前冬春交替、气温冷暖变化剧烈导致路面湿滑等特点，密切注意天气变化，进一步落实重点路段防控措施，及时做好恶劣天气下预警预报、交通提示、临时封闭、交通疏导和事故防范工作。

消防安全方面。要深刻吸取浙江天台“2·5”重大火灾事故教训，进一步加强对各类娱乐场所、商场市场、宾馆饭店、养老院、医院、学校、幼儿园、劳动密集型企业等人员密集场所、地下经营场所和易燃易爆单位的消防安全检查，严厉查处各类违法违规行为，严防群死群伤火灾事故。

建筑施工方面。强化对建筑施工企业复工和新开工项目施工现场的安全检查，对建筑深基坑、起重机械、建筑模板、脚手架和施工临时用电等关键部位和环节加大隐患排查力度，严格落实各项安全防护措施，防止事故发生。

特种设备和城镇燃气方面。加强锅炉、压力容器、电梯等特种设备的现场动态管理和检查，确保各项安全管理制度和措施的落实。对燃气经营、使用单位全面开展安全检查，加大对城镇燃气管线的巡查力度，科学设置警示提示标志，严防施工等意外因素造成的燃气泄漏和爆炸事故发生。

其他重点行业领域。要加强铁路道口设备、安全防护设施、管理制度等专项检查，对车流量较大道口进行重点管控。加强工贸行业领域的安全监督检查，重点对有限空间、粉尘涉爆和涉氨制冷等容易发生火灾、爆炸危险的企业进行检查，及时发现和消除事故隐患。同时要加强民爆、电力、学校、大型活动等行业领域的安全监管，确保安全。

四、工作要求

（一）高度重视，精心组织。全国“两会”是全国人民政治生活中的一件大事，各级各部门要进一步强化政治意识、大局意识、忧患意识和责任意识，高度重视全国“两会”期间安全生产专项检查工作，切实加强组织领导，周密研究部署，明确目标任务、工作重点、实施步骤和具体要求，狠抓责任和防范措施的落实，认真组织好本地区本部门的安全生产督导检查和执法检查活动，确保取得实效。

（二）明确责任，彻底整改。各级各部门要研究制定本单位的安全生产专项检查工作方案，要紧紧围绕督促整改前一阶段国家、省、市督查检查中发现的安全隐患，深入开展安全隐患排查治理，严格落实安全防范措施。对查出的隐患和问题，能立即整改的要立即整改，不能立即整改的要落实安全防范措施；要认真抓好隐患整改责任、措施、资金、时限、预案“五落实”，确保各项问题隐患整改到位。

（三）强化引导，营造氛围。各级各部门要进一步搞好安全生产宣传工作，加大正反两反面的典型宣传，对严重非法违法、违规违章行为和典型案例公开曝光，强化警示教育作用，要扩大社会参与度，依靠群众，鼓励广大群众对各类非法违法生产行为和事故隐患的举报、充分发挥社会的监督作用，形成全社会积极支持、广泛参与的浓厚氛围。

（四）掌握信息，及时报送。各级各部门要强化值班值守，严格执行领导值班和24 小时值班制度，进一步加强网络舆论监测，及时收集掌握安全生产和社会稳定的信息，采取措施，科学、有效的引导安全生产网络舆论，避免发生群体性事件或造成不良社会影响。要及时掌握全国“两会”期间安全生产专项检查情况，明确专人负责，及时向市安委办报送专项检查工作信息。
