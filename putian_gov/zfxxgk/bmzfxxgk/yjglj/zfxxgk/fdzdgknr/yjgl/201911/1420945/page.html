关于全市餐饮场所燃气安全专项治理督查情况的通报

发布时间：2013-05-06 08:00
| | |

莆市安办〔2013〕17号

 

 

 

各县(区)人民政府（管委会），市政府安委会有关成员单位：

根据市政府安委会《关于印发莆田市深入开展小型餐饮场所燃气安全专项治理检查实施方案的通知》（莆市安〔2012〕15号）、《转发国务院安委会关于深入开展餐饮场所燃气安全专项治理的通知》（莆市安〔2013〕6号）和市政府安办《关于开展全市餐饮场所燃气安全专项治理督查的通知》（莆市安办〔2013〕12号）精神，2013年4月15日至19日，市政府安办抽调市住建局、经贸委、质监局、安监局、消防支队、工商局、卫生局等有关部门领导和人员组成三个督查组，采取听取汇报、查阅资料、现场检查等形式，对各县（区）人民政府（管委会）和市直有关部门深入开展餐饮场所燃气安全专项治理的情况进行督查。现将有关情况 通报如下：

一、总体情况

从督查情况看，各县（区、管委会）和市直有关部门都比较重视餐饮场所燃气安全专项治理工作（以下简称专项治理），制定了本辖区、本部门专项治理实施方案，明确专项治理范围、职责分工、时间安排和保障措施，开展调查摸底，建立基础台账，并组织餐饮场所对照专项治理标准进行自查自改，有序推进专项治理工作。截止目前，全市调查摸底火锅店、烧烤店、小吃店等各类使用燃气的餐饮场所2265家，从业人数7953人，企业自查安全隐患3762项，其中重大安全隐患10项（已全部自改到位），自改1325项，自改率35.2%，落实整改资金8.15万元。各县（区、管委会）组织检查组93个，检查人员1172人次，检查258家，发现安全隐患509项，已督促整改469项，整改率92.1%，落实整改资金5.68万元。荔城区能充分发挥镇街的作用，全面排查辖区内使用燃气的餐饮场所的底数，掌握其营业执照、餐饮服务许可证、是否使用螺丝瓶等情况，并已组织相关部门开展专项督查。秀屿区也相应组织开展了专项督查。涵江区重视开展联合执法，先后开展联合执法检查3次，检查131家次。市住建局注重结合节日安全检查、清剿火患等活动，强化对各县区住建部门和各燃气企业开展专项治理进行督查，要求加强对餐饮场所的安全用气宣传、指导，组织安全培训，帮助指导餐饮场所建立相应安全管理制度。市城管执法局积极与住建、公安、质监、安监等相关部门协作，互通信息，开展经常性联合执法。专项治理行动开展以来，共组织出动人员1039人次，车辆482辆次，排除安全隐患119项，劝导纠正85起，查获并暂扣非法经营液化气瓶57瓶，制止燃气设施安全保护范围内违法施工5起、发出整改督办函6份。市卫生局共组织8个检查组，出动执法人员973人次，已检查餐饮场所2237家次，摸底排查出无证小餐饮203家。

二、存在的主要问题

专项治理开展以来，全市各级、各相关部门做了大量的工作，取得了一定成效，但从督查情况看，仍存在不少薄弱环节和突出问题，必须引起各级、各相关部门的高度重视。主要表现在：

一是个别单位对专项治理不够积极主动。未能认真落实专项治理工作部署要求，充分发挥基层作用，组织各类使用燃气的餐饮场所全面开展自查自改，对排查上报的餐饮场所燃气安全隐患未能及时督促整改，不严格依法履行各自的法定职责，甚至存在等待、观望、畏难情绪和推诿、扯皮现象。

二是调查摸底情况差异较大，基础台账不够完善。全市共调查摸底使用燃气的餐饮场所2265家，其中仙游县116家、城厢区454家、荔城区1138家、涵江区217家、秀屿区228家、北岸63家、湄州岛49家。从督查来看，调查摸底不全面，与实际情况仍存在一定的差距，个别单位仅统计燃气供应企业提供有签订安全供气合同或有取得相关证照的数据，缺少使用无燃气经营资质、外地燃气供应、未签订安全供气合同以及未办理证照的餐饮场所数据，尚未建立起本辖区、本部门较为完善的基础台账。

三是餐饮场所自查自改情况不够理想。从抽查的餐饮场所来看，大部分餐饮场所未能对照专项治理标准开展安全隐患自查自改，未见企业自查自改台账，现场安全隐患仍然比较突出，个别餐饮场所大量使用瓶装液化石油气，且堵塞通道，未设立专用气瓶间，钢瓶供应多台液化石油气灶具未采取硬管连接，软管违规穿墙，同一房间同时使用液化石油气和蜂窝煤炉等明火，未按规范安装可燃气体浓度报警装置，未见燃气作业安全管理制度、操作规程和应急预案，未定期开展燃气安全检查等。

四是餐饮场所燃气安全宣传教育培训不够到位。从宣传资料、宣传方式和现场询问餐饮场所负责人、从业人员燃气安全情况来看，餐饮场所燃气安全宣传内容不够丰富，形式单一，个别餐饮场所从业人员燃气安全教育培训不到位，反“三违”意识淡薄，事故应急处置能力不强。

三、下一步工作意见

针对督查发现的主要问题，现就下一步继续抓好专项治理提出以下意见：

一要进一步加强组织领导。本次专项治理是国务院、省、市政府安委会今年的重点工作之一，也是开展安全生产 “打非治违”的重点领域之一，各级、各相关部门要高度重视，进一步加强组织领导，对照本次通报情况，查找工作薄弱环节，对专项治理工作进行再部署、再督导、再落实，切实履行部门监管责任和属地管理责任。

二要进一步组织排查整治。各级、各相关部门要充分调动乡镇（街道）、村居等基层力量，进一步排查使用燃气的餐饮场所，摸清底数，建立基础台账，组织企业对照专项治理标准进行自查自改，督促企业落实安全生产主体责任。

三要进一步加强宣传培训。各级、各相关部门在开展专项治理的同时，要结合实际，采取印发宣传资料、举办培训班、以案说法等多种形式，宣传燃气防爆安全知识，进一步加强对餐饮场所从业人员的安全培训教育，提高从业人员的安全意识和操作技能，规范作业行为，减少和杜绝“三违”现象。

有关县（区、管委会）和市直有关单位要抓   好本次督查发现问题（见附件）的整改落实工作，于5月20日前，将有关落实情况与重新排查统计表一并报送市政府安办。
