莆田市人民政府安委会办公室关于2017年全市工贸行业有限空间作业条件确认工作开展情况的通报

发布时间：2018-03-19 10:42
| | |

 

 

莆市安办[2018]14号

 

各县（区）人民政府（管委会）安委会办公室，市政府安委会有关成员单位，有关央属、省属、市属企业：

2017年，全市各县（区、管委会）按照国家、省里和市里统一部署，持续开展工贸企业有限空间作业条件确认工作，工贸企业有限空间事故易发多发态势得到有效遏制，现将有关情况通报如下，并请结合《国家安全监管总局办公厅关于2017年工贸行业有限空间作业条件确认工作的通报》（安监总厅管四[2018]4号）、《福建省人民政府安委会办公室关于2017年全省工贸行业有限空间作业条件确认工作开展情况的通报》（闽安委办[2018]17号）(可在福建省安监局网站自行下载)文件精神，举一反三，对照检查，针对存在的现实问题，认真抓好整改落实工作。

一、基本情况

2017年，我市结合安全生产大排查大整治、安全生产大检查等安全专项行动，进一步深入开展冶金、建材、轻工行业为重点的有限空间作业条件确认工作，继续推动造纸和酱腌菜生产企业以及工贸企业附属污水处理系统有限空间作业条件确认工作专项检查，突出严格监督检查和宣传教育培训工作重点，把工贸行业有限空间作业安全检查纳入日常监督检查计划中，并严格抓好落实，去年，我市对有限空间作业企业进行全面梳理，完善了基础管理台帐，夯实了基础。市安办先后组织2次专项督查，检查工贸企业23家，共发现安全隐患和问题55条，及时督促有关企业落实整改要求，现已全部整改完毕，整改率达100%。全市各级安办督促指导检查了144家涉及有限空间作业工贸企业，发现事故隐患369项，已全部督促整改到位、整改率100%，有效提升了企业有限空间作业安全管理水平。

二、主要做法

（一）突出重点，精心研究部署。各级各部门严格按照《莆田市人民政府安委会办公室关于2016年全市工贸企业有限空间作业条件确认工作情况的通报》（莆市安办〔2017〕15号）要求，坚持问题导向，结合我市工贸行业有限空间作业条件存在的现实问题，及时通报了全市2017年工贸行业有限空间作业条件确认工作开展情况，各级各部门紧紧围绕“怎么做”上下功夫，广泛动员部署，组织专题培训，开展专项检查，督促指导市、县（区、管委会）基层部门按照本级政府的职责分工，认真开展有限空间作业条件确认和专项检查，督促本行业相关企业落实自查自改措施，提高有限空间作业安全管理水平。同时督促企业对有限空间风险辨识和台账建立、作业人员安全培训、作业审批及执行、警示标识设置、通风检测作业仪器装备配置、应急演练、外委有限空间作业安全管理等7个方面进行自查自改，推动有限空间作业条件确认工作的落实。

（二）加大力度，强化督查检查。一是强化督查检查。2017年，全市各县（区、管委会）将有限空间作业条件确认工作推进情况作为年度安全生产目标责任和重点工作督查检查的重要内容，全市各辖区各有关部门开展专项及结合性的工贸行业有限空间作业安全督查检查共计26批次，督查检查企业168家，排查隐患465条，已全部整改到位，整改率达100%。二是开展专家组抽查“会诊”工作。根据省安办编制《工贸企业有限空间作业条件确认安全生产专家组抽查“会诊”情况检查表（试行）》，采取“四不两直”的方式，组织专家组深入涉及有限空间作业工贸企业，通过查阅资料、勘察现场、讨论汇总、座谈反馈，对相关企业开展安全生产抽查“会诊”、解剖示范，促进所在地安全监管部门提高监管能力，推动工作落实。涵江区安办从源头上把好粉尘涉爆和有限空间企业入门关，对无证照的违法粉尘涉爆和有限空间企业一律取缔；对整改仍达不到安全生产条件的，依法予以关闭；对存在重大安全隐患的要实行挂牌督办。凡粉尘涉爆和有限空间企业要求不达标的，安全责任制不健全的，安全规章制度不落实的，一律列入“黑名单”并对外公布。北岸管委会通过专项整治和日常监管相结合，利用安全生产大排查大整治和三个阶段安全生产大检查行动，充分发挥聘请专家查隐患的作用，确保企业安全生产主体责任落实到位，有序推进隐患排查治理工作。

 （三）加强培训，营造浓厚氛围。一是加强培训。2017年7月18日市安办在市安全生产协会举办一期工贸行业有限空间作业专项整治安全培训班。各县（区）人民政府（管委会）安办负责工贸行业有限空间作业安全条件确认工作的业务股室负责人或具体工作人员；各乡镇（街道）涉及有限空间作业企业的监管业务人员；全市工贸行业有限空间作业企业主要负责人或安全管理人员参加。主要对工贸行业有限空间作业企业安全技术要求应急处置和现场监督检查重点进行培训。二是广泛宣传。全市各级各有关部门利用电视、报纸、横幅、网络、LED显示屏、“工贸安全”微信公众号等各种媒体，广泛宣传《有限空间安全作业五条规定》《工贸企业有限空间作业安全管理与监督暂行规定》《工贸企业有限空间参考目录》等法律法规、标准规范，以及有限空间作业安全知识。仙游县安办5月中旬组织各有关部门及乡镇（街道办、管委会）相关人员在县政府办召开粉尘防爆有限空间作业知识讲座；秀屿区安办组织全区企业负责人和乡镇监管人员参加工贸行业有限空间作业专项培训班，同时通过微信、QQ群等平台，在线开展工贸行业有限空间作业安全生产专项整治宣传。

三、存在问题

虽然全市在开展有限空间作业条件确认方面做了一些工作，也取得了一定成效，但与上级要求仍有差距，还存在一些薄弱环节：一是部分企业对有限空间作业危害性认识不足，主体责任落实不到位。有的对有限空间的概念不清，有的自查自改工作不到位，基础台账不健全。二是有的县区安全培训、监督检查没有真正做到“全覆盖”。三是个别地方监管部门安全监管执法不严格，对开展工贸行业有限空间作业条件确认工作不到位的，未依法予以行政处罚、停业整顿或关闭。

四、2018年工作要求

（一）工贸行业涉及有限空间作业的企业门类多、数量多、中小企业多、基础薄弱，有限空间事故易发多发，事故占比较高，各级各部门要从思想上提高认识，切实重视有限空间作业条件确认工作，不断巩固和提升工贸行业有限空间作业安全管理水平。

（二）加强业务培训，提升工贸行业安全监管人员和企业管理人员工作能力。一方面要抓基层和行业部门工贸安全监管人员开展有限空间安全培训工作，另一方面要抓企业主要负责人和安全管理人员开展有限空间安全培训工作。按照国家安全监管总局《工贸企业有限空间目录》，重点解决“哪些场所属于有限空间？”“有限空间作业条件确认工作要怎么做？”“日常监管工作要怎么做？”“企业进入有限空间作业有哪些要求？”“怎么做才算真正到位？”，等等。

（三）要强化企业有限空间作业审批工作，督促所有造纸、酱腌菜生产企业，以及排查出涉及有限空间作业的工贸企业建立并落实统一、规范的有限空间作业审批制度，审批表单能反映实际工作情况，同时要积极探索建立企业内部第三方确认制度，确保审批表单上的安全措施、定期检测等要求真正落实到位。

（四）要继续摸排、专项检查涉及有限空间作业的工贸企业，重点抓住冶金、建材、轻工等有限空间事故占比最多的行业，有序推进工贸行业有限空间作业条件确认工作。结合本辖区行业企业现状，制定企业摸排或专项检查计划，在自行规定期限内健全完善冶金、建材、轻工等行业企业有限空间监管台账，并督促有关企业落实有限空间作业各项要求。

（五）要在前一阶段造纸和酱腌菜生产企业、附属污水处理系统有限空间作业条件确认工作专项检查的基础上，全面查漏补缺，督促企业整改到位，确保工作取得阶段性成果。

（六）要强化企业有限空间作业安全警示标志设置监管工作。规范“先通风、再检测、后作业”程序，在有限空间作业场所醒目位置设置安全警示标志，防止擅自进入及盲目施救，为防范有限空间事故建立有效防线。

（七）严格执法检查，推动工贸行业企业有限空间作业条件确认工作落实。各级各部门要加大对工贸企业有限空间作业的监督执法力度，严厉查处违法违规行为，对问题突出的企业还要进行通报、曝光，提高涉事企业违法违规的社会和经济成本，形成监管执法威慑力，推动工贸行业企业有限空间作业条件确认工作真正落实到位。

（八）要将工贸企业有限空间摸排、检查工作与日常监督执法、各类专项治理、安全生产大检查等工作结合起来，将有限空间作业条件确认工作融入安全生产标准化建设、隐患排查治理体系建设、工贸行业较大危险因素辨识管控计划等工作中。

（九）各地区要利用微信、网站、报纸、电视等各种媒体，扩大有限空间作业安全宣传途径和范围，普及有限空间作业安全常识，在全社会营造防范遏制有限空间事故浓厚氛围。

请各地认真做好本辖区工贸行业有限空间作业条件确认工作部署和2018年工作总结。其中，部署情况于2018年4月10日前、总结报告及《工贸行业有限空间作业条件确认工作汇总表》（见附件2）于2018年11月15日之前以正式文件报送市政府安办（联系人及电话：龚冠华，0594-2392566，电子邮箱：ptajjek@163.com）。

    生产经营单位未与承包单位、承租单位签订专门的安全生产管理协议或者未在承包合同、租赁合同中明确各自的安全生产管理职责，或者未对承包单位、承租单位的安全生产统一协调、管理的，责令限期改正，可以处五万元以下的罚款，对其直接负责的主管人员和其他直接责任人员可以处一万元以下的罚款;逾期未改正的，责令停产停业整顿。
