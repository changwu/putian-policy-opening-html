关于举办安全生产管理知识专题讲座的通知

发布时间：2018-06-26 11:17
| | |

 莆市安办函〔2018〕17号

 

 

各县（区）人民政府（管委会）安办，市政府安委会有关成员单位：

为进一步贯彻落实《中共中央 国务院关于推进安全生产领域改革发展的意见》，全面推动落实企业主体责任，构建安全风险管控与隐患排查治理双重预防机制，有效防范和遏制重特大事故。根据省政府安办安排，市安办决定于6月份举办两期安全生产管理知识专题讲座。现将有关事项通知如下：

一、课程安排

第一期：6月15日下午15:30-17:30，加强企业全员安全生产责任制工作相关政策解读，主讲人：李叶枝（教授级高工，国家、省政府安全生产专家组成员）；

第二期：6月19日下午15:30-17:30，安全生产风险分级管控和隐患排查治理“双重预防体系”建设相关政策解读，主讲人：李翰文（注册安全工程师，省政府安全生产专家组成员）。

二、地点

莆田海源国际大酒店三楼海禧厅，公交车2路、5路、8路、13路、17路、52路、53路、55路、56路、96路、98路、201路、209路乘坐到莆仙大剧院站，步行5分钟到达。

三、参加对象

1、市安委会成员单位联络员；

2、各县（区、管委会）安办分管领导、股室负责人；

3、危险化学品生产、带储存经营企业（不含加油站）和烟花爆竹批发企业负责人和安全员；中石化、中石油莆田分公司分管领导和安全员

4、其他行业领域双重预防机制构建标杆企业负责人和安全员。

四、其他事项

1、请市安委会有关成员单位、各县（区、管委会）安办做好参训人员的报名组织工作，汇总参会人员名单，于6月13日下午下班前报市安办（联系人：许高荣、邱剑楠，电话：2333662，13950759893，邮箱：ptajsk@126.com）。

2、请各县（区、管委会）安办通知辖区内相关企业人员按时参加（参训人员提前15 分钟入场）。

3、本次讲座不收取任何费用。

 

附件：安全管理知识专题讲座报名汇总表            

           

 

                          莆田市政府安办

                                     2018年6月11日
