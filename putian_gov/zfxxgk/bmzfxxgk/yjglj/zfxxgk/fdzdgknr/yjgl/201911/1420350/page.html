关于全面排查整治危险化学品企业安全隐患及安全生产大检查督查情况的通报

发布时间：2011-11-30 08:00
| | |

莆市安监〔2011〕170号

 

 

 

各县（区、管委会）安监局（科）：

根据市安监局《关于印发莆田市全面排查整治危险化学品企业安全隐患实施方案的通知》（莆市安监〔2011〕123号），结合《关于继续深入开展安全大检查切实做好第四季度安全生产工作的通知》（莆安委明电〔2011〕6号）和《关于印发莆田市危险化学品行业安全大检查工作实施方案的通知》（莆市安监〔2011〕160号）文件精神，近期我局对各县（区、管委会）安监局（科）开展全面排查整治危险化学品企业安全隐患及安全生产大检查进行督查。现将督查情况通报如下：

一、总体情况

从这次督查情况看，各县（区、管委会）安监局（科）能够按照市安监局关于开展危险化学品企业安全隐患全面排查整治及安全生产大检查工作部署，强化组织领导，落实监管责任，督促危险化学品企业落实主体责任，积极开展相关工作，建立健全排查治理工作机制，注重对危险化学品在生产、经营、储存、运输、使用等各环节中事故隐患开展日常巡查，发现存在安全问题责令限期整改，督促企业及相关部门按照措施、责任、资金、时限和预案“五到位”的要求，切实抓好整改落实工作。同时，各县（区、管委会）安监局（科）在推进企业全面开展安全生产标准化建设方面做了较全面的动员布署工作，从而有效督促企业按照法律法规要求，健全管理制度，加大安全投入，强化“三级”教育，完善应急预案，配备安全生产管理人员，加强日常安全管理，从本质上提高企业安全生产水平。

二、存在问题

此次督查也发现了一些问题，部分县(区、管委会)安监局（科）虽然制定了安全隐患排查治理活动实施方案，但方案的落实不够到位，相关工作进展缓慢；部分县(区、管委会) 安监局（科）人员变动较大，日常安全监管未能全面开展，监管台帐不健全。此外，仍有部分危化品企业主体责任落实不到位，隐患排查治理存在盲区，安全教育培训流于形式，职业危害防护设施不完善，未按标准配备安全设施设备，规章制度未上墙等。督查发现的主要问题及隐患情况见附件。

三、下一步工作意见

一要进一步加强日常安全监管，持续深入开展安全隐患排查整治，切实抓好各类隐患整改。要以此次隐患排查整治和安全生产大检查为契机，继续强化对危化品从业单位的日常监管；要针对此次督查发现的问题，督促危化品从业单位加强安全生产管理，认真排查治理事故隐患，完善并严格落实各项安全规章制度，特别要加大对企业落实安全风险评估制度和全面日常管理、隐患排查治理工作的监督检查力度，督促企业增加安全投入，改善安全生产条件；强化过程执法，对违反操作规程或对隐患整改工作不及时的单位，加大处罚力度，切实提高安全保障水平。

二要大力推进危化品从业单位开展安全生产标准化建设，督促企业配备必要的专业人员或中介机构签订技术服务协议，改善安全技术和管理水平。要重点抓好企业负责人、安全管理人员和特种作业人员教育培训，严格落实岗前培训和持证上岗制度。在完善软件建设的同时，要重视安全设施和作业环节的管理，切实通过开展标准化活动，提升企业本质安全水平。

三要不断加强学习培训，提高业务水平。要以此次新修订的危险化学品安全管理条例的颁布实施为契机，采取多种形式，组织乡（镇、街道、园区）安监站监管人员加强对新条例及配套规章的学习，持续提高危险化学品安全监管人员的执法水平和依法行政能力；要进一步完善落实危险化学品监管部门联席会议制度，及时研究协调解决危化品安全监管工作中存在的问题。

此次督查发现问题的整改情况，请各县（区、管委会）安监局（科）采取有效措施，认真整改落实，并将整改落实情况于2011年12月20日前报送市局三科。联系人:徐智伟，联系电话： 13850259862，E-Mail:fjptajj@163.net。
