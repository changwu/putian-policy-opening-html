莆田市人民政府安委会办公室关于对星级酒店旅行社风景区公园开展安全督查情况的通报

发布时间：2011-09-30 08:00
| | |

莆市安办〔2011〕62号

 

 

各县（区）人民政府（管委会），市直有关部门：

为了做好我市“一会一节”安全生产工作，根据市委、市政府有关安全生产指示精神，9月23日至28日，市政府安办组织市旅游局、市住建局、市质量技术监督局、市消防支队、市林业局等部门对全市星级酒店、旅行社、风景区、公园开展节前安全生产工作督查。现将有关情况通报如下：

一、督查情况

本次督查最佳西方恒丰酒店、壶兰大酒店、山水旅行社、假日旅行社、九鲤湖、九龙谷、凤凰山公园、体育公园等企业。督查组采取听取汇报、查内业资料、现场检查并反馈。重点检查内容为：1、安全生产责任制的落实情况。企业法人负责制及主要负责人、分管负责人、安全管理人员、各岗位安全生产责任制的建立及落实情况；2、安全生产法律法规、标准规定的执行情况。设立安全生产管理机构和配备专(兼)职安全管理人员情况；特种设备安全管理制度和岗位安全操作规程的建立、执行情况；3、隐患排查整改安全台帐建立落实情况。星级宾馆（饭店）的重要设施、装备的完好状况及日常维护、保养情况；A级景区内的特种设备的完好状况及检验检测情况；旅游活动的重点时段、重点环节、重要部位防范措施的落实情况；4、应急管理情况。制定应急预案和应急演练情况；按照有关部门规定配备应急救援装备情况；建立应急救援队伍或与相关应急队伍开展协作情况；5、安全基础工作及教育培训情况。企业主要负责人、安全管理人员、特种作业人员的持证上岗情况；生产一线员工(包括临时务工人员)的安全教育培训情况。

督查中发现，我市星级酒店、旅行社、风景区、公园大部分能够重视安全生产工作，按照上级有关安全生产工作的具体要求，成立安全领导机构，层层签订安全生产责任状，参加安全知识和安全技能培训并组织应急预案演练，加大投入，消除安全隐患。

在督查中也发现，部分企业的安全管理不到位，普遍存在问题有：1、安全生产职责分工不明确，安全管理人员没按规定参加安全培训，特种作业人员证件过期未参加复审；2、安全文化氛围不够，缺少安全警示标志，部分安全警示标志不醒目；3、日常隐患排查安全台帐不规范，缺少具体的整改反馈记录；4、事故应急救援预案未及时修订，编制不符合导则要求，应急演练未形成记录；5、安全卫生条件欠佳，有的景区景点和餐馆饭店安全卫生有待加强。（具体督查情况见附表）

二、下一步要求

（一）各级各行业主管部门要认真落实“一岗双责”规定，切实负起安全监管责任，做好国庆期间的安全生产工作，对星级酒店、旅行社、风景区、公园进行全面的安全隐患排查并督促企业整改落实到位，，确保节假日期间安全。

（二）对本次督查发现的问题，请有关县（区）人民政府（管委会）和主管部门要督促有关企业认真整改，并将整改落实情况于10月30日前书面报市政府安办（联系人：张玉栋，联系电话：2230918，传真：2339655。

    

 

 

 

二〇一一年九月三十日
