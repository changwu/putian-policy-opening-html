关于抓好省政府“五一”黄金周安全生产工作督查组检查隐患整改落实的通知

发布时间：2006-04-30 08:00
| | |

 

莆市安[2006]7号

 

 

 

涵江区、秀屿区人民政府、湄洲岛管委会、市直有关单位：

    2006年4月27日至28日，省政府“五一”黄金周安全生产工作督查组对我市贯彻落实国务院安全生产委员会办公室《关于认真做好“五一”黄金周及汛期安全生产工作的通知》精神，以及“五一”黄金周期间安全生产工作情况进行督查。督查组对我市贯彻落实国家、省有关“五一”黄金周期间安全生产工作精神以及开展情况是比较满意的，但在督查抽查中也发现了一些单位仍不够重视安全，存在不少隐患，安全形势不容乐观。为切实抓好事故隐患的整改工作，现将省政府督查组督查发现的问题予以分解，要求涵江区政府、秀屿区政府、湄洲岛管委会及相关行业主管部门尽快制定整改措施，落实整改责任和时限，并加强监督检查，确保整改到位。对一时无法整改的，也要制定整改方案，落实防范措施，确保安全。各单位要把落实情况于5月20日前以书面形式报送市政府安办（联系电话：2223322；传真：2339655）。市安办将在近期内进行跟踪督查。
