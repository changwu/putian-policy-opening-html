关于加强烟花爆竹禁燃宣传工作的通知

发布时间：2016-01-18 08:00
| | |

莆市安办〔2016〕3号

 

各县（区）人民政府（管委会），市直各有关单位：

根据市委、市政府领导有关批示指示精神，按照《莆田市加强烟花爆竹销售、燃放管理规定》（莆政办〔2015〕22号）要求，为切实做好我市烟花爆竹禁燃宣传工作，现将有关事项通知如下：

一、禁燃区域及地点

（一）禁止在下列地点燃放烟花爆竹

文物保护单位保护范围内；车站、码头等交通枢纽以及铁路线路安全保护区内；易燃、易爆危险物品生产储存场所及其周边100米范围内；输变电设施安全保护区内；医疗机构、幼儿园、学校、敬老院；城市主次干道及高架路、过街天桥、立交桥、隧道；商场、超市、影(剧)院等人员密集的公共场所；林地、绿地、苗圃等重点防火区。

（二）禁止在下列区域燃放烟花爆竹

市中心城区（荔城区、城厢区）：东圳水渠（市检察院至广化寺）——城厢区人民政府——江鸿路——荔园路——东圳路——东圳水渠（市检察院）。

仙游县：北至学府路（北一环路）、南至木兰溪（含鲤南镇柳坑社区中亥亭岭街以北老城区）、西至城象线（喇叭口）、东至东一环路。

涵江区：涵东街道，涵西街道，商场管委会，国欢镇码头村部分区域（公园西路以南、西环城路以东）。

秀屿区：笏石镇的前线路、八二0路、工农路、大众路、顶社村下街、三门井、下桥头、三社头及土埕路以东、前线路以西、工农路以南区域。

二、工作分工

各县（区）人民政府（管委会）：负责组织实施本辖区禁燃宣传工作，落实工作经费保障。

市交通运输局：负责在城市公交车、出租车、客运车站等场所开展宣传工作。

市教育局：负责在禁燃区各中小学校开展“禁燃”主题教育活动。

市民宗局：负责在禁燃区宗教活动场所开展宣传工作。

市住建局：负责在禁燃区物业小区开展宣传工作。 

市工商局：负责向禁燃区个体商户开展宣传工作。

市商务局：负责在禁燃区商场、超市等场所开展宣传工作。

市民政局：负责在禁燃区养老院、福利院等场所开展宣传工作。

市文化新闻出版局：负责在禁燃区文化市场、经营性文化娱乐场所等公众聚集场所开展宣传工作。

其他机关、团体、企事业单位：负责组织本系统、本单位员工及本行业管理对象的宣传工作。

三、工作要求

（一）提高思想认识。要充分认识烟花爆竹禁燃行动对改善我市大气环境质量、创建文明城市和保护群众生命财产安全的重要意义，根据实际情况，制定宣传计划，切实履行烟花爆竹禁燃行动宣传教育主体责任。

（二）丰富宣传方式。要调动一切社会资源，充分运用广播、电台、电视、报纸及互联网等新闻媒体和标语、横幅、宣传册、手机短信等形式，广泛宣传烟花爆竹管理相关政策和销售燃放规定，让烟花爆竹禁燃工作家喻户晓、人人皆知，为烟花爆竹禁燃工作营造良好的舆论氛围

（三）加强信息报送。要积极汇总收集本地区、本行业领域烟花爆竹“禁燃”工作动态，编写工作信息，每周五上午下班前向市安办报送一条工作信息（报送截止时间为2月29日）。邮箱：ptsab@sina.com

附件：禁燃宣传标语

 

               莆田市人民政府安全生产委员会办公室
