转发福建省人民政府安委会办公室关于进一步加强文物建筑消防安全工作的通知

发布时间：2019-05-21 11:38
| | |

 

莆市安办〔2019〕21号

 

 

各县（区）人民政府（管委会）安委会：

现将省安办《关于进一步加强文物建筑消防安全工作的通知》（闽安委办〔2019〕27号）转发给你们，请认真贯彻落实习近平总书记关于文物、博物馆安保工作的重要批示精神，深刻汲取历年来我市文物建筑火灾事故教训，严格落实文物建筑消防安全责任制，建立健全常态化巡查检查工作机制，大力推进文物建筑消防安全标准化管理，科学制定各项防范措施，全面加强全市文物建筑消防安全工作。

5月25日前，请各县（区、管委会）文物主管部门牵头负责对本辖区内文物建筑进行梳理，摸清底数。对地理位置偏远、消防设施缺乏、管理人员不足的文物建筑，要先行研究管控措施，重点解决存在突出问题，有效推动日常管理人员招聘配备、消防设施建设经费保障等措施落实。

 

莆田市人民政府安全生产委员会办公室

                     2019年5月17日

福建省人民政府安委会办公室关于进一步

加强文物建筑消防安全工作的通知

闽安委办〔2019〕27号

 

各设区市人民政府及平潭综合实验区管委会安委会：

2019年5月1日，宁德市霞浦县沙江镇竹江村前澳天后宫发生火灾，着火建筑全部烧毁坍塌，事故原因正在调查中。事故虽未造成人员伤亡，但该起火灾发生在全国开展博物馆和文物建筑消防安全大检查期间，着火建筑属省级文物保护单位（清代建筑），引起各级领导高度关注，在社会产生较大影响。省政府领导作出重要批示，应急管理部在“五一”节日应急值守视频调度会上对这起火灾事故进行了通报。该起事故暴露出我省文物建筑消防安全基础仍较薄弱，特别是一些单位存在消防安全主体责任落实不到位、火灾风险防控不到位、监管部门信息沟通不到位等问题。为深刻吸取事故教训，举一反三，有效防范类似事故的发生，落实省领导批示要求，现将进一步加强我省文物建筑消防安全工作通知如下：

一、严格落实文物建筑消防安全责任制。据统计，自2009年以来，我省共发生各类文物建筑火灾事故37起（近10年全省文物建筑火灾形势分析见附件），其中有2起被国家文物局通报。文物建筑是国家重要的历史文化遗产，是国家文明的重要标志，保护文物建筑安全的责任重于泰山。各地、各有关部门要充分认清当前文物建筑消防安全形势的严峻性，认真贯彻落实省委、省政府领导关于消防安全工作的指示批示要求，严守文物建筑消防安全红线、底线，深刻汲取火灾事故教训，进一步增强做好文物建筑消防安全工作的责任感、紧迫感和政治敏感性。要全面落实省政府办公厅《关于进一步加强文物安全工作若干措施的通知》（闽政办〔2018〕11号）和《福建省消防安全责任制实施办法》要求，逐一夯实文物建筑的政府属地管理责任、部门监管责任和文物建筑单位的主体责任。省文旅厅要牵头负责对全省文物建筑进行梳理，分地区逐一明确行业主管部门，并告知属地政府、行业管理部门以及公安、住建、消防部门。省公安厅要督促公安派出所在消防机构转制过渡期继续依法履行好消防工作职责。各职能部门依各自监管责任履行消防安全工作责任，共同督促文物建筑单位严格落实消防主体责任。

二、深入开展文物建筑消防安全巡查检查。各地要建立文物建筑消防安全常态化排查机制，督促各乡镇街道、村（居）委会将属地文物建筑消防安全纳入日常“网格化”管理，加大对文物建筑的日常巡查力度，确保能及时发现问题、处置问题。在重大节庆和大型活动期间进行重点盯防，督促严格规范用火用电用气用油管理，强化火灾防控措施。要结合“防风险保平安迎大庆”消防安全执法检查专项行动，深入开展文物建筑消防安全检查，督促文物建筑管理单位认真开展消防隐患自查自纠，对照大检查发现的问题，逐一落实整改措施，坚决确保消防安全。对逾期不改的消防安全隐患问题，各地文物、消防部门要坚决依法处理；一时整改不了的，要纳入政府挂牌督办，属地文旅（文物）部门要督促单位落实整改经费，提高防范等级，加强值班巡查，做到严防死守。省文旅厅、民族宗教厅、文物局、消防总队要联合组织对各地文物建筑火灾防控措施落实情况开展检查，强化监管合力，推进责任落实。

三、推进文物建筑消防安全标准化管理。各地文旅（文物）和消防部门要联合组织文物建筑消防安全责任人和管理人员开展火灾警示教育和消防业务培训，督促文物建筑对照《文物建筑消防安全管理十项规定》、《文物消防安全检查规程》以及消防安全“四个能力”建设等要求，开展消防安全标准化管理工作，结合“文物平安工程”建设，因地制宜改善文物建筑消防安全设施条件，提升文物建筑本质安全。各地、各有关部门要积极协调主流媒体，密集刊播消防专题节目和消防安全提示，在各类户外视频、楼宇电视滚动播出消防公益广告。制作高质量文物建筑火灾案例警示片、挂图、宣传册，通过各类途径广泛开展警示性宣传，强化文物单位管理人员和当地群众消防安全意识。要落实“四个一批”要求，曝光久拖不改的隐患单位，通过舆论监督推进隐患整改。各地消防部门要制定完善文物建筑灭火应急救援预案，做到“一场所一预案”，组织指战员开展现场演练；要指导重点文物建筑单位建立消防管理团队和专职消防队，配备消防装备器材，完善联防联控机制，提高自防自救能力。

四、依法依规严肃事故调查和责任追究。宁德市政府安委会要对霞浦“5·1”火灾事故查处实行挂牌督办，霞浦县政府要认真组织事故调查，查清原因和责任，启动火灾事故责任单位和责任人的追究工作。各地要深刻吸取霞浦“5·1”火灾事故教训，在文物建筑大排查基础上，于5月25日前，对本地区地理位置偏远、消防设施缺乏、管理人员不足的文物建筑进行梳理，从加强文物建筑日常管理人员招聘配备和消防设施建设经费保障等方面，分别制定针对性防控措施，落实重点管控，推动本地区文物建筑消防安全工作落到实处。

福建省人民政府安全生产委员会办公室

近10年全省文物建筑火灾形势分析

 

2009年以来（截至2019年5月6日），全省共发生各类文物建筑火灾37起，未造成人员伤亡，统计直接财产损失190万元。发生火灾的文物建筑部分还是省级以上文保单位，舆论关注高、社会影响大，造成的影响损失无法估量和挽回。经分析，近10年全省文物建筑火灾形势主要有以下四个特征。

一、部分地区文物建筑火灾多发。分析文物建筑起火的地区，其中泉州7起（鲤城区3起），福州5起（鼓楼区4起），南平5起，宁德5起（霞浦和屏南县各2起），龙岩5起（永定区3起），厦门4起（均在同安区），三明4起，莆田2起。

二、冬春季节文物建筑火灾高发。从月份分布上看，文物建筑火灾多集中在冬春季节。据统计，发生在1至5月份的文物建筑火灾共26起，占总起数的72%。主要因为冬春季节各地传统节日文化气氛浓厚，民俗节庆活动增多，烧香礼佛、敬神祭祖、烧纸、燃放烟花爆竹等活动剧增，致灾因素增多，发生火灾机率大。

三、入夜时段文物建筑火灾集中多发。从发生火灾的时段分布看，16时至18时、20时至22时各6起，02时至04时、14时至16时、18时至20时各4起，00时至02时、10时至12时各3起，08时至10时、22时至24时各2起，04时至06时、06时至08时、12至14各1起。16时至22时，文物建筑共发生火灾16起，占全天各时段起数的44%。

四、生活用火不慎和电气线路故障是主因。分析文物建筑火灾原因，生活用火不慎12起、电气线路故障7起，分别占总数的32%和19%，其中生活用火不慎中的敬神祭祖引发火灾为9起，占25%。另外，放火5起，雷击2起，玩火3起，吸烟1起，原因不明4起，其他原因3起。
