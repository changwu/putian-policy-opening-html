关于立即全面排查整治危险化学品事故隐患的通知

发布时间：2015-04-12 08:00
| | |

 莆市安监〔2015〕20号

 

 

 

各县（区）安监局：

根据省政府安办《关于深刻吸取漳州腾龙芳烃“4·6”事故教训全面排查整治事故隐患的通知》（闽安委办〔2015〕22号）精神，市局决定立即在全市全面排查治理危险化学品事故隐患，现将有关事项通知如下：

  一、检查对象

    1、危险化学品生产、储存经营企业和使用危险化学品从事生产的化工企业。

  2、涉氨制冷企业液氨使用。

二、重点检查内容

1、安全生产责任体系建立情况。是否按照新《安全生产法》、《化工（危险化学品）企业保障生产安全十条规定》、《福建省危险化学品企业负责人安全生产“九确保”》、《企业安全生产责任体系五落实五到位规定》等要求，建立健全各岗位安全生产责任人、责任范围和考核标准，做到“五落实五到位”。

2、安全生产规章制度和操作规程制定执行情况。是否按照新《安全生产法》、总局41号、45号、55号、57号令和《涉氨制冷企业液氨使用专项治理培训教材提纲》等要求，结合实际，制定并严格执行各类安全生产规章制度和操作规程。新建、改建、扩建是否落实安全设施“三同时”制度。

3、安全生产教育培训计划制定实施情况。是否按照新《安全生产法》、总局3号、30号和44号令等要求，制定实施安全生产教育培训计划，如实记录安全生产教育和培训时间、内容、参加人员以及考核结果等情况。主要负责人和安全管理人员（包括分管负责人）经安监部门安全生产知识和管理能力考核合格，特种作业人员特别是防爆电气、非危险工艺化工自动化控制仪表安装、维修、维护作业人员持证上岗，从业人员经安全生产教育培训合格后上岗。

4、隐患排查治理制度制定落实情况。是否按照新《安全生产法》、总局16号令、《危险化学品企业事故隐患排查治理实施导则》和《福建省危险化学品生产储存企业专家安全检查制度指导意见》等规定，建立健全并落实隐患排查治理制度和聘请专家定期排查隐患制度，把隐患排查治理责任落实到每个部门、每个岗位和各岗位操作人员。重大隐患是否按规定及时上报。

5、自动化控制系统的改造和运行情况。涉及危险工艺和重点监管危化品的装置是否按规定完成自动控制系统改造。危化品重大危险源是否按照总局40号令落实各项安全管理要求，建立健全安全监测监控体系、完善控制措施。自动控制系统、监测监控系统是否适用并有效维护、正常运行，是否对相关安全设施、仪表控制系统、安全联锁装置等设备设施定期检测合格。

6、作业现场安全管理制度落实情况。是否按照新《安全生产法》、《化学品生产单位特殊作业安全规范》（GB30871-2014)等要求，落实动火、进入受限空间等特殊作业票证管理制度，做到危险作业前风险分析到位、作业许可证会签审批到位、现场监督监护到位、防范措施到位。是否落实对外来施工队伍（承包商）的资质审查、教育培训、现场监督等安全监督和管理。危化品装卸环节是否严格落实危化品发货和装载的查验、登记、核准制度，防止危化品运输车辆超载超装。

7、应急管理制度落实情况。是否按照新《安全生产法》、总局17号令、《企业安全生产应急管理九条规定》、《生产经营单位生产安全事故应急预案编制导则》（GB/T29639-2013）、《危险化学品单位应急救援物资配备要求》（GB30077-2013）、《生产安全事故应急演练指南》（AQ/T9007-2011）、《生产安全事故应急演练评估规范》（AQ/T9009-2015）、《液氨泄漏的处理处置方法》（HG/T4686-2014）等要求，组织修订应急救援预案并定期组织开展应急演练、评估。是否建立应急救援组织，配备必要的应急救援器材、设备和物资，并进行经常性维护、保养，保证正常运转。

三、检查组人员组成

在企业开展自查自纠的基础上，市局分三组开展检查督查。

第一组，佘国华、邱剑楠、属地县（区）危化品监管人员2人、专家2人，检查中央属危化品生产、储存经营企业。

第二组，吴爱红、陈启晶、属地县（区）危化品监管人员2人、专家2人，检查除中央属以外的其他危化品生产、储存经营企业。

第三组，许高荣、曾福添、属地县（区）危化品监管人员2人、专家2人，检查涉氨制冷企业液氨使用，每个县（区）抽查2家。

检查具体时间由各组与相关县（区）联系确定。

四、工作要求

1、各县（区）安监局要立即将本通知精神传达到各属地危化品企业，指导督促企业立即开展自查自纠，企业隐患排查治理的情况，务必于4月20日前报县（区）安监局。

2、各县（区）安监局要立即组织力量对本辖区所有危化品企业进行全面检查，检查情况和企业自查情况于4月30日前将报市局。

3、分组检查督查要以专家对照国家有关危化品安全生产法律法规和标准以及重点检查内容进行检查为主，检查发现的安全隐患由属地县（区）安监局负责督促企业落实整改。

4、检查组要认真遵守廉洁自律的有关要求，严格执行党风廉政建设的有关规定。专家工作补贴由市局参照省政府安委员会《福建省安全生产专家工作补贴管理暂行规定》（闽安委办〔2014〕61号）的补贴标准给予补贴，不得向企业摊派。

 

 

                               莆田市安监局

                                2015年4月12日
