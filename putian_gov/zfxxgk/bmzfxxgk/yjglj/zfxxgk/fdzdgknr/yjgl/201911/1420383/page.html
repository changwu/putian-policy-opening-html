关于印发莆田市深入开展涉氨制冷企业液氨使用专项治理工作实施方案的通知

发布时间：2013-11-07 08:00
| | |

莆市安〔2013〕19号

 

各县（区）人民政府（管委会），市直有关部门：

为贯彻落实《国务院安委会关于深入开展涉氨制冷企业液氨使用专项治理的通知》（安委〔2013〕6号）和《福建省人民政府安全生产委员会关于印发深入开展涉氨制冷企业液氨使用专项治理工作实施方案的通知》（闽安委〔2013〕24号）精神，经市政府同意，现将《莆田市深入开展涉氨制冷企业液氨使用专项治理工作实施方案》印发给你们，请认真组织实施。

 

莆田市人民政府安全生产委员会　　　　

                           2013年11月7日

莆田市深入开展涉氨制冷企业

液氨使用专项治理工作实施方案

 

为贯彻落实9月29日全国深入开展涉氨制冷企业液氨使用专项治理电视电话会议精神，深刻吸取上海翁牌冷藏实业有限公司“8·31”重大氨泄漏事故教训，根据《国务院安委会关于深入开展涉氨制冷企业液氨使用专项治理的通知》（安委〔2013〕6号）和《福建省人民政府安全生产委员会关于印发深入开展涉氨制冷企业液氨使用专项治理工作实施方案的通知》（闽安委〔2013〕24号）的工作要求，市政府决定从即日起至12月底，在全市深入开展涉氨制冷企业液氨使用专项治理工作（以下简称专项治理），现制定以下工作方案：

一、工作目标任务

依据安全生产、危险化学品管理、特种设备等有关法律法规和标准规范，对全市涉氨制冷企业液氨使用情况全面开展大检查、大治理，实现安全培训全覆盖、安全隐患排查治理全覆盖、治理检查全覆盖，取缔关闭一批不具备安全生产基本条件的非法违法企业，治理整改一批液氨使用存在安全隐患的企业，提升一批安全管理基础较好的企业，有效遏制事故发生，全面提升企业安全管理水平。

二、工作重点

（一）凡存在以下情形的涉氨制冷企业，一律依法取缔关闭：

1.相关证照不全的；

2.停产整顿未验收达标擅自恢复生产的；

3.存在重大安全隐患，且无法整改的；

4.不具备安全生产基本条件的。

（二）凡达不到以下要求的涉氨制冷企业，立即责令停产停业整改，并经政府有关部门验收合格后方可生产经营：

1.冷库及制冷系统应由具备冷库工程设计、压力管道设计资质的设计单位设计；

2.包装间、分割间、产品整理间等人员较多生产场所的空调系统严禁采用氨直接蒸发制冷系统；

3.液氨管线严禁通过有人员办公、休息和居住的建筑物；

4.氨制冷机房贮氨器等重要部位应安装氨气浓度检测报警仪器，并与事故排风机自动开启联动；

5.压力容器、压力管道及其安全附件应定期检验；

6.库区及氨制冷机房和设备间（靠近贮氨器处）门外应按有关规定设置消火栓，应急通道保持畅通；

7.构成重大危险源的冷库，应登记建档、定期检测、评估、监控等。

（三）凡达不到以下要求的涉氨制冷企业，立即整改，限期完成：

1.氨制冷机房贮氨器上方应设置水喷淋系统；

2.在厂区内显著位置应设风向标；

3.压力容器、非专业操作人员免进区域、关键操作部位等应设置安全标识；

4.作业现场应配置空气呼吸器、橡胶手套等防护用具和急救药品；

5.企业应建立健全并落实液氨使用的有关安全管理制度和安全操作规程；

6.涉及液氨制冷的特种作业人员，应取得相关特种作业操作证，持证上岗；

7.企业的从业人员应经过液氨使用管理及应急处置等有关安全知识的培训；

8.企业应建立健全液氨泄漏等事故应急救援预案，并定期组织演练；

9.企业应建立设备管理档案，并妥善保存。

三、组织领导与工作分工

市政府成立涉氨制冷企业液氨使用专项治理工作领导小组，市政府分管领导任组长，市府办、经贸委、外经局、农业局、海洋与渔业局、旅游局、住建局、城管执法局、工商局、质监局、安监局、消防支队、环保局、气象局等分管领导为成员，主要负责对全市专项治理工作实施统一领导，督促、指导、协调专项治理工作。领导小组办公室设在市政府安办，主任由市政府安办主任担任，负责日常的组织、协调、督促、指导工作。

市经贸委、外经局、农业局、海洋与渔业局、旅游局、住建局、城管执法局、工商局、质监局、安监局、消防支队、环保局、气象局等市直有关部门按照“一岗双责、管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，负责本行业（领域）专项治理工作，切实落实部门监管责任，集中时间、集中力量扎实抓好专项治理工作。

四、方法步骤

（一）宣传发动、组织培训（即日起至11月初前）

1.各县（区、管委会）、市直有关部门对本辖区、本行业（领域）的涉氨制冷企业进行一次全面调查摸底，摸清基本情况，建立基础台账（格式见附件），明确工作责任；

2. 各县（区、管委会）、市直有关部门制定本辖区、本行业（领域）专项治理实施方案，深入企业大力宣传液氨使用安全知识和有关安全法规标准，动员企业认真开展专项治理。市直有关部门还应确定本单位分管领导、业务科长各一名作为专项治理领导小组成员、联络员。

3.《涉氨制冷企业液氨使用专项治理培训教材提纲》和《涉氨制冷企业执法检查表》、《涉氨制冷企业自查自改表》，请市、县（区、管委会）经贸、外经、农业、海洋与渔业、旅游、住建、城管执法、工商、质监、安监、公安消防、环保、气象等有关部门到国家安监总局网站机关子站监管四司（http://www.chinasafety. gov.cn/newpage/Contents/Channel_20006/2013/0930/220891/content_220891.htm）查询《关于印发涉氨制冷企业液氨使用专项治理视频讲座培训教材提纲和执法检查表企业自查自改表的通知》（管四函〔2013〕25号）并下载打印。各级各有关部门把《涉氨制冷企业自查自改表》印发给参加专项治理检查的每位监管人员。县（区、管委会）有关部门把《涉氨制冷企业液氨使用专项治理培训教材提纲》和《涉氨制冷企业自查自改表》印发给所有涉氨制冷企业；

4.各县（区、管委会）、市直有关部门组织本辖区、本行业（领域）有关监管人员、所有涉氨制冷企业主要负责人、分管安全负责人、安全部门和制冷车间负责人参加的安全培训班，以《涉氨制冷企业液氨使用专项治理培训教材提纲》为主要内容，重点培训学习《冷库设计规范》（GB50072-2010）、《冷库安全规范》（GB28009-2011）和危险化学品使用管理、特种设备、消防管理等有关法律法规，明确本次专项治理的工作要求。

（二）自查自改、治理整改（11月初至12月上旬）

1.涉氨制冷企业要按照相关法规标准的要求，组织全员安全培训，重点培训学习《涉氨制冷企业液氨使用专项治理培训教材提纲》；对照《涉氨制冷企业自查自改表》的要求，认真进行自查自改，并于2013年12月上旬将本企业开展自查自改的情况报送制冷企业行业管理部门，同时抄送县（区）安监局；

2. 各县（区、管委会）、市直有关部门要组织有关监管人员和专家深入企业，按照液氨使用的有关法规标准和专项治理的要求，帮助指导和推动企业落实全员安全培训和自查自改工作。同时，按照《涉氨制冷企业执法检查表》的要求，进行全覆盖的监督检查，做到不留死角、不留盲区。

（三）检查验收、全面总结（12月中旬至12月底）

1.各县（区、管委会）、市直有关部门要组织开展专项治理检查，对专项治理检查情况进行全面总结分析；

2.市政府安委办要组织各县（区、管委会）开展交叉互检（互检方案和具体要求另行通知），同时组织联合督查组对各县（区、管委会）、市直有关部门开展专项治理情况进行检查，并将检查情况予以通报。

五、工作要求

（一）加强组织领导。各级政府要相应成立专项治理领导小组和办公室，按照“党政同责，一岗双责，管行业必须管安全，管业务必须管安全，管生产经营必须管安全”的要求，建立政府领导、协调联动、联合执法、社会监督、综合治理的工作机制，明确责任，狠抓落实，注重实效。要切实落实企业安全生产主体责任、部门监管责任和政府属地管理责任，集中时间、集中力量扎实抓好专项治理工作。

（二）坚持统筹兼顾。各级各有关部门要把本次专项治理作为深化安全生产大检查的重要工作来抓，按照“全覆盖、零容忍、严执法、重实效”的要求，与“打非治违”有机结合，采取明查与暗访、回访检查等方式，彻查安全隐患，严防事故发生；要与推动企业安全生产标准化建设有机结合，不断提升企业本质安全水平，推动企业转型升级。

（三）做好宣传报道。各级各有关部门要充分发挥主流媒体的作用，对抓得好的地方和企业及时进行正面宣传表扬，总结推广好的经验做法；对落实不到位的地区进行通报批评，对安全培训、自查自改等不落实的企业向社会公开曝光。

（四）严格依法办事。对没有开展专项治理、存在安全隐患的企业，要依法从严处理；对检查发现存在重大安全隐患的企业，要责令停产整顿或限期整改，及时消除安全隐患；对非法生产经营的企业，一律依法予以取缔；对整改不到位，导致发生事故的企业，要严格按照“四不放过”和“科学严谨、依法依规、实事求是、注重实效”的原则，查明原因，分清责任，依法依规严肃处理，并及时向社会公布调查处理结果。

各县（区）人民政府（管委会）、市直有关部门要及时总结和发现专项治理工作中的经验和问题，保持信息畅通，做到及时反馈。同时将本单位专项治理实施方案（连同领导小组成员及联络员）和工作总结（连同基础台账）分别于11月15日和12月20日前以书面形式上报市政府安委办。联系人：许高荣，联系电话：2333662，传真：2392566，电子邮箱：ptajsk @126.com。
