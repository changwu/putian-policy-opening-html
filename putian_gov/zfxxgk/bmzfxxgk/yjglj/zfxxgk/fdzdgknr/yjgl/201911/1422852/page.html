关于开展危险化学品单位防爆电气作业人员安全技术培训考核的通知

发布时间：2011-10-19 08:00
| | |

莆市安监〔2011〕156号

 

 

 

各县(区、管委会)安监局（科），中石化、中石油莆田分公司：

为认真贯彻落实《国务院关于进一步加强企业安全生产工作的通知》（国发〔2010〕23号）、省政府《意见》（闽政〔2010〕22号）、市政府《实施意见》（莆政综〔2011〕2号）精神，深入开展全市特种作业人员持证上岗专项执法检查活动，根据《特种作业人员安全技术考核管理规定》（国家安监总局令第30号）等有关规定，决定开展全市危险化学品单位防爆电气作业人员安全技术培训考核。现将有关事项通知如下：

一、培训考核对象

全市涉及使用防爆电气设备的危险化学品生产、储存、经营、使用单位（含加油站，下同）负责防爆电气设备安装、检修、维护的专、兼职防爆电气作业人员。

二、培训考核内容

按照国家安监总局《防爆电气作业人员安全技术培训大纲和考核标准》规定的内容、项目、学时等要求，进行安全技术培训考核。

三、培训考核组织

各县(区、管委会)安监局（科）负责督促辖区内的危险化学品单位防爆电气作业人员参加安全技术培训考核。

四、其他事项

1、防爆电气作业人员安全技术培训必须由具备三级以上特种作业安全培训资质的安全培训机构承担。

2、各危险化学品单位应积极主动组织防爆电气作业人员参加特种作业安全技术培训考核，依法持证上岗。

3、对涉及使用防爆电气设备的危险化学品单位却无防爆电气作业人员的或聘请无防爆电气作业操作证的人员上岗的，各县(区、管委会)安监局（科）要依法进行查处。

请各县(区、管委会)安监局（科）立即将本《通知》发至辖区内使用防爆电气设备的危险化学品单位，并于2011年11月10日之前，将辖区内涉及使用防爆电气设备的危险化学品单位防爆电气作业人员持证上岗情况表（见附件）报送市局应急中心，联系人：许高荣，联系电话：2223322，传真：2336128。
