关于近期我市几起安全事故情况的通报

发布时间：2007-02-09 08:00
| | |

 

莆市安[2007]1号

 

 

 

各县（区、管委会）、市直有关部门：

    今年以来，全市相继发生了几起安全事故，给人民群众生命财产造成了重大损失，在社会上造成了较大的负面影响。现将有关事故情况通报如下：

    1月19日17：00左右，秀屿区平海镇一艘养殖船在平海村海区沉没，造成2人失踪。

    1月20日00：30左右，一艘宁德籍货轮“海通 116号”（总吨495T、船长57.4米）在我市湄洲岛附近海域翻沉，造成8人失踪。

    1月29日19：50左右，涵江区江口镇石狮村山兜自然村一非法地下烟花爆竹加工小作坊发生爆燃，造成1人受伤。

    2月7日15：00左右，秀屿区埭头镇汀岐村一手扶拖拉机到潘宅村运载石料，在返程途中掉落于山坡下，造成3人死亡。

    上述几起安全事故的发生，说明我市安全生产方面存在不少问题，安全生产形势较为严峻。主要是：一是一些地方政府领导对安全生产工作的认识不到位，安全生产责任不够落实；二是部分行业主管部门安全监管工作不到位，一些重点行业和领域的事故隐患排查不全面、整改不彻底；三是部分企业主体责任不落实，从业人员安全意识不强、安全操作技能不高，违规指挥、违章操作等现象大量存在。

    为认真吸取上述安全事故的深刻教训，切实加强安全监管，防止类似事故再次发生，推动我市安全生产形势稳定好转，现提出如下要求：

    一、全面落实安全生产责任制。安全生产事故的发生其主要原因之一就是安全生产责任制没有得到全面落实，总有某一个方面或某一个环节出现工作上的疏漏。为此，要强化各级政府行政首长和企业法定代表人两个责任制，政府是安全生产监管主体，企业是安全生产责任主体。各级各部门要以对党和人民生命财产高度负责的精神，把严格管理、严格要求贯穿到安全生产监管的全过程，落实到每个环节、每个企业、每个岗位和每个职工上，坚决克服监管不力现象。各企业的法定代表人必须切实负起责任，自觉接受政府的有效监管、行业部门的有效指导和社会的有效监督，健全安全制度，加强安全管理，形成企业强化安全基础工作、劳动者自我约束的安全生产工作长效机制。

    二、继续深化专项整治工作。各级各有关部门要切实履行各自的职责，深化各专项整治工作，完善整治方案，明确整治目标，落实整治责任，切实抓好重大事故隐患的整改，强化重大危险源的监管工作。特别要重点抓好烟花爆竹、道路交通、水上交通、消防火灾、危险化学品、非煤矿山、渔业生产等领域的安全专项整治工作，针对关键问题和薄弱环节，采取有效措施深化整治，及时消除安全隐患，严格落实各项安全管理措施，防止重特大事故的发生。

    三、认真抓好节前和节日期间安全生产工作。春节即将到来，工业生产和市场销售进入旺季，人流、物流剧增，交通运输更加繁忙，安全生产工作面临的任务十分繁重。各地、各部门、各单位要认真履行职责，针对节日安全生产工作的特点，结合本地、本部门实际，在节前要认真开展一次全面的安全检查，扎实抓好安全生产工作。认真做好春运安全工作，加强对重点路段、人群的管理，严厉查处超速超载、货车及农用车载客、疲劳驾车、酒后驾车等交通违章行为，严防重特大事故发生。加强对车辆、渡口、渡船的安全管理，落实安全责任制，加大监督检查力度，严防带病运营、非法渡运等而引发事故。要根据气候、客流等的变化督促客运企业采取相应的安全措施，制定和完善相应的应急预案，确保交通运营安全。要认真做好消防安全工作，加强对商场、市场、医院、宾馆及娱乐场所等人员密集的公共场所、易燃易爆场所监管，督促生产经营单位加强管理，确保疏散楼梯、安全出口的畅通，疏散指示标志明确有效和应急照明设备、消防设施完好和正确使用，并认真开展自查，加强日常巡查管理，及时排除隐患。针对不同企业特别是高危企业的特点，做好节日正常生产和停工检修企业的安全监管工作。要加强节日期间烟花爆竹燃放、举办大型娱乐活动的安全管理，按照“谁主办、谁发证、谁审批、谁监管”的原则，落实安全责任，制定周密的安全保卫计划和应急预案，加强现场安全管理，确保大型活动安全、有序。要加强节日期间值班和落实事故报告制度，各级各部门、各单位领导同志要带班，值班人员要坚守岗位、尽职尽责，及时掌握安全生产动态，如实上报情况，不得迟报、缓报，更不能漏报、瞒报。一旦发生险情或事故，要组织力量抢救并妥善处理，把事故危害降到最低限度。

    四、加大事故查处力度。对发生的安全事故，要依照《安全生产法》以及《违法行为处罚规定》、《国务院关于特大安全事故行政责任追究的规定》（国务院302号令）和《福建省人民政府关于重大安全事故行政责任追究的规定》（福建省人民政府第66号令），对负有责任的政府及有关部门领导、企业负责人及事故主要责任人依法追究责任。通过运用经济、行政、法律等手段，打击无视法律、无视监管、无视劳动者生命安全的非法违法行为，维护广大人民群众利益、国家法律尊严和政府监管权威。

 

 

二OO七年二月九日
