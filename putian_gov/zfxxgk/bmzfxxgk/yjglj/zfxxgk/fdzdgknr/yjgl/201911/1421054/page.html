关于进一步加强当前安全生产工作的通知

发布时间：2017-08-16 15:26
| | |

 

 

 

各县（区）人民政府（管委会）安委会，市直各有关单位：

今年以来，全市安全生产形势总体稳定，但近期发生多起事故，给人民群众生命财产造成重大损失。7月19日，城厢区霞林街道北渠屿上段荔园路7号桥旁挡土墙工地，在迎水面勾隙作业时，两人不慎掉入北渠河道溺水，造成2人死亡。7月31日，仙游县枫亭镇一处出租民房，因电动车充电引发火灾，造成2人死亡、1人受伤。7月31日，秀屿区平海镇莆田市金益大明液化气有限公司平海溪边邱山供应站，因燃气泄漏引发爆炸，造成3人受伤。

上述事故充分暴露出部分地区和企业安全生产责任制不落实、安全标准规程执行不严格、隐患排查整治不彻底、安全生产大检查工作不得力、监督管理不认真等突出问题。为深刻吸取事故教训，进一步加强安全生产工作，坚决遏制重特大事故多发的势头，现就有关要求通知如下：

一、严格落实安全生产责任。7月27日，省委常委、副省长周联清在厦门召开专题会议，就做好当前安全生产工作作出重要指示，要求“严格落实安全生产责任，抓基础，抓提升，抓重点，抓规范”。8月14日，李建辉市长主持召开安全生产督导检查专题会议，强调“始终把安全生产摆在日常工作的首要位置，在思想上加深认识、在行动上强化落实，善用法律手段守住这一不可逾越的红线”。各级各部门要认真贯彻落实省、市领导有关安全生产重要指示精神，始终牢固树立“发展决不能以牺牲人的生命为代价”的红线意识，切实加强组织领导，就做好当前安全生产工作进行再动员、再部署，充分认清做好当前安全生产工作的重要性和紧迫性。要认真分析研判本地区、本部门、本单位安全生产形势，紧盯安全生产薄弱环节和问题短板，采取切实有效措施，消除监管盲区，堵塞安全漏洞。要加大督导检查力度，层层压实责任，层层传递压力，全面落实党委政府领导责任、部门监管责任和企业主体责任，将安全生产各项防范措施抓紧、抓实、抓出成效。

二、加大隐患排查整改力度。要针对本地区、本行业实际，进一步深化安全生产大排查、大整治、大检查，各级党政领导亲自带队，各有关部门抽调精干力量，深入生产、经营、建设一线，坚持问题导向，开展全方位、全覆盖、不间断的安全生产巡查、检查，横向到边、纵向到底、不留盲区。要强力推进风险分级管控和隐患排查治理双重预防工作机制，加大隐患排查治理工作力度，对排查出的安全隐患，按照定措施、定标准、定期限、定责任人的要求，分类治理，彻底整改，形成闭环。对检查中发现的安全生产违法行为，要依法从严查处。对存在重大隐患、无法整改到位的，要果断依法采取关停措施，严防“带病”作业。对今年以来国家、省、市督查检查发现的隐患，要加大督办跟踪力度，适时组织开展“回头看”，确保真正整改到位。

三、突出重点行业领域整治。要扎实开展重点行业生产型经营单位改变工业用房、存在“住宿、生产经营、仓储混合”现象的出租房屋、人员密集场所等方面消防安全排查整治工作，严厉查处“三合一”场所。要扎实开展危险化学品综合治理，加强危险化学品生产、储存、经营、运输、使用和废弃处置各环节的安全监管。要加强城镇燃气专项治理，严格执行瓶装燃气销售实名制度，加大“黑气”打击力度。要加大醇基燃料生产、经营、储存、运输和使用环节的查处力度，确保8月20日前治理到位。要深化粉尘防爆专项整治，聚焦爆炸风险高的粉尘涉爆领域，紧盯粉尘作业场所30人及以上的重点企业。要继续深化道路交通、水上交通、建筑施工、学校、旅游、特种设备、渔业船舶等重点行业领域安全专项整治，促进重点行业领域安全状况持续改善。

四、强化应急值班值守工作。要加强厦门金砖会晤等重点、敏感时段值班值守，严格执行领导干部到岗带班、关键岗位24小时值班制度，保证安全生产信息上传下达畅通。要健全安全生产预测预警和应急协调联动机制，完善应急预案，落实应急力量，强化应急演练，做好各项应急准备工作，确保一旦发生事故或险情能快速应对、有效稳控，努力把事故的损失和影响减到最小。要充分利用互联网、报刊、电视、广播和手机短信、微信微博等方式，广泛进行安全常识宣传教育，增强各类人员的安全意识、安全知识和安全技能，提高群众性的自防、自救、互救及逃生能力。

 

莆田市人民政府安全生产委员会办公室

                           2017年8月16日
