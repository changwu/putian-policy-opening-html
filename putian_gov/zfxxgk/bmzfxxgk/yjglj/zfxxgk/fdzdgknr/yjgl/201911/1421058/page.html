关于做好省政府安委会安全生产巡查有关工作的通知

发布时间：2017-11-15 17:13
| | |

 

莆市安办〔2017〕84号

 

                  

 

各县（区）人民政府（管委会）：

根据省政府安委会安全生产巡查组工作行程安排，11月15日—22日将赴各（区）人民政府（管委会）及其相关部门开展安全生产延伸巡查，为认真做好巡查迎检工作。现将有关事项通知如下：

一、延伸巡查工作行程安排表（见附件1）

二、巡查组成员

组  长：丁明干  福建煤监局原副局长

副组长：黄  辉  福建煤监局纪检组副组长监察室主任

成  员：陈祥华  省环境应急与事故调查中心高工

        林文元  省安监局监管四处副处长（联络员）13763835711

        林  财  省公安消防部队副团职参谋

        戴秉富  省林业厅产业处干部

        周春耀  省公安厅交警总队干部

        刘向腾  省安科院高工

        刘碧英  省重大危险源监控中心高工

三、有关事项和要求

1、各级各部门要高度重视此次巡查工作，精心安排，周密部署，成立领导机构，指定专人负责，积极配合巡查组完成巡查工作。巡查期间，相应各县（区、管委会）原则上要安排车辆负责巡查组的巡查和接送工作，如果确有困难，要指定专人与市政府安办提前联系说明，以便统一安排。

2、市政府安办负责协助做好省政府安委会安全生产巡查组对各县（区、管委会）的延伸巡查工作，市政府安办陪同领导和工作人员安排见附件2。

3、市政府安办负责此次巡查的组织协调工作，巡查有关事项可与市政府安办联系，联系人：薛凤池、陈酉鹤，联系电话：2298938、2330086，手机：13959541319、13559399909。

 

附件：1、延伸巡查工作行程安排表

          2、市安监局陪同人员安排表
