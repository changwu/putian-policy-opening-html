关于切实加强2012年中秋、国庆期间及节后安全生产工作的通知

发布时间：2012-09-25 08:00
| | |

 

内部明电

 

 

发往

地址

见报头

签批：

盖章：

黄玉明

等级    特急           部委号：莆安办明电〔2012〕7号

 

 

各县（区、管委会）人民政府，市直各有关单位：

中秋、国庆两节即将来临，这是党的十八大召开前的假期最长的节日。为确保人民群众过一个欢乐、祥和、平安的节日，促进全市安全生产形势持续稳定好转，根据省政府安办《关于切实做好2012年中秋、国庆期间及节后安全生产工作的通知》（闽安委办明电[2012]19号）精神，结合我市实际，就切实做好我市中秋、国庆期间及节后安全生产有关工作通知如下：

一、强化安全责任落实

各级各相关部门要站在迎接党的十八大胜利召开和推动莆田科学发展、安全发展的高度，充分认识做好中秋、国庆期间安全生产工作的重要性，切实把握长假期间安全生产工作的规律和特点，深入贯彻落实市委、市政府近期有关安全生产工作的一系列工作部署，切实加强节日期间安全生产工作领导，落实安全生产“一岗双责”，做到主要领导亲自抓，分管领导负责抓，责任部门具体抓，紧紧盯住安全生产基础薄弱、隐患和问题较多、生产安全事故多发频发的地方和单位，帮助指导督促企业落实安全生产主体责任，有效落实各项安全生产工作措施，坚决防范各类生产安全事故的发生，切实保障人民群众生命财产安全。

二、强化道路交通安全综合整治

各级各相关部门充分估量重大节假日免收小客车通行费政策实施给道路交通安全带来的更大压力，认真分析中秋、国庆期间群众出行大量增加的实际情况，及早做好预案，合理安排，及时疏导，科学应对，确保群众出行安全。要按照《莆田市道路交通运输安全综合整治“三年行动”实施方案和莆田市道路交通运输安全集中整治大会战实施方案》（莆政办〔2012〕159号）文件精神，全面推进综合整治“三年行动”和三个月“大会战”，严格落实客运车辆凌晨2~5点停车落地休息制度。要严格路面巡查执法，严厉打击超载、超速、超员、酒后驾驶、疲劳驾驶、不按规定车道行驶、无证非法载人等严重交通违法违规行为，严防发生群死群伤事故。要加强驾乘人员的安全管理和教育，严格车站码头的安全检查，坚决防止乘客携带易燃、易爆、剧毒等危险物品进站上车（船）。

三、强化安全生产大检查

各级各相关部门要针对当前生产和需求旺季的特点，立足超前防范，结合“打非治违”专项行动、“百日大检查”活动和隐患排查治理体系建设工作，突出消防、旅游、危险化学品等重点行业（领域），突出重点地区、重点环节和重点单位，认真组织开展全面深入检查督查，确保各类安全隐患和非法违法生产经营建设行为及时整治到位。消防要以人员密集场所为重点，着重检查消防通道和紧急疏散通道是否畅通，消防设施是否齐全完好，从业人员是否经过消防安全培训等。对节日期间举办的大型聚集活动，要按照“谁主办、谁负责”的原则，制定严格的安全保障措施，并由公安机关严格审批把关，严防拥挤踩踏等事故发生。旅游景区景点安全要重点检查汽车、游船、索道等游客运载工具和大型游艺设施设备是否检验合格，漂流等旅游项目是否制定了安全防范措施，悬崖等危险路段和危险区域是否设置了安全防护装置和醒目的禁行标志等。危险品安全要重点检查安全生产责任制、管理制度和操作规程是否建立健全并落实，相关人员是否持证上岗，特种设备、压力容器及相关措施是否定期检验，重大危险源的管理、监控情况是否登记备案。其他各行业领域也要根据各自的实际，加强监督检查，切实把事故隐患消灭在萌芽状态，确保节日期间安全生产。同时，各级各相关部门要紧密结合本辖区、本部门实际和第四季度安全生产工作的特点，超前谋划，及早部署，采取有力措施，严把节日期间停产企业复产安全生产验收关，严防节后和第四季度事故反弹，巩固我市安全生产形势持续好转的态势。

四、强化节日应急值守

各级各相关部门要高度重视节日期间值班工作，严格执行领导干部带班和值班人员24小时值班制度，严格落实企业现场带班人员、班组长和调度人员在遇到险情时第一时间下达撤人命令的决定权和指挥权。严格执行事故信息报告制度，全面做好生产安全事故和其他紧急突发事件的信息报送工作，保持安全生产信息渠道畅通。要制定完善节日期间生产安全事故应急救援预案，组织做好各类安全生产专业应急队伍应急准备，加强对重点行业领域、重要设施、重点单位和场所应急准备工作的检查，确保应急组织机构、救援队伍、装备、物资等应急资源落实。一旦发生事故或紧急情况，要及时组织抢险救援，妥善处置。

 

 

 

莆田市人民政府安委会办公室

2012年9月25日

  

 

抄送：市府办，市政府分管领导、分管副秘书长，各县（区、管委会）安办，本办领导。
