关于2016年度全市平安企业考核分类情况的通报

发布时间：2017-06-08 17:12
| | |

 

莆市安监〔2017〕72号

 

 

各有关企业：

    根据《关于进一步深化拓展全市平安创建工作实施意见》（莆综治〔2014〕13号）和《关于印发莆田市“平安企业”创建提升工程行动工作实施方案的通知》（莆平安企〔2014〕1号）精神，市安监局、市综治办、市经信委、市国资委对全市有关企业2016年度开展平安企业创建活动进行检查考评，经综合评定，福建湄洲湾控股有限公司等12个企业为一类平安企业，莆田市国有资产投资有限公司等33个企业为二类平安企业，莆田市公共交通集团有限公司等66个企业为三类平安企业。

被评为平安企业的奖励问题，参照市委办、市府办《关于2016年度全市平安单位考核分类情况的通报》（莆委办〔2017〕37号）有关说明执行。在案（事）件中因被责任追究且受到党纪政纪处分、尚在处分影响期的人员不得发放。

2016年度平安企业分类结果是对各参评企业开展综治（平安建设）工作成效的肯定，希望评为层次较高的企业要总结创建经验，强化创建措施，为“平安莆田”建设作出更大贡献；评为层次较低的企业要认真剖析原因，学习先进，改进工作，力争来年综治（平安建设）工作取得新突破。
