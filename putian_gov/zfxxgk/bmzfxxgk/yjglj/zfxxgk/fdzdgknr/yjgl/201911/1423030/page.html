关于涵江区涵东街道建成路阿海私房菜“9·14”醇基液体燃料爆燃事故的通报

发布时间：2015-09-18 08:00
| | |

 莆市安办〔2015〕61号

 

 

各县（区）人民政府（管委会），市政府安委员会有关成员单位：

2015年9月14日下午18时许，涵江区涵东街道新区社区建成路阿海私房菜在一楼厨房加注醇基液体燃料过程中发生爆燃事故，造成1人死亡。经初步调查，发现该家餐饮场所私自将燃料桶挂在室外墙壁上，并使用非导静电、易燃、不耐腐蚀的橡胶输送管；使用不合格灶具；在加注过程中，未采取防雷、防静电、防泄漏、液位监测等安全措施；运输醇基液体燃料车辆为非法改装轻型厢式货车，驾驶员、押运员均未取得道路危险货物运输从业资格证。事故暴露出安全大检查大排查大整治工作不落实、隐患排查不彻底、打非治违不深入等问题。为深刻吸取事故教训，有效防范类似事故发生，特提出以下要求：

一、要高度重视，认清当前使用醇基液体燃料餐饮场所安全生产形势。醇基液体燃料是以甲醇、乙醇为主混配的液体燃料，具有热效能高、费用低、清洁环保等特点，是近年来新型餐饮场所燃料。目前，在我市使用数量快速增长，并且有继续大幅上升的趋势。使用单位盲目追求经济利益，忽视安全，使用不符合安全要求的灶具、储存桶、储罐、管道及其附件,在向储存桶、储罐加注醇基液体燃料过程中，容易产生静电积聚引起爆燃事故，存在严重的安全隐患。各级各相关部门要认清形势，切实加强食堂及餐饮场所使用醇基液体燃料的安全监管。

二、要立即行动，严厉打击餐饮场所非法使用醇基液体燃料行为。各级各相关部门要深刻吸取涵江“9·14”事故教训，举一反三，结合当前正在集中开展的“打非治违”专项行动，组织各方力量，全面集中开展使用醇基液体燃料餐饮场所排查治理，严厉打击取缔餐饮场所非法使用醇基液体燃料行为。对非法改装、安装的醇基液体燃料灶具、储存桶或储罐及其管道、阀门，要跟踪督促使用单位拆除到位，严防死灰复燃。同时，要严格追溯、治理源头，安监部门要严厉打击醇基液体燃料非法储存、经营行为；交通运输、公安交警部门要严厉打击醇基液体燃料运输车辆非法改装、拼装及道路危货运输非法违法行为。教育、卫计、民政、商务、安监、食药监、国资、质监、消防、住建、交通运输、公安、交警、环保等相关部门要按照“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的原则，切实加强学校、医院、养老院、福利院、救助管理机构、企事业单位等食堂和其他餐饮场所使用醇基液体燃料安全排查治理。各县（区、管委会）要组织乡镇（街道）和相关部门开展排查治理，并加强排查治理的检查督查。乡镇（街道）政府要对辖区内所有餐饮场所使用醇基液体燃料全覆盖排查治理。市政府安办将结合安全大检查大排查大整治工作一并开展督查，并纳入安全生产责任制考评的重要内容。

三、从严查处事故，严肃追究责任。市政府安委会已对该起事故进行了挂牌督办，责成涵江区政府成立事故调查组开展调查工作。要依法从严从快进行查处，从灶具、储存桶、运输车辆改装安装和燃料经营、运输、使用以及相关监管等方面，查明事故原因，分清事故责任，严肃追究责任特别是安全大检查大排查大整治工作不落实的责任。事故结案后要依法及时向社会公开事故调查报告，并按要求将整改防范措施落实情况报送市政府安办。

四、加强事故警示教育和安全培训。要坚持把隐患当作事故对待、把小事故当作大事故对待、把别人的事故当作自己的事故对待，举一反三，对一些典型隐患，利用电视、报刊、网络等各种媒体进行曝光，不间断地开展警示教育。要进一步加强应急管理和职工安全教育培训，不断提高职工逃生自救、科学施救能力，坚决杜绝盲目施救。

 

 

莆田市政府安委会办公室

                            2015年9月18日
