莆田市人民政府安委会办公室关于步行街人防工程塌方事故的通报

发布时间：2011-07-07 08:00
| | |

 

莆市安办〔2011〕30号

 

 

荔城区、城厢区人民政府，市人防办、市住房和城乡建设局:

近期，市安办连续接到人防工程施工中发生路面及周边房屋沉降、墙体开裂、地面塌方等工程质量安全投诉和报告。

2月27日凌晨5时许，人防工程所在路段步行街城南市场附近人行道（“鞋柜”店铺门口台阶及城南市场入口路面）发生塌方，塌方面积约2平方米。

4月25日晚8时30分许，人防工程所在路段步行街“大唐饼业”店铺里面及外面人行道发生塌方，塌方面积约20平方米。

6月24日下午4时许，人防工程所在路段步行街城南市场“忠明干货”店铺门口踏步台阶发生塌方，塌方面积约8平方米，1名小孩跌落泥坑未受伤。

塌方事故发生后，建设单位及时采取有效措施加固地基，有效防止了事故的继续扩大。市政府领导高度重视人防工程安全情况，作出批示，要求将人防工程作为重点监控单位。为保障工程周边居民、单位、商户的人身财产安全，采取有效安全防护措施，减少和降低工程施工对周边居民、单位和商户生产及生活的影响，现将有关事项要求如下：

一、切实落实安全生产主体责任

工程建设、施工、监理单位要按照《国务院关于进一步加强企业安全生产工作的通知》（国发[2010]23号）要求，切实履行安全生产义务，落实责任，严格执行法律法规规定、各项安全生产制度和操作规程，切实采取有效措施，防止工程事故的发生。在安全施工的同时，对因工程施工造成周边建筑物不安全及周边居民、单位、商户提出的安全隐患，建设单位应及时妥善予以解决。对无法确认是否属于工程施工造成的安全隐患，为确保工程及周边安全，建设单位应从树立企业形象、营造良好社会关系出发，先行适当解决。

二、加大安全生产监管力度

人防工程所在步行街段是我市商业及人口密集区域，人车混杂，一旦发生事故，易造成严重后果。各级各有关部门要引起高度重视，按照市政府领导批示精神和《莆田市人民政府安委会办公室关于文献路人防工程安全隐患督办的通知》（莆市安办[2011]11号）要求，加强对工程周边群众的安全宣传教育，完善突发事件应急预案；加强对工程及周边的安全监督检查，对施工中非法违法建设行为要坚决打击制止，并依法予以处理。

荔城区、城厢区人民政府要及时受理工程周边居民、单位、商户的安全投诉，督促区人防、建设、消防等部门加强工程周边安全检查，协调电力、自来水、燃气、通信等管线单位加强管线的清理和检查。针对人防工程可能出现的周边地面塌方、楼房倒塌、火灾等突发事件，制定应急疏散方案，并组织工程周边街道居委会、公安派出所等单位和周边居民、单位、商户开展应急演练，应急预案编制和演练情况形成书面材料，于8月5日前报市安办（市政府一号楼248室，联系电话：2223322）。

市人防办应按照“谁审批、谁监管”的原则，落实“一岗双责”制度，并按照市政府专题会议纪要[2011]68号精神，一方面督促建设单位做好工程周边沉降、塌方路面和房屋的修复加固，防止衍发新的事故；另一方面加强对工程施工的安全检查，定期组织建设、消防等有关部门对工程及周边安全情况进行检查。对发现的安全隐患要督促建设、施工单位立即解决；对检查中发现的重大安全隐患，应责令其确保安全后方可继续施工，并将隐患和问题及时抄告具有行政执法权的部门予以处理。加强与建设行政主管部门的沟通协作，督促建设单位对工程及周边路面、房屋影响制定安全防护措施和解决方案，组织有关土木工程、建筑工程、线路管线工程专家和省、市有关部门对措施方案有效性进行评估，并跟踪措施方案的修订和实施，协调有关部门解决出现的安全问题。

市住房和城乡建设局应在职责范围内，按照市政府专题会议纪要[2010]141号要求，与市人防办做好服务配合工作,指导当地政府、市人防办对人防工程依法监督管理，加强对工程安全施工的业务指导，加强对周边建筑物安全状况的监督检查，对发现施工违法行为要依法作出处理，对无处理权限的违法行为应及时抄告有权限部门予以处理。

三、严格执行事故报告和调查制度

从这三起塌方事故报告情况看，建设单位虽以文件形式上报事故情况，但未严格执行事故报告程序和时限。工程所在地政府和有关部门要依法监督工程事故报告情况，及时受理群众来信来访的安全生产事故举报，查清事故原因，依法对事故发生具有责任的单位和人员给予相应处理。对迟报、漏报、瞒报事故，造成严重后果的，要坚决严肃追究有关责任。

 

 

 

二〇一一年七月七日
