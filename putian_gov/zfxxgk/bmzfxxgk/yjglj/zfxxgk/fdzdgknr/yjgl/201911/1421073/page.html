关于切实做好国庆和党的十七大期间安全生产工作的通知

发布时间：2007-09-27 08:00
| | |

盖章：

等级    特急             部委号：莆安委明传[2007]6号

 

 

各县(区)人民政府（管委会）安委会，市直有关单位：

    国庆即将来临，党的十七大也将在十月中旬召开，为认真落实党中央、国务院和省委、省政府及市委、市政府关于进一步加强安全生产工作、坚决遏制重特大事故的重要部署，切实保护人民群众生命财产安全，维护社会稳定，确保广大人民群众度过一个欢乐、祥和、平安的节日，为党的十七大胜利召开创造良好的安全环境，现就抓好国庆和党的十七大期间安全生产工作的有关事项通知如下:

    一、提高认识，强化领导

    即将召开的党的十七大是我国改革发展关键阶段召开的一次十分重要的盛会，国庆节是生产、运输、经营和旅游的旺季，抓好这期间的安全生产工作，意义重大、责任重大。各级、各部门、各单位要进一步提高认识，站在全面落实科学发展观、构建“平安莆田”、“和谐莆田”的高度，牢固树立“安全发展”理念，认真贯彻落实“安全第一、预防为主、综合治理”的方针，切实把做好国庆和十七大期间的安全生产工作作为保障人民群众生命财产安全和维护政治稳定、社会安定的重要政治任务来抓。国庆节前，各级、各部门和各单位的主要领导要通过召开会议、组织检查等多种形式，对国庆和十七大期间的安全生产工作进行认真研究和周密部署，制定具体方案和措施并认真落实。要建立健全严格的节日安全生产责任制，落实领导责任，实行分兵把口、分块负责，做到职责明晰、任务具体、责任到人、工作到位，确保安全生产形势继续保持平稳态势。       

    二、突出重点，加强监督检查

    在国庆和十七大召开前，各级、各部门、各单位都要集中开展一次安全生产大检查，安全检查要采取企业自查、部门专业检查和重点抽查相结合的方式，尽量邀请相关专业技术人员参与，加大部门之间的密切配合，推行联合检查、联合执法。各级各部门各单位领导要亲自带队，深入企事业单位、机关、学校等进行全面检查，重点检查各级各部门各单位贯彻落实《国务院办公厅关于进一步加强安全生产工作坚决遏制重特大事故的通知》的情况，检查基层单位的安全制度、安全责任、安全措施、隐患整改的落实情况。特别是要深入到非煤矿山、生产车间、景区景点、人员密集场所、建设施工现场等重点场所、重点部位和重点环节进行认真检查。对发现的问题和隐患，要采取有效措施，及时整改。对一时难以整改的，要制定可行的防范措施，专人负责监控，确保安全。

    各地区、各部门要认真履行安全监管职责，突出重点，强化监督检查。道路交通安全监管方面，要认真落实《莆田市人民政府办公室转发关于进一步强化道路交通安全监管工作的意见的通知》确定的十二项工作措施，深化道路交通安全“五整顿”、“三加强”工作。要加强对客运企业特别是“挂靠”单位和个体客运的监督检查，督促企业认真做好驾驶员安全行车教育，加强路面巡查监控，重点查处非法从事旅游客运和交通运输工具带病、超载、超限、超速、超时运营、驾驶员疲劳驾驶、非客运车辆载客等危及游客安全的行为；严格查禁乘客携带易燃、易爆、剧毒等危险物品，确保交通运输安全。要切实采取有力措施，加快危险路段、桥梁事故隐患整治，对险情实施有效监控。要加大水上交通的监督力度，严把主要港站、码头和渡口，现场监督关，严肃查处超载、冒险航行和农用船、渔船非法载客行为。非煤矿山安全监管方面，要继续加大联合执法力度，杜绝非法生产，重点督促露天矿山落实“采剥并举、剥离先行”和自上而下分台阶开采的要求，加快推进机械化铲装、中深孔爆破步伐，加强对矿山机械及运输通道安全防护，严禁违法、无证、病车运输，防止重大事故发生。危化品、烟花爆竹安全监管方面，各级、各有关部门要认真落实安全监管制度和监管责任，全面加强对危险化学品和烟花爆竹生产、储存、经营、运输、使用等各环节的安全监管，严厉打击非法生产经营行为，严格危险化学品道路运输许可制度，严防火灾、爆炸、泄漏、中毒等事故。旅游安全监管方面，各类风景名胜区、公园、游乐园管理部门和经营单位要切实加强对汽车、轮渡等游客运载工具及大型游艺机等设备的安全检查，加强日常检查、维护和管理，对达不到安全要求的，一律停止运营使用。公共集聚场所安全监管方面，公安消防等部门要重点加强对车站、码头、商场、影剧院、歌舞厅、宾馆饭店、网吧等人员密集场所、 “三合一”建筑等重点场所的消防安全排查、检查和整治，严肃查处锁闭、封堵或占用疏散通道、疏散楼梯、安全出口等违法行为，及时消除火灾事故隐患。建筑施工安全监管方面，各级、各有关部门要重点加强对建筑施工现场脚手架搭设、模板支撑、卸料平台等临边洞口防护、施工用电、塔吊和施工电梯、施工机械及安全管理的监督检查，严格落实特种作业人员依法持证上岗的规定，落实各项安全措施。对主要景观区域、道路两侧、大型活动场所周围的建筑施工工地要逐一进行检查，以确保设备、设施的安全可靠。

    各级、各有关部门要认真落实化工、建筑、电力等行业和领域的安全生产措施，严密防范各类生产安全事故。

    三、加大力度，深入持续抓好事故隐患排查治理          

各级各部门各单位要认真按照国务院、省政府和市政府关于开展重点行业和领域安全生产隐患排查治理工作的部署和要求。深入持续抓好事故隐患排查治理工作。一要组织“回头看”。认真制定工作计划，组织力量开展再检查，对认识不到位、行动迟缓、工作不落实、责任不明确、隐患严重、事故多发、排查治理走过场的地方、部门和企业，各级安全监管部门要及时发出整改指令，责令共进行“补课”，并实施重点跟踪督查，确保工作落实。二要加强检查督查。各级、各部门要在9月下旬至10月上旬，组织开展隐患排查治理工作的再检查、再排查、再落实，巩固隐患排查治理工作成效。三要加大隐患治理力度。对隐患排查治理专项行动中排查出的重大隐患，有关部门要督促企业认真制定并落实整改的具体方案、措施，明确整改责任人及整改期限，确保及时整改到位。对经整改仍达不到基本安全生产条件、无法确保安全的生产经营单位，各级各有关部门必须及时提请政府予以关闭。

    四、完善预案，及时妥善处置生产安全事故及突发情况

    国庆和十七大前夕及期间，各地区各部门各单位要针对节日期间易发火灾、中毒、人员踩踏事故等情况，广泛组织开展群众性的安全生产宣传教育活动，加大群众性的自防、自救、互救及逃生知识的宣传，提高各类人员的安全意识、自防自救和互救能力。要建立重大节日、重要时期生产安全事故的预测和预警机制，制度和完善有针对性的事故应急救援预案，细化各项应对措施，落实应急救援队伍，准备充足的救援物资和抢险装备，并组织好演练，确保应急救援做到反应迅速、处置得力、救援有效。国庆和十七大期间举办大型文体、商贸等活动的单位，要按照“谁主办、谁负责”的原则，制定可行的应急救援预案，在保证安全的前提下，安全有序地组织各项活动。对各种突发事故和异常情况，要按规定及时启动应急预案，组织力量及时妥善处理，确保社会稳定。

    五、加强值班，确保安全生产信息畅通

    各级各部门各单位要加强节日值班工作，落实领导带班值班制度，带班领导必须保证24小时通讯畅通，值班人员必须在岗在位，不得擅离职守。要及时掌握安全生产动态，对各种生产安全事故和突发情况，要严格按照《生产安全事故报告和调查处理条例》规定的时限、程序如实向上级有关部门报告。对不按规定时限上报有关生产安全事故情况的，尤其是瞒报、谎报、漏报和迟报的，要按有关规定给予通报批评，由此影响、延误生产安全事故及突发情况的应急救援、处置并造成严重后果的，要依照有关规定追究相关领导和人员的责任。

    各县（区、管委会）及市直有关单位、有关市属企业应将本地区本单位国庆节期间安全生产的简要情况和各类伤亡事故汇总数据，于10月6日下午5时前，书面传真报送市政府安委会办公室(电话：2292259，自动传真:2339655)。

 

 

 

二〇〇七年九月二十七日
