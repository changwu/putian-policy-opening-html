关于贯彻落实企业安全生产责任体系五落实五到位规定的通知

发布时间：2015-04-28 08:00
| | |

 

各县(区)人民政府（管委会)安委会，市政府安委会有关成员单位，央属、省属、市属有关企业：

根据国家安全监管总局、省政府安委会办公室分别下发《关于印发企业安全生产责任体系五落实五到位规定的通知》（安监总办〔2015〕27号）、（闽安委办〔2015〕27号）要求，现就全面贯彻落实《企业安全生产责任体系五落实五到位规定》（以下简称《五落实五到位规定》）的有关事项通知如下：

一、提高认识，加强领导。《五落实五到位规定》是贯彻落实党中央、国务院决策部署和习近平总书记重要指示精神的重大举措，是有关法律法规要求的归纳提炼和突出强调，抓住了企业安全生产的关键和根本，是企业必须履行的法定职责和义务。宣传贯彻好《五落实五到位规定》，对于保护职工生命安全、落实企业安全生产主体责任和实现安全生产状况持续稳定好转具有重要意义。各级各有关部门和企业要高度重视《五落实五到位规定》的学习和宣贯活动，主要负责同志要直接抓，确定本地区、本部门的工作联络员，制定部署本地区、本行业贯彻落实的具体措施，细化任务分工，层层落实责任，积极协调指导，及时掌握进展情况，研究解决存在的问题。

二、印发挂图，广泛宣传。各级各有关部门要按照以下工作任务分工，在2015年4月底前将《五落实五到位规定》挂图（式样附后）印发到企业。具体是：市直有关部门印发到本行业领域的企业；央属、省属企业印发到所属各级企业（含控股、参股企业）；各县（区、管委会）政府安委会印发到辖区内的冶金、有色、建材、机械、轻工、纺织企业（不含央属、省属企业）。同时，要将《五落实五到位规定》作为今年安全生产宣教培训的重要内容，纳入“安全生产月”等活动中，通过互联网、报纸、电视、广播、板报、LED显示屏等多种途径广泛宣传，营造浓厚的氛围。

三、狠抓典型，以点带面。各级各有关部门要及时发现和总结在贯彻执行《五落实五到位规定》方面好的典型经验，以点带面，发挥典型引路作用，全面带动所有企业加强安全生产工作。要严厉查处反面典型，对不严格落实《五落实五到位规定》、敷衍应付，造成事故发生的，要认真倒查责任，严格按照“四不放过”的原则，依法追究企业负责人责任，并通过事故通报、警示教育、召开现场会等形式，吸取教训，真正做到“一厂出事故、万厂受教育，一地有隐患、全市受警示”。

四、加强督导，严格执法。各级各有关部门要将《五落实五到位规定》宣贯工作开展情况作为2015年度安全生产目标责任制考核的重要内容之一，及时开展专项监督检查和工作指导，认真研究、协调解决贯彻实施中出现的突出问题；要将《五落实五到位规定》贯彻落实情况作为企业安全生产标准化建设和监督检查的重要内容，纳入达标评审内容和全年执法计划，作为提升达标水平、深化安全专项整治、强化“打非治违”的重要举措，督促企业把规定的每一项要求逐一落实，执行到位，不留死角。对违反规定的，要依法依规严肃追究有关单位和人员的责任。特别要加强对《五落实五到位规定》落实情况的随机动态抽查和检查，确保落实到位，杜绝形式主义和做表面文章，确保2015年底所有规模以上企业必须做到安全生产责任体系五落实五到位，2016年扩大到所有规模以下企业。

五、全面落实，加强管理。各企业要将挂图张贴在醒目位置，确保无遗漏、全覆盖。所有企业都必须组织全体员工逐条逐字深入学习，领会精神实质，把握准确内涵，贯彻落实到位。特别是具有公司治理结构的企业，要逐条对照《五落实五到位规定》，对本企业安全生产工作情况进行一次全面梳理，认真查找不足和漏洞，抓紧完善安全生产领导责任制，调整安全生产管理机构人员，进一步健全并落实安全生产责任和安全生产规章制度，把《五落实五到位规定》转化为本企业的规章制度，自觉落实到企业管理的全过程、落实到安全生产的每个环节，切实加强安全管理、加大安全投入、改善安全生产条件，提高安全生产水平，有效防范各类事故发生。

请各县（区、管委会）政府安委会、市直有关部门于4月30日前将本地区、本单位的工作联络员姓名、联系电话、电子邮箱报送市政府安办，并于每季度首个月的2日前将《企业“五落实五到位”进展情况汇总表》报送市政府安办（联系人：陈志鹏，联系电话：0594-2392566，传真：2392566，电子邮箱：ptajjek@163.com）。
