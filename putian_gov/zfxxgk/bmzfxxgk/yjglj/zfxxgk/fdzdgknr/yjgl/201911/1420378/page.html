关于印发莆田市危险化学品领域安全生产大检查工作实施方案的通知

发布时间：2013-07-12 08:00
| | |

莆市安监〔2013〕64号

 

各县（区）安监局，市直有关单位，有关大中型企业：

为全面、深入、彻底地开展全市危险化学品领域安全生产大检查，我局制定了《莆田市危险化学品领域安全生产大检查工作实施方案》，现印发给你们，请结合本辖区、本部门、本单位安全生产实际，进一步细化检查具体内容和要求，认真抓好贯彻落实。

 

 

                                   莆田市安监局　　　　

2013年7月12日　　　　

 

 

莆田市危险化学品领域

安全生产大检查工作实施方案

 

一、总体要求

认真贯彻落实市府办《关于集中开展安全生产大检查的紧急通知》（莆政办明电〔2013〕47号）、市政府安委会《关于印发莆田市安全生产大检查工作实施方案的通知》（莆安委明电〔2013〕5号）和省安监局《关于印发福建省危险化学品领域安全生产大检查工作实施方案的通知》（闽安监管三〔2013〕96号）等文件精神，按照“全覆盖、零容忍、严执法、重实效” 的总体要求，坚持“企业自查是基础、政府督查是关键、消除隐患是核心、遏制事故是目标”的原则，开展一次彻底的危险化学品领域安全生产大检查，铁腕打击各类非法违法生产经营建设行为，堵塞漏洞，消除隐患。

二、检查时间和范围

结合危化品领域安全生产重点整治百日行动，从6月至9月底，对各级政府和相关部门，以及危化品领域的所有生产、经营、储存、使用、运输单位进行全面彻底检查。

三、检查内容

（一）对县（区、管委会）和危化品监管部门的检查内容

1.安全生产工作总体情况。贯彻落实安全生产方针政策、法律法规，建立和落实危化品安全监管责任和制度情况。

2.组织开展安全生产大检查情况。是否按照市府办47号明电、市政府安委会5号明电进行了全面部署，组织所有危化品企业开展彻底的自查自纠。

3.深化专项整治和“打非治违”工作情况。危化品领域安全专项整治是否取得实效；“打非治违”联合执法机制是否建立和完善；是否对2012年“打非治违”专项行动开展以来查出的非法违法、违规违章行为进行了登记造册，并严格按照“四个一律”要求进行了查处；“打非治违”工作各项措施是否得到落实。

4.汛期安全防范情况。是否组织开展了汛期隐患排查和隐患点除险加固，汛期各项安全防范措施是否落实。

（二）对危化品从业单位检查的内容

1．危险化学品生产环节。企业落实“三同时”及安全生产许可证取证审查时不符合项和企业内外部间距不符合规范要求的整改情况，涉及重点监管的危险化学品的建设项目和自动化改造情况，设备维护保养、检维修作业、生产装置正常开停车和紧急停车及重点监管危险化学品等规章制度、操作规程的制定和执行情况。重点监管的危险化学品特别是甲苯二异氰酸酯、乙炔、甲苯、乙酸乙酯等有毒有害易燃易爆危险化学品，重大危险源的安全管理情况；完成提升危险化学品领域本质安全专项行动任务情况；重大危险源监控情况，储罐安全监控检测情况（液位、压力、温度报警和可燃气体泄漏报警）；作业现场安全监督检查，严格执行直接作业安全标准，有效防范直接作业环节事故情况。

2．危险化学品储存环节。重点检查储存有毒（特别是液氯、液氨、甲苯二异氰酸酯和二氯甲烷）、易燃、易爆危险化学品的企业，涉及氯、氨、液化气体、甲苯二异氰酸酯等被列入重点监管的危险化学品名录的化工企业，以及构成重大危险源的企业和单位。

3．危险化学品经营环节。重点检查经营易制爆危险化学品和交通运输工具用加油（气）站、液化气体充装单位。

4．危险化学品使用环节。使用危化品从事生产并达到危化品使用量的数量标准的化工企业，是否具备颁发安全使用许可证条件。使用危险化学品进行试验的科研院所及各类学校、医院实验室的危险化学品安全管理情况以及废弃处置情况。

5．危险化学品运输环节。重点检查承运剧毒、有毒、液氯、液氨、液化气体、甲苯二异氰酸酯等被列入重点监管的危险化学品名录的化学品和易爆化学品的运输企业和单位。

四、检查方式方法

（一）企业自查自纠全覆盖。各危化品企业要全面开展自查自纠，细化方案，明确具体检查内容和责任。对照大检查内容以及相关法律法规规章、规程规范和技术标准，对本企业安全生产工作的每个部位、每个环节进行细致彻底、全方位的检查。对排查出的隐患、问题，要制表一一列出清单，建立台账，制定整改方案，落实整改措施、责任、资金、时限和预案。排查情况、整改方案和整改结果要经本单位主要负责人、实际控制人签字后，在单位内部公布，接受职工群众监督，并每月上报当地主管部门，作为事故查处的重要依据。

各危化品中央、省属企业在莆分公司、市属危化品企业要在本企业内部认真组织自查自纠，并加强对下级单位的检查。各驻地中央企业、省属和市属企业要自觉接受各级安监部门和相关部门的监督检查。中央企业集团、省属在莆分公司和市属企业要及时将检查情况、整改方案和整改结果报市安监局。

（二）强化属地检查。各级安监部门要按照属地监管原则，组织各部门各单位开展全过程、全覆盖的检查。县（区）安监局及市直相关部门要对本辖区本系统危化品从业单位进行一次调查摸底，摸清安全生产基本情况以及存在的突出问题和薄弱环节，建立基础台账，制定督查检查工作方案。市级检查要全覆盖所有县（区）安监局及市直危化品监管部门、辖区内直接监管的所有危化品从业单位和中央、省属、市属企业，并对辖区内各县（区）危化品从业单位进行抽查；县（区、管委会）、乡镇（街道）两级检查要全覆盖本辖区的所有危化品从业单位。

（三）强化行业检查。负有危险化学品监管职能的部门要结合实际，对本行业、本系统危险化学品大检查及百日行动进行全过程、全覆盖督查、检查、抽查，组织互查，做到横向到边、纵向到底，不留死角、不留盲区。市安监局将会同市直相关部门组成联合督查组，对各县（区）安监局及所有危化品中央、省属企业在莆分公司和市属危化品从业单位进行督查，并对全市各县（区）危化品从业单位进行抽查。

（四）创新检查工作方式。全市各级安监部门要组织危化品专家，深入现场，注重从技术层面查找隐患，真正发现和解决问题。

五、工作要求

（一）加强组织领导。要把集中开展安全生产大检查与危化品领域“安全重点整治百日行动”紧密结合，作为当前安全生产的首要任务，切实加强领导、精心组织、周密部署、狠抓落实、取得实效。为加强组织领导，决定成立由市安监局分管领导任主任、市直有关部门相关人员任成员的市危化品安全生产大检查工作办公室（成员名单附后），负责大检查和百日行动的组织协调。各级要成立相应机构，加强对大检查和百日行动的指导监督，确保取得实效。

（二）落实“一岗双责”。各级安监部门应充分发挥危化品安全监管部门联席会议作用，进一步明确和细化负有危化品安全监管职能部门的具体职责，按照“谁主管、谁负责”原则，认真落实“一岗双责”，形成危化品安全监管工作合力。

（三）严格监管执法。要以更加“严细实”的作风，以对隐患和问题“零容忍”的态度，严格执法，狠抓落实，切实做到不留死角、不留盲区、不走过场。对查出的每一起隐患和问题，要现场提出处理意见，责令立即整改；不能立即整改的，要实行挂牌督办，并跟踪落实。对存在隐患拒不整改或查出重大隐患和问题的，要按照有关法律法规或组织纪律对相关责任人予以严肃处理，并及时通报。

（四）定期报送情况。各县（区）安监局要于每周四向市安监局报送大检查和百日行动的主要做法、成效和发现的突出问题及典型案例，每月18日前报送本月大检查进展情况的月度小结材料；大检查结束后要认真进行总结并形成总结报告，于10月5日前上报市安监局。
