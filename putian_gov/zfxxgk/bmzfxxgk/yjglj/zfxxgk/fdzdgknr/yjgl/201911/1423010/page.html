关于我市五起建筑施工维修作业安全事故的通报

发布时间：2012-09-13 08:00
| | |

  

                                         莆市安办〔2012〕77号

 

各县（区、管委会）安办，市直有关部门：

今年6月份以来，我市一些地方相继发生建筑施工、维修作业安全事故，给国家和人民生命财产造成巨大损失，教训十分深刻。现将有关情况通报如下：

6月24日下午2：30左右，湄洲岛影视园工地，在顶棚施工过程中发生坠落事故，造成1人死亡。

7月8日上午10：45左右，北岸开发区妈祖文化体育公园，在塔吊安装过程中发生倒塌事故，造成2人死亡，1人受伤。

7月19日晚上8：00左右，涵江区涵江速8酒店，工人在对广告牌进行维修时发生触电事故，造成1人死亡。

7月22日下午2：00左右，秀屿区笏石社区卫生服务中心施工工地，工人在收拾工具过程中发生事故，造成1人死亡。

8月31日下午4：10左右，涵江区白塘上梧村民房装修，在装修外墙时发生井架掉落事故，造成2人死亡，2人受伤。

我市发生的以上事故既暴露出部分建设单位违反基本建设程序，是典型的违法建设工程，没有建设工程规划许可证、施工许可证及质量安全监督等手续，也暴露出建设单位法律意识淡薄，安全生产责任不落实、管理不到位，违章指挥、违章作业，安全培训教育不到位、隐患监督整改不力和安全监管部门“打非治违”不到位等问题。为深刻吸取事故教训，强化建设工程施工安全监管，有效遏制非法违法风气，防止生产安全事故发生，现提出以下要求：

一、认真开展安全生产“百日大检查”活动，坚决遏制事故发生

各县（区、管委会）、市直有关部门要深刻吸取事故教训，进一步加强建筑安全管理工作，采取果断措施遏制事故频发的势头。一要建立健全安全生产目标责任制，按照“属地管理、分级负责”、“谁主管、谁负责”的原则，落实有关部门安全监管责任，确保安全责任层层落实到每个环节、每个岗位、每个人员。二要继续深入推进安全隐患排查治理工作，根据《关于开展安全生产“百日大检查”活动的通知》（莆安委明电〔2012〕2号）文件要求，认真开展隐患排查治理工作，将排查中发现的问题逐一梳理、认真整改。三要严密监控重点地区、重点企业、重点环节、重点部位，特别是发生事故的涵江区、秀屿区、湄洲岛、北岸经济开发区等地要对事故频发的乡（镇）、安全管理薄弱的企业、隐患严重的项目、危险性较大工程加大监督检查力度。四要做好秋季、冬季施工安全工作，指导和督促施工单位根据第三季度、四季度施工特点，组织编制有针对性的秋季、冬季施工方案，采取有效的保暖、防冻、防滑措施，严防因盲目赶抢工期发生生产安全事故。

二、加大监管执法力度，深入推进“打非治违”专项行动

各县（区、管委会）、各相关部门要加大执法力度，要结合正在开展的严厉打击非法违法生产经营建设行为专项行动，加大对建筑工程非法违法行为的打击力度。严厉打击工程建设领域施工企业证照不全，超越资质范围承揽工程、违法分包、转包工程，违规托管、代管、挂靠等行为，以及施工企业主要负责人、项目负责人、专职安全生产管理人员无安全生产考核合格证书，特种作业人员无操作资格证书等非法违法行为。特别要严厉查处不办理施工许可证、无资质的施工队伍从事建筑施工活动等行为，该停工的要责令停工，该处罚的要给予处罚，该拆除的必须进行拆除，有效防范建筑安全事故的发生，确保人民生命财产安全。

三、加强安全教育培训，提高作业人员安全素质

从近期发生的这几起事故来看，施工从业人员的整体素质不高、安全意识淡薄、自我防护意识差是导致事故发生的原因之一。为此，施工单位务必要切实加强对 “三类”人员、施工作业人员、特种作业人员的教育培训，特别要重点做好对上岗农民工的三级安全教育培训，提高其安全生产意识和操作技能，增强自我防护能力和应急处置能力。要充分利用各种渠道和形式，有针对性地开展施工安全专项宣传教育活动，普及安全常识，将宣传教育经常化、制度化，营造建设工程施工安全的良好社会氛围。

四、严肃事故查处，严格责任追究

各级、各部门要严格依照有关法律法规，坚持事故调查“四不放过”的原则和依法依规、实事求是、注重实效的要求，加大对事故的查处力度，查明事故原因，认定事故责任，吸取事故教训，提出并督促落实整改措施。要严肃追究事故责任人和责任单位的责任，构成犯罪的移送司法机关。要严格执行事故报告制度，事故发生后，按规定时限和要求报送有关政府部门和单位，不得迟报、谎报、漏报和瞒报。

 

 

 

 

 

莆田市人民政府安委会办公室

2012年9月13日

 

  

抄送：市府办，市政府分管副市长、分管副秘书长，本办领导。

莆田市人民政府安全生产委员会办公室    2012年9月13日印发
