转发省“两办”关于进一步做好当前防汛防灾工作的紧急通知

发布时间：2016-05-10 08:00
| | |

内部明电

发往：见报头                         签批盖章：陈金晃

等级：特提                部委号：莆安办明电〔2016〕13号

 

 

 

各县（区）人民政府（管委会）安委会：

现将《转发省“两办”关于进一步做好当前防汛防灾工作的紧急通知》（闽安委办明电〔2016〕3号，以下简称《紧急通知》）转发给你们，请按照《紧急通知》要求，认真抓好贯彻落实。

 

 

莆田市人民政府安全生产委员会办公室

2016年5月10日         

 

 

 

 

转发省“两办”关于进一步做好当前

防汛防灾工作的紧急通知

闽安委办明电〔2016〕3号

 

各设区市及平潭综合实验区安监局：

现将《中共福建省委办公厅 福建省政府办公厅关于进一步做好当前防汛防灾工作的紧急通知》（闽委办发明电〔2016〕35号，以下简称《紧急通知》）转发给你们，请按照《紧急通知》要求，结合省安办《转发国务院安委会办公室<关于加强“五一”节日期间和汛期安全生产工作的通知>等两份文件的通知》（闽安委办明电〔2016〕4号）等精神，认真抓好贯彻落实。

各级安监部门要切实重视汛期安全生产工作，督促各地各相关部门按照安全生产“党政同责、一岗双责”、“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，根据各自地区、各自行业领域的特点，有针对性地开展隐患排查治理，特别要突出煤矿、非煤矿山、危险化学品、交通运输、建筑工地、旅游、人员密集场所及消防安全等重点行业领域，认真组织开展安全检查，治理各类安全隐患，严防自然灾害引发生产安全事故发生。同时，要加强汛期值班值守，遇有突发事故或紧急情况，要及时上报情况，有效开展应急救援。

 

福建省安全生产监督管理局  

2016年5月8日
