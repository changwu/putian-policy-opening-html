关于切实做好防范自然灾害引发事故灾难工作的通知

发布时间：2008-01-25 08:00
| | |

 

莆市安〔2008〕3号

 

 

 

各县（区）人民政府（管委会）安委会，市直有关单位：

    近年来，由于台风、风暴潮、暴雨、洪水、雷电、地震、地质泥石流、山体滑坡等自然灾害原因引发一些煤矿淹井、矿山坍塌冒顶、建筑施工工地遭洪水泥石流袭击等事故灾害，给人民生命财产安全带来重大损失。为深入贯彻党的“十七大”精神，继续深化安全生产隐患排查治理工作，根据《国务院安委会办公室关于切实做好防范自然灾害引发事故灾难工作的通知》（安委办[2008]1号）、省政府办公厅1月16日的通知和《福建省人民政府安委会关于做好防范自然灾害引发事故灾难工作的通知》（闽安委[2008]1号）的精神，经市政府领导同意，结合我市实际，现就抓好自然灾害引发事故灾难防范工作的有关事项通知如下：

 

    一、隐患点排查治理工作的责任单位、对象和内容

    （一）非煤地采矿山、露天采场坑口、排土场以及尾矿库等场所

    1.排查治理工作内容：(1)摸清非煤地采矿井、露天采场坑口由于井口(洞口)标高不够或露天矿封闭圈不符合规范要求，存在淹井、淹矿事故隐患场所以及受暴雨、洪水、地震影响易发生溃坝、泥石流的尾矿库、排土场等场所的隐患点位置、数量和危害等级；(2)建立健全各生产企业和主管部门相应的包括隐患点位置、数量、危害等级以及监控、监测、整治情况等安全监管工作档案;(3)根据排查结果，按照分级属地原则，及时制定除险加固和隐患治理工作计划，并落实责任、方案、资金、人员、物资、期限和预案等要求;(4)加强督促、检查，并做好记录和通报，确保工作取得实效; (5)按时上报隐患点排查以及除险加固和治理情况。

    2.牵头单位:安监部门

    3.配合单位:国土资源、地质矿产勘查开发、地震、气象等相关部门，各县（区）政府安委会

    （二）建筑施工企业工地、人员居所、设备物资场地以及城市交通的路桥、涵洞，有人作业、有车通过、有人行走的城市道路上部和侧边有山体的地段，易发生淹没或坍塌危险的隧道等场所

    1.排查治理工作内容:(1)摸清周围存在山体滑坡、垮塌和泥石流威胁的建筑施工企业工地、人员居所、设备物资场地以及存在被冲毁危险的城市交通的路桥、涵洞，有人作业、有车通过、有人行走的城市道路上部和侧边易跨落、坍塌山体的地段，易发生淹没或坍塌危险的隧道等场所的隐患点位置、数量和危害等级;(2)建立健全各建筑施工企业、各产权单位和各级建设主管部门相应的包括隐患点位置、数量、危害等级以及监控、监测、整治情况等安全监管工作档案;(3)根据排查结果，按照分级属地的原则，及时制定除险加固和隐患治理工作计划，并落实责任、方案、资金、人员、物资、期限和预案等要求;(4)加强督促、检查，并做好记录和通报，确保工作取得实效； (5)按时上报隐患点排查以及除险加固和治理情况。

    2.牵头单位:建设部门

    3.配合单位:地震、气象等相关部门，各县（区）政府（管委会）安委会

    （三）病险水库大坝、水电站大坝、江河大堤、海堤及河道等场所

    1.排查治理工作内容:(1)摸清存在溃坝、溃堤危险的病险水库大坝、水电站大坝、江河大堤及存在淤积危险的河道或类似场所的隐患点位置、数量和危害等级;(2)建立健全各产权单位和各级主管部门相应的包括隐患点位置、数量、危害等级以及监控、监测、整治情况等安全监管工作档案;(3)根据排查结果，按照分级属地的原则，及时制定除险加固和隐患治理工作计划，并落实责任、方案、资金、人员、物资、期限和预案等要求;(4)加强督促、检查，并做好记录和通报，确保工作取得实效;(5)按时上报隐患点排查以及除险加固和治理情况.

    2.牵头单位:水利部门

    3.配合部门:经贸、电力、地震、气象等相关部门，各县（区）政府（管委会）安委会

    （四）渔港、渔排(含库港养渔渔排)场所及其他渔船停泊点等场所

    1.排查治理工作内容: (1)摸清存在由台风、风暴潮、暴雨引发海难事故的渔港、渔排(含库港养渔渔排)及其它渔船停泊点或类似场所的隐患点位置、数量和危害等级;（2）建立健全各产权单位和各级主管部门相应的包括隐患点位置、数量、危害等级以及监控、监测、整治情况等安全监管工作档案；（3）根据排查结果，按照分级属地的原则，及时制定除险加固和隐患治理工作计划，并落实责任、方案、资金、人员、物资、期限和预案等要求； (4)加强督促、检查，并做好记录和通报，确保工作取得实效;(5)按时上报隐患点排查以及除险加固和治理情况。

    2.牵头单位:海洋与渔业部门

    3.配合单位:地震、气象等相关部门，各县（区）政府（管委会）安委会

    （五）除城市交通外的路桥、涵洞，有人作业、有车通过、有人行走的公路上部和侧边有山体的地段等场所

    1、排查治理工作内容：（1）摸清存在被冲毁危险的路桥、涵洞，有人作业、有车通过，有人行走的城市道路上那和侧边易跨落、坍塌山体的地段或类似场所的隐患点位置、数量和危害等级；（2）建立健全各产权单位和各级主管部门相应的包括隐患点位置、数量、危害等级以及监控、监测、整治情况等安全监管工作档案; (3)根据排查结果，按照分级属地的原则，及时制定除险加固和隐患治理工作计划，并落实责任、方案、资金、人员、物资、期限和预案等要求;(4)加强督促、检查，并做好记录和通报，确保工作取得实效;（5）按时上报隐患点排查以及除险加固和治理情况。

    2.牵头单位:交通部门

    3.配合部门:地震、气象等相关部门，各县（区）政府（管委会）安委会

    （六）其它易造成泥石流、山体滑坡的区域和场所

    1.排查治理工作内容:(1)摸清其它易造成泥石流、山体滑坡等自然灾害引发事故灾难区域和场所的隐患点位置、数量和危害等级;(2)建立健全各产权单位和各级主管部门相应的包括隐患点位置、数量、危害等级以及监控、监测、整治情况等安全监管工作档案;(3)根据排查结果，按照分级属地的原则，及时制定除险加固和隐患治理工作计划，并落实责任、方案、资金、人员、物资、期限和预案等要求;(4)加强督促、检查，并做好记录和通报，确保工作取得实效;(5)按时上报隐患点排查以及除险加固和治理情况。

    2.牵头单位:国土资源部门

    3.配合部门：地震、气象等相关部门，各县（区）政府（管委会）安委会

    二、实施步骤

    （一）摸清底数阶段:各责任部门要按照本方案职责分工，结合本部门、本行业的实际和类似已发生的自然灾害事故的经验、教训，及时制定实施方案，组织本行业、地震、气象等部门的专家进行认真排查、论证。排查结果请各市级责任部门按登记表(见附件)的相应要素认真填写，于1月30日前报市政府安办(市政府安办联系人:薛凤池，联系电话:2330086,传真：2339655)，以便及时汇总上报省政府安办。县级以下的责任部门除了报送上级主管部门外，还必须同时报本级政府安办备案。

    （二）除险整治阶段:各责任部门要针对排查出的隐患点，采取有力措施，全面加强防范，尤其是隐患治理工作。防范和隐患治理工作要在各地汛期来临之前完成，对一时难以治理完成的，要及时报告当地政府及其有关部门和上级单位，并制定好切实可行的治理计划，落实资金、确定专人、限期整改。同时，要制订好应急预案，落实应急组织、装备和物资，加强监测监控。对由于客观原因无法治理的(如地震活跃地带)，要与地震、气象等部门签订协议，做好预测预报预警预防工作。除险加固和治理情况请各市级责任部门于5月5日前报市政府安办，县区级以下的责任部门除了报送上级主管部门外，还必须同时报本级政府安办备案。

    （三）抽查复查阶段：国务院安办将于6月份开始组织由国务院有关部门参加的联合督查组，对各地开展工作的情况进行督查。省政府安办将于5月中旬组织有关部门对省直有关部门和自然灾害地区工作情况进行抽查复查。市政府也将于4月底组织相关部门进行督查。各县（区）政府（管委会）安委会、市直有关单位要组织对辖区内的排查、除险加固及治理情况进行督查，发现问题，跟踪督促，限期整改，推动工作。各县（区）政府（管委会）安委会、市直有关单位的督查情况要及时下发通报，并抄送市政府安办。

    （四)建章立制阶段：各地区、各部门、各企业要建立包括隐患点位置、数量、危害等级以及监控、监测、整治情况等安全监管工作档案资料，健全隐患点运行监控、运营管理长效机制和事故隐患排查评估机制，进一步完善应急预案和应急救援体系。同时，各地区要贯彻落实国家安监总局、中国气象局等六部门联合下发的《关于建立可能引发生产安全事故灾难的自然灾害预警工作机制的通知》(安监总应急[2007] 239号)文件精神，负有安全监管职责的部门要与有关部门签订协议，建立起协同应对的有效工作机制，及时对自然灾害进行预测、预报、预警和预防，确保人民生命财产安全。

    三、工作要求

    （一）要提高认识，加强领导。由自然灾害引发的事故灾难具有突发性、诱发性和危害性大、破坏性强等特点。各地区、各部门要站在深入贯彻落实科学发展观的高度，深刻认识做好防范自然灾害引发事故灾难工作的重要性，坚持“安全第一、预防为主、综合治理”的方针，认真落实行政首长负责制和法定代表人负责制，切实加强领导、周密部署、精心组织、狠抓落实、务求实效。

    （二）要落实责任，明确分工。各级政府安委会、各有关部

门要按照市政府安委会的工作部署，明确职责分工，落实工作责任。隐患排查、工作计划、除险加固和隐患治理等具体工作由相应的负有安全监管职责的主管部门组织实施，各县（区）政府（管委会）安委会做好专查、协调和通报工作。

    （三）要加强协调，形成合力。此项工作涉及到多个部门，地方各级政府安委会及其办公室要在当地政府的统一领导下，发挥好综合协调功能，充分调动各有关部门的主动性和积极性，真正做到查实、查细、查全、真抓、真治，坚决防止走过场。

    （四）要广泛动员，群防群治。各地区、各部门要加强宣传动员，充分发挥和依靠人民群众搞好排查治理工作。要建立举报信箱和电话，完善信息沟通渠道，接受群众和社会监督。要注重用事故教训推动工作，不断完善政策措施，建立健全长效机制。

 

 

 

二〇〇八年一月二十五日
