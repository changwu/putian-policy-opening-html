关于印发莆田市开展危险化学品安全生产“百日大检查”活动方案的通知

发布时间：2012-08-06 08:00
| | |

 

  

莆市安监〔2012〕82号

 

 

各县（区、管委会）安监局（科）：

根据市安委会《关于开展安全生产“百日大检查”活动的通知》（莆安委明电〔2012〕2号）通知要求，结合危险化学品领域“打非治违”专项行动、清剿火患战役、危险化学品消防安全保卫战工作和我市危险化学品安全生产工作实际，经研究，制定《莆田市开展危险化学品安全生产“百日大检查”活动方案》，现印发给你们，请认真组织实施。

 

莆田市安全生产监督管理局

2012年8月6日

 

莆田市开展危险化学品安全生产“百日大检查”

活动方案

 

为进一步加强危险化学品安全生产工作，更好地促进我市经济安全发展，结合我市正在开展的危险化学品领域“打非治违”专项行动暨深入开展清剿火患战役工作和危险化学品消防安全保卫战工作，决定从8月起至10月，在全市范围内开展危险化学品安全生产“百日大检查”活动。现将有关事项通知如下：

一、工作目标

通过开展危险化学品安全生产“百日大检查”活动，认真解决日常安全监管工作中存在的突出问题和薄弱环节，进一步深化隐患排查治理，有效防范和减少各类安全生产事故发生，坚决遏制重特大生产安全事故，为党的十八大胜利召开营造良好的安全生产环境。

二、检查的主要内容

1. 贯彻落实《关于印发莆田市危险化学品领域集中开展“打非治违”专项行动暨深入开展清剿火患战役工作实施方案的通知》（莆市安监〔2012〕43号）、《关于加快推进山区乡镇加油站建设切实打击成品油非法经营的意见》（莆市安办〔2012〕36号）及《关于印发党的十八大莆田市危险化学品消防安全保卫战工作方案的通知》（莆市安监〔2012〕71号）的情况；

2. 危险化学品安全生产“百日大检查”工作部署开展情况；

3. 对辖区内所有危险化学品生产、储存、经营单位及剧毒化学品使用企业进行全面检查的台帐资料。

三、工作要求

一要高度重视，加强领导。各县（区、管委会）安监局（科）要高度重视，把这次安全生产“百日大检查”作为减少隐患、遏制事故的重要举措，切实组织好，落实好。各单位主要领导要亲自召开会议进行动员部署，带队开展检查，扎实开展危险化学品安全生产“百日大检查”活动。

二要周密组织，突出重点。各县（区、管委会）安监局（科）要结合工作实际，制定具体实施方案，认真组织实施，排查整改安全隐患，有效预防和遏制事故发生。至10月底前，要对辖区内所有危险化学品生产、储存、经营单位及剧毒化学品使用企业开展拉网式排查不少于3次。

三要落实责任，务求实效。各县（区、管委会）安监局（科）要认真开展检查，做到横向到边，纵向到底，不留死角。对检查中排查出的隐患和发现的问题，及时进行专题研究，落实责任和整改措施。对发现的重大隐患及时提交政府挂牌整改，跟踪督办，确保大检查活动取得实效。

四要深入基层，强化督导。各县（区、管委会）安监局（科）一把手是开展危险化学品安全生产“百日大检查”活动的第一责任人，要亲自部署，亲自带队到基层进行督促和检查3次以上；各分管领导要采取拉网式排查、抽查等方式，带队深入基层和生产一线进行督促和检查6次以上。市局要适时组织督查、互检、抽查等方式，对各县（区、管委会）安监局（科）开展危险化学品大检查情况进行督查。

各县（区、管委会）安监局（科）要做好危险化学品安全生产“百日大检查”信息报送工作，指定专人负责，认真收集相关数据和工作情况，汇总工作进展情况，并于8月10日前将危险化学品“百日大检查”方案以书面形式报送市局监管三科。要结合“打非治违”工作，于每周二前以电子档形式将危险化学品“百日大检查”阶段性开展情况报送市局监管三科（联系人：吴爱红；电话：2333662）。

 

 

抄送：省安监局，局领导。

莆田市安全生产监督管理局                                 2012年8月6日印发
