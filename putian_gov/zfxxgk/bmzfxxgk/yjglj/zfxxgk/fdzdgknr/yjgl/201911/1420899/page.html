关于开展“平安莆田5号”湄洲岛旅游环境安全生产专项行动的方案

发布时间：2006-04-19 08:00
| | |

 

莆市安办[2006]12号

 

 

 

秀屿区人民政府、湄洲岛管委会安委会，市直有关单位：

    根据《关于开展“平安莆田5号”湄洲岛旅游环境综合整治专项行动的通知》（莆综治委[2006]7号）文件精神，结合我局的工作职能，现就湄洲岛旅游景区安全生产环境专项集中整治行动制定具体方案如下：

    一、组织领导

    为了加强领导，统一协调指挥，确保整治工作扎实、有效地推进，经局研究，决定成立专项整治工作领导小组，名单如下：

    组  长：张元璋

    成  员：陈彩萍  黄玉鸿  杨福金  郭金木  林一舟

    二、职责任务

    开展安全生产监督检查、综合指导，重点检查码头、景点及周边旅游服务业的安全生产工作，确保不发生重、特大安全事故。

    三、实施步骤

    第一阶段：宣传发动（4月19日至4月21日）

    督促各安全生产监管职能单位针对安全生产整治目标任务，按照活动总体要求，制定出目标明确、规范详细、可操作性的实施方案，对专项整治进行全面部署。并利用各种宣传媒体手段，广泛发动全民参与，营造浓厚的活动氛围。

    第二阶段：集中整治（4月21日至6月15日）

    组织各职能部门对湄洲岛轮渡码头及旅游景区进行全面的安全生产隐患排查，督促湄洲岛管委会切实落实渡口、旅游景区的安全管理责任制，帮助解决存在的实际问题，消除渡口、旅游景区存在的安全隐患，力争在5月1日前取得成效。市安监局将会同市监察局对专项整治工作进行定期、不定期的督查、暗访。

    第三阶段：巩固提高（6月15日至8月15日）

    围绕整治的内容和要求，认真梳理查摆薄弱环节和难点，研究制定针对性、可操作性强的强化方案和整改措施，并及时进行总结，建立长效的管理机制。

    第四阶段：总结考评（8月15日至10月15日）

    对整治活动开展情况进行总结，制定长效管理办法，逐步转入常规管理，迎接湄洲岛旅游环境综合整治工作领导小组对整治活动进行检查验收和评比。

    四、保障措施

    1、统一认识，加强领导。深刻领会开展整治活动的重大意义和总体要求，统一思想，提高认识，明确目标，推动安全生产各项工作措施的落实。

    2、细化分解，明确责任。根据专项整治工作领导小组的统一部署，对每项工作定时、定人推进落实，做到分工明确、措施具体、责任到人、领导到位。

    3、宣传造势，营造氛围。加大对整治活动的宣传报道力度，对活动过程中出现的好经验、好做法、好成效进行宣传报道，对存在的问题随时进行曝光。

    4、依法行政，强化督查。严格执行有关法律法规和政策，做到有法必依、执法必严、违法必究。加强督查，查找整治活动中存在的突出问题，及时提出整改督办意见。

    5、探索创新，长效管理。按照“综合治理、标本兼治、重大治本”的要求，及时制定、修订、完善相关工作制度，制定出长效管理办法，逐步转入常规管理。

 

 

二OO六年四月十九日
