关于加强全市危险化学品领域岁末年初安全生产工作的通知

发布时间：2016-01-14 08:00
| | |

 莆市安监〔2016〕7号 

 

 

 

各县（区、管委会）安监局：

为认真贯彻落实1月6日全国、全省安全生产电视电话会议精神，把思想和行动统一到党中央、国务院、省委和市委的部署上来，坚持底线思维、增强忧患意识，克服麻痹思想、消除侥幸心理，以“三严三实”的要求把各项工作做实、做细、做到位，坚决预防和遏制重特大火灾事故的发生，确保人民生命财产和社会稳定，经研究，决定在全市危化品领域开展岁末年初生产安全大检查工作，现将有关事项通知如下：

  一、检查对象

    1、危险化学品生产、储存经营企业和使用危险化学品从事生产的化工企业。

  2、涉氨制冷企业液氨使用。

二、工作重点

    各县（区、管委会）安监局要切实加强危险化学品生产、经营、运输、使用各个环节的安全监管工作，特别是加强易燃易爆化学品、危险工艺环节和涉氨制冷企业的安全检查。要督促化工（危险化学品）企业认真组织开展节前生产旺季、节后恢复生产期间的全面安全检查，严格按照《危险化学品企业事故隐患排查治理实施导则》要求，排查防冻、防火、防爆、防泄漏、防静电等方面措施落实情况，要特别做好设备、管线等重点部位的日常巡查，防止发生泄漏、火灾爆炸事故。要督促企业落实检维修作业期间特殊作业环节安全管理措施，做好节前停产期间及特殊节假日期间应急值班值守工作，确保岁末年初生产安全。

三、工作要求

    一要按照“党政同责、一岗双责、失职追责”的要求，从严落实安全生产属地管理责任，加强对岁末年初安全生产工作的领导，认真分析本地区危化品企业安全生产状况，研究制定切实可行的工作措施，确保本地区安全形势持续稳定好转。

    二要坚持问题导向，严格落实党政同责的监管责任、部门的直接监管责任和企业主体责任，开展横向到边、纵向到底的拉网式检查，深查细查严查重点企业和重点部位，要紧紧盯住安全生产基础薄弱、隐患和问题较多的企业，督促、指导危化品生产经营单位全面排查治理事故隐患，及时解决影响安全生产的突出矛盾和问题。

    三要进一步深化企业安全生产标准化提升建设，增强应急救援能力，强化安全培训，提高全员安全意识，要进一步推进企业落实主体责任，强化企业把安全责任层层落实到每个环节、每个岗位和每个职工。

各县（区、管委会）安监局要立即将本通知精神传达到各属地危化品企业，指导督促企业立即开展自查自纠，要组织力量对本辖区所有危化品企业进行全面检查，市局将按不少于30%的比例进行抽查。检查工作开展情况总结请于2016年3月31日前报市局。

 

 

 

莆田市安全生产监督管理局

                            2016年1月14日
