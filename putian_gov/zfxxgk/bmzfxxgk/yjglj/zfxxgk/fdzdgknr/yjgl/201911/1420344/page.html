关于开展全面排查整治危险化学品企业安全隐患互查工作的通知

发布时间：2011-09-21 08:00
| | |

内部明电

 

发往

地址

见报头

签批：

盖章：

 陈金晃

等级    特急             部委号：莆安监明电〔2011〕3号

 

 

 

各县（区、管委会）安监局（科）：

根据市安监局《关于印发莆田市全面排查整治危险化学品企业安全隐患实施方案的通知》（莆市安监〔2011〕123号）要求，决定从9月26日—30日，由各县（区、管委会）安监局（科）抽调有关人员组成督查组，对其他县（区、管委会）安监局（科）贯彻落实莆田市全面排查整治危险化学品企业安全隐患工作开展情况进行互查。现将有关事项通知如下：

一、各县（区、管委会）安监局（科）领导要高度重视，认真按照市安监局《关于印发莆田市全面排查整治危险化学品企业安全隐患实施方案的通知》（莆市安监〔2011〕123号）文件要求，实事求是、高度负责地完成互查工作，严防马虎应付走过场。

二、本次互查全市共分七个组。各县（区、管委会）安监局（科）要派1位领导带队，并派2-3名有经验的干部参加。具体分组和督查单位名单见附件。

三、各组互查时间原则上为1-2天，此次互查采取查阅相关资料与现场检查相结合的方式，各检查组要对县（区、管委会）安监局（科）危险化学品企业安全隐患活动开展情况进行检查，同时至少要抽查一个乡（镇、街道）安监站（中队）、1-2家生产性企业，2-3家危险化学品经营单位（甲证），5家以上其他危险化学品经营单位（乙证）。

四、各县（区、管委会）安监局（科）全面排查整治危险化学品企业安全隐患互查情况由组长单位形成书面材料（电子版），于10月10日前通过办公系统或局邮箱报送市局三科，并由市局汇总后进行通报。

联系人：吴爱红，联系电话：0594-2333662，邮箱：fjptajj@163.com。

 

 

附件：全面排查整治危险化学品企业安全隐患县（区、管委会）互查名单。

 

二〇一一年九月二十一日
