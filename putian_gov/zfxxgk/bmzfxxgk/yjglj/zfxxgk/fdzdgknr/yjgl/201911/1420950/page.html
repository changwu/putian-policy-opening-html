市政府安委会办公室关于切实加强第一届全国青年运动会期间安全生产工作的通知

发布时间：2015-10-13 08:00
| | |

发往

盖章：

等级    特提             部委号：莆安办明电〔2015〕16号

 

 

 

各县（区）人民政府（管委会）安委会，市直有关单位：

第一届全国青年运动会将在我省举行，2015年10月18日至10月24日在我市赛区进行射箭、射击项目。为确保青运会期间全市安全生产形势持续稳定，现就有关安全生产工作提出如下要求：

    一、强化安全生产责任，严格落实安全防范措施。青运会期间人流车流物流增多，影响安全生产的不稳定、不确定性因素增大，极易造成事故易发、高发。全市各级各有关部门和单位要进一步强化安全生产红线意识和底线思维，按照“党政同责、一岗双责、失职追责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”要求，加强组织领导，全面落实安全生产责任，认真分析研判青运会期间安全生产工作的特点和规律，周密部署安排，狠抓各项安全措施落实。

二、突出工作重点，全面排查整治安全隐患。全市各级各有关部门和单位要按照《莆田市人民政府安委会关于印发全面开展安全生产大检查、深化“打非治违”和专项整治工作实施方案的通知》（莆市安〔2015〕11号）要求，继续深入开展安全生产大检查、打非治违及危险化学品和易燃易爆物品大检查大整治，突出道路交通、消防、危险化学品、建筑施工、非煤矿山、烟花爆竹、特种设备、冶金等重点行业领域，突出重点地区、重点部位、重点环节和重点单位，全面彻底排除治理安全隐患。要针对青运会期间车流量大的特点，落实预案，科学应对，加大车流量监测、管控，强化路面巡查执法，严厉打击各类交通违法违规行为，确保青运会期间交通安全；从严整治不具备安全条件、违章经营和“三合一”等存在重大火灾隐患场所；要加强对人员密集场所各项内容的安全检查，制定并落实安全措施，严防拥挤踩踏等群死群伤事故发生。

三、加强值班值守，全面提升应急处置水平。各级各有关部门和单位要严格执行领导干部带班值班和关键岗位24小时值班制度，严格执行信息报告制度，做好生产安全事故和其他紧急突发事件的信息报送和处置工作，确保事故信息和其他重要信息及时、准确上报。要密切关注互联网、新闻媒体等舆情动态及群众举报信息，及时组织核查，属实的要按照规定上报并妥善处置。进一步完善生产安全事故应急救援预案，一旦发生事故或紧急情况，立即启动应急响应，地方政府及有关部门负责人要迅速赶赴现场，第一时间组织开展应急救援和处置工作。

 

 

莆田市政府安委会办公室
