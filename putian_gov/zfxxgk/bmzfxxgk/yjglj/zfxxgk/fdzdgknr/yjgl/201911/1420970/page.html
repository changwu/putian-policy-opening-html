关于开展全市工贸行业企业安全生产大检查督查情况的通报

发布时间：2017-08-17 15:29
| | |

 

 

 

 

 

 

 

莆市安监〔2017〕104号

 

 

各县（区、管委会）安监局：

为进一步推动冶金、有色、建材、机械、轻工、纺织等工贸行业企业安全生产大检查深入开展，根据《关于印发莆田市安监局安全生产大检查工作方案的通知》（莆市安监〔2017〕75号）精神，市安监局从7月中旬开始对全市部分工贸企业安全生产大检查开展情况进行督查，现将督查情况通报如下：

一、督查总体情况

督查组采取查资料、看现场等方式，对工贸行业10家企业安全生产大检查开展情况进行督查。从督查的情况看，各县（区）安监局能认真贯彻落实上级统一部署，行动迅速、措施有力,各项工作取得一定成效。各企业能开展安全生产自查自纠，对检查安全隐患能及时整改。但也存在一些问题，部分企业未能制定安全生产大检查方案或未能结合实际，简单照搬照抄；安全隐患排查不够彻底，各项制度落实不够到位。

二、下一步工作要求

一是各县（区、管委会）安监局要持续推进工贸行业企业安全生产大排查大整治深入开展，深刻领会安全生产大排查大整治和大检查之间的关系，克服麻痹思想、厌烦畏战的情绪。要抓住关键问题，采取“回头看”“找茬”和“挑刺”等形式开展督导检查，有步骤、有节奏地梯次加强安全生产执法力度，消除安全盲区和死角，确保工贸行业企业生产安全。

二是要继续督促工贸行业企业进一步落实企业主体责任，开展安全生产自查自纠工作，加强对重点场所、要害部位、关键环节检查，对排查发现的安全风险和事故隐患要有清单、有台账、有措施，严格落实事故隐患整改责任、措施、资金、时限、预案“五到位”。

三是要加大宣传力度，拓展宣传广度，延伸宣传深度，积极引导广大群众举报工贸企业各类非法违法行为，营造安全生产浓厚氛围。

请各县（区、管委会）安监局于8月31日前将通报中问题整改情况反馈市安监局，联系人：陈志鹏，联系电话：2392566。

附件：工贸行业企业安全生产大检查督查情况汇总表
