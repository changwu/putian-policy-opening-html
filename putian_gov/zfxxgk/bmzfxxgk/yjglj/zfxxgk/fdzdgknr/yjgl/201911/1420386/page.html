关于危险化学品重大危险源安全监管工作督查情况的通报

发布时间：2013-12-25 08:00
| | |

莆市安办〔2013〕80号

 

 

 

 

各县（区、管委会）安委会办公室，市直有关单位：

为加强我市危险化学品重大危险源安全监管工作，落实企业安全生产主体责任和政府部门监管责任，根据《莆田市人民政府安委会办公室关于加强危险化学品重大危险源安全监管工作的通知》（莆市安办〔2013〕54号）要求，市安办于12月5日至10日对各县区安办开展危险化学品重大危险源安全监管工作情况进行督查。现将督查情况通报如下：

一、总体情况

本次督查内容主要为：危险化学品重大危险源安全监管工作开展情况，闽安委〔2012〕28号和莆市安办〔2013〕54号文件落实情况；重大危险源安全监管台账建立情况；辖区内重大危险源企业辨识分级、评估备案、监测监控情况。

督查组通过查阅内页、现场交流、抽查企业等方式，了解各县区安办及危险化学品重大危险源行业主管部门开展重大危险源安全监管工作的进度和实际遇到的问题。从督查情况看，各县区安办及有关行业主管部门能认识到重大危险源安全监管工作的重要性，按照“属地管理，分级负责”、“管行业必须管安全”的原则,推动辖区及行业领域内重大危险源企业安全生产主体责任的落实；按照9月27日市安办加强危险化学品重大危险源安全监管工作会议的部署，指导、督促重大危险源企业开展辨识分级和评估备案工作。目前各县区（除湄洲岛管委会）已重新评估备案的企业数为：城厢2家、荔城1家、涵江1家，仙游0家、秀屿0家、北岸0家。督查发现，城厢区重大危险源安全监管工作落实情况较好，深刻领会有关法律法规、文件通知和会议精神，指导住建、水利等有关行业主管部门做好重大危险源评估和备案事宜，发函督促未重新评估的重大危险源企业及时报备，对已发现重大危险源的企业及时上门跟踪服务；荔城区安办会同经贸、公安部门，督促民爆生产、销售和使用企业按照要求进行重大危险源评估备案，将重大危险源企业备案资料整理归档、装订成册。涵江区安办跟踪指导重大危险源企业开展备案和监控工作。

二、存在的主要问题

从督查情况看，全市危险化学品重大危险源安全监管工作全面展开，各县区安办及有关行业主管部门推进有力，取得了一定成效,但也发现县区开展重大危险源评估备案工作进度不平衡，主要问题有：

（一）工作部署流于形式

督查发现，部分县区对重大危险源安全监管文件只是简单转发，对重大危险源安全监管工作的认识明显不足，以转发代替落实，流于形式，未将市安办会议精神及时完全地传达到各有关行业主管部门。个别行业主管部门不清楚重大危险源监管有关法律法规、规范和上级文件的要求；不清楚本行业领域内重大危险源企业存放危险品的种类、数量和评估备案及监控情况；不清楚重大危险源安全监管要管什么、如何管。

（二）检查排查不到位

督查发现，各县区能结合全市安全生产大检查和危化品专项检查行动开展重大危险源的安全检查，但普遍未按照莆市安办〔2013〕54号通知要求开展辖区内覆盖全行业的危险化学品重大危险源监督检查，排查不到位，可能出现漏报情况。

（三）主动服务意识不强

督促发现，部分县区安办未主动协调有关行业主管部门督促重大危险源企业开展评估备案事宜，工作落实不到位；对已发现重大危险源的企业未主动跟踪指导评估、备案、监控事宜，主动服务意识不强。

（四）业务水平有待提升

督查发现，城厢区重大危险源安全监管台帐较为齐全，荔城区企业备案材料齐全，其他县区的重大危险源安全监管台帐大多不完整，台账中缺少安全监管依据和规范标准、各级通知要求、落实整改情况、检查排查记录等内容，个别县区甚至未建立监管台帐；部分县区的业务人员对重大危险源的监管范围、辨识标准、备案程序不熟悉，反映了县区有关部门及业务人员未深入学习领会有关法律法规、政策文件和监管会议精神，未能认真钻研业务、总结监管工作的经验和不足，业务水平有待提升。

三、下一步工作意见

（一）加强业务学习培训，提高监管能力水平。各级各有关行业主管部门要提高对重大危险源安全监管专业性的认识，业务领导和负责人首先要带头学习业务，清楚重大危险源安全监管的责任和内容；业务经办人员要主动学习掌握业务知识，增强责任感，指导督促企业做好重大危险源评估备案工作。

（二）全面开展检查排查，建立健全监管台帐。各级各有关行业主管部门要充分认识到危险化学品重大危险源事故群死群伤的危害性和安全监管工作的重要性，深刻汲取近期吉林“6·3”特别重大火灾爆炸事故和上海“8·31”重大氨泄漏事故教训，结合当前全市安全生产大检查“回头看”工作，根据莆市安办〔2013〕54号通知要求，加强对辖区内和行业领域内危险化学品重大危险源监督检查，检查中发现新的重大危险源，要督促重大危险源单位开展辨识评估备案工作，并建立健全重大危险源安全监管台帐，。

（三）建立监管长效机制，定期开展专项督查。各县区安办要结合工作实际，完善重大危险源安全监管机制，大力协调各级各有关部门履行好安全监管责任，主动靠前服务重大危险源企业落实好安全生产主体责任，及时将工作中发现的问题向市安办反馈。各县区安办要定期开展对有关行业主管部门重大危险源安全监管工作的专项督查，于2014年1月18日前将发现问题整改情况以文件报市安办。

 

莆田市人民政府安委会办公室  

2013年12月24日
