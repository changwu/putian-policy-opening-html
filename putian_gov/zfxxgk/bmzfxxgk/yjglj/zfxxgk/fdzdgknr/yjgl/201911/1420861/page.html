关于公布莆田市非煤矿山安全生产标准化三级达标企业名单的通知

发布时间：2012-12-12 08:00
| | |

莆市安监〔2012〕128号

 

 

 

各县(区、管委会)安监局（科）：

根据《国家安全监管总局关于进一步加强非煤矿山安全生产标准化建设工作的通知》(安监总管一〔2011〕104号)的规定，我局组织有关矿山技术专家并会同仙游县安监局人员，对仙游县龙华金溪村大湖底采石场等4家申报非煤矿山安全生产标准化三级达标验收的企业进行考评，根据专家综合评定，并经网上公告、市安监局审核确认，上述4家非煤矿山企业符合安全生产标准化三级达标要求，现予公布（名单附后），有效期至2015年12月2日。

 

附件：莆田市非煤矿山安全生产标准化三级达标企业名单。                                                   

 

莆田市安监局

2012年12月12日

 抄送：局领导、局相关科室。
