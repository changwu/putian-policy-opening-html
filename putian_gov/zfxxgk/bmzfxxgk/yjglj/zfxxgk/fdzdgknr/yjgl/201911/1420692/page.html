关于开展危化品安全知识竞赛活动的通知

发布时间：2008-06-10 08:00
| | |

 

莆市安监〔2008〕64号

 

 

各县（区、管委会）安监局（科），本局有关科室：

    为加强安全意识，提高我市安监系统危化品监管人员的执法水平和应对突发事件的能力，决定结合全国安全生产百日督查专项行动和安全生产月活动，于6月下旬开展全市危化品安全知识竞赛活动，现将竞赛活动方案印发给你们，请认真组织实施。

 

 

二〇〇八年六月十日

 

 

关于开展危化品安全知识竞赛活动方案

 

    为提高对危化品安全事故的认识，强化危化品事故预防和防护能力，提高危化品行业监管人员和执法人员专业技能和应对危化品安全突发事件能力，结合安全生产百日督查专项行动和全国安全生产月活动，市局决定开展危化品安全知识竞赛活动，具体方案如下

    一、时间

    2008年6月27日上午9：30-10：30

    二、对象

    本次竞赛参加对象：全市安监系统危化品安全监管人员、执法队，包括：市局公共设施科、执法支队、县区安监局危化品监管股室、执法大队及乡镇（街道）安监站监管人员。

    三、形式

    竞赛采取笔试的形式，由各县区安监局自定考场分别组织辖区内相关人员（含乡镇（街道）安监站人员）笔试，市局在27日上午将派人前往发试卷并监考。市局笔试将在1号楼248室组织市局公共设施科、执法支队相关人员参加。

    四、内容

    1、竞赛采取笔试形式，参赛人员要积极准备，须“公平、公正”的参加本次竞赛。

    2、竞赛的范围为危化品安全知识（可到市局网站http://www.ptsafety.gov.cn/aqdt/aqcs/2008610153440.html  下载），题型为：判断、选择（单选、多选）、简答。

    3、笔试考卷统一由市局制作，分为两个奖项：个人奖和集体奖。个人奖，取个人总分前16名，设一等奖1名、二等奖3名，3等奖12名。集体奖，取集体平均分的前三名，分别设一等奖、二等奖、三等奖各1名。成绩奖项将公示在市局网站上。

    五、要求

    1、各县（区、管委会）安监局（科）要认真组织部署，确保辖区内危化品监管人员、执法人员和乡镇（街道）安监站人员参考率达100%。

    2、请各县（区、管委会）安监局（科）统计本次竞赛参考人员名单并于6月20日前上报市局，发送参考人员名单至电子邮箱ptsafetyidea@163.com 。
