莆田市安全生产监督管理局关于开展安全生产培训工作专项检查的通知

发布时间：2012-08-07 08:00
| | |

 

莆市安监〔2012〕84号

 

 

各县（区、管委会）安监局（科）：

安全生产培训是安全生产领域一项重要的基础性工作，是减少生产安全事故和伤亡人数的源头性、根本性举措，是提升安全管理水平和职工安全素质，构建安全生产长效机制的重要措施。为加强安全生产培训管理，规范安全生产培训秩序，根据《国家安全监管总局关于进一步加强安全培训监督检查工作的意见》（安监总培训〔2012〕57号）和市政府安委会《关于开展安全生产“百日大检查”活动的通知》（莆安委明电〔2012〕2号）要求，经研究决定，在全市范围内开展安全生产培训工作专项检查。现将有关事项通知如下：

一、工作目标

认真贯彻落实《国务院办公厅关于继续深入扎实开展“安全生产年”活动的通知》（国办发〔2012〕14号）关于安全培训的规定和要求，结合我市开展安全生产“百日大检查”活动、“打非治违”专项行动和隐患排查治理工作，加强安全生产培训执法检查，依法依规，严厉打击和查处无证上岗和未经培训或培训不合格就安排上岗作业的行为，有效防止和减少违章指挥、违章作业、违反劳动纪律等现象，促进我市安全生产形式继续保持平稳。

二、阶段任务

自2012年8月15日开始至2012年11月30日结束，共分为动员准备、检查执法、整改督查、分析总结四个阶段。

（一）动员准备阶段（8月15日至8月31日）

成立领导机构，制定专项检查方案，对全市安全生产培训情况调查摸底。动员部署各县（区、管委会）安监局（科）全面开展安全生产培训工作专项检查。

（二）检查执法阶段（9月1日至9月29日）

指导企业开展安全生产培训工作自查，打击未经安全培训上岗作业和特种作业人员无证上岗现象。1 、各县（区、管委会）安监局（科）按照属地监管原则，指导辖区内企业做好安全培训工作，加大安全生产培训执法力度。2、市局对特种作业培训考核情况进行检查，对安监部门违规发文组织培训、培训机构违规办班、安监系统内个人违规参与培训费和考试费的收取等行为给予有关责任人员严肃处理。

（三）整改督查阶段（10月8日至10月31日）

继续推进安全生产培训检查工作，各县（区、管委会）安监局（科）督促企业建立健全安全培训档案，对检查发现问题回头看，确保专项检查落到实处。市局将派出督查组对各县区开展专项检查和执法情况进行抽查，确保安全生产培训检查不流于形式。

（四）分析总结阶段（11月1日至11月30日）

对本次检查情况进行深入剖析，认真分析我市安全培训现状和存在问题，总结企业安全教育培训经验和基层安全培训监督检查经验，推动我市安全生产培训工作的良好发展。

三、工作要求

（一）加强组织领导。安全生产教育培训是安全生产工作的基础，各县（区、管委会）安监局（科）要高度重视本次专项检查的重要性，加强组织领导，确保责任落实，制订详细检查方案，明确职责和任务，切实将专项检查部署落实到每个企业。

（二）加强指导检查。各级安监部门要广泛深入企业，帮助指导企业开展安全生产培训工作自查，督促企业落实安全生产培训主体责任，加大安全教育培训投入，按照《生产经营单位安全培训规定》（国家安监总局令第3号）要求做好从业人员安全教育培训工作，建立健全企业安全生产培训内业档案。

（三）加强监管执法。各级安监部门要深入学习领会《安全生产培训管理办法》（国家安监总局令第44号）精神，提高安全生产培训业务水平，依据《办法》第四十一条规定，加强对企业安全培训情况的监督检查，并以安全生产“百日大检查”活动为契机，加大监管执法力度，严厉打击无证上岗现象，切实履行部门监管职责。

（四）加强经验总结。各县（区、管委会）安监局（科）要对专项检查情况形成书面总结，认真分析辖区内企业安全培训现状和存在问题，提出企业好的经验做法，并填写《安全培训专项检查情况表》，于11月30日前一并报市局应急救援中心。

 

附件：《安全培训专项检查情况表》

 

莆田市安全生产监督管理局
