关于2011年上半年中央属、省属驻莆企业和市属企业安全生产责任制落实情况的督查通报

发布时间：2011-09-15 08:00
| | |

莆市安办〔2011〕54号

 

各县（区）人民政府（管委会）安办、市直相关部门，各中央属、省属驻莆企业、市属企业：

根据市委、市政府的部署和要求，2011年7月12日至13日，市政府安办组织相关人员，采取听取汇报、查阅资料、现场检查和反馈交流等方式，对部分中央属、省属驻莆企业和市属企业2011年上半年安全生产责任制落实情况进行督查。现将督查情况通报如下：

一、基本情况

从督查情况看，今年以来，中央属、省属驻莆企业和市属企业都能重视安全生产工作，认真贯彻市委、市政府有关安全生产的工作部署，紧紧围绕“安全生产年”和“责任落实年”的各项工作要求，加强领导，落实责任，健全制度，完善机制，深入开展落实企事业安全生产主体责任“三年行动”和“平安企业”创建工作，切实消除各类安全隐患，取得了较好的成效，安全生产形势保持稳定平稳的态势。主要措施有：

一是领导重视，进一步健全完善安全生产责任体系。中央属、省属驻莆企业和市属企业领导能重视安全生产工作，把安全生产事故工作纳入重要议事日程，坚持每季度召开一次安全生产专题工作会议，研究部署各时段的安全生产工作，真正做到“一把手”亲自抓，负总责，做到与各项日常工作同部署、同检查、同落实。各企业领导能根据本单位的工作实际，建立健全安全生产工作机构，配备专兼职安全管理人员，完善各项安全规章制度，认真抓好安全生产责任制的落实，将目标责任层层分解，落实到具体岗位和人员。如移动莆田分公司每年层层签订安全生产目标责任书，将安全生产管理工作纳入公司管理效能考核，与考核奖金直接挂钩，通过建立目标考核与责任追究相结合的考核体系，强化安全责任管理，使安全生产责任制有效执行到位。

二是率先示范，积极推进企业主体责任落实。中央属、省属驻莆企业和市属企业作为全市企业的排头兵，能积极贯彻上级有关落实企业主体责任会议精神和部署要求，进一步明确职责分工，结合单位实际，细化企业级别评定标准，通过宣传发动、教育培训、典型引路、自查自评等方式，推进企业主体责任“三年行动”和“平安企业”创建活动深入开展，起到了很好的模范带动作用。如电信莆田分公司、莆田烟草公司等企业按照《级别评定实施方案》，结合本单位实际，认真开展自查自评，排查各类安全隐患，建立安全检查制度、隐患排查治理制度等一系列规章制度，对发现的安全隐患能制定整改方案，落实整改资金，明确整改责任人和整改期限，确保安全生产，在全市率先达到安全生产A级企业评定目标和一级“平安企业”。

三是深化治理，有效排查事故隐患。中央属、省属驻莆企业和市属企业能按照省、市关于开展隐患排查治理和“打非治违”专项行动的统一部署，制定细化工作方案，明确自身职责，采取有效措施，排查治理各类隐患，纠正各类“三违”行为，并做到有排查、有台帐、有反馈、有落实。同时各企业还能通过发动企业员工举报安全隐患、举办隐患排查治理知识竞赛等形式，积极开展全方位、多层次、多角度的隐患排查活动。如莆田交通投资集团对湄洲（文甲）对台旅游集散中心配套基础设施建设项目工程，定期或不定期地进行监督检查，督促项目部完善各项安全事故应急救援预案，确保工程安全施工；中行莆田分行认真落实各项安全防范措施，在元旦、春节、五一等重大节日期间开展安全生产大检查活动，上半年共排查出各类安全隐患33处，全部整改落实到位。

四是加大投入，不断提升企业本质安全。中央属、省属驻莆企业和市属企业通过加大资金投入，更新改造安全设施，强化应急演练，安全保障能力和监管水平有了进一步提高。如市邮政局投入资金100多万元，完成监控中心主体建设，并为邮政车辆补充更新灭火器、安全工具包等安全防护设备，强化安防措施和网点监控；联通莆田分公司投入120多万元，在新大楼建设技防设施、自动灭火系统和防火防盗门，安全防范设施进一步完善。

五是强化宣教，营造良好的安全生产氛围。中央属、省属驻莆企业和市属企业积极创新宣教形式，以“安全生产月”活动为契机，大力宣传安全生产法律法规、安全生产常识，进一步提高了企业员工安全意识和素质。如市邮政局投入近万元培训基金，加强对保安人员的专项培训，开展对广大员工的安全知识教育，提高员工综合素质和应急处理能力；电信莆田分公司通过开展基层安全生产管理标准化建设竞赛活动，强化员工安全意识和自我防范能力。

二、存在的主要问题

今年以来，中央属、省属驻莆企业和市属企业在安全生产责任制落实、安全生产主体责任级别评定和“平安企业”创建工作方面做了大量的工作，取得了较好的成效，但仍存在一些薄弱环节和问题。主要表现在：

一是企业主体责任仍未得到有效落实。一些企业没能按照上级要求，切实开展落实安全生产主体责任级别评定和“平安企业”创建工作；没能结合自身工作实际，有针对性地开展工作，存在照抄照搬现象，没有具体的落实措施，缺乏操作性；有的企业文件资料零散，记录不规范，台帐缺项严重，安全制度不完善，执行不够到位。

二是企业隐患排查有待进一步深化。部分企业对隐患排查治理和“打非治违”工作没有专题部署，没有制定具体实施方案，隐患排查治理台账不健全，对于工作中发现的一些安全隐患，没有落实整改措施、投入整改资金，未能及时消除安全隐患或落实防范措施，使隐患排查治理流于形式。

三是企业教育培训还不全面。个别企业对员工安全教育培训不够广泛、深入，存在安全生产管理人员及特种作业人员没有持证上岗或复审，对员工没有及时进行三级教育就仓促上岗等现象，一些员工甚至认为安全生产仅是保卫方面的事，导致安全生产职责不清。

三、下一步工作意见

一要进一步落实安全生产责任制。各中央属、省属驻莆企业及市属企业要高度重视安全生产工作，认真研究、落实安全生产责任制。建立健全安全生产工作机构，配齐专兼职安全管理人员。制定各项工作制度，狠抓落实。进一步明确安全生产职责范围、职责内容及相应责任，并将安全生产的责任目标进行细化、量化，分解到相关领导、相关部门、相关人员、各生产经营车间、班组。及时协调解决存在的困难和问题，研究针对性措施，狠抓各项安全防范措施落实。

二要进一步推进企业安全生产主体责任级别评定、“平安企业”创建和安全生产标准化建设工作。各中央属、省属驻莆企业及市属企业要按照省政府《意见》、市政府《实施意见》精神，持续推进企业安全生产主体责任“三年行动”和“平安企业”创建，确保全面完成预定的工作目标。认真贯彻落实《国务院安委会关于深入开展企业安全生产标准化建设的指导意见》（安委[2011]4号）精神，全面推进企业安全生产标准化建设，实现岗位、专业和企业达标，夯实企业安全生产基础。

三要进一步深化隐患治理排查工作。各中央属、省属驻莆企业及市属企业要结合本单位实际情况，针对安全隐患排查治理工作中的薄弱环节，按照市政府安委会《关于立即开展全市安全生产大检查的通知》（莆安委明电〔2011〕4号）和市政府安办《关于组织开展安全生产大检查和隐患排查治理工作督查的通知》（莆安办明电〔2011〕7号）要求，继续深入开展安全隐患排查治理，对排查出的隐患要落实整改措施，及时消除安全隐患，从源头上预防和减少各类事故的发生。

四要进一步强化安全生产教育培训。各中央属、省属驻莆企业及市属企业负责人、安全生产管理人员和特种作业人员必须持证上岗，定期参加复审。要制定安全宣传教育的规划和方案，拓展、创新安全宣传教育内容与形式，积极开展员工“三级”教育和岗前培训，提高宣传教育效果，提升企业员工安全意识和安全素质。

 

                                   二〇一一年九月十五日
