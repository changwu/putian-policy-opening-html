关于开展电梯安全监管大会战督查工作的通知

发布时间：2015-08-12 08:00
| | |

莆市安办〔2015〕52号

 

 

各县（区）人民政府（管委会）安委会，市直各有关单位：

根据市政府安委会办公室《关于印发莆田市电梯安全监管大会战工作方案通知》（莆市安办〔2015〕24号）文件要求，决定对各县（区）人民政府（管委会）、部分市直重点单位开展电梯安全监管大会战情况进行督查。现将有关事项通知如下：

一、督查时间

    2015年9月8日至9月15日。

二、督查内容

1、贯彻落实省政府办公厅《关于进一步加强电梯使用安全工作的意见》（闽政办〔2015〕100号）、市政府安委会办公室《关于印发莆田市电梯安全监管大会战工作方案通知》（莆市安办〔2015〕24号）、市质监局《关于立即开展自动扶梯与自动人行道安全检查的紧急通知》（莆质监〔2015〕85号）等文件的情况；

2、电梯使用单位、电梯维保单位开展自查自纠及隐患整治情况；

3、各级政府和行业主管部门开展督促检查情况；

4、存在问题和整改防范措施及应急措施制订落实情况。

三、督查方式

采取听取工作汇报、查阅资料、现场检查等方法进行。督查县（区、管委会）时，抽查1个乡镇（街道）、1个（区、管委会）部门、1个电梯使用单位和1个电梯维保单位；督查市直重点单位时，抽查1个电梯使用单位。

四、督查组成员及分工

第一组：负责督查仙游县、市商务局、市文化广电新闻出版局、。

组  长：黄玉明（市安监局局长）

成  员：陈酉鹤（市安监局宣教中心主任）

        陈飞峰（市质监局特安科负责人）

    第二组：负责督查荔城区、涵江区、市住建局、市教育局。

组  长：吕正山（市质监局局长）

成  员：林铸强（省特检院莆田分院检管部主任）

        佘雷勇（市安监局宣教中心科员）         

第三组：负责督查城厢区、市经信委、市卫计委。

组  长：唐新裕（市安监局副调研员）

成  员：陈  旻（省特检院莆田分院副院长）

        张玉栋（市安监局宣教中心科员）

第四组：负责督查秀屿区、湄洲岛管委会、北岸开发区管委会、市旅游局、市体育局。

组  长：卓金通（市质监局副局长）

成  员：吴  伟（市质监局特安科主任科员）

        赵丹丹（市安监局宣教中心科员）

五、工作要求

（一）各县（区、管委会）安委会、市直重点单位要积极配合，认真做好工作台帐、相关文件及资料等迎检准备工作。

（二）各督查组要按照督查时间、方式要求，认真对照督查内容，负责地开展督查工作。督查结束后，请各督查组将督查情况整理形成书面材料，于9月18日前将督查情况报送市电梯安全监管大会战领导小组办公室。

（三）各县（区、管委会）安委会、市直各有关单位要对本辖区本行业（领域）内电梯安全监管大会战开展情况进行督查。督查情况要整理形成书面材料，于8月28日前报送市电梯安全监管大会战领导小组办公室。

（四）各级各部门要将督查结果纳入本地区、本单位年度安全生产目标责任制考核内容。

联系人：陈飞峰，联系电话：2651390，13859850019。
