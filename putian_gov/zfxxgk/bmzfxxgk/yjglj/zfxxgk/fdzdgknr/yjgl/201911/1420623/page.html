关于印发莆田市开展非煤矿山安全生产“严整治、促提升”专项行动实施方案的通知

发布时间：2018-05-17 10:46
| | |

莆市安监〔2018〕68号

 

 

    现将《莆田市开展非煤矿山安全生产“严整治、促提升”专项行动实施方案》印发给你们，请认真组织实施。

 

                         

                     

                     莆田市安全生产监督管理局     

                            2018年5月10日

 

 

莆田市开展非煤矿山安全生产

“严整治、促提升”专项行动实施方案

 

 为认真贯彻落实国务院、省、市有关领导批示指示精神，深刻吸取莆田“5·4”事故教训，根据福建省人民政府安全生产委员会办公室《关于深刻吸取莆田“5·4”事故教训立即开展安全生产大检查的紧急通知》（闽安委办明电〔2018〕12号）、中共莆田市委办公室和莆田市人民政府办公室《关于迅即组织开展安全生产“严排查、严整治、严监管”活动的通知》（莆委办发电〔2018〕34号）和莆田市人民政府安全生产委员会《关于开展安全生产“严整治、促提升”专项行动的通知》（莆安委明电〔2018〕3号）文件精神，结合全市实际，制定本实施方案。

一、总体要求

全面贯彻落实党的十九大精神，以习近平新时代中国特色社会主义思想为指导，牢固树立安全发展理念，弘扬生命至上、安全第一的思想，突出问题导向、目标导向、效果导向，深化非煤矿山企业安全专项整治，强化安全生产监管执法，推动企业落实主体责任，构建风险分级管控和隐患排查治理双重预防工作机制，切实“控风险、除隐患、防事故”，确保全市安全生产形势持续稳定好转，为第五届世界佛教论坛、第三届世界妈祖文化论坛等重大活动顺利举办创造安全稳定的社会环境。

二、工作目标

通过开展专项行动，狠抓持证非煤矿山安全隐患排查整治，严打持证非煤矿山非法违法生产经营，切实把源头治理挺在安全风险管控前面，把安全风险管控挺在隐患前面，把隐患排查治理挺在事故前面，查缺补漏、精准发力，增强安全防范治理能力，促进隐患整改、监管执法、应急管理、安全防控四项工作全面提升，有效防范和坚决遏制持证非煤矿山企业各类事故发生。 

三、 组织领导

为加强我市持证非煤矿山安全生产专项行动的综合协调和监督检查，市安监局成立全市持证非煤矿山安全生产专项行动工作领导小组。

组  长：蔡国萍

副组长：陈德全

成  员：郑祖敏、顾斌、张建安、陈志鹏、龚冠华

领导小组办公室设在市局监管二科，郑祖敏同志兼任办公室主任。

    四、检查主要内容

    (一）是否依照非煤矿山开采设计方案，规范非煤矿山开采行为；是否遵循自上而下的开采顺序，落实分台阶（分层）开采；是否采用中深孔爆破技术；台阶高度、边坡角度等是否符合设计要求；是否采用机械铲装、机械二次破碎；是否未经设计乱采滥挖及未按设计建设和开采；是否建立隐患排查制度，隐患排查治理是否到位；是否及时对工作帮坡面浮石、危石和伞檐体进行处理；是否制定防治职业危害的具体措施，并为从业人员配备符合国家标准或者行业标准的劳动防护用品；。

    （二）台阶高度、边坡角度、安全平台宽度是否符合规程要求；排水防洪设施、排水能力是否满足汛期要求；排土场排土工艺、排土顺序、安全平台宽度是否符合设计要求；排土场安全度汛措施是否落实。

（三）是否及时掌握汛情、气象情况，做好灾害性信息预警预报，妥善应对突发情况；是否加强应急救援队伍值班备勤和应急物资配备，认真组织开展应急救援演练，提升应急处置能力；是否加强应急值守，严格落实领导带班和24小时值班制度。

五、时间安排及重点任务：

专项行动从即日起至12月31日止，分四个阶段开展。

第一阶段（动员部署阶段，即日起至5月15日）。召开专题会议研究部署专项行动工作，组织制定实施方案，落实保障措施，建立持证非煤矿山专项行动整治台账，编制非煤矿山安全生产检查表，充分利用各类媒体对持证非煤矿山安全生产专项行动进行宣传发动,并动员部署组织持证非煤矿山企业开展安全生产排查整治工作。

第二阶段（集中整治阶段，5月16日至9月30日）。按照中共莆田市委办公室和莆田市人民政府办公室《关于迅即组织开展安全生产“严排查、严整治、严监管”活动的通知》（莆委办发电〔2018〕34号）文件要求，从隐患整改、监管执法、应急管理、安全防控等方面深挖细究。组织持证非煤矿山企业按照相关法律法规、规程规范和技术标准要求,全面评估本单位安全生产状况，进行风险隐患自查自纠，立查立改,签订企业安全生产自查自改承诺书,并进行备案存档。市安监局对县（区、管委会）安监局督查全覆盖，对持证非煤矿山企业督促检查全覆盖，县（区、管委会）安监局对辖区内的持证非煤矿山企业做到督促检查全覆盖。对表对标开展全面细致的安全生产监督检查，对排查出的安全风险和事故隐患全部建立清单台账，定准整治对策和防范措施, 明确整改时限，逐一进行问题隐患“清零”。

第三阶段（重点防控阶段，10月1日至11月30日）。突出第五届世界佛教论坛和第三届世界妈祖文化论坛等重点时段，采取 “找茬”和“挑刺”等形式，对持证非煤矿山企业开展安全生产专项督导，并对前一阶段发现的问题隐患整改情况开展“回头看”复查。全面加强值班值守、应急准备和安全防范，必要时还可选派干部、专家到持证非煤矿山企业进行蹲点驻守，严防死守、盯死看牢。

第四阶段（总结提升阶段，12月1日至12月31日）。结合岁末年初安全生产工作特点，继续对持证非煤矿山企业加强排查治理事故隐患、加强安全风险管控，确保形势持续稳定好转。要反思问题不足，固化经验做法，形成长效机制。

六、工作要求

（一）强化组织领导。各级安监部门要按照近期省、市有关安全生产工作部署要求，将专项行动提上重要工作日程，牢固树立责任意识和忧患意识，形成主要领导亲自抓，分管领导具体抓，一级抓一级，层层抓落实的良好局面。坚持问题导向，瞄准短板和薄弱环节，制定实施方案，成立专项行动领导小组，设立相应工作机构，及时研究和解决工作过程中存在的问题，切实推动专项行动深入开展。

（二）强化排查整改。各级安监部门要制定持证非煤矿山安全生产检查表，详细列明检查事项、具体内容和检查标准。对排查出的事故隐患和安全风险要做到“4个100%”,即:100%制表列出清单,100%建立台账,100%制订管控措施和整改方案,100%落实事故隐患整改责任、措施、资金、时限、预案“五到位”。对存在重大事故隐患的，要提请同级政府挂牌督办，依法责令停产停业治理。要切实加强督促跟踪，实行闭环管理，确保发现的问题隐患整治到位。

（三）强化督查指导。各级安监部门要采取暗访暗查、“四不两直”和“双随机”等方式，对本地区持证非煤矿山企业专项行动部署安排、组织开展、工作实效等方面进行认真的督查、检查、指导。专项行动期间，各级安监部门主要领导至少带队开展两次督导检查；各级安监部门分管领导在集中整治阶段每月至少带队开展一次督导检查，在重点防控阶段每半月至少带队开展一次督导检查，引导和督促各级安监部门深入开展持证非煤矿山企业专项行动。各县（区、管委会）安监局要每月重点督导检查基层问题隐患自查自改自报情况，并将督导检查情况报市安监局。

（四）强化应急管理。各级安监部门要围绕重点时段安全生产应急保障工作，强化安全生产值班值守，进一步规范事故信息接报和应急处置。要结合“安全生产应急演练周”等活动，组织开展持证非煤矿山企业应急演练，检验应急预案的有效性,锻炼队伍,检查并充实应急力量和资源，完善应急机制。要督促企业完善应急预案和各类应急保障措施，优化应急资源配置，提高事故应急处置能力。

（五）强化安全防控。各级安监部门要运用科技化、信息化手段加强安全生产防控，探索通过政府购买服务、开展基层“网格化+安全生产”等方式，创新安全生产工作。开展非煤矿山安全生产规律特点和“专项治理工程”研究，准确摸清掌握非煤矿山安全生产真实状况和突出问题，形成一整套可借鉴、可推广、可套用的非煤矿山企业安全生产风险管控和隐患排查治理双重预防机制。

（六）强化监管执法。各级安监部门要组织开展持证非煤矿山企业安全生产执法专项行动，规范检查执法程序，加大执法力度，充分运用“双随机”、明察暗访、联合执法、突击检查、专家会诊等方式，强化安全生产监管执法，严厉打击非法违法行为。重点对2017年各类督导督查检查发现事故隐患未“清零”,以及自查自纠未发现问题或未上报自查自纠情况的持证非煤矿山企业,开展严格的执法检查。对责任不落实、措施不到位、管理不严格的持证非煤矿山企业和安全生产违法违规行为要落实“四个一律”、“五个一批”要求,对执法检查中发现持证非煤矿山企业越界开采和无采矿许可证非煤矿山企业违法开采的移送国土部门依法处置。以最严格的执法,倒逼持证非煤矿山企业有效落实主体责任。

（七）强化舆论引导。各级安监部门要结合“安全生产月”等主题宣传活动，充分利用报纸、广播、电视、网络，借助各类新闻媒体，对专项行动进行广泛宣传发动、动员、引导社会各界广泛参与，积极举报持证非煤矿山企业各类违法违规行为和事故隐患。要组织观看警示教育片，从警示教育片中吸取教训，做到举一反三，做到思想上警钟长鸣、制度上严密有效、监督上严格细致。各级安监部门要及时组织报道先进典型和经验，对专项行动开展走过场、隐患排查治理不力的，对存在重大隐患问题和严重违法违规行为的企业予以公开曝光至。

（八）强化责任追究。各级安监部门要把专项行动作为年度安全生产目标管理考核的重要内容，加强专项行动全过程的监督考核。对消极应付、工作落后的,要采取通报批评、诫勉约谈等措施，及时督促纠正;对因工作不落实、不到位、不负责任造成严重后果的,要按照相关规定严肃追究当事人及相关领导的责任。对存在安全生产失信行为的企业,纳入联合惩戒对象;存在严重违法违规行为等联合惩戒对象,纳入安全生产不良记录“黑名单”管理,予以曝光。

各级安监部门要高度重视信息报送工作，安排专人负责，按要求准时报送，每月8日前，向市安监局报送安全生产检查整治情况表（见附件1）、重大隐患未按时整改企业名单（见附件2）；每阶段工作结束后，3日之内向市安监局报送阶段工作小结。
