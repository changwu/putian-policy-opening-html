关于举办全市用人单位职业健康专题讲座的通知

发布时间：2017-07-07 15:52
| | |

 

 

 

 

 

 

 

莆市安监〔2017〕90号

 

各县（区、管委会）安监局：

为全面落实企业安全生产与职业健康主体责任，结合我市职业健康监管工作及尘毒危害等专项整治要求，提高用人单位从业人员职业健康意识，提升主要负责人和职业健康管理人员管理能力，定于7月18日-21日举办六期全市职业健康专题讲座，现将有关事项通知如下：

一、参加对象

用人单位主要负责人和职业健康管理人员。

二、讲座内容

1、传达贯彻上半年全省职业健康监管工作会议精神；2、

《建设项目职业病防护设施“三同时”监督管理办法》有关规定政策解读；3.职业健康基础建设与重点行业领域专项治理；4.职业病事故现场应急救援与事故信息报送；5、用人单位职业卫生监督管理系统操作。

三、讲座时间

  7月18日-21日

四、讲座地点

1、7月18日上午9:00-11:00 城厢区 （莆田金海湾大酒店）；

2、7月18日下午3:00-5:00  荔城区 （莆田凤达酒店2楼会议室）；

3、7月19日上午9:00-11:00 涵江区 （涵江区政府1号楼6层会议室）；

4、7月19日下午3:00-5:00  秀屿区、北岸、湄洲岛（莆田秀屿假日酒店）；

5、7月20日上午9:00-11:00  仙游县  （仙游宾馆综合楼）；

6、7月21日上午9:00-11:00 在建重点项目专场 （市政府1号楼3层会议室）；

五、讲座专家

黄财林 福州市现代安科职业培训中心  主任医师

谢海梅 福州市现代安科职业培训中心  高级工程师

六、其他事项

（一）请各县（区、管委会）安监局做好本辖区参训人员的组织报名工作，并于7月12日前将参训人员名单报送至市安监局监管一科。

（二）请各县（区、管委会）安监局通知辖区用人单位参训人员准时参加，提前15分钟报到。

（三）请各县（区、管委会）安监局做好专题讲座的组织保障工作，除在建重点项目专场讲座费用由市局负责外，其他场次费用由对应的县（区）负责，并严格遵守“八项规定”有关要求，按规定标准接待。

联系人：李一辉，联系电话：2230918、15980611772，邮箱：576478906@qq.com。
