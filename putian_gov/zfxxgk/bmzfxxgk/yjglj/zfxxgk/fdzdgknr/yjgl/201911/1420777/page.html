莆田市人民政府安全生产委员会印发《关于进一步加强我市道路交通安全集中宣传教育活动的方案》的通知

| | |

 

莆市安〔2011〕22号

 

 

各县（区）人民政府（管委会），市直有关部门、单位：

根据市委、市政府领导指示精神和《福建省政府安委会印发〈关于进一步加强道路交通安全集中宣传教育活动的方案〉的通知》（闽安委〔2011〕25号）要求，现将《关于进一步加强我市道路交通安全集中宣传教育活动的方案》印发给你们，请认真贯彻落实。

 

二〇一一年九月二十二日

 

 

主题词：安全生产  道路交通  宣传教育  通知

抄送：市府办，市政府分管副领导、副秘书长。

莆田市人民政府安全生产委员会         2011年9月22日印发

 

关于进一步加强我市道路交通安全

集中宣传教育活动的方案

 

为营造良好的舆论氛围，促进我市道路交通安全综合整治深入开展，根据市委、市政府领导指示精神和省政府安委会闽安委〔2011〕25号文件要求，制定年底前进一步加强道路交通安全集中宣传教育活动方案。

一、指导思想

认真贯彻国务院第165次常务会议、省政府第三季度防范重特大事故会议、市政府第108次常务会议精神和市委、市政府领导近期关于加强道路交通安全工作的重要批示指示精神，不断加强道路交通安全新闻宣传，加强舆论引导和舆论监督，营造有利于我市道路交通安全综合整治的舆论环境，推动安全文化建设，提高人民群众的道路交通安全意识。

二、任务分工与活动内容

市政府安委会各成员单位及各县（区）政府（管委会），应结合本地区、本部门、本单位工作特点，按照职责分工，从今年9月份起至年底，采取多种形式集中开展道路交通安全集中宣传教育活动。

（一）市安监局：承担本级宣传教育活动协调沟通工作；负责协调督促相关部门及各县（区）政府（管委会）组织实施。

（二）市委宣传部：协调市主要新闻媒体、专业广播频道加强对交通安全法规的宣传和交通安全综合整治工作的宣传报道。

（三）市政府新闻办：适时组织开展道路交通安全综合整治新闻发布会；负责组织协调全市网络媒体加大道路交通安全宣传教育力度；协调组织开展网络道路交通安全知识竞赛、网络微博道路交通安全隐患举报等活动。

（四）市交通运输局：负责组织协调全市交通系统集中宣传教育活动；在车站、码头等人员密集场所醒目位置，悬挂张贴道路运输交通安全宣传警示标语；利用乘客购票、候车、安检等时机，向广大驾乘人员发放各种安全宣传材料；客运车辆在发车前5分钟，利用视频播放器播放交通安全知识和安全警示片；驾驶员培训机构在培训和考核中，增加道路运输安全和应急处置内容，并进行督查检查；在全市开展“工人先锋号”、“青年安全生产示范岗”、“星级驾驶员”等先进典型评选表彰和宣传推广活动。

（五）市公安局交警支队：负责组织协调全市交警系统集中宣传教育活动，十一月份在全市开展文明交通主题宣传月活动；在广播、电视上不间断播放有关道路交通安全整治的新闻信息或公益广告；向广大群众散发道路交通安全宣传资料；协调电信运营商，支持、配合道路交通安全综合整治宣传教育，每周2次向驾驶员发送道路交通安全提示信息；在市电视台《今日视线》栏目开辟的“交通曝光台—看看谁违法”、“交通视点—以案释法”和“交警新闻”等栏目及时曝光各种交通陋习，对全社会进行交通安全警示宣传。

（六）莆田高速公路交警支队：负责组织协调全市高速公路交警系统集中进行宣传教育活动；利用车辆在高速公路出入口取（领）卡和缴费等时机，向广大驾乘人员发放各种安全宣传材料；在各高速公路入口处及道路上利用LED电子显示屏，适时显示安全警示内容。

（七）市教育局：将道路交通安全宣传教育纳入学校新学期安全教育的内容；针对不同年龄段学生认知特点，分类开展形式多样的道路交通安全教育活动；校园电视、广播、网络、报刊、电子显示屏、报纸等，应经常播、刊、发道路交通安全内容，每周不少于一次；召开或发放一次（封）学生道路交通安全家长会、家长信，布置一次由学生及家长共同完成的交通安全家庭作业。

（八）市住建局：负责组织协调全市住建系统集中宣传教育活动；在施工现场、建设单位开展施工运输车辆整治宣传活动。

（九）市农机总站：负责组织协调全市农机系统集中宣传教育活动；向广大农机驾驶人员散发道路交通宣传资料；在农机驾驶员培训和考核中，增加交通安全和安全应急处置内容，并进行督促检查。

（十）市广电中心：负责组织市电视台、市广播电台开展集中宣传活动；协调市电视台每周2次在群众关注时段播放安全公益广告；每周在莆田新闻联播栏目播放1-2次道路交通安全综合整治相关内容。莆田电台交通频道开设道路交通安全专题，每天至少播出3条以上道路交通安全信息。

三、活动要求

（一）加强领导，落实责任。各级各相关部门要切实加强对道路交通安全综合整治集中宣传教育活动的组织领导，紧密结合实际，把做好“集中宣传教育活动”作为年底前的一项重要工作，健全工作机构，明确职责分工，制定具体方案，督促抓好落实。

（二）督促检查，纳入考评。将宣传教育活动开展情况作为道路交通安全综合整治专项督查的重要内容，纳入年终目标责任制考评。要加强对实施方案落实情况的跟踪分析、督导检查，搞好引导，及时纠正存在的问题。

（三）强化配合，形成合力。相关部门在抓好职责范围内任务落实的同时，要加强相互配合，及时通报情况，共同解决问题。要采取多种方式，组织多家媒体，突出宣传主体，集中宣传报道，形成强大的舆论攻势和良好的社会氛围。

（四）加大投入，做好保障。各级政府要在活动宣传经费上给予大力支持，财政部门给予必要的经费保障。各职能部门要通过多种渠道筹措落实宣传经费，保障活动的有效开展。

各县（区）政府（管委会）及市直有关部门工作落实情况每月底报送市政府安办。联系人：陈酉鹤；电话及传真：233008
