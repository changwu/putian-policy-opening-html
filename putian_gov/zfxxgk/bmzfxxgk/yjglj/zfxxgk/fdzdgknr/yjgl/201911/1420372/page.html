关于印发莆田市危险化学品领域继续深入开展清剿火忠战役工作方案的通知

发布时间：2013-02-20 08:00
| | |

莆市安监〔2013〕5号

 

各县(区)安监局：

根据市府办《关于印发全市继续深入开展清剿火患战役工作方案的通知》（莆政办明电〔2013〕9号）精神，我局制定了《莆田市危险化学品领域继续深入开展清剿火患战役工作方案》，现印发给你们，请认真组织实施。

 

 

莆田市安监局

2013年2月20日

 

 

莆田市危险化学品领域

继续深入开展清剿火患战役工作方案

 

为巩固危险化学品领域“清剿火患”战役成果，进一步加强危险化学品安全生产工作，根据市府办《关于印发全市继续深入开展清剿火患战役工作方案的通知》（莆政办明电〔2013〕9号）精神，决定从即日起至2013年12月31日，在全市范围内继续深入开展危险化学品领域清剿火患战役工作。具体工作方案如下：

一、总体要求

进一步动员全社会力量，深入排查危险化学品生产、储存、经营场所的火灾隐患，采取行政、法律、社会监督等手段，有效控制动态火灾隐患，杜绝源头性火灾隐患，全面消除一般火灾隐患，彻底整治重大火灾隐患，进一步夯实火灾防控基础，有效遏制火灾事故，促进全市危险化学品安全生产形势持续稳定好转。

二、清剿范围和工作重点

（一）检查危险化学品企业未经消防设计审核、未经消防验收投入使用；

（二）整治生产、储存、经营危险化学品场所与住宿防火分隔，安全疏散不符合消防技术规范，违章存放、非法设置可燃物堆场和仓库，违章用火用电用油用气，堵塞安全出口，违章设置员工宿舍等火灾隐患；

（三）易燃易爆危险化学品场所未采取防火防爆措施，自动消防设施操作人员未经培训或无证上岗；

（四）单位消防安全责任制落实情况，单位消防安全“四个能力”建设情况；

（五）应急救援专业队伍建设，应急救援预案评审备案及演练情况。

三、方法步骤

（一）动员部署阶段（2月中旬）

各级安监部门要按照清剿火患工作的重点内容，结合去年以来开展危险化学品安全生产“打非治违”、“百日大检查”专项行动查出的突出问题，找准主攻方向，明确打击的重点内容，认真研究制定具体工作方案。请各县(区)安监局于2月25日前将方案报市安监局三科。

（二）组织实施阶段（2月下旬—12月31日）

1.开展“除火患、保平安”冬春专项行动，时间：2月中旬至“两会”闭幕。围绕“两节”、“两会”消防安全保卫任务，重点排查危险化学品地下小作坊等无证无照生产经营单位。

2.开展行业、系统单位火灾隐患排查整治活动，时间：4月1日至12月底。各县（区）安监局按照年度消防责任书要求，在职责范围内组织、部署开展本部门、本行业、本系统单位火灾隐患排查整治活动。

3.开展重大节日、重要活动消防安全检查活动，时间：各重大节日、重要活动期间。要围绕劳动节、国庆节、中秋节、圣诞节、海峡论坛等重要节日，在当地政府统一领导下，依照危险化学品安全监管职责，认真开展检查执法，深入排查各类危险化学品生产、储存、经营场所的火灾隐患，并加强与相关配合部门的沟通协调，确保重大节日、重要活动期间危险化学品企业的安全生产。

（三）总结阶段（2014年1月1日—1月15日）

各县(区)安监局要认真总结经验做法，巩固战役成果，逐步建立火灾防控长效机制。请各县(区)安监局于12月31日前报市安监局三科。

四、工作要求

（一）高度重视，加强领导。各级安监部门要充分认识开展清剿火患的重要性和迫切性，切实把危险化学品清剿火患工作作为推进危险化学品企业安全生产主体责任落实，全面加强危险化学品安全生产工作的有力措施和重要抓手。要加强对清剿火患工作的领导，并严格落实一把手负责制。及时研究解决清剿火患工作中的焦点和难点问题，强化整治措施，确保取得实效。

（二）明确分工，落实责任。各级安监部门要依照危险化学品安全监管职责，认真开展检查执法，确保“清剿火患”战役有效开展。要加强与相关配合部门沟通协调，组织相关部门开展联合检查执法，形成“清剿火患”战役工作合力，对发现消防违法行为的，要依法及时移交相关职责部门查处，做到不越位、不错位。

（三）统筹兼顾，标本兼治。各级安监部门要坚持执法与服务并重，坚持推动企业转变发展方式，坚持立足当前、着眼长远，抓住关键、统筹推进，做到“六个结合”。通过清剿火患工作，推动企业自觉遵守安全生产法律法规，建立健全安全生产规章制度，强化安全生产教育培训，全面推进安全生产标准化建设，建立安全生产长效机制。进一步推动各县(区、管委会)化工园区、危险化学品经营市场和储存仓库建设，从源头上巩固战役成果，减少火灾隐患，杜绝危险化学品非法生产经营储存行为。

（四）营造氛围，强化监督。要在清剿火患工作期间，充分利用网络、广播、电视、报纸等各种新闻媒体以及召开危险化学品企业法人代表会议等多种形式，加大宣传力度，营造浓厚的社会氛围，动员和引导危险化学品企业从业人员和人民群众全面理解、参与和推进专项行动。要加强社会监督和舆论监督，用好12350举报平台，鼓励群众举报非法违法生产经营建设行为，对于举报有功人员，给予适当奖励。要公开曝光因非法违规行为导致事故发生的企业，强化社会舆论监督，确保“清剿火患”战役工作取得预期成效。

 

 

 

 

 

 


抄送：省安监局，市府办，市安全生产执法支队，局领导。

莆田市安全生产监督管理局                      2013年2月20日印发
