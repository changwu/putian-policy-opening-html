莆田市人民政府安委会办公室关于继续做好烟花爆竹禁燃工作的通知

发布时间：2016-03-07 08:00
| | |

 

 

 

 

 

莆市安办〔2016〕10号

 

 

各县（区）人民政府（管委会），市直有关单位：

2016年春节期间，各县区、各部门认真贯彻落实《莆田市人民政府办公室关于印发莆田市加强烟花爆竹销售、燃放管理规定的通知》（莆政办〔2015〕22号）、周书记和翁市长的批示指示及沈副市长的部署要求，共出动巡逻力量2300 人次、车辆612 车次、宣传车540车次，查处违规燃放烟花爆竹案件75起,行政罚款 8700元。现场阻止燃放410起、教育528人，查处非法运输、储存、销售烟花爆竹治安案件72起、行政拘留60人，收缴烟花爆竹约6000件。禁燃工作已经取得了阶段性成绩，烟花的燃放已大幅度减少，禁燃工作取得了积极成效。为继续做好烟花爆竹禁燃工作，进一步巩固和提升我市城市管理水平，大力改善大气环境，减少噪音污染，消除火灾、爆炸隐患，保障人民群众生命财产安全，确保社会安定稳定，现将有关要求通知如下：

一、进一步加大宣传力度

各县区政府要进一步深入社区、商场、学校、寺庙等场所开展禁燃宣传，组织公安、安监、城管、工商等部门，在辖区主要交通干道沿线及重点部位周边开展流动宣传，发挥报刊、广播、电视、微博、微信、手机短信等媒体的主渠道、主阵地作用，开展形式多样、贴近群众的宣传活动。鼓励群众举报违规燃放烟花爆竹法行为，营造全民齐参与的社会氛围。

二、进一步加强协调配合

开展禁燃工作是一项艰巨而又长期的任务，牵涉面广、任务重，各职能部门要形成合力，建立完善的监管体系。各职能部门要按照职责分工，认真履行职责，确保各项措施落实到位。各行政执法部门要加强协作，积极做好执法环节的衔接，建立完善纵向到底、横向到边的监管体系，切实加大查处打击力度，确保辖区禁燃工作稳步、有序推进。同时，要实行有奖举报制度，鼓励群众主动举报有关案件的线索，充分调动广大市民关心、监督、参与禁燃工作的积极性。

三、进一步加强重点巡查

汲取前一阶段禁燃工作经验、教训，加强宣传，改进方法，持续抓好我市禁燃烟花爆竹工作。针对莆田有做“头牙”的传统和风俗，要集中力量加强宣传和巡查，特别是要加强对背街小巷、没有物业管理的小区的巡查管控。对传统燃放烟花爆竹较多的时间段，要提前布置对重点燃放部位的巡查，走访群众，及时制止违规燃放烟花爆竹行为，做到制止一个人，教育一大片。各街道、村（居）委会要广泛组织工作人员入户宣传禁燃规定，特别要对当地店面的强化跟踪监管，采取上门劝导、温馨提示等人性化的措施来劝阻燃放烟花爆竹。

 

 

莆田市人民政府安委会办公室
