关于印发开展“树实体标杆，供可学模式”活动（加油站）实施方案的通知

发布时间：2019-06-21 16:55
| | |

莆市应急〔2019〕43号

 

 

 

各县（区、管委会）应急管理（安监）局，各加油站：

现将《开展“树实体标杆，供可学模式”活动（加油站）实施方案》印发给你们，请结合实际，抓好贯彻落实。

 

 

                     莆田市应急管理局  

                   2019年6月4日

 

开展“树实体标杆，供可学模式”活动

（加油站）实施方案

 

为切实解决当前全市加油站安全生产工作整体情况不均衡、日常安全生产管理水平参差不齐等问题，全面提升我市加油站本质安全水平，实现规范化安全管理，根据4月24日应急管理部防风险保稳定工作视频会议以及省政府安办《福建省危险化学品重点县专家指导服务工作方案》（闽安委办〔2019〕14号）等精神，经研究，决定在全市范围内开展加油站“树实体标杆，供可学模式”活动。现制定实施方案如下：

一、活动目标

选择两家安全生产基础扎实的加油站，在全面落实企业安全生产标准化建设工作的基础上，重点在设施设备、规章制度、日常运营、应急管理等方面下功夫，打造“符合标准、简单易学”的安全管理模式。其余加油站通过学习实体标杆，明确改进方向，补齐工作短板，实现安全生产管理水平提升。

二、活动实施步骤

从6月5日起至10月31日结束，分“树、学、创”三个阶段进行：

（一）树标杆阶段（6月上旬）。经过多次反复筛选，决定选择一家中石油加油站和一家中石化加油站，作为实体标杆的试点单位，在原有基础上，进一步提升设施设备、管理制度、日常运营、应急管理等方面安全生产工作水平。

（二）学标杆阶段（6月份）。结合6月份全国安全生产月活动，市局将组织全市加油站主要负责人进行集中培训，并现场观摩实体标杆试点单位。

（三）创标杆阶段（7月至10月份）。各加油站认真学习实体标杆单位安全管理模式，根据自身实际，制定工作方案，取长补短，不断改进提升设施设备、管理制度、日常运营、应急管理等方面安全生产管理水平。10月份，各县(区、管委会）应急(安监）局组织人员对照标杆标准要求进行检查，督促辖区内加油站成为标杆。

三、工作要求

（一）提高认识，强化组织领导。各县（区、管委会）应急管理（安监）局要充分认识标杆创建活动的重要性和紧迫性，配齐配强工作力量，为活动提供坚强组织和后勤保障。中石油、中石化要发挥资源优势，组织精干力量，采取有效措施，按时推进创建任务。各加油站要强化主体责任意识，积极主动参与。

（二）明确责任，加强业务指导。各县（区、管委会）应急管理（安监）局要扎实推进标杆创建活动深入开展，有计划、有步骤开展培训，并组织专家深入辖区内各加油站，帮助解决学习过程中遇到的困难和问题。

（三）严格标准，加强监管执法。各县（区、管委会）应急管理（安监）局要将各加油站标杆创建标准作为日常监督检查内容，指导督促加油站对标看齐，对逾期不达标存在安全隐患的，要责令期限整改；对整改不到位的，依法给予行政处罚。

（四）突出实效，综合运用成果。市局将标杆创建活动纳入县（区）政府（管委会）年度安全生产考核内容。各县（区、管委会）应急管理（安监）局要将标杆创建活动作为加油站分级管控依据。对按期达标的，市局将以通报表扬并授牌，同时优先予以“青年文明号”、“平安企业”等评先评优推荐；对不按期达标的，要加大监督检查频次和监管执法力度，直至达标。

（五）广泛宣传，营造浓厚氛围。各县（区、管委会）应急管理（安监）局要充分运用新闻媒体，多形式、多渠道加强活动宣传，增强各方工作的自觉性，营造树标、学标、创标的良好氛围。

 

 

抄送：省应急管理厅，市府办，市政府傅冬阳常务副市长、陈枫副市长。

莆田市应急管理局                          2019年6月4日印发
