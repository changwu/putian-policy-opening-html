关于对安全生产培训机构办班培训抽查情况的通报

发布时间：2019-05-09 15:37
| | |

 

 

 

 

 

 

 

莆市应急〔2019〕31号

 

 

各县（区、管委会）应急管理局，各培训机构：

为促进我市安全生产培训工作的有序开展，根据《安全生产法》、《生产经营单位安全培训规定》、《安全生产培训管理办法》等法律法规规章要求，近期我局组织人员分别对莆田市安全生产协会、莆田市致远安全生产培训有限公司办班培训情况进行抽查。现将有关情况通报如下：

一、检查情况

通过采取现场检查、现场听课、询问学员听课效果等方式分别对莆田市安全生产协会、莆田市致远安全生产培训有限公司办班培训情况进行检查，共发现问题11条。

二、存在的主要问题

（一）培训方式单一。个别安全培训机构对培训工作不重视，没有组织教学研讨，培训方式单一，培训的针对性不强，效果不够明显。莆田市致远培训有限公司老师照本宣科，讲课内容单调，报备的老师常松彦注安师注册类别是危险物品安全，但其报送的培训计划除了安全生产法律法规及标准一课由另一位教师授课外，其他培训内容全部由常松彦一人进行培训，学员听课效果不佳。

（二）考勤制度不严格。在抽查过程中发现，两家培训机构均存在考勤不规范现象，签到签退一起签。莆田市安全生产协会先盖考勤章后考勤表统一签到签退，还在上课已完成签退。莆田市致远培训有限公司正在上课，已完成签退，14:30上课，15:30还有很多学员刚到。

（三）课堂纪律混乱。跟班班主任未负起应有的责任，未维持好课堂秩序，上课期间学员玩手机、睡觉、在走廊抽烟、学员随意进出教室等。

（四）未按报送的培训计划进行培训。莆田市致远培训有限公司报送培训计划为一般企业主要负责人、安全管理人员复训，检查人员在现场发现有83名初训学员。

三、下一步工作要求

（一）严格报送办班计划。各培训机构应认真制定办班培训计划并在开班前一周书面报送市局，同时抄送办班所在县（区、管委会）应急局。对不按规定要求报送办班计划的，不得开班，市局不予组织考核发证。

（二）进一步提高培训质量。各培训机构要严格按照国家统一的培训大纲、选择优秀教材，开展安全生产培训工作，严格培训纪律，认真做好考勤，建立培训档案，加强师资队伍建设管理，注重教师能力建设，按照报备教师专业结构进行授课，杜绝个别老师完成全部培训教程。

（三）加强监督检查。各县（区、管委会）应急局、各镇、街、园区安办对培训机构开班情况进行全面检查、市局抽查。在监督检查中发现安全培训机构不具备安全培训条件的、未按照国家统一的培训大纲组织教学培训的、未建立培训档案或者培训档案管理不规范等违法违规行为要依法依规予以查处。

（四）加强队伍廉政建设。各县（区、管委会）应急局、各镇、街、园区安办不得指定培训机构，不得为培训机构打招呼、通知、组织人员参加培训，不得干预正常的培训市场，确保干部队伍廉洁自律。

（五）进一步抓好问题整改。针对此次检查中发现的问题，各培训机构要制定整改方案，细化整改措施，确保整改取得实效。对不认真落实整改，整改不到位的机构，将依法依规予以查处。请有关培训机构于5月6日前书面上报整改反馈情况。

安全生产培训机构办班培训抽查发现的问题

 

培训机构

存在问题

莆田市安全生产

培训中心

1、考勤制度不严格，签到不规范，先盖考勤章后考勤表统一签到签退，还在上课已完成签退；

2、课堂纪律不严，有学生玩手机；

3、LED屏幕过小，PPT看不清，影响上课质量;

4、初复训合在一起办班（初训80人，复训91人）。

莆田市致远安全

生产培训有限公司

1、考勤制度不严格，签到不规范，签到签退一起签，2:30上课，3:30还有很多学员刚到；

2、课堂纪律不严，有学生玩手机、睡觉，上课期间学员随意进出教室，课堂秩序混乱；

3、LED屏幕过小，PPT看不清，影响上课质量;

4、老师照本宣科，讲课内容单调，课堂效果不佳；

5、初训复训合在一起办班，开办前向市局报送培训计划是复训，培训时有很多初审的（初训83人，复训79人）;

6、培训计划未按照专业结构安排老师（常松彦注安师注册类别是危险物品安全，其报送的培训计划除了法律法规一课由一名教师负责外，其他培训内容全部都由常松彦一人进行授课）；

7、未印制分发培训课程表，给学员造成不便。
