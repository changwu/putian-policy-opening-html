关于组织参加全市危险化学品安全生产政策法规培训考试的通知

发布时间：2014-06-03 08:00
| | |

莆市安监〔2014〕59号

 

 

各县（区）安监局，中石化、中石油、中化莆田分公司：

根据《国家安全监管总局关于进一步严格危险化学品和化工企业安全生产监督管理的通知》（安监总管三〔2014〕46号）和5月29日全省危险化学品安全监管暨重点县重点企业安全生产攻坚工作会议精神，我局决定举办两期危险化学品安全生产政策法规培训班，现将有关事项通知如下：

一、培训对象

1、各县（区）安监局负责危险化学品安全监管人员。

2、中石油、中石化、中化莆田分公司及其加油站负责人、安全员。

3、民营加油站负责人、安全员。

4、危险化学品生产、储存经营企业负责人、安全员。

二、培训内容

1、《国家安全监管总局关于进一步严格危险化学品和化工企业安全生产监督管理的通知》（安监总管三〔2014〕46号）；

2、《化工（危险化学品）企业保障生产安全十条规定》（国家安监总局令第64号）；

3、《关于印发福建省危险化学品企业负责人安全生产“九确保”的通知》（闽安监管三〔2013〕59号）；

4、安全月宣传片《生命的红线》、《生命的刻度》等。

 三、培训考试时间、地点

 1、 第一期（负责人）：2014年6月5日15：00—17：30

     第二期（安全员）：2014年6月6日15：00—17：30

    2、地点：莆田市工业经济展示馆八层会议室，地址：梅园西路市委党校停靠站附近

四、其他事项

1、各县（区）安监局要将本通知传达到辖区所有危险化学品企业，要认真组织辖区相关企业人员参加培训考试。

2、无储存经营企业负责人、安全员危险化学品安全生产政策法规培训考试由各县（区）安监局负责，并将培训考试情况于6月底前报告市局。

3、考试不合格的人员要限期补考，补考不合格的，将依法取消其与安全生产有关的任职资格。

4、培训考试不收取任何费用。

5、各危险化学品企业要将本次培训内容作为企业员工三级安全教育培训的重要内容。

 

 

                              莆田市安监局

                             2014年6月3日
