关于组织观看电影《生命监管》的通知

发布时间：2013-06-14 08:00
| | |

莆田市安全生产监督管理局

莆田市教育局

文件

莆田市文化广电新闻出版局

莆田市总工会

 

莆市安监〔2013〕57号

 

 

 

各县（区、管委会）安监局、教育局、文化广电新闻出版局、总工会，各有关单位：

由国家安全生产监督管理总局、国家广播电影电视总局任总监制，河南省安全生产监督管理局、河南影视集团联合拍摄的优秀电影故事片《生命监管》，已在全国相继上映。该电影以“安全发展忠诚卫士”河南煤矿安全监察局豫东分局局长丁安同志的事迹为原型，真实再现了丁安同志的感人事迹和崇高精神，塑造出一个对党无限忠诚、对煤矿安全监察事业无限热爱的优秀共产党员的光辉形象。影片故事感人、催人泪下、寓意深刻、引人深思、促人奋进，具有强烈的艺术感染力。为充分发挥影片的宣传教育作用，根据《省安监局、省教育厅、省广电局、省总工会关于认真组织观看电影<生命监管>的通知》（闽安监综合〔2013〕71号）要求，现就做好该片的发行放映工作通知如下：

      一、各县（区、管委会）安监局、教育局、文化广电新闻出版局、总工会、市各有关单位，市属有关企业要积极组织干部职工观看影片《生命监管》，要求各县（区、管委会）组织放映不少于一场。把观看影片作为党团活动和励志教育的重要内容之一，在广大干部群众中掀起学习先进典型的热潮，用模范人物为国尽责、为民奉献的感人事迹和崇高精神，引领大家做时代先锋、行业楷模。

二、为配合继续深化“安全生产年”活动，有关部门可送电影进机关、企业、矿山、学校、社区，巡回放映电影《生命监管》，广泛宣传安全生产和劳动保护的重要性，教育广大干部职工树立爱岗敬业、无私奉献的精神风貌。

三、各广播影视主管部门要积极与有关方面密切合作，共同做好电影《生命监管》的发行、放映工作。各电影发行、放映单位要组织好片源，安排好档期，努力为广大干部群众放映好影片，扩大影片的社会影响，发挥好影片的教育、引导和激励作用。

四、各报刊、电视台、电台、互联网站等新闻单位要配合影片的宣传放映，积极做好该片的宣传和推介工作，进一步扩大和提升影片在广大干部群众中的影响力。
