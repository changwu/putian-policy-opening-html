| | |

莆市应急〔2019〕28号

 

各县区（管委会）应急局，局机关各科室、直属事业单位：

　  现将《2019年全市应急管理新闻宣传工作要点》印发给你们，请结合工作实际，推动应急管理和新闻宣传工作深入开展。

 

 

莆田市应急管理局

 2019年4月15日

 

 

2019年全市应急管理新闻宣传工作要点

 

2019年是新中国成立70周年，是全面建成小康社会和坚持高质量发展落实赶超的关键之年，也是应急管理系统全面履职的第一年。全市应急管理新闻宣传工作要以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记关于应急管理、安全生产和防灾减灾救灾等方面的重要论述，紧紧围绕全市应急管理中心工作，大力宣传党中央、国务院、省委、省政府和市委、市政府关于应急管理、安全生产和防灾减灾救灾的决策部署，宣传法律法规，宣传公共安全知识常识，培育应急管理特色文化，推动应急管理系统媒体融合发展，不断提高应急报道和舆论引导能力，推动提升全社会安全意识、防灾减灾意识和应急避险能力，为全市应急管理事业营造良好舆论氛围。

一、加强理论武装，推动习近平新时代中国特色社会主义思想深入人心

1.深入宣传习近平新时代中国特色社会主义思想，坚持用党的创新理论武装应急管理系统干部职工头脑，切实把学习宣传习近平新时代中国特色社会主义思想和党的十九大精神成果转化为认同核心、维护核心、看齐核心的政治自觉，转化为指导实践、推动工作、改造客观世界的行动自觉，不断增强“四个意识”、坚定“四个自信”，做到“两个维护”。要利用系统内网站、新媒体开设专题专栏，及时转载中央主要媒体评论言论和新闻报道，将中央精神及时传播到全系统干部职工中。

2.深入宣传习近平总书记关于应急管理、安全生产、防灾减灾救灾的重要论述和向国家综合性消防救援队伍训词精神；宣传党中央、国务院、省委、省政府和市委、市政府加强应急管理、安全生产、防灾减灾救灾的决策部署；宣传应急管理部、省应急管理厅和市应急管理局应急管理、安全生产、防灾减灾救灾工作安排。

3.积极参与宣传部门组织的庆祝新中国成立70周年“我和我的祖国”“你好新时代”等群众性主题教育宣教活动。组织系统干部收看收听庆祝大会、阅兵式和群众游行实况；在系统内网站、新媒体开设庆祝新中国成立70周年专题专栏，策划推出应急管理系列报道、评论言论和新媒体宣传产品。

二、精心组织应急管理战线新闻宣传工作

4.认真宣传贯彻安全生产、应急管理工作会议精神，围绕“搭平台、建机制、求精准、重创新”和深化应急管理部门机构改革、防范化解重大安全风险坚决防范遏制重特大事故、加快建设灾害事故防范救援能力体系、建设忠诚干净担当的应急管理干部队伍等重点工作任务，策划推出重点报道、新闻发布、网络访谈和新媒体产品，及时反映工作进展成效。围绕应急管理重点工作、重要节点等大力开展网上宣传，加大新媒体推送力度，做好应急管理系统开展“不忘初心、牢记使命”主题教育、应急管理部门组建1周年、国家综合性消防救援队伍组建1周年等重要活动宣传报道工作，展示机构改革成效和我市综合救援能力提升。

5.深入开展“防灾减灾周”“安全生产月”“海西安全发展行”和“消防宣传月”等主题宣教活动，继续与市总工会、团市委联合开展“安康杯”、“青年安全生产示范岗”活动。

三、不断提升突发事件新闻宣传应对能力

6.密切关注应急管理安全生产自然灾害舆情、媒体关切、突发事件等热点问题舆情动态，及时发布权威信息，讲清事实真相，认真回应关切，确保不失声、不缺位，及时将舆情化解在萌芽阶段。强化与媒体的协调联动机制，做好应急管理领域舆情监测、分析研判和热点引导，及时化解舆论风险，确保舆情平稳有序。做好重大安全风险隐患和典型生产安全事故曝光，剖析案例，警示社会。

7.建立健全宣传协同联动机制，加强与各地宣传部门、网信办等部门的沟通协作，加大应急管理信息的推送力度。认真落实上级有关的灾害事故现场应急新闻报道、新闻发布和媒体记者管理制度办法，规范灾害事故现场新闻工作流程。

四、扎实开展应急管理科普宣传和培育特色文化

8.组织系统内报刊网站和新媒体围绕自然灾害、事故灾难和应急救援开展科普宣传，组织开展应急管理科普作品征集活动,制作推出一批应急管理、安全生产、防灾减灾救灾公益宣传画、挂图、读本、手册及新媒体等科普产品。联合相关部门共同推动应急管理科普宣传进教材和进学校、进机关、进企事业单位、进社区、进农村、进家庭、进公共场所，不断扩大宣传覆盖面。鼓励有条件地区建设一批应急管理科普基地场馆，引导社会力量参与应急管理科普宣传工作。

9.通过主题宣传、典型宣传、征集微视频等方式，大力培育和弘扬极端认真负责、甘于牺牲奉献，勇于担当作为、善于开拓创新的应急管理特色文化。挖掘报道一批应急管理系统岗位大练兵、大比武先进组织和先进典型，塑造应急管理队伍良好形象，树立职业尊崇。

五、全面强化应急管理新闻宣传队伍建设

10.建立完善应急管理系统新闻发言人制度，开展常态性新闻发布工作，围绕重点工作，组织召开专题新闻发布会和网络在线访谈，对突发事件应在第一时间及时回应。

11.整合优化应急管理系统新闻宣传力量，组建全市应急管理系统新闻发言人、理论工作者、专家智库、新闻通讯员、网评员“五支队伍”，建立健全中国应急管理报和《安全与健康》杂志通讯员队伍，组织开展应急管理系统新闻通讯员培训活动，努力打造一支政治过硬、本领高强、求实创新、能打胜战的新闻宣传工作队伍。

六、全面建设应急管理系统媒体平台

12.大力推动应急管理系统媒体融合发展，加强市应急管理局网站建设，打造网上权威对外窗口；加强与中国应急管理报、东南网、湄洲日报、今日头条等媒体的合作，在电视、广播、报刊、网络等媒体进行专题报道、系列报道、跟踪报道。

13.加强应急管理系统官方微信、微博等新媒体平台建设，配合省级完成省、市、县三级“双微”合作联动，形成统一指挥、协调联动、协调发声、信息集聚、优势互补和资源共享的福建应急管理“双微”矩阵，全面提升应急管理宣教的社会影响力。

七、加强应急管理系统意识形态阵地管理

14.认真贯彻落实意识形态工作责任制，加强系统报刊、网站、新媒体等意识形态阵地管理，完善信息发布内容审核制度及规范流程，落实审签制度，主动开展风险隐患排查，强化底线思维，及时发现处置苗头性、倾向性问题，确保意识形态领域安全。
