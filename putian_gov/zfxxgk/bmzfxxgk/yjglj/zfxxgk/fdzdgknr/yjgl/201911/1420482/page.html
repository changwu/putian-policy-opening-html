关于规范危险化学品和烟花爆竹安全监管业务网格化管理机制的通知

发布时间：2018-09-06 17:21
| | |

莆市安监〔2018〕121号

 

 

 

各县（区、管委会）安监局、社会治理网格化中心：

为进一步贯彻落实《中共莆田市委办公室 莆田市人民政府办公室关于印发全面提升城乡综合执法和服务治理网格化的实施意见的通知》（莆委办发〔2017〕3号）和《莆田市安办 莆田市网格办关于开展基层安全生产网格化监管工作的通知》（莆市安办〔2018〕33号）要求，充分利用已投入运行的全市网格化服务治理大平台，发挥网格员队伍的“信息员”和“宣传员”作用，推动安全生产监管工作关口前移、重心下移，实现对基层安全生产工作的动态监管、源头治理和前端处理，进一步推动安全生产监管充分有效地融入网格，完善网格化监管模式，实现生产安全社会共治，现将有关事项通知如下：

一、强化组织保障

市安监局成立以蔡国萍局长为组长的市安全生产网格化监管工作领导小组，各县（区、管委会）安监部门也要相应成立工作小组，建立主要领导负总责、分管领导具体抓、相关人员分工落实的工作机制，高度重视，积极推进危险化学品和烟花安全监管网格化工作有效开展。

二、积极协作配合

为优化平台管理服务，我市已建成市级社会治理网格化管理平台并正式启用运行，各县（区、管委会）安监部门要按照“统一标准、统一划定、一格统管”的原则积极对接当地县（区、管委会）网格中心，密切协作配合，按照全市统一的数据清单和业务办理流程规范运转，确保网格化服务管理数据交互畅通，及时接收、处置各级网格中心流转的工作业务，并将办理结果反馈至同级网格中心。 

三、明确职责分工

（一）市安监局负责统筹推进全市危险化学品和烟花爆竹安全监管入格事项工作。

具体职责：监管三科负责制定危险化学品和烟花爆竹入格事项业务工单和操作指南；执法支队负责安排专人签收市级网格中心流转的事件，可根据业务性质将任务按属地管辖原则将事件流转至各县（区、管委会）安监部门并督促按期办结反馈；监控中心负责收集汇总工作成效及存在问题，适时对各县（区、管委会）安监部门入格事项办理反馈情况进行通报，推进安监综合信息平台与网格化管理平台对接。

（二）各县（区、管委会）安监局负责推进辖区内危险化学品和烟花爆竹安全监管入格事项工作。

具体职责：按照市安监局制定的危险化学品和烟花爆竹安全监管入格事项业务操作指南，加强与县（区、管委会）网格中心的业务衔接；安排专人签收县（区、管委会）网格中心流转的事件，由各县（区、管委会）安监部门办结反馈或督促乡镇安监站办结反馈；组织开展网格员业务培训并指导其开展入格事项工作、落实网格员奖励措施；对安监站办结的问题事件处置情况进行抽查，并适时对安监站工作开展情况进行督查通报。

（三）各级社会治理网格化中心负责危险化学品和烟花爆竹安全监管入格事项的综合协调。

具体职责：负责与同级安监部门的业务衔接；负责网格员队伍的日常管理，检查指导网格员规范采集并如实上报安全生产入格事件；及时根据事件处置流程将问题事件准确流转至安监部门；跟踪监测问题事件办理进度；协助安监部门开展入格事项的业务培训。

（四）网格员负责协助巡查危险化学品和烟花爆竹安全监管入格事项。

具体职责为：网格员作为安全生产监管部门的补充力量，对安全生产监管入格事项开展协助巡查，不代替安全生产监管职能部门履职主体责任。由于网格员不具备执法检查资格，因此原则上不强制要求网格员进入危险化学品和烟花爆竹生产、加工场所。网格员在日常走访过程中，发现涉及安全生产入格事件按照工作流程规范采集并上报县级网格中心；协助安监部门开展安全生产宣传教育活动。

四、工作要求

（一）建立联络制度。各县（区、管委会）安监部门要指定专人负责登录网格化管理系统，并按部门职责开展工作。遇有工作变动应及时做好网格化管理工作交接，交接人员名单、职务、联系方式应及时报送市安监局和同级社会治理网格中心，确保工作运转顺畅。

（二）规范办理流程。各县（区、管委会）安监部门接到网格化管理系统流转的问题事件后，应在规定时限内按办理流程规范处置，涉及跨区域的事件可流转至市安监局进行处理。网格内事件的事中、事后处理，由相关责任科室按照安全生产举报事件办理程序负责跟踪、督促落实，确保已经发现的问题能及时处理、消除隐患。

（三）加强结果运用。各县（区、管委会）安监部门在推进危险化学品和烟花爆竹安全监管网格化监管工作过程中要及时总结工作经验和成效，将存在的困难问题以及意见建议等向市安监局及同级社会治理网格中心反馈；要定期梳理、甄别网格化监管平台上各类安全生产信息并分析研判，以切合安全生产日常监管实际需要、对整治提升生产安全监管最为有利来引导网格员协助巡查，确保监管重点更加明确。

（四）强化考核提升。安全生产网格化监管工作已列入市对县区安全生产目标责任制考评内容，市安监局将汇同市网格中心适时对各县（区、管委会）安监部门入格事项工作进行考核评价。各单位要严格落实工作责任制，促进安全生产网格化工作成效不断提升。
