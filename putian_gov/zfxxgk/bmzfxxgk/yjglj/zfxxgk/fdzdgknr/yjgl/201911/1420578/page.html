关于全市非煤矿山安全大检查专项督查情况的通报

发布时间：2011-12-05 08:00
| | |

 

 

莆市安监〔2011〕172号

 

 

 

各县（区）人民政府（管委会）安监局（科）：

根据《福建省人民政府安全生产委员会关于深入开展安全大检查切实做好第四季度安全生产工作的通知》（闽安委明电〔2011〕11号）要求，从2011年10月20日至11月20日，市安监局组织11名专家组成督查组，对仙游县和城厢区13家非煤矿山开展安全生产大检查工作情况进行了专项督查。现将有关情况通报如下：

一、基本情况

从督查的情况看，我市各级各相关部门都能够认真履行非煤矿山安全监管职责，认真开展安全生产大检查工作，全力推进非煤矿山安全生产标准化、落实企业安全生产主体责任和“平安企业”创建工作，继续深化非煤矿山安全专项整治、隐患排查，大力推广先进实用技术，狠抓非煤矿山安全基层基础建设，大力开展打击非法开采行为。并督促非煤矿山企业积极参与，充分发动职工群众参加隐患排查、整改和监控工作，认真落实各项安全防范措施，取得了初步的成效。今年1-11月份，全市非煤矿山安全生产保持平稳态势。

二、存在的主要问题

各级各相关部门自非煤矿山安全生产大检查工作开展以来，虽做了大量的工作，取得了初步的成效。但从督查情况来看，仍存在一些问题，主要表现在：

一是未按设计要求开采。部分矿山企业没有按照“自上而下，分层开采”原则进行开采，台阶高度超高，坡面角、终了边坡角未按规定削坡，开采设计与现场状况不符。个别矿山改、扩建后未重新进行“三同时”建设。 二是安全管理仍需加强。部分矿山企业未严格按照标准化建设要求进行管理、生产，存在安全管理人员不在现场、浮石危石没有及时清理、作业人员不配戴安全帽、劳保用品不按规定存放等现象。 三是业主、从业人员安全意识淡薄。一些非煤矿山的业主安全意识薄弱，重生产、轻安全现象严重，贪图短期利益，安全投入不足；从业人员变动较大，安全教育培训没有落实到位，出现新招员工未经培训先上岗现象。 四是安全标准化建设进度缓慢。受业主自身素质不高，指导督促不到位等影响，部分企业创建意识不高，创建积极性不强，导致我市非煤矿山安全标准化建设进度缓慢，推进难度较大。

三、下一步工作意见

（一）进一步强化日常安全监管力度。要持续开展矿山安全生产专项检查，重点检查台阶高度超高，坡面角、终了边坡角未按规定削坡，开采设计与现场状况不符等情况。要严格非煤矿山新、改、扩建审查和非煤矿应急预案的评定、管理、修订、演练和应急保障工作。加强应急值守和检查巡查，保证及时发现险情、及时处理、及时上报。

（二）进一步落实非煤矿山安全生产主体责任。进一步督促非煤矿山企业落实安全生产主体责任，健全安全管理机构，完善安全管理制度，加大安全投入，足额提取和使用安全费用，全员参加安全生产责任保险。继续加强教育培训，认真排查矿山企业主要负责人、安全管理人员、特种作业人员持证上岗制度落实情况。

（三）全面推进非煤矿山安全生产标准化建设。继续按照《非煤矿山安全标准化建设实施方案》要求，精心培育示范典型，全面推进企业安全标准化建设。进一步健全完善非矿山的企业技术支持、教育培训、考评认定、激励约束和工作交流制度，指导督促企业加强全员、全方位的安全管理，规范安全生产行为。

（四）持续推广先进适用技术和装备。在露天矿山巩固推广机械化铲装和中深孔爆破成果的基础上，重点推广液压锤二次破碎技术、非电导爆等技术，鼓励由专业爆破公司实施中深孔凿岩爆破工作；在荒料采石场上积极推广圆盘、链式机械开采。同时，要强制淘汰非煤矿山落后技术、工艺和设备。露天矿山重点淘汰扩壶爆破、使用爆破方式进行二次破碎、人工装载矿岩、没有捕尘装置的干式凿岩、雷电多发地区采用电雷管起爆等落后技术、工艺和装备。

对督查中发现的主要问题和安全隐患（见附表），各县（区、管委会）安监局（科）要抓紧督促整改到位，整改落实情况于12月底前书面报送市安监局二科，联系人：顾斌，电话：2392566，传真：2339655，邮箱地址：fjptajj@163.net。
