转发关于加强基层危险化学品安全监管专业力量的通知

发布时间：2018-08-30 17:41
| | |

 

莆市安监〔2018〕116号

 

 

 

各县（区、管委会）安监局：

现将省安监局《福建省安全生产监督管理局办公室关于加强基层危险化学品安全监管专业力量的通知》（闽安监办管三〔2018〕26号）转发给你们，各县（区、管委会）安监局要依据危险化学品安全综合治理的工作要求，切实提高对加强基层危险化学品安全监管专业能力重要性的认识，结合本辖区实际，多措并举，研究解决专业能力不足问题。

 

莆田市安全生产监督管理局

                     2018年8月17日

（此件主动公开）

福建省安全生产监督管理局办公室关于加强

基层危险化学品安全监管专业力量的通知

 

闽安监办管三〔2018〕26号

 

各设区市及平潭综合实验区安监局：

危险化学品生产储存过程具有易燃易爆、有毒有害、高温高压等危险特性，安全技术性强，专业要求高。在监管实践中发现，一方面，部分企业主要负责人和安全管理人员不懂化工、不会管理，高素质产业工人严重短缺；另一方面，基层安监部门力量不足，缺乏懂专业的监管人员，与危险化学品行业快速发展不匹配，矛盾突出，已成为制约危险化学品安全生产的短板。

我省目前共有取得安全许可的危险化学品生产经营单位5477家，分布在九个设区市和平潭综合实验区，其中，泉港、古雷、江阴为省级石化工业基地，一些市、县（区）还设立了市级、县级的化工园区或集中区。目前，我省安全监管部门危险化学品专业监管力量不足问题突出，全省现有危险化学品安全监管人员共341人，其中化工专业人员125人、仅占36.6%，与危险化学品安全综合治理目标任务的要求（75%）差距很大。全省13个危险化学品重点县（市、区）安监局中，化工专业监管人员仅19人，其中6个县（市、区）安监局分别为1人、3个县（市、区）为零。因此，各地要依据危险化学品安全综合治理的工作要求，切实提高对加强基层危险化学品安全监管专业能力重要性的认识，结合本地实际，多措并举，研究解决专业能力不足问题。

一、突出重点，强化执法队伍建设。认真落实《福建省人民政府办公厅关于印发福建省“十三五”安全生产专项规划的通知》（闽政办〔2016〕65号）要求，推进重点县、化工园区(化工集中区)危险化学品安全监管机构建设，加强危险化学品重点县、重点企业的安全监管。健全完善安全生产监管监察执法机构和队伍，强化基层执法力量，优化监管人员结构，实现专业监管人员配比不低于在职人员的75%。

二、强化培训，提升现有监管人员能力。省局将结合实际，制定面向全省基层危险化学品安全监管人员的年度培训计划，积极组织各地监管人员参加国家举办的培训活动，采取集中培训、以会代训和调研交流等形式，切实提高基层监管人员的业务素质。各地要通过举办各类培训班，对照《危险化学品安全监人员提升专业知识培训重点》，对辖区内危险化学品监管人员进行轮训。同时，选择部分人员就近参加应急管理部安排的化工安全复合型高级人才研修班学习，使监管人员逐步掌握化工安全专业知识，不断提升专业监管能力。

三、借鉴泉港、晋江做法，加强专业监管力量。近年来，泉州市泉港区针对专业监管力量不足问题，采取公开招聘方式，面向全国高薪聘请了一批危险化学品安全专家，常驻地方，指导危险化学品企业隐患排查、应急处置，协助监管部门安全审查、培训教育等，开创了常驻专家服务安全生产的新模式。晋江市通过试点先行、政策引导等办法，探索建立了政府购买服务、部门依法监管、企业查改隐患的机制，有效提升了安全监管水平。各地可学习借鉴泉港区、晋江市政府或其他地方的经验，结合本地实际，积极探索有效的监管办法（泉港、晋江经验材料见附件）。

四、加强院校合作，努力培养专业监管人才。认真贯彻落实教育部、国家安全监管总局关于加强化工安全人才培养工作的指导意见和相关文件精神，加强与高等院校合作，采取委托培养、短期专题培训等多种形式，对危险化学品监管人员进行化工及安全知识培训。同时，推动企校合作，有计划地培养企业急需的安全管理人员。

五、交流互动，探索建立政企双向挂职制度。积极争取当地组织部门的支持，研究推进建立辖区内中央企业、省属企业、大型国有企业与安全监管部门双向挂职制度，解决监管部门缺少专业监管力量的问题，提升专业化监管水平。

附件1

 

泉港区开创常驻专家服务安全生产新模式

 

一、背景

泉港区是全国危险化学品安全生产攻坚重点县(区)，石油化工企业多，生产装置规模大，产业链关系紧密，危险化学品重大危险源数量多。2015年全区共有危险化学品从业单位110家，其中生产企业11家，经营企业57家，使用企业27家，运输企业10家，液化气储配站5家。既有国有、合资企业，又有台资、私人企业，安全生产管理水平参差不齐；部分中小型企业工艺和设备落后，员工安全意识差，监管难度大。2015年泉港区危险化学品监管人员仅3人，监管人员疲于奔命但监管效果不佳。

二、做法

为提升危险化学品企业查改隐患能力和政府监管水平，泉港区委区政府决定采取公开招聘方式，面向全国高薪聘请危险化学品安全专家。成立了以分管副区长为组长、区安办主任为副组长，区委组织部和区人社局、财政局、安监局负责人为成员的招聘领导小组，下设考务组、外联组、面试组、监督组、后勤组，并邀请省安科院、泉州安全生产协会等有关方面8名专家作为面试考官，设置了结构化面试和现场模拟检查两个环节，对拟招聘专家进行全方位的考核。在中国安全生产报、化工英才网、海峡人才网、泉港人才网等招聘平台显著位置上刊出广告后，全国有100多人报名参加竞聘，经资格审查、面试、体检、组织考察、公示、聘用等程序，于2016年2月择优录取5名分别来自辽宁、河南、安徽、云南、福建的高级工程师。对应聘专家，泉港区政府给予高出几倍公务员工资的待遇，且为每人各提供人才公寓1套，配齐家具家电，解决就餐问题，提供子女就学、家属陪同等各种生活便利，消除生活上的后顾之忧；同时，租赁商务用车1辆，专门用于专家下乡镇到企业检查，还配齐劳保用品、执法装备，为专家提供了良好的工作条件。

为充分调动常驻专家的工作主动性和创造性，泉港区制定了《危险化学品安全专家绩效考核实施方案》，建立了立体式绩效考核管理模式。专家薪酬上，分为基本劳务费和劳务奖金两部分，劳务奖金根据专家每月工作绩效分档发放、按效取酬。考核指标上，设置了个人素质、工作态度、工作能力和工作成果4个大项12个子项，明确考核内容和考核标准，考核结果设优秀、良好、合格、不合格四个档次。并设置了加分项和扣分项，对提出合理化建议、有安全生产科研成果的予以加分;有违反廉洁自律倾向、拒不执行任务安排等现象的予以扣分。建立一票否决机制：未及时发现企业重大安全隐患或违法违规行为的，取消当月绩效工资；发生较大涉险事故、违反廉洁自律相关规定的，取消当月绩效工资及年度绩效工资；发生亡人及以上事故、拒不执行工作任务的，取消当月绩效工资及年度绩效工资，且当月基本工资不予发放。

三、成效

常驻专家聘请以来，为泉港区危险化学品企业隐患排查、安全准入、应急处置、培训教育等方面做了大量工作，危险化学品安全管理水平得到有效提升。

隐患排查方面，将化工和危险化学品及烟花爆竹企业、冶金等工业八大类企业分为4组，围绕“专家百企督导行”中“八个重点内容”，梳理出9个检查表134项检查重点，为企业隐患自查、监管部门安全检查提供标准。2016年全区排查整治隐患704条，同比增长53.7%，企业安全条件有了质的提高；2017年专家指导企业建立隐患自查自改机制，监管部门排查的隐患明显减少，共排查隐患341条，同比降低25.5%。

安全准入和应急处置方面，审查永悦科技、佳化化学等10余家企业安全评价报告、安全设施设计专篇，提出审查意见100余条，参加项目准入会及规划评审会10余次。载运电石汽车着火、柴油罐车翻车等突发事件发生后，常驻专家立即赶赴现场指导，为现场应急处置提供技术支持。

建言献策方面，为区政府决策、行业主管部门监管提供智力支持，帮助企业理顺安全管理体系，形成良好的“专企互动”，促进企业自觉落实安全生产主体责任。在每月召开的安全专家工作会上积极提出意见建议，形成安全生产调研文章10余篇。

宣传教育方面，定期开展安全培训，已组织10余期危险化学品安全生产培训班、经验交流会，为企业在风险分级管控、隐患排查治理、特殊作业安全管理等方面答疑解惑，提升企业管理人员和从业人员的安全意识和技能。中央推进安全生产领域改革发展意见出台后，组成讲师团，深入各镇（街道、园区）、企业宣讲、解读，进一步提升了泉港区的安全生产软实力。

 

 

 

 

 

附件2

 

晋江市实行安全生产社会化服务

 

晋江市民营企业多，中小微企业量大面广。市政府创新安全治理举措，实行安全生产隐患排查治理社会化服务，从2016年6月起开展为期半年的试点，2017年起在全市各镇（街）、市直部门全面推开，经过2年来的探索实践，逐步建立起“政府购买服务、专家排查隐患、部门依法监管、企业落实整改”的工作机制。

一、试点先行，前期筹备扎实有序。2016年初，晋江市安办组织前往深圳南山区学习政府购买安全生产社会化服务工作经验后，扎实抓好3项工作。一是顶层设计，抽调精干力量组建工作推进小组，根据前期调研情况制定《推行安全生产社会化服务试点工作实施方案》、《试点工作业务指导手册》。二是对接引入，成功引入深圳安评、深圳保顺安2家技术服务机构，完成服务项目收集汇总、专项工作经费补助及服务机构报备等配套工作。组织召开市镇两级社会化服务启动动员会议，实行市安办挂钩协调试点制度，指导各试点单位与服务机构洽谈、合同签订及服务开展。三是启动推进，2016年6月，青阳、梅岭、灵源、陈埭、东石、龙湖、深沪等7个镇（街）率先试点，以半年为周期，推行技术顾问、送教上门、专家驻点3种业务服务。通过半年运行，完成对354家企业“一对一”安全技术指导，对1556家沿街店面进行面对面的安全培训和隐患排查，累计排查、整改隐患近1万条，消除了一大批安全隐患，4名驻点专家分批派驻的14个单位安全监管职责进一步落实。

二、政策引导，工作推进精细规范。在总结试点经验的基础上，晋江市自2017年起，全面推行政府购买安全生产社会化服务。市安办充分发挥桥梁和纽带作用，加强服务过程的沟通协调、指导督促和监督管理，规范形成4项工作机制。一是协调机制。每年组织多场对接会、协调会，统筹调配 20个镇（街）、开发区启动社会化服务，先后促成海洋与渔业、经信、市政园林、卫计、交通运输、水利、住建、旅游、教育等市直部门开展先行先试工作，定期协调解决存在问题和难点。二是服务机制。出台《晋江市安全生产技术顾问服务工作基础台账建议清单》，制定《安全生产社会化服务中介机构月度隐患排查报表》，规范技术服务工作流程和方式。三是督查机制。对委托单位进行经常性走访，开展多轮次企业问卷调查，全面了解和掌握技术服务情况；定期组织对各服务机构进行监督检查，督促限期整改存在问题，推动其提高服务质量和水平。四是奖励机制。出台《晋江市安全生产社会化服务优秀项目评选奖励暂行办法》，市财政每年拨出200万元专项经费，用于对各委托单位开展服务项目的评选奖励。截至目前，已开展2次安全生产社会化服务优秀项目评选活动，兑现奖励金额200万元。

三、协同协作，模式创新成效明显。充分发挥5家报备服务机构的技术优势，提升5方面服务模式。一是安全生产技术顾问服务。深入企业开展全面诊断排查和安全风险点辨识，强化信息互联互通，构筑精细化、立体化服务。2017年至今，5家中介机构对所服务企业开展多轮现场隐患排查检查、复查和技术帮扶指导，共排查各类安全隐患2万余条，制订整改帮扶计划或措施1.2万余份（条），有效整改和消除了一大批安全隐患。二是安全生产送教上门。对沿街店面开展“点对点”、“面对面”的隐患排查检查和安全培训，根据检查结果实行分类分级，健全完善“一户一档”台账资料。截至目前累计排查各类安全隐患近1万条，培训有关人员5700余人。三是安全生产专家驻点。先后聘请4名专家分批轮流派驻69个市直部门、镇（街）和经济开发区，借力专家专业指导，有效化解消防、特种设备、危化等重点行业领域安全监管一线普遍存在的重点难点问题。四是危化领域安全风险专项评估。依托专家深入一线现场开展安全风险评估管理，结合企业安全管理现状，逐家进行安全风险辨析，研判评定安全风险，目前已完成全市132家危险化学品生产经营企业风险评估评定，排查出重大风险0处、较大风险39处、一般风险511处、低风险1437处，并建立企业安全生产风险数据库，形成全市危险化学品生产经营企业安全风险分布图。五是信息技术服务。以“互联网+安全”为支撑，积极推进安全生产隐患排查长效机制建设，池店镇、金井镇、梅岭街道依托服务机构研究开发“镇级安全生产信息化管理系统”；深圳安评晋江分公司利用航拍机采集企业安全生产风险点信息。通过信息化手段，让一线监管人员及时掌握安全生产工作动态。此外，各相关单位结合工作实际，策划生成一批如安全风险分级管控、应急救援演练、安全生产专项整治、宣教培训等项目，助推安全监管创新发展。
