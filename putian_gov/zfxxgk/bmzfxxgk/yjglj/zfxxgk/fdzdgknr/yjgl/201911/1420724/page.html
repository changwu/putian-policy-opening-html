关于开展莆田市“电信杯”《安全生产法》及相关法律法规知识竞赛的通知

发布时间：2015-05-19 08:00
| | |

莆市安办〔2015〕29号

                      

 

 

    各县（区）人民政府（管委会）安委会，市直有关部门，各中央属、省属、市直有关企业：

    为更好地推动《安全生产法》的学习和贯彻，根据市安办《关于印发新修改〈安全生产法〉学习宣传贯彻工作方案的通知》（莆市安办〔2014〕72号）安排，结合2015年“安全生产月”活动，拟于6月份组织开展“电信杯”《安全生产法》知识竞赛活动。现将有关事项通知如下：     

    一、参赛人员：参赛队伍共24支，其中市安委会成员单位选派9支、各县（区、管委会）选派7支，重点企业选派8支（名单见附件1）。每支参赛队伍3人（其中至少有1人是安全生产管理人员）。

二、参赛形式：

（一）参赛时间、地点：另行通知   

（二）题目范围：《安全生产法》及道路交通、消防、建筑施工、特种设备、学校安全、职业病卫生等相关法律法规。

（三）赛制规定：（具体规则见附件2）。

    （四）比赛题库：（请搜索莆田市安监局网站，网址：http://www.ptsafety.gov.cn/ggtz/20150519/304900015.shtml）。

请各参赛单位抓紧组织选拔参赛选手，并于6月10日前将名单报市安监局监管一科（报名表见附件3）。

联系人：张玉栋，联系电话：2230918，传真：2339655；

邮箱：171719363@qq.com。

市安监局地址：城厢区龙桥街道市政府1号楼531室。

 

附件：1.参赛单位参赛名额分配

      2.赛制规定

      3.《安全生产法》知识竞赛参赛人员表

 

 

 

 

                       莆田市人民政府安委会办公室
                            2015年5月19 日

 

 

 

 

附件1

 

参赛单位参赛名额分配

 

一、县区：

仙游县、荔城区、城厢区、涵江区、秀屿区、北岸管委会、湄洲岛管委会各选派一支参赛队伍。

二、市安委会部分成员单位：

市住建局、市交通局、市公安消防支队、市交警支队、市质监局、市教育局、市水利局、市海洋与渔业局、莆田海事局各选派一支参赛队伍。

三、企业：

电信莆田分公司、国家电网莆田分公司、中海油莆田分公司、中石化莆田分公司、中石油莆田分公司、莆田汽车运输股份有限公司、莆田市国有资产投资有限公司、福建省建投集团有限公司各选派一支参赛队伍。

 

 

 

 

 

 

 

 

附件2

赛制规定

 

1、比赛分初赛阶段，决赛阶段。初赛阶段由24支参赛队伍随机抽签分成四小组进行，每个小组由6支队伍对决，每个小组取前 2名进入决赛；决赛阶段由进入决赛的8支队伍进行对决。决出一等奖2名，奖励6000元；二等奖3名，奖励3000元；三等奖3名，奖励1500元。其余为优秀奖，奖励900元。

    2、初赛阶段和决赛阶段各分三轮。第一轮为必答题，抽签决定答题内容，每支队伍3道题（每人一题），答对一题加10分，答错不扣分；第二轮为抢答题，答对者加10分，答错扣10分；第三轮为风险题，每道题按难易程度给予不同的分值，分别是30分、20分、10分，每组最多可选两题，答对加相应的分数，答错扣相应的分数。
