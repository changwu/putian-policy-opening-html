集中开展危险化学品领域“打非治违”、清剿火患和安全生产标准化工作进行了督查。现将督查情况通报如下：
一、总体情况
督查组通过听取汇报、查阅资料和现场检查等方式，对各县
(
区、管委会
)
和部门企业进行了督查。从督查情况看，各县
(
区、管委会
)
基本上能按照全国、全省、全市开展危险化学品领域“打非治违”、清剿火患和安全生产标准化的工作部署，制定工作方案，明确工作重点内容，并结合安全生产行政许可、安全生产标准化达标创建等工作，认真开展检查执法，严格落实“四个一律”、“六个一批”，严厉打击各类非法违法行为。城厢区、荔城区危险化学品经营（零售）企业安全生产标准化达标创建工作进度较快，已有部分乡镇已完成初评并报区局核准。
二、存在的主要问题
一是安全标准化工作进展不平衡。
个别县
(
区、管委会
)
和一些危化品企业对开展安全生产标准化工作的重要性、紧迫性认识不足，存在消极观望思想，推进安全标准化工作力度不大，办法不多，进度不够理想。除城厢区、荔城区外，其他县
(
区、管委会
)
危险化学品经营企业安全生产标准化仍处于动员部署阶段。
二是“打非治违”、清剿火患工作不够有力。
个别县
(
区、管委会
)
和危化品企业“打非治违”、清剿火患台账不完整甚至没有建立，仙游县、涵江区、北岸打非工作尚未开展，且未见隐患排查治理档案。部分县
(
区、管委会
)
未能及时上报“打非治违”、清剿火患、安全生产标准化动态，隐患排查不深入、不彻底，一些企业还不同程度地存在安全隐患，无证经营危险化学品未能彻底取缔，其中仙游县、秀屿区、涵江区非法经营危险化学品比例较大（抽查危险化学品经营（零售）企业存在问题详见附件）。
三、下一步工作要求
（一）加快推进危险化学品安全生产标准化工作。
要按照全市危险化学品安全监管工作会议和市局《关于印发〈莆田市危险化学品经营（零售）企业安全生产标准化评审工作实施办法〉的通知》（莆市安监〔
2012
〕
45
号）、《关于明确危险化学品经营（批发）企业安全生产标准化评审有关事项的通知》（莆市安监〔
2012
〕
74
号）文件等精神，结合开展危险化学品领域“打非治违”、清剿火患、十八大危险化学消防安全保卫战役、安全生产“百日大检查”活动，按照
10
月底前全面达标、
11-12
月扫尾的时间要求，倒记时安排工作进度，制定工作计划，快马加鞭，稳步推进危险化学品经营企业安全标准化达标创建工作。
（二）扎实深入开展危险化学品“打非治违”、清剿火患战役、十八大消防安全保卫战和“百日大检查”活动。
要在前阶段工作基础上，按照全国、全省、全市的各专项工作部署，加强领导，落实责任，查找薄弱环节，扎实深入开展各专项工作。特别是非法经营危险化学品比较突出的县
(
区、管委会
)
，要充分发挥危险化学品安全监管部门联席会议作用，加强工作协调，开展联合执法，严格落实“四个一律”、“六个一批”工作制度，建立健全各专项工作台账，形成“检查有记录、有复查，督查有通报、有反馈”的良好工作模式，确保各专项工作取得实效。
（三）严格危险化学品经营安全许可。
要加强新修订《危险化学品经营许可证管理办法》（国家安监总局令第
55
号）的宣贯，重新梳理发证条件及程序，严格现场安全条件核查，对经营场所与住宿未防火分隔、有生活设施、有住宿、电气线路防护不到位等不符合安全条件的，一律不予以发证；对已取证但降低安全条件且拒不整改的，依法予以行政处罚，直至吊销相关证照。
（四）加强危险化学品信息的统计和报送。
要按照市局各专项工作信息统计和报送要求，指定专人负责，及时准确上报本辖区开展危险化学品各专项工作情况。
本次督查中发现的主要问题，各相关县
(
区、管委会

要督促企业落实整改，并于

之前报送市局监管三科。
