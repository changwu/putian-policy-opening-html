关于印发2021年度绩效管理工作方案的通知

发布时间：2021-07-12 17:07
| | |
政策解读:

局各部门、各直属单位：

经研究，现将《莆田市林业局2021年度绩效管理工作方案》印发给你们，请结合实际，认真贯彻执行。

 

 

 

 

 

 

                              莆田市林业局

                            2021年 7月12日

 

莆田市林业局2021年度绩效管理工作方案

 

根据《2021年度莆田市绩效管理工作方案》文件要求，围绕推进市委、市政府重点工作任务落实，马上就办、真抓实干，以优异成绩庆祝建党100周年，结合我局工作实际，特制定本工作方案。

一、组织领导

绩效管理工作在市效能办的具体指导和局党组的统一领导下组织实施。成立以党组书记、局长为组长，其他领导班子成员为副组长，各部门、各直属单位负责人为成员的绩效管理工作领导小组，领导小组主要负责绩效管理工作的组织协调指导工作。领导小组下设办公室，挂靠在局综合科，负责牵头年终考评及日常工作，各部门、各直属单位配合抓好落实。

二、考评对象

局各部门、各直属单位及干部职工（以下简称干部）。

三、考评内容

重点考核各部门、各直属单位及干部的业务工作、自身建设、改革创新三项内容。

1.业务工作方面：（1）贯彻落实中央、省、市决策部署要求情况，特别是扎实做好“六稳”工作、全面落实“六保”任务，统筹抓好促生产、促消费、促项目建设、促外经贸、促旅游以及保基本、防风险、控疫情等“五促一保一防一控”，开展“三看两评”活动等工作；（2）根据职能职责应承担的重点工作任务以及效能工作要点等落实情况。

2.自身建设方面：主要考核学习贯彻习近平总书记在福建考察时的重要讲话精神，全面贯彻党的十九届五中全会精神，聚焦“一个篇章”的总目标、“四个更大”的新要求和四项重点任务，结合党史学习教育及“再学习、再调研、再落实”活动，落实全面从严治党主体责任，增强“四个意识”、坚定“四个自信”、做到“两个维护”；推进依法办事和依法行政，以及提高效率、优化服务、转变作风和推行项目工作法等方面情况，努力建设担当、服务、创新、实干、廉洁机关。

3.改革创新方面：主要考核解放思想、与时俱进，自觉运用系统观念、改革思维、创新办法来解决问题、推动发展，推进治理理念创新、行政方式创新和体制机制创新等方面情况。

四、考评方式

采取指标考核、公众评议、正向激励、察访核验、省对市考评结果运用相结合的方式进行。

（一）指标考核

根据市委、市政府对我局绩效考评的7个一级指标、21个二级指标，进行责任分解（具体指标及责任分解详见附件1），制定绩效管理工作方案，于2021年7月31日前报送市效能办备案。及时建立负面清单制度（具体填写说明详见附件2、附件3），对市委、市政府下达的实质性目标任务落实情况进行常态化跟踪管理，每月5日前报送局效能办，局效能办对科室“负面清单”进行重点滚动管理、跟踪落实。负责林长制成效指标的科室要认真、客观采集指标数据，原则上所采集指标的最高扣分要不低于分值的30%，经征求参评单位意见后于2022年1月31日前报市效能办。

（二）公众评议

由局综合科结合年度考核民主测评适时开展。

（三）正向激励

鼓励各科室部门（干部）结合实际创造性开展工作，认真贯彻落实中央、省、市重大决策部署，马上就办、真抓实干，卓有成效地完成各项工作任务，在全国、全省创出亮点品牌，得到表彰表扬、批示肯定、经验推广等，以及在开展“我为群众办实事”实践活动中成效明显、在“再学习、再调研、再落实”活动中积极破解12345高频诉求取得实效的，予以正向激励加分。对正向激励事项进行常态化“滚动”管理报送给市效能办，正向激励得分占总分10%。

（四）察访核验

局综合科结合日常效能督查，采用日常监管、实地督查、随机暗访等多种方式，建立问题台账实时扣分。对上级督查检查考核通报的典型问题；市本级效能督查发现的效率意识、行政服务、工作作风、担当作为，以及推行项目工作法等方面存在的典型问题；办理12345诉求件、效能投诉件中存在的典型问题；按照察访核验扣分办等规定，在绩效考评中予以扣分。

对情节轻微、影响较小、及时整改到位的问题，按照《莆田市机关效能建设正向激励和容错纠错暂行办法》（莆委办发〔2017〕14号）等规定予以减免扣分。

（五）省对市考评结果运用

1.省指标考核。根据省对市绩效考核指标权重实行分档运用（不含平潭，下同）。省对市绩效考核指标位列全省第1-3位的，分别加4分、3分、2分；位列第7-9位的，分别扣3分、4分、5分。位列第4-6位的，相比上一年每进步（退步）1位，按照权重档次加（扣）0.4分。累计加（扣）分不超过10分。

2.省公众评议。公众评议位居全省后四位（含平潭）时，对日常组织协调、分析指导、宣传引导不到位，以及公众评议排位靠后板块或分值较低指标涉及的市直单位，予以扣1-4分。居全省前三位时，对作出重要贡献的单位加1-3分。

3.省察访核验。对省察访核验扣分运用的问题，按省扣分分值2倍扣分运用，每个问题最低扣1分。

五、结果汇总与等次确定

（一）结果汇总

绩效考评得分=指标考核得分×60%＋公众评议得分×30%＋正向激励加分×10%－察访核验扣分±省对市考评结果运用。

（二）等次确定

1．考评结果分为优秀、良好、一般三个等次。按绩效考评得分高低排列，优秀等次控制在30%（含）以内，一般等次控制在10%（含）以内，其他的为良好等次（具体等次比例由局务会根据考评得分研究确定）。

2.出现下列情形之一的，予以降低一个考评等次：

（1）受到党政纪处分。

（2）发生重大群体性事件、重大安全事件、重大生态破坏事件、重大环境污染事件以及其他对公共安全、经济社会发展造成恶劣影响或严重后果的事件。

（3）重大疫情防控措施不落实，导致扩散蔓延等严重后果的。

（4）因工作落实不到位、履职不力造成省对市绩效考评扣分较多，严重影响市对我局绩效考评成绩的。

（5）存在其他重大问题的。

3．出现下列情形之一的，不能评为优秀等次：

（1）在省对市绩效指标考核中，按市考评规则换算后，扣6分（含）以上的相关科室（直属单位）和相关干部。

（2）在省察访核验扣分中，导致我局扣分居市直责任单位前2名的相关科室（直属单位）和相关干部。

（3）导致局被效能问责的相关科室（直属单位）和相关干部。

4．在绩效管理工作中弄虚作假导致我局绩效考评为差等次的相关科室（直属单位）和相关干部的内部绩效考评等次为一般等次。  

5.绩效降档后空出的等次名额依排名次序递补，出现多种降级情形的，从重降级一次。

六、结果运用

1、通报考评结果。绩效考评结果在全局进行通报。

2、挂钩考核评定。绩效考评结果作为单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。

市对局绩效考评结果抄送市委组织部、文明办、人社局，作为干部能上能下和领导班子考核、领导干部评价、精神文明单位评定、市直单位公务员年度考核优秀等次比例确定以及评先评优的重要依据。评为优秀等次的，局主要领导年度考核直接定为优秀等次（不占单位名额）；评为优秀、良好、一般、差等次的，工作人员年度考核优秀等次比例分别按25%、20%、15%、8%核定（其他文件另有规定的除外）。按照中组部《公务员平时考核办法》要求，按月开展对公务员（含参公）个人绩效考核的市直单位，年度考核优秀比例最高可再增加10%（有意向开展的单位，需于6月底前向市委组织部报备）。评为差等次的（不含绩效降档后为差的），领导班子成员（含具体分管工作的处级干部）自考评结果通报下发之日起一年内不能评先评优、提拔任用。

因科室（直属单位）履职不到位导致局被评为差等次的科室（直属单位）负责人自考评结果通报下发之日起一年内不能评先评优、提拔任用。

3、实行绩效激励

（1）市直政府部门（含下属单位）根据考评结果发放绩效奖励。绩效奖励由绩效工资和绩效奖金构成，具体标准与考评结果经市委、市政府研究后确定。全年在职不足12个月的，按实际在职月数折算。财政全额拨款单位在编在职人员所需经费由财政预算安排，其他文件另有规定的除外。

（2）市直各单位进驻市行政服务中心审批服务窗口工作人员绩效奖励，按照市行政服务中心管委会或进驻单位绩效考评等次，由其进驻单位按“就高原则”发放。

（3）负责省对市绩效考核指标的市直责任单位，按市考评规则进行加、减分总换算后，根据最后加分情况予以贡献奖励，每分奖励2万元，全市所有指标的贡献奖励封顶50万元，用于奖励作出贡献的具体科室或个人，具体发放由单位内部研究。

（4）按照本方案精神，对内设机构（含履行公共事务管理职能的下属单位），组织开展实质性内部绩效考评，作为本单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。内部绩效考评结果分为优秀、良好、一般三个等次，由参评单位自主确定三个等次比例（其中0＜优秀等次比例≤30%，0＜一般等次比例≤10%，评为优秀等次的处级干部不能超过单位处级干部总数的30%），优秀等次、一般等次分别按照良好等次个人绩效奖金的1.2倍、0.5倍发放绩效奖金。对于内部评为优秀等次高于30%、一般等次高于10%、未评出一般等次的要向市效能办说明；未按要求实行绩效奖金差异化发放的单位，按每人1千元的标准扣回绩效奖金。

（5）凡受到党纪政务处分、效能问责的人员，年度考核被评为不称职（不合格）的人员，被省委、省政府、省效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的单位人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假累计超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病事假超期人员标准的5倍减发绩效奖励。

（6）市直单位因领导班子成员违纪违法而被降低考评等次的，领导班子成员按照降低后的等次发放绩效奖励，其他人员按照降低前的等次发放绩效奖励。因其他情形被降低考评等次的市直单位，直接按照降低后的等次发放绩效奖励。

4、实施效能问责

（1）年度绩效考评结果为一般的科室（科级及以下干部），责成其向局机关效能建设领导小组提交书面整改措施。

（2）省、市效能督查发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫（含）以上处理，对科室负责人进行通报批评，存在突出问题的对局分管领导进行诫勉教育。

（3）存在以下情形之一的，科室及下属单位负责人要在局机关效能建设领导小组会议上提交书面检讨：在省对市绩效指标考核中，按市考评规则换算后，扣6分（含）以上的责任科室；在省察访核验扣分中，扣分前2名的责任科室。

5、反馈整改提升

针对绩效考评中发现的问题，认真分析研究，查找薄弱环节，深刻剖析原因，制定整改措施，促进绩效提升。市效能办结合察访核验对整改情况进行“回头看”。

七、实施步骤

（一）制定方案，动员部署（2021年7月1日-7月31日）

按照2021年度莆田市绩效管理工作方案的要求，认真研究制定《莆田市林业局2021年度绩效管理工作方案》，明确目标任务和责任分工。组织全局干部职工认真学习绩效管理工作有关会议精神和文件规定，充分认识开展绩效管理工作的重要性和必要性，切实增强做好绩效管理工作的积极性和自觉性，扎实推动工作开展。

（二）组织实施，常态管理（2021年8月1日-12月31日）

建立工作台账，对市委、市政府下达的实质性目标任务落实情况进行常态化跟踪管理并建立“负面清单”按月报送。加强日常跟踪督促，推进工作落实到位。注意日常相关资料的收集、分类和存档，科室于每个月5日前向局综合科报送负责“负面清单”工作台账，要注意分析存在的问题及原因，及时采取有效措施加以推进。综合科及时汇总各科室部门“负面清单”工作台账并上报市效能办。

（三）分析汇总，迎接检查（2022年1月1日-1月31日）

各指标落实责任科室部门要对照绩效管理工作方案，全面系统地对各自负责落实指标工作进行自我评估和客观分析，认真收集相关迎检资料，并于2022年1月15日前报到局综合科。局综合科要收集、汇总各科室相关迎检材料，进行自我评估，形成全面、完善的迎检材料，撰写自评报告于2022年1 月31日前送市效能办；根据市效能办、市直机关党工委的安排，认真做好绩效迎检工作。

（四）内部考评，整改提升（2022年2月1日-3月30日）

市对我局绩效考评检查结束后，结合考核组反馈的情况，局综合科组织对局内部各科室部门（干部）的差异化绩效考评，考评结果报局务会研究确定。各科室部门要针对绩效考评反馈存在的问题和不足，及时进行深入分析，查找问题症结原因，制定整改措施，推动全局工作科学化水平进一步提升。整改情况纳入下一年度绩效考评。

八、工作要求

（一）统一思想认识。树立正确的绩效价值观，把绩效管理作为促进市委、市政府决策部署落实的重要举措，增强主体责任意识，要认识到考评方案的变化，深入推进绩效差异化考评，细化分解责任。要经常分析绩效指标进展情况，加强过程监控，确保全面实现年度绩效目标。各科室负责人是本科室绩效管理工作第一责任人，对本科室的绩效管理工作负总责，要指定专人负责绩效考评工作（人员名单于7月31日前报局综合科）。全局上下要继续贯彻“马上就办”的工作作风，共同提升全局工作效能，共同维护全局良好形象，全力争取在全市绩效考评中取得优秀等次。

（二）强化统筹协调。机关效能建设领导小组及其办公室要充分发挥组织协调作用，统筹协调相关科室，做好各个环节的衔接，提升整体工作合力。机关效能建设领导小组办公室每季度要检查各科室完成绩效考评各项工作，及时发现问题，及时协调解决，确保绩效管理工作顺利开展。

（三）强化结果应用。各科室要以严谨细致、务实求效的作风共同做好绩效管理工作，做到资料真实完整，数据准确可靠，台账规范有序。要坚决防止和克服形式主义，坚决制止马虎应付、弄虚作假现象。
