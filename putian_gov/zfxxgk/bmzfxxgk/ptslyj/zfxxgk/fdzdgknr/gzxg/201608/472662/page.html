关于市政协六届五次会议第2016132号提案办理情况的答复

发布时间：2016-08-01 10:42
| | |
政策解读:

签发：方宝昌

办理结果：B类

 

魏阳青委员：

您提出的《关于尽快更新抢救我市沿海防护林的建议》的提案（第2016132号）收悉，现将办理情况函复如下：

沿海防护林是沿海地区人民赖于生存和社会经济藉以发展的“生命线”和“保安林”，是保障沿海人民安居乐业的“绿色长城”，是保障我市沿海地区经济繁荣和社会可持续发展的重要支撑。加强沿海防护林建设，对于防灾减灾、改善生态环境、建设生态文明、促进经济社会发展具有重要意义。因此，您提出的尽快更新抢救我市沿海防护林的建议十分重要，代表莆田沿海人民的心声，同时也为林业工作提出了合理化建议，对此我们表示衷心的感谢！

一、沿海防护林建设成效

    （一）森林资源。近年来，我市狠抓造林绿化，突出消灭山地水土流失区荒山迹地，推动面上造林绿化发展，促进生态修复。据省造林检查验收统计，“十二五”期间，全市完成造林绿化面积75.65万亩，占省下达目标任务62.09万亩的121.84%，据2014年森林资源建档资料，全市森林面积345.45万亩，森林覆盖率达59.82%，森林蓄积量达982.03万立方米，提前一年完成省政府下达的“十二五”森林覆盖率、森林蓄积量“双控”指标任务。

    （二）沿海防护林。近年来，我市充分利用中央预算内防护林项目投资，积极争取省年度造林绿化补助资金及市财政支持切实加强全市沿海防护林建设，“十二五”期间，共完成以木麻黄为主的沿海防护林建设面积42.36万亩，总投资8106.9万元。全市现有基干林带长度254.9公里、面积3.41万亩，沿海20个乡（镇）森林覆盖率达26.56%。

二、主要做法

（一）加强领导，建立目标责任。我市各级政府充分认识沿海防护林建设的重要性和迫切性，把沿海防护林建设摆上农村工作的突出位置，切实加强领导，认真部署，狠抓落实。每年召开专题会议，动员发动、明确任务、交流经验。如今年6月，市政府组织召开沿海防护林建设专题会，各县区政府（管委会）分管领导、林业主管部门主要领导和年度沿海防护林任务镇镇长参加，傅东阳副市长做强调讲话。各主要县区把沿海防护林建设纳入乡镇党委领导的政绩考核内容，签定任期目标责任状和年度目标责任状，强调乡(镇)主要领导亲自抓，分管领导具体抓、任务落实到山头地块，责任落实到人。  

（二）积极探索，拓展造林空间。近年来，全省林业系统积极探索拓展沿海防护林造林空间，试行沿海基干林带租地造林和石漠化造林新模式。特别是这两年，我市在秀屿区在东庄镇三苏片区（苏田、苏厝、厝头村）、西梧村实施沿海基干林带租地造林共200亩，省财政补助1.2万元/亩（其中增加租地补助1万元/亩，租地年限应达20年），造林成效明显；今年，我市沿海基干林带建设列入省委省政府为民办实事项目，秀屿区埭头镇温李村列入全省石漠化造林两个试点之一，面积300亩，省、市财政补助1.5万元/亩。

（三）制定措施，加强保护管理。一是认真做好沿海防护林生态红线划定工作。按照《福建省林业厅关于印发福建省林业生态红线划定实施方案的通知》要求，组织各县区（管委会）认真开展沿海防护林生态红线划定工作，建立全市林业生态红线地理空间数据库，形成全市林业生态红线一张图；二是落实管控措施，严格管理，确保保护面积不减少、保护性质不改变、生态功能不退化、管理要求不降低；三是对过去已有防护林而被破坏侵占的，坚决退耕还林，不予补偿，对于新占用的，严格要求实行“占一补一”政策，并根据“三个必造”要求在次年全部造上林；四是加强执法，严厉打击破坏沿海防护林行为。

（四）多方筹措，不断加大投入。近年来，市林业部门积极争取中央财政、省级造林专项资金、市财政等造林补助资金加强沿海防护林建设，据统计，“十二五”期间内全市共完成沿海防护林建设面积42.36万亩，争取各级财政投资8106.9万元。一是沿海防护林项目中央预算内投资7432万元，完成人工造林3.67万亩、封山育林37.35万亩；二是年度造林省财政专项资金575.5万元，完成沿海防护林基干林带建设1.34万亩；三是年度造林市财政投入99.4万元。此外要求各县区(管委会)按市补助标准予以配套。

    （五）参观学习，借鉴先进经验。为加快建设我市沿海绿色屏障，确保造林绿化的质量与成效。2016年4月，傅冬阳副市长带领沿海三个区政府（管委会）领导及下属相关部门、乡镇领导和市林业局分管领导及相关人共50多人赴平潭综合实验区参观学习吹沙地防风固沙林建设、石漠化荒山植被恢复等沿海防护林造林绿化经验。傅冬阳副市长指出，我市各地要学习借鉴平潭领导重视、舍得投入、科技兴林、质量第一等造林绿化经验与做法，大力开展造林绿化，加快建设沿海防护林，为创建国家森林城市、打造宜居莆田奠定基础条件。

三、沿海防护林保护和建设面临困难问题

（一）沿海防护林生态功能仍然脆弱。全市现有沿海基干林带存在一定长度断带，现有沙泥岸林带平均宽度有待加宽加厚；廿十世纪六、七年代营造木麻黄林老化严重，防风固沙能力弱；沿海气候恶劣，山头立地条件差，森林植被恢复缓慢；现有防护林中幼林比例高，树种结构单一。

    （二）沿海防护林建设保护争地矛盾突出。我市近几年港口码头、工业园区、滨海大道等项目建设，审批征占用林地，砍伐了原有建设的基干林带、农田林网等，导致沿海防护林建设与保护争地矛盾突出。

    （三）沿海防护林建设保护难度不断加大。一是落实用地难。虽然按建设标准要求区划界定沿海基干林带，补充了新增林地、逆转林地和非规划造林地，但群众以种种理由，不愿意将宜林地用于造林；二是造林更新难。沿海土地贫瘠沙化，气候条件恶劣，造林更新不易成活；三是保护管理难。沿海群众建房、采石、养殖等非法占用林地履禁不止。

四、下一步工作计划

    （一）提高认识，切实加强组织领导。沿海防护林建设是一项利益当代、功在千秋的伟大事业，要把沿海防护林建设定位在维护生态安全、抵御自然灾害、建设宜居城市之上，实现从一般性生态功能，向以应对风暴潮等突发性生态灾难为重点的综合防护功能扩展。各级政府要高度重视沿海防护林建设，加强领导，强化措施，努力推动沿海防护林建设上新台阶。要认真制定规划，切实抓好实施，做到政府主要领导亲自抓，分管具体抓，部门分工负责抓，建立领导目标责任制，做到持之以恒、常抓不懈，一任接一任干下去，推动沿海防护林建设的发展。

（二）突出重点，推进沿海防护林建设。将沿海防护林建设作为林业生态建设重中之重来抓，省统一编制《沿海防护林体系建设规划》（2016-2025年），制定《关于加快推进沿海防护林体系建设的实施方案》。“十三五”期间全市计划完成沿海防护林建设任务47.3万亩，其中：人工造林更新12万亩、林分修复6.3万亩，封山育林29万亩。一是加强基干林带建设。对沿海基干林带断带进行填平补齐、拓展加宽、完善配套、巩固提高，促进基干林带建设达标；二是加快老林带更新改造。二十世纪六、七十年代营造的木麻黄老林带较多，成为成过熟林，枯死严重，防护功能差，更新改造刻不容缓；三是大力开展封山育林。充分利用自然力，采用补植、抚育、人工促进天然更新的办法，增加森林植被，提高森林覆盖率；四是优化林种树种结构。大力提倡营造补植阔叶树，形成混交林或针阔混交林，立足乡土树种，大力引种适生优良阔叶树种，改变树种单一现状。

（三）注重科技，提高沿海防护林成效。一要突出重点，把海岸基干林带断带合拢、沙荒风口治理、老林带更新、农田林网建设作为重点来抓；二要分片规划，对沙荒风口治理，要采取工程措施和生物措施相结合的办法，筑防风沙堤或砌石堤，埋设挡风笆篱，栽植蔓荆、苦槛蓝、马樱丹等固沙植被，造林挖大穴、填足客土、栽大容器苗，确保一次性治理成功；对新垦区农田林网建设，采取挖深沟、排盐碱、填红土、筑高床造林，以提高造林成活率;对老林带更新，要先内后外，由里及表，分段改造，留足防风林带，注重沙壤改良，推广种植抗风、抗病木麻黄良种；三要丰富老林带更新树种，巨尾桉、红千层、厚荚相思等，以老林带更新、农田林网、护路护岸、红树林建设为主，以相思类、桉类、棕榈类、木麻黄类及草花藤本等多层次绿化，大力营造优良乡土和外来速生阔叶树种，提倡营造混交林，循序渐进，逐步优化树种结构，提高林分质量，增强森林防护能力；以速丰林的营造标准进行管理老林带更新、农田林网、护路护岸林，实行大穴大肥管理营造，分期实施；四要大力推广良种壮苗造林，积极引进“闽平二号”木麻黄水培容器苗，提高造林成效。

（四）创新机制，活化沿海防护林建设。要深化改革，创新机制，解决用地难、保护难、发展难等深层次矛盾和问题，推动沿海防护林建设发展。一是创新管护机制。积极探索在土地林木所有权不变的情况下，通过征用、租赁、补偿、置换等多种方式对划定基干林带范围的土地林木收归统一经营管理，建立以县（市、区）为主、责权利相结合的管护机制，在县级林业主管部门成立“防护林管理站（所）”，专门负责重点防护林的建设规划、组织实施和监督管理；二是创新造林机制。明确规定将征占用林地征收的植被恢复费返还部分，主要用于沿海防护林基干林带、农田林网建设造林；落实“征一补一”制度；三是突破政策制约。建议尽快修改相关法律、法规和政策，放宽防护林更新采伐，加快木麻黄老林带更新改造步伐。

（五）增加投入，保障沿海防护林建设。沿海防护林建设是一项社会性公益事业，需要全社会支持和投入。要要充分利用国债资金及地方配套资金，加大沿海防护老林带更新、护路林、农田林网的投资力度，加强防护林建设；二要鼓励个体、外商、联合体、企业等投资造林。落实“谁造谁有、谁投资谁受益”的政策，鼓励各种所有制承包经营荒山迹地，沿海林带内农田营造适宜当地的果树、花卉、珍贵树种、药材等，提高防护林的经济效益，调动全社会办林业的积极性，形成全社会办林业，全民搞绿化的局面。

   （六）依法保护，巩固沿海防护林建设。一要强化对破坏防护林海防林行为的打击力度。严格依照有关法律法规，加强执法，强化对破坏防护林的查处力度，发现一起处理一起，决不能姑息迁就。二要严格防护林林地征占用管理。特别是征用基干林带、农田林网等防护林，严格审核把关，尽量不批少批，确因项目建设需要，由业主同步征用一定面积的土地，用于等项目周围林带林网建设。三要加大防护林防火林带建设力度。在造林和低效林分改造时要结合防火林带建设，做到同步设计，同步施工；加强森林病虫害的监测和防治，减少火灾和虫害对防护林的破坏，确保防护林建设成果。

感谢您对林业建设事业的关心的支持，以上答复如有不妥之处，敬请批评指正！
