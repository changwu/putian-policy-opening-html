莆田市林业局关于做好第十四届中国·海峡项目成果交易会有关林业项目征集等筹备工作的通知

发布时间：2016-05-17 16:52
| | |
政策解读:

 

各县区林业主管部门、各省属国有林场：

第十四届中国·海峡项目成果交易会（简称第十四届“6.18”）将于6月18日在福州开幕。为扎实做好林业项目征集和林业展馆布设等各项筹备工作，现将有关事项通知如下：

一、总体任务

根据总体部署和要求，我局今年要完成征集企业技术需求14项以上，并成功对接项目6项以上；组织科技专家赴有关县区开展下乡入企进林区活动。其中，展品及企业技术需求征集、对接项目报送、开展科技专家下乡入企进林区活动等工作需要县区林业主管部门配合完成。

二、主要任务分解及要求

（一）企业技术需求征集、对接项目申报

1.任务分解。征集我市林业企业技术需求14项以上、对接项目6项以上。具体分解如下：

2.时间要求：为了及时发布企业技术需求，做好对接，请于5月10日前上报第一批企业技术需求，5月31日前报送对接项目。同时，请各县区登录“6.18虚拟研究院”（网址：http://www.618.gov.cn/），做好本地区的技术需求和对接项目的网上录入工作。

（二）科技专家下乡入企进林区活动

主要以讲座、科技咨询、科技成果对接、企业技术诊断等形式开展。以省内科研院校的专家为主，有针对性邀请省外科研院校专家。请县区提前摸底，提出需要林业专家帮助提升的行业技术内容和方向、拟对接的林业专家名单（或专长）及项目，希望能安排专家参加的活动等，并于5月9日前报市局产业科。

（三）展示展销工作

按照组委会的展务要求以及林业工作特点，林业馆的展示主题：发展森林生态产业，增加百姓生态福利。今年重点展示的内容为：竹材（笋）精深加工产品（以竹产品设计大赛获奖样品为主）、林下经济、林业生物医药、珍稀树木、新品种花卉苗木等，让全社会进一步了解林业在生态建设中的地位与作用，让广大群众享受林业生态建设的成果。请各县区按照要求，认真收集文字、图片，征集供展示展销的精品（详见附件3），并于5月15日前将参展的文字、图片（用于制作展板）以及拟参展、销售的企业及产品清单报厅产业处；于6月10日前将参展产品送达厅产业处。销售企业于6月16日下午闭馆前完成产品就位。

三、加强领导，确保落实

请县区林业林业主管部门高度重视，加强领导，按照要求抓好任务的分解落实工作，并确定1名联络员，及时报市局产业科。联系人：陈 昱，E-mail：ptlyjcyk@163.com。
