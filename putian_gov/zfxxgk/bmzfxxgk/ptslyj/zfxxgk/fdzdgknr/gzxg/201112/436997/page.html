莆田市林业局关于印发《贯彻莆委办[2011]76号文件精神实施方案》的通知

发布时间：2011-12-30 08:00
| | |
政策解读:

　　莆林综［2011］102号

　　莆田市林业局关于印发《贯彻莆委办[2011]76号文件精神实施方案》的通知

　　 

　　市局各部门、各直属单位：

　　根据《莆田市进一步贯彻落实<海峡西岸经济区发展规划>任务分工方案》及其考核评估办法的通知》（莆委办[2011]76号）精神，现将《贯彻莆委办[2011]76号文件精神实施方案》印发给你们，请根据各自承担任务切实开展工作，并将分解工作的开展情况、取得的突出成绩、存在问题及下一步工作建议等形成工作报告，半年度报告于7月5日前，年度报告于下一年1月5日前报送办公室汇总，特此通知，请认真组织实施。

　　二○一一年十二月三十日

　　主题词： 林业  海西规划  任务分工  实施方案  通知     

　　莆田市林业局办公室                 2011年12月30日印发

　　贯彻莆委办[2011]76号文件精神实施方案

　　一、加强台湾农民创业园建设

　　（一）目标

　　到2015年，建成海峡西岸有影响力的创业园，新引进台资企业50个，园区开发建设面积达4000公顷，园区总产值达30亿元。

　　（二）措施

　　 1．推进林业交流平台建设

　　借助海峡两岸农博会、花博会等重大展会，争取与三明市轮流举办海峡两岸林博会，大力开展莆台林业合作项目洽谈和对接；同时邀请台湾企业、投资者和林业专家、学者到莆田考察项目，积极参与海峡两岸林业学术交流活动，提高莆台现代林业、生物多样性保育及苗木花卉繁育、林产品加工、森林生态旅游等方面的交流合作水平。到2015年，莆台林业合作交流达到一定的深度和广度。（牵头科室：种苗站；责任科室：营林站、林业科技实验中心、产业科）

　　2．推广台湾林业发展经验

　　加强台湾良种引进繁育中心建设，推广示范台湾“五新”技术；借鉴台湾林业行之有效的发展机制、经营模式和管理经验，大胆试验，促进我市传统林业向现代林业转变，实现林业增效，农民增收。到2015年，引进台湾优质农林品种5个以上，在林业发展经验示范推广上有较大的突破。（牵头科室：营林站；责任科室：种苗站、林业科技实验中心）

　　二、加强生态建设和保护

　　（一）目标

　　完成植树造林3万公顷，其中人工造林0.57万公顷，净增森林面积7666.7公顷，净增森林蓄积量75万立方米。到2015年，森林覆盖率达59.8%，森林蓄积量达883万立方米。城市、县城建成区绿化覆盖率达43.5 %、36%，人均公园绿地面积达 11.9平方米、8.5平方米。

　　（二）措施

　　1．实施“四绿”工程

　　（1）绿色城市。围绕“保护壶山兰水景观，建设生态环保家园，突出荔林水乡特色，打造滨海宜居城市”的总体目标，以创建园林城市、森林城市为载体，大力发展城市森林，结合全民义务植树活动，构建城区绿美相拥、城郊森林环抱、林水相依、林路相连、山水辉映、各具特色的城市绿地生态系统；加快城市和县城绿化、美化、园林化建设，提升面城“五山”（凤凰山、天马山、壶公山、九华山、囊山）绿化水平，营造南北洋水乡荔林绿色美景，推进开发区、军营、校园绿化建设。 “十二五”期间，全市创建国家园林城市1个，国家森林城市1个，省级森林城市（县城）2个,建设绿色开发区10 个、绿色军营10个、绿色校园100个。

　　（2）绿色村镇。结合社会主义新农村建设，以“创绿色家园、建富裕新村”活动为载体，引导农民在“四旁四地”（村旁、宅旁、水旁、路旁、宜林荒地、低质低效林地、坡耕地、抛荒地）等非规划林地，广泛种植珍贵和优良乡土树种、特色经济树种，将农村居住环境改善与农民增收相结合。到2015年，全市创建绿色乡（镇）24个、绿色村庄270个，绿色乡（镇）建成区绿化覆盖率提高到18.5%以上，人均公园绿地面积提高到5.5平方米以上。

　　（3）绿色通道。大力推进绿色通道建设，进一步提高交通主干线沿线绿化美化水平，构建荔港、城港、仙港、荔涵等大道森林景观，加快建成通车的高速公路、国省道、铁路等交通干线及两侧一重山造林绿化美化。“十二五”期间，高速公路、国省道、铁路等通道绿化长度达1131公里、面积1533公顷，沿线一重山造林绿化面积0.3万公顷。到2015年，全市高速公路、国省道、铁路沿线可绿化里程绿化率达95%以上，一重山一面坡可绿化宜林地绿化率达100%。

　　（4）绿色屏障。重点建设海岸基干林带，巩固提高陆地海岸线280多公里绿色屏障的防灾减灾功能；进一步加大海岛绿化美化力度，建成湄洲、南日绿色明珠；大力推进纵深防护林建设，努力建起带、网、片相结合，林种、树种结构合理，生态结构稳定，与社会经济可持续发展相适应的森林综合防御体系。“十二五”期间，绿色屏障建设3.82万公顷，其中基干林带0.33万公顷，纵深防护林3.49万公顷。到2015年，全市海岸基干林带建成长度 240公里，沿海20个乡镇森林覆盖率达28%。（牵头科室：绿化办；责任科室：营林站、种苗站）

　　2．搞好森林经营工程

　　全面启动森林经营，强化科学经营管理，构建树种多样、层次复杂、结构稳定、功能完备的森林生态系统，加强中幼林抚育和低质低效林改造，优化森林结构，提高林地生产力和森林质量，增强林产品和生态产品供给能力，提升森林的多种功能。“十二五”期间，完成中幼林抚育2.36万公顷，低质低效林改造0.26万公顷，封山育林1.29万公顷。到2015年，全市森林蓄积量达883万立方米。（牵头科室：营林站；责任科室：绿化办、种苗站、林政站）

　　3．加快主要溪流和饮用水源保护区的生态修复

　　加强木兰溪、萩芦溪等主要溪流干支流一重山造林、补植，修复东圳、外渡、古洋、金钟等饮水库区一重山水源涵养林和水土保持林，提升区域森林生态功能。“十二五”期间，完成主要溪流和饮水库区一重山造林3666.7公顷，中幼林抚育1.06万公顷，低产低效林改造900公顷。到2015年，全市主要溪流和饮水库区一重山可绿化宜林地绿化率达100%，水土流失治理率达90%。（牵头科室：营林站；责任科室：绿化办、种苗站、林政站）

　　4.加强森林防火工作

　　进一步落实森林防火行政首长负责制，开展森林防火宣传教育工作，加大森林火灾扑救应急物资储备库，生物防火林带建设力度，及时发布高森林火险预警信息，组织重点火险时段巡山护林，健全县、乡二级扑火队伍，提高森林火灾快速反应与扑救能力。全市森林火灾受害率控制在1‰以下，森林火灾发生率控制在1次／万公顷以下。（牵头科室：防火办；责任科室：森林公安局、林业执法支队、林政站、营林科、林场处）
