莆田市林业局关于印发2017年度绩效管理工作方案的通知

发布时间：2017-07-12 09:46
| | |
政策解读:

　　莆田市林业局关于印发2017年度绩效管理工作方案的通知

　　局各部门、各直属单位：

　　经研究，现将《莆田市林业局2017年度绩效管理工作方案》印发给你们，请结合实际，认真贯彻执行。

　　                                                    莆田市林业局

                                                       2017年 6月28日

　　　　                    莆田市林业局2017年度绩效管理工作方案

　　为激发各部门、各直属单位勇于担当、真抓实干，持续有力地推进市委、市政府决策部署落实，打造宜居港城、建设美丽莆田，创建美丽中国的示范区，根据《中共莆田市委办公室、莆田市人民政府办公室关于印发〈2017年度绩效管理工作方案〉的通知》（莆委办〔2017〕46号）精神，结合我局工作实际，特制定本工作方案。

　　一、组织领导

　　绩效管理工作在市效能办的具体指导和局党组的统一领导下组织实施。成立以党组书记、局长为组长，其他领导班子成员为副组长，各部门、各直属单位负责人为成员的绩效管理工作领导小组，领导小组主要负责绩效管理工作的组织协调指导工作。领导小组下设办公室，挂靠在局办公室，负责日常工作，各部门、各直属单位配合抓好落实。

　　二、考评对象

　　局各部门、各直属单位及干部职工（以下简称干部）。

　　三、考评内容

　　考评采取指标考核、公众评议、正向激励、察访核验相结合的方式进行。重点考评各部门、各直属单位及干部贯彻落实市委、市政府的决策部署、2017年省政府工作主要任务、省政府“立项挂牌办理”任务、市政府工作主要任务、国民经济和社会发展计划主要指标、为民办实事项目、效能工作要点等情况，以及履职尽责、加强自身建设、推进改革创新等情况。

　　（一）指标考核

　　根据市委、市政府对我局绩效考评的12个一级指标、26个二级指标，进行责任分解和考核（具体考核指标及责任分解详见附件1）。

　　（二）公众评议

　　由局办公室结合年度考核民主测评适时开展。

　　（三）正向激励

　　鼓励各科室部门（干部）结合实际创造性开展工作，卓有成效完成各项任务（具体加分标准详见附件2）。

　　（四）察访核验

　　局办公室结合日常效能督查，采用随机抽查、问题核查、明察暗访等方式，不定期组织开展察访核验。发现的问题按照《效能督查发现问题绩效考评扣分办法》（莆效办〔2016〕15号），以倒扣分形式计入绩效考评总分（具体扣分标准详见附件2）。

　　四、结果汇总与运用

　　（一）结果汇总

　　处级干部绩效考评得分=分管科室绩效考评平均分+正向激励加分－察访核验扣分。

　　科室（部门）绩效考评得分=指标考核得分×60%＋公众评议得分×40%+正向激励加分－察访核验扣分。

　　科级及以下干部绩效考评得分=科室绩效考评得分*30%+个人指标考核得分×30%＋公众评议得分×40%+正向激励加分－察访核验扣分。

　　（二）等次确定

　　1．考评结果分为优秀、良好、一般三个等次

　　（1）局主要领导按照市对我局绩效考评结果确定个人绩效考评等次，市对我局绩效考评为优秀、良好、一般（含差）时，个人绩效考评等次分别为优秀、良好、一般等次。

　　（2）其他处级干部按绩效考评得分高低排列，排在前30%（含）的为优秀（评为优秀等次的处级干部不能超过单位处级干部总数的30%），其他80分（含）以上的为良好，60分（含）至80分的为一般，60分以下的为差。

　　（3）科室部门（科级及以下干部）按绩效考评得分高低排列，优秀等次控制在30%（含）以内，一般等次控制在10%（含）以内，其他的为良好等次（具体等次比例由局务会根据考评得分研究确定）。

　　2．符合下列情形之一的科室部门（干部），直接评为优秀等次：

　　（1）受到部级以上单位表彰（表扬）、推广或领导批示肯定。

　　（2）获省效能办绩效考评激励加分。

　　（3）负责省林业厅年度单项工作考评居全省第1名。

　　（4）负责省林业厅年度单项工作考评在全省位次比上一年提升3名以上。

　　（5）在建设美丽莆田工作中成效显著。

　　（6）负责市对我局年度绩效考评评为优秀等次。

　　3. 符合下列情形之一的，评为良好以上等次：

　　（1）受到厅级以上单位表彰（表扬）、推广或领导批示肯定。

　　（2）负责省林业厅年度单项工作考评居全省第2-3名。

　　（3）负责市对我局年度绩效考评评为良好等次。

　　4. 出现下列情形之一的，不能评为优秀等次：

　　（1）年度请病假累计超过2个月。

　　（2）年度请事假累计超过22个工作日。

　　（3）存在旷工问题。

　　5. 出现下列情形之一的，直接评为一般等次：

　　（1）负责省对市绩效考评指标、省林业厅年度单项工作考评居全省后2位且位次比上一年没有上升（不含平潭综合实验区，涉及负责多个指标的单位按照综合排位运用）。

　　（2）《建设美丽莆田2017年行动计划》重点任务（30大攻坚项目、20项重点工作）严重滞后。

　　（3）受到党政纪责任追究（含组织处理、诫勉谈话）、效能问责；

　　（4）不依法办事或不作为、乱作为，引发群体性事件，造成恶劣影响或严重后果的；

　　（5）社会治安综合治理工作出现严重问题，被一票否决的；

　　（6）生态文明建设工作中出现严重问题，发生重大以上环境污染事件，造成恶劣影响或严重后果的；

　　（7）发生重大以上安全生产（含食品安全）责任事故，造成恶劣影响或严重后果的。

　　（8）被上级查实或通报存在作风纪律问题。

　　（9）旷工超过5个工作日。

　　（10）在绩效管理工作中弄虚作假。

　　6. 其他：

　　市对我局绩效考评为一般等次时，处级干部（不含局主要领导，下同）不能评为优秀等次；市对我局绩效考评为差等次时，处级干部评为一般等次（直接评为优秀等次的除外）。

　　（三）结果运用

　　1. 通报考评结果。绩效考评结果在全局进行通报。

　　2. 挂钩考核评定。绩效考评结果作为单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。

　　（1）市对我局绩效考评为优秀等次时，负责市对我局绩效考评的科室负责人、经办人年度考核直接定为优秀等次；市对我局绩效考评为良好等次时，负责市对我局绩效考评的科室负责人、经办人年度考核直接定为称职以上等次；

　　（2）评为优秀等次的科室，科室负责人年度考核直接定为优秀等次（存在不能评为优秀等次的其他情形除外）。评为优秀、良好、一般等次的科室，科级及以下干部年度考核优秀等次比例分别按20%、12%、8%核定。

　　（3）在当年度省对市绩效考评任务落实、市本级绩效考评等工作中表现突出的一线干部，报市机关效能建设领导小组予以通报表扬。

　　（4）评为一般等次的科室，科室负责人一年内不推荐评先评优、提拔任用。

　　（5）评为一般等次的个人，一年内不推荐评先评优、提拔任用。

　　3. 实行绩效奖励

　　（1）优秀等次、一般等次分别按照良好等次个人绩效奖金的1.2倍、0.5倍发放绩效奖金。

　　（2）凡受到党政纪责任追究、效能问责的人员，年度考核被评为不称职（不合格）的人员，被省委、省政府、省效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的单位人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假累计超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病事假超期人员标准的5倍减发绩效奖励。

　　4. 实施效能问责

　　（1）年度绩效考评结果为一般的科室（科级及以下干部），责成其向局机关效能建设领导小组提交书面整改措施。

　　（2）省、市效能督查发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫（含）以上处理，对科室负责人进行通报批评，存在突出问题的对局分管领导进行诫勉教育。

　　五、实施步骤

　　（一）制定方案，动员部署（2017年6月10日-6月30日）

　　按照《2017年度莆田市绩效管理工作方案》（莆委办〔2017〕46号）要求，认真研究制定《莆田市林业局2017年度绩效管理工作方案》，明确目标任务和责任分工。组织全局干部职工认真学习绩效管理工作有关会议精神和文件规定，充分认识开展绩效管理工作的重要性和必要性，切实增强做好绩效管理工作的积极性和自觉性，扎实推动工作开展。

　　（二）组织实施，常态管理（2017年7月1日-12月31日）

　　建立绩效目标工作台账，加强日常跟踪督促，推进工作落实到位。各科室部门要对照《莆田市林业局绩效考核指标体系》（详见附件1）责任分工和评分标准，认真设定各自负责落实指标的年度工作目标，注意日常相关资料的收集、分类和存档，负责绩效考评指标数据采集责任科室于每个月10日前向局效能办报送负责采集的指标绩效目标工作台账（附件3）。对未按序时进度完成、进度不够明显的工作指标，要注意分析存在的问题及原因，及时采取有效措施加以推进，确保我局各项绩效工作指标保质保量完成。局效能办要及时汇总各科室部门绩效目标工作台账并公开。

　　（三）分析汇总，迎接检查（2018年1月1日-3月31日）

　　2018年3月底前，市效能办、市直机关党工委联合组织对我局开展指标核验。各指标落实责任科室部门要对照绩效管理工作方案，全面系统地对各自负责落实指标工作进行自我评估和客观分析，认真收集相关迎检资料，并于2018年1月20日前报到局效能办。局效能办要收集、汇总各科室相关迎检材料，进行自我评估，形成全面、完善的迎检材料，撰写自评报告于2018年1 月31日前送市效能办；根据市效能办、市直机关党工委的安排，认真做好绩效迎检工作。

　　（四）内部考评，整改提升（2018年4月1日-4月30日）

　　市对我局绩效考评检查结束后，结合考核组反馈的情况，局办公室组织对局内部各科室部门（干部）的差异化绩效考评，考评结果报局务会研究确定。各科室部门要针对绩效考评反馈存在的问题和不足，及时进行深入分析，查找问题症结原因，制定整改措施，推动全局工作科学化水平进一步提升。整改情况纳入下一年度绩效考评。

　　六、工作要求

　　（一）统一思想认识。树立正确的绩效价值观，把绩效管理作为行政管理的一项基本制度，增强主体责任意识。各科室负责人是本科室绩效管理工作第一责任人，对本科室的绩效管理工作负总责，要指定专人负责绩效考评工作（人员名单于7月10日前报局效能办）。全局上下要继续贯彻“马上就办”的工作作风，共同提升全局工作效能，共同维护全局良好形象，全力争取在全市绩效考评中取得优秀等次。

　　（二）强化统筹协调。机关效能建设领导小组及其办公室要充分发挥组织协调作用，统筹协调相关科室，做好各个环节的衔接，提升整体工作合力。机关效能建设领导小组办公室每季度要检查各科室完成绩效考评各项工作和绩效目标工作台账建设情况，及时发现问题，及时协调解决，确保绩效管理工作顺利开展。

　　（三）强化结果应用。各科室要以严谨细致、务实求效的作风共同做好绩效管理工作，做到资料真实完整，数据准确可靠，台账规范有序。要坚决防止和克服形式主义，坚决制止马虎应付、弄虚作假现象。

　　附件：1．2017年度莆田市林业局绩效考核指标体系 

　　      2．2017年度莆田市林业局科室（干部）差异化绩效考评评分标准 

　　      3. 莆田市林业局2017年1- 12月绩效目标工作台账
