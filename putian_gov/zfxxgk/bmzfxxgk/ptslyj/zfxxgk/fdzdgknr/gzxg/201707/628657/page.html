莆田市林业局关于松材线虫病防控工作进展情况的通报

发布时间：2017-07-31 09:02
| | |
政策解读:

各县（区）人民政府（管委会）：

松材线虫病是一种毁灭性的森林病害，俗称“松树癌症”，属重大林业检疫性有害生物。为做好松材线虫病等重大林业有害生物防控工作，省、市人民政府先后印发了《福建省人民政府关于下达2015-2017年松材线虫病等重大林业有害生物防控目标责任的通知》、《莆田市人民政府关于下达2015-2017年松材线虫病等重大林业有害生物防控目标责任的通知》，明确了防控目标、责任和工作要求。2017年初，省林业厅制定下发了“2017-2019年全省松材线虫病除治总体方案”，确定了三年内“基本消除现有疫情存量，控制疫情增量”的防控目标，并将2017年防治任务分解下达给各市、县（区）。

为确保完成省、市下达的2015-2017年松材线虫病等重大林业有害生物防控目标责任，实现未来3年的防控目标，今年以来，省、市多次对仙游县、涵江区、城厢区等地松材线虫病防控工作情况进行督查。近期，省林业厅就督查中发现的问题进行了通报，并约谈了有关县区。具体如下：

2017年6月19日，《福建省林业厅关于松材线虫病防治任务完成情况通报（第三期）》点名通报了仙游县、涵江区松材线虫病松林采伐改造完成率低于50%，仙游县未全面完成以菌治虫任务等有关情况。2017年7月12日，省林业厅就城厢区在松材线虫病防控工作中存在的突出问题约谈了城厢区政府分管领导、区农业局主要领导，指出城厢区在松材线虫病防控工作中存在责任落实不到位、监测不到位、落实整改不到位、技术力量配备不足等问题，要求限期整改到位。

各地务必要举一反三，引以为戒，查找工作薄弱环节，贯彻落实省、市人民政府下达的松材线虫病等重大林业有害生物防控目标责任中关于“各级政府对松材线虫病等重大林业有害生物防控工作负总责”等有关要求，把松材线虫病等重大林业有害生物防控工作纳入对基层政府工作的绩效考评，按照省、市政府的总体部署，全面做好松材线虫病疫情防控工作。目前，防治工作进度缓慢的县（区）要抓紧推进，积极完成省下达的年度防治任务；存在突出问题的县（区）要及时制定整改方案，按规定要求，限期完成整改任务。
