莆田市林业局关于市八届人大五次会议第1087号建议的答复

发布时间：2025-05-21 16:56
| | |
政策解读:

郭雄新代表：

　　《关于推动油茶产业高质量发展，助力乡村振兴的建议》（第1087号）收悉，现答复如下。

　　一、调查研究，摸清油茶产业家底

　　截至2024年底，全市油茶林面积5.13万亩。按县区分，仙游县4.39万亩，涵江区0.44万亩,城厢区0.3万亩,主要分布在菜溪、游洋、社硎、书峰、萩芦、东海等乡镇；油茶品种有龙眼油茶和闽43、48、60等为主，现有油茶种植、加工单位100多家，其中仙游县90多家；全市年产油茶籽8195吨，较上年增长46吨。

　　二、争取资金支持油茶产业发展

　　2024年充分利用莆田市木兰溪全流域国土绿化试点示范项目资金，结合林地所有者意愿及林地实际情况，采取中央财政、省市财政配套、村民自筹等资金推动我市油茶产业发展，在中央财政项目补助基础上，省级财政配套补助油茶新造1000元/亩、改造350元/亩，有力推动我市油茶产业发展；在油茶种植、改造生产活动涉及林木采伐的，优先保障采伐指标，加快办理采伐审批手续。2024年已完成新造油茶3330亩、改造1300亩，并积极指导油茶业主加强油茶林垦复和抚育、施肥措施，提高丰产油茶面积。

　　三、开展部门协作，推进基础设施建设 

　　目前我市油茶的发展主要依赖林业部门，但油茶产业机械化发展涉及山、水、林、田、路、园林等多方面，2023年由林业、财政、发改等部门共同参与全市油茶产业发展规划，化解林业单一部门不能解决的事情；通过山林权流转、生产托管、入股分红、联耕联种等方式，培育油茶大户、油茶家庭林场、专业合作社、服务组织等新型经营主体，形成“公司+合作社+基地+农户”等专业合作组织和林农之间利益共享、风险共担的经营机制，推动油茶产业规模化、集约化、经营化发展。多方位扶持条件相对成熟、经营情况良好的中小企业、专业合作社、种植大户等经营主体创建规模化、专业化油茶产业标准化基地。

　　四、强化技术支撑，提高管理水平

　　结合林长制业务培训工作，邀请省、市技术专家来莆开展油茶高产栽培、高接换冠、芽苗嫁接及食用林产品追溯管理平台赋码技术等培训；组织油茶技术人员定期不定期下基层开展油茶栽培、修剪、机械化施肥、采果及加工技术等技术指导，不断提高油茶林的科学化管理水平,集中力量、集中资金进行低改、丰产栽培示范片建设，不断提高油茶丰产栽培水平。

　　五、加强校企合作，开展校地共建

　　我市与省林业科学研究院合作多年，开展仙游当家品种龙眼油茶的良种选育，认定龙眼茶母树林龙仙1-3号，持续培育油茶良种苗木400多万株，油茶种植面积和栽培技术水平有了较大提高，支持菜溪、社硎、游洋等油茶主产地与科研院校开展校地共建活动，对接油茶加工及系列产品开发，开展产品改良及生产示范基地，做好科技创新、品牌建设，推动油茶产业持续健康发展，实现油茶产业链的延伸，促进油茶产业效益跃升，才能真正实现油茶产业振兴。

　　六、完善基础设施建设，提高机械化水平

　　整合乡村振兴等资金，坚持开发与保护并举、生产与生态并重理念，集中力量、集中资金进行低改，通过品种改良、间作套种的方式，优化现有林相，按照机械化生产要求配套好机耕路、电网、灌溉、病虫防治、管理房等设施建设，改善交通、水利等基础条件，提高油茶机械化生产基地建设水平，特别是有规模的油茶基地按照机械化生产规划、推进，为油茶产业的机械化发展提供基础保障。

　　七、制定优惠政策，支持油茶产业发展

　　油茶是价位高、市场小、受益明显的特殊产业，在总结经验教训，不回避问题症结，扬长避短，利用木兰溪全流域国土绿化试点示范项目资金及林地落实，结合低效商品林地、茶果园、疏林地、采伐迹地、火烧迹地、森林防火隔离带、电力走廊林带、房前屋后“四旁”地等各类非耕地资源种植油茶。优先保障油茶种植、改造生产活动涉及林木采伐指标，加快办理采伐审批手续。通过政策引导鼓励企业加大投入，强化品种改良、间作套种的方式，优化现有林相，提高生产效益，实现产业可持续良性发展。

　　八、探索乡村旅游，推动产业观光融合

　　结合社硎草山樱花、菜溪风景名胜区、书峰兰石珍贵树种示范园等建设，联合文旅部门借鉴省内外油茶产业发展先进经验，探索“油茶生态+乡村旅游”产业发展模式，推进油茶种植、农产品加工、生态农业发展项目与乡村旅游等项目融合，鼓励菜溪、社硎、游洋、萩芦等地利用油茶花果同树景观开展油茶园区景区化，打造“油茶产业园区化、园区景区化、农旅一体化”基地，组织游客在油茶成熟期参与采果、茶籽、茶油制作等工序发展油茶采购游，如鼓励菜溪乡开展油茶示范片建设与菜溪岩风景名胜区观光相结合，发展油茶观光小镇；鼓励油茶示范片与樱花观赏相结合，推出油茶-樱花节，让游客现场体验油茶采摘游、烹油茶美食等农家体验项目，充分让游客亲身体验油茶采摘及系列生产乐趣，亲身体会油茶的优良品质，体验油茶文化，让油茶走向大众。

　　九、培育行业龙头，做强油茶品牌

　　鼓励支持仙游菜溪浔阳油茶专业合作社、福建大自然生物有限公司等油茶产业精深加工企业积极申报省、市级农业产业化龙头企业，打造地方特色品牌，培植一批自主创新能力强、年销售收入大、行业领军的骨干龙头企业，推动农业产业化龙头企业的数量增长和质量提升；鼓励动员种植大户与有意参与油茶生产、经验丰富的农产品加工企业来莆田联合发展专业合作社，开展油茶规模化、标准化、机械化建设，促进油茶生产主体单打独斗向联合经营升级、抱团发展、品牌推介，提高抵抗市场风险能力。

　　发展油茶产业，是一项系统工程，需要各级政府、各部门和全社会共同努力。结合落实耕地非农化、非粮化及国土绿化试点示范项目林地，按照中央、省、市有关工作部署，切实履行部门职责，把油茶产业发展有效衔接脱贫攻坚与乡村振兴，做到油茶种得活、加工好、销售广、卖得好，真正成为林业绿色富民产业抓手，努力为乡村振兴建设服务。

　　感谢你对我市油茶产业发展的关心和支持，以上答复如有不妥之处，敬请批评指正！
