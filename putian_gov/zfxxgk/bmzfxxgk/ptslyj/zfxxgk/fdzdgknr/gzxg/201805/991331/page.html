莆田市林业局关于开展林业安全生产大检查情况的通报

发布时间：2018-05-28 08:23
| | |
政策解读:

各县（区管委会）林业系统、局各直属单位：

          为贯彻落实市委办、市府办《关于迅即组织开展安全生产“严排查、严整治、严监管”活动的通知》（莆委办发电〔2018〕34号）和《莆田市林业局安全生产办公室关于切实加强全市林业安全生产工作的通知》（莆林安办〔2018〕17号）文件精神,以及5月7日市林业局召开林业安全生产工作专题会议对安全工作部署的要求，各林业主管部门认真组织涉林企事业开展安全生产隐患大清查，在各企业、单位自查的基础上，市林业局对两个国有林场安全生产工作开展情况进行了督查，现将情况通报如下：

          一、督查工作开展情况

          5月10日至11日，市林业局副局长、安办主任刘清林率吕福如、翁金珊、陈明富等人组成林业安全生产检查督查小组，分别对涵江云龙、仙游溪口国有林场等责任单位开展林业安全生产工作进行督查。督查工作采取现场抽查、听取汇报、查阅资料和召开座谈会、反馈交流等程序。从督查情况看，被督查单位都能够认真按照文件精神和会议要求，及时部署并开展林业安全生产工作，加强组织领导，强化安全管理，扎实开展安全生产“严排查、严整治、严监管”活动，及时排查整改各类安全隐患，确保我市林业生产安全。

         二、自查和督查中发现的安全隐患和管理问题

从自查上报的安全生产问题隐患清单看，发现一般安全隐患问题7条，立即整改的7条；市林业局督查2个直属单位，发现一般安全隐患5条，限期整改5条。分类如下：

       （一）报送材料不及时或不报送

        市林业局要求5月8日前报送安全生产隐患清单，只有仙游、秀屿、湄洲和溪口林场等单位上报；有的单位安全工作管辖范围无法准确把握，有的单位对企业的督促检查力度不够大，隐患排查治理机制还不健全。

      （二）两个国有林场督查情况

       1.溪口林场：一是发现场部管理区五一点房屋配电盒无盒盖，电线接头裸露在外，食堂布线不规范；二是森林防火器材放置凌乱，没有上架；三是复查在第一季度对该林场安全检查中发现存在的安全稳患，已及时整改到位。

       整改要求：对第一个隐患，要规范重新布置电线路及更换配电盒；对第二个存在问题，防火储备库内器材要上架放置，排放整齐。以上存在隐患和问题，在一个月内整改完成。

       2.云龙林场：一是可山工区管理房老旧，存在安全隐患；二是洋尾工区管理房年久失修，已封闭管理，但未设置安全警示牌；三是森林防火物资设备老化，部分品种和数量不足。

      整改要求：对第一个隐患，在遇有暴雨，台风等极端灾害天气时，居住人员必须全部撤离；对第二个隐患，立即设置安全告示牌，禁止人员进入；对第三个存在问题，要按储备库建设标准更新补充先进森林防火物资设备，于2018年9月前整改到位。

       三、下一步工作要求

       1.此次活动至9月30日结束，活动采取企事业全面自查、地方各级政府和有关部门、单位全面检查，市、县区林业主管部门按分管行业（领域）抽查、督查的方式进行。着力抓好林木采伐、森林公园、自然保护区、森林防火等部位的安全监督管理工作。对本通报督查发现的隐患和管理问题，各相关单位对隐患要按要求整改。

       2.切实提高对安全生产工作重要性的认识，正确认识安全生产形势的严峻性、复杂性、长期性和反复性。始终坚持以人为本、安全发展的科学理念，进一步增强做好安全生产工作的责任感和紧迫感，真正解决安全责任、防范措施、安全监管、治理整改不到位等问题，切实把安全生产这一重要的民生工作摆在更加突出的位置抓紧抓好，促进全市林业安全生产形势的持续稳定。

      3.夏季高温和台风暴雨多发季节正当来临，也是各类生产安全事故的易发多发期，各地各单位要结合实际，督促检查指导各类生产经营单位，全面检查防雷电、防汛、防台风、防高温等方面的措施落实情况。加强对重大危险源、易燃易爆、危化物品和在用车辆的监控和管理，严防各类生产安全事故发生。进一步建立完善安全生产应急救援预案，强化应急演练，提高事故救援能力和群众自救互救能力。加强安全生产值班值守和领导带班，畅通安全生产信息渠道，严格报告制度。加强对重点单位和部位的安全检查监控，做好事故防范和应急救援等各项工作。

                                                             莆田市林业局安办

                                                              2018年5月18日
