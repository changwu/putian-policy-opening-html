莆田市林业局关于开展2019年度随机抽查事项市级监督检查工作的通知

发布时间：2019-07-04 17:31
| | |
政策解读:

各县（区、管委会）林业主管部门，局各有关部门： 

　　 按照省林业局、市政府有关工作部署要求，决定开展2019年度随机抽查事项市级监督检查工作，现将《莆田市林业局2019年度随机抽查事项市级监督检查工作方案》印发给你们，请按要求认真组织实施。 

　　  

　　  

　　                                                             莆田市林业局 

　　                                                             2019年6月28日 

　　                                莆田市林业局2019年度随机抽查事项市级监督检查工作方案 

　　  

　　为深入推进林业简政放权放管结合优化服务改革，规范检查行为，提升监管效能，促进生态文明建设和林业经济社会持续健康发展，根据有关法律法规规章规定和国务院、省政府、市政府等部署要求，结合我市林业实际，特制定本方案。 

　　一、目标要求 

　　深入贯彻国务院、省政府、市政府部署要求，以深化林业“放管服”改革为引领，以构建新型林业监管体系为目标，转变行政监督检查方式，推进公正执法，提升监管效能，激发市场活力，强化市场主体的自觉、自律和社会监督，切实解决当前一些领域存在的执法扰民、执法不公、执法不严等群众反映强烈的突出问题，营造公平高效的执法环境。 

　　二、主要任务 

　 （一）制定2019年度市级林业随机抽查事项清单。以法律法规规章为依据，对适用随机抽查方式的市级林业行政监督检查事项，原则上都要列入市级林业随机抽查事项清单。按照“谁审批谁监管”、“谁主管谁监管”的原则，由有关职能机构提出随机抽查事项，经牵头组织机构复核汇总后，报局领导审定。林业随机抽查事项应当列入本级林业权责清单，与本级林业权责清单衔接，并实行动态调整。随机抽查事项应明确事项名称、法定依据、检查主体、检查层级、检查对象、检查内容、检查方法等内容。 

　　（二）建立市级林业随机抽查检查对象名录库。按照随机抽查事项清单逐项建立，具体检查对象及其有关信息由相应的职能机构提供并根据变动情况及时调整，由牵头组织机构统一建立，实行动态管理。检查对象包括林业企业等市场主体、林业行政许可的相对人或从事林业生产经营管理的单位和个人。检查对象信息一般包括检查对象名称、社会信用代码（组织机构代码）、法定代表人、所在区域、通讯地址、检查对象类别、随机抽查事项名称、检查层级等内容。 

　　（三）建立市级林业随机抽查执法检查人员名录库。执法检查人员名录库按照随机抽查事项逐项建立，实行分级管理。建立检查人员综合库和检查人员专业库，原则上市级持有林业行政执法证件执法人员都要列入市级检查人员综合库，检查人员专业库由各有关职能机构按照专业需要逐项或分类建立，执法检查人员不足的，可以要求县（区、管委会）林业主管部门选派，需要调整的，由原选送单位负责提出递补人员并说明理由。执法检查人员应当具备良好的思想政治素质、业务工作能力、职业道德水准，并持有林业行政执法证件。 

　　（四）建立健全双随机抽查机制。检查对象和执法检查人员应当从相应名录库中随机抽取确定。检查对象每年抽取数不低于名录库中检查对象总数的5%，执法检查人员按事项清单优先从专业库中抽取，至少两人一组。被随机抽取的执法检查人员确有其他重要公务无法参加的，按抽取先后顺序依次进行递补。同组执法检查人员共同承担抽查监管责任，共同履行抽查工作职责。检查人员与检查对象有利害关系的，应依法回避。随机抽查频次原则上每年不少于2次，可以一次性全部抽取检查或分类多次抽取检查，各地根据实际情况进行选择。为了提高检查工作效率，可以采用以县（市、区）或者乡镇（街道）为区域，按区域随机抽取检查对象的方式，被抽中区域即该区域内的全部检查对象相应列入检查范围。 

　　（五）规范开展随机抽查。执法检查人员开展检查工作时应当出示执法证件、说明检查事项、告知权利义务，做到程序合法、文明检查，同时要做好记录和留取相关证据。实施检查要严格按照随机抽查事项清单及其所列的检查内容，重点检查近1年以来发生的行为。对检查中发现或者通过其他途径获得违法线索的，应当延伸检查或者扩大检查范围。县级以上林业主管部门在6个月内已对检查对象实施检查的，原则上不再重复检查，对其检查成果进行审查后可以引用。检查过程中发现应当依法给予行政责令、行政处罚、行政强制的，应当及时移交当地林业主管部门统一处理；涉嫌犯罪的按有关规定处理。 

　　（六）加强抽查结果运用。建立“一抽查一通报制度”，对抽查发现的违法违规行为，要依法依规加大惩处力度，形成有效震慑，增强市场主体遵纪守法的自觉性。抽查情况及查处结果要及时向社会公布，主动接受社会群众监督。对于检查对象涉嫌违法犯罪的，应当由接收案件的部门和单位，按照行政案件或者刑事案件有关规定进行信息公开。 

　　（七）充分运用市场监管信息平台，推进随机抽查与社会信用体系相衔接。将随机抽查结果及时报送国家企业信用信息公示系统平台，纳入市场主体的公共信用信息记录；要加强与市直相关部门的沟通协调，建立健全市场主体的诚信档案、失信联合惩戒、黑名单和整改回访，并根据市场主体的信用情况，采取相应监督检查方式。 

　　 三、有关要求 

　　（一）加强组织领导。全市各级林业部门要加强对本级随机抽查事项的组织领导和统筹协调，大力推广应用随机抽查机制，严格规范事中事后监管，切实增强责任意识，履行相关监管责任，对于失职渎职行为，依法依规严肃处理。 

　　（二）加大培训宣传。各级各单位要加大随机抽查的政策宣传工作力度，切实转变执法理念，加强对随机抽查的指导和监督，充实执法检查力量，加强执法人员培训，不断提高执法能力。 

　　（三）制定抽查方案。各县区（管委会）林业主管部门要结合自身实际，制定切实可行的工作方案。要坚持依法监管，推进随机抽查制度化、规范化建设；坚持公正高效，推进行政权力规范运行，做到严格规范和公正文明执法；坚持公开透明，推进随机抽查事项公开、程序公开、结果公开，做到“阳光透明执法”。
