关于市八届人大六次会议第1372号建议的答复

发布时间：2026-04-29 11:51
| | |
政策解读:

郑望代表：

　　《关于促进莆田森林旅游高质量发展的建议》（第1372号）由我单位会同市文化和旅游局办理。现将有关情况汇总答复如下：

　　一、基本情况

　　莆田市共有林地面积307.65万亩，森林覆盖率45.1%；森林景区方面，拥有九鲤湖风景区、九龙谷森林公园等自然保护地19个，总面积72.43万亩，其中：森林公园11个、风景名胜区4个、自然保护区3个、海洋公园1个；按县区分：仙游县自然保护地5个（自然保护区1个、风景名胜区2个、森林公园2个），总面积39.2万亩;涵江区自然保护地7个（自然保护区1个、森林公园6个），总面积10.1万亩；城厢区自然保护地3个（风景名胜区1个、森林公园2个），总面积3.6万亩；荔城区自然保护地1个（森林公园），总面积1.7万亩；秀屿区自然保护地1个（自然保护区），总面积0.03万亩；湄洲岛自然保护地2个（风景名胜区1个、海洋公园1个），总面积17.8万亩。公园体系方面，建成绶溪公园、泗华郊野公园、客山妈祖公园等重点公园，配套打造玉湖公园、土海湿地公园、木兰陂公园、天马山公园等特色公园，实现森林景观与城市休闲、湿地保护有机融合，为市民游客提供多元化生态休闲空间。

　　二、十四五期间森林旅游主要工作

　　（一）加强保护，严守生态红线。严格按照国家、省有关生态保护红线的规定，切实强化生态保护红线底线约束，严守自然生态安全边界，统筹好保护与发展关系，按照国家三部门关于有限人为活动准入清单要求，除了清单内允许的项目外，其他建设项目必须避让生态保护红线，高质量推进森林旅游建设。

　　（二）结合项目，提升基础设施。一是推进“百园千道”建设。我市依托森林公园丰富的景观资源和现有的森林步道系统，优化公园森林景观，利用已有的林道、护林防火道和生产性道路，修建满足不同人群需求的森林步道，十四五”期间共改善提升森林公园3处，新建、改造森林步道32公里。二是依托凤凰福道连接城区森林景区。核心项目莆阳福道全线贯通并优化延伸至53公里，北连东圳水库、南接木兰陂，串联九龙山、凤凰山、绶溪公园、泗华郊野公园等众多森林、公园节点，成为城市生态脊梁和休闲核心廊道，通过对现有的东圳绿道、凤凰山沿渠景观带进行综合提升改造，并在主道建设架空栈桥连接现有绿道及周边山体，形成俯瞰城区的效果。三是改造提升道路设施。城厢区对通往九龙谷森林公园的主要道路进行改造提升，由水泥路改造为沥青路，改造总里程3.7公里;步道及服务设施方面，在莆阳福道等重点步道沿线，选用透水混凝土等环保建材，高标准建设智慧厕所、休憩驿站、补给点，配备智慧路灯、无线充电座椅等便民设施；同步完善无障碍通道、应急救援站、母婴室等设施，建立健全应急处置机制，全面提升森林旅游接待承载能力和安全保障水平。四是聚焦配套设施。聚焦游客出行便捷性与舒适性，持续推进配套设施提质增效。停车设施方面，莆阳福道植物园一期工程配套建设停车场2处，泗华郊野公园新增生态停车场车位330个，客山妈祖公园福道周边配套完善停车设施，同步优化九龙谷国家森林公园、瑞云山森林公园停车场布局，引入智能停车系统，有效缓解停车难题。

　　（三）创建品牌，助力森林旅游。一是A级旅游景区。全市自然保护地中共有5个创建了4A级以上景区，其中：5A景区1个、4A景区4个。二是省级森林康养基地。九鲤湖风景名胜区获评为省级森林康养基地，为我市首家经省林业局认定的康养基地。三是自然教育基地。九鲤湖风景名胜区获评全省首批省级自然教育基地，仙水洋景区获评全省第二批省级自然教育场所。四是森林人家。全市共有森林人家8家。五是森林乡村、森林城镇。全市16个村被评为“国家森林乡村”，70个村被评为“省级森林村庄”，5个乡镇被评为“省级森林城镇”。

　　（四）植树造林，提升森林景观。一是景观改造提升。对现有的森林资源有针对性地开展森林抚育、林相改造和景观提升，营造、补植当地适生的珍贵树种、景观树种和花卉植物，打造生态优良、林相优美、景致宜人的森林旅游环境，“十四五”期间共营造红锥、闽楠、木荷等乡土树种、珍贵树种4.3万亩。二是保护古树名木。强化对古树名木的保护和利用，提升森林景观质量，突出森林景观特色，全市目前共有古树名木2739株，“十四五”期间共通过病虫害防治、施肥、枯枝修剪、开挖复壮沟、围栏和排水设施等技术手段，抢救复壮古树8株。

　　（五）注重细节，聚焦服务品质。在莆阳福道、绶溪公园、九龙谷森林公园等重点节点，常态化推出莆田“礼遇”志愿服务，精准提供行李寄存、旅游咨询、便民雨伞、应急药品等暖心服务，切实提升游客出行体验。针对亲子家庭、老年群体等不同群体的差异化需求，专门推出专属导游服务与舒适化行程定制服务，配套建设儿童玩乐区等设施，兼顾服务的便捷性与舒适性,进一步丰富森林旅游服务场景，推动服务品质持续升级。

　　三、森林旅游下一步发展方向

　　下一步，我市森林旅游工作将按照贵代表的建议继续推动森林旅游从规模扩张向质量提升转变，持续巩固现有工作成效，进一步聚焦森林旅游高质量发展重点任务，补齐短板、强化弱项，深化文旅融合，不断提升森林旅游品质和影响力实现生态保护、经济发展与民生改善的多赢。

　　（一）继续加强保护。将生态保护放在首位。一是严守生态红线。继续按照国家三部门关于保护生态红线的要求，加强对森林资源的保护，限制不合理的开发行为，确保森林资源的可持续利用，严格遵守有限人为活动准入清单，规范管控对生态功能不造成破坏的有限人为活动，统筹好保护与发展关系。二是争取升级木兰溪源自然保护区。争取将木兰溪源自然保护区从省级升级为国家级，保护木兰溪源头的森林生态系统、野生动植物栖息地及自然景观。三是加强对野生动植物的保护，禁止非法捕猎和采集，维护生物多样性.四是加强对旅游活动的监管，引导游客文明旅游，保护生态环境。

　　（二）加强安全工作。进一步完善应急预案，加强安全演练，

　　提高应对森林火灾和其他自然灾害的能力。一是制定详细的应急预案，明确各个部门的职责；二是定期组织应急演练，提高应急队伍的实战能力；三是加强对森林火灾的预防，加强火源管理，提高火灾应急处置能力；四是加强对森林景区的安全隐患排查，确保游客的人身安全。

　　（三）提升基础设施。优先选择靠近城镇周边、交通便利、通达性较好，尤其是已具备一定旅游基础景区的基础设施进行改造提升。一是建设森林步道。江口镇大东村2026年争取到省级资金30万元用于建设3公里森林步道。二是改善森林康养基础设施。九鲤湖省级森林康养基地计划推进新迎宾路、拦河坝等改造项目，建设九鲤湖生态保护展览馆，对破旧步游道、电瓶车道进行全面提升改造，增设缘梦湖、第二步游道安全护栏，优化景区导览、语音讲解等系统。三是促进品牌创建。仙游县全力推进仙水洋景区创建国家4A级旅游景区，

　　感谢您对林业工作的关心和支持。
