莆田市林业局关于下达2013年度松材线虫病防控目标责任的通知

发布时间：2013-09-13 08:00
| | |
政策解读:

　　莆田市林业局关于下达2013年度松材线虫病防控目标责任的通知

　　各县（区）林业局、湄洲岛农林水局、湄洲湾北岸农办：

　　根据《福建省林业厅关于下达2013年度松材线虫病防控目标责任的通知》(闽林防〔2013〕10号) 和《莆田市人民政府关于下达2011-2013年松材线虫病防控责任书的通知》（莆政综〔2011〕224号）的通知精神，结合各地年度防控实施方案（预案），现将2013年松材线虫病防控目标责任下达给你们，请认真抓好落实。

　　一、防控目标

　　（一）全面加强疫情监测，确保第一时间发现新疫情；一旦发现新疫情，要第一时间控制和消灭疫情。

　　（二）全面及时完成松枯死木清理任务，做到“发现一株，清理一株，除害一株”，清除率达100%。

　　二、防控责任

　　（一）将防控工作纳入单位年度目标责任制，全力抓好防控工作。

　　（二）建立完善松材线虫病等林业有害生物监测、防治、检疫日常工作制度和检查考核制度。落实监测责任，认真组织开展春、秋季普查和季度枯死木调查；准确掌握疫情发生和枯死木分布情况，按规定时限上报监测结果和有关疫情防控信息。

　　（三）制定本级年度防控实施预案，并按预案要求抓好落实。

　　（四）开展科学防控，将疫情防控与营造林项目相结合，鼓励营造非松树种和阔叶树；严格按要求做好松枯死木清理（包括伐桩及枝桠的处理）；加强媒介昆虫松墨天牛的综合防治，确保方案各项措施落实到位。同时，加强督查指导，发现问题及时通报并督促整改，保证除治进度和质量。

　　（五）加强植物检疫工作。加强松枯死木管理，完善各项规章制度，加强产地检疫、调运检疫和检疫执法工作，防止疫情入侵扩散。

　　（六）加强松材线虫病防控宣传和技术培训，提高防控能力；积极争取政府对防控经费的支持，增加防控投入，确保防控需要。

　　（七）完善内业档案材料。做好2011-2013年防控目标责任期间内业档案材料的汇总整理和归档工作。

　　三、监督检查与考核

　　各地要按时部署辖区内防控目标责任制自查，并做好考核检查工作。市林业局将对各地目标责任完成情况进行跟踪督查，并于2013年秋季普查前对各单位目标责任完成情况进行考核。对防控工作取得显著成绩的，给予通报表扬；对责任不落实，没有完成防控目标任务的，给予通报。

　　莆田市林业局         

　　2013年9月13日       

　　莆田市林业局办公室                      2013年9月13日印发
