莆田市林业局关于印发《2013年林业工作要点》的通知

发布时间：2013-02-28 08:00
| | |
政策解读:

　　莆林综〔2013〕11号

　　莆田市林业局关于

　　印发《2013年林业工作要点》的通知

　　 

　　各县区林业局、湄洲岛农林水局、北岸农办、局各部门、各直属单位：

　　现将《2013年林业工作要点》印发给你们，请结合实际，认真贯彻落实。

　　莆田市林业局

　　2013年2月18日

　　2013年林业工作要点

　　一、工作思路

　　2013年，全市林业工作要按照党的十八大精神，紧紧围绕 “跨越发展、宜居港城”的总体目标和建设“五个莆田”的具体要求，高举生态林业和民生林业这两面大旗，以创建 “国家森林城市”为抓手，持续开展绿色行动，巩固提升“创模”成果，全面推进绿色发展，努力建设生态莆田、森林莆田，让人民群众享受更多的绿色成果，为建设“美丽莆田、幸福家园”作出新的贡献。

　　二、主要目标

　　全市造林绿化任务15. 5万亩，其中“四绿”工程2.9万亩，林分补植修复10万亩，人工造林更新（含生物防火林带建设和珍贵用材树种造林）2.6万亩；积极创建“国家森林城市”；全市森林覆盖率达59.4%，森林蓄积量达853.32万立方米；实现林业总产值230亿元，增加值25亿元，年增长率12%，其中木材浆纸产业产值105亿元，年增长率15%；森林火灾受害率控制在1‰以下，林业有害生物成灾率控制在3‰以下。

　　三、工作重点

　　（一）更加注重改革创新

　　1.争创国家森林城市。成立“创森”工作机构，编制《莆田市森林城市建设总体规划》，制定“创森”工作实施方案，大力开展“创森”活动宣传，动员全社会支持、参与创建工作。按照“保护壶山兰水景观，突出荔林水乡特色，建设生态环保家园，打造滨海宜居城市”的总体要求，突出重点，推进城市片林、环城林带、森林公园、经济开发区绿化工程、幸福家园试点村庄绿化等建设，打造结构合理、生态安全、功能完备、特色明显、景观优美的城市生态网络体系。

　　2.深化林权配套改革。继续做好林改“回头看”，努力完成林权发证扫尾工作，确保林权证发放到位；进一步完善林权流转平台建设，扶持和规范林业专业合作社等合作经济组织发展，促进林权依法、规范流转，实现林业集约经营、规模经营；深化林业投融资改革，创新金融产品，加大林权抵押贷款和小额贴息贷款力度，巩固森林综合保险覆盖面，充分发挥林权证作用，缓解林农生产发展资金不足，降低经营风险；大力发展林下经济，提高林地综合利用水平，最大限度实现农民增收，林业增效。

　　3.推进国有林场改革。通过推进国有林场改革，逐步理顺国有林场管理体制，创新经营机制，规范运行管理，妥善解决历史遗留问题，稳步提高职工收入，使森林资源得到有效保护和发展，林场生态和社会功能明显增强。

　　（二）更加注重森林培育

　　1.落实“四绿”工程。绿色城市着重抓好城市片林、城市森林公园和南北洋水系两岸荔枝林带，加大城市道路林带宽度和绿化、美化、彩化力度，加强社区（住宅区）绿化、开发区（工业园区）绿化，积极创建“国家森林城市”；绿色村镇侧重抓好幸福家园试点绿化，村镇公园（片林）建设、近村坡耕地造林、零星“四旁”植树，加强城乡接合部森林生态景观建设，积极创建“绿色乡镇”、“绿色村庄”；绿色通道注重抓好福厦高铁、向莆铁路和莆秀、莆永高速公路及交通主干道两侧绿化与提升；绿色屏障重点抓好沿路、沿溪（库）、沿海、环城一重山的造林绿化和4500亩沿海防护林基干林带造林。

　　2.实施生态修复工程。重点抓好郁闭度0.2—0.4的稀疏林地及重点水土流失区的林分修复补植、荒芜经济林补植套种、人工针叶纯林改造和1800亩稀疏林地速生大苗造林补植。

　　3.推进森林经营工程。加大未成林地管护和中幼林抚育力度，完成中幼林抚育6万亩。继续抓好沈海高速公路森林生态景观通道建设的管护抚育。继续将封山育林作为保护生物多样性、治理水土流失、提高森林质量的重要措施，完成封山育林6万亩。要持续推进不炼山、不全垦造林，择伐面积占林木主伐面积的30%以上。切实抓好2600亩生物防火林带建设，构建林火阻隔网络。完成4000亩珍贵用材树种造林，加快木材战略储备基地建设。

　　4.开展义务植树活动。全市义务植树法定人数160万工日，全民义务植树630万株，新建义务植树点7个，面积3000亩，加强生态文明宣传，广泛开展城市绿地认建、认养、认管等多种形式的社会参与绿化活动，建立义务植树登记卡和跟踪制度，全民义务植树尽责率达95%。

　　（三）更加注重生态保护

　　1.强化资源管理。做好国家第八次森林资源清查工作。国家第八次森林资源清查工作关系到我省森林资源“双增”考核指标能否达标，也关系到我省第九次党代会提出“森林覆盖率保持国家首位”目标的实现。要按照省政府的统一部署，加强领导，加大投入，强化措施，高质量、高标准开展清查工作，全市在9月份前完成样地外业调查，年底前全面完成清查材料上报。同时，认真做好森林资源动态监测和数据更新工作，严格森林资源增长考核。加强生物多样性保护。进一步加大生态公益林、自然保护区和古树名木的管护力度，做好古树名木普查试点工作，加快树种结构调整，维护生物多样性。

　　2.强化依法行政。充分发挥林政、公安、执法等队伍的作用，加大检查执法力度，健全完善上下联动机制，持续开展专项打击行动。加大对重点林区、“三沿一环”的巡查和查处力度，特别是对城市周边和沿海防护林征占用林地情况进行全面检查，有效查办一批大案要案，坚决遏制各种破坏森林资源违法犯罪行为。

　　3.强化防控建设。认真落实森林防火行政首长责任制，加强森林火灾防灾减灾体系建设，做好森林防火物资贮备库建设，加强生物防火林带建设，提升整体防控水平；加强林业有害生物监测、防治、联合检疫执法，加强松材线虫病疫情防控体系建设，抓好松材线虫病的防控工作，确保防控目标责任制落实；坚持预防为主、综合治理的原则，做好信访处置工作，努力解决林区人民群众合理诉求。加强安全生产监管，加大涉林纠纷调处力度，切实化解一批山林矛盾纠纷，努力营造和谐稳定林区。

　　（四）更加注重产业扩张

　　1.做大第二产业。加大帮扶服务力度。积极推进莆头木材集散基地和秀屿木材加工区开发建设，采取扶优扶强的原则，引导重点企业进一步发挥产能，发挥龙头带动作用。发展特色产业。建设以仙游榜头坝下工艺一条街和宝泉工艺产业园为主体的仙游古典工艺家具木材精深加工区，以荔城区黄石镇为主体的木材雕刻精深加工区，以秀屿国家级木材贸易加工示范区为主体的木材贸易加工区，以北岸林浆纸一体化为主体的东南沿海最大浆纸基地，以涵江、城厢木制文化艺术镜框产品为主体的木制工艺美术基地。

　　2.做活森林旅游业。以森林公园、森林人家为载体，发展壮大以北部山区为主体的深度生态休闲旅游业。重点加强瑞云山省级森林公园、九龙谷国家森林公园和大洋笛韵森林人家基础设施和景观改造，积极培育九龙谷国家森林公园和大洋笛韵森林人家等省级森林旅游重点线路，广泛开展森林文化及生态文明教育。

　　3.做好花卉苗木产业。认真落实《福建省人民政府关于扶持花卉苗木产业发展的意见》（闽政[2012]37号）精神，加快规划建设本地大型的花卉苗木基地，推进10大花卉苗木基地建设，推动我市花卉苗木产业尽早形成专业市场。推进国有林场重点项目建设，重点实施溪口国有林场《国家重点马尾松良种繁育基地建设项目》。

　　（五）更加注重服务大局

　　1.主动作为。主动履行职责，敢抓敢管，勇于担当“美丽莆田、幸福家园”建设的主力军，充分发挥绿化委员会作为综合协调部门的作用，在做好规划指导、种苗供应、技术服务等本职工作的同时，主动参谋、积极服务，加强对城乡绿化工作的指导。

　　2.高效履职。把服务全市经济发展作为林业工作的出发点，不断提高服务水平和服务质量，做到超前服务，现场服务，积极向省厅争取林地指标，保障省市重点项目使用林地的需要。对重点建设工程，超常规对待，确定专人服务，提升林业保障经济发展的水平。

　　3.服务大局。围绕全市农村工作“实施555610工程，统筹城乡兴三农”的工作思路，加快构筑林业防灾减灾体系建设，加大花卉苗木基地和森林生态休闲旅游基地建设，大力发展绿色经济，促进林农增收。积极融入城乡一体化综合配套改革试验，加强生态屏障建设，加大对木兰溪、萩芦溪源头等自然保护区的建设力度，推进“绿色家园”建设，为我市加快建设更加优美更加和谐更加幸福的新型城乡做出新的贡献。

　　（六）更加注重队伍建设

　　1.加强学习教育。深入学习贯彻党的十八大精神。把学习宣传贯彻十八大精神作为首要政治任务来抓，用十八大精神统领林业工作全局，结合主题活动，推动林业改革与发展，全面提升生态林业和民生林业发展水平。加强业务理论学习。围绕提升林业应对气候变化能力、加强林业资源保护管理、加强森林资源培育、确保“双增”目标实现、发挥森林的生态功能等方面加强学习，撰写理论文章，为发展现代林业，推动绿色发展提供决策依据。今年，全局干部每人要读一本书，写一篇心得，讲一堂课，撰一篇指导工作的文章，局领导要带头执行。

　　2.加强机关建设。在制度建设上，对机关财务管理制度、车辆使用及管理制度、机关干部管理、责任追究制度以及节假日值班等制度进一步完善。在作风建设上，继续弘扬 “创新、实干、奉献”的林业行业精神，提高履职意识，服务发展大局。扎实开展“下基层”活动，深入基层、深入研究，推动工作落实。在干部培养上，加强后备干部培养，加强干部岗位交流，为全面提升干部工作能力提供必要平台。

　　3.加强组织建设。加强党的组织建设和工会、共青团、妇委会、林学会工作，做好局党支部及工会、妇委会等进行换届工作，吸收干部加入党组织。开展“创先争优”、创建“先进党支部”等活动，努力建设政治强、业务精、作风正的林业队伍，充分发挥先进引领、团队带领作用，促进各项工作更好地开展。

4. 加强党风廉政和惩防体系建设。全面落实党风廉政建设责任制，做到与业务工作同研究、同部署、同考评。坚持标本兼治、综合治理、惩防并举、注重预防的方针，推进惩治和预防腐败体系建设，加强党员干部教育和监督，强化各种制度落实，进一步拓展从源头上防治腐败的领域。
