关于印发莆田市林业局开展廉政风险防控工作实施方案的通知

发布时间：2012-05-09 08:00
| | |
政策解读:

　　 莆林综[2012]37号

　　局各部门、各直属单位：

　　加强廉政风险防控，是构建惩治和预防腐败体系的重 要举措，是规范权力运行的客观要求，是推进预防腐败工作的有力抓手。今年，市纪委已把开展廉政风险防控工作作为十项重点工作之一，为切实提高本单位全体干部思想认识，增强工作责任感、紧迫感，促进干部廉洁自律、保护干部健康成长，建立起查找风险在前、教育提醒在前、建章立制在前、监督约束在前的防控机制。现提出如下实施方案：

　　一、目标要求

　　按照“全面清权查险、全程跟踪监督、全力化解风险、重点选题防控”的思路，全面推进廉政风险防控机制建设。围绕“人、财、物、权”等关键环节和重点岗位，将重大事项决策、重要干部任免、重大项目安排、大额度资金使用（简称“三重一大”）作为监管重点，通过查找岗位廉政风险点，评估岗位风险等级，制定有效防控措施，完善管理制度和工作流程图，做到“风险定到岗，制度建到岗，责任落到岗”，确保不漏岗、不漏责、不漏人，形成以工作岗位为点、工作流程为线、监管制度为面，环环相扣的廉政风险防控体系。

　　二、实施范围

　　廉政风险防控工作的实施范围包括局领导班子、各科室、各直属单位所有岗位。市森林公安局、三个国有林场方案制定后上报市局办公室。

　　三、组织领导

　　为确保工作开展，成立莆田市林业局廉政风险防控工作领导小组。

　　四、实施步骤

　　按照计划、执行、考核、修正的PDCA循环管理机制，对预防腐败工作实施科学管理。

　　（一）计划阶段（5月起）

　　局已成立了廉政风险防控工作领导小组及其办公室，指定专人负责此项工作。市森林公安局、三个国有林场也要成立相应的领导小组，制定工作方案，上报市局办公室。各单位要召开动员大会，全面部署开展廉政风险防控工作各项任务，使广大党员干部思想上进一步确立“风险无处不在，防控人人有责”的风险意识。

　　（二）执行阶段

　　1、风险排查。紧紧围绕本岗位的职责，采取自下而上查找和逐级审核的方式，从思想道德、岗位职责、工作流程、规章制度等方面逐一排查，筛选廉政风险点，评估风险等级。

　　查找风险点：按照“对照岗位职责——梳理岗位职权——找准廉政风险——公示接受建议”的步骤，全面排查岗位廉政风险点。廉政风险具体可分为思想道德风险、岗位职责风险、业务流程风险、制度机制风险、外部环境风险五种类型。

　　思想道德风险：指因私欲、私利等自身思想道德偏误或因亲情请托等情节，可能造成个人行为规范或职业操守发生偏移，行政管理行为失控，或授意他人违反职业操守，导致行政行为结果不公正不公平，行政行为对象利益受损或不当得益，构成“以权谋私”等严重后果的廉政风险。

　　岗位职责风险：指由于岗位职责的特殊性及存在思想道德、外部环境和制度机制等方面的实际风险，可能造成在岗人员不正确履行行政职责或不作为，构成失职渎职、“以权谋私”等严重后果的廉政风险。

　　业务流程风险：业务流程各环节缺乏有效的相互制约、制衡的监督内控机制，造成管理者易发生腐败行为的风险。

　　制度机制风险：指由于缺乏工作制度的明确覆盖，工作程序的明确规定，工作时限、标准、质量的明确约定，个人自由裁量空间较大，缺乏有效制衡和监督制约，可能造成行使权利失控，行政行为失范，构成滥用职权、“以权谋私”等严重后果的廉政风险。

　　外部环境风险：指为了达到行政结果有利于自身利益的目的，行政管理对象可能对相关行政人员进行利益诱惑或施加其他非正常影响，导致行政人员行为失范，构成失职渎职或“权钱交易”等严重后果的廉政风险。

　　各单位及个人要采取自查、互查、帮查等方法，客观真实地排查个人岗位的廉政风险点，填写《单位廉政风险自查表》、《岗位廉政风险排查表》，提出防控工作措施，并公开公示接受群众监督。

　　评估风险等级：根据不同岗位权力的大小、腐败现象的发生机率和对社会危害程度的高低等，对各个岗位进行风险评估，确定风险等级。廉政风险点分为三个等级：

　　（1）一级风险是指对于潜在廉政风险大、发生问题危害严重，涉及“三重一大”的事项、涉及人财物等权力较大、较灵活，有自由裁量权的岗位，容易造成严重违纪违法行为的；

　　（2）二级风险是指对于潜在廉政风险较大、发生问题危害较重，不直接拥有人财物的支配权，但可借助工作中的权力和机会谋取私利的岗位，容易造成一般违规违纪行为的；

　　（3）三级风险是指对于潜在廉政风险较小、发生问题危害较轻，不涉及人财物等权力，工作内容较公开透明的岗位，容易造成轻微违规违纪行为的。

　　2、风险防范。各单位及个人要围绕确定的各类岗位廉政风险点和风险等级，着重开展教育防范、制度防范、科技防范，有针对性地制定防控管理制度和工作流程等，并报单位分管领导审核后，集中上报廉政风险防控办备案；最后由廉政风险防控办集中上报局党组研究决定。

　　教育防范：各单位要以开展“明岗位职责，强廉政意识”活动为载体，以领导干部和关键岗位为重点，着力抓好党员干部的经常性学习教育，着力加强党性党风党纪教育和理想信念、廉洁从政教育，加强对党员干部特别是领导干部思想作风、学风、工作作风、领导作风、生活作风方面的日常化监督，加强对党员干部的廉政风险教育，筑牢拒腐防变的思想道德防线。

　　制度防范：一要梳理岗位规章制度。根据PDCA循环管理方法，针对查找出的廉政风险，各单位要对现有的制度进行一次较为全面梳理和修改，既要有针对性地补充一些新的制度规定，又要根据形势的变化，对不适应、不配套和不便执行的制度，及时进行修订和完善，努力形成内容科学、程序严密、配套完备、有效管用的反腐倡廉制度体系及岗位职责。二要制定工作流程图。通过查找出的廉政风险点，对重点工作和关键环节必须制定岗位廉政风险防控工作流程图，工作流程图要有效、管用、可控，能直观全面地反映工作环节中可能发生人为干预行为或发生运用自由裁量权的节点，确保涉及职权、利益的“关键节点”看得见，并得到有效的制度规范和约束。

　　科技防范：充分依托现代信息技术，驻农业局纪检组拟对市农业局、林业局、水利局、海洋与渔业局、供销社等五个单位建立内部业务管理廉政监督平台，围绕群众关心的热点、难点和惠及民生的重点工作，针对权力运行过程中易发多发腐败问题的环节。

　　3、风险监控。一要落实廉政风险防控工作责任制。按照“谁在岗谁防控，谁主管谁监督”的原则，明确防控职责，实行分类防控，以岗位工作人员自我防控为基础，各职能部门负责防控职责范围可能产生的廉政风险，部门负责人承担风险防控的主要责任。实行分级监督，主要领导要带头做好自己的风险防控，还要对一级风险的岗位进行防控监督；分管领导对二级风险的岗位进行防控，负责检查监督，督促风险防控责任部门落实各项防控措施；各科室（站）负责人对三级风险岗位进行防控监督。二要实行廉政风险防控工作责任追究机制。推行诫勉提醒、诫勉督导和诫勉纠错等“三诫勉”制度，及时处置和化解廉政风险。通过开展效能监察、执法监察，定期或不定期的廉政监督检查，以及征求服务对象、政风行风监督员意见等形式发现问题，针对发现的问题运用廉政提醒、批评教育、诫勉谈话、岗位问责、党政纪处分等形式及时采取处置措施，纠正工作中的失误和偏差，堵塞漏洞，化解廉政风险，避免苗头性、倾向性问题演化发展成违纪违法行为。对不落实风险防控措施，监督不力，发生廉政问题、监管事故的，追究有关责任人的责任，确保风险防控措施得到有效落实。

　　（三）考核阶段

　　局廉政风险防控工作领导小组每年组织对本单位各个岗位进行专项检查考核，作为党风廉政建设责任制检查考评的一项重要内容。评定结果作为干部评先评优的重要依据，党员干部发生不廉洁行为的取消评先评优资格；并按照干部管理权限，分级建立领导干部廉政档案，综合运用于党员干部的选拔、任用、考核等工作中。

　　（四）修正阶段

　　开展自查：各岗位应每半年对廉政风险防控管理工作的落实情况进行一次自查，并把自查情况上报局廉政风险防控办。

　　改进提高：各岗位要根据廉政风险防控管理工作的运行情况，结合自查发现的问题和检查监督提出的意见和建议，运用PDCA循环管理方法，对岗位权力点和廉政风险点进行再次排查梳理，并对新排查出的风险点建立相应规章制度、工作流程及监督检查措施，做到持续改进，不断提高。修订完善的制度、流程图汇总后于每年的12月10日报局廉政风险防控办。

　　五、工作要求

　　开展廉政风险防控工作是从源头上预防腐败的一项重要举措，各单位要把开展廉政风险防控工作作为一项重要工作摆上议事日程，切实加强组织领导。要建立由主要领导亲自抓，分管领导重点抓，职能科室负责人及工作人员具体抓的廉政风险防控工作格局。要突出抓好领导班子和中层干部、关键岗位和重点人员，使排查防控工作做到多层次、全方位。同时，要把廉政风险防控工作与推进惩治和预防腐败体系建设相结合，与落实党风廉政建设责任制相结合，与林业业务工作相结合起来，统筹安排工作，落实工作责任，确保工作取得实效。
