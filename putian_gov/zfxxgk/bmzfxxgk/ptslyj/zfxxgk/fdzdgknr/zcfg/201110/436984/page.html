莆田市林业局关于加强林业信息工作的通知

发布时间：2011-10-27 08:00
| | |
政策解读:

　　莆林综[2011]82号

　　莆田市林业局关于加强林业信息工作的通知

　　各县区（管委会）林业局（林办），局各部门、各直属单位：

　　为进一步加强我市林业信息工作，及时反映和交流我市林业系统的工作动态、先进事迹和典型经验，为各级领导决策林业工作提供参考，促进我市“森林莆田”科学发展、跨越发展，特对全市林业系统信息工作提出如下要求和规定。

　　一、加强领导，健全网络。信息是各级各部门科学决策的基础和依据，是领导开展工作的前提。各级林业部门的领导要站在“森林莆田”的发展全局来认识和审视加强林业信息工作的重要性，自觉把信息工作摆在总体工作的重要位置，做到主要领导亲自抓、主管领导具体抓、其他领导共同抓。各单位各部门的主要领导要切实加强对信息工作的领导和指导，要经常给信息员出题目、交任务、压担子，努力提高信息报送质量。各业务部门要树立抓信息就是抓业务、抓业务必须抓信息的意识，把林业信息工作作为一项硬任务，与业务工作同步开展、同步推进。各县（区、管委会）林业局（林办）要指定一名专职信息员做好信息报送工作。各直属单位、局机关各部门也要指定一名专职信息员，专门负责本部门的信息报送工作。各县（区）各直属单位分管信息领导、各单位各部门信息员的名单和联系电话于2011年11月5日前报市林业局办公室。

　　二、围绕中心，搞好服务。信息的作用在于帮助领导对重大问题作出决策，推动部门和基层实际问题和困难的解决，及时了解动态，发现问题，科学决策，推动全局工作。林业信息工作者要以港口林业建设为中心，扎实开展工作。一要围绕林业改革、发展、稳定的大局，挖掘大主题、深层次信息；二要把学习宣传贯彻落实党和国家、省委省政府、市委市政府和省林业厅的重大决策部署作为工作的重点，及时收集,形成反馈信息；三要抓住各级党委、政府领导关注的、群众反映强烈的“热点”，尤其是基层群众的呼声、要求、建议、愿望，做好追踪收集、整理上报信息。四要及时捕捉林业改革发展中出现的新气息、新思路、新举措，及时、准确、全面地总结、收集改革中出现的新鲜事物，掌握典型，总结经验，推动全局工作。五是对林业改革开放和林业经济发展中出现的新情况、新问题、新矛盾、新倾向、新苗头以及一些带有普遍性的“老大难”问题，主动捕捉、采集报送信息。

　　三、强化措施，提高质量。一是加强队伍建设，提升林业信息员的素质。人才和队伍是林业信息工作的根本。要特别重视队伍建设，尤其是基层林业信息队伍建设，不断提高信息队伍的素质。要按照“政治强、业务精、作风硬”的要求，建设一支精干的林业信息骨干队伍。各级各部门要将政治敏感性较强、工作责任心较强、政策水平较高、文字功底较扎实的同志安排到信息岗位上，并为他们提供参加领导活动、重要会议和重要调研活动条件，使他们能掌握各方面的情况，做到心中有数，有的放矢。要采取“走出去，请进来”的办法，安排信息干部参加一些外出考察学习活动，邀请专家进行讲座辅导，不断提升信息干部的业务水平。林业信息干部必须自觉学习邓小平理论、“三个代表”重要思想、科学发展观和十七大精神，同党中央保持高度一致；要深入基层，调查研究，树立热爱林业、服务林业的思想和艰苦奋斗、无私奉献的精神，全心全意为人民服务；要与时俱进地加强学习研究，提高把握全局的能力，提高利用市场资源策划开展重大活动的能力，提高组织和推动生态文化体系建设的能力，提高运用现代传媒开展林业信息宣传工作的能力，努力成为政治过硬、业务精通、作风扎实，能够担起新形势下林业信息宣传工作重任的高素质人才。二是坚持原则，保证信息工作的正确导向。各单位各部门要坚持“六个原则”，确保信息报送的质量。（一）及时、准确、全面地收集、加工、存贮、传递的原则；（二）坚持条块、纵横结合的原则；（三）坚持逐级报送原则；（四）专题信息与综合信息相结合的原则；（五）喜忧兼报原则；（六）严格审核把关原则。同时要确保网络安全运行。

　　四、明确职责，建立机制。各级各部门要十分注重信息的时效性，及时报送信息。各县区林业部门信息员每月至少向市林业局报送4条以上信息，2个管委会林业部门信息员每月至少向市林业局报送2条以上信息，市森林公安局、局机关各部门信息员每月至少向办公室报送3条以上信息(其中计财科含基金站、林权登记中心、种苗站信息员每月至少向办公室报送2条以上信息)，各直属单位信息员每月至少报送2条以上信息。为激励先进，鞭策后进，市林业局将实行信息报送、采用情况通报制度，且分别把信息工作列入各级各单位年度目标责任考评和局机关各部门绩效考评的重要内容，同时建立年度信息评比和表彰制度，对年度信息工作先进的个人，将给予适当的奖励。对未完成信息报送任务和信息工作落后的单位，取消年度评先评优资格，相关人员年度绩效奖金按信息完成的相应比例发放。

　　二○一一年十月二十七日
