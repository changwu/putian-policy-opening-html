莆田市林业局关于进一步简政放权深化林业行政审批制度改革的工作意见

发布时间：2011-05-15 08:00
| | |
政策解读:

　　市审改办、市效能办：

　　根据《莆田市行政审批制度改革领导小组办公室、莆田市机关效能建设领导小组办公室关于加大简政放权力度、进一步做好行政审批项目清理梳理工作的通知》（莆市审改[2011]2号）精神，根据我局实际，经过对目前行使的行政审批项目按要求逐项进行清理，研究提出放权处理意见，具体如下：

　　一、林业行政审批项目自查情况

　　本次清理涉及林业行政许可项目15项，非行政许可审批项目13项。（具体见附件2、附件3）

　　二、进一步下放行政审批事权情况

　　经梳理，15项林业行政许可类审批项目中直接下放县区行使审批权的有核发《出省木材运输证》，现建议增加两项直接下放县区行使审批权，即核发《特许采伐许可证》（采伐胸高直径36cm以下的人工珍贵树木）、《木材经营加工批准书》（加工木材年消耗量折合材积2万立方米以上5万立方米以下）等2项。另外13项非行政许可类审批项目建议其中两项直接下放县区行使审批权，即《野生动物驯养繁殖许可证》（除省控蛇、蛙类外的省一般保护野生动物）、《野生动物经营加工许可证》（除省控蛇、蛙类外的省一般保护野生动物及其产品）。（具体见附件1）

　　附件：1、莆田市林业局下放行政审批事权目录（4项）

　　2、行政许可项目目录（15项）

　　3、非行政许可项目目录（13项）

　　二〇一一年五月十五日
