集中清查行动 打造“绿色省运”

发布时间：2010-09-15 08:00
| | |
政策解读:

　　2010年9月8日、9日，秋高气爽，莆田森林警方的一场生态保卫战正如火如荼地开展着。

　　为认真贯彻落实市委五届九次会议精神，打造“绿色省运”，深入推进公安机关“2010年严打整治”行动， 8日至9日，全市各级森林公安机关开展集中宣传保护野生动物资源，清查破坏野生动物资源违法行为的专项行动。这次行动的主要目的是通过集中打击，坚决遏制破坏野生动物资源违法犯罪行为，维护我市生态安全；通过清理整顿，规范对野生动物的依法经营利用，维护野生动物及其制品市场的良好秩序；通过宣传教育，形成群众自觉抵制破坏野生动物违法犯罪行为的社会氛围。

　　领导重视 凝聚警心鼓士气

　　为确保集中行动成功开展，市森林公安局制定工作实施方案，确定专项行动的指导思想、行动重点及步骤，成立工作领导小组，由陈建中局长任组长，刘金龙副局长任副组长，确保行动指挥有力。9月7日召开会议专题部署，分析辖区内非法猎捕、收购、经营野生动物违法行为的特点，梳理线索，提高应变能力；部署了及时查处违法行为、适时开展宣传活动、力争破获一批有影响力案件的行动方案。陈建中局长向全体参战民警作了战前动员讲话，并提出要求：一是要严守纪律，服从命令；二是要突出重点，准确打击；三是要打出声威，打出士气，扩大震慑效果。领导的有力动员和周密的部署激发民警同违法犯罪行为斗争的信心和勇气，为行动开展鼓足了士气。

　　集中清查 行动迅速重实效

　　全市森林公安机关积极协同林业行政执法部门以及野生动物保护站分组对辖区内各市场、饭店、酒楼展开地毯式的集中清查，对发现违法经营野生保护动物的违法行为的一律没收野生保护动物，并按照野生动物保护有关法规进行依法处理。据统计，此次行动共出动车辆64台次，执法人员328人次，其中森林公安民警307人次。共检查酒楼、餐馆、饭店166余家，发放宣传资料共1154份，查处林政案件38起，行政处罚39人，收缴国家二级重点保护野生动物8只（条），省级保护野生动物195只（条）、制品2.6公斤。各级森林公安机关对收缴的死体就地深挖掩埋销毁，活体按规定放归林区，对相关违法经营野生动物人员进行了处罚。

　　宣传并行 传播法律造声势

　　集中清查行动既是严厉打击的过程，更是深入群众传播法律的好时机。在行动前，我局精心制作野生动物保护法律宣传画图，在清查中发放给饭店、酒楼业主及市民，普及野生动物保护法律常识。一方面提高各餐饮业业主自觉守法意识，另一方面激发群众对违法犯罪行为举报揭发的正义感，整个行动中共发放宣传单1100份，得到群众的一致赞同。我局还主动与市电台“民主与法制”栏目联系，邀请电台工作人员全程跟踪行动过程，制作专栏宣传保护野生动物普法知识。及时组织人员动笔，通过信息简报、报刊、网络等各种媒体适时发布我局此次集中清查行动情况，及时通报战果，展示我局打击破坏野生动物资源违法行为的决心，形成高压严打的态势，有力震慑违法犯罪分子的气焰。

　　联合执法 通力协作强打击

　　为加强全面打击力度，我局不仅加强和林业行政执法部门以及野生动物保护管理部门之间执法协作，还邀请工商执法部门开展联合清查，推进执法信息沟通和交流，整合执法资源，加大多部门联合执法力度。

　　野生动物保护  警民联防共努力

　　集中清查只是一时之策，要彻底消除破坏野生动物的不法行为，还有待全体民众自觉保护野生动物资源意识的提高。森林公安机关提醒广大市民，在省运会期间利用带有“野味”字样及野生动物图样的广告牌、饭店菜谱等招揽顾客的，一经发现，将坚决依法从严从重查处。同时呼吁广大市民积极营造全社会保护野生动物资源的良好氛围，为省运会的成功举办创造和谐稳定的生态环境。
