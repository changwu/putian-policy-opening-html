莆田市林业局关于上半年市级林业随机抽查和林业监管领域跨部门联合随机抽查情况的通报

发布时间：2020-07-14 16:35
| | |
政策解读:

各县（区、管委会）林业主管部门，局各有关部门：

根据《莆田市林业局关于印发双随机抽查事项清单、林业监管领域跨部门联合随机抽查事项清单的通知》（莆林〔2019〕3号）和《莆田市林业局关于开展2020年度随机抽查事项市级监督检查工作的通知》（莆林综〔2020〕32号）文件要求，我局于2020年6月15日至7月1日，对林业随机抽查事项清单8个清单项目15家市场主体、林业监管领域跨部门联合随机抽查清单2个清单项目2家市场主体进行事中事后监管执法检查，现将检查结果予以通报。

附件：

1.2020年上半年林业随机抽查结果通报

2.2020年上半年林业监管领域跨部门联合随机抽

查结果通报
