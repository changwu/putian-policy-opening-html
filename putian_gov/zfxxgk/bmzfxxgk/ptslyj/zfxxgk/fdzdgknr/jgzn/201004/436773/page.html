中共莆田市林业局党组关于开展“加快转变发展方式，促进港口城市建设”学习教育活动的实施方案

发布时间：2010-04-13 08:00
| | |
政策解读:

　　局各部门、各直属单位：

　　根据《中共莆田市委关于开展“加快转变发展方式，促进港口城市建设”学习教育活动的意见》(莆委〔2010〕17号)的要求，为认真学习贯彻胡锦涛总书记在福建考察时的重要讲话精神，深入贯彻落实党的十七届四中全会、省委八届七次全会以及市委五届八次全会精神以及刚刚召开的全市林业工作会议精神，积极推进学习型党组织建设，努力推动港口林业又好又快发展，全面推进湄洲湾港口城市建设取得新成效，经研究，决定在全市林业系统广大干部职工中广泛开展“加快转变发展方式，促进港口城市建设”学习教育活动。现制定实施方案如下：

　　一、指导思想

　　高举中国特色社会主义伟大旗帜，坚持以邓小平理论、“三个代表”重要思想为指导，深入贯彻落实科学发展观，深入学习贯彻党的十七大、十七届三中、四中全会精神；认真学习贯彻胡锦涛总书记在省部级主要领导干部专题研讨班上的讲话和在福建考察时的重要讲话精神；深入贯彻落实省委八届六次、七次全会精神和市委五届七次、八次全会精神。通过开展主题教育活动，引导广大干部职工以良好的精神状态、更加开阔的视野、更加昂扬的斗志和求真务实的作风落实好胡锦涛总书记的重要指示要求，着力在加快转变林业发展方式方法、打造滨海宜居园林城市上取得新进展；在坚持利民惠民，保障民生，促进社会和谐稳定上取得新突破；在推进学习型党组织建设、提高党的建设科学化水平上取得新成效；在创新林业科学发展的管理体制机制，优化港口林业发展环境，创造港口林业崛起的发展优势，推动港口林业建设上取得新成就，为实现今年“保八超十”和全面完成“十一五”目标任务作出新贡献。

　　二、活动内容

　　整个学习教育活动分四个阶段进行。

　　第一阶段：部署动员（3月底至4月上旬）

　　1、制订方案。根据市委下发教育活动实施意见，结合我局实际，认真研究制订具体实施方案。

　　2、动员教育。4月上旬，局党组召开大会，进行部署动员，广泛进行思想发动，提高认识，明确要求。

　　第二阶段：主题教育（4月中旬至6月）

　　1、学习内容。重点学习党的十七大有关转变经济发展方式的论述、学习胡锦涛总书记在省部级主要领导干部专题研讨班开班式上的讲话和在福建考察时的重要讲话精神，以及省委学习贯彻意见；学习中央、全省经济工作会议精神；学习全国、全省两会精神和中纪委五次全会精神；学习《国务院关于支持福建省加快建设海峡西岸经济区的若干意见》、省委八届六次、七次全会精神和市委五届七次、八次全会精神；学习全国、全省、全市林业工作会议精神，学习省委、省政府《关于持续深化林改 建设海西现代林业的意见》（闽委[2009]44号）和市委、市政府《关于持续深化林改 建设港口林业的实施意见》（莆委[2010]23号）精神。深刻理解和把握当前的国际国内形势，深刻理解和把握加快经济发展方式转变的重要性紧迫性，深刻理解和把握加快经济发展方式转变的重点任务，深刻理解和把握加快经济发展方式转变的重要保证，切实把思想和行动统一到中央和省委重要精神上来，以“等不起”的紧迫感、“慢不得”的危机感、“坐不住”的责任感，坚定不移地加快港口林业发展方式转变步伐，积极融入港城建设大局，持续破解林业发展难题，激发改革创新活力，努力实现林业新一轮发展。同时要结合林业工作实际，认真落实每周集中学习制度，深入抓好林业相关业务知识特别是法律法规的学习，增强法制意识，不断提高依法行政能力和水平。

　　2、学习要求。各单位要根据各自工作实际安排学习，严格学习纪律，确保学习效果。每周都集中学习相关的文件精神，同时，要把自学贯穿于活动全过程，个人自学原则上每天学习时间不少于半小时。每名参加学习的同志都要认真记好学习笔记，并联系各自工作至少撰写一篇学习心得体会。

　　3、专题辅导。安排“实施‘四绿’工程建设，打造滨海宜居城市”、 “做大做强林业产业”等专题讲座。

　　4、调研考察。由局领导带队分赴各县区林业部门进行调研，了解各单位重点工作进展情况，加强指导，推动工作。积极学习借鉴沿海发达地区发展港口林业，提升林业产业综合竞争力的经验做法，特别是管理机制、服务机制上的创新和举措。

　　第三阶段：实践整改（6月至9月）

　　按照市委五届七次全会提出的“五个突破”要求，以编制林业“十二五”规划为契机，以“以港兴市、工业强市”为带动，着眼于提升林业产业发展水平，打造滨海宜居园林城市建设，认真研究探讨港口林业科学发展运行体制机制，深入破解港口林业发展难题，努力实现工作再上新台阶。

　　各部门各单位要围绕“加快转变发展方式，促进港口城市建设”这个学教活动主题，结合各自工作实际，在六月底前至少提出一个调研课题，报局党组研究确定后，组织开展调研活动。

　　第四阶段：总结提高（10月至12月）

　　各单位要结合学习贯彻党的十七届五中全会精神，及时开展专题调研结果汇报交流，总结学习教育活动的经验做法，着力构建富有效率、更加开放、有利于科学发展的体制机制，形成有利于加快经济发展方式转变的制度安排，并将学习教育活动总结汇报材料和专题调研材料于12月10日前上报局学教办。局学教办将对各单位的主题教育活动进行专项考评，其结果作为行评考核和先进评比的一个重要条件，并召开主题教育活动总结会议。

　　三、组织领导

　　1、局党组成立领导小组，加强对学习教育活动的领导。

　　2、领导小组下设办公室，挂靠综合科，办公室主任由林春嘉同志兼任，成员由局机关各科室抽调人员组成。

　　四、工作要求

　　各单位一定要把“加快转变经济发展方式，促进港口城市建设”学习教育活动作为当前和今后一个时期的一项重大政治任务，高度重视，按照本实施方案的要求，抓好每一个环节，落实好每一项任务，确保活动成效。

　　（一）认真贯彻落实上级部署，深刻认识学习教育活动的重要性。“加快转变经济发展方式，促进港口城市建设”学习教育活动是近年来市委一手抓经济社会发展、一手抓党员干部思想作风建设的重要持续点，是深入贯彻落实党的十七届四中全会精神、深入学习贯彻胡锦涛总书记在福建考察时重要讲话精神的重要举措。学习教育活动以领导班子和党员领导干部为重点，全体党员都要参加。参加学习教育活动的单位的党组织要全面负责本单位的学习教育工作，精心组织，周密部署，做到领导重视贯穿始终，创新机制贯穿始终，注重实效贯穿始终，统筹兼顾贯穿始终。同时，主要领导干部要亲自抓、带头学、先行做，带头撰写心得体会，带头参加学习，带头开展调查研究，积极参加各种集体学习，率先垂范，引导和调动广大干部职工参加学习教育活动的自觉性和主动性。要充分发挥专题辅导、交流讨论、座谈调研、学习简报的作用，在全局上下形成人人积极学习，全员参与活动的良好氛围，确保学习教育活动取得实实在在的效果。

　　（二）准确把握关键环节，以改革创新的精神促进工作开展。开展学习教育活动要注重把握加强理论武装、突出学习教育特色、贯彻群众路线、转变工作作风、强化林业队伍建设为主的原则，通过理论联系实际，结合去年学教活动的有效形式、有益做法、成功经验，把加强学习教育与解决实际问题结合起来，不断改进、有所创新，努力做到边学边改边干。同时，要深入领会贯彻胡锦涛总书记在福建考察时的重要讲话精神，紧密联系全市林业工作发展实际，联系本科室、本单位工作实际，联系广大干部职工的思想和工作实际，有针对性地开展学习，正确处理工作和学习的关系，边学边改边干，比学赶超、争先创优，在全市林业系统中持续营造想干事、会干事、干成事、干净干事的创业环境。

　　（三）加强监督领导，确保学习教育活动取得实效。学习是基础，实践是关键。学习教育活动必须紧密联系湄洲湾港口城市建设的实际，边学习边实践。局学习教育活动领导小组办公室要精心组织，周密部署，紧紧围绕“在发展中促转变、在转变中谋发展”和“在发展中促调整、在调整中谋发展”这条主线，正确处理好速度和效益、总量和质量的关系，切实抓好学习教育活动，下更大功夫推动港口林业发展方式转变。要强化督导检查，及时跟踪、指导各单位活动开展情况，检查各单位的集中学习情况、学习记录、学习考勤表和个人学习笔记，召开座谈会、心得交流会认真总结学习实践过程中遇到的问题，及时提出相应的解决方法和措施，确保学习教育活动生动有效、扎实深入地开展。

　　（四）及时上传下达，广泛营造良好的宣传氛围。做好舆论引导工作，营造良好氛围，是开展学习教育活动的有效举措。局学教办要按照全市学习教育活动的时间安排和活动内容，结合实际，进一步细化学习教育的工作方案，明确任务，组织开展好各项活动，制定好学习活动方案，要充分利用《莆田林业》信息专刊、学习实践活动专报等媒体渠道，既要突出各阶段的学习教育重点，又要加强各阶段活动的小结、衔接与部署，及时总结我局开展学习教育活动的好经验、好做法，将学教活动中取得的新成效、新亮点上报市委学习教育活动领导小组办公室。各科室、各单位要结合本单位实际，认真制定各自的学习教育实施方案，召开动员会议广泛进行宣传发动，并指定一名专职联络员，及时向局学教办报送相关活动信息。

　　局机关党支部、市森林公安局党支部及各直属单位要把学习教育活动当作推动工作的重要机遇和强大动力，把学习教育活动与深入贯彻落实党的十七届四中全会精神和胡锦涛总书记在福建考察时重要讲话精神相结合，与转变经济发展方式，促进港口城市建设相结合，与推进学习型党组织建设、提高党的建设科学化上水平相结合；与贯彻落实全市林业工作会议相结合。通过学习教育活动促进各项工作，用推动港口林业建设的各项工作，加快推进湄洲湾港口城市建设的实际成果来衡量和检验学习教育活动的成效。

　　二0一0年四月十二日                                        

　　主题词：学教活动 “加快转变发展方式，促进港口城市建设” 实施方案

　　抄送：市委学教活动领导小组办公室，市委农办，各县区（管委会）林业局（林办）
