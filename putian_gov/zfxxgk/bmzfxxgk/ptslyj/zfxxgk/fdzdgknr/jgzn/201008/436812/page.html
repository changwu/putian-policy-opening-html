关于开展创先争优承诺践诺活动的实施方案

发布时间：2010-08-12 08:00
| | |
政策解读:

　　各县区（管委会）林业局（林办）党支部，各直属单位党支部：

　　开展承诺践诺活动是创先争优活动的一项特色工作，也是保证创先争优活动有效开展的重要基础性工作。根据市创先争优领导小组统一部署，现就林业系统党组织和党员开展承诺践诺活动制定如下实施方案：

　　一、公开承诺的主要内容

　　基层党组织和党员实行公开承诺，必须按照“先行先试、加快转变、民生优先、党建科学”的要求，深入学习实践科学发展观，组织抓好创先争优活动，围绕完成中心任务，充分发挥党组织的战斗堡垒作用，从推动日常工作、服务发展、服务群众等方面作出承诺，努力创建“五个好”党组织。党员应重点围绕积极参加创先争优活动，模范履行党章规定的义务，努力做到“五带头”，在履行岗位职责特别是在森林资源管护、森林防火、沿海防护林建设、壮大林业产业等方面发挥先锋模范作用，在爱岗敬业、服务群众、争做学习型职工等方面作出承诺。
    二、基本要求
    公开承诺要始终把握以下要求：
    1、注重体现先进性要求。着眼于支部创先进、共产党员争优秀、科学发展上水平、人民群众得实惠，按照党章规定的基层党组织的基本任务和党员标准、义务及中央提出的基层党组织创建“五个好”、党员做到“五带头”的基本要求，引导支部和党员服务发展、展示先进形象。同时，要防止降低标准，把承诺等同于一般性的工作和纪律要求。
    2、注重结合职责任务和岗位实际。要从实际出发，注重围绕改革发展、立足本职比贡献、创佳绩进行承诺，切实提高公开承诺的针对性和实效性。不同类型的党员要分别结合所从事的工作进行承诺，在参加公开承诺的同时，要按照所在党组织的要求，就在本职岗位上发挥作用进行公开承诺。坚持尽力而为、量力而行，防止公开承诺标准过高过泛、不切实际，搞形式主义。
    3、注重回应职工群众的关切和期盼。坚持以职工群众满意为最高标准，顺应职工群众的期待，把职工群众的意愿和需求作为承诺的重要内容，认真落实党的惠民利民政策。支部要根据本支部的工作实际，党员要结合发挥自身的工作岗位和能力，向职工群众承诺几件办得到的实事好事，并与学习实践活动整改落实后续工作结合起来，帮助职工群众解决工作生活中遇到的实际困难。

　　三、方法步骤
   公开承诺按以下步骤进行：

　　1、调研走访。承诺前，支部和党员要进一步深入实际、深入群众，广泛征求意见建议，了解群众所思所盼，了解学习实践活动整改事项落实情况，把群众的意愿和需求作为承诺的重要内容和依据，力求承诺事项惠及职工群众、得到职工群众认同。同时要对自身职责、义务进行梳理、明确，为开展承诺奠定基础。
    2、提出事项。党支部要结合开展创先争优活动实施方案制定年度工作目标，通过召开组织生活会和开展“我参与、我承诺、我奉献”大讨论活动，在充分酝酿的基础上，提出承诺事项。党员要结合岗位特点和本人实际，提出参加活动的具体打算，自愿提出承诺事项。
    3、审核确定。党支部的承诺事项由林业局党组审核把关，各党小组要指导帮助党员确定承诺事项。审核指导重点看承诺事项是否体现先进性要求，是否体现中心工作，是否体现岗位、职责特点，是否符合群众意愿，是否切实可行。对不符合要求的，要指导督促，加以完善。
    4、公开公示。承诺事项确定后，支委会要通过会议、文件、党务政务公开栏、网络等形式向党员、职工公布，确保党组织和党员的承诺及时公开、群众普遍知晓并全程参与监督。
    四、组织领导
    1、落实领导和指导责任。要充分认识做好公开承诺工作的重要意义，加强领导，精心组织，具体指导。领导干部要加强调查研究，尊重群众首创精神，指导党员不断丰富承诺内容，严格承诺标准，改进承诺方法。要加强检查督促，坚持诺必践、践必果，做到项项有着落，件件有结果。对公开承诺落实不好、党员和群众不满意的，应要求限期整改。
    2、努力扩大公开承诺覆盖面。力争公开承诺工作在各党小组和党员中全面覆盖，不留空白点。
    3、做好宣传引导。要大力宣传公开承诺的重要意义、原则要求、主要内容和方法步骤，及时总结和上报开展公开承诺的好做法和好经验，发现和推广公开承诺、扎实履诺、民主评诺过程中涌现出来的先进典型，发挥示范引导作用，促进创先争优活动顺利开展。
    4、公开承诺要在8月底前完成。要注重做好公开承诺与领导点评、群众评议、评选表彰等其他推进方式的相互衔接，把践行公开承诺情况作为领导点评、群众评议、考核评价的重要内容。
