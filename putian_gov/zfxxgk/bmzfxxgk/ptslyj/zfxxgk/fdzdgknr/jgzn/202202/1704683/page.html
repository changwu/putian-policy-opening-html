莆田市林长办公室关于2021年林长制工作考核结果的通报

发布时间：2022-02-09 16:52
| | |
政策解读:
 各县（区）人民政府（管委会）:

全面推行林长制是以习近平同志为核心的党中央作出的重大决策部署，是深入践行习近平生态文明思想的重大实践探索。市委市政府高度重视，主要领导亲自部署推动，各级党委政府有力推进，各协作单位协作发力，结合贯彻习近平总书记来闽考察重要讲话精神，落实习近平总书记关于治理木兰溪、保护好湄洲岛重要指示要求，全面推行林长制。

通过推行林长制，全市于2021年9月建立市县乡村四级林长责任体系，实现了森林资源网格化全覆盖管理，完成构建党政同责、属地负责、部门协同、源头治理、全域覆盖的长效机制，全市森林资源得到有效管护。2021年，全市完成植树造林4.47万亩，占省下达任务的109%；全市林业总产值达573亿元，比增5.1%；全市林业行政案件查处率显著提高；森林灾害得到有效控制，森林火灾受害率低于千分之0.8的省控指标，实现森林防火网格化管理全覆盖；松材线虫病防控实现疫情乡镇数量减少4个，疫情面积减少2万亩，提前超额完成省下达防控目标任务。

为推动各县（区、管委会）党委政府履职尽责，确保林长制落地见效，市委将林长制工作纳入督查检查考核计划。市林长办公室根据市委部署要求，按照《莆田市林长制工作考核制度（试行）》等规定牵头开展了2021年林长制工作考核。考核得分由高到底依次为:仙游县，湄洲岛管委会，荔城区，涵江区，城厢区，北岸管委会，秀屿区。考核结果经市林长同意，现予以公布。

各地要从本次考核中认真总结经验，针对存在问题和不足，举一反三，列出问题清单，制定整改措施，明确整改时限，压实整改责任，抓紧整改到位。同时，认真组织对本级协作单位和下一级林长制工作考核，严肃对待、严格考评、严明规矩，考出实效，改进工作。

各地要进一步提高政治站位，认真落实党中央国务院决策部署和省委省政府、市委市政府工作要求，全面深入推行林长制，在服务乡村振兴、维护生物安全多样、增强固碳中和等工作中积极作为，为我市实施“双轮”驱动，全方位推动高质量发展超越提供支撑保障。

                                 

                             莆田市林长办公室

                              2022年2月8日
