莆田市体育局关于做好2019年度福建省体育产业发展专项资金（A类）项目申报的通知

发布时间：2019-10-25 10:40
| | |

各县（区）文化体育和旅游局、湄洲岛管委会社会事务管理局、北岸开发区党工委宣传部：

根据《福建省体育局 福建省财政厅关于印发<福建省体育产业发展专项资金管理办法>和<福建省竞技体育品牌项目建设专项资金管理办法>的通知》(闽体〔2019〕261号)文件要求。现就2019年福建省体育产业发展专项资金（A类）申报工作通知如下：

一、申报要求

根据上述管理办法规定“本办法印发之日前已下达资金可按原有规定执行”，今年专项资金评审可按2018年有关规定执行，各县（区、管委会）体育行政主管部门须组织属地内体育产业单位及时开展省级体育产业发展专项资金项目的申报工作，并参照《福建省体育局关于做好2018年度福建省体育产业发展专项资金（A类）项目申报的通知》（闽体〔2018〕157号）等文件要求做好组织申报、项目真实性核查等初审工作。

二、补助范围

2019年A类专项资金，用于补助2018年7月1日至2019年6月30日符合条件的项目，其中已获得2018年福建省体育产业发展专项资金的项目不能重复补助（2018年1月1日至2019年6月30日未获得补助且符合条件的项目可继续申报2019年产业专项资金A类）。

三、申报时间

各县（区、管委会）体育行政主管部门做好组织申报、项目真实性核查，并填报《福建省体育产业发展专项资金项目材料审查表》（附件3），于2019年11月6日前将申报材料连同电子光盘报送至市体育局。

四、联系方式

联系人：莆田市体育局体育产业发展办  朱琳璐

联系电话：19905948188

邮寄地址：莆田市城厢区龙桥街道市政府2号楼603

特此通知。
