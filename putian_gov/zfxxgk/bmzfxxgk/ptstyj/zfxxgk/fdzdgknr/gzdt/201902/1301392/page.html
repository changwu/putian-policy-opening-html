莆田市体育局关于2018年度莆田市体育社会组织考核评估方案的通知

发布时间：2019-01-22 08:33
| | |

莆田市市级体育社会组织：

为全面贯彻落实国家全民健身战略，促进体育社会组织健康有序发展，扎实推进基层党组织建设，着力提升非公党建工作水平，根据《莆田市市级体育类社会组织管理暂行办法》有关规定，现就我市2018年度市级体育社会组织考核评估工作有关事项通知如下：

一、考核目的

通过考核评估，对市级体育社会组织的整体情况进行客观、全面的分析和评判，确定评估等级，激励市级体育社会组织不断提高综合发展能力；通过参与评估，使各单位熟悉了解市级体育社会组织建设的标准和要求，明确自身发展方向，促进规范化建设。切实实现“以评促改、以评促建、以评促管、以评促发展”的考核评估目标。

二、考核对象

经市体育局、市民政局登记成立，符合《莆田市市级体育类社会组织管理暂行办法》中要求的莆田市市级体育社会组织。

三、考核内容

市级体育社会组织的组织建设、制度建设、体育活动赛事、体育宣传、工作成效等内容。

四、考核小组成员

郭文标、郭建春、曾霖辉、黄晓婷

 五、考核程序及时间安排

（一）发动阶段

1.时间及地点：1月17日上午9:00在莆田市综合体育馆新闻发布厅。

2.对象：各市级体育社会组织主要负责人。

3.工作内容

（1）考核评估总动员、2019年工作部署；

（2）对考核办法细则及评分标准进行说明；

（3）布置考核评估工作。

（二）自查自评阶段

1.时间：2019年1月20日前。

2.工作内容

（1）各单位按照《2018年度莆田市体育社会组织考核评估表》对照检查，查找问题及不足；

（2）各单位按照《2018年度莆田市体育社会组织考核评估表》的具体考核内容及要求准备相关材料，并装订成册（考核评估阶段交考核组用于评估，并留存市体育局备案）；

（3）各单位根据《2018年度莆田市体育社会组织考核评估表》对本单位工作进行自评。

3.自评要求：各市级体育社会组织要坚持实事求是，凡弄虚作假的，经查证后，将对该单位的考核成绩下调一个等级处理；情节特别严重的，取消考核资格，并对相关责任人进行严肃处理。凡体育社会组织主要负责人或法人代表违法违纪的，考核为不合格。

（三）考核评估阶段

1.时间及地点： 2019年1月21—2月15日在各单位办公场所。

2.工作内容

（1）召集各单位主要负责人及专职工作人员座谈；

（2）检查核对评估材料；

（3）收集考核评估材料。

（四）考核综合评估阶段

六、考核等级

市级体育社团组织年度考核分值组成为100分，其中组织建设（20分）、制度建设（25分）、体育活动赛事（35分）、工作成效（15分）、体育宣传（5分）。考核结果分为四个等级，分别为优秀（80分以上）、良好（70—79分）、合格（60—69分）、不合格（60分以下）。

评估分值评选达“优秀”的单位，给予表彰及政策支持。对不配合参加考核评估和评估不合格的单位，限3个月内整改，在规定时间内整改不到位的单位给予通报，对不整改的单位，市体育局不予年检，并建议市民政局注销该组织。

特此通知。
