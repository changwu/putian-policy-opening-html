莆田市体育局转发中共莆田市委组织部等四部门向全国“人民满意的公务员”和“人民满意的公务员集体”学习活动的通知

发布时间：2014-01-29 00:00
| | |

局直属各单位、机关各科室：

现将中共市委组织部、中共市委宣传部、市人力资源和社会保障局、市公务员局联合下发的《关于开展向全国“人民满意的公务员”和“人民满意的公务员集体”学习活动的通知》（莆人综〔2014〕8号）转发给你们，请结合本单位的实际情况，要高度重视，认真组织实施，及时总结学习先进活动的经验做法，进一步强化舆论宣传，弘扬榜样精神，努力形成“学先进、做表率、比贡献”的浓厚氛围，不断提升市体育系统队伍整体素质，全力推进莆田“人兴业茂、清风明月”的宜居城市作出贡献。

各单位开展学习活动的情况于2014年3月5日前报送市体育局办公室（邮箱：ptty2005@163.com,电话：2393628）。

附件：中共福建省委组织部、省委宣传部、省人力资源和社

中共福建省委组织部 省委宣传部

省人力资源和社会保障厅 省公务员局

关于开展向全国“人民满意的公务员”和

“人民满意的公务员集体”学习活动的通知

闽人发〔2013〕107号

各市、县（区）党委组织部、宣传部，政府人社局、公务员局，平潭综合实验区党工委党群工作部，省直各单位组织人事部门：

2013年12月13日，中共中央组织部、中共中央宣传部、人力资源社会保障部、国家公务员局联合发出《关于表彰第八届全国“人民满意的公务员”和“人民满意的公务员集体”的决定》。12月17日，中共中央政治局常委、国务院总理李克强，中共中央政治局常委、中央书记处书记刘云山，以及马凯、刘奇葆、赵乐际、杨晶、郭声琨、王正伟等党和国家领导人接见受表彰人员和与会代表。李克强同志发表了重要讲话，高度赞扬受表彰个人和集体所做出的突出成绩，充分肯定广大公务员在治国理政、促进改革开放、推动经济社会发展中发挥的重要作用。他对弘扬“人民满意的公务员”精神提出“促进改革创新、始终勤政为民、践行法治原则、严守清正廉洁”四点希望。

在受表彰的99名个人和80个集体中，我省南平市延平区人民法院副院长兼少年庭庭长詹红荔、省人民检察院正处级检察员李彬、福州市晋安区公安局副局长林新获得全国“人民满意的公务员” 荣誉称号；漳州市行政服务中心、省防汛抗旱指挥部办公室获得全国“人民满意的公务员集体” 荣誉称号。他们是近年来我省各级机关坚持以邓小平理论、“三个代表”重要思想、科学发展观为指导，认真贯彻党的十七大、十八大精神，全力推动科学发展、跨越发展，切实加强公务员队伍建设中涌现出的先进典型，是全省公务员和公务员集体学习的榜样。为弘扬先进，充分发挥先进典型的示范作用，省委组织部、省委宣传部、省人力资源和社会保障厅、省公务员局决定，在全省开展向全国“人民满意的公务员”和“人民满意的公务员集体”的学习活动。现将有关事项通知如下：

一、认真学习贯彻李克强总理“四点希望”

公务员是国家重要的人才资源，是执政兴邦、治国理政的主体。李克强总理对公务员寄予的“四点希望”，充分体现了党和国家对公务员队伍建设的高度重视和对公务员的殷切希望，也是新时代对广大公务员提出的基本要求。当前，各地各部门要结合深入学习贯彻党的十八届三中全会精神，认真学习贯彻李克强总理对公务员队伍建设提出的明确要求，积极开展全国“人民满意的公务员”和“人民满意的公务员集体”学习活动。

一要学先进，促进改革创新。广大公务员要深入学习党的十八届三中全会和省委九届十次全会精神，充分认清我省改革发展面临的形势，增强全面深化改革的紧迫感和责任感。在改革创新的实践中，勇于克服因循守旧的思维定势，开动脑筋，大胆突破，争做改革创新的先锋，以更加富有创造性、针对性、实效性的工作适应发展的新要求。坚持实干兴邦，克服急功近利的短期思想，树立功成不必在我任的意识，多做打基础利长远惠民生的事。

二要学先进，始终勤政为民。公务员是人民的公仆，“人民满意”是公务员的最高荣誉，也是公务员全部工作的衡量标准。广大公务员必须坚持人民至上，忠于职守，尽心竭力。要推行扁平化管理，缩短流程，简化办事程序，实行“一个窗口、一站式、一条龙”服务，大力推行“马上就办”，让群众和管理相对人切实感受到公务员的优质服务，提升服务水平和群众的满意度。

三要学先进，践行法治原则。广大公务员要增强法治意识，自觉遵纪守法，严格依法办事，规范履行工作职责。各级机关要深化行政审批改革，切实解决放权不到位、取消不彻底、服务不配套的问题，提高行政服务标准化水平。

四要学先进，严守清正廉洁。要将学先进与扎实开展党的群众路线教育实践活动有机结合起来，带头执行中央八项规定和国务院“约法三章”，全面落实改进工作作风、密切联系群众各项规定。反对官僚主义，当好人民公仆；反对形式主义，坚持脚踏实地；反对铺张浪费，勤俭办一切事业；反对享乐主义和奢靡之风，弘扬新风正气，做到为民务实清廉。

二、学习先进典型弘扬榜样精神

受表彰的“人民满意的公务员”和“人民满意的公务员集体”大多数来自基层普通岗位，他们认真履行党和人民赋予的职责，心系群众，为民尽责，兢兢业业，勤勤恳恳，务实进取，在平凡岗位上创造了不平凡的业绩，这种精神值得弘扬光大。广大公务员要以他们为榜样，学习他们对党和国家无限忠诚、理想信念坚定、全心全意为人民服务的政治品质，学习他们无私奉献、严于律己、淡泊名利的高尚情操，学习他们与时俱进、敢于担当、开拓创新的进取精神，学习他们爱岗敬业、秉公执法、清正廉洁的职业操守，学习他们扎根基层、艰苦奋斗、求真务实的优良作风。当前，各地各部门和广大公务员要紧紧围绕我省全面深化改革的总要求和各项工作部署，深入实施“三规划两方案”，深入推进我省经济、政治、文化、社会、生态文明建设。广大公务员不仅要做改革的参与者，更要做改革的推动者，要以先进典型为榜样，锐意进取，真抓实干，敢于担当，为进一步开创福建科学发展跨越发展新局面做出新的贡献。始终要牢记和坚持党的宗旨，忠诚党的事业，坚持党的群众路线，视人民如父母，把人民当靠山，始终把广大人民群众的利益作为一切工作的出发点和落脚点，真正做到为民用权、为民谋利、为民守责。

三、精心组织务求实效

党的十八大对建设高素质执政骨干队伍作出了总体部署，十八届三中全会对深化干部人事制度改革提出了明确要求，公务员队伍建设是党和政府治理体系和治理能力建设的重要组成部分。各地各部门要把这次学习活动作为当前推进公务员队伍建设的一项重要举措来抓，自觉从政治上、思想上、行动上与以习近平同志为总书记的党中央保持一致，把学习贯彻李克强总理 “四点希望”、学习宣传“人民满意的公务员”和“人民满意的公务员集体”的先进事迹与深入开展群众路线教育实践活动结合起来。学习活动要认真组织，科学安排，务求实效，努力形成“学先进、作表率、比贡献”的浓厚氛围。

一要组织学习先进事迹。要安排专门时间，采取多种形式，组织机关公务员联系岗位和思想实际，学习人民满意的公务员和集体的先进事迹，增强学习的针对性。要把开展向“人民满意的公务员”和“人民满意的公务员集体”学习活动和挖掘身边的先进典型结合起来，结合榜样的力量和示范带动作用，教育和激励广大公务员树立正确的世界观、人生观、价值观。

二要积极整改突出问题。紧密结合当前正在开展的群众路线教育实践活动，立学立行，立说立改，紧密联系本单位的实际，建构务实管用的载体，借鉴人民满意的公务员和集体的工作经验，提出学习先进活动的具体措施和要求，切实整改存在的“四风”问题，深入一线、深入实际，察实情、出实招、办实事。

三要切实加强制度建设。要通过学先进，把好的做法以制度的形式固定下来，不断提高依法执政、依法行政、依法办事的能力，真正做到践行法治原则、规范履行职责。

四要在系统和队伍内部形成创先争优的氛围。要自我激励和鞭策，不断深化创先争优开展做人民满意公务员活动，推广公开承诺，健全领导点评机制，建立健全群众民主评议和民主测评制度，及时表彰和树立先进典型。

各地各部门要及时总结学习先进活动的经验做法。各设区市和各省直机关（单位）开展学习活动的情况于2014年4月前按干部管理权限报送省委组织部干部六处和省公务员局考核奖惩培训处。
