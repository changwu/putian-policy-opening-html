莆田市体育局关于举办2018年市体育局科级干部“深入学习贯彻习近平新时代中国特色社会主义思想”专题班暨全市体育系统“干部综合素质提升年”系列活动培训班（第二期）相关事宜的通知

发布时间：2018-10-25 16:37
| | |

　　各县（区、管委会）体育行政主管部门，局各工作办、直属单位，各有关单位：

　　为贯彻落实省委《关于在全省进一步兴起习近平新时代中国特色社会主义思想“大学习”热潮的通知》精神，根据市委组织部关于抓好科级干部“深入学习贯彻习近平新时代中国特色社会主义思想”轮训工作的通知和《莆田市体育局关于举办2018年全市体育系统“干部综合素质提升年”系列培训班的通知》(莆体〔2018〕82号)要求，我局将举办2018年科级干部“深入学习贯彻习近平新时代中国特色社会主义思想”专题班暨全市体育系统“干部综合素质提升年”系列活动培训班（第二期），现就有关通知如下：

　　一、培训目的

　　为进一步深入学习习近平新时代中国特色社会主义思想，努力提高政治站位，强化政治担当，坚决维护习近平总书记核心地位、坚决维护党中央权威和集中统一领导，牢固树立“四个意识”、坚定“四个自信”，更加自觉地用新思想武装头脑、指导实践、推动工作。进一步加强我市体育系统干部职工的党务工作能力培训，提高干部职工的思想政治素质、业务能力与服务水平，为建设美丽美丽、加快实现高质量发展和赶超目标服务。

　　二、培训时间、地点及培训对象

　　(一)培训时间：2018年10月30日--11月2日；

　　(二)培训地点：莆田市体育场地管理处（莆田市荔城区西天尾镇溪华路509号）；

　　(三)培训对象：

　　1.全程参加对象：市直体育系统全体科级干部、各支部（总支）党务工作者。

　　2.请各县（区、管委会）体育行政部门局长、分管副局长参加10月31日上午课程，其他课程邀请参加。

　　三、培训内容

　　(一)观看林宝金书记主题报告录像；

　　(二)专题讲座：认真学习习近平关于体育重要论述  努力推动当前莆田体育工作发展；

　　(三)专题讲座：如何加强基层党支部建设；

　　(四)专题讲座：学习领会新思想 做好新时代意识形态工作；

　　(五)专题讲座：宣讲《中国共产党纪律处分条例》；

　　(六)专题讲座：坚定不移推动全面从严治党——学习新时代党建思想及新党章；

　　(七)专题讲座：坚持以人民为中心 推动经济高质量发展；

　　(八)专题讲座：学习习近平总书记全面深化改革重要论述；

　　(九)分组研讨：如何深入贯彻落实习近平新时代中国特色社会主义思想；

　　(十)专题讲座：《深入学习贯彻习近平新时代中国特色社会主义思想》专题宣讲；

　　(十一)专题班学习总结。

　　四、自学内容

　　(一)《习近平谈治国理政》第一卷、第二卷；

　　(二)《习近平新时代中国特色社会主义思想三十讲》；

　　(三)《十九大报告》（单行本）；

　　(四)《做一个思想清醒的人----提升党员干部意识形态能力》；

　　(五)《摆脱贫困》。

　　五、培训形式

　　采取观看录像、专题讲座、分组讨论、交流研讨和撰写学习体会相结合的形式。

　　六、培训要求

　　(一)遵守各项纪律。每位学员在学习期间要严以治学，自觉遵守学习培训和廉洁自律各项规定，树立学员意识，端正学习态度，集中精力，认真完成学习任务。

　　(二)撰写学习体会。每位学员要结合观看录像、专题讲座和交流研讨，就深入学习贯彻习近平新时代中国特色社会主义思想，切实学懂弄通做实，撰写一份不少于1000字的学习体会，并于培训结束后一周内交至党建工作办。邮箱：pttydj@163.com，文件名格式：2018年科级干部“深入学习贯彻习近平新时代中国特色社会主义思想”专题班暨全市体育系统“干部综合素质提升年”系列活动培训班（第二期）XXX同志学习体会。

　　(三)培训费用情况。培训期间，参训人员的培训费（师资费、住宿费、伙食费、培训场地费、培训资料费等）由培训举办单位承担，往返交通费用按照市直机关差旅费有关规定回单位报销。

　　2.培训班报名表
