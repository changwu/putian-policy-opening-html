莆田市体育局关于市人大八届六次会议第1338号建议的协办意见

发布时间：2026-03-19 15:58
| | |

市教育局：

吴锦程代表提出的《关于以设施升级与师资赋能推进乡村学校体育帮扶的建议 》（第1338号）已收悉，就退役运动员专项招聘、驻校指导、师资补强相关工作，我单位协助办理意见如下：

一、基本情况

（一）落实省级专项招聘部署

加大体育教师招聘力度。2026年2月，由省教育厅、省体育局、省委编办和省人社厅联合发文开展2026年退役运动员专项公开招聘学校教练员工作。有意向招聘退役运动员进校任教的省级及以上高水平体育后备人才基地学校、体育传统特色学校、中小学校和各级体校均可参与。该工作由各级教育部门统筹协调会同有关部门收集招聘岗位计划并于3月底上报省教育厅。省教育厅汇总全省岗位信息，制定公开招聘方案，于4月底前统一公开发布。5-6月，各地组织开展技能测试、面试、考察、体检等工作。7月底前，完成公示、聘用及结果上报等工作。

（二）强化师资精准匹配

主动对接省体育局退役运动员就业安置平台，提前摸排我市业余体校、体育传统特色学校师资缺口，做好岗位测算与人员匹配，推动专业体育人才下沉基层学校。

（三）推进退役运动员驻校试点

指导秀屿区少年业余体育训练学校制定专项招聘方案，面向羽毛球退役运动员开展招聘，以秀屿区实验小学城东校区为试点，开展驻校教学与训练指导，打造体教融合示范点位，助力乡村及城区薄弱学校体育师资能力提升。

二、下一步工作安排

（一）按期完成岗位汇总上报

按照《莆田市教育局 莆田市体育局 中共莆田市委机构编制委员会办公室 莆田市人力资源和社会保障局转发福建省教育厅等四部门关于开展2026年面向退役运动员专项公开招聘学校教练员工作的通知》（莆教体〔2026〕11号）要求，配合市教育局收集全市各级学校招聘需求，于3月23日前报送市教育局汇总上报省教育厅。

（二）深化供需对接与招聘落地

积极参与省体育局组织的退役运动员转任学校教练员供需见面会，提前开展人员摸排、岗位需求测算和精准匹配，科学制定岗位设置方案与专项招聘计划，推动更多符合条件的优秀退役运动员进入省级传统特色学校任教，补齐乡村体育师资专业短板。

（三）完善驻校指导长效机制

推广退役运动员驻校指导模式，扩大覆盖范围，支持退役运动员参与乡村学校体育教学、社团训练、赛事组织，提升乡村学校体育教学与训练专业化水平。

最后，再次衷心感谢各界人士对体育事业的关心和支持，欢迎多提宝贵意见！
