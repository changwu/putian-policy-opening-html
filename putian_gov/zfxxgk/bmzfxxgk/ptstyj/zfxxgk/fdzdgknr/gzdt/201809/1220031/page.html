莆田市体育局关于征求印发《莆田市县（区）级竞技体育工作年度考评办法（试行）》意见的通知

发布时间：2018-09-21 16:28
| | |

各县（区）体育行政主管单位，湄洲岛管委会社会事务局，北岸工委宣传部：

为加快转变竞技体育发展新理念新方式，推动竞技体育高质量发展，进一步提高县（区）级竞技体育工作整体水平，根据《福建省体育局关于进行省重点体育后备人才基地年度考评的通知》（闽体〔2017〕219号）、《莆田市人民政府关于印发莆田市“十三五”体育发展专项规划的通知》（莆政办〔2016〕171号）、《莆田市人民政府办公室关于2016年推进简政放权放管结合优化服务的实施意见》（莆政办〔2016〕128号）和《莆田市人民政府关于推进2017年简政放权放管结合优化服务工作的通知》（莆政办〔2017〕59号）文件精神，现将《莆田市县（区）级竞技体育工作年度考评办法（试行）》征求意见稿发给大家，并于2018年9月21日之前，把建议意见发送至邮箱：ptjxqsb@163.com；联系电话、传真：0594-2290157。

特此通知。

附件1：

莆田市县（区）级竞技体育工作年度考评办法（试行）

（征求意见稿）

 

   为加强县（区）级竞技体育工作，推动全市竞技体育事业高质量发展，根据《福建省体育局关于进行省重点体育后备人才基地年度考评的通知》（闽体〔2017〕219号）、《莆田市人民政府关于印发莆田市“十三五”体育发展专项规划的通知》（莆政办〔2016〕171号）、《莆田市人民政府办公室关于2016年推进简政放权放管结合优化服务的实施意见》（莆政办〔2016〕128号）和《莆田市人民政府关于推进2017年简政放权放管结合优化服务工作的通知》（莆政办〔2017〕59号）文件精神，制定本办法。   

一、考核时间

各县（区）每年考评一次，全面考评在考核期（上年度的11月1日—本年度10月31日）的工作。每年度10月31日前，各县（区）参照<<莆田市县（区）级竞技体育工作年度考评表>>（见附件2）对当年度的县（区）级竞技体育工作进行自评；11月10—31日，由市体育局对各县（区）进行终评。

二、考核内容

（一）部门领导（县区体育行政主管部门领导）

1.重视竞技体育

认定依据：查阅文件、相关材料。

2.竞技体育投入

认定依据：查阅文件、支付凭证材料。

3.协调解决竞技体育存在的困难和问题

认定依据：查阅文件、相关解决困难和问题的凭证材料。

4.教练员、运动员、后勤保障人员评价

认定依据：组织教练员、运动员、后勤保障人员进行评价。

（二）业余训练

1.常年开展业余训练

认定依据：建成若干项特色竞技体育训练项目，有专业教练、有场地设施、有经费投入、并已开展正常训练。教练员训练计划及总结；年度训练计划；阶段训练计划。

2.制定业余训练考核机制

认定依据：业余训练考核方案等相关文件材料。

3.制定运动员、教练员档案

认定依据：本年度内所有运动员、教练员档案。

4.每年用于业余训练经费不少于10万

认定依据：提供运动员伙食费、运动服装费及训练竞赛经费的支付有关凭证。

（三）开展市队县区（学校、社会)办项目

认定依据：开展市队县区（学校、社会)办竞技体育项目相关文件材料依据。

（四）体教结合

1.联合下发本年度体育竞赛计划、教练员（体育教师）和裁判员培训计划，并组织实施。

认定依据：相关联合下发文件等材料。

2.省级体育传统特色校

认定依据：积极开展省级体育传统特色校考核工作。

3.市级体育后备人才训练基地学校

认定依据：积极开展市体育后备人才训练基地学校考核工作。

（五）基地建设

1.国家级（省级）体育后备人才基地

认定依据：国家级（省级）体育后备人才基地文件；补助经费使用的支付有关凭证。

2.青少年体育俱乐部

认定依据：举办青少年体育技能培训，开展青少年体育冬夏令营活动。

（六）竞赛工作

1.承担市队参加省级青少年体育赛事任务

认定依据：参加赛事秩序册、成绩册。

2.积极组队参加市体育局、市教育局主办的市级各项竞赛活动

认定依据：参加赛事秩序册、成绩册。

3.承办市级以上青少年体育赛事

认定依据：承办赛事秩序册、成绩册、赛事总结、赛事预算结算。

（七）竞赛成绩

1.省运会新周期培养一年以上所属运动员参加市级及以上青少年各类体育竞赛取得优异成绩

认定依据：取得竞赛成绩的运动员名单及成绩统计；竞赛成绩证明包括运动员成绩证书、秩序册、成绩册。

2.省运会新周期培养一年以上所属运动员获等级运动员

认定依据：所属运动员获等级运动员相关证明文件。

（八）人才输送

1.省运会新周期培养一年以上所属运动员直接向上级训练单位输送优秀体育后备人才

认定依据：本年度输送学生名单及有关体育行政部门正式颁发文件。

（九）科研(选材)、培训

1.积极开展科研(选材)工作

2.积极派人参加上级教练员和裁判员培训

认定依据：有关科研(选材)、培训文件通知，查阅科研(选材)、培训相关材料；教练员、裁判员培训能够证明参加培训的原始资料；同一教练在同一年中参加多次培训以一人计算。

（十）工作完成情况

1.按时完成市体育局交办竞技体育工作任务和材料上报

认定依据：市体育局交办竞技体育工作任务和材料上报按时报送。

三、奖励办法

　在省运新周期中每年度底考评结果在全市体育工作会议和有关媒体上公布，并对前三名进行授匾。5个县区考核80分以上为合格（2个管委会65分以上为合格）。每年度底考核合格以上给予兑现奖励，第一名奖励200万元、第二名奖励150万元、第三名奖励100万元、第四名奖励50万元、第五名奖励30万元、第六名奖励20万元、第七名奖励10万元。未达合格标准的，及时会商寻找解决问题，连续两个年底考核未达合格标准的，视情节给予约谈、问责等。

奖励资金主要用于县（区）级竞技体育工作，包括改善场地设施、训练、科研(选材)、比赛、培训、宣传、表彰等方面。

四、本办法解释权归莆田市体育局，本办法自发布之日起实施。
