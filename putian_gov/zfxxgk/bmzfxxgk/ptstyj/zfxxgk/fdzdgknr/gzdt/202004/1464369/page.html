莆田市体育局关于市政协七届四次会议第2020092号提案办理情况的答复

发布时间：2020-04-17 09:26
| | |

民建莆田市委员会：

您委提出的《关于加快发展我市体育竞赛表演产业的提案》（2020092号）已收悉，现将办理情况函复如下：

体育竞赛表演产业是推动体育产业向纵深发展的重要引擎，近年来，我局积极推进体育竞赛表演产业专业化、品牌化、融合化发展，培育壮大市场主体，加快产业转型升级，不断满足人民群众多层次、多样化的生活需求，提升人民群众的获得感和幸福感。

一是完善政策支持体系，持续优化投资环境。扎实推进《莆田市体育产业“十三五”规划》《莆田市体育产业发展行动计划（2017-2021年）》《莆田市人民政府办公室关于加快发展健身休闲产业的实施意见》等政策落实，在全省率先出台《莆田市促进体育产业高质量发展的若干措施》，为我市体育产业发展提供政策保障。

二是全面推进赛事改革，不断丰富活动供给。在全省率先采取了“群众体育赛事（活动）全部向社会力量购买服务”运行机制，2019年莆田市全民健身运动会25个项目，全部采取公开招投标和公开征集合作单位的方式向社会力量购买服务。全年组织举办各类群众赛事活动达260余场，直接参与人数超11万人次，投入资金1283.8万元，初步形成了“莆田市百村体育联赛、莆田市社区体育节、全国海钓锦标赛(莆田站)、联发迎新健身跑”等品牌赛事，并持续推动以南少林武术、妈祖民俗体育、全国海钓锦标赛等为龙头的特色体育赛事发展。

三是加强资源盘活力度，合力打造特色项目。两年来总投资近1.5亿元，创新推进旧厂房改造体育休闲综合体10余个约5.5万㎡，有效盘活城市“金角银边”，辐射惠及广大人民群众，其中有示范意义的项目有仙游四季体育休闲小镇、城厢汉岚体育城市南广场体育综合体、涵江区仓篮部落等。加强省级体育产业基地建设，其中仙游县四季体育综合体和涵江区坪盘体育休闲旅游综合体获评2019年省级体育产业示范项目。

四是强化项目宣传推介，有效推进项目落地。通过新闻发布会、专题招商推介会、体育两博会、9.8厦门投洽会等，宣传推介双修户外体育素质拓展基地等各具特色的“体育+”和“+体育”品牌项目30多个，并在2019年省体育产业高质量发展现场推进会上，成功签约7个，签约数位列全省第一，其中莆田LNG循环经济综合利用冰雪体育场馆PPP项目投资近30亿元。

五是立足体制机制创新，重大赛事精彩纷呈。推进“管办分离”改革措施，采取“政府引导、市场运作、企业承办、社会参与”的赛事运作模式，以“妈祖杯”、海峡两岸系列品牌赛事为核心，构建具有莆田特色的体育赛事体系，成功举办了国际性、全国性体育赛事8场。

下一步，我局将根据您的建议，围绕美丽莆田建设，贯彻落实《莆田市体育产业发展“十三五”规划》，发挥体育竞赛表演产业规模大、范围广、关注度高、拉动力强、影响时间长、辐射力强大等特点，进一步推进我市体育竞赛表演产业发展。

一、打造品牌赛事，丰富赛事活动

一是全力打造“妈祖杯”等系列品牌赛事。做强“妈祖杯”海上丝绸之路国际羽毛球挑战赛、“妈祖杯”海上丝绸之路国际围棋系列赛等国际国内品牌赛事，同时以南少林禅武文化为依托，举办南少林武术节，发展以“南少林禅武文化”冠名的系列品牌赛事，扩大赛事影响力，建设具有莆田特色的体育强市，发挥高端体育赛事在激发城市活力，提升生活品质、拉动体育消费等方面的积极作用。

二是引入扶持职业精品赛事。积极引进NBL（全国男子篮球联赛）等由职业体育俱乐部组成的全国性体育联赛，鼓励具备条件的运动队与社会资本合作成立职业运动队，推动篮球、射击等项目走职业化、产业化发展之路。积极探索电竞产业在我市落地布局，参照国内外承办电子竞技比赛的成功模式，在条件成熟的前提下引进NEST（全国电子竞技大赛），支持社会资本发展职业体育。推动和发展俱乐部本地化、专业化。积极举办职业体育赛事，培育具有本地特色、知名度高的职业精品赛事。

三是积极培育自主品牌赛事。利用现有的射击、射箭、击剑等国家级训练基地的区位优势，引进步手枪射击世界杯总决赛、全国射击射箭冠军赛、中国枪王争霸赛等高端体育赛事的同时，加强与国家体育总局、国际体育组织和国际知名体育赛事公司的合作，拓展自主品牌赛事的辐射影响力。积极鼓励市场活跃、关注度高、影响力广泛的原创商业性体育赛事。

四是大力发展全民健身赛事。以全民健身品牌赛事为龙头，大力推进全民体育赛事的发展，形成赛事常态化。鼓励机关、企事业单位及体育社会组织等举办市民喜闻乐见的篮球、足球、羽毛球、广场舞、龙舟等群众体育赛事。按照“一县区一品牌”的体育赛事布局，培育中国（仙游）国际马拉松比赛、城厢区联发健康跑、秀屿国际海钓（矶钓）邀请赛等。推进市属国有企业“一企一赛事”，发挥市属国有企业作用，倡导市属国有企业创办符合本行业特点的“一企一赛事”活动，支持各县（区）根据自身经济、社会、文化、地域等特点，在“政府主导、社会参与、市场运作”的框架下开展举办具有地域特色和民族传统特色的体育赛事活动。

五是探索拓展冰雪运动赛事。加快推进莆田 LNG 循环经济综合利用冰雪体育场馆 PPP项目建设，力争到2022年，建成莆田 LNG 循环经济综合利用冰雪体育场馆，与周边规划建设的冰雪乐园、冰雪小镇商业街、水乐园等组成集冰雪赛事、冰雪服务、冰雪度假、冰雪文化于一体的多功能国际冰雪小镇，填补市场空白，引领国内冰雪产业。争取打造成为“南方冰雪训练基地”、“冰雪运动旅游基地”、“冰雪产业发展基地”三个国家级基地，大力引进国内外冰上精品赛事落户莆田。

二、改革办赛模式，深耕赛事经济

一是鼓励社会承办体育赛事。激活市场主体，鼓励支持国有企业、民营企业及社会团体组织作为赛事投资主体，建立和健全“政府引导,市场运作,企业承办,社会参与”的赛事运作机制，在承办方式上除自行组织举办和委托承办外，推进企业化、社会化办体育赛事进程，摆脱传统模式，增强企业开展体育产业的活跃度和积极性，鼓励更多的社会力量参与体育竞赛表演业活动，探索多元化的体育竞赛表演业发展模式，激发莆田中小型体育赛事活力，提高赛事运作的市场化、职业化水平。

二是引导企业深挖赛事经济。以举办体育赛事为契机，以比赛场馆为平台，组织企业在比赛地点，组织举办企业品牌产品展销会；推广“赛事+”的模式进行展销，销售企业生产的品牌产品。充分利用体育竞赛表演业的影响力和各类媒体拓宽销售渠道、共建共享营销渠道网络、开拓国内外展销市场，开展跨境电子商务等新型营销模式，打造集体育赛事、展销会展、品牌推广、电商金融、运营分销、数据服务等一体化展销营销聚集区，进一步“以赛促销”、“以赛养销”。

三是培育体育赛事中介机构。以中高端体育赛事为载体，吸引国内外知名体育中介机构入驻，开展赛事执行、赛事推广、体育咨询、运动员经纪、体育保险等体育赛事中介业务活动。引导体育行政部门和社会组织向体育中介公司购买咨询、策划、公关、品牌管理、无形资产开发等服务。支持体育中介服务组织参与重大体育赛事的申办、举办和商业化运作。

四是壮大体育赛事消费市场。利用体育品牌赛事的影响力，提高企业知名度，通过有偿（或无偿）冠名，做好体育赛事的赛前、赛中、赛后的服务工作，使冠名企业的自主品牌产品获得最大的宣传推广。鼓励体育赛事制播分离，完善体育赛事转播竞争机制，以社会关注的大型体育赛事为推介重点，创新体育赛事宣传手段和传播方式，充分运用报纸、广播、电视、网站、微博、微信等各类媒体以及政府部门网站、户外宣传阵地等平台，扩大体育赛事的社会影响力和商业价值，营造体育赛事发展良好的市场消费环境。

三、加强平台衔接，推动产业融合

一是加强与相关产业的有机融合。以体育赛事为合作平台，推动“赛事+”和“+赛事”融合发展，促进体育赛事与文化、旅游、教育、会展、商贸、科技、制造、互联网、健康服务等领域的联动互通。以赛事为契机，引导体育明星（奥运冠军）走进企业，代言莆田企业生产的品牌产品，引导体育名星来莆田创办各类培训基地，着力推动鞋业个性化定制发展。同时鼓励体育赛事在旅游名胜区和特色小镇（示范基地）举办，促进“体育+旅游”，“体育+文化”等重点发展。

二是完善体育赛事统计监测机制。加强对体育竞赛组织、体育保障组织、体育场地设施管理、健身休闲活动等体育类企业服务和运行监测，加大扶持力度，培育一批行业龙头企业，推动其纳入规上服务业企业统计。将体育竞赛纳入莆田市体育产业统计序列，建立健全体育赛事常态化监测统计工作机制，收集汇总和定期发布在本市举办的重大体育赛事目录。拓展体育赛事大数据采集渠道，全面系统评估本市举办的重大体育赛事产生的经济社会效益，形成体育赛事持续发展的长效机制。

三是落实体育赛事场地设施建设。大、中型体育场馆设施的规划优先兼顾重大体育赛事举办需求，与体育赛事规划紧密衔接，与赛后综合利用有机结合，提高场馆使用效率。加快推进以冰雪小镇、市体育训练基地、市皮划赛艇基地等重点体育设施项目建设，推动各县区“一场二馆一中心”综合体育设施建设，在开发湄洲岛旅游综合体的同时，力争打造成国内外知名的滨海体育旅游运动休闲区和体育旅游户外运动度假岛，完善体育及相关配套设施服务功能，方便承接举办高品质的体育赛事。改革创新体育场馆管理体制和运营机制，健全激励机制，激发场馆活力。支持体育场馆聚焦主业、以体为主、复合经营，提供专业优质的体育赛事服务，不断提升场馆运营管理效率、效能和综合效益。

四是深化学习交流合作。加强与国内外知名体育竞赛表演组织机构、体育组织和体育赛事公司的合作，发挥对台区位优势，加强海峡两岸体育交流互鉴，学习借鉴著名体育城市的经验做法，以体育赛事质量效益提升和品牌建设为根本导向，以体育赛事本土化、特色化、品牌化、国际化为主要特色，打造国际品牌赛事、国内精品赛事、自主品牌赛事、特色品牌赛事、传统品牌赛事“五位一体”的莆田特色品牌赛事活动体系。
