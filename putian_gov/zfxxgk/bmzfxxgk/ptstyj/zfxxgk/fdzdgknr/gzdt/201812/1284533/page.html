莆田市体育局关于2018年法治政府建设情况的报告

发布时间：2018-12-20 16:24
| | |

市政府：

2018年，我局坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届一中、二中、三中全会精神，严格落实《福建省体育系统贯彻落实<法治政府建设实施纲要（2015-2020年）>实施方案》 要求，按照市委、市政府部署，结合体育工作实际，深入推进法治政府建设工作，依法行政、依法治体的能力和水平不断提高。现将2018年度我局依法行政工作情况报告如下：

一、2018年法治政府建设主要情况

（一）加强组织领导，切实落实依法行政工作责任

我局对推进依法行政工作极为重视，积极按照市委、市政府的通知要求，严格执法程序，加大执法管理力度，加强体育法治建设作为重要内容，成立了体育系统法治政府建设工作领导小组及“七五”普法工作领导小组。明确局党政主要负责人为法治政府建设第一责任人。要求机关工作人员特别是领导干部要带头树立依法行政理念，切实提高运用法治精神、法治思维、法治方式推动各项工作。

（二）加强法制学习，深入开展法制宣传教育活动

1.积极开展法律法规知识的学习。《中华人民共和国宪法》、《中华人民共和国行政复议法》、《体育法》、《全民健身条例》、《国家体育总局贯彻落实〈法治政府建设实施纲要（2015-2020年）〉实施方案》、《体育总局关于进一步规范体育赛场行为的若干意见》、《福建省体育经营活动管理条例》等法律法规是体育事业推进的重要保障。我局把学法、用法、遵法纳入干部考核的重要内容，长期组织学习会学习体育法律、法规、规章和相关文件。在与各科室、各单位签订的目标责任中，学法、用法、遵法情况被纳入其中，局依法行政领导小组经常对领导干部的守法情况进行考核检查。

2.法制宣传教育工作不断深入。充分利用“12﹒4国家宪法日”、“普法宣传月”集中开展法治政府建设活动，形成浓厚的舆论氛围和活动声势；借助莆田市电视台“爱上运动”栏目、湄洲日报“体育专栏”、莆田市体育局门户网站、公众微信号“莆田体育”等新媒体平台广泛宣传《体育法》、《反兴奋剂法》、《全民健身条例》、《公共文化体育设施管理办法》《福建省体育经营活动管理条例》、《福建省公共游泳场所管理办法》等法律法规；借助“8.8”全民健身日、群众体育赛事等活动平台，利用LED显示屏、赛场悬挂横幅、现场布置普法宣传站、搭设普法知识板、分发普法手册，将体育相关的法律法规在群众中普及开来，让群众换一种方式观看体育赛事，感受体育的魅力。将法治宣传落实到体育工作的各个环节，促进我市体育事业法制化、规范化和科学化发展。

（三）开展执法培训，全面贯彻落实普法责任制

1.我局根据《国家体育总局贯彻落实〈法治政府建设实施纲要（2015-2020年）〉实施方案》文件精神，将体育部门工作人员的法治教育培训作为“七五”普法工作的重要内容，11月13日至11月15日我局在莆田市体育公园举办2018年莆田市体育系统行政执法培训，邀请市农业局法规科蔡金凤科长为全市体育系统相关人员授课，全面提高体育部门干部法治思维和依法行政能力。

2.严格落实“谁执法、谁普法”的普法责任制，将执法过程变成普法过程，使体育行政执法人员在执法普法实践中提高自身法治素养和执法能力。今年7、8月我局对全市范围内向社会公众开放的各室内外游泳池、游泳馆和天然游泳场进行“双随机”抽查和整顿，并将检查结果向社会公开。9月份，局长徐德俊带队前往荔城区镇海街道镇海社区、拱辰街道办事处辰门兜小区、西天尾镇、城厢区龙桥街道太平社区等地检查体育健身设施使用情况,现场发放普法宣传传单并听取相关情况的汇报。

（四）转变政府职能，进一步创新和优化服务方式

深化体育行政审批和公共服务制度改革，做好已取消和下放体育行政审批事项的落实和衔接，强化放管结合，落实“双随机一公开”制度，重点加强对商业性和群众性体育赛事活动、高危险性体育项目经营活动的事中事后监管。规范行政审批和公共服务流程，进一步转变服务职能、优化再造流程和提升行政效能。全面推行审批服务“马上办、网上办、就近办、一次办”，增强企业和群众的改革获得感。我局把体育产业发展资金的审核、经营高危险性体育项目许可（潜水、攀岩、人工滑雪）、因特殊情况需要临时占用公共体育设施批准等3项列入“最多跑一趟”事项。把二级运动员等级审核、拆除公共文化体育设施或者改变其功能、用途的审核、二级社会体育指导员审批、举办跨县（区）健身气功活动批准等列入4项“一趟不用跑”事项，事项占比62.5%。实现了“一趟不用跑”和“最多跑一趟”事项100%覆盖。

（五）强化决策机制，完善体育部门信息公开制度

1.健全体育依法决策机制。按照制度科学、程序正当、过程公开、责任明确的要求，完善重大体育行政决策制度，进一步明确决策主体、事项范围、法定程序、法律责任。2018年我局聘请福建律海律师事务所陈明德律师为法律顾问，进一步提升局依法决策、依法办事的能力和水平。今年我局出台了《莆田市市级体育类社会组织管理暂行办法》、《莆田市体育产业发展专项资金评审实施办法》、《莆田市体育竞赛裁判员管理办法》（试行）等规范性文件。

2.推进“互联网+政务服务”。在政务服务大厅设立综合服务窗口，通过网上公开运行，我局共审批二级运动员89件。规范各类证照，取消了无谓的盖章环节和繁琐程序，不断提升公共服务水平和群众满意度。加强政务热线12345建设，目前办结事项26件，及时答复率和回复满意率都做到了两个百分百。

3.做好政府信息公开工作。按照“公开是原则，不公开是例外”政务公开要求和局政务信息公开制度，我局及时对政策法规、行政审批程序、违法案件处罚项目和标准等在官方网站上进行公开。利用政务公开栏、政府信息平台、爱尚运动电视栏目、莆田体育微信公众号等形式实施政务公开，力求做到公开内容全面具体、通俗易懂，及时有效。进一步增强了单位内部事务的公开性和透明度。截至11月底，在市政府公众门户网站上我局主动公开政务工作信息75条。

二、存在问题

一是法治政府建设的意识不够，依法行政、依法治体的理念树立的不够牢固。对法治政府建设工作的长期性、复杂性、艰巨性认识还不够深。二是法治队伍建设能力水平不高。执法队伍建设有待加强，执法人员的素质有待提高。三是法治政府建设宣传力度不大，普法宣传创新不够。

三、下一步工作

在今后工作中，一是进一步建设以《体育法》为核心，以国家和省级层面体育法律、法规、规章为基础，结合体育全方面工作，完善地方体育法规、规章，建立涵盖体育工作基本方面，层次分明、衔接配套的体育法律法规体系。运用法治思维和法治方式推进体育改革发展。二是继续加强法治队伍的建设，健全体育行政执法人员岗位培训制度，定期组织开展体育行政执法人员通用法律知识、体育法律知识、新法律法规等专题培训。三是加强对体育法律法规、体育部门法定职责的宣传，推动形成全社会支持体育部门依法履职的氛围。改进和创新执法方式，积极探索行政指导、示范服务、行政奖励等非强制执法手段，严格执行重大体育行政执法决定法制审核制度，未经法制审核或者审核未通过的，不得做出决定。四是积极探索体育市场管理的方式方法，切实把政府职能转变到为体育市场服务和创造良好的发展环境上来，把工作重点放到民生改善和公共服务上来，不断提升我局法治政府建设水平。

特此报告。
