莆田市体育局关于2018年莆田市少年儿童篮球、乒乓球比赛资格公示的通知

发布时间：2018-11-09 11:51
| | |

各县（区）体育行政主管部门：

2018年少年儿童篮球、乒乓球比赛报名工作已截止，现将参赛运动员资格进行公示，公示期为2018年11月2日至11月6日，具体附后。

公示期内，如对公示有异议，任何单位和个人均可以电话、书面或其他形式向局竞训青少办反映。以单位名义反映问题的，要加盖单位公章；以个人名义反映问题的，须署名或当面反映。

公示电话：（0594）2290157
