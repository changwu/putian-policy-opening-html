标题: 关于举办莆田市第十二届全民健身节的通知
发布时间: 2008-07-03 00:00
文号: 莆市体〔2O08〕29号
发布机构: 莆田市体育局
栏目: 竞技体育、体育产业等工作情况
原始链接: https://www.putian.gov.cn/zfxxgk/bmzfxxgk/ptstyj/zfxxgk/fdzdgknr/gzdt/200810/t20081006_1206322.htm
正文:
各县区文体局，管委会事业办:
根据闽体群[2 0 0 8]2 1号文《关于举办福建省第十二届全民健身节的通知》精神，经研究决定从2 0 0 8年8月2日奎6日止，举办莆田市第十二届全民健身节。市级活动开幕式拟定8月2日在市区举行。
一、指导思想
深入学习领会和贯彻落实党的十七大精神，以科学发展观为统领群众体育工作，紧紧抓住举办北京奥运会和全面建设小康社会的历史机遇，坚持以人为本深化和推进“全民健身与奥运同行"主题，以提高全民体育意识和健身意识，增强人民体质为目的，在全市城乡通过举办系列群众性体育活动和竞赛，进一步增强广大人民群众的全民健身意识，为北京奥运会成功举办营造浓郁的全民健身氛围。
二、全民健身节活动要求
1、通过组织开展全市群众性体育活动，坚持“有影响、有规模、有创意，群众喜闻乐见’’的原则，充分发挥各方面的优势，积极调动社会各方面的力量，整合资源、统一协调、扩大活动范围。拓宽活动内容，提升活动效果，把全民健身节作为一个平台，激发人民群众关注奥运，参与健身的热情，共同唱响“全民健身与奥运同行”主题。掀起我市全民健身活动的新高潮。
2、健身节期间各级体育部门要根据市里的统一部署、同步进行，突出“全民健身与奥运同行”主题，结合各自特点，组织开展具有地方特色的各类群体活动，充分发挥各行业、各体育社会团体开展健身活动的作用，形成多层面，多形式，贴近生活、贴近基层、贴近行业特点的全民健身氛围。
三、全民健身节的宣传
健身节期间，要加强与新闻媒体的合作，及时宣传报道各地“全民健身与奥运同行”活动的情况，介绍各地、部门行业开展全民健身活动的好经验、好做法和典型事迹，宣传科学健身、弘扬体育文化、扩大影响，宣传奥林匹克精神，为建设体育强市服务。
四、落实责任、确保安全
健身节期间，各县区、管委会、各部门要切实加强对健身节系列群体活动的统一领导，高度重视举办大型活动的安全工作，增强风险意识，提高防范能力。做到精心策划、严密组织，落实责任，确保健身节平安和谐。
五、开展评比表彰活动
省体育局将在第十二届健身节期间，评选出优秀组织奖、先进单位和先进个人(另行发文)，各县区、管委会要认真做好总结，发现典型，及时上报，以推动我市全民健身事业不断向前发展。
各县区文体局、管委会事业办根据通知要求，结合当前实际情况制定工作计划，统筹安排好本地区的全民健身活动，请单位将本地区2008年5月份至lO月份举办“迎奥运”全民健身系列活动安排以表格形式于7月10目前报市体育局群体科。
