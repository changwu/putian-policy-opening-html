莆田市体育局关于莆田市第四届运动会运动员资格注册及赛事承办申请等相关事宜的通知

发布时间：2017-03-14 00:00
| | |

各县（区、管委会）体育行政主管部门，莆田体育运动学校：

为了保障莆田市第四届运动会的顺利召开，确保办好赛事、进一步提升我市及各县（区、管委会）影响力、取得良好的社会效益，现将第四届市运会运动员资格注册及赛事承办申请等相关事宜通知如下：

一、市运会运动员资格注册事宜：

为规范市运会运动员管理，建立准确、完备的运动员信息管理系统，杜绝弄虚作假、冒名顶替参赛等不良现象发生，确保市运会赛事的公平公正，请各有关单位严格按照规定要求，认真做好市运会运动员年度注册工作。注册工作安排及相关要求如下：

（一）注册项目：《莆田市第四届运动会竞赛规程总则（青少年部）》设置的竞赛项目。

（二）注册人员：运动员参加第四届市运会，均要进行代表资格注册或确认，本次资格注册是运动员参加第四届市运会的依据。

（三）注册分工：各县（区、管委会）体育行政主管部门负责本县（区、管委会）所辖项目市运会青少年运动员注册基础数据信息的采集工作；市体育局负责注册运动员的身份、学籍等信息核查核实以及最终名单的公示与公布。

（四）运动员注册需提供的材料

1.二代居民身份证原件（临时身份证无效）；

2.参赛运动员注册表2份；

3.二代居民身份证和户口簿(首页、本人信息页)复印件各1份；

4.二代居民身份证和户口簿扫描件；

5.运动员本人采集指纹；

6.参赛运动员学籍卡；

7.照片：采用二寸彩色数码相片电子档导入系统，要求相片质量不低于20K，最大不超过150k，文件格式(jpg)，背景要求为红底，另冲洗2张贴入注册表；

8.运动员信息汇总表。

（五）注册时间安排及审核程序：

1.第四届市运会注册时间安排为3月27日-4月15日，此前为各单位采集注册运动员基础数据信息准备阶段。

2.3月27日开始市体育局将组织人员到各县（区、管委会）进行现场信息采集，请提供拍照、指纹采集的场所，派遣人员的食宿由各县区负责（各县区信息采集时间安排详见附表）。

3.4月16日-20日，市体育局对各单位提交的运动员注册信息、书面材料进行审核、整理。

4.4月21日-29日对运动员资格认定予以公示（请各县（区、管委会）提供公示的电子邮箱）。若有疑义，请及时反馈，超过时限，资格问题不再受理。

5.4月30日公布注册运动员名单。

（六）相关要求：

1.本周期已在福建省体育局成功申报注册并通过身份信息、学籍核查，认定合格的运动员并进行年度确认的，视为有效注册。

2.2017年度参加福建省体育局申报注册的运动员，以省局公布的合格名单为准，否则视为无效注册。

3.各注册单位应认真审核运动员注册资料和省局公示的名单，及时反馈相关信息，避免出现差错或无效数据导致无法确认等问题。在规定时间内未进行资格注册申请的视为放弃注册，运动员信息不全或资料有误的也将视为无效注册。严禁注册工作中弄虚作假、冒名顶替等不良现象发生，确保运动员注册工作顺利进行。

4.请各单位填好运动员注册表，备好注册相关材料并组织运动员到现场采集指纹、录入相关信息等。

二、申请承办市运会比赛项目（含资格赛）事宜：

根据《莆田市第四届运动会竞赛规程总则（青少部）（草案）》的规定，五个县区至少承办市运会3个项目的赛事（含资格赛及行业组篮球、拔河、象棋、气排球），北岸、湄洲岛至少承办市运会1个项目的赛事，用申请办法确定承办项目。承办一个项目奖励2枚金牌和相应所得分数带入各代表团奖牌数和总分。现征集各单位承办比赛项目意见（第四届市运会竞赛项目日程详见附表），请于3月31日前提交申请，并在申请确认后，做好赛事组织、实施、安保、交通和后勤接待服务等准备工作，确保赛事圆满成功。
