莆田市体育局关于市政协八届四次会议第20253023号提案的协办意见

发布时间：2025-04-09 16:26
| | |

市文旅局:

蔡立群委员提出的《关于借助免签政策，进一步推动莆田国际文旅发展的建议》（20253023号）已收悉，我单位的办理意见如下：

一、基本工作情况

近年来，市体育局紧扣市委市政府“1236”工作部署，以体育赛事为媒介，积极融入文旅发展大局，取得了阶段性成果。

一是国内国际赛事培育初见成效。已成功举办2024莆田马拉松、2024年海峡两岸大学生篮球赛、2024年海峡两岸体育嘉年华“妈祖杯”桥牌邀请赛、2024年湄洲岛“妈祖杯”全国风筝冲浪邀请赛等多项品牌赛事，吸引国内外选手及游客超万人次，赛事直接拉动餐饮、住宿、旅游消费超亿元。其中2024莆田马拉松评估结果显示，全网曝光率超3亿，为莆田市带来的综合经济效益为2.55亿元，其中直接经济效益为0.92亿元，带动旅游消费、文创制作等经济效益约1.63万元。在实地问卷调查中，总体满意率为96.67%，且80.27%的受访者有计划参加或观看下届莆田马拉松。二是构建文体旅场景。结合妈祖文化、南少林武术等本土资源，以“体育+文化+旅游”特色活动为契机，

赛事现场精心设置少林功夫、莆仙戏、舞龙舞狮、车鼓队等表演。赛道沿途串联妈祖祖庙、南少林寺等文化地标，让选手感受千年信俗与禅武合一的魅力。完赛终点及补给站特设莆田特色美食免费供应，奖牌设计融入妈祖、少林等莆田元素，夜间配套映像妈祖、缘起湄洲、武术等体验，打造集赛事、非遗、美食、观光于一体的沉浸式文体旅消费新场景。三是优化赛事服务。为全面提升赛事服务水平，在赛事现场配套莆田学院等高校志愿者指引，提供中英双语服务；深度融合人工智能（AI）技术，打造智能化互动体验新场景，观众可以与虚拟莆田历史文化人物进行实时对话，深入了解莆田的文化故事。通过精细化服务打造“参赛+旅游+文化体验”一站式服务，让国际选手成为莆田文旅的传播使者。

二、下一步工作计划

下一步市体育局将以过境免签政策为契机，以体育赛事为纽带，将重点推进以下工作，助力莆田建设“国际文旅目的地”。

（一）深化体育合作，扩大城市影响力。积极对接国内外社会组织，争取更多知名赛事落户莆田，依托赛事曝光提升城市国内外知名度。深化海峡两岸体育交流，升级海峡两岸大学生篮球赛、桥牌、马拉松等传统项目，融入非遗展示、民俗体验等环节，形成“体育+文化”品牌矩阵。

（二）优化赛事服务，提升接待能力。完善赛事多语种服务体系，加强赛事志愿者的专业英语沟通能力培训。在起终点、补给站等关键区域设置双语指引标识，配备便携式翻译设备，确保国际选手参赛无障碍。结合莆田特色，在赛事服务中融入妈祖文化元素，如提供妈祖平安符多语种解说卡片，在医疗站设置“妈祖应急包”等。

（三）强化宣传营销，拓展国内外市场。联动新媒体平台。策划“赛事+文化”活动。结合妈祖诞辰、莆仙戏等文化节点，举办非遗展演；利用“战神”刘玉栋影响力，开展篮球文化节及篮球明星见面会等配套活动，延长游客停留时间。
