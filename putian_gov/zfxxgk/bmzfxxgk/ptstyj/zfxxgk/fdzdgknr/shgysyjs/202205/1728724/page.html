莆田市体育局 共青团莆田市委关于莆田市体育工作志愿者队伍建设的通知

发布时间：2022-04-30 16:07
| | |

各有关单位：

为进一步提高莆田市公共体育服务水平，积极发挥体育服务社会、服务大众的作用，着力打造一支素质优良、结构合理、相对稳定的体育志愿服务专业队伍。经研究，决定建立莆田市体育志愿服务队，并依托“志愿汇”平台全面规范我市体育志愿者、志愿团队的注册管理和志愿服务记录工作，统筹各方志愿服务资源，开展各类体育志愿服务活动，形成各方支持、积极参与体育志愿服务的良好氛围。现将有关事项通知如下：

一、组织结构

莆田市体育志愿服务队在莆田市体育局和共青团莆田市委领导下开展工作，旨在经常性地组织开展志愿服务活动，全面推动莆田市体育志愿服务发展。

二、注册登记

（一）注册对象

1.体育志愿者个人：凡热心体育公益事业，有意参加并符合招募条件的全市干部职工及市民群众，均按注册要求进行体育志愿者登记注册并在“志愿汇”app首页“加组织”板块中申请加入所属县区的体育志愿服务队（操作手册详见附件）。

2.体育志愿者团体：市直各单位、市体育局直属各单位、各县（区、管委会）体育行政主管部门、各体育社会组织、企业、俱乐部要积极组织发动干部职工、体育社会组织会员、体育企业员工等符合条件的人员应报尽报，并在“志愿汇”app首页“加组织”板块中申请加入所属县区的体育志愿服务队。

（二）招募条件

　　1.身体健康，16周岁以上，常年在本市工作或生活；

　　2.遵纪守法，无不良嗜好，无违法违纪记录；

　　3.愿意用自己的时间、知识、技能、体能和资源，无偿为体育事业的开展提供志愿服务；

　　4.具备基本文明素质，富有爱心和奉献精神，团队意识强，具有较好的服从性、执行力，具备良好的沟通、活动实践能力；

　　5.具备与所参加的志愿服务及活动相适应的基本素质。

（三）开展注册

1.各县（区、管委会）体育行政主管部门负责属地体育志愿服务队的“志愿汇”平台组织注册、属地体育志愿服务队微信群创建等管理保障工作。市体育局负责市直及直属各单位体育志愿服务队的管理工作并汇总全市数据建立成库，实行定期更新，动态管理。

2.要完善登记管理制度，志愿者在“志愿汇”平台登记注册后需向属地体育行政主管部门邮箱报送《莆田市体育服务志愿者登记表》、《莆田市体育服务志愿者承诺书》和《莆田市体育服务志愿者汇总表》（团体申报时填报），并实名加入所属县区的体育志愿服务队微信群。

三、服务类别

（一）体育技能类志愿服务

1.在足球、篮球、排球、乒乓球、羽毛球、网球、田径、游泳、健美操、武术、跆拳道、气排球等项目拥有专业体育技能，开展体育公益知识讲座或培训，讲解体育健身知识和普及科学健身理念，推广体育锻炼方法传授体育技术技能；  

2.开展体育康复理论与实践，开展运动处方、运动损伤后的体育医疗与机能康复及常见病的体育康复等；

（二）综合体育类志愿服务

1.在体育赛事后勤保障、场地布置、会务礼仪、团队联络、现场医疗应急救护等方面开展志愿服务活动；

2.协助组织开展体育公园、全民健身路径等设施专项情况调査工作；

3.协助开展体育产业调研及大数据调查；

4.在体育宣传、文明礼仪、创城文明、网络文明等方面开展服务活动。

四、激励机制

（一）体育志愿者的志愿服务时间、绩效评价，统一经“志愿汇”平台确认，各属地体育行政主管部门负责定期登记管理。根据服务时间和绩效评价折算有效服务时间，有效服务时间累计达到一定时长，经体育志愿者本人申请，将按我市志愿者管理办法的有关规定给予表彰；

（二）依据体育志愿者的服务时间和服务业绩，视情每年开展“星级”体育志愿者评选活动，星级体育志愿者优先推荐参加各级社会体育指导员培训（食宿均免）；

（三）对表现突出的体育志愿者，通过多种途径予以宣传，并向媒体进行推荐；

（四）各体育社会组织、企业体育志愿者注册人数、年度服务时间和服务业绩等数据也将作为年度考评及申报各类项目的重要依据。

五、有关要求

（一）高度重视，加强领导。各县（区、管委会）体育行政主管部门要切实加强组织协调，完善落实机制，指定专人负责，规范有序地推进体育志愿者注册、管理工作。要科学制定体育志愿活动方案，找准服务项目，明确工作目标和重点，确保体育服务志愿者参加活动有途径、为民服务有方向、展示风采有舞台。　　

（二）加强宣传，广泛发动。要加大对体育志愿服务工作的宣传力度，充分利用新闻媒体、单位公示栏、手机短信等宣传阵地，宣传体育志愿服务的意义、作用，引导各年龄段人们自觉加入注册体育志愿者行列，努力形成人人参与体育志愿服务。

（三）规范管理，开展服务。经过注册的体育志愿者每年需参加一定时长的体育志愿服务活动，才能成为一名真正意义上的注册体育志愿者。各单位不仅要做好体育志愿者的注册工作，而且要把注册与体育志愿者招募、业务培训、活动组织相结合，充分发挥体育志愿者的应有作用，严格按照要求开展体育志愿服务。

六、其它事项

（一）莆田市体育赛事志愿者有违反国家法律法规，不遵守有关管理办法、规定，未履行志愿服务项目或利用志愿者身份从事任何营利和非法活动等情况，将取消其志愿者资格。

     （二）各县（区、管委会）体育行政主管部门于2022年6月24日前将第一批志愿者信息汇总上报市体育局办公室，电子版报送市体育局邮箱：ptty2005@163.com。自即日起，报名常年有效，各县（区、管委会）体育行政主管部门今后按每季度汇总报送。
