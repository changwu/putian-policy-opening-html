莆田市体育局关于2017年福建省城市社区全民健身场地设施建设项目实施方案的申报

发布时间：2017-03-24 00:00
| | |

福建省体育局：

根据省体育局《福建省体育局关于印发2017年城市社区全民健身场地设施建设项目实施方案的通知》（闽体〔2017〕73号）要求，我局组织人员对下设各县、区、管委会申报的建设项目进行实地考查，现将符合条件的经公示无异议后的申报单位上报，请予审批。

莆田市体育局
