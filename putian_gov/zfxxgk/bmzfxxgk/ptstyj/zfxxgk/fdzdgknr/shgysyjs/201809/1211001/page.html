关于推荐2018年度莆田市“老年人健身 康乐家园”的通知

发布时间：2018-08-30 17:37
| | |

各县（区）体育行政主管部门、文明办、民政局、老龄办、老体协，市直机关老体协： 

　　为进一步贯彻落实福建省体育局、中共福建省委文明办、福建省民政厅、福建省老龄工作委员会办公室、福建省老年人体育协会《关于推荐2018年度“老年人健身康乐家园”的通知》（闽体〔2018〕342号）文件精神，莆田市体育局、莆田市委文明办、莆田市民政局、莆田市老龄办、莆田市老体协决定：联合开展2018年度莆田市“老年人健身康乐家园”评选活动，与美丽乡村、幸福院、居家养老建设等有机结合，互动融合，共同推进，为推动基层创建“老年人健身康乐家园”工作扎实有效开展。现将有关推荐工作通知如下： 

　　一、推荐范围 

　　全市乡镇(街道)、行政村(社区)，市直单位基层单位。 

　　二、推荐条件 

　　申报莆田市“老年人健身康乐家园”要坚持标准，严格条件，择优推荐(具体标准和条件：附件1)。 

　　三、推荐名额 

　　根据各单位申报莆田市“老年人健身康乐家园”工作情况，市级级授牌总数60家左右，具体不作名额分配。由各单位根据申报条件严格推荐；市级将在推荐名额中择优选树。 

　　四、有关要求 

　　(一)做好自查自评。各级老体协会同同级体育行政主管部门、文明办、民政局、老龄办，按照推荐“老年人健身康乐家园”的“六有要求”，先行自查自评。推荐对象必须在各县区（管委会）、市直基层单位中能够起示范带动作用。 

　　(二)做好推荐材料报送。选推的“老年人健身康乐家园”要认真填写《莆田市老年人健身康乐家园推荐表》，同时提供一份2000字的创建工作总结，以电子版和纸质(加盖公章一式2份)于2018年9月底前报市老体协办公室。 

　　（三）各单位在申报莆田市“老年人健身康乐家园”的同时，可根据福建省体育局、中共福建省委文明办、福建省民政厅、福建省老龄工作委员会办公室、福建省老年人体育协会关于推荐2018年度“老年人健身康乐家园”的通知（闽体〔2018〕342号）文件（见附件4）要求，结合本单位实际情况，申报省级“老年人健身康乐家园”。 

　　特此通知。

　　附件1: 

　　2018年度莆田市“老年人健身康乐家园” 评选标准和条件 

　　一、有一个好的班子 

　　（一）有一位威望高、责任心强、热心老体协工作的好带头人。 

　　（二）有一个团结协作、勤奋敬业的好班子，班子成员热爱老年体育工作，善于调研协调，积极争取各级党政和社会力量的支持，热心为老年人服务。 

　　（三）有切实可行的工作安排，年初有计划，年终有总结，班子成员分工明确，各司其责，形成合力。 

　　（四）有一处功能适用的办公场所，具备基本的工作条件。 

　　二、有一支好的队伍 

　　（一）有一支健身指导员、辅导员和志愿者队伍，服务老年人科学健身活动。 

　　（二）乡镇（街道）、行政村（居委会）建有老年辅导健身站（点），有培训计划，有辅导员，积极培训、推广、普及老年体育健身项目，健身活动常态化。 

　　三、有一个好的经费保障机制 

　　（一）乡镇（街道）、行政村（居委会）老体协有相对固定的老年体育活动经费。乡镇（街道）每年安排不少于2万元，行政村（居委会）每年不少于5千元的活动经费。 

　　（二）争取企事业单位、社会各界的支持，形成多渠道、多层次、多形式的经费保障机制。 

　　四、有形式多样的活动载体 

　　（一）乡镇（街道）定期举办老年人体育健身大会，每年开展若干健身项目的展示交流活动。 

　　（二）利用节假日、纪念日、庆典日，开展与传统文化相结合的常态化的老年体育健身活动。 

　　（三）积极引进、推广普及多项老年人文体健身活动项目，挖掘、整理、创新传统体育健身项目，为老年人体育健身提供更多的项目选择。 

　　（四）以康乐大课堂等为载体，向老年人宣传科学健身知识，促进老年人身心健康。 

　　五、有功能适用的健身场地 

　　（一）“一室”。乡镇（街道）、行政村（居委会）建有老年人文体健身活动室。内设棋牌、乒乓球、台球等。有条件的乡镇（街道）、村（居）建有老年人健身活动中心。 

　　（二）“一场”、“一点”。室外建有若干个适合老年人健身的球类活动场所，有若干个满足老年人健身需求的晨晚练点和纳凉点（公园、广场、纳凉亭、纳凉椅等）。 

　　（三）老年人健身场地建设纳入城乡建设规划，与幸福院、美丽乡村同步建设，同步使用。 

　　六、有完善的管理制度 

　　乡镇（街道）、行政村（居委会）老体协有健全完善的管理制度，包括辅导员、志愿者队伍、场地设施管理制度，工作议事制度，学习培训制度，开展活动制度，财务管理制度等，各项职能和责任落实到位。

　　附件3: 

　　填写“推荐表”说明 

　　一、推荐的对象名称:是指被推荐授予“老年人健身康乐家园”的单位,即行政村(社区)、辅导站或乡镇(街道)老年人活动场所的名称。 

　　二、负责人、职务、电话、邮箱、编码、通信地址等均为被推荐单位的相关数据。 

　　三、推荐的对象应按“六有”要求,逐项简要说明,并附有图片、照片佐证。 

　　（一）班子建设情况。应明确去年以来党政班子或分管领导听取几次工作汇报,解决了哪些问题:老体协班子人员的结构如何;是否有固定的办公场所,面积多少,办公设备如何等情况。 

　　（二）队伍建设情况。应明确有无健身辅导站(点)、健身辅导员多少人,什么项目,获得哪级职称;健身队伍有多少,什么项目,多少人;去年以来组织了哪些项目的培训、培训了多少期、多少人等。 

　　（三）经费保障情况。应明确每年工作经费多少,活动经费多少，社会赞助多少等情况。 

　　（四）活动开展情况。是否有举办四年一届的老健会,设置多少项目、多少人参加;每年是否有2个以上健身项目的交流展示,什么时间、什么项目,多少人参加;是否有组队参加上一级或同级的友谊赛、联谊赛、邀请赛和各种交流活动等情况;获得各级的奖励如何,要罗列并附照片或复印件佐证。 

　　（五）场地建设情况。老年人活动中心(室)多少面积,内设项目和数量;室外有什么项目、面积多少(附场地照片)。 

　　（六）管理制度情况。主要有老年体育活动中心、健身辅导站，志愿者队伍、场地管理制度等,附照片佐证。 

　　四、县级单位推荐意见:应在被推荐的单位所在的县级体育行政主管部门、文明办、民政部门、老龄办、老体协共同研究审核后的意见,可同时盖章、亦可委托一个单位具体办理并盖章,说明清楚什么时间由哪些单位负责人参加研究,同意推荐上报的字样。 

　　五、填写推荐表要实事求是,不弄虚作假,认真负责。
