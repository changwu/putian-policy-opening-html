关于2017年市级全民健身体育设施项目 建设情况督查的通知

发布时间：2018-02-13 10:27
| | |

各县（区）体育行政主管部门：

为进一步做好我市2017年市级全民健身体育设施建设工作，确保为民办实事项目落到实处。经局领导同意，我局将成立督查组于2018年2月23日起对各县（区、管委会）2017年市级全民健身体育设施所有项目建设情况及2018年拟上报省、市级建设点进行实地核实，现将有关事宜通知如下：

一、 检查顺序和时间

检查具体时间详见附件

二、 检查组人员名单

李庆祥　郭建春　蔡鑫钦

 

三、检查内容

2017年市级全民健身体育设施所有项目建设情况，2018年拟上报省、市级建设点。

四、检查方式

听取汇报、查看资料（含招标资料）、实地核验

五、工作要求

各县（区、管委会）体育行政主管部门请提前上报检查路线，准备好相关检查资料，并派一名工作人员对接检查工作。市体育局群体办联系人：郭建春 13305942566，邮箱：pttyqtk@163.com。
