莆田市体育局关于市政协八届一次会议第2022081号提案“回头看”二次办理情况的答复

发布时间：2023-10-24 11:29
| | |
 民进莆田市委员会：

贵单位提出的《关于补齐全民健身供给短板 实现我市体育平衡发展的建议》（2022081号）已收悉，现将“回头看”办理情况函复如下：

近年来，在市委、市政府的正确领导和省体育局的精心指导下，以全民健身实施计划为抓手，加强部门协作、引导社会参与、推动全民健身向纵深发展。至目前，全市体育场地面积789.15万平方米，人均体育场地面积2.46平方米，参加体育锻炼的人数比例达42%，国民体质合格率达到92%。

一、全民健身工作情况

（一）履行政府职责，推动全民健身工作。发挥全民健身领导小组作用，不断增强全民健身工作发展合力。制定实施《莆田市全民健身实施计划（2021-2025）》，将全民健身工作经费列入到本级政府财政预算，强化各相关部门、单位履行发展全民健身事业的责任，做到有部署、有要求、有检查，从而在全市形成了上下联动、齐心协力促进全市全民健身事业蓬勃发展的工作格局。在全省率先部署开展体育助力乡村振兴工作，印发《莆田市体育助力乡村振兴工作实施方案》，将政策、资金、项目等资源向乡村倾斜，实现全市行政村体育健身工程全覆盖，通过“体育搭台，农事唱戏”，借助农民丰收节、采摘节等赛事活动契机，现场举办农副产品展销会，实现强村与富民双赢，让“体育+赛事+N”成为乡村致富的金字招牌。这一系列做法得到省体育局主要领导的批示肯定，并以文件形式在全省转发推广。

（二）完善体育设施建设，提升管理服务水平。把全民健身场地设施建设列入为民办实事项目之一，2022年以来，积极向上争取资金项目，认真谋划省、市为民办实事全民健身场地设施项目，共投入体彩公益金3397.8万元，新建3个智慧体育公园、9个游泳池、10个多功能运动场、9个笼式篮球场、8个笼式足球场、122套室外健身路径、95台室外乒乓球桌等。联合市住建局、市城市管理局联合制定《关于开展“国球进社区”“国球进公园”活动实施方案》，结合城镇老旧小区改造、完整社区建设试点、城市公园绿地开放共享和智慧体育公园等工作。认真做好公共体育设施免费或低收费开放工作，全市6座体育部门所属公共体育场馆免费或低收费服务健身群众年均达60万人次以上，全市所有公共体育设施均实现免费或低收费开放。扎实推进首批90所学校体育场地向社会开放，今年我市首批体育场地向社会开放的90所学校向社会开放。

（三）打造品牌影响，赛事活动出新出彩。2022年以来，我市以莆田市全民健身运动会为主平台，打造“全民悦动·活力莆阳”赛事活动体系，面向全市机关企事业单位征集赛事活动承办单位，在项目设置上问需于民，根据各承办单位的意愿选择群众喜闻乐见的项目给予政策、资金等支持，在承办方式上摆脱传统模式，推进“管办分离”，从“闭门办体育”到“开门办体育”，构建覆盖全体市民的市、县（区、管委会）、街道（乡镇）、村（社区）四级赛事体系，推动各界人群广泛开展体育活动，提高市民体育健身的参与度。通过结合农民丰收节、莆田荔枝、龙眼、枇杷、文旦柚等四大名果及南日鲍鱼节、紫菜节等特色节日文化等契机，策划举办了中国·南日岛全国海钓邀请赛、2023年美丽中国全国门球大赛（福建莆田站）、“妈祖杯”海峡两岸桥牌邀请赛、海峡两岸大学生联赛（莆田站）、福建省全民健身运动会莆田市“爬龙船”民俗赛事活动启动仪式等258场市级及以上级别群众性赛事活动，参与人次达到6万余人。

（四）完善服务体系，增强全民健身组织保障。莆田在全省率先将社会力量引入群众体育赛事活动筹办，通过政府购买服务的方式，面向体育社会组织、企事业单位购买赛事服务。组织了如莆田市建党100周年全民健身展演活动、“运动健身进万家 居家锻炼抗疫情”莆田市全民健身运动会线上系列活动、莆田市机关企事业单位篮球赛等，吸引了超过5万人积极参与，打响“全民悦动 活力莆阳”等形式多样的全民健身活动品牌。积极引导成立莆田市冰雪协会、莆田市掼蛋运动协会等新兴协会，发动社会力量开展健身指导、举办体育赛事活动，市广场舞协会、市健美协会、市太极协会等体育社会组织免费为体育爱好者进行广场舞、动感单车、太极拳等体育项目的专业技能指导。2022年，“社区服务暖民心 串起邻里心连心”体育志愿服务项目，成功入选国家体育总局评选的2022年全民健身志愿服务项目库。举办二级社会体育指导员培训班，提升社会体育指导员业务素质和服务水平，进一步健全公共体育服务体系，2022年以来共举办1场2期，培训审批二级社会体育指导员136人，向上推荐参加一级社会体育指导员培训5人、国级社会体育指导员培训15人。

（五）加强体育宣传力度，营造浓厚全民健身氛围。充分利用互联网和新媒体平台，积极发动群众通过“两微一端”、公众号、APP等方式宣传赛事、参与赛事，持续不断举办莆田市全民健身运动线上系列活动、“奔跑吧·少年”线上健身活动等形式多样、覆盖全年龄段、便于群众参与的线上全民健身赛事活动，吸引了近3万人参与，掀起了全民健身新热潮。指导市级体育社会组织发动协会内部专业健身教练及社会体育指导员参与，录制电视专栏节目《居家健身一起动起来》16期，推出瘦身、瑜伽、太极拳等网络公益直播教学12项等。

下一步，市体育局将坚持“以人民为中心”的幸福理念，牢固树立争先创优导向，强化体育品牌创建，提升全市体育发展质量和效益。

最后，再次衷心感谢您对体育事业的关心和支持，欢迎多提宝贵意见！
