莆田市体育局关于政协八届一次会议第2022172号提案“回头看”二次办理情况的答复

发布时间：2023-10-24 11:19
| | |

郑黎霞委员：

　　您在2022年莆田市政协八届一次会议提出的《关于增加公共场所青少年、儿童户外健身器材的建议》（第2022172号）已收悉，现将“回头看”办理情况函复如下：

　　一是合理规划青少年体育场地设施。按照《莆田市全民健身实施计划（2021-2025）》要求，均衡分配、规模适当、便民实用、因地制宜的原则，科学规划各级各类全民健身设施建设，加强全市青少年儿童体育设施规划和建设，将儿童青少年体育设施建设纳入全民健身范畴，近年来全市共建设有多功能运动场141个、笼式足球场48个、室内健身房55个、室外健身路径504套、笼式篮球场14个、游泳池5个、门球场8个、室内外乒乓球场295个、二代室外智能健身路径7套、气排球场4个、地掷球场6个、智慧体育公园7个、全民健身中心2个、社会区健身中心1个、党建+社区（乡村）邻里中心21个等共1118个健身场地设施。2023年我局争取省级资金740万元，建设１个智慧体育公园、４个游泳池和3个多功能运动场，市级投入资金736万元，建设7个多功能运动场、5个笼式篮球场、2个笼式足球场、62套室外健身路径、35台室外乒乓球，以及在荔城区西天尾镇溪白村建设少儿智能公共体育设施，开辟少儿运动区域，进一步为儿童青少年提供丰富、便利的健身活动场所。

　　二是加大力度开放公共体育场地设施。目前，我市共有2个大型体育场馆（莆田市体育中心、莆田市综合体育馆）、4个中小型体育场馆（莆田市游泳馆、莆田市体育训练基地网球馆、仙游县体育中心、涵江区体育场）、2个全民健身中心（莆田市全民健身中心、仙游县全民健身中心）对所有青少年实行免费、低收费开放。根据《福建省教育厅等六部门关于印发〈学校体育场地向社会开放管理指导意见〉的通知》（闽教体〔2022〕20号）文件精神，我局积极协同教育部门，推动全市首批学校体育场馆与公共体育场馆双向开放，为青少年儿童健身提供便利，有效缓解广大青少年日益增长的体育健身需求与体育场馆资源供给不足之间的矛盾。

　　三是建立健全我市青少年竞赛体系。广泛动员街道（乡镇）、社区、学校、体校、青少年体育俱乐部，利用体育中心、各类体育场馆、公园和社区空间等公共场地资源，举办“奔跑吧·少年”儿童青少年主题健身活动，推动形成政府主导、部门协同、社会参与、深入基层的长效机制，实现活动长流水、不断线、贯穿全年。线上通过公众号等平台举办健身打卡、线上运会比拼、体育教学、云端分享、平台投稿活动，线下结合市中小学生联赛、市锦标赛、各项技能展示、竞赛、健身科普以及家庭亲子活动等青少年体育赛事活动，营造崇尚体育、热爱运动、健康向上的良好氛围。2022年共开展“奔跑吧·少年”儿童青少年主题健身活动暨“居家健身，同心抗疫”线上健身活动、“菁英少年”校外运动俱乐部交流赛等系列赛事活动67场次，覆盖全市54个乡镇300多所学校,参与人数约10万人。同时，建立完善赛事活动体系，打通青少年儿童从校园到全国赛事的通道等。

　　四是拓宽资金渠道，保障运转管理。近几年市体育局积极争取各级财政资金，发动社会资本参与，累计投入资金15亿元，建成了智慧体育公园、全民健身中心、多功能运动场、笼式篮球场、社会足球场、室外健身路径、室外乒乓球桌、健身步道等一批公共体育健身设施，加大了全民健身场地设施建设的投入，出台了《莆田市公共体育设施运营和维护管理办法》，加强设施维护与管理力度。同时，运用国家总局全民健身信息服务平台器材填报系统建立长效管理机制和动态数据库，提升器材管理智能化水平和工作效率，不断完善全民健身场地设施运营和维护管理办法。

　　最后，再次衷心感谢您对体育事业的关心和支持，欢迎多提宝贵意见！
