关于市政协八届三次会议第20242042号提案办理情况的答复

发布时间：2024-07-12 10:13
| | |
农工党莆田市委员会:

你们提出的《关于进一步激活我市体育消费市场的建议》（20242042）已收悉，现将办理情况函复如下：

一、盘活城市“金角银边”，完善场地设施供给。积极争取资金项目，认真谋划省、市为民办实事全民健身场地设施项目，2023以来，共投入资金2283万元，建设4个游泳池、1个智慧体育公园、14个多功能运动场、笼式篮球场5个、笼式足球场4个、室外健身路径93套、室外乒乓球桌75台、社区智慧“运动角”3个等。2023年，完成首批90所学校体育场地向社会开放。2024年，推进39所新增学校体育场地向社会开放。

二、壮大体育指导员队伍，提高科学服务质量。2023年以来，共培训二级社会体育指导员179人，一级社会体育指导员10人、国级社会体育指导员培训10人。以莆田市全民健身志愿者服务队为主旗帜，组织成立莆田市全民健身志愿者服务队，积极发动市级体育社会组织500余名拥有体育运动项目专业技能人员加入志愿者队伍，开展各种经常化的全民健身志愿者服务活动。更新体质测试设备，定期联合体育企业、社会组织、体育教师共同推进国民体质测试公益行活动进学校、进企业、进社区，2023以来共开展国民体质监测志愿服务20场。多渠道宣传推广科学建设视频，策划“奏响休闲体育奋进曲 激发消费活力”为主题的体育产业宣传公益宣传片，鼓励更多人参与体育活动中，促进体育消费。

三、丰富体育赛事活动，激发体育经济消费。2023年，我市共举办品牌赛事省、市、县29项，参赛人数19209人次，现场观赛人数约36.9万人次，赛事总投入3257万元，带动消费约1.88亿元。品牌赛事在撬动社会资金上位列全省第三，在赛事总投入及带动消费上位列全省第五。2024年，将围绕“全民悦动·活力莆阳”赛事体系，结合新中国七十五周年、习近平总书记亲自擘画推动木兰溪治理二十五周年、全民健身日等节点以及体育赛事进景区、进街区、进商圈等工作，联动市直有关部门、县区（管委会）和社会组织，组织策划木兰溪健康跑、“王文教杯”羽毛球公开赛莆田分站赛、海峡两岸大学生篮球赛、“妈祖杯”海峡两岸桥牌邀请赛、莆田市“百村千场”和美乡村篮球赛、中国·南日全国海钓邀请赛、福建省自行车联赛（仙游站）、仙游马拉松赛暨福建马拉松联赛（仙游站）、妈祖（湄洲岛）女子半程马拉松、莆田木兰溪马拉松妈祖以及全民健身日系列赛事等200余场赛事活动，赛事覆盖了老、中、青、少各个年龄层。同时积极探索“体育+融合”，充分融合莆田旅游资源、文化遗产、党建交流、农副产品等资源，促进了体育与农业、旅游、文化等融合发展，将赛事活动带来的“流量”转换为经济的“增量”，促进产业联动消费，为莆田经济高质量发展贡献体育力量。

四、完善政策措施，优化体育市场环境。一是积极推进体育领域安全行动、法治建设，出台了《莆田市体育局安全生产治本攻坚三年行动方案》《莆田市体育局关于全面推行行政执法公示制度执法全过程记录制度重大执法决定法制审核制度的通知》等文件5份，重点对体育赛事活动、高危险性体育项目、体育经营性企业、海上船舶等方面进行检查，上半年运用闽执法平台开展体育条线行政检查34次，排查整治安全风险隐患12个，现所有问题均已整改到位。为满足人民群众体育锻炼需要提供了坚实法治保障。二是积极对接服务体育企业，沟通统计局、商务局等相关部门，为企业提供简单明了、方便操作的申报指南，成功助力四季体育休闲小镇有限公司升规纳统。三是为持续优化企业营商环境，2024年印发了《莆田市体育局关于公布2024年莆田市体育服务业“白名单”企业的通知》文件，更新了体育服务业“白名单”企业17家，并将相关企业名单报市发改委、市金融办等部门，以便“白名单”企业及时享受政策性融资担保等相关惠企政策。
