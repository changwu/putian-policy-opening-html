根据市委专题会议纪要〔
2017
〕
24
号精神，滑雪馆、滑冰馆为社会事业文体项目，冰雪小镇体育休闲旅游项目建设采用
EPC+PPP
模式实施，由市体育局作为项目实施机构和项目合同签约主体交负责组织专家于
2018
年
1
月前完成项目体育场馆室内功能布局设置论证。根据市政府专题会议纪要〔
2018
〕
10
号精神，冰雪小镇体育休闲旅游项目
PPP
所需的“两评一案”及招标代理同意由实施机构市体育局按规定程序委托福建省招标采购集团有限公司。为推进项目建设，经局党组研究，决定成立冰雪小镇体育休闲旅游项目（冰雪运动场馆项目）服务小组。现将相关事宜通知如下：

二、服务小组工作职责
(一
)
会同财政局等相关部门组织编制项目
PPP
实施方案，并报请市政府批准；
(二
)
协调各部门讨论项目实施方案并定稿；协调相关部门完成设计方案审查、施工图设计与审查、预算编制与财审工作；
(三
)
作为招标人组织社会资本的招标工作；
(四
)
负责项目功能、定位论证，对接总局及冬奥组委会等工作事宜；
(五
)
协助项目公司办理工程开工建设的前期审批手续及建设过程中的相关手续以及档案收集归档、宣传报道等工作；
(六
)
牵头组建询价小组；
(七
)
对社会资本及项目公司的履约情况实施监督；
(八
)
组织参与工程竣工验收；
(九
)
牵头组建考评小组对项目公司进行建设考核和运营考核；
(十
)
落实莆田市冰雪小镇体育休闲旅游项目指挥部交办事项及工程建设、运营日常联系、协调、督促、检查等工作。
