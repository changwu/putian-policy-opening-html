关于加强所出资企业用工管理工作的通知

发布时间：2011-03-28 00:00
| | |

 

各所出资企业：

为加强对市国资委所出资企业（以下简称企业）用工管理，规范用工行为,依据《中华人民共和国劳动法》、《中华人民共和国劳动合同法》、《中华人民共和国公司法》、《中华人民共和国企业国有资产法》和《福建省劳动合同管理规定》等有关法律法规，现就企业用工管理工作有关事项明确如下:

一、用工原则

（一）坚持精干高效与提高素质相结合的原则；

（二）坚持总量控制与企业用人自主权相结合的原则；

（三）坚持公开公正与择优录用相结合的原则；

（四）坚持能进能出与全员劳动合同制相结合的原则。

二、用工条件

企业聘用管理岗位人员，应具备大学及以上学历或者具有相应执业资格，年龄原则上应在35周岁以下，且符合岗位需要的专业等条件要求的人员中聘用。

企业聘用技术岗位人员，一般应具备大专及以上学历、相应技术职称和年龄40周岁以下，且符合岗位需要的专业技术等条件要求的人员中聘用。特殊技术岗位和特别人才可适当放宽条件。

企业聘用一般岗位人员，原则上应在具有大专及以上学历或者具有相应执业资格，且年龄一般在30周岁以下的人员中聘用。

其他条件可由企业根据岗位特点、有关规定和实际需要确定。

三、用工方式

企业用工须实行全员劳动合同制，与所有员工签订劳动合同。

企业应根据行业性质、岗位特点和招聘条件，可分别选择以下3种聘用方式组织实施：一是面试聘用，适用于企业普通职工聘用；二是考核聘用，适用于企业专业性较强的工程技术、金融财务、企业管理等岗位的职工聘用；三是引进人才，适用于企业急需引进的中高级职称专业人才、硕士以上高学历人才或有相应岗位工作特长的专门人才，年龄一般不超过40周岁。

鼓励企业在招聘过程中有条件或条件比较成熟的，采取竞争上岗或引进人才的方式组织招聘，尽可能引进、聘用具有高学历、高职称、高技能的专业人才。

四、用工审批

（一）用工计划审批。企业用工应根据企业生产经营的实际需要，于每年年底前提出次年度用工计划，填写《莆田市国有企业 年度用工计划呈报表》，报市国资委研究审批。

（二）人员调动审批。企业除本集团（公司）内部人员调整外，企业员工调动均应报市国资委审批。

（三）引进人才审批。企业对拟引进专业岗位人员的基本情况经初审、研究后，填写《莆田市国有企业引进人才审批表》，并附其个人简历及相关材料等，报市国资委研究审批。

五、用工管理

（一）用工计划管理。企业用工实行计划管理，市国资委根据企业经营状况和实际需求实行宏观调控，年度用工计划总量审批控制，并指导企业做好用工工作。企业在组织招聘前，应将本次招聘计划、招聘条件、招聘方式、招聘简章等资料报市国资委备案；在组织招聘时，可根据实际需要，采取分期分批招聘的办法，由各集团（公司）自行统一组织实施，从而规范企业用工行为。

（二）用工合同管理。企业应按规定由各集团（公司）与所有的职工签订劳动合同，用劳动合同来确立企业与职工的劳动关系。在签订劳动合同时，企业应根据岗位和人员等实际情况设定试用期限，除项目用工外一般应确定劳动合同期限，不得与新聘用的员工签订无固定期限劳动合同。企业员工除名、解聘、辞退等应及时解除或终止劳动合同，并报市国资委备案。

（三）用工岗位管理。企业接收政策性安置人员，按有关规定执行，由市国资委审批。特殊工种岗位和国家规定应持证上岗的技术工种岗位，企业不得聘用未取得执业资格证书的人员。企业总工程师、总会计师、财务主管等岗位，原则上应具有大学及以上学历和本专业中级及以上技术职称，由市国资委审批、任免。

（四）人员档案管理。企业应加强员工档案管理，建立健全组织人事档案资料和档案管理制度，及时建立人力资源管理台账，包括企业人员花名册和员工动态档案、纸版档案、电子版档案等，并报市国资委备案。今后，各所出资企业实行人事季报和年报制度，企业新聘用的职工不得再有“干部”和“事业”等身份，并在签订劳动合同前将拟新聘用职工的《莆田市国有企业聘用职工审批表》一式四份报市国资委审核备案，以便于规范企业员工档案管理。

（五）工资档案管理。企业应建立健全工资管理制度和办法，建立职工个人工资管理档案等，并报市国资委，由市国资委实施监管。今后，企业员工工资调整和新聘用员工工资标准等，须及时报市国资委备案，以便宏观统计、分析和管理。

市国资委转授权管理的所出资企业和国有控股公司适用于本通知。国有参股公司可参照本通知执行。

 

 

二0一一年三月二十二日
