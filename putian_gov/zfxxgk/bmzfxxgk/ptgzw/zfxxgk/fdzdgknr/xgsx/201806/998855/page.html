关于印发《莆田市国资委2018年度绩效管理工作方案》的通知

发布时间：2018-06-11 09:44
| | |

本委各科室、下属机构：

根据《中共莆田市委办公室 莆田市人民政府办公室关于印发<2018年度绩效管理工作方案>的通知》（莆委办〔2018〕30号）精神，结合本委工作实际，经研究，现将《莆田市国资委2018年度绩效管理工作方案》印发给你们，请结合工作实际和岗位职责，认真贯彻执行。

 

 

 莆田市人民政府国有资产监督管理委员会  

                       2018年6月10日

莆田市国资委2018年度绩效管理工作方案

 

为深入贯彻习近平新时代中国特色社会主义思想和党的十九大精神，有力促进市委、市政府决策部署的落实，激发各科室及下属机构勇于担当、真抓实干，奋力完成赶超任务，打造宜居港城、建设美丽莆田，创建美丽中国的示范区，现就本委2018年度绩效管理工作制定如下方案：

一、组织领导

为加强对机关绩效管理工作的组织领导，由莆田市国资委机关效能建设领导小组负责绩效管理工作的组织领导、管理协调、动态分析和实时评估等工作。组长由本委主任林素琼担任，副组长由本委分管领导谢仙满担任，成员由各科室负责人组成，下设办公室挂靠委办公室。

二、考评对象

各科室、下属机构及干部职工（以下简称干部）。

三、考评内容

坚持目标导向、过程导向、结果导向，紧紧围绕“再上新台阶、建设新福建”和创建美丽中国示范区的目标，将市委、市政府关于高质量发展与实现赶超有机统一起来的各项决策部署，以及防范化解重大风险、精准脱贫、污染防治三大攻坚任务，实化细化为具体考核指标，推动各科室有针对性采取措施，促进全市经济社会持续健康发展。重点考核业务实绩、自身建设、机制创新三项内容。

1．业务实绩方面：（1）贯彻落实市委、市政府的决策部署情况；（2）2018年省政府工作主要任务、市政府工作主要任务、国民经济和社会发展计划主要指标、为民办实事项目、效能工作要点等落实情况。推行任务落实“负面清单”管理，对市委市政府文件、纪要议定的有明确时间节点的事项，逾期5个工作日未落实的，各科室要实时梳理并列入“负面清单”，强化跟踪落实，按月报送进展情况，委效能办对科室“负面清单”进行重点“滚动”管理、跟踪督办。

2．自身建设方面：主要围绕依法行政、高效行政、民主行政、廉洁行政4个方面进行考核。

3．机制创新方面：每个科室要力争创出1至2项特色、亮点工作，年底报送1项最具有创新性、示范性、推广性的工作参加市效能办的集中评审。

四、考评方式

采取指标考核、公众评议、正向激励、效能督查、省对市考核指标排名情况运用相结合的方式进行。

    （一）指标考核

委效能办根据市委、市政府对我委绩效考评的10个一级指标、22个二级指标，进行责任分解（具体指标及责任分解详见附件），制定绩效管理工作方案，于2018年6月10日前报送市效能办备案。委效能办要建立工作台账，对市委、市政府下达的实质性目标任务落实情况进行常态化跟踪管理并建立“负面清单”，从6月份起按月报送。

    （二）公众评议

由委政治处结合年度考核民主测评适时开展。

    （三）正向激励

鼓励各科室（干部）马上就办、真抓实干，卓有成效完成各项任务，争取在全国、全省名列前茅，或受到上级表扬肯定。科室（干部）工作任务在全国、全省名列前茅，或受到上级表扬肯定的，予以正向激励加分，加分累计不超过6分。委效能办要对正向激励事项进行常态化“滚动”管理、按月梳理报送市效能办，市效能办将不定期进行抽查、通报（具体计分办法由市效能办另行制定）。

（四）效能督查

委效能办结合日常效能督查，采用随机抽查、问题核查、明察暗访等方式，定期不定期组织开展效能督查。发现的问题经核属实的，以倒扣分形式计入绩效考评总分，扣分累计不超过6分。

五、结果汇总与运用

（一）结果汇总

绩效考评得分=指标考核得分×70%＋公众评议得分×30%＋正向激励加分－效能督查扣分

（二）等次确定

1.考评结果分为优秀、良好、一般三个等次。按绩效考评得分高低排列，优秀等次控制在30%（含）以内，一般等次控制在10%（含）以内，其他的为良好等次（具体等次比例由委主任办公会议根据考评得分研究确定）。

2．符合下列情形之一的科室（干部），直接评为优秀等次（直接评为优秀等次的人数超过干部总数10%时，按绩效考评得分高低排序）：

（1）受到厅级以上单位表彰（表扬）、推广或领导批示肯定。

（2）在建设美丽莆田工作中成效显著。

（3）负责市对我委年度绩效考评评为优秀等次。

3. 出现下列情形之一的，不能评为优秀等次：

（1）《建设美丽莆田2018年行动计划》重点任务（30大攻坚项目、20项重点工作）严重滞后。

（2）受到党政纪责任追究（含组织处理、诫勉谈话）、效能问责；

（3）年度请病假累计超过2个月。

（4）年度请事假累计超过22个工作日。

（5）存在旷工问题。

4.在绩效管理工作中弄虚作假，造成严重后果的，考评等次定为一般。

（三）结果运用

1.通报考评结果。绩效考评结果在全委进行通报。

2.挂钩考核评定。绩效考评结果作为单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。

（1）在当年度省对市绩效考评任务落实、市本级绩效考评等工作中表现突出的一线干部，报市机关效能建设领导小组予以通报表扬。

（2）评为一般等次的个人，一年内不推荐评先评优、提拔任用。

3.实行绩效奖励

（1）优秀等次、一般等次分别按照良好等次个人绩效奖金的1.2倍、0.5倍发放绩效奖金。

（2）凡受到党政纪责任追究、效能问责的人员，年度考核被评为不称职（不合格）的人员，被市委、市政府、市效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假累计超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病事假超期人员标准的5倍减发绩效奖励。

4. 实施效能问责

（1）年度绩效考评结果为一般的科室（科级及以下干部），责成其向委机关效能建设领导小组提交书面整改措施。

（2）省、市效能督查发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫（含）以上处理，对科室负责人进行通报批评，存在突出问题的对委分管领导进行诫勉教育。

5．反馈整改。各科室要针对市效能办对本委绩效考评中发现的问题，认真分析研究，查找薄弱环节，深刻剖析原因，制定整改措施，促进绩效提升。市效能办将结合“一季一督查”对整改情况进行“回头看”。

五、实施步骤

（一）制定方案，动员部署（2018年6月1日-6月10日）

按照《2018年度莆田市绩效管理工作方案》要求，认真研究制定《莆田市国资委2018年度绩效管理工作方案》，明确目标任务和责任分工。组织全委干部职工认真学习绩效管理工作有关会议精神和文件规定，充分认识开展绩效管理工作的重要性和必要性，切实增强做好绩效管理工作的积极性和自觉性，扎实推动工作开展。

（二）组织实施，常态管理（2018年6月1日-12月31日）

建立工作台账，对市委、市政府下达的实质性目标任务落实情况进行常态化跟踪管理并建立“负面清单”，加强日常跟踪督促，推进工作落实到位。各科室要认真梳理本科室的目标任务，注意日常相关资料的收集、分类和存档，并于每个月15日之前向委效能办报送各自负责的市委、市政府下达的实行性目标任务落实情况的“负面清单”。对未按序时进度完成、进度不够明显的工作指标，要注意分析存在的问题及原因，及时采取有效措施加以推进，确保我委各项绩效工作指标保质保量完成。委效能办要及时汇总各科室绩效目标工作台账并公开。

（三）内部考评，整改提升（2019年6月1日-6月30日）

市对我委绩效考评结果出来后，结合考核组反馈的情况，委效能办组织对委内部各科室（干部）的差异化绩效考评，考评结果报主任办公会议研究确定。各科室要针对绩效考评反馈存在的问题和不足，及时进行深入分析，查找问题症结原因，制定整改措施，推动全委工作科学化水平进一步提升。整改情况纳入下一年度绩效考评。

六、工作要求

（一）统一思想认识。党的十九届三中全会作出了《中共中央关于深化党和国家机构改革的决定》，明确要求严格绩效管理。本委各科室要把严格绩效管理作为促进市委、市政府决策部署落实的重要举措，作为打造宜居港城、建设美丽莆田，创建美丽中国的示范区的重要保障，作为实现高质量发展和赶超目标的重要抓手，摆上重要议事日程。各科室负责人是本科室绩效管理工作第一责任人，对本科室的绩效管理工作负总责，要指定专人负责绩效考评工作，要经常分析绩效指标进展情况，加强过程监控，确保全面实现年度绩效目标。全力争取在全市绩效考评中取得优秀等次。

（二）强化统筹协调。委机关效能建设领导小组及其办公室要充分发挥组织协调作用，统筹协调相关科室，做好各个环节的衔接，提升整体工作合力。机关效能建设领导小组办公室每月定期研究分析绩效考评指标进展情况，查找不足，及时改进，并对滞后事项建立“负面清单”进行跟踪管理、倒逼落实。（三）强化结果应用。各科室要以严谨细致、务实求效的作风共同做好绩效管理工作，做到资料真实完整，数据准确可靠，“负面清单”规范有序。要坚决防止和克服形式主义，坚决制止马虎应付、弄虚作假现象。
