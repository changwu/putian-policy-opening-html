关于开展“整治庸懒提效率、马上就办优服务”活动的实施方案
为深入贯彻落实《印发关于开展“整治庸懒提效率、马上就办优服务”活动实施意见的通知》（莆委办〔
2013
〕
41
号）的精神，进一步转变机关作风，改善行政管理，提高机关效能和服务质量，增强政府的公信力和执行力，营造更加宽松和谐的发展软环境，决定在全委开展“整治庸懒提效率、马上就办优服务”活动
,
特制定如下实施方案。
一、指导思想
以党的十八大精神为指导，深入贯彻落实中央和省市关于改进工作作风的各项规定，以整治庸懒、马上就办为着力点，以提高效率、优化服务为关键点，以问题解决、群众满意为落脚点，进一步改进工作作风，深化机关效能建设，努力建设行为规范、运转协调、公正透明、廉洁高效的机关形象。
二、工作任务
通过开展专项活动，着力解决机关工作人员作风方面存在的“四个突出问题”，切实达到“四个确保”的目标要求。
（一）解决不思进取、庸碌无为的问题，确保服务意识明显提升。
着力解决因循守旧，工作起点低、标准低，缺乏力争上游、敢为人先的创先争优意识问题；懒惰消极，得过且过，不主动学习，习惯于凭老经验办事，遇到问题简单地说“不行”，不去考虑和研究“怎样不行”的消极被动问题。
（二）解决有令不行、有禁不止的问题，确保执行能力明显提高。
着力解决对上级的决策部署、工作安排过分强调客观理由，讨价还价的问题；不经请示汇报，擅自搁浅，或者于已有利的就落实，不利的就不落实的问题；敷衍应付，在贯彻执行决策部署上打折扣、做选择、搞变通的问题。
(
三
)
解决服务不优、权力失范的问题，确保行政行为明显规范。
着力解决审批下放不到位、审批环节多、手续繁琐，时限过长，特别是项目审批中生搬硬套相关法规，互为前置的问题；进驻中心的窗口授权不充分、不到位和体外循环的问题；没有严格执行行政自由裁量权，“同案不同罚”、“畸轻畸重”等问题。
(
四
)
解决衙门作风、官僚主义的问题，确保行政效能明显转变。
着力解决无组织、无纪律，上班无故迟到、早退、旷工、脱岗的问题；工作期间上网聊天、“逛”网店、玩游戏、看影视、炒股票等问题。
三、活动内容
(
一
)
集中学习自查，促进思想认识再提升
1
．集中学习讨论。
结合开展以“为民、务实、清廉”为主要内容的党的群众路线教育实践活动，每两周集中人员组织一次学习，学习近年来中央和省市关于加强作风建设的一系列部署要求，重点学习《中央改进工作作风、密切联系群众的八项规定》、《关于推动“马上就办”促进投资环境改善的意见》（闽效综【
2012
】
5
号）、《福建省机关工作人员效能问责办法》（闽委办发【
2012
】
15
号）等文件，并结合实际深入研究探讨，创造性地贯彻落实，推动本委工作人员树立“马上就办”理念，使“马上就办”成为行政自觉和良好作风。
2
．深入查摆整改。
通过走访群众、入企访问、召开座谈会、发放征求意见表、网上问卷调查等形式广泛征求服务对象、基层群众和社会各界的意见建议，找准本单位作风方面存在的不足和群众反映的突出问题。在此基础上，进行“五查五看”：一查工作理念，看是否把“人民”二字放在心中，强化“马上就办、办就办好”的意识；二查工作程序，看是否环节简化、流程规范、时限合理：三查工作作风，看是否办事拖拉、推诿扯皮、超时办理；四查工作实效，看是否效率提高、服务到位、群众满意；五查工作机制，看是否职责明晰、运作顺畅、奖优罚劣。对梳理出的问题，要建立台账，制定措施，抓好整改。
3
．营造工作氛围。
在莆田市国资委网、莆田廉政网共建平台上开设“马上就办”活动专栏，及时在专栏上公开相关工作措施、查摆整改情况，并总结、提炼、宣传好做法好经验，进行实时动态宣传。
（二）推行马上就办，促进管理服务再提质
1.
转变市级行政审批项目管理方式。
根据市政府《关于公布市级行政审批项目清理结果的通知》（莆政综
[2012]155
号）精神，取消监管企业工效挂钩方案审批项目，对取消的审批项目，进一步强化服务和监督措施；原五项审批项目从行政审批转为一般管理类。按照全面推进服务政府、责任政府、法治政府建设的要求，本委继续深化行政审批制度改革，着力提高机关办事效率，通过进一步优化审批流程、创新服务、提高效能等一系列措施，努力实现行政审批方式向一般管理和主动服务的转变。
2.
缩短工作时限。
本
委涉及转变管理方式的审批项目共有五个，分别是企业国有资产产权登记，国有资产评估资产评估备案（核准），企业国有产权转让事项批准，市直国有企业或控股企业清产核资审核，监管企业经营层薪酬方案审批。本着高效便捷的原则，减少审批材料，承诺时限缩短至法定时限的
60%
以内。为做好上述五个项目审核审批工作，本委将进一步转变服务方式、方法，努力提高服务质量和水平。做到“三个一次清”即登记表等材料一次给清、咨询事项一次说清、办事程序一次讲清；并推行“四个一”服务：即一张笑脸迎人、一把椅子让座、一句礼貌问候、一个满意答复；做好“五个一样”，即份内份外一样热情、生人熟人一样和气、领导群众一样尊重、忙时闲时一样接待。
3.
实行公开承诺。
在本委内部大力推行“立说立行、马上就办、办就办好”的工作理念，全面推行政务公开，积极实行服务承诺。要尽快把审批的结果通过市国资委网站“政务公开栏”向社会公开。要本着急事急办、要事快办、特事特办、所有事情认真办的原则，严格按照规定的工作规程，办好各项服务事项，促使权力公开透明运行。
4.
规范行政权力运行。
为进一步规范行政权力运行工作，加大对行政权力运行工作的督查力度，提高行政权力运行工作质量和水平，确保行政权力运行工作公开透明、公正合法，本委成立了行政权力运行工作集体讨论领导小组，对各类重大、疑难、复杂的行政权力项目的运行进行集体讨论研究决定。加强落实，并设立了行政权力运行公开工作投诉举报电话：
2621209
。
（三）强化跟踪问效，促进执行力度再提高
1
．强化内部管理。
严格落实岗位责任制、同岗替代制、服务承诺制、首问责任制、一次性告知制、限时办结制、否定报备制和责任追究制等机关效能建设“八项制度”。强化内部督查，加大整治庸懒散力度，开展经常性的机关作风和行政办事效率督查，及时发现和解决本委影响机关效能的问题，并严格按照《福建省机关工作人员效能问责办法》实行责任追究。
2.
强化效能督查。
加强对“五大战役”推进情况的督查，坚持季度巡查、联席会议、电子监察等好做法，对部门履职服务项目情况进行督查。
3
．强化直查快办。
严格按照《福建省办理机关效能投诉事项“路线图”》办理效能投诉。对事关企业、群众切身利益的效能投诉，特别是对反映强烈、投诉频繁的典型案件，立查快办、及时处理，确保投诉在第一时间得到妥善处置。对反映投资环境的问题，属于本委职责范围的，马上办理，并在
5
个工作日内予以答复；不属于本委职责范围的，第一时间告知当事人；需要转办的，在
2
个工作日内完成。对重大、紧急的效能投诉事项，立即进入办理程序。
(
四
)
加强绩效管理，促进绩效水平再提升
1
．发挥部门主体责任。
建好台账、用好台账，加强指标跟踪和工作沟通。对本委主抓作用发挥不好、业务不熟练的，加大结果运用力度。
2
．运用科技手段强化绩效管理。
建好、用好政府绩效管理信息系统，利用现代科技、信息技术，实现绩效管理信息发布、数据采集、统计分析、预警纠偏、评估反馈等网上运行，提高绩效管理科学化水平。
3.
推进绩效管理制度化。
把绩效管理制度作为行政管理的一项基本制度，围绕绩效目标、绩效责任、绩效监控、绩效评估、绩效提升等基本环节，建立适合本委的绩效管理制度，提高制度化水平。特别是要健全绩效管理结果运用机制，充分发挥绩效管理的导向作用。
四、方法步骤
(
一
)
动员部署。
制定下发活动实施方案，全面安排部署，
使广大干部提高认识，明确活动开展的基本要求和主要内容
。
（二
)
自查整改。
对照此次活动的工作任务，进行“五查五看”，对存在的各种问题进行认真排查和深入剖析，制定具体措施，认真组织整改。排查出的问题、整改措施、工作目标通过网络方式向社会公布。
(
三
)
组织实施
。根据活动的实施意见，逐项研究确定具体措施、责任科室、责任人员，建立工作台账，全力抓好工作落实。
(
四
)
建章立制。
本委将对活动进行总结回顾，认真总结好做法、好经验．并将活动中行之有效的做法、举措，用制度形式固定下来，努力巩固活动成果，推动机关效能建设不断加强，使之制度化，常态化。
五、工作要求
（一）加强组织领导
。
成立由委主要领导任组长、分管领导任副组长的“整治庸懒提效率、马上就办优服务”活动领导小组，下设办公室，负责活动的日常工作
。各科室要把开展“马上就办”活动作为新形势下深入学习
实践党的十八大精神和科学发展观活动的重要举措
，作为促进经济增长的一项全局性工作，切实抓好落实，解决实际问题，真正做到思想有触动、作风有改进、工作有突破。
(
二
)
强化跟踪问效。
本委内部机关效能建设工作机构要对活动开展情况进行全程跟踪督促，及时协调解决工作中的突出问题。
（三）务求工作实效。
把握工作重点和要求，认真履行职责，力戒浮华，不走过场，不搞形式，建立的制度和制定的措施都要落实，做到有诺必践，有行必果，真正让群众感受到加强效能建设带来的新变化
。要宣传引导，借助莆田市国资委网站、莆田廉政网专栏等实时动态宣传，形成氛围，提升工作水平。
