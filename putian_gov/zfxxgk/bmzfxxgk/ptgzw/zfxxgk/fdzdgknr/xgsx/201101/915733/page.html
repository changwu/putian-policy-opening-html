莆田市人民政府国有资产监督管理委员会2010年度政府信息公开年度报告

发布时间：2011-01-08 00:00
| | |

市府办：

　　根据《中华人民共和国政府信息公开条例》有关规定和莆田市人民政府办公室《关于做好2010年度政务信息公开工作年度报告有关事项的通知》（莆政办[2010]197号）要求，报告本委2010年度政府信息公开工作情况，本报告统计数据时限从2010年1月1日—2010年12月31日，报告内容在我委开设的政府信息网站上公布，联系电话：2621209。

　　一、概述

　　（一）财政性资金拨付公开情况

　　我委2010年第一季度无财政性资金下拨。第二季度下拨资金情况：1、罗屿作业区等码头下拨财政性资金1800万元，公开时间为4月21日。2、妈祖城核心区填地项目下拨财政性资金2000万元，公开时间为5月27日。第三季度无财政性资金下拨。第四季度下拨财政性资金情况：1、东吴港区工业园区开发公司下拨注册资本金2000万元，公开时间为12月31日。2、湄洲湾港口项目下拨资金1300万元，公开时间为12月31日。

　　（二）规划及政府投资项目、行政审批过程公开情况

　　2010年我委无规划及政府投资项目。我委设置的7个非行政许可审批项目的审批过程均纳入网上审批和电子监察系统。

　　（三）重大公共政策决策过程、政策解读及执行公开情况。

　　2010年我委无此项工作职责

　　（四）公共服务类信息公开情况。按照编制的《指南》和《目录》。做好信息的编制和发布工作。根据上级有关要求，《目录》包括国资委机构职能，行政法规、工作规划、国资监管等13项内容；《指南》就信息主动公开范围、公开形式、公开时限、查询方法以及依申请公开的有关规定作了详细的说明，便于上网查阅。

　　（五）政府信息公开渠道建设情况

　　一是我委积极关注省国资委重点工作和学习兄弟市网站工作方法，把握内网信息组织方向；加强信息综合力度，积极组织上传时效性强、质量较高的信息资料，取得了较好效果。二是我委建立网站运行维护机制，指定专人负责网站维护和管理工作，同时将所有栏目内容分解到各科室，对上报资料的时间和格式都作了具体的规定，建立了科室负责人，网站管理员，分管局领导层层审核把关的资料审批制度。三是针对网站建设过程中出现的一些问题，委领导还定期组织召开科室负责人会议，提出改进意见，从而保证了各栏目资料的准确和及时更新。

　　（六）建立健全政府信息公开长效机制。

　　一是加强了对政府信息公开工作的领导。我委成立了政务公开工作领导小组，由委主任担任领导小组组长，1名副主任担任副组长分管，下设办公室具体负责，二是建立工作机制，落实配套措施。根据国务院《政府信息公开条例》规定精神，我委重新修订了《莆田市国资委机关政务公开工作实施方案》，方案明确规定政务公开工作的基本原则，主要内容、具体形式、基本程序和保障措施。印发了《莆田市国资委信息公开制度》，以确保本委信息及时、准确地公布。

　　二、主动公开国资委政府信息

　　（一）信息公开程序及数量。本委需公开的信息由相关职能科室制定，经科室负责人及分管的领导人审批后，由委政务公开办再核稿后统一编号予以公开，重要信息公开还经过主要领导的审批。信息公开工作的程序规范，责任落实。截止12月底，本委已公开信息389条。

　　（二）主动公开的国资委政府信息类别有：

　　01、市国资委领导班子、委机构设置、主要职能、办事程序；

　　02、行政法规、规章和规范性文件；

　　03、国资委工作规划；

　　04、国有资产产权管理情况；

　　05、国有资产统计、分析信息，监管企业工资监控；

　　06、所监管企业的改革发展情况；

　　07、行政事业单位资产管理情况；

　　08、重大建设项目的投资实施；

　　09、国资委系统党建，管理权限内的人事管理；

　　10、纪检、监察工作；

　　11、突发公共事件的应急预案、预警信息及应对情况；

　　12、政务动态；

　　…………..

　　30、国资委应主动公开的其他信息。

　　我委目前做到每月都有新的政府信息公开，且能公开的都登网公开。

　　我委网站开设“留言板”，群众随时可实行在线访谈。

　　（三）本委信息公开的形式主要有：1、门户网站；2、市政府办的政务公开栏。3、送交市档案馆的纸质文件。

　　三、依申请公开信息情况

　　我委在《信息公开指南》中明确规定，公民、法人和其他组织根据自身需要，可申请获取除主动公开的国资委信息，可以直接在本委网站上填写并递交《信息公开申请表》或从网站下载并填写《信息公开申请表》。至目前，我委尚未收到这方面的申请。

　　四、政府信息公开的收费及减免情况

　　我委实行政府信息公开至今，从未收费。

　　五、因政府信息公开申请行政复议，提起行政诉讼的情况

　　我委实行政府信息公开至今，未出现申请行政复议和提起行政诉讼的问题。

　　六、信息公开工作存在的主要问题及改进措施

　　存在主要问题：

　　网页排版还不够新颖、内容不够丰富，有待进一步改进。

　　改进措施：

　　学习、借鉴先进单位经验，不断探索、创新，使网页内容更饱满、版面更新颖。
