莆田市人民政府国有资产监督管理委员会关于2025年法治政府建设情况的报告

发布时间：2026-02-28 17:53
| | |

市委、市政府：

　　2025年，市国资委坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十大和二十届历次全会精神，深入践行习近平法治思想，全面落实省、市法治建设工作部署，紧扣国企改革深化提升行动收官节点，以制度体系完善为根基、以数字化监管为引擎、以特色法治实践为突破，持续深化依法监管、依法治企实践，为国资国企高质量发展提供了坚实法治保障。现将有关情况总结如下：​

　　一、2025年度法治政府建设工作总结​

　　（一）政治引领持续强化，法治思想根基更加牢固​

　　坚持全面贯彻落实党的二十大和二十届历次全会精神，认真学习贯彻习近平总书记对全面依法治国工作作出的重要指示和中央全面依法治国工作会议精神以及省委、市委全会精神，深入贯彻落实习近平法治思想。党委理论学习中心组始终把习近平法治思想作为重要学习内容，通过各种形式，将习近平法治思想贯彻落实到各级监管企业。

　　（二）履行第一责任人职责，切实抓好法治建设

　　我委把推进依法行政作为政府工作的重要任务来抓，建立健全由委主任亲自担任组长，分管领导担任副组长，各科室负责人为成员的依法行政工作领导小组。领导小组下设办公室（挂靠法规监督科），形成了“一把手”亲自抓，分管领导协同抓，各科室分头抓，职能科室和专职人员具体抓的工作格局，从而为市国资系统普法和依法治理工作扎实有效地开展提供了组织保证。我委领导高度重视依法行政工作，依法行政领导小组实行主任负责制，分管主任对主任负责，抓好分管科室的依法行政工作，涉及国资管理的重大事项由委领导班子集体讨论决定。

　　（三）升级立体化监管模式，增强治理能力效能​

　　一是完善制度。2025年3月28日印发《莆田市国资委内部监督检查实施办法（试行）》，进一步细化各科室监督检查职责，强化监督检查责任。二是强化检查。建立50项业务监管工作台账，督促委各科室按季度持续对企业贸易管理、巡视巡察及审计整改和融资借款等领域开展立体式、全方位的监督检查，并创新开展重点监管领域抽查督查，实现委内部监管业务再监督再督查。对发现违规问题和线索，并造成国有资产损失或其他严重不良后果的，予以严肃追责问责。三是强化提示函运用实效。2025年度，委内各科室累计向监管企业印发提示函32份，有效提示相关企业防范化解风险、推动问题整改。四是数字监管。推动国资监管数字化转型纵深发展，实现监管云平台与 “全市一张图” 深度融合，增设产权管理、投资管理、经济指标、人事管理、国资管理、法律纠纷管理等专项监管模块，构建起实时监测、智能预警的数字化监管体系，让监管更精准、更高效。

　　（四）强化监督制约，规范权力运行流程​

　　一是严格落实信息公开制度。及时地向社会公开国资委政务信息，保障了公民的知情权、参与权和监督权，把推进政府信息公开与转变政府职能、规范权力运行、促进依法行政紧密结合起来。同时坚持公开原则，遵循基本程序，落实保障措施。2025年度，市国资委共收集各监管企业信息1951条，其中被市政府国资监管专栏采用74条，被省国资委网站采用23条，被省国资委八闽国资公众号采用15条，被学习强国学习平台采用7条，被市委、市政府刊物采用41条。二是构建多元协同监督格局。自觉接受人大、政协监督，畅通政务热线、12345、信访等群众反馈渠道。三是健全责任追究机制。严格执行相关条例规定，对违规经营投资问题严肃追责问责，形成有力震慑，切实防范国有资产流失，确保权力在阳光下运行。

　　（五）深化依法治企，筑牢合规经营防线​

　　以“合规管理深化年”活动为载体，指导各监管企业全面建立“党委领导、董事会决策、经理层执行、合规部门牵头、业务部门嵌入”的合规管理体系，实现合规管理全域覆盖、全流程渗透。健全“内部法务+外部律师”协同风控机制，将法律审核嵌入业务全链条，有效防范化解各类法律风险，妥善处理纠纷争议。2025年，市国资系统共聘请法律顾问213位，法律顾问出具合同审查法律意见8515份，参与各类诉讼、执行等案件150件，出具法律意见书180份，出具律师函102份，提供法律咨询3127余次，开展法律讲座51次，出具法律尽职调查报告77份等法律支持，参与企业商业谈判68次。

　　（六）构建风险防控体系，护航国企行稳致远

　　一是建章立制。2025年3月26日印发《所出资企业重大经营风险事件报告工作规则》，督促企业出台相应配套措施，规范所出资企业重大经营风险事件报告工作，建立健全重大经营风险管控机制，确保及时采取应对措施，有效防范和化解重大经营风险。二是强化处置与督导。明确将可能引发重大财务损失、经营环境剧变、严重违法违规、国际制裁、重大舆情及核心资料丢失等六类情形纳入强制报告范围，严格执行“首报、续报、终报”程序，并加强事中事后督查与典型剖析，形成风险管控闭环。三是深化成果运用与长效建设。持续推动风险事件处置经验转化为长效机制，提升企业自主风险识别与防控能力，夯实国资安全运行的制度基础。

　　（七）强化案件管控，护航国资国企安全

　　一是完善制度。2025年12月24日印发《所出资企业法律纠纷案件管理办法》，督促企业加强案件管理，明确责任主体，完善管理制度，健全工作机制，积极主动维权，切实防止国有资产流失。二是分类管理。对所出资企业案件进行分类管理，具体分为重大案件、较大案件和一般案件，分别实施事前备案、事后备案和企业自备自管制度。要求各企业按季度将所有案件信息（所出资企业法律纠纷案件情况表、汇总表）导入“莆田市一张图”，及时掌握案件情况，健全管理指标体系，加强数据统计分析，更新案件管理台账，增强案件管理的针对性和有效性。三是重点跟踪。市国资委专案督办“重大案件”，建立管理台账，持续密切关注案件情况，实时掌握案件动态，督促企业适时应对，诉讼案件一有最新进展，即专题向市政府报告。

　　（八）全方位深化普法宣传，构建多元立体宣法格局

　　一是抓实常态化学习。依托党委中心组学习、干部职工例会、主题党日等平台，系统组织学习《中华人民共和国宪法》、《民法典》、《安全生产法》、《企业国有资产法》等核心法律法规，推动监管企业同步开展全员学法活动，实现法治学习全员覆盖、入脑入心。二是创新多元化载体。通过监管企业公众号推送解读、电子屏滚动展示、宣传栏图文科普、张贴警示标语等形式，在办公区域、项目一线营造浓厚法治氛围，同时，面向社会公众宣传《劳动合同法》《中华人民共和国宪法》等重点法规，扩大普法社会影响力。三是夯实学习保障。持续征订《法治日报》《福建法制报》《长安》等报纸杂志，为干部职工提供权威学法资料，助力法治理念日常浸润。四是深化品牌化实践。以“蒲公英”公益普法行动为抓手，组织企业普法志愿者队伍，紧扣《福建省司法厅关于进一步推进公共法律服务的八条措施》要求，开展线下普法宣传活动，向群众发放《中华人民共和国宪法》、《民法典》等法律书籍，提供法律咨询与法律服务，推动形成“人人参与法治宣传、人人共享法治成果”的良好局面，在国资监管系统内筑牢“依法经营、依法管理”的思想根基。

　　二、法治建设存在的问题

　　在法治建设中存在的问题为：法治理念渗透力不足。部分干部职工法治思维树得不牢，存在“重业务推进、轻法治把关”的倾向，运用法治方式破解改革发展难题的主动性不强。少数企业法治学习流于形式，存在“学用脱节” 现象，法治理念未能真正融入经营决策、项目推进、风险防控等关键环节。

　　三、下一步工作打算 ​

　　2026年，市国资委将坚持以习近平法治思想为指引，深耕思想引领，厚植法治根基，构建“理论学习+案例研讨+实践应用”三位一体的法治教育体系，将习近平法治思想纳入各级党委中心组学习、干部培训的核心内容，通过专题讲座、法治沙龙等形式，推动法治理念入脑入心。建立“靶向普法”机制，针对企业高管、中层骨干、一线员工分类定制普法内容，升级“蒲公英”普法品牌，打造线上线下联动的普法矩阵，让法治宣传既有“高度”又有“温度”。锚定新一轮国企改革深化提升行动目标，以问题为导向，以创新为动力，推动法治政府建设与国资国企高质量发展深度融合，着力实现“法治理念更牢固、制度体系更完善、监管效能更精准、依法治企更深入、队伍建设更过硬”的工作目标，让法治成为国资监管的鲜明底色、国企发展的坚实保障，奋力谱写新时代国资国企法治建设新篇章。

　　　　 莆田市人民政府国有资产监督管理委员会​

　　　　2026年2月28日​
