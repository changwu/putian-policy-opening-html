莆田市人民政府国有资产监督管理委员会2007年工作总结和2008年工作计划

发布时间：2007-11-20 00:00
| | |

 

莆田市人民政府:

今年以来，在市委、市政府的正确领导和省国资委的具体指导下，国资系统全体干部职工坚持科学发展观，认真贯彻落实省委、省政府提出的“四谋发展”实践主题和“四个重在”实践要领，严格按照年初市委提出的突破“五四二”确保“八五六”的发展目标，团结一心，积极主动地开展各项工作，取得了较好的成绩，实现了国资监管工作的平稳发展。

一、2007年工作总结

（一）加强学习，努力创建学习型机关

本委一直高度重视干部职工的政治、业务学习工作，年初市委《关于开展“提高四种能力，践行八个作风，发挥骨干作用”学习教育活动的意见》下发后，我委及时贯彻实施《意见》，制定了学习教育活动方案，制订详细的学习计划，开办学习宣传栏，并结合工作实际，举办业务知识专题讲座、业务讨论会，组织党员上党课等，拓宽干部知识面，全年共组织委机关干部参加省国资、省、市委党校业务辅导培训培训班8人次，监管企业高级管理人员境内培训4人次，境外培训1人次，较好地提高了国资队伍的业务素质。从10月份开始，本委按中央、省委和市委的部署要求，精心组织、周密安排，分阶段、分步骤地扎实推进十七大精神的学习宣传和贯彻工作，认真制定学习计划。围绕学习贯彻十七大精神和“提高能力、改进作风、推动发展”这个主题，在委内部开展心得体会交流活动，引导广大党员干部进一步创新发展观念，破解发展难题，提高发展质量，以学教活动推动十七大精神的学习宣传和贯彻。

（二）扎实工作，确保国有资产保值增值

一是推动企业改革与发展。积极协调所监管企业为有关项目和企业提供贷款担保，帮助企业实现融资2.4亿元；配合粮食管理部门做好军粮供应企业的整合工作，支持粮食企业深化改革；协同有关部门落实市外贸公司资产处置，着力解决企业改制遗留问题；主动介入有关企业拆迁补偿的协调，切实维护国有企业及其职工的合法权益；认真审核国有独资公司章程。审核修改了《莆田市金莆供水有限公司章程》、《莆田市滨海新区有限公司章程》等；根据工商管理和公司发展要求，适时调整公司注册资本金。如：适时调增妈祖城开发建设有限公司、市金钟水利枢纽工程开发建设有限公司注册资本金等；规范资本运作，对所出资企业重大投融资规划提出建设性意见。按照《公司法》、《企业国有资产监督管理暂行条例》等法律法规要求，规范企业资金的审批程序、提高资金使用效益。积极引导企业正确的投资方向，确保投资的科学性和合理性。如：对东吴路堤工程西埔垦区排洪纳潮应急工程项目建设性问题提出建设性意见等。

二是严把国有资产评估质量关。对企业国有资产评估项目，统一实行在中介机构备选库中采用随机抽取的办法选聘评估机构，同时，严格按照《国有资产评估管理办法》的要求，做好企业国有资产评估项目的备案工作，加强对评估结果的合规性、合理性审查。对企业改制的资产评估实行评估结果公示制度，引入公众监督机制；对单项金额较大的标的，实行部门联审制度，最大限度地保证评估结果的真实、合理和完整。截至10月底，共办理国有资产评估备案24宗，评估价值2793.69万元。

三是规范国有产权交易。严格执行国务院国资委、财政部第3号令及《企业国有产权转让管理办法》的规定，加大对国有集体产权交易的监管力度，推动产权的有序流转，促进产权市场的健康发展，保证产权交易过程中的公正性和有序性。全面实行进场交易，防止暗箱操作，不断增强产权交易的透明度。截至10月底，全市共有国有和集体资产进场交易26宗，交易额871.33万元，增值率达31%。与此同时，加强对产权交易领域的监督检查，发现2宗个别县区违规场外交易问题，及时会同有关部门予以制止和纠正，维护了产权交易秩序。

四是加强行政事业资产管理。去年底，按照市政府的统一部署，我委牵头组织对全市246家行政事业单位进行了全面的资产清查，并对60多家单位进行重点抽查。针对清查中发现的问题，我委及时起草了《关于加强市直行政事业单位资产管理的若干意见》，以市政府的名义下发，对行政事业单位长期闲置、借用和超标配置的资产进行无偿调拨，实现各部门闲置资源的合理流动，促使其转化为有效资源，截止11月1日，共批复17个行政事业单位间资产无偿调拨，累计金额4614579元。对市直行政事业单位已报废的资产，要求各单位补办报废手续，确系报废的资产，予以批复，至今共审批41个单位，涉及报废资产达6882898.9元。

五是逐步完善公司法人治理结构。今年本委共考察推荐了莆田市金莆供水有限公司、仙游金钟水利枢纽工程开发有限公司、莆田市滨海新区开发建设有限公司、莆田湄洲湾控股有限公司等国有企业的董事、监事人选，积极探索建立现代企业法人治理结构。

六是服务重点项目建设。认真审核并及时下达了经市政府授权由市国资委履行出资人职责的市重点项目等有关资金，共计79,331.5万元。其中：荔港大道建设项目10,000万元；回购外度引水隧洞工程项目5,004万元；注资成立福建湄洲湾控股股份有限公司20,000万元；福厦铁路莆田段征地拆迁建设项目4,100万元；湄洲湾港口铁路支线项目10,000万元；向莆铁路莆田段建设项目10,000万元；妈祖城工程建设9,000万元；金钟水利枢纽工程项目2,200万元；仙游抽水蓄能项目627.5万元；城港大道二期工程项目5,200万元；金莆供水工程1,000万元；市房地产开发总公司2,200万元。

（三）健全制度，规范国有资产管理

一是规范行政事业单位资产管理。出台了《市直行政事业单位资产出租审批程序及招租操作规程》，为完善市直行政事业单位资产管理提供了制度依据。7月31日，市科技中试大楼的一坎80平方米店面进入市招投标中心进行公开招租，系全市第一宗，最终承租者以年租金2.76万元中标，比去年同期租金提高了1.14万元，增值率达70%。

二是规范国有产权转让行为。出台了《莆田市市属企业国有产权转让管理暂行规定》，对企业国有产权转让的行为审批、价值评估、信息披露、进场交易、资金监管等各个环节都作了明确的规定，进一步规范企业国有产权的转让行为。截至10月底共对9宗企业国有资产处置依法进行审批。

三是强化对中介机构的监管。出台了《莆田市清产核资、资产评估、财务审计等中介服务的执业机构选聘及委托服务管理暂行规定》，对国有产权持有单位在实施企业改制、资产处置和其他经济活动中，需要委托中介机构提供清产核资、资产评估、财务审计等中介服务的行为，就其选聘工作进行了规范。截至10月底共对11宗需委托中介提供服务的事项公开组织选聘中介机构。

四是开展企业经营业绩考核和薪酬管理工作。为了切实履行企业国有资产出资人职责，维护所有者权益，落实国有资本保值增值责任，建立有效的激励和约束机制，出台了《关于开展企业经营业绩考核和薪酬管理工作的通知》，在本委所监管的企业中挑选条件较为成熟的企业，开展企业负责人员经营业绩考核和薪酬管理工作。

（四）防微杜渐，进一步加强党风廉政建设

一是贯彻落实党风廉政建设责任制。委主要领导认真履行第一责任人责任，多次召开会议专门研究部署企业党风建设和反腐倡廉工作,与各监管企业签订了党风廉政建设责任书，并下发了《中共莆田市国资委委员会关于贯彻落实党风廉政建设责任制规定的实施意见》。各监管企业也都能认真落实党风廉政建设责任制的规定，进一步加强组织领导，明确机构与任务，把党风廉政建设责任制与企业改革发展、经营管理等工作同部署、同检查，形成齐抓共管的工作格局。为认真贯彻落实全市预防腐败工作会议精神，下发了《莆田市国资委关于当前预防腐败的工作意见》，就预防腐败的14项工作任务进行分工，明确责任领导和牵头科室，并建立了联席会议制度，推进预防腐败各项工作任务的落实。

二是稳步推进领导干部廉洁自律工作。在市国资委党委成立大会上，市国资委党委委员带头公开作出六条廉政承诺，自觉接受社会各界和广大党员干部的监督，树好榜样。出台了《莆田市国资委廉洁谈话和函询制度》，今年以来，已对委机关12名科级干部进行任前廉洁谈话，对1名监管企业的领导进行了诫勉谈话；此外，还出台了《关于领导干部报告个人重大事项的实施意见》、《关于建立市国资委机关科级干部和监管企业领导人员廉政档案的暂行规定》等制度规定。今年元旦、春节期间，我们及时下发了《关于元旦春节期间严格遵守纪律的通知》，要求各监管企业领导人员要严格遵守纪律，严禁铺张浪费，严禁送收现金、有价证券、支付凭证和贵重礼品，并专门组织人员对贯彻落实情况进行了检查。

三是强化对权力的监督制约。今年以来，市国资委纪委、监察室对湄洲岛供水管道保护等工程的招标，以及中介机构的选聘过程进行监督，确保公开、公平、公正；对市国投公司使用开发银行9.3亿元贷款资金的情况进行跟踪监督，确保专款专用；对市商品物业管理公司大额度资金的使用情况进行核实，确保资金使用安全与合理。此外，还加强对企务公开工作的监督检查，确保职工参与企业民主决策、民主管理和民主监督权力的落实。

四是开展治理商业贿赂专项工作。先后下发了《莆田市国资委治理商业贿赂专项工作方案》、《关于深入推进治理商业贿赂专项工作的实施意见》等文件，就治理商业贿赂专项工作进行部署。通过专题会议、学习会以及利用宣传栏、内部刊物等形式，认真做好思想动员、宣传教育，引导广大党员干部充分认识贿赂行为的危害性和严重性，提高参与专项治理的自觉性和主动性，营造良好的氛围。根据市治贿办《关于<转发福建省治理商业贿赂自查自纠工作检查评估实施细则>的通知》要求，认真做好对照检查和自评工作，并对各监管企业自评情况进行检查。

五是加大查办案件工作力度。重点查处产权交易、资本运营和经营管理中隐匿、私分、转移、贱卖国有资产的案件，以及市直行政事业单位资产流失的案件。今年以来，市国资委纪委、监察室协同市监察局对市科技馆等五家单位房产租赁中存在的问题进行查处，并督促及时整改；纠正了2宗场外交易案件；及时办结了市纪委下转的2件信访件；认真查处了监管企业的2起违反计生案件。

（五）统筹兼顾，党的建设进一步增强

一是机关党建有序开展。严格按照

《中国共产党章程》

规定和上级有关部门的要求，有条不紊的做好委机关本级党委组建工作。9月7日，根据市委批复，市国资委召开了第一次党员大会，按照预定程序，大会选举产生了第一届党委会和纪委会。紧接指导委机关和国投公司搞好党支部的组建和成立工作，做到组织到位、程序规范、机构健全。在抓好党员队伍建设和管理的基础上，重点抓好发展对象的培养、新党员的发展和预备党员转正等工作。全年共培养积极分子3名，发展新党员2名，审核办理了4名预备党员转正。

二是安全生产和平安建设得到加强。认真落实《莆田市人民政府关于下达2007年安全生产目标管理责任的通知》《莆田市“平安建设先进单位”考评验收细则》要求，坚持“安全第一，以防为主，综合治理”的方针，坚持“安全发展”指导原则，调整充实了委综治和“平安莆田”建设领导小组，进一步明确分工，加强了对安全生产和平安建设工作的组织领导，根据市政府、市安监部门的工作部署，扎实有效地组织开展“安全生产月活动”、“重点行业和领域安全生产隐患排查治理专项行动”，确保全年国资系统安全生产无事故，促进了经济发展和社会稳定。

三是深入开展政风行风和效能建设。按照市政府布置，深入开展政风行风评议和机关效能建设，成立了工作机构，制定了工作方案，通过征求社会各界对国资监管工作的意见和建议，切实找准国资部门在工作作风，办事效率，勤政廉政，依法监管、政务公开、服务态度等履行职能职责方面存在的主要问题，加大制度建设力度，推进制度完善和创新，增强制度执行力，确保政令畅通。

四是加强国资监管队伍建设。加强国资委自身建设，自觉接受企业和社会的监督，寓监管于服务，重心向下、服务向下，服务发展、服务企业、服务于广大职工群众。结合从事工作的特点和职责任务，解放思想，开拓进取，努力提高依法履行出资人职责的能力，提高依法监管国有资产的能力。

回顾刚刚过去的一年，市国资监管部门在市委、市政府的正确领导下，在有关部门的关心和指导下，经过全体国资监管干部的共同努力，国资监管工作取得了一定的成绩，但仍存在一些问题，主要有：一是监管职能不清，由于管人、管事不能真正有效统一，造成国有资产管理有时未能真正落实到位；二是监管企业不多，目前全市真正纳入国资监管的企业只有4家，其它主要还是由主管部门管理，造成履职不能全部到位；三是监管关系不顺，各县区国有资产监管职能均依托财政部门，没有独立的机构和专职人员，县区国有资产监管相对薄弱等等，对这些问题我们将在今后的工作中努力加以解决。

二、2008年工作思路

2008年是全面贯彻落实十七大会议精神的关键年，也是各项改革攻坚克难的重要一年。我市国资监管工作的总体要求，是以邓小平理论和“三个代表”重要思想为指导，认真贯彻落实党的十七大、省委八届三次全会精神，全面贯彻落实科学发展观，准确定位、依法履职，以深化产权制度改革为核心，以健全企业法人治理结构与机制为重点，以国有资产的保值增值为目标，坚持改革方向，创新体制机制，促进企业发展，更好地发挥国有经济的作用，为建设海峡西岸经济区做出积极贡献。根据这个指导思想，今年主要做好六个方面的工作。

1、继续加强国有资产产权管理。要根据相关的法律法规要求和市政府的统一部署，加强对所监管的国有资产产权界定、登记、划转、处置及产权纠纷调处等工作，依法履行出资人职责，加强对企业的指导、协调和服务，积极引导企业正确的投资方向。督促市直行政事业单位加强资产的会计核算，建立资产台帐，有条件的单位要利用资产管理软件进行动态管理，对不合理的帐务处理要及时进行纠正、调整,做到账账相符、账实相符，不重不漏。同时，完善产权管理制度，进一步规范国有资产评估和产权交易行为，对所监管的国有产权的变动情况进行有效的监控。继续做好由市国资委履行出资职责的有关市重点项目的服务工作。

2、积极推进建立现代企业制度。我市国有企业特别是市国资委所监管的相当部分企业的法人治理结构仍不符相关法律法规的要求，明年将继续按《公司法》、国资管理有关规定和市政府的统一要求，逐步推进我市国有企业特别是市国资委所监管企业的现代企业制度建设，将建立现代企业制度与转换企业内部经营机制紧密结合起来，促进企业科学管理、规范经营运作。建立健全监管企业中层干部的宏观管理及任免制度；探讨建立党管干部与市场化配置企业经营管理者相结合的现代企业用人机制；探讨建立符合现代企业制度的企业经营管理者激励约束机制。

3、探索我市国有资本运作新模式。在我国资本市场渐趋成熟的今天，为实现我市经济又好又快发展，积极探索我市国有资本运作模式已显得时不我待了。通过优化国有资本运作，提高国有资本效益，实现国有资产保值、增值。认真研究所监管企业合并、股份制改造、上市、合资等重组方案。积极探索在股份公司中实施国有资本运作及监管模式。协助所监管企业解决发展中的有关问题。

4、做好企业改革改制工作。国资监管的根本目标是推动国有企业改革和发展，实现国有资产保值增值。结合我市实际，要抓紧构建科学的国有资产监管体系，完善专家决策咨询体系和国有资产监管机构内部工作制度，增强国有资产监管的科学性、规范性和民主性。认真做好我市有关国有单位的改革改制工作，做到既要维护职工合法权益，也要确保国有资产安全完整与保值增值。继续按职能协助市国企办做好改制企业的服务工作等。

5、继续加强干部队伍建设。一是要继续加强学习。按照市委的要求重点做到八个“深入学习宣传”，在全委掀起学习十七大精神的高潮，通过开展多种形式的的学习宣传活动，使十七大精神深入人心。同时结合学习十七大精神、加快湄洲湾港口城市建设，有计划的安排本委领导、干部、职工进行培训和轮训，加快知识更新，熟练掌握企业国有产权管理工作所需的技能和知识。二是要完善反腐倡廉制度。要与现代企业制度相配套，与市场经济规律相适应，把反腐倡廉要求融入企业决策和经营管理等各项制度之中，依靠教育导向和监督管理，从制度上预防腐败。三是要继续做好综治和平安建设。要根据市委、市政府的统一部署，继续加强综治和平安建设工作，落实安全责任制，确保国资系统安全生产无事故，促进经济发展和社会稳定。四是要继续开展政风行风和效能建设，全面提高国资系统队伍素质。

6、加强对县区国有资产管理的指导和监督。要加强与县区政府的联系和沟通，把国资监管体系建设摆上县区政府的议事日程，争取做到各县区都有相对独立的国资监管机构和专职人员，同时帮助县区理顺国资监管职能，加强国资监管制度建设，提高县区国有资产管理水平。
