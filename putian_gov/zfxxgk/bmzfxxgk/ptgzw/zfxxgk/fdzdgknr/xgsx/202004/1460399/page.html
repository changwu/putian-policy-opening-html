关于印发2020年安全生产工作要点的通知

发布时间：2020-04-08 10:19
| | |

各监管企业：

　  根据《莆田市人民政府安委会关于印发2020年工作要点的通知》（莆市安〔2020〕2号）文件要求，现将《莆田市人民政府国有资产监督管理委员会2020年安全生产工作要点》印发给你们，请结合企业实际情况，制订具体措施办法，细化分解任务，明确责任分工，抓好贯彻落实，并于2020年12月18日前将各项工作完成情况报送法规科办公室。

　　 

　　                  莆田市人民政府国有资产监督管理委员会

　　2020年4月1日 

　　

　　

　　　　

　　莆田市人民政府国有资产监督管理委员会

　　2020年安全生产工作要点

　　 

　　以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中、四中全会精神，深入贯彻习近平总书记关于安全生产工作重要论述和指示批示精神，认真贯彻落实党中央、国务院、省委、省政府及市委、市政府的决策部署，不断深化安全生产领域改革发展，坚决打好防范化解重大安全风险攻坚战，深入开展重点行业领域安全生产专项整治，进一步完善和落实安全生产责任和管理制度，健全完善隐患排查和安全预防控制体系，持续强化安全生产基础能力建设，努力减少一般事故，坚决防范遏制较大及以上事故，促进全委安全生产形势持续稳定好转，推动提升安全生产整体水平，为高质量发展落实赶超创造稳定的安全生产环境。

　　一、深入学习贯彻落实习近平总书记安全生产工作重要论述精神

　　1.持续深入开展宣贯教育活动。深入学习贯彻习近平总书记在主持中央政治局第十九次集体学习时的重要讲话和1月23日就“2019年全国生产安全事故主要特点和突出问题”作的重要批示精神，以强烈的政治担当、历史担当、责任担当，有力防范化解重大安全风险。各监管企业要将学习贯彻习近平总书记关于安全生产工作重要论述纳入理论中心组学习和干部培训内容，牢固树立新发展理念，坚守红线意识和底线思维，把好安全发展、高质量发展的总开关，坚决扛起保民平安的政治责任。

　　2.扎实开展专项整治行动。认真贯彻落实习近平总书记重要指示精神，深入开展安全生产隐患大排查大整治，扎实推进全委安全生产集中整治，全面整治政治站位不高、红线意识不强、安全责任缺位、隐患排查不扎实、监管执法宽松软、形式主义等问题。制定实施安全生产专项整治三年行动计划，常态化开展安全生产隐患排查整治专项行动，持续深化危化品、道路交通、建筑施工、房屋安全和消防安全等专项行动，着力从根本上消除事故隐患。结合年度安全生产工作考核对整治行动开展“回头看”。

　　3.推动落实改革发展重点任务。对照《中共莆田市委 莆田市人民政府关于推进安全生产领域改革发展的实施意见》重点任务分工和时间进度要求，进一步明确责任、措施和要求，加强专项督导，适时组织开展任务落实情况“回头看”，确保各项任务措施落地生根。

　　4.加强安全生产领域规划设计。推动将安全生产重点内容纳入莆田市“十四五”规划，打好安全生产“十三五”规划落实收官之战，确保实现规划目标。

　　二、创新抓好新冠肺炎疫情防控期间安全生产工作

　　5.切实抓好安全生产和疫情防控“两个责任”落实。切实落实“一手抓疫情防控、一手抓安全生产”的要求，做到安全生产与疫情防控同部署、同落实、同指导、同服务；各企业要落实好疫情防控和安全生产“两个主体责任”，落实好复工复产安全防范工作各项责任措施。按照市应对新型冠状病毒感染肺炎疫情工作领导小组的要求，绘制复工复产计划图，结合无疫情区、零星散发疫情区、一般疫情区、较多病例疫情区等四类疫情区特点，实行分区分类、精准施策、有效服务、差异化复工复产。重点行业领域企业落实“班班见领导”制度，对存在重大安全隐患和发生事故的企业，要坚持一事一处理，严防简单化、“一刀切”等偏激和极端做法。对企业内各类隔离观察场所,开展全覆盖安全检查，防范化解潜在安全风险，及时消除事故隐患，严厉打击涉及集中隔离点的安全生产非法违法行为，加强应急准备。

　　6.进一步创新安全监管方式方法。对建筑工地、农贸市场、大型商业综合体等特殊场所开展“一对一”安全服务,指导管理单位落实主体责任，建立健全内部安全责任制和安全管理机制。落实疫情防控要求减少人员接触和聚集，运用信息化技术、专家咨询服务、点对点现场指导等手段创新安全监管，强化安全服务和安全防控措施落实，严防企业因赶工期、超能力生产引发生产安全事故。加强消杀环节安全管理，严防消毒剂使用储存不当引发事故。采用“安全生产月”活动的有效做法，集中开展疫情防控期间相关安全生产宣传教育，强化安全意识，确保安全生产形势平稳。

　　7.巩固提升好的经验做法。全面总结疫情防控期间安全监管工作，固化好的经验做法，反思问题不足，形成长效机制。注重举一反三，探索人员密集型企业、场所等遇突发事件人员分散管理办法，进一步健全完善突发事件中安全监管应急机制，同时大力加强应急物资储备体系建设。

　　三、织牢织密织严安全生产责任体系

　　8.完善落实安全生产和消防工作考核制度。合理利用年度工作考核，科学制定考核评价指标，优化整合考核事项，创新检查考核方式方法，加强结果运用，切实发挥考核的“指挥棒”作用。多措并举用好约谈通报、警示曝光、建议提醒、挂牌督办等“组合拳”，推动《莆田市党政领导干部安全生产责任制实施办法》《福建省消防安全责任制实施办法》落到实处。

　　9.推动部门进一步落实安全管理职责。按照“三个必须”、“谁主管谁负责”的原则和部门“三定”规定，修订安全生产权责清单，做到日常照单监管，失职照单追责，推动企业进一步落实安全生产工作职责，厘清安全监管边界交叉、职责不明等问题，消除安全监管盲区和空白。

　　10.建立健全企业安全生产主体责任内生机制。建立生产经营单位主动报告安全生产风险制度。大力推进企业安全生产标准化建设，进一步完善安全生产标准化创建的经济杠杆、差异化监管等激励措施，提高企业创建的内生动力。严格高危行业主要负责人安全生产知识和管理能力考核，推动完善全员安全生产责任制，不断强化企业安全管理基础。加强市属企业安全生产业绩考核，突出企业主体责任落实，发挥市属企业示范引领作用。

　　四、深入排查隐患，健全预防控制体系 

　　11.全力防范化解危险化学品系统性安全风险。部署开展危险化学品本质安全三年提升行动,严格危险化学品安全风险管控，深化综合治理和专项整治,推动完善危险化学品储存、使用和废弃处置各环节安全监管体制机制,坚决防范危险化学品“灰犀牛”风险。

　　12.加大交通运输领域“打非治违”力度。严厉打击非法从事道路旅客运输、出租车客运的企业和车辆，对市内道路机动车生产企业加强生产准入管理，加大货运车辆超限超载治理力度，严查客车超速、超员等严重违法行为，加强长途客车、旅游客车、重型载货汽车等重点车辆安全监管，切实整顿运输企业“挂而不管”“以包代管”问题，深入推进公路交通秩序整治，加强危险货物道路运输安全管理。完善“公跨铁”立交桥上车辆超载超速等违法行为的防范措施，健全完善高速公路沿线环境综合整治长效机制。

　　13.开展建设工程施工安全综合治理。在房屋市政、建筑施工、轨道交通、公路、水利、建筑安装等建设工程领域，严厉打击各类违反安全生产法律法规、工程建设强制性标准、规章制度和操作规程的行为，有效遏制转包、违法分包和挂靠、无证上岗等问题。聚焦桥梁隧道、脚手架、高支模、深基坑、起重机械、地下暗挖等危险性较大的工程，强化执法检查，督促建设单位等工程建设各方参建主体切实落实责任，加强施工现场安全风险管控，强化员工教育培训和安全技术交底，建立健全危大工程安全管控体系，及时排查治理各类事故隐患。

　　14. 深化房屋安全隐患排查整治。继续深入开展房屋安全隐患排查整治工作，全面排查 “四无”（无审批手续、无专业设计、无专业施工、无竣工验收）房屋以及擅自改变功能结构、违法扩建、擅自对地下空间进行开挖等问题隐患突出房屋建筑，做好信息建档，根据房屋使用状况、隐患程度等，依法依规分类处置，并健全房屋安全管理的长效机制。以城乡结合部、城中村、企业工棚、城市建成区、农贸市场为重点，大力整治各类违规建设酒店、出租房、铁皮房、广告牌、临时搭盖等问题。

　　15.深入开展打通“生命通道”集中整治行动。以住宅小区、高层建筑、大型商业综合体、体育场馆、农贸市场等为重点，全面开展建筑内部及周边道路消防车通道安全隐患排查整治，进一步督促管理使用单位和物业服务企业落实维护管理职责，严格按照标准划设消防车通道标志标线，设置警示牌，预留消防车通道宽度，并定期组织开展巡查、检查和维护等。对占用、堵塞、封闭消防车通道的违法行为依法严肃予以查处，情节恶劣的纳入消防安全严重失信行为，加大宣传曝光力度。指导各企业结合实际情况，探索完善停车供给优化、多部门联合惩戒等消防车通道安全管理长效机制。

　　16.推进重点领域消防安全综合治理。紧盯大型商业综合体、体育场馆、农贸市场、酒店等人员密集场所以及高层建筑、“多合一”、老旧小区、小微企业等高风险场所，重点整治违规使用易燃可燃材料装修装饰、疏散通道不畅通、违规存放易燃易爆危险品、电动自行车违规停放充电等突出风险，加大检查和惩戒力度。

　　17.深化其他行业领域安全风险隐患排查治理。以保障举办第44届世界遗产大会为契机，加强燃气安全检查，开展燃气隐患排查整改，抓好餐饮场所用气安全整治。严厉查处瓶装液化石油气使用等环节中各类违法违规行为。持续推进烟花爆竹、特种设备、民爆等行业领域专项整治，有效防控安全风险、坚决消除安全隐患。加强职业病防治工作，实施尘肺病防治攻坚行动和职业健康保护行动，做好源头防范。

　　18.扎实排查治理城市道路塌陷隐患。全面梳理排查地下工程施工影响区域、老旧管网集中区域、地下人防工程影响区域主要道路，对发现的塌陷隐患要及时采取措施治理。强化城市道路塌陷源头因素的安全管理，加强对在建地下工程施工现场周边沉降变形加强监测监控，加大道路及沿路地下管道巡查及管理力度，发挥好网格管理员作用，鼓励采用探地雷达等科技手段开展空洞探查，及时研判隐患，制定方案整改。进一步完善城市道路塌陷的巡查防控常态化机制，加大道路、市政管网等城市重大公共设施的检查力度。

　　19.推进城市安全发展。贯彻落实《莆田市关于推进城市安全发展的实施方案》，组织开展城市安全风险综合评估，探索建立城市安全风险分布图。开展重大风险、重大问题排查摸底，建立重大安全生产问题库，并进行挂牌督办。

　　    20.全面加强安全生产示范标杆创建。继续推动构建风险分级管控和隐患排查治理双重预防机制建设，依托专业技术服务机构，在重点行业领域开展示范单位创建。继续深化“树实体标杆，供可学模式”活动，在巩固提升2019年建筑施工等标杆单位基础上，逐步推动道路交通等重点行业领域创建一批标杆单位，实现安全生产管理水平“以点带面、示范引领、整体提升”目标。

　　五、构建完善安全监管执法体系

　　21.完善安全生产相关法律制度和标准规范。结合实际认真贯彻落实危险化学品、道路运输、特种设备等易造成群死群伤行业领域的安全管理制度和相关标准规范，筑牢安全底线。

　　22.健全完善安全生产监管效能提升制度。健全完善生产安全事故调查评估制度，强化生产安全事故调查评估工作，突出发现和解决本质问题，跟踪评估一般事故调查报告提出的整改措施落实情况，不断提升安全生产监管水平。推行“网格化+安全生产”模式，拓展更多行业领域安全生产纳入网格化管理工作体系，发挥网格员走访协查、信息采集、宣传劝导作用。

　　23.坚持严格检查与指导服务并重制度。推动落实对高危行业领域重点企业检查全覆盖，持续开展重点企业专家指导服务等工作；全面推行“双随机、一公开”抽查、先进企业安全承诺、高危企业重点监管模式。

　　六、巩固提升安全生产基础保障体系

　　24.持续推进科技兴安强安。扩大安全风险监测预警系统覆盖面，推动完成所有危险化学品企业重大危险源监控数据的接入。推广应用安全用电综合保障服务系统、智慧消防等科技手段，提升安全防控能力。在房屋建筑、交通设施、水利设施等施工项目领域，全面推行在线智能监控平台，加强作业现场安全防护品佩戴、高空作业等环节线上实时监控。推进安全产业示范企业创建，鼓励企业研发新技术、新产品、新服务，切实解决安全生产突出问题。

　　25.发挥社会化市场化风险防控作用。建立健全“吹哨人”、内部举报人等制度，鼓励企业职工、家属和社会公众检举重大风险隐患和企业违法行为，推进举报奖励政策的落实。支持新闻媒体对安全生产领域进行舆论监督。在高危行业领域依法依规推行安全生产责任保险。推动落实安全生产信用分级分类制度，运用制度化手段倒逼企业落实安全生产主体责任。

　　26.加强重点领域工程治理。持续推进道路交通安全三年专项行动、公路安全生命防护工程建设、团雾多发路段治理、公交车和桥梁防护安全专项治理，鼓励普通国省道设置中央隔离设施。

　　27.提升生产安全事故应急救援能力。支持国家综合性消防救援队伍建设，建强安全生产专业应急救援队伍；配合做大做强中华妈祖应急救援队伍，吸引更多各具特点的专业救援力量加入，统筹规范社会应急力量管理，加强企业救援队伍建设。进一步抓好《生产安全事故应急条例》的宣贯培训，研究制定配套规章标准，切实把各项要求落到实处。

　　28 .加强安全生产宣教培训工作。加强安全生产公益宣传，普及安全知识、培育安全文化，不断创新“安全生产月”、 “安康杯”竞赛、“青年安全生产示范岗”创建、“安全生产法宣传周”、“交通安全日”等活动组织形式，充分利用政府网站、微博微信等线上线下资源，建立安全生产社会化宣传教育矩阵。健全公民安全教育体系。大力实施《福建省贯彻落实<高危行业领域安全技能提升行动计划>实施方案》，全面落实从业人员的各项培训考试制度。
