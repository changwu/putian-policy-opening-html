关于开展“119”消防宣传月活动的通知

发布时间：2020-11-05 16:51
| | |

各监管企业：

　　为深入贯彻习近平总书记“人民至上、生命至上”理念和加强公共安全教育的重要指示精神，进一步推动社会各界关注消防、学习消防、参与消防，不断提升全民消防安全素质，夯实火灾防控基础，维护消防安全形势稳定，结合《莆田市消防工作联席会议办公室关于开展“119”消防宣传月活动的通知》（莆消联办〔2020〕18号）文件要求和部署，决定在全委开展“119”消防宣传月系列活动，具体通知如下：

　　一、 活动时间

　　2020年11月1日至11月30日

　　二、活动主题

　　关注消防、生命至上

　　三、活动内容

　　（一）开展消防主题“大宣传”。各监管企业及其下属子公司要进一步落实消防安全主体责任，围绕“关注消防、生命至上”主题，提前策划，结合各企业实际及行业系统特色，部署开展系列消防安全宣传活动，营造浓厚的消防安全宣传氛围。

　　（二）开展消防安全“大培训”。各监管企业及其下属子公司要组织企业人员开展1次消防安全集中培训，重点开展消防安全法律法规和消防安全知识教育，做到“一懂三会”（懂得本岗位火灾危害性和防火措施，会报火警、会使用灭火设施、会逃生自救）。开展1次消防宣传教育培训，重点组织人员密集场所、高层建筑、大型商业综合体、办公大楼、在建工地、火车站广场、汽车站、农贸市场等开展针对性消防宣传教育培训。

　　（三）开展生命通道“大体验”。各监管企业及其下属子公司开展“畅通生命通道，增强自救技能”体验活动，组织本企业人员对工作、生活场所的疏散通道、安全出口进行1次疏散体验；组织企业人员到消防科普教育基地开展逃生自救体验活动，推动本企业人员学习掌握火灾扑救和逃生自救技能，提升企业火灾应急处置水平。

　　（四）开展消防隐患“大检查”。各监管企业及其下属子公司要组织开展火灾隐患和消防违法行为全面排查整治活动，找准本企业、本行业的消防安全弱点、难点，严格落实消防安全主体责任及消防安全措施。组织、聘请社会专业机构深入企业各场所，协助查改火灾隐患。

　　（五）开展消防安全“大提示”。各监管企业及其下属子公司利用电子显示屏、微信公众号增加消防安全知识和消防工作提示推送频次。充分利用城市标志性建筑、旅游景区、商市场、宾馆酒店、车站、公交、出租车以及宣传栏开展消防安全宣传提示。

　　四、工作要求

　　（一）高度重视，严格落实。“119”消防宣传月活动是一项社会性、全面性活动，是提高全民消防安全素质和自防自救能力的重要手段。各企业要切实提高思想认识，强化主体责任意识，研究制定本企业的消防宣传月活动方案，细化分工、明确责任，围绕主题开展贴近实际、富有成效的消防安全学习宣传活动。

　　（二）精心策划，务求实效。各企业要加强沟通配合，形成工作合力，打造“党政领导重视、部门齐抓共管、公众积极参与”的消防安全学习宣传格局。宣传活动内容要贴近实际、贴近生活、贴近群众，最大限度地扩大消防宣传教育覆盖面。

　　（三）广泛宣传，形成机制。各企业将消防宣传月活动与消防安全专项整治三年行动紧密结合起来，以浓厚的宣传氛围推动消防安全专项整治三年行动开展，并及时总结工作经验，建立消防宣传教育长效工作机制。

　　各企业“119”消防宣传月工作开展情况及实施细节，请于11月23日前报送法规科办公室（联系人：郑一帆，ptgzwzhk@163.com）。
