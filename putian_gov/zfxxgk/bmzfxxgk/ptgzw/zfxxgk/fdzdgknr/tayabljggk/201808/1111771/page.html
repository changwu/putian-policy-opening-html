关于市政协七届二次会议第2018164号提案办理情况的答复

发布时间：2018-08-08 10:46
| | |

陈伟建委员：

你提出的“关于进一步加强城市交通管理的建议”的提案（2018164号）收悉，现将办理情况函复如下：

一、关于优化慢行出行品质问题

提案中所提到的“机动车或人流量很大，冲突明显的，或学校（如，逸夫小学）、医院、城市综合体（万达广场）等周边可以设置天桥或者地道立体过街”问题,根据莆田市人民政府《关于研究推进城乡规划建设管理提升年阶段性攻坚项目有关问题的纪要》（〔2018〕17号）相关指示,“由市住建局牵头，市规划局、交警支队等部门配合，市城投集团子公司莆田市城建停车场管理有限公司作为项目业主。按照先急后缓原则，先行建设筱塘小学、莆田三中、逸夫小学、东园路和北大路交叉口四座人行过街天桥。”及市政府3月9日《关于研究城乡规划建设管理提升年有关项目建设问题的备忘录》“由市城投集团负责，在荔城区第一实验小学和砺城中学中间建设荔涵大道（绶溪公园）人行过街天桥，纳入中心城区人行过街天桥建设计划。”的指示精神，市城投集团正抓紧开展城区人行过街天桥提升工程建设工作。

（一）项目概况

上述拟建的五座天桥根据前期规划选址情况并结合现场实际地形，从方便人流过街的角度出发，同时本着尽量少占地，减少管线搬迁及对周边居民出入影响的原则，经设计单位多方案比选之后，最终确定选址位置，分别位于学园路-筱塘小学段、学园路-莆田三中段、荔城区-逸夫小学段、东园路-东园路与北大路交叉口段、荔涵大道-绶溪公园段。各天桥主桥跨径为26~36米，桥底净高5米 ，桥面净宽3.5米，总宽3.8米；每座天桥设置4个人行梯道，梯道净宽2.1米，总宽2.4米，梯道坡度均为1：2.5，主体采用钢箱梁结构，包含灯光夜景工程。

（二）进展情况

在市政府统筹安排及属地政府、各有关单位的大力支持下，现各天桥项目均已完成项目前期工作，并进入工程施工阶段。其中莆田三中段目前已经完成全部7个承台基坑开挖及地基承载力检测，7月3日开始混凝土浇筑；逸夫小学段、东园路与北大路交叉口段已完成大部分管线迁改工作，桩机开始进场作业；筱塘小学段前正根据沿街产权单位意见对方案进行局部优化调整，待方案调整到位后即进入后续的管线迁改及桩基施工阶段；新增的绶溪公园段天桥项目已完成施工招标，7月上旬开始组织施工单位进场。

上述项目计划在9月份完成主体工程建设，各天桥建成投入使用后，不仅可以保证行人过街的安全，缓解临近学校放学时段学生集中过街人流压力，还能避免过街行人对机动车干扰，提升道路通行能力，改善路段交通拥堵的状况。

二、关于提升公交服务水平，提高出行分担率问题

近年来，市公交集团紧紧围绕服务经济社会、服务群众民生这两大主题，不断开通新线网、添置新车辆、建设新场站，有力地促进了公交事业的全面发展，基本满足了市民的出行需求。推出了一系列特色公交线路：

“园区公交”：为解决各工业园区交通不便的问题，市公司集团根据实际情况，开通了市区通往涵江高新技术园区（218路、231路）、华林工业园区（2路、6路、58路（夜）、101路等）、仙游博览城（501路）的公交专线。

“景区公交”：为解决旅游区游客出行不便的困难，给游客的安全出行提供保障，市公交集团先后开通覆盖九龙谷（96路、98路）、涵江白塘湖公园（211路、212路、215路）、绶溪公园（1路、23路、7路等）、湄洲岛（湄洲1路、湄洲2路、湄洲3路等）线路。为助力创建湄洲岛5A景区，市公交集团加大车辆采购资金投入，于2017年9月在湄洲岛公交线路上投放了33辆全新的纯电动公交车。

“学校公交”：为了方便学生就学，解决家长送子女读书难、交通堵塞等系列问题，市公交集团根据城区各中小学分布情况，开辟了1路、2路、5路、7路、8路、10路、202路等线网，并根据上下学的时间加密班次，延长服务时间，大大方便了学生，缩短了等车的时间，解决了学校门前交通拥堵多年的老问题，也大大缓解了学生家长的忧患。

“医院公交”：为解决莆田山区沿海市民就医不便的问题，市公交集团根据实际情况，推出途经市第一医院及附属医院（13路、17路）、九五医院（2路、28路）、8710部队医院（10路）、江口平民医院（202路）等多条公交线路。

“山区公交”：为了解决山区群众出行难的问题，市公交集团先后开通途经白沙（205路、215路）、新县（219路）、大洋（216路）的山区线路，下一步将结合山区居民实际出行需求，开通覆盖马院的99路。

“快速公交”：为增强公交出行者的吸引力，市公交集团积极响应公务用车改革，根据实际开通了5条快速公交线路，加快了连接市区与各县（区）政府通行速率。K02路（南站至涵江区政府）、K03路（南站至秀屿区政府）、K05路（二中至仙游公交总站）。同时，为接驳码头和动车站，分别开通了K01路（凤凰山直达莆田火车站），K06路（南站直达湄洲岛）。

“旅游定制公交”：为进一步拓展客运旅游业务，完善定制包车服务流程，市公交集团于2016年成立了交运旅游客运公司，为市民旅游提供了多种车型选择和定制线路，满足了各种群体出行需求。

下一步公交集团营运生产部门将根据城市、乡村、山区、沿海、工业园区、旅游景点等不同的出行需求，增加直达枢纽站或功能区的公交线路和班次，进一步优化公交线网布局，提升公交出行服务水平。

 

 

莆田市人民政府国有资产监督管理委员会

                    2018年8月7日
