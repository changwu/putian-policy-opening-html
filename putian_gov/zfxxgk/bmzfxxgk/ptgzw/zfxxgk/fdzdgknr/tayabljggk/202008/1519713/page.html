关于市政协七届四次会议第2020057号提案办理情况的答复

发布时间：2020-08-20 16:27
| | |

 

中国农工民主党福建省莆田市委员会：

　　您们提出的《关于推进地方城投类企业转型发展的提案》（第2020057号）收悉，现将办理情况函复如下：

　　目前，市城投集团职能较为单一，主要承担市政府下达的公益性市政基础设施建设任务，自主经营业务匮乏。伴随财政部《关于规范金融企业对地方政府和国有企业投融资行为有关问题的通知》（财金〔2018〕23号）等政策性文件出台，地方政府举债融资受到严厉管控，城投再融资面临巨大压力，靠负债融资已满足不了日益增长的建设资金需求，现金流、经营利润、偿债能力等“短板”制约了市城投集团的可持续发展。

　　参考其他地区城投转型破解发展困局的成功经验，从“融资端”转型为“投资端”，通过债务置换将存量债务转化为地方债，设立基础设施建设基金，补充用于存量债务偿还的资金，是当下国资国企改革的几个主要方向。在此形势下，市城投集团重新对自身的发展和功能进行定位，比如剥离政府融资职能后，市城投集团在建设、运营、投资、开发等其他领域是否有新的突破口、需要打造什么样的核心竞争力、整合哪些资源、建立什么样的组织运行机制、匹配哪些人才、制定哪些相适应的制度流程等，以上这些都是城投在转型和发展定位过程中一并需要解决的问题。

　　一、融资循环增造血，化解生存难题

　　一是盘活存量。对当前经营流动资金短缺的现状，市城投集团提前制定近期及中远期资金使用计划，积极对接银行，合理调配资金，做好贷款续授信和新增授信工作，力求平稳过渡。同时，积极拓展融资渠道，市城投集团先后成功发行全市首单“内保外债”2亿港元、全市首单“外债直投”2.3亿港元。二是挖潜增量。市城投集团多向发力，充分挖掘社会资金潜力，力求在资本市场中有新突破。2019年11月，向国家发改委递交了15亿元停车场专项债的申报材料，现正处于国家发改委财金司审核反馈阶段；2020年3月，成功发行全市首支定向债务融资工具（PPN），发行总额10亿元；积极探索应用理财直接融资工具，通过委托商业银行对市城投集团债项评级和主体评级的运作，向中国银行保险监督管理委员会申请注册登记理财直接融资工具，作为SPV代替之前的银行通道业务。三是债务置换。跟踪年度预算资金和地方政府债券资金下达情况，抢抓政策机遇，加大地方政府债券资金争取力度。积极申报2020年第一批地方政府专项债券14.8亿元项目资金和2020年补短板稳投资应急专项项目39.443亿元专项资金。

　　二、突出核心竞争力，做大做强主业

　　市城投集团作为城市基础设施建设的主力军，从前期手续办理到工程项目现场施工，积累了丰富的项目管理经验，形成一套独具特色的“城投样本”。在转型过程中，城投将继续突出核心能力建设，巩固提升自身优势，打造企业核心竞争力，培育市场化竞争优势，做大做强“城投品牌”。积极谋划、推进一批对莆田经济社会发展有重大影响的项目，优先做好片区开发等盈利性项目。同时，做好建材、管线、园林、停车场等衍生业务板块的整合植入，盘活各子公司盈利点。比如，整合荔园公司园林绿化业务，合理拓展城市公园及主干道绿化养护、观光农园、花鸟市场、公墓陵园等经营业务。再比如，根据市政府专题会议纪要〔2012〕202号文件精神，“同意市城投集团投资统一建设的地下管网收取适当的投资回报，原则上投资回报率控制在10%左右”，通过经营、管理地下管网（包含售卖、租赁等），收取购买费用或者租赁费用。转型后，政府应与市城投集团建立平等的市场化契约关系，原则上政府应先明确建设资金回购问题或注入等价资产资源，并适当给予政策倾斜。

　　三、探索多元化经营，补齐发展短板

　　市城投集团主动适应新常态，转变传统发展理念和经营模式，坚持稳中求进、科学发展，探索走进市场、融入市场的转型发展之路。一是“老基建”方面。2019年12月，住建部、国家发改委联合印发了《房屋建筑和市政基础设施项目工程总承包管理办法》，鼓励施工单位申请工程设计资质，具有一级以上施工总承包资质的单位可以直接申请相应类别的工程设计甲级资质。该模式目前在建筑市场已大量应用，主要是设计、施工等阶段实行总承包。为适应当前形势，可以对标山西建投“四位一体”全产业链发展先进做法，从工程总承包方向切入，初期与实力国企战略合作，带动市城投集团施工总承包资质升级，逐步推动设计咨询、投资建设、建筑施工、运营维保一体化融合发展。二是“新基建”方面。考虑当前经济环境和疫情的影响，“新基建”政策利好正不断加码，城际交通、物流、市政基础设施，以及5G、人工智能、工业互联网等领域是新型基础设施建设的重要发力点。目前，市城投集团主营业务以外的城市智能停车系统建设、城市智慧汽车基础设施建设、平台经济+大数据建设等业务迎来转机。比如，产业公司在做好国际木材贸易风控的同时，积极探索新增其他贸易板块，拟通过与国企合作等形式，在风险可控的前提下拓展其他国际贸易业务，增加市城投集团经营性收入和贸易现金流。

　　感谢您们对地方城投类企业可持续发展的关注及重视，我们将继续深化改革，做大做强国有企业。
