关于2018年度工资总额结算情况及2019年工资总额预算的通知（城投）

发布时间：2019-10-08 11:23
| | |

莆田市城市建设投资开发集团有限公司：

你司《关于2018年度工资总额预算执行情况及2019年度工资总额预算的报告》（莆城投干〔2019〕23号）收悉。根据《关于印发<所出资企业工资总额预算管理暂行办法>的通知》（莆国资统配〔2018〕9号）等文件精神，经研究，现将2018年度工资总额结算情况及2019年度工资总额预算下达给你司，请严格按照“总额控制，结余留用”原则，统筹合理安排年度工资预算。

一、2018年度工资总额结算情况

（一）2018年度工资总额核定

1、2018年度工资总额基数为1451.56万元。

2、2018年度你司正式员工增员13人（不含引进人才），当年度实际发放工资总额44.33万元，予以核增。

3、2018年度你司正式员工减员3人，预计当年度未发放工资总额5.18万元，予以核减。

4、企业经营效益指标综合增减幅度

根据莆国资统配〔2018〕9号文件精神，你司2018年度经营效益综合指标为43.36%，按照2018年市人社局工资增长指导线8%要求，你司2018年度工资总额使用可增幅8%以内。

综上，你司2018年度工资总额为1606.42万元[（1451.56-5.18）*（1+8%）+44.33=1606.42]。

（二）2018年度工资总额使用情况

2018年度你司实际发放工资2174.26万元。具体如下：

1、预算内发放工资情况

正式员工184人（包含2018年新增正式员工13人，不含停薪留职4人、引进人才2人），实际发放工资总额1474.44万元，具体情况如下：

（1）集团本部71人，发放工资687.99万元；

（2）莆田市荔园园林有限公司29人，发放工资269.6万元；

（3）莆田市市政建设工程公司 40人，发放工资206.9万元（其中仅领职称工资22人〈含半薪2人、发放病假工资1人〉，发放工资38.15万元)；

（4）莆田市城建停车场管理有限公司20人，发放工资141.4万元；

（5）莆田市城建管线服务有限公司14人，发放工资87.34   万元；

（6）莆田市城投建材贸易有限公司12人，发放工资 76.87万元。

（7）发放项目工地驻地伙食补贴4.34万元。

2、单列管理发放工资情况

（1）企业高管6人，实际发放工资139.52万元。

（2）引进人才2名，实际发放工资6.95万元。

（3）临时工(门卫保洁)14人，实际发放工资总额32.98 万元。

（4）项目用工29人，工资总额实际发放236.52万元。             

（5）劳务派遣人员22人，实际发放工资总额176.19万元。

（6）发放正式员工精神文明奖金27.23万元，平安奖金71.27万元。

（7）根据莆财行（2018）125号及莆财行（2018）130号文件的通知分别发放高层次人才补助经费5.78万元、3.38万元，合计9.16万元。

综上，2018年度实际发放预算内工资1474.44万元，预算外实际发放工资699.82万元。

截止2018年你司工资总额结余131.98万元（1606.42-1474.44=131.98）。

二、2019年工资总额预算管理情况

（一）企业负责人工资总额预算情况

你司共有企业高管人员7人，其工资总额将根据我委薪酬管理有关规定及年度业绩考核结果据实予以结算。

（二）普通员工工资总额预算情况

1、2018年工资总额基数为1451.56万元。

2、2018年新进员工13人，预计2019年发放工资总额95.58万元，予以核增工资总额预算基数。

3、2018年度减员3人，予以核减工资总额基数13.01万元。

4、对2019年按照规定程序新增员工，经委审核确认后，给予相应核增正式员工工资总额预算基数。

综上，2019年度普通员工工资总额预算1534.13万元（1451.56+95.58-13.01=1534.13）。

（三）劳务派遣人员工资总额预算情况

2018年劳务派遣人员25人，实际发放工资总额176.19万元，2019年工资总额待年终据实结算。

（四）单列工资总额预算管理情况

1、临时工(门卫保洁)14人，实际发放工资总额32.98 万元。鉴于你司的实际情况，对你司临时工限额10人（门卫保洁），按照企业人均工资的50%包干，超过部分列入工资总额。

2、引进人才2名，实际发放工资6.95万元，待年终据实核算。

3、项目用工29人，工资总额预算227万元，超过部分列入工资总额。

4、对你司获得精神文明和平安企业相应级次荣誉的，按相关文件规定参照执行发放相应奖金, 待年终据实结算。

5、职业经理人工资总额预算按我委核准的标准执行。

6、高层次人才补助经费，按相关文件规定予以发放，待年终据实结算。

（五）工资总额指标结余管理情况

截止2018年度，你司工资总额结余数为248.98万元（117+131.98=248.98）。

 

 

 

莆田市人民政府国有资产监督管理委员会

   2019年9月30日
