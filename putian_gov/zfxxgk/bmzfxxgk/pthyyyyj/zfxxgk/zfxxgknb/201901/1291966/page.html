莆田市海洋与渔业局2018年政府信息公开工作年度报告

发布时间：2019-01-09 15:54
| | |

根据《中华人民共和国政府信息公开条例》《福建省政府信息公开办法》和《莆田市人民政府办公室关于认真总结2018年政务公开工作要点落实情况及做好政府信息公开工作年度报告编制发布有关事项的通知》（莆政办网传〔2018〕64号）有关规定，我局编制了《2018年度政府信息公开工作年度报告》。本报告由概述、主动公开政府信息情况、政府信息依申请公开办理情况、因政府信息公开申请行政复议、提起行政诉讼的情况、政府信息公开工作存在的主要问题及改进措施、需要说明的事项与附表共六个部分组成。本报告中所列数据的统计期限自2018年1月1日起至2018年12月31日止。报告的电子版可在市政府网站（https://www.putian.gov.cn/zfxxgk/bmzfxxgk/pthyyyyj/zfxxgk/zfxxgknb/）政府信息公开专栏里部门政府信息栏目中“莆田市海洋与渔业局”下载。如对本报告有任何疑问，请与莆田市海洋与渔业局政府信息公开工作领导小组办公室联系（地址：莆田市市政府五号楼；邮编：351100；电话：0594-2692095；传真：0594-2685851；电子邮箱：pthyyyj@163.com）。

一、概述

根据本单位工作实际，结合《中华人民共和国政府信息公开条例》《福建省政府信息公开办法》和《莆田市人民政府办公室关于印发莆田市2018年政务公开工作主要任务分解表的通知》（莆政办网传〔2018〕33号）等有关文件精神，完善制度建设，坚持“以公开为常态、不公开为例外”，以公开促落实、以公开促规范、以公开促服务，推进我局政府信息公开工作高效运行。

（一）全面推进政府信息公开工作

2018年，我局累计主动公开政府信息82条，移交档案馆、图书馆82条。以局部门网站、内部政务公开栏等为主要公开载体，不断健全政务舆情收集研判处置和回应机制，同时开设新媒体，不断扩大信息交流平台，全面推进政府信息公开工作。

（二）主要亮点和成效

1.注重政策解读，回应社会关切问题。认真做好有关海洋与渔业的社会热点、难点问题，做好相关舆情监测研判，提出意见建议。注重对重要文件、法规、规章进行解读，及时回应社会关切。2018年我局共上报舆情监测6份，重点解读1份工作细则。

2.规范公开目录，方便群众查阅。按照相关要求，对我局的政府信息公开目录进行进行调整充实，共有6个一级目录，便于群众查阅，扎实推进我局政府信息公开工作，较好地完成了政府信息公开工作任务。切实保障人民群众的知情权、参与权、监督权和表达权。 

3.强化监督检查，确保公开实效。注重政府信息公开工作的监督检查工作，局效能办组织定期或不定期对各科室（单位）的公开工作进行抽查，并把检查结果纳入绩效考核，以此不断提高各科室（单位）的政务公开实效。

   （三）突出重点政务公开落实

局注重政务公开工作，每年定期召开政务公开专题会议，及时研究解决存在的困难和问题，要求各科室、各单位把推行政务公开工作纳入部门的工作计划，同业务工作紧密结合起来，分工明确，责任到人。切实保障经费投入，将政务公开工作经费纳入年度预算范围，实行实报实销。

一是推进决策、执行、管理、服务、结果“五公开”。局政务公开工作坚持以公开为常态、不公开为例外的原则，本部门各项讨论决定的事项，及各部门制定的政策、计划，除依法需要保密的，都通过局部门网站设立的政务公开栏目的子栏目“规划计划”栏目进行公开，2018年我局共公开20份专项规划，2份计划方案,3份计划总结。

在执行公开方面，执行过程以“阳光透明”为原则，通过局部门网站的政务公开栏目“行政权力运行”下的“行政监督”栏目进行公开，2018年我局共公开12份。

在管理公开方面，我局按照部门职能，设立了“专题专栏”栏目，各科室、单位的工作开展情况均在各自专栏下公开，2018年我局专题专栏工作情况共公开了344份。在资金管理方面，设立“财政资金”，公开每个月的“三公经费”使用情况、季度预算执行情况、季度公车费用统计情况及各类资金使用情况等。

在服务公开方面，一是在我局部门网站上设立“举报”专栏、“领导意见箱”，对群众诉求的问题统一接收、按责转办、限时办结，及时公开；二是实现局部门网站与福建省政务服务网对接，更方便服务群众；三是局部门网站与莆田12345平台数据共享，让群众更方便、快捷地知晓自己诉求的结果。

在结果公开方面，局部门网站设立了“公告”、“双公示”栏目，工作执行结果均在网上公开，2018年我局共公开79份。

二是推进政务服务工作开展。全面推广“互联网+政务服务”。2018年我局积极配合市数字办、市行政服务中心完成本单位的任务，每月按时向市数字办报送月进度，积极配合市数字推进局部门网站、网上办事大厅、闽政通app、12345便民服务平台建设，构建全省一体化政务服务平台。局部门网站已完成与省政务服务网站、12345便民服务平台的对接工作。我局进驻省政务服务网的办事事项共22项，2018年共560宗生成电子证照（因系统更新，尚有17宗未生成电子证照），全面推进网上办事服务。实现在省网上办事大厅、莆田市行政审批系统的审批服务办件中有年审的证照免于提交纸质证照。

三是落实重点领域政务公开清单编制。局在编制单位重点领域政务公开清单过程中，积极与省海洋与渔业局相关部门对接、沟通，目前已完成本单位重点领域政务公开清单编制工作。主要涉及到涉海涉渔减税降费信息、涉海重大项目信息、海洋与渔业防灾减灾信息、水产品质量与安全、伏季休渔政策执法信息、海洋渔业资源保护、海洋渔业环境监测与疫病防控、渔业科技创新、渔民教育培训、捕捞标准渔具、渔船违规专项执法等领域，相关信息均在局部门网站相对应栏目公开。2018年共公开涉海重大项目信息30份，海洋与渔业防灾减灾信息408份。

    四是强化政务考核监督。局效能办已将政务公开工作纳入年度绩效考评。局效能办将对各科室（单位）政务公开情况定期、不定期组织抽查，抽查发现的问题在绩效评估中予以运用，促使公开责任落到实处。政务公开工作主要落实情况将纳入政府信息公开年度报告并向社会公布，接受社会监督。

    （四）完善政府信息公开制度

不断更新完善制度建设，在原有的《莆田市海洋与渔业局政府信息公开制度》《莆田市海洋与渔业局政府信息公开保密审查制度》等制度的基础上，2018年又出台了《莆田市海洋与渔业网络宣传平台暨政府信息公开专栏、政务公开目录自查工作方案》，调整充实了《莆田市海洋与渔业信息公开保密审查领导小组》、《莆田市海洋与渔业政务公开领导小组和监督领导小组》。注重政府信息公开保密审查工作，所有公开的信息都必须经过科室（单位）负责人、信息公开领导小组办公室、分管领导审查签字确认后才能发布。明确信息公开审查相关程序，做到以制度管人、按程序办事，为扎实推进政府信息公开工作打下坚实的基础。2018年共审查公开信息数226条，进一步防止泄密事件的发生。

（五）强化政府信息公开机构与队伍建设

局领导对政府信息公开工作高度重视，切实加强对信息公开工作的组织领导，完善充实信息公开领导小组，及时根据人员变化，调整局信息公开领导小组成员，成立由局主要领导担任组长，各分管领导担任副组长、各科室（单位）负责人为小组成员的政府信息公开工作领导小组，并指定1名干部负责日常的政府信息公开工作，各业务科室制定专人作为信息公开工作联系人。政府信息公开办公室下设在局办公室，由专人负责信息政府信息收集、整理和发布等工作。

（六）拓展信息公开渠道

一是继续利用部门网站的政府信息公开专栏，发布最新政府信息，加强对涉及面广、事关群众利益的政策性文件进行解读。二是继续开展政府信息送交“两馆”工作，方便群众查阅。三是通过今日头条、福建长安网、正义莆田等主流媒体主动公开宣传各业务事项。

二、主动公开政府信息情况

（一）本机关主动公开政府信息的数量

2018年度，我局新增主动公开信息82条，历年累计主动公开政府信息1971条，全文电子化率达100%。

（二）主动公开政府信息的主要类别情况

2018年主动公开的主要类别：

1.发展规划类信息28条。

2.组织机构设置类信息22条。

3.法律法规和规范性文件类信息7条。

4.公共事件应急管理类信息5条。

5.监督检查情况类信息16条。

6.主动公开的其他信息类信息4条。

（三）主动公开政府信息的形式

多渠道主动公开政府信息，方便公众查阅。一是通过政府门户网站设置的“政府信息公开专栏”进行查阅。二是按要求每月5日、10日将政府信息公开的文件移送市档案馆、图书馆政府信息查阅场所，供公众查阅。三是在局一楼设立了政务公开栏，将公开的政府信息挂在相应的栏目中，方便干部职工查阅。

（四）开展政策解读工作情况

在局部门网站设立“政策解读”栏目，以加强政策法规解读、妥善回应公众质疑、权威发布重大信息为重点，在出台重要政策时，将文件和解读方案一并报批，相关解读材料及时于文件公开后3个工作日内在政府网站发布，2018年我局重点发布了《莆田市海洋与渔业局“双随机一公开”工作细则》的政策解读，同时转发省海洋与渔业局政策解读2份。

    （五）回应社会关切问题情况

在局部门网站开设了“网络求真”、“网上调查”、“民意征集”、“在线访谈”等栏目，及时回应社会群众关切的热点问题，解决社会疑虑。通过“网上调查”、“民意征集”等栏目，向社会征求有关对海洋与渔业工作的意见、建议，充分尊重民意，引导公众参与。2018年我局共发布3份网上调查、3份民意征集。同时做好咨询回复工作，2018年，通过局部门网站上“领导信箱”、“监督投诉”、“咨询反馈”等栏目收转网友来信0件；通过12345平台受理的咨询投诉件6件，均按规定妥善处理并及时反馈。

三、政府信息依申请公开办理情况

（一）受理申请的数量

    2018年我局共收到1件通过网上申请要求公开的政府信息，历年累计7件。

（二）对申请的办理情况

我局已经按照要求办结1件通过网上申请要求公开的政府信息，该件属于“不予公开”范畴。

（三）“不予公开”的政府信息涉及的主要内容及不予公开原因

    申请人要求申请公开莆田市罗屿港口开发项目申请海域使用申请书、海域使用论证材料、相关的资信证明材料以及审核文件等资料的信息公开申请。根据《中华人民共和国海域使用管理办法》《福建省海域使用管理条例》等法律法规规定，罗屿港口开发项目涉及的海域使用申请由福建省海洋与渔业厅受理，根据《政府信息公开条例》的有关规定，申请人应向福建省海洋与渔业厅提出有关信息公开申请。

四、因政府信息公开申请行政复议、提起行政诉讼的情况

我局2018年度及历年均无因政府信息公开申请行政复议、提起行政诉讼、举报的情况发生。

五、政府信息公开工作存在的主要问题及改进措施

（一）工作中存在的主要问题

2018年，局政府信息公开工作取得了一定的成绩，但与信息公开工作的发展要求、社会公众的需求还有一定差距，主要表现在：一是公开渠道不够丰富、创新，还局限在局部门网站、政务公开栏、传统的报刊、广播、电视等，公开渠道仍需不断拓宽；二是公开内容深度不够，特别是在政策解读、“双随机一公开”方面，局2018年共公开1份政策解读，2份双随机抽查情况；三是宣传力度不够，公众参与度不高。由于缺乏对外政府信息公开的宣传，公众认识、参与度不够。

（二）具体解决办法和改进措施

    一是做好宣传和动员工作。在局机关内部加大宣传学习力度，让局机关广大干部职工了解公开的意义，关心、重视公开，使政府信息公开成为全体干部职工的自觉行为。

    二是拓展公开渠道。充分发挥政府部门网站的公开作用，不断拓展信息公开渠道和载体。结合新形势下公众对海洋事务的关注度，在沿用报刊、广播、电视和政务公开栏等传统载体的同时，多开设在线访谈节目，通过访谈节目对公众关注的问题予以积极回应。同时积极探索运用网络、短信、微信等现代信息手段，提高政府信息公开的时效性和覆盖面。

    三是推进重点领域政府信息公开工作。进一步推进重点领域政府信息公开工作，重点公开与群众利益相关的行政权力运行、财政资金信息、公共资源配置信息等，充分回应社会关切问题。
    四是注重公开时效，保证公开质量。严格遵循政府信息公开基本原则，按照公开时限，及时公开，防止搞形式主义和应付式的工作态度,做到“依法公开,真实公开，保证公开质量。
