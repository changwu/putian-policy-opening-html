各县（区、管委会）海洋与渔业局（办），局机关有关科室，执法支队：
现将市局《关于开展渔船管理督查工作方案》印发给你们，请认真组织实施。
莆田市海洋与渔业局
2015年3月30日
莆田市海洋与渔业局关于
开展渔船管理督查工作方案
为进一步加强和规范渔业船舶登记、检验和捕捞许可证年审及渔船检验费、渔业资源增殖保护费(以下简称“两费”)等渔船管理工作，根据局党组关于开展对全市渔船管理督查专题会议精神要求，制定以下督查工作方案。
一、督查内容
督查的主要内容：2010年以来，渔业船舶登记、检验和捕捞许可证年审情况；“两费”征收管理情况；渔船燃油补助申报、发放情况。各县区要按照上述督查内容全面开展自查，重点检查以下内容：
(
一)渔船档案管理：
渔业船舶登记(含过户)、拆解、检验和捕捞许可证年审档案材料是否及时整理归档、规范、齐全。
(
二)渔业船舶检验：
各年度渔船检验是否存在应检未检问题；办理检验证书是否按证书规范要求及时办理、签发和发给持证人。
(
三)捕捞许可证年审：
各年度年审是否按规范要求办理年审手续、是否存在漏审问题。
(
四)“两费”征收管理：
各年度“两费”征收是否存在漏、少收问题以及执行“票款分离”制度、“两费”票、款管理情况。
(
五)
渔船燃油补助申报、发放：
各年度渔船燃油补助申报、发放资料整理归档是否规范完整，渔船“三证”审核是否规范完整。
二、时间安排
督查时间二个月（ 2015年3月25日至5月24日），分三个阶段：
(
一)工作部署
(3月25日至3月31日)
市、县两级研究制定工作方案，召开会议对具体工作进行布置、落实。
(
二)全面自查
(4月1日至4月15日)
各县区要按照督查内容对照相关法律法规制度要求，认真进行自查，要做到边查边改，对发现存在的问题要逐一整改到位。
(
三)整改提高
(4月16日至5月24日)
各县区对督查、自查中发现存在的问题，要认真研究制定和落实整改措施，确保在5月底全面整改到位，并把渔船管理工作及问题整改情况进行总结报送市局规划法规监督科。
三、工作要求
(
一)加强组织领导。
为加强督查工作的组织领导，市局成立渔船管理督查工作领导小组(附领导小组及办公室成员名单)，负责组织协调指导开展督查工作。各县区渔业主管部门主要领导要高度重视，切实加强领导，亲自抓好落实。要指定相关人员组成工作小组，具体负责自查和问题整改工作的落实。
(
二)认真开展自查。
各县区要按照督查内容，依据相关法律法规制度的要求，认真全面进行对照自查，做到自查全面到位，查找问题不留死角，认真查排渔船管理工作方面存在的问题和薄弱环节。
(
三)及时整改问题。
各县区要按照边查边改、立行立改的原则，制定和落实存在问题的整改措施，确保在5月底全面整改到位。对一些需要其他职能部门协助解决而一时难以整改到位的，要加强沟通协调，逐项制定整改办法，限期整改到位。
(
四)落实岗位职责。
各县区要根据渔船管理业务的需要，合理设置管理岗位，进一步完善和落实岗位职责，加强业务学习培训，提高业务能力和水平，确保渔船管理各项业务工作依法有序开展。各县区要落实配备渔船档案管理和渔船登记、检验、捕捞许可证年审业务管理及“两费”征收管理、渔船燃油补贴申报、发放业务等岗位专(兼)职人员，并于2015年4月2日之前把具体名单报送市局规划法规监督科。
(
五)完善管理制度
。
各县区要切实加强渔船管理制度建设，特别是要针对这次检查发现存在的问题和薄弱环节，依据相关法律法规规定，制定切实可行的管理制度，严格规范渔船管理权力运行，确保渔船管理各项业务工作依法、廉洁、高效。
(
五)强化督查指导。
市督查工作领导小组将按照这次督查内容，组织对各县区自查和问题整改情况进行全程督查指导，市局副处级领导负责督查所挂钩的县区。对没有认真开展自查，问题整改措施不力，问题没有及时整改到位的，要依据相关规定严肃问责。市局将于2015年4月10日前举办全市渔船管理相关岗位业务培训班，指导各县区做好渔船管理业务工作。
