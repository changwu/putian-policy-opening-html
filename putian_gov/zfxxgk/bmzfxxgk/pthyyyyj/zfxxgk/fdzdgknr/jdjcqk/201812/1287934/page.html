莆田市海洋与渔业局关于印发开展农村假冒伪劣食品专项整治行动工作方案的通知

发布时间：2018-12-29 16:57
| | |

 

各县区（管委会）海洋与渔业行政主管部门，局机关各科室，局属各单位：

    为共同开展农村食品质量安全风险隐患排查，全面打击生产经营农村假冒伪劣食品等违法违规行为，加强农村假冒伪劣食品治理，规范农村食品市场秩序，维护群众健康和合法权益，扎实推进乡村振兴战略实施，我局制定了《开展农村假冒伪劣食品专项整治行动工作方案》，现印发给你们，请抓好落实，确保取得成效。

                          莆田市海洋与渔业局

                               2018年12月29日

 

 

莆田市海洋与渔业局开展农村假冒伪劣食品

专项整治行动工作方案

 

    根据《福建省农业农村厅等六单位关于加强农村假冒伪劣食品治理的指导意见》（闽农综〔2018〕223号）、《福建省农业农村厅等六单位关于印发农村假冒伪劣食品专项整治行动方案的通知》（闽农综〔2018〕224号）和《莆田市农业局等七单位关于开展农村假冒伪劣食品专项整治行动实施意见的通知》要求，决定自2018年12月份起，在全市范围内集中开展为期3个月的农村假冒伪劣食品专项整治行动，结合我市水产品质量安全实际，现就加强农村假冒伪劣食品专项整治行动制定如下工作方案。

    一、整治目标

    2019年春节前，农村假冒伪劣食品问题得到有效改善。以专项整治为契机，进一步发动和引导全社会积极参与农村假冒伪劣食品治理，全面规范农村食品生产流通秩序，夯实农村地区食品监管基础，提升农村食品安全水平和保障能力。

    二、整治措施

    全市海洋与渔业系统要在全面贯彻落实《福建省农业农村厅等六单位关于加强农村假冒伪劣食品治理的指导意见》《福建省农业农村厅等六单位关于印发农村假冒伪劣食品专项整治行动方案的通知》和《莆田市农业局等七单位关于开展农村假冒伪劣食品专项整治行动实施意见的通知》要求的整治措施的基础上，进一步认真、扎实抓好以下“五大加强，五个推进”的措施落实。

    （一）加强追溯建设，推进准入准出衔接。各县区（管委会）海洋与渔业部门要持续组织开展水产品生产主体培训，尤其要开展追溯系统操作培训，确保生产经营主体和工商登记在册的水产企业、合作社、家庭农场等用户熟练掌握“一品一码”政策法规、追溯系统平台使用、三项记录填写、上传追溯信息、打印食用水产品追溯准出凭证、追溯码赋码标签打印等内容，实现水产品赋码销售和产地准出，确保2019年1月1日，水产品“一品一码”全程追溯系统正式顺利上线运行。要落实产地准出与市场准入衔接机制，加强与市场监管部门协调配合，确保2019年4月1日起严格执行市场准入制度。

    （二）加强执法检查，推进超标案件全查处。一要深入开展对虾等水产品质量安全专项整治，以整治养殖环节禁用药物、限用药物违规使用行为为重点，采取查处、整治等相结合的手段，大力整顿规范生产经营秩序。二要按照“严密排查、问题导向、标本兼治、铁腕治患”的总要求，深入开展水产品质量安全专项执法行动，对节假日、育苗养殖高峰期、重点养殖区域、重点养殖品种，加大执法巡查力度，消除风险隐患。要开展水产品“一品一码”追溯平台线上巡查和现场指导巡查。要积极出动执法人员，检查水产品生产主体，一旦有假冒伪劣的水产品，就收缴、就查处假冒伪劣水产品案件，为消费者挽回经济损失。坚持严字当头，强化检打联动、联合执法和案件督办的机制，确保市级以上水产品药残超标案件查处率达100%。三要加强与公安、市场监督管理等部门协调配合，推进水产品质量安全违法案件的行政执法与刑事司法衔接工作，杜绝有案不移、以罚代刑，严厉打击养殖过程违法用药行为。

    （三）加强产品抽检，推进产品源头管控。各县区（管委会）海洋与渔业部门要积极落实“两检合一”机制，加强监测、技术推广和行政执法部门的统筹协调，强化水产品质量安全抽检的协同配合，扩大水产品质量安全风险监测、监督抽查、快速检测的覆盖面。2019年全年开展水产品质量安全监督抽查、风险监测、快速检测945次以上，确保水产品质量安全监督抽查合格率稳步提升。今年市局提早陆续下发2019年水产品质量安全风险监测、监督抽查、快速检测任务安排的通知，各县区（管委会）海洋与渔业部门和局属各单位尽早抓好落实。

    （四）加强技术推广，推进精准规范用药。由省水产技术推广总站承担，对鳗鲡、对虾、石斑鱼、大黄鱼、罗非鱼、草鱼、鲫鱼等7个主要养殖品种进行药敏与耐药性试验，筛选敏感药物，反馈并指导养殖业者规范用药、精准用药，形成水产养殖规范、精准、减量用药技术模式。市水产技术推广站和各县区（管委会）尤其是秀屿区渔业部门主动对接省水产技术推广总站积极开展此项工作。同时，强化标准推广应用，提高水产品品质；强化技术服务，不断指导规范食品生产经营行为。

    （五）加强宣传培训，推进社会共治氛围。各县区（管委会）海洋与渔业部门组织要开展宣传活动，通过发放宣传品、加强与传统媒体和新兴传媒合作等方式，宣传普及水产品质量安全知识，提升公众安全意识和判断能力，引导公众科学理性看待水产品质量安全问题。通过开展放心渔资下乡进村宣传周、水产品质量安全宣传周等活动，提高生产经营者和消费者的质量安全意识。通过举办健康生态养殖技术、质量安全管理培训班，指导养殖生产者科学养殖，合理用药。全面完善水产品违禁药残超标养殖企业和个人黑名单制度，充分发挥新闻媒体和社会公众监督作用，畅通投诉举报渠道，营造水产品质量安全社会共治氛围。

    三、时间要求

    （一）部署发动阶段（2018年12月）

    各县区（管委会）海洋与渔业行政主管部门要在当地政府的统一领导下，与农业、商务、公安、食药监、工商及供销合作社相互配合，联合行动，共同开展专项整治行动。要制定符合当地实际情况的专项整治工作方案，周密部署、精心安排、突出重点、迅速行动。

    （二）集中整治阶段（2018年12月—1月）

    各县区（管委会）海洋与渔业行政主管部门组织力量，围绕重点对象、重点品类、重点违法违规行为开展大建设、大检查、大保护、大追查、大行动、大宣传，严打重惩、打出声威、形成震慑，构建共治大氛围，规范农村食品生产经营行为和市场经营秩序。

    （三）调研督促阶段（2019年1月）

    市农业局、商务局、公安局、食品药品监管局、工商局、海洋与渔业局、供销社将联合派出工作组，赴各县区（管委会）实地开展农村假冒伪劣食品治理工作专项调研指导，督促各地专项整治工作取得实效，以良好的工作业绩和准备迎接国家部委和省局的检查督导。

    （四）总结提升阶段（2019年2月）

    及时开展数据统计，挖掘典型案例，总结专项整治行动中的好经验、好做法，提炼形成农村假冒伪劣食品有效监管模式，在全市范围宣传推广，并择优报送省局和国家各部门，争取在全省、全国范围宣传推广。推动建立长效机制，健全完善“黑名单”等制度，落实联合奖惩。

    五、工作要求

    （一）加强组织领导。市局成立农村假冒伪劣食品专项整治工作组（详见附件1），各县区（管委会）海洋与渔业行政主管部门也要成立工作组，强化部门法定职责，建立网格化监管体系，把监管责任落实到岗到人。要在当地政府统一领导下，积极争取财政、发改、税收、科技、信贷等部门支持，加大对农村食品治理工作的财政投入。

    （二）务求工作实效。在专项整治行动期间，对发现的风险隐患和不规范行为，整改率要达到100%；对发现的违法行为，打击和查处率要达到100%；加强行政执法和刑事司法的有效衔接，对涉嫌食品犯罪的案件，依法向公安机关移送率要达到100%。对大要案件要一案一报、挂牌督办、限期办结。对发现涉及其他地区的问题食品，要及时通报相关地区监管部门彻底追查。

    （三）及时报送信息。要建立整治信息报送制度，从2019年1月2日起，各县区（管委会）海洋与渔业部门和局属各单位每周三上午下班前要将本辖区、本级阶段性专项整治情况和统计数据（见附件2统计表）分别向本级专项工作组和市局报送，并于2019年1月18日前报送农村假冒伪劣食品专项整治工作总结（包括整体情况、主要措施、存在的问题、下一步工作安排等）。各县区（管委会）海洋与渔业部门和局属各单位要确定一名联络员，于2019年1月2日前，将联络员的姓名、单位、职务、工作电话、手机、电子邮箱报送至市局渔业管理科。
