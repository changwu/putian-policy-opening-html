莆田市海洋与渔业局关于开展海洋与渔业行政审批事项随机抽查工作的通知

发布时间：2017-08-31 11:46
| | |

各县（区、管委会）海洋与渔业行政主管部门，市海洋与渔业执法支队，局机关各科室：

    为贯彻落实《莆田市人民政府办公室关于做好推广随机抽查机制规范事中事后监管工作的通知》（莆政办〔2016〕80号）和福建省海洋与渔业厅《关于推广随机抽查机制规范事中事后监管的实施方案》（闽海渔〔2016〕52号）,根据《莆田市海洋与渔业局双随机抽查工作实施办法（试行）》（莆海渔〔2016〕120号）要求，为进一步强化行政审批事中事后监管，经研究，决定开展随机抽查工作，现将有关事项通知如下。

　　一、随机抽查事项

　　随机抽查工作按照以下事项的责任分工，由牵头单位负责组织从市场主体库中随机抽取市场主体，从检查单位执法人员名录库中随机抽取参与执法检查的人员对各事项进行检查。对专业性较强的检查事项，检查人员无法独立完成的，应提请检查单位派相关业务人员进行指导。

　　（一）省级委托我局办理的审批事项

　　1.渔业捕捞许可证核发（省级权限）

　　牵头单位：规划法规监督科

　　检查单位：市海洋与渔业执法支队

　　2.渔业船网工具指标批准书的审批

　　牵头单位：规划法规监督科

　　检查单位：市海洋与渔业执法支队

　　（二）市本级承办的行政审批事项

　　1.渔业捕捞许可证核发（市级权限）

　　牵头单位：规划法规监督科

　　检查单位：市海洋与渔业执法支队

　　2.海洋工程建设项目环境影响报告书(表)核准意见落实情况的检查

　　牵头单位：资源环保科

　　检查单位：市海洋与渔业执法支队

　　3.海域使用项目检查

　　牵头单位：海域和海岛管理科

　　检查单位：市海洋与渔业执法支队

　　4.无居民海岛开发利用的检查

　　牵头单位：海域和海岛管理科

　　检查单位：市海洋与渔业执法支队        

　　二、抽查的市场主体

　 （一）已取得省厅委托我局办理的渔业捕捞许可证和渔业船网工具指标批准书的渔业船舶；

　 （二）我局承办的行政许可和公共服务类事项：①已取得市级审批的渔业捕捞许可证的渔业船舶、②已取得海洋环境影响报告书(表)核准或审查意见的用海项目、③已取得海域使用权证的用海项目、④已取得无居民海岛使用权证的用岛项目；

    三、参与抽查检查人员

　 （一）在开展随机抽查工作时，应根据抽查内容，通过抽签的方式，从市局和市支队执法人员名录库中随机选派参与抽查的执法检查人员；

　　（二）对抽查对象实施检查时，选派执法检查人员不得少于2人；

　　（三）执法检查人员与抽查对象有利害关系的，应依法回避。

　　 四、抽查检查方式

　　（一）定向抽查，即按照执法监督检查抽查主体的证件类型、作业区域、地理区域等特定条件，通过摇号等方式，随机抽取待查对象名单进行检查。

　　（二）不定向抽查，即不设定条件，通过摇号等方式，随机抽取确定待查对象名单进行检查。 

　　 五、抽查检查内容

　　（一）捕捞许可证核发行政许可的主要抽查内容：1.检查捕捞许可证取得情况；2.检查捕捞许可实施情况；重点检查作业类型、场所、时限、渔具数量及规格、捕捞品种等是否与捕捞许可证书一致；3.检查捕捞许可终止后有关义务履行情况。

　　（二）渔业船网工具指标行政许可的主要抽查内容：1.检查《渔业船网工具指标批准书》来源情况；2.对照渔船检验证书、渔船登记证书查看渔船信息是否和核准的船网工具指标一致。

　　（三）海洋工程建设项目环境影响报告书(表)核准意见落实情况的主要抽查内容：1.是否遵守环境影响评价制度及“三同时”制度；2.环保设施及污染物排放等是否符合相关管理规定和要求；3.污染防治措施及污染事故的预防和处理措施是否落实等。

　　（四）海域使用项目的主要抽查内容：1.检查海域使用权取得情况。重点检查海域使用权证书或临时海域使用证，核查用海申请人用海项目的真实性；2.检查海域使用许可实施情况。重点检查用海项目名称、占用海域面积、使用期限、用途是否与海域使用权证书一致；3.检查海域使用权人履行义务情况。重点检查海域使用权人是否按照规定办理年审、变更登记、填海项目竣工海域使用验收等事项；4.检查海域使用金是否按时、足额缴纳；5.检查海域使用权终止后有关义务履行情况。重点检查海域使用权终止后，原海域使用权人是否按照规定拆除了可能造成海洋环境污染或者影响其他用海项目的用海设施和构筑物等。

　　（五）无居民海岛开发利用的主要抽查内容：1.检查已确权发证的无居民海岛开发利用项目是否按照《无居民海岛开发利用具体方案》和《无居民海岛开发利用项目论证报告》的要求进行保护和开发建设；2.检查无居民海岛使用金缴纳情况。

　　 六、抽查时间频次

　　 渔业类事项每年随机抽查2次，年抽查比例为市场主体名录库总数的5%；海洋类事项每年随机抽查2次，年抽查比例为市场主体名录库总数的20%。

    七、工作要求

　　（一）各单位要高度重视随机抽查工作，严格按照各级有关随机抽查的工作部署和要求，抓紧开展随机抽查工作，并对工作开展情况做好自查自评；

　　（二）各单位要在实施抽查后7个工作日内完成抽查检查报告，内容包括：检查时间、检查内容、检查情况、对被检查人评价，以及处理意见和建议等。检查报告完成后要及时向被检查对象反馈检查结果； 

　　（三）各单位要依法依规惩处抽查中发现的违法、违规行为，采取针对性强的监督检查方式，将随机抽查结果及时推送省、市公共信用信息平台，纳入市场主体的社会信用记录；

　　（四）各单位要对抽查情况进行存档备案，并于11月10日前向局有关职能科室报送随机抽查工作总结；

　　（五）各单位要增强服务意识，及时帮助群众解决可即知即办的问题，并严格遵守“八项规定”；

　　（六）各县（区、管委会）海洋与渔业行政主管部门要根据当地政府和市局的部署组织开展好随机抽查工作。

　　   

　　                                 

　　                                莆田市海洋与渔业局

　　                                  2017年8月29日
