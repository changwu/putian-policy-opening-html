莆田市海洋与渔业局关于开展护岛2015专项执法行动方案的通知

发布时间：2015-05-20 08:00
| | |

　　各县区（管委会）海洋与渔业行政主管部门，市海洋与渔业执法支队：

　　为了进一步加强我市海岛及其周边海域生态的保护，强化海岛执法检查工作，严厉打击各类违法用岛行为，根据省海监总队《关于转发福建省海洋与渔业厅关于开展护岛2015专项执法行动的通知》（闽海监〔2015〕8号）文件要求，市局决定在全市开展“护岛2015”专项执法行动（以下简称“护岛”行动）。并制定行动实施方案。方案如下：

　　一、任务目标

　　通过开展“护岛”行动，加强对我市辖区内海岛及其周边海域生态的巡查、监管和保护，推进海岛执法工作有序开展，确保海岛保护、开发利用合法有序。

　　二、组织和实施

　　按照“统一领导、属地管辖、分级管理”的原则，行动由市海洋与渔业局统一领导，各县区（管委会）海洋与渔业行政主管部门及其所属的海监机构具体实施。市海监执法支队统筹全市“护岛”行动工作，并指导和督促各县区（管委会）海洋与渔业执法机构开展“护岛”行动。

　　三、主要任务

　　（一）巡查核实。市执法支队、各县区（管委会）海洋与渔业行政主管部门要制定海岛巡查计划，扎实开展巡查工作，并根据确定的海岛名录和相关资料，全面核实本辖区内负责监管的海岛现状。尤其要把有居民海岛、已开发利用无居民海岛、近岸海岛等容易发生违法行为的海岛作为巡查监管的重中之重。如发现海岛名录内的海岛因种种原因目前已失去“海岛”属性或“消失”的，应进一步调查原因，并及时把有关情况报主管局，同时上报市海洋与渔业局、市执法支队。

　　（二）打击违法。市执法支队、各县区（管委会）海洋与渔业执法机构要依托巡查，严厉打击违法围、填海改变海岛岸线；违法在无居民海岛上采石、挖砂，进行生产、建设；违法严重改变无居民海岛自然地形地貌；在海岛周边海域采砂违法用海，破坏海洋环境等违法行为。

　　四、具体要求

　　（一）强化组织领导。各县区（管委会）海洋与渔业行政主管部门、市执法支队要高度重视，将此专项行动纳入年度重点工作，同时加强人员和经费保障，确保“护岛”行动取得实效。

　　（二）加强宣传教育。通过电视、报纸、网络等媒介加强海岛保护的宣传力度，也可对典型案例予以“曝光”，提升公众依法护岛、依法用岛意识；同时要加强执法人员的业务素质培训，提升依法执法的能力。

　　（三）注重巡查效率。按照《福建省无居民海岛巡查执法工作规则》所确定的分工开展巡查；要把有居民海岛、日常有人为活动的已开发利用无居民海岛和特殊用途海岛等重点海岛作为主要巡查对象，加强此类海岛的登岛频度，及时发现查处违法行为。

　　（四）加强案件查处。对违反《海岛保护法》有关规定的海岛违法行为，要加强力量攻关，提高案件的查处率。对《海岛保护法》第四十五、四十九条所设定的违法行为，应当先依据《海岛保护法》立案，后依据海域使用或海洋环保法律、法规作出处罚决定。对违法行为立案查处的，要做到程序合法、证据确凿、定性准确、量罚得当。

　　对主体不明确、无法调查等难以立案查处的违法行为，应当提请当地政府实施综合整治。

　　（五）汇总情况上报。市执法支队、各县区（管委会）海洋与渔业执法机构在巡查过中，要认真对照省总队制作的“海岛分布图”和“海岛名录”光盘，认真核实辖区海岛情况，填写“失去‘海岛属性’无居民海岛核对表”（见附件），并附相关调查报告并于9月25日前报市执法支队。

　　以每季度末为节点，按照《中国海监总队关于汇总海岛执法相关数据工作要求的通知》（海监岛字〔2013〕142号）要求，各县区（管委会）海洋与渔业执法机构及时把行动进展报市执法支队，在汇总行动进展成果时，不限于依据《海岛保护法》立案案件的查处情况，还应把有居民海岛上海洋工程环保监管，海岛周边海域采砂监管、倾废监管等执法工作作为行动成果进行收集。同时，以“护岛”行动为契机，进一步完善海岛的本底资料，做到“一岛一档”。

　　（六）加强指导督促。我市将结合辖区海岛保护执法的实际，围绕 “护岛”行动主要任务和具体要求，加强对辖区县级海洋行政主管部门及其所属海监机构的指导和督促。市支队要经常性组织开展市、县（区）管委会两级海监联合执法，及时了解掌握全市“护岛”行动动态，并通过通报、指定管辖等措施，促进有关海监机构规范、有效开展“护岛”行动。

　　附件：失去“海岛属性”无居民海岛核对表

　　莆田市海洋与渔业局

　　2015年5月20日
