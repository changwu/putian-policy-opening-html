莆田市海洋与渔业局关于进一步加强海底电缆管道保护执法监管工作的通知

发布时间：2017-04-05 10:12
| | |

各县区（管委会）海洋与渔业行政主管部门，局机关相关科室、市海洋与渔业执法支队：

    为进一步加强我市海底电缆管道保护工作，切实保障海底电缆管道运行安全，现将有关事项通知如下：

一、切实加强组织领导

各级海洋行政主管部门要切实加强海底电缆管道保护工作的领导，把海底电缆管道保护工作列入重要议事日程，做到主要领导亲自抓，分管领导具体抓。要结合本辖区实际，周密部署，认真制定巡查工作计划，合理安排每月、每季度的巡查频次，确保监管工作落到实处。推进我市海底电缆管道运行安全的监管保护工作。

二、强化执法巡查监管

市、县两级海洋与渔业执法机构要各负其责、紧密配合，形成合力，强化海底电缆管道区海域的执法巡查监管，依法严查危及海底电缆管道安全的违规行为。各县区海洋执法机构要按照“属地管理”原则，负责对本辖区海底电缆管道区的日常定期巡查（具体分工见附件1），加大执法监管力度，严厉查处违规行为，及时处理可能影响、破坏海底电缆管道正常运行的相关举报件。市支队要加强组织直属执法船队、大队，加大日常巡查频次，定期组织市、县两级海洋执法机构开展联合执法，形成上下齐抓共管合力。

三、严打非法采砂行为

各县区（管委会）要进一步完善联合执法机制，联合海事、边防、海警等涉海执法部门，紧密协作，加大海上综合执法力度。要加强海底电缆管道区执法监管，从严从重查处在海底电缆区周边违法采砂的行为，对进入海底电缆保护区作业的违法采砂船只，要从严从重查处。

四、着力整治岸边砂场

各县区（管委会）海洋与渔业主管部门要加强海域岸线巡查监管组织工作，依法查处非法占用海域建岸边砂场的违法用海行为,并根据《莆田市砂场“两违”专项整治工作方案的通知》（莆清违发〔2016〕4号）文件要求，及时向当地政府移送砂场未经批准占用海域的 “两违”线索，积极主动参与岸边砂场“两违”整治工作。

五、监督落实保护措施

各县区（管委会）海洋与渔业主管部门加强对海底电缆管道用海单位的安全保护措施落实情况进行监督检查,督促海底电缆管道业主采取有效措施，强化日常管护。一是要督促业主依法申报划定海底电缆保护区，为执法监管提供法定依据；二是要督促业主依法设置海底电缆保护区标识、警示牌等，并将路由及保护区范围等相关材料及时报送海事部门备案，避免过往船舶误抛锚等作业而引起危及海底电缆的事件，以起到有效的警示作用；三是要督促业主落实企业主体责任，配备适应海上巡查船舶装备和巡查人员，开展海底电缆安全日常巡查管护工作，及时发现劝阻危及海底电缆安全的行为，对劝阻无效的要及时报请相关职能部门处置。

 

附件：1.莆田市海底电缆管道保护执法巡查分工表。
