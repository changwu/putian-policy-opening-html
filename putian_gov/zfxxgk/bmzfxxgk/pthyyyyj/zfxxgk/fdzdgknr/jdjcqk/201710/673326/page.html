莆田市海洋与渔业局关于印发加强重大风险管控遏制重特大渔业船舶生产安全事故工作实施方案的通知

发布时间：2017-10-10 17:16
| | |

各县（区、管委会）海洋与渔业行政主管部门，局安委会成员单位:

　　根据《福建省海洋与渔业厅关于印发加强重大风险管控遏制重特大渔业船舶生产安全事故整体方案的通知》（闽海渔〔2017〕237号）要求，市局结合工作实际，制定了《莆田市海洋与渔业局加强重大风险管控遏制重特大渔业船舶生产安全事故工作实施方案》，现印发给你们，请认真组织实施。

　　             

　　                                                                                                                                                                 莆田市海洋与渔业局

　　                                                                                                                                                                2017年10月10日

　　

 

加强重大风险管控遏制重特大渔业船舶生产

　　安全事故工作实施方案

　　为进一步贯彻落实《标本兼治遏制重特大事故工作指南》，有效降低和管控重大安全风险，坚决防范遏制渔业船舶水上安全重特大事故，保障人民生命财产安全，制定如下实施方案。

　　一、总体思路

　　（一）指导思想。牢固树立新发展理念，坚守发展决不能以牺牲安全为代价这条不可逾越的红线，强化安全风险预控、关口前移、标本兼治、系统治理，采取制度机制、工程技术、管理等措施，切实把源头治理挺在安全风险管控前面，把安全风险管控挺在隐患前面，把隐患排查治理挺在事故前面，增强安全防范治理能力，提升全市海洋与渔业安全生产整体水平，有效防范和遏制重特大事故，保障人民群众生命财产安全。

　　（二）工作目标。到“十三五”末，基本建成以制度机制为保障、以信息技术为支撑、以行业监管、渔业企业和渔业船舶自控为手段的重大安全风险预防预控体系，在落实源头管控的基础上，对全市重大安全风险进行评估分类、分级管控、在线监测、风险预警和应急联动。

　　为各县（区、管委会）海洋与渔业行政主管部门安办主任。

　　三、主要任务及责任分工

　　（一）制定源头管控机制和措施。各级海洋与渔业行政主管部门及其执法机构要按照《福建省人民政府安委会办公室关于印发落实遏制重特大事故工作指南全面加强安全生产源头管控和安全准入工作实施意见的通知》（闽安委办〔2017〕53号）要求，加快构建渔业船舶船型、渔业从业人员、船用安全终端设备、船用产品的源头管控和安全准入制度体系，不断提升渔业企业和渔业船舶的本质安全水平。

　　责任单位：各级海洋与渔业行政主管部门及其执法机构。

　　（二）制订安全风险辨识标准规范和管控制度。根据《莆田市人民政府安委会办公室关于印发实施遏制重特大事故工作指南构建双重预防机制实施方案的通知》（莆市安办〔2017〕13号）要求和《莆田市海洋与渔业局关于印发莆田市实施遏制重特大渔业安全事故工作指南构建双重预防机制实施方案的通知》（莆海渔〔2017〕83号）工作部署，确定并指导标杆渔业企业和渔业船舶开展双重预防机制建设试点工作，并在2018年3月底前，依据省厅出台的相关标准规范，结合工作实际，分行业制定出台所监管行业领域市级安全风险分级管控和隐患排查治理的制度规范，明确安全风险类别、评估分级的方法和依据、管控的制度措施，明晰重大事故隐患判定依据；组织所监管行业领域企业开展对标活动，开展渔业企业和渔业船舶双重预防机制建设，实现把安全风险控制在隐患形成之前、把隐患消灭在事故前面。

　　责任单位：规划法规监督科（局安办），市海洋与渔业执法支队，县（区、管委会）海洋与渔业行政主管部门及其执法机构。

　　（三）配合省厅升级海上渔业安全应急指挥辅助系统。为适应当前海上安全与应急的需要，拓宽服务领域，做好海上渔业安全应急信息资源的有效整合工作，积极配合省厅升级开发新的系统平台，实现应急处置一个平台、一张图，多元合一促进应急管理，为海上各类突发事件的应急处置提供决策支持。

　　责任单位：局应急指挥中心。

　　四、重大风险管控原则

　　（一）坚持重大安全风险优先原则。切实把全面辨识评估安全风险和严格管控重大安全风险作为安全生产的第一道防线，切实解决“认不清、想不到”等突出问题，把安全风险管控挺在隐患前面。

　　（二）坚持全过程控制原则。树立系统防控安全风险的观念，从人、机、环、管四个方面建立全生命周期的安全风险评估和防控系统，努力把每一个安全风险都控制在可接受范围内。

　　（三）坚持全员参与和持续改进原则。不断强化渔业企业、渔业船舶主体责任和企业员工主体地位，建立和执行好全员负责、全过程控制、自我修复、持续改进加强的多重预防工作机制。

　　五、时间安排

　　第一阶段（2017年8月-2018年底）。各县（区、管委会）海洋与渔业行政主管部门和市局有关科室（单位）按照属地管理、职责分工，研究制订安全风险辨识标准规范、管控制度措施。到2018年底，渔业船舶安全风险辨识标准规范、管控制度基本完善，配合省厅基本建成全市海上渔业安全应急指挥辅助系统。

　　第二阶段（2019－2020年）。各级海洋与渔业行政主管部门及其执法机构组织对渔业企业和渔业船舶重大安全风险进行全面摸排，对重大安全风险实施分级分类管控和风险预警；组织制订渔业船舶安全风险辨识标准规范、管控制度；到2020年底，渔业船舶市级安全风险辨识标准规范、管控制度建立健全；基本建成“一张图、一个源、一个库、统一指挥”的渔业安全生产应急救援指挥平台，基本实现信息实时传递、远程指挥调度、远程会商和协调联动。

　　六、工作要求

　　（一）加强组织领导。市局成立重大安全风险管控领导小组，下设办公室挂靠在市局安办，负责日常协调工作；成立市海洋与渔业重大安全风险管控工作联络组，负责重大安全风险管控具体工作。领导小组办公室建立紧密型的协同会商机制和跟踪督办、考核奖惩、定期通报等工作制度，及时掌握工作落实进度，协调解决跨部门的重大问题。根据省厅安全风险分级分类有关工作部署，及时向省厅重大安全风险管控领导小组提交渔业船舶安全风险分级管控和隐患排查治理的制度规范。各县（区、管委会）海洋与渔业行政主管部门要相应成立领导小组，制订具体的工作实施方案，明确具体负责的工作机构、人员，落实必要的人力、物力、财力保障，确保工作顺利推进。

　　（二）强化改革创新。各县（区、管委会）海洋与渔业行政主管部门要强化目标导向和问题导向，结合贯彻实施《中共中央国务院关于推进安全生产领域改革发展的意见》（中发〔2016〕32号），进一步推进体制机制改革创新，加快相关标准规范的制修订工作，及时清理不符合安全生产要求的准入规定，着力弥补安全生产源头管控和安全准入方面的短板及监管盲区。

　　（三）强化主体责任。渔业企业和渔业船舶要严格落实安全生产主体责任，依法保障安全投入，认真开展安全风险辨识、评估分级，建立重大安全风险监管责任制，对安全风险分级、分层、分类、分专业进行管理，实行红、橙、黄、蓝四色风险管控措施，按规定向本级政府安监部门报送重大安全风险情况，确保渔业企业和渔业船舶的重大安全风险纳入省重大安全风险管控平台进行管理，切实把重大安全风险管控到位。

　　（四）加强重大安全风险摸排管控。各县（区、管委会）海洋与渔业行政主管部门要根据现有标准规范（《福建省渔业船舶安全生产风险分级分类管控办法》），重点摸排渔业船舶、涉氨制冷等存在的重大安全风险。对排查发现的重大安全风险要建立台账，督促渔业企业和渔业船舶落实管控责任，逐项制订管控措施进行有效管控；对构成重大危险源的，督促企业落实辨识、评估、登记、备案管理制度和监测监控措施。

　　（五）强化信息报送。各县（区、管委会）海洋与渔业行政主管部门每季度末要及时总结本地区加强重大安全风险管控工作情况，形成书面材料于每季度最后一个月的30日前报送市重大安全风险管控领导小组办公室（市局安办），每年12月10日前报送全年工作进展情况。市局安委会将结合安全生产考核、巡查，对各县（区、管委会）工作推进情况进行督导检查。
