莆田市海洋与渔业局转发福建省海洋与渔业厅关于进一步加强河豚鱼监管工作的紧急通知

发布时间：2012-05-10 08:00
| | |

　　各县区（管委会）海洋与渔业行政主管部门：

　　现将福建省海洋与渔业厅《关于进一步加强河豚鱼监管工作的紧急通知》（闽海渔电[2012]59号）转发给你们，请认真抓好各项工作落实，并将有关情况及时上报。

　　二0一二年五月十日

　　主题词：渔业  监管  通知

　　抄送：市食安办，市海洋与渔业执法支队，存档。

　　莆田市海洋与渔业局办公室           2012年5月10日印发
