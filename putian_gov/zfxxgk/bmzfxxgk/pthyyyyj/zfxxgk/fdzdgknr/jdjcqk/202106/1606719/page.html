内容概述

莆田市海洋与渔业局关于开展2021年上半年渔业企业暨水产品质量安全监管“双随机、一公开”抽查工作的通知

发布时间：2021-06-04 14:26
| | |

各县（区、管委会）海洋与渔业行政主管部门，市海洋与渔业执法支队、市海洋与渔业环境监测站、后海围垦管理局：

根据《福建省海洋与渔业局关于调整福建省海洋与渔业局随机抽查事项清单的通知》（闽海渔〔2021〕13号）、《莆田市海洋与渔业局关于印发<2021年“双随机一公开”抽查工作计划>的通知》（莆海渔〔2021〕10号）和《莆田市海洋与渔业局关于调整莆田市海洋与渔业局随机抽查事项清单的通知》（莆海渔〔2021〕30号）精神，组织开展2021年上半年渔业“双随机、一公开”抽查工作，现将有关事项通知如下：

一、时间安排

2021年5月28日，完成抽查对象、执法人员、抽检监测人员的随机抽取工作。

2021年5月31日-6月2日，完成本次“双随机、一公开”抽查工作的渔业执法检查和市级产地水产品随机抽检工作。

2021年6月7日至6月11日，完成执法检查、抽检情况统计和抽查结果公示。

二、检查事项

（一）水生野生动物及其产品利用的监督检查

（二）水产苗种进出口的检查

（三）水产品质量安全监督管理

（四）无公害水产品认定后的监督检查（暂无抽查对象）

三、工作流程

①抽取“双随机”抽查事项对应的市场主体名单→②抽取“双随机”抽查执法检查人员、水产品抽检人员名单→③在规定的时间内实施现场检查和产地水产品抽查→④执法机构向局渔业产业科报送检查结果、监测机构向局渔业产业科报送抽检监测报告→⑤对检查事项检查结果进行处置和公示→⑥执法检查机构建立“双随机”执法检查档案。

四、抽查比例

“双随机”抽查以渔业产业科牵头组织，执法机构、监测机构具体实施的方式进行。抽查对象比例按照市场主体库的5%抽取，每个事项随机选派1组（2名）执法人员，水产品质量安全监督管理事项随机选派1组（2名）抽检监测人员。具体如下：

五、工作要求

（一）加强协调配合。各单位要及时调整工作安排，保障“双随机、一公开”任务按时完成，并及时将相关抽查情况报送市局渔业产业科汇总。各县区要积极配合此次抽查工作，帮助协调解决抽查过程中遇到的具体困难问题。

（二）规范抽查流程。以2021年5月份各县（区、管委会）渔业行政主管部门上报的统计结果作为作为本次“双随机”抽查的市场主体库，推广运用福建省地方标准《政府部门“双随机、一公开”监管工作规范》，严格按照随机抽查事项清单规范开展抽查检查，及时公示检查结果。对“双随机”抽查中发现的违法违规行为,及时予以通报,依法进行查处,并纳入市双随机办建立的市场主体诚信系统,做到“惩处一例警示一片”。

（三）完善抽查档案。各单位要建立健全“双随机、一公开”抽查检查相关档案材料，抽查时应当制作相应的执法检查文书、产地水产品抽检记录以及图片资料等,做到全程留痕,成效可鉴。
