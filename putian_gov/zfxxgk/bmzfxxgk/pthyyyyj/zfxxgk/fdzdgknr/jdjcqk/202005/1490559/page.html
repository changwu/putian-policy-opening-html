莆田市海洋与渔业局关于印发《莆田市推进水产绿色健康养殖工作方案》的通知

发布时间：2020-05-21 17:06
| | |

各县（区、管委会）海洋与渔业行政主管部门，局机关各有关科室、局属事业单位：

现将《莆田市推进水产绿色健康养殖工作方案》印发你们，请结合工作实际认真贯彻执行。

 

 

 

                         莆田市海洋与渔业局        

                          2020年5月18日          

莆田市推进水产绿色健康养殖工作方案

 

    为贯彻党中央、国务院关于应对新冠肺炎疫情、做好“六稳”“六保”工作等重要精神，深入落实2020年中央1号文件作出的“推进水产绿色健康养殖”重要部署，以及《关于加快推进水产养殖业绿色发展的若干意见》（农渔发〔2019〕1号）、《农业农村部办公厅关于实施2020年水产绿色健康养殖“五大行动”的通知》（农办渔〔2020〕8号）、《福建省海洋与渔业局关于加快水产养殖业绿色发展十三条措施的通知》（闽海渔〔2019〕121号）有关文件精神，进一步推广先进适用的水产绿色健康养殖技术和模式，加快推进我市水产养殖业绿色健康发展，制定本工作方案。

一、指导思想

全面贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，深入贯彻落实中央、省委决策部署，坚持生态优先、绿色发展，坚持质量兴渔、品牌强渔，坚持融合发展、提升效益，深入推进渔业供给侧结构性改革，加快渔业转型升级，推动我市渔业高质量发展，为全市实施乡村振兴战略作出积极贡献。

二、主要目标

到2022年，水产养殖业绿色健康发展取得明显进展，生产空间布局得到优化，转型升级目标基本实现，水产养殖实现尾水达标排放，养殖水域生态环境进一步改善，水产品质量监督抽查合格率保持在98%以上。

三、重点任务

（一）严格落实养殖水域滩涂规划制度。依据《莆田市养殖水域滩涂规划（2018－2030年）》，统筹生产发展与环境保护，稳定水产健康养殖面积，保障养殖生产空间，加强对重要养殖水域滩涂保护，严格限制养殖水域滩涂占用，严禁擅自改变养殖水域滩涂用途。合理确定养殖密度和规模，鼓励发展不投饵的生态养殖，支持发展深远海大型智能化养殖。依法开展水域滩涂养殖证发证登记工作，做到应发尽发，强化落实持证养殖，推进全市水产养殖绿色健康高质量发展。

责任单位：局渔业产业科、市海洋与渔业执法支队、市水技站、市水科所、后海围垦管理局，各县（区、管委会）海洋与渔业行政主管部门

（二）推广水产生态健康养殖技术模式。结合本地实际，配合国家农业部和省局开展生态健康养殖模式推广行动，积极打造一批可复制、可推广的技术模式样板，辐射带动生态健康养殖技术模式广泛应用，促进水产养殖业绿色发展。筛选推广应用：1.稻渔综合种养技术模式。利用稻田为基础条件，通过渔艺、农艺的融合，对其进行适度整理，在确保水稻稳产的前提下，适度开展水产养殖，做到“一水两用、一田多收”，提升稻田使用效率和经济效益。目前，已有稻虾、稻蟹、稻鱼、稻鳅、稻鳖等多种技术模式。2.工厂化循环水养殖技术模式。在室内建设养殖设施，通过对养殖水进行物理过滤、生物净化、杀菌消毒、脱气增氧等一系列处理后，使全部或部分养殖水得以循环利用的养殖模式。由于养殖过程全程受控，因而具有节水、节地、节约控温能耗、养殖生物生长速度快等显著优势。3.深水抗风浪网箱养殖技术模式。将网箱养殖系统安放在离岸相对较深的水域，开展集约化养殖。目前市场推广的新型深水抗风浪养殖网箱具有较强的抗风、抗浪、抗海流的能力。

责任单位：市水技站、市水科所、后海围垦管理局，各县（区、管委会）海洋与渔业行政主管部门

（三）推进水产养殖设施升级改造。推广应用全塑胶养殖渔排、深水抗风浪养殖网箱和筏式吊养浮球（高密度聚乙烯塑料）等环保型渔业养殖设施，支持水产种业基地、工厂化养殖基地建设和标准化池塘改造。2020年，全市完成深水抗风浪养殖网箱20口以上、普通循环水工厂化养殖基地建设1个、按省级原良种场规模建设的种苗繁育基地1个，加快淘汰老旧渔排，改造建设全塑胶养殖渔排3万平方米以上、筏式吊养浮球1000亩以上，全力推动渔业养殖模式转型升级。

责任单位：各县（区、管委会）海洋与渔业行政主管部门，局渔业产业科、市水技站、市水科所、后海围垦管理局

（四）推进水产养殖尾水生态治理。巩固提升木兰溪流域水产养殖尾水生态治理成效，推进养殖节水减排，鼓励采取进排水改造、生物净化池、循环水利用、人工湿地等技术措施开展集中连片池塘养殖区域和工厂化养殖尾水处理，推动养殖尾水资源化利用或达标排放。进一步加强水产养殖尾水监测，落实养殖尾水排放属地监管职责和生产者环境保护主体责任。

责任单位：各县（区、管委会）海洋与渔业行政主管部门，渔业产业科、市水技站、市海洋与环境监测站

（五）加强水产养殖垃圾污染治理。加快推进淘汰“木质+浮球”等老旧渔排，推广应用新型环保型塑胶渔排，防治渔业养殖区垃圾入海，落实养殖和生活垃圾集中上岸处理，建立长效保洁机制。与生态环境、城市管理环卫等部门协调建立养殖垃圾集中存放点，探索推进贝壳、网衣、浮球等养殖生产副产物及废弃物集中收置和资源化利用，促进养殖水域尽快恢复自然生态环境。

责任单位：各县（区、管委会）海洋与渔业行政主管部门，渔业产业科、后海围垦管理局、市振兴乡村集团

（六）加大水产养殖投入品监管力度。加强水产养殖用药指导，严格落实兽药安全使用管理规定、兽用处方药管理制度以及饲料使用管理制度，加强对水产养殖投入品使用的执法检查，严格执行休药期制度，重拳打击使用假冒伪劣渔用药品、饲料和违法使用其他投入品等行为。持续开展水产养殖精准减量规范用药试点推广，深入推进水产品质量可追溯和信息化监管体系建设，加大产地养殖水产品质量安全风险监测和监督抽查力度，实施有效监管。

责任单位：局渔业产业科、市海洋与渔业执法支队、市水技站、市海洋与环境监测站

四、保障措施

（一）加强组织领导。成立以局主要领导任组长，分管局领导任副组长，相关责任科室和单位主要负责人为成员的工作领导小组，分解目标责任，明确时间节点，精心组织实施。各县（区、管委会）渔业行政主管部门要结合实际，认真研究，细化措施，努力做到步调一致、统一行动、扎实推进。

（二）聚焦政策投入。整合项目、资金、资源，对重点产业、关键领域加大支持力度。积极创新投入机制，探索利用保险、担保、基金等金融手段，鼓励和引导社会资本积极参与。

（三）加大宣传引导。要充分发挥电视、报纸、广播、网络等媒体的作用，全方位、多角度宣传水产健康养殖及质效提升行动。要结合渔业改革创新发展典型案例征集等活动，及时总结宣传好典型、好经验、好做法，营造推动专项行动的良好社会氛围。

（四）强化督办检查。建立督办机制，各责任单位要积极行动，开展专题调研，每季度报一次进度，每年底进行全面总结。市局将加大督导检查力度，强化绩效考核结果运用，确保行动落地见效。

 

 

 

    （此件主动公开）

抄送：莆田市生态环境局。
