莆田市海洋与渔业局关于印发《2016年莆田市海洋与渔业局机关效能建设工作要点》的通知

发布时间：2016-04-29 11:14
| | |

局机关各科室，局直属各单位：

    根据莆田市机关效能建设领导小组《2016年莆田市机关效能建设工作要点》（莆效综〔2016〕1号）文件精神，结合我局机关效能建设工作实际，制定了《2016年莆田市海洋与渔业局机关效能建设工作要点》，现印发给你们，请认真贯彻落实，确保各项工作落到实处。

 

 

                       莆田市海洋与渔业局

                          2016年4月29日

 

 

2016年莆田市海洋与渔业局机关效能建设工作要点

 

2016年,莆田市海洋与渔业局机关效能建设工作的总体要求是：深入学习贯彻党的十八大、十八届三中、四中、五中全会和习近平总书记系列重要讲话精神，全面贯彻五大发展理念，认真落实《关于进一步加强党务政务效能督查工作的实施意见》（莆委办发〔2016〕1号），按照市委、市政府重大决策部署，紧密结合市局各项工作要求，牢固树立和贯彻创新、协调、绿色、开放、共享的新发展理念，聚焦海洋与渔业中心工作，持续传导压力，突出职能职责，强化责任担当，提升“马上就办”实效，为建设海洋经济强市和打造宜业宜商宜居的莆田提供更加有力保障。

一、围绕中心工作，强化效能督查

（一）围绕行动计划开展督查。对接省、市行动计划督查要求，以项目为为主线，查找各科室（单位）在贯彻过程中存在的乱作为、不作为、慢作为等问题；同时对接市效能办、发改委，重点督查后海现代渔业产业园“三个落实到位”情况，以及全市“一月一调度”、“半月一协调”、重大项目“两周一调度”、协调问题“一周一报告”、“两个月项目集中开竣工”等议定事项涉及我局任务落实情况，确保省、市重点用海项目按序时推进。

牵头科室：局办公室（效能办）、后海管理局、海域和海岛管理科

（二）围绕“比服务”和简政放权开展督查。突出围绕各科室（单位）提高工作效能、改进机关作风、优化行政服务、创新工作方法等情况，重点督查推进“四下基层”、“马上就办”、“放管服”三管齐下，项目用海、海洋环评等要素保障和各责任科室（单位）主动服务、优化审批、融资平台建设、渔业品牌打造、海域收储、海域出让、招投标等关键环节“攻坚克难”，以及直面经济下行压力，部门主动作为、帮扶水产企业，共克时艰，提振水产企业发展信心等情况，促进放权到位、服务见效。

牵头科室：局办公室（效能办）、规划法规监督科（审批科），责任科室：海域和海岛管理科、资源环保科、渔业管理科、海洋经济科、海域海岛储备中心、水技站、环境监测站、执法支队、水科所、后海管理局

（三）围绕重要会议议定及主要领导批办事项开展督查。围绕市局《2016年海洋与渔业工作要点》分解任务和局党组、局务会议定事项以及主要领导批示交办事项的落实情况，以及简政放权、办事效率、服务质量、行政作为等情况，重点督查各科室（单位）落实工作进度、措施、成效及存在的问题，建立督查台账，跟踪督促落实。

责任科室：局办公室（效能办）负责，各相关业务科室（单位）配合

（四）围绕机关效能突出问题开展督查。着重围绕各科室（单位）及服务窗口在工作作风、办事效率、服务态度、服务质量等方面存在的突出问题，干部群众提出和反映集中、投诉密集的重要问题以及存在的庸懒散拖、推诿扯皮、敷衍塞责等问题开展督查，对发现的典型问题进行通报。突出对“办事难”、“办证难”的整顿治理，实行直查快办，进一步正风肃纪、固本清源，不断提升执行力和公信力。

责任科室：局办公室（效能办）、监察室负责，各相关业务科室（单位）配合

（五）强化整改与结果运用。建立督查问题台帐，实行销号管理，采取下发《落实与反馈》，以及立项挂牌督办、约谈提醒、效能问责等方式，责令限期整改，逐项进行销号。对整改不到位的，适时组织再督查；对问题集中的科室（单位），实行跟踪督办，直到问题得到有效解决。同时，将督查问责情况作为评先评优和绩效考评的重要依据。

牵头科室：局办公室（效能办）、党支委、监察室

二、深化“马上就办”，提升服务效能

（六）深化“比服务”活动。坚持把“比服务”活动作为深化“马上就办”的重要载体，对去年“比服务”活动情况进行自查自纠，查找突出问题，分门别类加以解决，尽快补齐短板。认真研究制定2016年度“比服务”活动具体实施方案，进一步明确2016年“比服务”活动的总体要求、主要任务和创新举措，建立“比服务”活动的促进机制和保障制度，每月向市效能办及时报送活动开展情况及成效，营造“促创新”和“比服务”的浓厚氛围。

责任科室：局办公室（效能办）负责，各相关业务科室（单位）配合

（七）推进简政放权。做好审批事项“接、放、管”工作，认真对接省海洋与渔业厅取消、下放的行政审批事项，在承接好省厅取消、下放行政审批事项的同时，进一步精简和下放市级行政审批事项，最大限度地减少市级行政审批事项。按照市政府最新公布的行政权力清单、责任清单和公共服务事项清单，进一步调整和规范市、县行政审批事项目录清单，推进市、县权力清单和责任清单有效衔接，全面实施清单管理。

牵头科室：规划法规监督科（审批科），责任单位：海域和海岛管理科、资源环保科、渔业管理科、执法支队

（八）完善窗口建设。按照行政服务中心规范化、标准化建设要求，完善人员入驻管理，落实“一个窗口”对外，确保授权到位、人员到位、服务到位。同时进一步完善项目审批过程通报机制和限时办理承诺制度，强化对审批过程的实时监控，确保审批承诺件限时办结。

牵头科室：规划法规监督科（审批科），责任科室：海域和海岛管理科、资源环保科、渔业管理科、执法支队

三、强化绩效管理，确保指标完成

    （九）优化绩效指标。紧贴新形势新任务，融合市委、市政府重大决策部署、《政府工作报告》确定的经济社会发展目标及市局2016年工作要求，以及培育海洋经济新增长点、推动渔业产业转型升级、促进人与海洋和谐发展等领域，实化细化绩效考评指标。各科室（单位）除完成正常业务指标外，要把工作重点放在绩效对比进步和项目创新上。发挥评估导向作用，探索将重点性、特色性工作纳入绩效体系，形成工作亮点、特色品牌。

    责任科室：局办公室（效能办）、党支委负责，各相关业务科室（单位）配合

（十）加强过程监控。进一步健全绩效管理指标设置、责任分解落实、绩效奖惩等保障制度。各科室（单位）要定期分析本部门的绩效运行状况，加强对年度绩效指标落实情况的监督检查，研究提出改进措施。督促绩效考评数据采集责任部门严格按照规定的标准、程序和方法采集、提供数据。突出互动交流，建立绩效管理“微信群”，即时交流互动。

    责任科室：局办公室（效能办）、党支委负责，各相关业务科室（单位）配合

（十一）严格实施奖惩。实施绩效奖惩，对考评结果为优良的予以表扬，考评结果为差的进行效能问责。年度绩效考评结果将作为干部考察、评先评优的重要依据，促进干部增强责任意识、认真履职尽责。

牵头科室：局办公室（效能办）、党支委、监察室

四、加强组织领导，强化能力建设 

（十二）落实主体责任。各科室（单位）负责人要切实肩负起抓好本单位机关效能建设的责任，对省、市督查通报的问题要抓好整改。同时，把机关效能建设工作与业务工作，同研究、同部署、同检查、同推进，通过层层细化责任、细化措施，把机关效能建设的各项要求落到实处，做到亲自抓、负总责。

牵头科室：局办公室（效能办），责任科室：水技站、环境监测站、执法支队、水科所、后海管理局

（十三）强化队伍建设。各单位要进一步提升队伍素质，统一规范工作机制，健全完善相关制度，促进工作有序开展。

牵头科室：局办公室（效能办），责任科室：水技站、环境监测站、执法支队、水科所、后海管理局

（十四）提升履职能力。局办公室（效能办）要认真贯彻市委《关于进一步加强党务政务效能督查工作的意见》，整合党务、政务和效能督查力量，督查在“深”、“实”上下功夫，突出重点，讲求实效；抓住“准”和“快”，找准问题，查办结合，快速反馈。加强业务沟通交流，通过召开座谈会，或在工作调研中，加强与市效能办在效能建设工作上的沟通交流，学习新经验新做法，促进素质能力和工作水平的提高。

牵头科室：局办公室（效能办）
