莆田市海洋与渔业局关于印发《莆田市海洋与渔业局2019年法治宣传教育计划》的通知

发布时间：2019-05-05 10:03
| | |

各县（区、管委会）海洋与渔业行政主管部门，市海洋与渔业执法支队，局机关各科室，局属事业单位：

为认真贯彻落实《2019年莆田市普法依法治理工作要点》的通知（莆委法办〔2019〕2号），做好2019年海洋与渔业法治宣传工作，我局根据年度工作安排，制定了《莆田市海洋与渔业局2019年法治宣传教育计划》，现印发给你们，请认真贯彻落实。

 

                            莆田市海洋与渔业局

                             2018年4月25日

莆田市海洋与渔业局2019年

法治宣传教育计划

 

2019年，我局法治宣传教育工作以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中全会精神，省委十届七次全会，市委七届七次全会精神，紧扣莆田经济社会发展的目标任务，充分发挥法治宣传教育在全面推进依法治渔和法治海洋建设中的指导性、基础性和规范性作用，为进一步提升现代渔业水平，加快推动海洋与渔业科学发展跨越发展，努力为坚持高质量发展落实赶超、为美丽莆田建设营造更加优良的法治环境。

一、重点任务

（一）学习宣传习近平新时代中国特色社会主义思想。通过多形式学习宣传，把坚持党的全面领导、坚持以人民为中心的发展思想，全面贯彻落实到法治宣传教育工作中，推动全市海洋与渔业部门进一步提高政治站位，牢固树立“四个意识”，坚定“四个自信”，做到“两个维护”，进一步增强走中国特色社会主义道路的自觉性和坚定性。开展习近平总书记全面依法治国理念新思想新战略专题学习活动，党组理论学习中心组、局机关党委、各支部要认真学习贯彻落实习近平总书记在中央全面依法治国委员会第二次会议和中央政法工作会议上的重要讲话精神。深入学习宣传习近平总书记关于全面从严治党的重要论述，大力宣传《中国共产党章程》《中国共产党重大事项请示报告条例》《中国共产党党组工作条例》《中国共产党支部工作条例（试行）》《中国共产党政法工作条例》《党的领导干部考核工作条例》等各项党内法规，注重党内法规宣传与国家法律法规宣传的衔接和协调，坚持纪在法前、纪严于法，把纪律和规矩挺在前面。

（二）持续深入宪法宣传教育提升领导干部宪法意识。坚持把学习宣传宪法摆在首要位置，在海洋与渔业系统普遍开展宪法教育，认真组织好“12·4”国家宪法日集中宣传活动，弘扬宪法精神，树立宪法权威，组织开展宪法精神进渔村主题宣传活动，深入宣传依宪治国、依宪执政等理念,宣传党的领导是宪法实施的最根本保证,宣传宪法确立的基本原则、国家的根本制度、根本任务、国体和政体，公民的基本权利和义务等宪法基本内容，培养宪法意识，增强宪法观念，树立宪法至上理念，维护宪法实施。

（三）持续深入学习宣传海洋与渔业行业法律法规。学习宣传《渔业法》《野生动物保护法》《农产品质量安全法》《中华人民共和国渔业船员管理办法》《福建省渔港和渔业船舶管理条例》《福建省安全生产条例》《福建省食品安全条例》《福建省食品安全信息追溯管理办法》等涉渔法律、法规、规章。组织开展多种形式的法律培训和法治宣传活动，切实提高全系统干部职工自觉守法、依法办事和主动服务莆田经济发展的意识和能力，不断强化广大人民群众遇事找法、解决问题用法、维护权益靠法的法律意识。

    二、工作措施

（一）实施机关周例会学法制度。充分利用局机关每周一学习例会干部职工集中的有利时机，大力开展法律、法规以及规章制度学习，及时更新干部职工法律知识。

（二）结合日常工作送法律下乡。利用日常工作下基层、安全生产专项整治、扫黑除恶等活动的契机，举办培训班和召开座谈会、讲座，在渔区广泛进行海洋与渔业普法教育和宣传，使法治宣传“进渔村、入渔户、上渔船”。

（三）重要时段针对性开展普法。在宪法日、海洋与渔业防灾减灾日、水产品质量安全宣传周、安全生产宣传月等重要时段，通过电视、报刊、发短信、发宣传材料等形式有针对性的进行专门宣传。充分发挥渔港防灾减灾LED屏、微信等媒介积极开展普法，努力扩大海洋与渔业法治宣传的覆盖面。

三、工作要求

（一）领导干部带头学法。领导干部应当成为尊法学法守法用法的模范，带头学习宪法和法律，带头厉行法治、依法办事。进一步落实党组理论中心组学法制度，把宪法、法律和党内法规列入局党组理论中心组年度学习计划。党组书记认真履行第一责任人职责，带头讲法治课，做学法表率。

（二）工作人员学法经常化。落实日常学法制度，工作人员每年度的法律知识培训不得少于40学时。不断拓宽学法渠道，组织开展以案释法、警示教育等，推进学法形式创新。把海洋与渔业法治教育内容作为工作人员入职培训、晋职培训的必训内容。

（三）落实“谁执法谁普法”工作责任制。按照“谁主管谁负责”“谁执法谁普法”“执什么法普什么法”的原则，在管理和服务过程中，结合海洋与渔业行业特点和特定群体的法律需求，有针对性地开展法治宣传教育活动。落实普法责任制，对照年度普法责任清单（详见附件），根据实际需要，从不同群体的特点出发，因地制宜开展有特色的法治宣传教育。各牵头单位于12月15日前将法治宣传教育工作开展情况总结报送局规划法规监督科。
