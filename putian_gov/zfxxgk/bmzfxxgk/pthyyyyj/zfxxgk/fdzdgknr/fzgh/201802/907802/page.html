莆田市海洋与渔业局2017年度政府信息公开工作年度报告

发布时间：2018-01-25 10:40
| | |

莆田市人民政府办公室：

根据《中华人民共和国政府信息公开条例》、《福建省政府信息公开办法》和《莆田市人民政府办公室关于做好2017年政府信息公开工作年度报告编制发布有关事项的通知》（莆政办网传〔2017〕67号）有关规定，我局编制了《2017年度政府信息公开工作年度报告》。本报告由概述、主动公开政府信息情况、政府信息依申请公开办理情况、因政府信息公开申请行政复议、提起行政诉讼的情况、政府信息公开工作存在的主要问题及改进措施、需要说明的事项与附表共六个部分组成。本报告中所列数据的统计期限自2017年1月1日起至2017年12月31日止。报告的电子版可在莆田市海洋与渔业局门户（http://www.phy.gov.cn）“政府信息公开年度报告”专栏下载。如对本报告有任何疑问，请与莆田市海洋与渔业局政府信息公开工作领导小组办公室联系（地址：莆田市市政府五号楼；邮编：351100；电话：0594-2692095；传真：0594-2685851；电子邮箱：pthyyyj@163.com）。

一、概述

2017年以来，我局政府信息公开工作按照市委、市政府的统一部署，深入贯彻落实《中华人民共和国政府信息公开条例》和《福建省政府信息公开办法》等有关规定精神，以政府门户网站、政务公开栏等为主要公开载体，强化组织领导，完善工作机制，深化公开内容，积极推进政府信息公开工作。

（一）加强组织领导，完善制度建设

一是完善组织体系。根据人员变动情况，及时调整充实了由局党组书记、局长任组长，各分管领导任副组长的局政府信息公开工作领导小组，成员由各科室（单位）主要负责人组成，领导小组下设办公室，挂靠在局办公室。坚决把政府信息公开作为一项重要举措，形成主要领导亲自抓，分管领导具体抓，机关各科室协助配合，1名专职人员负责具体的日常公开的工作机制。二是建立健全制度。制定了《莆田市海洋与渔业局政府信息公开制度》、《莆田市海洋与渔业局政府信息公开保密审查制度》和《莆田市海洋与渔业局网络舆情分析研判引导制度》等制度。按照“谁制作、谁公开”的原则，规定了公开的范围、内容、程序、形式等，对不按规定的内容、时间、程序、形式进行公开，或者公开内容失实的科室或个人给予责任追究。对应当主动公开的政府信息坚持“先审查，后公开”“一事一审”的原则，经信息制作人、相应科室（单位）负责人、分管领导层层审查后发布，确保不发生泄密事件。三是全面规范运作。全面完善公开内容和公开栏目，下发了《莆田市海洋与渔业局关于在政务公开工作中进一步做好政务舆情回应的通知》等，建立舆情收集和回应机制、重要政策解读机制，依法公开行政权力运行、年度报告、干部任用、考核奖惩等重要政府信息，做到及时有效发布，回应公众关切问题，正确引导舆论。四是强化考核监督。将政务公开工作与日常绩效相结合，将各科室（单位）政务公开的考评结果纳入年度差异化考核内容中，并采取定期检查与不定期检查的方式，提高各科室（单位）的政务公开水平。

（二）突出政务公开重点，推进工作落实

按照《莆田市人民政府办公室关于印发2017年政务公开工作主要任务分解表的通知》的文件要求，及时印发了《莆田市海洋与渔业局2017年政务公开任务分解表》，把任务分解到各科室（单位）。同时局领导也高度重视政务公开工作，今年局主要领导、分管领导共组织召开了4次专题会议，布置政务公开工作，协调工作中遇到的难点、难题，强调政务公开工作的重要性，层层推进政务公开工作落实。

一是推进决策、执行、管理、服务、结果“五公开”。“以公开为常态、不公开为例外”，着力推进决策公开、执行公开、管理公开、服务公开与结果公开等“五公开”。决策公开作为建设开放透明政务环境的首要环节，我局在局门户网站设立了“规划计划”、“法规文件”等栏目公开局年度重大决策、计划。在执行、结果公开方面，我局在门户网站设立“行政权力运行”、“双公示”等栏目，对行政许可、行政处罚、行政强制、行政征收、行政确认、行政监督等执法行为、结果在网上公开。在管理公开方面，我局设立“专题专栏”栏目，针对社会公众普遍关注的海洋事务，逐一对照专栏公开；同时设立“财政资金”，公开每个月的“三公经费”使用情况、季度预算执行情况、季度公车费用统计情况及各类资金使用情况并接受社会监督。并对公开招投标的政府采购信息及时上网发布，方便单位及个人查询，对中标信息及时予以公布，努力确保招投标过程及结果的公开、公平、公正。在服务公开方面，在我局门户网站上设立“举报”专栏，实现群众诉求的统一接收、按责转办、限时办结，同时与莆田12345平台数据共享，让群众更方便、快捷地了解相关信息。

二是推进重大建设项目批准和实施过程中重点政府信息公开。严格按照《中华人民共和国政府信息公开条例》规定，对重大建设项目批准和实施过程中产生的政府信息，及时按形成之日或变更之日起20个工作日内予以公开。并专门在局门户网上开设“网上办事”栏目，对我局重大项目批准事项的服务信息进行梳理，规范上传了每个批准事项的服务信息，包括申报的要求、申报需要的材料清单、批准流程、办理事项、受理机构联系方式、监督举报方式等，市行政服务中心同步更新相关服务信息。同时在局网站“通知公告”栏目公示项目批准结果信息，以“服务信息”、“结果信息”的公开提升我局项目批准、实施的透明度和效率，保障人民群众合法权益。2017年在局门户网站“通知公告栏目”公示海域使用审核事项17次，海洋环境影响评价事项28次。

三是做好政策解读和回应社会关切问题。在局门户网站网上开设“政策解读”栏目，以加强政策法规解读、妥善回应公众质疑、权威发布重大信息为重点，及时于文件公开后3个工作日内在政府网站发布相关解读材料，让群众第一时间深入了解政策背景、依据、目标任务、涉及的范围等，今年共发布省海洋与渔业厅政策解读4份。同时也开设了“在线访谈”、“民意征求”、“网上调查”栏目。对涉及公众利益的政策措施，通过网上征集、网上调查的方式，引导公众参与、听取公众意见、了解公众需要，接受公众建言献策，并将征集、调查的结果公布。2017年我局共发布1期在线访谈节目、民意征求4份，网上调查4份，实时发布海洋环境预报信息365条、新增各类新闻信息174条，总浏览量1.8万次。同时开设“莆田12345”栏目，对“12345”热线转来的投诉、咨询件都能按规定积极办理，并与莆田12345平台数据共享。

    （三）加强门户网站建设，拓宽公开渠道

在局门户网站设置了“政府信息公开专栏”，以“政府信息公开专栏”为父栏目，又添加“公开指南”“公开目录”“公开规定”“年度报告”“依申请公开”“意见建议”等子栏目，进一步方便企业和群众自行查询。同时有效发挥电视、广播和报纸等传统媒体的作用，在湄洲日报、福建日报、福建长安网、东南网等媒体上刊发主动公开的政府信息。今后我局将不断优化网站建设，拓展公开渠道，创新公开方式，力求以更加及时、准确、生动的平台，提高政府信息公开水平。

（四）加大资金投入，确保工作有序开展

把政府信息公开工作作为一项重要工作来抓，将政府信息公开工作经费纳入年初预算，每年预算3万元经费，为政府信息公开工作有序开展提供有力保障。

二、主动公开政府信息情况

（一）本机关主动公开政府信息的数量

2017年度，我局新增主动公开信息89条，历年累计主动公开政府信息1889条，全文电子化率达100%。

（二）主动公开政府信息的主要类别情况

2017年主动公开的主要类别：

1、机构职能类信息22条。

2、政策、规范性文件类信息6条。

3、规划计划类信息22条。

4、行政许可类信息11条。

5、为民办实事类信息1条。

6、国土资源城乡建设环保能源类信息2条。

6、科技文体卫生类信息1条。

7、安全生产、应急管理类信息24条。

（三）主动公开政府信息的形式

多渠道主动公开政府信息，方便公众查阅。一是通过政府门户网站设置的“政府信息公开专栏”进行查阅。二是通过门户网站在线咨询功能，进行网上咨询，我局会在规定时限内给予回复。三是按要求每月5日、10日将政府信息公开的文件移送市档案馆、图书馆政府信息查阅场所，供公众查阅。四是在局一楼设立了政务公开栏，将公开的政府信息挂在相应的栏目中，方便干部职工查阅。

（四）开展政策解读工作情况

    今年，我局未出台相关的政策解读性文件。但在局门户网站“政策解读”栏目公布了福建省海洋与渔业厅解读的政策性文件。发布了《福建省海岸带保护和利用管理条例》、《福建省海洋经济发展补助资金管理办法》和《福建省远洋渔业补助资金管理办法》等政策解读，以及时加强政策法规解读，妥善回应公众关注重点。

（五）回应社会关切问题情况

    建立《莆田市海洋与渔业局网络舆情分析研判引导制度》，及时借助媒体、网站等渠道发布准确权威信息，讲清事实真相、有关政策措施、处置结果等。结合新形式下公众对海洋事务的关注，我局在门户网站开设了“在线访谈”、“民意征求”、“网上调查”栏目，在制定涉及人民群众切身利益的重大政策措施时，通过网上征集、网上调查的方式，引导公众参与、听取公众意见、了解公众需要，接受公众建言献策，并将征集、调查的结果公布。2017年我局共发布1期在线访谈节目、民意征求4份，网上调查4份。对公众关注的问题予以积极回应，积极争取社会公众对海洋与渔业工作的理解和支持。同时开设“莆田12345”栏目，对“12345”热线转来的投诉、咨询件都能积极办理，与莆田12345平台数据共享

三、政府信息依申请公开办理情况

（一）受理申请的数量

2017年我局没有接到书面或其它形式要求公开政府信息的申请，历年累计6件

（二）对申请的办理情况

我局并未接到书面或其他形式要求公开的政府信息的申请。

（三）“不予公开”的政府信息涉及的主要内容及不予公开原因

无。

四、因政府信息公开申请行政复议、提起行政诉讼的情况

我局2017年度及历年均无因政府信息公开申请行政复议、提起行政诉讼、举报的情况发生。

五、政府信息公开工作存在的主要问题及改进措施

    （一）工作中存在的主要问题。近年来，我局政府信息公开工作取得了一定的成绩，但还存在着一些问题，主要表现在：公开的时效性有待进一步提高；公开的形式还不够丰富；政策法规解读力度还不够；监督力度还不足，监督机制不够完善；政府信息公开宣传教育力度不够，少数干部对政府信息公开工作的认识有待进一步提高等。

    （二）具体解决办法和改进措施。下一步，我局将紧紧围绕党的十九大精神，与加强党风廉政建设紧密结合起来，继续坚持把公开透明作为政府施政的基本准则，继续坚持“公开为原则，不公开为例外”，进一步规范政府信息公开工作，加快公开步伐，深化公开内容，加强平台建设，健全制度保障，强化监督指导，切实增强公开实效，不断提高行政透明度，充分保障公民知情权、参与权和监督权，提升政府行政公信力。

1.继续加强主动公开水平。继续加强对涉及公共利益、公众权益、社会关切及需要社会广泛知晓的政府信息公开力度，主动及时向社会公开应公开的政府信息。

2.提升政府信息公开平台服务功能。加强政府门户网站的建设和管理，增加更多服务功能，力求把网站建设的更加丰富、生动。

    3.进一步完善机构建设和宣传教育工作。加强对政府信息公开机构建设，充实人员队伍，完善公开机制，落实公开政策，加强人员的宣传培训，丰富宣传形式，增强宣传效果，进一步提高干部职工的政府信息公开工作能力。
