莆田市海洋与渔业局关于印发《2015年度创建国家环境保护模范城市实施方案》的通知

发布时间：2015-01-28 08:00
| | |

　　各县（区）、管委会海洋与渔业行政主管部门，局机关各科室：

　　根据《莆田市人民政府办公室关于下达2013年度生态市建设工作计划的通知》（莆政办〔2013〕72号）精神，我局制定了《2015年度创建国家环境保护模范城市实施方案》，现印发给你们，请结合工作实际，认真组织实施。

　　

　　莆田市海洋与渔业局    

　　2015年1月28日     

　　 

　　2015年度创建国家环境保护模范城市实施方案

　　为全面贯彻落实市政府创建国家环境保护模范城市的工作部署，根据《莆田市人民政府办公室关于下达2013年度生态市建设工作计划的通知》（莆政办〔2013〕72号）要求，结合本部门创模的主要工作任务，制定本方案。

　　一、工作目标

　　严格落实市“创模”领导小组工作要求，着眼于环境质量的提高，注重创模的过程和实效，确保在2015年底全面完成海洋与渔业系统的各项“创模”目标任务。

　　 二、工作任务

　　（一）加强水产养殖业污染整治

　　根据《海水养殖水域规划》要求，合理开发利用养殖水域资源，控制水产养殖规模，推进和完善养殖管理制度，推广生态养殖，在养殖集中区成立保洁队，配置垃圾桶、垃圾转运车，租用保洁船和垃圾车，定期清理养殖区垃圾。组织监测人员在养殖区开展水质跟踪监测，并在局门户网站上发布监测结果，科学指导养殖生产。

　　（二）着重清除主河道上施肥和投饵料的养殖网箱

　　各县（区、管委会）海洋与渔业行政主管部门必须在2015年9月30日前清除管辖区域内主河道上施肥和投饵料的网箱养殖，并将清除情况以文字材料报送市局资源环保科。本项工作完成情况列入2015年度海洋环保目标任务落实情况考核内容。

　　海洋与渔业执法机构 负责对养殖户的生产经营行为进行不定期的突击检查，检查内容包括投放饵料、使用禁药行为、用药记录、水产养殖生产许可证、施肥等。

　　三、保障措施

　　（一）成立“创模”领导小组，为“创模”工作提供组织保障。领导小组部署全市海洋与渔业系统创模工作的重要工作任务，负责审定“创模”工作中的重要文件和计划，听取相关部门“创模”进度汇报，研究部署“创模”工作任务。

　　（二）建立“创模”工作例会制度。为保证“创模”目标的实现，掌握“创模”工作的进展情况，协调解决“创模”过程遇到的各种问题，确保“创模”工作有效开展，建立“创模”工作例会制度，定期召开“创模”工作例会，部署工作任务。

　　（三）实行“创模”任务目标考核，定期通报工作进展。责任分工由市局确定后，各责任单位的一把手要对“创模”工作亲自抓、负总责，定期将工作进度情况报告市局“创模”领导小组办公室，市局“创模”领导小组办公室定期对相关责任单位工作进度和完成情况进行通报。

　　（四）加大宣传力度。把“创模”作为今年宣传工作的重点，不断提高公众的环境意识和参与力度，通过充分宣传，广泛动员，让公众了解我市的环境保护状况和努力方向，全面提高全民“创模”意识，为创模工作营造良好的氛围。

　　（五）增强环保投入。积极向上级有关部门争取资金支持，加快环境保护基础设施建设。

　　

　　抄送：市创模办

　　莆田市海洋与渔业局办公室            2015年1月28日印发
