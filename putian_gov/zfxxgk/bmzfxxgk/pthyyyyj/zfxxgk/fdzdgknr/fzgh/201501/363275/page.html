莆田市海洋与渔业局关于印发莆田市2015年渔业安全生产工作计划的通知

发布时间：2015-01-23 08:00
| | |

　　各县、区（管委会）海洋与渔业行政主管部门，市海洋与渔业执法支队，局属事业单位，局安委会成员单位:

　　现将《莆田市2015年渔业安全生产工作计划》印发给你们，请各单位认真抓好落实，并结合工作实际，制定本单位年度安全生产工作计划，于2015年2月5日前报送市局。

　　联系人：规划法规监督科（局安办） 俞智敏 

　　电  话：0594-2619615    传  真：0594-2685851  

　　邮  箱：pthyab@163.com

　　莆田市海洋与渔业局   

　　2015年1月23日    

　　莆田市2015年渔业安全生产工作计划

　　为全面贯彻落实省、市党委政府和上级主管部门有关安全生产工作的指示精神，进一步强化渔业安全生产工作，根据《中华人民共和国安全生产法》、《莆田市安全生产“党政同责、一岗双责”规定》等法律法规规章和《福建省海洋与渔业厅关于印发福建省2015年渔业安全生产工作计划的通知》（闽海渔〔2015〕12号）文件精神，按照市政府安委会部署要求，结合我市渔业安全生产工作实际，制定本计划。

　　一、指导思想

　　认真贯彻落实认真贯彻落实习近平总书记、李克强总理关于安全生产重要讲话精神和省、市党委政府关于加强安全生产工作的重要决策部署，建立健全渔业安全生产“党政同责、一岗双责、齐抓共管”责任体系，进一步落实渔业船舶、渔业企业安全生产主体责任，进一步深化渔业安全制度建设、队伍发展、专项整治、督导检查、标准化提升、宣传培训、应急处置和安全保障，夯实安全生产基础，有效预防重特大事故和减少事故总量，推动全市渔业安全生产形势持续稳定好转。

　　二、工作目标

　　杜绝重大事故，遏制较大事故，控制一般事故。渔业船舶事故死亡人数和较大以上事故起数控制在市政府下达的年度安全生产目标责任指标内。

　　三、工作内容

　　（一）强化安全生产责任落实。通报2014年度渔业安全生产目标管理责任制考评情况；下达2015年渔业安全生产目标责任，进一步强化渔业安全生产监督管理，确保实现年度安全生产目标责任；计划于7月份、12月份开展安全生产目标责任制考评；认真贯彻落实《莆田市安全生产“党政同责、一岗双责”规定》，做好渔业船舶隐患排查专项行动、推进渔业安全生产标准化提升工程三年行动、深入开展油气输送管道隐患整治、推进安全生产标准化提升工程，进一步推进渔业安全生产管理工作，认真开展市县包乡镇、乡镇包村居、村居包渔船（养殖区）责任包干，将安全生产责任落实到每个环节、每个责任单位和每一个人，确保安全生产责任有人担、有人管，全面落实安全生产监督管理责任。

　　（二）强化安全宣传教育培训。围绕“安全生产月”主题，深入开展好安全生产咨询日、警示教育周等安全生产月系列宣传教育活动，宣传普及安全知识；积极组织各县（区）执法大队长或安办主任参加省厅举办的新《安全生产法》和《福建省安全生产“党政同责、一岗双责”规定》培训；继续落实省厅《关于进一步加强渔业安全培训工作的实施意见》（闽海渔〔2013〕85号），加强船东船长、职务船员、专业训练合格证等培训，提高船员持证上岗率。 

　　（三）强化安全隐患专项整治。持续开展“六打六治”打非治违等专项行动，进一步维护海上安全生产秩序；继续深化安全生产隐患排查治理工作，全面深入排查、治理渔业船舶安全隐患；开展渔业安全生产大检查，在重点地区、重点时段、敏感时期适时开展渔业安全监督检查，排查安全隐患。

　　（四）强化应急处置能力提升。加强应急指挥中心建设，加快改革步伐和进度，调整和充实相关工作队伍人员，投入足够的资金保障，建立相应值班、考勤、考核等制度；进一步加强和规范渔业船舶水上事故调查处理工作；计划与部分县区联合开展水上安全应急救助演练，提高渔业安全救助能力；继续推进应急管理标准化建设，积极协助省厅开发福建省海洋与渔业应急指挥决策支持系统；推动海洋渔业北斗应用示范项目建设，至2015年底，完成全市44.1千瓦以上海洋捕捞渔船北斗海事一体化船载终端安装任务，解决外海生产渔船的定位、通信联系、遇险救助和安全监管问题。

　　（五）强化基层基础建设。加强渔船出海编队生产，认真落实渔船出海编队生产作业，加强宣传教育和检查督促，做到所有渔船同时出海、同区作业、同时返回，做到每艘船有编队、每艘船有人管；继续推进渔船公司化协会化管理模式，规范管理制度，进一步解决好渔船管理组织机构不健全、经营管理水平有限、重效益轻安全、没有专职人员负责安全工作等问题，全面提升渔船安全管理水平。

　　  抄送：省海洋与渔业厅安办，市政府安办。

　　  莆田市海洋与渔业局办公室                 2015年1月23日印发
