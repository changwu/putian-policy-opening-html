莆田市海洋与渔业局关于印发《2015年莆田市海洋与渔业局机关效能建设工作要点》的通知

发布时间：2015-05-04 08:00
| | |

　　局机关各科室，局直属各单位：

　　根据莆田市机关效能建设领导小组《2015年莆田市机关效能建设工作要点》（莆效综〔2015〕2号）文件精神，结合我局机关效能建设工作实际，制定了《2015年莆田市海洋与渔业局机关效能建设工作要点》，现印发给你们，请认真贯彻落实，确保各项工作落到实处。

　　莆田市海洋与渔业局

　　2015年5月4日

　　2015年莆田市海洋与渔业局机关效能建设工作要点

　　2015年莆田市海洋与渔业局机关效能建设工作的总体要求是：认真学习贯彻党的十八届三中、四中全会、习近平总书记重要讲话和省委九届十一次、十二次全会精神，按照《2015年莆田市机关效能建设工作要点》的要求，深入实施《福建省机关效能建设工作条例》（以下简称《条例》），坚持改革创新，深化“马上就办”，以绩效管理为抓手，围绕行动计划，加强效能监督检查，强化责任落实，为推进海洋经济强市建设和打造宜业宜商宜居的莆田营造良好环境。

　　一、围绕行动计划，加强监督检查

　　（一）坚持问题导向，突出检查重点。重点围绕省、市行动计划任务落实、南日海洋牧场建设、后海现代渔业产业园区建设、培育壮大海洋产业龙头企业、防灾减灾体系建设、海岛海域收储试点、海洋生态环境保护、重点项目用海保障等8个方面进行检查，主要包括：责任科室单位任务不分解、责任不落实；在落实政策、项目进展、资金使用中慢作为、不作为、乱作为；在项目申报中通知不到位、程序繁琐、办事拖拉；主动靠前指导不到位、协调解决问题不及时；监督检查发现问题整改不及时、不到位等。（责任单位：局效能办、海洋牧场办、渔业管理科、后海管理局、海洋经济科、防灾减灾办、海域海岛收储中心、资源环保科、海域和海岛管理科）

　　 （二）实行条块结合，分段开展检查。局机关各科室、局直属各单位要按照《关于印发进一步加快莆田科学发展跨越发展行动计划、贯彻落实丝绸之路经济带和21世纪海上丝绸之路建设战略行动计划、深入实施生态市战略加快生态文明先行示范区建设工作方案（海洋与渔业部分）任务分解方案的通知》（莆海渔〔2014〕244号）要求，坚持上下联动、条块结合的原则，将自查贯彻于全过程，每季度开展一次自查并上报自查情况；局效能办每季度将适时重点督查，并将督查结果上报市效能办。（责任单位：局效能办、局机关各科室单位）

　　   （三）强化责任落实，加快项目推进。各责任单位要严格按照省、市行动计划及我局任务分解方案，细化目标任务，强化责任落实，加快项目推进。局效能办要采取会议协调、内部通报的方式，确保重点项目建设高效推进。（责任单位：局效能办、局机关各科室单位）

　　   （四）用好检查成果，促进问题整改。监督检查情况在局务会、学习例会上进行通报，纳入年度绩效考评；对工作人员效率低下、推诿扯皮、工作不力等影响重点项目推进的典型问题，实行责任倒查；对省、市督查发现典型问题被通报批评的，局效能办将对有关责任人进行效能问责。（责任单位：局效能办）

　　二、注重科学导向，提升绩效管理

　　  （五）优化指标体系。认真贯彻省市地方标准《政府绩效管理规范》，推进绩效管理标准化建设，制订2015年度市海洋与渔业局绩效管理考评工作方案。简化考评体系，把落实行动计划、海洋牧场建设、产业园区建设、海岛海域收储、海洋生态修复和规范权力运行等内容作为考评重点，增加体现科学发展跨越发展的相关指标。（责任单位：局效能办）

　　（六）强化指标管控。突出常态化，建立日常问题台帐，督促责任单位对以省海洋与渔业厅和市委市政府名义下发的文件加大日常跟踪检查力度，及时发现问题，推进问题整改。结合察访核验，加强对各责任科室单位完成指标情况和数据真实性、准确性的核查，进一步健全完善绩效管理配套制度及工作办法。（责任单位：局效能办）

　　（七）加强结果运用。坚决杜绝不作为、慢作为、乱作为、推诿扯皮、纪律松散等行为，对违反制度规定的人和事，严格按照《条例》进行问责。强化干部管理，把日常督查和各项任务完成情况作为加分扣分依据，并将考评结果与评先评优、年度考核、干部选拔任用等工作相结合，与责任单位的精神文明奖、综治平安奖及责任人的绩效奖励工资挂钩，强化绩效管理的整体效应。（责任单位：局效能办、党支委）

　　三、深化“马上就办”，优化行政服务

　　（八）完善行政审批动态管理机制。要建立市局统一审批目录清单，并对近年来市局承接、取消、下放审批事项进行梳理汇总。要认真配合市效能办、行政服务中心对“放、接、管”三到位情况进行逐项核查。（责任单位：规划法规监督科、审批科、局效能办）

　　（九）深入推进驻中心服务窗口标准化建设。坚持“应进必进”的原则，进一步规范入驻事项，充分授权审批科，确保及时受理，提高办结率。进一步规范重大项目用海、海洋工程环评现场勘查、集体讨论、专家论证、社会听证等环节，明确办理时限。以“三减少、两提高、一促进”为目标（即减少项目、收费、时限，提高服务效率、服务质量，促进公平竞争），持续规范以海洋工程环评影响报告书（表）核准为主要内容的行政审批中介服务行为。（责任单位：规划法规监督科、审批科、资源环保科、海域和海岛管理科）

　　（十）加强网上审批建设。进一步健全完善局网站办事指南、表格下载、在线申报、状态查询、收费标准、特殊人群快速访问通道以及海洋与渔业信息查询系统等办事大厅建设，推进行政审批和公共服务事项网上办理，实现数据互联互通。（责任单位：审批科、规划法规监督科、海域和海岛管理科、资源环保科、渔业管理科、执法支队）

　　四、遵循法治思维，推进效能建设

　　（十一）加大直查快办力度。规范效能投诉件办理，适时分析、梳理投诉问题，采取会议协调、联合办理、现场办公、“一事一通报”等方法，推动问题解决。严格按照《条例》和效能投诉“路线图”要求，健全12345投诉办理机制，建立办件台帐，落实主体责任，提高办理质量。建立12345政务服务知识库，便于现场答复诉求，提高办理效率。（责任单位：局效能办、局机关各科室单位）

　　（十二）注重用好法定手段。强化内部监管，开展内部督查，配合市效能办、评议办重点检查和发现服务作风、服务态度、服务效率等方面存在的“三难”、“中梗阻”、“庸懒散拖”、“为官不为”等典型问题，综合运用提醒谈话、提出建议、效能问责等法定手段，加大整治力度。（责任单位：局效能办、局机关各科室单位）

　　（十三）开展《条例》执行情况专项检查。以配合市人大常委会开展《条例》实施情况专项检查为契机，对全局执行效能制度、推行绩效管理、开展效能督查、办理效能投诉、实施效能问责等情况进行自查，总结经验做法，落实问题整改，健全完善制度，确保全局干部职工队伍不出现违反《条例》的行为。（责任单位：局效能办、局机关各科室单位）

　　莆田市海洋与渔业局办公室            2015年5月4日印发
