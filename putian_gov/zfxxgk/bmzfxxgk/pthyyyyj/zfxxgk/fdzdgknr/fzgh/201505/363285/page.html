关于印发《莆田市海洋与渔业局开展“比服务”活动的工作方案》的通知

发布时间：2015-05-07 08:00
| | |

　　局机关各科室、局直属各单位：

　　现将《莆田市海洋与渔业局开展“比服务”活动的工作方案》印发给你们，请结合实际，认真贯彻落实。

　　

　　莆田市海洋与渔业局

　　2015年5月7日

　　莆田市海洋与渔业局开展“比服务”活动的工作方案

　　按照市效能办《关于印发<开展“比服务”活动的工作方案>的通知》（莆效办〔2015〕7号）和市委办、市府办《关于印发<莆田市落实“三比一看”活动的工作计划>的通知（莆委办发〔2015〕11号）文件要求，为推动“比服务”各项任务落实，现制定如下工作方案：

　　一、目标要求

　　通过开展“比服务”活动，力争实现“四促进”：一是促进机关效能进一步提升，“马上就办”理念得到自觉践行，效能制度得到有效落实，办事效率得到切实提高；二是促进机关作风进一步改进，“四下基层”优良传统得到弘扬，干部为基层排忧解难得到加强，基层反映的突出矛盾和实际问题得到基本解决；三是促进行政服务进一步优化，审批更简便，管理更规范，服务更主动，办事更透明；四是促进要素保障进一步落实，重点项目用海、互助成长资金等难题得到及时有效解决，征海工作和谐顺畅，政银企合作密切。

　　二、活动内容及任务分工

　　整个活动围绕“提高工作效能”、“保障项目建设”、“深入基层一线”、“帮扶企业发展”四个方面，将市里布置的任务分解细化为11项任务。

　　（一）提高工作效能。重点比思想解放不解放，比放权力度大不大，比行政审批事项削减、审批服务方式创新、审批流程优化、审批事项缩短、行政审批和公共服务事项网上办理，以及下放的行政审批事项承接办理等情况。

　　    1.削减行政审批事项。按照“能减则减、能放则放、能快则快、能优则优”的原则，对海域和海岛管理科、资源环保科、渔业管理科、规划法规监督科、执法支队等5个科室单位保留的2项行政许可和4项公共服务事项，进一步精简，凡与公共利益无关，市场竞争机制、行业组织可自主调节，或局机关采用事中、事后监管等方式能够解决，以及没有办件量的事项一律不再保留为行政审批事项。（牵头单位：规划法规监督科、审批科，责任单位：海域和海岛管理科、资源环保科、渔业管理科、执法支队；完成时限：全年）

　　2.落实三张“清单”。落实行政权力清单制度，做到“法无授权不可为”；细化职能部门责任清单，针对不同岗位明确具体责任，分级细化责任归属、确定具体责任承担者，做到“法定职责必须为”；完善公共服务事项、审批目录清单，形成审批要素信息库，实行动态调整。（牵头单位：规划法规监督科、审批科，责任单位：海域和海岛管理科、资源环保科、渔业管理科、执法支队；完成时限：2015年4月前完成初稿并上报）

　　3.创新审批服务方式。积极推行延时、预约、上门、代办、网上预审等特色服务；加强和改进渔船服务管理，切实规范标识管理、检验管理和登记程序，进一步提高便民服务水平和群众满意率。（牵头单位：规划法规监督科、审批科，责任单位：海域和海岛管理科、资源环保科、渔业管理科、执法支队；完成时限：全年）

　　  4.优化审批流程和缩短审批时限。承诺件实行限时办理，严格落实办理环节统一压缩到5个环节以内、办理时限统一控制在法定时限60%以内，提高当日办结率。进一步规范重大项目用海、海洋工程环评等审批事项的现场勘查、集体讨论、专家论证、社会听证等环节，明确办理时限。以“三减少、两提高、一促进”为目标（即减少项目、收费、时限，提高服务效率、服务质量，促进公平竞争），持续规范海洋工程环境影响报告书（表）核准行政审批中介服务行为。推进项目用海、海洋环评等项目的并联审批，促进项目提速提效。（牵头单位：规划法规监督科、审批科，责任单位：海域和海岛管理科、资源环保科、渔业管理科、执法支队；完成时限：全年）

　　5.规范网上办理。认真配合市行政服务中心，全面规范局系统网上办理事项目录和内容，推进行政审批和公共服务事项网上办理，实现数据互联互通。（牵头单位：规划法规监督科、审批科，责任单位：海域和海岛管理科、资源环保科、渔业管理科、执法支队；完成时限：2015年5月前）

　　6.做好下放的行政审批事项承接办理。建立全局统一审批目录清单，对近年来取消、下放、调整的审批事项进行梳理汇总形成目录库，对“放、接、管”三到位情况进行逐项核查，切实做好承接和落实工作。（牵头单位：规划法规监督科、审批科，责任单位：海域和海岛管理科、资源环保科、渔业管理科、执法支队；完成时限：2015年6月前）

　　（二）保障项目建设。重点比创新办法多不多，比协作配合好不好，比海域、资金等相关要素保障情况。

　　7.保障项目用海。上半年取得省政府批复的项目用海10宗，用海面积3500亩；市政府审批的项目用海4宗，用海面积11000亩。全年取得省政府批复的项目用海16宗，用海面积6000亩；市政府审批的项目用海6宗，用海面积13500亩。一是推进重点项目用海报批，向上争取围填海指标，统筹安排项目用海报批时间节点。二是推进区域用海建设规划实施，重点推进石门澳、涵江临港产业园、莆头作业区等3个区域建设用海规划的实施。三是科学编制新一轮市级海洋功能区划，争取将湄洲岛轮渡第二通道工程用海、前海盐田区等海域的海洋功能区划调整列入本轮市级海洋功能区划修编内容，为我市经济发展预备足够的用海空间。（责任单位：海域和海岛管理科；完成时限：全年）

　　8.融资平台建设。深化海洋融资平台建设，加强与农村商业银行等银行的合作，积极拓展海洋与渔业产业融资渠道，做大做强海洋牧场成长资金、渔船更新改造发展资金等“政、银、企”合作融资平台，推动开展海域使用权抵押、无居民海岛权证抵押、在建船舶抵押和“渔船+保单”抵押贷款等金融业务，鼓励渔区建立渔业互助担保基金。（牵头单位：规划法规监督科、渔业管理科，责任单位：海洋牧场办、海域海岛管理科、渔保办；完成时限：全年）

　　（三）深入基层一线。重点比下基层解决问题的情况。

　　 9.坚持“四下基层”。提高干部为基层排忧解难的能力，及时协调解决基层反映的困难和问题，切实做到发现问题在一线，化解矛盾在一线，工作落实在一线。局领导干部每月至少安排一次到基层现场办公，及时协调解决。一是信访接待下基层。落实接待群众来访制度，听取群众诉求，化解矛盾纠纷，解决好联系和服务群众“最后一公里”问题，维护渔区社会稳定。二是现场办公下基层。严格执行精简会议有关规定和“无会周”制度，推行“一线工作法”，广泛听取各方面意见建议，现场研究解决问题。三是调查研究下基层。深入基层收集和反映重要民情事项，记好“民情日记”，用调研成果促进问题解决。四是宣传党的方针政策下基层。宣传党的路线方针政策和省委、市委的决策部署，开展海洋与渔业法律法规、政策、信息、科技咨询服务活动，有针对性地回答基层关心的重大理论和现实问题。（牵头单位：局办公室，责任单位：局机关各科室各单位；完成时限：全年）

　　（四）帮扶企业发展。重点比服务意识强不强，比增长政策落实、企业减负、执行涉企收费清单等情况。

　　10.落实稳增长政策。加强宣传解读，通过局门户网站、新闻媒体、邮件、短信、QQ、微信，及时主动把涉海涉渔惠企政策传递到用海单位和水产品加工企业，提升强渔惠农政策知晓率，让企业用好用足政策。及时配套政策，更好发挥政策叠加和扩大效应。着力引导对接，利用“6·18”“9·8”项目成果交易会等平台，促进科技项目成果与企业对接。开展权力运行网上公开，进一步优化政策兑现流程，简化海洋与渔业项目资金申报手续。采取面对面交流、专题座谈、问题会诊、答疑解惑等形式，主动帮助企业解决生产经营中遇到的困难和问题。（责任单位：海洋经济科、渔业管理科、规划法规监督科、海域和海岛管理科、海域和海岛储备中心、水技站、水科所、后海管理局；完成时限：全年）

　　    11.减轻企业负担。清理和规范各种涉企行政收费项目，建立涉企收费目录清单制度，目录清单之外的涉企收费，一律不得执行。（牵头单位：规划法规监督科，责任单位：海域和海岛管理科、水技站、执法支队；完成时限：2015年6月前）

　　三、保障措施

　　（一）加强日常跟踪。局效能办要根据“比服务”内容，制定具体方案，细化目标任务，逐项明确责任科室单位和完成时限。局机关各责任单位要认真对照“比服务”内容，于每月8日前将进展情况电子版（见附件）报送局办公室汇总，局办公室还要于每月10日前将进展情况报送市效能办。

　　 （二）强化效能督查。局效能办要把“比服务”情况作为今年效能督查的重要内容，与落实“行动计划”督查相结合，通过会议协调、内部通报等形式，督促各责任单位抓紧抓实抓好，确保各项任务落实到位。

　　（三）纳入绩效考评。局效能办要充分发挥绩效导向作用，把开展“比服务”情况纳入年度绩效考评指标体系，实行奖优罚劣，形成比学赶超的氛围。
