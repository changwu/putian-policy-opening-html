莆田市海洋与渔业局关于印发莆田市2019年渔业安全生产应急救援演练实施方案的通知

发布时间：2019-06-25 11:38
| | |

 

秀屿区海洋与渔业局，局相关科室及直属单位，莆田市渔保办：

为检验和提高渔业船员海上自救互救实际操作能力，根据市政府安委会和省海洋与渔业局关于开展2019年安全生产月活动的工作部署要求和2019年全市渔业安全生产应急演练计划，市局决定在秀屿区平海镇平海村举行2019年莆田市渔业安全生产应急处置渔船船员自救互救实际操作演练。现将《莆田市2019年渔业安全生产应急救援演练实施方案》印发你们，请按照方案要求，认真组织实施。

莆田市海洋与渔业局

2019年6月18日　　　　

           2019年莆田市渔业安全生产应急救援演练实施方案

 

一、演练目的：检验和提高渔船船员海上求生、船舶消防灭火、海上急救和救生筏操纵应急反应操作能力；宣传渔业互保政策。

二、主办单位：莆田市海洋与渔业局

    承办单位：秀屿区海洋与渔业局、莆田市渔保办

协办单位：秀屿区平海镇镇政府、平海镇平海村村委会

三、组织领导：成立莆田市2019年渔业安全生产应急救援演练领导小组（指挥部），组长（总指挥）由市局余毅理副局长担任，副组长（现场总指挥）由秀屿区海洋与渔业局林国存副局长担任，成员由市局安办、防灾减灾科、市海洋与渔业执法支队、市渔保办和秀屿区海洋与渔业局相关人员组成。领导小组负责本次演练的组织、协调、指挥工作。

四、演练时间与地点：

（一）时间：2019年6月27日上午9：30-11：30(如遇气候不适，将另行通知）。

（二）地点：船舶消防灭火、海上急救演练地点在秀屿区平海镇平海渔港。海上求生、救生筏操纵演练地点在秀屿区平海镇平海渔港水域。

五、参加对象：

（一）市局分管领导，市局安办、防灾减灾科、指挥中心，市海洋与渔业执法支队，莆田市渔保办相关人员，秀屿区海洋与渔业局相关人员。

（二）平海镇镇政府和平海镇平海村相关人员，平海镇参加渔业专业训练合格证（简称“四小证”）培训的渔民和船员培训机构的指导老师。

（三）当地渔民20人及其他县区渔民观摩代表。

六、演练科目：

演练科目包括海上急救、船舶消防灭火、海上求生和救生筏操纵四个方面。

（一）海上急救：模拟船员操纵机械时受伤进行包扎；模拟船员溺水进行人工急救。

（二）船舶消防灭火：模拟船舶失火，船长组织船员扑救灭火。

（三）海上求生与救生筏操纵演练：模拟船舶触礁沉没，船员弃船逃生。船长组织船员施放求救信号，释放救生筏，船员穿着救生衣跳水攀上救生筏逃生。

七、筹备工作

（一）领导小组办公室下设演练组、联络组和后勤保障宣传组三个小组。演练组由船员培训机构和秀屿区海洋与渔业局负责。联络组由市局防灾减灾科负责人、秀屿区海洋与渔业执法大队负责人、平海村村主任负责。后勤保障宣传组由秀屿区海洋与渔业局办公室负责。联络人员名单和联络电话：市局余志明138****7018，秀屿区局吴志鹏138****0991，平海村委会高双奇189****3188。

（二）参演船艇3艘，由秀屿区大队所属渔政艇和平海村两艘渔船组成。演练场地、两艘参演船和渔民担任演练人员的准备工作由秀屿区大队和平海村委会负责。

（三）实操演练所用的求生、救生、急救、消防器材由船员培训机构提供。

（四）救生筏、火焰信号弹及其他现场用品由市渔保办提供。

八、具体时间安排

（一）演练前准备（6月26日）

1、进行预演练，参演船舶、演练人员必须参加，熟悉演练流程，并进一步完善演练步骤、流程。

2、派出中国海监8041船艇对演练水域进行清场和警戒。

（二）演练实施阶段（6月27日）

演练前2小时，所有联络人到达指定位置；演练前1小时，参演两艘渔船到达指定位置锚泊；演练前30分钟，所有观摩人员、演练人员到达指定位置；上午9:30时，演练总指挥余毅理副局长发布指令，宣布演练开始。

1.海上急救

（1）模拟船员受外伤进行三角巾包扎。

（2）模拟船员溺水被救上后进行人工呼吸和胸外按压。

   （3）联络员郭承恩向现场总指挥林国存副局长报告，人员成功获救，海上急救科目演练结束。

2.船舶消防灭火

（1）模拟3个火盆点燃柴油后灭火。

（2）联络员郭承恩向现场总指挥林国存副局长报告，渔船大火扑灭，火险解除，船舶消防灭火科目演练结束。

3.海上求生与救生筏操纵

（1）参演A渔船模拟触礁事故，船舱大量进水，船长决定弃船，船长向同编队的B渔船呼救、施放声号（三长声），指挥3名船员分别施放红光火焰信号弹、释放救生筏，抛下救生圈，组织船员跳水攀上救生筏。

（2）4名船员穿着救生衣从船舷跳水游泳到放开救生筏旁，攀爬上救生筏。

（3）模拟救助船同编队生产的B渔船接到A渔船险情求救后立即赶到参与救助，如有落水船员未爬上救生筏，B渔船要立即抛下救生圈参与救助落水人员。

（4）在成功救起落水人员和完成伤员转移后，海上人员搜救行动结束。联络员郭承恩向现场总指挥林国存副局长报告，落水人员全部获救，险情排除。

4.现场总指挥向演练总指挥报告，渔船员海上自救互救实操演练四个科目全部顺利完成。

5.集中人员，由莆田市渔保办现场讲解渔业互保政策。

6.总指挥宣布，2019年莆田市渔业安全生产应急处置渔船员自救互救实际操作演练圆满结束。

   九、工作要求：

（一）演练前，联络员、参演人员务必熟悉演练实施方案各项要求。

（二）培训机构要确保提供的演练设备、器材处于安全适用状态。

（三）参演人员、船舶务必按要求提前到岗到位，服从演练指挥并注意安全。

（四）秀屿区局要协调平海镇政府和平海村委会提前组织做好演练场地清洁、参演船员通知、参演船舶安排、停车规划、后勤保障和宣传工作。

   （五）市局防灾减灾科要加强与秀屿区局的沟通协调，做细演练环节，完善演练流程，制定演练脚本。
