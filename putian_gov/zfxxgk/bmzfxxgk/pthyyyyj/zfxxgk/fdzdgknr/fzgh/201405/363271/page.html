中共莆田市海洋与渔业局支部委员会关于印发《2014年市局机关党建工作要点》的通知

发布时间：2014-05-05 08:00
| | |

　　局机关各科室、局直属各单位：

　　现将《2014年市局机关党建工作要点》印发给你们，请结合实际，认真贯彻执行。

　　中共莆田市海洋与渔业局支部委员会    

　　2014年5月5日  

　　 

　　抄送：市农办。     

　　莆田市海洋与渔业局办公室　             2014年5月5日印发

　　2014年市局机关党建工作要点

　　2014年是贯彻落实党的十八届三中全会精神、全面深化改革、深入推进海洋经济强市建设的重要一年。今年我局机关党建工作的总体要求是：以党的十八大、十八届三中全会和习近平总书记系列重要讲话精神为指南，按照省委、市委的部署要求，坚持党要管党、从严治党，坚持稳中求进、改革创新，全面推进学习型、服务型、创新型党组织建设，不断提高机关党建科学化水平，为推动莆田海洋经济强市建设、实现“人兴业茂百姓富、清风明月生态美”有机统一提供坚强保证。

　　一、以学习党的十八届三中全会精神为重点，着力深化思想理论建设。

　　1、深化党的十八届三中全会和习近平总书记系列重要讲话精神学习贯彻。坚持用马克思主义中国化最新成果武装头脑、指导实践、推动工作。以深入学习贯彻十八届三中全会、省委九届十次全会和市委六届六次全会精神为重点，认真制定党组中心组《2014年学习计划》，推进领导干部学习常态化规范化，同时充分利用专题例会传达、局网专栏宣传、党员心得体会撰写、小组交流讨论等多种形式做好习近平总书记系列重要讲话精神的学习贯彻。

　　2、深化中国特色社会主义和中国梦宣传教育。持续深入开展中国特色社会主义宣传教育，认真贯彻落实中央《关于培育和践行社会主义核心价值观的意见》，做好《中国特色社会主义学习读本》等理论读本的学习宣传，深入开展“中国梦”主题教育活动，引导党员干部增强道路自信、理论自信、制度自信，争作践行价值观的模范，凝心聚力筑牢思想建设的根基。

　　二、以开展党的群众路线教育实践活动为契机，积极推进机关作风和效能建设。

　　3、开展群众路线教育实践活动。围绕保持和发展党的先进性纯洁性，扎实开展以“为民、务实、清廉”为主题的党的群众路线教育实践活动，结合海洋与渔业工作实际，以“四下基层”和“马上就办”为主要载体，以反对“四风”、服务群众为重点，以理论思想、党章党纪、民心民声、先辈先进为镜，坚持聚焦“四风”、解决问题，坚持敞开大门、群众参与，坚持建章立制、务求实效，着力解决用海单位、水产企业和渔民群众反映强烈的突出问题，提高新形式下做好群众工作的能力。

　　4、改进机关作风。围绕反对形式主义、官僚主义、享乐主义和奢靡之风，落实中央八项规定、《党政机关厉行节约反对浪费条例》和《关于市委常委会改进作风的意见》等精神，严格执行《党政机关国内公务接待管理规定》，进一步规范公务活动，切实转变文风会风。以开展“政风行风人民评”活动为契机，促进行风转变，提升群众满意度。

　　5、抓好效能建设。深化机关效能建设，认真贯彻《福建省机关效能建设工作条例》，认真开展“整治庸懒提效率、马上就办优服务”活动，扎实推进省级“马上就办”示范点创建工作，建立健全机关内部管理制度，加大对行政中梗阻、行政不作为乱作为以及“庸懒散”等突出问题的问责力度。

　　三、以干部管理和班子建设为基础，切实加强党组织和党员队伍建设。

　　7、加强领导班子建设。进一步提升领导班子和领导干部的整体素质，不断强化大局意识、责任意识、发展意识、创新意识；进一步加强民主集中制建设，强化民主意识，维护班子团结，充分发挥班子整体功能，促进科学决策，提高工作效率；进一步抓好作风建设，牢记“两个务必”，树立勤政廉政的良好形象。

　　8、加强机关支部建设。定期召开支部会，分析研究解决党建工作问题。不断健全完善先进性教育的长效机制，进一步增强党组织创新力、凝聚力和战斗力，发挥党支部在领导班子建设中的带头作用，通过完善制度、健全机制、创新管理，促进局机关党支部建设水平的提高。

　　9、加强党员干部管理。坚持党管干部原则，继续推行并完善竞争上岗、公开选拔、择优聘任的用人制度，进一步规范干部选拔任用工作。进一步加强、改进党员的教育管理工作，严格组织生活制度，不断提高党员整治素质，更好地发挥先锋模范作用。严格党员发展工作，按照“坚持标准、保证质量、改善结构、慎重发展”的原则，发展和吸收一批新党员。

　　四、以健全惩防制度为保障，持续推动反腐倡廉建设。

　　10、开展警示教育活动。把维护政治纪律放在首位，引导党员干部坚定政治立场，遵守政治纪律。把党章学习教育作为经常性工作，制定计划，创新形式，领导干部带头遵守，带头执行。组织党员干部到市反腐倡廉警示教育基地参观，坚持重点岗位干部廉政教育，加强廉政风险防控管理，发挥局机关廉政走廊文化和LED电子显示屏的作用，努力营造崇廉尚洁的良好氛围。

　　11、落实党风廉政建设责任制。巩固渔船管理廉政风险防控112做法成果，着重防范重点领域和关键环节的廉政风险。突出行政审批、行政执法、强农惠渔补助资金监管、渔业互助保险和事业单位公开招聘等重点，深入抓好专项治理工作，促进权力规范透明运行。扎实推进机关效能建设，抓好机关作风明察暗访，加强对群众反映突出问题的集中整顿、监督督查和责任追究。认真处理来信来访，配合查办违纪违法案件。

　　五、以文明单位创建为抓手，有效推进机关精神文明建设。

　　12、深化文明平安创建活动。以文明单位建设为抓手，不断完善精神文明建设和机关管理各项工作制度，积极开展创先争优，倡导微笑、文明服务，深化“创建四优文明科室、争做人民满意公务员”活动。深入开展海洋与渔业法制宣传教育，推进“六五”普法工作，持续平安单位创建活动。

　　13、丰富精神文化生活。结合道德讲堂活动，挖掘“身边好人”，宣扬道德模范，组织党员干部参与志愿服务活动，加大对局工、青、妇等群团组织工作的支持力度，不断丰富干部职工文化生活，增强机关活力。
