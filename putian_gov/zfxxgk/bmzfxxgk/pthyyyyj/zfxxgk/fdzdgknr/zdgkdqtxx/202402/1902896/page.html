莆田市海洋与渔业局关于2023年法治政府建设情况的报告

发布时间：2024-01-31 08:31
| | |
        2023年，在市委市政府的领导下，我局深入学习贯彻习近平新时代中国特色社会主义思想，全面认真贯彻落实《法治政府建设实施纲要（2021－2025年）》《<法治莆田建设规划（2021-2025年）>重要举措分工方案》等要求，认真履行职责，扎实开展工作，大力推进海洋与渔业依法行政工作，不断完善执法机制，规范执法行为，在推进海洋与渔业法治体系建设、深化行政审批制度改革、进一步加强海洋与渔业行政执法、强化法治教育等方面取得了较大成效，为全市海洋与渔业发展提供了有力的法治保障。现将今年法治建设工作主要情况汇报如下：

　　一、健全制度机制，推进法治体系建设 

　   （一）落实法治建设第一责任人责任。局主要领导高度重视法治政府建设，认真贯彻落实《党政主要负责人履行推进法治建设第一责任人职责规定》，将法治政府建设工作作为海洋渔业工作的重要内容，重点部署落实履行法治建设重要职责，严格落实重大行政决策制度，规范决策程序，明确决策主体、事项范围、法律责任等，海洋经济与渔业行政管理中的重大事项均经集体讨论决定。注重增强公众参与实效，制定事关发展全局和涉及群众切身利益的重大行政决策事项时，均广泛征求公众意见并予以充分考虑，全力推进行政决策科学化、民主化、法治化。 

　   （二）加强规范性文件全过程管理。严格落实行政规范性文件管理有关规定要求，认真执行事前合法性审查、事后备案审查等制度，全面对重大行政决定、规范性文件出台和涉及公平竞争等事项开展合法性审查，提高规范性文件质量。根据有关要求，结合对不符合营商环境、民营经济、行政复议等相关规定的规范性文件专项清理工作，我局全面开展现存有效的规范性文件梳理工作，新制定了3件行政规范性文件，保留7件行政规范性文件。            

　   （三） 健全矛盾纠纷调处化解机制。制定《莆田市海洋与渔业局应对突发事件敏感舆情舆论引导和舆情处置工作预案》《中共莆田市海洋与渔业局党组网络安全责任制实施细则》等制度，全面加强舆情跟踪调处工作。指定专人负责及时接收、转理信访件，严格按照信访事项“路线图”依法处理，引导当事人通过诉讼、仲裁、行政复议等途径解决涉法涉诉信访问题，并将所有信访件的办理情况录入福建省信访信息系统。全年共受理办结信访件1件，环保督查22件，12345平台诉求件21件、群众来电反映问题4件，舆情监测1件，均得到有效处理按时办结答复，未发生服务对象越级上访、集体上访或群体性事件，无行政复议事项。 

　   （四）加强专业法律顾问制度建设。根据单位实际情况，聘用福建律海律师事务所陈志强等律师为局法律顾问，建立健全单位内部法律顾问队伍，对局机关重大行政决策、规范性文件、重要事项及合同等进行全面审核，有效防范了法律风险，切实提高政府依法决策、依法行政水平，维护公民合法权益，优化营商环境。 

　　二、严格行政执法，全面推进依法行政 

　   （一）全面规范行政执法行为。认真贯彻落实《福建省行政执法条例》《福建省重大行政执法决定法制审核办法》《渔政执法工作规范（暂行）》，全面制定完善海洋与渔业行政执法三项制度，推进“三项制度”相关清单、指南、流程图和证明事项告知承诺制工作落实，切实加强行政执法主体资格和执法人员的管理，严格落实执法人员持证上岗制度，未通过执法资格考试的，不得从事海洋渔业行政执法活动，对持证执法人员实行网上信息公示，接受社会监督，目前我局共有60人持有福建省行政执法证。同时，按照省一体化大融合行政执法平台建设和应用工作部署要求，率先完成海洋渔业执法平台接入和规范使用工作。截止12月底，通过省一体大融合行政执法平台执法办案模块开展行政检查82次，办理行政处罚案件40起。 

　  （二）加大渔业资源保护力度。认真组织市县两级打击违规张网作业、电鱼行动及清理整治违规渔具行动，集中查处使用禁用渔具和小于最小网目尺寸网具的行为，严厉打击非法捕捞作业，共出动执法人员5282人次，船艇359艘次，开展岸线巡查12731公里，海上巡查9308.6海里，检查渔港码头1539个次、渔船2429艘次，2023年全市共查处渔业案件156起，罚款260.26万元，移交追究刑事责任9起。认真做好伏休执法监管工作，查处违反伏休规定渔业船舶 26艘，行政处罚22艘，罚款24.31万元，没收渔获物1797.35公斤，移送追究刑事责任4艘，营造了良好的休渔氛围，确保渔区社会安定稳定。积极开展水生野生动物保护执法行动，检查水生野生动物繁育展演经营利用场所10家，救护水生野生动物4只；重点加强木兰流域渔业执法，开展水产养殖业执法巡查71次，河道水域巡查执法76次，检查水产养殖单位117家次，发放责令整改通知书2份，查处内陆水域非法电鱼案件2起，罚款1万元，收缴电鱼设备2套。 

　　 (三)强化渔业安全执法监管。以“蓝剑2023”、“亮剑”行动为抓手，结合“商渔共治”，深入开展渔船渔港安全和水产品质量安全执法专项行动。2023年共劝离进入相关海域渔船76艘次；出动执法船9艘次、渔船47艘次开展海上救援工作，海上救助8起，救助船舶7艘，人员7人。查处渔船擅自拆卸北斗系统的渔业行政处罚案件12起，收缴罚没款36万元，排查渔业安全一般隐患 548项，重大隐患8项，全部整改到位，整改率100%，海上安全生产隐患得到有效消除。加大水产品质量安全执法监管，检查水产市场55个次，水产养场116家，有效保障渔业安全生产，提升水产品质量安全水平。 

　  （四）深入推进扫黑除恶斗争。认真学习贯彻党中央关于常态化开展扫黑除恶斗争的决策部署和省委、市委工作要求，紧盯行业重点整治任务和难点突出问题，坚持标本兼治，持续深入推动行业常态化扫黑除恶斗争走深走实。落实行刑衔接有关工作规定，开展“中国渔政亮剑2023”和“蓝剑2023”系列专项执法行动，对9起涉刑案件及时移送司法机关追究刑事责任，形成有力震慑。 

　　三、深化“放管服”改革，着力践行惠企便民 

　  （一）实行窗口前移“就近办”。针对南日岛、湄洲岛渔企渔民办事出岛奔波、缺项补齐难度大、时间成本高等问题，持续深化“放管服”改革，在全省率先开展市级行政审批和公共服务事项受理权限下放海岛实行“就近办”，27项市级审批受理事项在两个海岛乡镇行政服务中心就可以实现现场受理、远程审批的服务，真正实现“渔民办证不出岛”，该做法被列为福建省推进政府职能转变和“放管服”改革16个工作典型经验典型经验做法之一，也是全省海洋与渔业系统唯一入选事例。

　  （二）进一步优化办事流程。全面精简优化办事流程，推进减环节、减材料、减时限、减费用改革，有效提升营商环境，目前27项市级审批与服务事项中全部为五星级“一趟不用跑”事项，占比达 100%；即办事项 22项，占比81.5%；办事时限全部已压缩至原法定时限的 93%，所有办事时限均位居全省各地市前三。进一步深化“我为群众办实事”活动，开展渔船检验业务上门服务，组织船检人员进村入港，逐船现场受理、检验，让渔民群众足不出村、一趟不用跑办理渔船检验及证书年检业务。 

　  （三）完善事中事后监管。进一步强化“双随机一公开”监管机制，健全完善《莆田市海洋与渔业局随机抽查事项清单》和市场主体名录及执法人员数据库，按照业务科室职责分工，落实监管责任，确保行政许可、行政检查事项监管依法有序，不断规范化和制度化。2023年分别在5月份和10月份开展两次抽查工作，通过监管系统平台对8个事项按5%比例随机抽取市场主体46个，随机选派执法人员38人次（渔船每2人检查4艘），随机抽查结果在政府门户网站和局政务公开栏进行公示，并及时录入互联网+监管系统和国家企业信用信息系统；同时对行政许可和行政处罚事项均在7个工作日内上报莆田市信用信息系统公示，“双公示”上报数据合格率达100%。 

　  （四）全面推进政务公开。认真贯彻落实政府信息公开相关规定，全面推进政务公开，坚持“以公开为常态、不公开为例外”的原则，对单位相关决策、执行、管理、服务和结果进行全面公开公示。2023年公开各类信息34条，包括发展规划4条、组织机构设置12条、公共事件应急管理2条、监督检查情况3条、主动公开其他信息10条、规范性文件3条等，截止2023年底，累计主动公开政府信息960条，全文电子化率100%。 

　  （五）自觉接受多方监督。自觉接受人大及其常委会的法律监督、政协的民主监督等，及时研究办理人大代表和政协委员提出的意见和建议，切实改进工作。2023年以来，共收到人大建议2件，共收到委员提案6件，其中独办1件、分办3件、会办1件，均在规定的期限内解决办理，并主动征求相关人员的意见，普遍得到了各位代表、委员的理解、支持和称赞。 

　　四、强化法治宣传，落实普法责任制 

　  （一）落实领导干部带头学法制度。把习近平总书记全面依法治国新理念新思想新战略作为局党组理论学习中心组学习内容，组织开展专题学习8次，专题研讨3次。认真落实“三会一课”制度，把法律法规列入重点学习内容，开展法律法规专题讲座3次。同时，通过举办3次为期7天的读书班、聆听专家讲座6次，开展机关内部学法用法活动，让法治成为领导干部“必修课”，努力提升领导干部运用法治思维和法治方式处理问题的能力。   

　  （二）扎实推进“八五”普法规划。细化落实《全市海洋与渔业系统法治宣传教育第八个五年规划（2021-2025年）》，制定《莆田市海洋与渔业局关于做好2023年海洋与渔业系统法治宣传教育工作的通知》（莆海渔〔2023〕31号）和年度海洋与渔业重点普法清单，明确了各阶段重点宣传普及法律法规、机关内部学法活动、面向执法（服务）对象及社会公众开展的普法活动等工作内容。 

　  （三）落实“谁执法谁普法”责任制。按照“谁执法谁普法”原则，利用特殊时节开展相关法律法规的普法工作。一是在“安全生产月”活动期间，充分利用网站、LED屏、宣传栏、举办安全知识讲座、开展应急演练等手段开展宣传活动，举办了9场专题培训会，举办渔业船员培训班7期，培训船员342人次，由组织宣讲团深入渔区、渔村进行开展安全隐患排查宣贯活动。二是在伏季休渔期间，在渔港码头、重点渔村等场所，通过现场咨询、图谱展示、执法检查等形式开展宣传活动，电视电台报道21次，登报宣传1次，新媒体平台宣传17次、悬挂横幅28张，发放宣传材料7404多份、宣传渔民2300人次，营造了良好的休渔氛围。三是在保护野生动物宣传月期间，以“宣传贯彻‘一法一办法’ 保护水生野生动物 ”为主题开展宣传活动，发放宣传材料930多份，张贴、悬挂宣传标语和横幅32条幅，受教育人数多860人次。四是在“宪法宣传周”活动期间，联合秀屿区海洋与渔业局在平海上林渔港开展宪法宣传活动，邀请平海镇司法所干部开展现场宣讲，发放宣传单100份，悬挂宣传横幅5条。 

　　五、存在的问题 

        一是普法宣传形式较为单一。利用新媒体创新开展法治宣传的手段还不够多样，普法内容干货少，主要依赖传统线下普法载体，导致普法受众有限。 

        二是执法工作研究不够深入。各项法律法规学习仍缺乏系统性，碎片化学习比较多，精研深思少，部门法律工作人才储备不足和基层执法力量薄弱，影响法治工作的深入开展。 

六、2024年工作计划 

　  （一）进一步开展普法工作。按照“谁主管谁负责”“谁执法谁普法”“执什么法普什么法”的原则，有针对性地开展法治宣传教育活动，落实普法责任制。进一步梳理单位权责清单，制定对应普法责任清单，将普法任务进一步分解细化，明确责任科室和年度安排。 

　  （二）进一步规范行政执法行为。严格落实规范性文件合法性审核要求，认真执行事前合法性审查、事后备案审查等制度，正确行使法律职权把好法制审核关，认真开展专项清理和执法安全评查工作，强化行政执法监督，规范行政执法行为，促进依法行政。 

　  （三）进一步完善行政审批服务。认真落实省“五级十五同”审批改革统一部署，优化内部审批流程，从减时间、减跑动、提升即办程度和网办深度等方面进行优化调整，推进减环节、减材料、减时限、减费用，进一步提高审批效率，有效提升营商环境。 

　  （四）进一步加强市场监管工作。加大双随机工作实施力度，通过事项整合、部门联合、信用融合，坚持监管和服务并举，科学计划有序推进“双随机、一公开”对海洋渔业工作情况进行监督检查任务，全面落实“双公示”，进一步强化市场主体自律和社会监督，提升海洋渔业监管能力。 

　　2024年，我局将以习近平新时代中国特色社会主义思想为指导，继续深入贯彻党的二十大精神，紧紧围绕市委、市政府中心工作，统筹推进海洋与渔业领域法治建设工作，创新普法宣传形式，进一步强化海洋综合管理和服务，为将我市建设成为高质量发展的先行市提供有力法治保障。
