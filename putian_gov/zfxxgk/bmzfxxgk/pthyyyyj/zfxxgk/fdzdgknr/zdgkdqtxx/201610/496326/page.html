关于莆田湄洲湾石门澳污水处理厂一期工程用海的预审意见

发布时间：2016-10-10 11:56
| | |

莆田市水务集团港城水务科技有限责任公司：

你公司报送的《莆田湄洲湾石门澳污水处理厂一期工程项目海籍调查报告》（报批稿）（以下简称《报告》）收悉。经审查，提出预审意见如下：

一、你公司拟建的莆田湄洲湾石门澳污水处理厂一期工程用海域位于湄洲湾北岸秀屿区东庄镇石门澳海域，用海面积为5.3925公顷，均为填海。用海方式建设填海造地。海域使用类型一级类为造地工程用海，二级类为城镇建设填海造地用海，海域等别为五等；拟申请用海期限50年。

二、项目用海在《福建省海洋功能区划》（2011—2020）中，位于“石门澳工业与城镇用海区”，项目建设符合省级海洋功能区划的功能定位，且不影响国防安全。

    三、项目拟申请海域目前尚未设置海域使用权，亦无计划设置更重要的开发利用方式。工程设计及施工应严格按照国家有关技术规范执行，加强施工管理，避免雨季、台风及天文大潮的不利气象条件下施工，减少施工期对海水水质的影响。你公司应继续妥善处理好利益相关者的关系。

四、你公司应认真落实海域使用论证报告书和专家评审意见的各项内容。《报告》报批稿可作为上报省海洋与渔业厅审核项目用海和呈报省政府审批用海的依据。

五、项目批准后应严格按照批准的范围用海，若因不可抗力等客观原因造成超面积的，应在发生超面积事实之日起十日内将有关情况上报省海洋与渔业厅核查。

本预审意见有效期为两年，自2016年10月8日至2018年10月7日止。有效期内，如项目拟用海域位置、用海方式和面积发生改变的，应当重新提出海域使用申请。

 

 

                           莆田市海洋与渔业局

                            2016年10月8日

 

（此件主动公开）

 

 

抄送：福建省海洋与渔业厅，秀屿区海洋与渔业局、发展和改革委员会。
