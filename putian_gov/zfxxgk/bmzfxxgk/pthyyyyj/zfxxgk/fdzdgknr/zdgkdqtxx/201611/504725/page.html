莆田市海洋与渔业局关于核准莆田市石门澳区域建设用海规划化工新材料3号填海工程海洋环境影响报告表的函

发布时间：2016-11-21 17:11
| | |

莆田市海域海岛储备中心:

    你中心报送的《莆田市石门澳区域建设用海规划化工新材料3号填海工程海洋环境影响报告表》（以下称<报告表>）收悉，经综合专家、部门及听证意见，现就《报告表》提出如下核准意见：

    一、该项目属填海工程，位于秀屿区东庄镇石门澳湾海域及国家海洋局批准的《莆田市石门澳区域用海建设规划》范围内。项目申请用海面积为31.3045hm2，选址符合《福建省海洋功能区划（2011-2020）》、《石门澳区域发展建设规划（2010-2030）》和《石门澳区域建设用海规划》。

    二、《报告表》的编写基本符合《海洋工程环境影响评价技术导则》，评价目的明确，评价内容较全面，工程概况和工程分析基本清楚，海洋环境现状调查与评价基本满足要求，环境影响预测结果基本可信，海洋环境保护对策和措施可行，评价结论总体可信。

    三、按照省海洋与渔业厅《关于印发全面推进海域资源市场化配置的实施意见及其配套制度的通知》（闽海渔〔2015〕191号）的要求，本项目由莆田市海域海岛储备中心收储，实施海域招标拍卖挂牌，目前尚无确定的建设内容。《报告表》的海洋环境影响评价内容仅涉及填海工程，因此只对填海工程海洋环境评价进行核准，具体项目的建设内容对海洋环境影响应另行评价和审批。在建设单位严格落实《报告表》所提出的各项海洋环保措施的条件下，从海洋环境保护角度出发，本项目的建设可行。

四、本项目涉及的主要环境影响问题是：施工期悬浮泥沙、含油废水、生活污水、生产和生活垃圾入海以及填海造成部分浅海滩涂湿地丧失等问题。你中心应从管理方面着手，制定事故应急预案，采取相应的防范措施，避免污染事故的发生。

五、严格按照规定的工艺方法和设备进行施工，并加强施工过程的管理、监督。制定施工计划，合理安排施工期，避免在台风或风暴潮等恶劣天气施工，保证作业安全。切实落实生态保护措施。对项目施工造成的海洋生物资源损失，建设单位应按《报告表》要求制定生态补偿方案，落实相应的补偿措施。

六、严格落实跟踪监测计划。建设单位必须委托有资质的监测单位编制海洋环境跟踪监测方案，经我局审定后实施，并送省海洋与渔业厅备案，监测结果定期报送市海洋与渔业局。秀屿区海洋与渔业行政主管部门在该项目施工期和营运期应加强各项环保措施的监管落实；市、县（区）海监执法机构要加强对该项目及周边海域海洋环境的执法检查。

 

 

                         莆田市海洋与渔业局    

                          2016年11月18日
