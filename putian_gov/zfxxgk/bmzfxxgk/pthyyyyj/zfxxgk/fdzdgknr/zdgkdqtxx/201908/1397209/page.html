关于市政协七届三次会议第2019211号提案办理情况的答复

发布时间：2019-08-20 15:44
| | |

陈旅棱委员：

首先，衷心感谢您对海洋渔业生态环境保护的关心和支持！您提出的《保护好我市海洋生态环境 推进海洋经济可持续发展》（第2019211号）收悉，因政府机构改革，海洋生态环保职能已划转至生态环境局，海洋渔业部门主要负责渔业养殖区和渔船、渔港油污染防治，提案建议中涉及海洋渔业部门职能的主要是第（六）点“加强养殖户、沿海居民的海漂垃圾监管处理”和第（七）点“发展生态循环养殖，促进海洋渔业转型升级”，现将办理情况函复如下：

一、关于“加强养殖户、沿海居民的海漂垃圾监管处理”的建议

莆田市海洋与渔业局与莆田市生态环境环境局等十部门联合印发《莆田市近岸海域海漂垃圾综合治理工作方案》（〔2019〕105号），并进一步制定《莆田市渔业水域生态治理暨污染防治实施方案》（莆海渔〔2019〕109号），着力推进渔业养殖垃圾入海防控工作。一是推进渔业养殖设施升级改造。计划到2022年底前基本完成渔排升级改造，淘汰“木质+泡沫浮球”等老旧渔排，推广应用新型环保型抗风浪塑胶渔排养殖。目前，由南日集团在南日岛东岱湾海域实施总面积约为32320平方米的塑胶渔排2020口（单口面积为4*4）的采购与安装。其中1500口为养鲍塑胶渔排，520口为养鱼塑胶渔排。第一批1127口塑胶渔排已全部完成下水安装和固锚投放，并完成竣工验收和渔排招租工作；福建省兴海渔业有限公司抗风浪深水风箱建设，已完成周长为40米的抗风浪深水网箱4口，配套网衣4套。二是加大整治资金扶持力度。我局每年下达县区海洋环境整治资金100万元左右，主要用于近岸海域海漂垃圾治理，2019年已下达省级海洋环境整治资金70万元，主要用于渔业养殖垃圾入海和渔港港区内垃圾入海治理，各县区成立保洁队伍，设置养殖垃圾和渔港港区内垃圾固定回收点。三是加强渔业执法监督检查。市海洋与渔业执法支队组织市县两级渔业执法机构开展渔港水产养殖区执法和巡查，加大对渔港渔业养殖垃圾非法倾倒入海的执法监管。2019年上半年，全市渔业执法机构开展港口执法检查222次，检查渔业港口513个次

二、关于“发展生态循环养殖，促进海洋渔业转型升级”的建议

一是探索发展深远海养殖。与上海振华重工集团合作，引进深远海鲍鱼养殖装备“振鲍2号”。2019年2月15日在南日小麦屿海域下水进行安装调试，计划今年开展鲍鱼试养殖，将带动我市鲍鱼养殖向机械化、智能化模式转变，有效拓展鲍鱼养殖发展空间，促进渔业产业转型升级、提质增效。二是大力推进海洋牧场建设。投资900万元，建立南日岛人工鱼礁工程（五、六期），2018年5月底通过完工验收，工程质量合格。投资2000万元在南日岛附近海域建立第七期人工鱼礁，2018年7月进场施工，至2018年12月已完成礁体制作700个，投放269个，占总工程量约70%，2019年已开展560块28.1立方米框架型钢筋混凝土礁投放工作，预计年内完工验收，南日岛邻近海域海洋牧场示范区生物资源得到明显恢复。三是持续开展增殖放流活动。通过中央、省财政渔业资源保护专项资金、生态补偿金等多种资金渠道，依法开展渔业资源增殖放流活动，连续多年向兴化湾、平海湾等投放各类鱼苗、虾苗、贝苗。2018年，结合“百姓富、生态美”福建海洋生态·渔业资源保护十大行动，我市共争取中央财政渔业资源保护资金130万元，完成长毛对虾、双线紫蛤、泥东风螺、黑鲷、鲢鱼、鳙鱼等苗种增殖放流，有效修复了渔业生态资源。2019年，已完成省级渔业资源保护补助资金190万元的招投标采购。其中，已使用80万元省级补助资金开展“6.6放鱼日”活动，投放对虾苗种1.3亿尾，其余110万元省级补助资金的增殖放流按合同在年底前完成苗种投放工作。

衷心感谢您对海洋渔业事业的关心和支持，我们将倍加努力，深入贯彻习近平总书记生态发展理念，加快推动我市渔业生态绿色健康发展，努力实现海洋经济的高质量发展。
