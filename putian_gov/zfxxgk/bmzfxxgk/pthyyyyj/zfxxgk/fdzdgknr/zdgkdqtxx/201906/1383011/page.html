莆田市海洋与渔业局关于市政协七届三次会议第2019076号提案办理情况的答复

发布时间：2019-06-28 09:02
| | |

詹永东等三位委员：

你们提出的《构筑较为完善的海洋环境应急能力体系建设的几点建议》（2019076号，以下简称《建议》）提案收悉，现就《建议》涉及海洋与渔业部门管理有关事项的办理情况答复如下：

    一、关于加大宣传保护海洋环境力度，增强海洋环境保护意识的建议

近年来，我局注重从提高全民特别是用海企业、业主的海洋环保意识入手，以法律宣传提升环保意识，通过每年开展“海洋宣传日”、5.12海洋防灾减灾宣传周、海洋伏季休渔宣传等活动，以及办理用海审批手续时，深入宣传贯彻《海洋环境保护法》《防治海洋工程建设项目污染损害海洋环境管理条例》《自然保护区条例》《海洋自然保护区管理办法》和《海洋倾废管理条例》等海洋环境保护法律法规，大力宣传保护海洋环境、科学开发利用海洋资源的重要意义，广造依法用海、依法管海、依法兴海的社会氛围。同时为及时反映我市海洋环境质量状况和海洋环保工作情况，每年编制《莆田市海洋环境状况公报》发放各级政府、相关部门和相关社会大众，并在莆田电视台一套每晚黄金时段开设《海洋环境预报》专栏，让社会各界和广大公众认识和了解保护海洋环境的重要性，形成人人关心海洋和爱护海洋的良好氛围。下一步，我局将继续加强海洋环境宣传工作，拓宽基层宣传渠道，积极利用港区LED、渔民手持应急终端短信群、微信群等新媒介平台，进一步加大渔业水域污染防治、渔船和水产养殖污染海域的宣传教育，增强渔区渔民海洋环保意识。

二、关于强化海洋区域管理意识，进一步整合涉海监管执法力量，提高依法治海水平的建议

为有效保护我市近岸海域环境，近年来，我局不断加强海洋环境执法力度，组织海洋与渔业执法机构深入开展“蓝剑”“净海”“平安海域”“碧海”“银滩”等专项行动，仅2017年来，办结海洋行政处罚案件40起、收缴罚款2774.58万元，办结渔业违法案件18起、罚款4.78万元，移送涉嫌犯罪案件线索1起。进一步强化跨县区、跨部门联合执法机制，市、县海洋与渔业执法机构上下联动开展联合执法，与边防、海事、海警等部门常年开展海上综合联合执法行动，成立工作专班，推动海上一体管理格局，有力地打击了海上违法违规行为。

下阶段，我局将根据海洋环保和海域管理职能的划转，积极配合生态环境和自然资源部门加强海洋生态保护工作，深化渔业水域环保的监管执法工作；海洋与渔业执法机构将根据生态环境执法的委托进一步加强与公安、海事、海警部门在打击非法采砂、海洋污染防控和应急处置以及严防海上交通安全事故等执法监管方面建立常态化协作机制，形成执法合力，强化信息联通和执法联合，深化案件联处工作机制，切实保护海洋生态环境，维护沿海社会安定稳定。

三、关于进一步优化全市的海洋环境监测结构，建设海上自动监测系统的建议

为加强海洋环境监测，提升我市海洋防灾减灾服务保障能力，我局积极争取资金建设海洋监测系统建设，几年来，共建设湄洲、石城、东吴3座海洋验潮站和南日岛东岱、坑口、港南、筶杯、湄洲5套浮标系统，2016年启动海洋灾害及自动在线监测系统建设，通过布设自动在线监测浮标，可实现对赤潮灾害实时在线自动监测和预警，配置检测石油烃所用的荧光分光光度计，用于生物体内石油烃的快速检测，为我市应对赤潮灾害和溢油事故的应急响应能力打下坚实基础。在2018年的江阴港货轮漏油监测获取第一手数据提供了有力数据支撑。下一步，我局将根据职能划转后的渔业生产检测业务，进一步加强渔业灾害精细化监（检）测，提升业务技术水平，更好地服务渔业生产、水产品产地质量检测和渔业应急处置工作需要。

四、关于推进海洋生产环境应急体系建设的建议

近年来我局协同沿海各有关县区海洋行政主管部门不断加强近岸海域环境趋势监测预警和应急处置工作。每年组织开展了海洋环境质量趋势性监测、主要海湾环境监测、陆源入海排污口等多项海洋环境调查、监视、监测工作，共布设监测站位50多个，每年获取监测数据近万个，为开展海洋环境应急处置工作提供有力保障。同时不断完善海洋环境保护应急工作预案，制定了赤潮灾害、渔船溢油等突发性污染事故应急工作预案，建立了海洋与渔业执法队伍为主，群众性渔船志愿者为辅的海上应急救援队伍，积极推行海水生态养殖模式，推广实施渔船配置油污和垃圾回收“两桶”，加强对海上养殖生产生活垃圾打捞、收集、处理的监督，对非法开采海砂、违规倾废等破坏污染海洋环境的违法行为依法坚决予以查处。海洋环境污染防范能力逐步提升，针对海洋赤潮、溢油污染等事件，能及时启动应急响应，切实做好事故灾害防御和应急处置等工作，形成工作合力，减少损失。

下一步我局将根据调整后海洋生态环境保护工作职能分工，进一步修订完善赤潮及突发性渔业污染事故等灾害的应急处置预案，提高应急工作的针对性和高效性；健全应急监测预警网络建设，根据近岸海域养殖布局，增加养殖水域监测点布设，提升在线监测和预警能力；加强应急救援队伍建设，加大执法船应急检测设备和救援装备，开展相关应急救援演练，编制《莆田市海洋与渔业执法支队海上环境资源和渔业突发事件应急处置预案》，提升海上整体应急救援处置能力。

五、关于加大政府投入，完善海洋生态保护保障机制的建议

    近年来我市不断加大投入，开展海洋环境整治和海洋生态修复工作。一是开展海漂垃圾专项治理。我局把海漂垃圾治理作为最具体的民生工作和最基础的生态工程加以推进。市级财政每年预算安排专项资金100多万元，用于沿海各县区岸线海漂垃圾整治，保障基层海漂垃圾日常清理、转运需要。通过开展治理专项行动，彻底清理了长年堆积在海岸带的垃圾，建立了海岸带环境卫生日常保洁机制，海岸带环境卫生保持良好状态。二是开展渔业增殖放流活动。为保护海洋生态系统的可持续健康发展，我局每年根据各海区的渔业资源的特性，开展有针对性的鱼虾苗增殖放流活动，2017年以来争取农业部增殖放流资金450万元，在木兰溪、兴化湾、平海湾等海区投放鱼类、虾类、贝类等苗种共有11.6亿尾（粒）。三是实施一批海洋生态修复工程。争取中央财政投入3400万元，开展了湄洲岛生态修复示范工程项目，实施对海岛生态岸线、黄金沙滩、红树林种植等11个项目进行整治修复；投入中央财政资金2900万元，建设7期南日海域人工鱼礁项目，有效提升海岛海域生态环境保护效果。下一步我局将根据调整后海洋生态环境保护工作职能，继续加大投入，开展渔港内水域和水产养殖区的海漂垃圾整治，推进水产养殖污染防治的研究，加大海区渔业资源的养护，重点推进南日岛海洋牧场建设，切实保护海洋生态环境。

最后，衷心感谢你们长期以来对我市海洋与渔业工作的关心支持，望今后对我们的工作提出更多更好的意见和建议。
