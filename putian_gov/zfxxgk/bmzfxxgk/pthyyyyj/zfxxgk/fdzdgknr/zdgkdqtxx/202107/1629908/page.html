莆田市海洋与渔业局关于印发《莆田市海洋与渔业局2021年普法责任清单》的通知

发布时间：2021-07-20 15:02
| | |

 各县（区、管委会）海洋与渔业行政主管部门，局机关各科室、局属各事业单位:

 根据《2021年莆田市重点市直机关普法责任清单》《莆田市海洋与渔业局2021年法治工作方案》文件要求，为全面贯彻落实“谁执法谁普法”普法责任制，现制定2021年普法责任清单。

 

附件：莆田市海洋与渔业局2021年度普法责任清单

                                                        2021年7月16日
