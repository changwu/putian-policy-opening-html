莆田市海洋与渔业局关于抓紧做好第十五届6·18对接项目和技术需求征集工作的通知

发布时间：2017-04-25 11:51
| | |

各县区（管委会)海洋与渔业行政主管部门，后海围垦管理局，局属有关单位，南日集团：

第十五届中国·海峡项目成果交易会（简称6·18）将于2017年6月在福州海峡国际会展中心举行，根据6·18组委会的统一部署，省厅将于6·18期间搭建“海洋馆”并举办系列配套活动，为海洋渔业领域涌现出的项目成果提供展示与对接交易的平台。为共同做好各项筹备工作，现就对接项目和技术需求征集工作的有关事项通知如下：

一、 成立工作领导小组

    为强化对第十五届6·18工作的组织领导，市局成立了工作领导小组，由分管局领导任组长，领导小组办公室挂靠局渔业管理科。请各单位指定1位分管领导担任领导小组成员，并指定1位经办同志为联络员，于4月26前将第十五届6·18工作领导小组成员及联络员名单回执（详见附件1）报市局渔业管理科。

    二、 做好对接项目和技术需求的征集工作

 ㈠加强对接项目和技术需求的征集工作

    对接项目和技术需求的征集工作已列入年度绩效考评内容，各单位务必高度重视。各单位要紧密围绕建设21世纪海上丝绸之路核心区和海峡蓝色经济试验区的发展战略，结合我市海洋与渔业工作重点，充分发挥行业协会、学会、产业组织等科技中介服务机构作用，依托各级各类工程研究中心、重点实验室等产、学、研平台，组织有关人员深入基层，进一步加强对接项目和技术需求的征集工作。要根据企业的需求，有针对性地组织开展专业化、个性化对接，不断提高对接活动的成效，花大力气加强海洋渔业对接项目和技术需求的征集工作。请各单位于5月17日前将所征集的对接项目和技术需求报送市局渔业管理科，以便汇总上报省厅。（具体要求详见附件2、3、4）

㈡筛选典型对接项目

为突出重点，加大跟踪推进工作力度，请各单位从第十五届6·18对接项目中筛选选出1个典型项目（简介提纲详见附件5），于5月17日前报送市局渔业管理科，以便汇总上报省厅。

10、合作方式：指购买专利技术转让、技术入股、合作开发；

11、签约方式：指合同、协议、初步接洽等；

12、成果简介：指应用的科技成果及效果等（限60字以内）；
