关于市政协八届一次会议第2022007号提案办理情况的答复

发布时间：2022-08-01 17:16
| | |

林淑云委员：

你提出的《关于做大做强海洋产业 推动海洋经济高质量发展的建议》（第2022007号）已收悉，现将办理意见答复如下：

一、关于统筹全市海洋产业资源，优化布局，促进传统海洋产业转型升级

根据《莆田市海洋渔业发展中长期规划（2018-2030年）》，我市以南日岛现代海洋渔业产业发展示范区为一、三产产业发展重心，提出了“一心引领、二带协同、三区并进”的总体产业发展布局规划。“一心”指南日岛现代海洋渔业产业发展示范区，为莆田市海洋渔业一产产业发展重心，围绕南日岛海洋牧场建设，打造以海洋渔业为特色的集海水立体生态养殖、海上风电、滨海度假旅游于一体的海洋产业集群。“二带”指湄洲湾北岸滨海现代渔业产业带和平海湾生态渔业产业带，湄洲湾北岸滨海现代渔业产业带定位为陆基现代渔业功能区，主要是以湄洲湾北岸的东海镇——灵川镇一带花蛤池塘生态养殖区为平台，贯彻落实绿色发展理念，建立陆基工厂化花蛤繁育示范基地，发展海洋水产品精深加工业和休闲渔业，促进一二三产有机融合；平海湾生态渔业产业带定位为生态渔业功能区，依据生物多样性和生态平衡原则，研发推广先进适用的、生态习性互补的海洋水产生物优质新品种。“三区”指平海石城渔港经济区、湄洲文甲休闲渔业园区和后海渔业产业园，重点发展生态养殖、生态休闲、滨海旅游、水产品加工、水产品集散等产业。通过明晰产业功能区规划、优化产业空间布局，有效加速渔业结构调整，促使传统海洋渔业产业转型升级。

二、关于打好种业翻身仗，培育壮大水产种业

我市围绕“四大贝苗”（鲍鱼、花蛤、牡蛎、双线紫蛤）以及对虾、海带、紫菜、龙须菜等本地优质种源保护和利用，加大三倍体牡蛎（生蚝）、真蛸等水产新品种繁育技术研发和产业化养殖技术攻关，推进水产苗种繁育与种业创新工程。组织开展第一次全国水产养殖种质资源普查工作，全市入库主体305个，普查完成率100%。建设秀屿区平海湾全国双壳贝类育苗基地，新增贝类育苗场3家，基地育苗总面积达4万多平方米，年产蛤蛏、贻贝等苗种9000多亿粒，年产值1亿多元，是全国最大的厚壳贻贝苗生产基地（占全国80%）和重要的菲律宾蛤仔室内育苗基地（占全国10%）。新建省级原良种场规模水产种业基地建设4个（秀屿耀辉、荔城华源、荔城亿星、城厢中灵）、市级特种水产苗种繁育基地1个（仙游腾龙）。2022年，市海洋与渔业部门与中国海洋大学达成初步意向，合作建设东南水产种质种源研究院，由市海发水产养殖开发公司承接的三倍体牡蛎试验基地已改扩建完成，中国海洋大学水产学院已派驻专家技术人员入场指导；同时，市海洋与渔业局已组织市级水产原良种场评定工作，4家企业（良种场3家、原种场1家）均通过专家评审并公示，下一步拟推荐该4家企业申报评定省级原良种场。

三、关于常态化抓好三湾、两岛的生态环境建设，实施海陆湾联防治机制

一是开展入海排污口排查整治。在2017年入海排污口普查基础上，我市于2019年12月重新印发实施了《莆田市入海排污口排查整治工作方案》（莆环保委〔2019〕12号），按照“全口径、全覆盖”原则组织各县区对海岸带及向内延伸2公里区域内排污口进行全面排查。至2020年底，我市共排查出各类入海排水口2241个，其中国家海洋督察335个，新增排口1906个。2021年海洋渔业部门对渔业养殖入海排口进行了整合，入海排水口总数降至1767个（其中国家海洋督察335个、新增排口1432个），2022-2023年重点整治我市51个列入国家海洋督察的养殖入海排放口。二是夯实海漂垃圾综合治理基础。我市以7个县（区、管委会）为主体组建第三方“海漂环卫队伍”，其中仙游、城厢、北岸、湄洲岛4个县（区、管委会）委托市环境集团，荔城、涵江、秀屿3个区分别委托莆田龙马环卫、福建东飞环境、中鑫航（深圳）实业等3家企业，全市目前共配备海漂垃圾打捞船舶23艘、保洁人员215人。2022年，全市海岸线共打捞清理海漂垃圾约2330吨。三是探索推进常态长效治理。市生态环境部门正会同有关单位正在制定海漂垃圾综合治理考评方案，量化海漂垃圾治理成效，拟通过差异化奖补激励属地县区落实落细海漂垃圾保洁制度，确保海漂垃圾治理“长治长效”。

四、深化产学研合作，打造海洋科技创新体系

一是科技创新助力海洋经济发展。为推进海洋经济高质量发展，市科技局制定了《关于贯彻落实加快建设海上莆田推进海洋经济高质量发展三年（2021-2023年）行动方案的实施意见》，围绕我市海水养殖、良种育苗、海洋食品精深加工等产业需求，在加强自主研发、产业协同创新、创新创业支撑、技术交流合作等方面提出了具体的落实措施。专班指导海洋类企业申报国家级高新技术企业以及各级各类科技项目，创建各类创新平台，采用“一对一”辅导、“一企一策”等方式为企业做好创新政策辅导。2021年，我市有3项海洋省级科技计划项目获得立项，资助资金230万元。新增10家国家级海洋高新技术企业、4家海洋省级小巨人企业、1家海洋省级星创天地。二是科技特派员服务海洋经济建设。鼓励和支持科技特派员服务海洋经济发展，在海洋领域我市有省级科技特派员23人、省级科技特派员团队8个，市级科技特派员18名为我市的海洋养殖和海产品加工企业开展技术服务。科技特派员以科研项目带动海洋渔业企业积极开发养殖新品种、海产品精深加工等技术研发，加速海洋科技成果的应用与推广，为我市海洋企业造了显著的经济和社会效益。2021年，我市共有2个海洋类科技特派员后补助项目获得省级和市级立项，企业获得资助经费40万元。三是开展海洋产学研合作。市科技局与集美大学签订校地产学研合作协议书，校地双方设立产学研合作办公室。利用集美大学在水产养殖、食品加工、环境治理等领域的优势，搭建技术开发、成果转化、人才培养的新平台。2021年，集美大学领导和专家4批24人次来莆调研指导我市海洋科技型企业，与企业多次召开座谈会进行技术对接。集美大学在我市开展牡蛎壳粉土壤调理剂示范试验，我市有7家企事业单位参与。市农科所开展的《牡蛎壳粉土壤调理剂在蔬菜栽培中的应用研究》项目，证明其具有调节土壤酸性、持续补钙、土壤结构改良、抗病抗逆、促根壮苗等特点，为下一步我市推广应用该科研成果提供科研技术基础。

五、以创建秀屿省级海洋产业发展示范区为契机，培育壮大“智慧海洋”产业

一是升级改造海上养殖设施。在市政府印发的《莆田市海上养殖转型升级行动方案》（莆政办〔2021〕36号）指导下，市海洋与渔业局全力推进海上养殖转型升级，利用两年时间（2021-2022年）完成泡沫浮球、老旧渔排更新改造，应用推广全塑胶养殖网箱、深水抗风浪大网箱等新型环保养殖设施和大型智能养殖装备，计划投入资金7亿元以上，更新改造渔排3.8万口以上，改造筏式吊养浮球海域面积5.7万亩以上，新建深水大网箱100口以上。其中：秀屿区任务为更新改造渔排2.34万口，浮球改造海域面积4.5万亩。截至目前，秀屿筏式吊养浮球已改造海域面积4.35万亩、建设环保型塑胶渔排1.5万口、利用设施渔业资金新建深水大网箱36口，其他相关县区同步推进海上养殖转型升级行动。任务完成后，海上养殖将更加环保、生态，产业发展将更加融合。二是推广应用现代科技管理手段。加强渔船信息化、智慧化管理，在沿岸建设17个渔港和15个渔排养殖集中区视频监控系统，共享20个海防沿海视频监控数据，实现渔港、渔排和沿岸多视角监控。对大中型海洋渔船安装海上宽带和船上可视化设备以及固定式北斗示位仪、“插卡式”AIS 安全监管设备，对7209艘乡镇船舶全部安装北斗三号定位终端，实行沿海船舶“一张图”信息化动态管理，实现“看得见、联得上、管得住”的安全监管目标。推进海洋灾害自动在线监测项目建设，在南日岛、平海湾、兴化湾重点养殖水域选择布设5个浮标系统，开展海洋环境污染及赤潮监测等突发海洋灾害自动在线监测，提高海洋环境灾害应急监测能力。三是推进现代渔业高质量发展。强化规划引领、优化养殖空间布局，推动全市水产养殖规范、生态、绿色、融合发展。制定颁布《莆田市养殖水域滩涂规划（2018-2030年）》（莆政综〔2018〕79号），明确“三区”（养殖区、限养区、禁养区）划定，深入开展水产养殖绿色健康养殖技术推广“五大行动”，推广应用工厂化循环水、立体生态养殖等养殖新模式，鼓励发展离岸养殖和深远海养殖。我市海洋与渔业部门成功创建海发国家级水产健康养殖和生态养殖示范区以及汇龙、海发2个省级鲍鱼养殖标准化示范区和万亩生蚝养殖基地；促成秀屿区与福建省闽投深海养殖装备租赁有限公司签订合作协议，拟引进1台套6万立方水体的深海养殖装备；围绕南日岛海域国家级海洋牧场建设，科学谋划南日岛全域开发，积极打造海洋牧场“南日岛样本”，推动数字、海洋、绿色、文旅经济融合发展，争创福建“四经”融合发展示范区，再造海洋经济高质量发展新引擎。

六、加快建设专业化、数字化的现代航运物流业

一是持续完善港口基础设施。莆田市港口目前已建成千吨级以上泊位20个，其中万吨级以上泊位14个，港口吞吐能力6584万吨（含集装箱4万TEU），具备靠泊通航世界最大矿石船（40万吨）、最大煤炭船（20万吨级）、最大LNG船等大型散货船，2021年完成港口货物吞吐量5012万吨。今年以来，我市认真贯彻落实市委、市政府《关于全方位推进莆田港口高质量发展的意见》及市政府《关于加快建设“海上莆田”，推进海洋经济高质量发展三年行动方案》，积极发挥港口优势，推进提升港口能级，全力推进海洋经济高质量发展。二是鼓励和引导航运业发展。通过下放行政审批权限减少办事环节、鼓励和引导企业发展船舶运力、强化服务意识提供优质服务等，不断优化营商环境，以积极的政策引导企业做强做大。2021年至今，我市共新增3家企业（航丰船务、湄龙船务、兴发工程公司），共新增船舶运力10艘共约8万吨，比增80%。现有航运企业13家，共有船舶77艘18.1万载重吨。三是简化审批推动水运服务业发展。船舶代理企业实施多证合一（国内船舶代理由工商部门直接登记即可）和备案制度（向交通运输部船东协会备案），不需要交通运输部门办理审批手续，直接可开展业务。船舶管理企业实施准入制度，全省实施五级十五同，符合条件即可获得经营许可。2021年以来，我市新增船舶管理1家，我市现有船舶管理业5家（湄龙、永顺、华海、长盛发、海顺公司）；现有船舶代理企业16家。水运服务企业能满足我市港航发展需求。
