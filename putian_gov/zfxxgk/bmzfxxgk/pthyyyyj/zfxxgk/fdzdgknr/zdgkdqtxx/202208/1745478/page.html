关于市政协八届一次会议第2022088号提案办理情况的答复

发布时间：2022-08-01 17:26
| | |

詹永东委员：

你提出的《关于统筹考虑南日群岛基础产业（农业+渔业)振兴的若干建议》（第2022088号）已收悉，我局分办意见如下：

南日镇是我市渔业产业强镇，周边海域资源丰富，水质优良，具有发展渔业的先天禀赋。近年来，我市以传统贝藻类养殖为基础，大力推进渔业产业结构调整，加快设施渔业升级改造，促进产业融合发展，积极推动南日岛渔业产业振兴和海洋与渔业经济高质量发展，着力打造南日岛特色的渔业岛、能源岛、旅游岛、低碳岛、智慧岛、生态岛。

一、关于探索海岛特色农业现代化发展模式

根据《莆田市海洋渔业发展中长期规划》（2018-2030年），市海洋与渔业局以南日岛现代海洋渔业产业发展示范区为未来一、三产产业发展重心，规划出南日岛沿岸滩涂增养殖区、近岸浅海增养殖区、近海增养殖区、海洋牧场示范区、深海装备养殖示范区及休闲渔业产业区等产业功能区，重点打造集海水立体生态养殖、海上风电、滨海度假旅游于一体的海洋产业集群。2022年，海洋渔业部门主动与龙源风电合作，以南日岛海上风电场一期项目为基础，在南日东北侧海域风电区开展贝藻类多层立体化生态养殖，总投资9000万元，预计实现水产品年产量3.4万吨，年产值4800万元，目前已养殖龙须菜等藻类3000多亩。项目最大程度实现了还海于民，解决了渔民群众失海再就业问题，形成了可复制可推广的海上风电区融合环保养殖模式，推进海上风电与海洋养殖、海上旅游等产业融合发展。接下来，我局将利用南日岛超10万吨的藻类年产量，主动推进南日岛藻类碳汇交易，预计创收数百万，提高养殖户收入的同时响应国家“双碳”政策号召，为生态产品价值实现探索新的路径。

二、关于妙用杠杆，撬动农业现代化要素保障

为加快我市现代渔业发展，推进“海上莆田”建设，全面实施乡村产业振兴战略，我局已争取市财政专项资金支持海洋与渔业经济高质量发展，制定出台《莆田市现代海洋与渔业发展专项资金管理办法》（莆财农〔2022〕43号），重点支持远洋渔业、水产种业、海上养殖转型升级、渔业品牌建设、产业融合发展等九个方向，引导促进渔业结构调整、产业链延伸、多产融合式发展。加大与金融机构合作力度，海洋渔业部门与农商银行签订战略合作协议，出台资金扶持政策和优惠金融产品，积极协调相关部门强化用海、用地以及资金等重点项目建设要素保障。

三、关于加强技术支持广度和深度

鼓励引导渔业龙头企业与科研机构深度合作，搭建产学研用合作平台，推进水产种业育繁推一体化发展。我局积极对接中科院海洋所和中国海洋大学，促成海发、正洋水产公司与中国海洋大学达成合作，在秀屿区南日岛海域示范推广龙须菜新品种“鲁龙一号”。落实省市人才引进办法，引进海洋高端科技、管理人才，提高科技创新能力，增强产业发展后劲，我局引进中科院海洋研究所的水产养殖专业博士选调生，并与组织部对接将其安排在南日镇进行为期两年的基层锻炼，加快培养产业发展带头人和创新型人才，切实做到人尽其才。邀请中科院海洋研究所李钧研究员、林承刚副研究员来南日岛指导海洋牧场建设，争取中科院海洋研究所及其他海洋研究机构在南日岛设立海洋技术研究中心、工程研究中心等海洋科研平台，为海洋牧场建设提供技术和人才支撑。

四、关于建立南日岛国家海洋牧场的监督、督查和反馈机制

我市坚持南日岛开发与保护并重的原则，立足海岛自然资源条件，突出海岛差异化定位，给予差异化政策倾斜，建立健全符合实际、科学规范的海岛开发与管理制度，推进海岛开发建设可持续发展，为全面系统保障南日岛创建好国家级海洋牧场先行示范区提供制度支撑。南日岛海域国家级海洋牧场为海底养护型海洋牧场，主要工程为分七期投放人工鱼礁、开展增殖放流和建设海底可视化系统，目前全部项目已于2021年完成建设，正准备迎接国家农业部项目验收。2022年，为深入贯彻落实省、市党委、政府有关海洋经济高质量发展的精神和要求，秀屿区以创建国家级海洋牧场先行示范区为核心，以南日岛全域开发为突破口，着力推进湾岛产业一体化发展态势，打造福建海洋牧场“南日岛样本”。南日岛国家级海洋牧场示范区正在由1.0时代向3.0时代迈进，为促进南日岛“四经”融合发展发挥积极作用。
