关于贯彻全省高温季节水产养殖生产管理暨赤潮灾后恢复渔业生产工作会议精神的通知

发布时间：2012-07-11 08:00
| | |

　　各县（区）海洋与渔业行政主管部门、后海管理局：

　　5月25日至6月3日期间，我市沿海持续发生赤潮灾害，使鲍鱼等养殖业遭受严重损失。赤潮灾害刚过一个多月，又迎来了高温季节，随着养殖水域水温逐步升高，各类养殖病害也容易发生，将严重影响水产养殖生产。6月26日省厅召开全省高温季节水产养殖生产管理暨赤潮灾后恢复渔业生产工作会议，对下一阶段工作进行布署，为贯彻落实《全省高温季节水产养殖生产管理暨赤潮灾后恢复渔业生产工作会议》的精神，现将有关事项通知如下：

　　一、要继续加强赤潮灾害的防控与高温引起病害的防治

（一）加大水质监测力度。在省厅水质监测预警项目建设未实施之前，各县（区）可根据实际情况，采取一些简易、快速、有效的水质监测方法，对辖区内重点水产养殖水域水质进行监测，及时、准确地掌握高温季节重点水域的养殖生产动态，防范水产养殖生物因高温缺氧或病害出现大面积的死亡。建立病害信息预警机制，充分利用手机等信息平台发送预警信息和相关防控措施，增强养殖户的预防意识，做到早发现、早预防。

　　（二）完善赤潮灾害应急预案。各渔业行政主管部门和有关单位要充分认识高温季节水产养殖生产管理及防控赤潮灾害工作的重要性，各县区要根据《莆田市人民政府办公室关于印发莆田市赤潮灾害的应急预案的通知》（莆政办〔2012〕117号）文的精神，结合实际情况，制定和完善县区防控赤潮工作预案。同时，要密切关注当前气候下各地方的养殖情况，开展各类养殖品种季节养殖状况的调查，研究制定针对高温季节水产养殖生产管理及赤潮灾后恢复渔业生产工作的具体措施和方案，严防赤潮灾害和高温气候引起的病害。

　　二、要加大水产养殖管理力度，恢复灾后渔业生产

(一)合理规划布局。合理规划布局是水产养殖业健康持续发展的重要措施。各县区海洋与渔业行政主管部门要按已颁布的水产养殖水域规划作为依据，精心组织对辖区内的各养殖水域的养殖总量、密度、品种搭配等进行指导，引导渔民规范养殖和科学管理。

(二)加强培训工作。各县（区）海洋与渔业行政主管部门要根据当前实际情况，合理安排、有针对性组织举办夏季池塘高温水产养殖管理培训班和赤潮灾害的预防与恢复生产培训班，引导渔民科学养殖，提高养殖灾害防控能力。各县（区）海洋与渔业行政主管部门要在7月20日之前将培训方案上报市局备案。

　　(三)做好渔民群众安抚工作。此次赤潮灾害，给我市部分海区养殖业造成重大损失，养殖户信心也受到严重打击。各县（区）渔业主管部门要继续做好对受灾群众的思想安抚工作，让群众看到养殖业的前景，恢复生产的信心和决心，同时要妥善解决受灾群众关心的难点、热点问题，切实维护社会安定稳定。

　　三、要加强领导，保障各项措施落实到位

　　（一）强化责任。各县（区）海洋与渔业行政主管部门和相关单位要充分认识高温季节水产养殖生产管理及赤潮灾后恢复渔业生产工作，是确保渔业平稳发展、渔民收入不减的重要保障，是自身义不容辞的义务和责任。要成立防灾减灾领导小组，建立“高效有序、运转协调、保障有力”的防灾减灾领导机制，集中力量、全力以赴地加强对高温季节水产养殖场生产管理及赤潮灾后恢复渔业生产工作的领导。将高温季节水产养殖生产管理及赤潮灾后恢复渔业生产工作作为当前首要任务，强化责任意识，将措施落实到每个养殖区、受灾点，指导养殖户在高温季节做好提前预防、科学养殖、科学管理。要关心关注遭受赤潮灾害养殖群众的生产生活，组织力量深入一线，扎实高效有序做好恢复生产指导工作。

　　（二）形成合力。高温季节水产养殖生产管理及赤潮灾后恢复渔业生产工作涉及渔业、环保、防灾减灾、应急指挥、渔业执法、技术推广、环境监测等职能部门和机构，要在主管部门的统一领导下，各司其职、加强沟通、形成合力，保障工作取得良好成效。

　　二○一二年七月十一日
