莆田市海洋与渔业局关于开展2019年渔业消防安全执法检查专项行动的通知

发布时间：2019-06-17 09:22
| | |

 

各县（区、管委会）渔业行政主管部门，市海洋与渔业执法支队：

    根据《福建省海洋与渔业局关于开展“防风险保平安迎大庆”渔业消防安全执法检查专项行动的通知》（闽海渔电〔2019〕103号）要求，我局决定开展2019年渔业消防安全执法检查专项行动，现将有关事项通知如下。

    一、检查时间

 自2019年6月至9月在全市范围内开展渔业消防安全执法检查专项行动。

    二、检查内容

    （一）渔港码头的检查

    1.制度建设，责任落实方面。重点检查渔港码头经营者或管理公司安全生产责任是否落实，安全管理制度、安全规程是否建立健全，是否制定消防安全制度和应急预案，消防责任部门和责任人是否落实到位。

    2.设施建设，规范管理层面。检查渔港码头的消防设施是否配备完整且处于可使用状态；渔船在港锚泊是否整齐有序，保留必要的水上消防通道，确保畅通无阻；渔港是设置明火作业区和装运易燃、易爆危险品作业区；渔船在渔港明火或装运易燃、易爆危险品是否经过渔港监督机构批准，且在作业区域内进行。

    （二）渔业船舶的检查

重点检查在港锚泊渔船消防制度是否健全，是否留足值班人员，渔船消防设备是否齐全，存放位置是否正确并处于随时可用状态；机舱、厨房、起居室等火灾易发点灭火器、消防泵、消防管路、电气设施老化、破损、漏油、短路或渗漏等安全隐患。

    （三）渔业养殖场的检查

    检查渔业养殖场、水产养殖企业安全管理制度、安全规程是否建立健全，安全生产责任是否落实到岗到人，是否制定消防安全制度和应急预案，消防设施是否配备完整且处于随时可用状态。重点检查使用危险化学品（特别是液氨）的水产养殖企业，全面开展隐患排查，坚决遏制涉渔危化品事故发生。

    三、工作要求

    （一）加强组织领导

    各级渔业主管部门及其执法机构要充分认识当前渔业消防安全的严峻形势,要将渔业消防安全列为安全生产监管工作的重中之重来抓,要结合海洋“蓝剑”“渔政亮剑”“打非治违”等执法行动，认真组织开展渔业消防安全执法检查，坚决消除渔业火灾隐患。

    （二）强化宣传教育

    各单位要大力宣贯《福建省消防安全责任制实施办法》，建立健全消防安全责任制制度，落实消防安全职责。结合今年开展的渔船安全生产隐患排查治理专项行动和常态化隐患排查治理工作的要求，督促渔船船东船长、渔业企业严格执行消防安全法规和标准，全面落实安全主体责任。同时，要积极开展渔业消防安全工作的宣传教育,让消防宣传“进渔港、到渔村、上渔船、进渔企”,在渔业领域全面普及安全用火、用电、用气、用油等消防安全知识,提高广大渔民群众的消防安全意识。

    （三）严格执法检查

    各级渔业执法机构要强化消防安全生产执法监管，充分利用当前伏休期间渔船停港靠岸的有利时机，加大执法检查力度。对检查发现的安全隐患，能当场整改的，责令当场整改到位；需限期整改的，发出责令整改通知书，责令停航停产限期整改到位；对拒不整改的，要依法从重处罚。

    （四）应急处置培训

    各级渔业行政主管部门及其执法机构要落实好船东船长的培训工作，加大消防安全教育培训力度，重点加强对渔业普通船员的培训工作，强化实战演练操作、消防知识人人会知道，消防应急处置人人能过关。各级渔业应急指挥机构要利用伏休节点，组织开展渔船、渔港消防安全应急救援演练，修订完善演练预案，提升消防应急救援能力，提高渔业从业人员自救互救能力。

    各单位每月24日前将专项行动工作进展情况表报送市局安办，9月13日前报送工作总结。
