莆田市海洋与渔业局关于做好2023年渔业防汛备汛工作的通知

发布时间：2023-02-10 14:53
| | |

各县（区、管委会）渔业行政主管部门，局渔业防台风应急工作领导小组成员单位：

   2023年是全面贯彻落实党的二十大精神的开局之年，做好防汛备汛工作责任和意义重大，各级渔业行政主管部门要坚持以习近平新时代中国特色社会主义思想为指导，坚持人民至上、生命至上，扎实做好渔业防汛备汛各项工作，为我市全方位推动渔业高质量发展超越创造良好的安全环境。

据省市防指会商预测，2023年我省气候和台风灾害总体趋势接近常年，但不排除发生极端强降雨、强台风的可能，登陆或影响我省的台风个数为5-6个，6月可能有早台风影响我省，夏季有1-2个台风登陆或严重影响我省。为扎实做好2023年我市渔业防汛备汛工作，消除渔业防汛防台风隐患，切实拧紧责任链条，根据省海洋与渔业局和市防指有关工作部署精神，现将有关事项通知如下：

一、全面压紧压实防汛责任

各县（区、管委会）渔业行政主管部门要按照当地防指部署要求认真抓好贯彻落实，切实加强渔业防汛备汛工作组织领导，及早部署、细化安排，督促落实安全度汛防台风各项措施。要进一步完善上下级、部门间的衔接配合，及时调整充实防汛防台风机构，优化人员组成。严格落实以部门责任制、岗位责任制为重点的责任体系和各项责任制度，逐级落实所管辖区养殖渔排、水产养殖场（水库、池塘）、渔船、避风渔港、避风锚地等防汛防台风责任人,把工作责任制落实到人到岗，拧紧责任链条。

各县（区、管委会）渔业行政主管部门要重新统计辖区避风渔港、避风锚地和渔船、海上养殖渔排及作业人员的数量，并登记造册，为渔业防汛防台风决策摸清底数。及时公布辖区内责任人名册，主动接受社会监督，并采取电话抽查等方式，加强防台风责任人工作落实。加强渔船跨省避风管理工作，认真落实省防办和省局《关于加强渔船跨省紧急避风管理的通知》（闽汛防办〔2022〕7号）中明确的六项措施要求，确保群众生命财产安全。

二、及时修订完善应急预案

各县（区、管委会）渔业行政主管部门和局渔业防台风应急工作领导小组成员单位要认真抓好海洋渔业各类应急预案的编修工作，在今年4月1日前完成海洋渔业防台风预案的修订工作。应急预案是防汛工作的重要抓手，各地要切实加强应急预案管理，把修订预案工作作为重点工作抓实抓细抓好，突出适用性、针对性和可操作性，坚持问题导向，定期开展预案评估，发现问题，查找短板，动态优化，及时优化和健全工作机制，健全完善我市应急预案体系。应急预案公布后，各地要做好组织实施和解读工作，并组织相关管理人员、救援人员、应急值班人员开展实战演练和培训教育工作，让预案有关单位和人员明晰各自职责和工作要求，熟悉处置流程，提升指挥决策和协同联动水平，进一步提高人员队伍能力水平。同时，根据部门实际和需求，做好应急物资储备管理工作。

三、持续排查整治安全隐患

各地要紧盯责任预案、度汛安全等重点，按照当地防汛抗旱指挥部部署要求组织做好汛前安全检查工作，认真查找扫除盲点死角，重点排查渔船、养殖渔排、避风渔港（锚地）、渔业码头的避风防灾功能以及执法、抢险救灾船艇等，抓紧组织力量对渔业设施进行除险加固，对发现的险情和安全隐患，要建立台帐，明确责任单位、整改措施，限期整改到位，严格落实闭环管理制度；若汛前无法整改到位的，必须落实应急防护措施，并报告上级主管部门和当地防汛抗旱指挥部，同时要及时将当地防汛抗旱指挥部部署的汛前防汛防台风大检查工作情况上报上级主管部门和当地防汛抗旱指挥部。

四、强化应急能力建设

各县（区、管委会）渔业行政主管部门要根据应急管理标准化要求，认真抓好机构、人员、职责制度、场所、经费落实。要认真落实汛期应急值班制度，加强安全应急24小时值班和领导带班；通讯工具要始终处于开机状态，保障应急通讯畅通；及时接收、转发省海洋预报台和气象部门发布的预警报信息。继续做好全国渔业24小时值守电话“95166”开通管理工作，提升渔业公共服务能力和水平。充分利用“北斗示位仪”和“AIS”等手段加强海上作业渔船和渔港内避风渔船的组织、保障指挥和监管，掌握辖区内渔船数量和动态，保障渔船安全生产。同时，加大安全救助终端在线管理力度，认真开展终端离线的自查自纠，严厉打击擅自关闭、拆卸和故意损坏终端设备的违法违规行为，切实保证终端上线率。切实做好渔船动管系统和渔港渔排集中区视频监控系统及设备的维护，发现问题及时采取措施修复，确保防汛防台风期间正常运行。熟练运用“莆田市大数据调度指挥平台”中“防汛防台风”应用专题场景，并及时更新各类防汛防台风要素数据信息。

五、及时报送灾情信息

各县（区、管委会）渔业行政主管部门要高度重视灾情报送信息员队伍建设和管理，确保每个渔村、乡镇以及县区主管部门都要有1名灾情信息员，要在保障信息员队伍稳定的同时，及时开展灾情调查、统计、核对和报送工作，杜绝出现迟报、漏报、乱报现象。市水产技术推广站、水产科学研究所、后海围垦管理局和市海洋与渔业执法支队等单位要加强防汛防台风应急抢险与灾后重建队伍库人员管理，做好汛期的应急准备工作，根据市防指和省局的统一指挥，执行应急任务。

各县（区、管委会）渔业行政主管部门和后海局要认真落实以上各项防汛防台风措施，按时完成2023年防汛备汛各项统计汇总工作。按下列时间要求报送：1.分别于2月13日、3月3日、3月17日前将2023年备汛情况汇总表 （附件1）报送市局防灾减灾科；2.于3月22日前将辖区内避风渔港、避风锚地、海上养殖渔排集中区防台风责任人汇总表及渔船、渔排数量摸底统计表（附件2、3、4）汇总后同汛前隐患排查整治情况（重点检查渔船渔排、避风渔港和乡镇管理船舶）一起上报市局防灾减灾科。上述需报送的材料请加盖公章后报送至市局防灾减灾科，同时将电子文档发送至电子邮箱。
