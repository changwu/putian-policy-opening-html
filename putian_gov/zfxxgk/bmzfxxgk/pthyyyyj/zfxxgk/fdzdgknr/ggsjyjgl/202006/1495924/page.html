莆田市海洋与渔业局关于印发莆田市2020年渔业安全生产工作要点的通知

发布时间：2020-06-10 10:05
| | |

各县（区、管委会）渔业行政主管部门，局安全监管工作领导小组成员单位:

现将《莆田市2020年渔业安全生产工作要点》印发给你们。请各有关单位按照“管行业必须管安全，管业务必须管安全，管生产经营必须管安全”的要求，抓好贯彻落实。各项工作完成情况于2020年12月15日前报送市局安办。  

 

                           莆田市海洋与渔业局

                                 2020年5月28日

莆田市2020年渔业安全生产工作要点

 

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中、四中全会精神，深入贯彻习近平总书记关于安全生产工作重要论述和指示批示精神，认真贯彻落实党中央、国务院和各级党委政府的决策部署，不断深化渔业安全生产领域改革发展，坚决打好防范化解重大安全风险攻坚战，深入开展渔业安全生产专项整治工作，进一步完善和落实安全生产责任和管理制度，健全完善隐患排查和安全预防控制体系，持续强化安全生产基础能力建设，努力减少一般事故，坚决防范遏制较大及以上事故，促进全市渔业安全生产形势持续安定稳定。

 一、深入学习贯彻落实习近平总书记关于安全生产工作重要论述精神

（一）持续深入开展宣贯教育活动。深入学习贯彻习近平总书记在主持中央政治局第十九次集体学习时的重要讲话和1月23日就“2019年全国生产安全事故主要特点和突出问题”作的重要批示精神，以强烈的政治担当、历史担当、责任担当，有力防范化解重大安全风险。将学习贯彻习近平总书记关于安全生产工作重要论述纳入理论中心组学习内容，牢固树立新发展理念，坚守红线意识和底线思维，把好安全发展、高质量发展的总开关，坚决扛起保民平安的政治责任。

（二）推动落实改革发展重点任务。对照《中共莆田市委 莆田市人民政府关于推进安全生产领域改革发展的实施意见》（莆委发〔2017〕20号）及省局《贯彻落实<中共福建省委 福建省人民政府关于推进安全生产领域改革发展的实施意见>工作方案》（闽海渔〔2017〕278号）重点任务分工和时间进度要求，进一步明确责任、措施和要求，加强专项督导，确保各项任务措施落地生根。

二、抓好新冠肺炎疫情防控期间的渔业安全生产工作

（一）抓好安全生产和疫情防控“两个责任”落实。按照“一手抓疫情防控、一手抓安全生产”的要求，做到渔业安全生产与疫情防控同部署、同落实、同指导、同服务。督促渔船、渔业企业落实好疫情防控和安全生产“两个主体责任”，落实好复工复产安全防范工作各项责任措施。

（二）创新服务方式推动复工复产保障安全生产。对较大

渔业企业等特殊场所开展“一对一”安全服务,指导生产经营单位落实主体责任，建立健全内部安全责任制和安全管理机制，落实疫情防控要求，减少人员接触和聚集。深化集中整治和隐患排查，全力服务保障渔业复工复产安全生产。

三、完善渔业安全生产责任体系

（一）落实渔业安全生产和消防考核。抓好年度工作考核，科学制定考核评价指标，优化整合考核事项，创新检查考核方式方法，强化结果运用，切实发挥考核的“指挥棒”作用。多措并举用好约谈通报、警示曝光、建议提醒、挂牌督办等“组合拳”，推动《莆田市党政领导干部安全生产责任制实施办法》和《福建省消防安全责任制实施办法》落到实处。

（二）加强渔业安全监管执法。贯彻落实《福建省实施<渔业法>办法》，持续开展“打非治违”、福建海洋“蓝剑”、“中国渔政亮剑”、伏季休渔等执法行动，加强敏感海域渔船管控，严厉打击涉渔“三无”船舶、渔业船舶脱检、无证出航、拆除或故意屏蔽关闭渔船安全终端等安全生产违法违规行为。落实渔船进出港报告制度，维护水上安全生产秩序。进一步规范渔业安全监管执法，推行行政执法公示制度、执法全过程记录制度和重大执法决定法制审核制度，严格执法信息公开制度。加强执法监督，组织一线执法人员参加执法业务培训，进一步提升渔业安全监管执法水平。

（三）强化渔业安全应急管理。修订完善各类安全应急预案，落实24小时应急值守和领导带班制度，严明工作纪律，保持信息畅通，落实事故报告制度，有效开展应急救援和处置，及时处置化解突发事件。严格执行《渔业安全救助终端管理暂行办法》，严厉打击私自拆卸、屏蔽渔船安全救助终端等行为，确保设备在线率，进一步抓好《生产安全事故应急条例》的宣贯培训。组织开展渔业安全生产和应急管理培训，持续开展水上安全应急救援演练，提高渔业安全救助能力，切实把各项要求落到实处。

（四）建立健全安全生产主体责任机制。积极参与农业农村部组织的“平安渔业示范县”创建活动。大力推进渔船安全生产标准化建设，提高渔船创建的内生动力。开展安全生产责任制考核，推动完善全员安全生产责任制。不断强化渔业安全管理基础，加强安全生产业绩考核，突出主体责任落实。

四、深入排查隐患，健全预防控制体系 

（一）深化渔业安全风险隐患排查治理。坚持“分级负责与属地负责相结合、属地负责为主；部门监督检查与船东船长、渔业养殖企业主自查自纠相结合、自查自纠为主”的原则，集中排查治理渔船、渔业养殖企业安全风险隐患。做到所有经营人、负责人深入开展自查自纠，落实风险隐患闭环管理。规范隐患排查治理月报统计和归口直报工作。加大重大事故隐患整改力度，严格落实整改措施、责任、资金、时限、预案“五到位”工作要求。

（二）开展渔业安全隐患整治专项行动。以问题导向，开展渔船安全生产专项整治行动，坚决整治防范化解重大安全风险中责任落实不到位、树立新发展理念不到位、安全生产责任落实不到位、开展隐患排查不深入不扎实、打击违法违规行为不力等形式主义、官僚主义突出问题。加大渔船不适航、船员不适任等行为的整治力度。严厉打击超员、超载、超抗风等级、超航区航行作业等行为。整治养殖占用航道、超规划养殖、养殖渔排设施老旧等安全隐患。

（三）做好防汛防台风工作。严格落实渔业防汛防台风各项制度，逐级落实渔业防汛防台风责任人。切实抓好汛前安全检查，紧盯薄弱环节，全面排查整治风险隐患。进一步修订完善渔业防台风预案，严格落实汛期应急值班制度，贯彻落实市委、市政府、市防指关于防汛防台风的工作部署，按照预案科学指挥调度，从严、从细、从实做好渔业防台风各项工作。

（四）全力防范化解危险化学品安全风险。开展危险化学品本质安全三年提升行动,严格渔业行业使用危险化学品安全风险管控，深化综合治理和专项整治,推动完善危险化学品储存、使用和废弃处置等各环节安全监管体制机制,坚决防范危险化学品风险。

（五）加大渔业船舶“打非治违”力度。严厉打击渔业船舶脱检脱管、非法挂靠经营、恶劣天气条件下违反禁限航规定等违法违规行为。积极推进海洋渔船北斗视位仪定位终端安装工作。加强渔港视频监控、渔船动态管理系统建设。联合有关单位开展涉渔“三无”船舶、泡沫筏、乡镇农用船等非规范船舶综合治理工作，严厉打击渔业船舶非法载客行为，严防商渔船碰撞，严防疫情海上输入。

五、构建完善安全监管执法体系

（一）完善安全生产相关制度和规范。完善“党政同责、一岗双责”规定，规范渔业行政处罚自由裁量标准，充分发挥行刑衔接机制的作用，依法严厉打击安全生产违法违规行为。

（二）坚持严格执法与指导服务并重。推进行政审批“放管服”改革和事中事后监管，对接省级“双随机、一公开”协同监管平台，全面推行“双随机、一公开”抽查、跨部门联合抽查。合理划分市、县（区）执法管辖权限，明确职责分工，避免多层级重复执法和执法缺位。

六、巩固提升安全生产基础保障体系

（一）持续提升基础保障能力建设。加快实施渔港工程建设，提高渔港防灾减灾保障能力。积极推进渔船通导与安全设备建设项目，完成全市小型海洋捕捞渔船北斗示位仪的安装。配合省局推进渔船动态管理系统和一级以上渔港视频监控系统建设，为海洋渔船全方位、全周期的安全管理提供技术支撑。

（二）加强渔业安全生产宣教培训工作。围绕“安全生产月”和“防灾减灾日”等主题，深入开展好安全生产咨询日、防灾减灾日等活动，通过宣传册、科普知识、短视频等多种形式，深入宣传贯彻落实《福建省实施<渔业法>办法》《渔船进出港报告制度》，严格执行《渔业安全救助终端管理暂行办法》，宣传普及安全知识，提高公众防灾减灾意识和安全生产意识。加强渔业船员培训，加大安全培训力度，突出安全实操、应急处置、商渔船避碰规则、值班瞭望、自救互救知识与技能的培训，提高船员持证率，提高渔民遵守安全生产规定的自觉性和应急处置能力。
