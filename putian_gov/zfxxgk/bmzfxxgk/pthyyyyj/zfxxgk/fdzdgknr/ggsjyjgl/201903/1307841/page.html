莆田市海洋与渔业局关于公布2019年海上渔船渔排防台风责任人的通知

发布时间：2019-03-19 17:12
| | |

各县区（管委会）海洋与渔业行政主管部门，局机关各科室、局直属各单位：

为进一步做好今年我市渔业防台风工作，坚持属地为主和分级分部门负责的原则，保证渔业防台风工作高效有序开展，根据《莆田市渔业防台风应急预案》要求，现将2019年莆田市避风渔港、避风锚地和海上养殖渔排集中区防台风工作责任人进行公布，请各县区（管委会）海洋与渔业主管部门和各防台风工作责任单位以及责任人要以对人民生命财产安全高度负责的态度，按照《莆田市渔业防台风应急预案》要求，认真履行职责，切实落实责任，扎实做好渔业防台风的宣传、渔船回港避风、渔船渔排人员转移以及值守巡查和应急处置等工作。市局防台督查组要按照《莆田市海洋与渔业局关于印发渔业防台风督查工作方案的通知》（莆海渔〔2014〕194号）分组层级督查的要求，加强片组辖区内避风渔港、避风锚地和海上养殖渔排防台责任制落实情况的督促、检查和指导工作，确保汛期各项渔业防台风措施的落实。
