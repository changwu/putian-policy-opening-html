莆田市海洋与渔业局关于做好2015年渔业防汛备汛工作的通知

发布时间：2015-02-13 08:00
| | |

　　各县区（管委会）海洋与渔业行政主管部门、后海围垦管理局、局属各有关科室单位：

　　据气象、水文部门对气候水情分析预测，今年影响我市的台风个数接近常年，其中影响或登录我市台风的有3个。根据市防汛抗旱指挥部《关于做好2015年防汛抗旱工作的通知》（莆市防汛〔2015〕2号）文件精神，结合我市海洋与渔业防汛工作实际，现就做好今年防汛备汛工作通知如下：
　　一、落实渔业防台责任
　　各县区（管委会）海洋与渔业行政主管部门和有关单位要在汛期和台风到来之前安排部署好各项防汛准备工作，落实以主要领导负责制为主的各项责任制，要按照海洋与渔业防灾减灾各类预案，尤其是按照渔业防台风应急预案的具体要求，对辖区养殖渔排、水产养殖场（水库、池塘）、渔船、避风渔港、避风锚地、渔船停泊点等渔业设施及渔业从业人员进行普查统计，分门别类登记造册（登记表见附表1、附表2、附表3），并在3月中旬前，按照渔业防台风包镇、包村、包组，包排（船）挂钩联系责任制的要求，确定并逐级落实渔业防台风具体责任人，明确职责，防止因人事变动、岗位调整造成的责任脱节。市局将根据各县区（管委会）上报的统计资料和责任挂钩情况进行汇总，并在市局门户网站上公布，接受社会监督。
　　二、开展安全隐患排查
　　各县区（管委会）海洋与渔业行政主管部门和有关单位要及早动员部署，组织开展防汛防台安全检查，重点对渔港避风防灾功能、渔业码头、养殖渔排、抢险救灾船艇和渔港的监控、消防、照明等设施设备的安全检查，对检查中发现的险情和安全隐患，要明确责任单位、整改措施，限期整改到位。要充分利用汛前的有利时机，抓紧组织力量对渔港、渔排、养殖场等渔业设施进行除险加固，确保安全度汛，要做好沿海渔港、养殖区视频监控系统、应急指挥平台等应急管理设备的维护修理工作，执法机构要组织对执法船艇及其设备进行检验检修，加强与各级指挥中心通讯定位测试，对发现的问题及时采取措施修复，确保防台防汛期间正常运行，省厅和市局将在汛前组织开展检查。

　　三、完善应急预案体系
　　市、县区海洋与渔业行政主管部门和有关单位要加强预案的执行和管理，要根据上级渔业防台风预案实施和修订情况，结合本辖区实际，适时修订完善各自的应急预案，按照市局《渔业防台风督查工作方案》的要求，进一步健全完善防汛防台工作机制，规范和落实防台风工作应急值班、分片包干、驻点巡查、层次督查、险情通报、灾情统计等制度，加大对防台风工作落实督查和责任追究工作。

　　四、强化渔船终端管理

　　渔船通讯终端的配备和使用以及指挥平台建设是提高应急救助的根本保障，已列入渔业安全生产年度考评的重要内容，各县区（管委会）渔业行政主管部门要加强终端设备使用情况的监督检查，指定一名业务人员专人负责指挥系统后台数据的日常维护工作，建立市、县（区）两级终端数据双查双核制度，各县区（管委会）在办理渔船过户、注销和新增业务时，要审核并及时更新指挥系统后台数据，并在一周内将《船载终端入网注册、变更、注销、安装、证明》传真市局指挥中心，由市指挥中心对数据库更新情况进行复核补缺，确保船载终端数据与渔船信息匹配，提高终端定位率。

　　五、落实渔船救助队伍

　　建立健全海上渔业船舶应急救助队伍，提高渔民海上应急事件的自救互救能力，发挥区域性群众渔业海上应急救助作用具有十分重要的意义。各县区（管委会）渔业主管部门要加快组建和建立乡镇、村渔业船舶应急救助队伍，登记造册（见附表4），加强管理培训，强化渔业应急救助调度。同时要在辖区内组织1～2次防灾减灾、应急抢险业务培训和演练，提升应急抢险队伍的技术和技能，确保一旦发生险情，能够高效、有序、及时地开展抢险,将损失降到最低限度。对于积极参与抢险救助行动的船舶要按照《福建省渔业船舶救助专项补助暂行办法》（闽海渔〔2012〕140号）规定予以申请补助奖励，提高渔船参与抢险救助的积极性。

　　六、完善灾情统计，落实灾情报送

　　各级海洋与渔业行政部门和相关单位要加强灾情信息员队伍的建设，确保每个渔村、乡镇以及县区主管部门都要有1名灾情信息员，负责灾情信息调查统计，核实汇总工作，并明确分管领导对统计资料进行复核把关，严格按照省厅的《福建省海洋灾情调查评估和报送规定（暂行）》和市局《关于规范海洋渔业防台风报表报送工作的通知》（莆海渔〔2014〕152号）的相关规定，及时做好灾情调查、统计、核对和报送工作，杜绝出现迟报、漏报、乱报现象。

　　七、强化应急值守，保障信息畅通

　　各县区（管委会）海洋与渔业行政主管部门和有关单位要认真落实汛期应急值班制度，加强安全应急24小时值班和领导带班，通讯工具要始终处于开机状态，保障应急通讯畅通。各级应急指挥中心和单位值班人员要加强与海洋预报台气象、水文等部门联系，及时收集汇总预警信息，并在第一时间通过手机短信平台、传真电报等形式向相关部门和单位以及渔民进行通报，确保汛期风暴潮、海浪、赤潮等灾害的预警报信息发布及时有效。

　　请各县区（管委会）海洋与渔业行政主管部门和有关单位于3月15日前将本部门防汛备汛工作落实情况，特别是责任制落实情况，汛前安全检查等情况书面报告市局，并将相关表格汇总上报市局防灾减灾办。
