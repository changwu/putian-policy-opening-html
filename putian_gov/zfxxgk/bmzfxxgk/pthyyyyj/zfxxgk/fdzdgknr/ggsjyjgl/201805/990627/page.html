莆田市海洋与渔业局关于做好2018年防汛备汛督查整改工作的通知

发布时间：2018-05-25 09:32
| | |

各县区（管委会）海洋与渔业行政主管部门,局机关各科室、局直属各单位：

　　为认真贯彻落实省、市今年开展防汛备汛安全工作的部署精神，省海洋与渔业厅和我局分别于4月下旬组织开展了2018年防汛渔业安全生产督查工作，现将《福建省海洋与渔业厅关于2018年防汛备汛督查情况的通报》（闽海渔〔2018〕98号）转发给你们，并提出以下工作要求，请结合《莆田市海洋与渔业局关于2018年渔业防汛备汛工作督查情况的通报》（莆海渔〔2018〕98号）情况，认真落实督查反馈问题的整改工作。

　　一、强化防汛责任落实。各县区渔业行政主管部门和相关单位要按照督查通报的情况和渔业防汛工作的要求，进一步落实渔业防汛防台工作责任制，加强协调指导，督查督办，及时解决防汛防台安全排查中发现的问题，把整改责任压紧压实落实到位，切实做好汛期渔业安全工作。

　　二、限期整改落实到位。各县区渔业行政主管部门和有关单位要认真对照省、市督查发现的问题，并举一反三，重点做好渔港避风防灾功能、渔港设施设备、渔船安全救助终端配备使用的安全隐患排查和按照渔业应急管理标准化建设要求，落实应急管理整改工作，明确整改责任单位、整改措施，限期整改到位。请各单位于2018年7月15日前将整改落实情况报市局。

　　三、深化排查整改工作。各县区渔业行政主管部门和有关单位要继续深入全面开展渔业防汛安全隐患排查工作，按照属地管理原则，抓紧组织力量对渔港、渔排、养殖场等渔业设施进行除险加固，对检查中发现的问题和薄弱环节要加快整改，并落实安全度汛措施，若短期无法整改到位的，必须落实应急防护措施，并报告市局和当地防汛抗旱指挥机构，协调督查整改工作，确保渔业防汛防台措施落到实处。

　　附件：福建省海洋与渔业厅关于2018年防汛备汛督查情况的通报（闽海渔〔2018〕98号）

　　                        莆田市海洋与渔业局

　　                          2018年5月22日
