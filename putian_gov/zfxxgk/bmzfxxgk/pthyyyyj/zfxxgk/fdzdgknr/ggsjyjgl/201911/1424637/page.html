莆田市海洋与渔业局关于印发莆田市近岸海域赤潮灾害渔业应急预案的通知

发布时间：2019-11-12 16:26
| | |

各县区（管委会）渔业行政主管部门，局机关各科室，局属各单位：

    为有效应对我市近岸海域赤潮灾害突发事件，我局根据有关法律法规对《莆田市海洋与渔业局赤潮灾害应急工作预案》进行了修订。现将修订后的《莆田市近岸海域赤潮灾害渔业应急预案》印发给你们，请结合实际贯彻执行。原《莆田市海洋与渔业局赤潮灾害应急工作预案》（闽莆渔〔2017〕186号）同时废止。

                                 

 

莆田市海洋与渔业局                               

                                     2019年11月6日


莆田市近岸海域赤潮灾害渔业应急预案

    1. 总则

    1.1 编制目的

    为建立健全赤潮灾害对渔业影响的应急反应机制，确保能够及时、迅速、高效、有序地开展应急跟踪监测和防灾减灾工作，最大限度地减轻赤潮灾害造成的损失和危害，保障公众生命财产安全，促进海洋渔业全面、协调、可持续发展，特制定本工作预案。

    1.2 编制依据

    依据《中华人民共和国环境保护法》《中华人民共和国海洋环境保护法》《中华人民共和国渔业法》《中华人民共和国突发事件应对法》《福建省环境保护条例》《福建省海洋环境保护条例》《国家突发公共事件总体应急预案》《福建省突发公共事件总体应急预案》以及农业农村部等十部委《关于加快推进水产养殖业绿色发展的若干意见》《福建省近岸海域赤潮灾害渔业应急预案》《莆田市自然灾害救助应急预案》等。

    1.3 工作原则

    1.3.1 以人为本，减少危害。切实履行政府的社会管理和公共服务职能，坚持以人为本，最大程度地保障公众生命财产安全，促进海洋渔业健康发展。

    1.3.2 统一领导，分级负责。建立健全综合协调、属地管理为主、分级负责（响应）的赤潮灾害渔业应急管理机制。各部门和单位按照职责分工密切配合、资源共享、协同行动，形成协调有序、运转高效的应急管理机制。

    1.3.3 预防为主，防应结合。开展海洋赤潮灾害的宣传和普及工作，加强赤潮的常规监测和赤潮生物毒素检测，提高赤潮灾害预警报能力，建立赤潮预警快速反应机制，保证发现、报告、监测、防治等环节紧密衔接，一旦发现赤潮，快速做出反应。

    1.4 适用范围

    本预案适用于我市近岸海域发生赤潮灾害并影响渔业时所进行的应急处置工作。

    2. 组织机构和工作职责

    2.1 应急组织体系

    成立莆田市海洋与渔业局赤潮灾害渔业应急工作领导小组（以下简称“市局领导小组”），负责全市海洋渔业系统赤潮灾害渔业应急处置工作。市局领导小组下设办公室，挂靠局防灾减灾科。

2.1.1 市局领导小组

组  长：局长

    副组长：分管防灾减灾工作的副局长任常务副组长；其他局领导和市海洋与渔业执法支队主要领导任副组长。

成  员：局防灾减灾科、渔业产业科、办公室负责人，局机关党委专职副书记，市海洋与渔业执法支队分管副支队长，市海洋与渔业环境监测站、市水产技术推广站、市水产科学研究所和后海围垦管理局负责人。

2.1.2 市局领导小组办公室

主任：局防灾减灾科负责人

成员：局防灾减灾科、市海洋与渔业环境监测站、市水产技术推广站、市水产科学研究所等有关人员。

    2.2 组织机构职责

2.2.1 市局领导小组主要职责

    ⑴制定市级赤潮灾害渔业应急预案并监督实施；

    ⑵批准启动、调整和终止赤潮灾害渔业应急响应；

⑶研究决定赤潮灾害渔业应急工作重大事项；

⑷及时向市委、市政府和省局报告赤潮灾害状况、发展趋势和防御应对工作情况；

⑸决定派出赤潮灾害渔业应急响应技术指导工作组。

2.2.2 市局领导小组办公室职责

⑴负责市局领导小组的日常工作；

⑵在赤潮灾害发生期间，负责落实应急值班；

⑶加强与相关部门沟通与联系，组织落实市局领导小组的工作部署，督促各项赤潮应急处置措施的落实，反馈上级领导的批示；

⑷建议启动、调整和终止赤潮灾害渔业应急响应，及时报告全市赤潮灾害情况和渔业应急处置情况；

⑸协调督促各成员单位抓好赤潮灾害渔业应急工作的落实；

⑹负责赤潮灾害信息的收集、归档，组织赤潮灾害损失调查、汇总、评估工作；起草、修订市级赤潮灾害渔业应急预案。

2.2.3 市局领导小组成员单位的主要职责

⑴局防灾减灾科（应急指挥中心）：承担市局领导小组办公室职责。

⑵局办公室：负责赤潮灾害应急处置后勤保障工作；负责赤潮渔业防灾减灾的信息公开、新闻宣传、舆情监测和舆论引导工作；负责赤潮渔业防灾减灾应急工作的资金保障，申请申报省、市级防灾抗灾救灾救助资金。

⑶局渔业产业科：协助指导、监督渔业生产防灾减灾和渔业灾后恢复生产工作；负责做好赤潮期间赤潮海区水产品质量安全监管，指导县区渔业行政主管部门适时决定关闭和解禁养殖区。

⑷局机关党委：协调督促局有关部门和单位落实赤潮渔业防灾减灾应急工作情况的监督检查工作，对有关责任人工作不到位、玩忽职守、推诿扯皮，造成严重后果与不良影响的，按照有关规定追究责任。

⑸市海洋与渔业执法支队：协助做好赤潮灾害养殖海区内养殖水产品的监管；加强重点海域巡航监视，及时向市海洋与渔业环境监测站通报监视情况；协助赤潮灾害应急监测的用船工作。

⑹市海洋与渔业环境监测站：协助市局领导小组办公室做好日常工作；开展赤潮应急监视监测工作；负责赤潮发生、发展条件的预测分析，编制赤潮灾害监测信息，及时将监测结果和趋势预测向市局领导小组办公室报告。

⑺市水产技术推广站：负责渔业减灾和灾后恢复生产、水生生物疫病防控的技术指导，通过短信平台向沿海养殖户发送赤潮相关信息和防灾减灾技术措施。

⑻市水产科学研究所：负责赤潮灾害渔业直接经济损失评估工作，编报赤潮灾害调查评估报告，参与渔业减灾和灾后恢复生产的技术指导和赤潮应急监测。

⑼后海围垦管理局：负责做好后海垦区内海域赤潮灾害的防御工作。

⑽局机关其他科室和直属其他事业单位：参与赤潮渔业防灾减灾应急值班等工作；承办局领导小组交办的其他任务。

    3. 常规监测与预警机制

3.1 常规监视监测

    各级渔业行政主管部门要建立有效的社会动员机制，充分动员、发挥专业技术人员、社会团体、渔民和志愿者队伍的作用，依靠公众力量，形成全方位、覆盖广的赤潮灾害监视监测网络。赤潮高发期，对重点养殖海域开展赤潮常规监视监测工作，及时掌握赤潮发生动态，获取赤潮监测、预警及防范基础数据和信息。

    3.2 预测预警

各级渔业行政主管部门要组织相关技术单位和专家按照赤潮发生面积、赤潮生物毒性以及对渔业产生危害程度，对监测信息进行预警会商和评估，确定赤潮灾害预警响应等级，并及时向同级政府和上级渔业行政主管部门报告。

4. 应急响应与处置   

按照赤潮发生面积、生物毒性和对渔业造成的危害程度，将赤潮灾害渔业应急响应级别分为四级。    

    4.1 四级应急响应

4.1.1 启动条件

在我市管辖的近岸海域发生的赤潮灾害，出现下列情况之一的，启动四级应急响应程序：

⑴无毒赤潮面积100平方公里及以上；

⑵有毒赤潮灾害面积达到5平方公里及以上；

⑶出现3人以下因赤潮毒素导致的人身严重不适病例报告；

⑷可能造成渔业直接经济损失100万元以上。

4.1.2 应急处置

⑴市局领导小组办公室接到赤潮确认信息后及时报告市局领导小组；通知各相关成员单位、沿海县区（管委会）渔业行政主管部门进入应急状态；落实24小时带值班制度，加强信息监控、收集和报送，并将发生赤潮灾害情况适时上报市政府办公室和省局领导小组办公室。

⑵市局领导小组召开应急会商会，制定相应的对策，组织、协调和监督应急响应措施的实施；根据赤潮发生情况和应急需要，及时组织有关部门和技术人员赴现场，开展渔业生产防治、减灾自救、灾情统计等工作进行指导。

⑶监测单位赶赴赤潮发生海域开展应急跟踪监测，对有毒赤潮开展赤潮生物及赤潮毒素鉴定和检测，对赤潮区域及邻近海域的水产品质量安全检测，及时掌握赤潮灾害发展趋势，并将相关信息报市局领导小组办公室。监测信息报送频率不少于每2日1次。

⑷沿海渔业行政主管部门接到通报后，认真履行职责，切实组织落实应急处置各项工作；组织渔业技术人员深入一线指导渔业生产减灾自救；开展灾情统计、评估工作，按要求积极配合做好敏感、重要养殖区水域采样送样工作，禁止受生物毒素污染的水产品上市。

⑸通报相关部门做好市场监管和赤潮毒素患者救治工作；做好赤潮灾害的信息公开、新闻宣传、舆情监测和舆论引导工作。

4.2 三级应急响应

4.2.1 启动条件

在我市管辖的近岸海域发生的赤潮灾害，出现下列情况之一的，启动三级应急响应程序：

⑴无毒赤潮面积200平方公里及以上；

⑵有毒赤潮灾害面积达到50平方公里及以上；

⑶出现因赤潮毒素导致的人身严重不适案例3人及以上；

⑷可能造成渔业直接经济损失2000万元以上。

4.2.2 应急处置

启动三级应急响应后，在采取四级响应措施基础上，还应采取以下措施：

⑴市局领导小组副组长赴现场督导赤潮灾害渔业应急处置，并将赤潮灾害情况及时上报市政府办公室和省局领导小组办公室；各成员单位抽调人员赴现场指导属地渔业行政主管部门开展工作，实行日报制度。

⑵沿海渔业行政主管部门加大赤潮灾害渔业水域样品采样范围，增加送样监测频率，样品报送频率不少于每日1批次。

⑶监测单位加密开展应急跟踪监测，加强对赤潮区域及邻近海域的水产品质量安全检测，监测信息报送频率不少于每日1次。

4.3 二级应急响应

4.3.1 启动条件

在我市管辖的近岸海域发生的赤潮灾害，出现下列情况之一的，启动二级应急响应程序：

⑴无毒赤潮面积达到500平方公里及以上；

⑵有毒赤潮灾害面积达到200平方公里及以上；

⑶出现因赤潮毒素导致的人身严重不适案例10个及以上或出现3人以下人身死亡案例；

⑷可能造成1亿元以上渔业直接经济损失。

4.3.2 应急处置

启动二级应急响应后，在采取三级响应措施基础上，还应采取以下措施：

⑴市局领导小组组长赴现场督导赤潮灾害渔业应急处置，并将赤潮灾害情况及时上报市政府办公室和省局领导小组办公室。

⑵市局领导小组及时申请省级应急资源支持。

4.4 一级应急响应

4.4.1 启动条件

在我市管辖的近岸海域发生的赤潮灾害，出现下列情况之一的，启动一级应急响应程序：

⑴无毒赤潮面积达到1500平方公里及以上；

⑵有毒赤潮灾害面积达到500平方公里及以上；

⑶出现因赤潮毒素导致的人身严重不适案例50个及以上或出现3人及以上人身死亡案例；

⑷可能造成5亿元以上渔业直接经济损失。

4.4.2 应急处置

启动一级应急响应后，在采取二级响应措施基础上，还应采取以下措施：

⑴市局领导小组立即向市政府和省局领导小组上报赤潮灾害情况。

⑵根据需要，市局领导小组可会同有关部门成立联合指导组，指导赤潮发生影响地开展工作，确保实现对赤潮发展动态的有效监控，最大限度减低赤潮对渔业带来的损失。

4.5 应急响应调整与终止

4.5.1 应急响应调整

市局领导小组根据赤潮灾害发生情况、发展趋势及危害影响程度的变化情况,在达到上调或下调应急响应级别条件时，应适时决定调整应急响应级别。上调响应级别时可越级调整，但下调响应级别时应逐级调整。

在造成渔业直接经济损失不再增加的前提下，满足以下条件时，可下调应急响应级别。

⑴在启动一级应急响应期间，若无毒赤潮面积降到1500平方公里以下、有毒赤潮灾害面积降到500平方公里以下，且未出现因赤潮毒素导致的人身死亡案例和造成的直接经济损失不再增加的情况下，可降为二级应急响应；若出现因赤潮毒素导致的人身死亡或人身严重不适案例，在连续3天无新增病例或连续两周贝毒未检出的情况下，可降为二级应急响应。

⑵在启动二级应急响应期间，若无毒赤潮面积降到1000平方公里以下、有毒赤潮灾害面积降到200平方公里以下，且未出现因赤潮毒素导致的人身死亡案例和造成的直接经济损失不再增加的情况下，可降为三级应急响应；若出现因赤潮毒素导致的人身死亡或人身严重不适案例，在连续3天无新增病例或连续两周贝毒未检出的情况下，可降为三级应急响应。

⑶在启动三级应急响应期间，若无毒赤潮面积降到500平方公里以下、有毒赤潮灾害面积降到50平方公里以下，且造成的直接经济损失不再增加的情况下，可降为四级应急响应；若出现因赤潮毒素导致的人身死亡或人身严重不适案例后，在连续3天无新增病例或连续两周贝毒未检出的情况下，可降为四级应急响应。

4.5.2 应急响应终止

当赤潮消亡时，市局领导小组办公室应及时建议终止应急响应。

有毒赤潮的应急响应终止后，局渔业产业科根据水产品中赤潮毒素情况继续做好水产品质量安全监管工作。

5. 信息管理与发布

5.1 信息传输

    ⑴按照逐级上报原则，在赤潮灾害渔业应急处置期间，属地县区（管委会）渔业行政主管部门应及时向市局领导小组办公室报告赤潮灾害信息，再由市局领导小组向市委市政府、省海洋与渔业局报告。 

　　⑵赤潮灾害期间，达到一级和二级应急响应级别时，赤潮灾害信息上报频率为每日1次；达到三级和四级应急响应级别时，赤潮灾害信息可适当降低上报频次。

    5.2 信息发布 

影响渔业的赤潮灾害信息由省海洋与渔业局统一归口管理。达到赤潮灾害一至四级应急响应条件时，影响渔业的赤潮灾害信息由省局领导小组办公室通过广播、电视、报刊、网络、电信、短信或彩信等媒体向社会发布。未达到四级应急响应条件的赤潮灾害信息由市海洋与渔业局向社会发布。

    6. 后期处理

    6.1 灾后处置 

    对遭受赤潮灾害严重影响的地区，市、县区（管委会）渔业行政主管部门适时派出工作组指导当地群众做好恢复生产等灾后工作。局办公室负责申请省、市级防灾抗灾救灾工作经费和救助资金。 

　　6.2 灾害评估 

对渔业造成直接经济损失的赤潮灾害，属地县区（管委会）渔业行政主管部门应及时组织开展赤潮灾后渔业经济损失评估工作；市水产科学研究所指导和协助做好全市的赤潮灾后渔业经济损失评估工作；局渔业产业科负责指导收集、整理全市赤潮灾害对渔业造成的直接经济损失；局防灾减灾科负责汇总统计全市渔业生产受灾情况。

6.3 奖励与责任 

　　⑴对应急行动中成绩突出的单位和人员给予适当奖励；对于玩忽职守、推诿扯皮，造成严重后果与不良影响的单位和个人给予处分。 

　　⑵根据实际情况，对发现重大赤潮并及时报告的单位和个人应予一定的奖励。 

　　⑶有毒赤潮灾害发生后，赤潮灾害海域内的渔业生产者及相关的企事业有义务配合应急响应行动。 

　　⑷对偷运、偷卖禁止上市的水产品造成群众中毒伤亡的有关责任人，移交有关部门依法追究刑事责任。 

　　6.4 资料归档 

　　赤潮灾害渔业应急处置工作资料统一由市局领导小组办公室保存。 

    7. 保障措施

    7.1 组织保障 

　　各级渔业行政主管部门应加强对赤潮灾害渔业应急工作的组织和领导，建立健全赤潮灾害渔业应急工作体系，强化与各级人民政府及有关部门的沟通和协调，在组织机构和人员编制方面保障应急工作的正常开展。 

　　7.2 能力建设 

　　各级渔业行政主管部门要进一步加强监测、预警报工作能力建设，使各地渔业技术单位配备必要的设备设施，具备开展赤潮生物种类鉴定、赤潮毒素检测和水质分析等赤潮应急基本工作能力，保障赤潮灾害的渔业应急监测工作。 

　　7.3 经费保障 

　　赤潮趋势性及频发期监测、赤潮防治的研究以及赤潮发生的经验性预警报等经费按分级负担的原则，纳入各级渔业行政主管部门年度预算。赤潮灾害渔业应急响应行动所需经费，以及渔业应急行动中成绩突出的单位和人员的奖金，按属地管理原则由所在地市、县区（管委会）财政做好经费保障工作。 

7.4 技术保障 

　　各级渔业行政主管部门应建立赤潮灾害专家咨询机制，为各项赤潮灾害渔业应急工作提供技术支撑。依托渔业环境监测、预报机构和科研院所，积极组织开展赤潮灾害监视监测、预警预测和应急处置技术研究，切实提高应急能力。 

　　各级渔业行政主管部门应加强渔业应急管理及专业技术培训，有计划地组织举行赤潮灾害渔业应急演习，锻炼队伍、完善预案，切实提高防范和处置赤潮灾害的实战能力。 

　　7.5 宣传教育 

各级渔业行政主管部门充分利用广播、电视、互联网、报纸等新闻媒体，加大对赤潮灾害渔业应急工作的宣传力度，提高社会各界对赤潮灾害的认识，形成全社会关心、支持赤潮防灾减灾工作的氛围，为应急工作奠定良好的社会基础。

8. 附则

    8.1 预案实施

本预案由市海洋与渔业局负责解释和组织实施。

本预案自发布之日起实施。

    8.2 名词术语

    ⑴赤潮是指海洋中某些浮游生物、原生动物或细菌在一定的环境条件下暴发性增殖或聚集，引起水体变色或对海洋中其它生物产生危害的一种生态异常现象。

    ⑵赤潮生物是指能够大量繁殖并引发赤潮的的生物。赤潮生物包括浮游生物、原生动物和细菌等，其中有毒、有害赤潮生物以甲藻类居多，其次为硅藻、蓝藻、金藻、隐藻和原生动物。

    ⑶赤潮毒素是指由有毒赤潮生物产生的具有毒副作用的天然有机化合物。主要包括麻痹性贝毒素（PSP）、腹泻性贝毒素（DSP）、神经性贝毒素（NSP）、失忆性贝毒素（ASP）和溶血性毒素等。

⑷有毒赤潮是指体内含有某种赤潮毒素或能分泌出毒素的藻类形成的赤潮。
