莆田市海洋与渔业局关于做好2021年全国防灾减灾日有关工作的通知

发布时间：2021-04-21 16:36
| | |

各县（区、管委会）海洋与渔业行政主管部门,局机关各科室、局直属各单位：

今年5月12日是我国第13个“防灾减灾日”，其主题是“防范化解灾害风险，筑牢安全发展基础”，5月8日至14日为防灾减灾宣传周。为做好今年“防灾减灾日”海洋与渔业防灾减灾的各项宣传活动，根据省、市减灾委的工作部署要求，结合行业实际，我局制定了《2021年莆田市海洋与渔业防灾减灾日宣传活动方案》（详见附件）。请你们根据活动方案，认真做好今年防灾减灾宣传周的各项工作，并于5月27日前将宣传活动开展情况报我局防灾减灾科。

附件1

2021年莆田市海洋与渔业防灾减灾日

宣传活动方案

 

为做好今年第13个“防灾减灾日”宣教工作，多渠道宣传各类海洋与渔业灾害的严重危害，广泛普及各类海洋与渔业灾害防御知识和技能，切实提高广大人民群众的海洋与渔业防灾减灾意识和能力。结合我市海洋与渔业防灾减灾实际，制定本活动方案。

一、活动时间

2021年5月8日至14日为防灾减灾宣传周。5月12日为“防灾减灾日”。

二、活动主题

“防范化解灾害风险，筑牢安全发展基础”。

三、活动内容及具体要求

（一）开展海洋与渔业防灾专题宣教活动。各级海洋与渔业行政主管部门要结合海洋灾害风险普查工作，拓展社会面宣传渠道，开展赤潮灾害防范、渔业防台风安全等防灾专题宣传“五进”暨海洋灾害普查宣传培训活动，以社区、学校、渔区、渔港等为重点，通过现场咨询、渔民培训、入户宣传等形式，面向社会公众和渔民普及海洋与渔业灾害基础知识、防灾减灾科普知识和防灾减灾基本技能。同时，充分发挥广播、电视、报刊等传统媒体和微博、微信、手机短信、LED屏等新兴媒体作用，创新防灾减灾宣传活动形式，提高宣传教育实施效果。

（二）组织开展“防灾减灾日”主题宣传活动。宣传周期内，各县（区、管委会）海洋与渔业行政主管部门要充分结合境外疫情输入海上、伏季休渔监管和赤潮防范工作，在渔区、渔港设置宣传现场，通过张贴海报、放置展板，发放宣传材料等形式，进行宣传咨询和广播等，掀起海洋与渔业防灾减灾宣传活动的高潮，推进防灾减灾知识进村入港上船宣传活动的深入开展。

（三）开展海洋灾害风险普查和隐患排查整治。各县（区、管委会）海洋与渔业行政主管部门要组织做好第一次海洋灾害风险普查，聚焦渔船渔港、海水养殖区、海岸防护工程和滨海旅游区的风险隐患排查，摸清全市海洋灾害风险隐患底数和抗灾能力，客观认识海洋灾害综合风险水平，教育引导社会各界特别是社会公众提高灾害风险防范意识。要严格落实自然灾害风险隐患信息报送制度，落实各级信息报送责任人。要针对海洋灾害监测预警、抢险救援、应急处置和保障等重点环节，加强应急物资准备，对照本辖区、海洋灾害特点和相关应急预案，积极组织开展灾害隐患排查整治和防灾减灾应急演练活动，提升本辖区海洋与渔业灾害应急预案的针对性和有效性，进一步规范各类灾害应对处置程序，确保责任明确到人，落实到位。

四、工作总结

防灾减灾宣传周活动结束后，各县（区、管委会）海洋与渔业行政主管部门要做好活动总结，于5月27日前将书面总结材料、《全国防灾减灾日活动情况统计表》及相关活动图片和资料报送市局防灾减灾科。
