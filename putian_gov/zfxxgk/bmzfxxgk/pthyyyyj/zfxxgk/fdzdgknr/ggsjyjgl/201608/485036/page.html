莆田市海洋与渔业局关于印发莆田市2016年渔业船舶水上突发事件应急演练工作方案的通知

发布时间：2016-08-26 17:27
| | |

各县（区、管委会）渔业行政主管部门，市海洋与渔业执法支队、局各相关科室：

    为深入推进渔业安全生产应急管理工作，强化渔区渔民安全生产意识和海上自救互救能力，进一步提高应对海上突发事件的组织协调能力、快速响应能力和应急处置能力，营造和谐稳定的渔区氛围，根据《福建省海洋与渔业厅关于印发福建省防范和遏制重特大渔业船舶水上安全事故工作实施方案的通知》（闽海渔〔2016〕167号）关于应急演练制度的要求，我局制定了《莆田市2016年渔业船舶水上突发事件应急演练工作方案》，现印发给你们。请按照演练预设内容，结合各自的预案情况，科学安排、精密组织实施渔业船舶水上突发事件各项应急演练工作，切实完成本年度的演练任务。                        

                             

 

                           莆田市海洋与渔业局

                           2016年8月26日

 

莆田市2016年渔业船舶水上突发事件

应急演练工作方案

 

根据《福建省海洋与渔业厅关于印发福建省防范和遏制重特大渔业船舶水上安全事故工作实施方案的通知》（闽海渔〔2016〕167号）精神，为切实做好莆田市2016年渔业船舶水上突发事件应急演练工作，特制定本方案。

一、演练目的

根据《福建省海洋与渔业厅关于印发福建省防范和遏制重特大渔业船舶水上安全事故工作实施方案的通知》（闽海渔〔2016〕167号）要求，政府专项和部门应急预案每3年至少演练一次；水上抢险救助等专项预案每年至少演练一次，现场处置方案应经常性开展演练。通过预案演练和应急处置演习，切实提升各级应急指挥职能部门及从业人员的响应速度和应急能力，提高现场作业人员的应急技能。

  二、组织部署

 为确保2016年全市渔业船舶水上突发事件应急演练工作有序开展，市局成立应急演练工作领导小组（指挥部），组长（总指挥）由市局分管领导担任，副组长（现场总指挥）由市支队支队长及各县区（管委会）渔业行政主管部门分管领导或渔业执法机构负责人担任，成员由市局安委会成员单位及各县区渔业执法机构负责人员组成。领导小组负责本年度演练的组织、协调、指挥工作。

    各县区要根据当地实际情况，充分结合渔业船舶职务船员和普通船员培训考试合理安排演练计划，根据海洋与渔业应急预案和本方案的要求，确定参加演习人员，设定应急演练现场，制定具体工作方案并上报市局演练领导小组。各县区可根据本方案自选演练科目，原则上各县区每年应组织渔业安全应急演练不少于一次，参加市局联动演练不少于一次。

三、演练内容

演练内容应围绕渔业船舶水上遇险突发事件应急救援演练和渔船船员自救互救实际操作演练两方面开展。具体科目包括包括海上急救、船舶消防灭火、海上求生和救生筏操纵以及部门应急处置四个方面。

1.海上急救：模拟船员操纵机械时受伤进行包扎；模拟船员溺水进行人工急救。

2.船舶消防灭火：模拟船舶失火，船长组织船员扑救灭火。

3.海上求生与救生筏操纵演练：模拟船舶触礁沉没，船员弃船逃生。船长组织船员施放求救信号，释放救生筏，船员穿着救生衣跳水攀上救生筏逃生。

4.应急指挥职能部门响应。各级应急单位进行响应和应急处置各环节的实际操作。

四、参加演练单位及其分工

参加演练单位：市海洋与渔业局安办、应急指挥中心、市海洋与渔业执法支队，各县（区、管委会）渔业行政主管部门及其渔业执法机构，应急演练所在地乡镇政府，船员培训机构。

市海洋与渔业局及执法支队负责市县（区）联动演练方案的制定与指挥工作；各县（区、管委会）渔业行政主管部门及其渔业执法机构负责本级演练具体方案的制定，参与演练船只组织与一键报警手机、救生设备、消防设备、烟火信号等求生设备的准备落实与演练海区的清场等工作。

实操演练所用的求生、救生、急救、消防器材可由船员培训机构提供。

五、实操演练项目基本流程

（一）海上急救

1.模拟船员受外伤进行三角巾包扎。

2.模拟船员溺水被救上后进行人工呼吸和胸外按压。

    3.现场人员向现场总指挥报告，人员成功获救，海上急救科目演练结束。

（二）船舶消防灭火

1.模拟3个火盆点燃柴油后灭火。

2.现场人员向现场总指挥报告，渔船大火扑灭，火险解除，船舶消防灭火科目演练结束。

（三）海上求生与救生筏操纵

1.参演A渔船模拟触礁事故，船舱大量进水，船长决定弃船，船长向同编队的B渔船呼救、施放声号（三长声），指挥3名船员分别施放红光火焰信号和橙色烟雾信号、释放救生筏，抛下救生圈，组织船员跳水攀上救生筏。

2.4名船员穿着救生衣从船舷跳水游泳到放开救生筏旁，攀爬上救生筏。

3.模拟救助船同编队生产的B渔船接到A渔船险情求救后立即赶到参与救助，释放救生筏救助落水人员。

4.在成功救起落水人员和完成伤员转移后，海上人员搜救行动结束。现场人员向现场总指挥报告，落水人员全部获救，险情排除。

（四）部门应急响应处置流程按相关预案要求制定。

    六、相关要求

（一）加强领导，落实责任

    渔业船舶水上突发事件应急演练工作是落实水上突发事件应急预案一项重要举措。各地各单位要按照落实安全生产主体责任和监管职责的要求，将应急演练作为加强海洋与渔业安全生产的一项基础性工作，并纳入安全生产目标责任制考核内容抓紧抓实，切实加强对水上突发事件应急演练的组织领导，有效落实本辖区、本单位的应急演练工作，切实提高海洋与渔业安全事故和突发事件的应急处置能力。

    （二）突出重点，应急先行

    各地各单位要结合实际、把握特色、突出重点，把应急演练作为一项长期艰巨的任务常抓不懈，进一步熟悉、掌握、运用应急救援知识、救助程序、救援方法，完善应急救援体系和应急预案，确保预案的可行性、紧密性和可靠性。同时要加强应急救援工作的宣传、培训和教育工作力度，定期对渔民进行安全知识、操作规程、应急救援知识和防灾自救知识的宣传和教育，提高渔民应急救援水平，随时做好应急处理突发安全事故的准备工作，

    （三）精心策划，严密组织

    市局安办、防灾减灾办和执法支队要围绕演练目的，精心策划，搞好协调和指导，保障各项演练工作按计划实施。各县（区、管委会）渔业行政主管部门及其渔业执法机构要按照演练预设内容，结合渔船民各项宣传培训工作，精心安排演练计划，按有关要求（见附表）于9月5日前将组织和计划开展水上突发事件应急演练活动情况报送市局防灾减灾办，同时应科学设计演练方案，周密组织演练活动，制订并严格遵守有关安全措施，确保演练参与人员及演练装备设施的安全。演习结束后两天内将相关演示总结和视频图片材料上报市局防灾减灾办。
