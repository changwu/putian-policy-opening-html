莆田市海洋与渔业局关于进一步做好渔船应急救助终端设备管理的通知

发布时间：2017-08-18 17:27
| | |

各县区（管委会）海洋与渔业行政主管部门、市海洋与渔业执法支队：

　　近年来，我市通过各级财政预算补贴，为全市渔船安装配备船舶自动识别（AIS）终端、北斗卫星定位通信终端、CDMA定位手机等渔船安全救助信息系统终端设备（以下简称终端设备）。这些终端设备在渔船避碰、海上信息传递、海上抢险救助、追踪肇事船舶等方面发挥了重要作用。但目前仍存在终端设备使用不规范，开机定位率低等问题，为进一步规范终端设备管理，保障我市各级海上渔业安全应急指挥系统的正常运行，充分发挥终端设备作用，根据《福建省渔业船舶安全生产管理办法》、《福建省海上渔业安全应急指挥系统管理办法》、《福建省海洋与渔业厅关于进一步加强渔业船舶非法违规生产处置的意见》等有关规定, 现就有关事项通知如下：

　　一、明确管理职责，加强终端设备管理

　  市渔业行政主管部门负责辖区渔船终端设备的统一管理和监督检查，复核终端设备过户、变更备案资料，定期通报终端使用开机情况；各县（区）渔业行政主管部门负责监督辖区渔船终端设备的安装、调试以及办理入网注册、信息变更和注销手续等工作，及时向市局报送变更备案资料，落实市局定期通报未开机情况的核实处理工作，确保渔船按规定安装和正常使用终端设备。

　　各级渔业行政主管部门应当安排专门机构和人员，加强对渔船终端设备使用的日常管理，重点做好以下工作： (1)加强终端设备的使用操作培训，确保每艘渔船至少有1人熟练操作终端设备。 (2)实时监控辖区安装终端设备渔船的动态，严格按照接警处置流程处理各类信息终端的报警信息。 (3)每周检查渔船终端设备的开机情况，并对未开机渔船通过通报、电话、短信等提醒方式，逐一核实处理。 (4)建立渔船终端设备档案，做好终端设备数据资料登记管理工作。随时报送渔船资料变更情况，及时更新终端设备信息系统数据信息。

　　

　　

　　

　 

    二、严格管理程序，规范终端设备入网、过户、注销工作

　　由于渔船进行买卖、拆解等行政受理时有些地方没有及时对终端设备数据进行更新，终端设备与渔船配对出现错位，导致海上渔业安全应急指挥系统平台定位到的渔船位置信息与实际不符，甚至出现已拆解注销渔船的终端设备仍在其他船舶上使用，降低了对渔船的监管和救助的效果。各县区（管委会）海洋与渔业行政主管部门要高度重视，要设置专人岗位，在办理渔船过户、新增、报废过程时，要同步办理终端设备的数据变更，要及时将渔船终端设备、船东船长变更的信息录入渔船数据管理平台，并将相关资料报送市局应急指挥中心备案复核（可通过传真方式），确保信息准确有效。

　　三、强化管理措施，确保渔船按规定配备和使用终端设备

　　(1)加大查处力度。各级渔业行政主管部门及其所属执法机构要依法将渔船终端设备等配备安装和使用情况纳入渔港监督和渔船检验的监管范围。对于未按规定配齐渔船终端等设备的，按照相关法律法规及渔船检验法定标准和规则等规定，依法不予签发船舶检验证书。执法检查时应将渔船终端等配备和使用情况作为重要检查监管内容；对不符合规定的，依法予以查处。

　　(2)完善查验工作。各县区渔业行政主管部门及其所属执法机构要定期组织对各乡镇渔船开展终端设备的现场查验工作，可参照湄洲岛管委会今年的做法，结合年度渔船检验工作，对渔船使用终端设备进行全面普查、现场登记核验，取得渔船及其终端设备第一手数据，并按照各自数据管理权限，对海上渔业安全应急指挥系统后台数据库进行核对清理，确保渔船终端数据真实性和有效性，督促终端设备的正常使用和定位。

　　(3)建立通报机制。市局指挥中心将定期对各县区渔船北斗终端使用定位情况进行汇总统计，并向各县区渔业行政主管部门进行通报，各县区渔业行政主管部门要组织对通报情况进行核查处理，建立渔船终端使用与油补发放挂钩机制，对未开启使用终端设备的渔船要按规定予以严肃处理，并将核实处理落实情况反馈市局，市局将把各县区通报核实处理落实情况列入当年度渔业安全生产目标责任制考评内容，促进渔船终端设备使用规范化管理。
