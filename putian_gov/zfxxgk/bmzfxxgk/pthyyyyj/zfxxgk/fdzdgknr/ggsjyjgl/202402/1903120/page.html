莆田市海洋与渔业局关于印发《2024年全市近岸海域赤潮灾害渔业应对工作要点》的通知

发布时间：2024-02-06 15:39
| | |
 各县（区、管委会）渔业行政主管部门，局赤潮灾害渔业应急工作领导小组成员单位：

        为加强赤潮灾害渔业防范应对工作，做到早宣传、早监测、早发现、早预防，最大限度减少赤潮灾害造成的损失，根据《福建省海洋与渔业局关于印发2024年全省近岸海域赤潮灾害渔业应对工作要点的通知》（闽海渔电〔2024〕01号）精神，我局制定了《2024年全市近岸海域赤潮灾害渔业应对工作要点》，请结合工作实际认真贯彻落实，并于2024年2月7日前将赤潮灾害渔业应急工作负责人名单（附件2）报市局防灾减灾科。

　　联系人：余志明      传真：0594-2380619

　　邮箱：ptfzjzb@163.com

　　                                                                                                                              莆田市海洋与渔业局

　　                                                                                                                                    2024年2月6日

　　2024年全市近岸海域赤潮灾害渔业应对

　　工作要点

　　一、健全基层观测监视队伍

　　各县（区、管委会）渔业行政主管部门根据辖区海域管理需要，继续动员组织渔民、养殖户、基层水技人员、环保志愿者等加入赤潮基层观测监视队伍，加强重点养殖海域赤潮观测监视和灾情信息报送工作。

　　赤潮高发期实行“零报告”制度，3月15日至6月30日，基层观测监视人员每日上报所负责片区的观测监视结果，各县（区、管委会）渔业行政主管部门每日17：00前将辖区观测结果报送至市局防灾减灾科，市局汇总后报送至省渔业资源监测中心。

　　二、增强赤潮灾害发生条件预测能力

　　市海洋与渔业环境监测站要加强能力建设，及时掌握所在海域水温、盐度、浊度、叶绿素、pH、溶解氧等要素的变化，为赤潮灾害防御提供数据支持，为养殖户应急救灾争取时间。

　　三、加强常规监测

　　市海洋与渔业环境监测站编制年度赤潮常规监测工作方案，对重点养殖监控区开展赤潮常规监测。4月至6月在南日岛养殖区每周监测2次，并及时上报数据。

　　四、强化应急监测

　　赤潮灾害发生后，各县（区、管委会）渔业行政主管部门立即开展全过程跟踪监视监测，监测频率为每1-2天监测1次，市海洋与渔业环境监测站负责提供技术支持，并将检测结果报送市局和省渔业资源监测中心。市局在第一时间向省局报告灾情，编制《赤潮灾害信息报告》（附件1），加盖印章后传真至省渔业减灾中心。后续视情接续报送本地区赤潮灾害进展、消亡情况及应对措施等相关信息和材料。

　　五、规范信息发布，保障信息畅通

　　《赤潮监测预警信息》由市海洋与渔业环境监测站负责汇总浮标信息和人工监测信息制作。

　　《赤潮灾害信息》由渔业行政主管部门发布。按照《福建省近岸海域赤潮灾害渔业应急预案》要求，达到三级及以上应急响应级别的，由省渔业资源监测中心编制，经省局审核后，在省海洋与渔业局门户网站上发布；未达到三级应急响应级别的，由市海洋与渔业局负责发布，并报省海洋与渔业局。

　　充分发挥各级水产技术推广机构作用，运用《赤潮监测预警信息》《赤潮发生条件预测信息》《赤潮灾害信息》等信息，规范发布预警信息，扩大预警信息覆盖面。市水产技术推广站要以现有微信公众号、养殖户信息交流群、手机短信平台等为基础，将重点养殖企业纳入其中，完善信息发布机制，及时将赤潮灾害预测预警信息发送到渔民、养殖户手中。

　　六、加强宣传培训和舆情应对

　　各县（区、管委会）渔业行政主管部门要借助新媒体、融媒体传播优势，结合“5·12”“世界海洋日”“国际减灾日”等活动为契机，开展多形式、多角度的赤潮科普宣传，提高公众赤潮灾害防范意识。根据《赤潮灾害渔业应急预案》组织开展应急演练，规范工作流程，强化关键节点，提高应急处置能力。

　　市海洋与渔业环境监测、市水产技术推广站和省渔业互保协会莆田市办事处要适时组织相关单位开展重点养殖区赤潮灾害防范技术培训，重点向渔民、养殖户宣传赤潮成因、发生现象、应急处置等知识，提高渔民赤潮灾害危机应对意识和应急处置技能，最大限度降低赤潮灾害引起的健康损害和经济损失。

　　赤潮发生期间，要密切关注赤潮动态，研判舆情趋势，利用权威机构鉴定、专家解读等形式，及时回应社会关切，保障养殖户、社会公众合法权益。

　　七、做好灾后损失评估和恢复生产工作

　　赤潮消亡后，受灾地区的各县（区、管委会）渔业行政主管部门应组织技术人员深入一线，指导渔民做好赤潮灾后自救和恢复生产工作；开展赤潮灾害渔业经济损失统计与评估，结果报送市局防灾减灾科。

　　八、扩大赤潮指数保险覆盖面

　　省渔业互保协会莆田市办事处要紧密结合养殖户的实际需求，进一步优化海水养殖赤潮指数保险试点方案，在去年试点的基础上，根据各地申请，扩大试点覆盖区域，增加保险保费规模，提高保险保障能力。

　　各县（区、管委会）渔业行政主管部门、监测机构、水技推广站要协助加强宣传引导，全力支持海水养殖赤潮指数保险业务开展，尽可能减轻灾害风险。

　　九、加强科技支撑保障

　　各级渔业行政主管部门要鼓励和支持技术支撑单位借智借力，充分发挥高等院校、科研单位等各类科研平台作用，持续开展赤潮机理、监测预警、生态养殖、减灾防控等研究，加大赤潮监测与防控技术推广力度。要依托国债项目建设，提升赤潮灾害监测预警能力。
