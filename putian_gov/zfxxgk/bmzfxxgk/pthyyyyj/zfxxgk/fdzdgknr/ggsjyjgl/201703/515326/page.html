莆田市海洋与渔业局关于印发莆田市2017年渔业安全生产工作计划的通知

发布时间：2017-03-06 12:01
| | |

各县（区、管委会）海洋与渔业行政主管部门，局安委会成员单位:

现将《莆田市2017年渔业安全生产工作计划》印发给你们，请按照职责分工，明确工作任务，制定工作计划，强化工作落实，推动全市渔业安全生产形势持续稳定向好。请各县（区、管委会）海洋与渔业行政主管部门、后海围垦管理局于3月15日前将本单位2017年渔业安全生产工作计划报送市海洋与渔业局安办。

 

 

                       莆田市海洋与渔业局

                         2017年3月6日

 

 

莆田市2017年渔业安全生产工作计划

 

为深入贯彻落实党中央、国务院、省、市党委政府有关安全生产工作的指示精神和2017年全国安全生产工作电视电话会议精神，进一步强化渔业安全生产工作，根据《中华人民共和国安全生产法》、《福建省安全生产条例》、《莆田市安全生产“党政同责、一岗双责”规定》等法规制度和《中共中央 国务院关于推进安全生产领域改革发展的意见》、《福建省海洋与渔业厅关于印发福建省2017年渔业安全生产工作计划的通知》等部署要求，结合我市渔业安全生产实际，制定本计划。

一、指导思想

深入贯彻落实十八届六中全会和习近平总书记、李克强总理有关安全生产工作的系列重要指示批示精神，按照全国、省、市安全生产电视电话会议和省委省政府、市委市政府以及省厅安全生产工作的重要决策部署，以为党的十九大胜利召开创造稳定的安全生产环境为首要任务，以贯彻落实中央关于推进安全生产领域改革发展工作部署为动力，以实施莆田市“十三五”渔业安全生产专项规划为主线，以防范和遏制重特大事故为重点，按照安全生产“一岗双责、党政同责、齐抓共管”的总体要求，继续推进渔业安全生产管理体系建设，着力全国“两会”“金砖会晤”“十九大”以及防汛抗台等重要、敏感时段，立足积极预防，强化标本兼治、综合治理和源头管控，认真落实渔业安全生产各项防措施，加强敏感海域渔船管控，全面提升安全保障、风险防控和应急处置能力，推动全市渔业安全生产形势持续稳定向好。

二、工作目标

按照“三个持续下降”总体目标要求，控制一般事故，遏制较大事故，杜绝重(特)大事故。力争渔业船舶生产安全事故死亡人数在“十二五”期间平均数以内，渔业船舶较大（以上）事故起数控制在市政府、省厅下达的年度安全生产目标责任指标内。

三、工作内容

（一）强化渔业安全生产责任落实。通报2016年度渔业安全生产目标责任考评情况；分解下达2017年渔业安全生产目标责任任务；适时开展渔业安全生产目标责任落实情况半年督查与年度考评，控制好事故考核指标，推进落实渔业安全生产重点工作，配合市政府安办做好省政府对我市的安全生产考核工作；认真贯彻落实市政府安全生产“党政同责、一岗双责”规定和工作机制，健全完善渔业生产责任体系，按照安全生产“三个必须”和“谁主管谁负责”的要求，明晰权力清单、责任清单，与各县（区、管委会）海洋与渔业安全生产第一责任人签订渔业安全生产目标责任状，加强对渔业安全生产“一岗双责”责任落实情况的跟踪、督查，严格落实责任倒查和失职追责，全面落实安全生产监督管理责任。

（二）强化渔业安全生产隐患排查整治。按照强化渔业风险管控、突出重点、从严执法、排查隐患、强化治本的工作要求，持续开展“打非治违”等专项行动，严厉打击涉渔“三无”船舶和各类违法违规渔业生产经营行为，维护水上安全生产秩序；继续深化隐患排查治理工作，全面深入排查、治理渔船安全隐患，推动渔业船舶和渔业企业建立健全事故隐患自查、自报、自改的闭环管理机制；加强汛期、台风期间重点地区、重要时段和敏感时期的渔业安全生产工作督导、检查，认真细致地排查、治理渔船、渔港和渔排安全隐患；加大重特大事故隐患整改督促力度，严格落实整改措施、责任、资金、时限、预案“五到位”工作要求；深入推进“全国渔业安全生产大检查”，定期进行督促检查和通报，推动安全生产责任和各项工作的有效落实；进一步规范隐患排查治理月报统计和归口直报工作，拓展参与事故隐患排查治理统计渔业船舶（企业）覆盖面。

（三）强化渔业安全生产安全执法监管。推进海洋与渔业监管执法规范化建设，根据《福建省安全生产监督管理行政执法案卷管理办法》和《福建省安监系统监管执法工作规范》，规范安全监管执法程序和文书格式；市执法支队要制定2017年年度执法计划，并严格落实，加大安全生产监管执法力度；组织推动落实“双随机”抽查机制，完善“四不两直”执法检查方式；严格事故调查问责，建立事故调查组组长负责制，健全典型事故提级调查、跨地区协同调查和挂牌督办制度；所有事故调查报告要全文发布，做好解读，回应社会关切。

（四）强化渔业安全生产领域改革。认真贯彻落实《中共中央 国务院关于推进安全生产领域改革发展的意见》，积极探索改革创新途径，理顺工作体制机制，形成安全发展的强大内生动力。抓好《意见》的宣传贯彻，通过研讨交流、专家讲解、媒体宣传、集中报道等多种形式，组织全市海洋与渔业系统干部职工认真学习《意见》，统一思想、提高认识，不断增强安全、责任和法制意识；根据市政府和省厅工作部署，结合工作实际，制定具体实施方案，对有关改革制度措施和工作任务进一步细化分解，并明确工作任务、分工和责任人，推动安全生产领域改革发展工作落实。

（五）强化渔业安全生产重点工作落实。一是持续推进防范遏制重特大事故工作，认真贯彻落实国务院安办《标本兼治遏制重特大事故工作指南》，加快构建安全风险分级管控和隐患排查治理双重预防机制，扎实开展安全生产专项整治，通过不断排查和整治隐患问题，坚决遏制和有效防范重特大事故；二是落实渔业船舶和渔业企业全员岗位安全生产责任制，要督促渔业船舶和渔业企业经营者（或法人）根据各类岗位从业人员的岗位工作内容，建立健全覆盖所有管理和操作岗位的安全生产责任制，明确经营者（或法人）依法履行的安全生产职责和从业人员在安全生产方面所应承担的职责；三是全力配合市政府安办、省厅做好厦门金砖会晤水上安保工作，组织开展水上渔业安全生产大检查大排查大整治，按照安全管理“零距离”、隐患排查“零盲区”、安全隐患“零容忍”、责任落实“零缝隙”的要求，深查隐患、精准发力、强力整治，最大限度消除事故隐患；四是积极推进争创“全国平安渔业示范县”活动，协助各县（区、管委会）渔业行政主管部门开展创建平安渔业示范乡、村、船，筑牢渔业安全生产基层基础，构建渔业安全监管长效机制；五是推进渔业安全生产诚信体系建设，健全安全生产信用信息报送机制，实施安全生产不良信用“黑名单”制度，在政务网等媒体上公开曝光安全生产不良记录“黑名单”渔业船舶和渔业企业信息，推动渔业船舶、渔业企业建立安全生产承诺和安全生产诚信报告制度；六是配合省厅完善安全生产技术专家信息库建设，充分发挥专业人才的作用，丰富渔业安全生产监管手段，提升安全生产监管与应急救援能力。

（六）强化安全生产宣传教育培训。组织开展新修订的《福建省安全生产条例》的学习宣传贯彻和培训，不断提高安全生产法治意识；认真开展“5.12”防灾减灾日、“6.8”海洋日和“安全生产月”等活动，宣传普及安全知识。组织人员参加省厅举办的渔业安全生产和应急管理培训，提升安全生产管理人员依法行政、依法治安和应急处置能力；认真贯彻落实省委宣传部、省安监局等八部门《关于加强福建省全社会安全生产宣传教育工作的实施意见》。

（七）强化渔业安全生产安标化创建。进一步巩固渔业安全生产标准化建设提升工程三年行动的成果，积极引导渔业船舶和渔业企业建立以标准化为基础的自主管理，持续改进安全生产管理体系，规范渔业船舶和渔业企业安全管理基础台账，深入开展岗位达标、专业达标和企业达标，推进建设安全风险分级管控和隐患排查治理双重预防机制，推动落实渔业船舶和渔业企业安全风险自辨自控、事故隐患自查自治，从而全面提高渔业船舶和渔业企业自主安全管理水平，夯实渔业安全生产本质安全。

（八）强化渔业安全生产应急管理能力。进一步加强和规范渔业船舶水上事故调查处理工作，提高事故结案率和事故调查报告质量；组织开展水上安全应急救援演练，督促各县（区、管委会）海洋与渔业行政主管部门修订完善各类安全应急预案和开展安全应急救援演练活动，计划在重点渔区、县区和相关部门联合举办水上安全应急救助演练活动，提高渔业安全救助能力；继续推进应急管理标准化建设，积极配合省厅开发建设和使用海洋与渔业应急指挥决策支持系统，提升渔业应急处置能力和水平；推进落实小型渔业船舶手持安全应急终端升级改造。

（九）强化渔业安全生产信息报送工作。加强对渔业安全生产数据信息统计和报送工作的组织领导，明确任务、明确分工、明确时限，保质保量完成好信息数据报送工作。在每月月底前报送《渔业船舶执法行动情况月报表》、《渔业行业安全生产事故隐患排查治理情况月报表》，每月26日前报送《渔业船舶水上生产安全事故基本情况月报》。按时报送半年、年度、“安全生产月”活动、“打非治违”专项行动、安全生产标准化等等总结信息材料及本单位安全生产第一责任人履职报告，并根据市局有关工作部署适时报送相关信息材料。
