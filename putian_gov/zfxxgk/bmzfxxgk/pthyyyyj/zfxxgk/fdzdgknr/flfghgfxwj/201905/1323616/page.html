莆田市海洋与渔业局 莆田市财政局 关于印发《2019年莆田市渔业互助保险和水产养殖台风指数保险试点方案》的通知

发布时间：2019-05-20 16:10
| | |

 

各县（区、管委会）渔业行政主管部门、财政部门，全市渔业执法机构，各县（区、管委会）渔业互保机构：

为扎实推进我市渔业互助保险工作，有效化解渔业生产风险，按照《福建省海洋与渔业局 福建省财政厅关于做好2019年渔业互助保险工作的通知》（闽海渔〔2018〕199号）、《福建省海洋与渔业局 福建省财政厅关于印发2019年度福建省水产养殖台风指数保险试点方案的通知》（闽海渔〔2018〕190号）、《莆田市人民政府关于同意提高全市渔业互助保险财政补贴比例的批复》（莆政综〔2019〕31号）文件要求，结合我市实际，制定《2019年莆田市渔业互助保险和水产养殖台风指数保险试点方案》，现印发给你们，请认真组织实施。

 

 

 

 

      莆田市海洋与渔业局       莆田市财政局 

                             2019年5月8日

2019年莆田市渔业互助保险

和水产养殖台风指数保险试点方案

 

根据《福建省渔业互保协会雇主责任互助保险条款》《福建省渔业互保协会雇主责任附加补充责任互助保险条款》《福建省渔业互保协会雇主责任附加意外伤害医疗互助保险条款》《福建省渔业互保协会沿海内河渔业船舶互助保险条款》《福建省渔业互保协会渔民人身平安互助保险条款》《2019年福建省水产养殖台风指数保险试点方案》，结合我市实际制定本方案。

一、工作目标

年度内完成沿海渔工参保1822人、捕捞渔船参保135艘，保费任务719.13万元。各县（区、管委会）任务详见（闽海渔〔2018〕199号、闽海渔〔2018〕190号、闽互保〔2019〕33号）。

二、各级保费财政补贴政策

（一）沿海渔船渔工责任互助保险

1.雇主责任互助保险

各县（区、管委会）辖区内经检验合格的渔船上船东雇佣的渔工在25-100万元之间自选保额。

保费财政补贴政策：按每名渔工25万元保额核定，保费省级财政补贴30%，市、县两级财政各补贴5%，（有条件的县（区、管委会）可自行提高）。参保25万以上保额的按参保附加补充责任互助保险政策执行。

2.雇主责任附加补充责任互助保险

在60马力以上渔船工作的渔工须同船同保额参保，每名渔工可投保40万元以上的保额，最高100万元。

保费财政补贴政策：参加雇主责任附加补充责任互助保险的会员须按第一、第二档的顺序依次参保。省级财政不予补贴，市、县两级财政各补贴保费的5%，会员承担90%，有条件的县（区、管委会）可自行提高。

3.雇主责任附加意外伤害医疗互助保险

参加雇主责任互助保险的会员方可自愿参加雇主责任附加意外伤害医疗互助保险。

保费财政补贴政策：省级财政不予补贴，市、县两级财政各补贴保费的5%，会员承担90%，有条件的县（区、管委会）可自行提高。

（二）沿海渔船互助保险

1.沿海渔船互助保险主险（全损险和综合险）

各县（区、管委会）辖区内经检验合格的60马力以上渔船均可参保。

保费财政补贴政策：在估价60-80%参保的渔船，省级财政补贴30%;市、县两级财政各补贴5%（有条件的县（区、管委会）可自行提高，船东承担60%。对超过估价80%的部分不予财政补贴。

2.综合险作为主险下设3个附加险种：附加四分之一碰撞责任互助保险、附加船东对第三者人身伤亡责任互助保险、附加船舶碰撞事故不计免赔互助保险。

凡参保沿海渔船互助保险综合险的会员方可投保附加险。

保费财政补贴政策：省级财政不予补贴，市、县两级财政各补贴保费的5%，会员承担90%，有条件的县（区、管委会）可自行提高。

（三）渔民人身平安互助保险

各县（区）管委会辖区内的从事渔业生产或为渔业生产服务的单位或自然人均可参保。

保费财政补贴政策：省级财政补贴30%；市、县两级财政各补贴保费10%，会员承担50%，有条件的县（区、管委会）区可适当增加财政补贴比例。

（四）水产养殖互助保险试点

政府扶持政策：省级财政补贴30%，市、县两级财政各补贴保费的10%（有条件的县（区、管委会）可自行提高）。

（五）莆田地区水产养殖台风指数保险试点

保费财政补贴政策：市、县两级财政各补贴保费的20%， 2019年省级财政采取“以奖代补”方式，在市、县两级财政补贴之和不低于总保费30%的情况下，省级财政按总保费的20%奖励给市、县财政，即市、县两级财政实际补贴各为总保费的10%。

三、工作要求

（一）加强组织领导

政策性渔业互助保险是省级为民办实事工作，涉及广大渔民群众的切身利益，是推进渔业经济安定稳定发展的重要手段，渔业生产发展的社会保障体系措施之一。各单位要明确分管领导、渔业互保工作联络人员，加强与莆田市办事处的沟通交流，将渔业互助保险列入常态化管理工作，制定本辖区内渔业互助保险实施方案，确保渔业互保工作有序开展。

（二）加强协作宣传

各相关单位要落实渔业互助保险工作责任制，指定专人，切实做好宣传与承保工作。结合伏季休渔、防灾减灾宣传、渔业船舶检验、安全生产宣传、防范台风、暴雨等自然灾害、新互保政策出台等多途径宣传互助保险，多形式提高渔民对渔业互助保险的认知，增强渔民投保积极性。各渔业行政主管部门、执法部门、互保机构等相关部门应加强沟通联系，不定期通报本辖区渔业互保工作进展情况，对工作中存在困难与问题及时给予解决，以更好推进渔业互保工作。

各单位及各县（区）管委会财政部门可将保费补贴政策与其他惠农支农政策有机结合，有条件的县（区、管委会）可在省、市级的补贴标准基础上提高保费补贴比例，进一步减轻渔民缴费压力。

（三）强化风险防范

各级渔业互保机构接到渔民报案后，要及时向渔业行政主管部门、执法部门及省协会理赔部通报，加快抢险救灾速度，将损失降到最低。各渔业行政主管部门及其执法部门要结合渔业互保理赔案件，加强安全宣传，加强防灾减灾意识，引导渔民安全生产，防止重特大事故的发生，提升防控能力。市办事处要建立渔业互助保险理赔“绿色通道”，及时、准确、合理地做好理赔服务，加快渔民的灾后恢复生产能力。

（四）规范工作流程

各级财政部门应切实落实好保费财政补贴资金，并列入本级财政预算，及时予以拨付，为我市渔业生产风险提供保障。

各级保费财政补贴结算步骤：以县（区、管委会）为单位，由各级渔业互保机构每季度汇总一次辖区内财政补贴结算材料，并经同级渔业行政主管部门审核盖章确认后逐级上报省协会，一式三份，一份本单位留存作为本级财政补贴申报依据、一份交莆田市办事处汇总作为市级财政补贴申报依据、一份交省协会汇总作为省级财政补贴申报依据。

各单位申请保费财政补贴时，应先经各级渔业行政主管部门严格审查后，再向同级财政部门申请拨付。
