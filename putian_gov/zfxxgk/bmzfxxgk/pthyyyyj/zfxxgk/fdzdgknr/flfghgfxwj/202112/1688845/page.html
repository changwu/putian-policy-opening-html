莆田市财政局 莆田市海洋与渔业局关于下达2021年水产品质量安全检测样品费专项资金的通知

发布时间：2021-12-14 09:16
| | |

各有关县（区、管委会）财政局、海洋与渔业行政主管部门，莆田市后海围垦管理局：

根据《莆田市财政局关于批复2021年市本级一般公共财政支出预算调整的通知》（莆财农〔2021〕93号）及《福建省海洋与渔业局关于进一步加强水产品质量安全监测工作的通知》文件精神，经研究，现下达2021年水产品质量安全检测样品费专项资金9万元。水产品质量安全检测样品费资金专项用于水产品质量安全市级监督抽查和市级风险监测样品费，款列“2130199--其他农业农村支出”预算科目，请加强资金管理，确保专款专用，并按时完成绩效目标任务。
