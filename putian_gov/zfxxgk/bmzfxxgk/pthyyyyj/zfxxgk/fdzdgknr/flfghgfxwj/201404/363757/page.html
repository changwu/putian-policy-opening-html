莆田市海洋与渔业局 莆田市财政局关于做好2014年渔业互保工作的通知

发布时间：2014-04-15 08:00
| | |

　　各县区（管委会）海洋与渔业行政主管部门、渔业执法及互保机构，财政局：

　　2012年、2013年我市渔业互保工作得到各级政府、财政和渔业行政主管部门及执法机构的大力支持，取得了良好的成绩，全面完成省海洋与渔业厅、省财政厅、省渔业保险工作领导小组、省渔业互保协会下达的各项任务。为贯彻落实党的十八大精神，抓住国务院颁布《农业保险条例》的有利时机，进一步巩固我市渔业互保工作成果，确保参加互助保险的渔民受灾后依法得到及时补偿，根据省海洋与渔业厅和省财政厅联合下发的《关于做好2014年渔业互保工作的通知》（闽海渔[2013]457号）文件要求，各县区要认真按照通知要求，全面落实、规范运作、扎实推进渔业互保工作。现结合我市实际将有关事项通知如下：

　　一、提高认识，加强领导

　　各县区要进一步加强对渔业互保工作的组织领导，认真组织、周密部署、广泛动员，将渔业互保列入渔业安全生产的一项重要工作纳入常态化管理。做到领导到位、工作到位、政策到位、资金到位、措施到位，服务到位，积极有效作为，努力推动渔业互保事业扎实稳定向前发展。

　　二、深入发动，广泛宣传

　　各县区要结合本地实际和渔业互保工作的特点，深入开展宣传活动，动员渔船船东和渔民积极参加渔业互助保险；要多渠道、多层次、多角度广泛宣传渔业互保化解生产风险的作用，进一步增强渔区广大干部群众的风险防范意识和保险意识，提高渔民入会参保的积极性。

　　三、强化协作，落实责任

　　各单位要在当地党委政府的领导下，切实落实渔业互保工作责任制，把工作任务分解到乡镇、到村、到人，采取各种有效措施，切实把渔业互保工作落到实处，争取出台相关促进渔业互保

　　工作发展的配套措施，有条件的县（区）可将60马力以下渔船纳入互保范畴，同级财政将给予适当的保费补贴。

　　渔业行政主管部门、渔业乡镇、村要建立和完善联合推进渔业互保工作发展的机制，实现优势互补、信息共享、形成工作合力。渔业行政主管部门及执法和互保机构应结合伏季休渔、渔业许可管理、渔用燃油补贴发放、安全生产监督检查等渔业管理工作，不断创新工作方法，积极推进渔业互保工作，最大限度将应保对象纳入渔业互保范畴。

　　财政部门要将保费补贴政策与其他支农惠农政策有机结合，认真做好互保费补贴资金的落实、拨付、管理与监督工作。有条件的县（市、区）可在省定的补贴标准基础上提高互保费补贴比例，进一步减轻渔民缴费压力。

　　四、加强防灾，及时理赔

　　各级渔业行政主管部门及其执法机构要结合渔业互保工作，做好渔业安全生产知识普及和宣传工作，敦促渔民及时收听天气预报等安全信息，引导渔民配备安全设施，增强渔民自救互救的意识和能力，科学防范渔业生产风险。同时，要做好灾后救助工作，灾情发生后，各县区渔业行政主管部门及其执法机构要积极配合市办事处迅速做好定损勘验工作，及时公正确认事故责任；要建立跨区域联合处理渔业海损事故勘验机制，进一步方便渔民索赔，及时帮助渔民灾后恢复生产生活；市办事处要建立渔业互保理赔“绿色通道”，及时、准确、合理地做好理赔服务。

　　五、落实补贴，规范流程

　　各级财政部门应切实落实好互保费财政补贴资金，并列入本级财政预算。市级财政互保费补贴以市办事处为单位，由市（县、区）办事处（营业部）每季度汇总一次辖区内财政补贴结算材料，并经同级渔业行政主管部门审核盖章确认后逐级上报到市办事处。县区办事处（营业部）向同级渔业行政主管局和财政局申请互保费财政补贴时，由渔业行政主管部门严格审查后，再向同级财政部门申请拨付。由于新增渔船时间的不确定性，为确保保费收入任务全面完成，一年分为上半年度和下半年度财政补贴申请。结算前，由海洋与渔业局、财政局、渔保办（营业部）对各个渔业互保机构的申报材料进行会审，核实各地渔业互保数量；会审通过后拨付保费财政补贴。对不按规定投保、申报材料不完整的，财政不予补贴。

　　根据省海洋与渔业厅、省财政厅《关于做好2014年渔业互保工作的通知》（闽海渔[2013]457号）文件精神，结合我市财政实际情况，今年渔业互保保费市级财政补助为5%，县区财政补助为5%，并列入本级财政预算。各级渔业互保机构向财政部门申请省、市、县（区）保费补贴资金时，应提供以下材料：补贴申请报告、渔业行政主管部门确认的投保情况汇总表。福建省渔业互保协会应留存以下文件备查：渔业互保凭证、开具的保费收据复印及入会参保情况明细表。市海洋与渔业局、财政局将组织人员对各个机构渔业互保情况进行核查，一经发现弄虚作假、骗取财政补贴资金将按有关规定进行严肃处理。

　　莆田市海洋与渔业局           莆田市财政局

　　2014年4月15日

　　抄送：省海洋与渔业厅，省财政厅，市府办，省渔业互保协会。

　　  莆田市海洋与渔业局办公室              2014年4月15日印发
