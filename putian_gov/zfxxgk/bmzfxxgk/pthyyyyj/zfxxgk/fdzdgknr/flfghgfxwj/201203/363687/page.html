莆田市海洋与渔业局关于加强春季渔业安全生产工作的紧急通知

发布时间：2012-03-08 08:00
| | |

　　各县区渔业行政主管部门，市海洋与渔业执法支队：

　　2012年3月6日23点左右，一艘宁德市霞浦县的“闽霞渔运02376”渔船在泉州湾崇武以北小岞村附近海域（东经119°03′，北纬24°54′）沉没，8名船员落水。福建省、莆田市政府主要领导、分管领导高度重视和关注，经省海洋与渔业厅、莆田市海洋与渔业局及其执法机构和湄洲岛渔业部门等领导干部、湄洲岛等渔船紧张有序开展搜救工作，有3人获救（其中1人获救后抢救无效死亡，以上3人被送至湄洲岛），5人失踪中3人下落不明，均为宁德市霞浦县西洋乡人。目前我市还在全力协调渔船开展应急救援、搜救工作，并协助宁德市和霞浦县海洋与渔业部门做好被救船员和落水遇险、失踪船员家属的安置工作。搜救工作仍正进一步进行中。

　　根据市政府、市局领导要求和我市渔业安全生产实际，请各县区渔业行政主管部门、全市渔业执法机构举一反三，认真吸取事故教训，加强春季渔业安全生产工作，立即开展渔业安全生产大检查活动，进一步强化渔业船舶安全监管责任，落实各项安全防范措施，防止发生类似事故。同时，请一并贯彻落实在我市召开的全国渔业安全生产暨“平安渔业示范县”创建工作会议精神和闽海渔电[2012] 21、22号及莆安办明电[2012] 1号文件精神，努力维护我市渔业安全生产态势稳定的良好局面。现将有关事项通知如下：

　　一、提高认识，加强监管。各级渔业行政主管部门及其执法机构要针对我市春季渔业安全生产的形势，认真分析深层次原因，积极研究防范措施，切实落实渔业安全生产监管职责，充分发挥指导管理和监督检查作用。各县区渔业行政主管部门要从坚持以人为本、执政为民的高度，切实履行监管工作职责，层层落实渔业安全生产监管责任，并采取有效措施，督促渔业企业、渔业船舶落实主体责任，全力遏制渔业船舶事故发生。

　　二、加强执法，排查整治。各县区渔业行政主管部门、全市渔业执法机构要立即开展春季渔业安全生产大检查活动，进一步认真组织开展渔业安全隐患排查整治，要重点检查事故应急处置机制建设情况，渔船安全生产主体责任落实情况，渔船持证和通信、救生、消防、信号设备配备情况，防避碰装系统建设情况，进出渔港申请签证情况，船舶编队生产制度落实情况，船员配备及持证情况，对检查中发现的各类安全隐患，要跟踪落实整改，努力把事故消除在萌芽状态。同时，要加强海上巡逻检查，及时纠正渔船违法违规行为；要督促渔民严格按规定显示和使用雾灯、雾号，切实加强渔船雾中、夜间等能见度不良条件下航行作业和锚泊的值班瞭望。要根据《莆田市开展渔业船舶安全生产标准化建设活动实施方案》（莆海渔〔2011〕205号），全面推进我市44.1KW以上渔业船舶安全生产标准化建设，不断提高渔业船舶安全生产管理水平

　　三、强化宣传，提高能力。针对春季海上气候多变和雾多、浪大的特点，全市各级渔业行政主管部门及其执法机构要密切关注海洋气象动态，利用海上渔业安全应急指挥中心、渔船安全救助信息系统网络等渠道，及时将灾害性气象预警信息传递到渔区、渔业企业和渔民，以便及早做好防范，做到早防范不出事。要开展形式多样、富有成效的宣传活动，教育广大渔民吸取渔业事故教训，提高渔民的安全意识、安全技能和自救能力。各县（区、管委会）要进一步完善应急值班和通讯联络制度，及时掌握渔船生产动态，保证通讯联络通畅，确保能及时有效地组织海上搜救行动。同时，指导渔业企业、渔业船舶制定应急预案，适时开展培训和演练，提高渔民应对事故能力，提高船员的操作和应急处置能力，提高渔民安全意识和自我保护意识。

　　二○一二年三月八日
