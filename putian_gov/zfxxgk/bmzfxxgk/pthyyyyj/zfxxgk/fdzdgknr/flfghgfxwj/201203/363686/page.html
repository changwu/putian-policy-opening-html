莆田市海洋与渔业局关于印发《莆田市2012年海洋与渔业工作要点》的通知

发布时间：2012-03-06 08:00
| | |

　　各县区（管委会）海洋与渔业行政主管部门，局机关各科室、局直属各单位：

　　经研究，现将《莆田市2012年海洋与渔业工作要点》印发给你们，请认真组织实施。

　　二○一二年三月六日

　　

　　主题词：文秘工作  海洋  渔业  工作要点  通知

　　莆田市海洋与渔业局办公室      2012年3月6日印发

　　 

　　莆田市2012年海洋与渔业工作要点

　　 

　　2012年是实施“十二五”规划的重要年份，是我市海洋与渔业转型升级的关键时期。全市海洋与渔业系统要认真贯彻落实市第六次党代会和市委六届二次全会的决策部署以及全市经济工作、农村工作会议精神，紧紧围绕市委、市政府确定的“实现一二三一五，突破项目促跨越”目标任务，牢牢把握“稳中求进”的工作总基调，努力构建数字海洋、生态海洋、安全海洋、和谐海洋 ，持续推动全市海洋与渔业科学发展、跨越发展，为推进宜居港城建设提供项目用海服务保障和水产品生产供给保障，以优异成绩迎接党的十八大胜利召开。主要预期目标：全市海洋经济总产值比增20%，海洋经济增加值比增19%；水产品总产量72万吨，与去年持平；渔业总产值64.4亿元，比增8%。

　　一、把服务发展大局作为各项工作的头等大事

　　一是把思想和行动统一到市委、市政府的重大决策部署上来。全系统要紧密结合海洋与渔业工作实际，认真分析工作差距与潜力，深刻认识面临的形势和挑战，积极参与莆田城乡一体化综合改革试点工作，重点开展海域使用权属制度改革；加快推进科技创新型城市试点建设，重点实施科技兴海强渔战略，在新的起点上进一步解放思想，勇于探索，认真解决海洋与渔业发展的深层次矛盾和问题，努力促进科学跨越发展，推动宜居港城建设。二是进一步理清工作思路。海洋管理要在发挥市场配置资源的基础性作用、促进海洋资源有序有度开发以及强化管理和公共服务功能上下功夫，加快培育海洋战略新兴产业和海洋现代服务业。渔业开发要加快实现由资源渔业向设施渔业、由产量渔业向质量渔业、由速度渔业向效益渔业的“三大转变”，加快发展优质高效、外向、生态、安全的现代渔业。三是增强服务发展的主动性和创造性。积极向国家和省级争取围填海指标，优先保障涉海重点建设项目用海需求。充分运用福建新编省级海洋功能区划成果，认真配合开展兴化湾南岸涵江港开发和湄洲湾北岸涉海重点项目的海域使用论证和海洋环境影响评估工作。推进湾外围填海区块选划研究成果应用和区域建设用海规划的报批工作。继续做好优化用海审批的前期工作，依托海域使用动态监视监测系统，公示项目用海审批进度，提高服务效率，展示服务成果，自觉接受社会监督。积极协调解决用海业主、渔民群众最关心、最迫切、最需要的问题，切实保障管理相对人合法权益。四是加大对海洋与渔业的宣传力度。充分运用专业报刊和部门网站的功能，精心组织刊发一批有深度、有高度的通讯报道，借助莆田广电中心新闻热线，开辟《海洋之波》、《渔业之声》等栏目，推出专家学者访谈、在线访谈，扎实做好舆论引导工作，取得社会公众的理解和支持。

　　二、把增强发展活力作为跨越发展的坚强后盾   

　　一是推进海洋资源市场化配置。探索、完善海域资源市场化配置，建立健全海域收储制度，设立海域储备和海洋产权交易机构，继续推进养殖海域使用权、填海项目海域使用权、海域采砂临用海和海岛使用权等招拍挂和海域使用权抵押融资工作，发挥海洋资源效益。二是探索渔船管理改革途径。继续开展渔船“小改大、木改钢”工作，努力消除                                                                        木质破旧渔船安全隐患。继续推进渔业船舶安全生产主体责任的落实，学习借鉴泉州市局开展渔业船舶安全生产标准化建设成功经验。扎实开展渔船安全生产标准化建设活动，深入开展秀屿区“全国平安渔业示范县”和石城一级渔港“全国文明渔港”创建活动。三是切实提高渔业生产组织化程度。加大对渔民专业合作社示范社的扶持力度，推进示范社规范化、标准化、品牌化建设；切实推广和落实渔船编队生产制度，提升渔船自救互救能力，落实渔业救助补助奖励机制，规范海难救助资金的申报和发放。四是深化对台对外海洋与渔业合作交流。加大对外经贸合作力度，通过组织参加“9·8投洽会”、“渔业周”、“渔博会”、“农交会”等合作交流平台，引导外商、特别是台商投资莆田海洋与渔业产业。五是积极推动海洋文化建设。加强海洋文化研究，充分利用“妈祖”、“中国花蛤之乡”、“南日鲍”等文化资源，打造独具莆田地方特色的海洋文化产业品牌，促进滨海旅游业的发展。加强海洋教育，普及海洋知识，形成文化引领，着力培育海洋文化创意产业，为莆田港口经济发展和海洋综合能力建设的全面进步提供强大精神动力和智力支持。依法加强海底文物保护工作，严厉打击海底打捞文物违法行为。六是深化直属国有企业改革。积极推进水产国有企业改制工作，认真抓好市水产冷冻厂破产申报工作，切实加强市水产冷冻厂和水产养殖公司职工计生管理。

　　三、把做大海洋经济作为宜居港城建设的新增长极   

　　一要推进试点省规划实施。抓住福建省实施海洋经济发展试点省建设的有利时机，认真借鉴平潭综合改革实验区海洋经济发展实施方案做法，切实履行莆田市城乡一体化综合改革试点工作分工职责，加快转变海洋经济发展方式，高起点谋划，高标准建设，深化细化做好与省级海洋产业各项方案的衔接和相关政策意见的贯彻实施，创造性地推进海洋经济试验区莆田板块建设。二要认真实施用海用岛规划。严格实施新版《福建省海洋功能区划》和《福建省海岛保护规划》，并启动《莆田市海洋功能区划》的修编和《莆田市无居民海岛保护和利用控制性详细规划》的编制工作，为进一步规范我市海域、无居民海岛开发提供科学依据。坚持市场需求、切实可行和分期分批的原则，统筹湾岛综合利用，创新海洋开发模式，合理规划开发利用石岛以及南日岛周边一批无居民海岛，积极探索无居民海岛使用权出让方式，有计划分步骤地推进可适度利用无居民海岛的开发利用工作，着力促进海洋经济发展。三要创新服务工作机制。在改进工作作风、提高工作效率和服务水平上下功夫，改变目前存在的一些不良现象，特别是在项目的审批、渔船的管理、渔船检验、执法、用海等方面强化服务。四要开展海洋经济运行监测与评估。推进市、县海洋经济运行监测评估中心建设，提升我市海洋经济运行监测评估能力，建立起能够及时反映海洋经济结构布局，增长方式及发展环境等方面的监测评估系统，加强对海洋经济的指导和协调。五要推进海洋资源统筹开发和集约利用。合理控制岸线及附近海域资源的开发强度，促进岸线、滩涂和水域等海洋资源的合理高效利用。六要拓宽海域使用权等权属抵押融资范围。积极推动各类船舶、在建船舶保单抵押融资模式和海域使用权抵押贷款等适应海洋产业发展的新型信贷模式。

　　四、把可持续发展作为提高海洋与渔业生命力的根本途径

　　一是进一步加强和完善与涉海部门合作联动机制。与市环保局在海洋环保规划与区划、主要海湾污染控制、监测数据与技术共享、海洋环保联合执法监督检查、日常工作协调等方面全面开展合作，推动沿海县级海洋部门与环保部门协调机制的建立，与海事等涉海部门加强合作，形成海洋环境保护工作强大合力。二是进一步深化海洋环境保护和生态建设。加大落实海洋环境保护责任制的力度，纳入县区政府绩效管理责任指标体系进行统一评估，促进县区政府领导更好地落实海洋环保“一岗双责”，共同推进海洋环保领域依法治市方略和可持续发展战略的有效实施。重点实施一批海洋环境综合整治和生态建设项目，加强对重点海湾、沙滩、渔港和重要养殖集中区的海洋环境综合整治与生态修复，在南日岛周边海域建立总投资500万元、总面积2平方公里的人工鱼礁，在平海湾投入89万元增殖放流长毛对虾、黄鳍鲷、中国鲎，在湄洲岛轮渡港区、石南轮渡港区、九宝澜黄金沙滩、南日岩黄金沙滩、平海一级渔港、石城一级渔港、上林二级渔港、枫亭二级渔港、仙游锦湖村枫慈溪入海口开展“海漂垃圾”整治工作；不断提升海洋环境监视监测的能力和水平，推进重点养殖水域水质环境监测预警预报系统建设，提升处理处置海洋环境污染损害和渔业水域污染事故的能力。三是进一步推进陆源污染源预防和治理工作。加快建设城乡污水、生活垃圾集中处理设施，加强入海河流源头的污染治理，整合海陆环保机构力量，抓紧建立重点排海污染企业在线监管系统，努力实现达标排放陆源污染物。参照省环保厅、省海洋与渔业厅签订的海洋环保合作协议文件，拟定我市的海陆一体化海洋环保行政管理机制。四是进一步完善海洋环境保护规划。选择湄洲湾北岸和兴化湾南岸开展“总量控制”试点工作，尽快完善并力争颁布《莆田市海洋环境保护规划》，使海洋环保规划成为我市“十二五”贯彻实施海洋环保法律法规的有效补充，统筹引导海洋环保工作。

　　五、把科技和机制体制创新作为提升工作水平的动力源泉

　　一要加快科技兴海平台建设。积极跟进服务中海源（莆田）海洋高技术产业园建设项目，促进项目尽快投资建设。二要加快科技成果转化步伐。充分利用6.18项目交易会等交易平台，紧扣“项目、技术、资本、人才”主题，扎实推进海洋与渔业科技项目成果与企业对接并落地投产，为我市现代渔业发展提供有力的项目和技术支撑。三要加大渔业科技推广力度。探索和改革、创新渔业科技推广工作的模式、机制和方法。开展水产育苗、水产品质量安全等渔业实用技术培训，继续实施渔业科技入户示范工程。推进渔业“五新”工作，重点推广抗逆性强的水产优良新品种、标准化健康养殖技术，推广应用国标新渔药及循环水处理设备等水产新机具。

　　六、把产业结构调整作为刻不容缓的战略任务

　　一要加快新兴优势品种产业带建设。推进鲍鱼、海参、海带、龙须菜、花蛤等5条产业带建设，进一步扩大养殖规模，形成优势产区。推广运用新型网箱、筏式养殖设施等现代高科技、新设备，加快湾外20米等深线外海域开发，引导和扶持建设一批陆上工厂化养殖基地，进一步拓展水产养殖空间，实现水产养殖业战略调整。二要推进现代渔业基础设施体系建设。加快推进水产良种体系建设，着力抓好具有生产环境、生产规模、亲本来源、管理人员、技术人员达标的市级水产良种场认定，对符合申报省级水产原良种场的市级水产良种场将推荐上报省厅参评省级水产原良种场。继续开展标准化水产养殖池塘改造，建设千亩集中连片、设施完善、配套齐全的标准化现代水产养殖基地。继续创建健康水产养殖示范场，面积达5千亩以上。三要加快发展休闲渔业。继续创建水乡渔村，指导已经授牌的水乡渔村完善建设，提升档次，积极参加旅游部门开展的乡村旅游经营单位服务质量星级评定，扩大宣传效果，进一步提高社会对休闲渔业的认识水平。四要持续发展壮大水产加工业。以新一轮省级水产产业化龙头企业为重点，引导企业加强自主研发和品牌创建；跟踪掌握水产加工业动态，加强加工信息搜集，帮促加工项目落地，积极引导民间资本投资贝、藻类加工业，延伸产业链，提高大宗产品附加值，促进渔业增效渔民增收。着力培育水产加工企业做大做强，帮导重点企业申报省级加工项目，支持企业技术成果应用和自主品牌创建，提高产品占有率和市场竞争力。发挥莆田市“中国花蛤之乡”品牌效益，加快实施花蛤产业提升规划，引导促进海源实业有限公司开发花蛤精深加工产品，提高花蛤产品附加值。

　　七、把注重保障民生作为海洋与渔业发展的根本出发点

　　一是规范海洋与渔业防灾减灾预案管理。加大海洋与渔业防灾减灾宣传力度，加强灾害性天气预警预报制度建设，抓好渔业防台风工作的落实，做好海洋赤潮等突发性事件的应急处置工作。二是完善海洋与渔业防灾减灾百千万工程。加大渔港建设和管理力度，规范渔港权属管理，要抓住国家和省里加大渔港建设投入力度的难得机遇，努力争取市县（区）财政增加渔港建设资金投入，督促平海镇平海一级、上林二级、埭头镇淇沪三级和南日镇的罗盘、鳌屿二个三级渔港的标准渔港建设进度，积极争取南日镇的浮叶一级渔港项目的立项。三是保障水产品有效供给。围绕水产品供应“量足、质优、价稳”的基本目标，按照“建基地、扩生产、求质量、保供应”的要求，加强政策引导，争取资金扶持，改善生产设施，提高供应水平，保障水产品安全供给。四是建立和完善水产品质量安全监测体系。依托市海洋与渔业环境监测站，抓好市级水产品质量检测站建设，扶持提升水产品质量安全自主检测能力。开展鲍鱼等主要养殖品种水产品质量安全可追溯体系建设试点，开展水产品产地准出、市场准入试点。加强无公害水产品产地认定和产品认证工作。五是加强水产养殖病害防治管理。继续参与实施“福建省渔业病害疫情与生态环境监测”项目，在主要品种的池塘、网箱等养殖集中区开展病害疫情监测，控制水生动物重大病害的发生和疫病流行，配置病害测报仪器设备，重点加强测报能力；在病害流行季节，组织各级水技人员到养殖区进行指导。六是创新水技推广方式方法。围绕现代渔业发展和渔民需求，通过渔业“五新”展示示范、科技入户、手机短信平台和技术服务网站等多种手段，探索建立“以人为本，以市场为准”的水技推广方式方法，确保基础性技术服务、集成性技术推广和关键技术试验示范等推广活动的有效开展。七是扎实推进渔业保险工作。完善渔业互助保险工作机制，扩大渔业保险范围，开展水产养殖保险试点，增加险种，提高保额，争取加大财政补贴力度，增强渔民抵御风险能力。积极推动银保互动机制建设，认真实施参保渔船小额贷款实施办法，帮助解决渔民生产性融资问题。

　　八、把规范生产作为促进安全生产的重要保障

　　一是全面落实渔业安全生产管理制度。巩固扩大渔业安全生产年和责任落实年活动成果，加强对一系列渔业安全生产制度落实情况进行督查。二是建立安全应急管理机制。进一步完善渔船自动识别系统建设，充分利用监控管理平台加强对渔船的监管。对船载终端开机率和使用率不高的问题，切实做到以制度来监督，重点在渔船检验、买卖变更、油补发放环节采取行之有效的措施，确保开机率和正常使用率，不断完善海上应急救助系统。三是继续推进“平安渔业”系列活动。深化秀屿区“全国平安渔业示范县”创建工作，尤其是要将渔业安全事故的立案调查落实到位，建立渔业安全事故档案，使违法违规责任人得到应有的惩处，进一步促进提升渔业安全生产管理水平；通过“渔业安全生产月”等形式，开展安全生产责任主体活动，落实渔船的船东、船长安全生产主体责任，重点对全市60马力以上的机动渔船进行安全生产级别评定和隐患排查，力争覆盖率达到90%。

　　 九、把强化执法能力作为管理服务的有力抓手

　　一是完善渔港监督站建设。力争县区政府（管委会）支持在全市二级以上渔港及渔船比较集中停泊的港口完善渔港监督站，做到机构、人员、经费、设备“四到位”。二是加强执法信息化。建设全市海洋与渔业执法船艇综合通信指挥监控系统，统筹应用海洋与渔业执法办案系统软件和渔业船员管理软件，提升执法信息化水平。三是加强执法队伍作风效能建设。对整合后的执法力量，建立统一、协调、高效的监管机制。建立执法工作效能评价机制，以执法监管到位、打击违法有力为目的，扎实推进执法队伍作风效能建设。以争创“海洋与渔业执法文明窗口”为契机，着力打造海洋“卫士”和渔业“守护神”的形象。五是扎实开展日常执法工作。围绕海洋与渔业执法监管职能，以开展“海盾”、“碧海”、“海岛”、“护渔”等专项执法行动为抓手，注重工作重点，提升执法效能，推动海洋与渔业各项执法工作的全面开展。          

　　十、把创先争优作为加强干部队伍建设的重要载体

　　一是加强思想政治建设。深入贯彻学习党的十七届五中、六中全会、省委九届二次全会和市委六届二次全会精神，自觉提升党员领导干部学习力，进一步强化思想政治建设，认真开展“进百村入千企访万户”主题实践活动，为“实现一二三一五，突破项目促跨越”提供坚强的思想组织保证。二是加强领导班子建设。进一步完善领导班子工作机制、议事规则和决策程序，着力提高领导班子和领导干部的执行能力和创造性工作能力，充分发挥拓展一线的骨干作用，为海洋与渔业新一轮创业展现表率带头效果。三是深入开展“创先争优”活动。突出机关党建“三级联创”载体，强化党员意识和责任意识，充分发挥党员的先锋模范作用，加强检查指导和交流，通过开展创满意窗口和优质服务品牌、党员公开承诺和挂牌上岗等活动，增强活动实效，真正把党支部建设成为战斗堡垒，带动工作作风的转变和工作水平的提升，进一步增强党员队伍的软实力。四是加强业务能力建设。对基层领导干部和中层业务骨干加强业务知识、法律知识、管理知识和现代科技知识的培训，提高业务素质和工作能力，把海洋与渔业部门逐步打造成宏观指导和综合协调部门。五是扎实推进政风行风建设。把政风行风建设贯穿到全年各项工作之中，以解决热点难点问题为重点，以群众满意为标准，以优化服务为目标，继续践行“海八条、渔八条”服务承诺，及时提供保姆式、菜单式服务，切实解决政风行风中存在的问题。六是切实加强党风廉政教育。认真落实党风廉政建设责任制，坚持“一岗双责”，贯彻执行《党政领导干部问责的暂行规定》和干部选拔任用工作的四项监督制度等，全面推行廉政风险防控管理新机制，不断提高党员干部反腐倡廉的自律意识，树立海洋与渔业系统的良好形象。七是着力推进惩防体系建设。进一步贯彻落实《建立健全惩治和预防腐败体系2008-2012年工作规划》要求，认真落实党风廉政建设责任制，依法依规加强对权力运行的制约和监督，深化政府信息公开以及机关党务公开，运用纪律和行政手段强化对行政执法机关和直属事业单位领导干部的监管。全面落实规范海域使用管理牵头责任，继续加强渔业强农惠农资金监管，把反腐倡廉建设融入海洋与渔业工作的各个环节之中，确保各项工作的健康、有序、顺利开展。八是加强机关效能建设和部门绩效管理。深入开展“效能督查征海域、效能督查促项目、效能督查保安全、效能督查抓规范”等提速增效活动，整合网络资源，建立内部全覆盖OA系统，配备部分掌上电脑本，提高业务互动能力和资源共享水平，增强机关办公的硬实力；综合行政手段，切实完善内部绩效考评机制和岗位目标责任制，全面推行行政问责制、跟进问效制、AB顶岗制和督查通报制，拓展督查形式，运用《海洋与渔业信息》、《落实与反馈简表》载体，及时反映工作动态，形成自压互比机制，督促工作落实，务求取得实效。注重运用制度落实和绩效考评成果，以绩效评先评优，以绩效选人用人；创新部门绩效管理办法，深化干部人事制度改革，推进绩效评估争先进位，提升整体滚动力和部门影响力。把机关效能建设融入机关党的建设、精神文明建设、党风廉政建设、政风行风建设、综治平安建设、干部队伍建设和人口计生管理之中，确保政令畅通、事业发展。
