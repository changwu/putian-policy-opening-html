莆田市海洋与渔业局关于下达2014年度莆田市海洋经济发展专项补助资金的通知

发布时间：2014-12-19 08:00
| | |

　　各县区（管委会）海洋与渔业行政主管部门，市属有关单位：

　　为认真落实海洋产业政策措施，加快推进海洋经济发展，根据《莆田市海洋经济发展专项资金管理暂行办法》（莆市财农〔2013〕68号）、《关于印发2013年度莆田市海洋经济发展专项补助资金申报指南的通知》（莆海渔〔2014〕220号）和《关于批复2014年市本级部门预算的通知》（莆市财农〔2014〕6号）等文件精神，经研究并经公示，现将2014年海洋经济发展专项补助资金450万元下达给你们，请加强专项资金使用管理，确保专款专用。此款项属一性奖励补助，款列“2200214海域使用金支出”预算科目，务必及时到位。

　　附件：2014年度莆田市海洋经济发展专项补助资金分配表
