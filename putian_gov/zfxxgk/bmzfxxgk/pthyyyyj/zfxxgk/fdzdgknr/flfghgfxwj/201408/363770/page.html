莆田市海洋与渔业局印发《关于深化“马上就办”行动实施方案》的通知

发布时间：2014-08-14 08:00
| | |

　　局机关各科室、局直属各单位：

　　现将《关于深化“马上就办”行动实施方案》印发给你们，请结合工作实际，认真贯彻落实。

　　莆田市海洋与渔业局

　　2014年8月14日

　　关于深化“马上就办”行动实施方案

　　为进一步推进“马上就办”，根据莆田市机关效能建设领导小组《关于深化“马上就办”行动方案》（莆效〔2014〕3号）精神，结合我局实际，在全局范围内开展深化“马上就办”专项行动。实施方案如下：

　　一、总体要求

　　深入贯彻落实党的十八届三中全会和习近平总书记系列重要讲话精神，结合党的群众路线教育实践活动，以贯彻实施《福建省机关效能建设工作条例》（以下简称《条例》）为契机，围绕转职能、改作风、优服务、提效能、促发展目标，以解决实际问题为导向，强化“马上就办”理念，提升“马上就办”实效，进一步营造更加规范便捷、更加简单宽松、更加透明公开的办事环境，为我市海洋与渔业科学跨越发展提供有力保障。

　　二、主要任务

　　（一）推进部门职能转变

　　1.按照专业化管理的要求，加快推进市水产科学研究所、市后海围垦管理局的职能划归、整合工作。（牵头单位：局办公室；完成时限：11月）

　　（二）优化服务审批

　　2.规范审批程序，对一般审批事项，不超过3个工作日，能当场办结的事项，要当场办结；对情况复杂，确需进行研究调查的事项，要限定在5个工作日内办结。法律法规规定已有明确时限要求且审批时限较长的，要尽量提前审批，原则上要比“法定时限”缩短40%，不断提高即办件比率，当日即办率提高至70%以上。（牵头单位：审批科；责任单位：海域和海岛管理科、资源环保科、渔业管理科、规划法规监督科、执法支队）

　　3.加大惠企政策的宣传、指导、执行力度，注重优化流程，减少管理环节，提高工作效率。（责任单位：海洋经济科、渔业管理科、规划法规监督科、水技站、渔保办）

　　4.建立全局统一审批目录清单。由审批科负责对局本级及本系统县区海洋与渔业部门的行政审批（含行政许可和非行政许可审批）、公共服务（含转变管理方式）等事项进行全面清理，明确名称、依据、标准、流程、办理时限、申请材料等，分清即办件和承诺件，建立市、县（区）两级清单目录，于8底前上报市行政服务中心管委会、市审改办审核。（牵头单位：审批科；责任单位：海域和海岛管理科、资源环保科、渔业管理科、规划法规监督科、执法支队；完成时限：8月）

　　5.建立审批清单动态管理机制。依托局网站，统一公布经市审改办、法制办、行政服务中心管委会审核通过的审批事项项目，并对新增、调整、取消审批事项统一上报审批科审查后再上报市里审核，清单之外的，一律不得实施审批。（牵头单位：审批科；完成时限：11月）

　　（三）推进并联审批

　　6.抓好港航工程类投资建设项目和交通工程类投资建设项目中的涉及的海域使用权确认审核、海洋工程环境影响报告书（表）核准项目的并联办理，加快项目审批。（责任单位：海岛和海岛管理科、资源环保科）

　　（四）梳理机关内部管理与服务事项

　　7.各单位要根据本单位的机构职能，岗位职责，对内部管理和服务事项进行全面梳理，分类明确事项性质和办理时限，并形成清单目录。同时，要制订《业务岗位责任制及业务工作流程》，主要内容包括科室职责、岗位责任、政策法规、工作流程、环节时限等，做到单位内部办事流程规范、环节简化、时限合理。各科室单位清单目录、《业务岗位责任制及业务工作流程》等梳理情况于10月底报局办公室审核、汇总后，由局办公室上报市效能办备查。（牵头单位：局办公室；完成时限：10月）

　　（五）规范行政审批中介服务行为

　　8.建立项目审批路线图，编制项目审批操作指南，由责任科室或项目业主组织办理的现场勘察、技术审查、专家论证、公示听证、检验检测、集体研究等外部办理环节，必须明确具体实施条件和办理时限，纳入市网上审批和电子监察系统监管。（牵头单位：审批科；责任单位：海域和海岛管理科、资源环保科、规划法规监督科、渔业管理科、执法支队；完成时限：11月）

　　（六）健全长效机制

　　9.健全完善机关管理制度。根据我局职能职责，结合开展党的群众路线教育实践活动，认真查找本单位在制度建设方面存在的突出问题，对机关现有制度进行梳理，对不合时宜的制度规定进行修订完善，健全完善机关管理长效机制，努力实现以制度管权、用制度管事、靠制度管人。（牵头单位：局办公室；完成时限：11月）

　　10.健全完善审批服务制度。健全完善岗位责任、办事公开、服务承诺、首问责任、一次性告知、限时办结、否定报备、责任追究等制度，坚决纠正办事程序繁琐、审批手续繁杂，政策规定不明确、解释答复不清楚、告知事项不到位、服务承诺不兑现等突出问题，主动、热情、耐心地为群众和企业服务，真心实意为群众和企业排忧解难。（牵头单位：审批科；完成时限：11月）

　　（七）注重总结提升

　　11.结合开展学习、宣传、贯彻《条例》“十个一”活动，认真对照“马上就办”要求，查找机关效能和工作作风方面存在的突出问题，抓好整改，建章立制，使“马上就办”要求转化为真正为民服务的实际行动。（牵头单位：局办公室；完成时限：11月）

　　12.认真开展“换位体验”活动，深化“马上就办”，促进机关干部进一步更新观念、开阔思路，深入一线、体验民生，转变作风、改进服务。（牵头单位：局办公室）

　　13.珍惜省级“马上就办”示范点单位荣誉，进一步总结提升渔船检验管理廉政风险防控“112”做法，并积极开展渔船燃油补贴廉政风险防控网上公开试点工作。（责任单位：规划法规监督科、执法支队）

　　（八）强化效能监督问责
    14.畅通反映诉求渠道。要确保值班、咨询和投诉举报电话使用畅通，认真倾听群众的呼声，帮助群众解决实际困难和问题。结合党的群众路线教育实践活动，通过召开座谈会、发放调查问卷、电话回访等形式，多渠道收集群众、企业对本地区和本部门及其机关工作人员在作风建设、办事效率、行政审批、便民服务等方面的意见建议，抓好存在问题的整改落实。（牵头单位：局办公室）
    15.直查快办投诉问题。对企业和群众反映局机关违反“马上就办”要求，以及影响投资环境建设等的投诉问题，做到严查、快处、速结；对破坏发展环境的案件，深挖线索，责任倒查，严肃处理。（牵头单位：驻市水利局纪检组、监察室，局办公室）
    16.强化效能监督问责。突出督查重点，依法依规用好效能督查建议和效能问责等法定手段，增强效能监督的威慑力。加大效能督查问责力度，对违反“马上就办”要求的典型案例，实行指名道姓公开曝光。（牵头单位：驻市水利局纪检组、监察室，局办公室）

　　三、保障措施

　　（一）加强领导。局党组把深化“马上就办”行动作为机关效能建设的重要工作来抓，做到思想认识到位、组织领导到位、工作措施到位。成立以局党组书记、局长黄德元同志为组长，局班子成员为副组长，局机关各科室、局直属各单位主要负责人为成员的领导小组，领导小组下设办公室，挂靠在局办公室，由林金顺同志兼任办公室主任，柯丽霞为副主任，成员由陈建珊、吴其通、陈丽华等同志组成，负责制定具体的实施方案，推进工作落实。实施方案于8月中旬前报送市效能办备案。
   （二）强化责任。实行严格的工作责任制，把“马上就办”的各项措施和要求分解到每个岗位和个人，落实到具体工作中，做到转作风提效能、抓落实见成效、聚合力树形象。牵头单位要主动谋划，切实发挥好组织协调、牵头抓总作用；责任单位主要负责人是第一责任人，要严格落实主体责任，自觉支持，密切配合，积极主动地完成任务，切实担负起推动莆田海洋与渔业科学跨越发展的使命和责任。
   （三）务求实效。坚持时间进度服从质量的要求，认真按照实施方案，狠抓落实。创新拓展服务企业和群众的新办法、新措施，帮助企业和群众解决“最后一公里”问题。市委督查室、市政府督查室、市效能办将组织开展督查，加强明察暗访，对庸懒散拖、推诿扯皮、吃拿卡要，不作为、慢作为、乱作为等妨碍投资发展环境的行为，要依法依规从严问责，并进行通报和曝光，做到“查处一个、教育一片、震慑一方”，营造良好的投资发展环境。局效能办将联合驻市水利局监察室开展明查暗访。

　　 

　　抄送：市效能办，驻市水利局纪检组、监察室。  

　　莆田市海洋与渔业局办公室　           2014年8月14日印发
