莆田市海洋与渔业局关于印发《2013年民主评议政风行风工作实施方案》的通知

发布时间：2013-05-31 08:00
| | |

　　各县（区、管委会）海洋与渔业行政主管部门，局机关各科室、局直属各单位：

　　为进一步做好民主评议政风行风工作，现将《莆田市海洋与渔业局2013年民主评议政风行风工作实施方案》印发给你们，请结合工作实际，认真抓好贯彻落实。

　　

　　莆田市海洋与渔业局

　　2013年5月31日

　　莆田市海洋与渔业局

　　2013年民主评议政风行风工作实施方案

　　根据市政府《关于2013年开展“政风行风人民评”活动的实施意见》（莆政综〔2013〕51号）和省厅《2013年民主评议政风行风工作实施方案》（闽海渔〔2013〕166号）文件精神，以及局党组《2013年党风廉政建设和反腐败工作任务分工》的文件要求，特制定本实施方案。

　　一、指导思想

　　坚持以邓小平理论、“三个代表”重要思想和科学发展观为指导，深入贯彻落实中央八项规定，坚持党的群众路线，紧密围绕海洋与渔业中心工作，围绕加快海洋经济发展、建设海洋强市为目标，以加强政风行风建设为核心，以解决损害群众利益的热点难点问题为目的，以人民群众满意为标准，以加强和改进政风行风建设为基础，以优化发展环境为重点，认真扎实推进各单位“创先争优”和“服务标准化”建设。

　　二、评议对象

　　（一）各县（区、管委会）海洋与渔业主管部门。

　　（二）局机关各科室、局直属各单位，其中市海洋与渔业执法支队为重点评议和重点督查单位。

　　三、评议内容

　　（一）转变职能。积极推进“马上就办”的要求，优化发展环境，从企业和群众需要出发，主动为市场主体和人民群众提供直接、便利、公正、有效的服务。（牵头单位：局办公室，责任单位：局机关科室和执法支队、水技站、环境监测站）

　　（二）改进作风。认真落实中央八项规定和我市实施细则，坚持走群众路线，坚决克服官僚主义、形式主义和浪费现象。（牵头单位：局办公室，责任单位：局机关科室和执法支队、水技站、环境监测站）

　　（三）维护民利。认真落实中央和省、市出台的利民惠民政策，加强和改进群众工作，着力为群众办实事、解难题，坚决纠正损害群众利益的不正之风。（牵头单位：局办公室，责任单位：局机关科室和执法支队）

　　（四）信息公开。认真履行公开责任，做到政策法规、办事流程、收费标准、办理时限、服务承诺等政务（事务）信息应当公开的尽可能公开。（牵头单位：局办公室责任单位：计划规划科、执法支队）

　　（五）依法办事。正确履行职责，严格依法依规办事，无滥用职权、执法不严、办事不公，以及乱收费、乱罚款和各种摊派等问题。（牵头单位：计划法规科，责任单位：局相关科室和执法支队）

　　（六）廉洁自律。认真执行党风廉政建设各项规定，在履行职责中忠于职守、廉洁奉公，无徇私舞弊、以权谋私、吃拿卡要等问题。（牵头单位：局办公室，责任单位：局相关科室和执法支队）

　　（七）制度建设。内部管理和监督制度完善，政风行风建设责任制落实，建立对群众反映问题的受理、整改和反馈机制。（牵头单位：局办公室，责任单位：局机关科室和执法支队、水技站、环境监测站）

　　四、评议方法

　　民主评议政风行风工作在市纠风办的统一领导下进行，考评采取日常考评（《壶兰监督》诉求整改、专项治理、明查暗访、网络维护）、群众评议（专家评议、群众代表评议、服务对象评议）和下级评议相结合的方法。

　　五、主要任务

　　（一）完善工作机构。调整充实局民主评议政风行风工作领导小组，确定莆田廉政网网上纠风平台的网络维护信息员、审核人员。（牵头单位：局办公室、执法支队）

　　（二）制定实施方案。结合海洋与渔业工作实际，认真制定2013年民主评议政风行风工作实施方案，明确评议对象、内容和任务。各科室各单位必须按照实施方案认真组织实施。（牵头单位：局办公室）

　　（三）开展选题评议。按照省厅的统一部署，今年的选题为：标准化水产养殖改造。要安排专题会议研究选题评议工作，按照选题评议的时间节点安排，及时将各项内容上报省厅。（责任单位：渔业生产科、局办公室）

　　（四）开展明察暗访。组织相关人员深入基层开展明察暗访活动，加强工作检查指导，查找政风行风建设存在的问题，督促做好整改。（联系单位：局办公室）

　　（五）参加在线访谈。密切配合莆田人民广播电台《壶兰监督》栏目组，积极安排落实8月31日《壶兰监督》直播间上线访谈活动，由局主要领导带队参加直播，局相关科室和执法支队负责人具体解答听众提出的热点问题咨询，对热线咨询和投诉的问题，及时进行调查了解和回复。（牵头单位：局办公室，责任单位：局相关科室和执法支队）

　　（六）及时上传信息。市纠风办利用莆田廉政网网上纠风平台对市级各参评单位日常工作进行网上动态监管和考评。局保障网上纠风平台的网络信息员、审核人员要按照民主评议日常工作网上考评内容和要求，及时上传发布。（责任单位：局办公室、执法支队）

　　（七）抓好整改工作。回顾当年开展政风行风评议工作情况，总结经验，查找差距，扎实推进新一轮政风行风建设。在做好总结工作的同时，还要认真收集整理相关工作资料与台帐，并造册归档，规范管理。（责任单位：局办公室、执法支队）

　　六、工作要求

　　（一）加强组织领导。各参评单位要坚持“谁主管、谁负责”、“管行业必须管行风、抓机关必须抓基层”的工作责任制，把民主评议政风行风工作作为落实党风廉政建设的重要措施，把政风行风建设与建立服务标准体系相结合，摆上重要议事日程，纳入目标管理，融入具体工作，落实“一把手”负总责、亲自抓，分管领导具体抓，形成一级抓一级，层层抓落实的工作格局，不断推进评议工作扎实有效开展。 

　　（二）注重工作实效。海洋与渔业部门作为民生保障实施的重要职能部门，要按照中央和省、市的部署要求，切实关注民生，结合实际，在完成“规定动作”的情况下，努力创新“自选动作”，解决好用海单位、水产品加工企业和渔民群众反映强烈的突出问题。通过政风行风建设促进业务工作开展，着力解决群众需要解决的问题，把解决问题作为一条主线，贯穿于评议工作全过程，以实际工作成效取信于民。

　　（三）严肃评议纪律。各单位要严格遵守工作纪律，严禁弄虚作假。评议工作要严格程序，切实做到实事求是、客观真实。对违反评议纪律的，要依照有关规定追究相关人员和领导的责任。

　　抄送：省海洋与渔业厅，市纠风办。

　　莆田市海洋与渔业局办公室         2013年5月31日印发
