关于印发莆田市开展海域采砂整治行动工作方案的通知

发布时间：2009-07-29 08:00
| | |

　　各县（区）海洋与渔业主管部门，市海洋与渔业执法支队：

　　接市纠风办通知，经研究，决定在全市海洋与渔业系统民主评议政风行风活动中将原定开展优势水产品产业带渔业科技提升行动调整为开展海域采砂整治行动进行选题评议，现将《莆田市开展海域采砂整治行动工作方案》印发给你们，请认真遵照执行。

　　莆田市海洋与渔业局

　　二OO九年七月二十九日

　　莆田市开展海域采砂整治行动工作方案

　　莆田市海洋与渔业局

　　(2009年7月29日)

　　根据《莆田市人民政府关于2009年度民主评议政风行风工作实施意见》（莆政综[2009]60号）和《莆田市人民政府办公室关于印发莆田市开展海上非法采砂整治工作方案的通知》（莆政办[2009]107号）文件精神，按照“谁主管谁负责，管行业必须管行风”的原则，我局通过组织明察暗访、征求群众意见、对照工作职责等方式，认真查摆本系统在政风行风上存在的突出问题，经研究，选定海域采砂整治行动（严厉打击海上非法采砂行为）问题进行评议,依据《福建省海洋环境保护条例》和《福建省海域采砂临时用海管理办法》，结合我市实际，现就进一步加强海上非法采砂综合整治提出如下工作方案。

　　一、组织领导

　　为加强对海上非法采砂整治工作的领导，确保整治行动的扎实开展，成立莆田市海洋与渔业局整治海上非法采砂工作领导小组。

　　组  长：张文发

　　副组长：苏美琼  黄玉枝 李雷声

　　成  员：郑国辉  郑建明 刘国辉  黄金鹏  张新立

　　各县(区、度假区、开发区)海洋与渔业主管部门及其执法机构负责人

　　领导小组下设2个组：

　　1、指导督查组

　　组  长：苏美琼

　　成  员：郑国辉  郑建明  刘国辉  朱爱民  柯丽霞

　　职  责：负责对各县区开展整治行动的指导、督查、宣传报道等工作。

　　2、执法整治组

　　组  长：黄玉枝

　　副组长：李雷声

　　成  员：黄金鹏 张新立  各县(区、度假区、开发区)海洋与渔业执法机构负责人。

　　职  责：负责组织开展整治海上非法采砂执法行动。

　　各县(区、度假区、开发区)海洋与渔业主管部门要相应成立整治行动工作领导小组，切实加强组织领导，确保整治海上非法采砂工作有序进展。

　　二、总体目标

　　从2009年起，力争用两年时间，使莆田海域“三湾两岛”沿岸非法采挖海砂行为得到有效遏制，海湾岸线与海岛岸线、海洋与海岸工程得到有效保护，海岸资源持续保持，近岸海水水质达到三类以上标准，海洋环境质量达到海洋环境功能区划的基本标准，逐步形成海洋生态良性循环、人与自然和谐相处的发展态势。

　　三、整治重点

　　1、充分发挥规划引导作用。以全省启动海洋功能区划修编工作为契机，充分发挥海洋科研院所的技术力量优势，做好海砂开采区规划和海砂开采权市场化配置前期工作，注重规划的先导作用，促进海砂开采活动的有序、有度进行，为全市各类工程建设的海砂需求提供保障。

　　2、依法打击非法采砂行为。认真制定《福建省海洋环境保护条例》的法规配套制度和《福建省海域采砂临时用海管理办法》的政策配套措施，坚持法制宣传教育和依法打击处罚相结合，规范海洋行政权力运行，严格执行损害海洋环境的自由裁量权，坚持“纵向联动，横向联手”，组织市、县区两级海洋与渔业执法机构，协调海事、公安、国土资源、海警支队等相关部门，重拳出击，围追堵截，开展“不定期、多部门、拉网式”的联合执法大行动，实施海域采砂综合治理，做到不缺位、不错位、不越位。

　　3、加大源头整治处罚力度。积极配合海事等部门，全面清理取缔 “无证或证件不齐”的海砂采挖、运输船舶，强制拆除擅自改装的采砂设备，依法吊销船主的运输营业执照，并对违法人员依法移交公安机关进行处理。

　　4、加强岸线巡查和近岸巡航监管。实行市、县区两级执法船艇轮流巡航制度，加强对现有非法采砂点的日常监管，借助市、县区渔业安全应急指挥系统视频监控平台，推行全天候值班远程监控制度，严守执法人员保密制度，设立专用举报电话（0594-2610868），采取蹲点守候办法，多渠道掌握非法采砂动态，确保有效实施打击行动。

　　5、保持边界联合追击高压态势。会同海警支队、公安、海事等部门，邀请市电视台当场曝光并跟踪报道，从快从重打击处罚本市辖区边界周边海域的非法采砂船舶，严防外来采砂船舶非法作业，坚决制止辖区海砂资源“掏空外流”现象。

　　四、方法步骤

　　第一阶段：动员部署（7月31日前）。认真制定专项整治行动方案，及时动员部署，广泛宣传发动。

　　第二阶段：组织实施（8月1日--11月30日）。严格落实整治措施，精心组织整治行动，严厉打击海上非法采砂行为。

　　第三阶段：总结提升（12月1日-12月20日）。各县区海洋与渔业主管部门要认真总结整治行动工作的主要成效，及时推广成功做法和先进经验，进一步完善长效管理机制，不断巩固和扩大整治行动成果，确保海岸与岛岸沙滩退缩趋势得到有效遏制。

　　五、保障措施

　　1、加强组织领导。开展整治海上非法采砂行动，涉及面广，工作量大，各县（区）海洋与渔业主管部门及其执法机构务必高度重视，密切配合，齐抓共管，把开展整治海上非法采砂行动作为今年头等大事来抓，切实负起整治责任，精心组织，周密安排，确保整治工作取得明显成效，真正成为沿海群众满意工程。

　　2、加大宣传力度。市、县两级海洋与渔业执法机构要加大宣传教育力度，积极开展形式多样、内容丰富的宣传教育活动，广泛深入地宣传海域使用管理、海洋环境保护、矿产资源管理、社会治安管理、海上交通安全等涉海法律法规，不断增强广大群众的海洋国土意识、海洋环保意识和海洋法制意识，努力营造人人参与保护海洋资源与生态环境的良好社会氛围。

　　3、加大执法力度。市、县区两级海洋与渔业执法机构要加大整治海上非法采砂的执法力度，严厉打击海上非法采砂行为。一是适时组织海上执法行动。各县区海洋与渔业主管部门要针对本辖区海上非法采砂活动态势和侦察情报以及举报信息，作出快速反应，适时组织执法人员开展海上执法行动。二是上下联合开展专项执法行动。市、县两级执法机构要加强联合，增强海上执法力量，对重点、难点采砂区开展联合执法行动，严厉打击群体性非法采砂行为。三是牵头开展综合整治行动。按照《莆田市人民政府办公室关于印发莆田市开展海上非法采砂整治工作方案的通知》要求，积极与海事、国土、公安、边防、交警、海警、工商、水利等有关部门联手，形成合力，综合整治海上非法采挖、运输、经营海砂的行为。

　　4、强化日常监管。各县区海洋与渔业主管部门及其执法机构要强化日常监管，采取“三个结合”措施，切实提高日常监管效果。一是结合开展岸线巡查，加强对近岸海域非法采砂行为的监管，及时发现和查处近岸非法采砂行为。二是结合实施渔业巡航，加强对海上非法采砂行为的监管，及时查处海上非法采砂行为。三是结合实行渔业安全视频监控，完善海上渔业安全应急指挥系统视频监控设施，加强对海上非法采砂活动的全程实时远程监控，有效提高海上执法效果。

　　5、加强监督检查。我局整治工作领导小组将不定期组织力量对各县区开展整治工作情况进行专项督查，协调解决整治工作过程中存在的问题，推进整治工作全面扎实开展。同时，加强宣传教育和舆论监督，邀请新闻媒体对整治工作进行监督，确保依法整治行动顺利进展。
