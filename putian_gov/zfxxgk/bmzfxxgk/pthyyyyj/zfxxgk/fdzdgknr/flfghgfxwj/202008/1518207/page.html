莆田市海洋与渔业局 莆田市发展和改革委员会莆田市财政局关于下放和授权有关渔港审批权限的通知

发布时间：2020-08-19 09:04
| | |

各县、区（管委会）渔业行政主管部门、发改局（计统局）、财政局:

    为进一步推动我市渔港建设，规范和完善渔港投资建设管理机制，根据《福建省渔港和渔业船舶管理条例》、省政府《关于进一步加快渔港建设的若干意见》（闽政〔2020〕2号）及《福建省渔港投资与建设管理办法》文件精神，按照国家“放管服”改革要求，现将二级渔港、渔业避风锚地项目可行性研究报告和

初步设计审批权限分别下放县（区、管委会）发改局（计统局）、渔业行政主管部门；

二级渔港、渔业避风锚地项目竣工验收授权县（区、管委会）渔业行政主管部门组织实施。

 

附件：福建省海洋与渔业局 福建省发展和改革委员会 

     福建省财政厅关于印发《福建省渔港投资与建设管理办法》的通知
