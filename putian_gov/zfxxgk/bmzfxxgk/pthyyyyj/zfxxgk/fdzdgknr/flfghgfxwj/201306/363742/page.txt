各县(区、管委会)海洋与渔业行政主管部门，局机关各科室，市海洋与渔业执法支队：
经研究同意，现将《莆田市渔船管理廉政风险防控系统运行管理职责分工》印发给你们，请遵照执行。
莆田市海洋与渔业局
2013年6月18日
莆田市渔船管理廉政风险防控系统运行管理职责分工
为保障“渔船廉政风险防控系统”(下称系统)的正常运行，发挥系统加强廉政监督、规范权力运行、提高工作效能的作用。根据系统设定的功能作用和运行管理要求，以及相关部门的职能，制定以下系统运行管理职责分工。
一、渔船信息数据管理
系统设置渔船基本信息数据库，对渔船的基本信息进行管理。渔船基本信息包括渔船检验证书的基本数据、照片(大中型渔船：船体左、右侧面、船头正面、船尾正面、标识牌安装位置共5张，小型渔船：船体左、右侧面、船尾正面、标识牌安装位置共4张)。
(
一)初始录入。
全市登记在册的渔业船舶要全部录入“渔船基本信息数据库”，确保准确无误，并与“中国渔业船舶检验监督管理系统”的数据一致，具体职责分工如下：
1、市支队船检科。指定专人负责市级管理的渔业船舶基本信息收集、整理和录入工作。
2、县级船检机构。指定专人负责本级管理渔业船舶基本信息收集、整理和录入工作。
(
二)变更修改。
新建造、买卖过户、更新改造、报废拆解、灭失和渔船数据修改等发生渔船信息变化的，要在办理渔船登记、注销手续后5个工作日内相应变更修改“渔船基本信息数据库”信息，具体职责分工如下：
1、市支队船检科。指定专人负责市级管理的渔业船舶信息变化的变更修改，填制《渔船基本信息变更修改审批表》，经局分管领导审批后，由系统管理员负责录入。
2、县级船检机构。指定专人负责本级管理的渔业船舶信息变化的变更修改，填制《渔船基本信息变更修改审批表》，经本级分管领导审批后，由系统管理员负责录入。
二、渔船检验业务管理
系统依据《渔船法定检验规则》要求设置现场检验的项目内容，统一使用渔船执法终端实时录入现场检验信息，具体职责分工如下：
1、市支队船检科。由船检人员负责市级管理的渔业船舶现场检验信息实时录入，并指定专人导出打印相关检验信息，按相关规定整理形成船检档案。
2、县级船检机构。由船检人员负责本级管理的渔业船舶现场检验信息实时录入，并指定专人导出打印相关检验信息，按相关规定整理形成船检档案。
三、渔船标识信息管理
系统设置渔船标识牌信息数据库，按照《莆田市渔船标识牌管理制度》(莆海渔([2012]50号)文件(下称《制度》)规定，对渔船标识牌的制作、使用、授予、变更等信息进行管理，具体职责分工如下：
(
一)标识牌制作、使用。
由市支队渔政渔监科负责统一管理标识牌制作、使用，填制“渔业船舶管理标识牌制作对照表”，及时录入渔船标识牌信息数据库，并形成纸质档案妥善保管。
(
二)标识牌授予。
渔业船舶授予加挂“莆田市渔船管理标识牌”，应按照《制度》规定，办理“渔业船舶管理标识牌授予审核表”，填制“渔业船舶管理标识牌安装对照表”，并及时录入“渔船标识牌信息数据库”和形成纸质档案，具体职责分工如下：
1、市支队渔政渔监科。指定专人负责办理市级管理的渔业船舶标识牌授予审核手续和市、县两级标识牌授予安装信息的录入及档案管理工作。
2、市支队船检科。指定专人负责市级管理的渔业船舶标识牌安装，并填制“渔业船舶管理标识牌安装对照表”送市支队渔政渔监科录入数据库。
3、县级渔业部门。指定专人负责办理本级管理的渔业船舶标识牌授予审核手续，所属的船检机构要指定专人，根据本级渔业船舶标识牌授予安装情况，填制“渔业船舶管理标识牌安装对照表”，并及时报送市支队渔政渔监科录入数据库。
(
三)标识牌变更。
因渔业船舶过户、更换、作废、灭失等，应按照《制度》规定，填制“渔业船舶管理标识牌更换审核表”、“ 渔业船舶管理标识牌过户记录表”，办理标识牌变更手续，并及时录入“渔船标识牌信息数据库”和形成纸质档案，具体职责分工如下：
1、市支队渔政渔监科。负责办理市级管理的渔业船舶标识牌变更手续和市、县两级的标识牌变更信息录入。
2、县级渔业部门。指定专人负责办理本级管理的渔业船舶标识牌变更手续，并及时报送市支队渔政渔监科录入数据库。
四、对外公开信息管理
系统设置渔船年度检验、规费征收、行政处罚、燃油补贴等渔船管理行政权力运行情况及国家惠民政策的落实情况的相关公开信息，与局门户网站公开栏自动链接，接受公众监督，具体职责分工如下：
(
一)渔船年度检验信息。
系统设置实时自动生成市、县两级渔船现场检验相关公开信息。
(
二)渔船规费征收信息。
渔船规费征收信息实行按月录入公开，由市、县两级船检部门各自负责本级渔船规费征收信息的录入，每月的渔船规费征收信息应在次月初5日前完成录入。
(
三)渔船行政处罚信息。
渔船行政处罚信息实行按月录入公开，由市支队办公室、县级渔政执法机构各自负责本级渔船行政处罚信息的录入，每月的渔船行政处罚信息应在次月初5日前完成录入。
(
四)渔船燃油补贴信息。
渔船燃油补贴信息按审核发放的批次录入公开，由各县区渔业主管部门负责将本县区每期渔船燃油补贴发放花名册报送市局计划法规科审核并及时录入。
(
五) 投诉信息处置。
由局办公室负责按照来信来访投诉件处置办法规定进行处置，反馈意见需录入系统公开反馈的应经局分管领导审核后录入。
五、系统管理
系统设置用户信息、用户权限管理功能，实现对机构的维护、管理和用户权限分配、管理。由市海洋与渔业执法支队办公室指定专职系统管理员进行管理，委托莆田市电信分公司进行系统日常维护管理，保障系统正常运行。
六、监督管理
系统设置监督管理窗口、政务公开窗口，实现对渔船管理相关环节权力运行、工作进展等进行实时监督管理，切实加强廉政风险防控，促进改进工作作风，提高工作效能。为加强内部层级监督，按以下分工强化日常监管。
(
一)职能部门监督：
市局办公室、计划法规科和市支队办公室、船检科、渔政渔监科负责人为渔船廉政风险防控工作直接责任人，要按照各自的职能和职责分工，充分利用系统平台，加强日常检查监督。
(
二)综合部门监督：
市局效能督查组负责渔船廉政风险防控工作的综合监督，要充分利用系统平台，加强日常检查监督，对发现存在的问题要提出整改意见，及时向局主要领导、分管领导报告，及时处理。
(
三)领导监督：
市局主要领导、分管领导和驻农业局纪检组领导及市局所属执法支队的主要领导、分管领导，要充分利用系统平台，加强日常检查监督，及时协调处理存在的问题。
