发布时间：2011-08-05 08:00
| | |

　　局机关各科室、局直属各单位：

　　根据莆田市机关效能建设领导小组办公室《关于市级政府部门、直属机构2011年度绩效管理工作自评方案的批复》（莆效办〔2011〕14号）文件精神，现将经市效能办审核同意的《2011年度绩效管理工作方案》印发给你们，请按照职责分工，进一步加强绩效管理，确保各项重大决策和工作部署的贯彻落实，力争取得更好成绩。各科室（单位）要认真对照《莆田市海洋与渔业局2011年度绩效评估指标考核表》，开展自查自评，形成各自的书面自评报告，并提供原始备查材料，于2011年12月20日前报局办公室汇总。

　　二〇一一年八月五日

　　主题词：绩效管理  工作方案  通知

　　抄送：市效能办，存档 

　　莆田市海洋与渔业局办公室           2011年8月5日印发

　　2011年度绩效管理工作方案

　　根据市委办、市府办《关于印发2011年度绩效管理工作方案的通知》（莆委办〔2011〕41号）文件精神，在认真总结近年我局开展绩效管理经验的基础上，现结合部门职能和工作实际，制定2011年度绩效管理工作方案如下：

　　一、指导思想

　　以邓小平理论和“三个代表”重要思想为指导，深入贯彻落实科学发展观，按照市委五届九次全会、十次全会和市纪委五届九次全会的部署要求，以“治庸懒提绩效促跨越”为主线，深入推进绩效管理实践，促进各单位抢抓机遇、加快发展，改进作风、注重实效，不断提高部门履职力、执行力和公信力，促进年度主要指标、重点项目和各项任务的全面落实，为服务全市“打好五大战役、大干开局之年”，推动海洋与渔业科学发展、跨越发展提供有力保障。

　　二、组织领导

　　绩效管理工作要在市效能办的具体指导和局党组的统一领导下组织实施。经研究，决定成立以局长为组长，以2位副局长和3位处级领导干部为副组长，以各科室（单位）负责人为成员的绩效评估工作领导小组，负责组织协调指导工作，下设绩效评估工作办公室，挂靠在局办公室，负责处理日常事务。

　　三、工作步骤

　　我局绩效评估工作计划分“三步走”，包括动员部署、评估准备和自我评估三个阶段。

　　（一）动员部署阶段（2011年8月上旬－2011年8月下旬）

　　组织召开全体干部职工大会，认真学习市委办、市府办《关于印发2011年度绩效管理工作方案的通知》（莆委办〔2011〕41号）等有关文件精神，由局长亲自动员部署，要求全体人员充分认识开展绩效评估工作的重要性和必要性，高度重视绩效管理工作，建立健全绩效目标工作台帐，坚持绩效目标落实情况月报和职能部门项目建设情况专报制度，不断增强做好绩效管理工作的主动性和自觉性，把思想统一到市委、市政府的重大决策上来，扎实开展绩效管理工作。

　　（二）评估准备阶段（2011年9月下旬）

　　按照市效能办对我局绩效管理工作方案的批复要求，明确工作任务，开展业务培训，让迎评工作人员掌握分项指标相关资料采集和有关数据分析的方法，做好自我评估的准备工作。

　　（三）自我评估阶段（2011年11月下旬）

　　采取定量与定性相结合的办法，按照平时记实和年终评鉴相结合原则，进行自我评估。在各行政科室和各事业单位自查自评的基础上，局绩效评估工作办公室负责汇总整理，形成综合自评分析报告，经局长审核修改后，上报市效能办，并迎接市效能办的全面考核评估检查。

　　四、工作要求

　　（一）强化领导，落实主体责任。各科室（单位）要树立正确的绩效价值观，把绩效管理作为行政管理的一项基本制度，增强主体责任意识，认真抓好落实。进一步加强对绩效管理工作的组织领导，主要负责人要亲自挂帅，局办公室要充分发挥组织协调作用，统筹协调职能部门，加强各个环节的衔接，齐抓共管，协同推进，共同努力形成绩效管理的整体合力。

　　（二）精心组织，推动长效运行。各科室（单位）要围绕职能职责，紧密结合实际，认真制定本科室（单位）的绩效管理工作方案。要从行政管理的要求出发，组织人员精心研究，努力建立以目标为导向、以实绩为核心的绩效评价体系，积极探索提升工作绩效的方法和途径，形成长效机制，做到用机制管理人、规范人、引导人。

　　（三）求真务实，确保工作实效。要把绩效管理同海洋与渔业部门的职能职责、目标任务紧密结合起来，通过绩效管理促进职能职责的发挥和工作目标的实现，促进年度主要工作任务的完成，推动全局重点工作有序有效开展。要克服功利思想，力戒形式主义，反对弄虚作假。对在绩效管理工作中弄虚作假的，要严肃追究单位负责人和有关人员的责任。
