莆田市海洋与渔业局关于落实市级行政审批项目清理结果有关事项的通知

发布时间：2014-06-05 08:00
| | |

　　各县区（管委会）海洋与渔业行政主管部门，局机关各科室、局直属各单位：

　　根据市政府《关于公布市级行政审批项目集中清理结果的通知》（莆政综〔2013〕152号）和市行政服务中心管理委员会、机关效能建设领导小组办公室《关于开展“建一流中心、造最优流程”专项梳理活动的通知》（莆行政管〔2014〕21号）文件精神，以及莆田市行政审批事项联合审核会议的布置要求，市局对市级行政审批项目开展新一轮集中清理，取消和调整了一批市级审批项目，清理后共保留行政审批和管理服务项目6项。其中，局机关3个行政科室保留行政许可和管理服务5项（行政许可2项、非行政许可1项、管理服务2项）；市执法支队保留管理服务1项。我局已按照市政府的通知要求，配合市行政服务中心对市网上审批和电子监察系统的相关审批项目数据进行修改，现将有关事项通知如下：

　　各有关科室单位要以行政服务中心标准化建设为契机，将本轮集中清理确定的时限、流程、材料以及创新机制等内容，融入行政服务中心标准体系，按照“应进全进”要求，进驻行政服务中心规范办理，进一步提高派驻窗口服务水平。

　　局派驻窗口负责人和具体经办人要依法对行政审批和管理服务项目实行动态管理，凡未列入市政府公布的事项，相关科室单位不得办理，视同取消。今后，凡依法新增、调整、下放和取消的项目，实施科室单位必须及时向局规划法规监督科备案，并上报市审改办核准。

　　附件4：

　　行政审批事项下放方案

　　1.莆田市海洋与渔业局关于直接下放

　　水域滩涂养殖使用证审核(湄洲岛)的方案

　　根据《莆田市人民政府关于公布市级行政审批项目清理结果的通知》（莆政综〔2013〕152号）文件精神，莆田市海洋与渔业局决定将本局承办的“水域滩涂养殖使用证审核(湄洲岛)”项目直接下放湄洲岛海洋与渔业行政主管部门承办。为了做好该行政审批项目的下放工作，特制定本方案。

　　一、行政审批项目的名称及其性质

　　（一）行政审批项目的名称：水域滩涂养殖使用证审核(湄洲岛)。

　　（二）行政审批项目的性质：非行政许可。

　　二、行政审批项目的法律依据

　　（一）《中华人民共和国渔业法》第十一条。

　　（二）中华人民共和国渔业法实施细则》第十条。

　　三、行政审批项目的下放主体和接收主体

　　（一）下放主体：莆田市海洋与渔业局。

　　（二）接收主体：湄洲岛海洋与渔业局。

　　四、行政审批项目的下放方式和下放程度

　　（一）下放方式：直接下放。

　　（二）下放程度：全部下放。

　　五、下放后的行政审批权限

　　县级海洋与渔业行政主管部门承办本级审批的水域滩涂养殖使用证审核（后海由市局受理）。

　　六、行政审批项目的下放和接收时间

　　自本方案公布之日起，湄洲岛海洋与渔业局按照下放的行政审批权限承办本辖区水域滩涂养殖使用证审核，莆田市海洋与渔业局不再办理。

　　2.莆田市海洋与渔业局关于直接下放

　　《中华人民共和国渔业船舶职务船员证书》（乙类四等及以下渔业船舶职务船员）的考试发证的方案

　　根据《莆田市人民政府关于公布市级行政审批项目清理结果的通知》（莆政综〔2013〕152号）文件精神，莆田市海洋与渔业局决定将市执法支队承办的“《中华人民共和国渔业船舶职务船员证书》（乙类四等及以下渔业船舶职务船员）的考试发证”项目直接下放各县区(管委会)海洋与渔业行政主管部门承办。为了做好该行政审批项目的下放工作，特制定本方案。

　　一、行政审批项目的名称及其性质

　　（一）行政审批项目的名称：《中华人民共和国渔业船舶职务船员证书》（乙类四等及以下渔业船舶职务船员）的考试发证。

　　（二）行政审批项目的性质：管理服务。

　　二、行政审批项目的法律依据

　　（一）中华人民共和国海上交通安全法》第七条。

　　（二）《中华人民共和国渔港水域交通安全管理条例》第十四条。

　　（三）《福建省渔港和渔业船舶管理条例》第三十一条。

　　三、行政审批项目的下放主体和接收主体

　　（一）下放主体：莆田市海洋与渔业执法支队。

　　（二）接收主体：各县区（管委会）渔政渔港监督机构、湄洲岛海洋与渔业局。

　　四、行政审批项目的下放方式和下放程度

　　（一）下放方式：直接下放。

　　（二）下放程度：全部下放。

　　五、下放后的行政审批权限

　　县级海洋与渔业渔政渔港监督机构承办本级审批的《中华人民共和国渔业船舶职务船员证书》（乙类四等及以下渔业船舶职务船员）的考试发证。

　　六、行政审批项目的下放和接收时间

　　自本方案公布之日起，莆田市各县区（管委会）海洋与渔业渔政渔港监督机构按照下放的行政审批权限承办本辖区《中华人民共和国渔业船舶职务船员证书》（乙类四等及以下渔业船舶职务船员）的考试发证，莆田市海洋与渔业执法支队不再办理。

　　3.莆田市海洋与渔业局关于直接下放

　　渔业船舶登记发证（只受理湄洲岛）

　　根据《莆田市人民政府关于公布市级行政审批项目清理结果的通知》（莆政综〔2013〕152号）文件精神，莆田市海洋与渔业局决定将市执法支队承办的“渔业船舶登记发证（只受理湄洲岛）”项目直接下放湄洲岛海洋与渔业局承办。为了做好该行政审批项目的下放工作，特制定本方案。

　　一、行政审批项目的名称及其性质

　　（一）行政审批项目的名称：渔业船舶登记发证。

　　（二）行政审批项目的性质：管理服务。

　　二、行政审批项目的法律依据

　　（一）《中华人民共和国海上交通安全法》第五条。

　　（二）《中华人民共和国渔港水域交通安全管理条例》第十二条。

　　（三）《福建省渔港和渔业船舶管理条例》第二十二条第二款。

　　（四）《中华人民共和国渔业船舶登记办法》第三条。

　　三、行政审批项目的下放主体和接收主体

　　（一）下放主体：莆田市海洋与渔业执法支队。

　　（二）接收主体：湄洲岛海洋与渔业局。

　　四、行政审批项目的下放方式和下放程度

　　（一）下放方式：直接下放。

　　（二）下放程度：全部下放。

　　五、下放后的行政审批权限

　　湄洲岛海洋与渔业局承办本级审批的渔业船舶登记发证。

　　六、行政审批项目的下放和接收时间

　　自本方案公布之日起，湄洲岛海洋与渔业局按照下放的行政审批权限承办本辖区渔业船舶登记发证，莆田市海洋与渔业执法支队不再办理。

　　二、申报材料

　　（一）初次检验提交材料：

　　1、受理现有渔业船舶的初次检验应提交材料：1) 检验申报书；2）船网工具指标审批文件；3）渔港监督部门船名号审批文件；4）船船舶图纸及技术文件；5）原船籍注销证明；6）进口渔业船舶技术评定书（进口船舶）；7）国家机电产品进口审批文件（进口船舶）；8）海关完税证明（进口船舶）。

　　2、受理新建造渔业船舶的初次检验应提交材料：1）检验申报书；2）船网工具指标审批文件；3)渔港监督部门船名号审批文件；4)渔业船舶设计单位资格认可证书复印件；5)渔业船舶设计图纸及技术文件或经审查批准的设计图纸、审批文件及审图意见书；6)渔业船舶修造厂资格认可证书复印件；7)船舶建造合同复印件；8)建造进度表；9)渔政部门签发的建造批准书。

　　（二）营运检验提交材料：

　　1、受理渔业船舶年度、定期和期间检验应提交材料：1)检验申报书；2)现有渔业船舶检验证书及技术文件。

　　2、受理渔业船舶的换证检验应提交材料：船舶所有人应在原证书有效期届满前3个月内提出申报换证检验。1)检验申报书；2)现有渔业船舶检验证书及技术文件；3)渔业船舶修造厂的资格认可证书复印件；4)船舶修造合同复印件。

　　（三）临时检验提交材料：

　　验船师按照《法定规则》规定执行临时检验核查现有检验证书的常规或非常规检验情况，分别按照适用的年度或定期、或期间、或换证检验的规定审查相应的文件。

　　三、法定时限：7个工作日

　　四、承诺时限：4个工作日

　　五、收费标准：《国家计委、财政部关于调整渔业船舶及船用产品检验费标准的通知》（计价格〔2000〕559号）
