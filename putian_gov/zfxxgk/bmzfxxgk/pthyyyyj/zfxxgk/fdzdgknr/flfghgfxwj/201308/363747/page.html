发布时间：2013-08-29 08:00
| | |

　　局机关各科室、局直属各单位：

　　经研究，现将《2013年度绩效管理工作方案》印发给你们，请结合工作实际和岗位职责，认真贯彻落实。

　　莆田市海洋与渔业局

　　2013年8月29日

　　

　　抄送：市效能办。

　　莆田市海洋与渔业局办公室        2013年8月29日印发


　　莆田市海洋与渔业局2013年度绩效管理工作方案

　　根据市委办、市政办《关于印发2013年度绩效管理工作方案的通知》（莆委办〔2013〕50号）文件精神，结合我局工作实际，制定本工作方案。

　　一、指导思想

　　坚持以邓小平理论、“三个代表”重要思想为指导，深入贯彻落实科学发展观，按照中央和省、市委关于加快推进绩效管理制度的要求，以优化发展环境、提供优质服务为重点，深入推进绩效管理工作实践，促进认真履职、创新管理、转变作风、优化服务，全面完成年度工作任务。

　　二、组织领导

　　为保证绩效评估工作顺利开展，我局成立机关绩效管理工作领导小组，成员名单如下：

　　三、工作步骤

　　第一阶段：制定方案、动员部署（2013年8月26日-8月31日）

　　认真对照市级政府部门绩效评估工作方案，制定局机关绩效管理工作方案。组织全体干部职工传达学习有关文件精神，进行动员部署，明确工作任务，促进有序开展。根据绩效管理工作需要，成立工作机构，组织工作人员学习培训。

　　第二阶段：组织实施、建立台账（2013年9月1日-12月31日）

　　绩效管理工作方案及时在莆田廉政网和局网站上进行公示，接受社会监督。各科室各单位要认真对照工作方案，建立绩效目标工作落实月度台账(附件2)，每月3日前将上月绩效目标落实情况报送局办公室汇总，并在局网站和莆田廉政网上公开。其中1-8月的台账应于9月3日前报送办公室统一汇总、公开。

　　第三阶段：分析汇总、自我评估（2014年1月1日-2014年1月15日）

　　严格对照工作方案确定的量化评估指标，实事求是地对本单位绩效管理情况开展自我评估，自评报告于2014年1月15日前报送市效能办。

　　第四阶段：迎接检查、完善提升（2014年1月16日-2014年2月28日）

　　各科室各单位要根据任务分工，认真收集、全面汇总有关指标及数据材料，并按照《莆田市绩效管理成效显著工作认定办法》(莆效〔2012〕4号)，积极对绩效评估成效显著工作申报加分（附件4），为2014年2月底前的市效能办绩效管理工作考核评估、察访核验、综合汇总奠定基础。根据市效能办检查反馈情况，针对存在的问题和不足，深入研究分析，制定整改措施，不断提升海洋与渔业工作科学化水平。

　　四、工作要求

　　㈠统一思想认识。要把开展绩效管理、绩效评估工作作为促进科学发展观落实，促进职责职能发挥和工作目标实现，开展“马上就办，办就办好”活动，促进行政效率和能力提高的有力抓手，进一步提高认识，增强责任意识，逐步建立绩效管理良性机制。要深入总结往年绩效管理工作经验，认真查找工作中的薄弱环节和存在问题，加强过程监控，建立完善奖惩激励约束机制，并大胆改革创新，积极探索工作新做法、新经验，确保绩效管理工作取得实效、不断提升。

　　㈡加强组织领导。绩效管理工作涉及面广、内容丰富、情况复杂，各科室各单位要密切配合。各科室各单位主要负责人为本科室（单位）第一责任人，负责职能范围内的绩效管理工作，同时要确定专人负责绩效管理具体工作。要以严肃认真的态度、高度负责的精神抓好工作落实，在完成绩效指标的同时，配合局效能办做好资料汇总、整理和建档工作，确保工作任务完成情况有完整资料和凭证可查。

　　　　㈢努力改进作风。要以绩效的改进提升为基础，采取切实有效的措施，实现公众评议项目的整体提高。要增强服务意识，改进服务手段，优化工作流程，主动加强与人大代表、政协委员，以及相关部门和基层单位、管理和服务相对人的沟通联系，争取社会各界更大的理解和支持。要进一步加强内部管控，深入开展治庸治懒活动，严格执行考勤制度和上班纪律，突出对失职渎职行为的督查，着力打造整洁美观、优质高效、正规有序的工作环境。
