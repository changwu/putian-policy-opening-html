莆田市海洋与渔业局关于进一步加强考勤、请销假和出差报备工作的通知

发布时间：2018-03-08 16:14
| | |

局机关各科室，局属各事业单位：

为切实加强机关效能建设，增强工作人员组织纪律观念，改进机关工作作风，提高工作效率，强化考勤管理，对局机关考勤、请假销假、带薪休假、考勤奖惩措施等方面作出明确规定，特将机关考勤、请销假和出差报备等制度修订如下：

    一、考勤制度

    （一）全局工作人员必须自觉遵守市政府统一规定的上班时间，按时上下班，不迟到早退，不擅离岗位，认真履行各自岗位职责，不做与上班无关的事。

    （二）上、下班时在考勤机上签到、签退。签到、签退必须在上、下班规定时间15分钟内完成，签到时间为上午8:15以前、下午14:45以前（夏时制为15:15以前），超过15分钟签到视为迟到（特殊情况经领导批准后可延迟至30分钟），签退时间为上午11:45之后，下午17:15之后（夏时制为下午17:45之后），提前15分钟以上签退视为早退，如有事不能按时考勤的,须填写外出办事报备单经科室负责人或分管领导批准,交办公室备案，否则视为早退或迟到。每月每迟到或早退超过4次的，按事假或休假1天计算。

   （三）工作人员上班期间在市区内参加会议或因公务外出办事的，必须提前向科室负责人或分管领导报备；科室负责人报分管或主要领导审批，一般工作人员报科室负责人审批，并填写《市区内外出办事含参会参训报备单》，及时送办公室备案，紧急情况应在事后2个工作日内补办手续。外出不履行报告制度按旷工对待。参加长期培训的，应经单位主要领导批准。局领导外出办事、开会，应口头向办公室报备。

    二、出差批备制度

（一）工作人员市内下乡或市外出差应履行报备程序，并事先填报出差审批单报备联与报销联，按审批权限，经有关领导批准后方可出差，紧急情况应在事后2个工作日以内补办手续。   

（二）市内下乡或市外出差按审批权限进行审批。一般工作人员（含副主任科员、主任科员）出差，经科室负责人审核后报分管领导审批。科室（单位）负责人出差，经分管领导审核后报局长审批；其他局领导出差报局长审批。特殊情况来不及填写的，可由其他人员代为办理手续或科室负责人打电话到办公室报备，再补办相关手续，无报备联的一律视为旷工。

（三）出差审批单经按审批权限批准后，报备联送局办公室备案，报销联送局财务室作为报销差旅费凭证。

（四）局办公室负责考勤人员应搞好衔接，做好出差审批单保管工作，并按月汇总统计后于次月5日前在局政务公开栏上公布。

    三、请销假制度

（一）机关工作人员必须做到按规定程序履行请假销假手续，主要领导请假报市委、市政府领导批准，其他局领导和科室（单位）负责人请假报主要领导批准，一般工作人员（含副主任科员、主任科员）请假须经科室（单位）负责人同意，报分管领导批准，请假2个工作日以内（含2个工作日）的，可只由科室负责人批准；请假2个工作日以上的，由分管领导批准。

（二）事假、病假、带薪年休假、婚假、产假、丧假、探亲假按规定天数请。请事、病假超过规定天数的，应按照市人社局局的有关规定，扣发相应的基本工资、职务津贴和岗位津贴等。

1.事假。事假按照省公务员局、省人力资源开发办公室《关于机关事业单位工作人员事假及事假期间待遇等有关问题的通知》（莆人发[2009]284号）文执行。工作人员需要处理私人事务的，应尽量安排在双休日及本人年休假期内进行。已休完年休假的工作人员仍须占用工作时间处理私人事务的，可以请事假，但全年事假期限掌握在8个工作日。全年累计事假超过8个工作日的，从第9个工作日起，其基本工资、省规定的津贴补贴或绩效工资按日减发。其日减发计算方式为：每月列入工资基金管理的扣除改革性补贴外的应发工资总额除以21.75天。根据《关于津贴补贴发放有关问题的通知》(莆市人综〔2008〕8号)文件规定，事假当月累计5个工作日以上的，工作性津贴按50%发放；事假累计超过22个工作日的，扣发6个月的工作性津贴；一年事假累计超过44个工作日的，扣发全年的工作性津贴。国家法定节假日、休息日不计入事假假期。

 2.带薪年休假。带薪年休假按《职工带薪年休假条例》执行。干部职工累计工作已经满1年不满10年的，年休假5天；已满10年不满20年的，年休假10天；满20年的，年休假15天。年休假在1个年度内可以集中安排，也可以分段安排（原则上不超过3段），不跨年度安排。累计工作满1年不满10年的职工，请病假累计2个月以上的；累计工作满10年不满20年的职工，请病假累计3个月以上的；累计工作满20年以上的职工，请病假累计4个月以上的，不享受当年的年休假。国家法定休假日、休息日、探亲假、婚假、丧假、产假的假期，不计入年休假期。

 3.病假。病假按《关于国家机关工作人员病假期间生活待遇的规定》(国发〔1981〕52号)和《关于津贴补贴发放有关问题的通知》(莆市人综〔2008〕8号)文件规定执行。病假2天以上(含2天)要有县级以上医院证明，病假超过1个月的，由主管部门(或授权所在单位)委托莆田市第一医院或莆田学院附属医院病残鉴定小组鉴定，重病可凭医院证明。基本工资部分，工作人员病假在2个月以内的，发给原工资;病假超过2个月的，从第三个月起，工作年限不满10年的，发本人标准工资90%，满10年的工资照发;病假超过6个月的，从第7个月起，工作年限不满10年的，发本人标准工资的70%;满10年及其以上的，发本人标准工资的80%。津补贴部分，病假一个月以上的，工作性津贴按当月份应发标准的80%发放。事业单位工作人员根据《关于莆田市公共卫生和基层医疗卫生及其他事业单位绩效工资实施意见的通知》(莆政综〔2010〕149号)，当月病假累计达到或超过15天，停发岗位津贴。工作人员病假超过6个月以上的时间不计算连续工龄。

4.婚假、产假。婚假、产假按《福建省人民代表大会常务委员会关于修改〈福建省人口与计划生育条例〉的决定》（2017年11月24日）规定执行。依法办理结婚登记的夫妻享受婚假十五日。符合计划生育条例生育子女的夫妻，女方产假延长为一百八十日，男方照顾假为十五日。国家法定节假日、休息日计入婚假、产假假期。

5.丧假。工作人员直系亲属死亡时，经批准，可视情况给予1-3天丧假。

6.探亲假。探亲假按《国务院关于职工探亲待遇的规定》（国发[1981]36号）文执行，国家机关、事业单位工作满一年的正式干部职工，与配偶或父母不住在一起，又不能在公休假日团聚，即利用正常的交通工具（汽车、火车（动车及高铁）等），不能利用公休假日回家居住一夜和休息半个白天的，可以分别享受探望配偶或父母的待遇。干部职工探望配偶的，每年给一方一次探亲假30天；未婚职工探望父母的，原则上每年给假一次20天；若因工作需要当年不能探亲或本人愿意的，可两年给假一次45天；已婚职工探望父母的（不包括岳父母、公婆），每四年给假一次，假期20天。职工探望配偶和未婚职工探望父母的往返路费，由所在单位负担。已婚职工探望父母的往返路费，在本人月标准工资30%以内的，由本人自理，超过部分由所在单位负担。

（三）请假者必须事前填写请假条,按审批权限经所在科室(单位)负责人或分管领导或主要领导签署意见后用假，并按时返回销假。凡不履行上述程序擅自离岗者,按旷工对待。

（四）经组织批准参加在职学习和各种专业考试的人员,需经领导同意，持学校和有关单位的通知事先办理请假手续,按请假程序批准后方可离岗。其脱产参加集中面授的时间，应计入本人的年休假时间。面授时间超过本人可休年休假天数的，本人应提交校方面授安排通知等书面材料和书面报告，经批准同意后可不计为事假，否则按旷工处理。请假条交局办公室备案，作为年度核发绩效考勤奖励的重要依据。

    四、奖惩制度

    （一）根据市委办、市府办《2017年度绩效管理工作方案》（莆委办〔2017〕46号）文件精神，年度请病假累计超过2个月或请事假超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病假事假超期人员标准的5倍减发绩效奖励（此项规定以市里当年度绩效管理工作方案要求为准）。

（二）根据省委组织部、省公务员局印发的《关于严格确定公务员年度考核等次有关事项的通知》（闽委组通〔2010〕1号）规定，当年内旷工或者因公外出、请假期满无正当理由逾期不归，连续超过（含）2天，或者一年累计超过（含）4天，以及多次迟到、早退，经批评教育仍不改正的，当年年度考核应确定为基本称职等次；当年内旷工或者因公外出、请假期满无正当理由逾期不归，连续超过（含）4天，或者一年累计超过（含）8天的，当年年度考核应确定为不称职等次，并按照《公务员考核规定（暂行）》的相关规定执行。

（三）根据《中华人民共和国公务员法》规定，旷工或者因公外出、请假期满无正当理由逾期不归连续超过15天，或者一年内累计超过30天的，给予辞退。

（四）根据《行政机关公务员处分条例》规定，旷工或者因公外出，请假期满无正当理由逾期不归，造成不良影响的，给予警告、记过或者记大过处分；情节较重的，给予降级或者撤职处分；情节严重的，给予开除处分。

    五、督查制度

采取不定期检查办法，由副处级领导干部带队，抽调局机关各科室，以及执法支队、水技站、环境监测站、水科所、后海管理局等局属单位工作人员为成员的督查组，每月进行不少于二次的上班纪律督查，检查结果结合每月汇总情况列入当年度绩效考核内容，并作为评先评优的依据。

以上制度请严格执行，局属各单位可参照建立本单位考勤管理制度。

1.根据《职工带薪年休假条例》及国家有关规定：工作年限已满1年不满10年的，年休假5天；已满10年不满20年的，年休假10天；20年以上的，年休假15天。国家法定休假日、休息日、探亲假、婚丧假、产假的假期，不计入年休假的假期。2.科室（单位）负责人使用年休假，须经分管领导同意后，报局长审批；一般工作人员（含副主任科员、主任科员）使用年休假，须经科室负责人同意后，报分管领导审批。3.休假人员应提前安排和衔接好休假期间的工作。4.各科室内部应合理安排休假人员，确保工作不脱节。5.本申请表应报局办公室备案。
