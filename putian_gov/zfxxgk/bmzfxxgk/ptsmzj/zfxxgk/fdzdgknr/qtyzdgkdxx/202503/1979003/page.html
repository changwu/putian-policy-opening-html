莆田市财政局 莆田市民族与宗教事务局关于下达2025年省级少数民族补助资金的通知

发布时间：2025-03-06 15:37
| | |

 

莆田学院、莆田第一中学、莆田市民族与宗教事务局：

根据省财政厅、省民宗厅《关于下达2025年省级少数民族补助资金的通知》（闽财行指〔2025〕1号）文件，为促进少数民族地区经济社会发展，推动我市民族团结进步事业发展，经研究，现下达你单位2025年省级少数民族补助资金  万元（详见附表），款列“2130599—其他巩固脱贫攻坚成果衔接乡村振兴支出”科目。请严格按照有关规定，加强资金使用管理。

此次资金为省级第二批少数民族补助资金，2025年度省级少数民族补助资金市本级绩效目标一并下达。请有关单位按照省厅下发的绩效目标表加强项目实施管理，并按照《中共福建省委 福建省人民政府印发<关于全面实施预算绩效管理的实施意见>的通知》相关要求，做好绩效跟踪管理，切实提高财政资金使用效益。
