莆田市民族与宗教事务局2015年工作总结

发布时间：2016-02-02 00:00
| | |

2015年全市民族宗教工作部门认真贯彻落实党的十八大和十八届三中、四中全会精神，深入学习习近平总书记系列重要讲话精神，牢牢把握两个共同的主题，促进民族团结进步事业；以加强和创新宗教事务管理为主线，发挥宗教界的积极作用，维护宗教领域和谐稳定，为建设宜业宜商宜居莆田营造和谐稳定的社会环境。

一、深入贯彻党的民族政策

1. 深入调研，理清思路。一是深入贯彻落实中央民族工作会议精神。牢牢把握各民族“共同团结奋斗、共同繁荣发展”的民族工作主题，不断加大民族工作力度，创新工作机制，扎实开展民族团结进步创建活动。9日15日上午，我市民族宗教团结进步和谐慈善助推创城活动在荔城区西天尾镇东星民族自然村启动，推动民族团结进步事业，发挥宗教慈善优势，进一步推动我市创建全国文明城市活动深入开展；同时还积极参与第六次全国民族团结进步表彰大会，认真筛选严格把关，推荐了涵江区大洋乡坝头村书记郭乐君作为先进个人，并获得表彰。二是对接两个调研工作。省委统战部关于民族干部情况工作调研和市政协关于《福建省少数民族权益保障条例》落实情况的视察调研。三是结合“三个课题”深入调研民族工作。根据省民宗厅关于“城市民族工作”、市委统战部关于“流动人口管理”、市委农办关于“少数民族扶贫工作”等调研课题，张元坤局长等局领导多次深入各少数民族村开展调研工作，进一步理清民族村发展思路。坚持以人为本，加大帮扶力度，将挂钩帮扶工作作为改进作风和深化“三严三实”专题教育的重要内容。四是帮助民族村理清发展思路。7月9日，市委常委、统战部长林素钦率市直相关部门负责人深入涵江区白塘镇双福民族村，就该村少数民族特色村寨项目建设情况进行检查指导。在查看了回族进村寨门、郭氏祠堂修缮、鉴湖景观一期工程、村容村貌整治、民族特色文化建设等方面内容后，林素钦对双福回族村的特色村寨建设工作给予了充分肯定。同时对该民族村特色村寨建设的下一步工作提出了四点要求：把好民族特色关；把好工程质量关；把好项目规划关；把好产业发展关。镇党委、政府要做好特色村寨建设尤其要做好产业发展这篇大文章，充分开发利用双福村已有的养殖产业，把它们做大做强，增加农民收入。7月31日上午，市委常委、统战部长林素钦前往挂钩的仙游县龙华镇金溪民族村调研，并召开挂钩帮扶现场会。林素钦部长强调，镇、村干部要力求接地气，尊重群众意愿，把握群众需求，认真解决群众诉求，把实事办好，把好事办实，打造强村、富民、宜居的美丽乡村、幸福家园示范点。要因地制宜做好规划，充分发挥实施 “一村一品”的平台作用，做好做强茶产业，进一步提高村民和村集体经济收入，增强造血功能，推动金溪民族村健康、可持续发展。要创新环境治理理念，尊重自然规律，完善村道绿化、内河治理等基础设施建设，打造宜居绿色的生态家园

2. 突出特色，促进发展。一是重点扶持，加快发展。推动少数民族地区“加快发展，实现跨越式发展”是中央民族工作会议确定的发展思路，对民族地区的支持力度，只能加强不能削弱，只能加大不能减少。2015年3月，为进一步贯彻落实全国民族工作会议精神，经莆田市委常委会会议研究决定，追加2015年扶持少数民族地区发展专项资金70万，专项用于扶持西苑乡柳园村等7个民族村引进、培育和新建重大项目，要求各县（区、管委会）按规定给予1:1配套，并尽快将资金拨付到位。同时，要加强资金使用的监督管理，确保专款专用。二是转型升级，提质增效。重点发展“一村一品一业”特色产业，把民族村帮扶重点转向扶持经济发展，以民族村自身经济产业去促进我市的少数民族共同繁荣发展，帮扶由救济式向开发式过渡，实现民族村经济“输血式”向“造血式”转变。向市委农办推荐“一村一品”项目3个（前溪村金线莲和铁皮石斗、坝头村的莴笋、新窑村的陶器制作）；向市交通局推荐民族村道路修建项目6个；向市水利局推荐7个民族村水利建设项目。三是倾斜照顾，办好实事。对少数民族村的专项资金分配、村道路硬化、医疗卫生、协调金融单位发放小额贷款、组织参加各类技术培训等，给予重点考虑，优先满足少数民族群众需要。2015年我局为少数民族村向上级部门机关申报民族资金项目18个，申请补助款126万元，特色村寨1个申请60万元，高山族补助经费5万元。

3. 落实政策，保持稳定。一是认真、严格落实民族优惠政策。在民族身份变更中制作一次性告知内容，积极为少数民族群众办理民族成份证明和更改手续，上半年，按政策及时为64名符合条件的市民更改了民族成份。二是做好中高考民族学生身份证明，其中，办理中考学生 336名，高考学生7名（不含在县区办理的学生数）。同时，针对部分少数民族村贫困学生上不起大学的情况，推荐高教助学4名，为每名学生申领到3000元的学习补助。三是密切联系回族穆斯林群众代表，成立在莆穆斯林群众工作联络组，及时掌握他们的思想状况，并向市财政申请4万元专项经费，切实为他们解决设立伊斯兰教活动场所问题，引导他们融入莆田生活，加强民族团结，今年以来，我市没有发生一起因民族问题引发的矛盾纠纷及信访案件，为构建和谐社会和全面建设小康社会营造了良好的环境。四是加强少数民族人才队伍建设。开展少数民族干部队伍普查工作，建立少数民族干部队伍数据库，重视培养选拔少数民族干部和各类人才，继续抓好少数民族人口千人以上乡镇及民族村干部的配备工作。

二、依法规范宗教事务管理

1、深入开展宗教政策法规学习月活动。以贯彻实施《宗教事务条例》十周年为契机，在宗教界中开展以“国法与教规的关系”为主题的“宗教政策法规学习月”活动。5月28日在市局会议室召开全市宗教系统开展“宗教政策法规学习月”活动动员部署会议，局领导作动员部署讲话。学习月活动期间，共举办各类宗教政策法规培训班、消防演练10余期，1500多人次参加了培训。

2、进一步简政放权依法行政。为了便于群众办事，进一步压缩了审批时限，提高办事效率。2015年，我局共办理2件行政许可和1件公共服务事项，办理答复了2件人大建议和3件政协提案，办结率100%。6月底，按照市政府及市审改办的要求，参照省厅的“清权”目录，清理后，莆田市民族与宗教事务局行政权力事项共4类23项。行政审批1项、行政处罚7项、行政监督检查9项、其他6项。

3、重点抓好宗教活动场所安全检查及财务监督。每季度组织一次安全大检查，由局领导带队，分成四个小组深入各县区、各宗教活动场所进行安全检查，对发现的安全隐患，责成有关县区和场所整改到位。8月27日莆田市在城关基督教堂召开全市宗教系统安全工作分析会。会上各县区和各宗教团体分别汇报了安全生产月开展情况、宗教活动场所安全排查情况、存在问题及整改措施。张元坤局长对各个县区安全工作存在的问题进行点评，同时传达全省天主教专项工作电视会议精神。会议指出，当前正值抗日战争胜利纪念日关键时期：要加强领导，统一思想；要突出重点，狠抓整改；要加强宣传，营造氛围；要加强监管、追究责任。4月份，统一委托审信会计事务所对5个全市性宗教团体进行财务审计，查找各宗教团体财务管理中存在的问题，完善财务管理制度。

4、加强宗教界人才队伍建设。为进一步加强宗教界后备人才的储备培养，我局下发《关于推荐宗教团体后备人才的通知》，按照政治上靠得住、学识上有造诣、品德上能服众、关键时起作用的要求，决定每个宗教团体推荐10个人选作为全市性宗教团体后备人才进行培训锻炼。

5、开展南少林“禅修习武”工作。根据2015年市政府工作主要任务分解表的要求，我局对于南少林“禅修习武”工作进行了布置，主要开展以下几项工作，一是开展南少林赏花制茶活动；二是举行南少林寺佛像开光法会；三是举办南少林水陆法会。

6、继续开展以“教风”为主题创建和谐寺观教堂活动。转发《国家宗教事务局关于2015年继续以“教风”为主题开展和谐寺观教堂创建活动的通知》的通知，3月18在东山祖祠召开动员部署会议，积极探索各种适合各宗教特点的创建活动，不断创新载体，丰富创建活动内容。如：佛教开展“内修三学，外显三风”活动，道教开展“庄严道相、端正道风”活动，天主教开展“潜心灵修、提升信仰”活动，基督教开展“做光做盐、荣神益人”活动。结合国家宗教事务局倡导的佛道教场所加强文明进香、建设生态寺观活动，进一步治理佛道教乱象，树立佛道界的良好形象；结合国家宗教事务局通报河南基督教张少杰案例，进一步规范基督教原教派问题、私设聚会点问题、跨区域讲经讲道问题，不断促进基督教界人士和谐团结、服务社会。

7、举办第五届中国（莆田）南少林武术文化节。第五届中国（莆田）南少林武术文化节于11月8日至11日隆重举行，向世界展示南少林名扬天下的禅武文化。武术文化节开幕式于11月8日晚7：20在莆田市体育中心举行，主题为《盛世雄风》，时长65分钟，分《豪情壮志》、《名邦风采》、《中华追梦》3个篇章，共11个节目。开幕式表演以大场面、快节奏、真功夫为主，在编排上突出新、奇、险，充分展示南北少林功夫艺术和莆田非遗拳种南拳风采。除了开幕式表演，本届武术文化节还有武术比赛、佛艺展、禅文化交流展示等系列活动。11月8日至11日，首届中华佛教文化艺术精品展在莆田市体育中心田径场举行，近500个展位和19个大型特装区集中展示中国多地的佛教文化艺术精品；11月10日至11日，本次武术节新增的项目——武术比赛在莆田市少体校举行，15个代表团近200名武林高手角逐金、银、铜奖；11月8日至11日，南少林寺举行禅文化交流、展示活动。

 

三、加强机关效能建设

1. 抓学习教育。5月25日，局党组书记、局长张元坤同志带头讲党课，正式启动我局“三严三实”专题教育，张元坤局长要求，每位党员干部始终要保持共产党人的蓬勃朝气、昂扬锐气、浩然正气，始终牢记和保持共产党人的纯洁性和先进性，努力争当一个讲政治、重品行、做表率和忠诚的好干部。

2. 抓党风廉政。5月18日，我局召开了党风廉政建设专题会议，张元坤局长根据中央改进作风的八项规定，结合民宗部门实际，要求全体民宗干部增强党性，坚定信念，真心实意关心少数民族、宗教界人士和广大信教群众，帮助解决实际困难，使他们切实感受到党和政府的关怀和温暖。同时张元坤局长还与各分管领导和各科室、中心负责人签订了《莆田市民宗局党风廉政建设责任书》和《市民宗局廉洁从政承诺书》。深入开展廉政风险防控，严格控制“三公”经费支出，规范行政权力运行，加强关键环节监督，保障重大决策部署的贯彻落实。

3. 抓作风转变。以深入开展“三严三实”专题教育为抓手，进一步加强我局机关效能建设，深化政风行风和效能建设，保证政令畅通，改进工作作风、提高行政效能，促进依法行政，加大治理“庸、懒、散”力度，今年以来没有发生一起因机关作风问题而被投诉的案件，进一步提高了机关工作效率，树立民宗部门良好的形象。
