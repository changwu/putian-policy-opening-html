莆田市民族与宗教事务局2016年工作总结及2017年工作思路

发布时间：2016-12-30 00:00
| | |

2016年全市民族宗教工作部门认真贯彻落实党的十八大和十八届五中、六中全会、中央民族工作会议以及全国和全省宗教工作会议精神，牢牢把握两个共同的主题，促进民族团结进步事业；以加强和创新宗教事务管理为主线，发挥宗教界的积极作用，维护宗教领域和谐稳定，为建设美丽莆田作出积极的贡献。

一、深入贯彻党的民族政策

（一）加强宣传教育，维护民族团结。

1、认真开展民族团结进步宣传活动。积极配合市政协做好《回族百年实录》征稿，从5月份起邀请民族界名人及侨乡时报记者深入坝头村、双福村、南下村、芹山村、沧溪村进行采编，围绕美丽乡村、先进人物、历史名人、回族村演变等课题报送6篇文章。并以县乡换届为契机，广泛深入宣传党的民族政策和法律法规，推动党和国家民族政策的贯彻落实；3月14日向市委组织部、市委统战部拟文《关于在县乡换届选举中配备少数民族干部的报告》，建议按政策配齐配足少数民族干部。乡镇换届后，全市少数民族人口千人以上的乡镇中共配有一名正科级干部、七名副科级干部，并推荐3名45岁以下的少数民族处级干部参加全省第十期少数民族干部培训班。

2、抓好民族团结进步试点创建工作。5月份积极争取将前溪村纳入全国第三批民族特色村寨的申报工作，争取20万元资金作为前期启动资金。开展各种形式的民族团结进步创建活动，抓好兴安社区和坝头村的试点创建，兴安社区结合全市创建文明城市开办民族团结进步创建教育基地，开通热线电话，8月份市民族经济发展促进会慰问了10名民族贫困老人和学生，11月份举办民族团结模范先进个人图片展，张贴了创建文明城市公益公告，通过创新形式、形成载体、依托阵地，充分发挥了试点的辐射和引领作用。坝头村结合红色旅游修复民族古民居，做好环境整治，挖掘乡村旅游资源，确保创建工作有序开展。9月份，全市在涵江区萩芦镇南下村举行民族团结进步宣传月活动启动仪式，通过走访穆斯林群众、制作民族团结教育宣传栏、举办实用技术培训等形式，大力促进民族团结进步系列活动的深入开展。

3、加大民族村实用技术培训力度。坚持实际实用实效的原则，以“现代农业农村新理念”为主题，邀请市县有关专家，重点围绕民族村的农作物种植、养殖技术以及农作物病虫害防治、农民转移就业等方面，对民族村的干部及群众进行培训, 9月份在仙游县砺山村、涵江区南下村举办2期实用技术培训班，提高少数民族群众发展生产的能力。

（二）落实民族政策，促进民族村发展。

1、认真编制发展规划。7月份牵头市委统战部、市财政局、市农业局、市教育局等有关部门编制和实施“十三五”少数民族事业发展规划，从推动少数民族乡村加快发展、提升挂钩帮扶民族村实效、加大少数民族造福工程支持力度、繁荣发展少数民族文化事业、加快发展民族教育卫生事业、不断推进民族团结进步事业等七个方面，统筹全市各级各部门的力量，在民族村发展的政策资金项目技术和信息上予以大力扶持，为促进民族村发展生产，增加收入，改善生产生活设施奠定了基础。

2、帮助民族村理清发展思路。认真做好人均4500元以下贫困村及高山族贫困户的调研工作，帮助民族村做好“十三五”发展规划。6月份制订出台《莆田市少数民族补助资金管理办法》，加强和规范我市少数民族补助资金的管理，提高资金使用效益。认真做好项目资金的申报工作，抓好项目的筛选、评审和推荐工作，积极争取资金、重点用于民族村基础设施建设，全市共上报15个项目，争取133万元专项资金。并首次将市级民族补助款按县区少数民族人口比例予以分配。

3、加大民族村帮扶力度。5月份以市委办、市府办的名义下发《关于继续做好挂钩帮扶民族村工作的通知》，实现全市民族村挂钩帮扶全覆盖，由市直部门牵头，县区、乡镇及财政部门每年各筹措至少10万元，共同挂钩全市11个民族村。据了解，11个市直挂钩部门都先后召开了帮扶现场会，共筹集235万元资金，其中最少10万元，最多34万元，为民族村发展发挥政府部门的积极作用。推荐上报柳园村、前溪村、游洋村及南下村纳入全省少数民族贫困村，申报每个村每年补助20万元扶持特色产业发展，引导民族村消除“等靠要”的依赖思想，增强脱贫意识，并积极争取把民族经济发展纳入全市扶贫范围，争取早日脱贫致富，不拖全市后腿。

（三）抓好规范服务，做好城市民族工作。

1、抓好便民服务工作。指导县区民宗局做好民族身份更改工作，规范民族身份更改审批程序，简化手续，在民族身份变更中制作一次性告知内容，积极为少数民族群众办理民族成份证明和更改手续。4至5月份，主动对接市教育局，按照招生政策，做好中考民族学生身份证明，为405名学生办理中考身份证明，使他们享受中考总分加10分的优惠政策，县区民宗局也为参加高考的考生办理民族成分证明，为民族考生进入高校深造创造条件。

2、抓好民族文化的保护工作。做好仙游第二道德中学民族班助学金的申报工作，要求学校建立少数民族学生档案，确保落实民族学生每人每年1000元的民族教育优惠政策。按照“保护为主、抢救第一、合理利用、传承发展”的方针。做好我市民族文化的保护，重点引导双福村纳入涵江区城市建设规划、坝头村纳入闽中红色旅游规划，推动我市民族文化的挖掘和保护。

3、规范流动人口的管理工作。提升外来少数民族流动人口管理服务水平，年初积极协调市教育局，协助解决16位穆斯林群众子女的读书难题。发挥穆斯林群众联络组的作用，加强管理，指导穆斯林群众联络组制订在莆穆斯林经商规定，预防和化解各类矛盾。主动以公安国保等部门联系，协助做好“古尔邦节”、“开斋节”安全保障，使外来穆斯林群众能够顺利庆祝自己的民族节日。

二、依法规范宗教事务管理

（一）召开宗教领域安全稳定联席会议。3月4日，召开全市宗教领域安定稳定联席会议。原市委常委、统战部长林素钦，副市长蒋志雄出席会议。会上，分析了我市宗教领域维稳形势、各县区汇报了维稳工作落实情况，会上梳理出来的影响我市宗教界稳定的16件个案问题，全部纳入党政工作的重要议事日程，逐件逐案进行责任分解，并列入全市绩效考核，同检查、同奖惩、同落实。在全市各级各部门努力下，年底前这些个案已全部协调解决到位，进一步化解了矛盾，确保宗教领域的和谐稳定。

（二）开展宗教政策法规学习月活动。以贯彻实施新《宗教事务条例》为契机，在宗教界中广泛开展 “宗教政策法规学习月”活动。6月8日，召开全市宗教系统开展“宗教政策法规学习月”活动动员部署会议，局领导作动员部署讲话。学习月活动期间，全市共举办各类宗教政策法规培训班5期，1000多人次参加了培训，进一步增强了法治意识，为规范宗教事务管理打下了坚实的舆论基础。

（三）进一步简政放权依法行政。为了便于群众办事，进一步取消行政审批项目和压缩审批时限，经清理，现有1件行政许可和2件公共服务事项，全年共办理3件行政许可事项，办结率100%。按照市政府及市审改办的要求，参照省厅的“清权”目录，清理后，市民宗局行政权力事项共4类23项。行政审批1项、行政处罚7项、行政监督检查9项、其他6项。使行政权力在法律规定的范围内活动，不越权、不失职，受到社会的广泛好评。

（四）继续开展以“教风”为主题创建和谐寺观教堂活动。发出《关于以“规范”为主题开展和谐寺观教堂创建活动的通知》，6月17在城关基督教堂召开动员部署会议。分学习动员、查找不足、整改落实、总结提高四个阶段来开展活动。9月30日，在涵江区江口东岳观召开2016年以“规范”为主题开展和谐寺观教堂创建活动经验交流会，各县区民宗局局长、各宗教团体负责人、市直属登记场所负责人参加会议，会上南少林寺、龙华寺、江口东岳观、文峰宫、莆田天主教堂、平海天主教堂、莆田基督教堂、莆田城关基督教堂8处场所作典型经验交流汇报。通过开展创建活动，进一步推动宗教活动场所加强对场所宗教教职人员的教育引导和规范管理，真正做到用制度管人、按制度办事，提高宗教界自我约束、自我管理、自我规范的能力。

（五）抓好宗教活动场所安全检查及财务监督。每季度组织一次安全大检查，由局领导带队，分成四个小组深入各县区、各宗教活动场所进行安全检查，对发现的安全隐患，都责成有关县区和场所予以整改。6月17日，在城关基督教堂召开全市宗教系统安全工作分析会，会上各县区和各宗教团体分别汇报了安全生产月开展情况、宗教活动场所安全排查情况、存在问题及整改措施。局分管领导对各个县区安全工作存在的问题进行点评，主要领导强调要高度重视安全工作，却不可有丝毫麻痹大意思想，确保全市宗教领域生命财产安全。今年，全市宗教领域没有发生一起安全责任事故，为社会和谐稳定做出了贡献。

（六）举办学习贯彻全国宗教工作会议精神辅导培训班8月9日举办学习贯彻全国宗教工作会议精神辅导培训班，全市宗教干部、各宗教团体、三一教协会副秘书上以上人员120人参加了培训。会议认真学习了全国宗教工作会议精神，特别是习近平总书记在全国宗教工作会议上的重要讲话。会议强调要深刻把握全国宗教工作会议对宗教界提出的要求、明确的方向，坚持党的宗教信仰自由政策，引导宗教坚持中国化方向、加强爱国主义教育，不断提高宗教团体自身建设，进一步发挥宗教界的积极作用。

（七）加强宗教界后备人才建设。为进一步培养我市宗教界后备人才，9月2日，召开全市宗教界后备人才爱国爱教培训班，全市各宗教团体120名后备人才参加会议。会上，主要领导作《坚持宗教中国化方向 提升宗教服务社会水平》专题辅导讲座。使大家明确了坚持中国化方向的重要性、必要性和紧迫性，进一步增强了爱国爱教的信心和决心，努力成为“政治上靠得住、学识上有造诣、品德上能服众、关键时起作用”的人，为国家繁荣发展发挥了积极作用。

（八）组织宗教干部及宗教团体负责人外出考察学习。4月13日，我局组织全市宗教干部、市基督教和天主教负责人前往福建神学院考察学习，受到了福建神学院院长岳清华等人的热烈欢迎。座谈中，主要领导就在校神学生生活、学习与该院莆田籍学生进行了亲切的交谈，鼓励他们要爱国爱教，珍惜学习机会，多为神学思想建设以及莆田教会的今后发展积蓄正能量。全市宗教工作干部一行前往福州中洲基督教堂、马尾基督教堂就宗教场所的规范管理问题进一步学习考察，为提升做好全市宗教工作新水平奠定了良好的基础。

（十）加强民族宗教事务管理系统建设。10月初，组织全市民族宗教业务骨干人员参加省民宗厅在三明将乐举办全省民族宗教事务管理系统培训班，按照省民宗厅关于加强民族与宗教事务管理系统建设的相关指示精神，11月初，组织各县区、湄洲湾北岸、湄洲岛群工部民族宗教业务骨干人员、市县区各宗教团体负责人和市直管场所负责人召开培训会，分数据采集、数据录入、数据核对和核验上报四个阶段开展数据库建设，争取在年底前初步完成全市民族宗教事务管理系统录入工作，为下一步加强规范管理打下坚实基础。

（十）抓慈善事业，弘扬宗教慈善优势。积极引导各宗教团体、宗教活动场所在扶贫、济困、助残、养老、助学、义诊等方面多办实事、多行善举，推动各种慈善帮扶、助人为乐活动的深入开展。2016年春节之前，组织各方资源资金，重点走访慰问了一批民族村苦难群众、孤寡老人和部分宗教界人士，开展结对帮扶民族团结实践活动。据不完全统计，2016年，全市宗教界用于开展扶贫、济困、助残、救灾、养老、助学、支教、义诊等公益慈善活动资金有19341752元，其中：佛教3794229元、道教12863865元、天主教168600元、基督教347500元、三一教2167558元。这是宗教和民间信仰活动场所在促进经济社会发展中发挥积极作用的一个重要、有效和现实的途径。

三、加强机关效能建设

（一）抓学习、突出主题教育。4月22日，局党组领导以“为维护民族宗教领域和谐稳定，充分发挥共产党员的先锋模范作用”为题给全局党员干部上了一堂生动的党课，并就我局开展好“两学一做”学习教育作出全面的布置。要求把学习教育与民族宗教工作紧密结合起来，与完成本部门各项任务紧密结合起来，实现党建工作与业务工作两手抓、两促进。局党支部要按照部署，紧密结合我局实际，切实订好学习教育计划，抓好个人自学和集中学习，丰富形式内容，扩大学习教育覆盖面，切实把“两学一做”学习教育高标准、高质量开展好。

（二）抓监督、突出廉政建设。7月4日，召开党风廉政建设专题会议，局党组领导结合我市民族宗教工作实际，作了题为《扛起责任抓落实 把纪律挺在前面》的廉政工作报告，充分肯定了2015年以来局党风廉政建设所取得的成效，部署下一步工作意见。局主要领导还与各分管领导和各科室、中心负责人签订了《莆田市民宗局党风廉政建设责任书》和《市民宗局廉洁从政承诺书》，并作了集体廉政谈话，同时严格控制“三公”经费支出，规范行政权力运行，加强关键环节监督，保障重大决策部署的贯彻落实。

（三）抓管理、突出制度规范。为加强机关作风监督管理，制定完善机关工作、机关党务、机关文明创建、机关治安管理、机关考勤等一系列制度。加强全体干部职工的管理，切实改进工作作风，保证廉洁、公正、高效。建立作风督查小组，由局分管领导牵头，不定期对机关人员在岗情况、工作情况及党风廉政落实情况进行抽查检查，发现问题立即予以纠正。加强工作人员考勤管理，严肃上班纪律，完善请假制度，规范请假手续，上班时间严禁迟到早退、随意脱岗和做与工作无关的其它事情。严格遵守党风廉政规定、严格执行中央八项规定，持之以恒的抓好作风建设。严格遵守和执行《廉政准则》各项规定要求，局领导自觉抵制不良风气，做好廉洁从政的表率。同时，加强和规范机关公车管理，没有发生公车私用现象。

四、2017年工作思路

（一）认真实施“十三五”少数民族事业发展规划。深入贯彻落实中央民族工作会议精神，按照“十三五”少数民族事业发展规划，统筹全市各级各部门的力量，在民族村发展的政策、资金、项目、技术和信息上大力扶持，促进民族村发展生产，增加收入，改善生产生活设施，并积极争取把民族经济发展纳入全市扶贫范围，争取早日脱贫致富。

（二）加大帮扶民族地区发展力度。认真贯彻落实《中共福建省委办公厅、福建省人民政府办公厅关于做好挂钩帮扶民族乡村工作的通知》（闽委办【2016】10号）、《莆田市关于继续做好挂钩帮扶民族村工作的通知》文件精神，督促市直部门和发达乡镇（街道）挂钩帮扶，实现11个民族行政村挂钩全覆盖，力争到2018年，全市民族村人均收入及公共服务达到所在县（区）平均水平，生产生活设施明显改善，与全市同步实现全面建成小康社会的宏伟目标。

（三）进一步探索外来穆斯林群众服务管理工作。充分发挥穆斯林群众联络组在维护稳定、服务发展上的积极作用，引导他们更好地融入莆田，更好地为莆田的经济社会发展作贡献。

（四）学习全国、全省宗教工作会议精神。把学习贯彻全国宗教工作会议精神作为当前和今后一个时期最为重要的政治任务和中心工作落实好。重点是要认真学习习近平总书记的重要讲话精神，深刻领会讲话内涵和要求，用会议精神指引我市宗教工作健康开展。

（五）开展宗教政策法规学习月活动。认真开展“宗教政策法规学习月”活动，重点学习新修订的《宗教事务条例》，指导各县区和各宗教团体举办学习《宗教事务条例》培训班、讲座。

（六）开展和谐寺观教堂创建活动。部署各宗教团体和各宗教活动场所认真开展和谐寺观教堂创建活动，推动建设和谐寺观、文化寺观、生态寺观。

（七）开展“宗教慈善周”工作。积极引导宗教界开展慈善活动，不断拓展“宗教慈善周”活动内容，丰富活动载体，不断推进宗教界积极服务社会。

（八）加强宗教团体建设。加强宗教团体思想、组织、作风和制度建设，更好发挥宗教积极作用。指导市道教协会做好换届工作，通过换届工作，确保宗教领导权牢牢掌握在爱国爱教的宗教界人士手中。

（九）落实党风廉政建设责任制。深入开展廉政风险防控，严格控制“三公”经费支出，规范行政权力运行，加强关键环节监督，保障重大决策部署的贯彻落实。

（十）加强机关效能建设。以绩效管理和继续以“马上就办”为抓手，深化政风行风和效能建设，提高办事效率。建立健全信息工作机制，加强信息工作，突出信息特色，把握信息报道时机，进一步提升信息工作水平。深化创建“文明单位”活动。加强政务公开工作，加大治理“庸、懒、散”力度，扎实做好信访、保密、档案、平安、计生等工作，提高机关工作效率。

莆田市民族与宗教事务局
