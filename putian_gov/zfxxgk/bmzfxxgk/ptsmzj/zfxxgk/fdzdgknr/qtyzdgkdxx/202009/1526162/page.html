发布时间：2020-08-04 09:12
| | |

局机关各科室、中心、所：

根据《莆田市机关效能建设领导小组关于印发2020年度莆田市绩效管理工作方案的通知》（莆效综〔2020〕5号）文件精神，结合本局工作实际，经研究，现将《莆田市民宗局2020年度绩效管理工作方案》印发给你们，请结合工作实际和岗位职责，认真贯彻执行。

 

        莆田市民族与宗教事务局                   2020年7月 27 日 

 

莆田市民宗局2020年度绩效管理工作方案

 

为大力传承弘扬习近平总书记关于机关效能建设的创新理念和重大实践，紧扣“强产业、兴城市、惠民生、优生态、保稳定、重党建”等重点工作，围绕依法管理民族宗教事务，坚持宗教中国化方向，进一步促进民族关系和睦、宗教关系和谐，奋力夺取疫情防控和实现经济社会发展目标双胜利，努力为推进新时代美丽莆田治理现代化贡献力量，现制定莆田市民宗局2020年度绩效管理工作方案如下。

一、组织领导

调整市民宗局机关效能建设领导小组成员，组长由林天耀局长担任，副组长由钟文斌二级调研员、陈瑞发副局长、黄祖洪四级调研员、陈宗桂四级调研员担任，成员由各科室负责人组成，下设办公室挂靠局办公室。

二、考评对象

各科室、下属机构（莆田市宗教文物管理所、莆田市民间信仰服务管理中心、莆田市天主教爱国会）及全体干部职工。

三、考评内容

重点考核业务工作、自身建设、改革创新三项内容。

（一）业务工作方面：1、贯彻落实党中央国务院、省委省政府决策部署和市委市政府工作要求情况，特别是做好“六稳”落实“六保”工作；2、2020年度市委市政府重点工作、重点目标、重大任务落实情况；3、本单位根据职能职责应承担的重点工作以及效能工作要点等落实情况；4推行任务落实“负面清单”管理，对市委市政府文件、纪要议定的有明确时间节点的事项，逾期5个工作日未落实的，要实时梳理并列入“负面清单”，强化跟踪落实，按月报送进展情况，局办公室对各科室“负面清单”进行重点“滚动”管理、跟踪督办。

（二）自身建设方面：重点考核严格执行省委“三四八贯彻落实机制”，践行“两个维护”，落实全面从严治党主体责任、发挥制度优势、推进依法办事和依法行政、提升机关效能等方面的情况，努力建设让党放心、让人民群众满意的模范单位。

（三）改革创新方面：重点考核以新发展理念引领新实践，推进关键领域改革，着力解决影响创新创业创造的突出体制机制问题，营造良好发展环境的情况。各科室要力争创出1至2项特色、亮点工作，年底由局效能领导小组选送1项最具有创新性、示范性、推广性的工作上报市效能办，参加全市集中评审。

四、考评方式

采取指标考核、公众评议、正向激励、察访核验、省对市考评结果运用相结合的方式进行。

（一）指标考核

各科室要建立工作台账，对市委、市政府下达的实质性目标任务落实情况进行常态化跟踪管理并建立“负面清单”，每月2日前报送局办公室汇总。

（二）公众评议

1、由局办公室结合年度考核民主测评适时开展；2、年底各科室提供一份500字以内的年度工作总结，由局办公室组织人员对各科室作出评价；3、根据要求认真完成“福建省网上办事大厅”、“闽政通APP”、“莆田市统一政务服务管理平台”等平台各项工作，把政务服务“好差评”工作开展情况作为公众评议的一项重要考核指标；4、积极参与县区（管委会）和市直部门互评工作。

（三）正向激励

各科室要认真贯彻落实中央、省、市重大决策部署，马上就办、真抓实干，卓有成效地完成各项工作任务，在全国、全省创出亮点品牌，争取得到表彰表扬、批示肯定、经验推广等，为我局争取正向激励加分。对正向激励事项进行常态化“滚动”管理、按季度梳理报送给局办公室。

（四）察访核验

局办公室结合日常效能督查，采用随机抽查、问题核查、明察暗访等方式，不定期组织开展察访核验。发现的问题参照《效能督查发现问题绩效考评扣分办法》（莆效办〔2016〕15号）以倒扣分形式计入绩效考评总分。被省、市察访核验扣分的人员，年度考评直接予以降档或考评等次定为一般。

五、结果汇总与运用

（一）结果汇总

处级干部绩效考评得分=分管科室绩效考评平均分－察访核验扣分。

科室绩效考评得分=指标考核得分×60%＋公众评议得分×40%+正向激励加分－察访核验扣分。

科级及以下干部绩效考评得分=科室绩效考评得分*30%+个人指标考核得分×30%＋公众评议得分×40%+正向激励加分－察访核验扣分。

（二）考评等次

考评结果分为优秀、良好、一般三个等次。（其中0＜优秀等次比例≤30%，0＜一般等次比例≤10%，评为优秀等次的处级干部不能超过单位处级干部总数的30%）。

（三）结果运用

1. 通报结果。绩效考评结果在全局进行通报。

2. 综合运用。绩效考评结果作为单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。

（1）市对我局绩效考评为优秀等次时，局主要领导直接定位优秀等次（不占单位名额），负责市对我局绩效考评的科室负责人、经办人年度考核直接定为优秀等次；市对我局绩效考评为良好等次时，负责市对我局绩效考评的科室负责人、经办人年度考核定为称职以上等次；

（2）评为优秀等次的科室，科室负责人年度考核直接定为优秀等次（存在不能评为优秀等次的其他情形除外）。评为优秀、良好、一般等次的科室，科级及以下干部年度考核优秀等次比例分别按20%、12%、8%核定。

（3）评为一般等次的科室，科室负责人一年内不推荐评先评优、提拔任用。

（4）评为一般等次的个人，一年内不推荐评先评优、提拔任用。

3. 绩效激励

（1）优秀等次、一般等次分别按照良好等次个人绩效奖金的1.2倍、0.5倍发放绩效奖金。

（2）凡受到党政纪责任追究、效能问责的人员，年度考核被评为不称职（不合格）的人员，被省委、省政府、省效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的单位人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假累计超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病事假超期人员标准的5倍减发绩效奖励。

4. 效能问责

（1）年度绩效考评结果为一般的科室（科级及以下干部），责成其向局机关效能建设领导小组提交书面整改措施。

（2）省、市效能督查发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫（含）以上处理，对科室负责人进行通报批评，存在突出问题的对局分管领导进行诫勉教育。

5.整改提升

各科室、中心、所要针对绩效考评中发现的问题，认真分析研究，查找薄弱环节，深刻剖析原因，制定整改措施，促进绩效提升。局办公室结合察访核验对整改情况进行“回头看”。

六、有关要求

（一）组织实施。绩效考评由局办公室牵头，各科室、中心、所要积极配合，要加强对上级主管部门的沟通协调，每个月12日前将省主管部门抄送省效能办的典型问题报送市效能办，并加强整改落实和跟踪协调；同时，同步将发现的各科室存在的典型问题抄送市效能办。各科室、中心、所要根据本方案的要求，按时保质保量完成各项工作。

（二）时间安排。各科室、中心、所要根据本方案，认真研究细化绩效管理各项工作；10月底各科室、中心、所要上报一项拟参加省改革创新项目评审的项目至局办公室；11月底各科室、中心、所要上报一项本年度最具有创新性、示范性、推广性的工作，由局办公室组织推选一项作为改革创新项目参加市里集中评审。

（三）压力传导。各科室、中心、所要健全并严格落实绩效运行定期分析、预警预测、点评通报等制度，重点跟踪掌握市考评指标、日常通报问题绩效运用等情况。局办公室要完善“月通报、季分析”制度，定期汇总、通报指标落实、机制创新、正向激励等情况，并通过季度分析会进行会诊、点评、督导，促进工作提升。要健全绩效差异化发放、激励约束、容错纠错等机制，把绩效考评与干部使用、评先评优真正挂钩起来，激励广大干部履职尽责、担当作为。
