关于市政协七届五次会议第2021206号提案的办理意见

发布时间：2021-08-13 16:29
| | |

 

                                        答复类别：B类

 

关于市政协七届五次会议第2021206号

                                      提案的办理意见

释宏玉委员：

您提出的关于《防止宗教文化、民族文化在大文化融合下的没落》的提案（2021206号）已收悉，本提案交由市民宗局主办，市文旅局会办。现将办理情况函复如下：

一、关于“国家应通过立法，进行保护，保证宗教文化、民族文化的自由平等发展”。

2018年2月1日起施行的《宗教事务条例》第四条规定：国家依法保护正常的宗教活动，积极引导宗教与社会主义社会相适应，维护宗教团体、宗教院校、宗教活动场所和信教公民的合法权益。第八条规定了宗教团体的职能，其中：从事宗教文化研究，阐释宗教教义教规，开展宗教思想建设。相关的民族政策法规中也明确强调要传承建设各民族共享的中华文化，继承和弘扬少数民族优秀传统文化。因此，宗教文化、民族文化的自由平等发展必然受到国家法律的保护。

《福建省宗教事务条例》（草案）征求意见时，市民宗局对保护宗教文化进行了积极呼吁，所提建议采纳吸收到《福建省宗教事务条例》第九条、第十一条。即：第九条：县级以上地方人民政府应当加大对本行政区域内具有重要历史价值、文化价值的宗教活动场所、宗教实物、重要史迹的保护和合理利用。第十一条：支持宗教团体、宗教院校、宗教活动场所和宗教教职人员在宗教文化方面与港澳台地区加强交流，增进同胞情感。

二、关于“保持各文化自身的特殊性，防止宗教、民族文化内涵的弱化”。

市文旅局在这方面的工作高度重视。一是在市图书馆馆藏结构上十分注重传统文化、宗教文化书籍的采购，在传统文化方面，采买中华书局、上海古籍出版社等普及点校型书籍成为常态。在典藏领域，注重采购经典大部藏书，为学术研究提供良好的参考资料来源。二是充分发挥市图书馆参考咨询职能，对图书馆馆藏文献、莆田历史文化进行梳理整合，出版《人文莆阳》、《文脉莆阳》用于普及宣传。三是积极投入资金购买本土书籍。自2015年起，每年投入莆田市图书馆73万元购买莆田本土书籍，建设充实农家书屋本土书柜，截止2018年，共投入280余万元购买《绶水书香》、《壶山门第》、《二十四史莆田人物传》等二十余种与莆田名人相关的本土书籍，以阅读普及莆田名人文化。

市民宗局在宗教文化典籍的收集、整理、研究和出版方面不断加大度，注重加强古刹名寺、寺院丛林的文化资料整理和保护，收集编撰了《莆田佛教寺院概览》《莆田佛教名刹简介》，并向省政协民宗委、省民宗厅、省佛协提供莆田各大寺庙相关稿件材料，为保护和弘扬宗教文化积极努力。

三、关于“重视宗教的自我完善，自我教育及依其教义实行统一而规范的管理”。

全市各级宗教事务主管部门积极支持佛教教风建设，坚持以戒为师、强化戒律，加强僧团管理。支持各级佛协加强对佛教教务指导，开展早晚功课、半月诵戒、夏季安居，开展讲经活动，普遍提高僧众综合素质。近年来，随着《宗教事务条例》《福建省宗教事务条例》《宗教团体管理办法》《宗教教职人员管理办法》等一系列的法规规章出台，下一步要继续深入搞好普法宣传，健全完善各项管理规章制度，同时要严格按照规定在宗教活动场所内部成立民主管理组织，强化集体领导和民主决策，强化共同监督，强化持规守戒，不断提升教风建设水平。坚持把做好宗教工作与开展民族团结工作紧密结合，积极探索宗教事务规范化管理模式，依法加强对宗教活动场所、宗教活动、教职人员的管理。

四、关于“民族文化的保护和传承”。

市文旅局多措并举，努力做好民族文化的保护和传承。（一）在将民间艺术带入学校、社区方面，积极组织市群众艺术馆开展非遗进社区进学校活动，与全市10所学校和10个社区进行挂钩，在每年的传统节假日和非遗日都与挂钩点联合开展非遗专题宣传工作。同时，将应用“党建+邻里中心莆阳文化驿站，努力弘扬非遗文化，通过展览表演形式开展非遗进社区活动。（二）在鼓励民间艺术者教学，传承民间艺术方面，注重加强挖掘和培养民间艺人，尊重民间自发性传承方式，全力挖掘尚存的传承地和传承人，加强对掌握非物质文化遗产技艺技能的艺人的调查登记，积极发现辅导培养民间艺人，先后培养了一大批优秀的民间文化传承人，并通过举办文化协管员培训班，一方面培训了一批基层非遗保护工作骨干，另一方面也培训培养了一批民间艺术的传承人，有力地推动了民间文化的传播和发展。同时，鼓励传承人建立传习所开展传承活动，评选出两批次共62个市级非物质文化遗产传承基地（传习所），有效促进民间艺术活态传承。（三）在各类多媒体平台，增加民族文化元素方面，拍摄《福建文化记忆-寻访老艺人》和《妈祖故里-欢乐春节》等系列专题片，全面记录丰富的莆仙传统文化，在电视、网络、社交等广为传播。同时，在市图书馆一楼设立电子文化墙，将莆田历史大事记、莆田历史文化名人、莆田春节元宵习俗等植入其中，读者只需点击触碰，即可从影像、图像等资料上了解历史，了解莆田。在传统文化传播上，局属单位还常规性举办“我们的节日”等传统节日文化普及活动，如举办“莆阳讲堂”，由莆田市图书馆莆阳书院每周定期在书院讲堂内举办地方文史方言讲座，用妙趣横生的莆仙方言讲述莆田人文历史文化 ，以留住浓浓乡愁，增强对家乡的自豪感和认同感。（四）在恢复、发展各种传统民族节日及风俗活动方面，正积极配合市政府努力打造莆田元宵等民俗文化节庆品牌，推进非遗与旅游的融合发展。

感谢您多年来对莆田市民族宗教工作的大力支持！
