莆田市民族与宗教事务局关于印发民族宗教领域安全隐患大排查大整治工作方案的通知

发布时间：2020-04-07 09:10
| | |

各县（区）委统战部（民宗局），湄洲岛、北岸党工委统战部：

根据省安办《关于泉州“3.7”坍塌事故情况的通报》、省民宗厅《关于印发民族宗教领域安全隐患大排查大整治工作方案的通知》（闽民宗办[2020]3号）、市委办市府办《莆田市房屋结构安全隐患大排查大整治百日攻坚专项行动方案》和市安办《莆田市各领域安全隐患大排查大整治工作方案》的通知要求，为了深刻汲取泉州欣佳酒店发生坍塌事故的教训，决定自即日起至2020年12月31日我市民族宗教领域开展安全隐患大排查大整治，具体方案如下：

一、总体要求

坚决贯彻落实习近平总书记关于安全生产工作的重要讲话重要指示批示精神，全面贯彻落实党中央、国务院决策部署和市委、市政府的工作要求，增强“四个意识”、坚定“四个自信”、做到“两个维护”，严守安全底线，层层压实责任，全面排查和整治安全隐患，为打赢疫情防控阻击战、保障我市民族宗教领域安定稳定创造良好的安全环境。

二、整治重点和责任分工

（一）民族领域。包括民族村、城市少数民族流动人口服务设施等。

整治内容：各级民族工作部门要在当地党委政府的统一领导和部署下，及时督促、指导民族村开展全面排查。严格落实少数民族群众居住房屋的安全管理责任，从房屋的结构安全、用电用气安全、消防安全和应急通道等方面逐一排查，特别是针对年久失修、临时改建、位于地质灾害易发地的存在重大安全隐患的建筑，要立即停止使用。

牵头领导：钟文斌

牵头科室：民族科

责任单位：各县（区）民族工作部门、民族村

（二）宗教领域。包括已登记宗教活动场所和民间信仰试点登记场所（没有登记的场所纳入所在乡镇排查及监管范围）。

整治内容：各地要坚决落实“两暂停、一延迟”的要求，全面检查宗教活动场所在建工程、消防安全、围墙安全和封闭情况等，特别是有举办养老机构和已鉴定为危房的，无证建设的“四无”房屋，以及擅自改扩建，生产、经营、居住功能混杂的“三合一”、“多合一”房屋等，要切实走到查到。对于场所消防方面存在堵塞消防车通道、疏散通道和出口，消防设施损坏、主体责任不落实、源头管控不到位，违规住人以及电动自行车违规停放充电、违章用火用电、油气等易燃易爆物品失管等安全隐患的，坚决予以纠治，对于施工存在安全隐患的在建项目，坚决予以叫停。对于检查发现的隐患和问题，要督促场所和相关责任人员限期整改，并制定落实后续监管措施。对存在严重安全隐患和拒不整改的宗教活动场所，要坚决予以关停关闭，确保宗教领域的安定稳定。疫情结束后，对举行大型宗教活动和聚集性宗教活动的场所，应要求其制定相应的应急预案并组织演练。大型宗教活动和宗教节日活动等存在人群聚集情况的，场所管理组织要预控、监测现场人流，对人员趋于安全容量时，要及时封闭入库，立即疏导分流人群，避免出现满员或超负荷举行集体宗教活动的情况。市局将适时组织“双随机”抽查，采取“四不两直”的方式对各地宗教活动该场所进行明察暗访。局宗教业务科室要负责督促、指导宗教活动场所开展全面自查，发现隐患，立查立改。

牵头领导：陈瑞发  黄祖洪   陈宗桂

牵头科室：宗教科、民间信仰服务管理中心

责任单位：各县（区）宗教工作部门

三、整治方法

本次安全隐患大排查大整治不分阶段、不分步骤，各地要立即行动，坚持边动员、边排查、边整治，把宣传发动、自查自改、隐患整改和执法问责贯穿全过程。

（一）立即拉网自查。即日起，各地民族宗教工作部门要督促当地民族村和宗教活动该场所开展全面自查，发现隐患立即整改。

（二）全面督查执法。各地宗教部门要对当地宗教活动场所开展全面安全监督检查，对检查发现的隐患，要建立台账，分批分期整改。对于危及人身安全隐患要立查立改，杜绝隐患。对于不配合、不整改的，要依法予以处罚，情节严重的予以关停宗教活动场所或吊销宗教活动场所登记证。

（三）畅通沟通渠道。近期，疫情防控是中心任务，我局已按要求建立疫情信息报送联系制度，实现点对点指导、沟通。各地要将大排查大整治情况作为一项报告内容，及时报送给市局联络员。

（四）建立长效机制。各地要将安全检查融入日常检查范畴，建立安全风险防范化解长效机制，努力将问题和隐患解决在萌芽状态，确保我市民族宗教领域的安定稳定。
