关于开展民族宗教领域公共安全隐患排查整治专项工作的通知

发布时间：2020-08-21 09:17
| | |

各县（区）委统战部（民宗局），湄洲岛、北岸党工委统战部(群工部):

今年3月，市民族宗教局下发了《关于印发民族宗教领域安全隐患大排查大整治工作方案的通知》（莆市民宗〔2020〕19号），部署开展民族宗教领域安全隐患大排查大整治专项工作。专项工作开展以来，各县（区）民族宗教工作部门强化安全红线意识，深入开展大排查大整治，取得初步成效。据统计，前期全市排查的19处危房中，已完成加固5个、正在加固1个，已完成翻建2个、正在办理翻建手续或翻建5个、不愿意就地翻建的5个，需要市、区协调的1个。

近期，长江、淮河等流域发生严重洪涝灾害。习近平总书记就防汛救灾工作发表重要讲话，作出重要指示，强调要始终把保障人民生命安全放在第一位。市委多次就防汛防台风、安全生产等工作作出具体部署。当前正值汛期，据气象部门预测，今年登陆或影响我市的台风可能偏多偏强，存在发生局地强降雨、超强台风、大洪水的可能。市委常委、统战部部长高度重视民族宗教领域安全工作，市委统战部部务会议多次研究部署民族宗教领域安全工作。全市各级统战、民族宗教工作部门要深入学习贯彻习近平总书记重要讲话重要指示精神，清醒认识严峻形势，坚持人民至上、生命至上，压实责任、勇于担当，按照省委统战部、省民宗厅《关于开展民族宗教领域公共安全隐患排查整治专项工作的通知》要求，守土有责、守土负责、守土尽责，深入开展民族宗教领域公共安全隐患专项排查整治，将防汛防台风和各项安全工作抓紧抓实抓细抓到位，确保全市民族宗教领域持续保持安定稳定。现将有关事项通知如下：

一、进一步开展隐患排查。各级统战、民族宗教工作部门要在原有排查摸底情况的基础上，结合防汛防台风工作，继续组织力量对宗教领域的公共安全隐患开展拉网式、滚动式摸排。排查工作实行三级联动，动态管理。县（区）统战、民族宗教工作部门对辖区内所有宗教活动场所进行全覆盖检查，建立全面检查风险隐患问题清单台账。市委统战、民族宗教工作部门对全市宗教活动场所进行抽查巡查，建立巡查发现风险隐患问题清单台账。所有宗教活动场所全面开展自查，接受当地党委、政府有关部门的检查，列出问题清单，逐一进行整改。各级宗教团体要主动配合统战、民宗部门，全面梳理本宗教领域活动场所风险隐患，加强工作指导，共同做好安全隐患排查整治工作。市里将对宗教活动场所和宗教团体开展“双随机”抽查，发现风险隐患及时开具整改通知书，并将问题清单纳入属地隐患清单台账一并整改。

二、进一步突出工作重点。本次排查范围为全市所有宗教活动场所（包括正在使用和筹备设立、新建、改建扩建的各类宗教活动场所），宗教临时活动地点、以及宗教界兴办的养老机构等。重点排查：发生过安全事故的宗教活动场所，过去发现存在火灾、坍塌等重大安全隐患的宗教活动场所，老旧宗教活动场所（含重点文物保护单位），地质灾害点、低洼地带、山边水边的宗教活动场所，位于人口密集区域的宗教活动场所，开办养老院或出租住房的宗教活动场所。重点整治：建筑、消防、卫生防疫、食品安全、治安、文物等方面存在的公共安全隐患，做到不放过任何一个漏洞、不漏掉任何一个盲点、不留下任何一个隐患。

三、进一步深化隐患整治。要树立“隐患就是事故”的意识，坚持边查边治、查治结合，聚焦问题清单，明确时间节点，落实整治措施。对能够马上整改的，要即知即改、立行立改；对需要一定时间整改的，要提出具体办法，列出时间表和路线图，倒排时序进度，限期整改到位；对问题复杂、一时无法解决的，要依托统战工作领导小组建立协调机制，会同相关部门会商解决。近阶段要高度警惕汛情和台风叠加风险，把保障信教群众的生命财产安全摆在第一位，坚决遏制房屋安全事故。对于因年代老旧、建设标准低、失修失养、达不到建筑安全标准而存在重大安全隐患的房屋，要采取果断措施，立即停止使用，撤出居住人员，排除隐患。该拆除的，坚决拆除；该加固的，立即委托有资质的单位进行加固。要坚持标本兼治、重点治本，深入查找问题根源，研究建立防范化解安全隐患的长效机制，坚决堵塞漏洞。要完善应急预案及配套措施，积极组织安全演练，提高应急处置能力，一旦安全事件发生时，能够及时响应，迅速控制事态，有效控制局面，以最快速度最小代价解决危机，确保宗教领域公共安全。

四、进一步落实工作责任。严格按照“党政同责、一岗双责、齐抓共管、失职追责”“管行业必须管安全、管业务必须管安全”的要求，建立健全工作责任制，压紧压实工作责任。各级统战、民族宗教工作部门对宗教领域公共安全工作负有行业检查监督、督促整改、依法处罚的职责，要牢固树立法治思维和法治观念，坚持抓结合、抓日常、抓重点、抓长效，依法依规开展好排查治理专项行动。要及时提请当地党委、政府协调有关部门履行好对宗教领域公共安全工作行政监管和督查执法职责，建立联合执法机制，加大联合执法力度，有效处置宗教领域公共安全问题。要积极推动将宗教领域公共安全问题纳入社会网格化治理体系，落实宗教工作三级网络和两级责任制，将场所公共安全纳入乡镇（街道）和村（社区）工作网格，畅通宗教领域公共安全治理的“毛细血管”。

五、指导民族乡村做好防汛防台风工作。各级统战、民族宗教工作部门要以高度的政治责任感，指导民族村在当地党委、政府的统一领导下，针对汛期可能多发的洪灾、地灾、台风等自然灾害，立足防大汛、抗大灾、抢大险，突出重点地区、重点设施，组织开展灾害风险和隐患排查。对突出问题、薄弱环节和安全隐患，抓早抓细、落实措施，全面排危除险。加强值班、监测、预警、巡查、应急处置等各项防汛防台风工作，严防严守、严管严控，防止麻痹思想和侥幸心理。关心关注边远地区、地质灾害点的困难群众，及时给予有效救助，坚决保障各族群众生命财产安全。把防汛防台风工作与决战决胜脱贫攻坚结合起来，与做好常态化疫情防控和经济社会发展各项工作结合起来，确保民族村经济社会发展有良好的安全保障。

各县（区）委统战、民族宗教工作部门要加强组织领导和工作协调，明确专人负责，结合疫情防控工作建立安全信息报送常态化制度。各县（区）统战、民族宗教工作部门于每月30日前将阶段性工作情况和《莆田市宗教领域公共安全隐患排查整治台账》报送市民族宗教局宗教科。联系人：陈宗桂、卢建炳，联系电话：0594-2221822。
