莆田市民族与宗教事务局关于印发2021年“安全生产月”和“莆田安全发展行”活动实施方案

发布时间：2021-06-03 15:45
| | |

各县（区）委统战部（民宗局），湄洲岛、北岸党工委统战部,市各宗教团体、三一教协会，市直属宗教活动场所：

根据《莆田市人民政府安委会办公室、莆田市应急管理局关于开展2021年“安全生产月”和“莆田安全发展行”活动的通知》（莆市安办〔2021〕14号）和《莆田市人民政府安全生产委员会办公室、莆田市减灾委员会办公室关于进一步加强全市应急管理宣传教育工作的通知》（莆市安办〔2021〕13号）文件要求，结合我市民族宗教工作的实际，现就开展2021年全市“安全生产月”和“莆田安全发展行”活动有关事项通知如下：

     一、总体思路

 以习近平新时代中国特色社会主义思想为指导，深入宣传贯彻党的十九大和十九届二中、三中、四中、五中全会精神，坚持人民至上、生命至上，紧紧围绕全市民族宗教安全生产工作，深入宣传贯彻落实习近平总书记关于安全生产的重要论述和来闽考察重要讲话精神，扎实推进全市安全生产专项整治三年行动排查整治工作及全市“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动，深入排查安全风险隐患，扎实推进问题整改，检查遏制重特大事故发生，切实维护宗教活动场所和信教群众生命财产安全。面向全市宗教活动场所、宗教界人士、少数民族群众和广大信教群众，集中组织开展一系列主题鲜明、内容丰富、形式多样、影响广泛的安全生产宣传教育活动，普及安全生产法律法规知识和安全常识，提高全员安全生产意识和素质，为庆祝建党100周年和莆田高质量发展落实赶超营造稳定的安全生产环境。

二、活动时间和主题

活动时间：6月1日至30日。

活动主题：落实安全责任，推动安全发展。 

三、组织机构

成立莆田市民宗局“安全生产月”和“安全生产专题行”活动领导小组，由局主要领导任组长，分管副局长任副组长，各科办负责人为成员，领导小组挂靠在局宗教科，具体负责组织、协调、指导工作。同时要求各县区宗教事务部门、各宗教团体和各宗教场所也要成立活动领导小组，确保活动的顺利实施。

四、活动内容

（一）深化习近平总书记关于安全生产、应急管理和防灾减灾救灾重要论述的宣传贯彻。

 1.加强专题学习宣传教育。紧密结合建党100周年开展的党史学习教育和“再学习、再调研、再落实”活动，深入学习习近平总书记关于安全生产、应急管理、防灾减灾救灾的重要论述和来闽考察重要讲话精神，专题学习《生命重于泰山——学习习近平总书记关于安全生产重要论述》电视专题片。教育引导信教群众强化“人民至上、生命至上”理念，牢固树立安全生产是红线、是底线、是生命线的工作理念，增强从根本上消除事故隐患的思想自觉和行动自觉，健全完善场所的安全消防规章制度，确保场所安全无事故。

（二）深入开展“专项整治集中攻坚”和“控事故、保安全、迎建党百年”专题宣传活动。

2.开展问题隐患排查整治。各县区宗教事务部门要紧密结合《全市安全生产专项整治三年行动实施方案》、安全隐患大排查大整治、“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动，各县区宗教事务部门要发动宗教团体、宗教活动场所开展一次“安全生产月”大排查大整治，确保各项排查整治任务精准推进落实。排查重点：是否存在明火进殿、用火用电有无违章、安全出口、疏散通道是否畅通、消防设施、器材和消防安全标志是否配备完整；是否存在大型活动无报批、无预案、无向主管部门报告；是否存在食品卫生问题；是否存在危房问题（C、D级危房）；是否存在在建工程施工安全问题；是否配置监控设施；是否加强文物保护管理等。要建立“两个清单”，问题隐患清单和整改责任清单。通过排查，集中消除一批安全盲区、死角和隐患，实现“零事故”月。

 3.开展安全生产应急预案演练活动。6月份，各县区宗教事务部门至少要组织各宗教团体开展一次消防安全应急培训和演练。重点宗教活动场所要组织一次安全生产应急预案演练或消防演练活动，将演练活动与加强从业人员的安全知识教育和应急结合，增强从业人员的安全防范意识，提高从业人员防灾避害和自救互救能力。通过演练活动，充实应急储备，完善应急预案。

（三）组织开展好“安全生产月”系列宣传活动

4.加强典型安全事故警示教育。各县区宗教事务部门和重点宗教活动场所要建立安全生产警示教育制度，要采取观看典型事故警示教育片、参观事故警示教育展览、现场警示会等方式开展事故警示教育，提高宗教事务干部、场所负责人以及场所安全员的安全意识。各宗教团体要结合各自实际，分别组织相关人员有针对性开展警示教育，以案释法，强化警示教育作用。

（四）开展“莆田安全发展行”宣传活动

2021年“莆田安全发展行”与“安全生产月”活动同步启动，12月份结束。各县区宗教事务部门和各宗教活动场所要紧紧围绕《全市安全生产专项整治三年行动实施方案》和“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动工作要求，突出排查整治安全隐患，宣传推广经验做法，推动场所落实安全生产主体责任，不断强化安全生产工作。

5.营造“安全生产月”活动氛围。从6月1日至30日，在少数民族村、各宗教团体、人员密集的宗教活动场所，悬挂横幅，张贴标语，设置公共宣传栏、制作黑板报等。向各少数民族群众、宗教活动场所及信教群众发放有关安全生产法律、法规及消防等方面的科普宣传材料，营造“安全生产月”活动氛围。

  6.开展安全培训宣传教育活动。各县区宗教事务部门要结合“我为群众办实事”实践活动，将安全知识宣传作为一项重要内容，积极参与场所的隐患排查、宣传、板报标语制作等工作，切实确保安全宣传走深走实。结合6月份“宗教政策法规学习月”活动，各宗教场所要组织开展一次以宗教政策法规知识、安全生产法律法规知识和安全生产基本知识为主要内容的培训活动，重点宣传《中华人民共和国安全生产法》、《中华人民共和国消防法》、《中华人民共和国国家安全法》、《中华人民共和国反恐怖主义法》、《福建省安全生产条例》、《森林防火条例》、《宗教事务条例》、《宗教团体管理办法》、《福建省宗教事务条例》、《宗教教职人员管理办法》等政策、法律法规宣传力度，提高宗教场所的安全防范意识。加强日常安全检查工作中采取赠送宣传资料、召开座谈会、现场普法等形式，面对面向基层教职人员、信教群众讲解相关法律法规知识，切实增强安全宣传的针对性、实效性。

 五、有关要求

1.加强组织领导。各县区宗教事务部门、各宗教团体和各宗教活动场所要认真部署动员，召开专题会议，确保组织到位、责任到位。主要负责人要亲自过问，分管负责人要直接负责，要成立“安全生产月”活动组织机构，制定方案，精心组织，务求实效。

2.加强组织协调。各少数民族村和各宗教团体要根据各自的情况，认真组织好具有特色、宣教性强的“安全生产月”活动；各宗教活动场所要认真组织好本场所“安全生产月”活动，同时积极参与、支持当地的各项活动。

3.营造浓厚氛围。要充分运用横幅、板报等形式，宣传《福建省少数民族权益保障条例》、《宗教事务条例》《福建省宗教事务条例》、《安全生产法》、《消防法》以及新型冠状病毒感染肺炎疫情当前防控工作有关法律知识问答等法律法规、党和政府在安全生产方面采取的一系列标本兼治、重在治本的政策措施，让“安全发展”科学理念深入人心。

4.强化督导考核。各县区宗教事务部门、湄洲岛群工部、北岸统战部要充分发挥指导协调作用，加强督促和指导，及时报送“安全生产月”活动方案、活动进展、创新亮点、活动总结等，我局将于7月份组织对各县区宗教事务部门、各宗教团体开展“安全生产月”活动情况进行抽查，并将此作为年度对各县区工作考核依据。

各县（区）人民政府（管委会）宗教事务部门请于7月5日前报送活动总结和统计表（见附件2）。
