关于落实宗教教职人员社会保障工作的通知

发布时间：2011-04-01 00:00
| | |

各县(区)民族宗教局、劳动和社会保障局、财政局、民政局、卫生局、地税局，湄洲湾北岸、湄洲岛各相关单位：

根据省领导关于“省有关部门要加强宗教教职人员社会保障工作专项检查、完善相关政策、提高办事效率，力争在今年上半年全部落实到位，把好事办好办实”的要求，以及《关于贯彻〈关于妥善解决宗教教职人员社会保障问题的意见〉的实施办法》（闽民宗[2010]144号）精神，省民族与宗教事务厅、省人力资源和社会保障厅、省财政厅、省民政厅、省卫生厅、省地税局联合下发了闽民宗[2011]17号文件《关于落实宗教教职人员社会保障工作的通知》，现就落实我市宗教教职人员社会保障工作通知如下：

一、加强领导

成立宗教教职人员社会保障专项工作小组（以下简称专项小组）。市专项小组由民族宗教局、人力资源和社会保障局、财政局、卫生局、民政局、地税局等部门组成，组长由市委统战部副部长、市民宗局局长张元坤担任，办公室设在市民宗局宗教科。各县区要相应成立专项小组，专项小组名单于3月20日前报市民宗局宗教科。

专项小组成员单位工作职责：民族宗教工作部门负责牵头组织、统筹协调，推动落实；人力资源社会保障部门负责统一受理医疗保险并开具收费单据，督促社保经办机构做好社会保险各项业务经办工作；财政部门按有关规定提供资金保障；卫生部门负责新型农村合作医疗工作；民政部门负责城市和农村最低保障；地税部门负责做好养老保险法人登记和社会保险费收缴工作。

二、参保对象

参加社会保障的对象为我市县（区）级以上宗教工作部门审核确认的下列人员：

（一）经过相关宗教团体认定、并经有关宗教工作部门备案的宗教教职人员；

（二）长期在宗教团体、宗教活动场所、宗教院校从事宗教专职活动的人员；

（三）已签订劳动合同，长期在宗教团体、宗教活动场所、宗教院校从事宗教服务保障工作的人员。

三、工作安排

1、成立机构。3月，成立市和县区专项工作小组，下发通知，对参保对象、时间安排、宣传发动、参保登记、缴费政策，征收方式、参保手续及督促检查等工作提出具体要求，作出安排。

2、学习培训。3月，召开县区专项工作小组和四大宗教团体负责人培训动员会议，解读政策，部署工作。

3、宣传发动。3月，通过深入宗教活动场所，政策上墙、媒体通告、发放指南等多种形式，多渠道向参保对象开展政策宣传，一次性告知经办流程和所需材料。

4、调查摸底。3月，民宗部门牵头进行拉网式调查摸底。各级社会保险经办机构主动配合民宗部门为宗教教职人员办理参保登记，县区填报《宗教教职人员参加社保情况调查登记表》（附件2）、设区市填报《宗教教职人员参加社保情况汇总表》（附件3），全面掌握人数、分布、参保意愿、缴费能力等。

5、身份认定。3月底前，以县区宗教工作部门为主，各级社会保险经办机构配合，按规定对宗教教职人员和工作人员做出认定。

6、参保登记。4-5月，各级经办机构通过集中受理、上门办理、开辟绿色通道等形式全面开展参保登记工作。4月底前基本完成符合条件人员参保登记。5月重点解决困难、零星人员参保登记问题。

7、落实缴费。6月底前各项参保资金应基本到位。各有关部门应特事特办，全力保障相关参保资金及时到位。对明确表示参保愿意并已完成参保登记的宗教教职人员，可以视同已参保人员，在参保登记和完成缴费义务期间发生的医疗费用，在缴费手续完成以后即可予以报销。

8、建立专报制度。自3月开始，由民宗部门牵头，各有关部门配合，每月月中、月底以报表形式联合汇总上报当地宗教教职人员和工作人员参保工作进展情况。

9、督促检查。5月，市级有关部门组织开展联合检查，听取当地宗教代表人士意见，针对发现的问题进行扫尾。

10、总结上报。7月底，由市民宗部门牵头总结工作，专报市政府和省专项工作小组。

四、督查检查

建立宗教教职人员社会保障工作落实情况督查机制，通过《宗教教职人员参加社会保障进度表》（附件4）、组织联合检查、听取宗教人士意见、召开汇报分析会、印发工作简报、总结验收等形式，确保按时完成任务。
