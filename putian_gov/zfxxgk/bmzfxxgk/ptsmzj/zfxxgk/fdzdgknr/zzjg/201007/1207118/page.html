莆田市佛教重点寺院规范管理指导意见

发布时间：2010-07-29 00:00
| | |

 

市佛教协会、各重点寺院：

佛教寺院是出家人住持修学、弘扬佛法的道场，是佛教信众过正常宗教生活的活动场所，也是联系、团结信教群众感情的桥梁和纽带。随着社会的发展、人类文明的进步，寺庙管理面临新的情况、新的问题。为了加强重点寺院管理，充分发挥重点寺院在构建社会主义和谐社会中的积极作用，根据《宗教事务条例》、《全国汉传佛教寺院管理办法》、《全国汉传佛教寺院共住规约通则》的要求，结合莆田市重点寺院的实际情况,制定本指导意见。

一、严字当头，管理规范

重点寺院规范管理的首要任务是建立健全各项规章制度。要按照《宗教事务条例》要求，结合各寺院的实际情况，组织编制《寺院管理制度汇编》，并上墙公布，做到常住人员人手一册，便于照章办事，定期检查。制度内容包括人员、财务、治安保卫、消防安全、环境卫生、文物保护、重大活动预报、请销假、基建、档案、仓库、斋堂、车辆管理、功德箱开启、佛事活动、僧人修学、共住规约等。制度建立以后，关键在于落实，重点要把财务制度、安全管理制度执行好落实好。要严格遵守《宗教活动场所财务监督管理办法(试行)》，建立一套完整的财务制度和严格的监督机制，在银行开立单位结算帐户，定期向政府登记管理机关报送财务报表。要建立安全工作的长效管理机制，严格遵守《中华人民共和国消防法》、《古建筑消防管理规则》等，切实负起安全管理责任，把安全措施落实到位、责任落实到人。重点寺院管理组织负责人的推选，要在登记管理机关指导下与市、区佛教协会进行充分协商，经市、区佛教协会考察研究同意后，按程序报政府登记管理机关备案。各重点寺院举行大型活动时，要在一个月内向政府登记管理机关报告，并制定安全工作预案。各重点寺院负责人离开本市前，要向登记机关报告。常住人员离开和返回寺院，要及时向寺院负责人报告。要加强外来僧尼和居士的管理，凡是挂单或暂住人员，要实行严格的身份登记制度。

二、道风纯正，形象较好

重点寺院负责人要高举爱国爱教的旗帜，做到政治上靠得住，学识上有造诣，品德上能服众，关键时起作用。每位出家人首先是一个合法的公民，而后才是一个合格的僧人。要坚决执行国家宗教政策和法律法规，做守法的公民和合格的僧人。作为重点寺院的出家人，对佛教知识和本地的佛教历史沿革，对本寺院的历史和景观，都要熟悉掌握，并能够熟练地进行讲解。要大力培养年轻一代的寺院管理人才和佛学研究人才，不断提高佛教的总体素质。重点寺院负责人之间要建立定期交流机制，根据工作需要组织外出参观学习，不断提高自身素质。要坚持以戒为师，坚持清规戒律双轨制。僧团要在戒律的约束下进行生活、管理和修持。要严格遵守修持制度，特别是对早晚课诵、坐禅、念佛、诵经、冬参夏学等，要长期坚持,并有专人负责并督促落实。僧尼要坚持僧装、素食、独身，讲究仪表和礼仪，体现端庄文明。不得抽烟、喝酒、荤食等违反教规的行为。不得外出营销商品，谋取私利，借教敛财。不得到娱乐场所或参与各类娱乐活动。不得在宿舍会见异性信徒，有事在客堂或公共场所会见。不得从事佛教规定禁止的其他行为。如有发现，经劝告不改者，所在寺院给予起单，由市佛教协会上报省佛教协会予以收回戒牒。

三、环境优美，香火旺盛

重点寺院不但是出家人修行的道场，同时又是旅游的胜地，一定要营造优美的环境。要树立环境整洁意识，建立健全环境卫生管理责任制，实施严格的卫生保洁制度，保持寺庙环境卫生整洁美观。对于进入寺院内的各类车辆，要有专人负责指挥，按规定停靠，实行动态管理，为广大香客、游客提供一个干净、文明、有序的环境。要保证寺庙建筑的协调美观。重点寺院改扩建时，要按照程序进行上报申批，未经政府有关部门批准的，都不得擅自改建或扩建。重点寺院改建或扩建时，事先要进行规划设计，做到建筑风格符合佛教规制，并与周围的景观相协调。佛教建筑文物修缮，要修旧如旧，保持寺院历史原貌，体现寺院的文物价值。

四、弘扬传统，慈悲济世

重点寺庙要弘扬佛教的慈善传统，积极参与慈善公益事业，在慈善公益事业上发挥表率作用。各重点寺院要成立慈善领导小组，在市佛教协会指导下开展各项慈善公益活动，年初要对全年的慈善工作作出计划安排，年终要对开展慈善公益工作进行总结。在政府的引导下，积极开展社会公益宣传，发动社会爱心人士参与社会公益事业，发扬佛教优良传统，保护自然生态环境。有条件的寺院每年要举行几场有声势的慈善活动，积极帮助困难寺院、贫困少数民族家庭和困难少数民族学生度过生活难关，促进慈善成为寺院自觉承担的社会责任，为构建社会主义和谐社会作出积极的贡献。
