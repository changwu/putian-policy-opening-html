莆田市民族与宗教事务局关于扎实开展2016年“双百结对”活动的通知

发布时间：2016-09-19 00:00
| | |
各县区民宗局、湄洲岛群工部、北岸工商联，市各宗教团体、三一教协会：

2016年是“十三五”开局之年，是全面建成小康社会进入决胜阶段的第一年，为进一步推动民族团结进步事业和创建全国文明城市，发挥宗教慈善优势，提高市民文明素质，争创一流城市文明，树立民族宗教领域的良好形象，为莆田市创建全国文明城市和建设宜业宜商宜居莆田发挥民族宗教的积极作用，经局务会议研究，决定积极引导宗教界扎实开展2016年“双百结对”暨百个宗教（民间信仰）活动场所结对百个少数民族贫困户（困难学生）活动，不断拓展“宗教慈善周”活动内容，现将活动有关要求通知如下：

一、活动时间

“双百结对”活动原则上集中安排在9月份“宗教慈善周”，爱心宗教（民间信仰）活动场所也可结合自身实际，安排开展活动，不搞“一刀切”。

二、参加对象

爱心宗教（民间信仰）活动场所自愿报名，市各宗教团体、三一教协会推荐100个宗教（民间信仰）活动场所，其中：市佛教协会20个，市道教协会30个，市天主教爱国会10个，市基督教两会20个，市三一教协会20个。

三、受资助对象

基层推荐上报的100个少数民族贫困户（困难学生）。

四、资助标准

资助少数民族贫困户的，原则上每年资助不低于1000元/户；资助少数民族困难学生的，原则上每年资助不低于600元/名，也可根据自愿原则赠送慰问品等。

五、资助方式

爱心宗教（民间信仰）活动场所可采取“一对一”或“一对多”的方式与少数民族贫困户（困难学生）进行结对。资助可通过以下三种方式，自主选择：？爱心宗教（民间信仰）活动场所可在今年“宗教慈善周”活动时资助慰问；？自行前往结对少数民族贫困户（困难学生）家中开展关爱慰问活动；？与少数民族贫困户（困难学生）联系，通过汇款方式给结对的贫困户（困难学生）。

请市各宗教团体、三一教协会加强与爱心宗教（民间信仰）活动场所沟通协调，密切跟踪“双百结对”活动的进度和落实情况，认真做好活动总结工作，并与12月上旬前将总结报送市民宗局宗教科，联系人：彭开宗，联系电话：13860945838，邮箱：pkz0594@163.com。市民宗局将及时宣传“双百结对”活动的好经验、好做法，促进民族团结进步事业和创建全国文明城市，加快推进民族村全面建成小康社会步伐，让少数民族贫困户（困难学生）感受到党和政府的关怀和温暖，享受到改革开放的胜利果实和红利。
