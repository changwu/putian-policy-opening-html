标题: 关于加强民间信仰活动场所试点管理的意见
发布时间: 2010-08-23 00:00
文号: 莆市民宗〔2010〕47号
发布机构: 莆田市民宗局
栏目: 机构职能
原始链接: https://www.putian.gov.cn/zfxxgk/bmzfxxgk/ptsmzj/zfxxgk/fdzdgknr/zzjg/201008/t20100817_1207151.htm
正文:
各县区民宗局、
北岸社会事务局、湄洲岛群工科
：
为了进一步加强和规范民间信仰的管理工作，提高民间信仰的服务管理水平，使试点管理的民间信仰活动场所内部事务管理有章、各项活动安全有序、对外交往依法依规、回报社会积极有效，根据闽委办
[2002]7
号文件和省民宗厅关于加强民间信仰管理工作通知精神，特提出我市加强民间信仰活动场所试点管理的意见。
一、
由于民间信仰量多面广、参差不齐，对民间信仰管理按照“抓大放小、循序渐进，依法管理，分级负责”的原则，实行试点管理。
二、
试点管理的民间信仰活动场所实行登记管理。登记按照下列程序实施：
（一）民间信仰活动场所的登记由该场所的管理组织向所在地县
(
区
)
人民政府宗教事务部门提出申请。
（二）县
(
区
)
人民政府宗教事务部门在受理民间信仰活动场所的登记申请后，对拟同意上报的，应当征求该场所所在地乡镇人民政府、街道办事处的意见后，报市人民政府宗教事务部门批准。
（三）经批准同意后，民间信仰活动场所由所在地县
(
区
)
人民政府宗教事务部门负责登记。
三、
试点管理的民间信仰活动场所登记须具备下列条件：
（一）当地群众有经常进行民间信仰活动的需要；
（二）有健全的民主管理组织和管理制度；
（三）布局合理，不妨碍周围单位和居民的正常生产、生活；
（四）有正常开展民间信仰活动所必要的资金；
（五）规模较大，主殿一般达到
100
平方米。
四、
申请试点管理登记的民间信仰活动场所，应填写《民间信仰试点管理场所登记申请表》，同时提交下列材料：
（一）拟登记地点和民间信仰活动场所的情况说明；
（二）民主协商成立管理组织的情况说明；
（三）管理组织成员的基本情况、户籍和居民身份证明；
（四）有关管理规章制度的文本；
（五）合法的经济来源的情况说明；
（六）拟登记场所使用土地和房屋的有关证明；
（七）需要提供的其他有关材料。
五、
试点管理的民间信仰活动场所实行民主管理。民间信仰活动场所的管理组织应当由该场所经常参加民间信仰活动的群众代表民主推选、协商组成，并报所在地县
(
区
)
级人民政府宗教事务部门备案。
试点管理的民间信仰活动场所的民主管理组织成员应当拥护中国共产党的领导和服从政府的行政管理，群众基础好，有一定的文化水平和组织管理能力。
试点管理的民间信仰活动场所管理组织履行以下职责：
（一）负责本场所人员和经常参加该场所民间信仰活动的群众的教育和管理；
（二）安排本场所的民间信仰活动和内部事务；
（三）管理、使用本场所的房屋、收入及其他财产，维护本场所的合法权益；
（四）每年向登记机关报告上年度的财务和管理情况；
（五）管理本场所的其他事务。
六、
改建、扩建民间信仰活动场所应当由该场所管理组织提出申请，经原登记机关和市人民政府宗教事务部门同意后，再向有关部门申请办理基本建设工程等手续。
七、
试点管理的民间信仰活动场所应当依照有关法律、法规、规章的规定，建立健全人员、财务、会计、治安、消防、文物保护、卫生防疫、档案、环境保护等管理制度，接受所在地人民政府有关行政管理部门的业务指导、监督和检查。
八、
试点管理的民间信仰活动场所举行大型民间信仰活动和跨行政区域的民间信仰活动，试点管理组织应提前二个月主动向乡镇人民政府提出申请。超出本村（居）范围活动的，经乡镇人民政府（街道）同意后，报县
(
区
)
宗教事务部门和公安机关备案。乡镇人民政府要指导场所做好安全工作。
对跨乡镇活动，由主办场所所在地的乡镇把关审核，拟同意的报县
(
区
)
宗教事务部门审批，报设区市宗教事务部门和公安机关备案。县
(
区
)
宗教事务部门要及时向分管领导汇报，由分管领导召集统战、民宗、公安、交警、消防、卫生防疫和街道（镇）等部门，研究协调活动保障方案，明确分工、责任到人，并做好突发事件的处置准备。
九、
利用民间信仰活动场所和民间信仰活动进行违法犯罪活动的，由有关部门按照国家法律、法规依法追究相关责任。
登记管理机关对违反政策和本办法规定的民间信仰活动场所及其管理组织应进行批评教育并责令整改，情节严重和逾期不整改的应整顿管理组织直至撤消试点管理登记。
十
、
《民间信仰试点管理场所登记申请表》和《民间信仰试点管理场所登记证》的格式由市人民政府宗教事务部门统一制订。
《民间信仰试点管理场所登记证》不得涂改、转让、出借。证书遗失的，应当及时向登记管理机关申请补办。
十一、
试点管理的场所要积极开展精神文明进民间信仰场所活动，按照爱国爱教、知法守法、团结稳定、活动有序、教风端正、管理规范、安全整洁、服务社会的要求，不断地提高规范管理水平，促进内部关系更加和谐，为我市的经济社会发展作出应有的贡献。
