莆田市民族与宗教事务局关于开展“比服务”活动的工作方案

发布时间：2015-05-12 00:00
| | |

局机关各科室、中心、所：

按照市效能办《关于印发（莆田市开展“比服务”活动的工作方案）的通知》（莆效办【2015】7号）和市委办、市府办《关于印发（莆田市落实“三比一看”活动的工作计划）的通知》（莆委办发【2015】11号）要求，为推动“比服务”各项任务落实，现制定工作方案如下：

一、目标要求

通过开展“比服务”活动，力争实现“四促进”：一是促进机关效能进一步提升，“马上就办”理念得到自觉践行，效能制度得到有效落实，办事效率得到切实提高；二是促进机关作风进一步改进，“四下基础”优良传统得到弘扬，干部为基层排忧解难能力得到加强，基层反映的突出矛盾和实际问题得到基本解决；三是促进行政服务进一步优化，审批更简便，管理更规范，服务更主动，办事更透明；四是促进要素保障进一步落实，项目用地、用林、用海、资金、征迁等难题得到及时有效解决，征迁工作和谐顺畅，政银企合作密切。

二、活动内容及任务分工

整个活动围绕“提高政府效能”、“深入基层一线”两个方面，现将任务分解细化为5项任务。

（一）提高政府效能。重点比思想解放不解放，比放权力度大不大，比行政审批事项消减、审批服务方式创新、审批流程优化、审批事项缩短、行政审批和公共服务事项网上办理，以及下放的行政审批事项承接办理等情况。

1、消减行政审批事项。按照“能减则减、能放则放、能快则快、能优则优”的原则，对我局保留的4项行政许可和公共服务事项，进一步精简，凡与公共利益无关，市场竞争机制、行业组织可自主调节，或行政机关采用事中、事后监管等方式能够解决，以及没有办件量的事项，一律不再保留为行政审批事项。

责任科室：宗教科、民族科；完成时限：12月份

2、落实三张“清单”。推行政府行政权力清单制度，做到“法无授权不可为”；探索政府部门责任清单，针对不同岗位明确各自责任，分级细化责任归属、确定具体责任承担者，做到“法定职责必须为”；完善公共服务事项清单，汇总审批目录清单，形成审批要素信息库，实行动态调整。

责任科室：宗教科、民族科；完成时限：12月份

3、优化审批流程和缩短审批时限。推进行政审批标准化、规范化，推动承诺件转为即办件，进一步提高即办件比重和当日办结率。进一步规范现场勘查、集体讨论、专家论证、社会听证等环节，明确办理时限。以“三减少、两提高、一促进”为目标（即减少项目、收费、时限，提高服务效率、服务质量，促进公平竞争），持续规范行政审批中介服务行为。积极推行并联审批。

责任科室：宗教科、民族科；完成时限：12月份

4、做好下放的行政审批事项承接办理。建立我局统一审批目录清单，对近年来我局取消、下放、调整的审批事项进行梳理汇总形成目录库，对“放、接、管”三到位情况进行逐项核查。

责任科室：宗教科、民族科；完成时限：12月份

（二）深入基层一线。重点比下基层解决问题的情况。

5、基层“四下基础”。提高干部为基层排忧解难的能力，及时协调解决基层反映的困难和问题，切实做到发现问题在一线，化解矛盾在一线，工作落实在一线。局领导干部每月专题研究基层群众反映的突出问题，及时帮助解决。

责任科室：办公室、宗教科、民族科；完成时限：12月份

三、保障措施

（一）加强日常跟踪。各科室要根据“比服务”内容要求，认真开展各项活动，并于每月8日前将进展情况（见附表）报送局办公室。

（二）强化效能督查。要把“比服务”情况作为今年效能督查的重要内容，与落实“行动计划”督查相结合，督促各科室明确工作推进机制，确保各项任务落实到位。

（三）纳入绩效考评。把开展“比服务”情况纳入我局绩效考评指标体系，实行奖优罚劣。

（四）严格效能问责。要按照《福建省机关效能工作条例》、《福建省机关效能投诉奖惩办法》等规定，认真办理群众反映的工作人员作风和效能问题，一经查实，严肃处理。对“比服务”活动任务不落实、活动情况填报不实和报送不及时的，要予以通报问责。
