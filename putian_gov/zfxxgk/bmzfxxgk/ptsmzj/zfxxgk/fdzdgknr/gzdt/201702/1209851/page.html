莆田市民族与宗教事务局2016年度民主生活会情况报告

发布时间：2017-02-13 00:00
| | |

市纪委：

根据市纪委、市委组织部《关于认真开好2016年度全市县以上党和国家机关党员领导干部民主生活会的通知》（莆委组通〔2016〕53号）精神，我局于2017年1月20日召开了2016年度局领导班子民主生活会。市纪委蔡志明主任莅会指导，局机关部分党员干部、少数民族村和部分宗教界代表共6名列席会议。整个会议民主氛围浓厚，自我批评中，见人见事见思想，把自己摆进去、把职责摆进去、把思想和工作摆进去查找不足，进行党性分析，明确整改方向。相互批评时，坦诚相见、开门见山，针对性和操作性强，看得见、摸得着。现在将有关情况汇报如下：

一、高度重视，周密部署

局领导班子对这次民主生活会十分重视，把重点放在会前，扎扎实实做好各项准备工作。

（一）深化学习研讨成果。严格按照《莆田市民族与宗教事务局开展“学党章党规、学系列讲话，做合格党员”学习教育实施方案》，组织领导班子成员认真学习习近平总书记系列重要讲话特别是在党的十八届六中全会上的重要讲话精神和对福建工作的重要指示，深刻领会省第十次党代会、省委十届一次全会精神和市第七次党代会、市委七届一次二次全会精神，理解党章和《中国共产党廉洁自律准则》、《中国共产党纪律处分条例》等规章制度。仔细研读《习近平谈治国理政》、《习近平关于党风廉政建设和反腐败斗争论述摘编》、《摆脱贫困》和《习近平总书记系列重要讲话读本（2016年版）》等重要书目，围绕专题定期开展集中研讨，充分认识新形势下加强和规范党内政治生活、加强党内监督的重要意义，切实增强加强党内政治文化建设，扎扎实实打牢了开好局领导班子民主生活会的思想基础。

（二）广泛征求意见建议。发放征求意见表30份，2017年1月6日召开座谈会，广泛征求市直机关各相关单位、县区民宗局、各民族村和宗教团体等方面的意见，共征集到对局党组班子和个人的意见和建议共6条，涉及下基层、干部队伍建设、民宗业务学习培训等方面，并原汁原味向局领导班子及成员本人反馈。

二、严格程序、精心准备

（一）深入开展谈心活动。局领导班子成员之间结合日常工作，主动开展谈心活动，坦诚相见、沟通交流、相互提醒，认真按照“三必谈”的要求：局主要领导和每个班子成员必谈、班子成员相互之间必谈、班子成员与分管科室负责人之间必谈。谈心谈话坚持一对一、面对面，既谈工作问题、也谈思想问题，既谈自身差距、也谈对方不足，班子成员对其他每位成员的批评意见不少于2条，做到充分沟通、严肃对待，真正放下了包袱、加深了理解、消除了隔阂、增进了团结。

（二）认真进行对照检查。坚持严的标准、严的措施、严的纪律，领导班子的对照检查材料由局主要领导亲自主持起草，并督促班子成员紧密联系自身思想和工作实际，结合征求到的意见建议，认真撰写个人对照检查材料，从理想信念、政治纪律和政治规矩、作风、担当作为、组织生活、落实全面从严治党等方面，进行党性分析，深入剖析根源、认清问题实质，提出整改的具体措施。

三、围绕主题，坦诚相见

会上，局党组书记、局长张元坤首先代表局领导班子作对照检查，从理想信念、遵守政治纪律和政治规矩、作风、担当作为、组织生活和落实全面从严治党主题责任六个方面深刻剖析查找突出问题，对问题产生的原因进行认真深入分析，并提出了下一步整改方向和措施。

随后，局主要领导带头作自我批评，带头查摆问题，带头接受各位班子成员的批评意见。班子其他成员逐一发言，查摆自身存在的不严不实突出问题，严肃认真开展了批评和自我批评。相互批评时应直奔主题，开门见山，不绕弯子，不说客套话，真正做到“深”到位，“痛”到度，“警”到点，使局领导班子成员真正受到了一次深刻的思想洗礼。

最后，局党组书记作了表态发言，对下一步的整改工作，提出了三点意见：一要以从严从实的态度，狠抓整改落实。领导班子每位同志要从我做起、从现在做起，进一步提高整改的针对性和操作性；尽快细化整改方案，明确整改目标、措施、责任人和时限，确保问题件件有落实，事事有回音。二要根据查摆和对照检查出来的问题情况，结合我市民族宗教工作实际，进一步完善制度规定。切实加强对遵纪守规情况的日常监督和定期检查，加强干部日常监督管理，要立行立改，接受党员、群众监督。三要坚持领导干部带头，身体力行。带头遵守党的政治纪律和政治规矩，要进一步严格党内政治生活制度，严肃政治纪律、组织纪律、廉洁纪律、群众纪律、工作纪律，把纪律和规矩挺在前沿，推动形成积极向上、干事创业、风清气正的政治生态，在更高起点上为打造宜居港城、建设美丽莆田营造和谐稳定的社会环境。

通过此次专题民主生活会，局领导班子成员对自身存在的问题与根源有了更加清醒的认识，对下一步整改方向和目标有了清晰的把握，一致表示将结合开展“两学一做”学习教育和我市民族宗教工作实际，下大气力抓好整改落实，建立健全作风建设长效机制，确保各项工作取得新成效，班子整体形象有新提升。

 

 

莆田市民族与宗教事务局

2017年2月6日

抄报：市纪委驻市府办纪检组
