莆田市民族与宗教事务局关于开展“进百村入千企访万户”主题实践活动实施方案的通知

发布时间：2012-03-30 00:00
| | |

局各办、科、中心、所、局党支部：

按照市委部署，为了落实“四下基层”活动，推动我局机关干部转变作风、深入基层、解难题、办实事，现把《莆田市民族与宗教事务局开展“进百村入千企访万户”主题实践活动的实施方案》印发给你们，请认真贯彻执行。

莆田市民族与宗教事务局

2012年3月26日

莆田市民族与宗教事务局开展“进百村入千企访万户”

主题实践活动的实施方案

按照市委统一部署，为推动机关干部重心下移，深入基层为民服务，根据《中共莆田市委关于印发开展“进百村入千企访万户”主题实践活动的实施方案的通知》（莆委[2012]18号）精神，特制定本方案。

一、指导思想

以迎接党的十八大召开为主线，以深入基层服务群众为主题，以转变机关作风、促进发展为目标。

二、目标任务

组织机关党员干部深入秀屿区东庄镇堤头村，以配齐配强村级班子为重点，达到推动发展、促进和谐、服务群众、加强基层的目标。

（一）进村访户，了解民情。

组织党员干部进驻挂钩村，每次有一名分管领导带队，采取召开座谈会、发放调查表、实地考察、上门走访等方式，与群众面对面交流，全面了解村情村貌、组织建设、经济发展以及群众生产生活等情况，掌握面临的主要困难和问题。

（二）综合分析，形成报告。

全体党员干部进村访户时要认真做好登记，详细记录了解问题，然后综合各位党员干部的日记，形成一份比较完整的调研报告。

（三）出谋献策，形成规划。

充分发挥单位和党员个人的优势，结合村情村况，围绕现代农业、培养新型农民、促进农民增收，帮助村两委完善发展规划等。

（四）做细工作，配好班子。

以村级组织换届为契机，认真听取村干部、党员、村民代表等各层面人员的意见建议，对过去影响换届工作的各类问题认真分析，做细思想工作，制定整改措施，化解矛盾，消除不安定因素，指导做好村级换届选举工作。

（五）结对帮扶，解决困难。

选择一些家庭困难户，认真分析致困原因，根据实际情况，形成结对帮扶，“一帮一、多帮一”等模式，解决面临的实际困难。

（六）集中精力，办好实事。

帮助挂钩村筹措资金，解决好群众最关心、最直接、最现实的利益问题。如路灯、供水、供电等基础设施，方便群众生产生活。加强环境卫生综合整治，开展农村“家园清洁行动”，搞好村庄绿化，改善村容村貌。

（七）深入学校，解决困难。

深入村所在学校调研，了解学校办学情况，为学校发展、改善办学条件、提升办学质量献计献策。

三、方法步骤

主题实践活动从今年4月上旬开始，12月底基本结束，具体分动员部署、走访调研、破解难题、巩固提升四个步骤。

（一）动员部署（4月上旬）。制定下发主题实践活动实施方案，4月中旬，对活动进行全面动员部署。深入动员、统一思想，明确活动的目标任务、方法步骤和工作要求，引导党员干部在服务基层、服务发展、服务群众中创先进、争优秀。

（二）走访调研（4月中旬至5月中旬）。集中一个月时间，组织党员干部开展走访调研活动。采取“看、听、问、析”等形式，进村入校察看，掌握基本情况；召开座谈会，倾听民情民意；上门访问，找准困难问题；梳理分析，形成走访调研材料。撰写1篇有情况、有分析、有对策的调研报告。

（三）破解难题（5月下旬至9月下旬）。对基层、学校和群众反映的问题以及提出的意见建议，在调查研究、客观分析的基础上提出对策措施，制定整改计划，作出公开承诺，集中抓好整改。对应该解决而暂时难以解决的问题，做好宣传和解释工作，争取群众的理解；对群众反映的共性问题，结合实际制定系统的整改计划，并明确整改责任人和整改时限。参加活动的党员、干部至少为基层和群众办1-2件实事好事。整改落实情况要向党员群众公布，接受监督。

（四）巩固提升（10月上旬至12月底）

认真总结主题实践活动开展情况，把在加强党性修养、转变工作作风、推动跨越发展、夯实基层基础等方面取得的好经验好做法加以提炼，形成务实管用、简便易行的制度成果。活动结束前，组织开展回访，进一步听取意见，找出不足，做好查漏补缺，及时跟踪落实，巩固活动成果。

四、组织领导

（一）加强领导，落实责任。局党组高度重视，把开展“进百村入千企访万户”活动作为创先争优活动取得实效的重要举措，作为本单位党建工作的拓展延伸，加强组织领导，落实工作责任，找准切入点，把握着力点，促进活动扎实有效开展。成立活动领导小组，确定一名分管领导，具体负责组织协调。

（二）统筹兼顾，合理安排。要把主题实践活动与学习型党组织建设、重点项目建设、基层组织建设年活动结合起来，与发挥部门职能作用、培养锻炼干部、治庸治懒治散结合起来，统筹安排，共同推进，防止走过场、搞形式。

（三）树立典型，营造氛围。及时总结宣传活动中创造的新鲜经验，深入宣传报道活动开展情况，大力宣传活动中的先进典型、成功经验和感人事迹，努力营造良好的舆论氛围。

（四）深入基层，执行“五不”。要带上好作风下基层，拿出真心意办实事。全体党员干部在深入基层时要严格执行“五不”：不组织迎送、不单独乘小车进村镇、不收任何礼物、吃便餐不喝酒、座谈会上不摆香烟水果，以好的作风、好的形象服务基层、联系群众，促进机关干部下基层转作风重实效。

（五）加强督查，确保实效。要建立月报制度，每月月底前把活动开展情况及时报送市直机关党工委，成立专门督查组，定期不定期对活动开展情况进行督导检查。对落实不力、马虎应付的，进行通报批评。把党员干部参与活动工作情况，纳入个人年度考核，确保活动取得实效。
