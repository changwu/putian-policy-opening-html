中共莆田市委统战部 莆田市民族与宗教事务局关于印发《第十五个民族团结进步宣传月活动方案》的通知

发布时间：2022-09-12 10:30
| | |
各县（区）委（工委）统战部、民族宗教局：

为深入持久推进民族团结进步创建工作，定于9月份以“福籽同心爱中华”为主题，开展我市第十五个民族团结进步宣传月活动。现将有关事项通知如下：

一、指导思想

全面贯彻党的十九大和十九届历次全会精神，深入学习贯彻习近平总书记关于加强和改进民族工作的重要思想以及中央、省委、市委民族工作会议精神，以铸牢中华民族共同体意识为主线，以“中华民族一家亲·同心共筑中国梦”为总目标，广泛开展“四个与共”“五个认同”及党史、新中国史、改革开放史、社会主义发展史、中华民族发展史等宣传教育，大力唱响共产党好、社会主义好、改革开放好、伟大祖国好、各族人民好的时代主旋律，广泛宣传党的百年光辉历程和伟大成就、宣传民族工作辉煌成就，深入推进全市民族团结进步创建活动，以实际行动迎接党的二十大胜利召开。

二、活动重点

（一）大力做好我市民族团结进步的宣传。深入学习宣传贯彻习近平总书记关于加强和改进民族工作的重要思想，深刻认识铸牢中华民族共同体意识的重要意义，以中央、省委、市委民族工作会议为指导精神，通过展板、宣传页、面对面宣讲、知识竞答等方式，大力宣传党的民族政策，引导各族群众树立正确的国家观、历史观、民族观、文化观、宗教观，增强对中华民族的认同感和自豪感。今年9月份也是各地举办农民丰收节的时节，各县（区）委统战部、民宗局要主动对接农业农村局，利用好重要节庆开展民族团结进步宣传活动，广泛宣传习近平总书记“十二个必须”的宝贵经验，铸牢中华民族共同体意识。

（二）积极讲好我市民族团结进步的故事。深化今年省、市、县民宗系统大调研的工作成果，在涵江区萩芦镇南下村召开11个民族村促进共同富裕的经验介绍，充分展示我市民族村经济社会发展和民族团结进步的新成果、新面貌，不断探索各民族村共同富裕的有效途径。不断总结推广莆田一中新疆班办班十周年的成果，邀请援疆先进个人分享援疆故事，让更多的人参与民族团结进步事业。开展民族传统体育竞技活动，传播民族团结正能量。深入培育和践行社会主义核心价值观，大力弘扬以爱国主义为核心的中华民族精神，以改革创新为核心的时代精神，引导各族人民牢固树立休戚与共、荣辱与共、生死与共、命运与共的共同体理念。

（三）办好促进我市民族团结进步的实事。以铸牢中华民族共同体意识为主线，以“共同家园、共同富裕、共同进步”为目标，关心关注民族村“一老一小”，组织开展经常性走访慰问，重点帮助少数民族群众解决医疗、养老、教育等实际困难，把党的关怀、组织的关爱、社会主义大家庭的温暖送到他们手中。关心关爱少数民族流动人口，依托少数民族流动人口服务管理联系点，广泛开展法律咨询、疫情防控、就业服务、医疗卫生、科技文化下基层等活动，提升少数民族流动人口的归属感和认同感。

三、活动形式

（一）认真组织实施。要以“福籽同心爱中华”为主题，研究制定宣传月实施方案，充分整合各方资源，营造人人支持、人人参与宣传月活动的良好氛围。充分调动各项资源，举办形式多样、内容丰富、群众参与度高的宣传活动，共同讲好各民族团结进步的好故事，引导各族干部群众铸牢中华民族共同体意识，促进各族群众像石榴籽一样紧紧抱在一起。

（二）大力开展宣传。要组织和引导新闻媒体加强宣传报道，发挥传统媒体和新媒体、融媒体共同作用，针对不同对象和受众特点多做“滴灌式”宣传教育。要持续实施“互联网+民族团结”行动，鼓励开展“我为民族团结”代言等主旋律突出、符合互联网传播的活动，提升民族团结进步宣传的广度。

（三）及时化解矛盾。要以宣传月活动为契机，集中开展民族领域矛盾纠纷的排查调处，及时分析研判，依法妥善处理影响民族团结的矛盾纠纷和涉民族因素的事件，坚决纠正和杜绝违反民族政策、伤害民族感情的做法，尊重少数民族群众风俗习惯，解决好少数民族流动人口的特殊困难和问题，维护民族团结和社会稳定。要坚决防范民族领域重大风险隐患，加强对涉及民族因素的网络舆情的引导和管控，掌握网上舆论的主动权。

四、活动要求

（一）领导带头示范。各县（区）委统战部、民宗局要切实加强组织领导，主要负责同志要亲自抓谋划、抓部署、抓落实，注意突出重点、体现特点、打造亮点，充分发挥职能优势，加大人力、物力、财力投入，并带头参与宣传月活动，示范带动各级各部门、全社会广泛参与。

（二）落实“三提三效”。要充分发挥各自职能优势，切实按照省委关于“提高效率、提升效能、提增效益”行动部署的要求推进宣传月活动，注重集中发力、持续开展，着力打造亮点品牌，形成常态化宣传教育机制，确保活动高起点谋划、高标准推进、高质量落实。

（三）及时梳理总结。要认真总结民族团结进步宣传月活动的典型做法，学习交流借鉴，建立长效机制，持续推动宣传教育活动开展。活动结束后，请各县（区）委统战部、民宗局及时梳理汇总本地区活动情况，并于10月8日前将活动总结报市民族宗教局，各县区工作开展情况将作为2022年度乡村振兴实绩考评重要依据。
