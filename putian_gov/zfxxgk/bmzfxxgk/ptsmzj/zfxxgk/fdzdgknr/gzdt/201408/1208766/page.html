莆田市民族与宗教事务局关于开展民族团结进步宣传月活动的通知

发布时间：2014-09-02 00:00
| | |

 各县（区）民宗局、湄洲湾北岸工商联、湄洲岛群工部：

根据省政府办公厅《关于开展民族团结进步宣传月活动的方案》（闽政办[2008]150号）和省厅《关于组织开展2014年民族团结进步宣传月活动的通知》（闽民宗[2014]106号）,确定今年9月份在全市继续开展民族团结进步宣传月活动。现将有关工作通知如下 :

一、深刻认识宣传月活动的意义，推动宣传教育创新发展

开展民族团结进步宣传月活动是做好民族工作、营造良好氛围、促进民族和睦的一种好的形式，是展示我市各民族人民在改革开放和社会主义现代化建设中涌现出的开拓进取、奋力拼搏精神并有着旺盛生命力的活动。这对于巩固和发展社会主义新型民族关系，增进中华民族的凝聚力、向心力，促进社会主义现代化建设和海峡西岸经济区建设，推动整个社会的发展进步，都具有十分重要的意义。各县区民族工作部门要从讲政治的高度，充分认识新形势下开展民族团结进步宣传月活动的重要意义，深入学习、宣传、贯彻党的民族工作方针、政策，并结合本地实际，创造性地推动民族团结进步事业的健康发展。宣传月活动期间，各县区民族工作部门和各民族村要拿出具体措施，组织各族干部群众深入学习领会和贯彻落实习近平总书记重要论述，按照中央民族工作会议和全省民族工作会议精神的要求，紧紧围绕“各民族共同团结奋斗，共同繁荣发展”的民族工作主题，深入开展民族团结进步宣传教育活动，调动全社会力量，共同维护民族团结，共同促进少数民族和民族地区经济社会发展，共同巩固和发展平等、团结、互助、和谐的社会主义民族关系，园好团结梦、实现发展梦、共铸中国梦，以此推动我市民族团结进步事业不断开创新局面。

二、扎实开展“六个一”活动，扩大宣传教育活动的影响

1、举行一次宣传月活动启动仪式。为把临时零散性的民族团结进步宣传和公益慈善活动发展成为经常性的统筹安排的活动，市民宗局将在涵江区白塘镇双福民族村举行一次民族团结进步宣传月活动暨宗教慈善周启动仪式，通过一系列富有成效的活动来推动民族团结进步宣传月活动的扎实开展。

2、集中一次民族政策法规宣传活动。宣传月活动期间，利用文艺宣传队，广泛宣传民族团结进步典型。各县区民宗局要在各民族村悬挂横幅和宣传标语，民族行政村要制作专题宣传栏，宣传党的民族政策、民族理论和民族基本知识活动，推动宣传月活动的深入开展。

3、组织一次走进民族村书画笔会。组织一批民族宗教界书画爱好者，在相关民族村举办书画笔会活动，营造宣传月活动氛围，同时展现我市各族人民共同奋斗、共同繁荣发展的成果，展示我市少数民族文化建设和艺术创作方面的辉煌成就。

4、开展一期劳动技能培训活动。各县区要以民族村为单位，举办一期农村实用技术培训，鼓励少数民族青少年提高技能素质和水平，不断加大少数民族劳动技能培训工作力度，缓解少数民族因技术水平低就业难的问题。

5、组织开展一次送医下乡活动。宣传月期间，市民宗局将组织相关医院有关专家医师深入民族村开展医疗义诊活动，向少数民族群众宣传、普及有关医疗防病知识，免费健康体检。

6、开展帮扶一批困难群众慰问活动。宣传月期间，市民宗局和市宗教慈善协会将通过不同形式，组织开展民族村困难户、困难学生走访、慰问活动，扎扎实实为民族村群众办一些实事、好事，并着力解决少数民族和民族地区加快发展中存在的突出问题。

三、加强宣传月活动的领导，确保宣传教育活动取得实效

各县区民族宗教局要成立开展民族团结进步宣传月活动领导小组，切实加强领导，摆上工作位置，结合当地实际，认真进行研究，制定活动方案，作出具体部署，大力推进宣传月活动的开展。各地对开展民族团结进步宣传月活动情况要及时进行总结，注意发现模范典型和事迹，及时加以推广、确保宣传月活动有序、有力、有效地展开，努力形成各方面踊跃参与宣传月活动的生动局面。各县区民族工作部门在宣传月活动结束后，请于10月15日前将开展活动情况的书面材料报告市局民族科。
