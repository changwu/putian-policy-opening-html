莆田市民族与宗教事务局关于印发深入开展铸牢中华民族共同体意识宣讲实施方案的通知

发布时间：2024-05-28 08:37
| | |

各县区委（工委）统战部（民宗局）：

　　为扎实推进习近平总书记关于加强和改进民族工作的重要思想入脑入心，引导各族群众不断铸牢中华民族共同体意识，现将《深入开展铸牢中华民族共同体意识宣讲工作方案》印发给你们，请结合工作实际，认真贯彻落实。

　　

    附件：关于深入开展铸牢中华民族共同体意识宣讲实施方案

　　 

                                                     莆田市民族与宗教事务局

　　                                                    2024年5月17日

 

附件

　　关于深入开展铸牢中华民族共同体意识宣讲实施方案

　　

   根据省民宗厅办公室《关于印发深入开展铸牢中华民族共同体意识宣讲工作方案的通知》精神，为坚决贯彻落实习近平总书记关于加强和改进民族工作的重要思想，引导各族群众不断铸牢中华民族共同体意识，构建铸牢中华民族共同体意识大宣教工作格局，现制定关于深入开展铸牢中华民族共同体意识宣讲实施方案如下。

　　一、总体要求

　　坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记关于加强和改进民族工作的重要思想，牢牢把握铸牢中华民族共同体意识主线,坚持把中华民族共同体意识教育纳入国民教育、干部教育、社会教育全过程，大力宣传中华民族的历史、中华民族共同体理论、新时代党的民族工作取得的历史性成就，推动各族人民牢固树立“四个与共”的共同体理念，坚定“五个认同”，为扎实做好新时代民族工作提供坚实保证。

　　二、宣讲重点

　　要深入学习领会习近平总书记关于加强和改进民族工作的重要思想，参照国家民委制定的《铸牢中华民族共同体意识宣讲大纲》，重点围绕铸牢中华民族共同体意识的基本概念、重大意义、理论渊源、深刻内涵、基本任务、根本保证等方面进行有针对性地宣讲。紧抓“十二个必须”，讲清楚铸牢中华民族共同体意识的思想来源、理论根基和实践基础；紧抓“四个共同”，讲清楚中华民族历史观和中华文明突出特性；紧抓“四对关系”，讲清楚做好新时代党的民族工作的方法原则；紧抓“主线任务”，讲清楚坚持党对民族工作的全面领导是以中国式现代化推动中华民族共同体建设和中华民族现代文明建设的实践要求。

　　三、组织领导

　　组  长：黄建国   市民宗局党组书记 局长

　　副组长：陈瑞发    市民宗局党组成员 副局长

　　成  员：陈建平   仙游县委统战部副部长、民宗局局长

　　        陈宜宓   城厢区委统战部常务副部长

　　        陈文昌   荔城区委统战部常务副部长、民宗局局长

　　        陈  洪   涵江区委统战部副部长、民宗局局长

　　        郭晓艳   秀屿区委统战部副部长、民宗局局长

　　        陈  瑜   湄洲岛党工委群工部（统战）部长

　　        苏顺权   北岸经开区党工委统战部副部长

　　四、工作要求

　　（一）提高思想认识。各县区民族工作部门要把常态化开展铸牢中华民族共同体意识宣讲作为一项重大政治任务，结合铸牢中华民族共同体意识主题月、青少年学生主题演讲大赛、民族团结进步宣传月等活动，认真谋划、定期研究、周密部署。

　　（二）细化宣讲方式。宣讲领导小组成员要组织宣讲骨干分别深入机关、学校、企业、社区、乡村、宗教活动场所开展一次宣讲，根据不同单位、不同受众群体，采取多样化、个性化、差异化的宣讲方式，让广大受众听得懂、能领会、可落实。

　　（三）提升宣讲成效。要牢记总书记关于建好“福建窗口”的重要嘱托，大力宣讲新时代民族团结的好故事。要在《宣讲大纲》基础上，组织宣讲骨干用好《中华民族共同体概论》教材、“道中华”公众号、“福建民族宗教”公众号等平台，用好史料，努力把鲜活的思想讲鲜活、把彻底的理论讲彻底。

　　各县区委（工委）统战部（民宗局）要认真制定宣讲工作计划、扎实完成“六进”宣讲，11月10日前形成本地宣讲工作开展情况报告，报送市民族宗教局。
