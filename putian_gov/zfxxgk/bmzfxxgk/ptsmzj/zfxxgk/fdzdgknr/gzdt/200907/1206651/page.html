2009年上半年全市民族宗教工作督查情况通报

发布时间：2009-07-31 00:00
| | |

7月中旬，市民宗局组织两个督查组深入县区民宗局、部分宗教活动场所，采取听取汇报、查阅资料、实地检查、座谈了解等方式，对县区上半年宗教活动场所安全隐患排查治理、“五五”普法教育、治理乱滥建等工作进行督导。现将督导情况通报如下：

一、主要成效

各县区民宗局按照省、市民族宗教工作部门的部署，认真抓好各项工作的落实，取得了一定的成效，主要体现在以下几个方面：

（一）各县区普遍重视治理乱滥建工作。市委治理乱滥建工作动员部署后，各县区、各重点乡镇及时调整充实治理乱滥建工作领导小组及办公室，健全机构，加强领导。其中荔城区治理乱滥建工作领导小组成员由原来的部门副职领导，全面调整为正职领导，六个镇街党委书记全部兼任成员，进一步强化了领导。城厢区、秀屿区所有乡镇都成立了治理工作机构，切实负起了属地管理的职责。总的看，我市治理乱滥建寺观教堂、民间信仰场所和露天宗教造像工作取得了阶段性成果。其中仙游县已拆除2处、改作他用的5处；荔城区已拆除4处，迁移1处；城厢区已拆除3处、制止2处；涵江区拆除5处（其中露天造像2处）；秀屿区已拆除2处，还有2处已表态自行拆除，北岸已拆除1处；湄洲岛已拆除1处。

（二）“五五”普法教育力度加大。各县区民宗局加强对“五五”普法教育，宣传覆盖面不断扩大，广大干部群众的法制观念和依法管理民族宗教事务的意识不断增强，各级领导和社会对民族宗教工作的目的、意义，有了比较深入的认识。仙游县、荔城区民宗局以会代训，通过召开全县统战委员会议、教职人员和场所负责人培训班等形式，加大对《福建省少数民族权益保障条例》、《宗教事务条例》和宗教法律法规宣传力度，局领导多次主动上台讲课。荔城区、秀屿区注重对民族宗教工作的宣传，凡是举行重大活动，都能邀请新闻媒体采访报道。涵江区民宗局会同区依法治区领导小组办公室制定《开展民族宗教系统法制宣传教育意见》下发各乡镇、宗教团体，按照省民宗厅《福建省民族宗教系统开展法制宣传教育第五个五年规划》精神，由区民宗局组织，区法制宣讲团对各宗教团体、宗教活动场所主要负责人进行法制讲座和现场法律咨询，并开通法律援助站，进一步提高全区民族宗教干部、宗教界人士、广大信徒群众的法律意识和法制观念。

（三）重视抓好宗教活动场所的安全管理工作。各县区都能定期组织人员对宗教活动场所安全隐患进行摸底排查，一旦发现问题，立即发放整改通知书，确定整改时限，要求按时整改。仙游县举办了5期安全知识培训，参训人员达400多人次。荔城区举办宗教团体负责人及各场所负责人消防安全知识培训和演练，年初制订出台了公共安全应急事件处置预案。涵江区宗教场所设立安全监督员204人，负责对场所的安全情况进行跟踪督查，对不安全现象及时予以纠正。城厢区认真开展宗教活动场所汛期安全排查工作，建立低洼、易滑坡等地质灾害地带宗教场所档案和标志，重点掌握分布情况，加强台风、暴雨等恶劣气候安全值班。秀屿区每月至少两次组织人员对场所进行安全隐患排查，还结合“安全生产月”活动，邀请区消防大队作“消防安全知识讲座”。通过狠抓安全工作，该区宗教活动场所未发生安全事故。

（四）安定稳定工作比较扎实有效。各县区都能定期组织人员对宗教领域不稳定因素进行摸底排查，及时了解动态，及时化解矛盾。仙游县重点抓好佛教协会、太平禅寺、七级堂、南门堂等宗教团体、场所矛盾纠纷跟踪工作，把矛盾处理在萌芽状态。荔城区共化解各类矛盾和群众性事件3件，解决了多起群众可能或已引发的群体性问题。涵江区认真做好民族团结稳定工作，上半年平息了2个村民小组300多人因未确认民族成份而将集体上访事态。主动积极配合有关部门协调解决争议纠纷，按照综治平安建设责任要求，上半年共调处了10个宗教场所矛盾，维护宗教界的安定稳定局势。秀屿区举办1期平安建设和反邪教知识讲座，宣传“平安秀屿”的重要性，张贴平安建设宣传标语，与宗教团体负责人签订《2009年民族宗教系统社会治安综合治理目标管理责任书》，促进了民族宗教领域和谐稳定。

二、存在问题

各县区民宗局在宗教活动场所安全隐患排查治理、“五五”普法教育、治理乱滥建等工作，虽然取得了一定的成效，但仍存在一些问题和不足：

（一）治理乱滥建工作任务仍然艰巨。虽然各县区领导对治理乱滥建工作非常重视，但宗教和民间信仰乱滥建现象仍然存在，城市改造中未按程序批准擅自易地安置的问题也比较普遍。荔城区出现在城市规划区范围内乱建宫庙行为。

（二）少数宗教活动场所还存在较大安全隐患。主要表现在：一是宗教活动场所负责人思想不重视、麻痹大意，安全意识淡薄，责任不落实。特别是安全宣传教育存在盲区，个别未经登记的宗教或民间信仰场所发生安全事故。二是宗教场所大多是土木结构，在设计时没有考虑到消防问题，特别是电线大多老化交叉又没有隔离，宗教节日焚烧纸品,燃放鞭炮，容易发生火灾，如：前年涵江囊山寺观音殿因电线老化碰电引起火灾，造成观音殿烧毁；今年天王殿又烧毁。三是消防器材配备严重不足，自救能力差，大部分场所还没有配备消防器材。四是场所经常集体聚餐，特别是乡村场所不太讲究卫生，一旦发生集体食品中毒，后果将相当严重。五是场所建设重报批、轻管理的现象严重，建设工程施工中安全措施落实不到位，安全资金投入少等。

（三）宗教领域不稳定现象仍然存在。荔城区个别宗教活动场所内部矛盾纠纷较多，如果不加整顿，有可能引发矛盾纠纷。黄石东阳天主教堂旁经营柴油等危险品虽经各级领导多次催促，至今问题没有解决。反映多次的仙游枫亭镇宝莲庵安全隐患和矛盾纠纷问题久拖不决。山立学校校园一段围墙倒塌，该土方石料压在大雄宝殿后墙基，至今并无清理，同时影响到该庵排水系统，安全隐患比较严重。涵江区囊山寺内部管理不规范，虽经区有关部门整顿，但内部矛盾没有彻底解决。宫口基督教聚会处和如意堂在拆迁中仍出现个别越级上访现象。城厢区综治平安建设工作尚未全面展开。秀屿区宗教团体建设仍然比较薄弱。

三、意见建议

（一）要提高做好新时期民族宗教工作重要性和必要性的认识，特别要通过认真的学习和研究，提高对宗教存在的长期性，宗教特殊复杂性和宗教问题群众性的认识，在工作中要坚决克服以权代法、以言代法的现象，坚持教育与引导相结合，充分发挥宗教界人士和信教群众在经济社会发展中的积极作用。

（二）要加大治理乱滥建工作力度。充分利用全市清理整治“两违”用地统一行动的契机，各县区要积极对接，近期要对本辖区乱滥建情况进行一次全面的清查，并总结经验，健全机制，确保治理乱滥建工作取得成效。

（三）宗教和民间信仰场所安全要常抓不懈。安全工作是一项事关社会和谐稳定大局的重要工作，各县区务必每季度进行一次全面排查，对排查出来的问题要限定时间和责任人，确保整改到位。要进一步贯彻落实“以防为主”和“属地管理”的原则，精心组织，周密部署，制定和完善应对各类安全事故的预案，确保我市宗教和民间信仰场所不出现安全事故。

（四）不断加强自身建设。各县区要高度重视民族宗教工作干部的思想作风建设，通过科学发展观的教育，使干部不断增强依法行政意识，提高驾驭全局能力，更加扎实更有成效地做好民族宗教工作，不断提高民族宗教工作水平。

 

 

 

莆田市民族与宗教事务局

二○○九年七月二十九日
