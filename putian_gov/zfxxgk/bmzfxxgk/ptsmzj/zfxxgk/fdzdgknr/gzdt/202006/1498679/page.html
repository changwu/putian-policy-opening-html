莆田市民族与宗教事务局关于2020年开展以“平安建设、法治同行”为主题的宗教政策法规学习月活动的通知

发布时间：2020-06-12 10:14
| | |

各县（区）委统战部（民宗局），湄洲岛、北岸党工委统战部:

2020年是全面建成小康社会和“十三五”规划收官之年也是“七五”普法收官之年。为深入贯彻落实党的十九大和十九届二中、三中、四中全会精神，根据省民宗厅《关于2020开展以“平安建设、法治同行”为主题的宗教政策法规学习月的通知》和市司法局部署的开展“七五”普法总结检查验收要求，经研究，决定于2020年6月份开展以“平安建设、法治同行”宗教政策法规学习月活动。

一、把学习宣传习近平总书记全面依法治国新理念新思想新战略作为学习月活动的首要任务

在宗教工作领域组织深入学习宣传习近平总书记全面依法治国新理念新思想新战略，切实把思想和行动统一到习近平总书记关于依法治国和疫情防控的重要讲话重要指示批示精神上来。要按照中央关于加大全民普法工作力度的部署和省市要求，深入宗教团体、宗教活动场所和信教群众，结合宗教政策法规学习，大力宣传我国的根本制度、基本制度和重要制度。进一步推动宗教团体、宗教活动场所负责人发挥示范带头作用，增强宗教界走中国特色社会主义法治道路的自觉性和坚定性。

二、把维护安全稳定和服务中心大局作为学习月活动的核心要求

宗教团体、宗教活动场所是社会的组成单元，宗教界人士首先是普通的中华人民共和国公民，学习贯彻党的大政方针和《宪法》以及其他相关国家的法律法规既是基本义务，也是学习贯彻宗教政策法规题中应有之义。

一要深入贯彻落实中央全面依法治国委员会第三次会议精神，组织开展“防控疫情，法治同行”专项普法宣传。大力宣传与疫情防控相关的法律法规，深入宣传全国普法办编印的《新型冠状病毒感染肺炎疫情当前防控工作有关法律知识问答》，营造宗教工作领城依法防疫的法治氛围，全面提高依法防控依法治理能力，引导宗教界依法行动，依法行事。

二要坚决贯彻落实市委关于安全生产和平安建设部署要求，组织开展“平安建设，法治同行”专项普法宣传，统筹政治安全和公共安全，坚决扛起“促一方法治、保一方平安”的政治责任，组织宗教界认真学习《中华人民共和国安全生产法》、《中华人民共和国消防法》、《中华人民共和国国家安全法》、《中华人民共和国反恐怖主义法》等有关政策和法律法规，以学习宣传、提高思想认识为先导，以明确责任、排查梳理隐患为落脚点，让学习宣传与正在开展的疫情防控、复工复产安全生产、消防安全大排查大整治和其他有关维护社会稳定的各项工作同频共振、深度融合。

三、把迎接“七五”普法总结检查验收作为展现学习月活动成效的重要契机

对照国家、省、市和宗教工作系统“七五”普法规划与要求，全面总结“七五”期间，在宗教工作领域开展的深入学习宣传习近平总书记关于全面依法治国的重要论述情况，以宪法为核心的中国特色社会主义法律体系宣传普及情况，各地宗教工作部门落实“谁普法、谁执法”责任工作情况，特别是“四进”宗教活动场所活动的开展情况。全面总结“七五”普法工作期间各地开展政策法规学习月的成效和特色做法，挖掘发现一批、通报表扬一批、宣传展现一批宗教界“七五”普法表现突出的集体和个人，全面展示5年来工作成效。

四、把组织保障和推进落实作为学习月活动取得实效的重要途径

一要加强组织领导。宗教政策法规学习宣传贯彻，是依法管理宗教事务的重要环节，是提高宗教领城社会治理水平的基础性工程。各县区务必高度重视，切实扛起推动学习宣传教育工作的重要责任，加强对学习月活动的组织领导，结合实际，统筹谋划，整合普法、调研、执法、监督、检査等相关任务，把学习月活动与疫情防控复工复产、安全生产、平安建设、“七五普法”、落实“四进”、开展商业化治理以及和谐寺观创建等工作结合起来，认真谋篇布局，精心组织实施，一体推进，全面提高宗教界尊法、守法意识和知法、懂法、用法水平。

二要突出问题导向。要紧紧抓住场所安全的突出问题，认真组织学习贯彻执行《中华人民共和国城乡规划法》、《中华人民共和国建筑法》、《宗教事务条例》和《宗教团体管理办法》以及系列配套规章措施和相关内容，强化各宗教团体、宗教活动场所的主要负责人为相关组织安全生产和平安建设第一责任人。要聚焦宗教活动场所设立和宗教活动场所改扩建等重大行政许可项目，开展全面宣传教育和检査，禁止“未批先建”等乱滥建宗教活动场所和民间信仰活动场所；对审批事项要从严把关从严审核、从严审批，严禁违规审批，缺项和漏项审批和弄虚作假；对审批项目要加强事中、事后监管，严禁“批小建大”等违法行为，着重对是否办理领取施工许可证和质量验收的关键环节开展督查检查，确保审批项目的全过程在法治轨道中运行、在安全范围内运转。

三要注重探索创新。要抓住宗教界政策法规学习宣传教育的“关键少数”，强化宗教团体、宗教活动场负责人和管理组织的学习政策法规的意识，落实组织学习和发动宣传教育的责任。要在宗教团体、宗教活动场所培育“法律明白人”，发挥他们在学习宣传政策法规、引导法律服务、化解矛盾纠纷、参与社会治理中的中枢作用，服务保障宗教界的和谐稳定。要反对形式主义、官僚主义，深入基层、深入实际、深入群众，送法上门，送政策到场所；要创新载体方式，坚持把智慧普法和精准普法作为创新方向，综合应用传统媒体和网络媒体两个手段，充分运用纸质宣传和网、端、微、屏等电子宣传载体，组织开展宗教政策法规学习宣传教育活动，鼓励宗教界积极参与新时代法治文化作品创作和传播，积极参加“我与宪法”等法治微视频、法治动漫、法治歌曲、公益广告、书画作品的征集制作和推送展播活动，为维护宗教领域的和谐稳定、为坚持高质量法治落实赶超，推进新时代新福建建设，菅造优质良好的法治环境。

各县区活动开展情况(以文字和图片形式)请于7月5日之前报送我局办公室。
