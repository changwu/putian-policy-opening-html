关于开展宗教界挂钩帮扶少数民族村工作的通知

发布时间：2020-05-08 09:52
| | |

各县（区）委统战部（民宗局），湄洲岛、北岸党工委统战部、市有关宗教团体：

根据中共福建省委办公厅、福建省人民政府办公厅《关于积极应对新冠肺炎疫情影响决战决胜脱贫攻坚十九条措施的通知》（闽委办发明电〔2020〕27号）和中共莆田市委办公室、莆田市人民政府办公室印发《关于补短板提质量决战决胜脱贫攻坚2020年行动方案》的通知（莆委办发电〔2020〕20号）文件精神，为深入贯彻习近平总书记重要讲话重要指示批示精神和党中央决策部署，为进一步加快我市民族地区经济和社会各项事业的发展，切实帮助我市少数民族村和少数民族群众解决实际困难和问题，经研究，特制定宗教界挂钩帮扶少数民族贫困村工作方案如下：

一、指导思想

以党的十九大精神为指导，以全面建成小康社会为目标，深入贯彻落实习近平新时代中国特色社会主义思想，全面整合社会资源，广泛动员全系统力量，深入开展精准帮扶贫困群众和贫困村工作，确保少数民族群众和民族地区脱贫攻坚取得实效。

二、工作任务

1.帮扶对象。我市共有3个省定的少数民族贫困村，分别是仙游县西苑乡前溪村、柳园村和涵江区萩芦镇南下村3个少数民族贫困村。其中道教协会挂钩帮扶南下村，天主教爱国会挂钩帮扶前溪村，基督教协会挂钩帮扶柳园村。

2.帮扶目标。积极支持打造我市少数民族贫困村建设成为经济发展、社会和谐、文化繁荣、民族团结、生态优美、特色浓郁的美丽乡村，进一步改善少数民族贫困群众的生活状况，确保帮扶对象的基本生活得到保障，让民族村群众有更多获得感、幸福感和安全感。

三、帮扶内容

1.开展精准帮扶工作。精准扶贫的对象为挂钩村的建档立卡贫困户，根据帮扶对象不同就业意向、劳动者技能、身体状况以及经营环境、条件等情况，对挂钩村的贫困户落实精准帮扶措施到户，重点做好治病、助学、就业、创业四个方面工作，多渠道、多途径为贫困群众出谋划策、寻找帮扶办法，开展慰问和帮扶活动，切实增强贫困户“造血”功能，给他们带去精神和物质上的安慰，使每个贫困户能切身地感受到党的温暖和关怀。

2.扶持贫困村集体经济。立足贫困村的地理位置和资源优势，支持加快发展蔬菜、水果、水产、畜禽、花卉苗木、茶叶、竹林等优势特色产业，探索设立区域性少数民族特有品牌，促进少数民族村发展特色经济产业。对村集体经济薄弱，受疫情影响导致集体经营收入减少、支出明显增加的贫困村，要加大扶持力度，引导和帮助各民族村发展特色生产性项目，进一步增强民族村集体经济实力，形成“一村一品”特色产业，提升村级自我保障和服务群众能力。

3.开展宗教慈善助困活动。引导宗教界发挥服务社会、服务人群的优良传统，发扬本宗教的传承理念，积极开展助学、助困及其他的志愿服务活动。疫情期间，为建档立卡贫困户子女复学提供口罩20个，每季度慰问金不少于500元，同时力所能及为更多的贫困户提供帮助，以宗教公益慈善感化人心，为党委、政府分忧，助力脱贫、奉献爱心传递正能量。

四、工作要求

全面落实“一户一策”“一户一挂钩”制度，在疫情防控期间要做到“一月一帮扶”，挂钩帮扶的宗教团体要通过进村入户、电话联系、沟通协调等方式，了解掌握贫困户生产生活情况，帮助解决生产物资代购、农业社会化服务、防护用品等实际困难。对因疫情等因素影响，可能返贫或出现返贫的，要立即按程序报告，实行单列管理，纳入重点帮扶。

 

 

 

 

                    莆田市民族与宗教事务局

                    2020年4月30
