关于印发《推动民族村（含自然村）实施乡村振兴战略行动方案》的通知

发布时间：2020-04-16 09:42
| | |

 

各县（区）委统战部（民宗局），湄洲岛、北岸党工委统战部：

现将《推动民族村（含自然村）实施乡村振兴战略行动方案》印发给你们，请结合实际，认真贯彻落实。

 

                    莆田市民族与宗教事务局

                   2020年4月7日

 


 推动民族村（含自然村）实施乡村振兴战略行动方案

（2020-2022年）

为深入贯彻落实市委市政府《关于实施乡村振兴战略的实施意见》（莆委发〔2018〕3号）文件精神，更好地推动全市民族村加快发展，与全市同步实现农业农村现代化，有效促进民族团结进步事业深入发展，现结合我市少数民族和民族村实际，就推动民族村全面实施乡村振兴战略，制定本行动方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大精神和中央农村工作会议精神，以习近平总书记在福建工作期间提出“努力把福建建设成为中华民族团结进步窗口”的要求为引领，牢牢把握各民族共同团结奋斗、共同繁荣发展的民族工作主题，紧紧围绕铸牢中华民族共同体意识的民族工作主线，把少数民族和民族村发展摆上更加突出的战略位置，以推动民族团结、社会和谐、人民幸福为宗旨，坚持农业农村优先发展，按照“产业兴旺、生态宜居、乡风文明、治理有效、生活富裕”的总要求，深入推进城乡融合发展和乡村特色发展，促进民族村高质量发展，建设少数民族和民族村安居乐业的美丽家园，为全面建成小康社会，加快美丽莆田建设作出新贡献。

二、主要目标

按照市委提出“到2020年，乡村振兴取得重要进展，制度框架和政策体系基本形成”“到2035年，乡村振兴取得决定性进展，农业农村现代化基本实现”的目标，突出特色培育，积极支持打造我市少数民族村建设成为经济发展、社会和谐、文化繁荣、民族团结、生态优美、特色浓郁的美丽乡村，让民族村群众有更多获得感、幸福感和安全感。力争到2022年探索形成具有一定特色的民族村振兴模式和经验，健全民族村振兴的制度框架，推动民族村振兴取得阶段性成果。

三、主要任务

（一）支持民族村实施产业兴旺行动，培育高质量发展典型。坚持质量兴农、绿色兴农、科技兴农、品牌兴农，推动民族村农业高质量发展。加快发展蔬菜、水果、水产、畜禽、花卉苗木、茶叶、竹林等优势特色产业，探索设立区域性少数民族特有品牌，促进11个少数民族村发展特色经济产业。加大对集体经济薄弱的民族村扶持力度，进一步增强民族村集体经济实力，提升村级自我保障和服务群众能力。支持少数民族农民合作社、农业企业与小农户签订生产合同，引导小农户从分散生产转向有组织有规模生产，更好地将小农生产引入现代农业发展的轨道。积极推进民族村一二三产业融合发展。

（二）支持民族村实施生态宜居行动，打造现代版美丽乡村。坚持人与自然和谐共生，打造新时代少数民族美丽乡村。支持民族村争创国家级、省级生态文明乡村，实施乡村旅游“百镇千村”提质升级行动，建设“一村一品”工程，发展休闲农业和生态旅游，构建乡村旅游精品体系，创建休闲农业示范基地。加大少数民族特色村寨保护和发展力度，持续实施少数民族特色村寨试点工作，加大宣传力度，扩大全市已命名中国少数民族特色村寨影响力。组织开展少数民族特色村寨保护与发展情况调研，加大传统村落保护力度，建设民族文化生态保护实验区和示范点。

（三）支持民族村实施文化繁荣发展行动，塑造新时代文明乡风。坚持文化自信，传承和弘扬优秀少数民族文化，建设文明民族村。积极弘扬莆田优秀传统文化，协调有关部门支持民族村开展少数民族优秀传统文化传承发展，保护民族古村落。持续开展“三月三”畲族文化节、“中国农民丰收节”、“中华民族一家亲，同心共筑中国梦”等活动，指导各县区开展民族文化节庆活动，繁荣群众文化生活。支持民族村建立少数民族文化展示馆、农家书屋。支持民族村开展有民族特色的文化活动，推动民族文化、少数民族非物质文化遗产保护传承发展，并实现效益转化。

（四）支持民族村实施团结和谐行动，建设现代化善治乡村。深入开展民族团结进步创建工作，深化民族团结进步宣传教育，促进各族群众像石榴籽一样紧紧地抱在一起。不断加大培育和选树示范、模范的工作力度，挖掘和宣传一批民族团结进步好故事。继续开展少数民族流动人口示范点工程，加强中华民族团结进步宣传阵地建设，推动城乡融合发展，促进我市各族人民交流交往交融。

（五）支持民族村实施均衡发展行动，实现公共服务均等化。坚持把保障和增进少数民族群众福祉作为民族村工作的出发点和落脚点，千方百计补齐民族村发展短板。促进民族村劳动力转移就业和农民增收，鼓励支持大学生毕业回乡下乡创业，培育创新创业基地。推动民族村水、电、路、网等基础设施和消防、防洪、防震、便民利民商贸网点等配套设施建设。支持农村饮水安全巩固提升工程，加快数字乡村建设，推广应用远程教育、远程医疗、金融服务等信息服务。支持民族村建设幸福院，大力发展农村互助养老服务。

(六)支持民族村实施巩固脱贫成果行动，创造更加美好生活。坚持民族因素与区域因素相结合，因地制宜、因贫施策，解决民族村发展不平衡不充分的问题。聚焦少数民族薄弱村和因病因残因灾等返贫户，积极探索防范少数民族群众返贫、缓解相对贫困等措施和有效机制，确保少数民族群众稳定脱贫，实现少数民族与全市一道过上小康生活。持续推进部门挂钩帮扶民族村发展工作，力推11个市直部门继续在资金、项目、人才、技术等方面加大对民族村的支持力度，探索民族村与挂钩帮扶单位“双向合作”推动发展的模式。进一步规范少数民族扶贫资金的分配和监管工作。推动全市少数民族村社会经济持续增长。

四、保障措施

（一）提高政治站位。实施乡村振兴战略，是以习近平同志为核心的党中央着眼党和国家事业全局，着眼实现“两个一百年”奋斗目标，顺应亿万农民对美好生活的向往作出的重大决策部署。少数民族村振兴是实施乡村振兴战略的重要组成部分，是贯彻落实习近平总书记关于民族工作重要论述精神，推动民族村加快发展的重要途径。要认真学习习近平总书记关于实施乡村振兴战略重要论述精神，深入贯彻中央、省、市委关于实施乡村振兴战略的决策部署，提高政治站位，统一思想认识，进一步增强做好推动民族村振兴发展的责任感和紧迫感。

(二)加大扶持力度。加强对乡村振兴、惠民政策的调查研究，积极协调统战、教育、科技、农业、交通、住建、文旅生态环境等部门在政策、资金、项目、人才等方面加大对民族村的倾斜支持力度。统筹推进全市11个民族行政村以外少数民族人口达到200人以上、有条件的自然村公路建设。充分发挥财政资金的引导作用，支持鼓励社会各界参与和扶持民族村实施乡村振兴战略，推动民族村振兴发展。

(三)强化督促落实。各县区委统战部（民宗局）要加强对本地区少数民族和民族村的调研和指导，扎实按照实施方案要求落实好本辖区的乡村振兴工作，及时宣传总结推广行之有效的好机制、好做法，确保民族乡村跟上全市乡村振兴的步伐。要加强对民族村实施乡村振兴战略过程中资金使用情况的监督检查和绩效评估，对资金使用效益不高、成效不明显、违反资金使用管理规定的民族村，给予通报、责令整改。各县区民族村乡村振兴工作落实情况将纳入县区乡村振兴工作考评。
