关于认真做好2011年民族团结进步宣传月活动的通知

发布时间：2011-08-25 00:00
| | |

各县区民族宗教局：

为开展好今年的民族团结进步宣传月活动,巩固和发展我市各民族平等、团结、互助、和谐的社会主义民族关系，促进我市各民族的发展进步和共同繁荣，努力营造推进全市民族工作、服务海峡西岸经济区建设的良好氛围。现将今年开展民族团结进步宣传月活动有关工作通知如下 :

一、宣传月活动的指导思想

民族团结进步宣传月活动要认真结合庆祝建党90周年活动，高举各民族大团结的旗帜，紧紧围绕“各民族共同团结奋斗，共同繁荣发展”的民族工作主题，深入开展民族团结进步宣传教育活动，调动全社会力量，共同维护民族团结，共同促进少数民族和民族地区经济社会发展，共同巩固和发展平等、团结、互助、和谐的社会主义民族关系，为构建和谐社会和全面建设小康社会，为海峡西岸“两个先行区”建设营造良好的环境。

二、宣传月活动的主要任务

1、精心组织宣传活动，营造浓厚舆论氛围。要突出重点，加强党的民族政策法律、法规的宣传教育。一是各县区民宗局要充分利用新闻网络、宣传栏、黑板报及印发宣传小册子和悬挂横幅标语的形式，大力宣传党的民族政策，增强各民族群众的政策观点和法制意识，把思想和行动统一到发展经济、改善生活、脱贫致富奔小康上来。二是全市各民族村要以民族宣传月活动为契机，利用村级宣传栏，广泛宣传民族政策及民族法律法规，使少数民族群众做一个知法、懂法、守法的好公民。三是各民族行政村的小学，要在9月开学时，通过举办宣讲会、报告会、主题班会及民族团结征文比赛等形式，增强少年儿童维护民族团结的意识，争当维护民族团结的好学生。

2、认真实践主题活动，确保活动取得实效。要找准载体，深化民族团结进步工作成果。切实开展民族团结进步宣传月“三个十”主题活动。一是举办10期农村实用技术培训班，以“现代农业农村新理念”为主题，坚持“实际、实用、实效”的原则，邀请有关专家，重点围绕民族村的农作物种植，保护性耕作技术、养殖技术以及农作物病虫害防治、动物疫病防控，农村专业合作社、农民转移就业等方面对民族村的干部及群众进行培训。具体任务安排：仙游县4期，荔城区1期，城厢区1期，涵江区3期，秀屿区1期。各县区在10月10日前将培训的相关材料及照片报送市民宗局民族科。二是在10个民族行政村举办巡回展览。各民族行政村要以各民族共同团结奋斗、共同繁荣发展为主题，以图文的形式选择民族典型做法、发展经验及民族方面的政策法规等，认真制作专板内容，由县区民宗局把关后发送市民宗局邮箱，以便统一制作展板在10个民族行政村巡回展出，组织民族村的干部参观学习，交流经验，促进各民族村的相互了解和团结友爱。三是评选10名民族团结进步创建个人。为进一步营造社会重视民族，关心民族事业、支持民族发展的浓厚氛围，不断开创民族团结进步事业的新局面，决定评选10名民族团结进步创建活动先进个人，具体名额安排：仙游县4名、荔城区1名、城厢区1名、涵江区3名、秀屿区1名。各县区民宗局要紧紧围绕民族团结进步和维护民族团结，促进民族地区社会经济发展这个主题，采取民主推荐，评选与审核相结合的办法，做好先进个人的推荐工作，先进个人的事迹要典型突出，为群众所公认。

3、努力做好衔接结合，切实解决实际问题。要把为民办实事，促进经济社会发展作为此次活动的出发点和落脚点，通过开展扶贫帮困、捐资助学、解决影响各族群众生产生活中的困难和问题等活动，巩固和发展平等团结、互助、和谐的民族关系，为我市的社会经济发展提供良好的环境。宣传月活动期间，各县区民宗局要积极协调民族工作协调委成员单位，深入少数民族乡村，为少数民族村办一件实事好事或解决一个实际问题。要通过宣传月活动，在全市形成一个为少数民族和民族地区出实招、办实事、办好事的良好氛围。

三、宣传月活动的工作要求

1、加强领导，精心组织。深入开展民族团结宣传教育是当前一项十分重要的政治任务。各县区民宗局要高度重视，切实加强领导，精心组织实施，把民族团结教育活动搞得既轰轰烈烈、有声有色，又扎扎实实、富有成效。紧密结合本地区、本单位实际，认真制定实施方案，明确工作任务、措施办法和责任分工，确保民族团结教育活动深入有效地开展。

2、创新形式、丰富内容。各县区民宗局要结合本地区、本单位实际，进一步创新形式，贴近实际、贴近群众、贴近生活，在吸引群众广泛参与上下功夫，生动有效地组织开展一系列特色鲜明的教育活动。要精心组织形式多样、健康向上的群众性文体活动，生动展示各族人民群感恩伟大祖国、建设和谐莆田的真挚情感。要把民族团结教育活动贯穿于本职工作之中，把组织活动与群众自发开展活动结合起来，把集中开展教育活动与日常宣传教育活动结合进来，把宣传教育与解决实际问题结合起来，切实把民族团结宣传教育活动渗透到千家万户。

3、结合实际、注重实效。各县区民宗局要紧密联系群众的思想实际，联系群众最关心最直接最现实的利益问题，找准宣传月活动与群众切身利益的结合和共鸣点，多用群众喜闻乐见的形式和听得懂的语言，多用群众身边的典型事例，不断增强宣传教育的实际效果，努力使民族团结教育月活动更加贴近实际、贴近生活、贴近群众，进一步增强民族团结教育的吸引力、感染力和影响力。各县区请于10月10日前将开展活动情况的书面材料报市民宗局。
