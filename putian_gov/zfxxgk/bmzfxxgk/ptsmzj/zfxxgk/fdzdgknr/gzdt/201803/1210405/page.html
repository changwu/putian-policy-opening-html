关于在宗教界中深入开展移风易俗活动的通知

发布时间：2018-02-16 09:22
| | |

各全市性宗教团体、市直宗教活动场所：

为进一步弘扬勤俭节约、艰苦奋斗的优良传统，净化社会风气，引导广大宗教界人士和信教群众逐步建立科学、健康、文明的生活方式，以实际行动，移风易俗，破旧立新，抵制不良习俗，树立文明新风。特通知如下：

一、加强宣传教育，营造崇尚节俭浓厚氛围

宗教团体、宗教活动场所、宗教界人士要加大宣传引导力度，充分利用在广大信教群众中影响力，因势利导、积极引导，结合学习十九大精神及新修订《宗教事务条例》，充分利用宗教节日、宗教活动等时机，大力宣传国家倡导移风易俗有关精神、国家宗教局等12部门《关于进一步治理佛道教商业化问题的若干意见》要求，以通俗易懂的语言、灵活多样的方式，借助网络、广播、海报、宣传栏、宣传单等载体，在宗教界中广泛开展社会主义核心价值观、移风易俗乡风文明等宣传教育活动，使移风易俗成为信教群众的自觉行动。各宗教团体要发出《移风易俗倡议书》，在春节、元宵、宗教重大节日、宗教大型活动中，宗教团体负责人要带头移风易俗，组织宗教界人士和信教群众积极参与各种移风易俗活动，从我做起，从现在做起，以文明节俭为荣、大操大办为耻;以艰苦朴素为荣、爱慕虚荣为耻;以厉行节约为荣，铺张浪费为耻，争做文明新风的积极倡导者、主动传播者和自觉实践者，在宗教领域内营造崇尚节俭的浓厚氛围。

二、坚持爱国守法，依法依规开展宗教活动

宗教界要以习近平新时代中国特色社会主义思想为引领，深入学习党的十九大精神和新修订《宗教事务条例》，坚持宗教中国化方向，积极引导宗教与社会主义社会相适应。坚持爱国爱教、遵纪守法，全面贯彻党的宗教信仰自由政策，教育引导宗教界人士和信教群众自觉在法律法规范围内开展正常宗教活动。宗教活动要宜少不宜多，严格控制规模、人数，仪式简办，不搞铺张浪费。大型宗教活动要依法报批，制定活动安全应急预案。经常开展安全隐患排查，明确安全责任，落实防范措施，确保宗教活动安全有序开展。

三、发挥积极因素，倡导健康文明进步新风

结合宗教经典教义中的勤俭节约的内容，通过讲经会道、弥撒礼拜等形式，引导广大信教群众自觉抵制“天价彩礼”和“高价贺礼”，不讲排场，不比阔气，不大操大办，不铺张浪费等。积极引导广大信教群众多关心老人，应尽子女赡养义务，使他（她）们老有所养、老有所乐。开展文明祭祀，采用“献一束花、植一棵树、开一个家庭追思会”等方式祭奠逝者，自觉抵制封建迷信陋俗，倡导婚丧喜庆新事新办，树立健康文明进步新风。积极开展文明敬香、合理放生、建设生态寺观活动，遵守禁燃禁放规定，禁止烧高香，明火不进殿，逐步实现不烧金纸贡元，净化寺观环境卫生。结合“和谐寺观教堂”创建活动，深入开展国旗、核心价值观、文化书屋、报刊杂志“四进”宗教场所活动。在重大节日和重要节点举行升国旗仪式，在宗教场所围墙等显著位置印刷或张贴核心价值观内容，打造文化书屋，为信教群众学习中华优秀文化、宗教政策法规、经典教义提供平台，引导广大信教群众不断增强讲文明树新风意识。

四、坚持正导确向，积极开展服务社会活动

宗教团体、宗教活动场所要深入研究分析本团体、本场所的特点，对“移什么风”、“易什么俗”要找准问题、抓住重点、对症下药，有针对性地解决和纠正教风和管理中的存在问题，提高教风建设和规范管理的能力和水平。要引导宗教界及信教群众积极发扬乐善好施、扶危济困、关怀社会、服务人民的传统美德，在宗教界中大力倡导“节俭办教”的理念，引导宗教界人士简办各类宗教庆典，广泛开展“省下香火钱，多做公益事”主题活动，引导宗教活动场所或者宗教界人士将香火钱捐出，变成公益金，用于公益慈善事业，支持当地教育、卫生、文体、生产生活设施建设，开展修桥铺路、扶贫济困、助学助残、尊老爱幼等公益慈善活动，改善农村基础设施和困难群众的生活条件，为社会公益事业和福利慈善事业作出新的贡献。

 

 

 

莆田市民族与宗教事务局
