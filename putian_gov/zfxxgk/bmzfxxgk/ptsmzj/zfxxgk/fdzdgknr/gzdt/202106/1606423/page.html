莆田市民族与宗教事务局关于2021年开展以“爱党爱国、平安创建”为主题的宗教政策法规学习月活动的通知

发布时间：2021-06-03 15:53
| | |

各县（区）委统战部（民宗局），湄洲岛、北岸党工委统战部：

2021年是中国共产党成立100周年，是实施“十四五”规划开局之年，是“八五”普法规划启动之年，也是《福建省宗教事务条例》（以下简称《条例》）颁布实施之年。为了贯彻落实党的十九大和十九届二中、三中、四中、五中全会精神，深入学习宣传习近平法治思想，坚持宗教中国化方向，加大宗教领域《条例》学习宣传力度，经研究，决定于2021年6月开展以“爱党爱国、平安建设”为主题的宗教政策法规学习月活动。

一、把学习宣传习近平法治思想作为学习月活动首要任务

各县（区）要把深入学习宣传贯彻习近平法治思想作为宗教领域普法工作的头等大事，把握正确政治方向和舆论导向。要把习近平法治思想的学习宣传和普法工作结合起来，按照中央关于加大全民普法工作力度的部署和省委要求，发挥宗教团体、宗教活动场所普法宣传阵地的作用，结合宗教政策法规学习，大力宣传习近平法治思想，大力宣传《宪法》《民法典》等相关法律法规，进一步推动宗教团体、宗教活动场所负责人和宗教教职人员发挥示范带头作用，引导广大信教群众坚定不移地走中国特色社会主义法治道路。

二、把坚持宗教中国化作为学习月活动的核心要求

坚持我国宗教中国化方向，是习近平总书记关于宗教工作的重大创新论断，是新时代宗教工作的重要主题和重大战略。各县（区）要旗帜鲜明地鼓励宗教界坚持宗教中国化方向，结合全国性宗教团体倡议开展“爱党爱国爱社会主义”主题教育的有利契机，发动宗教界积极参与“砥砺初心，爱我中华——福建宗教界坚持宗教中国化方向系列活动”，结合宗教活动场所“四进”，开展党情国情社情世情学习教育活动，倡议“四史”（党史、新中国史、改革开放史、社会主义发展史）学习教育进宗教团体和宗教活动场所，提高宗教界的思想自觉和行动自觉，让更多信教群众通过参与活动，更加看到宗教爱国报国、追求和平、与中国共产党中华民族同呼吸共命运的历史，更加充分感受中国特色社会主义制度的优越性。

三、把维护宗教领域安全稳定作为学习月活动的重要内容

各县（区）要认真贯彻习近平总书记关于安全工作的重要论述和指示批示精神，落实中央、省委、省政府和市委、市政府关于安全工作的决策部署，根据市委统战工作领导小组办公室《关于进一步加强宗教领域“安全工程”建设的行动方案》通知的要求，全面加强宗教领域安全宣传教育和管理，全面提升建筑、消防、卫生防疫和食品、治安、文物等安全监管服务水平，有效遏制恶性安全事件，推动宗教事务管理从治标向治本深化，从“管得住”向“管得好”转变，确保我市宗教领域安定稳定。

一要科学精准做好宗教领域常态化疫情防控工作。各县（区）要大力宣传与疫情防控相关的法律法规，组织宗教界开展疫情防控相关普法学习宣传，按照当地部署要求做好疫苗接种工作。要督促宗教界绷紧疫情防控之弦，指导宗教界开展爱国卫生运动，完善疫情防控工作措施和应急预案，减少非必要的集体宗教活动，引导宗教界把“疫”时防护转变为卫生健康常态。

二要开展宗教领域平安创建活动。各县（区）要坚决扛起防范化解重大安全风险、保一方平安的政治责任，始终把习近平总书记关于安全生产的重要论述作为根本遵循，结合市委“再学习、再调研、再落实”活动要求，进一步强化责任担当，开展宗教领域“平安创建”普法宣传，组织宗教界认真学习《中华人民共和国安全生产法》、《中华人民共和国消防法》、《中华人民共和国国家安全法》、《中华人民共和国反恐怖主义法》等有关政策和法律法规，以学习宣传、提高思想认识为先导，以明确责任、排查梳理隐患为落脚点，有机结合宗教活动场所房屋隐患专项治理三年行动和宗教活动场所消防专项治理三年行动，按照专项行动的工作部署和时间节点，开展“控事故、保安全、迎建党百年”安全排查集中整治专项行动，对宗教领域的隐患开展全面自查排查和检查，特别是对在建的建筑施工和发现的宗教活动场所消防安全隐患要做到自查检查全覆盖，切实建立隐患清单，按照隐患项目化、项目清单化、清单具体化的要求，逐一销号，确保宗教领域集中攻坚专项行动取得实效。各县（区）要认真培育总结本地区宗教活动场所平安创建的典型（每个县（区）培育总结2个、北岸、湄洲岛各1个典型），有关典型名单和材料请于学习月结束后报送市民宗局宗教科。

四、把宣传贯彻《条例》作为学习月活动的主要内容

《条例》是我省宗教领域立法的首部法规，已于今年3月1日正式施行。各县（区）要认真贯彻落实市委统战部、市民族宗教局下发的《关于学习贯彻〈福建省宗教事务条例〉的意见》，组织专题学习，宗教工作部门要带头学、深入学、学原文，深刻理解、准确把握《条例》的指导思想、基本原则、主要制度和各项规定。要把《条例》作为宗教政策法规学习月学习培训的重要内容，有机结合国家宗教事务局近期颁布的《宗教教职人员管理办法》《宗教院校管理办法》等规章，在宗教界和信教群众中广泛开展学习宣传培训活动。一要加大培训力度。市、县两级要把《条例》作为今年法治宣传的重要学习培训内容，宗教活动场所要结合“四进”活动，将《条例》宣传上墙进框，宗教教职人员要将《条例》内容融入到讲经讲道之中，让更多的干部和群众了解和学习《条例》。二要开展系列活动。市民族宗教局将发送《条例》单行本，送法上门，做到宗教团体、宗教活动场所和宗教院校全覆盖。各县（区）要不断创新宣传形式，着力提升宣传效果，充分发挥传统媒体和新媒体的传播特点和优势，注重运用现代传媒、互联网、移动终端等新技术，采用板报、知识竞赛等接受度高的有效方式，努力提升宣传效果和传播力度，着力扩大社会知晓面，持续营造学习贯彻《条例》的浓厚氛围。三要实施宗教界“法律明白人”培养工程。要抓住宗教界政策法规学习宣传教育的“关键少数”，强化宗教团体、宗教活动场负责人和管理组织的学习政策法规的意识，落实组织学习和发动宣传教育的责任。要在宗教团体、宗教活动场所培养“法律明白人”，做到三个一：宗教院校要培养一支法律宣讲队伍、宗教团体要培养一批法治带头人、宗教活动场所要培养一群法律明白人（以场所管委会成员为主）。通过宗教界“法律明白人”的示范引领，教育引导广大信教群众自觉遵法守法学法用法，在我市宗教领域形成办事依法、遇事找法、解决问题靠法的浓厚氛围，切实维护我市宗教领域的和谐稳定。
