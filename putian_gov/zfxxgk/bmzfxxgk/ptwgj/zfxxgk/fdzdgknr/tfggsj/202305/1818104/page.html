莆田市文物局关于文物安全检查有关问题督促整改的通知

发布时间：2023-05-10 17:04
| | |
 各县区文化体育和旅游局，湄洲岛旅游和文化体育局，北岸党工委宣传部，市直文博单位：

近期，我局赴仙游县、荔城区、城厢区、涵江区、秀屿区和市直文博单位开展“五·一”节前文物安全巡查检查，经查，主要存在以下八个方面文物安全隐患：一是文物安全直接责任人信息未挂牌公示公告；二是灭火器数量配置不足，部分灭火器过期、失压、锈蚀未定期维保或未放置于灭火器箱；三是未设置消防安全标志，安全应急预案和日常检查记录缺失，值班人员不熟悉应急处置流程；四是使用花线，电线紧贴木质结构未套管敷设，夜景亮化灯具直接安装在文物本体上；五是未建设安消防系统工程，监控设施设备无法正常运行；六是在文物本体内违规焚香，堆放易燃物品等杂物；七是文物修缮工地现场安全管理不规范；八是文物本体滋生白蚁、杂草。

上述安全隐患问题我市各县区（管委会）均较为普遍存在，请各县区（管委会）文物行政部门、市直文博单位务必高度重视，举一反三，开展全面对照检查，及时消除各类安全隐患，确保文物安全。相关县区（管委会）文物行政部门要将检查发现问题整改情况（盖章扫描件）于5月20日前报市文物局邮箱ptswwj@163.com，联系人：唐智明，联系电话：2623669。
