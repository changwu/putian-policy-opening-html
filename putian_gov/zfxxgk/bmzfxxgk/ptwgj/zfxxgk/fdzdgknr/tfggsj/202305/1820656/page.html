莆田市文化和旅游局关于印发2023年度文化和旅游安全工作要点的通知

发布时间：2023-05-01 16:27
| | |
 各县区文体旅游局，湄洲岛旅游文体局，北岸党工委宣传部，机关各科室，局属各单位： 

根据《福建省文化和旅游厅关于印发2023年文化和旅游安全工作要点>的通知》（闽文旅市场〔2023〕1号）和《莆田市人民政府安全生产委员会关于印发2023年安全生产工作要点的通知》（莆安委〔2023〕9号），我局制定了《2023年文化和旅游安全生产工作要点》，现印发给你们，请各县区（管委会）文旅部门、机关各科室和局属各单位结合实际，制订具体措施办法，明确责任分工，抓好贯彻落实。

 

                         莆田市文化和旅游局

                         2023年4月21日　　　　

2023年度文化和旅游安全工作要点

 

2023年，全市文化和旅游安全工作总体思路是：坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的二十大精神，深入贯彻落实习近平总书记关于安全生产重要论述重要指示批示和党中央、国务院、省委省政府、市委市政府决策部署，实施“深学争优、敢为争先、实干争效”行动，压紧压实安全生产责任，夯实安全基础，化解安全风险，坚持人民至上、生命至上，统筹发展和安全，力争实现安全生产“零”责任事故。

一、强化安全生产意识

1.及时传达学习习近平总书记关于安全生产重要论述。及时传达学习习近平总书记关于安全生产的重要指示批示精神，以及党中央、国务院决策部署和省委省政府、市委市政府工作要求，研究落实举措，增强工作的前瞻性、主动性和针对性。将学习贯彻习近平总书记关于安全生产重要论述纳入理论中心组学习和干部培训内容，牢固树立新发展理念，坚守红线意识和底线思维，把好安全发展总开关，坚决扛起安全生产政治责任。（人教科牵头，各县区（管委会）文旅部门、机关各科室和局属各单位负责）

二、压紧压实安全责任

2.压实安全生产责任。进一步提高政治站位，承担起“促一方发展、保一方平安”的政治责任，落实好“党政同责、一岗双责、齐抓共管、失职追责”安全生产责任制，加强安全生产工作组织领导。推动文化和旅游经营单位、公共文化单位落实安全生产责任制，健全安全生产规章制度和操作规范，完善应急预案；单位主要负责人严格履行安全生产第一责任人责任，对本单位安全生产负总责。将安全生产有关要求纳入部门权力和责任清单，制定年度安全生产工作要点、重点任务清单，要建立健全安全生产工作领导小组，局党组每季度至少分析研判一次安全生产形势，专题研究一次安全生产工作。与有关部门合作开展联合检查、联合执法，压实安全生产主体责任。对涉及文化和旅游的新兴业态，依据法律和自身职能厘清安全管理责任边界，守好底线。（市场法规科牵头，各县区（管委会）文旅部门、机关各科室和局属各单位负责）

三、推进重点领域风险整治

3.做好旅行社安全管理工作。制订道路交通安全治理工作方案，要求旅行社选择符合条件、有资质的旅游包车，签订规范租车协议。配合有关部门进一步规范旅游客运安全带管理和使用，督促旅行社（导游）提醒游客全程系好安全带，将工作落实情况作为检查旅行社安全工作重要内容。加大对旅行社向不合格的供应商订购产品和服务等违法行为的打击力度。（市场法规科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

4.做好娱乐场所和网吧安全工作。制订网吧和剧本娱乐场所专项整治方案，指导娱乐场所和网吧落实消防安全主体责任，加强消防业务培训演练；开展消防安全隐患排查，重点整治违章搭建使用彩钢板、易燃可燃材料装饰装修、电源火源管理不到位、疏散通道被堵塞占用、安全出口被封堵等突出安全隐患。指导督促剧本娱乐经营场所落实《剧本娱乐经营场所消防安全指南（试行）》有关要求。（市场法规科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

5.做好A级景区安全工作。制订A级景区安全隐患大排查大整治方案，配合景区主管部门全面排查A级景区位于地表河流、湖泊、水库附近和易受山洪、泥石流、滚石等灾害威胁的区域的隐患；排查A级景区内索道、缆车、大型游乐设施等特种设备安全情况，不符合条件的游客禁止参加高风险项目，达不到安全要求的坚决停止运营和使用；指导A级景区落实森林火灾防控措施，开展防火宣传；指导A级景区开展低温天气防范应对和人员疏散工作，针对节假日期间天气和人流特点，提前做好防范措施，督促建立健全流量控制机制，提升应急指挥能力，及时发布流量信息，引导游客合理出行。（资源开发科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

6.做好印刷发行行业安全工作。制订新闻出版安全生产工作要点，督促印刷发行单位严格落实安全工作宣传教育制度、生产人员安全培训制度、安全设施器材维护管理制度；督促建立完善的安全工作检查、安全工作讲评、安全隐患整改、安全工作奖惩机制。督促行业协会、企业主体要组织开展《安全生产法》等相关安全生产法律法规业务培训，完善各类应急预案和应急机制，开展安全生产应急演练，测试应急预案、应急措施、协调联动的实效性，提升应急处置能力。（新闻出版广电科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

7.做好电影放映场所安全工作。制订广电行业安全生产工作要点，督促电影院场所落实消防安全主体责任，制定安全措施，加大安全工作投入，做好治安、消防监控系统和消防设施设备的维护、保养等工作，建立健全安全保障机制和突发事件应急预案；对全市农村电影放映人员开展安全教育，落实安全责任，排除安全隐患，确保农村电影放映场所人身安全、车辆安全等。（新闻出版广电科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

8.强化文物安全管理工作。制订文物消防安全工作要点，全面落实文物安全工作责任制，明确文物安全行政责任人、巡查人和直接责任人，并向社会公示公告。建立健全安全管理应急预案，开展日常巡查检查。规范具火灾危险性文物建筑用火用电管理，加强火源管控，严格安全用电，有序推进安全防护系统工程实施，采取穿金属阻燃管敷设电气线路等保护措施。开展应急预案演练和安全教育培训，提升管理人员防火灭火和应急处置能力。密切关注汛期极端天气变化，组织文物建筑检漏检修，落实落细防灾减灾应急措施，配备必要的安全防护设施设备，对文物保护工程和考古作业施工区域、部位采取加固、支护、围挡等安全措施，提高应对防御水平。（文物科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

9.加强演出安全管理。制订演出安全管理工作方案，指导演出相关单位把安全管理工作落实到进出场、装拆台和排练演出等全过程。认真执行《临时搭建演出场所舞台、看台安全监督检验规范》及舞美装置安全、舞台威亚安全等相关要求，并开展过程监检和安全检测；做好演员人身安全防护工作，开演前务必提早彩排，向演职人员讲解舞台风险点及注意事项，为演职人员购买安全生产责任等保险；制定详实可靠的应急处置预案，适当预备必要、常用的医药物资，全力防范化解演出期间可能发生的风险。（艺术科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

10.做好文化艺术类校外培训机构安全管理。制订文化艺术类校外培训机构安全管理方案，落实培训机构法定代表人或实际控制人为安全管理第一责任人，督促培训机构全面落实国家规定的人防、物防、技防等安全风险防范要求，建立安全管理制度，定期开展安全自查，及时消除安全隐患。培训场所要配备符合相关技术标准的音视频监控设备，确保教室、户外活动场地、活动室、周边等场所无死角，设置明显提示性标识，并应具备与公安、教育等部门实时联网的接口。线上机构还应符合网络安全有关要求。（艺术科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

11.做好公共文化场馆安全工作。制订公共文化场馆安全工作方案，督促各级图书馆、文化馆（站）等公共文化场馆要加强日常安全隐患排查，重点排查整治电源火源管理不到位、消防设施设备没有保养维护、疏散通道被堵塞占用等突出安全隐患。要制定完善应急处置工作预案，针对性地开展消防管理、人员疏散应急处置等相关培训及演练，切实增强安全责任意识和安全管理能力。举办群众性文化活动，涉及舞台搭建要按照《临时搭建演出场所舞台、看台安全监督检验规范》落实好安全措施。（公共服务科科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

12.做好星级饭店安全工作。指导星级饭店做好电梯、锅炉等特种设备的定期维保，排查隐患；指导星级饭店安全规范使用燃气；配合市场监管部门开展星级饭店食品安全监督检查工作，督促其食品经营者落实食品安全主体责任。（市场法规科牵头，各县区（管委会）文旅部门、市文化市场综合执法支队和旅游质量监督管理所负责）

13.做好机关和局属单位的安全管理工作。围绕消防安全、建筑物安全、设施设备安全、食品安全、治安安全、交通安全等重点，加强机关和局属单位安全督导检查，完善隐患整改清单，督促整改落实，推动相关单位提高自查自改能力。加大安全生产培训和宣传力度，提升干部职工安全意识和应急处置能力。（办公室牵头，机关各科室和局属各单位负责）

四、强化安全综合治理

14.抓好反恐怖工作。督促指导各公共文化单位、文博单位、电影院和A级景区等人员密集场所健全完善反恐怖工作制度机制，加强人防、物防和技防建设，开展涉恐隐患自查自治，配合公安部门对文旅经营场所落实反恐责任情况开展督导检查。（资源开发科牵头，各县区（管委会）文旅部门、文物科、公共服务科、新闻出版广电科和市场法规科负责）

15.强化安全生产标准化建设。引导文化和旅游经营单位自觉开展安全生产标准化建设，实现安全生产规范化管理。各科室要对监管行业的安标化建设年内实现全部达标。（市场法规科牵头，各县区（管委会）文旅部门、机关各科室和局属各单位负责）

16.强化突发事件信息报送工作。及时报送文化和旅游突发事件信息，加强突发事件信息研判分析，采取有针对性的措施加强和改进安全管理工作。（市场法规科牵头，各县区（管委会）文旅部门、机关各科室和局属各单位负责）

17.强化安全生产教育培训。加强对《安全生产法》《消防法》等安全法律法规的培训学习，开展文化和旅游安全生产培训和应急演练，推动各部门各单位在相关业务培训中增加安全生产培训和应急演练内容，切实提升安全生产管理和应急处置能力。（市场法规科牵头，各县区（管委会）文旅部门、机关各科室和局属各单位负责）

18.强化安全生产宣传提示。开展“安全生产月”等形式多样的主题活动，及时发布安全提示提醒，多形式、多渠道开展安全宣传引导，持续提升公众安全意识，增强应急避险和自救互救能力。（市场法规科牵头，各县区（管委会）文旅部门、机关各科室和局属各单位负责）

19.建立安全生产常态化督导检查机制。实行“两个每月”工作机制，局分管领导和各行业监管科室要每月组织会商研判安全生产形势，每月开展1次安全生产督导检查。（各县区（管委会）文旅部门、机关各科室、市文化市场综合执法支队和旅游质量监督管理所负责）
