莆田市文化和旅游局关于做好2025年 清明节、劳动节、端午节假日市场工作的通知

发布时间：2025-04-10 09:45
| | |
 各县区文体旅游局，湄洲岛旅游文体局，北岸党工委宣传部，局机关各科室、局属各单位：

2025年清明节、劳动节、端午节假期即将来临，为切实做好假日期间全市文化和旅游行业安全生产工作，有效防范和遏制各类安全事故发生，确保广大游客生命财产安全和文旅市场平稳有序，现就有关事项通知如下：

一、压实工作责任，健全安全体系

按照《莆田市文化和旅游系统安全生产和消防安全治本攻坚三年行动方案（2024-2026年）》要求，严格落实属地管理责任、部门监管责任和经营单位主体责任，紧而又紧、实而又实抓好防风险、保安全、护稳定工作。

（一）落实属地管理责任。各县（区、管委会）文旅部门要按照“党政同责、一岗双责、齐抓共管、失职追责”要求，切实加强对节假日安全生产工作的组织领导，制定详细工作方案，明确任务分工，确保责任落实到岗到人。要加强与公安、应急、自然资源、交通、市场监管等部门的协同配合，指导督促文化和旅游经营单位、公共文化单位严格执行安全生产规章制度，形成工作合力，共同做好文旅行业安全生产监管工作。

（二）强化部门监管责任。各县（区、管委会）文旅部门要严格落实“三管三必须”原则，主要负责人要定期带队对文旅市场开展监督检查，督促文旅企事业单位落实安全生产主体责任。要结合本地实际，针对节假日文旅市场特点，突出重点领域和关键环节，深入开展安全隐患排查整治，及时发现和消除各类安全隐患。

（三）夯实企业主体责任。各县（区、管委会）文旅部门要加强《文化和旅游领域重大事故隐患判定标准》的宣贯解读和落实工作，切实提高重大事故隐患排查整改质量。要督促各类文旅企事业单位严格履行安全生产法定职责，建立健全安全生产管理制度和操作规程，加大安全投入，加强安全培训，完善应急预案，强化应急演练，提高安全管理水平和应急处置能力。要加强对员工的安全教育，增强员工安全意识，确保各项安全措施落实到位。

二、紧盯重点领域，深入排查隐患

聚焦重点领域，全面深入开展隐患排查整治，筑牢坚实的安全屏障。

（一）A级旅游景区。要加强对景区内游览设施设备的安全排查整治，特别是滑道、大型游乐设施、非公路用旅游观光车辆等特种设备，要严格按照规定进行维护保养和检测检验，确保设备安全运行，对不符合安全要求的设备坚决停止运营。要完善景区内安全提示、警示标识和安全防护设施，特别是在危险区域、易发生事故地段要设置明显的警示标识和防护设施。要加强景区内消防安全管理，定期开展消防设施设备检查和维护，确保消防通道畅通。要合理规划景区游览线路，制定游客流量管控方案，加强对景区出入口、重要游览点、室内演出场所等关键节点的管理，严防人员拥堵、踩踏等事故发生。要督促A级旅游景区强化火源管控，加强防火安全提示，严禁野外用火，严防森林火灾。

（二）旅行社。要指导督促旅行社和在线旅游企业选择有资质的供应商、合作商，对旅游产品、旅游线路进行安全评估，合理安排行程。要规范旅游包车行为，全面落实旅行社用车“五不租”制度，加强对导游的安全教育培训，行程中开展经常性安全宣传教育，导游在行程中要及时提醒游客系好安全带，规范使用旅游设施设备。要严格旅游观光船安全管理，督促旅行社依法依规开展海上观光旅游活动，旅行社组织旅游团队活动不得乘坐不具备经营条件和无安全保障的船舶，导游要提醒游客规范使用救生圈、救生衣。

（三）星级旅游饭店。要加强饭店内消防安全管理，对消防设施设备进行检查和维护，确保消防通道畅通。要配合有关部门深入开展燃气安全治理，严格落实人员密集场所和有限作业空间动火作业安全防范措施。加强对厨房、布草间、配电室等重点部位的安全管理，严格用火用电用气制度，防止火灾事故发生。要强化食品安全监管，严格把控食品采购、加工、储存等环节，确保食品卫生安全。要加强对饭店员工的安全培训，提高员工安全意识和应急处置能力。

（四）公共文化场所。要加强消防安全管理，定期开展消防设施设备检查和维护，确保消防通道畅通。要加强对展览展示活动的安全防范，严格活动审批程序，制定安全保障方案和应急预案。要加强对场所内设施设备的安全检查，及时消除安全隐患。要做好人员疏散引导工作，确保在紧急情况下游客能够迅速、安全撤离。

（五）文化娱乐场所。互联网上网服务营业场所、歌舞娱乐场所、游戏游艺娱乐场所等场所要加强消防安全管理，严格落实消防安全制度，定期开展消防设施设备检查和维护，确保消防通道畅通。要加强对场所内电气设备的安全管理，严禁乱接乱拉电线，防止电气火灾事故发生。要严格控制场所内人员密度，防止人员拥堵、踩踏等事故发生。要加强对从业人员的安全教育培训，提高从业人员安全意识和应急处置能力。

（六）文旅活动。要严格遵循“谁举办、谁负责，谁组织、谁负责”的原则，加强演唱会、音乐节等各类文旅活动的安全管理，严格履行报批程序，建立安全管理责任制度。活动主办方要制定详细的安全保障方案和应急预案，明确安全责任，落实安全措施。要加强对活动现场的安全检查，特别是舞台搭建、电力电气设备、消防设施等关键环节，确保活动安全有序。要严格控制活动现场人员数量，做好人员疏散引导工作，防止发生安全事故。

三、丰富市场供给，提升消费能力

各县区（管委会）文旅部门、局属各单位要因地制宜做好节日市场供给，积极开发旅游新产品、新场景，推出特色旅游产品和旅游线路，引导符合条件的经营单位延长开放时间，更好满足人民群众多样化、多层次、多方面的文旅消费需求。要进一步丰富文旅市场供给，推出一批节日主题文艺演出、艺术展览和非遗展示展演、主题活动等文旅促销活动，激发传统文化蕴含的消费潜能。要持续办好“周末戏相逢”公益性演出活动，结合“莆阳爽夏”“5.11演唱会”“5.19中国旅游日”“银河左音乐节”等系列文旅活动，策划推出一批文旅促消费活动。要深挖节日文化内涵，举办主题夜间活动，策划主题夜游项目，活跃夜间消费氛围。要结合全国“五一”文化和旅游消费周，推出特色活动及惠民措施，培育文化和旅游消费新增长点，提升旅游支付便利化水平，激发市民和游客文旅消费意愿。

四、加强综合监管，维护市场秩序

要加强文化市场综合执法检查，加大对旅游、网络表演、娱乐场所、网吧、演出场所、游戏游艺等场所的监管力度，依法查处提供含有国家法律法规禁止内容的文化产品、违规接纳未成年人、未经许可经营旅行社业务、强迫购物、“不合理低价游”、向不合格供应商订购产品和服务等违法违规行为，切实保障市场平衡有序。要以整治导游乱象、强制消费等问题为重点，持续开展“福剑净旅”文旅市场专项整治行动，营造“放心游福建”良好市场环境。要指导星级饭店、等级旅游民宿对照标准，规范服务流程，提高服务质量。要督促演出举办单位严格落实大型演出活动实名购票和实名入场、门票比例等规定要求。要加强对文化娱乐场所日常巡查，畅通举报投诉渠道，及时处置违法违规行为，及时回应社会关切，维护消费者合法权益。要按照属地党委政府部署，认真抓好文旅领域禁毒、反恐维稳、扫黄打非、跨境赌博等工作。要严厉打击旅行社以收取旅游保证金形式销售旅游产品、以旅游项目开发等名义参与非法集资活动。要持续抓好涉旅海上船舶监管工作，督促旅行社、导游依法依规开展海上旅游活动。要加强生态环境保护，严禁旅行社组团赴水资源保护区、生态保护区、自然保护区等区域旅游。

五、加大宣传引导，营造安全氛围

（一）开展安全宣传。各地各单位要充分利用电视、广播、报纸、网络、微信公众号等媒体，广泛宣传文旅行业安全生产知识和应急常识，提高游客的安全意识和自我保护能力。要在景区景点、星级饭店、旅行社、公共文化场所、文化娱乐场所等显著位置设置安全宣传标语、宣传栏，发放安全宣传资料，营造浓厚的安全氛围。

（二）发布安全提示。强化重点时段安全管理，密切关注台风、暴雨等气象预警信息，提醒旅行社、导游及游客落实好极端天气安全防范措施，合理规划旅游行程，谨慎参与高风险旅游项目，遵守旅游安全规定。特别是在节假日期间，要加强对旅游热点地区的安全提示，引导游客错峰出行，避免前往人员密集场所和危险区域 。

（三）加强文明旅游宣传。各县区（管委会）文旅部门、局属各单位要深入开展文明旅游公益宣传、教育引导和志愿服务，举办“文明旅游 美丽中国”主题系列活动。督促旅行社落实好出境游团队行前说明制度，加大出境文明旅游提示提醒，引导游客文明出行、文明游览、文明消费，自觉遵守旅游秩序和景区规定，爱护环境和文物，共同营造文明和谐的旅游环境。要引导游客按需取餐，文明就餐，拒食野味，剩菜打包，落实“光盘行动”，杜绝舌尖上的浪费，树立文明、健康、绿色旅游新风尚。

各地各单位要按照《文化和旅游假日市场工作导则》有关要求，严格落实24小时领导带班、专人值班制度，确保信息畅通，确保出现重大安全事故不漏报不瞒报。要联合相关部门开展督导检查，做好假日市场信息报送工作。请各县区（管委会）文旅部门于清明节假期最后一天（4月6日）、劳动节假期第一、三、五天（5月1日、3日、5日)、端午节假期最后一天（6月2日）10时30分前将本地假日市场情况报送我局值班室和邮箱，以便汇总上报省文旅厅。报送内容主要包括当日游客接待量、假日活动亮点、督促检查情况、安全生产情况等。局属各单位假日期间每日15时前向局值班室和邮箱报送每日安全情况和假日活动亮点（报送时间若有调整以最新通知要求为准）。市文旅局值班电话:2696660;传真:2692819;邮箱：pt2696660@163.com。
