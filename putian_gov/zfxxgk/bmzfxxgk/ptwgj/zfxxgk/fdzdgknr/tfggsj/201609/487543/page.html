莆田市文化广电新闻出版局关于印发莆田市文化广电新闻出版系统防范和遏制重特大事故工作实施方案的通知

发布时间：2016-07-28 10:23
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属各单位，机关各科室：

为进一步推进落实安全防控措施，有效防范和遏制重特大事故，根据市安办《关于印发莆田市防范和遏制重特大事故工作实施方案的通知》（莆市安办﹝2016﹞25号）要求，结合我市文化广电新闻出版系统实际，制定《莆田市文化广电新闻出版系统防范和遏制重特大事故工作实施方案》，现印发给你们，请认真贯彻执行。

 

 

                  莆田市文化广电新闻出版局  

                  2016年7月28日

莆田市文化广电新闻出版系统

防范和遏制重特大事故工作实施方案

 

    为认真贯彻落实党中央、国务院，省委、省政府，市委、市政府决策部署，着力解决当前安全生产领域存在的薄弱环节和突出问题，强化安全风险管控和隐患排查治理，有效防范和遏制重特大生产安全事故发生，结合我市文化广电新闻出版系统实际，制定本工作方案。

    一、工作目标

    到2018年，努力争取实现以下工作目标：
    （一）构建形成安全风险分级管控和隐患排查治理双重预防性工作体系。
    （二）构建形成惩治违法违规行为制度体系。
    （三）构建形成安全生产源头治理体系。
    （四）构建形成安全生产专项整治体系。
    （五）构建形成安全生产应急救援体系。

    二、组织领导
    成立以局长为组长，局各分管领导为副组长，局属各单位主要负责人为成员的工作领导小组，领导小组办公室设在局办公室，主任由局安办主任兼任，负责组织协调全市文化广电新闻出版系统防范和遏制重特大事故工作的开展。
    三、工作任务

    （一）构建文化广电新闻出版系统安全风险分级管控和隐患排查治理双重预防性工作机制
    1.全面排查评定安全风险和事故隐患等级。在深入总结分析本行业领域重特大事故发生规律、特点和趋势的基础上，每年排查评估工作重点，依据相应标准，分别确定安全风险“红、橙、黄、蓝”（红色为安全风险最高级）4个等级，分别确定事故隐患为重大隐患和一般隐患，并建立安全风险和事故隐患数据库。
    2.建立安全风险分级管控机制。按照“分区域、分级别、网格化”原则，实施安全风险差异化动态管理，明确落实每一处重大安全风险和重大危险源的安全管理与监管责任，强化风险管控技术、制度、管理措施，把可能导致的后果限制在可防、可控范围之内。健全安全风险公告警示和重大安全风险预警机制，定期对红色、橙色安全风险进行分析、评估、预警。落实企业安全风险分级管控岗位责任，建立企业安全风险公告、岗位安全风险确认和安全操作“明白卡”制度。
    3.推进隐患排查治理体系建设。加快推动安全生产网格化管理与隐患排查治理“两化”体系对接融合，实现安全生产监管区域全覆盖、监管企业全覆盖。推进安全生产标准化建设，根据行业细分和生产经营特点，采取专家购买服务方式，督促企业量身定制排查治理清单并做到照单排查、对标整改，实现隐患排查、登记、评估、报告、监控、治理、销案的全过程记录和闭环管理。
    4.建立健全安全风险和事故预警防控制度。加强在建工程建筑余泥渣土受纳场、危险边坡、危化品存放等安全风险源头管控，加强安全风险的前瞻性和预见性研究，及时采取防控措施，超前化解事故风险。及时发布安全风险和事故预警通报，按照应急预案要求做好应急处置，最大限度减少事故损失和人员伤亡。
    （二）严厉打击惩治各类违法违规行为
    5.加强安全监管规范化建设。依法履职，结合实际制定安全监管工作细则。坚持公开为常态、不公开为例外的原则，强化执法信息公开，加大执法监督力度。
    6.依法依规严格落实执法措施。健全“双随机、一公开”检查、暗查暗访、联合执法和重点执法制度，对情节恶劣、屡禁不止、可能导致重特大事故的严重违法违规行为，依法依规处理。
    7.运用司法手段强化从严治理。加强文化执法和刑事司法的衔接。对抗拒执法、逾期不执行执法决定的，由公安机关依法强制执行或向人民法院申请强制执行，对涉嫌犯罪的违法案件，及时移送司法机关，坚决杜绝有案不移、有案不立、以罚代刑。
    8.强化群防群控。推行违法违规曝光工作机制，强化警示教育。进一步畅通渠道，鼓励发动群众举报、媒体曝光违法违规生产经营建设行为，加强社会监督。完善生产经营单位安全生产不良记录“黑名单”制度，完善联合惩戒机制。
    （三）全面加强安全生产源头治理
    9.严格规模准入。严禁新建不符合最低规模要求的小企业。推动实施劳动密集型作业场所空间物理隔离技术工程，严格限制劳动密集型作业场所单位空间作业人数。
    10.严格工艺设备和人员素质准入。督促企业实施更加严格的生产工艺、技术、设备安全标准，严禁使用国家明令禁止或淘汰的设备和工艺，对不符合相关国家标准、行业标准要求的，一律不准投入使用。
    （四）持续开展安全专项整治和实施一批重点工程建设
    11.深入开展安全生产专项整治。结合不同时段和行业特点，深入开展文化市场安全专项整治。
    12.加快实施一批重点工程建设。认真查找容易发生重特大事故的关键环节和制约安全发展的突出问题，明确责任，积极主动落实攻坚措施，加大安全生产投入。
    （五）切实提升事故应急处置能力
    13.加强员工岗位应急培训。督促企业健全全员应急培训制度，针对员工岗位工作实际组织开展应急知识培训，加强应急演练，提升一线员工第一时间化解险情和自救互救的能力。
    14.健全快速应急响应机制。建立健全部门之间应急协调联动制度，强化应急响应。接到事故报告后，事故发生地相关负责同志要立即赶赴事故现场组织抢险救援，在事故现场救援指挥部的统一领导下，高效开展事故处置与应对工作。
    15.开展科学决策与安全施救。充分发挥应急管理专家、企业现场管理人员和救援队伍指挥员在开展救援中的作用，实行科学决策。遇到可能直接威胁救援人员生命安全或者造成次生灾害等情况时，应迅速撤离救援人员，采取相应措施消除隐患。
    16.加强应急保障能力建设。进一步优化布局，加强安全生产应急救援队伍、救援基地建设，强化大型先进救援装备、应急物资和紧急运输、应急通信能力储备。完善应急指挥平台，实现应急资源共享，形成前方救援有力、后方支援有序、综合协调高效的应急保障体系。
    四、工作措施
    （一）加强组织领导。站在坚守红线、安全发展的高度，进一步提高对防范遏制重特大事故重要性、紧迫性和事故规律性的认识，切实把遏制重特大事故工作作为文化安全生产“牛鼻子”工程，摆在重中之重的突出位置。
    （二）加强重特大事故特点和规律的研究。深入研究本行业重特大事故致因特点，针对安全风险高、人员密集的重点区域、重点领域深入分析查找容易发生重特大事故的风险点，研究提出有效管用的事故预防对策措施，对症下药、精准施策。坚持问题导向，瞄准安全生产薄弱环节、风险节点和重点时段，明确责任，看死盯牢，力争在减少事故数量、频次和减轻危害后果上见实效。
    （三）加强事故警示宣传教育。加强安全生产新闻宣传、事故警示教育和网络舆情引导，全面提高文化广电新闻出版企业、从业人员对防范遏制重特大事故重要性的认识，凝聚安全共识，提升全社会安全防范意识和风险防控能力。同时，定期曝光一批重大隐患，惩治一批典型违法行为，通报一批“黑名单”企业，取缔一批非法违法企业，关闭一批不符合安全生产条件的企业，形成齐抓共管、社会共治的工作格局。
    （四）强化跟踪督导和信息报送。落实安全工作例会、季度通报和跟踪督办制度，定期通报工作完成情况。适时组织开展专项检查督查，督促指导工作措施落实，及时解决实施过程中存在的问题，共同推动防范遏制重特大事故。高度重视遏制重特大事故工作情况报送工作，及时部署，明确机构，落实职能和人员。

 

 

莆田市文化广电新闻出版局办公室          2016年7月28日印发
