莆田市文化和旅游局关于进一步做好当前文旅行业安全生产和疫情防控工作的通知

发布时间：2022-09-13 09:26
| | |
 各县区文旅局，湄洲岛旅游文体局，北岸党工委宣传部，机关各科室，局属各单位：

当前正值暑期、汛期和旅游旺季，人员流动大，高温、暴雨、台风天气较多，安全生产和疫情防控形势复杂严峻，为进一步贯彻落实习近平总书记关于安全生产重要论述和重要指示精神，认真落实省、市安全生产工作要求和市疫情防控工作指挥部专题会议要求，根据《莆田市人民政府安全生产委员会转发福建省人民政府安委会关于做好当前安全防范工作的通知》（莆市安〔2022〕14号）、福建省文化和旅游厅《关于进一步加强文旅安全生产和疫情防控工作的通知》和《关于做好当前文化和旅游安全生产工作的通知》（闽文旅市场〔2022〕12号），现就进一步做好当前文旅行业安全生产和疫情防控工作有关事项通知如下：

一、毫不放松抓好安全生产和疫情防控工作

各县区（管委会）文旅部门、机关各科室和局属各单位要进一步提高政治站位，把思想和行动统一到习近平总书记关于安全生产和疫情防控的重要讲话重要指示批示精神上来，按照“疫情要防住、经济要稳住、发展要安全”的总体要求，深刻吸取省内外有关经验教训，充分认识安全生产和疫情防控工作的极端重要性，进一步强化红线意识和底线思维，以强烈的政治责任感和高度的历史使命感做好当前安全生产和疫情防控工作，努力为文旅经济高质量发展营造安全稳定环境，以实际行动迎接党的二十大胜利召开。

二、突出关键环节落细落实安全措施要求

各县区（管委会）文旅部门、机关各科室和局属各单位要牢固树立 “隐患就是事故“ 理念，深入开展安全生产大检查，全面细致开展隐患排查，对排查出来的问题隐患“一抓到底、见底清零”，有效防范化解各类风险。

（一）认真落实全省、全市文物安全工作会议精神，迅速组织对全市各类文保单位开展拉网式排查，对木质结构类文物建筑开展消防安全专项治理，强化日常检查巡查，确保人防物防技防措施落实到位。

（二）积极配合景区主管部门，指导督促A级旅游景区落实景区内游乐场所、游乐设施的安全生产工作，根据属地 政府具体要求，指导A级旅游景区及时采取关闭场所和转移人员等措施。

（三）严格督促旅行社不得租用 “无运营资质” 的车辆、民船、渔船等非法交通运输工具，并签订合同，明确责任；严禁旅行社组织旅游团队到未开放开发的景区（点）、海岛等从事旅游活动；不得组织旅游团队到受灾地区、台风地区从事旅游活动。

（四）督促星级饭店等使用燃气的文旅经营单位与合法的供气企业签订供用气合同，按照有关规定安装可燃气体浓度报警装置，开展燃气使用安全自查，并对相关经营单位自查情况及隐患整改情况进行督促检查。

（五）持续推进歌舞娱乐场所消防安全标准化管理，针对高层建筑、公共娱乐场所和星级饭店等人员密集场所，加强火灾风险研判，加大执法检查力度，督促相关经营单位加强隐患自查。

三、紧盯重点严格落实疫情防控要求

各县区（管委会）文旅部门、机关各科室和局属各单位指导A级旅游景区落实“限量、预约、错峰”要求，按照属地党委、政府的疫情防控要求，控制游客接待上限；落实门票预约制度，确保游客信息可查询可追踪；落实进景区景点前扫码登记、测体温等要求，督促游客执行好 ”一米线”、佩戴口罩等防控措施。严格落实跨省旅游经营活动管理 ”熔断“ 机制，督促旅行社和在线旅游企业加强风险研判，合理规划线路，不得组团前往省内外中高风险地区所在县（市、区）旅游，不承接来自中高风险地区所在县（市、区）的旅游团队；严格落实“一团一报”制度，及时如实在全国旅游监管服务平台填报团队信息，上传电子合同。加强星级饭店、剧院、博物馆、 公共图书馆、文化馆、美术馆、A级旅游景区室内场所、娱乐场所、上网服务场所及剧本娱乐经营场所等空间相对密闭场所的疫情防控，按照防疫指南合理设置人员接待上限，强化卫生管理，加强通风消毒，对进入场所人员严格落实扫码、测温等防控措施；对于在室内文旅活动场所开展活动的，要按照属地疫情防控部署要求落实好常态化疫情防控工作。

四、强化协同联动提高应急处置能力

各县区（管委会）文旅部门要结合本地实际，进一步修订完善疫情防控应急处置方案预案，细化实化响应流程、应急措施、处置规范等具体内容。要加强与卫健、疾控、公安、工信等部门的沟通协调，强化联防联控，形成工作合力。一旦出现疫情，应根据跨省旅游“熔断”要求，立即暂停旅行社及在线旅游企业经营进出出现中高风险区的县（市、区）跨省团队旅游及 “机票＋酒店” 业务，对团队游客全面排查，落实核酸检测；针对滞留游客，要在属地党委、政府的领导下，会同相关方面耐心细致做好服务保障和安置等工作，做好舆情处置和涉疫投诉化解工作。

五、加大督导检查和宣传引导力度

各县区（管委会）文旅部门、机关各科室和局属各单位要加大安全生产和疫情防控工作指导检查力度，对安全责任落实、隐患排查整治、宣传教育引导等情况开展检查，对发现的问题督促相关单位整改到位。市文化市场综合执法支队要把疫情防控督导检查作为执法检查的重要内容，督促各类文化和旅游经营单位落实防控主体责任，严格执行防控措施，完善应急处置方案预案，加强演练培训，做好疫情防控物资和条件的准备，提升疫情防控能力。各县区（管委会）文旅部门、机关各科室和局属各单位要通过网站、微信公众号和微博等多种渠递宣传安全生产和疫情防控有关知识，广泛开展 “文明旅游” 系列宣传活动，引导广大游客提高安全意识，合理安排行程，加强个人安全防范；要加强旅游安全提示，提醒游客谨慎参与高风险项目，不擅自进入未开发、未对社会公众开放区域开展旅游活动，自觉遵守旅游目的地有关安全管理和疫情防控规定。
