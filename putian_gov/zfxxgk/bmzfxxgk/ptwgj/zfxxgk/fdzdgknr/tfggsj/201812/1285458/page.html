莆田市文化广电新闻出版局关于印发《安全生产百日攻坚促提升行动方案》的通知

发布时间：2018-11-27 17:07
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属各单位，机关各科室：

现将《莆田市文化广电新闻出版局安全生产百日攻坚促提升行动方案》印发给你们，请结合实际认真贯彻执行。

 

 

                     莆田市文化广电新闻出版局

                          2018年11月27日    

 

 

 

 

莆田市文化广电新闻出版局

安全生产百日攻坚促提升行动方案

 

为进一步巩固安全生产“严排查、严整治、严监管”活动成效，推动“严整治、促提升”专项行动增效，全力推进安全生产整治攻坚，坚决遏制各类生产安全事故发生，根据市安办《安全生产百日攻坚促提升行动方案》的通知（莆市安〔2018〕14号）文件精神，按照市委、市政府部署要求，决定在全市文化广电新闻出版系统内组织开展安全生产百日攻坚促提升行动，现制定如下方案。

一、目标任务

全面贯彻落实市委、市政府关于开展安全生产百日攻坚活动部署要求，以有效防范和坚决遏制各类生产安全事故为重点，强化特殊时期安全生产管控措施，着力解决影响当前安全生产突出问题和薄弱环节，提升安全生产工作水平，进一步促进全市文化广电新闻出版系统安全生产形势安定稳定。

二、组织领导

由局安办负责安全生产百日攻坚促提升行动的组织实施，局属各单位及机关各科室负责日常具体工作。

三、时间安排

即日起至2019年2月底

四、重点工作

（一）宣贯落实党政领导干部安全生产责任制。认真学习贯彻落实《地方党政领导干部安全生产责任制规定》《福建省党政领导干部安全生产责任制实施细则》，通过举办学习研讨、辅导讲座、专题讲座等多种形式，组织党政领导干部进行系统学习，切实增强政治意识、大局意识、核心意识、看齐意识，强化抓好《规定》《实施细则》贯彻落实的政治自觉和责任自觉。

（二）持续深化重点行业领域专项整治。继续深入开展安全生产“严整治、促提升”专项行动，突出文化娱乐场所重点行业领域场所安全生产专项整治。

（三）持续加大安全生产监管执法力度。深入开展安全生产执法专项行动，突出重点领域重点单位、重点领域重点单位、重点部位重点环节，强化部门执法、联合执法、精准执法，实现对重点企业检查执法率达100%、对发现的安全生产违法行为依法查处率达100％、对检查发现存在安全生产问题企业的复查率达100％、对举报各类安全生产违法行为的核实查处率达100％。

（四）强化重点时段安全生产管控保障。切实加强重大活动、元旦春节等重点时段安全生产管控保障，盯紧盯牢事故多发易发的地区、场所和行业领域，切实细化风险防范和隐患治理措施，摸排查清安全风险隐患点，集中力量进行整改，并强化重点时段安全巡查管控力度，落实专业人员及技术保障。密切关注灾害性天气、地质灾害预测预报和人流车流监测，加强部门间沟通联系、会商分析，第一时间发布预警信息，指导企业和社会公众做好防范应对。严格执行领导带班和重要岗位24小时值班制度，加强应急准备，确保发生紧急情况及时响应、及时处置，最大限度减少损失影响。

（五）认真开展安全生产问题隐患“回头看”。从严落实安全生产问题隐患整改责任，坚决杜绝安全生产领域各类督查检查查出问题隐患“表面整改”“虚假整改”等问题，对2018年以来本行业领域以及上级各类督查检查查出的隐患和问题整改落实情况进行“回头看”，逐项复查整改情况，并对涉及的企业安全生产情况进行一次全面检查。

（六）夯实安全生产基层基础能力。认真贯彻落实上级关于推进安全生产领域改革发展的系列文件及我市实施意见，按时完成2018年度51项安全生产领域改革发展重点任务。树立一批本行业领域双重预防机制标杆企业、试点企业（各县区不少于1家），探索建立一整套可借鉴、可推广、可套用的企业安全生产风险管控和隐患排查治理双重预防机制。推动“网格化+安全生产”工作，完善安全网格化管理工作体系，打通安全监管最后一公里。

（七）大力营造安全生产浓厚氛围。深入开展安全生产进企业、进文化公共场所宣传活动，全面加强安全生产知识宣传教育和普及，切实增强社会公众安全法制观念和意识。

五、工作要求

（一）加强组织领导。各单位要高度重视，切实加强安全生产百日攻坚促提升行动的组织领导，做到主要负责人亲自抓，分管负责人具体抓，多级联动，层层抓紧、抓实、抓好。要召开专题会议分析研判当前安全生产形势，制定切实可行的工作措施，全力确保完成各项任务。

（二）强化督导检查。局安办将对行动开展情况进行督查，并在年终考核时一并进行考核。各单位要加强监督检查，采取“四不两直”、暗查暗访、“双随机”等方式深入基层和生产一线进行督导检查，掌握本行业领域行动开展真实情况，及时发现问题，及时解决问题，确保活动取得实效。

（三）广泛宣传发动。各单位要充分利用电视、报纸等各种媒体，加大宣传和舆论监督力度，教育引导企业和广大职工增强做好安全生产百日攻坚促提升行动的主动性和自觉性。积极宣传先进典型，激励引导广大干部在安全生产工作中勤勉尽责、担当作为。

（四）加大问责力度。对本行业领域安全生产百日攻坚促提升行动工作开展消极应付、任务滞后的单位和个人，视情采取约谈提醒、诫勉谈话、通报批评、组织处理、纪律处分等措施，倒逼相关责任人把责任扛在肩上、抓在手上、放在心上。对行动期间发生的生产安全责任事故，切实从快、从严、从重查处，着力提升事故查处和警示教育力度。
