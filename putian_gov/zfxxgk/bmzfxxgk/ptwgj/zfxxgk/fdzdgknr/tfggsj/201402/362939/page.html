莆田市文化广电新闻出版局关于开展2014年度全市印刷企业年度核验及换发《印刷经营许可证》工作的通知

发布时间：2014-02-18 08:00
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，市印刷行业协会，有关印刷企业：

根据省新闻出版广电局《关于开展2014年印刷企业年度核验及换发〈印刷经营许可证〉工作的通知》（闽新广出发[2014]2号）文件精神，决定开展全市印刷企业2014年度核验及换发《印刷经营许可证》工作。现将有关事项通知如下：

一、核验工作范围

参加年度核验的单位为领取《印刷经营许可证》的印刷企业单位，含2013年新批准设立的印刷企业。

二、核验工作时间

年度核验工作至2014年3月31日前完成。

三、年检工作部署

（一）出版物、出版物（专项、排版、制版、装订）印刷企业由省新闻出版广电局年检。

（二）包装装潢印刷企业、其他印刷品印刷企业由各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部受理初审，市文化广电新闻出版局组织年检，市印刷行业协会配合。

四、核验企业需报送的材料

（一）《2014年印刷企业年度核验表》一式三份。《印刷企业审核登记表》所填资料必须完整、清晰；空缺项目必须说明原因。

（二）印刷企业自查报告。主要包括：执行国家有关印刷管理法规规章情况；开展印刷经营活动的基本条件；印刷经营情况及经营业绩；奖励和受处罚情况；国内设备使用情况、国外新旧设备的引进情况，《产业结构调整指导目录》（淘汰类）的印刷设备是否已淘汰；产品质量情况，通过ISO9000、ISO14000及其他认证情况，实施企业资源计划管理系统（ERP）的情况；实施绿色印刷的情况；对违规行为的整改情况；统计数据报送情况及其他需要说明的情况；参加培训情况；兼并重组的情况；组建印刷集团的情况；企业发展受国内外经济形势的影响；对出版行政部门在印刷管理方面的建议等。

（三）《印刷经营许可证》（正本、副本原件），《营业执照》（副本复印件）；

（四）《外商投资企业批准证书》（复印件，限外商投资印刷企业）；

（五）《印刷法规培训合格证书》（复印件）；

（六）《组织机构代码证（副本）》（复印件）。

各印刷企业核验材料报送各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部。各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部对印刷企业年度核验提出审核意见，并在《2014年印刷企业年度核验表》上加盖公章；审核时应对企业上报的材料是否完整、翔实严格把关，必要时应进行现场查验，掌握辖区内印刷企业的具体情况，切实履行“属地管理”的工作职责；核验材料汇总后报送市局，市局联合市印刷行业协会进行年检，通过年检的印刷企业，市局委托市印刷行业协会统一发放《印刷经营许可证》；《2014年印刷企业年度核验表》一份上报省局，一份返回各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部。

五、审核登记主要内容

（一）注册资本是否符合规定；

（二）生产经营场所是否符合规定；

（三）印刷设备是否符合规定，列入《产业结构调整指导目录》（淘汰类）的印刷设备是否已淘汰。

（四）法定代表人及主要生产、经营负责人是否取得《印刷法规培训合格证书》；

（五）是否按照《印刷业管理条例》、《印刷品承印管理规定》等有关法规、规章要求建立、健全印刷企业五项制度，并在日常生产经营中贯彻执行。

（六）印刷产品是否达到国家规定的各项质量标准要求；

（七）是否按规定按时逐项向新闻出版行政部门报送统计数据，各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部对列入新闻出版网上统计的企业要认真把关；

（八）出版物印刷企业应提交2种以上由省级以上国家法定质量监督检验机构出具的质检报告（或省优产品证书）；

（九）有无违反印刷管理规定的行为。

六、审核登记条件

（一）准予审核登记。对符合《印刷业管理条例》第八条、《印刷业经营者资格条件暂行规定》、《设立外商投资印刷企业暂行规定》、《数字印刷管理办法》要求的资格条件，无违反印刷管理法规规章行为，按规定向新闻出版行政部门及统计部门报送数据，在规定时间内递交核验材料的印刷企业，准予审核登记。

（二）印刷企业有下列情形之一的，须暂缓审核登记：

1.经审核发现有违法行为应予以处罚的；

2.正在限期停业整顿的；

3.法定代表人及主要生产、经营负责人未取得新闻出版行政部门颁布的《印刷法规培训合格证书》；

4.未按规定报送统计报表的；

5.存在严重质量问题的企业；

6.存在安全隐患的企业。

暂缓审核登记的企业在暂缓期间应进行认真整改，整改到位后，提交书面申请，报各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部审批。暂缓期满，按本通知规定重新办理审核登记。

（三）印刷企业有下列情形之一的，不予通过审核登记：

1.违法行为被查处后拒不改正或者没有明显整改效果的；

2.已经不具备《印刷业管理条例》第八条和《印刷业经营者

资格条件暂行规定》、《设立外商投资印刷企业暂行规定》、《数字印刷管理办法》规定的资格条件的。    

未通过审核登记的印刷企业，不得继续从事印刷经营活动，

由原审批的新闻出版行政部门收回《印刷经营许可证》。印刷企业未在规定的时间内申报审核登记，下发催告通知书30日内仍未申报的，由原审批的新闻出版行政部门注销《印刷经营许可证》。印刷企业必须于2014年3月15日前向各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部报送核验材料，逾期不予受理。

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸

工委宣传部于2014年3月25日前向市局报送印刷企业核验材料、《年检情况汇总表（名录）》、被缓期登记、警告、罚款及其它行政处罚企业名单，逾期不予受理。
