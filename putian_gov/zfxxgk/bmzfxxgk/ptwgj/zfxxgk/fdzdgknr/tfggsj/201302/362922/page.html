莆田市文化广电新闻出版局关于印发莆田市文化广电新闻出版系统继续深入开展清剿火患战役工作方案的通知

发布时间：2013-02-18 08:00
| | |

各县区（管委会）文体广电出版局（社会事务办、文教局），局属各单位，机关各科室：

现将《莆田市文化广电新闻出版系统继续深入开展清剿火患战役工作方案》印发给你们，请认真贯彻落实。

 

 

                      莆田市文化广电新闻出版局

                       2013年2月18日

 

 

 

 

莆田市文化广电新闻出版系统

继续深入开展清剿火患战役工作方案

 

根据《莆田市人民政府办公室关于印发全市继续深入开展清剿火患战役工作方案的通知》（莆政办明电〔2013〕9号）精神，为巩固全市文化广电新闻出版系统“清剿火患”战役成果，进一步加大火灾隐患的排查整治力度，经研究，决定从即日起到2013年12月31日，在全系统继续深入开展“清剿火患”战役行动。

一、工作目标
　　在去年开展“清剿火患”战役的基础上，继续深入排查文化公共场所、文化经营场所、文物保护单位和印刷企业火灾隐患，采取行政、法律、社会监督等手段，有效控制动态火灾隐患，杜绝源头性火灾隐患，全面消除一般火灾隐患，彻底整治重大火灾隐患，进一步夯实火灾防控基础，有效遏制火灾事故，特别是群死群伤火灾事故。

二、清剿范围和工作重点
　 （一）未排查整治的单位场所。各单位要按照谁主管、谁负责和属地原则，组织有关人员对文化公共场所、文化经营场所、文物保护单位和印刷企业隐患排查整治工作开展“回头看”，尤其要对前期排查不到位或整治不彻底的场所开展新一轮排查，重点整治未经消防设计审核、消防验收投入使用的场所。
　 （二）小单位及“三合一”场所。小网吧、小歌厅和小印刷企业及“三合一”场所等，重点整治建筑耐火等级、生产储存经营和人员住宿防火分隔、安全疏散不符合消防技术规范、以及违章存放易燃易爆化学物品、非法设置可燃物堆场和仓库、违章用火用电用气、安全出口堵塞、违规设置员工宿舍等火灾隐患。
　　（三）人员密集场所。重点整治建筑消防设施损坏、关停、瘫痪，疏散通道堵塞，安全出口锁闭，易燃易爆场所未采取防火防爆措施，以及自动消防设施操作人员未经培训或无证上岗，重大火灾隐患和突出消防安全问题。各单位要将存在重大火灾隐患、消防违法行为和“四个能力”建设不落实的单位纳入重点整治范畴，研究制定整改方案，明确整改时限。要落实重大火灾隐患逐级挂牌督办制度，定期跟踪落实并通报整改进展情况，并报送同级公安消防机构依法进行处理。
　　三、实施步骤

（一）动员部署阶段（2月8日至2月20日）。各单位要按照本方案要求，结合各自实际，制定详细的工作方案，明确“清剿火患”战役目标任务和工作措施，并在本单位进行广泛宣传、动员、部署。

（二）组织实施阶段（2月21日至12月31日）

1.开展“除火患、保平安”冬春专项行动。从2月21日至全国“两会”闭幕。围绕“两节”、“两会”消防安全保卫任务，重点排查整治公共文化场所、文化经营场所、文物保护单位等人员密集场所，博物馆建设施工工地和节庆场所等。

2.开展消防安全专项治理活动。从4月1日至12月底。市文化市场执法支队和市文管办要在分析研判全市文化市场和文物保护单位消防安全形势的基础上，结合实际组织开展不少于2次的消防安全专项治理行动，重点整治“三合一”、“多合一”场所等，及时上报消防安全专项治理情况。　　

3.开展重大节日、重要活动消防安全检查活动。各重大节日、重要活动期间。各单位要围绕劳动节、国庆节、中秋节、圣诞节等重要节日、重大活动消防保卫任务，组织开展以公共娱乐场所等公众聚集场所、节庆主要活动场所及周边场所等重点的安全检查活动。

（三）总结阶段（2014年1月1日至1月15日）。认真总结经验做法，巩固战役成效，逐步建立火灾防控长效机制。

四、工作措施

（一）严查火患，排除火灾隐患。各单位要认真梳理未纳入监管范围的区域、单位和场所，确保全部排查到位。对火灾隐患不清的人员密集场所开展“回头看”，重新组织排查，彻底查清火灾隐患底数。对不及时消除火灾隐患可能严重威胁公共安全的“三合一”等场所，要依法采取临时查封措施；对未通过消防行政许可的文化经营场所、网吧、印刷企业，要依法责令停产停业；对占用、堵塞、封闭疏散通道、安全出口、消防车通道，或者在公共文化场所、文化经营场所等人员密集场所门窗上设置影响逃生和灭火救援的障碍物，拒不改正的，要依法予以强制执行；对排查中发现安全隐患的场所，应积极配合公安、消防等部门坚决依法予以取缔。未依法取得营业执照的文化经营场所从事经营活动的，提请工商行政管理部门依法予以取缔；对凡逾期不改或经整治仍达不到基本消防安全要求、危及人员生命安全的，必须吊销相关证照并坚决依法予以取缔。

（二）广泛宣传，提高防范能力。各单位要充分利用各种手段和形式，加大对“清剿火患”行动的宣传力度，提醒社会单位加强自身安全防范，警示群众提高消防安全意识，营造浓厚的行动氛围。要结合各单位的实际，强化内部安全管理人员和重点岗位的消防安全培训，提高单位履行消防安全职责的意识和能力，强化员工扑救初起火灾和组织疏散逃生的基本技能，不断增强员工消防安全意识。执法单位要设立举报电话、电子信箱，接受群众举报。

请单位于每季度结束后5日内将本单位前一季度本单位开展“清剿火患”的阶段总结报局办公室，2013年12月31日前报送工作总结。
