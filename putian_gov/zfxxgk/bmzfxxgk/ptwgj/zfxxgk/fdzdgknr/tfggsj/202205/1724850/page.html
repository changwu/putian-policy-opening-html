莆田市文化和旅游局关于做好全市广电行业安全生产工作的通知

发布时间：2022-05-13 08:32
| | |

各县区文化体育和旅游局（新闻出版广电局）、北岸工委宣传部、湄洲岛旅游和文化体育局，市广播电视台，福建广电网络集团莆田分公司，市文化市场综合执法支队：

为认真落实国家广电总局关于安全生产工作部署要求，按照4月21日召开的全省广电行业安全生产电视电话会议精神，深刻认识做好安全生产工作的极端重要性，围绕迎接宣传贯彻党的二十大工作主线，结合开展“提高效率、提升效能、提增效益”行动，扎实抓好安全生产工作，有效防范化解各类风险隐患，全面提升全市广电行业安全保障水平。现将有关要求通知如下：

一、压紧压实安全生产主体责任

全面落实安全播出保障单位、部门的主体责任，确保各项责任落实到岗、到位、到人。加强核心部门、关键岗位值班值守力量，领导干部要以上率下、靠前指挥，确保广播电视安全播出和各类信息系统网络安全。市广播电视台负责莆田电视、调频广播和仙游广播电视台的安全播出；壶公山转播台安全发射任务，中央、省无线覆盖代维业务以及省干线微波安全传输业务，监听监看监测广播电视信号情况等。福建广电网络集团莆田分公司负责全市广播电视网络安全传输、防范非法插播、安全保障等。

二、落实落细安全生产监管责任

各县区（管委会）广电行政部门要进一步提高政治站位，把深入学习贯彻习近平总书记关于安全生产工作的重要指示批示精神作为一项重要的政治任务，深刻认识安全是高质量发展的前提基础和内在要求，充分认识当前安全生产形势的复杂性和严峻性，时刻绷紧安全生产这根弦，牢固树立安全生产“底线思维”和“红线意识”。进一步细化安全播出保障工作方案,市、县区（管委会）广电行政部门负责广播电视安全播出工作的统筹协调，监督融媒体中心、广播电视记者站、广电网络分公司做好本辖区内广播电视安全播出工作，协调处置突发应急事件（事故）等，要围绕党的二十大各项重大活动直播转播工作万无一失的工作目标，有针对性地细化完善实施符合本辖区、本单位工作特点的安全播出保障工作方案。

三、切实加大执法专项检查力度

（一）持续加强广播电视设施保护和安全防范。市广播电视台、市广电网络公司要加强与公安、无线电管理等相关部门的沟通协调，持续做好防范5G基站干扰广播电视卫星接收相关工作，做好防范非法攻击、破坏、插播等工作。加强广播电视重要设施和传输线路的巡查、值守，及时排查消除隐患和故障。加强广播电视无线传输覆盖网管理，严格执行无线电管理各项规定，确保无线电用频安全。加强重点单位、重点部位的安全防护和人员排查，完善人防、物防、技防，全面提高安全防范应急处置能力，确保各项安全防范工作严密有效。

（二）持续开展非法卫星电视接收设施专项整治。市、县区（管委会）文化执法机构要抓好生产、流通、销售环节整治，加强与公安、市场监管等相关部门沟通配合，及时移交相关案件线索，齐抓共管、形成合力，特别是对老城区、城乡结合部等重点区域非法储存销售卫星电视接收设施行为进行全面、集中、彻底整治。抓好安装、使用环节整治，依法查缴、拆除单位和个人非法安装使用的卫星广播电视地面接收设施，针对重点问题要重点查处，对存在问题较多、治理难度大的区域，要采取集中行动进行严厉打击。抓好重要时机整治，组织开展非法卫星电视接收设施专项检查，按照纵向到底、横向到边，不留死角的工作要求，统筹联动，多措并举，扎实开展集中整治工作，确保达到整治效果。

（三）持续开展配合打击治理“黑广播”违法犯罪集中行动。市、县区（管委会）文化执法机构要认真对照广电部门的职责分工，切实履职尽责，充分依托无线电管理机构、公安部门技术手段提高快速发现“黑广播”的监测能力，加强对调频广播频段的全方位、全时段监测，不断扩大监测面，提升监测水平，依法严厉查处“黑广播”违法犯罪行为。

四、全面开展安全生产隐患大排查大整治

（一）开展安全播出大检查。各单位要紧紧围绕迎接党的二十大安全播出保障开展大检查工作，重点检查隐患问题的排查和整改，技术系统配置和运行维护，监听监看和应急处置，以及网络安全、技术安全、安全生产和反恐、防范夏季雷雨、台风等方面的防范措施和应急预案制定等。一是自查自纠。各安全播出责任单位落实安全播出主体责任，安全自查、隐患自除、责任自负，督促指导相关单位开展自查工作。二是现场检查。要对辖区内有关单位开展检查工作，核验安全播出的制度、工作预案、运行维护档案的完整性、有效性，对播出传输相关技术系统中的供配电配置、信号源配置、主备系统配置、网络安全配置、应急处置流程等方面进行现场抽查、核实。三是随机抽查。我局将随机抽查有关单位，重点抽查建党百年安全播出大检查发现问题的整改情况和安全播出管理其他问题。

（二）开展房屋安全大检查。各县区（管委会）广电行政部门及有关单位要对标对表，采取自查、普查、督查等多种形式，及时消除管辖领域内房屋安全、消防安全等各类隐患。对检查中发现的隐患问题，要坚决依法立即整改。不能立即整改的，要制定整改方案，明确整改措施，落实整改责任、部位、资金和期限。市广播电视台要贯彻落实《广播电视系统重点单位重要部位的风险等级和安全保护级别》，强化对壶公山发射台、播控机房等重点部位的人防、物防、技防、联防建设，安全隐患排查整治工作，严密防范措施，堵塞安全漏洞，完善应急预案。福建广电网络集团莆田分公司要督促落实所属单位老旧房屋安全隐患排查整治，该加固的，立即加固，该停用的，坚决停用，彻底消除安全隐患。

（三）组织业务培训和应急演练。各单位要组织开展业务培训，完善各类应急预案和应急机制，在本辖区、本单位范围内分层级分业务开展安全播出应急演练，测试各单位应急预案、应急措施、上下游单位协调联动的实效性，提升应急处突能力。市广播电视台、市广电网络公司要积极组织针对行业关键信息基础设施等重要系统的网络攻防实战演习和渗透测试。

五、实施安全播出月和重要保障期高等级保障。在党的二十大重要保障期和安全播出月期间，各单位要加强组织领导，层层动员部署、广泛宣传发动，切实抓出成效，主要负责同志要亲自研究、亲自部署、亲自协调，其他负责同志要认真履行各自岗位的安全职责，明确专人牵头负责相关工作，落实落细职责分工，提高安全播出保障等级，强化保障措施，加强指挥调度、值班值守、巡视巡护和运行维护，严防非法攻击、破坏、干扰、插播等事件，严格事件事故调查处理。同时，要加强与网信、工信、公安、综治、消防、电力、通信等部门沟通联系，建立健全突发事件应急协调机制，形成工作合力。

六、深入开展安全生产主题宣传。充分发挥广电系统优势，广播电视播出机构、融媒体中心、“村村响”应急广播等，设置安全生产专题专栏，深入宣传解读习近平总书记关于安全生产的重要论述和省委、市委关于安全生产的决策部署，做好重点工作宣传、经验做法推广、安全生产知识普及。广泛深入开展安全生产宣传报道，制作播出一批安全生产公益广告，营造浓厚社会氛围，为我市安全生产工作高质量发展贡献广电力量，以安全生产的优异成绩迎接党的二十大胜利召开。
