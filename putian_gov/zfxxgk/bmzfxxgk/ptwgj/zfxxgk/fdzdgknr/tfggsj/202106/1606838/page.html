莆田市文化和旅游局关于开展2021年“安全生产月”和“莆田安全发展行”活动的通知

发布时间：2021-06-04 15:45
| | |

各县区文旅局，湄洲岛旅游文体局，北岸党工委宣传部，机关各科室，局属各单位：

    根据《福建省文化和旅游厅关于开展2021年“安全生产月”和“八闽安全发展行”活动的通知》和《莆田市人民政府安委会办公室 莆田市应急管理局关于开展2021年“安全生产月”和“莆田安全发展行”活动的通知》（莆市安办〔2021〕14号）要求，结合我市文化和旅游实际，现就开展2021年“安全生产月”和“莆田安全发展行”活动有关事项通知如下：

一、总体思路

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中、四中、五中全会精神，坚持人民至上、生命至上，紧紧围绕全市安全生产重点工作，紧密结合庆祝建党100周年活动，深入宣传贯彻落实习近平总书记关于安全生产重要论述和来闽考察重要讲话精神，落实市委市政府部署和市领导批示要求，扎实推进安全生产专项整治三年行动集中攻坚、安全隐患大排查大整治及“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动，有效防范和科学应对事故及灾害，积极推动安全宣传深入开展，增强管理人员、从业人员和消费者的安全意识，提升安全生产水平，营造安全稳定的文化旅游发展环境。

二、活动内容

2021年“安全生产月”活动将于6月1日至30日开展，活动主题为“落实安全责任，推动安全发展”，各县区（管委会）文旅部门和文旅企业要采取多种形式开展“安全生产月”和“莆田安全发展行”活动。

（一）深入学习宣传贯彻习近平总书记关于安全生产重要论述精神

1.开展理论学习。结合正在开展的党史学习教育和“再学习、再调研、再落实”活动，通过理论学习中心组专题学习、干部专题培训、专题巡回宣讲，专题网络课堂等形式，深入学习宣传贯彻习近平总书记关于安全生产重要论述和来闽考察重要讲话精神，专题学习《生命重于泰山——学习习近平总书记关于安全生产重要论述》电视专题片，做好《应急管理体系和能力建设干部读本》的学习使用，教育引导领导干部强化“人民至上、生命至上”理念，牢固树立安全发展理念，增强从根本上消除事故隐患的思想自觉和行动自觉，更好统筹发展和安全，切实把安全责任扛在肩上、落在行动上，以实际行动和实际效果做到“两个维护”。

2.开展主题宣讲。文旅部门领导干部要深入基层开展宣讲，邀请安全生产专家、企业安全生产负责人等，开展学习宣传教育和辅导培训交流。通过广播、电视、报刊、网站、新媒体等平台开设专题专栏，在单位和公共场所的宣传栏、文化廊等广泛张贴学习宣传挂图、海报，开展全方位、多角度、立体化的宣传，扩大安全宣传覆盖面，切实增强安全宣传教育实效。

3.开展宣传培训。切实组织开展文旅企业全员安全生产教育培训，充分以安全生产法律法规、政策文件、标准规程、操作技能和风险隐患排查治理为重点，开展企业全员全岗位安全生产教育培训，推动企业全员落实安全知识应知必会、安全技能应会必会。

（二）深入开展“专项整治集中攻坚”和“控事故、保安全、迎建党百年”专题宣传活动

4.组织好“两个专题”集中宣传。紧密结合《安全生产专项整治三年行动实施方案》和“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动，通过多种形式宣传安全生产责任落实和安全诚信、安全承诺等经验做法，推广在落实责任链条、创新管理举措、优化制度机制等方面的优秀经验做法，提升安全生产工作水平。

5.开展问题隐患排查整治。广泛发动企业职工开展“查找身边安全隐患”“安全红袖章”“事故隐患大扫除”“争做安全吹哨人”活动，对事故易发多发、易造成人员伤亡的重点环节进行全面细致的自查自纠，强化源头治理，切实把风险隐患化解在萌芽之时、成灾之前。

6.开展执法检查和应急演练。加大安全生产执法检查力度，通过开展驻点检查、异地交叉执法检查等方式，深入开展安全生产督查，对存在问题隐患的企业依法处罚。要组织开展行业领域应急演练，督促企业完善应急预案，常态化、规范化开展应急演练。

（三）组织开展好“安全生产月”系列宣传活动

7.开展安全宣传咨询。充分利用“6. 16安全宣传咨询日”，组织开展线上线下相结合、形式多样的咨询活动，集中宣传安全生产政策法规、应急避险和自救互救方法。

8.开展网上互动展示。结合实际，充分利用各类媒体、网站、手机软件等，积极参加“回顾安全生产月20年”网上展览、“测测你的安全力”知识竞赛、“6. 16我问你答”直播答题、“接力传安全－－我为安全生产倡议”等活动。

9.开展事故警示教育。建立安全生产警示教育制度，要采取观看典型事故警示教育片、参观事故警示教育展览、现场警示会等方式开展事故警示教育，提高党政领导干部、安全监管人员、企业负责人以及基层员工的安全意识。

（四）开展“莆田安全发展行”宣传和安全宣传“五进”

2021年“莆田安全发展行”与“安全生产月”活动同步启动，12月份结束。要紧紧围绕《安全生产专项整治三年行动实施方案》和“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动工作要求，曝光突出问题和重大隐患，宣传推广经验做法，推动企业落实安全生产主体责任，不断强化安全生产工作。

10.加大问题隐患曝光力度。结合疫情防控常态化形势和安全生产工作实际，组织开展好专题行等活动，加强问题隐患和反面典型曝光力度，推动企业落实主体责任。

11.开展安全宣传“五进”。紧密结合党史学习教育“我为群众办实事”实践活动，组织广大党员干部深入基层，察民情、访民意、办实事，结合工作实际，扎实推进安全宣传“进企业、进农村、进社区、进学校、进家庭”。要充分利用电视、广播、报纸、网站以及微博、微信等媒体平台，形成全媒体、矩阵式、立体化宣传格局，切实提升公众安全意识和应急处置能力。

各县区（管委会）文旅部门、机关各科室、局属各单位要及时提供活动期间好的做法、特色项目、重要事项以及视频、图片、文字等电子版资料，并于6月30日前报送活动综合情况。
