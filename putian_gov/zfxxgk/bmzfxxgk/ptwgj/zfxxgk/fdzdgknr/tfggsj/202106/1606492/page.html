莆田市文物局关于开展“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动的通知

发布时间：2021-06-03 17:37
| | |

各县区文化体育和旅游局，湄洲岛旅游和文化体育局，北岸党工委宣传部，市直文博单位：

根据《福建省文物局关于开展“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动的通知》（闽文物字〔2021〕133号）和《莆田市人民政府安委会关于开展“控事故、保安全、迎建党百年”》（莆市安〔2021〕3号）等文件要求，自即日起至2021年7月底，在全市文博系统开展“控事故、保安全、迎建党百年”安全生产集中攻坚专项行动（以下简称“集中攻坚行动”），现将有关事项通知如下：

一、总体要求和目标

认真贯彻落实习近平总书记关于安全生产的重要论述和来闽考察重要讲话精神，按照党中央、国务院关于安全生产的决策部署，全面落实省委省政府和市委市政府工作要求，坚持人民至上，生命至上，严守文物安全红线、底线、生命线，强化“三个必须”（管行业必须管安全、管业务必须管安全、管生产经营必须管安全）要求，全面落实文物安全监管责任，督促协调辖区内各级政府履行文物安全主体责任，督促各文博单位履行文物安全直接责任，统筹推进文物火灾隐患和消防能力提升三年行动，通过开展集中攻坚专项行动，确保全市文博系统安全生产形势持续稳定，以优异的成绩迎接建党100周年。

二、工作任务

深入开展全市文博系统火灾隐患排查整治，特别是文博单位重点场所，逐一梳理整治文博单位电气、用火、燃香烧纸、危险物品、设施设备、消防管理以及其他等安全隐患，重点整治消防安全主体责任不落实、消防设施损坏、违规住人和电动车违规停放充电等隐患，对前期排查整治工作中排查发现但尚未整改到位的问题，要及时督促整改。

三、工作要求

（一）加强组织领导。各县区（管委会）文物行政部门要加强组织领导，认真研究制定具体实施方案，主要负责人要亲自研究部署，落实责任，细化措施，层层动员，广泛发动，统筹文物火灾隐患整治和消防能力提升三年行动工作，扎实开展集中攻坚专项行动。

（二）深化隐患排查。各县区（管委会）文物行政部门要严格履行实文物安全监管责任，组织对安全风险和事故隐患进行全面排查，严格检查事故易发的重点场所、要害部位、关键环节，不放过任何一个漏洞、不漏掉任何一个盲点、不留下任何一个隐患。各县区（管委会）文物行政部门和市直文博单位要在2021年6月5日和6月29日前，分别将集中攻坚专项行动的阶段情况（填写《全市文物消防安全“控事故、保安全、迎建党百年”专项行动情况表》）报送市文物局，7月29日前报送总体情况。

（三）强化安全督查。各县区（管委会）文物行政部门要加强对集中攻坚专项行动工作的督促检查，对检查有安全问题的文博单位，要督促及时整改，消除隐患。对暂时不能整改的隐患问题，要制定并落实防范措施，限期整改，确保落实到位。对发现的责任不落实，集中攻坚行动推动不力，部门监管走形式等问题，要依法依规严肃问责。市文物局将适时组织督察组，开展督察检查工作。
