莆田市文化广电新闻出版局关于开展火灾隐患排查整治专项行动的通知

发布时间：2010-09-29 08:00
| | |

各县区（管委会）文体局（社会事务办、文教局）、市直属各单位：

根据《莆田市人民政府办公室关于开展火灾隐患排查整治专项行动的通知》（莆政办明电〔2010〕40号）和莆田市安办《关于做好2010年中秋节和国庆节及省运会期间安全生产工作的通知》（莆安办明电〔2010〕7号）精神，深刻吸取沈阳“8.28”火灾事故教训，坚决预防和遏制人亡火灾事故的发生，进一步维护全市文化广电新闻出版系统消防安全形势持续稳定，为确保国庆节消防安全和第十四届省运会等重大活动胜利召开营造良好的消防安全环境，经研究，决定在全市文化广电新闻出版系统内开展为期三个月的火灾隐患集中排查整治专项行动。现将有关事项通知如下：

一、认清形势，增强消防安全工作的责任感和紧迫感。

从现在起到年底，重大活动多，人流物流加快，各类文化活动频繁，消防安全工作面临的形势十分严峻。各单位尤其是领导干部一定要充分认识开展火灾隐患排查整治专项行动的重要性和紧迫性。认清消防安全工作面临形势，严格落实安全生产“一岗双责”规定，周密部署，强化专项整治措施，切实做到思想认识到位、组织部署到位、工作措施到位，坚决遏制较大以上火灾尤其是群死群伤火灾事故发生，确保全市文化广电新闻出版系统火灾形势稳定，为省运会等重大活动顺利举办提供良好的消防安全环境。

二、扎实开展专项行动，坚决消防各类火灾隐患。

（一）排查形式。按照“谁主管、谁负责”、“ 管生产经营必须管安全”和属地管理的原则。根据市政府统一部署，市直属各单位务必要认真领会精神，对本单位火灾隐患情况进行全面细致的检查，认真查找安全方面存在的漏洞和隐患，并及时采取措施加以解决。县区（管委会）文体局（社会事务办、文教局）要在当地人民政府的统一领导下密切配合消防、安全监管部门，负责所监管领域内火灾隐患排查整治专项行动的组织实施。市文化广电新闻出版局安全领导小组要对全市文化广电新闻出版系统的专项行动进行督促检查。

（二）排查范围。排查范围包括文化娱乐场所经营单位、网吧、电影放映单位、文物保护单位、音像制品经营单位、出版物（图书）经营单位、演出场所、印刷企业、图书馆、文化馆、莆仙大剧院建设项目等文化广电新闻出版系统各企事业单位。

（三）排查内容。一是抽查各单位消防安全“四个能力”落实情况；二是消防设施运行状况；三是消防安全情况；四是其他突出消防安全问题。对上述排查发现的消防安全违法行为和火灾隐患，必须做到“七个一律”：一是凡消防设计审核不合格的，一律不得同意施工；二是凡消防验收不合格的，一律不得投入使用；三是对现有建筑和易燃易爆单位，凡消防设计和竣工验收备案抽查不合格的，一律停止施工、停止使用；四凡发现在能造成重大人员伤亡的，一律予以查封；五是凡发现疏散通道、安全出口数量不足或严重堵塞，已不具备安全疏散条件的，一律予以查封；六是凡建筑消防设施严重损坏，不再具备防火灭火功能的，一律予以查封；七是人员密集场所门窗设置影响逃生和灭火救援障碍物的，要坚决责令改正，拒不改正的，一律将障碍物予以拆除。

三、强化责任，确保整治专项行动落到实处。

各县区文体局要全面部署开展以网吧、营业性演出、歌舞娱乐、印刷企业等文化经营场所和营业性演出活动存在的突出问题和安全隐患的排查工作，全面掌握文化经营场所的安全生产、火灾隐患等情况。做到排查不留死角、整治不留后患。对排查中发现安全隐患的场所，应积极配合公安、消防等部门坚决依法予以取缔。未依法取得营业执照的文化经营场所从事经营活动的，提请工商行政管理部门依法予以取缔；对凡逾期不改或经整治仍达不到基本消防安全要求、危及人员生命安全的，必须吊销相关证照并坚决依法予以取缔。

文物部门要进一步强化内部管理，落实安全岗位责任制，建立健全文物安全防范体系，对事故隐患多的单位和部位，要采取有效措施，不放过任何细微的不安全因素，整治到位，坚决防止文物安全事故发生。

莆仙大剧院建设项目的主要负责人要深入一线全面检查安全制度、安全责任、安全措施等重点环节是否健全，对重大危险源要制定可行的防范和监控措施，落实专人负责监控，确保安全。重点加强对施工现场脚手架搭设、临边洞口防护、施工用电、塔吊和施工电梯、施工机械的安全监督检查，

各单位要将排查发现的重大问题及时通报本级政府和我局办公室，以便做好整改情况的跟踪落实。

四、广泛宣传，提高防范能力。

各县区、各单位要充分利用各种手段和形式，加大对火灾隐患排查整治专项行动的宣传力度，提醒社会单位加强自身安全防范，警示群众提高消防安全意识，营造浓厚的专项行动氛围。要结合各单位的实际，强化内部安全管理人员和重点岗位的消防安全培训，提高单位履行消防安全职责的意识和能力，强化员工扑救初起火灾和组织疏散逃生的基本技能，不断增强员工消防安全意识。执法单位要设立举报电话、电子信箱，接受群众举报。各单位要总结、分析、研究专项排查工作中存在的新情况、新问题，加强专项行动信息报送，及时反映专项行动开展情况。并于12月20日前提交本单位开展火灾隐患排查整治专项行动的总结报局办公室。

五、加强值班，确保信息畅通。

各单位要加强节日值班工作，安排专人24小时值班。值班人员要严格遵守值班纪律，按时交接班，不得脱岗空岗。领导干部要在岗带班及时掌握安全生产动态。同时，做好信息反馈和报告工作，如发生重大问题要及时报告，不得迟报、漏报和隐瞒不报。市直各单位的节日值班表请于9月29日前报局办公室。

各县（区）文体局（管委会）、社会事务办，市直有关单位于2010年10月8日上午8：30前将本单位国庆节日期间安全生产工作的简要情况和生产安全事故情况以书面形式报送市局办公室。

 

 

二○一○年九月二十九日
