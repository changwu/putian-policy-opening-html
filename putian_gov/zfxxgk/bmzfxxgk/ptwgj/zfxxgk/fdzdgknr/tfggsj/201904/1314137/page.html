转发《莆田市人民政府办公室关于切实加强今冬明春消防安全工作的通知》的通知

发布时间：2012-11-27 08:00
| | |

　　各县（区、管委会）旅游局：

　　现将《莆田市人民政府办公室关于切实加强今冬明春消防安全工作的通知》（莆政办明电[2012]69号）转发给你们，请认真执行，并将贯彻落实开展工作情况于2012年3月20日前报送市旅游局行管科（联系电话：6735835，传真：2692674）。

　　莆田市旅游局

　　2012年11月26日

　　内 部 明 电

莆田市人民政府办公室关于

　　切实加强今冬明春消防安全工作的通知

　　各县（区）人民政府（管委会），市直有关单位：

　　为认真贯彻落实福建省人民政府办公厅《关于加强今冬明春消防安全工作的通知》（闽政办发明电［2012］134号）精神，切实做好今冬明春特别是元旦、春节等传统节日期间消防安全工作，坚决预防重特大火灾尤其是群死群伤火灾事故的发生，经市政府同意，现将有关事项通知如下：

　　一、认清形势，不断增强冬防工作的责任感和紧迫感

　　今年以来，经过全市各级各部门的共同努力，消防工作取得了较好成效，全市火灾形势总体平稳。据统计，1-10月份，全市共发生火灾269起，造成2人死亡，1人受伤，直接财产损失425.5万元，与去年同期相比，除受伤人数持平外，火灾起数、死亡人数、直接财产损失分别下降了24.2%、80%和25.3%。冬季历来是火灾的多发期和重特大火灾尤其是群死群伤火灾事故的高发期，冬季气候变冷，圣诞、元旦、春节、元宵等节日集中，节庆活动频繁，人流、物流增大，生产、生活用火、用电、用气的增加，加之风干物燥，诱发火灾的因素大大增多。冬季夜长昼短，许多火灾难发现、难扑救，人员难逃生、难疏散，尤其是一些地区易燃建筑密集，“城中村”、“九小场所”火灾隐患十分突出。我市先后发生几起较大火灾事故均在冬季，这些血淋淋的火灾教训十分深刻。各级、各部门、各单位要切实增强做好冬季防火工作的责任感和紧迫感，加强领导，落实措施，全力确保全市火灾形势持续稳定；要认真分析、研究本地区冬季防火工作面临的形势、存在的问题和薄弱环节，抓紧制定冬季防火工作方案，及时部署，将工作责任落实到乡镇街道、落实到社会单位；要高度重视城乡结合部和农村防火工作，推动居民委员会、村民委员会经常开展群众性消防工作，指导村（居）民落实生产生活用火用电安全措施，实行村民多户联防，加强对老弱病残等群体的消防安全防护。在元旦、春节等节日期间，各级政府要组织有关部门联合开展防火检查，严防发生火灾。

　　二、强化领导，切实加强冬季防火组织工作

　　为加强对冬季防火工作的组织领导，市政府决定成立由市政府副市长卢炳椿为组长，市政府副秘书长王焕新、市公安局副局长吴建华为副组长，市消防工作联席会议成员单位分管领导为成员的工作领导小组，领导小组下设办公室，设在市消防支队，办公室主任由市消防支队支队长陈立民担任。各县区要成立相应的工作领导小组及办公室，以党的十八大精神为指导，站在维护社会大局稳定的高度，切实加强今冬明春防火安全工作的组织领导。要精心组织，周密部署，明确责任，突出重点，强化措施，深入推进火灾隐患排查整治，加强督促检查和跟踪问效，确保领导到位、认识到位、部署到位、措施到位、落实到位，确保全市火灾形势的安全稳定。

　　三、精心组织，加大火灾隐患排查整治力度

　　各地要全力推进“清剿火患”战役，继续加大对重大火灾隐患单位、人员密集场所、易燃易爆场所、住宿与生产储存经营合用场所（“三合一”场所）、高层地下建筑等场所的整治力度，下狠手、出重拳，严格整治各类场所火灾隐患和依法严惩各类消防违法行为。对尚未整改的火灾隐患要紧盯不放，确保按要求时限整改完毕；对排查出的火灾隐患，公安机关消防机构要依法督促整改，决不手软；对可能造成群死群伤的重大火灾隐患，坚决依法铲除，决不放过；对政府挂牌督办的重大火灾隐患，当地政府和有关部门的主要领导要亲自督办，积极协调解决整治工作中遇到的难题，确保及时整改到位。同时要对今年以来持续开展清剿火患战役工作进行认真总结，针对区域、行业消防安全突出问题，坚持什么问题突出就重点整治什么问题，什么隐患严重就重点解决什么隐患，切实增强隐患排查整治工作的针对性和实效性；对遗留“老大难”火灾隐患和消防安全问题进行集中整治，对不具备消防安全条件的场所坚决依法取缔或责令停产停业；对历史遗留的“老大难”消防问题，当地政府和有关部门的主要领导要亲自过问，亲自督办，积极协调解决整治工作中遇到的难题，确保短期内解决历史遗留的“老大难”消防问题。

　　四、深化管理，不断夯实社会火灾防控基础

　　各地要全面推行消防安全“网格化”管理，建立健全乡镇、街道消防安全组织，充分发挥街道、乡镇和社区、村等基层单位的作用，着力构建全覆盖的消防安全管理网络。各行业系统要逐步推行消防安全“户籍化”管理，推动社会单位通过互联网社会单位消防安全信息系统，逐一建立“户籍化”管理档案，实行消防安全管理人员、消防设施维护保养、消防安全自我评估等“三项申报”制度，实现社会单位由被动接受管理向主动参与管理的转变。同时，要继续开展社会单位消防安全“四个能力”（检查消除火灾隐患能力、扑救初起火灾能力、组织疏散逃生能力、消防宣传教育培训能力）达标创建活动，对已达标的社会单位开展“回头看”，不断巩固成效。

　　五、形式多样，深入开展消防宣传教育培训

　　各级各有关部门要认真贯彻《全民消防安全宣传教育纲要》，组织协调宣传、广电、文化、教育等部门广泛开展以今冬明春消防安全为主要内容的消防宣传活动。11月份，要充分利用各种宣传媒介，以“人人参与消防，共筑平安和谐”为主题，以普及消防安全常识、提高火场逃生自救能力为重点，以减少火灾人员伤亡为目标，积极开展 “119” 消防宣传月系列活动。各级各有关部门要严格落实《社会消防安全教育培训大纲》，加强消防安全教育和培训，增强群众的消防安全意识和消防法制观念，特别是进城务工人员、中小学生、老弱病残等群体的消防安全意识和素质；要召开社会单位法定代表人、消防安全管理人会议，集中开展消防法制教育，明确消防安全主体责任要求，督促落实消防安全责任制；各单位要对消防控制室操作人员以及重点工种人员普遍进行一次消防安全管理教育和技能培训，提高单位消防安全“四个能力”。广播、电视、报刊、互联网站等新闻媒体要积极配合冬防工作，定期播发和刊登消防常识及公益广告，报道消防工作动态，曝光火灾隐患和消防违法行为，为冬防工作营造良好的舆论氛围。

　　六、强化演练，扎实做好灭火救援准备工作

　　各县（区）人民政府（管委会）要贯彻落实省政府办公厅《关于进一步加强消防车辆装备建设的通知》（闽政办〔2011〕17号），安排专项资金，添置防火灭火和个人防护器材，改善消防部队装备条件，提高防火灭火能力和抢险救援水平。全市各级公安消防部队、各企业专职消防队以及乡镇（街道）专职消防队要根据冬季火灾特点，加强执勤战备和灭火训练工作；要进一步修订完善高层建筑、地下工程、石油化工等特殊火灾的应急预案，对重要场所、重点区域要制定有针对性的灭火作战预案，加强技术战术训练和综合演练，不断提高灭火实战能力，时刻做好“打恶仗、打硬仗”的准备；要坚持“救人第一，科学施救”，按照“五个第一”行动要则，力争打早、打小，减少火灾造成的损失。

　　2012年11月10日起至2013年3月20日是冬季防火期，请各级各有关单位将贯彻落实开展工作情况于2013年3月21日前报送市消防工作联席会议办公室（设在市公安消防支队，联系电话：2750152，传真：2785623）。

　　莆田市人民政府办公室

　　2012年11月16日

　　抄送：市委、市人大常委会、市政协、市纪委办公室，市法院，市检察院。

　　莆田市人民政府办公室                   2012年11月19日印发
