关于认真做好我市2015年“清明、五一”小长假旅游安全工作的通知

发布时间：2015-03-30 08:00
| | |

　　各县（区）人民政府（管委会）、市假日办成员单位：

　　2015年“清明、五一”小长假即将来临，为实现“安全、秩序、质量、效益”四统一的假日旅游工作目标，切实做好假日旅游各项准备工作，根据市政府领导指示，现将有关事项通知如下：

　　一、切实加强假日旅游安全工作

　　各县（区、管委会）旅游管理部门和旅游接待单位要按照国家《旅游安全管理暂行办法》和安全生产有关文件要求，认真做好假日旅游安全工作，确保假日旅游安全、有序。按照《大型群众性活动安全管理条例》的要求，加强对假日期间各类旅游节庆活动的审查和监管，按照属地管理的原则，落实主承办单位和场所管理者的安全责任，按照《旅游突发公共事件应急预案》要求，认真组织安全演练，提高应急反应能力。结合前期我市开展春节“黄金周”假日旅游市场专项整治活动和《关于开展全市旅游安全生产大检查的通知》要求，强化假日旅游安全保障措施，确保假日旅游各类旅游设施安全可靠。要做好安全出行相关提示，保证广大人民群众假日出游安全。要特别注意做好防抗恶劣天气等各项工作，各旅行社、各旅游景区(点)、星级宾馆饭店等要按照旅游法的要求，落实好相应防范措施。节前各级假日旅游协调机构要组织相关单位认真开展全面的旅游安全检查，狠抓安全工作落实。

　　二、切实做好服务保障工作

　　各县（区、管委会）旅游管理部门和旅游接待单位要利用好“清明、五一”小长假，在推动经济发展等方面积极发挥旅游业的带动和促进作用，不断满足人民群众假日旅游需求。要根据当地实际，结合开展“清新福建”旅游主题系列活动，开发有地方特色、富有传统文化内涵、适合多层次需求的假日旅游产品。加强对精品旅游线路的宣传推广，积极发展乡村旅游、城市周边度假休闲游，将旅游与文化深度结合，开发旅游专题活动、节庆活动等大众化产品和自驾游、自助游、生态游、文体科技旅游、红色旅游等个性化产品，丰富节日生活，增加旅游产品供给。

结合福建省旅游安全生产标准化建设提升工程三年行动，在旅游行业大力开展诚信服务、文明服务、快速处理投诉服务和散客咨询服务等，不断提升公共信息服务水平，扩大信息发布渠道和受众面，节前开展市场预测，动态发布交通、住宿、游览、气象、卫生等出行信息，进一步方便群众假期出游。要广泛开展形式多样的文明旅游宣传引导活动。积极组织旅游公益宣传，引导游客追求旅游品质，做国内旅游、出境旅游的文明使者，共同创建和谐文明的旅游环境。

　　三、切实做好假日旅游监管工作

　　各县（区、管委会）旅游管理部门要采取有效措施，规范旅游市场秩序。加强假日旅游市场监管，在“清明、五一”小长假到来前，联合相关部门开展对重点旅游景区及其周边“一日游”旅游市场的检查行动，重点检查价格、合同、广告等是否诚信、规范、合法，打击无证及超范围经营、黑车黑导、欺客宰客、强迫消费及恶性价格竞争等违法违规行为，加大对旅游餐饮安全的管理和监控力度，加强对旅游企业及从业人员的培训教育，切实从源头保障旅游者的合法权益。要认真落实《关于进一步加强我市道路客运业管理的通知》，联合交通运管部门加强对旅游用车的管理，抽查旅游用车情况，及时查处使用没有运营资质车辆从事旅游运输的企业和驾驶人员。

　　四、切实做好假日旅游统计工作

　　各县（区、管委会）旅游管理部门应在节前指定专人负责假日期间统计预报工作，及时发布旅游预报和旅游信息，做好假日期间景区游客量适时监测和统计汇总工作，统计数据、分析资料应及时上报市旅游局。

　　五、切实保障假日旅游工作运转顺畅

　　各县（区）人民政府（管委会）假日办在2015年4月2日前应完成如下工作：

　　（一）按照假日旅游协调工作规则，及时启动假日旅游协调机制，督促各项工作落实到位。

　　（二）结合本地实际，组织开展旅游市场和旅游安全大检查，有重点地进行各类旅游应急预案的演练，严格执行安全事故报告制度和值班制度，保证24小时值班，确保联络顺畅。

　　（三）各县（区、管委会）假日办向社会公布旅游投诉电话和旅游咨询电话。

　　（四）各县（区、管委会）假日办要加强节日值班和领导带班，保证24小时联络畅通。要将假日值班电话、旅游投诉电话和值班负责人姓名、职务和电话号码传真市假日办(见附表)。
