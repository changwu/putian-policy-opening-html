莆田市旅游发展委员会关于印发推进安全生产领域改革发展实施方案的通知

发布时间：2018-07-05 09:25
| | |

 

各县（区、管委会）旅游局，局机关各科室、直属事业单位：

　　现将莆田市旅游系统《推进安全生产领域改革发展实施方案》印发给你们，请结合实际，认真贯彻落实。

　　                  

  

                                             莆田市旅游发展委员会（代）

　　                                                                              2018年7月3日

 

莆田市旅游系统推进安全生产领域改革发展实施方案

　　

为贯彻落实市委、市政府《关于推进安全生产领域改革发展的实施意见的通知》，进一步加强安全生产工作，结合全市旅游系统实际，制定本实施方案。

　　一、工作目标

　　全面贯彻党的十九大精神，以邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想为指导，深入贯彻习近平总书记系列重要讲话精神和治国理政新思想新战略，进一步增强“四个意识”，紧紧围绕统筹推进“五位一体”总体布局和协调推进“四个全面”战略布局，树立新发展理念，坚守发展决不能以牺牲安全为代价这条不可逾越的红线，坚持安全发展、改革创新、依法监管、源头防范、系统治理的原则，依靠严密的责任体系、有效的监管体系、严格的法治措施、科学的风险管控、有力的基础保障，坚决杜绝较大及以上事故，大力提升安全生产整体水平，切实增强人民群众安全感、幸福感，确保人民群众共享改革发展和社会文明进步成果。到2020年，全系统领域生产安全良好态势持续巩固，没有安全生产事故发生。到2030年，实现安全生产治理体系和治理能力现代化，本系统领域安全文明素质全面提升，安全生产保障能力显著增强，为莆田经济社会持续健康发展奠定稳固可靠的安全生产基础。

　　二、主要措施

　　（一）完善组织机构，落实安全生产责任。一是建立完善本部门安全生产工作机制，强化安全生产领导小组办公室工作职能。全面落实《莆田市安全生产“党政同责、一岗双责”规定》，将主要负责人列为安全生产第一责任人，制定安全生产责任清单，实行照单履责、失职追责。同时，根据工作需要召开党组会议，听取安全生产工作汇报，解决安全生产工作中的重大问题，研究部署安全生产工作。二是落实责任清单，明晰监管责任。按照“三定”方案管理要求，严格执行本部门领域安全生产职责，研究制订本部门的安全生产监管权力清单和责任清单。三是严格落实企业主体责任。企业对单位安全生产负全面责任，要建立健全自我约束、持续改进的机制。建立企业全过程安全生产和职业健康管理制度，做到安全生产责任、管理、投入、培训和应急救援“五到位”。

　　（二）加强安全风险管控，消除安全隐患。一是建立安全隐患排查机制。建立完善安全风险评估与论证机制，加强旅游景区、星级酒店等人员密集场所等安全风险排查，实现“全覆盖”。完善重大安全风险联防联控机制，制定应急联动预案，开展联合应急处置演练。二是建立隐患治理监督机制。全面推行“检查诊断、行政处罚、整改复查”执法检查工作方法，确保查准问题、违法必究、闭环销号。对检查中发现重大事故隐患，实行跟踪督办，明确相关生产经营单位及牵头督办部门的责任，全面落实隐患整改责任、措施、资金、时限、预案，并向社会公布，对隐患无法整改的，要依法停产、关闭。

　　（三）加大行业检查整治力度，保障行业系统安全。一是要星级酒店等人员密集场所建筑物安全、电气火灾防范、消防安全等检查和安全宣传教育，制定安全生产管理制度，加强安全隐患治理。要重点加强对星级酒店消防许可、消防安全责任制、日常防火检查巡查、建筑消防设备设施和安全出口及疏散通道、应急疏散预案制定及演练情况检查。二是要对A级景区安全生产主体责任落实，安全生产制度健全完善、安全管理、标准化建设、科技支撑、标牌标识、安全提示、安全教育培训、持证上岗、应急管理等安全生产基础工作，以及隐患排查整治，开展安全督促检查，确保落实企业安全生产落实到位。

　　（四）健全安全宣传教育体系，提升安全意识。一是要充分利用广播电视、新兴传媒等媒体，采取开设安全生产公益栏目、设置宣传专栏、滚动播出宣传标语等方式进行广泛宣传，形成强大宣传声势，营造浓厚的安全生产舆论氛围。同时，充分发挥群众和舆论监督作用，鼓励通过举报电话举报安全隐患。二是开展安全生产教育进企业，促进旅游经营单位（场所）安全生产责任落实，职工安全技能提升，群众安全知识提高和安全意识增强，重特大事故有效遏制，确保全市文化旅游经营单位（场所）安全生产形势稳定。

　　（五）建立长效机制，确保全系统行业安全稳定。要加大安全监管、宣传培训、应急管理、公共安全隐患治理、职业病防治等投入，提高全系统行业职工及广大群众安全生产意识，保障确保全系统行业安全稳定好转。

　　三、职责分工

　　按照《莆田市旅游局安全生产“党政同责、一岗双责”规定》要求，根据各自安全生产有关职责分工，对本领域行业的生产经营单位进行安全监管；各相关行业企业要认真开展落实本行业安全生产工作。

　　四、工作要求

　　（一）深入贯彻落实党的十九大有关安全生产工作精神。要认真落实十九大提出的安全生产发展理念，弘扬生命至上，安全第一的思想，采取坚决有力措施，全面深入抓好安全生产工作，维护旅游行业的稳定，营造良好的旅游发展氛围。

　　（二）严格实行安全生产“一票否决”。对被“一票否决”的，一律取消年度评优评先资格，主要负责人、分管负责人、直接责任人当年不评优、不评先、不提拔重用；对被“一票否决”的企业将作为安全监管执法检查重点对象。

　　（三）严格安全生产考核督办。要继续完善安全生产目标管理考核办法，强化过程考核，实行专项考核，加大安全生产考核权重，强化考核结果运用。

　　（四）加强综合检查和专项督查。要加强组织本行业领域安全生产督促检查，及时消除安全隐患。要督促相关企业、单位按照有关要求认真组织落实隐患整改工作，实现闭环管理；对一时难以整改到位的隐患，要采取有效措施或制定应急预案，切实加强隐患的安全防范；对不能整改到位又无有效安全防范措施的，必须停止使用设备设施或者停止生产施工；对重大安全事故隐患，应采取紧急措施，责令其停业停产整改，要盯住不放，实行动态监管、跟踪督查；对屡教不改、整改不力的要严肃处理，并将有关情况予以公布。

　　（五）严格落实安全值班制度。要严格落实领导带班值班和24小时值班制度，及时报送安全生产事故信息，积极妥善处理各种突发事件，重大问题要及时报告。
