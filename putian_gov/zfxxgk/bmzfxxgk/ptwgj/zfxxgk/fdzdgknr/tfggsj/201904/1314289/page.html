关于印发《莆田市旅游局关于继续深入开展“安全生产年”和“责任落实年”活动工作方案》的通知

发布时间：2012-05-15 08:00
| | |

　　各县（区、管委会）旅游局、各星级酒店、旅行社、A级景区、旅游车队：

　　为进一步加强旅游安全管理工作，根据《福建省旅游局关于继续深入开展“安全生产年”和“责任落实年”活动工作方案》要求，结合我市工作实际，制订了《莆田市旅游局关于继续深入开展“安全生产年”和“责任落实年”活动工作方案》，现印发给你们，请认真贯彻执行。

　　联系人：蔡雪松  电话：6735835

　　邮箱：ptly0594@163.com。

　　莆田市旅游局

　　二O一二年五月十四日

　　莆田市旅游局关于继续深入开展

　　“安全生产年”和“责任落实年”活动工作方案

　　为贯彻《福建省人民政府办公厅关于继续深入扎实开展“安全生产年”和“责任落实年”活动的通知》（闽政办[2012]68号）和《省政府关于坚持科学发展安全发展促进安全生产形势持续稳定好转的实施意见》（闽政【2012】13号）文件精神，全面落实《福建省旅游局关于继续深入开展“安全生产年”和“责任落实年”活动工作方案》（闽旅【2012】118号）要求，坚持科学发展安全发展，促进旅游安全管理形势稳定有序，结合旅游行业实际，进一步深入开展“安全生产年”和“责任落实年”活动，现将有关事项通知如下：

　　一、强化“一岗双责”，切实担负安全责任

　　（一）认真落实旅游部门安全监管责任。进一步落实“一岗双责”制度，强化行业监管，继续抓好市、县（区）旅游局第一责任人签订《安全生产责任状》、县（区）与辖区内相关旅游企业签订《安全生产责任状》的工作，做到层层监管，责任到人。督促指导旅行社、星级饭店第一责任人切实承担起安全管理的责任。

　　（二）加强安全生产目标管理责任考核。积极推进安全目标责任体系建设，层层分解落实安全管理目标责任，保证旅游安全目标管理分阶段、分重点、分责任加以落实，并把安全管理工作纳入创建文明行业活动、旅行社信用等级评比、星级饭店复核之中。实行安全管理（一票否决），全面落实目标责任考评奖惩措施。

　　（三）严肃认真查处旅游安全事故责任。按照“四不放过”原则。依法查处和追究责任单位、人员的责任，及时通报事故调查进展和查处结果，加大对责任单位的处罚，加快建立与项目资金补助、星级饭店复核等挂钩的企业安全管理失信惩戒制度。

　　二、强化行业监管，规范排查体系建设

　　（一）加强旅游安全相关标准体系建设。要加强对本地区本企业旅游安全隐患的排查治理体系建设，依法健全完善安全隐患排查治理体系建设，把安全隐患排查治理体系建设纳入安全生产标准化建设的重要内容，做到同部署、同推进、同考核，确保工作落实到位，实现隐患排查治理常态化、规范化、法制化，有效整治和消除各类安全隐患，跟踪整改到位，并做好排查整改情况的登记、存档。

　　（二）加大旅游安全隐患排查治理力度。要坚持经常性监督检查，做到警钟长鸣，将安全关口前移。落实“企业自查每周、县级每月、市每季度至少检查一次”的规定。积极配合相关部门加强对星级饭店消防、食品卫生等工作的安全指导、检查、监管工作。指导旅行社健全突发事件应急机制，做好消防安全知识宣传工作，提高消防安全“四个能力”建设，提高游客自我安全防范意识，全面开展安全隐患排查治理体系活动，切实增强安全保障和事故防范能力。

　　（三）加大旅游节庆等重点时段的检查。加强与相关部门的配合协调，全力抓好重点时段安全检查工作，特别是对重大节庆活动、黄金周、强台风等时期的安全检查和保障。严厉查处旅行社违规承包挂靠、刊登违规广告、租用“黑车”和聘用无证导游等违法违规行为，严格检查星级饭店消防、安保、食品卫生等场所安全制度以及措施和人员落实到位的情况。

　　三、强化培训教育，全面提升员工素质

　　（一）着力宣传科学发展安全发展理念。大力宣传、全面贯彻国务院和省政府关于坚持科学发展安全发展促进安全生产形势持续稳定好转的重大决策部署，扎实推进“安全生产年”和“责任落实年”活动，把科学发展安全发展的理念落实到旅游活动的每一个环节和岗位，使之成为衡量旅游行业安全管理的基本标准。

　　（二）着力推进旅游行业安全文化建设。大力宣传、营造氛围，结合“安全生产月”、“海西安全发展行”、“安康杯”和旅游行业“创行文明”等系列活动的开展，采取网络媒体等各种形式，大力宣传旅游安全应急避险、防火、食品卫生等知识，全面提升全行业从业人员和旅游者安全素质。以旅游节庆展会、旅游咨询活动等为契机，加强文明旅游、理性旅游、绿色旅游宣传，引导现代旅游新风尚。

　　（三）着力抓好行业安全管理培训教育。强化安全培训教育，进一步完善市、县（区）旅游安全培训教育工作，继续抓好旅行社、星级饭店负责人、安全管理人员、领队和导游人员的培训，大力培养专业安全技术人才和技能型操作员工，切实加强安全监管和从业人员的培训、复训，不断提升监管人员的能力和水平，建立和完善旅游企业安全培训机制和自我教育体系。

　　四、强化安全保障，全面提升安管水平

　　（一）加快实施旅游安全保障体系建设。全面实施《福建省旅游安全生产“十二五”规划》，积极推进安全标准体系、技术支撑体系、应急救援体系、培训教育体系等体系建设，建立旅行社责任保险统一投保制度，实现旅行社责任险统保覆盖达100%，实现旅行社、星级饭店安全经营和游客安全旅游。

　　（二）切实加大旅游安全管理保障投入。要建立安全资金投入保障体系，加大事故预防，宣传教育、监管能力等投入，进一步强化旅游安全监管人员、编制、资金、制度的落实。旅行社、星级饭店要按照规定，存储风险失抵押金或参加责任保险，加快安全系统和装备建设，做到安全监管工作机构、人员、经费、设施和装备“五到位”，形成“横向到边、纵向到底”的完善的安全生产网络体系。

　　（三）加强旅游突发事件应急体系建设。要有针对性的细化和落实各种突发事件预案和紧急救援预案，增强预案的可操作性，不断完善预警信息发布网络平台。切实做好各种突发事件应急处置，做到有预案、有防范、有应对，提高应急处置的能力，坚决预防和遏制重特大事故的发生。

　　五、夯实安全基础、着力推进标准建设

　　（一）进一步打牢旅游企业安全管理基础。继续推进旅行社、星级饭店主体责任落实，从管理机构、制度建设、安全投入、安全管理、教育培训等措施落实到位。严把行业安全准入关，严格落实主要负责人和实际控制人等第一责任人责任，按照职责分工，严格落实领导带班制度，及时处置旅游突发事件等问题。

　　（二）扎实推进旅游安全管理标准化建设。要按照《福建省开展旅游企业安全管理标准化建设三年行动计划实施方案》（闽旅[2011]228号）提出的要求，全面推进旅行社、星级饭店安全管理标准化建设，指导旅游企业抓好安全标准化分级考核评价，推动安全生产等级转换企业安全标准化建设达到90%以上，力争在2012年底前实现星级饭店、4A级旅行社100%达标，其他旅行社在2013年底前100%达标。

　　（三）注重树立先进典型的示范推动作用。切实加强对标准化建设的督促检查和指导服务，树立一二家可供学习、借鉴的典型的旅行社、星级饭店，带动行业标准化建设工作全面推进。

　　六、强化队伍建设，提高监管执法能力

　　（一）健全和完善安全监管机构。健全安全监管机构，进一步加强安全监管机构和适当增加人员编制，配齐配强安办安全管理人员。有专门负责安全监管职责的科室或有专人负责安全生产管理工作。应给安管专职人员配备通信工具、完善办公设施，保证安全生产管理资金到位，为安全教育宣传、责任制考核奖励奖金等提供经费保障。

　　（二）加大安管队伍教育培训力度。加强安管队伍自身建设，加大干部教育和管理，不断提升安全监管和服务发展的能力。切实加大旅行社、星级饭店安管岗位员工培训力度，提高其安全应急能力和履职水平。

　　七、强化联动协作，推进安全综合治理

　　（一）加强部门之间联动协作机制。加强各级旅游部门与公安、交通、卫生、质检、安监等部门协作力度，加强对旅游交通、游览、住宿等环节的联合治理。积极构建旅游安全预警网络平台，构建省、市、县三级联动的旅游安全预警网络平台。

　　（二）发挥市假日领导小组的作用。充分发挥市假日领导成员单位的作用，形成共同参与的工作联动机制，推进安全综合治理，在安全指导、安全检查、监管执法、政策制定、事故查处等方面，形成齐抓共管的合力。

　　（三）加大旅游安全管理监管执法力度。要制定并严格落实年度安全生产执法计划，加强对各级各部门各单位贯彻落实安全生产方针、政策、措施的监督检查。强化旅游安全责任事故问责制度。严格各类旅游安全事故的调查处理，依法追究有关单位和人员的责任。规范并落实各级行业部门领导组织或参加不同风险、级别、性质的企业和行业领域安全生产专题调研、安全检查、安全例会、安全培训等活动频次，以及解决倾向性安全问题的时限、效果等管理规定。加强对企业安全生产的现场监管和技术指导，帮助企业提高安全生产管理水平。

　　八、强化重点监管，防范生产安全事故。

　　（一）强化租用车辆管理。加强旅行社租用车辆督促检查力度，着重检查是否签订租车合同、是否租用资质合格、车辆状况良好且带有GPS行车记录仪的旅游车辆，严处旅行社租用“带病”车辆、三无车辆、无证驾驶和违规驾驶承载旅游团队游客；督促旅行社按时足额投保责任险，积极推荐旅游者投保旅游意外险；切实发挥导游人员、领队人员在整个旅游全过程中的作用，及时提醒驾驶员注意安全、防止疲劳驾驶、违章行驶等现象出现，杜绝旅游违法行为的发生，确保所有人员旅途安全。

　　（二）强化消防安全监管。全面贯彻“预防为主，防消结合”的消防工作方针，严格按照消防主管部门的要求，将消防工作纳入各单位安全考核范围。强化各部门、各单位自我管理主体意识，使单位自身具备“检查消除火灾隐患能力，组织扑救初起火灾能力，组织人员疏散逃生能力，进行消防宣传教育培训能力”。建立消防安全体系和自我约束机制，全面提高本单位消防安全管理水平。

　　（三）强化重点环节管理。加强旅游黄金周、节假日、自然灾害、重大庆典等期间安全管理，杜绝重特大事故的发生；强化应急管理，制定健全各类应急处置预案，从根本上降低突发事件危害程度；强化应急值守和信息报告，健全和完善事故报告制度、举报制度和责任追究制度，确保突发事件信息及时、准确上报，杜绝迟报、谎报、漏报、瞒报，提高突发事件信息报送时效性和规范性。
