莆田市旅游局2009年度旅游安全生产工作总结

发布时间：2009-11-16 08:00
| | |

　　省旅游局：

　　2009年，我局旅游安全工作在市委、市政府的领导下和省旅游局指导下，按照市政府安全生产会议精神和我局制定的旅游安全生产工作的要求，各级旅游管理部门和各旅游经营单位，牢固树立“没有安全就没有旅游”的思想，密切配合相关部门积极开展安全生产“三项行动”和企业安全生产主体责任“三年行动”等工作，采取行之有效的管理措施，杜绝发生重、特大旅游安全生产事故，取得了明显成效，全年没有发生任何伤亡事故。现就2009年的旅游安全工作总结如下：

　　一、主要工作开展及情况落实

　　（一）加强制度建设，重点落实各项责任制

　　一是层层签订《安全生产责任状》。在年初召开的全市旅游工作会议上，市旅游局与各县（区、管委会）旅游局长一一签订《安全生产责任状》，突出落实责任制和事故报告制度，杜绝发生重特大安全生产事故。要求各县（区）旅游局长要与辖区内的相关旅游企业签订（或下发）《安全生产责任状》，旅游企业内部总经理也要与中层部门一一签订《安全生产责任状》，层层抓落实，做到行政一把手负总责。

　　二是健全制度，完善预案。我局党组高度重视旅游安全工作的各项措施的制定和落实，特别是认真贯彻市政府下发的《莆田市人民政府关于下达2009年安全生产目标管理责任制的通知》（莆政综[2009]25号）文件精神，在已有的预案基础上，进一步完善了《莆田市旅游突发公共事件应急预案》，成立了市旅游突发事件领导小组及其办公室，明确了各成员单位的职责，制定了四级响应机制，形成了统一领导、分组负责、职责明确、运转有序、反应快速、处置有力、依法规范的应急处置体系，可最大限度地预防和处置旅游突发公共事件及其造成的损害；

　　三是加强安全事故报告制度。每月2日前（逢节、假日顺推）及时向省旅游局报告上个月旅游安全事故情况，每季度初及时向市安办报告隐患排查情况。并要求旅游企业一旦发生安全事故，应在第一时间报告市旅游局。

　　四是突出抓好黄金周的旅游安全工作。今年的春节、“五一”、“十一”三个黄金周之前，我局党组成员分别带领三个检查组分赴各县（区）、管委会和各旅游经营单位，检查、指导黄金周之前的旅游安全工作，消除安全隐患，确保旅游黄金周的组织、接待工作有序、健康、平安。

　　（二）迅速行动，积极推进安全生产“三项行动”工作

　　根据省旅游局和市政府安委会有关文件精神，我局立即召开局务会议，迅速对“三项行动”进行工作部署，并要求相关科室制订“三项行动”实施方案。5月31日，结合我市旅游系统安全生产工作重点，迅速以莆政旅[2009]60号文印发了《全市旅游安全宣传教育行动、治理行动、执法行动实施方案》的通知，明确了“三项行动”的时间、内容、工作要求，成立了以局长、党组书记李国华为组长，各职能科室负责人为组员的“三项行动”工作领导小组，负责全市旅游系统“三项行动”的组织指导和协调工作。在工作要求上，我局突出重点，治大隐患，防大事故。旅行社务必要杜绝租用不合资质的旅游车辆，星级饭店要确保消防安全和饮食卫生安全，切实遏制重特大事故发生。据统计：2009年，我局共出动执法人员160多人次，检查旅游团队200多团，检查导游员130多人。其中纠正了20多名导游员的违规行为。在隐患排查治理方面，检查企业25家，累计提出整改隐患38条，整改率100%，发出8份整改通知书，督促企业限时整改。我局还认真受理游客的投诉。2009年，共受理游客投诉15件，全部得以协调解决，受到旅游企业和游客的好评。

　　（三）精心组织，深入开展“旅游安全生产月”活动

　　根据莆田市委宣传部等六个部门联合发文（莆市安监[2009]49号）要求，我市定于2009年6月1日至30日为全市旅游安全生产月，主题是“关爱生命、安全发展”，要求各旅游企事业积极营造“关爱生命、安全发展”的良好氛围。要求各企业加强自身安全文化建设，大力开展企业安全文化建设示范活动，总结典型，推广经验，让安全生产在企业蔚然成风。活动期间，全市主要旅游风景区（点）、星级酒店、旅行社都悬挂以安全为主题的宣传条幅，营造了良好的氛围。仙游大酒店还组织员工观看安全生产月主题宣传片《关爱生命、安全发展》，使全体员工受到一次震撼的安全教育。在安全生产月期间，我们超前部署，加强督查力度，没有发生任何安全事故。

　　（四）全面部署，积极开展落实旅游企业安全生产主体责任行动

　　根据《莆田市人民政府安全生产委员会办公室关于印发全市2009年度开展落实企事业主体责任活动实施方案的通知》（莆市安办[2009]21号）和《关于印发〈关于开展落实旅游企业安全生产主体责任行动方案〉、〈福建省企业安全生产级别评定标准〉的通知》（闽旅[2008]171号）文件精神，我局高度重视，及时召开局务会议研究部署此项工作，相关科室迅速拟定了《关于开展落实旅游企业安全生产主体责任行动方案》及《评定标准》，并于2009年6月5日在东方国际大酒店召开全市旅游安全工作会议，重点部署开展落实旅游企业安全生产主体责任工作。经过半年的努力，至目前，各县（区、管委会）旅游局已完成对各旅游企业的现场初审分类。明年初，我局将对评上A、D两级的旅游企业进行复核。

　　（五）高度重视，认真做好应对甲型H1N1流感工作

　　为了尽量减少甲型H1N1流感对我市旅游业的危害，保障游客安全，我局成立了突发公共事件领导小组，由局长、党组书记李国华亲自部署领导此项工作。正式启动了“莆田市旅游突发公共事件应急预案”，要求各县（区、管委会）旅游局、各旅行社、星级饭店安排专人值班，领导带班，按预案要求贯彻执行。发现游客或住店客人发生感冒现象，应立即送往就近医院治疗，并在第一时间按程序报告相关单位。先后下发了《关于进一步做好甲型H1N1流感防控工作的通知》、《“国庆60周年”期间防控甲型H1N1流感、登革热等传染病暴发流行控制工作预案》等文件，有效遏制了甲型H1N1流感等传染病的扩散和蔓延。

　　二、存在问题

　　经过全局上下共同努力，我局旅游安全工作虽然取得一定成效，但旅游安全工作的基础还不够牢固，一些深层次问题还没有得到根本解决，旅游安全工作发展不平衡，个别企业对旅游安全生产重视不够，存在侥幸心理。责任制没有得到有效落实，专项整治流于形式；少数旅游企业安全意识差，只顾赚钱，疏于安全管理；一些旅游企业安全投入不足，内部安全管理比较混乱，安全监管工作跟不上市场经济发展步伐，等等。

　　三、2010年工作思路

　　1、着力抓好安全生产责任制落实。按照安全生产有关法律法规和市政府下达的安全生产目标管理责任制的规定，督促各单位的主要领导亲自抓，分管领导具体抓，相关人员全力抓，切实做到定期分析安全形势，适时开展安全检查，限期落实隐患整改。

　　2、着力深化旅游安全专项整治。坚持把旅游安全专项整治作为安全生产工作的一项重要内容，继续深入持久地抓下去。建立专项整治责任制，定期组织督查，对整治工作不力、责任不落实的单位及时予以通报，强化工作合力，密切协调行动。把专项整治工作抓紧、抓实、抓好，逐步推动整治工作走上经常化、规范化、制度化的轨道。

　　3、着力强化安全生产宣传教育。坚持把安全生产宣传教育作为思想工作和精神文明建设的重要内容，依托新闻媒体安全宣传阵地，采用群众喜闻乐见的形式，跟踪报道旅游安全生产先进经验和反面典型，加强安全生产教育培训工作，进一步提高政府、企业、社会不同层面人员的安全文化素质。

　　总之，旅游是以人为本，且行业关联度极强的综合性产业。平安旅游工作需要各级政府和相关部门齐抓共管。作为主管我市旅游的行政部门，始终会把安全工作摆在行业管理的首位，坚持“安全第一、预防为主”的方针，时刻紧绷安全生产这根弦。强化平安旅游管理，消除旅游安全隐患，全力维护旅游市场秩序，以安全、健康、有序的环境，迎接旅游业更快更好地发展。

　　莆田市旅游局

　　二OO九年十一月十六日


　　抄送：市安办
