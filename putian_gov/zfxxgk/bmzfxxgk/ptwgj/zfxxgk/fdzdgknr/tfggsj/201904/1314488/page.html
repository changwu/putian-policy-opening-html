莆田市旅游局关于下达2017年旅游安全管理目标责任的通知

发布时间：2017-03-13 10:11
| | |

 

 

各县（区、管委会）旅游局：

根据省旅游局关于建立安全生产责任制的要求，现将《2017年旅游安全管理目标责任》下达给你们，请认真遵照执行。

  

 

                                    莆田市旅游局

                                                                   2017年3月13日

 

 

2017年旅游安全管理目标责任

 

2017年是党的十九大召开之年，也是我市实施“十三五”规划、推进供给侧结构性改革的重要一年。为进一步推动旅游安全管理责任落实，全面强化旅游安全监督管理，有效防范和控制旅游安全事故发生，确保2017年全市旅游安全形势持续稳定有序。特制定目标责任如下：

一、责任对象

各县（区、管委会）旅游局。

二、目标管控

控制一般事故，严控较大事故，坚决遏制重、特大安全责任事故，力争全市旅游团队、星级饭店较大责任事故控制在1起以内，不发生重特大责任事故，确保旅游者生命、财产安全。

三、目标责任

（一）要认真贯彻落实党的十八大和十八届三中、四中、五中、六中全会精神和习近平总书记、李克强总理等中央领导以及市委、市政府领导关于安全生产工作的系列重要指示批示精神，进一步牢固树立旅游安全“红线意识和底线思维。紧紧围绕“十三五”旅游规划确定的发展战略和重点任务，推动莆田市“十三五”旅游安全管理指导意见落实，为旅游者提供安全保障工作。

（二）要严格落实“党政同责、一岗双责”规定，进一步健全完善安全监管责任体系；要按照旅游部门行政权力清单，进一步厘清旅游安全监管责任，认真制定完善本区旅游安全管理责任清单，做到日常照单监管，失职照单追责；定期召开安全专题会议，研究解决重大问题，推动旅游安全责任落到实处，取得实效。

（三）要按照市政府安委会、市旅游局和本级地方党委政府有关安全生产工作的决策部署，抓好本级旅游安全各项工作落实，确保完成2017年度全省旅游安全目标任务。

1、持续推动莆田市“十三五”旅游安全管理指导意见的实施，加大旅游安全管理人员、资金支持保障力，确保指导意见各项目标任务落到实处。

2、督促旅行社企业严格落实安全生产主体责任，推动旅游企业实行全员生产责任制度和岗位安全生产清单，做好安全责任、管理、投入、培训和应急救援五到位。

3、进一步深入开展旅游安全标准化建设，应根据各地安委会统一部署，引导旅游企业建立以标准化为基础的自主管理、持续改进的安全生产管理体系。

4、推进旅游安全诚信体系建设，进一步健全完善旅游安全信用信息报送和季度通报机制，并将旅游安全不良信用“黑名单”纳入到旅游诚信体系建设管理。

5、强化旅游安全管控，坚决防范和遏制重特大事故，推进旅游安全风险分级管控和隐患排查治理标准、制度规范制工作，督促旅行社企业落实《旅行社安全规范》（行业标准）；加强对星级饭店、A级景区旅游安全和应急管理工作的指导。

6、深化旅游安全监管，实行旅游安全监管执法“双随机”抽查机制；持续深化开展旅游安全大检查、专项整治和打非治违等工作，加强与安监、交通、公安、消防、质监、食品药品等部门的协作配合，联合开展旅游安全隐患排查治理，特别是要针对党的十九大、汛期、节假日以及金砖会晤等重点时段的排查整治；督促在职责范围内的旅游企业落实隐患排查治理的各项措施；督促落实挂牌督办安全隐患整改治理工作。

7、强化旅游安全宣传教育培训工作，积极推动《旅游法》、新修订《旅游安全管理办法》《福建省旅游条例》《福建省安全生产条例》的宣传贯彻工作；组织开展第16年全国“安全生产月”宣教活动；督促旅游企业认真学习领会、抓好贯彻落实，提升企业安全生产法治意识、员工安全意识和防护技能。

(四)要按照《莆田市人民政府办公室关于印发莆田市道路交通安全综合整治“三年提升工程”实施方案的通知》，进一步强化旅行社购买交通服务环节的安全监管，督促旅行社企业签订规范合同，健全完善旅游包车档案管理。

（五）严格落实考核奖惩措施，要采取警示通报、诫勉约谈、重点督办等综合措施，切实加强旅游安全管理目标责任的跟踪落实，严格实行旅游安全管理“一票否决”制度，并将旅游安全工作考核入列评先评优、文明旅游行业创建、平安综治等考核评分内容；对因管理松懈、责任制不落实引发事故的，要依法追究相关责任单位和责任人的责任。
