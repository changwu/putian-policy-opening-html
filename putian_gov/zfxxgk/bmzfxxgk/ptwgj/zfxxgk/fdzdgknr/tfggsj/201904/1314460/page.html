关于印发《2016年度旅游安全管理工作要点》的通知

发布时间：2016-03-30 11:25
| | |

各县（区、管委会）旅游局：

现将《2016年度旅游安全管理工作要点》印发给你们，请结合本单位实际，认真抓好贯彻落实。

  

 

莆田市旅游局

2016年3月30日

  

 

2016年度旅游安全管理工作要点

 

2016年旅游安全管理工作总体思路是：以党的十八届三中、四中、五中全会精神为指导，认真贯彻落实习近平总书记等中央领导和省委、省政府领导关于安全生产工作的重要批示精神，按照全省安全生产电视电话会议和全省旅游工作电视电话会议的总体部署要求。牢固树立安全发展观，强化红线意识，坚持游客利益至上，坚持综合治理、源头管控，坚持问题导向、紧盯短板瓶颈，以防范遏制旅游安全事故为重点，强化落实企业主体责任、行业监管责任和单位领导责任，创新监管模式，强化统筹协调，深化体系建设，提升行业安全管理能力水平，确保“十三五”开局之年开好局、起好步,推动全省旅游安全工作再上新台阶。

一、强化安全责任体系建设，有效督促旅游企业落实安全生产主体责任

1、按照“党政同责、一岗双责、失职追责”的要求，创新旅游安全目标责任机制和办法，强化落实“三个必须”（管行业必须管安全、管业务必须管安全、管生产经营必须管安全）的要求，全面厘清旅游安全监管责任，细化落实旅行社、星级饭店、A级景区、旅游节庆活动等安全责任制，消除监管盲区和漏洞。进一步明确旅游安全监管责任清单和权力清单，日常照单监管，失职照单追责，推动建立健全安全管理“党政同责、一岗双责”规定实施细则落实，努力构建“党政联动、齐抓共管”管理格局。

2、强化企业安全主体责任的落实，进一步督促旅行社、星级饭店严格履行安全生产法定义务，健全完善事故隐患排查治理制度，做到事故隐患自查、自报、自改的闭环管理，自觉履行安全生产主体责任。

3、按照市安全生产巡检工作制度要求，认真结合行业实际，加强对各县（区、管委会）旅游局和市局机关相关科室履行安全管理职责和重点工作部署落实等情况进行督促检查。强化重大事故隐患挂牌督办，建立事故隐患整改不落实责任追究制度。

4、根据市政府出台的安全生产考核办法，修订完善旅游安全管理考核办法，坚持过程考核和结果相结合，强化对各地履责检查和履职考核。

5、加大旅游安全管理工作在旅游产业发展、行业精神文明创建体系量化考核中的重权，实行旅游安全管理“一票否决”，推动落实“党政同责、一岗双责”和“三个必须”规定。

二、强化安全督查预警机制建设，彻底排除旅游安全生产隐患

6、严格落实企业隐患排查、治理、防控的责任，指导和督促旅游企业依法依规建立健全并落实隐患排查治理制度，着力抓好旅游企业安全隐患排查治理工作，推动落实“双随机”抽查机制，认真开展“四不两直”检查，各县（区、管委会）旅游局至少每季度开展一次，对检查中发现的安全隐患和问题，实行封闭管理，确保跟踪整改到位。

7、持续深化开展旅游安全大检查，发挥市旅游产业发展联席会议成员单位作用，联合开展旅游安全大检查，重点抓好重大节（假）日、重大旅游活动和重点时段的安全大检查。

8、深化开展专项整治和“打非治违”工作。重点查处星级饭店的消防、设施设备、非法用工、特种岗位持证上岗等安全管理情况，对作业规程缺乏针对性和可操作性、现场管理混乱、违章操作等现象进行治理。提升消防安全“四个能力”建设。

9、推进道路交通综合整治“三年提升工程”，重点对旅行社购买交通服务环节的监管。督促旅行社加强对旅游行程和线路安排的安全评估。加大联合执法力度，主动配合交通等相关部门依法查处旅游包车违规违法行为，确保用车安全。

10、加强旅游安全信息预警预报，加强与交通、气象、地震、卫生等部门开展协作，推动实现跨领域涉旅信息共享以及公共假日旅游信息监测预警的发布工作。

11、抓好旅游行业的防汛防台风工作，督促星级饭店、旅行社和A级景区做好汛期、台风期间的安全防范应对工作。

12、推进行业安全隐患排查治理体系和安全生产诚信体系建设，启动旅游安全信息管理系统列入大行管监管平台二期开发；建立并落实安全生产不良记录“黑名单”制度，推进企业安全生产诚信体系建设，继续推动企业开展安全生产诚信承诺制度。

三、强化安全基础建设，全面提升旅游企业安全管理水平

13、扎实推进旅游安全标准化建设提升工作，旅游安全标准建设提升工程已被省政府列入“立项挂牌办理”内容，各地要加大达标创建力度，采取有效办法，落实各项政策措施，确保全市旅游行业应达标企业到2016年12月底前100%评审达标，我局将在每季度后第1个月通报上季度开展安生标准化建设提升工程进展情况，对没按照时间进度要求完成的地区，在年度目标责任制考评中扣除分值。其中，3月底前评审达标率不少于85%、6月底前评审达标率不少于90%、9月底前评审达标率不少于95%。

14、推动旅游企业安全生产责任体系“五落实五到位”，继续把旅游企业贯彻落实《企业安全生产责任体系五落实五到位规定》工作情况纳入旅游安全生产标准化建设达标评审和安全监督检查的重要内容，促进旅游企业把“五落实五到位”规定转化内部规章制度，加大安全管理力度，加大安全经费投入，切实改善安全生产条件，提高旅游安全生产水平，确保2016年度旅行社、星级饭店“五落实五到位”100%落实到位。

15、根据国家出台的企业全员岗位安全责任指导意见，认真结合行业实际，督促推动星级饭店、旅行社贯彻落实，建立本企业安全生产责任清单，加强单位部门、班组、岗位和现场的管理。

16、推行旅游安全状况自评估和政府备检抽检，推动落实安全生产风险等级管理、安全诚信、安全费用提取等制度。

17、2016年是“十三五”开局之年，按照莆田市安全生产“十三五”规划的目标任务，推进和指导各地认真执行莆田市“十三五”旅游安全管理指导意见的实施，有效推进旅游安全工作的落实，争取在“十三五”开局之年实现开门红。

18、推动旅游应急机制与预案建设，落实政府主导、部门联动的应急处置机制，进一步完善应急救援体系建设和事故统计制度，督促做好旅游安全事故统计报送工作。 

19、推动星级饭店、A级景区评定严格按照评定标准的安全管理要求，把好星级饭店、A级景区评定的安全关，对不符合安全条件的饭店、景区，不得评定为星级饭店、A级旅游景区。

四、强化宣传培训，提升旅游企业从业员安全防范意识

20、持续推进开展新《安全生产法》、《旅游法》和做好新修订《福建省安全生产条例》的学习宣传和贯彻落实工作，形成良好的学法、用法、执法和守法氛围。

21、深化开展“安全生产月”、“中国旅游日”等活动，向社会发放旅游安全公益宣传片、旅游应急常识手册，让广大社会大众提高安全出游意识，形成全社会安全出游的良好舆论范围。

22、督促各地深化安全教育培训，指导星级饭店、旅行社加强对从业人员特别是高危岗位从业人员岗前的教育培训，开展应急救援预案演练，切实打牢企业的安全基础。
