关于进一步做好汛期旅游安全工作的通知

发布时间：2016-05-09 11:33
| | |

各县（区、管委会）旅游局：

　　据气象台预测，2016年全国全省雨季较长雨量较往年多，出现灾害性天气和极端天气的概率较大。我省已进入防汛紧要期，暴雨、洪涝以及次生灾害步频发，三明市泰宁县山体滑坡导致的重大人员伤亡事件给旅游安全工作敲响了警钟。为认真贯彻落实习近平总书记、李克强总理的重要批示和省、市会议精神，进一步做好汛期旅游安全工作，防止各类旅游安全事故发生，确保旅游者安全，现将有关工作通知如下：

　　一、切实抓好汛期隐患排查治理工作。各县（区、管委会）旅游局和旅游经营单位要充分认识做好汛期旅游安全工作的重要性，随时关注降雨特别是强降雨信息，防止次生灾害对旅游工作的影响。要根据气象预报和上级要求，适时启动各级应急响应，当前要立即启动Ⅲ级应急响应。要针对汛期特点制定周密的安全工作方案和应急预案，克服麻痹松懈思想，务必做好强降雨各项防范工作，认真部署汛期旅游安全工作，要立即组织对各项旅游设施进行一次全面检查，及时发现各种安全问题和事故隐患，采取切实可行的措施，整改安全隐患，确保游客生命财产安全。

　　二、各县（区、管委会）旅游局要配合有关部门做好涉旅企业安全工作。要求各A级景区要加强汛期的安全生产保障工作，在易遭受雷击的游览区域加设避雷装置和警示牌，遇到雷雨天气，要对游客进行疏导，防止地质灾害、洪涝灾害及泥石流、滑坡等带来的危害，根据天气情况及时关闭景区。要提示各旅游星级饭店针对汛期易发生安全生产故障和问题的部位，采取有效措施，加以防范，特别是要加强游泳池、制冷系统、供电线路、消防设施、疏散通道、应急广播以及各种火源和电源的安全检查，认真落实安全生产突发事件应急预案，及时消除各种安全生产隐患。

　　三、各旅行社要做好汛期交通安全等工作。各旅行社在组（接）团之前，应制定详细的行程安全方案，并对领队及导游人员加强安全教育。汛期行车要提醒司机注意交通安全，根据路况减速慢行，在途经危险路段、地质灾害可能性大或水上游览项目要提醒游客注意安全，对老龄和学生团队应当采取积极有效措施，随时清点游客人数，确保游客人身和财产安全。旅行社和导游要随时关注旅游目的地气象、地质、交通、卫生和防汛等部门的预警信息，适时采取应急处置措施，不组团前往雨水多雨量大发生地质灾害可能大的地区旅游。对在降雨强度大地区的旅游团队要立即停止一切旅游活动，提前将危险区域人员转移到安全地带，避免造成旅游安全事故。严禁组（接）旅游团队往发生暴雨及地质灾害大的景区旅游。

　　四、进一步加强值班值守，提高旅游安全事件处置能力。各县（区、管委会）旅游局和旅游企业要高度重视做好汛期旅游安全值班值守工作，严格执行领导干部到岗带班和关键岗位24小时值班制度。要及时与上下级有关部门之间保持联络，确保信息畅通。进一步完善旅游突发事件预案，提高应急处置能力，确保一旦发生旅游突发事件，能够迅速、有效展开救援，把损失降到最低程度。

　　五、做好汛期安全大检查工作。为保证汛期安全各项工作落到实处，根据安全生产“党政同责、一岗双责”规定，市旅游局成立汛期旅游安全生产工作领导小组，由局长王秋洪任组长，温训新调研员任常务副组长，黄宏敏副局长、苏玉庆副局长、陈兵副局长、赖秀云副调研员任副组长，办公室、行业管理科、市场开发科、产业发展科、旅游监察大队、公共服务中心负责人为成员。领导小组下设办公室，挂靠在行业管理科。同时成立四个汛期安全检查组，分别由温训新调研员、黄宏敏副局长、苏玉庆副局长、赖秀云副调研员任组长，立即组织对全市汛期旅游安全进行检查，具体分组名单是：

　　1、一组：（仙游县、秀屿区）负责人：温训新，成员：林国防、肖丽凡

　　2、二组：（城厢区、湄洲岛管委会）负责人：黄宏敏，成员：任斌俊、陈梅清

　　3、三组：（涵江区、北岸管委会）负责人：苏玉庆，成员：蔡雪松、钱丽莺

　　4、四组：（荔城区）负责人：赖秀云，成员：陈美弟、陈晨光

　　各县（区、管委会）旅游局也要成立汛期旅游安全工作领导小组，及时组织对辖区内旅游企业进行安全检查。

　　 

　　 

　　 

　　莆田市旅游局

　　                                                                                        2016年5月9日
