莆田市文化和旅游局关于开展2019年“安全生产月”和“安全生产专题行”活动的通知

发布时间：2019-05-29 16:42
| | |

　　各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸宣传部、文旅办，机关各科室，局属各单位：

　　根据省文旅厅《关于发展2019年“安全生产月”和“八闽安全发展行”活动的通知》（闽文旅市场〔2019〕21号）、市安办《关于开展2019年“安全生产月”和“安全生产专题行”活动的通知》（莆市安办〔2019〕23号）要求，现就有关事项通知如下：

　　一、指导思想

　　以习近平新时代中国特色社会主义思想为指导，深入宣传贯彻党的十九大和十九届二中、三中全会精神，深入学习宣传习近平总书记关于安全生产工作的重要论述。贯彻落实党中央、国务院、省委、省政府和市委、市政府关于安全生产工作的决策部署，以深入推进安全生产领域改革发展为主线，以“防风险、除隐患、遏事故”为主题，以增强全民应急意识、提升公众安全素质、提高防灾减灾救灾能力、遏制重特大生产安全事故为目标，以强化安全红线意识、落实安全责任、推进依法治理、深化专项整治等为重点内容，创新平台载体，强化部门协作，融合线上线下，丰富活动形式，大力开展安全生产宣传教育，推动全市文化和旅游系统安全生产形势持续稳定好转，为新中国成立70周年营造良好的安全生产环境。

　　二、组织机构

　　成立市文化和旅游局“安全生产月”和“安全生产专题行”活动组织委员会，（以下简称“组委会”），由局分管领导任主任，局机关各科室及局属各单位负责人为成员，组委会办公室设在局办公室，负责组织、指导、协调、督导全市“安全生产月”和“安全生产专题行”活动。各县区（管委会）文旅部门，局属各单位应成立相应的组织机构，抓好各项工作落实。

　　三、活动时间

　　6月1日至30日

　　四、活动安排

　　(一)开展主题宣讲活动。组织开展对文化和旅游企业对口宣讲，通过发放安全生产教育读本、观看安全生产宣传教育片等形式，解释企业安全生产主体责任的具体内容，宣讲安全生产法律法规和知识技能，推动企业切实做到安全责任、管理、投入、培训和应急救援“五到位”。

　　(二)配合开展“6·16”线下线上咨询活动。各县(区、管委会)文旅部门要积极参与当地安委办组织的现场咨询活动，用群众喜闻乐见的方式通俗易懂地宣传习近平总书记关于安全生产的重要思想、安全生产方针政策、法律法规和应急知识、旅游安全知识、消防安全知识、防灾减灾救灾常识等安全科普知识和技能,面对面解答安全生产问题,并现场接受举报。各级文化和旅旅行业网站、微信、微博、各类电子媒介要通过安全生产主题采访、开设专版专栏、播放安全宣传片、公益广告等多种形式深入开展宣传活动。

　　（三)开展安全生产事故警示教育活动。要强化文旅系统易发生重特大事故领域预警预报信息；集中组织观看警示教育片、警示教育展，采取以案说法等方式剖析典型事故和灾害案例，做到举一反三，严防类似事故；采取事故警示教育视频片网络展播等方式开展网上警示教育活动。要加强文旅安全设施建设，运用互联网+、大数据、虚拟现实(VR)等新科技，大力开展应急培训和体验式安全教育，不断提高旅游业者和游客的应急意识和安全素质。要在歌舞娱乐场所、游艺娱乐场所、互联网上网服务营业场所、文化场馆、印刷企业、文物保护单位、旅行社、星级饭店、A级景区等公共场所播放警示教育片、警示公益广告、微电影、动漫等，不断提高安全意识和防范技能。

　　(四)开展安全生产应急预案演练活动。要广泛深入开展实战化应急演练，选择歌舞娱乐场所、游艺娱乐场所、互联网上网服务营业场所、文化场馆、印刷企业、文物保护单位、旅行社、星级饭店、A级景区等安全重点区域和重点部位，广泛开展应急演练活动，举行安全生产应急培训，检验和完善应急预案，切实提高预案的严谨性、规范性、针对性和可操作性，强化应急安全管理,提高应急处置能力。要将演练活动与加强安全知识教育和应急建设相结合，加大装备物资投入，注重专业人才培养,组织开展应急预案、应急知识、自救互救和避险逃生技能方面的培训和比武竞赛等活动，提高防灾减灾和应急处置能力。

　　(五)组织开展专项执法活动。根据“管行业必须管安全”的规定，市文化市场综合执法支队要组织文化和旅游经营者及文保单位开展安全生产培训、专项隐患排查、安全生产执法检查和安全知识宣传等活动。要综合运用行政执法、联合惩戒、媒体曝光等手段，对违法违规行为严查重处，在全社会形成执法威慑，倒逼企业落实主体责任，强化安全基础管理，提升本质安全水平。

　　(六) 组织开展安全生产知识宣传。继续深入开展“安康杯”竞赛、安全生产宣传教育“七进”、《安全生产法》宣传周等安全生产共建共享活动，引导文化和旅游从业人员增强做好安全生产工作的主动性和自觉性。要充分发动文化和旅游从业人员参与检查工作，夯实安全生产的群众基础，维护社会公共安全。要采用LED屏播放、悬挂标语、横幅、发放宣传材料等形式，开展有针对性的安全生产宣传。在各公共文化和旅游场所，设立安全生产宣传栏、悬挂标语、横幅、安全等宣传手段，提高群众的安全生产意识，营造良好的安全生产氛围。利用网站、微信等新媒体传播安全发展观念，普及安全知识和技能，推动全社会关注安全生产，引导全社会深刻认识安全生产就是保生命、保健康、保幸福，大力营造安全生产人人有责、安全生产从我做起的良好氛围。市群众艺术馆、莆仙大剧院要开展有关安全生产的文艺演出等活动。

　　五、“安全生产专题行”活动安排

　　配合市安办邀请主流媒体和行业媒体的记者组成采访报道组，开展“安全生产专题行”与“安全生产月”活动，深入开展集中采访报道，活动以习近平新时代中国特色社会主义思想为指导，紧紧围绕贯彻落实党的十九大精神，聚焦责任落实、改革发展、科技强安、依法治安等方面重点内容，开展宣传、采访、报道活动，加强舆论引导和监督，推动应急管理和安全生产重点工作落实。

　　（一）配合开展问题整改“回头看”。配合市安办报道本系统落实《地方党政领导干部安全生产责任制规定》情况，深化安全监管监察体制、完善监管工作机制等改革创新举措，以及安全生产诚信体系建设、安全生产领域联合激励和联合惩戒机制等工作实施情况；采访企业落实安全生产主体责任和全员安全生产责任制、安全生产大检查自查自改工作情况，宣传好经验好做法，曝光安全责任不落实和落实不到位的企业和单位。

　　（二）配合开展依法治安专题行。围绕“安全生产执法提升年”活动，结合安全生产宣传教育“七进”等活动，配合市安办对本系统落实《安全生产法》《消防法》《防震减灾法》《福建省安全生产条例》等法律法规情况进行采访，推动相关措施要求落到实处；配合市安办跟随安全监管执法人员进行明查暗访，做好提升安全生产治理能力方面的报道，在主流媒体曝光典型非法违法企业和行为，形成执法检查高压态势。

　　（三）配合开展网上安全生产专题行。配合市安办调研文化和旅游行业，在运用信息化、数字化、智能化等现代方式提高安全基础保障能力等方面的工作开展情况，筑牢社会公众“生命至上、安全发展”的思想，推动实现文化和旅游安全生产共建共治共享。

　　（四）配合开展典型宣传专题行。配合市安办深入发掘、宣传一批奋战在文化和旅游系统安全生产战线上有代表性、有影响力的最美人物、先进典型，努力凝聚安全发展的正能量，进一步激发文化和旅游系统安全监管工作者和安全管理人员的责任感、使命感和荣誉感。

　　六、工作要求

　　（一）加强组织领导。各县区（管委会）文旅部门和局属各单位要召开专题会议，制定方案，认真部署动员，确保组织到位、责任到位、经费到位。要把“安全生产月”、“安全生产专题行”活动作为当前安全生产重点工作，做到与业务工作同谋划、同部署、同检查、同考核、同落实。各县区（管委会）文旅部门和局属各单位主要领导、分管领导要参加1至2项“安全生产月”、“安全生产专题行”系列活动。

　　（二）提升活动实效。各县区（管委会）文旅部门和局属各单位要将“安全生产月”活动与安全生产各项工作相结合，围绕主体，聚焦企业安全生产管理全过程，同步推进歌舞娱乐场所、游艺娱乐场所、互联网上网服务营业场所、文化场馆、印刷企业、文物保护单位、旅行社、星级饭店、A级景区等安全生产宣传教育活动。

　　（三）深入宣传报道。要制定“安全生产月”和“安全生产专题行”活动宣传报道计划,推出更多形式多样、内容丰富的新闻报道和题材,营造关心安全生产、参与安全发展的良好舆论氛围。

　　（四）强化督导考核。各县区（管委会）文旅部门和局属各单位要按照2019年全市“安全生产月”和“安全生产专题行”活动考核评分表，逐一落实各项考核标准，突出对安全生产宣传组织机构、活动开展、专栏专题等工作的检查督导，并要将“安全生产月”和“安全生产专题行”活动开展情况纳入年度安全生产工作考核内容，推动“安全生产月”和“安全生产专题行”活动的落实。

　　请各单位于每周三前报送“安全生产月”和“安全生产专题行”活动及其他相关工作开展情况，并于6月29日之前报送活动总结到局办公室。
