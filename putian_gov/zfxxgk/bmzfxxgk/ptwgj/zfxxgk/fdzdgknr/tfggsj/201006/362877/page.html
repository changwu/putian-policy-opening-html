莆田市文化广电新闻出版局关于印发《2010年全市文化广电新闻出版系统开展落实企事业安全生产主体责任活动工作要点》的通知

发布时间：2010-06-11 08:00
| | |

各县区（管委会）文体局（社会事务办、文教局），市直属各单位：

根据《莆田市人民政府安全生产委员会关于印发莆田市开展落实企业安全生产主体责任活动的指导意见的通知》（莆市安〔2009〕5号）要求，为确保本系统落实企事业安全生产主体责任活动顺利开展，现将《2010年全市文化广电新闻出版系统开展落实企事业安全生产主体责任活动工作要点》印发给你们，请认真贯彻执行。

 

 

二〇一〇年六月十一日

 

 

2010年全市文化广电新闻出版系统

开展落实企事业安全生产主体责任活动工作要点

 

    为了进一步深化开展落实企事业安全生产主体责任三年行动，强化企事业安全生产基础管理，有效遏制各类事故的发生，确保全市文化广电新闻出版系统安全生产形势稳定好转，根据上级的统一部署，结合本系统实际，现将全市文化广电新闻出版系统2010年度开展落实企事业安全生产主体责任活动工作要点通知如下：

一、工作目标

      进一步巩固和提升去年开展落实企事业安全生产主体责任活动的成效，强化隐患整改，实行分类管理。继续采取各种行之有效措施，加大宣传发动，精心培植典型，强化督促指导，拓宽覆盖面，力争今年所有的企事业单位参与并完成级别评定任务。

      二、工作步骤

（一）宣传发动阶段（2010年1—5月）

各单位要充分认识开展落实企事业安全生产主体责任的重要性，切实加强组织领导，细化工作措施，层层落实工作责任，在安全生产宣传月中广泛宣传发动，营造浓厚的舆论氛围；要根据市局的制定的工作要点，及时制定出本单位的工作要点，明确目标、任务和具体措施。并根据今年的工作目标，对开展级别的评定的企事业单位按《莆田市文化广电新闻出版局关于印发文化广电新闻出版行业开展落实企业安全生产主体责任活动指导意见的通知》（莆市文〔2009〕122号）的通知要求，逐一普查，分类造册，摸清底数，便于督促检查。各单位制定的工作要点和普查摸底情况，于6月20日前上报市局办公室（联系人：王建平，联系电话：2696660）。

（二）全面推进阶段（2010年6月—11月）

各相关单位要集中人员、集中时间，深入企业开展督促、检查、指导工作，并精心培植典型企业，通过召开现场会、交流会等形式，推进这项工作全面、深入开展，力争完成今年各项工作目标任务。同时，企事级别评定后，各县区文体局应按要求进行分类指导，落实具体管理措施。

（三）考评验收阶段（2010年12月）

市局将于6-7月间组织督查组，督查各县区文体局（社会事务办、文教局）、市直单位工作开展情况；于2010年12月底，对全市开展这项工作情况进行考评验收。

三、工作要求

（一）严格落实责任。各单位要把开展落实企业安全生产主体责任活动与“安全生产年”，“责任落实年”，平安文化市场创建工作等有机结合起来。严格工作标准，加强督促检查，要防止搞形式、走过场。对因组织领导不力，导致企业安全生产主体责任不落实、安全事故多发的，要按照有关规定，严肃追究相关人员的责任。

（二）强化工作力度。各单位要加强组织领导，加大工作力度，推进本单位开展落实安全生产主体责任活动，要加强与安全生产监督管理部门的联系、沟通、协调、配合，及时召开会议，协调解决具体困难和问题。

（三）突出工作重点。经研究，决定对市电影公司、市群众艺术馆、市图书馆、市艺术学校、市博物馆、市三清殿文物保护管理所列为开展落实企事业安全生产主体责任活动的重点。对莆田市三清殿文物保护管理所作为典型示范点，引导所属单位进行现场观摩、学习取经，提高全系统创建水平。各县区文体局（社会事务办、文教局）可结合各自的实际情况，分别确定工作重点，并开展工作部署和跟踪督查。市文化市场稽查队要重点对县区的娱乐场所、网吧、演出、印刷行业开展落实企业安全生产主体责任活动进行督促检查。

（四）加强舆论宣传。各单位要通过张贴标语、宣传栏、广播、电视、网络等宣传舆论工具，全面开展“落实责任”宣传教育和培训工作，努力提高员工安全意识，营造浓厚的舆论氛围。
