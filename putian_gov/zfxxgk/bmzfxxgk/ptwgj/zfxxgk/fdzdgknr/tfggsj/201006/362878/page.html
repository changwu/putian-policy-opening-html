关于印发《莆田市文化广电新闻出版局开展“平安文化市场”创建活动实施方案（修订）》的通知

发布时间：2010-06-22 08:00
| | |

各县区（管委会）文体局（社会事务办、文教局），机关各科室，市直属有关单位：

根据市委、市政府《莆田市社会治安综合治理和平安莆田建设工作责任考核暂行规定》（莆市综治委[2009]23号）和市综治委《关于全市深入开展系列平安创建活动的意见》（莆综治委［2009］25号）的通知精神，结合本系统实际，现将《莆田市文化广电新闻出版局开展“平安文化市场”创建活动实施方案（修订）》印发给你们。请结合本单位实际,认真贯彻执行。

 

 

二○一○年六月二十二日 

 

 

莆田市文化广电新闻出版局

开展“平安文化市场”创建活动实施方案（修订）

 

为了进一步深化开展我市平安文化市场创建活动，强化文化市场管理，有效遏制各类非法活动的发生，确保全市文化市场平安稳定，根据上级的统一部署，结合本行业的实际，现提出如下实施方案：

一、指导思想
    坚持以“三个代表”重要思想和科学发展观为指导，深入贯彻以人为本的执政理念，充分发挥行政管理部门的职能作用，紧紧围绕构建和谐社会的总体目标，以开展平安文化市场建设活动为载体，不断提高构建和谐社会的能力，为促进我市经济平稳较快发展和迎接省运会在我市的顺利召开营造和谐稳定的社会文化环境。
    二、工作目标
    “平安文化市场”创建活动的周期为五年（从2009年至2013年止）。按照市委、市政府和市综治办关于2009年系列平安建设工作的总体部署，各级主管部门要充分发挥行政管理职责，重点查处网吧、娱乐场所违规接纳未成年人,依法打击文化市场违法经营行为，整顿文化市场经营秩序，营造平安有序的市场环境和健康安全的消费环境，实现社会更加稳定、文化更加繁荣、经营更加安全、群众更加安心的创建目标。

三、组织领导
    为加强平安文化市场的创建工作，成立莆田市“平安文化市场”创建工作领导小组，组长：刘晶洁，副组长：罗锦枝、杨金远，成员：柳青、张玉应、蔡莉莉、吴寿涛、郑永昇、刘凌翔、林共和、林顺明、林锋、林平凡、曾德洪、周超鸿、戴玉瑞、林更宇。领导小组下设办公室。依托在市文化市场稽查队，联系人：罗冬碧，具体负责创建工作的检查指导工作。各县（区）文体局要参照市里的做法，相应成立创建工作领导小组及其办公室，具体负责创建工作的牵头协调、考评和命名工作。
    四、工作措施
    进一步强化行政管理职能，做好促进安全生产、保护安全消费和社会大局稳定等工作，多措并举，确保平安创建工作取得实效。
    （一）开展保护知识产权、打击侵权盗版专项整治行动。紧紧围绕知识产权宣传周活动，在全市掀起保护知识产权、打击侵权盗版的新高潮。严厉打击销售盗版音像、图书等非法经营行为，查市场，堵源头、端窝点，进一步提高全市图书、音像市场的正版占有率。坚决查处非法游商销售盗版音像、图书等非法经营行为，特别是对影响面广、危害性大的违法经营者，要依法严惩，涉嫌犯罪的，要移送司法机关追究其刑事责任。

（二）开展网吧专项整治行动。网吧管理关系到未成年人的健康成长，要加强暑假、寒假期间以及法定节假日、双休日等重点时段的监管，对网吧管理要始终保持高压态势，并采取强有力的措施，狠抓全方位的落实。重点查处网吧违规接纳未成年人行为、没有核对登记上网顾客的有效身份证件、登陆淫秽网站以及传播有害信息等行为。

（三）开展歌舞娱乐场所专项整治行动。进一步明确工作责任，落实工作措施，加大对娱乐场所的巡查的力度，依法查处歌舞娱乐场所违规接纳未成年人违法行为。

（四）开展演出市场专项整治行动。各县区和演出管理处要严把审批关，加强节日集会期间的演出市场管理，依法打击色情、淫秽表演等各类非法演出活动。加强对大型商业性演出活动的监管特别是场所安全和消防安全，取缔未经许可的营业性演出活动。

（五）开展公众聚集场所安全隐患排查专项整治行动。全面排查治理各类文化市场人员聚集经营场所和文化活动在安全生产方面存在的隐患，重点检查安全生产管理机制、管理组织体系、责任落实、劳动纪律、现场管理等方面存在的薄弱环节。对文化市场人员聚集场所，包括演出场所、歌舞娱乐场所、网吧等以消防安全为重点进行彻底排查。对存在安全隐患的公众聚集场所，要责令整改。对整改不到位或无法整改的，要坚决关停。

五、工作要求

（一）加强宣传力度。充分发挥新闻媒体的作用，坚持正确的舆论导向，利用各种渠道，采取多种形式，大力宣传平安文化市场创建活动的任务、目标和重要意义。举办各种培训班，大力普及“平安文化市场”创建的措施和方法，增加文化创安知晓率和参与率，把平安文化市场创建工作作为落实科学发展观、构建和谐社会、实现文化惠民的重要举措，不断加强组织宣传，营造良好的创建氛围。注意发掘和善于总结平安文化市场创建活动的典型，每年至少培育4个典型，其中，音像店、网吧、娱乐场所、书店各1个。通过在创建平安文化市场开展现场会表彰、授匾等方式，坚持典型引路，努力增强文化市场参与创建工作的主动性和积极性，认真总结经验，拓展面上工作。
    （二）落实工作责任。“平安文化文化市场”创建工作按照“属地管理”、“谁审批、谁负责”的原则，由县（区）文体局负责组织实施、市文化主管部门负责督促、指导。县（区）文体局要采取“文化市场业主自查自评，各县（区）文体局主管部门初评，县（区）文体局创建办考评验收命名”的程序进行（具体工作流程见附件3）。具体是：

1、文化市场经营单位要对照《莆田市“平安文化市场”创建考评验收标准》（附件1）进行自查自评后，填制申请表（附件2），报县（区）文体局文化主管部门，县（区）文体局文化主管部门要根据文化市场经营单位自查自评情况进行现场比对、初评后，报县（区）文体局文化主管部门创建工作办公室。

2、市文化主管部门创建工作办公室要对县（区）文体局上报的初评情况进行考评、确认，并对评上的“平安文化市场”予以授匾。

3、市文化主管部门要督促、指导县（区）文体局主管部门的创建工作，要经常深入文化经营场所调研、检查、指导，注重培育典型，强化宣传教育，切实提升“平安文化市场”的创建水平，市创建领导小组及其办公室要加强对全市“平安文化市场”创建工作的研究部署，检查指导、协调沟通、表彰先进工作，确保各项创建工作落到实处。

（三）落实创建措施。各县（区）文体局要将“平安文化市场”创建工作作为当前的重要任务，采取切实有效的措施，指导督促各文化经营单位开展创建工作。要根据全市“平安文化市场”创建总体部署和工作要求，结合各自实际，制订出台创建五年总体规划和年度创建工作计划，并细化创建标准和考评细则。要通过召开各种形式会议进行动员、部署、将创建精神贯彻到每个文化经营单位。要经常深入每个文化经营单位，为文化经营单位创建提供有效的指导和保障。要根据各类创建文化市场的不同基础条件，分解指标，明确进度，分层次、分步骤逐年有序推进。建立健全“平安文化市场”创建考评制度台帐，主要包括平安文化市场创建组织领导网络、平安文化市场创建五年规划、年度工作计划、市综治委有关文件（会议精神）的贯彻落实情况、创建经费投入情况和创建工作会议记录、检查指导记录、检查考评命名情况及各项工作制度建立情况等。

（四）严格考评奖惩。县（区）文体局要严格按照《莆田市创建“平安文化市场”考评验收标准》进行考评验收、命名。经考评验收合格的文化经营单位，由县（区）文体局创建工作领导小组命名为“平安文化市场”，授予“平安文化市场”牌匾。已获得“平安文化市场”称号的文化经营单位，如工作退步或发生严重问题，由县（区）文体局创建工作领导小组组织检查组对其进行复查，不符合标准的取消其“平安文化市场”资格并收回牌匾；如出现变更、兼并、倒闭等情形，原命名的“平安文化市场”自动取消，为确保创建工作质量，市“平安文化市场”创建工作领导小组要对各县区“平安文化市场”进行抽查，抽查不合格的，取消该“平安文化市场”的资格。创建活动先进单位、个人的评选表彰工作，经各县（区）创建工作领导小组组织初评和市创建工作领导小组办公室复评后进行表彰。

附件：1、莆田市文化市场经营单位平安创建考核细则
