莆田市文化广电新闻出版局关于印发全面开展安全生产大检查、深化“打非治违”和专项整治工作实施方案的通知

发布时间：2015-08-22 08:00
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属各单位，机关各科室：

为进一步加强安全生产工作，强化安全监管，推进依法治安，根据市政府安委会《关于印发全面开展安全生产大检查、深化“打非治违”和专项整治工作实施方案的通知》（莆市安〔2015〕11号）要求。我局决定，从2015年8月至12月底在文化系统全面开展安全生产大检查，进一步深化“打非治违”和专项整治工作。现将有关通知如下：

一、总体要求

认真贯彻落实习近平总书记、李克强总理等党中央、国务院

领导同志关于加强安全生产工作的重要指示批示精神，按照“全覆盖、零容忍、严执法、重实效”的总要求，坚持问题导向，全面开展大检查、大排查，强化安全，保持“打非治违”高压态势，深化专项整治，彻查安全隐患，堵塞管理漏洞，强化源头治理，有效防范和坚决遏制重特大事故发生，促进文化系统安全生产形势持续稳定好转，为纪念抗日战争胜利70周年活动和建设宜业、宜商、宜居莆田创造良好安全环境。

二、主要内容

（一）立即全面开展安全生产大检查

1．检查重点。以公众聚集的文化市场经营场所为重点检查对象，主要包括歌舞娱乐、游艺游戏、网吧、演出、影剧院、印刷、出版等经营场所。

2．检查内容。

（1）建立健全“党政同责、一岗双责、齐抓共管”安全生产责任体系，实现“五级五覆盖”、企业“五落实五到位”，推进重点工作落实情况。

（2）贯彻落实新《安全生产法》要求，加强安全监管。

（3）严格落实企业主体责任，健全安全制度，落实安全投入，加强安全培训，推进安全生产标准化建设等情况。

（4）落实安全检查责任制，突出重点行业领域，加强安全管理，深入开展隐患排查治理，对查出的问题和隐患整改落实情况。

（5）建立健全预防自然灾害引发事故应急处置协调联动机制，落实汛期安全防范措施情况。

（二）深入开展打非治违专项行动和重点行业领域专项整治

1．消防：重点打击消防设计未经审核或审核不合格擅自施工、消防设施未经验收投入使用行为。突出抓好人员密集场所火灾隐患排查整治，整治违规住人、违规使用聚苯乙烯和聚氨酯泡沫塑料作装修装饰材料、消防设施缺失损坏、安全出口疏散通道堵塞锁闭等问题。

2．粉尘涉爆：结合粉尘防爆安全生产专项整治、粉尘作业和使用场所防尘爆炸大检查工作的深入开展，重点打击违规使用可燃性彩色粉尘行为，整治作业场所违反《严防企业粉尘爆炸五条规定》（国家安全监管总局令第68号）存在除尘系统未采用泄爆措施、粉尘清理不及时等问题。

同时，把打非治违专项行动与安全生产大检查、劳动密集型企业消防安全专项检查、粉尘作业使用场所防范粉尘爆炸安全大检查、电梯和游乐设施等特种设备安全专项整治、加强应急救援演练等紧密结合，将安全生产大检查中发现的严重非法违法行为和重大隐患，纳入“打非治违”的重点内容，依法依规严厉打击、彻底整治。

三、工作安排

（一）全面排查

1．各单位要结合实际制定工作方案，深入动员、层层落实，全面开展自查自纠。

2．各单位要组织对文化系统领域进行全面检查。

（二）集中整治

加强督促检查，开展暗查暗访，推动各项工作措施落实到位。

（三）巩固提升

各单位对安全生产大检查、深化“打非治违”和专项整治工作开展情况进行全面总结，针对突出问题制定有力措施，推动建立安全生产长效机制。

四、有关要求

各单位要把全面开展安全生产大检查、深化“打非治违”和专项整治作为当前安全生产重点工作，精心安排部署，认真抓实抓好。

（一）加强组织领导。要按照“党政同责、一岗双责、齐抓共管”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，切实加强组织领导，确保贯彻到位、工作到位、措施到位，严防搞形式、走过场。

（二）创新工作方式。采取暗查暗访、随机抽查、“回头看”检查、交叉检查，通过实行联合执法、案件移送、公布“黑名单”、集中曝光警示等多种方式，深查问题，彻查隐患，督促整改到位。

（三）严格检查执法。坚持对非法违法行为和重大安全隐患

 “零容忍”，一经发现，坚决采取“四个一律”和等措施，做到从严查处、打击到位。

（四）加强宣传引导。充分利用电视台、报刊、网络等各种媒体，采取各种方式，加强示范引领和警示教育，引导广大职工和人民群众参与、支持安全生产工作。

（五）坚持综合治理。加强统筹协调，强化监督检查，把安全生产大检查、深化“打非治违”和专项整治工作纳入安全生产目标责任制考核重要内容，推动工作有效落实。
