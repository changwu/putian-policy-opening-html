关于印发莆田市文化广电新闻出版系统消防安全大排查大整治大宣传大培训大练兵活动实施方案的通知

发布时间：2011-02-17 08:00
| | |

各县区（管委会）文体局（社会事务办、文教局）、市直属各单位：

经研究同意，现将《莆田市文化广电新闻出版系统消防安全大排查大整治大宣传大培训大练兵活动实施方案》印发给你们，请结合实际，认真抓好贯彻落实。

 

 

 

二○一一年二月十七日 

 

 

 

 

莆田市文化广电新闻出版系统消防安全

大排查大整治大宣传大培训大练兵活动实施方案

 

为进一步贯彻落实《福建省文化厅关于组织开展消防安全大检查大整治活动的通知》（闽文办〔2011〕10号）精神，根据《莆田市人民政府办公室关于印发莆田市消防安全大排查大整治大宣传大培训大练兵活动实施方案的通知》（莆政办〔2011〕13号）的要求，决定从即日起至2011年底，在全市文化广电新闻出版系统集中开展消防安全“大排查、大整治、大宣传、大培训、大练兵”活动，特制定如下方案。

一、总体目标

进一步深化消防安全大排查大整治，不断加大消防安全监管力度，整改消除火灾隐患，严厉打击消防违法行为，有效改善消防安全环境；进一步强化消防安全大宣传大培训，牢固树立“全民消防、生命至上”理念，努力实现人人懂火灾预防常识、会扑救初起火灾、会疏散逃生；持续开展大练兵，切实提升综合应急救援队伍灭火救援能力、各单位处置初起火灾能力和公民火场逃生自救能力，不断增强各种场所抗御火灾的能力和水平，有效遏制重特大火灾事故发生，全力维护全市文化广电新闻出版系统消防安全形势稳定。

二、工作任务

（一）集中开展大排查大整治

各县区（管委会）文体局（社会事务办、文教局）、局属各单位要按照“谁主管、谁负责”和“属地管理”的原则，对在建工程施工工地、公共文化服务场所、文化演出场所、文物保护单位、公开娱乐场所、经营性文化娱乐场所等人员密集场所开展火灾隐患排查整治，积极改善全市文化广电新闻出版系统消防安全环境。

1、开展工程建设的安全排查

2011年春节前，积极配合建设行政主管部门开展排查整治。莆仙大剧院工地要进行一次全面的消防安全检查。检查建设工程消防设计审核、备案抽查情况，检查消防通道、消防水源、消防设施和器材的设置、配置情况，制止消防安全违法行为。

2、开展所属有关场所消防安全排查整治

2011年，对所有公共文化服务场所、文化演出场所、文物保护单位、公共娱乐场所、经营性文化娱乐场所等人员密集场所开展一次全面的安全检查。积极配合消防部门负责对以上场所进行检查。重点检查单位消防安全责任落实情况、建筑消防设施维护保养和完好有效情况、疏散通道和安全出口畅通情况、室内装修装饰违规使用易燃可燃装修材料情况、消防控制室值班操作人员持证上岗及应急处置程序掌握情况，依法查处消防安全违法行为。

按照安全工作“一岗双责”的要求，市文化市场综合执法支队要督促指导各县区对歌舞娱乐场所、网吧、演出场所、电子游戏场所等人员密集场所的检查和隐患的整改；市文管办要督促指导对全市文物保护单位的检查和隐患的整改，重点督促指导落实开展防火检查和落实防火巡查制度，建立健全各项消防安全管理制度，制定、完善灭火和应急预案，定期演练，切实提高单位的自防自救能力，督促和指导单位制定火灾隐患整改方案，以及依法对违反消防安全管理行为的处罚。艺术馆、艺校、博物馆、三清殿、图书馆、电影公司、人民影剧院等要健全防火预案，经常性检查用电、防雷、灭火等设施。

3、深化“三合一”场所排查整治

各县区（管委会）文体局（社会事务办、文教局）、局直属各单位结合《福建省人民政府办公厅关于印发“三合一”场所综合整治工作若干措施的通知》（闽政办〔2007〕235号）要求，开展“三合一”场所的全面排查，要按照“联合整治、分类处理、标本兼治、综合治理”的原则，分动员部署、自查整改、认真排查、严厉整治4个阶段进行，县区单位的具体阶段安排结合各县（区）实际确定。

（1）动员部署。各县区（管委会）文体局（社会事务办、文教局）、局属各单位要结合实际，确定本单位的工作重点和针对性措施，迅速进行动员部署，将任务分解细化到具体岗位及人员。

（2）自查整改。各单位要迅速召开会议，广泛深入动员，部署本单位开展火灾隐患自查自改工作。

（3）认真排查。各单位要按照职责分工，在本单位、本系统内开展大排查大整治活动。对排查的单位和场所，逐一登记造册，建立台账，如实记载检查人员的姓名、检查时间、检查发现的问题、提出的整改意见等。

（4）严厉整治。对排查发现的火灾隐患，要依法责令改正，督促制定整改方案，明确整改期限。对影响公共安全的重大火灾隐患，要提请当地政府按照《重大火灾隐患政府挂牌督办制度（试行）》的规定，实施挂牌督办，限期消除。

（二）集中开展大宣传大培训

各单位应当组织开展经常性的消防宣传教育培训，提高公民的消防安全意识。

1、开展消防安全大宣传

（1）开展群众性消防宣传教育活动。2011年春节前，各单位要充分利用自身的优势（如利用文艺活动、宣传栏、悬挂横幅等）开展以“普及冬防春运消防安全常识、安全燃放烟花爆竹知识，检查、消除身边火灾隐患，开展逃生自救演练”为主要内容的群众性消防宣传教育活动。

（2）强化媒体宣传工作。各单位要利用本单位的网站开设专栏、专题，以字幕提示、公益广告、专题报道等形式，在重大节假日期间和火灾多发季节，集中宣传防火常识和逃生自救常识。

（3）强化社会宣传活动。各单位要继续深入推进消防宣传“五进”工作，积极走进消防教育馆、博物馆、科普教育基地和消防站，利用文艺演出、逃生疏散演练等开展经常性的宣传教育活动。公共文化娱乐场所要在安全出口、疏散通道、消火栓、灭火器的位置设置明显的指示标识和使用方法的提示。

2、开展消防安全大培训

（1）开展从业人员集中培训。各县区文体局要督促所管辖的经营场所的从业人员进行一次消防安全知识培训。2011年底前，要有70%以上的消防控制室值班操作人员应取得相应的国家职业资格证书。

（2）开展单位消防安全教育培训。5月27日，市局将联合消防、安办部门在三清殿文保所举办“文物安全消防先行”为主题的消防安全知识培训班和消防实操演练。各县区应于6月10前与所在地的消防大队官兵联系，对所属单位人员进行消防安全知识培训和实操演练，培训与演练计划提前一周上报市局，届时市局将指派专人现场观摩。2011年底前，配合保安培训机构要对保安员进行全员消防技能培训，提高火灾防范和扑救初起火灾的能力。艺校要把防火预案、防火知识，火灾逃生自救演练纳入教学课程。

（三）集中开展大练兵

各单位要认真修订完善火灾应急预案，掌握各类火灾扑救及其他灾害事故处置程序，邀请消防官兵现场指导，开展一次消防应急演练活动，使干部职工熟悉疏散通道、安全出口，掌握疏散程序、逃生技能，增强干部职工逃生自救能力。

三、有关要求

（一）高度重视，提高认识。各单位要迅速动员部署，统一思想认识，细化工作措施，坚决预防和遏制重特大火灾尤其是群死群伤火灾事故的发生。

（二）明确责任，抓好落实。各单位要切实履行消防工作职责，建立健全逐级消防安全责任制和岗位消防安全责任制，明确消防安全责任人、消防安全管理人及其各自职责，严格落实消防安全责任制，一级抓一级，层层抓落实，确保各项工作落到实处。

（三）加强协作，齐抓共管。各单位要严格履行各自职责，对所属的（场所）火灾隐患查改情况认真进行检查督办，定期通报整治信息，切实加强协作、齐抓共管。对经整治仍达不到要求的各类场所，原发证主管部门应依法撤销或注销相应行政许可或证照。

　 （四）加大督查，狠抓落实。各单位要采取跟踪督办、分片包干等形式，加强督导检查和帮扶指导，及时总结推广典型经验做法，因监管不力、把关不严，导致发生重特大火灾事故的，进行责任追查，依法严肃追究有关领导和责任人的责任。市文化广电新闻出版局将适时对各单位工作开展情况进行督察，并将于2011年2月和11月，分两次对各单位工作开展情况进行检查。

各单位工作情况连同《消防安全大排查大整治大宣传大培训大练兵工作情况统计表》（见附件1）请及时报市局办公室，每月21日前报阶段性工作情况，2011年12月、12月9日前报工作总结。市局将定期把工作情况报送市政府办公室。
