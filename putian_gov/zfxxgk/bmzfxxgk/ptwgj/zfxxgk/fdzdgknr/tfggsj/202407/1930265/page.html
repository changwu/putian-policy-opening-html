莆田市文物建筑和历史建筑消防安全隐患大排查大整治工作专班关于开展工作督导检查的通知

发布时间：2024-06-28 17:37
| | |

各县（区）人民政府（管委会），市工作专班有关成员单位：

为进一步落实全省、全市文物建筑和历史建筑消防安全隐患大排查大整治工作视频会议精神，根据《福建省人民政府办公厅关于印发<福建省文物建筑和历史建筑消防安全隐患大排查大整治方案>的通知》（闽政办〔2024〕15号）和《莆田市人民政府办公室关于印发<莆田市文物建筑和历史建筑消防安全隐患大排查大整治实施方案>的通知》（莆政办〔2024〕13号）要求，切实做好文物建筑和历史建筑消防安全隐患排查整治工作，市级工作专班决定成立4个督导组，采取轮换督导检查的方式，每月赴各县区（管委会）开展文物建筑和历史建筑消防安全隐患排查整治工作督导检查，督导检查定于2024年6月14日开始，至10月底大排

查大整治行动结束。现将有关事项通知如下:

一、督导安排

（一）工作时间安排。2024年6月14日至10月底，具体督导时间和行程安排由各督导检查组与各县区（管委会）商定。

（二）检查督导方式。采取全面了解与重点抽查相结合的方式，各督导组对照各县区（管委会）有关工作台账，通过查阅资料、实地核查相结合，对相关县区（管委会）推动文物建筑和历史建筑消防安全隐患排查整治工作落实情况进行督导检查。第一次督导检查第一组负责督导仙游县，第二组负责督导荔城区、城厢区，第三组负责督导涵江区，第四组负责督导秀屿区、湄洲岛和北岸，接下来各督导组轮换开展督导检查工作。

（三）工作任务安排。每组负责抽查不少于1个县区（管委会）,原则上每个县区（管委会）抽查不少于4处文物保护单位(或未定级文物点)和2处历史建筑。

三、检查内容

（一）查阅台账资料。查看各县区（管委会）文物建筑和历史建筑消防安全隐患大排查大整治工作开展情况，重点查看是否结合本地实际细化制定实施方案，是否在政府层面进行动员部署，是否成立大排查大整治工作专班，并实体化运行等。

（二）实地督导检查。每组抽查不少于1个县区，重点检查是否组织全面排查并建立《文物建筑、历史建筑消防安全隐患排查整治问题清单、整改清单、责任清单》。对照《福建省文物建筑消防安全隐患排查表》《福建省历史建筑消防安全隐患排查表》，每个县区（管委会）随机抽查原则上不少于4处文物保护单位或未定级文物点，不少于2处历史建筑，重点检查消防安全责任制和安全管理制度情况，消防设施配备、管理情况，用火、用电及危险品使用管理情况，宗教活动和民间信仰场所焚香烧纸安全管控情况，高风险业态管理情况，电动自行车安全管理情况等。

四、工作要求

（一）各督导组要围绕督导检查重点，深入开展指导检查，及时发现问题、剖析结症，推动各县区（管委会）落实工作责任，完善工作机制。

（二）各督导组要及时督促有关单位立即落实有关问题的整改，及时将督导情况反馈市工作专班汇总通报，切实推动工作、解决问题、提升实效。

（三）请各县区（管委会）协助做好督导组的检查行程、食宿安排，督导检查期间严格遵守廉洁自律相关纪律要求，督导组车辆由各组自行保障。

请各组联络员在督导结束后3个工作日内将督导情况(附件3、4)反馈市工作专班。市文旅局联系人:唐智明，联系方式:13055698730，邮箱:ptswwj@163.com；市住建局联系人邱翱强，联系方式：15200831243，邮箱:ptzjxfzx@163.com。
