莆田市文化广电新闻出版局转发市安办关于切实做好岁末年初及2016年元旦春节期间安全生产工作的通知

发布时间：2015-12-29 08:00
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属各单位，机关各科室：

现将《莆田市人民政府安委会办公室关于切实做好岁末年初及2016年元旦春节期间安全生产工作的通知》（莆安办明电〔2015〕18号）转发给你们，请认真组织实施。2016年元旦春节即将到来，各类生产经营建设活动多，生产任务繁重，人员流动性大、人流、物流、车流剧增，加上冬季气候干燥。各单位要认真分析本单位、本行业安全生产形势，保持清醒认识，牢固树立安全生产“红线”意识和“底线”思维，认真贯彻落实安全生产“党政同责、一岗双责”规定，迅速对本单位安全生产工作作出全面部署并认真组织实施。市文化市场综合执法支队、市文管办和各县区文体广电出版主管部门要结合安全生产大检查、深化“打非治违”专项整治工作、“三合一”场所整治、文化市场、文物安全生产专项整治工作，全面开展对所属企事业单位、公共文化场所、公共娱乐场所、网吧、印刷企业和文物保护单位的火灾隐患排查整治工作，对有重大火灾隐患的单位，要提请当地政府、管委会进行挂牌督办，明确有关单位的整改责任，落实整改措施；对单位自身无能力整改的，要组织协调有关部门解决；对排查出的“三合一”场所要统一登记造册，建立健全基础台账，明确整改时间，落实整改措施，坚决消除场所火灾隐患。

各单位要认真落实带班、值班工作要求，保持信息畅通，全面做好安全生产事故和其他紧急突发事件的信息报送和处置工作，不得以任何理由迟报和瞒报。

 

附件：莆田市人民政府安委会办公室关于切实做好岁末年初及2016年元旦春节期间安全生产工作的通知

                             

 

莆田市文化广电新闻出版局

       2015年12月29日

内部明电

 

发往：见报头                         签批盖章：黄玉明

等级：特提              部委号：莆安办明电〔2015〕18号

 

关于切实做好岁末年初及2016年元旦春节

期间安全生产工作的通知

 

各县（区）人民政府（管委会）安委会，市直各有关单位：

为认真贯彻落实党中央、国务院、省委、省政府和市委、市政府领导重要批示指示精神，切实做好岁末年初及2016年元旦、春节期间安全生产工作，根据《国务院安委会办公室关于切实做好岁末年初及2016年元旦春节期间安全生产工作的通知》（安委明电〔2015〕30号）和《福建省人民政府安委会办公室关于切实做好岁末年初及2016年元旦春节期间安全生产工作的通知》（闽安委明电〔2015〕27号）精神，现就有关事项通知如下：

一、树立红线意识，落实安全生产责任和措施

岁末年初历来是安全生产的关键时期，一些生产经营活动进入旺季，交通运输繁忙，又临近元旦、春节，群众出行和活动增多，人流、物流、车流剧增，加上受冬季极端气候影响，事故易发多发。各级各有关部门和单位要认真分析当前所面临的安全生产形势，保持清醒认识，牢固树立安全生产红线意识和，按照“党政同责、一岗双责、失职追责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，全面落实安全生产责任和管理措施，确保岁末年初和两节期间安全形势平稳。各级党委、政府要进行专题研究部署，加强组织领导和检查落实；各相关部门要各司其职、各负其责、分口把守，消除监管盲区、堵塞管理漏洞；各级领导干部要亲力亲为，深入一线加强督促检查。各类企业要严格落实安全生产主体责任，加强安全管理和隐患排查治理，强化从业人员风险意识和安全教育培训，有效防范各类生产安全事故的发生。

二、强化专项整治，突出重点行业领域安全监管

各级各有关部门和单位要针对岁末年初与节日期间社会活动及气候特点，切实加强重点行业领域安全监管。一要加强节日和春运期间交通运输组织和安全管理，科学调度运力，强化铁路、车站及渡口渡船安全措施，严格执行易燃易爆危险品“三品”查堵制度；加强对交通运输企业和客车（船）、危险化学品运输车（船）等重点车辆船舶，及农村山区等重点路段的安全监管，严厉查处各类交通违法违规行为，及时消除事故隐患；进一步加强恶劣天气下道路通行安全管理、疏导管控和应急保障，防止大规模交通拥堵和群死群伤事故发生。二要加强消防安全检查和管理，深入排查人员密集场所、易燃易爆场所、劳动密集型企业以及高层地下建筑等存在的消防安全隐患，严格整治未经消防设计审核、验收备案擅自投入使用、违规使用聚苯乙烯和聚氨酯泡沫材料装修装饰、消防设施缺失损坏、安全出口疏散通道堵塞锁闭和违规住人等问题，严格对大型群众性活动的审批把关和“跨年夜”等自发性群众活动的安全管控。制定并落实安全措施，严防火灾和拥挤踩踏等群死群伤事故。三要加强对烟花爆竹运输、储存、销售和燃放等各环节的安全监管和旺季安全专项检查，严厉打击无证非法生产、分包转包、非法运输、许可证过期等行为，整治下店上宅、前店后宅、集中连片经营，以及销售超规格或不合格产品等问题。要严格审批大型焰火燃放活动，全面落实安全防范措施。

三、排查治理隐患，开展安全生产大检查“回头看”工作

各级各有关部门和单位要按照市政府安委会关于开展生产大检查“回头看”的部署安排，深入开展以危险化学品和易燃易爆物品为重点的安全专项整治，督促企业全面开展安全隐患排查整治，对本地区本行业领域发现的所有重大隐患和责令停产整顿、关闭取缔切企业逐一复查，对一时不能整改到位的，要确保整改的措施、责任、资金、时限和预案“五到位”；对不能保证安全生产的，要坚决停产整顿；对发现的非法违法行为，要依法依规实施行政处罚，切实有效消除各类安全隐患。              

要加强危险化学品生产、储存、经营、运输、使用和废弃处置各环节的安全检查，特别是加强易燃易爆化学品、合成氨企业和危险工艺环节的隐患排查治理，严防危险化学品丢失、泄漏、污染和爆炸等事故发生。要继续深化施工方案专项治理行动，强化施工现场安全管理，严禁大风等极端天气强行组织施工。要加强寄递物流企业、网点和寄递环节的安全管理，严格对疑似危险品的检查，及时发现、妥善处置各类隐患。要立即组织开展餐饮场所燃气使用安全大检查大整治，加强油气输送管道和供气、供电管线及设备设施安全巡查与维护，强化用气、用电安全管理，加大入户检查和安全宣传力度。其他各行业领域也要结合实际，扎实深入做好隐患排查治理工作。

四、加强应急管理，严防自然灾害引发生产安全事故

各级各部门和单位要进一步健全完善安全生产预测预警和应急协调联动机制，加强对灾害性天气的预报、预警、预防工作，及时发布预警信息。要加强重点领域、重要设施、重点单位以及人员密集场所等应急准备工作的检查，确保应急组织机构、救援队伍、装备物资等应急资源落实到位，提高事故防范和应急处置能力。要加强应急值班值守，严格执行领导干部带班、关键岗位24小时值班制度和事故信息报告制度，发生事故或遇有重要紧急情况，要立即报告并启动预案，及时采取有效措施妥善应对和处置。
