莆田市文化和旅游局关于做好2024年度公共文化场馆错时延时开放工作的通知

发布时间：2024-02-23 15:28
| | |

各县区文体旅游局、湄洲岛旅游文体局、北岸党工委宣传部，市群众艺术馆、图书馆、博物馆：

　　按照省委省政府、市委市政府和省文旅厅工作部署，我市6家公共文化场馆错时延时开放纳入省委省政府、市委市政府2024年度为民办实事工作项目。为扎实有效开展公共文化场馆错时延时开放，把实事办好，让群众满意，现将有关事项通知如下：

　　一、目标任务

　　（一）市群众艺术馆、市图书馆、市博物馆、仙游县博物馆等4家公共文化场馆，2023年已经纳入错时延时开放，2024年继续推进落实。

　　（二）2024年新增荔城区文化馆、秀屿区文化馆等2家公共文化场馆纳入错时延时开放。其他的县区文化馆、图书馆可参照本通知因地制宜推进落实。

　　二、开放要求

　　各场馆在开放时间不少于公共文化服务标准规定时间基础上，以错时开放为主、延时开放为辅，因地制宜，推进错时延时开放。原则上2月底前要按照要求落实到位。

　　（一）落实错时开放。除闭馆维修等特殊情况，各公共文化场馆均应全年向公众开放（预先公示的闭馆日除外），国家法定节假日不应闭馆。要综合考虑季节、节假日等因素，建立错时开放机制，根据群众参与公共文化服务的习惯与特点，调整开放时间。

　　（二）推进延时开放。要对接群众文化需求，大力推进延时开放，对公众需求较大的部分基本服务项目实施夜间开放服务。各场馆周末和重要节假日延时开放时间不少于2小时，其余时段以错时开放为主。

　　（三）提升服务效能。采取线上线下结合方式，积极策划开展形式新颖、内容丰富、百姓喜闻乐见的主题文化活动，吸引更多的群众走进公共文化场馆，提升错时延时开放的社会效益。要适时开展评估，动态调整方案，建立长效机制，使错时延时开放工作富有本馆特色，推动错时延时开放常态化。

　　三、加强保障

　　（一）加强组织领导。各县区（管委会）文旅部门要高度重视，将公共文化场馆错时延时开放工作纳入年度重要工作事项，认真组织实施。要积极主动向属地党委、政府争取经费、人员等方面给予支持，保障好事办好，实事办实；要做到一馆一方案，在人员调配、设施运转、安全保障等方面合理统筹安排，确保工作有序开展。新纳入错时延时开放的场馆要积极主动对接，做好学习借鉴，因地制宜、因时施策，对接群众文化需求。

　　（二）做好宣传推广。要加强宣传，结合各种形式的活动，持续加大宣传力度，提升社会关注度，要依托网站、微信、微博等官方自媒体，对错时延时开放进行专题宣传报道，采取有效措施，提高社会公众的知晓度、参与度和满意度。

　　（三）及时报送信息。各场馆错时延时开放方案（填报附件1）请于2024年2月27日前报送市文旅局，市文旅局将加强跟踪督查指导。项目进展情况实行月报制度，各县区、各单位请于每月1日前将有关落实情况报送市文旅局（填报附件2）。公共图书馆、文化馆相关材料报送市局公共服务科，博物馆相关材料报送市局文物科。
