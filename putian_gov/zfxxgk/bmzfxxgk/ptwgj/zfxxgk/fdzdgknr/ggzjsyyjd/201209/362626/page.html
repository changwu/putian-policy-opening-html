莆田市文化广电新闻出版局关于2008年度至2011年度全省文物博物馆专项经费收支情况的报告

发布时间：2012-09-20 08:00
| | |

省文化厅（文物局）、省财政厅和省审计厅：

    根据省文化厅、省财政厅和省审计厅《关于对2008年度至2011年度全省文物博物馆专项经费收支情况审计检

查的通知》（闽文财[2012]28号）精神，我局成立了全市文物博物馆专项经费审计检查领导小组，召开会议进行

专题动员部署，并对照文件的检查内容进行深入自查自审。现将有关情况报告如下：

    一、使用情况

（一）涉台文物

2008年至2011年中央补助涉台文物保护专项经费分别为230万元、65万元、200万元、85万元，合计580万元。2009年至2011年支出分别为90万元、72.9万元和92万元（2008年无支出），合计254.9万元。至2011年底结余325.1万元。

（二）国家重点文物

2008年至2011年国家重点文物保护补助经费分别为75万元、200万元和180万元，合计380万元。2009年至2011年支出分别为21万元、35.4万元和59.63万元（2008年无支出），合计116.83万元。至2011年底结余368.97万元。

（三）博物馆免费开放

2008年至2011年博物馆免费开放补助经费分别为100万元、50万元和65万元，合计255万元；2009年至2011年支出分别为0.87万元万元、34.29万元和86.31万元（2008年无支出），合计121.47万元。至2011年底余数132.53万元。

二、存在问题

（一）进展不平衡。部分项目建设进度较快，如涉台文物中的蒲坂郑氏宗祠、仙游文庙、莆禧城墙等项目；部分项目由于建设条件没有完全落实，特别是规划、设计、招标、审批等环节周期较长，进展缓慢，如东汾五帝庙、贤良港天后祖祠、林兆恩墓、江氏民居、黄石文庙和无尘塔等工程尚未动工。

（二）经费结存数额较大。由于东汾五帝庙、贤良港天后祖祠、林兆恩墓、江氏民居、黄石文庙和无尘塔等工程尚未动工，无发生经费支出，所以经费结存数额与补助经费相等；平海天后宫、枫亭麟山宫已完成规划编制，并进入招投标程序，经费结存数额较大；市博物馆新馆正在建设，尚未投入使用，所以免费开放支出额度偏小，结存余额也较大。

（三）部分经费未拨付到位。如平海天后宫补助65万元，尚有55万元在平海镇政府；贤良港天后祖祠补助150万元，尚有120万元在北岸管委会；仙游县博物馆仍有15万元的免费开放在仙游县财政局。

三、下一步措施

（一）明确工作职责

要以此次检查为契机，召开专题会议，进一步明确各相关单位工作职责，相互配合、相互支持，形成推进全市涉台文物、国家重点文物保护单位修缮和博物馆免费开放工作顺利推进的强大合力。
    （二）加快工程进度

要加快工作节奏，改进工作方法，强化工作措施，千方百计加快全市涉台文物、国家重点文物保护单位和市博物馆新馆建设进度，切实增强责任感和紧迫感，确保高质量完成省定的目标任务。　　

（三）加强监督检查

要组织专门检查小组，对全市文物博物馆专项经费拨付和收支情况的进行一次综合督查。掌握工程进度，尤其是工程进度滞后的项目，要找出差距，迎头赶上。督促各责任单位严格按照工程进度和资金管理办法及时拨付资金，实行法人责任制、招投标制、工程监理制和合同管理制，确保工程建设资金、工进度、标准、质量全面落实，确保各项工程项目顺利推进。
