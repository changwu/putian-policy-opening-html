关于要求核拨萝苜田保护区之涉台文物顺茂隆大厝维修经费的报告

发布时间：2008-11-13 08:00
| | |

福建省文物局：

涵江区涵西办延宁社区“萝苜田”为一面积约3万平方米的小片区，四周河水环绕，形成“小岛”状，上有以“徐氏顺茂隆大厝”为代表的多座各具特色的民国建筑，是难得的文物资源和旅游资源。2002年萝苜田规划为我市省级历史文化名城的核心保护区。徐氏顺茂隆大厝建于1926年，由面阔九间的前座单层主屋、后座双层主屋及两旁长46米的双层护厝组成，中为大砖埕，占地面积2850平方米，建筑面积2350平方米，布局奇巧，风格独特，用材考究，造型美观，为涵江市区内民国时期规模最大的住宅建筑，当时，有不少居民移居台湾与教育，至今联系不断，今年列入莆田市优秀近现代建筑名录。

我市本着保护历史文化名城和优秀近代建筑的宗旨，重视对顺茂隆的维修和整个萝苜田片区的整治，经预筹须经费305万元。在市财政紧张的情况下，拟核拨30万，自筹25万元，尚缺口250万元。为此，恳请上级部门支持核拨顺茂隆大厝维修及萝苜田整治经费290万元，以便及时组织设计及施工。

当否？请批复。

申报说明

 

 

 

 

 

 “萝苜田”为一面积约3万平方米的小片区，四周河水环绕，形成“小岛”状，上有以“徐氏顺茂隆大厝”为代表的多座各具特色的民国建筑，是难得的文物资源和旅游资源。2002年萝苜田规划为我市省级历史文化名城的核心保护区。徐氏顺茂隆大厝建于1926年，由面阔九间的前座单层主屋、后座双层主屋及两旁长46米的双层护厝组成，中为大砖埕，占地面积2350平方米，建筑面积2850平方米，布局奇巧，风格独特，用材考究，造型美观，为涵江市区内民国时期规模最大的住宅建筑，今年列入莆田市优秀近现代建筑名录。顺茂隆有100多名徐氏亲属为台湾政界、商界名人，为重要的涉台文物，故维修顺茂隆大厝对弘扬中华民族优秀传统文化、促进两岸交流、省级历史文化名城的保护、发展旅游事业有着极其重要的意义。

使用管理机构简介

涵江区文物管理办公室成立于1995年，财政全额拨款的事业单位，现有编制4名，在编人员4人，设主任1名，工作人员3名，年经费9万元。文管办在顺茂隆大厝维修及萝苜田整治中，将严格遵照国家的文物工作方针，做好保护管理工作。
