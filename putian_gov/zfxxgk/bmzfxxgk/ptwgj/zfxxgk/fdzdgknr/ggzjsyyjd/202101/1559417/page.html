莆田市财政局 莆田市文化和旅游局关于下达2020年省级旅游品牌宣传资金的通知

发布时间：2021-01-07 16:35
| | |

各有关县区（管委会）财政局、文化体育和旅游局，北岸党工委宣传部：

根据《福建省财政厅 福建省文化和旅游厅关于下达2020年旅游品牌宣传资金和旅游创优奖励资金的通知》（闽财教指〔2020〕92号）《福建省文化和旅游厅关于做好旅行社激励资金发放工作的通知》文件精神，为推动全域生态旅游建设，扶持旅行社复工复产，促进全市文旅业尽快恢复发展。经市文旅局研究，现下达2020年省级旅游品牌宣传资金    万元（详见附件），用于2020年扶持旅行社常态化疫情防控下恢复经营发展和市场拓展，款列“2070113旅游宣传”科目。

请你县区（管委会）及时将激励资金拨付到各项目单位，并切实加强资金管理和跟踪问效，加强绩效目标管理，做好绩效监控，确保专款专用，提高财政资金使用效益。

总体目标

一是为推动文旅企业复工复产，适时组织“全福游、有全福”主题消费活动，做好“六稳”工作，落实“六保”任务，引导和支持旅行社企业加快转型，创新发展，深度挖掘省内游市场潜力，全力推动常态化疫情防控下复工复产工作。二是根据省政府办公厅文件要求，鼓励全省各县（市、区）文化和旅游部门、24个全域旅游示范创建单位在旅游频道开展文化和旅游品牌形象宣传。三是奖励各地市文旅部门为提振市场，加快行业复苏，促进文旅消费，具有带动作用的重大活动。
