莆田市文化和旅游局2022年法治政府建设年度报告

发布时间：2023-02-24 09:06
| | |
 市委、市政府：

2022年，在市委、市政府的坚强领导下，我局认真贯彻落实《法治政府建设实施纲要（2021—2025年）》，进一步加大法治政府建设力度，紧紧围绕本单位法治政府工作目标任务，深入推进文化市场综合执法改革，积极完善文化市场执法机制，持续开展文化市场专项整治，严厉打击各类违法经营行为，彻查彻办文化市场案件，有力促进全市文化市场和谐稳定。现将有关情况汇报如下：

一、2022年度推进法治政府建设的主要举措和成效

（一）加强责任落实，强化工作合力

坚持早谋划、早部署、早安排，切实履行第一责任人职责，主要领导对法治建设的重要工作亲自部署、重大问题亲自过问、重点环节亲自协调、重要任务亲自督办，将法治建设与业务工作同部署、同推进、同考核。年初召开2022年全市文化市场综合执法工作会议，制定印发《2022年莆田市文化市场综合执法工作要点》、《2022年莆田市文化市场综合执法考评方案》。

1.明确了全年工作思路，即把牢“一条主线”（意识形态和文化市场安全），突出“两个抓手”（执法监管、执法改革），紧盯“三个零”（案件零诉讼、市场零事故、队伍零违纪），实施“四化”工程（市场管理有序化、执法监督规范化、严格执法常态化、执法能力现代化），坚持“五个队”要求（政治立队、从严治队、改革塑队、素质强队、科技兴队）。

2.明确了“三新”目标，即市场监管取得新成效、案件查办实现新提升、队伍建设迈上新台阶。全力以赴抓监管，切实落实“双随机、一公开”工作要求，采取日常检查与专项行动、独立执法与联合行动相结合等方式，熟练运用科技手段，严格保密管理，大力整治文化市场的乱点乱象、违法违规行为;主动出击“查”、发动群众“找”、依靠协作“报”，千方百计拓宽案件来源，提高案件数量和质量；积极开展岗位练兵，定期开展“以案施训”“案卷讲评”等多元化、有针对性、实用性的培训活动，全面提升整体队伍素质。

3.明确了“五聚焦、五抓”重点，即聚焦全域监管，抓实综合执法；聚焦主责主业，抓严案件查办；聚焦提质增效，抓紧队伍锻造；聚焦法治思维，抓牢机制建设；聚焦整体合力，抓好社会宣传。整体思路的确立，为完成全年各项任务奠定了思想基础，激发了奋进合力。

（二）加强市场执法，强化案件查办

1.持续加强事中事后监管。开展文化市场“双随机”抽查，积极开展“扫黄打非”、娱乐场所、演出市场整治等一系列专项行动，全面整治违规经营行为。围绕春节、清明节、“五一”、端午节及党的二十大等节日和重大活动，成立专项检查组，深入开展安全生产大检查，排查整改疫情防控问题、经营安全隐患，保障了假日文旅市场安全稳定。今年以来，全市共出动执法人员3715人次，检查文化经营单位1258家次，累计查处违法案件49件，警告24家次，罚款10.4万元，收缴非法出版物125件，有效遏制了文化市场违法违规行为，确保文化市场平稳、健康运行。开展文化市场安全生产大检查行动，对全市文化经营场所进行全面检查，深查事故隐患、严查违规行为、抓好应急处置。今年以来，在检查中共发现各类安全隐患14处，全部督促落实整改到位，进一步营造起“关爱生命，关注安全”的社会氛围和文化市场安全发展环境。

2.深化综合执法改革工作。我局高度重视文化市场综合行政执法改革工作，今年以来，围绕中央、省、市关于推进综合行政执法改革的有关要求，强化责任，注重沟通，深入协调，细化措施，扎实稳妥推进此项工作。持了解改革和转隶合并的新情况、新动向，本着稳定、有序的原则，审慎推进改革工作。目前，全市涉改文化执法机构人员锁定，将根据改革的新政策，择机适时推动人员转隶。在转隶工作未到位之前，各机构工作职能暂时不变，原机构原人员继续站好岗、履好职，确保不出现任何空档和脱节，做到秩序不乱、工作不断、干劲不减。

3.推进包容审慎监管执法。为激发市场活力，全方位推进高质量发展超越营造良好法治环境，根据《中华人民共和国行政处罚法》《中华人民共和国行政强制法》、国务院《优化营商环境条例》和《福建省行政执法条例》等法律法规，制定莆田市文化和旅游局包容审慎监管执法“四张清单”，以及对照《指导目录》中行政处罚事项，参考其他地市裁量基准经验做法，修订文旅领域行政处罚自由裁量标准。

4.开展“养老诈骗”专项行动。我局积极拓宽线索渠道。为依法严惩文化和旅游市场养老诈骗违法违规行为，确保工作取得实效，及时公布投诉举报渠道，并充分发挥网站、微信等新媒体平台的优势宣传养老诈骗举报渠道，加强文旅市场投诉举报受理工作，对有关涉养老诈骗问题的投诉举报线索尽快核实、查办、反馈，及时回应群众诉求，加大老年游客合法权益的保障力度，努力改善消费环境，自觉维护消费者权益，为老年游客创造“安全、放心、舒适、文明、秩序”的旅游环境。今年以来，我市文旅系统在养老诈骗专项行动中一共出动执法人员564人次，检查旅行社134家次，旅游购物场所7家次，艺术品经营单位21家次，网上巡查网站184个，摸排行政处罚案件5件，摸排信访投诉举报3件，我市文旅系统自行排查线索7条，成案2条。

（三）积极宣传引导，营造法制氛围

1.开展普法活动。利用广播电视、报刊和社区宣传栏等传统宣传阵地，以文化市场法制宣传日、旅游日、世界知识产权日、“全民禁毒宣传月”为主题，积极开展文化市场基层宣传活动，分发普法宣传品3000多份。4月26日，支队参与2022年福建省“绿书签行动”系列宣传活动仪式，通过以案释法、以法明理，让“扫黄打非”相关知识“飞入寻常百姓家”，进一步扩大宣传面和影响力，营造良好社会文化环境。

2.推进“八五”普法。持续推进“八五”普法规划贯彻落实，进一步增强全民法治观念。充分利用新媒体平台，结合“3.15”消费者权益日、“4.23”世界读书日、“5.19”中国旅游日、“6.13”文化遗产日、“6.26”禁毒日、“12.4”国家宪法日、宪法宣传周等各类法治宣传日、宣传周、宣传月，向执法对象、管理对象、服务对象以及社会公众开展普法活动，推动形成崇尚宪法、遵守宪法、维护宪法权威的良好氛围，逐步建立健全分工明确、奖惩结合的责任制和监督激励机制，文化和旅游行业的法制普法工作得到有序推进，学法、守法意识得到提升，法制建设环境得到优化。

3.推进乡村普法。我局制定、印发了《莆田市村综合文化服务中心管护制度》，推进“2131”农村电影放映工程，截至目前，全市共放映农村电影7126场，观影人数达38.6万人次，充分利用845个农村有线广播“村村响”的8730个喇叭、音柱，播放普法宣传相关知识，做好宣传。同时，加强农村文化市场监管。充分发挥村（社区）“扫黄打非”联络点信息员作用，及时收集发现贩卖传播淫秽色情、侵权盗版、封建迷信图书、报刊、音像制品等非法出版物和开设地下印刷厂等情况，联合文化执法、公安、市场监管等部门严厉打击各类非法出版传播活动，净化农村文化环境，巩固基层意识形态和宣传思想阵地。

（四）强化队伍建设，提升执法能力

一是提高干部法治素养能力。深入贯彻落实习近平总书记提出的“领导干部要做尊法学法守法用法的模范”讲话精神,建立健全领导干部学法制度，每年制定年度普法工作计划，下发普法责任清单，并通过集中学习和分散学习相结合的方式，认真学习宣传《中华人民共和国宪法》《民法典》、党内法规等，不断提升领导干部法治思维和依法行政能力，做到法治建设工作与业务工作同部署、同推进、同督促，为法治建设工作纵深发展提供坚实组织保障。

二是加强执法人员业务提升。切实加强文化市场综合执法人员培训教育，利用每周学习例会组织法律法规和执法业务学习，以网络文化、网络出版、营业性演出、旅游等领域为重点，执法人员轮流讲授的方式开展专题业务学习，讲授案件查处与证据收集实务解答、典型案例交流、案卷常见问题分析，组织行政执法综合知识考试，进一步提升执法人员法律知识和执法实务水平。

三是加强党员干部廉政教育。组织执法人员深入学习《中国共产党章程》、中央八项规定精神等党章、党纪、党规和法律法规知识，警示每位执法人员在岗位上要慎思、慎权、慎行，时时居安思危，处处管住自己。狠抓队伍的思想、组织、纪律、作风建设，使执法队伍持续保持公正廉明的良好形象。

二、推进法治政府建设存在的不足

（一）法治建设水平与上级要求仍有差距。推进法治的意识有待进一步提高，普法及依法治理工作有待进一步加强。

（二）依法管理的运行机制还不够完善。文旅改革后，有些工作机制还处于磨合、探索中，少数领域里综合长效监管机制有待完善，综合执法工作需进一步规范和加强。主要是执法机构改革仍未落实到位，执法队伍总体力量偏单薄。

三、2022年工作重点计划

2023年，我们将按照市局全年工作部署，以查办案件为抓手，深化文化市场专项行动和专项整治工作，切实维护文化市场平稳、有序。

（一）推进法治建设工作。围绕市法治政府建设重点工作的要求，全面谋划部署2023年全局法治建设工作，进一步提高依法治理的自觉性，增强领导干部的法治理念，培养全体领导干部的法律意识和法律素质，全面保障法治建设工作深入扎实开展。

（二）立法保障莆仙戏传承发展。为了建设文化强市，促进莆仙戏技艺传承，丰富莆田人民群众精神文化生活，正在制定《莆田市莆仙戏保护条例》，从保护传承对象、资源调查、技艺传承、院团发展、人才培养、普及推广、文化交流、资金保障等多个方面推动莆仙戏保护传承。

（三）加强市场监管执法。持续开展全市文化市场大检查，坚决打击网吧、娱乐、演出、网络文化违规经营行为，加强校园周边文化市场整治。积极开展扫黑除恶、“扫黄打非”“清源”“净网”“护苗”“秋风”“固边”专项整治行动，持续开展养老诈骗摸排行动，加强印刷复制企业“五项制度”检查，查处城乡结合部、农村集贸市场游商地摊，封堵非法出版物。加大“扫黄打非”情况收集，争取发现并取缔一批非法出版物地下仓库、窝点。强化文化市场安全保障工作，持续开展文化市场安全生产督查，积极排查整改隐患，切实维护文化市场安全发展环境。

（四）推进综合执法改革。全力推进文化市场综合执法改革，适时开展区级执法人员人员转隶工作，尽快实现“同城一支队伍”，建设一支政治坚定、行为规范、业务精通、作风过硬的文化市场综合执法队伍，统一行使文化、文物、出版、广播电视、电影、旅游市场行政执法职责，全市基本建成运行高效顺畅、队伍规范统一、手段科学有效、保障切实有力的文化市场综合执法体系。
