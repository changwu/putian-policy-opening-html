关于2009－2010年文化产业专项资金使用情况的报告

发布时间：2011-07-13 08:00
| | |

市委宣传部、市财政局：

根据省委宣传部、省财政厅《关于报送2009-2010年文化产业专项资金使用情况的通知》（闽委宣联〔2011〕28号）文件要求，现将2009－2010年文化产业发展专项资金使用情况报告如下：

一、莆仙戏现代小戏精品工程项目专项资金使用情况

（一）项目介绍

莆田地区拥有一百多个莆仙戏剧团，每年在城乡巡回演出达6万多场，成为莆田地区最为流行的艺术形式之一。

利用莆仙戏常年深入乡村演出、群众喜闻乐见的有利条件，通过精选多个现代文明小戏剧目，打造莆仙戏现代文明小戏精品项目，以专业剧团一团、二团做为示范剧团，不断增强小戏台的辐射带动效应，逐步向民间演出剧团广泛推广，变短期为常年，变几队为百团，变数场为万场，以“剧团受欢迎、群众爱看”的良性循环，推动莆仙戏的繁荣发展，创造良好的经济效益。

（二）资金情况

1、资金到位情况：2009年专项资金到位20万元。

2、资金使用情况：2009-2010年用于剧目编排、聘请演员、剧本征集费用等已支付121960元，还有部分剧本征集费及演员费用在2011年支付。

（三）项目进展情况

1、邀请莆仙戏实力剧作家、剧作者创作剧本，打造精品剧目，剧目包括：《搭渡》（郑怀兴编剧）、《最后一个公章》（姚清水编剧）、《土筛记》（阿水编剧）、《拣金链》（陈国恩编剧）、《留下拐杖》（陈宗棋编剧）等，由剧团以正式或加演的形式进行宣传演出。2009年，《搭渡》成功入选2008—2009年度“国家舞台艺术精品工程年度资助剧目”，实现莆田市在国家级精品剧目评选中零的突破。 

2、整理挑选出包括前几年的现代戏小戏精品剧目二十个，编撰成册，并于2010年印刷出版了《莆仙戏现代文明小戏剧本集》，由此带动和推进莆田市现代小戏的创作和演出。

3、2010年，莆田市组织全市现代小戏会演，共有48台小戏入围参赛。

（四）预期效益及产生的示范带动效果：

1、现代文明小戏加演活动受到中央、文化部、省各级领导的充分肯定，中央政治局委员刘云山、刘延东同志分别作了批示，中央政治局常委李长春同志在视察福建时观看了现代文明小戏的现场演出并给予了充分肯定，其典型经验入选中宣部《宣传思想文化工作百个案例选编》和中央文明办《农村精神文明创建工作百个典型经验评析》，中央电视台《新闻联播》、《新闻直播间》、《焦点访谈》等栏目中专题介绍。福建省的莆仙戏加演现代文明小戏活动现场会于2010年10月在我市举行。2009年，全省文化局长会议在莆田召开，并观看了莆仙戏现代小戏的专场演出，赢得了与会人员的一致好评。

2、继《莆仙戏现代文明小戏剧本集Ⅰ》编撰之后，综治办、纪委、计生委、教育局相继出版《莆仙戏现代文明小戏剧本集》Ⅱ、Ⅲ、Ⅳ，并分别组织各系统的现代小戏专场演出。

3、通过专业剧团精品小戏的带动，目前，莆田市民营剧团的现代小戏加演已成为常态，多数剧团每年现代小戏演出场次不下50场，使广大群众在欣赏寓教于乐、寓情于理的演出中读懂政策、辩明是非、知晓事理，民心更和顺，家庭更和睦，邻里更友爱，社区更和谐，实现了社会效益和经济效益的有机统一。

二、莆田市非物质文化遗产舞台艺术精品工程资金使用情况

    （一）项目介绍

深入挖掘莆田市非物质文化遗产资源，科学利用、有效开发传统艺术宝库，弘扬中国优秀文化，突出地方特色元素，对已经列入市级、省级、国家级的十三个传统艺术表演类非遗项目进行提升打造，力求以整台传统艺术精品演出为传播手段，实现五个目标：一是打造莆田市文化品牌，为海西文化建设和对台、对外文化交流发挥作用；二是有效宣传和保护性开发非物质文化遗产，更好地建立非物质文化遗产传承机制，践行《中华人民共和国非物质文化遗产法》；三是为我国非物质文化遗产的科学保护、合理利用开发先行先试，助推文化产业发展；四是提升农村文化品位，为广大人民群众提供共享文化遗产的平台；五是将现代声光电科技表现手段引入非遗舞台精品演出，并以电视、光盘等各种媒体广泛传播。

（二）资金情况

1、资金到位情况：2011年4月份省财政厅专项经费到位50万元。

2、资金使用情况：本项目严格按照《福建省文化产业发展专项资金管理暂行办法》有关规定，制定资金使用计划、审批制度，资金使用项目主要支付十三个节目的录音、录像、排练、研讨等费用，至2011年6月已支付专项资金3万元。

（三）实施情况

本项目于2010年10月开始正式实施。其实施方案分为四个步骤。（1）2010年10月－2011年3月，对十三个节目进行录音、录像，深入进行传承源流和艺术特征考证。（2）2011年4月-5月组成专家工作委员会，进行审视论证，提出详细可行的打造方案。（3）2011年6月－8月，对选定的十三个节目进行反复排演。（4）2011年9月对整台节目进行三轮彩排，并组织新闻媒体广泛宣传，宣传计划包括在《世界文化遗产》杂志以6个版面的专题推介，《中国文化报》及中央电视台、省市电视台的宣传等。（5）2011年国庆期间，正式推出莆田市非物质文化遗产舞台精品，向观众展演。

目前，本项目按计划安排已进入第三个步骤，基本上完成了十三个项目的提升排练。

（四）预期效益及产生的示范带动作用

本项目经过打造之后，正式搬上舞台，将纳入莆田市文化产业办统一经营管理，以莆仙大剧院舞台定点演出或巡回演出形式产生一定的经济效益和社会效益。计划与台湾、香港、澳门等地区及东南亚各国的莆仙同乡会联系，作为文化交流项目以扩大影响，计划到国内各大城市交流演出，以弘扬莆田地方传统特色文化，促进文化产业和非物质文化遗产的科学保护与合理开发。

三、莆田市电影发行放映公司转企改制专项资金使用情况

（一）项目介绍

按照《关于深化文化体制的若干意见》（中发[2005]14号）、《福建省人民政府办公厅关于印发福建省在文化体制改革试验点中支持文化产业发展和经营性文化事业单位转制为企业的两个实施办法的通知》（闽政办[2008]105号）等文件精神，根据2010年6月市人民政府批复的《莆田市电影经营单位体制改革试点工作方案》，在莆田市文化体制改革领导小组领导下，由莆田市文化广电新闻出版局牵头实施莆田市电影发行放映公司、莆田市人民影剧院两个事业单位转企改制工作。参照福建省全省出版社、福建省广播影视集团等体制改革的做法与经验，按照有关文化体制改革试点单位的相关规定，结合实际，进行电影经营单位体制改革。多层次开发数字电影市场，建立起以电影市场为导向，以政府指导、企业自主经营的电影发行放映新模式。

（二）资金情况

1、资金到位情况：省文化产业发展专项资金，即转企改制专项补助资金50万元于2011年6月到位。

2、资金使用情况：2010年已垫付分流人员工资及部分干部安置就业经费50万元。

（三）项目进展情况

在转企改制过程中，切实保障职工的合法权益。一是与市劳动和社会保障等有关部门协调，根据国家和福建省有关政策规定对社保医保等预留费用进行审核，切实维护干部职工的基本权益。二是与人事等部门协调，做好提前退休人员达到法定退休人员年龄时的核批，以及对转制留下在册干部职工的工资等相关手续进行审批备案，完成转制单位人员分流、社会保障、清产核资、人员就业等工作，确保改制中思想不乱、人心不散、安定稳定。三是筹措资金购置设备、安置部分干部职工就业，提高福利待遇，并做好前期的资产评估、清产核资、人员分流等工作，把安定稳定工作贯穿转企改制全过程。同时进行资源整合，组建了莆田市莆仙大剧院有限公司。

 

 

二○一一年七月十三日
