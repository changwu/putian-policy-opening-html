关于要求拨付精排和编辑出版莆仙戏现代文明小戏节目和优秀剧本辑专项经费的请示

发布时间：2009-07-20 08:00
| | |

省文化厅：

我市近年来开展的莆仙戏加演现代文明小戏活动引起了社会的广泛关注，尤其是受到了中央有关领导同志的充分肯定。中央、省委领导同志的重要批示，给我市文化大发展注入了新的活力和动力，为莆仙戏传播现代文明道德向纵深发展指明了方向。全省文化局长座谈会召开之后，我局结合莆田的实际，认真贯彻会议精神，对加强莆仙戏加演现代文明小戏工作作了专门的研究和提出下一步工作意见。一是在7月底前搜集整理首批莆仙戏现代文明小戏候选优秀剧目20个，聘请省、市专家指导，召开作者改稿会，请原作者进行必要的再修改，争取8月中旬结集付印；二是着手精抓10个莆仙戏现代文明小戏表演剧目，对这10个节目邀请我省著名导演、舞美、灯光、服装设计专家协助进行精加工、拍录像、制光盘（约3个小时）。三是再宣传、再发动，发挥莆田市戏剧创作优势，广征优秀剧作，以专业带业余，完善激励机制，巩固演出成果。

为了做好莆仙戏加演现代文明小戏的各项工作，特要求省厅给予莆仙戏加演现代文明小戏系列活动下拨专项经费77.8万元。

以上请示，妥否？请批复。

 

附件：1、莆仙戏现代文明小戏剧本结集出版预算
