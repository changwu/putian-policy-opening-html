关于请求核拨湄洲妈祖庙维修经费的请示

发布时间：2010-02-24 08:00
| | |

福建省文物局：

全国重点文物保护单位妈祖庙，创建于宋雍熙四年（987年），是分灵世界29个国家和地区5000多座妈祖庙（包括台湾地区1500多座妈祖庙）的祖庙。祖庙古建筑群主要有寝殿、正殿、圣父母祠、梳妆楼、中军殿、观音殿、钟鼓楼等，占地面积55亩，保护范围及建筑控制地带占地面积为650亩，是对台文化交流的重要窗口，每年上岛朝拜妈祖的台胞达十多万人次。

2009年《妈祖信俗》被联合国教科文组织列为世界人类非物质文化遗产代表作名录，妈祖文化成为全人类共同的文化遗产，湄洲岛成为世界妈祖文化中心。由于湄洲岛地处海岛，空气潮湿，妈祖祖庙古建筑群年久失修，毁损严重，急需保护维修。经预算，需投入维修资金1280万元，现经多方筹集资金320万元，尚缺960万元，特请求上级核拨湄洲妈祖祖庙古建筑群维修经费960万元。

以上请示，妥否？请批复。

申报说明

 

 

 

 

 

湄洲妈祖祖庙古建筑群创建于宋雍熙四年（987年），是分灵全世界29个国家和地区5000多座妈祖庙（其中台湾地区1500多座）的祖庙，她的信众广达2亿多人（其中台湾1600多万人，占台总人数75%）。现存建筑有寝殿、正殿、圣父母祠、梳妆楼、观音殿、中军殿、钟鼓楼、牌坊和妈祖山摩崖石刻等。为了保护好这一珍贵的历史文化遗产，对弘扬中华民族优秀传统文化，促进海峡两岸文化交流，发展旅游事业具有重大意义，根据《中华人民共和国文物保护法》和《文物保护工程管理办法》之规定，结合湄洲妈祖祖庙古建筑群的实际情况和专家实地考察的意见，特制定本维修保护方案。

保护单位的说明

 

湄洲妈祖祖庙系全国第六批重点文物保护单位，《妈祖信俗》已列入世界人类非物质文化遗产代表作名录。祖庙创建于宋雍熙四年（987年），初仅“落落数椽”，但“祈祷报赛，殆无虚日”。经历代朝廷褒封敕建和宋代航海商人三宝、明代郑和、清代施琅、姚启圣等人的不断扩修，形成了颇具规模的建筑群，占地面积55亩，建筑控制范围650亩。

湄洲妈祖祖庙：以正殿为中心，东北至朝天阁处，东南至正殿东廊外15米处，西北至梳妆楼外5米，西南至钟鼓楼外5米处。

 

 

 

 

 

使用管理机构简介

 

文物保护管理所于2004年12月成立，有所长、副所长各1名，成员3名，隶属湄洲妈祖祖庙董事会，具体负责实施保护管理工作。

景区管理处于1998年成立，人员10名，是湄洲岛国家级旅游度假区管委会下属正科级事业单位。
