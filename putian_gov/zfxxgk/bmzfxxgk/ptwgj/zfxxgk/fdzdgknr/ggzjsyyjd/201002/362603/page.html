关于要求核拨莆田市元妙观三清殿安全与消防项目专项经费的请示

发布时间：2010-02-24 08:00
| | |

福建省文物局：

莆田市元妙观三清殿系全国重点文物保护单位，其附属建筑物有山门、两廊、东岳殿、五帝庙、西岳殿、五显庙、文昌三代祠、福神殿、玄帝庙大门、照壁、碑园等，占地面积8162平方米。1999年国家文物局拨专款对三清殿、山门及两廊进行了维修；2006年、2007年，国家文物局又先后拨专款对西岳殿等附属文物进行了维修。近年来，我市利用元妙观三清殿建筑群开辟了《妈祖信仰源流展》、《莆田金石展》、《莆田民俗展》、《莆田历史名人展》等陈列展览，大大丰富了莆田人民的文化生活，元妙观三清殿成为莆田市未成年人思想教育开放基地，成为莆田市城市建设与精神文明建设的重要窗口。但是，作为现存的最早的莆田历史建筑之一，作为全国第三批一级风险单位，元妙观三清殿的安全防护和消防防范设施存在着严重的不足，现存的只是简单的传统状态。根据《文物系统博物馆风险等级和安全防护级别的规定》要求，以及安防、消防部门的现场勘察设计，共需安全与消防项目专项经费280万元。这几年，在我市财政十分紧张的情况下，我们自筹80万元，尚缺200万元。恳请视我市财政实际情况，请给予支持解决200万元，以确保元妙观三清殿的安全，并尽快按规定组织实施一级风险达标工程。

以上请示，妥否？请批复。

申报说明

三清殿系建于唐代元妙观建筑群遗存的建筑群之一，是我国江南较早的一座宋初木构建筑，具有极高的历史，艺术，科学价值，周边还有附属建筑东岳殿、照墙、五帝庙、西岳殿、五显庙、文昌三代祠、福神殿、玄帝庙大门、碑园等古建筑。为了保护好这一珍贵的历史文化遗产，对于开展科学研究，发展旅游事业，弘扬中华民族优秀传统文化，进行爱国主义教育都有着极其重要的意义。根据《中华人民共和国文物保护法》和《文物系统博物馆风险等级和安全防护级别的规定》，结合三清殿及附属建筑物目前的实际状况和消防、安防专家实地考察意见，特制定出安全防护和消防防范系统工程，本次申报为安全防护系统和消防防范系统建设工程。
