关于要求核拨省级文物保护单位东汾五帝庙维修经费的请示

发布时间：2009-03-25 08:00
| | |

福建省文物局：

东汾五帝庙始建于唐代，清康熙三十八年重建，为福建省第六批省级文物保护单位。庙藏文物丰富，计有文物65件，其中二级文物1件，三级文物34件，一般文物30件。1992年台湾新竹五帝庙到莆田寻根，同年又组团40多人前来进香朝拜。此后，近十五年来，每年都有台湾桃园、丰源、高雄、台北、嘉义、屏东等地组团前来进香，是莆田市重要的涉台文物。

东汾五帝庙现有库房十分简陋，消防设备、安防设施缺乏。近年来，受强台风影响，屋面受损严重，部分椽檩朽烂，存在诸多不安全隐患，应及早采取有效措施进行保护修缮。经测算，共需经费120万元，地方投入17万元，自筹资金9万元，尚缺口94万元。为此，恳请上级文物部门核拨东汾五帝庙维修经费94万元，以便及时组织设计及施工修缮。

以上请示，当否？请批复。

申报说明

 

 

 

 

 

   

    东汾五帝庙始建于唐代，现在的庙宇建于清康熙三十八年。为福建省第六批省级文物保护单位，庙藏文物丰富，计有文物65件，其中二级文物1件，三级文物34件，一般文物30件。1992年台湾新竹五帝庙派人来莆田寻根，同年组团40多人来庙进香朝拜。此后，台湾桃园、丰源、高雄、台北、嘉义、屏东等地也纷纷组团进香。近十五年来，每年都有台湾五帝庙组团来庙进香。为了保护文化遗产，促进海峡两岸文化交流，进行爱国主义教育具有重要意义。根据《中华人民共和国文物保护法》和《文物保护工程管理办法》之规定，结合东汾五帝庙建筑的实际情况和专家实地考察的意见，特申请上级部门核拨东汾五帝庙的维修经费。
