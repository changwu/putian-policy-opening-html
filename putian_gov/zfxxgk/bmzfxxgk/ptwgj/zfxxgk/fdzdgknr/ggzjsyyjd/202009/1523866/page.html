莆田市财政局 莆田市文化和旅游局关于下达2020年省级文旅发展专项资金（第二批）的通知

发布时间：2020-09-11 16:20
| | |

各有关县区（管委会）财政局、文化体育和旅游局：

根据《福建省财政厅 福建省文化和旅游厅关于下达2020年省级文旅发展专项资金和创优奖励资金的通知》（闽财教指〔2020〕9号）文件精神，持续推进乡村旅游“百镇千村”建设，助力乡村振兴。经市文旅局研究，现下达2020年省级文旅发展专项资金（第二批）   万元（共计80万元，详见附件），款列“2070199-其他文化和旅游支出”科目。请各县区（管委会）文旅部门严格按照有关规定督促项目业主补充相关资金申报材料，审核合格后于10月底前报送市文化和旅游局，并及时将资金拨付至项目单位；要会同当地财政部门切实加强对项目的监督检查和追踪问效，确保资金专款专用，及时将项目建设和资金使用情况反馈至市文化和旅游局、市财政局。

 

附件：1.2020年省级乡村旅游村补助资金安排明细表

2.省级文旅发展专项资金绩效目标表
