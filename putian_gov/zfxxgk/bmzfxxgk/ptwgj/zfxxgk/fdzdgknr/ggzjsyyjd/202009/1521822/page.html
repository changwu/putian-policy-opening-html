莆田市财政局 莆田市文化和旅游局关于下达第44届世界遗产大会项目保障经费的通知

发布时间：2020-09-02 17:55
| | |

市文管办、市博物馆、市三清殿文物保护管理所，各县区（管委会）财政局（计财局）、文化体育和旅游局，湄洲岛旅游和文化体育局，北岸党工委宣传部：

根据市政府《关于研究第44届世界遗产大会“六个一批”莆田项目有关问题的纪要》（〔2020〕49号）精神，经市文旅局研究，现下达第44届世界遗产大会项目保障经费    万元（共计1000万元，详见附件），用于迎接第44届世界遗产大会“六个一批”“一城七线”等相关项目的推进落实支出，主要包括展览展示点、考察点及周边环境整治提升，文物定线落图，市博物馆馆藏文物征集，文物丛书、画册制作，文物记录片、抖音短视频拍摄宣传，文物保护碑制作，木兰溪考古调查，展览展示点、考察点讲解等相关经费支出。款列“2070204-文物保护”科目。

请各县区（管委会）及时将专项资金拨付到各项目单位，并切实加强资金管理和跟踪问效，确保专款专用，提高财政资金使用效益。

 

附件：1.第44届世界遗产大会项目保障经费安排表

2.第44届世界遗产大会项目保障经费绩效目标表
