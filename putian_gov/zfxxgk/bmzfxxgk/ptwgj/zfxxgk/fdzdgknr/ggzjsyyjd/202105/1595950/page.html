莆田市财政局 莆田市文化和旅游局关于下达2021年省级非物质文化遗产保护传承专项资金的通知

发布时间：2021-05-12 09:41
| | |

市文旅局，有关县区财政局、文旅局，湄洲岛旅游文体局，北岸党工委宣传部，市群众艺术馆（非遗中心），市艺术研究所：

根据《福建省财政厅 福建省文化厅关于预下达2021年省级非物质文化遗产保护传承专项资金的通知》（闽财教指〔2021〕19号）文件精神，现下达2021年度省级非物质文化遗产保护传承专项资金     万元（详见附件），款列“2070111文化创作与保护”科目，用于非物质文化遗产系统性保护工作。同时把绩效目标下达至你们。

专项资金的管理和使用要严格执行国家有关法律法规和财务规章制度，并接受财政、审计和文化等相关部门的督查检查。有关县区（管委会）财政局、文旅行政主管部门要按照规定及时将专项资金拨付到各项目单位，合理安排，加强资金监管，确保专款专用，做好绩效跟踪和管理，切实提高资金使用效益。

2.2021年度福建省非物质文化遗产保护传承（地方剧种公益性演出补助）专项资金分配表
