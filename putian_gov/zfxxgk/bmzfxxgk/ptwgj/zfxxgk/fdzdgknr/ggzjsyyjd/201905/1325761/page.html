莆田市文化和旅游局关于做好2019年省级旅游专项资金申报工作的通知

发布时间：2019-04-02 09:41
| | |

各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸工委宣传部、北岸文旅办，机关各科室：

为进一步规范和加强省级旅游专项资金管理，发挥资金的引导和激励作用，根据《福建省文化和旅游厅关于做好2019年省级旅游专项资金申报工作的通知》（闽文旅财〔2019〕6号），现对2019年省级旅游专项资金申报工作有关事项通知如下：

一、旅游产业发展资金

（一）采取项目分配法的申报项目

1．竞争性扶持重大项目，具体办法另行通知；

2．景区提升；

3．自驾车露营地；

4．区域标志性产品项目；

5．旅游集散服务中心；

6．旅游交通标识标牌运维费；

7．乡村旅游提升工程。

（二）采取因素分配法的申报项目

8．旅游厕所；

9．乡村旅游休闲集镇、旅游村；

10．旅游扶贫；

11．红色旅游。

    二、旅游创优奖励资金

12．旅游品牌奖；

13．2018年港澳台青少年研学旅行奖励按照规定在2019年旅游创优奖励资金中予以安排；

14．2018年金牌导游员和金牌讲解员奖励按照规定在2019年旅游创优奖励资金中予以安排；

15．2018年入闽旅游奖励按照规定在2019年旅游创优奖励资金中予以安排。2019年入闽旅游奖励办法另行通知。

三、旅游品牌宣传资金

16．宣传营销奖补，采取因素分配法；

17．市场推介奖补、旅游频道宣传奖补、海外推广中心奖补，奖补方案另行通知。

四、申报对象和标准、申报材料及其他要求按照《福建省文化和旅游厅关于做好2019年省级旅游专项资金申报工作的通知》（闽文旅财〔2019〕6号）要求执行。

五、申报、审批程序

（一）对采取项目分配法的旅游产业发展资金项目，申报、审批程序如下：

1．项目业主申报。项目业主单位向所在县（区、管委会）文化和旅游主管部门提交书面申报材料一式二份。申报材料应按顺序装订成册。所有的申报材料复印件须统一在右上角注明与原件相符并加盖项目业主单位公章。

2．县（区、管委会）初审。县（区、管委会）文化和旅游主管部门初审通过后，以正式发文的形式连同省级旅游专项资金项目申报及审核意见表（附件3，资金项目按轻重缓急程度排序）、项目业主书面申报材料、项目资金绩效评价报告（仅限于前两年曾获得过补助且当年继续申请补助的项目须提供，由县（区、管委会）文化和旅游主管部门盖章），以上材料应按顺序装订成册报送市文旅局项目主管科室审核。

3．地市审核。市文旅局各项目主管科室对县（区、管委会）文化和旅游主管部门报送的项目材料进行审核，审核通过后分别行文上报省文旅厅各项目主管处室。

（二）对采取因素分配法的旅游产业发展资金项目，申报、审批程序如下：

1．项目业主申报。项目业主单位向所在县（区、管委会）文化和旅游主管部门提交书面申报材料一式一份。申报材料应按顺序装订成册。所有的申报材料复印件须统一在右上角注明与原件相符并加盖项目业主单位公章。

2．县（区、管委会）初审。县（区、管委会）文化和旅游主管部门初审通过后，以正式发文的形式连同省级旅游专项资金项目申报及审核意见表（附件3，资金项目按轻重缓急程度排序）、项目业主书面申报材料、项目资金绩效评价报告（仅限于前两年曾获得过补助且当年继续申请补助的项目须提供，由县（区、管委会）文化和旅游主管部门盖章），以上材料应装订成册报送市文旅局项目主管科室审核。

3．地市终审。市文旅局各项目主管科室对县（区、管委会）文化和旅游主管部门报送的项目材料进行审核，后将核定的项目报局办公室汇总按规定对外公示，公示期后会同市财政局联合行文下达资金，并在规定时间内分别报省文旅厅、省财政厅备案。

（三）旅游品牌宣传营销奖补资金，项目申报、审核程序如下：

1．县（区、管委会）申报。各县（区、管委会）文化和旅游主管部门按闽文旅财〔2019〕6号文件第二点第（三）款所列内容向市文化和旅游局提交书面申报材料一式一份。申报材料应按顺序装订成册。所有的申报材料复印件须统一在右上角注明与原件相符并加盖单位公章。

2．地市终审。市文旅局项目主管科室对县（区、管委会）文化和旅游主管部门报送的项目材料进行审核并确定金额后，报局办公室会同市财政局联合行文下达奖补资金，并在规定时间内分别报省文旅厅、省财政厅备案。

六、其他要求

（一）做好申报和审核。各县（区、管委会）文化和旅游主管部门要及时通知所在地的各项目业主单位，指导项目业主单位严格按要求及时申报，做好项目审核工作，提高项目申报和审核质量。申报的项目应做到按实填报，材料完整，同一个项目仅可选择一类项目进行申报资金补助，不得重复申报。全域旅游示范县（区）创建单位仙游县、城厢区至少申报1个旅游产业发展资金项目。

（二）严格按时申报。采取项目分配法的旅游产业发展资金项目，申报截止时间为2019年4月15日；采取因素分配法（除宣传营销奖补资金外）的资金项目，申报截止时间为2019年5月20日；宣传营销奖补资金项目，申报截止时间为2019年10月31日。2019年入闽旅游奖励资金项目（入闽旅游业务发生时间截至2019年12月31日），申报截止时间为2020年1月31日。其他旅游创优奖励资金、旅游品牌宣传资金项目，按省级通知及相关文件规定予以补助，无需申报。

（三）加强项目监管，全面实施绩效管理。各县（区、管委会）文化和旅游主管部门应严格项目监管，加强对项目建设进展情况的督查落实，确保专款专用。省、市文旅、财政部门将对专项资金使用和项目建设情况进行不定期检查，并按要求开展绩效评价；同时，将绩效评价结果作为下一年度资金安排的重要参考，进一步优化省级旅游专项资金的使用和管理。

（四）明确项目负责科室。请各县（区、管委会）文化和旅游主管部门将项目资金申报材料报送市文化和旅游局各项目主管科室：1.产业科负责第1-12项；2.行管科负责第13-15项；3.市场科负责第16-17项；4.办公室负责统一部署及会同市财政局联合发文下达资金。
