莆田市财政局 莆田市文化和旅游局关于调整下达2020年福建省基层综合性文化服务中心建设专项资金（中央公共文化一般项目）（第二批）的通知

发布时间：2020-11-11 08:42
| | |

市文旅局，仙游县、荔城区财政局、文化体育和旅游局，市群众艺术馆：

《莆田市财政局 莆田市文化和旅游局关于下达2020年福建省基层综合性文化服务中心建设专项资金（中央公共文化一般项目）（第二批）的通知》（莆财教〔2020〕87号）文件原下达市文旅局2020年中国农民丰收节文化旅游活动经费211.3万元。现根据福建省文化和旅游厅《关于开展福建省2020年农民文化周活动的通知》《关于福建农民文化周工作的纪要》（〔2020〕8号）和陈惠黔副市长批示精神，对原下达资金进行调整。现将调整后的2020年福建省基层综合性文化服务中心建设专项资金（第二批）    万元下达给你们，款列“2070109-群众文化”科目，具体分配情况详见附件。

请对照专项资金绩效目标表，切实加强资金管理和跟踪问效，确保专款专用，提高财政资金使用效益。

 

附件：1.2020年福建省基层综合性文化服务中心建设专项资金明细表（第二批）   

2.全省基层综合性文化服务中心建设专项资金绩效目标表（2020年度）
