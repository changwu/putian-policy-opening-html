莆田市财政局 莆田市文化和旅游局关于下达2020年旅游厕所资金的通知

发布时间：2020-11-26 11:42
| | |

各县区（管委会）财政局（计财局）、文体和旅游局，湄洲岛旅游文体局，北岸党工委宣传部：

根据《福建省财政厅 福建省文化和旅游厅关于下达2020年旅游厕所资金的通知》（闽财教指〔2020〕75号）文件精神，经市文旅局研究，现下达你县区（管委会）为民办实事旅游厕所资金资金     万元（见附件1），该专项资金用于2020年旅游厕所建设，列“2070199-其他文化和旅游支出”功能科目。市级已通过莆财教〔2019〕222号、莆财教〔2020〕108号分两批下达资金219万元，用于2020年旅游厕所建设，按“新建每座6万元、改扩建每座3万元、4A级以上第三卫生间每座2万元”进行补助。经各县区（管委会）申报及项目推进情况，具体补助名单见附件2。

请严格对照专项资金绩效目标，加强对项目的监督检查和追踪问效，并及时将项目建设、资金使用情况反馈至市文旅局、财政局。

总体目标
