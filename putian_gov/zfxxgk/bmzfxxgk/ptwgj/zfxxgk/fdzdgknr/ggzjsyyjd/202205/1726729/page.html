莆田市文化和旅游局关于印发 “全闽乐购·全福游·最莆惠”2022 莆田文化和旅游消费季实施方案的通知

发布时间：2022-05-20 18:24
| | |
 各县区文旅局，湄洲岛旅游文体局，北岸工委宣传部：

为贯彻落实省委、省政府关于促进消费工作的部署要求，统筹疫情防控和经济社会发展，根据《福建省商务厅、福建省文化和旅游厅关于印发福建省商旅促消费活动工作方案的通知》（闽商务〔2022〕45号）文件精神，现将《“全闽乐购·全福游·最莆惠”2022莆田文化和旅游消费季活动实施方案》印发给你们，请认真组织实施。

 

                      莆田市文化和旅游局

                      2022年5月17日

“全闽乐购·全福游·最莆惠”

2022莆田文化和旅游消费季实施方案

 

为贯彻省委、省政府和省文旅厅工作部署，统筹疫情防控和文旅经济稳增长工作，根据《福建省商务厅、福建省文化和旅游厅关于印发福建省商旅促消费活动工作方案的通知》（闽商务〔2022〕45号）文件精神，着力开展“全闽乐购·全福游·最莆惠”2022莆田文化和旅游消费季活动，具体方案如下。

一、目的意义

坚持公益、普惠、点面结合原则，依托“云闪付”平台，宣传营销“全民乐购·全福游·最莆惠”2022莆田文化和旅游消费季活动，发动全市文旅商家积极参与文旅惠民促消费，让全社会积极参与文旅惠民活动。

二、活动时间：2022年5月至10月

三、组织架构

指导单位：福建省文旅厅、福建省商务厅、莆田市人民政府

主办单位：莆田市文旅局，仙游县人民政府、荔城区人民政府、城厢区人民政府、涵江区人民政府、秀屿区人民政府、湄洲岛国家旅游度假区管委会、北岸经济开发区管委会

支持单位：中国银联福建分公司，湄洲日报、莆田市广播电视台、莆田晚报、莆田侨乡时报、东南网、海峡导报

参与商家：全市A级旅游景区、星级饭店、旅行社、实体书店、电影院、演出场所、娱乐消费场所及“+文旅”品牌等报名参与的文旅商家。

四、活动内容

围绕“全民乐购·全福游·最莆惠”主题，按照“省市县联动、银企平台联合、线上线下融合”方式，举办一场文旅消费季启动仪式、发放一批文旅消费券、推出一系列文旅优惠措施、开展一系列文旅消费营销活动，推动“百万补贴、千家参与、万户受惠”。

（一）举办一场文旅消费季启动仪式。结合2022年“中国旅游日”莆田市分会场活动，举办“全民乐购·全福游·最莆惠”2022莆田文化和旅游消费季启动仪式，发布莆田文旅消费季优惠政策，配套非遗美食体验互动及摄影展、书画展、汉服走秀等。

责任单位：市文旅局，中国银联福建分公司

（二）发放一批文旅消费券。通过银联“云闪付”平台发放400万元文旅消费券，用于支持在A级旅游景区、星级饭店、旅行社、电影院、实体书店、演出场所、娱乐场所、“+文旅”品牌企业等文旅消费。（具体每期次文旅消费券发券方案以“莆田文旅”官方微信公众号和“云闪付”平台发布为准）

责任单位：市文旅局，中国银联福建分公司，各县（区）人民政府（管委会）

（三）推出一系列商家优惠举措。组织全市文旅企业开展惠民促消费活动，引导文旅消费季参与商家，对应本次活动推出一系列商家优惠举措（优惠活动须低于市场最低折扣价），与文旅消费券叠加使用，放大乘数效应。

责任单位：市文旅局，中国银联福建分公司，各县（区）人民政府（管委会）

（四）开展一系列文旅消费营销活动。在统筹做好疫情防控和安全生产工作的前提下，开展“福来福往”湄洲岛-平潭海上游线首航仪式活动、2022年文化和自然遗产日、2022“湄洲之夏”沙滩音乐节等一系列文旅消费营销活动。组织文旅经营性企事业单位举办线上演播、剧场演出、艺术展览、非遗体验、温泉养生等特色活动。

责任单位：市文旅局，中国银联福建分公司，各县（区）人民政府（管委会），湄洲日报、莆田市广播电视台、莆田晚报、莆田侨乡时报、东南网、海峡导报

五、工作保障

（一）加强组织领导。各县区（管委会）文旅部门要高度重视促消费活动的重要性，抓好各项工作落实。要结合本地资源、特色，策划举办带动效应好的相关主题活动，助力做大文旅消费市场；要加强政策宣贯解读，持续动员文旅商家参加活动，并鼓励推出商家自有优惠措施。文旅部门收到商家报名材料（报名表及商家诚信经营承诺书）并提出初步意见后，将商家报名材料及汇总表第一时间报市文旅局资源开发科，电子版发邮箱：pt2696660@163.com。

（二）加强服务保障。为做好落地保障工作，由福建银联莆田业务部组织工作人员到报名企业或商户进行现场确认、活动培训、张贴标识及日常巡检，并协调银行人员前往办理“云闪付”受理。各县区（管委会）文旅部门要联合相关部门加强服务监督，确保活动期间各参与企业或商户服务水平不打折，如发现有降低服务水平、虚假套利、不诚信经营等行为，经审查确认后，报市文旅局取消其参与资格，并进行银行征信不良记录登记和纳入“黑名单”管理。

（三）加强宣传推广。各县区（管委会）文旅部门要运用网站、微信公众号、报纸媒体等形式同步开展活动预热及相关宣传报道工作，并结合519、端午、中秋、国庆等重要活动节点进行重点宣传。由银联配合提供基础版宣传素材设计稿，通过人民银行联动各商业银行网点，进行网点海报、大屏、LED走字等渠道的同步宣传；针对参与活动的商家，统一张贴“文旅消费季”商户受理标识，持续营造轰动效应，激发市民踊跃参与消费活动。

（四）做好安全预防。各县区（管委会）要按照属地疫情防控要求，严格落实相关企业的疫情防控措施，结合实际组织开展促消费活动。指导企业做好线下促消费活动场所的安全工作方案和紧急处置预案，坚决杜绝事故隐患，确保活动安全稳定进行。

1.遵守国家有关法律、法规和政策以及市场监管的有关规定；

2.确认所报送的商户信息准确无误，布放银联受理标识及活动物料，积极向消费者做好活动宣传和引导；

5.若被侦测出恶意套利行为，中国银联有权及时终止并取消本商户参与中国银联所有营销活动的资格，并有权追回被骗取的优惠资金；

6.因本商户提供的服务及产品问题引发的用户投诉、处理和争议等，本商户将协助解决，并妥善安抚用户，依法赔偿持卡人由此造成的相关损失。
