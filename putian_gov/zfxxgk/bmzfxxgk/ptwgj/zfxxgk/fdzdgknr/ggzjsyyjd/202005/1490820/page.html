莆田市财政局 莆田市文化和旅游局关于下达2020年福建省基层综合性文化服务中心建设专项资金（中央公共文化一般项目）（第一批）的通知

发布时间：2020-05-22 17:08
| | |

各县区财政局、文旅局，市图书馆：

根据《福建省财政厅 福建省文化和旅游厅关于提前下达2020年全省基层综合性文化服务中心建设专项资金（中央公共文化一般项目）的通知》（闽财教指〔2019〕141号），为贯彻落实国务院办公厅《关于推进基层综合性文化服务中心建设的指导意见》（国办发〔2015〕74号）和省委办公厅、省政府办公厅《关于加快构建现代公共文化服务体系的实施意见》（闽委办发〔2015〕58号）《中共福建省委实施乡村振兴战略领导小组关于加快实施乡村振兴战略十条措施的通知》（闽委振兴组〔2018〕1号）等文件精神，整合和建设基层综合性文化服务中心，完善提升乡镇（街道）文化站和村（社区）文化活动室的综合服务功能，建设特色版、升级版乡村特色文化服务中心，抓好典型培育，发挥示范引领，推动文旅融合，助力乡村文化振兴。根据省文旅厅确定的奖励补助名单（闽文旅公共〔2020〕4号），下达你县区2020年福建省基层综合性文化服务中心建设专项资金（第一批）    万元，款列“2070109-群众文化”科目，具体分配情况详见附件。

请你县区按规定及时将专项资金拨付到各项目单位，并对照专项资金绩效目标表，切实加强资金管理和跟踪问效，确保专款专用，提高财政资金使用效益。

 

附件：1.2020年福建省基层综合性文化服务中心建设专项资金明细表（第一批）   

2.全省基层综合性文化服务中心建设专项资金绩效目标表（2020年度）

 

莆田市财政局          莆田市文化和旅游局

                                2020年5月12日
