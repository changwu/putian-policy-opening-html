2016年莆田市文化广电新闻出版局部门预算说明

发布时间：2016-02-29 10:15
| | |

 

2016年部门预算经市六届人大五次会议审议通过，按照福建省人民政府办公厅《关于进一步做好部门预算公开工作的通知》（闽政办[2011]214号）及莆田市财政局《关于批复市文广局2016年度部门预算的通知》（莆财教〔2016〕9号）文件精神，现将我单位2016年部门预算说明如下：

一、部门主要职责

根据《中共莆田市委机构编制委员会关于印发莆田市文化广电新闻出版局主要职责、内设机构和人员编制规定的通知》（莆委编[2011]34号），莆田市文化广电新闻出版局主要职责是：

（一）贯彻执行党和国家关于文化、广播影视、新闻出版（版权）工作的方针、政策和法律、法规，起草并组织实施全市文化、广电、新闻出版（版权）工作的相关政策规定。

（二）拟订全市文化、广电、新闻出版事业发展规划并组织实施，深化文化广电新闻出版领域的体制机制改革。

（三）拟订文化产业发展规划，指导协调文化产业发展，推进文化产业对外合作交流。

（四）拟订文物（含水下文物）、非物质文化遗产及代表性传承人保护规划，组织实施文物（含水下文物）、非物质文化遗产保护和优秀地域特色文化的保护、传承工作。

（五）指导、管理全市文化艺术、广播影视和新闻出版事业、产业发展，推动各类门文化艺术、广播影视业和新闻出版业发展，管理全市性重大文化活动和广播影视制品、出版物。

（六）指导、管理电影发行、放映事业和著作权工作（包括计算机软件），打击侵权盗版活动；接受省版权局委托处理或协助处理著作权涉外案件。

（七）负责推动公共文化服务体系建设，规划、引导公共文化创作生产，指导市重点文化设施建设，管理市级公共文化设施；指导基层文化设施建设，推进基本公共文化服务均等发展。

（八）负责音像制品的批发、零售、出租、放映经营单位的审批和管理。

（九）负责全市书报刊发行、电子出版物出版、印刷或复制单位的行政管理；组织对新闻出版单位、出版活动、出版物内容监管和新闻单位记者证核发使用管理。

（十）负责文艺类产品网上传播的前置审核工作，对网吧等上网服务营业场所实行经营许可证管理，对网络游戏服务进行监管。

（十一）监督管理文化市场综合执法工作，依法开展文化（文物）、广电、新闻出版（版权）行业的行政执法工作，指导规范文化市场综合执法工作。

（十二）监督管理出版物市场，承担市“扫黄打非”办公室的工作，组织或参与协调全市出版物市场“扫黄打非”集中行动和大案要案的查处工作。

（十三）监督管理、审查广播电视节目、卫星电视节目接收使用和通过信息网络向公众传播的视听节目以及视频点播业务；管理广播电视系统及其通过闭路电视系统播屈的音像制品；负责通过广播电台、电视台播出的引进境外节目的监管；监督广播电视的安全播出。

（十四）审核、报批全市广播电台、电视台的建立和撤销；审核、报批、管理乡镇广播电视站以及企业、事业单位有线电视站的设立、合并和撒销；负责广播电视知识产权保护的监督和管理。

（十五）组织开展文化、广电影视、新闻出版和著作权对外对台港澳交流与合作的有关工作。

（十六）承办市委、市政府交办的其他事项。

莆田市文化广电新闻出版局包括6个机关行政科室及16个下属单位，其中：列入2016年部门预算编制范围的单位详细情况见下表：

三、部门主要工作任务

2016年是“十三五”规划的开局之年，做好2016年各项工作意义重大。今年我市文化广电新闻出版工作的总体思路是：深入贯彻落实习近平总书记系列重要讲话精神，按照省文化厅、省新闻出版广电局和市委市政府的部署要求，紧紧围绕“五位一体”总体布局和“四个全面”战略布局，围绕树立和贯彻“创新、协调、绿色、开放、共享”五大发展理念，积极培育践行社会主义核心价值观，着力促进全市基本公共文化服务标准化均等化，着力推动文化产业加快发展和文化市场健康繁荣，着力弘扬优秀传统文化，着力推出更多优秀文艺作品，努力实现“十三五”文化改革发展的良好开局。围绕上述任务，重点抓好以下工作：

（一）科学谋划，注重长效，进一步深化文化体制改革。

（二）立足保障，夯实基础，加快构建现代公共文化服务体系。（三）围绕中心，争创精品，大力繁荣发展艺术创作生产。

（四）转变职能，规范管理，推进现代文化市场体系建设。

（五）开拓创新，打响品牌，加快推进文化产业发展。

（六）强化举措，注重传承，提升文化遗产保护利用水平。

（七）落实责任，严守纪律，持续抓好党建、党风廉政建设和反腐败工作。

（八）强化结合，抓好保障，为文化建设提供有力支撑。

四、预算收支总体情况

按照预算管理有关规定，目前部门预算的编制实行综合预算制度，全部收入和支出都反映在预算中。2016年，莆田市文化广电新闻出版局（含下属预算单位）收入预算为7511.91万元，其中：一般公共预算拨款3465.64万元，基金预算拨款4000万元，纳入财政专户管理资金拨款46.27万元。相应安排支出预算7511.91万元，其中：人员支出652.14万元，对个人和家庭补助支出329.24万元，公用支出105.27万元（含财政专户资金拨款支出46.27万元），项目支出6425.26万元。

五、一般公共财政预算拨款支出情况

2016年度一般公共财政预算拨款支出3465.64万元，主要支出项目(按科目分类统计)包括：

（一）行政运行340.51万元。主要用于行政单位在职及离退休人员工资、缴交社会保险、住房公积金及公用经费等基本支出。

（二）一般行政管理事务33万元。主要用于文化干部培训、农村电影放映场次补贴、"2131"电影工程等支出。

（三）群众文化288.58万元。主要用于莆仙戏公益性低票价演出补助、文化激情广场建设、文化下乡、农家书屋出版物更新、全民读书月活动、群众艺术馆群众各项经费支出及开展群众文化活动等支出。

（四）其他文化支出729.56万元，主要用于莆仙大剧院工程建设、贷款贴息、文化产业博览交易会参展及人民影剧院拆迁职工安置等支出。

（五）文化创作与保护97.02万元。主要用于艺术研究所各项经费开支及剧本征集。

（六）博物馆843.43万元，主要用于市博物馆建设、贷款贴息及免费开放、文物征集等支出。

（七）中专教育151.04万元，主要用于市艺校各项教学经费支出。

（八）文物保护323.08万元，主要用于全市非物质文化遗产保护、文物维修保护、莆仙戏传承保护、海丝申遗及第一次全国可移动文物普查等支出。

（九）图书馆332.91万元，主要用于市图书馆免费开放、图书馆自动化运行、购书费等支出。

（十）文化市场管理127.64万元，主要用于市文化市场执法支队各项经费及办案、“扫黄打非”等支出。

（十一）宣传文化发展专项68.54万元，主要用于补助县区农村电影放映场次补贴。

（十二）艺术表演78万元，主要用于开展莆仙戏“周周有戏”公益活动。

（十三）行政事业单位医疗补助52.33万元，主要用于缴交行政事业单位医疗保险。

六、政府性基金预算支出情况

2016年政府性基金支出预算4000万元，其中用于莆仙大剧院建设贷款还本3000万元，莆田市艺术学校新校建设经费1000万元。
