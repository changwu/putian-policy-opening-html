2015年度莆田市文化广电新闻出版局部门决算说明

发布时间：2016-07-29 10:12
| | |

 

     按照《莆田市财政局关于深入推进预决算公开工作的通知》（莆市财预〔2014〕120号）要求以及《莆田市财政局关于批复市文化广电新闻出版局2015年度部门决算的通知》（莆财教〔2016〕113号）的批复，现将我单位2015年度部门决算说明如下：

一、部门主要职责

莆田市文化广电新闻出版局主要职责是：

（一）贯彻执行党和国家关于文化、广播影视、新闻出版（版权）工作的方针、政策和法律、法规，起草并组织实施全市文化、广电、新闻出版（版权）工作的相关政策规定。

（二）拟订全市文化、广电、新闻出版事业发展规划并组织实施，深化文化广电新闻出版领域的体制机制改革。

（三）拟订文化产业发展规划，指导协调文化产业发展，推进文化产业对外合作交流。

（四）拟订文物（含水下文物）、非物质文化遗产及代表性传承人保护规划，组织实施文物（含水下文物）、非物质文化遗产保护和优秀地域特色文化的保护、传承工作。

（五）指导、管理全市文化艺术、广播影视和新闻出版事业、产业发展，推动各类门文化艺术、广播影视业和新闻出版业发展，管理全市性重大文化活动和广播影视制品、出版物。

（六）指导、管理电影发行、放映事业和著作权工作（包括计算机软件），打击侵权盗版活动；接受省版权局委托处理或协助处理著作权涉外案件。

（七）负责推动公共文化服务体系建设，规划、引导公共文化创作生产，指导市重点文化设施建设，管理市级公共文化设施；指导基层文化设施建设，推进基本公共文化服务均等发展。

（八）负责音像制品的批发、零售、出租、放映经营单位的审批和管理。

（九）负责全市书报刊发行、电子出版物出版、印刷或复制单位的行政管理；组织对新闻出版单位、出版活动、出版物内容监管和新闻单位记者证核发使用管理。

（十）负责文艺类产品网上传播的前置审核工作，对网吧等上网服务营业场所实行经营许可证管理，对网络游戏服务进行监管。

（十一）监督管理文化市场综合执法工作，依法开展文化（文物）、广电、新闻出版（版权）行业的行政执法工作，指导规范文化市场综合执法工作。

（十二）监督管理出版物市场，承担市“扫黄打非”办公室的工作，组织或参与协调全市出版物市场“扫黄打非”集中行动和大案要案的查处工作。

（十三）监督管理、审查广播电视节目、卫星电视节目接收使用和通过信息网络向公众传播的视听节目以及视频点播业务；管理广播电视系统及其通过闭路电视系统播屈的音像制品；负责通过广播电台、电视台播出的引进境外节目的监管；监督广播电视的安全播出。

（十四）审核、报批全市广播电台、电视台的建立和撤销；审核、报批、管理乡镇广播电视站以及企业、事业单位有线电视站的设立、合并和撒销；负责广播电视知识产权保护的监督和管理。

（十五）组织开展文化、广电影视、新闻出版和著作权对外对台港澳交流与合作的有关工作。

（十六）承办市委、市政府交办的其他事项。

     三、部门主要工作总结

2015年，莆田市文化广电新闻出版局主要任务是深入学习贯彻习近平总书记系列重要讲话精神，全面贯彻市委、市政府和上级部门的工作部署要求，努力践行“三严三实”，奋发有为、敢于担当、攻坚克难。围绕上述任务，重点完成了以下工作：

（一）文化体制改革取得新突破。完成文化系统事业单位分类改革。整合市文管办和市演管处，挂牌成立了“莆田市文物局”。全省率先实行市图书馆、博物馆理事会制度，探索引导社会力量参与公共文化事业建设。行政审批改革扎实推进，落实“先照后证”政策，积极转变职能，放管结合，强化事中事后监管；取消了游艺娱乐场所、互联网上网服务场所总量控制和布局规划的要求，放开审批；编制公布了文化系列2大项8小项行政许可流程图。公共文化服务机制不断创新，通过政府买服务增加编外人员40名，增强公共文化场馆服务能力。鼓励社会资本兴建民办博物馆，2家正式对外开放。改革成果活力持续呈现，市级3家国有文化企业运营管理机制不断完善，取得社会效益和经济效益双丰收。莆仙大剧院有限公司年演出108场次，创收260多万元，是荔城区纳税大户；莆仙戏剧院有限公司年演出300多场次，年创收200多万元；市电影发行放映公司实现公共文化服务职能和市场运行有机结合。

（二）公共文化事业取得新进展。公共文化设施不断完善，市图书馆、博物馆新馆建设进展顺利，县区文化三馆建设陆续启动。通过全国文化馆、文化站评估定级，获评一级馆2个、三级馆2个；一级站3个、二级站8个、三级站12个。新建文化激情广场30个、数字农家书屋100个。文化服务内涵不断提升，实施本土文化进农家书屋工程，增设莆仙文化书柜100个。全市公共图书馆人均图书拥有量0.15本，是2011年0.03本的5倍；公共文化信息资源增加18TB，“掌中莆图”等移动阅读平台不断完善，城乡公共文化数字资源覆盖率不断提高。群众文化活动更加丰富，开展“我的舞台·我的梦”活动，举办了全市十音八乐、广场舞、大合唱等10多场文艺比赛、汇演；实施“文化助梦培训工程”，开设各类艺术培训课程20多门，培训5万多人次；打造“忘不了的乡愁”品牌，开展摄影展、文化迎春、春节去哪儿等系列活动；开展送文化、送戏下乡、“书香莆田”全民阅读、文艺展演、“纪念抗战70周年”图片展等各类公益性文化活动180多场；“文化惠民·周周有戏”演出100多场；“2131”工程放映数字电影1万多场次；莆仙戏演出6万多场次。莆阳书院常年举办国学、莆仙文化等各类讲座，被评为“福建省社区教育品牌”。莆仙大剧院先后承接承办了钢琴演奏会、儿童剧、音乐剧等各类商业性和公益性演出，满足市民的文化需求。

（三）艺术创作生产呈现新亮点。积极开展“中国梦”和社会主义核心价值观主题创作，一批本土文艺精品获得省级以上各项荣誉。歌曲《心永在 梦常在》受到省政府表彰；莆仙小戏《土筛记》获得华东六省一市现代地方小戏大赛银奖；参加福建省第六届艺术节、第六届“武夷奖”中青年演员比赛、第十二届“水仙花”戏剧比赛等赛事共获奖项73个，其中莆仙戏《魂断鳌头》和《海神妈祖》共获福建省第26届戏剧会演奖项18个。莆仙戏《春草闯堂》选段入选中宣部、文化部2016年新年戏曲晚会，党和国家领导人到场观看了演出。湄洲妈祖祭典民俗文艺创作基地、城厢区油画艺术创作基地被授予“福建省特色文艺示范基地”称号。

（四）文化遗产保护取得新成效。成立了我市“海丝”申遗工作领导小组，挖掘整理史料，开展学术研讨，精心筛选申遗文物点，编制申报文本，进一步确立了妈祖作为“海上丝绸之路庇护神”的重要地位。在第十个文化遗产日期间，开展以“保护成果 全民共享”为主题的摄影展、文物征集、鉴宝、非遗精品展等“乡音、乡情、乡愁”系列活动。重点开展以各级文物维修保护工程为主要任务的文物保护工作，争取上级文物保护资金577万元，筹集社会资金650多万元，推进37处县级以上文保单位的维修、安消防工程和3处市保单位迁移保护工作。公布第五批市级文物保护单位19处。11个村列入第一批“福建传统村落”。序时推进第一次全国可移动文物普查工作，共普查全市国有收藏单位8家，文物11845件（套）。注重莆田优秀文化资源的挖掘整理和传承保护工作，公布第五批市级非遗名录项目38项，积极推荐申报第五批省级“非遗”名录项目、国家级代表性传承人。完善非遗传习所建设标准，举办非遗传承人培训班，促进传习所建设与传承保护工作规范化。加强妈祖文化传承保护，提升、打造妈祖“海祭”、元宵尾暝灯祈福等民俗非遗项目。完成莆仙戏《目连戏》上、中两本复排和录制工作，对莆仙戏科介表演、锣鼓经等进行抢救性保护。

（五）对外文化交流取得新拓展。扩大文化“走出去”和“请进来”，妈祖信俗以《实践·传承·保护》为主题参加联合国教科文组织举办的非遗培训活动作专题经验介绍。莆仙戏剧院在台湾10所高校进行莆仙戏交流展示。莆田木雕、仙作家具等非遗精品在中国美术馆展出。中央电视台“心连心”艺术团第三次来莆慰问演出。2个非遗项目参加第一届全国青年运动会开幕式表演。拍摄出品《福建文化记忆·莆仙文化》纪录片之《做岁闹元宵》系列，在腾讯、莆田电视台、莆田网等网站、微信平台进行传播，点击量200多万。

（六）文化产业发展、文化市场管理实现新提升。加快文化产业发展，积极组团参加深圳文博会、厦门文博会等各类展会；成功举办第十届海峡工艺博览会、中国（仙游）红木艺雕精品博览会，成交额7.93亿元。加强院地校企合作，在中央美术学院举办莆田油画、雕塑进修班，在莆田建立中美院创业孵化基地和教学实践基地。新增国家级文化产业示范基地1个、省级2个、市级7个。建立工艺类行业协会版权保护机构，增强版权保护社会合力，新增版权登记900多件。预计2015年全市文化产业增加值占GDP比重达8.2%，持续居全省第一。强化文化市场监管，加大巡查办案力度，立案查处违法案件26件，移送公安部门刑事立案3起，责令停业整顿6家，吊销《网络文化经营许可证》1家，销毁非法出版物10余万片（册），拆除非法卫星地面接收设施11800多套，有力地震慑了违法违规行为。深入开展“清源”、“净网”、“秋风”、“护苗”等“扫黄打非”专项行动，市“扫黄办”荣获全国“扫黄打非”先进集体荣誉称号。持续推进文化市场技术监管与服务平台应用。继续推进网吧转型升级。巩固机关软件正版化成果，分步推进国有企业软件正版化工作。

（七）广播影视发展呈现新变化。加强广播电视安全播出秩序管理，市广播电视台、市广电网络公司认真落实安全播出主体责任，全年广播电视实现安全播出无事故。市广播电视台投入近1100万元升级和改造采编播等硬件设备，推出综艺比拼、美食等多个新节目，广播两套频率正式分开运营，仙游独立频道开播，加快推进壶公山转播台广播电视无线数字化覆盖工程建设。莆田广电网络基础设施建设飞速发展，共架设广电光缆5630.66皮公里，设立光节点3600个，铺设管道300公里，实现乡镇光电缆全联网，双向网升级改造加快推进，现有有线数字电视用户45.80万户，增长6.5%，其中高清用户12.1万户。数字影院快速发展，全市现有数字影院13家，比增85.7%，电影银屏68块，比增106%，可统计票房收入9千多万元，比增43.2%。乡镇（公社）老放映员历史遗留问题得到妥善解决。

（八）文化队伍建设呈现新气象。以打造一支忠诚干净担当的文化干部队伍为目标，继续巩固群众路线教育实践活动成果，深入开展“三严三实”专题教育。严格贯彻执行中央八项规定、《中国共产党廉洁自律准则》和《中国共产党纪律处分条例》，开展重大项目招投标、专项资金使用等专项督查，扎实推进党风廉政与惩防体系建设等工作。组织开展文化协管员、文物、文化执法等各类培训，提升队伍专业素养和能力。积极参与全国文明城市创建活动，深入推进“文明行业”、“文明单位”、“平安单位”创建工作。全系统党的建设、党风廉政、人才工作、机关效能和队伍建设不断加强，全系统干部队伍思想作风、群众意识、行政能力、业务水平进一步提升，整体形象继续向上向好。

五、公共财政拨款支出决算情况

2015年公共财政拨款支出4198.83万元，比2014年决算数减少  889.17万元，下降17.47%，具体情况如下(按项级科目分类统计)：

（一）2011102一般行政管理事务2.00万元，较2014年决算数增加2万元，增长100 %。主要原因是加强派驻纪检机构各项保障，。

（二）2050302中专教育165.31万元，较2014年决算数增加39.24万元，增长31%。主要原因是本年度人员增加、工资调整，相应资金增加。

（三）2070101行政运行342.95万元，较2014年决算数增加55.61万元，增长19.35%。主要原因是本年度人员增加、工资调整，相应资金增加。

六、政府性基金支出决算情况

2015年度政府性基金支出1096.28万元，比2014年决算数增加1029.41万元，增长1539%，具体情况如下(按项级科目分类统计)：

（一）2120802土地开发支出 775万元，较2014年决算数增加775万元，增长100 %。主要原因是2015年市财政从科目安排博物馆建设资金。

（二）2120803城市建设支出309.04万元，较2014年决算数增加309.04万元，增长100%。主要原因是2015年市财政从该科目安排莆仙大剧院建设资金。

（三）2296010用于文化事业的彩票公益金支出12.24万元，较2014年决算数减少4.63万元，下降27.44 %。主要原因是该科目资金使用减少。

七、“三公”经费公共财政拨款支出决算情况

2015年“三公”经费公共财政拨款支出22.55万元，同比下降43.01%。具体情况如下：

（一）因公出国（境）费0万元。

（二）公务用车购置及运行费18.29万元。其中：公务用车购置费0万元，2015年公务用车购置0辆。公务用车运行费18.29万元，主要用于公务用车燃油、维修、保险等方面支出，年末公务用车保有量8辆。与2014年相比，公务用车购置费下降100%，主要是：2015年没有新购公务用车；公务用车运行费下降20.37 %，主要是: 车辆使用次数减少。

（三）公务接待费4.26万元。主要用于接待上级来莆调研检查等方面的接待活动，累计接待29批次、接待总人数215人次。与2014年相比, 公务接待费支出下降35.45%，主要是:接待人数减少。
