莆田市文化广电新闻出版局关于批复市群众艺术馆2015年度部门决算的通知

发布时间：2016-07-26 09:57
| | |

市群众艺术馆：

根据市财政局《关于批复市文化广电新闻出版局2015年度部门决算的通知》（莆财教〔2016〕113号）文件精神，现批复你单位2015年度决算如下：

一、2015年年初结转结余86.98万元，本年收入402.57万元，用事业基金弥补收支差额0.00万元，本年支出461.43万元，结余分配0.00万元，年末结转结余28.11万元。

    (一)一般公共预算财政拨款年初结转结余47.23万元，本年收入381.18万元，本年支出417.94万元，年末公共预算财政拨款结转结余10.48万元。

    (二)政府性基金预算财政拨款年初结转结余8.90万元，本年收入0.00万元，本年支出8.90万元，年末政府性基金预算财政拨款结转结余0.00万元。

二、2015年基本支出83.87万元，项目支出377.56万元，上缴上级支出0.00 万元，经营支出0.00万元，补助下级支出0.00万元。

三、2015年一般公共预算基本支出83.87万元，其中：工资福利支出56.32万元；商品和服务支出3.83万元；对个人和家庭的补助23.73万元；其他资本性支出0.00万元；对企事业单位的补贴 0.00万元；债务利息支出0.00万元；其他支出 0.00万元。

四、2015年“三公”经费一般公共预算财政拨款支出0.26万元，其中：因公出国（境）费 0.00万元；公务用车购置及运行维护费  0.00万元；公务接待费0.26万元。
