莆田市文化广电新闻出版局关于开展2016年度“我们的节日”系列主题活动的通知

发布时间：2016-05-05 08:00
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属各单位，机关各科室：

根据市文明办关于做好“我们的节日”活动有关会议通知精神，为大力弘扬社会主义核心价值观，挖掘莆田地方特色节日文化，有效组织发动群众积极参与“我们的节日”主题实践活动，现就开展2016年度“我们的节日”系列主题活动内容通知如下：

一、指导思想

贯彻落实党的十八届三中、四中、五中全会和习近平总书记在文艺工作座谈会上的重要讲话精神，以弘扬和践行社会主义核心价值观为主线，充分利用公共文化场所，以非遗展示、节日民俗和文化娱乐等文化活动为载体，深入挖掘春节、元宵节、清明节、端午节、中秋节、重阳节的文化内涵，突出人文关怀，着力深化“讲文明、树新风”活动，引导广大群众尊重传统、继承传统、弘扬传统，努力营造和谐文明、团结稳定、家庭幸福的浓厚节日气氛，丰富广大人民群众的精神文化生活。为建设宜业、宜商、宜居莆田创造良好的社会环境。

二、活动内容

（一）春节、元宵节：以“妈祖故里·欢乐春节”文化迎春活动，抓好社会主义核心价值观贯穿融入。

1.公益广告宣传活动。因地制宜，制作、悬挂体现社会主义核心价值观内容的春联、灯笼、横幅等，LED屏幕刊播反映辞旧迎新、欢度佳节、幸福团圆主题的“讲文明树新风”公益广告，营造浓厚节日氛围。

2.开展特色文化活动。开展迎新春、庆元宵联欢会、诗歌朗诵、灯谜竞猜、书画展象棋、围棋比赛、春节元宵习俗资料展、莆仙戏演出、送春联等节庆活动，丰富群众文化生活。

3. 开展网络迎春活动。开展忘不了乡愁·回家过年随手拍活动，发动群众通过手机镜头捕捉、记录、分享回家过年欢乐、幸福的温馨节日场景，在网上凝聚正能量、唱响主旋律。

4.开展志愿服务活动。组织文化志愿者进社区、进农村为空巢家庭、孤寡老人、留守儿童、残疾人、困难户提供服务等形式的帮扶，广泛传递正能量。

（二）清明节：以“纪念先人、缅怀先烈”为主题，引导人

们正确认识我国优良传统，慎终追远，珍惜生活。

1.组织广大党员干部在公共博物馆、烈士纪念馆等爱国教育基地开展敬献鲜花、缅怀英烈活动，重温入党誓词，追忆革命精神。

2.积极引导市民摒弃不文明祭祀习惯，形成文明健康祭祀新风。

3.组织干部群众广泛开展植树护绿、沐春踏青活动，引导人们走进自然、亲近自然、关心生态、保护环境。

4.组织干部职工参与“网上祭英烈”活动，引导人们正确认识和理解中华民族优良传统和革命传统，慎终追远，珍惜幸福生活。

（三）端午节：以“缅怀伟人、爱国情怀”为主题，增强人们的爱国情感。

1.开展节日民俗活动，充分挖掘文化资源，开展民俗展示会、歌舞表演、书法棋艺、美术摄影、插艾叶、赛龙舟、包粽子、“忘不了的乡愁”文化遗产摄影展等活动项目，让市民沐浴温馨端午节。

2.组织全民阅读、专题讲座、文化展览、美术摄影、知识竞赛等活动，引领未成年人诵读中华经典和历代经典爱国主义诗篇，加强干部群众对优秀传统文化思想价值的阐发，在感受节日魅力中增强爱家、爱国、爱节日情感。

3.促进文明养成，继续大力实施文明交通、文明餐桌、文明

旅游、网络文明传播、清洁家园等行动，人人争做文明传播者、践行者，提升城市文明形象。

（四）中秋节：以“团结、团圆”为主题，营造民族团结、国家统一、社会和谐的氛围。

1.开展群众喜爱的庆中秋系列文化活动，以喜迎中秋赏月会、茶话会、非遗展示会、灯谜竞猜、歌舞表演、书法棋艺、美术摄影等群众文化活动，展现社会发展新面貌，节日文化新风采。

2.围绕“感恩、团圆”主题，发挥网络、短信、微博、微信等载体优势，开展网上庆佳节活动，组织干部职工抒写感恩他人、感恩亲情、感恩社会、感恩祖国的中秋签名寄语，表达节日感情。

3.开展走访慰问活动，组织文化志愿者为孤寡老人、残疾人、留守儿童、孝心少年、农民工子女等打扫庭院，净化环境，与他们一同过中秋、庆佳节，共享中华大家庭温暖。

（五）重阳节：以“九九重阳 敬老孝亲”为主题，大力弘扬尊老敬老的传统美德。

1.开展老年才艺展示、文艺汇演、联欢晚会、茶话会、棋牌、书画比赛等有利于老年人身心健康的文体活动，把老有所乐落到实处。引导人们孝老爱亲、家庭和睦的美好生活，大力弘扬尊老敬老的传统美德。

2.开展走访慰问老人、退休职工送温暖活动，切实关心老年人生活，倾听他们的心声，帮助解决他们的实际困难。

3.大力宣传弘扬老当益壮、发挥余热、奉献社会的各类老年典型人物，组织开展先进事迹，把他们请进道德讲堂，讲述感人故事，培育孝德文化，传承现代文明。

在广泛开展传统节日活动的同时，也应重视并认真组织纪念反法西斯战争胜利纪念日、五一节、建党节、建军节、国庆节等现代节日活动，大力弘扬民族和时代精神，切实增强社会责任和历史使命感，进一步激发实现中华民族伟大复兴中国梦的精神动力。

三、工作要求

（一）加强组织领导，细化活动内容

各单位要把深化“我们的节日”主题活动作为推进社会主义核心价值观的重要抓手和全国文明城市、文明单位创建工作的重要载体，同本单位的工作紧密联合起来，认真策划，丰富内容，不断提升活动的文化内涵，确保活动取得成效。

（二）加强宣传推广，弘扬社会正气

各单位要在活动中大力宣传介绍传统节日的相关知识，及时报道开展“我们的节日”主题活动的情况，努力营造浓厚舆论氛围和良好的活动环境。

（三）紧扣活动主题，提升活动水平

要紧扣活动主题，始终把培育和践行社会主义核心价值观这一根本要求贯穿于主题活动全过程，不断创新节庆活动的形式和载体，有针对性地设计项目、开展活动，增强“我们的节日”主题活动的群众性、广泛性和吸引力、感染力，提升活动水平。要积极倡导文明和谐、实用节俭的现代节日理念，在移风易俗中体现人文关怀，在欢乐喜庆中倡导文明新风。

各单位开展“我们的节日”主题活动的工作举措和成效（包括文字材料、图片），请及时报送局办公室，联系人：郑明霞。
