关于组织开展福建省第六届“书香八闽”暨莆田市2012年“书香莆田”全民读书月活动的通知

发布时间：2012-09-25 08:00
| | |

各县区（工委）委宣传部、文明办，文体广电出版局、教育局、总工会、团委、妇联，新华发行集团各分公司，市直有关单位：

    为深入贯彻党的十七届六中全会、省委九届二次和市委六届二次会议精神，推进社会主义核心价值体系建设，进一步弘扬和践行“福建精神”，积极营造迎接党的十八大胜利召开的浓厚氛围，根据省委宣传部、省委文明办、省新闻出版局、省文化厅、省教育厅、省总工会、团省委、省妇联、福建日报报业集团、福建广播影视集团、海峡出版发行集团《关于组织开展福建省第六届“书香八闽”全民读书月活动的通知》的精神，结合我市实际，拟于2012年9月28日至10月28日在全市范围内开展第六届“书香八闽”暨莆田市2012年“书香莆田”全民读书月活动。现将有关事项通知如下：

一、加强领导，建立健全组织机构

全民读书月活动是一项社会性、群众性、公益性活动，要从贯彻落实科学发展观、推进和谐社会建设的高度，充分认识活动的重要意义，切实加强领导，认真组织实施。为加强组织协调工作，市委宣传部、市委文明办、市文化广电新闻出版局、市教育局、市总工会、团市委、市妇联、湄洲日报社、市广播电视台、新华发行集团莆田分公司联合组成“书香莆田”全民读书月活动组委会，办公室设在市文化广电新闻出版局。各县（区）、各部门要相应地成立读书月活动领导小组及办公室，明确分管领导，指定专人负责本地本部门读书月活动的策划、协调、组织工作及其他日常事务，确保读书月活动落到实处，取得实效。

二、创新方式，广泛动员全民参与

各县（区）、各部门要精心策划、科学组织，结合实际、大胆创新，要围绕推进科学发展、跨越发展，加快宜居港城建设这个中心任务，将“书香莆田”全民读书月活动与与农家书屋、职工书屋、社区书屋、未成年人课外阅读实践基地建设相结合，与文明城市创建活动相结合，与学习型社会、学习型组织、书香校园建设相结合，从实际出发，深入机关、企业、社区、乡镇、农村、学校、街道、军营，开展主题鲜明、特色突出、形式多样、富有成效的读书活动，吸引干部群众广泛参与，努力增强读书活动的针对性、实用性和有效性，真正体现全民阅读的特点。要注重实效，注重宣传，营造全民阅读活动的良好氛围。在9月28日第六届“书香八闽”全民读书月活动启动日，莆田市分会场要与省主会场同时举办全民读书月启动仪式。

随着科技水平的提高和新兴传播渠道的不断完善，人们阅读方式已经发生巨大转变，数字阅读正在成为阅读的主要方式之一。要进一步加强数字阅读活动的组织领导和宣传，有关网站要链接“书香八闽”读书网（sxbm.chineseall.cn），充分利用“书香八闽”读书网提供正版数字图书免费在线阅读、在线交流互动的功能，积极开展网络主题阅读和征文活动。

三、广泛宣传，不断扩大社会影响

各新闻媒体要根据全民读书月活动方案，充分利用广播、电视、期刊、报纸、网络、手机短信等媒体形式，开辟专题专栏、刊发播出公益广告，大力宣传全民阅读活动的重要意义，全方位、多角度、深层次报道各地各部门开展读书月活动的情况，推介好经验、好做法，全面展示活动成果，扩大活动的影响力，精心营造良好的舆论氛围，在全社会形成爱读书、善读书、多读书、读好书的文明风尚。

四、上下联动，努力形成文化品牌

“书香莆田”全民读书月活动是全市性的一项活动，各县（区）、各部门要切实做好《莆田市2012年“书香莆田”全民读书月活动实施方案》的落实工作，并结合实际制定本县（区）、本部门的活动方案，丰富“书香莆田”全民读书月活动的内容和形式，齐心协力把“书香莆田”全民读书月活动打造成我市文化建设的品牌。

各县（区）、各部门要及时将读书月活动方案和活动开展的情况报市全民读书月活动组委会办公室。

莆田市文化广电新闻出版局　　　        2012年9月25日印发

莆田市2012年“书香莆田”全民读书月活动实施方案

 

为了深入贯彻党的十七届六中全会、省委九届二次市委和六届二次会议精神，落实新闻出版总署关于深入开展全民阅读活动努力建设“书香中国”的部署要求，积极营造“多读书、读好书”的良好氛围和文明风尚，迎接党的十八大胜利召开，根据上级部署，福建省第六届“书香八闽”暨莆田市2012年“书香莆田”全民读书月全民读书月活动定于2012年9月28日至10月28日在全市范围内开展。活动方案如下：

一、活动宗旨

以中国特色社会主义理论为指导，牢牢把握先进文化的前进方向，以促进经济发展、构建和谐社会为目标，通过全民阅读系列活动，引导全社会多读书、读好书，在全市大兴读书学习之风，大力弘扬科学精神、人文精神、福建精神，推动学习型政党和学习型社会建设，推进社会主义核心价值体系建设，推动社会主义文化大发展大繁荣，提高全民思想政治素质和科学文化素质，为建设“富裕莆田、和谐莆田、文化莆田、生态莆田、幸福莆田”提供精神动力和智力支持。

二、活动主题

倡导全民读书，推动科学发展

 三、活动时间

 2012年9月28日—10月28日

   

四、活动内容

（一）举行第六届“书香八闽” 暨2012年“书香莆田”全民读书月活动启动仪式

时    间： 9月28日上午9:00

活动地点：莆田学院

活动内容：市领导讲话，向全市人民发出“开展全民读书活动，提高市民文明素质”的《倡议书》，组织优秀图书展销，作家签名售书，向公众发布读书公益广告，媒体采访报道，大力营造全民阅读氛围。

责任单位：市委宣传部、市文化广电新闻出版局、市文联、新华发行集团莆田分公司、部分民营书店及相关单位

主办单位：市委宣传部、市文化广电新闻出版局、新华发行集团莆田分公司

（二）“媒体书香”系列活动

1、印发《莆田市2012年全民读书月活动标语》

活动内容：向各县区、市直相关单位印发《莆田市2012年全民读书月活动标语》，要求活动月期间在市、县区政府大楼，大中专院校和中小学，图书馆和出版物经营单位，悬挂活动标语。

活动时间：读书月活动期间

责任单位：市委宣传部、市教育局、市文化广电新闻出版局及相关单位，各县区

主办单位：市委宣传部、市教育局、市文化广电新闻出版局，各县区

2、开展全民读书系列报道

活动内容：在全市主要报刊、电视台、广播电台和相关网站开设专题或专栏，报道读书月活动和读书、用书的好人好事，推荐好书，介绍读书、选书、藏书方法。

活动时间：读书月活动期间

责任单位：市委宣传部，市文化广电新闻出版局

主办单位：湄洲日报、莆田广播电视台、莆田晚报、莆田学院报、莆田新闻网、莆田侨乡时报等

（三）“图书推荐”系列活动

1．优秀图书巡回展销和下乡文艺演出活动

活动内容：组织优秀图书进学校、社区、企业开展展销，组织精干文艺演出队伍，下基层演出。

活动时间：读书月活动期间

主办单位：市文化广电新闻出版局、新华发行集团莆田分公司

2．莆田籍作家签名售书活动

活动内容：邀请部分作家现场签名售书。

活动时间：与读书月启动仪式同时举行，并延续至读书月活动期间

主办单位：市文联、新华发行集团莆田分公司、部分民营书店及相关单位

3．优秀馆藏图书、精品图书阅读推荐活动。

活动内容：在市图书馆、莆田学院图书馆和其它各图书馆，对到馆读者进行读书宣传和针对性的阅读指导，并为读者进行咨询，引导广大群众多读书，读好书，增强读者的图书馆意识。

活动时间：读书月活动期间

责任单位：莆田学院、市图书馆、各县区图书馆    

（四）“快乐共享”系列活动

1．开展“亲子共读”活动    

内容：启动2012年家庭教育宣传实践月活动，开展“亲子共读·快乐共享”读书体会征文比赛，引导家长和孩子亲子共读好书，共享读书快乐，营造良好家庭文化环境。举办2012年家庭教育大型公益巡回讲座，传授科学育儿知识、家教知识。

活动时间：读书月活动期间

主办单位：市妇联、市教育局

2．为留守流动儿童“送阅读”活动

时间：读书月活动期间

内容：发动社会爱心力量，筹集资金建立留守流动儿童爱心书屋30个，组织志愿者为贫困留守流动儿童捐赠“爱心图书”。

活动时间：读书月活动期间

主办单位：市妇联

3．创建“巾帼文化中心户”    

    内容：在全市创建10个“巾帼文化中心户”，引导广大家庭成员读书、用书，养成健康、科学、文明的生活方式。

    实施单位：市妇联

（五）“读书征文”系列活动

1．校园读书征文

征文主题：《 学雷锋做有道德的人》

主办单位：市教育局

2．农村读书征文

征文主题：《希望的田野—我爱农家书屋》

主办单位：市文化广电新闻出版局

3．企业读书征文

征文主题：《我读书，我快乐》

主办单位：市总工会

4．社区读书征文

征文主题：《共创文明社区》

牵头单位：市委文明办

5．妇女读书征文

征文主题：《 喜迎十八大，争创新业绩》

主办单位：市妇联

6．青年读书征文

征文主题：《书香相伴，青春同行》

牵头单位：团市委

（六）“校园读书”系列活动

1．举办“书香校园”建设读书经验交流会

    时间：10月

内容：组织“书香校园”创建活动中表现突出、成果显著的学

校，召开读书经验交流会，就各校开展读书活动、创建“书香校园”的情况进行介绍、分享经验，并广泛探讨交流，促进“书香校园”建设活动的开展。

实施单位：市教育局

2．举办“名家进校园”活动

时间：读书月期间

内容：邀请知名作家深入到中小学校园，开设讲座，与学生互动探讨读书问题，以名家的读书与成长经历启迪师生。

实施单位：市教育局、市文联

3．“学习与成长”专家讲座

邀请有关专家学者，介绍读书经验和体会，帮助读者分析阅读心理，寻找阅读方法，享受阅读快乐，提高阅读品位，吸引更多的人加入到阅读的行列中来。与广大写作爱好者进行面对面交流，提升写作爱好者的写作水平和阅读品味。

活动时间：读书月活动期间

主办单位：莆田学院、湄洲湾职业技术学院、市教育局、市文联

（七）开展“创建学习型组织，争做知识型职工”活动

     内容：围绕建设学习型社会的总体要求，继续深入开展“创建学习型组织，争做知识型职工”活动，引导职工学政治、学科学、学文化、学技术，培育更多不同类型、各具特色的学习型班组和掌握新知识、新技能、新本领的知识型职工，为推动莆田经济跨越发展作贡献。

实施单位：市总工会

（八）第四届“莆仙籍作家艺术家书展”

书展征集对象为所有在莆作家、艺术家和海内外莆仙籍作家、艺术家近年出版的文学、艺术作品集及编著、译著。征集文学、戏剧、美术、书法和摄影等方面的著作，也把理论、科技、医药、经济、志书、党史、妈祖文化、宗教研究等方面的专著列入征集范畴（含内部出版），争取最全面、最完整地呈现文献名邦的文化成就。书展结束后，参展作品将收入“莆仙籍作家艺术家书库”永久收藏。

实施单位：市委宣传部、市文联

（九）开展“书香入军营”活动   

    内容：到基层部队举办图书展销，把优秀出版物推介到军营；组织各类主题读书活动，为基层官兵提供阅读指导服务，丰富军营文化生活，提升部队官兵整体阅读水平。

实施单位：市文化广电新闻出版局、新华发行集团莆田分公司

（十）进一步推进“农家书屋”、“社区书屋”、“职工书屋”、“县乡图书馆”、中小学校“爱心图书室”建设    

    内容：充分利用财政投放资金，积极募集社会爱心捐赠，加大“农家书屋”、“社区书屋”、“职工书屋”“县乡图书馆”、中小学校“爱心图书室”等建设力度，将书屋建好、用好、管好，为广大基层人民群众提供和创造方便、实用、舒适的读书场所和学习条件。

实施单位：市委文明办、市文化广电新闻出版局、市教育局、

市总工会、市妇联

（十一）开展“全民数字阅读活动”

内容：在“书香八闽”读书网（sxbm.chineseall.cn）上，提

供万种正版数字图书免费在线阅读，向部分农家书屋赠送数字图书。

 实施单位：市文化广电新闻出版局、中文在线

（十二）开展“学雷锋弘扬福建精神”主题读书活动

内容：以“书香八闽”读书网（sxbm.chineseall.cn）为平台，以广大青少年学生为重点，把雷锋身上体现出的爱党爱国、助人为乐、敬业奉献、锐意创新、艰苦奋斗的崇高精神，与“爱国爱乡、海纳百川、乐善好施、敢拼会赢”的福建精神紧密结合起来，推动雷锋精神和福建精神化为广大青少年学生的价值认同、精神追求和行为准则。

实施单位：市文化广电新闻出版局、市教育局、中文在线

（十三）手机创新阅读活动

内容：在读书月活动期间，由中国移动通讯集团福建有限公司开发“书香校园”手机阅读平台，免费为不同年龄层的学生及其家长提供为期3个月的“书香校园”手机阅读包，包内有30本适合各阶段学生群体阅读的电子图书，图书每月更替一次。

实施单位：市文化广电新闻出版局、市教育局、移动莆田公司、中文在线

五、几点要求
　　1．高度重视，加强领导。各县（区）、各单位要高度重视，切实加强活动的组织领导.要根据全市部署，结合实际制订活动的详细计划，并结合本地区、本部门特点，组织展览、论坛、讲座、知识竞赛、电影展映、读书心得交流等活动。要把任务明确到人，责任落实到人。
    2．密切配合，齐抓共管。各单位要树立整体观念和全局意识，各负其责，密切配合，齐抓共管，充分调动社会各级组织参与活动的积极性和主动性，采取多种形式，动员广大市民特别是未成年人积极参与到活动中来。
     3．注重总结，不断创新。要认真总结读书月各项活动的做法和经验。要及时收集本地、本单位读书月活动进展情况，活动的图片、文件、简报、信息等资料，上报活动组委会办公室。要积极探索，不断总结，开拓创新，为全民读书月活动的持续开展积累经验、提供支持。

请各县（区）、各单位报送一名联络员，负责读书月活动期间有关工作信息的上传下达。市2012年“书香莆田”全民读书月活动组委会将组织对各县（区）、各单位活动开展情况进行巡回检查督导，活动开展情况将作为评选文明单位的重要条件。
