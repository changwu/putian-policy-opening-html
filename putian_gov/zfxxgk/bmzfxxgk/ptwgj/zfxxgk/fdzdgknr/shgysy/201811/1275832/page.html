莆田市文化广电新闻出版局关于组织征集、编辑乡村文化故事和乡村特色文化资源名录的通知

发布时间：2018-11-15 09:06
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部、局属有关单位：

为深入实施乡村振兴战略，延续乡村历史文脉，讲好乡村文化故事，省厅决定在全省组织开展乡村文化故事和乡村特色文化资源名录征集、编辑工作。现将《福建省文化厅关于组织征集、编辑乡村文化故事和乡村特色文化资源名录的通知》转发你们，请按文件要求抓好贯彻落实。相关工作要求如下：

一、各县区（管委会）文化行政部门组织做好素材征集、编辑等工作。于2018年12月10日前将相关材料报送市局，市局汇总后上报省文化厅。

二、市局将组织局属相关单位做好市级乡村文化故事和乡村特色文化资源名录系列丛书编辑工作。同时，各县区（管委会）要确定若干重点村落，优先组织力量指导征集、编辑，并引导编印乡村文化故事宣传册或折页；要善于借力，充分挖掘、利用其他部门已有的成果，进行整理汇编；要形成系列，各县区（管委会）要对征集的成果进行汇编，形成乡村文化故事和乡村特色文化资源名录系列丛书，要争取于2019年3月底完成编辑工作。         

三、各县区（管委会）文化行政部门要统一思想认识，安排专人负责，确保征集、编辑工作高质高效完成。联系人名单请于11月19日前报送市局，联系人：林益清，联系电话：2689939，邮箱：pt2696660@163.com。

附件2

 

福建省文化厅关于组织征集、编辑乡村文化

故事和乡村特色文化资源名录的通知

 

各设区市文广新局、平潭综合实验区社会事业局，厅机关直属各单位：

为深入实施乡村振兴战略，全面推进乡村文化振兴和乡村文化传习所建设，加快系统抢救、保护、挖掘、合理利用乡村特色历史文化，保存乡村文化基因，延续乡村历史文脉，讲好乡村文化故事，根据《福建省推进乡村文化振兴工作方案》，决定在全省组织开展乡村文化故事和乡村特色文化资源名录征集、编辑工作。现将相关工作事项通知如下。

一、征集、编辑的目的意义

乡村文化故事和乡村特色文化资源是我省优秀传统文化的重要组成部分，具有悠久的历史、深厚的底蕴和丰富的内涵，是表现和承载乡愁的重要载体之一，千百年来在满足乡村人民群众的精神文化需求方面发挥了重要作用。征集、编辑乡村文化故事和乡村特色文化资源名录是贯彻落实《中共中央、国务院关于实施乡村振兴战略的意见》、省委《关于实施乡村振兴战略的实施意见》《关于实施中华优秀传统文化传承发展工程的意见》的必然要求和重要举措，对于进一步宣传弘扬乡村优秀传统文化，增强乡村人民群众的文化认同感和归属感，合理利用乡村特色文化资源，丰富新时代乡村艺术创作素材，让乡村人

民群众留住记忆、记住乡愁，具有积极的历史意义和现实意义。

二、征集、编辑的工作主体

各县（市、区）文化部门是责任主体，负责行政区域内乡村文化故事和乡村特色文化资源名录征集、编辑工作的组织领导；乡镇（街道）综合文化站为实施主体，具体负责本行政区域内乡村文化故事和乡村特色文化资源名录的征集、编辑工作；村级综合性文化服务中心负责所在乡村流传在乡间的故事和散落在乡间的历史文化资源的挖掘、整理、编撰和报送工作。

三、征集、编辑的主要内容

以发掘乡村文化资源、讲述乡村故事为主题，以人、事、物为主要线索，通过对乡村文物古迹、历史人物、历史事件，历史文献、非物质文化遗产等的挖掘和故事记述，让乡村留住村庄历史、教化村民、启迪后人，为实现乡村振兴提供文化支撑。

（一）文物古迹和名胜古迹。包括文物保护单位、古遗址、古碑（石）刻、历史人物墓葬和古宅、古街、古树、古桥、古村落以及名胜古迹等情况。

（二）历史人物。包括已故历史知名人士及在我省工作、生活过的知名人士或与我省有姻亲关系的知名人士。

（三）历史事件。包括政治、军事、经济、文化、社会等方面发生的历史事件，以及乡村建设中出现的新人新事。

（四）历史文献。包括重要典籍和地方文献，如方志、家（族）谱、报纸期刊、文集专著、碑帖铭文、善本书等。

（五）非物质文化遗产。包括民间文学、传统美术、传统音乐、传统舞蹈、曲艺、传统体育、游艺与杂技、传统戏剧、传统手工技艺、民俗、传统医药、民间信仰、老字号和地名掌故、神话故事、民间传说以及地方土特物产等。

四、征集、编辑的基本原则

（一）彰显地方性。征集、编辑的乡村文化故事和特色文化资源充分反映地方特点，体现地方特有的文化、历史、地理、社会和其他现实情况，反映区域文化、风俗人情。

（二）体现准确性。尊重故事和文化资源的历史和原貌，真实、客观、完整地记录记述，确保内容客观真实可靠。

（三）突出可读性。以记叙为主，主旨要鲜明，思想要健康，体现社会主义核心价值观，具有文学性、趣味性、故事性。

（四）尊重原创性。口述整理的要注明口述者和整理者；改编的要注明出处。

五、征集、编辑的具体要求

（一）高度重视。征集、编辑乡村文化故事和特色文化资源名录是乡村文化振兴的重要内容，是贯彻落实省委省政府“留旧”“留文”“留魂”等“五个留”要求的基础性工作。各地要高度重视，把此项工作纳入文化工作重要日程，列入乡村文化振兴重大工程，认真抓好落实。

（二）明确责任。各设区市文化部门要加强指导督查，推动各县（市、区）文化部门统一思想认识，明确任务书、时间表，安排专人负责，确保征集、编辑工作高质高效完成。各县（市、区）文化部门要积极主动向当地党委政府汇报，争取党委政府的支持；要成立专门工作专项小组，明确具体负责人员，领导协调征集、编辑工作；要充分发动社会热心人士主动参与，

形成工作合力。

（三）分类推进。要突出重点，每个县（市、区）确定若干重点村落，优先组织力量指导征集、编辑，并引导编印乡村文化故事宣传册或折页；要善于借力，充分挖掘、利用其他部门已有的成果，进行整理汇编；要形成系列，每个县（市、区）要对征集的成果进行汇编，形成乡村文化故事和乡村特色文化资源名录系列丛书。

（四）按时完成。每个县（市、区）在今年12月15日之前将征集到的素材报送各设区市文广新局社文科（处），设区市文广新局社文科（处）汇总后报送社文非遗处（邮箱：418208502@qq.com），省厅将从中遴选特色鲜明、文化底蕴深厚的乡村文化故事和乡村特色文化资源，编辑出版福建省乡村文化故事和乡村特色文化资源系列丛书。到明年3月底，各设区市文广新局、各县（市、区）文化部门要完成编辑各自的乡村文化故事汇编和乡村特色文化资源名录。

 

 

                                福建省文化厅

                              2018年10月19日
