莆田市文化广电新闻出版局关于组织开展“文化进基层百村行”活动的通知

发布时间：2015-07-29 08:00
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部，局属有关单位：

根据《中共莆田市委宣传部关于印发<莆田市“六进基层百村行”活动实施方案>的通知》（莆委宣〔2015〕43号）精神，为进一步做好文化进基层工作，丰富农村群众精神文化需求，促进城乡一体化，完善我市公共文化服务体系，提升农村基层文化服务水平。现将有关事项通知如下：

一、 活动时间

2015年7月—2016年12月

二、活动地点

根据市委宣传部统一安排，由各县区推荐，全市共100个村，第一批40个，第二、三批各30个。

三、 指导思想

以习近平总书记系列重要讲话特别是关于文化工作重要讲话精神为指导，紧紧围绕培养践行社会主义核心价值观，弘扬先进文化，在全市农村开展“文化产品进百村、惠民工程进百村”活动，健全农村文化设施，进一步推进农村文化建设，不断提高农民文化素质，促进实现农村基本公共文化服务标准化、均等化。

四、 活动内容

1. 建立完善农村文化设施网络建设，分批逐步在100个重点村建设完善村文化活动中心。同时配备文化激情广场、莆仙戏台、阅报栏和宣传栏等。

牵头单位：社文科

责任单位：各县区（管委会）文体局，市群众艺术馆

2. 全面实施文化惠民工程，落实百村广播电视村村通维护工程、文化信息资源共享工程、农村公益电影放映工程和农家书屋等重点文化项目。

牵头单位：办公室

责任单位：广电科、社文科、出版科

3.整合系统文艺资源，结合元旦春节、五一、国庆等节假日和文化下乡活动，组织开展莆仙戏、文艺演出、艺术扶贫进农村活动。举办全市激情广场舞合唱及十音八乐等系列群众文艺赛事。

牵头单位：社文科

责任单位：各县区（管委会）文体局，市群众艺术馆、莆仙戏剧院

4. 落实历史文化名村的保护规划，对古村内古建筑的古朴外观和内部的设施进行适当修葺和改装。加大对古民居的维修和安、消防建设工程力度，对22处古民居进行维修。

牵头单位：市文管办

责任单位：各县区（管委会）文体局

5. 加强农村非遗保护工作。组织申报第四批市级非遗项目名录。组织对我市非遗项目普查，开展对农村濒危非遗项目抢救性保护工作。

牵头单位：社文科

责任单位：市非遗保护中心，各县区（管委会）文体局

6. 在农村基层举办文化协管员和文艺骨干培训班，培养农村文化人才和文艺队伍，建立一批基层文化活动基地，实现结对子，种文化。

牵头单位：社文科

责任单位：市群众艺术馆，各县区（管委会）文体局

五、工作要求

1. 思想高度重视。此次“文化进基层百村行”是我市“六进基层百村行”活动的组成部分，也是我局推动文化进农村基层、提升公共文化服务水平重要举措。此次活动考评结果将作为绩效管理指标内容在全市范围内通报。

2. 加强组织领导。各县区、有关部门要认真组织、周密部署，明确具体的分管领导、责任单位和联系人。同时对每个活动要制定详细的工作方案，确保活动落实到位。

3. 注重沟通联系。由于此次“六进基层百村行”活动是由市委宣传部牵头组织的，各县区（管委会）文体局在活动中要加强与辖区宣传部的联系，争取支持。同时要积极配合市局活动，共同协作完成各项工作。

4. 及时总结经验。在活动中要善于发现亮点、及时总结在活动中大胆创新、先行先试的好经验、好做法。各县区（管委会）文体局、市直有关单位每季度要将活动进展情况总结上报市局。邮箱：pt2696660@163.com
