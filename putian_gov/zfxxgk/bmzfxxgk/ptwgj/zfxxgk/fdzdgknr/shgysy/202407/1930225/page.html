莆田市文化和旅游局关于做好“艺见乡韵·乡品乡创”莆田市民间美术暨乡村文创展相关工作的通知

发布时间：2024-06-14 16:44
| | |

各县区文体和旅游局、湄洲岛旅游和文体局、北岸党工委宣传部：

为深入学习贯彻习近平文化思想，着力推进中华优秀文化创造性转化、创新性发展，深化拓展“三争”行动，进一步做好我市文化保护、传承、传播、发展“四篇文章”，助力推进文旅深度融合发展和乡村振兴，深入学习“千万工程”经验，认真落实全省乡村振兴现场会的部署要求，拟于2024年6月中旬全市举办“艺见乡韵·乡品乡创”莆田市民间美术暨乡村文创展。现将相关工作通知如下：

一、活动主题

“艺见乡韵·乡品乡创”莆田市民间美术暨乡村文创展

二、时间地点

时间：2024年6月中旬

地点：市数字中心一楼大厅

三、展览内容

(一)全市民间美术及乡村文创展示。由各县区文旅行政部门筛选来自福建各地具有乡土气息、充分体现地域特色，民间美术作品及理念与制作工艺新颖独特的乡村文创产品30件左右。集中展现莆田悠久生动的民间艺术所具有的独特魅力及其传承与创新的优秀成果。讲好乡村振兴生动故事。任何剽窃、侵犯他人创意和版权的产品均不得参展。

(二)非遗工艺伴手礼展示区。由市群众艺术馆精选一批设计精美、结构精巧、具有艺术性、趣味性、代表性的非遗工艺伴手礼，凸显创新理念与市场结合，以此呈现莆田非遗的独特魅力和深厚历史文化底蕴所焕发出的新生命力。

四、工作要求

(一)高度重视。“艺见乡韵·乡品乡创”莆田市民间美术暨乡村文创展是全市深入学习“千万工程”经验推进乡村全面振兴现场会的重要组成部分，各单位要高度重视，充分展现近年来文化赋能乡村振兴的实践成果和风采。

(二)精心组织。各单位要围绕乡村振兴主题精选展品，制定参展方案，落实各项工作，展示特色亮点。市群众艺术馆负责做好展览统筹、策划、布置等工作；各县区文旅行政部门负责各自展位的展品挑选、运输、布置等，并在活动过程中对各自展位上的展品进行解说推介和现场互动。

(三)名单报送。请于6月13日前，各县区文旅行政部门将经办人名单发至莆田市群众艺术馆，邮箱：ptsysg2@163.com，联系人：朱晋，联系电话：13957182581。
