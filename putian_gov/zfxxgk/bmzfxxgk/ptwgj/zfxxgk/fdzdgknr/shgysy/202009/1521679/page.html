莆田市文化和旅游局关于提高2020年入莆旅游奖励标准的通知

发布时间：2020-08-26 11:04
| | |

　　各县区文化体育和旅游局，湄洲岛旅游文体局，北岸党工委宣传部：

　　为进一步做好“六稳”“六保”工作，加大对旅行社组织入莆过夜旅游奖励力度，加快促进我市旅游市场复苏，助力旅游行业纾困解难，现就提高2020年入莆旅游奖励标准有关事项通知如下：

　　一、范围标准

　　（一）单团过夜旅游。对单团10人及以上的入莆过夜游团队，每团给予100元奖励；单团20人及以上的，每团给予500元奖励；单团50人及以上的，每团给予1000元奖励；单团150人及以上的，每团给予3000元奖励。本奖项单家旅行社最高不超过10万元。

　　（二）旅游专列或汽车团旅游。对旅行社组织省外旅游专列或汽车团300人及以上入莆过夜的给予5000元奖励，入住两晚的给予1万元奖励；500人及以上的给予1万元奖励，入住两晚的给予2万元奖励；专列团和汽车团必须同日出发、同行程、同目的地。本奖项单家旅行社最高不超过10万元。

　　（三）年度过夜旅游。对年组织接待入莆过夜游客累计3000人次及以上的，每人次奖励15元；累计5000人次及以上的，每人次奖励20元；累计10000人次及以上的，每人次奖励25元。本奖项单家旅行社最高不超过50万元。

　　年度累计组团人数前三名的旅行社分别给予3万元、2万元和1万元的奖励。以上三项人数不能重复累计、奖励不能重复享受。

　　二、申报要求

　　（一）入莆过夜游奖励累计时间为自然年，即2020年1月1日至12月31日。申报截止时间为2021年6月30日。

　　（二）入莆专列停靠站点为莆田、仙游、涵江动车站，入莆过夜游必须通过莆田市旅行社组织接待，游客至少游览莆田1个购票4A级景区（点），入住莆田市酒店（不含民宿）1夜及以上。

　　（三）2020年度入莆旅游奖励全部以各旅行社上传到全国旅游监管服务平台的入莆团队名单为准，请各县区（管委会）文旅部门督促旅行社在出团前及时将名单录入监管平台，后期补录的取消奖励资格。

　　三、材料要求

　　（一）旅行社申报材料

　　1.专项资金申请报告（包括团数、人数、奖励额等）；

　　2.电子派团单；

　　3.组团社接待确认件；

　　4.订房信息表、酒店住宿清单（包括备注团号、人间数）及住宿发票；

　　5.团队门票购买凭证；

　　6.汽车团租车协议、包车确认件及发票；

　　7.统一社会信用代码证及法人代表身份证复印件。

　　（二）县区（管委会）文旅部门申报材料

　　1.正式文件（包括审核的团数、人数、奖励额等）；

　　2.《莆田市旅游专项资金申请报告书》（附件1）；

　　3.《2020年市级旅游专项资金绩效目标申报表》（附件2）；

　　4.《2020年莆田市 xx旅行社入莆过夜旅游奖申报汇总表》（附件3）；

　　以上两项材料一式两份，逾期申报不予受理。

　　四、审批程序

　　（一）旅行社申报材料复印件须在右上角注明与原件相符并加盖旅行社公章，资金结算票据须同时提供原件核验；发票实行一团一票，人数以电子派团单为准；团队申报资料须按时间顺序装订成册。

　　（二）市文旅局组织对申报材料和数据进行复核，复核数据误差率超过5%的予以通报并抄送属地效能办。对报送的纸质材料（如：住宿发票、电子派团单、组团社确认件、团队名单、景区购票凭证、包车确认件等）弄虚作假的旅行社实行“一票否决”，取消奖励资格，并列入“黑名单”管理。本通知下发之前旅行社组织的团队无需提供团队门票购买凭证、汽车团租车协议、包车确认件及发票。

　　（三）以上入莆旅游奖励范围、标准及申报材料与《关于2020年入莆旅游奖有关事项的通知》（莆文旅〔2020〕31号）、《莆田市文化和旅游局关于做好2020年市级旅游专项资金申报工作的通知》（莆文旅〔2020〕166号）不一致的，以本通知为准。
