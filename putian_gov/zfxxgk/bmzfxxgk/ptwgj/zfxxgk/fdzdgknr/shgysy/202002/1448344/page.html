莆田市文化和旅游局关于做好全省基层综合性文化服务中心省级优秀示范点推选工作的通知

发布时间：2020-02-19 09:40
| | |

各县区文化体育和旅游局，北岸工委宣传部、北岸文旅办：

为进一步发挥基层综合性文化服务中心在乡村文化振兴和文旅融合中的重要作用，省文旅厅在全省开展基层综合性文化服务中心省级优秀示范点推选工作，现将《福建省文化和旅游厅关于在全省推选基层综合性文化服务中心省级优秀示范点的通知》转发你们，请按照文件要求，抓好贯彻落实。

一、要认真组织推选。各县区（管委会）要精心组织，严格对照推选标准，高标准完成推选任务。从2018、2019年省文旅厅确定的基层综合性文化服务中心省级示范点中推选产生，要重点以村综合文化服务中心为主。要坚持标准，广泛调查研究，严格审核把关，做到好中选优。

二、要做好材料报送。各县区（管委会）择优推选一个示范点，要认真填报《基层综合性文化服务中心省级优秀示范点汇总表》《   综合性文化服务中心省级优秀示范点推荐表》《   综合性文化服务中心概况》，于2月28日前将材料电子版、纸质盖章版报送市文旅局公共服务科。市文旅局将结合日常调研了解的情况，对各地推荐的名单和材料综合分析评选，研究确定4个名单推荐报送省文旅厅。联系人：苏美婷，联系电话：2696660，邮箱：pt2696660@163.com。

三、要注重工作实效。要把推选过程作为加强本辖区构建现代公共文化服务体系的过程，作为激励先进、鞭策后进，推动各项工作的过程。要创造积累新的经验、新的做法，广泛宣传，以点带面，引导更多的示范点进入到优秀行列，营造良好氛围。省文旅厅、市文旅局将适时组织对各县区（管委会）推荐的省级优秀示范点进行实地督查，确保推选工作取得实实在在的效果。

福建省文化和旅游厅关于在全省推选基层综合性

文化服务中心省级优秀示范点的通知

 

各设区市文旅局，平潭综合实验区旅游文体局 ：

今年是全面建成小康社会的决胜之年，是“十三五”收官之年，也是我省贯彻落实《中共中央办公厅、国务院办公厅印发<关于加快构建现代公共文化服务体系的实施意见>的通知》（中办发〔2015〕2号）和《国务院办公厅关于推进基层综合性文化服务中心建设的指导意见》（国办发〔2015〕74号）确立五年目标任务的最后一年。为进一步发挥全省基层综合性文化服务中心在乡村文化振兴和文旅融合中的重要作用，经研究，决定在全省开展基层综合性文化服务中心省级优秀示范点推选工作。现将有关事项通知如下：

一、目的意义

近年来，在省委省政府的领导下，全省各级文旅系统坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大精神和乡村振兴战略，积极推进基层综合性文化服务中心建设，基层公共文化资源得到有效整合和统筹利用，基层综合性文化服务中心服务效能明显提高。在此背景下，推选基层综合性文化服务中心省级优秀示范点，展示宣传新时代我省基层综合性文化服务中心建设成果，对于进一步促进乡村文化振兴，进一步对接群众文化需求，提高服务效能，进一步促进文旅深度融合发展具有积极意义。

三、推选范围

厦门市根据实际工作情况，确定推选范围。其他的设区市、平潭综合实验区，在2018、2019年我厅确定的380个基层综合性文化服务中心省级示范点中产生，重点以村综合文化服务中心为主。

四、推选标准

推选的示范点在《福建省村（社区）综合性文化服务中心建设服务基本标准》基础上，重点考虑以下3个方面条件：

（一）领导重视。把基层综合性文化服务中心建设作为文旅工作的重要内容，列入重要工作议程；日常维护管理、活动开展等有经费保障；有懂文化、会管理、热心文化事业的专职文化协管员。

（二）管理规范。认真落实意识形态责任制，有比较健全的工作目标责任制、岗位责任制、安全责任制、绩效评价制等规章制度。场所标识明显，整洁美观。功能活动室、活动设备配置齐全，展览展示、民俗活动、图书阅读、文体活动等常态化组织开展，群众满意率高。

（三）效能突出。功能发挥比较好，成效比较显著，有特色文化活动品牌；纳入县级文化馆图书馆总分馆制建设；主动作为，积极承担乡村文化振兴各项具体工作，发动社会力量参与建设和运营管理；积极推动文旅融合，福建省乡村旅游特色村所在的示范点优先考虑。

五、推选程序

以各设区市、平潭综合实验区为推荐单位，采取自下而上、上下结合的方式开展推荐工作。具体推荐办法如下：

（一）提出推荐名单。推荐名额按照N+1的数量，即名额分配数+1个名额数量总和进行推荐。推荐的名额经公示后，于3月20日前将《汇总表》《推荐表》及《概况》（详见附件1、2、3）连同电子版一并报省文旅厅。

（二）研究确定。省文旅厅结合日常调研了解的情况，对各地推荐的名单和材料综合分析评选，研究确定名单。

（三）命名授牌。对入选单位统一授牌，并对除厦门市外的入选单位给予一次性补助30万元，用于统一开展宣传推介活动和村综合文化服务中心的设备添置、活动开展、（旅游服务）功能拓展、效能提升。

六、工作要求

1.高度重视，精心组织。各设区市、平潭综合实验区文旅局要加强组织领导，制定推选工作方案。要广泛宣传发动，精心组织实施，严格按照推选标准和程序，高标准完成推选任务，确保选出导向、选出干劲、选出氛围。

2. 坚持标准，保证质量。要坚持标准，对推选对象进行严格审核把关，做到好中选优。要把推选过程作为加强本地区构建现代公共文化服务体系的过程，作为激励先进、鞭策后进，推动各项工作的过程。

3. 强化宣传，营造氛围。要创造积累新的经验、新的做法，探索推进基层文化建设的规律和方式方法，充分利用各种平台，对推选为首批基层综合性文化服务中心省级优秀示范点的单位进行广泛宣传，以点带面，引导更多的示范点进入到优秀行列，营造良好氛围。

4. 加强督查，确保实效。省文旅厅将适时组织检查组对各单位推荐的省级优秀示范点进行实地督查，确保推选工作取得实实在在的效果。
