莆田市文化和旅游局关于印发《文化和自然遗产保护利用专项奖励工作方案》的通知

发布时间：2021-10-25 11:42
| | |

各县区（管委会），市直各有关单位：

经市委、市政府同意，现将《文化和自然遗产保护利用专项奖励工作方案》印发给你们，请认真抓好落实，并按要求做好评选推荐和材料报送工作。

 

 

                      莆田市文化和旅游局

                       2021年10月12日

 

文化和自然遗产保护利用专项奖励工作方案

 

按照福建省承办第44届世界遗产大会筹备工作小组综合协调部印发《关于办好第44届世界遗产大会推进我省文化和自然遗产保护“六个一批”项目和“一城七线”考察展示路线的实施方案》（闽世遗筹备工作小组综〔2020〕1号）文件要求，根据《中共莆田市委组织部 莆田市人力资源和社会保障局关于印发<莆田市机关事业单位工作人员及时奖励暂行办法>的通知》（莆人社文〔2020〕227号）文件精神，制定本方案。

一、奖励对象

在推进文化和自然遗产保护、传承、展示、利用等方面工作做出突出贡献的集体和个人。

（一）集体35个，其中机关事业单位给予嘉奖，企业及社会组织给予通报表扬。

（二）个人65人，其中机关事业单位人员给予嘉奖，企业及社会人士给予通报表扬。

二、奖励条件

全市文化和自然遗产保护利用专项奖励集体和个人必须热爱祖国，坚决拥护中国共产党的领导和社会主义制度，高举中国特色社会主义伟大旗帜，带头学习贯彻习近平新时代中国特色社会主义思想，认真执行党的路线方针政策，模范遵守党纪国法，增强“四个意识”、坚定“四个自信”、做到“两个维护”，自觉在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致，并具备下列条件：

（一）集体奖励条件

1.领导班子严守政治纪律和政治规矩，信念坚定、团结有力、作风民主、勤政廉洁，具有较强的凝聚力和战斗力，干部职工队伍素质高、团结进取、乐于奉献。 

2.单位自身的思想、组织和作风建设等制度健全规范，纪律严明，管理和服务水平走在本辖区、本系统前列。 

3.认真落实省委省政府、市委市政府关于文化和自然遗产保护利用工作的部署要求，积极完成各项任务。 

4.准确把握文化和自然遗产保护利用的新形势、新任务，坚持因地制宜、大胆探索，创新工作机制和方法，在推进文化和自然遗产保护、传承、展示、利用等方面工作有特色、有经验、有亮点，业绩突出、成效显著。

5.管辖范围内近5年来，未发生重大文化和自然遗产破坏、信访案件以及安全事故；本单位承诺未发生意识形态重大问题，不存在社会征信问题。 

（二）个人奖励条件

1.认真学习贯彻习近平新时代中国特色社会主义思想，旗帜鲜明讲政治，对党忠诚，热爱祖国，热爱人民，增强“四个意识”、坚定“四个自信”、做到“两个维护”，不折不扣贯彻落实党中央决策部署，在思想上政治上行动上始终与党中央保持高度一致，模范遵守宪法与法律法规。 

2.工作作风优良、业务素质良好、工作业绩突出，爱岗敬业、勤奋工作、清正廉洁、甘于奉献，坚持全心全意为人民服务，在群众中享有较高威信，模范带头作用突出。 

3.积极探索新形势下文化和自然遗产保护利用工作的新思路、新方法，坚持改革创新，勇于开拓进取，具有较高的管理水平或专业技术技能水平，在工作中发挥骨干作用。 

4.热爱文化和自然遗产保护利用工作，在推进文化和自然遗产保护、传承、展示、利用等工作中作出突出贡献。 

5.近5年来年度考核须为“称职（合格）”及以上等次；本人承诺未发生意识形态重大问题，不存在社会征信问题。

三、奖励程序

(一)申报。严格按照条件要求开展申报工作，根据单位和个人在文化和自然遗产保护利用中的具体表现情况，按照分配的名额提出奖励候选名单。奖励候选对象为机关事业单位的，须经所在单位党委（党组）集体研究决定，同时征求同级纪委监委、政法、干部管理等部门意见；奖励候选对象为国有企业、企业负责人或企业干部职工的，须征求所在地纪检监察机关、人力资源社会保障、生态环境、应急管理、税务、市场监管、公安等部门意见；奖励候选对象为其他所有制企业、企业负责人或企业干部职工的，须征求企业注册地统战、工商联等部门意见；奖励候选对象为社会组织、负责人或干部职工的，须征求注册地民政部门意见。奖励候选对象在本单位公示5个工作日，公示内容包括候选对象的基本情况和主要先进事迹。

(二)审核。由莆田市文化和自然遗产保护利用集体和个人专项奖励工作领导小组办公室对拟申报对象程序的规范性以及申报对象的身份、简历、事迹情况进行审核，并征求相关部门意见。

(三)公示。对拟奖励的集体和个人名单在全市范围内进行公示5个工作日，广泛征求社会各界意见建议。公示过程中如收到群众反映问题且核查属实的，取消奖励资格。市文化和旅游局负责将拟奖励对象提交市委市政府研究。

(四)决定。以市政府名义印发集体和个人专项奖励决定。同时，按照《公务员奖励规定》和《事业单位工作人员奖励办法》的有关规定，奖金按省人社厅发〔2018〕1号文件规定发放，从所在单位预算包干经费中开支。

四、组织领导

为加强对专项奖励工作的组织领导，成立莆田市文化和自然遗产保护利用集体和个人专项奖励工作领导小组。市政府分管副市长陈惠黔任组长，成员由市府办、市委组织部、市政法委、市公安局、市人社局、市文旅局、市住建局、市自然资源局、市林业局等单位领导组成。领导小组下设办公室，挂靠在市文旅局，负责专项奖励的具体工作。 

五、工作要求  

（一）高度重视，认真组织。各单位要积极配合做好文化和自然遗产保护利用集体和个人专项奖励申报工作，精心筹划安排，坚持公平公正，认真组织实施。  

（二）全面衡量，公平公正。申报对象要从谋划工作认真细致、推动工作注重协同、落实工作精益求精、发挥作用明显等方面考虑，向文化和自然遗产保护利用工作牵头单位和直接参与者或一线工作人员倾斜。

（三）严格程序，加强监督。严格按照评选条件和程序，广泛征求意见，全面衡量考虑，逐一审核推选，不搞平衡照顾，切实把工作成绩好、作风实、贡献大的先进典型推荐上来。

2021年10月31日前，各单位向市文化和旅游局报送《公务员奖励审批表》（附件1）、《事业单位工作人员奖励审批表》（附件2）、《公务员集体奖励审批表》（附件3）、《事业单位工作人员集体奖励审批表》（附件4）、《个人通报表扬审批表》（附件5）、《集体通报表扬审批表》（附件6）、《文化和自然遗产保护利用工作专项奖励集体或个人征求意见表》（附件7）、《文化和自然遗产保护利用工作通报表扬集体或个人征求意见表》（附件8、附件9或附件10）、《文化和自然遗产保护利用工作专项奖励集体和个人公示情况表》（附件11）、《文化和自然遗产保护利用工作专项奖励集体和个人名额分配表》（附件12）、《文化和自然遗产保护利用工作专项奖励集体和个人申报对象汇总表》（附件13）（以上材料一式3份，并附电子版本）。其中，基本情况和主要事迹要内容准确、突出业绩，集体和个人申报登记表内事迹简介字数在300字左右；申报对象照片为近期2寸免冠彩色照片3张（注明单位、姓名）。相关表格请各单位自行到OA系统下载后转发给相关单位和个人。联系人：张汉飞，联系电话：0594-2623669，邮箱pt2696660@163.com。
