莆田市财政局 莆田市文化和旅游局关于下达2021年中央广播电视节目无线覆盖运行维护费的通知

发布时间：2021-01-19 15:58
| | |

市广播电视中心：

根据《福建省财政厅 福建省广播电视局关于提前下达2021年中央广播电视节目无线覆盖运行维护费的通知》（闽财教指〔2020〕99号）文件精神，经研究，现下达你单位2021年中央广播电视节目无线覆盖维护费   万元（详见附件）。款列“2070899其他广播电视支出”科目。

请严格按照专项资金管理规定，加强资金使用和监督，提高资金使用效益，确保专款专用。

 

附件：1.2021年中央广播电视节目无线覆盖运维费安排表

  2.2021年中央支持地方公共服务体系建设补助资金绩效目标表
