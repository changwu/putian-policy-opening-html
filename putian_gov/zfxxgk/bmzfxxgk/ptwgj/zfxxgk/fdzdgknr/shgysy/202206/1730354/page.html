莆田市文化和旅游局关于印发2022年度发展街头文化工作方案的通知

发布时间：2022-05-23 17:37
| | |
 各县区文体旅局、湄洲岛旅游和文体局、北岸党工委宣传部，市群众艺术馆：

现将《2022年度发展街头文化工作方案》印发给你们，请认真抓好落实。

 

 

莆田市文化和旅游局

2022年5月18日

 

 

2022年度发展街头文化工作方案

 

发展街头文化是提供多样化文化供给，丰富市民和游客文化需求，为公共文化注入新动能、助力产业发展的重要举措。按照省文旅厅关于发展街头文化等相关工作部署，结合我市实际，现制定工作方案如下：

一、工作目标

要坚持因地制宜、分类指导、注重特色，通过建立健全工作机制，推动在历史文化街区、城市广场、大型公园和景区景点等区域常态化开展街头文化艺术表演活动，活跃街头文化氛围，培养一批自我创造、自我表现、自我管理的街头文化艺术能人，培育一批群众喜闻乐见的街头文化艺术品牌，打造一批有温度的街头特色人文艺术景观，推动一批街区景点成为旅游网红打卡点，为公共文化注入新动能，丰富市民和游客的文化需求。

二、工作措施

（一）招募一批街头艺人。市级由市群众艺术馆负责统一招募、培训、管理；各县区（管委会）可授权县区文化馆或景区等单位组织实施。各有关单位要结合工作需要，明确街头艺人招募的标准、条件、方式等，公开招募演唱、乐器、魔术、杂技、画像、手工艺人等民间艺人和文化艺术爱好者，确定街头艺人的管理名单。招募工作要于2022年7月底前完成。

（二）确定一批演出场所。各县区（管委会）要划定街头艺人表演的场所空间，明确时段区间。重点在历史文化街区、重要商圈、城市广场、景区景点等人流量大、群众关注度高的户外公共休闲场所设置表演点。演出场所选定要于2022年7月底前完成。

（三）开展系列演出活动。结合节庆、旅游季节等重要时间节点，积极引导各类民间文艺团体、文化志愿者参与街头文化的演出，扩大社会参与度。街头艺人以各自文化特长提供音乐演唱、魔术、乐器等丰富形式的文化艺术表演服务，并将莆仙戏、民间技艺等非遗项目展演展示纳入其中，既丰富街头文化内容又促进非遗项目的传承。组织省、市、县区（管委会）各类文艺赛事优秀节目以小型、灵活的方式进景区、入社区、上街头开展惠民演出，为市民和游客提供更多优质文化产品。

（四）培育一批特色品牌。市群众艺术馆、各县区（管委会）要因地制宜，结合地方特色文化旅游品牌和资源，创新形式，持续推进街头文化工作开展，积极培育一批群众喜闻乐见的街头文化艺术品牌，打造一批有温度的街头特色人文艺术景观，推动一批街区景点成为旅游网红打卡点。市文旅局将适时开展认定、典型宣传工作。

三、工作要求

（一）强化措施，推进工作落实。各单位要充分认识发展街头文化的积极意义，将其列为重点工作，采取有效措施，扎实推进工作开展。市群众艺术馆要主动作为，探索推进街头文化艺术发展，发挥示范带动作用。各县区（管委会）文旅部门要积极与城管、环保等单位协调演出场所选定、环保等问题；要加大资金支持力度，同时加大市场运作，加强对民间资本的吸纳和引导，为提升街头城市文化氛围提供经费保障。创新形式，探索与各大品牌活动、景区深度合作，推动街头艺术表演成为游客的网红打卡点，实现以文促旅、以旅彰文，促进旅游产业高质量发展。  

（二）明确要求，规范表演活动。街头艺人应在划定的场所和明确的时间进行街头表演，节目内容必须积极健康向上、体现社会主义核心价值观要求；应落实安全生产和环境噪声污染防治等有关规定和要求，遵守社会公德，恪守职业道德，非活动时间不在表演点位放置相关工具道具。要制定街头艺人自我管理规范，引导街头艺人签订相关自律公约；畅通监督渠道，鼓励引导群众对街头艺人进行评价，对不良行为及时反映。 

（三）加强宣传，营造良好氛围。注重总结经验、做法，依托报纸、电视、网站、两微一端等宣传平台，加大宣传力度，营造城市浓厚文化氛围。
