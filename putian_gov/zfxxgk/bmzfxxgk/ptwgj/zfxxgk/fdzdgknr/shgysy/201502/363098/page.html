发布时间：2015-02-09 08:00
| | |

局属相关单位：

为了进一步做好莆仙戏传承与发展工作，弘扬莆仙戏文化品牌，现将《莆仙戏传承与发展工作立项分解方案》印发你们，请遵照执行并抓好落实。

 

 

莆田市文化广电新闻出版局

2015年2月9日

 

 

 

 

莆仙戏传承与发展工作立项分解方案

 

莆仙戏有悠久的传统和独特的艺术魅力，是表现和传承优秀传统文化的重要载体，是具有莆仙特色、深受广大群众喜爱的地方戏。莆仙戏的传承和发展工作是个系统工程，挖掘、整理一批珍贵的莆仙戏史料，创作一批优秀的莆仙戏作品，培养一批德艺双馨的莆仙戏专业人才，全面、系统地做好莆仙戏传承与发展工作。现将有关工作分解如下：

一、主要措施

（一）完善莆仙戏相关资料

1.收集莆仙戏资料，建设莆仙戏资料室

收集莆仙戏传统剧本、乐谱、音像资料、历史图片、脸谱资料、研究书籍等资料。建设莆仙戏资料室，配备管理人员，做好整理、归档、索引等工作。

完成时间：2015年6月

责任单位：艺研所

2.征集莆仙戏文物，建设市博物馆莆仙戏专题展厅

向社会各界征集莆仙戏传统服装、脸谱、道具、乐器、剧作家手稿、作曲家手稿等文物。撰写莆仙戏专题展厅展陈方案，通过图片、视频、实物等展示方式建设莆仙戏专题展厅。

完成时间：2015年9月

责任单位：博物馆  配合单位：艺研所

3.出版剧作家作品

出版朱国福、周长赋、王顺镇、姚清水、郑文金等人莆仙戏剧作家作品。

完成时间：2015年6月

责任单位：艺研所  配合单位：出版科

4.整理出版锣鼓经

组织非遗传承人开展整理、录像、出版300多套锣鼓经工作。

完成时间：2015年5月

责任单位：艺研所  配合单位：戏剧院

5.建设市图书馆莆仙戏书籍专柜，建设莆仙戏资料数据库

全面收集莆仙戏相关书籍，建设市图书馆莆仙戏专柜；建设莆仙戏资料数据库，纳入莆田市图书馆数字化系统建设项目，为广大莆仙戏研究者提供便捷、优质的服务。

完成时间：2015年12月

责任单位：图书馆  配合单位：艺研所

（二）加强莆仙戏人才培养

1.建立师带徒培养机制，做好莆仙戏科介传承

建立“师带徒”培养机制，以“师带徒”方式培养莆仙戏编剧、表演、导演、音乐设计、传统乐器、服装设计、舞台美术、戏曲形象设计等人才。组织复排经典折子戏，传承莆仙戏传统科介，建立折子戏音像资料库。

完成时间：常年

责任单位：艺术科  配合单位：戏剧院、艺校、艺研所

2.开展系列培训工作

采取请进来、走出去的办法，邀请省内外戏曲专家学者、著名演员走进莆田，为莆仙戏院团、院校举办专题讲座、开展艺术交流。输送编剧、导演、舞美、灯光、音响、服装、音乐等人才赴高等艺术院校深造。加强与人力资源和社会保障局合作，举办莆仙戏民营剧团演职人员专业技能培训班。建立莆仙戏师资库，充实莆仙戏各类师资队伍，加强对师资库教师进行再教育培训。

完成时间：常年

责任单位：艺术科  配合单位：戏剧院、艺校、艺研所

（三）做好莆仙戏推广宣传

1.拍摄莆仙戏专题片，出版发行莆仙戏合辑

拍摄莆仙戏电视记录片，通过文化信息资源共享工程系统传播推广；出版发行经典莆仙戏合辑。

完成时间：常年

责任单位：图书馆、戏剧院

2.参加全国、全省戏剧展演、比赛

组织我市院团、院校参加文华奖、梅花奖、省戏剧会演、水仙花奖等各类展演、比赛。

完成时间：常年

责任单位：艺术科  配合单位：艺研所、戏剧院、艺校

3.举办莆仙戏剧节

举办三年一届的莆仙戏剧节，发现人才、提升莆仙戏整体水平，打造“戏剧之乡”品牌。

完成时间：常年

责任单位：艺术科  配合单位：艺研所、戏剧院、艺校

4.开设戏曲点播台，开办戏曲栏目

与网络部门合作成立戏曲点播台。加强与莆田市电视台合作，开辟戏曲专题栏目，定期播放莆仙戏资讯、视点、剧目。

完成时间：2015年6月

责任单位：艺术科  配合单位：戏剧院、艺研所、艺校

5.建设网络交流平台

依托莆仙大剧院网站平台，开设戏曲资讯宣传、戏迷票友互动栏目，开展宣传，加强与戏迷观众的互动。

完成时间：2015年4月

责任单位：大剧院  配合单位：戏剧院、艺研所、艺校

6.加强莆仙戏对外交流

开展莆仙戏“乡音之旅”全国巡回演出活动，加强与港澳台、国外戏曲交流演出。

完成时间：常年

责任单位：艺术科  配合单位：戏剧院

二、具体要求

1.加强组织，落实责任。各相关单位领导要高度重视莆仙戏传承与发展工作，将《莆仙戏传承与发展工作计划立项分解方案》纳入各单位年度工作计划，细化任务分解、明确责任单位、责任人；定期召开专题会议，研究解决工作中遇到的问题；相关科室要做好指导、协调、督查等工作，推动各项工作顺利完成，同时，立项分解方案完成情况将列入我局对各单位绩效考评内容。

2.细化方案，明确时间。各相关单位要对照《莆仙戏传承与发展工作计划立项分解方案》进一步细化工作方案，按照方案规定的时间期限完成各项任务，按计划推进莆仙戏传承与发展工作。

3.经费保障，一事一报。本着节约质量、一事一报的原则，落实经费保障，细化经费使用方案，严格遵守财经制度，保障莆仙戏资金规范使用。
