莆田市文化广电新闻出版局关于规范申报莆田市非物质文化遗产项目及代表性传承人文本的通知

发布时间：2013-03-07 08:00
| | |

各县区文体广电出版局，湄洲岛社会事务局，北岸工委宣传部，市直有关单位：

我市第四批非遗项目及第三批非遗项目代表性传承人申报工作开展以来，得到社会各界的热烈响应，目前已收到申报材料100多件。经过初步审查，大部分申报材料存在填写不规范问题。为了进一步规范非遗项目和代表性传承人的申报文本，确保我市非遗申报工作的科学、有序进行。现将有关事项通知如下：

一、请各县区（管委会）文化行政部门对原有推荐申报我市第四批非遗项目及第三批非遗项目代表性传承人申报文本材料进行重新审核、把关，材料不规范、不到位的要重新填写、补充。

二、各县区（管委会）文化行政部门要指定专人负责非遗申报工作。要求较熟悉当地历史、民俗文化，有较好的文字基础，专、兼职或聘用均可。具体名单请于3月 11 日下午下班之前以书面并加盖公章后报送市局社文科，传真：2689939。

三、为加强对填写申报文本的指导，我局将于3月13日上午8:30在市群众艺术馆六层演艺厅召开市级非遗项目和代表性传承人申报工作会议。参加对象：1.各县区（管委会）文化主管部门分管领导；2.负责非遗申报工作人员；3.申报市第四批非遗项目保护单位及第三批非遗项目代表性传承人代表各1人；4.市非遗专家委员会全体专家。（上述1至3项由各县区文化行政部门通知；第4项由市局通知）

四、材料报送时间

申报市级第四批非遗项目及第三批非遗项目代表性传承人文本由县区统一收齐后报送市局社文科，同时提供申报目录清单并加盖公章。申报材料报送截止日期为4月1日。

 

附件：1.申报莆田市第四批非遗项目名单
