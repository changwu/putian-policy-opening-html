关于推荐莆田市非物质文化遗产保护工作专家委员会专家库人选的通知

发布时间：2018-07-23 16:35
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部，局属有关单位：

为贯彻落实《中华人民共和国非物质文化遗产法》《福建省民族民间文化保护条例》和《莆田市非物质文化遗产保护管理实施办法》，进一步推进我市非物质文化遗产保护工作，构建我市结构合理、专业齐全的非遗保护专家队伍，提高全市非物质文化遗产保护科学化和规范化水平，我局将建立健全莆田市非物质文化遗产保护工作专家库(以下简称“专家库”)，具体事项通知如下：

一、职责定位

专家库隶属于莆田市非物质文化遗产保护工作专家委员会，对全市非物质文化遗产保护工作具有决策咨询、项目论证、评审考核和专业指导等作用，主要职责：

（一）为全市非物质文化遗产保护工作提供科学化咨询、提出合理化建议、提供专业化指导；

（二）参与全市非物质文化遗产代表性项目和代表性传承人的评审考核工作；

（三）参与全市非物质文化遗产保护规划、方案的制定，项目的论证、保护与管理，文化生态保护实验区的考察与规划纲要的论证起草，相关标准规范的制定，数据库建设，知识产权保护，及相关文字、音像出版物的编撰出版等方面工作；

（四）参与全市非物质文化遗产项目的研究、阐释和传播；

（五）参与其它有关非物质文化遗产保护工作。

二、推荐标准

（一）拥护中国共产党的领导，热爱祖国，热爱人民，模范遵守国家法律法规，了解有关方针政策；

（二）热爱非物质文化遗产保护事业，具有良好的职业道德和操守，在工作中和专业上能够坚持客观公正原则，实事求是，科学严谨，团结协作；

（三）从事非物质文化遗产保护或相关专业研究，具有副高级以上或具有中级职称职务、在非物质文化遗产保护工作领域内有较深造诣；

（四）身体健康，能够承担市级专家相关工作。  

三、推荐要求

（一）专家库分十个门类，具体为：Ⅰ民间文学；Ⅱ传统音乐；Ⅲ传统舞蹈；Ⅳ传统戏剧；Ⅴ曲艺；Ⅵ传统体育、游艺与杂技；Ⅶ传统美术；Ⅷ传统技艺；Ⅸ传统医药；Ⅹ民俗。原则上每名推荐人选只能申报一个门类，确有跨门类专长者最多只能申报两个门类，并注明主要和次要门类。

（二）各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部和局属有关单位要切实加强对本地区、本系统、本专业专家学者遴选推荐工作的领导，认真负责地择优推荐专家库专家人选，推荐名额不限。

（三）专家人选由个人填写《莆田市非物质文化遗产保护专家推荐表》（见附件）。表格一式两份，经专家所在单位签署意见后，于8月30日前报莆田市非物质文化遗产保护中心，同时报送电子版表格。附件表格可在莆田市文化广电新闻出版局官方网站(www.ptwgj.gov.cn)查看并下载。

（四）推荐表由各县区（管委会）文化行政部门汇总后报送，局属有关单位直接报送。

四、入选办法

各单位推荐的专家人选经市非物质文化遗产保护中心审核后，报市文化广电新闻出版局批准后纳入莆田市非物质文化遗产保护工作专家委员会专家库。
