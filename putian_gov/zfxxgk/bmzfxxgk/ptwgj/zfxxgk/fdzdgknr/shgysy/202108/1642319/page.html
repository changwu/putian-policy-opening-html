莆田市文化和旅游局 莆田市教育局关于公布莆田市第十二届少儿故事大王录像比赛结果的通知

发布时间：2021-08-31 17:53
| | |

各县区文化体育和旅游局、教育局，湄洲岛旅游和文化体育局，北岸工委宣传部，市直有关学校：

根据市文化和旅游局、市教育局《关于举办莆田市第十二届少儿故事大王录像比赛的通知》（莆文旅〔2021〕98号）文件，莆田市第十二届少儿故事大王录像比赛已于7月上旬成功举行。本次比赛分设幼儿组、小学组、小品组，其中小学组分为小学初级组、小学高级组。通过各县区选拔推荐，参加市级复赛的作品共有186个。共评出一等奖作品20个、二等奖作品28个、三等奖作品46个，现予以公布。

 

附件:莆田市第十二届少儿故事大王录像比赛获奖作品名单
