市直有关单位，各县区
文化体育和旅游局、湄洲岛旅游和文化体育局、北岸党工委宣传部
，各县区（管委会）发改局（计统局）：
版权登记工作，是激励作品创作，维护著作权人合法权益的重要举措，是尊重知识产权、重视创新创造的重要内容，
版权作品（不含计算机软件作品）自愿登记数量和年增长率已列入省、市营商环境
“知识产权创造、保护和运用”考评重要指标。
为进一步加强我市版权作品登记和版权保护工作，形成
“激励创造、依法保护、有效管理、强化服务”的良好局面，现将有关事项通知如下：
一、总体目标
2022年，我市
版权作品（不含计算机软件作品）自愿登记数量排名全省第
4名、年增长率排名全省第2名；截至2023年上半年，上述两个指标分别下降至第5名和第7名。按照营商环境考评自愿登记数量和年增长率指标要求，我市版权作品（不含计算机软件作品）年增长率要同比达到20%以上，实现指标不扣分，排名持续保持去年成绩以上。
二、重点任务
（一）做好版权作品登记工作。
根据《著作权法》及其实施条例有关规定，共有
文字作品、口述作品、音乐作品、戏剧作品、曲艺作品、舞蹈作品、杂技艺术作品、美术作品、建筑作品、摄影作品、视听作品、图形作品、模型作品等
13类作品可申请登记（详见附件1），结合我市实际情况，重点关注银饰珠宝、工艺家具、雕刻、油画、家居装饰等行业作品登记情况，主要分布在莆田油画城、莆田黄石工艺城、仙游博览城、北高珠宝城、上塘银饰城等工艺美术专业园区。各单位要
创新服务形式，充分发动，深入专业园区及其相关企业，瞄准版权密集型企业和个人，引导版权登记和保护创新，确保版权作品应登尽登、应保尽保。
（二）加强版权作品登记措施。
一是成立版权专业服务机构。
8月底前，全市各专业园区、行业组织、重点企业等挂牌成立版权登记服务中心，充分利用社会资源和力量，发挥版权行业组织、版权交易机构等平台的作用，加强对版权作品登记的服务和管理，推进版权作品登记的便利化和规范化发展。二是细化任务分解。各县区（管委会）要在2022年的登记数量的基础上（详见附件2），按照
20%以上的增长率，安排细化任务分解，开拓创新版权工作思路，激发版权作品创作活力，特别是仙游县、涵江区数量明显偏少，要加大工作力度，做好分类指导和针对性服务，确保版权登记数量和增长率实现跨越式增长。
（三）积极创建版权示范项目和单位。
各单位要积极引导企业和个人参加创建国家、省、市版权示范项目，引导版权企业集聚，促进版权运用和转化，实现版权示范向纵深发展，提升版权创新水平。鼓励各县区（管委会）对新获评的版权示范单位、园区（基地）和获得国家、省版权主管部门颁发、授予的优秀版权作品（国家级重点版权项目）荣誉的企业和个人给予优惠政策倾斜或奖励措施。
（四）加大版权执法监管。
把全面加强版权保护作为版权执法监管工作的重要内容，有效发挥文化市场综合执法机构的版权执法职能和
“12345”投诉平台作用，常态化组织工信、公安、市场监管、网信等部门开展侵权盗版“剑网”专项行动，进一步推动版权行政执法与刑事司法的有效衔接，加大案件查办力度，提高案件办案质量，不断提升版权执法效能，为推动版权高质量发展提供有力支撑。
三、相关要求
各县区（管委会）版权主管部门、市直有关单位要切实提高认识，全面加强对版权工作的领导，明确版权机构、分管领导、资金保障等，将版权工作纳入本部门本单位重点工作，建立健全考核评价机制，加强督导检查，确保版权登记各项工作有效落实。要积极与财政、金融、税务、发改等部门沟通协调，推动将版权登记工作纳入重大规划，争取财政及其他相关政策支持，将版权登记纳入专项资金或优惠政策倾斜范围，强化保护力度、拓展保护范围、突出保护重点、增强保护实效，不断优化版权领域营商环境。

作品版权登记指南
一、登记范围
《著作权法》及其实施条例规定的可进行作品登记，主要包括：
（一）文字作品，是指小说、诗词、散文、论文等以文字形式表现的作品
;
（二）口述作品，是指即兴的演说、授课、法庭辩论等以口头语言形式表现的作品
;
（三）音乐作品，是指歌曲、交响乐等能够演唱或者演奏的带词或者不带词的作品
;
（四）戏剧作品，是指话剧、歌剧、地方戏等供舞台演出的作品
;
（五）曲艺作品，是指相声、快书、大鼓、评书等以说唱为主要形式表演的作品
;
（六）舞蹈作品，是指通过连续的动作、姿势、表情等表现思想情感的作品
;
（七）杂技艺术作品，是指杂技、魔术、马戏等通过形体动作和技巧表现的作品
;
（八）美术作品，是指绘画、书法、雕塑等以线条、色彩或者其他方式构成的有审美意义的平面或者立体的造型艺术作品
;
（九）建筑作品，是指以建筑物或者构筑物形式表现的有审美意义的作品
;
（十）摄影作品，是指借助器械在感光材料或者其他介质上记录客观物体形象的艺术作品
;
（十一）电影作品和以类似摄制电影的方法创作的作品，是指摄制在一定介质上，由一系列有伴音或者无伴音的画面组成，并且借助适当装置放映或者以其他方式传播的作品
;
（十二）图形作品，是指为施工、生产绘制的工程设计图、产品设计图，以及反映地理现象、说明事物原理或者结构的地图、示意图等作品
;
（十三）模型作品，是指为展示、试验或者观测等用途，根据物体的形状和结构，按照一定比例制成的立体作品。
二、申请人范围
作者，其他依照著作权法享有著作权的公民、法人或者其他组织。
三、自主申报登记方式
在线登陆
“福建省作品自愿登记系统”
（
http://copyright.fjxuanchuan.cn/indexPage）自主申报作品，申报成功后，自主打印电子证书。
四、版权作品登记的作用
在著作权纠纷中作品登记证书可作为初步证据使用，在对方不能提出反证的情况下，可以证明作品著作权的归属。
