莆田市文化和旅游局关于进一步加快推进公共文化领域四项重点改革任务落实的通知

发布时间：2019-06-03 17:20
| | |

各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸工委宣传部、北岸文旅办，局属有关单位：

公共文化领域四项重点改革任务是中央深改办确定的改革任务，是国家文化领域全面深化改革的重点工作，是法律规定的工作事项，是推进现代公共文化服务体系建设的关键举措。现将《福建省文化和旅游厅关于进一步加快推进公共文化领域四项重点改革任务落实的通知》转发你们，请按照文件要求，抓好贯彻落实，确保基本公共文化服务标准建设、基层综合性文化服务中心建设、县级文化馆图书馆总分馆制建设、公共文化机构法人治理结构改革等四项重点改革任务在今年年底全部完成。请进一步明确路线图、时间表，认真填写《2019年四项重点改革任务月推进计划表》《行政村（社区）综合性文化服务中心建设计划清单》《县级文化馆图书馆总分馆制建设计划清单》《推进公共文化机构法人治理结构建设计划清单（地市级）》，于6月10日前报送市文旅局。联系人：林益清，联系电话：2689939，邮箱：pt2696660@163.com。

福建省文化和旅游厅关于进一步加快推进

公共文化领域四项重点改革任务落实的通知

 

各设区市文旅局、平潭综合实验区社会事业局：

公共文化领域四项重点改革任务是中央深改办确定的改革任务，是国家文化领域全面深化改革的重点工作，是法律规定的工作事项，是推进现代公共文化服务体系建设的关键举措。按照文旅部的工作部署，5月14日，我省组织召开了推进公共文化领域重点改革任务落实座谈会，对四项重点改革任务进行再动员、再部署。为进一步抓好会议精神的贯彻落实，确保四项重点改革任务在2019年年底全部完成，现将相关要求通知如下：

一、切实提高认识，扛起工作责任

各地文旅部门要按照全省推进公共文化领域重点改革任务落实座谈会要求，切实提升站位、提高认识，从讲政治的高度坚决扛起主体责任，要进一步明确路线图、时间表，把握好改革任务的重点要求、关键环节，抓到位、抓出成效。一是要加强沟通协调，争取党委、政府和发改、财政等部门的支持，形成合力推进的良好氛围。二是要层层传导责任，指导督促提升认识，攻坚克难，把四项重点改革任务扛在肩上，落实在行动上，确保工作任务如期完成。三是要善于总结提升，对照任务表，对已经完成的改革任务，及时总结经验，抓好巩固提升工作；对尚未完成的改革任务，要学习借鉴兄弟单位的经验做法，加快推进，确保按时序完成。

二、明确工作重点，全力推进实施

一是明确重点任务。基本公共文化服务标准建设，要求所有的设区市和县（市、区）必须全部制定公布基层公共文化基本服务目录，并组织实施。基层综合性文化服务中心建设，要求全省所有的乡镇（街道）和行政村（社区）都要建设基层综合性文化服务中心，实现村村有基本文化阵地。文化馆图书馆总分馆制建设，要求所有县（市、区）级文化馆图书馆都要建立总分馆制。公共文化机构法人治理结构改革，要求所有市级以上面向社会提供公益服务的公共图书馆、博物馆、文化馆、美术馆等公共文化机构，都要建立以理事会为主要形式的法人治理结构。二是明确工作时限。按照文旅部的工作要求并结合我省实际，四项重点改革任务要在今年年底全部完成。三是明确具体要求。各设区市要结合全省2019年四项重点改革任务季度推进计划表（附件1），分解确定本地区年度四项重点改革任务月推进计划表。村级综合性文化服务中心、总分馆制、法人治理结构三项重点改革任务尚未完成的单位要列出具体清单，具体到单位名称。

三、强化工作举措，确保如期完成

一是强化指导。各设区市要加大对本地区改革情况的过程管理和跟踪指导，及时研究解决工作中遇到的各种困难和问题，为改革任务顺利推进提供有力保障。二是强化督查。从通知下发之日起，建立双月工作报送机制，各设区市在每隔一个月的25日之前将本地四项重点改革工作任务完成情况上报省厅，省厅进行汇总分析后，对进度完成慢的地区将进行通报，并视情况抄报所在地政府。三是强化宣传。各地要通过各种方式对改革进展情况进行宣传，扩大影响，逐步形成声势和氛围，争取社会各界的理解和支持，推进改革任务顺利完成。

请各地将本地区的公共文化领域重点改革任务月推进计划表（附件2）于6月12日前报送至省厅，将具体清单（附件3）于6月21日前报省厅备案。
