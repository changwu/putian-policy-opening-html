关于举办“金色海西”福建青年歌手电视大赛（莆田分赛区）的通知

发布时间：2009-08-31 08:00
| | |

各县区委（工委）宣传部（党务科、党务人事局）、文体局、教育局、总工会、团委、妇联、莆田学院、湄洲湾职业技术学院、仙游师范学校：

今年是中华人民共和国成立六十周年。按照省委、省政府的统一部署，福建省人民政府将举办第四届福建艺术节。根据省委办公厅、省政府办公厅《关于印发第四届福建艺术节活动方案的通知》精神，中共福建省委宣传部、福建省文化厅、福建省军区政治部、福建省教育厅、福建省广播电视局、福建省文联、福建省广播影视集团联合下发了《关于举办“金色海西”福建青年歌手电视大赛的通知》（闽文社[2009]66号），通知要求各地需在10月10日前完成预赛选拔工作，11月上旬举行“金色海西”福建青年歌手电视大赛。

“金色海西”福建青年歌手电视大赛，也是中央电视台在明年举行的第14届全国青年歌手大赛大奖赛福建赛区的选拔赛。希各有关单位要高度重视，广泛发动和组织青年歌手参加比赛。现将我市“青歌赛”分赛区活动安排通知如下：

一、主办单位：

中共莆田市委宣传部、莆田市文化广电新闻出版局、莆田市教育局、莆田市总工会、共青团莆田市委、莆田市妇女联合会、莆田市广电中心。

二、承办单位：

莆田市广电中心、莆田市群众艺术馆。

三、报名办法：

时间：2009年9月20日。

地点：市群众艺术馆。

联系人：杜文广，电话：2694355。

四、比赛时间：

2009年9月23日至30日。

五、比赛地点：

莆田市广电中心演播厅，莆田市群众艺术馆五楼演艺厅。

六、评委结构：

拟邀请我市资深音乐届专家担任评委（副高职称以上），初定9-11人。

七、比赛内容：

按照美声、民族、流行、原生态、组合五个组别进行。

八、参赛对象：

不分职业和非职业，年龄在17周岁至34周岁（1975年1月1日至1992年12月31日之间出生）。

九、评选办法：

（一）每位选手演唱一首歌曲，并回答相关问题。

（二）评分标准为百分制，其中演唱水平（含音准、乐感、

作品难度、体现能力、舞台形象等）占99%，综合素质答题占1%。

（三）鼓励选手演唱新作品和首唱新作品。新作品是指2005年以来我省新创作且未正式出版的声乐作品，演唱或首唱新作品，奖励0.3分。

（四）采取现场打分方式评定，分别去掉两个最高分和最低分后，以平均分评定参赛选手分值，以分数高低评定参赛选手名次。

（五）评出市级金奖、银奖、铜奖若干个，由主办单位颁发证书。

（六）按照选手比赛名次选出前6名，参加省复赛和决赛。

十、奖项设置：

各组分设一等奖、二等奖、三等奖和优秀奖若干（或根据参赛人数情况设置获奖比例）。
