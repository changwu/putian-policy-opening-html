关于印发2016年“书香莆田”全民阅读月活动实施方案的通知

发布时间：2016-10-25 15:30
| | |

各县区委（管委会）宣传部、文明办、文体广电出版局、教育局、总工会、团委、妇联、社科联、文联，秀屿区教育局、湄洲岛社会事务局，新华发行集团各分公司，各邮政分公司、移动分公司，市直有关单位：

2016年是中宣部、国家新闻出版广电总局等部门倡导和开展全民阅读十周年。为全面贯彻落实党的十八大和十八届三中、四中、五中全会精神，深入学习贯彻习近平总书记系列重要讲话精神，深化 “倡导全民阅读，建设书香莆田”主题阅读活动，努力建设书香社会，推动全民阅读活动的深入开展，促进全民素质和社会文明程度显著提高，由市全民阅读组委会举办的莆田市第十届“书香莆田”全民读书月活动，定于2016年10月至11月期间在全市范围内全面开展。结合我市实际，现制定《2016年“书香莆田”全民读书月活动实施方案》，印发给你们，请认真组织贯彻落实。

2016年10月25日

 

2016年“书香莆田”全民读书月活动实施方案

 

为进一步贯彻落实中央关于推进全民阅读工作的决策部署,深化“倡导全民阅读，建设书香莆田”主题活动，推动全民素质和社会文明程度显著提高，努力把“书香莆田”全民读书月活动持续打造成我市精神文明建设和文化建设的重要品牌，根据省委宣传部等十六个部门联合印发的《关于开展2016年“书香八闽”全民阅读工作的通知》闽新广（〔2016〕170号）要求，制定2016年“书香莆田”全民读书月活动实施方案。

一、指导思想

全面贯彻党的十八大和十八届三中、四中、五中全会精神，深入学习习近平总书记系列重要讲话精神，倡导全社会多读书、读好书，进一步激发群众阅读热情，弘扬主旋律，传播正能量，践行社会主义核心价值观，推动社会主义文化大发展大繁荣，为“打造宜居港城、建设美丽莆田”提供精神动力和智力支持。

二、活动主题

倡导全民阅读，建设书香莆田。

三、活动时间

2016年10月28日—11月28日。

四、组织机构 

第十届“书香莆田”全民阅读组委会成员单位：中共莆田市委宣传部、中共莆田市委市直机关工作委员会、中共莆田市委精神文明建设办公室、莆田市文化广电新闻出版局、莆田市教育局、莆田市总工会、中国共产主义青年团莆田市委员会、莆田市妇女联合会、莆田市社会科学界联合会、莆田市文学艺术界联合会，湄洲日报社、莆田市广播电视中心、新华发行集团莆田分公司、中国邮政集团莆田分公司、中国移动通信集团莆田分公司。

组委会下设办公室，办公室设在市文化广电新闻出版局，负责全民读书活动的组织、协调工作。

协办单位：各县区组委会，莆田学院、莆田市艺术馆、莆田市图书馆、各县区图书馆、莆田晚报、莆田新闻网、莆田侨乡时报、仙游今报、莆田市出版物发行业协会、市朗诵协会、莆田市莆仙大剧院有限公司、民营书店。   

五、活动内容

   （一）莆田市第十届“书香莆田”全民读书月活动启动仪式

时间：2016年10月28日。

内容：莆田市第十届“书香莆田”全民读书月启动仪式，通过集中举办图书展销、捐赠书籍、诗歌朗诵、名家讲坛、“书香莆阳”微信公众号启用等活动，正式启动2016年全民读书月活动仪式。

地点：莆仙大剧院广场。

实施单位：第十届“书香莆田”全民阅读组委会，莆仙大剧院有限公司，市出版物发行行业协会等。

   （二）全民读书系列宣传活动

1.开设“书香莆田”专栏。市主要报刊、电视台和相关网站开设“书香莆田”专题或专栏，报道全民读书月活动；系列专题报道入围全国、全省“书香之家”的事迹；推荐好书，介绍读书、选书、藏书方法等。 

实施单位：市文广局、莆田广播电视台。

2.在“莆田网”等新媒体上刊登文学艺术作品，传播书香莆田信息，推介阅读经验，传播名家名作，促进全民点击名站。

实施单位：湄洲日报、莆田晚报、莆田学院报、莆田网、莆田侨乡时报。

3.制作、播放“书香莆田”全民阅读公益广告。发动群众加入公益广告作品征集评选活动,定期在“书香莆阳”微信公众号推送公益广告作品,并给予一定的奖励，获奖作品将在莆田广播电视台进行播放推送。印发2016年“书香莆田”全民读书活动标语、海报、宣传品。在市、县区政府办公大楼，大中专院校、中小学、图书馆和出版物经营单位，悬挂活动标语，电子屏滚动播出全民读书活动广告、标语等。

实施单位： 2016年“书香莆田”全民阅读组委会成员单位，各县区组委会，市出版物发行业协会等。

   （三）“全民阅读进机关”活动

4.在全市机关党组织中扎实开展“读书、荐书、品书”活动，加强社会主义核心价值观教育；向全市机关干部推荐优秀阅读书目；向市直机关各级党组织赠阅党建读物为主的书籍。

实施单位：市直机关党工委。

   （四）“全民阅读进学校”活动

5.开展“友善、孝敬、节俭、诚信”主题经典诵读比赛，组织各级学校利用早读、班会、语文课、思想品德课等时间，组织学生诵读。结合诗会、诗文赏析讲座、诗词创作征集、故事会等载体，引导青少年学生认识传统、尊重传统、继承传统、弘扬传统。

实施单位：市教育局。

6. 开展“每天半小时，书香伴成长”亲子阅读活动，通过家庭、学校携手的方式，发出“每天半小时、书香伴成长”亲子阅读行动倡议，组织学生与家长共同制作书签、读书卡，制定家庭读书计划，通过“一周一本好书”、“图书漂流会”等活动载体,让学生养成阅读的兴趣和习惯。积极撰写阅读心得、体会收获，通过家校携手，亲子共读，营造浓厚的读书氛围。

实施单位：市教育局。

7.扎实开展青少年爱国主义读书教育活动，以“传承中华文化，共筑精神家园”为主题，广泛开展内容丰富、形式多样、学生喜爱的读书活动，组织参加征文比赛、小学生讲故事比赛、中学生演讲比赛和“春苗网”知识竞赛等活动，帮助广大青少年深入了解中华民族的历史传统和文化积淀，增强民族文化自信和价值观自信。

实施单位：市教育局。

8.指导莆田市阳光青少年事务服务中心、莆田市青年志愿者协会、“飞得更高”爱心协会等青年公益组织广泛开展诵读经典主题活动。

实施单位：团市委。

9. 组织开展“青春阅读”活动，结合开学季积极与高校签约合作，共同组织“读书月”系列活动，构建具有本地特色的“书香校园”手机阅读平台。招募教师、学生为校园阅读推广大使，持续推进校园阅读长期运营。

实施单位：移动莆田分公司。

   （五）“全民阅读进企业”活动

10.向各级工会、全市企业职工积极推荐本市作家、全总推介的目录以及推广电子职工书屋；评选30家市级“职工书屋”示范点、20家“书香企业示范点”；组织企业员工开展各种形式的读书活动和岗位技能知识竞赛。

实施单位：市总工会。

11.通过企业阅读平台和“移家人”企业微平台，搭建“莆田移动职工书屋”。

实施单位：移动莆田分公司。

   （六）“全民阅读进乡村”活动

12.以农家书屋为主阵地，举办“美丽乡村，书香农家”系列活动。在广大乡村开展“我的书屋·我的梦”为主题的阅读实践活动，为农村少年儿童推荐优秀农家书屋出版物，进行阅读指导，组织教师、志愿者、返乡大学生开展阅读辅导，举办“我与书屋共成长”、“我当农家书屋管理员”等主题征文评选活动，并对获奖征文给予表彰、奖励。

实施单位：市文广局

13.探索“农家书屋建在书香之家”模式。选择部分符合条件的家庭，特别是“书香之家”搭建农家书屋。充分利用书香之家的资源优势、阅读经验及管理水平，让农家书屋与书香之家相得益彰，给予书香之家所需的管理费、运行费，并酌情予以一定的奖励。

14.实施莆仙文化进书屋工程，设立莆仙文化专柜，向100家农家书屋赠送莆仙文化图书、音像制品等。

实施单位：市文广局、市图书馆。

    15.继续在留守流动儿童较多的2所小学开展“爱心书屋”援建活动，各配送价值2万元图书。

实施单位：市妇联。

   （七）“全民阅读进家庭”活动

16.全市开展先进性别文化进“妇女之家”项目。为全市970个村（社区）“妇女之家”配齐《中国妇女报》，部分县区妇联为辖区村（社区）“妇女之家”赠阅《中国妇女》杂志和《海峡姐妹》杂志等女性刊物，供妇女姐妹学习阅览。

实施单位：市妇联。

17. 线上线下举办家庭和睦公益大讲堂、家庭教育公益大讲堂。举办走进社区、农村、机关、社区家长学校、中小学等，开设家风家训课堂、夫妻课堂、婆媳课堂、亲子课堂、祖辈家长课堂、妇女维权知识课堂，宣传男女平等基本国策，普及宣传婚姻家庭知识，传授家庭沟通艺术和科学教子理念，促进家庭文明和谐。在网上，依托市妇联官方网站、微博、微信，开设网上家长学校专栏，及时更新家庭教育等相关知识，依托官方微信、微博推送、转发荐读书目，促进家长自身的学习。

实施单位：市妇联。

    18. 举办全市农村（社区）女主干培训班和全市先进妇女之家负责人培训班。以女性村干部为重点进行全面业务培训，提升女村官、妇代会主任的履职和服务能力。

实施单位：市妇联。

   （八）“全民阅读进军营”活动   

19. 结合拥军活动，援建“拥军书屋”1个，配送价值3万元图书。

实施单位：市妇联。

20.到基层部队举办图书展销，把优秀出版物推介到军营；组织各类主题读书活动，为基层官兵提供阅读指导服务。

实施单位：新华发行集团莆田分公司。

   （九）“阅读点亮梦想”系列活动

21.举办“你看书我买单读者选书”活动。持有市图书馆借阅证的读者，可以凭《借阅证》到市新华书店图书城挑选图书不多于5本，阅读后完好归还市图书馆，所有费用由市图书馆买单。

实施单位：市图书馆，新华发行集团莆田分公司。

22. 评选“阅读之星”。以读者进馆借阅册数为标准，评选“阅读之星”，授予“阅读之星”荣誉称号。

实施单位：市图书馆。

23.举办“期刊在线有奖答题”、“倾听名家声音、感悟阅读与写作乐趣”活动，送书下乡、新书展阅等活动。

实施单位：市图书馆、莆田市邮政分公司

24.在三清殿设立莆阳书院，每周六开设一期莆阳讲坛。以小读者为主要对象，举办两场 “倾听名家声音，感悟阅读与写作乐趣”活动，加强作家与读者互动，分享读书心得体会。

实施单位：市图书馆。

25.举办阅读讲座沙龙、开设少儿朗诵与主持人培训课程。

实施单位：市艺术馆，市朗诵协会。

26.在《湄洲日报》上开辟“三湾潮”和“书香版”文化专版，请名家开专栏，推介莆仙籍作家艺术家书籍，介绍国内外文学名著、文艺新作等。

实施单位：湄洲日报社。

   （十）启动“书香莆阳”微信公众号

27.在全民读书月期间，建立“书香莆阳”微信公众号。初期通过关注公众号，获赠移动数据流量的方式来吸收、扩大读者群。此后，及时宣传报道全民读书月活动，推荐优秀阅读书目等。通过长年设置摇大转盘、有奖竞答等方式，奖品可设置为流量、电子书券、实体书券等，增强全民关注阅读，让“书香莆阳”微信公众号成为书香莆田的集结号。

实施单位：市文广局、莆田移动分公司。

   （十一）“好书惠民”系列活动

28. 图书优惠销售。各书报刊亭及出版物门市部在第十届“书香莆田”全民读书月期间，张贴活动标语，开展优惠售书，延长营业时间，方便读者购书。

实施单位：新华发行集团莆田分公司、莆田邮政分公司、民营书店。

29. 优秀图书巡回展销。组织“书香莆田·悦读家园”精品图书巡展等活动，组织优秀图书进学校、社区、企业展销。

实施单位：新华发行集团莆田分公司、莆田市邮政分公司、仙游分公司、民营书店。

30.设立莆田籍作家近年出版的作品集专柜，邀请部分作家现场签名售书。

实施单位：市文联、市社科联、新华发行集团莆田分公司、民营书店。

31.优秀馆藏图书、精品图书阅读推荐活动。各级各类图书馆对读者进行读书宣传和针对性的阅读指导，并为读者进行咨询，引导广大群众多读书，读好书，增强读者的图书馆意识。

实施单位：市图书馆、莆田学院、各县区图书馆。

   （十二）“精准扶贫捐赠图书”活动

    32. 新闻出版行政部门、出版物销售单位共同向山区、沿海农家书屋捐赠图书不少于2000册。更新农家书屋出版物140万元，新建数字农家书屋50家。

    实施单位：市文广局、市图书馆、市新华书店、莆田市邮政分公司、民营书店。

   （十三）设立单位图书角

33.为丰富部队、医院、社区的文化生活，方便读者选购与阅读，组织开展图书流动供应，把服务引伸到部队、医院、社区。在全市三甲医院、市行政服务中心、部分社区等人员密集场所设立16个图书角，方便市民阅读。

实施单位：市新华书店。   

    六、活动要求

一要高度重视。“全民读书月”活动是一项社会性、群众性、公益性活动，各县区、各部门要从打造宜居港城、建设美丽莆田的高度，充分认识活动的重要意义，切实加强领导，认真组织实施。做好全民阅读中长期规划，积极探索全民阅读工作的长效机制。各县区、各部门根据本通知要求，因地制宜，精心制订2016年全民阅读活动工作方案、工作计划，加大全民阅读工作所需人员、经费等的投入，切实履行好全民阅读工作职责，共同推动全民阅读工作的开展。

二要全民参与。各县区、各部门要坚持面向基层、面向群众，用群众喜闻乐见的方式，多搭建群众便于参与的平台，多开辟群众乐于接受的渠道，把统一组织的阅读活动与群众自发开展的学习活动结合起来，使全民读书活动渗透到农村、企业、社区、学校、机关和社会组织，贯穿在人们工作、学习、生活的各个方面，成为人们自觉参与、自我教育、自我提高的过程。

三要营造氛围。各县区、各部门要大力宣传开展全民读书活动的重大意义和主要任务，倡导多读书、读好书的良好风尚。各级新闻媒体要认真制定宣传报道计划，开辟专栏专题专版，全方位、多层次报道各级各单位开展“全民读书月”活动的情况，推介好经验、好做法，为“全民读书月”活动的顺利开展营造浓厚氛围。

四要督促检查。市全民读书月活动组委会将采取定期督查和不定期抽查的形式，对整个活动进行督促检查，及时通报活动，确保活动取得实效。请各县（区）、各单位于11月5日之前报送一名联络员至“书香莆田”全民阅读组委会办公室，负责读书月活动期间及时报送有关工作信息、活动照片等资料，并于12月15日前将活动总结、图片、资料等报送“书香莆田”全民读书活动组委会办公室。（联系人：王星，联系电话：2623066,13959569809，电子邮箱：95502935@qq.com）
