莆田市文化和旅游局关于印发“百姓大舞台”文化惠民演出活动实施方案的通知

发布时间：2023-03-31 15:06
| | |
 各县区文体旅游局、湄洲岛旅游文体局、北岸党工委宣传部，市群众艺术馆：

“百姓大舞台”文化惠民演出活动列入省政府2023年重点工作。按照《福建省文化和旅游厅关于印发“福建百姓大舞台”文化惠民演出活动实施方案的通知》（闽文旅公共〔2023〕4号）相关工作要求，我局研究制定了《莆田市“百姓大舞台”文化惠民演出活动实施方案》，现印发你们，请结合工作实际，制定方案抓好贯彻落实。

                          

                              莆田市文化和旅游局

                               2023年3月24日


莆田市“百姓大舞台”文化惠民演出活动实施方案


一、活动宗旨

以习近平新时代中国特色社会主义思想为指导，深入宣传贯彻落实党的二十大精神、习近平总书记关于文化和旅游工作重要论述和来闽考察重要讲话精神、《公共文化服务保障法》等，以满足人民精神文化需求作为文旅工作的出发点和落脚点，以“学习宣传贯彻党的二十大精神，群众文化活动走基层”为主题，广泛开展内容充实、内涵丰富、形式多样、高效优质的文化服务，丰富公共文化服务供给，推动“百姓大舞台”文化惠民活动规范化、品牌化、创新性发展，满足人民群众对美好生活的新期待，不断增强获得感幸福感。

二、组织机构

“百姓大舞台”文化惠民活动由市、县区（管委会）分级组织举办。市级活动由市文旅局主办，市群众艺术馆承办；县区活动由各县区（管委会）文化行政部门主办，文化馆等部门承办。

三、工作任务

（一）统一名称标识。按照省文旅厅统一部署，我市“百姓大舞台”演出名称统一为“福建百姓大舞台（莆田xx)”；省文旅厅正组织开展标识征集活动，届时另行通知。

（二）固定活动模式。市、县区（管委会）各设立常态化“百姓大舞台”室外演出场所1个以上，定期开展文化惠民活动。市级每个演出场所每年开展惠民演出不低于25场次，各县区（管委会）每个演出场所每年开展惠民演出不得少于20场次。

（三）突出活动内涵。围绕春节、元宵、清明等传统文化节日和国家重要庆典、纪念日，以宣传和弘扬中华优秀传统文化、“福”文化、讲文明树新风、移风易俗、民族团结、乡村振兴、扫黑除恶等为重点，开展富有时代气息、体现节日文化内涵、具有鲜明价值导向的文化惠民演出活动。

（四）调动各方力量。落实《福建省文化和旅游厅关于<鼓励和引导社会力量参与“百姓大舞台”文化惠民演出实施办法>的通知》（闽文旅公共〔2019〕1号），通过政府主导、社会参与等做法，真正做到群众喜欢、群众参与，推动参与文化活动成为百姓生活的新时尚。主要实施对象如下：

1.全市公共文化服务机构、国有文艺院团及专业艺术院校；

2.全市除政府部门和文化机构单位以外的企业和社会组织，主要包括：（1）依法在登记管理部门登记的非营利性组织。含社会团体、民办非企业单位、基金会以及青年团体、工会等；(2）依法在工商管理或行业主管部门登记成立的企业、机构。含国有企业、私营企业、各种混合所有制企业；（3）其他公益单位。如学校、部队等不直接承担政府公共文化职能的公共部门；（4）新文艺组织。指非公有制文艺团体，含民营工作室、民营文化经纪机构等；（5）文化志愿服务组织；（6）其他非营利性、公益性的社会团体等。

 

（五）加强交流联动。市群众艺术馆要组织优秀参演团队（节目），通过县区互动和全市上下联动的艺术交流演出模式，将“百姓大舞台”文化惠民演出活动升级为联动实施的融合性群众文化品牌活动。市文旅局将适时就演出举办情况、节目质量、参演团队影响力和配合度、创新亮点、社会效益和宣传效应等方面开展调研。

（六）加大线上应用。省文旅厅在福建省数字文化馆开设“福建百姓大舞台”专区，定期向各地市征集优秀演出场次和节目进行展播，并纳入“国家公共文化云数字资源库”推荐范畴。市各县区（管委会）、群众艺术馆在活动推进过程中，要做好视频录制、线上直播等工作。

（七）提升演出水平。省文旅厅将采取线上投票点赞、线下专家评审等方式，评选出“福建百姓大舞台”季度优秀场次和节目，同时纳入“国家公共文化云平台”直播申报范畴；并于12月份开展“福建百姓大舞台”优秀节目大联展活动。各县区（管委会）、市群众艺术馆，要注重节目质量，组织更多优秀节目参加“百姓大舞台”演出，不断提升演出水平，积极参与省文旅厅组织的评选评比、成果大联展等活动。

四、工作要求

1.加强组织领导。将“百姓大舞台”作为深入实施“深学争优、敢为争先、实干争效”的具体行动，遵守“政府主导、各地联动、社会支持、群众参与”的基本原则，进一步强化组织领导，制定工作方案，细化工作措施，统筹协调各方力量，集聚资源，形成合力。

2.压实工作责任。按照“谁承办、谁审查、谁负责”的原则，牢固树立“安全第一”的意识，严格落实意识形态工作责任制和安全生产工作责任制，制定应急工作预案，做好参演节目的编排和审查备案工作，把好政治导向关、节目质量关、安全生产关。

3.扩大社会影响。充分运用文旅部门官网、微信、微博等公共文化宣传阵地，借助网媒、纸媒及新媒体等手段进行传播，提升活动的参与度和覆盖面，扩大活动知晓率和社会影响力。

4.做好材料报送。指定专人负责“福建百姓大舞台”文化惠民演出工作，要注重演出过程中视频、照片等资料录制、收集、报送等工作。各县区（管委会）、市群众艺术馆报送材料包含以下几项：

（1）3月28日前报送《联络人回执》（附件1）。

（2）每月20日前报送《“百姓大舞台”文化惠民演出活动情况表》（附件2）和相关图文资料。

（3）每月20日前报送至少1个演出场次、2个优秀节目的高清视频和《“百姓大舞台”演出内容意识形态审核情况说明》盖章扫描件（附件3）。视频需体现“百姓大舞台”活动标识，每场演出时间不超过60分钟，视频分辨率不低于1280X720，帧率：25码流，不低于8Mbps。

5.联系人及联系方式。

市文旅局：林益清，联系电话：2689939，

市群众艺术馆：吴争明，联系电话：2694388，邮箱：pt2251199@163.com。
