莆田市文化和旅游局关于公布第八批市级非物质文化遗产代表性传承人的通知

发布时间：2025-06-20 16:07
| | |
 市直有关部门，各县区文旅局，湄洲岛旅文局，北岸工委宣传部，市非遗保护中心：

为深入贯彻落实习近平文化思想和习近平总书记关于非物质文化遗产系统性保护工作的重要指示精神，根据《中华人民共和国非物质文化遗产法》《福建省非物质文化遗产条例》《福建省省级非物质文化遗产代表性传承人认定与管理办法》(闽文旅非遗〔2020〕2号)和《莆田市非物质文化遗产保护管理实施办法》（莆政办〔2013〕61号）的相关规定和文件精神,莆田市文化和旅游局组织开展了第八批市级非物质文化遗产代表性传承人申报和评审工作。经各县区（管委会）和市直有关单位申报、专家评审、局务会议审议、社会公示等规定程序,确定了第八批市级非物质文化遗产代表性传承人名单(共34人),现予以公布。

各单位要鼓励和支持非物质文化遗产代表性传承人开展传承传播活动，切实做好非物质文化遗产的保护传承工作，努力推动中华优秀传统文化创造性转化和创新性发展，为弘扬优秀莆田文化、助力文旅经济高质量发展作出更大贡献。

 

附件：莆田市第八批市级非物质文化遗产代表性传承人名单（共34人）
