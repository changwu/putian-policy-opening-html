莆田市文化广电新闻出版局关于确认莆田市第一次全国可移动文物普查普查员名单的通知

发布时间：2013-08-28 08:00
| | |

各县区文体广电出版局，湄洲岛社会事务局，北岸工委宣传部，局属有关单位：

根据省文化厅和省文物局联合转发文化部和国家文物局关于积极做好文化系统第一次全国可移动文物普查工作的通知（闽文物〔2013〕111号）精神，按照《福建省文物局转发国家文物局关于发放第一次全国可移动文物普查普查员证的通知》（闽文物字〔2013〕234号）要求，为做好我市第一次全国可移动文物普查工作，请各县区、各单位确定普查人员，并认真填写普查员信息登记表，于8月30日前报市普查办（挂靠市文广局）汇总，以便统一上报省文物局申领普查员证，并参加市普查办9月底举办的莆田市第一次全国可移动文物普查培训班。

特此通知。

联系人及联系电话：市文广局办公室  陈永杰  2696660

                  市文管办        黄海珊   2699655
