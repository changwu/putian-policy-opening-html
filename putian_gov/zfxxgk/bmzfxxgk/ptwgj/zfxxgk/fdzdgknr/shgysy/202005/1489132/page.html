莆田市文化和旅游局关于转发省文旅厅确定基层综合文化服务中心省级优秀示范点等名单的通知

发布时间：2020-05-13 16:17
| | |

各县区文化体育和旅游局，湄洲岛旅游局，北岸党工委宣传部、北岸文旅办：

现将《福建省文化和旅游厅关于确定2020年基层综合文化服务中心省级优秀示范点和提升服务效能补助名单的通知》《福建省文化和旅游厅关于确定县域文旅公共服务机构功能融合》转发你们，请按照文件要求，强化措施，扎实推进基层综合文化服务中心省级优秀示范点、2020年基层综合文化服务中心提升服务效能补助单位、县域文旅公共服务机构功能融合试点的工作落实，实现设施不断完善，服务不断提升，文化旅游有效融合，确保相关单位工作创出特色，示范带动，扩大影响。

要按规定加强资金使用和监督，确保专款专用，提高资金使用效益，并做好资金使用情况的绩效评估。

 

附件：1.福建省文化和旅游厅关于确定2020年基层综合文化服务中心省级优秀示范点和提升服务效能补助名单的通知

各设区市文旅局,平潭综合实验区旅游文体局：

2019年12月,我厅会同省财政厅联合下发了《关于提前下达2020年全省基层综合性文化服务中心示范建设奖补资金（中央公共文化一般项目）的通知》( 闽财教指〔2019〕141号)，确定在全省遴选支持一批村级综合文化服务中心提升服务效能，遴选培育一批基层综合性文化服务中心省级优秀示范点。年初，部署开展遴选推荐工作。在各地认真推荐和把关审核的基础上，经研究，确定福州市仓山区螺洲镇洲尾村综合文化服务中心等80个单位为提升服务效能补助单位，福州市晋安区寿山乡前洋村综合文化服务中心等33个单位为省级优秀示范点。现将名单印发给你们，并就相关事项通知如下：

一、高度重视，及早谋划

培育一批基层综合文化服务中心省级优秀示范点、支持一批基层综合文化服务中心提升服务效能，是我省2020年乡村文化振兴的重点工作，各地各单位要高度重视，纳入年度文旅工作重要议事日程，专题研究，部署落实；要将经费及时足额下拨到相关单位（其中，80个提升服务效能支持补助单位每个10万元，30个省级优秀示范点奖补单位每个30万元，具体名单详见附件），并建立公共文化服务单位挂钩帮扶工作机制，指导帮扶基层综合文化服务中心按照《关于提升基层综合性文化服务中心效能促进乡村文化振兴的通知》要求（闽文旅社〔2019〕1号），强化供需对接，建设特色文化设施、开展特色文化活动；要狠抓落实，及早谋划、及早推进、及早出成效。

二、明确用途，科学支出

此项工作目的在于培育基层综合文化服务中心特色典型，以点带面，示范带动全省基层综合文化服务中心提升效能，满足人民群众的精神文化需求。补助资金主要用于推进文旅融合、提升综合文化服务中心服务效能，支持建设非遗展陈室、乡贤文化展示馆、乡村小戏台等特色文化设施，开展乡村春晚、民俗等特色文化活动；重点用于三个方面：一是文化活动设施修缮和文化活动设备添置；二是组织开展乡村春晚等群众性文化活动；三是乡村文化振兴特色工作和文旅活动的宣传推介等。

三、注重统筹，提升效益

补助资金使用要注重统筹，发挥整体效能；要发挥财政资金撬动引领作用，通过众筹等方式，鼓励乡贤等社会力量捐资参与综合文化服务中心运营和群众性文化活动的组织开展；省级优秀示范点要着眼社会效益最大化，安排部分乡村文化振兴资金，用于参与省厅策划的上下联动互动的乡村春晚汇演、新媒体宣传推介等活动，形成声势和影响。

四、加强督查，提升绩效

各地各单位要按照《中央补助地方公共文化服务体系建设专项资金管理暂行办法》（财教〔2015〕527号），做好资金使用情况的绩效评估；要加强督查，省文旅厅将会同省财政厅适时组织开展专项检查，确保资金合规使用；要及时报送绩效评估材料，在今年9月底之前将补助点建设情况和资金使用绩效评估情况报送省文旅厅。

请各地按照《福建省文化和旅游厅转发<文化和旅游部公共服务司关于开展文化和旅游公共服务机构功能融合试点工作>的通知》要求及各试点单位2020年开展文族功能融合试点工作计划表、加强对基层的指导督促、精心组织工作实施，确保试点工作创出特色、形成影响。试点期间的先进经验或典型案例，请及时报送厅公共服务处。

各试点单位补助经费（每个15万元，不含厦门)已下达你市(闽财教指〔2019]141号），请及时拨付至试点单位，并做好经费使用的监督管理。
