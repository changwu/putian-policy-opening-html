莆田市文化和旅游局关于公布莆田市第十六届少儿故事大王比赛结果的通知

发布时间：2025-07-16 16:21
| | |
 各县区文化体育和旅游局、湄洲岛旅游和文化体育局、湄洲岛社会事务管理局、北岸党工委宣传部，市群众艺术馆：

根据《莆田市文化和旅游局关于举办莆田市第十六届少儿故事大王比赛的通知》（莆文旅〔2025〕36号）文件精神，莆田市第十六届少儿故事大王比赛于2025年6月份成功举办。本次比赛分设少儿故事大王比赛（低幼组、中幼组、学前组、小学低年级组、小学高年级组）和少儿小品比赛两个类别,共181个作品参加市级决赛。经专家评审和社会公示，共评选出一等奖作品20个、二等奖作品28个、三等奖作品44个，现予以公布。

 

 

附件:莆田市第十六届少儿故事大王比赛获奖作品名单
