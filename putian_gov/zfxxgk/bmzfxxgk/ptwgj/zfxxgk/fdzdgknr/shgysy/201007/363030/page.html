莆田市文化广电新闻出版局关于做好莆田市第一批文化产业示范基地评选命名工作的通知

发布时间：2010-07-30 08:00
| | |

各县区（管委会）文体局（社会事务办、文教局）：

我市具有独特的文化优势和厚实的产业基础，为进一步引导促进我市文化产业持续健康快速发展，积极培育市场主体，提高文化产业的总体实力和竞争力，充分发挥文化产业在扩内需、保增长、调结构等方面具有独特的优势，根据国务院《文化产业振兴规划》、省委办公厅、省政府办公厅《关于加快文化产业发展的意见》（闽委办发〔2009〕3号）和我市有关大力发展文化产业的文件精神，经研究，决定在全市开展第一批文化产业示范基地评选命名活动。现将有关事项通知如下：

一、评选范围

我市从事演出业、影视业、音像业、文化娱乐业、文化旅游业、网络文化业、图书报刊业、文物和艺术品业以及艺术培训等领域的各类所有制的文化企业。

二、评选基本条件

1、在发展文化产业方面做出显著成绩、在全市本行业中具有典型和示范意义，在全省乃至全国具有一定影响。

2、企业发展符合社会主义精神文明建设与国家文化产业政策的要求，坚持发展先进文化，坚持社会效益和经济效益的协调和统一。

3、所生产的文化产品和提供的文化服务能够面向市场，面向群众，有一定生产规模，社会效益和经济效益显著。

4、有一支坚强有力的管理团队和行之有效的内部管理制度，具有自主创新精神和市场开拓能力，企业保持较快的发展速度。

三、评选办法

1、各县区（管委会）文化企业向所在地的文体局（社会事务办、文教局）提出申请，市直单位直接向市文化广电新闻出版局产业办提出申请。

2．各申报企业应将企业的基本概况、企业的生产经营情况及所取得的社会效益和经济效益、企业的发展规划和发展战略填写入《第一批莆田市文化产业示范基地申报表》（见附件）中，并提交企业营业执照复印件（盖章）和开户银行提供的资信证明。

3．各县区（管委会）文体局（社会事务办、文教局），对申报的材料要严格审核，要按照评选的要求，认真做好候选单位的推荐申报的初审工作。

四、时间要求

各文化企业请于9月10日前将经县区（管委会）文体局（社会事务办、文教局）初审后的申报材料（一式三份），送至莆田市文化广电新闻出版局办公室，并发送电子文本。

五、其它事项

1、《第一批莆田市文化产业示范基地申报表》，请登录莆田市文化广电新闻出版局网站（www.ptwgj.gov.cn）“公告公示”或“下载专区”查询下载。

2、今年市级和省级文化产业示范基地的申报同步进行，凡申报省级文化产业示范基地的文化企业，须同时申报市级文化产业示范基地。我局将根据推荐情况，命名第一批莆田文化产业示范基地，并从中向省文化厅推荐申报第五批福建省文化产业示范基地。今后，凡申报国家和省级各类文化产业示范基地，必须是市级文化产业示范基地。

3、省级文化产业示范基地的申报要求，仍按日前发

出的《莆田市文化广电新闻出版局关于推荐第四批国家文化产业示范基地和申报第五批福建省文化产业示范基地的通知》（莆市文[2010]145号）要求进行办理。
