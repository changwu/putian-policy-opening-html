莆田市文化广电新闻出版局关于加强文化志愿服务工作的通知

发布时间：2013-02-19 08:00
| | |

各县区（管委会）文体广电出版局（社会事务办、文教局），市直文化系统各单位：

为完善我市公共文化服务体系建设，鼓励社会力量参与公益文化事业，保障广大人民群众的基本文化权益，不断满足广大人民群众日益增长的文化生活需求，积极发挥文化志愿者服务社会、服务大众的作用，现将有关事项通知如下：

一、目的宗旨

宣传、发动、组织开展社会文化公益活动，指导和推动文化志愿者队伍的建设，在全市建立一支有一定规模、具有较高素质的文化志愿者队伍，实现每1000人中拥有1名文化志愿者的目标，提高公共文化服务能力，进一步完善公共文化服务体系。通过引导文化志愿者自愿参与、义务工作、提升自我、服务社会，在全社会营造“传递爱心，传播文明”的氛围，共同促进社会和谐与进步。

二、建立文化志愿者协会

文化志愿者是指不以物质报酬为目的，利用自己的时间、文艺技能等，自愿为社会和他人提供公益性文化艺术服务和帮助的人群。

（一）成立市文化志愿者协会。由市群众艺术馆牵头，根据《中华人民共和国宪法》、《、《民法通则》、《行政许可法》和国务院《社会团体登记管理条例》有关规定，在2013年上半年成立市文化志愿者协会，并举办市文化志愿者协会成立大会暨志愿者招募启动仪式。

市文化志愿者协会下设文化志愿者协会办公室，挂靠市群众艺术馆；各县区（管委会）相应成立文化志愿者协会分支机构，依托各县区文化馆，具体负责文化志愿者的招募、培训、管理、后勤保障等工作，并及时通过网站、新闻媒体、信息栏等形式向社会发布相关信息。

（二）明确具体职责。一是制定招募、培训计划。在全市开展招募和培训文化志愿者活动，逐步完善文化志愿者队伍建设。二是参与组织与服务。协助或接受授权组织文化志愿者各相关活动，在活动中做好服务工作。三是建立、健全工作档案。包括文化志愿者基础档案、服务档案和活动档案等。文化志愿者基础档案，按专业、服务岗位、服务时段等项目对文化志愿者实行管理；文化志愿者活动档案，主要是全市性文化志愿者活动的情况收集与分门别类，包括基本情况、工作特色、典型事例、组织成效等。文化志愿者服务档案，包括基本状况、服务情况、累计服务时间的服务档案，作为奖励的凭证。四是做好个人信息保密工作。严格按照个人信息保密原则做好保密工作，未经本人同意，不得公开文化志愿者的个人详细信息。五是信息收集、工作联络和总结汇报工作。

三、招募文化志愿者

（一）招募条件

个人会员招募条件：

1.具有良好的思想品质、职业道德和良好的敬业精神；2.热爱公益事业，自觉践行志愿服务精神；3.具有较强的团队意识，有集体荣誉感；4.具备一定的文化专业知识或文艺专长；5.身体健康，每年自愿参加一定时间的文化志愿服务。

团体会员招募条件：

1.具有独立的法人资格；2.拥有一支具有文化、文艺特长的人才队伍；3.热爱公益事业，自觉践行志愿服务精神；4.每年自愿参加一定时间的文化志愿服务。

（二）招募程序

市文化志愿者协会可采取公开招募与定向招募相结合、经常性招募与阶段性招募相结合、面向个人招募与面向集体招募相结合等方式开展招募工作，建立健全高效便捷的志愿者招募机制、稳定通畅的招募渠道。市文化志愿者协会成立之前由群众艺术馆代行职责。

发布信息：根据志愿服务项目和岗位需求情况，通过报纸、电视、网络、广播、信息栏等多种形式向社会公开发布有关志愿者需求数量、岗位要求和报名方式等招募信息，为志愿者参与志愿服务创造便利条件。

报名方式：有意参加文化志愿服务且符合条件的社会各界人士和团体，通过两种方式报名：一是携身份证或相关证件到市、县区、乡镇文化部门指定的单位填写《莆田市文化志愿者报名表》报名；二是到莆田市文化广电新闻出版局（http://www.ptwgj.gov.cn/）、莆田市群众艺术馆（www.ptsqzysg.com/）网站下载报名表格，填写清楚后发送到ptwhzyz@163.com报名。

资格确认：收到申请人资料后，市文化志愿者协会将在30天内对其进行资格审核；经批准确认后，即为注册文化志愿者，由市文化志愿者协会统一颁发文化志愿者证书。

（三）主要职责

文化志愿者具体承担以下工作：一是丰富基层群众文化生活。以文艺辅导为主，深入社区、农村开展文化辅导工作。二是传播文化知识。以讲座、培训为主，面向基层群众开展专题讲座和文艺辅导。三是展示文化建设成果。协助组织大型文化活动等。

（四）激励措施

为鼓励和表彰优秀文化志愿者，建立文化志愿者激励机制。主要以建立文化志愿者服务时间统计和绩效评价等制度，作为考核和表彰文化志愿者的依据。

享受优惠待遇：文化志愿者可优先享受各级文化部门组织或提供的艺术（演出）观摩、培训、文化艺术消费等优惠待遇。在条件许可的情况下可优先参加各级文化部门组织的有关集体活动。

获得表彰鼓励：经各级文化部门评选推荐，对服务时间长、表现突出、社会评论好的优秀文化志愿者，由市、县区文化行政部门进行表彰，并颁发优秀文化志愿者荣誉证书。

参与星级评选：依据志愿者的服务时间和服务业绩每年度开展“星级”文化志愿者评选活动，主要评出三个等级：从高到低分别为：五星、四星、三星。星级文化志愿者优先享受优惠待遇与评先评优。

（五）退出机制

文化志愿者可以自愿退出。自愿退出者，应经书面申请确认，并办理退出注销手续。

有下列行为之一的，市文化志愿者协会可取消其文化志愿者资格，并办理退出注销手续，书面通知其本人。

1.有违法违规行为，造成严重后果的；2.以文化志愿者或者服务单位的名义组织或者参与违反文化志愿者服务原则的活动，并损害了服务单位声誉的；3.不服从服务单位工作安排，总累计缺岗次数达10次（含）以上，或总累计未请假缺岗5次（含）以上。

四、具体要求

（一）加强组织领导。全市各级文化部门要高度重视文化志愿者机构、队伍建设工作，将文化志愿者服务作为“十二五”文化工作重点加以落实。市文化志愿者协会根据各级文化行政主管部门的工作要求，规划、组织、开展和参与各类文化活动。近期重点组织文化志愿者参与文化激情广场服务、幸福家园试点村文化服务，推动并丰富试点村群众文化活动。

（二）强化日常管理。各级文化部门协助文化志愿者协会开展文化志愿服务，市文化志愿者协会开展上岗培训和定期业务培训培训，为文化志愿服务提供交通、安全、卫生等必要的工作条件。

（三）注重宣传推广。做好文化志愿者的公益宣传工作，通过报刊、宣传栏、网站等形式，特别是在文化部门的网站开辟“文化志愿者”专栏，弘扬文化志愿者奉献、友爱、互助的高尚精神，表彰优秀文化志愿者，鼓励和吸引广大市民和外来建设者，尤其是有一定文艺专长和艺术才华的专业人士积极参与到文化志愿者行列中来。

（四）鼓励社会参与。引导吸纳企业、社会团体、赞助商对文化志愿者服务队伍进行资助或捐赠，为文化志愿服务提供必要的经费保障。
