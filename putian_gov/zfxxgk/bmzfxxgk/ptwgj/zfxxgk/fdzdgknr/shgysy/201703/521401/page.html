莆田市文化广电新闻出版局关于落实市委市政府2017年为民办实事项目的通知

发布时间：2017-02-07 09:09
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属有关单位：

根据《中共莆田市委莆田市人民政府关于开展2017年为民办实事活动的通知》（莆委〔2016〕76号）、《莆田市人民政府办公室关于印发推进基层综合性文化服务中心建设实施方案的通知》（莆政办〔2016〕189号）精神，为切实做好村（社区）综合文化服务中心示范点(以下简称示范点)项目建设，现就有关事项通知如下：

一、工作目标

2017年全市建成示范点20个，配套建设文体广场，并完善相关设施和服务功能，基本实现宣传文化、青少年活动、党员教育、科学普及、普法教育、体育健身等综合服务功能。其中，每个县区（管委会）至少利用祠堂、寺庙、旧民居等建设1个示范点。

二、资金及名额安排

每个示范点需要建设经费20万元，由各县区（管委会）财政各自承担。名额分配如下：仙游县4个，荔城区3个，城厢区3个，涵江区4个，秀屿区3个，湄洲岛1个，北岸2个。

三、建设要求

    各县区（管委会）按照《莆田市村（社区）综合文化服务中心建设服务基本标准》推进示范点建设，要求如下：

（一）设施要求。通过新建、整合利用、盘活存量等方式，主要以村（社区）文化室、村（社区）党组织活动场所、住宅小区公共服务配套设施、闲置校舍、办公场地以及其他公共服务设施为基础进行整合建设，鼓励结合祠堂、旧民居等进行整合利用。村（社区）综合文化服务中心面积不低于200平方米，基本功能标准包括1个宣传栏、1间图书室（可供借阅的实用图书不少于1500册，定期更新）、1间多功能室、1间科普活动室、1间广播室、1间文体活动室、1套文体设备（包含群众体育活动器材、简易音响及乐器等文艺器材）、1个农村电影固定放映点等。按照人口规模和服务半径，建设选址适中、与地域条件相协调的文体广场，面积不低于500平方米（有阅报栏、灯光等设施）。

（二）服务功能。发挥基层综合性文化服务中心的终端平台优势，整合分布在不同部门、分散孤立、用途单一的基层公共文化资源，实现人、财、物统筹使用。每个基层综合文化服务中心配有电脑、电视、多媒体设备、便携式音响、图书期刊（或电子图书期刊）、健身器材、乐器、书画等文艺器材，基本具备文艺演出、党员教育、科学普及、读书看报、广播电视、电影放映、文体活动、展览展示、教育培训等公共文化服务功能。

 （三）队伍建设。村（社区）综合文化服务中心由村“两委”确定1名专职或兼职工作人员，可购买服务等方式解决人员不足问题。扶持具有地域或民族特色的民间文艺团队和艺人，充实基层文化骨干力量，引导发展广场舞、戏曲、书画、读书等爱好者队伍。发挥文化志愿者、乡贤、文化能人等作用，吸纳有关方面代表、各界群众参与管理。

    四、工作步骤

（一）动员部署阶段（2017年2月底前）。按照上级有关要求，在充分调研的基础上，制定下发工作方案。

（二）开展选址阶段（2017年3月底前）。各县区（管委会）在3月30日前完成示范点选址工作。

（三）全面建设阶段（2017年4月—2017年11月）。按照建设要求，全面推进示范点建设。

（四）评估验收阶段（2017年11月—12月）。由市文广局成立村（社区）综合文化服务中心示范点建设验收小组，对各县区（管委会）示范点建设工作进行检查验收。

五、保障措施

（一）加强组织领导。市委市政府为民办实事项目是保障民生的一项重要工作,各县区（管委会）文化行政部门要进一步提高思想认识，从讲政治的高度，切实增强责任感和使命感，落实一把手负责制，明确分管领导和具体责任人；要结合本地实际，认真选点，严格把关；要加强与财政部门的沟通协调，确保资金及时到位；要确保各项工作措施到位，加大项目建设推进力度，务求把实事办好办实。

    （二）强化服务指导。各县区（管委会）文化行政部门要加强与国土、规划、住建、科技等部门配合，充分发挥县区文化馆、乡镇（街道）综合文化站的骨干作用，加大服务和指导力度，有序推进村（社区）综合文化服务中心示范点建设。

    （三）提升管理水平。要加强对项目建设专项资金使用的监管，依照规定专款专用，确保年内按时完成建设改造任务。要按照属地管理的原则，在群众自我管理的基础上，创新管理方式、活动形式和组织方式，提升活动内涵。要及时总结、大力宣传村（社区）综合文化服务中心示范点建设的好做法、好经验，发挥示范作用，培育活动品牌。

六、材料报送

请各县区（管委会）文化行政部门按照名额安排，根据本地实际情况，有序推进村（社区）综合文化服务中心示范点建设，并按要求报送相关材料。选址情况（填报附件1）于3月30日前报送；从4月份开始，每月25日前报送本月工作进度（填报附件2）。联系人：林立；邮箱：pt2696660@163.com；联系电话（传真）：2689939。
