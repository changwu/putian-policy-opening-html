莆田市文化广电新闻出版局 莆田市教育局关于公布2016年第二届“海峡杯”闽渝台三地少儿歌手大奖赛莆田赛区选拔赛结果的通知

发布时间：2017-02-22 09:31
| | |

各县区（管委会）文体广电出版局、教育局（社会事务局）、北岸工委宣传部，市直有关学校、市儿童活动中心幼儿园、市机关幼儿园:

    根据市文化广电新闻出版局、市教育局《关于举办2016年第二届“海峡杯”闽渝台三地少儿歌手大奖赛莆田赛区选拔赛的通知》（莆市文〔2016〕172号）要求，莆田市第二届“海峡杯”闽渝台三地少儿歌手大奖赛莆田赛区选拔赛已于2016年11月22日—29日举行。通过各县区选拔，参加市级复赛的选手共有172名，分幼儿组、儿童A组、儿童B组、少年A组、少年B组进行比赛。经过紧张激烈的角逐，共评出一等奖28名，二等奖36名，三等奖47名，指导教师75人，现将获奖名单予以公布。

 

附件:2016年第二届“海峡杯”闽渝台三地少儿歌手大奖赛莆田赛区选拔赛获奖名单
