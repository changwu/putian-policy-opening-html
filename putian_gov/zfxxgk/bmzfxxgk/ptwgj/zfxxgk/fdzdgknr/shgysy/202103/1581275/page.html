莆田市文化和旅游局关于开展2021年全市印刷企业年度报告工作的通知

发布时间：2021-03-19 08:53
| | |

各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部，市印刷行业协会，有关印刷企业：

为加强对印刷业的监督管理，按照福建省新闻出版局《关于开展2021年印刷企业年度报告和国家印刷示范企业年度考核工作的通知》（闽新出〔2021〕18号）要求，决定开展2021年全市印刷企业年度报告工作。现将有关事项通知如下：

一、指导思想

为贯彻落实党的十九届五中全会、省委十届十一次全会和市委有关精神，聚焦建成社会主义文化强国的目标，坚持正确出版印刷导向，坚持把社会效益放在首位、社会效益和经济效益相统一，牢牢掌握维护意识形态安全的主导权，迎接庆祝中国共产党成立100周年，推动我市印刷业高质量发展。

二、年度报告工作

2020年12月31日前，所有已领取《印刷经营许可证》的印刷企业、单位及个人，均要参加年度报告工作。印刷企业年度报告采取网上提交的方式进行，印刷企业注册登陆“福建印刷发行行业管理系统”（网址：http://220.160.52.134:8081/PrintManagement/），如实填报《2021年印刷企业年度报告表》，再由各级行政管理部门依管理权限对辖区所有印刷企业进行网上数据核查掌握后逐级上报。

1.企业注册及网上填报

（1）网上填报。未注册过的印刷企业登陆“福建印刷发行管理系统”，填写企业真实信息，注册信息经系统管理员核实通过后，获得用户权限，进行数据填报，确认数据无误后点击报送（企业网上填报数据未提交时可进行保存与修改，点击报送后，未经系统管理员同意，将无法数据修改）。已注册并完成填报的企业可使用已注册的企业账号与密码进行登陆，新建2021年度报告表进行填报。

（2）材料提交。各企业经网上填报并按属地管理权限由相应行政管理部门核查通过后，企业只需在系统中进行填报后提交上传加盖企业公章的填报内容确认证明即可（具体范本在系统中将有提示，请根据提示进行上传）。各企业在完成网上年报工作后，要将经营许可证原件副本和回邮收件人姓名、地址和联系手机号码邮寄至发证部门，其中出版物印刷企业、数字印刷企业、外商投资印刷企业寄至中共福建省委宣传部印刷发行处（地址：福州市晋安区六一北路233号新闻大厦807室张帅收，电话0591-87629052）；市文旅局发证的印刷企业年度报告工作由市局会同市印刷协会共同开展，材料由市印刷协会秘书处负责收集（地址：莆田市荔城区西天尾吴江村1号康启来收，13860902483，513050812@qq.com），市印刷协会汇总后报送市局。管理部门收到副证后将加盖年度报告章。

2.行政管理部门核查流程

（1）注册内容核查。各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部对辖区内新注册的印刷企业名称、印刷经营许可证号、统一社会信用代码进行核实，核对无误后给予注册通过；不予通过的，请联系并告知原因（含填写错误、恶意注册等）。其中，出版物印刷企业、数字印刷企业和外商投资印刷企业注册登记由省局负责审核。

（2）企业数据填报核查。各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部要对辖区内所有注册成功并提交印刷企业年度报告的企业上报数据进行核查，属上级管理权限的企业，要对企业数据核查后再逐级进行上报。对数据发生异常变化的，要提供相关情况说明；对基本内容出现填写错误或产生漏填和概念性理解错误的，要退回并提醒企业更正。

三、有关要求

(一)高度重视。各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部和市印刷行业协会要高度重视，落实国家“放管服”改革要求，落实意识形态工作责任制，落实属地管理原则，严格遵照新冠肺炎疫情防控要求，通过“无接触”方式开展有关工作，将任务落细落小落实，压实工作责任。

(二)传达到位。确保所有印刷企业知晓年报时限、方式和要求，与往年不同，除个别证件到期外，企业完成填报后只要将《印刷经营许可证》副本交至管理部门加盖年度报告确认章。

(三)认真核查。各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部要严格组织年报内容核查，重点加强对企业基本情况数据、现有设备和绿色印刷实施等情况进行核对，避免出现企业报告数据误差大、非绿印企业错报和“万元”单位换算不准确以及所获国际奖项填报栏错报等情况发生。

(四)加强监管。各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部要对不按规定时限报告的印刷企业，将其列为重点监管对象，并采取突击检查的方式，对重点监管对象落实“五项制度”、守法经营等情况进行检查，发现违法违规行为要给予行政处罚并及时通报有关情况。

(五)及时报送。各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部要在3月30日前，向市局报送《2021年印刷企业年度报告工作总结》（含重点监管对象名单）和有关表格。
