莆田市文化和旅游局关于收集文旅产业战线开放招商有关事项工作情况的通知

发布时间：2020-04-03 09:33
| | |

各县区文化体育和旅游局、湄洲岛旅游局、北岸党工委宣传部、北岸文旅办：

为积极做好全市文化旅游招商项目策划工作，打好文旅产业战线开放招商工作基础，市局正在收集文旅招商优惠政策、规划编制、项目策划等情况，以更好地指导制定全市的招商政策和项目策划。具体内容如下：

一、本辖区内各类和文旅共享叠加的优惠政策；

二、本辖区总体规划、文旅发展规划或专项规划，以及景区景点相关规划、文旅项目规划（或概念方案、工程可行性研究报告或初步初设、施工图设计等）等；

三、本本辖区文旅产业战线开放招商项目基本情况（含推进项目、储备项目、策划项目）。

请各单位积极收集汇总，并于2020年4月15日下班前将优惠政策文件、规划文本图纸及附件表格电子版发至pt2696660@163.com。

 

附件：1.   县区（管委会）文旅产业发展政策汇总表

2.   县区（管委会）文旅相关规划编制情况统计表

3. 2020年全市文旅产业战线开放招商项目情况一览表

 

                                             莆田市文化和旅游局
