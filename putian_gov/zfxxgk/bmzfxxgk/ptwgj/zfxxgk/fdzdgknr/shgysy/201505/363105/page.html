莆田市文化广电新闻出版局关于印发2015 -2017年度创建全国文明城市测评体系任务分解表的通知

发布时间：2015-05-25 08:00
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部，局属各单位，机关各科室：

为认真做好2015-2017年度全国文明城市创建工作，根据莆田市文明委《关于印发<莆田市创建全国文明城市测评体系任务分解表>有通知》(莆文明委〔2015〕6号)文件精神，结合本系统工作实际，制定了《2015-2017年度莆田市文化广电新闻出版系统创建全国文明城市测评体系任务分解表》，现印发你们。请各单位按照责任分解要求，认真组织实施，确保按期完成各项工作任务。

 

                        莆田市文化广电新闻出版局
