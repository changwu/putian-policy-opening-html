莆田市文化广电新闻出版局 莆田市教育局关于公布莆田市第五届少儿故事大王比赛结果的通知

发布时间：2015-01-05 08:00
| | |

各县区文体广电出版局、教育局，湄洲岛社会事务局，北岸工委宣传部，市直有关学校、市儿童活动中心幼儿园、市机关幼儿园:

根据市文化广电新闻出版局、市教育局《关于举办莆田市第五届少儿故事大王比赛的通知》（莆市文〔2014〕173号）要求，莆田市第五届少儿故事大王比赛已于10月2日—6日举行，本次比赛分设幼儿组、小学组，其中幼儿组分为低幼、中幼、学前组；小学组分为小学初级组（1—3年级）、小学高级组（4—6年级）。通过各县区选拔，参加市级复赛的选手共有名。经过紧张激烈的角逐，共评出一等奖70名，二等奖92名，三等奖113名，优秀辅导教师275人。现将获奖名单予以公布。

 

 

附件:莆田市第五届少儿故事大王比赛获奖名单

 

 莆田市文化广电新闻出版局       莆田市教育局

 

                          2015年1月5日
