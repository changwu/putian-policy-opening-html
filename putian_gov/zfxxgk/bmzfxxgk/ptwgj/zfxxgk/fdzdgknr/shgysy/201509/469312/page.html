莆田市文化广电新闻出版局关于做好第八届海峡两岸（厦门）文化产业博览交易会参展工作的通知

发布时间：2015-09-25 08:00
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部：

接省文化厅通知，第八届海峡两岸（厦门）文化产业博览会将于2015年10月30日至11月2日（会期4天）在厦门国际会议展览中心举行，我市届时将组团参展，参展组织工作由我局负责。现将有关事项通知如下：

一、主要任务

1. 工艺美术展区60个标摊以上（每个标摊9㎡）；重点组织工艺美术名家名师参展，重点组织木雕类工艺作品参与由中国工艺美术学会等主办的“中华工艺精品奖”、“中华工艺优秀作品奖”评选。

2. 项目签约合同总额30亿元以上；

二、主要活动

（一）开馆式及领导参观展览

时 间：10月30日上午9：00

地 点：厦门国际会议展览中心

（二）展览交易活动

时  间：10月30日-11月2日

地  点：厦门国际会议展览中心及市区分会场

（三）论坛、对接会活动（待定）

主论坛——“走进自贸、走进海丝”中国艺术品市场高端论坛

项目对接会——文创商业对接会

产业大会——数字内容产业大会及对接会

产业对接会——自贸区文化产业对接会

时  间：10月30日-11月2日

地  点：厦门国际会议展览中心

（四）评奖颁奖

本届文博会将设置涵盖两岸工艺界并由两岸专家共同评选的“中华工艺精品奖”、“中华工艺优秀作品奖”、“高校设计奖”等专业奖项及由组委会评选的最佳展览展示奖、优秀组织奖。

时  间：10月30日-11月2日

地  点：厦门国际会议展览中心

（五）各分会场活动

时  间：10月30日-11月2日

地  点：厦门

（六）两岸高校设计展

时  间：10月30日-11月2日

地  点：厦门国际会议展览中心

（七）红点设计营商周

时  间：10月30日-11月2日

地  点：厦门国际会议展览中心

（八）福建省最具创意文化产品奖及展示

时  间：10月30日-11月2日

地  点：厦门国际会议展览中心

（九）其他配套活动

两岸文博大讲堂等活动。

三、任务分工

1.市文广局：作为我市参展协调机构，负责对接省组委会和省文化厅，组织协调参展各项筹备工作，按工作进度召开相关会议，指导协调、检查落实相关任务完成情况，并定期通报；负责牵头组织参展企业和我市企业馆布展工作；展会期间相关数据统计、汇总上报；负责参展主要活动的组织协调；会同市委宣传部、市广电中心、湄洲日报社做好新闻宣传工作。

2.各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部：

（1）分别提供本地1个以上投资额5亿以上的项目，签约项目需提供项目名称、项目简介、签约双方单位名称、联系电话。

（2）负责提供本地需要宣传推介的音像资料，协助提供布展所需的相应文字、图片等资料。

（3）提供本地文化产业招商项目资料。

（4）负责组织本地参展工作。（以上10月9日前完成）。

四、经费安排

1.按照“少花钱、多办事”的原则，节约经费开支。经费预算进行分级负责，县区经费纳入县区财政预算；莆田市企业馆展馆布置、资料印刷等参展经费纳入市财政预算。

2.市直有关单位、各县区（管委会）根据工作需要自行组织参加，费用自理。

3.参展企业摊位租金按每个标摊3000元计算，企业自行承担50%，市财政补贴50%。参展企业按照实际使用摊位个数的总费用的50%上交我局汇总后统一缴纳。企业其他参展费用自理。报名截止日期为：2015年9月30日。

4.参展企业的展览尤其是特装布展要严格遵守组委会提出的限高限宽、消防安全等要求。
