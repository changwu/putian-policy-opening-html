莆田市文化广电新闻出版局关于推荐第二届全国“书香之家”暨福建省第二届“书香之家”的通知

发布时间：2015-08-31 08:00
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，市直有关单位:

    按照福建省新闻出版广电局印发《关于开展第二届全国“书香之家”暨福建省第二届“书香之家”推荐活动实施方案的通知》要求，结合我市实际，决定在全市范围内开展第二届全国“书香之家”和福建省第二届“书香之家”推荐活动。现将有关事项通知如下：

一、推荐范围

凡有莆田市户籍的家庭或在莆田市居住1年以上的家庭均可参加推荐活动。已入选首届全国“书香之家”的家庭不再参加本届推荐。

二、推荐标准

1．家庭成员热爱祖国，遵纪守法，拥护党和国家的方针政策，家庭和睦，崇尚健康、科学、文明的生活方式。有良好的社会公德、职业道德、家庭美德、个人品德。

2．家庭成员热爱阅读，具有良好的读书习惯。推荐全国“书香之家”的原则上要求家庭成员平均每日阅读时间在2小时以上；省“书香之家”的原则上要求庭成员平均每日阅读时间在1小时以上。

3．家庭成员爱书、藏书，订阅报刊杂志。家庭每年有一定支出用于购买书箱、订阅报刊；有一定的藏书数量，且藏书质量较高。

4.家庭成员积极参加各种形式的读书活动，利用传统媒介和现代网络，接受各类信息教育；经常参与图书馆（室）的借阅活动，参加过读书节、读书竞赛及各类读书交流和专题讲座等活动。

5.家庭成员学有所长、学以致用，有突出的阅读成效。要有通过读书给工作、生活、学习、子女教育、作品创作带来的帮助等阅读成果，在邻里、社区、村镇或工作单位等具有一定知名度、影响力，能够鼓舞带动周围群众阅读。

三、推荐程序及要求

1、要发动广大家庭成员以家庭为单位广泛开展推荐活动，通过组织推荐和个人自荐相结合的方式，开展第二届全国“书香之家”暨福建省第二届“书香之家”推荐活动。要参照评选标准，经严格审核和实地考察核实后，按时报送推荐的候选家庭材料（附件2、附件3）。全市共推荐全国“书香之家”候选家庭3个、省“书香之家”候选家庭10个（分配名额详见附件1）。

2. 推荐的候选家庭将在省新闻出版广电局和“书香八闽”网站上进行公示，公示无异议后确定入选家庭名单。在公示期间有异议并经核实存在问题的，将取消入选资格。

3. 国家新闻出版广电总局将于2016年“4·23世界读书日”期间，对入选全国“书香之家”家庭进行表彰。我省也适时对省“书香之家”的家庭进行颁奖。

4、推荐活动重在吸引基层群众积极参与，通过宣传先进典型，发挥全民阅读先进典型的引领示范作用，推动全民阅读活动健康发展。充分发挥宣传、财政、教育、民政、文化、工会、共青团、妇联等部门的作用，吸引基层群众参与推荐活动。

5、推荐候选家庭时要以基层和普通群众家庭为主，深入挖掘基层和普通群众家庭感人的读书事迹、读书故事。对于贫困地区和少数民族地区热爱阅读的家庭，可适当放宽条件，并予以倾斜。

6、推荐审核工作要严格标准，确保质量。坚持公平、公正、公开的原则，确保先进性、典型性和代表性。

     申报材料由各县区（管委会）文体广电出版局（湄洲岛社会事务局）、北岸工委宣传部或市直有关单位审核、盖章后，于2015年10月20日前报送市文化广电新闻出版局（市政府2号楼327室，联系人：张玉应，电话2623066），同时电子版发至邮箱：1286882925@qq.com。
