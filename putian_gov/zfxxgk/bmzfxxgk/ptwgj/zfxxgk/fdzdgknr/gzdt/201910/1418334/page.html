关于组织观看故事影片《黄大年》的通知

发布时间：2019-10-09 11:52
| | |

各县区文化体育和旅游局、湄洲岛社会事务局、北岸工委宣传部、北岸文旅办，教育局、总工会，市直各有关单位、各学校：

为贯彻落实习近平总书记对黄大年同志先进事迹的重要指示精神，结合庆祝中华人民共和国成立70周年和“不忘初心、牢记使命”主题教育，电影《黄大年》将于10月31日起在我市上映。现将福建省电影局、中共福建省委省直机关工作委员会、省教育厅、省总工会联合下发的《关于组织观看故事影片<黄大年>的通知》（闽影〔2019〕65号）文件转发给你们，请各单位积极组织广大党员干部、职工和师生观看。

组织观看电影联系人：张  娟15080049968

                    程家乐15980223607

 

附件：《黄大年》订票回执单

 

 

 

 

莆田市文化和旅游局      中共莆田市委市直机关工作委员会

 

 

 

 

莆田市教育局                 莆田市总工会         

            2019年10月9日        



附件2

 

请各单位结合“庆祝新中国成立70周年”、“不忘初心、牢记使命”等主题教育活动，积极组织党员、干部、职工、师生观看，系统单位可统一组织观看或将文件通知转发到下属单位分批组织观看，具体组织观看有关事项如下：

一、放映时间：2019年10月31日启动放映，具体观景时间请各单位与发行放映工作联系人沟通确定。（提供送票上门服务）

二、放映地点：莆田万达影城。（莆田万达广场2号门4楼）

三、票价：50元/张。

四、发行放映工作联系人：张娟 15080049968；程家乐15980223607。
