莆田市文化和旅游局关于举办“好生活 颂党恩”莆田市首届方言曲艺韵诵比赛的通知

发布时间：2021-03-29 15:02
| | |

各县区文化体育和旅游局，湄洲岛旅游和文化体育局，北岸工委宣传部，市群众艺术馆，市直有关单位：

今年是中国共产党成立100周年，我局将于“七一”前夕举办“好生活 颂党恩”莆田市首届方言曲艺韵诵比赛，采用方言曲艺韵诵这一弥足珍贵具有浓郁的地方特色和乡土气息、群众喜闻乐见的非遗艺术形式，讴歌党百年历程的丰功伟绩，激发广大人民群众的爱党爱国热情。现将有关事项通知如下： 

一、组织机构

主办单位：莆田市文化和旅游局

承办单位：莆田市群众艺术馆

二、名额安排

仙游县、荔城区、城厢区、涵江区、秀屿区各至少选送5个作品，湄洲岛、北岸各至少选送3个作品，老年大学等市直单位可各选送1-2个作品参加总决赛。选送的作品尽可能涵盖赞句、快板、三句半这三种韵诵类别。

三、参赛要求

（一）作品积极健康，可以是反映展示莆田山川风物、人生礼俗、岁时节庆等传统的内容题材，也可以是反映移风易俗、文明风尚、扫黑除恶等宣传党和国家方针、政策、倡议以及讴歌新时代的题材。

（二）作品可一人或多人组合参赛，相同的人员组合，仅限报一个作品参赛。

（三）使用方言参加比赛，讲究方言的合辄押韵，赞句比赛的“喊好”环节可使用录音或另行安排2人现场互动；快板比赛现场可使用竹板或者其他器物击打节拍；三句半比赛现场可以使用锣、鼓、钹、碰铃等打击器乐加强气氛。

（四）根据作品表现需要，可适当编配动作以及变化队形站位，但不能以动作或舞蹈编排弱化语言的主体性，评审更多注重评测作品内容的语言表现和韵律使用。

（五）参赛者为一个人的，比赛时间限定在两分钟内，双人或多人组合参赛的，比赛时间限定在5分钟之内。

（六）演员根据作品表现需要，自行选择特色服装。

四、评分标准

（一）评审分制

总分按一百分制评定，分四个档次量分。

A档：95-100分 B档：85-94分 C档：75-84分 D档：60-74分

（二）评审标准

1.方言流利，咬字清晰，声音洪亮，白读或文读运用自如，俚言俗语驾轻就熟。

2.合辄自然，押韵巧妙，遣词造句贴切生动，语言韵味独特，富有艺术感染力。

3.鼓励原创，常中见奇，熟中见巧，能在传承中发展创新。

4.肢体动作恰到好处，热情而不浮夸，生动而不单调。能张弛有度，调动气氛，台风自然大方。

五、奖项设置

按照得分高低排序，一等奖比例不高于20%，二等奖比例不高于30%，三等奖比例约占50%。颁发证书和奖金。

六、材料报送

各县、区（管委会）文化行政部门和市直有关单位指定专人负责比赛的报名和选拔工作，并6月10日前汇总材料（见附件1，附件2），报送市群众艺术馆。联系人：吴争明，联系电话：0594-2694388。电子版材料发至邮箱：pt2251199@163.com。
