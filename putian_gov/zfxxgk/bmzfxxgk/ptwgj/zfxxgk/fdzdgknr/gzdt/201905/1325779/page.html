莆田市文化和旅游局关于做好第三届莆田市旅游协会换届筹备工作有关事项的通知

发布时间：2019-04-11 10:06
| | |

各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸工委宣传部、北岸文旅办，行业管理科：

第二届莆田市旅游协会任期已满，根据《国务院社会团体管理条例》《莆田市旅游协会章程》要求，为充分发挥莆田市旅游协会在协调行业服务规范、推进行业自律、提高行业服务质量、维护行业合法权益、推动行业健康发展中的重大作用，使政府职能部门和行业协会两支力量真正形成合力，共同做大做强我市文化和旅游产业，莆田市旅游协会拟于近期开展换届工作，并筹备成立旅行社、酒店、景区、导游四个协会专委会。为确保新一届会员大会按时召开和换届选举工作顺利进行，现将有关事项通知如下：

一、推荐范围

全市所有旅行社（含分社、营业部）、旅游景区（含乡村休闲集镇、旅游村等）、酒店（含非星级酒店、民宿等）、旅游车队、旅游集散中心、旅游工艺品公司等旅游企、事业单位。

二、推荐条件

（一）会员（含个人会员与单位会员）条件

1.拥护本协会章程，自愿加入本协会；

2.在旅游行业内具有一定影响的相关的社会团体和企事业单位及与旅游相关的组织；

3.在涉旅的事业、企业单位干部职工中，通过动员、协商，原则上吸收为市旅游协会的会员。

（二）理事单位条件

1.企业实力强，经营信誉高；

2.对文化和旅游产业发展给予热心支持的社会团体、企事业单位；

3.在旅游行业中有一定影响力；

4.在会员单位中选举产生，主动接受文化和旅游部门管理，热心协会工作；

5.在参会会员单位中，可推荐出30%的优秀会员单位为理事单位。

（三）常务理事单位条件

1.企业实力强，经营效益高，社会信誉好；

2.在全国、全省、全市旅游行业中有一定知名度、影响力；

3.热心和支持协会工作，积极参与协会倡导的文化和旅游行业活动；

4.在理事单位中选举产生，对我市旅游行业有特殊贡献者；

5.在理事单位中，可推荐出30%左右的优秀理事单位为常务理事单位。

三、工作要求

（一）请各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸工委宣传部、北岸文旅办认真做好会员（含个人会员与单位会员）、理事单位、常务理事单位的推荐工作，全市所有在册专兼职导游人员由行业管理科组织发动。

（二）所有参加协会的会员都应填写个人或单位会员申请表（见附表1、附表2）一式两份，一份由各县区（管委会）文旅部门留底，一份随同汇总表（见附表3、附表4）于4月19日下午上班前报送莆田市旅游质量监督管理所。汇总表电子版请发送至邮箱ptly0594@163.com。
