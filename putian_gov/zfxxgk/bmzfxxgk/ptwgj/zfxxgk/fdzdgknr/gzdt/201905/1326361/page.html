莆田市文化和旅游局关于做好文化旅游特色村建设工作的通知

发布时间：2019-04-30 09:58
| | |

各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸工委宣传部、北岸文旅办，局属有关单位：

为深入实施乡村振兴战略，繁荣兴盛乡村文化，发展各具特色的乡村旅游，根据《中共莆田市委 莆田市人民政府关于开展2019年为民办实事活动的通知》（莆委〔2019〕2号）和 《市委实施乡村振兴战略领导小组乡村文化振兴专项小组关于印发<莆田市推进乡村文化振兴工作方案>的通知》(莆文旅〔2019〕34号)文件要求，现将文化旅游特色村建设有关事项通知如下：

一、工作目标

实施建设和科学合理开发利用，挖掘和传承乡村特色文化，推进非遗传承保护和利用，发展乡村手工艺等乡村文化创意产业和民宿经济，打造莆阳非遗民俗节庆游、乡村农耕体验游等各具特色的乡村旅游品牌和乡村文创基地，实现“望得见山、看得见水、记得住乡愁、留得住游人”。2019年选择文化旅游资源丰富的10个村，完成民俗文化、文化遗产、文化设施、名木古树、农耕文化、古镇村落等资源普查，建立文化旅游资源数据库，结合每村特色民俗、乡土文化和生态特色，秉承“见人、见物、见生活”的保护理念，按“一村一规划、一村一特色、一村一品牌”思路，推进旅游休闲功能开发利用、公共文化设施完善、文物维修利用、非遗融入休闲农业和农村旅游的开发建设等工作，初步具备文化旅游特色村雏形。

二、资金及名额安排

全市共培育建设10个文化旅游特色村，每个村需要建设经费100万元，由各县区（管委会）负责筹措，市文旅局根据乡村建设情况积极争取上级资金补助。名额分配如下：仙游县2个，荔城区2个，城厢区1个，涵江区2个，秀屿区1个，湄洲岛1个，北岸1个。

三、具体要求

按照“一村一规划、一村一特色、一村一品牌”思路，推进文化旅游特色村建设，具体要求如下：

（一）有特色。通过发掘和保护特色文化资源，弘扬和发展农村优秀传统文化，实现每个村都有自己的主打文化特色品牌。要善于利用文物古迹、古民居、传统文化设施、特色地方风貌、民族风情、生活习俗、文体艺术、手工工艺或其他性质的传统民间艺术活动等进一步丰富农村文化内涵，发展乡村手工艺等乡村文化创意产业和民宿经济，打造莆阳民俗节庆游、乡村农耕体验游等各具特色的乡村旅游品牌和乡村文创基地。

（二）有规划。开展民俗文化、文化遗产、文化设施、名木古树、农耕文化、古镇村落等资源普查，建立文化旅游资源数据库，结合每村特色民俗、乡土文化和生态特色，突出重点制定工作方案或编制文化保护发展规划，按方案、规划推进文化旅游特色村建设工作。若已经制定相关规划的村，可以根据实际情况，进行补充完善，突出文化属性和旅游功能。

（三）有设施。加强基础设施建设，确保交通顺畅，有游客服务中心或游客接待点。房屋建筑具有当地特色，巷道结构、形态、宽度等自然合理，村内道路绿植自然，村容村貌整洁，与周边自然环境协调，村域内河、湖、渠保持自然形态。公共厕所厕位数量合适，垃圾桶摆放合理。大力发展民俗、农家旅馆或其他住宿设施，有特色的餐饮设施、旅游商店或购物点，能提供当地特色的旅游产品。文化旅游标志标牌符合要求，具有当地特色。通过新建、整合利用、盘活存量等方式，充分整合利用闲置校舍、废弃厂房、祠堂、古民居等资源，建设村综合文化服务中心。按照人口规模和服务半径，建设选址适中、与地域条件相协调的文体广场。

（四）有队伍。围绕特色文化，每个村都要培养一支有一定文艺专长，热心公益文化事业的农村文化和旅游管理人才队伍。要努力加强文化旅游人才的培训，着力提升文化素质，注重发挥好基层文化干部、离退休老干部、老教师及乡土文化人才作用，壮大基层文化队伍力量。通过岗位培训，熟悉自然生态、当地历史文化与风土人情，为游客提供游览活动、旅游咨询、投诉、讲解、旅游急救等服务。

（五）有活动。依托当地特色文化，每年都举办至少5次以上的文化活动。要充分利用好村综合文化服务中心、文物、文化广场、戏台等基础设施，结合“送文化，结对子”、民俗节庆等文化活动，积极组织开展群众喜闻乐见的文化活动，并鼓励群众自办文化，引导更多群众参与村里的文化活动。

（六）有收入。增加村财收入，壮大村集体经济是建设文化旅游特色村的目的之一。各村要充分利用特色文化资源开发旅游市场，提升配套服务水平，增加旅游收入，壮大村集体经济。

四、工作步骤

（一）调查摸底阶段（2019年4月底前）。组织人员深入基层进行专题调研，了解基层文化实际情况，制定特色文化名村创建活动工作方案，确定10个特色文化名村创建名单。

（二）全面建设阶段（2019年5月—2019年11月）。动员部署，按照建设方案，实施，全面推进文化旅游特色村建设工作。5月10日前，完成普查，建立文化资源数据库；5月20日前，完成规划编制或按“一村一策”制定工作方案；11月30日前，完成年度建设任务。

（三）评估验收阶段（2019年12月）。组织对各县区（管委会）文化旅游特色村建设工作进行检查验收。

五、工作措施

（一）高度重视，加强领导。市委、市政府为民办实事项目是保障民生的一项重要工作,各县区（管委会）文化旅游行政部门要进一步提高思想认识，从讲政治的高度，切实增强责任感和使命感，落实一把手负责制，明确分管领导和具体责任人；要结合本地实际，认真选点，严格把关；要加强统筹，确保资金及时到位；要确保各项工作措施到位，加大项目建设推进力度，务求把实事办好办实。

（二）统筹推进，丰富内涵。各县区（管委会）文化旅游行政部门要根据实际，认真制定文化旅游特色村建设方案，选择基础较好的村开展建设工作，以点带面，有序推进，发挥示范带头作用，助力乡村文化振兴。方案要明确目标任务、特色内容、具体措施和进度安排等内容，确保建设工作有序有力。要结合自身实际，发挥优势，主动有为，指导建设村做好村文化基础设施建设、特色文化挖掘、旅游资源开发、旅游品牌打造、文化活动开展、人才队伍培养等工作。

（三）服务群众，注重实效。要明确文化旅游特色村建设工作，根基在群众，主体是群众，目的也是为了群众。要充分发挥群众的主体作用，吸引社会力量参与乡村文化旅游建设，同时积极开展特色文化活动，丰富群众文化生活。要始终把社会效益放在首位，把建设文化旅游特色村与发掘文化经济价值、改善农村生产生活环境结合起来，让群众得到更多实惠。

请各县区（管委会）文化旅游行政部门按照要求报送相关材料。《文化旅游特色村资源普查表》（附件2）、文化旅游特色村建设规划（方案）请于5月20日前报送；从5月份开始，每月25日前报送本月工作进度（附件3）。联系人：林益清，邮箱：pt2696660@163.com，联系电话：2689939，传真：2692819。
