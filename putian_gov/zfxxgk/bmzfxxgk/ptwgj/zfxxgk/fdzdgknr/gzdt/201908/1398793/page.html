市委实施乡村振兴战略领导小组乡村文化振兴专项小组关于落实乡村振兴“百村示范”工程建设的通知

发布时间：2019-07-25 11:16
| | |

市乡村文化振兴专项小组成员单位，各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸工委宣传部、文旅办：

按照《中共莆田市委实施乡村振兴战略领导小组关于印发<开展乡村振兴“百村示范”工程建设实施方案>的通知》(莆委振兴组〔2019〕1号)文件精神，要求从2019年起实施乡村振兴“百村示范”工程建设，用三年的时间在全市范围内创建100个示范村、12个示范区（具体名单附后）。为落实好乡村振兴“百村示范”工程建设，推进乡村文化振兴，结合《市委实施乡村振兴战略领导小组乡村文化振兴专项小组关于印发<莆田市推进乡村文化振兴工作方案>的通知》(莆文旅〔2019〕34号)文件要求，现将有关事项通知如下：

一、工作目标

《中共莆田市委实施乡村振兴战略领导小组关于印发<开展乡村振兴“百村示范”工程建设实施方案>的通知》(莆委振兴组〔2019〕1号)文件要求：要逐步分级推进，重点解决提升农村人居环境，推动农村产业发展，补齐农村公共服务短板，促进农村社会文明和谐，增加农民收入等问题。通过试点示范、以点带面、连线成片，在试点取得经验后，在全市推广学习，为全市深入实施乡村振兴战略提供示范样板。其中：初级版，从群众最关心的问题入手，抓好“一革命四行动”，解决好农村的垃圾、污水、厕所、农房、村容村貌等基础问题；中级版，着重在解决产业兴旺、百姓致富等农村经济问题上下功夫，同时进一步拓展工作内容；高级版，继续对中级版进行提升，重点解决好村民自治、民俗民风、乡村文化、人才等更深层次的问题。

按照工作要求，各有关单位、各县区（管委会）文化旅游行政部门要充分挖掘、合理利用100个示范村、12个示范区文化旅游资源，以乡村特色文化挖掘和传承发展为重点，完善乡村公共文化服务体系，保护传承和发展乡村优秀传统文化，营造浓厚乡村文化气息，提升农民文化素养，推动文化旅游产业发展，为乡村振兴战略创造良好的文化氛围。

二、工作重点

    （一）推进农村优秀传统文化保护传承。重视和处理好古镇、古村落的保护和发展问题，科学划定乡村建设的历史文化保护重建，对历史文化名镇名村和文物古迹、传统村落、民族村寨、历史建筑、农业遗迹以及灌溉工程遗产等都要逐一登记在册，全面建立档案，留下影像资料，全面加强保护。加强100个示范村的乡村文物、历史建筑的保护，修缮一批乡村文物、文化遗址和历史建筑；提升一批乡村文物保护级别，公布一批乡村历史建筑。坚持源头管控和科学保护，强化乡村规划的文物保护措施，做好定线落图工作。全面完成省级以上历史文化名镇名村保护规划编制；推动文物保护单位集中成片传统村落整体保护利用项目的实施。深入挖掘我市丰富的革命历史文化资源，重点实施陈国柱故居、澳柄宫革命旧址（东泉列宁小学）、中共仙游上宫支部旧址、闽中支队司令部旧址等红色文物保护利用工程，大力推进乡村红色文化资源保护开发利用。指导支持具有非遗代表性保护项目的乡村建设非遗传习所，开展非物质文化遗产保护传承活动。指导将有教育意义和传承价值的部分非遗项目，整理编排为舞蹈、歌曲、手工、戏剧等艺术作品，丰富乡村文化生活。培育挖掘乡土文化人才，传承发展优秀传统农耕文化、礼仪文化、民俗文化、非物质文化遗产等，展现乡村优秀文化在新时期的魅力和风采。

（二）提升基层公共文化服务效能。到2020年100个示范村综合文化服务中心功能整合基本到位，实现全覆盖，并利用古厝、祠堂、戏台等特色文化资源打造一批特色文化服务阵地；推进乡村文化活动广泛开展，县级文化馆图书馆总分馆建设有效落实，群众文化获得感得到明显增强。推进农村有线电视双向网络建设及升级改造，优化村村响广播和IP数字广播并轨建设、共缆传输、维护机制，促进优质资源向城乡基层延伸。持续推进农村电影放映工程，巩固提升一个行政村一月放映一场数字电影成果，商业片放映比例不低于50%；推进符合条件的行政村开展室外流动放映向室内固定放映转变试点建设。推进旅游厕所革命，完善相关旅游村“吃住行游购娱”各项配套基础设施。

（三）做强文化旅游产业。探索莆仙文化+文物+非遗+民俗等模式，纳入乡村游精品线路。继续开展“妈祖爱 元宵长”文化旅游月活动，精心规划活动线路，完善周边公共服务设施，丰富活动内容，做大做响活动品牌。围绕我市红色基地、生态、文化、乡村、海洋等资源，设计研学旅游精品线路，开展非遗研学、艺术研学等各类活动。推进书峰乡兰石村、度尾镇中岳村、西天尾镇林山村、常太镇马院村、白沙镇坪盘村、白塘镇洋尾村、东峤镇上塘村、湄洲镇宫下村等村打造文化旅游特色村。加快特色文化旅游开发利用和产业转换，培育壮大乡创文化经济新业态，大力推进乡村旅游“百镇千村”提质升级，积极培育星级休闲集镇和星级旅游村，支持鼓励乡村旅游点创建国家A级旅游景区。依托各地高校、农科、园艺、艺术、规划、摄影等专业产业机构和社会组织，引导艺术书法、摄影写生、园艺种养、非遗文化等不同产业植入丰富到乡村文化旅游业态中。因地制宜，按照“分类、分批、分级”的原则，多层次、多渠道的开展乡村文化旅游产业规划、产业辅导、创业辅导、技能培训、业态优化、营销策划等实训工作，助力乡村文化旅游提升工作，打造一批具有鲜明特色的乡村文化旅游品牌。

三、工作要求

（一）组织保障。乡村振兴“百村示范”工程建设是推进乡村文化振兴的重要措施，文化振兴是其中的重要组成部分，各有关单位、各县区（管委会）文化旅游行政部门要高度重视，强化措施，紧密结合实际，制定具体落实方案，明确责任主体，建立工作台账，确保高质量完成工作任务。

（二）资金保障。通过上级项目资金和财政奖励资金、县区级配套、群众自筹、社会投入等多种渠道筹措。对乡村文化旅游提升项目、基层综合文化服务中心建设、文物维修、文化旅游特色村等积极争取省级补助资金，并加大市级资金倾斜力度。

（三）宣传氛围 。通过多渠道多形式宣传，引导更多社会力量来关心、支持、发展乡村文化旅游，引导更多资金、人才、技术等优质要素投入。实施“互联网+乡村文化+乡村旅游”工程，形成持续畅销的网络推广及销售平台，宣传推介莆田乡村文化旅游黄金线路和黄金景点，讲好莆田最美的乡村文化故事，

附件2

12个乡村振兴示范区名单

1.仙游县2个：一是木兰溪源头示范区（共4个村）。主要是保护和治理木兰溪源头、发展文旦柚产业、设施蔬菜产业、艺雕产业等建设，以度尾镇洋坂村为中心，辐射带动周边的度尾镇中岳村、砺山村，大济镇乌石村。二是仙游北部休闲农业示范区（共3个村）。主要是依托九鲤湖、菜溪岩等自然景观，108团、上宫第一支部等红色基因和历史遗迹，建设莆台农业合作区、高品优质粮食基地、特色果蔬基地等，发展农业观光旅游产业；以钟山镇朗桥村为中心，辐射带动周边的钟山镇东溪村、南兴村。

2.荔城区2个：一是城市绿心荔枝林区（共8个村）。主要是依托城市绿心生态保护、挖掘保护莆阳古民居群、发展荔枝产业园；以拱辰街道东阳村为中心，辐射带动周边的北大村、长丰村、七步村、西洙村，西天尾镇的后黄村、吴江村，黄石镇江东村等。二是滨海休闲旅游区（共2个村），依托珠宝产业园、休闲农业发展基础，以北高镇山前村为中心，辐射带动周边的江边村等。

3.城厢区2个：一是木兰大道沿岸桂圆产业园区（共5个村），依托木兰大道、龙眼产业等优势，以华亭镇涧口村为中心，辐射带动周边的油潭村、郊溪村、埔柳村、五云村等。二是东圳水库水资源生态保护区（共4个村），依托库区生态环境保护，以常太镇岭下村为中心，辐射带动周边的溪南村、渡里村、马院村等。

4.涵江区2个：一是涵江北部山区农耕文化产业区（共4个村），依托北部山区传统农耕文化为支撑，以白沙镇坪盘村、新县镇张洋村为中心，辐射带动庄边镇萍湖村、大洋乡车口村等。二是蒜溪流域侨乡特色文化区（共4个村），依托蒜溪的青山绿水、侨乡文化、南洋风格古民居等，以江口镇东大村为中心，辐射带动周边的大东村、上后村、官庄村等。

5.秀屿区2个：一是海洋牧场经济产业区（2片共6个村居），依托兴化湾资源，发展海洋养殖、水产品加工业，以埭头镇石城村、南日镇东岱村为中心，辐射带动埭头镇淇沪村、东林村，南日镇后叶村、浮叶村等。二是康养旅游产业区（共3个村居），依托健康医疗产业、冰雪小镇、雄厚的民间资本，以东庄镇白山村为中心，辐射带动锦山村、营边社区等。

6.北岸管委会1个。历史文化产业区（共3个村居），以山亭镇东仙社区为中心，辐射带动莆禧村、文甲村等。

7.湄洲岛管委会1个。妈祖朝圣旅游区（共2个村居），以湄洲镇宫下村为中心，辐射带动莲池村等。
