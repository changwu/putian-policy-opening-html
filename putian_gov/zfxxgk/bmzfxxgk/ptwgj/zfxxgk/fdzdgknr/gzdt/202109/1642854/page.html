莆田市文化和旅游局关于印发加强旅游服务质量监管提升旅游服务质量实施方案的通知

发布时间：2021-09-02 11:36
| | |

各县区文化体育和旅游局、湄洲岛旅游和文化体育局、北岸党工委宣传部，局机关相关科室，市文化市场综合执法支队、市旅游质监所，市旅游协会：

为进一步提升旅游服务质量，严格规范旅游市场秩序，切实营造我市旅游发展良好环境，现将《加强旅游服务质量监管提升旅游服务质量实施方案的通知》印发你们，请认真抓好落实。

请各县区（管委会）文旅部门、局机关相关科室、市文化市场综合执法支队、市旅游质监所、市旅游协会每年11月10日前向我局报送本地、本行业旅游服务质量提升工作落实进展情况，提出意见建议，以便汇总上报省文化和旅游厅。

联系人：郭欢欢，电话：2221161，电子邮箱：hgk2221161@163.com。

 

 

                        莆田市文化和旅游局

                          2021年8月30日

 

加强旅游服务质量监管提升旅游服务质量实施方案

 

为贯彻落实省文化和旅游厅《关于印发加强旅游服务质量监管提升旅游服务质量实施方案的通知》（闽文旅市场〔2021〕4号），进一步抓好旅游服务质量监管，提升旅游服务品质，打造“妈祖圣地 美丽莆田”品牌，制定本实施方案。

一、总体要求 

（一）指导思想 

以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的十九大和十九届二中、三中、四中、五中全会精神，大力实施旅游质量提升工程,完善旅游服务质量体系,加强旅游服务质量监管,切实优化旅游发展环境,推动旅游业高质量发展，不断提升广大游客旅游体验获得感与满意度。

（二）基本原则 

一是坚持以人民为中心。树牢以人民为中心的发展理念，把人民群众更加满意作为旅游业发展的价值导向。二是坚持系统观念。加强旅游服务质量监管和提升的系统性思考、整体性推进、协同性发展，实现旅游服务质量持续提升。 三是坚持创新发展。加快完善旅游服务质量基础设施，加强标准、评价等能力建设。四是坚持深化改革。破除制约旅游服务质量提升的体制机制障碍。

（三）计划目标

到2025年，全市的旅游供给质量明显改善，旅游服务和管理质量显著提高，旅游市场秩序规范有序，旅游市场综合监管机制更加完善，旅游公共服务水平明显增强，旅游消费环境明显优化，旅游优质产品供给更加丰富，文化和旅游融合不断深入，游客投诉量明显降低。

二、重点工作

（一）落实旅游服务质量主体责任 

1.加强旅游服务质量保障。促进旅行社不断规范经营内容和行为，加快理念、技术、产品、服务、模式和业态创新，实现数字化转型。引导星级饭店和民宿提升管理水平和服务质量。指导A级旅游景区落实“错峰、预约、限量”和“三验一戴”（查验体温、查验健康码、查验行程轨迹、佩戴口罩）等疫情防控措施，落实景区最大承载量，推进旅游景区门票网上预约。针对老年人等特殊群体提升旅游服务便利性。（市场法规科、产业发展科按职责分工负责）

2.发挥行业组织作用。鼓励和支持旅游协会推动旅游市场主体进一步提升旅游服务质量，鼓励和支持相关行业组织建立旅游服务质量分会，加强质量文化宣传引导，提升质量兴旅、质量强旅意识。（公共服务科、产业发展科、市场法规科、市旅游协会按职责分工负责）

（二）夯实旅游服务质量基础 

1. 加强旅游服务标准的宣传和实施。加大标准宣传力度，提高全社会、全行业的标准意识。做好文旅融合下的旅游标准化试点工作，组织参加全国旅游标准化示范单位评选，以标准化引领旅游服务质量提升。推动《旅行社等级的划分与评定》《文明旅游示范单位要求与评价》《旅游民宿基本要求与评价》《旅游景区质量等级的划分与评定》等标准的宣传与实施。（市场法规科、产业发展科、公共服务科按职责分工负责）

2. 开展质量监测评价。加强旅游市场舆情监测，及时发现、分析、研判并采取有效措施妥善处置。加快建立区域、业态、企业等旅游服务质量监测机制，推进监测结果应用，督促引导社会各方提升旅游服务质量水平。加强旅游服务质量数据归集和共享，探索在A级旅游景区等主要旅游服务场所推广旅游服务质量评价二维码。（计财科、市场法规科、产业发展科按职责分工负责）

3. 探索建立旅游服务质量认证体系。配合省文旅厅做好旅游服务质量认证，鼓励旅游市场主体、相关资格评定机构及社会力量积极参与旅游服务质量认证，提升旅游服务质量管理水平。（市场法规科、产业发展科、公共服务科按职责分工负责）

（三）培育优质旅游服务品牌 

1.支持壮大旅游服务品牌。做大做强做优旅游企业，稳步推进规模化、品牌化、网络化经营，重点培育“专精特新”文化旅游企业。发挥5A级旅游景区--湄洲岛妈祖文化旅游区的优势，推动全市旅游产业优化升级。锚定“大九鲤湖”体系发展思路，对九鲤湖、九龙谷景区进行整体规划、整合开发。做大南少林文化旅游区，开展南少林文化旅游区规划编制和开发工作，全面转变旅游区发展状态。深化习近平木兰溪治理理念，以木兰陂历史遗迹为核心，建设木兰陂世界灌溉工程遗产景区，提升世界灌溉遗产名片。依托兴化古城、萝苜田等历史文化街区，到2025年，培育创建一批国家级、省级旅游休闲街区和历史文化街区。提升绶溪公园文旅业态体系，推动绶溪公园创建国家级、省级旅游度假区，力争到2025年实现区区有4A旅游区。（产业发展科、公共服务科、文物科按职责分工负责）

2.完善品牌创建激励机制。探索设立旅游服务质量奖（包括奖励新评定的4A、5A级旅游景区等），培育旅游服务质量品牌示范单位。依法依规查处侵权假冒旅游服务品牌行为，建设有利于品牌发展的长效机制。建立旅游企事业单位优质服务案例库，宣传推广旅游服务质量管理的成功经验和先进方法，促进旅游服务质量提升。（产业发展科、市场法规科，市旅游质监所按职责分工负责）

（四）加强旅游人才队伍建设 

1．加强导游队伍建设。落实省文旅厅导游素质提升计划，评选“十佳导游”，落实获得国家级、省级旅游人才称号奖励制度。保障导游合法权益，落实导游服务质量综合评价制度，推动导游队伍素质提升。推进 “金牌导游”培养，发挥“金牌导游”传帮带作用。（人教科、市场法规科按职责分工负责）

2.开展旅游服务技能竞赛。开展旅游饭店“十佳服务技能”、旅游景区讲解员等技能比赛。组织参与全国导游大赛、全国红色故事讲解员大赛、饭店服务技能竞赛，开展红色旅游“五好”讲解员建设行动，加强对先进人物和典型事迹的宣传推广。（人教科、市场法规科、产业发展科按职责分工负责，市旅游协会配合）

3.完善教育培训体系。将旅游服务质量纳入旅游培训内容，推动建立政府、院校、旅游协会和旅游企业共同参与的旅游服务质量教育网络。组织旅游服务标准化、旅游服务质量管理和服务技能培训。引导旅游企业建立实训中心，建立企业旅游服务质量培训制度，加强企业管理人员培训。（人教科、市场法规科、产业发展科、公共服务科按职责分工负责）

4.培养旅游服务质量人才。将旅游服务质量培训纳入乡村旅游能人支持等培养项目，提升乡村旅游人才旅游服务水平。实施乡村旅游人才引进政策，鼓励旅游区、景点聘请专业技术人员担任讲解员，鼓励具有文艺才能的人才到基层和乡村旅游点传授或展示技能，吸引更多游客。（人教科、市场法规科、产业发展科、公共服务科按职责分工负责）

（五）加快推进旅游信用体系建设 

1.完善旅游市场信用监管体系。实施行政审批告知承诺制度，鼓励旅游市场主体向社会作出信用承诺，指导旅游协会建立健全行业内信用承诺制度，加强行业自律。依托全国旅游市场信用管理系统，加强信用信息归集公示和共享，建立完善旅游市场主体和从业人员信用档案。组织开展企业信用评价，依托信用评价结果实施分级分类监管。（市场法规科牵头，相关科室配合）

2.严格失信名单管理。坚持“应列入、尽列入”原则，依法依规将查处的符合列入条件的失信主体列入失信名单，完善“双公示”系统，与“信用福建”无缝对接，依法实施联合惩戒。建立保护市场主体权益的信用修复机制，加强协同联动，提高信用修复效率。（市场法规科牵头，相关科室配合）

3.拓展信用应用场景。对信用等级高的A级旅游景区、星级饭店、旅行社等，推荐市场管理、税务等部门在市场准入、资质审核、评优评奖等方面依法予以优先考虑。加强诚信文化建设，打造一批诚信旅游企业，探索信用建设服务实体经济发展新路径。（产业发展科、市场法规科按职责分工负责，市旅游协会配合）

（六）加强行业旅游服务质量监管

1.完善旅游服务质量综合监管机制。深化“放心游莆田”服务承诺，完善旅游投诉“一口受理”“快速办结”“先行赔付”并横向市直相关部门、纵向市县三级联动联办的涉旅快速投诉处理机制。围绕游客反映的突出问题，加大旅游市场执法监管力度，严格查处“不合理代价游”等违法违规行为。完善“双随机”抽查和“体检式”暗访工作机制，确保巡查检查和暗访评估常态化开展。在不同时段开展跨部门联合执法，严厉打击“不合理低价游”、未经许可经营旅行社业务等违法违规行为。（市场法规科，市文化市场综合执法支队、旅游质监所按职责分工负责）

2．创新质量监管方式。推进“互联网+监管”，全面推广使用“全国文化市场技术监管与服务平台”“全国旅游监管服务平台”，提高数字化、智能化监管水平。依法公开市场主体基本信息，健全旅游领域公平竞争审查机制，反对垄断和不正当竞争行为；加强同市场监管等相关部门协作，维护良好旅游市场秩序。（市场法规科，市文化市场综合执法支队、旅游质监所按职责分工负责）

3. 加强游客权益保护。加强旅游市场秩序舆情监测，及时发现问题并妥善处置。积极推进旅游投诉纠纷调解与司法仲裁相衔接，切实提升旅游投诉调解成功率。鼓励建立旅游纠纷理赔中心、旅游消费维权站、人民调解委员会和巡回法庭。定期发布旅游纠纷典型案例和旅游投诉情况，加强“以案释法”，引导游客理性消费、依法维权。定期分析研判投诉内容，做好“诉转案”工作，打击旅游市场违法违规行为。持续开展“文明旅游 安全出行”主题活动，弘扬文明、健康、绿色旅游新风尚。（市场法规科，市旅游质监所按职责分工负责）

三、保障措施 

（一）提高思想认识。充分认识旅游服务质量提升工作的重要意义，建立旅游服务质量提升的领导机制和协调机制，加强与市场监管、公安、网信、电信主管等部门的合作，明确职责分工，确保旅游服务质量提升工作取得实效。

(二)加强宣传引导。加大宣传力度，充分调动各类市场主体、广大消费者、行业组织和社会媒体和积极性，主动践行旅游行业核心价值观，弘扬行业正能量，塑造诚信经营的文明旅游典范，共同推进落实旅游服务质量提升计划，营造旅游业高质量发展的良好氛围。

（三）强化督导检查。建立督导考核机制,对《方案》的实施情况进行定期检查,对服务质量提升工作中取得突出成绩的单位和个人给予通报表扬，对工作不认真落实的给予通报批评，每年11月10日前向我局报送本地旅游服务质量提升工作落实进展情况，提出意见建议，并将结果列入市政府对县区质量考核评价。
