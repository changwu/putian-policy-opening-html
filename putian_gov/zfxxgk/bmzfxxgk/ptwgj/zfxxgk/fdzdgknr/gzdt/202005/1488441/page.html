莆田市文化和旅游局关于开展2020年文化旅游市场整治的通知

发布时间：2020-05-11 09:06
| | |

各县区文化体育和旅游局，湄洲岛旅游局，北岸党工委宣传部、北岸文旅办，局机关相关科室、局属有关单位：

为巩固“不忘初心、牢记使命”主题教育成果，切实保障文化旅游企业顺利复工复产，促进文化旅游业健康稳定发展，根据《福建省文化和旅游厅关于开展2020年文化旅游市场整治行动的通知》（闽文旅综执〔2020〕2号），结合扫黑除恶专项斗争，经研究，继续在全市范围内开展2020年文化旅游市场整治行动。现将有关事项通知如下：

一、整治目标

坚持问题导向、依法整治、突出重点、标本兼治，牢牢守住政治底线和安全底线，针对文化和旅游市场特点，按照全市一盘棋的工作原则，坚持线上清查与线下整治同步实施、暗访评估与执法检查同步开展、日常监管与专项行动同步推进，加强黑恶线索摸排，深入整治娱乐场所涉黄涉毒、文化市场、出版物网络发行违法违规经营行为、“不合理低价游”、非法经营旅行社业务、无证无照印刷经营活动、非法卫星电视接收设施等突出问题，着力规范文化和旅游市场经营秩序，维护人民群众和经营者合法权益，营造良好的文化和旅游市场环境。

二、时间步骤

2020年4月20日至2020年底。

（一）部署落实（4月22日至4月30日）：调整充实领导机构，制定下发专项整治行动实施方案。各县区（管委会）文旅部门根据实际情况相应制订行动方案，同步开展整治行动；督促各企业、场所负责人落实主体责任，对照整治重点，全面开展自查及整改，并将自查整改情况报属地文化和旅游主管部门。

（二）整治提升（5月1日至10月15日）：各县区（管委会）文旅部门认真梳理2019年度文化旅游市场整治中的突出问题，将暗访暗查作为发现问题的主要抓手，通过双随机检査、重点检査、突击检査、日常执法等，多措并举、扎实推进整治行动，同时核查涉黑涉恶线索排査情况，严厉打击各类违法违规经营活动，持续保持市场整治高压态势，坚决打赢集中整治攻坚战。

（三）建立机制（10月16日至年底）：各县区（管委会）文旅部门对市场整治中发现的问题列出清单，制定方案，明确整改时限，把整改责任落实到具体单位、具体部门、具体人员。在开展集中整改的过程中，建立健全行业监管和综合治理工作机制。

三、工作措施

(一)加大整治力度。加强日常监督管理，加大执法力度，围绕互联网上网服务营业场所、娱乐场所、营业性演出、印刷经营、艺术品经营(含网络经营)、网络文化(网络音乐、动漫、艺术品、表演等)、出版物网络发行、卫星电视接收设施安装使用、社会艺术水平考级、在线旅游产品及信息、旅行社相关业务、导游人员相关活动、食品安全、旅游车辆超载混装、A级景区和乡村旅游点厕所存在日常管理和卫生保洁等工作重点，依法查办一批典型案件，打击黑恶势力，加大曝光力度，形成对违法违规经营的强力震慑。

(二)健全治理机制。充分发挥文化市场管理工作领导小组和旅游市场综合监管机制的作用，健全与公安、网信、通信管理、市场管理等相关部门的联合执法机制，各司其职，各负其责，密切配合，研究会商管理措施，开展联合执法，打击黑恶势力。推进市场管理信息化建设，实施创新管理技术措施，采取日常检查、突击检查与技术监控相结合的措施，巩固整治成果。

(三)推进信用监管。利用文化市场技术监管与服务平台等，加强经营单位一户一档管理，完善信用信息，积极探索对经营单位的信用监管，建立警示名单和黑名单制度，完善守信激励和失信惩戒机制，构建“一处失信，处处受限”的管理机制，营造良好信用环境。通过开展培训和交流座谈，加强经营单位管理人员的法律法规培训，提高守法合规诚信经营意识。

(四)严格内容监管。对舆论热点难点、重大突发事件进行分析研判、與情回应和與论引导，准确通报、积极引导、科学处置、有效回应社会关切。加强文化和旅游市场内容审核，严禁含有禁止内容的产品进入市场，严格落实意识形态工作责任制，强化文化和旅游阵地管理。

四、工作要求

（一）提高政治站位。各县区（管委会）文旅部门要提高政治站位，充分认识维护文化和旅游市场秩序是满足人民群众美好生活需要的重要保证、是开展“不忘初心、牢记使命”主题教育的重要实践、是推进扫黑除恶专项斗争的重要内容。要检视问题不足，清醒认识当前文化和旅游市场现状与人民群众的期盼还有不小差距，进一步提升政治站位、强化使命担当，扎实开展好整治行动。

（二）加强组织领导。各县区（管委会）文旅部门要在去年成立的领导小组基础上，根据实际情况及工作重点，及时调整充实领导小组成员。要按照“属地管理、部门联动、行业自律、社会监督、齐抓共管”的原则，建立“一把手”负总责的领导机制，制定切实可行的措施，承担依法整治文化和旅游市场的主体责任，推进整治行动的全面落实。

（三）主抓执法办案。各县区（管委会）文旅部门要把暗访暗查作为发现问题的主要抓手，采取委托第三方“体检式”暗访或执法人员专业暗访等形式，对本辖区文化和旅游市场进行全面体检，排查各类问题隐患。要综合运用突击检查、重点检查、进驻检查等方式，加大执法监管力度，梳理各类案件特别是黑恶线索，加强案件查办、督办、转办、协办，坚决杜绝推诿扯皮、查处不力、执法不严等现象。针对重点场所和重点问题，要集中执法力量重点攻坚，查处一批情节严重、影响恶劣的大案要案，及时向社会公布，形成有力震慑。

（四）落实服务承诺。深入实施“放心游莆田”服务承诺，畅通文化和旅游投诉渠道，有效调解和处理文化和旅游纠纷，不断加大“诉转案”力度。

（五）强化责任落实。各县区（管委会）文旅部门要对突出问题开展“回头看”，采取通报、约谈、督办等方式，落实企业主体责任。市局将于年内对互联网上网服务场所、娱乐场所经营单位(歌舞和游艺)、印刷企业、网络书店、营业性演出、旅行社及在线旅游产品、导游、A级景区、旅游厕所、星级饭店、旅游市场周边环境进行全面“体检式”暗访评估，并于暗访结束后梳理问题清单，针对重点地区、重要场所展开督査检查。

（五）营造宣传氛围。各县区（管委会）文旅部门要综合运用各类宣传手段，围绕市场热点和工作重点，多管齐下，多措并举，开展形式多样的法制宣传活动，提升全市文化和旅游市场领域法制宣传和整治行动的覆盖面及普及度，引导全社会共同参与营造依法治理文化和旅游市场的浓厚氛围。在市场整治的过程中，强化社会监督，鼓励群众举报，对典型案例进行曝光，扩大社会影响。

各县区（管委会）文旅部门要按照部署落实、整治提升和建立机制三个时间节点，分别于4月30日前报送整治行动计划(含联络人、联络电话)，10月12日前报送整治行动总结和工作成效，12月10日前报送整改责任清单、情况反馈等材料，对黑恶线索要及时向属地公安部门和市局报送。为确保整治行动顺利开展，问题整改及时到位，市局将适时开展调研指导工作，整治行动纳入2020年度平安文化市场综合考评内容。
