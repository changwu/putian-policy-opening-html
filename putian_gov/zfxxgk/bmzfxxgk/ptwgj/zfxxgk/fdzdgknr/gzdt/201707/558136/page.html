中共莆田市委宣传部 莆田市文化广电新闻出版局关于莆田市第一届“梅妃杯”莆仙戏青年演员比赛获奖情况的通报

发布时间：2017-06-05 10:31
| | |

各县区委（工委）宣传部，各县区（管委会）文体广电出版局，湄洲岛社会事务局，局属有关单位：

    莆田市第一届“梅妃杯”莆仙戏青年演员比赛已圆满结束，现将获奖名单予以通报。希望获奖的青年演员戒骄戒躁、再接再厉，为传承保护和发展莆仙戏、推动美丽莆田建设作出新的更大贡献。
