莆田市文化和旅游局关于加强文化和旅游诚信建设实施失信联合惩戒的通知

发布时间：2020-08-13 10:19
| | |

各县区文化体育和旅游局，湄洲岛旅游文体局，北岸党工委宣传部：

为进一步加强文化和旅游诚信建设，健全信用联合惩戒机制，营造诚实、自律、守信、互信的文化和旅游市场信用环境，促进文化旅游业持续健康发展，现就有关事项通知如下：

一、加强文旅诚信体系建设。各县（区、管委会）文旅部门要建立健全信用“双公示”机制，推动文化和旅游政务信用信息公开，全面落实行政许可和行政处罚信息公开制度。要按照《关于印发文化和旅游市场失信黑名单管理工作细则（试行）的通知》，完善文化和旅游失信“黑名单”机制，加大对文化和旅游经营不良、不文明等信息上报制度。要逐步健全文化和旅游经营企业及从业人员信用记录机制，及时完善文化和旅游经营企业及从业人员信用信息及信用档案，探索与市场管理部门联合建立文化和旅游经营单位信用等级评估制度。

二、突出文旅诚信宣传教育。各县（区、管委会）文旅部门要将文化和旅游诚信宣传纳入年度工作，充分发挥电视、广播、报纸等媒体宣传引导作用，大力倡导社会主义核心价值观，弘扬诚实守信精神，构建崇尚诚信、践行诚信良好社会风尚。要利用“3.15”国际消费者权益保护日、“5.19”中国旅游日、“6.14”信用记录关爱日、“12.4”全国法制宣传日等，开展“诚信活动周”“质量月”“诚信兴商宣传月”等公益活动。要突出文化和旅游诚信主题，营造“守信者荣、失信者耻、无信者忧”的氛围，形成遵纪守法、诚实守信的良好风尚。

三、推进失信联合惩戒。各县（区、管委会）文旅部门要按照《通知》要求，主动加强同法院、公安、发改、市场管理等部门的沟通协调，建立信息互通工作机制，及时向同级人民法院推送辖区内文化经营场所、营业性演出团体、星级饭店、旅行社（分社）及A级景区信息，向同级人民法院获取失信被执行人名单信息并推送至辖区内的文化和旅游企业。要积极争取发改部门支持，将文化和旅游系统失信被执行人名单接入“公共信息信用系统”和信用福建“双公示”平台。要及时将被吊销经营许可证的文化和旅游企业及相关管理人员、相关负责人信息推送至法院、公安、发改、市场管理等部门实施联合惩戒。

各县（区、管委会）文旅部门要及时将开展诚信教育及联合惩戒情况报送市文旅局。
