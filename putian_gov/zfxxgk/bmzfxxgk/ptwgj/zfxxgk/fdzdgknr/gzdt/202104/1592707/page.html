莆田市文化和旅游局关于因地制宜建设红色书屋（图书角）的通知

发布时间：2021-04-27 16:56
| | |

各县区文化体育和旅游局，湄洲岛旅游文体局，北岸党工委宣传部，局机关相关科室，市新华书店，市出版发行协会：

为深入学习宣传贯彻落实习近平总书记来闽考察重要讲话精神，进一步营造“学党史、感党恩、跟党走”的良好社会氛围，为奋力谱写全面建设社会主义现代化国家的福建篇章贡献莆田力量，经研究，决定在全市因地制宜开展红色书屋（图书角）建设活动。现将有关事项通知如下：

一、提高思想认识，强化组织领导。因地制宜建设红色书屋（图书角），是深入推进中共党史学习教育和“再学习、再调研、再落实”活动的重要举措，是把红色资源利用好、把红色传统发扬好、把红色基因传承好的重要抓手，也是加强城乡宣传思想文化阵地建设、推进文化便民惠民的基础工程。各单位要高度重视，增强责任意识，明确具体举措和时间安排，切实抓紧抓好组织实施。红色书屋（图书角）创建工作纳入我市推荐参评省级示范农家书屋、全民阅读示范点、示范实体书店的重要依据。各县区（管委会）要把年度农家书屋出版物更新经费重点用于采购党史、新中国史、改革开放史和社会主义发展史图书。

二、坚持融合融入，打造特色亮点。各单位根据实际情况，坚持共建共享共用开展红色书屋（图书角）创建工作，注重建设，强化管理，立足使用，循序渐进，逐步提升。可以结合农家书屋深化改革创新提升服务效能工作，融入当地红色文化、旅游和文物资源，打造特色红色农家书屋。要依托现有的农家书屋、综合文化服务中心等公共文化场所，开辟红色图书角，营造小而美的红色阅读空间。积极推进社区红色文化“嵌入式”融入，将红色文化创意融入“党建+”邻里中心莆阳文化驿站，提高环境的美观度和服务的便捷性。鼓励支持莆阳书房、新华书屋、实体书店，设立集借阅和销售于一体的红色出版物专区，打造融合红色经典阅读、文博文创、艺术鉴赏、文化沙龙、轻食餐饮等服务的新型红色文化业态。

三、深化改革创新，提升服务效能。要着眼于解决公共阅读空间普遍存在的“建、管、用”脱节的老大难问题，鼓励支持红色书屋（图书角）与教育、工会、共青团、妇联、机关工委、电讯运营商等企事业单位合作，通过捐图书、结对子、设专架、开展阅读推广和志愿服务等方式，提升服务效能。鼓励支持社会力量参与红色书屋（图书角）阅读推广活动，以及红色图书管理信息化建设，推进红色图书市域、县域通借通还，推动红色书屋（图书角）走出一条举旗帜、聚人气、有活力的特色发展之路。

四、选立创建典型，发挥示范引领。今年“七一”前，我市将选立一批红色书屋（图书角）创建典型，广泛宣传推广红色书屋（图书角）建设中的好经验，扩大红色书屋（图书角）的社会影响力。届时将邀请省新闻出版局领导来我市启动系列活动并授牌。请仙游县、荔城区、城厢区、涵江区、秀屿区各推荐红色书屋不少于2个(对照附件3，填报《福建省老区“红色书屋”推荐表》，将择优向省里申请补充更新一批党史学习教育类出版物），红色图书角不少于20个；湄洲岛和北岸各推荐示范红色书屋不少于1个，红色图书角不少于5个；市新华集团推荐红色书屋（图书角）各不少于1个；具备出版物批发资质的实体书店均要设立红色出版物专区。请于4月27日前将推荐名单（附件1、2）报送至市文旅局新闻出版科，并及时跟进报送完成情况（含现场和活动图片3-5张）。联系人：郑玉辉，联系电话：13959593704，邮箱：ptsxwcb@163.com。
