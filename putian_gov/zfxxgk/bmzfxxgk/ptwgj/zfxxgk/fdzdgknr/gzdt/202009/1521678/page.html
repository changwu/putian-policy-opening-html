莆田市文化和旅游局关于公布2020年度第二届“梅妃杯”莆仙戏中青年演员比赛结果的通知

发布时间：2020-08-25 10:59
| | |

各县区文化体育和旅游局,湄洲岛旅游文体局,北岸党工委宣传部：

根据福建省文旅厅《关于举办福建省第十届中青年演员比赛的通知》精神，莆田市第二届“梅妃杯”莆仙戏中青年演员比赛于2020年7月13-14日在市群众艺术馆成功举行，通过各县区选拔推荐，共有56名演员、演奏员参加市级总决赛，评出一等奖8名，二等奖16名，三等奖19名、优秀表演（演奏）奖13名。现将获奖名单予以公布，希望各有关单位和个人再接再厉，加强莆仙戏人才培养，促进莆仙戏弘扬和传承。
