莆田市文化和旅游局关于开展2020年农民文化周活动的通知

发布时间：2020-09-11 16:15
| | |

各县区文化体育和旅游局，湄洲岛旅游文体局，北岸党工委宣传部，局属有关单位：

按照乡村振兴相关工作部署，省文旅厅决定于“中国农民丰收节”期间，在全省广泛开展主题为“八闽丰收节节高、幸福小康样样红”的农民文化周活动，现将方案（附件1）转发你们，请各县区（管委会）、局属有关单位按照省厅文件要求，制定方案，精心组织开展系列文化活动。仙游县、荔城区、秀屿区要配合市局做好省厅在莆田的启动仪式、集中展示展演等活动。

请各县区（管委会）、局属有关单位在活动期间将活动组织开展情况的宣传视频等在第一时间向市局推送，以便进行宣传。9月30日前，将活动开展情况表（附件2）报送市局公共服务科。联系人：林益清，联系电话：2689939，邮箱pt2696660@163.com。

附件1

 

福建省文化和旅游厅关于开展福建省

2020年农民文化周活动的通知

 

各设区市文旅局、平潭综合实验区旅游文体局，厅直属有关单位：

为深入推进乡村文化振兴，为乡村群众提供更多高品质文化产品和服务，活跃乡村群众文化生活，根据省委乡村振兴年度工作部署，决定于“中国农民丰收节”期间，在全省广泛组织开展农民文化周活动。现将有关事项通知如下。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中、四中全会精神，深入落实《公共文化服务保障法》，围绕我省“八闽丰收节节高、幸福小康样样红”这一主题，依托各级文化旅游公共服务设施，因地制宜、就近就便组织乡村群众开展健康向上、形式多样、特色鲜明的群众性文化活动，集中展示乡村文化振兴各项新成就新成果，促进构建充满活力的乡村丰收节公共文化空间，丰富乡村人民群众的精神文化需求，增强乡村群众的文化获得感、幸福感，为全方位推动我省高质量发展超越营造昂扬向上的文化氛围。

二、活动时间、地点

时间：2020年9月22日至28日

地点：全省各级文旅公共服务阵地，重点是乡镇文化站和村级综合文化服务中心、乡村游客服务中心、乡村非遗传习所（点）等乡村文化旅游公共服务设施。

三、活动组织（举办单位）

活动由省文旅厅、省广播影视集团联合主办，各地文旅部门具体举办，全省不搞统一的开、闭幕式。省文旅厅、省广播影视集团将在莆田举办启动仪式和集中展示展演活动，在漳州、三明、龙岩、宁德等地市举办展示展演活动，并进行电视录播。活动期间每天将通过福建电视台综合频道、海博TV等媒体，对各地精彩活动情况进行实况报道；活动结束后，活动成果将以“有温度的乡土--福建省乡村文化振兴农民文化周活动集萃”为主题，以视频形式在福建电视台、海博TV、今日头条、抖音、学习强国等新媒体以及文旅部国家公共文化云等平台上进行宣传。

四、活动主题

八闽丰收节节高、幸福小康样样红

五、活动内容

（一）开展文艺演出系列活动。各地各单位以庆丰收、迎国庆、脱贫攻坚、抗疫情、复工复产等为主题，组织开展各种形式的文艺演出活动；鼓励和引导各地以乡镇为单位组织开展广场舞集中展演活动；鼓励各地文化馆组织文化志愿者深入乡村，尤其是历史文化名镇名村、乡村旅游重点村、乡村振兴示范点等开展文化惠民演出活动。

（二）组织展览展示系列活动。各地要充分利用图书馆、文化馆、博物馆、美术馆、乡镇文化站和村（社区）综合文化服务中心、游客服务中心公共文化场所，举办书法、绘画、摄影等展览活动；鼓励乡村文化能人、村级文化与食安协管员在乡村积极组织举办各种文化艺术展示活动。

（三）开展非遗主题系列活动。各地各单位要深入挖掘非遗文化内涵，组织开展非遗尤其是非遗传统技艺类项目、农耕文化遗产的展示展演活动；要组织开展非遗才艺技艺大比拼活动，让乡村群众了解非遗、热爱非遗，参与非遗传承实践活动，延续乡村非遗的生命力；要积极组织非遗院团开展戏曲进乡村活动，弘扬优秀传统文化；要鼓励引导非遗传承人创新非遗产品，积极参与“全闽乐购”等产品展销活动，推动非遗走进生活。

（四）开展阅读推广系列活动。各级公共图书馆、乡镇文化站和村（社区）综合文化服务中心要充分发挥阵地优势、资源优势，组织开展系列读书活动、诵读活动，引导广大乡村群众践行社会主义核心价值观，提高乡村群众文化修养。

（五）开展文化志愿服务系列活动。各级公共图书馆、文化馆要把具备条件的乡镇文化站和村（社区）综合文化服务中心纳入图书馆文化馆总分馆体系，提升服务效能。要开展结对帮扶活动，结合“文化进万家”，组织文化志愿者小分队送文化进乡村，或开展艺术培训活动，培训乡村文艺骨干和文化能人，或指导开展群众文化活动，或配送图书、数字文化资源、设备等。

六、活动要求

（一）加强领导，强化责任。农民文化周活动是今年我省乡村文化振兴重要工作事项，各地要认识到位，将农民文化周作为当前乡村文化振兴的重点工作内容，作为贯彻落实省委十届十次全会的重要举措，作为增加乡村高品质文化供给的有效途径，打造我省乡村群众性文化活动新品牌。要举措到位，加强领导，专题研究，制定方案，精心实施。要责任到位，严格落实常态化疫情防控工作要求，科学安排农民文化周活动开展；认真落实意识形态责任制，把好意识形态责任关；要严格遵守廉洁纪律有关规定和遵循中央“过紧日子”的要求，把活动的出发点和落脚点放在提升农民群众获得感、幸福感上，避免出现形式主义和奢靡之风。

（二）下移重心，面向基层。农民文化周活动要坚持重心下移、资源下移、服务下移，面向乡镇和村（社区）广大乡村群众，重在活动形式喜闻乐见，活动内容体现特色，活动阵地就近方便，活动开展常态长效，引导广大乡村群众积极参与、主动参与；要突出重点，把有限的资源和项目放到乡镇文化站、村（社区）综合文化服务中心、乡村游客服务中心、乡村非遗传习所（点）等，使文化周成为乡村群众身边的舞台和日常的活动，让广大乡村群众乐于参与、方便参与、在参与中增强文化获得感、幸福感。

（三）整合资源，突出特色。各地要根据当地实际情况，挖掘和利用特色文化资源，开展具有地方特色的主题活动；要结合年度工作安排，鼓励具备条件的组织开展乡村群众文化活动集中展示展演活动；要注重实效，鼓励将农民文化周活动融入当地相关演出、论坛、展览、旅游宣传推介等活动中，扩大活动的覆盖面和实效性。

（四）做好宣传，扩大影响。要充分发挥报刊、广播、电视和微信、微博、视频直播等新媒体手段，全方位多角度宣传农民文化周活动开展情况。要组织媒体深入基层，发掘乡村文化振兴典型，宣传我省乡村文化振兴新成就新成果，进一步营造我省乡村文化振兴的良好氛围。要认真总结，及时汇总本地农民文化周活动开展情况，总结经验，推广做法，推进农民文化周活动经常化、制度化。

请各地在活动期间将活动组织开展情况的宣传视频等在第一时间向省厅推送，以便省上综合后适时在福建电视台综合频道、海博TV、抖音等媒体平台上进行宣传推送。10月10日前，将活动开展情况（重点报送活动开展场次和活动参与人次以及图片、视频）报送厅公共服务处。
