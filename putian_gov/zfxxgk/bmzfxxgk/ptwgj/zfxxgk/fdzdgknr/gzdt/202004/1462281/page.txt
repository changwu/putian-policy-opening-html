标题: 莆田市文化和旅游局关于开展全市文化市场综合执法法制宣传活动的通知
发布时间: 2019-08-12 16:33
文号: 莆文旅〔2019〕154号
发布机构: 
栏目: 文旅综合
原始链接: https://www.putian.gov.cn/zfxxgk/bmzfxxgk/ptwgj/zfxxgk/fdzdgknr/gzdt/202004/t20200414_1462281.htm
正文:
各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸宣传部、文旅办，局机关各科室、局属各单位：
为进一步贯彻落实省文旅厅《关于开展全省文化市场综合执法法制宣传活动的通知》，强化“谁执法谁普法”责任制，激发文化市场综合执法人员法制意识、担当意识和责任意识，加强文化市场综合执法社会监督。经研究，决定在全市范围内开展文化市场综合执法法制宣传活动。现将有关事项通知如下：

三、宣传形式
(
一
)
要扩大宣传范围
依托公交站台、广告牌、告示栏、官网或微信公众号等，悬挂、张贴、宣传文化市场综合执法法制内容和信息
;
依托公交、出租车等移动媒体，投放文化市场综合执法法制宣传动画短片
;
依托电台、电视台、楼宇电视等视听渠道，播发播放文化市场综合执法公益广告
;
依托微信公众号、官方微博等线上媒体，开设文化市场综合执法普法专栏，开展知识问答、以案释法等活动。
（二）要开展“五进”活动
深入开展法制宣传进机关、进文化娱乐经营场所、进文化场馆、进旅游经营单位、进文保单位等活动，通过
LED
屏幕、制作宣传展板、发放宣传材料、宣讲法制案例等形式宣传文化市场综合执法政策法规，增强公众法制观念。
（三）要落实专题培训
结合各地近年来文化市场综合执法案件类型、领域、案由等，有针对性地举办市场主体法制专题培训班，提升各类市场主体的依法守法经营意识。
四、工作要求
(
一
)
市文旅局成立由局分管领导任组长，局机关各科室、局属各单位为成员的文化市场综合执法法制宣传领导小组。各县区（管委会）文旅部门要高度重视，精心制定法制宣传计划，切实加强组织领导，确保宣传活动落到实处。
(
二
)
各县区（管委会）文旅部门要主动与新闻媒体协调，做好本次活动的宣传工作，以扩大活动的社会影响。要重点宣传近期开展的文化和旅游市场整治行动，充分展示文化市场综合执法的成效。
(
三
)
各县区（管委会）文旅部门要对本地区法制宣传活动进行总结，并于
2019
年
10
月
25
日前将相关材料
(
书面总结、新闻稿件、新闻视频、活动图片等
)
报送至市局市场法规科。
(
四
)
机关各科室、局属各单位
要高度重视，把普法工作融于业务工作全过程，强化法治思维，突出依法行政，确定专人负责，严格按照“谁执法谁普法”“谁服务谁普法”责任清单，扎实开展法治宣传教育，确保工作落到实处、见到实效。
