莆田市文化和旅游局关于修订演出市场行政处罚裁量权裁量意见的通知

发布时间：2019-09-20 15:15
| | |

各县区文化体育和旅游局，湄洲岛管委会社会事务局、旅游局，北岸工委宣传部、文旅办，局市场法规科、市文化市场综合执法支队：

根据《国务院关于修改部分行政法规的决定》（国务院令第666号）和《文化部关于废止和修改部分部门规章的决定》（文化部令第57号）对《营业性演出管理条例》及《营业性演出管理条例实施细则》进行修订的相关内容，经研究，特对局行政处罚裁量权（演出）部分进行修改，现将新修改的《莆田市文化和旅游局规范行政处罚裁量权裁量意见》（演出）印发给你们，请参照执行。

 

 

附件：《莆田市文化和旅游局规范行政处罚裁量权裁量意见》

（演出）

2019年9月20日
