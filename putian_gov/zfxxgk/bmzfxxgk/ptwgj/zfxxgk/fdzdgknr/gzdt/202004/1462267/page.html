莆田市文化广电新闻出版局关于加强涉外营业性演出活动审批和监管的通知

发布时间：2018-12-10 17:20
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属有关单位：

近年来，我市涉外营业性演出活动数量持续增加，演出内容形式丰富多样，对丰富人民群众文化生活，促进我市文化市场繁荣发展起到积极作用。与此同时，当前涉外演出市场也存在一些不容忽视的安全隐患问题，如部分演出场所引进外籍演员未经审批擅自举办营业性演出活动；一些外籍演员表演低俗、良莠不齐；部分外籍艺员非法入境、非法居留、非法就业（以下简称“三非”）等。根据市“三非”外国人专项治理协调小组办公室工作部署，为进一步加强我市涉外营业性演出活动的审批和监管工作，确保演艺市场繁荣安全有序，现就有关事项要求如下：

一、各县区（管委会）文化主管部门应从讲政治的高度，清醒认识“三非”问题的危害性和严重性，切实规范涉外演出中介机构管理，严格审批外国人来华从事营业性演出许可，加强对涉外营业性演出活动的演员和内容审查，以高度的政治责任感和担当精神，切实履行好属地监管职责。

二、各县区（管委会）文化主管部门要按照“四不原则”，针对涉外演出项目的“举办单位”、“演出场地”、“演员/表演团体”、“演出内容”等四要素进行重点审查，严把准入关口。一是演出举办单位不具备申报涉外演出活动资质，对涉外演出人员和活动不能全程监管到位的不予受理；二是室内演出场所未经消防部门验收合格，户外临时搭建场地没有取得公安大型活动受理函/许可单的不予受理；三是外籍演员/表演团体应当持有效Z字签证或工作证明文件申请涉外演出活动，以旅游签、商务签、留学签等其它非工作签证申报的不予受理；四是演出表演内容有违反《营业性演出管理条例》第二十五条规定的不予受理。

三、各县区（管委会）文化主管部门、文化市场综合执法机构要重点加强对歌舞娱乐场所、主题公园、宾馆、饭店、酒吧、餐饮场所等非演出场所经营单位及大型体育馆、体育场等临时搭建舞台看台的涉外营业性演出的巡查工作，及时发现外国人非法就业线索，通报同级公安机关并配合查处违法行为。

四、各县区（管委会）文化主管部门要牢固树立全局意识和统筹意识，充分履行部门职能，密切部门间协作配合，主动会同同级公安出入境管理部门联合开展查处外国人非法演出专项检查行动，确保低调稳妥。要梳理自2018年1月1日至10月30日审批的涉外营业性演出批件，会同同级公安出入境部门开展人员入境、按期离境、演出地点等方面的核查，并于每月5日前将上月开展核查情况报送各县区（管委会）协调小组。

五、请各县区（管委会）文化主管部门及时归纳总结在加强涉外演出审批和监管过程中的经验做法、案件查处、取得成效、存在问题等内容，并形成工作报告于2019年3月10日前报送市文化广电新闻出版局市场与产业科。
