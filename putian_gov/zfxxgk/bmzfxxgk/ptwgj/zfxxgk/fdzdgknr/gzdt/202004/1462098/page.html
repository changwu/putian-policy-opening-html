莆田市文化广电新闻出版局关于印发教育实践活动建章立制计划的通知

发布时间：2014-09-12 08:00
| | |

局机关各科室、局属各单位：

现将《莆田市文化广电新闻出版局教育实践活动制度建章立制计划》印发你们，请各相关责任单位抓紧研究，尽快拟稿，提请局党组会议或局务会议研究出台文件。

 

                     莆田市文化广电新闻出版局

                          2014年9月12日

 

 

 

 

 

莆田市文化广电新闻出版局教育实践

活动建章立制计划

 

为切实推进我局教育实践活动制度建设，根据市委教育实践活动办公室《关于做好教育实践活动整改落实、建章立制工作的通知》（莆群组办〔2014〕20号）要求，结合我局实际，制定本计划。

一、总体要求

紧扣为民务实清廉主题，有计划、有步骤推进制度建设，切实形成制度体系，用制度机制固化教育实践活动成果。工作中注意把握以下基本要求：

1.突出重点、聚焦“四风”。以落实中央八项规定精神和省市实施意见为切入点，紧扣解决“四风”突出问题，分析原因，找准症结，抓紧修订完善已有制度，通过对关键性制度的完善和突破，最大限度地堵塞滋生“四风”问题的漏洞。

2.科学管用、简便易行。严格落实中央和省、市委的统一要求，紧密结合具体问题的实际，提出务实管用的措施和办法，确保建立的制度可执行、可监督、可检查、可问责。

3.立足当前、着眼长远。坚持从解决具体问题入手，需要什么制度就建立完、善什么制度，什么制度紧要就抓紧建立、完善什么制度，切实回应干部群众的关切和期盼。坚持经常抓、长期抓，严格党内生活锻炼，坚持贯彻民主集中制，提高密切联系群众的觉悟和做好群众工作的能力，形成促进党员干部坚持为民务实清廉的长效机制。

二、主要任务

1.认真梳理已有制度。对制度之间有重复或相悖的；现行工作中已经不需要的；与现行法规制度相抵触、不一致的；不适应密切联系群众、加强作风建设要求的，要予以废止。对实践证明行之有效、群众认可，但与新形势新任务要求不相适应的，要与时俱进，进行修订完善。制度缺位的,教育实践活动中好的做法经验需要总结巩固的，要围绕整治“四风”加快新建。

2.建立健全相关制度。结合中央、省委部署的“四风”突出问题专项整治任务，从为民、务实、清廉、保证落实等4个方面加强制度建设。抓紧对已有制度进行梳理，有针对性地确定本地本单位制度建设的重点任务，抓紧健全相关制度规定。做到成熟一项、出台一项、实施一项。

3.加大制度执行力度。建立相关制度推动为民务实清廉等方面制度规定的落实。通过自查、抽查、督查等方式，及时发现制度执行中的问题，督促整改落实。进一步畅通信访、新闻、网络、电话等监督渠道，落实群众监督。加大制度的执行力度，坚决维护制度规定的严肃性、权威性，不折不扣地贯彻落实到位，以制度机制巩固党的群众路线教育实践活动成果。严查违规行为，对违反制度规定的，要发现一起、查处一起，依纪依法严肃处理；对顶风违纪的，要从严从快处理。

三、工作要求

1.加强组织领导。要把制度建设作为整治“四风”、联系服务群众的重要举措，切实落实领导责任，强化顶层设计，坚持标本兼治，以边学边改边建的实际成效取信于民。各牵头领导要亲自主持研究谋划，采取有力措施推动落实。各责任单位要切实负起责任,集中精力抓好制度的完善、整改、建立、落实工作。

2.强化督促指导。局办公室要切实把好制度建设计划关、质量关、公示关，对制度建设质量达不到要求的，及时督促整改到位。教育实践活动基本结束后，组织开展制度建设“回头看”，推进密切联系群众、改进工作作风常态化长效化，以制度机制巩固教育实践活动成果。
