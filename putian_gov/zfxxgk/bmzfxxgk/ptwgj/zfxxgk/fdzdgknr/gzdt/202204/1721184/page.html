莆田市文化和旅游局关于举办莆田市2022年“海峡读者节”的通知

发布时间：2022-04-25 17:04
| | |

各县区文旅局、湄洲岛旅游文体局、北岸党工委宣传部，市文化市场综合执法支队，福建新华发行集团莆田分公司，市出版物发行行业协会，各有关单位：

2022年是党的二十大召开之年，是实施“十四五”规划、开启全面建设社会主义现代化国家新征程的重要一年。为深入贯彻落实市委、市政府关于全民阅读工作的重要部署，以迎接宣传贯彻党的二十大为主线，认真实施“提高效率、提升效能、提增效益”行动，深入推进全民阅读，建设“书香莆田”，大力营造爱读书、读好书、善读书的良好氛围，决定举办莆田市2022年“海峡读者节”。现将有关活动方案印发给你们，请认真抓好落实。

 

 

                                    莆田市文化和旅游局

2022年4月21日

莆田市2022年“海峡读者节”活动方案

 

一、活动主题

阅读新时代 奋进新征程 喜迎二十大 文明伴我行

二、活动时间

2022年4月22日至7月1日

三、主要活动

（一）启动仪式

2022年4月22日（星期五），在莆田市新华书店兴安门市举办莆田市2022年“海峡读者节”暨“绿书签行动”活动启动仪式。

主要内容：（1）“喜迎二十大”重点主题出版物展。（2）版权普法暨“绿书签行动”现场咨询。市文化和旅游局执法人员向群众宣传出版物管理等相关法律知识及讲解对非法出版书鉴定的基本方法，市“扫黄打非”办公室工作人员现场向群众解答“绿书签行动”的内容及意义。（3）世界读书日直播：以亲子阅读为主题邀请讲师线上直播授课借助新华书店微信抖音平台做场世界读书日直播，线上线下开展专题讲座，宣传“倡导全民阅读 建设书香莆田”。

主办单位：市文化和旅游局、市“扫黄打非”领导小组办公室、福建新华发行集团莆田分公司、莆田市城厢区教师进修学校附属兴安小学

承办单位：福建新华发行集团莆田分公司

4.23世界读书日图书巡回展暨“绿书签”宣传活动

1.主要内容：紧紧围绕迎接宣传贯彻党的二十大这条主线，以“党建读物空间”为阵地，组织开展“奋进新征程，建功新时代”—喜迎二十大主题出版物展示展销活动，在书店中心位置进行特色码堆和专台陈列，不断扩大主题出版物对读者的吸引力和影响力。

2.活动方式

（1）图书漂流以书会友

市民可根据需求到任意活动地点将自己的旧书进行交换，在现场打卡后即可找工作人员领取“绿书签”，在书签上写上交友赠语或读书心得，带着书籍漂流到下一个巡回点与其他读者进行交换。

（2）打卡领取图书盲盒

市民可在10个专场进行拍照打卡，凭8个不同专场发布的朋友圈内容或打卡照片，最后到莆田市任何新华书店门店拍照打卡集齐9宫格，即可领取价值99元的图书盲盒一份。

（三）新华·高校图书漂流

在莆田学院、湄职校校园店设置“图书漂流专柜”，鼓励学生将自己的旧书到书店进行交换阅读，领取“绿书签”，在书签上留下自己的读书心得感悟，夹进书中等待交换，让图书“漂流”起来，让书香“传递”下去。

（四）2022年春季新华馆藏图书线上订货会

线上展示适合图书馆的中文出版物25万种，其中2021年1月至今出版的新书品种约15万种，设立“喜迎二十大”主题出版物展、重点图书推荐展、闽版出版成果展、名社好书展等多个专区，为出版社和图书馆搭建起沟通交流的重要平台。

（五）新华阅读嘉年华活动

以海峡读者节为契机，融合“福”文化，结合“百家万品”选品工程，充分利用“新华·党建读物空间”“新华·阅读中心”“新华·作家空间”和“新华·阅读指导志愿者联盟”等平台，精心组织策划“我们的节日”“我是图书选品师”等富有特色的阅读活动，增强与读者的互动，共享文化盛宴。

（六）全民阅读“七进”活动

全民阅读深入机关、企业、学校、农村、军营、社区、家庭，开展各类阅读分享活动和“图书漂读”活动，设立“图书漂读”项目点，完善阅读公共服务基础设施建设，拓展阅读人群覆盖面，持续深入推动全民阅读“七进”工作。

（七）一起读书吧·百城百店共读计划

 参加“一起读书吧·百城百店共读计划”，邀请读者在世界图书日一起读书吧。和小读者喜爱的儿童文学作家沈石溪、汤汤、乐多多、八路、黑鹤一起加入“一起读书吧·百城百店共读计划”邀你一起读书共同领略阅读的魅力。

(八)“假期读一本好书”活动

以“读好书，诵经典，喜迎党的二十大”为主题，围绕弘扬优秀传统文化、展现大国风采、传承奥运精神、迎接二十大等主旋律，组织开展阅读征文活动，引导和培养广大青少年“好读书，读好书，读书好”的良好习惯，倡导积极向上、昂扬奋进的进取精神。
