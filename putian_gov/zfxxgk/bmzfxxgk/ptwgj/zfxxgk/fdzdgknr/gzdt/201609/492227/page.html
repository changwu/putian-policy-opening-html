中共莆田市委宣传部莆田市文化广电新闻出版局莆田市国防教育办公室关于举办国防教育暨纪念红军长征胜利 80周年书画作品展的通知

发布时间：2016-09-19 09:39
| | |
各县区委（工委）宣传部、文体广电新闻出版局（社会事务局）、国防教育办公室、各高等院校、各有关单位：

   为了进一步学习贯彻习近平总书记关于国防建设的重要讲话精神，教育引导广大干部群众铭记我党我军的光荣历史，培养爱党爱国、心系国防、缅怀先烈的社会风尚。中共莆田市委宣传部、莆田市文化广电新闻出版局、莆田市国防教育办公室决定联合举办国防教育暨纪念红军长征胜利80周年全市书画作品展。现将本次展览的有关事项通知如下：

 一、组织机构

主办单位：中共莆田市委宣传部、莆田市文化广电新闻出版局、莆田市国防教育办公室

承办单位：莆田市群众艺术馆、莆田市美术馆、莆田市画院

二、展览主题

传承红色基因，共建巩固国防

三、时间及地点

1.征集作品时间：2016年9月20日至10月25日

2.展览时间：2016年11月1日至11月15日

3.展览地点：莆田市群众艺术馆展览厅

四、征集作品要求

    1.参展作品种类：国画、毛笔书法

2.参展作品尺寸：国画、毛笔书法作品装裱后尺寸不得超过6尺轴或 2米×2米片

3.作品背面用铅笔注明作品名称、作者单位、姓名、身份证号码、手机号码。篆书及草书须附释文。

五、征集作品数量要求

   参展作品在全市范围内征稿，截稿时间为2016年10月20日。由各县区文化行政主管部门填写汇总表并统一收件后报送市群众艺术馆，汇总表电子版发至市群众艺术馆邮箱。市直单位作品可直接报送市群众艺术馆。

   为保护知识产权，不得使用临摹作品参展，如遇版权纠纷问题由作者自行承担。

各县区书画作品征集数量要求：仙游、荔城、城厢、涵江、秀屿分别不低于20件；湄洲、北岸分别不低于10件；每位作者参展的作品数量不限。

各县区委（工委）宣传部、文体广电新闻出版局（社会事业局）、国防教育办公室要高度重视，把征集作品当作一项重要的政治任务来抓，立即行动，采取有力措施，确保圆满完成任务。

六、入选参展及展后事项

国画、书法入选参展作品共计80幅左右，由主办单位组织人员进行筛选后展览，展览结束后作品退回选送单位或作者。

七、收件单位和联系方式

收件单位地址：城厢区学园中街1922号，莆田市群众艺术馆
