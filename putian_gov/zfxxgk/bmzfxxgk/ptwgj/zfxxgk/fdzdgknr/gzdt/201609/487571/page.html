莆田市文化广电新闻出版局关于举办庆祝中国共产党成立95周年暨中国工农红军长征胜利80周年大合唱、广场舞比赛的通知

发布时间：2016-07-21 12:35
| | |

各县区文体广电出版局、湄洲岛社会事务局、湄洲湾北岸工委宣传部：

为庆祝中国共产党成立95周年暨中国工农红军长征胜利80周年，重温党的光辉历程，讴歌中华民族实现伟大复兴中国梦的奋斗历程，缅怀革命先辈的丰功伟绩，充分发掘长征精神的历史内涵与时代价值，经研究决定，在2016年国庆节期间在莆田市群众艺术馆举办庆祝中国共产党成立95周年暨中国工农红军长征胜利80周年大合唱、广场舞比赛，现将有关事项通知如下：

一、组织机构

主办单位：莆田市文化广电新闻出版局

承办单位：莆田市群众艺术馆

二、比赛形式

采取县区（管委会）选拔赛和市级决赛方式进行。县区（管委会）选拔赛由各县区（管委会）文化行政部门自行确定时间、地点，自行组织比赛。市级决赛由莆田市群众艺术馆具体组织，大赛设一等奖、二等奖、三等奖和组织奖若干个；颁发荣誉证书和奖金。

三、决赛安排

（一）合唱比赛

1.比赛时间

2016年9月26日

    2.队伍选送

仙游县、荔城区、城厢区、涵江区、秀屿区各选送2支队伍，湄洲岛、北岸各选送1支队伍，老年大学选送1支队伍参加市级决赛（报名表附件2）。莆田学院音乐学院合唱团参加决赛展演，不参与奖项角逐。

    3.参赛要求

队伍人数：合唱队伍人数控制在30至50人。参赛曲目：两首，从备选曲目中选择（附件3）。演唱时间：两支曲目总演唱不超过10分钟。演唱方式：可根据参赛团队实际，选择齐唱或者多声部合唱。演唱伴奏：可钢琴伴奏或使用伴奏带。

    4.评审方法

合唱比赛由歌曲内容、台风面貌、艺术效果三部分对各参赛合唱队进行综合评分。

（1）进出场迅速有序，做到快稳准，队形整齐，服装统一，仪态大方，精神饱满。

（2）歌曲内容思想性强，健康向上，整体编排新颖。

（3）指挥姿势正确，指挥灵活准确，动作大方协调，与乐曲情绪相符。

（4）合唱人员，指挥，伴奏舞台表演恰当，配合默契。

（5）准确把握歌曲的主题思想，具有良好感染力。音乐处理得体，音色优美，声音洪亮，吐字清晰，气势磅礴，声部均衡和谐，强弱快慢对比鲜明，有乐感和表现力。声部层次清晰、有立体感，音乐情感表达细腻。

（6）演唱方法正确，形式丰富新颖，具有一定的艺术技巧，音准节奏掌握良好，作品表现完整，具有一定的艺术水准。

    5.材料报送

各县区（管委会）指定专人负责市级总决赛的报名和参赛工作，并于9月15日前汇总参赛队伍材料，报送莆田市群众艺术馆。

（二）广场舞比赛

1.比赛时间

2016年9月30日

    2.队伍选送

仙游县、荔城区、城厢区、涵江区、秀屿区各选送2支队伍，湄洲岛、北岸各选送1支队伍，老年大学选送1支队伍参加市级决赛（报名表附件1）。

    3.参赛要求

    队伍人数：每支参赛队伍由16人组成。音乐要求：所有参赛队伍统一使用U盘。参赛作品的伴奏需单独留盘，备注队伍及作品名称。表演时间：每支队伍作品的表演时间限定在4分钟之内。

    4.评审方法

（1）动作与队形编排：动作新颖流畅，队形变化巧妙（至少4个队形以上），画面富有美感，舞蹈动作设计应与音乐风格及节奏律动相吻合。鼓励原创，音乐及动作具有莆仙地域文化特色和地方广场舞蹈元素的作品。

（2）表现力：队员表情自然，表演投入，动作节奏准确到位、用形体的律动表达音乐的思想感情。

（3）服饰妆容：要求队员着装统一，简洁大方，舞台整体效果好。

    5.材料报送

各县区（管委会）指定专人负责市级总决赛的报名和参赛工作，并于9月19日前汇总参赛队伍材料，报送莆田市群众艺术馆。

四、工作要求

1.请各县（区、管委会）文化主管部门高度重视，务必要求把握时间节点，认真组织实施，确保各项赛事圆满成功。

2.莆田市群众艺术馆作为此次活动的具体承办单位，应加强整个活动的筹备工作。各项赛事的具体比赛时间及比赛赛程由市群众艺术馆统筹协调。

联系人：林陈宇，电话：0594-2658293，邮箱：ptsysg@163.com。
