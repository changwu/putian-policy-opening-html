莆田市文化和旅游局关于印发2023年普法责任清单的通知

发布时间：2023-09-18 10:16
| | |

机关各科室、局属各单位：

　　根据《关于印发<2023年莆田市重点市直机关普法责任清单>的通知》（莆法普组〔2023〕5号）精神，为进一步明确各单位普法职责任务，健全工作制度，不断推进普法工作深入开展，我局制定了《莆田市文化和旅游局2023年普法责任清单》，现印发给你们，请抓好贯彻落实。
