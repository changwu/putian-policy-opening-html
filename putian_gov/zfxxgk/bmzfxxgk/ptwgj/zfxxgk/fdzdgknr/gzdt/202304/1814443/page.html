莆田市文化和旅游局关于举办第九届 “海峡读者节”暨“护苗2023· 绿书签行动”的通知

发布时间：2023-04-21 11:16
| | |
 各县区文化体育和旅游局，湄洲岛旅游和文化体育局，北岸党工委宣传部，福建新华发行集团莆田分公司，莆田市出版物发行业协会，各有关单位：

2023年是全面贯彻落实党的二十大精神的开局之年，也是莆田建市40周年，为全面贯彻落实习近平总书记关于推进全民阅读、建设书香社会的重要指示精神，深入开展学习贯彻习近平新时代中国特色社会主义思想主题教育，贯彻落实党的二十大报告关于“深化全民阅读活动”的战略部署，认真实施“深学争优、敢为争先、实干争效”行动，在全社会大力营造爱读书、读好书、善读书的良好氛围，建设“书香莆田”，助力文化强市建设，我局决定于2023年4月至7月举办第九届“海峡读者节”暨“护苗2023·绿书签行动”，现将有关活动方案印发给你们，请认真抓好落实。

 

附件：第九届“海峡读者节”暨“护苗2023·绿书签行动”方案

附件：

第九届“海峡读者节”暨

“护苗2023·绿书签行动”方案

 

为深入推进全民阅读，建设“书香莆田”，在全社会大力营造爱读书、读好书、善读书的良好氛围，定于2023年4月至7月举办第九届“海峡读者节”暨“护苗2023·绿书签行动”，具体方案制定如下。

一、活动主题

奋进新征程，书香新福建

二、活动时间

2023年4月至7月

三、主要活动

（一）开幕式活动

1.活动时间

2023年4月21日（星期五）上午9：30

2.组织单位

主办单位：莆田市文化和旅游局、福建新华发行集团莆田分公司、莆田市“扫黄打非”领导小组办公室

协办单位：莆田学院图书馆、莆田学院妈祖文化研究院、莆

田市出版物发行业协会、莆田学院大学生社团

3.活动地点

莆田学院紫霄校区新华书店

4.主要内容

（1）第九届“海峡读者节”活动暨“护苗2023·绿书签行动”启动仪式。

（2）优秀出版物主题展。作家出版社、中信出版集团、中华书局等出版社联合展出近年来优秀出版物。

（3）版权普法暨“绿书签行动”现场咨询。市文旅局执法人员向学生讲解非法出版书鉴定的基本方法，市“扫黄打非”办工作人员现场向学生解答“绿书签行动”的内容及意义。

（4）莆仙文化讲座。参观妈祖文化研究院，感受海滨邹鲁、文献名邦孕育的妈祖文化魅力，特邀两位台湾籍老师介绍妈祖文化的研究成果。

（5）新华·高校图书集市。参观莆田学院图书集市，在莆田学院、湄职校校园店设置“图书漂流专柜”，鼓励学生将自己的旧书到书店进行交换阅读，现场领取“绿书签”，在书签上留下自己的读书心得感悟，夹进书中等待交换，让图书“漂流”起来，让书香“传递”下去。开展新书特卖会，精选好书75折优惠选购。

（6）图书小剧场。莆田学院读者协会组织学生演出，通过表演领悟书中人物的内心世界，体会表演乐趣，激发阅读兴趣。

（7）读者座谈会。视频回顾4月以来读书会的活动，举办读书分享，在不同的观点碰撞中体验阅读的不同视角，在头脑风暴的火花中收获乐趣。

（二）主题出版物展示展销活动

时间：4月23日开始

地点：全市各新华书店门市

主要内容：以“新华·党建读物空间”为阵地，开展学习贯彻习近平新时代中国特色社会主义思想主题教育出版物主题展销；开展“学习二十大，奋进新征程”——深入学习贯彻党的二十大精神主题书展，在全市书店中心位置进行特色码堆和专台陈列；持续推出 “新华·党建读物空间”图书目录以及领导干部阅读推荐书目等主题书单。

（三）4·23世界读书日“悦读福‘见’——春耕计划”巡展暨“护苗2023·绿书签行动”系列宣传活动。

1.图书漂流以书会友。市民可根据需求到任意活动地点将自己的旧书进行交换，在现场打卡后即可找工作人员领取“绿书签”，在书签上写上交友赠语或读书心得夹进书中，莆田市新华书店将带着书籍漂流到下一个巡回点与其他读者进行交换，让图书“漂流”起来，让书香“传递”下去。

2.打卡领取图书礼包。市民可在莆田市各巡回展区进行拍照打卡，凭3个不同专场（含新华书店各门市）打卡照片或任选13个我市非物质文化遗产中的3个主题手牌打卡照发布朋友圈附文字“书香莆田，我在xx等你来”“我是莆田非遗xx传播者”等宣传内容，即可领取价值59元的书香礼包一份。

（四）优秀图书优惠展销活动

时间：4月至7月

地点：全市各新华书店门市

主要内容：各新华书店实行全年最优惠促销，线上线下同步开展，最大力度让利读者。

1.“新华有礼”优惠活动。活动期间，全市新华书店所有门店实行8折优惠销售，“4·23海峡读者节”当天75折优惠（目录内教材教辅和集团规定不予打折的品种除外）。读者可登录福建新华发行集团在线商城（网址：http://mall.fjxhfx.com）优惠共享。

2.绘本特惠促销活动。新华书店联合少儿类绘本优质供商开展2023年绘本75折特惠促销活动。

（五）主题论坛活动

市新华书店组织举办教师阅读论坛、青少年阅读论坛、家庭阅读论坛等，扎实有效地推广全民阅读，建设学习型社会。并在门店设立“第二届福建新华阅读大会·教师阅读论坛推荐图书”专柜专架，同时开展多种形式的主题阅读分享活动。

（六）2023年春季新华馆藏图书线上订货会

时间：4月22日至7月1日

线上新华云馆配平台网址：http://gp.fjxhfx.com/

主要内容：依托信息化平台和大数据应用，整合全国出版物发行业资源，采用“线下线上联动，现采样采结合”的模式开展，在订货会现场进行图书现采，在新华云馆配线上平台样采。

（七）新华阅读嘉年华活动

时间：4月23日至7月1日

地点：全市各新华书店门市

主要内容：联合有关单位，融合“福”文化，结合“百家万品”选品工程，利用“新华·党建读物空间”“新华·阅读中心”“新华·作家空间”和“新华·阅读指导志愿者联盟”等平台，精心组织策划开展富有特色的阅读文化活动。

（八）出版单位主要阅读文化活动

时间：4月至7月

主要内容：汇集全省出版社优质阅读资源，集中推出一系列线上线下阅读活动。

1.2023年“假期读一本好书”活动。在全市开展“爱读书、读好书、善读书，书香伴成长”为主题的读书活动，举办征文比赛、朗诵比赛、讲故事比赛等配套活动。

2.“书香进校园”系列讲座。举办“新课标背景下的单元整体教学”主题讲座，“在希望的田野上”——新时代山海交响系列阅读分享会，“追寻二十四节气的脚步，探索奇妙的本草博物世界”专题分享会，“神秘的三星堆文明”人文科普讲座等。

（九）全民阅读“七进”活动

时间：4月22日至7月1日

主要内容：福建新华发行集团莆田分公司深入机关、企业、学校、农村、军营、社区、家庭，开展各类阅读分享活动和“图书漂读”活动，设立“图书漂读”项目点，完善阅读公共服务基础设施建设，拓展阅读人群覆盖面，持续深入推动全民阅读“七进”工作。

（十）一起读书吧·书店之选百店共读计划

时间：4月13日至4月30日

地点：市新华图书城

 参加由全国120个城市、200家书店发起的“一起读书吧·书店之选百店共读计划”邀请读者在世界图书日一起读书吧。即日起至4月30日针对全国第四届“全民阅读·书店之选”活动中千家实体书店选出的“十佳儿童文学作品”任一本读者发送相关内容发朋友圈并截图反馈给莆田市新华书店微信客服即有机会瓜分万元图书大礼。

（十一）线上平台促销（“绿书签”优购）活动

时间：4月16日至4月30日

地点：全市各新华书店门市

为配合“4·23海峡读者节”的开展，助力推广全民阅读及“绿书签行动”，培养读者线上线下同步购书的用户习惯，在新华电商平台上开展优购75折活动。
