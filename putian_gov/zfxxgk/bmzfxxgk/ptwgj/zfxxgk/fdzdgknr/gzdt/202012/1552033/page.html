莆田市文化和旅游局关于开展全市不可移动文物保护工作监督检查的通知

发布时间：2020-12-11 11:46
| | |

各县区文旅局，湄洲岛旅游和文体局、北岸党工委宣传部：

根据《福建省人民政府办公厅关于加强历史文化名城名镇名村传统村落和文物建筑历史建筑传统风貌建筑保护利用九条措施的通知》（闽政办〔2020〕53号）、《福建省住房和城乡建设厅  福建省文物局关于开展历史文化名城名镇名村传统村落保护工作监督检查的通知》（闽建风貌函〔2020〕58号）要求，经研究，定于近期开展全市不可移动文物保护工作监督检查。现将有关事项通知如下：

一、监督检查对象

全市各级文物保护单位和未定级不可移动文物，重点检查历史文化名镇、名村、街区和传统村落中的民居类文物建筑。

 

二、监督检查主要内容

（一）文物保护“四有”工作情况。开展文物“四有”工作，即划定必要的保护范围、作出标志说明、建立记录档案、设立专门机构或者专人负责管理及县区级以上文物保护单位建设控制地带划定公布等情况。（具体检查内容详见附件）

（二）抢救性保护措施情况。面临倒塌、损毁危险的濒危不可移动文物的具体名单，采取应急性、临时性抢救加固措施，实施抢险加固、保养维护工程，及时对民居类不可移动文物范围内外杂草杂物进行清理等情况。

（三）保护方案编制情况。依保护现状组织编制、报批不可移动文物保护工程设计方案。

（四）专项资金保障情况。各县区制定文物保护资金管理办法和相关政策、文物保护资金财政预算、鼓励和引导民间资本投入等情况。

（五）传统格局保护情况。名城、街区、名镇名村和传统村落的传统格局、历史风貌和空间尺度是否得到保护，是否进行大拆大建、拆真建假，保护范围内是否按建筑物分类保护实施整治等。

三、监督检查人员及时间安排

（一）检查人员

分2个检查组，每个组具体分工监督检查工作：

第一组：蔡明贤、陈飞新、温国献，负责仙游县、荔城区、秀屿区的检查工作；

第二组：余志武、吴芳芳、邹志鹏，负责城厢区、涵江区、湄洲岛、北岸管委会的检查工作。

（二）检查方式

以现场查看为主，并询问相关材料和沟通交流核实相关情况。

（三）检查时间

由每组各自另行通知。

四、有关工作要求

（一）各县区（管委会）文物行政主管部门要确定一名联络员，将名单和联系电话于12月3日前报市文旅局邮箱sqd2399655@163.com。同时，立即开展自查，相关自查情况以书面形式报告市文旅局。

（二）各县区（管委会）文物行政主管部门要组织人员提前介入，积极配合住建、自然资源部门做好辖区内历史文化名镇名村传统村落保护工作监督检查。

（三）监督检查期间严格落实中央八项规定及实施细则精神和省委省政府有关要求，严格执行公务活动食宿、交通标准，严格遵守保密规定。

监督检查内容

类别

具体内容

一、文物建筑保护

1.完成文物“四有”工作：划定必要的保护范围、作出标志说明、建立记录档案、设立专门机构或者专人负责管理；

2.县区级以上文物保护单位划定公布建设控制地带工作；
3.对不可移动文物开展日常巡查监管工作。

二、实施保护工程和有关规定情况

1.对面临倒塌、损毁危险的濒危不可移动文物，是否采取应急性、临时性抢救加固措施，实施抢险加固、保养维护工程，是否及时对民居类不可移动文物范围内外杂草杂物进行清理等情况；
2.建设工程选址，是否避开不可移动文物；因特殊情况不能避开的，是否实施原址保护。对不可移动文物实施原址保护的，建设单位是否事先确定保护措施，报城市、县人民政府同级文化（文物）主管部门批准。

三、组织编制保护方案情况

1.编制文物保护设计方案并报批情况；

2.批准文物保护设计方案情况。

四、安排文物保护资金情况

1.县区（管委会）制定文物保护资金保障的管理办法和政策情况；

2.在年度财政预算中安排专项资金情况，近5年投入金额；

3.鼓励和引导民间资本投入情况，近5年投入金额。

五、传统格局保护情况

1.开山、采石、采砂、开矿、毁林开荒等破坏传统格局和历史风貌情况；
2.修建生产、储存爆炸性、易燃性、放射性、毒害性、腐蚀性物品的工厂、仓库、码头等情况；
3.修建损害传统格局和历史风貌的建筑物、构筑物和其他设施，特别是对成片传统风貌建筑区域造成破坏等情况；
4.设置破坏或者影响风貌的广告、标牌、招贴等情况；
5.随处倾倒垃圾、排放污水等污染环境情况。
