莆田市文化和旅游局关于开展连续性内部资料性出版物2019年度核验换证工作的通知

发布时间：2019-12-23 17:15
| | |

各连续性内部资料性出版物编印单位：

为进一步规范和加强我市连续性内部资料性出版物管理，根据《内部资料性出版物管理办法》规定和省新闻出版局有关精神，结合工作实际，决定开展2019年度全市连续性内部资料性出版物核验换证工作，有关事项通知如下：

一、核验换证范围

2019年11月30日前经市文化和旅游局批准登记的连续性内部资料性出版物，均须参加本年度核验换证。

二、核验换证内容和要求

（一）连续性内部资料性出版物编印单位须严格依照《内部资料性出版物管理办法》进行自查，重点检查以下内容：

1.是否刊载《内部资料性出版物管理办法》和其他法律、法规规定禁止刊载的内容，是否刊载有政治导向错误、妨害青少年身心健康和违反社会公德方面的内容，造成不良社会影响的。

2.编辑、印刷、发送等活动是否符合法律法规和规章的有关规定。具体包括：是否严格限定在本行业、本系统、本单位内部交流；是否在社会上征订发行、在公共场所摆放、传播到境外、收取费用、刊登广告、拉赞助或搞有偿经营性活动；是否与外单位以“协办”形式进行印刷发行；是否在名称中使用“××报”（原高校校报转入连续性内资系列的除外）、“××刊”或“××杂志”等字样；是否在封面完整印刷标注《准印证》编号和“内部资料，免费交流”字样；是否在明显位置（封面、封底或版权页）标明编印单位、发送对象、印刷单位、印刷日期、印数和期号等。

3.是否擅自变更准印证的登记项目，是否存在“一期多版”及出租、转借、转让内部资料性出版物准印证号等问题。

4.是否按要求及时向相关行政管理部门缴送出版物样本。

（二）各连续性内部资料性出版物编印单位要对照以上内容，

认真进行检查，形成自查书面报告。有违规行为的，要根据《内部资料性出版物管理办法》有关规定，落实整改。具体要求如下：

1.已在社会上征订收费的，必须全部作清退处理，并在年度核验换证时提交清退清单复印件（加盖编印单位公章）。

2.未在封面完整印刷标注《准印证》编号和“内部资料，免费交流”字样，未在明显位置（封面、封底或版权页）标明编印单位、发送对象、印刷单位、印刷日期、印数和期号的，存在刊登广告、刊登多家理事、协办单位，以及存在冠以“××报（原高校校报转入连续性内资系列的除外）”“××刊”“××杂志”等违规情况的，须提供整改后最新编印的样本1份。

3.未及时寄送样本或样本不齐的，核验换证前请先补齐样本。

（三）《连续性内部资料性出版物2019年度核验换证表》，填写内容须真实完整。

（四）对经审核符合规定的连续性内部资料性出版物，将予以通过年度核验换证；对违反有关规定的连续性内部资料性出版物，将注销其准印证。

三、核验换证流程

参加年度核验换证的各连续性内部资料性出版物编印单位须于2020年1月3日前提供以下材料：

（一）2019年度自查报告一份（加盖编印单位公章）。自查报告要真实全面，认真对照本通知明确的核验换证内容，结合2019年度工作情况进行撰写。自查中发现问题需要整改的，应提供相应情况材料。

（二）《连续性内部资料性出版物2019年度核验换证表》一份（加盖编印单位公章）。

（三）《连续性内部资料性出版物准印证》原件。

（四）提交2019年度最后两期样本一套。未能提交样本的，必须在自查报告中说明原因，否则视为未能正常编印。

四、其他事项

（一）请各单位要安排专人负责（加入莆田市报刊工作QQ群：824437615），根据以上要求及时办理年度核验换证手续。对未说明充分理由又逾期不报送核验换证材料的单位，将予以暂缓换证处理；对经催告后仍不参加核验换证的单位，将根据有关规定直接注销其准印证，取消其编印资格。

（二）核验换证时间

2020年1月10日前全面完成工作。

（三）核验换证地点

莆田市文化和旅游局新闻出版科（市政府3号楼118室），联系人：郑玉辉，手机：13959593704，邮箱：ptsxwcb@163.com。
