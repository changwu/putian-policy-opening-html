关于印发《莆田市旅游服务质量提升方案》的通知

| | |

各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸宣传部、文旅办：

为进一步规范旅游市场秩序，提升旅游服务质量，营造全市旅游发展良好环境，持续打造“妈祖圣地美丽莆田”旅游品牌，特制定《莆田市旅游服务质量提升方案》，现印发你们，请结合实际认真贯彻落实。

附件：莆田市旅游服务质量提升方案

 

 

                           莆田市文化和旅游局

                             2019年6月11日

附件

莆田市旅游服务质量提升方案

 

为切实加强旅游行业监管工作的制度化、规范化及长效机制建设,提升旅游服务质量,促进全市旅游行业持续健康高质量发展,推进“妈祖圣地 美丽莆田”旅游品牌建设，根据省文化和旅游厅关于印发《福建省旅游服务质量提升方案》（闽文旅市场〔2019〕6号），结合我市实际，特制定本方案。

一、指导思想

以习近平新时代中国特色社会主义思想和党的十九大精神为指导,全面贯彻落实全省、全市文化和旅游工作会议精神,大力实施旅游质量提升工程,完善旅游服务质量体系,加强旅游服务质量监管,切实优化旅游发展环境,推动旅游业高质量发展，不断提升广大游客旅游体验获得感与满意度。

二、工作原则与总体目标

(一)工作原则

坚持政府、市场主体、行业组织、个人4个层面协同推进。坚持把人民群众更加满意作为旅游发展的价值导向，把诚信旅游作为旅游发展的重要基石,把“质量兴旅”作为旅游发展的核心理念,把安全旅游作为旅游发展的基本要求,把基础建设作为旅游质量发展的保障条件,把质量提升作为旅游发展的强大动力。

（二）总体目标

到2020年，全市的旅游供给质量明显改善，旅游服务和管理质量显著提高，旅游市场秩序规范有序，旅游市场综合监管机制更加完善，旅游公共服务水平明显增强，旅游消费环境明显优化，旅游优质产品供给更加丰富，文化和旅游融合不断深入，游客投诉量明显降低。

三、工作任务

通过提升旅游景区（景点）、旅行社的服务水平，规范和优化旅游住宿、在线旅游经营服务，提高导游和领队业务能力，建立完善旅游信用体系，不断增强旅游市场秩序治理能力，提升旅游服务质量，推动旅游业高质量发展。

(一)夯实旅游服务质量基础

1.切实加强旅游公共服务。深入贯彻落实《“十三五”全国旅游公共服务规划》,进一步完善旅游公共信息、咨询服务投诉处理、应急处置、紧急救援、旅游责任保险等旅游公共服务体系。推进旅游集散中心、旅游停车场、自驾车营地、游客咨询中心、旅游公共厕所等旅游公共服务设施建设。规范景区标牌标识体系和解说系统,加强重要旅游预警提示信息发布,不断扩大旅游公共信息服务的覆盖面。

2.推动智慧旅游发展。完善全市旅游服务信息化体系,建立旅游服务信息共享机制,通过全国旅游监管服务平台,归集导游执业信息、游客评价及奖惩投诉信息、带团实时位置等。完善旅游质量信息发布制度,为公众提供准确、可靠、及时的质量信息。以整合完善“12301”系统为重点,健全覆盖全市的旅游咨询、投诉以及举报网络、线上线下旅游信息服务集群和旅游信息声讯服务系统。深入推进智慧旅游景区、智慧旅游企业建设,提高旅游质量控制和质量管理的信息化水平。

(二)完善旅游服务质量体系

坚持星级饭店、A级景区等服务质量等级评定机制,严格质量标准准入条件。对评定为相关服务质量等级的旅游企业,切实抓好评定后续管理,严格动态监管,对质量下降、达不到相应质量等级标准的旅游企业,予以取消等级、强制退出或依法取缔。

(三)强化旅游服务质量监管

1.强化旅游市场综合整治。坚持“标本兼治、疏堵结合”的方针,健全和完善旅游投诉、举报处理和信息发布制度。认真落实“放心游莆田”旅游服务承诺，畅通旅游投诉和消费维权渠道,及时有效调解处理旅游纠纷。集中开展打击不合理低价和强迫购物消费专项行动,继续开展“暑期整治”“利剑行动”等行动,重拳打击“黑社”“黑导”“黑车”等违法违规行为,集中处理一批典型案件,形成公平有序、诚实守信的旅游市场环境。

2.实施旅游风险综合管理。坚持“安全第一、预防为主、综合治理”的方针,加强宣传培训教育,加大监督管理力度。完善风险管理工作机制,提升应急处置能力。加强对重点旅游目的地和高风险旅游产品安全风险监测和评估。加强风险信息资源共享,建立和完善旅游风险预警预报制度,对重大隐患及时处置。

(四)把握旅游服务质量提升重点

1.提升旅行社（分社、营业部）服务质量。支持、引导国内外品牌旅行社在我市设立分支机构,促进我市旅行社转型升级。推动旅行社优化产品结构，开发文化旅游、红色旅游、养老旅游、研学旅游、房车旅游、邮轮旅游等产品。规范旅行社广告发布、合同签订和价格监管，提升旅行社守法、诚信和安全意识。鼓励旅行社依托智能化、大数据、云计算等，创新产品体系，实现全产业链运营。规范旅行社在线经营，对在线旅游经营服务依法加强监督检查。指导在线旅游企业全面排查境内外自助游产品，发现不合格自助产品立即下架。加强对攀岩、冲浪、浮潜等高风险旅游项目的安全提示。

2、提升导游（领队）业务能力。加强优秀导游（领队）

培训，使导游的讲解真正做到精准讲解、“行家”讲解。开展应急培训和演练，增强应急处置、沟通协调和风险防控能力。加大对“金牌导游”的宣传力度，发挥“金牌导游”的标杆、引领和示范作用。利用全国旅游监管服务平台开展导游信用综合评价，严肃惩戒导游失德失信行为，将导游失德失信和违法违规行为列入“双公示”，接受社会监督。

3.提升旅游住宿饭店服务。扶持民宿、文化主题酒店、自驾营地等新业态发展，推动高端精品民宿发展。建设基础设施完善、功能齐全的自驾车、旅居车露营营地，大力发展民宿经济，推动乡村旅游发展。强化星级旅游饭店评定复核工作，联合有关部门对卫生、食品安全、消防安全等重点环节开展抽查，对不达标的星级饭店坚决予以取缔。支持国际知名品牌连锁酒店入驻我市,带动并提升全市星级饭店品牌。推动全市旅游星级饭店业向标准化、精品化、特色化发展。

4.提升旅游景区服务质量。落实《福建省百家重点A级旅游景区三年行动提升工程方案（2017-2019年）》要求，积极引导重点A 级景区推进厕所革命，科学配置提升景区游客中心，改进提升标识导览系统。推进红色景区创建A级景区，全面提升红色景区景点等级和特色。落实《乡村旅游“百镇千村”提质升级三年行动计划（2018-2020）》，持续创建休闲集镇和乡村旅游特色村。实施休闲集镇和旅游村评定工作，配合有关部门促进民宿业规范发展。实施旅游扶贫富民工程。

(五)构建旅游服务质量提升机制

1.深化文明旅游。贯彻实施《提升中国公民旅游文明素质行动计划》,按照《关于做好2019年文明旅游宣传引导工作的通知》要求（闽文旅市场〔2019〕22号），以“文明旅游 为中国加分--出行有礼”为主题，教育引导游客遵守境内外旅游目的地法律法规，引导游客了解并尊重当地风俗习惯，引导游客遵守社会公德，保护野生动物，爱护水体环境。积极打响“文明旅游为中国加分”品牌，开展文明旅游公益活动,创建旅游行业文明窗口。组织开展“文明旅游进A级景区、进课堂、进社区、进农村”主题活动,充分利用“中国旅游志愿者APP”,打造全民参与的文明旅游志愿公共服务平台。指导各地分层分级组织对旅游企业和从业人员的文明旅游培训。强化旅行社文明旅游引导责任，督导旅行社落实“行前说明、行中引导、重要环节及时提示”等文明旅游制度,加强出境游散客文明旅游引导工作。充分发挥A级旅游景区等重点场所文明旅游宣传引导作用。

2.推进诚信建设。一是按照《关于加强旅游诚信建设实施失信联合惩戒的通知》,及时将被吊销导游证以及受到吊销旅行社业务经营许可证处罚的相关信息推送至工商部门实施联合惩戒。二是落实行政许可和行政处罚信息上网“双公示”制度,建立完善旅游失信“黑名单”机制。按照《旅游经营服务不良信息管理办法(试行)》相关规定,加大旅游经营服务不良信息采集公示力度,建立健全旅游诚信“红黑榜”制度,在全市旅游行业营造“守信者荣、失信者耻、无信者忧”的良好氛围。

四、工作要求

（一）要狠抓落实。要充分认识旅游服务质量提升工作的重要意义，建立旅游服务质量提升的领导机制和协调机制，加强与市场监管、公安、网信、电信主管等部门的合作，明确职责分工，确保旅游服务质量提升工作取得实效。

(二)要加强宣传引导。加大宣传力度，充分调动各类市场主体、广大消费者、行业组织和社会媒体和积极性，主动践行旅游行业核心价值观，弘扬行业正能量，塑造诚信经营、的文明旅游典范，共同推进落实旅游服务质量提升计划，营造旅游业高质量发展的良好氛围。

（三）要强化督导。建立督导考核机制,对《方案》的实施情况进行定期检查,对服务质量提升工作中取得突出成绩的单位和个人给予通报表扬，对工作不认真落实的给予通报批评，并将结果列入市政府对县区质量考核评价。
