莆田市文化和旅游局关于组织开展2019年“文化和自然遗产日”宣传展示活动的通知

发布时间：2019-06-03 17:50
| | |

各县区文化体育和旅游局，湄洲岛社会事务局、旅游局，北岸工委宣传部、北岸文旅办，局属相关单位：

2019年“文化和自然遗产日”是6月8日。为贯彻落实党的十九大精神，落实习近平总书记参加十三届全国人大二次会议福建代表团审议时的重要讲话精神，进一步提高社会公众非物质文化遗产保护意识，传承弘扬中华优秀传统文化，营造非遗保护良好社会氛围，根据文化和旅游部办公厅《关于开展2019年“文化和自然遗产日”非物质文化遗产宣传展示活动的通知》和文化和旅游部非遗司《关于请做好2019年“文化和自然遗产日”非物质文化遗产宣传展示活动筹备工作的函》和省文化和旅游厅《关于开展2019年“文化和自然遗产日”非物质文化遗产宣传展示活动的通知》的文件要求和工作部署，各县区（管委会）、局属相关单位，要紧密围绕主题，立足实际，开展丰富多彩的宣传展示活动。现将有关事项通知如下：

一、活动主题

非遗保护 中国实践

保护革命文物 传承红色基因

    二、宣传口号

1.在生活中弘扬, 在实践中创新；

2.传承文化根脉，共筑民族未来；

3.非遗保护，你我同行；

4.保护文物人人有责 传承文明美美与共；

5.弘扬革命精神 汇聚发展动力；

6.讲好文物故事 展现中国形象；

7.文物活起来 生活美起来；

8.确认过眼神 我是文物保护人。

三、活动安排

（一）莆田市2019年中国“文化和自然遗产日”系列活动启动仪式

时间：2019年6月8日

地点：市群众艺术馆舞台

主办单位：莆田市人民政府

承办单位：莆田市文化和旅游局

主要内容：举行全市2019年中国“文化和自然遗产日”系列活动启动仪式，为莆田市第五批非物质文化遗产代表性项目代表性传承人颁证和第二批莆田市非物质文化遗产传承基地（传习所）授牌。

（二）“乡音乡韵”莆仙折子戏精品展演

时间：2019年6月8日

地点：市群众艺术馆舞台

主办单位：莆田市文化和旅游局

承办单位：莆田艺术学校、市群众艺术馆

主要内容：为庆祝中华人民共和国成立70周年，在文化和自然遗产日活动期间，展示莆仙戏经典折子戏，展现莆田艺术学校“薪火相传”的教学成果，弘扬莆仙戏艺术传承和保护。 

（三）《莆仙戏锣鼓经》、《莆仙西传统曲牌（上、下）》首发式现场分享会

时间：2019年6月8日

地点：市群众艺术馆演艺厅

主办单位：莆田市文化和旅游局

承办单位：市艺术研究所、市群众艺术馆

主要内容：举办《莆仙戏锣鼓经》《莆仙西传统曲牌（上、下）》首发式，并邀请部分专家和现场观众进行读书分享。

（四）“大漆之光 精器之美”林光旭传统漆器作品展览

时间：2019年6月8日—14日

地点：市群众艺术馆非遗传习中心

主办单位：市群众艺术馆

主要内容：展出林光旭传统漆艺作品约80件，这些作品注重实用，以融入生活为特点，具有超乎实用的审美价值和文化底蕴，是非遗传统技艺融入当代生活的一次启航。

（五）“木兰古韵”广场节目展演

时间：2019年6月8日

地点：市群众艺术馆广场

主办单位：市群众艺术馆

主要内容：选用气势昂扬大鼓吹、遒劲有力的武术展、独具风情的畲族竹竿舞以及耳熟能详的莆仙戏《春草闯堂》抬轿子的经典片段，诠释生动活泼的文化莆阳场景。

（六）“民风雅韵”传统曲艺展演

时间：2019年6月8日

地点：市群众艺术馆广场

主办单位：市群众艺术馆

主要内容：以省级非遗项目板鼓咚和女子十音八乐形式演绎传统曲艺魅力。

（七）“荧光意蕴”文创作品展览

时间：2019年6月8日

地点：市群众艺术馆非遗传习中心

主办单位：市群众艺术馆

主要内容：本次展览由莆田学院工艺美术学院学生的文创作品约30件组成，囊括了木雕、玉石雕、家具设计等文创作品。这些作品是对传统文化元素挖掘的基础上，又融入自己的创意点亮生活。

（八）“群艺汇”手工市集

时间：2019年6月8日

地点：市群众艺术馆广场

主办单位：市群众艺术馆

主要内容：选用莆田民间传统手工技艺项目，现场制作，现场展示，传统手工艺融入现代生活，让传统手工艺见人见物见生活。

（九）“莆阳风味”戏棚兜小吃

时间：2019年6月8日

地点：市群众艺术馆中亭下

主办单位：市群众艺术馆

主要内容：“莆阳风味”系列，选用人们对于“戏棚兜”的美好记忆，展售莆田的传统美食和非遗食品，既有现成卖品，也有现场制作，色香味俱全，让人流连忘返。

（十）“匠心芳华”工艺美术作品展

时间：2019年6月8日

地点：市群众艺术馆展览厅

主办单位：市群众艺术馆

主要内容：展示莆田学院工艺美术学院工艺美术系学生的作品约50件。

（十一）“欢乐闪秀”系列活动

时间：2019年6月8日

地点：市群众艺术馆广场

主办单位：市群众艺术馆

主要内容：以群艺合唱和旗袍秀为内容，用快闪的形式穿插在群艺系列活动。

（十二）“保护革命文物 传承红色基因”闽中革命文物图片展

时间：2019年6月8日—22日

地点：元妙观三清殿

主办单位：莆田市文化和旅游局

承办单位：莆田市文物局、莆田市博物馆、莆田市三清殿文保所

主要内容：为庆祝中华人民共和国成立70周年，在文化和自然遗产日活动期间，通过举办闽中革命文物图片展活动，  以闽中根据地革命文物保护利用为重点，依托革命文物资源，弘扬革命精神、传承红色基因。

（十三）“端午莆阳文化展”

时间：2019年6月3日—8日

地点：市图书馆一楼大厅

主办单位：莆田市图书馆

主要内容：展示莆田独有的五日岁习俗与莆田端阳诗篇等传统习俗与优秀传统文化内容，普及莆田文化，传递莆田精神。

（十四）“端阳话诗词”读书分享会

时间：2019年6月8日

地点：市图书馆一楼多功能厅

主办单位：莆田市图书馆

主要内容：利用端午节也是诗人节的特性，邀请朗诵协会会员与读书分享会成员，通过朗诵、诗歌分享、现场竞答的形式展示中华优秀传统文化。

（十五）“中华经典阅读”主题展

时间：2019年6月3日—8日

地点：市图书馆二楼平台

主办单位：莆田市图书馆

主要内容：中华经典文化名著摘要展示，通过普及中华传统文化经典，引导读者阅读经典，感悟经典，在精神上寻找作为中国人与中华优秀传统文化的契合点。

（十六）“莆田文化纵横谈”专题讲座

时间：2019年6月8日

地点：市图书馆大会议室

主办单位：莆田市图书馆

主要内容：通过对莆田优秀地方文化的专题性讲述，引导读者思考莆田文化的特质，并弘扬莆田精神，传承莆田优秀的历史文化遗产。

（十七）第二届小小讲解员比赛决赛

时间：2019年6月8日

地点：市博物馆A馆二层放映厅

主办单位：莆田市文化和旅游局

承办单位：莆田市博物馆、城厢区太平小学

主要内容：结合民俗厅、妈祖厅部分场景的资料，用讲解比赛方式演绎莆田民俗和妈祖文化,表演方式涵盖方言讲解、亲子解说、歌舞乐器，现场评分晋级并评定等级。

（十八）“大美黔东南”民俗展

时间：2019年6月8日-8月14日

地点：市博物馆A馆一层精品厅1号厅

主办单位：莆田市文化和旅游局

承办单位：莆田市博物馆

主要内容：黔东南民族服饰、银饰、工艺品等静态展示，并有刺绣、剪纸、银饰、蜡染等民间工艺现场制作和歌舞表演等动态展演。

（十九）旅法画家叶星千作品展

时间：2019年5月28日-6月28日

地点：市博物馆B馆三层书画厅

主办单位：莆田市文化和旅游局

承办单位：莆田市博物馆

主要内容：通过叶星千先生最具有代表性的作品展览，展现画家以艺术为哲学理念、以纯“美”为表现、以时代为符号的艺术追求。

（二十）《莆仙戏传统曲牌》（上下卷）、《莆仙戏锣鼓经》签售活动

时间：2019年6月8日上午

地点：莆田市艺术馆

主办单位：莆田市文化和旅游局

承办单位：莆田市艺术研究所

主要内容：结合庆祝中华人民共和国成立70周年，在文化和自然遗产日活动期间，举办莆仙戏传统艺术丛书签售会，展现国家级非遗项目保护的成果，展示莆仙戏音乐的技艺传承，引领广大民众关注非遗保护，推进莆仙戏艺术传承和保护。

四、工作要求

（一）高度重视，精心组织。文化遗产是优秀传统文化最实在、最具体、最直接、最真实的体现，也是文旅融合的主要载体。各县区（管委会）文化行政部门、局属有关单位要高度重视文化遗产日宣传工作，认真组织，周密部署，确保文化遗产日活动安全顺利开展，把活动真正办成展示文化和旅游形象的窗口。

（二）创新形式，丰富内容。我市2019年中国“文化和自然遗产日”主场活动在市群众艺术馆举行，各县区（管委会）文化行政部门、局属有关单位要充分利用好各级文化场馆、文物保护单位、非遗传习所，认真策划，组织形式多样的宣传展示活动。各单位请于6月6日前将《2019年中国“文化和自然遗产日”项目表》报送局办公室。联系人：林立，联系电话：2689939，邮箱：pt2696660@163.com。

（三）强化宣传，营造氛围。要注重结合当地实际，充分展示地方政府文化遗产保护的积极行动和工作成果，大力宣传文化遗产服务社会、推动发展、惠及民生所采取的举措和文旅融合取得的成效，强化价值导向。要积极利用电视、报纸、网络等媒体开展文化遗产知识宣传、文化遗产项目介绍等宣传报道，传播文化遗产保护理念，弘扬优秀传统文化。

附件：2019年中国“文化和自然遗产日”项目表
