关于印发《2020年“书香莆田”全民读书月活动实施方案》的通知

发布时间：2020-11-19 11:26
| | |

各县（区）委全民阅读组委会，市全民阅读组委会各成员单位，各有关单位：

根据省《关于开展第十四届“书香八闽”全民读书月活动的通知》（闽新出〔2020〕141号）和市全民阅读年度工作计划，决定在全市范围组织开展2020年“书香莆田”全民读书月活动，现将《2020年“书香莆田”全民读书月活动实施方案》印发给你们，请认真贯彻落实。

 

              

                    市全民阅读工作组委会办公室

                     莆田市文化和旅游局（代章）

 2020年11月5日  

2020年“书香莆田”全民读书月活动实施方案

 

为持续推动学习贯彻习近平新时代中国特色社会主义思想，为决胜全面小康决战脱贫攻坚提供良好的文化氛围和社会氛围，根据市全民阅读年度工作计划，市全民阅读工作组委会决定在全市范围组织开展2020年“书香莆田”全民读书月活动。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，认真学习宣传贯彻党的十九大精神和十九届五中全会精神，贯彻落实省委、市委有关精神，按照全民阅读工作的要求，认真谋划活动，创新思路、创新方法、创新举措，努力把“书香莆田”全民读书月活动打造成我市精神文明建设和文化建设的重要品牌。

二、活动主题

学习新思想、共圆小康梦、书香伴我行  

三、活动时间

2020年11月10日—12月10日

四、组织机构

2020年“书香莆田”全民读书月组委会成员单位：市委宣传部、市直机关党工委、市委文明办，市文旅局、教育局、财政局、发改委、民政局、自然资源局、住建局、税务局，总工会、团市委、妇联，市社科联、文联，湄洲日报社、市广电中心、新华发行集团莆田分公司、移动莆田分公司、邮政莆田分公司。

组委会下设办公室，挂靠市文旅局，负责全民读书活动的组织、协调工作。

协办单位：各县区组委会，莆田学院，市群艺馆、博物馆、图书馆，市出版物发行业协会、朗诵协会、诗词协会，民营书店等

五、活动内容

（一）举办启动仪式

时间：2020年11月

内容：举办2020年“书香莆田”全民读书月启动仪式，提出“读好书、做好人、圆好梦”倡议，举办图书展销、捐赠书籍、诗歌朗诵等活动，启动2020年“书香莆田”全民读书月活动。

责任单位：“书香莆田”全民阅读组委会

（二）营造浓厚氛围

1.主题宣传。印发2020年“书香莆田”全民读书活动海报、宣传品；在大中专、中小学，市、各县区图书馆、博物馆、群艺馆等文化单位，全市出版物经营单位，悬挂标有“2020‘书香莆田’全民读书月活动”等字样的标语，电子屏滚动播出全民读书活动标语等。

责任单位：市、各县区全民阅读组委会

2.特别宣传。市主要报刊、广播电视和相关网站开辟“书香莆田”专题或专栏，报道全民读书月活动；推荐好书，学习选书、藏书方法等。

责任单位：市文旅局、湄洲日报、莆田广电中心等

3.成效宣传。在“书香莆田”全民读书月期间，加大宣传力度，在“两微一端”、电子阅报栏等全媒体平台重点刊发读书月活动内容，切实保障未成年人、农村留守儿童等重点群体的基本阅读需求，营造良好的阅读氛围。

责任单位：市、各县区全民阅读组委会

（三）开展全民阅读“七进”工作

1.全民阅读进社区

（1）发挥社区干部、社区老党员、退休教师、书画名人的业余爱好，成立阅读活动组织，定期开展读书会、猜谜、填字、词语接龙、书画摄影展、诵读竞赛等活动。

责任单位：市委文明办、各县区全民阅读组委会

（2）加强服务创新，提高阅读便利，加强社区阅读微信公众号等网络文化服务平台建设，借助新媒体传播优势，建立健全全民阅读微信公众号，打造上下贯通左右互联的全民阅读信息交流平台。

责任单位：电信、移动莆田分公司等

（3）以“党建+邻里中心”试点活动强化阅读服务。开展“书香兴化，携手圆梦”读书活动，为社区青少年提供丰富的精神食粮。在全市“青年之家”平台建设读书角，在全社会形成“多读书、读好书”的文明风尚。

责任单位：团市委

2.全民阅读进机关

（1）市机关各单位结合实际，按照“日读一小时，月读一本书”的要求，制定阅读活动计划，利用网络、微信、微博等互联网+手段，丰富阅读载体和形式，鼓励和引导机关干部职工积极参与读书活动。

（2）以学习习近平新时代中国特色社会主义思想为契机，激发党员干部职工读书学习热情，努力在单位内部形成爱学习、爱读书的良好风尚，提升“全民阅读进机关”活动的吸引力和实效性，提升党员干部素养，改变机关作风，促进机关建设。

责任单位：市直机关党工委

3.全民阅读进学校

（1）开展“美好生活·劳动创造”活动。围绕“美好生活·劳动创造”主题，把主题教育读本阅读与语文、美育、综合实践等课程教学有机结合起来，把新时代好少年主题教育读本学思践悟与德育专题活动、研学旅行及综合实践活动有机结合。

（2）开展“红色教育 经典传承”主题阅读活动。引导学生广泛阅读革命历史、国学经典等内容读物，组织学生看红色文化图书、讲红色故事、唱红色歌曲、看红色电影、学习革命历史等，举办红色系列主题图书校园巡展、红色经典品读分享报告会、体验式阅读红色研学旅行、红色励志成人礼等活动。

（3）开展“友善、孝敬、节俭、诚信”经典诵读活动。利用早读、班会、语文课、思想品德课等时间，组织学生诵读，引导青少年学生认识传统、尊重传统、继承传统、弘扬传统。

（4）开展校外阅读实践活动。开放图书馆、文化站、文博场所等校外阅读实践活动场所，开展丰富多彩的阅读推广活动，充分发挥校外阅读实践活动场所的作用。

责任单位：市教育局，市图书馆、博物馆、群艺馆、莆仙大剧院等，各县区图书馆、文化馆

4. 全民阅读进企业

向企业职工、群众推荐精品书籍并现场提供给居民借阅，鼓

励大家在日常生活中养成爱读书、读好书的习惯。建好“职工之家”，用好“职工书屋”，丰富职工的学识，陶冶职工的情操，倡议每个家庭设一个图书角，家庭成员共享阅读好时光。

责任单位：市总工会

5.全民阅读进乡村

（1）实施“精准扶贫捐赠图书”活动，国有、民营出版物销售单位共同向山区、沿海农家书屋捐赠图书。更新农家书屋出版物，建设数字农家书屋。在留守流动儿童较多的学校和乡村援建“爱心书屋”，配送相应图书。

责任单位：市文旅局、妇联，新华发行集团莆田分公司，各县区文旅局，民营书店

（2）举办“我的书屋？我的梦”读书征文活动。以“我的书屋，我的梦”为主题，与文明创建、文化共享“结对子、种文化”活动和“圆梦蒲公英”主题活动相结合，鼓励读者用自己生动质朴的语言书写在农家书屋读书实践的收获和感受。

责任单位：市文旅局、教育局

6.全民阅读进家庭

（1）搭建网上网下学习平台。依托市妇联官方网站、微博、微信，开设网上家长学校专栏，及时更新家庭教育等相关知识，推送、转发荐读书目，有效促进家长自身的学习。通过购买的“莆阳好家风”暨《福建省家庭教育促进条例》宣讲、2020年儿童之家“阳光成长乐园”、福建省家庭教育进社区（村）等特色服务项目，开展亲子阅读活动。

（2）开展好家风好家训好家教公益巡回讲座进村、社区家

长学校、学校、机关企事业单位等，开展“百千万家庭教育公益行动”，为家长授课，促进互相交流。

责任单位：市妇联

7.全民阅读进军营

开展“好书进军营”活动，举办“书香军营讲坛”，开展好书推荐、阅读指导和座谈交流，丰富部队官兵的文化生活，组织演讲比赛、读书成果展评和军地读书心得交流等活动。

责任单位：新华发行集团莆田分公司

（四）“好书惠民”系列活动

（1）图书优惠销售。开展“好书聚惠”营销活动，在全民读书月期间，开展各种主题的优惠销售活动。优秀图书巡展、优惠。各实体书店开展优惠售书、图书巡展等活动，延长营业时间，方便读者购书。

责任单位：新华发行集团莆田、仙游分公司、民营书店

（2）设立莆田籍作家作品集专柜，邀请部分作家现场签名售书。

责任单位：市文联、市社科联、新华发行集团莆田分公司、民营书店

（3）优秀馆藏图书、精品图书阅读推荐活动。各级图书馆对读者进行读书宣传和针对性的阅读指导，并为读者进行咨询，引导广大群众多读书，读好书，增强读者的图书馆意识。

责任单位：各级图书馆

六、活动要求

（一）高度重视，精心组织。要把开展全民读书月活动作为

学习贯彻习近平新时代中国特色社会主义思想，推进精神文明建设和文化强市的一项重要工作，加强领导、周密部署，务求实效。

（二）全民参与，注重创新。各县区、各部门要坚持面向基层、面向群众，用群众喜闻乐见的方式，多搭建群众便于参与的平台，把统一组织的阅读活动与群众自发开展的学习活动结合起来，使全民读书活动成为人们自我教育、自我提高的自觉行为。

（三）营造氛围，有序进行。各县区、各部门要采取多种形式大力宣传全民阅读活动的意义、内容和要求，及时深入地报道活动的进展情况和成效，广泛宣传先进典型和经验，扩大社会影响，打造“书香莆田”文化品牌。

（四）督促检查，确保效果。市全民读书月活动组委会将对整个活动进行督促检查，及时通报。读书月活动期间要及时报送有关工作信息、活动照片等资料，并于11月28日前将活动总结、图片、资料等报送“书香莆田”全民读书活动组委会办公室。（联系人：张玉应，联系电话：2623066,电子邮箱：1286882925@qq.com）
