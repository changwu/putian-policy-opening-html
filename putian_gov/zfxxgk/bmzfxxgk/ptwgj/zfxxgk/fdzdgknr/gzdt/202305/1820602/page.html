莆田市文化和旅游局关于加强全市旅游服务质量监管提升旅游服务质量的通知

发布时间：2023-05-22 15:42
| | |
 各县区文体旅游局、湄洲岛旅游文体局、北岸党工委宣传部，市旅游协会、机关各科室、局属各单位：

根据《福建省文化和旅游厅关于印发贯彻落实<文化和旅游部关于加强旅游服务质量监管提升旅游服务质量的指导意见>2023年工作要点的通知》精神，结合我市旅游市场实际，为保障全市旅游服务质量监管与质量提升工作有序开展，助推全市文化和旅游产业绿色高质量发展，现就加强全市旅游服务质量监管、提升旅游服务质量工作通知如下：

一、培育质量主体责任意识与品牌。各县区（管委会）、各有关单位要引导旅游企业树立“争先创优”的理念与意识，提高旅游经营管理人员和从业人员质量意识和质量素养，实现旅游行业企业提质增效、规范经营。要引导企业增强品牌创建意识，通过酒店评星、旅行社评A、景区评A、民宿评级、导游评优等一系列举措，打造一批优质旅游服务品牌，并培育建设一批旅游服务质量品牌示范单位，建立旅游服务品牌创建激励机制，使品牌意识深入人心。

二、抓好旅游人才队伍建设。当前全市高素质的旅游人才紧缺，人才队伍建设急需加强。各县区（管委会）、各有关单位要加强与莆田学院旅游管理学院及各类旅游职业学校的合作，深入推进产教融合、校企合作，把各类特色旅游人才的培养纳入人才培养战略规划，培养出适合企业需要的旅游专业人才。要加强人才培训力度，有计划地组织各类专题培训和短期轮训班，对从业人员的岗前、岗中培训，提高旅游从业人员的职业道德意识与服务技能水平。要通过举办导游比赛、红色故事讲解员比赛、饭店服务技能竞赛等技能竞赛活动，培养行业服务技能标兵，在旅游行业服务企业中掀起一股比学赶超的热潮。

三、加强旅游行业服务质量监管。聚焦旅游行业顽疾，开展旅游包车安全专项整治行动、暑期旅游团队规范专项行动、“不合理低价游”专项整治行动、涉老旅游诈骗专项整治行动，重点查处在线旅游虚假宣传、无证经营、违规经营的“黑社”“黑车”“黑导”等单位和个人，规范旅行社、旅游汽车公司经营行为和服务行为，坚决打击“零团费”或“负团费”、强迫和变相强迫消费、“不合理低价游”等侵害游客合法利益的突出违法违规行为。切实强化“诉转案”工作，查处一批典型案例，处罚一批违法企业和个人，及时向全行业通报查处结果，向社会发布典型案例，达到震慑效果，营造和谐、文明、有序的文化和旅游市场环境。

四、加快推进旅游信用体系建设。发挥各相关部门、相关行业协会作用，推动各类标准实施，引导旅游经营者注重服务质量和诚信经营，提醒旅游者遵守文明旅游行为公约和行为指南，通过旅游信用信息公示和“红黑榜”制度，记录旅游经营者和从业人员旅游经营服务不良信息。要强化舆论监督，曝光扰乱旅游市场秩序的典型事件，形成社会舆论氛围，提升涉旅企业和从业人员的诚信经营、诚信服务水平。

2023年11月20日前，各县区（管委会）文旅部门要报送本地质量工作落实进展情况、质量工作典型案例（不少于1个）；机关各科室和局属各单位向局市场法规科反馈工作落实情况。我局将根据文化和旅游部的要求进行监督、开展评估，并将结果列入政府质量工作考核评价。
