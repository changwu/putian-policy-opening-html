关于开展莆田新旧二十四景调查工作的通知

发布时间：2018-05-24 16:17
| | |

　　各县（区、管委会）旅游局：

　　为了组织莆田市国家历史文化名城申报工作，深入挖掘莆田特色文化资源和历史文化价值，实施全市文物保护单位保护、整治、提升工程，做好莆田新旧二十四景调查、恢复和展示方案编制工作，由莆田市旅游发展委员会与莆田学院旅游发展联合开展调查活动，请各县、区、管委会积极配合，确保调查工作顺利完成。具体事项通知如下：

　　一、调查对象

　　莆田市辖区内新二十四景和旧二十四景，共48个景点，详见附件1。

　　二、调查时间

　　2018年5月下旬至7月中旬，根据各景点实际情况安排时间进行实地调查。

　　三、组织分工

　　调查组织工作分为三个小组：

　　第一组负责城厢区、秀屿区、北岸所属景点调查；联系人：小陈（联系号码：18******161）；

　　第二组负责荔城区、涵江区、湄洲岛所属景点调查；联系人：小熊（联系号码：18******165）；

　　第三组负责荔城区仙游县所属景点调查，联系人：小陈（联系号码：1560250025）。

　　四、具体要求

　　1、请各县、区、管委会旅游局组织所属各景点填报《莆田市新旧二十四景基本概况表》（附件2），收集相关资料，于2018年5月30日报送市旅游发展委员会，电子版发到莆田市旅游发展委员会邮箱：ptly0594@163.com 。

　　2、各县、区、管委会旅游局指定一位联系人，负责调查组实地调查的联系工作，并负责联系安排当地熟悉景点情况的人员实地介绍。联系人名单和联系电话于2018年5月22日报送市旅游发展委员会（联系人：林洲，联系电话：13******788）。

　　莆田市旅游发展委员会（代）

　　2018年5月18日
