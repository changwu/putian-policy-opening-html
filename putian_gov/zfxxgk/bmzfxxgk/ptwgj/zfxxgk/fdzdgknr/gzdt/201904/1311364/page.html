莆田市文化和旅游局关于做好第十五届海峡旅游博览会组织参展工作的通知

发布时间：2019-03-13 15:49
| | |

各县区文体旅游局，湄洲岛管委会社会事务局、旅游局，北岸工委宣传部、文旅办：

    由福建省文化和旅游厅与厦门市人民政府共同主办，厦门市旅游发展委员会具体承办的第十五届海峡旅游博览会，拟定于2019年4月19日至21日在厦门市举行。2019第五届中国（厦门）国际休闲旅游博览会拟将同期举行。

    本届旅博会将进一步发挥福建对台优势，挖掘海峡两岸及港澳地区旅游合作潜力，拓展“后金砖时代”“一带一路”旅游发展新机遇，扩大海峡两岸及港澳地区旅游业界交流合作，进而引导市场需求，突出展销一体，促进旅游消费，实现惠民利市，致力于把展会打造成巩固闽台港澳及东南亚旅游全方位交流的重要平台，建成21世纪海上丝绸之路核心区战略合作和招商引资的重要渠道。

    为借助旅博会平台充分展示我市各地旅游品牌和旅游产品、休闲产品，体现地方特色，切实做好参展参会工作。现将有关事项通知如下：

    一、展会时间及地点

    （一）展会时间

    4月16日-18日（8:30-17:00） 布展
    4月17日-18日（16:00-17:00）参展报到
    4月19日09:30               开馆仪式
    4月19日-21日（9:00-17:00） 展馆开放
    4月21日16:00               撤展

   （二）展会地点

    本届旅博会在厦门国际会议展览中心C1、C2、C3、C4、C5、B6厅及举办，展馆面积60000㎡，约2600个展位。莆田展区位于C5-A01，面积225㎡，标准展位25个。

    二、参展内容

本次莆田展区将着重探寻莆田文化与旅游之间的融合，以文化的角度探寻、结合旅游景点，使文旅融合跨界共展，营造以文旅为中心的共赢生态。主要设以下几大板块：

（一）莆田文化之旅——妈祖文化

本版块以介绍妈祖文化为主线，将妈祖祖庙景区、湄洲岛、湄洲渔村等展示在观众面前，同时融合南日岛等浪漫滨海旅游产品进行介绍和推广，展示以体验海洋生态、探索海岛奥秘、游览渔村风貌、感受渔家民俗文化和休闲度假旅游系列产品。

（二）莆田文化之旅——禅宗文化

以世界佛教论坛中心、中国佛教禅武文化遗产地的南少林、福建四大古刹南山广化寺为代表，展示莆田禅宗文化。

（三）莆田文化之旅——工艺文创

莆田雕刻技艺精湛，有“中国木雕之城”、“中国古典工艺家具之都”、“中国珠宝玉石首饰特色产业基地”、“中国银饰之乡”等称号，主要以莆田的工艺美术及莆阳书房等文化创新融合产品作为主线展示。

（四）莆田文化之旅——乡村民俗

莆田特色民俗乡村文化为主线，介绍莆田民俗旅游产品，重点将侧重展示莆田元宵习俗介绍及非遗项目展示，集中展示莆田民俗及文化的特色。同时结合美丽乡村旅游，介绍近几年美丽乡村旅游发展情况。

（五）莆田文化之旅——绿色生态

以莆田的青山绿水生态文化为主线，宣传推广莆田的国家级AAAA旅游景区，结合木兰溪水系，将木兰溪的历史文化、“荔林水乡”等景区集中展示。

（六）莆田文化之旅——红色革命

本次展区将以莆田红色文化为主线，闽中革命纪念馆为主线，介绍莆田红色旅游资源，弘扬红色革命精神。

    三、参展任务

    （一）请各县（区）人民政府（管委会）文旅部门组织辖区内旅游景区、旅行社、酒店、旅游商品企业、旅游文创企业等参展，原则上各县（区、管委会）每个安排2个以上（含2个）展台供参展商使用。参展的旅游景区要带足景区宣传材料、景区优惠门票现场发送；旅行社要推出莆田一日游、二日游产品现场销售；星级酒店要推出优惠住宿条件现场营销；文化旅游相关企业要携带莆田特色文化旅游产品现场展示销售。请2018年莆田“十佳旅游商品”生产企业携带获奖产品参展，每份旅游宣传材料不少于1000份，赠送旅游小纪念品500份。

    （二）请各县（区）人民政府（管委会）文旅部门负责提供本辖区需要宣传推介的音像资料，协助提供布展所需的相应文字介绍、高清宣传图片（3-5张）等资料；提供旅游宣传纸质资料（宣传手册）、旅游小商品、旅游伴手礼及销售地方特色的文化旅游产品等在展会现场展示销售。

    四、有关要求

    （一）强化组织。各县（区）人民政府（管委会）文旅部门要高度重视，要及时向县（区）人民政府（管委会）分管领导汇报，精心组织，周密部署，有序推进各项工作，确保我市各项参展筹备工作顺利进行。

    （二）加大宣传。各县（区、管委会）文旅部门要积极协调本地新闻媒体，充分利用各种传播媒介（电视台、报社、网站、新媒体等），切实做好宣传工作。组织好本地群众、企业积极参与旅博会。

    （三）抓好落实。各县（区）人民政府（管委会）文旅部门要根据各自分工抓好落实，指定专人逐项落实具体工作，按照要求组织辖区内旅游机构、旅游企业报名参展，做好相关材料收集报送、参展证件手续办理等工作，各单位参展人员食宿自理。

请各县（区）人民政府（管委会）文旅部门积极报送相关材料，并按照要求填写参展商、参展人员基本信息（见附件），于3月22日前报市文旅局。
