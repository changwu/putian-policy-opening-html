关于开展2015年全市旅游行业财务信息编报工作的通知

发布时间：2015-04-14 08:00
| | |

　　各县（区、管委会）旅游局：

　　为进一步做好2014年度全市旅游行业财务信息编报工作，按照国家旅游局办公室《关于开展2015年旅游行业财务信息编报工作的通知》（旅办发【2015】年61号）及省旅游局文件要求，现将有关工作通知如下：

　　一、编报范围及内容

　　2015年旅游行业财务信息编报范围为：旅行社、旅游饭店、旅游企业集团、旅游景区和其他旅游企业。旅游行业财务信息基础表按行政单位（各级主管部门使用）、企业及企业化管理事业单位、事业单位、民间非营利组织进行划分，各单位根据选择的“单位形式”，录入对应的基础报表（资产负债表、利润表、补充指标表等）。

　　二、编报说明

　　（一）编报模式。编报工作采用网上编报模式，报表类型为年报。各类旅游企业编制报表并上网录入数据，经系统审核无误后将报表上报到市旅游局，市旅游局将直接在网上对各旅游企业填报的数据进行审核，确认无误后上报省旅游局。省旅游局审核无误后上报国家旅游局。

　　（二）编报依据。各类旅游企业以截止2014年12月31日的2014年度会计决算报表和相关资料为填报依据，旅游企业集团以合并会计报表为填报依据，确实保证数据的合法真实、准确完整。

　　（三）登录方式。请登录国家旅游局网址(www.cnta.com），进入“统计与财务系统”，点击“行业财务信息系统”站点1或站点2，进入“国家旅游局行业财务信息系统平台”。已注册企业，2015年初次登录时“用户名”填写九位组织机构代码证号（不含“一”），“密码”为空，登录后请及时修改密码。以前年度未注册企业，请点击“注册”后进行新用户注册。

　　三、其他事项

　　（一）工作进度。财务信息系统填报截止时间为2015年5月10日。财务信息具有很强的时效性，请各填报单位要合理安排填报时间，确保在规定时间内上报。同时要重视报表数据质量，确保数据的真实性、准确性、完整性。

　　（二）请各县（区、管委会）旅游局要高度重视2014年度旅游行业财务信息编报工作，具体负责信息填报工作的人员要及时跟踪落实，认真组织和完成辖区内财务信息填报工作。

　　编报过程中，各单位可参考系统首页下载区中“用户手册”进行报表填制。如遇系统软件操作问题，请联系久其软件公司技术人员，电话：13381087760。如遇数据口径及审核问题，请联系负责本次数据汇审的会计师事务所，电话：（010）63259102。 或市旅游局林国防，联系电话：2656677、15960506696；姚丽娟，联系电话：6735831、13860956626。编报中，请将有关问题及时反馈国家旅游局规划财务司，联系电话：（010）65201527，65201534。

　　附：2015年旅游企业填报单位名单

　　莆田市旅游局

　　2015年4月14日

　　抄送：全市各旅游企业
