莆田市旅游局关于印发2017年政务公开

发布时间：2017-05-31 11:23
| | |

 

机关各科室、各直属单位：

为贯彻落实《莆田市人民政府办公室关于印发2017年政务公开工作主要任务分解表的通知》（莆政办〔2017〕80号）文件精神，现将市旅游局《2017年政务公开工作主要任务分解表》印发给你们，请认真抓好落实。

一、把握总体要求。2017年政务公开工作总体要求是：全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，认真落实《政府工作报告》有关部署，坚持稳中求进工作总基调，以供给侧结构性改革为主线，按照中共中央办公厅、国务院办公厅《关于全面推进政务公开工作的意见》和省委办公厅、省政府办公厅《全面推进政务公开工作实施意见》及市委、市政府的部署要求，全面推进决策、执行、管理、服务、结果“五公开”，加强解读回应，扩大公众参与，增强公开实效，助力稳增长、促改革、调结构、惠民生、防风险，为“打造宜居港城、建设美丽莆田，创建美丽中国的示范区”提供强有力保障，以优异成绩迎接党的十九大胜利召开。

二、强化组织领导。根据人员变动情况，及时调整了政务公开工作领导小组，在政务公开工作领导小组的统一领导下，建立办公室牵头、各科室各负其责、相互配合的工作机制。各科室要认真履行政务公开责任，把政务公开作为各科室工作的重要内容，与业务工作紧密结合起来，统筹考虑，统一部署，共同推进。办公室是政务公开工作的负责部门，具体负责组织协调、指导推进、监督检查本单位的政务公开工作。主要领导年内至少听取一次政务公开工作汇报，研究部署推进工作。

三、细化工作任务。各科室要紧紧围绕“五品牌、九行动”、建设美丽莆田2017年行动计划中的30个重点攻坚项目和20项重点工作、政府工作报告8个方面96项主要任务等市委、市政府中心工作，认真对照主要任务分解表，进一步细化内容、明确科室，制定具体工作方案，并在政府门户网站公开。各牵头科室要落实牵头主抓责任，加强工作指导，及时汇总情况；各责任科室要密切配合，抓好各项工作任务的落实。

四、加强督查考评。在创新公开载体、加强互联互动的同时，要持续抓好局公开栏（按月度对内公开）、门户网站、办事指南等传统公开工作，并加强日常监督检查。我局把政务公开工作纳入绩效考评，作为今年效能督查的重要内容，与“一季一督查”相结合，结合对各科室政务公开落实情况定期、不定期组织抽查，抽查发现的问题在绩效考评中予以运用。各科室要确定一名政务公开工作联络人，具体负责工作对接和落实情况汇报。各科室政务公开工作主要任务落实情况要纳入政府信息公开年度报告并向社会公布，接受社会监督。全年工作落实情况（包括主要经验做法、问题及建议、主要任务分解表逐项落实情况）于2017年11月20日前报局办公室。

莆田市旅游局

2017年5月27日

 

 

 抄送：市府办

 莆田市旅游局办公室                 2017年5月27日印发


莆田市旅游局2017年政务公开工作主要任务分解表

 

工作任务

责任科室

工作要求

一、以政务公开助力稳增长

（一）加强预期引导

1.深入解读政策背景、依据、目标任务、涉及范围

办公室牵头

各科室配合

通过新闻发布会、在线访谈等方式，及时准确解读旅游产业重要政策。加强舆情收集研判，针对涉及全市旅游发展的误导和不实信息，客观及时、有说服力地发声，澄清事实，解疑释惑，坚持正确舆论导向。

二、以政务公开助力促改革

（一）推进“放管服”改革信息公开

2.强化权责清单管理与应用

行管科

以清单管理推动减权放权，各类清单及时向社会公开。深化权责清单公开工作，让公众了解放权情况、监督放权进程、评价放权效果。

3.权责清单及时向社会公开

行管科

除涉密事项外，及时向社会公开权责清单。集中发布旅行社设立后的经营许可清单等，接受群众监督。

4.及时公开政策性文件的废止、失效等情况

办公室牵头

各科室配合

定期通过主动推送信息等方式告知政策性文件的废止、失效情况，及时在政府网站已发布的原文件上作出明确标注。

5.推行“双随机、一公开”监管全覆盖

行管科

围绕年内实现“双随机、一公开”监管全覆盖要求，汇总形成并统一公布本局随机抽查事项清单，明确抽查依据、主体、内容、方式等，及时公开抽查结果和查处情况。

6.大力推进“互联网＋政务服务”

行管科

按照市数字办、市审改办、市行政中心有关要求，加快完善电子证照系统，促进行政审批服务全程网办，加快实体政务大厅与网上服务平台融合发展，让企业和群众办事更加便捷。

三、以政务公开助力调结构

（一）推进消费升级和产品质量提升工作信息公开

7.定期发布消费市场运行情况分析报告

办公室牵头

各科室配合

重点公开与群众密切相关的全域旅游新兴服务业消费情况，引导消费升级。

四、以政务公开助力防风险

（一）推进政策执行和落实情况公开

8.“五公开”纳入办文办会程序

办公室牵头

各科室配合

一是将“五公开”要求落实到公文办理程序。各科室、直属单位在拟制公文时，要明确主动公开、依申请公开、不予公开等属性，随公文一并报批，拟不公开的，要依法依规说明理由。对拟不公开的政策性文件，报批前应先送本局政务公开领导小组审查。各科室、直属事业单位在起草政策性文件代拟稿时，应对公开属性提出明确建议并说明理由；科室上报的发文请示件没有明确的公开属性建议的，或者没有依法依规说明不公开理由的，办公室可按规定予以退文。二是将“五公开”要求落实到会议办理程序。在2017年底前，建立健全利益相关方、公众代表、专家、媒体等列席政府有关会议的制度，增强决策透明度。提交局党组会议或局务会议研究的重要方案和重要事项，除依法应当保密的外，应在决策前向监管对象、群众广泛征求意见。

9.建立公开内容动态扩展机制

办公室牵头

各科室配合

对照“五公开”要求，每年对本单位不予公开的信息以及依申请公开较为集中的信息进行全面自查，发现应公开未公开的信息应当公开，可转为主动公开的应当主动公开。

10.加快制定主动公开基本目录

办公室

2017年底前完成政务公开目录体系编制前期工作。

11.做好电视电话会议公开工作

办公室牵头

各科室配合

对涉及公众利益、需要社会广泛知晓的电视电话会议，除涉及国家秘密外，积极通过网络、新媒体直播等方式向社会公开。

12.进一步做好人大代表、政协委员提案办理结果公开工作

办公室牵头

各科室配合

对涉及公共利益、社会广泛关注的建议提案，原则上都要公开答复全文，及时回应关切，接受群众监督。

（二）进一步健全解读回应机制

13.切实做好政策解读回应工作

办公室牵头

各科室配合

 

充分利用新闻发布会、通气会、政策吹风会等方式，主动回应重大舆论关切，释放信号，引导预期。

14.落实政策解读“三同步”要求

各科室

按照“谁起草、谁解读”原则，落实政策性文件与解读方案、解读材料同步组织、同步审签、同步部署的“三同步”工作要求。

15.及时回应社会关切

办公室牵头

各科室配合

对于社会关注度高的信息，及时进行回应。

（三）加强政务公开平台建设

16.加强政府网站建设

旅游公共服务中心牵头，各科室配合

切实履行对单位网站的监管责任，强化网站信息内容保障，定期检查抽查并及时公开相关情况。

17.用好管好政务新媒体

旅游公共服务中心牵头，各科室配合

明确管理主体责任，健全内容发布审核机制，强化互动和服务功能，切实解决更新慢、“雷人雷语”、无序发声、敷衍了事等问题。

18.加强政府信息查阅场所工作

办公室

落实《福建省政府信息查阅场所管理办法》，规范建设政府信息查阅场所，开展信息查阅服务。进一步规范主动公开信息送交查阅场所工作。

（四）依法规范依申请公开工作

19.加强和规范依申请公开工作

办公室牵头

各科室配合

畅通依申请公开受理渠道，依法保障公众合理的信息需求。进一步规范依申请公开答复工作，严格按照法定时限答复，增强答复内容针对性并明示救济渠道，答复形式要严谨规范。对依申请公开工作中发现的依法行政方面问题，要及时向相关单位提出工作建议。对公众申请较为集中的政府信息，可以转为主动公开的，应当主动公开。

（五）接受社会监督

20.纳入政府信息公开年度报告

办公室

政务公开工作主要任务落实情况要纳入政府信息公开年度报告并向社会公布，接受社会监督。
