关于切实做好2018年中秋、国庆假日旅游 安全和文明旅游工作的通知

发布时间：2018-09-12 10:00
| | |
  

 

各县（区、管委会）旅游局：

    2018年中秋、国庆即将到来，为切实做好“两节”期间旅游安全和文明旅游工作，根据省旅游产业发展工作联席会议办公室《关于开展2018年中秋国庆假日旅游市场和安全大检查工作的通知》（闽旅产联办明电〔2018〕13号）和市委市政府工作要求，为切实做好我市假日旅游安全和文明旅游工作，现将有关事项通知如下： 

    一、要切实提高认识，高度重视旅游安全保障工作

    中秋、国庆假期时间长，群众出行和公众活动增多，人流、物流、车流集中，安全生产压力增多，做好节日期间安全生产工作，尤为重要。各县（区、管委会）旅游局要切实将安全工作摆在首位，强化红线意识和底线思维，确保中秋、国庆假日期间不发生重特大旅游安全事故。要认真落实旅游安全监管责任，加大对旅游安全的监督和管理。要加大对旅行社的安全监管，督促旅行社不得租（使）用无运营资质的车辆，不得安排到无经营资质、不符合安全许可条件的场所游览；要主动会同公安、交通、卫计、质监、食药监、水利等有关部门，加强对旅行社、星级饭店、A级景区等旅游企业的检查；要按照谁主办、谁负责原则，突出抓好大型活动和人群密集场所防踩踏等应急演练，依法指导A级旅游景区做好游客流量控制，制定应急疏散措施，加强应急救援演练，提高应急处置能力。各县（区、管委会）旅游局要督促旅游企业落实安全生产主体责任，扎实全面做好假日旅游安全工作，加强旅游安全宣传教育，提高游客和从业人员自我防范风险意识和能力。

    二、要彻底排查隐患，确保假日期间旅游安全形势持续稳定

    （一）要督促旅行社做好安全各项工作。要督促各旅行社租用车辆时，必须选择有营运资质的车队、技术性能合格的车辆和责任心强、技术过硬的驾驶员，导游要查看签订车辆、人身等相关保险合同，明确事故责任追究制度和处理赔偿办法。要认真开展安全防范教育，要求导游员加强对驾驶员的监督，确保在行车时注意车况、路况、人况，严禁驾驶人员违章、疲劳驾驶、酒后驾驶，保证旅游车辆行车安全。严禁使用非法车辆从事旅游客运；严禁使用带“病”运营、超载运营车辆从事旅游客运；严禁使用没有运营资格的社会闲散车辆从事旅游客运；严禁使用无车辆保险或保险手续不齐全的车辆从事旅游客运。在安排游览项目时，旅行社要向游客明确安全事项，尽量不安排具有危险性的游览项目。要做好安全应急预案，加强对导游人员的教育，做好客流高峰期间的游程安排，并担当起“安全宣传员”的责任。

    （二）要会同相关部门加强对A级旅游景区的安全监管。各县（区、管委会）旅游局要严格落实属地监管、行业监管、部门监管和企业主体责任，会同相关部门严格排查安全隐患，从严从实从细抓好各项安全防范措施落实。节前要对各A级旅游景区的风险区域、游客运载工具及带有危险性的旅游项目（设备）进行一次全面排查，落实有效安全管控措施，达不到安全要求的，要坚决采取封闭、禁用或停止运营等措施；要严格控制景区客流量，强化大型群众性活动安全管理，严密制定安全管控措施，合理控制、及时疏导密集人流，严防拥挤踩踏等群死群伤事故发生。各A级旅游景区要认真落实安全生产主体责任，健全安全生产各项制度，把责任落实到位、到人；要认真检查景区内的各种运输工具和游乐设施性能是否完好，是否有专人值守；游览线路的沿线安全警示标志是否明显，安全防护设施是否完好，紧急疏导通道是否畅通，秩序维护人员配备是否周全；餐饮场所卫生条件是否达标，购物场所的消防设施是否齐备，同时要做好景区防火工作，开展突发事件应急预案。

    （三）要扎实做好星级饭店的安全隐患排查。各县（区、管委会）旅游局要督促星级饭店切实做好节日期间的消防安全、供水、供电、卫生检疫、防止食物中毒等工作，健全安全管理制度和应急预案。要对店内消防喷淋设施、安全通道进行一次全面检查，杜绝火灾隐患；要认真检查内部供水、供电情况，对已老化的管道、线路及时进行维修、更换；要狠抓食品卫生、菜肴质量管理，严防食品中毒事故的发生。中秋、国庆假期和第五届世界佛教论坛期间要以防火、防盗、防各种恶性治安案件为重点，加强对楼层、停车场的24小时安全巡视；加强对重点消防部位和重点岗位防火、值守情况的检查；同时要注意观察可疑情况，发现问题要及时报告有关部门，并采取措施进行监控；要加强对境外旅游团体、散客住店的安全保卫工作，保障游客的人身、财产安全。对有可能产生的人身伤害和其他隐患的要对游客进行公开警示。

    三、要加强文明旅游宣传，认真开展文明旅游特色宣传活动

各县（区、管委会）旅游局要加强与新闻媒体的沟通和合作，充分发挥其舆论引导作用，通过各类新闻媒体、网络媒体联动，采取集中宣传与日常报道相结合的方式，广泛报道各地丰富多彩的文明旅游活动，营造鲜活丰富的文明旅游氛围。在旅游景区、商业街区、星级饭店、旅游集散中心等游客密集场所，大力宣传文明旅游《公约》和《指南》、十大文明旅游提醒语等内容，刊播文明旅游动漫片、微电影、微视频、提示语和公益广告，强化文明旅游意识，加强正面宣传引导。各旅游企业要围绕文明引导、游览讲解、质量监督、旅游咨询、特殊群体帮扶、应急救援等旅游志愿服务重点领域，在全市大力开展旅游志愿服务活动，宣传志愿服务精神。各出境游组团社（分社）要做好出境文明旅游工作，领队要配合地接导游，提醒游客文明旅游，严禁携带非法出版物和“黄毒”物品。

四、要强化应急值守，全面落实旅游安全生产报告制度

中秋、国庆期间，正值台风暴雨季节，各县（区、管委会）旅游局要全面落实防汛防台风责任，认真检查旅游企业防汛防台风防暴雨应急准备工作，关注气象预报，发布气象信息，认真落实节假日24小时值班、领导带班以及安全工作措施。要保证信息渠道畅通，确保人员到位，职责到位，措施到位。要提前做好各项应急保障和处置准备工作，一旦发生突发事件，确保能迅速实施应急救援，并立即向上级有关部门报告，做到不漏报、不误报、不瞒报。
