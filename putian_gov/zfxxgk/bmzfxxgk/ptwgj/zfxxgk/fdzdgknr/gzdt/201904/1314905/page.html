关于印发《莆田市旅发委2018年度绩效管理工作方案》的通知

发布时间：2018-06-06 10:42
| | |

 

机关各科室、直属单位：

根据《中共莆田市委办公室 莆田市人民政府办公室关于印发<2018年度绩效管理工作方案>的通知》（莆委办〔2018〕30号）文件精神，结合我委工作实际，经研究，现将《莆田市旅发委2018年度绩效管理工作方案》印发给你们，请结合工作实际和岗位职责，认真贯彻执行。

 

 

莆田市旅游发展委员会（代）

                          2018年6月6日


莆田市旅发委2018年度绩效管理工作方案

一、组织领导

绩效管理工作在市委、市政府的统一领导和市效能办的具体指导下，由委党组精心部署，成立委效能工作领导小组，组长由林桦主任担任，副组长由黄宏敏副主任、苏玉庆副主任、陈兵副主任和温训新调研员、赖秀云副调研员担任，成员由委机关各科室和直属单位负责人组成，主要负责绩效管理工作的组织领导、管理协调、研究分析和评定等次等。领导小组下设办公室，挂靠委办公室，日常工作由办公室负责，各科室和直属单位密切配合、抓好落实。

二、考评对象

机关各科室、直属单位全体干部职工。

三、考评内容

重点考核业务实绩、自身建设、机制创新三项内容。

（一）业务实绩方面：

1、贯彻落实市委、市政府的决策部署情况；

2、2018年省政府工作主要任务、市政府工作主要任务、国民经济和社会发展计划主要指标、为民办实事项目、效能工作要点等落实情况。推行任务落实“负面清单”管理，对市委市政府文件、纪要议定的有明确时间节点的事项，逾期5个工作日未落实的，各科室、直属单位要实时梳理并列入“负面清单”，强化跟踪落实，按月报送进展情况，办公室对“负面清单”进行重点滚动管理、跟踪督办。

（二）自身建设方面：

主要围绕依法、高效、民主、廉洁4个方面进行考核。

（三）机制创新方面：

重点考核全面深化改革，落实国家、省赋予的重大改革试验任务情况；项目推进、产业发展、政府配置资源方式、生态建设、“放管服”改革、优化营商环境，以及业务管理、自身建设等方面的创新举措。每个科室、直属事业单位要力争创出1-2项特色、亮点工作，年底选送1项最具有创新性、示范性、推广性的工作参加集中评审。

四、考评方式

采取指标考核、公众评议、正向激励、效能督查、省对市考核指标排名情况运用相结合的方式进行。

（一）指标考核

各科室、直属单位要建立工作台账，对市绩效考核指标落实情况进行常态化跟踪管理，对市委市政府下达的实质性目标任务落实情况进行常态化跟踪管理并建立“负面清单”，从6月份起按月报送办公室。

办公室、产业科等绩效考评指标数据采集责任科室要认真、客观采集指标数据，原则上所采集指标的最高扣分要不低于分值的30%，经征求参评单位意见后于2019年1月10日前报办公室。

（二）公众评议

由办公室牵头组织，对各科室、直属单位完成任务、优化服务、改善民生、维护群众利益和改革创新等方面情况结合年度考核民主测评适时开展。2019年初，办公室提供一份1000字以内的年度工作总结报市效能办，市效能办汇编成册后，报送市委、市人大、市政府、市政协领导，由领导对我委年度绩效情况作出评价。

（三）正向激励

鼓励各科室、直属单位结合实际创造性开展工作，卓有成效完成各项任务。各科室、直属单位受到上级通报表彰（表扬）以及在争取资金、任务落实、优化环境、增收减支、自查自纠等工作中取得显著成效的，给予适当的绩效激励加分，并及时将相关材料报送办公室，办公室要对正向激励事项进行常态化滚动管理、按月梳理报送市效能办。

（四）效能督查

由办公室牵头，结合日常效能督查，采用随机抽查、明察暗访等方式，重点就各科室、直属单位以及干部职工工作落实、作风建设等情况，以及绩效指标完成和数据真实性、准确性等情况，不定期组织开展察访核验。发现的问题以倒扣分形式计入绩效考评总分。

（五）省对市考核指标排名情况运用

办公室、产业科等负责的省对市绩效考核指标位列全省第1-3位的，分别加5分、4分、3分；位列第7-9位的，分别扣4分、5分、6分；位列第4-6位的，相比上一年每退步1位扣0.5分。

五、结果汇总与运用

（一）结果汇总

绩效考评得分＝指标考核得分×70%＋公众评议得分×30%＋正向激励加分－效能督查扣分＋省对市考核指标排名情况运用。

（二）结果运用

1、通报考评结果。绩效考评结果在全委进行通报。

2、挂钩考核评定。组织开展实质性内部绩效考评，作为单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。

3、实施绩效奖励

①优秀等次、一般等次分别按照良好等次个人绩效奖金的1.2倍、0.5倍发放绩效奖金。

②凡受到党纪政务处分、效能问责的人员，年度考核被评为不称职（不合格）的人员，被省委、省政府、省效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的单位人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假累计超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病事假超期人员标准的5倍减发绩效奖励。

4、实施效能问责

①年度绩效考评结果为一般和差等次的，责成其向市机关效能建设领导小组提交书面整改措施，单位主要领导作出整改承诺。

②省、市效能督查发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫（含）以上处理，对分管领导进行通报批评，存在突出问题的对单位主要领导进行诫勉教育。

5、反馈整改。各科室、直属单位要针对绩效考评中发现的问题，认真分析研究，查找薄弱环节，深刻剖析原因，制定整改措施，促进绩效提升。整改情况纳入下一年度绩效考评。

六、工作要求

（一）提高思想认识。要把严格绩效管理作为推进国家治理体系和治理能力现代化的重要内容，作为促进市委、市政府决策部署落实的重要举措，作为打造宜居港城、建设美丽莆田，创建美丽中国的示范区的重要保障，作为实现高质量发展和赶超目标的重要抓手，摆上重要议事日程，坚持主要领导负总责，分管领导亲自抓，经办人员具体抓，细化分解责任，层层传导压力。要经常分析绩效指标进展情况，加强对上沟通，对下指导，确保全面实现年度绩效目标。全力争取在全市绩效考评中取得优秀等次。

（二）加强过程监控。委机关效能建设领导小组及其办公室要充分发挥组织协调作用，统筹协调相关科室，做好各个环节的衔接，提升整体工作合力。各科室、直属单位要加强对年度绩效目标执行情况的监督检查、协调和考评，每月定期研究分析绩效考评指标进展情况，查找不足，及时改进，并对滞后事项建立“负面清单”进行跟踪管理、倒逼落实。各责任科室要按月统计分析省对市绩效考评指标落实情况，并按照要求将指标汇总报送市级指标采集责任单位。办公室要完善“月通报、季分析”制度，定期汇总、通报指标落实、机制创新、正向激励等情况，并定期进行会诊、点评、督导，促进工作提升。

（三）树立科学导向。各科室、直属单位要以严谨细致、务实求效的作风共同做好绩效管理工作，做到资料真实完整，数据准确可靠，台账规范有序。要健全绩效差异化发放、激励约束、容错纠错等机制，把绩效考评与干部使用、评先评优真正挂钩起来，形成“干与不干不一样、干多干少不一样、干快干慢不一样、干好干坏不一样”的鲜明导向，真正激发广大干部的干劲和冲劲。对绩效考评中发现的敷衍塞责、弄虚作假等问题，要严肃问责和处理。

附件：莆田市旅发委2018年度绩效考核指标体系
