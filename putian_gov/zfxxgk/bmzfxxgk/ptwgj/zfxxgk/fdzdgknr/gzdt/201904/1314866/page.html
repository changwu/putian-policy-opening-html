莆田市旅游局 关于印发2016年政务公开工作主要任务分解表

发布时间：2016-07-11 09:30
| | |
机关各科室、各直属单位：

为贯彻落实《莆田市人民政府办公室关于印发2016年政务公开工作主要任务分解表的通知》（莆政办〔2016〕106号），现将市旅游局《2016年政务公开工作主要任务分解表》印发给你们，请认真抓好落实。

一、强化组织领导。根据人员变动情况，及时调整了政务公开工作领导小组，在政务公开工作领导小组的统一领导下，建立办公室牵头、各科室各负其责、相互配合的工作机制。各科室要认真履行政务公开责任，把政务公开作为各科室工作的重要内容，与业务工作紧密结合起来，统筹考虑，统一部署，共同推进。

二、细化工作任务。各科室要根据职责分工，紧紧围绕市委市政府中心工作、重大决策部署和公众关切，细化工作任务，坚持以公开为常态、不公开为例外，加大公开力度，加强政策回应解读，各牵头科室要落实牵头主抓责任，加强工作指导，各责任科室要密切配合，抓好各项工作任务落实。

三、加强督查考评。我局把政务公开工作纳入绩效考评，作为今年效能督查的重要内容，与行动计划“一季度一督查”相结合，通过明察暗访、督促检查，确保各项任务落实到位。各科室要确定一名政务公开工作联络人，具体负责工作对接和落实情况汇报。前三季度、全年工作要点落实情况分别于9月2日、11月18日前报送局办公室。

附件：莆田市旅游局2016年政务公开工作主要任务分解表

 

 

 

 

莆田市旅游局

2016年7月8日

 

莆田市旅游局2016年政务公开工作主要任务分解表

 

工作任务

责任科室

工作要求

一、围绕深化改革推进公开

（一）进一步推进权力清单和责任清单公开

1.全面公开我局权力清单和责任清单

行管科牵头，各科室配合

通过政府门户网站集中展示，及时动态更新。

2.我局取消、下放、保留行政审批等事项的公开

重点公开保留的行政许可事项清单、中介服务事项清单。

（二）推进市场监管公开透明

3.依法公开随机抽查事项清单

行管科

明确抽查依据、主体、内容、方式，及时公布抽查结果和查处情况。

4.推进监管执法信息公开

质监所

推进旅游市场方面的监管执法信息公开，公开监管执法的依据、内容、标准、程序和结果。

5.推进企业信用信息公示系统建设

行管科、质监所

通过系统归集并公示对企业作出的行政许可、行政处罚、抽查检查和企业严重违法失信等信息。

（二）推动政务公开

6.推进“互联网+政务”

公共服务中心牵头，各科室配合

推动政务服务事项办理由实体政务大局向网上办事大局延伸，逐步实现在线咨询、网上办理、电子监察。

二、围绕促进经济发展推进公开

（一）进一步推进经济社会政策公开透明

7.加大稳增长、促改革、调结构、惠民生、防风险等方面的政策公开力度

办公室牵头，各科室配合

及时公布支持“双创”、培育发展新动能、改造提升传统动能、深挖内需潜力、优化产业结构、扩大对外开放等方面的政策措施。对公开的重大政策要分专题梳理汇总，通过在网站开设专栏、出版政策及解读汇编等方式集中发布。

三、围绕民生改善推进公开

（一）推进就业创业信息公开

8.推进就业创业信息公开

办公室牵头，质监督所、公共服务中心配合

做好局直属事业单位人员招录信息的发布工作，扩大就业信息服务的受众面。

四、围绕助力政府建设推进公开

（一）积极推进决策公开

9.推进重大决策预公开

办公室牵头，各科室配合

对社会关注度高的决策事项，除依法应当保密的外，在决策前应向社会公开相关信息，并及时反馈意见采纳情况。

（二）推进政策执行和落实情况公开

10.围绕政府工作报告、发展规划提出的重要事项，实事求是公布进展和完成情况

办公室牵头，各科室配合

特别是市委、市政府部署的改革任务、民生举措，要细化公开执行措施、实施步骤、责任分工、监督方式等。

（三）深入推进预决算公开

11.推进单位预决算公开

办公室

公开内容包括本单位职责、机构设置、一般公共预算和收支、政府性基金预算和收支、机关运行经费等。除涉密信息外，部门预决算支出应当公开到功能分类项级科目，一般公共预算基本支出细化公开到经济分类款级科目，其中“三公”经费公开格式参照《莆田市财政局关于市直各单位“三公”经费公开事项的通知》（莆市财预〔2014〕62号）。

五、围绕扩大政务参与加强解读回应

（一）主动做好政策解读

12.及时发布重要政策解读

办公室牵头，各科室配合

出台重要政策，应将文件和解读方案一并报批，相关解读材料应于文件公开后3个工作日内在政府网站和媒体发布。

13.主要负责人主动参与政策解读工作

对涉及面广、社会关注度高的法规政策和重大措施，单位主要负责人应通过参加新闻发布会、接受访谈、发表文章的方式带头宣讲政策，传递权威信息，年内解读重要政策措施不少于1次。

14.加强专家库建设

为专家学者了解政策信息提供便利，更好发挥专家解读政策的作用。

15.注重运用各级各类新闻媒体及时全面准确解读政策

针对不同社会群体，采取不同传播策略，要重视发挥主流媒体及其新媒体“定向定调”作用。

（二）积极回应社会关切

16.认真研判处置所涉及的重要政务舆情、媒体关切等热点

各科室

及时借助媒体、网站等渠道发布准确权威信息，讲清事实真相、有关政策措施、处置结果等。

17.做好重大突发事件处置

遇有重大突发事件，负责处置的地方、单位是信息发布第一责任人，主要负责人要当好“第一新闻发言人”，快速反应、及时发声。针对涉及突发事件的各种虚假不实信息，要迅速澄清事实，消除不良的影响。特别重大、重大突发事件发生后，应在24小时内举行新闻发布会。

（三）更好地发挥媒体作用

18.统筹运用媒体做好发布工作

办公室牵头，各科室配合

要善于运用媒体发布信息、解读政策，引领舆论、推动工作。

19.及时报道政策解读

重要信息、重大政策发布后，要注重运用主流媒体及其新媒体在重要版面、重要位置、重要时段及时报道解读。出台重大决策部署，要通过主动向媒体提供素材，召开媒体通气会，推荐相关专家学者接受访谈等方式做好发布解读工作。

20.畅通媒体采访渠道

创造条件安排主流媒体及其新媒体负责人列席有关重要决策会议。

六、围绕增强公开实效加强能力建设

（一）提高政务公开标准化水平

21.推进政府信息主动公开基本目录建设

办公室牵头，各科室配合

进一步明确重点领域、重点行业公开的主体、内容、时限、方式等，提升主动公开的规范化水平。

22.加强对规范性文件公开的审查

定期对不公开的政府信息进行评审，确保应公开尽公开。

23.严格执行保密审查

进一步完善政府信息公开保密审查制度，对拟公开的政府信息依法依规做好保密审查。

（二）提高政务公开工作信息化集中化水平

24.充分发挥门户网站信息公开第一平台作用

办公室牵头，各科室配合

增强政府网站发布信息、解读政策、回应关切、引导舆论的功能。加强政府网站数据库建设，完善查询功能，提升公开信息集中度，强化与新闻网站、商业网站的联动。

25.增进与公众互动交流

加强政府热线管理，开展部门开放日、网络问政等活动。

26.加强政府信息查阅场所工作

按照规范化要求做好政府信息送交工作。

（三）提高政务公开队伍专业化理论化水平

27.轮训政务公开工作人员

办公室

积极组织政务公开工作人员参加业务培训。

28.政务公开工作人员要加强政策理论学习和业务研究

政务公开工作人员要准确把握政策精神，增强专业素养，强化公开理念，提高指导推进政务公开工作的能力和水平。
