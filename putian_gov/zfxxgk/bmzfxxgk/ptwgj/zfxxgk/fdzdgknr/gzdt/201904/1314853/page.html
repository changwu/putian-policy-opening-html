关于参加2015年中国旅游日活动的通知

发布时间：2015-05-13 08:00
| | |

　　各县（区、管委会）旅游局：

　　为了进一步宣传“妈祖故乡 工艺莆田”的旅游品牌和倡导文明旅游，经研究，决定5月19日中国旅游日，在文献路步行街广场举办“妈祖故乡行”旅游宣传活动和“文明旅游倡议”签字仪式，请各县（区、管委会）旅游局按照活动方案的要求认真抓好落实，并组织辖区内的旅游企业积极参会，特此通知。

　　附：2015年中国旅游日“清新福建”莆田分会场活动方案

　　莆田市旅游局

　　2015年5月13日


　　附：

　　2015年中国旅游日“清新福建”莆田分会场活动方案

　　——“妈祖故乡行”宣传日暨“文明旅游倡议”签字仪式

　　 

　　一、指导思想

　　通过宣传“中国旅游日”系列活动，调动社会和企业力量投资兴旅，不断提升公民旅游意识和休闲意识，激发大众旅游热情；倡导文明旅游，充分发挥旅游业在传承文化、提升素质等方面的积极作用；在全社会营造关注旅游、参与旅游、支持旅游、推动旅游发展的良好氛围。

　　二、活动原则

　　1、广泛参与。注重发挥相关部门、行业协会、有关企业、新闻媒体、网络平台和广大游客参与“中国旅游日”活动的积极性，突出活动的大众化、群众性特点。

　　2、公益惠民。鼓励调动社会资源、结合当地实际采取措施，推出各类旅游公益惠民措施和促销活动，使“中国旅游日”活动更多地惠及民生、惠及百姓。

　　3、突出主题。紧紧围绕“中国旅游日”年度主题，策划宣传并开展活动。

　　4、形式多样。鼓励景区、旅游企业在5.19前后推出持续时间长、社会影响力大、形式多样的活动。鼓励旅游管理部门、旅游企业利用互联网和新媒体等手段扩大活动效果。

　　三、活动口号和主题

　　1、宣传口号：“爱旅游  爱生活”。

　　2、活动主题：“新旅游  新常态”。

　　四、中国旅游日莆田分会场宣传氛围营造

　　1、媒体宣传。联合莆田电视台栏目推出“妈祖故乡 工艺莆田”旅游日专栏，配合我市主要新闻媒体开展深度专访、旅游报道等版面营造氛围（湄洲日报、侨乡时报）提前发布旅游日活动信息。

　　2、广告宣传。以宣传广告牌为载体，鼓励支持各景区在公路沿线、车站、市区中心等位置，制作旅游广告牌进行宣传。

　　3、网络宣传。通过新浪、腾讯微博、微信、移动短信等平台发布旅游日活动方案及旅游日活动新闻的网络宣传。

　　4、酒店宣传。在酒楼饭店发放莆田旅游宣传材料，组织有意愿的旅游景区、旅行社做好定点宣传。

　　五、活动地点时间

　　1、活动时间：2015年5月19日上午9：00。

　　2、会场地点：文献路步行街舞台。

　　3、参加人员：莆田市人民政府副市长、市府办副主任、各县（区、管委会）分管领导、各县（区、管委会）旅游局局长、全市星级酒店、各旅行社、旅游景区的代表及游客、新闻媒体共计200人。

　　六、主要活动议程：

　　主持人：黄宏敏

　　1、市旅游局局长王秋洪讲话。

　　2、台上领导向在场游客代表象征性发放旅游免费门票15套（莆田一日游或二日游套餐价值500元）。

　　3、倡导文明旅游签字仪式（领导一行到大幅红布前签字后离开会场，然后旅游业界代表签字）。

　　4、主要景区现场发放莆田旅游宣传品等材料，鼓励推出老、少、残人员旅游优惠条件。

　　5、旅行社进行产品推介，旅游咨询活动，现场销售优惠价格的市内外旅游产品。

　　七、会场布置

　　1、搭建主席台，背景妈祖图案，台上铺设红地毯。横幅“2015年中国旅游日“清新福建”莆田分会场。副市长、市府办领导、各县（区、管委会）分管领导、市旅游局领导站在台上。

　　2、台前搭建拱形大气柱，内侧两颗大气球，拱形气柱书写“妈祖故乡  工艺莆田”，主席台正前方悬挂用于倡导文明旅游签字大幅红布。

　　3、主席台前两侧分别是旅游企业台位，以企业宣传图案作背景，各摆设一排座椅，供旅游企业代表现场促销。

　　八、其他要求

　　1、各县（区、管委会）旅游局组织辖区内收费旅游景区提供7折以上优惠门票各500张，可设定使用期限。

　　2、全市各旅行社、旅游景区、星级酒店要提供充足的宣传材料用于现场发放。

　　3、旅行社要组织部分旅游团队参加活动并派部分代表参加签字活动（由行管科负责）。

　　4、部分参会人员前往后黄村参观游览。
