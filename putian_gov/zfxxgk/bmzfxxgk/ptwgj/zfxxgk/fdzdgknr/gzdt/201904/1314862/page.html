关于开展2015年度导游员（景区讲解员）年审培训的通知

发布时间：2016-03-08 08:00
| | |

　　各县（区、管委会）旅游局、旅行社：

　　根据《导游人员管理条例》及闽旅人〔2015〕304号文件要求，现将2015年度全市导游人员年审工作有关事项通知如下：

　　一、年审对象

　　登记在我市并持有导游IC卡的所有专职、兼职导游人员，景区讲解员等。

　　二、年审内容

　　（一）2015年从事导游业务情况、扣分情况、接受行政处罚情况、游客反映情况等；

　　（二）参加日常培训和年审培训情况。

　　三、年审刷卡

　　（一）交卡时间（另行通知）；

　　（二）所需资料（培训时交齐）《导游人员年审培训考核登记表》、《导游人员年审培训汇总表》、挂靠单位社保单复印件及原件（2015年度）。

　　（三）交卡地点

　　城厢区石景路凤凰花园内――莆田市旅游公共服务中心（联系电话：2656768/6982656）

　　四、年审培训费用

　　1、本年度年审培训费用等由市旅游局承担；

　　2、未参加本年度年审培训的或年审不合格的，将采取补审，补审的费用由个人承担，每人300元/年。具体时间及补审的形式另行通知！

　　五、具体事项

　　1、参加年审培训的导游员须认真填写《导游人员年审培训考核登记表》。（从http://www.ptly.gov.cn网站上下载）

　　2、旅行社对导游人员本年度从事导游业务的情况、游客反映情况及日常培训情况等进行考核，并签署意见。

　　3、各旅行社负责组织并通知本单位专职及兼职（含挂靠）导游员及景区讲解员参加年审培训。

　　4、导游员必须参加年审。年审的内容包括当年度从事导游业务的情况、扣分情况、受行政处罚情况、游客反映情况等。

　　5、导游人员当年度不参加年审培训及年审检测不合格者，由各单位（旅行社）将其导游执业证（IC卡）收回，送交市旅游公共服务中心，暂扣一年。连续两年不参加年审培训或检测不合格的予以吊销导游执业证（IC卡），并在莆田市旅游局官方网站上公示。

　　6、各旅行社要将年审人员名单汇总后上报市旅游公共服务中心。（“导游人员年审培训汇总表”从http://www.ptly.gov.cn网站上下载）

　　六、年审培训实施

　　2015年度莆田市导游人员（景区讲解员）年审培训由莆田市旅游公共服务中心负责组织实施。

　　附件：1、2015年度莆田市导游人员年审培训方案

　　2、2015年度导游人员年审培训报名汇总表

　　3、2015年度莆田市导游人员年审培训考核登记表
