莆田市旅游局所属事业单位市旅游质量监督管理所、市旅游公共服务中心岗位设置方案

发布时间：2016-08-05 09:36
| | |
 
 

市人力资源和社会保障局：

为深化单位人事制度改革，加快推进聘用制度和岗位管理制度，实现单位人事管理的科学化、规范化和制度化，根据市委办、市府办《关于印发〈莆田市事业单位岗位设置管理实施意见（试行）〉的通知》（莆委办〔2008〕66号）等有关文件精神，结合我局实际，特制定莆田市旅游局所属2个事业岗位设置方案如下:

一、单位基本情况

莆田市旅游局下设市旅游质量监督管理所、市旅游公共服务中心等2个事业单位。

（一）市旅游质量监督管理所：旅游质量监督管理所为正科级事业单位，根据莆委编办[2016]31号文件批复，人员编制核定8名（其中所长1名，副所长1名，专技人员6名），人员经费实行财政核拨管理办法。现有在编事业人员4名，其中所长1名、业务经办人员3名。

（二）市旅游公共服务中心为正科级事业单位，根据莆委编办【2014】55号文件批复，由市旅游服务行业培训中心、市境外旅游办事处、市旅游接待站，重新组建莆田市旅游公共服务中心，核定编制8名（其中中心主任1名，副主任1名，专业技术人员5名，工勤人员1名），人员经费来源为自收自支。现有在编事业人员4名，其中中心主任1名，副主任1名（享受正科待遇），经办人员2人。

二、岗位设置的指导思想和基本原则

（一）指导思想

通过建立岗位管理制度和人员聘用制度，创新管理体制，转换用人机制，整合人才资源，凝聚优秀人才，实现由身份管理向岗位管理的转变，由固定用人向合同用人转变，调动单位各类人员的积极性和创造性，促进各项社会事业的发展。

（二）基本原则 

坚持科学合理、精简效能的原则；坚持按需设岗、竞聘上岗、按岗聘用、合同管理的原则；坚持公开平等、竞争择优、依法办事的原则。

三、拟设置岗位情况

我局下属2个事业单位设置岗位总量16个，实际在编人员8人。其中：管理岗位8个，占单位岗位设置总量的50%；专业技术岗位7个，占单位岗位设置总量的44%；工勤技能岗位1个，占单位岗位设置总量的6%。

（一）管理岗位的名称、等级、数量

管理岗位总量8个，占单位岗位总量的50%，设2个职员岗位为七级职员管理岗位，分别为市旅游质量监督管理所所长1个、市旅游公共服务中心主任1个；设2个岗位为八级职员管理岗位，为市旅游质量监督管理所副所长1个, 市旅游公共服务中心副主任1个；设4个岗位为九级职员岗位，分别为市旅游公共服务中心2个，市旅游质量监督管理所2个。

（二）专业技术名称、等级、数量及结构比例

专业技术岗位总量7个，占单位岗位总量的44%。

1、高级岗位1个，为专业技术六级岗位，占专业技术岗位的12%，该岗位设在市旅游质量监督管理所。

2、中级岗位2个，为专业技术八级岗位1个，九级1个，占专业技术岗位的35%。其中市旅游质量监督管理所八级1个，市旅游公共服务中心九级1个。

3、初级岗位4个，占专业技术岗位的53%。设初级专业技术十一级岗位2个，十二级2个。其中市旅游质量监督管理所十一级1个，十二级1个；市旅游公共服务中心十一级1个，十二级1个。

（三）工勤技能岗位名称、等级、数量

工勤技能岗位总量1个，占单位岗位总量的6%。为中级工岗位，设在市旅游公共服务中心。

    四、岗位设置工作组织领导情况

    1、研究成立莆田市旅游局事业单位岗位设置管理领导小组，下设领导小组办公室。

2、研究制定岗位设置方案和岗位设置实施方案。

3、开展政策文件的学习、宣传。广泛听取职工的意见。

4、岗位设置工作严格政策，严肃纪律，不违规突破岗位数额，不突击聘用人员，不突击聘用职务，精心组织，周密安排，承认现状，平稳过渡，积极有效推进本单位岗位设置工作。
