莆田市文化和旅游局关于做好全省“十佳旅游集散服务中心示范点”遴选工作的通知

发布时间：2020-07-28 16:17
| | |

各县区文旅局，湄洲岛旅文局，北岸党工委宣传部：

为提升旅游集散服务中心运营管理水平，省文旅厅将在全省开展“十佳旅游集散服务中心示范点”遴选工作，并为示范点单位颁发牌匾，同时给予每个单位10万元资金补助。请你们按照《福建省文化和旅游厅关于开展“十佳旅游集散服务中心示范点”遴选工作的通知》（附件）的推荐范围、基本条件等要求积极开展申报工作，我局将择优推荐报送省厅，相关材料于8月20日前报送市文旅局公共服务科。联系人：苏美婷，电话2696660，邮箱pt2696660@163.com。

务中心示范点”遴选工作的通知

 

 

                        莆田市文化和旅游局

                          2020年7月22日

 

附件

 

福建省文化和旅游厅关于开展“十佳旅游

集散服务中心示范点”遴选工作的通知

 

闽文旅公共〔2020〕6号

 

各设区市文旅局，平潭综合实验区旅游文体局:

    近年来，我省全面贯彻落实国务院印发的“十三五”旅游业发展规划，积极适应旅游业蓬勃发展的新形势和游客日益增长的服务需求，不断完善旅游公共服务设施建设，至2020年底将建成旅游集散服务中心85家，实现“十三五”期间全省所有县（市）建有旅游集散服务中心的目标。为总结推广目前较为成功的管理模式和运营方式，以点带面，推动全省旅游集散服务中心运营管理水平的提升，将在全省开展“十佳旅游集散服务中心示范点”遴选工作。现就有关事项通知如下：

一、推荐范围

2019年6月30日前已建成并投入使用的旅游集散服务中心，评定等级为1-3级并符合福建省“十佳旅游集散服务中心示范点”基本条件（详见附件1）。

二、名额分配

九个设区市和平潭综合实验区各推荐2个，全省最终遴选评定10个，授予“十佳旅游集散服务中心示范点”称号（原则上9市1区各1个）。

三、遴选方式

由县（市、区）文旅部门推荐出符合条件的旅游集散服务中心，相关材料报所在设区市及平潭文旅部门；设区市和平潭文旅部门对上报材料进行审核，并开展实地查看查核后分别推荐2个候选单位上报。

省文旅厅将组织专业学者以及省直相关部门业务人员组成专家组，根据《福建省“十佳旅游集散服务中心示范点”基本条件》进行评审并开展实地检阅交流等，择优遴选出10个旅游集散服务中心示范点（原则上每个地市1个），经研究审定并公示后，确定为福建省“十佳旅游集散服务中心示范点”。

四、时间安排

从下发通知之日起至9月30日，共三个阶段：

第一阶段：从下发通知之日起至8月10日。各县（市、区）文旅部门对符合要求的旅游集散服务中心进行推荐；

第二阶段：8月11日至8月31日。各设区市文旅局和平潭旅游文体局对县（市、区）推荐的材料进行审核并实地查看，按分配名额向我厅报送“十佳旅游集散服务中心示范点”推荐表（详见附件2）；

第三阶段：9月1日至9月30日，我厅组织专家组对各地推荐上报的“十佳旅游集散服务中心示范点”进行复核检查、评审、公示以及通报评定结果。

五、奖励与补助

省文化和旅游厅将为“十佳旅游集散服务中心示范点”颁发牌匾，并给予每个单位10万元资金补助（不含厦门）。厦门可参照此标准，争取市级财政给予奖励补助。

六、工作要求

（一）高度重视，抓好落实。开展“十佳旅游集散服务中心示范点”遴选工作，是进一步推动我省旅游高质量发展和旅游公共服务设施提档升级的重要举措，各地要认真落实通知要求，严格推荐、审核等程序，做到“公平、公正、公开”。

（二）从严把关，突出实效。要按照《福建省“十佳旅游集散服务中心示范点”基本条件》，注重其工作特点特色，亮点和成效，彰显其代表性、示范性、引领性。

（三）落细落小，及时上报。要认真填报《福建省“十佳旅游集散服务中心示范点”推荐表》，上报资料必须是盖章完整的纸质件和该纸质件的电子文档（PDF版和WORD版），如有视频或图片资料可另附。所有材料连同书面推荐报告于2020年8月31日前报送至省文旅厅公共服务处。

附件1

福建省“十佳旅游集散服务中心示范点”基本条件

基本条件

涵盖内容

功能分区

总体面积：总体规划面积为16666㎡（25亩）以上，包括周边旅游服务设施。

分区功能：布局合理，功能分区科学，应有售票区、停车场、公共厕所等主要功能区。

中心宜设置咨询接待区、候车区等。

建筑要求

建筑外观：应突出福建地方特色，并与所在地域的自然和人文环境相协调。

服务大厅：布局合理、整洁干净，应设置咨询接待区、候车区、售票区、餐饮服务区、旅游商品购物区、公共厕所、失物招领处等；

面积500㎡以上。

候车区：设置无障碍通道、安检区以及专职危险物品检查人员；

面积100㎡以上。

停车场：地面硬化处理，道路平整干净；

配备车辆调度室、停车站台、线路牌；

车辆进出口应设置门禁，通行管理指示灯和限速标志；

有绿化；

面积1000㎡以上。

公共厕所：数量充足、通风良好、地面干净、整洁、无异味、光线明亮、标识醒目规范。

设施配备

咨询设施:提供景区导览图、游程线路图、宣传资料、交通游览图；

设置摸屏和影像设备，介绍景区资源、游览线路、游览活动；服务大厅的语音播放系统，播报发车、出行信息和目的地天气状况，通告班次调整、线路变更等特殊情况。

展示宣传设施：应设置宣传资料展示架，展示景区资料；

播放旅游宣传视频。

休闲设施：应设置游客休息区，面积、座椅数量适当，满足高峰期的短暂休息需求；

应设置饮水设施、饮食售卖点；

应设置游客购物点，可提供10种以上的特色纪念品和土特产。

标识设施：区域分布示意图、疏散指示图、指引标识、无障碍标识、安全标志、游客须知、注意事项等相应的中文引导标识，且数量足够、指向准确。

服务项目

集散服务：发车延误或停运及时告知、疏导、安置游客；

提供住宿、票务等服务；

旅游线路开通2条以上。

语言服务：提供简单手语服务和两种以上语言（含方言）的咨询服务；

广播人员发音标准，播报内容准确。

智慧服务：能提供景点（区）票价、旅游产品、咨询电话、班车时间、联 系方式等基本信息服务；

现场咨询人员能为游客提供面对面的咨询服务。

换乘服务：提供站外换乘指示图及注意事项；

根据班次时间，引导游客上车、检票服务，并监督换乘车辆正点运营。

车辆服务：提供车辆清洗服务；

旅游直通车应符合运营车辆的安全保障规范并设导游专用座、配备旅游风光等影像资料；

车内应在明显位置标明禁止吸烟和禁止明火的标志。

行政服务：及时有效处理游客投诉；

旅游部门入驻旅游集散服务中心，实施监管和服务。

其他服务：邮政投递；紧急救助；小件物品寄存、失物招领；

能为老弱病残孕提供便利服务等。

运营管理

1. 合法合规经营。应取得相应的工商执照、相关证照；

2. 运营模式科学。有专门的管理机构和符合当地实际的运营模式。在管理方式上有创新、有特色、有亮点；

3. 经济效益良好。接待旅游人数较多，取得较好经济效益；

4. 安全责任到位。无发生重大安全责任事故或影响较大的旅游投诉事件；

5. 旅客满意度高。旅客满意度达85%以上。

文旅融合

1. 环境优美、文化氛围浓厚，较好地体现当地的特色文化、传统文化；

2. 在服务项目上融合1—2个文化项目，如非遗展览展示、传承实践活动，传统戏剧表演、音乐演奏，各类文化培训、讲习讲座以及图书角、阅览空间等等。
