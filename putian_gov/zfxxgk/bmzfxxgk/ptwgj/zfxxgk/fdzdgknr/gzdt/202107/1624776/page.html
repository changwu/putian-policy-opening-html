关于印发莆田市2021年推进使用正版软件工作实施方案的通知

发布时间：2021-07-01 10:19
| | |

各县区（管委会）人民政府，各市直单位、市属国有企业：

根据省推进使用正版软件工作厅际联席会议印发的《福建省2021年推进使用正版软件工作实施方案》（闽版权〔2021〕14号）有关工作要求和部署，市推进使用正版软件工作局际联席会议办公室结合我市实际，研究制定了《莆田市2021年推进使用正版软件工作实施方案》，现印发给你们，请认真贯彻执行。

 

附件：莆田市2021年推进使用正版软件工作实施方案

 

 

         莆田市推进使用正版软件工作局际联席会议办公室

         莆田市文化和旅游局（版权局)代章

       2021年6月22日

（联系人：张玉应，电话：2623066）

附件：

 

莆田市2021年推进使用正版软件工作实施方案

 

2021年莆田市推进使用正版软件工作要坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记关于宣传思想工作的重要思想和关于知识产权保护工作的重要论述，认真贯彻落实习近平总书记来闽考察重要讲话精神，落实省委、省政府和市委、市政府关于版权管理工作的要求，持续稳步推进我市软件正版化工作，努力开创新时代推进使用正版软件工作新局面。

一、巩固长效工作机制

（一）充分发挥制度优势。推动各县区（管委会）各部门健全完善软件正版化相关工作机制，联席会议各成员单位进一步明确责任分工，强化凝聚共识、协调协作，形成各司其职、相互配合、齐抓共管的工作格局。（市文旅局牵头，局际联席会议各成员单位按职责分工负责，各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（二）健全检查考核制度。完善软件正版化工作监督核查、考核评议、年度报告制度，加大问责和曝光力度。推进党政机关软件正版化核查全覆盖，加大企事业单位核查力度。发挥第三方机构专业和技术优势，重点检查操作系统软件、办公软件、杀毒软件和工业设计软件使用情况。（市文旅局牵头，局际联席会议各成员单位配合，各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（三）强化日常管理制度。指导全县区（管委会）各部门认真贯彻落实《政府机关使用正版软件管理办法》《政府机关办公通用软件资产配置标准（试行）》《正版软件管理工作指南》等软件正版化工作制度，抓好软件正版化相关的采购经费预算、采购源头监管、软件使用管理、日常督促检查、年终考核评议、年度总结报告等各项规章制度执行，确保相关政策措施落实落细落到位。（市文旅局牵头，局际联席会议各成员单位按职责分工负责）

（四）规范软件资产管理。学习参照《中央行政事业单位软件资产管理工作指南》和新修订的《中央行政事业单位软件资产管理办法》，加强对我市行政事业单位软件资产配置和处置管理的工作指导，明确软件正版化管理要求，完善软件资产绩效考评指标，规范软件正版化工作流程。（市财政局）

（五）完善科技监管机制。通过银行保险机构监管评级，加强非现场监测，完善信息科技非现场风险监测机制，提高银行业保险业软件正版化的科技监管水平。（莆田银保监局牵头）

二、聚焦重点工作任务

（六）巩固党政机关软件正版化成果。推进党政机关提高软件正版化工作思想认识，加强统筹协调、政策指导和考核评议，督促本级机关持续做好“回头看”自查整改的同时，分步推进机关直属单位和本行业、本系统软件正版化检查整改工作。（市文旅局牵头，局际联席会议各成员单位配合，各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（七）抓好国有企业软件正版化整改验收。持续推动国有企业使用正版软件工作，加强对市、县区（管委会）国有企业软件正版化工作指导和监管，推动工作落到实处。督促指导企业集团落实职责分工，强化对权属企业软件正版化工作考核、监管和督查。（市文旅局、市国资委按职责分工负责，各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（八）加快推进事业单位软件正版化。根据《福建省推进企事业单位使用正版软件工作规划》，积极推进事业单位软件正版化检查整改工作，加强对事业单位推进使用正版软件工作的日常政策指导和有效监管，确保对照工作规划，按期完成整改任务。（市文旅局牵头，局际联席会议各成员单位配合，各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（九）持续推进金融机构软件正版化。巩固金融机构软件正版化成果，推动金融机构完善工作长效机制，加强日常监管和督查整改，加快推进中小金融机构软件正版化工作。（市银保监局牵头）

（十）探索民营企业软件正版化工作创新。鼓励在民营企业的重点龙头企业和条件成熟的商会中建立软件正版化工作试点，做好标杆，带动更多民营企业落实软件正版化工作相关要求。（市工商联按职责分工牵头，局际联席会议相关成员单位配合）

（十一）分步推进重要行业领域软件正版化。按要求继续分步推进能源、医疗、教育、交通、新闻出版等特定行业和重点领域软件正版化工作。持续推进工业设计软件正版化工作。（市文旅局牵头，市工信局、卫健委、教育局、交通局按职责分工负责）

三、规范软件采购使用

（十二）做好软件采购服务。根据实际需要扩大软件协议供货采购范围，增加软件产品数量和软件服务种类，畅通采购渠道，不断规范网上超市软硬件采购。加强针对存量计算机的软件采购指导。（市委网信办、市发改委、财政局按职责分工负责）

（十三）强化软件采购监管。按照《关于进一步加强计算机软硬件采购源头管理的通知》（闽版权〔2018〕7号)和《关于进一步加强计算机软硬件采购源头管理的通知》（莆文〔2018〕138号）要求，加强对软件采购行为的监督检查。落实“安全性、适用性、经济性和正版化”原则，强化计算机软硬件采购单位的验收主体责任，充分考虑软件采购前瞻性。严格执行《政府机关办公通用软件资产配置标准（试行）》和相关规定，加强协议供货的商品审核，确保纳入协议供货的软件不超过价格上限。（市委网信办、市市文旅局、市财政局、审计局、机关事务管理处按职责分工负责）

（十四）鼓励集中联合采购。鼓励各县区（管委会）各单位尤其是大型企事业单位探索优化软件采购模式，集中软件采购需求，组织有经验的专家组成谈判小组与供应商进行谈判，各直属单位或权属企业根据自身实际需求自愿采购，统一软件服务价格，节约软件采购成本，提高软件采购效率。（市文旅局牵头，局际联席会议各成员单位配合，各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（十五）规范软件使用管理。推动各级党政机关和企事业单位加强正版软件使用管理，建立健全正版软件使用情况台账，做好存量软件资产调配使用，严禁个人私自在单位计算机中安装或卸载软件。（局际联席会议各成员单位、各县区（管委会）软件正版化工作协调机构办公室分工负责）

（十六）促进正版化信息化融合。推动各县区（管委会）各部门软件正版化与信息化、信息安全相结合，倡导使用国产软件，部署建设的信息系统要兼容国产操作系统软件、国产办公软件等国产软件，不断提高信息系统的安全性和实用性。（市委网信办、市文旅局、发改委、工信局、各县区（管委会）软件正版化工作协调机构办公室分工负责，局际联席会议各成员单位配合）

（十七）加强软件正版化审计工作。结合相关审计工作，将软件正版化工作情况纳入审计内容，对软件采购、预算编制、资产管理情况进行审计，及时发现软件正版化工作中存在的问题。（市审计局、各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（十八）推动软件生态环境建设。配合国家做好第三方机构国产软件兼容测试平台建设，推动软件企业及时解决兼容性问题，改善软件生态环境。推进数据库软件正版化督查工作，促进数据库软件产业发展。（市文旅局、市工信局牵头，局际联席会议各成员单位按职责分工负责）

四、深化优化督促核查

（十九）开展市级党政机关软件正版化年度核查。结合软件正版化年度考核工作，引入第三方专业机构，对市级党政机关开展软件正版化工作情况核查和不定期“回头看”。（市文旅局牵头，局际联席会议各成员单位配合）

（二十）开展市属国有企业软件正版化整改验收。对市属国有企业开展“十三五”软件正版化检查整改工作验收，督促市属国有企业集团加强对权属企业软件正版化工作的进行考核。（市文旅局、市国资委牵头）

（二十一）指导县区（管委会）开展党政机关软件正版化工作核查。督促指导各县区（管委会）党政机关和企事业单位分步分批开展软件正版化全覆盖核查，扩大检查深度和广度。对部分县区（管委会）机关和企事业单位软件正版化完成情况进行抽查。（市文旅局、各县区（管委会）软件正版化工作协调机构办公室分别牵头，局际联席会议各成员单位配合）

（二十二）开展金融机构软件正版化工作核查。随机抽查部分金融机构软件正版化工作，督促金融机构对所属各单位软件正版化工作全面检查。（莆田银保监局牵头，市文旅局配合）

（二十三）开展重要行业软件正版化工作核查。配合省检查，随机抽查部分能源、医疗、教育、交通、新闻出版等行业企业软件正版化工作，加强制造业企业工业软件正版化的检查力度，督促行业主管部门加强监管本行业软件正版化工作。（市文旅局牵头，市工信局、卫健委、教育局、交通局按职责分工负责）

（二十四）优化督促核查方式方法。推进跨部门联合监督核查，优化督查组人员构成。进一步完善软件检查工具，充分使用技术手段提高核查效率。（市文旅局牵头，局际联席会议各成员单位按职责分工负责）

五、维护市场公平秩序

（二十五）严厉打击软件侵权盗版行为。将打击软件侵权盗版行为纳入2021年打击侵权假冒工作和打击网络侵权盗版“剑网2021”专项行动的重点工作任务。（市市场监管局、市文旅局、各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（二十六）依法查处软件行业垄断和不正当竞争行为。加大对软件行业等重点领域的竞争执法力度，严厉查处垄断和不正当竞争行为，维护软件市场公平竞争市场秩序和消费者合法权益。（市市场监管局牵头）

（二十七）做好预装正版操作系统软件监管。配合工业和信息化部开展预装正版操作系统软件工作调研、年度预装正版操作系统软件统计分析和开源操作系统软件知识产权风险防范研究等相关工作。（市工信局牵头，市文旅局、市场监管局配合）

六、广泛开展宣传培训

（二十八）全面开展软件正版化培训。加强党政机关、企事业单位软件正版化工作培训，普及软件正版化专业知识，提升使用正版软件、拒绝盗版的意识，推动各县区（管委会）各部门进一步增强做好软件正版化工作的自觉性主动性。（局际联席会议各成员单位、各县区（管委会）软件正版化工作协调机构办公室分别牵头）

（二十九）积极开展软件正版化工作宣传。结合版权宣传周、纪念著作权法实施三十周年等版权宣传重要时间节点，开展形式多样的软件正版化宣传活动，宣传政策要求，发布工作成果，树立典型标杆，推广经验做法，营造良好的社会氛围。（市文旅局、各县区（管委会）软件正版化工作协调机构办公室分别牵头，局际联席会议各成员单位配合）
