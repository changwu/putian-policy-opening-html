莆田市文化广电新闻出版局关于开展“新时代新风采”党的十九大精神宣讲文艺巡演活动的通知

发布时间：2017-11-28 16:09
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部:

　　根据闽文艺〔2017〕22号文件精神，为了更好发动全市文化工作者全面学习宣传贯彻落实党的十九大精神，经研究决定，在全市开展“新时代新风采”党的十九大精神宣讲文艺巡演活动，采取群众喜闻乐见的文艺形式，在全市持续掀起学习宣传贯彻党的十九大精神热潮。现将有关事项通知如下：

　　一、总体目标

　　认真学习宣传贯彻党的十九大精神，充分发挥文化系统的阵地和人才优势，大胆创新模式，以党的十九大报告的新思想、新论断、新提法、新举措为演出创作内容，贴近基层贴近群众，从讲出来到演出来，创造性地将理论宣讲和文艺演出合二为一、融为一体，增强党的十九大精神宣传的针对性、实效性和艺术性。组织全市文艺小分队，以更加生动、更容易理解接受的方式，进乡村、进社区、进校园、进企业、机关、进军营、进网络，把党的十九大精神送到基层，激发全市干部群众学习贯彻党的十九大精神，歌颂党、歌颂人民、歌颂新时代，热爱莆田、建设美丽莆田的热情和干劲。

　　二、发挥宣讲文艺演出的特点和优势

　　此次巡演定位为党的十九大精神宣讲文艺演出，以宣传党的十九大精神和习近平新时代中国特色社会主义思想为主线，在创作上，紧扣党的十九大报告进行创作，对照十九大报告13个部分的重点内容，原创节目，以艺术形式系统解读十九大报告，同时宣传我省、我市的新作为、新风貌、新变化；在节目上，力求耳目一新，用小节目讲大道理，以小见大、通俗易懂，把十九大报告转化为一个个群众听得懂、记得住、传得开的内容，寓理于情、寓教于乐；在形式上，突出接地气、群众喜闻乐见，以诗歌朗诵、莆田赞句、莆仙戏、十音八乐、相声、快板、三句半、俚歌、情景剧、小品、歌舞、表演唱等生动的形式进行宣传，达到文艺节目接地气、理论宣讲入人心的效果；在演出上，市文广局设计演出样式蓝本，各县区（管委会）结合自身特色和优势，取舍调整后复制演出，以当地文艺力量为主体进行演出，新创作的节目不断进入巡演节目库；在场所上，利用全市各地的小舞台、小戏台、小广场和剧场作为演出平台，推动文艺巡演进乡村、进社区、进校园、进企业、进机关、进军营、进网络，迅速形成全市上下遍地开花的声势。

　　三、主办与承办单位

　　指导单位：莆田市文化广电新闻出版局

　　主办单位：各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部

　　协办单位：各乡镇党委、人民政府等

　　四、组织实施

　　本次巡演以县区（管委会）为单位组织实施，各县区（管委会）要高度重视，把党的十九大精神宣讲文艺巡演作为今后一段时间的首要政治任务和工作任务，通过文艺形式生动宣传党的十九大精神，发挥文化系统在宣传党的十九大精神中的独特优势和重要作用。

　　（一）强化责任落实。在市文广局指导下，各县区（管委会）要成立由工作领导小组，加强组织领导和统筹协调，强化责任落实。县区（管委会）文化行政部门要积极响应，制定本辖区巡演方案，细化好演出蓝本，组织文艺院团、社会力量，启动辖区内宣讲文艺巡演，推动十九大精神进乡村、进社区、进校园、进企业、进机关、进军营、进网络，共同营造声势。仙游县巡演不少于6场，荔城区、城厢区、涵江区、秀屿区巡演各不少于4场，湄洲岛、北岸巡演各不少于2场。

　　（二）制定演出蓝本。市文广局立足小制作、小节目、小舞台、小分队，精心策划，打磨形成巡演节目的样式蓝本。各县区（管委会）要参照蓝本，结合各地实际，组织创排演出节目。可以全部演，也可以选中部分节目演，特别是到乡村小戏台、小广场演出，应尽量选取演员人数少的节目。按照属地原则，各县区（管委会）文化部门对新创作的节目进行审查后方可进行演出。各县区（管委会）巡演的台口标、背景板及媒体宣传统一使用：莆田市XX县（区、管委会）“新时代新风采”党的十九大精神宣讲文艺巡演（XXX站）。

　　（三）加大宣传力度。各县区（管委会）应充分利用广播、电视、报纸、微信等新闻媒体加强组织策划，集中报道党的十九大精神宣传巡演活动中的经验和做法，要注重收集、报道广大群众对宣传活动的良好反响，形成良好的舆论氛围。同时，各县区（管委会）的演出，应主动邀请有关领导、社会各界嘉宾和群众代表、新闻媒体等共同参与。

　　（四）强化监督检查。各县区（管委会）要在每月25日前将辖区内组织开展宣讲文艺演出的情况报送市文广局。市文广局将组织调研组，对各县区（管委会）演出情况进行督促检查，既发现好经验好做法，又督促薄弱地区迎头赶上，真正把宣讲文艺巡演任务推进好落实好。
