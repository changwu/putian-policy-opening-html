莆田市文化广电新闻出版局关于开展“两提高一争先”机关效能建设主题活动的通知

发布时间：2018-05-09 11:10
| | |

各县（区）文体广电出版局、湄洲岛社会事务局、北岸工委宣传部，局属各单位，机关各科室：

    为大力弘扬“马上就办、真抓实干”精神，倡导廉洁高效的工作作风，全面提升服务效能，推动文化广电新闻出版事业高质量发展，根据国务院、省市廉政工作会议精神和《2018年莆田市机关效能建设工作要点》（莆效综〔2018〕1号），经研究，决定在局系统开展“提高服务质量、提高工作效率、激励争先创优”（以下简称“两提高一争先”）机关效能建设主题活动。现将有关事项通知如下：

    一、活动对象

    局系统全体干部职工

    二、活动时间

    2018年5月-12月

    三、活动内容

    开展“两提高一争先”主题活动，涉及到局系统工作的方方面面，要抓住关键，以点带面，整体推进，着力抓好以下三个方面的工作：

   （一）提高服务质量，增强群众获得感。以群众最关心、最直接、最现实的利益问题为着力点，切实深化“马上就办、办就办好”，推广“一趟不用跑”和“最多跑一趟”，努力将事情办到群众的心坎上，打通服务群众的“最后一公里”。各科室（单位）要学习借鉴先进经验，对标看齐，对行政审批、许可、服务事项以及部门业务群众投诉等进行自查自纠，并填报《2018年“马上就办、办就办好”优化事项清单》（附件1），于5月11日前送局办公室汇总。

   （二）提高工作效率，建立长效机制。紧扣建设美丽莆田，服务中心工作，坚持目标导向、问题导向、效果导向的有机统一，不断加强内部管理建设，促进依法依规依纪办事，提高工作实绩。各科室（单位）局属各单位要全面梳理局系统2018年承担的重点项目、重大活动，于5月14日前将2018年重点项目（活动）清单（附件2）送办公室汇总。局办公室要牵头对机关内部各项规章制度进行修订汇编，优化办文办事办会工作机制，促进形成全流程、闭环式、精细化管理模式。各科室要全力配合办公室，并于5月底前完成制度修编工作。

   （三）激励争先创优，推动迈上新台阶。坚持正向激励，优化干部过程考核和结果运用考评机制，激励干部多干事、干成事，在工作实践中打造特色和亮点，创出具有牵引性作用的好机制和好做法。局办公室要紧紧围绕年度绩效考评指标，逐一细化分解，明确任务，责任到人，务求有责任、有进度、见实效。局办公室将于6月初印发《2018年度绩效考评指标任务分解表》，各相关责任人要梳理总结往年考评情况，提前谋划、主动作为，优化工作举措，确保多加分、少扣分。

    四、活动要求

   （一）高度重视，精心组织。成立以局长为组长的“两提高一争先”机关效能建设主题活动领导小组，负责组织、协调、督促、指导活动开展，研究制定活动措施，协调解决重要问题。领导小组下设办公室，设在局效能办，负责日常工作。各科室（单位）要把主题活动摆上重要日程，加强领导，落实责任，精心组织，周密部署，形成上下联动、齐抓共管的工作格局。

   （二）注重实效，建章立制。要坚持查、纠、评、建相统一，将查找问题和加强自我建设贯穿于活动全过程。要结合工作职能和文化行业特点，狠抓对外服务窗口建设，切实提高管理和服务水平。要更加注重前瞻，更加注重预防，更加注重制度建设，促使各项工作由解决具体问题向建立预防机制转变，由突击性推动向靠制度保证转变，由外力推动向自觉行动转变，形成“两提高一争先”的长效机制。

　 （三）统筹兼顾，促进发展。要将推进主题活动与服务市委、市政府中心工作结合起来，与推进全局各项工作结合起来，与党建工作结合起来，做到“两不误、两促进”，要保质保序时完成我局2018年承担的各级各类建设项目和文化活动，力争2018年度绩效考评位次实现争先进位，确保“一城两区”（国家历史文化名城、国家级公共文化服务体系示范区和国家级妈祖文化生态保护实验区）创建工作和“美丽莆田·文化繁荣专项行动”取得新成效。

    各县（区）文体广电出版局、湄洲岛社会事务局、北岸工委宣传部要结合实际，参照制定主题活动方案，并将活动开展情况及时报送市局效能办。
