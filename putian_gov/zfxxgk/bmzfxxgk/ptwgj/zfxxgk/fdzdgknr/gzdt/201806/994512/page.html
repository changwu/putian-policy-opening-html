莆田市文化广电新闻出版局关于做好2018年文化志愿服务和创建全国“志愿之城”工作的通知

发布时间：2018-05-18 09:56
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部,局属有关单位： 

　　文化志愿服务是现代公共文化服务体系建设的重要内容，是促进国民素质和社会文明程度提高的有效途径,按照相关要求，现将2018年文化志愿服务和落实创建全国“志愿之城”工作通知如下： 

　　一、活动主题 

　　深入学习贯彻党的十九大精神，以习近平新时代中国特色社会主义思想为指导，结合创建全国“志愿之城”活动，以现代公共文化服务体系建设为支撑，大力弘扬志愿精神，通过系列文化志愿活动，实现文化志愿者、服务项目和服务对象的有效对接，让群众从 

　　文化的旁观者变成参与者、传播者，为建设美丽莆田贡献力量。 

　　二、宣传口号 

　　文化莆田手牵手，志愿服务心连心 

　　志愿服务奉献爱，文化莆田一起来 

　　奉献、友爱、互助、进步 

　　学雷锋，树新风，促和谐 

　　志愿服务是一种生活方式 

　　三、工作重点 

　　围绕全市文化工作重点，结合创建全国“志愿之城”活动，重点开展以下几项工作。 

　　（一）健全文化志愿工作机制。莆田市文化广电新闻出版局负责对全市文化志愿者工作的统筹指导，各县区（管委会）文化行政部门、图书馆、文化馆（站）、博物馆等公共文化服务机构要做好本辖区、本单位文化志愿者的招募、培训及管理，开展文化志愿服务活动。各单位要根据志愿服务的需要，明确志愿服务所需的条件和要求，鼓励和吸引广大群众，尤其是有一定文艺专长的专业人士积极参与文化志愿服务。要完善机制，加强对文化志愿服务者的管理、培训力度，实现志愿服务规范化管理。 

　　（二）组织开展主题志愿活动。要以公共图书馆、文化馆（站）、博物馆、美术馆为平台，广泛开展形式多样、丰富多彩的文化志愿服务活动。 

　　1.开展“文化名城·共享书香”公共图书馆志愿服务活动。 

　　公共图书馆要围绕图书馆业务工作，组织文化志愿者参与图书管 

　　理、讲座培训、阅读分享、读者咨询、流动借阅、“全民阅读”等各项服务，为读者学习知识创造良好环境。 

　　2.开展“群艺手牵手”文化馆（站）志愿服务活动。文化馆（站）要根据群众文化生活需求，组织文化志愿者提供器乐、声乐、舞蹈、美术等文艺技能的免费培训；参加文艺下乡、艺术扶贫、主题展览等各类文艺展示及活动组织；参与非遗展示进农村、进社区、进学校活动和非遗项目培训；参与基层群文干部和各类艺术人才培训；参与群文理论课题的研究，促进文化传承等各类服务，推广普及文化艺术。 

　　3.开展“弘扬传统文化·共建美丽莆田”博物馆志愿服务活动。博物馆要组织文化志愿者担任讲解员、参与展览布置、协助做好文物档案整理、参与文创产品开发、开展文物知识普及、课题研究等活动。推进馆校共建志愿服务活动，使市博物馆成为青少年学习地方历史、科学文化知识的实践基地。 

　　（三）积极拓展服务范围。要立足实际、聚焦群众需求，不断拓展志愿服务领域，扩大文化志愿服务覆盖面。 

　　1.积极组织文化志愿者协助做好“文化惠民、周周有戏”莆仙戏公益性低票价演出、“2131农村电影放映”、基层综合文化服务中心建设等重大文化惠民工程的技术支持、政策宣传、资源整理等，进一步提升建设水平，促进共建共享，活跃城乡基层文化生活。 

　　2.针对空巢老人、留守儿童、农民工和残疾人等特殊群体定期开展文艺演出、文化辅导、电影放映、 送戏下乡等文化志愿服务活动，让困难群众得到及时的关爱，大力弘扬中华民族尊老爱老、 

　　扶危济困、助人为乐的传统美德，促进社会和谐，维护社会稳定。 

　　3.鼓励公共文化设施与大中学校结对子，成为大中学生课外活动和社会实践基地，设计适合学生年龄特点的文化志愿服务项目。积极探索“互联网＋志愿服务”，安全合规利用信息技术手段，助推志愿服务专业化、特色化和精准化。 

　　（四）注重培育文化志愿品牌。要按照“推优树典、示范引领”的工作思路，着力搭建平台，培育文化志愿服务品牌项目、骨干队伍。各县区（管委会）、市群众艺术馆、市博物馆、市图书馆至少要各培育1个文化志愿者品牌项目，要通过拍摄宣传片、微信推广、网站宣传等形式加大文化志愿服务宣传，不断扩大影响力，扩大品牌项目影响力。 

　　（五）助力全国“志愿之城”创建。要贯彻落实好《关于印发莆田市创建全国“志愿之城”工作方案的通知》（莆文明委〔2018〕5号）文件精神，对照《2018年度莆田市创建全国“志愿之城”任务分解表（涉及文广局部分）》（附件1）进一步集中梳理，逐条细化，逐项分解，明确具体部门和人员，层层抓好落实，确保目标任务按期完成。局属有关单位要认真填报《2018年年度莆田市创建全国“志愿之城”月报表》，每月25日前将落实情况报送社文科汇总，联系人：林益清，联系电话：2689939，邮箱：pt2696660@163.com。 

　　四、工作要求 

　　（一）强化组织领导。开展文化志愿服务是构建现代公共文 

　　化服务体系、创建全国“志愿之城”的重要内容。请各县区（管 

　　委会）文化行政部门、市文广局局属各单位要把开展文化志愿服务工作提上重要议事日程，纳入年度工作计划，切实加强组织指导和统筹推动，确保顺利实施，取得实效。同时，要做好年度文化志愿者总结工作，于2018年12月5日前将相关情况报送市文广局社文科。   

　　（二）加大宣传力度。各单位要同步策划宣传方案，及时总结经验，充分发挥典型引导作用，采取各种宣传方式展示文化志愿服务成果，弘扬文化志愿服务“奉献、友爱、互助、进步”的精神。 

　　（三）加强保障工作。各单位要为文化志愿服务工作提供必要的资金支持，做好上岗培训和定期业务培训，为文化志愿服务提供必要的交通、安全、卫生等工作条件，提高文化志愿者参与活动的积极性。
