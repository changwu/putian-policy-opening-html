莆田市文化和旅游局关于举办“赓续文脉绘山海”——第六届莆田市“读中华经典 颂时代华章”诵读比赛活动的通知

发布时间：2024-05-24 11:27
| | |

　　

各县区文化体育和旅游局、湄洲岛旅游和文化体育局、北岸党工委宣传部，市图书馆:

为进一步推进我市公共文化服务体系建设，经研究，定于2024年5月至7月举办“赓续文脉绘山海”——第六届莆田市“读中华经典 颂时代华章”诵读比赛活动。现将有关事项通知如下：            

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入学习宣传贯彻习近平文化思想，全面落实《中华人民共和国公共文化服务保障法》《中华人民共和国公共图书馆法》，围绕庆祝中华人民共和国成立75周年，打响“妈祖故里 灵秀莆田”文旅品牌，做好文化保护、传承、传播和发展“四篇文章”，促进全民阅读，打造书香莆田，引导广大人民群众在经典诵读中，传承中华优秀传统文化，担当时代责任，为福建打造世界知名旅游目的地谱写更加出彩的莆田篇章。

二、活动主题

赓续文脉绘山海

三、组织机构

主办单位：莆田市文化和旅游局

承办单位：莆田市图书馆，福建省图书馆学会莆田学组

协办单位：各县区文化体育和旅游局、湄洲岛旅游和文化体育局、北岸党工委宣传部，莆田市朗诵协会

支持单位: 莆田市出版物发行业协会

四、赛事安排

本次比赛分少年组、成人组两个组别，通过初赛、复赛、决赛三个阶段进行。

(一)初赛

1.时间节点：6月14日前完成

2.责任主体：各县区（管委会）、市图书馆

3.工作内容：

（1）作品征集。各县区（管委会）、市图书馆加大宣传力度，可通过线上、线下报名渠道，对照《“赓续文脉绘山海”——第六届福建省“读中华经典 颂时代华章”参赛作品要求》（附件1），广泛征集作品。

（2）作品选拔。本届赛事搭建统一的音频作品报名通道，电脑端：https://wx.bookan.com.cn/dz/fujian_2024/index.html，手机端征集作品：https://miniapp.bookan.com.cn/?id=32947。选手也可以直接以视频作品的形式发送邮箱报名，各县区文旅局、市图书馆依托报名通道及工作邮箱开展初赛报名，并以线下现场选拔或线上视频评审等形式开展初赛选拔工作，择优选报诵读作品参加市级决赛。

各县区、市图书馆可推荐少年组、成人组作品各5个以上入围市决赛；各管委会选报少年组、成人组作品各3个以上入围市决赛。请各县区文旅局牵头汇总报送，本次赛事不接受个人报送，视频文件以“选送单位（市直/县区）+参赛组别+作品名称”的形式命名。评分标准可参考《“赓续文脉绘山海”——第六届福建省“读中华经典 颂时代华章”诵读比赛评分标准》（附件2）。

（3）材料报送。6月15日前将入围复赛作品及《复赛作品信息表》《活动组织情况表》《选手个人承诺书》（附件4、5、6）盖章扫描电子版报送至莆田市图书馆(ptxj2018@163.com)。作品手机或摄像机拍摄均可，画面清晰、稳定，对焦准确；声音清晰，无明显噪音、杂音。

(二)复赛

1.时间节点：6月20日前完成

2.责任主体：莆田市图书馆

3.工作内容：莆田市图书馆以线上录像评审的形式开展莆田赛区复赛，从全市少年组、成人组的参赛作品中分别评选出不多于20个作品入围莆田赛区决赛。

(三)决赛

1.时间节点：初定6月23日

2.责任主体：莆田市图书馆

3.决赛地点：莆田市青少年宫梦想剧场

4.具体内容：

（1）作品评选。由市图书馆采取线下评审的方式，对各县区（管委会）报送作品、市图书馆征集到的作品进行筛选，从少年组、成年组分别选拔5个作品入围福建省复赛。

（2）奖项设置。少儿组和成人组分别设置一等奖1名，二等奖2名，三等奖3名，优秀奖若干。市级获奖名单经主办单位同意向社会公示。

五、工作要求

（一）有序推进落实。各县区（管委会）要明确责任，指定专人负责，把握时间节点，做好诵读赛事的准备工作。一切有关赛事的宣传以及参赛作品内容均需严格的审核把关，确保政治立场正确、贴合赛事主题。《联络员名单回执》（附件3）于5月25日前报送市图书馆邮箱。市图书馆作为此次活动的承办单位，要做好整个活动的筹备工作，统筹协调赛事的具体时间及赛程。

（二）加大宣传力度。一是使用统一宣传主视觉。本次活动的宣传主视觉由福建省主办方统一设计，各县区（管委会）、市图书馆制作活动宣传物料时应使用主办方主视觉。二是做好赛事宣传引流。活动期间，以赛事各阶段为节点，开展“我在八闽大地上朗读——短视频展示活动”，短视频内容主要是：对赛事台前幕后组织工作的视频宣传、参赛选手优秀作品或日常优秀诵读作品等均可。市图书馆应在官方平台搭建本届及往届赛事成果展示专区，重点包装推送优秀获奖作品和“我在八闽大地上朗读——短视频展示活动”征集到的优质短视频。各县区（管委会）应注重收集整理活动影像资料并及时反馈至市图书馆。三是面向社会多平台、多载体宣传。按照各个阶段的宣传工作安排，广泛发动受众群体参与赛事活动，联动各级主流媒体平台，通过微信、微博、抖音等新媒体渠道全方位开展宣传推广工作。

（三）活动成果拓展。市文旅局酌情将获奖选手列入莆田市文旅推荐官队伍，并优先赋予参加研学、夏（冬）令营、讲座培训等活动资格。成年组省级获奖选手将纳入福建省图书馆“读者朗诵团”，并获得风采展示机会，适时邀请播音主持专家提升团队成员朗诵水平及节目质量，按照选手个人意愿优先选送参加其他系统或更高级别的诵读赛事活动。少年组省级获奖选手将会优先被福建省少年儿童图书馆纳入省文旅厅十佳“小小文旅推荐官”参评对象，参与省级各大文旅活动的展示展演环节。

联系人：市文旅局公共服务科林益清，联系电话：2689939，市图书馆王星、林琦萍，联系电话：13959569809、13959509019，邮箱：ptxj2018@163.com，地址：莆田市荔城区玉湖路1969号

附件1

“赓续文脉绘山海”——第六届福建省

“读中华经典 颂时代华章”参赛作品要求

 

一、参赛作品要求

（一）在内容上，应突出活动主题，围绕贯彻落实习近平文化思想、庆祝中华人民共和国成立75周年、传承弘扬中华优秀传统文化、打造世界知名旅游目的地，打响“妈祖故里 灵秀莆田”文旅品牌，做好文化保护、传承、传播和发展“四篇文章”及莆田特色文化等重点内容，为福建打造世界知名旅游目的地谱写更加出彩的莆田篇章。

各县区（管委会）、市图书馆要加强参赛作品内容意识形态审核工作，确保参赛作品弘扬主旋律、传播正能量，符合社会主义核心价值观。

（2）在数量上，每位选手（含团体形式）限参加1个赛区比赛、限报1个作品，且比赛期间不得更换作品。

（3）在时长上，每个参赛作品控制在3～5分钟。

（4）在版权上，参赛作品不得涉及侵权行为，严禁他人代录。若违反上述规定，取消参赛资格。若因此造成损失，由参赛者自行承担。主办方拥有对参赛作品进行展示、报道、宣传和整理出版的权利。

（五）在表现上，建议配以音乐或视频等其他富有创意的形式，并切合作品内容、朗诵所需、表演意境。

（六）在形式上，参加市复赛作品需录制视频，手机或摄像机拍摄均可，画面清晰、稳定，对焦准确；声音清晰，无明显噪音、杂音。视频文件以“选送单位（市直/县区）+参赛组别+作品名称”的形式命名。

二、参赛人员要求

（一）在身份上，参赛人员应为社会大众中的诵读业余爱好者，不包含播音、主持、朗诵等专业的在校师生及从业人员。

（二）在年龄上，少年组参赛年龄须在18周岁以下（在2006年4月23日（含）以后出生），成年组参赛年龄须在18周岁以上（在2006年4月22日（含）以前出生）。

（三）在人数上，每个参赛作品的选手人数不得超过8人。比赛按参赛作品评奖，团队参赛计1个作品。
