莆田市文化和旅游局关于全市A级旅游景区对志愿者和“好人”实行免费参观游览的通知

发布时间：2020-03-02 11:58
| | |

各县区文化体育和旅游局、湄洲岛旅游局、北岸文旅办：

根据《关于印发〈莆田市志愿者嘉许与回馈制度〉（修订稿）的通知》（莆文明委〔2020〕1号）和《关于印发〈莆田市礼遇帮扶好人实施办法〉的通知》（莆文明委〔2020〕5号）精神，现将全市A级旅游景区对志愿者和“好人”实行免费参观游览相关事项通知如下：

一、免费对象

（一）凡在莆田市文明实践“I志愿”APP（小程序）注册成功每年服务满200小时的志愿者，当年度评上“三星级及以上志愿者”；

（二）历届市级以上道德模范和道德模范提名奖获得者，全国、全省身边好人和新时代莆田“新人 新事 新风”代表等被市委文明办认定的“好人”。

二、免费方式

（一）“三星级及以上志愿者”凭市志愿服务中心认证证明，服务满200小时以上的志愿者凭市委文明办有效证明到市旅游协会领取全市A级旅游景区免费套票（见附件，年度编号暂编2020001－2020300，有效期一年，加盖市旅游协会公章），各景区凭套票予以免费；

（二）“好人”凭市委文明办颁发的礼遇卡和个人有效身份证，各景区予以免费。

三、有关要求

（一）志愿者和“好人”为社会作出了突出贡献，景区实行免费游览，充分体现了对志愿者和“好人”的尊敬和关爱，进一步树立“好人好报”、德行天下的价值导向，推进新时代公民道德建设。各A级旅游景区要积极支持礼遇帮扶志愿者和好人，带头倡导社会文明风尚，促进文明实践志愿服务持续健康发展。

（二）各县区（管委会）文旅部门要检查督促各A级旅游景区落实对志愿者和“好人”礼遇帮扶政策，并于2020年12月20日前将政策落实情况报市旅游协会并抄送市局。

（三）各A级旅游景区在落实志愿者和“好人”礼遇帮扶过程中遇到的实际问题，及时报告市旅游协会或市局协调解决。

附：全市A级旅游景区免费套票（模板）
