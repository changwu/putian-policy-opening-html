莆田市文化广电新闻出版局关于印发档案管理八项制度的通知

发布时间：2014-12-10 08:00
| | |

机关各科室、局属各单位：

为加强档案管理工作，提高档案管理水平。现将《文件材料归档制度》等八项制度印发给你们，请遵照执行。

 

 

莆田市文化广电新闻出版局

2014年12月10日

 

 

 

 

文件材料归档制度

 

1.档案中的文件材料应按其自然形成规律整理，保持其历史联系，正确反映本单位各项工作活动。

2.档案案卷标题，要写明反映卷内内容。

3.在拟稿时要根据“文件档案”保管期限栏内的规定，注明每一件的保管期限。

4.具有永久和长期保存价值卷内文件要逐卷编号，填写“卷内目录”，并根据需要附上“备考表”。

5.归档的案卷应附有“案卷目录”一同归档，档案人员要依据目录接收。

6.文书档案应在次年的第一季度向档案室移交清楚；科技档案应在每一项工程竣工一并移交档案室；财会档案在财务部门保留1—3年后移交。

 

 

 

 

 

 

 

档案保管制度

 

1.严格执行档案收集、整理、保管、鉴定、提供利用与销毁等有关制度和规定，确保其完整、系统和安全。

2.档案按档号排放，档案柜编顺序号，档案库房内悬挂相关档案管理规章和制度。

3.借出的档案须按时归还，利用后的档案应随即放回原处。

4.不得窃取、出卖和涂改档案，违者追究法律责任。

5.切实做好防火、防虫、防潮、防尘、防高温、防盗、防光、防鼠工作。

6.做好库房温湿度的监控与登记工作。

7.每年年初对库房档案进行全面检查、清点，发现问题及时处理。

 

 

 

 

 

 

 

 

 

 

档案室管理制度

 

    1.档案室由专门人员负责管理，管理人员应忠于职守，做好各项工作。管理人员工作调动时要办理移交手续。

2.加强档案室的保卫工作。非本单位人员未经许可不得进档案室。管理人员在离开库房时要关好窗，锁上门，防止失泄密事故。

3.落实档案的防火措施。库房内严禁吸烟、明火，不准把易燃、易爆物品带入档案室，做到人离电关，定期检查电路及防火设施，确保档案安全。

4.做好档案的防高温、防潮湿工作。坚持每天观察和记录库房温湿度，注意开窗通风，降温去湿，力求把档案室温度控制在14—24C，相对湿度控制在45—60%。

5.注意档案的防虫霉工作。每个档案柜都要放置防虫霉药物，并定期翻动档案，每年全面检查一次，发现虫霉时要采取灭虫去霉措施。新接收进档案室的档案，经消毒，除尘后方能入库。

6.保持档案室整洁，每月对箱橱、门窗、地板全面地擦拭一次。

7.坚持档案进出库房的登记制度，对调出档案做到当天归还进库，放回原位（特殊情况除外）；在档案资料调出的同时，应放有代理卡，清点，归还后即取出代理卡。

8.库房管理人员要遵守借阅和保密规定，不得私自借出档案和携带档案外出；不得擅自销毁任何档案；发现问题及时报告处理。

 

档案保密制度

 

1.高度认识档案保密工作的重要性，严格遵守有关法规和制度。

2.查阅涉密档案或内部材料，须经本单位办公室负责人批准，必要时报请有关校领导审批。查阅时须严格履行登记手续，注明查阅目的和内容。

3.未经批准，任何人不得私自带档案出档案室；档案工作人员不得私自摘抄、复制、传播具有保密性质的档案内容。

4.因需要经批准摘录或复制涉密档案材料的，须妥善保管，用后销毁，如发生涉密问题，后果由利用者负责。

5.不归档的重份文件及内部材料，须交由档案室集中销毁。

6.档案室工作人员如有违反保密规定的，视情节轻重按有关规定处理。

 

 

 

 

 

 

 

 

 

档案借阅制度

 

1.查阅利用档案室档案、资料者，须填写查阅登记表，经本单位办公室负责人审批同意后方可查阅。

2.查阅重要的或密级档案，按《档案保密制度》办理。

3.档案、资料一般不外借。确因工作需要外借的，须经办公室负责人批准，并办理外借手续（限5天内归还）；若续借，需办续借手续。

4.查阅利用档案时不得随意涂改、拆卷或损毁。档案室工作人员对违规者，有权给予劝告、责令赔偿或其它处置，直至追究法律责任。　

5.未经本单位领导批准或办公室授权，任何单位、个人无权公布档案内容。

 

 

 

 

 

 

 

 

 

 

档案鉴定与销毁制度

 

1.根据《文书档案保管期限表》规定，对到期的短期档案进行鉴定，确定档案文件的存毁。

2.鉴定工作的组织，应成立以本单位领导和有关部门负责人，档案保管人员参加的鉴定小组，确保鉴定工作的质量。

3.采取直接鉴定法对档案进行鉴定，每次鉴定要写出鉴定报告，填写档案鉴定情况记录表和档案销毁清册，由本单位领导签名，并注明鉴定日期。

4.对无需继续保存的档案，经过鉴定后，报经档案主管部门批准后，方能销毁，未经鉴定和批准，不得销毁任何档案。

5.销毁档案必须严格掌握，慎重行事，销毁前要造具清册，提出销毁报告。

6.销毁档案时要严格执行保密规定，应有两人以上监销人员。监销者应在档案销毁清册上签字，注明销毁灭的方式和日期，若销毁的档案数量多，应送当地造纸厂当场化为纸浆，严防泄密。

 

 

 

 

 

 

 

档案工作考核制度

 

1.按规定需要保管、移交的资料，做到齐全、完整、整洁、规范。

2.本单位每年组织的大型活动、召开的重要会议所形成的各种文件和材料，要及时做好汇总并移交档案管理人员。

3.各职能科室要配合本单位办公室共同做好档案工作，参加档案工作的检查、考核、认真做好各种档案资料的收集、整理。

4.档案工作考核由局办公室组织相关人员进行，时间一般为每年12月，考核结果与年度目标考核挂钩。

5.档案工作考核设置优秀、合格、不合格三个档次。档案材料整理规范、及时录入电子文档，在次年4月份以前归档的为优秀，在次年4月份以后6月份以前归档的为合格，没有配备档案员、次年6月份以后仍未及时归档以及发生损毁、丢失、泄密的直接确定为不合格。

 

 

 

 

 

 

 

 

档案人员岗位职责

 

1.认真学习、贯彻执行档案工作的法律、法规和各项方针政策、规章制度，增强档案意识。

2.自觉遵守党和国家保密制度和工作人员保密守则，做好文件材料的保密工作。

3.积极参加档案业务的学习，虚心接受档案部门的业务指导和督促检查，不断提高档案工作水平。

4.负责本单位及与本单位工作密切相关的不同载体、不同形式的文件材料的形成、积累、保管和整理立卷归档工作，确保归档材料的完整、准确、系统。

5.根据本单位工作的职能及不同种类文件材料形成的特点，将归档材料合理分类存放，便于利用和立卷归档。

6.归档案卷必须做到组卷合理、编写页号准确，编目填写清楚工整，案卷标题简明扼要、表述准确，保管期限划分科学、合理, 装订整齐、美观。

7.认真做好档案的防火、防虫、防潮、防尘、防高温、防盗、防光、防鼠等工作。
