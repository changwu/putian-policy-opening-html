莆田市文化广电新闻出版局关于印发开展全市影剧院、文化场所消防安全大检查实施方案的通知

发布时间：2010-12-08 08:00
| | |

各县区（管委会）文体局（社会事务办、文教局），市直属各单位、机关各科室：

为进一步加强和改善文化单位消防安全生产工作，根据省文化厅、省公安消防总队《关于开展对全省剧院、文化场所消防安全大检查的通知》（闽文办〔2010〕68号）精神，切实开展全市影剧院、文化场所消防安全专项检查，现将《关于开展全市影剧院、文化场所消防安全大检查实施方案》印发给你们，请结合本单位实际，认真抓好落实。

 

 

二○一○年十二月八日 

 

关于开展全市影剧院、文化场所消防安全

大检查的实施方案

 

为贯彻落实省文化厅、省公安消防总队《关于开展对全省剧院、文化场所消防安全大检查的通知》（闽文办〔2010〕68号）精神，结合正在开展火灾隐患排查整治专项行动的工作，特制定莆田市文化广电新闻出版局《关于开展全市影剧院、文化场所消防安全大检查实施方案》。

一、总体要求

通过全面、深入、细致的检查，进一步落实消防安全工作的组织领导、岗位职责、管理制度和保障措施，严格执行社会单位消防安全“四个能力”建设，认真解决消防安全管理上存在的突出问题和薄弱环节，有效防范和坚决遏制事故的发生。

二、检查范围

全市各级影剧院和各级文化场所（艺术馆、图书馆、博物馆、文化馆、文化站等）。

三、重点内容

（一）消防安全工作的组织领导和岗位职责情况

1、是否建立健全消防安全管理机构，明确消防安全责任人，落实消防安全管理人；

2、是否建立专职或兼职消防队伍；

3、是否明确岗位职责。层层落实消防安全责任制，签订责任书。

（二）消防安全管理制度、消防安全档案建立情况

1、是否建立下列消防安全管理制度：消防安全教育、培训；防火巡查、检查；消防（控制室）值班；消防设施、器材维护；火灾隐患整改；用火、用电安全管理；专职和兼职消防队伍的管理；灭火和应急疏散预案演练；燃气和电气设备的检查和管理（包括防雷、防静电）；消防安全工作考评和奖惩等。

2、是否按规定建立消防档案，消防档案是否完整、规范。

（三）消防设施设备及其使用情况

1、是否按相关要求设置消防设施、器材和消防安全标志是否保持齐全、完好有效；

2、消防水源、消火栓等设施建设和使用情况；

3、是否设立必要的消防通道；

4、消防控制室值班和设施运行情况；

5、职工对消防知识的掌握，对消防设施、设备、器材的操作使用情况。

（四）消防安全预案的制定和演练情况

1、灭火和应急疏散预案是否科学、有效，具有可操作性；

2、是否定期组织消防演练。

（五）消防安全检查和火灾隐患整改情况

1、日常防火巡查、定期防火检查和抽查情况；

2、对火灾隐患是否立即整改，不能立即整改的是否采取了有效措施，限期整改。

四、方法步骤

采取单位自查自改、文化与消防联合检查和迎接省文化厅重点抽查的方式进行。

（一）自查自改阶段（2010年11月20日至2010年11月30日）

各有关单位要按照检查内容，对每一项消防措施落实情况等进行全面彻底的自查自改。

（二）联合检查阶段（2010年12月1日至2010年12月31日）

市文化广电新闻出版局与公安消防部门联合组成文化单位消防安全检查组，对本市文化单位实施联合检查。并对影剧院、文化场所火灾隐患和消防安全管理存在的重大问题向市政府报告或通报，并作为文化消防安全隐患整改重点督办单位进行跟踪督办。同时，迎接省文化厅和省公安消防总队的抽查。

（三）汇总上报（2011年1月上旬）

各县区、各所属单位对本部门、本单位的消防安全检查工作情况进行汇总分析，形成检查报告，上报市局办公室。

四、工作要求

（一）加强领导，迅速行动。

各级各有关单位要充分认识开展消防安全工作的重要性，切实抓紧、抓实、抓好。各级各部门行政负责人要亲自部署，立即行动，有效组织。

（二）即查即改，落实责任。

要坚持边检查边整改，以检查促整改。对检查发现的问题场所和单位，要制定切实可行的整改措施，指定专人负责，限期整改、跟踪落实，彻底消除事故隐患。
