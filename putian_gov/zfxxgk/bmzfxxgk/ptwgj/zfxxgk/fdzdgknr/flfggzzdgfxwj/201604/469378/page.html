莆田市文化广电新闻出版局关于印发考勤等七项工作制度的通知

发布时间：2016-04-27 08:00
| | |

机关各科室、局属各单位：

为进一步加强机关效能建设，建立行为规范、运转有序、公开透明、勤政务实、廉洁高效的工作机制，经研究，重新修订了《莆田市文化广电新闻出版局考勤制度》等七项工作制度，现印发你们，请认真抓好贯彻落实。

 

 

                        莆田市文化广电新闻出版局

                       2016年4月27日    

 

莆田市文化广电新闻出版局考勤制度

 

为进一步规范工作纪律，提高工作效率，根据有关规定，结合我局实际，特制定本制度。

1. 局机关、局属各单位均实行指纹考勤上下班。

2. 按照规定时间，准时上下班。每天考勤4次，上班签到截止时间为规定上班时间顺延15分钟，下班签退开始时间为规定下班时间前15分钟。每月考勤情况由各单位办公室负责统计汇总，作为年度考核依据之一。

3. 上班时间必须遵守工作制度，不得无故离岗或在岗办私事，不得上网（电话）聊天、炒股、看影视片、玩游戏、浏览不健康网站、窜岗、闲聊等。

4. 工作人员因工作需要双休日、节假日调整上班、加班的，由各单位统筹调度，按照“加一补一”的原则，予以安排调休、补休。双休日、节假日上班、加班人员纳入单位统一指纹考勤。

5. 所有机关、企事业单位工作人员均应轮流参加节假日值班，坚守岗位，履行职责，及时处理突发事项，如遇特殊情况，在职权范围内无法处置的，按规定及时向带班领导报告。

6. 局机关及局属单位办公室设立专用的《因公外出、下乡登记本》，工作人员因公外出均应在《登记本》中登记，并告知办公室负责人。登记事项将作为查岗及下乡补贴报销的依据。

 

 

 

莆田市文化广电新闻出版局请休假制度

 

为进一步规范工作纪律，提高工作效率，根据有关规定，结合我局实际，特制定本制度。

    一、工作人员请假需办理书面请假手续，经批准并与相关人员衔接工作后方能离岗，请假期间保持通讯畅通。假满后及时销假。

二、工作人员假别：

1. 法定年休假：按相关政策规定执行，由各单位根据工作需要统筹安排，按国家规定享受寒暑假的单位不安排年休假。符合休假条件的工作人员在休假期间工资照发，福利待遇不受影响。

2. 事假：年累计请事假不超过8天，超过8天的根据《关于机关事业单位工作人员事假及事假期间待遇等有关问题的通知》（闽人发〔2009〕284号）文件规定，从第9个工作日起，其基本工资、省规定的津贴补贴或绩效工资按日减发。其日减发计算方式为：每月列入工资基金管理的扣除改革性补贴外的应发工资总额除以21.7天。

3. 病假：请病假须提供县级以上医院相关疾病证明。

4. 婚假、产假、探亲假、丧假等：按国家有关规定执行。

病事假应先用年休假抵扣，全数抵扣后再按规定扣减工资、奖金待遇。

三、审批程序：

    1. 局长请假按市委、市政府规定报批；其他处级领导请假报局长审批。

2. 机关科室及局属企事业单位的负责人请假1天以内由分管领导审批，并报局长；请假1天以上的由分管领导签署意见后报局长审批。

3. 机关一般干部及局属企事业单位副职人员请假3天以内（含3天）的由科室（单位）负责人签署意见后报局分管领导审批，并报告局长；请假3天以上的报局分管领导签署意见后报局长审批。

4. 局属事业单位一般工作人员请假3天以内（含3天）由单位负责人审批，3天以上由单位负责人签署意见后报局分管领导审批，超过8天的需报局长审批。

5. 局属企业单位一般工作人员请假由各单位负责人审批。超过8天需报局分管领导审批。

四、经审批后的请假条交由各单位办公室留存。凡不履行请假手续的，未经批准擅自离岗或超假的，一律按相关规定处理。特殊情况需请假或延长假期，应事先电话向相关人员报告，事后按规定补办手续。

莆田市文化广电新闻出版局

出差审批报销制度

 

为加强和规范差旅费管理，推进厉行节约反对浪费，根据市财政局《关于印发〈莆田市市直机关差旅费管理办法〉的通知》（莆市财行〔2014〕69号）和市财政局《关于调整市直机关差旅住宿费标准等有关问题的通知》（莆财行〔2016〕1号）文件精神，结合实际，制定本制度。

一、出差审批

局机关及企事业单位所有工作人员因公出差的均需履行审批手续，否则不予报销任何相关费用。

（一）市外出差审批：工作人员出差有上级部门相关通知文件的，以单位领导批示意见为准；没有相关通知文件的，机关工作人员及企事业单位正、副职人员填写《出差审批单》报局长审批，企事业单位一般工作人员填写《出差审批单》报单位负责人审批。

（二）市内出差审批：机关及企事业单位工作人员因公市内出差下乡的，在《因公外出、下乡登记本》中填写注明，并告知本单位办公室负责人。

（三）局领导出差按照市委、市政府规定办理审批手续。

二、差旅费报销

（一）报销标准

1. 城市间交通费。出差人员按规定等级乘坐火车、轮船、飞机等交通工具（出租小汽车除外），到出差目的地有多种交通工具可选择时，在不影响公务、确保安全的前提下，应当选乘经济便捷的交通工具并凭据报销。

2. 住宿费。工作人员到国内相关地区出差发生的住宿费在市财政局规定的对应职级限额标准以内报销。取消处级以下人员两人住一个标准间的限制。

3. 伙食补助费

省内市外出差按出差自然（日历）天数计算，每人每天100元包干使用。

省外出差按照出差自然（日历）天数计算，按财政部发布的相关地区出差伙食补助费标准执行。

出差人员应当自行用餐。凡由接待单位统一安排用餐的，不得报销伙食补助费。

工作人员因出差到市内除荔城区、城厢区辖区内各街道办事处以外的地点，每人每天补助伙食费30元。

4. 市内交通费

在国内市外出差的，市内交通费按出差自然(日历)天数计算，每人每天80元包干使用。

在莆田市内出差的，按实际发生的除出租小汽车以外的交通工具凭据报销。

出差人员由所在单位提供交通工具的，不再报销市内交通费。所在单位提供的交通工具当天回去的，必须提供派车单才可以报销出差期间市内交通费。

驾驶员不得报销市内交通费。

（二）报销规定

1. 工作人员出差结束后应当及时办理报销手续。差旅费报销时应当提供相关通知文件或《出差审批单》、机票、车票、住宿费发票，驾驶员需提供《行车情况登记表》和《派车单》等凭证。

2. 财务部门应当严格按规定审核差旅费开支，对未经批准出差以及超范围、超标准开支的费用不予报销。未按规定开支差旅费的，超支部分由个人自理。实际发生住宿而无住宿费发票的，不得报销住宿费以及城市间交通费、伙食补助费和市内交通费。

3. 机关工作人员因公市内出差差旅费报销报局分管领导审核。

4. 各类旅行社开具的发票不得作为公务出差的报销凭据。

5. 工作人员外出参加会议、培训，举办单位统一安排食宿的，会议、培训期间的食宿费和市内交通费由会议、培训举办单位按规定统一开支；往返会议、培训地点的差旅费（头尾两天）由所在单位按照规定报销。

6. 企业单位可参照执行或在限额标准内制定本单位差旅费管理办法。

莆田市文化广电新闻出版局财务管理制度

 

为加强财务管理，严肃财经纪律，保证资金的规范使用，根据有关政策和规定，结合实际，制定本制度。

1. 经费使用坚持“量入为出、厉行节约”原则，合理使用资金，严格控制费用开支，严格按规定办事，严格按程序审批。

2. 经费开支实行局长“一支笔”审批制度，所有公务费用开支，必须由局长签批。重大财务开支的审批由局领导班子会议讨论决定。

3. 行政事业性收费、罚没款、预算外收入，严格按照有关部门规定的标准执行，实行票款分离，款项上缴国库或财政专户，执行“收支两条线”管理。

4. 科室不得自行收费,不得私设小金库，所有按规定要求的代办项目收费由局财务统一收取，各主办科室需要收取代办费，必须与局财务做好成本核算、支出核算，局长批准后才能进行。

5. 对不真实、不合法或报销手续不完整的报销凭证，财务有权拒绝办理报销或按有关规定予以纠正。

6. 凡开具和取得的发票，必须按发票管理规定的品名、单位、数量、金额及内容等据实填写，字迹要清楚，不得涂改、挖补；凡从外单位取得的发票及原始凭证，必须盖有填制单位财务印章或发票专用章；自制零星费用开支原始凭证必须由领款人、经办人、证明人和单位负责人签字，禁止白条报支有关费用。

7. 费用报销时，应按规定附上有关审批单和费用结算清单。发票必须由经办人、证明人、审核人及领导签字。

    8. 工作人员因公务需要借用公款时，应由借款人按规定填制三联式借款单（参考格式附后），由局长审批后，财务部门方可办理借款手续。公务结束后应及时办理借款核销手续，公务结束后三个月内未办理借款核销手续的按挪用公款论处。单位工作人员因公借款凭据必须附在记账凭证后，收回借款时应当另开收据或退还借款凭据副本，不得退还原借款单。

9. 物资采购属于固定资产范围的要办理固定资产登记手续，属于政府采购的物品必须实行政府采购。实物购入后，要按照规定办理验收手续。

10. 各科室召开各种会议应事先编制《会议费预算表》（格式附后），经分管领导审核后，报局长审批。报销会议费支出应附会议通知文件、参加人员签到单、会议费预算审批表、会议费结算清单和会议费的发票，凡超出审批标准的会议费，超出部分不得报销。培训费报销参照执行。

11. 修缮项目的管理必须按有关规定执行。所有修缮项目（包括零星修缮费）应编制预算，按照有关规定确定施工方，并签订施工合同。工程进度款的支付，必须凭合法正式的原始凭证。

12. 工作人员调动或退休时应及时办理资产移、交接手续，否则，有关部门不予办理调动或退休手续。

13. 单位领导要模范遵守财经纪律，支持财会人员依法履行职责。单位财会人员要认真履行职责，对费用原始凭证进行逐一审核，对不符合规定的报销凭证或附件不全的不予报销。

14. 其他未尽事项按照国家有关法规以及财经纪律和财务制度办理。

莆田市文化广电新闻出版局公务接待制度

 

为贯彻落实中央八项规定和反对“四风”的要求，厉行勤俭节约、反对铺张浪费，加强公务接待管理，结合我局实际，制定本制度。

1. 公务接待实行办公室归口管理与部门对口接待相结合的原则。接待对象限于有业务往来的单位，且必须持有派出单位开具的公函，无公函的公务活动和来访人员一律不予接待。接待中需要市领导陪餐的，按规定报告市政府接待处统筹安排。

2. 公务接待前主办科室应严格按照规定的标准填写公务接待审批单、经办公室审核、局长审批后，办公室专人协助主办科室安排接待，接待后主办科室按规定报销。

3. 住宿应安排在来宾住宿限额标准以内的酒店。住宿费由客人自行结算回原单位报销。

4. 用餐标准按照有关规定执行，厅级、处级、一般来宾的接待分别按照100元/人、80元/人、70元/人予以安排。菜单实行标准化安排，每种标准固定3-5种供选择菜单，菜品以家常菜为主，突出本地特色，原则上不安排烟酒、鲜榨果汁。

5. 确因工作需要，接待单位可以安排工作餐一次，并严格控制陪餐人数。接待对象在10人以内的，陪餐人员不得超过3人；超过10人的，陪餐人数不得超过接待对象人数的三分之一。用餐地点可就近安排在定点经济型酒店。

6. 公务接待审批实行“一批一单一结算”的办法，接待结束后，主办科室人员凭接待公函、接待审批单、发票、菜单经财务人员审核后报局长审批。

7. 局属企事业单位参照执行。

莆田市文化广电新闻出版局学习制度

 

为加强学习型机关建设，进一步提高干部职工的政治思想素质和业务管理素质，特制定本制度。

1. 全体工作人员应加强政治、业务学习，努力提高政治思想和业务政策水平。

2. 实行每周一下午集中学习制度，学习时间不少于2小时，提倡干部职工8小时之外自学。

3. 局集中学习由一位局领导牵头，局办公室根据上级要求，结合形势、任务，联系思想和工作实际，组织政治、理论及业务学习，做到计划、时间、内容、人员四落实。

4. 集中学习原则要求全体人员参加，实行学习签到，确因公、因私（病）不能参加学习的，必须事先向带班领导履行请假手续；凡未经准假不参加学习者视为无故缺席。对无故缺席者，由分管领导对其诫勉谈话，年度缺席累计的5次的年度考核不得评为优秀。

5. 全体工作人员必须自觉遵守学习制度，积极参加集体学习，除参加上级召开的会议或出差，因病因事请假外，一律不得无故缺席，并坚持做好学习记录，按要求撰写心得体会文章。

 

 

 

 

 

莆田市文化广电新闻出版局保密工作制度

 

为保守国家机密，维护国家安全，根据《保密法》有关规定，结合实际，制定本制度。

1. 机关工作人员严格执行《保密法》及有关保密规定，自觉遵守保密纪律，履行保密义务。

2. 机关工作人员对工作办公场所负有安全保卫责任，严格遵守有关保密规定，在特殊情况下，当国家秘密安全受到威胁时，应挺身而出，敢于斗争，不怕牺牲，确保其安全。涉密岗位工作人员做到先备案，后上岗；先培训，后上岗，持证上岗。

3. 国家秘密文件资料及物品，使用统一登记帐簿登记管理，做到专人专室专柜妥善保管，定期检查核对，确保帐物相符。

4. 国家秘密文件资料及物品保密管理实行分管领导和保密干部负责制，在使用、传递、借阅、销毁、清退、保管等方面负有直接责任。未经上级批准，不准擅自复制密码电报、涉密文件、资料。

5. 严格执行密码电报收发管理规定，杜绝密电明传、密收明复等问题的发生；对密码电报定期核查，确保安全。

6. 落实技防措施，计算机及信息系统配备国家保密技术产品，切实加强计算机及其信息系统的保密管理，防止发生泄密事件。

7. 对涉密计算机、非涉密计算机、涉密存储介质、非涉密存储介质统一进行登记、编号，落实保密工作责任制；涉密计算机做到专机专用，不得与国际互联网或其它公共网络联接；非涉密计算机不得涉及国家秘密和内部敏感信息。

8. 制定保密宣传教育计划，加强对工作人员的保密教育，增强保密法制观念，自觉做好保密工作。

9.加强对保密工作的领导和督办检查，督促工作人员按照保密管理规定正确处理电报、公文，严防发生泄密事件。

10. 严禁使用手机等无线通信工具谈论国家秘密事项；严禁移动存储介质在涉密计算机与非涉密计算机上交叉使用。

11. 加强保密安全设施建设，对要害部位安装报警器、配备文件碎纸机、铁门、铁窗等安全防护设备，提高保密安全管理水平。

12. 组织机关工作人员学习和掌握本机关保密范围，落实定密责任人，按照法定程序确定国家秘密；做好确定国家秘密登记，统计和上报工作。

13. 机关党政组织和主要负责同志重视保密工作，定期召开会议研究保密工作并解决好实际问题；机关保密组织健全，分管领导和责任部门及职责明确，做到保密工作领导落实、组织落实、经费落实、工作任务落实。
