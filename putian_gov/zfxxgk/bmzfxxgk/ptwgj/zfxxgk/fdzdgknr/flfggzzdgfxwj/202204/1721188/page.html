莆田市文化和旅游局关于组织开展2022年 “中国旅游日”莆田全民旅游季系列活动的通知

发布时间：2022-04-25 17:10
| | |
 局机关各科室、局属各单位，各县区文化体育和旅游局、湄洲岛旅游局、北岸党工委宣传部、北岸文旅办，市旅游协会：

2022年5月19日是第12个“中国旅游日”，为进一步提振文旅行业发展信心，增强旅游市场活力，助力旅游市场恢复和发展，打响“福”文化标识和“清新福建”“全福游、有全福”“妈祖圣地·美丽莆田”品牌，做大做强做优文旅经济，我局将在做好疫情防控工作的前提下，组织开展2022年“中国旅游日”莆田全民旅游季系列活动。现将有关事项通知如下：

    一、活动主题

    感悟中华文化，享受美好旅程——闽山闽水物华新——木兰风光好去处

    二、活动时间

    2022年4月23日（农历三月廿三）-5月31日

    三、主要活动

（一）纪念妈祖诞辰1062周年大会暨春祭妈祖大典

活动时间：2022年4月23日（农历三月廿三）

活动内容：在湄洲岛现场视频连线全球五大洲宫庙开展云祭拜活动，现场直播纪念妈祖诞辰1062周年春季祭典及文艺演出活动，通过直播间向全球介绍世界非物质文化遗产妈祖信俗，解说妈祖祭典文艺表演特色，宣传国家5A级旅游景区。

（二）“福往福来”湄洲岛至平潭海上游线首航仪式活动

活动时间：2022年5月

活动内容：举办“福往福来”湄洲岛至平潭海上游线首航仪式活动，围绕平潭岛、湄洲岛旅游综合布局，开发城际海上旅游精品线路，构建沿海旅游环线发展新格局，拓展滨海旅游产业链条，打造滨海旅游目的地。

（三）木兰风光好去处·达人带你去旅游

活动时间：2022年4月23日-5月31日

活动内容：邀请旅游达人实地探访莆田美丽乡村，发布旅游攻略推文，带领全国游客“云旅游”，让民众足不出户也能体验我市旅游自然风光和深厚文化底蕴。充分整合运用各类网络自媒体平台，带上#519 去旅游#、#莆田全民旅游季#话题，推送我市举办的中国旅游日系列活动等信息，营造浓厚的舆论氛围。

（四）木兰风光好去处·嘴巴带你去旅游

活动时间：2022年4月23日-5月31日

活动内容：通过微信公众号等自媒体平台，发布非遗美食系列线上宣传推文，传播非遗技艺，讲好非遗故事，进一步增强民众对非遗的保护意识，保护好、传承好莆田市的非遗美食，打造莆田非遗美食品牌，激发群众文化旅游消费热情。

（五）“木兰风光好去处·莆田人游莆田”文旅惠民活动

活动时间：2022年4月23日-5月31日

主要内容：由莆田智慧文旅公司依托“莆田文旅一卡通”平台，开展“木兰风光好去处·莆田人游莆田”文旅惠民活动，策划开展线上“莆田文旅一卡通”文旅惠民措施宣传推广，组织“莆田文旅一卡通”用户参与线下特色短线旅游线路产品体验。引导游客通过购买“莆田文旅一卡通”，实现“一卡在手、畅游不愁”。

    （六）“中国旅游日·莆田全民旅游季”微信朋友圈推广

    活动时间：2022年4月23日-5月31日

    活动内容：通过微信平台定向给民众发送《这就是莆田》莆田文旅宣传片和微信朋友圈信息，提高民众对“中国旅游日”的社会知晓度和莆田全民旅游季的社会参与度。

    （七）开展创建文明城市——文明旅游“六进”活动

    活动时间：2022年4月23日-5月31日

    活动内容：结合文明城市创建，强化文明旅游宣传引导。制作文明旅游创城公益宣传折页，开展文明旅游“进A级旅游景区、进星级饭店、进旅行社、进出入境办证大厅、进社区、进校园”活动，宣传文明出游小知识，倡导市民文明出行，强化市民文明出行意识。

四、有关要求

（一）构建立体化宣传矩阵。活动期间，各县区（管委会）文化和旅游行政部门、局属各有关单位要在重要地段、重要场所显著位置张贴、悬挂、喷刷中国旅游日相关的宣传标语和宣传海报，严格遵照《中国旅游日标志管理办法》规定使用“中国旅游日”标志及口号，充分利用宣传栏、电子显示屏、电视走底字幕、手机祝福短信等形式开展中国旅游日宣传，提升群众对中国旅游日的知晓率和参与度，激发形成“爱旅游，爱生活”的节日氛围。要严格遵照《中国旅游日标志管理办法》规定和《福建省文化和旅游厅关于在全省推广应用新版标识的通知》要求，规范使用“中国旅游日”标志及口号、福建文旅新版旅游标识、莆田文旅标识图案。

（二）出台旅游惠民措施。各县区（管委会）文化和旅游行政部门、局属各有关单位要结合实际，在活动期间出台多种形式的旅游惠民措施，包括但不限于：一是发放文化和旅游消费券；二是旅游企业推出免费、打折等优惠措施；三是旅游助老、助残措施；四是对抗疫工作者、劳动模范等先进群体的优惠措施；五是公益性文艺演出、公共文化场馆扩大开放等文化惠民措施。相关惠民措施要通过网站、微信公众号等形式开设专栏定期公开发布。

    （三）统筹做好疫情防控和活动组织工作。各县区（管委会）文化和旅游行政部门要按照当地党委、政府要求，在做好疫情防控的前提下，围绕活动主题制定切实可行的工作方案，确保活动安全有序，开展相关活动的信息要及时通过市、县区（管委会）的宣传矩阵进行发布更新。活动须统一冠以“感悟中华文化，享受美好旅程——闽山闽水物华新——木兰风光好去处”主题名称。

    （四）做好相关信息的汇总报送工作。各县区（管委会）文化和旅游行政部门、局属各有关单位要指定专人，明确时限，制定切实可行的 “中国旅游日”活动工作方案，梳理惠民措施，并于4月22日前将拟举办活动汇总表、惠民措施汇总表（见附件）报送至市文旅局宣传推广科。

    （五）做好本地“中国旅游日”活动总结工作。请各县区（管委会）文化和旅游行政部门、局属各有关单位在5月21日12:00前将“中国旅游日”活动开展工作总结（活动总体情况、采取的主要措施、取得的效果等）以及开展的相关活动图片和视频资料报送至市文旅局宣传推广科。
