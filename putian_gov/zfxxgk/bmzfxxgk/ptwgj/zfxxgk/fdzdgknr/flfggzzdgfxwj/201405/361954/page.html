莆田市文化广电新闻出版局关于印发莆田市文化市场技术监管与服务平台推广应用工作实施方案的通知

发布时间：2014-05-30 08:00
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部，机关各科室、局属有关单位：

现将《莆田市文化市场技术监管与服务平台推广应用工作实施方案》（以下简称《实施方案》），现印发给你们，请认真贯彻执行。

 

 

莆田市文化广电新闻出版局

2014年5月30日

莆田市文化市场技术监管与服务平台

推广应用工作实施方案

 

根据《文化部关于全国文化市场技术监管与服务平台建设的实施意见》（文市发〔2013〕11号）、《文化部关于进一步开展全国文化市场技术监管与服务平台应用工作的通知》（文市发〔2014〕10号）和《福建省文化厅关于开展全国文化市场技术监管与服务平台应用工作的通知》（闽文市〔2014〕53号）等文件精神，为推动我市文化市场信息化建设，提升文化市场管理的规范化建设，切实做好平台推广应用工作，结合我市实际，制定如下工作实施方案。

一、平台作用

“全国文化市场技术监管和服务平台”是集文化市场统一信息共享、统一业务关联、统一应用集成和统一技术支持为一体的综合性平台，平台的建立将为部、省、市、县四级的文化行政管理部门、综合执法机构提供以信息网络为手段的技术监管共享支持，以及为文化经营单位提供文化市场服务共享支持。平台的投入使用将全面提升文化部门在文化市场监管及服务能力。

二、工作目标

根据省文化厅要求，力争至2015年6月，地市级文化行政部门和综合执法机构使用率达80%以上；县级文化行政部门和综合执法机构使用率达70%以上。

三、工作任务

（一）采集基础数据。1．采集市、县区（管委会）两级覆盖文化市场全领域的经营单位主体、产品等信息。2．采集市、县区（管委会）两级文化市场行政管理部门的机构、人员等信息。3．采集市、县区（管委会）两级文化综合执法机构的机构、人员、装备等信息。

（二）成立组织机构。市文广局成立全市文化市场技术监管与服务平台推广应用工作领导小组，组长：林志强；成员：吴建新、罗冬碧、李锋；领导小组下设办公室：办公室设在市文化市场综合执法支队办公室。各县区（管委会）要相应成立平台工作领导小组，做好统筹协调和组织实施工作，要明确实施部门，确定专人负责，责任到人。

（三）制定工作计划。各县区（管委会）要按照《实施方案》要求，结合实际，制定本地推广应用工作计划，明确实施的时间、任务和进度，有计划、分步骤，扎实推进本县区（管委会）平台应用推广工作。

（四）开展平台应用。各县区（管委会）要按照《实施方案》和培训要求，认真做好文化、广电、新闻出版、文物等市场门类存量数据的采集、录入工作，做好上线前的准备工作；平台上线或对接后，要在规定时限内完成账号分配与权限设置、存量数据激活与核对等工作，有序推进平台应用，实现审批、执法业务的规范化。

四、工作步骤

（一）启动阶段。各县区（管委会）要相应成立平台推广应用工作领导小组，确定1名负责人，指定2名业务能力强、计算机操作熟练的人员作为管理员（审批和执法人员各1名）。填写《全市文化市场技术监管与服务平台应用推广联系人员登记表》（附件1），上报市文广局市场管理科。

（二）采集阶段。各县区（管委会）要于6月1日前，按照文化部《全国文化市场技术监管与服务平台基础数据采集工作流程》（附件2）完成经营单位主体信息以及管理部门与执法机构相关数据的采集；于9月1日前完成经营单位产品信息数据采集（具体事项另行通知）。

（三）上线阶段。

1．制定工作方案。各县区（管委会）要对照《全国文化市场技术监管与服务平台上线标准》（附件3），规划实施步骤；要科学制定本地区平台推广应用工作方案，并上报市文广局。

2．存量数据初始化及校验。各县区(管委会）要在采集数据导入平台后30日内完成复核工作，力求数据的完整真实。

3．业务流程确认。各县区（管委会）要对照《全国文化市场技术监管与服务平台业务流程规范》（附件4）梳理业务流程，并于平台上线前15个工作日由省级文化行政部门确认后报文化部。

4．人员培训。组织市、县区（管委会）两级平台管理人员参加省文化厅组织举办的培训班学习培训，对上线县区（管委会）给予人员及技术支持。

（四）运用阶段。各县区（管委会）要自上线运行15个工作日内，完成账号分配、流程调整、权限设置等工作；60日内完成经营单位主体数据的激活和核对等工作，经营单位主体激活率达到80%并核对无误后，正式使用平台办理业务工作。

五、工作要求

（一）加强组织领导。平台的建设应用，是今年文化市场的一项重点工作，各县区（管委会）文化行政部门和综合执法机构要高度重视，统一思想，充分发挥平台领导小组作用，扎实有效推进平台应用工作，以信息化建设促进文化市场管理与执法工作的规范化。

（二）明确任务分工。各县区（管委会）要加强统筹协调，细化任务分工，组织业务培训，做好本县区（管委会）的平台应用。各县区（管委会）文化管理部门要以真实性、完整性为判定标准，将上线应用前所有的主体数据纳入平台，自平台上线应用之日起，所有新增业务工作必须通过平台办理，所有证照、文书经平台打印方可生效。县区（管委会）文化市场综合执法机构要对纳入平台的经营主体数据认真进行核对和校验，日常检查、案件办理等业务工作必须通过平台办理，执法文书经平台打印方可生效。

（三）建立考核机制。市文广局将把平台应用情况列为2014年度全市文化市场管理工作考评内容，并在以后各类案卷评选工作中，优先考虑经平台办理的案件。同时，市文广局将建立平台应用情况通报机制，定期通报平台应用情况，评估、检验各县区（管委会）的使用情况，确保平台应用工作的顺利进行。

（四）注重运行管理。各县区（管委会）要建立平台运行管理制度，对平台系统管理、权限、用户账号等制定明确的管理办法，确保平台操作安全。除依据《政府信息公开条例》规定必须公开的事项外，平台所收集的其他信息仅限于文化行政部门和综合执法机构履行管理职能，不得擅自向社会公开或向无关人员提供。

（五）强化沟通协作。各县区（管委会）在平台应用过程中要保持与省、市文化部门的沟通联系。同时加强与负责行政审批系统建设相关部门的沟通协调工作，做好平台与行政审批系统的对接工作。文化市场管理部门与综合执法机构之间要密切配合，相互支持，总结经验，在实际应用过程中不断完善平台功能。

（六）及时做好反馈。各县区（管委会）文化行政部门要充分运用好省文化厅建立的平台推广工作群（福建省文化市场管理群：144354588），及时反馈平台应用过程中发现的各类问题和意见建议。
