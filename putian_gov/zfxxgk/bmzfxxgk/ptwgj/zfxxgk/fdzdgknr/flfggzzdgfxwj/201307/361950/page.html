莆田市文化广电新闻出版局关于印发2013年文物工作要点与目标任务分解方案的通知

发布时间：2013-07-03 08:00
| | |

各县区文体广电出版局、湄洲岛社会事务局、北岸工委宣传部、市直文博单位：

现将《2013年全市文物工作要点与目标任务分解方案》印发给你们，请认真贯彻落实。

 

 

莆田市文化广电新闻出版局

2013年7月3日

 

 

 

2013年莆田市文物工作要点

与目标任务分解方案

 

根据省文物局年度部署和本局年度工作安排，结合我市文物工作实际，为进一步明确年度工作目标，落实文物保护责任，推进全市文物保护工作，特制定2013年莆田市文物工作要点与目标任务分解方案。具体如下：

一、推进省级文物保护单位维修工程。启动文峰宫三代祠、浦口宫、平海卫城隍庙等10处文物维修工程，完成三清殿东岳殿、平海天后宫、蒲坂戴氏宗祠等5处文物维修工程。

监管单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部、市文物保护协会

责任单位：各相关文保单位管理机构（见附件1）

二、推进省级文物保护单位维修方案设计。完成大宗伯弟、石室岩砖塔、林兆恩墓等6处文物维修方案设计。

监管单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部、市文物保护协会

责任单位：各相关文保单位管理机构（见附件1）

三、推进省级文物保护单位安防方案设计。完成谷城宫、太湖祠、黄滔祠等3处文物安防建设方案设计。

监管单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部、市文物保护协会

责任单位：各相关文保单位管理机构（见附件1）

四、推进省级文物保护单位安防建设工程。启动江口东岳观、万寿观、龙纪寺等6处文物安防建设工程。

监管单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部、市文物保护协会

责任单位：各相关文保单位管理机构（见附件1）

五、推进全国重点、省级文物保护单位立项、规划编制。全市统一组织对第七批全国重点文物保护单位龙华双塔、仙游文庙、宁海桥、平海天后宫进行立项、规划编制。完成省级文物保护单位莆禧城墙规划编制。

监管单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部、市文物保护协会

责任单位：各相关文保单位管理机构（见附件1.2）

六、推进文物保护单位迁移工程。完成修史堂、朱天贵祠、翁氏民居的迁移保护工程，落实林氏民居、薛公池·咏归亭的迁移保护工程选址。

监管单位：荔城区人民政府、市文管办、荔城区文体局、城厢区文体局

责任单位：福建鑫炎建筑工程有限公司、荔城区文体局、城厢区建设发展有限公司

七、做好“三普”资料的整理、出版工作。对第三次全国文物普查资料进行整理、汇总、建档，出版莆田文物地图集，编写莆田文物丛书。

责任单位：市文管办、市博物馆、各县区文体局、湄洲岛社会事务局、北岸工委宣传部

八、围绕发展大局，主动服务重点项目。完成市重点项目建设用地勘察论证和重点项目建设规划论证。

责任单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部

九、加强文物职能部门的主体作用。发挥市文物保护协会等民间文物保护组织的桥梁和助手作用，积极争取资金，大力发动社会捐资，抢修、维修文物古建筑，做好文物安、消防设施建设。

责任单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部、市文物保护协会、各相关文保单位管理机构

十、完成第五批市级文物保护单位的申报工作。

监管单位：各县区人民政府（管委会）

责任单位：各县区文体局、湄洲岛社会事务局、北岸工委宣传部

十一、推进文物保护单位和历史文化名村的合理利用。发挥文化遗产在经济社会发展特别是旅游业中的作用，利用各文物古建筑的特点建设成为群众文化活动、休闲益智的场所，适应群众新的文化需求。

责任单位：各县区文体局、湄洲岛社会事务局、北岸工委宣传部

十二、申报国家及历史文化名村。申报仙游县济川村为国家级历史文化名村。

监管单位：仙游县人民政府

责任单位：仙游县文体局

十三、做好群众信访工作。认真办理群众的文物信访件，做到既保护文物博物，又化解群众诉求。

责任单位：市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部

十四、有效开展文物行政执法工作。积极配合有关部门，打击文物违法活动。

责任单位：市文化市场综合执法支队、市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部

十五、强化文物安全工作。落实文物安全五项制度，重点防范文物保护单位火灾、文物失窃和台风暴雨等恶劣天气引起的安全事件，每年开展四次以上的文物安全大检查活动，发现安全隐患，限期整改。（见附件3）

监管单位：市文广局办公室、市文化市场综合执法支队、市文管办、各县区文体局、湄洲岛社会事务局、北岸工委宣传部

责任单位：各级文保单位、文物点管理机构
