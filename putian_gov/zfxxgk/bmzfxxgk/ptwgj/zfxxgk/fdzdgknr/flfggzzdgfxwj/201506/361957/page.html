莆田市文化广电新闻出版局关于推进我市“十三五”文化改革发展专项规划编制工作的通知

发布时间：2015-06-01 08:00
| | |

各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属各单位，机关各科室：

根据《莆田市人民政府关于组织开展莆田市“十三五”专项规划编制工作的意见》（莆政综〔2015〕50号）文件要求，我局牵头编制《莆田市“十三五”文化改革发展专项规划》，现将有关事项通知如下：

一、成立规划编制领导机构

　　成立莆田市“十三五”文化改革发展专项规划编制工作领导小组及办公室，成员名单如下：

组　长：刘晶洁

副组长：林志强、何黎仙

成　员：蔡明贤、张玉应、蔡莉莉、吴寿涛、刘凌翔、　　　　

　　　　连金焰、陈　豪、游国鹏、李志扬、洪剑雄、

　　　　林金标、郑智专、宋国平、龚雄华

领导小组下设办公室，挂靠在局办公室，主任由蔡明贤兼任，成员由李志扬、陈永杰、洪剑雄、李锋、郑丽鑫组成。

请各县区文体广电出版局、湄洲岛管委会社会事务局、北岸工委宣传部，局属各单位成立相应的规划编制工作小组。具体名单及联系方式请于6月5日前报送局办公室。

二、工作要求

根据莆政综〔2015〕50号文件要求，我局就本规划编制工作要求如下：

　　（一）由局属各单位、各科室自行完成“十三五”文化改革发展规划大纲的草拟、前期调研和完成规划初稿写作。各单位、各处（室、局）提供的规划初稿必须包括以下内容：

1. 发展基础和面临形势。回顾总结“十二五”时期各自领域的文化建设取得的主要成就，分析“十三五”时期各自领域的文化发展面临的机遇和挑战。

2. 指导思想、基本原则和发展目标。明确“十三五”时期各自领域的文化改革发展的指导思想、基本原则和发展目标。

3. 主要任务。确定“十三五”时期各自领域的文化改革发展的主要任务。同时，提出一批重大文化建设工程、项目,特别是要把妈祖文化生态试验区建设、我市参与联合申报“海上丝绸之路世界文化遗产”的相关工作纳入规划范畴。

4. 保障措施。明确实施“十三五”时期各自分管领域的文化改革发展专项规划的保障措施。

写作体例具体可参考我市“十二五”文化改革发展专项规划（莆政综〔2011〕157号）。各单位、各科室提出的重大文化建设工程、项目和拟提请赋予的政策也请一并在规划初稿中详细说明，争取统筹纳入《莆田市“十三五”文化改革发展专项规划》、《福建省“十三五”文化改革发展专项规划》。

　　（二）进度要求。请各单位、各科室要认真抓好规划的编制工作，在2015年7月10日前完成上述工作，规划初稿于2015年7月15日前报局办公室汇总。编制工作小组办公室要认真组织，统筹协调，确保按时优质完成各阶段编制工作任务。具体进度安排如下：

1. 2015年5－6月组建规划工作班子，落实任务分工，拟定规划大纲，开展前期调研；

2. 2015年7月，完成规划初稿；

3. 2015年8－9月，征求意见和修改完善；

4. 2015年10－11月，报送市发改委初步衔接；

5. 2015年12月，修改完善，完成论证工作；

6. 2016年1－2月，再次报送市发改委与《纲要》衔接，修改形成送审稿，上报市政府审定；

7. 2016年3月，规划印发实施。
