莆田市文化广电新闻出版局关于组织参加第四次全国文化馆评估定级工作的实施方案

发布时间：2015-06-01 08:00
| | |

各县区文体广电出版局，市群众艺术馆：

根据《文化部办公厅关于开展第四次全国文化馆评估定级工作的通知》（办公共函〔2015〕125号）和《福建省文化厅关于做好第四次全国文化馆评估定级工作的实施方案》（闽文社〔2015〕30号）精神，为组织做好我市参加第四次全国文化馆评估定级工作，特制定莆田市关于组织参加第四次全国文化馆评估定级工作的实施方案。

一、评估对象

市群众艺术馆、县区文化馆

二、评估标准

1.市（地级市、区）文化馆等级必备条件和评估标准（附件1）；

2.县（市、区）文化馆等级必备条件和评估标准（附件2）。

三、工作安排

1.2015年6月10日前，市群众艺术馆、县区文化馆按照评估定级标准，进行自查自评。自评数据录入“第四次全国文化馆评估定级系统”。登录地址：国家数字文化网（www.ndcnc.gov.cn）进入首页左边“全国文化馆评估定级”。具体账号及密码见附件3。

县区文体广电出版局要加强对辖区文化馆评估工作的指导和督促。市局将于6月15日前组织评估组对县（区）文化馆进行评估和满意度测评。

2.2015年7月，省艺术馆组织评估组对市群众艺术馆进行评估和群众满意度测评，同时抽查部分县区文化馆。

3.2015年8—9月，中国文化馆协会组织对省艺术馆、厦门市艺术馆进行评估，并抽查部分地市级馆和县级馆。

4.2015年9月底，省艺术馆完成全省的评估总结报告报送省文化厅，由省文化厅报送文化部公共文化司、中国文化馆协会秘书处。

四、工作要求

1.文化馆评估定级是加强我市公共文化服务体系建设，衡量文化馆建设、管理和服务水平的一项重要工作。各县区要高度重视，将组织参加第四次全国文化馆评估定级工作作为今年的工作重点抓紧抓好。

2.整个评估定级工作坚持实事求是、公开公正原则，各参评馆要认真组织学习，对照标准，逐项落实，认真做好本单位自评和迎接国家、省、市组织的评估。

3.文化馆评估结果关系当地文明城市、文化先进县（区）创建等工作。按照文化部统一要求，各级群众艺术馆、文化馆一律参加本次评估工作。如有特殊原因确实无法参加的，各县区文体广电出版局要以文件形式报送市局，由市局上报省文化厅。

4.为做好此次文化馆评估工作，我局将成立评估工作小组，负责指导全市文化馆评估工作。同时将召开专题会议，组织培训。具体会议时间另行通知。
