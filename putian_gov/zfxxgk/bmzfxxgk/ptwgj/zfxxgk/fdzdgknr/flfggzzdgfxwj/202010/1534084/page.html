福建省新闻出版局关于开展首届福建省示范书店评选活动的通知

发布时间：2020-10-29 11:38
| | |

各县区文化体育和旅游局，湄洲岛旅游文体局，北岸党工委宣传部，市出版物发行业协会：

现将《福建省新闻出版局关于开展首届福建省示范书店评选活动的通知》（闽新出〔2020〕173号）转发给你们，请按照通知要求组织推荐。各县区(管委会）分别推荐参评书店1-2家，并于10月21日前将参评单位申报纸质材料一式3份报送市局新闻出版科（同时报送PDF格式电子版）。我局将会同市出版物发行业协会对拟推荐的书店进行现场核查，从中择优推选5家上报省局。

 联系人：张玉应，2623066，13860935655，邮箱：1286882925@qq.com。

 

附件：1.福建省新闻出版局关于开展首届福建省示范书店评选活动的通知

2.莆田市获得2018年—2020年度省实体书店项目资金扶持名单

 

 

                    莆田市文化和旅游局 

                                            2020年10月16日

 

附件1

福建省新闻出版局关于开展

首届福建省示范书店评选活动的通知

 

各设区市新闻出版广电局（新闻出版局），平潭综合实验区党工委宣传办：

为贯彻落实中宣部等11部门《关于支持实体书店发展的指导意见》（新广出发〔2016〕46号）和省委宣传部等14部门《贯彻落实〈关于支持实体书店发展的指导意见〉的实施意见》（闽新广〔2017〕223号）精神，进一步支持实体书店发展,全方位推动我省出版物发行业高质量发展超越，根据《福建省示范书店评选办法》，我局决定开展首届福建省示范书店评选活动。现将有关事项通知如下：

一、推荐程序

由符合条件的实体书店自愿申报，各设区市（含平潭）新闻出版行政主管部门从中择优按额度、依顺序推荐，再经我局专家评审小组评审，最终确定全省示范书店名单。

二、申报条件

（一）基本条件

1.从事出版物发行业务满三周年，且通过2018年—2020年出版物发行单位年度核验；

2.营业场所面积不低于60平方米；

3.有完整的进销货清单，经营状况良好，资信等级较高，以出版物发行为主营业务，年销售出版物2万册以上；

4.遵纪守法，近三年未受到行政处罚且无其他违法违规记录；

5.未曾获得2018年—2020年度省实体书店项目资金扶持。

（二）重点支持方向

1.取得较好的社会效益。积极宣传习近平新时代中国特色社会主义思想，传播党的方针政策，弘扬社会主义核心价值观；弘扬中华民族优秀传统文化，挖掘福建历史文化内涵；有销售和展销重点主题出版物。

2.创新经营模式。积极探索馆店结合、场店结合、院店结合、线上线下结合等可复制、可持续的经营模式，走“专、精、特、新”内涵式发展道路，在促进产业转型升级方面有显著成效。

3.业态定位明确。在环境布置、装饰设计、图书陈列、管理服务、衍生品开发等方面具有鲜明特色，艺术性、主题性、专业性和学术性突出；坚持服务广大读者，特别是致力于为妇女、儿童、学生、农民等提供阅读服务。

4.大力推动全民阅读。积极参与“4·23海峡读者节”“书香八闽全民读书月”“新时代乡村阅读季”等活动和组织推动全民阅读“七进”工作；经常性开展内容丰富、形式新颖、读者认可的文化活动，参与捐赠活动等。

5.近三年获得设区市级以上政府部门、行业协会表彰的，或者在省级以上媒体上被正面宣传报道的，可作为优先推荐对象。

三、申报材料

（一）《福建省示范书店申请表》（见附件1）；

（二）工商营业执照和出版物经营许可证复印件（皆须加盖书店公章）；

（三）参与阅读推广和相关社会公益活动、媒体宣传报道、获得各种荣誉等证明材料（含相关图片）；

（四）书店门面和不同角度的内景图片（不少于3张）。

以上所有材料皆须提供电子版和纸质版：电子版用PDF格式；纸质版须装订成册，一式二份。

四、有关要求

（一）各地要高度重视，做好宣传发动工作，并明确专人负责，加强对其申报工作的指导。

（二）各地要对申报材料进行严格审核把关，对拟推荐书店须现场核查，确保申报材料真实、有效。

（三）各地要明确推荐顺序，统一用“请示件”上报我局。

（四）本次示范书店评选结果将作为2021年省实体书店项目资金扶持的推荐依据。各地推荐示范书店数量为：福州、莆田、泉州、厦门和漳州各不超过5家，龙岩、三明、南平、宁德各不超过4家，平潭不超过2家。

请各地于2020年10月26日前将申报材料（含纸质版和电子版）报送至省委宣传部印刷发行处，逾期不予受理。
