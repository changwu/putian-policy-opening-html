关于印发《莆田市文化广电新闻出版局开展深入学习实践科学发展观活动的实施方案》的通知

发布时间：2009-03-31 08:00
| | |

市直属各单位、机关各科室：

现将《莆田市文化广电新闻出版局开展深入学习实践科学发

展观活动的实施方案》印发给你们，请认真贯彻落实。

 

 

二〇〇九年三月三十一日

 

 

 

 

 

莆田市文化广电新闻出版局

开展深入学习实践科学发展观活动的实施方案

  

     根据中共莆田市委深入学习实践科学发展观活动领导小组《关于印发<莆田市开展深入学习实践科学发展观活动的实施方案>的通知》（莆学组发[2009]1号）精神,为扎实开展莆田市文化广电新闻出版系统学习实践科学发展观活动,现结合本系统工作实际,制定本实施方案。

一、指导思想、目标要求、主要原则和时间安排

（一）指导思想。全面贯彻党的十七大精神，高举中国特色社会主义伟大旗帜，以邓小平理论和“三个代表”重要思想为指导，以省委“科学发展、四求先行”和市委“四用发展”为主题，持续推进思想解放、持续争创发展优势、持续改进工作作风，以“海西应先行、港城当崛起”为实践载体，组织全系统广大党员特别是各级领导班子和党员领导干部深入学习实践科学发展观，紧紧围绕党员干部受教育、科学发展上水平、人民群众得实惠，进一步解放思想、实事求是、改革创新，着力转变不适应、不符合科学发展要求的思想观念，着力解决影响和制约科学发展的突出问题，着力解决影响和制约文化广电新闻出版事业科学发展的突出问题，着力解决党员干部党性党风党纪方面群众反映强烈的突出问题，着力构建有利于科学发展的体制机制，团结一致、坚定信心、抢抓机遇，把市委、市政府赋予的保发展、保民生、保稳定的要求落到实处，不断提高我市公共文化服务水平，不断提高广大人民群众对文化广电新闻出版工作的满意度，为进一步解放和发展文化生产力，通过加快文化自身发展，推动经济社会又好又快发展，作出新的贡献。

（二）目标要求。学习实践活动以局党组领导班子和党员领导干部为重点，全系统党员参加，努力实现“党员干部受教育、科学发展上水平、人民群众得实惠”的总体要求和“提高思想认识、解决突出问题、创新体制机制、促进科学发展”的目标。

1、党员干部受教育是搞好学习实践活动的基础。通过学习实践活动，进一步提高对科学发展观的认识，进一步用科学发展观武装党员干部头脑，形成“海西应先行、港城当崛起”的共识，增强贯彻科学发展观、走科学发展道路的自觉性和坚定性，着力把握发展规律、创新发展理念、转变发展方式、破解发展难题、实现发展目标。

2、科学发展上水平是搞好学习实践活动的核心。通过学习实践活动，增强信心、增添力量，努力把科学发展观转化为自觉行动，转化为“海西应先行、港城当崛起”的坚强意志、正确思路、实际能力和政策措施，坚持“四用发展”和“三个持续”，推动和促进我市文化广电新闻出版事业全面转入科学发展轨道，开创我市文化广电新闻出版事业繁荣发展的新局面。

3、人民群众得实惠是搞好学习实践活动的目的。通过学习实践活动，教育引导广大党员干部增强宗旨意识、责任意识，着力民心、着力民生，将以人为本的发展理念落实到湄洲湾港口城市建设，落实到文化广电新闻出版事业繁荣发展的火热实践中，努力解决党员干部党性党风党纪方面群众反映强烈的突出问题，让人民群众持续得到实惠，使学习贯彻科学发展观的过程成为不断为民造福的过程，成为不断提高人民文化权益的过程，让发展成果惠及广大人民群众。

（三）主要原则。为确保学习实践活动健康开展，要切实把握以下原则：

1、坚持解放思想。以解放思想为先导，以改革创新为动力，克服不思进取、自甘落后的保守思想，准确把握本系统服务发展的潜在优势，弘扬我市改革开放30年的宝贵经验，引导广大党员特别是党员领导干部紧密联系当前形势，更新发展观念，转变发展思路，在本系统要不要科学发展、能不能科学发展、怎么样科学发展等重大问题上形成共识。

2、突出实践特色。紧紧围绕“科学发展、四求先行”主题，落实“四用发展”和“三个持续”的要求，以“海西应先行、港城当崛起”为实践载体，认真学习、深入实践，努力取得看得见、摸得着的实际成果。把开展学习实践活动与贯彻落实党的十七大和省委、市委的一系列重大部署结合起来，与加强领导班子思想政治建设和作风建设结合起来，与市委实施“以港兴市、工业强市”发展战略和保发展、保民生、保稳定的要求结合起来，与贯彻落实《中共福建省委办公厅、人民政府办公厅关于进一步加强公共文化服务体系建设的意见》结合起来，与3月27日全市文化广电新闻出版工作会议上提出的2009年十大重点工作任务结合起来。通过开展学习实践活动，达到提高思想认识，创新体制机制，加强党的建设，促进科学发展的目标要求，努力在对科学发展观认识的深度和广度上有新突破，在解决影响的制约科学发展的突出问题上有新的举措，在推动本系统、本单位的科学发展上的新成果。通过学习推动实践，通过实践深化学习。

3、贯彻群众路线。坚持“开门”搞活动，充分发扬民主，吸收群众全程参与，认真听取群众意见和建议，真诚接受群众监督，努力解决影响和制约“海西应先行、港城当崛起”的突出问题，把群众参与贯穿学习实践活动全过程，把群众满意作为评价活动成效的重要依据。

4、正面教育为主。坚持高标准、严要求，组织广大党员干部深入学习实践科学发展观，加强党性修养，树立和弘扬良好作风，实事求是查找存在的问题，深刻分析产生问题的原因，全面总结经验教训，认真开展批评和自我批评，进一步明确努力方向，以坚强的党性和优良的作风保证科学发展观的贯彻落实。

（四）时间安排。市文化广电新闻出版系统参加学习实践活动，从2009年3月开始，到2009年8月基本完成。

二、学习实践活动的方法步骤

开展学习实践活动，要做好调查摸底、征求意见、成立机构、制定方案等准备工作。全系统召开动员大会后，各单位也要进行动员，全面开展。学习实践活动分三个阶段进行：

第一阶段：学习调研（3月底至4月底左右）。学习调研阶段是整个学习实践活动的基础，主要任务是学好理论，提高认识，统一思想，转变观念。

1、组织处级领导干部带头学习培训。要根据市委统一安排制定学习培训计划，创新学习培训载体，采取党组学习、集中培训，分批轮训、专题辅导、集体研讨、个人自学等形式，组织党员、干部认真学习《毛泽东邓小平江泽民论科学发展》和《科学发展观重要论述摘编》，处级领导干部还要认真学习《深入学习实践科学发展观活动领导干部学习文件选编》。同时要认真学习贯彻党的十七大、党中央一系列指示精神以及省委、市委作出的一系列决策部署。组织处级领导干部参加市委举办的领导干部深入学习实践科学发展观专题研讨班，学习当前形势任务、港口经济建设、农村改革发展、加强党性修养等“四个专题教育”。处级领导干部要带头到基层部门或挂钩联系点作辅导。各单位要安排相应的集中学习时间。

2、组织领导干部深入基层调研。要从本系统实际出发，紧紧围绕“海西应先行、港城当崛起”这一实践载体，组织局领导班子深入基层单位调研，各单位采取多种形式，深入基层、深入群众调查研究，认真梳理查找影响本单位发展的突出问题，提出具有针对性和可操作性的对策建议，使深入实践的过程转化为指导实践、推动发展的具体行动。要认真制定调研方案，领导班子成员都要确定重点调研课题，带头开展调研，带头听取意见建议，带头撰写调研报告，带头交流调研成果。

3、组织全体党员开展大讨论。紧密联系工作实际和党员干部的思想实际，组织系统全体党员开展“海西应先行、港城当崛起”大讨论。大讨论要围绕保发展、保民生、保稳定的需要来开展。保发展，就是要坚持凝聚人心共谋发展，项目带动支撑发展，统筹兼顾协调发展，加强党建保障发展，为确保今年全市经济增长顺利实现“十百千”目标做贡献，确保落实好2009年我局十项重点工作任务。保民生，就是要坚持以人为本，着力民生民心，进一步开展困难群众帮扶工作，帮助贫困村和困难群众，着眼于最大限度在满足人民群众日益增长的物质文化需要，着眼于构建公共文化服务体系，着眼于提高我市文化软实力，真正让人民群众共享文化发展成果。保稳定，就是要进一步深化“平安莆田”、“平安文化”建设，发挥文化广电新闻出版工作优势，多做化解矛盾的事，构建和谐文化，为全市文化广电新闻事业又好又快发展，创造良好的发展环境。各单位要按统一布置的专题，结合实际组织党员干部开展大讨论，进一步统一思想、提高认识、形成合力、推动工作。

第二阶段：分析检查（5月上旬至7月上旬）。这一阶段是把认识成果转化为实践成果的关键阶段，主要任务是征求意见、找准问题、分析原因、明确方向。

1、召开领导班子专题民主生活会。局领导班子要紧紧围绕深入贯彻落实科学发展观这一主题，按照加强领导班子思想政治建设的要求，紧扣党的十六大以来本局的发展实践，紧密联系领导班子作风建设实际，深入查找个人和班子在全面推进湄洲湾港口城市建设和推进莆田文化广电新闻出版工作中，贯彻落实科学发展观方面存在的突出问题，面对发展压力和挑战反映出来的突出问题，党性修养和作风建设等方面存在的突出问题，深刻分析原因，开展批评与自我批评。民主生活会前，领导班子成员之间要相互谈心，听取群众意见，撰写发言材料，进行自我检查，做好充分准备。专题民主生活会可适当扩大列席人员范围，并邀请上级纪委、组织部、宣传部等有关部门和学习实践活动指导检查组参与指导，按照科学发展观要求分析查找自身差距和不足，明确努力方向。

2、形成领导班子分析检查报告。领导班子分析检查报告要充分运用学习调研和开展“海西应先行、港城当崛起”大讨论的成果，充分反映本局贯彻落实科学发展观的实际情况，简明扼要概述取得的成效，系统全面梳理存在的问题，实事求是分析存在问题的主客观原因，特别是主观方面的原因。要深入分析国际国内经济形势对文化广电新闻出版系统带来的挑战和不利影响，充分反映本系统广大党员干部在以科学发展观为指导，保持文化广电新闻出版工作持续较快发展上形成的共识，明确进一步做好工作的努力方向、总体思路和主要举措。分析检查报告要突出检查分析问题、理清科学发展思路、明确改进措施这个重点，切忌写成工作报告。党组书记要全程主持、局办公室负责分析检查报告的起草工作。分析检查报告初稿形成后，要召开党组扩大会议充分讨论，并以适当方式听取各方面意见，反复修改完善，使之成为指导本系统科学发展的重要文件。

3、组织群众评议。领导班子分析检查报告形成后，要在一定范围内公布，组织党员、群众进行评议，广泛征求意见。参评人员既要有本系统的党员和干部职工，也要有一定数量的服务对象代表，特别要注意吸收熟悉情况、有较强议政能力的党代会代表、人大代表、政协委员、专家学者、基层单位代表和服务对象代表参加。参加评议人员要着重从领导班子对科学发展观的认识深不深、查找的问题准不准、原因分析得透不透、发展思路清不清、改进措施可行不可行等方面进行评议。群众评议中提出的正确意见要体现到分析检查报告中。分析检查报告和群众评议结果要在一定范围公开。评议要根据实际情况采取召开座谈会或书面评议等形式进行，尊重党员群众的评议意见，使群众评议的过程成为上下交流、取得更广泛共识的过程。

第三阶段：整改落实（7月中旬至8月底）。这一阶段是出成果、见实效阶段，主要任务是明确目标、落实责任、扎实推进，切实取得实践成果和制度成果，重点开展“四进基层”活动。

1、制定整改落实方案。领导班子整改落实方案应以分析检查报告为依据，注重可操作性，针对查摆出来的突出问题和需要完善的制度，细化为具体项目，按轻重缓急和难易程度，分别提出整改落实的目标、方式和时限要求，明确责任，明确措施，明确时限。整改落实方案制定后，以适当方式向党员、群众公布，做出公开承诺。整改落实情况要向党员、群众通报，接受党员、群众监督。

2、集中解决突出问题。解决问题要突出重点，坚持什么问题突出就重点解决什么问题，要从群众最不满意的事情改起，从群众最关心的事情做起，切实解决群众普遍关心、反映强烈的热点、难点问题。要按照整改落实方案的要求，集中力量解决在学习实践活动中能够解决的问题，特别是贯彻中央和省委、市委一系列决策部署，保发展、保民生、保稳定方面的突出问题，领导班子和党员领导干部党性党风党纪方面的突出问题。要组织开展“进农村扶贫帮困、进社区共建文明、进企业破解难题、进学校结对助学”等实践活动，落实“四用发展”和“三个持续”要求，多为人民群众办看得见、摸得着、促进科学发展的实事，让群众实实在在地感受到学习实践活动的成效，防止形式主义、短期行为和“形象工程”。解决问题要坚持实事求是，尽力而为、量力而行，切忌搞形式主义。对涉及多部门的问题，要积极探索上下互动、左右联动的解决方式。

3、完善体制机制。要从促进“海西应先行、港城当崛起”的需要出发，认真清理现有的规章制度，把解决问题中形成的好办法好经验用制度的形式巩固下来，努力构建充满活力、富有效率、更加开放、有利于科学发展的体制机制。要从实际出发，从活动一开始就要注意做好创新体制机制的工作，充分借鉴学习调研成果，充分运用领导班子分析检查报告，及时制定和完善转变职能、改进作风、推动发展、促进和谐、惠民利民、勤政廉政、运转高效的措施和办法，把建立健全保障和促进科学发展的体制机制作为整改落实的一个重要内容。要发动和鼓励广大党员积极建言献策，提出合理化建议。

学习实践活动基本完成时，要及时做好总结工作，组织进行群众满意度测评。群众满意度测评的内容主要是对本系统开展学习实践活动情况的满意度。要合理确定参加测评人员的规模、范围，使之既有一定的代表性，又规模适中。测评方式和程序要简便易行，测评结果要客观真实。根据测评情况，进一步完善整改落实措施，抓好落实。

这次学习实践活动不作统一转段要求，各参学部门要注意各个环节之间的相互联系和相互衔接，坚持进度服务质量，以每个环节的高质量保证整个活动的高质量。

三、组织领导和指导

局党组要把学习实践活动摆上重要议事日程，高度重视，精心组织，坚持深入学习、解放思想贯穿始终，坚持突出实践特色、解决实际问题贯穿始终，坚持依靠群众、发扬民主贯穿始终，确保活动取得实效。

（一）落实领导责任。为保证学习实践活动有条不紊顺利推进，局党组成立学习实践活动领导小组，局长李尚清任组长，副局长郑国荣、罗锦枝、卓培华、杨金远任副组长，机关各科室和直属单位主要负责人任成员，负责对系统学习实践活动的工作指导和组织协调。领导小组下设办公室，办公室主任由柳青兼任。领导班子成员要充分发挥带头示范作用，积极参加学习实践活动，并结合分工，深入联系点指导检查。要积极配合市委学习实践活动领导小组的监督检查，并主动向市委学习实践活动办公室上报本系统学习实践活动的有关情况。

（二）加强分类指导。要坚持突出处级领导班子和党员领导干部这个重点，增强活动的针对性和实效性，同时抓好广大党员的学习实践活动。非中共党员的干部可参与活动，共同学习，结合自身的工作实际开展调查研究，为学习实践活动献计献策。对聘用、借用及挂职半年以上的党员，应在聘用、借用及挂职单位参加学习实践活动。

（三）鼓励探索创新。各单位在学习实践活动基本要求的前提下，可针对本单位的特点和不同的对象，进一步将“海西应先行、港城当崛起”实践载体具体化，丰富活动内容，强化活动效果。各部门广大党员要以履行岗位职责、加强职业道德建设、促进行风转变为重点，争当业务带头人，争创一流工作业绩。要讲成本，重实效，防止文山会海，杜绝形式主义。

（四）营造良好氛围。要充分利用“莆田市文化广电新闻出版局网站”、“文化信息”和“文化专报”等阵地，大力宣传科学发展观的科学内涵、精神实质和根本要求，宣传开展学习实践活动的重大意义，宣传学习在“海西应先行、港城当崛起”中涌现出来的先进典型，宣传学习实践活动的部署、要求、做法、经验和成效，做好舆论引导工作，切实增强宣传工作的吸引力和感召力，宣传推广经验做法，努力营造全系统开展学习实践活动的良好氛围，克服厌倦情绪和疲沓思想，不断提高参加活动的积极性、主动性和自觉性。

（五）坚持统筹兼顾。这次学习实践活动时间紧、任务重，各单位的要迅速把思想和行动统一到中央、省委和市委的精神上来，统筹安排学习实践活动各个阶段和各个环节的工作，做到有机衔接、前后呼应。要统筹协调和集中各方面的资源，进行有效融合，提高整改实际效果。要正确处理开展学习实践活动与做好当前各项工作的关系，用推动文化广电新闻出版各项工作、全面推进湄洲湾港口城市建设的实际成果来衡量和检验学习实践活动的成效，做到两手抓、两不误、两促进。
