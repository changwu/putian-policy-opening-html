关于印发莆田市文化广电新闻出版局2017年政务公开实施方案的通知

发布时间：2017-05-27 09:45
| | |

局属各单位、机关各科室：

现将《莆田市文化广电新闻出版局2017年政务公开实施方案》印发给你们，请认真贯彻落实。

 

 

    莆田市文化广电新闻出版局

2017年5月27日

 

 

 

 

莆田市文化广电新闻出版局

2017年政务公开实施方案

 

根据《莆田市人民政府办公室关于印发2017年政务公开工作主要任务分解表的通知》（莆政办〔2017〕80号）要求，结合本局实际，制定本实施方案。

一、把握总体要求

全面贯彻党的十八大和十八届三中、四中、五中、六中全会精神，深入贯彻习近平总书记系列重要讲话精神和治国理政新理念新思想新战略，坚持以公开为常态、不公开为例外，全面推进决策、执行、管理、服务、结果“五公开”，加强解读回应，扩大公众参与，增强公开实效，助力稳增长、促改革、调结构、惠民生、防风险，为“打造宜居港城、建设美丽莆田，创建美丽中国的示范区”提供强有力保障，以优异成绩迎接党的十九大胜利召开。

二、细化工作任务

（一）推进政策执行和落实情况公开

    主动及时做好解疑释惑和舆论引导工作，重点加强文化改革发展、文化市场管理、文化遗产、文物保护等重大政策贯彻落实情况的公开，扩大政策知晓率和参与度。（责任单位：办公室）

    （二）推进“放管服”改革信息公开

    1.强化权责清单管理与应用。以清单管理推动减权放权，各类清单及时向社会公开。深化权责清单公开工作，通过在局网站集中发布、开设反馈意见箱、增加在线提交意见建议功能等方式，让公众了解放权情况、监督放权进程、评价放权效果。（责任单位：办公室）

    2.及时公开政策性文件的废止、失效等情况。定期通过主动推送信息等方式告知政策性文件的废止、失效情况，及时在政府网站已发布的原文件上作出明确标注。（责任单位：办公室）

3.推行“双随机、一公开”监管全覆盖。围绕年内实现“双随机、一公开”监管全覆盖要求，汇总形成并统一公布随机抽查事项清单，明确抽查依据、主体、内容、方式等，及时公开抽查结果和查处情况。（责任单位：市文化市场综合执法支队）

4.大力推进“互联网＋政务服务。加快完善电子证照系统，促进行政审批服务全程网办，加快实体政务大厅与网上服务平台融合发展，让企业和群众办事更加便捷。（责任单位：审批科牵头，各科室配合）

    （三）推进财政资金公开

    按照规定做好部门预决算公开工作，通过本局和财政部门网站预决算公开统一平台（或专栏）集中公开部门预决算，方便公众查阅监督；按月公开本局财政收支情况；主动公开相关审计结果公告及审计发现问题的整改情况。（责任单位：会计核算中心牵头，办公室配合）

    （四）主动做好政策解读

    1.深入解读政策背景、依据、目标任务、涉及范围。通过新闻发布会、在线访谈等方式，及时准确将文化政策意图传递给社会公众。加强舆情收集研判，针对涉及全市文化发展的误导和不实信息，客观及时、有说服力地发声，澄清事实，解疑释惑。（责任单位：办公室）

    2.切实做好政策解读回应工作。各单位主要负责人要履行好“第一新闻发言人”“第一解读人和责任人”的职责，充分利用新闻发布会、通气会、政策吹风会等方式，主动回应重大舆论关切，释放信号，引导预期。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    3.落实政策解读“三同步”要求。要按照“谁起草、谁解读”原则，落实政策性文件与解读方案、解读材料同步组织、同步审签、同步部署的“三同步”工作要求。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    4.及时回应社会关切。严格执行特别重大、重大突发事件最迟5小时内发布权威信息、24小时内举行新闻发布会的时限要求，事发单位是信息发布第一责任人，主要负责人要当好“第一新闻发言人”。严格落实通报批评和约谈制度，确保回应不超时、内容不敷衍。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    （五）推进文化建设项目公开

    推进市博物馆、市图书馆、市艺校和村（社区）综合文化服务中心示范点建设进度公开；推进建设美丽莆田·文化繁荣2017年专项行动计划执行情况公开。（责任单位：办公室牵头，社文科、市博物馆、市图书馆配合）

    三、增强公开实效

   （一）“五公开”纳入办文办会程序。一是将“五公开”要求落实到公文办理程序。机关各科室、局属各单位拟制公文时，要明确主动公开、依申请公开、不予公开等属性，随公文一并报批。拟不公开的，要依法依规说明理由。对拟不公开的政策性文件，报批前应先送本单位政务公开工作机构审查。起草政府政策性文件代拟稿时，应对公开属性提出明确建议并说明理由；上报的市政府的发文请示件要明确公开属性建议，或者依法依规说明不公开理由，否则市政府办公室将按规定予以退文，并列入绩效评估扣分。二是将“五公开”要求落实到会议办理程序。2017年底前，建立健全利益相关方、公众代表、专家、媒体等列席政府有关会议的制度，增强决策透明度。提交市政府常务会议审议的重要改革方案和重大政策措施，除依法应当保密的外，应在决策前向社会公布决策草案、决策依据，广泛听取公众意见。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    （二）建立公开内容动态扩展机制。要根据国务院、省和市对政务公开工作的新要求以及公众关切，明确政务公开年度工作重点，把握好公开的力度和节奏，稳步有序拓展“五公开”范围，细化公开内容。要对照“五公开”要求，每年对本单位不予公开的信息以及依申请公开较为集中的信息进行全面自查，发现应公开未公开的信息应当公开，可转为主动公开的应当主动公开，自查整改情况应及时报送市政府办公室。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    （三）加快制定主动公开基本目录。2017年底前完成政务公开目录体系编制前期工作。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    （四）做好电视电话会议公开工作。对涉及公众利益、需要社会广泛知晓的电视电话会议，除涉及国家秘密外，积极通过网络、新媒体直播等方式向社会公开。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    （五）做好人大代表、政协委员提案办理结果公开工作。对涉及公共利益、社会广泛关注的建议提案，原则上都要公开答复全文，及时回应关切，接受群众监督。（责任单位：办公室牵头，机关各科室、局属各单位配合）

    四、加强平台建设

    （一）丰富公开载体。加强对政府网站的监管责任，强化网站信息内容保障；充分利用本局及直属相关单位微信公众号，扩大信息传播，开展在线服务。（责任单位：办公室）    

    （二）加强政府信息查阅场所工作。落实《福建省政府信息查阅场所管理办法》，规范莆田市图书馆政府信息查阅场所建设，开展信息查阅服务。进一步规范主动公开信息送交查阅场所工作。（责任单位：莆田市图书馆）

    （三）加强和规范依申请公开工作。畅通依申请公开受理渠道，依法保障公众合理的信息需求。进一步规范依申请公开答复工作，严格按照法定时限答复，增强答复内容针对性并明示救济渠道，答复形式要严谨规范。对依申请公开工作中发现的依法行政方面问题，要及时向相关单位提出工作建议。对公众申请较为集中的政府信息，可以转为主动公开的，应当主动公开。（责任单位：办公室）

    （四）纳入政府信息公开年度报告。政务公开工作主要任务落实情况要纳入政府信息公开年度报告并向社会公布，接受社会监督。（责任单位：办公室）

    五、加强组织领导

    （一）建立机制。成立由局长任组长、分管副局长任副组长的局政务公开领导小组，负责全局政务公开的组织领导工作。领导小组下设办公室，具体负责全系统政务公开的组织、协调、督促、检查工作。各单位主要领导年内至少听取一次政务公开工作汇报，研究部署推进工作。（责任单位：办公室牵头，机关各科室、局属各单位配合）

（二）强化监督。在创新公开载体、加强互动联动的同时，要持续抓好市级政务公开栏（按季度集中对外公开）、部门公开栏（按月对内公开）、门户网站、办事指南等传统公开工作，并加强日常监督检查。领导小组办公室要切实负起责任，加强对本系统政务公开工作的督促检查，要将政务公开工作纳入各单位绩效考评，对在公开活动中工作不力、搞形式主义的要批评教育，并责令限期整改；对不及时公开、不按规定公开或应公开而不公开、弄虚作假、造成不良后果的，要严肃追究责任，确保完成好政务公开各项工作。（责任单位：监察室）
