关于市政协七届五次会议第2021173号提案办理情况的答复

发布时间：2021-07-06 16:48
| | |

民进莆田市委员会：

你单位提出的《关于布局和开发莆田旅游商品购物休闲街区的建议》（2021173号）已收悉，现将办理情况答复如下：

旅游特色商品购物店、旅游休闲购物街区是文创产业发展的重要载体和渠道具体载体。围绕“发展城镇就是发展旅游，发展旅游就是发展城镇”的思路理念，结合文旅产业开放招商工作，着力加强特色旅游商品的研发和品牌打造，支持和引导商圈、休闲街区、历史文化街区等的建设，推动文创和旅游商品产业高质量发展。

一、推动商品品牌打造

一是打造妈祖文创IP。认真贯彻落实省委书记尹力来莆调研指导精神，不断丰富妈祖文创产品，突出地方特色，开发多层次、妈祖游客需求的伴手礼。与旺旺中时文化传媒（北京）有限公司合作举办金犊奖妈祖文创设计大赛，并基于此打造了自主品牌“妈祖平安礼”。今年新开发了妈祖利是封、国潮妈祖鼠标垫、萌萌妈、Q版妈祖插画等特色伴手礼20多样件。今年5月，组织“妈祖平安礼”参加中国（莆田）海峡工艺品博览会，各类妈祖和湄洲岛特色文化创意产品获得社会各界好评。6月，组织参加了第十七届海峡（厦门）旅游博览会，展出的304件文创产品充分展示了“妈祖”文化、“湄洲岛”海岛风情。下一步，将继续按照省委书记指示精神，结合地域特色，融入妈祖和海洋文化，做好“文化+文创”“艺术+文创”课题，将时尚、创意、传统等文化元素融入到各类作品中，做大做强湄洲岛文创IP。二是打造“壶兰耕读”品牌。编制《莆田市农产品区域公共品牌战略规划》，组织开展农产品质量认证和品牌建设，并由市乡村振兴集团注册“壶兰耕读”公共品牌商标，并与品牌企业搭建合作，引领构建“公共品牌+企业品牌”双品牌模式，整合包装我市特色农产品和文旅特产开展销售。至目前，完成鲍鱼、米粉等十款自主产品包装设计，打造了“莆田枇杷”“莆田桂圆”等系列子品牌，形成了莆田成熟的优质农业伴手礼。三是打造工美文化品牌。深化产业跨界融合，丰富旅游商品结构。出台《促进工艺美术产业转型升级九条措施》，推动油画与鞋服产业合作、定制生产，打造莆田特色产业产品；鼓励木雕、油画等行业协会、企业牵头组织在旅游景区、美丽乡村打造创作体验基地，筛选莆田代表性工艺精品入驻湄洲岛等景区购物中心，拓宽商品推广展销渠道。

二、推动商圈街区建设

一是推动商圈建设。委托专业机构编制《莆田市商业网点发展纲要（2019-2023年）》，指导推动万达广场等城市商圈、商业网点建设发展，并组织商圈企业参加福建消费品采购会暨商圈（步行街）博览会、“全闽乐购”等活动，积极推动商圈繁荣发展。二是推动街区建设。目前，我市已有正荣财务中心步行街等5条综合性步行街，及体育中心美食街、仙游美食城等特色街区。结合旧城改造和新城建设，注重把提高服务品质与改善文化体验结合起来，积极推进文化和旅游业态融合，重点抓好兴化府（县巷文创街）、萝苜田等历史文化街区改造提升，着力打造一批富有莆仙文化特色鲜明的国家级旅游休闲街区。遵循“ 修旧如故”原则，兴化府历史文化街区正在加快推进风貌修缮和改造，并同步开展招商工作。湄洲岛作为我市重要形象窗口，打造旅游休闲街区是推动旅游业发展尤其是文创和旅游商品产业发展的重要举措。2021年，湄洲岛拟重点打造“印巷·妈祖广场”休闲街区项目，共有商铺66间。目前，该街区已完成游客集散广场、停车场、咨询服务中心等旅游基础设施配套。下一步，着力加大开放招商，积极引入具备较强实力的品牌商家，共同打造集文创机构、百年老号、现代艺术、非遗展示、高端沙龙、DIY体验、伴手礼等业态于一体的旅游休闲购物街区。

三、推动集市节会开展

每年，结合文化和自然遗产日、博物馆日、中国旅游日、农民丰收节等节事活动，我市积极策划举办美食节、音乐节、非遗购物节、旅游商品购物节等系列“集市型”子活动，通过以节事带动集市，以集市丰富节事，围绕旅游、休闲服务，整合全市非遗小吃、地方特产、非遗文创、非遗工艺、文化研学、旅游商品、艺术展览、民俗展演等各类产品，为游客和市民打造了多主题、移动式、“快闪式”旅游休闲购物街区。
