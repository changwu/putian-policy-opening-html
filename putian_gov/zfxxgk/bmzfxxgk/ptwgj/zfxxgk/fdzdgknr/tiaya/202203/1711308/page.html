关于市八届人大一次会议第1031号建议的协办意见

发布时间：2022-03-14 11:02
| | |
 仙游县人民政府：

释宏玉等代表提出的《关于建设东南“五台山”推动文化和旅游融合发展的方案》已收悉，我单位的办理意见如下：

一、关于“塑造东南‘五台山’景区的智慧文化旅游名片”的建议

“五台山”是第一批国家风景名胜区，是“中国佛教四大名山”之一，是中国佛教及旅游胜地。“五台山”充分利用宗教建筑、宗教文明、宗教文化、宗教艺术、人文景观等资源，打造成一个融自然风光、古建艺术、历史人物、佛教文化、民俗风情、避暑休养为一体的旅游区，在国内外享有较高的声誉。释宏玉等代表提出的仙游要围绕“有的看、留得住、带的走、想再来”，建设集商贸、休闲、娱乐、养生、文化为一体东南“五台山”景区的发展思路，观点独特，值得探讨研究。仙游县文化底蕴深厚、旅游资源丰富，近年来，县政府高度重视文化旅游发展，全县现有国家A级旅游景区10家（其中4A级旅游景区2家，省级旅游度假区1家），是省级全域生态旅游示范区。我局支持仙游县以创建国家全域旅游示范区为抓手，全面梳理整合各类文化旅游资源，借鉴“五台山”的发展模式和旅游特点，注重佛教文化和生态旅游紧密结合，深入谋划、科学布局，把仙游县建设成具有仙游独特文化特色、佛教文化特色、生态环境特色为一体的国家全域旅游示范区，真正把仙游打造成莆田市文化旅游的又一个典范。

二、关于“打造集素食与餐饮、疗养、艺术等为一体的综合文化场所”的建议

近年来，仙游县围绕“把仙游打造成国际知名、国内著名的生态文化旅游休闲度假胜地”工作目标，大力遵循“宜融则融，能融尽融，以文促旅，以旅彰文”的工作思路，不断优化旅游发展布局、加快核心产品建设、完善公共服务设施、提升旅游主题形象，打响“仙作”“祈梦”“生态”旅游名片，使文化旅游产业成为县域经济发展新的增长点，是全国“工艺美术之乡”、“中国古典工艺家具之都”。释宏玉等代表提出的建设素食一条街、小吃一条街的建议，仙游县应加快美食城招商，有效汇集仙游特色小吃，开展仙游美食节、美食评选等活动，打响仙游美食品牌。

三、关于“建设老人文创园”的建议

我市高度重视文创产品开发工作，依托工艺美术、文化创意、传统技艺等优势，先后举办中国（莆田）海峡工艺品博览会、中国（仙游）红木博览会、世界木材日暨首届国际木文化节（博览会）、中国（莆田）油画产品世界订货会、“中国银饰之都” 银饰采购节等大型展览，为文创产品提供展销的平台。释宏玉等代表提出的为老年人提供手工、编织文化自创产品的建议，一方面要扩大文创知识产权宣传，广泛开展知识产权普及教育，提高老年人文创知识产权保护意识；另一方面，对老年人手工编织的文创产品，鼓励报名参加莆田特色文旅IP创意设计产品征集，入选产品所有人享有优先合作权，我局将通过产品授权并量产的产品组织参加全国各类活动展示销售。

四、关于“切实优化服务保障”的建议

我局将加强文化旅游品牌宣传营销，深耕巩固国内传统客源市场，开拓新兴客源市场，组织赴广东潮汕、江西南昌、浙江台州、湖南长沙等重要客源地开展“妈祖圣地 美丽莆田”文化旅游推介。举办“5.19”中国旅游日活动，组织参加第十八届海峡旅游博览会、2022福建旅游生活展及省厅组织的各类展会，不断拓展国内旅游市场；以举办第七届世界妈祖论坛及湄洲妈祖文化旅游节为契机，推进与主要客源地及港澳台文化旅游合作，提升对港澳台文化旅游业界人士接触层面，持续扩大莆田文化旅游在港澳台地区的知名度和影响力。
