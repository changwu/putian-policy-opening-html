关于市八届人大一次会议第0105号建议的协办意见

发布时间：2022-03-14 11:00
| | |
 市农业农村局：

郭雄新代表提出的《关于休闲农业和乡村旅游发展的建议》已收悉，我单位的办理意见如下：

一、关于“做好规划，打好乡村休闲经济健康发展的基础”的建议

我局将进一步整合乡村旅游资源特色，持续推进乡村旅游提质升级，积极推动全国乡村旅游重点村、省级全域生态旅游小镇和金牌旅游村培育创建工作，并评定一批三星级旅游村，鼓励发展乡村民宿旅游、A级旅游景区创建等，推进乡村旅游发展的新热点，持续打响乡村旅游知名品牌。

二、关于“制定政策扶持，营造乡村经济发展的良好环境”的建议

我局将继续实施乡村旅游品牌奖励政策，对乡村旅游村被评为国家4A级、3A级旅游景区，分别给予一次性奖励100万元、50万元；被评为省级全域生态旅游小镇和三星级休闲集镇，分别给予一次性奖励60万元、40万元；被评为省级金牌旅游村和三星级旅游村，分别给予一次性奖励30万元、20万元，重点扶持旅游村编制旅游规划和旅游基础设施项目建设，大力提升乡村旅游公共服务水平。

三、关于“加大对休闲农业和乡村旅游产业发展的资金扶贫”的建议

近年来，我局根据福建省《乡村旅游“百镇千村”三年行动计划》，全市共打造乡村旅游村107个，每个村均获得省级旅游专项资金补助20万元，用于乡村旅游规划和基础设施项目建设。目前，省文旅厅正在推进乡村旅游升级，大力培育全域生态旅游小镇、金牌旅游村，对获评全域生态旅游小镇称号给予20万元奖励，获评金牌旅游村给予10万元奖励，同时，市级专项资金也将给予另行奖励，大力扶持乡村旅游项目建设。

四、关于“树立品牌”的建议

我局将根据郭代表的建议，支持将现代农业项目、农产品加工、生态农业发展项目与乡村旅游等项目融合，对形成旅游条件的项目，鼓励申报市级观光工厂、职工疗休养基地。

五、关于“加快组建休闲农业和乡村旅游产业发展培训机构”的建议

近年来，我局高度重视乡村旅游人才培训工作，先后选送乡村旅游村干部30多人次参加省、国家组织的乡村旅游业务培训班，市里每年举办一期乡村旅游专题培训班，组织乡村旅游经营户、乡村旅游带头人、乡村旅游管理人、乡村旅游讲解员等各类实用人才培训，帮助乡村旅游村干部转变思想观念，提升文化素质和知识水平，提高乡村旅游管理服务能力。

六、关于“加强规范化管理，提高服务水平”的建议

我局将推动文旅市场治理、服务重心和执法资源向乡村下移，为乡村提供精准化、精细化旅游服务，指导各乡村旅游村规范旅游市场秩序，实施行政许可和行政处罚“双公示”，建立乡村旅游市场主体信用“红黑榜”，营造不敢失信、不能失信、不想失信的乡村旅游管理氛围，不断优化净化乡村旅游管理秩序，提高乡村旅游管理人员的服务意识和服务水平。

七、关于“加大宣传力度，促进产业发展”的建议

我局高度重视文旅宣传，加强莆田旅游资讯服务，以网络为平台，加强资信宣传，为疫后散客游、自驾游提供准确的休闲农业和乡村旅游产品信息。同时，加强与其他设区市文旅局微信公众号、旅游网站、12306等平台合作，开展莆田休闲农业和乡村旅游产品宣传推广，拓宽莆田休闲农业和乡村旅游产品的营销渠道。一是积极主动走出去拓展市场，组织休闲农业和乡村旅游经营单位参加第十八届海峡旅游博览会和2022福建旅游生活展，把休闲农业和乡村旅游产品作为在省外主要客源地举办的莆田文旅推介会重点推介内容；二是组织休闲农业和乡村旅游经营单位参加厦门海峡休闲旅游博览会；参加闽东北协同区域组织的市场促销活动，将休闲农业和乡村旅游为重要营销产品，不断扩大休闲农业和乡村旅游产品的知名度。
