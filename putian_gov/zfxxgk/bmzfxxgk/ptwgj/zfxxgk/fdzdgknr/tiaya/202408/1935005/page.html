关于市政协八届三次会议第20242053号提案办理情况的答复

发布时间：2024-07-19 17:02
| | |

陈国华委员：

您提出的《关于促进我市“双岛”文旅联动发展的建议》（20242053号）已收悉，现将办理情况函复如下：

莆田素有“七海二山一分田”之称，拥有湄洲湾、平海湾、兴化湾三大港湾和湄洲岛、南日岛两大岛，岛屿150多个，海域总面积1.1万平方公里，海岸线总长443公里，可开发港口岸线100公里，居民海岛11个，无居民海岛256个，浅海面积1032平方公里，滩涂面积281平方公里，可开发休闲旅游的沙滩20多处。近年来，市委、市政府高度重视滨海旅游业发展，立足港产城联动、陆海岛统筹、一二三产融合，努力推进世界妈祖文化中心和全国知名旅游目的地建设。

一、关于全面规划布局，加大政策支持的建议

莆田是妈祖文化的发祥地，妈祖文化是海上丝绸之路重要的文化纽带，妈祖信俗是我国首个信俗类世界非物质文化遗产；具有全国重点文保单位湄洲岛妈祖祖庙、平海天后宫、镇海堤等，省市级文保单位雁阵宫、贤良港天后祖祠、湄洲麟山宫、青峰岩摩崖石刻、南日岛烈士纪念碑等资源。当前，我市正在加快建设“海上莆田”，实施滨海旅游品质提升、海上牧场升级等专项行动，积极推动滨海旅游高质量发展。截止目前，共打造湄洲岛、天云洞、后海渔村、港里祖祠等16个A级旅游景区（5A级1个，3A级6个，2A级9个）、全国乡村旅游重点村1个、省级金牌旅游村4个、省市级职工疗休养基地5家，培育国家级休闲渔业示范基地2个、省级水乡渔村12个。我局已委托南开大学编制《莆田市滨海旅游发展规划（2022-2035）》，着眼于以湄洲岛为核心龙头，以南日岛为新的增长极，借助国道 G228 线上的“1 号滨海风景道”莆田段及滨海岸线，串联“三湾”精华资源，整体打造滨海旅游目的地，构建“两岛三湾一带一城”的滨海旅游大格局。湄洲岛、南日岛作为旅游资源最集中的两个核心岛屿，统筹着力重点开发双岛，强化湄洲岛核心带动作用，将南日岛打造成为新的增长极。目前，湄洲岛根据全市文旅发展规划布局和部署安排，积极融入全市滨海旅游发展大局，服务“双岛”文旅联动发展，特别是在旅游民宿发展、妈祖文化保护传承、节事活动举办、滨海文旅业态培育、旅游基础设施建设等方面积极与南日岛方面开展交流合作，形成思路举措互帮互助、业态培育互补互动、游客线路互推互送的具有海岛特色的差异性文旅产业链。秀屿区围绕海洋牧场建设，将南日镇“国”字号誉名称号纳入市委市政府重要推动事项，统筹规划、同步建设，全面启动秀屿区南日岛数字经济、海洋经济、绿色经济、文旅经济“四大经济”融合发展先行区建设，切实推进“两岸渔业”、“风渔”融合、“渔旅”融合、“渔光”互补、“宽带入海”、“海钓运动”等海洋牧场多产业融合绿色高质量发展，依托南日海岛休闲风情园(鲍鱼博物馆)、南日岛海堤渔旅融合示范基地等省级水乡渔村，整合深海装备、旅游餐厅、塑胶渔排、渔港渔船、公务船艇、品牌展馆、电子围栏、垂钓运动、宾馆民宿、名胜古迹、海岛山水、滨海沙滩等优质资源，打造集蓝色、红色、绿色、黄色四色一体的生态海岛型精品旅游路线，形成具有海洋文化与渔业文化特色的渔旅融合发展新格局。

二、关于强化人才培育，促进服务升级的建议

（一）加大文旅产业人才招引，围绕全市十三条重点产业链发展技能人才需求和重点群体就业技能需求，制定《2024年度莆田市“壶兰工匠”万人职业技能提升培训计划》，依托行业协会、职业院校、企业职工培训中心等，以产业人才技能等级水平提升为导向，开展形式多样的职业技能培训，为各类劳动者提供更有针对性的技能培训服务，着力提升产业人才队伍技能素质。全年计划开展企业职工培训3410人次，其中支持文旅经济产业技能人才培训490人次。

（二）用好用足中央及省、市人才政策，围绕我市文旅产业发展，引进一批文旅领域高层次人才和紧缺急需人才。研究制定关于加强高素质文化和旅游人才队伍建设的意见，统筹推进各类文旅人才队伍建设。

（三）制定文旅人才培训方案，举办2023年全市乡村旅游、导游人员等文旅职业技能培训班，组织市、县区（管委会）两级旅游业分管负责人、文化旅游部门负责人、旅游重点乡镇负责人、文化旅游企业负责人以及智慧旅游、市场营销、旅游策划、旅游规划创新人才等参加培训，提升文旅人才职业技能水平。

（四）印发《2023年“技能莆田”万人职业技能培训“十大计划”实施方案》，围绕文旅产业发展技能人才需求，实施产业技能人才培训计划、“乡村工匠”人才培训计划等，拟选送300名文旅经济人才、100名乡村旅游农村文化人才参加培训，保护和传承乡土文化。

（五）南日镇组织召开民宿联盟、自媒体联盟成立仪式暨第一届会员大会，共有60余名民宿业主及自媒体达人、返乡青年参加。联盟的成立填补了行业的空白，建立健全了管理机制，积极发挥联盟平台、纽带和桥梁的作用，做好提优服务、提质增量、提档升级等工作，做到有组织架构、有阵地保障、有行业规则，有计划有步骤推进问题解决，破解行业瓶颈，从行业发展的“新岛人”变成文旅繁荣的“兴岛人”。定期举办“海岛青年说”交流会，邀请省自媒体协会、区委网信办、自媒体达人、本岛民宿业主及自媒体爱好者共同参加，为有意助力家乡发展的海岛青年们搭建互帮互助、互通有无的平台，滴水成海、形成合力，让青年群体在海岛乡村振兴中发挥澎湃力量，助力文化旅游和乡村振兴特色产业转型升级。

（六）湄洲岛按照文旅发展规划布局，在强化自身文旅人才引进、交流、培育的基础上，探索建立人才交流机制和实施“种子”工程，落实人才引进优惠政策，进而加强人才储备和产业发展智力支撑。

三、关于强化宣传质效，打造文旅品牌的建议

（一）积极培育滨海旅游品牌。随着湄洲岛、南日岛等滨海旅游快速发展，我市滨海旅游品牌建设取得显著成效。湄洲岛先后获评国家旅游度假区、国家5A级旅游景区、国家级风景名胜区和福建省滨海休闲度假福地、港澳青少年内地游学基地、5钻级智慧景区等品牌。南日镇被评为省级全域生态旅游小镇，港南村被评为省级金牌旅游村，海山社区被评为市级金牌旅游村，福建东禹海洋健康食品有限公司被评为市级观光工厂，九重山被评为3A级旅游景区，新增南日岛烈士纪念碑、浮叶村、皇帝山3家2A级景区。

（二）丰富文旅产品宣传渠道。为方便广大游客查找和预订莆田文旅产品，我市开发上线了“这就是莆田”数字文旅平台，并加强与携程等各大互联网平台的合作，上线“这就是莆田”携程星球号旗舰店。同时，秉承“互联网+文旅”的理念，充分利用好各类新媒体平台，如微信公众号、微博、抖音以及相应的短视频等，充分运用好互联网传播速度快、受众面广、参与程度高等特点，采取线上传播和线下活动相结合的方式，提高景区的曝光率和网民的关注度。加强与传统主流媒体的合作，做好全年常态化合作，扩大文旅品牌效应。注重精准营销，通过微信朋友圈广告进行广告投放，“妈祖圣地·美丽莆田”文旅品牌首次在铁路12306“城市之窗”平台展播，达到精准市场推广的目的。

（三）加大渔旅宣传推介力度。邀请中央、省、市多家主流媒体进岛拍摄，包括央视1套《三餐四季》、4套《远方的家》、17套《田园帮帮团》等栏目组，借助撒贝宁、刘玉栋等名人效应和主流媒体平台进一步扩大海岛渔旅融合知名度和美誉度，累计在各主流媒体品牌刊登新闻上百次，旅游热度持续攀升。成立南日镇自媒体联盟，整合全域自媒体力量，助力线上宣传百花齐放。同时计划邀请自媒体达人开展南日岛旅游vlog拍摄，带话题式在多平台投放，分析往年游客数据，对福建、江西、湖南等地针对性投放引流，为夏季海岛旅游做预热，营造南日岛滨海旅游热度。

（四）打造海上精品旅游线路。“福往福来”湄洲岛至南日岛海上游线自2023年4月28日首航以来，已累计开行2个航班。目前，游客对湄洲岛至南日岛海上航线关注度较高，我局将进一步指导湄洲岛与秀屿区密切协同，加大与我市各大旅行社的合作力度，共同宣传推介该条海上游线，努力推动“福往福来”湄洲岛至南日岛海上游线的稳定持续运营，积极融入全市滨海旅游发展大局，服务“双岛”文旅联动发展。
