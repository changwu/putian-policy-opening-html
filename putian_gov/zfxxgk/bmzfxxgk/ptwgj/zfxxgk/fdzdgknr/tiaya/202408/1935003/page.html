关于市政协八届三次会议第20242023号提案办理情况的答复

发布时间：2024-07-19 16:59
| | |

杨碧静委员：

您提出的《关于深化文旅互促赋能乡村振兴的建议》（20242036）已收悉，现将办理情况函复如下：

一、关于科学规划、重点突破的建议

我市重视加强乡村旅游顶层设计，把乡村旅游纳入旅游产业发

杨碧静委员：

您提出的《关于深化文旅互促赋能乡村振兴的建议》（20242036）已收悉，现将办理情况函复如下：

一、关于科学规划、重点突破的建议

我市重视加强乡村旅游顶层设计，把乡村旅游纳入旅游产业发展的总体规划加以推进，大力促进“旅游+”产业深度融合，培育工艺美术、食品加工、海洋养殖、基地农业、生态农业、景观水利等特色产业，力争建设一批文化旅游产业标杆基地，以此带动文旅产业融合发展。注重点面结合，突出重点，分类指导，将现代农业与文旅相结合，深入挖掘乡村文旅资源，积极打造乡村文化品牌，让乡村文化焕发生机，指导支持旅游村非遗传统文化的活化利用和创新发展，推进全国乡村旅游重点村、省级全域生态旅游小镇和金牌旅游村创建培育工作，全市现有全国乡村旅游重点村3个、省级全域生态旅游小镇7个和金牌旅游村15个。今后，我局将在指导推进乡村旅游规划编制过程中，更加重视“乡土文化、乡愁符号”的保护与传承；注重整合革命红色遗址、地域非遗、莆田四大名果等各类资源，挖掘风土人情特点，充分体现乡村旅游资源的乡土味，同时要求乡村旅游规划充分征求农业、自然资源、生态环境、住建、林业、文旅等部门的意见，确保乡村旅游规划的差异性、落地性和可操作性。在推进乡村旅游产品建设中，注重借鉴江西婺源、浙江省乌镇等国内一些最具典型性、代表性的乡村旅游案例。在推进乡村旅游资源开发中, 坚持抓特色、抓重点, 客观评估乡村旅游资源层次, 不盲目求全求大, 在创意设计中注重保持旅游资源的原始与真实性、展示美学特征。如：民居修复、文物维护、民宿、餐饮等方面处处体现乡村特点，外观保持民房原始质朴, 屋前有菜园可随手采摘；农产品保持原汁原味、新鲜果蔬、山珍海味和地方特色；餐饮选用乡村传统食材, 保证食品安全、无污染等，增强游客的满意度。同时，以乡村旅游标准化为抓手，持续完善旅游厕所、乡村文旅服务中心等旅游服务体系，推动妈祖文化、传统老字号、非遗工艺、农土特产、工艺美术开发文化创意产品进景区，不断提升产业效能和附加值，促进全市乡村旅游高质量发展。

下一步，我局将积极探索建立健全各种行之有效的机制，围绕“一村一品、一村一韵、一村一景”的特色，不断完善提升乡村特色文旅产业与乡村景观建设， 打造一批特色鲜明、吸引力强的农文旅融合精品。一是合理利用。从生态功能入手，把景观作为一个生态系统，合理利用当地土地资源及水资源的的使用，以生态适宜和环境承载力为基础，对能源、材料进行合理再利用。二是拓展思路。在乡村景观的开发中，依据当地文化传统特色，打造个性乡土景观，开发体验式乡村旅游。将乡村的原生态生活展现给游客，既保存当的文化生活习俗，还可带动乡村经济的发展。三是发挥主体。在今后的乡村旅游产业营造中，让村民成为乡村建设的主体，鼓励村集体利用资源优势和社会企业合作，成立农村集体经济控股公司，对集体资产进行清产核资，稳步推进农村集体资产入股，探索多样化发展途径，推行资源发包、资产参股等多种模式，探索“资源变资产、资金变股金、农民变股东”，让集体资产“活起来”，激发乡村文旅产业活力。

二、关于文化搭台、旅游唱戏的建议

在推进乡村旅游发展过程中，合理利用现有农业资源，支持将现代农业项目、生态农业发展项目与乡村旅游等项目融合。对形成旅游条件的项目，鼓励申报市级观光工厂、研学实践教育基地、职工疗休养基地等。着力构建以文化旅游为主要标志的都市型特色现代农业，支持仙游县游洋镇天马村，以发展乡村旅游为抓手，充分挖掘临近高速出口的交通便捷优势、天马古厝等众多传统村落和郑樵后裔唯一集居村的文化优势、石门峡谷和天马山优美风景的山水资源优势，推动“石门峡谷+天马山+传统村落+田园风光”串点成线，围绕“登游洋天马山，打卡石门峡谷，夜游天马古厝”设置一日游路线，打响“道口新邑，山水天马”品牌，助推乡村振兴，打造乡村旅游“新名片”。支持荔城区北高镇推进山前村九十六港田园综合区建设，着力打造以“四季花海”为主题的休闲农业以及集休闲旅游、亲子教育、劳动教育为一体的“网红”打卡点；引进一鑫生态农业项目，以一鑫生态农业示范基地为中心，深入开发汀峰村绿都蔬菜合作社、江边村美丽乡村生态园等产业基地,打造独具特色的北高现代农业示范区；基地实施仿太阳夜间催花补光新技术，不仅可实现全年挂果采摘，经济效益可观，还成为独特的夜间“灯光秀”，为当地增添一道亮丽的风景线。火龙果产业的发展，带动了周边村民就近务工，拉动了生态采摘游，火龙果成了村民们的“致富果”。实施“后备箱”工程，着力将乡村农产品、手工艺品转化为旅游商品，丰富旅游商品名录。鼓励在全国重点乡村旅游村、金牌旅游村等建设特色旅游商品店，展销枇杷膏、枇杷罐头、兴化粉、莆田桂圆干、鲍鱼干、荔枝干等。在涵江区萩芦镇成立萩芦文旅产业投资有限公司，发布区域公共品牌“五彩萩芦”，含龙眼、枇杷、樟洋大米、梅洋茗茶、南坛蜂蜜等农特产品，借助举办萩芦龙眼文化节、云端枇杷文化节、茶文化节等活动，推出“枇杷四宝”“梅洋清茗”“五彩福粽”等农特产品，帮助农民增收致富，推动农业和旅游深度融合。

下一步，我局将推动莆仙戏融入乡村旅游，推出具有复合实景演艺特色的文旅融合创新项目，推动莆仙戏演出进景区、进街区、进社区活动，在三清殿建设融文化创意、公益研学实景演出、非遗民俗古厝文化展等全新演艺、全景互动于一体的“莆田城市会客厅”，探索打造花船展示、状元游街等的沉浸式、互动式、研学式文旅体验演艺活动。支持符合条件的旅游演艺项目申报国家艺术基金，支持湄洲岛《祥瑞湄洲》等旅游演艺项目优化升级，创新升级“湄洲之夏”沙滩音乐节、平安塔秀等音乐活动，不断提升影响力和知名度。

三、关于多元融合、突出主题的建议

我市古街、古村、古建筑等资源丰富，据统计（不完全）具有莆阳特色、明清特色和中西合璧的古厝老房就超30处以上，特别是仙游县前连村、荔城区后黄村、涵江区江春霖御史故居、后坡明清古民居等古厝建筑风格独特、占地面积较大。目前，在“保护第一，合理开发”的前提下，坚持古村落保护与适当开发旅游的协调发展，有的乡村旅游发展较快，比如：荔城区西天尾镇后黄村，古民居保护得较为完整，经过适当修缮，结合农业休闲、农产品采摘，吸引众多游客前往观光。涵江区江口镇东大村姚馀三故居，是东大村最早的华侨私人住宅，为更好地传承和弘扬华侨文化，已改造装修为“廉善传家”侨乡家风家训馆，通过全面系统地展示先贤优良的传统美德，弘扬真善美、传递正能量，已成为涵江区廉政文化教育基地、蒜溪南洋文创小镇的标志性景点之一。仙游县国家级历史文化名村济川村，重视古建筑的保护，先后投入大量资金，组织能工巧匠对天堂宫、云山书院、于茂故居、拾德堂、枪楼、云潭古民居等进行保护性修缮。同时，全市按照“布局美、环境美、建筑美、生活美”要求，建设“宜居宜业、宜观宜游、特色突出”的美丽乡村，注重将古村落保护与美丽乡村建设相结合，通过科学规划，打造“一村一韵、一村一景、一村一品、一村一业”，呈现莆仙乡村风格和地域特色。其中：仙游县书峰乡立足于乡域特色，利用现在“一所一道一塘一园”风景点，打造富有特色的生态休闲旅游乡村；荔城区西天尾镇后黄村以“古屋、美景、自然、乡情”的空间布局，整合侨乡文化、民俗文化、饮食文化，发展特色郊区农业；城厢区华亭镇埔柳村大力发展花卉种植、果品采摘、生态餐饮、观光旅游等项目，体现“田园性”、“乡村性”、“生态性”。积极鼓励传承人创建各类传承基地，目前全市拥有国家级非遗生产性保护示范基地2个、国家级非遗保护研究基地2个、省级非遗生产性保护示范基地2个、福建省生产性保护重点传承单位2个和市级非遗传承基地（传习所）81个。基地以“非遗+企业”“非遗+校园”等多种“非遗+”结合模式，将木雕、戏曲、十音八乐等非遗文化融入课堂、企业、社区，每年近20万人参与学习。莆田市非遗展示厅常年免费开放，运用地面互动投影、幻影成像等科技手段展示非遗项目，将非遗的单向传播转化为双向的人机交互，助推参与者沉浸式体验非遗表演过程，累计接待青少年研学体验达100多万人次。制定莆仙戏高质量发展实施方案，实施“名师传艺”工程，支持12位名师以“师带徒”方式结对培养莆仙戏人才。传承基地的建立，对进一步加强妈祖文化、南少林武术、各类传统工艺的宣传推广，弘扬中华优秀传统文化，让大众了解非遗、爱上非遗，为非遗项目培养接班人起到积极的推动作用。

下一步，我局将组织开展“美好乡村等你来”乡村旅游数字提升行动，实施“看见”乡村好风光、“游购”乡村新消费、“培育”乡村内生力、“展示”乡村新成果等四项重点任务，开展乡村旅游推介、直播销售乡村旅游产品、培训提升从业人员数字新媒体能力、宣传提升行动成果。完善乡村文化设施，建设一批乡村戏台、农民文化公园等，推动“中国民间文化艺术之乡”建设，继续挖掘乡村文化资源，培育一批乡村文化振兴典型村，植入非遗技艺、特色民俗、乡土文化展示推广、旅游体验等功能，提升乡村文化内涵。

四、关于加强管理、加大保护，开展专业人才培训的建议

近年来，我市立足文源深、文脉广、文气足等特点，把文化元素有机植入旅游产品，着力激活文化基因，着眼于让文物和文化遗产活起来，推进“文物+旅游”“非遗+旅游”，打造全省首个“非遗一条街”，非遗市集、民俗演艺、非遗美食等非遗产品火爆出圈。创新文化赋能，莆仙戏《踏伞行》选段亮相央视春晚，三清殿莆仙戏传习所开展沉浸式演出48场、非遗研学30场。以百姓大舞台、乡村“村晚”等品牌活动为引领，成功举办各类群众性文化活动1865场次。实施绿心综合开发，利用绿心水系河道资源，串联推出5条“水上巴士”航线，培育荔林水乡生态旅游新业态。推动九鲤湖—九龙谷融合发展，霞客古道互联互通，两大景区实现资源共享。开发沉浸式体验式项目，“金秋水韵·月下白塘”国风主题游园会、沙滩露营文化节等系列活动人气爆棚。重视乡村旅游人才培训工作，研究制定《关于加强高素质文化和旅游人才队伍建设的实施方案》，统筹推进各类文化和旅游人才队伍建设，着力打造一支具有专业知识、专业能力、专业作风、专业精神的高素质文化和旅游人才队伍。制定《2023年全市文旅系统人才培训计划》，开展文化系列专业技术人员继续教育培训。开展莆田市第十二届文化系列中初级职务评审工作，共有8人获得文化系列中级专业技术职务任职资格、25人获得文化系列初级专业技术职务任职资格。举办莆田市全域旅游导游（讲解员）专题培训班，进一步加强导游（讲解员）队伍建设，全方位提高旅游服务质量。实施文化旅游人才培训行动计划，组织开展全市乡村旅游、导游人员、乡村文化振兴、文化市场综合执法业务等文旅职业技能培训班，提升文旅人才职业技能水平。配合省文旅厅开展乡村文化和旅游带头人选拔工作，积极向中央和省文旅厅推荐文旅系统优秀人才。

下一步，我局将进一步做好古村落保护和乡村旅游开发，把古村游作为精品乡村旅游线路大力推广，不断提高古村落的人文影响力。精心打造一批地方特色品牌，积极探索“莆仙文化+文物+非遗+民俗”等模式，培育“一县区一品、一镇一品、一村一品”特色文化品牌，进一步推进“水上巴士”沿线乡村旅游发展，通过打造双福村、白塘湖、萝苜田历史文化街区、吴江村、北大村、东阳村等文化特色鲜明的旅游休闲乡村和街区，让莆田文旅产业动起来、活起来、旺起来。加强乡村旅游业务培训，选送乡村旅游村干部参加省、国家组织的乡村旅游业务培训班，帮助乡村旅游村干部转变思想观念，提升文化素质和知识水平，提高乡村旅游管理服务能力。

五、关于加强宣传、拓展渠道，扩大乡村旅游的影响力的建议

（一）创新文旅宣传方式。实施精准营销，不断提高莆田文旅知名度、影响力。做强全媒宣传矩阵。开展“莆田市长带你游”活动，提高了关注度，带来了流量，形成了声势。推出“莆阳开春”“莆阳爽夏”“莆阳赏秋”系列文旅活动，全网累计总曝光量超1亿人次。央视《非遗里的中国》《山水间的家》《三餐四季》等热播，《一代匠师》央视同时段收视率全国第一，莆田元素“热辣滚烫”。做热重点事件营销。以建市40周年为契机，发布莆田城市LOGO、城市吉祥物和城市宣传口号，提升城市品牌影响力。策划推出100余条旅游线路，邀请海峡两岸100多家重点旅行社组团来莆考察。结合四季文旅市场，推出枇杷、荔枝、龙眼、文旦柚等特色水果文化节，策划举办中国·南日岛全国海钓邀请赛、雪津啤酒旅游美食季等一系列主打休闲、娱乐的互动式体验活动40余场，构筑四季全时旅游产品体验。

（二）搭建展示推介平台。以专业化、品牌化、国际化为导向，运用大数据、人工智能等现代技术手段方面，做大做强中国文化和旅游产品交易博览会，组织开展全国文化和旅游创意产品推进活动，全方位宣传定制化的文旅产品，提高莆田文旅产品的吸引力和人气度。开展莆田特色文旅IP、创意设计产品征集活动，助推我市文化旅游产业高质量发展；发挥全国图书馆文化创意产品开发联盟成员馆的优势，结合馆藏资源特色开发“莆阳日历”等文创系列产品；举办莆田市首届文物博物馆文化创意产品创作大赛，通过文化创意开发衍生产品，更好地弘扬我市传统文化内涵；举办妈祖文创设计大赛，两岸青年交流创意想法，把中国传统道德典范如立德、行善、大爱等精神发扬光大；湄洲岛妈祖文创产品续6年亮相中国（莆田）海峡工艺品博览会。在莆田市博物馆开设“莆仙印象”莆仙文化原创伴手礼实体店，向世界传播莆仙之美。

（三）加强乡村文旅宣传。与省旅游频道等主流媒体合作，制作播出乡村旅游专题宣传片，重点对后黄村、坪盘村、济川村等15个“金牌旅游村”进行系列宣传推介，加大乡村旅游宣传推介力度。利用莆田文旅微信公众号、抖音等平台，整合全市优质乡村文旅资源，策划推出了多条微度假、毕业季、亲子游、红色游、美食游等丰富多样的旅游线路，不断丰富产品供给，延伸产业链条。注重重要节会活动聚人气、树品牌、创特色的效应，办好“莆阳开春”“莆阳爽夏”等重点文旅主题活动，全面做好乡村旅游宣传推广。借助在主要客源地举办的推介会和各类文旅展览展会平台，展示我市乡村旅游发展的新面貌、新成果和新亮点，进一步树立我市乡村旅游特色品牌。

下一步，我局将进一步加大文旅宣传，加强莆田旅游资讯服务，以网络为平台，加强与其他设区市文旅局微信公众号、旅游网站、12306等平台合作，开展莆田休闲农业和乡村旅游产品宣传推广，拓宽莆田休闲农业和乡村旅游产品的营销渠道，组织休闲农业和乡村旅游经营单位参加海峡旅游博览会、福建旅游生活展等，把休闲农业和乡村旅游产品作为在省外主要客源地举办的莆田文旅推介会重点推介内容，不断扩大休闲农业和乡村旅游产品的知名度，依靠基层政府对村民进行宣传，努力提升村民的主人翁意识，将村民从城市的漂泊中引流回乡参与乡村旅游开发和管理服务，助力乡村振兴。
