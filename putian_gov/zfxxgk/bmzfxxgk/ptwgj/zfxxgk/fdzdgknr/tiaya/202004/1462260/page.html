关于市七届人大二次会议第1012号建议的答复

发布时间：2018-05-07 10:28
| | |

谢庆春等代表：

你们提出的“关于建议加大仙游县文物保护力度的议案”（第1012号）收悉，现答复如下：

近年来，在省文化厅、文物局的有力指导下，市委、市政府的正确领导下，我局始终高度重视文物保护工作，坚持“保护为主、抢救第一、合理利用、加强管理”的文物工作方针，全力做好文物保护、利用和管理工作，有力地促进了仙游县文物保护工作持续健康发展。

一、主要措施与工作成效

（一）落实安全制度。全面强化文物保护主体责任，完善“四有”档案，落实莆田市文物安全五项制度，主动联系公安消防部门，组成联合检查组，采取重点必查与面上抽查相结合的办法，有计划、有频率地对全部国保、省保、部分市保、县保、博物馆、历史文化名村、街区和传统村落进行检查。综合应用人力、物体、技术防范三个方面措施来加强安全管理工作，防范消防事故。人防方面，要求各地配备专职安全员进行巡查；物防方面，要求对香烛烟花等施行集中地点燃放、隔离易燃物、张贴“禁止烟火”警示标识等；技防方面，要求添置消防灭火器材、配备蓄水池、规范用电线路，大力推进改造老旧线路的工程。

（二）多方筹资维修。采取“财政补助、上级争取、民间筹措、个人赞助”四方结合的资金筹集办法，广泛发动社会各界参与文物保护工作。近三年，积极向上级争取文物专项补助经费571万元用于仙游县文物保护单位保护工程，市级财政配套补助资金多向仙游县倾斜，每年补助金额占全市文物保护专项资金总额的三分之一以上。根据《中华人民共和国文物保护法》、《全国重点文物保护单位文物保护工程申报审批管理办法（2014试行）》和《福建省文物保护工程立项和技术方案管理规定》要求，结合文物保护实际情况，我局指导各级文保单位管理机构编制相应的保护规划和维修设计方案，规范文物修缮工作。编制国保单位仙游文庙保护规划立项、龙华双塔保护规划和修缮方案及仙游文庙、天中万寿塔等安防方案，省保单位三会寺、陈谠墓维修工程设计方案；邀请专家实地指导革命遗址石苍高阳温氏祠堂、林氏大宗祠修缮事宜。完成国保单位无尘塔维修工程，国家级历史文化名村仙游济川村列入2016年省重点保护项目，省级补助资金500万元，地方政府配套500万元，启动环境整治工程。

（三）申报提升级别。开展全国重点文物保护单位、省级文物保护单位等各类文化遗产申报工作。成功申报仙游文庙、龙华双塔为第七批全国重点文物保护单位；埔坪陈氏墓、兴角宫、瑞云祠李耕壁画为第八批省级文物保护单位；仙游济川村成功列入国家级历史文化名村；赖店镇留仙村、游洋镇上头集厝自然村、西苑乡柳园村等3处村落被公布为福建省首批传统村落。同时，选择具有较高历史、艺术和科学价值的仙游林氏大宗祠、九鲤湖摩崖石刻、东门纠察庙、东石土楼、云山书院壁画等9处文物保护单位推荐申报第九批省级文物保护单位，并配合省文物局专家组现场复核，现有8处纳入公示名单，近期省政府将发文公布。

（四）加大宣传力度。把文物法规宣传作为一项经常性的工作来抓，加大对“一法两条例”的宣传力度，形成较为浓厚的社会舆论宣传氛围。注重对各乡镇（街道）领导干部和文物保护管理机构人员的宣传，每年至少召开一次文物保护和安全工作座谈会，举办业务培训班，提升业务技能和水平。同时，注重对基层广大群众的宣传，尤其是加强对施工单位的宣传，避免施工过程中对文物造成破坏，利用新闻媒体、宣传标语、发放宣传材料、图片展览等方式加大文物法规政策宣传力度，增强全社会的文物保护意识和法制观念。

（五）完善管理机制。市、县都成立了文物管理委员会，加强对文化遗产保护利用工作的领导，各乡镇相应成立保护管理机构，负责辖区内文物保护工作的统筹协调，乡镇综合文化站、村级文化协管员也兼负文物保护职责，做到层层落实责任。民间还自发组织众多的文物保护机构，成立了全省第一家市级文物保护协会。从整体上看，我市、县区、乡镇、村四级文物保护联动机制已经初步建立。

二、下一步工作思路

（一）以保护规划为抓手，加大保护力度。根据《中华人民共和国文物保护法》第八条“地方各级人民政府负责本行政区域内的文物保护工作。县级以上地方人民政府承担文物保护工作的部门对本行政区域内的文物保护实施监督管理。”的规定，按照文物保护属地管理的原则，我局将继续支持、指导和协助仙游县文化（文物）部门做好辖区内各级文物保护单位的保护规划、维修方案等编制工作，促进文物保护工作科学、有序发展。

（二）以专项资金为抓手，加大经费投入。加大文物保护专项资金投入仍需全社会共同参与和多方筹资，根据现行财政管理体制，一级政府一级财政，今后市财政将依据《中华人民共和国文物保护法》的有关规定，视市级财力情况，逐步加大对县区文物保护专项资金的补助力度，力所能及地解决县区财政困难。我局也将积极争取国家、省级文物专项资金支持，并发挥市文物保护协会和民间文物管理机构的作用，广泛发动社会捐资，继续实施文物保护工程项目，不断提高文物的完好率。

（三）以政策制度为抓手，强化保护机制。全面落实《莆田市关于进一步加强文物工作的实施意见》和市文物保护五项制度，制定出台《莆田市关于进一步加强文物安全工作的若干措施》，进一步明确文物保护主体责任，强化监管，守土尽责，有效开展文物行政执法工作，积极配合公安、边防、工商等部门，打击文物违法活动，做好防火、防盗、防破坏、防不按原则维修等文物安全工作。

（四）以联姻媒体为抓手，创新宣传形式。充分利用文化和自然遗产日、国际博物馆日、“七·五”普法日等节庆日，依托电视、报纸、网络、手机等媒体多形式、全方位开展宣传活动，加大文物普法和保护文物的宣传力度，扩大宣传教育普及面，营造全民关心文物保护，支持文物保护，参与文物保护的良好社会氛围，提高全民参与保护文物的意识和观念，使文物保护的历史使命感、责任感深入人心。

（五）以专业培训为抓手，提升保护水平。加强文物行政管理人员的各类培训，提高文博管理和专业队伍的政治、法律、科学和业务素质，举办文保人员培训班，进行文保知识、安全防范等方面的培训，提高安全防范能力。充分发挥市文物保护协会等民间组织的作用，进一步完善文物保护专家咨询制度，重视民间匠人传统技艺的挖掘、保护与传承，发动社会力量，培养一批技艺精湛的文物保护专业工匠和文物保护管理人才。
