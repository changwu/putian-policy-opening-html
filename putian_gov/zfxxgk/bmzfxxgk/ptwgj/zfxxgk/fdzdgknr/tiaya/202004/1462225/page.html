关于市七届人大一次会议第30号建议的答复

发布时间：2017-05-12 11:12
| | |

刘亚勇等代表：

    您们提出的“隆重纪念抗元民族英雄陈文龙的建议”（第30号）收悉，现答复如下：

陈文龙是莆田历史上重要的文化名人，他以状元之身，宰辅之尊在宋末国家危亡之际坚守本心，秉持忠义，以兴化孤城抗拒元朝大军，为宋室南奔粤海，延长国祚争取了时间。在被叛受俘之后，坚持气节，拒不仕元，绝食明心，在岳庙恸哭身亡，葬于杭州。他身上流露出的优秀而传统的中华民族美德受到后世景仰：“岳墓松不北向，陈墓坟生刺竹”的传说将其与岳飞并提；林则徐赞其“隆名与信国并峙”，将他和文天祥同列；邑人张琴更称他为“西湖三忠肃”，使其和岳飞、于谦共荣。今年正值陈文龙殉难740周年之际，在此时纪念陈文龙忠义满怀的爱国主义情操和不朽的民族气节，对于提倡大力弘扬中华民族优秀传统文化的今天有着重要的意义。我局结合代表建议、立足本职工作、发挥文化职能方面做了以下工作：

一、开展艺术创作，再现人物风采

充分发挥引领文化创作的职能，通过艺术创作手法，塑造人物形象，展示英杰风采：一是今年全力创作编排莆仙戏《陈文龙》，该剧剧本由剧作家陈道贵创作。已完成省、市两级文史学者、莆仙戏研究专家、剧作家、剧评家、戏剧研究学者论证。目前正在根据省市专家论证意见进行修改提升，争取以艺术性、历史性、可看性三者高度融合的面貌出现，打造舞台精品，弘扬地方优秀历史人物事迹。二是我局结合玉湖陈氏宗祠文物风貌和玉湖陈氏历史名人陈俊卿、陈瓒、陈文龙等史迹拍摄的《玉湖陈》专题纪录短片于2017年春节期间，在莆田市广播电视台、腾讯视频等媒体机构播出，利用影视纪录、传播的手法广泛宣传玉湖陈氏的忠烈节义和陈文龙、陈瓒的爱国情怀，受到了广大市民的普遍好评。

二、加强学术研讨，挖掘历史底蕴

鼓励、支持社会力量开展陈文龙学术研讨，为深挖人物的历史底蕴，普及人物形象提供便利。一是利用“全国社科普及基地”莆田市图书馆分馆莆阳书院莆阳讲堂积极推广抗元英雄陈文龙的相关事迹，烈烈英风。自2016年起，市图书馆多次邀请地方文史专家陈天宇先生、许元松先生在莆阳讲堂做《千秋节义愧当时——陈文龙祭》、《陈文龙故事》、《玉湖家风和二忠精神》等学术普及讲座，向广大市民传播陈文龙事迹，弘扬陈文龙爱国主义情怀，受到广大市民的欢迎，取得了良好的社会效果。二是近年来，市图书馆向社会征集、收集地方文献，尤其注意对陈文龙相关文献的收集。目前已收集有《玉湖陈氏》、《玉湖陈氏家庙族谱》、《莆阳玉湖陈氏家乘（三卷）》、《玉湖世泽》、《纪念爱国民族英雄陈文龙》、《宋民族英雄陈文龙：论文集》、《南宋民族英雄陈文龙：莆仙戏剧本初稿》、《海峡两岸纪念民族英雄陈文龙丛书·研究论文集、诗联散文集、摄影绘画集》等相关文献，有利于地方学者到馆查阅，加强陈文龙相关史迹及影响的研究。

三、开展民间合作，拓宽宣传渠道

支持玉湖陈氏理事会有关弘扬抗元英雄陈文龙事迹方面的对接交流合作工作。一是市非遗中心协同玉湖陈氏理事会成员至谷城宫商讨陈文龙纪念与杨公太师出巡结合的问题，因民间信俗的难以革新，暂时无法完成融合。但了解了谷城宫与陈文龙的历史渊源，对于后续开展陈文龙信仰研究起到了一定的帮助。二是组织有关文史人才与玉湖陈氏理事会就五月西湖祭墓进行详细的行程、仪规探讨，并与杭州市文广局联系，取得支持和协助，陈氏后裔祭墓活动提供了便利。三是三清殿与兴化府城隍庙董事会、玉湖陈氏理事会在2017年5月1日至5月8日举办纪念陈文龙、陈瓒殉国740周年书画作品展。本次展览通过陈文龙、陈瓒二忠事迹绘画作品、名家书法作品、名家画作等集中展现了陈氏二忠舍身取义、杀身成仁的爱国精神，吸引了广大群众到场参观，在潜移默化间完成了一场深具意义的爱国主义教育。

今后，我们将借着大力弘扬地方优秀传统文化的良好机遇，奋力有为，扎实推进莆仙优秀文化、历史人物资源研究，广泛开展与民间组织的交流宣传活动，为把优秀地方文化、历史名人文化资源更好地融入“美丽莆田”建设中做出更大的努力。
