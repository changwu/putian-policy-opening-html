关于市政协六届四次会议第2015123号提案办理情况的答复

发布时间：2015-07-17 08:00
| | |

卓银妹委员：

你提出的关于规范发展中老年人健身场所的建议（第2015123号）收悉，现将办理情况函复如下：

我局十分关注中老年人文化娱乐生活，从硬件、软件等方面加强文化建设，着重做好以下几个方面工作。

一、推进文化激情广场示范点建设。充分发挥激情文化广场在丰富群众文化生活中的积极作用，目前，全市在城乡已建设115个文化激情广场示范点，每个点4万元左右的扶持经费，用于场地设施改造和添置音响、灯光演出器材。同时，为推动全市文化激情广场健康、有序的发展，要求达到“六个有”的规范，即有统一命名、有管理制度、有骨干队伍、有音响设备、有表演团队、有组织开展活动。

二、在农村建立公共文化服务场所。我市在县区建立文化馆，乡镇建立文化站，在各村设立文化协管员，每年定期开展协管员培训，不断提高农村文化协管员的综合素质，提升农村文化协管员的业务能力，为中老年人的健身活动及文化艺术休闲提供业务指导。

三、开展中老年人公益性艺术培训。积极推进全市公益性的艺术培训。2014年全年，市艺术馆开设免费艺术培训课程10个，其中广场舞培训课程达108班次，受益群众达560人次。2015年，为进一步丰富中老年人休闲娱乐生活，市艺术馆开设广场舞、健身球、拉丁舞、古典舞、休闲舞、秧歌、健身舞、流行舞蹈、民族民间舞、古筝、竹笛、民族打击乐、二胡、书法、国画等课程。

四、坚持文化惠民，打造群众文化活动品牌。开展“我的舞台·我的梦”，组织广场舞比赛、十音八乐比赛、合唱比赛等文艺比赛；实施“文化助梦人才培训工程”，开展艺术培训，提高群众文化生活质量；举办“乡音·乡情·乡愁民俗文化艺术节”，开展丰富多样的文化艺术展演活动。同时，不定期开展书画展、摄影展，丰富中老年人的文化生活。

五、加强与各部门合作为中老年人提供更好的服务。市艺术馆与莆田学院、市老年大学以及周边各社区合作共建，资源互补，为更多中老年人提供优质、良好的服务。
