关于市政协六届四次会议第2015109号提案办理情况的答复

发布时间：2015-07-17 08:00
| | |

黄叶等委员：

你们提出的关于莆仙方言辑录，研究工作刻不容缓的提案（第2015109号）收悉，现将办理情况函复如下：

莆仙方言又称莆田话、莆仙话、兴化方言等，属于汉藏语系汉藏语系汉语闽方言方言。主要分布于莆田市、乌丘屿乌丘屿（莆田市乌丘屿乌丘屿，由台湾台湾代管）等地。与莆田相邻的福州市的永泰县、福清市、泉州的泉港区都有很多居民也使用莆仙方言。莆田人外出经商很多，东南亚很多莆田侨民后裔,也讲莆仙方言。使用人口大致500万。

目前，我局已经采取多项措施，做好保护莆仙方言工作：

一、保护以莆仙方言为载体的非物质文化遗产有莆仙戏莆仙戏、莆仙木偶戏、独角戏、文十番莆仙木偶戏等。

二、在国家级文物保护单位元妙观三清殿的东岳殿内建立莆阳书院（市图书馆三清殿分馆），开设“莆阳讲堂”，每周定期邀请莆田地方文史专家用莆田方言形式向广大市民讲授莆仙方言莆田地方文化，起到既传播莆仙文化，又保留莆田方言的作用。

三、为保留莆仙方言文读的典型性，特选取《诗经》、《左传》、蒙学、唐诗、宋词等古典文学名篇，邀请唐文桂、王琛等老专家使用莆仙方言进行吟诵并录制成光盘予以保存。并利用莆阳书院联谊会的莆仙方言名家进行更全面更广泛的方言诵读、朗读、日常用语、俗谚民谣的记录工作。同时，为传承保留莆仙方言诗词吟诵的独特韵律感，莆阳书院拟开设诗词吟诵班，采用报名办班，免费培训的方式进行诗词吟诵的教学。

四、为支持莆仙方言辑录、研究工作，我局依托市图书馆馆藏中相关莆田方言的方志资源、专著资源、学术论文资源等，为有关学者、专家研究提供参考服务。
