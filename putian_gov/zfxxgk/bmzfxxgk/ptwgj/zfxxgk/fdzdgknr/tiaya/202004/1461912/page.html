关于市五届人大四次会议第2009053号建议的答复

发布时间：2009-05-26 08:00
| | |

林国庆等代表：

你们提出的“关于加强规范网吧管理的建议”（第2009053号）收悉，现答复如下：

我市网吧管理的现状可概括为“三个基本”：基本捣毁了黑网吧，基本扫清了校园周边200米以内网吧，基本遏制了未成年人进入网吧。文化部网站头版头条报道了《福建省莆田市整治校园周边网吧游戏机》的消息，《中国文化报》以“福建莆田飙风行动净化校园周边网吧”为题向全国推介了我市的做法，在成效上可概括为“一窝端尽”、“一刀切断”、“一线摧毁”。

“一窝端尽”无证经营的黑网吧。采取“一窝端”的办法，下狠心解决校园周边的黑网吧和游戏室。2006年开始，我局在全市范围内开展“飙风行动”，对校园周边无证经营的黑网吧、游戏室进行拉网式的专项打击，发现一家，取缔一家，由工商行政管理部门或者由工商行政管理部门会同公安机关依法查封其从事违法经营活动的场所，扣押从事违法活动的专用工具。2006年取缔119家，2007年取缔19家，2008年取缔27 家，2009年取缔11家。

“一刀切断”校园周边网吧。采取“一刀切“的办法，责令校园周边距离不足200米的网吧限期迁移。2006年责令搬迁19家,2007责令搬迁2家。日前，我市已彻底解决了离校园不足200米的网吧问题。

“一线摧毁”未成年人入内网吧。把未成年人入内作为一条碰着必毁的高压线，严惩重罚敢以身试法者。第一次发现违规接纳未成年人的，罚款5千－1万元，并责令限期整改；第二次发现违规接纳未成年人的，罚款1－1.5万元，停业整顿15天；第三次发现接纳未成年人的，实行“一线摧毁”办法，吊销其《网络文化经营许可证》。2006年查处违规经营网吧320 家，罚款58万元，2007年查处违规经营网吧385家，罚款65万元，2008年查处违规经营网吧328 家，罚款81万元。

取得上述成效，在实践中我们总结了三条基本经验，即：

一是硬到底。----2006年以来，黑网吧业主慑于严打威力纷纷停业。我们抓住少数敢于顶风违纪、以身试法、胆大妄为、有持无恐的黑网吧 “钉子户”，重拳出击，严打不怠。在查处黑网吧时，市文化市场稽查队受到严重的威胁和阻挠，黑网吧业主持刀操棍，恶言相加，不明真相的群众围攻谩骂，挡住车辆，稽查队依法行政，政策攻心，斗智斗勇，文明执法，对查获的所有黑网吧按照《条例》要求全部当场移交所在地工商部门予以取缔。并对省税务学校旁边“蔚蓝海岸”、“比特”、“情网”3家网吧和湄州工业学校附近“E缘”、“智技园”、“经典”3家网吧不按照搬迁的有证网吧进行电信信号切断。并协同市工商、市公安、县区文体局，对无证经营的游戏机室进行取缔，对经营赌博行为的业主移送公安部门立案处理。在查处畅林赤溪3家黑网吧时，我们发现这3家黑网吧十分隐蔽，“大世界网吧”时关时开，装有探头，有严密的防范措施；“超音速网吧”利用一家有证网吧搬迁后的旧址经营，具有欺骗性；“时光网吧”在内街民房内，不易发现，经过3次暗访才查到目标。我局主动牵头，联系公安、工商一起联合执法，坚决端掉。此外，我们向电信部门发函，切断接入信号的黑网吧25家。

二是严到家。----从2006年开始，市文化市场稽查队冒高温酷暑，分4支队伍，共出动执法人员107377人次，车辆35792 趟次，每天中午、晚上执法2次，一天不休息，不间断频繁稽查，发现违规经营网吧1033 家，立案 965 起；发现网吧有消防安全隐患的350处,责令整改60家，删除低俗视频154个,删除色情文章75篇,删除低俗图片513张，责令停业整顿16家。

三是打到位。----针对中小学放学、吃饭和节假日未成年人上网的高峰期，加强中午12－14点，下午18－21点和双休日的检查力度，保持每周对每个网吧最少巡查2次以上，对自行关闭的网吧加强巡查，坚决打击假关闭、时关时开、转入地下、死灰复燃的违法经营行为。按照《互联网上网服务营业场所管理条例》规定，文化行政部门主动负起有证网吧和游戏机依法管理责任，工商行政部门主动负起对无证经营的黑网吧和黑游戏机取缔打击责任，公安行政部门主动负起对黄、赌、毒、消防安全等检查打击责任。

当然，网吧是个两重性的场所，网吧整治也不会一蹴而就。虽经整治，管理仍有缺憾，工作中也存在不少问题：

一是推进不平衡。市里决心大、协调好、干劲足、行动快、成效大。大多数县区领导靠前、主动协调、攻坚克难、成效明显，但也有一些县区文化部门畏难不前，一些县区公安部门重视不够，一些县区工商部门借口推脱，没有形成合力。特别是基层工商所、公安派出所协战不力、消极对待，文化行政执法在基层缺乏安全保障和刚性支持。

二是整治难彻底。①校园周边黑网吧、游戏机室大多租用民房，地处偏僻，目标隐蔽，客观上存在管理漏洞。②黑网吧、游戏机规模小，易于搬迁，游兵散勇，变化多端，难以彻底打尽。③有些网吧表面上打着电脑培训班的招牌，背地里却干起经营黑网吧的勾当，十分狡猾，容易蒙混过关。④一些黑网吧和游戏机高压时有所收敛，严打后死灰复燃，“野火烧不尽，春风吹又生”。

三是执法无保障。目前，法律法规没有赋予文化部门应有的执法权威，一无制服，二无装备。取缔无证网吧、游戏机时遇到暴力抗法，势单力薄，险象环生。文化市场稽查队员多次被围攻殴打，被恶狗撕咬，被门窗夹伤。特别是市、县区没有足够的执法力量，市稽查队有一半队员是借调的。荔城区没有稽查队编制，秀屿区稽查队只有2个人，城厢区稽查队编制至今仍为自收自支。县区执法经费普遍不足，没有专门执法车辆，加上点多面广，路途遥远，很难保障日常监管。

为了网吧行业的规范有序，我们付出了艰辛的劳动。我们认为，我市网吧的管理总体力度是较大的。但由于未成年人自控能力差，经不起网络世界的诱惑，部分经营业主唯利是图，未成年人上网等违规现象时有发生，整治网吧任重道远。今后，要着眼于建立校园周边网吧游戏机管理的长效机制，全社会齐心，各部门协力，共同营造一个健康有序、和谐稳定的校园周边环境。要做到“三个严”：

（一）严把关口，分头负责。坚持属地管理的原则，坚持谁审批，谁负责，谁管理。文化部门要主动负起对有证网吧和游戏机进行依法管理的责任，工商部门要主动负起对无证经营的网吧和游戏机进行取缔的责任，公安部门要主动负起对黄、赌、毒、安全等进行查禁的责任，电信部门要主动负起对黑网吧和停业整顿的网吧中断接入的责任，教育部门要主动负起教育中小学生远离网吧、加强外出学生管理的责任。特别是要严格控制网络信号非法接入，凡没有取得《网络文化经营许可证》的，电信、联通等部门不得提供信息接入服务。

（二）严阵以待，露头就打。整治校园周边网吧游戏机，要持续不断地保持高压严打的态势。一是健全预警机制——早发现。校园周边网吧游戏机问题，学校是第一知情者。一经发现，学校要及时举报，不要等到问题成堆时才反映。凡属黑网吧黑游戏机室的，直接向工商部门举报，举报电话：12315；凡属距校园不足200米有证经营网吧游戏机的，直接向文化部门举报，举报电话：12318。二是完善稽查制度——早查处。校园周边黑网吧游戏机室的存在，工商所和公安派出所应成为第一责任人。工商所和公安派出所要一经发现，露头就打，不要等到市、县联合执法才行动。三是严格审办程序——早防堵。校园周边无证网吧游戏机的设置，电信、联通部门是第一道防线。要严防死守，不可轻易接通。文化部门更要严格控制审批距学校200米以内网吧游戏机的。四是健全责任追究制度——早监督。市专项整治办要为市委、市政府看好文化市场管理的第一道门，及时全面掌控全市校园周边网吧游戏机监管动态。发现问题出在县区文体局的，要及时向市委宣传部报告，并提出处理建议；发现问题出在电信、联通部门的，要及时向市委市政府分管领导报告，并提出处理建议；发现问题出在工商所和公安派出所的，要及时向市公安局、工商局反映，并提出处理建议。工商、公安部门要专门下文严令工商所、公安派出所守土有责，主动出击，使黑网吧黑游戏机成为过街老鼠，没有藏身之所。

（三）严以监管，源头抓起。一是实施技术监管。加大财政投入，建立市县两级网吧监管平台，用科技手段对网吧实行有效监管。二是科学规范布局。坚决停止办理单体网吧，发展“绿色网吧”。三是开展行业自律。已成立网吧协会，发挥行业自律作用。四是发动社会监督。聘请网吧协管员，发挥爱心人士共同参与网吧的监督管理。五是实行严惩重罚。严格按照行政处罚自由裁量权的意见要求,对接待1名的给予警告并处5000元整罚款; 接待2名的给予警告并处6000元整罚款; 接待3名的给予警告并处7000元整罚款; 接待4名的给予警告并处8000元整罚款; 接待5名的给予警告并处9000元整罚款; 接待6名的停业整顿15天并处10000元整罚款; 接待7名的停业整顿20天并处15000元整罚款; 接待8名以上（含8名）的或者在24:00—8:00非法定营业时间内接待3名以上未成年人的吊销《网络文化经营许可证》。六是加强自身建设。建议市政府参照兄弟市的做法，专题研究一次市、县区文化稽查队工作，统一解决人员编制、工作经费和执法用车等问题。
