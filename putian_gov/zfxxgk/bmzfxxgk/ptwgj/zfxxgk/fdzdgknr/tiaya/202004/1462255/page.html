关于市七届人大二次会议第0009号建议的答复

发布时间：2018-05-07 10:08
| | |

林峰代表：

你提出的“关于实施绿心区域乡村振兴战略的建议”（第0009号）已收悉，现答复如下：

你提案中涉及我局职能范围内的主要是绿心区域村庄整治中的文物保护问题。

一、基本情况

莆田素有“文献名邦、海滨邹鲁”之誉，而绿心所处的南北洋平原更是历史源远流长，文化积淀深厚，文物古迹众多。绿心区域内拥有省级历史文化名村1个（白塘镇洋尾村）、福建省首批传统村落2个（拱辰街道东阳村、白塘镇洋尾村），各级文物保护单位30处（其中：全国重点文物保护单位2处，省级文物保护单位2处，市级文物保护单位8处，县区级文物保护单位18处），文物点77处。

二、工作措施及成效

近年来，我局认真贯彻落实《中华人民共和国文物保护法》、《历史文化名城名镇名村保护条例》和《关于切实加强中国传统村落保护的指导意见》等法律法规，积极做好“绿心”区域内文物保护传承工作，取得了一定的成效。主要表现在：

（一）推进文物申报升级

文物是不可再生的宝贵遗产。近两年，新公布第五、六批市级文物保护单位29处，推荐鳌山雁阵宫、杨泗宫、尚书桥赤石宫、仙游林氏大宗祠等18处文物保护单位申报第九批省级文物保护单位，并配合省文物局专家组现场复核，现有14处纳入公示名单。“绿心”区域内的白塘镇洋尾村、拱辰街道东阳村被列入福建省首批传统村落名录，其中洋尾村更是成为省级历史文化名村。同时，我局积极组织文物专业人员进行红砖古民居建筑专项调查，建立红砖古民居建筑名录档案等基础性工作。

（二）完善文物安全制度

文物管理制度不断健全完善，“绿心”区域内的文物均按照市里出台的《莆田市文物安全工作责任制度》、《莆田市文物安全工作检查经常化制度》、《莆田市文物安全重要事项报告制度》、《莆田市文物安全工作例会制度》和《莆田市文物安全工作备案制度》等五项制度进行保护管理，同时，在文物管理工作中做到有保护范围、有保护标志、有记录档案和有保护管理机构，形成市、县（区）、乡（镇）、村（居）四级文物保护联网管理机制，为文物保护提供制度和机制保障。

（三）实施文物修缮和安消防工程

在做好“绿心”区域内文物“四有”工作的基础上，有计划有步骤地实施“绿心”区域内文物建筑修缮和安、消防保护工程。近年来，区域内浦口宫、下亭陈氏民居2处省级文物保护单位已按照维修设计方案实施维修工程，上梧塔桥、集奎万寿桥、洋尾李富祠、大宗祠、州牧祠先后完成抢救性维修工程、部分电线线路改造工程和周边环境整治工程。

三、下一步保护思路

下一步，我局将一如既往做好“绿心”区域内的文物保护工作，坚持“整体保护、分级保护、适度整治更新”等原则，根据文物保护单位及文物点保存状况进行综合评价，实行分级分类保护，把有限的人力、财力用在亟需修缮保护的文物建筑上，对濒危的文物进行抢救性保护，做到好钢用在刀刃上。加强对文物保护设计方案、施工图纸审核、重大变更报审等工作，组织文物建筑保护专家现场指导保护工作，保障文物安全和工程质量，培育熟悉、精通我市传统村落、文物建筑和古民居特点的设计队伍、施工队伍，不断提高保护水平。同时，动员广大群众积极参与，组建志愿者队伍，加强巡视防范力量，预防天灾损毁和人为破坏。
