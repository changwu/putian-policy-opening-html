市七届人大一次会议第52号建议的答复

发布时间：2017-04-26 15:54
| | |

吴道斌等代表： 

您们提出的“关于重视并加强莆田地方文化建设的议案”（第52号）已收悉，现答复如下：

莆田素有“文献名邦”、“海滨邹鲁”之誉，千年历史孕育了妈祖文化、莆仙戏曲等独特的文化资源，文化遗产丰富。近几年，我局充分挖掘，采取有力措施推进优秀传统文化传承保护，取得一定成效。

一、在优秀传统文化宣传方面。利用文化遗产日、国际博物馆日、传统节日等机会，开展形式多样的文化遗产宣传展示活动，营造文化遗产保护浓厚氛围。如2016年组织开展了“兰溪雅韵”非遗舞台精品展演、“匠心研造”非遗传统技艺展示、非遗技艺手工互动、海外华裔青少年夏令营体验莆仙戏传统艺术等活动。深入挖掘、弘扬莆仙地方特色文化，出版了《莆仙十音八乐》《乡愁莆阳》等书籍；拍摄了《寻访老艺人》《福建工艺美术》《莆仙文化记录片》等专题片列入国家数字共享工程数据库；拍摄制作《妈祖故里？欢乐春节》《妈祖故里？文化莆阳》等纪录片，在莆田电视台新闻联播栏目及腾讯视频、爱奇艺等网络平台播出，获得广泛的好评。开展莆仙戏、非遗展示进校园活动，并常年开设《莆仙戏艺术讲座》，多次接待海内外专家学者，作为市委党校的第二课堂，让各界近距离体验莆仙戏艺术，成为各界了解莆仙文化的窗口。

    二、在莆仙方言保护方面。目前，我局已经从以下几个方面加强莆仙方言保护：一是在国保单位元妙观三清殿的东岳殿内建立莆阳书院，开设“莆阳讲堂”，每周定期邀请莆田地方文史专家用莆田方言形式向广大市民讲授莆田地方文化，起到既传播莆仙文化，又保留莆田方言的作用。二是加强以莆仙方言为载体的非物质文化遗产莆仙戏、莆仙木偶戏、独角戏、文十番等的传承保护力度。实施莆仙戏振兴计划，开展十音八乐、独角戏等项目的展示展演活动，扩大影响范围和人群。三是支持莆仙方言辑录、研究工作，市图书馆馆藏中有关莆田方言的方志资源、专著资源、学术论文资源等，为有关学者、专家提供参考服务。为传承保留莆仙方言诗词吟诵的独特韵律感，下一步拟开设诗词吟诵班，采用报名办班、免费培训的方式进行诗词吟诵的教学，并选取《诗经》、《左传》、蒙学、唐诗、宋词等古典文学名篇，邀请唐文桂、王琛等老专家使用莆仙方言进行吟诵并录制成光盘予以保存。

三、在历史文化名村保护利用方面。近年来我局和住建等部门积极配合，根据《历史文化名镇名村保护条例》等法律法规对历史文化街区进行较有效的保护，推进历史文化街区保护工作进程。一是坚持规划先行。编制了《莆田市历史文化名城保护规划》，《古谯楼历史地段修建详细规划及重点地段修缮建筑方案设计》，目前在编《萝苜田历史文化街区修建性详细规划》。二是开展保护整治。遵循“保护历史的真实性、保持风貌的完整性、维护生活的延续性”的名城保护原则，根据建筑物的现状、历史信息与街区保护的实际需要，按照“重点保护、合理保留、局部改造、普遍改善”的要求，对历史文化名城中心片区和罗苜田片区进行保护，目前已完成历史文化名城核心区县巷、大路等六条街道的路面整治工程，涵江区罗苜田片区的截污、河道清淤、河水疏通工程。通过保护整治，初步恢复了街区历史风貌，修复了部分重点文物和历史建筑。

    保护和开发利用历史文化街区是一项综合性工程，需要多部门配合，形成联合保护开发机制。基于现今我市历史文化街区保护起步较晚、传统格局破坏、整体风貌缺失、内涵活力不足、保护开发力度不够的实际，下一步我局将配合住建等部门重点抓好以下几项工作：一是明确定位，拓展空间。要按照街区原有的历史风貌进行规划保护和开发建设，根据名城规划的要求，划定保护范围，依法坚决禁止在保护范围内的非法拆建活动。二是完善规划，强化功能。按照名城规划要求，逐步恢复名城核心区历史文化街区的历史风貌和业态，再展宋城风采。三是挖掘内涵，激发活力。一方面组织专业人员挖掘整理历史文化街区的文化信息，推进文物保护单位和历史文化街区的合理利用，发挥文化遗产在发展旅游等产业方面的作用，为经济发展服务；另一方面梳理原有的街巷结构，发展街区商业，逐步恢复传统特色商业经营，调整民居使用功能，鼓励开展特色餐饮、民间美术、传统工艺、传统技艺展示和特色产品特色文化旅游的经营活动等。四是健全体制，多元集资。采取“产权人出资、财政补助、民间筹措”等三者结合的办法，整合各方力量参与名城保护工作，提升历史文化街区保护和开发利用工程。

    迁移古民居会破坏文物原始格局和历史环境风貌协调，不符合文物保护不改变原状的基本原则，根据《中华人民共和国文物保护法》第二十条规定：“对文物保护单位应当尽可能实施原址保护，无法实施原址保护，必须迁移异地保护的，应当报省、自治区、直辖市人民政府批准；迁移省级文物保护单位的，批准前须征得国务院文物行政部门同意，全国重点文物保护单位迁移须由省、自治区、直辖市人民政府报国务院批准”。您们建议中提出将偏远不利于保护的有价值的古民居整体搬迁到文化街区进行保护的做法是不可取的。

四、在非物质文化遗产传承保护方面。我市非物质文化遗产保护管理工作不断规范化、制度化。全市现有世界人类非物质文化遗产1个、国家级非遗项目10个、省级非遗项目43个、市级非遗项目217个。一是加强立法保护。积极配合市人大做好《妈祖信俗保护条例》的立法工作，已形成初稿。在市政府公布的《莆田市非物质文化遗产保护管理实施办法》（试行）的基础上，建议市人大将《莆田市非物质文化遗产保护条例》的立法工作提上议程。二是完善传承体系。近几年，我市非遗传承制度化建设不断加强，现有国家级非遗代表性传承人9人、省级55人、市级293人，市级第四批代表性传承人的评审推荐工作已完成专家论证，下一步将进行公示并提交市政府研究公布。2017年将开展省级第四批代表性传承人的组织申报工作。择优公布，建立了55个市非遗项目传习所，通过业务培训，强化指导，规范各传习所开展传习工作。同时，强化资金保障，省级代表性传承人达到60周岁以上的每年政府给予3000元补助，国家级代表性传承人每年给予20000元传承补助经费。三是开展非遗数据化保护工作。完善非遗档案，实施非遗申报档案电子化。建立妈祖文化数据库，利用电视、广播、网络等媒体进行资源共享，成为首批国家级非遗项目数字化试点项目。目前正在建设莆田市非遗综合性展示馆，运用各种手段展示全市非遗项目，弘扬地方特色文化。

    您们在提案中提到的相关内容，我们将在以后的工作中强化措施，继续推动莆仙优秀传统文化的传承保护。非常感谢您们在百忙中对我市文化工作的关心支持！也欢迎您们继续提出宝贵的意见和建议。
