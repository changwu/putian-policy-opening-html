关于市七届人大五次会议第0002号建议的协办意见

发布时间：2021-03-02 15:36
| | |

市农业农村局：

郭雄新代表提出的《关于加快实施乡村振兴战略的建议》已收悉，我单位的办理意见如下：

一、关于以人为本，激发农民创造创新创业活力的建议。坚持以促进农民就地创业和增收为目标，变资源优势、文化优势为经济优势，丰富文化内涵，提升服务水平，提高示范带动能力。

一是推动农民享受基本公共文化服务。我市公共图书馆、艺术馆（文化馆）、博物馆、乡镇（街道）综合文化站、村（社区）综合文化服务中心等公共文化场所，在做好疫情防控的同时，全部向农民免费开放，并增加面向农民的展示展览、艺术培训、图书阅读、培训讲座、艺术鉴赏等文化服务活动场次。如：2020以来先后组织开展“春节去哪儿”系列活动、第二届莆田市音乐舞蹈节、非遗夜市、“迎国庆 贺中秋”旗袍诗会、“春雨工程”宁夏文化志愿者福建行等各类活动，吸引了众多农民群众参加；市艺术馆分别开设了广场舞、健身球、拉丁舞、休闲舞、秧歌、健身舞、书法、国画等20多个秋季培训课程，农民可以免费申请培训；市图书馆全年免费提供文献资源借阅、检索与咨询、公益性讲座和展览、阅读推广等惠民服务项目；市博物馆常年举办《莆田历史文化陈列》《莆田民俗文化陈列》等公益展览，提高了农民了解莆田历史文化的内涵；举办了2020年福建农民文化周启动仪式和闭幕仪式活动，共举办活动23场次，其中启动仪式共吸引近150万群众线上共同参与。

二是完善提升基础公共服务效能。着眼共建共享，继续推进基层综合性文化服务中心整合提升，示范引领作用更加明显。遴选了荔城区文化馆、常太镇马院村游客服务中心、书峰乡兰石村综合文化服务中心作为文旅融合试点；枫亭镇麟山村、北高镇竹庄村、华亭镇五云村、萩芦镇梅洋村、东庄镇前云村5个村综合文化服务中心，给予支持补助，提升服务效能；西天尾镇后黄社区、白塘镇洋尾村、东庄镇苏厝村3个村综合文化服务中心被评为省级优秀示范点。在2020年全省乡村文化振兴现场会上，书峰乡兰石村作典型发言，白塘镇洋尾村、东庄镇苏厝村做书面典型材料交流；印发《莆田市文化和旅游局关于进一步做好县级文化馆图书馆总分馆制工作的通知》（莆文旅〔2020〕73号），各县区制定方案、新增30个点纳入总分馆体系，不断延伸覆盖面，提高服务效能。

二、关于突出特色，推进休闲农业和旅游业的融合发展的建议。发展休闲农业应以突出自然生态为重点，加强休闲农业与旅游业的结合，形成一批休闲农业与乡村精品项目，组织开展推介活动，推动休闲农业与乡村旅游和其他旅游业态的融合发展。

近年来，我市乡村旅游发展迅速，在全域旅游专项行动的带动下，乡村旅游项目建设也兴起热潮，乡村旅游产品不断丰富。仙游西苑凤山村、书峰百松村，荔城西天尾后黄村、象峰村，城厢常太岭下村、马院村，涵江白沙坪盘村、江口东大村，秀屿区汀港村、港南村等旅游配套设施逐步完善，接待能力显著提升。仙游西苑仙水洋、济川村风景区，荔城区象峰村西隐亭，城厢常太马院人家，涵江秋水谷，秀屿后海渔村等一批乡村旅游点先后被评为国家A级旅游景区。仙游榜头镇被评为省级乡村旅游“十佳休闲集镇”，荔城区西天尾镇后黄村、涵江区白沙镇坪盘村被评为省级乡村旅游“二十佳特色村”。荔城区西天尾镇后黄南洋风情村旅游创客基地、仙游县书峰乡百松村旅游创客示范基地、涵江区江口镇东大村蒜溪创客示范基地被省旅发委评为乡村旅游创客基地。“花果莆田—四季采摘”成为了莆田乡村旅游的一大亮点，书峰枇杷节、华亭杨梅节、度尾文旦柚节、钟山甜柿节等一系列活动有力地推动我市乡村旅游朝着规模化、常态化、产业化、市场化方向发展。我局将加大乡村旅游宣传推介力度。一是加强区域合作，推进休闲农业旅游产品促销。积极组织参加省厅组织的市场营销活动和各种博览会，特别是新客源市场的拓展；积极组织参加闽东北区域组织的市场促销活动，组织旅游促销团赴周边地市开展宣传营销活动，重点营销休闲农业，不断扩大休闲农业知名度和影响力。二是强化市场推广，做大做强休闲农业旅游产品品牌。积极主动走出去拓展市场，组织休闲农业企业参加第十七届海峡旅游博览会和2021福建旅游生活展，视疫情情况赴广东、江西、湖南等省外主要客源地，举办莆田文旅推介会，把休闲农业旅游项目作为重点推介内容；同时加强莆田旅游资讯服务，以网络为平台，加强资信宣传，为疫后散客游、自驾游提供准确的休闲农业旅游信息；举办“荔枝红 家乡美”等休闲农业微旅游活动，促进休闲农业旅游品牌不断提升。三是加强线上营销 ，扩大休闲农业旅游产品网络宣传效应。利用抖音、直播等新媒体，筹划休闲农业旅游产品线上网络营销，拉动网络效应，提升莆田休闲农业旅游产业的知名度；落实休闲农业旅游产品网络营销计划，加强与厦门文旅局微信公众号、其他设区市文旅部门网站、12306等平台合作，开展休闲农业旅游产品的宣传推广，拓宽莆田休闲农业旅游产品的销售渠道。

三、关于提高思想认识，增强发展信心的建议。坚持“政府引导、市场运作、科学规划、体现特色”的基础上，落实规划布局，强化扶持引导，做足生态休闲农业、乡村旅游与农业产业化、旅游业结合文章。

近年来，我市高度重视发展乡村旅游，根据福建省《乡村旅游“百镇千村”三年行动计划》，全市共打造乡村旅游休闲集镇10个、乡村旅游特色村107个，闽台乡村旅游示范基地1个、试验基地1个；四星级乡村旅游休闲集镇（全域生态旅游小镇）4个、四星级乡村旅游村（金牌旅游村）9个，三星级休闲集镇2个、三星级乡村旅游村9个，三星级以上乡村旅游经营单位35个；涵江区坪盘村、湄洲岛下山村被评为全国乡村旅游重点村；被评为乡村旅游致富带头人2个、乡村旅游模范户2人。我市乡村旅游发展的水平正在不断的提升，成功开发了农耕体验、农产品采摘、田园观光、民俗文化等旅游产品，不仅吸引了大量市民和周边地区游客前来观光，同时也增强了我市乡村旅游的吸引力。

今年，我局将继续按照《福建省乡村旅游“百镇千村”提质升级三年行动方案》，推动做好全国乡村旅游重点村、省级全域旅游小镇（四星级休闲集镇）和金牌旅游村（四星级旅游村）创建培育工作，评定一批省级乡村旅游三星级旅游村，鼓励发展乡村民宿旅游、A级旅游景区创建等，推进乡村旅游发展的新热点，持续打响乡村旅游知名品牌。同时，大力支持乡村旅游品牌创建，对被评为国家4A级、3A级景区，分别给予一次性奖励100万元、50万元；被评为省级五星、四星、三星级乡村旅游休闲集镇，分别给予一次性奖励80万元、60万元、40万元；省级五星、四星、三星级旅游村，分别给予一次性奖励50万元、30万元、20万元，重点扶持乡村旅游基础设施项目建设，提升乡村旅游公共服务水平。

四、关于要培育行业龙头品牌的建议。将现代农业项目、农产品加工、生态农业发展项目与乡村旅游等项目融合，重点扶持，精心打造一批地方特色的品牌。

近年来，我局认真贯彻市委市政府关于乡村振兴的统一部署，积极探索乡村旅游发展新模式、新途径，按照一村一品的发展思路，大力打造乡村旅游综合体，培育了各具特色的乡村旅游典型。如：白沙镇香积国香草庄园主营有机蔬菜、香草植物的种植及观光农业，是福建省首家以香草为主题的复合式休闲农庄，被评为“省级休闲农业示范点”和省级乡村旅游四星级经营接待单位称号；白沙镇坪盘村依托新农村建设的成果,取得省级乡村旅游三星级接待单位；大洋乡笛韵森林人家利用红色文化和生态资源建成集餐饮、住宿、会务、旅游、娱乐为一体的休闲山庄；后海垦区利用福建省休闲渔业示范基地和“水乡渔村”的资源优势，形成独具特色的渔村旅游景观。同时，创新管理模式，坪盘村建立了“集体+农户+公司”的旅游发展经营模式，后黄村和莆田康辉旅行社结合形成联合体共同开发后黄村乡村旅游。今后，我局将进一步指导乡村旅游村因地制宜做好乡村旅游发展规划，突出资源优势、挖掘内涵，妥善处理好乡村旅游项目开发与自然生态及文物保护的关系，推动乡村旅游发展与当地自然环境和谐相处，与当地经济发展阶段相适应，确保乡村旅游资源的合理开发和可持续发展。

五、关于加强技术培训的建议。运用就业培训、农村技能培训、职业技能教育等载体，加快组建休闲农业和乡村旅游产业发展培训机构，负责对休闲农业和乡村旅游的从业人员进行农业科持、职业道德、民俗文化、旅游接待经营管理等方面的培训，从而提高服务质量、提供规范和标准化服务，提高从业人员综合素质，为乡村旅游发展提供人才资源保障。

近年来，我局高度重视乡村旅游人才培训工作，先后选派36名乡村干部赴台参加乡村旅游培训班，选送乡村旅游村干部20多人次参加省、国家组织的乡村旅游和旅游扶贫人才培训班，市里每年举办一期乡村旅游专题培训班，组织乡村旅游经营户、乡村旅游带头人、乡村旅游管理人、乡村旅游讲解员等各类实用人才培训，帮助乡村旅游村干部改变思想观念，提升文化素质和知识水平，提高乡村旅游服务能力。
