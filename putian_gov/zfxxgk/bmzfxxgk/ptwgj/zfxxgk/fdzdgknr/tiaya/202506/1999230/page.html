关于市八届人大五次会议第1007号建议（或议案）的答复

发布时间：2025-04-24 16:42
| | |
 黄长城代表：

您提出的《关于设立妈祖文化艺术中心以促进莆台文化交流及经济合作的建议（或议案）》（第1007号）已收悉，我单位的办理意见如下：

妈祖文化是我市极具影响力的文化瑰宝，也是中华优秀传统文化的重要组成部分。妈祖是中国沿海民众在海洋活动中孕育出来影响最大的航海保护神，妈祖信俗是以崇奉和颂扬妈祖立德、行善、大爱精神为主旨，以宫庙、祭器、祭品等为活动载体，以祭祀、庙会、习俗、文学、艺术、技艺等为表现形式的以海洋文化为主体融合农耕文化的民俗文化。2006年妈祖祭典列入国家级非物质文化遗产代表性项目名录，2009年妈祖信俗列入联合国教科文组织非物质文化遗产代表作名录，这也标志着妈祖文化在莆田得到进一步的弘扬、传承和保护。2022年以来，我们还从国家级、省级非遗资金中补助332 万元用于举办妈祖祭典、妈祖信俗等非遗代表性项目保护传承活动，有力地推动了妈祖文化的传承与发展。​

我市市委、市政府一直高度重视妈祖文化产业的开发利用，成立了全市文旅经济（含妈祖文化）发展暨招商工作专项领导小组，统筹推进全市文化和旅游产业发展。突出顶层设计，将湄洲岛文旅产业发展列入《莆田市“十四五”文化和旅游改革发展专项规划》，强化“天下妈祖、祖在湄洲”朝圣中心地位，围绕建设世界妈祖文化中心核心区，深入挖掘妈祖文化的当代价值，全面提升妈祖文化的影响力。指导推动湄洲岛策划建设妈祖邮轮中心，支持在湄洲岛作业点拓展出1个3-5万吨级邮轮泊位，对港口配套设施进行扩建提升，并作为邮轮访问港在中期进行发展，考虑在远期升级为邮轮始发港，促进湄洲岛旅游从观光休闲型向品质度假型转变。加快开展妈祖邮轮中心前期工作，目前省湄洲湾港口发展中心已组织对湄洲岛妈祖文化旅游港工程波浪数模、潮流数模、物理模型可行性进行专家咨询评审，突出招大引强。对接国家、省市产业政策及方向，策划湄洲岛两岸融合社区、华信度假山庄、数字化妈祖文化交流平台项目、湄洲岛国际旅游度假区深度开发项目等招商项目，先后在北京、上海、浙江等地举办“这就是莆田”文旅招商推介会。推进岛岸一体发展文旅产业的定位目标、模式路径、品牌形象、与其他产业融合体系等，研究岛岸一体发展的滨海旅游重点项目、促进发展政策等。

按照莆田市建设“妈祖故里文化名城、山水诗画生态韵城、匠心智造产业新城、通江达海战略港城”的“四城”总体目标要求，我局正在编制《莆田市文旅经济发展规划》《莆田市滨海旅游发展规划》，积极构建将城市发展与文旅经济融合发展的一个大格局。坚持以文塑旅、以旅彰文，实施全产业链招商工程，成立全市文旅经济（含妈祖文化）发展暨招商工作专项领导小组及其五个工作组，统筹协调推进文旅产业链发展各项工作。围绕木兰溪、绿心、1号滨海风景道、湄洲岛等产业特色，突出文旅跨界融合，策划生成一批投资规模大、带动能力强、综合效益好的文旅招商项目，制作《文旅招商项目册》，加强招商推介和服务保障，积极营造侨胞投资莆田文旅、建设莆田文旅的良好环境。“妈祖故里·灵秀莆田”文旅品牌影响力不断扩大。

二、下一步工作安排​

（一）继续做好总体规划和专门策划

结合代表建议，积极构建妈祖文化传承传播体系，全面阐释妈祖文化精神，搭建文旅融合和产业发展平台，以及提升城市经济、完善市场基础等一系列工作，以更高的站位、更务实的举措，持续推进妈祖文化传承发展工作，促进文城融合、以文兴产方面做好全面提升，进一步拓展文旅融合的深度和广度。在城市规划建设中，充分融入妈祖文化元素，打造以妈祖文化为主题的城市地标性建筑，打造妈祖文化主题街区，合适时机选取莆田市区或湄洲岛具有历史文化底蕴的街区，进行整体规划改造，融入妈祖文化元素，邀请院校、企业等共同打造业态。街区建筑风格参考妈祖文化相关的古建筑特色，设置妈祖文化展示店铺、特色餐饮、民俗体验店等，挖掘妈祖文化元素开发特色文创产品与旅游商品，同时，对莆田传统特色产品进行妈祖文化赋能，如对莆田木雕、石雕、金银珠宝加工等传统工艺品融入妈祖文化设计，打造旅游伴手礼，既延伸妈祖文化产业链，又借助商品流通宣传妈祖文化，促进文化与商业融合，提升城市文化经济活力。打造集文化展示、购物、餐饮、休闲为一体的主题街区，成为城市文化新地标，吸引游客深入体验妈祖文化，拉动区域经济增长，实现文城融合发展。全力将我市打造成世界妈祖文化中心和国际知名的文化旅游目的地。​

（二）促进莆台文化交流与经济合作​

全力搭建莆台文化交流平台，定期举办莆台妈祖文化论坛、艺术交流活动等，进一步加强两岸文化界的沟通与合作。结合每年举办的世界妈祖文化论坛，邀请两岸专家学者、文化名人齐聚一堂，共同探讨妈祖文化的传承与创新发展路径。积极鼓励台湾文化企业、艺术机构入驻妈祖产业园，开展文化创意产品开发、文化艺术培训等业务，大力促进两岸文化产业合作。为入驻企业提供优惠政策与优质服务，全力营造良好的发展环境。以妈祖文化为紧密纽带，大力推动莆台旅游合作，精心开发妈祖文化主题旅游线路，吸引更多台湾游客来莆旅游观光。计划与台湾旅游企业携手合作，推出“妈祖文化寻根之旅”“莆台妈祖文化体验游” 等特色旅游产品，进一步拓展莆台旅游市场。​

感谢您对我市文旅工作的关心与支持，期待您继续提出宝贵意见和建议。
