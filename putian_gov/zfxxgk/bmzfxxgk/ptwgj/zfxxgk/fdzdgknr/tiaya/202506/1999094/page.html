关于市政协八届四次会议第20252058号提案办理情况的答复

发布时间：2025-06-11 09:15
| | |
 柯福星委员：

您提出的《关于提升湄洲岛民宿高质量发展的建议》（20252058号）已收悉，现将办理情况函复如下：

　   近年来，随着旅游业的快速发展，湄洲岛的民宿产业迎来了前所未有的发展机遇，取得了数量和质量的双突破。关于你提出的建议，对推动湄洲岛民宿业高质量发展具有很强的指导性和可操作性，我局将加强研究，并在今后的工作中加以实施。

一是完善民宿政策保障。市政府出台了《莆田市促进民宿高质量发展若干措施》，对获评甲、乙、丙级旅游民宿，分别给予10万元、5万元、3万元奖励，积极引导民宿提质升级，参与民宿品牌建设。湄洲岛管委会出台了《湄洲岛旅游民宿星级评定及管理办法（试行）》，从2022年开始，对湄洲岛旅游民宿实行星级管理（每两年评星一次），着力提升旅游民宿管理和服务水平。

二是夯实民宿人才基础。组织2期湄洲岛民宿主人、民宿管家参加全省“数字木兰”计划培训，推动省民宿协会在湄洲岛举办2期民宿主人、民宿管家培训班，湄洲岛上的民宿主人、民宿管家近100人参加了培训。邀请行业专家、高校学者对湄洲岛民宿从业人员进行系统性、集中性培训，提高民宿从业者的综合能力。2024年以来，湄洲岛累计组织开展民宿从业人员培训12场次，参加培训0.7万人次。

三是科学谋划民宿发展。结合湄洲岛实际情况，实施民宿“总量控制+动态评估”管理办法，对岛内民宿总量进行有效的动态调整与控制，确保湄洲岛民宿客房数、床位数增速与上岛游客人数增速保持协调。力争通过3-5年的努力，使湄洲岛形成布局合理、规模适度、内涵丰富、特色鲜明、服务优质的旅游民宿发展格局。

四是全力提升民宿品牌。湄洲岛已成功创建国家丙级民宿4家，1家民宿申报乙级民宿评定，已通过省级初评。有“泊澜”“湄屿”2个本土民宿品牌，共有星级民宿450家，其中，五星精品民宿16家。2025年，湄洲岛将对尚未评星民宿委托第三方开展新一轮的星级评定，鼓励引导品质较好的民宿参与国家级民宿品牌建设，力争3年内创建国家甲级民宿1家、乙级民宿2家、丙级民宿6家，星级民宿覆盖率达100%，推进民宿品质升级迭代。

五是全面提升民宿服务质量。制定《湄洲岛旅游民宿服务标准化手册》，从卫生、安全、接待等维度设定动态考核指标，并联合民宿协会不定期开展卫生、安全交叉检查，对问题民宿实施“黑名单”制度。实施湄洲岛“民宿一张图”，努力实现集民宿房源管理、客源分析、过夜游客统计、投诉处理等功能为一体的智慧化管理效果。

六是延伸拓展民宿产业链。精心打造“夜湄洲”消费场景，做好《印象妈祖》《缘起湄洲》《首见妈祖》等沉浸式文旅体验产品的更新与升级，扩大文化演出市场优质供给，抢占线下演出高地，引进明星、网红大咖等做大“新流量”，吸引更多国内外游客，助推民宿产业发展壮大。鼓励民宿开发“民宿+康养”、“民宿+研学”、“民宿+体验”等多元化产品，有效延长游客停留时间，促进游客二次消费，延伸民宿产业链条。

七是强化民宿服务保障。2024年以来，湄洲岛以“快处先赔”和“放心游湄洲”为承诺，建立涉旅诉求秒回日结办理制度，组建湄洲岛旅游投诉快速处理微信群，采用纵向联动、横向配合、监督到位、推动有力的督促协调机制，对游客反映的各类旅游投诉，做到反应更快速（10分钟内响应）、处理更高效（2个小时内反馈初步核查情况），办结不过夜（当天内办结）。目前，湄洲岛旅游民宿客房退订等投诉问题均能得到及时、高效、妥善处置，游客对处置结果普遍表示满意。

八是加强等级旅游民宿安全监管。将等级旅游民宿纳入安全督导指导范畴，强化部门联动，在重要节假日及春季、夏季等重要时间节点，协同公安、交通运输、住建、应急、市场管理、消防等部门，联合对等级旅游民宿进行安全检查和服务质量督查，促进依法运营，强化综合监管，推动旅游民宿业高质量发展。

在此，谨对您提出的关于提升湄洲岛民宿高质量发展的建议、对莆田文化旅游业发展的关心表示衷心的感谢！
