关于市政协八届三次会议第20243034号提案办理情况的答复

发布时间：2024-08-30 11:46
| | |

李少霞委员：

您提出的《关于发挥妈祖文化优势，促进莆台民间文化交往的建议》(第20243041号)已收悉。现将办理情况函复如下：

莆田市悠久的历史孕育创造了丰厚的文化遗产，妈祖文化是其中的典型代表，也是中华优秀传统文化的重要组成部分。妈祖是中国沿海民众在海洋活动中孕育出来影响最大的航海保护神，妈祖信俗是以崇奉和颂扬妈祖立德、行善、大爱精神为主旨，以宫庙、祭器、祭品等为活动载体，以祭祀、庙会、习俗、文学、艺术、技艺等为表现形式的以海洋文化为主体融合农耕文化的民俗文化。2006年妈祖祭典列入国家级非物质文化遗产代表性项目名录，2009年妈祖信俗列入联合国教科文组织非物质文化遗产代表作名录。这标志着妈祖文化在莆田得到进一步的弘扬、传承和保护，对逐步扩大两岸妈祖文化交流和提升妈祖文化在世界的影响力具有重要意义。

 一、注重在立法中聚力。推动《湄洲岛保护管理条例》纳入地方立法，并于2019年7月通过省人大常委会批准，并于当年10月1日起施行。这使得妈祖文化生态遗产保护更加有章可循、有法可依，为妈祖文化生态遗产保护和利用提供了强有力的保障。

二、注重在“申遗”中提升。参与中国海丝联合申报世界文化遗产，以湄洲妈祖祖庙成为我市唯一被列入的遗产点为契机，投资1亿多元，邀请中国文化遗产研究院编制遗产点周边环境整治提升方案，对祖庙历史建筑进行全面修缮，安装具有电线路监测、温湿度监测、消防检测等功能的智能楼宇系统，并对祖庙周边的朝圣路、朝宫街进行立面改造，有效地保护了“申遗”遗产点风貌。目前，按照国家文物局启动中国世界文化遗产预备名单更新工作的要求，作为妈祖文化史迹最具代表性遗产点湄洲妈祖祖庙，推荐列入“海上丝绸之路”项目申报中国世界文化遗产预备名单。对接省文物局完成申报项目初步评审，已将我市上述申遗项目向国家文物局行文推荐申报，更好的奠定了妈祖文化对外宣传的安全基础保障。

三、注重在交流中弘扬。配合组织举办八届世界妈祖文化论坛，论坛已成为海丝沿线以妈祖文化为纽带，多元、开放、包容的交流合作平台。每年持续承办中国·湄洲妈祖文化旅游节，指导湄洲岛妈祖祖庙开展好春秋妈祖祭典、祖庙跨年活动、祖庙新春祈福大会、元宵妈祖巡安布福活动、妈祖庙会、天下妈祖回祖庙、妈祖绕境巡安活动、妈祖巡天下、妈祖下南洋·重走海丝路等十多项节事活动，广角度、多元化、矩阵式扩大妈祖文化影响力和凝聚力。

2023年9月，两岸共计有600多家妈祖宫庙参加“瓣香湄洲·福佑兴化”湄洲妈祖金身巡安莆田活动。其中，来自台湾的有90多家妈祖文化机构，台胞400多人。2024年以来，湄洲岛妈祖祖庙开展了甲辰年海峡两岸新春祈年典礼、莆台同胞护驾妈祖金身回上林故居省亲布福活动、天下妈祖回娘家活动等，并在活动期间共同推动两岸信俗规范化，举办妈祖祭典、三献礼仪式、晨拜妈祖、诵经祈福、庙会祭祀、供品展示等信俗交流互鉴活动。

四、注重在传承中创新。与省图书馆联合拍摄了6集系列专题片《妈祖信俗》，已列入国家文化信息资源共享工程资料库；建立妈祖祭典首批国家级非遗项目数据库，运用音像等多媒体对妈祖祭典等民俗活动进行录像，开展数字化保护，充分发挥文化信息共享的作用；在市博物馆中设立妈祖文化专题展厅，以多种形式展示妈祖信俗文化。

同时，鼓励台胞申报妈祖信俗代表性传承人，吸引台湾人才共同实施妈祖文化遗产保护工程，开展闽台研学活动，打造两岸青年妈祖文化研学基地。吸引台湾高校师生来湄洲岛研习妈祖文化，举办闽台青年妈祖信俗研学体验;推动两岸民间的进一步融合。

五、注重在融合中发展

市委市政府成立全市文旅经济（含妈祖文化）发展暨招商工作专项领导小组，统筹推进全市文化和旅游产业发展。突出顶层设计，将湄洲岛文旅产业发展列入《莆田市“十四五”文化和旅游改革发展专项规划》，强化“天下妈祖、祖在湄洲”朝圣中心地位，围绕建设世界妈祖文化中心核心区，深入挖掘妈祖文化的当代价值，全面提升妈祖文化的影响力。指导推动湄洲岛策划建设妈祖邮轮中心，支持在湄洲岛作业点拓展出1个3-5万吨级邮轮泊位，对港口配套设施进行扩建提升，并作为邮轮访问港在中期进行发展，考虑在远期升级为邮轮始发港，促进湄洲岛旅游从观光休闲型向品质度假型转变。加快开展妈祖邮轮中心前期工作，目前省湄洲湾港口发展中心已组织对湄洲岛妈祖文化旅游港工程波浪数模、潮流数模、物理模型可行性进行专家咨询评审。突出招大引强。对接国家、省市产业政策及方向，策划湄洲岛两岸融合社区、华信度假山庄、数字化妈祖文化交流平台项目、湄洲岛国际旅游度假区深度开发项目等招商项目，先后在北京、上海、浙江等地举办“这就是莆田”文旅招商推介会。推进《印象妈祖》演艺项目，目前编创方案已定稿，进入合资公司人员配备及演员招聘工作已完成并开始进行舞蹈排练，演出剧场（妈祖论坛平安会堂）装修已开始施工，相关设备已陆续进场安装。编制《莆田市滨海旅游发展规划（2022-2035）》，推动湄洲岛与北岸一体化发展融入规划，明确岛岸一体发展文旅产业的定位目标、模式路径、品牌形象、与其他产业融合体系等，研究岛岸一体发展的滨海旅游重点项目、促进发展政策等。

下一步我们将按照延续中华文脉的重大战略决策，进一步弘扬妈祖文化，推动妈祖文化新跃升，充分发挥妈祖文化在“一带一路”中的重要作用。一是加强与世界妈祖文化组织的联系，与各地妈祖文化组织建立合作关系，共同举办活动，推动妈祖文化的交流。二是开展妈祖文化研讨会，定期举办妈祖文化研讨会，邀请国内外专家学者共同探讨妈祖文化的传承与发展。三是打造妈祖文化旅游品牌，利用妈祖文化的知名度和影响力，打造妈祖文化旅游品牌，吸引国内外游客前来参观。
