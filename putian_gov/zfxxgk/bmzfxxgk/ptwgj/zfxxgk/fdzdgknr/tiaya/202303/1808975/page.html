关于市八届人大二次会议第1017号建议（议案）的协办意见

发布时间：2023-03-30 08:59
| | |
 莆田市农业农村局：

郭雄新代表提出的《关于加快发展现代生态休闲农业，推进乡村振兴战略的建议》已收悉，我单位的办理意见如下：

一、关于创新服务，规范提升休闲农业的整体发展水平的建议

实施乡村旅游商品“后备箱”工程，着力将乡村农产品、手工艺品转化为旅游商品，丰富旅游商品名录。在4A级及以上景区、重点旅游村、旅游休闲街区建设特色旅游商品店，在九龙谷景区特色商品体验点销售枇杷膏、枇杷罐头、兴化粉、莆田桂圆干、鲍鱼干、荔枝干等；在绶溪公园新凯特文创体验馆展出美陈5帧，生活创品180件，艺术创品40件等，展现老莆阳的风华绝代、古兴化的迷人之彩；在湄洲岛“妈祖平安礼”旗舰店销售“妈祖平安礼”包括赏心悦、全家服、平安瓷、海神表、味极品、海贝贝、微卡通、捏海人、茗香醇等9大类平安礼；在涵江区萩芦镇成立萩芦文旅产业投资有限公司，2021年9月正式发布区域公共品牌“五彩萩芦”，对龙眼、枇杷、樟洋大米、梅洋茗茶、南坛蜂蜜等农特产品进行包装。同步搭建“五彩优选”电商平台，借助举办萩芦龙眼文化节、云端枇杷文化节、茶文化节等活动，推出“枇杷四宝”“梅洋清茗”“五彩福粽”等一批“独一份”“好中优”的农特产品，帮助农民增收致富。自平台上线以来，仅枇杷的销售额就达上千万元，“梅洋清茗”茶叶还销往国外。

二、关于推进休闲农业和旅游业融合发展的建议

一是推进乡村旅游提质升级。全市共打造乡村旅游休闲集镇10个、乡村旅游村107个，闽台乡村旅游示范基地1个、试验基地1个；共培育创建国家乡村旅游重点村3个，省级金牌旅游村11个、三星级乡村旅游村9个，三星级以上乡村旅游经营单位35个；仙游县入选首批福建省全域生态旅游示范县；被评为乡村旅游致富带头人2个、乡村旅游模范户2人。我市乡村旅游发展的水平正在不断的提升，成功开发了农耕体验、农产品采摘、田园观光、民俗文化等旅游产品，不仅吸引了大量市民和周边地区游客前来观光，同时也增强了我市乡村旅游的吸引力。二是加大宣传力度。实施“莆阳开春，开河、开街、开村”活动，东阳村、北大村、洋尾村、双福村、吴江村“开村”，通过开展大型“福兔”、画舫游船、美食集市、郊野露营、皮划艇赛事等各式文旅活动，植入业态，激活价值，激活乡村文脉。情况整合全市优质文旅资源，策划推出8条乡村旅游精品线路，不断壮大文旅产品体系；组织开展2022“艺塑乡村·诗画莆阳”莆田行活动，推动艺术赋能乡村振兴，打造地域特色文旅品牌。举办2023“这就是莆田”（北京）文旅推介会，对乡村旅游路线、济川村旅游开发项目、东阳村旅游度假区等乡村文旅项目进行推介，推动乡村旅游和其他旅游业态融合发展。

三、关于培育行业龙头品牌的建议

仙游西苑仙水洋、济川村风景区，荔城区象峰村西隐亭，城厢常太马院人家，涵江秋水谷，秀屿后海渔村等一批乡村旅游点先后被评为国家A级旅游景区。仙游榜头镇被评为省级乡村旅游“十佳休闲集镇”，荔城区西天尾镇后黄村、涵江区白沙镇坪盘村被评为省级乡村旅游“二十佳特色村”。荔城区西天尾镇后黄南洋风情村旅游创客基地、仙游县书峰乡百松村旅游创客示范基地、涵江区江口镇东大村蒜溪创客示范基地被评为省级乡村旅游创客基地。“花果莆田—四季采摘”成为了莆田乡村旅游的一大亮点，书峰枇杷节、华亭杨梅节、度尾文旦柚节、钟山甜柿节等一系列活动，有力地推动我市乡村旅游朝着规模化、常态化、产业化、市场化方向发展。探索莆仙文化+文物+非遗+民俗等模式，培育“一县区一品、一镇一品、一村一品”特色文化品牌。实施“莆阳开春，开河、开街、开村”，活动，通过打造双福村、白塘湖、萝苜田历史文化街区、吴江村、北大村、东阳村等文化特色鲜明的旅游休闲乡村和街区，让莆田文旅产业动起来、活起来、旺起来。

四、关于加强技术培训的建议

近年来，我市高度重视乡村旅游人才培训工作，先后选送乡村旅游村干部30多人次参加省、国家组织的乡村旅游业务培训班，市里每年举办一期乡村旅游专题培训班，组织乡村旅游经营户、乡村旅游带头人、乡村旅游管理人、乡村旅游讲解员等各类实用人才培训，帮助乡村旅游村干部转变思想观念，提升文化素质和知识水平，提高乡村旅游管理服务能力。

下一步，我局将进一步推进乡村旅游提质升级，支持旅游村非遗传统文化的活化利用和创新发展，大力培育打造一批全国乡村旅游重点村、国家全域旅游示范区、省级全域生态旅游小镇和金牌旅游村，持续打响乡村旅游知名品牌。挖掘乡村特色旅游资源，加大乡村旅游宣传推介，加强农村文化市场监管，推动农旅融合，促进我市旅游市场全面发展。
