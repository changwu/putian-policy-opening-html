关于市八届人大五次会议第1352号建议（或议案）的答复

发布时间：2025-02-28 17:35
| | |
 赖晨龙代表：

《关于推动民宿提质升级为文旅产业添活力的建议（或议案）》（第1352号）收悉，现答复如下：

近年来，随着旅游业快速发展，旅游基础设施不断改善，景区品质和产品不断提升，游客也从生态观光型向休闲度假型转变，民宿业越来越得到各方重视，民宿的发展呈持续快速增长的态势。许多地方民宿预订火爆，成为节假日消费的一大亮点。民宿创造出来的商机引得大伙争先恐后的进入民宿经营这一模块，在竞争者众多的情况下，品质、服务以及效率的经营管理竞争力需求，影响力慢慢出现，随之而来的是国家和一些地区针对民宿发展陆续出台的一系列政策，如：2015年11月19日，国务院网站发布《国务院办公厅关于加快发展生活性服务业促进消费结构升级的指导意见》，首次点名“积极发展客栈民宿、短租公寓、长租公寓等细分业态”；2016年1月27日，《中共中央 国务院关于落实发展新理念加快农业现代化实现全面小康目标的若干意见》发布，其中明确指出要大力发展休闲农业和乡村旅游，有规划地开发休闲农庄、乡村酒店、特色民宿、自驾露营、户外运动等乡村休闲度假产品；2017年8月，国家旅游局《旅游民宿基本要求与评价》在市场准入方面，强调民宿经营者必须依法取得当地政府要求的相关证明，并满足公安机关治安相关要求，民宿单幢建筑客房数量应不超过14间（套）。

关于你提出的建议，对推动莆田民宿业的发展具有很强的指导性和可操作性，我局将加强研究，并在今后的工作中加以实施。

一是完善旅游民宿政策保障。我市已出台莆田市促进民宿高质量发展若干措施，对获评甲、乙、丙级旅游民宿，分别给予10万元、5万元、3万元奖励。秀屿区政府、湄洲岛管委会也出台民宿发展扶持措施。下一步，我局将积极配合其他县（区）人民政府（管委会）尽快出台民宿发展政策，明确相关部门的职责，健全和完善审批机制（消防安全许可证、特种行业许可证、营业执照、卫生许可证等），简化审批程序，加强行业指导。如鼓励村民或投资者租赁集体用房或移民后闲置的房屋，以租赁、入股等方式进行多模式的开发经营；维护产权与经营权分离；及时收集和发布民宿数目、供需情况、产能利用率等信息；开展民宿旅游市场专项整治，规范民宿旅游市场运行秩序，提升民宿旅游业的服务质量。

二是夯实旅游民宿人才基础。2023-2024年，我局组织2期湄洲岛民宿主人、民宿管家参加全省“数字木兰”计划培训，推动省民宿协会在湄洲岛举办1期民宿主人、民宿管家培训班，湄洲岛上的民宿主人、民宿管家近60人参加了培训，培训内容涵盖民宿管理知识、服务技能提升、基础数字技能、应急处理能力以及基础摄影技巧等。通过培训，有效提升了旅游民宿主人、民宿管家及从业人员的综合素质、职业技能和应急处置能力，为民宿管家打造一条通往职业化、专业化的成长路径。下一步，我局将继续商请省文化和旅游标准化建设中心、省民宿协会加大对我市旅游民宿主人民宿管家的培训力度，不断提升全市旅游民宿的服务水平、服务技能和应急处置能力。

三是提升旅游民宿接待品质。按照国家标准，把好等级旅游民宿评定关，在主题客房、特色餐饮、农事体验、工艺研学、亲子课程等产品开发中，深度融入莆田文化旅游元素，打造特色鲜明、品质优良的民宿产品体系，满足不同消费群体需求。目前，湄洲岛已有4家民宿被评定为丙级旅游民宿。下一步，我局将进一步靠前指导，按照《旅游民宿基本要求与评定划分》，加强对全市旅游民宿硬件设施设备、服务水平及服务技能提升的指导，促进全市旅游民宿软硬件提质提级，争取我市有更多的民宿被评定为等级旅游民宿。

四是推进旅游民宿快速发展。我市民宿总体发展不平衡、良莠不齐、模式单一。湄洲岛在旅游业快速发展、旅游需求不断变化的背景中，湄洲岛家庭旅馆业抓住了契机，以家庭房屋为依托，以岛民为经营管理者，以妈祖文化和滨海特色为支撑点，成立湄洲岛家庭旅馆协会，充分发挥家庭旅馆协会的自我管理、自我约束、自我服务作用，不断把家庭旅馆业发展成为湄洲岛旅游的新名片和新亮点。目前，湄洲岛有旅游民宿662家，房间6021个，床位10221个，秀屿区有民宿11家，房间144间，床位226个，为入住旅游者呈现了原汁原味的滨海风光，很受游客欢迎。为进一步推进全市民宿旅游业发展，下一步计划将湄洲岛民宿发展经验向全市推广，为全市民宿发展提供参考。

五是加大旅游民宿宣传营销。我局将高度重视民宿旅游业的品牌推广，按照你的建议，收集全市民宿数量，在旅游宣传册中增加民宿板块等，摆放到全市Ａ级旅游景区游客服务中心。充分利用厦门旅博会、“9.8”投洽会、福建旅游交易会、莆田旅游推介会等，加强我市民宿旅游业的宣传营销，扩大我市民宿旅游知名度，为促进我市民宿旅游业加快发展营造良好环境。

六是建立健全民宿行业组织。我局将依托市旅游协会，推

动设立民宿行业分会，协调处理政府职能外的相关事宜。如：除政府既定的审批和监管机制外，一些政策的推广及行业管理规范由民宿行业组织实施；民宿行业人才培养、平台建设、咨询评估等方面由民宿行业组织制定等。强化民宿诚信经营引导，加强等级旅游民宿质量监督，倡导民宿行业合法经营、诚信服务，建立健全诚信管理体系，防止不平等竞争、恶性竞争等行为。

七是加强等级旅游民宿安全监管。将全市等级旅游民宿纳入安全督导指导范畴，强化部门联动，在重要节假日及春季、夏季等重要时间节点，协同公安、交通运输、住建、应急、市场管理、消防等部门，联合对等级旅游民宿进行安全检查和服务质量督查，促进旅游民宿依法运营，规范旅游民宿管理，强化等级旅游民宿安全综合监管，推动全市旅游民宿产业规范安全高质量发展。

在此，谨对您提出的关于推进我市民宿旅游业发展的建议、对莆田文化旅游业发展的关心表示衷心的感谢！
