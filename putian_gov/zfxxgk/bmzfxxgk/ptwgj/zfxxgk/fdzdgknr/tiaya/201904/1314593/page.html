关于市政协五届三次会议第2009187号提案办理情况的答复

发布时间：2009-06-01 08:00
| | |

　　尊敬的陈春森委员：

　　你提出的“关于整治莆田旅游环境，树立妈祖故乡良好形象的建议”提案收悉，现将办理情况函复如下：

　　诚如你所说，近几年来，我市旅游业出现稳定发展的势头，产业规模不断扩大，产业形象日益鲜明，取得了较大的成绩。特别是作为全球妈祖祖庙所在地的湄洲岛国家旅游度假区，每年到该岛朝圣旅游的游客就超过100万人以上。但同时也出现了一系列问题，如旅游景区及其周边环境脏乱差，在通往湄洲岛的文甲码头和宫下码头地区表现尤为突出。针对这些问题，我局联合有关部门采取以下措施进行整治：

　　一、已将旅游环境脏乱差的整治措施列入政府颁布实施的《莆田市旅游发展专项规划》中，在《规划》中明确提出要“建立环境卫生规章制度，加强教育，强化旅游从业人员和游客的环境卫生知识，提高旅游区环境卫生水平”，对旅游环境保护高瞻远瞩地进行预防和治理。

　　二、在《莆田市旅游发展专项规划》中提出，要是将在莆田市旅游协调领导小组的基础上进一步提升规格，成立莆田市旅游发展领导小组，领导小组组长由市委或市政府主要领导担任，市委副书记、副市长任副组长；旅游局长任办公室主任，相关部门领导及县（区、管委会）分管领导任成员，使之更具有权威性和高效性。各职能部门要按照各自的职能分工，与旅游管理部门密切协作，形成合力，共同把旅游环境预防和整治工作做好，从而进一步提高旅游管理水平为促进旅游规范发展，旅游管理走上法制化、规范化、制度化轨道提供组织保证。

　　三、是联合相关职能单位，进一步加大对旅游景区（点）、码头周边及主干道的执法力度。除了市旅游局行政执法人员加强景区的日常检查外，建议湄洲岛管委会尽快成立具有执法资格的旅游质监队伍，以加大执法力度，随时处理违规行为。2008年共出动旅游执法人员96人次，检查旅游团队200多团，检查导游员300多人，纠正了50多名导游员的违规行为，有力促进了我市旅游市场的健康发展。市交通局已责成北岸运管站，湄洲岛运管所采取了以下措施：一是抓督查，促规范，强化“三把关、一监督”的源头管理职责。二是做好本职工作，严厉查处拉客、宰客违章，同时，积极配合公安派出所、交警等部门共同维护码头秩序，加大打击非法营运车辆力度。三是强化值勤制度，加大监管力度。合理安排执法人员在文甲、宫下候船厅码头客运站等地值勤。四是督促忠湄轮渡公司对两边码头的旅客采取分区管理、户外售票等措施，减少候船大厅压力，控制上船人数，确保渡运安全畅通。市公安交警部门加强勤务管理工作，高峰期间在文甲码头停车场坚持巡查和管控；黄金周和妈祖“3.23”节日期间开展统一整治月活动，对旅游景区周边乡镇开展道路交通秩序集中整治。全力维护旅游景区的道路通行秩序。去年以来，在文甲码头共出动警力1000余人次、警车300多辆次；查处车辆违法停放达600多辆次，打击无牌无证车辆40多辆次；规范码头车辆停车秩序，规划停车泊位360个。下一步将采取以下措施继续加大对旅游景区及其周边的交通秩序整治工作，确保旅游景区道路交通安全畅通。一要加大整治力度。增加路面一线警力，强化路面巡查和管控力度，依法依规查纠交通违法行为，重点查处无牌无证、超速行驶、车辆超载、强行超车、车辆违法停放等交通违法行为；积极会同交通部门对非客运车辆违法载人进行专项整治，齐抓共管、共同打击非法营运车辆。二要增加停车泊位。加强车辆源头管理、规范停车秩序，在原有的停车泊车的基础上，进一步规划文甲码头停车泊位150个。市城管执法局多次与北岸管委会、山亭乡人民政府、边防、工商、交管等部门成立联合执法小组，采取先劝导后强制的措施，设置围栏，规范摊点集中摆放，规范车辆停放，对出现占道经营现象进行严厉打击，至2009年5月共纠正占道作业及经营180余起，强制拆除沿街两侧违章乱搭盖600多平方米。同时在重大的节日都有安排执法人员加强现场值班巡查，及时纠正有违市容市貌现象。目前文甲码头广场整体路面硬化已建设完成，执法大队将与各个部门加强交流，共同探索长效的管理机制，进一步规范整体市容市貌，营造良好的旅游环境。针对野广告、黑广告等‘牛皮癣’现象，市城管执法局秀屿大队先后共组织多次对此类现象进行了全面清理，同时大队还与文甲村针对此类现象进行了专门探讨，当地村委会已经加强了日常的保洁工作，聘请清洁工进行清理，至2009年5月份共清理乱张贴广告1200余张，乱悬挂布条200余条。并发动当地协管员及群众对发现有乱粘贴的及时举报，大队将在第一时间采取措施，目前这一现象已经得到了明显的好转。

　　四、加大宣传力度。市工商局、公安局、交通局、执法局等职能部门都采取了多种方式进行宣传，特别是大大地增大了公益广告的宣传力度，通过强化宣传，增强了公民遵守各种法规的自觉性。我局也将逐步采取多种形式来加大宣传力度，如充分利用电视、报刊、画册、明信片、挂历、邮票、互联网等传播效应，激发群众热爱莆田市、为游客服务的热情。同时配合市电视台，全程跟踪拍摄旅游执法人员在湄洲岛的执法过程，公开、及时曝光“野导”、“黑车”欺客宰客、尾追兜售等各种违法、违规行为，从而保障我市旅游业健康有序发展。

　　衷心感谢你对我市旅游事业的关心和支持，恳切地希望你多为促进我市旅游事业的全面发展提宝贵意见。

　　分管领导：温训新

　　联系人：蔡雪松

　　二OO九年五月三十一日
