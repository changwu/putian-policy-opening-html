关于市七届人大四次会议第0085号建议（议案）的答复

发布时间：2020-05-13 16:07
| | |

黄长城代表：

你提出的关于“一带一路”背景下莆田海上旅游文化创意园暨开发海上旅游的建议（议案）收悉，现答复如下：

感谢你对我市海上旅游发展的关注和支持，你提出的开发海上旅游文化创意园的建议，是一个新的课题，对我市开发海上旅游指出一条新的发展方向。我局将加强研究，并在今后推动海上旅游发展规划和项目建设中充分借鉴，加以落实。

一、关于“文创区域”相关建议

目前，我市海上游船还处于起步阶段，仅湄洲岛建有快艇码头（可供游船靠泊），但没有专用游船码头和游船，南日岛和平海湾均没有游船码头和游船。下一步，我们将按照你提出的建议，在规划游船、邮轮码头建设中，在游船码头公共服务空间及游船上设置专门区域，用于“展示相关莆仙老照片及湄洲岛和妈祖文化的历史简介和区域讲解，深度体现当地人文特色，如莆仙戏、闹元宵、红团卤面炝肉特色美食、四大名果、南少林武术表演、工艺手作、湄洲女发髻表演等莆田招牌。设立纪念品销售专区和免税购物商店，展示和售卖特色旅游伴手礼；举办妈祖文化旅游节、海峡论坛-妈祖文化活动周等活动时，设置游船配套相关活动，利用游轮内部会议室和活动空间，邀请中国海洋协会等相关团体，举办有关于“海上丝绸之路”及海洋文化有关的各种研讨会和学术交流，定期邀请文艺团体举办摄影展及画展，主体密切围绕莆田的历史底蕴，凸显“文献名邦”的历史地位，进一步助推莆田在国内的知名度”。

二、关于“设置相关主题展览馆”的建议

你提出的“利用现代的3D动画技术，通过动画的形式，展示千年前郑和下西洋的盛况、模型以及海上丝绸之路沿岸国家的异域文化、物品等”建议，目前，我市旅游景区的宣传模式较为传统，运用现代技术展示文化旅游资源相对较为落后。下一步，我局将根据的建议，探索邀请第三方专业机构进行合作，有效整合海丝特色旅游文化资源，推动一些重点旅游景区景点（例如古谯楼、南少林、九鲤湖、九龙谷、南日岛、妈祖庙、百年南洋建筑华侨民居后黄村和罗屿港等）设置宣传专区及相关主题展览馆，运用3D动画技术，重现古代渔业和妈祖林默生平事迹，福建三大渔女之一的湄洲女服饰、发髻等。

三、关于“当地特色美食”的建议

莆田具有独特的美食文化，在国内可谓闻名遐迩，备受各地食客所青睐。2017年，原福建省旅游局举办“福建好礼“百佳旅游商品评选活动，我市有4件旅游美食入选（分别是莆田桂圆干、63号枫亭糕、南日鲍罐头、宴江南佛跳墙）；你提出“美食是旅游途中不可或缺的一环，海上旅游文创园将对这一部分进行重点规划，打造全新的海上旅游餐饮，做出特色”等建议。我们将结合开放招商，邀请第三方专业设计团队，认真策划海上文化创意旅游项目，把莆田地面上的美食发展到海上游船邮轮，打造新型景点和我市特色滨海旅游黄金项目及新一代城市网红打卡地标，使游客在用餐的时候能尽情的领略海丝文化和异域风情。

四、关于“建设海岛度假、垂钓基地”的建议

莆田海洋旅游资源丰富，拥有湄洲湾、平海湾、兴化湾三大港湾和湄洲岛、南日岛两大宝岛，辖区海域总面积1.1万平方公里，海岸线总长443公里。莆田是中国海洋文化的发祥地，海上女神妈祖从这里诞生并走向世界，被誉为海上丝绸之路的保护神，是海上丝绸之路重要的文化纽带。明代郑和七下西洋，在世界上弘扬了以妈祖文化为基础的中华海洋文明，郑和所到之处大都建有妈祖宫庙，因而海上丝绸之路的沿途各国特别是东南亚诸国，无不留有大量的妈祖圣迹、文化等。因此，妈祖文化是福建、乃至中国最重要海洋文化旅游资源。

目前，湄洲岛在市委市政府的高度重视下，经过多年的开发，妈祖文化品牌不断扩大，逐渐从宗教朝圣向休闲度假海岛转型，2019年11月，湄洲岛创建国家5A级旅游景区顺利通过国家文化和旅游部的景观质量评价，取得了重大突破。南日岛是莆田的第一大岛，推进海洋牧场建设，着力构建“风行海西、鲍打天下”的海洋经济发展新格局，南日海域盛产的南日鲍享誉全国，是中国地理标志，岛上拥有众多战地人文景观资源与自然旅游资源，是典型的原生态海岛。此外，南日岛拥有“中国海钓基地”的称号，吸引众多国内外海钓爱好者，被誉为海钓天堂。南日岛旅游开发虽处于初级阶段，旅游景区建设与旅游基础设施建设还有待进一步完善，但南日岛以“海峡两岸海钓(矶钓)邀请赛”与“海峡两岸海钓(矶钓)邀请赛暨全国海钓(矶钓)锦标赛”为契机，联合南日十八列岛，未来的发展目标是建设中国海钓基地，打造不同的海钓体验项目。

下一步，我们将按照你的建议，加快推进南日岛海洋文化和旅游开发建设，加大招商引资力度，引进央企或国企对南日岛的旅游进行全面开发，做强休闲渔业与海岛旅游，促进旅游业与渔业的高度融合。深挖海岛资源，构建“渔业养殖、风力发电、海岛生态旅游”的三大产业联动体系。一是充分利用海洋养殖优势。依托海洋牧场建设，持续推进鲍鱼、紫菜、龙须菜、石斑鱼等海产品繁育、生产基地建设，进一步规范养殖，科学用海，拓宽延伸产业链，促进南日水产品加工向精深化、品牌化、规模化、功能化方向发展。加强与市乡村振兴集团的合作，着力开发建设南日东部现代渔业综合示范区项目，发展新型塑胶渔排，对东岱湾养殖区域进行科学规划，不断提升养殖区的抗灾能力和经济效益，打造集滨海港湾、休闲垂钓、观光体验、观赏渔业、渔文化保护等多元化的特色“海上快乐农庄”。二是逐步扩大旅游业比重。依托海岛、海风、海景、海滩等生态资源空间组合，将发展旅游业作为发展海岛新产业的突破口，坚持产业、文化、旅游“三位一体”的发展理念，充分挖掘岛屿及海洋自然资源和人文资源，打造“风情南日、度假胜地”旅游品牌。突出以中心村、生态旅游特色村建设为重点，加快推进港南村全域旅游建设，开发建设九重山景区、笔架山景区、南日岛海洋庄园项目，不断完善旅游观光、休闲度假、亲水娱乐、渔俗体验等功能设计，循序推进特色旅游产业发展。三是开发海洋特色文化产品。以南日岛浮叶村正月十八的特色元宵节为主，把“闹元宵”路线与主要景点、街巷空间以及周边自然景点串联为一体，启动大峤鱼山“浮斗观日”生态修复，看闽南民俗，游街巷“迷宫”，开展浮叶岛礁观光，建立台湾小额保税商品旅游商贸区、浮叶渔港码头观光购物区、“闽南风情渔家乐”等，形成自然与人文交融的旅游体验区。带动沿海民俗节庆联动发展，开发传统节庆旅游产品，进而提升我市影响力。

五、关于“在我市，游艇业有很大的发展空间”的建议

当前，中国特色社会主义进入新时代，作为旅游业和接待业完美结合的邮轮游艇旅游产业已经成为现代旅游业中发展最为活跃的产业之一。邮轮游艇旅游产业的经济效益十分显著，其强大的拉动能力和吸附能力已成为拉动城市经济的新动力，并刺激周边地区经济的迅速增长。近年来，国际邮轮经济重心开始向欧洲和亚太地区倾斜，一带一路的倡议为邮轮旅游的开放合作提供了更大的空间。但从我省邮轮发展情况看，目前仅有厦门已经开展了邮轮旅游，邮轮游艇旅游仍处于产业发展的幼年时期和起步阶段，还存在许多需要探讨的问题，仍缺少总体规划。

莆田秀屿港位于秀屿区东庄镇莆头村，是“中国少有，世界不多”的天然深水良港，介于福州与厦门和香港与上海之间，东距台湾台中港72海里，北距福州马尾港132海里，距上海港510海里，南距厦门港96海里，距香港397海里，是我国沿海对外开放地带及对台往来的交通枢纽。1995年被国务院批准为对外开放的一类口岸，是台湾海峡两岸人流、货流的重要口岸。湄洲岛作为一个文化特色国际旅游度假名岛，具有较大的吸引力，岛上具备较为完善的游客接待设施，拥有大规模的散客或团客的旅游接待经验，适合发展邮轮游艇。南日岛生态资源良好，沙滩及岸线资源优质丰富，拥 有“山、海、沙漠”三景共存的奇观，适宜发展游艇、快艇、钓艇等为主的轻奢生态度假游。2019年，也列入《福建省邮轮旅游产业发展规划》。

下一步，我局将按照你的建议，大力推动邮轮游艇旅游发展，以市委、市政府开放招商决策为契机，拟邀请国内知名规划设计单位，全面进行招商项目的梳理和筛选、价值评估、投资策划包装、招商政策梳理等综合性服务工作，有效整合我市港口资源，认真策划“邮轮、游艇、游船”招商项目，同时加大招商推介力度，与专业招商咨询和执行机构进行合作，引入“互联网+”，构建“线上+线下”的“云招商”平台，开展远程对接、视频选址、网上注册等在线服务等，把文旅招商工作与世界妈祖论坛、妈祖文化旅游节、莆田艺博会、文旅博会、旅游生活展、旅游推介会等充分结合，通过“走出去”和“请进来”的方式，统筹开展文旅推介和项目招商对接。在网站、微信公众号等设立开放招商专栏，滚动发布重点产业信息、投资环境、招商载体、项目动态，公布招商服务机构联系方式，提供产业政策速递和咨询服务。拓宽交流合作和招商引资渠道，坚持平台招商、生态招商、以商招商，充分交流开放招商经验和做法，形成全市文旅系统各单位、各协会、各企业全员招商的氛围。积极对接邀请国内外知名文旅企业到湄洲岛、南日岛、秀屿港、平海湾等现场考察，洽谈游艇等滨海旅游开发合作，积极探索“政府+N”或引进社会资本注入，有效开发邮轮、游艇、游船等旅游产品，做大做强我市滨海文化旅游品牌。同时，全面加强海洋防灾减灾能力建设。着力提高全民海洋生态意识，切实推进海洋防灾减灾公共基础设施建设，以全面启动莆田南北岸国家级“蓝湾整治”工程和湄洲岛生态修复建设为契机，深入实施莆田海洋防灾减灾“十百千”工程，加快提升“十座渔港升级改造、百里岸线减灾修复、千艘渔船通导管控”功能，整合建立智慧海洋信息化平台，充分运用海洋灾害风险评估区划成果，努力创建国家级海洋防灾减灾示范区，逐步打造妈祖故乡近岸海域生态安全屏障。

最后，再次感谢黄长城代表对莆田文化旅游的关心和支持，希望一如既往的对莆田文化旅游业的发展提供宝贵意见！
