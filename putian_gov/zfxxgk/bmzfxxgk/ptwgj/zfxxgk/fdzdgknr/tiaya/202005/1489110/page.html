关于市七届人大四次会议第0032号建议（议案）的答复

发布时间：2020-05-13 16:05
| | |

王元柱代表：

你提出的关于做大做强我市乡村旅游业的建议（议案）收悉，现答复如下：

非常感谢你对莆田市乡村旅游发展的关注和支持，你提出“充分利用我市乡村丰富的旅游资源，不断提升完善软件硬件水平；转换发展动力机制，壮大乡村旅游业；融入全域旅游理念，注重农耕文化的传承与创新；积极打造生态家居新乡村，让乡村旅游更好助力乡村振兴；加强乡村旅游乡土专业人才培训，助推美丽莆田乡村旅游发展；适度扶持规范的旅游客运企业，助推我市乡村旅游发展”六点建议具有很强的针对性、指导性和可操作性，我局将认真研究，并在今后的工作中充分借鉴，采取有效措施加以推进。

一、关于充分利用我市乡村丰富的旅游资源，不断提升完善软件硬件水平的建议

我市乡村山川秀丽、风光如画。山乡云缠雾绕，梯田重迭，山青水秀林美；水乡平畴沃野、水网交错，稻海蔗浪荔花飘香；海乡依陆临海、海阔天高，阳光海浪沙滩迷人；既有气势磅礴的流泉飞瀑(以九鲤湖飞瀑、济川粗溪温泉为代表)，又有微波荡漾的人工湖泊(以东圳水库为代表)；既有美丽迷人的海滨风光(以湄洲岛、湄洲湾为代表)，又有怪石嶙峋的群峰绝壁(以菜溪岩、永兴岩、麦斜岩为代表)；既有年代久远的古树名木(以唐荔宋家香、东晋樟树、宋荔枝王为代表)，又有四季飘香的鲜花佳果(以荔枝、龙眼、枇杷、文旦柚、市花月季为代表)等等，无不以其乡村风光的独特魅力吸引着中外游人。

今年，我局将大力支持乡村旅游品牌建设，对被评为国家5A级、4A级、3A级景区，分别给予一次性奖励300万元、100万元、50万元；被评为省级五星、四星、三星级乡村旅游休闲集镇，分别给予一次性奖励80万元、60万元、40万元；省级五星、四星、三星级旅游村，分别给予一次性奖励50万元、30万元、20万元，重点扶持乡村旅游基础设施项目建设，提升乡村旅游公共服务水平。

二、关于转换发展动力机制，壮大乡村旅游业的建议

根据福建省旅游局《乡村旅游“百镇千村”三年行动计划》，全市共打造了乡村旅游休闲集镇10个、乡村旅游特色村99个，闽台乡村旅游示范基地1个、试验基地1个，四星级休闲集镇3个、旅游村6个，三星级休闲集镇2个、旅游村5个，三星级以上乡村旅游经营单位35个，乡村旅游重点扶贫村15个。榜头镇被评为全省十佳乡村旅游休闲集镇，后黄村、坪盘村被评为全省二十佳乡村旅游村、省级金牌旅游村和乡村旅游模范村，湄洲岛下山村被评为省级金牌旅游村。被评为乡村旅游致富带头人2个、乡村旅游模范户2人。我市乡村旅游发展的水平正在不断的提升，成功开发了农耕体验、农产品采摘、田园观光、民俗文化等旅游产品，不仅吸引了大量市民和周边地区游客前来观光，同时也增强了我市乡村旅游的吸引力。

今年，我局将继续按照《福建省乡村旅游“百镇千村”提质升级三年行动方案（2018-2020年）》（闽旅发法〔2018〕27号），年度计划创建省级乡村旅游村8个，乡村旅游四星级休闲集镇1个、旅游村3个，三星级休闲集镇1个、旅游村4个，择优培育一批省级“金牌旅游村”、“全国乡村旅游重点村”，鼓励发展乡村民宿旅游、A级旅游景区创建等，推进乡村旅游发展的新热点，持续打响乡村旅游知名品牌。

三、关于融入全域旅游理念，注重农耕文化的传承与创新的建议

近年来，我局认真贯彻市委市政府关于乡村振兴的统一部署，积极探索乡村旅游发展新模式、新途径，按照一村一品的发展思路，大力打造乡村旅游综合体，培育了各具特色的乡村旅游典型。如：白沙镇香积国香草庄园主营有机蔬菜、香草植物的种植及观光农业，是福建省首家以香草为主题的复合式休闲农庄，被评为“省级休闲农业示范点”和省级乡村旅游四星级经营单位称号；白沙镇坪盘村依托新农村建设的成果,取得省级乡村旅游三星级接待单位；大洋乡笛韵森林人家利用红色文化和生态资源建成集餐饮、住宿、会务、旅游、娱乐为一体的休闲山庄；后海垦区利用福建省休闲渔业示范基地和“水乡渔村”的资源优势，形成独具特色的渔村旅游景观。同时，创新管理模式，坪盘村建立了“集体+农户+公司”的旅游发展经营模式，后黄村和莆田康辉旅行社结合形成联合体共同开发后黄村乡村旅游。

我局认真贯彻落实《建设美丽莆田行动纲要》，以全域旅游行动为总抓手，紧紧围绕旅游景区提升、产业融合、设施完善、品牌创建、环境治理“五大工程”，共推进旅游项目107个，完成投资51多亿元，推动旅游各项工作全面提升。全面推进旅游厕所革命，2015以来，全市共完成新改建旅游厕所277座（新建210座、改扩建67座），乡村旅游厕所得到了明显改善，旅游公共服务水平得到了快速提升。同时，在发展乡村旅游过程中，注重从美丽乡村建设、农村人居环境整治等方面为发展乡村旅游提供优美的农村环境。自2012年开展美丽乡村建设以来，采取“抓点示范、分类实施、全面推进”方法，拓展美丽乡村建设内涵，逐步改善村庄人居环境，打造了一批“宜居、宜业、宜游”的可持续发展美丽村庄，全面提升村庄生产生活条件，至2019年底，全市累计整治484个美丽乡村，通过建立完善农村垃圾、污水处理系统，实施绿化亮化、文化建设以及群众素养提升等工作，先后建成一批美丽乡村示范村，如：西天尾镇后黄村、华亭镇涧口村、白沙镇坪盘村、龙华镇金溪村等，全市农村人居环境得到有效提升，有力促进了我市乡村旅游的发展。

我们将根据你的建议，重视加强全域旅游顶层设计，把乡村旅游业发展融入到全域旅游规划加以推进，大力促进“旅游+”产业深度融合，选择工艺美术、食品加工、海洋养殖、基地农业、生态农业、景观水利等特色产业，力争建设一批文化旅游产业标杆基地，以此带动文旅产业融合发展。继续按照乡村振兴和农村人居环境建设工作要求和部署，全力推进乡镇生活污水治理，提高乡镇污水处理率；推进既有农房整治，有效改变村庄建筑风貌；推进村容村貌提升，做好村庄房前屋后整治，整治村庄公共空间和庭院环境；推进福厦铁路、向莆铁路沿线环境综合整治提升等相关工作，进一步整治建设宜居村庄，优化乡村生活环境，为我市乡村旅游的快速发展创造更加优美的农村环境。

四、积极打造生态家居新乡村，让乡村旅游更好助力乡村的建议

近年来，重视“大农业”与“大旅游”有机结合，以现代农业产业为依托，以抓好示范点建设和申报国家级、省级示范点为重点，以单一的观光型向农事体验、展示教育、休闲度假等多类型、多业态发展为突破，为做大做强我市乡村旅游业添砖加瓦。2010年至2013年，每年都申报获得省休闲农业示范建设项目的立项补助1个以上，每个获得补助资金5—10万元，共获得补助31万元。全市有全国休闲农业与乡村旅游示范点2个（城厢区九龙谷生态风情园和仙游聚仙堂生态休闲山庄），省级休闲农业示范点11个（坪盘村、九莲山庄、香积国香草庄园、桂花香等），福建最美休闲乡村2个（仙游县石苍乡济川村和荔城区西天尾镇后黄村）。截止2019年底，我市共有休闲农业经营主体64个，从业人数0.3万人，其中农民从业人数0.1万人，带动农户数0.8247户，接待人次214.8万人，营业收入2658万元，其中农副产品销售收入560万元，利润总额965.55万元，从业人员人均工资额3.57万元。

扎实推动“绿盈乡村”建设工作。根据《福建省实施乡村振兴战略乡村生态振兴专项小组关于做好2019年乡村生态振兴工作的通知》精神，以“绿盈乡村”创建为抓手，推动富有绿化、绿韵、绿态、绿魂的乡村生态振兴村建设。通过摸底调查、走访调研，对照“绿盈乡村”建设指标体系找差距，对有短板薄弱项的村庄提出针对性措施，以生态环境为目标，促进乡村生态振兴工作落细落实。2019年底全市共创建初级版“绿盈乡村”275个，推荐上报48个拟创建高级版“绿盈乡村”的村庄，占比达到30%以上。

下一步，将继续大力培育休闲农业示范项目。一是优先支持示范建设项目。按省农业厅要求，做好休闲农业示范建设储备项目调查备案。此外，在种养业“五新“项目、园艺作物标准化示范和一区两园等项目，给予休闲农业企业倾斜支持和优先安排。二是积极组织申报示范点。按要求组织各县区发动符合条件的休闲农业企业申报国家级、省级休闲农业示范点，推荐莆田市涵江区萩芦镇崇福村、仙游县西苑乡凤山村、荔城区北高镇山前村、仙游县龙华镇金溪村申报中国美丽休闲乡村。三是落实一次性奖励政策。根据市委市政府2012年出台的《莆田市旅游产业发展意见》，对获得国家级、省级农业旅游示范点的企业分别给予20万元、5万元的一次性奖励。市农业农村局将积极与市财政局协调，将该项奖励在去年列入现代农业发展专项资金补助，对获得省农业厅确认的省级休闲农业示范点，给予一次性奖励补助5万元；对获得农业部和国家旅游局联合认定的全国休闲农业和乡村旅游示范点，给予一次性奖励补助20万元。四是推进优惠政策出台。积极配合推进《福建省人民政府关于促进休闲农业持续健康发展的意见》政策文件的出台，落实省政府办公厅出台的“关于支持农民工等返乡人员创业十二条措施”相关政策，争取在用地、交通和税收等方面均有优惠政策，并实行对休闲农业示范点进行奖励，对获得国家级、省级休闲农业示范点的创业企业，分别给予一次性补助60万元、40万元，为全省发展休闲农业创造更好的政策条件，鼓励返乡人员发展休闲农业。

五、关于加强乡村旅游乡土专业人才培训，助推美丽莆田乡村旅游发展的建议

近年来，我局高度重视乡村旅游人才培训工作，先后选派36名乡村干部赴台乡村旅游培训，选送乡村旅游村干部20多人次参加省、国家组织的乡村旅游和旅游扶贫人才培训班，市里每年举办一期乡村旅游专题培训班，组织乡村旅游经营户、乡村旅游带头人、乡村旅游管理人、乡村旅游讲解员等各类实用人才培训，帮助乡村旅游村干部改变思想观念，提升文化素质和知识水平，提高乡村旅游服务能力。

六、适度扶持规范的旅游客运企业，助推我市乡村旅游发展的建议

近年来，我市不断完善乡村交通基础设施建设。一是推进通等级以上公路。为大力建设旅游公路网,实现从高速路口、主要交通枢纽中心到各景区之间快速、畅通对接，促进旅游产业跨越发展，自2014年起，我市规划拟建旅游公路26条共279公里，总投资约50亿元。至目前，已建成14条152.3公里，在建3条27.8公里，完成投资36亿元。已有旅游景点基本通双车道（宽度6.5米）以上等级公路，实现通客车基本条件。二是完善旅游交通道路指引标志。随着大众旅游时代到来，自助旅游已成为一种新兴的出游方式，旅游服务更需要交通作为保障。旅游交通道路指引标志作为旅游交通服务和景区公共服务的重要载体，自2014年以来，我市根据省交通厅和省文旅厅要求，已经在动车站沿线、高速公路出口处、国道通往3A级以上景区路段设置公路游客公共交通服务标志牌（湄洲岛国家旅游度假区、莆田工艺美术城、九龙谷生态景区、仙游九鲤湖、莆田古典工艺博览城、莆田御庄园温泉度假村等）共73面，完成投资283.6万元。2016年，新增4A 级景区瑞云山风景区，完成公路游客公共交通服务标志牌12面，完成投资23.92万元。全市通往旅游景区标识系统正在不断完善。三是扶持规范旅游包车客运业务。至目前，全市共有市际旅游包车客运企业12家、运力145辆，比2018年新增旅游客运企业6家、增长100%；新增旅游运力55辆、增长61.11%。将进一步方便各单位组织和群众群体包车出行，特别是乡村旅游交通出行将更加便捷、安全。进一步发展我市旅游客运健康发展，2019年4月29日，市交通运输局印发《市、县区（管委会）、乡镇（街道）三级交通运输行政审批服务事项统一目录》（莆交运法〔2019〕16号），将市际旅游包车客运企业审批、旅游包车运力投放审批下放县级交通运输部门实施。旅游包车客运运力投放，按照各县区确定的年度投放发展计划，运力投放向社会公开，采取招投标方式确定经营主体，促进旅游包车客运发展。

下一步，市交通运输局将按照你的建议，继续扶持规范的旅游客运企业。一是加强旅游交通基础设施建设。围绕全域旅游发展主线，加强旅游交通基础设施统筹规划，完善旅游交通布局，构建“快进”“慢游”综合旅游交通网络。在有条件的地方，建设一批旅游专用道路，提高连接特色景观名镇名村、乡村旅游重点村的道路等级，推进高速公路网服务功能向周边景区和乡村旅游点延伸。为实现省政府提出的4A旅游景区30分钟内上高速要求，结合我市公路网情况，2020年策划通九龙谷森林公园4A、瑞云山风景区4A高速公路连接线工程，纳入地方专项债项目。二是完善旅游景区主要交通连接线。实现城市中心区、车站、码头到主要景区、旅游度假区等景区之间的交通无缝衔接。在全市推动动车站、客运码头到4A级以上景区班线客车、旅游专线车、公交车线路，切实解决景区“最后一公里”交通运输服务困局。鼓励开通至景区的旅游专线、旅游直通车，鼓励在黄金周、小长假等重大节假日期间开通定制旅游线路，增强城乡客运线路服务乡村旅游的能力。

最后，再次感谢王元柱代表对莆田文化旅游的关心和支持，希望一如既往的对莆田文化旅游业的发展提供宝贵意见！
