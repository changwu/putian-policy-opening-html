关于市政协八届二次会议第2023084号提案办理情况的答复

发布时间：2023-07-18 15:42
| | |
 民盟莆田市委员会：

你们提出的《关于破解美丽乡村景观建设同质化的建议》（2023084号）已收悉，现将办理情况函复如下：

近年来，乡村旅游已成为一种新的产业及消费形态，正朝着集观光、休闲、康养、度假、娱乐等于一体的田园综合体方面发展。而乡村旅游项目很多涉及到土地利用规划红线，甚至涉及耕地、林地等大量农用地，有的项目在建设过程中被紧急叫停、有的项目建完后被责令拆除，一定程度造成资源的浪费，也限制了乡村旅游的快速发展。2022年8月5日，福建省自然资源厅、发改委、农业农村厅印发《保障和规范农村一二三产业融合发展用地实施细则》，明确个别以旅游发展为主的建制村，可适当放宽，但建设用地总规模应在县域内统筹。

一、关于“挖掘在地文化，做好景观主题规划”的建议

文化是旅游的灵魂，旅游是文化的载体，没有文化的乡村旅游是没有吸引力的，我局在指导编制乡村旅游规划时，注重整合各类资源，如：革命红色遗址、地域非遗、莆田四大名果等，挖掘风土人情特点，将乡村旅游资源的乡土味发挥到极致，同时要求乡村旅游规划充分征求农业、自然资源、生态环境、住建、林业、文旅等部门的意见，确保乡村旅游规划的差异性、落地性和可操作性。仙游县围绕北部山区文旅资源，加快建设仙游北部文化旅游经济开发示范带，做好“仙”字文章，打响“四仙”品牌，以“有的看、留得住、带得走、想再来”的理念，编制完成了《仙游县“十四五”文化体育旅游事业发展专项规划》的制定，明确了推动全域旅游示范创建、打造仙游旅游品牌形象、丰富旅游发展模式内容、增强文化旅游产业活力等方面的重点任务。按照县第十四次党代会精神对《仙游县全域旅游发展规划》进行修订，起草编制北部山区国际度假区总体规划，推进与国土空间规划的衔接融合。加快项目推进，2022年推动文旅产业开工项目8个，项目总投资17.34亿元，年度计划投资1.91亿元，全年完成投资21326.57万元，完成年度投资额的111.66%；策划包装申报重点景区专项债等项目，获批专项债3亿元。2023年推进市文旅重点项目6个，项目总投资15.2亿元，年度计划投资1.56亿元；启动“仙游北部旅游度假区文旅项目”、“木兰溪源头省级生态文化旅游项目”等5个国家专项债项目申报，获批额度6.49亿元。城厢区常太镇莒溪片区乡村振兴暨省级移民后扶示范区是围绕水库移民“在地文化”进行规划的示范区。总占地面积约1780亩，总投资约2.5亿元，主要建设内容为示范区入口景观、桐花漫道、龙鳞凤羽图画区、八卦古厝区、研学基地区五大板块。项目位于溪南、溪北、下莒、埔头四个村。莒溪片区依托仙游九鲤湖及九龙谷景区两个4A级景区，每年有150万左右的游客量，充分带动周边乡村发展通过挖掘提炼三大文化IP（栖梦文化、龙凤文化、移民文化），打造“龙鳞”“凤羽”田间艺术、改造提升移民“集体厝”等来吸引客流，最终形成民宿、市集、餐饮、文创、农副产品深加工五大产业，促进文旅产业融合发展与消费场景创新。作为莆田融入福州都市图的“桥头堡”，涵江区具有“拥溪抱湖”“环心面湾”的区位特点，近年来，随着涵江区旅游业发展品质不断提升，逐渐与文化、工业、农业、体育等相关产业跨界融合，突破文旅产业封闭的自循环。通过深挖文化特色，坚持因地制宜，加强对“一镇一文化一品牌”战略的持续推进，探索发展绿色生态、红色文化、蓝色海丝、金色工业研学、紫色历史文化街区的“五色文旅”品牌。例如大洋闽中司令部的红色文化、江口蒜溪的南洋文化、三江口英博雪津的啤酒文化、新县夹漈草堂的郑樵耕读文化、萩芦江春霖故居的廉政文化、白塘李富祠的家风文化等。

二、关于“乡村景观的场景化打造”的建议

我市乡村旅游资源类型多样, 各地都有绿水青山、田园景象、乡土文化、农耕文明、农家餐饮、传统手工艺等资源。近年来我市乡村旅游发展迅速，持续完善旅游厕所、乡村文旅服务中心等旅游服务体系，推动妈祖文化、传统老字号、非遗工艺、农土特产、工艺美术开发文化创意产品进景区，不断提升产业效能和附加值，目前已创成国家A级旅游景区9个（3A级4个，2A级5个），共培育创建国家乡村旅游重点村3个，福建省全域生态旅游小镇5个，福建省金牌旅游村11个，三星级乡村旅游村20个，三星级以上乡村旅游经营单位35个。城厢区马院村依托闽中革命游击队旧址，建设闽中革命游击队纪念馆，深入打造红色旅游基地。配套爱情海（玫瑰园）、忘忧谷、千亩竹海、马院新村等，形成乡村游的休闲圈。华亭镇埔柳村引导本土漫雕艺术家回村修建漫雕馆，展示其漫雕作品，开办漫雕艺术培训班，激活“漫雕+文创”产业。涵江区通过注重当地乡土文化的传承，打造注重差异化发展的示范点，持续激发乡村景观建设的发展活力。结合“莆阳开春”、“水上巴士”，提升优化白塘湖—洋尾村周边环境，挖掘了村史馆展、特色小吃、民俗表演等特色活动及白塘湖夜间经济、潮玩集市、亲子皮划艇活动、风车展、亲子乐园、露营新式茶饮、巨型北极光秀、轻奢音乐趴、非遗文化（美食）、落日大电影、水幕电影、画舫船观光、码头卡座等集音乐、美食、非遗产品、体育运动于一体的文旅活动。通过特别体验、视觉体验、故事体验等项目，不断强化游客与村民的互动交流，努力营造或质朴、或热情、或野趣、或幽静的特色乡村文化，实现产品、服务、形象的差异化发展，形成历史文化与生态绿心并重的文旅新样板，做大洋尾村环白塘湖旅游圈。

三、关于“结合互联网技术，与时俱进的乡村景观”的建议

今年来，我市实施乡村旅游商品“后备箱”工程，着力将乡村农产品、手工艺品转化为旅游商品，丰富旅游商品名录。在4A级及以上景区、重点旅游村、旅游休闲街区建设特色旅游商品店，在九龙谷景区特色商品体验点销售枇杷膏、枇杷罐头、兴化粉、莆田桂圆干、鲍鱼干、荔枝干等；在绶溪公园新凯特文创体验馆展出美陈5帧，生活创品180件，艺术创品40件等，展现老莆阳的风华绝代、古兴化的迷人之彩；在湄洲岛“妈祖平安礼”旗舰店销售“妈祖平安礼”包括赏心悦、全家服、平安瓷、海神表、味极品、海贝贝、微卡通、捏海人、茗香醇等9大类平安礼；在涵江区萩芦镇成立萩芦文旅产业投资有限公司，2021年9月正式发布区域公共品牌“五彩萩芦”，对龙眼、枇杷、樟洋大米、梅洋茗茶、南坛蜂蜜等农特产品进行包装。同步搭建“五彩优选”电商平台，借助举办萩芦龙眼文化节、云端枇杷文化节、茶文化节等活动，推出“枇杷四宝”“梅洋清茗”“五彩福粽”等一批“独一份”“好中优”的农特产品，帮助农民增收致富。自平台上线以来，仅枇杷的销售额就达上千万元，“梅洋清茗”茶叶还销往国外。仙游县推动手绘地图语音导览系统成功上线，开展仙游2022“全闽乐购·全福游·最莆惠”旅游消费季活动，在福州三坊七巷举办“仙游文旅推介会”。2023年初开展“仙游开春”文旅主题营销活动，重点在西苑乡、游洋镇举办隆重、丰富多彩的文旅活动，以仙游开春的三开，打开仙游文旅的“四仙”魅力，打响“有一种旅游叫仙游”的旅游品牌。城厢区开展“名果飘香·厢遇有福”2023年城厢区“莆阳爽夏”枇杷音乐节暨常太镇“闽台文化交流周”活动，含枇杷优质品种推介、枇杷种植能手评比、网络带货直播等活动，同时展示台湾文创艺术作品、特色小吃、现场交响乐团演奏等，旨在通过推动“景观+餐饮+活动”新型旅游模式，美化乡村景观环境，进一步增强常太枇杷文化吸引力，促进两岸文化交流，带动乡村经济、文旅产业发展。涵江区通过智慧平台，实现联动发展，借助“这就是莆田”文旅智慧平台，对全区旅游资源进行统筹整合，实现“吃、住、行、游、购、娱”的联合开发，共打造特色主题旅游线路，推动组合连贯的旅游活动，构建全域共建、全域共融、全域共享的新型旅游发展格局，打通区内旅游小循环，打响涵江特色的文旅品牌。萩芦镇崇福村引进莆田市思博文化旅游有限公司与萩芦文旅产业投资有限公司共同开发“萩山来信·崇福”露营基地，围绕微旅游、微体育、微度假需求，在各大网络社交平台热度持续攀升，不仅全面挖掘了崇福村的乡村文化价值、生态价值和经济价值，还拓宽“五彩萩芦”特色农产品销售渠道。

四、关于“倡导乡村景观由市场主导、开发运营”的建议

近年来，我局认真贯彻市委市政府关于乡村振兴的统一部署，积极探索乡村旅游发展新模式、新途径，按照一村一品的发展思路，大力打造乡村旅游综合体，培育了各具特色的乡村旅游典型。如：白沙镇香积国香草庄园主营有机蔬菜、香草植物的种植及观光农业，是福建省首家以香草为主题的复合式休闲农庄，被评为“省级休闲农业示范点”和省级乡村旅游四星级经营接待单位称号；白沙镇坪盘村依托新农村建设的成果,取得省级乡村旅游三星级接待单位；大洋乡笛韵森林人家利用红色文化和生态资源建成集餐饮、住宿、会务、旅游、娱乐为一体的休闲山庄；后海垦区利用福建省休闲渔业示范基地和“水乡渔村”的资源优势，形成独具特色的渔村旅游景观。同时，创新管理模式，坪盘村建立了“集体+农户+公司”的旅游发展经营模式，后黄村和莆田康辉旅行社结合形成联合体共同开发后黄村乡村旅游。城厢区常太镇环库休闲产业经济带先后吸引半浮生文创园、一亩芸生态园等15家网红打卡点入驻经营，渐渐形成了“慢生活”业态。半浮生文创园由半浮生文化传播有限公司运营，项目总投资5000万元，占地70亩，依托东圳水库的自然风光，融合文旅产业，打造集休闲茶院、特色餐饮、儿童乐园、星空露营、主题民宿、花海田园等为一体的综合业态，形成观光、休闲、度假、文化体验等于一体的特色“慢生活”文创园。目前该文化园已入驻半浮生文化传播有限公司、叶深秋、楼前小院等企业，每年带动流量约30万人次，吸纳当地群众农户就业近百人，带动销售当地农户蔬菜、枇杷、地瓜等多种农副产品。涵江区围绕旅游资源，新策划包装高速“机”情文旅项目、会展中心酒店项目、白塘湖景区项目等文旅项目，积极对接省交通集团、市国投公司、市旅投公司推进啤酒特色小镇项目、赤港服务区双开放项目、白塘湖景区项目的实施。邀请返乡乡贤考察文旅项目，组织召开座谈会共叙乡情、共商文旅经济发展思路和意见建议，为家乡发展出谋划策、 引路出力。

下一步，我局将进一步指导乡村旅游村因地制宜做好乡村旅游发展规划，突出资源优势、挖掘内涵，妥善处理好乡村旅游项目开发与自然生态及文物保护的关系，推动乡村旅游发展与当地自然环境和谐相处，与当地经济发展阶段相适应，确保乡村旅游资源的合理开发和可持续发展。通过区域联动的方式将旅游与现代农业、文创产业、健康养老、文物保护及教育、体育、科技等相关产业深度融合，不断延伸乡村旅游产业链条，提升乡村旅游发展的产业关联带动效应与辐射溢出效应，推动乡村旅游四季全时发展。围绕“一村一品、一村一韵、一村一景”的特色，完善提升乡村特色文旅产业与乡村景观建设， 打造一批特色鲜明、吸引力强的农文旅融合发展精品。一是合理规划。从生态功能入手，把景观作为一个生态系统，合理规划当地土地资源及水资源的的使用，以生态适宜和环境承载力为基础，对能源、材料进行合理再利用。二是拓展思路。在乡村景观的开发中，依据当地文化传统特色，打造个性乡土景观，开发体验式乡村旅游。将乡村的原生态生活展现给游客，既保存了当的文化生活习俗，还可带动乡村经济的发展。三是发挥主体。依靠基层政府对村民进行宣传，努力提升村民的主人翁意识，将村民从城市的漂泊中引流回乡。在今后的产业营造中，村民成为乡村建设的主体，不仅是当地传统建筑景观施工工艺的传承者，同样也是当地文化风俗的传承者。
