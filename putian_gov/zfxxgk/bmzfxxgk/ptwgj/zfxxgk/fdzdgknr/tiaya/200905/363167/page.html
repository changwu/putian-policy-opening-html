关于市政协五届三次会议第2009250号提案办理情况的答复

发布时间：2009-05-26 08:00
| | |

张开新委员：

你提出的“关于加快建设莆仙戏剧院，推进申报“世遗”进程”的提案（第2009250号）收悉，现将办理情况函复如下：

一、关于加快组建莆仙戏剧院

从您所提出的提案中可以看出，您对莆仙戏十分热爱，也十分关注，既了解到莆仙戏的现状及政府有关部门所付出的努力，又提出了加快建设福建省莆仙戏剧院的几点建议，其出发点是相当好的，许多建议也很有操作性。实际上，市政府近几年来对文化是高度重视的，尤其是对文化设施及非物质文化遗产保护方面做了大量的工作，有的已初见成效。主要有：一是市政府已于2008的8月14日决定莆仙戏申报世遗工作，出台了工作意见，举行了启动仪式，借申报之机，进一步有效保护莆仙戏。二是早在2004年元月，已隆重地举行“福建省莆仙戏剧院”的挂牌庆典，国家文化部艺术司领导、原省政协副主席王耀华、原省文化厅副厅长范碧云、原莆田市主要领导袁锦贵、詹毅等都出席了庆典仪式，并为剧院揭牌，足见市领导对组建莆仙戏剧院的重视。在近年来市委、市政府的工作报告中都明确提出了组建莆仙戏剧院的工作计划。三是2006年以来，市政府投资2亿多元的莆仙大剧院已进入室内外装修阶段。四是市政府为了培养莆仙戏后备人才，已于2007年起预算专项资金用于市艺校免费招生，已有35个13-14岁左右的小学员进入艺校学校。同时，为改善艺校办学条件，市政府已决定市艺校迁建，地点毗邻莆仙大剧院，实现资源共享。五是市政府已于2003年10月，行文省文化厅征求组建福建莆仙戏剧院的函，省文化厅也于2003年11月批复了我市的组建设想。六是市政府分管领导及文化主管部门协调了仙游鲤声剧团退休职工的养老、医疗保险的落实，解除了剧团演员们退休后的后顾之忧，稳定了剧团演员不安情绪。七是市文化部门已于2008年8月，向省文化厅请示，请求省文化厅领导来我市调研和指导组建剧院工作。八是市财政已多年拨出专款用于抢救和保护莆仙戏老艺人的表演艺术，还逐年增加了对文化的投入。

应该说，莆田市政府对莆仙戏的生存和发展是高度重视的，设施建设及剧院建设都已列入市政府的重要议程。然而，正象您在建议所提及的为什么2004年挂牌成立的福建省莆仙戏剧院至今人员编制迟迟得不到解决，其主要原因：一是近几年正逢我国多项体制改革进入关键时期，文化体制改革也不例外，因此2004年财政、编办部门都提出待中央对文化类事业单位改革统一部署后，再统筹考虑的意见建议。二是由于我市的经济体量不大，对抓紧组建莆仙戏剧院的决心还不够大，从某种程度上制约了莆仙戏的发展。总之，市政府已经意识到抓紧组建莆仙戏剧院的必要性和紧迫性。市政府将尽快协调有关部门抓紧组建工作并限时在2009年内组建完毕，硬件建设及软件建设一起抓紧、抓好。

二、关于推进申报“世遗”进程

正像您在提案中提到的市政府在莆仙戏申报世遗方面已所做许多努力。目前，市莆仙戏申报世遗领导小组已成立，张国胜市长亲自挂帅担任组长，我局李尚清局长还兼任办公室主任。今年，我局将认真按市政府提出的《关于做好莆仙戏申报世遗工作的实施意见》逐一落实，配强工作班子，加大工作力度，针对申报世遗程序的硬件和软件要求，件件抓落实，争取2009年起好步、开好局。然而，申报世遗之事非一日之功，需要全社会的广泛支持，希望您继续支持并关注申报进程，多给我们提宝贵建议。

三、关于抢救和保护莆仙戏艺术工程及其他

1、莆仙戏大剧院建设最新进展。正像您所说的，建设莆仙戏院，填补了我市大型综合剧院的空白。现在莆仙大剧院已封顶并进入室内外装修和舞台设备安装及智能化设施安装阶段。虽然工程建设资金缺口巨大，但市政府及建设单位十分努力，尤其是张丽冰副市长靠前指挥，多方协助，筹集了急需的建设资金，使工程的进展顺利。我们决心迎难而上，加倍努力，争取年底竣工投入使用。

2、切实抢救保护莆仙戏艺术。几年来，我局不仅争取省政府下拨抢救和复排老艺人表演艺术经费，也大力争取市政府下拨专项经费，一以贯之地进行抢救和保护莆仙戏艺术，至今已抢救、复排、录制优秀传统折子戏30多个，抢救了（包括朱石凤、黄宝珍、王国金、许秀莺、陈先镐、黄美云、祁玉钦在内的）一大批老艺人的表演艺术，受到了领导、社会、戏剧界及老艺人的一致称赞。

3、莆仙戏剧院人员编制亟待市政府统一协调及编办部门的核准。对于组建莆仙戏剧院的方案，我局已反复研究、论证并上报过多次，其中包括剧院性质、定员、组团方式、运行模式等作了详细的报告，至于落实人员编制问题，只能等待市政府统一协调后由编办部门定编。

4、不断争取财政投入，夯实莆仙戏申报世遗基成。虽然由于我市体量小财力还不强，但近几年对文化的投入逐年在加大。尤其是去年市政府作出莆仙戏申报世遗的决策，无疑对莆仙戏的抢救、保护、发展有利。在莆仙戏申报世遗的大前提下，我们已抢救了老艺人的表演艺术，在莆仙大剧院内辟一莆仙戏博物馆，鼓励专家学者著书，搜集整理古剧本、古曲目，实行师带徒的传授方式，抓紧后备人才培养，抓紧戏剧精品创作，巩固和提高莆仙戏戏剧创作优势，改善莆仙戏演员的工作条件和演出条件等，引导和培育莆仙戏演出市场，不断夯实莆仙戏申报世遗基础。

5、实施精品工程战略。去年，我市已于国家、省舞台精品工程接轨，结合我市实际，制定了我市精品工程，包括已分工小说家杨金远副局长主抓戏剧创作工作，与郑怀兴、周长斌、姚清水等名剧作家签约，政府提高了优秀剧本的稿酬，通过各种手段，保持我市戏剧创作的优势。

再次感谢你对莆仙戏的关注及付出的劳动。
