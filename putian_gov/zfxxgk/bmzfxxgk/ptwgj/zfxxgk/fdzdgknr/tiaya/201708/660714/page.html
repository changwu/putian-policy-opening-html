关于市政协七届一次会议第2017132号提案办理情况的答复

发布时间：2017-06-26 17:22
| | |

林新春委员：

您提出的“关于加强莆田民俗文化保护的建议”提案（第2017132号）收悉，现将办理情况函复如下：

莆田素有“海滨邹鲁”、“文献名邦”的美称，悠久的历史孕育创造了丰厚的文化遗产。其中，民俗文化是莆田文化遗产的重要组成部分之一。

一、关于“全面普查”的建议

为了有效保护和合理利用传承非物质文化遗产,促进传承活动的开展，2007年至2009年，我市通过普查，共收集非物质文化遗产线索35000多条，其中民俗方面近10000条，并按照行政区域划分整理成卷。同时，筛选出1500多个比较有价值的非物质文化遗产项目，进行挖掘整理，申报各级非物质文化遗产代表性项目名录。目前，民俗类非遗代表性项目世界级1个、国家级2个、省级5个和市级53个。

二、关于“加强宣传”的建议

在加强民俗文化保护的宣传方面，我局主要通过以下举措营造浓厚保护氛围：

一是以文化遗产日、重大节庆宣传活动为载体，开展对非物质文化遗产保护特别是民俗文化的宣传。组织举行文艺表演、传承人现场展示、专题讲座等系列活动，充分展示我市丰富的非物质文化遗产和保护成果，营造浓郁的宣传氛围。

二是通过举办民俗专题摄影展等展览、开展“我们的节日”专题演出等形式，让社会各界充分了解莆田民俗文化，并建设完成莆田市非物质文化遗产展览厅，利用各种手段充分展示我市民俗文化。

三是拍摄宣传专题片，我局和省文化厅联合拍摄《福建文化记忆·莆仙文化》专题片。专题片包括莆仙戏曲 、音乐舞蹈 、传统工艺、莆仙民俗、文物古迹等内容，全面记录丰富的莆仙传统文化。同时，完成拍摄《妈祖故里·欢乐春节》和《妈祖故里·文化莆阳》两个系列共56集，并于春节期间在各种电视和网络进行播放宣传。

四是提供珍贵资源。在编撰民俗文化丛书方面，我局依托市图书馆馆藏中相关莆田民俗的方志资源、专著资源、学术论文资源等，并提供博物馆有关莆田民俗馆藏的照片等，为有关学者、专家研究提供参考服务。

三、关于“注重传承”的建议

在加强乡村文化和民俗文化人才队伍建设工作方面，我局注意搞好普及教育工作，尊重民间自发性传承方式，全力挖掘尚存的传承地和传承人，加强对掌握非物质文化遗产技艺技能的艺人的调查登记，积极发现辅导培养民间艺人，先后培养了一大批优秀的民间文化传承人，并通过举办文化协管员培训班，—方面培训了一批基层非遗保护工作骨干，另一方面也培训培养了一批民间艺术的传承人，有力地推动了民间文化的传播和发展。同时，鼓励传承人建立传习所，评选出首批55个市级非遗项目传习所。

根据“保护为主，抢救第一，合理利用，传承发展”的工作方针，对非物质文化遗产内容丰富、较为集中的区域，实施整体性保护。在湄洲岛建立了省级妈祖文化生态保护区，并于今年启动了国家级妈祖文化生态保护实验区的申报工作。同时，在市、区两级政府的支持下在黄石镇建立了十音文化和九鲤舞文化生态保护村，在镇海街道办事处文峰天后宫成立妈祖文化研究基地，在拱辰街道办事处瑞云祖庙建立了戏神庙会习俗基地等，积极鼓励和扶持建立项目与民俗相结合，重点项目与其他民间艺术相结合，打造特色传统文化基地，彰显民俗文化价值，传承和弘扬民俗文化。
