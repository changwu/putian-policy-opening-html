关于市政协七届一次会议第2017121号提案办理情况的答复

发布时间：2017-06-26 17:09
| | |

李丽娟等委员：

您们提出的“关于抢救莆仙方言 弘扬地域文化的提案”（第2017121号）收悉，现将办理情况函复如下：

莆仙方言又称莆田话、莆仙话、兴化方言等，属于汉藏语系汉藏语系汉语闽方言方言。主要分布于莆田市、乌丘屿乌丘屿（莆田市乌丘屿乌丘屿，由台湾台湾代管）等地。与莆田相邻的福州市永泰县、福清市、泉州市泉港区都有很多居民也使用莆仙方言。莆田人外出经商很多，东南亚很多莆田侨民后裔,也讲莆仙方言。使用人口大致500万。

目前，我市已经采取多项措施，做好保护莆仙方言工作：

一、在编撰方言词典方面，市文广局依托市图书馆馆藏中相关莆田方言的方志资源、专著资源、学术论文资源等，为有关学者、专家研究提供参考服务，积极配合市政协做好莆仙方言词典的编撰工作。同时，为便于推广莆仙话的教学，市教育局邀请莆仙戏曲艺术家开展研讨，收集整理具有代表性且简单易懂易学的曲目和剧本片段，编写《莆仙戏剧本、曲谱选编》和《莆仙戏曲进校园乡土教材》作为校本教材，每年印制15000多册，免费发放给试点校学生。

二、积极普及方言工作，保护以莆仙方言为载体的非物质文化遗产有莆仙戏莆仙戏、莆仙木偶戏、独角戏、文十番莆仙木偶戏等，配合支持相关学者编辑出版方言辑录，如《兴化古邑山歌》等，并计划在今年举行莆田市首届山歌比赛。在国家级文物保护单位元妙观三清殿的东岳殿内建立莆阳书院（市图书馆三清殿分馆），开设“莆阳讲堂”，每周定期邀请莆田地方文史专家用莆田方言形式向广大市民讲授莆仙方言莆田地方文化，起到既传播莆仙文化，又保留莆田方言的作用。同时，通过组织莆仙方言参加艺术比赛，营造良好氛围。2015年，《梅娘教子》、《春草罢宴》、《上学路上》、《养与教》、《有志者事竟成》等5个莆仙戏曲节目参加全省第五届中小学校艺术展演分别获得全省一1个、二等奖2个、三等奖2个；2016年11月，我市在进修学院附属小学举行了40所试点学校唱腔比赛，近1200名学生参加演出；2017年5月，第八届全市故事大王比赛中首次设立童谣，鼓励方言从小抓起。；2017年6月我们还举行了为期3天120名教师参加的莆仙戏唱腔培训，进一步营造了“人人爱学莆仙戏、人人会唱莆仙戏”的良好氛围。

三、关于做好乡土文化传统艺术进校园工作。我市自2012年起启动“莆仙戏曲进校园”试点工作，将莆仙戏曲纳入小学三、四、五年级音乐课教学计划，确定每两周在音乐课或地方课程中调整一节作为莆仙戏曲课程，用于学习莆仙戏曲的基本唱腔和经典表演艺术。各试点校纷纷开设莆仙戏唱腔课，组建十音八乐演奏兴趣小组，聘请退休老艺人进校授课，邀请专业剧团进校巡演，受到学生们的追捧，孩子们在玩中学习、感悟传统艺术魅力，既丰富了校园文化，也助推了未成年人思想道德建设。截至目前，全市共有40所小学列入“莆仙戏曲进校园”试点学校。

四、为保留莆仙方言文读的典型性，特选取《诗经》、《左传》、蒙学、唐诗、宋词等古典文学名篇，邀请唐文桂、王琛等老专家使用莆仙方言进行吟诵并录制成光盘予以保存。并利用莆阳书院联谊会的莆仙方言名家进行更全面更广泛的方言诵读、朗读、日常用语、俗谚民谣的记录工作。同时，为传承保留莆仙方言诗词吟诵的独特韵律感，莆阳书院拟开设诗词吟诵班，采用报名办班，免费培训的方式进行诗词吟诵的教学。

下一步，我市将继续抓好相关工作：一是进一步抓好“莆仙戏曲进校园”试点学校建设，做好试点校的培育和管理工作，争取更多的学校纳入试点校范围，同时，把试点校的范围扩大到幼儿园。二是抓好试点学校的示范作用，加大宣传力度，将试点校的成果推广到全市小学和幼儿园。三是抓好艺术展演，使更多的学校莆仙戏曲进入展演节目，在全市小学、幼儿园营造学唱莆仙戏的浓厚氛围。
