关于市政协八届一次会议第2022212号提案的协办意见

发布时间：2022-10-31 17:06
| | |
 市农业农村局：

民盟莆田市委员会提出的《关于遏制乡村旅游开发失序问题的建议》（2022212号）已收悉，我单位的办理意见如下：

一、关于“优化农村国土空间布局”的建议

近年来，乡村旅游已成为一种新的产业及消费形态，正朝着集观光、休闲、康养、度假、娱乐等于一体的田园综合体方面发展。而乡村旅游项目很多涉及到土地利用规划红线，甚至涉及耕地、林地等大量农用地，有的项目在建设过程中被紧急叫停、有的项目建完后被责令拆除，一定程度造成资源的浪费，也限制了乡村旅游的快速发展。2022年8月5日，福建省自然资源厅、发改委、农业农村厅印发《保障和规范农村一二三产业融合发展用地实施细则》，明确个别以旅游发展为主的建制村，可适当放宽，但建设用地总规模应在县域内统筹。建议在新的一轮国土空间规划和村庄规划编制中，要突出规划重点，优化乡村旅游、公共服务等空间布局，建设用地指标重点投放到那些具备自然、历史人文资源富集的村，支持发展自然生态、民俗文化、科普研学、红色旅游、康养度假、运动休闲等乡村旅游。

二、关于“编制实施好区域乡村旅游的总体规划”的建议

目前，由于大多县（区）、镇对乡村旅游发展仍未整体统筹，乡村旅游缺乏精准定位和总体规划，一些具备文化旅游资源的村庄，村干部编制乡村旅游规划时，往往追求现代城市景观模式，对乡土文化重视不够，忽略“乡愁符号”的保护与传承，把乡村当城市来设计，致使乡村旅游发展偏离了方向。文化是旅游的灵魂，旅游是文化的载体，没有文化的乡村旅游是没有吸引力的，今后在指导编制乡村旅游规划时，要注重整合各类资源，如：革命红色遗址、地域非遗、莆田四大名果等，挖掘风土人情特点，将乡村旅游资源的乡土味发挥到极致，同时要求乡村旅游规划充分征求农业、自然资源、生态环境、住建、林业、文旅等部门的意见，确保乡村旅游规划的差异性、落地性和可操作性。

三、关于“加大金融运作，建立长效资金使用机制”的建议

当前，乡村旅游发展最大的困难之一是资金短缺，村集体经济弱，难以支撑乡村产业发展。民盟莆田市委员会提出开发针对中小企业和旅游经营户的额度较小的信贷产品，为中小企业提供便利的建议。《中共中央国务院关于实施乡村振兴战略的意见》明确指出:“要健全投入保障机制, 创新投融资机制, 加快形成财政优先保障、金融重点倾斜、社会积极参与的多元投入格局, 确保投入力度不断增强、总量持续增加”，乡村旅游开发要紧紧依靠国家政策支持, 设法增加各项投入, 为乡村旅游发展提供良好条件。近期，福建省农业农村厅、福建省财政厅等五部门已联合出台《福建省乡村振兴贷实施暂行办法》，是缓解中小微农业企业融资难、融资贵、融资慢问题的有效途径，为符合条件的中小微农业企业提供流动性融资服务的信贷产品，建议支持将乡村旅游产品能够列入信贷范围。

四、关于“加强人才扶持和培养”的建议

乡村振兴需要资本也需要技术，但真正需要人才，乡村旅游发展同样急需解决人才问题。近年来，我局高度重视乡村旅游人才培训工作，先后选送乡村旅游村干部30多人次参加省、国家组织的乡村旅游业务培训班，市里每年举办一期乡村旅游专题培训班，组织乡村旅游经营户、乡村旅游带头人、乡村旅游管理人、乡村旅游讲解员等各类实用人才培训，帮助乡村旅游村干部转变思想观念，提升文化素质和知识水平，提高乡村旅游管理服务能力。

五、关于“打造县域经济新活力”的建议

我市乡村旅游发展迅速，目前已创成国家A级旅游景区9个（3A级4个，2A级5个），不断加强旅游产品建设，旅游业态逐步丰富，吸引了广大游客前来观光旅游。今年，我局重点围绕红色之旅、生态之旅、文化之旅、乡村之旅等内容，积极培育创建乡村旅游品牌，其中：推荐荔城区后黄村申报第四批全国乡村旅游重点村，推荐仙游县游洋镇兴山村、秀屿区平海镇平海社区、湄洲镇莲池村、涵江区江口镇东大村、仙游县鲤南镇象林村申报2022年福建省“金牌旅游村”。充分利用妈祖文物、海丝文物、革命文物、非遗传承基地和生产性保护基地等，推出妈祖信俗、红色文化、自然生态等旅游精品线路，筹划举办枇杷、荔枝、龙眼、文旦柚采摘文化节等。同时，以乡村旅游标准化为抓手，持续完善旅游厕所、乡村文旅服务中心等旅游服务体系，推动妈祖文化、传统老字号、非遗工艺、农土特产、工艺美术开发文化创意产品进景区，不断提升产业效能和附加值，推动文旅融合发展。
