关于市政协八届一次会议第2022200号提案办理情况的答复

发布时间：2022-10-31 16:47
| | |
 致公党莆田市委员会：

你单位提出的关于我市康养产业发展存在的瓶颈问题的建议收悉，现答复如下：

疫情之下，消费者追求健康旅游的意愿显著提升，康养旅游迎来发展机遇。发展康养旅游，对于实施“健康中国”战略，推动旅游业转型升级、满足人民群众幸福生活需求等具有重要意义。当前，我市紧抓政策及市场机遇，充分利用资源优势，谋划推动康养旅游发展。全市现有国家旅游度假区1个（湄洲岛），省级全域生态旅游示范区1个（仙游县），国家A级旅游景区42家（其中5A级1家、4A级6家、3A级16家、2A级19家），国家森林公园1个（九龙谷）、全国水利风景区2个（九鲤湖、木兰陂），国家风景名胜区1个（湄洲岛），乡村旅游村107个，全国乡村旅游重点村2个，省级金牌旅游村（含4星级）13个。

一、加强规划引领，优化发展布局

认真编制《全市“十四五”文化和旅游改革发展专项规划》，提出着力打造辐射中国的健康旅游目的地的目标。借助莆田在外的民营医疗资源、优越的生态健康环境和适宜开展健康旅游、季节性康养的良好基础条件。紧扣健康产业发展需求，加大开放招商力度，建设健康旅游产业园和康养基地，打造国内最受欢迎的健康旅游目的地之一。同时不断完善康养产业生态，优化城市环境，以健康的生活撬动城市健康发展，打造良好城市形象，吸引优质人才来莆工作和生活。对接福建省文旅经济发展总体部署，加快推进莆田文旅经济高质量发展，推进滨海旅游创新突破，市文旅局正在委托第三方专业团队编制《莆田市文旅经济发展规划（2022-2035）》、《莆田市滨海旅游发展规划（2022-2035）》两个重点文旅规划。通过探索莆田文旅经济发展模式，提出如何深入推进莆田市文化和旅游深度融合（包括“文旅+康养”产业融合），打造文旅消费新热点，打响莆田文旅品牌，做大做优做强莆田文旅经济。

二、坚持项目带动，发展康养旅游

结合我市资源，立足市场发展趋势，策划推出了西苑乡刺刀峡谷户外运动基地、西苑乡前溪村“乡村振兴”综合项目、游洋镇乡村振兴示范带、草屿岛保护开发、五侯山康养旅游开发、桃花源故里、南少林禅文化温泉旅游区、一亩芸生态旅游园、大蚶山生态修复及国家地质公园建设、紫玉湖文旅项目等康养旅游项目35个。今年年初，南少林禅文化温泉旅游度假区项目在全市民营经济发展大会上签约，由香港万紫国际集团拟投资6亿元，在西天尾镇紫霄片区开发建设，是首个以南少林禅文化为主题、温泉为载体的，集生态、休闲、康养为一体的智能化综合文旅项目。目前，该项目正在编制旅游规划。

三、加快业态培育，打造康养产品

充分发挥莆田生态资源优势，大力发展运动休闲旅游、研学旅游、养生休闲旅游、房车露营、职工疗休养基地等新业态，开发多层次、多样化的休闲养生产品。城厢区、湄洲岛正在积极创建省级全域生态旅游示范区，今年6月，邀请了省文旅厅吴立官一级巡视员来莆指导创建。九龙谷被省“旅游+”质量等级评定委员会认定为首批体育旅游休闲基地示范创建单位，九鲤湖被评为省级风景名胜区、养生旅游休闲基地和“清新福建·气候福地”首批避暑清凉福地，九龙谷、萩芦镇、仙水洋等被评为福建省体育旅游休闲基地，培育一批疗休养基地。近年，市文旅局和市总工会联合培育了一批省市级职工疗休养基地，现有省级职工疗休养基地2家，市级9家。培育一批露营地产品。立足辖区内旅游资源优势，推进自驾车房车营地建设，培育旅游消费新热点。目前有忘忧谷、凤山等露营地对外运营。规范一批民宿产品。我局联合市市场监管局、公安局、住建局等12部门印发了《关于推广湄洲岛民宿管理经验做法的通知》（莆文旅〔2022〕82号）文件，引导和推动各县区建立民宿管理发展机制，规范民宿审批、经营和管理，促进我市民宿产业健康有序发展。培育绿心休闲业态。按照市委关于“莆阳开春”工作部署，市文旅局委托第三方专业团队深入开展莆田绿心、水上巴士、乡村等实地调研，着力以水上巴士为钥匙，串联绿心内的乡村，以荔城区东阳村、吴江村、北大村、涵江区洋尾村-白塘湖、双福村等五村为先行先试，通过轻资产文旅业态项目引入，开发建设康养、休闲度假、会议、婚恋研学等产品，打造引爆点。目前正在与荔城区、涵江区开展深度策划。
