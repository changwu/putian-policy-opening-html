关于市八届人大三次会议第1455号建议的答复

发布时间：2024-05-06 09:31
| | |

朱少雄代表：

您提出的《关于进一步加强莆仙方言代际传承的建议》（第1455号）收悉，现答复如下：

一、关于“应从政府层面上引导使用莆仙方言的自豪感”的建议

（一）申报项目，补助资金。我局积极挖掘以莆仙方言为载体的传统戏剧、民间文学、传统音乐、曲艺等项目。截至目前，我市拥有6项不同级别以莆仙方言为载体的非遗项目，分别是国家级非遗代表性项目莆仙戏和莆仙十音八乐、省级非遗代表性项目梆鼓咚、市级非遗代表性项目莆田方言、木偶戏、莆仙话讲古。通过正式列入非遗保护名录，进一步促进莆仙方言传承发展工作，从而提升群众使用莆仙方言的自豪感。特别在以莆仙方言演唱的莆仙戏这个非遗项目，持续加大专项资金补助，为莆仙戏的传承发展保驾护航。

（二）方言讲解，编写教材。推动市图书馆、博物馆等公共场所为群众提供双语讲解、广播服务；鼓励各景区提供双语尤其侧重莆仙方言的讲解服务。莆田市教育局将莆仙方言纳入学生课后学习活动，不但收集整理了一些易懂易学的代表性曲目和剧本片段，而且还编写校本教材《莆仙戏剧本、曲谱选编》和《莆仙戏曲进校园乡土》，免费发放给学生，让孩子们有更多的交流莆仙方言的机会。同时聘请市艺术学校和退休老艺人进校，通过莆仙戏进校园的形式，让孩子们零距离体验国遗莆仙戏的艺术魅力，激发学生说莆仙方言的兴趣。据统计，我市已有46所参与“莆仙戏进校园”活动的特色学校，旨在发挥学校莆仙方言传承的辐射作用，提升学生说莆仙方言的自豪感。

 二、关于“应以年轻人喜闻乐见的形式推广莆仙方言”的建议

（一）录制节目，广泛传播。我局结合不同阶段宣传工作重点，积极开展莆仙方言艺术精品创作并参赛，通过年轻人喜闻乐见的方式进行宣传推广。莆田市群众艺术馆出品方言赞句《华丽蝶变新莆田》、梆鼓咚《壶山兰水沐春风》、方言快板《文明创建入人心》等方言作品并广泛传播，同时在微信公众号推出《乡音乡韵》莆仙方言宣传系列，通过俚语故事和方言谜语、方言俗语、童谣、莆仙折子戏等方式传播莆仙方言；莆田市广播电视中心有《莆仙戏院》《秋生讲古》《有味有醋》《莆仙戏剧场》等多档方言节目播出。近年来，又陆续推出23集《莆阳英烈》系列，用莆仙方言讲述莆阳英烈的感人故事。在过年前夕，录制莆仙戏作品、《八仙游莆田》《搭渡》等方言小品；在秋冬防火宣传期，推出《秋生消防安全知识小课堂》系列科普视频节目、短片节目《全国土地日宣传赞句》，通过线上的形式更便捷地让年轻人参与莆仙方言的传承中来。

（二）开设讲堂，举办活动。 为了满足广大市民的不同文化需求，在国家级文物保护单位元妙三清殿建立莆阳书院开设莆阳讲堂，定期邀请莆田当地文史专家以莆仙方言授课，并联谊莆田方言名家进行方言诵读、俗谚民谣等日常记录工作。近年来，在莆田市群众艺术馆举办了三届莆田市民间歌谣比赛、“梅妃杯”莆仙戏中青年演员比赛、方言曲艺韵诵比赛等比赛以及莆仙方言吟诵、“云中射虎”方言谜语竞猜活动、“壶兰花儿开”莆田方言民间歌谣吟唱会等方言普及活动，吸引了来自学校、社区以及社会上各界人员的广泛参与，通过莆仙方言说唱、表演、吟诵、猜谜等方式，将乡音乡情融入传统文化血脉中，从而助力莆仙方言的深入传承发展。

三、关于“支持鼓励年轻人、文旅、文创、传媒公司等，利用莆仙方言的资源，用方言讲好新时代的故事”的建议

年轻人是传承方言的中坚力量，鼓励文创、传媒等社会各界人士积极参与进来，才能为构建方言文化传承体系提供坚实基础。

莆田市广播中心将莆仙方言融入新媒体宣传，在莆田广播电视台微信视频号、抖音号、莆田TV官网及客户端等多个平台，制作发布了多个莆仙方言视频作品。2023年发布《快来听秋生讲台风防范知识》科普短视频，点击量达10万人次；发布莆仙方言三句半《兴化古街赞莆田》《莆阳开春》《莆仙传统文化》点击量达4.6万，转发人数近7000次，互动超1000次。莆田市教师进修学院附属小学，于2022年先后荣获“教育部中华优秀传统文化传承基地”和“福建省师范大学《闽台地方戏曲》莆仙戏传习基地校”。该校创新性地将莆仙戏融入课间操，以学生为主体，通过跨学科，建立新型“莆仙戏鼓课间操”，真正利用莆仙方言的资源，激发学生浓厚的学习兴趣，营造了传承方言的良好氛围。该项目在莆田市“项目式学习+跨学科”融合创新优秀项目展评活动中荣获“一等奖”的优秀成绩。
