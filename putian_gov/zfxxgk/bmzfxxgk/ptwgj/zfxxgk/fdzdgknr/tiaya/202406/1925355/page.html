关于市八届人大三次会议第1174号建议的答复

发布时间：2024-06-09 14:56
| | |

翁凌晖代表：

《关于进一步加大莆田优秀传统文化保护力度的建议》（第1174号）收悉，由我单位会同市住建局办理。现将有关情况汇总答复如下：

一、工作措施及成效

（一）夯实保护工作基础。按照《莆田市人民政府办公室关于在城市更新改造中进一步加强历史文化遗产保护的通知》要求，继续推进全市50年以上建筑普查甄别、评审认定和不可移动文物、革命文物补充普查。2021年我市全面开展历史文化遗产普查认定工作，截止2024年4月，共组织开展了36场历史文化遗产普查成果专家评审会，新增公布历史建筑17批（莆田市区10批，仙游县7批）共434座；新增公布传统风貌建筑10批（莆田市区6批，仙游县4批）共1249处。全市现共有不可移动文物1496处、历史建筑648处，传统风貌建筑1249处。持续完善文物“有保护范围、有标志说明、有记录档案、有专门机构或专人负责”工作和历史建筑测绘建档及保护图则编制工作，规范文物保护碑（牌）的材质、规格、形制和内容，邀请名家撰写碑文，统一制作安装77块省、市保单位保护碑和12处国保单位及兴化府、萝苜田街区30处市级以上文保单位保护界桩166根。全市1400余处不可移动文物定线落图通过评审验收，持续推进建档立卡工作，并将不可移动文物“两线”保护控制要求纳入国土空间规划管理和“全市一张图”统一管理。

（二）延续城市历史文脉。严格遵守《莆田市历史文化名城保护规划》《莆田市兴化府（宋城）、萝苜田历史文化街区保护规划》要求，结合我市文化遗产现状，积极争取国家、省级文物专项资金补助，稳步推进文物保护工程实施。近5年共争取到上级文物专项补助资金4341万元，市级文物专项补助资金440万元，发动民间力量自筹8000多万元。重点实施兴化府、萝苜田历史文化街区内文物保护工程，完成12处国保、55处省保、123处市保单位维修、安消防和环境整治工程；实施“百村千屋”工程，2020年至今共完成约30处历史建筑保护修缮。充分利用文化遗产特质，建立文化交流基地和群众益智场所，为改善民生和经济发展服务。利用国保单位元妙观三清殿大殿作为书画、摄影作品等展览场所，开辟东岳殿、西岳殿为莆仙戏传习所和莆阳书房、讲堂，在古谯楼、崇功祠设立莆阳书房、莆仙折子戏表演剧场，探索发展夜间经济的新路径；利用仙游文庙、涵江江氏民居、洋尾李富祠等开辟为廉政教育基地，挖掘整理历代人文典故，弘扬历代先贤的先进事迹和爱国爱乡的崇高精神；利用中国传统村落后黄村林水境故居、福音医院旧址，建成荔城区党员政治生活馆和后黄村的民国往事馆，让历史文化遗产保护成果更多惠及人民群众。

（三）传承非遗传统技艺。不断创新非遗活态传承，实施传统工艺振兴行动，持续创建联合国教科文组织“手工艺与民间艺术之都”，丰富“非遗一条街”业态，公布一批市级非物质文化遗产代表性项目名录，57人入选第七批市级非遗代表性传承人，新认定市级第三批非遗传承基地（传习所）19个。央视《非遗里的中国》《山水间的家》《三餐四季》等热播，《一代匠师》央视同时段收视率全国第一，莆田元素“热辣滚烫”。积极培育扶持当地传统建筑修缮技术人才和工匠，全市已评选公布两批市级传统建筑修缮技艺传承人和传统工匠28名，推动传统工艺的传承发展、长久保护和永续利用。

二、下一步工作思路

下一步，我们将持续落实好《莆田市历史文化名城保护规划》《莆田市人民政府关于在城市更新改造中进一步加强历史文化遗产保护的实施意见》等要求，强化历史文化遗产保护主体责任，扎实做好历史文化遗产保护利用工作。一是健全文化遗产保护长效机制。坚持科学规划引领，将文化遗产保护利用工作纳入区域发展规划中统筹，切实履行好文化遗产保护属地管理主体责任，加强队伍建设、人才和资金保障，健全壮大市、县（区）文化遗产保护管理机构队伍，确保文化遗产保护工作责任落实到位。二是加强文化遗产系统性保护。结合国家第四次全国文物普查工作部署，开展不可移动文物现状调查，统筹抢救性与预防性保护，本体与周边保护，单体与群体保护，逐步实施抢险加固和修缮工程，持续改善低级别文物保护状况。三是推动文化遗产活化利用。利用是最好的保护，以地域代表性的文物建筑、历史建筑为试点，建设一批融文化创意、实景演出、非遗民俗活动于一体的公共休闲服务场所，打造“城市会客厅”。以文化内涵深厚的历史文化名村、传统村落为代表，建设一批乡村遗产酒店、民宿、客栈、茶舍、乡土文化馆，打造文旅新业态。着力提高文化遗产的社会效益和经济效益，让更多人了解莆田灿烂的历史文化，让文化遗产保护成果更多惠及广大人民群众。
