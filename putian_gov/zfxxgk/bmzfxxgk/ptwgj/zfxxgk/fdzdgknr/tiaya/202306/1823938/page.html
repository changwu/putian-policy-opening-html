关于市政协八届二次会议第2023089号提案办理情况的答复

发布时间：2023-05-25 11:19
| | |
 民革莆田市委员会：

你们提出的《关于促进文旅深度融合，推动文旅产业高质量发展的建议》（2023089号）已收悉，现将办理情况函复如下：

莆田是妈祖故里文化名城、山水诗画生态韵城、匠心智造产业新城、通江达海战略港城，当前市委市政府正在全面贯彻省委省政府加快推进文旅经济高质量发展的战略部署，落实《新形势下促进文旅经济高质量发展激励措施》，实施“千古木兰溪、百里江山图、十里风光带”工程，统筹“一溪两岸”连片发展，加快推进水上巴士、木兰陂世界灌溉遗址创建国家5A级景区，构建木兰溪生态富美走廊，打造生态带、文化带、健康带、产业带、创新带。我局将按照你们的建议，采取有效措施，推进文化和旅游深度融合发展，提升旅游的文化魅力和文化的消费活力，推动文旅产业高质量发展。

一、关于把讲好文化故事摆在突出位置的建议

（一）注重资源整合。莆田具有浓厚人文历史底蕴和自然风光，拥有金银、木雕、盐等特色产业优势，我市深入挖掘莆仙文化等特色资源，促进文化和旅游深度融合，推出更多以景点为基础、以文化为灵魂、以特色为核心的精品旅游线路。

（二）注重平台打造。为方便广大游客查找和预订莆田文旅产品，我市加强与携程等各大互联网平台的合作，上线“这就是莆田”携程星球号旗舰店。同时，秉承“互联网+文旅”的理念，充分利用好各类新媒体平台，如微信公众号、微博、抖音以及相应的短视频等，丰富文旅产品宣传渠道。

（三）注重宣传推广。扎实推进文旅产品品牌宣传营销力度，充分运用好互联网传播速度快、受众面广、参与程度高等特点，采取线上传播和线下活动相结合的方式，提高景区的曝光率和网民的关注度。一是继续加强与传统主流媒体的合作，做好全年常态化合作，扩大文旅品牌效应。二是注重精准营销，通过微信朋友圈广告进行广告投放，“妈祖圣地·美丽莆田”文旅品牌首次在铁路12306“城市之窗”平台展播，达到精准市场推广的目的。三是开展旅游宣传推介活动。先后在北京、天津、义乌等地开展文化旅游宣传推介活动，积极组织文化旅游企业参加推介会、博览会等，借助展会、推介会对外宣传推介我市文化旅游资源。四是做好莆仙戏《踏伞行》获得“文华奖”系列宣传报道工作，进一步宣传推广了国家级非遗项目莆仙戏文旅特色品牌。

二、关于多措并举吸纳文旅人才的建议

（一）用好用足中央及省、市人才政策，围绕我市文旅产业发展，引进一批文旅领域高层次人才和紧缺急需人才。研究制定关于加强高素质文化和旅游人才队伍建设的意见，统筹推进各类文化和旅游人才队伍建设。

（二）制定文旅人才培训方案，举办2023年全市乡村旅游、导游人员等文旅职业技能培训班，组织市、县（区）两级旅游业分管负责人、文化旅游部门负责人、旅游重点乡镇负责人、文化旅游企业负责人以及智慧旅游、市场营销、旅游策划、旅游规划创新人才等参加培训，提升文旅人才职业技能水平。

（三）印发《2023年“技能莆田”万人职业技能培训“十大计划”实施方案》，围绕文旅产业发展技能人才需求，实施产业技能人才培训计划、“乡村工匠”人才培训计划等，拟选送300名文旅经济人才、100名乡村旅游农村文化人才参加培训，保护和传承乡土文化。

三、关于实现游客需求与市场供给的匹配的建议

（一）丰富文旅产品供给。充分发挥妈祖文化、祈梦文化、禅武文化、非遗文化等特色文化优势，融入妈祖祖庙等祈福圣地、妈祖文化影视园、九真观祈梦文化核心区、非遗一条街、春晖艺术馆等特色文化旅游场景，开展“妈祖故里·欢乐春节”、九鲤湖“山水交响、九鲤圆梦”山水音乐节、“游菜溪·中状元·小菜一碟”状元主题文化旅游节、南少林“功夫国潮”禅武文化节、兴化府历史文化街区“非遗一条街”展示、“妈祖回娘家”非遗文化节、第七届世界妈祖文化论坛——妈祖文化与两岸文旅发展分论坛等系列特色文旅活动，丰富文旅产品体验，有效提升市民游客体验感和获得感。

（二）数字赋能文旅融合。以深化现代科技在文化和旅游领域的应用为主线，上线运行“这就是莆田”数字文旅平台，植入景区酒店、文物非遗、文史典故、工艺美术等基础数据，推出莆田好资讯、好视频、好去处、好味道、好线路等版块，通过科技促进文化和旅游生产方式、体验方式、服务方式、管理模式创新，打造文旅融合品牌。加快推进数字文旅系统融合与工程建设，上线“这就是莆田”携程星球号旗舰店，建立莆田市文旅基础资源数据库，对景区、酒店、乡村旅游、民宿、旅行社、文博场馆等数据的采集、处理、管理、更新，推动形成内部数据资产，提升文化和旅游供给质量。

四、关于开发独具特色的文创产品的建议

（一）持续推进文化文物单位文化创意产品开发工作。发行“莆田文旅一卡通”电子年卡，优惠范围涵盖湄洲岛、九鲤湖、九龙谷等全市58个优质联盟景区及商家，市民游客购卡后即可畅游全市，享受多个景区全年每天一次首道门票免费、多种应用场景联盟商家专属折扣优惠，打造集“吃住行游购娱”于一体的文旅产业服务平台经济。依托妈祖文化、莆仙戏、木兰陂、仙作家具等文化IP，以“莆阳开春”主题活动为契机，成功推出“谯见”大碗茶、“谯见·莆田”非遗美食礼盒、“无可枇敌”枇杷花叶茶、古谯楼主题慕斯蛋糕、棒棒糖等文创美食。围绕文化和自然遗产日源自文化遗产日，推出莆田市图书馆非遗文创产品——莆仙戏剧脸谱书签。在绶溪公园新凯特文创体验馆展出美陈5帧，生活创品180件，艺术创品40件等，展现老莆阳的风华绝代、古兴化的迷人之彩；在湄洲岛“妈祖平安礼”旗舰店销售“妈祖平安礼”包括赏心悦、全家服、平安瓷、海神表、味极品、海贝贝、微卡通、捏海人、茗香醇等9大类独具妈祖文化特色的平安礼。

（二）搭建有效展示推介平台。以专业化、品牌化、国际化为导向，运用大数据、人工智能等现代技术手段方面，做大做强中国文化和旅游产品交易博览会，组织开展全国文化和旅游创意产品推进活动，全方位宣传定制化的文旅产品，提高莆田文旅产品的吸引力和人气度。开展莆田特色文旅IP、创意设计产品征集活动，助推我市文化旅游产业高质量发展；发挥全国图书馆文化创意产品开发联盟成员馆的优势，结合馆藏资源特色开发“莆阳日历”等文创系列产品；举办莆田市首届文物博物馆文化创意产品创作大赛，通过文化创意开发衍生产品，更好地弘扬我市传统文化内涵；举办妈祖文创设计大赛，两岸青年交流创意想法，把中国传统道德典范如立德、行善、大爱等精神发扬光大；湄洲岛妈祖文创产品续6年亮相中国（莆田）海峡工艺品博览会。在莆田市博物馆开设“莆仙印象”莆仙文化原创伴手礼实体店，向世界传播莆仙之美。
