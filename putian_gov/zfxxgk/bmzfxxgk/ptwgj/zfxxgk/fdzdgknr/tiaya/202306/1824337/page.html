关于市政协八届二次会议第2023037号提案办理情况的答复

发布时间：2023-05-30 16:12
| | |
 郑洁红委员：

你提出的《关于促进市民下乡养老 积极应对莆田市人口老龄化的建议》（2023037号）已收悉，现将办理情况函复如下：

2022年7月，省委省政府印发《福建省贯彻<中共中央、国务院关于加强新时代老龄工作的意见>实施方案》，要求落实积极应对人口老龄化国家战略，将积极老龄观、健康老龄观理念融入经济社会发展全过程，在更大范围、更高水平上实现老有所养、老有所医、老有所为、老有所学、老有所乐，不断增强老年人获得感、幸福感和安全感。我局围绕老年人出行、办事、旅游等服务，大力推进市图书馆、博物馆、群众艺术馆、莆仙大剧院等公共文化场馆和电影院、星级酒店、A级景区等完善无障碍通道设施，提供轮椅、老年人使用的拐杖等便民设备；旅游厕所在条件允许的前提下尽量增设第三卫生间，为游客提供人性化服务。健全老年人优待政策，鼓励A级旅游景区对65以上老年人实施门票半价政策。下步，我局将按照你的建议，有效发挥职能部门作用，进一步推进公共设施无障碍建设，丰富老年人文化生活，推进公共文化服务均等化、标准化。

一、关于“发展乡村医养结合模式“的建议

积极推进老龄产业融合发展，依据国务院印发《“十四五”中医药发展规划》，将文旅康养产业列入《莆田市“十四五”文化和旅游改革发展专项规划》，依托我市生态、温泉、中医药等资源优势，发展中医药养生、温泉度假、文化体验等康养旅游，培育一批乡村康养、森林康养、温泉康养、海洋康养等绿色康养旅游新业态，丰富老人旅游产品有效供给。重点围绕海洋、城市绿心、仙游北部山区山地峡谷等地形地貌及资源，开展山地运动、户外拓展、户外体育运动、养生运动、徒步旅行、攀岩探险等康体活动，积极策划平海湾嵌头沙滩旅游度假区、白塘湖-洋尾村旅游度假区、仙水洋康养休闲旅游度假区项目、刺刀峡谷仙山旅游开发项目、济川村旅游开发项目、凤凰福道文旅业态运营项目、华信度假山庄等文旅康养项目，纳入招商手册，组织赴北京、天津等国内重要城市开展“这就是莆田”文旅招商推介，聚焦央企、上市公司、文旅头部企业等，争取引进有实力的企业助力莆田康养项目发展，增强旅游发展新动能。依托妈祖文化、戏曲文化、禅武文化、民俗文化，推出集自然、人文、生态、养身、疗养资源于一体的一日游、两日游等红色旅游、乡村旅游、康养旅游、周末“趣”游精品旅游线路，推进全域康养休闲生态产业的全面发展。深化现代科技在文化和旅游领域的应用为主线，上线运行“这就是莆田”数字文旅平台，植入景区酒店、文物非遗、文史典故、工艺美术等基础数据，推出莆田好资讯、好视频、好去处、好味道、好线路等版块，通过科技促进文化和旅游生产方式、体验方式、服务方式、管理模式创新，打造文旅融合品牌。加快推进数字文旅系统融合与工程建设，上线“这就是莆田”携程星球号旗舰店，建立莆田市文旅基础资源数据库，对景区、酒店、乡村旅游、民宿、旅行社、文博场馆等数据的采集、处理、管理、更新，推动形成内部数据资产，提升文化和旅游供给质量。

二、关于多举措保障村民的建议

近年来，我市乡村旅游发展迅速，重视将现代农业与文旅相结合，深入挖掘乡村文旅资源，指导支持旅游村非遗传统文化的活化利用和创新发展，让乡村文化焕发生机，持续推进乡村旅游提质升级，积极培育乡村旅游品牌，已成功创建全国乡村旅游重点村3个，福建省全域生态旅游小镇5个，福建省金牌旅游村11个，组织评定莆田市第一批全域生态旅游小镇和金牌旅游村。有力地推动我市乡村旅游朝着规模化、常态化、产业化、市场化方向发展。但也存在乡村旅游开发总体不够平衡，乡村旅游基础设施不完善、旅游产品和旅游业态创意水平不高、乡村旅游人才缺乏、乡村旅游景点缺少专业团队运营等问题。我们将根据你的建议，着力培育农民经营主体，增加和提升乡村旅游供给，引导培育特色民宿、乡村自驾游和房车露营地、乡村特色街区、亲子研学基地、主题果园、非遗传承课堂等新业态，以满足游客日益旺盛的个性化、多样化乡村旅游需求。研究探索发挥农村集体股份经济合作社的作用，鼓励旅游村集体利用资源优势和社会企业合作，成立农村集体经济控股公司，对集体资产进行清产核资，稳步推进农村集体资产入股，探索多样化发展途径，推行资源发包、资产参股等多种模式，探索“资源变资产、资金变股金、农民变股东”，让大量集体资产“活起来”，为激发乡村文旅产业活力提供有力支撑。同时，有效盘活农村空余房屋资源，大力发展民宿经济，按照“政策鼓励、登记备案、加强监管、行业自律”的原则，由湄洲岛先行先试，破局民宿发展瓶颈。我局及时联合市市场监管局、公安局、住建局等12部门制定出台《关于推广湄洲岛民宿管理经验做法的通知》，推动各县区（管委会）建立民宿管理发展机制，规范民宿审批、经营和管理，填补民宿监管空白，目前秀屿区率先出台《秀屿区旅游民宿管理暂行办法》（莆秀政办规〔2022〕4号），成立民宿行业协会，参与旅游民宿等级的评定与复核，已有36家民宿入会。同时支持县区结合各自实际成立民宿协会，协调处理政府职能外的相关事宜，加强旅游质量监督，倡导民宿行业合法经营、诚信服务，建立健全诚信管理体系，防止不平等竞争、恶性竞争等行为，保障民宿经营者和游客的合法权益，促进我市民宿产业健康有序发展。
