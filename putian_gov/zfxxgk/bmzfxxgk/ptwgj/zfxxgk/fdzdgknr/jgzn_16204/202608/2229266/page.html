关于报送2025年度全市 艺术、图书资料、文物博物、群众文化 专业中初级职务任职资格评审材料的通知

发布时间：2026-08-06 16:49
| | |
 市直有关单位，各县区（管委会）职改办，各县区文旅局、湄洲文化旅游和体育局：

为做好2025年度全市艺术、图书资料、文物博物、群众文化专业中初级职务任职资格的评审工作，根据闽人社发〔2021〕1号文件精神，现就报送全市艺术、图书资料、文物博物、群众文化专业中初级职务任职资格评审材料的有关事项通知如下：

一、申报对象和范围

凡在我市企事业单位直接从事艺术、图书资料、文物博物、群众文化专业工作，符合《关于福建省艺术系列专业技术职务任职资格评审工作的实施意见》（闽文职改〔2012〕22号）、《关于福建省艺术专业人员职称评价工作的实施意见》（闽文旅规文〔2023〕4号）《福建省图书资料系列专业技术职务任职资格评审工作的实施意见》(闽文旅职改〔2019〕15号）、《关于福建省文物博物专业技术职务任职资格评审工作的实施意见》（闽文旅职改〔2020〕13号）、《关于福建省群众文化系列专业技术职务任职资格评审工作的实施意见》(闽文旅规文〔2022〕3号）等有关条件，且尚未达到法定退休年龄的在职在岗人员，均可申报2025年度艺术、图书资料、文物博物、群众文化系列中初级任职资格评审。申报艺术、图书资料、文物博物、群众文化专业中初级职务的专业技术人员，实践能力和业绩成果计算年限为取得本系列初级职称后至2025年12月31日，任职年限计算为担任初级职务后至2025年12月31日。

二、材料报送时间

报送材料截止时间为2026年9月15日，逾期不予受理。请各有关单位做好安排，于上班时段集中报送至莆田市文化和旅游局人教科（市政府2号楼322室），逾期不予受理。申报材料具体要求详见附件1，电子版内容打包命名为“姓名+单位名称+申报资格名称”（例：张三莆田市图书馆中级馆员），并由委托单位统一发至邮箱：pt2696660@163.com。

三、答辩

申报人员需答辩，答辩范围为论文代表作内容、从事本专业工作的基本情况、本专业的基础理论和专业知识。答辩时间另行通知。答辩考核时，答辩对象应准时到场，无故不参加答辩者视为自动放弃申报，其申报材料不提交评委会评审。

联系人：小黄，联系电话：0594-2656677
