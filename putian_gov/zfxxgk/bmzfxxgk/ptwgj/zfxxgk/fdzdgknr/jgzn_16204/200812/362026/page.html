关于要求选调林杰同志加强莆仙戏申报世遗工作力量的请示

发布时间：2008-12-15 08:00
| | |

市委编办：

近年来，随着市委、市政府不断加大文化工作力度，促进了我市文化的大发展大繁荣。莆仙大剧院的建设、市博物馆新馆的确定、莆仙戏申报世遗工作的启动等重大文化项目的落实和展开，极大地鼓舞了全体文化人的工作士气。在推动文化各项工作开展的同时，我们深感人才培养和使用的重要性。11月14日，市政府已经出台了《关于做好莆仙戏申报世遗工作的实施意见》，明确了莆仙戏申报世遗的工作目标，即2008年启动，2009—2010年申报文本上报省、国家，2012年前争取列入世遗预备名单；2015年前争取获得通过。市政府的《意见》出台后，我局根据莆田的实际进行具体细化研究，并着手启动前的各项准备工作。

由于申报世遗是一项完整系统的事业，是极其严肃认真的国际共识和义务，我们既要对莆仙戏成功申报世遗充满信心，又要预见申报工作的艰巨性和复杂性，我们决心扎扎实实地做好申报的每一项工作。

按照市政府的《意见》中对我局提出的组织强有力工作班子的要求，为了加强申报工作力量和工作指导与协调，请求成立莆田市非物质文化遗产申报中心，并选调林杰同志到申遗办做专职工作，请求给予该办特批一名科级领导职数。

以上请示，恳请批准。

林杰同志简况

 

林杰同志，男，1958年8月出生，中共党员，1978年考入福建农学院养蜂专业，1981年1月大学毕业后留校工作，历任福建农学院养蜂系团总支部书记、院团委常委、宣传部长、院党委宣传部秘书等职。1986年7月因家庭原因调回莆田工作，先后在湄洲报社担任记者和栏目编辑，1992年评上中级职称（编辑），2007年又获政工师中级职称。1989年11月调入市电影公司，历任办公室主任、支部副书记、经理等职。

2003年5月，为充实局办公室力量，特选调林杰同志到局办公室协助工作。借调工作期间，该同志思想进步、积极肯干，很快进入角色，显示出较强的组织协调能力和文字功底。几年间，该同志参与了包括起草市委、市政府关于进一步加强文化工作决定、“十一五文化专项规划”、改革开放30年文化篇的执笔人、市政府关于做好莆仙戏申报世遗工作的实施意见的拟稿人以及莆仙大剧院建设在内的所有的计划、报告、总结等各种文件的撰写，出色地完成了上级部门及局领导交给的各项任务。由于该同志出色的工作，2004年10月被市直机关工委和市直机关文明委评为第九届（2002—2003年度）精神文明建设先进个人。先后分获福建省文化厅、市委办、市委宣传部授予的信息工作先进个人称号。2003年—2007年连续5年年度考核均为优秀。

2004年7月，由于市电影公司班子更迭，为全面培养人才，经群众推荐，局党组考核任命该同志为公司经理。任职期间，该同志具有强烈的事业心和责任感，发展意识强烈，面对日益萎缩的电影市场，他带领公司一班人奋力拼搏，狠抓发展，具有较强的经营管理能力，并取得了较好的成绩。

2005年10月，经市委决定，原文化与出版和广电两大部门合并，成立市文化广电新闻出版局，新成立后的局职能加大，文秘工作量骤然增多，我局不但要应对省级一厅二局的业务和文字交往，还要完成市本级相关部门的文字往来，办公室和文秘工作力量亟需大力加强。为了解决这一矛盾，2005年12月，局党组研究把林杰同志重新抽调上来，以解燃眉之急。实践证明，该同志回到他熟悉的岗位上，如鱼得水，除做好日常的文秘工作外，还参与我市抢救和保护莆仙戏艺术工程的全过程，并起到积极的作用。

综观该同志的工作履历，既有共青团工作的学习锻炼，又有报社记者、编辑的文字功底，既有基层一把手实践的经验，又有机关工作的经历，加上该同志为人正派，刻苦肯干，能写、能编，熟悉文化工作特点，熟悉莆仙戏的各个方面，又有较强的组织能力。对我市文化广电战线上的人和事都比较了解，是一位理想的文秘人才。符合市委提出的用发展考核干部的要求，特向市领导力荐，请求特批该同志调入申报办。
