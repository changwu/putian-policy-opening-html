莆田市对口支援新疆玛纳斯县2014年发展资金和项目跟踪审计结果

发布时间：2014-12-25 00:00 点击数：
| | |

一、莆田市对口支援新疆项目年度跟踪审计开展情况

根据审计署《关于印发开展支持新疆发展资金和项目审计工作方案的通知》（审投发〔2010〕167号）和《关于做好2014年度对口支援新疆资金和项目审计的通知》要求，2014年9月至10月，莆田市审计局派出审计组5人赴新疆，对福建省援疆工作前方指挥部玛纳斯县莆田分指挥部（以下简称“市援疆工作前方指挥部”）负责的2014年莆田市支援新疆发展资金和项目进行了跟踪审计，主要审查了对口援建项目资金管理及使用情况、建设项目管理情况等。

二、莆田市2014年援疆项目建设进展情况

（一）援疆项目建设进展情况。根据莆田市援疆年度计划，2014年，我市援建项目6个，计划投资9468万元，均为“交支票工程”，安排援建资金1030.15万元。截至2014年9月底，已完成投资7153万元。分项目进度为：

1、游牧民定居工程。2014年，计划投资1080 万元。该项目于今年9月6日开工，目前，清水河乡61户定居平房主体工程已完工，正在进行室内外装修和室外硬化等工程施工；塔西河乡黄台子村29户定居楼房主体已完工，正在进行内墙保温工程施工。截至2014年9月底，已完成投资900万元。

2、玛纳斯县职业技术培训学校建设项目。该项目由莆田、三明两市共同援建，计划总投资6800万元，拟建1幢综合楼12000㎡，1幢教学楼5100㎡，2幢学生宿舍楼12000㎡，1幢学生餐厅2200㎡等辅助设施。该项目于2012年4月10日复工建设，于2013年8月底按计划完工并投入使用，可容纳4500多人学习培训，将有效缓解玛纳斯县混纺、碧玉等重点产业技能人才紧缺的现状。2014年，计划投资200万元，计划建设职业技术培训学校道路硬化及绿化等工程。目前，该项目已完工，进入验收阶段。

3、富民安居工程。2014年计划完成投资7848万元，其中援建资金0.15万元（完成兰州湾乡1户安居富民房屋补助）、中央投资686.7万元、自治区配套523.2万元、其它资金6637.95万元。目前，正在进行主体工程施工，完成投资6000万元。

4、人才援疆工程。2014年计划投入40万元，现已完成投资20万元。组织县直部门、乡镇主要领导及有培养潜力的科技干部35人于10月18日至10月31日在复旦大学培训。计划于11月中旬组织中、高级人才约30人到上海同济大学学习深造。其它人才援疆工作也正在有序推进。

5、玛纳斯县产业示范培训基地建设项目。本项目系我市与三明市共同援建。2014年计划投资250万元，计划完成产业示范培训基地综合培训楼主体工程建设，目前，该项目正在编制项目可研，同时正在进行施工图设计及前期相关支持性文件办理工作，计划2014年10月底开工建设。

6、玛纳斯县职业技术人员就业培训工程。2014年计划总投资50万元，开展碧玉雕刻技艺人才、乡镇旅游人才、红十字会应急救护人才等的培训工作。目前，已完成投资33万元,涉及的主要工作为：组织了碧玉雕刻技艺培训一场；培训碧玉雕刻、鉴赏、营销人员280人。红十字会已组织培训47场，参训应急救护人员达14450人次。其它相关工作正在按照计划顺利实施。

（二）2014年援建资金筹集、分配、管理和使用情况。我市援建资金由市财政局归集后拨付玛纳斯前方指挥部，我市援建项目为“交支票工程”项目，工程款统一由市援疆工作前方指挥部按项目进度拨付给玛纳斯县有关部门或相关建设单位。截至2014年9月底，市援疆工作前方指挥部已收到援疆资金600万元，支出573万元,其中: 职业技术人员培训经费拨付33万元，塔西河乡定居兴牧工程拨付140万元，清水河乡团庄村牧民定居项目拨付300万元,职业技术学校援建资金100万元。

三、审计评价

跟踪审计结果表明：莆田市委、市政府高度重视对口援疆工作，一把手亲自抓，机构保障有力，措施落实到位，有力有序推进，援疆项目工作取得显著成效。

一是领导到位。莆田市委、市政府对新一轮援疆工作高度重视，强化领导，于2010年7月成立了由市长担任莆田市对口支援新疆工作领导小组组长（莆委〔2010〕37号）的领导机构，同时成立市对口支援新疆工作领导小组办公室，挂靠在市经贸委。2013年8月我市选派城厢区副区长林锋同志担任福建省援疆工作前方指挥部莆田分指挥部指挥长。市援疆工作前方指挥部内设综合组、项目资金组、产业对接组、干部人才组、纪检监察组、宣传组等 6个专项工作组，具体负责我市援疆工作的相关事项。

二是人员到位。2014年我市先后选派14名干部和专业技术人才赴玛纳斯县开展对口援疆工作，其中：指挥长援疆期限为三年，3名干部援疆期限为三年，8名专业技术干部援疆期限为一年半，其余人员援疆时间为4个月或6个月。截至审计日，我市在玛纳斯县工作的援疆干部和专业技术人才共14人，其中组织部门选派的援疆行政干部3人，教师5人，医生3人，短期技术人才医生2人、农技人员1人。

三是措施到位。我市出台了《莆田市对口援疆专项资金管理办法》，规范了资金的运行，切实保障援疆资金专款专用，援建各项工作全面、有序开展。市直相关部门能认真贯彻国务院有关援疆政策，选派出优秀的、年轻的援疆干部，积极筹集援建资金，确保我市援疆项目如期圆满完成。市援疆工作前方指挥部在市委、市政府和省前指的正确领导下，认真落实总体规划要求，积极开展援建项目工作，严格执行《福建省对口支援昌吉州建设项目工程施工管理办法》、《福建省对口援疆专项资金管理办法》等规章制度，并相应制定了一系列的规章制度，如：《福建省援疆工作前方指挥部玛纳斯县莆田指挥部援疆建设项目财务管理制度》、《关于印发莆田市对口支援玛纳斯县建设项目工程施工管理办法（试行）的通知》等，严格援疆资金管理，规范资金拨付程序和手续，注意对援建工程进度、质量的管理，确保了资金的运行规范、使用安全和专款专用。同时，市援疆工作前方指挥部坚持把援建项目作为新一轮援疆的重点任务和改善民生的重要依托，2014年从自身有限的工作经费中挤出33万元用于支持当地部分村的自来水、路灯等民生项目支出，将使玛纳斯县受助群众得到实惠，切身感受到莆田与玛纳斯两地人民的深情厚谊。

经跟踪审计抽查，我市援建项目的资金使用和建设管理方面未发现重大违法违规问题，但部分援建项目在工程建设管理等方面也存在一些不规范的问题。市援疆工作前方指挥部能积极采纳跟踪审计提出的审计建议，努力做好跟进督查工作，确保了跟踪审计发现的问题整改到位。

四、跟踪审计发现的主要问题

（一）个别项目进度滞后。县产业示范培训基地建设项目年度计划完成产业示范培训基地综合培训楼主体工程建设。目前，该项目规划方案尚未确定，还无法开展下一步的建筑方案和施工图设计工作，项目进度明显滞后，与原计划进度有较大的差距。

（二）部分项目当地配套未到位。经现场勘验部分游牧民定居工程发现，大部分定居工程项目均接近完工。但清水河乡游牧民定居点及旱卡子滩乡游牧民定居点由于未靠近水资源区，即使主体工程完工也无法立即投入使用，亟需当地政府配套投入数百万元建设引水工程，才能实现游牧民定居的目标。

（三）部分援建项目建设管理不规范。我市对口支援玛纳斯县的建设项目均为“交支票工程”，即援建项目的建设管理由玛纳斯县有关部门或相关建设单位负责，我市援疆工作前方指挥部仅负责按照玛纳斯县各有关部门、单位核定的工程进度拨付援建资金。审计抽查发现，存在有的项目先开工后报建、先施工后招标；有的项目高定施工单位资质要求；有的工程结算价严重超过合同价等问题。

针对以上存在的问题，市审计局已要求市援疆工作前方指挥部责成相关单位按照规定予以整改。

五、审计建议

1、要督促建设资金及时到位。鉴于玛纳斯10月份以后当地的气候条件不利于工程建设的现实，建议市援疆工作前方指挥部应当积极沟通协调，争取先于序时拨付援疆资金及配套资金，以保证工程进度。

2、要加强督促检查。建议市援疆工作前方指挥部加强与项目单位的沟通与协调，督促项目单位依法依规进行工程招投标，严控工程造价与质量，切实发挥援疆财政性资金的整体效益。

3、要加强援建项目评估。建议市援疆工作前方指挥部评估原有援疆项目的效益情况，加强对项目的跟踪与后续支持工作，发挥援疆资金“四两拨千斤”的作用。


2014年12月25日
