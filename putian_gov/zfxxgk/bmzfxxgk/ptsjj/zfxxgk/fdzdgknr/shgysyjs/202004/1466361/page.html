莆田市审计局关于全市应对新冠肺炎疫情防控资金和捐赠款物专项审计公告

发布时间：2020-05-06 16:27 点击数：
| | |

  根据《中华人民共和国审计法》规定和国务院部署，按照《审计署办公厅关于印发应对新冠肺炎疫情防控资金和捐赠款物专项审计工作方案的通知》要求，2020年2月25日至2020年4月3日，莆田市审计局组织全市审计机关共派出6个审计组、16名审计人员，对全市疫情防控资金和捐赠款物开展了专项审计，重点审计了2.4亿元财政资金、0.53亿元捐赠资金，延伸审计了7家红十字会、慈善组织，25个卫健局、工信局等政府机构和单位，1家企业，对重要事项进行了必要的延伸和追溯。现将审计情况公告如下：

  一、基本情况

  （一）财政资金方面

  截至2020年3月1日，2020年以来，莆田市、县（区）管委会财政共收到中央疫情防控资金3238万元、省级疫情防控资金23532万元、市级疫情防控资金7938万元、县（区）级疫情防控资金8244万元，共计42952万元；并全部拨付市卫健委等相关部门，截至3月31日实际使用33641万元，9311万元尚未支出。在实际使用33641万元中，包括：患者救治费用补助支出218万元，疫情防控人员补助支出2050万元，设备和防控物资支出10231万元，医院新建或改扩建支出2180万元，其他支出18962万元。

  （二）捐赠款物方面

  截至2020年3月31日，福建省莆田市各级红十字会、慈善会和其他公开募集的慈善组织以及指定接受社会捐赠的政府部门和单位共收到社会捐赠资金5778.96万元，支出4650.29万元，结余1128.67万元元。 接受捐赠的医用防护服、口罩等各类物资1138.1万件（其中已折价3381.77万元），上述物资已全部安排使用。

  二、审计评价意见

  审计结果表明，市委、市政府能够认真落实党中央国务院和省委省政府决策部署，及时成立莆田市应对新冠肺炎疫情工作指挥部，包括成立医疗物资保障组、市场供应及资金保障组等14个工作组，各工作组履职担当，各负其责，统筹推进、抓实抓好各阶段疫情防控工作。加大疫情防控资金和物资保障力度，着力打赢疫情防控阻击战，确保社会大局和谐稳定。全市财政等部门及时下拨疫情防控资金，为规范财政补助资金使用和管理，提高资金使用效益，市财政局等部门分别出台了《关于落实新型冠状病毒感染肺炎疫情防控经费有关经费保障政策的通知》和《关于印发莆田市新型冠状病毒感染的肺炎疫情防治工作专项补助资金管理办法的通知》、荔城区、城厢区财政局等部门也出台了相关管理办法。全市红十字会、慈善总会等捐赠组织积极发动捐款捐物，捐赠款物能够及时分配使用。但审计中仍发现部分财政专项资金未及时下达、项目单位支出进度缓慢、部分捐赠资金尚未全部使用到位、捐赠物资使用管理不够规范等问题。

  三、审计发现的主要问题

  （一）财政资金存在的问题

  1.部分疫情防控财政专项资金未及时下达。截至2020年3月31日，秀屿区疫情防控财政专项资金指标已下达但资金未下拨，涉及2笔计292.05万元，主要因区财政财力有限尚未安排。

  2.个别专项资金支出进度缓慢，未能充分发挥绩效。截至2020年3月31日，荔城区卫健局累计支出各类疫情防控财政补助资金83.22万元，仅占补助收入的13.9%，支出力度不够。

  3.用财政资金购买疫情防控物资未及时结算拨付。仙游县工信局委托县供销集团公司购买疫情防控物资37.51万件涉及资金137.66万元，县工信局已收到该批疫情防控物资，但款项未及时拨付给县供销集团公司。

  4.部分县区应急物资出入库台账不完整。涵江区卫健局疫情防控应急物资出入库台账不完整，只登记从市卫健委、区工信局等领取的应急物资明细情况，而对于各卫生机构领取的疫情防控应急物资只有对方领取手续，没有登记出库台账。

  （二）捐赠款物存在的问题

  1.部分捐赠资金尚未全部使用到位。截至2020年3月31日，（1）市本级及县（区）红十字会均存在捐赠资金未全部使用到位，主要系非定向捐赠、正在安排使用计划将陆续拨付到位。一是涵江区红十字会尚有结余230.3万元，占收入96.4%，截至4月10日，已使用24.5万元购买口罩援助宁夏西吉县。二是城厢区红十字会尚有结余154.41万元，占收入58.4%；三是荔城区红十字会尚有结余207.2万元，占收入52.2%；四是市红十字会尚有结余428万元，占收入16.6%。（2）部分项目单位接受捐赠资金未使用到位。如秀屿区有平海、笏石、东庄、东峤等4个镇共收到捐赠资金计260万元，均未支出。秀屿区卫健局、工信局尚有捐赠资金余额分别为251.13万元（占收入50.5%）、157.07万元（占收入50.8%）未使用。

  2.捐赠物资使用管理不够规范。一是市红十字会捐赠证书未专门设置台账登记、已盖章的捐赠证书未作备案登记；市工信局、市红十字会对捐赠物资的收支台账登记不规范、不够清晰。二是捐赠物资分配交接手续不齐全。如：涵江区红十字会分配给白塘镇人民政府、涵江医院的口罩、防护服等，没有接收人签字及落款时间；秀屿区个别捐赠物资领取过程，相关人员未开具介绍信、也未在领取登记表上签字存底备查等；荔城区卫健局在物资申领书中仅有所需物资及数量，但无领取人及联系方式，也无相关领导签批等。

  3.捐赠款物未及时全部公开。涵江区红十字会收到捐赠款物在涵江时讯上公开部分接受捐赠情况。

  4.用捐赠资金购买物资未取得发票。仙游县供销集团公司用捐赠资金170.37万元向福州源泉生物科技有限公司等单位和个人采购疫情防控物资50.68万件，尚未取得购进发票。

  5.部分捐赠物资质量不合格。如荔城区工信局、红十字会等接受捐赠和分配的医用口罩有4800个（折价1.43万元）存在污染、假货、过期等问题。

  四、审计发现问题的整改情况

  （一）财政资金方面

  1.促进市财政局、市卫健委按照上级文件规定要求做好一线援鄂人员薪酬（3倍）的补助发放工作。截至3月31日，我市18名援鄂医护人员中已有14人发放到位，还有４人近期也将发放。

  2.促进防控物资规范管理。对于应急物资出入库台账不完整和个别物资领取手续不够齐全问题，审计指出后，涵江区卫健局已补登了出库台账，并结出物资库存情况；秀屿区疫情防控医疗物资保障组发放手续已补全。

  （二）捐赠款物方面

  1.促进捐赠资金高效使用。针对审计指出的部分捐赠资金尚未全部使用到位问题。一是市红十字会对结余资金428万元，已作安排使用计划，拟用于补助新冠肺炎防控隔离点有关费用及无症状新冠肺炎防治费用；二是荔城区红十字会对结余资金207.2万元，拟安排补助用于教育系统学生购买口罩；三是涵江区红十字会对结余资金230.3万元，已使用24.5万元购买口罩援助宁夏西吉县，下一步计划用于“拥抱湖北、温情关怀”，第一批投入40万元。

  2.促进捐赠物资规范管理。针对审计指出捐赠物资使用管理不够规范、部分捐赠款物未及时全部公开等问题。一是市红十字会对捐赠证书已专门设置台账登记，对已盖章的捐赠证书作备案登记；市工信局、市红十字会对捐赠物资的收支台账已规范登记，做到日清月结；涵江区红十字会、秀屿区及荔城区卫健局对捐赠物资分配交接手续等不齐全问题。审计提出后，上述有关单位已补办了相关手续，完善台账登记等。二是涵江区红十字会收到捐赠款物只在涵江时讯上公开部分接受损赠情况。审计提出后，该会已将全部接受损赠款物情况在涵江时讯上公开。
