莆田市审计局关于印发2016年度稳增长促改革调结构惠民生防风险政策措施落实情况跟踪审计工作方案的通知

发布时间：2016-02-02 00:00 点击数：
| | |

各县（区）审计局、本局各科室（中心）：

根据《国务院办公厅关于印发稳增长促改革调结构惠民生政策措施落实情况跟踪审计工作方案的通知》（国办发明电〔2014〕16号）、《审计署关于进一步加大审计力度促进稳增长等政策措施落实的意见》（审政研发〔2015〕58号）和《福建省审计厅关于印发2016年度稳增长促改革调结构惠民生防风险政策措施落实情况跟踪审计工作方案的通知》（闽审财〔2016〕12号），我局制定了《莆田市2016年度稳增长促改革调结构惠民生防风险政策措施落实情况跟踪审计工作方案》，现印发给你们，请认真贯彻执行。

 

 

莆田市2016年度稳增长促改革调结构惠民生防风险政策措施落实情况跟踪审计工作方案

根据《国务院办公厅关于印发稳增长促改革调结构惠民生政策措施落实情况跟踪审计工作方案的通知》（国办发明电〔2014〕16号）、《审计署关于进一步加大审计力度促进稳增长等政策措施落实的意见》（审政研发〔2015〕58号）和《福建省审计厅关于印发2016年度稳增长促改革调结构惠民生防风险政策措施落实情况跟踪审计工作方案的通知》（闽审财〔2016〕12号），为做好2016年度对中央、省和我市稳增长、促改革、调结构、惠民生、防风险政策措施落实情况的跟踪审计，制定本方案。

一、审计目标

通过审计，推动中央、省和我市稳增长、促改革、调结构、惠民生、防风险政策措施落实到位，促进经济平稳较快发展、增强改革创新活力和区域开放协调发展。

二、审计对象和范围

审计对象主要为各县（区）人民政府、湄洲湾北岸经济开发区管委会、湄洲岛国家旅游度假区管委会和市直相关单位，必要时延伸审计相关企事业单位、社会组织和项目建设单位等。审计时间范围为2016年各季度贯彻落实稳增长、促改革、调结构、惠民生、防风险政策措施落实情况。

三、审计重点

围绕国务院和省、市出台的稳增长、促改革、调结构、惠民生、防风险一系列政策措施，围绕项目落地、资金保障、简政放权、政策落实、风险防范“五个抓手”，结合我市经济社会发展实际和部门特点，确定以下方面审计重点：

(一)市局围绕精准扶贫和扶持实体经济等方面确定4项政策专题审计内容，分季度实施。专题具体内容分解如下（实施专题及分工见附件1）：

1. 2015年度职业技能培训与促进就业创业政策落实情况跟踪审计；

2. 全市产业转型升级扶持实体经济政策落实情况跟踪审计；

3. 金融支持实体经济，特别是中小微企业政策落实情况跟踪审计；

4. 扶贫资金暨精准扶贫政策落实情况跟踪审计。

各县（区）局应根据省厅确定的8项政策专题审计内容，结合本地区实际选择若干项开展审计，并将安排的专项项目和时间报市局，做好上下联动，推动政策落地生根、产生实效。

（二）重点建设项目建设进展情况。结合国家和省、市 “十三五”专项规划和区域发展战略，以及省政府确定的2016年度省重点建设项目重点对水利、城市基础设施、保障性安居工程、工业、服务业等行业重点建设项目进行全过程跟踪审计。对已批复项目，开工和建设滞后的，推动尽快形成实物工作量，关注项目是否存在虚报工程进度、项目建设工程质量不达标等问题。对建设项目的程序性问题，按照有利于项目实施、政策目标落实、促进经济增长的要求，督促尽快完善。对正在报批项目，重点揭示审批环节多、耗时长、效率低等突出问题，促进优化审批流程、加快进度。对各环节进展缓慢的项目，要深入分析原因，严格区分主体责任，提出有针对性的建议。

2016年度确定:一是全市各级审计机关继续跟踪2015年尚未整改和正在整改的重点项目; 二是从省政府确定的2016年度省重点项目中选取水利、城市基础设施、工业、服务业等不同行业12个项目，分季度开展重点跟踪，其中：市局审计6个项目；各县（区）审计局审计6个。（具体跟踪项目清单与分工见附件2)

（三）重点资金落实使用和盘活财政资金存量情况。重点关注与稳增长、促改革、调结构、惠民生、防风险直接相关的财政资金是否保障到位并及时投入使用，加强对各级财政存量资金，特别是民生方面的存量资金审计。把财政资金投入与项目进展、事业发展以及政策目标实现统筹考虑，重点揭示应投未投、该用未用问题，推动财政资金合理配置。研究分析存量资金的成因、结构、闲置时间和资金性质，区别对待，分类施策，推动加快清理盘活进度。对项目已无法实施的长期结转资金，要督促及时收回。对确定当年预算不能执行的项目，要推动及时调整预算，防止形成新的资金沉淀。对清理收回的存量资金，要督促及时安排使用。

2016年，市局结合市本级预算执行审计，安排社会保障和就业支出科目审计、民生方面财政存量资金盘活使用情况审计，职业技能培训与促进就业创业政策落实情况跟踪审计，各县（区）审计局应结合当年预算执行审计，安排社会保障和就业支出科目审计、财政专项资金和存量资金盘活审计。

（四）推进简政放权政策落实情况。一是检查本地区、本部门取消下放行政审批事项，推动规范和公开行政审批流程，压缩和明确审批时限等情况；对已取消下放的行政审批事项，重点揭示明放暗留、变相审批、弄虚作假等行为。二是推进收费项目清理，严肃查处违规设立的基金和收费项目；促进清理规范行政审批中介服务，推动整顿规范行业协会商会收费。三是推进商事制度改革和职业资格改革，推动通关便利化。四是推进监管方式创新，促进提升监管效能，营造公平竞争、良性发展环境。

市局及县（区）审计局，2015年预算执行审计中结合政策落实情况，重点开展对推进商事制度改革，推进行政事业性收费清理和推动整顿出口环节乱收费等方面的审计，促进简政放权落实。

（五）防范资源环境风险情况。关注资源环境风险，加强对水、矿产、土地等资源以及环境保护情况的审计，防范危害资源环境安全等问题。

2016年市局确定对仙游县自然资源资产进行审计试点。

（六）跟踪审计发现问题整改情况。针对2015年和2016年稳增长等政策措施落实情况跟踪审计报告中提出的问题，检查各地区、各部门是否制定或完善相关政策，是否积极组织相关单位进行整改。已经整改的问题是否产生积极效果，重点关注未及时整改或整改暂时困难的问题，深入分析原因，找出问题节点，进一步揭示体制障碍和制度缺陷，提出解决问题的意见和建议。

四、组织分工和时间安排

（一）组织分工

本次审计，由市局财金科具体组织实施。

1．由市局财金科、农保科等10个科室分别牵头实施确定的专题审计事项及跟踪每季度确定的省重点项目（具体见附件1、附件2）。

涉及多个科室参与的重点工作任务，由任务落实牵头科室负责协调汇总各科室的审计情况，任务参与科室根据各自科室任务审计相关内容，并做好配合工作。

2．各县（区）审计局对本辖区的事项组织审计。市局各审计组延伸相关县（区）、部门、企业和建设项目时，要与县（区）审计局做好工作衔接，确保审计对象不重复、不交叉。

（二）时间安排

1. 2016年度跟踪审计从1月开始，分季度持续实施。各县（区）审计局审计过程中发现的重大情况，要及时上报市审计局。

2. 市局各审计组每个季末当月30日前向财金科报送已征求意见的审计报告。各县（区）审计局实施的跟踪审计报告，于每个季末当月30日前主送本级人民政府，抄送市审计局。

3. 市局各审计组、各县（区）审计局每季度应随审计报告填报《重大项目跟踪进度情况表》（附件3）、《跟踪审计发现问题情况表》（附件4）、《稳增长跟踪审计总体情况统计表》（附件5）、《稳增长等政策跟踪审计整改情况统计表》（附件6）。

五、工作要求

（一）高度重视，组织有力。对国务院和省、市出台的有关稳增长、促改革、调结构、惠民生、防风险政策措施贯彻落实情况进行跟踪审计是国务院、省政府和市政府交办的重要任务，是审计机关的法定职责和经常性审计任务。各级审计机关要把思想和行动统一到党中央、国务院重大决策部署上来，把促进稳增长等相关政策措施贯彻落实作为当前审计工作的重中之重，进一步加大跟踪审计力度。

（二）精心谋划，有效落实。市、县（区）审计机关要科学谋划2016年全年稳增长等政策措施落实情况跟踪审计工作，各项审计都要把监督检查稳增长等政策措施贯彻落实情况作为重要内容，做到责任分工明确、人员保障到位、工作有效衔接、成果反映及时。开展领导干部经济责任审计，应将重大决策部署落实、重大指标（如节能减排、基本农田保护、精准扶贫等）完成、年度政府经济工作会议和政府工作报告等文件中可量化的具体工作完成以及简政放权落实等情况列入必审内容，审计实施结束后应单独形成稳增长审计结果，交由市局经责室汇总后报财金科。

（三）精心组织，确保质量。市、县（区）审计机关要加强项目组织实施，每个专题项目和省重点建设项目均按独立的审计项目进行管理，单独开具审计或审计调查通知书，并出具审计报告，年度终了独立归档。审计过程应明确和落实审计质量控制责任，确保实现预定的审计工作目标。市局将加强督促和检查，建立对各县（区）审计局和市局相关科室（中心）跟踪审计组织实施、审计结果上报以及审计质量情况的检查、考核和通报制度。

（四）严明纪律、文明审计。市、县（区）审计机关要严格在法定职责权限范围内开展审计工作，既要敢于碰硬、又要善于解决问题。要严格遵守廉政纪律、保密纪律、审计工作纪律，做到审计程序合法，审计方式遵法，审计标准依法，审计保障用法。要切实做到文明审计，坚持客观公正、平等待人、以理服人，充分听取被审计单位和有关方面意见。

各县（区）审计局和市局相关科室要将稳增长跟踪审计实施方案和具体联系人名单报送市局财金科。

莆田市审计局

2016年2月2日
