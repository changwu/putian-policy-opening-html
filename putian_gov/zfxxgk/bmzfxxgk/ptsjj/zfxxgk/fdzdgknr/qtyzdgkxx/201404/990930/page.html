莆田市审计局关于开展2013年度审计机关信息化工作考核的通知

发布时间：2014-04-21 00:00 点击数：
| | |

各县（区）审计局，市局各科室（中心）：

为进一步加强我市审计信息化建设，全面落实党组“强力推进应用计算机审计”的工作要求，按照市局印发的《莆田市审计机关审计信息化工作考核暂行办法》（莆市审[2013]10号）要求，经研究决定，对各县（区）审计局及各科室（中心）2013年度审计信息化工作开展考核。现将有关事项通知如下：

一、组织领导

为加强考核工作的组织领导，市局成立2013年度审计信息化工作考核领导小组，小组成员如下：

组 长：余志生 局长

副组长：林金顺 副调研员

成 员：陈炜华 办公室副主任

宋建瓯 监察室主任

王建绍 法制科主任科员

卢庆元 计算机应用中心副主任

考核领导小组下设办公室，挂靠在计算机应用中心，卢庆元同志兼任办公室主任，成员由以下人员组成：陈象广，黄金双，吴秀丹，林建锋，郭健健同志组成。

二、考评内容

2013年度审计机关信息化工作考核标准，参照省厅2013年度信息化工作考核标准进行修订，考核内容包括信息化建设和信息化应用，包括计算机中级培训及考试、AO与OA交互、计算机审计案例与方法评选、计算机设备管理、安全保密、信息化建设等事项。具体考核事项及内容见附件。

三、考核程序及时间安排

（一）自评阶段：（4月21日至4月27日）

各县（区）审计机关按照《各县（区）审计局信息化工作考核标准及自评表》进行自评，经单位领导审核签章（签字）后，将自评表及相关证明资料的纸质和电子文件于4月27日前报送考核办公室。

（二）复查阶段（4月28日至5月5日）

1、考核领导小组办公室负责收集整理各单位（部门）自评材料，并复查确认上报材料。

2、考核领导小组办公室将对各县（区）审计局考核结果排在前3名的单位进行实地复查。如有弄虚作假取消评优资格，所在名次由下一名次递补，并通报批评。

（三）结果审核阶段

考核领导小组办公室将整理汇总后的复查结果，于2014年5月7日前报考核领导小组审核并提交局办公会议审定考核结果。本次考核将对考核结果优秀的单位（部门）进行表彰，其中，各县（区）审计局择优选取第一、二、三名各1个。市局各科室（中心）考核结果并入科室年度考核的重要内容。

各县（区）审计局及市局各科室（中心）要高度重视本次审计信息化考核工作，加强对考核工作的组织与领导，在规定时间内完成本单位（部门）的考核工作并将相关材料上报考核领导小组办公室。

联系人：卢庆元 ，联系电话：2386900。


莆田市审计局

2014年4月21日
