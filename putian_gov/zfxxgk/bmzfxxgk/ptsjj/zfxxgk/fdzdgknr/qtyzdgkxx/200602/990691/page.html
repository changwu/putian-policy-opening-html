标题 莆田市审计局《关于2006年元旦、春节期间严格遵守廉洁自律规定反对奢侈浪费》的情况报告

莆田市审计局《关于2006年元旦、春节期间严格遵守廉洁自律规定反对奢侈浪费》的情况报告

发布时间：2006-02-10 00:00 点击数：
| | |

市委反腐办：

接到贵办关于转发中共福建省委反腐败工作小组办公室《关于2006年元旦、春节期间严格遵守廉洁自律规定反动奢侈浪费的通知》的通知（莆委反腐办[2005]15号）后，我局领导高度重视，于元月4日上午，组织干部职工认真学习中央、省委和市委关于廉洁自律的各项规定，增强廉洁自律意识，筑牢思想道德防线。春节之后结合局党组民主生活会，督促干部职工认真进行对照检查。

经自查，近年来我局狠抓财务制度管理，坚持一支笔审批报销的原则，严格执行公务接待审批制度，没有利用各种会议、学习、培训之机用公款互相宴请；上级审计机关到我局进行公务活动，严格控制陪餐人数和执行食宿标准，没有超标准接待；下级审计机关到我局办理公务，没有以任何名义用公款宴请我局工作人员工员和其他相关人员。严格执行中央规定，元旦、春节期间没有给干部职工发放福利奖金和年货物品。

局党组成员和局领导班子成员能坚决执行省委反腐办提出的“九个严禁”、市委出台的“五条禁令”和“四项制度”，切实加强我市审计机关反腐倡廉工作。紧紧围绕发展、服务发展、保障发展，以发展来谋划审计工作，以谋促发展的效果来衡量我市审计机关的党风廉政建设工作的成效。坚持正确的工作方向，把审计机关的一切工作放在大局工作中去把握，把是否有利于加快建设湄洲湾港口城市、推动莆田在海峡西岸城市群中的壮大和崛起这个发展大局作为工作目标，在促进全市经济保持持续发展的态势中体现成效，在落实科学发展观，破解发展难题，构建和谐莆田发展中体现成效，在巩固保持共产党员先进性教育成果中体现成效。在日常工作中，倡导并落实：思想立廉、教育养廉、制度律廉、典型促廉、民主兴廉、监督保廉的“六廉并举”之措施和“审计兼职监督员制度”，扎实开展“法制与时效建设年”活动。严格执行“三个管好”承诺、个人收入申报和重大事项报告制度，自觉做到：没有收送现金、有价证券和支付凭证；没有放任、纵容配偶、子女及身边工作人员利用干部职权和职务影响收受礼金、有价证券和贵重物品；没有“跑官要官”；没有接受单位、企业或私人安排的可能影响公正执行公务的旅游、娱乐、健身、宴请；没有用公款购买、发放各种代币购物券（卡）和违反规定滥发钱物；没有参与赌博；没有用公款公物操办婚丧嫁娶和借婚丧嫁娶之机收钱敛财。积极响应市纪委、市妇联、市直机关纪工委、市直机关妇工委号召，我市审计机关严格遵守廉洁自律各项规定，自觉抵制各种不良风气，大力弘扬艰苦奋斗作风，营造崇尚廉洁，反对奢侈浪费等不正之风的良好氛围，提高廉洁自律意识，筑牢拒腐防变的思想道德防线。要求全体干部职工切实做到过年不忘修身律己，树好形象；不忘爱我莆田，谋促发展；不忘送温暖献爱心，扶贫助困；不忘走亲访友，尊老敬贤，过一个健康欢乐，文明祥和的节日

积极响应市委保持共产党员先进性教育活动领导小组《关于2006年春节期间认真做好农村先进性教育活动》和《关于2006年春节期间各级各部门单位和党员干部走访挂钩结对村和孤寡病残困难户》号召，开展“送温暖、献爱心”活动，关心帮助困难群众,主动落实机关部门和党员干部挂村联户长效机制的重要措施，早布置、早行动、早落实。1月11日,结合挂钩村开展的第三批保持共产党员先进性教育活动,由局党组成员、副局长朱明带领有关人员，深入涵江区秋芦镇崇联村，集中回访了20户孤寡病残困难户、特困户, 送去慰问金4000元和部分衣服，关心群众生活，构建和谐社会，开展扶贫济困活动，充分体现为民办实事、好事的真情实意。

结合贯彻市委反腐办关于转发《关于2006年元旦、春节期间严格遵守廉洁自律规定反动奢侈浪费的通知》精神，会议要求全体审计干部在履行审计监督职能过程中，切实担负起反腐败抓源头单位之一的重任，提高思想认识，以对党和人民高度负责的态度，解决好群众反映强烈的热点难点问题，把“严格遵守廉洁自律规定、反动奢侈浪费行为”的专项工作，作为当前和今后一个时期审计工作的重点抓紧抓好，切实把党风廉政建设责任制落实到位。

2006年2月10日
