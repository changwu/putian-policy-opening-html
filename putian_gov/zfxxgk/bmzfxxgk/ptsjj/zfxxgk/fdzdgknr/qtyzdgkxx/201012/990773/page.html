莆田市审计局绩效管理办法

发布时间：2010-12-15 10:00 点击数：
| | |

各科室、计算机中心：

为了贯彻落实省委、省政府和市委、市政府关于绩效管理的工作要求，加强审计机关队伍建设，提高审计干部依法行政能力和审计执法水平，结合我市审计工作实际，制定《莆田市审计局绩效管理办法》。

一、指导思想

绩效管理工作坚持以邓小平理论、“三个代表”重要思想和十七届五中全会精神为指导，深入贯彻落实科学发展观，以深化行政管理体制改革为目标，以提升工作效能抓手、以正确政绩观为导向，深入推进绩效管理实践，促进我局各科室、计算机中心和全局干部、职工，抢抓机遇、加快发展，改进作风、注重实效。运用考核评估机制，检验工作绩效，激发审计机关工作人员转变发展观念，创新发展意识，提高履职力、执行力、公信力。更好地适应新形势，完成新任务，实现新发展，使审计工作更好地服务于莆田的政治、经济、文化和民生，推动莆田新一轮加快发展。

二、组织领导

市审计局设立绩效管理工作领导小组，同时下设绩效管理办公室。办公室抽调相关人员组成，负责对全局绩效管理工作的组织实施，监督检查和评估考核。绩效管理考评工作以年度为单位每年进行一次。

 

三、绩效管理对象和分值设置

绩效管理对象：市审计局在职现任科级以下（含科级）所有工作人员。绩效管理以科室为单位，分值设置为百分制，公共职责基本分为40分，相关业务基本分为60分。集体共同完成的项目加分或扣分，相关参与科室一般折半加分或扣分计分。特殊情况经局务会议研究，可按相关科室人员对完成项目的工作量大小或所负责任不同给予另外加分奖励或扣分处罚。

四、绩效管理内容及方法

（一）公共职责绩效考评细则

1、违反局机关考勤管理暂行规定（莆市审[2007]50号文），每人次扣0.5分。年度考评时，按科室人员的总扣分，除以科室总人数，为科室考勤最后得分。

2、对局机关及党支部组织的政治理论和业务学习及其它要求参加的会议，无故不参加或迟到早退每人次扣1分。

3、对市委、市政府及相关职能部门组织的各种活动无故不参加或迟到早退的，以及布置的工作任务没有完成的每人次扣2分。

4、半年工作总结及年终工作总结未认真完成、未及时上交的每次扣1分。

5、违反莆田市机关工作人员“四要四不得”工作纪律和“五条禁令”的，经查实的每人次扣2分。被省、市效能办明察暗访并受处理的每人次扣10分。

6、违反审计纪律和廉政纪律，利用职权谋取私利或接受礼物、礼金、有价证券等行为的，经查实的每人次扣10分。

7、积极编写审计业务和队伍建设等各种信息，每个科室每年至少要在《莆田审计》刊登两条信息，少一条扣2分，每多刊登一条信息加0.2分。审计信息要求内容真实、文字简炼，言之有物、可用性强。

8、信息被批示、采用的，每条加分如下：被审计署内部刊物采用或署领导、省领导、省委办、省政府办批示的加8分；被审计厅和市委办、市府办内部刊物采用或省厅领导和市领导批示的加6分。以上信息含相关网页采用信息，同样信息内容在不同层次刊物采用或批示的不能重复加分。

（二）相关业务绩效考评细则

1、办公室绩效考评细则

办公室要做好办文、办事、办会等日常事务管理工作，确保机关系列工作正常运转，提高服务全局的意识和水平。

（1）认真完成好市委、市政府及上级审计机关布置的各项工作任务，超时或没有完成好的每一项扣1分。

（2）认真编制和调整年度审计工作计划，没有及时编制和调整年度工作计划的扣1分。

（3）认真做好局务会议记录，并根据实际情况编写会议纪要，按要求没有落实好的每次扣1分。

（4）做好文件的起草、发文、收文、传阅、保管和归档工作，领导批示的传送、办理工作，规范印章的保管使用和车辆的管理维护工作，造成失误的每次扣1分。

（5）每月至少编办一期莆田审计信息，少一期扣0.5分。因工作不负责任，导致审计信息出现严重差错的每次扣1分。

（6）认真做好党委、政府及相关部门布置的创平安莆田、创党建先进单位和创文明单位以及绩效管理、民主评议政风行风等基础性工作，没有尽职尽责做好以上各项工作的分别扣1分；绩效管理为优秀、民主评议政风行风名列全市前五名的分别加5分；最后三名的分别扣3分；创党建先进单位和继续保持省级文明单位的分别加3分；获创平安莆田奖加1分。

（7）参与审计业务工作，按照审计业务考评细则的规定加分或扣分。

2、监察室绩效考评细则

（1）没有制定《年度党风廉政建设责任书》的扣1分、没有督促签订《年度党风廉政建设责任书》的扣1分。

（2）每年至少进行两次审计效能和党风廉政工作督查，少一次扣1分。

（3）根据年度审计项目计划安排情况，每年至少开展二次审计回访，回访单位不少于被审单位总数的50%，了解检查审计人员在被审计单位遵守审计纪律的情况，没有开展审计回访的扣1分。

（4）协助相关职能科室做好创平安莆田、创党建先进单位和创文明单位以及绩效考评、民主评议政风行风工作，没有协助、工作被动的每项扣1分。

（5）行评中群众反映的问题没有认真调查核实的，每件扣3分，调查后没有及时反馈的每件扣2分。

（6）效能投诉件、省厅及市委市政府、市纪委（监察局）转办的其他群众信访举报件，没有办理的，每件扣2分，办结后没有及时反馈的每件扣3分。

（7）参与审计业务、创党建工作、文明建设、平安莆田、绩效评估、行评等其他工作，按照所参加的项目规定参照办公室相应加分或扣分。

3、法制科绩效考评细则

（1）每年至少组织1次以上涉及审计相关的法律法规宣传工作,未组织实施的扣1分。

（2）每年至少组织两次审中审计质量检查,少1次扣1分。

（3）认真制定审计业务质量考评方案，并负责对全市审计机关的业务综合考评工作，没有组织考评的扣2分。

（4）认真做好《审计报告》和《审计决定书》在适用法律上的审核把关。对审计报告和审计决定书引用法律法规条款不规范的，没有发现和指正的每次扣1分。

（5）按照省审计厅的方案要求，认真组织审计优秀项目评选工作。审计项目被审计署评为“优秀项目”加5分，评为“表彰项目”的加3分；被省审计厅评为“优秀项目”的加3分，评为“表彰项目”的加1分。

（6）参与审计业务工作，按照审计业务考评细则的规定加分或扣分。

4、计算机应用中心绩效考评细则

（1）做好网络安全管理和上网资料的保密工作，失误一次扣1分，造成严重后果的每次扣5分。及时对全局计算机及其相关设备的验收、安装、调试、维护等工作，发现险情要及时报告，及时处理。未履行好职责的每一项扣1分。

（2）保障设备的安全，机房内的计算机及网络设备和重要设施，没有专人负责管理的扣1分。机房设备在不安全的环境下运转（如温度过高或其他危险情况），没有及时采取相应措施、没有及时报告的每次扣2分。由于维护和管理工作不到位，造成机器设备损坏的每次扣5分。

（3）做好与县区审计局计算机联网工作，出现故障没有及时处理，每次扣1分。

（4）参与审计业务工作，按照审计业务考评细节的规定加分或扣分。

（5）其他加分取办公室、监察室、法制科等科室的加分平均。

5、审计业务科室绩效考评细则

（1）完成年度审计计划

年度审计项目除特殊情况提出申请经核准延长时限外，其他必须按年度计划规定的时间完成任务，没有按年度计划规定的时间完成任务的每个项目扣2分。

（2）审计统计与分析

①审计项目结果统计台账没有及时、完整、准确填报的每次扣2分。

②对审计统计不作综合分析或专题分析，造成针对性不强的每个项目扣1分。

（3）审计项目质量考评加分

①审计项目被审计署评为优秀项目的加15分。

审计项目被审计署评为表彰项目的加10分。

②审计项目被审计厅评为优秀项目的加10分。

审计项目被审计厅评为表彰项目的加7分。

③审计项目被市审计局评为优秀项目的加5分

审计项目被市审计局评为表彰项目的加3分。

④获得单项奖，按署级、厅级、局级分别加7分、5分、3分（如审计统计与审计信息、审计科研及成果应用、创新工作机制、计算机应用等其他项目单项奖）。

以上项目不能重复加分。

（4）审计项目结果加分

①对重大问题能查深查透，有下列情况之一的，每个审计项目可加2分，但不能重复加分：

（a）纠正和追回政府性资金，增加国库收入或财政专户收入（不含挂账应缴未缴数）10万元以上，并落实到位。

（b）减少各项财政拨款、补贴10万元以上，并落实到位。

（c）追回专款，归还原资金渠道10万元以上，并落实到位。

（d）减少建设项目投资金额50万元以上，并落实到位。

②审计查出案件线索，依法向纪检监察或司法机关移送，根据下列情况加分：

（a）查出案件线索，依法向纪检监察或司法机关移送的加1分。

（b）纪检监察或司法机关立案调查的再加4分。

（c）立案调查后有处理结果的再加4分。

③审计项目取得较好的宏观效果，审计报告或有关专题报告有下列情况之一的给以加分（要有证明材料并归入所属项目档案，不能重复加分）：

（a）审计项目得到署领导、省领导批示的加8分。

（b）审计项目得到审计厅领导和市领导批示的加6分。

（c）审计成果公布或新闻媒体报道后在社会反响较好的加1分。

④审计维护群众利益有效果的每条加2分：

（a）纠正、清退向群众乱收费、乱罚款5万元以上的。

（b）督促扶贫救灾、支农项目等资金落实生效到位10万元以上的。

（5）审计项目结果加分

查出“小金库”，有处理处罚上缴罚没金额的，并落实到位，加3分。

（6）其他扣分

本项扣分以审计业务质量考评为依据。

①审计发现的问题未经审计组集体讨论就在审计报告征求意见稿中反映的每一项扣2分。

②对发现违纪问题的处理处罚没有召开审计业务会议，没有形成业务会议纪要并入卷归档的每项扣2分。

③对审计发现重大问题的疑点、线索，没有及时向局领导报告，在审计职权、手段范围内没有追踪审深审透的发现一项扣3分。

④对审计决定书落实、整改不到位且没有开展后续审计的每一项扣1分。审计项目没有及时整理归档，或归档材料不全的，每个项目扣３分。

五、组织绩效评估

1、评估方法

采取自我评估、公众评议、考核评估、综合汇总、评估结果公示、评估结果复核六种方法进行。

（1）自我评估。

各科室、计算机中心按照工作方案确定的考核指标体系对本单位绩效开展自我评估、分析和绩效总结。

（2）公众评议。

各科室、计算机中心可以相互对其他科室、计算机中心的指标数据采集，工作绩效的合理性进行评议，并提出增、减分意见。

（3）考核评估。

①数据收集：局绩效管理工作办公室在每年的1月底将自评结果和绩效总结报送局绩效管理工作办公室。

②数据核验：每年2月15日底前，局绩效管理工作办公室，根据绩效评估指标考核体系对各科室、计算机中心进行考核评估，核对反馈绩效评估指标完成情况，反馈考核评估情况。被评估单位对考核评估情况如有异议，可以申请复核，局绩效管理工作办公室要及时提出复核意见。

（4）综合汇总。

绩效管理工作办公室按照设定的计分方法计算综合得分，评出评估等次，并撰写绩效评估工作通报。

（5）评估结果公示。

绩效评估结果和绩效评估工作通报将以适当的方式进行公示。

（6）评估结果复核。

被评估的各科室、计算机中心对评估结果如有异议，可以在公示之日起三日内向绩效管理工作办公室申请复核，逾期视同无异议，绩效管理工作办公室要及时提出复核意见。

六、绩效管理结果应用

绩效管理综合评分前三名的科室，给予全市审计机关通报表彰，其科室主任、科长及主要负责人作为年度公务员考核“优秀”等次，其他科员给予一定比例的“优秀”等次。并作为各类评先评优、安排年度学习培训考察优先考虑的人选。连续两年最后一名的科室主任、科长予以调整领导岗位，可以在科室之间岗位交流、也可以在领导职务与非领导职务之间调整。

七、工作要求

（一）强化管理，落实主体责任。各科室、计算机中心要树立正确的绩效价值观，把绩效管理作为行政管理的一项基本制度，增强主体责任意识，认真抓好落实。科室领导要亲自挂帅，加强绩效管理工作的组织实施。科室人员之间要形成合力，协同推进，努力形成绩效管理的整体合力。

（二）精心组织，推动有效运行。各科室、计算机中心要围绕职能职责，紧密结合实际，以实绩为核心的绩效评价体系，积极探索提升工作绩效的方法和途径，形成长效机制，做到用机制管理人、规范人、引导人。

（三）真抓实干，确保工作实效。要把绩效管理与政府绩效管理部门的职能职责要求、目标任务紧密结合，通过绩效管理促进职能职责的发挥、工作目标的实现。构建充满活力、富有效率、更有利于审计科学发展的体制机制，为推动莆田新一轮跨越发展做出贡献。

  

 

                              莆田市审计局

                             2010年12月15日
