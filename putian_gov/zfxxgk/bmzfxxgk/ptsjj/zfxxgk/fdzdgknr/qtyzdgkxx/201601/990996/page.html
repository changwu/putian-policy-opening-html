莆田市2016年审计信息化工作意见

发布时间：2016-01-26 00:00 点击数：
| | |

各县（区）审计局、市局各科室（中心）：

为加快我市审计信息化建设步伐，进一步落实《福建省审计厅“十三五”审计工作发展规划》等文件确定的目标任务，深入贯彻落实科学审计理念，全面落实市审计局党组提出“强力推进应用计算机审计”的工作要求，到“十三五”末实现全市审计信息化建设达到全省中上水平，部分领域走在全省前列。现结合我市实际，提出2016年度审计信息化工作意见。

一、继续完善审计管理系统建设。市局审计项目全部实施AO与OA交互。办公室负责审计项目计划制定及下达，各审计项目承担科室（中心）从OA系统下载项目任务，在项目实施过程中，审计工作底稿、重要审计证据和审计文书等归集纳入AO软件进行管理，最后通过交互完成审计项目在OA系统归档。同时，在夯实内部公文流转的基础上，逐步推进重要外来公文的流转，促进公文业务流程规范化、电子化，提高无纸化办公水平。全面推进审计移动办公平台运用，促进审计专网延伸和扩展，充分发挥办公平台在审计现场和审计机关之间信息交互的作用。

二、组织审计信息化应用相关征集评选活动。将计算机审计项目计划列入年度项目计划。加大开展AO应用实例及计算机审计方法、信息系统审计项目案例和优秀计算机审计项目等征集评选活动力度，市局各业务科室（中心）至少完成1个优秀计算机审计项目、1篇AO应用案例和1篇审计方法，各县（区）局至少完成2个优秀计算机审计项目、2篇AO应用案例和2篇审计方法。组织召开全市审计系统AO案例征集评审会，本着以评审带培训，以交流增联系，以教学促提高为目的，加强审计人员的沟通交流。

三、开展信息系统审计试点。组织开展全市信息系统审计实例征集活动。信息系统审计不仅要对被审计单位的信息系统从立项、设计、开发、测试和运维全过程审计，而且要通过对信息系统审计，进一步了解单位业务流程、数据流程，掌握单位核心业务，提升审计监督能力。按照征集活动要求，我市将开展信息系统审计试点，并至少完成一个信息系统审计项目。县(区)局开展审计项目时，在条件允许的情况下，也应尝试对被审计单位的信息系统进行部分或完整的审计。开展信息系统审计可以独立开展，也可与传统审计项目结合进行。

四、加大计算机审计人才培养和引进力度。要利用空编、购买社会服务等方式引进计算机专业人才，缓解人员少任务重的突出矛盾。同时，继续加强对现有审计人员的计算机专业技能培训。支持鼓励审计人员参加计算机审计中级培训及后续培训班、计算机审计高级人才培训班，鼓励参加国际信息系统审计师等高级资格认证考试。开展计算机审计研讨交流活动，内容包括优秀AO应用案例、计算机审计方法、信息系统审计案例、专题研讨等，继续做好AO认证考试，促进通过考试比例不断提高。

五、成立数据分析团队。通过整合全市审计机关专业人员，组建包括计算机数据分析人员和业务骨干在内的非专职的跨行业综合数据分析团队。数据分析团队人员要统一服从调配，做到数据先行，起到侦察兵作用。数据分析团队分设预算执行审计数据分析组、税收审计数据分析组、社保审计数据分析组、财政审计数据分析组、信息系统审计组、综合数据分析组等，也可根据审计工作需要，增设其他数据分析组。项目数据分析组由审计组长进行管理，主要负责整个审计项目的数据分析工作、技术保障和计算机方法的实现。

六、筹划审计数据中心建设。市局所有审计项目应开展被审计单位信息系统应用情况调查，通过努力，不断积累和收集数据源信息，为数据中心建设打下扎实基础。

审计项目应当归集下列电子数据：

（1）审计组执行审计项目采集或者获取的基础资料数据、会计核算数据、行业业务数据、企业ERP的控制数据等被审计单位数据；

（2）审计组执行审计项目形成的审计数据（含审计中间表和结果表）；

（3）审计组根据审计需要向相关部门单位收集的外部数据；

（4）其他应当归集的数据。

七、做好金审工程三期建设初期准备工作。按照《福建省“金审”工程（三期）的建设内容》要求及省厅统一部署，稳步推进联网审计建设。围绕到2020年，实现覆盖财政、地税、金融、公积金、社保、企业和自然资源资产等行业联网审计的总体目标，在省厅完成行业联网审计系统的基础上，确保完成各行业联网审计系统建设和应用。同时，以福建省审计数据中心和交换中心为平台，加快审计数据库建设。构建被审计单位财务业务数据库、审计机关审计结果数据库、第三方信息数据库等三大类数据库。

八、组织开展信息化考核工作。按照《莆田市审计机关审计信息化工作考核暂行办法》要求，对各县（区）局、各科室（中心）信息化应用和信息化建设开展考核，进一步有效推动我市审计信息化工作的开展，并不断健全完善信息化工作考核激励机制。同时，将信息化工作纳入审计工作效能监督范畴，市局监察室要全面介入督查，将审计信息化工作情况与评优评先、干部提拔等挂钩，采取有效措施推行计算机审计，鼓励审计人员创新计算机审计方法，全面推进审计信息化建设和应用。

 

莆田市审计局

2016年1月26日
