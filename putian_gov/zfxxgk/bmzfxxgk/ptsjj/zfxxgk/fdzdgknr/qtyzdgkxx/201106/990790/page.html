莆田市审计局关于2011年行评选题的函

发布时间：2011-06-03 00:00 点击数：
| | |

市评议办：

根据《莆田市人民政府关于莆田市2011年民主评议政风行风工作的实施意见》（莆政综〔2011〕64号）文件要求，为更好地服务市委市政府提出“跨越发展、宜居港城”的目标和要求，经过广泛征集社会各界意见和建议，对照工作职责，围绕今年审计计划，决定把“加大民生资金审计，助推和谐莆田建设”作为今年行评的选题进行整改。

一、选题内容

加大民生资金审计，助推和谐莆田建设。

二、选题目标

1、坚持以人为本，把维护人民群众的利益作为审计工作的出发点和落脚点，把涉及到人民群众利益的、人民群众关注的问题作为审计监督重点，把对人民群众负责、让人民群众满意作为评判审计成果的根本标准。

2、以科学发展观为指针，坚持审计为民理念，把改善民生和促进民生摆在审计工作更加突出的位置，认真履行审计职责，规范审计行为，提高审计质量，切实发挥审计“免疫系统”功能作用，推进依法行政，更好地服务市委市政府提出“跨越发展、宜居港城”的目标和要求，推进和谐莆田建设。

三、方法步骤

我局将从贵办批复后至今年年底前，按以下步骤开展选题评议工作：

1、领导部署。局主要领导靠前指挥，亲自召开专题会议，研究部署，确定工作方案，精心组织实施，切实抓好选题评议工作。

2、自查自纠。各业务科室、全局干部要对今年以来开展“民生”项目审计进展情况进行一次认真检查。局行评督查小组跟踪检查，进一步督促按时完成“民生”项目审计工作。

3、整改承诺。采取适当方式向社会公开承诺整改目标，接受群众监督。

4、整改落实。实行谁主审谁负责的原则。各责任人要认真收集整改意见，重点检查在开展民生项目审计过程中是否严格执行审计程序、有无违规审计、有无超过审计时限没有提交审计报告等问题，提出针对性强的整改措施，全力整改，务求实效。

5、督促检查。局行评办、行评督查小组每月对“民生”审计项目的完成情况进行考核督促，检查整改成效。年终全面进行考核验收、评比。

6、建章立制。年终要认真总结今年民生资金审计的工作成果、经验，并针对存在的问题、薄弱环节，提出切实可行的加强和改进民生审计的意见、办法。

四、工作措施

1、加强培训，提高能力。利用每周一全体干部学习日，加强政治理论、党史（第二卷）、中央、省、市有关会议精神学习，引导全体审计人员牢固树立民本审计观，过好权力关、人情关、名利关；同时加强《审计准则》等法律法规和审计业务培训，增强审计人员素质，提高工作效率和工作水平。

2、分解任务，明确责任。将今年的民生项目审计工作任务分解到业务科室，明确责任人、完成时限、质量要求。

3、规范程序，严把质量。一是要求审计人员都要严格按审计规范进行运作，防范审计风险，并实行审计质量与目标管理考核挂钩，坚持廉洁从审、高效审计。二是执行复核制度。对“民生”审计项目实行严格复核，随时纠正，随时处理，层层把关，规避风险，提高质量。三是坚持审计业务会议制度。加强对“民生”项目审计报告的审定把关，及时纠正审计质量方面存在的问题，做到早发现、早解决，把质量隐患消灭在萌芽状态。对重大审计项目审计报告的审定和处理处罚，必须由审计业务会议决定。

4、强化责任，严格奖惩。将“民生”项目列入年度审计项目质量考评的重点对象，对获得优胜审计项目，给予奖励和表彰；对因审计质量问题而影响审计机关形象的责任人及相关人员，给予通报批评。追究因审计质量问题而被行政诉讼或行政复议的责任人及相关人员的连带责任。

我局将认真落实上述各项措施，确保“民生”项目审计存在问题得到彻底有效整改，实现预期目标。

妥否，请批复。

 

莆田市审计局

2011年6月3日
