莆田市审计局关于开展2013年度审计项目质量检查及优秀审计项目评选的通知

发布时间：2014-07-15 00:00 点击数：
| | |

各县（区）审计局、本局各科室（中心）：

为迎接省审计厅对我市的优秀审计项目的考核及检查工作，根据《审计机关审计项目质量检查暂行规定》的规定和福建省审计厅关于印发《福建省优秀审计项目评选办法》的通知（闽审法[2014]57号）的要求，我局决定对各县区审计局、市局业务科室按要求审结归档的2013年度审计项目质量进行检查，并对2013年度全市的优秀审计项目进行初选（原则上县区审计局各初选2个项目、市局业务科室各初选1个项目）。现将有关事项通知如下：

一、审计项目质量检查

在全面了解各县区审计局审计质量控制相关情况的基础上，主要抽检《国家审计准则》执行情况，重点抽取部分审计项目实施详细检查。这次质量检查的内容主要抽查包括：

（一）审计实施方案。主要检查审计项目是否编制审计实施方案，审计实施方案是否重点突出、可操作性强，审计实施方案确定的审计事项是否得到有效落实，有无漏审或者偏离方案实施审计等情况。

（二）审计证据和审计工作底稿。主要检查相关审计事项是否取得必要的书证、询问笔录、电子数据等证据，审计发现的问题特别是重大问题及作出的结论是否有相关的、充分的、可靠的审计证据支持，有无查证不实的问题等。是否编制审计工作底稿，底稿记录是否完整，是否经审计组长审核等情况。

（三）审计报告等结论性文书。主要检查审计报告是否事实清楚，定性准确，引用法律法规适当，处理处罚恰当；审计评价意见是否恰当，审计建议是否切实可行。是否存在应当处理处罚而未处理处罚的问题；是否存在应当移送相关部门处理而未移送处理的问题；是否存在审计报告征求意见稿中反映的重要问题未在正式审计报告反映的情况等。

（四）审计程序。主要检查是否在实施审计3日前送达审计通知书，直接持通知书审计时有无经过本级人民政府批准。审计组的审计报告有无征求被审计对象的意见；审计处罚是否依法履行了听证告知程序。查询被审计单位及有关人员在金融机构的存款账户、封存被审计单位有关资料资产是否依法履行审批手续和遵守法定封存期限的规定等。

二、优秀审计项目初选

全市参选的审计项目应符合以下条件：

（一）2013年度审计机关立项、并已实施完成的审计项目和审计调查项目，且项目实施全过程严格执行审计法律法规和国家审计准则的规定；

（二）审计查出的问题事实清楚、证据确凿、定性准确、处理处罚适当，审计评价客观公正，审计建议切实可行；

（三）审计成果突出，揭露出重大违法违规问题、涉嫌违纪或者犯罪案件线索以及体制机制制度问题；

（四）督促被审计单位和有关单位整改的成效明显；

（五）审计项目审计思路、审计方法具有创新性；

（六）采用AO进行项目管理且参评全省AO应用实例的项目。

三、相关要求

（一）本次审计质量检查工作将抽调各县区审计局负责法制的相关人员各1名，组成检查组。检查组成员在对各自所在单位进行审计质量检查时予以回避。请各县区审计局于7月18日前将负责法制工作的相关人员名单报送给市局法制科。

（二）审计质量检查以现场查阅审计档案为主，必要时可以向审计组组长、主审或有关审计人员了解情况。请各县区审计局予以配合，并准备好相关资料（见附件1）。拟于7月22日开始，具体到县区检查时间另行通知。

（三）各优秀审计项目参选单位应按照《福建省优秀审计项目评选办法》的要求，认真整理项目档案卷宗，并据实填写优秀审计项目推荐表。

 

                                    莆田市审计局

                                    2014年7月15日
