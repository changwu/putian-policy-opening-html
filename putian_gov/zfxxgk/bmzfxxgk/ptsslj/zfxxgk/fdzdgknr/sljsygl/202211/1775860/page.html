莆田市水利局 莆田市发展和改革委员会关于印发“十四五”用水总量和强度双控目标的通知

发布时间：2022-10-28 19:01
| | |

各县（区）水利局、发改局，湄洲岛农林水局、统计局，北岸农业农村局、发改局：

为持续实施水资源消耗总量和强度双控行动，根据《福建省水利厅 福建省发展和改革委员会关于印发“十四五”用水总量和强度双控目标的通知》（闽水资源〔2022〕1号），市水利局商市发展和改革委员会组织制定了各县（区、管委会）“十四五”用水总量和强度双控目标，现印发给你们，请严格贯彻执行。
