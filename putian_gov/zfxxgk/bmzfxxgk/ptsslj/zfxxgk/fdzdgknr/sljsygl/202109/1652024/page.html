关于荔城区中小河流重点县综合整治黄石镇祈境项目区实施方案的批复

发布时间：2015-02-04 14:54
| | |

 

 

荔城区水务局、财政局：

受省水利厅、财政厅委托，市水利局、财政局组织召开中小河流重点县综合整治莆田市荔城区黄石镇祈境项目区实施方案审查会议，参加会议的有荔城区水务局、荔城区财政局等单位领导和邀请专家。会议认真审查了该工程的实施方案报告，在工程的设计标准、水文地质、主要工程措施、生态修复、投资概算、工期等方面取得了基本一致的意见，现批复如下：

一、工程规模和标准

同意项目实施河段总长3.081km（含主河道1.988km、支流1.093km），主要建设任务为水系沟通，河道清淤、清障，堤防加固、新建护岸和沿河岸两侧15m范围内的生态修复和园林景观工程。同意采用10年一遇排涝标准设计。工程等别为Ⅴ等，主次要建筑物级别为5级。

二、水文

基本同意《实施方案》中洪水计算方法及成果。

三、工程地质

基本同意工程地质的评价，对地基岩土的物理力学参数应进行复核。

四、工程设计

1、岸线确定

基本同意河道岸线布置，桩号QJ0+000～QJ1+988段设计河宽按照15m控制。河道左右岸各延伸15m作为两岸绿化带。

2、工程设计

同意水系连通工程布置在QJ0+000～QJ0+348和QJ1+903～QJ1+988。

同意河道桩号QJ0+000～QJ1+555、QJa0+000～QJa0+668、QJb0+000～QJb0+425段进行清淤。

基本同意结合地形地貌条件、区分居民区和耕地区采用不同断面形式对河道进行护岸加固。

桩号QJ0+010～QJ0+269段左右岸、QJ0+630～QJ0+833段左岸和QJ1+090～QJ1+360段左右岸、QJ1+360～QJ1+564段右岸高程3.15m以下采用干砌石挡墙结构，取消桩号QJ0+010～QJ0+269段干砌石护坡设计。高程3.15m处设置水生植物平台，平台以上至4.0m高程采用填筑1:3的自然土坡，表面采用草皮护坡。

同意桩号QJ0+274～QJ0+328段设置干砌石挡墙，要求在挡墙两侧布置人行步道。

桩号QJ0+348～QJ0+630段、桩号QJ0+630～QJ0+833段右岸、桩号QJ0+833～QJ1+090段、QJ1+360～QJ1+564段左岸、QJ1+564～QJ1+988段高程3.65m以下采用干砌石挡墙结构护岸。高程3.65m以上采用填筑自然土坡形式，土坡表面三维网格草皮护坡。

全段干砌石挡墙基础采用C20埋石砼，并用块石夹桩头及松木桩对基础进行加固处理。

基本同意QJ0+000～QJ0+010、QJ0+269～QJ0+274、QJ0+328～QJ0+348、QJ1+933～QJ1+950布置4处净宽3×5m的C30钢筋砼箱涵。基础采用水泥搅拌桩处理。

基本同意子堤结合园林景观进行设计，应做到高低错落有致，利于堤后排水。应适当降低两岸回填土的高度。

基本同意堤后设置排水沟，要求排水沟尺寸为1m×1m，基本同意设置穿堤排水管。

应对挡墙结构稳定和开挖坡等的稳定进一步复核，对1.093km支流清淤应保留现有护岸挡墙基础一定量埋置深度。

3、生态修复及景观工程

同意部分河道两侧各延伸15m范围内设置景观带，将景观工程和河道整治相结合。注重景观节点设置，节点应设置在居民区附近，其他河段应以生态修复为主。

设计单位应进一步优化总平面布置，对细部结构做好设计，并对所栽种的苗木树种进行详细设计，选用本土型、经济适用和管护方便的品种，要求选用荔枝、芒果等其它本土树种，合理搭配其他本土乔木进行绿化。

4、其他工程

同意根据需要拆除桥梁4座，新建人行桥和机耕桥7座。补充桥梁设计主要技术要求。桥梁的外观应和两岸的景观相结合。桥梁的设计，应作好施工图审查。桥梁应和河道整治同步建设。

5、截污设计

同意沿河道左岸桩号W0+000～W2+000和右岸桩号Z0+000～Z0+427、P0+000～P0+770铺设截污管道，对沿线排入河道的污水进行收集，铺设截污管总长3.239km(包括过河倒虹吸管42m)。污水管道布置于挡土墙背侧。同意管材采用波纹管，原设计的管径DN315改为DN500，DN400改为DN600，截污管根据地形及流量分别选用。污水管道的埋设深度应适当加深，截污管管顶绿化植被应多样化，检查井出露高程应高出水生植物平台并隐入绿化带或隐入墙体。

五、施工组织

同意本工程施工工期按8个月控制。严格控制临时工程投资。施工道路的布置及结构应根据同类工程的施工经验结合本工程场地实际进行优化设计。施工道路填筑材料采用单价较低的土石混合料。应进一步落实清淤土方的堆放地点。

六、投资概算

工程项目总概算投资为3578.8万元（不含建设征地拆迁补偿费用3501万元）。资金除申请中央补助外，其余由省级及地方政府配套。

 

专项资金管理严格按照《中小河流治理重点县综合整治项目和资金管理暂行办法》（财建〔2012〕671号）要求执行。

 

 

莆田市水利局        莆田市财政局       

2015年2月4日
