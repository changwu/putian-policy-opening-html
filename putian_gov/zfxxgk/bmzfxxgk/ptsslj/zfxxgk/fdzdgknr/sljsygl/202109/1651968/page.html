关于印发《2016年莆田市涉河安全专项执法检查活动实施方案》的通知

发布时间：2016-03-18 15:41
| | |

 

 

 

各县（区）水务局：

根据《福建省水利厅关于开展全省涉河安全专项执法检查活动的通知》（闽水水政〔2016〕12号）要求，经研究，特制定《2016年莆田市涉河安全专项执法检查活动实施方案》，现印发给你们，请结合实际抓好贯彻落实。

附件：2016年莆田市涉河安全专项执法检查活动实施方案

 

 

莆田市水利局

2016年3月18日

 

抄送：省水利厅水政水资源处

莆田市水利局办公室                2016年3月18日印发

附件

2016年莆田市涉河安全专项执法检查活动实施方案

 

《福建省河道保护管理条例》（以下简称《条例》）已于2016年1月1日起施行，为进一步做好《条例》贯彻落实，切实加大涉河安全执法监督检查力度，维护正常水事秩序，根据《福建省水利厅关于开展涉河安全专项执法检查活动的通知》（闽水水政〔2016〕12号）要求，结合我市实际，经研究，从今年3月初至4月底在全市范围内开展以宣传贯彻《条例》为抓手、以涉河防洪安全为目的、以打击非法采砂为重点的涉河安全专项执法检查活动，为确保此次活动取得实效，特制定本实施方案。

一、检查重点

（一）坚决打击河道采砂违法行为：持续做好与当地公安机关联合执法活动，打击无证和非法采、运砂行为；砂石弃碴未处理，影响防洪，影响观瞻；采砂作业场所未设立公示牌，未载明采砂范围、数量、期限、作业方式、作业时间以及许可证号等，并设置警示标志；有关安全生产责任制、安全措施未到位等。

（二）严厉查处河道管理范围内的违法行为：在河道管理范围内洗砂、制砂以及弃置、倾倒矿渣、石渣、煤灰、泥土、泥浆、垃圾等废弃物；侵占河道水域从事餐饮、娱乐等经营活动；侵占河道规划岸线；修建妨碍行洪的违法建筑物、构筑物以及违章搭建等；

（三）坚决查处破坏水工程的违法行为：破坏、侵占、毁损堤防、水闸、排水渠系等水工程和水文、通信设施以及防汛备用器材、物料；在堤防安全保护区内，从事打井、钻探、爆破、挖筑池塘、采石、取土等危害堤防安全的活动。

二、时间安排

（一）部署动员阶段（3月初）

 各县区水务局及所属水政监察队伍应根据专项执法检查重点，结合“世界水日、中国水周”主题活动，宣传《条例》、营造氛围，结合本辖区实际，细化任务，明确责任，落实分工，有针对性的制定专项执法检查实施方案，于3月20日前报送我局。

（二）各县区水务局专项执法检查（3月中旬至4月中旬）

县区水务局及所属水政监察队伍开展专项执法巡查和现场检查，对检查的河段、项目做好巡查记录。针对检查中存在的问题，要分清情况，认真处理。针对检查中发现的违法行为，要及时下达责令停止违法行为通知书或者限期整改通知书，并做好调查取证及相应的行政处罚工作。同时，可联系相关职能部门开展联合执法检查。

（三）市水利局检查、抽查（4月中旬至4月底）

市水利局及所属水政监察支队组织对各县区专项执法活动检查，重点检查省、市督办案件办理情况，对于检查过程中发现的问题，及时研究整改措施，督促各县区落实到位。

（四）迎接省厅抽查督查（4月底）

省水利厅及省水政监察总队将对市、县（区）专项执法活动进行督查指导，及时发现和纠正存在问题，对重大违法案件采取挂牌督办等方式，加大执法力度，严肃查处。

三、几点要求

（一）提高认识，加强领导。涉河安全专项执法检查活动是进一步加强水利依法管水、依法治水和水生态文明建设的一项重要举措。各水政监察队伍要高度重视，精心组织，抽调力量，根据执法检查重点要求，有针对性的制定切合实际的执法方案，认真组织实施务求实效。

（二）严格执法，坚决查处违法行为，各县区水务局要深入现场实地，认真排查，加大执法巡查力度，强化执法监督，对在专项执法检查活动中发现的违法行为要依法予以查处。对违法社会影响大、案情复杂、危害严重、存在较大阻力的河道采砂案件要按照省厅《关于河道采砂重大违法案件实行省级挂牌督办的通知》（闽水水政〔2015〕1号）要求实行挂牌督办，一查到底，做到依法查处到位、责任追究到位、整改落实到位。

（三）总结经验，及时上报。各县区水务局要加强执法巡查等制度建设，完善与公安、国土资源、交通、海事等其他部门联合执法机制建设，及时总结专项执法活动中好的经验做法，全面提升水行政执法水平。专项行动结束后，4月25日前，各县区水务局要将本辖区内开展的执法检查情况形成书面材料报送市水政监察支队，有关专项执法情况将在全市通报。
