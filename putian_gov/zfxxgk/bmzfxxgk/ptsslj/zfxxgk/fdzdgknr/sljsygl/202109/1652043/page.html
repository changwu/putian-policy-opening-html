关于莆田市胜垦三闸除险加固工程实施方案的批复

发布时间：2014-11-24 16:00
| | |

 

市胜利海堤管理处：

2014年4月17日，市水利局组织召开莆田市胜利海堤三闸除险加固工程实施方案（以下简称实施方案）审查会议。参加会议的有市水利局、市胜利海堤管理处、市水利水电勘测设计院等单位领导、工程技术人员和邀请的专家。会议认真审查了该工程的实施方案，在工程建设必要性、工程规模、标准、设计方案等方面取得了基本一致的意见，同时也提出了一些建议和要求。设计单位根据会议要求进行了修编，形成了“报批稿”。现批复如下：

一、除险加固的必要性

由于胜利海堤三闸目前存在浆砌条石闸底板部分脱浆；闸墩出现裂缝；钢闸门锈蚀严重；闸槽损坏严重；钢筋混凝土启闭梁、人行桥风化脱落，受力钢筋已基本锈蚀殆尽；两台启闭机运行多年，已达到金属设备的报废期限；管理设施落后，不能满足现代水利管理的要求。所以，对胜利海堤三闸进行除险加固及增加部分管理监控设施是非常迫切的。

二、 设计依据

同意采用《防洪标准》（GB50201-94）、《水闸设计规范》（SL265-2001）、《水闸施工规范》（SL27-91）、《水利水电工程等级划分及洪水标准》（SL252-2000）等作为设计的主要依据。

三、工程规模和设计标准

胜利海堤三闸除险加固工程位于胜利海堤的北端，其主要功能为排涝挡潮，设计最大过闸流量为18m3/s。同意水闸设计洪水标准取20年一遇，校核洪水标准采用50年一遇；主要建筑物级别为4级，次要建筑物级别为5级。

四、工程地质

基本同意工程区抗震设防烈度为7度，设计基本地震加速度为0.10g，设计地震分组为第二组；应阐述闸址地质工作情况，补充地质柱状图。对水闸地基岩土层物理力学参数应进一步复核。

五、水文计算

本次水闸除险加固仅涉及闸室部分，同意设计采用闸室上、下游有关特征水位保持不变。

六、除险加固措施

（一）闸门设计

同意水闸2扇平板钢闸门按照原尺寸予以更换，即：闸门分两块拼装；主次梁采用18b槽钢；面板采用Q235，厚度10mm。增加检修闸门1扇。

（二）机电设备

同意选择QL10T手电两用单吊点螺杆式启闭机，配套Y100L2-4型电动机，利用原有380/220V低压输电线路；同意在启闭房内设置1面DJPR-03型动力配电箱、1面PZ30-04型照明配电箱和2面现场操作箱（包括KDY开度仪、行程开关等）。取消20kw柴油发电机组作为备用电源的设计。

（三）启闭房设计

同意拆除重建启闭房；人行桥的栏杆采用花岗岩条石结构；水闸设计要考虑信息化系统及水闸外照明；建筑设计应进一步深化，外观设计及内外墙装饰应美观大方。下阶段，应进一步探明闸室底板运行情况；钢筋混凝土底板、铺盖厚度应不少于50cm，并分别在水闸底板及铺盖的上下游设置高度不少于75cm的齿墙。

七、施工组织设计

基本同意施工组织设计方案；同意施工工期安排3个月；建设单位应在2015年主汛期之前完成主体工程，并保证施工安全。

八、工程概算

报告概算的编制依据、编制办法和定额采用正确。概算总投资55.35万元。资金来源为财政拨款。

九、其他

请你单位加强工程质量监管，做好工程施工组织及现场施工质量、安全管理工作，保证工程质量，确保水闸安全运行；进一步落实管护责任，提高管理水平。
