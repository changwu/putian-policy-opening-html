关于开展2019年“世届水日”“中国水周”宣传活动的通知

发布时间：2019-03-11 16:23
| | |

 

 

各县区水利局（农林水局）、局机关各科室、局属各单位：

根据《福建省水利厅关于组织开展2019年“世界水日”和“中国水周”宣传活动的通知》（闽水函〔2019〕115号）文件要求，经我局研究决定组织开展2019年“世界水日”、“中国水周”宣传活动，现将《莆田市水利局2019年“世界水日”“中国水周”宣传方案》（附件1）和《2019年“世界水日”“中国水周”宣传口号》（附件2）印发给你们，请结合实际认真组织开展好宣传活动。

各县区水行政主管部门、局机关各科室及局属各单位要对本地区、本单位宣传活动及时进行跟踪报道，把宣传活动开展得有声有色、丰富多彩，并于4月15日前把活动情况（含图片资料）报市水政监察支队，联系人：陈建煌、薛煌钦，联系电话：13860911885、18950719680，邮箱：ptszzd@163.com。

附件1：

 

莆田市水利局

2019年“世界水日”“中国水周”宣传方案

 

 今年3月22日是第二十七届“世界水日”，3月22－28日是第三十二届“中国水周”。现将我局宣传活动安排如下：

一、指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻落实十九大精神和十九届二中、三中全会精神，认真落实党中央、国务院、省委、省政府决策部署，坚持“节水优先、空间均衡、系统治理、两手发力”的新时代水利工作方针和水资源、水生态、水环境、水灾害统筹治理的治水方针，全面落实“水利工程补短板、水利行业强监管”的总基调，实施国家节水行动计划有关要求，按照以水定需原则，体现水资源管理“最严格”的要求，打好节约用水攻坚战，不断加大舆论宣传力度，在全社会形成更加浓厚的节水氛围。

二、宣传主题

联合国确定的 2019年“世界水日”宣传主题为“Leaving no one behinb”（不让任何一个人掉队）。我国纪念2019年“世界水日”和“中国水周”活动的宣传主题为“坚持节水优先，强化水资源管理”。

三、宣传方式

1、“保护母亲河，争当河小禹”行动

3月22日，联合市公安局、木兰溪建设处、莆田学院举办“保护母亲河，争当河小禹”活动，拟通过木兰溪警务队挂牌、沿河骑行、环保游园、千人签名倡议、主题海报展示、宣传材料发放等方式，普及水环境保护等知识。

2、水源地保护宣传入镇村活动

3月22日，在莆田市东圳水库库区常太镇举办“水源地保护宣传入镇村活动”，通过张挂横幅、粘贴海报、发放传单、现场宣讲、以案释法等方式，宣传《水法》、《防洪法》、《莆田市东圳库区水环境保护条例》等重要法律法规。

3、户外LED大屏幕公益广告宣传

在城区各主要路口户外LED大屏幕发布水法宣传公益广告。

4、拱门横幅宣传

“世界水日”“中国水周”期间，在莆田学院宣传活动现场和市政府广场、市水利局设置宣传拱门、立柱、横幅；在市政府1号楼LED大屏幕滚动播放水周宣传主题标语。

5、发送公益宣传短信

3月22日通过移动短信平台向全市市民发送“世界水日”宣传公益短信。

6、印发普法宣传材料

制作印发20000份水法宣传单和定制《世界水日、中国水周特刊》2000份，由各县（区）和各有关单位组织宣传。

7、水利网站宣传

通过莆田水利信息网（www.ptsl.gov.cn）发布宣传主题、宣传画、宣传口号，报道全市开展水周纪念活动情况。

8.参加水法律知识竞赛

组织全市水利系统干部参加省水利信息网开设的水法律专题知识竞赛活动。
