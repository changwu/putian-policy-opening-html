关于莆田市阔口渠道荔园路七号下游段河道改道工程实施方案审查意见

发布时间：2014-08-07 15:53
| | |

 

莆田市闽中水处理有限公司：

6月26日，市水利局组织召开莆田市阔口渠荔园路七号桥下游段河道改道实施方案（以下简称“实施方案”）审查会议，参加会议有:市规划局、市木兰溪水利管理处、荔城区水务局、市闽中水处理有限公司及市水利水电勘测设计院等单位的领导、技术人员以及邀请专家。会议认真审查了该工程实施方案，在工程建设的标准、规模、总体布置、施工组织、占地及拆迁、环境影响评价、工程管理、投资估算及资金筹措、经济评价等方面取得了基本一致的意见，同时也提出了一些建议和要求。设计单位根据审查会议要求进行了修编，形成“报批稿”。主要审查意见如下：

一、设计依据及标准

同意根据《防洪标准》（GB50201-94）、《水利水电工程等级划分及洪水标准》（SL252-2000）、福建省水电厅闽水电（1997）水926号颁发的《福建省城市排水排涝设计暂行规定》及《福建省人民政府关于加强城乡基础设施建设的实施意见》（闽政[2013]38号）等有关规定，综合考虑城市发展需要，本工程采用采用30年一遇城区排涝标准。

同意根据《堤防工程设计规范》（GB50286-2013），确定堤防工程级别为3级，临时建筑物级别为5级。

二、水文计算

基本同意改道河段起始水位案玉湖滞洪区调蓄高水位4.63m取值；应考虑橡胶坝建设的影响，复核水面线计算成果。

三、 工程地质

基本同意工程地质评价方法及成果；进一步复核地质参数取值。

四、工程布置及主要建筑物

（一）河道岸线及宽度

基本同意根据安置区及《下黄泵站迁建工程建设项目选址意见书》（选字第350300201407020号）征地红线情况进行平面布置，并确定河道岸线及宽度。应处理好新旧护岸的平顺连接、与安置区征地红线的交叉关系。

（二）护岸工程

1、堤顶、岸顶高程确定

基本同意根据《堤防工程设计规范》（GB50286-2013）和两岸绿化、右岸安置区地坪标高及平面布置等因素确定河道的堤顶、岸顶高程。

2、左岸护岸结构设计

基本同意护岸采用斜坡式与重力式挡墙相结合的断面形式。挡墙迎水坡坡度1：0.1，背水坡坡度1:0.3，墙顶采用C20砼压顶，宽度0.6m，墙顶高程3.5m；基础采用0.5m厚C20砼埋块石（埋石率20%），墙趾、墙踵宽度均为0.5m；同意采用水泥搅拌桩进行地基处理，桩径0.6m，桩长8m，正方形布置，桩距1.0m。

同意岸顶设花岗岩栏杆。

新旧连接段水平方向应平顺、垂直方向应采用渐变过渡，并满足水力条件。

原护岸压顶石后面种植篱笆及爬藤类植物。

生态砌块护坡改为草皮护坡，坡度1:2，在坡脚位置采用干摆块石，顶面高程按3.8m控制；在岸顶及护坡脚种植爬藤类植物，在护坡中间应铺设草皮及种植一定数量的花木；岸顶C20砼镶嵌小卵石路面改为铺设彩色透水砖。

3、右岸护岸结构设计

基本同意采用两级挡墙形式，在高程3.5m处设置种植爬藤类水生植物平台，宽度3.0m。平台以下挡墙迎水坡坡度1：0.1，背水坡坡度1:0.3，墙顶采用C20砼压顶，宽度0.6m，墙顶高程3.5m；基础采用0.5m厚C20砼埋块石（埋石率20%），墙趾、墙踵宽度均为0.5m，下设0.4m厚的块石夹桩头；采用松木桩进行地基处理，桩径0.1m，桩长4m，梅花形布置，桩距0.6m。基本同意二级挡墙基础采用0.5m厚C20砼埋块石（埋石率20%），墙趾、墙踵宽度均为0.5m；同意采用水泥搅拌桩进行地基处理，桩径0.6m，桩长10m，正方形布置，桩距1.0m。

新旧连接段水平方向应平顺、垂直方向应采用渐变过渡，并满足水力条件。

平台以上二级挡墙墙顶高程除了桩号K0+066～K０+089段可采用7.5m外，其它桩号改为6.00m,且应做好新旧连接段的渐变过渡；岸顶花箱改为种植篱笆及爬藤类植物。

原护岸压顶石后面种植篱笆及爬藤类植物；全长铺设宽度为2.0m的彩色透水砖人行步道

（三）景观绿化

绿化及生态设计须有详细的设计图纸。

（四）阔口水闸迁建

原则同意在桩号K0+034设置橡胶坝。橡胶坝顶高程由4.2m改为4.80m，两侧的挡墙顶面高程应高出橡胶坝顶0.3m；进一步细化橡胶坝的结构设计。

五、施工组织设计

基本同意施工组织方案设计。应细化进度安排，补充施工进度横道图及总平面图；进一步完善右岸两级挡墙的施工顺序及方法。

基本同意建设工期为4个月。

六、占地及拆迁

基本同意设计单位根据现行补偿标准提出的占地及拆迁补偿估算方案。

七、工程建设与管理

建设单位应按照规划部门要求，做好河道治理与城市路网、土地利用、用地竖向等相关规划的衔接，做好工程沿线附属管线等设施的专业处理。要全力以赴推进工程进展，确保按照规定时序完成建设。工程建成后应及时移交管理部门。

八、环境影响

基本同意设计单位对环境影响的评价结论及所采取的应对措施。

九、工程概算及资金筹措

实施方案概算的编制依据、编制办法和采用定额、标准基本可行。概算总投资472.82万元，其中建安投资400.98万元，征地拆迁费用43.60万元，专项费用8.19万元，基本预备费20.05万元。资金来源为建设单位自筹。
