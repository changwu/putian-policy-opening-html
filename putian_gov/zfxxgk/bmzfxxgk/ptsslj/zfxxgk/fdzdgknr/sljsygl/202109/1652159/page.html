关于下达2019年度省、市政府工作主要任务公工的通知

发布时间：2019-04-22 09:57
| | |

 

局机关各科室、局属各单位：

根据莆田市政府办公室《关于印发2019年市政府、省政府工作主要任务分工方案的通知》（莆政办明电[2019]3、4号）等文件要求。为确保年度工作任务保质保量按时完成，现将各项任务分解落实到各有关责任科室（第一个为牵头科室），请对照工作目标，强化责任、各负其责、请各科室指定专人负责工作进展情况的收集与汇总。具体通知如下：

1.自3月份起，省、市政府主要工作任务相关进展情况实行月报告制度，由各责任科室与牵头单位主动对接，并于每月28日前按要求报送牵头单位同时报局办公室（效能办）备案。

2.由我局牵头的省、市政府主要工作任务共23项，其中列入省政府主要工作的有6项，列入市政府主要工作的有17项，由责任科室汇总各单位情况后原则上于每月28日前报办公室汇总，以便统一报送市府办联系业务科室（以附件格式通过OA上报，同时抄送市政府督查室）。

3.市效能办将各责任单位落实情况列入“行动计划”一季度一督查，督查情况将列入市直有关单位年度绩效考评。请各科室认真负责，协调配合抓好落实

具体任务分解见各附件。

 

附件：1、省政府主要工作任务分解立项内容安排（摘要）；

2、市政府主要工作任务分解立项内容安排（摘要）；

3、市水利局牵头的省政府主要任务分解落实情况表；

4、市水利局牵头的市政府主要任务分解落实情况表；

5、省、市政府第X项主要任务落实情况进度表（1-月份）。
