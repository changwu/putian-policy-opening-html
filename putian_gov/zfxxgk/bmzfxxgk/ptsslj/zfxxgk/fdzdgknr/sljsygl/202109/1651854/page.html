关于开展2016年度水利工作责任目标执行情况考核的通知

发布时间：2017-03-01 15:19
| | |

　　各县（区）水务局、北岸农林局、湄洲岛农林水局：

　　为检验各地落实年度水利责任目标情况，更好地总结经验，发现典型，表彰先进，推动工作，经研究，拟于2017年3月下旬在全市范围内开展2016年度水利工作责任目标执行情况考核工作。现将有关事项通知如下：

　　一、考核内容

　　依据《关于下达2016年度水利工作责任目标的通知》（莆市水利〔2016〕83号）精神，考核内容包括:水利投资、农村饮水安全和农田水利工程建设、安全生态水系建设、病险水库海堤除险加固、水利重点骨干工程建设、水资源管理和水土流失综合治理、农村水电增效扩容改造、山洪灾害防治和防灾减灾工作、水利科技推广示范基地建设、安全生产和党风廉政建设等主要任务完成情况。

　　二、考核方式

　　考核采取各地自评、市水利局领导、机关各业务科和推进组测评的方式进行。市局建设管理科汇总考核情况后，提交局党组会议研究，确定考评结果。

　　（一）各县（区、管委会）水务局自评。依据本地区2016年度水利工作责任目标，对照2016年度水利工作责任目标考核评分参考标准，逐项开展自检自评。

　　（二）市局领导、局机关业务科和推进组测评。市局领导和各业务科根据一年来各县（区、管委会）完成目标任务情况和平时下基层检查掌握的情况对每个县（区、管委会）各项任务指标进行测评；各推进组根据平时掌握的情况进行测评。

　　（三）市局建设管理科汇总考核情况。市局建设管理科根据各县（区、管委会）得分情况，进行汇总排序，形成考核意见提交市局党组会议研究。

　　三、评分比例

　　评分采取总分100制。其中各县（区、管委会）自评得分占总分20%，市局机关各业务科室评分占总分40%，市局领导评分占总分30%，各个推进组测评占总分10%。四项相加总分为该单位总评得分。

　　四、工作要求

　　（一）各地要严格对照本地区2016年水利工作责任目标，认真进行工作总结，认真开展自检自评，做到不隐瞒、不造假，如实反映工作亮点和问题，保证自评得分真实有效。各县（区、管委会）水务局自评报告和自评得分表请于2017年3月10日上午下班前报市水利局建管科。（联系人：黄骁男，电话：2692512，传真：2281771，邮箱：ptslgh@163.com）

　　（二）各业务科室评分和各个推进组测评要根据各地实际情况，坚持公平公正，确保评分客观真实。

　　附件1

　　2016年度水利工作

　　责任目标考核评分参考标准

　　市水利局对各县（区、管委会）2015年度水利工作责任目标考核以百分制为计。

　　一、水利投入（26%）

　　1、完成2016年度水利资金投入责任目标，占16%；

　　2、地方配套资金占年度水利资金投入总量比例，占5%；

　　3 、2016年度水利资金投入比2014年度增长率，占5%。

　　二、定量指标（42%）

　　1、农村饮水安全工程建设投资完成率占3%，解决农村饮水不安全人口任务完成率占3%；

　　2、海堤强化加固完工项目数占3%，投资完成率2%；

　　3、病险水库除险加固项目完工率占5%；

　　4、水利重点骨干工程投资完成率占7%；

　　5、安全生态水系项目建设投资完成率占6%；

　　6、发展节水灌溉面积占3%；

　　7、水土流失治理任务完成率占4%，省级重点县水土流失治理项目完工率占3%，省级重点乡（镇）的水土流失治理项目完工率占3%。

　　三、定性指标（28%）

　　1、落实最严格水资源管理制度设占4%；水资源地保护和水生态修复保护工程建设占2%；

　　2、农田水利工程建设占4%，基层水利服务机构建设3%；

　　3、山洪灾害防治和防灾减灾应急管理占4%；

　　4、水利科技建设占2%；

　　5、安全生产占4%；

　　6、党风廉政建设占5%。

　　第1-5项定性指标重点围绕工作进度、工作进步、工作创新以及经验、做法在全省、全市领先情况进行考核。第6项定性指标重点围绕安全生产事故、安全信息系统建设及应用、生产标准化建设3年提升行动、日常安全生产工作情况进行考核。第1-5项指标中成效明显的4-3分，成效较好的3-2分，成效一般的1分以下。第6项指标中，成效明显的5-4分，成效较好的4-3分，成效一般的2分以下。

　　四、表彰项目（2%）

　　受表彰对象为县区级水利部门，表彰范围包含综合表彰或单项表彰，获省部级以上表彰的，1项得1.5分，获市厅级表彰的，1项得1分，获县区效能考核前三名及民主评议行风政风前三名的得1分，获县处级表彰的，1项得0.5分。总得分不得超过2分。提供表彰复印件报市局办公室，以供核实参考。未受表彰的不得分。

　　五、扣分项目（2%）

　　未完成中央投资计划面上项目80%、“172”项目90%的扣1分；存在拖欠农民工工资等违反上级规定问题的扣1分。

　　备注：以上考核指标有的地区没有，可增加本考核大指标中其他指标的权重。如，定量指标中7个细化指标，有的地区一些指标没有考核任务，可增加其他定量指标的考核权重。
