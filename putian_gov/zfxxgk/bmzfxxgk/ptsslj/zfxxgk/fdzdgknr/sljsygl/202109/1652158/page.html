关于下达美丽莆田2019年专项行动计划任务分工的通知

发布时间：2019-04-22 09:55
| | |

 

 

各县（区）水利局，市水务集团，局直属单位，局机关各科室：

根据中共莆田市委办公室和莆田市人民政府办公室关于下达建设美丽莆田2019年行动计划通知要求。与我局有关的有30个重大攻坚项目中的“木兰溪全流域系统治理项目”、20项重点工作里的“木兰溪全流域系统治理现场推进会”以及绿色产业（一产）、生态文明、基础设施等3个专项行动，由我局牵头推进项目上报进度的有20项重点工作里的“木兰溪全流域系统治理现场推进会”、以及绿色产业（一产）、基础设施等2个专项行动。由我局跟踪推进项目情况的有30个重大攻坚项目中的“木兰溪全流域系统治理项目”以及生态文明专项行动。为确保年度工作任务保质保量按时完成，现将各项任务分解落实到各县区及局各有关科室，请各单位对照目标任务，各负其责、抓好落实，做好项目服务、推进和部门协调配合工作，相关工作的进展情况直接按要求报送牵头部门。同时局相关科室要指定专人负责工作进展情况的收集与汇总，绿色产业（一产）、基础设施2个专项行动计划的重点项目进展情况按照时限要求报送局项目办汇总。具体任务分解详见附件。

莆田市水利局

2019年4月22日

 

 

 

 

 

                                                             

  抄送：市美丽办，局领导                                     

  莆田市水利局办公室                     2019年4月22日印发    


1、建设美丽莆田2019年行动计划（摘要）

 

为深入贯彻习近平总书记木兰溪治理的重要理念，以及省第十次党代会提出的“机制活、产业优、百姓富、生态美”的新福建要求，全力推进高质量发展落实赶超，努力为建设美丽中国提供生动范本，制定本行动计划。

一、行动目标

紧紧围绕美丽莆田建设，努力提升“五品牌、九行动” 各项工作水平，深入开展“聚焦项目比质量、争先进位比赶超”活动，打好三大攻坚战，全面实施乡村振兴战略，加快扫黑除恶专项斗争向纵深推进，在新的起点上创建美丽中国的示范区。

今年我市的总目标是实现争先进位。具体目标是：全市地区生产总值增长9％左右，规模以上工业增加值增长9％，一般公共预算总收入増长8％、地方一般公共预算总收入增长5％，固定资产投资增长13％，外贸出口总额持平，实际利用外资增长6.5％，社会消费品零售总额增长12％，居民消费价格总水平涨幅3％左右，城镇登记失业率控制在3％以内，城乡居民人均可支配收入增长9.5％，农村居民人均可支配收入增长9％左右

二、行动任务

各级各单位要进一步深化五大品牌，全力推进九个行动，重点抓好30个重大攻坚项目、20项重点工作，推动美丽莆田建设落到实处。

(一）打造国际品牌

妈祖文化品牌：站位国家层面，围绕一带一路、对台交 流、海洋文明和海洋经济。重点发展海洋牧场和海洋捕捞产业，做大做强海洋生物工程，打造海产品集散中心。办好第四届妈祖文化论坛，把妈祖文化和现代文明、经济发展结合起来，创建智慧海洋、国家级妈祖文化生态保护实验区、世界妈祖文化中心。  

深水良港品牌：围绕建成东南沿海大宗散货交易中心，重点推进罗屿40万吨铁矿石码头及航道建设，大力发展港口物流等配套产业，完善海关监管、保税等功能。真正实现港口“大进大出”，力争今年吞吐量翻番。

工艺美术品牌：发挥传统产业优勢，推进大工美、金银谷、仙作供应链等平合，加快转型升级步伐，建设“全球最高端、业态最完整、配套最齐全”的金银珠宝第一镇，将仙作打造成为全球工艺美术产业第一品牌。

绿色食品品牌：做大做强高质量绿色食品产业集群，重点在一二三产融合发展上下功夫，提升整体效益。以产品深加工、捕捞、特色现代农业品牌为重点，打造雪津食品产业园和兴化湾南岸食品产业园。

医疗健康品牌：立足搭平合、建高端、创品牌，加快妈祖国际健康城、药械网等平合建设，引进落地一批高端专科医院，并依托莆田健康企业总会，规范行业管理，打响国际品牌。

(二）抓好专项行动

绿色产业（一产）行动：引进大型投资集团，加快发展 海洋渔业，围绕建设现代特色农业，在木兰溪全流域系统治理 中，建设一批乡村振兴示范点，做大做强农业规模和质量，促进农村一二三产业融合发展。

绿色产业（二产）行动：积极推动实体经济发展，重点推动合力泰、华佳彩二期、乙烷裂解制乙烯、哈纳斯等项目年内尽快开工，加快永荣CPL、HDT高效太阳能电池、元生智汇、创世纪超算中心、三棵树涂料、华峰系列、上海电气等项目建设，尽快投产达产、释放产能；推动雪津、佳通、国投、中海油加大投资步伐。加大招商引资力度，争取多抱几个“金娃娃”。    

绿色产业（三产）行动：聚集平合经济，重点推进众协联、智慧能源、普天药械网、仙作供应链、大工美之家等11个重点平台，力争实现平台交易额突破1000亿元，销售额突破200亿元；实现服务业新增“下转上”企业600家，促进外贸出口总额和实际利用外资大幅增长。

全域旅游行动：围绕冲刺今年第四届世界妈祖文化论坛，在原有基础上再策划精品线路。以乡村振兴为契机，打造一批示范村、文化古街、美食街。发挥佛教论坛后效应，利用会展中心、妈祖文化论坛永久会址等场所，推动会展业和旅游业结合。把莆田建设成为世界妈祖文化旅游目的地和国内极具吸引力的滨海生态度假胜地。

开放创新行动：加快营造一流营商环境，推动重点领域和关键环节改革取得明显突破，打造一批创全省全国的行政审批、政务服务、市场主体的示范窗口和典型基地。

生态文明行动：坚持木兰溪全流域系统治理是今年工作的重中之重，围绕“四水”统筹治理，加快实施城乡供水及污水处理一体化、河库连通及水系治理等十大工程，重点攻坚木兰溪水质，力争上半年有较大提升。

城乡建设行动：以莆阳新城、木兰片区和高铁片区等三大片区为今年提升年行动的重点工作，结合创建国家历史文化名城，抓紧实施一批启动项目，推动实现连片发展。

基础设施行动：进一步提升“一区三网”建设水平，以建成东南沿海大宗散货交易中心为目标，开工建设城际铁路F2线一期工程，重点推进新建福厦铁路（莆田段）、联十一线、纵三线、联二线涵江段、木兰大道三期等项目，加快建成安全高效、智能绿色、互联互通的现代基础设施体系。

民生改善行动：建立稳定脱贫长效机制，消除绝对贫困；抓好学校布局规划，新增幼儿学位4500个、中小学学位3000个；推进全市常住人口千人均床位数达到5.85张，全市人均体育场地面积达到1.9平方米，常住人口基本养老保险参保率超过95％。

文化繁荣行动：围绕创建国家级公共文化服务体系示范区、国家历史文化名城，打造世界妈祖文化中心，实施文化强市战略，重点是实施文化产业提升工程，保护一批历史文化名街、名村。

社会治理行动：继续组织实施全域平安创建、社会和谐建设、基层治理提升“三大工程”，实现全市社会治理“社会化、法治化、智能化、专业化”水平“五提升一加快”的高质量赶超。 

三、行动要求

坚持一切围绕项目干、一切围绕项目转，动员全市上下把时间和精力集中到项目建设上来。

一要对标一流。各级各部门要进一步理清思路、拉高标杆，站位全省全国，以大格局、大手笔来谋划推进“五品牌、九行动”。要对标一流，找定位、找标杆、找差距，在“双比”活动中比出动力、比出质量、比出水平，营造比学赶超的浓厚氛围。各县区（管委会）要注重比看全年和任期内在全省位次有没有提升，市直单位要注重比看其牵头负责和配合落实的指标有没有完成。要坚持一月一例会，一季度一分析，做好定期分析研判，及时跟踪落实，努力实现争先进位。

二要创新机制。要在创新机制方面多想新办法、新招数，做到用制度来说话，用机制推动项目，用实绩来检验活动成效。创新项目推进机制，实行清单化管理、常态化推进。市委和市政府决定定期召开推进会，通过“路演模式”，抓落实、促成效。建立典型示范机制，力争每个品牌、每个行动都能出一批好的先进典型。完善督查考评机制，把“双比”活动与五个一批、美丽莆田等考评统筹起来，并运用考评结果，作为年度绩效考评、评先评优和干部使用的重要依据，形成能者上、庸者下的用人导向。

三要齐心协力。美丽莆田建设能否取得实效，“双比”活动能否比出水平，关键在干部。全市要坚持一盘棋、上下一条心。各挂钩县区（管委会）四套班子领导，每月必须集中到基层召开协调问题现场会；各指挥长要带头亲力亲为，多深入挂钩县区（管委会）现场办公，多一线协调解决问题、推动工作落实；指挥部办公室要配强力量、加强统筹。各县区（管委会）要严格落实属地责任，抓紧制定实施方案。市直有关部门要强化服务意识，多想办法、靠前服务。市人大、政协要组织开展视察调研、专题协商等，积极建言献策。组织部门要及时介入，加强一线考察。纪检监察部门要全程跟踪、监督到位。宣传部门要及时跟踪报道最新进展，为建设美丽莆田营造浓厚的舆论氛围。

 

 

 

 

 

 

 

 

 

建设美丽莆田·绿色产业（一产）
2019年专项行动计划（摘要）

 

为推动乡村振兴战略实施，推进农业供给侧结构性改革，促进农村一二三产业融合发展，构建绿色现代农业体系，制定2019年专项行动计划。

一、行动目标

紧紧围绕水利建设主要建设内容，共细化实施53个重点项目，计划总投资121.869亿元，年度计划投资27.521亿元。预期目标达到第一产业增加值比增3%；农村居民人均可支配收入增长9%左右；农林牧渔总产值增长率实现争先进位。其中细化实施17个水利重点项目，计划总投资106.09亿元，年度计划投资19.505亿元。

二、任务支撑

实施农田水利建设。重点推进乌溪水库、西音水库、莆田木兰溪防洪工程仙游段、华亭白塘段、宁海闸及配套工程、秀屿区河道综合整治（一期）工程等项目建设。

牵头单位：市水利局

配合单位：有关县(区)政府（管委会）

责任科室：建设站、管理站、木兰溪防洪工程建设管理处、市水务集团

三、保障措施

（一）加强组织形成合力。牵头单位定期召开项目推进会，加强工程进度及质量安全管控，开设绿色通道，加快或简化项目审批流程，确保项目按序时完成。

（二）加大宣传营造氛围。利用各种新闻媒体，切实对行动计划中各项惠农政策、项目成效的典型宣传，引导社会各界参与、支持与监督行动计划的实施。

（三）强化考评推动落实。加强目标管理考核，优化考核指标体系。实施“月通报、季督查”，推动各项目标任务、政策落实。

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

建设美丽莆田·生态文明2019年

专项行动计划（摘要）

 

为持续融入国家生态文明试验区建设，打好污染防治攻坚战，坚持绿水青山就是金山银山的理念，打造人与自然和谐共生的美丽莆田，制定2019年专项行动计划。

一、行动目标

加快改善生态环境质量，水、大气等主要生态指标在全省争先进位。一是巩固提升水环境质量，木兰溪、萩芦溪干流Ⅰ－Ш类水质比例均达到100%，省控小流域Ⅰ－Ш类水质比例达到或优于95%，县级及以上集中式饮用水水源地水质功能达标率达100%。二是持续提升空气质量，臭氧浓度升高趋势得到有效控制，城市空气质量优良天数比例达到近三年达标率的平均水平，森林覆盖率稳定在60%左右。三是城乡环保设施加快完善，工业固体废物综合利用能力和医疗废物处置能力持续提升，企业控排措施进一步加强，固体废物资源得到有效循环利用，危险废物处置利用率达96%以上，医疗废物集中处置率达100%。四是生态文明制度更加完善，使木兰溪样本成为新时代生态文明建设的新标杆。

二、任务支撑

生态文明行动共生成相关项目46个，总投资额661.3亿元，年度计划投资133.4亿元。其中涉及水利项目23个，年度计划投资26.86亿元。

（一）深化木兰溪综合治理

3.综合治理工程。修复提升沿溪水生态环境，重点推进木兰溪干流防洪、综合整治及生态景观配套工程、主要支流及南北洋

水系整治。

牵头单位：市水利局

配合单位：有关县(区)政府（管委会）

责任科室：建管科、管理站、木兰溪防洪工程建设管理处、木兰溪水利管理处、市水务集团

4. 绿心塑造工程。确定绿心启动区的具体范围和工作任务，实施整体改造提升工程，推进绿心的功能植入、设施完善、水系整治、景观提升等工作。

牵头单位：市水利局

配合单位：有关县(区)政府（管委会）

责任科室：建管科、管理站

5.湖泊提升工程。重点实施玉湖、白塘湖、东阳湖、南湖、

木兰湖等五大湖群生态保护示范工程，提升调蓄洪水、涵养水源、

净化环境功能。

牵头单位：市水利局

配合单位：有关县(区)政府（管委会）

责任科室：管理站、建管科、水政科

（六）推进生态文明机制创新

1.加强河湖管护。全面推行河湖长制，创新管河治河机制，

推进全城水环境提升改善。

牵头单位：市河长办

配合单位：市水利局、市生态环境局、市自然资源局、市住建局、城市管理和综合执法局、各县(区)政府（管委会）

责任科室：河务中心

三、保障措施

（一）强化组织领导。完善协调推进工作机制，建立主要任务和重大项目工作台账，实行清单化、项目化管理，做到一个工程、一套方案、一抓到底。

（二）强化机制创新。采取PPP+EPC建设模式，寻求与金融机构和社会资本开展融资合作。推进以木兰溪流域为试点，开展自然资源资产核算。

（三）强化要素保障。进一步优化营商环境，全面盘活存量闲置土地，加快项目用地用林报批等前期手续。积极争取中央和省级预算内资金支持，带动一批环保领域工程包建设。

（四）强化总结推广。加强对重点任务落实情况的跟踪分析、督促检查和效果评估，必要时委托第三方机构进行独立评估。对试行有效的重大举措和成功经验做法，及时总结推广。

 

 

 

 

 

 

 

 

 

 

 

 

建设美丽莆田·基础设施2019年专项行动计划

 

为加快建成安全高效、智能绿色、互联互通的现代基础设施体系，完善基础设施建设和服务、提升“一区三网”建设水平，制定2019年专项行动计划。

一、行动目标

本专项行动共安排基础设施项目81个、总投资958亿元，年度计划投资90.2亿元。力争全市交通运输系统计划投资300亿元，增幅20%以上。

二、任务支撑

（六）完善全市供水“一张网” 

完善防洪（潮）减灾工程体系，推进木兰溪防洪工程华亭白塘段、仙游段、涵江临港产业园防洪排涝工程建设;推进第三水厂、东圳水库枢纽引水配套、湄洲岛世界妈祖文化中心供水保障等一批引调水工程。

牵头单位：市水利局

责任单位：各县（区）人民政府（管委会）

责任科室：管理站、建设站、木兰溪防洪工程建设管理处、市水务集团

三、保障措施

（一）强化前期推进。完善“同步审批、限时办结、信息共享”的项目并联审查审批机制。审批环节统一压缩至“受理、审核、决定”3个环节。

（二）强化要素保障。创新项目投融资体制，争取更多支持政策。强化项目用地、用林、用海等要素保障，建立“及时发现问题、及时报告问题、及时协调问题”的工作推进机制。

（三）强化协调落实。加大前期工作和在建项目推进力度，分门别类制定针对性措施，及时解决困难和问题。强化地方政府征迁、安置、民事纠纷协调主体责任，继续推行“无障碍施工”，落实和谐征迁。

（四）强化比学赶超。加强“三比三晒”，“比前期，晒开工”、“比推进，晒完工”、“比服务，晒成效”，做到目标、重点、措施、进度、责任“五明确”。加强工地党建，实现工地建设和工地党建双促进、双丰收。
