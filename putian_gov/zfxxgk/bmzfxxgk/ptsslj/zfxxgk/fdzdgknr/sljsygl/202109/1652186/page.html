关于开展河湖“清四乱”专项行动督导工作的通知

发布时间：2020-05-07 11:49
| | |

各县（区）水利局、湄洲岛农林水局、北岸农林局，局属单位：

为贯彻落实《福建省水利厅福建省河长制办公室关于进一步推进河湖“清四乱”工作的通知》（闽水函〔2020〕174号）的文件要求，我局拟于5月份派出6个督导组，分赴各县（区、管委会）督促指导开展河湖“清四乱”专项行动工作，现将有关事项通知如下：

　　一、时间安排

　　河湖“清四乱”专项行动督导时间为2020年5月份至12月份，具体时间和行程由各小组自行安排。

　　二、督导内容

（一）针对流域面积50平方公里以上河流、水面面积0.1平方公里以上湖泊全流域的“清四乱”专项行动实施情况开展全面督导，促进专项行动有序有效推进，并对各县（区、管委会）上报的问题清单及整改成果进行全面核查（附件1和附件2），重点核查漏查漏报、清理整治不到位、整治后出现反弹等问题。

（二）督促指导各县（区、管委会）开展2018年以来的涉河审批项目回头看工作，并对问题整治情况进行核实检查（附件1和附件3），确保做到闭环管理。

　　三、督导方式

　　市水利局督导组采取深入现场、听取汇报、查阅资料等方式开展督导工作，每个县（区、管委会）以不低于30%比例进行核查抽查，对核查时仍存在的涉河湖问题，坚决督促整治到位。对整治不力的，按照“五个一批”的要求，坚决督促加快整改进度，责令限期完成。

　　四、分组情况

　　涵江区：张章模、吴建洪、叶为人、佘振东;

    北岸、湄洲岛：王二虎、颜文喜、陈阳珊、林腾飞；

    城厢区：陈东风、张福泉、陈叶昉、郑清;

    仙游县：王萍、许智强、王宝喜、郑志涵;

    秀屿区：陈萍、吴荔三、邹圣侠、卓慧晶;

    荔城区：蔡开国、陈景锋、蔡风飞、陈建洪。

　　五、有关要求

（一）各县（区、管委会）水利局（农林水局、农林局）要高度重视、周密安排、精心组织，全面开展河湖“清四乱”专项行动。对发现的问题要及时建立问题隐患和整改销号台账，明确整改时限和要求、责任单位和责任人，如时限内无法整改到位的，必须落实整改方案，确保整改工作有序落实到位。

（二）局属各单位要及时对接县（区、管委会）水利局（农林水局、农林局），密切跟踪整改落实情况，加强行业指导督促，确保整改工作落实到位。各督导组要将督导工作开展情况、各县（区、管委会）专项行动推进情况、存在的问题以及工作建议形成督导情况报告于6月份起至12月份止每月15日前报送市水利局水政监察支队。
