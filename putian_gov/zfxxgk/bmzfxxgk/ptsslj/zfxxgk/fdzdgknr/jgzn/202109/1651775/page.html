关于印发《2020年莆田市水利局防汛工作领导小组及岗位职责》的通知

发布时间：2020-05-25 08:25
| | |

局机关各科室：

经研究，现将《2020年莆田市水利局防汛工作领导小组及岗位职责》印发给你们，请认真贯彻执行。

 

 

 

莆田市水利局         

2020年5月25日        

 

 

 

 

2020年莆田市水利局防汛工作领导小组

及工作岗位职责

 

根据省市防汛抗旱工作视频会议精神，自5月1日起，各级防汛办设在应急部门，由应急、水利两部门相关工作人员组成，实行合署办公。防汛工作事关人民群众生命财产安全，是水利工作的重要内容和重大职责，市水利局干部职工务必全员参与、全程参与。为进一步明确责任，实现无缝对接，有序开展防汛抢险救灾工作，经研究，成立2020年莆田市水利局防汛工作领导小组，现将领导小组及岗位职责分工如下：

一、成立领导小组

组  长：黄德元

    常务副组长：陈东风

副组长：蔡开国、王二虎、王萍、陈萍、张章模

成  员：郑志洪、陈国宁、颜文喜、蔡风飞、黄斌锋、吴建洪、许智强、林荔三、张福泉、陈景锋

工作领导小组下设6大工作组，水旱灾害防御科负责日常工作的组织协调。

二、成立工作组

（一）综合协调组

组  长：陈东风

副组长：张福泉、黄金鹏

成  员：郭加跃、林建平、蔡宗迎、包艳丽、林荔颖

    工作职责：

1.综合协调并贯彻下达执行市委市政府和市防汛抗旱指挥部相关决定、指令；

    2.负责市水利局领导防汛防台风工作汇报、部署等及提供市领导汇报、工作部署中有关水利内容材料等；

3.按照上级有关规定收集上报水利灾情，主要包括灾害发生时间、地点、类型、影响范围以及损失等情况。

4.负责应急视频会商指挥系统（以下简称“视频系统”）日常检测工作，并定期对全市7个县（区、管委会）视频终端进行检测；

5.负责视频系统维护、调试等，保障视频会议正常使用；

6.负责市级管理的洪水预警报站点的运行、管理和维护工作，保障洪水预警报系统正常运行；

7.负责防汛物资维护保养，定期质检，进出库登记造册等。

（二）防汛调度组

组  长：张章模

副组长：陈国宁、黄金鹏、张福泉

成  员：郑国海、卓燕青、吴俊伟、陈阳珊、陈叶昉

工作职责：

1.主动掌握全市水情、雨情、工情、灾情和险情；

2.根据需要参与各类防汛防台风会商会议；

3.为防汛防台风决策指挥提供技术咨询；

4.贯彻执行市防汛抗旱指挥部调度指令。

（三）工程抢险组

组  长：蔡开国

副组长：蔡风飞、颜文喜、吴建洪、苏雷

成  员：姚建友、刘世军、黄金志、黄骁男、佘振东、陈书东

1.主动掌握全市水情、雨情、工情、灾情和险情；

2.根据需要参与各类防汛防台风会商会议；

3.督促指导水利各类灾情、险情评估；

4.督促指导水利灾情、险情处置实施方案；

5.为水利工程现场抢险救灾提供技术指导。

（四）后勤保障组

组  长：王二虎

副组长：郑志洪

成  员：郑第腾龙、黄秦煌、林瑞金、梁玉萍

工作职责：

在市防汛指挥部启动防暴雨洪水台风Ⅲ级应急响应及以上响应时：

1.配合上级水利部门防汛防台风督查组人员食宿安排；

2.配合安排参加防汛的工作人员用餐；

3.负责局本部、防汛指挥部会议室、会商室卫生保洁和视频会议的茶水供应；

4.负责水利工程现场抢险和督查用车的调度；

5.负责抽调局直属单位工作人员到市防汛办开展电话督查。

（五）宣传报道组

组  长：王萍

副组长：许智强、刘世军

成  员：林国富、郭加跃、陈顺妹、郑志涵

（二）工作职责

1.配合市防指起草市委市政府主要领导防汛防台风工作部署、市长在电视台发表讲话材料、防御台风暴雨洪水期间防汛防台风阶段性总结材料和防汛防台风专题片文字稿等；

2.配合市防指起草市委市政府主要领导防汛防台风工作向上级汇报材料、市防汛指挥长防汛防台风工作部署材料和常规防汛防台风总结材料等； 

3.配合市委宣传部做好防汛防台风新闻宣传报道工作；

4.配合做好市委市政府、市防汛指挥部的防暴雨洪水台风部署和领导指示报道，及时上传莆田市水利信息网，编发《水利汛情快报》、防汛简报等。

六、效能督查组

组  长：陈萍

副组长：邓万福、林泰、苏雷、陈景锋

成  员：卓慧晶、邹圣侠、郭志煌、佘雪钦、林国辉、陈建洪

工作职责：

1.配合省防汛指挥部、省水利厅、市应急局等防汛防台风督查组检查；

2.协助市效能办、应急局开展防汛防台风责任制和抢险救灾调度指令执行情况督查；

3.负责对市直各水管单位防汛值班、履职等情况进行督查，督促指导南北洋河道围堰清除及预案执行，根据领导的要求将督查情况向市防汛指挥部书面报告。
