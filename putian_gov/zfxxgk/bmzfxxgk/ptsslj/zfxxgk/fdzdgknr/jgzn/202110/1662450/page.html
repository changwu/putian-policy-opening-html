关于莆田市2021年1-8月份水利项目建设与投资完成情况的通知

发布时间：2021-09-18 15:50
| | |

各县（区）水利局、湄洲岛农林水局、北岸农业农村局，市水务集团，局属有关单位：

今年7月份以来，省水利厅已召开三次计划规划与建设推进工作视频调度会，莆田市因个别项目推进滞后屡遭通报直至被约谈，此种情况与我市历年水利建设在全省排位，水利工作在全省形象不相符，与书写生态文明木兰溪样本要求不相适应。现将9月7日全省视频会点名工作严重滞后的问题通报如下：

一、仙游县

中岳溪（一期）、中岳溪（二期）、粗溪象山段、粗溪桥光段等4条中央补助资金4733万元已到位的中小河流治理项目目前基本零投资。上级规定要求年内4条中小河流治理项目需完成中央水利发展资金支出80%以上，具体推进要求另文通知。

应接入省水利基建项目管理视频平台的粗溪象山段整治工程、粗溪桥光段整治工程尚未接入。

二、荔城区

明显慢于序时的在建项目为城涵河道生态修复综合整治工程（荔城区段）。

计划开工项目中荔城区玉湖新城安全生态水系建设工程未开工。

三、城厢区

中央预算计划执行率仅31.81%，与上级要求年内要确保中央投资任务的考核目标差距较大。

计划开工项目共5个，其中尚未开工项目3个为桂山溪河道综合治理项目、华亭镇兴沙溪河道综合治理项目、下磨溪生态河道整治工程（学园桥-文献桥段）。

应接入省水利基建项目管理视频平台的莒溪中小流域治理工程、溪北溪上游河道生态治理工程尚未接入。

四、涵江区

中央预算计划执行率61.16%，低于序时进度要求。

明显慢于序时的在建项目为莆田市蓝色海湾整治行动项目（涵江区段）、城涵河道生态修复综合整治工程（涵江区段）。

计划开工项目共3个，其中尚未开工项目2个为东泉溪整治工程、萩芦溪流域江口防洪工程（二期）。

应接入省水利基建项目管理视频平台的涵江水环境综合治理一期工程、梧梓河整治工程（二期）、塘头河整治工程（二期）、蓝色海湾整治行动项目（涵江区段）尚未接入。

五、秀屿区

秀屿区凤岸溪山洪沟治理要求年内完成80%以上工程量，目前还未开工。

慢于序时的在建项目为南日镇东岱海堤应急加固工程。

计划开工项目为土海周边水系综合整治及连通工程，目前尚未开工。

应接入省水利基建项目管理视频平台的南日镇东岱海堤应急加固工程、石门澳产业园堤防提升工程-东堤南堤及管理房标段、石门澳产业园滞洪区清淤及配套工程、秀屿区河道综合整治（一期）工程、秀屿区河道综合整治（二期）工程尚未接入。

全省第三批水系连通及农村水系综合整治试点县规定要求年底前方案内建设内容要全面完成，目前工程严重滞后，尤其中央资金拨付慢，中央资金完成率为52%。凤岸溪河道综合整治工程、大蚶山水源涵养与水土保持工程尚未开工。

六、湄洲岛

全省第三批水系连通及农村水系综合整治试点县规定要求年底前方案内建设内容要全面完成，目前工程严重滞后，尤其中央资金拨付慢，中央资金完成率为37.3%。湄洲岛污水处理厂技改工程严重滞后，二期工程尚未开工。

七、北岸管委会

应接入省水利基建项目管理视频平台的蓝色海湾整治行动项目（湄洲湾北岸段）尚未接入。

八、市水务集团

西音水库中央预算年度计划4000万元，上级规定要求中央投资任务重大项目需完成年度计划90%以上，目前完成1100万元，占比仅27.5%。

明显慢于序时的在建项目为莆田市东圳水利枢纽引水配套工程、莆田市玉湖与企溪水系连通项目、莆田市河道水质治理工程。

计划开工项目福建省木兰溪下游水生态修复与治理工程尚未开工。

应接入省水利基建项目管理视频平台的玉湖与企溪水系连通项目、城乡供水一体化试点项目、东圳水利枢纽引水配套工程、西音水库工程尚未接入。

九、木兰溪防洪建设管理处

应接入省水利基建项目管理视频平台的宁海闸及配套工程尚未接入。

十、木兰管理处

城区排涝（张镇）泵站工程计划6月开工建设，至今项目可研尚未批复。

十一、东方红水库管理处

东方红水库除险加固工程完成年度计划58.68%，建设进度慢于序时。已下达中央预算年度计划2885万元，上级规定要求中央投资任务重大项目需完成年度计划90%以上，目前中央资金执行率严重滞后，仅完成1156万元，占比40.07%。

切望各县（区）水利局、各项目单位统筹项目建设与疫情防控，提振信心，落实责任，举措过硬，奋力追赶，确保年度任务完成。

为跟踪掌握上述滞后项目推进情况，请县（区）水利部门、市直项目建设单位每月15日和月末，分两次上报最新推进情况，以便及时与省厅沟通汇报。需要市水利局协调解决问题请及时书面函告。

 

 

莆田市水利局

                             2021年9月18日
