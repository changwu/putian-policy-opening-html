关于开展水利行业基层安全生产网格化监管工作的指导意见

发布时间：2018-05-24 11:30
| | |

 

各县（区）水务局、湄洲岛农林水局、北岸农办,局属各单位：   

为贯彻落实《国务院安委会办公室关于加强基层安全生产网格化监管工作的指导意见》（安委办[2017]30号），进一步夯实我市水利行业基层安全生产监管工作，根据《莆田市安办、莆田市网格办关于开展基层安全生产网格化监管工作的通知》（莆市安办[2018]33号）文件要求，现就开展基层安全生产网格化监管工作作如下指导意见：

一、目的意义

基层安全生产网格化监管是新形势下创新安全生产监管模式，是增强安全生产监管效能的重要举措，是推动安全生产监管工作关口前移、重心下移和解决监管难题的有效手段。实施基层安全生产网格化监管，对于缓解基层安全生产监管任务和监管力量之间的突出矛盾，构建全覆盖、齐抓共管的安全生产工作格局，提升全社会安全生产综合治理能力具有重要的现实意义。

二、工作目标

    将我市水利安全生产监督管理责任按照属地、单位，划分若干个责任区，明确水利安全管理责任和工作内容，做到定人、定岗、定责，构建“责任全覆盖、监管无盲区”的网格化式水利安全生产监管责任体系，依托该体系，充分发挥网格员的“宣传员”、“信息员”和“巡视员”作用，有效提高基层安全生产宣传教育的知晓率、基层安全生产隐患问题的整改率。实现对基层安全生产工作的动态监管、快速处理和源头治理。

三、工作步骤

（一）启动部署阶段（5月）

积极参加市安办、市网格办组织召开的现场会，学习推广仙游、涵江经验，部署推进“网格化+安全生产”工作，按照“党政同责、一岗双责”的要求，将基层安全生产网格化监管工作纳入安全生产工作重要内容。

（二）组织实施阶段（6-8月）

各单位按照各自的责任范围，将水利安全生产责任进行内部分解，把责任具体细化到部门内设机构和直属单位，落实到每个工作岗位，形成一个完整的责任链条。编制基层网格员安全生产工作工单，明确各网格的网格员、安全监管责任人和分管领导，根据网格内监督管理对象的情况，编制《基层安全生产网格化监管工作手册》等实用性强的工作规范和标准，制作网格员明白卡，明确网格员工作任务和报告方式。

（三）全面推行阶段（9-10月）

各单位对“网格化+安全生产”模式运行中的问题要及时发现、反馈、研究和解决，通过现有的网络资源、媒体报道和部门之间交流等途径，认真总结和推广好的经验和举措，不断推动基层安全生产网格化监管工作的规范化、长效化。

四、工作要求

（一）提高认识，加强领导。各单位要深入贯彻党的十九大精神，以习近平新时代中国特色社会主义思想和安全生产重要思想为指导，充分认识新形势下做好基层安全生产网格化监管工作的重要性。按照“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的要求，加强组织领导，主要负责人要坚持亲自抓，分管领导具体抓，从制度上、机制上确保基层安全生产网格化工作各项责任的落实。要经常深入基层加强调查研究，切实解决工作中的难点问题，不断改进和提升工作水平。

（二）明确职责，落实责任。坚持“属地管理”和“谁主管、谁负责”、“条块结合”原则，安全生产网格化管理各责任人要严格按照有关规定，结合本单位、行业实际，进一步明确安全监管工作职责，做好检查和监管。网格内的责任单位与责任人实行“三定”，即定人、定岗、定责，切实做到工作到人、职责到人、责任到人。第一责任人、分管责任领导要经常检查责任区内重点单位的安全工作，并指派专人负责，跟踪落实各项管理措施。各安全管理责任人要加强对重点单位的检查，及时发现和消除安全隐患，杜绝重特大事故的发生。

（三）统筹协调，确保实效。在安全生产网格化管理工作中，各单位要对安全生产网格化建设统筹安排，绘制基层安全生产网格化监管示意图（表）。各单位要通过各种途径教育引导，深刻认识开展安全网格化管理的重要性、必要性和紧迫性，增强做好安全生产网格化管理工作的主动性和自觉性，落实各单位主体责任，对隐患严重、安全管理不到位的单位要追究相应的责任。
