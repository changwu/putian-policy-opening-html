关于健全安全生产大检查工作制度的通知

发布时间：2015-09-06 09:57
| | |

 

 

各县（区）水务局、湄洲岛农林水局、北岸农办、局直属各单位：

为推动安全生产大检查工作扎实有序开展，确保取得实效，

现就建立健全安全生产大检查工作制度要求如下：

一、建立健全工作例会制度。各县（区）水务局、局直属各单位要每周召开工作例会，分析本地区、本行业领域安全生产大检查进展情况，及时通报有关情况，安排部署下一步工作重点，研究解决工作中出现的具体问题。

市水利局安全生产大检查工作例会原则上每周五上午召开，由局安全生产大检查领导小组办公室组织，各检查组组长参加。

二、建立健全综合督查制度。各单位要适时组织开展督查，重点督查本辖区、本行业领域安全生产大检查工作落实情况，并采取“四不两直”暗查暗访等方式抽查重点企业，检验安全生产大检查工作成效。每次督查结束后，要进行认真总结，对发现的突出问题和隐患要列出清单，以正式文件形式通报督办，并及时抄送市水利局安监科。

三、建立健全信息交流制度。各县（区）水务局、局直属各单位要明确专人负责安全生产大检查信息工作，跟踪掌握本地区、本行业领域安全生产大检查工作进展情况，在每月13日、28日向市水利局安监科报送1条以上安全生产大检查工作信息和《莆田市安全生产大检查信息统计表》（附件1）。信息工作人员名单及联系方式于9月10日前报送市水利局安监科。

（联系人：林腾飞，电话：2673395，传真：2336526，邮箱：sljzak109@163.com）。

四、建立健全调度统计制度。各县（区）水务局、局直属各单位要明确专人负责安全生产大检查调度统计工作，认真做好反映工作成效的相关数据统计工作，每月1日前将《莆田市安全生产大检查深化“打非治违”和专项整治工作统计表》（附件2）报送市水利局安监科。调度统计人员名单及联系方式于9月10日前报送市水利局安监科（联系人：林腾飞，电话：2673395，传真：2336526，邮箱：sljzak109@163.com）。

五、建立健全宣传教育制度。各县（区）水务局、局直属各单位要把集中开展安全生产大检查作为当前安全生产的首要任务，层层动员部署、宣传发动到基层、到单位、到企业，做到家喻户晓、深入人心。要加强与新闻媒体合作，在莆田电视台和湄洲日报上大力宣传安全生产大检查开展情况。要利用媒体曝光发现重大问题和隐患拒不整改的单位，以及安全生产领域突出的非法违法行为，着重抓好反面典型案例的教育警示作用。
