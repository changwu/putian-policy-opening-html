关于开展2018年“安全生产月”活动的通知

发布时间：2018-05-24 11:26
| | |

 

各县（区）水务局、湄洲岛农林水局、北岸农办,局属各单位，市水务集团有限公司：   

根据《莆田市人民政府安委会办公室关于开展2018年“安全生产月”活动的通知》（莆市安办[2018]38号）、《福建省水利厅安委会关于开展2018年全省水利“安全生产月”系列活动的通知》（闽水安[2018]22号）文件要求，为进一步加大安全生产宣教工作力度，推动落实我市水利安全生产主体责任和水利安全生产各项工作部署，特制定2018年莆田市水利系统“安全生产月”活动方案。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入宣传贯彻习近平总书记关于安全生产工作的重要思想和党的十九大精神，以及党中央、国务院、省委、省政府和市委、市政府关于安全生产工作的决策部署，以深入推进安全生产领域改革发展为主线，以“生命至上、安全发展”为主题，创新平台载体，丰富活动形式，大力开展安全生产宣传教育，推动全市水利安全生产形势持续稳定向好。

二、活动主题和时间

活动主题：想安全事，上安全岗，做安全人

活动时间：2018年6月1日至30日，各县（区）水务局、湄洲岛农林水局、北岸农办，局属各单位，市水务集团有限公司同时组织开展。

三、组织机构

成立莆田市水利局“安全生产月”活动组委会，具体名单如下：

组  长：黄德元

副组长：张章模、王二虎、陈东风、蔡开国、吴国庆、王萍

成  员：郑志洪、陈国宁、肖金锁、许智强、黄金鹏、

        颜文喜、吴建洪、蔡风飞、黄斌锋

组委会下设办公室，办公室设在局安监科，办公室主任由颜文喜兼任，具体负责活动组织、指导、协调工作。

四、活动安排

（一）开展主题宣讲活动。1.市水利局有关领导通过作专题报告、发表电视讲话、接受采访等形式，引导全社会树立安全发展观念，坚守安全生产红线，落实安全生产责任。2.组织“安全生产志愿服务宣讲”活动。市、县（区、管委会）两级水利系统安监科各组织3-5个安全生产宣讲团，深入县、乡和重点企业集中宣讲安全生产法律法规、政策措施和安全技能，推动落实企业安全生产主体责任、部门监管责任、党委和政府领导责任。3.组织“落实企业安全生产主体责任”活动。有关市水利局直属企业负责同志要把落实企业主体责任挺在前面，通过举办安全生产教育专题讲座、公开课，发放安全生产教育读本，观看安全生产宣传教育片等多种形式，深入阐释企业安全生产主体责任的具体内容，宣讲安全生产法律法规和知识技能。

（二）开展“6·16”安全宣传咨询日活动。1.开展广场宣传咨询活动。各有关单位面向社会公众和从业人员集中宣传安全生产方针政策、法律法规、安全知识和自救互救方法等，回答群众关心的安全生产问题。2.开展微信传播安全知识活动。把参加咨询日等“安全生产月”活动的自拍照，对“安全生产月”活动及安全生产的期望寄语等分享到朋友圈。

（三）开展应急演练活动。各单位要积极参加由市安办组织的综合性演练活动，并组织全市水利系统针对危险化学品等高风险领域和工程建设中存在安全隐患的重点部位，开展水利行业安全应急预案演练活动。将演练活动与加强从业人员的安全知识教育和应急结合，增强从业人员的安全防范意识，提高从业人员防灾避害和自救互救能力。并认真组织评估、总结和宣传，通过演练优化应急预案，完善应急准备。

（四）开展网上安全文化精品博览活动。各单位要择优推荐一批警示教育影视作品、展板挂图、公益广告和安全科普读物等安全文化精品，经我局活动组委会和市活动组委会审核后上传至国家安全监管总局政府网站和全国“安全生产月”活动官方网站，实现安全文化精品的广泛展映和快速共享，经线上投票和线下评比，选出一批安全文化精品力作在媒体广泛展示传播。

（五）参与网络宣教和微信“我为安全生产代言”活动。

1.各单位动员辖区内社会公众和本单位职工参加全国“安全生产月”活动组委会办公室组织的应急和安全生产知识竞赛、安全文化精品博览、“安全月”特色宣教活动展示交流、“全国有了安全月的味儿”随手拍等系列网络安全生产月宣教活动。2.参与“福建安全生产”微信公众号上以“我为安全生产代言”为主题开展的“福建安全月味儿”“安全在我心中”微信接龙系列活动。

（六）开展事故警示教育活动。各单位要选择一些安全生产典型事故案例，通过警示教育展、专题研讨和媒体展映等形式开展事故警示教育。特别要针对危险化学品事故等易发事故开展事故警示教育，引导全社会深刻吸取事故教训，提高防范意识和能力，推动安全生产工作。

（七）开展新闻发布和专家访谈活动。1.举办安全专家访谈，各单位要组织水利安全监管干部与水利安全生产专家走进水利生产经营、建设单位开展访谈，深入挖掘、宣传推广一批落实安全生产责任制、遏制重特大事故、改革创新安全生产工作等方面的先进经验和先进典型；2.各单位要组织安全生产新闻发言人、理论专家、通讯员、网评员和监督员借助媒体优势，撰写理论文章、发布通讯综述、发表网络评论等，普及安全知识，引导公众和本单位职工把“生命至上、安全发展”的思想转化为强烈的自觉意识和自觉行动。

（八）开展水利专项检查宣传活动。各单位要继续深入开展“安康杯”竞赛、青年安全生产示范岗、《安全生产法》宣传周等具有行业领域特色的群众性安全生产共建共享活动，深入宣传水利安全生产大检查、水利安全生产“三严”行动和水利安全生产“严整治，促提升”专项行动等重点开展情况，引导企业和广大从业人员增强做好安全生产工作的主动性和自觉性。

（九）开展“海西安全发展行”活动。各单位可以结合水利实际，适时组织开展本行业本区域内新闻采访专题行，开展好五个主题宣传。1.安全责任专题：采访企业落实安全生产主体责任和全员安全生产责任制、安全生产大检查自查自改工作情况等；2.安全改革发展专题：对本行业本地区在安全生产领域内的创新举措和改革亮点进行集中报道，推动重点改革措施落地见效；3.科技强安专题：采访调研涉及危化品使用的水利生产经营单位，看其在安全基础保障能力等方面是否有所提高。4.依法治安专题：围绕“安全生产执法提升年”等活动，对各单位在落实《安全生产法》、《福建省安全生产条例》等法律法规进行采访，推动相关措施落到实处。5.典型宣传专题：深入发掘、宣传我市水利行业奋斗在安全生产战线上具有代表性和影响力的最美人物，努力凝聚安全发展的正能量，激发水利人的责任感、使命感和荣誉感。

（十）开展“身边隐患随手拍”活动。各单位要动员辖区内社会公众和本单位职工查找本行业不安全行为，拍照并配好相应文字信息发送至我局安监科邮箱，经分类梳理好我局将通知所辖部门进行督促整改，这样有助于提高社会公众以及本行业部门的隐患意识和防范能力。

（十一）开展“施工现场送安全”活动。各单位在“安全生产月”活动期间，通过购买一些水利安全生产教育片和挂图等资料，组织施工现场人员观看，并在施工现场摆放警示教育挂图，切实提升施工人员的安全意识。

（十二）开展水利青年干部安全教育。为进一步加强水利系统青年干部的安全与责任意识，我局拟在“安全生产月”活动期间，组织各级负有安全监管责任的青年干部开展一次以“聚青年之力，护安全之树”为主题的交流会，旨在强化青年干部的“红线”意识，助其树立底线思维。

五、工作要求

（一）强化“四个意识”。进一步强化政治意识、大局意识、核心意识、看齐意识。把深入贯彻习近平总书记关于安全生产的重要思想、党的十九大对应急管理和安全生产工作的部署要求作为一项首要政治任务和头等大事贯穿到活动全过程和各环节，务求落到实处。

（二）加强组织领导。各单位要组织召开专题会议，认真部署动员，确保组织到位、责任到位、经费到位。要把“安全生产月”活动作为当前安全生产重点工作，做到与业务工作同谋划、同部署、同检查、同考核、同落实。各单位主要领导、分管领导及安全监管部门主要负责人要参加1至2项“安全生产月”系列活动。

（三）深入宣传报道。要层层制定“安全生产月”活动宣传方案，把握正确宣传导向，充分发挥市内主流媒体的舆论导向作用、行业媒体的深度挖掘作用、地方媒体的广泛传播作用、新兴媒体的快速渗透作用，形成广电媒体、纸质媒体以及新媒体并重的矩阵式、全媒体、立体化的宣传格局，营造“安全生产月”的浓厚社会氛围。

（四）强化督导考核。各有关单位要建立“安全生产月”活动联络员制度和检查督导制度，加强沟通联络，掌握活动动态并及时报送市水利局安监科。要层层开展检查督导，将“安全生产月”活动开展情况纳入年度安全生产责任制考核内容并加大考核权重。

请各县（区）水务局、湄洲岛农林水局、北岸农办、局属各单位指定专人负责此次活动联络工作，并把联络员名单于6月1日报送我局安办。活动期间，各单位联络员于每周四前报送本周内“安全生产月”活动及其他相关工作开展情况（电子文本），重大活动可随时报送。安全月期间，请各单位积极参与各项活动，并做好各类活动影像的摄制工作（影像分辨率大于1280x720，格式为MP4、MPG2、AVI、MTS；照片资料分辨率不低于1920x1080，格式为JPG、PNG、PSD），并于7月1日前报送活动总结。
