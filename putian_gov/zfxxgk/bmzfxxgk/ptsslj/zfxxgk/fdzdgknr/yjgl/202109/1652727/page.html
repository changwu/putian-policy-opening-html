关于水利安全生产标准化评审工作有关事项的通知

发布时间：2018-09-04 17:31
| | |

 

 

各县（区）水务局、湄洲岛农林水局、北岸农林局，局属各单位，各有关单位：

 

为进一步做好我市水利安全生产标准化评审与管理工作，根据《福建省水利厅安全生产委员会关于水利安全生产标准化评审工作有关事项的通知》（闽水安[2018]26号）， 结合我市实际，现将评审工作有关事项通知如下：

一、评审标准

1、《水利部办公厅关于印发<水利安全生产标准化评审管理暂行办法实施细则>的通知》（办安监〔2013〕168号）

2、《水利部关于印发<水利安全生产标准化评审管理暂行办法>的通知》（水安监〔2013〕189号）

3、《水利部办公厅关于水利安全生产标准化评审工作有关事项的通知》（办安监函[2017]1088号）

4、《水利部办公厅关于印发水利安全生产标准化评审标准的通知》（办安监[2018]52号）

二、评审组织

1.水利生产经营单位根据安全生产标准化创建情况， 自愿申请标准化等级评审。

2.水利安全生产标准化一级单位的申请由省级水行政主管部门出具审核意见，上报水利部评审并颁发证书。

3.水利安全生产标准化二级单位的申请由市级水行政主管部门出具审核意见，上报省水利厅评审并颁发证书。

4.水利安全生产标准化三级单位的申请，原则上由申请单位注册地县（区、管委会）水行政主管部门出具审核意见，上报市水利局评审并颁发证书。

三、初次评审

1.初次申请水利安全生产标准化一级的水利生产经营单位，应提交申请表、自评报告、支撑性材料以及市级水行政主管部门出具的相关意见，由省级水行政主管部门组织审核工作，提出审核意见。

2.初次申请水利安全生产标准化二级的水利生产经营单位，应于每年10月底前提交申请表（附录A）、自评报告、支撑性材料，由市级水行政主管部门组织审核工作，并提出审核意见。

3.初次申请水利安全生产标准化三级的水利生产经营单位，应于每年10月底前提交申请表（附录B）、自评报告（附录C）、支撑性材料（附录D）及评审机构出具的评审报告,由市级水行政主管部门进行评审并颁发证书。

4.初次申请水利安全生产标准化等级的生产经营单位， 对提交的评审材料负责，如有发现存在弄虚作假行为，一经查实则取消当年评审资格，并录入诚信体系档案。

 

四、延期申请

1.水利安全生产标准化二级、三级证书有效期为3年，水利生产经营单位可在等级证书期满前3个月，自愿提出延期申请。

2.水利安全生产标准化二级、三级单位在证书有效期内应满足下列条件才可以申请延期：

（1）未发生人员死亡或者一次重伤3人及以上，或500万元以上(三级延期为100万元以上)直接经济损失的水利生产安全事故；

（2）不存在重大隐患或安全管理突出问题；

（3）无非法违法生产经营行为,生产经营状况未发生重大变化；

（4）每年对安全生产标准化情况进行自评，并按规定提交自评报告;

（5）符合水利安全生产标准化相关评审标准规定。

3.申请单位应按照延期申请材料清单（附录E）要求，提交延期申请相关材料；申请水利安全生产标准化三级的单位，还需评审机构出具的评审报告。

五、其他要求

（一）安全生产标准化等级撤销

取得水利安全生产标准化二级、三级证书的单位，在证书有效期内，如有以下情形之一，经核实后撤销其安全生产标准化等级并予以公告：

1.存在评审过程中弄虚作假，材料不真实；

2.迟报、漏报、谎报、瞒报生产安全事故；

3 .建设项目发生较大及以上生产安全事故：

4.管理单位发生人员死亡、重伤3人以上或经济损失超过100万元以上的生产安全事故等情况的。

 

（二）安全生产标准化二级、三级单位初次申请，自评报告（附录C）中表4“单位基本条件符合性自查表”序号6、7（未发生安全事故等）由我局向各县（区、管委会）水行政主管部门征求意见。

（三）安全生产标准化二级、三级单位延期申请条件中（1）～（3）由我局向各县（区、管委会）水行政主管部门征求意见。
