关于全面开展防汛安全隐患排查整改工作的通知

发布时间：2017-07-10 14:59
| | |

 

各县（区）水务局、湄洲岛农林水局、北岸农办、局属有关水管单位、局机关各相关科室：

6月24日四川阿坝州茂县叠溪镇新磨村发生山体高位垮塌灾害，为贯彻落实中央、省委省政府、市委市政府主要领导的重要指示、批示精神，确保2017年水利工程安全度汛，请各地、各有关单位立即组织开展水利工程防汛安全隐患排查整改工作，特通知如下：

一、全面排查安全隐患

各县（区、管委会）水利部门、局直属水管单位，结合实际，组织人员对本辖区水利工程全面进行防汛安全拉网式排查。市水利局将派出5个检查组，分赴各地，在你们全面检查的基础上进行重点抽查、检查。重点检查水库山塘、江海堤防、河道围堰、水闸、渠道等工程。一是在建工程的高边坡开挖、破堤施工、土方、石方等堆料场安全。二是水利工程度汛准备，包括水库防汛责任人、度汛预案落实情况。三是检查工程运行情况，包括海堤、水闸渗漏情况，特别是绕闸边墙渗漏；堤防、水库边坡平整度情况是否存在异常裂缝等，水库、山塘泄洪通道是否通畅等，渠道边坡、渡槽结构有无变形。

二、落实安全隐患整改

各县（区、管委会）、各有关部门对排查中发现的安全隐患和问题，要逐项登记、逐一整改，确保消除隐患。要明确整改责任单位、责任人、方案和具体措施，限期整改到位。主汛期前确实无法整改销号的，必须制定应急度汛方案，着手制定整治加固方案，并报防汛指挥部、主管部门备案。

三、上报整改落实工作

各县（区、管委会）、局属有关水管单位要在7月14日前将本辖区内的防汛安全隐患排查情况上报各对应的市局检查组汇总。各检查组应汇总县（区、管委会）自检情况和抽查情况并于7月14日前上报市水利局。
