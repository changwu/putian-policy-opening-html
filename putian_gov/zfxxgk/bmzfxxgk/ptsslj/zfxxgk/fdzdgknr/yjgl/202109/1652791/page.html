莆田市水利局关于切实加强今冬明春消防安全工作的通知

发布时间：2014-11-24 15:50
| | |

 

 

 

 

 

各县（区）水务局、湄洲岛农林水局、北岸农办，局直属单位：

    为认真贯彻落实《莆田市人民政府办公室关于切实加强今冬明春消防安全工作的通知》（莆政办明电[2014]58号）精神，切实加强全市水利系统2014年冬季、2015年春季（以下简称今冬明春）火灾防控工作，坚决预防和遏制重特大尤其是群死群伤火灾事故发生，确保今冬明春全市水利水电工程建设管理及生产、2015年全国“两会”及元旦、春节、元宵节期间消防安全，特制定我市水利系统今冬明春火灾防控工作方案。

    一、工作目标

    紧紧依靠党委政府，联合相关职能部门，动员社会备方面力量，在全系统内全面排查整治火灾隐患，广泛开展消防宣传培训，全力做好灭火救援准备，努力预防和减少较大亡人火灾，坚决遏制重特大尤其是群死群伤火灾，维护火灾形势总体平稳。今冬明春水利水电工程建设管理及生产、2015年全国“两会”及元旦、春节、元宵节期间，不发生较大以上火灾事故。

    二、组织领导

    莆田市水利局成立今冬明春火灾防控工作领导小组，负责全市水利系统火灾防控工作的领导、组织、指挥和协调。

    组  长：吴健明

副组长：王二虎、陈东风

成  员：局机关各科室负责人。

领导小组下设办公室，由颜文喜兼任办公室主任，负责日常工作协调。联系人：吴骥，联系电话：2336526，电子邮箱sljzak109@163.com。

    三、工作时间

    2014年11月至2015年汛期（4月1日）之前。

 四、工作内容

 莆田市水利局及时印发文件、召开会议部署今冬明春火灾防控工作，明确各科室、直属各单位的消防工作职责和任务；在重大活动、重要节日期间要切实做到组织领导到位、检查督导到位、任务落实到位。

要按照市政府安委会的统一部署，继续深入推进消防安全“打非治违”专项行动和“清剿火患”战役。各级水利部门要深入贯彻落实 “党政同责、一岗双责”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”的总要求，加强对全市水利系统的消防安全监管，督促所属单位落实消防安全职责，常态化地开展消防安全自查自纠，及时消除单位自身发现的火灾隐患。要重点加强对消火栓、“三合一”场所、水电站、水厂厂区（特别是危化品仓库）、各单位驻地办公场所等消防隐患排查整治工作。加大消防安全检查力度，打击违法生产经营行为，整治违规住人、消防设施缺失损坏、安全出口疏散通道堵塞封闭等问题。对排查出的火灾隐患，要依法督促整改，决不手软；对可能造成群死群伤的重大火灾隐患，坚决依法铲除，决不放过。要紧盯尚未整改的重大火灾隐患单位、区域性火灾隐患，严格落实整改方案，强化整治措施。对未整改完毕的重大火灾隐患进行跟踪督办，严格按照整改期限如期销案，对整改期间不能保障消防安全的单位，要依法责令停业整改；对未按时整改销案的单位，要采取临时查封等强制措施，坚决依法予以关停。对尚未整改到位的区域性火灾隐患，牵头制定整改计划，落实整改措施。

各县（区）水务局、市水务集团要认真贯彻《关于抓紧维修部分损坏市政消火栓的通知》（莆市水利[2014]52号）和《关于加强市政消火栓维护管理工作的通知》（莆市水利[2014]85号）文件精神，努力在2014年年底完成所有损坏消火栓的维修工作。

直属各单位今冬明春火灾防控工作方案请于12月2日前报送水利局火灾防控工作领导小组办公室，并在每月23日前上报当月工作开展情况，2015年3日2日前上报今冬明春火灾防控工作总结。

  五、工作要求

 (一)切实提高认识，加强组织领导。各科室、直属各单位要本着对人民群众生命安全高度负责的态度，坚决克服松懈思想和厌战情绪，扎实做好今冬明春火灾防控工作。

 (二)严格督导检查，落实工作责任。各科室、直属各单位要建立工作责任制，层层分解工作任务，确保工作任务落实到具体单位和具体人员。市局将适时派出工作组，开展督导检查，对工作落实不力、行动迟缓、弄虚作假的，将按照相关规定严肃进行责任倒查。

 (三)认真总结经验，及时反馈信息。加强信息交流，及时上报重要情况和突出问题。要认真查找存在的不足和问题，采取有效措施加以解决。同时，要总结提炼成功经验和好的做法，建立健全消防安全管理的长效机制。
