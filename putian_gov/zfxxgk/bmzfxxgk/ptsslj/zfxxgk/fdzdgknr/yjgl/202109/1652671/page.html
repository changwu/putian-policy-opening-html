关于进一步做好安全生产工作的紧急通知

发布时间：2020-11-28 18:59
| | |

 

  

各县（区）水利局、湄洲岛农林水局、北岸农业农村局，局属各单位，市水务集团有限公司：

2020年11月27日16时49分许，涵港大道荔城区黄石镇惠下村路段一辆水泥搅拌车与一辆农用车发生碰撞，造成9死7伤的重大交通事故。11月28日上午，市政府召开全市安全生产工作紧急视频会议，市领导李建辉、傅冬阳、陈文荣在会上就进一步加强安全生产工作作出部署。为贯彻落实全市安全生产工作紧急视频会议精神，深刻汲取道路交通事故教训，现就进一步做好安全生产工作有关事项通知如下：

一、保持高度警惕，落实安全生产有关责任。各级水行政主管部门要清醒认识当前水利安全生产面临的严峻形势，进一步增强政治自觉和责任自觉，强化红线意识、风险意识和责任担当。牢固树立安全发展理念，层层压实责任，始终把安全生产摆在首位，克服麻痹大意思想，针对冬春季节企业生产经营活动集中，极易出现赶工期、抢进度和突击生产等问题，要强化抓落实、补短板、排隐患、促整改，隐患排查不走过场，坚决遏制重特大事故发生。

二、汲取事故教训，扎实开展水利重点领域隐患排查。各级水行政主管部门要进一步加强各类水利工程的安全监管，重点加强对在建工程、水库工程、供水工程、行业管理的农村小水电、水利风景区、人员密集场所的安全监督检查。结合当前开展的安全生产专项整治三年行动和安全隐患大排查大整治专项行动，全面排查整治各类事故隐患，对检查督查中发现的问题隐患要始终坚持“零容忍”，能立即整改的要立即整改，不能立即整改的要确保治理措施、资金、人员、时限、预案“五落实”，并加强跟踪督办，确保按期完成治理。

各级水行政主管部门和局属单位要立即对交通运输车辆开展隐患排查工作，对车辆驾驶人员进行安全教育及交流，特别要加强水利建设施工场外搅拌车、卡车等运输车辆驾驶人员的安全教育培训，全面了解驾驶员身心状况，对上路车辆开展全面排查，车辆未检验、交通违法未处理、车辆隐患未整改等问题，禁“三超一疲劳”（超速、超员、超载和疲劳驾驶）等道路交通违法违规行为。

三、强化应急管理，狠抓应急处置能力提升。临近年底，各级水行政主管部门要进一步加强值班值守，严格执行领导带班制度、关键岗位24小时值班制度和事故信息报告制度。进一步健全完善安全生产预警机制、应急联动协调和快速反应机制，不断完善应急预案，加强演练，落实应急资金、物资和队伍。要大力宣传安全生产知识和险情应急处置、逃生避险自救等常识，切实提高从业人员安全意识和事故防范能力，有效提升水利生产安全事故防范应对能力和水平。

 

 

                    莆田市水利局

                     2020年11月28日
