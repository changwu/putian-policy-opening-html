莆田市水利局关于开展水利安全生产百日攻坚专项行动的通知

发布时间：2021-07-19 18:12
| | |

 

各县（区）水利局、湄洲岛农林水局、北岸农业农村局，局机关业务科室，局属各单位，市水务集团有限公司：

按照7月17日全省水利安全生产百日攻坚专题会议精神及7月18日全市水利安全生产百日攻坚专项行动布置会会议精神，为进一步贯彻落实省委省政府的决策部署以及省领导的工作要求，自即日起至2021年10月31日，开展全市水利安全生产百日攻坚专项行动（以下简称“百日攻坚专项行动”），现将有关事项通知如下：

一、总体要求

全市上下要认真贯彻习近平总书记关于安全生产的重要论述和来闽考察重要讲话精神，全面落实省委省政府和水利部关于安全生产的决策部署和工作要求，坚持人民至上、生命至上，强化党政同责、一岗双责，标本兼治，强化红线意识和底线思维，深刻吸取事故教训，举一反三，担当作为，全力以赴，紧盯水利行业重点领域、重点部位和关键环节，有效管控化解各类水利安全风险，坚决防范遏制各类水利安全事故，全力维护人民群众生命财产安全，为全方位推动水利事业高质量发展超越创造良好安全环境。

二、工作目标

自即日起至2021年10月底，开展全市水利安全生产百日攻坚专项行动。统筹推进水利安全生产专项整治三年行动和安全隐患大排查大整治，通过开展百日攻坚专项行动，深查、细查、严查，补短板、堵漏洞、扫死角，突出隐患排查治理，有效管控各类水利安全风险，全面防范遏制各类水利生产安全事故。

三、工作安排

第一阶段：突击行动（7月17日至7月26日）

以项目法人和业主为责任主体，开展自查自纠。全面排查在建水利工程、维修养护作业的安全隐患。一是省级在建重点重大水利工程项目在确保安全生产的前提下，边自查、边施工、边整改。二是其他在建水利工程和维修养护作业全部先停工，开展自查自纠自改，发现的安全生产问题整改到位并经业主单位确认后，方可复工。三是落实一项目一表格一报告，每个项目都要有一个检查情况记录表（须由负责人签字）、一份自查报告，自查完成后须于7月27日前将表格和报告上交至市、县水行政主管部门，并由市水利局汇总上报省水利厅。

第二阶段：复核督导（7月27日至9月底）

按照“省级统筹、市县参与、共同推进”原则，分级分区精准施策，开展随机抽查、复核督导安全服务。省水利厅将依托区域协调、干部挂钩工作机制，由84个处级干部对挂钩县百日攻坚专项行动开展情况和在建重点重大水利工程进行随机抽查、复核督导；市、县水利部门组织对辖区内的其他在建水利工程和维修养护作业开展随机抽查、复核督导。市水利局机关各科室按照业务职责分工负责开展随机抽查、复核督导工作，检查情况报局安办汇总。

第三阶段：建立机制（2021年10月）

各级水行政主管部门和单位要在深入开展隐患排查和攻坚整治的基础上，系统总结，建档立卡，规范管理，加强监督，督促项目法人和业主严格落实安全生产危险源辨识与安全风险分级管控制度，积极构建安全风险管控与隐患排查治理双重预防机制，着力从根本上消除安全隐患。

四、工作要求

（一）要提高政治站位。全市各级水利部门和单位要高度重视此次的百日攻坚专项行动，坚决扛起防范化解重大安全风险、保一方平安的政治责任，始终把习近平总书记关于安全生产的重要论述作为根本遵循，结合“再学习、再调研、再落实”活动要求，进一步强化责任担当，力戒形式主义、官僚主义，全力保障水利安全生产形势稳定。

（二）要加强组织领导。按照“统一部署、分级联动、全面覆盖”的原则，各级水利部门和单位要认真研究制定细化方案，明确职责分工，层层动员部署，细化工作安排，切实抓出实效。省级在建重点重大水利工程项目实行“省统筹、市管理”，其他在建水利工程和维修养护作业实行“省汇总、市统筹、县管理”。省水利厅负责组织实施、督促指导，市、县两级水行政主管部门负责监督检查、执法问责、督促整改，项目法人和业主负责自查自纠、整改落实。

（三）规范工作成果。各在建水利工程要在自查自纠自改的基础上，形成“一项目一表格一报告”，由相关责任人签字确认后报市水利局汇总，最终统一报送省水利厅安办。

（四）落实闭环管理。对检查发现的安全隐患问题，要建立隐患清单、整改清单、销号清单，定准对策措施，实行动态闭环管理，决不漏掉任何一个盲点，决不留下任何一个隐患。对重大安全隐患挂牌督办，要督促责任主体做到整改责任、措施、资金、时限、预案“五落实”。对重复存在同类型重大隐患、隐患整改弄虚作假的要严厉打击、严格监管，确保排查发现的隐患全部整改到位。
