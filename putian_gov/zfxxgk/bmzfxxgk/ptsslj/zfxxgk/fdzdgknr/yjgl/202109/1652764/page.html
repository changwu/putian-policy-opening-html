莆田市水利局关于印发《水利安全生产信息填报工作方案》的通知

发布时间：2014-06-20 15:19
| | |

 

 

各县（区）水务局、湄洲岛农林水局、北岸农办，局直属各单位：

为落实好省水利厅的指示和要求，根据福建省水利厅关于印发《水利安全生产信息填报工作方案》的通知（闽水安监〔2014〕6号）精神，抓好我市水利系统安全生产信息化建设，提升水利安全生产监督工作效能，现将《水利安全生产信息填报工作方案》印发给你们，请认真贯彻落实。

 

 

 

 

 

 

水利安全生产信息填报工作方案

莆田市水利局

 

为落实好各级领导的指示和要求，抓好全市水利系统安全生产信息化建设，提升水利安全生产监督工作效能确保水利生产安全，根据福建省水利厅关于印发《水利安全生产信息填报工作方案》的通知（闽水安监〔2014〕6号）要求，制定我市水利安全生产信息填报方案。

一、工作任务

按照省水利厅的统一部署，全市各级水行政主管部门组织填报本级所属及本行政区行业管理的水利安全生产信息，包括水利行业单位及所管在建和运行工程的基本信息、隐患排查治理和事故信息，通过水利安全生产信息上报系统逐级填写上报，统计各级、各单位、各工程的安全责任落实情况、隐患排查治理情况和事故发生处理情况。

二、工作安排

（一）组织集中培训。计划5月5日我市组织各县（区）水行政主管部门、各直属单位负责信息填报的人员集中培训，做到每名学员熟练掌握信息填报工作。5月上旬，各设区县（区）水行政主管部门负责组织本级所属单位及在建工程项目法人集中培训。

（二）梳理用户体系，5月上旬前完成。已录入上报系统水利行业单位和工程涵盖不全的，各县（区）、直属单位根据已下发的水利行业单位基本情况表和水利工程基本情况表，补充录入本级应纳入监管范围而尚未录入系统的单位和工程名称及编码（水利普查时已编码的单位或工程必须使用既有编码），尤其是普查之后新设立的单位和新建的工程，为其在系统中建立用户名。对已不存在或不归本级监管但已经录入系统的单位或工程予以删除。

（三）组织信息填报，5月底完成。组织各县（区）、直属单位填报本单位及所管工程的基本情况信息、隐患排查治理信息和事故信息，同时通过系统报送5月份的隐患月报表和事故月报表。

三、有关要求

（一）切实加强领导。各县(区)、各单位要充分认识开展水利安全生产信息填报的重要性和紧迫性，责成一位分管安全的领导，精心组织，狠抓落实，取得实效。要结合各地实际，制定周密的填报工作方案。

（二）逐日报送进展情况。根据水利部《通知》要求，5月10日-20日，各县（区）要逐日向市水利局报送本级培训进展情况。5月20日-30日，逐日报送信息填报进展情况。我局将对报送进展情况适时给予通报。

（三）逐一核实信息。各级都要对本级直管单位上报的信息严格把关，一一进行审核，杜绝乱报、错报、漏报、不报等情况，保证上报的信息准确无误。在按要求组织本级直管单位填报信息的同时，还要组织好本行政区水利行业的信息填报工作。

（四）认真分析，加强总结。各级各单位要结合这次信息填报工作，推动安全生产监督管理工作和安全隐患排查治理工作的深入开展。全面客观地进行总结，针对安全生产工作存在的问题，分析研究治本之策，进一步完善水利安全生产长效机制。
