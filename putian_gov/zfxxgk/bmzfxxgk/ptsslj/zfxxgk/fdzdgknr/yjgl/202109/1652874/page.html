关于印发《莆田市水利局安全生产领导小组工作规则》的通知

发布时间：2016-12-14 11:16
| | |

 

 

 

 

 

各县（区）水务局、湄洲岛农林水局、北岸农林局，局属各单位，市水务集团公司：

为进一步加强全市水利行业安全生产管理工作，健全安全生产工作机制，落实安全生产监管责任，根据“党政同责、一岗双责”规定要求，修订《莆田市水利局安全生产领导小组工作规则》，现印发给你们，请认真遵照执行。

 

 

                         莆田市水利局

                     2016年12月14日

 

 抄送：市安办、省水利厅安办，局领导、局机关各科室。                      

莆田市水利局办公室                     2016年12月14日印发

莆田市水利局安全生产领导小组工作规则

为切实落实市委、市政府及有关部门安全生产监督管理责任，进一步加强全市水利行业安全生产管理工作，落实安全生产监管责任，健全安全生产工作机制，根据“党政同责、一岗双责”规定要求，修订本规则。

一、指导思想和工作目标

以科学发展观为指导，深入贯彻以人为本、安全发展理念，坚持“安全第一、预防为主、综合治理”方针，严格落实“党政同责、一岗双责、齐抓共管”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”等要求；按照综合监管和专业监管相结合、多管齐下、标本兼治的原则，采取有效措施落实安全生产责任、健全安全生产规章制度、加大安全生产投入、创新安全管理体制机制、强化行业安全监管，构建安全生产长效机制；坚决杜绝重特大安全事故，进一步减少较大和一般安全事故，降低伤亡人数，保证水利安全生产形势持续向好。

二、局安全生产领导小组工作职责

（一）贯彻落实和宣传上级关于安全生产的方针政策、法律法规，负责研究部署、指导协调、检查督促全市水利行业安全生产工作。

（二）分析全市水利行业安全生产形势，研究提出水利安全生产目标和规章制度。

（三）研究解决水利安全生产工作中重大问题。

（四）指导和组织协调水利重大生产安全事故调查处理和应急救援工作。

（五）完成市政府安全生产委员会、省水利厅安全生产委员会交办的有关工作。

三、局安全生产领导小组办公室（安全监督科）主要职责

（一）研究提出全市水利行业安全生产计划、目标、措施和建议。

（二）向成员单位通报全市水利安全生产形势和市安全生产委员会、省水利厅安全生产委员会、局领导有关安全生产工作指示。

（三）承办局安全生产领导小组召开的会议和重要活动，检查督促安全生产领导小组决定事项的贯彻落实情况。

（四）监督检查、指导全市水利行业安全生产工作，督促检查和组织协调局机关有关科室和直属单位涉及安全生产的相关工作，组织县（区、管委会）水行政主管部门、直属单位安全生产工作的目标责任考核，

（五）组织水利安全生产大检查工作，汇总各检查小组隐患排查情况，印发整改通知书，督促整改到位。

（六）负责安全隐患排查信息上报，水利安全信息收集、报送，开展水利安全生产宣传教育培训等工作。

（七）承办局安全生产领导小组交办的其他事项。

四、局安全生产领导小组各成员单位安全生产职责

局领导班子成员按照“党政同责、一岗双责”规定要求，领导各自分工的负责业务、分管科室和联系单位的安全生产工作。

局机关各科室（办、支队、站）主要负责人是本科室（办、支队、站）安全生产工作的第一责任人，全面负责本科室（办、支队、站）安全生产工作，履行以下职责：

（一）负责抓好安全生产法律、法规、方针、政策和市委、市政府及本局有关安全生产的决策、部署、指示在本科室（办、支队、站）及所联系单位的贯彻落实。

（二）组织落实局安全生产领导小组下达的安全生产目标任务，及时研究解决本科室（办、支队、站）及所联系单位安全生产中的突出问题。

（三）坚持将安全生产工作与本科室（办、支队、站）业务工作同时安排部署、同时组织实施、同时检查督促。

（四）督促本科室（办、支队、站）及联系单位排查整治安全生产隐患工作。

（五）本科室（办、支队、站）及所联系单位发生安全事故时，按规定赶赴事故现场，组织协调事故抢险救援和相关善后工作。

（六）各科室（办、支队、站）负责人要于每月5日前提交上一月安全生产排查等各项工作的记录（信息）。

 

安全生产领导小组各成员单位职责分工如下：

1、办公室：负责局机关防火、防盗、机密文件、车辆管理、机关用电、办公设备等安全管理工作，抓好节假日值班制度落实。负责安全生产目标绩效考核；负责安全生产教育培训的归口管理工作。组织指导局直属单位职工劳动保护。

2、计财科：负责资金管理、使用安全、保障局机关安全生产经费投入使用，监督检查经费使用情况。

3、水政水资源科（含水政监察支队）：负责河道设障阻洪清理、河道非法采砂、河道排污口检查等水事安全。

4、建设与管理科：负责水利企业安全资质与水利建筑市场安全、诚信等事宜。

5、防汛办及洪水预警报中心：负责防汛备汛、防汛调度、防汛抢险保安、洪水预警等安全。组织汛前、汛中安全检查，监督全市各级防汛、防台风等预案的落实。

6、水土办：负责水土流失治理及水土保持监督等安全生产及监管工作。指导全市水土保持工程建设中的安全生产监管工作。

7、总工室：负责水利工程技术审查过程中安全措施方案把关，指导工程技术安全认证、咨询与技术方案审定等工作。

8、水利建设站：负责农田水利基本建设、滩涂围垦、雨水集蓄利用、农田灌溉排水、节水改造、泵站建设与改造、村镇供水排水、农村水电站以及农村饮水安全等工程建设安全生产工作。

9、水利管理站：负责水库、堤防、水闸等水利工程运行管理和除险加固，防洪排涝、河道治理、水毁工程修复等水利工程建设安全。组织指导全市水利工程蓄水安全鉴定和验收。

10、水利工程质量监督站：负责其监督的在建水利工程质量安全监管，组织开展水利工程质量安全监督检查、专项督查工作；参与重大水利质量、安全事故查处。

    五、安全生产领导小组工作制度

（一）严格按照“党政同责、一岗双责、齐抓共管”和“管行业必须管安全、管业务必须管安全、管生产经营必须管安全”原则开展工作。

（二）安全生产领导小组全体会议原则上每年召开1-2次，会议由安全生产领导小组组长或其委托的副组长主持。

（三）每季度召开一次安全生产分析会。

（四）安全生产领导小组组长认为必要时可召开全体会议或有关成员及有关科室、单位负责同志参加的专题会议。

（五）安全生产领导小组全体会议或专题会议决定的重要事项要形成纪要报送局领导，印发有关单位。

六、附则

本规则自印发之日起施行。
