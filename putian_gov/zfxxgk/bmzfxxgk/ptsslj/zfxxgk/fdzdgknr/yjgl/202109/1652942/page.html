关于开展防汛备汛和水利工程安全检查的通知

发布时间：2017-02-16 16:54
| | |

 

各县（区）水务局、湄洲岛农林水局、北岸农林局，局属各单位： 

   为贯彻落实省市水利工作视频会议精神，确保2017年水利安全度汛，我局拟于2月下旬至3月上旬派出5个检查组，分赴各地开展防汛备汛和水利工程安全检查。现将有关事项通知如下：

　　一、检查内容

　　（一）防汛备汛工作检查重点：1、防汛抗旱责任制落实情况；2、防汛指挥图编制与防汛抗旱防台风预案修订情况；3、抢险队伍建设与防汛抗旱物资储备情况；4、防汛指挥、山洪灾害监测系统与防汛设施设备运行情况；5、水利水毁工程修复情况。

　　（二）工程安全管理检查重点：1、江海堤防、水库、闸坝等防洪防潮工程安全运行与防汛备汛情况；2、小型水库隐患排查与除险情况；3、在建工程施工安全生产与度汛预案情况；4、水利生产安全工作落实情况。

　　二、检查方式与时间安排

（一）各县（区、管委会）水务局（农林水局、农林局）、局属各单位于2月25日前，全面开展“拉网式”检查工作，对自查发现问题提出书面整改意见，及时落实整改，并形成检查情况汇报材料。

　　（二）检查组于3月3日前（具体时间由各检查组另行通知），赴各县（区、管委会）、局属各单位开展防汛备汛和水利工程安全抽查工作，采取深入现场、听取汇报、查阅资料等方式开展检查工作，对抽查发现的问题，提出整改要求和完成时限，督促各地防汛备汛和水利工程安全管理工作落实到位。

三、分组情况

检查组分组情况（名单按带队领导、组长、组员排序）：

    局属单位：黄德元、黄斌锋、郭加跃、蔡宗迎;

    仙游县：王  萍、许智强、王宝喜、郑志涵;

    荔城区、城厢区：陈东风、蔡风飞、张福泉、蔡洪华;

    涵江区：张章模、吴建洪、叶为人、佘振东;

    秀屿区、北岸、湄洲岛：王二虎、颜文喜、陈阳珊、郑航。

各县（区、管委会）水务局（农林水局、农林局）、局属各单位检查情况报告及隐患整改汇总表请于2月26日前上报市水利局工管科；各检查组检查情况报告请于3月5日前报送市水利局工管科，市水利局将根据检查情况进行通报。

工管科联系人：陈叶昉，电话：2380273，邮箱： ptsgk@163.com；市防汛办联系人：郭加跃，电话：2292995，邮箱：ptfb@163.com。
