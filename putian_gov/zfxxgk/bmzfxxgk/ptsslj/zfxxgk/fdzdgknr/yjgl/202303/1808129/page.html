关于公布市直管小（1）型水库防汛“三个责任人”名单的通知

发布时间：2023-03-15 18:27
| | |

市东圳水库管理局、市萩芦溪水电管理处：

根据水利部《水库大坝安全管理条例》和《福建省水利厅关于认真做好2023年水库安全管理工作的通知》(闽水函〔2023〕73号)的要求，现将2023年莆田市市直管小（1）型水库防汛“三个责任人”名单予以公布，接受社会监督。责任人出现工作变动的，要及时做出调整并报备。
