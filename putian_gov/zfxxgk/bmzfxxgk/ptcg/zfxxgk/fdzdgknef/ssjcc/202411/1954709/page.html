关于2024年下半年城镇燃气跨部门“双随机、一公开”暨“综合查一次”联合抽查情况通报

发布时间：2024-11-05 16:39
| | |
政策解读:

各县（区、管委会）燃气安全专项整治工作专班，各燃气经营企业：

　　10月25日，市燃气安全专项整治工作专班办公室（以下简称专班办公室）组织市城市管理局、市市场监督管理局、市公安局及市消防支队开展2024年度下半年城镇燃气跨部门“双随机、一公开”暨“综合查一次”联合抽查工作，期间抽查瓶装燃气储配站点2家次。现将有关情况通报如下：

　　一、基本情况

　　10月25日，专班办公室组织市城市管理局、市市场监督管理局、市公安局及市消防支队，随机抽取检查对象、随机选派执法检查人员，组织联合检查组抽查2家瓶装燃气经营企业：莆田市秀屿区东峤富民液化气有限公司、莆田市秀屿区埭头祥和液化气有限公司。检查组采取实地抽查，查阅相关资料，调研座谈等方式，现场检查发现存在问题11处。

　　二、存在问题

　　被抽查的燃气企业场站管理松散懈怠。莆田市秀屿区东峤富民液化气公司场站管理不到位，存在部分阀门的启闭标识牌悬挂错误；上墙公示的员工证件与现场员工不符；手持检漏仪长期未使用，放置箱已积灰；场站内堆积大量送检钢瓶；消防器材配备不足、保养不到位等问题。莆田市秀屿区埭头祥和液化气有限公司进行场站改造却未向当地燃气主管部门报备并办理改造审批；消防设备保养不到位，部分灭火器软管老化龟裂；室外消火栓保养不到位，锈迹斑斑，未发现水带水枪；部分压力表超期未校验。

　　三、处理意见

　　（一）举一反三，开展全面排查。请各燃气企业立即对照表格，举一反三，杜绝类似行为，重点抓好以下工作：一是严格场站日常管理，认真开展每日巡检，定期做好设施设备保养，定期开展员工培训，提升场站管理水平。二是加大随瓶安检的力度，通过购买服务、招聘专业安检人员等方式，严格按照法律法规要求，完成随瓶安检工作，必须建立登记纸质安检台账，安检单填写要规范，分类归档。对于发现的隐患，要及时督促配合用户整改，无法整改的及时上报燃气主管部门。

　　（二）齐抓共管，压实安全责任。各县（区、管委会）燃气工作专班应加强各职能部门的联动，齐抓共管，共同发力，常抓不懈，做到安全责任零缺位。一是要督促燃气企业加强场站自查管理，加大日常巡检力度，保障安全生产。二是对本次双随机及综合查一次抽查过程中发现的安全问题（详见附件），要督促企业落实整改，确保安全隐患得到有效消除，形成隐患整改闭环。

　　（三）及时反馈，接受社会监督。请相关县（区、管委会）燃气工作专班牵头汇总，并于11月25日前将调查处理及整改情况书面报送市燃气工作专班办公室。本次抽查的结果录入《福建省“互联网+监管”系统》及《福建省一体化大融合行政执法平台闽执法系统》进行公开，主动接受有关部门和群众的监督。

　　附件：城镇燃气跨部门“双随机、一公开”联合抽查问题汇总表

 

　　莆田市城镇燃气安全专项整治工作专班办公室（代章）
