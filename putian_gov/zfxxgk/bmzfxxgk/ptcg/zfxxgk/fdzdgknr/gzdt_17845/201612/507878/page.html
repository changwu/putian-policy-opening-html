2016年法治政府建设情况报告

发布时间：2016-12-28 10:52
| | |
政策解读:

　　2016年，在市委、市政府的领导下，在市城管委的统一协调下，我局紧紧围绕打造宜居港城、建设美丽莆田的发展大局，以“城市提升年”为主题，规范行政执法行为，严把法制审核关，依法执法、文明执法、和谐执法，较好地完成城管执法各项工作任务。现总结如下：

　　一、2016年工作总结

　　（一）加强组织领导。

　　我局依照上级的工作部署，结合我市城市管理执法工作实际，制定了《关于2016年推进依法行政工作实施方案》、《法治城管建设实施纲要（2015-2020年）》及《全市城管执法系统中开展法治宣传教育第七个五年规划（2016—2020年）》，及时作出工作部署，成立了相关工作的领导小组和日常工作机构，定期分析工作进展情况及存在问题，并提出要求。

　　（二）规范行政执法行为

　　1、深化行政执法体制改革。一是认真学习领会中共中央、国务院《关于推进城市执法体制改革改进城市管理的指导意见》，组织专题讲座一次。二是依照住建部的工作部署，制定市执法局推进城市执法体制改革近期重点工作方案，明确近期工作重点和责任分工，各有关科室按照方案和工作分工逐步推进城市执法体制改革工作。三是提出修改意见。我局积极配合省法制办、省编办、省住房和城乡建设厅就城市管理体制的调研内容提出意见，多次参加省住建厅组织的调研会，并提交城市管理执法队伍的基本情况。在省改革方案征求意见稿下发后，牵头组织市直各有关部门和各县、区、管委会，认真研究，提出修改意见。四是牵头起草我市的工作方案，目前代拟稿初稿已完成，已在城管执法系统征求意见，待修改后呈市政府。五是做好现有职权的权责清单，并着手梳理建设系统行政处罚权清单，为下一步承接相关行政处罚权做准备。六是参加市政府召开了我市深入推进城市执法体制改革改进城市管理工作协调会，市委编办、市住建局、市法制办、市执法局、市人社局、市财政局等部门领导参加。市执法局局长传达了《中共中央、国务院关于深入推进城市执法体制改革改进城市管理工作的指导意见》、《福建省深入推进城市执法体制改革改进城市管理工作的实施方案》和中央、全省城市工作会议精神，并就我市起草具体实施方案提出了建议；与会部门领导根据各自职能发表了意见。

　　2、做好法制咨询审核。一是建立了法律顾问制度，聘请资深律师担任局法制顾问，对我局各项经济合同、重大项目的法律文件进行把关；对重大行政执法事项会同法律顾问进行研究。二是根据新的行政执法事项集体评议规则，局法制科直接下基层，参与执法一大队的执法事项集体评议，共参与批后跟踪监察意见审核62件、行政处罚案件16件。三是认真组织属地执法局对行政复议、行政诉讼进行答复、答辩。今年以来，共办理行政复议3宗，1宗调解结案、2宗中止；行政诉讼2宗，1宗判决驳回诉讼、1宗裁定驳回起诉。

　　3、抓好电子系统运行。一是为进一步建立健全行政执法与刑事司法衔接的协调配合机制，我局做好信息共享平台的录入工作，截止目前，共录入16件行政处罚案件。二是严格按照行政处罚电子监察系统建设有关规定，将一般程序行政处罚案件全部通过电子监察系统进行办理接受监督，截止目前，共录入13件行政处罚案件（因电子监察系统于9月份开始无法使用）。三是根据市社会管理综合治理委员会的通知，将2014年以来的行政处罚案件录入莆田市综治诚信信息系统，截止目前，共录入2031件行政处罚案件。四是将2016年10、11月240件行政处罚案件信息报送市发改委信用科，由其录入信用莆田网站。

　　4、新增城市桥梁检测和养护维修管理权力清单、责任清单。根据《关于加强莆田市城市桥梁管理工作的意见》（莆政办[2016]103号）文件要求，我局制定了城市桥梁检测和养护维修管理规章规定的权力清单、责任清单及自由裁量标准，已将相关材料报送市审改办审核。

　　5、加强行政执法证件管理。一是完成行政执法主体资格确认，并上报市法制办审核。完成莆田市城管执法系统行政执法人员清理工作及2016年新取得执法证件人员的申领工作，并将人员名单在市执法局网站上公开。修订行政执法主体和行政执法证件管理制度。二是组织行政执法资格专业考试。我局与市法制办共同组织的城管执法类行政执法资格专业法律知识考试。考试内容包括市容环境卫生、城市规划、城市园林绿化、城市道路、城市照明、城市燃气、河道等城市管理行政执法专业知识，考试采取闭卷方式进行。城管执法系统共有30名干部职工通过考试。

　　6、加强行政执法监督。局法制科与综合业务科联合开展季度行政执法检查，并在城市管理考评执法案卷加分核查时，对案件办理中的瑕疵及时指出，督促改正。

　　（三）接受对行政权力的监督

　　1、开展行政处罚信息公开。一是公开职权信息。将我局裁量标准、行政职权信息通过政府门户网站、局门户网站公开，主动接受社会监督。二是做好行政处罚结果公开。将行政处罚案件，在市政府门户网站和局门户网站上公开。三是推进行政处罚信用信息公示工作。执法一大队在做出行政处罚决定之日起7个工作日内，将具体行政处罚事项通过局门户网站公开。

　　2、接受社会监督。广泛听取各级各部门的意见，及时办理人大建议和政协提案，做到件件有落实，事事有回音。今年以来收到的举报、投诉、转办督办件5件，市人大建议10件、市政协提案17件都已及时办理反馈。

　　（四）推进普法教育活动

　　1、加强法制教育。一是持续开展“每月一法”学习。按照学法计划，采取集中学习与自学相结合的方式学习法律法规，确保个人每年学法时间不少于40小时。二是举办法律知识讲座。为了提升行政执法水平，适应新形势工作需要，市局举办两场知识讲座，学习《中共中央　国务院关于进一步加强城市规划建设管理工作的若干意见》的文件精神和《依法开展市容和环境卫生管理工作要点》，全体干部职工参加。三是开展行政执法业务培训。10月9日—10月13日，我局组织开展了两期行政执法业务培训班，市城管执法系统全体执法人员共332人参加。培训班邀请了省住建厅法规处、省建设监察总队、市法制办、市中级人民法院行政庭的领导、专家以及局有关业务科室的领导进行授课，课程包含城市管理执法体制改革政策解读、行政法学知识、执法业务、城乡规划及建设工程批后跟踪监察工作重点和信访投诉件办理工作要点等内容。

　　2、开展法律宣传。一是加强社会宣传。通过宣传车、T型广告牌、电子显示屏、工地围挡等平台进行标语宣传，向广大市民宣传城市管理执法法律法规，增强广大市民的城市管理法律意识。在局网站上设立普法专栏，不定期的更新专栏内容，宣传普法依法治理新动向。二是注重新闻宣传。在湄洲日报《法治莆田进行时》宣传专栏刊登一期“规范摆摊经营  严查占道毁绿”宣传内容，通过案例分析占道、毁绿触犯的城市管理相关法律法规，提高广大市民遵章守法的意识。与莆田广播电视中心联合推出一档城市管理类电视专栏节目——《城市管理你我他》，对城市管理的亮点、难点进行报道，用第三只眼看城管、用第三张嘴评城管，截止目前，共播出20期。三是开展专题宣传。积极开展2016年国家宪法日暨全国法制宣传日宣传，通过多媒体宣传、法律咨询、“法律进企业”活动等系列活动，宣传普及宪法及城市管理方面的法律法规，营造宣传氛围。四是突出信息宣传。积极向市法制办、市依法治市办报送宣传城管执法工作的材料。

　　二、存在主要问题

　　一是城市综合管理机制尚需进一步完善。城市管理是项社会工程，迫切需要“大城管”工作合力。随着综合考评制度的实施，各县区（管委会）越来越重视城市管理工作，但有的市直部门和镇（街）、居委会的作用还没有完全发挥出来，“大城管”格局尚未真正形成。

　　二是专项治理任务还很繁重。城市管理仍时好时差，各县区（管委会）整治进展不平衡，还未达到预期目标。“两违”整治虽取得阶段性成效，但任务还相当繁重，整治压力大。

　　三是执法队伍形象有待继续提升。由于执法队伍中个别队员文化素质偏低，队伍形象有待进一步提高。

　　三、2017年工作思路

　　（一）开展法制教育活动。紧紧围绕城管执法体制改革，加强法律知识培训，落实经常性的法律学习制度，确保干部、职工学法时间、计划、内容落实。要在学以致用上下功夫，侧重提高队伍的法治意识和执法实践能力，不断提高依法行政水平。

　　（二）加大法制宣传力度。围绕城市管理各项业务工作，开展多角度、多层次、全方位的宣传工作，大力宣传城市管理法律法规和市执法局职能，及时报道执法工作动态，曝光违章违法行为，推广典型经验和做法，不断增强市民的城市意识、文明意识和守法意识，引导社会各界和广大市民关心、支持和参与城市管理工作，营造良好社会氛围。

　　（三）推进城管执法体制改革。会同相关部门做好城管执法体制改革的实施，协调确定新划转职能，并做好权责清单、行政处罚自由裁量标准、行政强制自由裁量标准等相关材料。

　　（四）积极参与地方立法工作。结合我市经济、社会发展实际，积极配合做好我市城市市容和环境卫生管理方面的立法工作。

 

　　莆田市城市管理行政执法局

　　2016年12月28日
