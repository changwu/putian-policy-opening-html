关于举办2008年第一季度城管执法研讨会的通知

发布时间：2008-05-05 00:00
| | |
政策解读:

局属各大队： 

　　为进一步规范执法程序，提高城管执法水平，经局务会议研究，决定于5月13日举办2008年第一季度城管执法研讨会，现就有关事项通知如下： 

　　一、会议时间：2008年5月13日（星期二）15：00—17：30 

　　二、会议地点：市执法局四层会议室 

　　三、参加人员：局领导、机关科室相关人员、各大队领导和法制干部。邀请市法院行政庭、市政府法制办、市司法局、市建设局、市规划局、市土地局、市农业局、市效能办、市纪委执法室、城厢区法院行政庭的领导前来指导。（请于5月12日前将参加会议的名单反馈给联系人柳金玉，联系电话0594-2626007） 

　　四、会议保障：政策法规科负责起草研讨课题内容、制作会议横幅、发放嘉宾请柬；办公室负责会场后勤保障；一大队负责音量调试。 

　　附：2008年第一季度城管执法研讨课题 

　　二〇〇八年五月五日 

　　2008年第一季度城管执法研讨课题 

　　一、在行政处罚决定书中，有“你有xx的行为，违反了xx的规定，根据xx的规定，本单位决定对你处罚如下：xxxx。”根据《城市规划行政执法委托书》的规定，市规划局委托市城建监察支队行使《城乡规划法》第六十四、六十六条的行政处罚权，如果分别根据第六十四条、第六十六条对违法行为进行处罚，行政处罚决定书的“违反了xx的规定”填写哪个条款？ 

　　二、擅自改变建筑物、构筑物和其他设施的使用性质的，《福建省实施<城市规划法>办法》第五十五条第二款规定：由城市规划行政主管部门责令限期改正；逾期不改正的，依法强制改正，并处以该项目整体工程造价的10%至20%的罚款。但2008年1月1日起施行的《城乡规划法》对此没有明确规定。如果现在发现擅自改变建筑物使用性质的行为，该引用什么条款进行处理？ 

　　三、《城乡规划法》第六十四条规定，未取得建设工程规划许可证或者未按照建设工程规划许可证的规定进行建设的，由县级以上地方人民政府城乡规划主管部门责令停止建设；尚可采取改正措施消除对规划实施的影响的，限期改正，处建设工程造价百分之五以上百分三十以下的罚款。”目前法律没有对“建设工程造价”进行细化规定。请问，作为罚款计算基数的建设工程造价是指已建部分的建设工程造价还是拟建全部建设工程造价？加层或扩建的项目，是把加层或扩建部分的建设工程造价作为罚款计算依据还是把这幢建筑的全部建设工程造价作为罚款计算依据？2008年在一座1990年建造的合法建筑上违法加层，因2008年和1990年建设工程造价差别巨大，如何确定建设工程造价？在规划案件中，如当事人在未取得《建设工程规划许可证》情况下建房，建至第二层完工，被依法查处，并按工程总造价5%-10%罚款，当事人按期缴纳罚款，该案件结案后，当事人又再加层建设至第三层，执法单位重新立案调查，此时，对该当事人进行罚款，罚款额度是否还是按照该工程总造价进行核算，即是否按第一层至第三层的工程总造价进行核算？ 

　　四、目前，城市规划执法环境不好。当事人拒不接受调查、拒不配合调查、暴力抗法现象时有发生。如果有人大门紧锁在屋顶加层或在院内扩建，执法人员明知有违法行为存在，但无法进入违法现场进行调查，这种情况下行政执法如何开展？
