关于印发《城市道路扬尘污染点题整治工作方案》的通知

发布时间：2023-08-22 17:00
| | |
政策解读:

各县区（管委会）城市管理局（执法局）、住建局（建交局），环卫处（所），局属有关单位：

　　现将《城市道路扬尘污染点题整治工作方案》印发给你们，请认真组织实施。

 

 

　　莆田市城市管理局

　　2023年8月10日

 

 

　　（此件主动公开）

 

 

　　城市道路扬尘污染点题整治工作方案

　　为着力解决我市城市道路扬尘造成的空气污染问题，持续改善城市空气质量，不断提升人民群众获得感、幸福感、安全感，根据省、市纪委监委关于2023年“点题整治”工作部署要求，结合我局职能，制订本工作方案。

　　一、整治目标

　　加强扬尘综合治理，强化渣土车的日常管控，加大查处力度，有效抑制车辆“滴洒漏”等现象；深化我市环卫清扫常态化保洁机制，强化日常洒水降尘，城市道路扬尘污染问题得到有效控制，信访投诉按期办结率100%，建立健全城市道路扬尘管控长效机制。

　　二、整治任务

　　1.持续加大城市道路扬尘治理力度，健全道路长效常态保洁机制，严格执行市容环境卫生作业质量标准，加强城区道路路面日常保洁作业;加大对群众反复投诉区域重要路段路面清洗喷洒作业。

　　责任单位：市局市容环卫监管科、市环卫处，各县区（管委会）城市管理局（执法局）、环卫处（所）。

　　2.加大市政维护项目的扬尘管理。督促市政维护施工单位规范切割、路面破除等部分易扬尘的工序，采取洒水等有效的降尘措施，施工过程产生的渣土、淤泥等建筑垃圾必须及时清运。

　　责任单位：市局市政公用科、市政维护处，各县区（管委会）住建局（建交局）。

　　3.强化渣土车的日常管控，组织对渣土车等进行检查，联合交警、交通等部门共同开展执法巡查，加大对重点区域、重点路段、重点时段的巡查力度，严厉打击渣土车滴撒漏、违法运输、乱倾倒等违法行为，有效控制道路扬尘。

　　责任单位：市局执法协调科、数字城管中心，各县区（管委会）城市管理局（执法局）。

　　4.依托12345平台监督热线,受理有关道路扬尘污染的投诉举报,及时分析研判信访数据,做到有呼必应、有诉必理、有理必果。

　　责任单位：市局指挥中心、执法协调科、市容环卫监管科、市政公用科，各县区（管委会）城市管理局（执法局）、住建局（建交局），环卫处（所）。

　　三、整治步骤

　　（一）部署阶段（8月11日前）：完成工作方案印发，召开动员部署会，指导督促各县（区、管委会）城市管理（执法）局、住建局（建交局）、环卫处（所）制定实施方案，明确工作举措、责任分工，及时启动整治工作。

　　（二）实施阶段（8月12日-11月30日）：对照工作方案，组织各县（区、管委会）城市管理（执法）局、住建局（建交局）、环卫处（所）大力推进道路扬尘污染点题整治工作，组织排查并建立台账，定期调度更新。同时建立健全信息报送制度，依托12345平台监督热线，按照属地管理、分级负责、归口办理，谁主管谁负责、谁审批谁负责，依法、及时、就地解决问题的原则，受理有关道路扬尘污染的投诉举报，并及时分析研判信访数据。采取有力措施强化对薄弱环节的监管。

　　（三）总结阶段（12月1日-12月31日）：各责任单位梳理总结工作成效、经验和好的做法，报市局整改办整理汇总上报。

　　四、保障措施

　　1.强化组织领导。成立由市城市管理局局党组书记任组长、各分管领导任副组长，各县区（管委会）城市管理局(执法局)、住建局（建交局）和市局有关单位（科室）负责人为成员的城市道路扬尘污染点题整治工作领导小组。根据“管行业必须管环保”、“管业务必须管环保”的原则，由各分管领导牵头、各相关业务科室负责开展城市道路扬尘污染防治指导工作。领导小组下设办公室，挂靠在市局市容环卫监管科，具体负责日常事务协调、工作进展汇总、落实情况报告等工作。各县区（管委会）城市管理局（执法局）、住建局（建交局）要及时进行动员部署，强化对整治工作的组织领导。

　　2.注重宣传教育。各单位要加大城市扬尘污染综合整治工作的媒体宣传报道力度，通过官方渠道、新闻媒体，宣传报道扬尘治理先进典型和经验，及时公开曝光反面典型。同时，要坚持“开门”搞整治，积极拓宽群众监督举报渠道，营造全民参与的良好氛围。各单位每月至少完成1篇工作信息宣传报道，并将相关情况上报市局整改办（附件5）。

　　3.包片督导帮扶。根据《市整治城市扬尘污染问题 改善城市空气质量工作方案》要求，市局包片督导帮扶涵江区，不定期组织开展下沉督导，及时发现问题，督促整改落实。

　　4.加强材料报送。各单位按各自职责对扬尘整治工作情况实行周调度并存档备查，要落实月、季报告制度，每月25日前各责任单位将工作进展（附件2）、问题清单（附件3）及信访汇总表（附件4），每个季度首月5日前将上季度工作开展情况上报至市局牵头科室（责任单位中的第一家），由牵头科室报市局整改办汇总。（报送邮箱：ptsgjb@126.com，联系人：陈婷婷，联系电话：2626233）。
