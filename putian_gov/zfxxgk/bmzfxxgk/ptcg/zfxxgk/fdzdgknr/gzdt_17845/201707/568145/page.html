关于印发《莆田市城市管理行政执法局2017年度绩效管理工作方案》的通知

发布时间：2017-07-17 08:52
| | |
政策解读:

局机关各科室、局属各单位：

　　经局务会研究，现将《莆田市城市管理行政执法局2017年度绩效管理工作方案》印发给你们，请认真组织实施。

　　莆田市城市管理行政执法局

　　2017年7月14日

　　（此件主动公开）  

莆田市城市管理行政执法局2017年度绩效管理工作方案

　　根据《中共莆田市委办公室 莆田市人民政府办公室关于印发2017年度绩效管理工作方案的通知》（莆委办〔2017〕46号）精神，结合局工作实际，现就2017年度绩效管理工作制定方案如下。

　　一、组织领导

　　调整市城市管理行政执法局机关效能建设领导小组成员，组长由局党组书记、局长卓继祖担任，副组长由局领导张建山、郑金清、陈小宇、林万春担任，成员由局机关科室、局属各单位负责人组成，下设办公室挂靠局效能办。

　　二、考评对象

　　（一）单位

　　根据我局机构设置和职能职责特点，将14个单位（以下用单位“简称”）列入考评。

　　1、局机关（5个）：政治部、办公室、法制科、业务科、行装科。

　　2、所属单位（6个）：一大队(含三、四中队、指挥中心)、

　　环卫处、广告办、生物质处、城管考评中心、荔盛公司。

　　3、临时机构（市执法局借调人员，3个）：城管办（含数字城管中心）、治违办、共建办。

　　（二）个人

　　局机关各科室、局属各单位、临时机构内市执法局借调的干部职工及协管员（以下简称干部职工）。

　　三、考评内容

　　考评采取指标考核、公众评议、正向激励、察访核验相结合的方式进行。

　　（一）指标考核

　　根据市委、市政府对我局绩效考评的12个一级指标、26个二级指标，进行责任分解和考核。

　　（二）公众评议

　　由局政治部结合年度考核民主测评适时开展。

　　（三）正向激励

　　鼓励各科室、单位（干部职工）结合实际创造性开展工作，卓有成效完成各项任务。

　　（四）察访核验

　　处级干部察访核验由市效能办负责。局效能办结合日常效能督查，采用随机抽查、问题核查、明察暗访等方式，不定期组织对各考评对象开展察访核验。发现的问题按照《效能督查发现问题绩效考评扣分办法》（莆效办〔2016〕15号）及局考勤、保密、信息报送等工作要求，以倒扣分形式计入绩效考评总分。各被考评单位参照本方案要求，对本单位现岗位的干部职工（含协管员）进行察访核验。

　　四、结果汇总与运用

　　（一）结果汇总

　　1．处级干部绩效考评得分=分管科室绩效考评平均分+正向激励加分－察访核验扣分。

　　2．科室、单位绩效考评得分=指标考核得分×60%＋公众评议得分×40%+正向激励加分－察访核验扣分。

　　3．科级及以下干部职工绩效考评得分=科室绩效考评得分×30%+个人指标考核得分×30%＋公众评议得分×40%+正向激励加分－察访核验扣分。

　　4．个人年度指标考核得分=（个人自评得分＋监督审评得分＋负责人核评得分＋分管领导点评得分）÷4＋年度加总。

　　（二）等次确定

　　1．考评结果分为优秀、良好、一般三个等次

　　（1）局主要领导按照市对我局绩效考评结果确定个人绩效考评等次，市对我局绩效考评为优秀、良好、一般（含差）时，个人绩效考评等次分别为优秀、良好、一般等次。

　　（2）其他处级干部按绩效考评得分高低排列，排在前30%（含）的为优秀（评为优秀等次的处级干部不能超过单位处级干部总数的30%），其他80分（含）以上的为良好，60分（含）至80分的为一般，60分以下的为差。

　　（3）科室、单位（科级及以下干部）按绩效考评得分高低排列，优秀等次控制在30%（含）以内，一般等次控制在10%（含）以内，其他的为良好等次（具体等次比例由局务会根据考评得分研究确定）。

　　（4）个人年度指标考核得分由机关各科室、局属各单位自行负责，统一采用“个人自评、考勤审评、负责人核评、分管领导点评”四级评方式，每月对干部职工（含协管员）履职尽责及作风出勤等情况进行考核。个人月考核总分为10分，年度总分为120分。将干部职工（含协管员）当月四级得分进行平均，算出个人“月得分”，再将个人全年“月得分”进行加总，得出个人年度指标考核总分。个人月考核结果请各单位于次月6日前报局政治部备案，局政治部负责统计各单位报备情况，逾期将按规定减（扣）该单位年度绩效考评分。

　　2．符合下列情形之一的科室、单位（干部职工），直接评为优秀等次（直接评为优秀等次的人数超过干部总数30%时，按绩效考评得分高低排序）：

　　（1）受到部级以上单位表彰（表扬）、推广或领导批示肯定。

　　（2）获省效能办绩效考评激励加分。

　　（3）负责省住房建厅年度单项工作考评居全省第1名。

　　（4）负责省住建厅年度单项工作考评在全省位次比上一年提升3名以上。

　　（5）在建设美丽莆田工作中成效显著。

　　（6）负责市对我局年度绩效考评评为优秀等次。

　　3. 符合下列情形之一的，评为良好以上等次：

　　（1）受到厅级以上单位表彰（表扬）、推广或领导批示肯定。

　　（2）负责省住建厅年度单项工作考评居全省第2-3名。

　　（3）负责市对我局年度绩效考评评为良好等次。

　　4. 出现下列情形之一的，不能评为优秀等次：

　　（1）年度请病假累计超过2个月。

　　（2）年度请事假累计超过8个工作日。

　　（3）存在旷工问题。

　　5. 出现下列情形之一的，直接评为一般等次：

　　（1）负责省对市绩效考评指标、省住建厅年度单项工作考评居全省后2位且位次比上一年没有上升（不含平潭综合实验区，涉及负责多个指标的单位按照综合排位运用）。

　　（2）《莆田市城市管理行政执法局关于落实<建设美丽莆田2017年行动计划>的通知》重点任务（6项重点工作、20项配合工作）严重滞后。

　　（3）受到党政纪责任追究（含组织处理、诫勉谈话）、效能问责；

　　（4）不依法办事或不作为、乱作为，引发群体性事件，造成恶劣影响或严重后果的；

　　（5）社会治安综合治理工作出现严重问题，被一票否决的；

　　（6）生态文明建设工作中出现严重问题，发生重大以上环境污染事件，造成恶劣影响或严重后果的；

　　（7）发生重大以上安全生产（含食品安全）责任事故，造成恶劣影响或严重后果的；

　　（8）被上级查实或通报存在作风纪律问题；

　　（9）旷工超过5个工作日；

　　（10）在绩效管理工作中弄虚作假。

　　6. 市对我局绩效考评为一般等次时，处级干部（不含局主要领导，下同）不能评为优秀等次；市对我局绩效考评为差等次时，处级干部评为一般等次（直接评为优秀等次的除外）。

　　（三）结果运用

　　1. 通报考评结果。局效能办牵头组织对各被考评单位进行年度绩效考评，绩效考评结果在全局进行通报。各被考评单位负责组织对本单位现岗位的干部职工（含协管员）进行个人年度指标考核，考核结果在单位内部进行通报。

　　2. 挂钩考核评定。绩效考评结果作为单位内部评优评先、干部使用、绩效奖励差异化发放的重要依据，激励干部多干事、干成事。

　　（1）市对我局绩效考评为优秀等次时，负责市对我局绩效考评的科室负责人、经办人年度考核直接定为优秀等次；市对我局绩效考评为良好等次时，负责市对我局绩效考评的科室负责人、经办人年度考核定为称职以上等次。

　　（2）评为优秀等次的科室，科室负责人年度考核直接定为优秀等次（存在不能评为优秀等次的其他情形除外）。评为优秀、良好、一般等次的单位（局机关科室除外），科级及以下干部年度考核优秀等次比例分别按20%、15%、12%核定（优秀等次人数控制在市公务员局核定指标范围内）。

　　（3）在当年度省对市绩效考评任务落实、市本级绩效考评等工作中表现突出的一线干部，报市机关效能建设领导小组予以通报表扬。

　　（4）评为一般等次的科室、单位，科室、单位负责人一年内不推荐评先评优、提拔任用。

　　（5）评为一般等次的个人，一年内不推荐评先评优、提拔任用。

　　3. 实行绩效奖励

　　（1）绩效奖励由局行装科、政治部、效能办组织实施，对局机关科室、单位及个人实行年度绩效奖励差别性发放，局考评对象年度考评结果与绩效奖励发放方案一并报局务会议定。 

　　（2）优秀等次、一般等次分别按照良好等次个人绩效奖金的1.2倍、0.5倍发放绩效奖金。

　　（3）凡受到党政纪责任追究、效能问责的人员，年度考核被评为不称职（不合格）的人员，被省委、省政府、省效能办查实或通报存在作风纪律问题的人员，绩效考评结果为差的单位人员，不予绩效奖励（其中由单位自查并给予诫勉教育、通报批评、效能告诫等效能问责的人员，分别可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假累计超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发（每日减发标准为个人日应发工资额）；旷工人员按病事假超期人员标准的5倍减发绩效奖励。

　　（4）广告办进驻市行政服务中心审批服务窗口工作人员按照市行政服务中心管委会或我局绩效考评等次按“就高原则”发放绩效奖励。由市行政服务中心管委会制定实施窗口工作人员差异化绩效补助考评方案，对窗口工作人员实行差异化绩效补助。

　　（5）局效能办不列入局年度绩效考评，办工作人员（正式在编）按照当年度局机关在市绩效考评等次及本方案关于差别性发放规定发放绩效奖励。

　　（6）由于工作人员借调到局机关科室、单位，城管考评中心工作人员（正式在编）按照当年度局机关在市绩效考评等次及本方案关于差别性发放规定发放绩效奖励。

　　4. 实施效能问责

　　按照《福建省机关效能建设工作条例》、《莆田市城市管理行政执法局提升工作执行力的管理规定》（莆执党组[2016]13号）规定实施效能问责。

　　（1）年度绩效考评结果为一般的科室（科级及以下干部职工），责成其向局机关效能建设领导小组提交书面整改措施。

　　（2）省、市效能督查发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫（含）以上处理，对科室负责人进行通报批评，存在突出问题的对局分管领导进行诫勉教育。 

　　（3）被全局通报批评2次以上（含2次）的干部职工，视情节予以诫勉教育及以上的效能问责；被效能问责的干部职工，当年度继续违反工作纪律的，移送驻住建局纪检组查处。

　　五、实施步骤

　　（一）制定方案，动员部署（2017年6月10日-6月30日）

　　按照《2017年度莆田市绩效管理工作方案》要求，认真研究制定《莆田市城市管理行政执法局2017年度绩效管理工作方案》，明确目标任务和责任分工。组织全局干部职工认真学习绩效管理工作有关会议精神和文件规定，充分认识开展绩效管理工作的重要性和必要性，切实增强做好绩效管理工作的积极性和自觉性，扎实推动工作开展。

　　（二）组织实施，常态管理（2017年7月1日-12月31日）

　　建立绩效目标工作台账，加强日常跟踪督促，推进工作落实到位。治违办、城管办要分别做好“2017年度县（区）科学发展目标绩效考核指标体系”中“‘两违’综合治理工作和城市综合管理考评”的每月数据采集工作，年度采集指标数据经征求各县（区、管委会）治违办、城管办意见后于2018年1月20日报局效能办；业务科、办公室要及时与市直各数据采集单位对接沟通，按要求报送好“2017年度省对市绩效考核指标体系”中涉及我局的“责任或配合落实”的工作（共4项）进展情况；各单位要对照《2017年度莆田市城市管理行政执法局绩效考核指标体系》责任分工和评分标准，认真负责落实各自指标的年度工作目标，注意日常相关资料的收集、分类和存档，并在每月10日之前向局效能办报送各自负责指标的绩效目标工作台账（涉密内容不得公开，配合工作进展也要认真填报）以及提升机关效能、工作绩效方面的工作信息。对未按序时进度完成、进度不够明显的工作指标，要注意分析存在的问题及原因，及时采取有效措施加以推进，确保我局各项绩效工作指标保质保量完成。局效能办要及时汇总各科室、单位绩效目标工作台账并公开。

　　（三）分析汇总，迎接检查（2018年1月1日-3月31日）

　　2018年3月底前，市效能办、市直机关党工委联合组织对我局开展指标核验。各指标落实牵头责任科室、单位要对照绩效管理工作方案，全面系统地对各自负责落实指标工作进行自我评估和客观分析，认真收集相关迎检资料，并于2018年1月10日前报到局效能办。局效能办要收集、汇总各科室、单位相关迎检材料，进行自我评估，形成全面、完善的迎检材料，撰写自评报告于2018年1 月31日前送市效能办；根据市效能办、市直机关党工委的安排，认真做好绩效迎检工作。

　　（四）内部考评，整改提升（2018年4月1日-4月30日）

　　市对我局绩效考评检查结束后，结合考核组反馈的情况，局机关科室、所属单位及各临时办组织对内部干部的差异化绩效考评，考评结果报局效能办汇总，并报局务会研究确定。各科室、单位要针对绩效考评反馈存在的问题和不足，及时进行深入分析，查找问题症结原因，制定整改措施，推动全局工作科学化水平进一步提升。整改情况纳入下一年度绩效考评。

　　六、工作要求

　　（一）统一思想认识。树立正确的绩效价值观，把绩效管理作为行政管理的一项基本制度，增强主体责任意识。各科室、单位负责人是本科室、单位绩效管理工作第一责任人，对本科室、单位的绩效管理工作负总责，要指定专人负责绩效考评工作（人员名单于7月18日前报局效能办）。全局上下要继续贯彻“马上就办”的工作作风，共同提升全局工作效能，共同维护全局良好形象，全力争取在全市绩效考评中保持优秀等次。

　　（二）强化统筹协调。机关效能建设领导小组及其办公室要充分发挥组织协调作用，统筹协调相关科室，做好各个环节的衔接，提升整体工作合力。机关效能建设领导小组办公室每季度要检查各科室完成绩效考评各项工作和绩效目标工作台账建设情况，及时发现问题，及时协调解决，确保绩效管理工作顺利开展。

　　（三）强化结果应用。各科室、单位要以严谨细致、务实求效的作风共同做好绩效管理工作，做到资料真实完整，数据准确可靠，台账规范有序。要坚决防止和克服形式主义，坚决制止马虎应付、弄虚作假现象。
