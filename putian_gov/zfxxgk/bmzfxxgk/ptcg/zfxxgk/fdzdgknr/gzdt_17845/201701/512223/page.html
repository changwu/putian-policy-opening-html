2016年度政府信息公开年度报告

发布时间：2017-01-11 08:29
| | |
政策解读:

　　根据《中华人民共和国政府信息公开条例》（以下简称《条例》）、《福建省政府信息公开办法》（以下简称《办法》）规定，以及《莆田市人民政府办公室关于做好2016年政府信息公开工作年度报告有关事项的通知》（莆政办网传〔2016〕41号）要求，特向社会公布市城市管理行政执法局2016年度信息公开年度报告。本报告由概述、主动公开政府信息情况、依申请公开政府信息办理情况、政府信息公开的收费及减免情况、因政府信息公开申请行政复议和提起行政诉讼的情况、政府信息公开工作存在的主要问题及改进措施、需要说明的其他事项与附表共七个部分组成。本报告中所列数据的统计期限自2016年1月1日起至2016年12月31日止，报告全文将在莆田市城市管理行政执法局门户网站（www.ptcgzf.gov.cn）“政府信息公开年度报告”栏目上公布，并报送莆田市档案馆和图书馆，欢迎查阅。如对本报告有任何疑问，请与莆田市城市管理行政执法局办公室联系（地址：城厢区凤凰山街道筱塘北街283号；邮编：351100；电话：0594-2618836；传真：0594-2618856）。

　　一、概述

　　2016年，我局认真贯彻实施《条例》、《办法》，按照省、市政府的统一部署，加强组织领导，健全公开机制，分解落实政府信息公开工作要点，深化公开内容，拓展优化公开形式，扎实推进全局政府信息公开工作，切实保障公民知情权、参与权和监督权。

　　（一）政务公开工作部署和落实情况

　　一是细化公开内容，扎实落实工作要点

　　按照《关于印发<2016年莆田市政务公开工作要点>的通知》要求（莆政务公开办〔2016〕1号）抓好工作落实，结合我局工作实际制定印发《关于印发<2016年莆田市城市管理行政执法局政务公开工作要点>的通知》（莆执综[2016]16号）、《关于进一步做好2016年政务公开工作的通知》（莆执综[2016]24号）等文件，对2016年我局政府信息公开工作进行细化部署。

　　二是围绕中心工作，全面推进政务公开

　　1、围绕深化改革推进公开。（1）在局网站上全面公开部门权力清单和责任清单，公开执法人员名单；（2）在局网站上及时公开取消、下放、保留行政审批事项，2016年9月2日上网公开市审改办、行政服务中心及执法局三部门联合下发的《关于店招设置登记退出属地行政服务中心窗口及加强事中事后监管的通知》。（3）推进监管执法信息公开，按月在局网站公开批后跟踪情况、行政处罚案件办理情况，按件公开行政处罚案件信用情况，截至12月31日已经公开17例；（4）推进“互联网＋政务”，市广告办在市行政服务中心综合窗口牵头受理户外广告设置许可公共服务事项，并将相关政务服务事项提交进入市行政服务中心网上办事大厅进行办理；（5）通过设置政务公开栏、印发便民服务卡及办事指南、在局网站公开办事信息等方式积极推进公共企事业单位办事公开。

　　2、围绕促进经济发展推进公开。（1）推动政府和社会资本合作（PPP）项目的信息公开，在局网站上完成莆田市餐厨垃圾处置场项目环境影响评价公示、审批前公示、批复前公示，通过公开招投标确定市餐厨垃圾处置场PPP项目专业咨询机构，通过局网站、中国招标网等平台发布公告，并召开项目市场测试会；（2）加强国有企业运营情况监管，按季度公开荔盛公司的三公经费及采购费用并报市财政局，不定期对荔盛公司整体运营情况、国有资产保值增值情况进行检查。

　　3、围绕民生改善推进公开。及时公开就业供求信息，做好国有企事业单位人员招录信息和人力资源市场供求信息的发布工作。2016年，通过春季全省公务员招考公开招考2名工作人员；荔盛公司在福建海峡网公开发布7个岗位招录信息，公开招聘11人，目前公开在招岗位3个。

　　4、围绕助力政府建设推进公开。（1）推进环境卫生、环卫基础设施等重大民生决策事项民意调查制度，2016年4月组织专家并征求各县区环卫部门等意见，对公厕外观样式进行论证；2016年6月征求各县区环卫部门及相关单位意见、组织省市专家论证后出台《莆田市生活垃圾转运站建设技术标准》；2016年11月分别召开《莆田市招牌标示设置导则》研讨与专家论证会和餐厨垃圾处置场实施方案论证会；（2）围绕政府工作报告、发展规划提出的重要事项，制作月工作台账，按月公布进展和完成情况。2016年，我局牵头办理的30座公厕市级为民办实事项目全部完工并投入使用，完成总投资2054万元，占年度计划投资的114.1%；（3）推进单位预决算公开，按照要求按月及时公开局机关及局属各单位“三公”经费，按季度公开物资采购情况，及时公开2015年度决算及2016年度预算。

　　5、围绕扩大政务参与加强解读回应。（1）及时发布重要政策的解读，截至12月31日共公开政策解读14份，其中我局自行公开的政策解读4份；（2）按照市信息公开办、市政府新闻办的要求，在局网站新设“最新文件”栏目，用于更新国务院、省政府、市政府网上公开发布的文件，及时传递文件精神和权威信息，截至12月31日已经更新67篇文件；（3）组建网络文明传播队伍，开设“网络求真”专栏，第一时间核实网传事件真相，及时回应群众声音；建立并落实防台风防汛防暴雨应急带班值班制度，做好应急响应和防御工作。

　　6、围绕增强公开实效加强能力建设。（1）积极做好政府规章和政策性文件清理工作，加强规范性文件公开审查，及时公开我局代拟的相关规范性文件，确保应公开尽公开；（2）严格执行保密审查制度，对拟公开的政府信息依法依规做好保密审查；（3）开设《城市管理你我他》栏目，每周在市电视台播放，增进与公众互动交流，从2015年开播至今共录播30期；（4）指定专人负责主动公开信息送交工作，2016年分别向市档案馆和图书馆报送信息公开材料各40份；（5）组织各单位、各科室负责政务公开工作的人员参加政务公开培训，学习相关文件精神，每两周通报政务公开工作情况。

　　（二）公开制度建设情况

　　结合工作实际，我局建立并完善《政务公开责任制度》、《政务公开检查监督制度》、《信息公开保密审核制度》等配套制度，并将政务（信息）公开工作纳入绩效管理进行跟踪考评。

　　（三）工作组织、机构、人员情况

　　我局切实加强对政务（信息）公开工作的组织领导，成立局政务（信息）公开工作领导小组，由局长任组长，其他局领导任副组长，局属各单位负责人为成员。领导小组下设办公室，挂靠在局办公室，配备一名专职工作人员，负责日常事务的处理、协调等工作。局属各单位都相应成立信息公开工作机构，分别指定专人负责及时收集、报送本单位需要公开的信息及文件材料，并对局网站页面内容的发布、更新等进行监测。

　　（四）工作经费投入情况

　　我局将信息公开工作经费纳入年度预算，配备专用电脑及打印机等设备。每月定期在《湄洲日报》上公开城市综合管理考评和“两违”工作考评结果，公示“两违”集中拆除案件。与莆田电视台合作开设《城市管理你我他》栏目，每周在市电视台播放，栏目宣传费用合计90万元，共制作44期，从2015年开播至今已经录播30期。

　　（五）公开渠道建设和利用情况等内容

　　局门户网站是我局政府信息公开的主要载体，2016年我局门户网站正式并入市政府网站集群，使我局门户网站的功能更加齐全、特征更加明显、页面更加鲜活、内容更加规范、更加方便市民使用。此外，我局还利用莆田市政府网站、市电视台、湄洲日报等载体多方位、全过程地公开政府信息；利用政务公开栏、市档案局及市图书馆信息查阅中心等，提供资料查阅，拓宽政府信息公开的广度和深度，进一步方便市民查询、利用。

　　二、主动公开政府信息情况

　　我局政府信息公开工作严格遵循“谁主管、谁负责；谁公开、谁审查”的原则，对拟公开的政府信息进行保密审查，做到积极稳妥、及时准确、公开公正、便民利民。

　　（一）本机关主动公开政府信息的数量

　　2016年我局共主动公开政府信息40条，历年累计主动公开政府信息759条。

　　（二）主动公开政府信息的主要类别情况

　　2016年重点公开了以下政府信息：机构职能，部门文件，政策规定，资金监管，其他应主动公开信息等内容，其中：机构职能类7条，部门文件类19条，政策规定类6条，资金监管类6条，其他信息2条。

　　（三）主动公开政府信息的形式

　　1、政府门户网站。我局积极建设网上公开平台，开设政府信息公开专栏，做到信息目录公开，链接信息原文，附件上传完整。专栏设置政府信息公开目录、依申请公开、政府信息公开规定、年度报告、政府信息公开指南、意见箱及监督渠道等子栏目。

　　2、政府信息查阅中心。目前，我局今年公开的信息文件已全部送到市档案馆和市图书馆进行公开，供公众查阅。

　　3、通过电话、电子信箱、传真电话，实行人工答复。

　　4、通过莆田电视台开设《城市管理你我他》专栏，通过《湄洲日报》，宣传城市管理工作。

　　（四）开展政策解读工作情况 

　　在局门户网站上开设“政策解读”专栏，切实加大政策解读工作力度，2016年共公开政策解读14份，其中我局自行公开的政策解读4份，分别是关于加强莆田市城区生活垃圾分类试点工作、莆田市生活垃圾转运站建设技术标准、莆田市餐厨垃圾管理实施意见和进一步改善农村人居环境共建美丽乡村实施意见等4份文件。

　　（五）回应社会关切情况 

　　建立并实行环境卫生、环卫基础设施等重大民生决策事项民意调查制度，组织省市专家论证后出台《莆田市生活垃圾转运站建设技术标准》，分别召开《莆田市招牌标示设置导则》研讨与专家论证会和餐厨垃圾处置场实施方案论证会。建立城市管理行政执法舆情监测处置制度，建立监测网络，及时借助网站等渠道发布准确权威信息，回应群众关切。通过网上调查、民意征集等广泛征求群众意见，充分尊重民意，引导公众参与。2016年共发布网上调查3期、民意征集3期、在线访谈3期。

　　三、政府信息依申请公开办理情况

　　我局在网站中设置了受理电子邮箱，并在网站上提供了依申请公开表格的下载和直接发送。2016年我局未接到政府信息公开申请。

　　四、政府信息公开的收费及减免情况

　　我局2016年度及历年政府信息公开均未收费。

　　五、因政府信息公开申请行政复议、提起行政诉讼情况

　　我局2016年度无因政府信息公开申请行政复议、提起行政诉讼和举报情况。

　　六、政府信息公开工作存在的主要问题及改进措施

　　2016年，我局政府信息公开工作扎实有效开展、成效明显，但仍存在一些不足：一是政策解读的形式有待进一步改进、完善；二是公开还是以主动发布为主，与市民互动仍有不足。

　　2017年，我局将深入贯彻落实中央、省、市信息公开工作有关要求，坚持落实政府信息公开各项制度，继续加大公开力度、深化公开内容，继续加强政府信息公开监督检查，确保政府信息公开工作人员到位、责任到位，不断夯实工作基础，着力把政府信息公开工作办成一个群众满意的民心工程。
