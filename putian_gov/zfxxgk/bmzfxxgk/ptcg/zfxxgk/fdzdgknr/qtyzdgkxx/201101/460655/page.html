莆田市城市管理委员会办公室关于迎新春开展市容环境卫生整治的通知

发布时间：2011-01-27 08:00
| | |
政策解读:

各区人民政府、管委会、市直有关单位：

　　2011年春节将至，认真做好节日期间各项工作，确保全市人民过一个欢乐祥和、节俭文明的节日，对于深入贯彻落实科学发展观，实施“跨越发展、宜居港城”的战略部署，推动实现“十二五”时期开好局、起好步，夺取全面建设小康社会新胜利，以优异成绩迎接中国共产党成立90周年，具有重要意义。市委、市政府对做好节日期间工作十分重视，要求各级各单位认真贯彻落实党中央、国务院和省委、省政府的部署，全面做好关心群众生产生活等工作。现就抓好2011年春节期间城市管理，以清新净美、整洁有序的城市环境喜迎新春佳节，通知如下：

　　1、美化临街各种设施。对主次街道上建筑物立面脏污破损的，要进行清洗、维护；沿街店招、贴墙广告、公交站台、电话亭、店面雨披、遮阳篷和垃圾箱陈旧损坏的要进行维护更新。

　　2、清理乱占道经营现象。对大街小巷乱占道经营现象进行一次全面检查，彻底清理，取缔未经批准的乱占道摆摊、乱占道维修加工，店外店，摊外摊及流动摊贩。。

　　3、清理市区“牛皮癣”。对临街建筑物立面、围墙，街道上电线杆、街路牌、公交站台、变压器、报栏等设施上乱张贴、乱涂写的各种小广告进行彻底清理。

　　4、环境卫生每天20小时保洁 

　　要组织开展一次环境卫生大扫除，在抓好主次街道清扫保洁的同时，重点抓好背街小巷、居住小区、城中村、城乡结合部以及城际之间交通干道两侧的环境卫生清理，疏通沟渠、清理杂草、清除垃圾、杂物，消灭卫生死角；组织机关企事业单位进行室内外卫生大扫除。按照省运会期间做法，中心市区每天从4:00至24:00，实行20小时清扫保洁，确保城区洁新净美。

　　5、市区交通秩序整治 

　　检查维护城市交通设施，道路隔离护栏陈旧、破损和护栏广告破损的要进行更换，机动车停车位、人行道自行车停车位标志模糊的要重新上漆；规范市区交通行为，加强日常路面巡查和重点路段、路口值勤，查处违规驾驶行为，纠正自行车、摩托车、汽车乱停放现象，确保各种车辆按位停靠，停放有序，保持市区交通良好秩序。

　　6、园林绿化整治 

　　对城区及城际主要交通干道的绿化隔离带、绿篱、绿地、城区行道树、道路绿化树进行一次全面修剪；绿化带被种菜或踩踏成空白地的进行补植、恢复；清理绿化带、绿地的垃圾杂物，清理绿化树下堆放的渣土石块，保持园林绿化的整齐美观。 

　　7、市政道路整治 

　　清理占道堆放；恢复破路路面；维护广告设施；乱拉乱挂布条广告清理；检修道路照明和夜景工程设施，排除故障隐患，确保路灯和夜景工程设施处于良好工作状态。

　　8、建筑工地和工程车滴撒漏整治 

　　建筑工地围墙破损陈旧的要进行修补、粉刷，墙体上设置的宣传标语、广告破损的要进行更换或拆除。加强对施工运输车辆的监管，督促落实工程车滴撒漏的防患措施，按规定的时间、路线行驶，对出现滴洒漏要及时进行清理，杜绝滴洒漏大面积污染道路现象的发生。

　　9、农贸市场的卫生整治 

　　加强农贸市场卫生管理，落实农贸市场管理规定，规范农贸市场经营秩序，查处对农贸市场内外乱搭乱建、乱堆乱放、乱泼乱倒等影响市场卫生的行为，确保农贸市场内外有序经营。让市民有个卫生、安全、有序的购物环境。

　　10、加强城区河道环境卫生整治 

　　加强城区河道环境卫生管理，落实河道保洁制度，组织打捞河面漂浮物，清除河岸垃圾，查处纠正向河道河岸乱扔乱倒垃圾行为，有条件的要向河道放水，冲排污水，净化河道水质，提高河道水质。

　　各区、管委会及市城管办成员单位要把城市管理专项整治作为一项重要工作来抓，按照整治的通知精神组织实施，确保整治质量，保证春节期间的市容环境卫生整治工作落到实处，为广大市民欢度新春佳节营造整洁、有序、优美的城市环境。市城管办将组织对各单位的整治落实情况进行检查。

　　二〇一一年一月二十一日
