关于开展城管执法领域安全生产百日攻坚促提升行动的通知

发布时间：2018-11-26 08:43
| | |
政策解读:

各区（管委会）执法局、局属各单位：

　　为进一步巩固安全生产“严排查、严整治、严监管”活动成效，推动“严整治、促提升”专项行动增效，全力推进安全生产整治攻坚，遏制各类安全事故发生，根据市安委会《关于印发<安全生产百日攻坚促提升行动方案>的通知》（莆市安〔2018〕14号）及市安办《转发关于进一步加强当前安全生产工作的紧急通知》（莆安办明电〔2018〕12号）等文件精神，现将开展城管执法领域安全生产百日攻坚促提升行动的有关事项通知如下：

　　一、目标任务

　　全面贯彻落实市委、市政府关于开展安全生产百日攻坚活动部署要求，以有效防范和坚决遏制各类安全事故为重点，强化岁末年初等特殊时期安全生产管控措施，着力解决突出问题和薄弱环节，进一步促进全局系统安全生产形势稳定好转。

　　二、时间安排

　　即日起即2019年2月底。

　　三、重点工作

　　（一）宣贯落实党政领导干部安全生产责任制。认真学习贯彻落实《地方党政领导干部安全生产责任制规定》、《福建省党政领导干部安全生产责任制实施细则》，通过举办学习研讨、辅导讨论、专题讲座、集中学习等多种形式，组织党政领导干部进行系统学习，切实增强政治意识、大局意识、核心意识、看齐意识，强化抓好《规定》、《实施细则》贯彻落实的政治自觉和责任自觉。

　　（二）持续深化行业领域专项整治。持续开展安全生产“严整治、促提升”专项行动，突出渣土车、户外广告、违法建设、燃气、环卫及配套设施领域安全生产监管和执法力度，加大对在建项目的监督检查频率，强化部门执法、联合执法，实现对重点目标对象检查执法率达100%，对发现的安全生产违法行为依法查处率达100%，对检查发现存在安全生产问题目标对象的复查率达100%，对举报各类安全生产违法行为的核实查处率达100%，确保本行业领域安定稳定。

　　（三）强化重点时段安全生产管控保障。切实加强重大活动、元旦春节等重点时段安全生产管控保障，盯紧盯牢事故多发易发的部位、场所，切实细化风险防范和隐患治理措施，摸排查清安全风险隐患点，集中力量进行整改，并强化重点时段安全巡查管控力度，落实专业人员及技术保障。密切关注灾害性天气、地质灾害预测预报，加强部门间沟通联系、会商分析。严格执行领导带班和重要岗位24小时值班制度，加强应急准备，确保发生紧急情况及时响应、及时处置。

　　（四）认真开展安全生产问题隐患“回头看”。从严落实安全生产问题隐患整改责任，坚决杜绝安全生产领域各类督查检查出问题“表面整改”“虚假整改”等问题，对2018年以来本地区、本行业领域以及上级各类督查检查查出的隐患和问题整改落实情况进行“回头看”，逐项复查整改情况，并对涉及的企业安全生产情况进行一次全面检查。

　　（五）大力营造安全生产浓厚氛围。深入开展进企业、进公共场所等“七进”宣传活动，全面加强安全生产知识宣传教育和普及，切实增强社会公众安全法制观念和意识。拓宽举报渠道，充分发挥群众监督作用。加强新闻媒体监督，及时曝光与安全生产相关的违法违规典型案例，本次行动期间各区（管委会）执法局在各类媒体平台上曝光不得少于1次，曝光内容可涉及户外广告、渣土车、违法建设等方面。

　　四、工作要求

　　（一）强化组织领导。各单位要高度重视，切实加强安全生产百日攻坚促提升行动的组织领导，做到主要负责人亲自抓，分管负责人具体抓，层层抓紧、抓实、抓好。要召开专题分析研判当前安全生产形势，制定切实可行的工作措施，全力确保完成各项任务。

　　（二）强化排查整改。各单位要对照相关制度规定、规程规范和技术标准要求，制定本行业领域的安全生产检查表，详细列明检查事项、具体内容和检查标准。对排查出的事故隐患和安全风险要做到“4个100%”,即:100%制表列出清单,100%建立台账,100%制订管控措施和整改方案,100%落实事故隐患整改责任、措施、资金、时限、预案“五到位”。要切实加强督促跟踪，实行闭环管理，确保发现的问题隐患整治到位。

　　（三）强化督查指导。各单位要采取暗访暗查、“四不两直”和“双随机”等方式，对本地区本行业领域行动开展情况、工作实效等方面进行认真的督查、检查，市局安办也将不定时开展督导，及时发现问题，及时解决问题，确保行动取得实效。

　　（四）广泛宣传发动。各单位要充分利用电视、报纸、微信、微博、门户网站等各种平台，加大宣传和舆论监督力度，教育引导广大干部职工做好安全生产百日攻坚促提升行动的主动性和自觉性。积极宣传先进典型，激励引导广大干部职工在安全生产工作中勤勉尽责、担当作为。

　　本次行动结束后，请于3个工作日内向市局综合业务科报送工作小结（报送邮箱：zfk6009@126.com）。

 

　　莆田市城市管理行政执法局

　　2018年11月23日
