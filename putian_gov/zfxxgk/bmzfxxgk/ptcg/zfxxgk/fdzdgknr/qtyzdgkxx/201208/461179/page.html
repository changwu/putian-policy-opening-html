关于开展燃气行业安全生产专项整治工作的通知

发布时间：2012-08-28 08:00
| | |
政策解读:

局属各单位：

　　为认真贯彻执行《安全生产法》和《福建省燃气管理条例》，加强燃气行业监督管理，消除事故隐患，遏制重、特大事故发生，确保党的十八大期间燃气行业安全生产，经研究，决定在全市范围内开展燃气行业安全生产专项整治工作。现就有关事项通知如下：

　　　一、整治目标

　　落实科学发展观和“以人为本”理念，牢固树立“安全责任重于泰山”思想，坚持“安全第一、预防为主”方针，按照“政府部门依法监管，企业个人积极参与”的工作原则，通过专项整治，进一步落实安全生产主体责任，增强燃气企业安全管理意识；规范我市燃气经营市场，查处和取缔无证经营和违规经营的燃气企业及供应站点；查处违规施工损坏燃气管道和设施的行为，有效预防和控制各类事故发生，为党的十八大胜利召开创造良好的安全生产环境。

　　　二、整治范围

　　专项整治工作在全市范围（仙游县除外）开展，重点是各区（管委会）的城区、乡镇所在地、燃气企业及供应站点、燃气管线设施的保护范围内。

　　三、整治内容

　　(一)未经许可从事燃气经营活动（管道燃气特许经营、燃气经营、汽车加气经营、燃气销售）的;

　　(二)向未取得燃气经营许可证的单位或者个人提供用于经营的燃气的；

　　(三)燃气经营者、燃气用户及相关单位和个人在不具备安全条件的场所储存燃气的；

　　(四)在燃气设施保护范围内从事爆破、取土等作业或者动用明火的；倾倒、排放腐蚀性物质的；放置易燃易爆物品或者种植深根植物的；未与燃气经营者共同制定燃气设施保护方案，采取相应的安全保护措施，从事敷设管道、打桩、顶进、挖掘、钻探等可能影响燃气设施安全活动的；建设占压地下燃气管线的建筑物、构筑物或者其他设施的；

　　(五)侵占、毁损、擅自拆除、移动燃气设施或者擅自改动市政燃气设施或燃气设施安全警示标志的。

　　　四、方法步骤

　　坚持属地为主与行业督导相结合，企业自查自纠与政府督查相结合，全面排查与重点整治相结合，日常巡查与明查暗访相结合，监督检查与联合执法相结合。从2012年8月25日开始，到11月底结束，分四个阶段进行：

　　（一）动员部署阶段（2012年8月25日-9月15日）

　　1、传达部署。传达市里有关燃气安全生产专项整治的文件和会议精神，成立整治机构，制定整治方案，明确整治内容，分解整治任务，部署落实整治工作。

　　2、普查建档。加强与住建等部门及所在地乡镇（街）、村（居）的联系，对本辖区内从事燃气生产经营的单位（个人）进行全面排查摸底，掌握合法经营的燃气企业及供应站点的有关情况并建立档案，取得燃气无证经营点的相关线索。加强与燃气企业的联系，掌握燃气管线等燃气设施的分布、具体位置的有关基础资料并建立档案。

　　3、宣传教育。采取上门入户宣传、设点接受咨询、车载宣传、LED广告宣传、新闻媒体宣传等方式，向燃气生产经营单位（个人）和广大市民宣传燃气管理法律法规和安全生产知识，督促燃气生产经营单位（个人）规范经营，按规定存气、供气，教育广大市民安全用气。设立并公布举报投诉电话，可以采取有奖举报措施鼓励群众举报燃气无证经营等违法违规行为。

　　（二）集中整治阶段（2012年9月16日-10月15日）

　　集中人员、集中力量对辖区开展拉网式排查检查，依法查处各类燃气违法违规行为。对燃气经营单位（个人）违法经营、燃气设施安全保护范围内违法施工和违法建设、侵占或移动燃气设施等燃气违法行为，责令限期整改；拒不整改的，依法从重处罚；对无证经营的，依法取缔。

　　（三）巩固提高阶段（2012年10月16日-11月15日）

　　开展专项整治“回头看”，巩固整改成果。同时，加派巡查人员，加强对重点区域、重点路段、重点时段、重点单位的监管，保障燃气行业健康、安全运转，为十八大召开营造一个安全、有序的社会环境。

　　（四）总结验收阶段（2012年11月16日-11月30日）

　　市局组织对各分局整治工作开展情况进行检查验收，对工作有力、成效明显单位予以表彰，对工作不力的单位予以通报批评，并把考评结果与单位评先评优相挂钩。同时认真总结好的经验、做法，积极探索燃气市场安全管理工作新思路，研究建立长效监督管理机制。

　　五、有关要求

　　1、加强领导，抓好落实。

　　燃气安全生产事关人民群众生命财产安全，事关社会安定稳定大局。各单位领导务必统一思想认识，高度重视整治工作。为加强对整治工作的组织领导，市局成立以分管副局长为组长，局机关相关科室和各分局负责人为成员的整治工作领导小组，下设办公室，挂靠在综合业务科。各单位也要相应成立燃气安全专项整治领导小组，主要领导亲自抓，分管领导具体抓，力求将这项工作抓紧、抓好、抓实，抓出成效。

　　2、认真排查，深化整治。

　　燃气违法违规行为特别是无证经营行为，隐蔽性强、危害性大。各单位要全面巡查、认真排查，积极通过群众举报、部门通报、查找“黑气”广告、询问送气工等方式查找无证经营点，综合采用暂扣、处罚、查封等措施，大力查处燃气无证经营等违法行为，净化燃气市场，维护燃气行业安全、有序。

　　3、强化联合，齐抓共管。

　　燃气管理涉及住建、公安、安监、质监等多个部门，是一项系统工程。各单位要加强与相关部门的沟通联系，互通信息；要开展经常性的联合执法活动，形成部门联动、齐抓共管的长效监管机制。

　　莆田市城市管理行政执法局

　　2012年8月28日
