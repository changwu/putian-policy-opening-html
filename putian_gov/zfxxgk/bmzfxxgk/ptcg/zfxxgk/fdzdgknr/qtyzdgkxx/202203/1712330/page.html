关于分解落实2022年市委市政府为民办实事活动相关任务的通知

发布时间：2022-03-18 11:08
| | |
政策解读:

局机关各科室，局属有关单位：

根据市委、市政府《关于开展2022年为民办实事活动的通知》（莆委〔2022〕20号）精神，现将我局牵头主办的4项和协办的9项任务分解如下，请认真抓好落实。

一、牵头主办任务（4项）

（一）改造提升市政道路无障碍设施

主要内容：改造提升市政道路无障碍设施，实施东圳路人行道、仙游县城区主次干道人行道、北岸经济开发区学府路人行道等3个项目。

责任单位：市政公用科、市政维护处

（二）建设城区生活垃圾分类屋（亭）

主要内容：计划在全市各城区建设生活垃圾分类屋（亭）145座。其中，仙游县40座，荔城区30座，城厢区20座，涵江区30座，秀屿区10座，湄洲岛5座，北岸10座。有害垃圾处理设施、可回收物回收管理、再生资源综合利用体系完成年度建设任务。

责任单位：市容环卫科、市环卫处

（三）创建城区生活垃圾分类示范区

主要内容：计划在荔城区主城区创建省级生活垃圾分类示范区建设，形成深化示范、以点带面的工作格局，实现“三个全覆盖”，即生活垃圾分类管理主体责任全覆盖，生活垃圾分类类别全覆盖，生活垃圾分类投放、收集运输、处理系统全覆盖。

责任单位：市容环卫科、市环卫处

（四）实施易涝点整治工程（市政排水系统改造）

主要内容：计划实施易涝点市政排水改造10处，其中：市本级2处（荔城大道与莆阳路交叉万达红绿处排水管道清淤疏浚、迎宾大道建发段建发·央著—文龙路排水系统），荔城区5处（城港大道下坂段排水系统、莆兴路与谷城西路双赢物流桥洞、东井街排水系统、仪莘路雨水管网建设、西洪路馨宜新天地段排水系统），城厢区2处（华林工业园区段排水系统、学园南街城厢区法院段排水系统），秀屿区1处（莆兴路云悦壹号排水系统）。

责任单位：市政公用科、市政维护处

二、协办任务（9项）

（一）治理“餐桌污染”、建设“食品放心工程”

主要内容：（一）加强食品和食用农产品安全监管。重点围绕与人民群众关系密切的“五类产品、一个行业”（即畜牧业产品、种植业产品、水产品、饮用水、加工食品和餐饮业），深入开展食品安全日常监管、专项治理、检验检测、宣传教育、举报奖励、违法违规行为查处等，推进国家食品安全示范城市创建工作。（二）开展农药兽药使用减量和产地环境净化、食品加工质量和婴幼儿配方乳粉质量安全提升、校园食品安全守护、农村假冒伪劣食品治理、保健食品行业专项清理整治、进口食品“国门守护”等专项行动，严厉查处食品安全违法违规行为。（三）推进食品安全示范建设。新认证无公害农产品、绿色食品、有机食品和农产品地理标志产品10个以上，积极组织申报“福建十大农产品区域公用品牌”和“福建名牌农产品”评选认定，创建省级餐饮食品安全“明厨亮灶”示范单位10家以上。（四）推进食品安全“一品一码”全过程追溯体系建设。（五）做好食品污染物及食品中有害因素监测、食源性疾病监测等工作，防控食品安全风险隐患。

市直主办单位：市食安办

我局责任单位：执法协调科

（二）综合治理海漂垃圾

主要内容：（一）常态化清理海漂垃圾，特别是清理处置海上养殖升级改造所产生的废旧渔业养殖设施，保障海湾水清滩净。（二）完善海上环卫建设，对原先组建海上环卫队伍，进一步加强人员、设备和管理等方面能力建设，确保海漂垃圾常态化、专业化治理效果。（三）健全海漂垃圾综合治理长效机制，压实海漂垃圾网格化巡查和清理责任，推动“美丽海岸带”建设10公里，提升群众滨海体验。（四）加强“数字化”监管，建设县区交界海岸段及重点岸段海漂垃圾高清智能视频探头14个。

市直主办单位：市生态环境局

我局责任单位：市容环卫科、市环境集团

（三）市政生活污水管网建设

主要内容：新建或改造城镇生活污水管网60公里，其中市直5公里，县区（管委会）55公里。

市直主办单位：市住建局、水务集团

我局责任单位：市政公用科、市政维护处

（四）城镇老旧小区改造

主要内容：实施改造城镇老旧小区项目49个，涉及3000户。改造内容包含雨污分流、通信管网整合下地、天燃气入户、道路修缮、房屋修缮加固、小区环境及绿化景观提升、停车场整治及充电桩建设、小区照明提升、适老化设施改造等。

市直主办单位：市住建局

我局责任单位：市政公用科、市容环卫科、市燃管处

（五）城乡福道建设

主要内容：新建和改造提升福道35公里（包括城乡绿道、森林步道、登山步道、自行车道等），其中市本级（东圳水库坝头至木兰陂沿渠福道）18公里，仙游县、荔城区、城厢区、涵江区、湄洲岛各3公里，秀屿区、北岸各1公里。

市直主办单位：市住建局

我局责任单位：市容环卫科、市政公用科 

（六）电动汽车公共充电桩建设

主要内容：计划新建电动汽车公共充电桩200个（标准桩）以上，加快形成适度超前、快充为主、慢充为辅的公共充电网络，便利群众绿色出行。

市直主办单位：市工信局、莆田供电公司

我局责任单位：市政公用科

（七）泗华溪水环境整治及泗华郊野公园建设

主要内容：开展泗华溪沿溪入河排污口“全口径”排查整治，完成各类水质超标排污口溯源治理和泗华溪清淤工程。其中，城厢区负责完成项目用地征收工作；市园林集团负责建设公园绿道2公里、提升改造公园绿地5万平方米。

市直主办单位：市住建局、生态环境局

我局责任单位：市政公用科、市政维护处

（八）实施易涝点整治工程（雨污网管分流改造）

主要内容：计划对下店路、莆仙大剧院周边、东圳路、学园南街、荔城大道与东园路交叉口、溪南路、学园南街城厢区法院段等7个路段实施雨污网管分流改造。

市直主办单位：市住建局、水务集团

我局责任单位：市政公用科、市政维护处

（九）“综治+”社区治理中心建设

主要内容：在第二批58个试点村居（社区）建成集综治网格、治安防控、矛盾纠纷调解、法律服务、平安支援服务、应急处置等为一体的“综治+”社区治理中心，其中仙游县10个、荔城区10个、城厢区10个、涵江区10个、秀屿区10个、湄洲岛3个、北岸5个。

市直主办单位：市委政法委

我局责任单位：执法协调科、市政公用科、数字城管中心

三、工作要求

为民办实事项目进展情况实行月报告制度，落实情况纳入年度绩效运用。属于我局牵头主办的项目，要加强统筹协调，细化实施措施，倒排时间节点，实行挂图作战，由市容环卫科、市政公用科分别指定专人负责，由市容环卫科统一汇总后于每月2日前上报市政府督查室；属于我局协办的项目，要密切配合主办单位，积极主动作为，认真抓好落实并按要求报送进展情况。

 

 

          莆田市城市管理局
