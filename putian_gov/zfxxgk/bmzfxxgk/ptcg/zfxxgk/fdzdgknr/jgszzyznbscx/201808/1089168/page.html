关于许金潘同志退休的通知

发布时间：2018-08-01 16:17
| | |
政策解读:

市环卫处：

你单位工勤人员许金潘，男，汉族，秀屿东峤人，1958年8月出生，1976年3月参加工作，参公管理单位工勤人员身份，现聘任为技师。

根据《中华人民共和国公务员法》、国务院国发〔1978〕104号文件等规定，经研究决定，同意许金潘同志于2018年8月退休。

 

 

 

 

                     莆田市城市管理行政执法局

                              2018年8月1日
