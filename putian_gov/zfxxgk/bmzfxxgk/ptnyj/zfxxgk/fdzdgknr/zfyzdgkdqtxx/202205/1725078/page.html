莆田市农业农村局关于市八届人大一次会议第0101号建议的答复

发布时间：2022-04-28 16:22
| | |

郭雄新代表：

您提出的《关于全面支持仙游县乡村振兴战略工作的建议》（第0101号）收悉，现答复如下：

一、推动产业品牌培育

一是打造产业集群。按照主导产业突出、规模效益显著、产业链条健全、综合竞争力强的总体要求，全面启动闽东南高优蔬菜优势特色产业集群（仙游）、福建柑橘优势特色产业集群（仙游）、福建铁观音优势特色产业集群（仙游）、福建蜜柚优势特色产业集群（仙游）、福建枇杷优势特色产业集群（仙游、涵江）、福建龙眼荔枝优势特色产业集群（仙游）等6个列入省级“十四五”期间拟建设的优势特色产业集群备选名单建设，打造乡村产业区域增长极和产业高地；二是打造试点典型。仙游县文旦柚产业园还获得省级产业园称号，获得省级补助资金1000万元；度尾镇湘溪村、书峰乡书峰村、龙华镇金溪村、钟山镇朗桥村等11个村先后获得国家、省市级一村一品示范村，为全市最多；三是推动休闲农业发展。2021年以来新培育2家省级休闲农业示范点和3个福建省美丽休闲乡村，其中仙游县金湖格生态茶庄园获评2021年福建省休闲农业示范点；仙游县石苍乡济川村获评2021年中国美丽休闲乡村。

二、加大资金扶持力度

仙游县共有22个村庄作为省级乡村振兴试点村，为全市最多。22个省级乡村振兴试点村平均每村每年获得200万元的的专项资金支持，用于试点村基础设施和公共服务的改善提升，截止当前，已获得专项补助资金1.32亿元。此外，仙游县还有3个村（榜头镇光埔村、书峰乡四黄村、西苑乡前溪村）获得省级乡村振兴实绩突出村，各获得省级400万元奖励补助金。全市共有6个省级乡村振兴特色乡镇，仙游占2个（钟山镇和度尾镇），为各县区中数额最多的，其中钟山镇获得2020年度省级乡村振兴重点特色乡镇荣誉称号，获得1000万元的奖励。

三、盘活土地资源

打造了“壶兰乡村”综合平台，包含乡村闲置土地流转服务，已归集含仙游县在内的近3万亩待流转土地，并为企业扩产增效提供千余亩优质土地。此外，仙游农商银行以仙游县被列为农村承包土地经营权抵押贷款试点县为契机，因地制宜，探索推出“农地+农户+合作社+征信”的“自助式担保融资”模式，实现了“一地两用”：一方面，村民以农村承包土地经营权入股农民合作社，并获得合作社收益分红；另一方面，由农民合作社担保，以入股的农村承包土地经营权反担保，对村民进行授信。该模式的推出得到各级有关部门的认可，全国政协办公厅在了解其运作情况后，专门编辑了信息稿件转送中国人民银行办公厅，以供借鉴推广；国家发展改革委办公厅将其选定为第一批国家新型城镇化综合试点经验，成为莆田市唯一一条入选经验。

四、推动人才资源回归

开展第六批驻村第一书记和莆田学院规划人才驻村帮扶工作，有效推动机关和高校人才下沉服务仙游县基层；大力扶持自主创业，强化创业担保贷款支持，对首次创办企业的高校毕业生、返乡创业人员等给予5000-10000元的一次性创业补贴；对市级优秀创业项目给予3-10万元资助，对省级资助项目，在省级补助的基础上予以1:1等额配套补助，有效吸引人才、乡贤回归。同时，注重推动和支持仙游县发展一批“土专家”“田秀才”，扶持培养一批农业职业经理人、经纪人、乡村工匠、文化能人、非遗传承人等。全面深入推行科技特派员制度，引导科技特派员提供互联网化的多形式科技服务，促进科技特派员工作向仙游县农村一二三产业拓展。
