莆田市农业农村局关于市八届人大五次会议第1237号建议的答复

发布时间：2025-04-07 16:24
| | |
 杨少龙代表：

《关于实施乡村振兴战略，促进城乡融合发展的建议》（第1237号）收悉，现答复如下：

一、稳妥有序加快乡村建设。完成新一轮村庄分类工作，按照初、中、高三个版本等级和村庄分类类型为村庄属性赋标。去年以来，深化电信普遍服务试点，持续拓展镇区千兆光网和5G网络覆盖，实现100%乡镇地区和重点行政村5G覆盖。推进城乡供水一体化建设，铺设管网721公里，新增受益人口超8万人。完成22个公共充电站，建成乡镇充电桩5187个。推进农村建设品质提升行动，实施26项重点任务、33个任务指标，完成投资15.5亿元，投资完成率133.94%。持续推进木兰溪流域7个乡村振兴重点片区建设，相关做法得到省委领导肯定，并作为全省优秀案例推广。5个乡镇、56个村成为省级乡村振兴示范镇、村创建对象，全市绿盈乡村占比94.27%。完成农村公路新改建50.4公里、危桥改造5座。接续实施农村人居环境五年提升行动，打造“五个美丽”建设点3365个。

二、聚焦农业推进产业兴旺。践行大食物观，入围联合国粮农组织支持的中国生态低碳大食物系统项目区（为华南地区唯一项目区）。落实“菜篮子”市长负责制，确保猪肉、果蔬、水产品等主要农产品稳产保供。推动渔业高质量发展，全球首座漂浮式风渔融合平台投产，新增南日镇、黄石镇为国家产业强镇建设项目立项。去年以来，开展农业绿色发展促乡村振兴工作，创建省级农业产业化联合体3个、省级“一村一品”专业村12个。仙游县获评福建省2024年联农带农典型示范奖补县，仙游甜柿列入农业农村部2024年农业品牌精品培育计划，度尾文旦柚入选“土特产”名录，新增全国名特优新农产品8个、绿色食品33个。2024年全市一产增加值完成152.36亿元，同比增长3.4%，居全省第5位，位次比2023年前进3位。农村居民人均可支配收入达到28093元，同比增长6.8%，增幅居全省第3位，位次比2023年前进5位。

三、打造乡村文旅品牌。整合优质乡村文旅资源，策划推出了多条微度假、亲子游、红色游、美食游等丰富多样的旅游线路，不断丰富产品供给。城厢区入选福建省县域文旅经济工作正向激励，受到省政府表彰。兴化府历史文化街区延续街区历史风貌的做法获全国推广，获评省活力“街艺”示范区。《缘起湄洲》《印象妈祖》等沉浸式文旅演艺项目成为新IP。新增省级“全域生态旅游小镇”3个、“金牌旅游村”2个，市级“全域生态旅游小镇”4个、“金牌旅游村”10个。《三餐四季》《山水间的家》在双福村、南日岛等地开展文旅专题栏目摄制工作，并在央视播出，有效带动乡村消费，农民增收。

四、全力推动乡村人才振兴。建强村级班子，开展村党组织书记“练兵比武”活动。实施村党组织书记力量储备三年行动，探索提升村居干部待遇、激励担当作为等举措，开办“田间课堂”，2024年以来累计举办220场乡村规划、特色种养殖、农产品加工等个性化导师帮带培训课堂，开展高素质农民培训10085人次。选拔一批有志从事农业的农村青年壮年、返乡农民工和退役军人，到农业大中专院校接受继续教育。深入实施科技特派员制度，积极发挥驻村第一书记作用，开展“农业专家八闽行”活动。引进乡村（镇）教师602名、医生35名，培育省级乡村工匠名师5人，选派127人支教、支医、支农帮扶乡村振兴。

五、加大金融扶持力度。面对市级财政困难局势，始终坚持农业农村优先发展，2024年全市一般公共预算农林水支出达173759万元，增长6.27%。全年土地出让收入用于农业农村比例超土地出让收益的50%。2024年市本级共投入乡村振兴资金14196万元，比2023年略有增长。同时，推动金融服务机构覆盖面提升，推动建立财政、银行、保险、担保“四位一体”的多元化立体型支农政策体系，大力发展普惠金融。建立健全多渠道乡村振兴、美丽乡村投入保障制度，优化财政支出结构，充分发挥财政资金引导作用，利用国有企业投融资平台,运用PPP等投融资方式，撬动金融和社会资本更多投向乡村振兴。推进乡村振兴贷落实落细，缓解中小微农业企业融资难、融资贵、融资慢难题。

感谢您对我市乡村振兴工作关心与支持！
