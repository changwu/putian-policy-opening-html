莆田市农业农村局关于市政协八届四次会议第20252032号提案办理情况的答复

发布时间：2025-07-22 19:01
| | |
 林忠华委员：

您提出的《关于完善强农惠农富农支持制度、建设和美乡村的建议》（第20252032号）收悉，我单位的办理意见如下：

一、完善农村集体经营性建设用地入市制度。一是健全制度。农村集体经营性建设用地入市试点工作开展以来，市自然资源局强化指导跟踪，与荔城区政府组织区发改、税务、财政等相关部门共同学习研究国家及省厅出台的有关政策文件，并前往晋江等地考察学习先进做法，指导荔城区政府着手对荔城区的现状存量集体建设用地面积及拟入市的存量集体建设用地面积进行摸底，根据法律法规制定了《关于建立农村集体经营性建设用地使用权入市试点工作协调机制的通知》(荔政办〔2024〕4号)、《关于印发莆田市荔城区农村集体经营性建设用地入市实施办法的通知》(荔政规〔2024〕2号)、《关于公布荔城区集体建设用地基准地价的通知》(荔政规〔2024〕3号)、《莆田市荔城区农村集体经营性建设用地入市收益分配指导意见》(荔政办规〔2024〕1号)等相关政策制度，同时强化村庄规划编制或修编。二是试点先行。北高镇福岭村小学地块（1.68亩）、北高镇埕前村集体经营性建设用地地块（5.8亩）已成功入市挂牌拍卖，分别拍得107万元、785万元。

二、推进乡村建设和乡村发展。一是实施专项行动。出台《学习“千万工程”经验建设美丽乡村三年行动方案》《莆田市“片区化”跨村联建推进木兰溪全流域共同富裕实施方案》，提质木兰溪流域7个重点片区，扩面60个共富片区，引领带动、迭代梯次推进全域初、中、高级版本的美丽乡村建设。落实发展壮大村级集体经济三年行动《实施方案》和《激励办法》，带动村强民富。二是产业发展“一村一策”。依托“全市一张图”开发乡村振兴版块即“和美莆田 数字乡村综合服务平台”，从重中之重的乡村产业入手，通过经营性收入、五大振兴成效评价、村庄分类、初中高三个版本、乡村振兴示范创建村等参数赋标，为全市972个村（社区）精准画像。完善“三表一库”（资产负债表、资源性资产清查登记表、经营性固定资产清查登记表和乡村人才库），用好用活用足产业发展清单、问题清单、服务清单，一村一策靶向发力。

三、深入实施科技特派员制度。一是“科技副总”赋能。近两年多来，累计3批51人次“科技副总”服务莆田市重点产业链的科技型企业。“科技副总”指导企业参与创新创业大赛3项，主持企业研发项目30多项，指导和协助企业申报专利20多项，开展创新创业培训500多人次，组织在校学生到企业开展实习350多人次。协助企业建立了“校企合作研究平台”“经济融合服务平台”等8个创新平台，推动企业申报省“科创中国”博士创新站2个，组建博士创新团队2个，建立本科生校外实习基地、研究生联合培养基地6个。二是提高服务效能。全市54个乡镇（街道）科技特派员工作站全覆盖，科技特派员个人服务实现全市行政村全覆盖。引进、推广应用新品种、新技术、新工艺、新装置2000多个，培训群众5万人次，新认定市级科技特派员示范基地10个，科技特派员助推产业发展的成效日益凸显。不断健全乡村振兴的科技特派员制度和管理体系，形成了“政府推动、部门配合、制度保障、注重实效”的工作模式。

四、强化基层党组织战斗堡垒。一是建强队伍。实施村党组织书记力量储备三年行动，常态化开展村党组织书记“练兵比武”，分层分类举办村主干产业专题培训班，着力提升基层干部能力素质。制定出台《莆田市发展壮大村级集体经济激励办法（试行）》，分四个区间对村集体经济发展有突出贡献的村居干部给予梯次奖励，有效激发干部积极性，提升村集体经济收入。如，城厢区积极开展人才“带富先锋”行动，挖掘培育有文化、懂技术、会经营的农业技术人才和种养大户等72人加入党员队伍，培养95名党员致富带头人任职村干部，通过“党支部＋党员＋农户”模式，带动农民参与土地流转、发展特色产业。注重发挥群众主人翁作用，让党的领导坚强有力，群众自治充满活力。二是做强服务。开展新一轮“机关+农村”党组织结对共建，制定挂钩联系村（社区）服务队伍建设管理办法，107个市直单位和村党组织结对共建，选派216名驻村第一书记，推动“三官一律”等力量全员下沉，建立“一村一支服务队”，推动任务、问题、发展“三张清单”线上流转处置。当前，全市组建挂钩联系村居服务队973支，1130名挂钩领导、1061个共建单位、7269名服务队成员下沉服务村居，指导村居围绕园林花卉、休闲文旅、果蔬种植、渔业生产等，逐村制定产业发展对策清单，帮助基层党组织进一步理清发展思路。三是增强收入。全域建立“一村一档、一村一策”，探索片区化模式推动跨村联建，建立木兰溪流域7个乡村振兴重点片区党委，推动100多个村党组织签订产业发展联建协议书，推动乡村振兴抱团发展。2024年，“破壳消薄”资金收益兑现村集体1.84亿元。如，涵江区积极依托“一乡一业、一村一品”打造区域公共品牌，推出梅洋茗茶、双福荔枝、广山麻花等近百个优质品牌产品，通过设立驻村驿站、驻村第一书记直播带货，常态化举办各类活动，实现村民增富、村财增收。
