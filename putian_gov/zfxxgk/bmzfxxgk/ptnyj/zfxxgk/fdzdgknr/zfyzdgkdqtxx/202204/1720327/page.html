莆田市农业农村局关于市八届人大一次会议第0065号建议的答复

发布时间：2022-04-11 10:54
| | |

林素平代表：

你提出的《关于做好土地流动工作的建议》收悉，现答复如下：

一、办理情况

（一）关于“加大土地流转政策宣传教育力度”的建议落实情况

为让农民群众放心流转农村土地，我局以稳定农村土地承包关系为工作重点，强化宣传培训，全面落实农村土地承包经营权确权登记颁证工作，给农民群众流转土地吃上“定心丸”。近年来，我市加大《农村土地承包法》、《农村土地经营权流转管理办法》宣传力度，连续两年利用春节期间两个月的时间在莆田市电视台黄金时段滚动宣传农村土地承包政策，进一步提高农民群众参与农村土地流转及确权登记颁证的积极性和主动性；借助广播电视、《湄洲日报》等新闻媒体，专题报道农村土地承包政策，营造干群联动的农村土地流转及确权登记颁证工作氛围。全市共培训农村土地确权业务人员2000多人次，分发宣传单2.4万份，发放政策挂图200份，以及订购分发新修订《农村土地承包法》《农村土地承包经营权确权登记颁证技术教程》2200多本。

（二）关于“政府相关部门制定具体配套措施”的建议落实情况

1.制定配套措施。以市府办名义先后出台了《关于印发莆田市农村土地承包经营权流转实施细则的通知（试行）》《关于印发莆田市加强农村土地承包经营权流转工作管理与服务实施方案的通知》《莆田市完善农村土地所有权承包权经营权分置办法的实施方案》文件，规定了农村土地流转的原则、方式、条件、程序，以及管理和服务、体系建设、政策扶持等措施，引导规范有序开展土地流转。同时，联合市振兴乡村集团建设全市统一的土地流转信息服务平台，及时发布土地流转供求信息。先后建立了市农村土地确权登记颁证和土地流转工作领导机构，强化对农村土地承包管理工作的领导；各涉农县区、乡镇都建立了农村土地流转服务中心，为流转双方提供政策咨询、合同签订、备案、鉴证等便捷服务，进一步指导农村土地流转双方的行为。

2.稳定农村土地承包关系。按照全省统一部署，我市全面组织开展农村土地承包经营权确权登记颁证工作，通过成立工作领导机构，制定实施方案，召开部署会议，举办培训班，加强检查验收以及启动约谈等各种行之有效的措施，全市全面完成农村土地确权登记颁证工作，涉及承包户47.9万户，家庭承包面积65.18万亩，确权数据库通过农业农村部验收，切实为农村承包地确实权、颁铁证，让农民群众放心流转土地。

（三）关于“支持农村土地流转”的建议落实情况

1.健全管理机制。为规范工商资本租赁承包耕地的监管，促进工商和社会资本依法投资农业，加快现代农业发展。我市5个涉农县区都出台了工商资本租赁农地监管和风险防范办法，明确规定工商资本租赁农地要坚持依法自愿有偿、经营规模适度和农地农用的原则，不损害农民权益、不改变土地用途、不破坏农业综合生产能力和农业生态环境。同时，加强事中事后监管，建立工商资本租赁农地资格审查、项目审核制度，健全多方参与、管理规范的风险防范机制。

2.落实扶持政策。我市出台一系列农村土地流转扶持政策，促进山区抛荒地的复耕复种，激活土地资源。对规模利用山区抛荒耕地的各类新型农业经营主体，市县两级财政给予耕地流转实行一次性奖励，连片流转山区耕地20亩以上的，每亩奖励200元，2018-2020年共落实奖励面积6500多亩，兑现奖励130多万元，2021年加大奖励力度，增加奖励金额，给予每亩奖励300元，也将于近期落实到位。同时，对规模种植中稻、晚稻和旱粮作物20亩以上的各类新型经营主体，每亩补助300元；对经过山垅田改造，规模种植粮食作物的各类新型经营主体，头三年每年再另外补助200元。以上补助市、县两级财政各承担一半，仅2021年市级财政落实补助资金167.28万元，补助面积11152亩（次），促进农村土地流转，增加农民收入。

3.盘活土地经营权。为推动农村土地所有权、承包权、经营权分置有序实施，以市委办、市府办名义印发了《莆田市完善农村土地所有权承包权经营权分置办法的实施方案》，在全面完成农村承包地确权、稳定土地承包权的基础上，放活土地经营权，积极引导承包农户采取出租、托管、股份合作等方式向农业经营主体流转土地，做大农业产业化规模。特别是引导已建成高标准农田流向新型农业经营主体，发展集约化生产、规模化经营，全面提升土地生产能力。指导仙游县实施农业生产社会化服务项目，完成每年全程耕地托管面积3000亩，促进了小农户和现代农业的有机衔接。截止2021年12月底，全市农村土地流转面积16.51万亩，流转率达25.33%。

4.建立健全纠纷调解仲裁体系。为及时有效化解农村土地流转纠纷，促进平安乡村建设，我市全面建立健全农村土地承包经营纠纷调解仲裁体系。截止目前，全市5个涉农县区均成立了县级纠纷调解仲裁委员会，46涉农乡镇设立了调解委员会，705个村组设立了村级调解小组（或指定专职调解员），全市共配备乡镇调解员269个，村级调解员1614人，通过不断地完善体系，确保农村土地流转纠纷“小事不出村，大事不出镇”，切实把问题解决在基层。

二、下一步工作安排

虽然我市农村土地流转工作取得一定成效，但县区之间工作开展不平衡，与周边地区比、与农民期望要求还有一定差距。下一步，我们将按照代表的建议意见，持续创新体制机制，探索新的流转模式，盘活农村集体土地资源，促进乡村振兴。

（一）宣传教育，提高思想认识。持续加大宣传力度，深入细致地做好群众工作，营造良好工作氛围。继续宣传农村土地流转的法律、法规及政策，让农民群众了解自发土地流转的隐患及问题，引导其进入乡镇流转服务平台备案、鉴证、交易，提升农民群众规范土地流转的意愿，逐渐让“土地必须规范流转”的观念深入人心，实现土地流转备案从“被动”到“主动”的转变。

（二）加强服务指导和扶持。通过多方争取财政资金，落实农村土地流转扶持政策。同时，完善县、镇、村土地流转服务中心建设，对农村土地流转程序、合同签订进行指导，提供政策咨询、免费合同鉴证、纠纷调解等服务，促进土地资源有序流转和优化配置。

（三）强化用途管制。加大对新修订的《农村土地经营权流转管理办法》宣传力度，进一步推动落实工商资本流转农村土地资格审查、项目审核和风险防范制度,实行工商资本租赁农地分级备案，加强事中事后监管，遏制耕地“非农化”，严格管控“非粮化”，促进工商和社会资本规范有序农业投资，保障承包农户合法权益。

（四）激发活力，提高规模效益。加快发展农民合作社、家庭农场等新型农业经营主体，提升农业经营主体发展质量。组织开展省、市、县三级示范社（场）创建工作，今年计划新培育农民合作社示范社、示范家庭农场各20家以上，发挥示范社（场）示范引领作用，促进闲置土地向新型农业经营主体集中，不断扩大土地经营规模，逐步实现规模化种植、集约化经营，促进农民群众持续增收，最大限度地释放土地政策红利。
