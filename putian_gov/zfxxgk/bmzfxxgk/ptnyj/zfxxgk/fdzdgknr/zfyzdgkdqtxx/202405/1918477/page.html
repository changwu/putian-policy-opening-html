莆田市农业农村局关于市八届人大三次会议第1077号建议的答复

发布时间：2024-04-23 15:52
| | |

张玉和代表：

《关于发挥政府引领作用，促进乡村振兴的建议》（第1077号）收悉，现答复如下：

一、加强高标准农田建设。我市各级农业农村部门认真贯彻落实“藏粮于地、藏粮于技”战略，坚决贯彻落实总书记重要指示和党中央重大部署。市委市政府高度重视，把高标准农田建设作为保障粮食安全的关键举措，扎实推进高标准农田建设工作，不断夯实粮食安全根基，进一步提升农业综合生产能力。

（一）加大高标准农田建设相关政策宣传。为更好推动高标准农田建设，促进好的政策落地见效，确保广大农户群众知晓高标准农田建设有关政策，近年来，各级农业农村部门持续开展多渠道多形式宣传活动，提高群众知晓度，共同参与高标准农田建设。

（二）鼓励农业经营主体积极参与项目建设。除以乡镇为项目建设单位外，鼓励、支持家庭农场、农民合作社、种植大户、农业企业等新型农业经营主体以及农村集体经济组织（以下简称经营主体）直接参与高标准农田建设，充分发挥新农人的作用，加快完善农田基础设施。各类经营主体均可直接申报、承担实施高标准农田建设项目。

（三）不断提高高标准农田项目建设标准。高标准农田建设资金投资从2019年亩均标准1600元提高到2024年亩均标准2400元。同时，鼓励社会资金参与、支持高标准农田项目建设，增加社会资金投入，不断提高高标准农田项目建设标准。

通过高标准农田建设，有力提升农村基础设施条件，提升农业综合生产能力，提高防灾抗灾能力，提高农田利用，进一步促进农业增效、农民增收。

二、强化政策引导，鼓励、支持群众复耕复种

按照“因地制宜、粮经结合、三产融合”的思路，积极推广粮食等优质高效农作物，引进农业生产社会化服务组织开展代耕代种代防等社会化服务，避免再抛荒弃耕现象。加快土地流转，大力引进工商户规模化流转土地，以获取较高的种植效益。接续开展“我在乡间有亩田”活动，助力撂荒地复耕复种。对撂荒耕地加大豆科绿肥推广力度，实施秸秆还田，增加有机肥施用，推广测土配方施肥技术等，稳步提升撂荒耕地地力。落实好耕地地力保护补贴、种粮农民一次性补助政策，加大对《稳定粮油生产十六条措施》惠粮政策宣传力度，并重点向撂荒耕地复耕复种倾斜，发挥叠加补助资金作用。加大金融服务农业生产力度，降低“三农”信贷担保门槛，加大粮食种植保险补助，提高赔率，充分调动耕地复耕复种积极性。

    三、建议。我们农业农村部门继续加大高标准农田建设，有效解决田间生产代理、灌排设施，特别对干旱区域建设水塘、机井、蓄水池等工程措施，通过雨水收集、储水、循环利用等技术，一定程度上缓和生产用水问题，但还无法有效解决生产灌溉用水需求。一方面，我们主动沟通水利部门，加大灌区骨干渠建设，解决水库、灌区引水灌溉农业生产问题；另一方面，敬请代表您一起呼吁相关部门加大水源工程建设，突破农业生产用水“最后一公里”。

感谢贵代表对农业农村工作的关注和支持，我们将一如既往地做好“三农”各项工作，服务“三农”、服务群众。
