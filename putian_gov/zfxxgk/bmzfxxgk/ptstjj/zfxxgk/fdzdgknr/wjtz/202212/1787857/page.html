莆田市第七次全国人口普查领导小组办公室关于人口普查立项课题结题验收评审结果的通报

莆人普办〔2022〕4号
发布时间：2022-12-08 15:51
| | |

各县（区、管委会）人口普查领导小组办公室、统计局，有关高等院校、科研机构，市统计局各科室（中心）：

经评审，《莆田市第七次全国人口普查办公室关于人口普查课题立项的通知》（莆人普办〔2022〕3号）确定的26个课题验收合格，其中重点课题2个，一般课题24个。一般课题中，面向高校、科研机构的课题3个，面向各级人普办的课题21个。面向高等院校、科研机构的2个重点课题和3个一般课题安排经费，面向各级人普办的21个一般课题不安排经费。

 

附件：莆田市第七次全国人口普查验收合格课题名单

 

 

 

莆田市第七次全国人口普查领导小组办公室
