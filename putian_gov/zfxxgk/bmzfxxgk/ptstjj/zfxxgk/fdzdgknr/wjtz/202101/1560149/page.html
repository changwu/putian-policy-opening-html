莆田市统计局2020年政府信息公开工作年度报告

莆统〔2021〕2号
发布时间：2021-01-11 11:23
| | |

政府信息公开工作年度报告，是《中华人民共和国政府信息公开条例》确立的法定监督保障制度，是全面反映政府信息公开工作情况的基本方式，是加强政府信息管理、摸清政府信息底数、从政府信息的角度记录并展现政府施政过程及结果的基础，对于改进政府信息公开工作、加强政府自身建设、推动国家治理体系和治理能力现代化具有重要意义。根据《中华人民共和国政府信息公开条例》规定，现将编制的莆田市统计局2020年政府信息公开工作年度报告予以公布。本报告由总体情况、主动公开政府信息情况、收到和处理政府信息公开申请情况、政府信息公开行政复议和行政诉讼情况、存在的主要问题及改进情况、其他需要报告的事项等六个部分组成。报告中所列统计数据时限从2020年1月1日起至2020年12月31日止。本报告在莆田市人民政府网站（http://www.putian.gov.cn)政府信息公开专栏公布。如对本报告有任何疑问，请与莆田市统计局办公室联系（地址：莆田市荔城中大道2169号政府1号楼629室；邮编：351100；电话：0594-2221989；电子邮箱：ptstjj@126.com）。

一、总体情况

2020年以来，我局认真学习贯彻《中华人民共和国政府信息公开条例》，坚持以公开为常态、不公开为例外，遵循公正、公平、合法、便民的原则，进一步深化对政府信息公开工作年度报告重要作用的认识，切实提高工作主动性、自觉性，进一步加强管理、完善制度，切实提高政府信息公开工作质量，推动政府信息公开工作有序开展。

（一）主动公开政府信息的情况。2020年我局结合统计工作实际，主动公开政府信息318条，其中：机构职能类1条，规划计划类2条，统计信息、资金信息、人事信息等其他类信息315条。

（二）收到和处理政府信息公开申请的情况。2020年我局收到依申请公开政府信息6件，均为网络申请，上年度结转依申请公开政府信息0件。我局按规定进行受理并答复，其中“属于已主动公开范围信息数”2件,非我局职能不予公开3件，无相关统计数据不予公开1件。

（三）因政府信息公开工作被申请行政复议、提起行政诉讼的情况。2020年我局无因政府信息公开工作被申请行政复议或提起行政诉讼的情况。

（四）政府信息公开平台建设情况。一是依托市政府门户网站信息公开专栏。加强网站内容建设和信息发布审核，及时公开统计分析、统计数据、统计年鉴、数据公报、资金等信息。二是召开新闻发布会。1月份与市政府新闻办联合举办2019年莆田市经济运行情况暨第四次全国经济普查结果新闻发布会，对全市国民经济和社会发展情况、第四次全国经济普查结果进行解读。三是大力发展新媒体。2020年，局领导现场接听12345热线5期，局“莆田统计”微信公众号发布信息2062条，在“统计微讯”、“福建统计”等国家局、省局新媒体发表信息27条，及时对经济社会发展有关统计数据情况进行解读、积极开展统计法律法规宣传，方便社会各界了解我市经济社会发展情况。

（五）政府信息公开管理情况。2020年6月，先后印发《莆田市统计局关于加强政务新媒体平台管理工作的通知》、《莆田市统计局公共领域宣传载体管理制度》，明确网站栏目、新媒体内容责任分工，指定专人负责公开的政府信息制作、发布、统计等工作，进一步加强政府信息公开工作流程的规范化管理、完善制度，切实提高政府信息公开工作质量，推动政府信息公开工作有序开展。

（六）政府信息公开组织领导和监督保障情况。一是加强学习。2020年多次组织全体干部职工分别学习《中华人民共和国政府信息公开条例》、国办公开办《关于政府信息公开工作年度报告有关事项的通知》。二是完善工作机制。根据人事变动及时调整充实政府信息公开领导小组，有针对性地加强领导，确保内部协调有力。按照《中华人民共和国政府信息公开条例》要求，建立健全政府信息公开申请登记、审核、办理、答复、归档等各项内部工作制度，本年度修订了网络舆情应急预案、网络宣传工作机制和网站内容发布管理办法、政务新媒体管理制度、政务新媒体信息发布审签制度等制度。三是定期开展自查。定期组织栏目责任人对网站发布的信息准确性、是否过时等开展自查，确保信息描述准确、链接正常，维护好政府信息的权威和正确导向。

五、存在的主要问题及改进情况

我局目前存在的主要问题是政府信息公开专栏公开信息内容不丰富、贴合群众需求信息少的问题，针对此问题，我局将进一步做好政府信息公开工作，继续提高思想认识，稳步提升公开质量，加强公开信息管理，继续抓好统计快报、月报、公报、手册、白皮书、年鉴等统计资料编印工作，为党政领导和社会各界提供更加全面翔实的基础数据，利用多种渠道，及时对外提供统计信息和数据资料等政府信息，及时回应社会关切，提供统计信息宣传的传播力和覆盖面。
