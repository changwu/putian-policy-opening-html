莆田市统计局关于2022年度全市统计执法检查情况的通报

发布时间：2023-01-12 10:29
| | |

各县（区）统计局:

2022年，全市各级统计部门深入学习贯彻习近平总书记关于统计工作重要讲话重要指示批示精神，坚决贯彻落实党中央、国务院统计改革决策部署和省委省政府、市委市政府工作要求，认真做好国家统计督察反馈意见整改、统计造假不收手不收敛问题专项纠治和入退库专项检查等工作，顺利完成国家统计局和省统计局、市统计局统计执法检查任务。

据统计，2022年全市各级统计部门共检查单位224家，立案查处统计违法案件15起，结案18起，其中：罚款15起，罚款金额4.3万元；公示失信企业7家；通报曝光2起。

从统计执法检查情况看，全市所有县(区)均开展了执法检查，超额完成年度执法检查任务数。全市各级统计部门要再接再厉，持续巩固深化统计督察反馈意见整改和专项纠治工作成果，为推动高质量发展提供坚实的统计保障。

附件：2022年度莆田市统计执法检查情况汇总表
