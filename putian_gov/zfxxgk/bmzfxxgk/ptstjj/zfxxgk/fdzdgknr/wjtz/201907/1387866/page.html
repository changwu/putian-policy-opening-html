莆田市统计局关于印发2019年全市统计执法监督检查工作计划和统计法治宣传教育工作计划的通知

莆统〔2019〕49号
发布时间：2019-07-17 15:28
| | |

各县(区)统计局、湄洲岛计财局、北岸发改局，市局各科室(中心)：

现将《2019年全市统计执法监督检查工作计划》和《2019年统计法治宣传教育工作计划》印发你们，请结合实际，认真贯彻执行。

附件：1．2019年全市统计执法监督检查工作计划

2．2019年全市统计法治宣传教育工作计划

 

莆田市统计局

2019年7月17日

 

附件1

2019年全市统计执法监督检查工作计划

 

2019年全市统计执法监督检查工作的总体思路是：全面贯彻习近平总书记关于统计工作重要讲话指示批示和中央《关于深化统计管理体制改革提高统计数据真实性的意见》《统计违纪违法责任人处分处理建议办法》和《防范和惩治统计造假、弄虚作假督察工作规定》（以下简称《意见》《办法》《规定》）及省委《关于深化统计管理体制改革提高统计数据真实性的实施意见》（以下简称《实施意见》）等重要文件精神，按照国家局、省局工作会议精神，围绕莆田统计中心工作要求，加大统计执法监督检查力度，严惩统计违法违纪行为，完善统计执法工作机制，从严推进统计执法工作，提高依法治统和数据监管能力，为我市统计管理体制改革和提高统计数据质量提供强有力保障。

一、切实增强防范和惩治统计造假、弄虚作假的责任意识

各级统计机构要将学习贯彻习近平总书记关于统计工作重要讲话指示批示和中央《意见》《办法》《规定》及省委《实施意见》精神作为当前首要政治任务，提高政治站位，牢固树立“四个意识”，始终坚持“四个自信”，自觉做到“两个维护”，清醒认识防范和惩治统计造假、弄虚作假的形势和要求，深刻领会加强统计法治建设对于防范和惩治统计造假、弄虚作假的重要意义，增强推进统计法治建设的自觉性、主动性。采取有效措施，积极推动各地各级各部门持续深入学习贯彻中央《意见》《办法》《规定》及省委《实施意见》，旗帜鲜明反对统计造假、弄虚作假，确保党中央国务院关于统计工作的各项决策部署落地落实。

二、强化监督管理，加大执法队伍建设

（一）加强统计执法监督检查。各级统计机构要加强重点领域、重点地区和单位的监督检查，严肃查处统计违法行为，继续推进消灭统计执法空白县区，保证一定的检查数量和办案数量，提高执法质量和效果，坚决杜绝统计执法只检查不办案的现象。一是继续推进统计执法“双随机”抽查工作。根据“双随机”抽查办法，市局将于今年下半年对涵江区统计局开展统计监督检查，随机抽查检查专业、随机抽取对象，随机抽取执法人员参与检查。各县（区）也要认真开展对五分之一乡镇（街道）的统计监督检查工作。二是开展专业统计数据质量执法检查工作。各专业要根据本专业统计工作的重点内容，认真开展专业数据质量核查和执法检查工作。对有关重要统计指标数字增速异常的地区和相关指标之间匹配性、协调性差的单位；对统计执法空白县或统计执法检查开展不力的、统计法治基础工作薄弱的县（区），作为专业执法检查重点对象。三是开展经济普查专项执法检查。及时查处普查中虚报、瞒报、拒报、迟报，伪造、篡改普查数据的各种违法违纪行为，依法公开普查违法违纪案件的查处情况，为普查工作顺利实施创造良好的舆论环境。四是依法受理统计违法举报案件。主动获取各种统计违法线索，承担受理、核实和处理的责任。对省局移交、群众来信来电举报、媒体披露、领导批示的统计违法案件，及时深入现场调查核实。发现问题及时报告、处理，严肃追究统计造假、弄虚作假责任人责任，努力形成不敢、不能、不想统计造假、弄虚作假的工作氛围。

（二）配合做好首次统计督察。按照督察的相关规定做好各项准备和配合工作。以统计督察推动统计法定职责履行、统计违纪违法现象治理、统计数据质量提升。

（三）健全各级统计执法机构。市局争取成立统计执法监督局，建立全覆盖的统计执法监督检查体系。各县（区）统计局要认真贯彻中央和省委文件精神，抓住深化统计管理体制改革契机，健全法治机构，充实法治力量，选优配强法治工作人员，着力解决统计法治专业人员不足的问题。保障必要的统计执法经费并列入年度预算，配齐必要的执法装备，保证统计执法工作正常开展。

（四）加强执法骨干队伍建设。按照国家、省局要求，继续组织好全国统计执法资格考试参考人员的培训考试工作。强化执法人员业务培训，通过统计执法骨干培训、经普执法培训、案卷评查等方式，加强对执法人员的业务知识培训，不断提高执法人员的法律素养和执法水平。各县（区）要积极选派并支持执法骨干人员参与国家局、省局、市局执法检查工作。

三、完善工作机制，提升依法行政能力

（一）健全规范性文件审查机制。依法履行规范性文件报送备案职责，强化规范性文件监督管理，全面开展合法性审查工作。

（二）健全统计执法检查机制。健全统计执法检查制度，建立统计执法检查责任制，完善统计执法人员培训考试制度和统计违法举报工作制度，建立健全分类查处统计违法案件制度，认真执行国家局《统计执法“双随机”抽查办法》和《统计执法监督检查办法》等，加大对典型统计违法行为的通报曝光力度。

（三）建立干预统计工作记录制度。严格执行领导干部违规干预统计工作记录制度，对以种种手段、措施行政干预统计数据和统计违法案件查处的统计违纪违法行为，各级统计机构和统计人员应当按照中央和国家统计局、省统计局的要求，及时如实予以记录，做到有据可查，全程留痕。

（四）认真落实法律顾问制度。为进一步提高统计部门依法行政、依法管理和依法办事的能力和水平，根据莆田市人民政府《关于建立健全政府法律顾问制度的意见》（莆政综［2016］82号）精神，县（区）统计局要继续认真落实法律顾问制度，实现政府法律顾问制度全覆盖。

（五）继续推广约谈问责制度。针对在统计执法监督检查中发现的重大统计违法违纪行为，贯彻统计法、统计制度不到位，落实上级工作部署不力的以及在社会上造成恶劣影响的地区，市局将继续按照统计行政执法约谈制度对相关县（区）政府和政府有关部门及统计局领导进行约谈。同时，对查处不力、统计数字严重失实的地区、单位负责人进行问责。

（六）继续开展统计执法案卷抽查工作。根据《福建省统计行政处罚案卷规范化暂行规定》和《福建省统计行政处罚案卷评查标准（试行）》的规定，完善统计行政处罚自由裁量标准和统计执法案卷评查制度。年底将组织县(区)统计执法人员，进行交叉检查，开展对执法程序、执法文书、执法案卷等行政执法行为的评查工作，发现问题及时纠正。严格执行执法人员资格制度，提高执法人员的法律素质，逐步提高各县(区)办案质量，力争全市没有行政诉讼、行政复议机关案件。

（七）加快推进统计违法联合惩戒工作。全面落实国务院《社会信用体系建设规划纲要（2014—2020年）》和中央、国家44个部委《关于对统计领域严重失信企业及其有关人员开展联合惩戒的合作备忘录》（修订版）及市政府《莆田市建立完善守信联合激励和失信联合惩戒制度加快推进社会诚信建设的实施方案》（莆政综〔2017〕56号），不断完善统计社会信用制度机制，加快推进实施统计上严重失信企业信息公示和惩戒制度，依法依规公示统计上严重失信企业，促进广大企业依法独立真实上报统计资料。

附件2

2019年全市统计法治宣传教育工作计划

 

2019年是新中国成立70周年，是全面建成小康社会、实现第一个百年奋斗目标的关键之年，也是贯彻实施“七五”普法规划的重要之年。2019年全市统计法治宣传教育工作的总体要求是：以习近平新时代中国特色社会主义思想为引领，贯彻落实党的十九大精神和《意见》《办法》《规定》要求，认真实施全市“七五”普法规划和统计“七五”普法规划，以提高全社会法治意识为目标，认真落实“谁执法谁普法”普法责任制，深入开展《宪法》《统计法》《统计法实施条例》宣传教育，切实加大统计普法力度，进一步增强全社会尊统计法、学统计法、守统计法、用统计法意识，营造良好的统计法治环境。

一、明确目标，推动统计“七五”普法规划的贯彻落实

今年是统计“七五”普法第四年，要全面落实统计“七五”普法规划目标、任务和要求，各县（区）要按照“七五”普法的要求，结合本地工作实际，科学制定2019年统计普法工作计划，要以各级领导干部、统计工作人员和统计调查对象为重点，有针对性开展统计法治宣传教育。重点学习宣传好《统计法》《统计法实施条例》《经济普查条例》及中央《意见》《办法》《规定》、福建《实施意见》等统计法律法规和统计政策性文件。要建立统计普法宣传平台，完善普法制度，及时总结、推广普法经验，整理统计“七五”普法有关资料，切实推动统计“七五”普法工作持续有效开展。

二、围绕重点，以点带面推动全民学法用法

（一）认真抓好党组理论中心组学法工作。进一步完善党组理论中心组、领导班子集体学法活动。高度重视领导干部的学法工作，把法治学习列入党组理论中心组、领导班子集体学法的重要内容，系统学习中国特色社会主义法治理论，学好宪法、监察法以及统计法律法规等。年度党组理论中心组学法活动不少于4次，原则上每季度1次。

（二）切实抓好“关键少数”人员学法用法。全力推动《统计法》《统计法实施条例》《统计违纪违法责任人处分处理建议办法》《防范和惩治统计造假、弄虚作假督察工作规定》等统计法律法规宣传教育进市（县、区）委理论中心组、进党校。加强对党政领导这一“关键少数”人员的统计普法宣传教育工作，进一步提升领导干部对统计法律法规的重视程度，筑牢防范和惩治统计造假弄虚作假的思想防线。

（三）突出抓好政府统计工作人员学法用法。政府统计工作人员要重点学习和掌握统计法律法规和依法行政理论，不断增强统计法治理念，把统计法律法规的各项规定作为行动指南。始终将依法统计、不出假数作为政府统计部门重大政治纪律、政治规矩和政治任务。通过法治培训、法治讲座、法治报告、网上在线学习、普法考试、科室（中心）学习等形式，深入开展政府统计工作人员学习有关法律法规和依法行政相关知识活动。每人每年学法时间不少于40学时，其中集中学习时间不少于16学时。

（四）重点抓好统计调查对象学法遵法。充分利用统计培训会、工作布置会、年报会等载体，把统计违法典型案例、统计法律法规知识、统计信用列入必讲内容，不断提高统计调查对象依法统计的意识。紧抓普查、专项调查、统计执法检查、行政指导、工作检查、调研走访等时机，通过上门送法、检查中普法的方式，向统计调查对象开展面对面的统计法治宣传教育。要因地制宜、因势利导的组织统计人员开展依法统计重要性、统计违法危害性及应承担的法律后果等方面培训，切实增强统计法治宣传教育的针对性和有效性。同时加大对重大统计违法案件通报曝光和统计上严重失信企业的公示力度，充分发挥“查处一案、教育一片、警示一方”的作用。

（五）精准抓好社会公众的法治宣传教育。积极开展统计法律法规宣传教育“进机关、进乡村、进社区、进学校、进企业、进单位”活动，不断增进社会公众对统计法律法规和统计工作的了解，提高对统计工作的支持配合程度，增强维护合法权益的意识。要充分利用“9·20”中国统计开放日、“12·4”国家宪法日和“12·8”《统计法》颁布纪念日、各项法律颁布实施日等时间节点，组织开展形式多样、丰富多彩、人民群众喜闻乐见的统计普法宣传活动，引导社会公众充分了解统计法和统计工作，切实提高全民宪法意识和统计法治意识。

三、丰富形式，推动法治宣传教育创新发展

（一）拓展“互联网+”普法载体平台。新时代是“互联网+”的时代，是大数据时代，年轻一代的统计普法对象更多地是通过互联网学习与交流，了解有关政策，掌握有关法律法规，要进一步转变统计法治宣传教育方式，切实开拓占领“互联网+”平台，例如微博、莆田统计微信公众号等统计普法阵地，通过形式新颖、丰富多彩、互动交流的全新统计普法手段，不断增强统计普法效果。 

（二）扎实推进以案释法警示教育活动。要重视统计违法典型案例的收集，注重发挥以案释法的引导、规范、预防和教育功能，将其作为业务培训、案例指导、法治宣传的重要资料，要根据统计调查对象特点，有针对性开展以案释法工作，促进以案释法与文书说理、舆论宣传工作的有效结合，使之更直观、更形象、更生动，切实增强人民群众对统计法治实践的感受和认知。
