1-8月莆田规模以上服务业稳步增长 后劲不足亟需关注

第六十二期
发布时间：2021-10-12 11:11
| | |

今年以来，全市各级各部门统筹抓好疫情防控与经济社会发展，成效明显，服务业经济稳步增长，平台企业贡献突出，但发展层次偏低、后劲不足、规模偏小，增速提升进位压力较大。

一、运行亮点

（一）商务服务业贡献突出。受福建硕合才储信息科技有限公司、莆田云智薪共享经济信息咨询有限公司、仙游弹好工科技有限公司等企业营业收入大幅增长的拉动，全市商务服务业保持较快增长。1-8月，全市规模以上商务服务业实现营业收入31.99亿元，增长22.2%，增速比上年同期提高8.0个百分点，比其他营利性服务业快6.7个百分点；对全市其他营利性服务业增长的贡献率高达91.3%，拉动增长14.1个百分点，是其他营利性服务业增长的主要支撑点。

（二）软件和信息技术服务业增势迅猛。1-8月，全市规模以上软件和信息技术服务业增势强劲，实现营业收入3.07 亿元，由上年同期的下降29.6%转为增长55.1%，增速高于全省平均水平38.6个百分点。主要原因是福建星宇瀚信息技术有限公司、福建匆匆科技有限公司、硕今（福建）软件开发有限公司等新增平台企业拉动有力，共拉动该行业营业收入增速增长72.0个百分点。

（三）文化体育娱乐业恢复性快速增长。受上年疫情低基数影响，全市文化体育娱乐业呈持续恢复性快速增长态势。1-8月，全市规模以上文化、体育和娱乐业营业收入由上年同期的下降35.8%转为增长73.0%，增速高于全省平均水平34.6个百分点；对全市其他营利性服务业增长的贡献率为20.5%，同比提高41.5个百分点。分行业看，广播、电视、电影和录音制作业由上年同期的下降83.3%转为增长2.1倍，娱乐业由上年同期的下降14.2%转为增长65.2%，文化艺术业由上年同期的下降28.8%转为增长63.8%，体育业由上年同期的下降18.5%转为增长55.1%。

二、主要问题

全市规模以上其他营利性服务业自6月份以来增速逐月回落，1-8月营业收入增长15.5%，增幅分别比1-7月、1-6月和1-5月回落7.1、14.2和19.0个百分点，比全省平均水平低22.2个百分点。

（一）互联网和相关服务业下降明显。1-8月，全市规模以上互联网和相关服务业营业收入由上年同期的增长35.1%转为下降55.8%，降幅较1-5月扩大2.6个百分点，主要原因是福建海丝商品交易中心有限公司、福建泽石网络科技有限公司等6家退库企业负拉动明显，共拉低该行业营业收入增速60.0个百分点；另外，缺乏新增企业拉动也是造成该行业明显下降的重要原因，年度和月度均无新入库企业。

（二）租赁和商务服务业拉动力减弱。占其他营利性服务业营业收入的比重达74.6%的租赁和商务服务业是我市其他营利性服务业的主导行业，增速持续明显回落。1-8月，全市规模以上租赁和商务服务业营业收入增长17.8%，增速分别比1-5月、1-2月和上年同期回落16.1、7.1和4.8个百分点，低于全省平均水平44.3个百分点。分行业看，租赁业持续负增长，营业收入由上年同期的增长1.4倍转为下降11.1%，降幅分别比1-5月和1-2月扩大17.8和15.4个百分点，低于全省平均水平43.0个百分点，主要原因是福建省仙游县松琴机械设备租赁有限公司、莆田市芷文机械租赁有限公司等7家退库企业的影响，共拉低该行业营业收入增速35.7个百分点。商务服务业增速持续回落，营业收入增长22.2%，增速分别比1-5月和1-2月回落15.2和5.3个百分点，低于全省平均水平41.3个百分点。主要原因是瑞智无忧（福建）科技有限公司等大企业今年业务量萎缩及福建远景投资管理有限公司、莆田标准红木交易市场有限公司等18家退库企业影响，共拉低该行业营业收入增速12.1个百分点。

（三）科学研究和技术服务业持续负增长。今年以来，全市规模以上科学研究和技术服务业持续负增长，且降幅呈扩大态势。1-8月，全市该行业营业收入仅1.37亿元，由上年同期的增长10.4%转为下降15.4%，降幅分别比1-5月和1-2月扩大8.8和7.3个百分点。主要原因：一是该行业整体规模小，缺乏大企业拉动，户均规模仅859万元；二是4家退库、停业企业共拉低该行业营业收入增速18.8个百分点。

（四）发展后劲不足。全市其他营利性服务业增长主要靠新增企业拉动，存量企业对其他营利性服务业为负拉动，后劲不足和疫情冲击将导致全年增速提升进位压力较大。2020年末以来，全市新入库其他营利性服务业企业29家，同比减少14家，拉动全市其他营利性服务业营业收入增长17.4个百分点，存量企业拉低其他营利性服务业增速1.9个百分点。

三、工作建议

（一）强化合力提升发展后劲。年度新增入库关口，建议市、县两级各相关职能部门强化分工协作，夯实工作责任，加大力度推动年度新增入库工作，对达规的企业及时纳入统计，确保应统尽统。建立“准规企业库”，对临界未达规模的市场主体归入“准规企业库”，进行储备观察，有针对性地重点予以扶持、培育，对于成长良好、发展潜力大的企业建立跟踪回访机制，加大培育力度，争取尽早达到入库条件。尤其是秀屿区、涵江区其他营利性服务业行业结构单一，容易受行业影响而出现异常波动，需引起重点关注，加大力度积极培育和发展新行业业态，优化行业结构，确保服务业持续健康发展。

（二）精准施策助力全面复苏。为应对疫情带来的冲击,省市都出台了一系列的惠企优惠政策,但当前企业经营面临的困难仍然较多,不同行业对政策的需求也不尽相同,要帮助更多企业走出困境还需要提供更加精准的帮扶措施。建议相关行业主管部门加强对规模以上服务业企业的调研监测，建立服务业企业复工帮扶机制，及时梳理形成行业内受疫情影响严重、濒临破产倒闭的民营中小企业名单，根据不同受损程度，开展精准扶持，特别是创新能力强、发展潜力大的中小企业进行专项帮扶，必要时采取“一企一策”，切实把“服务”送到家、送到位、抓到底，确保惠企政策及时兑现和精准落地。

（三）优化环境提振消费信心。优化服务业的整体消费环境，提升人民群众对于服务业的消费信心。在疫情得到控制后一些群众还是对于外出消费有一定的顾虑，相关职能部门应积极采取措施消除服务业疫情安全隐患，继续毫不放松提高防控风险意识，严格按规定落实好防控措施，确保群众放心消费，大胆消费。另一方面，面对大规模报复性消费的情况，为了避免服务业出现不和谐的因素和保障服务质量和品质，相关部门需要对服务业进行严格的监管和审查。

撰稿：许燕华 阮建霞
