2007年莆田市社会消费品市场分析

发布时间：2008-01-22 00:00
| | |
今年的全社会消费品零售市场，受益于宏观经济趋热、投资规模增幅较大、就业环境进一步改善、居民收入增幅较大的拉动，和以原材料为首的物价上涨等因素影响，全年的消费品零售总额增长较快。全市全年实现社会消费品零售总额172.9 亿元，比上年同期增长18.5%，增幅创十多年来新高，比全省平均增幅高 0.6个百分点，增幅居九个设区市第二位，增幅比最低的地市高3.5个百分点，总量居九地市第六位。分行业看，批发零售贸易业与住宿餐饮业实现了同步增长，分别增长18.8%和17.2%。
一、主要特征
（一）市场总量扩张明显。今年的消费品市场在去年较快增长的平台上，继续保持了较好的增长势头，在以石油和原材料为主的物价上涨影响下，生产成本提高引起商品价格的相应上涨，社会消费品零售额总量下半年开始出现逐月走高的趋势，六至十二月的零售总额分别为13.13亿元、14.12亿元、13.29亿元、14.39亿元、15.50亿元、16.56亿元、17.70亿元，各月与上年同期对比增幅也基本上保持在15个百分点以上。
（二）消费升级成为亮点。伴随着城市居民可支配收入增长16.9%，农民纯收入增长14.3%的较快发展，加上惠及千家万户的广大农村医疗保障制度的建立、中小学义务教育和城乡低保户福利制度的完善，使城乡居民的后顾之忧减少，居民的消费能力与消费热情得到进一步释放。一是房子装修成为居民消费热点。不管新房旧屋，装饰装修已经成为时尚和潮流，房子装修后许多生活电器与家居设备也提前更新换代，由此带动限额以上企业的家用电器和音像器材类零售消费增长33.9%、五金电料类消费增长64.1%、化工材料及制品类增长59.1%、金属材料类增长85.7%。二是品牌产品消费份额扩大。专卖和名牌经营店的生意明显好过经营同类非品牌商品的店铺，越是繁华的商业地段经营利润越好，单价越高的商品专卖店销售比重越多，展示了商家品牌时代的来临，以国美电器连锁集团为代表的家电行业和以万家惠连锁企业为代表的生鲜超市的总体销售额占市场份额的比重稳固上升。两家集团的销售额分别比上年同期增长38.7%和87.2%。三是家用轿车发展较快。随着达中产阶级和小康水平家庭比重的增加，家庭消费方式也在改变，家庭拥有电动车或摩托车已经十分普遍，购买家用小轿车已经成为一种时髦。据统计，2007年全市限额以上企业小轿车的消费达5.8亿元，比上年增长32.4%,占零售消费比重的3.35%，比上年比重的2.99%增加了0.36个百分点。四是休闲娱乐消费同步增长。全国性的集中休假形成的旅游黄金周，让度假和旅游成为人们生活的一项重要内容，据统计，2007年全市住宿餐饮业的消费额为18.9亿元，同比增长17.2%，其中限额以上住宿餐饮业的营业收入3.1亿元，增长20.9%。
（三）做强与做大成为企业发展方向。全市限额以上零售企业的年平均零售额为1858万元，比上年同期增长31.7%，限额以上餐饮业年平均营业收入832万元，比上年同期增长29.4%。亿元市场的年销售总额增长速度为14.0%，而普通农贸市场的全年销售额只增长10%以下。
（四）繁华区域发展快于农村。由于城市商场的商品品种较齐全，质量较有保证，价格更优惠，更能吸引周边的消费者前往购买。特别是位于市区繁华地段，限额以上零售企业、亿元市场和大型生鲜超市的分布更多，使之每平方米营业面积创造出更多的销售额，经济效益远远高于农村集镇。市区的零售额同比增长19.9%，均高于县增长7.0%和县以下增长11.5%的幅度。
（五）主要商业街经营特色明显。商品按类集中经营对买卖双方可产生双赢效应，也是商业发展的一个趋势，经过多年的发展，我市已形成一批特色商业街，如：荔城南路集聚全市一半以上的限额以上餐饮酒店和较大规模的饮食店，为饮食一条街打好基础；步行街、文献路与梅园路主要分布服装、鞋帽与美容用品店。汽车与轿车的销售地点主要集中在西天尾龙山村的福厦路旁；装修与建材主要集中在南门的建材市场附近。
二、存在问题与建议
（一）许多商品集中程度不够。我市市区规模正在扩大，一些专业性较强的商品零散经营，集聚度不高，如缺乏家具市场、地方风味小吃市场、鞋帽市场、内衣与小商品市场、灯饰与开关市场、洁具市场等，给消费者带来许多不便，也给质量监督增加难度。随着市区的不断扩大，建议有关部门加强规划与引导，使各条商业街的经营品种更具专业与特色。
（二）一些服务项目尚待开发。社会经济的发展，使更多的家庭进入小康和中产或富裕阶层，这些人的消费需求也将发生相应改变，许多人消费理念从过去的实用型转向舒适型和享受型过渡，品牌产品越来越受到青睐，专卖店和品牌店的需求比重增大，消费服务的需求向层次多样化、个性多元化、范围扩大化发展。相比之下，许多商家的服务跟不上需求，比如品牌快餐店尚未经营送货上门服务项目，大规模的专卖店和大商场大超市尚未开展网上订货与送货上门业务，等等，给消费者造成不便，抑制了部分消费需求的实现。
（三）销售假冒伪劣商品现象仍存在。构建和谐社会要求商家的诚信经营。但个别大型商场和超市内仍有销售无产家或非正规厂家生产产品的现象，一部分食品被添加有害安全健康的化工产品，严重危害消费者的身体健康，广大消费者对此深恶痛绝，建议有关部门加强监管，严惩销售假冒伪劣商品的商家。同时，要发动消费者进行举报，新闻媒介进行舆论监督。要在电视、报纸和网络上公布不诚信企业的信息，让不法商家付出应有的代价。
                                                                （撰稿：吴碧兰）
