2012年1-8月份莆田市规模以上工业生产形势简析

发布时间：2012-09-18 00:00
| | |

今年以来，面对严峻复杂的国内外经济形势，市委市政府积级应对，牢牢把握稳中求进的总基调，坚定实施工业强市的主战略，着力扩大内需，加快结构调整，全市工业呈现平稳较快的发展态势。1-8月份全部工业实现增加值396.19亿元，占GDP比重53.3%，对GDP增长贡献率达63.2%，拉动经济增长8.0个百分点，工业发挥着促进经济增长“挑大梁、主力军”的作用。

主要特点

（一）工业经济运行总体保持稳定。1-8月份我市规模以上工业实现工业总产值1153.99亿元，比上年同期增长16.6%，增幅比全省平均水平高1.3个百分点，连续六个月居全省九设区市第三位；实现规模工业增加值362.61亿元，比上年同期增长16.6%，比全省平均增速快1.9个百分点，增幅从今年1-2月份第7位升至目前全省九设区市第五位，工业经济呈现稳步增长态势(详见下图)。

1-8月份全市规模以上工业增长趋势图（单位:%）

（二）轻工业发展快于重工业，小微企业逆势上扬。1-8我市规模以上轻工业企业实现工业总产值796.80亿元，比上年同期增长18.9%，重工业实现工业总产值357.19亿元，增长11.8%，轻工业增长快于重工业7.1个百分点，说明目前我市规模以上工业发展仍以轻工业为主。

小微企业是扩大就业、改善民生、激活民间活力、促进社会和谐稳定的有效途径。在工业经济增速总体放缓的大背景下，小微工业企业发展逆势上扬，成为全市工业经济发展的一大亮点。1-8月份我市规模以上小微企业实现工业总产值628.08亿元，比上年同期增长19.0%；大中型工业企业实现工业总产值525.91亿元，增长13.9%，小微企业增长快于大中型企业5.1个百分点。

（三）股份制企业成为拉动全市规模工业增长的主力军。1-8月份规模以上工业各经济类型中股份制企业完成工业总产值600.87亿元，占规模以上工业的52.1%，比上年同期增长21.5%，比全市规模以上工业平均水平高4.9个百分点，对规模以上工业增长的贡献率为64.3%，拉动规模以上工业增长10.7个百分点。外商及港澳台商投资企业、国有企业、其他经济类型企业、股份合作企业和集体企业分别实现工业总产值389.50亿元、79.03亿元、57.32亿元、18.00亿元和9.27亿元，分别增长12.1%、6.7%、16.0%、12.7%和23.8%。

（四）工艺美术品制造业高速增长。1-8月份我市149家规模以上工艺美术品制造业实现工业总产值130.85亿元，比上年同期增长30.1%，比规模以上工业平均增速快13.5个百分点，对规模以上工业经济增长的贡献率达18.2%，拉动规模以上工业增长3.0个百分点；累计实现销售产值128.41亿元，增长32.8%，比规模以上工业平均增速快14.7个百分点；产销衔接良好产销率达98.1%。

（五）运行质量不断提高，利润高速增长。1-7月份，全市规模以上工业企业经济效益综合指数为283.25，比上年同期提高41.32个点，比全省平均水平高52.86个点。1-7月由于中海福建天然气责任有限公司、福建佳通轮胎有限公司、中海福建燃气发电有限公司等大企业利润成倍增长的拉动，我市规模以上工业实现利润总额42.22亿元，比上年同期增长58.0%，比全省平均水平高55.5个百分点，这几家企业对规模以上工业利润增长贡献率达到64.8%，扣除以上三家企业规模以上工业企业实现利润总额27.28亿元，增长24.7%；1-7月份全市共上缴税金总额25.47亿元，增长34.1%，比全省平均水平高12.4个百分点，工业运行质量向好。

存在问题

总体来看，全市工业经济整体运行在一个平稳较快的轨道区间，但作为工业经济增长“晴雨表”的工业企业用电量增速今年以来一直处于低位增长态势，1-8月份累计比上年同期增长0.85%，但增幅仍居全省九设区市第七位，工业用电量低增长一定程度上反映出我市工业企业产能不足，工业经济运行中存在的一些问题与矛盾，需引起关注。

（一）外需萎缩的影响程度加深。当前世界经济面临的不确定性增加，我国经济发展的外围环境依然严峻，导致我市外贸企业不敢接中长期定单，造成外销生产企业的不确定性，直接影响我市工业经济进一步增长。1-8月份我市规模以上工业出口交货值实现221.96亿元，比上年同期增长12.5%，增幅比全市规模以上工业销售产值增幅低5.6个百分点，比今年一季度、上半年分别低4.9个、1.7个百分点，呈逐月回落态势。特别是作为我市产业老大的制鞋业受冲击最大，今年订单较往年直线锐减。

（二）用工短缺制约产品订单按期交付，企业资金面临考验。当前我市很多劳动密集型工业企业受近年来国内用工紧张、工资大幅提高的影响出现用工短缺，研发人才匮乏，制约生产规模扩大，产品订单难以按期交付。同时银行贷款有限，我市大部分商业银行执行最高利率，使我市中小企业获取银行贷款综合成本上升幅度达13%以上。部分生产资料、原材料价格不断上涨等多种因素共同制约，严重压缩了企业利润空间，加之引进技术、更新设备等原因产生的资金缺口，企业流动资金普遍紧张。

（三）工业产业结构不够优化，工业发展基础仍然薄弱。由于我市工业产业结构单一，增长方式粗放，而且新技术产业项目企业偏少，产业技术含量还不高。企业对科技研发投入较低，缺乏创新人才，在自主创新、产学研合作等方面进展缓慢，市场竞争能力和抗风险能力薄弱。企业规模偏小，产业结构相对落后仍旧是制约我市工业发展的一个瓶颈。1-8月份我市仅有31家新投产工业企业，实现工业总产值13.63亿元，户均产值4397万元，仅拉动规模以上工业增长1.2个百分点，缺乏新投产大企业，工业发展后劲不足。同时重点项目推进与预想的有较大差距。不少项目因受到资金缺乏、用地指标不足等因素制约难以按计划开工建设，影响了全市经济总量的提升。

（四）企业自主创新能力不强，抵御市场风险能力不足。全市电子、纺织服装、制鞋等行业多数企业以加工贸易为主，大量低端产品抵御国际市场变化风险能力不足。同时，受国内劳动力成本持续刚性上涨、人民币升值明显等因素影响，“莆田制造”低成本时代不复存在，欧美等经济发达国家全球产业布局调整，国际知名企业纷纷将投资转向东南亚、国内中西部等低制造成本地区，大批国际订单纷纷转移，导致部分出口企业订单短缺或流失。

对策建议

工业是立市之本、强市之基，在我市经济发展中占有举足轻重的位置。保持我市经济平稳较快发展的关键是保工业增长。为了促进我市工业企业健康稳定发展，建议抓好以下几项工作:

（一）借外力。应乘海西建设的东风，抓住有利契机，全线出击，多作并举，兴起招商引资的新高潮；要重点抓好项目的宣传、包装和策划，争取吸引一批重大项目落地我市，增强我市工业经济发展的后劲。

（二）强推进。进一步加大项目推进力度，一是对在建项目帮助协调解决建设过程中存在的问题和矛盾，促其尽快竣工投产；二是对已经建成投产的项目，尽快帮助其协调好外部环境，促使尽快达产产生效益。

（三）育高新。加强与高校、科研机构的联系，引进科技项目，培育高新技术企业，用高新技术“包装”产品，提升产品档次，变“莆田制造”为“莆田创造”，使工业经济步入良性循环。

（四）大投入。一方面加大对重点骨干企业的技改投入，以进一步增强其竞争能力和发展后劲，促其尽快做大做强，从而进一步提高我市工业的整体竞争力；另一方面，集中精力加快工艺、制鞋等产业集群建设，以形成具有鲜明特色和磁场效应的产业群，培育新的经济增长点。

（五）重服务。政府有关部门在积极引导企业活化营销、开拓市场、强化管理、降本增效的同时，要切实帮助企业解决生产经营中的实际困难和问题，提高服务质量。
