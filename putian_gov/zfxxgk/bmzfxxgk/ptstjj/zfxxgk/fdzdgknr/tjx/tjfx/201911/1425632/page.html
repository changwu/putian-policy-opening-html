1-10月莆田市房地产运行简析

第七十六期
发布时间：2019-11-14 09:43
| | |

 

在国家稳定经济增长和提质增效推进供给侧结构性改革政策推进下，我市房地产投资逆势发力，房地产开发到位资金相对充足，商品房待售面积继续减少。

一、房地产运行情况

（一）房地产开发投资位居全省第一

在“稳地价、稳房价、稳预期”政策作用下，房地产市场出现积极变化，主要指标多呈稳中向好态势，投资结构进一步优化。1-10月，全市房地产开发投资完成351.65亿元，增长29%，增速较上个月略有回落，仍位居全省第一，比全省平均水平提高12.9个百分点，占全市固定资产投资的比重为22.4%，对全市固定资产投资的贡献率为63.4%，拉动固定资产投资增长5.4个百分点，房地产开发投资支撑作用明显。主要是今年加大开发用地出让力度，今年累计出让土地114.6公顷，是去年同期的2.5倍；土地出让金88.6亿，是去年同期的2.1倍，保证了房地产投资的稳定增长。

（二）房地产销售面积稳定增长

在市场总体稳定的大环境下，购房需求持续释放。房地产销售面积稳定增长，1-10月全市销售面积累计完成361.04万平方米，增长7.2%。

本月房地产销售面积呈现三个特点:1、总量增速均居全省前列。销售面积增速紧随三明、福州，居全省第三位，比全省平均水平高5.9个百分点。2、大项目销售贡献明显。央著单月销售面积超过5万平方米，秀屿高铁西地块云悦壹号和碧桂园天城单月销售面积均超过1.5万平方米。三个项目占全市单月销售面积的29.8%，拉动销售面积增长2.6个百分点。3、90平米以下住宅逐渐受青睬，增速明显。90平方米以下住宅销售面积20.32万平方米，增长30.2%；90-144平方米住宅销售面积256.63万平方米，增长9.6%；144平方米以上住宅销售面积34.41万平方米，下降23%。

（三）房地产新开工面积较快增长

在新入库项目的带动下，我市房屋新开工面积实现较快增长。1-10月，共有房屋施工面积2534.19万平方米，增长10%；其中本年新开工房屋426.14万平方米，比上年同期增加95.93万平方米，增长29.1%，增幅同比提高29.4%，扭转了去年一再下降的局面。

（四）房地产开发资金相对充足，房企压力小

房地产开发企业到位资金主要来源于国内贷款、定金及预收款和个人按揭贷款，国内贷款增速明显提高，房企资金相对充足。1-10月份，全市房地产开发到位资金为348.39亿元，增长9.5%。其中：国内贷款为55.95亿元，增长110.2%；自筹资金186.29亿元，增长11.6%；其它资金来源45.90亿元，增长123.4%。其他资金来源中，其中，定金及预收款为43.64亿元，下降34.2%；个人按揭贷款为16.62亿元、下降55.9%。房地产到位资金增长主要是受商品房销售额持续上涨因素的影响，房企资金回笼速度加快。

（五）商品房待售面积持续减少，去库存效果进一步显现

1-10月，全市商品房待售面积为161.26万平方米，下降8.3%。其中：住宅待售面积为65.10万平方米、下降12.4%；商业营业用房待售面积为38.77万平方米、下降21.1%；其他待售面积29.62万平方米、下降18.0%。

二、促进莆田市房地产业发展的建议

（一）严格落实房地产调控政策

针对当前房地产市场的情况，全市上下必须要从经济发展和社会稳定的大局出发，认真落实国家、省、市有关房地产调控精神，采取切实有力措施，积极引导和完善房地产相关政策落到实处，进一步推进全市房地产市场稳定健康发展。

（二）优化发展房地产市场环境

对于遗留项目，要进一步进行盘活，加快完善项目建设手续，尊重历史、实事求是，推进违法项目整治，尽快推动遗留项目存量房上市。对于开发企业购地行为，有关部门需依法严格查处土地闲置及炒地行为，对商品住宅用地储备量大、未按土地出让合同约定时限开竣工的企业给予相应的限制，促进房地产新项目开工落地。

（三）加强房地产市场动态监测

各级政府和各部门要进一步加强房地产市场统计分析和监测，密切关注房地产市场走向，积极引导舆论，高度重视房地产市场调控工作，密切关注市场发展中出现的新情况、新问题，依据各自情况精准施策，确保莆田市房地产市场健康稳定发展。
