搭借跨越引擎 激发动车时速

发布时间：2011-02-14 00:00
| | |

作为现代服务业的重要组成部分，旅游业在加快经济发展方式转变中扮演着举足轻重的角色。因其是一个集群产业，发展旅游业不仅能增加地方旅游收入，亦可带动旅游效应辐射下的诸如住宿、餐饮、交通、娱乐等行业的发展。在当前我国旅游业所处的“市场转型期、矛盾凸显期、管理提升期”的大背景下，优化产业结构、转变增长方式、提升发展质量等种种艰巨任务已迫切需要其由粗放型经营向集约化经营、由数量扩张向素质提升、由满足人们旅游的基本需求向提供高质量的旅游服务转变。

今年来，在市委、市政府的正确领导和关心扶持下，我市各级旅游部门整体联动，各地景区密切配合，持续宣传促销，既有力提升了莆田旅游的知名度和影响力，也拓展了旅游市场。全年旅游接待人数创历史新高，经济运行情况为历年最好，共接待接待国内外游客793.18万人次，比上年增长22.5%，实现旅游总收入63.58亿元，增长28.6%。其中境外游客18.47万人次，增长18.9%，创汇1.29亿美元，增长77.3%；接待国内游客774.71万人次，增长22.6%，实现国内旅游收入54.81亿元，增长23.3%。促成市场繁荣的因素是多样的，与此同时，我们仍要看到，当前我市旅游业仍存在品牌效应不够大、资源配置不够合理、从业人员不够专业等各种先天或后天的不足，并直接遏制了市场潜力的最大化激活。基于此，本文意从莆田市当前的旅游发展现状，分析我市旅游业所面临的发展瓶颈及其对策。

一、莆田旅游：丰富资源的集大成者

发展旅游业的适合与否，首先取决于对其先天条件的考量，可以说，旅游业既可看成是一个地区的地理名片，也可展览成一方水土的人文化石。发展旅游业应遵循“有的放矢”，避免“缘木求鱼”。莆田旅游资源的丰富性主要表现在以下三个方面：

（一）山川景色绮丽秀美。莆田地处福建中部，与福建在整个海西经济区中的位置不谋而合，而福建典型的“八山一水一分田”的结构也成为莆田地貌的精确注解。整个辖区依山伴海，地属亚热带海洋性季风气候，陆域面积4119平方公里，海域面积1.1万平方公里，海岸线总长534.5公里：有湄洲湾、兴化湾、平海湾等三大天然深水港湾，有木兰溪、萩芦溪、延寿溪等三条主要水系，有壶公山、大蜚山、凤山、钟山等四大山脉，有南北洋、东西乡等两大平原，更有星罗棋布其间的莆田二十四景、仙游四大景以及沿海十二景。不仅于此，多层次的地貌结构亦催生了丰富的生产资源，莆田的矿产、水产、农产品在福建省内均具备相当的竞争力，荔枝、龙眼、枇杷和文旦柚等四大名果更是驰名海内外。

（二）人文积淀博大精深。一是姓氏渊源根深蒂固。现今流传下来的莆田姓氏大多形成于兴化历史上第一次汉化，即西晋永嘉之乱后，中原士族“衣冠南渡，八姓入闽”，也为今日闽台“地缘相近、血缘相亲、文缘相承、商缘相连、法缘相循”书写了血浓于水的扉页。二是教育学习蔚然成风。唐朝“南湖三兄弟”开莆来学，奠定莆田“海滨邹鲁，文献名邦”的鸿基，在此后数千年的历史过程中形成并传扬“家贫子读书”的风气，历史上的文人学士及其故迹更是数不胜数。三是宗教信俗广播全球。妈祖文化、南少林、三一教、广化寺等信仰囊括中国古代“儒释道”三教，而尤以前者为最，仅台湾省就有80%的人口为妈祖信众，妈祖文化已成为莆田形象的首标签。四是历史古迹繁若星火。全市共有著名景点250多处，留存了以宗教胜地、名人故居、红色旅游为代表的诸多历史古迹，为福建省“历史文化名城”之一。

（三）民俗文化源远流长。由唐朝宫廷剧种演变而来的莆仙戏历经磨洗，成为与南音、歌仔戏等齐名的闽剧奇葩；由宋代沿袭至今的妈祖文化，衍生了历史悠久的妈祖祭典；经历了明末抗倭战争淬炼后的莆田，流传下全国独一无二的过年与节庆习俗；同样由唐宋传承至今的兴化民间工艺也为莆田盖满“仙作”、“中国银饰之乡”、“中国珠宝玉石首饰特色产业基地”等著名商标，促进了经济发展。

二、莆田旅游：在夹缝和困惑中生存

近年来，莆田旅游业虽取得长足发展，但仍存在不足。影响莆田旅游快速发展的症结，主要表现为以下几种。

一是合作观念较为淡薄。随着社会高速发展，旅游的含义已从最初单纯的游玩渗透至各个领域，事务合作、学科合作甚至区域合作都尤为必要，但我市多数旅游景点还缺少联动机制，导致客源分流，旺季不旺。

二是地理交通上的缺钙。今年四月底，福厦铁路的开通使来莆观光的人数大幅增加，动车效应可见一斑。但因向莆铁路、福厦高速扩建工程、莆永高速以及省内支线机场等尚未建成，莆田旅游的爆发力在近期难以得到完全激活。另外，辖区内部分地理位置较偏僻的景区如九鲤湖、九龙谷等，由于路程远、路况差、专线少等原因，也直接导致顾客放弃前往游玩的选择。

三是前有劲敌后有追兵。莆田介于福泉之间，因发展起步较晚所导致的经济实力上的差距，使莆田旅游企业的生存面临周边地市同行业的威胁。据调查，每年由台湾赴湄洲岛朝拜旅游的团队，多由泉州、厦门入境，直接与莆田当地旅游企业联系业务的则寥寥无几。

四是配套设施有待健全。随着经济社会的飞速发展，特别是在莆田市举办了福建省第十四届省运会、第十二届中国湄洲妈祖文化旅游节等活动之后，面对日益增加的入境游客，旅游文化娱乐配套设施还无法满足不同层次游客的需求，旅游服务质量还有待进一步提高。另外，全市大型购物中心的匮乏亦是影响旅游收入的重要原因。

三、莆田旅游：大品牌大环境大格局

发展莆田旅游，应扬长避短，依托六大战役阶段性成果，分批次、分层次对莆田旅游资源进行整合、规划，依次实现从大品牌到大环境，大环境到大格局的逐步提升。

（一）大品牌即立足妈祖文化优化旅游线路。

要立足妈祖文化，精心规划，细心经营，做大、做响妈祖品牌，使其在福建省内具备不可动摇的竞争力，成为莆田乃至整个福建的代名词。

要继续推广南少林和工艺美术文化，与妈祖文化一起在莆田形成三足鼎立的形势，增强莆田旅游实力。

要对莆田市内众多规模较小的旅游资源进行重新配置，整合成若干条精品线路；在农村推广“一村一特色”旅游项目，如农家游、渔家乐、自驾游、自助游等，丰富旅游载体。

（二）大环境即加大旅游扶持合作力度。

要加大财政投入。推进营销平台建设，依据动车效应对周边省市推广莆田旅游，帮助企业走出营销困境；继续完善旅游基础设施建设，引导更多娱乐设施、大型购物中心等落户莆田，增强旅游竞争软实力；加强旅游景区周边环境整治与保护；对优秀的旅行社采取一定的奖励机制，鼓励旅游企业积极引客入莆；进一步提升旅游服务质量，加大对旅游从业人员的培养、培训力度。

要加强领域合作。加强与政府会议、企业商务、校园社团、旅行协会等的事务合作，发展团体性游客来莆观光；加强与文化、体育、教育等领域的合作，通过举办联欢晚会、演唱会、运动会、博览会等大型活动带动旅游发展；加强与周边地市的合作，利用海西“两小时经济圈”，策划若干精品线路对外推广，使省外游客了解莆田，光顾莆田。

（三）大格局即策划海西旅游合作框架。

莆田在福建的位置，类似于福建位于整个海西经济区的位置，在未来五年内，依靠福建省“三横六纵九环路”的整体建成以及沿海高速铁路的全线连接，市域旅游乃至省域旅游作为新的名词必将炙手可热。莆田的地理重要性将日益凸显，因此，政府部门应高站位、高起点、高谋划，先人一步，以《闽东北五市旅游协作规划纲要》为基础，扩大合作范围，着手策划海西旅游合作框架，逐步推动莆田成为福建省旅游业中心城市。
