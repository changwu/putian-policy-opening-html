1-11月莆田规模以上服务业运行情况分析

第1期
发布时间：2024-01-25 09:39
| | |

2023年，全市上下坚持稳中求进工作总基调，深入实施“深学争优、敢为争先、实干争效”行动，规模以上服务业有序恢复，自9月份以来实现正增长，但新增入库单位数少、规模小，支撑力不足，其他营利性服务业因后劲不足持续负增长，需引起重点关注。

一、总体情况

1-11月，全市规模以上服务业实现营业收入311.83亿元，增长4.1%,增幅比1-8月提高4.3个百分点。

（一）交通运输、仓储和邮政业拉动力最强。自9月份以来，全市规上交通运输、仓储和邮政业营业收入增速加快回升，持续保持两位数增长。1-11月，全市该行业实现营业收入183.70亿元，增长13.2%，增幅比1-8月提高9.2个百分点，拉动全市规上服务业营业收入增长7.2个百分点，居十大行业之首。其中，重点行业其他交通运输业增长1.9%，增速高于全省平均水平20.6个百分点。

（二）互联网和软件信息技术服务业平稳较快增长。受新增企业拉动，今年以来，我市互联网和相关服务、软件和信息技术服务业持续保持两位数较快增长。1-11月，全市28家规模以上企业实现营业收入11.41亿元，增长14.8%，增速比1-10月提高4.1个百分点，比其他营利性服务业高21.1个百分点，拉动全市其他营利性服务业营业收入增长1.6个百分点。其中，互联网和相关服务业增势强劲，增长1.1倍，拉动全市互联网和软件信息技术服务业营业收入增长19.1个百分点。

（三）科学研究和技术服务业保持快速增长。受合利安项目管理和平行在线设计院两家新增企业拉动，今年全市规上科学研究和技术服务业营业收入持续保持快速增长。1-11月，全市规模以上科学研究和技术服务业实现营业收入7.94亿元，增长22.3%，拉动全市其他营利性服务业营业收入增长1.6个百分点。

二、主要问题

（一）其他营利性服务业后劲不足。今年以来我市新增入库单位数少、规模总体偏小，拉动力不足，加上部分支撑平台企业增长乏力和停业退库企业影响的不断加大，我市规上其他营利性服务业营业收入增速回落明显，由1-2月的增长18.3%逐月大幅回落，1-4月开始出现负增长，已连续8个月负增长。1-11月，全市规上其他营利性服务业实现营业收入85.94亿元，下降6.3%，降幅比1-8月扩大0.7个百分点，比全省平均水平低24.5个百分点。其中，主导行业租赁和商务服务业持续明显下降是主要原因，营业收入下降11.5%，拉低全市其他营利性服务业增速8.1个百分点。

（二）县区发展不平衡。1-11月，全市仅3个县（区）规上其他营利性服务业营业收入比去年同期有不同程度增长，其中秀屿增长13.9%、仙游增长8.1%，涵江增长1.2%，但这三个县（区）整体规模较小，行业结构相对单一，对全市的拉动不明显。其他四个县区均不同程度负增长，其中，荔城（-10.0%）、城厢（-5.7%）、湄洲岛（-38.1%）和北岸（-52.7%），分别拉低全市其他营利性服务业增速2.7、1.8、1.7和2.4个百分点。

（三）多数行业发展滞缓。从增速看，1-11月，全市规上服务业十大行业门类营业收入呈“三升七降”态势，除交通运输、仓储和邮政业（增长13.2%），房地产业（增长9.8%）及科学研究和技术服务业（增长22.3%）外，其余7个行业同比均负增长，尤其是部分重点行业持续负增长，增幅远低于全省平均水平。其中：租赁和商务服务业下降11.5%，低于全省31.9个百分点；居民服务、修理和其他服务业下降15.3%，低于全省19.2个百分点；文化、体育和娱乐业下降7.5%，低于全省21.2个百分点。从规模看，1-11月份，全市仅30家规上服务业企业营业收入超亿元，数量仅占规上服务业企业数量的8.6%，实现营业收入234.76亿元，占规上服务业营业收入比重高达75.3%，剔除这部分企业后，全市其余规上服务业大多数企业规模偏小，户均营业收入仅2424万元，尤其是文化体育娱乐业、居民服务修理和其他服务业以及教育行业企业规模均较小，缺乏龙头企业。其中：文化、体育和娱乐业户均营业收入1394万元，教育业户均营业收入440万元，居民服务修理和其他服务业户均营业收入1310万元。

三、对策建议

（一） 加大扶持力度，补强短板行业。一是加强行业统筹，齐抓共管。进一步明确服务业行业主管部门责任，继续推动行业主管部门统筹、相关部门积极参与的工作联动机制，形成有效工作合力。加强部门协调，研究解决莆田互联网服务业，软件和信息技术服务业，居民服务业，教育业，文化、体育业和娱乐业等短板行业发展中的问题。二是加大招商帮扶力度。各部门进一步梳理短板行业相关帮扶政策，加大扶持力度，在奖励资金、人才引进、项目规划、场地建设等方面给予更多的支持。三是持续为服务业企业纾困解难。加强对恢复滞后行业的调研、监测，深入了解相关企业经营存在的困难及原因，及时有效给予精准帮扶。

（二）加强企业培育，持续抓好进规入库。一是建立有效的数据共享机制，利用好部门行政记录资料、项目审批备案资料等，对相关企业进行实时监测跟踪，及时发现达到入库条件的企业。二是进一步压实行业主管部门责任。各行业主管部门要进一步压实“管行业就要管统计”的工作职责，督促行业内达到入库标准的企业及时入库纳统。三是重视和加强“下转上”、“大个体转企”工作，尤其是居民服务业、文化体育娱乐业等重点行业的薄弱领域，加强宣传和引导，解决企业纳统顾虑。对于“准规”、“大个体”后备单位建议各县区和行业主管部门加强跟踪服务，采取“一对一”帮扶措施，增强企业入库意愿。
