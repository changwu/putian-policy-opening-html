复工复产成效显著 商贸市场回暖向好——1-4月莆田市限额以上商贸业运行情况分析

第二十七期
发布时间：2020-05-19 09:43
| | |

随着新冠病毒疫情的有效控制，在复工复产有序推动下，全市限额以上商贸市场逐步向好发展，我市限额以上批发、零售业商品销售额和消费品市场由2月、3月的下降转为4月份的正增长；限额以上住宿和餐饮业营业额降幅也呈逐月收窄态势。

一、运行特点

（一）限额以上批发、零售业商品流通加快，趋势向好。

1-4月，全市限额以上批发业实现商品销售额466.53亿元，同比下降2.8%，降幅较1-3月收窄5.7个百分点；限额以上零售业商品销售额160.11元，扭转了前3个月下降1.6%的态势，实现增长0.6%。

4月份限额以上批发业、零售业商品销售额增速均由3月份的负增长转为正增长，分别为增长15.4%和增长8.3%。

（二）消费品市场回暖向好。

1-4月，全市限额以上消费品零售额156.23亿元，下降2.3%，降幅较1-3月收窄3.3个百分点，其中，4月份限额以上消费品零售额增长7.1%。分消费形态看，限额以上商品零售额152.53亿元，下降1.4%，限额以上餐饮收入3.70亿元，下降29.3%，降幅分别较1-3月收窄3.1个和6.3个百分点。

随着人们的生活回归常态，生活必需品等部分商品零售呈现上升态势。一是限额以上吃、穿及用类商品零售实现增长或降幅收窄。1-4月，全市限额以上吃类商品零售额15.21亿元，扭转前两个月下降0.6%的态势，实现增长0.1%；穿类零售额48.59亿元，下降0.1%，用类零售额88.73亿元，下降2.3%，降幅分别比1-3月收窄4.3个和2.9个百分点。其中，全市限额以上肉禽蛋类、饮料类等部分民生必需品实现零售额1.18亿元、2.16亿元，分别增长32.2%和30.4%；用类商品中，服装类、日用品类、文化办公用品类实现零售额10.64亿元、21.57亿元、1.24亿元，分别为增长70.2%、47.3%和26.8%。用类商品中消费升级趋势明显：1-4月，全市计算机及其配套产品实现零售额0.30亿元，增长23.1%；新能源汽车零售额1.34亿元，增长 53.3%。二是满足顾客便利性需求的食杂店和便利店供需平稳。1-4月，与群众生活密切相关的限额以上食杂店实现零售额0.23亿元、便利店零售额1.88亿元，分别为增长9.2%和36.2%。三是网上零售持续上行。电商企业开展多形式的促销活动，如直播带货、打折等，网上零售额较快增长。1-4月全市限额以上实物商品网上零售额76.94亿元，增长20.0%，占限额以上零售额的比重为49.2%，同比提高11.9个百分点。 

（三）住宿业营业额和餐饮业降幅进一步收窄。

随着人们抗疫信心增强及消费券发放的带动下，1-4月，全市限额以上住宿业营业额2.85亿元，下降14.7%，降幅比1-3月收窄17.9个百分点；餐饮业营业额3.62亿元，下降26.5%，降幅比1-3月收窄6.8个百分点。

二、存在困难

（一）215家限额以上批发零售企业关闭停业。自2019年12月至今年4月底，我市共有116家限额以上批发企业和99家限额以上零售企业受疫情影响无订单、经营不善、资金困难、资产重组等原因关闭停业并退库， 这些批发和零售企业商品销售额同比分别减少38.79亿元和17.87亿元，分别拉低全市限额以上批发业、零售业商品销售额增幅8.1个和11.2个百分点。

（二）受疫情影响仍有部分企业未复产。受疫情影响，市场订单减少，经营成本增加，资金压力增大，全市仍有4.6%的企业未能复产。分行业看，批发业未复产企业1-4月商品销售额比上年同期减少23.98亿元，拉低1-4月全市限额以上批发业销售额5.0个百分点；零售业未复产企业1-4月商品销售额比上年同期减少2.01亿元，拉低1-4月全市限额以上零售业商品销售额1.3个百分点。

（三）商贸企业仍将面临较大下行压力。据对803家全市限额以上企业调查，受疫情影响，34.9%的企业生产水平是疫情前的80%以下，达到正常水平的80%-100%的有57.0%，只有8.1%的企业超过正常经营水平。综上，复工企业还未能全部复产，大部分已复产的企业只能维持或保本经营，商贸企业仍将面临较大的下行压力，经济恢复仍需一段时间。
