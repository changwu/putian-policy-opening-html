一季度全市消费品市场较快增长

发布时间：2018-04-19 08:22
| | |

一季度，全市消费品市场运行呈较快增长态势，实现社会消费品零售总额196.19亿元，增长12.7%，增幅同比提升2.9个百分点。

分限额标准看，限额以上消费品零售市场发展较快，实现限额以上消费品零售额91.22亿元，增长18.8%，增幅同比提升5.6个百分点；限额以下单位实现104.98亿元，增长7.8%，增幅同比提升0.4个百分点。

按消费类型分，一季度，商品零售180.38亿元，增长13.1%，增幅同比提升3.1个百分点；餐饮收入15.81亿元，增长7.4%，增幅同比回落0.7个百分点。

按单位规模分，3月末全市限额以上小微批零企业1058家，累计实现消费品零售额57.16亿元，占限额以上消费品零售市场的62.7%，增长24.9%，对限额以上消费品零售额增长的贡献率达78.8%。

一、限额以上消费品零售市场主要特点

从限额以上单位商品零售类别看，一季度，吃、穿、用类商品零售额同比分别增长24.8%、11.1%和18.5%。新业态不断向纵深发展，网络销售渠道多样化，市场向海外拓展。

（一）网上零售保持较快增长。一季度，全市369家限额以上电商企业实现网上零售额28.67亿元，增长22.5%，增幅高于全市平均水平3.7个百分点，占限额以上消费品零售市场的31.4%。

（二）汽车类商品销售拉动作用明显，鞋帽类保持平稳增长。一季度，限额以上汽车类商品零售额15.92亿元，增长27.2%，增幅比上年同期提升26.8个百分点，占限额以上消费品零售市场的17.5%。同期，限额以上鞋帽类零售额20.92亿元，增长13.9%，增幅低于全市平均水平4.9个百分点，占限额以上消费品零售市场的22.9%。

（三）石油及制品类商品零售涨幅扩大。一季度，成品油价格上调，带动销售额上升，全市限额以上企业实现石油及制品类商品零售额8.51亿元，增长9.8%，增幅比1－2月及上年同期分别提升9.5个和5.4个百分点，占限额以上消费品零售市场的9.3%，继鞋帽类、汽车类后占比居第三位。

（四）综合零售保持向好发展态势。一季度，全市限额以上商贸企业实现综合零售额7.77亿元，增长17.5%，增幅同比提升6.9个百分点，其中，超级市场零售额2.23亿元，销售好于上年，由上年同期的下降2.0%转为今年的增长2.0%。

二、应关注的问题

1、总部经济型企业销售不稳定。从这些企业经营来看，总体销售额增速由上年的14.3%下滑至9.4%，有关部门应做好企业跟踪服务工作。

2、电商企业销售增速放缓。一季度，全市限额以上电商贸易企业网上零售额增长22.5%，增幅较上年同期放缓3.7个百分点，主要原因有企业经营不善、资金周转困难及部分企业关停等影响。

3、破产（注、吊销）企业基数影响。一季度破产（注、吊销）的批零企业零售额同比减少2.09亿元，拉低限额以上消费品零售额2.7个百分点，其对城厢影响最大，基数有1.23亿元，其次为荔城，基数0.53亿元。

4、家具类销售增长乏力。一季度全市限额以上家具类实现零售额4.90亿元，增长2.1%，增幅比上年同期低6.0个百分点，主要原因是目前高端红木家具市场需求有限，为销售淡季。

三、发展建议

1、加大相关政策扶持力度，促进贸易流通。据对50家大中小型企业的调查，仅有13家企业受益于相关政策的帮助和支持，分布在简政放权、创新支持、减税降费、互联网+扶持政策及促进外贸稳定增长政策等方面，企业在“国家政策有待改进方面”的诉求集中在减税降费、银行利息高及拓宽中小企业融资渠道方面。相关部门应积极对待企业诉求，多在政策、优惠措施上向企业倾斜，促进贸易流通业繁荣发展。

2、传统零售企业要加快转型步伐。目前，以商场（大卖场）为代表的传统零售企业存在较为落后的营销模式，地理位置、停车位、排队买单、提货还有高租金成本等都在影响商家的业绩。传统零售业在降低成本、提高销售量、提升服务上还有很多工作要做。
