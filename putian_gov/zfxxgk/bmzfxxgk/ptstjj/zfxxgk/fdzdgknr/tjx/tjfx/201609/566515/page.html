1-8月莆田市消费市场运行情况简析

发布时间：2016-09-22 00:00
| | |

8月份全市消费品市场保持温和回升，前8个月市场总体运行平稳。

一、市场运行平稳

1－8月，全市实现社会消费品零售总额397.14亿元，同比增长11.2%，增幅虽同比回落0.5个百分点，但与1-7月持平，比全省平均水平低0.1个百分点，居九设区市第五位。其中，8月份实现社会消费品零售总额47.40亿元，增长11.1%，增幅比7月份回落2.0个百分点。按消费形态分，1－8月，餐饮收入31.73亿元，增长5.3%，增幅比1－7月提升0.4个百分点；商品零售额365.41亿元，增长11.7%，增幅与1－7月持平。

（一）零售行业零售额占比略超八成。1－8月，零售业累计实现零售额322.23亿元，占全市消费品零售市场的比重达81.1%，占比与1－7月持平，增长12.2%，对全市社会消费品零售总额增长的贡献率达88.0%，贡献率较1－7月回落0.5个百分点；其次是批发业，累计零售额贡献率8.0%，贡献率比1－7月提升0.1个百分点；再者是餐饮业，累计零售额贡献率3.6%，贡献率比1－7月提升0.3个百分点，而住宿业则为0.4%，贡献率与1－7月持平。

（二）网络零售保持较快增长态势。1-8月，宣妮斯、金拓实业等219家限额以上电商企业实现网上零售额48.60亿元，占全市限额以上消费品零售市场的27.6%，同比增长30.5%，增幅比全市限额以上零售额快17.1个百分点，远高于实体零售店增速。

（三）部分限额以上商品零售较快增长。1、鞋帽类商品零售较快增长。在古奇天伦、新达等企业增长带动下，1-8月，全市限额以上鞋帽类商品零售额41.45亿元，同比增长26.5%，增幅比全市限额以上零售额快13.1个百分点，占全市限额以上零售额的23.5%，占比居限额以上商品类首位,比第二位的汽车类高6.9个百分点。2、吃类商品保持稳定增长。1－8月，粮油、食品类商品零售额16.97亿元，增长34.6%；饮料类2.52亿元，增长23.3%；烟酒类3.34亿元，增长24.8%。3、文化办公用品类较快增长。1－8月，文化办公用品类商品零售额1.88亿元，增长60.5%。4、健康类等消费活跃。今年来，健康类等消费持续活跃，其每月累计零售额增幅均在30%以上，1－8月零售额增长62.9%。5、汽车类商品销售持续增长。8月份全市实现限额以上汽车类商品零售额3.66亿元，增长15.4%，在7月、8月销售利好带动下，1－8月，全市实现汽车类商品零售额29.31亿元，增长12.3%，增幅比1－7月提升0.5个百分点。

二、当前限额以上消费市场发展的制约因素

一是停业（注吊销）企业影响较大。受市场行情低迷、需求疲软、资金困难、被外地企业兼并等因素影响，1-8月停业（注吊销）批零企业达68家，影响全市批发零售业商品销售额增长3.0个百分点，影响社会消费品零售总额增长0.6个百分点。

二是传统实体商场仍经营困难。1-8月，全市限额以上超市零售额12.17亿元，同比增长3.3%。其中，城厢增长5.5%，荔城下降5.5%。城厢超市业绩增长，主要是靠增加新的门店。全市大部分超市经营业态、商品趋于同质化，加上微商等冲击，客流量减少，销售额增长乏力。

三是家具、珠宝等本地特色行业拉动作用有限。受宏观经济下行影响，具有本地特色行业的家具类及金银珠宝类商品零售带动作用不大。1－8月，家具类商品零售额12.15亿元，增长9.3%，金银珠宝类商品零售16.02亿元，增长6.1%，对全市社会消费品零售总额增长的贡献率分别为2.6%和2.3%，贡献率同比回落9.9个和14.9个百分点。

四是石油类商品零售不景气。受价格持续低迷影响，1-8月，全市限额以上石油类商品零售额下降9.8%，占限额以上消费品零售市场10.3%，市场份额退居第三位。

三、发展建议

做好新增限额以上商贸企业入库审核工作。今年的限额以上商贸企业月度新增入库审核工作至23日将全面结束，3月至9月全市新入库企业20家，约占全省的7.7%。从工商部门的市场主体登记情况看，上半年，全市新增内资企业6406户，同比增长41.2%，新增外资企业14家，同比增长16.7%。市场主体登记的活跃与新增入库企业形成鲜明对比。2016年度的新增企业入库工作即将开始，要提前做好入库前的名录核查、现场调查、走访工作。
