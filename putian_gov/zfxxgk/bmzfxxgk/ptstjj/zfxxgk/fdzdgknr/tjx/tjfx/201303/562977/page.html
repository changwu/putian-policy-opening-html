前2个月莆田市商贸业运行情况简析

发布时间：2013-03-26 00:00
| | |

前2个月，全市商贸业在上年繁荣发展的基础上，以科学发展为主题，进一步转变经济发展方式，加快发展现代商贸流通业，市场运行总体保持有序、健康的发展态势，实现了良好开局。1－2月，全市实现商品销售额（营业额）167.32亿元，同比增长37.4%，增幅比上年同期上升16.7个百分点；实现社会消费品零售总额77.95亿元，增长19.1%，增幅同比上升3.1个百分点。销售额（营业额）及社会消费品零售额增幅如下图所示。

一、商贸市场运行特点

1－2月，批发业和零售业快速发展，其中，批发业实现销售额74.5亿元，增长37.9%；零售业实现销售额83.21亿元，增长40.8%。批发业和零售业增幅均居九设区市第一位。社会消费品零售总额也较快增长，增幅居九设区市第一位。

（一）新增限额以上法人企业充满活力。1－2月，全市共有461家法人企业参加了网上直报，从2011年报起， 2012年全市共新增158家限额以上企业，这些企业给商贸业发展注入新的活力，其实现销售额（营业额）14.80亿元，增长4.3倍，拉动限额以上销售额（营业额）增长22.0个百分点；实现消费品零售额2.23亿元，增长2.0倍，拉动限额以上零售额增长9.4个百分点。在上年同期数相对较少的情况下，推动限额以上商贸业快速发展。

（二）销售额超亿元企业增多。随着商贸业发展壮大，亿元企业创新经营模式，增加销售网点，集聚效益愈加明显。1－2月，全市限额以上销售额超亿元企业共有12家，比上年同期增加5家，主要分布在烟草、服装鞋帽、石油及制品类、建材和大型超市等行业。1－2月，这12家企业共实现销售额51.90亿元，增长113.2%，实现零售额10.91亿元，增长81.4%，对限额以上批发零售业销售额、零售额增长的贡献率分别高达78.0%和67.4%，比上年同期提高48.9及21.4个百分点。

（三）限额以上销售额（营业额）比重提升。1－2月，限额以上实现销售额（营业额）90.13亿元，增长65.4%，占全市销售额（营业额）的比重过半，达53.9%，超出限额以下7.8个百分点，其中，限额以上批发零售业比重为56.2%，比上年提升9.9个百分点。

（四）石油制品及机动车燃料类商品销售贡献率高。从商品销售分类看，1－2月，石油制品及机动车燃料类实现销售额29.63亿元，增长2.5倍，对限额以上批发零售业销售额增长的贡献率居25类商品首位，高达59.7%，比第二位的金属材料类贡献率多46.3个百分点。如此好的业绩，得益于中石化森美公司大幅增长的销售额，其销售额拉动全市增长27.1个百分点，零售额拉动全市增长9.4个百分点。

（五）城乡消费品市场平稳发展。1－2月，城镇实现零售额68.62亿元，增长18.8%;乡村实现零售额9.32亿元，增长21.1%，城镇和乡村增幅分别比上年同期提高2.9、4.1个百分点。从城镇和乡村各自发展来看，乡村增幅快于城镇2.3个百分点，比上年扩大1.2个百分点。

（六）县区间发展呈良性发展格局。各县区加大发展力度，1－2月，限额以上商品销售额及零售额增幅均好于上年同期，其中，秀屿区、北岸因基数较小，出现倍数增长。具体数据如下表所示。

二、商贸业运行需注意的问题

限额以上部分商品市场竞争激烈，增长乏力。首先是汽车类商品销售。在上轮的汽车下乡政策的带动下，中国成为全球第一大汽车市场，随着市场饱和和城市交通滞后的限制，单纯靠刺激政策继续寻求中国汽车业销量快速增长的空间有限。对莆田而言，也存在同样的情况。有数据显示，2012年，全市民用汽车拥有量12.97万辆，比上年增加2.42万辆，增长23.0%。在这样高的汽车拥有量下，汽车销售还是有所增长，但增速放缓。从全市汽车销售市场行情看，上年钓鱼岛外交事件后，本地日系车销量受到一定程度冲击，销售量有所下降，1－2月，全市实现汽车类商品销售4.97亿元，下降4.4%，汽车类商品零售4.47亿元，仅增长16.4%，增幅分别比上年同期（39.9%和30.4%）有明显下降。其次是家用电器和音像器材类商品销售。2013年1月，是长达4年的家电下乡政策到期的最后1个月，又适逢春节，各卖场都加大促销力度，家电销售有所回升。但是在补助政策结束后的2月份，家电销售下降。据2月市场快报显示，前2个月累计销售额2.06亿元，仅增长13.7%，对限额以上批发零售业增长的贡献率仅0.7%。

三、对一季度的预计

从前2个月的运行情况看，目前商贸市场运行良好，预计3月份的商品销售额（营业额）及零售额也会有小涨幅，但是，批发业面临更大压力。由于上年3月份批发业销售额大增，当月销售额高达50.3亿元，比2月份增加23.7亿元，其中，各县区限额以上批发业销售额增加情况如下：城厢近1亿，荔城6亿，秀屿3亿，仙游3亿。高基数将在一定程度上拉低今年3月批发业增幅。预计全市3月商品销售额（营业额）将达90亿，其中限额以上44亿；累计销售额（营业额）257亿元，增长27%。预计3月份社会消费品零售总额36亿，累计114亿，增长20%。
