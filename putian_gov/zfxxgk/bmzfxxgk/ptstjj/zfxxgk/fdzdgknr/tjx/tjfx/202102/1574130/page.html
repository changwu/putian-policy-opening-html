2020年莆田GDP增长3.3%

第八期
发布时间：2021-01-27 08:40
| | |

根据地区生产总值统一核算结果，2020年，全国实现生产总值1015986亿元，增长2.3%；全省实现生产总值43903.89亿元，增长3.3%，增幅居全国第十九位。全市实现生产总值2643.97亿元，增长3.3%，增幅居全省设区市第六位；其中，第一产业增加值125.66亿元，增长1.4%；第二产业增加值1362.33亿元，增长1.5%；第三产业增加值1155.98亿元，增长5.8%。

一、运行特点

（一）从三次产业贡献率看。第一产业贡献率为2.1％，比前三季度回落4.4个百分点;第二产业贡献率为24.9％，比前三季度提高18.1个百分点;第三产业贡献率为73.0％，比前三季度回落13.7个百分点。

（二）从三次产业拉动情况看。第一产业拉动GDP增长0.1个百分点，与前三季度持平。第二产业拉动GDP增长0.8个百分点，比前三季度提高0.7个百分点。第三产业拉动GDP增长2.4个百分点，比前三季度提高1.1个百分点。

（三）农业生产有序开展。2020年，莆田市实现农林牧渔业增加值136.84亿元，增长1.7%。农业实现产值56.53亿元，增长  4.9%；林业实现产值6.29亿元，增长0.1%；牧业实现产值39.88亿元，下降2.0%；渔业实现产值114.94亿元，增长0.8%。

（四）第二产业持续发展。2020年，工业实现增加值1094.00亿元，增长1.9%，增幅比前三季度提高0.9个百分点；拉动GDP增长0.8个百分点，比前三季度提高0.3个百分点。建筑业实现增加值270.96亿元，下降0.3%，降幅比前三季度收窄3.8个百分点。

（五）服务业加快恢复。2020年，全市第三产业增加值增长5.8%，增幅位居全省第二位,比前三季度提高2.6个百分点,高于全省平均水平1.7个百分点。从第三产业内部看，交通运输、仓储及邮政业实现增加值62.78亿元，增长5.4%，高于全省平均水平0.6个百分点;批发和零售业实现增加值342.58亿元，增长10.5%，高于全省平均水平5.2个百分点;金融业实现增加值144.92亿元，增长7.4%，高于全省平均水平1.0个百分点；房地产业实现增加值  160.35亿元，增长0.5%，低于全省平均水平2.5个百分点。其他服务业实现增加值396.55亿元，增长4.2%，高于全省平均水平0.5个百分点。

二、需关注的问题

（一）工业增长后劲乏力。停、减产面居高不下。2020年末，全市规模以上工业企业停、减产面达47.8%，同比扩大14.7个百分点。规模以上工业企业数减少。12月末，全市规模以上工业企业数1164家，同比减少37家。存量企业贡献不足。2020年，规模以上存量企业工业增加值下降2.0%，低于规模以上工业增加值增长4.2个百分点。

（二）投资增长后劲不足。2020年，全市固定资产投资下降2.3%，增幅比全省平均水平低1.9个百分点，居全省第七位；建筑安装工程下降12.9%;而土地购置费增长21.8%,呈现建安工程推动缓慢而土地购置费提前集中释放的现象，或将对后续投资潜力产生不利影响。

（三）部分核算GDP指标增幅较低。从全年核算GDP的相关指标来看，仍有部分指标下降且增幅在全省排名靠后。如资质内建筑业总产值下降2.9%、商品房销售面积下降3.1%；农业总产值、资质内建筑业总产值增幅均居全省第9位，商品房销售面积、规模以上工业增幅均居全省第7位。

三、建议

（一）稳消费。完善消费政策，改善消费环境，促进消费向绿色、健康、安全发展，鼓励消费新模式新业态发展；努力扩大消费需求，不断释放消费潜力，提升消费对GDP的贡献率，更好发挥消费在双循环新发展格局中的基础性作用。    

（二）扩投资。未雨绸缪，加紧储备一批项目;引鸟入笼，学习南昌等先进地区“行政审批局”经验做法，着力优化营商环境;聚焦高端，加快制造业项目转型升级;引导投资,促进“343”重点产业高质量发展。

（三）提服务。各相关行业主管部门充分发挥部门联动机制的作用，协同配合，各负其责，主动领责，紧密跟踪核算GDP各项基础指标的完成情况，加强各项经济指标的跟踪、分析和监测。
