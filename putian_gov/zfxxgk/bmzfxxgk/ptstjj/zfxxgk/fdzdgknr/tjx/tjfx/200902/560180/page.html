2008年莆田市对外经贸运行情况分析

发布时间：2009-02-03 00:00
| | |

2008年全市外经贸工作在严峻的国内外经济形势下，坚持立足转变外贸增长方式，促进外贸可持续发展，认真落实市委提出的“四用发展”的工作要求，坚定不移的实施“发展是各项工作的重中之重”的工作思路，积极开展外经贸工作。

一、基本情况

——招商引资形势不容乐观 2008年，全市共审批利用外资项目63个（其中增资项目27个）下降36.4%，合同利用外资按历史可比口径40723万美元，同比下降27.5%，完成年度计划67.9%；按验资口径18658万美元，同比下降31.1%，完成年度计划66.6%。增幅居全省第四位。

——实际到资低位增长 全年全市利用外资实际到资按历史可比口径56258万美元，同比增长1.7%，完成年度计划93.8%；按验资口径13611万美元，同比增长13.1%，完成年度计划90.7%。实际利用外资增幅在全省的位置由去年的第6位降到第9位。

——对外贸易增长缓慢  全年全市外贸进出口总值23.21亿美元，同比增长8.04%，增幅比上年回落17.6个百分点，比全省平均增幅低5.9个百分点。其中进口6.05亿美元，增长0.7%，增幅比上年回落39.2个百分点，完成年度计划的89.0%；出口17.16亿美元，增长10.8%，增幅比上年回落10.6个百分点，完成年度计划97.0%。

二、主要特点

——工业仍是引资的主要领域  全年新批外资项目36个，合同外资11186（验资口经）万美元。其中工业类项目28个，占77.8%，合同外资10397万美元，占92.9%，比上年增加2.9个百分点。新批增资项目27个，合同外资7989（验资口经）万美元，占全部合同外资的41.7%。其中工业类项目24个，占88.9%，合同外资6366万美元，占增资总额的79.7%。

——重点外贸企业出口增长乏力 全年全市40家重点企业出口11.81亿美元，比增4.1%，增幅比上年回落5.5个百分点。在这40家企业中有60%的企业出现负增长，两家持平，有24家出现负增长。

——民营企业出口仍是增长的主力 全年全市民营外贸企业出口53245万美元，同比增长26.2%，增幅高于全市平均水平15.9个百分点，拉动全市外贸出口增长7.1个百分点，净增出口额11508万美元，占全市外贸出口增量的68.9%，成为全市外贸出口的增长主力；“三资”企业出口113070万美元，比增4.9%，低于上年增幅14.2个百分点；集体外贸企业出口2118万美元，同比增长6.1%；国有外贸出口3146万美元，同比下降12.9%。

——各类商品出口增长差距拉大 全市外贸六大出口商品中轮胎出口28343万美元，同比增长11.3%，比上年回落46.2个百分点，占全市出口比重16.5%，出口总量居全市第二位；纺织服装出口9333万美元，同比下降0.8%，比上年回落28.5个百分点；鞋类产品出口84456万美元，同比增长13.9%，比上年提高0.8个百分点；烤鳗出口2769万美元，同比下降34.2%；机电产品出口21548万美元，同比增长13.0%；木制品出口5178万美元，同比下降1.9%。

——一般贸易出口持续快速增长  全年全市一般贸易出口80866万美元，比上年增长25.7%，高于全市平均增幅15.3个百分点,继续保持良好的增长势头。加工贸易出口90768万美元，比上年下降0.45%。

——出口市场的相对集中度较高  全市出口的前三大市场是美国、欧盟和日本，全年对这三大市场的出口额为106604万美元，增长10.1%，增幅比上年回落8.2个百分点，占全市出口总额的62.1%；其中对欧盟出口21407万美元，比增40.9%，增幅比上年提高17.3个百分点，成为三大出口市场中发展前景最看好的区域；对美国出口77193万美元，比增9.7％，增幅同比下降7.5个百分点；对日本出口8004万美元，同比下降14.1％。

三、影响外经贸发展主要因素

招商引资不尽人意 近年来，周边国家竞相推出了吸引外资的新举措，而在国内的外资梯度转移中，中西部省份为抢占国际、国内资本流入的先机，纷纷采取更加宽松的政策吸引外商投资，地区间的竞争日趋激烈。我市经济发展整体水平与周边省、市比还相对较低，产业配套能力较弱，产业集聚度不高，资源配置的承载能力不强，全年全市新批项目及合同外资显负增长态势。

产业分布过于集中  今年在新签外商投资项目中，第一产业仅3项、第三产业5项、第二产业28项（合同外资为10397万美元），分别占全年全市新签合同外资额的0.5%、6.5%和92.9%，这种状况不利于产业结构的调整和优化。

产业国际竞争力不强  我市出口产品主要依靠数量增长和加工贸易方式提升竟争力，虽然从中获得了较大的利益，但也为此付出了资源、环保等方面的代价，单纯依靠数量规模和价格优势的增长方式其弊端逐渐显现，转变外贸增长方式成为未来需要解决的首要问题，从可持续发展的角度看，转变外贸增长方式，提高产品附加值，提升进出口质量和效益已成为当前的紧迫任务。

多方因素将制约对外经贸发展 人民币升值对企业出口的负面影响逐步加剧，工资成本上升、资源环境约束、技术创新能力不足、产业结构不合理、节能减排投入增加以及贸易摩擦加剧等方面的因素已在一定程度上影响和制约着我市出口企业的发展。

面对机遇和挑战，全市要采取切实有效措施转变对外贸易增长方式，增强对外贸易可持续发展的后劲。一要采取加强成本控制，改进生产工艺，加大研发力度，积极拓展市场和产品转型等措施来不断提升企业的赢利能力；二要加快推进出口产品结构调整，引导和鼓励全市外向产业沿国家与省里的产业政策导向加快发展，促进出口产品高新化、品牌化，鼓励并支持企业提高产品的核心竞争力；三要积极鼓励开展加工贸易出口，提高加工贸易档次；四要尽快建立和完善政府、企业和中介组织三者分工合作的贸易摩擦应对机制，加快培养应对贸易摩擦的专业人才，加强对企业的指导，提高应对风险能力。

                                   撰稿：姚春玉
