2014年1-9月莆田市农业农村经济运行情况分析

发布时间：2014-10-11 00:00
| | |

今年以来，我市认真贯彻落实中央一号文件精神和省、市农业农村工作会议精神，按照“山区学利农、海上建牧场”的总体思路，紧紧围绕粮食增产、农业增效、农民增收目标，努力提高农业综合生产能力，大力推进农业产业化和新农村建设，继续深化农村改革，发展农村社会事业，1－9月全市农业农村经济稳步发展。

一、农业农村经济运行特点

（一）农林牧渔业总产值完成情况

1－9月，全市农林牧渔业总产值135.25亿元，可比增长3.3%，增幅比上半年回落0.2个百分点。其中，农业产值48.48亿元，增长3.6%，增幅与上半年持平；林业产值1.22亿元，增长35.8%，增幅比上半年提高15.9个百分点；牧业产值23.31亿元，下降3.9%，增幅比上半年回落3.0个百分点；渔业产值50.53亿元，增长5.5%，增幅比上半年提高0.8个百分点；农林牧渔服务业产值11.69亿元，增长5.2%，增幅与上半年持平。

（二）春夏收农作物生产总体情况良好，但粮食生产呈下降趋势

全市春夏收农作物总播种面积95.90万亩，同比增长0.4%。其中粮食播种面积29.82万亩，下降1.8%；粮食产量10.74万吨，下降0.9%。在粮食生产中，稻谷播种面积20.77万亩，下降3.1%，影响粮食播种面积增幅回落2.2个百分点；稻谷产量8.91万吨，下降1.5%，影响粮食产量增幅回落1.2个百分点。油料面积20.79万亩，增长0.6%，增幅比上半年回落2.0个百分点；油料产量4.06万吨，增长2.3%，增幅比上半年回落6.5个百分点。蔬菜面积39.68万亩，增长1.4%，增幅比上半年上升1.0个百分点；蔬菜产量81.17万吨，增长1.2%，增幅比上半年上升0.8个百分点。中药材面积0.29万亩，增长13.4%；产量0.20吨，增长7.0%。花卉面积0.89万亩，增长42.9%。

（三）春夏收茶叶和水果产量明显增加

全市春夏收中，茶叶产量0.33万吨，同比增长9.0%，其中红茶、绿茶、青茶分别增长53.0%、15.0%、6.0%。园林水果产量16.16万吨，增长11.0%。其中龙眼产量3.81万吨，增长34.0%，拉动园林水果产量增长7.1个百分点；枇杷产量10.18万吨，增长6.0%，拉动园林水果产量增长4.2个百分点。

（四）畜禽生产情况呈持续下降趋势

今年以来，随着我市各县（区、管委会）畜禽整治不断推进，一方面很多不规范、达不到环保等要求的畜禽养殖单位陆续被关闭，另一方面因养殖户为了达到环保要求而增加投资和饲料价格上涨而增加养殖成本，致使很多畜禽养殖户处于盈亏临界间，为了减少亏损，很多养殖户减少养殖规模，导致1－9月我市畜禽产品全面下降。

1、生猪出存栏数继续下降。1－9，全市生猪出栏86.94万头，同比下降7.3%，降幅比上半年扩大1.6个百分点，其中非农户增长8.3%，规模户下降19.6%，散养户下降16.2%；存栏65.69万头，下降13.3%，降幅比上半年收窄7.9个百分点，其中非农户下降2.3%，规模户下降38.9%，散养户下降13.2%。

2、畜禽出栏数小幅增长，存栏数降幅进一步扩大。家禽出栏2030.81万只，同比增长0.1%，增幅比上半年回落7.2个百分点，其中非农户增长2.4%，规模户下降28.8%，散养户增长1.5%；存栏618.90万只，下降7.1%，降幅比上半年扩大3.6个百分点，其中非农户增长9.9%，规模户下降47.9%，散养户下降12.7%。

3、肉蛋奶总产量全部呈现下降态势。1－9月全市肉类总产量9.53万吨，由上半年的持平转为下降3.5%。其中猪肉产量下降6.3%，家禽肉产量增长4.7%；禽蛋产量2.62万吨，下降13.7%，降幅比上半年扩大3.5个百分点；奶类产量1.13万吨，由上半年的增长0.1%转为下降3.4%。

（五）渔业生产继续保持平稳较快的发展态势

1－9月，全市水产品总产量66.26万吨，同比增长5.7%，增幅比上半年提高0.5。其中海水产品产量62.95万吨，增长5.8%；淡水产品产量3.30万吨，增长3.5%。

（六）蘑菇播种面积及产量全面增长

1－9月，全市蘑菇播种面积达755.20万平方米，同比增长1.6%；产量达5.15万吨，增长2.2%；亩产为6.8公斤／平方米，与去年同期持平。

二、存在问题

（一）农业基础设施还是薄弱。水利等农田基础设施不尽完善，抵御洪涝、干旱等自然灾害的能力不高，生产仍然面临较大的威胁，高产稳产无法得到保障。

（二）耕地面积减少，稳粮难度大。由于交通建设、经济开发区、工业园区建设等，宜粮耕地面积逐年减少，而且农户种粮积极性不高，撂荒面积不断增多，加之农田基础设施不完善，干旱季节难以保障农作物用水问题，粮食面积减少的趋势难以扭转。

（三）生猪养殖户处于盈亏临界间，部分养殖户减少养殖规模和压栏观望。今年初以来，生猪价格呈下跌态势，5月份跌至最低点，约为9.6元∕公斤，而因饲料原材料等价格不断上涨引起饲养成本不断提高，成本价约为14元∕公斤，6月份生猪价格有所回升，但回升幅度不大，养殖户为了减少亏损，一方面减少养殖规模，另一方面压栏观望。这无疑给今年本因畜禽整治而低迷的畜牧养殖业雪上加霜，造成今年1－3季度生猪出栏数和猪肉产量呈持续下降趋势。

（四）现代农业组织化程度偏低。全市现代农业企业产业化规模偏小，组织化程度低。农产品初级加工多、深加工少、产品增值率低。龙头企业少，农业龙头企业实力不强，缺乏带动力强的农业产业化龙头企业，产业化水平、标准化生产仍然处于初级阶段。上规模、运行比较规范的专业合作经济组织较少，且农民经纪人大部分文化层次不高，销售渠道不畅，造成丰产不增收等现象，不同程度上挫伤了农民发展农业产业化的积极性。龙头企业虽然日趋规模化，产业化，但是缺少自主品牌、品牌辐射范围小、销售渠道不够畅通，市场抗风险能力低，销售价格很难掌控，极易出现大起大落现象。
