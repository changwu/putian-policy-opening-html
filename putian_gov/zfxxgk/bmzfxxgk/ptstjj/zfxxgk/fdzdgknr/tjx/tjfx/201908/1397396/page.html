1-7月莆田市经济运行情况分析

第五十四期
发布时间：2019-08-20 08:41
| | |

1-7月，全市经济继续保持稳中有进的发展态势，部分主要经济指标（固定资产投资、规模以上其他营利性服务业营业收入（错月）、实际利用外资）增幅继续稳居全省首位。同时也要清醒地看到，受多重因素影响，经济运行中还存在一些问题，下行压力仍然较大，必须采取有针对性的措施切实加以解决。

一、经济运行主要特点

（一）工业经济大盘稳定。1-7月，全市规模以上工业增加值可比增长8.4%，虽增速有所放缓，但总体仍保持在8%稳中向好区间内。主要亮点：一是重点产业贡献突出。1-7月，全市规模以上化工新材料、电子信息、高端装备三大产业分别拉动全市规模以上工业增加值增长2.1个、1.0个和1.0个百分点。二是工业生产后劲增强。全市74家新增规模企业共拉动全市规模以上工业增加值增长2.0个百分点。其中，18家去年以来新投产企业拉动全市规模以上工业增加值增长1.7个百分点；56家2018年底“下转上”企业拉动全市规模以上工业增加值增长0.3个百分点。

（二）规上服务业发展良好。1-6月，全市规模以上其他营利性服务业营业收入同比增长23.6%，增幅高出全省平均水平0.6个百分点，连续四个月稳居居全省第一位，是我市第三产业保持较快增长的主要动力。主要亮点：一是互联网和相关服务、软件和信息技术服务业贡献突出。全市该行业企业营业收入同比增长89.9%，增幅同比提高56.1个百分点，拉动全市规模以上其他营利性服务业营业收入增长14.0个百分点。二是新增企业拉动显著。全市新增规模以上其他营利性服务业企业75家，拉动全市规模以上其他营利性服务业营业收入增长22.7个百分点, 主要得益于福建豆讯科技有限公司、福建聚合网络有限公司等新增企业。

（三）市场销售稳中趋缓。1-7月，全市社会消费品零售总额481.63亿元，同比增长9.9%，增幅分别比1-6月、上年同期下降0.4、2.4个百分点。主要亮点：一是新增企业拉动有力。 2018年以来新入库的523家企业快速增长，共实现零售总额37.80亿元，拉动全市社会消费品零售总额增长4.7个百分点。二是网络消费保持两位数增长。1-7月，全市限额以上网络零售额108.75亿元，同比增长15.4%，增幅快于全市社会消费品零售总额5.5个百分点。三是品质类商品零售涨幅较大。如可穿戴智能设备零售额增长196.4%；新能源汽车增长97.5%；智能手机增长28.0%。四是部分有店铺零售业绩较好。限上便利店、食杂店、百货店实现商品零售额同比分别增长34.4%、24.8%和17.5%。五是餐饮收入保持两位数增长。今年来全市餐饮收入均保持在15%以上，1-7月全市限上住宿餐饮业餐费收入增长21.0%，增幅快于社会消费品零售总额11.1个百分点。

（四）固定资产投资增速领先。1-7月，全市固定资产投资同比增长10.0%，增幅比全省平均水平高3.1个百分点，居全省首位。主要亮点：一是在建亿元项目高速增长。全市218个在建亿元项目完成投资增长61.2%，增幅分别比上年同期、全市固定资产投资高73.8个和51.2个百分点，其中，85个本年新开工亿元项目完成投资同比增长130.6%。二是房地产业投资快速增长。全市房地产业投资同比增长33.7%，分别比1-6月、上年同期提高6.4、40.3个百分点，对全市固定资产投资增长的贡献率为60.6%，拉动全市固定资产投资增长6.1个百分点。三是工业投资增速回升。全市工业投资同比增长9.7%，增幅同比提高3.4个百分点，占全市固定资产投资的比重为28.9%，对全市固定资产投资增长的贡献率为28.0%，拉动全市固定资产投资增长2.8个百分点。

三、主要问题

（一）工业回暖基础还不牢。一是减停产面居高不下。7月末，全市规模以上工业停、减产面达31.8%，共拉低全市规模以上工业增加值增幅6.3个百分点。二是降成本任重道远。1-7月，全市规上工业企业主营业务成本同比增长11.1%，高出全市规上工业主营业务收入增速0.9个百分点；每百元主营业务收入中的成本为88.66元，同比增加0.64元；全市规模以上工业利润总额同比仅增5.8%，增幅低于全省平均水平4.8个百分点

（二）部分限上大类商品销售疲软。一是鞋帽类商品零售波动较大。1-7月，限上鞋帽类商品零售额70.50亿元，同比增长8.3%，增幅比1-6月回落3.3个百分点，其中7月当月下降8.3%。主要是部分实体店受电商企业冲击以及电商企业关闭影响。二是粮油、食品类商品个位数增长。1-7月，限上粮油、食品类商品零售额仅增5.6%，增幅同比回落15.1个百分点，其中7月当月仅增1.3%。三是家电类商品消费饱和。家电更新换代较慢，又恰逢淡季，1-7月，家电类商品零售额下降18.2%，主要受家电更新换代较慢，恰逢淡季影响。

（三）固定资产投资动力不足。一是项目个数减少，投资额下降。1-7月，全市在库项目1479个，同比减少590个，特别是5000万以下项目1201个，同比减少635个，投资额同比下降47.7%。二是基础设施投资降幅扩大。1-7月，全市基础设施投资同比下降7.9%，降幅比1-6月扩大1.8个百分点。其中交通运输业投资同比下降20.4%；电力、热力、燃气及水的生产和供应业投资下降19.1%；水利管理业投资下降17.7%。三是民间投资回落明显。1-7月，全市民间投资同比仅增5.7%，增幅同比回落36.6个百分点，其中项目民间投资增速回落66.7个百分点，工业民间投资增速回落23.9个百分点。

四、对策建议

（一）激发工业发展活力。继续落实支持企业发展的各项政策，加大企业降费减税力度，减少企业生产、运营各项成本，从而拓展利润空间，缩减停减产企业规模，提升生产意愿。加快产业转型升级，不断延长上下游产业链，推动企业上规模提档次，支持有条件的企业开发高端产品，积极争取工业企业项目技改资金，努力为中小企业解决融资难等问题。围绕重点产业发展，量身定制相关的配套政策，充分激活工业发展活力。

（二）扶持零售业发展。加强宏观管理，制定行业规划，平衡零售业布局，为零售业的发展提供更好的软环境。加快推进以连锁经营、特许经营和电子商务为代表的现代零售方式。积极引导连锁经营从超市、百货店、便利店、专卖店等多业态渗透；鼓励城市连锁和超市向农村延伸，鼓励零售企业下乡，积极开拓农村消费市场。

（三）提升固定资产投资效率。继续加大招商引资力度，积极策划和退胡一批科技含量高、市场前景好、发展潜力大、带动效应强的好项目、龙头项目，进一步加强项目储备，提高发展后劲。加大对大项目的指导服务，密切跟踪重大投资项目推进情况，及时解决项目推进过程存在的问题，防止重大投资项目出现断档现象；对部分进展缓慢的重点项目，实行责任到人，月度监督，及时有效解决项目存在的问题，确保项目尽快落地开工。
