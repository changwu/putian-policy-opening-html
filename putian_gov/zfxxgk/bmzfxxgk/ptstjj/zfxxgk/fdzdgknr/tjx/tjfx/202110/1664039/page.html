迎难而上 莆田经济发展表现出强大韧性——2021年前三季度莆田市经济运行情况分析

第六十七期
发布时间：2021-10-20 09:10
| | |

今年9月以来面对本轮突发疫情的冲击，在市委、市政府的坚强领导下，全市上下凝心聚力，共度难关，不到一个月就夺取了疫情防控阻击战的全面胜利，经济社会秩序已基本恢复正常。尽管前三季度主要经济指标增速受疫情影响有所回落，但全市经济发展还是表现出了强大韧性，除实际利用外资以外，26个主要经济指标均实现了增长。初步核算，前三季度，全市地区生产总值完成2286.10亿元，可比增长6.6%，增幅比上年同期提高5.1个百分点。其中：第一产业增加值95.51亿元，增长3.0%；第二产业增加值1150.77亿元，增长5.2%；第三产业增加值1039.83亿元，增长8.7%，三次产业结构调整由上半年的4.6：50.7：44.7为4.2：50.3:45.5，第三产业增加值占GDP比重比上半年提高0.8个百分点。

一、前三季度经济运行情况

（一）从供给端看

1、农业稳中有进。前三季度，全市农林牧渔业总产值完成178.33亿元，可比增长3.6%，增幅比上半年提高0.6个百分点。主要亮点：一是加强气象预报预警，适时进行人工降雨，加强防冻减灾、防涝抗旱等农作物田间管理服务，茶叶、园林水果和蔬菜产量分别增长4.2%、1.0%和1.0%。二是加大规范实施口蹄疫、猪瘟免疫等重大动物疫病防控力度，加强协调解决疫情期间畜牧业生产所需的物资调配保障工作，生猪存、出栏分别增长47.0%和15.0%；三是引进建设 “振渔2号”高端智能养殖平台和“海峡2号”深远海养殖网箱，大面积推广龙须菜与海带轮养、鲍鱼南北对调养殖等健康养殖模式，水产品总产量增长3.8%。

2、工业建筑业稳中趋缓。前三季度，全市规模以上工业增加值可比增长8.4%，增幅比上半年回落5.6个百分点。主要亮点：一是全市规上工业33个行业大类中有26个行业增加值实现增长，增长面为78.8%，特别是占据主导地位的规上“343”重点产业工业增加值增长9.0%，拉动规全市规上工业增加值增长8.4个百分点；二是全市225家大中型规上工业企业增加值增长12.6%，增幅高于全市规上工业增加值4.2个百分点，拉动全市规上工业增加值增长6.3个百分点。全市建筑业总产值完成601.15亿元，同比增长10.9%，增幅比上半年回落8.5个百分点。其中，全市资质建筑企业在外省完成产值348.38亿元，增长22.1%，占全市建筑业总产值的58.0%，拉动全市建筑业总产值增长11.6个百分点。

3、服务业稳步增长。一是规模以上商务服务业、软件和信息技术服务业快速增长。1-8月，全市规上商务服务业实现营业收入31.99亿元，增长22.2%，拉动全市规上服务业营业收入增长5.3个百分点；规上软件和信息技术服务业营业收入由上年同期的下降29.6%转为增长55.1%，增幅高于全省平均水平38.6个百分点。二是批零住餐业销售额（营业额）保持两位数增长。前三季度，全市批发业、零售业、住餐业销售额（营业额）分别增长40.5%、15.8%和21.2%，增幅虽然分别比上半年回落13.9个、16.9个和20.5个百分点，但仍保持两位数增长。三是商品房销售面积增幅稳居全省首位。前三季度，全市商品房销售面积完成389.50万平方米，增长28.4%，增幅高于全省平均水平17.4个百分点，虽然比上半年回落20.4个百分点，但增幅仍连续六个月居全省首位。

（二）从需求端看

1、固定资产投资保持增长。前三季度，全市固定资产投资同比增长3.9%，增幅比上年同期提高7.9个百分点。主要亮点：一是房地产投资贡献突出。占全市固定资产投资23.1%的房地产开发投资增长13.5%，增幅高于全市固定资产投资9.6个百分点，拉动全市固定资产投资增长2.9个百分点，是固定资产投资持续增长的主要支撑。二是投资质量逐步提高。三次产业投资占比由上年同期的1.0：33.1：65.9调整为1.3：30.4：68.3，第三产业投资占比提高2.4个百分点。特别是高技术产业投资增长36.8%，占全市固定资产投资的11.9%，占比同比提高2.8个百分点；改建和技术改造投资增长43.4%，占全市固定资产投资的7.9%，占比同比提高2.2个百分点。

2、消费市场持续回暖。前三季度，全市社会消费品零售总额完成1318.17亿元，同比增长11.7%，增幅比上年同期提高12.7个百分点。主要亮点：一是全市限上21类商品类别中有17类商品实现正增长，增长面为81.0%，形成以鞋帽类、日用品类和汽车类为主的限上消费品市场。其中，限上鞋帽类零售额115.41亿元，增长19.6%；限上日用品类零售额61.08亿元，增长24.6%；限上汽车类零售额56.57亿元，增长8.0%。二是网上零售快速增长。占全市社会消费品零售总额18.5%的限上网上商品零售额同比增长20.7%，增幅高于社会消费品零售总额9.0个百分点，拉动社会消费品零售总额增长3.5个百分点。

（三）从要素、民生端看

1、财政金融保持两位数增长。前三季度，全市财政总收入完成200.26亿元，增长19.6%，增幅高于上年同期23.8个百分点，其中，地方财政收入完成126.14亿元，增长19.6%，增幅高于上年同期24.2个百分点。财政支出完成183.59亿元，增长1.1%。9月末，全市金融机构本外币存款余额2583.66亿元，增长11.1%；金融机构本外币贷款余额2422.07亿元，增长10.6%，保持两位数稳定增长态势。

2、民生保障更加坚实。9月末，全市城镇新增就业人数17367人，城镇失业人员再就业6732人，城镇登记失业率为2.77%，低于5%的控制目标。前三季度，市区居民消费价格总水平同比上涨0.3%，涨幅比上年同期回落2.0个百分点，八大类消费“三增三降两持平”，其中：教育和文化娱乐类价格上涨3.3%，交通和通信类上涨2.8%，生活用品及服务类上涨0.8%；其他用品和服务类价格下降6.0%，食品烟酒类价格下降0.8%、居住类价格下降0.1%；衣着类、医疗保健类价格与去年持平。

二、经济运行中存在问题

（一）工业经济稳增长压力大。一是停减产面扩大。截至9月末，全市规模以上停、减产企业达399家，停减产面达35.3%，比1-6月扩大11.8个百分点，影响全市规上工业增加值增长4.3个百分点，主要受9月疫情影响部分企业因员工无法返岗、原材料和产品运输受限，影响企业正常生产，加上销售不畅、成本提高等因素影响。二是小微企业增长疲软。占全市规模以上工业企业数80.1%的规模以上小微工业企业增加值仅增3.4%，增幅分别低于全市规模以上工业和规模以上大中型企业5.0个和9.2个百分点，小微企业增长疲软是影响全市工业经济增长的主要因素之一。

（二）建筑业发展尚存短板。一是停产面扩大。截至9月末，全市倒闭（停业）企业数达60家，停产面为11.8%，比上半年扩大1.3个百分点。主要是受疫情影响，原材料无法运输到位、部分工人无法返岗，导致9月全市在建项目大部分停工。二是新签合同额和新开工面积出现“双降”。资质建筑企业新签合同额由上年同期的增长54.6%转为下降10.1％，承建的房屋建筑新开工面积由上年同期的增长45.1%转为下降14.2%。

（三）固定资产投资增长后劲不足。一是9月份固投下降明显。9月份，全市固定资产投资下降39.9%，主要是全市有近500个投资项目受疫情影响及其他方面的原因停工，部分未停工项目也因原材料运输受限、施工人员无法到岗等因素影响建设进度。二是新开工项目不足。前三季度，全市纳统投资项目数仅相当于2019年同期的65.8%，新开工项目计划总投资同比下降44.3%，新开工项目投资下降32.1%，其中9月当月下降29.2%。三是重点行业投资低迷。占全市固定资产投资57.5%的工业投资和基础设施投资均出现负增长，1-9月分别下降0.8%和5.0%，重点行业投资低迷势必影响了全市固定资产投资的持续增长。

（四）消费市场活力有待进一步激发。一是本月无营业企业较多。截至9月末，全市本月无营业企业达564家，占限上贸易企业数的28.1%，主要是受资金紧张、企业经营不善而注销、经济纠纷、季节性因素及疫情等各种因素影响。二是实体企业经营困难。前三季度，限上有店铺零售额仅增5.1%，主要是实体商贸流通企业大多数面临客流不足、房租及人员等成本高等问题，经营环境较为艰难，经营压力较大，加上本轮疫情影响导致多家本地超市门店关闭。三是住餐业受疫情影响较大。第三季度，住宿业和餐饮业营业额分别下降25.5%和5.2%，主要是餐饮企业响应疫情防控要求，取消各种聚餐及宴请活动，原本的中秋和国庆两大消费高峰也没了，导致餐饮企业业绩大幅回落，而住宿业企业大部分被政府征用为隔离点，隔离费用何时到帐尚未明确。

三、对策及建议

（一）精准帮扶企业。建议各行业主管部门要积极贯彻落实市、县各级出台的各项复工复产措施，及时梳理目前仍尚未复工复产的企业名单，“一企一策”精准对接，协调解决企业复产复工中遇到的各种难题，在做好疫情防控的前提下有序推动企业全面复工复产。建议以龙头企业带动产业链供应链复工复产，实行以大带小、以强带弱或者抱团取暖的方式，推动全产业链协同复工复产，确保企业供应链稳定。

（二）主动纾困解难。建议各行业主管部门充分发挥网上平台作用，快速收集和处理企业在用地、资金、技术、市场、产品认证和资质认证等方面面临的困难和问题，有针对性地研究解决措施，建立问题清单、责任清单和时限清单，尽早解决打通企业产能恢复的硬阻点，让纾困解难常态化。要强化服务保障，加快落实市、区助企纾困系列政策措施，助力企业加快复工复产，有效保障重点项目建设需求，尽快恢复正常生产生活秩序。

（三）加强金融支持。建议因企施策加大金融授信支持，综合运用抗疫贷、纾困贷等各类优惠贷款品种满足受疫情影响企业信贷资金需求。开通线上信贷申请绿色通道，提高金融信贷效率，通过调整还本付息安排、完善展期衔接和无还本续贷等措施进行纾困帮扶，保障融资服务连续性，解决企业资金周转不足的难题。

（四）助力产销对接。建议拓宽莆田产品的销售渠道，积极搭建平台，发挥龙头企业带动效益，增加对市内上下游配套企业的采购，促进产业融合创新发展。加大经销商与生产大户的产销对接工作，发动各级机关事业单位对全市优质农产品进行团购。大力发展直播经济、互联网+经济等消费新模式，积极开展“县区长+直播”、“网红+直播”等直播促销活动，助力产销对接。

（五）抓好安全生产。建议各行业主管部门要实时关注行业内企业生产恢复情况，要求企业把疫情防控和安全生产作为复工复产的基础和前提，毫不放松落实落细各项防控措施，压紧压实安全生产责任，确保复工复产安全有序。

（六）激发消费需求。建议研究出台刺激消费的政策（如去年的“全闽乐购”、发行消费券等），带动消费市场复苏。针对近期省里出台的汽车下乡活动、家电下乡活动等政策研究具体实施细则，促进汽车和家电消费回升及商品更新换代，激发消费者需求。鼓励住宿餐饮企业积极适应消费升级趋势，加快推动产品迭代更新，提升服务质量，保持市场竞争优势，增加营业收入。
