规模以上服务业增长放缓 存在问题亟需关注——1-5月莆田规模以上服务业运行情况分析

第三十四期
发布时间：2018-07-16 15:44
| | |

今年以来，市委、市政府始终把加快发展服务业作为推进经济结构转型升级的重要动力，全市规模以上其他营利性服务业总体呈较快发展态势，为第三产业经济较快增长做出了积极的贡献，但服务业增速放缓，部分民生相关行业发展显疲弱，企业规模整体偏小、竞争力弱，区域发展差距大等问题亟需关注。

一、运行的主要特点

（一）其他营利性服务业贡献突出

1-5月，全市334家规模以上其他营利性服务业企业实现营业收入20.52亿元，增长34.5%，增幅虽比1-4月回落2.2个百分点，但仍比全省平均水平高8.0个百分点，居全省第五位，对全市第三产业增加值的贡献率达44.3%，拉动全市第三产业增加值增长4.2个百分点。一是租赁和商务服务业仍是拉动全市其他营利性服务业增长的主要动力。全市租赁和商务服务业实现营业收入13.59亿元，增长32.6%，对规模以上其他营利性服务业营业收入增长的贡献率为63.3%，拉动规模以上其他营利性服务业营业收入增长21.9个百分点；二是新增企业拉动有力。去年5月以来新入库的160家其他营利性服务业企业实现营业收入7.74亿元，同比增长2.0倍，对规模以上其他营利性服务业营业收入增长的贡献率达97.8%，拉动规模以上其他营利性服务业营业收入增长33.8个百分点；三是民生相关行业快速增长。全市居民服务修理和其他服务业及文化体育娱乐业营业收入增势强劲，分别增长57.7%和42.7%，增幅分别高于其他营利性服务业23.2和8.2个百分点。

（二）科技服务业增势强劲

近几年，莆田加快实施科技创新驱动战略，科技创新动力逐步增强。1-5月，全市科学研究和技术服务业营业收入1.08亿元，增长63.9%，增幅同比提高34.1个百分点。其中，专业技术服务业增长38.3%，增幅同比提高6.5个百分点；科技推广和应用服务业增长2.6倍。

 二、存在的主要问题

自2017年11月以来，全市规模以上服务业营业收入增速逐月放缓。1-5月，全市480家规模以上服务业企业实现营业收入47.89亿元，增长5.8%，增速同比回落33.8个百分点，居全省的位次下滑至第七位。

（一）企业规模整体偏小

受经济发展阶段影响，莆田服务业企业规模扩张速度总体较慢，重点品牌企业不多，专业水平和竞争力不强。截止5月底，全市规模以上服务业企业户均营业收入仅998万元，其中，营业收入超亿元的企业仅7家，近八成的企业营业收入规模在全省平均水平以下，表明服务业企业平均规模偏小、竞争力弱。分行业看，全市28个行业大类中，仅房地产中介服务和水利管理业户均规模高于全省平均水平，分别为1184万元和264万元，其他26个行业户均规模均远低于全省平均水平。

（二）信息传输、软件和信息技术服务业低位增长

以“互联网+”为代表的新业态不断涌现，很多传统的、固化的商业模式受到冲击，其中影响较大的是电信行业，莆田移动、电信和联通三大电信运营商营业收入增速明显回落。1-5月，全市信息传输、软件和信息技术服务业营业收入仅增长4.0%，增幅同比回落12.5个百分点。其中，电信、广播电视和卫星传输服务业营业收入下降3.5%，增幅同比回落10.0个百分点；软件和信息技术服务业增长28.4%，增幅同比回落86.8个百分点。

（三）民生相关行业发展滞后

1-5月，全市教育行业仅实现营业收入1827万元，下降5.9%，降幅同比缩小7.8个百分点，户均营业收入仅141万元；卫生行业营业收入仅4815万元，增幅由上年同期的增长18.8%转为下降41.4%；文化艺术行业仅1家企业，体育行业仅3家企业。此外，健康、养老、医疗等服务业供给不足,不能很好满足居民消费需求，目前尚未有达到规模的健康养老服务企业纳入我市规模以上服务业统计范围。

（四）区域发展不平衡

全市规模以上服务业企业呈区域性集中分布，各县区发展水平差异大。从营业收入占比看，规模以上服务业企业主要集中在城厢区和荔城区，营业收入合计占全市规模以上服务业营业收入的比重达67.6%。其中，城厢区156家，占全市企业数的32.5%，实现营业收入12.22亿元，占全市规模以上服务业营业收入的比重为25.5%；其次是荔城区，企业数114家，占全市的23.8%，实现营业收入20.15亿元，占全市的42.1%。其他5个县（区、管委会）共有企业210家，占全市企业数的43.8%，实现营业收入15.52亿元，仅占全市服务业营业收入的32.4%。从营业收入增速看，涵江区增长26.8%，增速同比回落48.9个百分点；北岸增长24.7%，增速同比回落64.6个百分点；城厢增长22.7%，增速同比提高0.8个百分点；荔城区增长6.9%，增速同比回落10.0个百分点；湄洲岛增长5.7%，增速同比回落26.1个百分点；仙游县增长1.5%，增速同比回落30.5个百分点；秀屿区由上年同期的增长2.3倍转为下降20.3%。

三、加快发展规模以上服务业的若干建议

（一）提高认识，健全激励机制

受传统政绩观的影响，一些地区和部门对发展服务业的重要性认识还不够充分，对服务业发展还不够重视，激励服务业发展的各项政策措施还没有健全或者没有真正发挥作用，建议将规模以上服务业发展主要指标纳入市对县区的绩效考核，同时将规模以上服务业培育达规工作纳入市直相关职能部门的绩效考核，建立服务业发展的整体性、系统性和科学性考核监测机制。

（二）聚焦短板，优化产业结构

全市规模以上服务业行业分布较为集中，传统服务业占比大，虽然新兴服务业增长较快，但企业数量少、规模小，带动作用不强。应根据全市经济发展进程及时调整产业导向，优化行业结构。着力推进“互联网+”行动计划，以“数字莆田”建设为依托加快发展平台经济，推动大平台、大市场、大流通融合发展，重点推动大数据、云计算等新技术在健康养老、家政、旅游服务业等我市薄弱行业领域中的应用，打造适宜平台经济发展的法治营商环境，培育一批特色鲜明、竞争力强的平台经济品牌企业，建设一批功能完备、配套完善的平台经济集聚区，转莆田“GNP”为“GDP”。依托我市纺织鞋服、电子信息、电子商务等行业优势，重点突破软件外包、设计研发、贸易营销、专业配套、创意设计等领域，培育一批创新能力强、具有国际竞争力的服务外包龙头企业。

（三）优化发展环境，加大培育帮扶

近几年我市服务业发展取得一定成效，但受地方经济发展水平、自然环境及产业结构的影响，以及资金、人才、土地等资源要素的制约，全市服务业发展存在总体规模偏小、大企业少、竞争力弱等问题。要加快发展服务业，应尽快完善出台鼓励和支持服务业企业发展的优惠政策，增强现有企业发展动力，吸引规模大、竞争力强的服务业企业入驻莆田。要进一步优化提升政府服务水平，降低企业成本，在政策扶持、资金奖励、贷款支持、税费减免等方面多方助力，为服务业发展营造良好环境。各级服务业行业主管部门要精准施策，分类指导，对重点服务业企业要量身定制“一企一策”帮扶政策，着力帮助企业解决政策、资金、信息等方面的实际困难，为企业营造良好的经营发展环境。对达到规模标准的企业要应统尽统，尤其是单位数较少的县区和相关行业主管部门，要加强企业培育，特别要加大我市规模以上服务业空白行业企业的摸底和申报工作力度，将达到规模标准的企业尽快纳入规上服务业统计范围，缩小服务业在区域、行业之间的发展差距，推进全市服务业健康持续发展。
