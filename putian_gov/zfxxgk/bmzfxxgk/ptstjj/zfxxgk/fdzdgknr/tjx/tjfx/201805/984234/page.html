2018年一季度我市能源生产消费情况简析

第二十五期
发布时间：2018-04-28 09:06
| | |

2017年我市单位GDP能耗下降率为0.14%，与年度目标任务相差较大。随着经济的稳步运行，一季度我市一、二、三产均呈现较好的发展态势，用电量增速提高；同时规模以上工业新增入库企业规模大，能耗高，导致我市规模以上工业能耗增速大幅提高，进而影响了一季度我市节能任务的完成。

一、能源生产情况

2018年1-3月我市规模以上发电量为56.70亿千瓦时，同比增长100.0%，增幅较2017年全年提高68.9个百分点。其中，火力发电量为41.37亿千瓦时，同比增长170.7%，占规模以上发电量的73.0%；水力发电量为7.18亿千瓦时，同比增长17.3%，占规模以上发电量的12.7%；风力发电量为8.15亿千瓦时，同比增长17.8%，占规模以上发电量的14.3%。

可见火力发电仍是我市最主要的电力来源。国投云顶湄洲湾电力有限公司投产发电以来，我市火力发电增速始终保持在较高水平，今年一季度各月当月火力发电增速分别为：171.2%、135.4%、206.3%，增势迅猛。

二、能源消费情况

（一）全社会用电量增势较强

一季度，我市全社会用电量为32.23亿千瓦时，同比增长20.2%，增幅较上年扩大19.8个百分点。其中，第一产业用电量为0.23亿千瓦时，同比增长28.7%；第二产业用电量为19.82亿千瓦时，同比增长22.2%；第三产业用电量为3.81亿千瓦时，同比增长18.7%；居民用电为8.02亿千瓦时，同比增长16.0%。

（二）规模以上工业综合能源消费量增长较快

一季度，我市规模以上工业综合能源消费量为88.07万吨标准煤，同比增长83.4%，增幅较上年同期提高66.1个百分点；完成工业增加值同比增长7.9%，工业增加值能耗增长9.4%。

1、六大高耗能行业能耗增速高，比重大

一季度，我市六大高耗能行业综合能源消费量为69.09万吨标准煤，同比增长129.1%，增幅提高104.1个百分点，占全市规模以上工业综合能耗的78.4%，推动作用达81.1个百分点。其中，电力、热力生产和供应业综合能源消费量为62.76万吨标准煤，同比增长154.4%，推动全市规模以上工业综合能耗增长97.3个百分点，是高耗能行业对全市规模以上能耗的主要影响力。

2、五成的规模以上工业行业综合能耗呈增长

我市现有的32个规模以上工业企业行业中有16个行业综合能源消费呈现增长趋势，占比达50%。其中，黑色金属冶炼和压延加工业增速最高，增幅达到3922.3%，主要是鞍钢冷轧恢复生产造成的能耗增长。另外，计算机、通信和其他电子设备制造业，电力、热力生产和供应业，木材加工和木、竹、藤、棕、草制品业，汽车制造业，通用设备制造业综合能源消费量增幅均在15%以上。

3、原煤、天然气消费量增速高，增幅大

一季度，我市规模以上工业原煤消费量为153.54万吨，同比增长157.8%，其中电力、热力生产和供应业原煤消费量最大，占比达89.1%，其次是化学纤维制造业，占比为5.5%。一季度，电力、热力生产和供应业及化学纤维制造业工业增加值同比增长22.8%，带动原煤消费量的增长。同时，一季度我市天然气消费量为1.74亿立方米，同比增长58.2%，高于上年同期增幅40.5个百分点。

三、节能形势预判

2018年一季度我市节能工作仍保持预警的严峻形势，预计单位GDP能耗速度较2017年将只增不减。

（一）全社会用电量增速提高。电力消费占全社会能源消费比重始终保持50%以上，是影响我市全社会能耗的主要因素。全社会用电量增速越高，意味着全社会能耗的增速越高。一季度我市全社会用电量增速为20.2%，增速较2017年全年高出10.0个百分点。因此，一季度单位GDP能耗速度将高于2017年全年。

（二）新增规模以上工业企业能耗高。2017年我市新增火电二期、华佳彩、华锦等规模较大的规上工业企业，同时恢复鞍钢冷轧的生产，这些企业能耗基数为0，一季度能耗合计为48.16万吨标准煤，占规上工业综合能耗的54.7%，能耗增量拉动全市规上工业综合能耗100.3个百分点。然而，这些企业对工业增加值的拉动力却较低，这将直接影响规模以上工业增加值能耗的下降率，进而影响单位GDP能耗的下降率。
