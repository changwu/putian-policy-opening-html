2014年上半年莆田市劳动情况分析

发布时间：2014-07-31 00:00
| | |

上半年，春节期间的季节性工人返乡潮影响逐渐退去，工人稳定性相对提高，同时新开工一批建筑项目也使得工人需求量有所增加，因此我市城镇单位从业人员总量同比有所增长，随着人力资源在生产要素中的地位越来越高，单位投入的人力资本也随之水涨船高，工资水平保持了平稳快速的增长，就业形势总体发展良好，但企业工荒现象持续存在，这势必将影响企业后续发展，需引起各方面足够重视。

一、基本情况

（一）城镇非私营就业总量同比增长平稳

截至6月底全市城镇非私营单位从业人员为43.44万人，较上年同期增加4.85万人，增长12.6%，其中在岗职工为41.33万人，增加3.86万人，增长10.3%。

从不同经济类型看：国有单位从业人数为101928人，同比减少949人，下降0.9%，主要由于部分国企、事业单位正常人事调配；城镇集体单位从业人数6426人，减少590人，同比下降8.4%，主要为企业关停并转及人员正常流转；其他所有制单位人数326025人，增加5万人，同比增长18.1%，但增速较上季度回落了1.9个百分点，连续两个季度增幅处于下降状态。虽然由于建筑新增项目上马，人力资源需求量相应增加，以及数据并轨、口径变化等因素，就业容量持续扩充，但经济增速整体放缓，用工荒长期存在，普工短工化现象较为普遍，未来就业增容速度将逐步回落。

从不同行业分类看，1-6月份从业人数的增长主要来自于制造业和建筑业。其中增速最快、增长绝对量最大的为建筑业，由于上年末新增不少建筑企业纳入统计范围，从业人数有了较大的增加，因此6月底建筑业从业人数为11.23万人，同比增速为54.7%，增加3.97万人，而制造业依然是吸纳劳动就业的主要渠道，从业人数为19.11万人，虽然同比增速2.1%低于上季水平，但总量仍占城镇非私单位从业总数的44%。

（二）职工工资总额持续增长

上半年，全市城镇非私营单位从业人员工资总额为97.19亿元，比上年同期增长29.9%，其中在岗职工工资总额92.35亿元，同比增长26.3%，保持平稳较快的发展势头。

从国有、集体、其他分组看，本季工资总额增长主要来自于其他所有制单位效益提升带来的工资增长，而国有、集体单位工资晋级及少量补发增资带来的提升影响并不显著。其中，国有单位从业人员工资总额为28.37亿元，比上年增长9.2% ；城镇集体单位工资总额为1.58亿元，比上年增长3.3%；其他单位工资总额为67.24亿元，同比增长42.1%。

从行业分类看，从业人员工资总额的增长基本遵从从业人数的增长，增速最快、增加绝对额最多的是建筑业，工资总额为26.27亿元，增加11.87亿元，同比增速为82.4%。

（三）平均工资平稳较快增长

全市上半年城镇非私营从业人员平均工资为22464元，同比增长15.8%；在岗职工平均工资为22437元，同比增长14.8%，呈平稳增长态势。

从国有、集体、其他单位分组来看，国有单位在岗职工平均工资为27738元，比上年同期增长11.4%，主要由于正常工资晋级以及行政、事业单位全面补发之前的少量增资；城镇集体单位在岗职工平均工资为24920元，比上年同期增长16.6%，主要由于春节期间集中发放年终奖；其他所有制单位在岗职工平均工资为20659元，比上年同期增长18.5%。主要由于制造业开工不足，为了吸引工人普遍增加用工成本，提高薪酬待遇，因此劳动密集型工作的工资保持了较快的增长，从而拉高其他所有制职工工资的整体水平。

从国民经济各行业看，除个别行业有略微下降外，大部分行业职工工资都有不同程度的增长，其中同比增幅10%以上的行业有10个。我市各行业中，上半年平均工资处于20000元/人至30000元/人区间的行业占多数，共有13个，30000元/人以上的行业仅2个，20000元/人以下的行业有4个，其中上半年平均工资最高的为金融业62844元/人，其次是卫生和社会工作34283元/人，第三为电力、燃气及水的生产和供应业29826元/人。而工资最低的为采矿业8604元/人，其次是住宿和餐饮业14274元/人，第三为批发和零售业17728元/人。平均工资最高行业与最低行业的差比为7.3：1。

二、存在问题

（一）招工难。随着人口红利的消退及经济环境的变化，一直存在的工荒现象近年来似乎愈演愈烈，对企业尤其是劳动密集型企业的发展带来越来越显著的影响。2013年底我市城镇非私营单位从业人员为46.64万人，比增25.4%，2014年一季度为41.73万人，比增12.8%，而6月底为43.44万人，比增12.6%，半年来的季度环比增幅连续处于下降态势。其中第二产业受到的影响尤为明显，2013年底我市第二产业从业人员总数为34.3万人，同比增幅为33.3%，2014年一季度为29.52万人，同比增幅为16.7%，二季度为30.99万人，同比增幅为16%。

（二）用工贵。与从业人数增幅的明显下降相对应的是平均工资的持续走高，这也意味着企业用工成本的不断增加。2013年底城镇非私营单位在岗职工（含劳务派遣人员）年平均工资为43963元，同比增幅为9.8%，2014年一季度在岗职工（含劳务派遣人员）单季平均工资为11379元，同比增幅14.4%，而2014年二季度在岗职工（含劳务派遣人员）半年平均工资为22437元，同比增幅14.8%；其中第二产业自2013年底以来这一指标分别39985元、10397元和20203元，同比增幅也依次为9.7%、18.4%和18.8%。

三、建议

（一）双管齐下破解招工难。一方面企业要向产业结构升级、先进管理机制要效益，加快转变生产经营方式，摆脱传统的依靠密集劳动获得效益的思路；另一方面要注重对劳动者技能的更新换代，这不仅是教育部门的责任，也是企业与劳动者共同的责任。教育要与社会接轨，培养更多既有人文精神又具备职业素养的适销对路的人才。企业不仅仅是从社会寻找人才，更要学会培养适应自身需要的人才，同时要建立长效的用人机制。而求职者则既要有想法，又要有办法，更多地了解企业的需要，有针对性地提高自身的职业素质，从而提高职场竞争力。

（二）用工贵是把双刃剑。用工成本提高对企业与个人来说都是既有坏处又有好处。对企业来说，用工成本提高无疑加重企业负担，但同时也促进了产业转型和更新换代；对劳动者来说，工资待遇提高是劳动力价值提高的具体体现，但也意味着企业对劳动者素质、能力等方面有了更高的要求和期待。所以工资水平的适度增长有利于劳动力市场供求关系的调节，有利于社会的稳定和谐，但过高的工资水平超出企业负担，可能成为压垮企业的最后一根稻草，也不利于维护社会公平，需要政府对过高工资给予限制，对低工资阶层给予补贴。

（注：本文所述在岗职工均包含劳务派遣人员）
