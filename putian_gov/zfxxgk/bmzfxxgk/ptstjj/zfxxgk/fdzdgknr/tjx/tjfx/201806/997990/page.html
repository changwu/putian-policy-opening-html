2018年1-5月莆田市规模以上工业经济运行分析

第三十一期
发布时间：2018-06-19 08:24
| | |

今年以来，我市工业经济稳中向好，先关先行指标保持较快增长，随着供给侧结构性改革不断深化，结构调整步伐加快，工业经济迈向高质量发展。1-5月，全市规模以上工业增加值增长8.7%,比1-4月提高0.5个百分点，增幅排名前移二名,位居全省第三位。

一、工业经济运行主要特点

（一）工业先行指标总体向好。一是工业用电量明显上升，持续保持较快增长。5月全市工业用电量8.78亿千瓦时，增长79.7%，比4月上升51.0个百分点。1-5月全市工业用电量33.78亿千瓦时，增长33.9%，比1-4月上升10.0个百分点，增幅位居全省九设区市第一位。扣除抽水蓄能后，5月全市工业用电量增长76.0%。1-5月全市工业用电量累计增长32.4%，增幅位居全省九设区市第一位。制造业用电量保持快速增长。5月全市制造业用电量增长98.2%，比4月上升64.7个百分点。1-5月，全市制造业用电量增长39.7%，比1-4月上升15.4个百分点。制造用电量保持较快增长主要原因是部分省级龙头企业本月抄表时间调整、周期加长以及气温因素的影响。二是工业增值税两位数增长。1-5月全市工业增值税增长15.1%，已连续3个月保持两位数增长。

（二）重点行业保持较快增长。1-5月份，33个大类行业中有22个行业增加值同比正增长，并且16个行业实现两位数增长。其中食品制造业增长10.4%，皮革、毛皮、羽毛及其制品和制鞋业增长10.5%，计算机、通信和其他电子设备制造业增长27.3%，纺织业增长42.1%,电力、热力生产和供应业增长50.0%。

（三）亿元企业挑大梁。1-4月，全市超亿元以上规模企业共有329家，占规模以上工业企业单位数的27.0%，工业增加值增长19.0%，增速比全市规模以上工业平均增速高10.3个百分点，对规模以上工业经济增长的贡献率为134.7%，拉动规模以上工业增加值增长11.7个百分点。

（四）私营企业活力涌现。1-5月，全市规模以上私营企业工业增加值增长16.6%，增速比全市规模以上工业平均增速高7.9个百分点，对规模以上工业经济增长的贡献率为23.0%，拉动规模以上工业增加值增长2.0个百分点。

（五）技改企业显成效。1-5月，全市108家规模以上工业技改企业工业增加值增长16.4%，增速比全市规模以上工业平均增速高7.7个百分点，对规模以上工业经济增长的贡献率为29.6%，拉动规模以上工业增加值增长2.6个百分点。

（六）新投产工业企业拉动作用明显。1-5月，全市16家去年新投产企业对规模以上工业经济增长的贡献率为31.1%，拉动规模以上工业增加值增长2.7个百分点。

（七）民营企业贡献突出。1-5月，全市规模以上民营企业工业增加值增长7.2%，占全市规上工业增加值总量75.9%，对规模以上工业经济增长的贡献率为66.7%，拉动规模以上工业增加值增长5.8个百分点。

（八）“三新”工业企业增长喜人。1-5月，全市战略性新兴产业工业增加值增长20.2%，增速高于全市规模以上工业平均增速11.5个百分点，对规模以上工业经济增长的贡献率为31.1%，拉动规模以上工业增加值增长2.7个百分点；高技术企业工业增加值增长16.1%，增速高于全市规模以上工业平均增速7.4个百分点，对规模以上工业经济增长的贡献率为9.8%，拉动规模以上工业增加值增长0.8个百分点。

（九）传统制鞋产业支撑明显。1-5月，占全市规上工业增加值总量28.5%的制鞋产业工业增加值增长10.3%，对规模以上工业经济增长的贡献率为31.9%，拉动规模以上工业增加值增长2.8个百分点。一是内销市场的开拓。东方猎狼、大诚、新步、三威、祥冠、三迪等制鞋企业，本年新增“足力健”老人鞋的生产订单，预计全年有7500万双的“足力健”老人鞋订单生产。二是外销订单回暖。主要是原先转移到东南亚的制鞋订单受税费、基础设施及工人素质等因素影响，回流到国内生产。

二、存在问题

（一）停、减产企业影响明显。5月末，全市停、减产面达30.4%，共拉低全市工业增加值增幅7.4个百分点。其中停产企业97家，比4月末增加7家，拉低全市工业增加值增幅5.0个百分点。减产企业274家，比4月末增加2家，拉低全市工业增加值增幅2.4个百分点。

（二）规上工业企业数减少，转规企业贡献不足。5月末，全市共有规模以上工业企业1220家，但比上年同期减少42家。37家去年年底转规企业对规模以上工业增加值增长的贡献率为4.6%，仅拉动规模以上工业增加值增长0.4个百分点。

（三）传统工艺与创意产业不景气。受红木市场不景气和产品转向中低端市场影响，1-5月我市工艺创意产业工业增加值下降5.1%，拉低全市工业增加值增长0.2个百分点。

（四）工业企业去库存、降成本任重道远。1-4月，全市规模以上工业产成品存货增长33.3%，比上年同期提高30.7个百分点；全市规模以上资产负债率52.6%，比上年同期下降0.4个百分点；每百元主营业务收入中成本87.74元，比上年同期增加1.12元。全市规模以上工业实现利润总额59.62亿元，同比下降1.7%， 低于全省平均水平14.2个百分点。

（五）外需市场仍然疲软。从产业看，我市企业外向度比较高，1-5月规上工业出口交货值增长2.7%，增幅低于全市规上工业销售产值增幅7.1个百分点，说明外需市场依旧不景气拉动力不足。
