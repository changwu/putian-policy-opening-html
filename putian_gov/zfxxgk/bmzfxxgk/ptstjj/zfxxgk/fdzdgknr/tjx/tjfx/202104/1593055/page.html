2021年1-3月莆田市经济运行情况分析

第二十二期
发布时间：2021-04-22 15:10
| | |
 今年以来，在市委、市政府的坚强领导下，全市上下大力实施“强产业、兴城市”双轮驱动，全方位推动高质量发展超越，巩固拓展疫情防控和经济社会发展成果，一季度全市经济开局良好。1-3月，全市GDP完成802.66亿元，增长18.0%，增幅比上年同期提高24.0个百分点,居全省第五位，比2020年前移一位。其中，第一产业增加值30.67亿元，增长3.1%；第二产业增加值386.27亿元，增长16.2%；第三产业增加值385.72亿元，增长21.1%。

一、经济运行特点

（一）经济实现良好开局。1-3月，27个主要经济指标中第三产业增加值、财政总收入、规上服务业营业收入、房地产投资、商品房销售面积、批发业商品销售额等6个指标增幅居全省首位；GDP、第一产业增加值、第三产业增加值、农林牧渔业总产值、建筑业总产值、财政总收入、固定资产投资、房地产投资、商品房销售面积、批发业商品零售额等10个指标增幅位次比2020年前移；GDP、规上工业增加值、社会消费品零售总额、财政总收入、固定资产投资等21个指标增幅比2020年提高。

（二）农业生产稳步增长。1-3月,全市农林牧渔业总产值完成57.53亿元，可比增长4.0%，增幅比上年同期提高2.7个百分点。主要特点：一是蔬菜稳中有升，产销两旺。全市以优质蔬菜标准化示范基地建设，推动蔬菜产业集约化育苗、设施化改造、采后商品化处理等基础设施建设，提高蔬菜生产能力，蔬菜播种面积达8.93万亩，增长0.8%；产量达17.21万吨，增长1.5%。二是渔业生产恢复常态化。随着国内疫情得到有效控制，人们生活消费逐步恢复正常，水产品价格逐步回升，渔业生产也随之恢复常态，全市水产品总产量达27.77万吨，增长4.0%。

（三）规上工业恢复较快。1-3月，全市规模以上工业增加值可比增长20.4%,增幅比上年同期提高26.3个百分点。主要特点：一是产业集聚显成效。全市规模以上鞋服产业、工艺美术产业和食品产业三大传统产业对全市规模以上工业增加值的贡献率达50.7%，拉动全市规模以上工业增加值增长10.3个百分点；全市规模以上新型功能材料、电子信息产业、高端装备产业和新能源产业四大新兴产业增加值增长27.1%，拉动全市规模以上工业增加值增长5.8个百分点；全市规模以上医疗产业增加值增长79.9%，增幅高于全市规模以上工业增加值59.5个百分点。二是工业经济效益明显提升。1-2月，全市工业经济效益综合指数为386.86，比上年同期提高59.59个点；每百元营业收入中的成本85.59元，较上年同期下降1.48元；实现利润总额45.70亿元，增长65.6%，增幅高于全省平均水平5.1个百分点。三是新增企业拉动明显。1-3月，全市新增工业企业对全市规模以上工业增加值的贡献率达12.2%，拉动全市规模以上工业增加值增长2.5个百分点。

（四）建筑业总产值快速增长。从注册地看，1-3月，全市资质内建筑业企业完成产值184.97亿元，同比增长33.5%，增幅比上年同期提高55.5个百分点。主要特点：一是“走出去”战略继续发挥作用。1-3月全市在外省完成的产值98.95亿元，同比增长38.6%，增幅比上年同期提高31.1个百分点，占全部建筑业总产值的53.5%，比去年同期提高2.0个百分点。二是发展后劲增强。1-3月，全市签订的合同额1046.03亿元，同比增长41.3%，增幅比上年同期提高43.7个百分点。新签订的合同额221.37亿元，同比增长44.7%，增幅比上年同期提高64.0个百分点。新签订合同额大幅增加，工程量加大，建筑业发展后劲迅速增强。

（五）消费市场持续火爆。1-3月，全市社会消费品零售总额完成477.56亿元，同比增长25.0%，增幅比上年同期提高32.2个百分点。主要特点：一是网上零售火热。全市限额以上网上零售额增长36.1%，占社会消费品零售总额的16.9%。二是住餐企业爆发性增长。全市限额以上住宿业和餐饮业营业收入分别增长50.4%和96.3%，主要得益于住宿餐饮企业积极参与“全闽乐购”、“云餐吧 跨年购”等促消费行动，加上今年出台的就地过年优惠政策也一定程度上促进了住宿餐饮业增长。

 （六）规上服务业蓬勃发展。1-2月，全市规模以上服务业营业收入完成42.96亿元，同比增长71.0%，增幅高于全省平均水平30.6个百分点，稳居全省首位。主要是在物泊科技有限公司带动下，全市交通运输、仓储和邮政业营业收入完成23.45亿元，同比增长1.4倍，拉动规模以上服务业营业收入增长54.2个百分点。

（七）固定资产投资增势喜人。1-3月，全市固定资产投资（不含农户）同比增长40.9%，增幅比上年同期提高69.0个百分点,居全省第三位。主要特点：一是投资结构持续优化。全市三次产业投资结构由2020年的1.1：30.7：68.2调整为0.8：28.5：70.7，第三产业投资提高2.6个百分点。二是房地产投资拉动有力。1-3月，全市房地产开发投资增长60.6%，拉动全市固定资产投资增长14.5个百分点，主要得益于土地购置费均超过10亿元的文献首府和中南莆田荔城大道项目拉动。三是商品房销售火爆。1-3月，全市商品房销售面积增长151.4%，主要得益于销售面积超过10万平方米的坂头东片区改造项目地块四安置房拉动。

二、存在问题

（一）畜牧业存在问题不容忽视。一是生猪产能尚未恢复到非洲猪瘟疫情前。1-3月，全市生猪存栏量虽然增长78.7%，但与非洲猪瘟疫情前的2018年1-3月相比下降22.4%。二是家禽存出栏出现双降态势。自去年下半年开始，随着猪肉价格的回落，家禽市场需求也随之减少，家禽生产价格也随之下跌，很多家禽养殖户也开始逐步缩小养殖规模，导致家禽存出栏分别下降11.3%和7.5%。

（二）规上工业持续增长动力仍需强化。一是停、减产企业影响较大。3月末，全市停、减产面达20.2%，拉低全市规模以上工业增加值增长6.3个百分点。二是新投产企业偏少。新投产纳统工业企业数偏少。2020年月度新投产入库工业企业数仅4家，为近五年来最少。截止3月末，全市规上企业数1125家，比上年同期减少35家。

（三）限上批零业增长后劲仍待加强。一是退库企业较多。受外部经济环境、企业资金困难等影响，3月末，203家限额以上商贸企业退库，影响全市限上消费品零售额增长4.9个百分点。二是零售额下降企业影响较大。受销售模式转变及公司战略决策改变等影响，企业市场占有份额减少，235家限上企业零售额比上年同期下降，占全市限额以上商贸业企业数的11.8%，影响全市限上消费品零售额增长8.6个百分点。

（四）规上其他营利性服务业增速偏缓。1-2月，全市规模以上其他营利性服务业营业收入11.67亿元，增长31.0%，增幅低于全省平均水平29.0个百分点，居全省末位。一是主导产业商务服务业受退库带基数企业影响拉动力减弱，18家退库带基数企业（福建远景投资管理有限公司、福建省莆田市涵江区商贸城投资管理有限公司等）影响该行业营业收入增长10.9个百分点，营业收入仅增长27.5%。二是规模以上互联网和相关服务业年度无新入库企业，同时3家退库带基数企业（福建省芬木网络科技有限公司、仙游网库信息技术有限公司等）影响该行业营业收入增长48.8个百分点，导致营业收入下降56.9%。三是规模以上租赁业受8家退库带基数企业（福建省仙游县松琴机械设备租赁有限公司、莆田市芷文机械租赁有限公司、莆田市百冠机械租赁有限公司等）影响，营业收入仅增长4.3%。

（五）固定资产投资后劲不足。截止3月底，全市新开工亿元项目仅10个，同比减少16个，计划总投资同比下降70.7%，本年完成投资同比下降56.8%，这直接影响全市投资增长后劲。扣除上年因素影响，近两年固定资产投资平均增长仅0.7%，增幅低于全省平均水平3.5个百分点。

三、对策建议

    （一）精准施策促工业。一是精准对接企业，做到精准帮扶，精准施策，优化企业生产经营环境，完善上下游产业配套，帮助工业企业提高核心竞争力，特别是对停、减产企业要逐一对接认真分析,找准原因,一企一策对症下药,帮助企业尽快走出发展瓶颈。二是进一步从政策、资金、技术、人才等方面给予企业支持,积极鼓励企业进行创新研发，进行技术改造和提升，加快企业的转型升级,打造工业经济新的增长点。三是积极组织企业开展产销对接活动，加大本地产品品牌推广力度，鼓励重点企业一方面积极参与产销对接活动，另一方面通过线上销售打开市场销路，扩大产品知名度。

（二）千方百计促消费。一是认真梳理商贸停业企业情况，将针对零售企业的相关帮扶政策落实到位，帮助企业尽快恢复生产经营，并通过节假日营销组织产销对接活动帮助企业打开市场销路。二是鼓励企业充分利用新媒体渠道打造“线下+线上+快递物流融合”的新型零售模式，通过优质化精细化服务拓宽商品销路，激发市场消费需求。三是在做好疫情防控常态化基础上保持政府惠企政策的延续性、稳定性，以提振市场信心，进一步激发个体化、多样化的消费需求，积极推进消费结构优化升级，以促进消费市场加速向好发展。

（三）狠抓项目促投资。一是全力做好重大项目招商引资工作，紧紧围绕各地产业发展规划，不断加强优势产业中强链补链项目招商引资力度，努力吸引一批技术领先、未来市场广阔的项目落户。二是加大基础设施投入，着重围绕民生领域突出短板，加大基础设施领域投入力度。全力推动在建项目加快进度，推动有条件的项目尽快开工，推动已开工项目入库列统，创新增量，挖掘存量，在充分利用有限资源条件下，实现投资有效回升。三是继续加大现代服务业投资，聚焦消费新增长点，引导资金更多投向供需共同受益的现代服务业等领域，加快5G网络、数据中心等新型基础设施建设。
