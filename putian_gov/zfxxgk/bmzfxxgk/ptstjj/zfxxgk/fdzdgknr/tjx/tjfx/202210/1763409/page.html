全面提速 稳中向好——前三季度莆田市经济运行分析

第六十七期
发布时间：2022-10-28 15:56
| | |

今年以来，面对复杂严峻的外部环境和多重超预期因素冲击，在市委、市政府的正确领导下，全市上下团结一心、迎难而上，认真贯彻落实党中央“疫情要防住、经济要稳住、发展要安全”的重要要求，高效统筹疫情防控和经济社会发展，有力有效落实稳经济一揽子政策和接续政策措施，前三季度全市主要经济指标全面提速，呈现稳中向好态势。前三季度，全市地区生产总值2375.75亿元，同比增长4.2%，增幅比上半年提高1.6个百分点，居全省位次由上半年的第8位跃居第6位。其中，第一产业增加值103.59亿元，增长5.1%；第二产业增加值1214.66亿元，增长4.3%，增幅比上半年提高1.4个百分点；第三产业增加值1057.50亿元，增长4.1%，增幅比上半年提高2.2个百分点。三次产业对经济增长的贡献率分别为4.9%、51.0%和44.1%，分别拉动地区生产总值增长0.2个、2.1个和1.9个百分点。

一、经济运行基本情况

（一）农业生产稳中有升，农产品供应充足。前三季度，全市农林牧渔业总产值194.69亿元，同比增长4.9%，增幅分别比上半年、全省平均水平高0.1个和0.2个百分点。从行业看，农业产值39.29亿元，增长3.2%；林业产值1.74亿元，增长12.8%，增幅比上半年提高2.5个百分点；牧业产值26.35亿元，增长4.8%，增幅比上半年提高0.7个百分点；渔业产值110.30亿元，增长5.4%；农林牧渔业服务业产值17.02亿元，增长5.2%。从产量看，蔬菜产量增长3.2%，木材产量增长25.4%，肉蛋奶总产量增长5.8%，增幅比上半年提高0.6个百分点，生猪期末存栏增长5.2%，累计出栏增长3.5%，水产品总产量增长5.5%。

（二）工业生产加快回升，亿元企业支撑有力。前三季度，全市规模以上工业增加值同比增长3.6%，增幅比上半年提高1.1个百分点。从行业分类看，33个行业大类中有17个行业增加值实现正增长，其中规模以上化学纤维制造业、纺织业、化学原料和化学制品制造业等三个行业增加值分别增长34.9%、27.1%和19.3%，共拉动规模以上工业增加值增长1.9个百分点。从经济类型看，规模以上民营企业增加值增长5.9%，增幅比上半年提高1.6个百分点，拉动规模以上工业增加值增长3.9个百分点。从龙头企业看，521家规模以上亿元及以上企业增加值增长14.4%，增幅高于规模以上工业增加值10.8个百分点，拉动规模以上工业增加值增长7.7个百分点。

（三）建筑业增速领跑全省，特级企业增势良好。前三季度，全市建筑业总产值667.11亿元，同比增长11.0%，增幅分别比上半年、全省平均水平高3.5个和1.8个百分点，居全省位次由上半年的第8位跃居全省首位。全市特级企业共完成产值145.27亿元，占建筑业总产值的21.8%，增长17.9%，拉动建筑业总产值增长3.7个百分点。本地建筑企业在外省完成产值373.81亿元，增长7.3%，增幅比上半年提高0.8个百分点。

（四）服务业明显提速，批发零售业贡献突出。前三季度,全市服务业增加值同比增长4.1%，增幅比上半年提高2.2个百分点。其中，批发和零售业增加值增长6.4%，增幅比上半年提高2.0个百分点，拉动服务业增加值增长2.1个百分点；非营利性服务业增加值增长5.5%，增幅比上半年提高2.0个百分点，拉动服务业增加值增长0.8个百分点；营利性服务业增加值增长3.6%，增幅比上半年提高1.0个百分点，拉动服务业增加值增长0.7个百分点；金融业增加值增长5.5%，增幅比上半年提高0.1个百分点，拉动服务业增加值增长0.6个百分点。

（五）投资增幅进位明显，重大项目拉动有力。前三季度，全市固定资产投资完成1539.89亿元，同比增长11.1%，增幅分别比上半年、全省平均水平高3.9个和1.9个百分点，居全省位次由1-8月份的第7位跃居第2位。从投资领域看，基础设施投资484.78亿元，增长19.7%，拉动固定资产投资增长5.7个百分点，其中市政建设投资增长31.4%，水利管理业投资增长137.4%；工业投资440.01亿元，增长4.6%，增幅比上半年提高10.5个百分点；房地产投资271.80亿元，下降15.2%，降幅比上半年收窄1.2个百分点。从项目接续看，截至9月末，全市新入库固定资产投资项目859个，同比增加243个，计划总投资1597.73亿元，同比增长42.5%，完成投资733.25亿元，增长42.9%。从重大项目看，全市360个亿元及以上项目投资完成1007.06亿元，增长12.6%，拉动固定资产投资增长8.1个百分点。

（六）市场销售加快复苏，新型消费高速发展。前三季度,社会消费品零售总额1356.88亿元，同比增长2.9%，增幅比上半年提高0.4个百分点。其中，限额以上消费品零售额502.05亿元，增长4.6%，增幅比上半年提高0.9个百分点。从商品类别看，限额以上文化办公用品类、服装类、石油及制品类、家具类和鞋帽类商品零售额分别增长125.5%、43.7%、20.4%、19.9%和18.6%，共拉动社会消费品零售总额增长4.5个百分点。从零售模式看，限额以上网上商品零售额272.04亿元，占社会消费品零售总额的20.0%，增长6.2%，增幅比上半年提高0.8个百分点，拉动社会消费品零售总额增长1.2个百分点。从消费类型看，绿色化、智能化、数字化消费不断升级，限额以上可穿戴智能装备、新能源汽车、智能家用电器和音像器材零售额分别增长46.9%、38.4%和22.9%。

（七）外贸出口稳居全省前列，鞋类出口承压增长。前三季度，全市外贸出口总额281.8亿元，增长25.7%，增幅高于全省平均水平11.5个百分点，今年以来稳居全省第2位。占我市出口额53%的鞋类出口，顶住海外市场需求下降、订单外流、国外采购商库存积压等情况的叠加影响，连续21个月保持正增长。

（八）财政收入增幅快于全省，金融市场平稳运行。前三季度，全市一般公共预算总收入170.07亿元，剔除增值税留抵退税因素，同口径增长3.4%，增幅分别比1-8月份、全省平均水平高2.7个和1.7个百分点。其中，地方一般公共预算收入120.38亿元，同口径增长9.9%，增幅分别比1-8月份、全省平均水平高4.2个和3.5个百分点，居全省第3位。全市一般公共预算支出199.74亿元，增长8.8%，增幅分别比1-8月份、全省平均水平高3.8个和2.4个百分点，居全省第2位。9月末，全市金融机构本外币各项存款余额2864.4亿元，增长10.9%，金融机构本外币各项贷款余额2680.62亿元，增长10.7%，增幅比6月末提高0.2个百分点。

（九）居民收入稳步增长，消费价格温和上涨。前三季度，全市居民人均可支配收入29047元，同比增长6.1%。其中，城镇居民人均可支配收入36501元，增长5.5%，增幅比全省平均水平高0.2个百分点，居全省第3位；农村居民人均可支配收入19492元，增长7.1%。前三季度，市区居民消费价格同比上涨1.5%，八大类消费“六增两降”，其中：交通和通信类上涨6.7%，其他用品和服务类上涨2.3%，食品烟酒类价格增长1.7%，衣着类价格上涨1.1%，生活用品及服务类价格上涨0.4%，居住类价格上涨0.3%，医疗保健类价格下降0.9%，教育文化和娱乐类价格下降0.4%。

二、需要关注的问题

（一）工业持续回升压力较大。一是通用设备制造业大幅下降。受上海电气、上电电机等大型企业停产影响，规模以上通用设备制造业增加值下降32.8%，拉低规模以上工业增加值增速0.6个百分点。二是企业生产成本持续走高。1-8月份规模以上工业企业每百元营业收入成本89.17元，同比增加1.30元。三是新兴产业发展较慢。规模以上战略性新兴产业增加值增长3.4%，增幅比规模以上工业增加值低0.2个百分点；高技术产业、装备制造业增加值分别下降4.8%和9.8%。

（二）建筑业增长后劲不足。一是新签合同额下降。前三季度本年新签合同额同比下降5.1%，资质建筑企业签订合同额增幅（7.0%）比上年同期回落6.2个百分点。二是中小企业中标率低。随着市场竞争日趋激烈，本地中小企业综合实力不如外来央企、国企，承揽新项目特别是大型项目的难度不断加大，中标率偏低。前三季度，全市有32家资质建筑企业产值为0，占企业总数的6.5%。

（三）重点领域投资仍需加强。一是房地产开发投资持续低迷。受新增项目较少、土地购置费大幅下降等因素影响，房地产开发投资下降15.2%，拉低固定资产投资增速3.5个百分点。二是工业投资增速较慢。受工业投资规模偏小（261个工业投资项目平均投资规模比上年同期低3.8亿元）、库存投资不足（下降23.8%）等因素影响，工业投资增长4.6%，增幅低于全省平均水平14.6个百分点。

（四）消费活力有待进一步增强。一是退库企业影响较大。截至9月末，全市限额以上商贸业退库企业达493家，拉低社会消费品零售总额增速4.7个百分点。二是日用品类零售降幅较大。受日用品销售市场不旺、企业关停较多等因素影响，限上日用品类零售额下降45.2%，拉低社会消费品零售总额增速2.1个百分点。三是燃油汽车消费不振。受芯片短缺等因素影响，全市传统燃油车零售额完成48.03亿元，下降5.1%。

（五）服务业发展存在瓶颈。一是退库企业影响较大。截至8月末，规上其他营利性服务业退库企业达102家（年度新增仅31家，月度新增仅2家且规模较小），特别是65家退库带基数企业拉低规上其他营利性服务业营业收入增速6.6个百分点。二是部分重点企业负增长。瑞智无忧、弹好工、特洛特人力资源等4家重点企业负增长，拉低规上其他营利性服务业营业收入增速3.6个百分点。三是民生服务业发展滞后。规上卫生和社会工作业企业仅3家，营业收入下降84.4%；规上水利、环境和公共设施管理业企业仅10家，营业收入下降19.9%；规上教育业企业仅4家，营业收入下降72.4%。

（六）房地产销售持续负增长。一是商品房供地面积下降。今年1-8月份房地产用地供应面积与去年基本持平，但剔除安商房、批发市场后可售纯商品房用地面积下降60.2%，势必影响房地产投资、销售的持续回升。二是新增项目减少。截至9月末，全市新增房地产项目19个，同比减少9个，商品房新开工面积仅226.38万平方米，下降54.0%。

三、下一步工作建议

下阶段，全市上下要认真学习贯彻党的二十大精神，进一步推动一揽子稳经济政策措施和接续政策落地见效，全力保主体、扩投资、促消费、抓入库，巩固经济回升向好态势。

（一）保主体稳工业基础。一是持续推动惠企政策落地见效。落实落细稳经济一揽子政策及接续政策措施，加强留抵退税等惠企政策的实施力度，切实扩大政策措施的覆盖面和惠及面，确保政策受益主体不漏户、不漏人和应知尽知、应享尽享，促进工业经济加快恢复。二是切实保障产业链供应链稳定。充分发挥十二条产业链专班作用，促进上下游、产供销、大中小协同发展，协调帮助重点企业和关键节点企业解决运行中的困难和问题，扎实做好能源、大宗原材料保供稳价，保障产业链供应链稳定畅通，推动企业稳产达产。三是培育“专精特新”企业。引导鼓励传统行业企业不断改进技术、升级产品，向绿色、创新型企业转型，向工业智能化方向发展，以培育自主知识产权、自主品牌和产品创新为重点，增强企业在行业细分市场的占有率，力争成为“专精特新”企业。

（二）抓项目扩有效投资。一是加强项目储备。抢抓政策性开发性金融工具和专项债增加规模、扩大领域机遇，加强项目梳理储备，按照“高大上、链群配”的思路做好项目招引，积极谋划和储备一批管长远、增后劲、补短板、惠民生的好项目。二是加快项目进度。要加强项目要素保障，推动储备项目加快成熟、前期项目加快落地、在建项目加快推进，主动对接服务项目业主，帮助协调解决项目推进过程中存在的各种问题，在确保项目质量的前提下加快项目建设进度。

 （三）激活力促消费回补。一是加大促销力度。持续深入实施“全闽乐购•约惠莆田”促消费行动，通过发放消费券进一步激发消费市场需求，鼓励商家利用“双十一”、双十二契机加大促销力度，活跃本地消费市场。二是鼓励大宗商品消费，用好800万元汽车促销资金和550万元家电家居家装促销资金，增加停车场、充电桩、换电站等配套设施，提供更多停车便利，刺激居民汽车消费欲望。

（四）抓入库增发展后劲。一是建立“准规企业库”，各行业主管部门要加强对大个体及小微企业的摸排力度，运用大数据、“天眼查”等方式，多渠道建立“准规企业库”，并在财政资金、税费政策、金融贷款等方面予以重点扶持，助力“准规企业”成长上规。二是“一企一策”精准服务，对产值（销售额、营业收入等）较大但尚未纳统的企业以及个体户逐个进行调研，一企一策帮助解决实际问题，推动在营单位“个转企”“下转上”。
