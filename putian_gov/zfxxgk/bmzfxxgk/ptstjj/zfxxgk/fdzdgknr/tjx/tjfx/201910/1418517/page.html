规上服务业形势良好 其他营利性服务业隐忧犹存——1-8月全市规模以上服务业运行情况

第六十四期
发布时间：2019-10-12 09:11
| | |

今年以来，我市规模以上服务业总体发展态势良好，营业收入增速稳居全省第一位，但作为我市第三产业主要拉动力的其他营利性服务业后劲不足，增速持续下滑，隐忧犹存，需引起重点关注。

一、主要亮点

（一）规模以上服务业增速稳居全省第一

1-8月，全市规模以上服务业营业收入增长42.1%，增幅高于全省平均水平26.8个百分点，居全省第一位。主要支撑因素是交通运输、仓储和邮政业增势迅猛，营业收入增长1.7倍，对全市规模以上服务业营业收入增长的贡献率达94.6%，拉动全市规模以上服务业营业收入增长39.9个百分点，原因是物泊科技有限公司本年陆运水运港口运量大幅增加，对交通运输、仓储和邮政业营业收入增长的贡献率达100.5%，拉动该行业营业收入增长173.4个百分点。

（二）非营利性服务业增势强劲

1-8月，全市规模以上非营利性服务业营业收入增长25.3%，增幅高于全省平均水平9.3个百分点，居全省第二位。主要支撑因素：一是水利、环境和公共设施管理业（不含土地管理业）贡献突出。全市该行业营业收入增长56.9%，拉动规模以上非营利性服务业营业收入增长21.4个百分点，主要原因是福建星绿环境有限公司本年清扫保洁业务增加，拉动该行业营业收入增长17.1个百分点；二是教育行业快速增长。全市该行业营业收入增长35.2%，拉动规模以上非营利性营业收入增长3.4个百分点，主要是莆田市学必达文教投资管理有限公司今年补习班开展数量增加，对教育行业营业收入增长的贡献率达57.4%，拉动该行业营业收入增长20.2个百分点。

二、主要问题

（一）其他营利性服务业增速明显下滑

今年以来，全市规模以上其他营利性服务业营业收入增速高开低走，由1-2月的27.7%逐月回落至1-7月的22.3%，1-8月更是急剧下滑至5.6%，低于全省平均水平17.6个百分点，分别比1-5月和上年同期回落19.2和22.3个百分点，居全省的位次由第一位下滑至末位，预计分别拉低GDP和第三产业增加值增速0.7和1.8个百分点。主要原因：一是租赁和商务服务业个位数增长。全市该行业营业收入增长2.8%，增幅同比回落23.3个百分点，拉低其他营利性服务业营业收入增速15.9个百分点，主要受莆田市城市建设投资开发集团有限公司上年高基数的影响；二是互联网和相关服务、软件和信息技术服务业增速明显回落。全市该行业营业收入增长16.2%，增速同比回落15.4个百分点，拉低全市增速3.8个百分点，原因是福建豆讯科技有限公司因国家局服务业司核查发现该企业主营业务活动为电信增值服务，非软件开发行业，不能参与其他营利性服务业汇总，拉低全市增速9.2个百分点；三是秀屿区医疗咨询行业全线下滑。秀屿区医疗咨询行业受省税务局核查事件影响增速明显下滑，导致全区其他营利性服务业营业收入下降18.2%，拉低全市增速7.5个百分点。

（二）服务业整体规模偏小

1-8月，全市规模以上其他营利性服务业企业289家，户均营业收入仅1226万元；规模以上非营利性服务业企业60家，户均营业收入仅833万元。分行业门类看，科学研究和技术服务业企业35家，户均规模仅544万元；居民服务、修理和其他服务业企业39家，户均规模仅487万元；教育行业业企业10家，户均规模仅524万元；卫生和社会工作行业企业仅3家，户均规模仅721万元。分行业大类看，研究和试验发展、社会工作等两个行业尚未有达规模企业。

（三）民生相关行业低位增长

1-8月，全市规模以上居民服务、修理和其他服务业营业收入1.90亿元，增长7.5%，增速同比回落13.6个百分点；文化、体育和娱乐业营业收入2.90亿元，增长9.5%，增速同比回落34.7个百分点；卫生和社会工作行业营业收入0.22亿元，增长6.4%。

三、全年其他营利性服务业发展形势判断

据初步研判，全年我市规模以上其他营利性服务业营业收入增速有可能继续跌落15%以下，在全省排位靠后，会拉低第三产业增加值增速1.1个百分点，导致我市第三产业增加值和GDP增速排位后移。主要原因：一是随着基数的不断增加，秀屿区医疗咨询行业受省税务局核查事件影响将继续加大，全区其他营利性服务业营业收入降幅恐将继续扩大，进一步拉低全市增速；二是发展后劲不足，截止目前，全市今年月度仅2家新增入库企业，拉动力不足；三是今年我市其他营利性服务业营业收入增速主要靠福建豆讯科技有限公司企业拉动，该企业不参与汇总，对全市增速影响大。

四、工作建议

（一）加强部门联动，提升工作合力

其他营利性服务业行业分类复杂，涉及范围广，各行业相关主管部门（市发改委、工信局、市场监督管理局、人社局、民政局、财政局、司法局、国资委、文旅局、体育局等）要加强与市三产办的协调配合，形成有效的工作合力，重点要加强对联网直报企业的调研和跟踪监测，确保应统尽统、应统必统。

（二）培育新增长点，增强发展后劲

市直各行业相关主管部门要积极主动作为，督促各县区相关部门配合统计部门做好入库入统工作，尤其是单位数较少、存在空白行业（物联网技术服务、咨询调查服务、会展服务、文体设备和用品出租、宠物服务、出版业、研究和试验发展、社会工作等）的县区和相关行业主管部门（工信局、文旅局、农业农村局、生态环境局、民政局、科技局等）要加强企业培育，将达到规模标准的企业尽快纳入规上服务业统计范围。其中，秀屿区其他营利性服务业行业结构单一，主要靠医疗咨询行业拉动，增速容易受行业影响而出现异常波动，需引起重点关注，可结合本区产业发展特点，积极培育和发展新行业业态，优化行业结构，确保其他营利性服务业持续健康发展。
