2016年1-6月份莆田市规模以上工业运行分析

发布时间：2016-07-19 00:00
| | |

今年以来，莆田市工业经济呈现稳中趋缓运行态势。1-6月，全市规模以上工业实现工业增加值432.12亿元，可比增长8.8%,增速比1-5月回落0.2个百分点，比上年同期低2.0个百分点，在全省各设区市中排名第一。

2015-2016年1-6月工业增加值累计增速（单位：%）

一、工业生产平稳运行

（一）制造业主要行业生产增长平稳。1-6月，全市规模以上工业中制造业完成增加值409.55亿元，同比增长10.5%。分主要行业看：皮革、毛皮、羽毛及其制品和制鞋业完成增加值103.87亿元，增长5.6%。文教、工美、体育和娱乐用品制造业完成增加值49.19亿元，增长26.3%。农副食品加工业完成增加值28.01亿元，增长2.1%。化学原料和化学制品制造业完成增加值24.77亿元，增长131.2%。纺织业完成增加值12.79亿元，增长44.7%。纺织服装、服饰业完成增加值17.50亿元，增长9.0%。计算机、通信和其他电子设备制造业完成增加值19.96亿元，增长16.3%。

（二）亿元企业贡献突出。1-6月，全市371家超亿元企业实现工业增加值335.74亿元，增长14.2%，占全市规上工业增加值总量达77.7%，对规模以上工业经济增长的贡献率为121.4%，比1-5月高10.1个百分点，拉动规模以上工业经济增长10.7个百分点。

（三）民营企业继续保持领先发展态势。1-6月，全市规模以上工业中民营企业生产继续保持领先发展态势，完成增加值271.66亿元，同比增长14.5%，增幅比全市规模以上工业平均水平高5.7个百分点，比上年同期提高2.1个百分点；民营工业对全市规模以上工业增长的贡献率为99.5%，拉动规模以上工业增长8.8个百分点。国有控股企业完成增加值22.89亿元，下降28.6%，增幅比上年同期回落35.5个百分点。外商及港澳台商投资企业完成增加值111.25亿元，下降0.5%，增幅比上年同期回落2.9个百分点。

（四）小微企业展现较强活力。1-6月，991家规模以上小微工业企业实现工业增加值219.90亿元，增长12.5%，比全市规模以上工业增速高3.7个百分点，比大中型工业增加值增幅高7.4个百分点，对规模以上工业经济增长的贡献率为70.5%，拉动规模以上工业增加值增长6.2个百分点。主要是文教、工美、体育和娱乐用品制造业，纺织业，化学原料和化学制品制造业三个行业增势强劲，增幅分别达31.6%、32.2%、201.1%。

（五）新增企业对工业拉动明显。1-6月，全市新增工业企业共拉动规模以上工业经济增长5.9个百分点。其中，120家规下转规上企业实现工业增加值10.96亿元，同比增长76.4%，对规模以上工业经济增长的贡献率为14.4%，拉动全市规模以上工业经济增长1.3个百分点。去年以来39家新投产工业企业实现工业增加值20.94亿元，同比增长3.8倍，对全市规模以上工业经济增长贡献率为52.8%，拉动规模以上工业经济增长4.6个百分点，其中去年新投产的中锦新材料、祥麟鞋业等企业拉动作用较为明显。

（六）十大工业产业集群“八升二降”。1-6月，全市规模以上十大产业实现工业增加值413.52亿元，可比增长8.7%。对全市规模以上工业经济增长贡献率为94.5%，拉动规模以上工业经济增长8.3个百分点。十大产业中除能源（-19.1%）和金属冶炼及压延（-71.1%）两大产业增幅下降外，制鞋（7.3%）、木材浆纸（10.1%）、电子信息（10.5%）、化工（48.2%）、纺织服装（20.8%）、机械装备制造（5.3%）、工艺与创意（10.1%）和食品医药（1.4%）八大产业均有不同程度的增长。其中，化工、制鞋、纺织服装和工艺与创意等四大产业对工业经济贡献较大，对全市规模以上工业经济增长贡献率为98.5%，拉动规模以上工业经济增长8.7个百分点。

二、工业转型升级成效初显

（一）高技术、战略性新兴产业成为工业发展的新引擎。代表工业转型升级主要方向的高技术和战略性新兴产业活力显现。1-6月全市高技术产业实现工业增加值32.71亿元，增长10.3%，增幅高于规模以上工业1.5个百分点。1-6月全市战略性新兴企业实现工业增加值79.69亿元，增长26.3%，增幅高于规模以上工业17.5个百分点，对全市规模以上工业经济增长贡献率为48.6%，拉动规模以上工业经济增长4.3个百分点，成为工业发展的新引擎。

（二）省级龙头企业和高成长企业引领带动作用突出。全市重点监测的省级龙头企业和高成长企业适应新常态，加大产品研发投放和市场开拓力度，采取了一系列提质降本增效的举措，对全市工业经济发展的引领、带动作用得以突显。1-6月，全市省级龙头企业和高成长企业实现工业增加值83.18亿元，增长30.9%，占全市规模工业增加值总量19.2%，对全市规模以上工业经济增长贡献率为57.7%，拉动规模以上工业经济增长5.1个百分点。

（三）高耗能产业生产放缓。1-6月，全市高耗能产业实现工业增加值58.76亿元，增长25.4%，增幅比1-5月和1-3月分别回落4.5个和6.5个百分点，迈开了绿色转型步伐。

三、企业效益总体向好

（一）政策效果逐步显现。目前，国家出台的一系列稳增长措施和改革红利持续释放，供给侧结构性改革方案逐步落实。降税、减费、降息等措施效果显现。1-5月，全市规模以上工业企业每百元主营业务收入中的主营成本87.46元，同比降低0.94元；利息支出同比下降25.0%，比上年同期回落19.2个百分点；规模以上工业企业应交增值税同比下降4.3%，比上年同期回落26.3个百分点。

（二）工业生产经营效益提升。1-5月，规模以上工业综合经济效益指数达339.96，同比提高33.0个点。在中锦新材料、LNG、燃气发电、英博雪津和福能新能源5家企业大幅增加的带动下，全市规模以上工业实现利润总额69.41亿元，增长60.1%，增幅同比提高55.7个百分点，高于全省40.7个百分点，若扣除这5家企业利润，全市利润总额增长为16.7%。在反映经济运行质量的七个综合指标中，总资产贡献率19.0%，同比提高3.7个百分点，流动资产周转次数加快0.2次，全员劳动生产率增长7.8%，资本保值增值率提高12.5个百分点，资产负债率下降4.5个百分点，产品销售率提高0.7个百分点。

四、需要关注的问题

（一）减、停企业影响仍然较大。6月，规上工业停、减产面达30.0%，比5月末和3月末分别回落0.2个和3.0个百分点，共拉低全市规上工业增加值增幅10.6个百分点，高于5月末9.3个百分点，对工业经济增长的影响持续加大。停产企业60家，较5月末、3月末分别增加4家和6家，影响全市规模以上工业增加值15.00亿元，拉低规模以上工业增长4.4个百分点。其中， 21家企业为去年停产企业，影响全市规模以上工业增加值6.83亿元，拉低规模以上工业增长2.0个百分点。39家为今年新增停产企业，影响全市规模以上工业增加值8.17亿元，拉低规模以上工业增长2.4个百分点。6月末，312家企业减产，较5月末和3月末分别减少6家和46家，占全市规模以上工业企业数的25.1%，累计减少工业增加值21.52亿元，拉低规模以上工业增长6.2个百分点。其中，产值减产超过2千万的规上企业有61家，比5月末增加7家，累计减少工业增加值17.33亿元，约占总减产量的80.5%。

（二）工业出口交货值增速持续下降。1-6月，全市工业出口形势仍然严峻，出口交货值延续上年年末的下降态势。全市规模工业实现出口交货值186.58亿元，下降0.4%。主要是木材浆纸下降3.2%，化工下降28.7%，纺织服装业下降13.2%。

（三）高端领域发展缓慢。 高技术产业和装备制造业占比偏低，拉动力不足。1-6月，高技术产业占全市规上工业增加值比重仅为7.6%，比上年同期占比提高0.1个百分点，拉动工业经济增长极为0.8个百分点。装备制造业实现工业增加值64.40亿元，增长7.3%，低于规模工业增速1.5个百分点，拉动工业经济增长仅为1.1个百分点。以战略性新兴产业为代表的高端产业占比偏低，1-6月，战略性新兴产业增加值占全市规模以上工业比重仅为18.4%，战略性新兴产业新业态、新模式的发展还需注入新的发展动力。

（四）新投产企业贡献逐月下降。由于缺乏大型新增企业的有力支撑，导致新增企业的增长贡献逐步缩小。6月末，全市当年新投产企业5家，仅占规上工业企业数0.4%。仅1家企业产值超亿元，其余4家新投产企业的规模不大，户均不足4千万，仅拉动全市工业经济增长0.1个百分点，工业经济保位压力增大。

（五）市场预期未见好转，企业家信心不足。全市规模以上工业企业生产经营状况及景气状况调查显示，二季度企业家信心指数为114.22，比上年同期下降12.1点，二季度工业企业景气指数为113.46，比上年同期下降16.3点，企业家信心指数和企业景气均处于“相对景气”区间。当前市场预期未见好转，工业企业经营压力较大，企业对预期发展缺乏信心亟需提振。
