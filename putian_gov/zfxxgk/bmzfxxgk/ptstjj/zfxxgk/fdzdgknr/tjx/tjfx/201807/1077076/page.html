上半年全市消费品市场运行情况分析

第四十期
发布时间：2018-07-23 16:29
| | |
 上半年全市实现社会消费品零售总额376.72亿元，同比增长12.0%，增幅比上年同期高0.7个百分点，比1－5月回落0.4个百分点，居九设区市第五位。按消费形态分，上半年，餐饮收入27.52亿元，增长6.0%，增幅比上年同期回落1.3个百分点；商品零售349.20亿元，增长12.5%，增幅比上年同期提升0.9个百分点。

一、限上消费品市场的主要特点

（一）限上消费品市场较快增长。上半年，限额以上（简称限上）单位实现消费品零售额195.20亿元，增长17.6%，增幅比上年同期快0.2个百分点，比全省平均水平高1.1个百分点。

（二）网上零售保持较快增长。上半年，全市370家限上电商企业实现网上零售额67.75亿元，增长23.0%，增幅比全市限上平均水平高5.4个百分点，占限上消费品零售市场的34.7%。

（三）品质类消费提升。上半年，全市限上化妆品类商品零售额增长111.1%；金银珠宝类增长27.5%；书报杂志类增长59.8%；通讯器材类增长83.3%。

（四）家居类消费趋好。上半年，家用电器和音像器材类增长15.5%，其中，当月增长26.0%；同期，家具类增长14.0%，当月增长31.3%。

（五）石油及制品类商品实现两位数增长。因价格提升及汽车保有量增加，上半年全市限上石油及制品类商品零售额16.49亿元，增长10.3%，增幅创今年新高。

二、应关注的问题

（一）破产（注吊销）及停业企业影响。上半年，全市破产（注吊销）及停业企业商品零售额同比减少5.20亿元，拉低限上消费品零售额增幅3.1个百分点。分县区看，城厢最多，同比减少2.42亿元，荔城次之，减少1.16亿元，两个县区占全市的比重高达68.8%。分行业看，电商企业居多，达31家，网上零售额同比减少2.94亿元，拉低全市限上单位网上零售额增幅5.3个百分点。

（二）减产企业的影响。上半年，全市104家限上商贸企业营业业绩下降，零售额同比减少4.62亿元，下降11.6%，拉低限上消费品零售额增幅2.8个百分点。其中，荔城下降企业最多，零售额同比减少达3.45亿元，占全市的74.7%。

（三）限上鞋帽类及汽车类商品零售额当月涨幅回落。从限上消费品市场商品类别来看，鞋帽类及汽车类零售额分别居限上消费品市场的第一及第二位。6月鞋帽类商品零售额增长9.6%，累计增长16.2%；汽车类当月增长5.1%，累计增长15.6%，两者累计增幅分别比1－5月回落1.9个和2.4个百分点，对限上消费品零售市场的贡献率从1－5月的6.3%回落至上半年的5.7%。

（四）限下餐饮收入增长乏力。上半年，限下餐饮收入实现22.15亿元，呈V型运行态势，增速由一季度的增长2.8%、到1－5月的增长0.6%、再到上半年的增长1.4%，比上年同期回落6.4个百分点。主要原因是竞争激烈和市场萎缩所致。

三、发展建议

（一）加大企业入库力度。6月末，全市年度以来入库企业有零售业绩的共有152家，上半年户均实现零售额11834千元，比上年同期减少1538千元，累计实现零售额增长119.5%，增幅同比回落83.5个百分点。在新增入库企业发展质量不如上年的情况下，有关部门更要加强配合，积极培育市场，引导企业做大做强，做好优质企业入库纳统工作。

（二）加快零售行业转型升级

上半年，以超市为代表的实体零售行业实现限上综合零售额16.55亿元，增长12.6%，增幅比全市限上平均水平及网上零售额分别低5.0个和10.4个百分点，其中，超级市场零售额下降0.2%。同期，实现主营业务收入14.90亿元，增长21.1%，增幅与主营业务成本持平。收入与成本增速持平，表明企业收入空间有限，成本压力较大。传统零售业要转型，要突破，营销模式一定要多样化，在传统的打折、特价、让利销售等方式下，要引入线上销售，融入互联网大潮中。

1、要大力发展品质零售。“打铁还需自身硬”，传统商家要在商品品质上完胜消费者，避免商家间商品同质化竞争，持续打价格战。商家应加强自身管理、优化商品选择、定价机制、着力提高商品管理能力，针对不同消费群体提供定制化、个性化商品服务，让消费者买的放心、用的舒心。

2、加快线上线下融合发展。目前，全市只有苏宁云商实现线上、线下同时销售，实体与网络融合发展较好。由于互联网已深入各个领域，当前的零售业可谓是新零售，是基于大数据时代的商业形态。传统零售业不跟上时代发展，就会被淘汰，苏宁云商的经营模式值得借鉴和推广。
