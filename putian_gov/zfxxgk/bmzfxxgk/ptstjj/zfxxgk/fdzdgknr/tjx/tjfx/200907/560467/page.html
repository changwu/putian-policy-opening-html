上半年莆田市投资形势分析

发布时间：2009-07-17 00:00
| | |

今年以来，全市上下积极应对全球金融危机的不利影响，认真贯彻落实中央扩内需、保增长的政策措施，狠抓投资项目落实，固定资产投资保持平稳较快增长态势。上半年，全市全社会固定资产投资188.81亿元，比去年同期增长23.7%，增幅回落5.1个百分点，增幅比全省平均水平快3.9个百分点，居全省第五位。其中，城镇固定资产投资155.23亿元，增长25.3%，回落3.7个百分点。

一、投资运行的主要特点

（一）各县(区)发展较为均衡，均呈两位数增长。上半年，城厢区完成全社会投资33.53亿元，增长19.7%；涵江区完成全社会投资35.69亿元，增长27.4%；荔城区完成全社会投资43.55亿元，增长29.3%；秀屿区完成全社会投资38.00亿元，增长20.6%；北岸完成全社会投资3.32亿元，增长84.3%；湄洲岛完成全社会投资1.03亿元，增长33.0%；仙游县完成全社会投资31.36亿元，增长16.5%。

（二）第一产业投资继续下降，第三产业投资比重进一步提升。在全社会投资中，第一产业完成投资2.96亿元，下降6.9%，下降幅度比一季度加大3.0个百分点，占全社会投资的比重为1.6%，比上年同期低0.5个百分点；第二产业完成投资67.61亿元，增长12.6%，占全社会投资的比重为35.8%，比上年同期低3.5个百分点；第三产业完成投资118.24亿元，增长32.1%，比同期全社会投资快8.4个百分点，占全社会投资的比重为62.6%，比上年同期提升4.0个百分点。

第二产业中，工业完成投资67.21亿元，增长13.7%，增速同比回落4.4个百分点。其中：制造业完成投资44.04亿元，增长10.5%，增速同比回落12.6个百分点；电力、燃气、及水的生产和供应业完成投资23.09亿元，增长19.8%，增速同比加快10.7个百分点。

（三）基础设施投资增势强劲，增速同比加快33.3个百分点。今年以来，随着一大批资金陆续投向铁路、高速公路、港口、民生等重大基础设施项目，全社会基础设施投入保持了持续强劲的增长势头。1—6月，全市基础设施共完成投资65.64亿元，比去年同期增长45.8%，增速同比加快33.3个百分点，占全社会投资的比重由去年同期的29.5%提高到34.8%。在基础设施投入中，交通运输、仓储和邮政业完成投资31.87亿元，增长76.8%，增速同比加快74.5个百分点；水利、环境和公共设施管理业完成投资9.32亿元，同比增长37.8%，增速同比回落53.3个百分点。

（四）国有资本在危机中的中流砥柱作用充分显现。受市场需求减弱，企业盈利水平下降等因素的影响，民间投资能力和投资意愿明显降低，投资增幅明显回落。而中央政府和各级地方政府为实现保增长、促就业的宏观经济目标，切实履行政府职能，加大了财政投入，国有投资增长较快。1-6月，我市全社会国有及国有经济投资78.95亿元，增长53.0%，比上年同期加快41.6个百分点，比同期外资、民间投资分别快45.6、44.1个百分点，对全社会投资的贡献率达75.7%，成为我市投资增长的领头羊。在我市民营资本历来较为活跃，其投资增幅在一般年份都要远高于国有投资，2008年民间投资要比国有投资高28.0个百分点。而到了今年的上半年，国有投资明显高于民间投资，充分显示了在危机面前，国有资本的中流砥柱作用。

（五）中央扩大内需项目建设积极推进。今年以来，我市各级各部门认真贯彻落实市委、市政府《关于进一步扩大内需促进经济持续较快增长的实施意见》，把扩大投资、加快中央增投项目建设作为扩大内需的重要抓手，真抓实干，扎实运作，促进了中央增投项目的顺利进展。截止6月30日，我市共争取前三批中央增投项目118个，主要涉及农村基础设施、水利、生态环境、医疗卫生和保障性安居工程等行业和领域，项目总投资20.23亿元，下达投资计划11.43亿元，中央增投补助2.57亿元。其中前两批项目102个，已有84个项目实现开工，开工率82.4%，累计完成投资6.51亿元，占中央下达投资计划的64.9%。

今年上半年，我市中央扩大内需投资所涉及的行业和领域增长幅度较高，拉动增长的效果明显。1-6月，我市全社会固定资产投资中，用于农村基础设施的投资7.53亿元，同比增长47.5%；用于水利、环境、公共设施建设的投资9.32亿元，增长37.8％；用于卫生、社会保障和社会福利业的投资1.55亿元，增长21.6％；用于保障性住房、拆迁安置房等安居工程建设的投资17.52亿元，增长54.9%。

（六）重点项目快速推进，支撑有力。上半年，我市重点建设项目完成投资107.65亿元，完成年度计划的45.6%，比去年同期快3.7个百分点。投资额占同期全社会投资的比重为57.0%，比上年同期高10.1个百分点。其中：192个在建重点项目完成投资67.34亿元，完成年度计划的51.0%，比上年同期快2.8个百分点；93个预备重点项目完成投资9.34亿元，完成年度计划的21.6%，比上年同期快7.7个百分点。在192个在建重点项目中，有29个项目超额完成全年计划。在93个预备重点项目中，有15个项目序时进度已过半。57个重点前期工作项目的前期工作有序推进，其中有8个项目已完成前期工作。

（七）房地产开发投资降幅收窄，商品房销售趋暖态势逐步显现。上半年，我市完成房地产投资32.78亿元，同比下降8.9％，增幅比上月提升2.9个百分点。其中土地购置费为11.19亿元，比上年同期增长36.6%，增幅比上月提升10.5个百分点。土地购置面积40.56万平方米，比上年同期增长35.7%，增幅比上月提升48.4个百分点。

上半年，我市商品房销售面积为58.80万平方米，增长10.6%；其中商品住宅销售面积为56.62万平方米，增长25.6%，快于商品房总销售面积15.0个百分点，住宅销售占商品房总销售面积的96.3%。二手房成交面积为36.89万平方米，增长83.3%。

二、投资运行中值得关注的几个问题

1、民间投资信心仍然不足。今年以来，受国际金融危机的影响，民间投资能力和投资意愿明显降低。上半年，全市全社会民间投资完成额为94.89亿元，增长8.9%，增速同比回落34.3个百分点，比同期全社会投资慢14.8个百分点，占全社会投资的比重也比去年同期下降6.8个百分点。

2、房地产开发市场发展形势依然不容乐观。虽然今年商品销售有所回暖，但从房地产市场的诸多先行指标分析，开发商对后市预期仍然不高，投资意愿不强，以消化积压房为主。上半年，全市房地产开发完成土地开发面积12.46万平方米，下降71.6%；商品房新开工施工面积66.87万平方米，下降61.7%；待开发土地面积为58.44万平方米，下降49.8%。商品房空置面积为27.10万平方米，增长72.4%；其中住宅空置面积为12.65万平方米，增长83.1%。

3、本年新开工亿元项目明显减少，投资增长后劲明显不足。今年上半年，全市共新开工亿元项目18个，下降47.1%；亿元本年新增项目完成投资10.32亿元，下降15.8%。本年新增亿元项目个数和投资的减少将直接影响今年我市投资的增长后劲。

4、制造业投资增长乏力，三分之一行业投资下降。上半年，在我市50万元以上项目投资中，制造业完成投资44.04亿元，增长10.5%，增速同比回落12.6个百分点；增幅比同期全社会投资慢13.2个百分点，比同期50万元以上项目投资慢23.9个百分点。在制造业30个行业中，有10个行业投资出现下降。
