农业生产稳步推进 “菜篮子”稳产保供——2020年一季度农业经济简析

第十八期
发布时间：2020-04-21 15:06
| | |

一季度正值春耕备耕的时节，更是疫情防控的关键时期。我市深入学习贯彻习近平总书记对全国春季农业生产工作作出的重要指示精神，认真落实省委省政府的部署要求，统筹推进疫情防控和经济社会发展，全力抓好春耕备耕，农业生产稳步推进，确保疫情期间“菜篮子”稳产保供。

一、主要运行特点

（一）农业生产有序推进，农林牧渔业总产值增长基本平稳

一季度,莆田市农林牧渔业总产值52.35亿元，可比增长1.3%，增幅比上年同期回落2.4个百分点。其中：农业产值7.48亿元，增长7.0%；林业产值0.39亿元，增长5.5%；牧业产值10.34亿元，下降10.4%；渔业产值29.81亿元，增长2.2%；农林牧渔服务业产值4.33亿元，增长5.1%。

（二）蔬菜生产情势良好，产量稳步增加

一季度,全市蔬菜播种面积为8.86万亩，播种面积比上年同期扩大0.40万亩，增长4.7%；产量达16.96万吨，比上年同期增加0.98万吨，增长6.1%；平均亩产达1914公斤/亩，比上年同期增加26公斤/亩，增长1.4%。其中耐储存、便于运输、亩产高的蔬菜品种扩种明显，分别是芹菜、其他叶菜、白菜类、胡萝卜、青椒、菜用豆类、花椰菜，分别增长27.2%、17.4%、9.1%、19.4%、16.5%、17.3%、8.2%。

（三）食用菌生产规模不断萎缩，降幅逐年收窄

一季度，全市食用菌生产用地为0.44万亩，在上年和前年同期分别下降11.1%和28.5%的基础上今年继续下降7.4%；食用菌产量为3.03万吨，在上年和前年上年同期分别下降4.3%和34.8%的基础上今年继续下降0.2%。其中，蘑菇产量2.91万吨，在上年和前年同期分别下降4.3%和35.0%的基础上今年继续下降0.2%。食用菌生产用地、产量降幅均呈逐年收窄态势。

（四）生猪存栏首季出现增长，家禽和草食动物发展稳定

一是生猪存栏首季出现增长，出栏仍然延续去年大幅下降态势。一季度全市生猪存栏18.60万头，同比增长12.7%；出栏11.04万头，下降37.3%。二是家禽养殖规模扩大明显。一季度全市家禽存栏901.19万只，增长16.9%；出栏918.94万只，增长9.5%。三是草食动物稳定发展。一季度全市牛存栏0.90万头，增长36.0%，出栏0.07万头，增长27.4%；羊存栏2.82万头，增长7.3%，出栏1.79万头，下降11.7%。

（五）渔业发展空间受限，水产品产量增幅回落

一季度，全市水产品总产量26.71万吨，增长2.2%，增幅比上年同期回落2.7个百分点。其中海水产品产量25.56万吨，增长2.3%，增幅比上年同期回落2.7个百分点；内陆水域水产品产量1.15万吨，由上年同期的增长2.1%转为今年的下降0.2%。

二、存在的主要问题

（一）非洲猪瘟对生猪养殖业的影响仍未消除。自去年以来，猪肉价格一路高涨，推动生猪价格也一路攀升，生猪销售价格一直保持在成本价的两倍以上，生猪养殖业效益达到历史最高点。但国内非洲猪瘟疫情尚未结束，很多生猪养殖企业担忧场外引种引仔会引发非洲猪瘟疫情风险，无法扩大养殖规模。今年一季度我市生猪存栏虽然增长了12.7%，但与2018年一季度比还是下降了56.6%。

（二）海产品出口仍然受限。自一月底起，为了阻断新型冠状病毒疫情的传播，我市提倡居家隔离，市民外出受阻，海产品采购意愿减弱，餐饮业停止营业，导致海产品消费需求下降，同时受中内外疫情影响，南日鲍等我市高端海产品出口受到限制，导致我市海产品滞销和价跌。

三、下一步建议

（一）扩大粮食种植规模，保障粮食生产安全。国家粮食安全战略具有特殊的重要意义，粮食播种面积及产量是粮食安全省长责任制考核的重要指标，粮食安全也是4月17日中央政治局常委会会议首提的“六保”之一，我市要落实惠农扶粮政策，千方百计调动农民种粮积极性，加大高标准农田建设力度，把抛荒地、旱地通过高标准农田建设改造成适合规模经营种植水稻的农田，切实提高我市的粮食种植规模，为全年粮食稳定发展奠定基础。

（二）引导因非洲猪瘟而关闭的生猪养殖场转产。2018年底我市因非洲猪瘟处置70个高风险生猪规模养殖场，有部分养殖场至今还是闲置，要引导闲置生猪养殖场尽快进行转产，如改养家禽和牛羊等。

（三）大力发展畜牧业规模化养殖和循环养殖。要加大招商引资力度，引进国内外先进养殖模式的畜牧业企业，如丹麦皇冠等国际知名生猪养殖屠宰加工一体化企业，带动我市畜牧业向规模化养殖和循环养殖发展，提升行业整体竞争力。

（四）拓宽海产品销售渠道，延伸产业链。一是拓宽海产品销售渠道，扩大内销，引导出口受限的南日鲍等高端海产品由出口转向内销；二是出台优惠政策支持海产品加工业发展，延伸产业链，增强抵御风险能力。
