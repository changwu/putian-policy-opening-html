2008年1－3季度莆田市投资运行情况简析

发布时间：2008-10-16 00:00
| | |

一、总体运行形势及特点

（一）投资增幅明显回落。1－3季度，全市共完成全社会投资226.78亿元，增长27.7%，增幅与上期持平，比上年同期回落24.1个百分点。其中，50万元以上项目投资167.01亿元，增长25.0%，增幅比上年同期回落21.1个百分点；房地产开发投资48.66亿元，增长39.3%，增幅比上年同期回落47.3个百分点。

（二）50万元以上项目本年施工项目个数和本年新开工项目个数出现负增长。今年以来，我市受国家宏观调控政策、项目用地审批、资金和拆迁等因素的影响，项目开工明显不足，出现50万元以上项目本年施工项目个数、新开工项目个数和本年新开工项目计划总投资同时下降。1－9月，全市在建的50万元以上投资项目个数为1129个，下降4.8%，在建项目计划总投资为770.15亿元，增长26.0%，在续建项目的拉动下，在建项目计划总投资仍然保持较快的增长；其中本年新开工项目个数为637个，下降8.5%，新开工项目计划总投资为133.74亿元，下降20.3%。

（三）国有投资增长放缓，民间投资继续引领投资增长。由于受宏观调控政策的影响，我市土地类基金收入大幅度下滑，直接影响到我市以政府主导为主的各项基础设施建设和公共事业发展的资金保障，从而影响了我市国有投资增长，国有投资增幅出现大幅回落。1－9月，我市全社会国有投资达77.98亿元，增长12.4%，增幅比去年同期回落53.2个百分点，比同期全社会投资低15.3个百分点。随着我市投资环境的不断改善，“民资回归工程”得到纵深推进，民间投资更趋活跃，成为拉动我市投资增长的主动力。1－9月，我市全社会民间投资完成129.83亿元，增长41.7%，增幅分别比国有和外资快29.3个百分点和27.1个百分点，占全社会投资的比重为57.2%，比上年同期提升了5.6个百分点，对全社会投资的贡献率达77.6%，拉动全社会投资增长21.5个百分点。

（四）电力、燃气及水的生产供应业和交通运输、仓储及邮政业投资低速增长。今年1－9月，全市电力、燃气及水的生产供应业完成投资29.43亿元，增长7.4%，增幅比上年同期回落87.0个百分点，比同期全社会投资增幅低20.3个百分点。交通运输、仓储及邮政业完成投资27.82亿元，增长6.0%，增幅比去年同期回落46.9个百分点，比同期全社会投资增幅低21.7个百分点。今年以来，我市电力、燃气及水的生产供应业和交通运输、仓储及邮政业没有新开工的大项目，由于缺乏新的大项目支撑投资增幅大幅回落。

（五）水利、环境和公共设施管理业投资增长4.3倍。今年以来，我市水利、环境和公共设施管理业在木兰溪防洪工程和北洋水系整治工程等重点项目的强劲拉动下，投资呈现高速增长的态势，投资额比去年同期翻了两番。1－9月，全市水利、环境和公共设施管理业完成投资9.58亿元，增长4.3倍，拉动50万元以上项目投资增长5.8个百分点。　

（六）亿元项目拉动作用减弱，投资后劲明显不足。今年1-9月我市计划总投资达亿元以上的项目（不含房地产开发项目）共有88个，比去年同期增加7个，计划总投资达473.34亿元，增长15.1%，完成投资65.11亿元，增长10.5%，增幅比同期全社会投资低17.2个百分点，占全社会投资的比重为28.7%，比去年同期低4.5个百分点。亿元项目对全社会投资的支撑力度和拉动作用明显减弱。从新开工亿元项目看，今年1－9月我市新开工亿元项目只有7个，比去年同期减少20个，新开工项目计划总投资和新开工项目平均规模分别比去年同期下降85.9%和45.5%。亿元新开工项目个数、计划总投资和项目平均规模的大幅下降，将直接影响今后我市投资总量，投资后劲明显不足。

（七）房地产开发投资增幅逐月回落，市场观望气氛依然较浓。今年以来，在国家宏观调控政策的影响下，我市房地产开发投资增幅逐月回落，土地开发投资、土地购置费和土地购置面积同时出现负增长。1－9月我市房地产开发投资增长39.3%，比上年同期回落47.3个百分点。其中建筑工程因续建项目的惯性推动而增长95.8%，拉动房地产开发投资增长49.1个百分点；土地购置费为9.53亿元，下降21.6%，比上年同期回落163.2个百分点，拉动房地产开发投资下滑7.5个百分点；土地开发投资、土地购置面积和土地成交价款分别下降47.3%、52.2%、54.6%，分别比上年同期回落171.9、440.1、295.8个百分点。

受央行多次加息累积效应，以及买方对高房价心理预期的影响，居民购房意愿减弱，商品房成交量明显减少，出现商品房销售面积小幅增长，空置面积大量增加，市场观望气氛依然较浓。1-9月全市共销售商品房屋建筑面积77.36万平方米，增长2.9%，比去年同期回落24.4个百分点；商品房屋竣工面积66.21万平方米，增长6.3%，比去年同期回落246.0个百分点；商品房空置面积18.48万平方米，增长42.8%，增幅比去年同期高38.0个百分点，面积比去年同期增加5.54万平方米。

二、投资增速回落的原因及存在的问题

今年以来，国家宏观调控政策力度不断加大，在项目用地审批、资金、征地拆迁和材料涨价等难点问题的困扰下，今年1－3季度我市各类管理渠道投资增速全面放缓，全社会投资增幅大幅回落，比上年同期回落24.1个百分点，比全省平均水平低0.6个百分点，增幅也从去年同期全省第一位退居全省第七位，投资增幅全面回落的主要原因：

（一）连续几年的高增长，造成基数较高。从2005-2007年三年间的固定资产投资情况看，是我市投资增幅最快、投资额最大的一个时期，05年、06年、07年三年投资增幅分别为45.0%、43.1%、45.9%，投资额先后突破了100亿、150亿、200亿几个大关，特别是去年达到了240.93亿元。投资连续几年的高增长使得同期基数较高，今年在宏观调控政策趋紧的形势下继续保持高速增长难度很大。

（二）新开工项目减少，投资缺乏新的增长点。今年1－9月我市50万元以上项目本年新开工项目个数为637个，比去年同期减少59个；50万元以上项目本年新开工项目完成投资46.83亿元，下降1.3%，新开工项目投资占50万元以上项目总投资的比重为28.0%，比去年同期低7.5个百分点。本年新开工项目投资额的减少直接影响了我市项目投资的增长，从而影响了全市全社会投资的增速。

（三）在建重点项目对全社会投资的带动和支撑作用有所减弱。今年全市共有在建重点项目130个，比去年增加25个；本年计划投资为139.81亿元，比去年同期增长16.1%，低于全年全社会投资目标任务的32.8%；1-9月份累计完成投资99.38亿元，增长25.5%，增幅低于同期全社会投资2.2个百分点；占同期全社会投资的比重为43.8%，比去年同期低0.8个百分点，对全社会投资的带动和支撑作用有所减弱。

（四）土地的频频流拍影响了土地购置费投资和政府主导类投资的增长。今年以来，由于受国家宏观调控政策和楼市不景气的影响、我市土地流拍频频上演，直接减少了土地购置费投资和以政府主导为主的基础设施建设和公共事业发展等投资。一方面，土地的频频流拍引起本年土地购置费投资减少。1－9月份我市50万元以上项目本年购置土地面积为736.19万平方米，下降45.9%；本年土地成交价款为5.12亿元，下降56.2%。1－9月份我市房地产开发本年购置土地面积为41.06万平方米，下降52.2%；本年土地成交价款为5.87亿元，下降54.6%；本年土地购置费为9.53亿元，下降21.6%，拉动房地产开发投资下滑7.5个百分点。另一方面土地的频频流拍直接影响了我市土地类基金收入大幅度下滑，土地基金的短收直接影响了今年我市政府主导的基础设施建设和公共事业发展等投资的资金保障，从而影响了全市投资的增长。
