2018年莆田市全社会综合能源生产消费情况分析

第九期
发布时间：2019-01-31 08:19
| | |

2018年我市社会经济稳中有优，二、三产业蓬勃发展，产业结构持续优化。电力生产行业规模扩大，全年发电量高速增长，强力支撑经济社会生产、生活用电的消费需求。工业增加值增速比上年提高，规模以上工业增加值能耗不降反升，是影响全市节能降耗形势的主要因素。面对严峻的节能压力，全市上下一心，主抓落实，节能工作有序开展，成效较好，年底单位GDP能耗趋势较前三季度有明显好转。

一、规模以上工业能源生产现状

2018年我市规模以上工业发电企业发电量为219.16亿千瓦时，同比增长52.1%，增幅较上年提高21.0个百分点。其中，火力发电量为164.0亿千瓦时，同比增长81.4%；水力发电量为29.30亿千瓦时，同比增长4.4%；风力发电量为25.85亿千瓦时，同比增长1.0%。

（一）火力发电，稳居重首。火力发电是支撑我市生产、生活消费的最主要电力来源，近年来火力发电占规模以上工业发电的比重始终保持在60.0%以上,2018年达到74.8%。2018年我市火力发电量已超出全社会用电量，超出的电量为19.62亿千瓦时。其中因为国投云顶湄洲湾电力投产，燃煤发电量比上年翻了一番。而年底燃气电厂因上游LNG溢罐风险，增加了发电计划，发电量同比增速由上年的下降7.7%提升至增长5.1%。

（二）水力发电，平稳回升。2018年我市规模以上水力发电量一改上年持续走低的形势，发电趋势有所回升，主要原因是仙游抽水蓄能夜间调峰次数增多，发电量相应有所增加。

 

（三）风力发电，增势大减。我市主要的县（区、管委会）均建有风电场，是全省最大的风力发电基地。目前规模以上风电企业有14家，发电量同比增长3.6%，占规模以上发电量的比重为11.8%。2018年我市总体风况较差，风力发电增幅较上年回落38.03个百分点。

二、规模以上工业能源消费现状

2018年我市规模以上工业综合能源消费量为374.50万吨标准煤，同比增长47.6%，扣除火力发电行业，同比增长1.8%。全市规模以上工业增加值可比增长9.1%，单位工业增加值能耗增长35.2%，较2017年提高20.3个百分点。

（一）高耗能行业能耗增速和比重再提高

2018年全市六大高耗能行业综合能源消费量为297.94万吨标准煤，同比增长69.6%，增幅提高了33.6个百分点，占规模以上工业能源消费量比重为79.6%，提高了10.4个百分点。

1.电力、热力生产和供应业综合能源消费增势扩大。2018年一至四季度我市电力、热力生产和供应业综合能源消费量增速分别为154.4%、155.7%、111.1%、79.4%，全年各月均呈较高速的增长状态，且增势比上年扩大较多。从比重看，该行业综合能源消费量占规模以上工业综合能源消费量比重始终保持70%以上，对全市规模以上综合能源消费量走势影响较大。

2.黑色金属冶炼和压延加工业能耗增幅逐步回落。在经历了2016年的市场低潮期后，2017年行业生产逐渐复苏，生产大幅增加。鞍钢冷轧生产逐渐稳定，影响行业能耗由年初增长3776.3%回落至增长137.5%。

3.有色金属冶炼和压延加工业能耗增速由负转正。2017年有色金属冶炼和压延加工业全年走低，各月降幅均超过15.0个百分点。今年降势收减，企业订单数量有所增加，生产回暖带动能耗增速由年初的下降15.3%提升至增长5.3%。

（二）主要能源品种消费量再增长

2018年我市规模以上工业原煤消费量608.11万吨，比上年增加269.78万吨。从工业分行业看，原煤消费量较大的行业主要包括电力、热力生产和供应业（564.69万吨），化学纤维制造业（31.41万吨），橡胶和塑料制品业（6.75万吨）。其中，造成全市规模以上工业原煤消费量增长的主要因素在于火电二期的投产。

与原煤消费量的增量比天然气消费量增势较为平缓。2018年我市规模以上工业天然气消费量为5.94亿立方米，同比增长10.3%，是2015年以来的首次消费量增长。从工业分行业看，电力、热力生产和供应业是我市天然气消费主体，占比超过80%，燃气电厂本年发电量的增长带动了天然气消费量的增长。另外，鞍钢冷轧的复产、英博雪津的煤改气，都是引起天然气消费增长的直接原因。

（三）区域性能耗差异再扩大

我市工业产业区域分布各具特色，城厢、涵江、荔城三个辖区以制鞋业、服装业、电子产业及食品加工等轻工业为主要支撑，仙游县文化产业突出，而重工业主要集中在秀屿区和北岸，这就意味着全市的规模以上工业能耗也存在着较大的区域差异。2018年各县（区、管委会）规模以上工业能耗从高到低排列为：北岸（238.63万吨标准煤）、秀屿区（71.68万吨标准煤）、仙游县（22.61万吨标准煤）、涵江区（19.58万吨标准煤）、荔城区（8.45万吨标准煤）、城厢区（6.52万吨标准煤）。北岸受火电厂、赛得利等重点耗能企业影响，能耗占全市规模以上工业能耗的63.7%，较上年同期增长87.7%，能耗增速常年保持全市首位，对全市规模以上工业能耗的影响为43.9个百分点。而其他县（区）中仅有涵江区、荔城区规模以上工业能耗增势较上年有所回落，区域间能耗差异再次拉大。

三、全社会用电情况

2018年我市全社会电力消费量为144.38亿千瓦时，同比增长16.1%，增速较上年提高5.9个百分点，增幅保持在全省第一位的水平。

（一）分产业看，第一产业用电量为0.92亿千瓦时，同比增长6.0%；第二产业用电量为93.04亿千瓦时，同比增长24.5%；第三产业用电量为19.03亿千瓦时，同比增长7.1%；生活电力消费量为31.39亿千瓦时，同比增长1.1%。

（二）工业用电量占全社会用电重头。2018年我市工业用电量为73.90亿千瓦时，占全社会用电量的51.2%，同比增长24.1%，增幅较上年提高13.5个百分点，位居全省第一。

四、节能形势预测和分析

回顾“十三五”以来我市的能耗“双控”情况，节能形势不甚理想。2016年、2017年我市全社会能耗的增量分别为38.3万吨标准煤、42.9万吨标准煤，都超过能耗增量年均34.0万吨标准煤的控制目标；单位GDP能耗的下降率分别为0.96%、0.14%，都低于单位GDP能耗年均下降2.97%的目标要求。面临严峻的节能形势，全市上下迎难而上，经过了两年多的努力节能成效逐渐显现，1-3季度单位GDP能耗增幅比一季度和上半年有所缓解。受全社会用电增速明显回落、规模以上重点耗能企业能耗增速降低等影响，预计全年单位GDP能耗趋势会有进一步的好转。

尽管当前节能压力较年初稍有舒缓，但与完成“十三五”目标序时进度比还有较大差距。要控制能耗总量的增量和单位GDP能耗的速度，本质上都是对能耗总量增速的控制。能耗总量增速低，能耗总量的增量就小，单位GDP能耗的增速便不会高。

（一）电力消费增速仍然较高。电是当前经济社会发展最主要的能源消费品种，二、三产业的生产经营需要用电，居民生活水平的改善更是离不开电。今年以来全市用电量始终保持高速度增长，各季度的累计用电量增速分别为20.2%、27.9%、20.9%、16.1%，增幅一直居全省第一。从能耗测算的角度看，电力消费占我市全社会能耗比重超过60%，可以说电力消费的快速增长决定了我市全社会能耗趋势是只增不减。而GDP的全年增速为8.3%，这就意味着电力增速超过GDP增速近一倍，电力产出率明显降低。

（二）重工业发展带动能耗增长。产业结构决定能耗趋势。我市工业产业结构以轻工业为主，制鞋、服装、食品等传统产业基础扎实，发展有力，2018年规模以上轻工业增加值占规模以上工业增加值比重为70.8%。这部分产业能耗较低，占规模以上工业能耗的比重仅17.7%，对节能形势的影响并不大。我市工业能耗主要集中在重工业，节能降耗的重点也在重工业。近年来为满足社会生产需要，重工业发展速度有所提升，2018年规模以上重工业增加值同比增长13.2%，增幅比上年提高了7.6个百分点，高于规模以上轻工业的增长速度；能耗同比增长66.0%，增幅比上年提高30.9个百分点，可见重工业带来的能耗增长是客观的，是符合发展现状的。

（三）重点耗能企业单耗已达行业前沿水平。节能技改不仅关系到全社会的用能效率，同时也是关系企业成本、收益的重要环节。我市的重点耗能企业在几轮的节能工作后，单耗水平持续降低，有些甚至已经达到全国领先水准，节能潜能很小。比如火电厂二期的超超临界机组，发电效率是当前燃煤发电机组中的最高水平。赛得利的背压式发电机组，发电效率可以将近100%。

（四）新增大项目能耗影响突出。近年来我市投资状况较好，大项目陆续建设投产。2017年国投云顶湄洲湾电力、华佳彩、华锦实业、宏海设备新增入库，产能逐渐发挥，能耗在2018年均达到万吨标准煤以上，列入我市重点耗能企业名单。其中国投云顶湄洲湾电力能耗已超百万标准煤，是目前全市规模以上工业中能耗最大的企业。
