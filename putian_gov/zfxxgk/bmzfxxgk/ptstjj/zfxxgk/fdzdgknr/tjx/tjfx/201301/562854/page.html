2012年产业结构与经济运行质量

发布时间：2013-01-28 00:00
| | |

2012年，我市按照“稳增长、调结构、惠民生”的工作思路，努力克服宏观形势的不利影响，持续打好“五大战役”，加强科学谋划，把握好扩大内需、发展实体经济、加快改革创新和保障改善民生等重大问题，及时出台相应的政策措施，推动稳中求进目标的实现，全市经济保持平稳较快增长势头，综合经济实力跃上新台阶，经济运行质量和效益显著提高，经济发展实现了量和质的同步提高。

一、产业结构调整取得新进展

2012年全市实现生产总值1202.79亿元，增长12.8%，增幅位居全省设区市第一位，高于全省平均水平1.4个百分点。其中，第一产业增加值 107.24亿元，增长3.8%，对经济增长的贡献率为2.7%；第二产业增加值700.18亿元，增长15.7%，对经济增长的贡献率为71.7%；第三产业增加值395.37亿元，增长10.2%，对经济增长的贡献率为25.6%。三次产业结构由2011年的9.4：58.4：32.2调整为2012年的8.9：58.2：32.9。

（一）农业内部结构不断优化。农林牧渔业经济在发展的同时，内部结构得到优化。其中农业在农林牧渔总产值中所占的比重由2011年的34.9％上升为2012年的35.5％，上升了0.6个百分点；林业产值所占比重为2.0%，与2011年持平；牧业产值所占比重由2011年的20.1%下降到2012年的19.0％，下降了1.1个百分点；渔业产值所占比重由2011年的35.6％上升为2012年的36.1％，上升了0.5个百分点。

（二）工业产业结构日趋合理。2012年莆田从实际出发，加大投资力度，相继新建、扩建和改造了一大批富有莆田特色的工业项目，工业内部各行业的发展趋于合理、协调。全市工业实现增加值579.41亿元，增长14.1%。重工业实现产值519.45亿元，增长10.9%，轻工业实现产值1127.86亿元，增长19.9%；轻重工业的比例从2011年的67.8：32.2调整为2012年的68.5：31.5。企业规模快速壮大，工业发展后劲不断增强。2012年，产值超亿元企业达407家，实现产值1432.33亿元，占规模以上工业总产值的87.0%。鞋服、木材浆纸、食品、电子信息、化工、能源、机械装备制造、工艺美术等十大优特产业，实现产值1550.94亿元，增长17.0%。663家规模以上民营企业实现产值1037.26亿元，增长20.6%，增速高于规模以上平均水平3.7个百分点。

（三）第三产业发展势头良好。2012年第三产业实现增加值395.37亿元，增长10.2%，增幅位居全省设区市第三位，高于全省平均水平1.7个百分点，对GDP的贡献率25.6％，拉动GDP增长3.3个百分点。从服务业内部看，交通运输、仓储及邮政业、批发和零售、住宿和餐饮等三个传统行业稳步增长，2012年实现增加值149.59亿元，占服务业增加值的37.8%；金融业实现增加值52.08亿元，增长15.1%，占服务业增加值的13.2%，有力支持地方经济建设；租赁和商务服务业，居民和其他服务业，文化、体育和娱乐业等营利性服务业发展势头良好，实现增加值65.13亿元，增长15.8%；教育、卫生、公共管理等非营利性服务业实现增加值58.72亿元，增长5.4%。

二、经济运行质量进一步提高

（一）消费市场稳定增长，消费需求继续有效拉动经济增长。2012年,我市继续实施拉动内需、促进消费等一系列政策，积极完善现代市场体系，引导消费，推动全市商贸经济结构调整和发展方式的转变，消费档次进一步提升，消费品市场保持较快增长态势，稳中趋旺。全市实现社会消费品零售总额380.70亿元，增长16.8    %。

（二）投资需求规模继续扩大，在经济增长中继续发挥主导作用。2012年，全市把扩大投资与提高投资效益、促进科学发展有机结合起来，全市固定资产投资在结构调整中赶超跨跃，呈现出增长平稳快速、总量进一步扩大、结构不断优化的良好态势。2012年，全社会固定资产投资930.43亿元，增长29.5%。

（三）进出口增幅有所回落。2012年全市实现出口额294958万美元，增长6.1%，居全省第八位；全市实现进口额147419万美元，下降21.0%。

（四）效益继续改善，财政稳定增收。2012年，全市规模以上工业经济效益综合指数达273.54%，比上年提高了31.16个百分点；资产总计925.20亿元，增长18.9%；利润总额65.85亿元，增长28.4%。企业效益好转，促进了财政的稳定增收。全年实现财政总收入129.03亿元，增长24.9%。财政总支出119.60亿元，增长25.4%。金融形势稳定看好，存贷款余额快速增长。年末全市金融机构人民币各项存款余额1062.99亿元，增长23.7%，金融机构人民币各项贷款余额888.30亿元，增长21.7%。

（五）居民收入增多，生活水平提高。2012年，城镇居民人均可支配收入24690元，增长13.0%，城镇居民人均消费支出16065元，增长12.5%；农民人均纯收入10311元，增长13.7%，农民人均生活消费支出7733元，增长14.6%。

三、经济增长中需关注的问题

2012年，莆田取得了国民经济较快发展的良好成绩，为2013年的进一步发展奠定了基础。但在经济发展中，还存在一些不容忽视的矛盾和问题，一是地区经济发展的不平衡、不协调现象仍然突出。GDP增幅高低相差6.6个百分点；地方财政收入增长高低相差21.6个百分点。二是农业基础仍比较薄弱。2012年虽然出现了粮食增产、农民增收的良好局面，但农业基础仍比较薄弱，结构性矛盾还比较突出。三是房地产市场存在不健康的因素。四是出口增长乏力。今年我市出口形势相对低迷，全年仅增长6.1%，居全省第八位；企业接单积极性降低，受出口成本上升和人民币升值等因素的影响，我市企业出口订单比往年有所减少，且大量常规订单转为短单、小单。
