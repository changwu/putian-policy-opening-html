2018年莆田市对外出口贸易平稳向好

第十一期
发布时间：2019-01-31 08:23
| | |

2018年全市实现进出口总额370.80亿元，同比增长1.0%。其中出口224.46亿元，同比增长8.1%；进口146.34亿元，同比下降8.3%，出口好于上年，进口由升转降，外贸顺差有所扩大。

一、全年出口贸易增势高开低走，各月出口额较为平稳

2018年我市出口贸易情况总体呈现增长趋势，增幅由年初的20.3%逐步回落至12月的8.1%。同时,各月出口额波动不大，除三、五月份外，当月出口额均较上年有不同程度的增长。

二、全年进口贸易总体低于去年，月度趋势波动较大

2018年我市外贸进口额趋势与出口额趋势基本相反，除1月份进口额同比增长22.3%外，2-11月累计进口额均少于上年，全年降幅达8.3%，与上年同比增长59.9%的趋势比差距较大。从各月进口额看，最高进口贸易额出现在9月份,12月进口最少。从各月增速看，全年月度趋势波动较大，9月份增速最高，增幅为78.4%；2月份同比下降45.1%，降幅最大。

三、对主要出口国出口贸易增长较多，亚洲、美洲地区进口明显减少

2018年，我市主要出口贸易伙伴为美国、欧盟、东盟、拉丁美洲、中东，出口额分别为16.45亿美元、5.25亿美元、3.18亿美元、2.66亿美元和1.05亿美元，合计为28.58亿美元，同比增长10.4%，增速提高了4.7个百分点。

其中，对日本、台湾、香港的出口额合计为2.04亿美元，同比增长34.2%，占全市出口额的比重由2017年的5.0%提高至6.0%。

四、主要进、出口商品贸易额持续增长，机电出口趋势好于进口

全年鞋类出口额为21.67亿美元，占出口总额的63.6%，出口额同比增长7.7%，较上年提高2.9个百分点。

全年天然气进口额为12.44亿美元，占进口总额的55.9%、5.8%，进口额同比增长42.6%，较上年提高27.4个百分点。

机电出口额为2.96亿美元，同比增长3.7%，与上年的下降8.2%比趋势向好，占全市出口额的比重为8.7%；机电进口额为3.10亿美元，同比下降59.9%，占全市进口额的比重为13.9%。

五、一般贸易进出口发展增速回落，加工贸易逐渐回升

全市全年一般贸易进出口46.60亿美元，同比增长4.8%，增幅回落23.3个百分点，占全市外贸进出口总额的82.7%。其中一般贸易出口26.61亿美元，同比增长14.2%；一般贸易进口19.99亿美元，同比下降5.5%。

全市全年加工贸易进出口9.40亿美元，同比下降1.5%，降幅比上年缩减7.2个百分点，加工贸易逐年回温，占全市进出口总额的16.7%。其中加工贸易出口7.46亿美元，同比增长2.0%；加工贸易进口1.94亿美元，同比下降13.0%。

六、进出口贸易活动区域主要集中在市辖区

2018年我市市辖区进出口贸易额为324.58亿元，同比增长3.4%，占全市进出口贸易额的87.5%。其中秀屿区进出口贸易额最大，全年合计进出口127.82亿元，同比增长22.0%，占全市进出口贸易额的比重为34.5%，贸易活动数量大，增速快。城厢区、涵江区、荔城区三个辖区的出口贸易明显增加，全年合计出口额为171.41亿元，同比增长15.8%，增幅比上年提高14.3个百分点。

总体而言，2018年我市在较为复杂的国际贸易形势下，进出口贸易总额增速虽然有所回落，但出口贸易情况好于上年，贸易顺差有所扩大。2019年全市外贸增长的下行压力仍然较大，全市上下要齐心共力，打造良好的营商环境，支持企业拓展多元化的国际市场，挖掘培育外贸新增长点，做好贸易摩擦升级的应对工作。
