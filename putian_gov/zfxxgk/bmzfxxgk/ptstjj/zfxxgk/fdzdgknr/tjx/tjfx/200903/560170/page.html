建筑业生产快速增长 经济效益继续好转

发布时间：2009-03-18 00:00
| | |

2008年，在全市经济平稳较快发展、投资持续增长的带动和影响下，我市建筑企业继续深化改革，开拓市场，生产与效益同步增长，建筑市场秩序进一步规范，各项生产经营指标继续保持上升趋势。建筑业的不断发展和壮大，为莆田市经济社会的蓬勃发展做出了重要的贡献。

一、2008年我市建筑业发展的主要特点

（一）建筑业生产继续快速增长

2008年，我市建筑企业克服金融危机、房地产低迷等多种不利影响，建筑业各项主要指标继续保持上升趋势。按注册地口径，今年全市具有建筑业资质的企业（含劳务分包建筑企业）共128家，同比增长28.0%；累计完成建筑业总产值（含劳务分包）65.54亿元，同比增长 21.6%。按在地口径，今年在莆施工建筑企业共216家，同比增加25家；累计完成建筑业总产值96.92亿元，同比增长46.0%。

（二）劳动生产率得到较大提高，经济效益继续好转

建筑业企业在着力发展生产的基础上，优化劳动组合，采取减员增效、控制建筑队伍规模等措施，使劳动生产率不断攀升。2008年，建筑业计算劳动生产率的平均人数为46120人，比上年减少6.3%。建筑业企业按建筑业总产值算的劳动生产率为138116元/人，比上年同期提高27.4% 。随着建筑企业生产管理体制改革的不断深化，生产经营方式有了新的变革，为建筑企业生产带来活力。今年全市资质以上建筑企业效益明显改善。全市资质以上建筑企业（含劳务分包）累计实现营业利润2.70亿元，同比增长51.4%；利润总额1.20亿元，同比增长45.3%；企业累计上缴税金2.70亿元，同比增长31.2%。

（三）建筑业结构继续调整

外来建筑企业发展势头强劲。建筑市场开放步伐加快。今年外来建筑企业占全部在莆施工建筑企业数的50.5%,比上年同期上升2.0个百分点；外来建筑企业完成产值占建筑业总产值（按在地口径）的46.9%，比上年同期提高5.0个百分点。

建筑工程产值所占比重增大。在全部建筑业总产值（不含劳务分包）（按注册地）中，建筑工程产值占有较大的比重。今年全市资质建筑企业建筑工程产值累计完成60.84亿元，比上年同期增长23.5%，占全部建筑业总产值的比重为92.8%。

建筑产业区域集中明显。按在地口径，建筑业总产值占首位的县区是荔城区，产值为24.36亿元，建筑业总产值占各县区建筑业总产值之和的28.7%；增长最快的县区是涵江区，涨幅为73.4%。近年来荔城区、涵江区建筑业持续保持高速发展，主要得益于两地重点项目和基础设施的建设。

多种形式承包广泛有序推进。建筑业市场规范化建设进一步深入，以招投标承包制为核心的多种形式的承包制在建筑行业广泛实行。今年全市建筑企业实行投标承包面积924.11万平方米，比上年同期增长19.8%，占全部房屋施工面积的92.2%。建筑企业实行承包经营责任制，建立健全考核制度和奖惩制度，建筑企业市场化程度进一步提高。

非国有建筑企业成长速度加快。随着市场需求的变化和建筑市场竞争的加剧，非国有建筑企业综合能力和适应市场的能力都有显著提高，取得生产与效益同步增长的好形势。今年全市资质以上非国有建筑企业累计完成建筑业总产值53.32亿元，比上年同期增长28.4%，占全部建筑业总产值的比重达到83.7%，比上年同期提高5.9个百分点。

（四）建筑业在经济社会发展中的作用不断增强

据初步核算，今年我市GDP达到609.96亿元，可比增长15.0%，建筑业增加值达到44.77亿元，可比增长17.7%，占全市GDP比重的7.3%，对经济增长的贡献率为7.8%。建筑业在直接拉动国民经济增长的同时，在扩大社会就业、保持社会稳定及推进城镇化进程等方面也做出了积极的贡献。今年全市资质建筑业全部人员年平均人数51897人，比上年同期增长6.6%。

二、当前我市建筑业存在的问题

（一）拖欠工程款现象依然严重

拖欠工程款一方面加大了建筑企业生产经营的困难，严重影响了建筑市场的健康发展；另一方面危及社会稳定，破坏社会经济秩序，严重影响工程建设的顺利实施，甚至导致工程质量和安全的隐患。近几年来，全国各地加大了清欠建设领域拖欠工程款力度，从莆田市目前的情况来看，清欠的效果不太明显，甚至出现了新拖欠。

（二）工程结算成本居高不下

工程结算成本增长过快，压缩了建筑企业的盈利空间，影响了企业经济效益的进一步提高。今年全市资质以上建筑企业工程结算成本51.47亿元，比上年同期增长了33.4%，占工程结算收入的87.5%，比上年同期上升了1个百分点，一直处在占工程结算收入80%以上的高位区间。

三、促进我市建筑业发展的几点建议

今年全市经济将继续保持平稳较快增长，为建筑业的发展提供了广阔的空间，建筑企业要抓住这一良好机遇，在激烈的市场竞争中壮大实力。目前应从以下方面加以努力：

（一）提高企业综合实力，培植龙头企业。

莆田市建筑企业的施工能力、管理水平、技术力量等与全国平均水平相比有一定的差距，今年全市资质建筑企业（不含劳务分包）平均实现建筑业总产值为5551万元，工程技术人员仅占从业人员的14.4%，主项资质为一级的只有3家，占建筑企业的比重为2.5%。因此，积极扶持一批市场竞争力强、市场占有率高、实力雄厚、人才技术密集度高、能充分发挥规模经济优势的龙头企业，是莆田建筑业步入良性发展轨道的关键所在，也是扩大我市建筑业市场份额的重要基础。

（二）强化建筑市场管理，规范市场行为。

垫资施工、拖欠工程款等问题是长期困扰建筑企业的难题。必须高度重视，予以有效解决，政府应积极服务企业，加大清欠工作力度；企业应运用法律、法规等各种手段，维护自己的合法权益。在清理拖欠工程款的同时，应控制和防止新的工程款拖欠，把解决好工程款拖欠问题作为一项社会综合工程来抓，促进建筑企业健康发展。

（三）降低企业经营成本，提高经济效益。

科学的管理仍然是现代企业竞争力的重要因素，也是降低企业经营成本，提高企业经济效益的最好途径。企业管理要特别重视信息化技术的应用，要通过企业管理水平的提升，达到竞争能力的提高，进而推进整个企业和行业的优化升级。

（四）切实加强执法检查，规范市场秩序。

建设行政管理部门要对建筑法实施情况进行经常性的执法检查，对检查中发现的建设单位肢解发包、任意压低价格、缩短工期、拖欠工程款等突出问题，要坚决处理。只有这样，建筑市场秩序才会趋于规范，安全生产形势才会逐步好转，工程质量才会稳定提高。

（五）规范政府投资行为，鼓励企业投资。

政府投资规范方面应该更多地借鉴外地先进做法，对政府投资项目采取委托制，委托给建设总公司承包和管理，根据合同对其进行考核，改变越是政府投资的项目浪费越大的不规范现象。同时积极筹划出台政府投资相关文件，理顺投资体制，保护企业的投资积极性。这将大大减少政府投资项目拖欠工程款的风险，也有利于建筑市场的规范。

撰稿：高荔
