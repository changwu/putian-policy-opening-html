2025年莆田市农业经济运行分析

发布时间：2026-02-02 10:04
| | |
 今年以来，在市委市政府的正确领导下，全市上下深入学习贯彻习近平总书记关于“三农”工作的重要论述，落实中央、省委农村工作会议部署，精准聚焦、攻坚突破，千方百计推动农业增效益、农村增活力、农民增收入，农业经济总体呈现稳定发展态势。

一、主要运行特点

（一）农林牧渔业总产值稳步增长

2025年,莆田市农林牧渔业总产值294.65亿元，按可比价格计算，同比增长4.1%。其中：农业产值74.82亿元，增长6.0%；林业产值8.24亿元，增长4.8%；牧业产值34.27亿元，下降1.6%；渔业产值151.93亿元，增长4.4%；农林牧渔服务业产值25.39亿元，增长4.9%。农林牧渔业总产值结构如下：

 

（二）粮食生产保持稳定

 市委、市政府始终把粮食安全和耕地保护作为重大政治责任，始终严守耕地红线，不断提升耕地质量，全力稳定粮食生产。2025年，全市粮食播种面积47.40万亩，增长0.9%；产量19.52万吨，增长1.4%；单产411.7公斤/亩，增长0.5%。分品种看，谷物产量12.40万吨，增长1.3%；薯类产量6.22万吨，增长2.6%；豆类产量0.90万吨，下降6.5%。

（三）蔬菜生产实现扩种增产

莆田市各级政府深入贯彻落实中央关于加大耕地利用率的决策部署，继续开展撂荒地复垦复种，加大耕地流转，不断扩大蔬菜种植面积，加强田间管理，有效提高蔬菜单产，实现扩种增产。2025年，全市蔬菜播种面积38.36万亩，增长5.5%；产量75.03万吨，增长5.7%；单产1956公斤/亩，增长0.3%。

（四）“四大名果”产量增长亮眼

莆田“四大名果”品质优良，市场需求旺盛，果农管护积极性增强，部分失管果园逐步复管；且今年我市气候适宜，气温较稳定，雨量适中，是园林水果大丰产年。全市园林水果产量27.26万吨，增长10.5%。其中枇杷产量8.05万吨，增长8.4%；龙眼产量3.14万吨，增长16.2%；荔枝产量0.15万吨，增长52.0%；柚产量11.39万吨，增长12.1%。

（五）油茶产业建设初见成效

为深入学习贯彻习近平总书记关于发展油茶产业的重要指示精神，深化落实党中央、国务院关于保障粮油安全、实施乡村振兴战略的决策部署，2023年《莆田市推进油茶产业高质量发展三年行动实施方案》实施以来，我市以木兰溪全流域国土绿化试点示范项目为契机，扎实推进油茶产业发展，取得了阶段性成效。2025年，全市油茶籽产量0.91万吨，增长12.0%。

（六）水产品产量逐年增加

莆田市深入贯彻落实省委、省政府关于加快建设“海上福建”的决策部署，紧密围绕“海上莆田”建设目标，系统推进海洋资源科学开发与高效利用，持续优化养殖空间布局，创新养殖模式，规范养殖管理，全市水产品生产能力稳步提升，水产品产量逐年增加。2025年，全市水产品总产量116.85万吨，增长4.3%。其中海水产品产量113.82万吨，增长4.4%；内陆水域水产品产量3.02万吨，增长0.7%。

二、需关注的问题

（一）肉类总产量下降

受市场价格持续走低、养殖成本攀升及疫病防控压力等多重冲击，养殖户生产积极性受挫。2025年，全市肉类总产量8.78万吨，下降6.4%。分品种看，猪肉产量4.69万吨，下降3.3%；牛肉产量0.04万吨，下降2.8%，羊肉产量0.08万吨，下降14.1%；禽肉产量3.98万吨，下降9.8%。

（二）海产品品种结构不合理

2025年，全市海产品产量增长主要依赖江蓠、牡蛎、海带、蛏、蛤等低价值品种，对海产品的贡献率分别为49.5%、24.4%、14.4%、4.7%、2.9%，共计95.9%；而鲍鱼、梭子蟹、鹰爪虾、虾蛄、紫菜等高价值品种增长疲软，增速分别为1.0%、1.0%、-0.4%、0.1%、0.7%。

三、对策建议

（一）精准发力稳定畜牧业产能

一是重点稳定生猪核心产能，加强对生猪生产各环节的技术指导，引导养殖场（户）科学调控生产节奏，保障生猪产能处于合理区间。二是推动养殖结构多元化，大力发展肉牛、肉羊等节粮型草食畜牧业，优化畜禽养殖结构，减少对粮食饲料的依赖，并逐步弥补猪肉产量缺口。三是强化科技驱动，重点推广畜禽优良品种、精准饲喂、疫病综合防控等关键技术，完善自动化、智能化装备，提升养殖水平。

（二）扩大鲍鱼等高价值海产品的养殖规模

一是优化品种结构，聚焦鲍鱼、梭子蟹、虾蛄等高价值海产品，加大资金扶持与技术服务，推广生态高效养殖模式，持续扩大高价值品种养殖规模。二是扩展养殖空间，科学规划养殖海域，支持深海渔场、智能化底播养殖等现代化海洋牧场建设，推动养殖方式从近海向深远海有序拓展，不断增加养殖面积。三是推动产业链条延伸，强化海产品精深加工，提升海产品的附加值。
