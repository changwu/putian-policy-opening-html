2017年莆田市一套表调查单位简析

第七十四期
发布时间：2017-11-08 15:03
| | |

伴随着市场经济的迅猛发展，社会各界对统计工作的关注度越来越高，给统计工作提出了更多、更新的要求。加强统计能力建设，提高统计数据质量，满足政府、企业和群众的数据需求是统计工作者的神圣职责。“一套表调查单位”作为地区经济的重要组成部分，是经济体量的重要支柱，也是衡量地区经济发展水平的重要标尺。解析“一套表调查单位”企业的发展状况，对于促进“一套表调查单位”企业的快速健康发展、做大做强经济总量和推进莆田市的社会经济发展等各方面都具有十分重要的意义。

一、“一套表单位”现状

（一）单位数逐年稳步上升

截至2017年10月份，我市共有“一套表”法人单位3552个，同比增长11.84%。按登记注册类型看，其他有限责任公司2615个，占比73.62%，同比增长13.60%；私营有限责任公司385个，占比10.84%，同比增长15.62%。（详见表一）

（二）单位的地区分布趋于合理

从分区域的情况看，各县区之间的“一套表”法人单位数趋于合理，其中以荔城区和城厢区的法人单位数最多，分别占比21.34%和20.02%。

从区域的增长情况看，同比2016年，其中以北岸和秀屿区的增速最快，分别比上期增长25.00%和22.86%。（详见表二）

（三）工业占比降低，服务业与贸易企业增长加快

2017年“一套表调查单位”企业与2016年相比总量增加376家，增长11.84%，其中工业企业1269家，占总量的35.73%，比重从16年的39.23%下降到了35.73%；服务业企业430家，占总量的12.11%，企业数增加了133个，同比增长44.78%；贸易企业1155家，占总量32.52%，企业数增加了173个，同比增长17.62%；房地产企业226个，占比6.36%；建筑业企业312个，占比8.78%；投资企业160个；占比4.5%。（详见表三）

二、存在问题

（一）区域经济发展相对不平衡

从县（区）的发展情况看，荔城区与城厢区的“一套表”法人单位数占全市的41.36%，涵江区和仙游县虽然在单位数与之相比差距不多，但是增速较慢，分别只有4.49%和3.69%；秀屿区与北岸增速最快但体量较低。

（二）产业结构不合理，行业分布不均

工业是我市国民经济的重要支柱，占“一套表”调查单位总量的35.73%；同时建筑业、房地产、投资的占比均有所下降，贸易与服务业单位数增加，增速加快。第三产业的占比越来越高，第二产业的占比慢慢回落，这是产业结构调整的市场表现。

三、对策与建议

（一）切实落实中小企业培育扶持政策，提高企业市场竞争力 

2017年，复杂的外部形势和宏观经济下行压力以及企业经营风险进一步加大，较大程度制约了经济的良性发展。在新的发展环境与发展阶段，要保持经济平稳较快发展，必须在各项扶持政策的落实上下功夫。一要切实落实中小企业培育扶持政策，积极支持中小企业特别是战略性新兴企业，向“专、精、尖”方向发展；鼓励全民创业大众创新，不断壮大基本单位数量，引导限上规模企业做大、做强、做优，使扶持新政真正对全市行业发展进一步产生催化反应，推动地区经济继续回暖升级。二要坚持“扶优扶强”，提高企业抗风险能力。通过市内企业之间的资源整合，培育扶优一批大公司和企业集团，提高企业效益和抗风险能力；鼓励小企业和民营企业与国内外大中企业建立专业化协作关系，延伸重点企业的产业链和增值链，形成大、中、小企业相互依存的经济结构体系。同时，要对那些生产能力过剩、技术落后、污染严重、不具备安全生产能力的企业，坚决实行关、停、并、转，将有限的资源有效地配置到具有发展优势或相对比较优势的行业和企业中去，增强企业市场竞争力。 

（二）加快调整产业区域布局，促进产业增效提质、优化升级

 一 是要根据自身产业基础和比较优势，依托现有各级各地工业园区，大力培育和发展本地优势产业，以进一步提高产业聚集度，形成产业特色，加快产业区域布局速度；二是要以加快转变经济增长方式为目的，以结构调整为方向，以提高产品供给侧竞争力为核心，推动产业结构增效提升优化；三要尽快理顺、有效衔接产业链各环节，完成产业与产业之间、行业与行业之间的协调布局，切实推进产业结构的优势化和高级化。 

（三）加快城镇群发展速度，促进县域经济协调发展 

目前，莆田市各县区经济体之间关联度低、产业同构、资源竞争等问题制约各县区经济进一步发展。针对各县区经济发展不平衡现状，应强化政府区域经济协调发展的调控职能，整合中心城区优势资源，依托各现有工业园产业发展特点，因地制宜，引导资源配置，带动经济实力较弱的板块组团式协调发展，是进一步提高全市整体经济增长能力的必由之路。
