1-10月莆田市经济运行情况分析

第七十七期
发布时间：2021-11-16 10:52
| | |

今年以来，在市委、市政府的坚强领导下，全市上下科学统筹疫情防控和经济社会发展，积极应对本轮疫情的持续影响，有序实现全面复工复产复商复市，经济运行总体上保持恢复向好态势。

一、经济运行特点

（一）工业生产稳定增长。1-10月，全市规模以上工业增加值同比增长7.6%,增幅高于上年同期6.2个百分点。从先行指标看，全市累计工业用电量71.51亿度，增长23.2%，增幅居全省第2位，自3月份以来累计增幅始终保持在20%以上。从分行业看，全市工业33个行业大类中，有24个行业增加值实现同比增长，增长面为72.7%，特别是占据主导地位的规上“343”重点产业工业增加值增长8.3%，增幅高于全市规上工业增加值0.7个百分点，对全市规上工业增加值增长的贡献率为100.4%，拉动全市规上工业增加值增长7.6个百分点。从经济效益看，1-9月，全市工业经济效益综合指数为387.94，同比提高6.73个点；每百元营业收入中的成本为88.08元，同比下降0.16元；实现利润总额176.30亿元，增长20.3%，增幅高于全省平均水平1.1个百分点。

（二）规上服务业平稳增长。1-9月，全市规模以上服务业营业收入同比增长2.3%。其中，规上其他营利性服务业营业收入增长8.0%。从分行业看，在弹好工科技、硕合才储信息科技、云智薪共享经济信息咨询等企业带动下，全市平台企业营业收入增长3.8倍，拉动全市规上其他营利性服务业增长13.8个百分点；在市城投集团、龙吉顺实业等企业带动下，全市规上水利、环境和公共设施管理业营业收入由上年同期的下降4.3%转为增长71.6%，增幅高于全省平均水平61.0个百分点。

（三）固定资产投资延续增势。1-10月，全市固定资产投资（不含农户）同比增长1.9%，增幅高于上年同期5.8个百分点。从投资领域看，制造业投资增长7.1%；房地产开发投资增长10.6%，增幅居全省第三位，拉动全市固定资产投资增长2.2个百分点，仍是全市固定资产投资持续增长的主要支撑。全市商品房销售面积410.90万平方米，增长22.0%，增幅连续七个月居全省首位。

（四）消费市场有序恢复。1-10月，全市社会消费品零售总额完成1452.02亿元，同比增长9.4%，增幅比上年同期提高10.4个百分点。从商品类别看，全市限上21类商品类别中有16类商品实现正增长，增长面为80.0%，形成以鞋帽类、日用品类和汽车类为主的限上消费品市场。其中，限上鞋帽类零售额127.43亿元，增长19.0%；限上日用品类零售额64.37亿元，增长21.2%；限上汽车类零售额62.98亿元，增长5.0%。从零售模式看，全市限上网上商品零售额延续较快增长态势，累计增长18.8%，增幅高于全市社会消费品零售总额9.4个百分点，拉动全市社会消费品零售总额增长3.5个百分点。

（五）财政金融运行稳健。1-10月，全市一般公共预算总收入完成218.59亿元，同比增长13.4%，增幅高于上年同期15.7个百分点。其中，一般公共预算收入完成136.44亿元，增长13.0%，增幅高于上年同期15.5个百分点。一般公共预算支出完成202.18亿元，增长4.3%，增幅高于上年同期3.9个百分点。10月末，全市金融机构本外币存款余额2518.03亿元，增长11.1%，增幅居全省第3位；金融机构本外币贷款余额2444.91亿元，增长11.1%。

（六）消费价格温和上涨。1-10月，市区居民消费价格总水平同比上涨0.2%，涨幅比上年同期回落1.9个百分点。八大类消费“三增四降一持平”，增长的有：交通和通信类价格上涨3.2%，教育文化和娱乐上3.1%，生活用品及服务类上涨0.8%；下降的有：其他用品和服务类价格下降5.6%，食品烟酒类价格下降1.0%；居住类价格下降0.2%；医疗保障类价格下降0.1%；衣着类价格与去年持平。

二、存在问题

（一）规上工业下行压力较大。一是停、减产企业影响较大。由于销售不畅，成本提高加上疫情影响，一些风险承受能力弱的企业生产恢复较慢，经营压力加大，出现复产又停产或减产的情况。截至10月末，全市规模以上停、减产企业414家，停减产面达36.6%，比1-9月扩大1.3个百分点，影响全市规上工业增加值增长4.3个百分点。二是小微企业增长疲软。1-10月，占全市规上工业企业数80.1%的规上小微工业企业增加值仅增2.6%，增幅分别低于全市规上工业增加值、规上大中型企业增加值5.0个和9.2个百分点，是影响全市规上工业经济增长的主要因素之一。

（二）规上其他营利性服务业持续回落。一是规上商务和租赁服务业增速持续回落。受瑞智无忧（福建）科技等大企业业务量萎缩及远景投资管理等退库企业影响，占全市规上其他营利性服务业营业收入67.5%的规上租赁和商务服务业营业收入增幅分别比1-8月、1-5月和上年同期回落6.9个、23.0个和13.5个百分点，低于全省平均水平49.3个百分点。二是企业“进少退多”。2020年末以来，全市新入库规上其他营利性服务业企业仅29家，同比减少14家，而退库企业达74家，共拉低全市规上其他营利性服务业营业收入增速16.5个百分点。

（三）固定资产投资后劲不足。一是大项目投资低迷。占全市固投65.7%的5000万及以上项目投资下降5.1%，降幅比1-9月扩大2.2个百分点，拉低全市固定投资增长3.6个百分点。二是重点行业投资支撑不力。合起来占全市固投57.4%的基础设施投资和工业投资分别下降7.7%和3.4%，降幅分别比1-9月扩大2.7个和2.6个百分点。

（四）限上贸易企业发展瓶颈突出。一是无营业企业较多。截至10月末，全市限上无营业企业达564家，占限上贸易企业的28.1%，主要是受资金紧张、企业经营不善而注销、竞争力弱、经济纠纷、季节性因素及疫情等因素影响。二是实体企业经营困难。1-10月，限上有店铺零售额仅增2.9%，增幅比1-9月回落2.2个百分点，主要是实体商贸流通企业大多数面临客流不足、房租及人员等成本高等问题，经营环境较为艰难，加上本轮疫情的冲击导致经营压力更大。三是住餐业受疫情影响仍在持续。受疫情影响，全市住餐业错过了中秋、国庆“双节”消费高峰期，导致业绩大幅下滑，虽然当前已全面复商复市，住餐企业也积极开展各种促销活动，但市场消费信心恢复仍尚待时日，住餐业整体恢复相对较慢。

三、对策建议

（一）稳住工业基本盘。一是聚焦重点工业行业、重点地区和骨干企业，采取有力措施确保稳产稳效，持续发挥较强支撑作用。鼓励制鞋、电子信息、化工新材料等“343”重点行业增产稳产，稳住工业经济基本盘。二是加快生产制造与信息技术服务融合。运用互联网、大数据等信息技术，积极发展定制生产，满足多样化、个性化消费需求。促进智能终端与应用服务相融合、数字产品与内容服务相结合，推动产品创新，拓展服务领域。

（二）力促服务业发展壮大。一是各级各有关部门要认真做好年底“上规”标准企业的入库工作，确保及时入统、应统尽统，增加联网直报企业数量，弥补退库企业的不利影响。二是建立“准规企业库”，对临界未达规模的市场主体进行储备观察，有针对性地重点予以扶持、培育，对于成长良好、发展潜力大的企业建立跟踪回访机制，加大培育力度。

（三）增强投资增长后劲。一是贯彻落实全省九市一区党政主要负责同志座谈会精神，大抓项目，抓大项目，积极开展“攻坚两个月 奋战六十天”重大项目攻坚行动，在确保安全和质量的前提下推动在建项目加快建设，形成更多的实物量。二是增强投资发展后劲，重点抓好集中开工的50个大项目及其他项目的入库工作，要主动靠前服务，协助建设单位做好项目前期工作，加快项目落地和开工建设。

（四）破解贸易发展瓶颈。一是积极开展“攻坚两个月 奋战六十天”扩内需促销费行动，全力扩内需、促消费，畅通国际国内双循环，促进全市消费稳定增长。二是推动实体零售企业线上线下融合发展，拓宽销售渠道。扩大农村电商覆盖面，提升农产品进城和工业品下乡双向流通效率。三是重点关注点钢、三棵树、新东联、点增等亿元企业，及时跟踪服务，帮助企业协调解决经营过程中遇到的困难和问题，增强企业市场竞争力。
