2018年上半年我市节能形势依然严峻

第三十八期
发布时间：2018-07-23 16:20
| | |
 “十三五”以来我市节能形势一直处于高度预警状态，今年一季度单位GDP能耗同比不降反升，增幅为2.3%，与全省下降的趋势相反。上半年预计单位GDP能耗的增幅将有所回落，但受新增项目能耗大增速快、全社会用电需求居高不下的影响，要按序时完成能耗“双控”目标较为困难。

一、节能降耗目标任务完成现状

（一）单位GDP能耗未能完成下降目标。一季度我市单位GDP能耗同比增长2.3%，规模以上工业增加值能耗同比增长70.0%，增幅均居全省第一。截至上半年，规模以上工业增加值能耗增幅有所回落，增速缩减为66.0%；单位GDP能耗增幅预计也将有所回落，但距离年度下降7.6以上的目标任务还有较大差距。

（二）全社会能耗总量增速偏高。一季度我市全社会能耗总量为139.18万吨标准煤，同比增长10.6%，增幅较上年同期提高7.2个百分点。能耗总量同比增量为13.37万吨标准煤，已经占年度能耗增量控制目标的64.3%。因为火电二期、华锦实业、华佳彩等新增高耗能企业投产时间为去年下半年，今年上半年对能耗总量的净增影响仍在，预计上半年能耗总量的增量将超过全年控制目标。

二、能耗生产、消费主要特点

（一）能源生产结构单一

我市地处东南沿海，风能、水能、潮汐能等可再生能源丰富，但煤、油、天然气资源短缺，能源生产结构单一，除电力以外的其他能源品种都要从市外调入。2017年煤品、油品、天然气、液化天然气的调入量分别为389.02万吨、59.29万吨、8.94亿立方米、16.79万吨。

从今年上半年我市规模以上电力生产情况看：1、火力发电比重高增速快。火力发电量为78.37亿千瓦时，占总发电量的72.5%，同比增长172.1%，增幅较上年提高150.7个百分点；2、水力发电量不断增加。近年来我市水力发电规模扩大明显，发电量从2014年的9.05亿千瓦时增加到2017年的28.08亿千瓦时，增长超过两倍。今年上半年水力发电量已达16.80亿千瓦时，预计全年发电量将超过上年全年；3、风力发电遍地开花。我市除湄洲岛外，城厢、涵江、荔城、秀屿、仙游、北岸均配有风电场，是全省风电规模最大的城市。上半年风力发电量13.00亿千瓦时，占全省风力发电量的43.6%；发电量同比增长17.6%，增幅比全省高6.6个百分点。

（二）产业电力消费差异大

产业发展结构决定了产业电力消费的结构。工业作为我市国民经济的主导力量，其增加值占GDP比重超过一半，用电量占全社会用电量也超过一半，用电量较上年同期增长37.4%，增幅远高于全省平均水平，推动全社会用电量增长22.5个百分点。可见我市工业正推动全社会经济稳健向好发展。但是单纯以用电量的增长来衡量地区经济发展已经不符合当前节能降耗、绿色发展的新形势。从三产增加值及用电结构看，上半年一、二、三产的增加值占比结构为5.5:57.2:37.3，用电量占比结构为0.7:83.4:15.9，二产的电耗产出低于一产、三产。产业间增加值电耗水平相差较大，工业增加值电耗同比增长26.5%，而建筑业增加值电耗增速仅为3.9%。

（三）能源消费相对集中

轻工业为主导，重工业提速发展，是我市当前工业发展的现状。上半年规模以上轻、重工业的增加值占比分别为71.5%、28.5%，但轻工业能耗水平普遍低于重工业，上半年轻、重工业能耗占比分别为18.9%、81.1%。因此我市规模以上工业能耗以重工业为主，而且相对集中在重工业中的高耗能企业上，上半年能耗总量超过万吨标准煤的重工业企业有9家，占规模以上工业企业数的0.8%；能耗总量合计130.80万吨标准煤，占规模以上工业能耗总量的76.4%。

（四）化石能源品种消费增加

煤品、油品、天然气是我市消费的主要化石能源品种。去年油品消费量占能耗总量比重有小幅下降，煤品、天然气消费量占能耗总量比重不降反升，尤其是煤品的消费比重提高了9.6个百分点。

2018年上半年，规模以上工业煤品消费量为296.05万吨，同比增长156.6%，增幅较上年提高141.7个百分点；油品消费量为0.6万吨，同比下降30.3%；天然气消费量为3.20亿立方米，同比增长62.4%，增幅提高42.3个百分点。

三、影响节能降耗形势的因素

（一）新增高耗能项目多。2017年新增规模以上工业企业中能耗超千吨标准煤的有4家，全年新增用能30.80万吨标准煤。今年上半年这四家新增高耗能企业能耗为50.89万吨标准煤，占规模以上工业能耗总量的29.7%。下半年永荣、HDT项目预计投产，将带来较大的能耗增量。

（二）区域节能进度不均衡。上半年我市规模以上工业增加值能耗同比增长66.0%，有六个县（区、管委会）工业增加值能耗出现不同程度的变动。仙游县、涵江区、秀屿区、北岸管委会工业增加值能耗均较上年提高，增幅分别为2.9%、0.6%、21.7%、101.9%；城厢区、荔城区工业增加值能耗同比下降，降幅分别为12.2%、11.1%。

（三）节能挖潜空间有限。“十三五”以来节能降耗工作持续推进，一产、三产增加值能耗水平已经低于全社会平均水平，下降空间较小。而作为能耗大头的工业，受产业结构升级进度较慢、重点耗能企业节能技术局限等影响，单耗水平要下降，难度很大。

四、改善节能降耗形势的建议

（一）严格高能耗项目准入。强化项目准入，全面启动能评机制改革，实行能评限批制度，限制能耗总量大、单耗水平高的项目建设投产。

（二）加快产业结构调整优化。大力发展新能源和可再生能源产业，减少化石能源品种的消费总量；加快淘汰改造落后生产能力，抓创新投资，大力发展智能制造、互联网经济等新经济、新业态。

（三）强化节能服务体系建设。加强节能新技术、新产品推广机制建设，在燃煤电厂、电机能效提升、锅炉提效等重点领域推广应用。同时加强节能监测，建立健全节能管理体系。
