一季度莆田市消费品市场运行情况简析

第二十三期
发布时间：2019-04-23 08:36
| | |

一季度，全市消费品市场发展呈向好态势，增速有所加快。

一、全市消费品零售市场运行状况及特点

（一）消费市场运行呈两位数增长

一季度，全市社会消费品零售总额216.58亿元，同比增长10.4%，增幅比上年同期回落2.3个百分点，但比1-2月和上年分别提升2.0个和0.6个百分点，增幅在全省的位次从上月的第八位上升至第四位。如下图所示。

                                                                     

 

按消费形态分，一季度，全市商品零售198.53亿元，增长10.4%，餐饮收入18.04亿元，增长10.0%。

按限额标准分，一季度限额以上单位实现消费品零售额112.89亿元，增长13.8%；限额以下单位实现103.68亿元，增长6.9%，限额以上和限额以下单位增幅均比1-2月提升1.7个百分点。

（二）限额以上消费品市场发展稳中向好

1、乡村消费较快发展。分经营地看，乡村消费潜力得到进一步释放，一季度，限额以上乡村单位实现商品零售额4.37亿元，增长32.9%，增幅比1-2月快2.5个百分点，比城镇快19.8个百分点。

2、网络零售较快增长。全市电商企业在销售渠道拓宽及店铺活动促销等活动拉动下，总体呈较快发展态势，商品涉及鞋类、通讯类、家电类及工艺品类等。一季度，全市限额以上批发和零售企业通过公共网络实现零售额40.29亿元(具体见附表)，增长21.8%，增幅分别比1-2月和上年提升4.2个和3.6个百分点，比全省低4.0个百分点，占全市消费品零售总额的比重比全省高12.2个百分点，达18.6%，对全市消费品零售总额的贡献率达35.4%。

3、部分实体店业态发展势头强劲。因交通便利及人流量多等因素，一季度，食杂店实现零售额增长39.6%，便利店实现零售额增长46.1%，百货店增长23.3%，家居建材商店增长13.2%。

4、居民消费升级加快

一是限额以上单位品质类商品热销。一季度，化妆品类商品零售额增长40.6%，中西药品类增长48.6%，通讯器材类增长40.6%，书报杂志类增长208.0%。

二是绿色消费快速发展。一季度，全省限额以上新能源汽车、可穿戴智能设备、智能家用电器和音像器材、智能手机零售额同比分别增长46.9%、87.5%、18.5%、35.8%。

三是家装类消费活跃。一季度，全市限额以上单位实现家具类商品零售额增长48.2%，五金、电料类增长82.4%，建筑及装潢材料类增长16.5%。

二、限额以上消费品市场发展应注意的问题

1、大宗商品增速减缓。一季度，全市限额以上汽车类商品实现零售额17.10亿元，同比增长4.0%，增幅比上年同期和上年分别回落23.2个和2.4个百分点。石油及制品类商品实现零售额8.30亿元，下降2.7%，增幅比上年同期和上年分别回落12.5个和7.4个百分点。汽车和石油类商品零售额占限额以上零售额的比重为22.5%，拉动限额以上零售额增长0.4个百分点，同比回落5.0个百分点。

2、有店铺零售增速回落。一季度，有店铺零售增长8.6%，比上年同期低11.6个百分点，比无店铺零售低8.3个百分点，除部分业态较快增长外，主要受专业店、专卖店和超市增速回落影响。一季度，专业店、专卖店和超市实现零售额分别增长8.8%、8.8%和增长4.7%，分别同比回落11.6个、15.1个和14.6个百分点。

3、部分企业停业影响。一季度，陆续有52家限额以上批发零售企业停业,累计零售额同比减少0.90亿元，拉低限额以上零售额增幅0.9个百分点。通过对停业企业调查发现，29家因竞争压力大、无订单等而关闭，9家注销、6家资金链断裂，5家迁出，3家转行业。其中，11家电商企业，占21.2%。

三、发展建议

1、进一步优化企业经营环境。据对58家大中小微型企业一季度生产经营景气状况的调查，在相关政策落实方面，有17家企业获得相关优惠政策扶持，占调查总数的29.3%，其受益政策最多的是减税降费，占56.5%，其次是简政放权，占13.0%，再者是创新支持、互联网+扶持政策和降息方面，均占8.7%。在“对扶持政策的诉求”中，企业呼吁扶持中小企业发展、拓宽中小企业融资渠道、进一步减税降息等等。这说明，有关部门在简政、减税降费、融资、口岸出关审批、电商企业扶持政策等方面有较多工作要做。有关部门应做好服务，努力打造法治化、国际化、便利化的营商环境，激发市场主体活力。

2、补短板促民生。一季度市场运行的“短板”集中体现在吃类、金银珠宝类和家用电器和音像器材类等部分商品类别上。要引导企业加快商品更新换代，增加商品种类，推进个性化定制，进一步细化市场、拓宽市场，满足城乡居民多层次、多样化的消费需求。

3、加快实体零售发展。一季度，实体零售总体增速放缓，究其原因是经营形式雷同、同质化竞争严重。互联网时代已突破了传统零售业的地域限制，市场范围已达全省、全国及全世界，实体零售要扭转低增长态势，企业就要解放思想，进一步推动线上线下有机融合，实现多渠道经营，提供更多优质商品并加强全方位的良好服务，这样才能吸引更多的消费者，从而推动行业较好较快发展。
