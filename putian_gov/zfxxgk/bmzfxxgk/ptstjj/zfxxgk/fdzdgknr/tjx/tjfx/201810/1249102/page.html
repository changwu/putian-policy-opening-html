三季度莆田GDP运行简析

第六十六期
发布时间：2018-10-24 11:14
| | |

初步核算，三季度全市实现生产总值1593.46亿元，增长7.7%，增幅比上年同期回落0.5个百分点，增幅居全省设区市第四位。其中，第一产业增加值77.73亿元，增长3.7%，增幅比上年同期提高2.8个百分点；第二产业增加值841.67亿元，增长8.5%，增幅比上年同期提高1.2个百分点；第三产业增加值674.06亿元，增长6.8%，增幅比上年同期回落3.9个百分点。

一、运行特点

（一）从三次产业贡献率看。第一产业贡献率为2.3％，比上年同期提高  1.6个百分点；第二产业贡献率为63.0％，比上年同期提高11.0个百分点；第三产业贡献率为34.7％，比上年同期回落12.6个百分点。

（二）从三次产业拉动情况看。第一产业拉动GDP增长0.2个百分点，比上年同期提高0.1个百分点。第二产业拉动GDP增长4.8个百分点，比上年同期提高0.6个百分点。第三产业拉动GDP增长2.7个百分点，比上年同期回落  1.2个百分点。

（三）农业生产增幅回升。三季度，第一产业实现增加值77.73亿元，增长3.7%，同比提高2.8个百分点。农业实现产值32.42亿元，增长4.0%；林业实现产值1.22亿元，下降8.1%；牧业实现产值19.12亿元，下降1.9%；渔业实现产值77.07亿元，增长5.8%。

（四）工业经济平稳向好。全市实现工业增加值690.39亿元，增长8.8%，增幅比二季度提高0.2个百分点，比上年同期提高1.3个百分点，对经济增长的贡献率为54.9％。全市规模以上工业增加值增长9.0%,比1-6月提高0.1个百分点，比2017年全年增幅8.2%高0.8个百分点。1-9月，全市规模以上皮革、毛皮、羽毛及其制品和制鞋业增加值同比增长11.4%；电力、热力生产和供应业增长41.5%；电子信息业增长31.5%；纺织业增长37.0%；纺织服装、服饰业增长19.9%；非金属矿物制品业增长17.3%；通用设备制造业增长25.2%。

（五）第三产业增速逐季走低。三季度，全市第三产业增加值增长6.8%，比二季度回落2.6个百分点，比一季度回落3.5个百分点，同比回落3.9个百分点；分别低于全市生产总值增速和规模以上工业增速0.9个和2.2个百分点。第三产业对生产总值增长的贡献率由上年同期47.3%回落至34.7%。从第三产业内部看，交通运输、仓储及邮政业实现增加值50.96亿元，增长6.1%，低于全省平均水平1.7个百分点；批发和零售业实现增加值108.80亿元，增长  6.6%，低于全省平均水平0.7个百分点；金融业实现增加值79.81亿元， 下降2.3%，低于全省平均水平5.3个百分点；房地产业实现增加值130.91亿元，增长2.6%，低于全省平均水平4.2个百分点。营利性服务业实现增加值179.68亿元， 增长23.5%，高于全省平均水平3.2个百分点；非营利性服务业实现增加值89.13亿元，下降6.4%，低于全省平均水平8.8个百分点。

（六）县区竞相发展、差距缩小。三季度，各县区呈现出竞相发展的良好势头。从GDP增速看，最高增速与最低增速相差由上年同期5.3个百分点，缩小到今年的2.9个百分点。2个县区GDP增速高于全市平均水平，GDP增速最高的荔城，增长8.5%，比增速最低的湄洲高出2.9个百分点。

二、需关注的问题

（一）停、减产企业影响仍旧明显。9月末，全市规模以上企业停、减产面达28.7%，共拉低全市规模以上工业增加值增幅7.5个百分点。其中停产企业124家，比8月末增加8家，拉低全市规模以上工业增加值增幅5.3个百分点；部分企业因环保整治影响产能受限；华佳彩、云度新能源、鞍钢冷轧等企业订单不足，产能发挥有限，与年初的预期产能差距较大。

（二）第三产业增长乏力。核算第三产业部分相关指标增幅明显回落。第三产业增加值增长6.8%，比上年同期回落3.9个百分点，影响GDP增长速度回落1.2个百分点。商贸业发展动力仍显不足。9月末，全市40家限额以上停业批发企业，影响全市批发业销售额累计增幅1.2个百分点。规模以上其他营利性服务业增速（错月）比1-5月回落6.6个百分点，影响第三产业增加值增长0.66个百分点。财政一般公用等八项支出由上半年增长17.6%转为下降4.1%，影响我市第三产业增加值增幅1.75个百分点。金融指标增幅持续走低。8月末，全市人民币存贷款余额比5月末回落2.7个，居全省末位；1-9月，全市保费收入增长11.1%，增幅比1-6月回落1.6个百分点，人民币存贷款余额及保费收入增幅回落共影响我市第三产业增加值增幅0.47个百分点。房地产销售面积增速由上半年的增长0.6%转为下降3.8%，影响我市第三产业增加值增幅0.13个百分点。
