新制度下我市规上工业企业研发投入分析

第六十三期
发布时间：2019-09-26 15:59
| | |

为规范企业对研发费用的核算，2018年开始企业研发统计调查制度改革：将“项目归集法”改为“财务支出法”，企业要按照其有关研究开发会计科目或税务部门提供的辅助账填报，即调查表各指标与有关研究开发会计科目（辅助账）中归集的项目对应。本文针对新制度下，我市规上工业研发投入（R&D经费投入）状况开展分析，探讨我市规上工业研发投入存在的问题，并提出相应的对策建议。

施行研发统计调查新制度，较大程度地避免了企业漏报或者虚报的情况，提高规上工业企业研发统计报表数据质量。今年的研发投入继续保持了两位数的增长，增速比上年提高了4.6个百分点，但仍面临着研发投入不足、研发质量不高、高端技术人才短缺等不容忽视的问题，需引起关注。

一、规模以上工业研发经费投入的主要特点

全市1202家规上工业企业中，有168家企业开展研发活动，其中大型企业19家、中型企业34家、小型企业17家、微型企业83家；有研发机构企业87家，占规上企业数的7.2%；R&D经费内部支出26.38亿元，比上年增长14.6%，其中企业资金占规上工业研发经费投入比重进一步加大，达到97.5%，政府资金、境外资金和其他资金合计所占比重仅为2.5%；规上工业研发投入强度（即研发投入占企业主营业务收入比重）为0.81%，比上年提高0.01个百分点；R&D人员0.56万人，比上年降低4.7%，R&D人员折合全时当量3639人年，比上年降低15.7%。

（一）内资企业研发经费投入高。2018年内资企业研发经费投入为19.73亿元，比上年增长了27.0%，高于规上工业平均水平12.4个百分点；占规上工业研发经费投入比重为74.8%，比上年提高了7.4个百分点，分别比港澳台商投资企业和外商投资企业高61.5个和62.9个百分点。

（二）区域研发投入不平衡。2018年，涵江区R&D经费内部支出占规上工业研发总投入的40.6%，涵江区是我市研发的主力，主要是三个大的研发企业带动作用明显（福建华佳彩有限公司2018年研发项目进入正轨，新引入一条价值3.6亿元的研发设备，上报研发经费翻了3.96倍；百威雪津啤酒有限公司提高产能，上报研发经费增长33.5%）。新制度下，参考了企业行业的特点核定各地区R&D经费，涵江区和仙游县几家大中型重点研发企业技术含量较高，研发经费投入增速最快，分别为增长了57.8%和81.4%，荔城区工业企业以鞋服的制造为主，传统行业科技含量较低，研发经费投入不理想。

三大优势行业研发能力强。从行业分布情况看，41个行业小类中，R&D经费投入集中在计算机、通信和其他电子设备制造业、化学原料和化学制品制造业、橡胶和塑料制品业三个行业，其中计算机、通信和其他电子设备制造业R&D经费投入占规上工业研发经费投入有明显优势，比重最大，达到29.3%，三大行业R&D经费投入占其主营业务收入比重分别为4.80%、1.53%和1.60%。

（四）研发相关指标发展情况。一是专利指标实现较快发展。2018年，全市规模以上工业企业发明专利、拥有有效发明专利分别比上年增长34.7%和50.9%。二是研发产出及销售平稳增长。全市各类规上工业企业全年共有新产品开发项目716项，同比增长4.8%；当年投入新产品开发经费27.42亿元，实现新产品产值182.12亿元，新产品销售收入达171.61亿元，比上年增长7.4%。

二、存在问题

（一）研发企业的覆盖面有待扩展，研发经费投入强度有待提高。

2018年，全市有开展研发活动的企业168家，比上年减少了40家，占全部规上工业的仅14.0%；全市规上工业R&D经费占全省规上工业R&D经费比重仅为5.0%，规上工业研发经费投入强度为0.81%，根据国际标准：企业研发投入强度小于1%表式企业创新能力较低。可见，开展R&D活动的企业覆盖面较小，创新动力依然不足。

（二）试验发展活动较多，基础研究和应用研究投入有待加强。

从技术发展层级看，企业研发的方向仍然是以不具备核心自主知识产权的低水平新产品开发为主，基础研究和应用研究投入甚为罕见。按照国际惯例，发达国家R&D投入比例大致是基础研究占10%-15%，应用研究占25%-35%，试验发展占60%-70%。2018年全市规上工业企业R&D经费投入基础研究领域为0，投入应用研究仅为3.1%，分别比全省平均水平低3.9个百分点和4.3个百分点。规模以上工业企业未涉足基础研究，研发活动更侧重于短期效益。

（三）政府资金对企业的支持非常有限。

2018年，企业使用来自政府扶持资金2196.8万元，占规上工业研发经费投入的1.6%，政府资金投入相对不足。工业企业是研发活动和研发成果绝对主力，R&D投入占全社会比重达96.4%的规上工业所获得政府资金支持只占全社会政府资金总额的22.2%，财政资金对规模企业的杠杆作用未得到充发挥。

（四）企业办研发机构构建还需全面提升。

2018年，莆田市企业办研发机构不论是从个数、人员，还是经费投入都出现较大幅度下降。全市研发机构100个，比上年减少48个，比上年下降了32.4%；机构人员2580人，比上年下降了17.4%；机构经费支出55708.7万元，比上年下降了23.4%。

（五）企业高素质人才相对匮乏。

2018年，莆田市工业企业R&D人员5609人，比上年下降了4.7%，R&D人员折合全时当量合计3639人年，比上年下降了15.7%。企业办研发机构人员构成中，具有博士学历的60人、硕士学历的136人，分别占企业办研究机构人员的2.3%和5.3%。

三、对策建议

（一）发挥政府导向作用，加大科技投入力度。

一是要建立莆田市科技研发投入的长效机制，调动企业开展科技研发的积极性，从制度供给层面上位企业开展研发活动创造优良的环境。从项目、优惠政策等方面向企业倾斜，促进企业主动参与技术研发和成果转化，加大有研发活动工业企业覆盖率；二是进一步增强政府资金引导作用，让企业积极主动申请并享受政府相关财税政策（研发费用加计扣除减免税和高新技术企业减免税等）。简化申报程序，不断改进市级科研项目和资金管理的若干意见中的鼓励政策，加大省级科技孵化器的财政专项资金扶持的争取，提升企业创新软环境；三是搭建“互联网+”环境下的产学研用合作平台，优化高等院校、科研院所和企业的分工合作，促进研发力量在“理论准备—应用发展—试验投产”全链条上的合理分配。

（二）努力构建我市产业新的增长集群。

2019年，莆田市政府已经出台了有关传统行业开展研发、引进科技人才和电商平台等的资金补贴方案，鼓励引导工业企业改变“一站式”的生产经营模式，推动工业上下游服务环节外包，提高生产性服务业的市场比重，有利地促进传统产业转型升级。在此基础上，应大力发展电子商务、互联网金融、远程技术支持等服务业新兴业态，着重在优势领域和新兴产业重点培育一批科技创新型企业，使之成为全市科技创新的标志性工程和带动全市高新技术产业发展的龙头。

（三）加强企业办机构和科技创新人才队伍建设。

一是出台一些针对性比较强的鼓励科技研发机构发展的措施，树立一个明确的政府导向。力争大中型的科技型工业企业全面设立研发机构，此外，对传统的大型的科技企业来说，独立设立研发机构或者研发办公室，也是他们提高市场竞争力、长久立足的重要措施。二是加强高端人才的引进和培养力度。要制定完善区别对待的扶持政策，着力鼓励企业引进具有科技创新能力的高端科技人才。如采用股权激励机制等优惠政策，增强企业对科技创新人才的吸引力、凝聚力，让他们“引得进、留得住、有动力、富起来”。建立科学的人才评价体系，激发科技人员的创新意识，推动企业创新能力建设。

（四）努力提升企业研发投入质量。

基础研究和应用研究是企业原始创新的源泉。因此，在试验发展投入增长的同时，应注重基础和应用研究的经费投入。一方面，引导实力较强的企业，加强拥有自主知识产权的核心科研项目的投入，更多的开展基础研究和应用研究；另一方面，加快传统政府主办科研院所改革进度，对于与市场结合紧密、以应用研究、试验发展活动为主要业务的单位，推动其改制转企，按照企业化经营、市场化运作，加大投入力度，使基础研究得到保障，摒弃重短期经济效益，轻长期社会效益的思想，让更多的科技资源配置到基础研究领域上，补齐基础研究短板。
