农业生产有序推进粮食果蔬喜获丰收——2020年莆田市农业经济简析

第二期
发布时间：2021-01-18 17:34
| | |

今年以来，我市气候条件良好，有利于农业生产。同时，我市各级各部门认真做好“六稳”工作、落实“六保”任务，坚持疫情防控和农业生产两手抓，稳定农业基本盘，农林牧渔业生产有序推进，粮食果蔬喜获丰收。

一、主要运行特点

（一）农业生产有序推进，农业经济稳步增长

2020年,莆田市农林牧渔业总产值237.41亿元，可比增长1.7%。其中：农业产值56.53亿元，增长4.9%；林业产值6.29亿元，增长0.1%；牧业产值39.88亿元，下降2.0%；渔业产值114.94亿元，增长0.8%；农林牧渔服务业产值19.78亿元，增长4.9%。

（二）补助政策成效显著，粮食实现扩种增产

我市全面贯彻落实国家、省委省政府粮食生产决策部署，出台粮食生产补助政策，鼓励引导种植户扩大粮食种植规模，提高粮食产能，粮食实现扩种增产。2020年，全市粮食播种面积为45.64万亩，增长1.1%；产量为18.53万吨，增长1.3%；平均亩产为406公斤/亩，增长0.2%。

（三）茶果蔬生产情势良好，产量稳步增加

今年我市气候条件良好，没有出现往年的倒春寒，虫害少，有利于茶果蔬生产，产量增加明显。2020年，全市茶叶产量为0.39万吨，比上年同期增加0.01万吨，增长3.8%。全市园林水果产量为20.24万吨，比上年同期增加1.23万吨，增长6.5%。全市蔬菜播种面积为33.27万亩，比上年同期扩大1.68万亩，增长5.3%；蔬菜产量达65.20万吨，比上年同期增加2.70万吨，增长4.3%。

（四）生猪存栏逐季增加，产能迅速恢复

随着支持生猪养殖政策的落地和生猪养殖效益的提高，生猪产能先行指标存栏数逐季增加，年末存栏数成倍增长，生猪生产呈逐步恢复态势。至2020年底，全市生猪存栏31.95万头，比9月底增加8.84万头；全年存栏增长101.9%，增幅比9月底提高33.1个百分点。全市生猪全年累计出栏46.09万头，下降20.9%，降幅比1-3季度收窄0.4个百分点。

（五）渔业产销衔接良好，生产价格逐步回升

2020年，全市水产品总产量99.51万吨，增长1.6%。其中海水产品产量96.75万吨，增长1.7%；内陆水域水产品产量2.76万吨，下降1.7%。随着国内餐饮业恢复常态化营业，我市水产品产销衔接良好，水产品价格逐步回升，2020年第四季度本季全省水产品生产价格指数为100.22%，生产价格指数分别比第三季度本季和第二季度本季高6.03个和10.6个百分点。

二、存在的主要问题

（一）生猪产能恢复遇到瓶颈

我市流域面积大，饮用水源多，高速公路和高铁覆盖范围广，导致我市生猪养殖可养范围较小，养殖用地相对紧缺，一些养殖场受资金、用地要素制约，增加产能方面遇到制约瓶颈。

（二）食用菌生产规模不断萎缩

2020年，全市食用菌生产用地为0.52万亩，在上年和前年同期分别下降11.8%和38.9%的基础上今年继续下降3.5%；食用菌产量为3.74万吨，在上年和前年同期分别下降4.1%和35.3%的基础上今年继续下降0.6%。其中，蘑菇产量3.27万吨，在上年和前年同期分别下降6.3%和36.2%的基础上今年继续下降0.5%。

三、下一步建议

（一）采取有效措施实现粮食应种尽种

一要继续加大高标准农田建设力度，真正实现旱涝保收、高产稳产；二要继续加强粮食生产补助，充分调动农民种粮积极性，尽可能杜绝抛荒，实现粮食应种尽种；三要进一步加强粮食作物病虫害统防统治等田间管理，提高单产，确保丰产丰收。

（二）大力发展畜牧业规模化养殖和循环养殖

要加大招商引资力度，引进国内外先进养殖模式的畜牧业企业，如丹麦皇冠等国际知名生猪养殖屠宰加工一体化企业，带动我市畜牧业向规模化养殖和循环养殖发展，提升行业整体竞争力。

（三）推动食用菌智能化生产

出台政策鼓励我市现有食用菌工厂化生产企业扩大生产规模，扶持培育食用菌龙头企业，积极引导我市食用菌从分散式的传统生产模式向 “企业+农户”模式和集约化、工厂化、专业化、精细化、产销一体化的现代企业经营模式转变，推动食用菌全产链发展，实现食用菌量增价升。
