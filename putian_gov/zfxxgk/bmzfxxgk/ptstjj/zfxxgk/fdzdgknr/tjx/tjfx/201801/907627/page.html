2017年莆田市固定资产投资稳中有进

发布时间：2018-01-22 14:56
| | |

2017年，在省委、省政府和市委、市政府的坚强领导下，全市围绕“坚持绿色发展，打造宜居港城、建设美丽莆田，创建美丽中国的示范区”奋斗目标，着力推进供给侧结构性改革，突出项目带动，积极落实“五个一批”项目工作机制，努力扩大有效投资，全市固定资产投资稳中有进。

一、固定资产投资总体稳中有进

2017年，我市固定资产投资完成2274.65亿元，同比增长17.4%，增幅同比提高5.6个百分点，比全省平均水平高3.9个百分点, 增幅位居全省第三位。其中：项目投资完成1885.83亿元，同比增长19.0%，比全省平均水平高3.3个百分点，增幅居全省二位；房地产开发投资完成388.82亿元，同比增长10.1%, 增幅位居全省第二位。

 

二、固定资产投资运行中的亮点

（一）三次产业全面增长

2017年，我市第一产业完成投资36.50亿元，同比增长14.2%；第二产业完成投资670.07亿元，同比增长12.5%；第三产业完成投资1566.71亿元，同比增长19.5% ，增速同比提高13.3个百分点，比第一产业、第二产业分别高5.3、7.0个百分点。三次产业结构由上年的1.6:30.7:67.6转为本年的1.6:29.5:68.9，产业结构有所优化。

（二）项目投资占比过八成且在库项目增多

2017年，全市项目投资完成1885.83亿元，同比增长19.0%，增幅居全省二位，占固定资产投资的比重为82.9%，比上年同期提高1.1个百分点；累计在库项目3763个，与上年同期比增加1161个，其中5000万以上项目335个；5000万以下项目3428个，同比增加1164个。

（三）市政建设投资带动基础设施投资增长

2017年，我市基础设施投资完成943.18亿元，同比增长13.0%，占固定资产投资比重为41.5%，对固定资产投资贡献率为32.4%。其中，市政建设投资在环湄洲湾尾水排放管道工程、木兰大道一期、白塘路建设工程、秀屿区埭头省级特色小城镇配套提升工程、鲤南片区二期市政基础设施工程建设等大型市政项目的带动下迅速增长，市政建设投资全年完成358.66亿元，同比增长22.6%，对基础设施投资和全市固定资产投资增长的贡献率分别为61.0%和19.7%，分别拉动基础设施投资和全市固定资产投资增长7.9、3.4个百分点。

（四）投资内涵持续深化

2017年，我市投资内涵持续深化，技术型投资快速提升。改建和技术改造项目投资完成171.30亿元，增速由去年同期的下降34.1转为增长16.7%；工业投资中，装备制造业投资同比增长22.8%，占工业投资比重为21.2%，同比提高1.8个百分点；先进制造业投资完成149.21亿元，同比增长28.4%。

（五）民生工程领域投资加快

今年以来，我市继续加快推进民生工程建设，民生领域投资快速增长。全市固定资产投资中，居民服务和其他服务业投资增长119.0%，文化、体育和娱乐业投资增长100.0%，卫生和社会工作投资增长55.0%，教育事业投资增长38.1%，水利、环境和公共设施管理业投资增长18.6%。

（六）民间投资活力增强

全市民间投资完成1360.88亿元，同比增长23.0%，增幅同比提高11.7个百分点,占固定资产投资比重为59.9%，同比提高2.8个百分点,对固定资产投资的贡献率75.9%，同比提高20.9个百分点。

（七）房地产开发投资增速回升

2017年，全市房地产开发投资完成388.82亿元，同比增长10.1%，增幅比上年同期提高25.2个百分点，比全省平均水平高5.6个百分点。全市完成商品房销售面积398.97万平方米，同比增长3.6%;商品房销售额345.27亿元，增长21.2%。

三、关注的问题

（一）投资存量不足

2017年，全市固定资产投资累计完成投资占计划总投资的87.6%，比上年同期高8.1个百分点。其中：项目投资累计已完成投资占计划总投资的86.3%，比上年同期高12.1个百分点，房地产开发投资累计已完成投资占计划总投资的89.7%,比上年同期高0.9个百分点。在库10亿元以上项目共38个，计划总投资1353.25亿元，有余量项目22个，剩余投资额269.16亿元，项目剩余投资额仅占计划总投资34.7%。在库大项目投资余量不足，加上新开工大项目较少，项目投资发展后劲乏力。

2、工业投资存量不足，全市工业投资自开始累计已占计划总投资的85.1%，同比提高了16.8个百分点，大型工业项目基本上接近完工，工业投资存量不足的短板已呈现。

3、技改投资完成276.00亿元，同比仅增长4.4%，增速比上年同期低8.9个百分点。

（三）基础设施投资增速逐月回落

2017年，全市基础设施投资同比增长13.0%，增幅比1-2月、1-3月、1-4月、1-5月、1-6月、1-7月、1-8月、1-9月、1-10月、1-11月分别回落18.5、14.8、11.6、11.0、7.2、8.2、7.6、7.0、3.0、0.5个百分点，比去年同期回落17.7个百分点，占固定资产投资41.5%的基础设施投资呈现逐月回落的态势，势必影响全市固定资产投资稳步增长。

（四）资金到位情况不理想

2017年，全市建设资金到位2287.60亿元，同比仅增长9.2%，增速比上年同期低0.3个百分点，比固定资产投资低8.2个百分点，项目建设资金到位1718.74亿元，同比增长11.6%，房地产开发投资资金到位568.87亿元，同比增长2.5%。其中，国内贷款258.94亿元，同比下降6.9%；国家预算资金143.44亿元，同比下降11.1%；自筹资金1461.97亿元，同比增长16.6%。

四、若干建议

（一）增强投资发展后劲

要围绕十大产业，策划生成具有比较优势和带动作用的重大龙头产业链项目。要增强招商氛围，加大招商引资力度，综合利用精准招商、产业链招商、“零地招商”等多种模式进行招商。有效发挥港口优势，积极推进大型项目前期工作。

（二）加大基础设施项目投资

1、推动交通基础设施投资。加快联十一线征迁建设，开工建设纵一线平海至山亭段、荔城大道—荔园路立交桥，加大福厦高铁客专项目建设力度，推进兴化湾和莆头泊位、城港大道提升工程等项目建设，加快推进莆田机场、绕城高速、城际轨道等前期工作，进一步构建、扩大交通系统框架。

2、推动市政基础设施投资。围绕宜居莆田的建设目标，推进城市绿道建设；城镇供水、污水处理提标改造；保障性安居工程等市政配套基础设施建设。

3、加快能源基础设施建设。重点加快中海油LNG5#6#罐以及南日岛、平海湾等海上风电场建设，推动哈纳斯燃气项目开工建设。

4、加快水利基础设施建设。实施城市内河综合治理工程；加快木兰溪防洪工程及玉湖等蓄洪区建设，实施城市片区防洪排涝工程，开工建设宁海闸，加快推进海堤除险加固。

（三）多渠道筹措建设资金

1、建立健全重大项目融资对接长效机制，建立重大项目融资需求信息数据库并发布项目融资需求，分门别类开展专场对接，引导银行、证券、保险、基金、融资租赁、信托等金融机构将更多资金投向重点领域和重大项目建设。

2、积极推进金融创新，发挥好金融机构和资本市场作用，对有条件的大中型企业，可以推动企业股权融资、债权融资；继续优化引资环境，实现利用外资较快增长。
