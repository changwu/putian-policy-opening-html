2018年1-3月莆田市规模以上工业运行分析

第二十期
发布时间：2018-04-19 14:50
| | |

1-3月，我市工业经济稳中向好，先关先行指标保持较快增长，随着供给侧结构性改革不断深化，结构调整步伐加快，工业经济迈向高质量发展，但全市工业经济发展的稳增长基础仍不牢固，下行压力依然较大。

一、工业经济运行主要特点

（一）工业先行指标总体向好。一是工业用电量增长给力。1-3月全市工业用电量18.12亿千瓦时，增长20.8%，增幅位居全省九设区市第1位。扣除抽水蓄能后，累计工业用电量增长17.0%，增幅位居全省九设区市第1位。其中，制造业工业用电量增长20.7%。工业用电量快速增长折射我市工业经济发展内在潜力强劲。二是工业增值税增幅止负转正。1-3月，全市实现工业增值税10.02亿元，增长19.1%，保持两位数增长，改变近年来负增长的态势。

（二）工业企业景气指数回升处于“较为景气”区间。据一季度工业企业景气调查结果显示，一季度企业景气指数为128.1，比上年四季度高4.4点，持续处于“较为景气”区间。其中，反映企业当前景气状态的即期企业景气指数为128.9，比上年四季度高2.7点；反映企业未来景气预判的预期企业景气指数为127.6，比上年四季度高5.5点。一季度企业家信心指数为129.0，比上年四季度高2.2点，企业家对后期经济运行持谨慎“乐观”。

（三）工业生产总体平稳。1-3月，全市规模以上工业增加值增长7.9%,与全省平均水平持平，比上年同期高0.7个百分点，位居全省第四位。分行业看，33个大类行业中有21个行业增加值同比正增长，并且15个行业实现两位数增长。其中皮革、毛皮、羽毛及其制品和制鞋业增长11.0%。酒、饮料和精制茶制造业增长11.6%。食品制造业增长17.8%。计算机、通信和其他电子设备制造业增长22.3%，电力、热力生产和供应业增长34.0%，纺织业增长52.3%。

（四）工业产业集群带动稳固。1-3月，全市十大行业工业增加值增长7.8%，总量占全市规上工业增加值总量达96.2%，对规模以上工业经济增长的贡献率为95.1%，拉动规模以上工业增加值增长7.5个百分点。

一是制鞋产业支撑明显。1-3月，占全市规上工业增加值总量27.3%的制鞋产业工业增加值增长10.5%，对规模以上工业经济增长的贡献率为33.0%，拉动规模以上工业增加值增长2.6个百分点。一是永丰、鑫龙、协丰、辉特等重点鞋业企业，中长期订单稳定，产能发挥80%以上，实现较快增长。二是我市鞋业供应链服务平台的有力助推。目前入驻企业普遍降低采购成本3%以上，促进鞋业降本增效。三是内、外两个市场开拓较好。郭氏、力奴、祥冠、祥麟等企业，今年内、外销订单充足，都新增生产线。

二是纺织服装业增长趋势强劲。1-3月，全市纺织服装业工业增加值增长35.9%，对规模以上工业经济增长的贡献率为24.8%，拉动规模以上工业增加值增长2.0个百分点。主要是去年新投产的华锦实业贡献较为给力。华耀运动用品与华峰新材料由于新厂房和设备陆续投产，产能进一步提高。

三是能源产业快速增长。1-3月，全市能源产业工业增加值增长29.7%，对规模以上工业经济增长的贡献率为15.6%，拉动规模以上工业增加值增长1.2个百分点。主要是LNG、国投湄洲湾电力拉动明显。

四是食品医药保持平稳增长。1-3月，全市食品医药产业工业增加值增长9.0%，对规模以上工业经济增长的贡献率为13.0%，拉动规模以上工业增加值增长1.0个百分点。主要是以英博雪津、闽中有机食品为龙头食品加工企业保持平稳增长。

（五）工业企业结构调整步伐加快。1-3月，全市战略性新兴产业工业增加值增长22.1%，高于全市规上工业平均增速14.2个百分点。对规模以上工业经济增长的贡献率为34.7%，拉动规模以上工业增加值增长2.7个百分点。高技术企业工业增加值增长13.4%，高于全市规上工业平均增速5.5个百分点，对规模以上工业经济增长的贡献率为9.7%，拉动规模以上工业增加值增长0.8个百分点。装备制造业工业增加值增长7.5%，较去年同期高3.1个百分点，对规模以上工业经济增长的贡献率为12.4%，拉动规模以上工业增加值增长1.0个百分点。高耗能行业工业增加值增长7.4%,增幅分别比全市规上工业平均水平和上年同期低0.5个和5.2个百分点，工业向绿色发展步伐迈进。

（六）重工业发展快于轻工业。1-3月，全市重工业工业增加值增长9.1%，增幅高于轻工业增速1.6个百分点，占全市规上工业增加值总量29.6%，对规模以上工业经济增长的贡献率为32.4%，拉动规模以上工业增加值增长2.6个百分点。

（七）新投产工业企业拉动作用明显。1-3月，全市16家去年新投产企业对规模以上工业经济增长的贡献率为35.1%，拉动规模以上工业增加值增长2.8个百分点。

（八）企业利润总额稳增长。1-2月，全市规上工业企业利润总额增长4.2%，每百元主营业务收入中的成本86.37元，比上年同期增加0.34元。主营业务收入利润率6.6%，比上年同期下降0.4个百分点。

二、存在问题

（一）停、减产企业影响明显。3月末，全市停、减产面达30.8%，比2月末提高4.5个百分点，共拉低全市工业增加值增幅8.4个百分点。其中停产企业82家，比2月末增加9家，拉低全市工业增加值增幅5.3个百分点。减产企业294家，比2月末增加46家，拉低全市工业增加值增幅3.1个百分点。

（二）部分企业产能发挥受限。鞍钢冷轧虽恢复生产，但受订单影响，产能未能发挥到预期目标。去年新投产的华佳彩、元生智汇，由于机器设备还处于调试和试产阶段，与预期的达产目标差距较大。

（三）规上工业企业数减少，转规企业贡献不足。3月末，全市共有规模以上工业企业1220家，但比上年同期减少41家。37家去年年底转规企业对规模以上工业增加值增长的贡献率为5.7%，仅拉动规模以上工业增加值增长0.4个百分点。

（四）工艺创意产业和化工产业支撑作用减弱。受红木市场不景气和产品转向中低端市场影响，1-3月我市第二大的工艺创意产业工业增加值下降6.1%，拉低全市工业增加值增长0.3个百分点。受中锦新材料（产品价格下降）、三棵树涂料（订单转移到四川、河南分厂）、滨海化工等龙头企业影响，化工产业贡献不足，1-3月全市化工产业工业增加值下降1.0%，拉低全市工业增加值增长0.1个百分点。

（五）转型升级仍需深耕。一是粗放管理方式阻碍企业转型升级。现代化管理是企业转型升级的必然路径，传统粗放管理方式已经无法适应产业结构调整的步伐。目前我市小微企业还是以家族化、粗放型管理偏多。二是科技创新动力不足难以实现新突破。创新是产业结构优化升级的依托和方向。一季度景气调查结果显示，60.8%的调查企业还不具有享受创新政策的支持，说明我市企业创新乏力。

（六）工业企业去库存、去杠杆、降成本任重道远。1-2月，全市规模以上工业产成品存货增长8.2%，比上年同期提高3.3个百分点。全市规模以上资产负债率54.3%，比上年同期提高0.5个百分点；每百元主营业务收入中的成本86.37元，比上年同期增加0.34元。
