2015年1－7月莆田市规模以上工业运行分析

发布时间：2015-08-13 00:00
| | |

今年以来全市工业经济运行平稳。1-7月份，全市实现规模以上工业增加值473.76亿元，可比增长10.6%，工业增加值累计增速已连续六个月稳居全省九设区市第二位。增幅比全省平均水平高1.3个百分点，但比上半年和一季度分别回落0.2和0.4个百分点，继续运行在10.6%－11.4%的平稳波动区间。

2015年1－7月份我市规模以上工业增长趋势图（单位:%）

一、主要运行特点

（一）轻工业发展快于重工业，重工业企稳回升明显。1-7月份我市规模以上轻工业实现工业增加值332.75亿元，可比增长11.3%，增幅比重工业快2.6个百分点，对规模以上工业经济的贡献率达75.6%，拉动规模以上工业增加值增长8.0个百分点。重工业实现工业增加值141.02亿元，可比增长8.7%，增幅比1-6月低0.5个百分点，但分别比1-5月、1-4月、1-3月、1-2月高2.3个、4.0个、5.2个和5.9个百分点。对规模以上工业经济的贡献率达24.4%，拉动规模以上工业增加值增长2.6个百分点。重工业回升迹象明显，主要是中锦新材料投产和LNG企稳回升。

（二）股份制企业增势喜人，亿元企业拉动效应明显。1-7月份我市规模以上工业股份制企业在燃气发电、华峰新材料增长的带动下快速发展，实现工业增加值324.34亿元，可比增长13.9%，增幅比全市平均水平高3.3个百分点，对规模以上工业经济的贡献率达87.9%，拉动规模以上工业增加值增长9.3个百分点。

鑫龙鞋业、金伯爵珠宝、永丰鞋业等379家超亿元规模以上企业实现工业增加值375.12亿元，可比增长16.1%，对规模以上工业增加值的贡献率达115.2%，比1-6月提高2.2个百分点，拉动规模以上工业经济增长12.2个百分点。

（三）十大产业集群贡献突出。1-7月，我市规模以上十大产业实现工业增加值454.65亿元，可比增长11.1%，增速比全市规模以上工业平均增速快0.5个百分点，对全市规模以上工业经济增长的贡献率达100.4%，拉动规模以上工业增加值增长10.6个百分点。

传统产业支撑作用逐步增强。1-7月，制鞋产业实现工业增加值109.15亿元，占全市规上工业增加值比重为23.0%，对全市规模以上工业经济增长的贡献率达20.6%，拉动规模以上工业增加值增长2.2个百分点。工艺与创意产业实现工业增加值67.50亿元，增长20.9%，对全市规模以上工业经济增长的贡献率达25.9%，拉动规模以上工业增加值增长2.7个百分点。

新兴产业发展势头强劲。中锦新材料的投产、滨海化工和三棵树涂料等企业的增长拉动全市化工产业持续高位增长。 1-7月，全市化工产业实现工业增加值41.87亿元，比上年同期增长25.2%，增幅比全市十大产业平均水平高14.1个百分点。对全市规模以上工业经济增长的贡献率达18.7%，贡献率位居全市十大产业第三位，拉动规模以上工业增加值增长2.0个百分点（详见下图）。

（四）小微企业成工业经济增长的主力军。1-7月，全市935家规模以上小微工业企业实现工业增加值241.16亿元，比上年同期增长13.1%，增幅比全市规模以上工业增加值平均增速快2.5个百分点，比大中型工业增加值增幅快5.1个百分点。对全市规模以上工业经济增长的贡献率达61.9%，高于大中型企业贡献率23.8个点，在工业经济稳增长中生力军作用更加凸显。分行业看，全市小微工业企业分布在33个行业大类中，有 27个行业同比实现增长，16个行业增速快于全市小微企业平均增速，增速均达15.0%以上，特别是纺织业、化学原料和化学制品制造业二个行业在华峰新材料、中锦新材料、滨海化工等企业快速增长带动下增势强劲，增幅分别达103.2%、134.8%。

（五）新增企业成新增长点。1-7月，全市新增工业企业共拉动规模以上工业经济增长6.3个百分点。其中，华峰新材料、金伯爵珠宝、山河制药等151家规下转规上企业实现工业增加值27.47亿元，同比增长1.4倍，对规模以上工业增加值的贡献率为36.6%，拉动全市规模以上工业经济增长3.9个百分点。去年以来32家新投产工业企业实现工业增加值13.74亿元，同比增长2.7倍，对全市规模以上工业增加值的贡献率为23.0%，拉动规模以上工业经济增长2.4个百分点，其中中锦新材料、滨海化工和贺喜光电拉动作用较为明显。

（六）民营企业发展活力进一步显现。7月底止，全市民营工业企业788家，占规上工业企业单位数的67.6%，完成工业增加值283.03亿元，比上年同期增长11.8%，占规模以上工业增加值的比重为59.7%，比去年1-7月提高了0.6个百分点，对规模以上工业经济的增长贡献率达65.9%，拉动规上工业经济增长7.0个百分点。

（七）经济效益总体保持较好水平。1-6月，全市规模以上工业经济效益综合指数为321.57，分别比上年同期和1-5月高25.4和4.7个点。“两金”占用平稳。1-6月，全市规上工业应收账款165.61亿元，比上年同期增长4.2%，工业产成品存货59.48亿元，比上年同期下降0.6%，这两项资金占流动资产比重达34.4%，同比下降1.1个百分点。1-6月实现利润总额58.07亿元，同比增长12.9%，比1-5月高8.5个百分点。主营业务收入利润率4.7%，同比提高0.1个百分点，高于1-5月0.5个百分点。

二、工业经济运行中存在的问题与不足

（一）工业经济下行压力仍然较大。1-7月份，全市规模以上工业增加值增长10.7%，比上年同期、今年上半年和一季度分别回落2.8个、0.2个和0.4个百分点。用电“晴雨表”折射工业经济发展放缓。1-7月全市工业用电量30.99亿元，增长34.4%，比1-6月回落3.7个百分点

（二）减、停产企业面持续扩大。7月末，规上工业停、减产企业减产面达26.2%，共拉低全市增幅10.6个百分点。停产企业66家，比6月份增加2家，影响全市规模工业增加值24.19亿元，拉低规模以上工业增加值增幅6.0个百分点。239家企业减产，占全市规模以上工业企业数的20.5%，累计减少工业增加值18.56亿元，拉低规模以上工业增加值增幅4.6个百分点。其中，产值减产超过千万的规上企业有103家，累计减少工业增加值16.84亿元，约占总减产量的90.7%。

（三）企业营业成本持续提高，二大产业利润不容乐观。1-6月，规模以上工业主营业务成本增长11.7%，高于主营业务收入增幅0.9个百分点，每百元主营业务收入中的成本88.30元，同比增长0.69元。1-6月，能源产业实现利润总额9.04亿元，同比下降31.0%；金属冶炼及压延加工业利润总额为-2.40亿元。

（四）部分产业增长放缓。1-7月，十大产业集群中，除木材浆纸、化工、纺织服装和工艺与创意产业增幅高于全市十大产业平均增幅，其他产业均低于平均增幅。其中，金属冶炼及压延加工业增加值下降13.1%，主要是钢材产能过剩，钢材价格长期处于低位，大部分钢材企业处于亏本经营，鞍钢冷轧大幅减产将导致该产业减产加大。制鞋产业增加值增长9.3%，增幅比上年同期回落5.1个百分点。能源产业增加值增幅较上年同期回落11.8个百分点，主要是LNG等龙头企业负增长、太平洋电力、福能、福煤风电等企业发电量下降影响。

（五）新投产工业企业少，投产企业规模小。7月末，全市当年新投产企业13家，仅占规上工业企业数1.1%。仅2家企业产值超亿元，其余11家新投产企业的规模不大，仅拉动全市工业经济增长0.5个百分点。

（六）受市场、设备检修等因素影响，部分中大型企业产能释放不足。赛得利（关闭两条生产线）、中锦新材料（设备检修，环比减产明显）、太平洋电力（设备检修）、佳通轮胎（“双反”影响，订单减少）、LNG（气价上涨，供气减少）和鞍钢冷轧（产能过剩，企业处于半停产）等企业当年产能释放不足，出现不同程度的减产。
