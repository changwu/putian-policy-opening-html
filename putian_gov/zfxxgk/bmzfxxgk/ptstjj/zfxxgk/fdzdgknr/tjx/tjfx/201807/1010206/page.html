2018年上半年莆田市固定资产投资情况简析

第三十三期
发布时间：2018-07-13 15:43
| | |

上半年我市固定资产投资同比增长16.7%,增速比上月提升1.3个百分点，位居全省第二位，比全省平均水平高3.3个百分点。其中项目投资同比增长23.4%，增速位居全省第二位，房地产开发投资同比下降6.1%，增速位居全省第八位。

一、运行情况

（一）投资结构有所调整。一是一产、三产比重提高，二产比重下降，产业结构有所优化：上半年，三次产业投资结构由上年的0.9：34.3：64.8调整为今年的1.2：31.8：67.0，第一产业投资比重上升0.3个百分点，第二产业下降2.5个百分点，第三产业提高2.2个百分点；二是科教文卫领域投资增长较快。上半年，全市科教文卫领域投资同比增长88.6%，增幅比去年同期提高30.9个百分点。其中，卫生和社会工作投资同比增长6.0%，教育投资同比增长89.0%，文化、体育和娱乐业投资增长357.8%。

（二）民间投资“三提高”。上半年全市民间投资同比增长45.8%，增速同比提高27.7个百分点，占固定资产投资的比重为67.4%，同比提高13.5个百分点，对固定资产投资的贡献率高达147.6%，比上年同期提高91.3个百分点，拉动固定资产投资增长24.6个百分点，民间投资增速、比重、贡献率“三提高”，是投资保持平稳较快增长的主要动力。

（三）交通运输、仓储和邮政业加速增长。上半年，为迎接世界佛教论坛的召开，我市加大交通运输业的投资力度，交通运输、仓储和邮政业同比增长20.7%，增速较上个月、一季度分别提升20.0、24.3个百分点。其中交通运输业同比增长21.3%，增速较上个月、一季度分别提升20.8、25.3个百分点。

（四）制造业投资快速增长。上半年，制造业投资同比增长33.8%，增速较上个月、一季度分别提升6.5、8.7个百分点，比固定资产投资增速高17.1个百分点，其中装备制造业投资同比增长33.1%,占全部工业投资比重27.3%，同比提高5.2个百分点，先进制造业投资同比增长33.0%。

（五）水利、环境和公共设施管理业高速增长。上半年全市水利、环境和公共设施管理业同比增长50.2%，增速同比提高33.7个百分点，占全市固定资产投资比重为18.7%，同比提高4.2个百分点，对全市固定资产投资的贡献率为43.6%，拉动全市固定资产投资增长7.3个百分点。其中，公共设施管理业同比增长42.8%，水利管理业同比增长69.8%，生态保护和环境治理业同比增长395.2%。

二、需关注问题

（一）大项目支撑不足且存量不足。

上半年5000万以上项目221个，同比减少56个，完成投资同比下降13.3%，且5000万以上项目自开始累计已完成投资占计划总投资比重今年以来一直在74%以上，1-6月份比重为76.0%，占比同比提高4.0个百分点，5000万以上项目投资存量不足，支撑乏力。

（二）重点领域投资增长乏力。

1、工业投资增速回落。上半年工业投资同比增长7.8%，增速虽然比上个月、一季度分别提升5.7、1.4个百分点，但是比上年同期回落17.9个百分点，特别是能源类投资中的电力、热力的生产和供应业同比下降54.3%，降幅比上年同期扩大49.9个百分点。

2、房地产业投资降幅扩大。上半年全市房地产业投资同比下降15.3%，降幅较上年同期扩大11.3个百分点，其中房地产开发投资同比下降6.1%，降幅较上年同期扩大3.3个百分点，房地产民间投资由上年同期的增长4.9%转为下降0.4%。

（三）资金到位情况不理想。上半年全市建设资金同比下降8.9%，项目建设资金同比下降7.8%，房地产开发投资资金同比下降10.1%。其中，国内贷款同比下降28.1%；国家预算资金同比下降46.8%；其他资金同比下降17.7%；自筹资金同比增长10.9%。
