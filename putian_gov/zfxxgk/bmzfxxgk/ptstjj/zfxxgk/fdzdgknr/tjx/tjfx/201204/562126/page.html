固定资产投资实现首季“开门红”

发布时间：2012-04-17 00:00
| | |

今年一季度，在市委市政府的统一布置和指导下，全市上下紧紧围绕“项目为纲，投资为要”，持续打好“五大战役”，项目建设快速有序推进，固定资产投资实现首季“开门红”。

一、投资运行的主要特点

（一）固定资产投资实现首季“开门红”。今年1－3月，全市共完成全社会投资205.23亿元，增长37.8%，增幅位居全省第二位，比1－2月提升0.8个百分点，比全省平均水平高10.6个百分点。其中固定资产投资（不含农户，下同）完成200.03亿元，增长38.4%，增幅位居全省第二位，比1－2月提升1.0个百分点，比全省平均水平高10.6个百分点。在固定资产投资中：项目完成投资156.60亿元，增长36.9%，增幅位居全省第一位，比全省平均水平高15.8个百分点；房地产开发投资43.43亿元，增长44.4%，增幅位居全省第七位，比全省平均水平低4.0个百分点。

（二）各县(区)投资形势喜人，区域增长协调性增强。从分县(区)看：今年第一季度我市全社会投资增速各县(区)保持全面增长态势，县(区)间的增速差异明显缩小，增长协调性有所增强，县区间的增速差距从去年同期的734.7个百分点缩小为今年的58.1个百分点。投资增幅比全市平均水平高的有3个（县）区，其中：荔城区因房地产开发投资的强劲拉动增速高达71.8%，增幅位居全市第一位，比全市平均水平快34.0个百分点，比排在第二位的仙游县快24.4个百分点；仙游县在宝泉工艺产业园等24个榜头镇工艺产业项目的有力拉动下增长了47.4%，增幅位居全市第二位；北岸经济开发区在差别化纤维等领港大项目的拉动下增长43.1%，增幅位居全市第三位。对全市全社会投资贡献率达到10%以上的有4个（县）区，分别为荔城区、仙游县、涵江区和北岸，对全市全社会投资的贡献率分别达到了33.5%、19.2%、18.1%和13.3%。

（三）三次产业投资全面增长，第三产业投资比重进一步提升。今年第一季度，我市三次产业投资呈现全面增长的态势，其中第一产业投资成倍增长，第二产业投资增速明显回落，第三产业投资比重进一步提升。1－3月，全市第一产业完成投资6.85亿元，增长1.7倍，增速同比加快86.3个百分点，增速比同期固定资产投资快131.7个百分点，比第二、第三产业投资增速分别快142.3个百分点和129.5个百分点；第二产业完成投资68.18亿元，增长28.1%，增速比上年同期回落39.1个百分点，比同期固定资产投资增速慢10.3个百分点；第三产业完成投资125.00亿元，在上年同期增长48.5%的基础上继续增长40.9%，占固定资产投资的比重为62.4%，比上年同期提升 1.1个百分点，对固定资产投资的贡献率达到65.3%。

（四）“民资回归”成效显著，民间投资主导地位突出。今年市委市政府继续实施“民资回归”工程，“民资回归”成效显著，民间投资在固定资产投资中继续保持着主导地位。在三大投资主体中，民间投资占固定资产投资的份额最大，增速最快，对固定资产投资的贡献率也最高，是拉动我市固定资产投资增长的主动力，成为我市投资的主角。1－3月，在我市固定资产投资中国有投资71.47亿元，增长14.6%，增速比上年同期放缓45.1个百分点；外资投资20.93亿元，增速由上年同期的增长2.4倍转为今年的下降13.8%；民间投资107.63亿元，增长86.1%，增速分别比同期国有、外资快71.5和99.9个百分点，占固定资产投资的比重为53.8%，对固定资产投资的贡献率达到89.6%，成为拉动投资增长的主动力，民间投资在固定资产投资中的主导地位突出。

（五）民生工程投资力度加大，社会事业投资成倍增长。今年来，在市委市府高度重视和坚强领导下，在各级各部门的积极支持和密切配合下，我市加大对民生工程的投资力度，社会事业投资成倍增长。1－3月，我市社会事业项目完成投资21.26亿元，增长1.1倍，增速比同期固定资产投资快76.2个百分点。其中：水利、环境和公共设施管理业完成投资10.15亿元，增长68.8%；教育事业完成投资4.63亿元，增长80.0%；卫生、社会保障和社会福利业完成投资1.5亿元，增长3.5倍；文化、体育和娱乐业完成投资2.99亿元，增长4.5倍；公共管理和社会组织完成投资1.99亿元，增长3.5倍。

（六）高新产业投资快速增长，高耗能产业投资明显减少，投资结构渐趋合理。今年我市高度重视培植高新产业，注重减少对高耗能产业的投资，高新产业投资呈现较快的增长态势，高耗能产业投资出现大幅下降，投资结构渐趋合理。1－3月，我市高新产业完成投资6.21亿元，增长57.5%，增幅同比加快11.1个百分点；高耗能产业完成投资16.04亿元，增速由上年同期的增长106.3%转为今年的下降18.6%，增幅同比回落124.9个百分点。

（七）房地产开发投资快速增长，商品房销售大幅下降，存量房大量增加。今年一季度，在正荣财富中心、莆田万达广场和莆田万科城I期等大项目的强劲拉动下，我市房地产开发投资呈现较快的增长态势，全市共完成投资43.43亿元，增长44.4%。其中建安工程完成投资25.12亿元，增长25.7%；其他费用完成投资18.19亿元，增长82.2%。在其他费用中土地购置费14.27亿元，增长1.2倍，占房地产开发总投资的比重为32.9%，对房地产开发总投资的贡献率达58.9%，土地购置费成倍增长主要是由于正荣财富中心和莆田万科城I期上缴大批土地购置费引起的。

受国家宏观调控政策的影响，今年一季度我市商品房销售呈现大幅下降，随着楼市的不景气，我市商品房待售面积大量增加。1－3月，全年商品房销售面积为30.85万平方米，下降24.8%；其中商品住宅销售面积为27.05万平方米，下降31.6%。至2012年3月底，我市共有商品房待售面积81.98万平方米，比2011年12月底增加36.72万平方米。其中商品住宅待售面积40.44万平方米，比2011年12月底增加21.35万平方米。

二、存在问题

今年一季度，我市投资运行态势良好，但投资运行中仍存在不容忽视的问题：

1、基础设施投资增长乏力，投资比重进一步回落。随着LNG接收站和燃气电厂等一批重大基础设施项目的陆续投产，又没有新的重大基础设施，今年一季度我市基础设施投资增长乏力，投资比重进一步回落。1－3月，我市基础设施建设完成投资45.34亿元，增长16.1%，增速比同期固定资产投资慢22.3个百分点，占同期固定资产投资的比重为22.7%，投资比重在上年同期回落9.0个百分点的基础上进一步回落4.3个百分点。其中：电力、燃气及水的生产业完成投资9.84亿元，在去年同期下降24.0%的基础上今年继续下降13.1%；交通运输、仓储及邮政业完成投资24.92亿元，增长14.8%，增幅同比回落47.8个百分点。

2、亿元项目支撑乏力。1－3月，我市项目投资中亿元项目完成81.00亿元，增长23.4%，增幅比同期项目投资慢13.5个百分点，增幅比上年同期回落65.1个百分点；亿元项目投资占项目总投资的比重为40.5%，比上年同期回落4.9个百分点。其中，亿元新开工项目完成投资6.83亿元，增长23.8%，增幅比同期项目投资慢13.1个百分点，增幅比上年同期回落742.1个百分点。

3、重工业、重化工和轻工业投资分别下降12.9%、1.7%和1.2%。1－3月，我市重工业项目完成投资23.70亿元，由上年同期的增长41.8%转为今年的下降12.9%；重化工业项目完成投资32.06亿元，由上年同期的增长72.5%转为今年的下降1.7%；轻工业项目完成投资25.72亿元，由上年同期的增长110.1%转为今年的下降1.2%。
