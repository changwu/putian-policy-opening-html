1-8月莆田市规模以上工业能源消费情况简析

发布时间：2023-09-28 17:05
| | |

1-8月，我市规模以上工业增加值同比增长2.0%，保持良好的发展态势。随着重点项目建成投产、重点耗能企业增产增效，我市规模以上工业能源消费快速增长，高耗能行业、高耗能企业比重持续扩大，能效水平有所下降。

一、规上能耗快速增长，能效水平有所下降

2023年1-8月，我市规模以上工业企业综合能源消费量为312.86万吨标准煤，同比增长16.9%，增幅分别比一季度、上半年提高21.2个、4.5个百分点，趋势持续走高。从能效水平看，1-8月全市规模以上工业单位增加值能耗同比增长13.8%，增幅分别比一季度、上半年提高6.1个、3.6个百分点，节能形势更加严峻。

二、重点项目建成投产，主要行业能耗增长

1-8月，我市规模以上工业六大高耗能行业综合能源消费量为260.78万吨标准煤，同比增长22.0%，占规模以上工业综合能源消费量的比重为83.4%。

其中，电力、热力生产和供应业综合仍是规模以上工业最主要能源消费行业，1-8月综合能源消费量合计183.72万吨标准煤，同比增长11.3%，占规模以上工业综合能源消费量比重为58.7%；化学原料和化学制品制造业综合能源消费量快速增长，1-8月综合能源消费量合计61.38万吨标准煤，同比增长82.7%，占规模以上工业综合能源消费量的比重由去年的14.2%扩大至16.2%，主要增长的原因在于永荣二期煤制氢项目的正式投产带来大规模的能源消耗。

三、万吨项目能耗量大，能源消费相对集中

1-8月我市规模以上工业企业中综合能源消费量超万吨标准煤的有18家，合计综合能源消费量286.51万吨标准煤，占规模以上工业综合能源消费量的91.6%。其中，综合能源消费量超十万吨标准煤的企业有4家，合计综合能源消费量242.95万吨标准煤，占规模以上工业综合能源消费量的77.7%。

分企业看，上述18家企业中1-8月综合能源消费量同比增长的有9家，其中永荣科技因二期项目正式投产综合能源消费量同比增长93.0%，赛隆科技因新工艺投入使用综合能源消费量同比增长37.8%；同比下降的有9家，其中抽水蓄能、燃气电厂受省电网调控减少发电，综合能源消费量分别同比下降32.2%、16.3%。

四、原煤消费大幅增长，生物质燃料比重扩大

1-8月，我市规模以上工业原煤消费量为577.43万吨，同比增长21.9%，其中作为原材料消费12.14万吨。原煤消费主要集中在电力、热力生产和供应业，1-8月该行业原煤消费量同比增长17.5%，占全市规模以上工业原煤消费量比重为80.5%。此外化学原料和化学制品制造业因永荣科技二期项目投产，原煤消费量快速增长，1-8月增加原煤消费34.46万吨，同比增速达83.1%。

1-8月，我市规模以上工业生物质燃料消费量为2.26万吨标准煤，同比增长75.7%，占规模以上工业综合能源消费量比重由去年同期的0.3%提高至0.7%，鑫祥新材料、鑫林新材料等20家企业选择消费生物质燃料替代原煤作为燃料，能源消费结构持续优化。

五、行业分布各有特色，区域能耗差异较大

受行业分布特色影响，我市各县（区、管委会）规模以上工业能源消费结构差异较大。1-8月，各县（区、管委会）六大高耗能行业综合能源消费量占规模以上工业综合能源消费量比重分别为：城厢区5.0%、涵江区37.6%、荔城区3.6%、秀屿区89.8%、仙游县51.7%、北岸90.4%。

从能效水平看，1-8月各县（区、管委会）规模以上工业综合能源消费量同比下降的有3个，分别为：城厢区-21.8%、仙游县-9.8%、涵江区-3.9%；同比增长的有3个，分别为：秀屿区29.1%、北岸18.7%、荔城区7.0%。其中秀屿区出现快速增长的主要原因在于永荣科技二期的投产。
