农业生产形势较好 粮食果蔬喜获丰收—1-3季度莆田市农业经济简析

第六十二期
发布时间：2020-10-21 17:27
| | |

今年以来，我市气候条件良好，有利于农业生产。同时，我市各级各部门认真做好“六稳”工作、落实“六保”任务，坚持疫情防控和农业生产两手抓，稳定农业基本盘，农林牧渔业生产形势较好，粮食果蔬喜获丰收。

一、主要运行特点

（一）农业生产形势较好，农林牧渔业总产值稳步增长

1-3季度,莆田市农林牧渔业总产值160.07亿元，可比增长2.9%，增幅比上半年持平。其中：农业产值36.13亿元，增长5.4%；林业产值1.24亿元，下降1.3%；牧业产值29.00亿元，下降2.7%；渔业产值78.67亿元，增长3.0%；农林牧渔服务业产值15.04亿元，增长4.8%。

（二）补助政策成效显著，夏粮保持稳中有升

我市全面贯彻落实国家、省委省政府粮食生产决策部署，出台粮食生产补助政策，鼓励引导种植户扩大粮食种植规模，提高粮食产能。在春粮扩种增产的基础上，夏粮播种面积和产量继续保持稳中有升。2020年全市夏收粮食播种面积为15.85万亩，增长2.6%，其中谷物和豆类分别增长2.4%、3.8% ，薯类下降1.8%；夏收粮食产量为6.36万吨，增长2.7%，其中谷物和豆类分别增长2.6%、4.5% ，薯类下降5.6%。

（三）果蔬生产情势良好，产量稳步增加

今年前三季度我市气候条件良好，没有出现往年的倒春寒，虫害少，有利于果蔬生产，产量增加明显。1-3季度，全市园林水果产量为11.22万吨，比上年同期增加0.64万吨，增长6.1%。其中枇杷产量为6.58万吨，比上年同期增加0.55万吨，增长9.1%，对园林水果的贡献率高达85.2%。全市蔬菜播种面积为23.53万亩，播种面积比上年同期扩大0.84万亩，增长3.7%；产量达43.59万吨，比上年同期增加2.02万吨，增长4.8%。

（四）生猪生产逐步恢复，当季出栏由负转正

随着支持生猪养殖政策的落地和生猪价格的一路攀升，生猪产能先行指标存栏数今年一季度首次出现增长，本季出栏数由上半年的大幅下降转为增长，生猪生产呈逐步恢复态势。至9月底，全市生猪存栏23.11万头，增长68.8%，增幅比6月底提高42.5个百分点；1-3季度全市生猪出栏35.62万头，下降21.2%，降幅比上半年收窄9.4个百分点。其中第3季度本季全市生猪出栏10.08万头，增长19.9%，比第一、二季度本季分别提高57.2个和44.4个百分点。

（五）水产品产量增幅逐季回升，对一产支撑有力

1-3季度，全市水产品总产量79.57万吨，增长3.1%，增幅分别比上半年和一季度提高0.1个和0.9个百分点。其中海水产品产量77.27万吨，增长3.2%；内陆水域水产品产量2.30万吨，下降0.8%。1-3季度渔业产值为78.67亿元，占一产产值的比重为54.2%。

二、存在的主要问题

（一）生猪产能恢复遇到瓶颈

我市流域面积大，饮用水源多，高速公路和高铁覆盖范围广，导致我市生猪养殖可养范围较小，养殖用地相对紧缺，一些养殖场受资金、用地要素制约，增加产能方面遇到制约瓶颈。

（二）食用菌生产规模不断萎缩

1-3季度，全市食用菌生产用地为0.48万亩，在上年和前年同期分别下降16.0%和27.8%的基础上今年继续下降2.8%；食用菌产量为3.30万吨，在上年和前年同期分别下降4.9%和36.5%的基础上今年继续下降0.4%。其中，蘑菇产量3.04万吨，在上年和前年同期分别下降4.6%和37.3%的基础上今年继续下降0.3%。

三、下一步建议

（一）加强秋粮生产田间管理。加强秋粮作物病虫害统防统治等田间管理，提高秋粮单产，确保秋粮丰产丰收，确保2020年我市粮食生产目标顺利完成。

（二）大力发展畜牧业规模化养殖和循环养殖。要加大招商引资力度，引进国内外先进养殖模式的畜牧业企业，如丹麦皇冠等国际知名生猪养殖屠宰加工一体化企业，带动我市畜牧业向规模化养殖和循环养殖发展，提升行业整体竞争力。

（三）推动食用菌智能化生产。出台政策鼓励我市现有食用菌工厂化生产企业扩大生产规模，扶持培育食用菌龙头企业，积极引导我市食用菌从分散式的传统生产模式向 “企业+农户”模式和集约化、工厂化、专业化、精细化、产销一体化的现代企业经营模式转变，推动食用菌全产链发展，实现食用菌量增价升。
