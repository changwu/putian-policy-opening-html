上半年莆田市规模以上工业运行分析

发布时间：2009-07-29 00:00
| | |

今年以来面对金融危机对我市工业等实体经济的冲击，莆田市坚持以科学发展观统领经济社会发展全局，积极落实中央一系列扩内需、保增长的扩张政策措施，紧紧围绕“以港兴市、工业强市”战略，科学决策，有效运作，努力攻坚克难，化危为机，保增长、保民生、保稳定取得初步成效，全市工业经济实现平稳较快发展。上半年全市实现规模以上工业总产值468.85亿元，可比增长15.6%，增幅虽同比下滑11.6个百分点，但仍居全省第二位。工业对经济增长的贡献率达49.0%，拉动经济增长5.9个百分点。

一、工业经济运行主要特点

（一）工业继续保持两位数增长。面对金融危机对工业的冲击，莆田市委、市政府制定出台了加快工业发展、积极扩大内需等一系列政策措施，并有效运作实施，取得了一定的成效。全市工业总产值增长速度虽然比上年同期下滑，但始终保持两位数增长，并居全省前三位。1-5月份工业总产值增长速度居全省九设区市第一位，1-6月份工业总产值增速居全省第二位，工业总产值总量居全省第五名（上半年莆田市工业总产值各月累计增幅见下图）。

（二）工业运行质量逐步向好，上缴税金较快增长。上半年规模以上工业经济效益综合指数为208.50%，比上年同期上升5.39个百分点，比1-5月份高3.6个百分点；上缴税金9.80亿元，比上年同期增长22.7%。从行业看，上缴税金总额列全市前五位的分别是饮料制造业（2.25亿元），皮革、毛皮、羽毛(绒)及其制品业（1.75亿元），纺织服装、鞋、帽制造业（0.63亿元），橡胶制品业（0.59亿元），工艺品及其他制造业（0.52亿元）。

（三）新投产企业、民营工业拉动明显。去年6月份后新投产的88家企业实现工业总产值30.80亿元，对规模以上工业经济增长的贡献率达49.4%，拉动规模以上工业经济增长7.6个百分点，其中今年上半年新投产企业38家，实现工业总产值7.16亿元，拉动规模以上工业经济增长1.8个百分点。

面对国际金融危机民营经济继续保持较快发展。上半年907家民营企业实现工业总产值351.35亿元，增长17.9%，增幅比全市平均水平高2.6个百分点，拉动规模以上工业经济增长13.1个百分点。

（四）小型企业活力显现，发展后劲继续增强。小型工业企业应对国际金融危机充分显现出“船小好调头”的经营灵活性，上半年工业生产呈现出快速增长的好势头，完成工业总产值290.96亿元，比上年同期增长23.4%，增幅分别比规模以上工业、大中型企业高8.1、19.3个百分点,拉动规模以上工业经济增长13.6个百分点。

（五）工业走势出现积极变化。

1、企业生产信心增强，停产或半停产的企业相继开工生产。根据我市二季度景气调查结果，第二季度我市企业景气指数和企业家信心指数分别比上季度提高19.0和16.4点，企业的信心进一步增强，部分企业也恢复生产，1-6月，规模以上工业停产企业共64家，分别比1-4月、1-5月减少了30家和16家。

2、利润总额首次出现正增长。上半年我市规模以上工业企业实现利润总额11.60亿元，比上年同期增长2.1%，一举扭转了从去年9月份以来利润负增长的局面。利润总额降幅从今年一季度开始逐月收窄，至6月份已扭转持续下降局面（见下图）。

3、化工产业产值降幅收窄。国家宏观政策产业振兴规划，涉及我市的化工等行业，这为我市十大主导产业加快发展提供了新的机遇。上半年在佳通轮胎产能逐步恢复带动下，化工产业实现工业总产值37.70亿元，比上年同期下降0.6%，降幅逐月收窄，分别比1-5月份、1-4月份、1-3月份分别缩小5.1、3.7、7.5 个百分点，出现企稳回升的势头。

二、工业经济运行中存在的问题

（一）“三资”工业企业增幅出现下降。作为外向度高的“三资”工业企业在各经济类型中受金融危机影响最大，上半年“三资”工业企业实现工业总产值204.12亿元，下降0.7%，增幅呈逐月下降趋势（具体情况见下表）。

（二）出口仍然受阻。上半年，全市规模以上工业品出口交货值为100.25亿元，同比下降7.0%，降幅比一季度继续扩大5.6个百分点，23个出口行业中有15个同比下降。佳通轮胎、协丰鞋业、大吉利鞋业等企业的出口均出现不同程度的下滑。外需的持续低迷制约着我市外向型企业的快速发展。

（三）大中型企业拉力趋弱。上半年，全市规模以上大中型工业企业完成总产值177.89亿元，仅增长4.1%，增幅虽比一季度提高3.4个百分点，但比全市规模以上工业平均增速低11.2个百分点。大中型工业企业对全市规模以上工业增速的拉动作用仅为1.7个百分点，影响带动作用相对偏弱。

（四）融资“瓶颈”制约，贷款难担保难问题仍然比较突出。上半年在信贷规模大幅增加的情况下，中小企业授信额度总体偏小，仍普遍反映贷款困难。有关部门在加大财税、信贷支持力度、创新对中小企业金融服务、拓宽中小企业直接融资渠道等方面做了大量工作，但中小企业融资难的问题未得到根本性的解决。

三、几点建议

工业是立市之本、强市之基，在我市经济发展中占有举足轻重的位置。保持我市经济平稳较快发展的关键是保工业增长。为了促进我市工业企业健康稳定发展，建议抓好以下几项工作：

（一）抓住机遇，大力发展先进制造业。5月14日，国务院《关于支持福建省加快建设海峡西岸经济区的若干意见》正式颁布，出台一系列政策明确"支持福建省加快海峡西岸经济区建设"。我市要紧紧抓住这个难得的历史性机遇，增强信心，迎难而上，用好"海西"平台，大力发展光电、生物医药、新材料、新能源等先进制造业，重点支持高科技、高效益、高成长的骨干型企业，不断增强工业竞争力和发展后劲。

（二）加强经济运行的预警监测。深入了解、全面掌握全市工业企业经济结构、布局和发展潜力，对当前金融危机给工业企业造成的不利影响从结构上进行调查分析，全面准确掌握企业生产经营情况，对影响较大的企业和新增长点企业都做到心中有数，积极为企业解决生产经营中存在的困难和问题寻找出路，积极为企业发展献计献策，促进企业正常生产。要掌握新增长点的投产、达产时间表，做到协调有方、计划有据。

（三）继续帮助企业大力开拓国内外市场。针对国外特别是欧美订单减少的情况，要进一步完善、落实鼓励出口的政策措施，稳住欧美市场，鼓励企业积极开拓东南亚、中东、拉非美洲等新兴市场，稳住外贸出口态势。同时，要鼓励和引导企业积极调整营销思路，帮助企业努力开拓国内市场，力保过剩产能的有效释放，最大限度地减少金融危机对企业的影响程度。

（四）积极培植经济发展后劲。继续做好重点企业和快速增长型企业扶持工作，促进增产增效，稳定我市工业发展基础。着力培育和发展一批市场竞争力强的骨干企业，大力发展高新技术企业，加大新产品开发力度，加强重点项目建设力度，确保重点项目按期投产达效，形成一批新的经济增长点，拉动工业经济增长。积极实施名牌战略，着力提升企业核心竞争力，提高企业抵御风险能力。加强招商引资工作，坚持国有、外资、民资项目齐头并进，促进更多的项目特别是大项目在我市落地。

（五）加大对中小企业的政策扶持力度。我市工业企业绝大多数是中小企业。中小企业在扩大就业、吸纳社会富余劳动力、保持社会稳定、促进经济增长等方面具有重要作用。要认真落实扶持中小企业发展的政策措施，从财税支持、金融服务、技术创新、产业调整、市场开拓、品牌建设、人才引进培养、企业减负、用工用地、优化环境等方面，给予积极扶持，切实帮助中小企业解决经营发展中的问题，为中小企业创造良好的外部环境，促进我市经济又好又快发展。
