2020年莆田市固定资产投资情况分析

第三期
发布时间：2021-01-15 17:41
| | |

2020年全市固定资产投资同比下降2.3%，降幅比1-11月份、上季度均收窄1.7个百分点。其中，项目投资同比下降1.5%，降幅比1-11月份、上季度分别收窄1.3、0.2个百分点，房地产开发投资同比下降5.3%，降幅比1-11月份、上季度分别收窄2.7、6.6个百分点。

一、运行特点

（一）投资结构持续优化。一是技术型投资提升，高端制造业投资高速增长。2020年全市工业改建和技术改造投资增长24.4%，高技术制造业投资同比增长56.4%；装备制造业同比增长32.6%，比上年同期提升6.9个百分点；先进制造业同比增长25.2%，均高于同期制造业投资增幅。二是社会领域投资稳定增长。2020年全市社会领域投资同比增长17.7%，增幅比上年同期提高16.4个百分点，其中教育业投资同比增长10.4%，卫生和社会工作投资同比增长13.0%，文化、体育和娱乐业投资同比增长29.7%。

（二）在建亿元项目快速增长。2020年我市投资主要靠大项目拉动，全市亿元以上项目352个，比上年同期多71个，计划总投资和本年完成投资同比分别增长43.4%、18.1%，其中亿元新开工项目173个，比上年同期多26个，计划总投资同比增长51.2%。

（三）工业投资平稳增长。2020年全市工业投资同比增长8.1%，比全部固投速度快10.4个百分点，比全省平均水平高7.4个百分点，拉动固投增长2.3个百分点。其中，采矿业同比增长72.2%，制造业投资同比增长2.6%，电力、热力、燃气及水的生产和供应业同比增长52.1%。

（四）资金到位情况较好。2020年全市本年到位资金同比增长10.5%，比固投速度高12.8个百分点，从资金来源看，主要依靠项目业主自筹，自筹资金比重为68.4%，自筹资金增长6.9%；国家预算资金增长266.5%；其他资金来源增长19.6%；贷款融资渠道有所收窄，国内贷款下降4.0%。

二、存在问题

（一）投资处于较低水平。2020年我市投资降幅虽然较1-11月份收窄1.7个百分点，与全省平均水平相差较大，速度比全省平均水平低1.9个百分点，位居全省第七位，特别是房地产开发投资同比下降5.3%，是全省三家负增长设区市之一，比全省平均水平低11.5个百分点。

（二）基础设施投资亟待加强。2020年全市基础设施投资延续去年以来的下降趋势，全年负增长，同比下降4.8%。其中交通运输业投资同比下降26.4%，降幅比上年同期扩大0.9个百分点；水利、环境和公共设施管理业由上年同期的同比增长3.7%转为下降3.4%。

（三）民间投资下滑明显。2020年全市民间投资也是全年负增长，速度由上年同期的增长5.5%转为下降12.3%，速度比全省平均水平低13.3个百分点，占固定资产投资比重为56.4%，比上年同期低6.4个百分点。

三、建议

（一）重储备。要落实省里“八项行动”要求，突出开发招商、强化项目带动，完善并深化强产业兴城市“三看两评”及“五个一批”考评机制，谋划实施一批重点项目，提高项目储备数量和质量；同时加强行业主管部门协调力度，强化责任要求，为项目建设提供各类要素保障。

（二）明目标。贯彻落实市委提出的持续围绕“双轮”驱动，立足重点工作、重点任务，集中资源、要素、力量、政策，一个节点、一个节点的推进投资项目进度。

（三）补短板。针对重点领域投资全年负增长情况，围绕重点投资领域，特别是新型基础设施建设、老旧小区改造、重点片区改造等方面，补齐短板投资。

（三）促活力。优化投资环境，吸引社会资本，激发民间投资活力，鼓励民间资本参与项目建设，引导社会力量对民生等领域进行投入。支持民营企业积极参与交通、能源、市政、生态环保、社会事业等补短板重大项目建设。
