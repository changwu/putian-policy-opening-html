1-5月莆田GDP简析及上半年GDP预计

发布时间：2013-06-24 00:00
| | |

初步核算，1-5月全市完成生产总值472.12亿元，按可比价格计算，比上年同期增长12.6%，快于全省平均水平1.1个百分点，高于上年同期0.4个百分点，增幅位居全省设区市第二位。其中，第一产业增加值40.69亿元，比上年同期增长2.5%，增幅比上年同期提高0.5个百分点；第二产业增加值315.13亿元，增长14.0%，增幅比上年同期下降1.6个百分点；第三产业增加值116.30亿元，增长12.6%，增幅比上年同期提高4.9个百分点。

一、从三次产业贡献率看

第一产业贡献率为1.7％，比上年同期提高0.1个百分点，与1-4持平；第二产业贡献率为72.9％，比上年同期下降8.8个百分点，比1-4月下降1.1个百分点；第三产业贡献率为25.4％，比上年同期提高8.7个百分点，比1-4月提高1.1个百分点。

二、从三次产业拉动情况看

第一产业拉动GDP增长0.2个百分点，与上年同期、1-4月持平。第二产业拉动GDP增长9.2个百分点，比上年同期下降0.8个百分点，比1-4月下降0.2个百分点。第三产业拉动GDP增长3.2个百分点，分别比上年同期、1-4月，提高1.2个百分点、0.1个百分点。

三、工业增加值增速放缓，但仍是“稳增长”的主要力量

全部工业增加值完成284.38亿元，同比增长12.8%，增幅比上年同期下降1.9个百分点，比1-4月下降0.3个百分点。对经济增长的贡献率为61.1％，比上年同期下降10.0个百分点，比1-4月下降2.0个百分点。拉动GDP增长7.7个百分点，比上年同期下降1.0个百分点，比1-4月下降0.3个百分点。

四、第三产业增长位居全省首位

1-5月份全市实现第三产业增加值116.30亿元，增长12.6%，增幅高于上年同期4.9个百分点，高于1-4月份0.6个百分点，第三产业对经济增长的贡献率为25.4%，拉动经济增长3.2个百分点。第三产业总量居全省第7位，增幅位居全省第一位。

分行业看，交通运输仓储和邮政业实现增加值15.69亿元，增长6.4%，增幅低于全省平均水平1.2个百分点；批发和零售业实现增加值27.87亿元，增长14.4%，增幅高于全省平均水平4.8个百分点；住宿和餐饮业实现增加值6.29亿元，增长2.2%，增幅低于全省平均水平2.3个百分点；金融业实现增加值21.52亿元，增长16.8%，增幅高于全省平均水平2.3个百分点；房地产业实现增加值15.29亿元，增长18.3%，增幅高于全省平均水平0.8个百分点；营利性服务业实现增加值15.20亿元，增长17.2%，增幅高于全省平均水平6.5个百分点；非营利性服务业实现增加值14.44亿元，增长5.8%，增幅低于全省平均水平0.8个百分点。
