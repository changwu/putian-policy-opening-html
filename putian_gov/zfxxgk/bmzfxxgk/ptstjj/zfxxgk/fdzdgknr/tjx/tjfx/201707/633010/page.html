从二季度景气调查情况看莆田工业形势

发布时间：2017-07-17 00:00
| | |

2017年二季度，企业家信心指数和工业企业景气指数分别为126.22和125.46，比一季度分别下降2.12个和3.24个点，但均比去年同期增加12个点，仍处于较为景气区间之内。整体来看，企业产能利用稳步推进、盈利增加、订单回暖，企业家对下期经济运行持较为乐观态度。但用工成本上升、资金紧张等影响企业发展的因素依然存在。

一、基本情况

（一）产能利用率明显回升。二季度被调查企业主要产品生产能力利用率为79%，比上季度提高1个百分点，比去年同期提高2个百分点。其中酒、饮料和精制茶制造业产能利用率为80%,比上季度提高20个百分点。被调查企业中，产能发挥程度高于正常水平的企业占7.4%，较上季度下降1.3个百分点；产能发挥处于正常水平的企业占81.7%，较上季度提高3.9个百分点；产能发挥低于正常水平的企业占10.9%，下降2.7个百分点。

（二）企业盈利状况正常。调查结果显示，盈利增加或持平的企业占87.5%，比上季度高7.6个百分点。其中，17.7%的企业认为盈利状况比上季度增加；69.8%的企业认为盈利状况与上季度持平；12.5%的企业认为盈利状况比上季度低。

（三）产品订单稳步增长。从企业订货情况看，市场需求有所回暖，认为订货量“正常”的企业家占82.8%，“高于正常”的占6.0%，两者合计比重比上季度上升1.8个百分点，比去年同期提高6.3个百分点。分行业看， 皮革、毛皮、羽毛及其制品和制鞋业产品订货量高于及处于正常水平的企业占87.7%，分别比上季度和去年同期提高2.1和5.3个百分点；化学原料和化学制品制造业、化学纤维制造业、酒、饮料和精制茶制造业等18个行业订货形势较好，订货量高于及处于正常水平的企业占90%以上。

（四）优惠政策惠及面扩大。近年来，为应对经济下行压力，中央、省委省政府和市委市政府出台了一系列稳增长、调结构、降成本等惠企政策措施。调查结果显示，二季度有31.1%的企业受到过相关政策的帮助和支持，与上季度和去年同期相比，享受优惠政策的企业比例分别提高0.7和4.1个百分点，政策惠及面进一步扩大。其中，受益创新支持、减税降费、简政放权政策的企业比例列前三位，分别为46.5%、39.5%和29.8%。分行业看，纺织业、化学纤维制造业、汽车制造业、电气机械和器材制造业等行业受惠企业比例在50%以上。分规模看，大型企业受惠最多，有53.1%的大型企业受到过相关政策的帮助和支持，分别比中、小、微型企业高21.7个、27.9个和13.1个百分点。

二、存在问题

（一）用工成本上升成为企业发展面临的首要困难。关于“本季度企业经营中的主要问题”，企业家选择比重最高的六项依次是：用工成本上升（占46.6%）、资金紧张（占30.8%）、招工难（占20.7%）、产品价格过低（占19.1%）、产品需求不足（占19.1%）、税费负担过重（占14.2%）。用工成本上升成为困扰企业生产经营的首要问题。在产品销售价格基本维持不变的情况下，用工成本上涨对企业效益构成较大压力。面对不断上涨的劳动力成本，目前已有6.8%企业通过“机器换人”减少用工。

（二）需求不足影响生产能力正常发挥。调查显示，企业产能未能充分发挥的首要原因是“产品需求减少、订单不足”，占 45.8%，比上季度和去年同期分别高6.2个和14.7个百分点，呈现上升的趋势。当前，工业经济未能摆脱下行压力，市场需求仍显不足，工业品出厂价格指数虽有所反弹，但部分重点产品的市场价格仍处于低位，19.1%的企业家认为产品需求不足是本季度生产经营的主要问题。

（三）企业依然面临资金压力。二季度，仍有23.7%的企业认为流动资金周转紧张，比上季度和去年同期分别高0.4个和7.7个百分点，呈现上升的趋势。有22.3%的企业认为生产能力未能充分发挥的主要原因是“资金紧张”。81.7%的企业没有投资，而其中有28.3%的企业认为主要原因是“资金不足”。与此同时，30.8%的企业认为“资金紧张”是本季度生产经营的主要问题，居第二位。造成本季度资金紧张的主要原因，占59.8%的企业认为是货款回笼慢；占37.9%的企业认为是融资难；占31.0%的企业认为是融资成本高；占28.7%的企业认为是存货资金占用较多；占27.6%的企业认为是工资等刚性支出较多。

（四）企业依然认为税费负担过重。二季度，有12.3%的企业认为税费负担加重，比上季度和去年同期分别高2.8个和3.5个百分点，呈现上升的趋势。14.2%的企业家认为税费负担较重是本季度生产经营的主要问题。

三、分析和预期

根据企业对下季度企业综合经营状况的合理预期，有30.5%的企业持“良好”态度，比上季度降低2.6个百分点，但比去年同期增加4.9个百分点；持“不佳”态度的企业占比由上季度的4.6个百分点上升到6.0个百分点，但比去年同期下降5.1个百分点。对下季度本企业经营状况的合理预期，持“良好”和“一般”态度的占94%，比上季度降低1.4个百分点，但比去年同期增加5.1个百分点。对下季度本行业运行状况的预期方面，占94.6%企业持“乐观”和“一般”态度，比上季度降低0.5个百分点，但比去年同期增加5.1个百分点。综上所述， 全市经济下行压力仍然较大，但经济形势有所好转，大部分企业家对后期生产经营的态度较为乐观，预计下季度莆田工业经济将继续保持平稳发展态势。
