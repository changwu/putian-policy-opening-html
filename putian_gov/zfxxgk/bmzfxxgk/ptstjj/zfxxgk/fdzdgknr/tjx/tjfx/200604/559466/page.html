加快经济发展 破解就业难题

发布时间：2006-04-13 00:00
| | |

经济增长是推进就业增加的根本动力。2006年伴随经济总量持续扩张、经济结构明显改善和市场化进程加快，我市就业渠道不断拓宽，就业结构日趋优化，资源的配置效率得以提升。但就业压力日渐增大仍是不容忽视的事实，因此在未来的五年里就业如何与经济社会发展相适应是一个亟待解决的难题，需要全社会的共同关注。

一、基本情况

（一）城镇单位就业规模不断扩大

今年年末全市城镇从业人员为27.97万人，较上年同期增加了2.85万人，上升11.33%，其中在岗职工为27.50万人，增加2.80万人，增长11.32%。

分经济类型看：国有单位从业人数显著增加，到2005年底我市国有城镇单位共有从业人员102005人，增加12152人，增长13.52%，主要为国有建筑行业为一些房地产项目赶工而招收了大量临时性用工；集体单位从业人数有所下降，从上年的15603人下降到今年的11735人，共减少3868人，下降了24.79%，主要由于建筑业、鞋业企业人员向其他所有制单位流动而减少；其他经济类型单位从业人员继续保持旺盛的增长势头，全市共有其他所有制单位人数165928人，比上年增加20177人，增长13.84%，主要原因是鞋服企业、建筑业及部分电子企业大量招收工人，（其中内资企业45653人，增加7461人；港澳台企业75558人，增加6549人；外商投资企业44717人，增加 6167人）。

（二）在岗职工工资总额保持较快增长

由于经济平稳发展，从业人员增加，企业效益不断提高以及机关、事业工资的正常晋级，我市在岗职工工资总额呈现稳步增长态势。全年累计发放从业人员劳动报酬36.68亿元，比上年的31.42亿元增加了5.26亿元，增长16.75%，其中在岗职工工资总额35.78亿元，比上年增加了5.18亿元，增长16.95%。

分经济类型看：一是国有单位工资总额继续保持快速增长。据统计，2005年底国有单位累计发放职工工资15.02亿元，与去年同期相比增长10.51%；二是城镇集体单位职工工资总额因人员减少的缘故而显著下降，共发放1.41亿元，比上年减少0.25亿元，下降了14.79%；三是其他各种类型单位职工工资总额迅速增长，其他单位工资总额为19.35亿元，同比增长26.08%。其中内资工资总额为5.35亿元，比上年增1.38亿元，增长34.73%；港澳台投资企业工资总额为8.39亿元，比上年增1.29亿元，增长18.17%；外商投资企业工资总额为5.61亿元，比上年增1.33亿元，增长31.16%

（三）在岗职工平均工资增长平稳

2005年全市从业人员平均报酬为13635元，在岗职工平均工资为13513元，平均工资增长6.8%。

1、分企业、事业、机关看：2005年我市企业、事业、机关职工平均工资水平增长较平衡，分别增长了5至8个百分点。其中：机关职工平均工资为15126元，比增6.70%；企业职工平均工资为12759元，比增8.18%；事业单位职工平均工资为14677元，比增5.66%。

2、分经济类型看：一是国有单位在岗职工平均工资保持了平稳的增长，人均年工资为16355元，比增5.92%；二是城镇集体单位由于今年底改制企业增加，领取一次性津贴人数较多，从而获得了平均工资增长水平的再度回升，截至2005年底，集体单位职工平均工资为12144元，比增10.93%；三是其他所有制单位职工工资增长速度仍然较快，为11071元，比增8.35%。近年来的“民工荒”问题尚存，以密集型劳动粗放型增长的企业要保持稳定的生产，必须想方设法留住工人，特别是有技术有能力的骨干，因此，提高工资待遇就成为最直接有效的办法。

3、分行业看：2005年我市城镇单位各行业在岗职工年平均工资均突破万元大关，超过两万元的行业有电力、燃气及水的生产和供应业、信息传输、计算机服务和软件业及金融业。其中信息传输、计算机服务和软件业职工平均工资达到48969元，为各行业之首；电力、煤气及水的生产和供应业为27550元，居第二；金融业26674元位居第三。而全市排后三位的是农林牧渔业10052元/人，住宿餐饮业11175元/人、建筑业11568元/人。平均工资最高行业与最低行业的差比为4.87：1，高于去年同期水平。

（四）离岗职工人数略有下降，平均生活费水平有所提高

离开本单位仍保留劳动关系的职工年平均生活费为2037元，较去年上升了4.3%，与整体工资增长水平基本保持一致。而离岗保留劳动关系职工人数也从去年的7697人减少到今年的7269人，下降5.56%，主要为离岗职工到龄退休或停薪留职人员辞去公职。

二、几点建议

2005年我市就业状况总体实现良性运作，为“十五”画上了一个圆满的句号。为了在“十一五”期间再接再厉，逐步建立完善合理的就业结构，加快实现就业与经济的协调健康发展，我市应从以下几方面着手：

1、实现经济政策和劳动力市场政策的整合，提高经济增长的就业含量。扩大就业的最根本途径当然还是依赖于经济增长。要使经济增长中就业的含量不断增加，就应在大力发展高新技术产业和资金密集型产业的同时兼顾发展劳动密集型产业。要大力发展非国有经济和民营经济，鼓励创造各种各样的就业形式。

2、大力培育和发展优势服务业和特色服务业。当前，旅游业已成为世界经济中发展势头最为强劲的朝阳产业，全国各地都把旅游业作为经济发展的重点。大力发展旅游业，对于带动第三产业的发展，改善资源环境，加快对外开放步伐，优化财源建设，配置新型财源，加速财政建设，提高职工工资水平，促进财政振兴，具有十分重要的意义。要充分发挥我市作为妈祖故乡的旅游资源优势，加大旅游业的宣传和促销力度，努力拓展旅游市场，提高旅游资源综合开发水平，促进我市旅游事业的快速发展。

3、大力开发人力资源，消除劳动力市场的分割。劳动力市场的第一重分割是城乡分割；第二重分割是人才市场和劳动力市场的分割。这一分割通过把人分成不同身份而拒其于特定的市场之外。消除劳动力市场的多重分割，才能整合出一个能更加有效地配置劳动力资源统一的市场。同时，应建立以劳动力市场需求为导向的教育和培训体制。目前就业难并不完全是总量过剩的问题，而是一个结构性的问题。教育体制也应该适应不断变化的市场需求，不同类型的高校应有不同的定位。

（撰稿：曾莉莎）
