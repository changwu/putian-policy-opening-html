2017年莆田市农林牧渔业生产情况简析

第一期
发布时间：2018-01-25 10:52
| | |

2017年，全市上下认真贯彻中央、全省农村工作会议精神，紧紧围绕推进农业供给侧结构性改革工作主线，以农业增效、农民增收、农村增绿为目标，以加强科技创新、深化农村改革为动力，着力推进农业结构调整，促进农村一二三产业融合发展，保持了我市农业农村经济运行健康稳定发展的良好态势。

一、主要运行特点

（一）农林牧渔业总产值保持稳步增长

2017年，全市实现农林牧渔业总产值236.16亿元，可比增长2.6%，增加值139.82亿元，可比增长2.4%。其中：农业产值84.26亿元，可比增长3.7%，增加值51.54亿元，可比增长3.7%；林业产值4.87亿元，可比增长2.4%，增加值2.70亿元，可比增长1.0%；牧业产值34.99亿元，可比下降3.0%，增加值18.38亿元，可比下降6.2%；渔业产值95.63亿元，可比增长6.5%，增加值57.69亿元，可比增长6.4%；农林牧渔服务业产值16.42亿元，可比下降1.3%，增加值9.52亿元，可比下降0.1%。

（二）农作物总播种面积及粮食播种面积呈持续下降趋势

近年来，我市农作物总播种面积及粮食播种面积呈逐年下降态势，2017年，莆田市农作物总播种面积为156.90万亩，同比下降2.2%，降幅比上年同期扩大0.5个百分点。其中粮食作物播种面积为66.72万亩，下降3.6%，降幅比上年同期扩大1.1个百分点；粮食产量为25.49万吨，下降1.4%，降幅比上年同期收窄3.4个百分点。在粮食作物中，稻谷播种面积为35.41万亩，下降6.3%，降幅比上年同期扩大1.8个百分点；稻谷产量为14.99万吨，下降2.8%，降幅比上年同期收窄5.4个百分点。

（三）园林水果产量呈恢复性的高增长态势

2016年由于我市园林水果生产受年初霜冻影响产量呈现大幅下降，2017年我市没有出现极寒天气，气候总体上适宜热带水果生长，园林水果生产产量恢复正常，产量呈现恢复性的高增长态势。2017年，全市园林水果产量为26.54万吨，增长19.1%。其中枇杷产量为9.58万吨，增长28.6%；柚产量为5.89万吨，增长19.6%；龙眼产量为3.95万吨，增长0.7%；柿子产量为3.29万吨，增长13.0%；香蕉产量为0.61万吨，增长17.7%；柑产量为0.55万吨，增长1.3%；李产量为0.40万吨，增长6.1%；桃产量为0.31万吨，增长4.2%；橄榄产量为0.27万吨，下降0.4%；杨梅产量为0.23万吨，下降0.1%；荔枝产量为0.17万吨，增长37.6%；葡萄产量为0.15万吨，下降16.0%。

（四）茶叶产量继续增加

近几年我市陆续扩大茶叶种植面积，且随着茶叶种植管理的跟进、种植技术的投入、茶树龄的增加、生产茶叶的茶树分枝增多，茶叶产量逐年增加。2017年，全市茶树年末实有种植面积为27836亩，比上年增长0.5%，茶树年末实有种植面积比上年净增加127亩；全年茶叶采摘面积为27163亩，比上年增长0.7%，茶叶采摘面积比上年净增加184亩；茶叶产量为0.66万吨，增长6.9%，茶叶产量比上年净增加427吨。在茶叶产量中：青茶产量0.55万吨，增长6.7%；红茶产量0.07万吨，下降7.1%；绿茶产量0.03万吨，增长9.4%；其他茶产量0.01万吨，增长9.0%。

（五）渔业生产继续保持较快的增长势头

近年来我市启动渔业底播增殖工程，引进南美白对虾高位池养殖，推广“购大苗养中鲍”养殖生产模式和网箱混养模式，我市渔业生产保持持续稳定较快的增长势头。2017年，全市水产品总产量97.01万吨，增长5.7%，产量比上年增加5.20万吨。其中海水产品产量92.49万吨，增长5.8%，产量比上年增加5.06万吨；淡水产品产量4.52万吨，增长3.2%，产量比上年增加0.14万吨。在海水产品产量中：牡蛎产量为38.53万吨，增长8.5%，产量比上年增加3.01万吨，对全市水产品总产量的贡献率高达58.0%；江篱产量为9.85万吨，增长28.7%，产量比上年增加2.19万吨，对全市水产品总产量的贡献率高达42.2%；海带产量为19.18万吨，增长0.9%，产量比上年增加0.16万吨，对全市水产品总产量的贡献率高达3.2%；鲍鱼产量为1.31万吨，增长7.3%，产量比上年增加0.09万吨，对全市水产品总产量的贡献率高达1.7%。

（六）蔬菜播种面积下降产量略升

由于受年初我市大宗蔬菜如花椰菜、西芹、莴苣等出现“卖难”现象，蔬菜价格季节性波动明显，直接影响了今年我市菜农种植露地蔬菜的积极性，我市蔬菜种植规模随之减小，蔬菜产量也受之影响。2017年，全市蔬菜播种面积为57.37万亩，下降1.3%，播种面积比上年减少0.77万亩；蔬菜产量为124.74万吨，增长0.1%，产量比上年增加0.08万吨；蔬菜亩产为2174.2公斤/亩，增长1.4%，亩产比上年增加30.1公斤/亩。

（七）食用菌生产规模大幅缩小

近几年来，由于受人工费用等生产成本提高影响，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其在我市的生产规模只减不增，食用菌产量受之影响呈大幅下降趋势。2017年，全市食用菌产量为6.07万吨，下降22.6%，产量比上年减少1.77万吨。其中，蘑菇产量5.50万吨，下降23.4%；姬松茸产量0.32万吨，下降17.7%；香菇产量0.18万吨，下降1.2%；其他菇产量0.06万吨，下降20.0%。食用菌生产占用耕地面积为10021亩，下降25.3%，占用耕地面积比上年减少3400亩；蘑菇种植面积为668.91万平方米，下降24.3%，种植面积比上年减少214.78万平方米。

（八）畜牧业生产有喜有忧

畜禽养殖污染整治基本上已到位，生猪生产已趋于稳定，存出栏及肉产量保持小幅增长态势。家禽生产受2016年年底的H7N9疫情影响，家禽出栏及肉产量均出现大幅下降，畜牧业总肉产量受之影响也呈较大幅度下降。2017年，全市生猪出栏94.83万头，增长1.0%，年末存栏50.42万头，增长3.5%，肉产量7.67万吨，增长3.0%；家禽出栏1858.90万只，下降28.7%，年末存栏589.22万只，增长9.4%，肉产量2.60万吨，下降28.8%；牛出栏0.66万头，增长2.9%，年末存栏2.62万头，增长2.3%，肉产量0.07万吨，增长3.3%；羊出栏18.39万头，增长2.4%，年末存栏10.92万头，增长1.1%，肉产量0.26万吨，增长2.3%。全市肉类总产量10.61万吨，下降7.2%；禽蛋产量2.85万吨，增长4.8%；奶产量1.34万吨，下降9.7%。

二、存在的主要问题

（一）生产成本及农产品价格对农业生产影响较大。一是近几年来受我市人工费用等生产成本不断提高影响，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其在我市的生产规模只减不增，我市食用菌生产规模逐年缩小。二是去年我市蔬菜价格低，蔬菜种植户增产不增收，大部分种植户亏本，导致今年我市菜农蔬菜种植积极性不高，蔬菜种植面积下降。

（二）农作物种植面积保持有难度。一是种粮比较效益偏低，农民种粮积极性不高，粮食播种面积和产量呈逐年下降态势。二是由于农民外出务工相比在家务农收入较高，我市部分山区青壮年人口常年外出打工，家里剩下老人与小孩，耕地因缺少劳动力耕作导致抛荒。三是受征地拆迁影响，耕地面积逐渐流失，特别是南北洋适合种植水稻的大片良田流失严重。

（三）畜禽可养范围较小，仅占全市总村居数的15%。根据市政府印发的《莆田市畜禽禁养区及禁建区划定方案》、《莆田市畜牧业集约化发展规划》（莆政综〔2010〕48号）和《莆田市人民政府关于公布畜禽养殖禁养区、禁建区及可养区的通知》（莆政综〔2011〕125号），全市行政区划内有近三分之二以上区域为禁养区，其中北岸和湄洲岛全境范围禁养；我市行政区划内可养区只有146村，占全市村居委会总数的比重为15.0%，其中仙游县52个村、城厢区15个村和秀屿区79个村。

（四）龙头企业带动作用减弱。年初以来，我市农业龙头企业农业生产规模总体呈现下降态势，全市农业生产受之影响也呈现下降态势。全年我市因莆田广东温氏家禽有限公司活家禽出栏及肉产量大幅下降拉动全市活家禽出栏及肉产量大幅下降。

（五）海洋经济短板仍未得到改善，渔业发展空间受限。随着城市建设和工业化的发展，适宜养殖发展的水域和滩涂等养殖区不断受到蚕食，水产养殖空间越来越小；湾外养殖扩展技术尚在实验阶段，技术难度大且风险高，尚需资金扶持，渔民参与积极性不高；海产品加工业发展滞后，不能有效促进渔业发展。

三、下一步建议

（一）以市场为导向，强化政策引导，提高农民农业生产积极性。要全面了解我市农业生产基本情况，摸清全市农业产业基本构架，分析预测农产品市场需求，有针对性地出台激励政策，提高农民农业生产积极性，尽可能避免耕地抛荒。

（二）加快农村耕地流转，扩大农作物种植规模。耕地流转是农业生产规模化的基础和前提。政府要出台相关政策引导、鼓励农村耕地流转，通过耕地流转把抛荒的耕地集中到种植大户、种植农民专业合作社和种植业龙头企业，发展适度规模的种植业生产，提高全市耕地利用率，从而扩大全市农作物种植规模。

（三）抓龙头企业农业生产。要着重抓好利农、鸿达、亿生、天怡、温氏等龙头企业的农业生产，支持和督促龙头企业扩大农业生产规模，带动全市农业经济稳定增长。
