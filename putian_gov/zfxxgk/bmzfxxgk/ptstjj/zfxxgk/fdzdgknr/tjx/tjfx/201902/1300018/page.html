2018年莆田市社会事业发展步伐加快

第十期
发布时间：2019-01-31 08:22
| | |

2018年，我市认真贯彻落实党中央决策部署，坚持稳中求进工作总基调，全面贯彻新发展理念，加快推进科技、教育、卫生、文化体育、社会保障等社会事业的建设步伐，更好地满足人民日益增长的美好生活需要。

一、科技事业方面

（一）科技创新能力提高，科技投入有所增加

一是大力培育高新技术企业和创新型企业。鼓励支持科技型企业研究开发新产品、新技术、新工艺，推广应用高新技术，提高企业的科技实力和产品的技术含量。至目前，全市共培育55家国家级高新技术企业、28家省级高新技术企业、40家省级创新型企业；另有科技小巨人企业69家，家国认定企业技术中心1家，省级企业技术中心35家，市级企业技术中心115家；省、市众创空间分别达10家、5家，重点实验室10家。与清华大学联合开展研究生社会实践活动，18名清华大学博士生在我市11家科技型企业实践6周，先后参与涉及新能源、装备制造、电子信息、精密仪器等方面科研项目共23个课题，为实践单位解决技术难题18个，撰写调研报告18篇7.2万多字。二是积极拓展科技特派员工作。2018年推荐认定省级科技特派员233名，比增366%，落实省级科技特派员工作经费304万元。组织认定市级科技特派员104人，下达市级科技特派员工作经费100万元。

（二）院地合作继续深化，促进成果对接与转化

2018年累计已邀请50多名中科院专家来莆推介最新科研成果和征集急需解决的技术难题，与企业进行项目精准对接。目前已征集技术需求20项，成功对接项目13项，纳入省STS计划项目8项，获省科技厅项目经费资助450万元。4月份，中科院海西研究院专家组来莆调研，先后考察了双方共建的莆田中心建设情况，调研华佳彩、海山机械、上海电气等21家重点企业。6月份，市政府与中科院上海分院、省科技厅、海西研究院四方签订共建STS莆田分中心协议书，成为我省设区市中首个中科院STS二级分中心。中科院STS分中心的成立和海西研究院莆田中心工程的建设，将积极推动中科院相关科研成果在我市落地转化，为莆田产业发展提供稳定可持续的科技支撑。

（三）知识产权创造、管理和服务水平持续提高

积极创建国家知识产权试点城市，顺利通过2017年度国家知识产权试点城市创建工作考核验收。加大知识产权优势企业培育力度，2家企业被评定为国家知识产权优势企业，6家企业被评定为省知识产权优势企业，14家企业被评定为市知识产权试点企业；2家企业通过企业知识产权管理规范贯标认证。持续推进企业专利权质押贷款融资，今年已新增11家企业获得专利权质押贷款，累计授信金额1.42亿元。2018年1-10月份，全市专利申请5216件，同比增长86.15%,增幅居全省第1位。全市专利授权2357件，同比增长61.22%，增幅居全省第3位。截至2018年10月底，全市共存有效发明专利773件，每万人口发明专利拥有量2.666件。

二、教育事业方面

（一）考核机制新突破，教育质量稳提升

完善各学段教学质量评价方案，研发精简校本作业，推进课堂教学模式改革，有效提升课堂容量和课堂效果。中考平均分在全省排名比上一年度跃升4个位次。学科竞赛取得重点突破，获省二等奖以上73人次，科创及机器人竞赛获省二等奖以上34人次。率先承办省级公开周活动。校企合作深入开展，全国职业院校技能大赛（中职组）中取得一银两铜佳绩。在全国率先推进市域书香校园智慧阅读工作，行政、专家、技术“三轮驱动”，全市近60万师生参与阅读。

（二）教育改革新突破，惠民政策贴民心

一是规划布局改革，学位供应快增长。策划2018-2022年教育类补短板项目202个，其中2018年幼儿园项目竣工28个，新增学位7380个，中小学竣工47个，新增学位13590个，有效缓解学位紧张问题。二是招生改革，促进教育公平。实行部分公办小学毕业生对应直升公办初中政策；在全省率先推进民办初中学校摇号招生改革，统一网上报名，统一随机派位，统一面试录取，统一学籍管理，简化新进城务工人员随迁子女入学申请手续。全市共有761名随迁子女通过电脑派位、2413名通过统筹安排进入公办义务教育学校就学。

（三）资源共享新突破，优质均衡再深化

一是坚持名校带动，共54所学校获批不同学段的省级示范校，超额完成名校创建任务。创新打造60个“教育联盟”、“教育集团”共同体，涵盖中小学校超过300所，优质办学形成规模。优化调整新一届52个名师工作室，建立以领衔名师所在学校为基地校、带动三个薄弱学校的帮扶机制。二是实施教育名师引进计划，重视公费师范生委托培养，首届12名男性公费师范生回莆任教。在省第四届中小学教师教学技能大赛中，奖牌榜位居全省前茅，其中特等奖2名，一等奖5名。首次建立127所教师专业发展基地学校，促进新任教师加快成长。

三、卫生事业方面

（一）医药卫生体制改革不断深化

一是扎实推进公立医院改革。正式出台《莆田市人民政府办公室关于建立现代医院管理制度的实施意见》（莆政办[2018]106号），在市第一医院和莆田学院附属医院大力推行后勤一站式服务社会化。二是着力推进基层综合改革。全市已完成建设集体所有村卫生所数736个；推行家庭医生签约服务，全市组建家庭医生服务团队540个，全面加强签约和履约服务，促进基层服务模式转变。三是稳步推进分级诊疗工作。继续以慢性病管理为切入点，在全市全面实施“基层首诊、双向转诊、急慢分治、上下联动”的分级诊疗制度。四是积极发展医疗健康产业。积极做好妈祖国际医疗健康城建设和项目引进工作，目前已签订合作协议6家，达成合作意向23家，中关村医学工程转化中心莆田园区项目已于2018年6月正式开业。继续鼓励引导社会办医，制定出台支持社会力量提供多层次多样化医疗服务的实施意见，2018年共新设置各级各类医疗机构15家，新开业2家。

（二）公共卫生服务体系不断健全

一是加强疾病预防控制。全力防控人感染H7N9流感和登革热疫情，加强对重点传染病的监测预警、防控管理和督导检查；强化免疫规划工作，全市以县（区）为单位儿童预防接种报告接种率达95%以上。针对吉林长春长生生物疫苗案件和非洲猪瘟事件，主动发布权威信息，开展健康教育，有效稳控舆情，并做好长春长生狂犬疫苗和武汉生物百白破疫苗跟踪观察和补种工作。二是实施基本公共卫生服务项目。2018年基本公共卫生服务补助经费和项目均有所提高，覆盖城乡居民生命全过程。全市共建立居民电子健康档案229.33万份,规范化电子建档率80%；为24.75万老年人建立健康档案。三是进一步健全卫生应急机制。莆田市卫健委与福州、宁德和平潭卫计部门签署“福莆宁岚卫生应急区域合作框架协议”。成功举行“空中120”启动仪式，多次组织省级紧急医学救援莆田队开展紧急集结、野外拉练、急救技能培训，并参与反恐应急演练。

（三）医疗保健服务能力不断提高

一是提升医政管理和医疗质量水平。积极开展进一步改善医疗服务行动，三级医院门诊预约就诊率约72.33％，复诊预约率约88.35％，全市实行临床路径管理的出院患者比例三级医院达43.6%、二级医院达24.62%，以上各项指标较2017年均显著提高。二是做好科技教育和医学科研工作。做好医学类科技项目审核把关。今年市第一医院科研立项9项，莆田学院附属医院科研院内申报42项。依托市医学会及临床质量控制中心，开展医学学术活动72场次，培训各级各类卫技人员9116人；继续做好6名仙游县乡镇卫生院医学大专定向委培生、17名仙游县医院定向委培生的培养工作。

四、文化事业方面

（一）公共文化服务体系不断完善

一是文化服务有新成效。市博物馆新馆开馆以来，接待市民400多万人次，举办各类展览15场次、活动20多场次，接待团体120多个；市图书馆新馆开馆以来，共接待读者140多万人次，外借图书120万多册，共举办了各类活动253场，参加2万多人次；市群众艺术馆全年举办展览20多场次、活动100多场次，公益艺术培训8万多人次，直接受益群众20多万人次。二是服务项目有新拓展。创新公共文化服务机制，选择古建筑、公共文化设施、非遗展示等新建集图书阅读、文化创意等于一体的“莆阳书房”示范点6个，既推进文化场馆综合利用，拓展了三馆服务功能，又实现了文物保护科学利用和文化事业产业融合发展，为市民提供了便捷、舒适的阅读空间和借阅服务，图书通借通还月均7000册次。

（二）文化产业发展不断加快

一是文化产业交流平台不断拓展。组织文化企业参加深圳、西部、厦门等文博会，获得优秀展示奖和优秀组织奖，参展规模居全国地级市首位。邀请福建省闽台文化交流中心、台湾文创交流团来莆考察工艺美术产业，成功举办了2018年闽东北经济协作区文化产业协作会议，促进了文化文创交流。二是对外文化交流不断拓展。积极融入“一带一路”建设，加强莆田市与东南亚国家及海上丝绸之路沿线国家的文化交流合作。第八届“博博会”考察团来莆考察，促进以妈祖文化为代表的莆田优秀传统文化通过世界各地博物馆传播，让世界了解莆田、了解妈祖文化。我市成功举办“妈祖文化活态传承与运用”主题论坛，组织文化交流团赴新加坡、马来西亚开展莆仙戏《海神妈祖》剧目巡演及文化交流活动，提升了莆仙文化影响力。

（三）文化遗产传承保护不断加强

一是文物保护等级有新提升。新增第九批省级文物保护单位14处，是历年来最多的一次，新公布第七批市级文物保护单位13处。二是文物法案市政府执件取得新突破。出台《关于进一步加强文物安全工作的若干措施》,仙游县盖尾镇昌山村临水庙被拆毁破坏事件已由公安机关按照相关法律规定立案查办，目前已刑拘2名嫌疑人，形成了有力震慑。三是非遗传承保护有新成效。编撰完成《国家级妈祖文化生态保护实验区规划纲要》，正在提请省政府转报国务院；新增国家级非遗传承人2名、省级非遗传承人22名，新公布第六批市级非遗项目名录37项。中国剧协、省文联、省剧协、省艺术研究院在莆田举办了“周长赋剧作学术研讨会”，国家艺术基金推广项目莆仙戏《踏伞行》在研讨会期间举行首演，受到了国家、省级戏剧专家的一致好评，荣获福建省第二十七届戏剧会演剧目一等奖。

五、体育事业方面

（一）群众体育实现新发展

一是完善全民健身设施。推动省、市共建全民健身场地设施建设项目建设（含多功能运动场22个，室内健身房14个，笼式足球场11个，门球场4个，室外健身器材50个），2018年省市财政投入共计1714万元，全市全民健身场地设施进一步覆盖。二是办好群众身边赛事活动。初步形成全民健身品牌赛事，如“妈祖杯"海峡两岸暨港澳地区门球邀请赛、第七届“妈祖杯”海上丝绸之路业余围棋联赛等大型群众体育赛事。2018年我市共举办全民健身活动（比赛）约150场，各县区举办活动126场。三是稳步推进全民健身赛事改革。2018年，市级全民健身运动会运动项目全部市场化运作，由市体育产业公司向社会公开招投标，进一步引导社会力量办体育，体育赛事改革取得成效。四是健全群众身边组织。今年新批准成立市黄氏太极拳协会及市广场舞协会。2018年市级体育社会组织举办各类群众活动和赛事共150余场，直接参与人数近2万人。

（二）竞技体育取得新成绩

一是积极承办大型赛事。2018年举办了6场全国性以上体育赛事：第二届“妈祖杯”海上丝绸之路羽毛球挑战赛、全国射击冠军赛、2018年全国海钓竞赛训练基地·福建南日矶钓邀请赛、2018年中国枪王争霸赛及系列活动。其中，“妈祖杯”羽毛球赛邀请超过22个海丝沿线为主的国家地区的选手参赛，运动员总规模超过1500人。二是亚运会莆田运动员斩获一金三银。在2018年第十八届印尼雅加达亚运会上，莆田运动员捷报频传，斩获一金三银，金牌数位于全省第4，奖牌数位于全省第3。三是第16届省运会续写辉煌。我市运动员共打破4项省运会记录，现场比赛金牌和带牌带分获得金牌创造了莆田市代表团在省运会上获得金牌数的最高纪录，其中，带牌带分获得金牌46.5枚，现场比赛获得金牌37枚。我市有5个项目获得金牌数位列全省前三名，3个项目金牌数位列全省第一。

（三）体育产业实现新提升

一是加强体育产业基地申报工作。推荐福建汉岚体育产业投资管理有限公司申报国家级体育产业基地，推荐仙游县菜溪乡、西苑乡特色小镇等14个项目申报省级体育产业基地项目。2018年，城厢区九龙谷体育休闲旅游和双驰鞋业进入福建省体育产业示范基地现场核验阶段，有望获得省级体育产业示范单位。二是做好体育产业招商项目工作。在福建省计划推出 100 个体育产业招商项目中，莆田市共申报21个项目，包括莆田冰雪小镇、“妈祖杯”海上丝绸之路国际羽毛球挑战赛等优质项目。三是推广莆田体育产业优质项目。推荐九龙谷和九鲤湖两个项目参展亮相正在广州举行的中国体育两博会；推荐冰雪小镇和萩芦镇参展亮相第36届中国国际体育用品博览会；推荐冰雪小镇项目和汉岚全民健身场馆全覆盖项目参展亮相2018年中国国际投资贸易洽谈会；推荐汉岚全民健身场馆全覆盖项目申报2018年现代服务业专场对接会；推荐“九鲤湖体育+旅游”线路申报2018年“十一黄金周”中国体育旅游精品线路。

六、民政事业方面

（一）在着力保障民生上有新亮点

一是社会救助保障体系逐步健全。全市城乡低保保障标准继续按省定最高标准（42%）执行，统一达7560元/年；城市居民和农村居民月人均补助水平分别提高250元和150元，同比大幅增长75.8%和64.9%。脱贫攻坚低保兜底保障作用进一步强化，全市符合条件的4248户11185人建档立卡贫困对象100%纳入低保保障范畴。完成残疾人“两项补贴”提标任务，扩面对三级、四级智力或精神残疾患者发放护理补贴，惠及全市4万余名残疾人。急难救助高效灵活，全年全市为突发性临时性困难家庭（个人）共16648人次发放临时救助金2407万元，资金使用率97.48%。二是防灾减灾救灾能力有效增强。安排冬令春荒救助资金650万元、救助困难对象6.1万人。下拨各类救灾应急资金415万元，切实保障受灾群众的基本生活。建成市级和城厢区、秀屿区救灾物资储备库，完成县、乡、村三级共1200个自然灾害避灾点的分类提升。2018年3月，澳门特区政府减灾避险工作交流团来莆考察学习相关经验做法。

（二）在养老事业发展上有新突破

一是为民办实事项目全面完成。养老服务照料中心建设省级15个、市级5个和农村幸福院建设省级23个、市级181个全面完成。每千名老年人拥有养老床位数35.9张，提前两年完成每千名老人拥有养老床位35张的目标任务。二是养老服务保障有效加强。目前，全市已建、在建养老机构67家；共建成农村幸福院388所，建制村覆盖率达45.65%；共建成居家社区养老服务照料中心32个，城区街道和中心城镇覆盖率达84.6%；年度新增住宅小区养老服务设施配建22宗，城市社区每万人拥有养老服务设施面积超过500平方米，提前完成十三五任务指标。三是养老红利逐步释放。首届6.18养老项目成果交易会成功签约7个项目、总投资额达77.2亿元，签约项目数量及总投资额位居全省第一。2018年全市养老事业投入资金总额3.58亿元，其中福彩公益金投入总额0.19亿元，实现福彩公益金80%以上用于养老事业建设。

（三）在未成年关爱保护上有新举措

目前，全市留守儿童5023人，困境儿童2767人，无户籍儿童12名，占比0.24%，完成率为全省第二名。其中，农村留守儿童总量与2016年首次摸底排查（10004人）相比减少49.8%、《委托监护责任确认书》签订率达100%。莆田市率先按人口比例增加配备全市乡镇（街道）133名民政协管员。2018年共解决108名留守无户籍儿童办理户籍和7名失学辍学留守儿童的返校就学问题。积极探索建立“儿童之家”模式，依托养老院、老协会等场所特色，实现资源共享共建共用，目前全市已建立儿童之家场所共128个。开展全省首例农村留守儿童跨市主题暑期公益夏令营活动，建立“五个一”机制，切实兜住农村留守儿童安全底线和政府责任风险底线。农村留守儿童关爱工作经验做法在《福建民政参考》刊登并全省予以推广。

七、环保事业方面

（一）环境质量不断改善

木兰溪、萩芦溪两大流域10个省控以上断面水质Ⅰ～Ⅲ类比例达90%，其中Ⅰ～Ⅱ类比例为20%；东圳、外度、古洋、金钟4个县级及以上集中式饮用水水源地（湖库）水质达标率均为100%；省控25条小流域（29个考核断面）水质优良比例达82.76%，同比上升10.34个百分点，其中劣Ⅴ类水质断面全部消除，均达到责任书目标要求。全市空气质量达标天数比例为91.8%（按国家新标准），同比上升1.1个百分点，PM2.5等六项指标均达到二级标准，综合指数3.17。

（二）污染防治力度不断加大

落实建设美丽莆田·生态文明2018年专项行动计划，市政府发出《关于全民行动打好污染防治攻坚战的通告》，进一步动员全市人民共同打好污染防治攻坚战。一是强化水污染防治。创新实行“双河长”制度，共设立河长784名，实现了区域流域监管全覆盖，实施跨区域流域断面分段监测考核机制。省控8条水质不达标小流域中3条小流域水质明显提升，3条劣Ⅴ类小流域全部销号。二是强化大气污染防治。开展挥发性有机物（VOCs）专项治理，全市442家重点涉VOCs企业已全部安装废气治理设施；开展“散乱污”企业整治，全市共排查1218家“散乱污”企业，已完成整治1191家。开展餐饮油烟污染整治，全市共排查1181家餐饮服务业，已安装油烟净化设施1175家。三是强化土壤污染防治。有序完成农用地详查1050个土壤pH和351个土壤重金属的样品测试任务。加强危险废物管理，危险废物规范化管理考核中经营单位合格率为100%，产废单位合格率为96%。全市共有1134家医疗机构签订集中处置协议，各级各类医疗卫生机构产生的医疗废物全部实现集中处置，处置率为100%。

（三）生态环境治理体系不断完善

全市共办理环境违法案件459件，其中办理行政处罚案件153件，罚款1125.09万元。一是推进生态环境信息化建设。依托福建省生态云、莆田政务云，推进我市特色应用开发，投资600万元建设莆田市环境监管网格化信息平台和莆田水环境（湖库）综合管理平台项目。完善生态云平台数据，全市122家规模畜禽养殖场（展示视频）、88家VOCs企业（展示视频）安装在线视频监控。汇聚污染源数据，采集入河排污口1423个、涉VOCs治理企业名单360家。二是全面推行排污权交易制度。全市共有化学需氧量5375.91吨、氨氮553.70吨、二氧化硫453.74吨、氮氧化物1085.41吨可交易排污权用于支撑新项目特别是重点项目的落地。
