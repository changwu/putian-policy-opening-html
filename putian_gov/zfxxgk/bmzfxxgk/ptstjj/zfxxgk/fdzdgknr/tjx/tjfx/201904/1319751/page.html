建筑业实现“开门红” 总产值增幅全省第二——2019年一季度莆田市建筑业运行情况简析

第二十七期
发布时间：2019-04-26 10:05
| | |

一季度，在市委市政府的重视指导下，全市建筑行业积极应对经济下行，加快推进建筑业转型升级，呈现较快增长态势，实现良好开局。

一、建筑业总体运行情况

注册地建筑业总产值增速逐月提高。从注册地看，一季度莆田市总专包建筑业企业完成建筑业总产值178.00亿元,增长17.4%，增速位居全省第二，较1-2月提高2.5个百分点。从省外入莆企业看，一季度省外入莆建筑企业完成产值29.81亿元，增长21.7%，增速较上年同期提高12.6个百分点。

其他建筑业指标呈两位数增长。一季度全市签订的合同额752.02亿元，同比增长10.0%。建筑工程产值172.90亿元，增长17.7%。竣工产值63.79亿元，同比增长23.7%，增速较上年同期提高43.0个百分点。

二、三大亮点

龙头企业产值贡献率过半。一季度产值超过10亿的企业有4家，仅占总企业数的0.8%，合计完成产值63.46亿元，增长27.1%，占全市总产值的35.7%，拉动全市建筑业总产值增长8.9个百分点，贡献率51.1%。可见大型企业支撑作用明显，进一步加大对龙头建筑企业的扶持力度，是我市建筑行业发展的重要一环。

新开工房屋面积增速明显提高。一季度新开工房屋面积444.77万平方米，同比增长34.4%，较去年同期提高36.7个百分点。一季度从事住宅房屋建筑业的资质企业产值115.80亿元，同比增长23.1%。今年我市房地产开发投资增速明显回暖是新开工房屋面积大幅增加的主要原因。

新增企业产值贡献率近四分之一。截止3月底，全市资质建筑业企业入一套表库（含劳务分包）507家，与上年同期相比，全市新增入库企业186家，同比增长57.9%。一季度新增企业产值合计5.90亿元，拉动全市建筑业总产值增长3.9个百分点，贡献率22.4%。新增企业大多是小型企业，工程量不大，但企业新增数量大，对全市总产值有一定拉动作用。

三、存在问题

从结构来看:一是专业工程行业占比偏低。一季度莆田市建筑企业房屋建筑业务量在总量中占比65.7%，房屋建筑业务中又以住宅工程为主，占比99.0%。本市建筑企业从事道路桥梁、轨道交通、机电安装、水利水电、建筑装饰、建筑幕墙等专业工程产值比重偏低。目前发达国家建筑业中，房屋建筑与专业工程建筑各占一半，我国与之相比还有差距，当前我们应努力培育专业工程企业。二是铁路、通信等总承包资质空白。目前全市入一套表库建筑企业（含劳务分包）507家，共有资质2638个。从施工总承包来看，超过8成的企业都拥有建筑工程、市政公用工程资质，但是铁路工程、通信工程等资质还是空白，特别是铁路工程都是大型重点项目，我市企业连招投标的资格门槛还未跨入；从施工总承包资质级别来看，公路工程仅有1家一级资质企业，电力工程没有一级资质企业。

从主要指标来看：一是外拓产值增速明显回落。一季度莆田市资质企业外拓产值66.40亿元，同比增长8.6%，增幅较上年同期回落11.6个百分点，占总产值比重为37.3%，较上年同期回落3.0个百分点。二是装饰装修产值下滑明显。一季度装饰装修产值完成0.81 亿元，同比下降25.0%，占总产值比重仅0.5%，比上年同期回落0.2个百分点。

四、发展建议

促政策落地。要认真落实《莆田市人民政府关于促进建筑业发展壮大的实施意见》(莆政综【2018】98号)文件，尽快出台相关的实施细则，切实解决企业发展存在的具体问题。

破融资困难。要强化监督，健全法律制度，对长期拖欠工程款的业主，制定相应的制约措施。根据不同项目情况，可采取投资补助、基金注资、担保补贴、贷款贴息等方式，放大财政资金撬动社会资本的作用。同时考虑中小企业可抵押物少的实际情况，出台针对中小企业的灵活贷款政策。

“走出去”。帮扶企业“走出去”发展，推动企业加快转型升级，各县（区、管委会）要对辖区内企业逐个摸排、重点帮扶，促进企业做大做强，积极引进外来企业，同时鼓励本市企业“走出去”发展。

“引进来”。引领总部经济建设，加大建设总部大楼的力度,吸引更多外来的大型建筑企业，形成有地方特色的建筑企业集聚区，吸引一批建筑企业入驻本市，带来更多税源，推动我市建筑业的跨越式发展。
