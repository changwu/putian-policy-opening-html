1－2月莆田市商贸业运行情况简析

发布时间：2014-03-18 00:00
| | |

1－2月，全市商贸业发展形势不容乐观。除批发业表现突出，其商品销售额实现快速增长外，零售业商品销售额、住宿业及餐饮业营业额均呈大幅回落态势，发展前景堪忧；消费品零售市场因去年高基数等因素影响，增长速度明显放缓，发展滞后，前2个月只实现个位数增长。

一、运行基本情况

（一）全市商贸业的支撑点仍为批发业。批发业以现有潜力挖掘为重点，突出以中石化炼油销售（福建）有限公司（荔城）、中海石油气电集团有限责任公司福建贸易分公司（仙游）等企业为代表，实现良好开局。1－2月，全市批发业企业（单位）延续上年快速增长的态势，实现商品销售额113.91亿元，同比增长50.0%，增幅分别高于上年同期、全省平均水平12.1个及36.9个百分点，依然居全省九设区市首位。其中，限上批发业发展形势较好，前2个月实现商品销售额96.68亿元，增长59.8%，对全市批发业商品销售额增长的贡献率高达95.2%，从而引领批发业快速发展。

（二）零售业销售额下降。前2个月，全市零售企业（单位）实现商品销售额77.58亿元，与上年同期相比下降7.4%，发展慢于全省平均水平17.6个百分点，居全省末位。分限额标准看，限上及限下商品销售额增速分别较上年同期回落146.6个和4.3个百分点，特别是限上零售业累计商品销售额大幅回落，拉低零售业13.4个百分点。

（三）住宿餐饮业个位数增长。前2个月，全市住宿餐饮业实现营业额10.14亿元，增长6.2%，增幅低于上年同期5.4个百分点。其中，限上住宿餐饮业营业额同比下降6.9%，限下住宿餐饮业发展好于限上，实现增长8.8%。

（四）零售市场低位增长

前2个月，全市消费品零售市场实现零售额83.81亿元，与上年同期相比，增长7.5%，增幅低于全省平均水平5.1个百分点。

1、分限额标准看，限上零售额小幅增长。前2个月限上零售额25.19亿元，增长2.4%，低于限下7.5个百分点。按消费形态分，限上商品零售额24.25亿元，增长3.2%，限上餐饮消费则同比下降，实现餐费收入0.94亿元，同比下降14.3%。

2、按销售所在地分，城镇快于乡村。1-2月，城镇零售额73.96亿元，增长7.8%，乡村零售额9.85亿元，增长5.6%，城镇增幅快于乡村2.2个百分点。

3、限上消费呈现“三高三低”

 “三高”为消费热点集中在三大类商品：鞋帽类、金银珠宝类及汽车类，其中，鞋帽类商品累计实现零售额2.18亿元，增长159.9%，纳入统计的限上网贸企业大部分从事鞋帽类产品销售，其累计通过互联网实现的商品零售额为1.74亿元，同比增长195.1%，增幅远高于全市平均水平；同期金银珠宝类商品零售额实现了46.4%的增长；值得一提的是汽车类，这类商品销售占全市限上零售市场的21.1%，市场销售较平稳，前2个月实现零售额5.10亿元，增长14.1%，增幅比上年同期小幅回落2.3个百分点。

“三低”为限上消费的盲点集中在石油、家电及其他类等商品类别上。前2个月石油及制品类、家用电器和音像器材类及其他类均呈不同程度下降之势，累计降幅分别为23.1%，15.4%及38.5%，制约市场进一步发展。

（五）各县区限上商贸业发展不平衡

从商品销售额增幅看，居全市前三位的分别为仙游县、荔城区及秀屿区。仙游县在石油类企业快速增长的带动下，限上批发零售业实现商品销售额29.40亿元，与上年同期相比增长159.2%，增幅高于全市平均水平133.0个百分点，居全市各县区首位；其次为荔城区，增幅46.2%；再次为秀屿区，为39.8%。城厢区因受中石化森美莆田分公司高基数影响，累计商品销售额下降28.8%。

从营业额增幅看，除涵江（增长8.9%）及北岸（增长14.8%）外，其余县区营业额均下降。

从消费品零售额增幅看，北岸零售额增速最高，达171.2%；其次为荔城区27.7%，涵江为11.8%，其余县区均为负增长。

二、制约因素

（一）上年高基数带来的负面影响。特别是中石化森美莆田分公司今年来停止联营单位在莆开票业务，而在上年筑成的高基数情况下，今年该企业商品销售额（零售额）大幅回落，受此影响，限上零售业商品销售额累计缺口达11.23亿元，预计上半年零售业商品销售额增速转正机会不大。

（二）新增法人企业体量小。从全市年度新增入库的145家企业上报情况看，1－2月户均销售额（营业额）分别为：批发业户均1501万元，零售业户均389万元，住宿餐饮业户均68万元。新增企业总体规模小，带动作用有限。

（三）超3成的限上批发零售企业业绩下降。全市限上批发零售企业中有195家（含25家未营业）商品销售额同比下降，下降面高达36.0%，较上年同期扩大6.5个百分点。分行业看，限上批发业下降面38.0%，限上零售业为33.4%。

 （四）限上住宿餐饮业不景气。今年来，限上住宿餐饮业公务消费明显下降，企业（单位）业绩下滑，前2个月户均营业额为209万元，少于上年同期65万元。受市场份额减少影响，全市有过半限上住宿餐饮业企业营业额同比下降。

三、一季度预测情况

今年一季度，全市预计批发零售业商品销售额将达322亿元，同比增长20.1%，其中限上205亿元，增长26.0%；住宿餐饮业营业额将达14亿元，增长6.2%，其中限上营业额2亿元，下降3.7%；社会消费品零售额将达123亿元，增长7.9%，其中限上42亿元，增长4.2%。

四、发展建议

今年商贸业面临的压力较大，限上批发业将从3月份起基数扩大，商品销售额超亿元的大企业都已带上基数，增速将放缓；限上零售业及住宿餐饮业将不会有大的好转。当前应做好以下工作：

（一）服务总部经济型企业。如果今年总部经济型企业经营出现波动，将深远影响批发业。建议进一步发挥区位优势及莆商资源优势，加快荔城区及城厢区的商务中心区建设，完善基础条件及商务设施，及时了解已有企业生产经营动态，实时服务企业，促进总部经济型企业持续健康发展。

（二）打好基础，做强小微企业。在商贸行业中，小微企业众多，数量占限上企业数的78.0%，小微企业因人工成本、租金上涨及融资困难等因素，企业经营压力较大。建议加大对小微企业发展的扶持力度，降低贷款融资门槛，鼓励企业抱团发展，促进企业做大做强。

（三）做好月度新增企业审核变动工作。依托于第三次全国经济普查，摸清商贸企业家底，对于符合条件的企业，要及时纳入统计，从而全面真实反映商贸业发展情况和趋势。
