1-5月莆田市经济运行情况分析

第三十六期
发布时间：2019-06-17 17:13
| | |

1-5月，全市固定资产投资、规模以上其他营利性服务业营业收入、实际利用外资、金融本外币存款余额增幅均居全省前列，主要经济指标符合预期，经济运行继续保持总体平稳、稳中趋优的发展态势。同时要清醒地看到，受多重因素影响，经济运行中还存在一些问题，下行压力仍然较大，必须采取有针对性的措施切实加以解决。

一、经济运行主要特点

（一）工业运行稳中趋缓。1-5月，全市规模以上工业增加值可比增长8.5%，增幅比1-4月回落0.3个百分点，比全省平均水平低0.1个百分点。主要亮点：一是重点产业贡献突出。1-5月，全市八大重点产业增加值可比增长9.3%，增幅高于全市规模以上工业增加值0.8个百分点，对规模以上工业增加值增长的贡献率为93.0%，拉动全市规模以上工业增加值增长7.9个百分点。其中：制鞋产业、化工新材料产业、电子信息产业、高端装备产业、食品加工产业分别拉动全市规模以上工业增加值增长1.8个、2.1个、1.1个、0.9个和1.0个百分点。二是“三新”工业经济快速增长。全市战略性新兴产业工业增加值增长14.7%，增幅高于全市平均水平6.2个百分点；高技术企业工业增加值增长17.8%，增幅高于全市平均水平9.3个百分点；装备制造业工业增加值增长19.2%，增幅高于全市平均水平10.7个百分点。三是七成主要产品产量实现增长。其中，鞋增长9.8%，涂料增长33.7%，模具增长27.5%，钢材增长22.5%，家具增长19.4%，大米增长22.5%，罐头增长3.7%。

（二）建筑业生产运行良好，大型企业贡献突出。从注册地看，1-5月，全市建筑业企业完成总产值287.91亿元,增长16.2%，增幅比1-4月回落1.2个百分点，但比上年同期提高1.4个百分点，位居全省第二位。其中，龙头企业产值贡献率过七成。5家产值超过15亿的企业共完成产值119.79亿元，同比增长31.4%，对全市建筑业总产值增长的贡献率达71.0%，拉动全市建筑业总产值增长11.5个百分点，龙头企业数仅占全部企业数的1.0%，产值占全市总产值的41.6%，表明大型企业支撑作用明显。

（三）规模以上其他营利性服务业增幅位居全省榜首。1-4月，全市规模以上其他营利性服务业同比增长25.1%，增幅高出全省平均水平3.0个百分点，居全省第一位。其中，互联网和相关服务、软件和信息技术服务业贡献突出。全市该行业企业营业收入增长88.2%，增幅同比提高43.8个百分点，拉动全市规模以上其他营利性服务业营业收入增长14.1个百分点，主要得益于福建豆讯科技有限公司、福建聚合网络有限公司等新入库企业拉动有力。

（四）消费品市场增幅回落。1-5月，全市社会消费品零售总额342.29亿元，同比增长9.8%，增幅分别比上年同期、1-4月回落2.6个和0.7个百分点。主要亮点：一是新增企业拉动有力。2018年以来新入库的513家企业快速增长，共实现零售总额25.02亿元，拉动全市社会消费品零售总额增长4.4个百分点。二是网络消费持续活跃。1-5月，全市限额以上网络零售额72.33亿元，同比增长16.6%，增幅快于全市社会消费品零售总额6.8个百分点。三是品质类商品零售涨幅较大。如可穿戴智能设备零售额增长279.8%；智能手机增长32.4%；新能源汽车增长76.5%。四是部分有店铺零售业绩较好。限上食杂店、便利店、百货店实现商品零售额分别增长33.4%、42.5%和20.6%。五是餐饮收入保持两位数增长。今年来全市餐饮收入均保持在15%以上，1-5月全市限上住宿餐饮业营业收入增长16.6%，增幅快于社会消费品零售总额6.8个百分点。

（五）固定资产投资增幅快速回升。1-5月，全市固定资产投资同比增长10.3%，增幅比1-4月提高9.3个百分点，比全省平均水平高3.7个百分点，居全省第三位。主要特点：一是在建亿元项目高速增长。全市173个在建亿元项目完成投资增长61.7%，增幅分别比上年同期、全市固定资产投资高77.9个和51.4个百分点，其中，40个本年新开工亿元项目完成投资同比增长142.5%。二是房地产业投资快速增长。全市房地产业投资由上年同期的下降7.4%转为增长40.0%，其中房地产开发投资同比增长24.1%，增幅同比提高20.6个百分点。三是制造业投资止跌回升。全市制造业投资由1-4月的下降9.8%转为增长13.9%。其中计算机、通信和其他电子设备制造业，化学纤维制造业，纺织业增幅分别比1-4月提高23.9个、20.1个和209.8个百分点。

二、存在问题

（一）传统制鞋业贡献明显减弱。1-5月，全市规模以上工业制鞋产业增加值仅增5.5%，增幅分别比1-4月、1-3月回落2.0个和3.0个百分点，对规模以上工业经济增长的贡献率比1-4月低5.4个百分点。主要原因：受外需不足、中美贸易战等因素影响，特别是中美贸易战不明朗，企业对后期预判不乐观，出现客户订单不敢下、企业订单不敢接的现象，将持续影响全市制鞋产业的进一步增长。

（二）汽车、石油及制品类商品销售市场较为疲软。一是汽车销售持续低位运行。汽车类零售额占限额以上零售额比重为14.8%，是影响全市消费品市场增长的重要因素。1-5月，全市限额以上汽车类商品实现零售额同比增长7.3%，增幅同比回落10.7个百分点，主要受汽车市场饱和影响，76家企业中有25家销售下降。二是石油及制品类影响较大。限额以上石油及制品类零售额占全部限额以上零售额比重为7.0%，是影响全市消费品市场增长的另一重要因素。1-5月，限额以上石油及制品类商品实现零售额同比下降3.6%，18家企业中有6家零售额下降。

（三）基础设施投资增幅下降，民间投资低位增长。1-5月，全市基础设施投资同比下降3.0%，其中交通运输业投资同比下降10.8%，电力、热力、燃气及水的生产和供应业投资同比下降13.5%。全市民间投资同比仅增5.4%，增幅同比回落48.8个百分点，低于全省平均水平5.5个百分点，其中项目民间投资增速由上年同期的增长71.5%转为下降0.9%，项目中的工业民间投资增速同比回落21.2个百分点。

三、对策建议

（一）确保工业经济实现稳步增长。强化工业生产经营状况监测，加大对重点企业的跟踪监测和服务力度，“一企一策”协调解决具体困难和问题，力促企业复产达产增效，全力巩固工业经济运行的稳定态势。做好升规入统工作，确保应统尽统。对成长性好、实力强的小微企业做好扶持培养，条件成熟及时纳规入库，为工业发展增强后劲。

（二）加强项目储备。一要继续加大项目储备力度,推进招商引资签约项目尽早落户。二要推进在建重点项目建设进度，争取在建项目早日投产，形成投资增长的有力支撑。三要大力发展中小项目，重视亿元以下项目的培育工作，增强投资增长后劲。四要加强部门联动，对已开工未入库项目，督促项目单位尽快完善相关手续，确保新开工项目及时入库。

（三）促进消费品市场持续增长。严格落实国家关于促进消费、扶持商贸流通业发展的相关政策，扶持在库企业不断壮大。同时，继续做好“个转企”、“小升规”工作，有方向、有重点地培育潜力大、有优势的企业，壮大限额以上法人企业，更好发挥骨干带动作用。
