2025年莆田市常住人口发展变化分析

发布时间：2026-04-06 08:38
| | |
 2025年，莆田市坚持优化人口发展路径，落细落实生育政策，积极应对人口老龄化、少子化趋势，城镇化水平持续提高，不断推进人口高质量发展。

一、人口发展总体情况

（一）常住人口有所下降，性别比保持稳定。2025年末，莆田市常住人口318.4万人，比2024年末减少0.8万人。全市出生人口1.40万人，比上年减少0.53万人；出生率4.39‰，比上年下降1.67个千分点。死亡人口2.35万人，比上年增加0.1万人；死亡率7.37‰，比上年提高0.31个千分点。人口自然增长率-2.98‰，自然增长人口为-0.95万人；净流入人口0.15万人。从性别结构看，男性160.9万人，女性157.5万人，性别比为102.16（以女性人口为100），基本与上年末持平，继续保持在合理区间。

（二）城镇化率稳步提高，区域城镇化差距缩小。2025年末，全市城镇人口213.2万人，比上年末增加2.5万人；乡村人口105.2万人，比上年末减少3.3万人；常住人口城镇化率66.96%，比2023年提高0.95个百分点，城镇化进程稳步推进。各县区城镇化率均有不同程度提升，区域水平差异仍较明显，但差距不断缩小。涵江、荔城、城厢三个县区城镇化率均超过70%。涵江区城镇化率最高，为81.16%；秀屿区最低，为48.80%。两地城镇化率相差32.36个百分点，差距比2024年缩小0.64个百分点。

（三）年龄结构有所变化，少儿人口比重高于全省平均水平。2025年末，全市0-15岁人口60.3万人，比上年减少2.6万人；16-59岁人口191.4万人，比上年减少0.6万人；60岁及以上人口66.7万人，比上年增加2.4万人。三个年龄段占比由2024年的19.7%、60.2%、20.1%调整为2025年末的18.9%、60.1%、21.0%。0-15岁少儿人口占全部人口比重为18.9%，比全省平均水平高1.1个百分点，居全省第二位。

（四）平均受教育年限持续提高，人口素质持续提升。2025年1%人口抽样调查数据显示，莆田市16-59岁劳动年龄人口平均受教育年限为10.55年，比2020年的10.07年提高0.48年。25岁及以上人口受高等教育比重为11.1%，比2020年的10.6%提高0.5个百分点，人口素质持续提升。

（五）就业人员总量有所下降，就业结构不断优化

2025年末，全市就业人员总量为151万人，比2024年末减少2万人。分城乡看，城镇就业人员106万人，比上年末增加1万人，占比达到70.2%，比上年末提升1.6个百分点。乡村就业人员45万人，比上年末减少3万人，占比为29.8%。分产业看，第一产业就业人员12万人，第二产业就业人员56万人，第三产业就业人员83万人，就业结构由上年末的8.5:37.9:53.6调整为7.9:37.1:55.0，第一、二产业就业人员向第三产业转移，为莆田市新型工业化和现代服务业的发展输送人力资源。

二、需关注的问题

（一）人口老龄化日益突显，社会抚养负担加重。2025年末，60岁及以上老年人口66.7万，比2020年全国第七次人口普查的57.8万增加了8.9万；老年人口占比为21.0%，比全省平均水平高1.5个百分点，比2020年的18.0%提高3.0个百分点，老龄化程度进一步加深。在60岁以上人口中，60-64岁人口占比29.2%，比全省平均水平低3.0个百分点，占比居全省末位，老年人口年龄结构没有优势，养老压力逐年增加。

（二）出生人口持续减少，自然增长率进一步下降。随着育龄女性人数减少及生育意愿下降，2025年，全市常住人口出生率4.39‰，创下历史新低，比全省平均水平低0.98个千分点，比2020年七人普时的8.84‰低4.45个千分点，除2024年因龙年因素出生率有所回升外，出生率呈现逐年下降趋势。随着出生率不断下降，我市自然增长率自2022年起由正转负，同步呈现除2024年外逐年下降趋势，人口自然负增长将成为常态。

（三）少儿人口大幅下降，人口红利进一步收缩。2025年末，0-15岁少儿人口60.3万，比2020年全国第七次人口普查的70.6万减少10.3万，比重由2020年末的22.0%逐年降低至2025年末的18.9%。少儿人口是未来的消费主力和劳动力，少儿人口的减少对未来的消费结构及产业结构都将带来重大影响。

（四）人口净流入规模小，产业拉动就业不足。2025年末，全市净流入人口0.15万人，机械增长率0.47‰，比全省平均水平低0.33个千分点。从就业情况看，我市传统支柱产业多为劳动密集型工业企业，但2025年末第二产业就业人员同比下降2万人，产业拉动就业不足。从职工薪酬看，2024年全市城镇非私营单位就业人员年平均工资92907元，居全省第八位，对流动人口吸引力不足。

三、相关建议

（一）加快健全养老服务体系，丰富养老照护模式。多渠道发展养老服务，强化社会、市场、家庭贯通协调，健全养老服务体系层次。一是大力发展社区养老服务。推动新建小区将社区养老服务作为标准配套服务，老旧小区设立片区养老服务点，让养老服务网格化。二是丰富养老照护模式，推行日托、短托等多种模式，让老年人从心理上更容易接受养老机构服务，同时减轻家庭照护负担。三是推动医养结合。强化养老机构和医疗卫生服务机构协同配合，鼓励医养市场化，丰富养老服务供给。

（二）加快完善生育支持政策体系，提升育龄家庭生育意愿。生育意愿受到就业、住房、教育、托育等多方面因素影响，只出台生育补贴等直接刺激政策不足以显著提升生育意愿，需多部门多体系协同共进，减轻生育带来的各方面负担。幼儿照护负担重是当前影响生育意愿的重要原因之一，着力发展托育服务，规范托育行业标准完善监管体系，丰富托育服务供给类型，增加临时托、计时托、周末托等服务供给，充分匹配不同的托育需求。推动社区托育点建设，鼓励有条件的企事业单位开办托育点，减轻育龄家庭照护负担，提升生育意愿。

（三）强化产业吸纳就业，推动人口集聚规模扩大。进一步推进产城人深度融合，构建产业升级、人口集聚、城镇发展良性互动机制。一是强化产业链集聚功能。依托龙头企业吸引产业链上下游新兴产业主体，创造更多就业岗位，推动人口集聚。二是健全新市民服务体系。对新市民给予职业技能培训、就业服务、创业扶持、子女入学保障、医疗绿色通道等方面优惠政策，吸引流动人口定居。保障有稳定就业的外来务工人员及其家属尽快安家落户，以企业为单位集中申报新市民优惠政策，探索将带动就业人口安家落户纳入企业奖励扶持政策考量指标。三是加强城市宜居建设。优化城市空间布局，完善社区功能，尤其要增强产业集聚区生活要素分配，使新市民在短距离内便捷获取生活所需各类资源，增强城市吸引力和归属感，吸引人才、留住人口。
