2017年1-9月份莆田市规模以上工业运行分析

第六十七期
发布时间：2017-10-19 16:02
| | |

今年以来，我市扎实推进工业转型升级，积极应对经济下行压力，工业经济总体呈现稳中向好态势。

一、工业经济运行主要特点

（一）工业生产稳步回升。1-9月份，全市规模以上工业实现工业增加值706.92亿元，可比增长8.0%,高于全省平均水平0.1个百分点，分别比1-8月、1-7月回升0.1个和0.2个百分点，逐月回升态势初现，增幅位居全省第四。

（二）工业经济主要先行指标稳步提升。1-9月，全市工业用电量累计增长11.2%（扣除抽水蓄能后），增幅位居全省第一位。其中，制造业工业用电量明显回升，1-9月累计增长12.6%，增幅分别比1-8月、1-7月和1-6月回升了2.9个、4.8个和4.4个百分点。工业增值税降幅逐月收窄，1-9月全市工业增值税同比下降9.7%，降幅分别比1-8月、1-7月、1-6月收窄2.4个、3.2个和3.1个百分点。

（三）工业企业景气指数和企业家信心指数持续保持在“较为景气”区间。调查结果显示，三季度企业景气指数为123.1，比二季度低2.4关个点，持续运行在较为景气区间，其中，反映企业当前景气状态的即期企业景气指数为122.6，比二季度低4.3个点。反映企业未来景气预判的预期企业景气指数为123.4，比二季度低1.1个点。三季度企业家信心指数为122.2，比二季度低4.0个点。

（四）重点产业贡献突出，主要产业持续保持较快发展。1-9月，全市重点培育的7个制造业产业实现工业增加值583.76亿元，增长10.0%，对规模以上工业经济增长的贡献率为94.6%，拉动全市规上工业经济增长7.6个百分点。

一是传统制鞋产业转型加快。1-9月，制鞋产业实现工业增加值182.32亿元，增长14.5%，对规模以上工业经济增长的贡献率为37.6%，拉动规模以上工业经济增长3.0个百分点。鑫龙、双驰、永丰、力奴、辉特等重点鞋业龙头企业，中长期订单稳定，带动制鞋产业快速增长。1-9月， 62家市级鞋业龙头企业实现工业增加值82.61亿元，增长20.2%，占全市制鞋产业总量的45.3%，拉动制鞋产业增长8.2个百分点。鞋业供应链服务平台正式运营，加快我市制鞋资源的整合，为企业降本增效提供有力平台保障，目前该平台已入驻企业200多家。

二是“33”产业保持稳定增长。1-9月，全市“33”产业实现工业增加值401.44亿元，增长8.1%，对规模以上工业经济增长的贡献率为57.0%，拉动规模以上工业经济增长4.6个百分点。其中，化工新材料和食品加工保持较快增长， 1-9月，化工新材料实现工业增加值105.95亿元，增长16.7%，拉动全市规上工业经济增长1.9个百分点。食品加工产业实现工业增加值87.64亿元，增长14.2%，拉动全市规上工业经济增长1.4个百分点。

（五）园区工业企业贡献近七成。全市园区规模以上工业企业752家，占全市规上工业企业数的59.4%，累计实现工业增加值492.39亿元，增长7.5%，占全市规模以上工业增加值的69.7%，对规模以上工业经济增长的贡献率为67.2%，拉动规模以上工业经济增长5.4个百分点。

（六）工业企业转型升级稳步推进。1-9月，全市战略性新兴产业实现工业增加值158.76亿元，增长13.6%，对规模以上工业经济增长的贡献率为31.3%，拉动规模以上工业增加值增长2.5个百分点。高技术企业实现工业增加值52.15亿元，增长8.8%，比1-8月提高0.4个百分点，对规模以上工业经济增长的贡献率为7.8%，拉动规模以上工业增加值增长0.6个百分点。装备制造业增加值99.05亿元，增长3.6%，对规模以上工业经济增长的贡献率为9.2%，拉动规模以上工业增加值增长0.7个百分点。

（七）亿元企业增势强劲贡献突出。1-9月，全市超亿元以上规模企业527家，比上年同期多33家，占规模以上工业企业单位数的41.6%。实现工业增加值612.77亿元，增长15.2%，占全市规上工业增加值总量达86.7%，对规模以上工业经济增长的贡献率为129.7%，拉动规模以上工业增加值增长10.4个百分点。

（八）省级高成长和龙头企业引领带动作用突出。1-9月，全市高成长和省级龙头企业实现工业增加值168.66亿元，增长24.3%，增幅高于规模以上工业增加值平均增速16.3个百分点，对规模以上工业经济增长的贡献率为48.8%，拉动规模以上工业增加值增长3.9个百分点。

（九）新增企业增添发展新动力。1-9月，全市新增工业企业共拉动规模以上工业经济增长1.5个百分点，成为工业经济发展新的增长极。其中，70家规下转规上企业实现工业增加值11.80亿元，增长90.1%，对规模以上工业经济增长的贡献率为7.4%，拉动全市规模以上工业经济增长0.6个百分点。其中赛博思、众翔鞋业、启丰鞋业等企业贡献突出。去年以来31家新投产工业企业实现工业增加值11.54亿元，增长286.3%，对全市规模以上工业经济增长贡献率为11.0%，拉动规模以上工业经济增长0.9个百分点，其中中粮华港、华锦实业等企业拉动作用较为明显。

二、存在问题

（一）规上工业停、减产面小幅回升。9月末，全市停、减产面达29.4%，比8月末提高0.3个百分点，共拉低全市增幅4.9个百分点。受环保整治力度的不断加强和企业产能淘汰等因素影响，本月我市停产企业增加明显，9月末，全市停产企业145家，比上个月增加22家，影响工业增加值35.59亿元，拉低全市工业增幅3.6个百分点；9月末减产企业228家，比上个月减少17家，影响工业增加值12.96亿元，拉低全市工业增幅1.3个百分点。

（二）工业经济面临下行压力加大。从工业景气调查结果显示，工业企业景气指数和企业家信心指数虽保持在“较为景气”区间，但相关指数呈现逐季回落的态势。三季度，企业景气指数分别比二季度、一季度回落2.4点和5.6点。企业家信心指数分别比二季度、一季度回落4.0点和6.1点。从工业经济效益看，全市工业经济效益综合指数349.42，分别比1-7月、1-6月和1-5月低4.13个、9.39个和8.44个点。1-8月全市实现利润总额115.42亿元，增长5.6%，低于全省平均水平11.5个百分点。从企业生产成本看，1-8月每百元主营收入成本为88.05元，比上年同期增加0.53元； 主营业务收入利润率为5.6%，比上年同期低0.4个百分点。

（三）传统工艺与创意产业不景气。1-9月全市工艺与创意产业增加值累计增长0.1%，增幅比上年同期回落10.6个百分点。受行业不景气和石雕企业整治影响，9月末，全市工艺与创意产业停产企业45家，比8月末、7月末和6月末分别增加11家、21家和29家。

（四）大项目投产、入库进度偏慢。华佳彩、云度新能源汽车等企业都未进入统计名录库。鞍钢冷轧虽恢复生产，但设备还处于调试期，产量较少，产能还未发挥。

（五）存量企业、民营工业增长动力不足。1-9月，全市规上工业存量企业工业增加值683.58亿元，增长5.9%。规上民营工业实现工业增加值537.07亿元，增长7.1%。存量企业与民营工业增加值增幅分别低于全市规上工业增幅2.1个和0.9个百分点。

                                         撰稿：蔡雨芳
