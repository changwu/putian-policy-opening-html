2014年1-2月份莆田市固定资产投资运行情况简析

发布时间：2014-03-14 00:00
| | |

1-2月份全市全社会固定投资178.50亿元，增长29.0%，其中固定资产投资（不含农户，下同）完成176.96亿元，增长29.4%，增幅位居全省第三位，比全省平均水平高6.9个百分点；在固定资产投资中：项目投资完成140.87亿元，增长27.2%，增幅位居全省第二位，比全省平均水平高8.8个百分点；房地产开发投资完成36.09亿元，增长39.1%，增幅位居全省第五位，比全省平均水平高5.6个百分点。

一、主要运行情况及亮点

（一）各县（区）、管委会出现全面增长的良好态势

1-2月份，得益于涵江港临港产业园陆域形成工程、福建莆田南日岛40万千瓦海上试验风电场项目、福建莆田白鹤风电场项目、湄洲湾第二发电厂、东吴港区罗屿作业区、瑞峰工业园区基础建设（道路及排污管道建设）等项目的强劲拉动，各县区出现全面增长的良好态势。（见表一）

（二）工业投资增势强劲，引领全市投资增长

1-2月份，我市工业投资完成55.88亿元，增长56.7%，增幅位居全省第一，高出全省平均水平39.0个百分点，占固定资产投资的比重为31.6%，对固定资产投资的贡献率为50.2%。其中：制造业投资支撑作用明显，完成投资42.26亿元，增长84.3%；电力、燃气及水的生产和供应业完成投资13.62亿元，增长7.5%。工业投资中重工业完成投资17.61亿元，下降8.5%；轻工业完成投资38.27亿元，增长133.1%，占工业投资的比重比去年同期上升22.4个百分点，对工业投资的贡献率高达108.1%，工业投资结构日益优化。

（三）从分产业看，二产是我市投资增长的主动力，对固定资产投资的贡献率达60.4%

1－2月份，我市第二产业完成投资61.52亿元，增长65.4%，增幅比同期固定资产投资快36.0个百分点，比一、三产分别快21.3和50.2个百分点，占固定资产投资的比重为34.8%，投资比重比上年同期提升7.6百分点，对固定资产投资的贡献率达60.4%，其中制造业投资、电力、热力、燃气及水的生产和供应业及建筑业对第二产业投资的贡献率分别达到79.5%、3.9%和16.8%。

（四）从分经济类型看，民间投资继续担当我市投资的主角，投资的自主性进一步增强

1－2月份，我市民间投资完成92.39亿元，增长38.0%，增幅比同期固定资产投资快8.6个百分点，占固定资产投资的比重为52.2%，投资比重比上年同期提升3.2个百分点，对固定资产投资的贡献率高达63.3%。其中500万元以上项目完成民间投资60.03亿元，增长37.4%，对民间投资的贡献率为64.2%；房地产开发投资完成民间投资32.36亿元，增长39.2%，对民间投资的贡献率为35.8%（见表二）。

（五）房地产开发投资和商品房销售面积、销售额持续增长

 1-2月份，我市房地产开发投资完成36.09亿元，增长39.1%，增幅比同期固定资产投资快9.7个百分点。全市商品房销售面积47.17万平方米，增长26.3%；商品房销售额达38.53亿元，增长30.8%。

二、存在问题

（一）各县（区）发展不均衡。从分县（区）看：1－2月份，我市各县（区）固定资产投资增长不均衡，增幅最高的与最低的相差233.5个百分点。其中增幅居全市最后一位的是仙游县，增幅比去年同期下降15.8个百分点，增幅比全市平均水平低19.5个百分点；城厢区、涵江区的增幅也比全市平均水平低，分别低16.2、2.7个百分点。

（二）亿元在建项目支撑乏力。1-2月份，在500万元以上项目投资中，我市共有亿元在建项目143个，亿元项目完成投资50.58亿元，下降0.5%，比同期固定资产投资慢29.9个百分点，占同期固定资产投资的比重为28.6%。 

（三）投资质量下降，投资结构矛盾依然突出。一是高新产业投资出现下降。1－2月我市高新产业完成投资2.71亿元，同比下降11.7%，占固定资产投资的比重仅为1.5%，投资比重比上年同期回落0.7个百分点。二是投资过分依赖房地产。1－2月，我市房地产开发投资占第三产业投资的比重高达32.4%，对第三产业投资的贡献率高达69.1%。
