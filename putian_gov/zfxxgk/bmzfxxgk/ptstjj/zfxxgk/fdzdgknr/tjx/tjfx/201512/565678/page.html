2015年莆田市基本单位现状分析

发布时间：2015-12-07 00:00
| | |

基本单位是各类法人单位、产业活动单位的总称，包括机关、事业单位、企业、社会团体等，是社会经济活动最基本的单元，其规模、结构、行业分布，一定程度上反映一个地区的经济社会发展水平、规模和产业结构情况。基本单位名录库建设是国家统计局提出的“四大工程”建设之基础，是开展各项统计调查工作的单位字典库和抽样框，有效推进名录库建设，对“提高统计能力、提高统计数据质量、提高政府统计公信力”具有十分重要的意义。

一、现状和主要特点

（一）基本单位总量不断扩大。2015年末，全市共有法人单位29166个，产业活动单位6682个，分别比2014年末增长71.9%和54.7%。在法人单位中，企业法人22544个、事业法人1698个、机关法人572个、社会团体1150个、其他法人单位3202个。其中，企业法人数比上年末增长72.0%。

（二）制造业、批发零售业成为经济规模发展壮大的主力军。全市法人单位行业分布主要集中在制造业、批发零售业、公共管理和社会组织等三个行业，2015年末，三个行业法人单位数分别占全市法人单位数的比重为24.2%、26.8%和16.1%。其中，制造业、批发零售业两个行业比重达51.0%，占全市经济规模的半壁江山（详见表1）。

（三）第三产业企业比重上升，服务业部分行业发展活跃。2015年末，第三产业企业数（不含公共管理和社会组织）14469个，比2014年末增长84.1%，增幅高于第二产业增长35.0个百分点，占全部法人单位数的比重为65.7%，比2014年末提高19.4个百分点，成为全市产业规模发展的主动力。交通运输仓储和邮政业等部分服务业行业发展活跃，增幅均超过30%。其中，交通运输仓储和邮政业比上年末增长68.3%；批发零售业增长117.1%；住宿和餐饮业增长30.9%；租赁和商务服务业增长124.1%。

（四）区域分布趋于分化,县区间发展差异较大。2015年末，荔城、仙游、城厢法人单位数占全市法人单位数的比重超过20%，分别为24.5%、22.6%、20.5%，而北岸、湄洲岛比重不足5%。荔城、仙游法人单位数增速超过全市平均水平，分别达到146.6%、87.7%，分别比全市平均水平高74.6%和15.7%（详见表2）。

二、存在主要问题

（一）基本单位总量较低。2015年末，全市法人单位数仅占全省法人单位数的4.8%，比龙岩低0.3个百分点，占比居全省九设区市末位（详见下表），基本单位数总量低不利于我市经济进一步发展。

（二）“四上”企业总体偏小。2015年末，全市统计的“四上”企业总数为2577个，仅占全市法人单位数的8.8%。其中，规模以上工业企业1177个，占全部工业法人单位数的16.1%；资质以上建筑业企业271个，占全部建筑业法人单位数的27.9%；资质等级以上房地产开发企业209个，占全部房地产开发企业数的33.0%；限额以上批发和零售业企业682个，占全部批发和零售业法人单位数的8.7%；限额以上住宿和餐饮业企业65个，占全部住宿和餐饮业法人单位数的18.3%；规模以上服务业企业173家，占全部服务业法人单位数的3.1%。
（三）产业结构有待进一步优化。从统计的“四上”企业情况看，2015年末，第三产业（包括房地产开发业、限额以上批发零售业、限额以上住宿餐饮业、规模以上服务业）企业总数为1129个，比第二产业（包括规模以上工业、资质建筑业）企业数少319个，第三产业企业数仍然偏少。从第三产业内部结构看，新兴服务业占比较低，其中交通运输仓储和邮政业仅占第三产业法人单位数的2.7%、信息传输计算机服务和软件业仅占1.8%、租赁和商务服务业仅占9.4%、居民服务和其他服务业仅占2.1%，第三产业内部结构不尽合理。

三、对策与建议

（一）完善产业链，提升产业吸引力。围绕我市十大产业集群特别是“33”产业发展营造良好的投资政策环境，加快产业链延伸，打造完善的产业链，推动处于产业链底层的个体小作坊向现代企业转变，吸引更多的企业落户扎根，切实加快全市基本单位总量的提升。

（二）做强做大重点企业，提升企业总体规模。大力培育行业龙头企业，特别是有特色、核心竞争力强的中小企业，发挥龙头企业的带动作用。建立和完善中小企业成长促进机制，加大扶持力度，鼓励企业改进技术，扩大规模、实施品牌战略，使企业不断发展壮大，提高全市上规模企业的总体数量。

（三）加快经济结构调整，促进产业优化升级。加大产业转型扶持力度，引导传统制造业由高耗能、劳动密集型向附加值高、技术含量高、耗能低的现代企业转型，坚决取缔高耗能、高污染、低效率的低增长方式企业。在巩固和提高商贸住餐等传统第三产业的基础上，大力发展金融、信息技术、电子商务、物流、文化、旅游等现代新兴服务业，推进全市产业结构优化升级。

（四）鼓励“个转企”，做大经济体量。各级政府要制定企业发展优惠政策，并做好宣传和指导工作，引导具有一定规模的个体工商大户“个转企”。各级各相关部门要用网格化管理的方式，摸清辖区内个体户底数，主动上门对接，做好宣传发动，引导具有一定规模的个体工商户实现“个转企，小转规”，特别是工商部门要引导经济实体注册法人企业，宣传法人企业优惠政策，高起点规范企业的经营，提升企业的竞争力，做到应统尽统，壮大全市经济总量。
