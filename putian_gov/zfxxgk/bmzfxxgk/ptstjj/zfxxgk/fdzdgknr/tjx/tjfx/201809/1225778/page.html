产业结构调整成效凸显

第五十四期
发布时间：2018-09-19 09:51
| | |

产业是国民经济可持续发展的支撑力量，也是社会和谐稳定的重要基石。习近平总书记指出：“产业结构优化升级是提高我国经济综合竞争力的关键举措。”产业结构的优化升级既依赖于经济的发展，又能推动经济自身的快速发展，改革开放以来，莆田市经济以较快的速度增长，与之相伴的也是产业结构的不断优化升级。

一、产业结构调整经历了四个阶段

改革开放以来，莆田市产业结构发生了一系列重大变化，呈现出由低级到高级、由失衡到基本合理的发展轨道。纵观从1978年到2017年四十年间莆田市的产业结构发展情况，大体可以划分为四个阶段：

1、第一阶段为1978－1984年的改革开放启动探索阶段。1978年，具有划时代意义的党的十一届三中全会胜利召开，中国确立实行对内改革、对外开放的伟大政策，此后中国人民进入了改革开放和社会主义现代化建设的新时期。农村实行家庭联产承包责任制，大大激发了广大农民的积极性，提高了劳动效率，有力的推动了第一产业的发展。1978-1984年，第一产业增加值从1.81亿元增加到4.92亿元，年均增长14.9%，比GDP高1.3个百分点；第二产业增加值从1.39亿元增加到2.98亿元，年均增长16.5%，比GDP高2.9个百分点；第三产业增加值从1.01亿元增加到1.98亿元，年均增长9.0%，比GDP低4.6个百分点。这一阶段， 第一产业比重上升，第二、三产业比重下降是第一阶段产业结构变动的特点（见表1）。

2、第二阶段为1985-2001年的社会主义市场经济体制初步建立阶段。从1985年开始，我国改革开放的重点由农村转向城市，这一阶段莆田市产业结构变动的特点是：第二、三产业比重持续上升、第一产业比重不断下降。1985-2001年，第二、三产业增加值年均分别增长17.8%和15.0%，而第一产业增加值年均仅增长6.1%；第二、三产业比重则分别由29.0%、24.0%上升到46.0%和35.6%，第一产业比重由47.0%下降到18.4%（见表2）。

3、第三阶段为2002-2012年的社会主义市场经济体制初步完善阶段。2002年，党的十六大召开，随后的十六届三中全会通过的《中共中央关于完善社会主义市场经济体制若干问题的决定》，提出了统筹兼顾的走科学发展道路。中国经济社会发展步入市场经济体制完善阶段。莆田市围绕加快发展，实施工业强市战略，全面振兴工业经济，工业生产增速明显加快，第一产业增加值年均增长4.1%，第二产业增加值年均增长17.8%，第三产业增加值年均增长12.3%。因此，第二产业比重快速上升，第一、三产业比重不断下降是这一阶段的特点（见表3）。

4、第四阶段为2013年至今的全面深化改革阶段。2012年党的十八大提出了全面深化改革，党的十八届三中全会审议通过的《中共中央关于全面深化改革若干重大问题的决定》，提出了全面深化改革的指导思想，这是在新的历史起点上全面深化改革的科学指南和行动纲领。我国经济发展开始进入新阶段，经济思路发生重要转变，开始启动实施供给侧结构性改革，注重“扩大总需求”与“供给侧改革”并重，经济全面步入转型升级发展期；这一时期，莆田经济同样遇上增长速度换挡期、结构调整阵痛期和刺激政策消化期“三期”叠加的新状态，经济增长出现回落态势，2013-2017年莆田经济年均增速10.4%，明显低于前三个阶段；但产业结构呈现不断优化升级的态势，支撑经济增长的动力逐步由要素驱动、投资驱动向创新驱动转变。

二、三次产业结构变化的一些特征

1、三次产业结构发生显著变化。第一产业的增加值比重由1978年42.9％下降到2017年的5.5％，降低了37.4个百分点，第二产业和第三产业增加值比重由1978年的33.1％和24.0％，分别提高到2017年的53.1％和41.4％。从总的趋势看，第一产业比重呈现持续降低的态势，第二、三产业比重明显提高。第二、第三产业的结构变化却在不同的时期有所差异。第三产业比重增长最快的是发生在“九五”期间，比重提高了5.3个百分点，年均增速比第二产业加快11.0个百分点。“八五” 时期，第三产业比重出现下降，下降了2.7个百分点；“十五” 、“十一五”时期，第三产业比重分别下降了0.6个百分点和0.7个百分点。自2012年到“十三五”头二年，二产比重步入了下降的趋势，三产比重逐步提升。

2、第二产业（尤其是工业）是拉动经济增长的主要力量。自1991年以来，第二产业对GDP的贡献率基本上在50%以上，两个高峰年出现在1994年和2006年，分别达到76.5%和67.7％；第三产业对GDP的贡献率高峰年出现在1997年，贡献率达61.9％。如果将GDP的增长速度与第二、第三产业比重的变化综合起来分析（见下图），可以发现，第三产业比重显著增加的时期，基本上是出现在经济景气回落的时期，而第二产业比重出现明显上升，推动了经济进入新一轮的增长周期。

                                                                                                                        

3、第三产业内部结构优化。从近十年第三产业内部各行业比重变化情况来看，上升的行业依次为金融业、房地产业和营利性服务业；比重下降的行业有交通运输邮政业、批发零售住宿餐饮业和非营利性服务业（见表6）。

三、三次产业结构演变的特点

1、三次产业结构的演变基本符合世界范围产业结构的演变规律，即第一产业比重下降，第二、三产业比重上升。具体来说，第一阶段的转换，即由第一产业向第二产业的转换已基本完成；第二阶段的转换，即由第一产业比重下降，第二产业比重基本不变，而第三产业开始上升,这个阶段的转换，则正在进行中；第三阶段的转换，即第一产业比例继续下降到低水平，第二产业比例也逐步下降，而第三产业比重上升到较高水平，这个阶段的转换则尚未出现。综合起来看，现阶段莆田的三次产业结构的转换过程处于中后期，第三产业比重还偏低。

2、第二产业尤其是工业增加值的增长成为莆田经济快速增长的主要动力之一。改革开放以来，产业结构演变的结果，实现了国民经济总量增长从主要由第一、二产业带动转为主要由第二、三产业带动，尤其是第二产业中的工业增长成为莆田经济快速增长的主要动力。

3、产业结构逐步走向融合发展。近年来，面对不利的国际经济环境，积极引领新常态，推进供给侧结构性改革，促进经济转型升级，经济实现中高速增长。莆田在2012年后经济发展开始转型，进入全面深化改革新阶段。第二产业占地区生产总值比重逐步下降，由2013年的58.0%下降为2017年的53.1%，第三产业占比逐年提高，由2013年的34.3%，上升到2017年的41.4%。三次产业结构由2013年的7.7:58.0:34.3演进为2017年的5.5:53.1:41.4，第三产业比重进一步提升，产业结构更加优化，一二三产业出现融合发展的新态势。
