1—5月份我市规模以上工业运行分析

发布时间：2012-07-05 00:00
| | |

今年以来，尽管宏观经济环境复杂严峻，我市工业企业依然保持了平稳较快的发展态势。1-5月份我市规模以上工业实现工业总产值728.29亿元，可比增长17.2%，增幅虽然比上年同期回落4.1个百分点，但比1-4月份高0.1个百分点，比全省平均水平高1.9个百分点，连续三个月位居全省九设区市第三位。实现规模工业增加值229.36亿元，比上年同期增长16.6%，比全省平均水平高1.9个百分点，增幅居全省九设区市第五位，比4月份第六位前移一位，工业经济呈现稳步增长态势。

一、工业运行的主要特点

（一）工业对GDP贡献不断加大。1-5月份，全部工业累计实现增加值253.19亿元，占GDP比重约60.2%，较去年底提升了9.8个百分点，增幅高出同期GDP增幅2.5个百分点，对GDP增长贡献率达71.1%，比去年底提升7.6个百分点，拉动经济增长8.7个百分点。工业仍发挥着促进经济增长“挑大梁、主力军”的作用。

（二）轻工业发展快于重工业。1-5月份我市轻工业企业实现工业总产值511.78亿元，比上年同期增长20.9%，重工业实现工业总产值216.50亿元，比上年同期增长9.5%，轻工业增长快于重工业11.4个百分点，说明目前我市规模以上工业发展仍以轻工业为主。

（三）小微企业逆势上扬。小微企业是扩大就业、改善民生、激活民间活力、促进社会和谐稳定的有效途径。在工业经济增速总体放缓的大背景下，小微工业企业发展逆势上扬，成为全市工业经济发展的一大亮点。1-5月份我市规模以上小微企业实现工业总产值393.65亿元，比上年同期增长19.4%；大中型工业企业实现工业总产值334.64亿元，增长14.8%，小微企业增长快于大中型企业4.6个百分点。

（四）股份制企业起主要拉动作用。1-5月份规模以上工业各经济类型中股份制企业完成工业总产值388.45亿元，占规模以上工业的53.3%，比上年同期增长23.7%，比全市规模以上工业平均水平高6.5个百分点，对规模以上工业增长的贡献率为68.8%，拉动规模以上工业增长11.8个百分点。外商及港澳台商投资企业、国有企业、其他经济类型企业、股份合作企业和集体企业分别实现工业总产值237.06亿元、45.31亿元、38.87亿元、11.26亿元和7.35亿元，分别增长10.7%、-2.0%、23.7%、5.9%和43.9%。

（五）家具制造业引领增长。 1-5月份全市32个工业行业大类中，有26个行业产值实现正增长，纺织、木材、家具制造等13个行业增幅快于全市平均水平，共完成工业总产值334.99亿元，同比增长40.0%，拉动规模以上工业增长11.9百分点。其中，家具制造业增幅最高，达145.2%，工艺及体育制造业对工业贡献率最大，达23.9%，拉动工业增长4.1个百分点。

（六）工业投资增长较快。1-5月全市工业固定资产投资完成110.68亿元，同比增长18.9%，其中制造业固投完成92.48亿元，同比增长26.1%。其中，新增长区域发展战役86个工业类项目完成投资76.4亿元，完成年计划的46.2%，发挥了强有力的拉动作用。鞍钢、皇冠易拉罐、忠门风电等3个项目已投产，华源工贸生产项目部分机械设备开始试产，海安巨型工程子午线轮胎、差别化化学纤维生产项目、海宏木业、福人中密度纤维板林板、中海石油深冷精细胶粉项目等一批在建项目投资速度加快，超序时进度建设。

（七）运行质量不断提高，利润高速增长。1-4月份，全市规模以上工业企业经济效益综合指数为293.32，比上年同期提高52.97个点，比全省平均水平高58.94个点。1-4月由于中海福建天然气责任有限公司、福建佳通轮胎有限公司、雪津啤酒等大企业利润成倍增长的拉动，我市规模以上工业实现利润总额246.13亿元，比上年同期增长84.8%，比全省平均水平高76.4个百分点；上缴税金总额138.43亿元，增长26.0%，比全省平均水平高3.1个百分点，工业运行质量向好。

 二、当前工业经济运行中需要关注的问题

（一）工业经济发展环境形势严峻。当前，欧美市场整体商业环境疲软、人民币对美元汇率升值预期下降、生产要素成本不断上升，导致外贸企业不敢接中长期定单，造成外销生产企业的不确定性，直接影响我市工业经济进一步增长。特别是作为我市产业老大的制鞋业受冲击最大，今年订单较往年直线锐减。1-5月份我市217家规模以上制鞋企业实现工业总产值164.15亿元，增长12.7%，但增幅比上年同期回落7.5个百分点；出口交货值82.41亿元，增长14.7%，增幅比上年同期回落16.5个百分点。1-4月份利润总额比全市规模以上工业平均水平低60.6个百分点，比上年同期低33.4个百分点。据调查不少出口型制鞋企业由于承受不了原料上涨、人民币升值等多方面的压力，纷纷考虑转行，或向内地转移。4月末全市规模以上制鞋企业停产达30家，比上年同期增加27家；从业人员10.25万人，比上年同期减少近万人，下降6.9%。“鞋老大”如何度过“寒冬”将直接影响我市工业的可持续发展。

（二）生产要素供给紧张，企业资金面临考验。今年以来用工成本上涨20%以上，如新威电子工业公司因用工成本上升，计算器生产线部分转移到外省，引起本地产能减少、用电量下降。同时银行贷款有限，我市大部分商业银行执行最高利率，使我市中小企业获取银行贷款综合成本上升幅度达13%以上。同时部分生产资料、原材料价格不断上涨等多种因素共同制约，严重压缩了企业利润空间，加之引进技术、更新设备等原因产生的资金缺口，企业流动资金普遍紧张。

（三）工业产业结构不够优化。由于我市工业产业结构单一，增长方式粗放，工业经济发展受制于LNG等国企老大生产的影响十分明显。1-5月份由于LNG等企业生产下滑，重工业增长低于轻工业11.4个百分点，各经济类型中国有企业发展也受LNG影响比上年同期下降2.0%，说明我市工业结构严重失调，工业经济发展的压力不断加大。而且新技术产业项目企业偏少，产业技术含量还不高。企业对科技研发投入较低，缺乏创新人才，在自主创新、产学研合作等方面进展缓慢，市场竞争能力和抗风险能力薄弱。

（四）县区之间发展不平衡。由于产业结构发展不平衡，各县区工业总产值增长差距越来越大，1-5月份增长最快的仙游与北岸相差34.3个百分点。分县区看：1-5月份仙游实现工业总产值104.41亿元，比上年同期增长28.6%；北岸实现工业总产值5.76亿元，增幅受太平洋火电厂影响下降5.7%；秀屿区实现工业总产值114.49亿元，增长17.8%；荔城区实现工业总产值141.53亿元，增长17.4%；涵江区实现工业总产值278.15亿元，增长14.1%。

（五）工业发展后劲不足。5月末我市仅有18家新投产工业企业，实现工业总产值5.13亿元，户均产值2850万元，仅拉动规模以上工业增长0.6个百分点，缺乏新投产大企业，工业发展后劲不足。同时重点项目推进与预想的有较大差距。不少项目因受到资金缺乏、用地指标不足等因素制约难以按计划开工建设，影响了全市经济总量的提升。

综上所述，今年我市工业经济整体运行在一个平稳较快的轨道区间，但增长的下行压力不断加大， 1-5月份工业总产值仅占全年计划的36.4%，差序时5.3个百分点。我市现有规模工业企业数877家，停产的企业达85家，平均每个企业需完成2.5亿元产值，才能完成全年2000亿元目标，而且作为工业经济增长“晴雨表”的工业用电量1-5月份下降0.1%，要完成全年及上半年“双过半”的目标任务压力很大。预计上半年完成工业总产值870亿元左右，比增17.2%左右;实现工业增加值280亿元左右，比增16.7%左右。为了保证完成上半年及全年任务，全市上下要积极落实国家、省、市有关政策，出台对应扶持措施，努力保持我市工业的持续平稳增长。
