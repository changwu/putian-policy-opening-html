莆田市上半年民间投资情况简析

第四十二期
发布时间：2017-07-19 15:39
| | |

上半年，全市民间投资完成662.07亿元，同比增长18.1%，增幅比上个月、上年同期、上年全年分别提高1.0、12.0、6.8个百分点，占固定资产投资比重为57.8%，对固定资产投资的贡献率56.3%，同比提高21.6个百分点。

从内部结构看：从固定资产投资内部结构看，项目民间投资占比大，增速高，上半年全市民间投资中：项目民间投资完成513.28亿元，同比增长22.6%，增速比全市固定资产投资高3.9个百分点，占全市民间投资比重为77.5%，同比提高2.8个百分点；房地产民间投资完成148.79亿元，同比增长4.9%，占全市民间投资比重为22.5%。

分产业看：第一产业民间固定资产投资15.73亿元，同比增长43.7%；第二产业民间固定资产投资253.31亿元，同比增长38.1%；第三产业民间固定资产投资393.03亿元，同比增长7.3%。

分行业看：从分行业投资情况来看，我市民间投资主要集中在房地产业、制造业、水利、环境和公共设施管理业。上半年，三者合计完成民间投资530.45亿元，同比增长16.1%，占全市民间投资的比重达80.1%。其中，制造业完成民间投资246.11亿元，同比增长36.3，占全市民间投资的37.2%，占比同比提升5.0个百分点，房地产业完成民间投资174.73亿元，同比下降0.3%，占全市民间投资的26.4%，占比同比下降4.9个百分点，水利、环境和公共设施管理业完成投资109.60亿元，同比增长8.4%，占全市民间投资的16.6%，占比同比下降1.5个百分点。

从资金来源看：上半年民间投资到位资金782.52亿元，同比增长10.3%，增速比全市固定资产投资低8.4个百分点。其中项目投资到位资金486.05亿元，同比增长15.3%，房地产开发到位资金296.48亿元，同比增长3.0%。全部到位资金中：国家预算资金30.62亿元，同比下降15.4%，占全部到位资金的3.9%；国内贷款54.65亿元，同比增长14.4%，占全部到位资金的7.0%；自筹资金471.57亿元，同比增长4.6%，占全部到位资金的60.3%；其他资金来源85.95亿元，同比增长20.7%，占全部到位资金的11.0%。

意见建议：要更深入贯彻落实国家和省里各项促进民间投资的政策措施，配套出台民间投资实施细则，从放宽市场准入、拓宽融资渠道、加大财税扶持、优化行政服务等方面促进民间投资健康有效的发展。
