1—7月莆田市建筑业运行情况简析

发布时间：2013-08-26 00:00
| | |

一、1-7月莆田市建筑业运行基本情况

建筑业生产继续快速增长。1-7月，我市建筑企业克服原材料涨价、拖欠工程款等多种不利影响，建筑业各项主要指标继续保持上升趋势。按注册地口径，1-7月全市具有建筑业资质的企业（不含劳务分包建筑企业）共161家，同比增加14家；累计完成建筑业总产值158.93亿元，同比增加48.06亿元，增长 43.3%，增幅位居全省第一。1-7月省外入莆施工企业累计完成建筑业总产值68.41亿元，同比增长53.0%。

二、1-7月莆田市建筑业发展的主要特点

（一）建筑业总产值增幅高开低走，上半年以来增幅略有上升

今年以来建筑业总产值增幅呈逐月下降的趋势，1月、1-2月、1-3月、1-4月、1-5月累计增幅分别为111.5%、51.4%、44.7%，40.0%，36.3%，1-6月、1-7月增幅分别为39.6%和43.3&，呈现上升趋势。

（二）建筑业结构继续调整

建筑工程产值所占比重提高。在全部建筑业总产值（按注册地）中，建筑工程产值占有较大的比重。1-7月，全市资质建筑企业建筑工程产值累计完成156.49亿元，比上年同期增长46.7%，占全部建筑业总产值的比重为98.5%，同比提高2.3个百分点。

多种形式承包广泛有序推进。建筑业市场规范化建设进一步深入，以招投标承包制为核心的多种形式的承包制在建筑行业广泛实行。1-7月，全市资质建筑企业实行投标承包面积2638.66万平方米，比上年同期增长30.2%，占全部房屋施工面积的93.8%，比上年同期提高了7.0个百分点。

非国有建筑企业成长速度加快。随着市场需求的变化和建筑市场竞争的加剧，非国有建筑企业综合能力和适应市场的能力都有显著提高，取得生产与效益同步增长的好形势。1-7月，全市资质以上非国有建筑企业累计完成建筑业总产值149.87亿元，比上年同期增长42.2%，占全部建筑业总产值的比重达到94.3%。

（三）建筑产业区域集中明显。按注册地口径，建筑业总产值前两名的县区是城厢区、荔城区，产值分别为57.51亿元和43.52亿元，两县区建筑业总产值占各县区建筑业总产值之和的63.6%；增长最快的县区是秀屿区、涵江区，涨幅分别为132.8%和 72.8%。近年来秀屿区、涵江区建筑业持续保持高速发展，主要得益于两地重点项目和基础设施的建设。

（四）市场竞争能力不断提高，进入增幅稳定期

近年来，莆田市施工企业在站稳本地脚跟的前提下，大胆实施走出去战略。1-7月莆田市建筑企业完成省外产值57.30亿元，增幅为36.0%，占全市建筑业总产值比重为36.0%。1-7月开拓占据省外建筑市场，涉及24个省市。其中江西、湖南两省产值分别为9.37亿元和7.44亿元，共占全市外拓总量的29.3%。

（五）住宅房屋在竣工房屋面积构成中占比最高

1-7月莆田市建筑企业房屋竣工面积为287.01万平方米，增长9.1%。其中，住宅房屋占总竣工面积的82.6%，厂房及建筑物占比11.3%，商业及服务用房屋占比3.0%，科研、教育、医疗用房屋占比2.9%，办公用房屋占比0.2%.

（六）建筑业发展压力有所减缓，后劲明显增强

1-7月，签订的合同额504.33亿元，同比增长41.8%，增幅较1-6月提高9.3个百分点，较上年同期下降25.0个百分点；本年新签合同额237.47亿元，同比增长81.7，增幅较1-6月提高22.9个百分点，较上年同期提高35.2个百分点。今年以来莆田市建筑行业发展压力逐月减缓，特别是本年新签合同额，上升较为迅速，为建筑行业增加强力后劲。

三、促进建筑业发展的几点建议

（一）调整产业结构，转变发展方式。进一步推动我市建筑业加快转型升级，调整产业结构，扩展外阜市场，加强企业科技进步和技术创新能力，进一步增强建筑业核心竞争力。实行跨行业、跨地区重组，快速增强实力，形成一批资金雄厚、人才密集，具有科研、设计、采购、施工管理和融资等能力的大型建筑企业，实现建筑业由数量型向质量型、劳动密集型向科技型、速度型向效益型、粗放型向集约型的转变。

（二）加大监管力度，规范市场秩序。建立健全建筑行业信用体系，逐步形成有效的信用监管和失信惩戒机制，有效规范建设市场各方主体的行为，保障行业持续健康发展。全面推行双向担保制度，维护承发包双方平等的主体权力。贯彻落实防新欠各项长效机制，确保各项目都能在规定时限内办理工程结算、决算，切实消除项目长期拖欠工程款造成企业发展的资金瓶颈。加强执法队伍建设，加大行政执法力度，进一步维护统一、开放、竞争、有序的市场秩序，促进建筑业健康发展。
