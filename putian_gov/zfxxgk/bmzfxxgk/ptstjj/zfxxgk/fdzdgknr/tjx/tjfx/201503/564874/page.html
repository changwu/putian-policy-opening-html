2014年全市城镇就业工作有序实施

发布时间：2015-03-02 00:00
| | |

2014年我市就业发展工作围绕城乡一体化目标，按照市委市政府的总体部署稳步推进，就业保障各项措施落实有力，就业三大指标持续向好。

一、基本情况

（一）就业保障各项措施有序推进

1、着力落实各项责任指标

一是社保五险综合增长率指标顺利落实。至12月底，全市城镇职工养老保险参保31.01万人，完成任务32.65万人的95.0%；医疗保险参保32.67万人，完成任务32万人的102.1%；失业保险参保25.33万人，完成任务24万人的105.5%；工伤保险参保39.63万人，完成任务39.42万人的100.5%；生育保险参保30.16万人，完成任务30万人的100.5%。城镇居民医疗保险参保人数30.59万人，提前4个月完成年度22万人的参保任务。城乡居民养老保险续保扩面涉及面广，全市参保人员达到150.24万人，续缴率达94.7%，在全省名列前茅，提前半年完成年度“续缴率达90%以上”的计划任务。二是促进就业责任指标得到保障。省政府下达我市责任指标，城镇登记失业率为3%。2014年我市把促进就业工作列入县区政府责任指标考核体系，各项就业指标全面完成。全市城镇新增就业人员2.27万人，完成年度任务2万人的113.7%；城镇下岗失业人员再就业2386人，完成年度任务2200人的108.5%；就业困难人员再就业532人，完成年度任务450人的118.2%；新增农业富余劳动力转移就业3.21万人，完成年度任务3万人的107.0%。城镇登记失业率为2.0%，控制在省定目标3%范围之内。

2、着力推进人社改革创新

近年来，我市围绕城乡一体化综合改革，不断推进人社系统体制机制的改革创新。一是推进养老保险改革。2013年出台了《莆田市人民政府关于城乡居民养老保险制度一体化实施意见》，打破城乡居民二元结构，实现城乡居民养老保险在统筹范围、缴费标准和待遇水平上的均等统一，2014年基础养老金从原来的每人每年55元提高到70元，全市现有城乡居民养老金领取人数38.60万人；被征地农民养老保障金从每人每月90元提高到132元，享受待遇人数7898人；城镇企业职工养老金自2005年以来第10次大幅度提高，人均养老金达到1733.59元，较上年度提高150.65元，增幅9.5%，享受待遇人数3.98万人；2014年将失独家庭、村级主干、乡村医生等特殊群体纳入城镇企业职工养老保险，提升其养老保障水平，解除其后顾之忧。二是推进医疗保险改革。2014年调整完善《莆田市城乡居民合作医疗统筹补偿方案》，实现城乡居民医疗保险在统筹范围、缴费标准和待遇水平上的均等统一。为创新管理，市人社局还出台了医保“两定点”进出机制，实行医保定点机构“12分制”记分管理办法，有违法违规行为的相应扣减分值，达不到标准分值的退出定点，解决定点医疗机构只进不出的问题，对医保“两定点”机构套串换药等违规行为严加监管；全面推行医保付费改革，出台定点医疗机构“总额预付制”管理办法，有效控制医保基金支出增长，遏制各定点医院小病住院、小处分开成大处分等不良行为。同时，全面调整提高城镇职工医疗保险报销待遇，减少个人自付比例、大幅提升医保待遇水平、调整提高最高支付限额，政策调整后预计医保年统筹基金将多支出5100多万元。三是推进工伤保险改革。2014年我市调整出台了《莆田市工伤保险费率浮动办法》，实行新的浮动费率，我市还被列入国家工伤预防试点市。调整工伤保险费率，减轻了企业缴费负担，促进企业职工参保；调整工伤保险理赔办法，协调好与民事赔偿的冲突，增进企业参保积极性。同时，选定了5家工伤康复定点医院，推进工伤预防与康复工作。四是推进服务机制创新。推行行政服务审批“三集中”试点，市医保中心、社保直属中心成建制向市行政服务中心集中，逐步理清本部门管理和服务事项100多项，实行前后台管理，业务实行网上登记受理审批，直接授权窗口办理；推行“民生云--社保通”便民查询服务，实现互联网、智能手机、终端查询机多渠道个人自助查询参保缴费情况及待遇领取情况；推行城乡居民养老保险服务“不出村”，在全市972个行政村（居委会）设立986个城乡居民保便民服务点，实现“不出村”参保缴费、领取待遇；设立综合性社保卡服务窗口，为省内各地市中第一家，并实现就地制卡，推行“立等可取”制发卡服务，解决了社保卡制发卡缓慢的历史遗留问题；推进福莆宁岚医保同城化，2014年5月四地已签订同城化协议，预计明年4月份开始实行，方便我市医保参保人员跨地就医；开通16868006（电信）和118114-7（移动）两部热线电话，方便医保参保人员转院转诊和政策咨询；简化生育保险医疗费报销流程，实行社保卡直接刷卡结算；拓宽网络声讯信访渠道，方便群众咨询投诉，包括“12333”人社服务平台、“12345”政务服务平台、市人社局门户网站“问答公开”和“局长信箱”等。2014年市级共收到网络声讯平台诉求件896件，办结率达100%，大幅减轻传统渠道信访压力，群众诉求得到及时有效解决，积案得到化解，维护了社会稳定。

3、着力促进服务企业用工

在服务企业用工和促进就业上积极作为，创新方式，有效组织开展现场招聘、网络招聘、声讯招聘“三位一体”的劳动力市场供需对接模式，创新开展网络视频招聘。2014年举办各类招聘活动189场，参加招聘企业11712家次，成功招聘6.32万人。组织高校毕业生专场招聘会2场，参加企业282家，达到就业意向2977人次。组织校企协作大型招聘会，参加企业132家，职业院校12所，达到就业意向1400多人次，签订校企合作协议42份。与全国多个劳务协作基地建立经常性联系，2014年开拓广西南宁、百色等新的劳务合作基地，引进外来工3.01万人。完成农民工职业技能培训9542人。全市促进就业工作进展顺利，企业用工紧缺得到缓解，用工稳定。

我市注重提升职工职业技能，2014年我市共组织14场职业技能竞赛（其中5场为省一类竞赛），全市现有高级技师486人，技师2942人，建立了26个大师工作室，推行“师带徒”行动。全市建立42个职业技能鉴定站，每年鉴定3万人。在职业培训上，加强与职业院校、行业协会协作，建立了上塘珠宝、食品焙烤、油画等技工实训基地。

4、注重构建和谐劳动关系

我市重视抓好劳动监察工作，及时规范企业用工管理。2014年，共主动服务用人单位1723家次，涉及劳动者20.70万人次；受理举报投诉案件344件，已全部办结；审查用人单位规章475件，纠正违法规章205件。全市各类职工劳动合同签订率达96.3%，督促补签劳动合同1.40万份。高度重视解决企业工资拖欠问题，妥善预防和解决企业工资拖欠问题。一是强化工资保证金制度。全市共有60家建筑施工企业缴存了农民工工资保证金4470万元。二是及时处置集体欠薪案件。各县区政府按照工作要求，上下联运，及时落实应急预案，推行“一线工作法”，落实第一时间、第一现场化解措施，及时平息了13起因工资纠纷引发的群体性欠薪案件，维护了社会的安定稳定。三是持续开展欠薪预防和查处。针对春节后我市陆续发生规模以上企业集体欠薪事件，发出《关于进一步做好预防和妥善解决企业工资拖欠工作的通知》，进一步加强巡查排查，及时化解欠薪案件。全市共为4297名劳动者追发工资4937.00万元；向司法机关移送拒不支付劳动报酬案件14件，公安机关立案14件，判刑1人。

全市劳动仲裁机构积极面对新常态，认真分析新情况、新问题，不断探索新机制、新办法，加强业务研讨，与法院等相关部门密切沟通，树立依法行政理念，切实提高仲裁员处理能力，有效维护劳资关系和谐。全市立案受理劳动争议案件562件，涉及人员2121人，涉案金额2739.60万元，结案率达到100%。其中通过调解方式处理的311起，调解成功率达到55.3%，排在全省前列。

5、着力推进服务平台建设

针对全市人社系统服务窗口“散、旧、危”的状况，我市启动筹建市社会保障服务中心及人力资源市场项目，该类项目属于公共服务项目，主要是推进社保五险合一办公。市、县（区）社会保障服务中心建设持续推进，目前，市社会保障服务中心已完成用地审批手续；荔城区人社局已完成1400㎡服务中心改建工作，并投入使用；涵江区人社局服务中心已装修完毕，面积800㎡，预计年底前投入使用；秀屿区人社局服务中心正在新建，规模2500㎡；仙游县人社局规划新建，今明两年县（区）服务中心平台全部启动，秀屿区、涵江区、仙游县等服务中心建设经争取已列入国家专项补助项目。同时，推进镇村一级社会保障服务网点建设，涵江区和秀屿区乡镇劳动保障所全面按300㎡规模安排改扩建，仙游县的榜头、郊尾、枫亭、龙华四个镇按300㎡先行推行规范化建设。积极推进“幸福家园”试点村“就业与社会保障服务站”建设，每个服务站安排补助资金5万元予以支持，2014年共安排补助第二批16个“幸福家园”试点村服务站，并对2013年第一批16个“幸福家园”试点村加拨建站补助经费。

（二）城镇非私营就业总量稳定快增

2014年底，全市城镇非私营单位从业人员达到47万人左右，与上年同期基本持平，其中在岗职工为40万人，从业人员工资总额达到211亿元，在岗职工年平均工资为45000元左右。截至9月底全市城镇非私营单位从业人员为43.96万人，较上年同期增加4.82万人，增长12.3%，其中在岗职工为41.64万人，增加3.66万人，增长9.6%。

从不同经济类型看：国有单位从业人数为90731人，同比减少13180人，下降12.7%，主要由于汇总口径调整及部分国企、事业单位正常人事调配；城镇集体单位从业人数5324人，减少1704人，同比下降24.2%，主要为企业关停并转及人员正常流转；其他所有制单位人数343541人，增加63071人，同比增长22.5%。

从不同行业分类看，1-9月份从业人数的增长主要来自于建筑业。其中增速最快、增长绝对量最大的为建筑业，由于新增不少建筑项目，从业人数有了较大的增加，因此9月底建筑业从业人数为12.05万人，同比增速为55.1%，增加4.28万人，而制造业从业人数为18.74万人，总量占城镇非私单位从业总数的42.6%，虽然仍是吸纳劳动就业的主要渠道，但同比增速为-0.1%，首次出现同比下降的情况。

（三）职工工资总额持续增长

2014年前三季，全市城镇非私营单位从业人员工资总额为148.54亿元，比上年同期增长27.3%，其中在岗职工工资总额141.52亿元，同比增长24.0%，保持平稳较快的发展势头。

从国有、集体、其他分组看，工资总额增长主要来自于其他所有制单位效益提升带来的工资增长，而国有、集体单位工资由于从业人员的减少双双出现下降的局面。其中，国有单位从业人员工资总额为39.27亿元，同比下降4.6% ；城镇集体单位工资总额为1.73亿元，同比下降24.5%；其他单位工资总额为107.54亿元，同比增长46.9%。

从行业分类看，从业人员工资总额的增长基本遵循从业人数的增长，增速最快、增加绝对额最多的是建筑业，工资总额为40.62亿元，增加17.83亿元，同比增速为78.2%。

（四）平均工资平稳较快增长

全市前三季城镇非私营从业人员平均工资为33762元，同比增长14.8%；在岗职工平均工资为33880元，同比增长14.7%，呈平稳增长态势。

从国有、集体、其他单位分组来看，国有单位在岗职工平均工资为44386元，比上年同期增长12.1%，主要来自于正常工资晋级以及行政、事业单位全面补发之前的少量增资；城镇集体单位在岗职工平均工资为33079元，比上年同期增长5.9%，集体单位整体效益没有明显增长，因此工资增长乏力；其他所有制单位在岗职工平均工资为31115元，比上年同期增长20.0%，主要由于制造业开工不足，为了吸引工人普遍增加用工成本，提高薪酬待遇，因此劳动密集型行业的工资保持了较快的增长，从而拉高其他所有制职工工资的整体水平。

从国民经济各行业看，除个别行业有略微下降外，大部分行业职工工资都有不同程度的增长，其中同比增幅10%以上的行业有6个。我市各行业中，前三季平均工资处于30000元/人至50000元/人区间的行业占多数，共有13个，50000元/人以上的行业仅2个，30000元/人以下的行业有4个，其中前三季平均工资最高的为金融业92610元/人，其次是交通运输、仓储和邮政业53431元/人，第三为信息传输、软件和信息技术服务业49532元/人。而工资最低的为住宿和餐饮业18486元/人，其次是采矿业20976元/人，第三为制造业28865元/人。平均工资最高行业与最低行业的差比为5：1。

二、存在问题

（一）就业增长速度逐渐减缓，制造业吸纳就业空间见小

2013年底我市城镇非私营单位从业人员为46.64万人，比增25.4%，2014年一季度底为41.73万人，比增12.8%，而6月底为43.44万人，比增12.6%，三季度底为43.96万人，比增12.3%，前三个季度同比增幅连续处于下降态势。其中制造业受到的影响尤为明显，2013年底我市制造业从业人员总数为20.49万人，同比增幅为6.3%，2014年一季度底为18.93万人，同比增幅为3%，二季度底为19.11万人，同比增幅为2.1%，三季度底为18.74万人，同比下降0.1%。

（二）企业用工成本不断提高，对第二产业影响尤甚

2013年底城镇非私营单位在岗职工年平均工资为43963元，同比增幅为9.8%，2014年一季度在岗职工平均工资为11379元，同比增幅14.4%，而2014年上半年在岗职工平均工资为22437元，同比增幅14.8%，前三季度在岗职工平均工资为33880元，同比增幅14.7%；其中第二产业自2013年底以来这一指标分别39985元、10397元、20203元和30594元，同比增幅也依次为9.7%、18.4%、18.8%和18.9%。

三、建议

（一）转变就业增长方式，逐步将就业增容的重心从二产转移到三产

人口红利逐年消退，二产企业结构升级、以机械代替人工将是必由之路，吸纳就业增速将逐步回落，以建筑项目带动的就业增长也不可能长期持续，因此发展第三产业才是就业持续增长的关键点，一方面要做大品牌服务产品，提升服务质量，另一方面要扶持小微服务企业，丰富产品种类。

（二）缩小行业工资差比，促进职工工资合理化增长

工资水平的适度增长有利于劳动力市场供求关系的调节，有利于社会的稳定和谐，但过高的工资水平超出企业负担，可能成为压垮企业的最后一根稻草，也不利于维护社会公平，需要政府健全收入分配机制，将工资差比限制在合理水平。
