降幅大幅收窄 回升态势明显——上半年莆田市建筑业发展状况分析

第四十四期
发布时间：2020-07-28 10:28
| | |

上半年，莆田市建筑企业复工复产稳步推进，生产经营情况逐步好转。

一、建筑业主要指标情况

（一）产值指标降幅收窄。上半年，全市总专包建筑企业积极复工复产，实现总产值353.31亿元，同比下降5.6%，降幅较一季度收窄16.4个百分点。其中，建筑工程产值339.71亿元，下降6.5%，降幅较一季度收窄16.4个百分点；安装工程产值8.33亿元，增长2.6%，降幅较一季度收窄23.7个百分点。

（二）主要财务指标增速由负转正。上半年总专包建筑业企业实现营业收入282.34亿元，同比增长2.0%,降幅较一季度收窄24.8个百分点；实现营业利润13.83亿元，同比增长3.9%，降幅较一季度收窄65.4个百分点，增速由负转正。

（三）部分生产指标增速大幅提高。上半年本年新签合同额530.81亿元，同比增长49.3%，增幅较一季度提高68.6个百分点；装饰装修产值1.88亿元，同比增长37.4%，增幅较一季度提高87.4个百分点；在外省完成的产值187.67亿元，同比增长43.9%，增幅较一季度提高36.4个百分点；本年新开工面积1183.41亿元，同比增长49.6%，增幅较一季度提高72.6个百分点。

二、建筑业产值分类情况

（一）从行业看：房屋建筑类、建筑装饰装修和其他建筑类企业生产经营状况恢复程度好于全市平均水平。上半年，建筑业包含的4个行业中，房屋建筑类、建筑装饰装修和其他建筑类企业分别实现产值283.60亿元、5.14亿元，产值增速均超过全市平均水平，分别为13.0%、203.4%，增速较全市平均水平分别提高18.6个、209.0个百分点。房屋建筑类建筑企业以超过八成总产值占比和高于全市18.6个百分点的增速，推动全市建筑企业逐步恢复生产。土木工程类、建筑安装类建筑企业总产值分别下降46.9%、28.9%。

    （二）从区域看：涵江区、荔城区成为全市总产值恢复的主要支撑。上半年，涵江区、荔城区总专包建筑企业实现产值增速双高，产值分别为94.72亿元、86.82亿元，增速分别为11.0%、6.1%。两区合计完成建筑业产值181.54亿元，占全市建筑产值的51.4%，拉动全市产值增长3.8个百分点。城厢区总专包建筑企业产值增速最低，下降30.9%，低于全市平均水平25.3个百分点；北岸增速倒二，下降24.9%，低于全市平均水平19.3个百分点。

（三）从资质等级看：一级资质总专包建筑企业基本恢复去年生产水平。根据一套表在库数据，上半年全市有33家一级资质总专包建筑企业实现总产值184.76亿元，同比增长38.8%，增速高于全市平均水平44.4个百分点，占全市建筑业总产值比重为52.3%。特级、二级及三级企业产值分别下降44.7%、6.7%和37.7%，分别拉大全市降幅9.4个、1.4个和8.6个百分点。

三、当前莆田市建筑业存在的困难

（一）受疫情等因素影响，部分大型企业生产还未完全恢复。上半年，中交建宏峰、亿晟建设及中浩市政等7家企业产值合计减少61.60亿元，拉大全市建筑业总产值降幅16.5个百分点，特别是龙头企业中交建宏峰产值减少35.67亿元，同比下降58.3%，拉大全市建筑业总产值降幅9.5个百分点。　

（二）从业人员逐步到岗，但近三成企业有裁员计划。3月以来，建筑企业逐步恢复生产，工人逐步到岗。上半年莆田市总专包建筑企业中从事建筑活动的平均人数为15.89万人，恢复至去年同期的90.4%。但近期问卷调查也显示，27.6%的企业有裁员计划或已裁员，67.9%的企业计划保持现有用工规模，仅4.5%的企业有扩大用工规模计划或已扩大规模。

四、发展建议

一是建议各县区政府要进一步加大基础设施、制造业和服务业等领域投资力度，特别以扩大铁路、城市轨道交通、节能环保等建筑行业市场为主，引导企业向该领域转型。

二是住建等主管部门要积极宣传，带动企业针对重点地区、重点行业不断开拓建筑业市场，同时要有针对性帮助企业获得公平的市场准入环境。
