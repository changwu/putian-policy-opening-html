2011年莆田市农业农村经济形势分析

发布时间：2012-02-16 00:00
| | |

2011年，莆田市认真贯彻中央、省农村工作会议精神，以提高农业经济效益和增加农民收入为中心，把加快农业产业化建设和新农村建设作为重要抓手，以科技兴农为支撑，继续强化落实一系列支农、惠农政策，大力培育特色产业，扎实推进新农村建设，多渠道增加农民收入，全市农村经济继续保持了平稳的发展态势。

一、农业农村经济总体情况

（一）农林牧渔业总产值、增加值稳步增长。

2011年，全市实现农林牧渔业总产值164.64亿元，比上年增长1.3%（按可比价计算）。其中,农业产值57.50亿元，增长3.1%；林业产值3.23亿元，增长21.6%；牧业产值33.12亿元，下降3.7%；渔业产值58.55亿元，增长0.8%；农林牧渔服务业产值12.25亿元，增长4.2%。

全市实现农林牧渔业增加值98.78亿元，比上年增长1.3%。其中,农业增加值35.32亿元，增长3.0%；林业增加值1.82亿元，增长20.9%；牧业增加值19.25亿元，下降3.5%；渔业增加值35.39亿元，增长0.7%；农林牧渔服务业增加值7.01亿元，增长4.2%。

（二）农民收支显著增长。

2011年，全市农民人均纯收入9066元，比上年增加1403元，增长18.3%；农民人均生活消费现金支出6748元，比上年增加1069元，增长18.8%。

（三）农户固定资产投资稳步增长。

2011年，全市固定资产投资完成额25.87亿元，比上年增长16.8%；农户新增固定资产原值16.09亿元，比上年增长3.2%。

（四）设施农业发展迅速。

2011年，我市加大资金投入，设施农业得以快速发展。全市投入1400万元新建钢架大棚达700亩，其中各级财政补贴达490万元。到目前，全市拥有钢架大棚面积1000亩，已安装喷灌机械的面积达2243亩。设施农业的迅速发展对农民的增收起到了积极的促进作用。

（五）农业产业化加快推进。

2011年，我市进一步推进主导产业，优化区域布局，积极发展规模经营，农业产业化进程加快推进。截至2011年底，我市农业产业化龙头企业138家，比上年增加18家，其中国家级农业产业化龙头企业4家，比上年增加2家；省级农业产业化龙头企业24家，比上年增加7家。

（六）农业机械化水平快速提高。

一是购机补贴力度加大。2011年，全市完成各级补贴资金超过2081万元，中央补贴资金达1500万元，共购置各类补贴机具4838台，带动农民投资近3500万元，直接受益农户4000多户。二是机插面积继续扩大。全年新增插秧机125台，插秧机拥有量达335台，其中乘座式高性能插秧机260台，农机专业合作社已成为机械化育插秧技术推广的中坚力量，全市机插面积突破10万亩达10.44万亩。三是农业机械化程度不断提高。农业机械总动力达76万千瓦，农机经营总收入5.5亿元，农机化综合水平超过39%。组织机耕、维修等作业服务队，调集拖拉机及配套机具，开展大规模农机作业，机耕面积73万亩；组织联合收割机400多台，机收水稻12.8万亩。

二、农业生产情况及特点

（一）种植业平稳发展。

1、粮食面积下降，单产提高。2011年，全市粮食面积79.44万亩，比上年减少2.90万亩，下降3.5%。分品种看，稻谷面积47.38万亩，比上年减少2.89万亩，下降5.7%。其中早稻面积22.68万亩，中稻面积8.09万亩，晚稻面积16.61万亩，分别比上年减少0.14万亩、0.5万亩和2.21万亩，分别下降0.6%、6.3%和11.7%。薯类面积21.67万亩，比上年减少0.16万亩，下降0.8%；大豆面积6.02万亩，比上年增加0.19万亩，增长3.2%。粮食总产量30.12万吨，比上年减少0.49万吨，下降1.6%。其中稻谷产量19.78万吨，比上年减少0.60万吨，下降2.9%。粮食平均单产378.1公斤，比上年增加6.2公斤，增长1.6%。其中稻谷平均单产417.6公斤，比上年增加12.1公斤，增长3.1%。

2、经济作物规模扩大。随着经济作物比较效益的提高，我市经济作物种植面积稳步增长。2011年，全市蔬菜种植面积51.92万亩，比上年增加1.27万亩，增长2.5%。蔬菜产量108.91万吨，比上年增加1.80万吨，增长1.7%。油料作物种植面积23.85万亩，比上年增加0.14万亩，增长0.6%。油料产量4.52万吨，比上年增加0.12万吨，增长2.8%。

3、食用菌减产增效。全年食用菌产量7.49万吨，比上年减少0.16万吨，下降2.1%。其中：蘑菇产量7.01万吨，减少0.16万吨，下降2.2%。由于种植面积下降，造成供不应求，蘑菇售价远远高于往年，菇农收入比往年有大幅提高。

4、水果产量下降。受气候影响，全市水果产量17.11万吨，比上年减少1.17万吨，下降6.4%。其中，枇杷产量8.94万吨，减少1.57万吨，下降15.0%。龙眼产量2.61万吨，减少0.07万吨，下降2.9%。荔枝产量0.13万吨，产量基本与去年持平。

（二）造林绿化成效显著。

2011年,全年完成荒山荒地造林面积9.75万亩，更新造林面积4.02万亩，零星植树94万株，完成幼林抚育14.36万亩，全市森林覆盖率达58.1%，有效地保护了我市的生态环境和生物资源，对保护水土流失、保障农田水利高产稳产、抵御自然灾害、吸引海内外投资兴业、旅游观光、进一步密切合作与交流、加快海峡西岸经济区建设起到了积极作用。

（三）畜牧业生产总体呈现下滑。

2011年，全市肉蛋奶产量18.55万吨，比上年下降3.3%。其中，肉类产量12.34万吨，下降4.4%；蛋产量4.63万吨，增长2.0%；奶类1.59万吨，下降9.0%。全市生猪出栏121.27万头，比上年下降6.2%；存栏94.36万头，比上年增长3.1%。家禽出栏2519.78万只，比上年下降0.3%；存栏979.77万只，比上年增长0.7%。

（四）渔业生产保持稳定。

2011年，全市水产品总产量72.71万吨，比上年增长0.1%。其中海水产品产量68.95万吨，增长0.1%。海洋捕捞产量12.04万吨，下降0.3%；海水养殖产量56.91万吨，增长0.2%。淡水产品产量3.76万吨，比上年增长0.1%。水产养殖面积2.23万公顷，比上年增长0.1%。

三、存在问题

（一）农产品价格波动明显。

随着经济发展速度的加快，目前千家万户的农业生产格局与千变万化的市场信息之间的矛盾越发突出，加之农业生产周期长，生产结构调整速度往往滞后于市场价格变化。随着农产品尤其是蔬菜价格的大起大落，盲目种植现象严重，不利于种植业持续健康发展。

（二）自然灾害偏多。

一是早春霜冻造成越冬作物和茶叶冻害严重。二是“南玛都”台风带来的暴雨给我市农业造成较大损失。据莆田市防汛抗旱指挥部办公室统计资料，“南玛都”台风造成我市农作物受灾面积19.77千公顷，农林牧渔业直接经济损失达3.01亿元。

（三）劳动力紧缺制约农业快速发展。

随着农村劳动力转移数量的不断增加，在农民增加收入的同时，也带来了一些新的问题：首当其冲的就是农村劳动力紧张的现象开始出现并且已经影响到农业生产的发展。由于农业产出的效益相对较低，迫使大量青壮年农民加入外出务工的行列。在农忙时节，多数外出人员不能返乡劳动，造成农村劳动力短缺。

（四）耕地面积逐年减少。

由于交通建设、经济开发区、工业园区建设等，耕地被征用，我市耕地面积逐年减少，播种面积减少的趋势难以扭转。

四、发展农村经济的若干建议

（一）强化科技，确保粮食增产、农民增收。

一是更加重视粮食生产，着力在稳定面积、提高单产和政策保障上下功夫，努力构建保护和提高粮食综合生产能力的长效机制。二是加强技术培训，提高农民素质。三是进一步加大农业新技术、新品种的推广应用与示范。四是完善农技服务体系。建立一支专业化、高素质的农业技术推广队伍，为农民提供系统、准确、快捷的农产品生产、加工和销售信息。

（二）培育特色，增强产业发展能力。

一是大力发展特色农产品基地，坚持农业结构调整不动摇，积极推动土地流转和规模开发。二是更加注重农产品质量安全，树立品牌形象。三是推进农业功能开发，走经济型、生活型、生态型、观光型和文化型农业发展之路。

（三）加强引导，促进农村劳动力本地就业。

加强农村转移劳动力的政府指导，鼓励农民工就地或返乡创业，创建农民自主创业平台，为农民创业项目提供政策咨询、配套设施等相关服务，营造优良的创业环境。

（四）调优结构，积极发展现代农业。

一是面向市场，选准主导产品，大力发展品质优良、特色明显、附加值高的名优特新农产品，提高农业集约化水平，增强特色产品的竞争力。二是优化区域布局，打造主导产业。科学规划，确定主导产业，引导特色产品向优势产业带聚集，推进农业生产规模化、区域化。三是继续实施“一村一品”工程，重点扶持特色经济的专业村，为农业农村经济发展注入新的活力。
