2016年1-2月份莆田市规模以上工业运行简析

发布时间：2016-03-18 00:00
| | |

今年以来，在宏观经济下行压力持续加大，市场需求持续疲软、部分行业产能过剩、资金环境依然趋紧等因素影响下，莆田市工业基本面总体保持稳定，1-2月莆田市规上工业增加值增幅位居全省第一位。

一、工业生产运行情况及特点

（一）工业经济持续快速增长，增幅稳中趋缓。1-2月份，规模以上工业实现工业增加值136.18亿元，可比增长9.3%,增幅比上年同期和上年12月累计分别回落2.1个和1.5个百分点，但比全省平均增幅高2.0个百分点，工业经济总体呈现稳中趋缓。

分三大门类看，1-2月，采矿业增加值同比增长10.7%，制造业增长10.2%，电力、燃气、水的生产和供应业下降4.6%。分经济类型看，1-2月，国有企业增加值同比增长52.2%，集体企业同比增长15.6%，股份合作企业同比增长42.4%，股份制企业同比增长14.3%，外商及港澳台商投资企业同比下降2.7%，其他经济类型企业同比增长10.6%。

分行业看，1-2月，33个大类行业中有24个行业增加值同比增长。其中，化学原料和化学制品制造业增长172.1%，文教、工美、体育和娱乐用品制造业增长23.3%，计算机、通信和其他电子设备制造业增长16.9%，非金属矿物制品业增长22.5%，纺织业增长30.9%，皮革、毛皮、羽毛及其制品和制鞋业增长2.1%，造纸和纸制品业增长15.4%，纺织服装、服饰业增长7.7%。

分产品看，1-2月，全市重点监测主要工业品中，原盐下降59.7%，大米下降13.0%，饲料增长3.3%，罐头增长7.7%，饮料酒下降10.6%，服装下降5.6%，鞋增长0.3%，家具增长33.2%，纸制品0.4%，涂料增长21.2%，商品混凝土增长16.7%，模具下降10.3%，表增长0.1%，橡胶轮胎外胎下降9.7%，钢材下降86.6%。

（二）亿元企业贡献突出，拉动作用明显。1-2月，全市超亿元以上规模企业82家，比上年同期多5家，占规模以上工业企业单位数的6.6%。实现工业增加值60.68亿元，增长17.1%，占全市规上工业增加值总量达44.6%，对规模以上工业经济增长的贡献率为76.3%，拉动规模以上工业增加值增长7.1个百分点。

（三）重工业发展明显快于轻工业，贡献力加大。1-2月规模以上轻工业实现工业增加值94.95亿元，增长7.1%，对规模以上工业经济增长的贡献率为54.5%，拉动规模以上工业增加值增长5.1个百分点。重工业实现工业增加值41.22亿元，增长14.7%，比轻工业高7.6个百分点。对规模以上工业经济增长的贡献率为45.5%，比上年同期的贡献率提高了37.7个百分点，拉动规模以上工业增加值增长4.2个百分点，主要是中锦新材料、抽水蓄能等企业产能释放拉动。

（四）小微企业贡献率破百，贡献给力。1-2月，1023家规模以上小微工业企业实现工业增加值75.72亿元，增长20.9%，增幅比全市规模以上工业增加值平均增速快11.6个百分点，比大中型工业增加值增幅快23.2个百分点。对规模以上工业经济增长的贡献率为112.4%，拉动规模以上工业增加值增长10.5个百分点。主要是文教、工美、体育和娱乐用品制造业，纺织业，化学原料和化学制品制造业三个行业增势强劲，增幅分别达31.8%、44.8%、239.5%。

（五）新增企业作用初显，成为工业经济新增长点。1-2月，全市新增工业企业共拉动规模以上工业经济增长5.5个百分点，成为工业经济发展新的增长极。其中，120家规下转规上企业实现工业增加值3.29亿元，同比增长72.4%，对规模以上工业经济增长的贡献率为11.7%，拉动全市规模以上工业经济增长1.1个百分点。去年以来34家新投产工业企业实现工业增加值6.87亿元，同比增长8.6倍，对全市规模以上工业经济增长贡献率为50.2%，拉动规模以上工业经济增长4.7个百分点，其中去年新投产的中锦新材料、祥麟鞋业等企业拉动作用较为明显。

（六）新兴产业发展迅猛，传统产业贡献依旧较大。1-2月，我市规模以上十大产业实现工业增加值130.95亿元，可比增长9.3%。其中，新兴化工产业实现工业增加值15.94亿元，增长54.5%，对全市规模以上工业经济增长贡献率为47.7%，拉动规模以上工业经济增长4.4个百分点，传统的工艺与创意、制鞋和纺织服装三大产业对工业经济贡献率达39.2%。工艺与创意产业实现工业增加值20.18亿元，增长14.6%，主要年初珠宝、黄金生产企业产销两旺以及黄金价格上涨等因素带动该产业快速增长。制鞋产业实现工业增加值30.49亿元，增长3.4%。纺织服装业实现工业增加值8.76亿元，增长12.4%。

二、造成现阶段工业经济下滑的主要原因

（一）减、停面持续扩大。2月，规上工业停、减产企业减产面达32.5%，分别比上年同期和上年12月末高6.0个和3.7个百分点，共拉低全市增幅12.2个百分点。停产企业56家，比上年同期和上年12月末分别减少10家和34家，影响全市规模以上工业增加值4.80亿元，拉低规模以上工业增长3.6个百分点。其中， 27家企业为去年停产企业，影响全市规模以上工业增加值3.16亿元，拉低规模以上工业增长2.4个百分点。29家为今年新增停产企业，影响全市规模以上工业增加值1.64亿元，拉低规模以上工业增长1.2个百分点。减产企业大幅增加，2月末，349家企业减产，较上年同期和上年12月末分别增加105家和100家。占全市规模以上工业企业数的28.0%，累计减少工业增加值9.43亿元，拉低规模以上工业增长7.1个百分点。其中，产值减产超过千万的规上企业有69家，累计减少工业增加值7.49亿元，约占总减产量的79.4%。

（二）用电“晴雨表”折射工业经济发展放缓。1-2月全市工业用电量10.71亿千瓦时，增长64.0%，扣除抽水蓄能、线路损失电量影响，累计工业用电量仅增长0.6%。其中，制造业用电量下降7.0%。1-2月，全市制造业工业增加值占全市规上工业总量的94.2%，制造业用电量下降，折射工业经济下行压力加大。

（三）市场需求仍显不足。内需方面，在社会保障仍显不足的环境下，国民消费需求未完全释放。外需方面，国际市场需求增长缓慢，工业出口持续低位徘徊。1-2月，全市规模以上工业实现出口交货值55.92亿元，下降2.2%，分十大产业看，食品医药（-23.5%）、电子信息产业（-6.5%）、化工产业（-33.6%）三大产业出口交货值增幅下降较多。据全市69家减产千万以上企业的调查显示，有66.7%的企业认为主要是订单不足，产能过剩的原因导致减产。

（四）制鞋和工艺美术行业发展前景堪忧，企业面临亏损经营的困境。从全市减停产企业看，减产企业主要分布在皮革、毛皮、羽毛及其制品和制鞋业（97家），文教、工美、体育和娱乐用品制造业（50家）和通用设备制造业（22家）三大行业，占全部减产企业数近半成。停产企业主要分布在皮革、毛皮、羽毛及其制品和制鞋业（19家）和文教、工美、体育和娱乐用品制造业（17家）两大行业中，占全市停产企业数的六成以上。据业内人士分析：目前我市制鞋企业面临转型升级的阵痛期，国外市场面临着东南亚国家制鞋业兴起，国外订单流失且呈现逐年减少的趋势，订单价格下降。加之美国等国家对中国的贸易壁垒，提高关税和产品检验标准等，国内市场面临产能过剩，人工成本逐年上涨，本地同质化企业恶性竞争等诸多经营问题，一大部分制鞋企业面临着亏损经营的困境。红木生产企业面临产能过剩、去库存、资金周转紧张以及如何转型升级的经营的困境。
