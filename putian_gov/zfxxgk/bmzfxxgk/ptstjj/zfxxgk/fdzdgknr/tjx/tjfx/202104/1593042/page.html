2021年一季度莆田市固定资产投资情况分析

第二十一期
发布时间：2021-04-19 15:01
| | |
 随着统筹疫情防控和经济社会发展成效持续显现，稳投资政策措施逐步到位，我市项目建设稳定推进，投资结构持续优化。2021年一季度全市固定资产投资（不含农户）同比增长40.9%，比2019年一季度增长1.3%，两年平均增速为0.7%，继续保持恢复性增长态势，其中项目投资同比增长34.7%，房地产开发投资同比增长60.6%。

    一、运行情况

（一）投资结构持续优化。一是三次产业结构优化调整。一季度三次产业投资结构由上年的1.1：30.7：68.2调整为今年的0.8：28.5：70.7，第三产业投资提高2.6个百分点。二是高技术产业投资快速增长。一季度高技术产业投资同比增长138.5%，其中高技术制造业投资增长111.9%，高技术服务业增长306.9%。高技术制造业中，计算机及办公设备制造业投资增长170.0%；高技术服务业中，环境治理业投资增长39.2%。

（二）民间投资稳步恢复。经过前年的低位增长，上年的全年负增长，全市民间投资恢复增长，一季度同比增长31.3%，其中，基础设施民间投资增长24.5%，教育民间投资增长40.8%，房地产开发民间投资增长67.1%。

    （三）社会领域投资稳定增长。一季度全市社会领域投资同比增长59.1%，两年平均增长5.5%。其中教育业投资同比增长135.3%，两年平均增长15.7%；文化、体育和娱乐业投资同比增长117.8%，两年平均增长22.7%。

    （四）重点行业投资支撑有力。一是基础设施投资稳定恢复。一季度基础设施投资同比增长30.8%。其中，交通运输业投资增长50.6%，生态保护和环境治理业投资增长246.8%，公共设施管理业增长33.4%。二是制造业投资恢复增长。一季度制造业投资同比增长32.7%，两年平均增长1.1%。其中，计算机、通信和其他电子设备制造业投资增长170.0%，化学纤维制造业增长35.5%，化学原料及化学制品制造业投资增长15.3%。装备制造业投资增长55.7%。三是房地产开发投资贡献明显。一季度房地产开发投资同比增长60.6%，两年平均增长7.5%，对全市固定资产投资的贡献率为35.4%，拉动全市固定资产投资增长14.5个百分点。其中，住宅投资增长68.3%；房地产开发企业到位资金增长81.9%。

    （五）投资到位资金保障有力。一季度本年投资到位资金同比增长48.9%，高于全部投资8.0个百分点；两年平均增长9.6%，高于全部投资8.9个百分点。

二、需关注问题

一季度以来的高增长大部分是由于上年疫情影响，项目建设的工期较短导致，从今年新开工的亿元项目来看，截止一季度全市只有10个，比上年同期减少16个，计划总投资同比下降70.7%，本年完成投资同比下降56.8%，新开工大项目较少势必影响全市的投资后劲，且扣除上年因素影响，两年平均仅增长0.7%，比全省平均水平低3.5个百分点。所以后续各县区、各部门要重点关注月度数据的波动情况，进一步加强项目储备，增强投资的发展后劲，对已开工的项目，做好项目入库申报工作，保持固定资产投资增速的平稳增长。
