2021年莆田市固定资产投资情况分析

第四期
发布时间：2022-01-19 15:26
| | |

2021年，全市各级各部门统筹推进疫情防控和经济社会发展，全市固定资产投资（不含农户）同比增长1.9%，增速比上年高4.2个百分点，比全省平均水平低4.1个百分点。其中项目投资同比增长1.5%，房地产开发投资同比增长3.4%。

一、总体情况

从项目个数看，项目个数增加。本年累计在库项目1291个，比上年多153个，其中5000万以下项目比上年多185个。 

从投资结构看，投资结构向好向优。一是三次产业投资结构优化调整。三次产业投资比重由上年的1.1：31.7：67.2调整为1.7：30.7：67.6，第一产业投资比重提高0.6个百分点，第二产业投资下降1.0个百分点，第三产业投资提高0.4个百分点；二是新动能投资快速增长。全市不断加大高技术产业投资力度，加速新旧动能转换，全市高技术产业投资同比增长17.5%，与2019年比两年平均增长33.3%。其中，高技术制造业投资增长5.6%，高技术服务业投资增长137.6%；三是转型升级步伐加快。全市改建和技术改造投资增长19.5%，与2019年比两年平均增长31.1%，改建和技术改造投资占全市投资的比重为8.0%，比上年提高1.2个百分点。全市加快传统工业产业技术改造，结构转型持续推进，工业改建和技术改造投资增长23.4%，其中制造业改建和技术改造投资增长60.1%。

分投资主体看，民间投资占比大、贡献率高。全市民间投资由上年的下降12.3%转为增长2.0%，占全市固定资产投资的比重为56.5%，对全市固定资产投资的贡献率为59.2%，比国有投资和外商和港澳台投资分别高9.7个、69.3个百分点。

分区域看，各县区发展不均衡。全市各县（区、管委会）固定资产投资“五升二降”，增幅高于全市的有：城厢区（10.2%）、荔城区（7.0%）、涵江区增长（6.4%）、北岸（5.5%）、仙游县（4.5%）；增幅低于全市的有：秀屿区（-13.0%）、湄洲岛（-44.3%）。

二、主要特点

（一）农林牧渔业投资高速增长。全市农林牧渔业投资同比增长129.3%。其中，农业投资增长104.6%，林业投资增长5.9%，畜牧业投资增长184.5%，农、林、牧、渔服务业投资增长1132.3%。

（二）交通运输业投资快速增长。全市交通运输业投资同比增长27.1%。其中，道路运输业投资同比增长4.7%，水上运输业投资同比增长466.5%。

（三）社会领域投资稳定增长。全市社会领域投资同比增长12.5%,与2019年比两年平均增长15.1%。其中：教育业投资同比增长24.8%，与2019年比两年平均增长17.4%；文化、体育和娱乐业投资同比增长4.2%，与2019年比两年平均增长16.3%；卫生和社会工作投资同比增长11.1%,与2019年比两年平均增长12.0%。 

（四）房地产开发投资贡献突出。全市房地产开发投资同比增长3.4%，对全市固定资产投资的贡献率为38.2%，拉动全市固定资产投资增长0.7个百分点。

（五）投资有效性提高。全市有效投资同比增长6.1%，占全市投资的比重为89.3%，比上年提高3.5个百分点。其中，建筑安装工程投资同比增长19.7%，增幅比全省平均水平高9.4个百分点；建筑安装工程投资占全市投资的比重为77.5%，比上年提高11.5个百分点。

（六）资金到位良好。本年投资到位资金同比增长5.5%,增幅高于全部投资3.6个百分点，与2019年比两年平均增长8.0%，高于全部投资8.2个百分点。其中，国家预算资金同比增长45.2%，国内贷款同比下降17.1%，自筹资金同比增长3.1%，其他资金来源同比增长21.7%。

四、存在问题

今年以来我市投资有所增长，但受到疫情的影响增速低于全省平均水平，两年平均增速已转为下降0.2%，投资增长存在较大制约。

（一）新晋投资贡献乏力。从新开工项目情况看，全市新开工项目计划总投资同比下降44.2%，本年完成投资额同比下降29.3%，其中亿元新开工项目本年完成投资额同比下降44.7%，对全市投资增长没有起带动作用；从新入库项目情况看，全年新入库项目830个，平均投资规模1.48亿元，比上年低1.58亿，新入库项目本年完成投资占全部项目的39.5%，近六成的项目投资是结转项目完成的。作为投资新鲜血液，新入库项目的规模下降、完成投资占比低，直接影响其对全部投资增长的贡献度。

（二）重点行业呈现降势。一是基础设施投资仍待破局。基础设施投资负增长的局面仍未打破，2021年，全市基础设施投资延续上年以来的下降态势（4.8%），降幅扩大2.9个百分点，与2019年比两年平均下降6.3%，对全市投资运行影响较大，基础设施投资占全市固定资产投资比重由上年的31.7%下降至28.7%；二是工业投资运行低迷。全市工业投资同比下降1.5%，速度比全省平均水平（11.6%）低13.1个百分点，其中，制造业投资增长8.9%，电力、热力、燃气及水的生产和供应业投资下降57.5%。这两个行业合起来占全市固定资产投资57.3%（扣除重复行业），投资的负增长对全市投资增长形成较大制约。

五、建议

一是抓招商。开展“一把手抓亲情招商”，利用春节期间老板返乡时机，围绕产业链精准招商，提高项目储备数量和质量，同时提高项目落地签约的有效性。二是强储备。针对重点薄弱行业，适度超前布局基础设施建设，强化工业类项目储备，跟踪工业及基础设施类大项目的前期及开工。三是抓进度。鼓励重点项目春节期间不停工、少停工、早复工，抓好大的存量项目投资进度，形成更多的实物投资量。四是抓入库。先入库才有数，做好后续促开工项目的入库工作，做到应入尽入、应统尽统。
