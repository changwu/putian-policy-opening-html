经济运行稳中放缓 新动能加快积聚——1-9月份我市经济运行情况分析

第六十二期
发布时间：2018-10-23 11:13
| | |

1-9月，全市经济运行稳中放缓，新动能加快积聚。初步核算，全市GDP实现1593.46亿元，可比增长7.7%，增幅分别比1-3月、1-6月、1-8月回落0.4个、0.8个和0.4个百分点。其中，第一产业增加值77.73亿元，可比增长3.7%；第二产业增加值841.67亿元，增长8.5%；第三产业增加值674.06亿元，增长6.8%。

一、经济运行新动能加快

（一）先进制造业较快增长。1-9月，全市规模以上战略性新兴产业、高技术企业实现工业增加值分别比上年同期增长20.0%、19.6%，增幅分别高于全市规模以上工业增速11.0个和10.6个百分点。高端装备产业工业增加值增长11.4%，增幅快于全市规模以上工业平均增速2.4个百分点。

（二）新业态新模式蓬勃发展。1-9月，网上购物快速增长，全市限上批发和零售业通过公共网络实现零售额105.76亿元，同比增长22.3%,增速比全市社会消费品零售总额快10.8个百分点；全市邮政及快递业务收入增长31.9%，增幅居全省九设区市第二位。网络购物、共享经济等新型消费模式和消费业态继续蓬勃发展。

（三）投资结构调整优化。1-9月，三次产业投资结构由上年同期的0.8：32.1：67.1调整为1.2：29.0：69.8，第一产业投资比重上升0.4个百分点，第二产业下降3.1个百分点，第三产业提高2.7个百分点。第二产业投资中，装备制造业投资同比增长31.3%，增幅快于全市固定资产投资增幅18.5个百分点；先进制造业投资增长33.5%，增幅快于全市固定资产投资增幅20.7个百分点。

（五）市场活力增强，新登记企业增长较快。随着制度改革的不断推进，各项措施的落实，全市大众创业、万众创新呈现良好发展态势。截止9月末，全市新登记企业10322户，同比增长36.6%，增幅分别比1-6月、1-3月提高11.2和0.8个百分点。全市新登记个体户52806户，增长77.1%，增幅分别比1-6月、1-3月提高28.7和38.6个百分点。

（六）物价涨幅温和，就业形势稳定。1-9月，全市居民消费价格同比上涨1.5%，其中，城市上涨1.6%，农村上涨1.3%。城镇登记失业率9月末、6月末、3月末分别为2.22%、2.49%和2.50%，均控制在3.0%的预期目标以内。

二、主要经济指标运行情况

（一）农业生产形势向好。1-9月，全市农林牧渔业总产值142.78亿元，可比增长3.8%，增幅分别比1-3月、1-6月提高3.6个和0.2个百分点。主要特点：一是农业生产稳中有升。全市农业总产值完成32.40亿元，增长4.0%，增幅分别比1-3月、1-6月提高10.3个和3.0个百分点。二是渔业生产贡献突出。1-9月，全市渔业总产值完成77.07亿元，增长5.8%，增幅分别比1-3月、1-6月提高1.1个和1.0个百分点。全市水产品总产量73.35万吨，同比增长5.7%。其中，海水产品产量71.09万吨，增长5.7%；淡水产品产量2.26万吨，增长4.4%。

（二）工业经济稳步发展。1-9月，全市规模以上工业增加值可比增长9.0%，增幅分别比上年同期、1-3月、1-6月提高1.0个、1.1个和0.1个百分点。三季度企业景气指数为122.6，继续运行在“较为景气”区间，表明我市工业经济保持平稳运行的发展态势。主要特点：一是先行指标快速增长。1-9月，全市工业用电量增长27.1%，增幅虽比1-8月回落2.3个百分点，但仍居全省九地市第一位。扣除抽水蓄能后增长24.7%，居全省首位；工业增值税增长25.7%，已连续7个月保持两位数增长。二是七大行业快速增长。1-9月，全市规模以上皮革、毛皮、羽毛及其制品和制鞋业增加值同比增长11.4%，增幅高于全市平均水平2.4个百分点，主要得益于代工企业内销订单增加、东南亚制鞋订单回流以及足球世界杯经济效益拉动；电力、热力生产和供应业增长41.5%，增幅高于全市平均水平32.5个百分点，主要得益于去年新投产的国投云顶湄洲湾电力拉动；电子信息业增长31.5%，增幅高于全市平均水平22.5个百分点，主要得益于新投产元生智汇、华佳彩、联懋科技等新投产企业快速增长拉动；纺织业增长37.0%，增幅高于全市平均水平28.0个百分点，主要得益于华锦实业、华峰新材料、华峰工贸、华源工贸等纺织龙头企业快速增长拉动;纺织服装、服饰业增长19.9%，增幅高于全市平均水平10.9个百分点，主要得益于华耀运动用品、才子服饰订单增加拉动；非金属矿物制品业增长17.3%，增幅快于全市平均水平8.3个百分点，主要得益于佛教论坛项目等基础设施建设，中建、新旺隆等混凝土生产企业订单明显增加拉动；通用设备制造业增长25.2%，增幅快于全市平均水平16.2个百分点，主要得益于上海电气风电设备，产能释放拉动。

（三）消费品市场有所上扬。1-9月，全市社会消费品零售总额555.80亿元，同比增长11.5%，增幅比上年同期提高0.3个百分点。主要特点：一是超六成热点商品保持两位数增长。限额以上22个行业大类中有19个商品零售保持增长，15类实现两位数增长，4类增速在20%以上。其中，化妆品类增长118.5%、通讯器材类增长63.4%、书报杂志类增长60.8%。二是餐饮收入较快增长。全市限额以上餐饮收入8.21亿元，增长30.0%，增速比上年同期提高22.4个百分点。

（四）固定资产投资稳中放缓。1-9月，全市固定资产投资同比增长12.8%，增幅比1-8月回落1.9个百分点。主要特点：一是水利、环境和公共设施管理业高速增长。全市水利、环境和公共设施管理业同比增长37.2%，增速同比提高13.8个百分点，拉动全市固定资产投资增长5.8个百分点，占全市固定资产投资比重为18.9%，同比提高3.4个百分点。二是交通运输、仓储和邮政业加速增长。全市交通运输、仓储和邮政业同比增长25.5%，增幅比1-8月提高2.0个百分点。其中，道路运输业增长41.5%，增速同比提高2.5个百分点。三是制造业投资增速高于全市平均水平。全市制造业投资同比增长18.1%，增幅分别比固定资产投资、工业投资增速高4.9、16.9个百分点。四是民间投资同比“三提高”。全市民间投资增长33.9%，增速同比提高17.1个百分点，拉动固定资产投资增长18.6个百分点；占固定资产投资的比重为65.3%，同比提高10.3个百分点；对固定资产投资的贡献率高达145.5%，同比提高87.9个百分点。民间投资增速、比重、贡献率“三提高”，是投资保持平稳增长的主要动力。

三、经济运行存在问题

（一）部分实体经济发展困难。 一是工业稳定增长基础不够牢固。9月末，全市规模以上企业停、减产面达28.7%，共拉低全市规模以上工业增加值增幅7.5个百分点。其中停产企业124家，比8月末增加8家，拉低全市规模以上工业增加值增幅5.3个百分点；部分企业因环保整治影响产能受限；华佳彩、云度新能源、鞍钢冷轧等企业订单不足，产能发挥有限，与年初的预期产能差距较大。二是本地建筑企业压力加大。今年以来，全市大中型项目大多被央企、地方国企以PPP或EPC模式中标，且大部分为十几亿以上大项目，本地企业项目中标率低。受此影响，1-9月,全市资质内建筑业企业建筑业总产值同比仅增6.0%，增速分别比上年同期、1-8月回落24.7个和3.2个百分点。三是商贸业发展动力仍显不足。9月末，全市40家限额以上停业批发企业，影响全市批发业销售额累计增幅1.2个百分点。气电集团（仙游）、中石化炼油（荔城）2家总部经济型企业暂停营业，影响全市批发业商品销售额累计增幅4.4个百分点。四是部分营利性服务业企业经营困难。1-8月，全市10家注、吊销带基数规模以上租赁和商务服务业企业增速共拉低规模以上其他营利性服务业增幅3.6个百分点。

（二）第三产业增速不断走低。1-9月，全市第三产业增加值增长6.8%，增幅分别比1-3月、1-6月、1-8月回落2.6个、1.8个和1.6个百分点，居全省末位。主要原因：一是财政一般公用等八项支出由上半年增长17.6%转为下降4.1%，影响我市第三产业增加值增幅1.75个百分点。二是规模以上其他营利性服务业增速（错月）比1-5月回落6.6个百分点，影响第三产业增加值增长0.66个百分点。二是金融指标增幅持续走低。8月末，全市人民币存贷款余额比5月末回落2.7个，居全省末位；1-9月，全市保费收入增长11.1%，增幅比1-6月回落1.6个百分点，人民币存贷款余额及保费收入增幅回落共影响我市第三产业增加值增幅0.47个百分点。三是房地产销售面积增速由上半年的增长0.6%转为下降3.8%，影响我市第三产业增加值增幅0.13个百分点。

（三）投资后劲亟待增强。一是大项目投资存量不足。1-9月，5000万以上项目250个，同比减少61个，完成投资同比下降11.1%，项目投资存量仅剩21.6%，表明全市投资增长后劲不足，目前低存量是难以支撑全市固定资产投资较快增长。二是工业投资增速回落。全市工业投资仅增1.2%，增速分别比1-8月、上年同期回落3.5个和16.2个百分点。其中，电力、热力的生产和供应业下降44.5%，降幅同比扩大41.5个百分点。三是房地产投资增速下降。1-9月，全市房地产由于存量不足造成投资额同比下降5.2%，降幅比1-8月扩大0.7个百分点。

四、下阶段经济运行对策建议

（一）加强经济运行监测力度，确保主要指标稳定增长。全面监测重点行业、重点企业的生产运行情况，发挥好龙头企业的引领作用，积极协调解决企业运行中出现的困难和问题，促其生产经营稳定增长。同时，要加大经济运行调度督导力度，通过强化部门之间协调与配合，精准施策确保经济运行企稳回升。

（二）抓好“四上”企业申报入库，增添经济发展新动能。各相关部门要把“四上”企业培育作为重要工作来抓，通过摸底排查企业经营情况，加大力度培育工业、批发、零售、住宿、餐饮业、建筑业、房地产业、服务业企业，做好“个转企”“下转上”工作，并妥善解决拟入企业存在的困难和问题，把企业入统工作落到实处，壮大全市经济总量，为莆田经济发展做出贡献。

（三）抓好投资项目建设，确保对经济拉动有力。要加快推进重大工程进度，对已开工的项目，做好推进，对未开工项目，积极创造条件尽快开工。要切实加强项目入库工作，督促完善相关手续，确保按时入库入统。要加大招商引资力度，为经济发展提供新的增长点。

（四）以新动能培育为目标，补齐第三产业短板。加快推进供给侧结构性改革，增加新兴领域有效供给，如引进高端百货商场、优质医疗、大健康、生态旅游、娱乐文化项目等，优化服务业产业结构，满足居民消费日益增长的需求。积极推进金融业、互联网相关服务、信息技术、科学技术等现代服务业发展，大力培育电子商务、总部经济、城市综合体等新兴业态，为经济持续发展培育新动能。
