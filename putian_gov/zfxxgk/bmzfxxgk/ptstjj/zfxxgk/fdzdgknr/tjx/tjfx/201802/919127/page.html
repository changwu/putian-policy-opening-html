2017年莆田市消费品市场稳中向好

发布时间：2018-02-02 15:28
| | |

在经济进入新常态的时代背景下，随着供给侧结构性改革深入推进，全市大力发展商业新模式、新业态，努力改善消费环境，消费在扩大内需、引领经济增长中的作用进一步凸显，新消费引领新供给，消费结构不断优化，全市消费品零售市场有序运行。

一、全市消费品零售市场运行状况及特点

（一）消费市场总体运行平稳，年末转暖动力增强

初步统计，2017年全市社会消费品零售总额达695.41亿元，比上年增长11.6%（名义增长，下同），增幅比上年和全省平均水平均高出0.1个百分点，增幅居全省九设区市第三位，位次好于上年。从各月实现的总量看，全年月均零售额达57.95亿元，比上年增加6.02亿元。从各月累计增幅看，前4个月在9.8%－10.8%间波动，从5月份开始在11.2%－11.6%间波动， 12月达到全年的最高值11.6%。与全省平均水平相比较看，年初全市增幅低于全省，年末则略高于全省，说明消费动能在进一步增强。全市各月份累计增幅见下表。

1、商品零售保持两位数增长。2017年，全市实现商品零售额637.56亿元，增长12.0%，增幅高于全市社会消费品零售总额0.4个百分点，高于全省平均水平0.2个百分点。分行业看，2017年，零售行业依然起主导作用，保持较快增长态势，带动了全市消费品零售市场全面发展，全年实现零售额561.94亿元，增长11.9%，增幅比全市社会消费品零售总额高0.3个百分点，占社会消费品零售总额的比重保持在80%以上，达80.8%，对社会消费品零售总额增长的贡献率高达82.6%。

2、餐饮收入维持个位数增长。2017年全市住宿餐饮业累计实现餐饮收入57.85亿元，增长7.1%，增幅同比回落0.7个百分点，低于全省平均水平1.2个百分点。分限额标准看，限额以上餐饮收入增速由上年的持平转为今年的增长8.7%，限额以下单位增长6.8%，增幅同比回落2.2个百分点。

（二）消费品市场结构进一步优化

1、批发业发展好于上年。应对市场发展，企业不断调整经营策略，跨行业发展已成常态。2017年，从批发业、零售业、住宿业和餐饮业实现的消费品零售额对全市社会消费品零售总额增长的贡献率看，批发业较快增长，贡献率为12.1%，比上年提升6.6个百分点，零售业（82.6%）、住宿业（0.2%）和餐饮业（5.0%）分别比上年回落5.7个、0.4个和0.6个百分点。

2、限额以上消费品市场规模扩大。 2017年，全市限额以上企业（单位）实现消费品零售额347.15亿元，增长17.0%，增幅高于全市社会消费品零售总额5.4个百分点，占社会消费品零售总额的比重由上年的44.8%提升至49.9%，对社会消费品零售总额增长贡献率达70.0%，贡献率同比提升15.9个百分点，拉动全市社会消费品零售总额增长8.1个百分点。

分经营地看，城乡市场结构优化，乡村市场较快发展。近年来，随着农村交通、物流、网络等相关基础设施建设不断完善，农村居民消费的意愿性提高，消费潜力得到进一步释放。2017年，限额以上乡村单位实现商品零售额15.98亿元，增长21.0%，城镇实现331.17亿元，增长16.9%，乡村增幅快于城镇4.1个百分点，比上年提升10.0个百分点。

（三）新业态快速增长，转型创新促发展

1、网络零售呈较快增长态势。随着安福电商城改造提升、联发电商未来城建设加快进行，全市电商企业发展的配套硬件和软环境不断完善，同时，全市制定了促进跨境电商发展有关项目的实施方案（试行），推动阿里农村淘宝项目，支持京东等知名第三方平台在我市农村布点，全市电商贸易得到长足发展。2017年末，全市有303家限额以上电商贸易企业实现网络零售额112.56亿元，增长28.1%，增幅快于限额以上消费品零售额11.1个百分点，占全市消费品零售总额的比重达16.2%，比重高于全省平均水平9.8个百分点，对全市消费品零售总额的贡献率达34.1%，推动其增长4.0个百分点。其中，累计网络零售额超亿元的企业有23家，比上年增加7家。

2、传统实体零售保持增长态势。全市传统实体零售企业加快转型步伐，创新经营模式，拓宽销售渠道，增强体验服务，总体业绩呈增长态势。2017年，传统零售实体单位（有店铺零售）实现零售额206.93亿元，增长9.4%，增幅比上年仅回落1.1个百分点，其中，便利店、超市、百货店、家居建材商店和厂家直销中心零售额增幅超20%。

（四）居民消费升级加快

2017年全市居民收入稳步增长，城镇居民人均可支配收入34490元，增长8.4%；农村居民人均可支配收入16492元，增长9.0%。城乡居民收入增加，差距进一步缩小，由2016年的2.10：1缩小到2017年的2.09：1，扩大了消费预期。2017年，全市限额以上吃、穿和用类商品分别增长16.3%、17.0%和17.6%。

一是享受型消费较快增长。2017年，全市限额以上单位化妆品类商品零售额增长15.6%、金银珠宝类增长14.3%，增幅分别比上年高18.9个和10.6个百分点，拉动全市限额以上消费品零售额增长0.1个和1.1个百分点。

二是部分文化类消费高位增长。2017年，全市限额以上单位书报杂志类、通讯器材类商品零售分别增长42.6%和99.6%，增速均大幅高于全市限额以上消费品零售额。另外，文化办公用品类商品零售保持两位数增长，全年增速为14.5%。

三是家装类消费活跃。2017年，全市限额以上单位实现家具类商品零售额22.04亿元，增长21.0%；建筑及装潢材料类商品零售10.77亿元，增长31.9%，增速高于全市限额以上消费品零售额4.0个和14.9个百分点。

四是汽车类商品消费个位数增长。汽车消费更新换代加快，奔驰、奥迪等高价位车换代较快，市场行情较好，而普通车型如东风标致、别克等销售下降，但总体保持增长。2017年，全市限额以上企业汽车类商品零售额53.01亿元，增长7.1%，增速是上年的一半，比全省平均水平低5.1个百分点。

二、消费品市场发展应注意的问题

一是整体市场消费环境不容乐观。初步测算，2017年全市地区生产总值2045.19亿元，可比增长8.4%，增幅在上年回落1.6个百分点的基础上今年又回落0.5个百分点。受经济大环境需求低迷影响，部分大宗商品价格走低、高端红木家具市场需求萎缩，在一定程度上制约了消费市场发展，市场主体对消费需求期待不高。对37家大中型批零企业调查显示，“预计下季度商品销售增速比本季度”加快的占16.2%、持平的占70.3%和减慢的占13.5%；“ 您对下季度国内宏观经济形势的合理预期”乐观的占30%，一般的占64%，不乐观的占6%。

二是传统零售企业经营成本居高不下。 对部分企业电话调查显示：企业订单减少仍是导致零售行业业绩下降的主要原因，人员工资、租金是企业发展的两大瓶颈，加上库存积压、资金周转困难、同行竞争、资金担保及交通位置等因素综合影响，实体零售企业要轻装上阵还有较长的路要走。

三是商圈集聚能力有限。2017年只有天博广场达到城市综合体标准，万达广场、金鼎广场、正荣时代、正荣财富中心、联创等未能达到统计标准，且入驻单位大多为个体户、产业活动单位，法人企业较少，市场主体呈“小、弱、散”状态，缺少引领行业发展的大型商贸企业。

四是部分大宗商品预期消费不明朗。2017年汽车类商品零售额增长7.1%，占全市社会消费品零售总额的比重为7.6%，因市场竞争激烈、福州、厦门虹吸效应可能挤压本地市场，加上本地已有的汽车保有量，2018年汽车类消费实现较快增长有一定难度。2017年汽油单价波动，虽略有回升，但还维持在较低价位，全市限额以上单位成品油类消费增长1.0%，占全市社会消费品零售总额的比重仅4.5%（2016年为4.4%）。因其单价深受国际原油市场影响，2018年市场能否回暖，消费走势如何还是未知数。

三、2018年展望及发展建议

市政府初定了2018年全市社会消费品零售总额增长12.2%的目标，要完成这一目标，既有建设“美丽莆田”、加快供给侧结构性改革、进一步推进特色小镇建设、培育消费新动能等积极因素，但也面临经济下行压力、城乡居民收入增长放缓、新的消费热点不足等影响消费市场发展的不利因素。为更好地发挥消费基础性作用，提出如下建议：

（一）用好政策助推电商再发展。要利用特色小镇建设的有利时机，同时各县区要继续利用已出台的电商扶持政策，加快完善安福电商小镇建设，发挥市电商协会作用，促进电商企业抱团发展，鼓励更多的电商企业“走出去”拓展海外网络市场。要引导更多企业、更多行业进入和利用“互联网+”，特别是在不断完善交通、电信等设施的基础上，要持续推进农村电商项目。培育传统商贸企业向电子商务应用方向发展，实现线上与线下交易融合发展。

（二）要积极拓宽消费空间。要以本地优势产业如鞋业、红木家具、金银珠宝、工艺品等为依托，以产品质量为中心，顺应个性化消费需求，实现精准化、特色化营销和定制服务，不断加大享受型、发展型、智能型消费品的供给力度，以产品促进消费增长和结构转型。要加大全域旅游的推广力度，做好“妈祖”文化传播，吸引更多的游客来本市观光、购物。

（三）加大“工贸分离”力度。从2017年度调查单位审核确认工作情况来看，全市仅有2家“工贸分离”企业入库，入库效果不理想。有关部门要加大市场主体培育力度，完善相关配套措施，推动“工贸分离”进程。

（四）鼓励传统零售企业抱团发展。鼓励零售实体企业采取连锁经营形式，这样有利于提高企业品牌知名度，还节约成本，减少开支，有利于企业做大做强。

（五）增加居民收入，提升消费能力。要加大民生投入力度，进一步提高医疗、养老、失业等社会保障水平，稳步提高各类离退休人员养老金支付标准，提高最低工资标准，增加低收入人群的收入水平。要加快分配、税收等制度改革进程，多渠道促进居民增收，进一步提高居民消费信心和消费能力。
