上半年我市工业经济在去年成功应对金融危机冲击影响的基础上继续保持了加快回升态势。1-6月份全市规模以上工业企业实现工业总产值622.59亿元，同比增长29.2%，比上年同期、今年一季度分别高13.6个、2.4个百分点，增幅居全省九设区市第四位；完成工业增加值204.77亿元，同比增长24.1%，增幅居全省九设区市第三位。（见下图）
分县区看：秀屿区、仙游县、城厢区规模工业增幅超过
30%，北岸受湄洲湾火电厂停产检修影响，产值下降
27.6%（详见下图）。
一、上半年规模以上工业运行的主要特点
(
一)国有工业强劲增长。
在LNG系列生产拉动下，上半年国有企业保持快速增长的势头，实现工业总产值31.35亿元，比上年同期增长58.6%，增幅居全市各经济类型榜首，高于全市平均水平27.5个百分点。
(
二)“三资”工业快速回升，
民营工业拉动明显
。
随着我市经济的进一步好转，上半年我市外商及港澳台投资工业实现产值245.93亿元，同比增长20.9%，增幅比上年同期（-0.7%）回升了21.6个百分点。全市1076家民营工业企业实现总产值
480.23亿元，同比增长31.2%，拉动规模以上工业经济增长24.0个百分点。
(
三)大中型、亿元企业贡献增强。
上半年大中型企业完成工业总产值249.59亿元，同比增长23.5%，增幅比上年同期提高19.4个百分点，对规模以上工业增长的贡献率达32.2%，比上年同期高20.9个百分点。亿元以上企业达140家，实现工业总产值355.53亿元，同比增长35.1%，对规模以上工业增长的贡献率达62.5%，比上年同期高15.0个百分点。
(
四
)产业发展势头好。
上半年十大产业实现了全面增长，有七大产业增幅高于全市平均水平。其中工艺美术产业增幅居十大产业之首，同比增长
43.5%；制鞋业贡献最大，拉动全市工业经济增长８.2个百分点。（详见下图）
(
五)工业品出口回升。
随着国际经济走势继续向好，工业产品出口不断回升。上半年规模以上工业企业完成出口交货值133.10亿元，同比增长30.0%，增幅比上年同期高37.0个百分点。1-5月份占全市出口额四分之三的鞋类、汽车轮胎二类商品出口额上扬，进入全面复苏阶段。其中鞋类出口４.3亿美元，同比增长19.8%；汽车轮胎出口１
.２亿美元，同比增长29.7%。
(
六)产销衔接良好，多种工业品产量大幅增长。
上半年我市工业企业实现销售产值614.01亿元，产销率为98.62%，比上年同期提高0.41个百分点，居全省第二位，产销衔接良好。我市统计29种主要工业产品生产大多实现较快增长，其中表、涂料、日用玻璃制品、模具等产量增长幅度均在60%以上。（详见下图）

(
七)工业运行质量不断提高。
上半年规模以上工业经济效益综合指数为231.24%，比上年同期提高18.02个百分点；实现利润总额
16.00亿元，同比增长34.0%，增幅比上年同期高31.9个百分点。亏损企业87个，下降29.8%；亏损企业亏损额2.32亿元，增长3.8%。
二、需要关注的几个问题
(
一)国际经济全面复苏的基础尚不牢固，不确定因素依然很多。
当前，欧洲部分国家的主权债务危机仍未消除，欧洲乃至全球的金融市场动荡不安，欧盟和国际货币基金组织联手启动救援机制，并不断扩大救援资金规模。欧洲主权债务危机的影响深远，不仅直接损害欧洲经济复苏进程，而且很可能严重拖累世界经济复苏进程，从而影响到我国工业产品的出口需求。此外，主要货币汇率波动、国际资本跨境异常流动风险加大、国际大宗商品价格高位震荡、贸易保护主义抬头等因素都增大了世界经济复苏的不确定性。
(
二)工业总量偏小，新增投产企业规模偏小。
1-6月份我市工业总产值总量仅占全省6.4%，居全省九设区市第五位，只比第六位的三明市高0.2个百分点；新投产企业71家，实现工业总产值9.28亿元，户均产值仅一千多万元。工业经济总量低、新投产企业数少、企业规模偏小等问题困扰我市当前工业经济进一步发展。
(
三)缺工影响企业产能发挥。
目前占我市近60%的鞋服、食品、电子等劳动密集型行业企业普遍存在有订单、无工人现象，年初以来的缺工尤其是缺高级技工的现状仍未得到根本扭转，初步统计全市目前缺工最少在3万人以上。缺工短期将影响企业按期交货，失去订单，长期将导致部分企业外迁到招工容易或劳动力成本更低地区。
(
四)企业融资受担保制约。
今年以来央行已三次上调存款准备金率，国家信贷政策逐渐收紧，连续调整存款准备金率显示金融政策有所趋紧。进入６月份以来银行间市场资金面趋于紧张，各银行已暂缓或减少贷款发放，部分企业资金融资紧张，增加了企业运营资金成本。同时我市担保公司业务开展进程较缓，尽管目前注册的有22家，但运转的仅12家。
三、对下半年工业经济发展的预测和建议
上半年我市工业经济发展实现了良好开局，一方面得益于国家及地方扩内需、保增长、促发展等宏观经济政策持续稳定带动；另一方面受去年年初国际金融危机剧烈冲击影响，全球经济普遍快速滑落，客观上导致全市工业经济同期基数相对偏低。展望2010年下半年，全市工业经济发展机遇与挑战并存。首先，世界经济虽复苏缓慢但比预期要好，国际货币基金组织（IMF）最新预测，2010年全球经济预期增长4.2%，比原先预测调高0.3个百分点；其次，国家继续施行积极的财政政策与适度宽松的货币政策，宏观经济政策保持持续与稳定，并注重提高政策的针对性与灵活性；再次，去年国内经济明显复苏，2010年发展预期进一步好转，企业景气指数及企业家信心指数稳中趋升，企业生产经营状况明显好转。据企业景气调查，第二季度，企业景气指数和企业家信心指数分别为122.78和119.14，分别比上年同期上升11.16和16.53点，预示下半年市场走势将继续看好。内需消费在政策刺激下快速增长，对工业经济发展的带动作用不断增强。同时，工业经济运行也面临国际国内不确定性因素增多、生产成本上升、经营管理难度增大等困难。只要我们坚定信心，更加注重结构调整，加快构建现代产业体系，不断增强我市工业的发展后劲和竞争力，完成全年工业经济任务还是大有希望的。当前工业经济工作应着力抓好以下几个重点：
(
一)密切关注国际国内经济形势的变化，为企业生产经营创造有利条件。
目前的经济形势十分复杂，有些问题很难看得清楚，需要各级政府部门进一步加强经济运行监测，密切关注和正确分析形势的发展变化，确保判断准确、政策措施科学到位。要充分估计人民币汇率升值对工业出口企业的影响，为企业提供及时的信息服务，加快出口退税办理手续，减轻企业的资金压力。要落实扩大内需战略和重点企业直通车有关政策措施，营造良好的生产和销售环境。
(
二)做强工业总量。
要加强招商引资，引进大项目，发展大工业，继续引进新的、带动能力强的生产性项目，不断壮大工业经济体量。要加快在建工业项目建设进度，竣工要尽快投产，投产项目要尽快达产，努力培育新的经济增长点。要重点扶持快速成长型企业，着力培育重大龙头骨干企业，努力扩大规模，充分发挥工业产业化的聚集效应。
(
三)优化工业结构。
要大力发展临港工业项目，加快推进鞍钢冷轧、福人林业等重点项目建设，通过一批重大工业项目的落地建设和建成投产，推动临港重化工业产业集群的快速崛起。要鼓励企业加大技术改造，加强院企、校企、企业强强合作，大力提高企业自主创新的能力，推进企业加快转型升级。要大力实施品牌带动，着力提升品牌的知名度和影响力，推动产业品牌化、规模化发展。要坚持走新型工业化道路，更加注重新能源、新材料、新工艺、新技术等的拓展开发，加快工业经济结构的优化升级。
