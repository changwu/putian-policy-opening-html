促进“三孩”生育政策落实建议

第四十四期
发布时间：2022-08-17 16:12
| | |

党的十八大以来，党中央着眼人口发展的转折性变化，作出逐步调整完善生育政策、促进人口长期均衡发展的决策部署，相继出台“单独两孩”、“全面两孩”政策，对妇女生育产生积极的效应。2017年、2018年两年的人口出生率明显提高。2020年0至14岁少儿人口比重比2010年的提高，出生人口中二孩总量增加。2021年，国家颁布《中共中央 国务院关于优化生育政策促进人口长期均衡发展的决定》，作出实施一对夫妻可以生育三个子女的政策及配套支持措施，开启我国人口发展新阶段，旨在缓解人口长期处于低生育水平，推动实现适度生育水平，促进人口长期均衡发展。“三孩”生育政策的出台对于改善人口结构，积极应对人口老龄化趋势，保持人力资源供给，促进人与自然和谐共生具有重要的推动作用。但从2021年人口变动情况抽样调查中生育意愿调查访问情况看，莆田“三孩”生育成效不够明显，意愿不够强，仍有等待观望更积极优惠的配套支持措施落实。

一、育龄女妇女生育意愿调查访问情况

为了了解“三孩”生育政策实施情况，我市结合2021年人口变动情况抽样调查开展育龄妇女生育意愿调查访问。调查结果显示：

（一）超九成二孩育龄妇女不愿生“三孩”。人口变动情况抽样调查中生育意愿调查访问结果显示，54.6%的育龄妇女认为最理想的子女个数是两个，已生育两孩的育龄妇女中，97.4%表示不愿再生第三孩。

（二）抚养成本高成为不愿生三孩的主要原因。61.6%的育龄妇女表示抚养成本高，经济负担重，成为不愿生育第三孩的第一主要原因，16.4%的育龄妇女表示年龄过大或身体状况欠佳，4.9%育龄妇女表示入托、入学等公共服务不能满足需求、担心工作受到影响、子女无人照料。

二、促进“三孩”生育的政策建议 

（一）强化资源配置，降低三孩养育成本 

1、合理配置教育资源。坚持教育优先发展战略，以推进义务教育均衡发展，优化教育资源配置，逐步实现义务教育的均衡发展。实施高位推动教育规划、投入、保障用人用地、待遇从优等，促进资源合理配置均衡。实行区域轮岗调配机制，推动教师区域交流，优化师资力量均衡化。突出创新发展促进办学均衡。加大公立幼儿园投资建设力度，开设三孩幼儿入托、入园和小学阶段的“绿色通道”，实现三孩幼儿就近入园、方便入园。引导和鼓励社会力量举办幼儿园，建设一批符合育儿资质的普惠性民办幼儿园。通过学校托管、联校办学、教师交流等，促进学校均衡发展，保障入学需求，缓解城乡差异产生的一系列问题。 

2、优化配置医疗资源。加快妇幼健康服务体系建设。在乡镇卫生院增设产科儿科，配足配强产科和儿科医护人员。同时加快产科和儿科医师、助产士及护士人才引进和培养，可考虑对此类人员在职称评定、报酬待遇等方面给予政策倾斜，确保能够吸引到人才，留得住人才。引导和鼓励社会力量兴资办医，投建非营利性妇女儿童医院，最大限度满足群众需求。 

3、建立完善婴幼儿照护服务体系。探索建立理念领先、特色鲜明的婴幼儿照护服务管理模式，完善家庭、社区、机构“三位一体”的服务网络，以多元服务满足城乡家庭的不同需求。多种形式鼓励和支持社会力量举办托育服务机构。加大社区对婴幼儿照护服务的支持力度，有条件的社区应兴办福利性的婴幼儿托育服务。小学、幼儿园要逐步推行“课后服务”方便上班族家长按时接送子女。相关部门要加强育婴师、婴幼儿看护人员的职业培训，增加人力供给。 

（二）保障妇女生育权益 

1、保持工作岗位稳定。制定妇女生育期间工作岗位稳定制度，不得因妇女怀孕、生育、哺乳期间而解雇或辞退。产假期满根据妇女的意愿，允许还回原岗位就业或辞职。产假期间用人单位（非公有制企业）应支付一定比例的劳动报酬，由企业属地的县级财政负担。 

2、适当延长产假和护理假。制定三孩产妇、配偶护理假期延长制度，期间的工作待遇保持不变，不要因种种原因克扣产妇工资。 

3、完善妇幼健康全方位服务。全面实行妇幼健康免费服务，包括结婚医学检查、妇科肿瘤筛查、孕产妇的相关检测等。拓展妇幼健康特色保健服务，降低孕产妇和幼儿死亡率，控制和减少出生缺陷发生率。 

4、构建三孩生育服务指导平台。通过设立再生育门诊服务、孕妇专班学习等为孕妇提供精准服务，为不孕不育等生育困难者提供辅助生殖技术服务。 

（三）实行相关扶助制度和优惠政策

全面落实具体的配套支持措施，出台三孩家庭的低利率房贷政策；将三孩的医疗保健、教育费用等纳入个人所得税附加扣除项目；降低第三孩子女的幼儿园及九年义务入学门槛，实行第三孩子女升学分数奖励制度；将婚嫁、生育、养育、教育一体考虑，加强适婚青年婚恋观、家庭观教育引导，坚决扼杀婚假陋习、天价彩礼等不良社会风气。
