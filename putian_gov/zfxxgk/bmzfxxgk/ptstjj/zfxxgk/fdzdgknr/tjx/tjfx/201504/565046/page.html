2015年1-3月份我市房地产运行情况简析

发布时间：2015-04-21 00:00
| | |

随着宏观经济形势稳中趋缓，政府房地产调控政策调整迹象逐渐显现，但是宏观经济和政策现实向房地产市场供求双方分别提供了不同的信号，导致供给方保守中渐趋乐观与需求方的观望等待并存。在市场供求前景未能明朗的条件下，总体上，2015年1-3月份我市房地产开发投资保持增长态势。

一、莆田市房地产运行情况

（一）房地产开发投资快速增长

1-3月份，房地产开发投资突破80亿元，投资增幅达到近2年新高。莆田市房地产开发投资完成87.09亿元，同比增长23.2%，增速比上年同期提高18.4个百分点。其中住宅完成投资56.71亿元，增长32.0%；办公楼完成投资5.75亿元，下降 11.6%；商业营业用房完成投资11.91亿元，增长5%；其它类型房屋完成投资12.72亿元，增长28.7%。其中，住宅投资仍为房地产投资主要流向，占全部投资总量的70.9%（见表1）。

（二）影响市场供给的先行指标快速增长

1、土地购置费大幅增长。1-3月份，莆田土地购置费为16.22亿元，增速由去年同期的1.3%转为今年的增长72.1%，土地购置费大幅增长。

2、全市房地产开发企业资金状况好转。1-3月份，本年资金来源小计101.67亿元，增速由去年同期的下降9.5%转为今年的增长14.8%，比上年同期提高24.3个百分点分，资金来源来看，国内贷款为12.87亿元，同比增长18.0%，其中，银行贷款12.87亿元，同比增长45.8%，自筹资金为48.47亿元，同比增长14.6%，其他资金来源40.33亿元，同比增长14.0%。定金及预收款21.23亿元，同比增长25.0%；个人按揭贷款6.94亿元，同比下降44.3%。

（三）房地产销售面积回升

1-3月份，房地产销售面积与去年低迷状态形成反差，从去年4月份房地产销售面积负增长以来，首次出现转正。商品房销售面积78.09万平方米，增长13.3%，增速比上年同期快4个百分点。其中住宅销售面积70.53万平方米，增长17.6%；办公楼3.51万平方米，增长16.5%；商业营业用房3.52万平方米，下降32.3%；其他房屋0.52万平方米，下降33.3%%（见图1）。

二、莆田市房地产运行存在问题

（一）房地产销售额持续下降

1-3月份受安置房销售价格较低的影响，我市房地产销售额在销售面积回升的情况下，却呈现出持续下降的趋势。商品房销售额47.20亿元，下降16.8%。其中住宅39.06亿元，下降17.7%；办公楼2.86亿元，下降7.1%；商业营业用房4.58亿元，下降13.8%；其他房屋0.7亿元，下降21.5%。

（二）待售面积持续增长

1-3月份，房屋待售面积为212.02万平方米，同比增长45.5%。其中，住宅待售面积97.30万平方米，同比增长48.5%；待售1—3年(含1年)面积136.88万平方米，增长40.1%；待售3年以上(含3年)面积11.21万平方米，增长14.2%。待售面积增长，使得房地产消化库存压力大。

三、莆田市房地产运行建议

（一）调整商品房供应结构，激活房地产开发市场

住房需求的总量决定住房供应总量，因此无论是房地产开发商还是政府职能部门都要根据市场需求来调整供给。一是合理规划，统筹考虑；二是从需求出发，坚持“抓两头、促中间”，既要成规模、高品位地开发建设精品工程，创造优质人居环境，引导和满足市场需求，又要充分考虑能更利于人口集聚的小户型商住房的开发建设。

（二）督促已购土地企业尽快开工建设

房地产开发投资中的土地购置费的确认必须在项目开工后才能填报，如果房地产企业只是购买土地而尚未开工建设，是不能填报土地购置费，所以应督促已购买土地的房地产企业加快开工建设，并在进行土地招拍挂的时候能要求企业在一定期限内开工建设或倾向于能马上开工的企业。

（三）房地产开发投资额各县区分布不平衡

从各县区看，荔城区房地产开发投资增幅处于比较活跃的态势，1-3月份，荔城区房地产投资额34.14亿元，增长98.2%，占全市房地产开发投资的39.2%；其次是城厢区，房地产投资额27.32亿元，增长45.9%，占全市房地产开发投资的31.9%；其他的各县区都是负增长，尤其是秀屿区，房地产投资额仅0.77亿元，下降69.1%，占全市房地产开发投资仅1%，下降幅度全市第一（见表2）。
