1-5月全市规模以上服务业增速全省第一

第三十四期
发布时间：2020-07-03 15:51
| | |

今年以来，莆田市各级各部门认真贯彻落实省委、省政府决策部署，统筹推进疫情防控与经济社会发展，落实落细各项帮扶优惠政策，帮助企业解决困难，助推服务业企业加快恢复正常经营，政策效果逐步显现。1-5月，全市规模以上服务业营业收入87.96亿元，增长37.7%，增速比1-2月提高35.2个百分点，比全省平均水平高38.1个百分点，居全省第一位。

一、主要亮点

（一）交通运输、仓储和邮政业强势发力。受物泊科技有限公司营业收入快速增长拉动，1-5月，全市该行业营业收入49.44亿元，同比增长102.1%，对全市规模以上服务业营业收入增长的贡献率高达101.7%，拉动规模以上服务业营业收入增长38.3个百分点。其中，道路运输业营业收入增长145.6%；多式联运和运输代理业营业收入增长24.6%。

（二）租赁和商务服务业贡献突出。1-5月，全市该行业营业收入17.94亿元，增长16.0%，对全市规模以上其他营利性服务业营业收入增长的贡献率高达220.8%，拉动规模以上其他营利性服务业营业收入增长10.8个百分点，是拉动我市其他营利性服务业营业收入增长的主要动力。主要支撑因素：一是受福建优之源模架租赁有限公司、福建省仙游县松琴机械设备租赁有限公司、莆田市芷文机械租赁有限公司等新增企业拉动，全市租赁业实现营业收入2.04亿元，增长1.4倍，对全市其他营利性服务业营业收入增长的贡献率达106.9%，拉动其他营利性服务业营业收入增长5.2个百分点；二是受瑞智无忧（福建）科技有限公司、莆田云智薪共享经济信息咨询有限公司等两家新开业企业强劲拉动，全市商务服务业实现营业收入15.91亿元，增长8.7%，对全市其他营利性服务业营业收入增长的贡献率达114.0%，拉动其他营利性服务业营业收入增长5.6个百分点。

（三）科学研究和技术服务业较快增长。1-5月，全市该行业营业收入0.78亿元，增长11.6%，增速高于其他营利性服务业6.7个百分点。其中，科技推广和应用服务业增长3.6倍，主要受莆田卓宇信息技术有限公司、莆田市智君信息服务有限公司两家新增企业拉动。

（四）居民服务业稳步回升。1-5月，全市规模以上居民服务、修理和其他服务业营业收入1.29亿元，增长10.5%，增速分别比1-2月、1-3月和1-4月回升16.5、17.8和10.5个百分点。主要原因是莆田市夏达家政服务有限公司和莆田市诚铭投资管理有限公司2家企业在疫情趋于稳定后业务量大幅增加，拉动全市该行业营业收入增长12.6个百分点。

二、主要问题

1-5月，全市规模以上其他营利性服务业营业收入24.13亿元，增长4.9%，增幅低于全省平均水平0.4个百分点，居全省的位次由1-4月的第三位回落至第六位。

（一）互联网服务、软件和信息技术服务业下降明显。1-5月，全市该行业营业收入3.15亿元，下降18.2%，拉低全市规模以上其他营利性服务业营业收入增速3.0个百分点，主要原因是该行业缺少规模较大的企业拉动，存量企业拉动力不足，其中，3家退库带基数和13家营业收入负增长的企业共拉低该行业营业收入增速35.1个百分点。

（二）文化、体育和娱乐业持续负增长。全市该行业受新冠肺炎疫情冲击影响较大，部分企业仍处于歇业状态，行业营业收入明显下降。1-5月，全市该行业营业收入0.96亿元，下降47.1%，连续四个月呈负增长态势，扭负为正压力较大。其中，广播、电视、电影和录音制作业营业收入下降81.9%，娱乐业营业收入下降27.3%。

（三）各县区发展不平衡。1-5月，湄洲岛、城厢区、涵江区和仙游县规模以上其他营利性服务业营业收入增速均高于全市平均水平，分别为68.2%、35.3%、20.5%和11.5%。秀屿区、北岸和荔城区其他营利性服务业营业收入增速均低于全市平均水平，呈负增长态势，其中：秀屿区下降40.6%，拉低全市增速6.1个百分点；北岸下降34.1%，拉低全市增速3.5个百分点；荔城区下降3.2%，拉低全市增速0.7个百分点。

（四）发展后劲不足。2019年末以来，全市新增入库规模以上其他营利性服务业企业40家，比上年减少33家，截止5月底全市无月度新增入库企业，发展后劲不足，随着上年同期基数不断加大，其他营利性服务业增速提升进位压力较大。目前，全市其他营利性服务业增长主要靠新增企业拉动，扣除新增企业，1-5月存量企业营业收入下降24.6%，低于全市平均水平29.5个百分点，拉低全市其他营利性服务业增速23.2个百分点。其中，有140家企业营业收入负增长，占比50.4%，拉低全市其他营利性服务业增速34.8个百分点。

三、若干建议

（一）构筑服务发展“大格局”。一是建议各县区、各部门按照“全市统一领导、市三产办牵头、部门归口管理、县区分级负责、各方共同参与”的原则，进一步明确服务业行业牵头部门、配合部门职责，夯实工作责任，紧盯目标、细化措施，突出重点、合力推进，构建服务业发展良好工作格局；二是在产业布局上，重点培育贴近服务人民群众生活、需求潜力大、带动作用强的生活性服务短板领域，促进和带动其他服务业领域发展；三是有关部门要加强对规模以上服务业企业的监测和引导，跟踪了解企业经营状况，协调解决企业生产经营中的问题，务实精准帮扶，确保惠企政策及时兑现和精准落地，促进服务业持续健康向好发展。

（二）推进城市能级“大提升”。一是将招商引资与招才引智结合起来，创新实施“壶兰人才计划”，通过引进一个高层次人才、带来一个创新团队、落户一批重大项目，促进一个产业发展。二是大力建设主导产业明确、专业分工合理、差异化发展鲜明的服务业园区，优先支持和保障园区加强园区规划制定实施和二次招商政策引导，推动产业园区高水平建设、高端化发展和特色化集聚，以加快全市服务业多点多极转型发展。三是始终把营商环境建设作为一项“永不竣工的工程”，全力打造政策更优、门槛更低、审批更少、服务更好的投资环境，吸引服务业大型企业落户，推进服务业重大项目建设，壮大行业规模，争取新培育一批大型标杆企业，改变全市服务业企业规模偏小、盈利能力弱的现状，增强发展后劲。

（三）推动产业融合“大升级”。一是推动现代金融、现代物流、科技服务、信息服务等生产性服务业提档升级，促进生产性服务业与现代制造业、现代农业深度融合，加快生产性服务业专业化、高端化发展。二是以信息化、网络化、便利化为方向，积极培育服务业新业态新模式。积极引进智能型、信息技术型企业，将“互联网+”融入健康养老、社区服务、文化娱乐等领域。加快第三产业与第一、二产业和扶贫产业融合发展，充分利用互联网、云计算、大数据、物联网、“互联网+”等新技术，聚焦产业链对接，推动服务业向价值链高端延伸，提高服务业发展质量，促进产业转型升级。三是本次疫情给服务业带来冲击的同时也带来了新的发展机遇。相关部门可为企业发展提供更多公共服务应用场景，拓展市场空间，助推企业破土成长，培育经济发展新动能。增加智慧交通、智慧医疗、智慧管理、智慧通信、智慧教育等公共服务应用场景，将大数据接入公共服务，以应用促产业升级，进一步助力城市治理能力现代化。

撰稿：许燕华 阮建霞
