2018年上半年莆田市规模以上工业经济运行分析

第三十六期
发布时间：2018-07-19 16:26
| | |
 今年以来，全市围绕经济发展战略目标，科学施策、深化改革、加快转型、积极创新，进一步夯实了工业经济发展基础，全市工业经济迈向高质量发展的步伐加快。上半年全市工业经济稳中向好、增幅稳步回升，后续持续向好可期。

一、工业经济运行主要特点

（一）工业生产持续回暖。上半年，全市规模以上工业增加值增长8.9%,比1-5月、1-4月和1-3月分别提高0.2个、0.7个和1.0个百分点，比2017年全年增幅提高0.7个百分点，排名位居全省九设区市第三位，与1-5月相同，比1-4月、1-3月分别提升二位和一位。全市工业经济稳中向好的发展势头继续保持。从全市规上工业33个大类行业来看，有23个行业工业增加值实现增长，增长面为69.7%。

（二）工业先行指标支撑有力。一是工业用电量持续保持较快增长。上半年全市工业用电量41.95亿千瓦时，增长33.4%，今年以来增幅持续保持20.0%以上的高速增长，位居全省九设区市第一位。其中，制造业用电量增长38.6%，持续保持快速增长的态势。二是工业增值税增长给力。上半年全市工业增值税增长33.5%，比1-5月提高18.4个百分点，已连续4个月保持两位数增长。

（三）工业景气指数处于较为景气区间。据工业景气调查结果显示，二季度企业家信心指数和工业企业景气指数分别为128.3和127.1，两项指数依然落在较为景气区间，持续保持去年一季度以来较为景气的区间，表明我市工业经济趋于平稳。

（四）重工业增长相对较快。上半年，全市规模以上轻工业增长7.2%，增幅比上年同期低1.4个百分点，对全市规模以上工业增长的贡献率为61.7%，拉动全市规模以上工业增加值增长5.5个百分点。规上重工业增长13.3%，增幅高于轻工业和上年同期6.1个、7.3个百分点，对全市规模以上工业增长的贡献率为38.3%，拉动全市规模以上工业增加值增长3.4个百分点。

（五）园区工业企业稳增长。上半年，全市工业园区共有695家规模以上工业企业，占全市规上企业数的57.0%，工业增加值增长8.5%，低于全市规上工业平均增速0.4个百分点，但总体保持稳定，对规模以上工业增长贡献率为62.6%，拉动全市规模以上工业增加值增长5.6个百分点。

（六）传统制鞋及“33”产业支撑明显。上半年，全市制鞋产业工业增加值增长11.4%，对规模以上工业经济增长的贡献率为33.8%，拉动规模以上工业增加值增长3.0个百分点。一是内销市场的开拓。预计全年约7500万双的“足力健”老人鞋订单在莆生产，以及安踏等一些国内品牌的订单明显增多。二是订单的回流。往年转移到东南亚的制鞋订单受税费、基础设施及工人素质等因素影响，逐步回流到国内生产。三是足球世界杯经济效应的影响。6月全市制鞋业本月出口交货值增长14.7%，比5月提高5.7个百分点，出口量明显增加。

“33”产业平稳增长。上半年，全市“33”产业工业增加值增长8.2%，虽比全市规上工业增速低0.7个百分点，但比上年同期增速高0.3个百分点，对规模以上工业经济增长的贡献率为50.2%，拉动规模以上工业增加值增长4.5个百分点。其中，化工新材料增长12.2%，工艺美术产业下降0.8%，食品加工业增长2.1%，电子信息产业增长35.1%，高端装备产业增长7.9%，医疗产业增长8.0%。

（七）亿元企业增势强劲贡献突出。上半年，全市超亿元以上规模企业共有395家，占规模以上工业企业单位数的32.4%，工业增加值增长20.4%，高于全市规模以上工业平均增速11.5个百分点，对规模以上工业增长贡献率达150.8%，拉动全市规模以上工业增加值增长13.4个百分点。

（八）新投产工业企业拉动力加强。上半年全市16家去年新投产企业对规模以上工业经济增长的贡献率为33.0%，拉动规模以上工业增加值增长2.9个百分点，比1-5月提高0.2个百分点。

（九）民营企业生产趋稳。上半年，全市规模以上民营企业工业增加值增长7.0%，占全市规上工业增加值总量81.2%，对规模以上工业经济增长的贡献率为68.3%，拉动规模以上工业增加值增长6.1个百分点。

（十）结构调整步伐稳健。上半年，全市战略性新兴产业、高技术企业、装备制造业增加值分别增长22.5%、20.8%、7.6%，除装备制造业增速低于全市规上工业增速1.2个百分点外，战略性新兴产业、高技术企业分别高于全市规上工业增速13.6个、11.9个百分点。高耗能企业增加值增长15.6%，增幅低于1-5月0.9个百分点。

（十一）新动能发挥初显成效。上半年，全市108家规模以上工业投入技改，占全市规上工业企业数的8.9%，实现工业增加值占规上工业增加值总量的18.9%，增长17.7%，对规模以上工业经济增长的贡献率为31.4%，拉动规模以上工业增加值增长2.8个百分点。

二、存在问题

（一）停、减产企业影响仍旧明显。6月末，全市停、减产面28.1%，比5月低2.3个点，共拉低全市规上工业增加值增幅8.4个百分点。其中停产企业100家，比5月末增加3家，拉低全市规上工业增加值增幅6.1个百分点；减产企业243家，比5月末减少31家，拉低全市工业规上增加值增幅2.3个百分点。

（二）规上工业企业及新投产入库数减少，转规企业拉动力有限。6月末，全市共有规模以上工业企业1220家，但比上年同期减少42家。截止6月底，全市仅1家工业企业达规上报入库材料。37家去年年底转规企业对规模以上工业增加值增长的贡献率为4.3%，仅拉动规上工业增加值增长0.4个百分点。

（三）传统工艺美术产业不景气。受红木市场不景气及企业转型阵痛期影响，1-6月我市规上工艺美术产业工业增加值下降0.8%，拉低全市规上工业增加值增长0.1个百分点。

（四）企业增产不增效，降成本任重道远。1-5月，全市规模以上工业企业利润总额下降2.1%，低于全省平均水平16.9个百分点。主要是部分新投产的企业亏损影响以及代工企业效益逐年下降影响。工业产成品存货高居不下，增长36.2%，高于1-5月、上年同期2.9个、32.5个百分点。每百元主营业务收入中成本87.93元，比上年同期增加1.24元。

（五）部分规模企业达产不达效。上半年，全市规上存量工业企业工业增加值增长4.8%，低于全市规上平均增速4.1个百分点。去年新投产的部分企业与企业设计的产能差距较大，存在达产不达效的现象。
