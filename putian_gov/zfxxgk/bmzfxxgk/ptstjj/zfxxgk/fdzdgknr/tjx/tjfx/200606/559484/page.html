促进协调发展 构建和谐社会

发布时间：2006-06-12 00:00
| | |

一年来，在市委、市政府的正确领导下，全市上下以科学发展观为指导，认真贯彻落实“三个代表”重要思想和党的十六届三中、四中、五中全会精神，按照省委提出“构建三条战略通道，推进三个层面发展”和“建设海峡西岸经济区”的战略，围绕全面建设社会主义和谐社会的宏伟目标和市委提出“建设新兴港口城市”的战略目标，求真务实，开拓创新，全方位、深层次、宽领域地推进改革开放，实现经济发展与社会全面进步。

一、基本情况和特点

（一）国民经济持续增长，运行质量不断提高，为社会发展奠定了坚实的物质基础。

1、国民经济持续增长。2005年，全市生产总值达到359.93亿元，比上年增长15.3%。人均生产总值达12855元，比上年增长18.9%。

2、产业结构继续调整。第二产业比重继续上升，一、二、三产业增加值占生产总值的比重由2004年的14.8%、50.6%、34.6%调整为2005年的14.0%、53.9%、32.1%。

3、运行质量不断提高。全市财政总收入29.46亿元，比上年增长18.2%，其中地方级财政收入14.56亿元，比上年增长26.6%。人均地方财政收入518元，比上年增加152元；人均财政支出694元，比上年增加67元。全年全社会劳动生产率达23080元，比上年增长19.4%。

（二）保持低生育低增长，人口结构明显变化，人口素质不断提高。

1、人口总量适度增长。2005年末，全市常住总人口281万人，比上年末增加2万人。人口出生率为12.5‰，比上年下降0.1个千分点；自然增长率为6.7‰，比上年上升0.1个千分点。

3、人口素质不断提高。据“五普”结果表明，全市人口平均预期寿命达73.5岁；2005年6岁及以上人口人均受教育年限7.59年，比上年提高0.13年；青壮年识字率达95.35%，比上年提高2个百分点；全市离婚对数4351对，比上年增长30.1%。人口素质的不断提高，促进了社会事业的全面发展。

（三）就业规模不断扩大，就业技能不断提升。

1、就业领域不断拓宽。2005年，全市共有从业人员160.37万人，其中女性79.77万人。城镇单位从业人员27.97万人，比上年增加2.85万人，增长11.35%。从业人员占全市15—64岁常住人口的比重达81.76%，比上年提高0.85个百分点，其中第三产业就业人员的比重达28.64%，比上年下降0.59个百分点。

2、城镇登记失业率控制良好。2005年，我市各级政府围绕经济发展，坚持以推进就业、再就业为重点，落实再就业各项优惠政策。全市新增就业人员26185人，完成年计划124.7%；城镇下岗失业人员实现再就业2181人，完成年计划的109%；“4050”人员再就业387人，完成年任务的129%；城镇登记失业率控制在2.49%，比去年提高0.03个百分点，但仍低于省政府下达控制3.2%目标的0.71个百分点。

（四）居民收入不断增长，生活质量稳步提升。

1、城乡居民收入不断增长，消费水平不断提高。2005年全市城镇居民可支配收入和农村居民人均纯收入分别达到11026元和4486元，比上年增长7.8%和9.6%；城镇居民人均消费性支出和农村居民人均生活消费支出分别为8469元和3250元，比上年增长11.5%和9.8%；城镇居民人均可支配收入最高与高低收入户差距为3.38倍，比上年下降0.62倍；居民储蓄存款余额达231.64亿元，比上年末增加29.68亿元，增长14.7%。

2、生活条件得到改善，生活质量稳步提升。2005年，城市人均住房建筑面积和农村人均居住面积分别达到34平方米和56.8平方米，比上年增加0.8平方米和1.9平方米；恩格尔系数分别为42和46.5，比上年下降4.3个百分点和0.4个百分点；人均生活用电229千瓦时，比上年增加24千瓦时，增长11.7%，人民生活水平和质量的提升，为社会发展夯实基础。

（五）社会保障程度得到加强，社会福利事业继续发展。

1、社会保障程度进一步加强。2005年末，全市参加养老保险人数为26.04万人，其中参加城镇基本养老保险的人数为16.59万人，比上年增加2.2万人，增长15.3%；参加农村社会养老保险参保的人数为9.45万人，比上年增加0.1万人，增长1.1%。参加失业保险、基本医疗保险、工伤保险和生育保险的人数分别达12.68万人、14.01万人、11万人和7.04万人，比上年分别增加0.21万人、0.5万人、1.2万人和0.09万人，增长2.2%、3.8%、12.1%和1.3%。全年共支出养老、失业、医疗、工伤、生育保险基金3.76亿元，比上年增加0.93亿元，增长32.8%。

（六）加大卫生保健投入，人民健康得到保障。

1、卫生基础投入进一步加大。2005年，我市财政投入公共卫生服务经费68487万元，比上年增加8162万元，增长13.5%。同时，全市医疗急救体系和疾病控制体系建设列入国债项目。卫生技术人员达6795人，比增12%，其中执业医师及执业助理医师2509人。

图五：

2、妇幼保健工作进一步加强。我市认真贯彻实施2001—2010年《莆田市妇女发展纲要》和《莆田市儿童发展纲要》。2005年，我市孕产妇死亡人数6人，死亡率为16.28／10万，比上年上升1.56／10万，但仍低于全省平均水平。5岁以下儿童死亡率和新生儿死亡率分别为13.32‰和11.56‰，比上年下降1.4个千分点和提高2.32个千分点；传染病发病率为255.43／10万，比上年下降1.43／10万。

（七）各类教育稳步推进，科技开发取得新进展。

1、全面普及九年义务教育，性别差异基本消除。我市认真实施“双高普九工程”，义务教育和学前教育发展水平再上新台阶。2005年度，全市教育经费支出达74503万元，比上年增加9732万元，增长15.03%；适龄儿童小学净入学率达到99.58%，比上年提高0.16个百分点，其中男童99.22%，女童100%；小学6年巩固率达到92.52%，其中男生92.85%，女生92.16%；小学生辍学率控制在0.21%，其中男生0.22%，女生0.21%；初中学生毛入学率和升学率分别达到108.24%和82.83%，比上年提高2.13个百分点和11.27个百分点，其中男生108.28%，女生108.18%；初中三年巩固率达到92.98%，其中男生92.99%，女生92.97%；九年义务教育完成率77.7%，比上年提高1.5个百分点，九年义务教育中的性别差异基本消除。高中阶段在校生人数达7.49万人，比上年增加0.73万人，增长10.8%。

2、高等教育实现突破，规模不断扩大，成功申办莆田学院。莆田学院实现专升本，填补了我市本科教育空白；湄洲湾职业技术学院正式升格，高等教育规模进一步扩大。目前在校大学生1.3万人，比上年增加0.41万人，增长46.1%；其中，女生0.66万人，比上年增加0.19万人，增长40.4%。

（八）文化体育事业稳步推进，精神文化生活日益丰富。

1、文化事业稳步发展。2005年末，我市每万人口拥有公共文化机构0.67个，比去年增加0.11个；拥有公共图书馆藏书15.73万册，比上年增加0.35万册，增长2.3%；订销报纸总计2217.55万份，比上年减少211.5万份，下降8.7%。农村人均文教娱乐用品及服务支出393.47元，比上年增加72.91元，增长22.7%；每百户城镇居民家庭拥有的家庭电脑52台，比上年增加7台，增长15.6%。文化精品不断涌现。举办为期2个月的市第四届农民电影节；成功举办第七届中国湄洲妈祖文化旅游节、为纪念妈祖诞辰1045周年以“妈祖缘、中华情”为主题的文艺晚会。同时组织对外文化交流，做好文物保护单位升格和“湄洲妈祖祖庙祭奠”、“莆仙戏”等国家级、省级非物质文化遗产申报工作。

 
 
 

 

2、广播电视事业稳步发展。2005年末，全市拥有无线广播电台1座，县(区)广播台(站)3个，乡镇有线广播站49个，调频广播发射台4座。广播电视线路得到升级改造，广电中心主体投入使用。广播人口综合覆盖率为98.01%，比上年提高0.3个百分点；电视人口综合覆盖率为98.09%，比上年提高0.01个百分点。

3、体育事业蓬勃发展。2005年，全市共有1356个体育场地，人均场地面积为0.92平方米。参加省常规赛并计入13届省运会10枚金牌、6枚银牌、5枚铜牌；我市运动员宋健在参加亚运会取得跳远第一名；仙游县少体校被评为“全国青少年体育俱乐部”；莆田一中被评为全国体育传统校先进单位。成功举办全市中小学生运动会和校际田径对抗赛；组织参加第三届全国篮球城市“市长杯”篮球赛，获得第一名；在全省老体协“亿万老年人健身活动”展示暨秧歌、缴灵圈健身操汇演中，获得优胜奖；在全国老年人气排球比赛中获得冠军。

（九）环境保护得到加强，生态环境不断改善。

1、生态环境保护工作取得成效。开展生态调查，编制莆田市、仙游县生态功能区划，强化生态保护工作。创建5个园林式乡镇、50个园林式村庄、500个绿化单位和3万户绿化农户。创建国家环境优美乡镇1个（荔城区西天尾镇）、省级生态示范乡镇7个（仙游西苑乡、象溪乡、书峰乡、石苍乡和涵江大洋乡、萩芦镇、白沙镇)。加大水土流失治理力度，减少水土流失面积16.5万亩；木兰溪流域流失治理下泄泥沙减少40%；人为新的水土流失控制在1000亩以内；实施6个省重点治理项目和2个市级精品示范工程。全市划定的国家级和省级生态公益林中水土保护林54200公顷，水源涵养林81659公顷，许多严重流失区变成龙眼、枇杷、橄榄等名优水果生产区。2005年末，城市人均公共绿地面积6.04平方米，比上年增长1%。

2、重点污染源进一步有效遏制。2005年，全市二氧化硫、烟尘和粉尘、化学需氧量、氨氮以及工业固废六种主要污染物排放量，均控制在省下达的计划指标内，其中：工业废水排放达标率、工业固体废物综合利用率、城市生活污水处理率和城市生活垃圾无害化处理率分别达93.45%、92.21%、63.01%和94.96%，比上年分别提高-0.26个百分点、2.08个百分点、17.46个百分点和0.66个百分点。

（十）社会治安不断改善，群众安全感进一步提高。

按照建设“平安莆田”的总体要求，全力维护社会安全稳定。2005年，全市公检法司财政支出达15492万元，比上年增加1927万元，增长14.2%，占地方财政支出的比重为8.09%，比上年提高0.39个百分点；人民警察数2175人，比上年增加47人；交通事故死亡212人，比上年减少47人，下降18.2%；火灾、交通事故死亡人数占当年死亡人数比重0.13%，比上年下降1.44个百分点；交通事故及火灾事故损失额为182.32万元和394.35万元，比上年分别下降302.1万元和上升7万元；治安案件查处数21255件，比上年增加297件，增长1.4%。

二、存在问题

（一）经济总量偏少，严重影响社会全面发展。2005年，全市常住人口占全省7.95%，GDP增幅15.3%，位居全省第二，但GDP总量占全省仅为5.49%，财政总收入为全省的3.95%，地方财政收入占财政总收入的49.42%，低于全省水平1.85个百分点，仅为全省地方财政收入的3.81%。地方财力不足，严重制约社会事业的发展。

（二）社会保障体系亟待进一步完善。2005年，我市各级政府虽然加大社会保障经费的投入，但解决脱贫任务仍然十分艰巨，最低生活保障线以下人口9.78万人，占总人口的3.48%。农村社会养老保险工作尚在起步，2005年参保人数为9.45万人，仅为农村总人口的3.84%。

（三）文化卫生事业滞后。2005年全市每万人拥有公共图书馆图书数0.06册，仅为全省平均水平0.36册的16.67%；每万人拥有卫生技术人员和卫生机构床位数为26.7人和19张，分别低于全省平均水平33.6人和25张的6.9人和6张，仅为全省平均水平的79.56%和76%。

（四）环境保护压力仍然存在。木兰溪和萩芦溪污染负荷没有得到根本性的缓解，南北洋河网和城市内河水质较差；医院废弃物处理、畜禽养殖业污染治理和乡镇生活污水、垃圾处理问题尚未得到很好解决；企业擅自停运治理设施、漏偷排污水的现象时有发生；城市油烟、噪声扰民等环境设诉居高不下；水土流失、过度垦荒、挖沙采石、乱砍乱伐等现象依然存在，生活饮用水源地生态环境综合整治的任务比较繁重。

（五）不同地区差别突出。由于受历史、自然、社会、经济等因素的影响，城乡二元格局依然存在，导致了城市与农村、平原与山区在教育、卫生、文化体育等方面的差异较大，影响社会的和谐、协调发展。

（六）社会治安形势仍然不容乐观。2005年，火灾事故造成的损失额比上年增加7万元，上升了1.8%。治安、刑事案件时有发生，刑事案件立案数比上年减少33件，但仍居高不下。青少年刑事案犯占全部刑事案犯的比重仍然偏高，比去年上升0.3个百分点。刑事案件破案率不高，特别是流窜犯罪时有发生，且破案难度加大。

（七）流动人口的管理跟不上形势发展要求。我市是沿海开放地带，近年来，人口流动日趋频繁。从总体来看，流入人口文化素质偏低，自我保护和法律意识相对淡薄，加上现有一些制度尚未完善，造成流动人口在子女就学、卫生保健、社会保障、法律援助等方面同当地居民相比，存在明显差距，同时也造成社会不稳定的隐患。

三、建议

（一）加强领导，进一步强化政府职能。坚持党政领导挂帅、职能部门负责、社会各界参与支持、通力合作、齐抓共管、综合建设的工作机制，充分发挥各职能部门作用，推动各级政府和各职能部门把社会发展同经济发展真正摆在同等重要位置，做到有计划、有投入、有落实。

（二）加大投入，进一步促进社会事业发展。社会事业是公益性事业，大多数本身不会创造经济效益，但社会效益、政治效益十分明显，需要大量投入，必须建立同经济发展水平相一致或适度超前的社会事业发展投资机制，根据经济发展速度和水平予以加大投入。

（三）加大力度，破解社会事业发展的重点和难题。要坚持分类指导原则，有重点开展工作。针对社会事业发展存在的薄弱环节和问题，各级政府、各职能部门要加大力度，实行一级抓一级，层层抓落实。特别是在社会保障、卫生保健、教育、文化体育和社会治安等方面应进行分门别类，找出难点、重点，有计划、有针对性地开展工作。在地区发展平衡方面，要兼顾农村地区特别是人口密度较高的农村地区公共基础设施的投入，以促进社会事业的平衡、稳定、全面、协调发展。

（四）加强统筹，为社会事业发展提供工作保障。通过激活目标管理机制，完善制度建设，真正把社会事业发展工作纳入各级政府和有关部门的工作范畴。深化示范工程，注重整体推进。进一步明确市、县(区)示范工作指标要求，规范示范标准，进行动态管理，推进示范地区实施社会事业发展的目标工作，发挥示范的引导作用。加强协调推进，强化督促检查。要加大统筹和督查力度，对社会事业发展中的难点，有关职能部门提出具体工作措施，进行重点推进，把工作落实到实处。
