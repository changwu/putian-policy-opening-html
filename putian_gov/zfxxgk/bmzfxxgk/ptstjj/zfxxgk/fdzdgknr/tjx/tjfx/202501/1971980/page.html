稳中有进 平稳向好——2024年莆田市经济运行情况分析

第7期
发布时间：2025-01-26 10:31
| | |
 2024年，在市委市政府的正确领导下，全市上下坚决贯彻党中央、国务院决策部署，认真落实省委省政府工作要求，深化拓展“深学争优、敢为争先、实干争效”行动和“五抓五比五看”活动，俯下身子抓产业、一心一意谋发展，做深做实“一五二三四”各项工作，加快建设绿色高质量发展先行市，全市经济稳中有进、平稳向好。

初步核算，2024年全市地区生产总值3442.74亿元，按可比价格计算，比上年增长5.5%。其中，第一产业增加值152.36亿元，比上年增长3.4%；第二产业增加值1609.92亿元，增长5.7%；第三产业增加值1680.46亿元，增长5.4%。三次产业占GDP的比重分别为4.4%、46.8%和48.8%，分别拉动GDP增长0.2个、2.8个和2.5个百分点。

一、三次产业协同发展，第三产业拉动有力

（一）农业生产总体平稳。2024年，全市农林牧渔业总产值285.11亿元，比上年增长3.5%。其中，农业产值增长4.6%，林业产值增长6.5%，牧业产值下降2.3%，渔业产值增长4.2%。主要农产品产量保持增长。2024年，全市全年粮食总产量19.26万吨，同比增长1.6%；蔬菜产量70.96万吨，增长2.1%；茶叶产量0.45万吨，增长3.1%；园林水果产量24.66万吨，增长6.4%；水产品总产量111.99万吨，增长4.9%。

（二）工业生产增势稳定。2024年，全市规模以上工业增加值比上年增长6.6%。一是超六成行业实现增长。全市规模以上工业34个行业大类中，有23个行业增加值实现增长，行业增长面为67.6%，特别是黑色金属冶炼和压延加工业，化学纤维制造业，纺织业增加值分别增长134.2%、34.4%和21.8%，共拉动规模以上工业增加值增长2.5个百分点。二是传统制鞋产业拉动有力。全市皮革、毛皮、羽毛及其制品和制鞋业用电量比上年增长13.0%，该行业增加值增长4.4%，拉动规模以上工业增加值增长1.3个百分点，增加值占规模以上工业比重30.2%，比上年提高1.1个百分点。三是重点产业链迸发新动能。重点产业链增长向好、拉动有力，新型功能材料产业增加值增长19.1%，拉动规模以上工业增加值增长3.2个百分点；电子信息产业增加值增长15.1%，拉动规模以上工业增加值增长1.2个百分点；高端装备产业增加值增长11.1%，拉动规模以上工业增加值增长1.1个百分点。

（三）服务业发展稳步向好。2024年，全市服务业增加值比上年增长5.4%。一是批发和零售业贡献突出。批发和零售业增加值增长8.0%，拉动GDP增长1.3个百分点，主要是限额以上批发业、零售业商品销售额分别增长6.4%和8.7%。二是营利性服务业快速增长。营利性服务业增加值增长6.3%，拉动GDP增长0.6个百分点，主要是规模以上其他营利性服务业营业收入由上年下降6.3%转为增长12.5%。

二、投资消费双向发力，对外贸易较快增长

（一）固定资产投资稳步增长。2024年，全市固定资产投资比上年增长2.1%，增幅比上年提高0.5个百分点。其中，项目投资增长5.5%，房地产开发投资下降10.2%。一是工业投资保持增长。工业投资增长16.4%，增幅比上年提高12.8个百分点，拉动固定资产投资增长5.5个百分点。其中，电力、热力、燃气及水的生产和供应业投资增长45.7%，制造业投资增长11.8%。二是设备购置投资高速增长。在大规模设备更新政策有力支持下，全市设备工器具购置投资增长33.5%，增幅比上年提高46.9个百分点，拉动固定资产投资增长2.2个百分点。三是民生领域投资稳定增长。批发和零售业投资增长68.7%，水利管理业投资增长56.5%，教育业投资增长47.6%，卫生和社会工作投资增长38.2%。

（二）消费品市场稳中有进。2024年，全市社会消费品零售总额完成1967.32亿元，比上年增长5.1%，增幅比上年提高1.3个百分点。一是“以旧换新”政策效益凸显。在消费品“以旧换新”政策的有力带动下，新能源汽车零售额增长46.7%，增幅比上年提高25.1个百分点；智能家用电器和音像器材类零售额增长14.0%。二是网络零售拉动作用明显。限额以上网络商品零售额200.50亿元，比上年增长17.9%，拉动全市社会消费品零售总额增长1.6个百分点。三是基本生活类商品较快增长。限额以上日用品类商品零售额增长20.6%，服装、鞋帽、针纺织品类商品零售额增长19.5%，粮油、食品类商品零售额增长0.6%，共拉动全市社会消费品零售总额增长1.4个百分点。

（三）对外贸易较快增长。2024年，全市外贸进出口总额完成692.9亿元，比上年增长7.9%，增幅比上年提高11.2个百分点。其中，出口额343.0亿元，增长4.9%，增幅比上年提高15.6个百分点；进口额350.0亿元，增长11.0%，增幅比上年提高5.1个百分点。

三、财政收支平稳运行，居民收入稳步增加

（一）财政收支运行平稳。2024年，全市实现一般公共预算总收入238.63亿元，比上年下降5.4%。其中地方一般公共预算收入157.60亿元，下降3.2%；一般公共预算支出307.50亿元，增长15.5%，增幅比上年提高18.5个百分点。

（二）居民收入保持增长。2024年，全市居民人均可支配收入41033元，比上年增长5.6%，增幅比上年提高0.6个百分点。其中城镇居民人均可支配收入50677元，增长4.8%，增幅比上年提高1.0个百分点；农村居民人均可支配收入28093元，增长6.8%，增幅比上年提高0.3个百分点。

（三）消费价格总体稳定。2024年，市区居民消费价格比上年下降0.3%。八大类消费“四增三降一持平”，其中，其他用品及服务价格上涨4.9%，教育文化娱乐价格上涨1.8%，生活用品及服务价格上涨0.4%，医疗保健价格上涨0.2%，食品烟酒价格下降0.5%，居住价格下降0.7%，交通和通信价格下降2.3%，衣着价格与上年持平。

四、要素保障支撑有力，发展后劲持续积蓄

（一）电力供应较为充足。2024年，全社会发电量292.13亿千瓦时，比上年增长8.4%，增幅比上年提高4.1个百分点；全社会用电量165.02亿千瓦时，增长6.6%，增幅比上年提高4.3个百分点。其中，工业用电84.77亿千瓦时，增长7.5%，增幅比上年提高9.8个百分点。

（二）金融市场稳健运行。2024年末，全市金融机构本外币各项存款余额3378.48亿元，比上年增长5.9%；金融机构本外币各项贷款余额3027.56亿元，增长3.1%，其中，制造业中长期贷款余额增长19.96%。

（三）货物运输流转畅通。2024年，全市公路总周转量比上年增长2.9%；水路总周转量增长12.9%，增幅分别比1-3月、1-6月、1-9月提高4.2个、3.0个和1.0个百分点。

（四）发展后劲持续增强。2024年，全市新登记市场主体18.56万户，其中新登记企业数5.62万户，比上年增长33.0%；新登记个体户12.94万户。2024年，全市新增入库纳统“四上”企业388家，其中：工业63家，建筑业22家，商贸业268家，房地产7家，服务业28家。

总的来看，2024年全市经济运行稳中有进、平稳向好，绿色高质量发展扎实推进。但同时也要看到，当前外部环境变化带来的不稳定性和不确定性因素增多，有效需求仍显不足，部分企业生产经营困难，推动经济持续向好的基础还需进一步巩固。下一步，要坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十大和二十届二中、三中全会精神，认真贯彻落实习近平总书记在福建考察时的重要讲话精神，落实中央、省委和市委经济工作会议部署，紧扣“奋勇争先、再上台阶”，扎实做好“一五二三四”工作，推动经济持续回升向好，加快建设绿色高质量发展先行市。

 

注：根据我国国民经济核算制度和第五次全国经济普查结果，2023年莆田市地区生产总值修订为3283.34亿元。
