2016年莆田市妇女发展纲要监测报告

第五十三期
发布时间：2017-08-04 11:28
| | |

妇女的发展水平是社会发展的重要标志，是衡量社会进步程度的尺度，也是构建和谐社会的重要环节。2016年《莆田市妇女发展纲要（2011-2020年）》（以下简称《妇女纲要》）在各级党委政府积极推动下,实施力度不断加大，妇女在劳动、参政、教育、健康水平等方面的权益得到充分保障，妇女生存、保护、发展的环境和条件得到明显改善。

监测结果显示：截止2016年底，涉及《妇女纲要》52项主要监测目标，已达标的有25项，达标率48%，预期可达标10项，改善率达67.3%。

第一部分    妇女发展外部环境

2016年，全市完成地区生产总值1823.43亿元，2010-2016年年均增长14.3%；全市财政总收入180.09亿元，2010-2016年年均增长14.9%。其中地方财政收入115.73亿元，2010-2016年年均增长15.9%；2016年全市城镇居民可支配收入达到31818元，农村居民人均可支配收入15131元；财政性教育经费支出达54.5亿元；医疗卫生与计划生育支出达23.75亿元。年末全市常住人口为289万人，妇女人口达到144.6万人，占全市人口的比重为50.0%，男女性别比为112.4，比2010年的130.6略有下降。经济持续发展，人民生活水平不断提高，政府投入持续加大，为我市妇女事业的发展奠定了良好的基础，提供了有力的保证。

第二部分    纲要实施进展情况

一、妇女与健康

（一）组织实施免费优生优育惠民服务项目。加强婚检、孕前检查和生育前咨询服务，通过实施免费孕前优生检查、免费婚前医学检查一站式服务，提高新婚夫妇、计划怀孕夫妇出生缺陷干预知识的知晓率，降低严重出生缺陷儿发生率。2016年，全市免费孕前优生检查43750人，覆盖率115.44%；全市免费婚前医学检查50885人，婚检率83.11%;检出疾病总数为4121人，疾病检出率8.10%；为20673对夫妇免费进行地中海贫血筛查，为20021名妇女免费进行Ⅱ型单纯疱疹病毒IgM抗体和IgG抗体测定，完成率为100.11%。

（二）组织实施重大公共卫生妇幼服务项目。切实加强组织管理，关注项目实施质量，对项目实施要求“确保按时完成，杜绝弄虚作假”，确保各项目实施有部署、有人管、有检查、有效果。2016年，对33530名农村孕产妇住院分娩进行补助，完成率为111.77%；对28100名育龄妇女免费发放增补叶酸预防神经管缺陷，完成率114.23%；分别为1.05万人和3500人进行宫颈癌和乳腺癌检查，完成率100%；对20491名农村孕妇和城市低保孕妇进行免费血清学筛查，完成率为160.09%；对15347名农村孕妇和城市低保孕妇进行免费超声筛查，完成率119.90%；对17585名城乡已婚低保妇女进行常见妇女病免费检查，完成率99.91%。

（三）切实做好妇女儿童基本医疗卫生服务。坚持以保健为中心，以降低孕产妇、婴儿死亡率和提高出生人口素质为重点，加强两个系统保健工作的管理。2016年孕产妇系统管理率90.58%，高危筛查率为35.61%，高危孕产妇管理率达100%，达到目标要求。孕产妇系统保健管理覆盖率98.87%，住院分娩率100%，孕产妇死亡率为4.41/十万。

二、妇女与教育

（一）女性享有平等教育权利。2016年全市在园儿童中女童比例为46.59%，比2010年增长1.4个百分点。2016年，全市普通初中、小学在校学生数中女生所占比例为45.85%；普通高中在校学生中女生所占比例为48.52%，比2010年增长2.28个百分点。初中阶段毛入学率98.09%，其中男生95.89%、女生100.90%。一是做好“控辍保学”工作。2016年，我市小学适龄女童入学率均在100%，小学女童年辍学率为-0.4%，初中女童年辍学率为-0.3%，均控制在省定标准内（省定标准：小学为1%，初中为3%），全面普及了九年义务教育，最大限度地防止女童失学现象的发生。二是实行中考中招照顾政策。给予双农双女及双农独女户考生，在语数英3科总分上分别加3分和6分参加中招录取。据不完全统计，2016年共有277位双农独女考生，1424位双农双女考生享受到照顾政策。性别平等原则和理念在教育教学过程中得到充分体现，女性享有平等接受教育的权利。

（二）女性接受高等教育比例增大。市内两所高校、中职学校依法维护男女平等受教育权，各学科专业都不得规定男女生录取比例。2016学年全市高校在校生21005人，如莆田学院2016年在校生16079人，女生比例为59%，职业学校在校生中女性所占比例为45.46%，妇女平等接受各阶段教育的权利都得到了切实保障。

（三）妇女的终身教育水平着力提高。加大职业教育宏观调控力度，引导初中毕业生合理分流，统筹区域内职业教育与普通高中教育的协调发展。创新人才培养培训模式，坚持以服务为宗旨、就业为导向，大力推行校企合作、工学结合。利用国家、省、市相关培训项目，开展了农村进城务工人员、实用人才和未升入普通高中的毕业生的职业教育与培训，促进了社会就业。加强农村地区“三教统筹”（即基础教育、职业教育、成人教育统筹），积极开展农村劳动力转移培训。多措并举，妇女接受终身教育的环境已形成。

三、妇女与经济

（一）城镇单位女性就业人数增加。2016年，全市就业人员共计248.34万人，其中女性就业人员为108.32万人，比2010年增加18.23万人，占全市就业人口的43.6%。城镇单位就业人员51.72万人，其中女性20.70万人 ，比2010年增加5.64万人，女性所占比例为40.0%，2010-2016年城镇单位女性就业人员逐步提高，提前完成目标。

（二）女性专业技术人员增长。2016年，全市国有事企业管理人才和专业技术人才总数53340人，其中女性25739人，占48.25%，持续保持在《妇女刚要》要求的45%以上水平，各类高级专业技术人才有5081人，其中女性1805人，占35.52%，已提前达到妇女发展纲要终期目标。

（三）努力提高妇女就业率。一是充分利用人才中介的平台优势，发挥妇女细、巧、柔等方面的特色，努力向第三产业，特别是社区服务业推荐人才。同时，结合中老年妇女知识结构较低的现状，发展适合女性就业的劳动密集型产业，扩大妇女的就业容量。二是认真组织女职工就业培训工作。有关部门联合下发文件，从促进就业专项资金中单列2000万元专项用于全市实行计划生育家庭户小额担保贴息贷款创业培训。市总女职委发挥工会“大学校”作用，积极协助党和政府做好下岗女职工和女农民工就业培训工作。莆田市3所职工职业学校得到省总工会的授牌命名。三是发放小额贷款采取贷款额度男性5万元，女性8万元，女大学生10万元的倾斜政策。四是对失业妇女实施重点援助。今年1—7月，全市就有1722名妇女通过失业登记领取了失业金，占失业登记总人数的69.74%，帮助保生活、续保险，送岗位、送培训促转岗提高就业竞争力，解决再就业问题。

四、妇女参与决策和管理

（一）妇女参政议政、参与社会事务管理进一步得到体现。妇女参政议政日趋广泛，2016年底，市人大代表人数340人，其中女性83人，占全市人大代表总数的24.4%，比2010年的19.8%提高了4.6个百分点；市政协委员人数315人，其中女性89人，占全市政协委员总数的28.25%，比2010年的18.3%提高9.95个百分点。市人大常委37名中女性7名，市政协常委71名中女性22名，市人大常委、政协常委中女性比例分别为18.9%和31%，比例不断加大。积极推进女性进村“两委”工作。2016年，全市村级组织换届实现了保持100%的村委会班子中都有女性成员和100%村妇代会主任进村“两委”班子，女村委会主任比例为4.64%，位居全省第一，村“两委”班子中女性正职和成员比例均比上届提高2.3个百分点和2.2个百分点，新一届村（居）委会妇女干部年龄结构、政治面貌、文化程度等各方面明显优化。

（二）女干部队伍建设加强，各级党政领导班子和部门女领导干部比例提高。女干部、女党员队伍逐步壮大。截止到2016年底，全市公务员总数11148人，其中女性公务员2685人，占公务员总数的24.1%，比2010年增长6.1个百分点。2016年，市级四套班子中全部配备女干部，市级领导班子配女干部的班子比例为100%；县级领导班子配有女干部的班子比例为100%；市政府工作部门配有女干部的班子比例为42.42%。

（三）发挥女性在企业决策和管理中的作用。大力提高女职工的地位。目前全市基层工会共有女职工委员会2023个，均配备女职工委员会主任；其中专职主任185人，都享受同级工会副主席待遇，兼职主任1838人，享受同级工会副主席待遇1820人。认真贯彻落实《企业民主管理规定》（总工发[2012]12号），加大对工会主席、工会副主席女性人才的培养，以便她们能作为职工董事、职工监事候选人选。采取各项措施，加大工会女职工组织组建、规范女工委主任作为工会副主席或享受工会副主席待遇、要求企业工资集体协商中必须有女职工代表等。

五、妇女与社会保障

（一）妇女参保水平保持稳定。全市参加城乡居民社会养老保险的人数为151.41万人，其中女性参保人数为73.89万人，占48.8%；参加城镇职工基本养老保险人数为31.8万人，其中女性15.3万人，占48.1%；参加城镇职工基本医疗保险人数为33.19万人，其中女性15.29万人，占46.07%；参加城镇居民基本医疗保险的人数为22.56万人，其中女性10.54万人，占46.72%；参加生育保险人数为32.16万人，其中女性15.29万人，占47.54%；参加工伤保险的人数为42.92万人，其中女职工14.43万人，占33.62%。

（二）女性社会救助体系进一步健全。一是持续提高城乡低保保障标准。继续实行城乡一体的低保保障政策，全市城乡低保保障标准统一达6480元/年（仙游县5904元/年），农村五保供养标准达8760元/年（仙游县7680元/年），城乡低保、农村五保对象中女性人数扩大到2.9万人。二是全面实施临时救助制度。2016年起全市各县（区、管委会）临时救助资金全面执行按当地户籍人口每人每年7元的标准筹集，共筹集资金2409.4万元，累计临时救助7162户1148.775万元。

六、妇女与环境

（一）男女平等社会氛围进一步增强。各级宣传部门、新闻媒体大力宣传男女平等基本国策，宣传市委、市政府关于妇女儿童工作的方针政策，提升了全社会的性别平等意识。有关部门加大扫除黄赌毒等社会丑恶现象，社会环境得到净化，开展基于社区的婚姻家庭教育和咨询，建立平等、文明、和谐、稳定的家庭关系。

（二）妇女生存发展环境不断优化。通过加大生态建设，控制和治理工业、生活污染，治理大气、水体、废物和噪音等环境污染，减少环境污染对妇女的伤害；2016年莆田市城市建成区绿化覆盖率为43.11%，人均公园绿地面积达到12.69m2，全市已建污水处理厂9座，处理污水能力33.6万吨/日，城市污水处理率88%，污水处理厂集中处理率88%。切实加强木兰溪及萩芦溪流域生态保护和水土流失治理，有效防控水质污染，确保水质安全，形成流域生态环境良性循环。全市农村集中供水受益率96%，自来水普及率94%，供水保证率90%，供水水质达标率67%，较2015年提升5个百分点；农村无害化卫生厕所普及率97.48%，比2010年提高7.68个百分点。

七、妇女与法律

（一）严厉打击侵害妇女儿童的违法犯罪活动。2016年，市公安机关破获强奸案件47起，破获拐卖妇女案件2起，解救被拐妇女2名，破获组织、强迫、引诱、容留、介绍妇女卖淫案件数77起，移送起诉涉拐犯罪嫌疑人10名，侵害妇女儿童的违法犯罪活动得到有效遏制。为预防和制止针对妇女的家庭暴力，市公安局将家暴处置工作纳入执法质量考评，牵头开展反家暴专项行动，在全市68个基层派出所设立反家暴报警投诉维权站，及时受理家庭暴力投诉案件，畅通家庭暴力报警投诉渠道。

（二）妇女法律保护意识进一步增强。宣传妇女权益保障法，大力倡导尊重妇女、男女平等方面的法律法规，为全社会依法维护妇女合法权益的意识起到了积极的推动作用。结合开展“法治莆田百场讲堂”巡回活动，“3.8”妇女维权月，集中开展婚姻家庭维权、反家暴知识等主题宣传活动，共接受法律咨询人数2000余人（次），发放宣传材料5000余份。开展“法律服务进乡村”法治宣传、法律服务巡回活动，组织律师、公证员、法律服务工作者等力量深入农村基层，在全市各乡镇巡回进行现场宣传咨询，把法律知识和法律服务直接送到广大农村妇女群众中。

（三）妇女获得较好的法律援助。2016年，全市各法律援助中心共为妇女提供法律援助427件。一是建立健全法律援助工作网络。目前，已完成了覆盖全市的四级法律援助工作网络，并在各级妇联设立法律援助站6个，方便基层妇女就近申诉法律援助，及时化解矛盾纠纷。二是开通法律援助绿色通道。实现五个“100%”免于经济困难审查，进一步降程序，满足特殊群体的法律援助需求。三是把维护妇女合法权益纳入大调解机制。全市基本建成了由信息员、村（居）调委会、镇（街道）调处中心、县（区）调处中心为主体的四级网络，及时掌握和了解家庭、妇女儿童维权方面的矛盾纠纷。

第三部分    实现目标的主要困难和问题

一、妇女就业和再就业形势依然严峻。2016年妇女就业人员占全部就业人员的比例为43.6%，虽然与《妇女纲要》45%目标差距不大，但2010年-2016年该指标逐年下降。2016年全市参加城镇登记失业人员总数7932人，比2015年的6890人增长了15.1%，其中女性3645人，比2015年的3227人增长了13.0%，女性占比46%，城镇登记失业率为2.22%。

二、培养选拔女干部工作发展不平衡。一是女领导干部中副职多、正职少；党群口多，经济部门少。在党政班子和党政工作部门中，大部分的女干部都是从事党务、精神文明建设工作，真正从事经济工作的较少；二是女性进村两委的比例还比较低， 2016年村委会主任中女性比例仅为4.64%，与2020年达到10%以上的目标差距较大，居委会成员中女性比例为30.18%,与2020年达到50%以上的目标有点差距。主要原因：传统观念制约女性从政。莆田历史上传统的“男尊女卑”、男强女弱思想根深蒂固，妇女参政的意义还没完全被全社会真正认识，女干部要面临工作和家庭的双重压力，进而造成男女从政的社会环境不平等。

三、女性社会保障力度仍需加大。一是部分用人单位不重视缴纳社会保险，尤其是为女职工缴纳生育保险的积极性不高，影响女职工享受相关待遇。2016年城镇女职工生育保险参保率为47.54%，距离2020年实现参保率达到95%目标差距较大；二是农村妇女缺乏社会保险参保意识，新型农村社会养老保险女性参保率有所下降，难以实现《妇女纲要》中提出的“大幅提高参保率”的目标；三是城镇基本医疗保险中女性参保人数比2015年有所减少，比2010年少约6.6万人。

第四部分  对策建议

一、创造条件助推女性就业创业。一是进一步消除就业中性别歧视，尽量消除就业市场男女性别同工不同酬，女性普遍职级较低的现象；二是政府有关部门用活用好支持女性就业创业各项政策和资金，不断拓宽就业渠道，创造就业机会，发展第三产业，为广大妇女就业提供便利条件。三是加强妇女的职业培训，提高妇女的自身素质，增强妇女社会竞争力。

二、进一步完善女干部培养选拔机制。着眼提升能力，加强教育培养，将女干部纳入全市干部培训总体规划。依托市委党校主阵地，有针对性地开展授课教育。根据女干部特点和需要，按干部管理权限，继续采取下派、轮岗、压担子、定向培养等形式，有计划地安排优秀女干部到重要项目建设、城市建设管理、新农村建设等基层一线培养锻炼。坚持备用结合的原则，通过滚动管理，建立健全一支数量较充足、素质较优良的女性后备干部队伍，选好配强女干部。

三、努力提高女性社保参保率。提高社保经办机构管理服务水平，完善管理措施，提高管理服务能力。以非公经济组织从业人员、城镇个体工商户和灵活就业人员为重点，依法扩大妇女基本养老保险覆盖面。充分发挥失业保险功能，大力促进女失业人员再就业，努力实现失业保险与再就业良性互动。积极推进工伤、生育保险工作，全面落实工伤、生育保险设区市统筹，不断扩大保险覆盖面。
