1-4月份莆田市经济运行情况分析

第22期
发布时间：2024-05-23 09:38
| | |

1-4月份，在市委市政府的正确领导下，全市上下坚持稳中求进工作总基调，完整、准确、全面贯彻新发展理念，加快构建新发展格局，深化拓展 “深学争优、敢为争先、实干争效”行动，围绕市委“一五二三四”部署，俯下身子抓产业、一心一意谋发展，加快建设绿色高质量发展先行市，全市经济发展态势总体向好。

（一）先行指标态势良好。1-4月份，全市工业用电量（扣除抽蓄）同比增长15.6%，增幅比全省平均水平高3.5个百分点，居全省第2位，其中化纤用电增长44.9%、制鞋用电增长11.7%；公路运输总周转量增长4.4%，水路运输总周转量增长8.3%。4月末金融机构本外币各项存款余额3282.49亿元，增长5.6%，增幅比全省平均水平高0.4个发百分点，本外币各项贷款余额3005.64亿元，增长4.5%。

（二）工业生产较快增长。1-4月份，全市规模以上工业增加值同比增长8.4%,增幅比全省平均水平高0.7个百分点。一是超七成行业正增长。全市34个行业大类中有25个行业增加值实现增长，特别是规模以上黑色金属冶炼和压延加工业，化学纤维制造业，化学原料和化学制品制造业增加值分别增长206.4%、51.3%和39.1%，共拉动规模以上工业增长2.9个百分点。二是民营企业较快增长。规模以上民营企业增加值增长8.8%，增幅比规模以上工业增加值高0.4个百分点，拉动规模以上工业增加值增长6.3个百分点。三是生产效益较好提升。3月末，规模以上工业企业营业收入增长9.8%，增幅比全省平均水平高3.8个百分点；营业利润增长33.7%。

（三）投资规模持续扩大。1-4月份，全市固定资产投资同比增长0.6%。一是工业投资贡献突出。我市出台《关于促进2024年一季度工业稳增长若干措施》，进一步扩大工业投资力度，对春节不停工的重点项目，予以适当慰问奖励。工业投资增长38.7%，拉动固定资产投资增长10.1个百分点。二是高技术产业投资快速增长。高技术产业投资增长32.3%，拉动固定资产投资增长2.7个百分点。其中高技术制造业投资增长26.9%，高技术服务业投资增长179.1%。

（四）消费市场持续升温。1-4月份，全市社会消费品零售总额完成672.06亿元，增长6.4%，增幅比1-3月份提高0.3个百分点，居全省第3位。一是网络零售增势喜人。限额以上网上零售额增长20.8%，拉动社会消费品零售总额增长1.8个百分点。二是日常消费类商品增长较快。限额以上新能源汽车、日用品类商品零售额分别增长49.2%和19.3%，共拉动社会消费品零售总额增长0.5个百分点。

（五）地方财政收入保持增长。1-4月份，全市一般公共预算总收入104.2亿元，同比下降2.3%。其中，地方一般公共预算收入70.29亿元，增长1.0%。一般公共预算支出78.56亿元，下降10.6%。

（六）外贸外资回稳向好。1-4月份，全市外贸出口总额104.2亿元，增长7.4%。实际利用外资增长12.5%。主要是鞋靴出口稳步回升，1-4月份出口额达41.5亿元，增长4.5%。

（七）消费价格总体平稳。1-4月份，市区居民消费价格同比下降0.5%。八大类消费“四增四降”，其中，其他用品及服务价格上涨4.7%，教育文化娱乐价格上涨2.2%，生活用品及服务价格上涨1.1%，医疗保健价格上涨0.1%，衣着价格下降0.4%，居住价格下降0.5%，交通和通信价格下降1.4%，食品烟酒价格下降1.8%。

总的来看，1-4月份，随着各项宏观政策发力显效，全市经济运行延续回升向好态势。但也要看到，外部环境复杂性、严峻性、不确定性上升，房地产市场低迷影响尚存，经济持续回升向好基础仍需巩固。下阶段，要坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实全国“两会”和中央、省、市经济工作会议精神，坚持稳中求进、以进促稳、先立后破，以木兰溪综合治理为总抓手，俯下身子抓产业、一心一意谋发展，加快建设绿色高质量发展先行市，不断巩固和增强经济回升向好态势，推动经济实现质的有效提升和量的合理增长。
