农村经济协调发展 农民生活迈向小康——改革开放40年莆田市农村经济发展成就分析

第五十八期
发布时间：2018-10-09 10:34
| | |

 

1978年，党的十一届三中全会作出了把全党工作重点转移到社会主义现代化建设上来的战略决策，开启了我国改革开放历史新时期，改革的春风吹遍了兴化农村，勤劳、睿智的兴化儿女抢抓机遇，争先发展，创业致富，我市农村经济呈现出一派生机勃勃、欣欣向荣的景象。40年来，我市农村经济社会发生了翻天覆地的变化，取得了令人瞩目的成就: 农村生产力高速发展，农业总产值和主要农副产品产量高速增长; 农业结构、农村产业结构不断得到调整和优化，由此带来了整个社会产业结构的调整和优化; 农民收入迅速增长，生活水平不断提高。

一、农村改革不断深化，推动农村经济社会协调发展

（一）农村改革不断深化。

40年来，自1982年家庭联产承包制改革后，国家针对农村经济社会出现的新情况新问题进行了一系列改革，先后进行了乡镇企业、农业劳动力转移、农村产业结构升级、农村组织制度创新、农村反贫困、农村可持续发展、农业税费改革、新农村建设、城乡发展一体化、乡村振兴战略等农村改革，农村改革不断向纵深推进。

1、实行联产承包责任制，促进农村经济快速发展。1982年，家庭联产承包责任制在我市农村全面展开，开启了我市农村经济体制改革第一步，突破了"一大二公"、"大锅饭"的旧体制，个人付出与收入挂勾，使农民生产的积极性大增，解放了农村生产力，为我市农村经济发展注入了活力，促进了经济的快速发展。2002年，全市农村经济总收入为231.45亿元，是1983年的39.0倍，年均增长21.3%；2002年，全市农村居民人均可支配收入为3558元，是1983年的14.1倍，年均增长15.0%。

2、推行农村税费改革和农村综合改革，促进农村经济社会全面发展。2003年，我市认真贯彻党的十六大以及中央经济工作会议和中央农村工作会议精神，按照《国务院关于全面推进农村税费改革试点工作的意见》（国发〔2003〕12号）文件要求，在全市全面推行农村税费改革，扭转了长期以来我市农民负担过重的局面，促进了农业增产、农民增收、农村繁荣。我市按照巩固农村税费改革成果和完善社会主义市场经济体制要求，在全市推进农村综合改革，扎实推进乡镇机构、农村义务教育和县乡财政管理体制改革，建立精干高效的农村管理体制和运营机制、覆盖城乡的公共财政制度、政府保障的农村义务教育体制，促进农民减负增收和农村公益事业发展，促进我市农村经济社会全面发展。2012年，全市农村经济总收入为455.45亿元，是农村税费改革前2002年的2.0倍，年均增长7.0%；全市农村居民人均可支配收入为10299元，是2002年的2.9倍，年均增长11.2%。

3、全面深化农村改革，促进农村经济社会协调发展。党的十八届三中全会作出的《中共中央关于全面深化改革若干重大问题的决定》，对深化农村改革作出了全面部署：围绕建设现代农业，加快转变农业发展方式，围绕促进农民增收，加大惠农改革力度；围绕城乡发展一体化，深入推进新农村建设，围绕增添农村发展动力，全面深化农村改革；围绕做好“三农”工作，加强农村法治建设。党的十八大以来，市委、市政府坚持以习近平新时代中国特色社会主义思想为指引，认真贯彻落实中央、省委一系列决策部署，扎实推进农业供给侧结构性改革，完善农业农村发展体制机制，落实精准扶贫精准脱贫政策，促进农村经济社会协调发展。2017年，全市农村经济总收入为665.92亿元，是深化改革前2012年的1.5倍，年均增长7.9%。各项强农惠农富农政策有效落实，农村基础设施和公共服务不断改善；农业农村体制机制取得实质成效，农村改革“四梁八柱”框架基本建立；脱贫攻坚取得历史性成绩，现行标准下贫困人口全部实现脱贫，2017年完成脱贫11644人，累计共脱贫3万多人；2017年全市农村居民人均可支配收入为16492元，是2012年的1.6倍，年均增长9.9%。

（二）农村经济社会协调发展。

40年来，莆田市委市政府贯彻落实中央、省委一系列决策部署，不断完善以家庭承包经营为基础、统分结合的双层经济体制，大力发展农村经济，加大农村招商引资力度，积极发展乡镇企业和民营经济，加快城乡统筹发展，扎实推进新农村建设，落实精准扶贫和精准脱贫政策,促进农村经济社会协调发展，我市农村呈现出政通人和、百业兴旺的大好局面。

1、农村经济快速发展。随着农村改革的不断深化，农村多种经营专业户、乡镇企业、农民专业合作社大量涌现，推动农村经济快速增长。2017年，全市农村经济总收入达665.92亿元，是1983年的112.1倍，年均增长14.9%，比全市同期国内生产总值年均增长13.9%快1.0个百分点。其中乡（镇）办企业经营收入35.31亿元，占农村经济总收入的比重为5.3%；村组集体经营收入5.13亿元，占农村经济总收入的比重为0.8%；农民家庭经营收入513.64亿元，占农村经济总收入的比重为77.1%；农民专业合作社经营收入5.13亿元，占农村经济总收入的比重为1.5%；其他经营收入101.78亿元，占农村经济总收入的比重为15.3%。

2、实现三次产业并重发展新格局。改革开放前，莆田农村经济是纯农业经济，改革开放后随着我市农村经济的快速发展，农村的生产经营活动已经逐步接近市场化，农村经济原有的自给经营也逐渐转变为商业经济，农村产品也逐渐走向多元化，农村产业也向二三产延伸。2017年全市农村非农劳动力达85.76万人，占农村总劳动力的比重由1983年的29.5%提高到60.6%。在2017年全市农村经济收入中，农业收入为60.78亿元，占农村经济收入比重为9.1%；林业收入为4.63亿元，占农村经济收入比重为0.7%；牧业收入为37.26亿元，占农村经济收入比重为5.6%；渔业收入为35.64亿元，占农村经济收入比重为5.4%；工业收入为283.76亿元，占农村经济收入比重为42.6%；建筑业收入为64.65亿元，占农村经济收入比重为9.7%；运输业收入为39.89亿元，占农村经济收入比重为6.0%；批发零售贸易业、餐饮业收入为70.41亿元，占农村经济收入比重为10.6%；服务业收入为34.85亿元，占农村经济收入比重为5.2%；其他行业收入为34.05亿元，占农村经济收入比重为5.1%。2017年全市农村经济收入中一、二、三产的比重为20.8：52.3：26.9，我市农村经济逐渐打破单一的第一产业旧模式，实现了农、工、建、运、商、服务业并存，一、二、三产并重发展的新格局。

3、农村基础设施日臻完善。40年来，我市不断加快农村基础设施建设，积极推进新农村建设，农村基础设施日臻完善，人居环境明显改善。第三次全国农业普查资料显示，2016年末，全市有100%的村通电，99.1%的村通公路，57.9%的村通公共交通，96.1%的村内主要道路有路灯，99.9%的村通电话，99.9%的村通宽带互联网，93.7%的村安装了有线电视，25.4%的村有电子商务配送站点，2.2%的村通天然气，93.5%的乡镇实施集中供水，95.7%的乡镇有垃圾处理站，98.6%的村实施生活垃圾集中处理，12.6%的村实施生活污水集中处理，95.5%的村完成改厕。

4、农村社会事业蓬勃发展。40年来，全市上下认真贯彻中央、省、市的一系列惠农、扶农、护农、富农政策，加大农村社会文化教育投入，加快发展农村义务教育，大规模开展农村劳动力技能培训，积极发展农村卫生事业，繁荣农村文化事业，逐步建立农村社会保障制度，倡导健康文明新风尚，推动我市农村社会事业蓬勃发展。第三次全国农业普查资料显示，2016年末，全市97.8%的乡镇有幼儿园、托儿所，93.5%的乡镇有小学，95.7%的乡镇有图书馆、文化站，13.0%的乡镇有剧场、影剧院，10.9%的乡镇有体育场馆，78.3%的乡镇有公园及休闲健身广场，97.8%的乡镇有医疗卫生机构，97.8%的乡镇有执业（助理）医师，76.1%的乡镇有社会福利收养性单位，69.6%的乡镇有本级政府创办的敬老院；全市60.8%的村有幼儿园、托儿所，61.8%的村有体育健身场所，68.5%的村有图书室（馆）、文化站，56.6%的村有农民业余文化组织， 94.6%的村有卫生室，94.6%的村有执业（助理）医师。

二、农业经济总量稳步增长，综合生产能力显著增强。

40年来，我市农业生产克服了不利条件的制约，在耕地面积和滩涂养殖面积逐步减少、生产成本不断提高的情况下，不断加大农田水利基础设施建设力度，不断改善农业生产条件，不断优化农业产业结构，大力开发推广高产、优质农作物品种和超高产配套栽培技术，促进农业经济稳步增长，农业综合生产能力显著增强。

（一）农业产业结构调整优化，经济总量稳步增长。

40年来，我市农业生产由改革开放前以种植业为主导逐渐调整为农林牧渔业全面发展，种植业由改革开放前以种粮为主逐渐调整为粮食和经济作物共同发展，农业产业结构不断优化调整，实现了农业经济总量稳步增长。2017年，全市农林牧渔业总产值达205.89亿元，是1978年的74.7倍，年均增长11.7%（按现价计算，下同）；农林牧渔业增加值达119.19亿元，是1978年的66.0倍，年均增长11.3%。农、林、牧、渔、服务业五业由1987年的44.5:2.4:25.7:14.3:13.1调整为2017年的22.7:2.1:14.7:52.7:7.7，粮食与经济作物的播种比例由1978年78.9:21.1调整为2017年的47.0:53.0。

（二）粮食推高推优，亩产大幅增加。

粮食生产在耕地面积减少、种植结构调整的情况下，实施粮食“丰产技术推广工程”，大力开发推广高产、优质、专用粮食作物，加大农业“五新”推广，增加粮食生产的科技含量，粮食亩产实现大幅增加。2017年我市早稻、中稻、晚稻、大小麦、 薯类、大豆等各种粮食亩产分别为427、451、399、203、404、173公斤/亩，分别比1978年增长25.2%、70.4%、27.7%、57.0%、44.6%、133.2%。

（三）农业生产条件明显改善，主要农产品产量持续增加。

40年来，我市不断加大农田水利设施和农业机械化建设投入，农田水利设施逐步完善，农业机械化水平明显提升，农业生产条件明显改善，农产品产量持续增加。2017年，全市农业机械总动力67.86万千瓦，是1978年的6.7倍，年均增长5.0%；农业排灌机械动力为8.36万千瓦，是1978年的5.9倍，年均增长4.7%；农业运输机械动力为18.21万千瓦，是1978年的56.9倍，年均增长10.9%；农村用电量为131602万千瓦小时，是1978年的210.2倍，年均增长14.7%。2017年，全市油料产品农产品产量3.74万吨，是1978年的3.4倍，年均增长3.2%；蔬菜产量56.77万吨，是1979年的14.6倍，年均增长7.3%；食用菌产量6.07万吨，是1993年的2.3倍，年均增长3.5%；园林水果产量22.06万吨，是1978年的21.9倍，年均增长8.2%；肉类总产量11.02万吨，是1983年的4.0倍，年均增长4.2%；水产品产量90.13万吨，是1978年的27.3倍，年均增长8.8%。

（四）农业产业化发展迅速，农业发展后劲增强。

40年来，莆田市把农业产业化作为农业工作的重中之重来抓，通过引进市外资金、内部挖潜改造，建立现代化企业制度等措施，龙头企业、农民专业合作社呈现集群式发展，企业数量、规模和效益不断提高。莆田市通过培育壮大农业龙头企业、积极扶持农民合作社，通过创新农业经营方式，加速推进农业规模化、产业化、组织化、标准化、品牌化进程，农业经营组织的整体带动效益日益突出，农业发展后劲增强。至2017年底，市级以上农业产业化龙头企业161家，全市拥有农民专业合作社1400多家，其中获批国家级农民专业合作社示范社14家、省级示范社43家、市级示范社118家。

三、农村居民收入稳步增长，生活逐步迈向小康

改革开放以来，随着农村经济的快速发展，农村居民增收的渠道逐步拓宽，农村居民收入水平和消费水平不断提高，消费结构加快转型升级，生活质量显著提高，实现了由贫困迈向小康的历史性跨越。

（一）农村居民收入稳步增长，收入来源渠道不断拓宽。

改革开放以来，农村经济的快速发展，扭转了长期以来农村居民收入增长缓慢的状况，农村居民收入快速增长。2017年，莆田市农村居民人均可支配收入为16492元，是1978年131元的125.9倍，年均增长13.2%。农村居民收入来源由单一的集体经营收入转为工资性收入、经营净收入、财产净收入和转移净收入。2017年，莆田市农村居民的工资性收入、经营净收入、财产净收入和转移净收入分别为7908元、4102元、358元和4124元，占可支配收入的比重分别为48.0%、24.9%、2.2%和25.0%。

（二）农村居民消费水平不断提高，消费结构日益优化。

40年来，随着我市农村居民收入水平的大幅提高，农村社会保障体系的不断健全，农村居民消费水平不断提高，消费结构日益优化。2017年，莆田市农民人均生活消费支出为14047元，是1978年95元的147.9倍，年均增长13.7%。其中食品烟酒、衣着、居住、生活用品及服务、交通通讯、教育文化娱乐、医疗保健、其他商品和服务占生活消费支出的比重分别从1978年的63.2：9.5：15.8：7.4：1.1：4.2：2.1：1.1调整优化为2017年的41.2：4.6：24.9：6.0：7.6：8.9：3.7：3.1，食品烟酒、衣着、生活用品及服务消费支出比重逐年下降，居住、交通通讯、教育文化娱乐、医疗保健、其他商品和服务消费支出比重逐年上升。

（三）农村居民居住环境不断改善，生活质量显著提高。

改革开放后，特别是随着社会主义新农村建设步伐的加快，我市加大了旧村改造、村庄整治建设力度，农村面貌焕然一新。排排砖瓦房、幢幢新楼群拔地而起，农民居住条件明显改善，很多农民有两三处住房，拥有商品房的农民也不在少数，新型家用耐用品不断增多，农民生活从“基本生存型”趋向“享受发展型”转变，生活质量显著提高。第三次全国农业普查资料显示，2016年，全市拥有两处以上的户比重为13.19%，比第二次全国农业普查高2.76个百分点，其中拥有商品房的户比重为9.7%。住房结构为钢筋混凝土的户比重为39.78%，比第二次全国农业普查高24.77个百分点；住房结构为砖混的户比重为40.22%，比第二次全国农业普查高3.36个百分点。使用经过净化处理的自来水的户比重为70.84%，比第二次全国农业普查高39.58个百分点；生活能源使用太阳能、电、煤气天然气液化石油气和沼气的户比重为85.8%，比第二次全国农业普查高65.28个百分点。农村居民家庭主要耐用消费品数量不断增多，特别是新型家用耐用品明显增加。第三次全国农业普查资料显示，2016年，莆田市农村居民平均每百户家庭拥有小汽车27.24辆，比第二次全国农业普查多24.92辆；摩托车、电瓶车119.08辆，比第二次全国农业普查多86.70辆；彩色电视机121.70台，比第二次全国农业普查多23.01台；电脑60.74台，比第二次全国农业普查多58.17辆；手机306.30部，比第二次全国农业普查多210.25部。随着农村居民收入的不断提高和农村社会保障的不断完善，在2006年第二次全国农业普查时我国农村家庭较少见的沐浴热水器、空调、电冰箱等新型家用耐用品逐渐进入农村家庭，数量增加明显，2016年莆田市农村居民平均每百户家庭拥有沐浴热水器102.13台，空调78.53台，电冰箱100.65台。

（四）农村居民恩格尔系数不断降低，生活逐步迈向小康。

40年来，我市农村居民恩格尔系数随着农村居民收入水平与消费水平的不断提高而逐年降低，农村居民生活由改革开放前的贫困逐步迈向小康。联合国根据恩格尔系数（即食品支出总额占个人消费支出总额的比重）的大小，对世界各国的生活水平有一个划分标准，即一个国家平均家庭恩格尔系数大于60%为贫穷;50%-60%为温饱;40%-50%小康;30%-40%属于相对富裕;20%-30%为富足;20%以下为极其富裕。1984年，全市农村居民的恩格尔系数由1983年62.9%降至55.6%，实现生活质量的第一次跨越——由贫困到温饱；2000年，全市农村居民的恩格尔系数由1999年52.4%降至46.5%，实现生活质量的第二次跨越——由温饱到小康；在2000年实现小康的基础上，农村居民恩格尔系数逐年下降，2017年全市农村居民的恩格尔系数为41.2%，靠近相对富裕。
