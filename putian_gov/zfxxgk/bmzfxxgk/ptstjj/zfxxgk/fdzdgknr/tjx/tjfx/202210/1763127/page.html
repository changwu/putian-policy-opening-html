前三季度莆田市房地产运行分析

第六十五期
发布时间：2022-10-28 08:36
| | |

前三季度，全市房地产开发投资、销售面积降幅持续收窄，但行业恢复不及预期，仍处于筑底区间。短期需关注企业融资和公积金逾期情况，建议继续优化政策措施，统筹住宅项目入市节奏。合理支持购房者刚性和改善性住房需求，促进宜居宜业。

一、房地产开发投资降幅收窄

（一）房地产开发投资降幅缩窄，但是实质性改善还需等待。

主要是受整个市场持续低迷影响，房地产用地出让连续下降。前三季度，全市房地产开发投资完成271.80亿元，同比下降15.2%，降幅比1-7月收窄1.1个百分点。其中，建安投资完成190.07亿元，同比下降5.4%，降幅比1-8月收窄2个百分点。9月当月，完成投资28.87亿元，同比增长55.2%。但是前三季度全市通过招拍挂供应经营性房地产用地13宗56.02公顷，同比下降14.8%。土地成交的下滑直接影响未来可供开工量。从工程用途看，开发投资仍以住宅为主，但144平方米以上住宅下降幅度较大。前三季度，住宅投资212.33亿元，同比下降14.1%，占开发投资的78.12%。其中，90平方米以下住宅投资增长86.7%，144平方米以上住宅同比下降36.0%。

（二）受去年基数较低影响，商品房销售降幅略有收窄

随着降低首付比例、提高公积金额度等一系列扶持政策的实施，再加上“保交楼”专项借款、纾困基金的积极推进，市场处于筑底阶段并企稳。叠加去年9月，仙游和秀屿疫情爆发，项目停工，基数较低。房地产销售面积降幅有所收窄，比全省平均水平高1.3个点，从一季度的位居第七位上升到第四位。前三季度，全市商品房销售面积354.52万平方米，同比下降9.0%，降幅较1-8月收窄5.8个百分点，较上半年收窄13.1个百分点；商品房销售额333.25亿元，同比下降11.1%，降幅较上半年收窄14个百分点。9月当月，全市商品房销售面积38.96万平方米，比8月增加5.64万平方米。

从结构看，年初以来保障性住房、商办地产销售面积增长，纯商品住宅销售面积下降。前三季度，全市保障性住房占比11.0%，带动全市商品房销售面积降幅逐步收窄，纯商品住宅销售面积下降7.7%，市场仍处于筑底阶段，观望情绪较浓厚。

（三）到位资金降幅扩大，融资难题仍存在

今年以来，商品房销售整体下行明显，企业回款能力下降，到位资金受到影响，尽管已出台政策支持房地产市场合理融资需求，但当前本年到位资金总量和增速均低于开发投资，企业资金较为紧张、融资压力较大的局面并未得到明显缓解。前三季度，全市房地产开发企业到位资金291.83亿元，同比下降24.7%。从资金来源看，企业到位资金以其他资金为主，与销售有关的个人按揭贷款、定金及预收款上升幅度大。按类别看，国内贷款下降54.4%；自筹资金下降51.3%；定金及预收款增长106.8%；个人按揭贷款增长12.2%。

二、项目减少、投资意愿下降导致房地产开发投资下行

（一）新入库项目“少弱小”，施工面积逐月下降。一是新入库项目个数减少。前三季度，全市新入库房地产项目仅19个，同比减少9个。二是新入库项目规模较小。新入库3个项目，计划总投资合计仅25.67亿元。房地产房屋施工面积逐月下降。前三季度，全市房屋施工面积2248.79万平方米，下降19.2%（1-7月下降17.5%、1-6月下降15.6%），比一季度下降了5.6个点。在库项目个数和房屋施工面积的下降，表明房地产开发投资后劲乏力。

（二）投资意愿下降，开发进度放缓。土拍市场持续低迷，企业投资意愿下降。前三季度，全市共出让13宗经营性房地产用地，其中可对外销售纯商品房用地8宗、安置型商品房用地有4宗、批发市场用地1宗，土地供应呈量价齐降。8宗纯商品房用地中有6宗溢价率未超过5%，溢价率最高的是玉湖片区（溢价率30%）。按区域分，市本级供地45.47公顷，下降6.7%；仙游县10.55公顷，下降37.9%。

（三）公积金逾期率上升。前三季度，全市新增办理公积金贷款楼盘55个，比去年同期减少20个，下降29.0%。个人贷款发放额10.59亿元，下降8.5%。市场经济疲软，导致职工收入减少，加剧了贷款偿还压力，关注类楼盘从去年的14个增加至9月末的21个，逾期率有上升现象。

三、建议

（一）继续加大“保交楼”工作推进力度。当前，全市多地已出台促进房地产市场平稳健康发展的政策文件，但政策效果尚不明显，开发投资增速持续下行。“保交楼”是有效化解房地产市场风险，提振市场信心，稳定预期的重要抓手。下一步，建议继续加大“保交楼”工作力度。一方面，聚焦在建项目，持续加强对房地产企业运营状况和项目建设情况的跟踪监测，确保在建项目顺利推进；另一方面，努力推进“烂尾楼”复工，形成实实在在的工作量，促进房地产市场稳定运行。

（二）继续加大金融信贷政策支持力度，保障房地产市场合理融资需求。从企业资金来源来看，5月以后，定金及预收款和个人按揭贷款持续增长，这主要得益于前期宽松的金融信贷政策。定金及预收款和个人按揭贷款与商品房销售市场密切相关，下一步，建议继续加大金融信贷政策支持力度，确保满足条件的企业和个人住房贷款应贷尽贷，推动商品房销售市场平稳运行。

（三）加大公积金支持住房消费力度，助力房地产业平稳健康发展。用足用活公积金政策，充分发挥住房公积金个人住房贷款在解决中低收入家庭住房困难问题方面的作用。强化公积金贷款风险防控，加强贷前审核、贷中审查、贷后管理等工作，有效管控贷款的逾期率，防范贷款风险。
