2018年莆田市农林牧渔业生产情况简析

第三期
发布时间：2019-01-18 10:22
| | |

2018年，我市坚持以习近平新时代中国特色社会主义思想为指引，认真贯彻落实中央、省委一系列决策部署，围绕实施乡村振兴战略，以“创新、协调、绿色、开放、共享”新理念引领农业新发展，以“提质增效转方式、稳粮增收可持续”为工作主线，扎实推进农业供给侧结构性改革，加快发展特色现代农业，大力提升农业质量效益，持续加强农业生态建设，促进农业绿色发展，保障我市农业农村经济保持健康可持续发展。

一、主要运行特点

（一）农林牧渔业生产保持健康持续发展，总产值稳步增长

2018年，全市农林牧渔业生产保持健康持续发展，实现农林牧渔业总产值217.10亿元，按可比价计算，比上年增长2.5%，实现增加值125.91亿元，可比增长2.6%。其中，农业产值50.95亿元，可比增长5.3%，增加值30.84亿元，可比增长5.1%；林业产值6.10亿元，可比增长14.8%，增加值3.58亿元，可比增长14.5%；牧业产值27.10亿元，可比下降6.4%，增加值14.12亿元，可比下降6.4%；渔业产值115.88亿元，可比增长3.5%，增加值67.73亿元，可比增长3.6%；农林牧渔服务业17.07亿元，可比增长5.4%，增加值9.65亿元，可比增长5.4%。

（二）政策扶持初见成效，粮食产量呈现增长态势

自2000年以来，随着我市经济的不断发展，种粮相对效益不断下降，农民种粮积极性不断减弱，我市粮食播种面积和产量呈逐年下降。2018年，我市出台了对规模种植中稻、晚稻和甘薯、马铃薯、玉米、大豆等旱地粮食作物20亩以上的合作社、农业企业和家庭农场等经营主体进行财政补贴政策，每亩补贴300元，调动了农民种粮积极性，粮食播种面积开始止跌回升，粮食产量也随之增长。2018年，全市粮食播种面积为453130亩，由上年的下降4.1%转为增长0.9%；粮食产量达182605吨，由上年的下降1.7%转为今年的增长2.3%。

（三）蔬菜生产情势良好，产量稳步增加

2018年，我市各级统筹推进“菜篮子”工程建设，积极发展现代设施蔬菜，蔬菜播种面积不断扩大，产量稳步增加。2018年,全市蔬菜播种面积为307927亩，播种面积比上年扩大25753亩,增长9.1%；产量为595476吨，比上年增加27788吨，增长4.9%。其中以便于运输储存的瓜类、根茎类、茄果类蔬菜增长较快，瓜类、根茎类、茄果类蔬菜播种面积分别增长了20.0%、14.5%、14.7%。

（四）水果生产喜忧参半，产量有增有减

2018年初我市出现低温和强冷空气，部分山区甚至出现下雪的极寒天气，枇杷、香蕉和杨梅幼果受冻减产，特别是早钟枇杷等早熟品种受冻严重，部分农户甚至颗粒无收。龙眼、柚和柿子因恰逢生产大年和适宜的生长期气候而喜获丰收。2018年,全市园林水果产量为172995吨，比上年减少47621吨，下降21.6%。其中枇杷产量为58356吨，比上年减少62827吨，下降51.8%；香蕉产量为6660吨，比上年减少464吨，下降6.5%；杨梅产量为1824吨，比上年减少356吨，下降16.3%；龙眼产量为23075吨，比上年增加3406吨，增长17.3%；柚产量为51102吨，比上年增加8766吨，增长20.7%；柿子产量为7156吨，比上年增加402吨，增长6.0%。

（五）茶叶种植面积不断扩大，产量逐年增加

近几年我市陆续扩大茶叶种植面积，且随着茶叶种植管理的跟进、种植技术的投入、茶树龄的增加、生产茶叶的茶树分枝增多，茶叶产量逐年增加。2018年末全市共有茶树种植面积18187亩，比上年末增加2022亩，增长13.0%；其中采摘面积为17107亩，比上年末增加942亩，增长6.0%。2018年，全市茶叶产量为4235吨，比上年增加191吨，增长4.7%。其中红茶产量为467吨，比上年增加74吨，增长18.8%；绿茶产量为200吨，比上年增加9吨，增长4.7%；青茶产量为3499吨，比上年增加106吨，增长3.1%。

（六）食用菌生产效益下降，生产规模不断萎缩

近几年来，由于受人工费用等生产成本提高影响，我市食用菌生产效益不断下降，食用菌产量受之影响呈逐年下降趋势。2018年，全市食用菌产量为39240吨，比上年净减21432吨，下降35.3%。其中，蘑菇产量35093吨，比上年净减19941吨，下降36.2%；姬松茸产量1871吨，比上年净减1292吨，下降40.8%；香菇产量1495吨，比上年净减344吨，下降18.7%。食用菌生产占用耕地面积6121亩，比上年减少3900亩，下降38.9%；蘑菇种植面积3785869平方米，比上年减少2903234平方米，下降43.4%；蘑菇单产为每平方米9.3公斤，增长12.7%。

（七）林木培育和种植投入加大，木材采伐量减小

2018年，全市本年新增林木育苗面积6325亩，比上年增加625亩，增长11.0%；全市完成造林面积为84573亩，比上年增加5329亩，增长6.7%；林木抚育和管理投入加大，全市抚育和管理林木457953亩，比上年增加54431亩，增长13.5%；全市共采伐木材146401立方米，比上年减少5491立方米，下降3.6%。其中原木104947立方米，比上年减少43131立方米，下降29.1%。

（八）生猪出栏大量减少，畜牧业肉类总产量下降4.8%

2018年第四季度，我市发生非洲猪瘟疫情，生猪存出栏出现大量减少，猪肉产量也随之大幅下降，导致畜牧业肉类总产量下降。2018年，全市生猪出栏834468头，下降12.0%；生猪肉产量为66764吨，下降13.0%。家禽出栏27024670只，增长14.2%；家禽肉产量为37237吨，增长14.2%。全市肉类总产量105000吨，下降 4.8%；禽蛋产量26151吨，下降4.4%；奶类产量3924万吨，增长5.6%。

（九）受泉港碳九泄漏影响水产品产量减少，增幅有所回落

2018年11月，泉港发生碳九泄漏事件，受之影响我市第四季度水产品产量明显减少，导致全市水产品全年增幅有所回落。2018年，全市水产品总产量938683吨，产量比上年净增37420吨，增长4.2%，增幅比第3季度回落1.5个百分点。其中海水产品产量911406吨，产量比上年净增35908吨，增长4.1%，增幅比第3季度回落1.6个百分点。从2018年第四季度当季完成情况来看：全市水产品产量第四季度当季完成205184吨，下降1.0%。其中海水产品产量200553吨，下降1.3%。

二、存在的主要问题

（一）生产成本及农产品价格对农业生产影响较大。近几年来受我市人工费用等生产成本不断提高影响，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其在我市的生产规模只减不增，我市食用菌生产规模逐年缩小。

（二）农作物种植面积保持有难度。一是种粮比较效益偏低，农民种粮积极性不高；二是由于农民外出务工相比在家务农收入较高，我市部分山区青壮年人口常年外出打工，家里剩下老人与小孩，耕地因缺少劳动力耕作导致抛荒；三是受征地拆迁影响，耕地面积逐渐流失，特别是南北洋适合种植水稻的大片良田流失严重。

（三）畜禽可养范围较小，仅占全市总村居数的15%。根据市政府印发的《莆田市畜禽禁养区及禁建区划定方案》、《莆田市畜牧业集约化发展规划》（莆政综〔2010〕48号）和《莆田市人民政府关于公布畜禽养殖禁养区、禁建区及可养区的通知》（莆政综〔2011〕125号），全市行政区划内有近三分之二以上区域为禁养区，其中北岸和湄洲岛全境范围禁养；我市行政区划内可养区只有146村，占全市村居委会总数的比重为15.0%，其中仙游县52个村、城厢区15个村和秀屿区79个村。

（四）生猪养殖规模大幅下降，2019年畜牧业生产形势将更加严峻。按照有关规定，在非洲猪瘟疫区（以疫点为中心的3公里内）都不能再养殖生猪。据有关统计，在我市疫区内共有11家规模以上生猪养殖场（生猪年饲养量在100头以上），已全部进行无害化处理。2018年初，全市共有63家大型生猪养殖场（生猪年饲养量在5000头以上），因环保整治不过关和非洲猪瘟疫情影响全市共停产17家，其他养殖户因担心受疫情影响存栏积极性不高，这将极大影响2019年我市生猪的养殖规模。2018年底，全市生猪存栏为385771头，比上年同期减少118463头，下降23.5%。

（五）海洋经济短板仍未得到改善，渔业发展空间受限。随着城市建设和工业化的发展，适宜养殖发展的水域和滩涂等养殖区不断受到蚕食，水产养殖空间越来越小；湾外养殖扩展技术尚在实验阶段，技术难度大且风险高，尚需资金扶持，渔民参与积极性不高；海产品加工业发展滞后，不能有效促进渔业发展。

三、下一步建议

（一）以市场为导向，强化政策引导，提高农民农业生产积极性。要全面了解我市农业生产基本情况，摸清全市农业产业基本构架，分析预测农产品市场需求，有针对性地出台激励政策，提高农民农业生产积极性，尽可能避免耕地抛荒。

（二）加快农村耕地流转，扩大农作物种植规模。耕地流转是农业生产规模化的基础和前提。政府要出台相关政策引导、鼓励农村耕地流转，通过耕地流转把抛荒的耕地集中到种植大户、种植农民专业合作社和种植业龙头企业，发展适度规模的种植业生产，提高全市耕地利用率，从而扩大全市农作物种植规模。

（三）抓龙头企业农业生产。要着重抓好利农、鸿达、亿生、天怡、温氏等龙头企业的农业生产，支持和督促龙头企业扩大农业生产规模，带动全市农业经济稳定增长。

（四）大力发展畜牧业规模化养殖和循环养殖。要加大招商引资力度，引进国内外先进养殖模式的畜牧业龙头企业，带动我市畜牧业向规模化养殖和循环养殖发展。
