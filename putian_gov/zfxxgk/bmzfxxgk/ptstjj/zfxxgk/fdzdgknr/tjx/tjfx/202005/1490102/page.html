莆田市1-4月房地产开发运行情况

第二十五期
发布时间：2020-05-14 16:46
| | |

受新冠肺炎疫情影响，莆田市房地产开发投资和商品房销售面积均出现不同程度下滑，但在一系列促进企业复工复产政策措施的带动下，房地产开发投资和商品房销售面积的下降幅度均较1-3月大幅收窄。

一、房地产开发运行主要特点

（一）开发投资降幅收窄

随着疫情得到控制，在一系列促进企业复工复产政策的带动下，降幅有所收窄。1-4月，全市房地产开发投资完成114.75亿元，同比下降18.3%，降幅较1-3月收窄9.7个百分点，比全省平均降幅（-7.5%）高10.8个百分点，居全省第7位。

从构成看，建安工程投资降幅扩大，土地购置费大幅增长。随着项目复工复产的推动，中心城区的建发·玉湖一号、融创·兰溪一号等新项目开工建设，由于去年同期建安工作量大，所以建安投资下降明显。1-4月全市房地产开发建安工程投资完成81.70亿元，同比下降28.1%。土地购置费30.43亿元，增长33.6%，增幅较1-3月提升21个百分点，主要得益于霞梧磐龙一期、仙港豪园、融创兰溪雅苑等土地购置费入市。

从工程用途看，住宅投资小幅下降，办公楼投资和商业营业用房腰斩。1-4月住宅投资完成83.71亿元，下降9.5%，较1-3月收窄11.1个百分点。办公楼投资4.2亿元，同比下降53.6%；商业营业用房4.18亿元，下降68.7%；其他投资22.66亿元，下降11.5%。

（二）新开工面积降幅收窄

进入3月份以来，项目逐步恢复施工建设，新开工面积降幅收窄，1-4月全市房屋新开工面积88.75万平方米，下降34.2%。其中，3月当月新开工面积34.41万平方米。同时，全市房屋施工面积2185.54万平方米，下降2.6%；房屋竣工面积25.44万平方米，下降42.2%。

（三）区域投资分化发展

1-4月投资增长主要依靠荔城区和仙游县，两个县区共占全市房地产开发投资总量的53.5%，分别完成30.96亿元和30.39亿元。其中，荔城区受霞梧磐龙一期、莆田香盛公馆等大项目拉动，完成投资17.52亿元，拉动全市投资增长6.6个百分点。仙游县仙港豪园、碧桂园天城、骏耀财富广场等4个大项目拉动下，完成投资16.49亿元，，拉动全市投资增长6.3个百分点。

（四）销售面积降幅逐步收窄

随着我市线下售楼部开始逐步对外开放，加上线上认筹销售一定的拉动作用，商品房销售面积降幅逐步收窄。1-4月，全市商品房销售面积113.28万平方米，降幅由1-3月的30.1%收窄至9.7%。较全省平均降幅（21.5%）收窄11.8个百分点，居全省第四位。其中住宅销售91.75万平方米，降幅由1-3月的36.6%收窄至11.3%。

从销售区域看，全市5个县（市、区）、1个管委会的商品房销售面积表现为“三正三负”。城厢区由于部分政府回购商品房实现网签、秀屿区国湄领秀工程（地块一二四）项目和仙游县建发玺院的热销，所以三个县区小幅增长，其他县区都有不同程度的下降。其中，城厢区26.35万平方米，增长8.0%；仙游县25.03万平方米，增长1.9%；秀屿区22.13万平方米，增长64.3%；涵江区17.42万平方米，下降51.1%；荔城区19.40万平方米，下降15.2%；北岸2.94万平方米，下降35.4%。

（五）到位资金大幅下降

信誉好、实力强的大企业资金自筹能力强，莆田市房地产较多都是中小型房地产公司，银行贷款额度仍比较不足，到位资金下降明显。1-4月，全市房地产开发企业实际到位资金113.94亿元，下降17.7%。其中，国内贷款17.72亿元，下降42.7%；自筹资金52.35亿元，下降21.2%；个人按揭贷款15.36亿元，增长133.6%。定金及预收款26.84亿元，增长58.0%。

二、后续需关注的问题

（一）商品房待售面积激增，1-3年待售面积库存压力大

商品房库存压力大，截至4月末，全市商品房待售面积172.16万平方米，增长7.3%，其中住宅待售面积87.30万平方米，增长6.4%；非住宅类待售面积84.9万平方米，占了全市待售面积的19.3%，同比增长66.1%。其中待售1-3年（含1年）面积 67.63万平方米，增长57.9%，待售3年以上（含3）面积78.05万平方米，下降2.2%。

（二）房企资金压力大

企业资金压力依旧较大。自去年年底以来，企业普遍面临资金回笼速度下降，销售收入明显下跌，资金压力骤增的情况。但是由于疫情期间，各项建设及有关工作暂未完全恢复，支付压力延后。

（三）房企复工复产较慢

自2月份开始，国家统计局4次《关于当前企业生产经营情况的调查问卷》显示，莆田市房地产开发企业存在销售收入下降、资金周转困难、经营成本上升、租金税费压力大等方面的困难。从3月问卷看，只有55.1%的企业达到正常生产水平的80%-100%，14.1%的企业达到正常生产水平的30%以下。

三、对策建议

一是加快项目建设。疫情期间施工进度放缓、项目运营成本上升，相关部门应密切关注企业项目经营状况，重点解决项目在防疫、融资、建材、用工、配套建设等方面存在的困难，预防和及时化解因企业资金周转困难引发的各种风险，确保项目按期建成交付使用。

二是有序推动土地出让。土地是房屋供给的源头，做好房地产开发供给侧改革，土地供给改革要先行，不断提升土地开发经营水平和土地价值。要进一步加强规划引领，推进土地整体开发，科学论证、合理安排、优化配置地块功能，有节奏、有计划推进土地出让工作。

三是加大金融支持力度。稳定企业贷款，降低企业融资成本，通过适当降低利率、减免逾期利息、调整还款期限等方式帮助企业摆脱困境。
