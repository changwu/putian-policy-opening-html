上半年莆田市房地产运行分析

第四十一期
发布时间：2021-07-17 16:24
| | |

2021年上半年，房地产市场整体延续了去年下半年的疫情后强劲复苏态势，房地产开发投资规模大幅增加。中央调控进一步向供给端侧重，房地产金融监管持续强化，央行推出房地产贷款集中度管理机制，及严查首付来源的机制下，市场回归价值和产品，房地产销售需求高位回落。

一、房地产运行特点

（一）房地产开发投资连续四个月增幅全省第一

上半年全市房地产完成投资242.80亿元，增长26.0%，比全省平均水平高11.8个百分点，连续四个月增幅位居全省第一。对全市固定资产投资的贡献率为57.2%，拉动全市固定资产投资增长5.3个百分点。

由于去年下半年全市经营性房地产用地大量供应，今年的新开工面积和土地购置费大幅增长。中南莆田荔城大道项目、保利绶溪片区地块一、和鸣·兰溪、文献首府等项目带动100多亿元土地购置费入库，支撑上半年房地产投资大幅增长。本年新开工面积330.17万平方米，增长141.6%。土地购置面积88.70万平方米，增长88.8%。

从工程用途看，增长主要来自于住宅投资，随着市场需求预期的变化办公楼投资大幅下滑。其中，住宅投资完成184.04亿元，增长31.2%；办公楼投资3.6亿元，下降60.4%；建安工程完成投资172.09亿元，下降14.0%。

（二）商品房销售热度不减

上半年，商品房销售面积315.13万平方米，增长48.8%。增速虽然比上个月回落23.9个百分点，但房地产销售面积增幅仍位于全省第一，比全省平均水平高26.8个百分点，连续四个月位居全省第一。

各县（区）商品房销售面积除了仙游是负增长外，全部正增长。荔城区无论是城区中心还是周边的项目都受到购房者的追捧；城厢区近两年加大城区中心棚户区拆迁改造，出让的经营性房地产用地位置均在主城区；涵江区则不断优化各楼盘教育资源等配套措施；秀屿区近两年出让的地块较多并已全面入市销售，价位相对中心城区明显偏低吸引周边刚需购买。

其中：城厢区90万平方米，增长92.2%；涵江区55.35万平米，增长65.5%；荔城区82.89万平方米，增长52.2%；秀屿区40.88万平方米，增长58.4%；仙游县41.43万平方米，下降12.5%；北岸4.58万平方米，增长18.3%。

（三）房地产资金面总体良好

上半年，全市本年实际到位资金289.14亿元，增长54.2%。其中，国内贷款47.34亿元，增长139.0%；自筹资金130.19亿元，增长48.7%；定金及预收款77.65亿元，增长69.0%；个人按揭贷款26.93亿元，下降13.2%；其他到位资金7.05亿元，增长118.5%。受商品房销售额持续上涨因素的影响，房企资金回笼速度加快。

二、后续需关注的主要问题

（一）房地产用地供应量降价升

上半年，全市经营性房地产用地供应有所下降，供应地块以位于城市周边为主。由于成交的12宗地块中有5宗达到最高限制价格进入摇号，因此全市土地供应呈量降价升现象，可见近期销售持续增长带给房企看好莆田市场的预期。1-6月全市通过招拍挂供应经营性房地产用地12宗60.94公顷，下降7.5%；出让总价款56.25亿元，增长7.7%。

（二）房地产开发投资主要依赖土地购置费拉动

房地产开发投资中，土地购置费达36.5%，土地购置费对本年完成投资的贡献率达83.3%，拉动增长21.7个百分点。按房屋建设工程、土地开发工程投资额和土地购置费的结构来看，莆田市的房地产开发投资过分依赖土地款，要提高持久稳定的建安工程、设备工器具等投资比例。

（三）商办地产库存压力仍大

虽然上半年商品房销售实现增长，但主要依靠住宅销售的拉动。住宅销售占所有商品房销售的92.0%。而办公楼销售面积仅7.81万平方米，下降49.2%。商业营业用房销售5.6万平方米，下降2.3%。摊大饼式的城市建设伴随的是粗放式的土地开发，大量的商业项目一哄而上，导致商办地产过剩。

三、对全市房地产市场发展的建议

（一）加大住宅土地供应

土地是影响房地产供给的重大因素，地价是房价的基础，需求较旺的情况下，地价上涨推动房价更快上涨。由于上半年房地产用地供应不足去年的一半，如果第三季度未加大供地力度，势必影响下半年新增项目投资和市场后续供给。

（二）扎实有效化解房地产库存，确保去库存消化周期合理。鼓励企业将商业、办公楼等非住宅商品房转化为住宅、租赁住房等其他符合条件的经营性、公益性用房，支持房地产企业从销售商品房转向“租购并举”投资模式。
