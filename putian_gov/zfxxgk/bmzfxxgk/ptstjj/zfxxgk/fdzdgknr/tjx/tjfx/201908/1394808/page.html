2019年上半年我市能源生产、消费情况简析

第四十九期
发布时间：2019-08-02 08:33
| | |

今年上半年，在市委市政府坚持高质量发展，落实跨越赶超的领导下，我市经济运行保持稳中有进的发展态势，实现地区生产总值1061.47亿元，同比增长8.1%，增幅位居全省第三。同时节能宣传活动全面铺开，节能降耗工作紧密落实，单位GDP能耗同比保持下降趋势，形势较上年有明显好转。

一、电力生产情况

2019年上半年我市规模以上工业发电量合计为99.32亿千瓦时，同比下降7.7%。其中，规模以上火力发电量为73.85亿千瓦时，同比下降5.8%；规模以上水力发电量为12.66亿千瓦时，同比下降20.3%；规模以上风力发电量为12.80亿千瓦时，同比下降4.1%。

从当月的发电情况看，6月份受气温升高影响，全社会用电需求增加，我市规模以上电力生产扭转持续下降的趋势，首次出现了当月发电量较上年增长，增速达26.2%。

二、全社会电力消费情况

2019年上半年我市全社会用电量为66.64亿千瓦时，同比下降5.1%。其中，第一产业用电量为0.42亿千瓦时，同比增长3.6%；第二产业用电量为42.12亿千瓦时，同比下降8.0%；第三产业用电量为8.73亿千瓦时，同比下降1.0%；居民生活用电为15.31亿千瓦时，同比增长1.0%。

工业用电的减少影响较大。1-6月我市工业用电量合计为41.25亿千瓦时，同比下降9.2%，降幅较一季度扩大8.3个百分点，工业用电量减少对全社会用电的影响为4.6个百分点。

三、规模以上工业综合能源消费情况

2019年上半年我市规模以上工业综合能源消费量为184.41万吨标准煤，同比增长4.6%；规模以上工业增加值同比增长8.4%，单位规模以上工业增加值能耗同比下降3.5%。

（一）高耗能行业能耗新增发力

上半年我市高耗能行业综合能源消费量为144.94万吨标准煤，占规模以上工业综合能源消费量比重为78.6%，同比增长4.5%，增幅比上季度增加2.4个百分点。其中，化学原料和化学制品制造业受福建永荣科技新建投产入库的影响，增速由一季度的-9.9%提高至255.4%，对全市规模以上工业综合能源消费量影响为7.3个百分点。

（二）化石能源品种消费有升有降

2019年上半年，规模以上工业煤品消费量为308.01万吨，同比增长4.0%；油品消费量为0.57万吨，同比下降6.9%；天然气消费量为2.74亿立方米，同比下降14.3%。

从分行业消费情况看，电力、热力生产和供应业仍是煤品、天然气的主要消费对象。1-6月电力生产消费的煤品、天然气占全市规模以上工业消费量比重分别为83.4%、79.9%。化学原料和化学制品制造业受永荣科技投产影响，原煤消费量增加较多，同比增长358.5%，占全市规模以上工业消费比重由上年的1.6%提高至本年的6.8%。

（三）地区间能耗趋势存在差异

2019年上半年，六大县区中单位规模以上工业增加值能耗同比下降的有5个，分别为仙游县（下降11.6%）、荔城区（下降11.4%）、城厢区（下降9.2%）、北岸（下降8.3%）、涵江区（下降6.5）；规模以上工业增加值能耗同比增长仅有秀屿区，增速为14.4%，出现增长的主要原因在于4月份永荣科技投产，生产尚处于爬坡期，但能耗增量大。

四、能耗“双控”形势预测

2019年一季度单位GDP能耗下降率为3.97%，降幅较2018年扩大较多，节能形势有所好转。从上半年全市用电及规模以上工业能耗情况看，预计我市能耗总量增速将有小幅度的提高，单位GDP能耗同比仍保持下降趋势，但降幅比一季度有所缩减。

（一）全社会用电量同比下降是我市单位GDP能耗保持下降趋势的主要因素。近五年来我市全社会用电量占全社会能耗的平均比重为63.8%，2018年达到77.7%的最高比重。因此全社会用电的趋势很大程度上决定了我市全社会能耗的增速。1-6月我市全社会用电量同比下降5.1%，与1-3月的增长0.6%比，趋势明显走低。根据评估法计算，其对全社会能耗总量增速的影响约为-3.3个百分点，是促进单位GDP能耗下降的有利因素。

（二）规模以上工业等价能耗增速提高推动能耗总量增速提高。1-6月我市规模以上工业等价能耗为116.6万吨标准煤，同比增长14.8%，增幅比1-3月增加11.0个百分点。规模以上工业能耗对全市能耗总量的拉动从1-3月的0.4个百分点提高到1-6月的4.8个百分点，但规模以上工业增加值对GDP的拉动仅为0.1个百分点。规模以上工业对能耗总量的影响较大于对GDP的影响，是导致单位GDP能耗降幅缩减的不利因素。
