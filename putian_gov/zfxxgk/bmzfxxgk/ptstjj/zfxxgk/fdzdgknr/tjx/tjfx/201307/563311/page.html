上半年莆田市规模以上工业实现“双过半”

发布时间：2013-07-15 00:00
| | |

今年以来，我市工业经济继续保持平稳发展的基调，上半年全市规模以上工业顺利实现了“双过半”。 1-6月份作为经济“晴雨表”的全社会工业用电量完成16.48亿度，比上年同期增长13.5%，增幅比1-5月提高1.28个百分点，显示出我市工业运行态势向好，且基础较为扎实。

 一、工业运行的基本特点

（一）工业生产实现“双过半”，增幅位居全省前列。1-6月，我市规模以上工业企业实现工业总产值1034.43亿元，完成年度计划的52.2%，超序时进度2.2个百分点，可比增长15.6%，比全省平均水平高0.8个百分点，增幅跃居全省九设区市第三位；实现工业增加值314.87亿元，完成年度计划的50.8%，超序时进度0.8个百分点，可比增长15.5%，比全省平均水平高2.3个百分点，增幅稳居全省九设区市第三位。

（二）效益水平进一步提升，社会贡献力不断扩大。1-5月份，规模以上工业经济效益综合指数为299.16%，同比提高0.90个百分点。实现税金总额19.40亿元，比上年同期增长6.4%；实现利润总额36.44亿元，比上年同期增长10.5%。工业经济的发展，创造了大量的就业机会，有效地缓解了社会就业压力。1-5月份规模以上工业企业吸纳的就业人员数23.10万人，比上年同期增长10.7%，就业的增长同时也显示了工业经济的不断好转，成为工业经济运行中的一大亮点。

（三）重工业领先增长，轻工业贡献突出。上半年规模以上重工业实现工业总产值314.49亿元，可比增长19.1%，增幅比轻工业快5.0个百分点，对规模以上工业经济增长的贡献率达36.1%，拉动规模以上工业经济增长5.6个百分点；轻工业实现工业总产值719.95亿元，可比增长14.1%，对规模以上工业经济增长的贡献率达63.9%，高于重工业27.8个百分点，拉动规模以上工业经济增长10.0个百分点。

（四）“国老大”增势喜人，亿元企业拉动力强。上半年规模以上工业中国有控股企业在LNG、鞍钢冷轧、龙源风力发电增长的带动下快速发展，实现工业总产值83.55亿元，可比增长29.8%，增幅比全市平均水平高14.2个百分点，对规模以上工业经济增长的贡献率达13.7%，拉动规模以上工业经济增长2.1个百分点。

1-6月份规模以上亿元企业数达284家，实现工业总产值790.99亿元，占规模以上工业总产值比重达76.5%，比上年同期增长18.6%，增幅比全市平均水平高3.0个百分点，对全市规模以上工业经济增长的贡献率达79.1%，拉动规模以上工业经济增长13.9个百分点。

（五）十大产业全面增长。上半年我市规模以上十大产业集群均实现不同程度的增长，共实现工业总产值978.31亿元，比上年同期增长15.6%，对规模以上工业经济增长的贡献率为94.6%，拉动规模以上工业经济增长14.8个百分点。其中，十大产业按贡献份额依次为：

1、制鞋产业：作为莆田工业经济的第一大产业和出口创汇的重要来源，目前超亿元的企业达86家，拥有协丰、荔丰、华丰等一批可制造耐克、阿迪达斯、彪马等世界名牌的企业。上半年企业数达212家，实现工业总产值235.54亿元，可比增长14.1%，对规模以上工业经济增长的贡献率达20.9%，贡献额居十大产业之首，拉动全市规模以上工业经济增长3.3个百分点。

2、机械装备制造业：上半年企业数达96家，实现工业总产值122.61亿元，可比增长23.7%，对规模以上工业经济增长的贡献率达16.8%，成为全市产业老二，拉动全市规模以上工业经济增长2.6个百分点。产值超亿元企业31家。主要产品有无刷电机、制动蹄块、活塞环、刀模钢、发动机盖体、铝型材、数控机床、金属制品以及中大型钢铁铝铸件等，装备制造产业的协作、配套较为充分。

3、工艺与创意产业：莆田工艺美术历史悠久，技艺精湛，在国内外享有盛誉。尤其是莆田雕刻工艺，不仅居福建之首，而且以“雕刻之乡”闻名全国，目前超亿元企业有26家。上半年企业数达193家，实现工业总产值125.83亿元，可比增长15.4%，增幅低于全市平均水平0.2个百分点，对规模以上工业经济增长的贡献率达12.0%，拉动规模以上工业经济增长1.9个百分点。

4、食品医药产业：上半年企业数达98家，实现工业总产值139.19亿元，可比增长10.7%，增幅低于全市平均水平4.9个百分点，对规模以上工业经济增长的贡献率为9.7%，拉动规模以上工业经济增长1.5个百分点。该产业主要以雪津啤酒、闽中食品重点企业为龙头的食品业为主，上半年超亿元企业42家，主要产品有：酒制品、蔬菜食品、饲料烤鳗、海产品、食品饮料、蛋制品、米面油食品、肉制品等。医药业只有6家规模企业，上半年产值仅2.1亿元，最大的企业产值不超过七千万，出现明显的短腿。

5、能源产业：目前我市形成以太平洋火电厂、LNG燃气电厂、龙源风力、南日风力发电场为主的煤、气、风在内的多品种电力能源结构。上半年企业数17家，实现工业总产值80.29亿元，可比增长19.1%，增幅高于全市平均水平3.5个百分点，对规模以上工业经济增长的贡献率达9.2%，拉动规模以上工业经济增长1.4个百分点。能源企业户均产值达4.7亿元，为各产业之首。

6、金属冶炼及压延加工业：上半年企业数16家，实现工业总产值23.78亿元，可比增长66.2%，比全市平均水平高50.6个百分点，增幅居十大产业之首，对规模以上工业经济增长的贡献率为6.7%，拉动规模以上工业经济增长1.0个百分点。主要产品有无刷电机、制动蹄块、活塞环、刀模钢、发动机盖体、铝型材、数控机床、金属制品以及中大型钢铁铝铸件等，上半年产值超亿元企业5家，停产1家。

7、化工产业：上半年企业数达51家，实现工业总产值70.04亿元，可比增长14.8%，增幅比全市平均水平低0.8个百分点，对规模以上工业经济增长的贡献率达6.5个百分点，拉动规模以上工业经济增长1.0个百分点。目前形成以佳通轮胎、海安橡胶、三棵树涂料为核心的莆田石化产业，亿元以上企业16家。

8、纺织服装业：上半年企业数达65家，实现工业总产值55.80亿元，可比增长17.8%，高于全市平均水平2.2个百分点，对规模以上工业经济增长的贡献率达6.1%，拉动规模以上工业经济增长1.0个百分点。纺织服装业中卡朱米服装、才子衬衫获中国驰名商标，超亿元企业达18家。

9、木材浆纸产业：上半年企业数达76家，实现工业总产值59.62亿元，可比增长14.9%，增幅比全市平均水平低0.7个百分点，对规模以上工业经济增长的贡献率达5.5%，拉动规模以上工业经济增长0.9个百分点。主要依托标准木业、亿发集团等重点企业，大力发展木材浆纸产业，亿元以上企业17家。

10、电子信息业：上半年企业数达48家，实现工业总产值65.61亿元，可比增长2.9%，低于全市平均水平12.7个百分点，其中6月份当月下降3.8%。1-6月份电子信息业对规模以上工业经济增长的贡献率为1.3%，增幅居十大产业末位，拉动规模以上工业经济增长0.2个百分点。上半年新世纪电子、中科万邦等为首的上亿元企业达19家。

二、值得关注的问题

（一）工业生产回升基础尚不稳固，发展后劲不足。6月份当月工业用电量增幅比5月份回落2.2个百分点，显示当前工业经济发展仍面临着“内忧外患”的双重压力。一是工业生产“高开低走”。1-2，1-3、1-4、1-5、1-6月份，规模以上工业增加值增幅分别为17.0%、16.0%、15.6%、15.6%和15.5%；规模以上工业总产值增幅分别为17.1%、16.2%、15.8%、15.8%和15.6%，呈缓慢回落态势。二是外需低迷。上半年我市规模以上工业出口交货值增长8.6%，比一季度低6.6个百分点，比全市规模以上销售水平低7.2个百分点，仍处于低位增长，说明当前外贸复苏基础不稳固、不确定性依然存在。三是缺少新投产企业。上半年只有5家新投产工业企业纳入规模企业范围，户均产值3100万元，缺乏新的龙头企业带动，发展后劲不足，难以形成集群效应和规模效应，降低了工业经济抗风险能力。

（二）企业规模小、高技术产业比重低。上半年我市规模以上工业超亿元企业284家，仅占规模企业数的30.0%，其中5亿元以上企业只有28家，10亿元以上企业仅7家，缺乏超50亿元的大企业，企业规模普遍较小，无法形成规模效应，造成工业企业因实力不足而不能进行转型升级，影响工业企业的竞争力。

6月份我市规模以上高技术产业企业实现工业总产值13.94亿元，下降5.9%，其中电子及通信设备制造业下降8.3%，电子计算机及办公设备制造业下降14.7%。1-6月份高技术产业累计实现工业总产值86.09亿元，增长3.2%，低于全市规模以上工业平均增速12.4个百分点。高技术产业总产值仅占我市规模以上工业总产值比重8.3%。

（三）企业自主创新能力不强、生产要素保障不足。全市电子、纺织服装、制鞋等行业多数企业以加工贸易为主，过度依赖订单生产，自主科研开发、创新设计、产品细化、功能差异化、产品专业化的能力不强，导致大量低端产品抵御国际市场变化风险能力不足。

在资金方面，政府投融资平台能力不足，民间资本融资渠道窄、成本高，中小企业融资困难，导致中小型工业企业投入严重不足，发展后劲乏力；在用工方面，劳动力供应缺口增大，“招工难”现象普遍存在，季节性缺工特别突出，员工流动性大，同时用工成本上升过快，企业负担加剧。

三、加快工业经济发展的建议

工业经济是推动全市经济发展的重要力量，也是加快转变经济发展方式的主力军，必须进一步解放思想、提高认识，坚定不移地鼓励、支持和引导工业经济可持续发展。

（一）密切关注工业经济运行中的新情况。要加强调查研究，分析需求变化，强化监测预警，及时发现经济运行中出现的苗头性问题，做到见事早、行动快、应对有效，不断提高政策的针对性和灵活性。重点关注工业经济的稳定运行，特别是帮助制鞋业、工艺美术与创意、纺织服装产业等行业重点企业增强信心、积极调整、开拓市场、提高效益；关注工业用电量、新开工项目、交通运输周转量等先行指标折射出的趋势信号；关注环境保护力度加大对化工等产业发展的新挑战。

（二）大力推进工业经济转型升级。借助经济结构调整、资源、环境等约束性指标形成的倒逼机制，鼓励工业经济坚守实体经济，大力改造提升传统产业，积极进入高技术产业、战略性新兴产业和现代服务业等领域，加快培育产业竞争新优势。加快培育和发展工业骨干企业，大力扶持和发展中小企业，切实帮助企业解决突出困难和问题，尽快形成大中小企业梯次结构、协同发展的良好格局。

(三)抓好要素保障，力促企业发展。发挥政府部门的职能作用，围绕企业产品销售、项目建设、技术创新、政策落实、贷款融资、要素保障等方面，切实为企业提供有针对性的服务，为企业建设和发展提供有力支撑。为企业创造可持续发展的外部环境。一方面，按照我市区域经济协调互动发展战略要求，坚持错位发展，避免项目既分散又雷同。另一方面，引导项目向工业园区、基地聚集，实现集约管理，集群发展。制定更加优惠政策，鼓励技术改造和产业升级的产业政策，进一步完善政、银、企合作平台，最大程度上解决中小企业融资难的问题。

（四）积极解决企业用人用工难题。与国内外高校、科研单位建立人才合作机制，引进人才，培育人才，增强企业自主创新能力；与劳动力资源丰富的地区建立长效劳务市场，缓解用工紧张局面；立足于莆田现有的高校和职业学校，培养行业亟需的专业人才和产业工人；提供优质服务，创造优良的工作、生活及成才条件，构建良好的人才集聚环境。

（五）大力加强品牌和渠道建设。品牌和营销渠道是制约产业发展的关键，要鼓励龙头骨干工业企业积极进行品牌和渠道建设，鼓励龙头骨干企业加快资源整合和行业协作，组建新型的产业协作股份公司，增强竞争能力，构建集团采购机制，联合共同建设渠道品牌，拓展国内外市场，在国内外建成一定规模的营销渠道。积极实施品牌战略，鼓励和引导企业打造国家级、省级著名商标和名牌产品。在现有区域品牌的基础上，争创更多的区域品牌，提升区域产业的知名度和影响力，以区域品牌带动产品品牌建设。
