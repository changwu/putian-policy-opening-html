2017年莆田市产业结构与经济运行质量分析

发布时间：2018-02-01 15:31
| | |

2017年，全市坚持稳中求进工作总基调，深化供给侧结构性改革，加快产业转型升级，培育新兴消费热点，提高经济质量效益。经济增长的质效更高、活力更强、后劲更足。经济保持了总体平稳、稳中向好的发展态势。

一、产业结构调整取得新进展

据初步核算，2017年，全市实现生产总值2045.19亿元，增长8.4%，增幅位居全省设区市第三位，高于全省平均水平0.3个百分点。其中，第一产业增加值130.30亿元，增长3.0%，对经济增长的贡献率为2.3%；第二产业增加值1146.50亿元，增长7.4%，对经济增长的贡献率为50.5%；第三产业增加值768.39亿元，增长10.8%，对经济增长的贡献率为47.2%。三次产业结构由2016年的6.9：56.2：36.9调整为2017年的6.4：56.0：37.6。

（一）农业内部结构不断优化。农林牧渔业经济在发展的同时，内部结构得到优化。其中农业在农林牧渔总产值中所占的比重由2016年的36.7％下降为2017年的35.7％；林业产值所占比重为2.1%与2016年持平；牧业产值所占比重由2016年的16.4%下降到2017年的14.8％；渔业产值所占比重由2016年的37.3％上升到2017年的40.5％。

（二）工业产业结构渐趋合理。2017年，莆田从实际出发，相继新建、扩建和改造了一大批工业项目，工业内部各行业的发展趋于合理、协调。轻工业发展快于重工业。2017年，全市规模以上轻工业增加值增长9.3%，增幅高于重工业增速3.7个百分点，占全市规上工业增加值总量71.7%，对规模以上工业经济增长的贡献率为77.4%，拉动规模以上工业增加值增长6.4个百分点。亿元企业增势强劲贡献给力。2017年，全市超亿元以上企业增长14.7%，占全市规上工业增加值总量达90.2%，对规模以上工业经济增长的贡献率为131.7%，拉动规模以上工业增加值增长10.8个百分点。主要产业支撑作用突出。2017年，全市重点培育的7大主要产业增长10.0%，对规模以上工业经济增长的贡献率为92.9%，拉动全市规上工业经济增长7.6个百分点。

（三）建筑业增加值占GDP比重有所提高。2017年，全市建筑业实现增加值 220.12亿元，增长6.2%。建筑业增加值占GDP的比重为10.8%，比2016年提高0.3个百分点。2017年，全市建筑业实现产值655.20亿元，增长23.6%，同比提高14.2个百分点。分行业看，房屋建筑业企业 188家，占全市建筑业企业（含劳务分包）个数的57.8%，同比提高1.2个百分点；土木工程建筑业企业95家，占全市建筑业企业个数的29.2%，同比提高 0.7个百分点；建筑安装业企业5家，同比减少1家；建筑装饰和其他建筑业企业38家，同比减少1家。分县区看，2017年各县区建筑业产值增幅较上年均有不同程度的提升，北岸、秀屿增速最高，分别达45.4%、44.1%。

（四）第三产业发展势头向好。2017年，第三产业实现增加值768.39亿元，增长10.8%，增幅位居全省设区市第六位，高于全省平均水平0.5个百分点，对GDP的贡献率47.2％，拉动GDP增长4.0个百分点。从服务业内部看，交通运输、仓储及邮政业、批发和零售、住宿和餐饮等三个传统行业平稳增长，实现增加值227.79亿元，增长5.6%，占全市生产总值的比重为11.1%，同比回落0.5个百分点。金融业增速趋缓。2017年，全市金融业实现增加值116.70亿元， 增长4.7%，占全市生产总值的比重为5.7%，同比回落0.3个百分点。房地产增长平缓。2017年，全市房地产业实现增加值94.48亿元，增长4.3%，占全市生产总值的比重为4.6%，同比提高0.1个百分点。营利性服务业发展迅速。2017年，全市营利性服务业实现增加值215.13亿元， 增长28.5%，占全市生产总值的比重为10.5%，同比提高1.5个百分点。

二、经济运行质量进一步提高

（一）消费市场平稳运行。2017年，全市实现社会消费品零售总额695.41亿元，增长11.6%。从消费结构看，家政服务、休闲娱乐、教育文化等服务消费有较大增长空间。从商品市场看，新型电子产品、智能型家电、节能型汽车、健身器材和环保家居建材增长迅速。从消费方式看，网上购物保持高速增长。全市303家限额以上批发和零售企业通过互联网实现商品零售额112.56亿元，增长28.1%，增幅比限上零售额快11.1个百分点，拉动社会消费零售总额增长4.0个百分点，网上购物成为拉动全市消费品市场增长的主要亮点。

（二）投资稳中提质。2017年，全市把扩大投资与提高投资效益、促进科学发展有机结合起来，全市固定资产投资在结构调整中呈现出增长平稳快速、总量进一步扩大、结构不断优化的良好态势。2017年，固定资产实现投资2274.65亿元，增长17.4%。分产业看，第一产业实现投资36.50亿元，增长14.2%；第二产业实现投资670.07亿元，增长12.5%；第三产业实现投资1566.71亿元，增长19.5%。分构成方式看，建安工程实现投资1845.13亿元，增长23.1%；设备工具器具购置实现投资197.65亿元，增长1.8%；其他实现投资231.00亿元，下降5.7%。

（三）地方级财政收入快速增长。2017年，全市财政总收入205.20亿元，增长13.9%。其中，地方级财政收入136.37亿元，增长17.8%。财政支出227.34亿元，增长9.6%。其中，一般公共服务等八项支出178.99亿元，增长17.5%。金融形势稳定向好，存贷款余额稳步增长。年末全市金融机构人民币各项存款余额1775.23亿元，增长4.9%，金融机构人民币各项贷款余额1791.69亿元，增长8.5%。

三、经济增长中需关注的问题

（一）从核算角度看，部分指标的回落对GDP增速影响较大。如，商品房销售面积增长3.6%，同比回落26.6个百分点；财政一般公共服务等八项支出增长17.5%，同比回落1.5个百分点；人民币存贷款余额增长6.1%，同比回落5.0个百分点；限上其他营利性服务业营业收入增长61.0%，同比回落3.5个百分点。经测算，以上几个因素影响GDP增速同比回落0.55个百分点。

（二）工业下行压力有所加大。减停产企业近三成。12月末，全市停产企业155家，影响工业增加值53.18亿元，拉低全市工业增加值增幅4.3个百分点；12月末减产企业205家，影响工业增加值15.83亿元，拉低全市工业增加值增幅1.3个百分点。

（三）投资质量有待提高。2017年，在项目投资中，全市新扩建项目完成投资1678.79亿元，增长22.4%，占项目投资的比重为73.8%；而内涵型的改建和技术改造项目仅完成投资171.30亿元，占项目投资的比重仅为9.1%。
