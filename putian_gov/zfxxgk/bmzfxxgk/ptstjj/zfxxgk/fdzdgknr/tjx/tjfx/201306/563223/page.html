1-5月我市外经贸发展步伐加快

发布时间：2013-06-24 00:00
| | |

今年以来，我市各级各有关部门积极为企业排忧解难，全市对外经济稳步发展，主要经济指标快速增长。

1-5月全市累计新签合同外资项目18个，同比增长20.0%，增幅比一季度高58.5个百分点；合同外资额15844万美元，同比增长101.2%，增幅比一季度高34.1个百分点；实际利用外资额17153万美元，同比增长19.5%，增幅比一季度高4.0个百分点，居全省九地市第一位，高于全省平均水平16.6个百分点。

1-5月全市外贸进出口额188185万美元，同比增长8.0%，增幅比一季度高3.1个百分点。其中，外贸出口额122244万美元，同比增长8.5%，增幅比一季度高1.3个百分点，居全省第七位，排名比一季度靠前一位；外贸进口额65941万美元，同比增长7.1%，增幅比一季度高6.8个百分点，居全省第六位，排名比一季度靠前一位。

一、利用外资情况

1、项目个数增长较快。1-5月全市累计实现合同利用外资项目18个，比上年同期增长20.0%，但比前年同期31个仍有较大的差距。

2、合同利用外资额成倍增长。1-5月全市合同利用外资额15844万美元，比上年同期增长101.2%，但与前年同期的30145万美元比仍处于较低的水平。

3、新增项目平均规模提高较快。18个新增项目中，平均每个项目的合同利用外资为880万美元，比上年同期增长67.6%。

4、实际利用外资额增幅位居全省首位。1-5月全市实际利用外资额17153万美元，比上年同期增长19.5%，也比前年同期的10408万美元增长64.8%（见表一）。

二、外贸进出口情况

1、外贸进出口平稳增长。1-5月全市完成外贸进出口总额188185万美元，比上年同期增长8.0%，增幅比前年同期的7.2%高0.8个百分点。

2、外贸出口平稳增长。1-5月全市完成外贸出口额122244万美元，比上年同期增长8.5%，增幅比前年同期的9.3%低0.8个百分点。增幅在全省排第七位，比第一季度靠前一位。

3、外贸进口增长加快。1-5月全市累计完成外贸进口额65941万美元，比上年同期增长7.1%，增幅比前年同期的2.7%高4.4个百分点。

4、私营企业出口额超过三资企业。1-5月，在出口企业中，私营企业出口额60787万美元，占总量比重从去年同期的48.2%上升到今年的49.7%，而三资企业由上年同期占比重的51.1%下降到今年49.6%。同时，私营企业贸易顺差为44767万美元，高于三资企业的32289万美元（见表二）。

5、鞋类占出口比重最大。1-5月全市鞋类出口额65141万美元，占出口总额的53.3%，比重比上年同期提高1.7个百分点。

6、天然气进口额居各类产品首位。1-5月全市天然气进口额21346万美元，占进口总额的32.4%，为最大进口产品类。

7、美国是我市最大出口地。1-5月全市对美国的出口额59274万美元，占出口总额48.5%，比重比上年同期提高2.1个百分点。同时，对美国的贸易顺差为53220万美元，居地区贸易顺差的首位。

8、一般贸易规模大于加工贸易。在出口企业中，一般贸易占约六成，加工贸易约占四成；在进口贸易中，一般贸易约占四分之三，加工贸易约占四分之一。

9、三类进口产品增长较快。一是化工类产品增长最快。1-5月全市累计共进口化工产品7397万美元，同比增长341.9%。二是机电类产品进口增长较快。1-5月全市进口机电产品5611万美元，同比增长28.9%。三是木材类增长较快。1-5月全市进口木材12350万美元，同比增长25.8%。
