建筑业增速全省第一 县域发展支撑点凸显

第三十三期
发布时间：2019-05-21 15:22
| | |

1-4月，莆田市建筑业生产保持较快增长的良好势头。从注册地看，1-4月总专包建筑业企业完成建筑业总产值231.31亿元,增长17.4%，增速位居全省第一，与一季度持平，较上年同期提高3.9个百分点。从省外入莆企业看，1-4月省外入莆建筑企业完成产值40.30亿元，增长39.0%，增速较一季度和上年同期分别提高17.3个和44.7个百分点。

一、城厢涵江两区领跑全市

从产值总量来看，1-4月，城厢、涵江两区领跑全市各县区建筑业，建筑业总产值双双超过50亿元，分别达到 60.65 亿元、52.99亿元，两区建筑业总产值合计占全市总量的 49.1%，将近半壁江山。从各县区产值增长情况看，北岸、秀屿区的增速最高，分别为57.2%、28.4%。增速最低的县区是荔城区，仅2.7%。

二、部分县区支撑点作用凸显

城厢区拥有全市最大规模的建筑企业。中交建宏峰是全市最大的两家特级企业之一，1-4月总产值超过全区总产值的6成，拉动全区建筑业总产值增长14.8个百分点，产值贡献率81.3%。涵江区中标外地房地产大项目量大且多。该区4大企业产值将近全区产值的9成，中标房地产项目主要涉及江西、重庆、成都、南京、福州等地，项目共计14个，签订合同额共计88.13亿元。北岸的新签合同额增速高。1-4月北岸资质建筑企业本年新签合同额21.8亿元，同比增长74.7%，较一季度和上年同期分别提高39.4个和82.3个百分点。湄洲打破去年资质企业空白。今年湄洲新增入库建筑企业29家，以小企业居多，共计完成建筑业总产值0.95亿元。

三、建筑业发展呈现三大问题

空壳企业多,部分小企业面临倒闭的危机。1-4月，无产值的企业数占总企业数的12.0%，产值低于500万的企业数占总企业数的61.7%。空壳化成为建筑行业一个较为普遍的现象，由此引发的一系列工程管理不规范、工程质量无保障、安全事故频发、法律纠纷等问题愈加明显。同时，未中标的企业数超过一成，也说明我市小企业多，或者处境困难，或者只是围标串标的工具。

部分大中企业无业绩，存在一级二级无工程中标的现象。一二级未中标的企业共有21家，其中一级总承包和专业承包企业各1家。资质升级或者专业拓展往往对注册建造师及相关技术人员有一定的专业、级别和人数要求，还对企业资产、业绩一级技术装备有具体标准，资质企业特别是成长为一级企业不易，这类现象需关注。

大企业迁移多，存在城市吸引力不足的现象。2014年底至今，我市至少10家一级企业搬迁厦门，去年这些搬迁企业共计完成建筑业总产值384.33亿元，超过去年全市建筑业总产值的一半，这十家企业在近五年内年平均增长超过50%。数据显示，近年来大量企业的迁移影响我市建筑业综合实力，不仅影响产值，也造成税收收入的流失，更是人才的外流。

四、发展建议

从中小企业来看，我市建筑业企业资质普遍不高、规模普遍偏小，招投标时，与外省建筑业企业竞争时相对处于劣势。要改变这一现状，建议或联合中小企业，取长补短，成立实力更强的企业，即联合经营战略；或引导企业集中资源，做细做专，即专业化经营战略。

从无业绩的大中企业来看，需鼓励企业挖掘自身优势,可进行兼并、重组，调整结构，整合资源，充分优化配置，使企业实力得到壮大，提高这类企业的中标率。同时,主管部门应积极引导我市大型企业到外省抢占市场。

从大企业外迁来看，建议从两方面入手：一要提升服务。各县区政府要变管理为服务，让企业感受到本地发展的环境和空间会越来越好。同时深入了解企业需求，在引导企业提高实力的基础上，切实解决实际困难。二要适时变通。当企业做到一定规模，需要更大的发展空间才能发展壮大时，要保持与企业的积极沟通，可引导企业设大城市为主要经营地，在本地设注册地。同时，对企业的相关优惠政策尽快落地。
