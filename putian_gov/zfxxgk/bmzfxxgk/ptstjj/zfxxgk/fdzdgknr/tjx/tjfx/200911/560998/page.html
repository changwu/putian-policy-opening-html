消费市场发展平稳 结构调整幅度加大

发布时间：2009-11-20 00:00
| | |

今年以来，我市社会消费品市场总体发展较为平稳。随着经济形势的回暖和明年省运会在我市召开日期的临近，一大批新增的大型商贸项目逐渐进入营业产出期，将为我市商贸市场整体规模的快速发展注入新的助推力。1-3季度，全市社会消费品零售总额167.23亿元，比上年同期增长13.8%，扣除物价下降1.8%因素，实际增长15.9%。其中：城区零售额142.30亿元，比增13.4%；镇区零售额11.62亿元，比增19.1%;乡村零售额13.31亿元，比增14.4%。分行业看，批发与零售业共完成143.56亿元，增长13.4%；住宿和餐饮业完成16.68亿元，增长17.5%；其他行业完成4.08亿元，增长13.4%。

一、主要特征

1、汽车行业总体增长较快。1-3季度，汽车业共完成零售额5.79亿元，同比增长28.5%，拉动全市零售额增长0.9个百分点。今年以来，汽车业逐季回暖。年初受金融危机影响较深，第1季只有小幅增长，1季度零售额为1.80亿元，比上年同期增长4.7%；4月份，国家出台购车优惠政策，减少小排量汽车的购置费，加上油价比上年同期下降一成以上，汽车市场开始快速升温，第二季伴随宏观经济的回暖，汽车零售额呈现较快增长的态势，完成2.02亿元，当季增长31.8%，1-2季累计3.82亿元，同比增长17.5%；第3季依托经济回升迹象的进一步明朗，汽车业销售走出补偿性增长，当季的零售额比上年同期增长57.1%。

2、超市、商场规模扩张迅猛。全市17家限额以上超市和商场完成零售额4.70亿元，比上年同期增长82.2%。自去年底以来新增了永辉和家乐福两个超市，新华都与万家惠联合并扩充了经营点，风凰百货增加经销分店扩大营业额。大超市快速发展原因之一是价格比较合理；二是商品质量较有保障；三是大超市除商品类别比传统类别增加外，也兼营生鲜水产品、洋快餐、新出炉面包与蛋糕、小件家电、服装与日用品等，专柜货物齐全，商品丰富多样，超市经营规模越来越大；四是近年来城乡道路畅通，方圆十几公里的郊区居民也常来城内大超市采购，大超市的吸引力越来越强，辐射范围不断扩展。

3、家电下乡促进农村消费增长。截至10月底，全市彩电、冰箱、手机、洗衣机、计算机、空调、电磁炉、热水器、微波炉等九类家电下乡商品，共售出4万多台，实现销售额1.14亿元。按13%补助，共发出财政补助一千多万元。家电下乡是政府积极应对金融危机和拉动消费的一大举措，也是惠及广大农村的一项民心工程，它为缩小城乡差距起到积极推动作用。据了解，我市国美和苏宁两大电器集团积极参与家电下乡销售。两大品牌家电集团前三季各自从这一活动中分得6-8百万左右的市场份额。

4、住宿餐饮业发展加快。住宿和餐饮业前三季完成19.59亿元，同比增长17.5%。(1)限上餐饮及住宿业2.34亿元，增长10.5%。其中：住宿业增长10.4%，中餐增长16.4%，洋快餐下降4.1%。(2)限下和个体住宿餐饮业完成零售额17.25亿元，增长18.5%。限下和个体住餐业增长较快的主要原因：一是随着生活质量的提高，人们的饮食习惯更加讲究卫生和质量，越来越多档次较高的餐饮店，使用了一次性或消毒标志的餐具，许多餐饮业也降低利润和提高质量留住常客；二是城镇化增加市区人口，许多家庭办婚庆酒席选择在中餐馆；三是高脂肪和油炸食品越来越不受欢迎，洋快餐经常被列入不良饮食的黑名单。

5、网售市场较红火。我市依托庞大的鞋业生产基地的地缘优势，催生出一支大规模的网上销售队伍，它们以批发给网售用户为主要业务，兼作网上零售。每个网售商店平均３-４人经营。许多实体店也兼营网上业务，网售业务有数万名的从业人员。全年可实现网上交易额数十亿元人民币。

6、工艺美术品销售较好。我市工艺美术城集聚了本地众多珠宝商入驻经营，经过近几年的打造已成为本省一个重要的珠宝批发市场。近年来市政府为促进消费，在工艺城成功举办了多届展销会。每届展销会除了以金银和珠宝饰品为主题外，还有古典家具、汽车、房地产、佛教文化用品博览会、名优特产品展销会、木业投资贸易洽谈会、海峡论坛、美食节等等。每一届的展销会都会带来数千万的销售额和一大批的订单。

7、上塘珠宝城是生产基地型市场。莆田是福建省工艺美术品重点产区。2008年，全市共有工艺美术企业3700多家，从业人员16.5万人，年产值60多亿元人民币。目前珠宝城内有固定商业店铺约150家，销售额超亿元，销售范围辐射到全国各地和东南亚地区。

8、妈祖文化旅游带动消费。我市湄洲岛是妈祖的故乡和妈祖文化的发祥地。妈祖信俗申报“世遗”获得成功，成为我国首个信俗类世界遗产，标志着妈祖文化正式成为全人类的共同文化遗产，对保护妈祖文化、传承信仰习俗、挖掘文化内涵、推动广泛传播、扩大世界影响将起到积极的促进作用。今年的“十一”黄金周，全市共接待游客60.6万人次，实现旅游收入2.39亿元，同比增幅均为16.0%。

近年来莆田相继获得“中国木雕之城”、“中国古典工艺家具之都”、“中国珠宝玉石首饰行业特色基地”和“中国银饰之乡”等称号，是国内拥有工艺美术区域品牌称号最多的城市。目前我市正规划依托这些独特优势，打造一个以工艺美术文化为特色，集工艺美术品贸易、研发、会展、观光、休闲、购物于一体的工艺美术文化旅游区。该旅游区规划范围为荔城区黄石镇、北高镇。工艺美术文化旅游区建成后，游客可游览购物的景点很多，如工艺美术城、梅妃故里景区、海峡工艺品博览会、黄石镇玉器加工市场、北高黄金首饰市场、北高黄金工艺品大观园、北高后海围垦工程、后海海鲜美食村等。

二、主要问题

近年来我市加大力度在改善城乡居民的生活质量上展开了一系列惠民工程项目，集中体现在改善交通通讯、建设休闲公园、引进大型超市和大品牌商贸物流企业上，同时提高低收入和困难群众的生活补助，对促进消费起到了积极的作用。但是，目前我市仍存在诸多抑制消费增长的因素，主要有以下几方面。

1、在岗职工人数下降对消费增长影响较大。受金融危机影响，全市城镇就业人数下降，继去年底在岗从业人数出现同比负增长6.1%后，到今年三季末仍同比下降2.6%；城镇居民人均消费性支出增长9.1%，居民人均生活消费支出增长8.6%，增幅分别比上年同期的增幅少4.3和7.2个百分点。

2、高房价对居民消费支出产生抑制作用。由于房价偏高，部份居民等待观望，使1-9月居民储蓄存款增加额比上年同期增长43.7%。新房装修所配的家电数量总体减少，影响了家电和建材市场的发展,全市限额以上家电业前三季销售额1.66亿元，同比下降16.0%；限上钢材零售额也比上年同期下降49.9%。

3、达到限额标准的个体户数量较多影响限上统计指标质量。我市拥有大量的快速成长的个体经营户，许多个体经营户经营规模已经达到贸易统计的限额标准以上，但由于其观念上的限制和注册企业要求有完善的财务制度等原因，许多个体户不愿改变身份为企业，按照国家统计方法制定规定，个体户是不能纳入限额以上统计范围的，因而使我市限额以上商贸企业的发展速度和发展水平无法完全反映出来。

                                  撰稿：吴碧兰
