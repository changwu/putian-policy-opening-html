2011年三季度莆田市城镇就业情况分析

发布时间：2011-12-15 00:00
| | |

前三季度莆田市就业形势总体平稳，城镇就业总量继续小幅增加，职工平均工资较快增长。

一、城镇就业基本情况

（一）城镇非私营单位就业人员小幅增长。

第三季度末，全市城镇非私营单位从业人员28.33万人, 比上年同期增加0.88万人，增长3.2%，增幅比上年同期上升了2.5个百分点。

1、分企业事业机关看，企业增加人数最多。企业从业人员20.86万人，比上年同期增加0.63万人，增长3.1%；事业、机关单位从业人员分别增加0.16万人和0.09万人，与上年同期相比增长2.9%和5.6%。企业增加人数占全部增加人数71.2%。

2、分经济类型看，主要是以股份、“三资”经济为主的其他单位增加人数最多。第三季度其他单位从业人数17.48万人，比上年同期增加0.52万人，增长3.0%；国有和集体单位分别比上年同期增加0.38万人和减少0.02万人，同比分别增长4.0%和下降1.8%。其他单位新增就业人数占全部新增就业人数的58.7%。

3、分行业看，主要是建筑业、教育和住宿餐饮业人数增加。第三季度，建筑业、教育和住宿餐饮业就业人数分别为1.80万人、3.82万人和0.28万人，与上年同期相比分别增加0.28万人、0.14万人和0.12万人，增幅分别为19.1%、3.7%和73.6%。与上年同期相比，就业人员减少的行业有七个，其中减少较多的行业有信息传输、计算机服务和软件业，交通运输、仓储和邮政业以及居民服务和其他服务业，这三个行业第三季度就业人数为0.14万人、0.39万人和0.03万人，分别比上年同期减少0.08万人、0.05万人和0.02万人，降幅达36.6%、12.1%和36.9%。

（二）城镇非私营单位劳动报酬有所增长。

1-9月，全市城镇非私营单位发放劳动报酬63.63亿元,与上年同期相比增加了10.73亿元，增幅达20.3%，比上年同期提高6.8个百分点。其中，在岗职工工资总额62.08亿元，比上年同期增加10.77亿元，增长21.0%，增幅比上年同期提高7.9个百分点。

1、按企业、事业、机关分类来看，企业、事业、机关劳动报酬都有不同程度增长。1-9月，企业、事业和机关单位劳动报酬分别为43.03亿元、15.56亿元和5.01亿元，与上年同期相比，分别增加7.22亿元、2.60亿元和0.90亿元，增幅达20.2%、20.1%和21.9%。在总增长额中，企业所占比重最多，达到67.3%。

2、按经济类型分类来看，其他类型的单位报酬总量增长最多。1-9月，其他、国有和集体的城镇非私营单位的劳动报酬分别为33.44亿元、27.66亿元和2.54亿元，与上年同期相比分别增加5.50亿元、4.99亿元和0.24亿元，增幅分别达到19.7%、22.0%和10.4%。

3、分行业来看，在19个行业中，17个行业有不同程度的增长，2个行业下降。制造业、建筑业和教育三大行业增长较多，信息传输、计算机服务和软件业以及居民服务和其他服务业劳动报酬下降。至本季末，制造业、建筑业和教育实现劳动报酬分别为28.26亿元、3.85亿元和10.03亿元，分别比上年同期增加4.01亿元、1.18亿元和1.32亿元，增幅达16.5%、44.6%和15.2%。与上年同期相比，信息传输、计算机服务和软件业报酬减少0.37万元，下降5.3%，居民服务和其他服务业报酬减少0.33万元，下降29.7%。

（三）平均工资稳步增长。

今年1-9月全市城镇非私营单位全社会从业人员平均工资为22282元（月均2476元），比上年同期增加2994元，增幅达15.5%，同比提高2.9个百分点。其中在岗职工平均工资为22438元（月均2493元），比上年同期增加3156元，增幅达16.4%，同比提高4.6个百分点。

1、按企业、事业、机关分类来看，各单位类型在岗职工平均工资均有所增长。企业、事业、机关单位在岗职工平均工资同比增长速度在20%之内。其中企业为16.0%、事业为17.7%、机关为16.8%。

2、按经济类型分类来看，三大经济类型齐头并进。国有经济单位在岗职工平均工资同比增速为15.9%，集体经济单位为13.6%，其他经济单位为16.5%。从增加额来看，国有经济单位增长最多，平均工资增加3910元。

3、分行业来看，18个行业增长，1个行业下降。在岗职工平均工资下降的行业为居民服务和其他服务业，其他行业均有不同程度的增长。在各行业中，金融业依然领跑，第三季末平均工资达到59804元；居第二位的是信息传输、计算机服务和软件业，达到47902元；第三位的是电力、燃气及水的生产和供应业，达到40877元；三个行业分别比上年同期增加10369元、8486元和2585元，同比增长21.0%、21.5%和6.8%，增幅比上年同期上升1.3、16.0和下降4.0个百分点。1-9月劳动报酬未达到2万元的有三个行业，居倒数第一位的是住宿和餐饮业，为16297元；其次是制造业，为18180元；再次是建筑业，为19661元。三个行业同比分别增长43.0%、15.0%和16.8%。平均工资最高行业与最低行业的比值为3.7：1，与前两季度持平。

二、存在问题

（一）全市体量总体偏小。全市在岗职工平均工资额比全省平均水平（27401元）少4963元，在全省中排名第8位，比最后一名的南平市（22398元）仅多40元，而比第一名的厦门市（33176元）少10738元。与全省的同比平均增速相比，莆田市社会从业人员增速低于全省（5.6%）2.4个百分点，从业人员劳动报酬低于全省（25.2%）4.9个百分点，在岗职工平均工资低于全省（17.6%）1.2个百分点。

（二）企业就业人员不稳定，人员进出频繁。与2季度相比，本季度企业就业人员同比增速放缓，下降了0.9个百分点，而在上季度却增长4个百分点。

（三）第二产业在岗职工平均工资较低。按三次产业划分，截至第三季末，第二产业在岗职工平均工资为19035元（月均2115元），比第一产业少3217元，比第三产业少9723元。第二产业为我市经济支撑产业，其工种一般较苦、较累，在坚持“效率优先、兼顾公平”的原则下，提高第二产业劳动报酬有着重要的意义。

（四）社会从业人员劳动报酬上涨面临诸多压力。从第三季度的有关数据来看，7-9月居民消费价格指数分别为106.2%、106.3%和105.8%，1-9月累计为105.9%，均在高位运行。高物价抵消了部分收入，给增加收入造成了压力。

三、建议和对策

（一）广开渠道，增加就业。就业是关系民生的一项重要的社会工程，政府要加强政策指导，企业要具体实施落在实处。要继续贯彻实施《劳动合同法》，不断完善和落实促进就业的政策，不断完善就业服务，逐渐加大对高校毕业生、农村劳动力、城镇就业困难人员的就业扶持力度。

（二）不断加大职业教育。当前，我市经济还是以劳动密集型产业为主，对人员数量的要求较高，对科技水平的要求相对不高。在这种情况下，加大职业教育，对提高劳动者的知识、技能，防止结构性失业意义重大。

（三）坚持和完善最低工资制度。最低工资是对劳动者的基本生活和合法权益的保障，有利于社会的维定。据悉，2010年，我市除仙游县最低工资为700元外，其他四个区为800元。政府要加大执法力度，对未执行最低工资标准的企业要坚决查处。
