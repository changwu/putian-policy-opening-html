2018年一季度莆田市规上工业企业景气状况分析

发布时间：2018-04-17 14:51
| | |

一季度，全市380家规上工业企业完成了工业企业景气调查问卷，占规上工业企业数的31.1%。从调查汇总情况看，企业景气指数较上年四季度有所提高，处于“较为景气”区间，企业家对后期经济运行谨慎“乐观”。

一、工业企业景气指数处于较为景气区间

一季度，企业景气指数为128.1，比上年四季度高4.4点，处于“较为景气”区间，其中，反映企业当前景气状态的即期企业景气指数为128.9，比上年四季度高2.7点。反映企业未来景气预判的预期企业景气指数为127.6，比上年四季度高5.5点。一季度企业家信心指数为129.0，比上年四季度高2.2点，企业经营状况持“谨慎”乐观。

二、生产能力利用情况

一季度，20.8%的企业认为本季度企业生产能力利用率与上年四季度相比提高，63.2%的企业认为不变，16.1%的企业认为下降。其中产能利用率的企业中，认为本季度生产能力利用率提高主要原因：65.8%的企业认为是市场需求大、订单增加影响。41.8%的企业认为是技术改造、生产效率提升。25.3%的企业认为是产品竞争优势增强。15.2%的企业认为是劳动供应改善。8.9%的企业认为资金状况改善。在产能发挥不足的企业中，认为本季度企业产能没充分发挥的主要原因：54.1%的企业认为产品需求减少、订单不足。39.3%的企业认为季节性减产。26.2%的企业认为劳动力供应不足。19.7%的企业认为产品竞争力不足。14.8%的企业认为资金紧张。

三、企业盈利与资金情况

一是企业盈利情况。11.6%的企业认为本季度盈利比上年四季度增加，73.9%的企业认为不变，14.5%的企业认为减少。据调查显示，企业盈利增加主要原因是受销售量增加、销售价格提高、税费下降等因素影响。企业盈利下降主要受销售量减少、用工成本上升、原材料上涨、产品价格下降等因素影响。

二是资金情况。资金周转情况：17.4%的企业本季度资金周转紧张，80.3%的企业认为基本正常，2.4%的企业认为资金充裕。融资情况：22.1%的企业无融资要求，63.2的企业认为融资难易程度一般， 8.9%的企业认为融资比较困难，2.4%的企业认为融资很困难，3.4%的企业认为融资比较容易。

四、企业投资情况

一季度，企业投资明显不足，仅15.0%的企业有投资，企业投资较为谨慎。企业主要投资方向偏向设备升级改造、扩大生产规模、新产品开发和节能环保投入等。受没有好项目、资金不足、投资效益低、对未来预期不乐观、科技和人才支撑不足等因素影响，还有85.0%的企业本季度无投资情况。

五、企业订单和用工情况

一是企业产品订货量总体平稳。83.9%的企业认为与上年四季度持平，5.0%的企业认为增加，还有11.1%的企业认为减少。

二是用工需求基本稳定。79.7%的企业认为本季度用工需求比上年四季度基本持平。12.1%的企业认为比上年四季度增加，主要是受订单增加、员工流失率高、企业规模扩大和季节性用工影响。受产能减少、订单不足等影响，还有8.2%的企业认为本季度用工需求比上年四季度减少。

六、相关政策落实情况

一是简政放权。57.1%的企业认为有一定效果，24.5%的企业认为不清楚或不享受该政策，7.4%的企业认为没效果。

二是创新支持。11.1%的企业认为效果明显，56.1%的企业认为有一定效果，6.1%的企业认为没有效果，26.8%的企业不清楚或不享受该政策。

三是减税降费。12.1%的企业认为效果明显，59.2%的企业认为有一定效果，7.6%的企业认为没有效果，21.1%的企业不清楚或不享受该政策。

四是降低融资成本。6.8%的企业认为效果明显，54.5%的企业认为有一定效果，6.8%的企业认为没效果，31.8%的企业不清楚或不享受该政策。

五是化解过剩产能。6.3%的企业认为效果明显，51.8%的企业认为有一定效果，6.6%的企业认为没有效果，35.3%的企业不清楚或不享受该政策。

六是“一带一路”建设。8.2%的企业认为效果明显，50.5%的企业认为有一定效果，5.0%的企业认为没有效果，36.3%的企业不清楚或不享受该政策。

七是促进外贸增长政策。7.9%的企业认为效果明显，50.3%的企业认为有一定效果，6.1%的企业认为没有效果，35.8%的企业不清楚或不享受该政策。

七、企业生产经营的主要问题

一是企业面临用工主要困难。34.5%的企业认为存在招工难的现象，24.6%的企业认为员工流失率较高，23.9%的企业认为员工工资上涨压力较大，6.2%的企业认为“五险一金”缴存比例高。

二是企业面临的主要成本压力。36.0%的企业认为用工成本，34.8%的企业认为原材料成本，8.1%的企业认为环保成本，7.6%的企业认为税费成本，6.3%的企业认为能耗成本，3.5%的企业认为物流成本，3.3%的企业认为融资成本。

三是融资难问题依然存在。据调查显示，76.7%的企业认为银行贷款门槛过高、手续繁杂、条件苛刻，34.9%的企业认为有效抵押资产不足，27.9%的企业认为利率水平过高、企业承受力不足，16.3%的企业认为资产负债率高、银行审贷困难，16.3%的企业认为经营状况不佳。

四是企业享受国家优惠政策的资格不足。据调查结果显示，50%以上的企业享受不到国家优惠政策，主要是不具备享受优惠政策的资格。
