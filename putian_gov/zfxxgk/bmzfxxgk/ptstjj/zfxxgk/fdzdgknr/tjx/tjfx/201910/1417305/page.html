1-9月建筑业总产值增幅位居全省第三

第六十七期
发布时间：2019-10-19 08:44
| | |

今年以来，在经济发展进入新常态，建筑业企业面临市场竞争加剧、发展速度放缓的严峻挑战情况下, 我市建筑业生产经营整体保持平稳较快增长。从注册地看，1-9月总专包建筑业企业完成建筑业总产值562.52亿元,增长14.6%，增速位居全省第三，较上年同期和1-6月分别提高8.6个和0.6个百分点。

一、建筑业发展特点

（一）大型企业持续发挥带动作用

9月份，我市新增5家一级资质企业，其中：4家新升级企业，1家新引进企业。1-9月，建筑业总产值超10亿元的建筑企业有15家，共完成建筑产值353.46亿元，同比增长20.0%，拉动全市资质以上建筑企业总产值12.0个百分点。

（二）区域建筑业发展不平衡

从总量看，1-9月荔城区、城厢区及涵江区完成建筑业总产值分别为141.81亿元、127.26亿元及125.51亿元，总量分居全市前三位；仙游县、秀屿区、北岸及湄洲岛完成建筑业总产值分别为87.23亿元、40.42亿元、38.49亿元及1.80亿元。从增速看，湄洲岛、北岸、仙游县及涵江区产值增速高于全市，分别为1860.9%、52.3%、25.3%及14.8%；产值增速低于全市的有：秀屿区、荔城区、城厢区产值增速分别为14.0%、7.9%、6.5%。

二、建筑业发展问题

（一）装饰装修产值下滑明显

近三年，我市资质企业的装饰装修产值总量逐年减少。1-9月完成装饰装修产值2.12亿元，下降35.4%，占总产值比重仅0.4%，降幅较上年同期、上半年分别收窄2.1个、13.2百分点。

（二）行业结构分布不均，个别行业发展落后

从行业看，全市建筑企业中，1-9月房屋建筑业、土木工程建筑业、建筑安装业及建筑装饰装修和其他建筑业产值分别为400.85亿元、155.60亿元、0.81亿元及5.26亿元，占总产值比重分别为71.3%、27.7%、0.14%及0.93%。房屋建筑业、土木工程建筑业的产值合计占总产值比重为98.9%,可见全市建筑行业结构分布不均。从行业细分类数据得出，铁路工程、城市轨道交通工程、海洋工程、节能环保工程等行业为主资质的建筑企业很少，甚至是空白。

（三）新签合同少，发展后劲严重不足

1-9月，新签合同额562.78亿元，与上年同期持平；签订合同额1121.93亿元，同比增长5.7%，增速较去年同期和上半年分别回落12.3个、1个百分点；1-9月房屋施工面积4466.64亿元，与上年同期持平，增速较上年同期及上半年分别回落2.3个、0.9个百分点。分行业情况看，新签合同额增速回落主要是由于主要业务活动为房屋建筑工程、管道工程、园林绿化工程的企业新签合同分别减少21.17亿元、1.81亿元、3.83亿元，同比分别下降5.1%、73.1%、64.0%，分别拉低全市新签合同额增速下滑3.8个、0.3个和0.7个百分点。本年新签合同额总量停滞不前，将影响建筑业市场开拓，不利于行业稳健发展。

三、建筑业发展建议

（一）助力市场开拓。一是建议各县区政府要进一步加大基础设施、制造业和服务业等领域投资力度，特别以扩大铁路、城市轨道交通、节能环保等建筑行业市场为主，引导企业向该领域转型；二是住建等主管部门要积极宣传，带动企业针对重点地区、重点行业不断开拓建筑业市场，尤其针对吉林、甘肃、陕西、北京、海南、内蒙古、上海、山东等占在外省完成产值0.5%以下的地区，同时要有针对性帮助企业获得公平的市场准入环境。

（二）助力企业转型。一是各县区要积极扩大绿色建筑、装配式建筑、超低能耗建筑应用规模，主管部门要及时出台各类新建筑模式的质量管理办法，组织企业间观摩学习，提升建筑企业劳动效率和工程质量；二是住建等主管部门要多措并举鼓励企业加强建筑技术研发，明确研发费用的范围，便于企业及时享受研发费用加计扣除红利，对企业高质量发展方面的创新、研发和推广应用给予一定的经济奖励并在工程评比中加大权重。

（三）助力营商环境优化。在经济多变环境下，应进一步规范招投标市场，打击围标、串标等不良行为，营造公平市场竞争环境，维护企业竞争秩序。同时及时清理废除和修订完善相关政策法规，不断改革创新，切实减轻企业负担。为着力解决EPC招标模式探索过程中遇到的问题，近期市住建主管部门对《关于规范房屋建筑和市政基础设施工程总承包项目（EPC）评标办法（试行）的通知》进行了重新修订，将进一步规范EPC招标投标市场，营造良好的营商环境。
