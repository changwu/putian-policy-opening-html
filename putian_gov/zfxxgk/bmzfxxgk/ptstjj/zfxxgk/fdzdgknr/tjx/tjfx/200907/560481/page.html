加强宏观调控 促进就业增容

发布时间：2009-07-21 00:00
| | |

金融危机持续影响我市外向型经济，但影响略有减弱，就业形势出现复苏迹象。2009年上半年全市城镇从业总量同比仍有下滑，但出现了一年多来的首次环比增长，政府经济刺激计划初现成效，只要社会各界坚定信心，政府继续加强宏观调控，经济复苏、就业增容应可逐步实现。

一、基本情况

（一）城镇就业总量环比略增

截至6月底全市城镇从业人员为27.27万人，较上年同期减少约1万人，下降3.5%，其中在岗职工为26.51万人，减少0.9万人，下降3.3%，但与今年一季度末相比，则增加2303人，增长0.9%，尽管增量较小，但这是自金融危机以来，连续五个季度就业总量环比下降后，出现的首次环比增长，可视为就业增容启动的一个信号。从不同经济类型看：

1、国有单位从业人数为94166人，同比减少929人，下降1%，环比增加866人，增长0.9%，主要原因是房地产回暖带来的建筑企业从业人员的增加。

2、城镇集体单位人数11429人，同比增加531人，增长4.9%，比上季末增加560人，增长5.2%，其中主要是个别建筑企业增员幅度较大，其余部分单位从业人员数有微量增长。

3、其他所有制单位人数167068人，同比减少9594人，下降5.4%，但较上季末则增加了877人，增长0.5%，经历了一年多持续下降后首次出现环比增长，说明政府一揽子经济刺激计划成效初现，但是，目前发展仍有较多不确定因素，相当部分中小企业尚未复工，特别是“三资”企业，用工较为谨慎，其用工量的增加仍有赖于宏观调控的继续实施和经济的进一步复苏。

（二）职工工资总额持续增长

2009年上半年，全市从业人员上半年劳动报酬总额为30.85亿元，比上年同期增长10.3%，其中在岗职工工资总额30亿元，同比增长11%，主要由于机关及部分事业单位工资改革中阳光福利的补发，其他所有制单位由于人员总量同比减少，工资总额增速明显放缓。

1、国有单位在岗职工工资总额为13.77亿元，比上年增长20.1% ；

2、城镇集体单位工资总额为1.13亿元，比上年增长14.6%；

3、其他单位工资总额为15.1亿元，同比增长3.5%。

（三）平均工资稳步增长

一方面受机关事业单位工资改革的影响，另一方面由于经济危机尚未过去，不少企业仍未复工，平均在岗人数下降较大，从而导致平均工资的持续提高，因此，2009年全市上半年从业人员平均报酬为11337元，同比增长15.9%；在岗职工平均工资为11395元，增长16.8%，呈平稳快速增长。

1、从国有、集体、其他分组来看，国有单位在岗职工平均工资为15666元，比上年同期增长19.2%。主要由于县区机关单位及教育系统事业单位阳光福利实行，使工资水平持续保持上升势头；城镇集体单位在岗职工平均工资为10182元，比上年同期增长3.7%，由于金融危机影响，部分企业工资发放不太稳定；其他所有制单位在岗职工平均工资为9193元，比上年同期增长13.4%，受经济危机影响，以制造业为主的其他所有制单位仍有相当部分关停并转，导致了上半年平均从业人数的下滑，所以虽然工资总额没有太大增加，却使得平均工资保持了一定的增长速度。

2、从企业、事业、机关分组来看，企业单位在岗职工平均工资为10285元，同比增长13.4%；事业单位在岗职工平均工资为13907元，同比增长21.7%；机关在岗职工平均工资为16445元，同比增长25.4%。由于机关事业单位存在阳光福利补发的情况，因此工资增速略高于其他类型单位。

3、从国民经济各行业看，除农林牧渔业、批发零售业、租赁和商务服务业有所下降外，其他行业职工工资都有不同程度的增长。我市各行业中上半年平均工资最高的为信息传输、计算机服务和软件业26378元/人，其次是金融业26019元/人，第三为垄断性的电力、燃气及水的生产和供应业23962元/人。而工资最低的为采矿业5850元/人，其次是住宿餐饮业7013元/人，第三为农林牧渔业8895元/人。平均工资最高行业与最低行业的差比为4.51：1，比上季末下降1.24个点。

（四）离开本单位仍保留劳动关系的职工情况

离开本单位仍保留劳动关系的职工上半年平均生活费为1909元，较去年同期上升了19.3%。而离岗保留劳动关系职工人数也从去年同期的3795人减少到今年的3318人，下降12.6%，主要为离岗职工到龄退休或停薪留职人员辞去工职，因此近年来一直呈下降状态。

二、存在问题

（一）金融危机对我市就业的影响仍在持续

政府经济刺激计划的实施已初现成效，部分企业已有复工迹象，但中小企业开工率仍然不足，大量农民工仍在寻找就业机会，因此，就业增容有赖于经济的进一步复苏。

（二）金融危机形势下劳动力市场存在不规范行为

目前部分企业以金融危机为由，拖欠农民工工资或拒签劳动合同，某些不法中介则利用求职者求职心切，骗取钱财，需要政府部门加强管理，及时整顿劳务市场，化解劳资矛盾，维护和谐的用工环境。

三、建议

（一）加大宏观调控力度

继续实行宽松的财政政策和货币政策，强化企业信心，对中小企业融资给予相应的优惠政策，尽量减轻中小企业负担，鼓励外贸出口企业积极寻找出路，利用国内市场拉动生产，稳固就业基础。

（二）进一步落实就业促进计划

一方面要强化失业人员信心，鼓励灵活就业、自主创业，在待业阶段不灰心、不气馁，积极充电，补充职业技能；另一方面要积极推进社会保障制度的进一步建立和完善，规范劳动力市场秩序，打击劳动力市场黑中介，及时解决劳资纠纷等问题，为劳动者营造和谐的用工环境，维护劳动者合法权益。
