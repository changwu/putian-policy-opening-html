2017年莆田市儿童发展纲要统计监测报告

第六十七期
发布时间：2018-10-24 11:17
| | |

儿童的生存、保护和发展是提高人口素质的基础，是人类未来发展的先决条件，关系着民族的兴衰，也关系着国家的经济发展和社会的进步。《莆田市儿童发展纲要（2011-2020年）》（以下简称《儿童纲要》）实施以来，我市始终坚持“儿童优先”的原则，以提高儿童整体素质、推动儿童事业全面发展为重点，各级政府和有关部门认真贯彻落实《儿童纲要》提出的各项目标，不断提高儿童的整体素质，努力促进儿童身心健康，实现了儿童事业与莆田经济社会同步发展，儿童成长环境进一步优化。《儿童纲要》五个领域中的关键性指标趋势向好，有力促进了儿童全面发展。《儿童纲要》涉及的五个领域的40个指标，28个提前达到2020年莆田终期目标，占70%（见表1），11个预期可达标，占27.5%。2017年莆田市儿童发展主要目标监测情况具体报告如下：

第一部分  外部环境

2017年，我市综合实力不断增强，社会民生持续改善。2017年，全市完成地区生产总值2045.19亿元，可比增长8.4%；全市财政总收入205.20亿元，增长13.9%。2017年全市城镇居民人均可支配收入达到31818元；农村居民人均可支配收入16492元；金融机构本外币存款余额达1803.61亿元；财政性教育经费55.08亿元；医疗卫生经费25.64亿元。

第二部分   纲要各领域实施进展情况

一、儿童与健康

（一）加强疾病防控，保障儿童健康安全。一是做好0-6岁儿童系统管理，保障工作质量，早期识别高危儿童。2016年7岁以下儿童保健覆盖率95.6%，其中3岁以下儿童系统管理率93.36%。二是加强对学校、托幼机构、重点疫区的防控力度和卫生监管。加强儿童免疫规划工作。在全市范围内推行数字化预防接种门诊建设，构建候诊、预检和接种、留观融为一体的自动服务系统。目前，全市已完成48家乡镇（社区）卫生服务的数字化预防接种门诊建设，儿童免疫接种率持续在高水平，均在98%以上，超过两纲终期目标95%要求。百日咳、乙脑、流脑、甲肝、乙肝、风疹、流腮等疫苗可预防传染病发病率大幅降低，切实保护儿童身体健康和生命安全。

（二）完善防控体系，切实降低出生缺陷率。一是认真开展婚孕检、生育咨询服务等项目，提高新婚夫妇、计划怀孕夫妇出生缺陷干预知识的知晓率。2017年全市婚检人数为49862人，疾病检出率为7.47%，对影响婚育疾病提出医学意见8623人，占17.29%；孕前优生检查33474人，覆盖率88.32%，查出高危风险人数1674人。二是加强孕期管理，提高产前筛查率和产前诊断率，有效降低出生缺陷发生率。2017年全市开展血清筛查29056例，产前筛查率64.18%，检出高风险1387例，筛查阳性率为4.77%；胎儿系统超声筛查检查共21699例，开展介入性产前诊断874例，诊断异常率10.07%。三是在将新生儿代谢性疾病筛查从原有两种增加到4个病种，且4个疾病筛查的诊疗项目均纳入基本医疗保险支付范围100%给予补偿。持续巩固新生儿疾病筛查、视力筛查和听力筛查工作，根据《福建省出生缺陷医院监测方案》，修订完善《莆田市出生缺陷医院监测方案》，扩大监测医院范围和监测时限，做好出生缺陷监测工作。

二、儿童与教育

（一）促进学前教育快速发展。2017年，我市现有幼儿园352所，在校幼儿123956人，学前教育三年入园率为98.12%，比2016年提高0.62个百分点，基本普及学前三年教育。一是继续扩大优质学前教育资源。对县区申报符合申报条件的幼儿园进行市示范性幼儿园评估验收，对部分省、市示范性幼儿园进行复查跟踪，确认郊尾中心幼儿园等5所为市示范性幼儿园，完成了涵江第二实验幼儿园等5所幼儿园的省、市示范性幼儿园复查跟踪工作。二是开展省级保教改革建设幼儿园遴选推荐工作，共有11所幼儿园确认为福建省首批“保教改革建设幼儿园”。三是开展学前教育宣传月活动。组织各县区（管委会）教育局积极开展学前教育宣传月活动，按省厅要求组织优秀经典游戏案例收集评选及报送工作。

（二）促进义务教育规范发展。一是开展义务教育管理标准化学校建设。经省教育厅评审，我市41所学校通过“义务教育管理标准化学校”。二是完善义务教育阶段招生制度。实行部分公办小学毕业生对应直升公办初中政策；规范中心城区民办初中招生，实现六个统一。三是推动学校提升办学层次。38所学校成为福建省首批义务教育教改示范校，16个学科申报省级普通高中优质学科课程项目建设立项；6所一级达标校申报省级示范性普通高中建设学校。

（三）加强农民工随迁子女就学工作。进一步规范对农民工随迁子女教育教学工作的管理，做好服务工作。2017年秋季共有2245名农民工随迁子女通过电脑派位进入义务教育阶段公办学校就读，12440名由县区教育局统筹安排相对就近学校就读。全市共有2141所义务教育学校招收农民工人员随迁子女，农民工随迁子女在校就读12640人。一是加强教育教学管理。针对流动人口子女地域文化背景的不同，因人施教、分类要求、分层指导，促进他们和本地学生共同成长。二是保障学校同等待遇。要求学校在学籍管理、评优评先、考试竞赛、文体活动、加入团队组织等方面同等安排，不歧视进城务工人员随迁子女。三是开展助学帮困活动。鼓励社会各类团体对农民工随迁子女进行专项的助学帮困活动，帮助他们顺利完成学业。四是建立家校联系制度。建立教师与农民工随迁子女谈心制度，加强与家长沟通，缓解农民工随迁子女因为陌生环境而产生的心理压力。

（四）全面加强学校德育工作。一是推动“三进”工作。深入开展社会主义核心价值观“进教材、进课堂、进头脑”、“爱学习、爱劳动、爱祖国”系列教育活动，把核心价值观教育体现到学生守则、行为规范及师德师风建设中。充分发挥激励的导向作用，传导正确价值取向。二是积极创建书香校园。在全市中小学开展“书香满校园  阅读伴成长”全民阅读活动，扎实地开展了新颖活泼、形式多样的全民阅读活动、青少年爱国主义读书教育活动、中华经典诵读活动，在广大师生及家长中倡导爱读书、读好书、善读书和终身学习理念。

三、儿童与福利

（一）加强救助管理，提高孤儿养育水平。一是加强儿童保障工作有效开展。困境儿童保障工作得到加强，集中供养和散居孤儿基本生活保障标准分别由1000元、600元提高到1500元、900元。市妇联等相关单位每年针对困境儿童开展慰问活动等。民政、教育、公安等8部门部署开展“合力监护、相伴成长”关爱保护专项行动，实行关爱保护“五个一”机制，解决了44名无户籍留守儿童户籍办理和4名失学辍学留守儿童的返校就学问题，全市5965名农村留守儿童的受委托监护人签订《农村留守儿童委托监护责任确认书》达100%。二是强化救助管理水平。目前全市共有市救助管理站、仙游县救助管理站、涵江区救助管理站、秀屿区救助管理站4个流浪儿童救助保护中心。市救助管理站联合社工机构，持续开展冬送温暖、夏送清凉和接送“流浪孩子回家”等专项行动，全年共救助流浪乞讨人员2023人次（未成年54人次）。认真开展站外托养机构排查整改工作，全市各救助站（点）的滞留人员在全国救助寻亲网上的寻亲信息发布率和公安部门的DNA采集率均达100%。

（二）残疾儿童康复服务水平不断提高。2017年免费为146名未成年残疾人发放儿童轮椅、助行器、助听器等7类辅助器具167件。救助0-6岁听障儿童人工耳蜗植入手术22例，造价补助440万元。康复训练听力残疾、精神残疾、智力残疾儿童分别为65名、126名、217名，指导社区和残疾人家庭肢体残疾儿童康复训练142名。一是加大对残疾儿童康复训练补助力度。出台了残疾儿童康复救助提标扩面优惠政策，落实残疾儿童三项补贴，全市6600多人次残疾儿童亨受三项补贴，发放补助546.6多万元。二是推进康复服务机构的发展。目前全市有24家社区康复室和9家康复服务机构为自闭症、脑瘫、听障、智力等残疾儿童提供康复服务。三是0-6岁残疾儿童康复训练补助实现全覆盖。2017年底全市0-6岁残疾儿童727名，接受康复训练和服务659名，有455名残疾儿童在8家康复服务机构得到康复训练服务，补助实现全覆盖。

 四、儿童与社会环境

（一）未成年人活动场所不断优化。2017年，全市已开办家长学校1176所，其中学校的家长学校1071所，社区的家长学校105个，学校的家长学校建校率和社区的家长学校建校率分别为100%和87.5%，比上年有所提高，超过《儿童纲要》达到80%的目标要求。儿童之家130个，比2016年增加67个。市、县区妇联推动各县区（管委会）将社区儿童之家和社区家长学校建设纳入2018年为民办实事项目。同时，自2018年起连续三年评选20个市级示范性社区儿童之家和社区家长学校，通过“以奖代补”的方式，市财政按每个2万元的标准给予补助。将儿童之家建设、社区家长学校工作列入创建全国文明城市和全国未成年人思想道德建设测评体系，同步推进，同步落实。同时，采取政府购买服务的形式为儿童之家、家长学校引进近300场社工服务。各级教育部门与妇联共同组织开展公民道德建设和家庭教育宣传实践活动，通过组织形式多样的家庭教育讲座，提高家长的教育意识和水平，以家庭教育、学校教育、社会教育“三结合”为载体，加强未成年人思想道德建设。

     （二）加强文化市场监管，净化未成年人的文化环境。市执法支队围绕创建全国文明城市、“金砖”会晤及党的十九大文化市场安全保障工作，积极开展“扫黄打非”和校园周边、网吧整治等系列专项行动，确保全市文化市场平稳、健康运行。全年共出动执法人员7107人次，检查经营单位2536家次，立案查处违法案件25件，责令改正56家，责令停业整顿11家，罚款总计22.4万元，收缴违法音像制品4888张，非法书刊2299册。顺利完成“扫黄打非”进基层工作，实现全市7个县（区）、管委会、54个乡（镇）街道、970个村居（社区）“扫黄打非”基层机构纵向全覆盖进校园横向拓展，推进“网格化”管理。

（三）发挥文化阵地优势，拓展儿童的文化空间。一是儿童活动空间不断拓展。市博物馆、图书馆和县区文化三馆已投入使用，全市46个乡镇建成综合文化站，全市881个村实现农家书屋、广播室全覆盖，建有文化激情广场145个。今年9月份博物馆新馆预开馆以来，全市各中小学、幼儿园预约参观频繁，博物馆热情接待，为各学校提供免费讲解服务，共接待全市各学校参观团队约3万人次。二是儿童文化生活不断丰富。2017年购买妇女儿童图书出版物4.4千册、儿童音像制品100张，有少儿文献共4万册、动画电视节目播出757小时，进一步丰富少儿的文化生活。

五、儿童与法律

（一）打击侵害儿童人身权利的违法犯罪行为。公安机关开展全国打拐专项行动，建立侦办拐卖案件责任制、儿童失踪快速查找机制和来历不明儿童摸排比对机制，抓获大批人口贩卖分子，解救大量被拐儿童。在“儿童失踪信息紧急发布平台”即“团圆平台”及时发布并找回失踪儿童。2017年，全市共利用“团圆平台”发布失踪儿童52名，结案找回儿童52名。

（二）发挥法律援助作用。成立了维护妇女合法权益工作领导小组、维护妇女儿童合法权益合议庭、反家庭暴力合议庭。扩大法律援助范围，加强弱势群体法律援助工作，重点做好妇女、未成年人、老年人等群体的法律援助工作，特别加强家庭暴力、留守儿童的法律援助力度。今年以来，我市为311名未成年人，363名妇女提供法律援助，共占受援总人数的54%。

（三）预防未成年人犯罪。常态化开展校园法制宣传教育活动，稳步推进校园法治共建，持续在辖区内常态化开展模拟法庭活动。开展“送法进校园”活动，赠送书籍《全国青少年普法教育读本》700余册。积极组织开展全市中学“莆田市青少年法律知识竞赛”，促进了广大青少年学生学法、懂法、用法、守法。落实省法院、团省委《关于构建青少年权益保护、矛盾调处和犯罪预防工作衔接互动机制的若干意见》，注重对青少年被告人，特别是未成年被告人的法制教育，充分利用庭审，通过当庭教育，播放《重生》等微电影教育片，寓教于审，最大限度地教育感化青少年罪犯。2017年未成年人犯罪人数为182人，占同期犯罪人数的3.7%。2017年青少年犯罪人数979人，占同期犯罪人数的19.7%，同比下降1.2个百分点。

第三部分   实现目标的主要困难和问题

（一）青少年受教育水平有待提高。2017年九年义务教育巩固率为95.94%，比2016年的巩固率下降了0.52个百分点，这一监测指标波动较大；高中阶段毛入学率为95%，预计可以达标，但是较上年下降1个百分点，近7年来首次出现下降；中等职业教育在校生数为2.82万人，2010-2017年持续下降，预期难以完成市级规划2020年目标（规模扩大，办学质量提高）。优质教育资源供给不足、配置不均衡，普惠性学前教育资源短缺，农村学前教育发展滞后，民办幼儿园缺乏有效监管，城市住宅小区配套幼儿园尚未完全得到落实，管理体制和机制尚未完善。义务教育目前只能基本均衡，距离优质均衡发展还有一定距离。

（二）留守儿童问题不容忽视。近年来，随着经济不断发展，越来越多的农村富余劳动力涌入城市，98%都是由家中老人照顾，由于父母不在身边，亲情缺失，监护不力，留守儿童几乎处于学习上缺乏辅导、行为上缺乏管教的状态，未成年人身心都还未成熟，容易犯错。这些问题，将影响未成年人的健康成长，也会影响社会的稳定。

（三）儿童成长的社会环境有待优化。一是2017年社区服务中心63个，虽然较2016年翻了接近一倍，但依然难以完成《儿童纲要》“覆盖90%以上的社区”的目标；二是“示范性家长学校”占比39.97%，虽比2010年提高26.07个百分点，但离《儿童纲要》达到60%的目标仍有差距。其中学校示范性家长学校还未广泛开展。儿童之家建设虽然较上年有较大的提高，但是离《儿童纲要》90%以上的目标有较大的差距。

第四部分    对策建议

（一）加强儿童素质教育和职业教育建设。各级政府要继续加大对儿童事业的投入力度，多渠道筹措资金，引进优秀教学人才，通过提高师资力量来提高现有教学水平，加强义务教育、高中教育及中等职业教育建设。一是以规范办学行为为切入点，加强机制建设，逐步推进全面实施素质教育步入规范化轨道。二是继续推进普通高中新课程改革，不断完善普通高中教育质量体系。三是加大宏观调控力度，加强职业院校基础能力建设，统筹整合职业教育资源。坚持以就业为导向，进一步推动教育教学改革，积极探索工学结合人才培养模式。

（二）加大关爱留守儿童力度。充分调动社会和政府力量，建立党政领导牵头、部门协调配合、社会共同参与的留守儿童关爱服务工作机制，营造关爱留守儿童的良好环境。推动“建立以家庭监护为基础、社会监督为保障、国家监护为补充”监护制度。将“留守儿童之家”建设纳入市委市政府为民办实事项目，在留守流动儿童集中的地方创办“儿童之家”（“春蕾爱心书屋”），为留守儿童提供托管、辅导、心理抚慰等服务。引导鼓励社会组织、社工机构、爱心企业、志愿者等，通过建“留守儿童爱心家园”、公益夏令营等多种方式参与关爱留守流动儿童行动。

（三）优化儿童成长社会环境。开展广泛的宣传，提高社会和家长对儿童的教育意识，增强全社会关心、爱护儿童的意识，创造一个有利于儿童健康成长的良好社会氛围。一是建立健全城乡社区服务体系。政府财政向社区服务中心倾斜，进一步推进社区服务站和社区社会工作服务站建设，配备场所和设备，不断拓宽社会工作服务平台。二是因地制宜建好城乡社区儿童之家和社区家长学校，并推动基层做好规范化建设。同时，加大政策和资金投入，继续将儿童之家和社区家长学校建设纳入市、县区为民办实事项目。
