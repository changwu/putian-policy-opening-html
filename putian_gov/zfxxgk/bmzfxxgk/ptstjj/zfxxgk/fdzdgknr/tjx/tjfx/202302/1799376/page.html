2022年莆田市农业经济运行分析

第10期
发布时间：2023-02-05 08:49
| | |

今年以来，市委市政府高度重视农业生产，把农产品稳产保供作为新冠病毒疫情防控期间的重要工作之一，我市各级各部门在市委市政府的统一部署下，统筹抓好疫情防控和农业生产，及时协调解决农业生产中出现的问题，保障农业生产有序推进，确保粮食、生猪、蔬菜、水产等主要农副产品的稳产保供，稳住农业基本盘。

一、主要运行特点

（一）农林牧渔业总产值稳步增长

2022年,莆田市农林牧渔业总产值273.94亿元，可比增长2.8%。其中：农业产值62.43亿元，同比增长4.6%；林业产值6.50亿元，增长2.4%；牧业产值38.04亿元，增长3.6%；渔业产值144.69亿元，增长2.1%；农林牧渔服务业产值22.28亿元，增长4.3%。

（二）全年粮食实现扩种增产

我市全面贯彻落实中央、省委省政府粮食生产决策部署，进一步压实压紧粮食生产属地责任，出台粮食生产补助政策，鼓励引导种植户扩大粮食种植规模，提高粮食产能，粮食实现扩种增产。2022年全市粮食播种面积为46.17万亩，增长0.9%；产量为18.77万吨，增长0.7%；平均亩产为406.6公斤/亩，下降0.2%。

（三）茶果蔬全面实现增产丰收

今年以来，我市坚持统筹疫情防控和农业生产，加强农业生产田间管理，茶果蔬全面实现增产丰收。2022年，全市蔬菜播种面积为34.44万亩，增长2.7%；产量达67.98万吨，增长3.1%；平均亩产为1974公斤/亩，增长0.3%。茶叶产量达0.42万吨，增长4.1%。园林水果产量达22.38万吨，增长7.5%。

（四）林产品产量快速增长

去年四季度以来，我省开展松林改造，我市积极采取措施，多方协调，木材产量实现快速增长。2022年，全市木材产量21.78万立方米，增长29.6%。其中，松木产量14.24万立方米，增长1.7倍。油茶籽产量0.79万吨，增长3.4%。竹笋干产量0.22万吨，增长4.6%。

（五）畜牧业生产有序推进

至12月底，全市生猪存栏37.48万头，同比增长4.3%，2022年全市生猪累计出栏57.84万头，增长4.1%。至12月底，全市家禽存栏980.83万只，增长11.3%，2022年全市家禽累计出栏3504.22万只，增长1.5%。2022年全市畜牧业肉蛋奶累计总产量13.52万吨，增长4.0%，其中肉类总产量增长1.7%，奶类总产量增长1.9%，蛋类总产量增长11.3%。

（六）水产品产量逐年增加

2022年，全市水产品总产量102.57万吨，增长1.0%。其中海水产品产量99.63万吨，增长0.9%；内陆水域水产品产量2.93万吨，增长4.9%。在海水产品产量中，蛤和海带分别增长21.2%和3.2%，对水产品的贡献率分别达到了82.8%和57.7%。

二、存在的主要问题

（一）农作物种植面积大幅增加有难度。一是农业生产比较效益偏低，农民农业生产积极性不高；二是因缺乏青壮劳动力、干旱缺水等原因造成各县区仍然存在不同程度的抛荒撂荒现象。

（二）生猪价格跌破成本线。节前生猪价格跌破成本线，节后生猪价格再次下降，并创下了最近一年以来的“新低”。不少养殖户抱着“只要不出栏就是不亏损”的想法而选择压栏惜售，畜牧业将因畜产品增量不足而增长乏力。

三、下一步建议

（一）继续落实撂荒地复耕复种，切实做到应种尽种。一要继续出台农业生产优惠政策，充分调动农民农业生产积极性，采取有力措施，引导和支持龙头企业、农民合作社和种植大户开展专业化生产，带动闲田合理流转和连片规模开发，杜绝抛荒撂荒现象，确保应种尽种；二要全力抓好春耕备耕工作，切实做到应种尽种。当前已进入春耕备耕关键阶段，各级各有关部门要全力抓好春耕备耕，引导种植户调整种植结构,扩大我市优势农产品和粮食油料等国家战略农产品的种植规模。

（二）做大做强做优，促进畜牧业高质量发展。一是持续推动现有养殖场改扩建项目建设，提升标准化水平，推动生猪产业高质量发展；二是大力发展莆田黑猪、乌骨鸡等特色优质品种养殖业，提高养殖效益；三是出台政策鼓励支持肉牛、肉羊等草食动物养殖规模的扩大，做大做强做优畜牧业。

（三）加强预警预报和防灾减灾，确保农林牧渔生产有序推进。加强部门协作和气象预报预警，不断提升防冻减灾、防涝抗旱、防病治虫等农业生产管理能力，不断加大规范实施口蹄疫、猪瘟免疫和常年实施禽流感免疫等重大动物疫病防控，确保农林牧渔生产有序推进。

（四）千方百计促进产销对接，确保主要农副产品稳产保供。莆田具有322万的常住人口，农产品消费需求量大。各级各有关部门应继续加强农产品的生产情况与市场调查摸底，引导本地农产品批发市场、农贸市场、大型商超、规模连锁企业和社区便利店等与我市农产品生产基地进行直接产销对接，确保粮食、生猪、蔬菜、水产等主要农副产品的稳产保供。
