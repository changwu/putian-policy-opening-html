农业经济总量稳步增长 综合生产能力显著增强 ——2024年莆田市农林牧渔业运行情况分析

第10期
发布时间：2025-02-19 15:03
| | |
 2024年，莆田市委市政府按照中央一号文件决策部署，深入贯彻习近平总书记关于“三农”工作的重要论述，牢固树立和践行大农业观、大食物观，多渠道拓展食物来源，千方百计落实地方责任，分环节挖掘增产潜力，加强农业防灾减灾能力建设，全力攻坚克难，落实落细，抓好粮油和重要农产品生产供应保障，持续建设高标准农田，不断提高综合生产能力。

一、主要运行特点

（一）农林牧渔业总产值稳步增长，综合生产能力显著增强。2024年，全市农林牧渔业总产值285.11亿元，可比增长3.5%。其中：农业产值68.23亿元，可比增长4.6%；林业产值7.82亿元，可比增长6.5%；牧业产值36.89亿元，可比下降2.3%；渔业产值147.94亿元，可比增长4.2%；农林牧渔服务业产值24.22亿元，可比增长4.8%。

分县区看，农林牧渔业总产值增幅高于全市平均水平的有仙游、北岸、湄洲和涵江，分别可比增长5.5%、4.8%、4.7%和3.9%；与全市持平的为秀屿，可比增长3.5%；低于全市平均水平的有城厢和荔城，分别可比增长3.1%和-0.8%。

（二）压紧压实属地责任，粮油实现扩种增产。今年我市继续出台粮油生产奖补政策，逐级压紧压实属地责任，加大工作力度，优化政策措施，序时推进粮油生产。在稳步推进播种面积扩大的基础上，着力提高单产水平，保障全年粮油扩种增产。2024年，全市粮食播种面积47.00万亩，增长1.4%；产量19.26万吨，增长1.6%；平均亩产409.7公斤/亩，增长0.2%。油料播种面积20.14万亩，增长2.5%；产量4.37万吨，增长2.9%；平均亩产216.8公斤/亩，增长0.4%。

（三）主要农产品量足质优，茶果蔬实现“双增长”。今年，我市各级各部门围绕市场需求，继续发展设施蔬菜、高山蔬菜，加快生态果园、优质农产品示范基地建设，优化种植业结构，蔬菜产业“提质添绿”，水果品种改良升级，茶果蔬实现面积产量“双增长”。2024年，全市茶叶年末实有面积1.51万亩，增长0.9%；产量0.45万吨，增长3.1%。园林水果年末实有面积27.83万亩，增长2.3%；产量24.66万吨，增长6.4%。蔬菜播种面积36.37万亩，增长2.0%；产量70.96万吨，增长2.1%。

（四）优化渔业养殖产业布局，纵深推进渔业高质量发展。近年来，我市通过深水抗风浪养殖网箱、工厂化循环水“楼房养虾”、南日岛海域“筏式吊养+新型底播网箱增养”鲍鱼立体规模化养殖、筶杯岛8000亩油蛤底播养殖区立体套养龙须菜等项目引擎作用，不断优化渔业养殖产业布局，建设多营养层级立体生态养殖体系，大力拓展养殖空间，优化生态养殖结构，提高海水养殖产量，纵深推进渔业高质量发展。2024年，全市水产品产量111.99万吨，增长4.9%。其中，海水产品产量108.99万吨，增长5.0%。

二、存在问题

（一）山区和沿海乡镇耕地多为旱地。我市山区和沿海乡镇耕地多为旱地，旱地也叫望天田，耕种受气候影响大。据自然资源部门提供的最新耕地数据显示：我市耕地中旱地的面积占耕地总面积比例高达54.5%。近年来，我市各级各部门针对耕地抛荒撂荒采取了一系列复耕复种措施，但因受干旱缺水等自然条件因素影响，部分山区和沿海乡镇仍存在因缺水无法耕作的情况，在一定程度上制约了我市农业高质量可持续发展。

（二）生猪家禽存栏均下降。2024年自年初以来，全市生猪家禽存栏一直处于下降态势，导致全年生猪家禽出栏和肉产量也相应出现下降。2024年12月底，全市生猪存栏31.42万头，下降11.8%；家禽存栏849.81万羽，下降2.4%。2024年，全市生猪出栏60.70万头，下降3.5%，肉产量4.84万吨，下降2.5%；家禽出栏3209.13万头，下降4.4%，肉产量4.41万吨，下降5.8%。2024年12月底生猪和家禽存栏的下降，将会影响今年第一季度生猪和家禽的出栏，进而影响到牧业产值核算主要指标肉产量的增幅。

三、下一步的工作建议：

（一）强化复耕复种长效管护，杜绝撂荒田冬闲田存在。开展农作物耕种情况全面排查检查活动，逐级传导应种尽种的压力与责任，强化撂荒地复耕复种长效管护机制，杜绝撂荒田冬闲田的存在，同时要加强农业生产管理，切实提高农作物的生产能力。

（二）进一步加强农田水利工程建设，不断提高农业综合生产能力。一是加强农田水利工程建设，包括灌溉系统、水库、水渠等，解决农田的水资源供应问题，提高农田的抗旱能力和灌溉效率。二是修建排水沟、排水管道等农田排水系统建设，确保农田在降雨过程中及时排除积水，在台风暴雨季节避免因过度积水而影响作物生长。三是持续推进高标准农田建设，分区域、分类型明确任务布局和时序安排，加大投入、持续建设，不断提高农业综合生产能力。

（三）调整优化养殖结构，促进畜牧业高质量发展。一是大力发展生猪规模化养殖和循环养殖。要加大招商引资力度，引进国内外先进养殖模式的生猪生产企业，如丹麦皇冠等国际知名生猪养殖屠宰加工一体化企业，带动我市生猪养殖业向规模化养殖和循环养殖发展，提升行业整体竞争力。二是出台政策鼓励支持莆田黑猪、乌骨鸡等本地特色优质品种养殖规模的扩大，调整优化生猪家禽养殖结构，同时要扶持肉牛、肉羊等草食动物养殖规模的扩大，做大做强做优畜牧业。
