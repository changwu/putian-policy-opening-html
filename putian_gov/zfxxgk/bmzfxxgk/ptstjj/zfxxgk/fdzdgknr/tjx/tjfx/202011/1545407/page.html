1-10月莆田经济稳中有升

第七十二期
发布时间：2020-11-19 15:42
| | |

今年以来，面对疫情和国内外环境带来的严峻挑战，全市上下坚决贯彻落实市委、市政府决策部署，统筹疫情防控和经济社会发展各项工作，“六稳”“六保”任务落实成效进一步显现，经济运行稳中有升。主要表现在：工业经济稳步回升、规上服务业增势喜人、消费市场企稳回暖、投资降幅持续收窄。

一、经济运行特点

（一）部分主要经济指标稳居全省前列,增幅位次前移。1-10月，有4个指标增幅居全省前列，其中，规模以上服务业营业收入增幅居全省首位；社会消费品零售总额、规模以上其他营利性服务业和金融机构本外币存款余额增幅居全省第3位。有4个指标增幅位次前移，其中，规模以上其他营利性服务业增长14.8%（居全省第3位，比1-9月前移1位）；财政总收入增长-2.3%（居全省第4位，比1-9月前移1位）；固定资产投资增长-3.9%（居全省第7位，比1-9月前移2位）；工业投资增长10.4%（居全省第4位，比1-9月前移2位）。

（二）工业经济稳步回升。1-10月，全市规模以上工业增加值可比增长1.4%,增幅比1-9月提高0.4个百分点。主要特点：一是新动能持续提升。全市规模以上高技术企业、战略性新兴产业和装备制造业增加值分别增长27.6%、8.0%和11.4%，增幅分别比规模以上工业增加值高26.2个、6.6个和10.0个百分点，分别拉动规模以上工业增加值增长1.8个、1.7个和1.4个百分点。二是民营企业贡献突出。全市规模以上民营工业企业增加值增长2.7%，增幅比规模以上工业增加值高1.3个百分点，拉动规模以上工业增加值增长2.1个百分点。三是新增企业拉动有力。截止10月底，全市2019年以来新投产企业、转规企业共有53家，对规模以上工业增加值的贡献率达254.7%和38.7%，拉动规模以上工业增加值增长3.5个百分点。

（三）规上服务业增势喜人。1-9月，全市规模以上服务业营业收入193.93亿元，同比增长48.5%，增幅比1-8月提高5.4个百分点，高于全省平均水平43.8个百分点，连续6个月居全省首位。其中，规模以上其他营利性服务业营业收入48.68亿元，增长14.8%，增幅比1-8月提高1.2个百分点，高于全省平均水平4.9个百分点，居全省第三位，比1-8月提升1位。主要特点：一是平台企业强力拉动。物泊科技有限公司、瑞智无忧（福建）科技有限公司、莆田云智薪共享经济信息咨询有限公司、莆田即富信息技术服务有限公司等平台企业增势良好，拉动规模以上服务业营业收入增长47.5个百分点。二是互联网服务、软件和信息技术服务业止降回升。在疫情防控常态化后互联网服务、软件和信息技术服务业企业经营情况好转，负增长面缩小，1-9月营业收入增长4.2%，增幅比1-6月提高15.1个百分点。

（四）消费市场企稳回暖。1-10月，全市社会消费品零售总额完成1326.70亿元，同比下降1.0%，好于全省平均水平1.1个百分点。主要特点：一是网上零售持续增加。全市限额以上批发和零售业网上零售额完成208.24亿元，增长18.1%，增幅高于社会消费品零售总额19.1个百分点，占社会消费品零售总额的15.7%。二是汽车消费支撑明显。全市限额以上新能源汽车类商品零售额-增长65.3%，拉动限额以上消费品零售额增长0.7个百分点。三是消费结构优化升级。消费升级类商品中占比较大的限额以上服装类和文化办公用品类分别完成28.61亿元和3.02亿元，分别增长44.9%和20.5%，分别占全市限额以上零售额的6.7%和0.7%。

（五）投资降幅持续收窄。1-10月，全市固定资产投资同比下降3.9%，降幅比1-9月份收窄0.1个百分点，呈持续收窄态势。主要特点：一是工业投资快速增长。全市工业投资增长10.4%，增幅比1-9月提高7.3个百分点，高于全省平均水平5.9个百分点，居全省第四位。其中，制造业同比增长4.8%，比1-9月份提升7.8个百分点；电力、热力、燃气及水的生产供应业同比增长53.6%，比1-9月份提升4.0个百分点。二是房地产投资降幅收窄。全市房地产开发投资下降10.0%，降幅比1-9月收窄1. 9个百分点，主要得益于建工木兰府、绿地朝晖等5个项目土地购置费的拉动。三是社会领域投资持续增长。全市社会领域投资增长15.4%，增幅比1-9月提高1.7个百分点，其中：教育业投资增长13.1%；卫生和社会工作投资增长21.1%。

（六）财政收入持续好转。1-10月，全市财政总收入192.83亿元，同比下降2.3%，降幅比1-9月收窄1.9个百分点。其中，地方财政收入120.69亿元，下降2.5%，降幅比1-9月收窄2.1个百分点。

 二、存在问题

（一）工业回升基础仍不牢固。一是经济效益有待提高。1-9月，全市规模以上工业共有75家亏损企业，增长50.0%；应收账款242.25亿元，增长24.3%；利润总额146.12亿元，下降2.3%；工业企业应收账款平均回收期加长，应收账款平均回收期12.0天，较上年同期增加2.2天。二是部分行业不景气。1-10月，受国外疫情、国际贸易壁垒以及市场持续低迷等因素影响，全市两大主导产业的工艺美术产业和制鞋产业增加值分别下降1.5%和0.8%，分别低于规模以上工业增加值增速2.9个和2.2个百分点。

（二）服务业部分行业复苏缓慢。一是规上文化、体育和娱乐业持续负增长。受新冠肺炎疫情冲击影响仍在继续，1-9月营业收入下降33.5%，连续八个月呈负增长态势，转正压力较大。二是规上科学研究和技术服务业增速持续回落。受企业规模小，单位数少，缺乏大企业拉动等因素影响，1-9月营业收入仅增长5.3%，增幅分别比1-7月和1-8月回落7.0和5.1个百分点。三是规上教育行业低位增长。受疫情影响较大，教育培训机构大规模停课，部分企业目前仍处于停业状态，1-9月营业收入仅增长1.5%，仍处于恢复性低位增长。

（三）住宿餐饮业仍是负增长。受疫情持续影响和部分地方改造拆迁影响，1-10月，全市限额以上住宿业营业额降幅虽较1-9月收窄3.7个百分点，但仍下降6.9%；限额以上餐饮业营业额降幅虽较1-9月收窄2.0个百分点，但仍下降2.4%。

（四）投资增长动力仍显不足。一是基础设施投资亟待加强。全市基础设施投资同比下降7.6%，降幅同比扩大0.5个百分点。其中，水利、环境和公共设施管理业由上年同期的增长10.1%转为下降6.1%。二是民间投资下滑明显。全市民间投资由上年同期的增长6.2%转为下降14.1%，增速比全省平均水平低17.5个百分点；占固定资产投资比重为56.8%，比上年同期低6.8个百分点。

三、对策建议

（一）转型升级推动工业发展。一是加强对制鞋、工艺美术等主导产业的动态监测，加大对企业政策帮扶力度，疏通工业供需不畅的“堵点”，重点加大消费品生产行业供给侧结构性改革力度。二是紧围绕制造业高质量发展，鼓励有条件的传统企业加大投资力度，对现有设备进行以信息化、自动化、智能化、供应链管理为重点的技术改造，强化核心基础零部件、关键基础材料、先进基础工艺、产业技术基础建设，实现流程创新、产品创新和模式转变，逐步以更多符合市场需要的高附加值产品来取代传统的落后产品，不断提高市场竞争力。

（二）政策引导促进行业复苏。一是促进消费，用好用活消费券、购置补贴等政策，激活消费需求，特别是交通运输、旅游、文化、体育和娱乐业等生活性服务业领域补助，以点带面推进服务业复苏。二是靠前服务，深入企业做好各类优惠政策宣传和解答，解决企业现实困难和诉求，尽快帮助企业恢复正常生产经营，尽力帮助企业减负，落实社会保险费用减免、房租减免及临时性补贴等扶持政策，加强企业短期金融输血。

（三）补齐短板促进市场回暖。一是加大对受疫情持续影响较大的住宿和餐饮业的扶持力度，积极落实省、市出台的各项惠企政策，引导实物消费和服务消费健康协调发展。二是鼓励、引导企业转变经营模式，加快从传统的线下消费模式转型为“线上下单+无接触配送”模式，降低对线下管理、营销等传统模式的依赖，提升企业市场竞争力。

（四）狠抓项目增强投资后劲。一是抓住入冬前的项目建设黄金期，全力推进新开工以及在建项目的建设进度。同时借助“十四五”规划编制机会，积极争取一批稳定生产体系、保障基本民生的重要项目，提前谋划，做好项目储备。二是进一步降低民间投资进入门槛，放开民间投资领域，支持民营企业参与基础设施、公用事业、公共服务等领域投资运营，建立向民营企业推介项目长效机制等，激发民间资本投资意愿；进一步落实助企纾困政策，拓宽企业融资渠道，降低企业融资门槛和成本，推动民间投资良性发展。
