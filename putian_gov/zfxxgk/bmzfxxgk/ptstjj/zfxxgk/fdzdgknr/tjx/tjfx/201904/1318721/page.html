2019年一季度莆田市工业景气调查分析

第二十二期
发布时间：2019-04-22 08:36
| | |

一季度，莆田市坚持新发展理念，坚持稳中求进，以供给侧结构性改革为主，全力推动高质量发展，新动能加快培育，全市规模以上工业经济呈现稳中趋缓发展态势。在对全市351家规模以上工业企业的景气调查显示：一季度企业家信心指数和工业企业景气指数分别为130.7和130.8，分别比上季度提高4.2和4.9个百分点，两项指数仍处于较为景气区间之内，随着企业订单回暖、生产能力利用率提升、减税降费等有利因素的不断释放，企业对下期经营状况持较为乐观态度。

一、主要特点

（一）企业判断工业经济基本面向好。从对行业的判断来看，持肯定态度的企业超九成。一季度，九成以上（96.6%）的企业对“本季度本行业总体运行状况”持肯定态度，较上季度提高0.2个百分点。对“下季度本行业总体运行状况”持肯定态度的企业占97.2%，较上季度提高2.7个百分点。从对企业自身的判断来看——企业基本面向好，增长动力继续巩固。对“本季度企业综合经营状况”持肯定态度的企业占96.6%，较上季度下降0.1个百分点。对“下季度企业综合经营状况”持肯定态度的企业占97.2%，较上季度提高3.0个百分点。

（二）产品订单稳定增长。调查结果显示，一季度企业接到的产品订货量比上季度增加或持平的企业占90.9%，比上季度提高1.9个百分点。其中，接到的产品订货量比上季度增加的企业占6.0%，比上季度提高1.6个百分点。

（三）企业生产能力利用率明显提升。调查结果显示，一季度被调查企业生产能力利用率比上季度提高或不变的企业占90.3%，比上季度提高1.1个百分点。其中生产能力利用率比上季度提高的企业占44.2%，比上季度提高29.6个百分点。

（四）投资意愿略有增加，“设备升级改造”成为主要投资方向。一季度，13.4%的企业反映“本季度企业有投资”，较上季度提高了0.7个百分点。从投资的方向看，“设备升级改造”是投资的首要方向，占59.6%，由此可见，随着新旧动能转换的不断加快，企业为提高竞争力，需要逐步淘汰落后设备，因此不断加强对设备升级改造。其次企业投资方向是“扩大生产规模”和“新产品开发”，分别占53.2%和42.6%。

（五）企业用工需求小幅增加。调查结果显示，本季度用工需求比上季度增加或基本持平的企业占94.0%，比上季度提高1.2个百分点。其中，本季度用工需求比上季度增加的企业占16.2%，比上季度提高6.0个百分点。

（六）相关惠企政策显成效。中央、省委省政府和市委市政府出台了一系列稳增长、调结构、降成本等惠企政策措施显成效。调查结果显示，73.8%的企业认为简政放权政策显成效，比上季度提高5.9个百分点；71.2%的企业认为创新支持政策显成效，比上季度提高3.2个百分点；82.0%的企业认为减税降费政策显成效，比上季度提高11.0个百分点；66.4的企业认为降低融资成本政策显成效，比上季度提高5.7个百分点；64.6%的企业认为化解过剩产能政策显成效，比上季度提高4.4个百分点；58.4%的企业认为“一带一路”建设政策显成效，比上季度下降0.2个百分点；60.4%的企业认为促进外贸增长政策显成效，比上季度提高4.0个百分点。

二、主要问题

（一）销售量减少和用工成本上升是导致企业盈利减少的主要原因。调查结果显示，本季度有14.8%的企业认为本季度盈利比上季度减少，比上季度提高4.0个百分点，主要是因为销售量减少和用工成本上升，分别占65.4%和42.3%。

（二）资金压力仍然较大。调查结果显示，本季度仍有15.1%的企业认为流动资金周转紧张，比上季度下降2.9个百分点，但资金充裕的企业只占1.1%，比上季度下降0.3个百分点。有14.7%的企业认为企业生产能力没有充分发挥的主要原因是“资金紧张”。86.6%的企业没有投资，其中有34.9%的企业认为主要原因是“资金不足”。14.3%的企业认为融资困难，反映融资较困难的主要原因是银行贷款门槛过高、手续繁杂、条件苛刻，占78.0%。

（三）企业产成品库存和综合生产成本增加。调查结果显示，本季度企业产成品库存比上季度增加的企业占8.3%，比上季度提高1.9个百分点，其中季节性备货是企业产成品库存增加的主要原因占58.6%。本季度企业综合生产成本比上季度增加的企业占16.5%，比上季度提高4.1个百分点，其中原材料成本和用工成本是企业面临的主要成本压力，两者共占70.6%。

三、对策建议

（一）加大装备投入，降低成本。一方面要积极通过推进转型升级减少对劳动力的需求量；另一方面加大装备投入，提高生产劳动率。企业要加大技术改造力度，提高工艺装备水平，特别是劳动密集型企业的流水线生产要逐步引进和推广机械手，或者机器人操作，提高劳动生产率，降低成本，增加盈利。

（二）加大金融服务实体经济的力度。积极争取政府和金融机构的资金支持，增强融资渠道，满足生产经营所需资金；加快产品创新与业务拓展，提供专项融资服务，着力帮助企业解决发展所需资金；加大融资担保力度，鼓励银行对市场前景好、成长性好但暂时有困难的企业不断贷、不抽贷，降低融资中间环节费用；有效引导民间投资，激发民间投资活力，提振民间投资预期，加快民间投资结构优化进程。确保企业融资渠道宽，贷款效率高，融资难度和成本降低。

（三）进一步减轻企业负担。要积极采取有效措施，全面落实减税降费和各项涉企收费政策，积极推进收费管理制度改革，狠抓涉企收费清理规范，降低企业运行成本，为企业发展创造良好环境。
