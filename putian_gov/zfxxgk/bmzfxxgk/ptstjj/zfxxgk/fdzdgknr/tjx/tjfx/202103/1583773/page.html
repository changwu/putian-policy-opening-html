2021年1-2月莆田市规模以上工业恢复性快速增长

第十四期
发布时间：2021-03-22 14:43
| | |

今年以来，全市上下大力实施“强产业、兴城市”双轮驱动，全方位推动高质量发展超越，紧盯稳产复工，打好“防疫+复产复工”组合拳，督促全市工业企业一手抓防疫，一手抓生产，确保工业企业春节期间有序生产，确保节后工业企业快速复工复产。1-2月份全市工业经济呈现恢复性快速增长态势，为“十四五”开局之年的工业经济迎来良好开端。

一、工业生产增长加快

1-2月，全市规模以上工业增加值增长20.6 %，较2019年1-2月增长8.4%。

从县区看，城厢区工业增加值增长22.6%，涵江区工业增加值增长23.2%，荔城区工业增加值增长15.0%，秀屿区工业增加值增长21.0%，仙游县工业增加值增长21.0%，北岸工业增加值增长24.0%。

从三大门类看，采矿业增加值增长71.2%，制造业增加值增长20.2%，电力、燃气、水的生产和供应业增加值增长27.7%。

从经济类型看，国有企业工业增加值下降25.9%，集体企业工业增加值增长15.5%，股份合作企业工业增加值下降3.0%，股份制企业工业增加值增长21.1%，外商及港澳台商投资企业工业增加值增长19.9%，其他经济类型企业工业增加值增长5.9%。

二、主要运行特点

（一）重点行业支撑有力。1-2月，全市制鞋业、电子信息和工艺美术行业都呈快速增长的态势。其中，受“就地过年”、《莆田市人民政府关于印发加快鞋业高质量发展十条措施的通知》等政府惠企政策助力和外贸订单加速恢复，皮革、毛皮、羽毛及其制品和制鞋业增长12.3%，拉动全市规模以上工业增加值增长3.4个百分点。计算机、通信和其他电子设备制造业增长30.1%，增速比全市规模以上工业平均增速高9.5个百分点，拉动全市规模以上工业增加值增长2.2个百分点。文教、工美、体育和娱乐用品制造业增长19.4%，拉动全市规模以上工业增加值增长1.9个百分点，呈恢复性增长，得益于政府惠企政策的落实，线上线下齐发力。

（二）大中型企业贡献突出。1-2月，230家规模以上大中型企业增长19.8%，对规模以上工业经济增长的贡献率为53.5%，拉动规模以上工业增加值增长11.0个百分点。

（三）新增工业企业拉动明显。1-2月，全市新增工业企业共拉动规模以上工业增加值增长2.4个百分点。其中，2020年以来新投产企业对规模以上工业增加值的贡献率为6.6%，拉动规模以上工业增加值增长1.4个百分点。2020年年底转规企业对规模以上工业增加值的贡献率为4.8%，拉动规模以上工业增加值增长1.0个百分点。

 三、存在问题

（一）停、减产企业影响明显。2月末，全市停、减产面达22.8%，共拉低规模以上工业增加值8.2个百分点。其中停产企业109家，拉低规模以上工业增加值5.3个百分点；减产企业148家，拉低规模以上工业增加值2.9个百分点。

（二）工业增长后劲不足。一是新投产纳统工业企业数偏少。2020年月度新投产入库工业企业数仅4家，为近五年来最少。二是规上企业数减少。2月末，全市规上企业数1125家，较上年同期减少35家。
