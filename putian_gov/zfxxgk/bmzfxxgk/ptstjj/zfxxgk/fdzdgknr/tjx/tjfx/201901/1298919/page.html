产业结构持续优化 助推经济平稳运行

第八期
发布时间：2019-01-25 08:23
| | |

2018年，全市坚持稳中求进工作总基调，落实发展新理念，积极推进供给侧结构性改革，加快新旧动能转换，推动产业转型升级。经济保持了总体平稳、稳中向好的发展态势。据初步核算，2018年，全市实现生产总值2242.41亿元，增长8.3%，增幅位居全省设区市第四位，与全省平均水平持平。三次产业结构由2017年的5.5：53.1：41.4调整为2018年的5.2：52.6：42.2。

一、三次产业呈现“稳升快”态势

（一）第一产业平稳增长

第一产业增加值116.27亿元，增长2.4%，对经济增长的贡献率为1.5%，拉动GDP增长0.1个百分点。从内部行业看，一是农业增长回升。农业增加值30.84亿元，增长5.1%，同比提高0.7个百分点。二是林业增长加快。林业增加值3.58亿元，增长14.5%，同比提高9.0个百分点。三是牧业增长回落。牧业增加值14.12亿元，下降6.4%，同比回落4.6个百分点。四是渔业占主导地位。渔业增加值67.73亿元，增长3.6%，同比回落10.0个百分点。

（二）第二产业持续上升

第二产业增加值1179.91亿元，增长8.5%，同比提高1.1个百分点；对经济增长的贡献率为59.4%，拉动GDP增长4.9个百分点。从行业发展看，一是工业生产持续回升。全市工业增加值实现934.96亿元，增长8.9%，同比提高1.2个百分点；增速分别比一季度、上半年和前三季度分别提高1.2、0.3和0.1个百分点。二是建筑业有所回升。全市建筑业增加值250.79亿元，增长6.8%，同比提高0.6个百分点。

（三）第三产业发展较快

第三产业增加值946.23亿元，增长8.6%，增幅位居全省设区市第五位，快于GDP增速0.3个百分点，快于二产增速0.1个百分点，在三次产业中发展速度最快；对经济增长的贡献率为39.1%，拉动GDP增长3.3个百分点。从服务业内部看，交通运输、仓储及邮政业、批发和零售、住宿和餐饮等三个传统行业平稳增长，实现增加值255.25亿元，增长4.5%，占全市生产总值的比重为11.4%；金融业增速回落，金融业实现增加值118.69亿元， 下降1.3%，占全市生产总值的比重为5.3%；房地产增长平缓，房地产业实现增加值168.57亿元，增长4.3%，占全市生产总值的比重为7.5%；营利性服务业发展迅速，营利性服务业实现增加值277.50亿元， 增长24.8%，占全市生产总值的比重为12.4%。

二、经济运行呈现“进优好”特点

（一）从供给侧看，产业转型稳步推进

结构趋优新兴服务业快速发展。一是三产占比稳步提升。2018年全市三次产业结构为5.2：52.6：42.2，三产占比较上年提高0.8个百分点。二是新兴服务业增势较快。2018年全市软件和信息技术服务业等营利性服务业增加值增长24.8%，高于服务业增加值平均增速16.2个百分点。三是高耗能行业增速持续回落。2018年，高耗能企业工业增加值增长13.6%，分别低于1-9月、1-6月3.0个和2.0个百分点。

供给侧结构性改革成效初显。2018年，全市商品房屋待售面积155.55万平方米，下降9.6%。2018年1-11月，全市规模以上工业企业资产负债率为53.7%，同比下降2.4个百分点；工业经济效益综合指数332.15%，同比提高15.94个百分点。2018年，全市生态保护和环境治理业投资同比增长5.6倍，全市科教文卫领域投资同比增长58.5%；“三去一降一补”初见端倪。

（二）从需求侧看，需求结构不断优化

投资结构优化。2018年，全市第一产业投资增长47.3%；第二产业投资增长0.1%；第三产业投资增长17.7%。三次产业投资结构由上年的0.9：30.3：68.8调整为今年的1.1：27.0：71.9，第一产业投资比重上升0.2个百分点，第二产业下降3.3个百分点，第三产业提高3.1个百分点，投资结构有所优化。

消费结构升级。居民基本生活类商品消费稳步增长。全市限额以上粮油食品类商品零售额增长19.9%，增幅同比提高3.4个百分点。限额以上单位品质类商品热销。化妆品类商品增长120.2%，中西药品类增长74.4%，通讯器材类增长42.9%，书报杂志类增长50.1%。家装类消费活跃。全市限额以上单位实现家具类商品零售额增长18.3%。

出口平稳增长。2018年全市进出口总额370.7亿元，增长0.9%。其中出口224.4亿元，增长8.0%，占进出口总额的60.5%，进口146.3亿人民币，下降8.4%,实现贸易顺差78.1亿元。一般贸易出口266068万美元，占全市出口78.1%，增长14.2%；加工贸易出口74578万美元，占全市出口21.9%，增长2.0%。

（三）从运行质效看，经济运行保障较好

部分先行指标回升转好。一是工业用电量、增值税等指标向好。2018年全市工业用电量83.90亿千瓦时，增长21.2%；全市增值税收入37.53亿元，增长18.5%，高出财政收入11.5个百分点。二是金融机构存贷款稳定增加。2018年末全市金融机构人民币存贷款余额3633.40亿元，较年初增加5.96亿元；全市银行业不良贷款率2.65%，较年初下降0.83个百分点。

财税收支平稳见好。2018年全市一般公共预算总收入完成225.91亿元，增长7.0%；一般公共预算支出229.27亿元，增长0.5%，全市一般公用等“八项”支出175.47亿元，增长2.7%。

三、经济增长中需关注的问题

（一）从核算角度看，部分指标的回落对GDP增速影响较大

2018年，财政一般公共服务等八项支出增长2.7%，同比回落14.8个百分点；人民币存贷款余额增长3.4%，同比回落2.7个百分点；限上其他营利性服务业营业收入增长25.1%，同比回落35.9个百分点。经测算，以上几个因素将影响GDP增速同比回落1.5个百分点。

（二）工业下行压力有所加大，减停产企业占三成

12月末，全市停、减产面达30.1%，为近年来的新高，共拉低全市工业增加值增幅6.2个百分点。其中停产企业143家，拉低全市工业增加值增幅4.4个百分点；减产企业227家，拉低全市工业增加值增幅1.8个百分点。

（三）投资质量有待提高

2018年，全市工业投资469.89亿元，下降0.8%，同比回落13.1个百分点；其中电力、热力的生产和供应业投资79.38亿元，下降35.7%，同比回落16.6个百分点。

四、经济发展若干建议

（一）巩固第一产业，加快现代农业优质发展。重点扶持农业示范基地和特色产业，增强种植、养殖和加工的一体化，培植壮大农业龙头企业。推行农业清洁生产，完善农产品质量追溯体系。依托优势企业，加强区域品牌建设，打造放心莆田农产品品牌。

（二）调整第二产业，谋划现代工业创新发展。抓住国家振兴装备制造业和国际制造业转移的有利时机，按照高端化、品牌化、智能化、国际化和服务化发展方向，依托莆田现有制造业的基础，用先进适用技术和高新技术改造提升传统制造业，积极发展高端制造业，打造临港莆田装备制造新基地。

（三）融合二、三产业，推进现代服务业高端发展。要以科技创新为动力，加大科技研发力度和科技成果的使用和推广，培育新经济增长点。拓展互联网服务新业态，大力推进电子商务发展，推进网络经济更快更好发展。优化全域旅游圈，整合提升市内旅游资源。推动医养结合，鼓励兴办健康养生产业，打造颐养莆田休闲健康服务品牌。
