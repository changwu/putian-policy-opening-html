承压前行 总体稳定——上半年莆田市经济运行分析

第三十七期
发布时间：2022-07-19 15:20
| | |

今年以来，面对严峻复杂的国内外环境，莆田市坚持以习近平新时代中国特色社会主义思想为指导，科学统筹疫情防控和经济社会发展，出台实施一系列稳经济政策措施，全市经济大盘基本稳定。但受多重超预期因素影响，主要经济指标增长速度呈现回落态势，经济下行压力依然较大。

一、经济基本面总体稳定

（一）全市经济承压前行。受国际环境复杂严峻、国内疫情冲击等超预期因素以及连续多年高增长所带来的高基数影响，今年经济增长压力加大。在高效统筹疫情防控和经济社会发展等各项政策措施的支持下， 全市经济顶住压力承压前行，经济发展质量有所提高。上半年，全市GDP完成1555.12亿元，同比增长2.6%，高于全国平均水平0.1个百分点。其中，第一产业增加值74.56亿元，增长5.1%，拉动全市经济增长0.2个百分点；第二产业增加值802.25亿元，增长2.9%，拉动全市经济增长1.5个百分点；第三产业增加值678.31亿元，增长1.9%，拉动全市经济增长0.9个百分点。第三产业投资占固定资产的比重为68.8%，同比提高1.0个百分点； 限上批发零售业企业网上零售额增长5.4%，增幅高于全市限上零售额1.7个百分点；1-5月规上信息传输、软件和信息技术服务业增长17.4%，增幅比规上服务业平均水平高19.2个百分点 。

（二）先行指标协调增长。用电方面，上半年全社会用电量（扣除抽水蓄能）增长2.5%，增幅居全省第4位，比1-5月前移一位；工业用电量（扣除抽水蓄能）增长2.8%，增幅居全省第4位，比1-5月前移一位。税收方面，全市税收收入（剔除留抵退税）增长0.9%，增幅比1-5月提高5.5个百分点，居全省第3位；增值税（剔除留抵退税）增长7.8%，增幅比1-5月提高9.7个百分点。交通方面，全市水路运输总周转量增长17.3%，增幅比1-5月提高1.7个百分点; 公路运输总周转量下降5.3%，降幅比1-5月收窄0.9个百分点。

（三）要素保障较为有力。财政方面，上半年，全市一般公共预算总收入131.41亿元，同比增长4.1%，居全省第6位。其中，地方一般公共预算收入91.18亿元，增长8.2%；一般公共预算支出132.00亿元，增长0.5%。其中，科学技术支出增长35.1%，住房保障支出增长33.1%，农林水支出增长25.3%。金融方面，6月末，全市金融机构本外币各项存贷款余额5488.41亿元，同比增长11.5%，其中，本外币各项存款余额2877.02亿元，同比增长12.5%,增幅居全省第3位；本外币各项贷款余额2611.39亿元，同比增长10.5%。

（四）民生就业持续改善。就业形势总体稳定，上半年全市城镇累计新增就业人数1.13万人，同比增长5.5%；城镇失业人员再就业1450人。居民收入稳步增加，城乡居民收入差距缩小。全市居民人均可支配收入20065元，同比增长5.9%。按常住地分，城镇居民人均可支配收入25205元， 增长5.1%；农村居民人均可支配收入14061元，增长7.4%。城乡居民人均收入比值1.79，比上年同期缩小0.04。消费价格温和上涨，上半年市区居民消费价格同比上涨0.8%，比一季度提高0.8个百分点。

二、重点领域运行特点

（一）农业生产基本稳定。上半年，全市农林牧渔业总产值135.45亿元，可比增长4.8%，增幅同比提高1.8个百分点，比一季度回落0.7个百分点。分行业看，农业产值21.86亿元，增长3.2%；林业产值1.28亿元，增长10.3%；牧业产值17.32亿元，增长4.1%；渔业产值84.30亿元，增长5.4%。主要特点：一是农业生产保持平稳增长。蔬菜播种面积、单产双提高，全市蔬菜产量增长2.8%，播种面积增长2.5%，单产提高0.3%；食用菌产量增长0.5%，增幅同比提高2.1个百分点；茶叶产量增长4.0%；园林水果产量增长3.8%，其中枇杷增长4.4%。二是林产品产量增幅较快。全市木材产量7.54万立方米，增长18.3%。三是畜牧业生产平稳增长。全市肉蛋奶总产量增长2.4%，肉类产量增长3.1%；全市生猪期末存栏36.05万头，增长6.3%，出栏28.76万头，增长7.2%。四是水产品总产量较快增长。全市水产品总产量增长5.4%。

（二）工业生产领域放缓。上半年，全市规模以上工业增加值同比增长2.5%，增幅比1-5月回落4.7个百分点。33个行业大类中有18个行业增加值实现正增长，增长面为54.5%。主要特点：一是龙头企业拉动有力。规上亿元及以上工业企业实现工业增加值增长14.9%，增幅高于规上工业平均水平12.4个百分点，拉动规上工业增加值增长6.8个百分点。二是民营企业贡献突出。全市规上民营工业企业实现工业增加值增长4.3%，增幅高于规上工业平均水平1.8个百分点，拉动规上工业增加值增长2.8个百分点。三是新型功能材料产业快速发展。全市规上新型功能材料产业实现工业增加值增长21.6%，增幅高于规上工业平均水平19.1个百分点，拉动规上工业增加值增长1.6个百分点。

（三）建筑业生产稳步发展。上半年，全市建筑业总产值444.88亿元，同比增长7.5%。主要特点：一是大型企业增长强劲。中交建宏峰、涵城建设、凡士建设、亿耀（福建）等4家大型企业产值增量共27.00亿元，拉动全市建筑业总产值增长6.5个百分点。二是外拓产值拉动明显。外省建筑产值244.20亿元，增长6.5%，拉动全市建筑业总产值增长3.6个百分点，占全市建筑业总产值比重为54.9%，比一季度提高1.0个百分点。

（四）服务业实现增长。上半年,服务业增加值同比增长1.9％。分行业看，批发和零售业增加值增长4.4%，住宿和餐饮业增加值增长0.5%，金融业增加值增长5.4%，营利性服务业增加值增长2.6%，非营利性服务业增加值增长3.0%。1-5月，全市规上其他营利性服务业企业实现营业收入35.62亿元，同比增长11.7%。生活性服务业持续恢复，规上文化、体育和娱乐业营业收入增长27.1%，增幅高于全省平均水平个29.0百分点；规上居民服务、修理和其他服务业营业收入增长37.5%，增幅高于全省平均水平17.4个百分点。

（五）固定资产投资稳步增长。上半年，全市固定资产投资完成1111.59亿元，同比增长7.2%，增幅比一季度回落8.5个百分点，其中城厢区（17.5%）、北岸管委会（14.0%）、涵江区（13.6%）三个县区增幅高于全市平均水平。主要特点：一是新入库项目支撑有力。上半年新入库项目共708个，同比增加329个，计划总投资1194.12亿元，同比增长152.7%，新入库项目完成投资435.83亿元，同比增长101.6%，投资后劲不断增强。二是基础设施投资快速增长。全市基础设施投资349.40亿元，同比增长20.0%，增幅比全市固定资产投资高12.8个百分点，拉动固定资产投资增长5.6个百分点。其中市政建设投资增长29.5%，水利管理业投资增长188.2%。三是重点项目推进有力。330个市重点项目完成投资471.9亿元，超序时进度5.5个百分点。

（六）消费品市场恢复性增长减缓。上半年，全市社会消费品零售额954.34亿元，同比增长2.4%，增幅比一季度回落6.2个百分点。主要特点：一是石油及制品类商品增势良好。国际油价上涨带动成品油价格上涨，全市限上石油及制品类商品零售额同比增长20.0%，拉动限上消费品零售额增长0.8个百分点。二是新型消费较为活跃。绿色化、智能化、数字化消费不断升级。限上可穿戴智能设备、新能源汽车零售额均保持两位数增长，同比分别增长47.1%和33.0%。三是传统类和部分升级类消费需求持续释放。限上传统鞋帽类、服装类、家具类零售额分别增长18.4%、57.2%和22.5%，共拉动限上消费品零售额增长11.4个百分点；与升级类消费相关的文化办公用品类零售额增长109.0%、中西药品类零售额增长27.2%。

三、存在问题

（一）工业运行存在隐忧。一是行业生产放缓面较大。停产、减产企业439家，占全部规上工业企业的37.7%。与1-5月份相比，上半年有20个行业大类生产放缓，占行业面的60.6%。二是企业经营压力加大。大宗商品和原材料价格高位波动、物流运输成本增加、市场需求减弱、叠加新冠疫情多点散发等因素影响，工业企业经营压力加大，盈利能力承压。工业产销率走低，6月份全市规上工业产销率仅为97.8%，比5月份低0.5个百分点；企业利润连续两个月出现下降，其中1-5月份规上工业利润总额同比下降8.8%。三是小微企业增长后劲不足。上半年，占全市规模以上工业企业数80.2%的小微工业企业增加值下降0.8%，分别低于规上工业平均增速、大中型企业增速3.3个和6.0个百分点，小微工业企业增长下滑是拉低我市工业经济增长的主要因素之一。

（二）建筑业发展后劲不足。上半年，全市资质建筑企业签订合同额增长9.2％，增幅比上年同期回落7.8个百分点。承建的房屋建筑施工面积增长1.0%，增幅同比回落14.7个百分点。41家建筑企业产值为0，占全部企业数的比重为8.5%,市场竞争日趋激烈，本地中小企业综合实力不如外来央企、国企，承揽新项目特别是大型项目的难度不断加大。

（三）房地产销售出现下降。受房地产调控政策及同期高基数影响，叠加市场预期下降、购房者观望情绪加重等因素，直接影响到全市房地产销售市场的热度。上半年，全市商品房销售面积245.33万平方米，同比下降22.1%，比1-5月扩大9.2个百分点。单月销售面积仅29.60万平方米，同比下降56.2%。单月超过1万平方米的仅2个项目。从分县区看，单月超过6万平米的仅荔城区和仙游县。

（四）贸易业复苏压力加大。一是部分龙头批发企业下降影响。上半年点钢、东铭、点增等3家龙头企业同比下降55.3%，拉低限上批发业销售额增长9.9个百分点。二是退库电商企业影响较大。截至6月末，全市限上退库电商企业163家，占限上电商企业的17.6%，拉低全市限上消费品零售额8.0个百分点。三是日用品类零售降幅较大。受电商零售促销力度减弱等因素影响，1-6月限上日用品类零售额下降51.1%，拉低全市限上消费品零售额7.1个百分点。四是汽车类零售低迷。受芯片短缺等影响，全市汽车类销售总体供需不足，上半年实现零售额40.19亿元，下降4.1%。其中，6月份下降24.0%。

（五）规上服务业发展瓶颈尚存。一是入库企业少，退库企业多。去年2月以来，全市新入库其他营利性服务业企业仅33家，退库企业达101家，其中64家退库带基数企业拉低全市其他营利性服务业营业收入增幅13.7个百分点。今年截止目前，全市无月度新增企业。二是其他交通运输业增长乏力。1-5月，全市规上其他交通运输业营业收入仅增3.2%，增速比1-2月回落9.7个百分点，低于全省平均水平21.8个百分点，主要原因是国投湄洲湾港口、八方物流和顺丰速运等重点企业增长乏力。三是商务服务业支撑力不足。1-5月，规上商务服务业营业收入增速比1-2月回落8.1个百分点，瑞智无忧、仙游弹好工、特洛特人力资源等28家负增长企业拉低该行业营业收入增幅10.5个百分点,忠门正泰、大爱妈祖等13家退库企业拉低该行业营业收入增幅9.0个百分点。

（六）工业、房地产投资双下降。上半年，全市工业投资完成305.67亿元，同比下降5.9%，比全省平均水平16.6%低22.5个百分点，位居全省末位。208个在库工业项目平均投资规模比上年同期减少5亿元，库存投资比上年同期下降19.0%。受“三道红线”金融政策监管及经营性用地供应不足影响，全市房地产开发投资同比下降16.4%，降幅比一季度扩大5.0个百分点，拉低全市固定资产投资3.8个百分点。

四、持续加力应对下行压力

（一）落实落细各项稳增长政策。全市上下要认真贯彻全国稳住经济大盘电视电话会议精神，按照省委省政府、市委市政府稳经济促增长工作要求，落实国家和全省、全市一揽子稳经济政策措施，最大限度释放政策红利，大力提振内需，有效改善预期，坚决顶住经济下行压力，确保全市经济稳定恢复、持续向好。一是加快落实既定政策举措并加大实施力度，密切跟踪实施情况，该完善的及时完善，确保政策受益主体不漏户、不漏人和应知尽知、应享尽享。二要及时回应企业的重点关切，以真招实招解决企业面临的困难，守住企业生存底线，提升企业获得感，提振企业信心，增强经济增长后劲。

（二）狠抓工业稳增长。一是抢抓进度建成投产批量工业企业，发挥新增企业的拉动作用。新增企业尤其是“大块头”规模以上企业，对地方工业经济增长具有明显拉动作用。各地认真梳理现有工业企业在建项目，优先保障符合产业转型升级发展方向的大企业，力争年内尽早建成投产、入库统计，有效发挥新建入库企业对工业经济增长拉动效应。二是针对停产、减产企业制定帮扶措施，力促尽快复产扩张；加强对重点企业、行业动态分析和监测，帮助企业做好产销、政银企、用工对接、油电煤气运等要素保障，降低成本、减轻负担，推动工业经济稳定增长。

（三）持续强化投资拉动。一是主动谋划一批大项目。围绕产业发展、脱贫攻坚、城乡建设、社会民生、生态环保等重点方面，谋划一批具有重大影响的大项目、好项目、实项目，调整充实项目库，争取更多项目挤进国家和省的规划盘子，筑牢全市发展的项目基础。二是全力抓好项目施工进度。要坚持问题导向，分类施策，着力解决制约项目推进的堵点、痛点和难点，对症下药出良方，采取现场协调、领导包联、挂牌督办等措施，精准聚焦诉求，主动服务企业，及时解决项目施工过程中存在的问题，帮助企业合理组织施工，加快施工进度。三是加大用工、物流、资金等要素保障力度，推动签约项目加快开工、开工项目加快进度，尽快形成实物工作量。 

（四）激发服务业经济发展潜力。一是加快各类减税退税降费、金融机构让利、点钢等龙头特困行业企业纾困扶持政策的落地落实，实现促消费和稳就业之间的良性互动。二是各地要持续加大消费券发放力度，有效发挥消费券的“杠杆作用”，重点刺激汽车、家电等大宗消费。支持新能源汽车加快发展，扩大二手车流通，鼓励开展绿色智能家电下乡和以旧换新。三是持续做好企业引进培育，切实做好增量企业引进及升规纳统工作，培育“生根型”企业，推动国内领军企业在莆设立独立法人企业，同时持续做好存量企业扶持引导，支持鼓励信息服务、人力资源服务、互联网广告企业成为“本土型”企业。 

（五）因地制宜优化完善房地产政策。针对我市房地产投资、销售全面下行的情况，建议各地强化发改、自然资源、住建等部门之间的协作，因地制宜完善细化房产政策。畅通房地产“销售—拿地—新开工”链条。在销售端探索更大力度的政策，支持刚性和改善性住房需求，如定向降低首付比例和交易契税等。在供地端给予房地产企业更多利润空间，如推出更多优质地块、合理设置起拍价及浮动范围、适度延长土地出让金缴纳时间等,努力遏制房地产市场持续下滑势头。
