1-8月全市消费品市场运行情况分析

第五十七期
发布时间：2022-09-26 17:05
| | |

随着疫情防控常态化推进，“全闽乐购 约惠莆田”促消费活动如期开展，各项稳生产促消费有利措施成效进一步凸显，8月份全市社会消费品零售总额实现疫情后的当月正增长，市场稳定因素增多，回升向好的基础进一步稳固。

一、消费品市场运行特征

1-8月，全市实现社会消费品零售总额1226.12亿元，增长1.7%，增幅比1-7月提升0.2个百分点。其中，8月份增长3.7%，比7月份回升8.5个百分点。

分限额标准，1-8月限上消费品零售额451.51亿元，增长1.5%，增幅比1-7月回升0.3个百分点；限下零售额774.61亿元，增长1.8%。

（一）限上单位网上零售活动企稳回升。全市部分电商企业活动加大促消费力度，1-8月实现网上零售额243.98亿元，占限上消费品零售额的54.0%，增长2.9%，增幅比1-7月回升0.5个百分点。

（二）乡村消费仍较快增长。虽受不稳定因素影响，但今年来乡村市场总体较活跃，1-8月，限上乡村消费26.74亿元，同比增长25.5%，增幅比1-7月回落1.5个百分点。

（三）餐饮消费恢复性增长。随着疫情防控稳固、旅游旺季到来及客流增多，8月份全市限上餐饮消费扭转6月和7月下降态势，实现增长7.0%，1-8月餐饮消费15.56亿元，增长7.0%，增幅比1-7月提升1.1个百分点。

（四）石油类商品零售额保持较快增长态势。在成品油价格拉升下，1-8月限上石油及制品类零售额增长17.3%，拉动限上消费品零售额0.7个百分点。

（五）部分绿色、智能化商品零售较快增长。1-8月，新能源汽车、能效等级为1级和2级的家用电器和音像器材类商品零售额分别增长34.7%和15.3%，可穿戴智能设备和智能家用电器和音像器材零售额分别增长49.2%和21.7%。

二、存在问题

（一）退库企业负面影响大。目前全市限上已退库的贸易累计零售额同比减少52.76亿元，拉低1-8月限上消费品零售额11.9个百分点。

（二）汽车类商品零售仍处于下降通道。虽然8月全市限上汽车消费行情向好，零售额实现增长7.2%，但仍受传统燃油汽车供需不足影响，1-8月，全市限上汽车类下降3.4%，降幅较1-7月收窄6.3个百分点，拉低限上消费品零售额0.4个百分点。
