1-2月莆田市经济加快复苏强劲增长

第十一期
发布时间：2021-03-19 15:45
| | |

今年以来，在市委、市政府的坚强领导下，各县区各部门统筹疫情防控和经济社会发展成效持续显现，投资和财政收入较快增长，工业和消费稳中有进，金融和物价总体稳定，全市经济加快复苏强劲增长。

一、经济运行特点

（一）工业加快恢复。莆田市积极落实“就地过年”、《莆田市人民政府关于印发加快鞋业高质量发展十条措施的通知》等惠企政策，工业企业生产天数比上年同期明显增加。同时，受国外疫情影响，外贸订单回流，仅制鞋业就实现出口交货值54.47亿元，增长21.4%。1-2月，全市规模以上工业增加值可比增长20.6%,增幅高于去年同期30.7个百分点。主要特点：一是重点行业支撑明显。全市规模以上皮革、毛皮、羽毛及其制品和制鞋业、计算机、通信和其他电子设备制造业以及文教、工美、体育和娱乐用品制造业增加值分别增长12.3%、30.1%和19.4%，分别拉动全市规模以上工业增加值增长3.4个、2.2个和1.9个百分点。二是大中型企业贡献突出。1-2月，230家规模以上大中型工业企业增加值增长19.8%，对全市规模以上工业增加值的贡献率达53.5%，拉动全市规模以上工业增加值增长11.0个百分点。

（二）消费市场火爆。莆田市主管部门积极引导企业在电商平台、直播平台上展示莆田好鞋、莆田好物等区域特色产品，鞋服、食品、家居、工艺美术、金银珠宝等29家代表企业、67款产品集中入驻福建商务一键通“福建日销品”专区展示展销，电商企业积极参与年货节等促销活动都有效激发了消费市场需求。1-2月，全市社会消费品零售总额完成307.79亿元，同比增长22.8%，增幅高于去年同期28.4个百分点。主要特点：一是网上零售火热。全市限额以上网上零售额完成45.58亿元，增长24.1%，增幅高于社会消费品零售总额1.3个百分点，占社会消费品零售总额的14.8%。二是餐饮企业回暖。全市限额以上餐饮业营业收入增长89.8%，增幅高于去年同期126.8个百分点，主要是餐饮企业积极参与“全闽乐购”促消费行动，在做好疫情防控基础上结合春节契机积极开展优惠活动吸引客户，加上今年出台的就地过年优惠政策也一定程度上促进了餐饮业的回暖。

    （三）投资增势喜人。春节期间莆田市出台了《关于鼓励春节期间省市重点项目不停工、早复工的通知》（莆发改〔2021〕26号），分三类对省市重点项目进行不停工、早复工进行奖励，有效保障了投资项目建设进度。1-2月，全市固定资产投资（不含农户）同比增长45.0%，增幅高于去年同期78.5个百分点。主要特点：一是投资结构持续优化。全市三次产业投资结构由2020年的1.3：37.3：61.4调整为1.1：24.9：74.0，第三产业投资提高12.6个百分点。特别是高技术产业投资同比增长65.6%。二是房地产投资拉动有力。全市房地产开发投资增长131.3%，增幅高于去年同期175.3个百分点，拉动全市固定资产投资增长22.9个百分点。商品房销售面积完成71.81万平方米，增长153.1%，增幅高于去年同期204.8个百分点。三是社会领域投资较快增长。全市社会领域投资增长88.5%，增幅高于固定资产投资43.5个百分点。其中教育业投资增长205.2%，卫生和社会工作投资增长50.9%，文化、体育和娱乐业投资增长60.7%。四是民间投资稳步恢复。全市民间投资增长18.8%，一举扭转2020年以来持续的负增长态势，实现了恢复性增长。其中：基础设施民间投资增长46.7%，教育民间投资增长68.5%，房地产开发民间投资增长122.1%。

（四）财政收入快速增长。1-2月，全市财政总收入完成52.14亿元，同比增长28.1%，增幅高于去年同期38.2个百分点。其中，地方级财政收入完成30.87亿元，增长26.4%，增幅高于去年同期42.5个百分点。财政支出完成43.49亿元，增长14.4%，增幅高于去年同期17.6个百分点。

（五）实际利用外资稳步增长。1-2月，全市实际利用外资（验资口径）完成0.90亿元，同比增长12.5%，增幅高于去年同期7.7个百分点。

（六）金融和物价总体稳定。2月末，全市金融机构本外币存款余额2433.23亿元，同比增长13.9%；金融机构本外币贷款余额2262.19亿元，同比增长11.4%。1-2月，市区居民消费价格总水平同比上涨0.2%，涨幅比去年同期回落3.5个百分点。

二、存在问题

（一）工业持续增长动力仍需强化。一是停、减产企业影响较大。2月末，全市停、减产企业有257家，停减产面达22.8%，影响规模以上工业增加值增长8.2个百分点。二是新投产企业偏少。截止2月底，全市月度新投产入库工业企业数仅4家，为近五年来最少，现有的规上企业数比上年同期减少35家。

（二）限上批零业增长后劲仍待加强。一是退库企业较多。受外部经济环境影响，2月末，全市有113家限额以上批零企业退库，退库企业零售额基数达3.37亿元，影响全市限上消费品零售额增长4.6个百分点。二是零售额下降企业影响较大。全市1882家限上批零企业中有286家零售额比去年同期下降，影响全市限上消费品零售额增长12.0个百分点。

（三）部分行业投资恢复较为缓慢。一是工业投资负增长。虽然疫情得到了有效控制，但外部环境还比较严峻，企业投资能力和投资信息的恢复尚待时日，导致工业投资恢复势头比较缓慢。全市工业投资下降3.4%，其中，纺织业投资下降99.1%，化学纤维制造业投资下降31.7%，化学原料及化学制品制造业投资下降25.5%。二是亿元新开工项目较少。截止2月底，全市亿元新开工投资项目仅5个，比上年同期减少12个，计划总投资下降71.8%，本年完成投资额下降38.2%。

三、对策建议

（一）政策引导推动工业发展。一是扎实推进纾困政策落地见效，加快兑现面向小微企业减免的房产税、土地使用税、社保费和补贴的利息、电费等，落细落实支持政策，精细指导企业学懂弄通、用好用实政策。二是着力拓宽企业融资渠道，进一步加大金融支持力度，拓展融资渠道，丰富融资方式，降低融资成本，切实帮助企业解决资金紧张问题。

（二）积极培育增强商贸后劲。一是加强部门协作，充分发挥行业管理力量，结合“四经普”成果和部门行政记录对限下商贸企业的全面深入摸排，加大培育发展力度，促进小规模企业加快发展，对达到限额标准的单位按照升规入统条件及时申报入统，以增强消费市场发展后劲。二是进一步加大消费市场主体多元化支柱企业培育，特别是具有莆田特色的金银珠宝、工艺美术品商贸企业发展，以逐步改变全市过度依赖鞋服、汽车、日用品支撑的单一消费支柱结构，切实增强消费市场整体竞争力。

（三）补齐短板促进投资持续增长。一是充分发挥政府对投资的宏观调控和导向作用，引导鼓励工业企业转型发展，加大自主创新、科技进步、节能降耗等方面的投入，引导投资向高新化发展，大力培育发展战略性新兴产业，集中力量推动产业集中集约集聚发展，形成规模优势，提高产业集中度、产业分工层次和整体竞争力。二是加大对投资项目进度的监测，重点关注接下来月份数据的波动情况，避免增速断崖式地回落，保持固投增速的平稳增长，争取做到以月促季，以季带年，为推动全市经济高质量发展超越添动力。
