莆田经济总体平稳——一季度莆田经济运行情况分析

发布时间：2018-04-20 14:51
| | |

今年以来，我市继续以新发展理念为引领，紧抓供给侧改革主线，加快培育新兴产业，改造提升传统产业，经济运行总体平稳，但经济企稳的基础仍不稳固，下行压力较大，需采取有效措施，力促经济持续健康发展。

一、经济运行基本情况

初步核算，1-3月，全市实现地区生产总值573.32亿元，按可比价格计算，增长8.1%，增幅分别比1-2月和上年同期回落0.2和0.3个百分点。其中，第一产业增加值29.25亿元，下降0.3%，增幅同比回落2.3个百分点；第二产业增加值320.11亿元，增长7.5%，增幅同比提高0.6个百分点；第三产业增加值223.96亿元，增长10.3%，增幅虽同比回落1.6个百分点，但高出GDP2.2个百分点。

（一）主要经济指标增幅排位情况

1-3月，我市经济运行总体平稳。其中，增幅居全省前三位的指标有9个：GDP、第二产业增加值、第三产业增加值、财政支出、出口额、零售业商品销售额、社会消费品零售额、批发业销售额、固定资产投资（不含农户）。但也有部分指标增幅在全省位次靠后，其中，增幅居全省后三位的指标有7个：农林牧渔业增加值、进出口总额、进口额、餐饮业营业额、本外币存款余额、财政总收入、地方财政收入。

（二）传统产业提质增效成效初显

1、制鞋业转型发展显成效。全市围绕稳增长、促转型目标，通过政府搭台、企业抱团、政策引导等措施促进传统优势产业加快转型升级步伐。1-3月，占全市规模以上工业增加值比重达27.3%的制鞋产业增加值增长10.5%，增速快于规模以上工业增加值2.6个百分点；对规模以上工业增加值增长的贡献率为33.0%，拉动全市规模以上工业增加值增长2.6个百分点。

2、纺织服装业拉动显著。1-3月，全市纺织服装业工业增加值增长35.9%，增速快于规模以上工业28.0个百分点；对规模以上工业经济增长的贡献率为24.8%，拉动规模以上工业增加值增长2.0个百分点。主要原因：去年新投产的华锦实业拉动显著以及华耀运动用品和华峰新材料新厂房和设备陆续投用，产能进一步扩大。

（三）经济发展活力增强

1、工业新动能快速成长。1-3月，全市战略性新兴产业增加值增长22.1%，增速高于规模以上工业14.2个百分点，对规模以上工业经济增长的贡献率为34.7%，拉动规模以上工业增加值增长2.7个百分点。高技术工业增加值增长13.4%，增速高于规模以上工业5.5个百分点，对规模以上工业经济增长的贡献率为9.7%，拉动规模以上工业增加值增长0.8个百分点。装备制造业增加值增长7.5%，增速同比提高3.1个百分点，对规模以上工业经济增长的贡献率为12.4%，拉动规模以上工业增加值增长1.0个百分点。

2、工业企业景气指数回升处于“较为景气”区间。据一季度工业企业景气调查结果显示，企业景气指数为128.1，比上年四季度高4.4个点，持续处于“较为景气”区间。其中，反映企业当前景气状态的即期企业景气指数为128.9，比上年四季度高2.7点；反映企业未来景气预判的预期企业景气指数为127.6，比上年四季度高5.5点。一季度企业家信心指数为129.0，比上年四季度高2.2点，企业家对后期经济运行谨慎“乐观”。

3、民间投资主导作用增强。1-3月，全市民间投资增长53.1%，增幅同比提高34.3个百分点；占固定资产投资的比重为68.0%，同比提高15.9个百分点；对固定资产投资的贡献率高达159.5%，同比提高111.4个百分点，拉动固定资产投资增长27.8个百分点，是投资保持平稳较快增长的主要动力。

4、短板领域投资增势强劲。今年以来，我市继续加快推进民生工程建设，短板领域投资高速增长。1-3月，全市固定资产投资中，居民服务和其他服务业投资增长5.5倍，文化、体育和娱乐业投资增长6.8倍，教育事业投资增长2.4倍，卫生和社会工作投资增长53.6%，水利、环境和公共设施管理业投资增长52.3%。

二、存在的主要问题

（一）农业生产增幅回落

1-3月，全市农林牧渔业总产值54.10亿元，按可比价计算，比上年增长0.1%，增幅同比回落2.1个百分点。其中：农业产值13.03亿元，增幅由上年同期的增长0.4%转为下降4.5%；林业产值0.37亿元，增幅由上年同期的增长18.4%转为下降6.3%；牧业产值8.07亿元，增幅由上年同期的增长0.1%转为下降9.1%。

1、食用菌生产规模不断萎缩。受人工费用等生产成本不断提高的影响，我市食用菌生产效益不断下降，食用菌生产大户生产规模不断萎缩，食用菌产量逐年下降。1-3月，全市食用菌种植面积下降28.5%；食用菌产量3.17万吨，下降34.8%，降幅同比扩大31.4个百分点。

2、木材采运量大幅下降。1-3月，全市木材采运量下降42.6%，主要是我市森林采伐指标受限及上年同期基数异常偏高等影响所致。

3、生猪家禽出栏负增长。今年以来，全国生猪市场犹如遭遇“滑铁卢”，价格持续下跌。1-3月，全市生猪出栏19.90万头，下降13.1%；肉类总产量2.47万吨，下降12.2%。

　　（二）工业回升基础不稳

1、减停产面扩大。3月末，全市停、减产面达30.8%，比2月末扩大4.5个百分点，共拉低全市工业增加值增幅8.4个百分点。其中：停产企业82家，比2月末增加9家，拉低全市工业增加值增幅5.3个百分点；减产企业294家，比2月末增加46家，拉低全市工业增加值增幅3.1个百分点。

2、企业数减少，“下”转“上”企业拉动乏力。3月末，全市共有规模以上工业企业1220家，同比减少41家。去年年底37家“下”转“上”工业企业对规模以上工业增加值增长的贡献率仅5.7%，拉动规模以上工业增加值增长0.4个百分点。

3、企业去库存、去杠杆、降成本任重道远。1-2月，全市规模以上工业产成品存货增长8.2%，增幅同比提高3.3个百分点；资产负债率54.3%，同比提高0.5个百分点；每百元主营业务收入中的成本86.37元，同比增加0.34元。

（三）服务业增长动力减弱

1、其他营利性服务业增速明显下滑。1-2月，全市规模以上其它营利性服务业营业收入7.99亿元，增长38.0%，增幅比上年全年回落15.6个百分点,直接影响一季度三产增幅1.3个百分点。主要原因：一是互联网和相关服务、软件和信息技术服务业营业收入增速大幅下滑至15.2%，同比回落73.9个百分点，拉低全市其他营利性服务业营业收入增速14.7个百分点，主要是受鸿瑞通信建设有限公司、海丝商品交易中心、闽中互联网产业有限公司和优膳名品信息科技有限公司等企业业务量明显下滑影响。二是全市租赁和商务服务业营业收入增速大幅回落至45.0%，同比回落20.9个百分点，拉低全市其他营利性服务业营业收入增速14.2个百分点，主要是受福建美奂医疗投资管理有限公司和莆田市国有资产投资有限公司营业收入来源不符合国家统计制度要求而被剔除，福建省中电网络科技有限公司和福建省中恒投资有限公司行业变更为金融业而不参与汇总等因素影响。

2、金融业增长持续放缓。3月末，全市金融机构本外币存款余额1865.91亿元，增长3.7%，增速均比上月末和上年同期回落1.2个百分点，居全省第八位；本外币贷款余额1855.24亿元，增长8.2%，增速比上月末回落1.0个百分点，比上年同期回落2.7个百分点，居全省第五位。

3、交通运输、仓储和邮政业增速回落。1-3月，全市水路运输总周转量增长8.7%，增幅比1-2月回落4.5个百分点，低于全省平均水平8.0个百分点，居全省第八位；公路运输总周转量增长7.4%，增幅比1-2月回落4.8个百分点；邮政及快递业务总量增长42.5%，增幅比1-2月回落29.4个百分点。

    （四）投资增长后劲不足

1、项目投资存量不足。3月末，全市5000万以上项目172个，同比减少49个，完成投资同比下降10.4%，降幅持续扩大；5000万以上项目累计已完成投资占计划总投资的77.2%，同比提高7.7个百分点，存量不足，支撑乏力。

2、重点领域投资增长乏力

（1）基础设施投资低位增长。1-3月，全市基础设施投资增长3.0%，增速分别比1-2月和上年同期回落2.9和25.3个百分点，比同期固定资产投资低14.4个百分点。

（2）工业投资增速持续回落。1-3月，全市工业投资增长6.4%，增速分别比1-2月和上年同期回落1.4和26.0个百分点，其中能源类投资中的电力、热力的生产和供应业同比下降50.6%。

　  三、建议

（一）抓工业发展，加快动力转换与提档升级

一是重视品牌培育。充分利用本土各类优特资源开发培育自主品牌、知名品牌，由价格优势向技术优势、创新优势转化，提高企业的核心竞争力和可持续发展能力。二是加快传统制造业提档升级。以新装备、新技术、新工艺为核心的改造工程促进工艺升级、产品升档，以信息技术提高企业的研发能力、生产能力和物流效率增强企业整体技术水平和经济效益。三是全力促进小微企业持续健康发展。完善扶持政策，抓好兑现落实，有效改善中小微企业的发展环境和发展条件。打造“专精特新”企业，设立专项资金，助推企业发展，引导小微企业由重规模扩张向质量提升转变。四是加大扶持力度解决企业技术创新瓶颈制约。多数企业期盼政府在技术创新中给予政策和技术上的支持和指导，应当继续健全“政府-企业-研发中心”的沟通协调机制，利用政府资源平台的优势，为企业技术创新搭建平台。

（二）抓服务业短板，着力增强后劲和层次提升

一是加快发展平台经济。着力推进“互联网+”行动计划，以“数字莆田”建设为依托加快发展平台经济，推动大平台、大市场、大流通融合发展，重点推动大数据、云计算等新技术在健康养老、家政、旅游服务业等我市薄弱行业领域中的应用，打造适宜平台经济发展的法治营商环境，培育一批特色鲜明、竞争力强的平台经济品牌企业，建设一批功能完备、配套完善的平台经济集聚区，转莆田“GNP”为“GDP”。二是积极拓展服务外包领域。依托我市纺织鞋服、电子信息、电子商务等行业优势，重点突破软件外包、设计研发、贸易营销、专业配套、创意设计等领域，培育一批创新能力强、具有国际竞争力的服务外包龙头企业。三是加大服务业新增企业的入库入统工作力度。加强部门联动，做好服务业摸排工作，特别是行业主管部门要加大对43个规模以上其他营利性服务业空白行业的摸底、入库工作力度，确保应统尽统，但不能采取狼群战术，以量致胜，为入而入，会给数据上报质量埋下隐患。

（三）抓数据质量，强化部门合力和基础夯实

一是加强领导，建立常态化协调工作机制。第一产业建议由分管农业的政府领导牵头，农业局具体负责，按季度开展联席工作会议；县区三产办要积极发挥机构职能作用，可参照市三产办做法每月召开联席会议汇报预判各部门指标运行情况、及时协调解决存在的薄弱环节和问题。二是加强部门联动，增强工作合力。各相关部门要强化分工协作，加强对相关指标的跟踪监测，分类施策，有针对性地做好统计业务工作。要注意指标匹配性问题，不仅要主动加强与同级统计部门的沟通联系，也要主动加强与上级对口部门的汇报衔接，避免拖了全市后腿。三是加强统计业务培训，夯实统计基础。要加强对乡镇、企业统计人员和相关职能部门业务人员的业务指导和培训，确保依法应统尽统，全面真实反映我市经济发展水平。同时，各相关职能部门要督促联网直报单位建立健全原始记录、统计台账和各项统计管理制度，完善联网直报工作条件，确保应统必统、统必合规，保证源头数据质量。
