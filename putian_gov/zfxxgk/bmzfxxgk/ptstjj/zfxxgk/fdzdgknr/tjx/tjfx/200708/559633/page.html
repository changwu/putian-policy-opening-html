莆田市2007年上半年规模以上工业企业能源消费情况分析

发布时间：2007-08-05 00:00
| | |
2007年是“十一五”计划的第二年，各级领导继续围绕中央提出的单位GDP能源消耗降低20%的目标，将节能降耗作为重点工作来抓。工业是能源消耗的重点产业，因此，抓好工业企业的节能降耗工作对建设节约型社会具有重要的意义。现就2007年上半年我市规模以上工业能源消费状况作简要分析。
1、消费总量下降。近年来，随着经济的发展，我市能源消费继续出现下降的趋势，据统计2007年上半年全市规模以上工业企业总产值310.64亿，比2006年上半年的240.97亿增长了28.91%，综合能源消费626172吨标准煤，比2006年上半年的549005吨下降了12.32%，能源消费合计749737吨标准煤，比2006年上半年下降了13.65%。
2、能源消费结构优化，电力消费比重上升。2007年上半年，我市工业企业能源消费仍然以原煤及电力为主，但消费结构有所调整，一次能源原煤的消费比重有所下降，二次能源电力的消费比重有所上升。据统计，全市规模以上企业原煤消费量为 721937吨，比去年同期下降16.83%，低于全部能源消费下降幅度约3.18个百分点，其能源消费总量占全市规模以上工业企业能源消费总量的78.08%，所占比重比去年同期下降了5.26个百分点；电力消费量为102562亿千瓦时，比去年同期增长23.44%，占能源消费总量的比重16.87%,比去年同期上升4.89个百分点。
3、耗能大户节能明显，综合能耗普遍下降。2007年上半年，我市共有年耗能10000吨标准煤以上的工业企业有7家，分别是福建太平洋电力有限公司、英博雪津啤酒有限公司、福建佳通轮胎有限公司、福建省莆田市电业局、莆田金匙玻璃制品有限公司、福建众和股份有限公司和莆田市华港制油有限公司，只占规模以上企业总数的0.99%，但这些企业全年的能源消费量达412566万吨标准煤，占全市规模以上企业能源消费总量的75.28 %，工业总产值只占 14.91%，这些企业的用能情况直接关系到全市工业企业的能源利用效率。2007年上半年，许多能耗大户的节能降耗工作取得了明显的成效，2007年上半年，全市7家能耗大户的万元产值综合能耗为0.891吨标准煤，比上年下降23.96%，相当于节约13万吨标准煤。这7家重点耗能企业所涉及的6个行业中，有5个行业的万元产值综合能耗比去年同期下降，下降面达83 %。其中，食品制造业下降8.93%,橡胶制品业下降12.19%,非金属矿物制品业下降2.01%, 电力、热力的生产和供应业下降19.05%。
4、从消费能源的的行业来看，消费集中在五大行业。全市2007年上半年规模以上工业企业能源消费较高的行业有：电力、热力的生产和供应业，消费能源折标准煤329702吨，占总量的60.5%；饮料制造业消费能源折标准煤29384吨，占总量的5.35%；皮革、毛皮、羽毛（绒）及其制品业，消费能源折标准煤27564吨，占总量的5.02%；橡胶制造业消费能源折标准煤27229吨，占部呈的4.96%；非金属矿物制品业消费能源折标准煤21129吨，占总量的3.85%；以上五个行业占全市规模以上工业企业能源消费的80%左右.全市2006年规模以上能源消费超万吨标准煤的几个工业分行业消耗能源情况如下表：

5、新增企业的产值能耗低，2007年上半年我市新增企业55家，消费型煤301吨，消费焦炭44吨，消费汽油19吨，消费柴油106吨，消费电力1759.5万度，综合能源消费合计 2568吨，工业总产值80040.05万元，万元产值能耗0.03吨，是全市万元产值能耗的1/6，拉大了全市产值能耗的下降幅度。这些新增企业大多集中在食品制造业，皮革、毛皮、羽毛(绒)及其制品业，木材加工及木、竹、藤、棕、草制品业，非金属矿物制品业行业,以轻工业为主。
6、能源利用效果上升，各县区能源消费不平衡。2007年上半年规模以上工业企业万元产值能耗为0.18，较上年下降了0.08个百分点，节能效果显著。这与各级政府，相关的部门及企业的节能降耗的努力是分不开的。虽然下降幅度过大，主要是太平洋电力公司能源消费占全市规模以上工业企业能源消费的67.42%，综合能源消费占全市规模以上工业企业综合能源消费的48.93%，其消费水平波动对全市的消费影响很大，其产值能耗的下降，拉下全市产值能耗下降达10%左右，若扣除这个因素，全市规模以上工业企业产值能耗下降22.05%。从分各县区来看，2007年上半年秀屿区规模以上工业企业能源消费量大，为第一消费大户，是节能的重点区。各县区能源消费情况如下表：

从我市能源消费的特点来看，能源消费总量下降明显，但节能降耗的空间还是有的，为此，我们必须做好以下几方面工作。
1、加快技术进步，提高节能降耗水平，节能技改工作是节约能源的根本措施，我市继续在一些企业按照国家政策淘汰纯凝机组，更新小热电组。并继续依靠科学，加快技术进步，有重点地选择和扶持了一批节能技改项目，加快对低效风机、水泵、压缩机、变压器、电动机设备的更新，推广智能化节电设备装置,把技改与环境、效益结合起来，切实提高节能降耗水平。
2、加强重点耗能企业的节能管理。目前我市年耗能10000吨标准煤以上的重点耗能工业企业现有7家 ，其能源消费总量占全市规模以上工业企业能源消费总量的81.45%，其综合能源消费量占全市规模以上工业企业综合能源消费总量的75.29%，因此，加强重点耗能企业的节能管理是重中之重，要对重点能耗企业制定节能降耗目标、措施，加强监测和指导
3、合理调整能源消费结构，不断提高能源有效利用率。能源有效利用率在不断提高。除行业差别外，能源的有效利用还取决于消费结构，以电力和石油为主的消费结构的能源利用率明显高于以煤炭为主的能源消费结构。随着福建液化天然气LNG工程的将近完工，将有利于我市能源消费结构的调整。天然气作为一种高热值、低污染、低成本的优质燃料和化工原料，势必在我市今后的经济建设和市民生活中发挥重要作用。
                                （撰稿：王雪玉）
