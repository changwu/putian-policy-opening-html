2013年莆田市固定资产投资分析

发布时间：2014-01-20 00:00
| | |

今年以来，全市各级各部门紧紧围绕“跨越发展、宜居港城”的奋斗目标，持续深化实施“五大战役”建设，切实有效地推进重大项目落地建设，全市固定资产投资实现平稳较快增长，民间投资表现活跃，城乡一体化投资加快，建设资金到位充足，重点领域投资亮点突出，为促进全市经济增长奠定了坚实的基础。

一、投资运行的主要特点

（一）投资增幅稳居全省前列。今年以来，我市固定资产投资继续保持平稳较快的增长态势。2013年，全市全社会固定投资1191.11亿元，同比增长28.0%，增幅位居全省第四位，增速比全省平均水平高出5.8个百分点。其中固定资产投资（不含农户，下同）完成1164.54亿元，增长29.3%，增幅位居全省第四位，增速比全省平均水平高出6.9个百分点。在固定资产投资中：项目投资完成881.21亿元，增长25.5%；房地产开发投资完成283.32亿元，增长42.7%。（见图一）。

图一：2013年莆田市全社会投资增速情况表

（二）各县区（管委会）呈现全面增长的良好态势。今年以来，我市各县区（管委会）紧紧围绕市委市政府工作任务，认真部署，加强调度，强化措施，奋力攻坚，力促项目提速，促进固定资产投资快速增长，各县区投资增势喜人，出现全面增长的良好态势。今年以来，北岸经济开发区得益于大型临港项目的强劲拉动，投资一直保持高速的增长态势，增幅稳居全市各县区首位（见表一）。

（三）工业投资快速增长。2013年，我市工业投资完成407.43亿元，增长43.6%，占固定资产投资的比重为35.0%，对固定资产投资的贡献率为46.9%。其中：制造业完成投资308.27亿元，增长34.6%；电力、燃气及水的生产和供应业完成投资99.02亿元，增长84.4%；采矿业完成投资0.14亿元，下降87.2%。工业投资从分县（区）看：城厢区完成33.74亿元，增长73.3%；涵江区完成103.71亿元，增长35.7%；荔城区完成38.06亿元，增长48.8%；秀屿区完成91.86亿元，增长59.7%；北岸完成61.88亿元，增长65.5%；湄洲岛完成0.54亿元，增长311.2%；仙游县完成64.02亿元，增长2.1%；市直完成13.62亿元，增长198.5%。

（四）商贸服务业投资稳步增长。2013年，我市商贸服务业投资完成123.42亿元，增长21.4% ，占全部固定资产投资比重为10.6%，对全市固定资产投资的贡献率为8.2%。（见表二）。

（五）民间投资继续引领投资快速增长。今年以来，我市投资自主性较强的民间投资继续保持快速的增长态势，引领我市投资快速增长。在三大投资主体中，民间投资占固定资产投资的份额最大，对固定资产投资的贡献率也最高，成为拉动我市投资增长的主动力，在固定资产投资中继续保持主导地位。2013年，我市民间投资共完成613.29亿元，增长31.9%，比同期固定资产投资增速快2.6个百分点，占固定资产投资的比重为52.7%，投资比重比上年同斯提高1.1个百分点，拉动固定资产投资增长16.5个百分点，对固定资产投资的贡献率达到56.2%（见表三）。

（六）城乡一体化推进投资快速增长。随着我市城乡一体化的稳步推进，我市加大对水利建设、环境治理、公共设施建设、居民服务与保障等方面的投资，相关行业投资呈现快速的增长势头。2013年，水利管理业完成38.54亿元，同比增长43%；生态保护和环境治理业完成3.61亿元，同比增长5.5倍；公共设施管理业完成49.18亿元，同比增长49.4%；居民服务和其他服务业完成3.02亿元，同比增长2.1倍。

（七）建设资金来源较为充足，有力保障了投资建设快速推进。2013年全市固定资产投资口径本年资金来源总额为1305.77亿元，是同期同口径投资额的1.1倍，较为充足的资金为我市投资的快速增长提供了有力的资金保障。在本年到位资金中：国家预算内资金为61.29亿元，下降4.4%；国内贷款为271.22亿元，增长73.0%；利用外资13.64亿元，下降64.3%；自筹资金726.57亿元，增长19.6%；其他类资金173.43亿元，增长42.2%。

（八）房地产开发投资和商品房销售面积、销售额继续呈高增长态势。2013年，我市房地产开发投资完成283.32亿元，增长42.7%，增幅比同期固定资产投资快13.4个百分点。全市商品房销售面积288.43万平方米，增长40.4%，增幅比1-11月份上升3.9个百分点；商品房销售额达224.89亿元，增长61.1%，增幅比1-11月份上升6.6个百分点。

二、存在问题

今年我市投资运行态势总体良好，但投资运行中仍存在不容忽视的问题：

（一）投资结构不合理。一是工业投资占比偏低，今年以来我市工业投资虽然增速较快，但占同期固定资产投资比重仍然偏低，这将影响到今后我市的经济增长后劲。2013年，我市工业投资占同期固定资产投资的比重为35.0%，比全省平均水平低2.1个百分点。其中制造业投资占同期固定资产投资的比重为26.5%，比全省平均水平低4.0个百分点。二是固定资产投资的外延性扩张特点表现依然较为突出，投资仍以新扩建为主，改建和技术改造项目投资占比仍然偏低，投资外延性扩张明显，投资质量下降。2013年，在500万元以上工业项目投资中，我市新扩建项目完成投资339.52亿元，占500万元以上工业项目投资的比重为83.3%，而改建和技术改造项目仅完成投资29.32亿元，占500万元以上工业项目投资的比重仅为7.2%，远远低于新扩建项目，其中500万元以上工业项目中含金量最高的设备工器具购置完成投资131.45亿元，占500万元以上项目投资的比重仅为32.3%。三是房地产业投资比重过高。在我市第三产业投资中，超半投资是来自房地产业投资，投资过分依赖房地产，投资结构矛盾依然突出。2013年，我市房地产业完成投资414.09亿元，增长35.0%，占第三产业投资的比重高达56.7%，占固定资产投资的比重也达35.6%，对第三产业投资的贡献率高达78.0%，对固定资产投资的贡献率也达40.7%。

（二）亿元在建项目支撑乏力。2013年，在500万元以上项目投资中，我市共有亿元在建项目183个，比去年同期减少15个；亿元项目完成投资400.58亿元，增速仅为13.6%，增速比同期500万元以上项目投资慢15.7个百分点，占同期项目总投资的比重为34.4%，仅拉动项目投资增长5.3个百分点，对项目投资的贡献率仅为18.2%，投资比重与投资贡献率明显不协调。

（三）影响项目推进的制约因素仍然存在。前期手续报批、用地拆迁和资金问题仍然存在，国际经济大环境尚未好转，这些都严重影响项目的前期进展和建设进度。如十大开工项目中：莆田差别化纤维及高端运动系列网生产项目因征地拆迁问题而推迟开工；莆田市丁基橡胶生产项目因行业还存在严重亏损，可研报告上报中海油未获审批，前期工作无法开展。

三、对策建议

（一）加大招商引资工作力度。我市要紧紧抓住海西大发展大建设的大好时机，加大招商引资工作力度，加强项目储备，争取形成“建成投产一批、加快建设一批、新开工一批、谋划储备一批”的良性滚动发展格局。

（二）加强在建项目跟踪监测，督促项目尽早开工。通过梳理全市重点项目、政府性投资项目中的未开工项目，对未按时开工建设的项目，各主管部门要尽快督促项目开工，确保项目顺利推进。市委、市政府督查室和市重点项目办要强化督促检查，及时掌握项目进展情况，分析项目建设过程中存在的实际问题，并通过市政府网站和市委督查通报等多种形式通报项目建设进展情况，督促加快项目建设进度，确保各项任务落到实处。

（三）拓宽融资渠道，保障投资建设资金。一是充分发挥政府桥梁纽带作用，为企业和金融机构牵线搭桥，积极引导信贷资金流向经济效益好、社会效益高、偿还能力强的项目，提高资金的使用效率。二是进一步拓宽资金来源渠道，为企业提供融资担保，综合运用贷款、融资、信托、工程保理、企业债等多种工具，充分发挥国债、民间资本和外资的作用，为投资建设提供资金保障。

（四）注重投资结构优化和投资效益。一是招引项目要重视环境保护，重视投资规模和强度，有利于产业配套，促进产业集群化，壮大支柱产业。在项目质量上，要注重引进投资规模大、科技含量高、经济效益好、对财政贡献大的优势项目；在项目规模上，要注重引进经济实力强、发展前景好的大企业大集团，形成一个有梯度、有深度、有高度的多层次招商格局。二是政府要鼓励和引导现有企业积极进行改扩建，杜绝盲目的外延性扩张，节约资源保护环境，提高投资社会经济效益。
