2016年全市规模以上服务业较快增长 新兴行业贡献提升

发布时间：2017-02-09 00:00
| | |

今年以来，在宏观经济下行压力较大的情况下，莆田市始终把加快发展服务业作为转方式、调结构、保增长、促就业的重要着力点，新常态下的服务业企业保持了较快增长态势，对全市经济的稳定、转型和升级发挥了重要作用，但是内部结构不优、区域发展不平衡、企业整体规模偏小等问题影响服务业的提质增效。

一、总体状况

规模以上服务业主要指标稳中向好。2016年，全市309家规模以上服务业企业完成营业收入80.04亿元，同比增长16.9%，增幅同比提高10.3个百分点，居全省第三位；实现营业利润8.22亿元，增幅由上年同期的下降0.4%转为增长5.5%；应付职工薪酬11.47亿元，增幅由上年同期的下降1.0%转为增长3.3%。

二、运行特点

（一）其他营利性服务业快速增长。2016年，全市207家规模以上其他营利性服务业企业实现营业收入28.13亿元，同比增长58.6%，增幅同比提高24.3个百分点，高出全省平均水平27.4个百分点，比规模以上服务业平均增速快41.7个百分点，居全省第一位。

（二）商务服务和信息服务等新兴服务业贡献提升。2016年，受莆田市城市建设投资开发集团有限公司、莆田市国有资产投资有限公司、福建东方星海广告有限公司等企业业务量快速增长的拉动，全市商务服务业营业收入增势迅猛，同比增长54.0%，对全市规模以上服务业营业收入增长的贡献率为58.3%，同比提高1.1个百分点，拉动规模以上服务业营业收入增长9.9个百分点；得益于“互联网+”战略，风云网络科技公司、也买银网络科技公司等企业业务量快速增长，拉动全市互联网和相关服务及软件信息技术服务业营业收入强劲增长，同比增长了1.1倍，对全市规模以上服务业营业收入增长的贡献率为22.8%，同比提高3.0个百分点，拉动规模以上服务业营业收入增长3.9个百分点。

（三）新增企业拉动作用显著。去年以来新开业及2015年度规下转规上的183家企业共实现营业收入16.27亿元，占规模以上服务业营业收入的20.3%，同比增长1.1倍，对全市规模以上服务业营业收入增长的贡献率达74.5%，拉动规模以上服务业营业收入增长12.6个百分点。

（四）生产性服务业主体地位增强。2016年，全市246家规模以上生产性服务业企业实现营业收入75.40亿元，同比增长17.7%，增幅同比提高11.5个百分点，比规模以上服务业平均增速快0.8个百分点，其营业收入占全部规模以上服务业营业收入的比重达到94.2%，同比提高0.5个百分点，主体地位进一步增强。

三、存在问题

（一）企业规模整体偏小。截止12月底，全市规模以上服务业营业收入超亿元的企业仅12家，超五亿元企业仅2家。2016年，全市规模以上服务业企业户均营业收入仅2590万元，远低于全省平均水平（7445万元）。分行业看，全市23个行业大类中，仅电信、广播电视和卫星传输服务业户均规模高于全省平均水平，达9.53亿元，其他22个行业户均规模均远低于全省平均水平，其中户均规模低于1000万元的行业有9个，分别为：体育（766万元），公共设施管理业（655万元），居民服务业（579万元），教育业（362万元），娱乐业（359万元），文化艺术业（349万元），科技推广和应用服务业（297万元），新闻和出版业（219万元），其他服务业（22万元）。

（二）产业结构仍有待调整优化。2016年，全市信息传输软件和信息技术服务业、交通运输仓储和邮政业及租赁和商务服务业三个行业企业数分别占全市规模以上服务业企业数的13.6%、18.4%和45.0%，其营业收入合计74.42亿元，占全市规模以上服务业营业收入的93.0%。而科技服务、文体娱乐、教育、居民服务等行业发展明显滞后，其企业数合计占全市规模以上服务业企业数的比重仅为23.0%，营业收入合计占全市规模以上服务业营业收入的比重仅为7.0%，亟需发掘潜力壮大规模，调整优化服务业的内部结构，提升发展层次。详见表1。

（三）区域发展不平衡。全市规模以上服务业企业主要分布在城厢区和荔城区。其中，城厢区89家，占全市规模以上服务业企业数的28.8%，实现营业收入20.27亿元，占全市规模以上服务业营业收入的25.3%；荔城区90家，占全市的29.1%，实现营业收入42.32亿元，占全市的52.9%；其他5个县（区、管委会）共130家，占全市的42.1%，但企业规模总体偏小，实现营业收入17.45亿元，仅占全市规模以上服务业营业收入的21.8%。

（四）基础产业仍显疲弱。当前国内外市场需求仍较低迷,产能过剩问题依然突出,工业回升基础不牢，再加上市场准入放开不够、重大项目支撑不足等诸多因素影响,投资增长后劲不足,与之联系紧密且占比较高的传统服务业动能不足,发展放缓；健康、养老、医疗等服务业供给不足,不能很好满足居民消费需求。2016年，全市交通运输、仓储和邮政业营业收入19.76亿元，同比下降2.8%，降幅同比扩大0.5个百分点，占全市规模以上服务业营业收入的比重为24.7%，同比下降6.0个百分点。此外，纳入我市规模以上服务业统计的健康养老服务企业尚未有零的突破。

三、对策建议

 （一）推动产业融合，大力发展健康养老服务业。一是推动产业融合发展。充分发挥莆系医疗优势，统筹谋划医疗卫生保健、健康养生、体育健康等发展领域，推动医疗健康服务产业与养老、旅游、互联网、健身休闲等产业的融合，催生健康新产业、新业态和新模式。二是鼓励社会资本投建高端健康养老综合体。出台《全市民办健康养老机构资助办法》，引导社会资金投建多功能、综合型医养结合的大型健康养老机构，形成一批规模化、连锁化的知名大型健康养老机构。三是加快建设示范性公办养老机构。积极争取国家养老养护楼项目，尽快建设一批养护型、医护型公办养老机构，发挥示范引领、专业培训作用，带动公办养老机构全面提升水准。四是探索建立居家养老服务网络。选择经济较好、人口较多的街道（乡镇）实施居家养老试点示范工程。在街道（乡镇）建立居家养老服务指导中心，负责居家养老服务的培训、示范和统筹规划；在社区（村）设立居家养老服务中心，负责统筹开展社区日间照料和居家养老上门服务。

（二）增强科技创新驱动，加快发展专业化服务业。推进我市供给侧结构性改革，科技创新是关键。目前，我市信息传输、软件和信息技术服务业及科技服务业发展明显滞后，企业规模偏小。一是提升信息服务的渗透融合能力。围绕延伸和完善电子信息产业链，重点开展云计算、大数据服务和电子商务、电子物流、信息服务等领域的招商引资，大力推进大数据、云计算在生产制造、商业服务、金融、文化、教育、民生等行业及领域的应用。二是积极拓展服务外包领域。依托我市纺织鞋服、电子信息、电子商务等行业优势，重点突破软件外包、设计研发、创意设计服务等领域，培育一批创新能力强、具有国际竞争力的服务外包龙头企业。三是打造专业化服务业“智力引擎”。进一步深化校企产学合作，培育打造高层次的产业研发和技术团队。同时，研究出台专业化服务业人才引进政策，吸引高端人才服务机构为我市专业化服务业企业开展猎头、人才培训、人才认定和测评等服务，对成功引进企业所需高端人才的服务机构给予奖励，着力解决重点企业的招工用工和人才引进问题。

（三）推动产业集群，重点打造特色生产性服务业聚集区。一是立足于自身的区位优势和特色，依托现有工业基础，围绕重点发展的生产性服务业领域，规划引导一些商务区和专业性园区建设，强化生产性服务业的集聚效应。二是政府要加强对新兴商务区和园区基础设施建设和公共服务平台建设的资金支持力度，为吸引企业入驻创造良好的硬件环境；以市场机制为基础，积极吸引一批国内外知名企业入驻，打造具有特色的商业区和园区品牌形象。三是发挥龙头企业的引领作用，打造生产性服务业特色产业链。鼓励本地企业之间、本地企业与国内外企业之间的并购、重组，形成一批具有自主知识产权、具有较大规模和较强实力的企业集团；并围绕龙头企业，积极拓展产业链条，带动中小企业进入商务区或园区，形成产业发展生态链，充分发挥产业集群所带来的集聚效应。

　 （四）支持企业做大做强，以品牌提升服务业产业层次。一是鼓励重点服务业企业做大规模、创出品牌、提升效益；二是支持企业做大做强，促进服务业企业集团化、网络化、品牌化发展，特别是在部分规模较小、发展相对较弱的行业领域，形成一批拥有著名服务品牌和较强市场竞争力的企业集团。
