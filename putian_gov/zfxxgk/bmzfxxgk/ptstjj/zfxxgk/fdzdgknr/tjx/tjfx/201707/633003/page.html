2017年1-6月份莆田市规模以上工业运行分析

发布时间：2017-07-14 00:00
| | |

今年以来，全市工业经济呈现持续向好态势，新旧动能加速转换，供给侧结构性改革持续推进，生产效益有所提升。 1-6月份，全市规模以上工业实现工业增加值475.48亿元，可比增长7.8%,工业经济运行总体上呈现回暖的趋势。

一、工业经济运行主要特点

（一）主要先行指标积极向好。1-6月，全市工业用电量累计增长7.8%（扣除抽水蓄能后）。其中，制造业工业用电量明显回升，制造业工业用电量累计增长8.2%，增幅比1-5月回升了1.2个百分点。工业增值税降幅逐月收窄，1-6月全市工业增值税同比下降12.8%，降幅分别比1-5月、1-4月和1-3月收窄0.4个、4.1个和8.5个百分点。

（二）工业企业景气指数和企业家信心指数均处于“较为景气”。二季度，企业景气指数和企业家信心指数均好于上年同期“相对景气”，但较一季度呈现小幅回落。调查结果显示，二季度企业景气指数为125.5，比一季度低3.2点，继续运行在较为景气区间，其中，反映企业当前景气状态的即期企业景气指数为126.9，比一季度低2.1点。反映企业未来景气预判的预期企业景气指数为124.5，比一季度低4.0个点。二季度企业家信心指数为126.2，比一季度低2.1点。

（三）重点行业保持较快增长。1-6月，34个大类行业中有25个行业增加值同比增长，其中11个行业大类实现两位数的增长。皮革、毛皮、羽毛及其制品和制鞋业增长12.9%，橡胶和塑料制品业增长14.7%，化学原料和化学制品制造业增长15.8%，酒、饮料和精制茶制造业增长19.7%，纺织业增长21.0%。

（四）主要产品明显增长。1-6月，全市重点监测的15种工业品中，除纸制品和模具同比下降外，其余13种产品呈现较快增长的态势。其中，鞋增长21.0%、饮料酒增长15.0%、罐头增长26.6%、商品混凝土增长42.8%、橡胶轮胎外胎增长17.3%、服装增长8.4%。

（五）主导产业表现较好。1-6月，我市规模以上“33”产业实现工业增加值272.19亿元，增长7.9%，对规模以上工业经济增长的贡献率为57.6%，拉动全市规上工业经济增长4.5个百分点。其中，化工新材料和食品加工形势大好，受中锦新材料新增生产线、赛得利产品国内市场供不应求和滨海化工产能恢复等龙头企业带动，1-6月，化工新材料实现工业增加值70.51亿元，增长14.8%，拉动全市规上工业经济增长1.7个百分点。雪津、闽中、中粮华港等龙头企业拉动食品加工产业实现工业增加值58.16亿元，增长12.9%，拉动全市规上工业经济增长1.3个百分点。电子信息、高端装备和工艺美术产业保持平稳增长，分别增长8.2%、1.2%和1.0%，分别拉动全市规上工业经济增长0.7个、0.2个和0.5个百分点。

（六）制鞋产业主动求变初显成效。作为我市传统支柱的制鞋业，在鑫龙、永丰、双驰等鞋类龙头企业的带动下，企业加快转变发展方式，加大机器换工，以及今年以来东南亚订单回流，企业订单总体好于上年同期。政府惠企政策的落实，如政府搭桥建设“众协联”惠企帮扶平台，解决部分中小企业订单、资金、降本等问题。1-6月，我市制鞋产业总体向好，实现工业增加值122.20亿元，增长13.2%，对规模以上工业经济增长的贡献率为35.5%，拉动规模以上工业经济增长2.8个百分点。

（七）亿元企业增势强劲贡献突出。1-6月，全市超亿元以上规模企业385家，比上年同期多14家，占规模以上工业企业单位数的30.5%。实现工业增加值379.65亿元，增长15.5%，占全市规上工业增加值总量达79.8%，对规模以上工业经济增长的贡献率为122.6%，拉动规模以上工业增加值增长9.6个百分点。

（八）龙头企业引领带动作用突出。1-6月，全市高成长和省级龙头企业实现工业增加值108.46亿元，增长21.6%，增幅高于规模以上工业增加值平均增速13.8个百分点，对规模以上工业经济增长的贡献率为43.6%，拉动规模以上工业增加值增长3.4个百分点。

（九）新增企业成为工业经济新动力。1-6月，全市新增工业企业共拉动规模以上工业经济增长 1.3个百分点，成为工业经济发展新的增长极。其中，70家规下转规上企业实现工业增加值7.74亿元，增长119.3%，对规模以上工业经济增长的贡献率为8.3%，拉动全市规模以上工业经济增长0.7个百分点。主要是赛博思、众翔鞋业、、启丰鞋业3家企业贡献突出。去年以来26家新投产工业企业实现工业增加值5.91亿元，增长239.4%，对全市规模以上工业经济增长贡献率为8.1%，拉动规模以上工业经济增长0.6个百分点，其中去年新投产的中粮华港、钰诚化学等企业拉动作用较为明显。

（十）工业新动能积极孕育。近年来，我市工业经济主动把握新一轮科技和产业革命带来的机遇，积极实施“互联网+”和“中国制造2025”，加大培育经济转型升级的新动能。1-6月，全市战略性新兴产业实现工业增加值107.61亿元，增长13.6%，占全市规上工业增加值的比重为22.6%，对规模以上工业经济增长的贡献率为31.8%，拉动规模以上工业增加值增长2.5个百分点。高技术企业实现工业增加值35.27亿元，增长8.0%，对规模以上工业经济增长的贡献率为7.5%，拉动规模以上工业增加值增长0.6个百分点。

（十一）供给侧结构性改革助推企业发力。工业领域供给侧改革持续发力，推动我市工业转型升级步伐明显加快。如雪津开发中高端市场，“百威大师”等新产品成为市场“香饽饽”。佳通纸品加快开拓海外市场的步伐。佳通轮胎加快“机器换工”的步伐，“降成本”成效显现，目前已引进两条机器人自动化生产线。鲁艺古典家具以“实体”+“互联网”+“金融”创新的运营模式，以及兼并重组的模式与中小古典家具合作，加大“名艺名居”和“庄氏和川舍”品牌推广，提升企业市场竞争力。双驰鞋业增加鞋类个性化定制市场，拓宽了营销渠道。

（十二）工业经济效益不断提升。1-5月，规模以上工业综合经济效益指数达357.86，同比提高22.0个点。全市规模以上工业实现利润总额76.81亿元，增长9.8%。

二、存在问题

（一）传统工艺与创意产业不景气。1-6月全市工艺与创意产业增加值累计增长0.7%，增幅比上年同期回落9.4个百分点。行业不景气，停产企业增多。6月末，全市工艺与创意产业停产企业16家，比上个月增加3家。

（二）新增企业拉动力不足。截止目前为止，全市规上工业新增企业96家（含新投产及下转上企业）仅拉动全市规上工业经济增长1.3个百分点，低于上年同期新增企业拉动力4.6个百分点。其中，产值超亿元的企业仅9家，其他产值户均不足4千万，新增企业总体规模偏小，拉动力不足。今年以来，新投产企业数较少，工业新投产企业仅城厢区1家。

（三）停、减产企业影响较大。6月末，全市停、减产面达28.1%，共拉低全市增幅 5.1个百分点。74家停产企业，比上个月增加10家,影响全市工业增加值21.88亿元，拉低规模以上工业经济增长3.3个百分点。281家减产企业，比上个月减少9家,影响全市工业增加值12.28亿元，拉低规模以上工业经济增长1.8个百分点。其中102家减产千万元以上企业，影响工业增加值10.68亿元，占总减产额的87.0%，拉低规模以上工业经济增长1.6个百分点。

（四）企业“降成本”任重道远。从企业生产成本看，每百元主营收入成本为87.51元，比上年同期上涨0.08元。每百元主营业务收入的销售费用、管理费用和财务费用三项费用6.2元，比上年同期减少0.1元。

（五）专业型人才匮乏，行业性用工难问题仍然存在。在社保制度的不断改革下，企业“用工难”问题已基本得到解决，但专业技术型人才、高端管理型人才等十分匮乏，企业培育技术型人才成本大、难度高，仍以招聘成熟型人才为主要手段。据部分企业反映，目前一些比较偏远的工业园区，由于园区基础配套设施建设不够完善，加之企业自身的限制，导致企业招聘和留用专业技术人员、普工仍有困难，进一步制约了企业产能的发挥。
