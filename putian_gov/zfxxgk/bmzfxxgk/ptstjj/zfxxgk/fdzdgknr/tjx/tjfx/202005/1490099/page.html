2020年1-4月莆田市经济运行情况分析

第二十六期
发布时间：2020-05-18 16:43
| | |

今年以来，在市委、市政府的坚强领导下，全市上下认真贯彻落实习近平总书记关于统筹推进疫情防控和社会经济发展重要指示批示精神及党中央、国务院，省委、省政府的决策部署，在疫情防控取得阶段性成效的同时，社会经济发展也取得积极进展，主要经济指标降幅逐月收窄，经济持续向好的基础正在逐步恢复。主要表现在：社会消费品零售总额增幅居全省首位；规模以上其他营利性服务业增速居全省第三；规模以上工业、固定资产投资降幅逐月收窄。

一、经济运行主要特点

（一）工业经济逐步恢复。1-4月，全市规模以上工业增加值可比下降3.8%，降幅比1-3月环比收窄2.1个百分点，工业经济发展稳步恢复。主要亮点：一是重点新兴产业拉动有力。全市规模以上化工新材料产业、电子信息产业工业增加值分别可比增长11.2%和3.7%，分别拉动全市规模以上工业增加值增长2.1个和0.4个百分点。二是新增工业企业贡献突出。8家新投产企业、43家转规企业对全市规模以上工业增加值增长的贡献率分别达72.1%和18.8%，分别拉动全市规模以上工业增加值增长2.7个和0.7个百分点。三是工业转型升级步伐加快。全市规模以上战略性新兴产业、高技术企业分别可比增长14.6%和3.5%，分别拉动全市规模以上工业增加值增长3.9个和0.3个百分点。

（二）消费市场逐步回暖。1-4月，全市社会消费品零售总额完成518.60亿元，同比下降5.3%，降幅比1-3月收窄1.9%。主要亮点：一是生活必需品零售额回升。全市限额以上肉禽蛋类、饮料类商品分别实现零售额1.18亿元、2.16亿元，分别同比增长32.2%和30.4%；限额以上服装类、日用品类和文化办公用品类分别实现零售额10.64亿元、21.57亿元和1.24亿元，分别同比增长70.2%、47.3%和26.8%，共拉动全市限额以上零售额增长7.4个百分点。二是商品消费升级趋势明显。全市计算机及其配套产品实现零售额0.30亿元，同比增长23.1%；新能源汽车实现零售额1.34亿元，同比增长53.3%。三是满足顾客便利性需求的行业增长较快。与群众生活密切相关的限额以上食杂店和便利店零售额分别增长9.2%和36.2%。四是网上零售持续火爆。限额以上实物商品网上零售额76.94亿元，同比增长20.0%，占限额以上零售额的比重为49.2%，比去年同期提高11.9个百分点。

（三）投资降幅逐步收窄。1-4月，全市固定资产投资同比下降16.4%，降幅比1-3月收窄11.7个百分点。主要亮点：一是制造业投资止降回升。全市制造业投资同比增长1.1%，增幅分别比1-3月、上年同期提升24.1个和10.9个百分点。主要是莆田创世纪超算数据中心、年产30万吨绿色纤维产业园项目建设、福建永荣新材料有限公司年产两百万吨化工新材料等项目拉动有力。二是房地产开发投资降幅收窄。全市房地产开发投资完成114.75亿元，同比下降18.3%，降幅比1-3月收窄9.7个百分点，主要是霞梧磐龙一期、仙港豪园、融创兰溪雅苑等项目带动下，全市房地产土地购置费完成30.43亿元，同比增长33.6%，拉动全市房地产开发投资增长5.4个百分点。三是基础设施投资降幅收窄。全市基础设施投资同比下降22.5%，降幅比1-3月收窄9.0个百分点，主要是水利管理业、电力、热力、燃气及水的生产和供应业实现增长，分别同比增长0.2%和18.7%。四是商品房销售日渐活跃。随着线下售楼部逐步对外开放，加上线上认筹销售的拉动，全市商品房销售面积完成113.28万平方米，同比下降9.7%，降幅比1-3月收窄20.4个百分点，降幅低于全省平均水平11.8个百分点。

（四）规上其他营利性服务业增速逐步提升。1-3月，全市规模以上其他营利性服务业实现营业收入13.92亿元，同比增长7.8%，增幅分别高于1-3月、全省平均水平2.7个和7.9个百分点。主要亮点：一是租赁和商务服务业快速增长。在新开业的优之源模架租赁、松琴机械设备租赁、芷文机械租赁等多家机械设备租赁企业带动下，全市规模以上租赁和商务服务业实现营业收入7.05亿元，同比增长21.0%，拉动全市规模以上其他营利性服务业营业收入增长14.1个百分点。二是科学研究和技术服务业增势强劲。在新增的卓宇信息技术和智君信息服务两家企业带动下，全市科学研究和技术服务业实现营业收入0.46亿元，同比增长24.6%，增速高于全市规模以上其他营利性服务业 16.8个百分点。

二、经济运行存在问题

（一）工业持续回升压力较大。一是停、减产面扩大。受疫情影响，截止4月底全市停、减产企业636家，停减产面达54.8%，比上年同期扩大27.2个百分点，拉低全市规模以上工业增加值增速18.5个百分点。二是企业经营成本增加、效益下降。1-3月，全市规模以上工业企业每百元营业收入中的成本为88.06元，比去年同期增加0.04元；实现利润总额40.46亿元，同比下降21.3%。三是工业出口形势不容乐观。我市工业品外向度较高，特别是制鞋业主要以代工出口为主，受国外疫情爆发影响部分国外品牌客户商开始取消订单或要求延期交货，导致1-4月全市制鞋企业出口交货值仅同比增长1.0%，增速比去年同期回落10.4个百分点，其中4月单月出口交货值同比下降9.0%。

（二）消费市场短期影响较大。一是部分企业受疫情影响停业。截止4月底，全市共有215家限上批零企业因无订单、经营不善、资金困难等原因关闭停业，商品销售额同比减少56.66亿元，影响全市限额以上批发业、零售业商品销售额增幅8.1个和11.2个百分点。二是部分企业至今仍未复工。截止4月底，全市仍有79家限上商贸企业因订单减少、经营成本增加、资金压力加大等原因尚未复工。三是正常经营的企业大部分只能维持保本经营。据5月11日对803家全市限额以上商贸企业调查显示，91.9%的企业生产水平无法达到疫情前的水平，甚至有34.9%的企业生产水平只会达到疫情前的80%以下。

（三）投资稳增长基础不牢固。一是投资增速低于全省平均水平。虽然全市1-4月投资降幅有所收窄，但降幅仍高于全省平均水平5.9个百分点。其中，房地产开发投资降幅高于全省平均水平10.8个百分点，民间投资降幅高于全省平均水平10.7个百分点。二是新增项目后劲不足。今年以来全市亿元新开工项目虽然比上年同期增加了3个，但新增项目计划总投资比上年同期下降69.8%，完成投资额比上年同期下降64.6%。三是企业扩大投资意愿不强。受疫情影响消费市场低迷，企业订单减少，较多企业对市场前景持观望态度，进一步扩大投资的需求和动能下降。

三、对策建议

（一）积极帮扶促工业。一是积极做好企业帮扶，持续对停产和产值增速下降的工业企业进行精准分析,找准原因,对症下药,帮助企业尽快恢复产能。二是进一步从政策、资金、技术、人才等方面给予企业支持,积极鼓励企业进行创新研发，进行技术改造和提升，加快企业的转型升级,打造工业经济新的增长点。三是积极组织企业开展产销对接活动，加大本地产品品牌推广力度，鼓励重点企业一方面积极参与产销对接活动，另一方面通过线上销售打开市场销路，扩大产品知名度。

（二）创新模式促消费。一是认真梳理商贸停业企业情况，将针对零售企业的相关帮扶政策落实到位，帮助企业尽快恢复生产经营，并通过节假日营销组织产销对接活动帮助企业打开市场销路。二是各级地方政府积极为区域特产代言、推广，充分利用新媒体渠道帮助地方特色企业打开网络销售的大门，打造“线下+线上+快递物流融合”的新型零售模式，通过优质化精细化服务，促进消费市场恢复。三是积极鼓励商贸企业创新销售模式，通过无接触配送、网上订单送货到家、无人零售等新模式满足疫情期间人们的消费需求，同时进一步挖掘消费热点，提升产品质量，拓宽产品销路。

（三）狠抓项目促投资。一是全力做好重大项目招商引资工作，紧紧围绕各地产业发展规划，不断加强优势产业中强链补链项目招商引资力度，努力吸引一批技术领先、未来市场广阔的项目落户。二是加大基础设施投入，着重围绕民生领域突出短板，加大基础设施领域投入力度。全力推动在建项目加快进度，推动有条件的项目尽快开工，推动已开工项目入库列统，创新增量，挖掘存量，在充分利用有限资源条件下，实现投资有效回升。三是进一步引导各类资本向优势产业集聚，做大做强新兴产业集群，不断拓宽投资渠道，提振企业投资信心，继续发挥好投资的关键作用，增强经济持续增长的动力。
