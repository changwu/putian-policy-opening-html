1-11月全市经济持续平稳恢复

第八十一期
发布时间：2021-12-16 10:24
| | |

今年以来，在市委、市政府的坚强领导下，全市深入贯彻落实党的十九届六中全会、省第十一次党代会精神和省委、省政府的决策部署，扎实统筹推进疫情防控和经济社会发展，全面落实市委、市政府“攻坚两个月、奋战六十天”部署，推动重大项目、工业企业、消费市场三大领域提振信心、奋起直追、合力冲刺，全市经济继续保持平稳恢复，攻坚取得明显成效。

一、经济运行特点

（一）工业生产稳定增长。1-11月，全市规模以上工业增加值同比增长7.4%,增幅高于上年同期5.6个百分点。从先行指标看，全市累计工业用电量78.88亿度，增长22.0%，增幅居全省第2位，自3月份以来累计增幅始终保持在20%以上。从分行业看，全市工业33个行业大类中，有23个行业增加值实现同比增长，增长面为69.8%，特别是占据主导地位的规上“343”重点产业工业增加值增长8.1%，增幅高于全市规上工业增加值0.7个百分点，对全市规上工业增加值增长的贡献率为100.4%，拉动全市规上工业增加值增长7.5个百分点。

（二）规上服务业平稳增长。1-10月，全市规模以上服务业营业收入同比增长4.0%，增幅比1-9月提高1.7个百分点。其中，规上其他营利性服务业营业收入增长5.4%。从分行业看，在弹好工科技、硕合才储信息科技、云智薪共享经济信息咨询等企业带动下，全市平台企业营业收入增长3.7倍，拉动全市规上其他营利性服务业增长14.1个百分点；在市城投集团、龙吉顺实业等企业带动下，全市规上水利、环境和公共设施管理业营业收入由上年同期的下降5.5%转为增长66.5%，增幅高于全省平均水平55.6个百分点。

（三）固定资产投资稳中有升。1-11月，全市固定资产投资（不含农户）同比增长3.9%，增幅比1-10月提高2.0个百分点。从投资领域看，制造业投资增长11.8%；房地产开发投资增长9.0%，拉动全市固定资产投资增长1.9个百分点，仍是全市固定资产投资持续增长的主要支撑。全市商品房销售面积完成443.00万平方米，增长15.3%，增幅连续八个月保持全省首位。

（四）消费市场持续复苏。1-11月，全市社会消费品零售总额完成1597.56亿元，同比增长8.9%，增幅比上年同期提高9.7个百分点。从商品类别看，全市限上21类商品类别中有15类商品实现正增长，增长面为71.4%，形成以鞋帽类、日用品类和汽车类为主的限上消费品市场。其中，限上鞋帽类零售额145.63亿元，增长20.0%；限上日用品类零售额68.91亿元，增长20.5%；限上汽车类零售额70.18亿元，增长4.5%。从零售模式看，全市限上网上商品零售额延续较快增长态势，累计增长18.7%，增幅高于全市社会消费品零售总 9.8个百分点，拉动全市社会消费品零售总额增长3.2个百分点。

（五）财政金融总体平稳。1-11月，全市一般公共预算总收入完成232.31亿元，同比增长11.5%，增幅高于上年同期11.9个百分点。其中，一般公共预算收入完成145.36亿元，增长10.7%，增幅高于上年同期10.7个百分点。一般公共预算支出完成217.45亿元，增长1.7%。11月末，全市金融机构本外币存款余额2522.38亿元，增长10.3%，增幅居全省第3位；金融机构本外币贷款余额2456.46亿元，增长11.2%。

（六）消费价格温和上涨。1-11月，市区居民消费价格总水平同比上涨0.2%，涨幅比上年同期回落1.6个百分点。八大类消费“四增四降”，增长的有：交通和通信类价格上涨3.5%，教育文化和娱乐上2.8%，生活用品及服务类上涨0.8%；衣着类上涨0.1%；下降的有：其他用品和服务类价格下降5.1%，食品烟酒类价格下降0.9%；居住类价格下降0.4%；医疗保障类价格下降0.2%。

二、存在问题

（一）规上工业持续增长压力较大。一是停、减产企业影响较大。截至11月末，全市规上停、减产企业366家，停减产面达32.4%，影响全市规上工业增加值增长4.3个百分点。二是经济效益有所下降。1-10月，规上工业经济效益综合指数为385.87，比1-9月下降2.07个点；每百元营业收入中的成本比1-9月提高0.12元；实现利润总额仅增10.5%，增幅比1-9月回落9.8个百分点，低于全省平均水平9.3个百分点。

（二）规上其他营利性服务业增幅持续回落。全市规上其他营利性服务业营业收入仅增5.4%，增幅比1-9月回落2.6个百分点，且呈持续回落态势。一是规上商务和租赁服务业增速持续回落。受瑞智无忧（福建）科技等大企业业务量萎缩及远景投资管理等退库企业影响，占全市规上其他营利性服务业营业收入75.4%的规上租赁和商务服务业营业收入仅增9.5%，增幅分别比1-9月和上年同期回落1.4个和14.0个百分点，低于全省平均水平48.0个百分点。二是企业“进少退多”。2020年末以来，全市新入库规上其他营利性服务业企业仅29家，同比减少14家，而退库企业达86家，影响全市规上其他营利性服务业营业收入增长7.2个百分点。

（三）固定资产投资持续回升后劲不足。一是新增项目偏小。截至11月，全市新增入库投资项目计划总投资总计977亿元，同比下降51.9%。二是投资存量不足。截至11月，全市投资存量仅剩22.7%，其中：房地产开发投资存量仅剩5.5%。三是重点行业投资支撑不力。基础设施投资同比下降7.5%，影响全市固定资产投资增长2.4个百分点；工业投资增长0.5%，仅拉动全市固定资产投资增长0.2个百分点，重点行业拉动力明显不足。

（四）限上商贸业发展短板依然突出。一是限上批零业后劲不足。截至11月末，全市已退库的限上批零企业达390家，同比增加了108家，涉及家具、超市及鞋服类等商品行业，退库企业销售额累计减少156.20亿元，影响全市限上批零业销售额增长6.7个百分点。而今年以来月度新增企业仅8家，即使加上65家尚未通过国家审核的年度第一批新增企业，新增企业数仍明显少于退库企业数，限上批零业的持续增长后劲堪忧。二是限上住餐业恢复较慢。受疫情影响，全市限上住餐企业错过了中秋、国庆“双节”消费高峰期，导致业绩大幅下滑，虽然企业也积极开展各种促销活动，但市场消费信心恢复仍尚待时日，限上住餐业整体恢复相对较慢。

三、对策建议

（一）抓工业增效。一是深化“白名单”企业服务机制，加强领导挂钩帮扶，积极兑现各项惠企政策，统筹用人、用电、能耗，强化运行监测，推动停减企业复产增产。二是大力推动龙头培育、品牌创建、模式创新、智能改造、数字赋能、园区改革，不断提升产业发展内涵。

（二）抓服务业培育。一是加大招商。围绕重点产业发展，加大对服务业项目的招商引资，大力发展总部经济、平台经济等产业，促进现代服务业向高端化、高附加值方向发展。二是优化存量。加大对重点企业的政策引导和扶持力度，帮助企业继续做大做强，发挥引领示范作用，形成一批品牌知名高、竞争力强的龙头企业。三是做大增量。各级各有关部门要认真做好年底“上规”标准企业的入库工作，特别是要重点关注临规企业，要开展实时监测和跟踪服务，全面掌握企业生产经营情况，及时解决企业入库遇到的问题，督促指导企业完善申报材料，确保及时入库、应统尽统。

（三）抓项目支撑。一是加快推进永荣CPL二期、华峰绿色纤维产业园等36个产业类项目，联十一线、木兰大道三期等41个基础设施类项目以及莆田学院迁建、绶溪片区棚改等23个民生类项目建设；做实赛得利天丝、无纺布等重大项目前期工作。二是加大重大项目攻坚力度，强化项目要素保障，优化项目审批事项，力促在建项目加快建设进度，形成更多实物量。三是全力推进开放招商，加强与央企、外企、民企对接，引进落地一批龙头产业项目。

（四）抓消费回升。一是常态化开展促消费行动，大力宣传推动“全闽乐购”促消费活动，力促消费市场加快恢复。二是出台扶持补助政策，引导有潜力的个体经营户转为法人企业，贸易公司、住宿餐饮企业等转为限上企业。三是扶持“莆田餐巴”平台，打响“莆田餐饮”名片，创新线上线下相结合的新型服务模式，助力餐饮行业恢复发展。
