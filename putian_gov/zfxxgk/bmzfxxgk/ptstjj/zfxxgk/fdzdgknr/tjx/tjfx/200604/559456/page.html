一季度对外经贸运行情况分析

发布时间：2006-04-11 00:00
| | |

今年全市各级政府紧紧围绕建设海峡西岸经济区，积极构筑利用外资平台，大力实施项目带动战略，促进外商投资全面增长，一季度全市新签外商投资按验资口径统计项目31项，合同外资12727万美元，（其中新批项目23个，合同外资11817万美元）比去年同期增长90.35%；实际到资2307万美元，同比增长13.14%；外贸出口17184万美元，比去年同期增长11.5%。

一、利用外资增长主要因素

1、大项目投资对全市外资总量起着支撑作用。今年我市进一步加大招商引资力度，不断创新招商引资方式，注重引资规模及高科技项目等。一季度全市新批千万美元以上的合同外资（验资口径统计）项目5项，比去年同期增加4项，合同外资6517万美元，占一季度全市新批合同外资额的55.1%，分别比去年同期增长4倍和4.4倍，同时拉动全市合同外资增长69.4个百分点，成为带动全市合同外资增长主要动力。在这些大项目的带动下，今年一季度我市合同外资项目平均规模达410.5万美元，比去年同期扩大92.1万美元。

2、欧美等国家成为招商引资的新增长点。随着投资环境的逐步改善，外商投资来源地继续扩大。一季度全市新批投资项目中，欧美两大洲占9项，比去年同期增加5项，合同外资5002万美元（验资口径），占一季度全市新批合同外资额的42.3%，分别比去年同期增长2.3倍和1.5倍。

3、台商来闽投资再现高潮。随着去年台湾三大政党相继访问大陆，开启了两岸交流与沟通的新纪元，闽台合作亦趁此东风进一步增强，吸收台资取得新的突破。一季度全市新批投资项目中台资占4项，合同外资721万美元（验资口径），分别比去年同期增长3倍和2.6倍。

4、第三产业领域吸收外资成为重要增长点。今年我市第三产业领域吸收外资取得明显成效，一季度我市第三产业领域吸收外资合同（验资口径）3871万美元，比去年同期增长6.7倍，占全市合同外资的比重由去年同期的8.0%上升到32.8%。

5、各县区合同利用外资均呈快速增长。一季度各县区（除秀屿区外）合同利用外资超序时进度有：仙游县完成计划（历史可比口径下同）102.8%、城厢区完成计划50.2%、涵江区完成计划38.8%、荔城区完成计划26.8%。

二、对外贸易的主要特点

1、私营企业出口成为外贸出口的新亮点。外贸体制改革深化，经营主体多元化，为对外贸易发展带来新的活力。外贸领域的市场准入使得私营企业长期积蓄的能量在短期内得到释放，形成我国近年独特的出口推动力。我市一季度私营企业出口2864万美元，（占全市出口的比重由去年同期的11.0%上升到16.7%）比去年同期增长68.2%，高于全市平均增幅56.7个百分点。

2、一般贸易和加工贸易出口平稳增长。前2个月全市一般贸易出口6637万美元，比去年同期增长22.82%，继续保持良好的增长势头。加工贸易出口发展平平。1—2月份加工贸易出口10545万美元，比去年同期增长5.37%。

3、鞋类出口增长明显烤鳗呈恢复性增长。一季度我市鞋类出口增长速度明显增速，达20.7%；烤鳗出口从去年8月份开始受“孔雀石禄”影响停止4个月出口后，已全部恢复出口，1-2月份出口599吨，出口额880万美元，分别比增为9.8%和15.1%。

三、问题及建议

一季度，我市外经贸工作虽取得一定成绩，但也存在一些问题值得关注：

1、产业分布过于集中。一季度在新签外商投资项目中，第一产业仅1项、第三产业4项、第二产业18项合同外资为7846万美元，占今年全市新签合同外资额的66.4%，这种状况不利于产业结构的调整和优化。

2、我市对外贸易发展底于全省平均水平。1—2月我市对外贸易出口增长11.5%，底于全省平均水平的 8.3个百分点，增幅排在全省第七位。

3、劳工紧缺依然突出。今年我市熟练工短缺问题仍然突出，据劳动部门统计，一季度我市缺工1.92万人，其中鞋帽、服装业缺工0.88万人，占45.9%，电子装配工缺0.61万人，占31.6%。由于熟练工短缺，导致企业定单不敢接而影响产量及出口量。

4、机电产品出口下降， 轮胎出口增长缓慢。电子产品由于市场的局限和劳工的严重短缺，1-2月份下降15.7%（主要是台湾通信产品改造所致，比去年同期减少394万美元，下降81.5%，新益电子同比减少109万美元，下降41.9%），佳通轮胎出口由于调整生产线增长不明显，1-2月份出口1515万美元，同比增长1.4%。

5、产业国际竞争力不强。出口产品主要依靠数量增长和加工贸易方式提升竞争力，虽然从中获得了较大的利益，但也为此付出了资源、环保等方面的代价，单纯依靠数量规模和价格优势的增长方式的弊端逐渐显现，转变外贸增长方式成为未来需要解决的首要问题，从可持续发展的角度看，转变外贸增长方式，提高产品附加值，提升出口质量的效益已成为当前的紧迫任务。

6、加强应对技术贸易壁垒，走品牌发展之路。尽快建立和完善快速、高效的进出口预警系统，加强行业商会等中介组织的建设，充分发挥其在应对各国贸易保护中的作用。各企业要充分依靠技术转移和技术创新加快提高产品的质量与技术含量，加强国际标准和质量体系的认证意识，走品牌发展之路。

7、提高集约度，充分发挥开发区功能。把开发区作为招商引资的重点区域重新定位和规划，充分发挥开发区机制灵活、功能齐全、技术密集、产业集中的优势，提高土地使用的集约度，使开发区在招商引资工作中不仅占据举足轻重的地位，而且起到了应有的辐射、示范和带动作用。

                                （撰稿：姚春玉）
