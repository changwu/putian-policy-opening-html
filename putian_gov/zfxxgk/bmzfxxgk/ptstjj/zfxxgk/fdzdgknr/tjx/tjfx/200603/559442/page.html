2005年莆田市人口状况简析

发布时间：2006-03-10 00:00
| | |

据2005年1%人口抽样调查资料显示，2005年我市人口状况呈现：继续保持低速增长，人口净流出，人口密度偏高，人口老龄化程度进一步加大，大专及以上学历人口比重有所提高，出生人口性别比仍然失调，家庭规模小型化，城镇化水平稳步发展，民族构成趋向和谐等特点。

一、人口继续保持低速增长

2005年底，全市户籍总人口304.8万人，常住总人口为281万人，比上年增加2万人，出生率为12.5‰，死亡率为5.8‰，自然增长率为6.7‰，与上年相比出生率、死亡率分别下降0.1、0.2个千分点, 自然增长率上升0.1个千分点，但仍保持低增长态势。

二、人口净流出

随着市场经济的不断发展，人口流动日趋频繁。据2005年人口抽样调查结果显示，本调查年度内离开我市半年以上人口占总人口的比重为26.6%,比上年上升0.1个百分点；从分户口登记状况的人口来看，属第一种人（本地户籍人口）占82.74%，比上年下降1.38个百分点；属第二、三种人（外来流动人口）占14.45%，比上年上升0.16个百分点。说明我市人口流动日趋频繁，且属于人口净流出地区。

三、人口密度偏高

截止2005年底，我市每平方公里人口数达682人，高出全省每平方公里291人的1.34倍，比2000年末增加20人。多年来，我市一直是全国、全省人口密度较高的地区之一。1990年人口普查时为637人，2000年末达到662人。较高的人口密度对于我市这样一个地域面积小、人口基数大、自然资源短缺的地区来讲，对经济社会的全面协调和可持续发展产生较大的压力。

四、人口老龄化程度进一步加大

随着人民生活水平的不断提高和医疗卫生条件的改善，人的寿命不断延长，人口年龄结构逐渐趋向老化。2005年人口抽样调查结果显示，本调查年度内我市人口年龄结构为：0—14岁人口比重21.05%，比去年下降1.42个百分点，15—64岁人口比重69.80%，比去年提高1.03个百分点， 65岁以上人口比重9.15%，比去年提高0.39个百分点，比2000年第五次人口普查提高1.92个百分点，超过国际上老年型社会的一般标准（65岁以上人口比重超过7%）的2.15个百分点，说明我市已完全进入老年型社会。

五、大专及以上学历人口有所增加,但比重仍然偏低

2005年人口抽样调查结果显示，全市人口中，具有大学程度（指大专以上）的人口6.8万人，高中程度（含中专）的人口25.3万人，初中程度的人口99.6万人，小学程度的人口为95.3万人。与第五次人口普查相比，大学程度的人口增加1.5万人，高中程度的人口增加0.9万人，初中程度的人口增加0.1万人，小学程度的人口减少0.9万人。本调查年度内,大专及以上文化程度人口占6岁以上人口比重2.64%，比去年提高0.29个百分点，但仍大大低于全省平均水平5.0的2.36个百分点，主要是由于我市的产业层次较低，能够吸引较高学历人才的高新技术产业还未形成支柱产业，输送出去的莆籍大学生回乡就业的人数比重较低，而流入人口大多属于劳动密度型或劳动强度高的手工从业人员，文化程度普遍偏低。

六、出生人口性别比有所回落,但仍失衡

人口性别比有其内在规律，长期失调将会造成严重的社会问题。据2005年人口抽样调查结果显示，全市人口中，男性占总人口的47.93%，女性占总人口的52.07%。性别比（以女性为100，男性对女性的比例）为92.07。与第五次人口普查相比，性别比下降了1.2。但出生人口性别比为121.3,明显高于全省115.7的5.6个点，比2000年第五次人口普查的出生人口性别比125.5低4.2个点。究其原因主要有人们的生育观念落后，非法鉴定胎儿性别，社会保障滞后等因素。这种出生人口性别比严重畸形的问题，必须引起各级政府和领导的高度重视。

七、家庭规模继续趋向小型化

家庭是组成社会的重要细胞。随着社会的发展和变革，家庭类型、规模和结构都在不断发生变化。调查资料显示， 2005年家庭户规模为3.2人，比上年减少0.4人，比2000年减少0.68人，呈逐年缩小的趋势。家庭户规模趋向小型化，两代户成为家庭户主体的格局，对今后家庭养老模式、独生子女教育、居民住房需求等将产生较大的影响。

八、城镇化水平稳步发展

调查资料显示，全市人口中，居住在城镇的人口133.5万人，占总人口的47.50%；居住在乡村的人口147.5万人，占总人口的52.50%；城镇人口占总人口的比重为47.5%。比去年提高0.6个百分点，与第五次人口普查相比，城镇人口占总人口的比重上升了18.32个百分点，呈逐年提高趋势，城镇化水平稳步发展。

九、民族构成趋向和谐

调查资料显示，2005年全市人口中，汉族人口278.2万人，占总人口的99.01%；各少数民族人口2.8万人，占总人口的0.99%。与第五次人口普查相比，汉族人口增加了7.7万人，增长了2.85%；各少数民族人口增加了0.5万人，增长了21.74%，表现出少数民族人口增长快于汉族人口增长的特点，民族构成趋向和谐。

（撰稿：黄国强）
