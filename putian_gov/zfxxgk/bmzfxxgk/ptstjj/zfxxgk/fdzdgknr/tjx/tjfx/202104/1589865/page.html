1-2月莆田市规模以上服务业运行情况分析

第十六期
发布时间：2021-04-16 09:40
| | |

今年以来，在市委市政府的坚强领导下，全市上下继续做好“六稳”工作、落实“六保”任务，统筹疫情防控和经济社会发展成效持续显现，在经济有力复苏和去年同期低基数的双重作用下，莆田规模以上服务业呈恢复性快速增长。

一、主要亮点

1.规模以上服务业增速稳居全省第一。1-2月，全市规模以上服务业营业收入42.96亿元，同比增长71.0%，增幅高于全省平均水平30.6个百分点，稳居全省第一位。主要原因是物泊科技有限公司贡献突出，拉动交通运输、仓储和邮政业快速增长。全市交通运输、仓储和邮政业实现营业收入23.45亿元，增长1.4倍，对全市规模以上服务业营业收入增长的贡献率高达76.3%，拉动规模以上服务业营业收入增长54.2个百分点。

2.民生相关服务行业复苏有力。民生相关服务行业受疫情影响逐渐减弱，复苏进程加快。1-2月，全市规模以上卫生和社会工作行业营业收入增长1.6倍，增速同比提高144.3个百分点；水利、环境和公共设施管理业由上年同期的下降4.6%转为增长1.2倍；文化、体育和娱乐业由上年同期的下降36.7%转为增长1.0倍；居民服务、修理和其他服务业由上年同期的下降6.0%转为增长83.0%；教育业由上年同期的下降2.9%转为增长34.8%。

二、主要问题

（一）其他营利性服务业增速位次全省靠后。1-2月，全市规模以上其他营利性服务业营业收入11.67亿元，增长31.0%，增幅低于全省平均水平29.0个百分点，居全省末位。主要原因是我市重点行业增长乏力且缺乏大企业拉动。分行业看，一是互联网和相关服务明显负增长，全市该行业营业收入0.28亿元，下降56.9%，增幅低于全省平均水平104.8个百分点，主要原因是缺乏新增企业拉动，年度无新入库企业，另外，3家退库企业福建海丝商品交易中心有限公司、福建省芬木网络科技有限公司和仙游网库信息技术有限公司等负拉动明显，共拉低该行业营业收入增速48.8个百分点。二是租赁业低位增长，全市该行业营业收入0.80亿元，增长4.3%，增幅低于全省平均水平59.4个百分点，主要原因是8家带基数企业拉低该行业营业收入增速40.0个百分点。三是主导产业商务服务业拉动力减弱，全市该行业营业收入7.79亿元，增长27.5%，增幅低于全省平均水平50.4个百分点，主要原因是18家退库带基数企业共拉低该行业营业收入增速10.9个百分点。

（二）各县区发展不平衡。1-2月，湄洲岛、荔城区和北岸规模以上其他营利性服务业营业收入增速均高于全市平均水平，分别为426.7%、62.9%和46.7%。涵江区、秀屿区、仙游县和城厢区其他营利性服务业营业收入增速均低于全市平均水平，其中，涵江区下降17.3%，低于全市平均水平 48.3个百分点；秀屿区下降4.2%，低于全市平均水平35.2个百分点；仙游县增长26.3%，低于全市平均水平4.7个百分点；城厢区增长27.7%，低于全市平均水平 3.3个百分点。

（三）发展后劲不足。2020年末以来，全市新增入库规模以上服务业企业31家，比上年减少22家，其中，规模以上其他营利性服务业新增入库28家，比上年减少15家。目前，全市其他营利性服务业增长主要靠新增企业拉动，发展后劲不足将导致增速提升进位压力较大。

三、建议

1.强化部门工作合力。服务业行业分类复杂，涉及范围广，各相关主管部门尚未形成有效的工作合力。为更好地推动我市服务业提质增效，建议各县区、各部门按照“全市统一领导、市三产办牵头、部门归口管理、县区分级负责、各方共同参与”的原则，进一步明确服务业行业牵头部门、配合部门职责，夯实工作责任，紧盯目标、细化措施，突出重点、合力推进，构建服务业发展良好工作格局。同时，要加强对规模以上服务业企业的监测和引导，跟踪了解企业经营状况，协调解决企业生产经营中的问题，务实精准帮扶，促进服务业持续健康向好发展。

2.加大力度推动新增入库工作。近年来我市其他营利性服务业增长主要靠新增企业拉动，但今年我市新增入库单位数明显减少，增速提升进位压力较大，特别是涵江区和秀屿区服务业结构单一、单位数少、发展形势不容乐观，对全市增速提升影响较大。建议市、县两级服务业相关职能部门要强化分工协作，对达规的企业及时纳入统计，确保应统尽统。继续推进“个转企、小升规”工作，建立“准规企业库”，对临界未达规模的市场主体归入“准规企业库”，进行储备观察，有针对性地重点予以扶持、培育，增强服务业发展后劲。

3.加快推进服务业提质增效。大力发展研发、科技服务、信息服务、现代物流、现代金融等生产性服务业，推动生产性服务业向社会化、专业化和高端化发展，促进生产性服务业效率和专业化水平显著提高。加快发展旅游、文化、教育、医疗、养老、健康、体育等生活性服务业，推动生活性服务业向便利化、精细化和品质化转变，促进生活性服务业满足人民消费新需求能力显著增强。引导传统产业谋划转型升级，把握数字化、智能化发展机遇，促进服务新业态多元化发展，为全市服务业提质增效注入新动能。
