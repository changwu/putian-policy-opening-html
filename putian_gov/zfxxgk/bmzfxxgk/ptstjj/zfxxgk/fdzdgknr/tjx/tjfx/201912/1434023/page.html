1-11月莆田市经济运行情况分析

第八十三期
发布时间：2019-12-17 15:14
| | |

 

1-11月，全市经济运行总体平稳，主要表现在：工业经济平稳增长，消费增长稳中放缓，投资、商品房销售增幅高于全省平均水平。

一、经济运行主要特点

（一）工业经济平稳增长。1-11月，全市规模以上工业增加值可比增长8.6%，连续3个月保持8.6%的增速，工业大盘基本稳定。主要亮点：一是龙头企业表现良好。全市244家规模以上大中型企业增加值可比增长10.7%，增幅高于全市规模以上工业平均增速1.9个百分点，对规模以上工业经济增长的贡献率为63.4%，拉动规模以上工业增加值增长5.5个百分点。二是重点产业拉动有力。规模以上化工新材料、食品加工产业、电子信息和高端装备四大产业分别增长15.6%、11.6%、14.8%和16.3%，分别拉动全市规模以上工业增加值增长2.3个、1.2个、1.0个和0.9个百分点。三是优势产业增势喜人。规模以上装备制造业、高技术企业增加值分别可比增长13.5%、10.1%，增幅分别高于全市规模以上工业增加值4.9个、1.7个。

（二）消费增长稳中放缓。1-11月，全市社会消费品零售总额同比增长9.9%，增幅比1-10月回落0.3个百分点。主要亮点：一是消费结构不断优化升级。全市部分升级类商品消费增势强劲，其中可穿戴智能设备零售额增长125.1%，新能源汽车增长59.0%，智能家用电器和音像器材增长37.4%，电子出版物及音像制品类增长27.9%。二是新兴零售快速增长。全市限上批发零售业网上商品零售额增长16.8%，增幅快于全市社会消费品零售总额6.9个百分点。三是限上餐饮收入快速增长。全市限上餐饮收入增长24.5%，主要是下半年以来企业宴会收入增加拉动。

（三）投资增幅高于全省平均水平。1-11月，全市固定资产投资同比增长8.1%，增幅高于全省平均水平2.1个百分点。主要亮点：一是在建亿元项目贡献突出。全市265个在建亿元项目完成投资增长43.1%，增幅同比提高53.8个百分点，快于全市固定资产投资增幅35.0个百分点，对全市固定资产投资增长的贡献率达225.4%。二是房地产投资拉动明显。全市房地产开发投资增长23.6%，增幅比上年同期高34.3个百分点，对全市固定资产投资增长的贡献率为57.1%，拉动全市固定资产投资增长4.6个百分点，主要得益于今年加大开发用地出让力度，累计出让土地114.6公顷，土地出让金88.6亿。三是工业投资持续回升。全市工业投资同比增长12.6%，增幅分别比上年同期、1-10月高14.8个、2.9个百分点，主要得益于莆田创世纪超算数据中心、赛隆科技的绿色纤维产业园项目建设、福建永荣新材料有限公司的年产两百万吨化工新材料项目等一批制造业项目顺利进展拉动。

（四）商品房销售增幅领先全省。1-11月，全市商品房销售面积395.93万平方米，增长7.8%，增幅比1-10月提升0.6个百分点，高于全省平均水平5.3个百分点，居全省前列，主要得益于莆田恒大御景半岛、碧桂园天城枫城新都二期北区、莆田香盛公馆四个项目当月销售额合计8.14万平方米，共拉动全市商品房销售面积增长2.0个百分点。

二、经济运行存在问题

（一）工业生产持续增长压力较大。一是工业发展后劲不足。截止11月底，全市仅有3家新投产企业，同比减少7家。二是中美贸易摩擦因素影响后期逐步显现。制鞋业关税的加征，直接影响制鞋企业的订单量，据企业主反映存在后期订单不敢接，对鞋业加征关税直接挤压企业利润，导致企业亏损。

（二）规上其他营利性服务业增幅靠后。1-10月，全市规模以上其他营利性服务业营业收入同比增长8.4%，增幅低于全省平均水平14.5个百分点，居全省末位。主要是受莆田市城投、豆讯科技及秀屿区医疗咨询行业影响，共拉低全市规模以上其他营利性服务业营业收入增长23.9个百分点。

（三）部分商品零售疲软。一是全市限上消费零售市场中有六大类商品零售额同比下降，其中家电及音像器材类零售额下降20.8%，石油制品类商品零售额下降2.4%。二是限上大类商品中粮油食品类零售额仅增0.9%，增幅比1-10月回落3.0个百分点。

（四）投资稳增长基础不牢固。一是在库项目同比减少。截止11月底，全市在库投资项目1760个，同比减少486个，其中500-5000万元在库项目1421个，同比减少546个。二是基础设施投资持续降势。1-11月全市基础设施投资由去年同期的增长14.9%转为下降8.0%。其中交通运输业投资下降24.1%；电力、热力、燃气及水的生产和供应业投资下降19.7%；水利管理业投资下降2.4%。三是民间投资回落明显。1-11月，全市民间投资仅增7.0%，增幅分别比上年同期回落20.4个百分点。 

三、对策建议

（一）做强工业增动力。一要持续对停产和产值增速下降的工业企业进行精准分析,找准原因,对症下药,帮助企业尽快恢复产能;二要深入抓好工业经济运行监测调度工作,密切关注企业生产经营状况与走势,特别是做好重点行业和骨干企业生产经营的监测工作,引导与帮助企业满负荷生产；三要进一步从政策、资金、技术、人才等方面给予有实力、有潜力的企业支持,加快企业的转型升级,打造工业经济新的增长点

（二）培育服务业增后劲。一是进一步加大重点企业扶持力度，帮助企业做大做强，发挥重点企业的引领示范作用，形成一批品牌知名度高、竞争力强的服务业龙头企业。二要进一步加大新增企业培育力度，积极挖掘规模潜力较大、效益较好的服务业企业，列出清单重点培育发展，扶持其做大做强，力争早日达到规模以上企业标准，尽早申报入库，增强服务业发展后劲。

（三）扶持电商促消费。一是积极扶持电商企业发展，鼓励支持重点行业、重点企业发展电子商务等新型消费模式，进一步挖掘消费热点，加强对新兴消费领域的市场监测和分析，合理引导市场供给结构趋于完善。二是推进电商与农村经济融合，坚持政府引导和市场推动，依托优势产业，借助公共网络交易平台实现农特产品“走出去”的跨越式发展，构建农村电商销售渠道，通过淘宝、京东等全国知名电商平台以及政府、企业自建平台进行商品展示交易，扩大知名度反哺实体经济。

（四）狠抓项目促投资。一要高度重视新项目策划工作，特别是要加快和推动重大项目的储备、落地和实施，推动形成持续不断、滚动实施的储备机制和良性循环，推进落实相关建设条件，积极争取国家和省上的资金支持；二要加强部门间的配合，积极督促企业准备相关入库材料，保证项目的及时入库；三要抓好战略性新兴产业、现代服务业、传统产业等领域投资，进一步引导各类资本向优势产业集聚，做大做强新兴产业集群，不断拓宽投资渠道，提振企业投资信心，继续发挥好投资的关键作用，增强经济持续增长的动力。
