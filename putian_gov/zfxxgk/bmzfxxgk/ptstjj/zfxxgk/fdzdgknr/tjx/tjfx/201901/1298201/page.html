工业经济稳中有进 产业结构不断优化——2018年莆田市规模以上工业经济运行分析

第四期
发布时间：2019-01-18 15:36
| | |

2018年，我市面对依然复杂的国内外经济环境，以习近平新时代中国特色社会主义思想为指导，全面贯彻落实中央、省各项决策部署，抓龙头、铸链条、建集群，做优做大产业，不断深化供给侧结构性改革，以高质量发展助推赶超跨越。全市工业经济运行稳中向好、稳中有忧，主要工业经济指标位居全省前茅，工业经济质量稳步提高。

一、工业经济运行主要特点

（一）工业先行指标总体向好。一是工业用电量快速增长。2018年，全市工业用电量83.90亿千瓦时，增长21.2%，增幅位居全省九设区市首位。扣除抽水蓄能后，全市工业用电量累计增长20.4%，增幅位居全省九设区市首位。其中，制造业用电量增长24.7%。二是工业增值税增势强劲。2018年，全市实现工业增值税33.8亿元，增长23.6%，已连续10个月保持两位数快速增长的态势。三是工业企业景气指数和企业家信心指数运行在较为景气区间。调查结果显示，四季度，工业企业景气指数125.9，企业家信心指数126.5，持续保持在较为景气区间，表明全市工业经济运行总体平稳。

（二）工业经济保持较快增长，贡献突出。2018年，全市工业增加值增长8.9%，占GDP比重41.7%，对GDP增长的贡献率达51.1%，拉动经济增长4.2个百分点，工业依然发挥着“挑大梁、主力军”的作用。其中，全市规模以上工业增加值增长9.1%,增幅分别比1-3月、1-6月和1-9月提高1.2个、0.2个和0.1个百分点，增幅比上年提高0.9个百分点，与全省平均水平持平。分行业看，33个大类行业中有22个行业增加值同比正增长，并且11个行业实现两位数增长。其中皮革、毛皮、羽毛及其制品和制鞋业增长10.8%，电力、热力生产和供应业增长27.7%，计算机、通信和其他电子设备制造业增长32.3%，纺织业增长32.4%。

（三）重点产业稳中有升，集聚效益明显。2018年，我市第一大制鞋产业工业增加值增长11.0%，对规模以上工业经济增长的贡献率为32.3%，拉动规模以上工业增加值增长2.9个百分点。主要原因：一是内销市场的开拓。以东方猎狼、大诚、三威、祥冠、力奴等鞋企为主的足力健老人鞋和安踏等内销订单大幅增加。二是鑫龙、永丰等龙头鞋业，外销订单充足，保持稳定增长。三是国际体育盛会带来的订单效应。全市“33”产业工业增加值增长9.1%，对规模以上工业经济增长的贡献率为53.8%，拉动规模以上工业经济增长4.9个百分点。电子信息和高端装备产业发展势头强劲。其中，电子信息产业工业增加值增长32.5%，对规模以上工业经济增长的贡献率为17.1%，拉动全市规上工业经济增长1.5个百分点；高端装备产业工业增加值增长16.0%，对规模以上工业经济增长的贡献率为9.0%，拉动全市规上工业经济增长0.8个百分点。

（四）工业园区发挥工业主战场作用，对规模经济贡献超六成。2018年，全市工业园区共有704家规模以上工业企业，占全市规上工业企业数的57.2%，工业增加值增长9.6%，占全市规模以上工业增加值的65.2%，对规模以上工业经济增长的贡献率为67.5%，拉动规模以上工业经济增长6.1个百分点，引领和支撑全市工业经济快速增长，充分发挥工业经济的主力军主战场作用。

（五）重工业持续发力，中小企业支撑给力。2018年，全市规模以上重工业增加值增长13.2%，增速高于轻工业增速5.7个百分点，对规模以上工业经济增长的贡献率为37.8%，拉动规模以上工业增加值增长3.4个百分点。全市规模以上中小型企业贡献给力，贡献率破百。2018年，全市规模以上中小型企业工业增加值增长12.9%，增速高于规模以上工业平均增速3.8个百分点，占全市规模以上工业增加值的79.6%，对规模以上工业经济增长的贡献率为101.7%，拉动规模以上工业经济增长9.3个百分点。

（六）亿元企业引领作用突出，新投产企业注入新活力。2018年，全市超亿元工业企业工业增加值增长16.8%，增速高于规模以上工业平均增速7.7个百分点，对规模以上工业经济增长的贡献率为142.1%，拉动规模以上工业增加值增长12.9个百分点。2018年，全市26家去年以来新投产企业对规模以上工业经济增长的贡献率为31.1%，拉动规模以上工业增加值增长2.8个百分点，新投产企业拉动明显，为我市工业经济注入新血液。

（七）产业结构调整持续推进，工业供给侧改革不断深化。一是新兴产业势头良好。2018年，全市战略性新兴产业工业增加值增长16.2%，对规模以上工业经济增长的贡献率为25.6%，拉动规模以上工业增加值增长2.3个百分点；高技术企业工业增加值增长21.7%，对规模以上工业经济增长的贡献率为12.8%，拉动规模以上工业增加值增长1.2个百分点。装备制造业工业增加值增长12.2%，对规模以上工业经济增长的贡献率为16.7%，拉动规模以上工业增加值增长1.5个百分点。二是高能耗行业增速持续回落。随着产业结构不断优化，高耗能行业增速持续回落。2018年，高耗能企业工业增加值增长13.6%，分别低于1-9月、1-6月3.0个和2.0个百分点。

二、存在问题

（一）工业企业停、减产面仍居高不下。12月末，全市停、减产面达30.1%，为近几年来的高位，共拉低全市工业增加值增幅6.2个百分点。其中停产企业143家，拉低全市工业增加值增幅4.4个百分点；减产企业227家，拉低全市工业增加值增幅1.8个百分点。

（二）规模工业企业数减少，转规企业贡献减弱。2018年，全市规模以上工业企业1231家，比上年减少45家，已连续两年减少。37家去年年底转规企业对规模以上工业增加值增长的贡献率为3.4%，仅拉动规模以上工业增加值增长0.3个百分点，拉动力明显不足。

（三）外需市场略显疲软，贡献不足。近年来，国际贸易保护主义的抬头，一定程度上影响我市工业品的出口。2018年，全市规上工业出口交货值增长6.4%，增幅低于全市规上工业销售产值增幅5.5个百分点，说明外需市场依旧不景气拉动力不足。

 （四）工业企业去库存、降成本任重道远。1-11月，全市规上工业企业主营业务成本同比增长13.9%，高出主营业务收入同比增速1.7个百分点。工业产成品存货增长37.1%，高于全省平均水平25.8个百分点；每百元主营业务收入中的成本为88.29元，同比增加1.33元；每百元资产实现的主营业务收入为343.56元，同比减少4.76元；产成品存货周转天数5.9，同比增加1天。全市规模以上工业利润总额下降4.7%，增幅低于全省平均水平20.1个百分点，企业增产不增效。

三、对策建议

（一）分类施策精准帮扶，助推停减产企业复工复产。摸清停、减产企业“困”在哪“难”在哪，建立“一企一册”台账，创新举措，因企施策，全力盘活停、减产企业。建立健全 “一业一策、一企一策”精准帮扶机制，帮助企业降低运行成本、各类生产要素成本和制度交易性成本，帮助企业解决实际问题，进一步优化营商环境，有效推进企业走出困境，激活企业“造血”功能，提高企业市场竞争力，进一步提高企业效益。

（二）加大招商引资力度，加快新增工业项目投建。进一步加大招商引资的力度，完善产业链，以“走出去”和“请进来”并重的招商工作思路，创新招商方式，提高招商成效，进一步优化工业产业结构，提高产品附加值。及时推进新增工业项目投建，做好要素保障，形成“签约一批、开工一批、投产一批、入库一批”的滚动发展态势，输入工业“新血液”。同时，加强规模工业的培育，加快资源整合力度，实现资源合理配置和产业结构优化，鼓励企业“抱团”发展，盘活现有闲置资产，优势互补，做大做强企业。

（三）积极开拓国内市场，开拓平台经济新模式。通过“政府搭台、企业唱戏”方式，整合各方资源，构建产品信息平台，打响“莆田质造”品牌。一是加大莆货品牌宣传力度。积极整合宣传、文化、新闻、广电、出版等资源，创新品牌宣传模式，提升莆货的知名度和美誉度。二是提升企业参展的商业转化率。鼓励企业参与市内外各类大中型展销、展会活动，帮助企业拓展国内外市场。三是促进企业“互联网+”融合发展。积极推广应用电子商务等现代营销方式，引导企业借助互联网宣传和推广产品，拓宽产品销售途径和发展空间。

（四）加快传统产业升级，促进企业提质增效。一是加快传统产业的转型升级，企业主动作为，加大科研投入，提升企业产品科技含量、提高产品附加值，降低成本。二是进一步优化产业链和产品结构，政府要加强对企业的引导，在转型上谋突破，创新上谋发展，加快供给侧结构性改革，促进企业经济效益持续稳定增长。
