1-11月莆田市消费品市场运行情况简析

第八十四期
发布时间：2017-12-18 08:24
| | |

1－11月，全市消费品市场总体运行平稳。

一、基本运行情况

前11个月，全市实现社会消费品零售总额627.89亿元，同比增长11.3%，增幅比1－10月回落0.1个百分点，增幅居全省第四位，位次较上月前移一位。

按消费形态看，全市实现商品零售额576.63亿元，增长11.7%；实现餐饮收入51.26亿元，增长6.5%。商品零售和餐饮收入增幅均比1－10月回落0.1个百分点。

按县区发展看，北岸、城厢和湄洲限上消费市场发展快于全市平均水平，荔城持平，秀屿最低，各县区间限上消费市场发展差距进一步缩小，增速最快与最慢的县区间相差22.9个百分点，差距较1－10月缩窄3.1个百分点。

分限额标准看，限上单位实现消费品零售额309.57亿元，占全市消费品市场的49.3%，增长16.8%；限下单位实现318.32亿元，增长6.4%。

二、当前限上消费品零售市场运行的支撑点

1、新增限上批零企业贡献率达三成。今年来全市新增限上批发零售企业212家，累计商品零售额32.38亿元，增长155.7%，对全市社会消费品零售额增长的贡献率为30.9%。分县区看：城厢11.96亿元，增长4.5倍；涵江5.99亿元，增长38.7%；荔城9.61亿元，增长2.0倍；秀屿2.14亿元，增长31.7%;仙游1.33亿元，增长43.8%，北岸1.34亿元，增长2.6倍。其中，城厢新增限上批零企业对全市社会消费品零售额增长的贡献率最高，达15.3%，其次是荔城，为10.0%。

2、网上销售保持较好发展态势。“互联网+”蓬勃发展，酷鱼爱尚、布依信贸易等299家限上商贸企业通过公共网络实现商品零售额99.93亿元，增长29.0%，占全市消费品市场的15.9%，比重较上年同期高3.1个百分点，比全省平均水平高9.5个百分点，对全市社会消费品零售总额增长的贡献率达35.3%，贡献率同比提升2.3个百分点。

分县区看，网上零售市场仍集中在城厢和荔城。1－11月城厢限上商贸企业实现网上零售额61.65亿元，占全市限上网络零售市场的61.7%，增长25.7%，荔城区实现网上零售额28.03亿元，占全市的28.0%，增长38.4%。

三、制约因素

一是破产（注吊销）企业基数影响。11月末已破产（注吊销）仍在库中的批零企业有55家，拉低全市社会消费品零售额1.1个百分点。其中，荔城和城厢分别拉低全市社会消费品零售额0.5个和0.3个百分点。

二是销售下降企业对限上消费品市场影响。11月末全市商品销售额下降的限上零售企业达107家，占全市限上零售企业数的21.7%，累计实现零售额44.43亿元，同比减少15.63亿元，下降26.0%，影响全市消费品零售额2.8个百分点，其中下降额超五千万的企业有12家。部分电商企业及汽车销售企业下降较大，主要原因是资金困难及商品品牌策略偏离市场需求。

三是部分商品销售增长乏力。1－11月石油类商品仍低速增长，累计实现零售额28.55亿元，增长0.6%；传统零售业面临较大的发展瓶颈，1－11月，全市限上超级市场零售额16.17亿元，同比下降3.5%，各限上商场营业收入普遍低于上年；汽车类商品消费也只维持在个位数增长，1－11月全市限上汽车类商品零售额47.18亿元，增长9.5%，低于全省平均水平3.7个百分点。
