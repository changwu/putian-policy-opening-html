上半年莆田市建筑业总产值平稳增长

第四十六期
发布时间：2021-07-21 08:59
| | |

面对复杂严峻的国内外环境，我市建筑业企业克服困难，坚持在常态化疫情防控中紧跟步伐、寻找机遇，主动开拓市场，推动建筑行业保持健康发展。

一、建筑业发展特点

（一）建筑业总产值平稳增长。截止6月底，全市总专包资质建筑业企业502家，同比增加5家。上半年完成建筑业总产值419.31亿元，同比增长19.4%，增幅位居九地市第六，较上年同期提高25.0个百分点。其中特级企业3家，占全市建筑企业数的0.6%，产值合计占全市总产值的19.0%；一级企业32家，占全市建筑企业数的6.4%,产值合计占全市总产值的49.0%；二级企业82家，占全市建筑企业数的16.3%,产值合计占全市总产值的15.5%；三级企业385家，占全市建筑企业数的76.7%,产值合计占全市总产值的16.5%。

（二）外拓产值保持增长但增速放缓。上半年资质建筑企业在外省完成产值236.08亿元，同比增长25.9％，增速较上年同期及一季度分别回落18.0个、12.7个百分点。外拓范围涉及28个省，其中江西、广东、浙江产值均超过20亿，合计119.33亿元，占全部外拓产值的50.5%。从各省数据来看,外拓产值下降最快的省份主要是河北、陕西和山西等北方省市；从各企业来看，祥荣建设、涵城建设等5家企业的外拓产值减少量大，均超过3亿。

（三）特级企业拉动产值增长作用明显。上半年，巨岸建设、涵城建设等3家特级企业产值均超过25亿，合计完成产值80.08亿元，占比0.6%的企业数完成全市产值的19.1%，贡献率8.9%，拉动建筑业总产值增长1.7个百分点。大型建筑企业将经营的触角逐步伸向建筑行业的各个领域，随着企业改革的逐步推进，这些企业实力将不断增强，在建筑行业发挥更大的作用。

二、建筑业存在问题

（一）建筑业发展后劲明显不足。上半年，全市资质建筑企业新签合同额469.24亿元，同比下降11.0％，增幅较一季度及上年同期分别回落55.7个、60.3个百分点。承建的房屋建筑新开工面积757.40万平方米，同比下降36.0%，增幅较一季度及上年同期分别回落81.7个、85.6个百分点。去年疫情造成基数小外，仙游建工、飞阳建设等４家企业今年上半年新签合同额较去年同期大幅减少，少签合同均超过３０亿元，合计减少176.34亿元，占全市新签合同额的３７．６%。顺安建筑、仙游建工等5家企业上半年新开工面积较去年同期大幅减少，减少量均超过50万平方米，合计减少471.38万平方米，占全部新开工面积的62.2%。

（二）倒闭(停业）企业数或创历史新高。上半年全市有53家建筑企业产值为0，超过全部企业数的一成,比重较去年同期提高3.0个百分点。建筑行业面临的窘境不仅仅是新冠疫情带来的冲突，疫情只是导火线，主要原因：一是市场竞争日益严峻化。受整体经济大环境及招投标市场全面开放影响，市场竞争日趋激烈，本地中小企业综合实力不如外来央企、国企，承揽新项目特别是大型项目的难度不断加大。二是建筑业原材料价格上涨。截至6月30日，全国建筑材料价格指数为195.21，较年初上涨11.5%，同比上涨31.1%。从莆田市数据来看，钢筋（HRB400E16-25mm）价格从1月的4605元/吨上升到6月的5066元/吨；袋装水泥（42.5）价格从1月的510元/吨上升到6月的546元/吨。

（三）区域发展不均衡。上半年，各县区建筑行业发展情况参差不齐。从总量看，资质建筑业总产值最大的是荔城区，为108.39亿元，占全市比重为25.8%；最小的是湄洲岛，为2.12亿元，占全市比重为0.5%，两区总产值相差超过50倍。从增速看，有3个县区超过全市平均增速，增速高低落差达157.5个百分点，北岸资质建筑业总产值增速最高，达145.3%；涵江区降速最高，下降12.2%。

三、对策建议

从整体数据来看，建筑产值的统计口径是按注册地，尽管全市加大投资力度，但大项目几乎都由央企承建。也就是说，大型项目的建筑业总产值将统计到央企的注册所在地，同时本地企业普遍反映中标难，今年面临濒临倒闭的企业数量明显增加。莆田市早已出台《莆田市中小微企业政策性融资担保工作方案》（莆政办（2019）76号）、《莆田市人民政府关于促进建筑业发展壮大的实施意见》（莆政综（2018）98号）等优惠政策文件，但从产值数据来看，扶持成效不够显著。建议各县区政府在引进项目的同时，重点扶持市内龙头企业，提高与央企抗衡的实力，争取今年下半年本地企业的大型项目中标率提高，纳入本地建筑业总产值统计范围。

从外拓企业数据来看，外拓工程不仅仅要靠大型企业的打拼，更需要政府的服务支持。尽管我市近年已出台《莆田市中小微企业政策性融资担保工作方案》，除了该方案要坚持有效落地外，各县区还要多渠道助力企业定位。如何锁定工程多、竞争少的外拓区域，如何锁定竞争少又稀缺的细分领域，引导中小企业走专业化、差异化特色之路。建议政府及相关部门多方获取信息资源，为企业指引未来努力的方向。
