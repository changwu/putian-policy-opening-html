2018年1-2月莆田市规模以上工业运行分析

第十四期
发布时间：2018-03-22 15:06
| | |

1-2月，我市工业经济稳中向好，工业经济高质量开局迎来首月开门红。工业相关指标增势回升，结构调整稳步推进。

一、工业经济运行主要特点

（一）工业生产运行稳中向好。1-2月，全市规模以上工业增长8.0%,高于全省平均水平0.1个百分点，位居全省第三位。分三大门类看，采矿业下降52.5%；制造业增长7.4%；电力、燃气、水的生产和供应业增长20.2%。分经济类型看，国有企业增加值增长1.3%，集体企业增长56.5%，股份合作企业增长8.4%，股份制企业增长9.7%，外商及港澳台商投资企业增长5.6%，其他经济类型企业下降20.8%。分行业看，33个大类行业中有20个行业增加值同比增长，14个行业实现两位数增长。其中酒、饮料和精制茶制造业增长11.3%，皮革、毛皮、羽毛及其制品和制鞋业增长13.0%，电力、热力生产和供应业增长18.2%，食品制造业增长23.1%，计算机、通信和其他电子设备制造业增长32.9%，纺织业增长58.5%。

（二）工业先行指标快速增长。2月全市工业用电量6.47亿千瓦时，增长36.2%，比上年同期增加50.2个百分点。1-2月全市工业用电量13.19亿千瓦时，增长30.8%，比上年同期增加36.2个百分点，增幅位居全省九地市第一位。制造业用电量快速增长。2月全市制造业工业用电量当月增长46.6%，比上年同期增加51.4个百分点。1-2全市制造业工业用电量增长31.0%，比上年同期增加28.5个百分点

（三）主要产品明显增长。1-2月，全市鞋增长22.3%；服装增长68.7%；罐头增长56.0%；商品混凝土增长38.0%。

（四）重点行业支撑明显。

1、皮革、毛皮、羽毛及其制品和制鞋业拉动明显。1-2月，全市皮革、毛皮、羽毛及其制品和制鞋业增长13.0%，拉动全市规模以上工业增加值增长2.7个百分点。一是内销订单增加，企业新增生产线。二是代工企业订单稳中有增。三是政府加大制鞋业的扶持力度，政府惠企政策效应显现。众协联平台聚集效应逐步发挥，增强企业加大生产信心。

2、文教、工美、体育和娱乐用品制造业有所回暖。1-2月，全市文教、工美、体育和娱乐用品制造业增长8.8%，比上年同期增加12.2个百分点，拉动全市规模以上工业增加值增长0.9个百分点。主要是红木市场有所回暖，政府加大扶持和品牌推广力度，此外企业加快转型升级的步伐，加快了新模式、新业态的融入，拓宽了企业销售渠道。

3、计算机、通信和其他电子设备制造业增长迅速。1-2月，计算机、通信和其他电子设备制造业增长32.9%，高于全市平均水平24.9个百分点，拉动全市规模以上工业增加值增长0.9个百分点。新增的华佳彩和元生智汇拉动较为明显。

（五）民营工业起支撑作用。1-2月，全市规模以上民营工业增长5.5%，总量占全市规上工业增加值总量达74.8%，对规模以上工业经济增长的贡献率为62.7%，拉动规模以上工业增加值增长5.0个百分点。

（六）工业企业转型升级稳步推进。1-2月，全市战略性新兴产业增长24.4%，对规模以上工业经济增长的贡献率为32.8%，拉动规模以上工业增加值增长2.6个百分点。高技术企业增长13.6%，对规模以上工业经济增长的贡献率为9.8%，拉动规模以上工业增加值增长0.8个百分点。装备制造业增长8.5%，对规模以上工业经济增长的贡献率为14.2%，拉动规模以上工业增加值增长1.1个百分点。

（七）小微企业活力涌现。1-2月，983家规模以上小微工业企业增长13.1%，增幅比全市规模以上工业增加值平均增速快5.1个百分点，对规模以上工业经济增长的贡献率为68.3%，拉动规模以上工业增加值增长5.5个百分点。

二、存在问题

（一）停、减产企业影响明显。2月末，全市停、减产面达26.3%，共拉低全市增幅6.8个百分点。其中停产企业73家，拉低全市工业增幅3.8个百分点；减产企业248家，拉低全市工业增幅3.0个百分点。

（二）部分企业产能发挥受限。鞍钢冷轧虽恢复生产，受订单影响，产能未能充分发挥。华佳彩、云度新能源汽车、元生智汇去年年底虽已入库，但由于机器设备还在调试阶段，产能发挥不足。

（三）工业达规企业数有所减少。2月末，全市共有规模以上工业企业1221家，但比上年同期减少40家。

（四）转型升级困难多。市场机制倒逼企业转型升级的作用显现，工业企业认识到粗放的发展模式已难以为继，转型升级迫在眉睫。但是由于缺少资金、技术、人才等要素支撑，转型面临困难。一是科研投入较弱。大多数工业企业缺乏创新动力，忽视技术研发，科研投入较弱，影响企业转型升级。二是技术人才缺乏。专业技术人才是企业淘汰落后产能、实现转型发展的重要保证。莆田作为三线城市，企业工作环境、福利待遇、工作稳定性等方面较一、二线城市差，难以留住技术人才，这也使得部分企业转型升级比较慢，效果不显著。三是融资难融资贵。企业融资难融资贵也是制约企业转型发展的重要原因。
