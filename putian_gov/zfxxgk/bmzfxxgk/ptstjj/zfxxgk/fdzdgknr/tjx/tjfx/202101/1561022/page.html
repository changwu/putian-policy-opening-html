莆田市规模以上服务业逆势快速增长——1-11月莆田市规模以上服务业运行情况分析

第一期
发布时间：2021-01-11 09:47
| | |

随着疫情防控成果不断巩固，疫后社会经济稳步复苏，人民生活恢复常态，企业经营状况持续改善、营业收入普遍增加，全市规模以上服务业在部分重点行业的拉动下实现较快增长。1-11月，全市规模以上服务业营业收入255.85亿元，增长54.4%，增速比1-8月提高11.3个百分点，比全省平均水平高46.4个百分点，居全省第一位。其中，规模以上其他营利性服务业营业收入67.53亿元，增长14.7%，增幅比1-8月提高1.1个百分点，比全省平均水平高0.8个百分点，居全省第四位。

一、主要亮点

（一）交通运输、仓储和邮政业持续迅猛增长。受物泊科技有限公司营业收入快速增长拉动，1-11月，全市规模以上交通运输、仓储和邮政业营业收入147.89亿元，同比增长1.1倍，自4月份以来持续保持60%以上的高增长，对全市规模以上服务业营业收入增长的贡献率高达86.9%，拉动规模以上服务业营业收入增长47.3个百分点。其中，道路运输业营业收入增长1.4倍；多式联运和运输代理业营业收入增长23.3%。

（二）租赁和商务服务业贡献突出。1-11月，全市规模以上租赁和商务服务业营业收入49.14亿元，增长25.9%，对全市规模以上其他营利性服务业营业收入增长的贡献率高达116.6%，拉动规模以上其他营利性服务业营业收入增长17.1个百分点，是拉动我市其他营利性服务业营业收入增长的主要动力。主要原因是瑞智无忧（福建）科技有限公司、莆田云智薪共享经济信息咨询有限公司和福建优之源模架租赁有限公司等三家大企业拉动强劲，实现营业收入12.10亿元，增长8.2倍，对全市其他营利性服务业营业收入增长的贡献率高达124.7%，拉动其他营利性服务业营业收入增长18.3个百分点。

（三）居民服务业小幅回升。1-11月，全市规模以上居民服务、修理和其他服务业营业收入3.61亿元，增长8.4%，增速比1-8月回升0.5个百分点。主要原因是莆田市诚铭投资管理有限公司和莆田市雅洁姐妹家政服务有限公司2家企业在疫情趋于稳定后业务量大幅增加，拉动全市该行业营业收入增长12.6个百分点。

二、主要问题

（一）文化、体育和娱乐业持续负增长。全市该行业受新冠肺炎疫情冲击影响仍在继续，营业收入持续明显下降。1-11月，全市规模以上文化、体育和娱乐业营业收入3.36亿元，下降27.7%，连续十个月呈负增长态势。

（二）互联网和相关服务、软件和信息技术服务业增速持续回落。1-11月，全市规模以上互联网和相关服务、软件和信息技术服务业营业收入9.28亿元，下降6.0%，增速比1-8月回落9.8个百分点，拉低全市其他营利性服务业增速 1.6个百分点，主要原因是缺乏大企业拉动，另有19家企业营业收入负增长，负增长面达50.0%，拉低全市互联网和相关服务、软件和信息技术服务业增速29.3个百分点。

（三）科学研究和技术服务业增长乏力。1-11月，全市该规模以上科学研究和技术服务业营业收入2.15亿元，增长8.1%，增速比1-8月回落2.3个百分点。主要原因是该行业规模小，单位数少，缺乏大企业拉动，户均营业收入仅1130万元。

（四）各县区发展不平衡。分县区看，城厢区、湄洲岛、荔城区和涵江区规模以上其他营利性服务业营业收入增速均高于全市平均水平，分别为31.8%、28.4%、23.2%和18.0%。北岸、秀屿区和仙游县其他营利性服务业营业收入增速均低于全市平均水平，其中：北岸下降32.1%，增幅低于全市平均水平46.8个百分点，拉低全市增速2.4个百分点；秀屿区下降27.2%，增幅低于全市平均水平41.9个百分点，拉低全市增速2.9个百分点；仙游县增长14.4%，增幅低于全市平均水平0.3个百分点。

三、对策建议

（一）填空白，进一步优化服务业行业结构。要重点调整和优化传统行业，加快互联网信息服务、数字内容服务、科学研究和试验发展、创业空间服务等规模以上服务业空白行业企业的发展步伐，各有关职能部门要结合第四次全国经济普查和市场监督管理局、税务局等有关部门的行政记录，深入企业做好本系统、本行业服务业企业的排查、指导、挖潜工作，建立“准规企业库”，对临界未达规模的市场主体归入“准规企业库”，进行储备观察，有针对性地重点予以扶持、培育，对达规的企业及时纳入统计，壮大规上服务业的总体规模，推动全市服务业结构优化升级。

（二）补短板，进一步增强服务业发展后劲。为缓解当前规上服务业发展后劲不足的问题，各行业主管部门要重点关注发展困难、行业龙头地位突出的企业，了解企业发展瓶颈，帮助企业解决实际困难，支持企业自身提质升级增强营收，同时，要更加注重在服务业领域培育支柱产业，下大力气抓好教育、居民服务修理和其他服务业、卫生和社会工作、水利环境和公共设施管理业等与民生相关企业，培育一批品牌知名度广、行业带动作用强、发展潜力大、营利能力强的信息传输、软件和信息技术等现代服务业企业，增强服务业发展后劲，带动服务业快速高质量发展。

（三）抓创新，进一步促进新兴服务业加快发展。主动融入国家“一带一路”和省重大发展战略，从服务业高质量发展的定位出发，把现代服务业企业和项目的招商引资作为重点，着力引进现代服务业的重点企业、新兴行业，并促进其与传统服务业的嫁接与合作，提高全市服务业的档次和水平。在基础服务方面，探索发展大数据、云计算、数字媒体等信息技术服务；在生产和市场服务方面，探索发展互联网+、电子金融、现代物流、电子商务、商业连锁经营、现代物业管理、中介和咨询服务等；在个人消费服务方面，探索发展数字教育、智慧医疗、保建服务、文化旅游等；在公共服务方面，探索发展公益性信息服务。
