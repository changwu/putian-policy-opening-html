2019年1-4月莆田市规模以上工业运行分析

第三十四期
发布时间：2019-05-27 18:52
| | |

今年以来，面对国内外经济下行压力持续加大的运行态势，我市坚持稳中求进工作总基调，深入贯彻新发展理念，以推动高质量发展为根本要求，以供给侧结构性改革为主线，着力解决工业生产运行中的困难和问题，全市工业经济总体呈现稳中趋缓的态势。

一、工业经济现状

1-4月，全市规模以上工业增加值增长8.8%，比上月回落0.1个百分点，低于全省平均增幅0.1个百分点。

分县区看，一季度，秀屿区规上工业增加值增长11.1%；城厢区规上工业增加值增长9.5%；涵江区规上工业增加值增长9.4%；仙游县规上工业增加值增长9.4%；荔城区规上工业增加值增长8.7%；北岸规上工业增加值下降8.9%。

分产业看，1-4月，全市重点产业中贡献较为突出的产业：一是传统制鞋产业工业增加值增长7.5%，对规模以上工业增加值的贡献率为26.9%，拉动全市规模以上工业增加值增长2.4个百分点。鑫龙鞋业、东方猎狼等鞋企龙头带动制鞋业保持平稳增长。二是化工新材料产业增长9.5%，对规模以上工业增加值的贡献率为16.3%，拉动全市规模以上工业增加值增长1.4个百分点。华锦实业和本月新入库的永荣科技拉动明显。三是电子信息产业增长22.2%，对规模以上工业增加值的贡献率为12.6%，拉动全市规模以上工业增加值增长1.1个百分点。元生智汇、联懋科技等龙头企业发挥龙头引领作用。四是高端装备产业增长19.2%，对规模以上工业增加值的贡献率为10.3%，拉动全市规模以上工业增加值增长0.9个百分点，其中上海电气拉动明显。

二、工业经济运行主要亮点、支撑点

（一）民营工业成为工业经济增长主力军。1-4月，全市规模以上民营工业增长8.1%，总量占全市规上工业增加值总量达81.0%，对规模以上工业经济增长的贡献率为77.4%，拉动规模以上工业增加值增长6.8个百分点，发挥我市工业经济增长主力军作用。

（二）亿元企业贡献率破百。1-4月，全市超亿元以上规模工业企业增长15.2%，增速比全市规模以上工业平均增速高6.4个百分点，对规模以上工业经济增长的贡献率为104.3%，拉动规模以上工业增加值增长9.2个百分点。

（三）小微企业增长涌现活力。1-4月，全市规模以上小微企业增长13.7%，增幅比全市规模以上工业平均增速高4.9个百分点，对规模以上工业经济增长的贡献率为65.5%，拉动规模以上工业增加值增长5.8个百分点。

（四）“三新”工业经济增长势头强劲。1-4月，全市战略性新兴产业工业增加值增长13.4%，高技术企业工业增加值增长21.6%，装备制造业工业增加值增长20.8%。

三、工业经济运行主要问题

（一）停、减产面居高不下。4月末，全市停、减产面达27.6%，比上月提高0.1个百分点，共拉低规模以上工业增加值4.3个百分点。其中停产企业70家，比上个月增加10家，拉低规模以上工业增加值2.2个百分点；减产企业261家，比上个月减少8家，拉低规模以上工业增加值2.1个百分点。

（二）规上工业企业退多进少，贡献不足。近年来，新投产达规的工业企业和下转上的工业企业明显减少，退库多于入库企业。1-4月，全市规上工业企业1198家，比上年同期减少22家。新投产企业贡献不足，华佳彩、云度新能源汽车、HDT太阳能电池等企业产能未能正常发挥。

（三）传统制鞋业贡献逐月减弱。受外需不足、中美贸易战等因素影响，我市制鞋产业增幅有所回落。1-4月，全市第一大传统制鞋产业增长7.5%，分别比1-3月、上年同期回落1.0个和3.5个百分点，对工业经济的贡献率由上年同期37.0%下降至本年的26.9%。

四、建议

（一）切实做大工业经济增量。强化县区一把手招商，加快“腾笼换鸟”、“零地招商”的新模式，精准招商，解决我市工业产业链的短板问题，增强工业发展后劲。在加大对规上工业企业扶持力度的同时，政府优惠政策也要倾向规下的小微企业，完善工业企业培育机制，培育有发展前景的工业企业，特别是培育能稳增长、适应市场需求、带动全市GDP增长的高品质企业。

（二）加快企业转型升级，开拓平台经济新模式。一要加大企业的技改投入，提高企业的产品品质和生产效率，来抵消企业生产成本攀升的压力，提高企业市场竞争力。二要通过“政府搭台、企业唱戏”方式，整合各方资源，构建产品信息平台，打响“莆田质造”品牌，帮助企业拓展国内外市场。三要促进企业“互联网+”融合发展。积极推广应用电子商务等现代营销方式，引导企业借助互联网宣传和推广产品，拓宽产品销售途径和发展空间。
