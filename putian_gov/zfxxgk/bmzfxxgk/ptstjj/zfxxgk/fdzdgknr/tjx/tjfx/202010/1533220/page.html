前三季度全市房地产运行情况分析

第五十九期
发布时间：2020-10-19 17:35
| | |

2020年，国内外各种形势相互叠加，房地产市场状况更加复杂多变。面对疫情和经济形势的变化，莆田市委、市政府坚持稳中求进工作总基调，坚持疫情与经济发展同抓共管，房地产开发投资降幅扩大，商品房销售面积降幅缩小，各项经济指标趋稳向上，但国内外经济形势依然不明朗，下阶段仍应重点关注新项目开工状态及施工面积、待售面积等指标情况。

一、前三季度房地产开发基本情况

（一）房地产投资降幅有所扩大

总体投资情况。前三季度，全市完成房地产开发投资282.45亿元，下降11.9%，排名全省第八，降幅比上个月扩大了2.9个百分点。

一是房地产在库企业数有所增加。截止9月底，全市共有房地产企业250家，比去年同期增加了4家。前三季度，全市共有28家企业首次纳入统计范围，房地产企业不断增多，为房地产投资增长奠定了基础。

二是投资构成中建安投资比重有所下降。前三季度，建筑工程完成174.65亿元，下降20.1%；安装工程完成9.80亿元，下降19.8%，建安工程占房地产投资的比重达65.3%，同比下降了7.7个百分点。其他投资中，设备工器具购置3.24亿元，下降4.2%；土地购置费91.10亿元，增长11.9%。

（二）商品房销售增速下降趋缓

今年来，受新冠肺炎疫情的影响，商品房销售情况较去年出现下降，随着疫情影响逐步散去，商品房销售面积的降幅逐步缩小。前三季度，全市商品房销售面积为303.35万平方米，同比下降8.6%，降幅比上个月收窄5.4个百分点，商品房销售额为269.48亿元，同比下降5.2%。前三季度我市房地产销售市场主要呈现以下特点：

一是各县（市、区）商品房销售有增有降。全市16个县（市、区）、开发区（投资区）商品房销售面积增幅呈现“二增四降”，城厢、秀屿近二年新出让土地增多，带动今年销量小幅增长，分别为增长39.0%、9.2%。下降的有涵江区、荔城区、仙游县、北岸，分别为-32.8%、-9.0%、-15.7%、-53.8%。主要是：荔城区、仙游县虽然有建发·磐龙府、湖心·正荣府等项目的热销，但因去年基数较高，还是出现同比下降，涵江区受新开发片区基础配套设施不足及大量安置房上市的影响，各楼盘销售整体情况不佳。

二是商品房住宅销售仍为主力。前三季度，全市商品住宅销售面积达259.85万平方米，占全市销售面积的85.7%。其中90平方米以下的小户型住宅销售面积10.36万平方米，下降44.5%，占全市住宅销售面积的比重为4.0%；90-144平方米住宅销售面积215.99万平方米，下降8.5%，占全市住宅销售面积的比重为83.1%；144平米以上的改善型住宅销售面积33.49万平方米，增长5.0%。

三是商品房均价小幅增长。从3月份市场需求逐步恢复后，价格也逐步回升，而且近期市中心城区一些高端品质的楼盘相继入市带动商品房销售均价小幅增长。从商品房买卖合同网签价格统计，前三季度全市商品房销售均价为10354元/平方米（扣除安置型商品房），同比增长5.9%，其中商品住房均价为10392元/平方米，比增4.5%（扣除安置型商品房）。

（三）房地产用地供应基本持平

在各级政府加大力度促征迁促供地下，前三季度全市房地产用地供应与去年同期基本持平。前三季度通过招拍挂供应房地产经营性用地（含安置型商品房）24宗116.15公顷（合1742.27亩），同比下降1.7%；出让总价款1081450万元，同比增长18.5%。从季度看，一季度出让6宗31.72公顷，二季度出让8宗34.14公顷，三季度出让10宗50.29公顷。

二、存在问题

（一）项目建设进度有待提高。前三季度，全市房地产投资依然处于下降区间，随着企业全面复工复产，全省房地产投资增幅已由负转正，而我市投资增幅远低于全省水平，项目建设进度仍要加快。从全省范围看，我市房地产开发投资增速居全省第八位。全省房地产投资增长7.0%。

（二）商品房待售面积激增，1-3年待售面积库存压力大。商品房库存压力大，截至9月末，全市商品房待售面积163.91万平方米，增长11.5%，其中住宅待售面积79.15万平方米，增长9.5%；非住宅类待售面积84.76万平方米，占了全市待售面积的51.7%。其中待售1-3年（含1年）面积64.63万平方米，增长67.6%，待售3年以上（含3）面积77.56万平方米，增长1.3%。

（三）房屋新开工面积下滑明显。房屋新开工面积作为房地产投资的先行指标，关系着投资在今后一段时间增长能否得到有力支撑，出现下降需要重点关注。由于去年第四季度全市土地出让大幅减少（仅2宗房地产用地），因些今年前三季度全市商品房新开工面积同比明显下降.前三季度，新开工面积为309.40万平方米，下降25.2%，其中住宅新开工面积为219.10万平方米，下降26.8%。

三、相关建议

1.把握土地供应节奏，促进新项目开工建设。把握好土地供应节奏，是保持房地产市场平衡的关键。今年以来，全市土地供应节奏有所加快，土拍市场也相对平稳，但由于企业从拍地到开发建设周期较长，很多项目仍未纳统。建议相关部门加强要素保障，缩短项目规划、审批、环评、建设等多个环节所需时间，督促企业早日开工建设。

2.探索多元销售途径，创新优化商品房质量。房地产开发项目有前期投入大、开发周期长、资金成本高等特点，应鼓励房地产开发企业加大技术创新和产品创新力度，提高商品房整体质量满足市场需求。

3.产城融合扩大体量，促进房地产健康发展。房地产长期发展，离不开产业推动，各地应联动推进新型工业化、新型城镇化的建设目标，将“产城融合”理念逐渐深入新一轮的工业园新区建设大潮中，鼓励房地产企业由传统的提供商业小区住宅的主题开发，转向参与某一区域的新区建设，从而带动房地产投资和销售，进而推动房地产业健康平稳发展。
