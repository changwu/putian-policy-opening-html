1-8月份莆田经济运行稳中提速

第五十六期
发布时间：2022-09-20 10:42
| | |

今年以来，在市委、市政府的坚强领导下，全市上下坚持“以稳促进、以进固稳”，进一步巩固疫情防控和经济复苏成果，积极应对内外部风险挑战，保持经济运行在合理区间。1-8月份，全市主要经济指标当月增幅、累计增幅均比上个月有所提高，经济运行呈现稳中提速、加快回升态势。

一、经济运行基本情况

（一）工业经济稳步提升

1-8月份，全市规模以上工业增加值同比增长1.8%，增幅比1-7月份提高0.8个百分点。其中，8月当月增长8.1%,比7月当月（增长0.9%）提高7.2个百分点。从三大门类看，采矿业增加值下降25.2%，制造业增长2.0%，电力、燃气及水的生产和供应业下降1.2%。从行业分类看，33个行业大类中有17个行业增加值实现正增长，特别是化学纤维制造业、纺织业、化学原料和化学制品制造业分别增长30.6%、23.7%和16.8%。从主要支撑看，规模以上大中型企业增加值增长8.4%，拉动规模以上工业增加值增长2.3个百分点；规模以上新型功能材料产业增加值增长19.0%，拉动规模以上工业增加值增长1.1个百分点；规模以上战略性新兴产业增加值增长2.5%，拉动规模以上工业增加值增长0.5个百分点；

（二）投资增速稳中有升

1-8月份，全市固定资产投资完成1402.84亿元，同比增长7.1%，增幅比1-7月份提高0.5个百分点。其中，8月当月增长12.4%,增幅比7月当月（增长2.7%）提高9.7个百分点。从三次产业看，第一产业投资49.14亿元，增长219.2%；第二产业投资384.28亿元，下降5.7%；第三产业投资969.41亿元，增长9.3%。从主要领域看，基础设施投资完成442.93亿元，增长17.2%，增幅高于固定资产投资10.1个百分点，拉动固定资产投资增长5.0个百分点。其中市政建设投资增长28.8%，水利管理业投资增长146.9%。从主要支撑看，截至8月末，新入库项目794个，同比增加235个，计划总投资1443.03亿元，增长45.4%，1-8月份完成投资647.01亿元，增长40.0%；亿元及以上项目投资完成913.89亿元，增长6.7%，拉动固定资产投资增长4.4个百分点。

（三）市场消费平稳增长

1-8月份，社会消费品零售总额完成1226.12亿元，同比增长1.7%，增幅比1-7月份提高0.2个百分点。其中，8月当月增长3.7%,增幅比7月当月（下降4.8%）提高8.5个百分点。从商品类别看，限额以上文化办公用品类、服装类、石油及制品类、家具类和鞋帽类零售额分别增长111.1%、43.9%、17.3%、16.5%和16.0%，共拉动社会消费品零售总额增长4.1个百分点。从零售模式看，限额以上网上商品零售额243.98亿元，增长2.9%，拉动社会消费品零售总额增长0.6个百分点。从新型消费看，绿色化、智能化、数字化消费不断升级，限额以上可穿戴智能装备、新能源汽车零售额分别增长49.2%和34.7%，拉动社会消费品零售总额增长0.2个百分点。

（四）财政收入增幅持续快于全省

1-8月份，全市一般公共预算总收入154.93亿元，剔除增值税留抵退税因素，同口径增长0.7%，增幅高于全省平均水平0.7个百分点。其中，一般公共预算收入107.98亿元，同口径增长5.7%，增幅高于全省平均水平1.8个百分点。一般公共预算支出174.19亿元，增长5.0%。

（五）物价水平温和上涨

1-8月份，市区居民消费价格总水平同比上涨1.3%，涨幅比全省平均水平低0.4个百分点。八大类消费“六增两降”，其中：交通和通信类上涨7.0%，其他用品和服务类上涨2.2%，食品烟酒类价格增长1.2%，衣着类价格上涨1.1%，生活用品及服务类价格上涨0.4%，居住类价格上涨0.2%，医疗保健类价格下降1.1%，教育和文化娱乐类价格下降0.4%。

（六）要素保障总体稳定

从金融存贷款看，8月末，全市金融机构本外币各项存款余额2816.93亿元，同比增长14.4%，增幅比7月末提高0.9个百分点；金融机构本外币各项贷款余额2651.30亿元，增长10.8%。从交通运输看，1-8月份，公路运输总周转量31.20亿吨公里，下降3.8%，降幅比1-7月份收窄0.6个百分点；水路运输总周转量17.98亿吨公里，增长16.2%。

二、存在问题

（一）工业下行压力较大。一是小微企业负增长。占规模以上工业企业数80.1%的小微工业企业增加值下降7.0%，拉低规上工业增加值增速0.4个百分点。二是企业生产成本持续走高。1-7月份规上工业企业每百元营业收入成本89.07元，同比增加1.47元。三是新增企业贡献不足。11家去年以来新投产企业仅拉动规模以上工业增加值增长0.06个百分点。

（二）部分领域投资下滑。一是房地产投资持续低迷。受新增项目较少、土地购置费大幅下降等因素影响，房地产开发投资下降16.3%，拉低固定资产投资增速3.7个百分点。二是工业投资增幅继续垫底。受工业投资规模偏小、库存投资不足等因素影响，工业投资下降5.4%，拉低固定资产投资增速1.7个百分点，增幅居全省末位。三是民间投资意愿不足。受市场预期的不稳定性和经营风险加大等因素影响，企业的投资能力和意愿下降，民间投资仅增0.8%，增幅比全省平均水平低7.5个百分点。

（三）市场消费恢复较慢。一是退库企业影响较大。截至8月末，全市493家限上退库企业拉低社会消费品零售总额增速4.8个百分点。二是日用品类零售降幅较大。受电商零售促销力度减弱等因素影响，限额以上日用品类零售额下降48.7%，拉低社会消费品零售总额增速2.4个百分点。三是汽车类零售低迷。受疫情、芯片短缺等因素影响，全市汽车类零售额下降3.4%，拉低社会消费品零售总额增速0.2个百分点。

三、对策建议

（一）稳住大盘促发展。一是加强对工业企业重点领域、重点地区、重点行业的企业精准服务，帮助企业开拓市场，推动企业扩产增效、做大做强。有针对性从各行业中挑选发展较好的大型企业重点培养，打造龙头企业带动行业发展。二是大力培育新的经济增长点，特别是要加强先进制造业、专精特新企业的培育工作。三是加快工业新建项目和技改项目的投产达效，从目前的情况看，投产项目不足、潜力仍然较大，要狠抓新建、技改项目投产达效，为工业经济持续增长提供有力支撑。

（二）狠抓项目增动力。一是抓入库，梳理近期各县区已签约的项目，加快推进项目前期工作，争取项目早日开工后入库报数。二是抓进度，积极推进在库项目在确保工程质量安全的前提下，抢抓工期，加快建设，争取形成更多的实物量。三是强信心，根据莆田实际情况持续优化楼市调控政策，以支持刚性和改善性住房需求为目标优化商品房销售、信贷、监管等政策，稳定市场预期，深挖消费潜力，提振市场信心。四是激活力，进一步支持民间资本参与数字经济、海洋经济、绿色经济、文旅经济发展，特别是加大在基础设施、公共服务、资源环境、生态建设等重点领域，切实将放管服改革、营商环境建设的成果体现到激发民间投资活力上。

（三）多措并举促销费。一是深入实施“全闽乐购•约惠莆田”莆田市促消费行动，借助中秋、国庆、双十一、双十二等契机加大促销力度，做好消费券发放工作，扩大促消费成效。二是持续推进步行街、商业综合体、便民生活圈建设，激发不同层次居民的消费需求。三是用好800万元汽车促销资金和550万元家电家居家装促销资金，持续抓好大宗消费促销活动。
