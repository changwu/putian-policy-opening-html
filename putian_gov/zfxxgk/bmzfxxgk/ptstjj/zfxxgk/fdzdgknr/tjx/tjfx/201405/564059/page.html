1-4月份我市规模以上工业稳步增长

发布时间：2014-05-16 00:00
| | |

1-4月份，我市规模以上工业实现工业总产值774.45亿元，可比增长13.8%；实现工业增加值233.72亿元，可比增长13.5%。工业总产值与增加值累计增速虽然比上年同期低2.0个、2.1个百分点，比1－3月份低0.1个、0.1个百分点，但分别比全省平均增速高1.2个、1.3个百分点，稳居全省九设区市第三位，说明我市工业增速总体仍处于合理区间。作为工业经济晴雨表的工业用电量继续保持两位数增长，1－4月份增长19.8%，居全省第二位，显示我市工业经济生产形势总体向好。

一、运行主要特点

（一）运行质量明显改善。我市采取“机器换人”等举措提高工业企业的劳动生产率，不断增强企业的核心竞争力和市场竞争力，从而一举扭转了上个月经济运行质量下滑的不利局面。1-3月份我市规模以上工业经济效益综合指数为312.84，同比提高16.09个点，增幅比1-2月份（-13.98）高30.07个点。其中实现劳动生产率30.86万元/人，比上年同期提高3.39万元/人，比1-2月提高6.93万元/人；实现利润总额24.57亿元，增长11.1%，增幅比1-2月（-2.5%）高13.6个百分点。　

（二）新增企业成亮点。1－4月份，全市109家新增的规下转规上企业共完成工业总产值18.64亿元，比上年同期增长1.8倍，对规模以上工业经济增长的贡献率为12.7%，拉动全市规模以上工业经济增长1.8个百分点。2013年以来18家新投产工业企业实现工业总产值12.77亿元，对全市规模以上工业经济增长贡献率为13.6%，拉动规模以上工业经济增长1.9个百分点，其中今年新投产的赛得利纤维拉动作用较为明显。

（三）内需成为主动力。1-4月份我市规模以上工业实现销售产值758.65亿元，比上年同期增长14.2%，增幅高于总产值增速0.4个百分点，产销衔接良好，产销率达97.96%，比上年同期高0.30个百分点。市场需求趋于旺盛，有利于提高工业企业生产经营的积极性。其中：内销产值达627.50亿元，比上年同期增长15.4%，内销产值占全部销售产值的比重达82.7%，分别比上年同期、2012年1-4月、2011年1-4月高0.9、2.4、3.4个百分点，呈逐年上升态势。

（四）重点企业增势强劲。随着我市鞍钢冷轧钢板产能逐步达产达标，佳通轮胎技术改造完成以及赛得利纤维等大企业的投产，我市重点企业增势强劲。1-4月份我市规模以上超亿元工业企业达213家，共实现工业总产值523.91亿元，比上年同期增长15.5%，增幅快于全市规模以上工业平均增速1.7个百分点，对全市规模以上工业经济增长的贡献率为74.5%，拉动规模以上工业经济增长10.3个百分点。

（五）制鞋产业贡献突出。1-4月份，我市规模以上十大产业集群共实现工业总产值742.18亿元，可比增长14.2%，增幅比全市规模以上工业平均增速快0.4个百分点，对全市规模以上工业经济增长的贡献率达98.0%，拉动规模以上工业经济增长13.5个百分点。作为我市最大产业的制鞋业贡献突出。1-4月份制鞋产业实现工业总产值178.44亿元，增长16.2%，增幅比1-3月份高1.5个百分点，比全市规模以上工业增速快2.4个百分点，对规模以上工业经济增长的贡献率为26.4%，拉动规模以上工业经济增长3.6个百分点。其中，制鞋业当月增幅比3月份高5.5个百分点。主要原因：一是由于今年以来广东等地订单外移，使我市制鞋业订单量大幅增加。二是部分制鞋企业快速增长。如华峰工贸由于NIKE等国内外几大知名产商订单量快速增长，旗下各子公司都保持快速增长态势；永丰鞋业强化成本控制，增加生产线，企业订单充足。

二、存在主要问题

（一）工业生产下行压力加大。受市场低迷、资金短缺等多因素影响，我市部分企业生产下行压力加大。一是减、停产企业依然严重。截止4月末，全市减产企业仍有255家，只比3月末减少16家，减产企业占全市规模以上工业企业数的24.9%，1-4月份累计减产近35亿元，其中减产超过千万的规上企业有73家，比3月末增加12家，减产近三十亿，约占总减产量的85%。另有30家企业停产，比3月末增加7家，影响全市工业产值二十多亿元。二是出口增速放缓。受外需疲软影响，1-4月份我市规模以上工业实现出口交货值131.15亿元，比上年同期增长8.6%，增幅分别比1-3月份、1－2月份低2.1个、0.5个百分点。

（二）劳动力等要素制约依然突出。据调查，今年我市工业企业招工难、留工难等问题依然突出，制约了企业的扩大再生产，同时用工成本逐年增加，工人工资每年以10%-15%的涨幅上涨，这对劳动密集型企业的影响尤为突出。此外，随着我市新型工业化建设步伐的不断加快，一批重大项目发展用地需求和用地供给紧缺的矛盾日益突出，土地刚性缺口给我市工业企业发展带来较大压力。

（三）企业资金问题不容忽视。企业融资难已经困扰我市工业企业进一步生产发展。中小微企业利率高、担保难、贷款门槛高等融资问题并未得到有效缓解，致使一些中小微企业的生产经营面临前所未有的困境。主要表现在中小企业自身无足值的抵押物，有的企业土地为租赁的，厂房无产权证书，无法办理有效的抵押担保，部分企业缺少相关价值证明，很多小企业购买设备时为节省费用，无设备发票，不能证明设备所有者及价值，给办理抵押带来了困难。此外小微企业受自身规模、财力等客观条件的限制，管理水平较低，财务制度并不规范，财务报表的随意性大、真实性不强、透明度和可信度不高，银行难以依据其提供的财务信息全面判断企业生产经营状况，影响了其获得的银行支持。

综上所述，1－4月份我市工业经济运行态势和增长速度仍处于合理区间，但下行压力依然存在。下阶段，要坚定科学发展理念，坚持稳中求进、改革创新，继续扩大积极变化，高度关注工业经济运行中出现的新情况、新问题特别是各种风险，通过全面深化改革来保持合理的工业经济增长速度，在产业结构优化中推进工业经济提质增效升级，努力实现全年预期目标任务。
