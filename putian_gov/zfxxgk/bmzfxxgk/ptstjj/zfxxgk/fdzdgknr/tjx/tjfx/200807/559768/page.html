上半年我市规模以上工业经济运行情况分析

发布时间：2008-07-14 00:00
| | |

在美国次贷危机余波未了、原油期货价格屡创新高、各国通货膨胀压力不断增大等国际经济大环境下，上半年我市规模以上工业克服人民币升值，能源、原材料价格不断上涨等诸多不利因素的影响，继续保持健康、平稳的增长态势。

工业经济运行主要特点

一、工业经济健康发展，运行质量不断向好

上半年，规模以上工业克服了各种不利因素影响，保持健康稳定发展。全市898家规模以上工业企业累计完成产值408.68亿元，可比增长27.2%，增幅比全省平均水平高4.8个百分点，比上个月累计增幅高0.9个百分点，增幅居全省九设区市第四位；累计实现工业增加值136.62亿元，比增23.2%。其中产值超亿元的工业企业达95家，实现工业总产值214.40亿元，比上年同期增长33.8% ，对规模以上工业增长贡献率达58.9%，拉动规模以上工业增长17.6个百分点。

同时工业经济运行的质量和效益稳步提高。作为全市财税重要源头之一的工业经济，其运行质量和效益也不断向好，为全市财政收入的稳定增长提供了坚实的保障。1-5月份，全市工业经济效益综合指数达201.35%,创历史新高，比上年提高26.86个百分点；实现主营业务收入310.76亿元，增长39.7%，利税16.08亿元，增长30.3%，其中实现利润9.54亿元，增长40.8%，从业人员达20.35万人。我市规模工业经济运行状况良好，质量效益在不断改善。

二、十大产业贡献突出

上半年，我市十大产业共完成产值386.14亿元，比上年同期增长29.9%，占全市规模工业比重达94.5%。其中制鞋业率先突破百亿，完成工业总产值107.28亿元，比上年同期增长22.8%，对全市规模以上工业经济增长的贡献率达21.2%，拉动规模以上工业经济增长6.3个百分点，居十大产业之首，成为我市上半年工业经济增长的一大亮点；食品产业实现工业总产值71.52亿元，比上年同期增长24.7%，对全市规模以上工业经济增长的贡献率达15.1%，拉动规模以上工业经济增长4.5个百分点；电子信息产业实现工业总产值43.44亿元，比上年同期增长38.8%，对全市规模以上工业经济增长的贡献率达12.9%，拉动规模以上工业经济增长3.9个百分点。（上半年我市十大产业完成情况见下表）

三、新投产企业拉动明显

随着我市三福古典家具、大家之家古典家具等一批新企业相继投产，为我市工业经济的持续快速发展增添了后劲。上半年我市共新增新投产企业86家，实现工业总产值14.55亿元，对规模以上工业增长的贡献率达15.5%，拉动规模以上工业增长4.6个百分点。其中：城厢区共新增12家，实现工业总产值1.47亿元；涵江区共新增12家，实现工业总产值1.51亿元；荔城区共新增22家，实现工业总产值5.19亿元；秀屿区共新增20家，实现工业总产值1.87亿元；仙游县共新增20家，实现工业总产值4.52亿元。预计下半年我市的LNG、莆田燃气、海安轮胎、七度珠宝等16家较大项目陆续投产后，新投产企业将发挥更大的拉动效应。

四、民营工业蓬勃发展

近年来，我市积极实施民资回归工程，相继在全国各地举办投资项目推介会，在外乡亲投资家乡的热潮不断掀起，民营工业经济实现了超常规、跳跃式的发展，成为我市最具活力和最具发展前景的经济增长点。上半年，全市规模以上民营工业企业达782家，实现产值301.70亿元，增长35.7%，增幅高于规模以上工业平均增幅5.8个百分点，对规模以上工业产值增长的贡献率为84.3%，拉动规模以上工业产值增长25.2个百分点。民营企业成为拉动我市工业增长的主要力量。

五、内需拉动明显,出口增势回落

上半年，全市规模以上工业企业实现销售产值401.92亿元，比上年同期增长31.3%；产销率98.35%，同比提高1.1个百分点，产销衔接良好。其中实现国内销售产值296.66亿元，比上年同期增长46.5%,增幅同比提高4.6个百分点；实现出口交货值105.26亿元，比上年同期增长1.7%，增幅同比回落12.6个百分点，出口交货值占工业销售产值的比重为26.2%，同比下降8.2个百分点。

工业经济运行存在的问题

制约因素：

一、生产要素紧缺仍制约规模工业持续发展。（1）土地。目前我市项目用地严重偏少。国家严格项目用地审批管理后，工业用地采用招标、拍卖、挂牌的方式出让，用地成本费用大幅度提高。项目用地存量少和土地使用费大幅提高直接影响到工业项目的落地。（2）资金。由于国家宏观调控，银根收紧，银行信贷权限的上收、企业担保条件的提高、商业银行资本充足率的限制等原因，企业资金短缺的矛盾依然存在，多数企业尤其是中小型民营企业融资难现象较为普遍，融资难已成为制约企业发展的瓶颈。一些企业因资金制约不仅生产速度受到了影响，连急于新上的项目也不得不放慢进度。（3）劳工。我市工业企业主要是以劳动密集型生产企业为主，“工荒”现象仍未从根本上得到缓解。目前全市工业企业用工缺口仍达6万多人。企业招工难，招收熟练的员工更难。员工不足直接影响经营生产和项目进度，对新项目报批落地、企业增资扩股也产生负面影响。

二、国际市场需求减弱、人民币升值和出口退税政策调整等因素制约我市企业进一步发展。受美国次贷危机影响，全球经济速度放缓，国际市场存在较多不确定因素，部分外向型企业国际订单减少。上半年我市规模以上工业出口交货值仅增长1.7%，同比回落12.6个百分点，其中：电子信息业下降4.6%、食品业下降30.8%、纺织业服装业下降25.9%、林产加工业下降16.8%、机械制造业下降18.9%。而国内出口退税率下调、人民币加速升值、国家实行从紧货币政策、银行不断加息、原材料涨价等使企业利润空间减少，影响生产积极性。

存在问题：

一、名牌企业增长缓慢。近年来我市大力发展品牌经济，利用品牌效应来提高区域或企业产品竞争力，壮大企业规模，带动区域经济进一步发展。但是上半年我市9家获中国名牌产品企业，实现工业总产值37.66亿元，比上年同期增长13.3%，低于全市平均水平16.6个百分点，品牌效应没有得到充分显现。

二、工业规模总量小，轻重比例欠合理。我市工业不论是规模体量或是数量均只有全省的1/19左右,与所处海西地带不相符。在现有898家规模企业中，企业规模小特征突出，2007年产值超10亿元的仅5家，最大的佳通也不到30亿元，与其他设区市相比明显偏小。在轻重工业结构方面，上半年轻工完成产值299.8亿元，重工完成108.9亿元，轻重比例73：27，与全省47：53差距较大。尽管近年来重工增幅一直快于轻工，但因其结构占比偏低，整体优化步伐缓慢。工业规模小和重工发展滞后是我市工业总量在全省一直难以提升的主要原因。

三、企业自主创新意识较为薄弱。全市898家规模以上工业企业中，有科技活动投入的企业只有66家，有新产品生产的企业只有20家，实现产值9.14亿元，下降1.9%,即九成以上工业企业没有科技投入和新产品。由于企业自主创新意识差，投入不足，导致企业综合竞争力不强，市场抗风险能力弱。

四、行业分布仍以传统产业、劳动密集型企业、加工类企业为主。我市工业产业层次偏低，占全市一半的制鞋、电子、纺织等均属劳动密集型行业，产品以贴牌生产为主，科技含量不高，附加值低，产业核心竞争力不强，抗风险能力弱，在目前宏观政策和严峻经济形势下，必须鼓励帮助这类企业转型升级，避免遭受重新洗牌。

工业经济运行对策及建议

一、加大招商引资力度。为增强我市工业发展后劲，需要加大招商引资力度，继续强化招商引资的重要地位，完善考核激励机制，创新招商办法，积极拓展招商领域。积极探讨企业招商途径，充分利用现有资源，大力引进现代制造业，尤其要重点引进工业大项目，有了工业大项目，才有工业的大投入。要以工业的大投入为坚强后盾，确立我市工业经济在全省、全国的地位。

二、造就企业品牌。在当今社会，企业要立于不败之地，就必须不断创新，更新自己的产品，形成“一代产品在销售，二代产品在生产，三代产品在研究”的格局，来提高产品的技术含量和附加值，巩固和发展产品的市场空间。企业只有掌握以高新技术为后盾的专门品牌才能在激烈的市场竞争中拔得头筹。在实施品牌战略中还必须保持技术的更新和升级，做到“人无我有，人有我优，人优我新，人新我精”，才能有效地提高产品附加值，迅速地扩大企业规模，增强企业的发展后劲。

三、关注“汇率”变动，积极应对国际贸易纠纷。人民币汇率改革，实行浮动汇率制，扩大汇率波动范围，经营出口贸易的企业感受到人民币升值所带来的压力。应考虑加强对外汇市场的研究，预测汇率变动，并建立相应的定期公布机制，供企业进行进出口贸易时参考。面对贸易纠纷，过去企业出于成本考虑，鲜有企业应诉，使出口企业遭受重大损失。政府应协助企业建立反倾销指控的应诉机制，积极应对反倾销指控，并借鉴其他国家经验，在应对反倾销指控中，充分发挥行业协会的作用。

四、提高务工薪酬待遇，改善劳动者务工环境。要提高员工工资待遇。政府部门应加强引导和宏观调控，把调整提高员工工资待遇摆到突出位置，根据当地经济社会发展水平适时调整最低工资标准，提高工资总体水平；要多渠道发布劳动力市场工资指导价位，引导企业参考当地劳动力市场工资指导价位，确立合适的工资水平，增强企业的吸引力；要创造良好的生产生活和治安环境。坚持以人为本，实行人性化管理，提高员工的工作积极性和主动性，增强员工的归属感。

                                      （撰稿：黄蓓芳）
