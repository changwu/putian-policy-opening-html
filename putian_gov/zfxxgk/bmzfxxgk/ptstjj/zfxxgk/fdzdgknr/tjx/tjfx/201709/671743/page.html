1-7月莆田市建筑业生产情况分析

第五十五期
发布时间：2017-08-14 11:30
| | |

一、全市建筑业企业生产情况

（一）建筑业发展增速强劲。从注册地看，1-7月全市资质内建筑业企业完成建筑业总产值346.05亿元，同比增长31.0%，增速位居全省第一，增速较上年同期提高28.4个百分点，较上半年提高15.7个百分点。增速高是由于去年1-7月三家一级建筑企业迁至厦门，基数减少，拉高全市增速12.1个百分点。从项目所在地看，1-7月省外入莆建筑产值61.79亿元，同比增长24.7 %，增速较上半年下降0.5个百分点，增速较上年同期增加47.4个百分点。

（二）新签合同额增速下降。1-7月签订的合同额771.13亿元，同比增长16.2%，增幅较上年同期提高8.0个百分点，较上半年回落9.5个百分点。本年新签订的合同额437.33亿元，同比增长14.1%，增幅较上年同期回落28.3个百分点，较上半年回落24.3个百分点。新签订合同额增速下降，建筑业发展后劲有所减弱。

（三）“走出去”战略继续发挥作用。1-7月全市在外省完成的产值133.23亿元，同比增长33.0%，增速较去年同期回落34.7个百分点，占全部产值的38.5%，比重较去年同期提高0.6个百分点。范围涉及27个省，其中江西、重庆、四川、广东产值均超过十亿，合计59.99亿元，占全部外拓产值的45.0%。目前我市建筑企业除了在北京、内蒙古、西藏没有工程外，在全国各省都已安营扎寨，工程量稳步提高。

（四）工程施工速度加快，竣工率提高。1-7月完成竣工产值190.89亿元，同比增长71.3%，增速较上年同期提高95.9个百分点。1-7月房屋竣工面积为548.11万平方米，同比增长30.8%，其中房屋住宅房屋面积378.94万平方米，同比增长19.0%，占全部房屋竣工面积的69.1%。全市房屋建筑施工面积4052.36万平方米，同比增长24.4%，增速较上年同期提高17.6个百分点。房屋竣工率为13.5%，较上年同期提高0.6个百分点。

二、各县区建筑业企业生产情况

从注册地数据来看，1-7月荔城、城厢两区建筑业依然领跑全市，建筑业总产值双双超过90亿元，分别达到97.38亿元、91.67亿元，两区建筑业总产值共占全市建筑业总产值的54.6%，比上年同期下降2.7个百分点。

从各县区建筑业总产值增长情况看，北岸、秀屿区增速最高，分别达89.1%、82.8%。北岸增速高是由于去年1-7月巨龙建设迁至厦门，基数减少，拉高全区增速66.4个百分点。秀屿区增速高是由于去年1-7月中环宏岸迁至厦门，基数减少，拉高全区增速82.1个百分点。

三、我市建筑业发展的建议

（一）转变产业发展方式。建筑业要获得可持续发展，必须加快转变生产方式。在“供给侧改革”的政策背景下，建筑行业必须改变传统的劳动密集型、粗放式的生产方式，推行建筑工业化、生产经营集约化、绿色环保化。目前我市建筑行业以中小企业为主，多沿袭传统的发展模式，要企业摒弃旧的落后的生产方式，需要从思想上放长远，完成转变还需要很长一段时间。

（二）优化产业结构。产业结构直接关系到建筑业的供给能力和水平，因此建筑业需控制产能过剩类行业工程的增加，如资源类工业、房地产工程项目等，对现有存量进行优化、消化；加大民生类工程及绿色智能类建筑工程的投资和政策支持，如公共交通、水利、环保、养老、绿色智能建筑等工程项目。当前国内推行的“装配式建筑”需要大规模生产才能降低成本，“PPP模式”多为大型国有企业承包，我市建筑企业多为传统中小型企业，在转型升级上难度较大，目前两者几乎都是空白。

（三）推进科技创新和技术进步。要素投入是“供给侧改革”的重要内容之一，随着“人口红利”的逐步消失，建筑业应提升劳动力素质供应，加大创新要素投入，提高企业的创新能力和科技含量，提高各建筑相关要素的利用效率。从根本上说，就是人才和技术，两者缺一不可。

（四）加大政府扶持力度。一是抓紧落实扶持文件。面对改革转型的关键期，企业的发展需要政府做好服务。任何一项措施或变革都需要配套制度的支持才能真正落实。各级各有关部门应加大对《关于促进建筑业发展壮大的实施意见》（莆政综[2016]158号）的落实力度，同时定期走访重点企业，听取企业家意见，解决企业实际困难。二是继续鼓励走出去战略。“走出去”战略既可以消化市内建筑企业产能过剩，又能提升建筑业整体竞争力。要加大对“走出去”战略的政策解读与宣传，鼓励企业主动改变旧的经营模式。由于我市建筑企业以中小企业为主，综合竞争力不强，走出去战略可从中西部开始，进一步拓展省外建筑市场。
