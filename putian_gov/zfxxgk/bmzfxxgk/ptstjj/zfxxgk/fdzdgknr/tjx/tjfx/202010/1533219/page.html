2020年前三季度莆田市固定资产投资情况分析

第五十八期
发布时间：2020-10-19 17:34
| | |

前三季度，全市固定资产投资同比下降4.0%，速度比全省平均水平低5.4个百分点，降幅比1-8月份收窄0.2个百分点。其中，项目投资同比下降1.7%，降幅比1-8月份收窄1.2个百分点，房地产开发投资同比下降11.9%，降幅比1-8月份扩大2.9个百分点。

一、运行情况

1、在建亿元项目快速增长。我市投资主要靠大项目拉动，前三季度全市亿元以上项目290个，比上年同期多55个，计划总投资和本年完成投资同比分别增长24.3%、19.6%，其中亿元新开工项目111个，比上年同期多9个，计划总投资同比增长5.1%。

2、农业投资较快增长。今年以来，我市加大农业方面的投资，前三季度我市农业投资由上年同期的下降28.9%转为增长15.5%，其中林业、畜牧业、渔业投资分别增长109.5%、154.3%、182.7%。

3、社会领域投资稳定增长。前三季度社会领域投资同比增长13.7%，增幅比1-8月份、上年同期分别提高1.8、14.1个百分点，其中教育业投资同比增长18.1%，卫生和社会工作投资同比增长16.2%，文化、体育和娱乐业投资同比增长7.1%。

4、高端制造业投资高速增长。前三季度，制造业中的高技术制造业同比增长49.6%；装备制造业同比增长23.9%；先进制造业同比增长19.3%。

二、存在问题

1、投资处于较低水平。前三季度我市投资降幅虽然较1-8月份收窄0.2个百分点，但与全省平均水平相差较大，速度位居全省末位，特别是房地产开发投资同比下降11.9%，是全省二家负增长设区市之一。投资中项目投资速度比全省平均水平低0.6个百分点，房地产开发投资速度比全省平均水平低18.9个百分点。

2、基础设施投资亟待加强。前三季度全市基础设施投资同比下降8.0%，降幅同比扩大2.1个百分点。其中交通运输业投资同比下降27.8%，降幅比1-8月份、上年同期分别扩大1.1、6.8个百分点；水利、环境和公共设施管理业由上年同期的同比增长8.5%转为下降8.0%。

3、民间投资下滑明显。前三季度民间投资同比下降18.1%，降幅比1-8月份扩大3.5个百分点，速度比全省平均水平低20.2个百分点，占固定资产投资比重为56.1%，比上年同期低7.9个百分点。

三、建议

1、重储备。要落实省里“八项行动”要求，深化“五个一批”项目推进机制，围绕重点投资领域，瞄准关键领域和薄弱环节，谋划实施一批重点项目，特别是新型基础设施建设、老旧小区改造、重点片区改造等方面，提高项目储备数量和质量。

2、促进度。发改委要梳理今年以来已签约项目，加快推进项目前期工作，争取年内开工；住建局要督促今年重点片区改造项目如龙德井、沟头片区改造的实施进度；市自然资源局、住建局要督促已拍地未动工的项目尽快动工，力争房地产开发投资速度能转正。

3、抓入库。从今年的入库情况来看，全市投资项目较上年同期少了四分之一，因此入库工作至关重要，各行业主管部门（发改、工信、交通、住建等）要配合统计部门，梳理各自分管领域的投资项目，分类比对，抓好入库工作。对已开工项目，要督促业主按规定的时间节点上报规范有效的入库材料；对拟开工项目，提前做好服务和监督工作，争取在开工的同时进行项目入库申报工作；对未开工项目，发改委要与项目主管部门互相配合，梳理全市重点项目中的未开工项目，做好项目前期服务工作，及时协调解决项目开工过程中存在的困难和问题，确保每个项目按计划如期开工。

4、强指导。市县（区）统计部门要指导项目业主上报规范的入库材料，提高项目入库的有效性。月报期间要加强对新入库项目业主的上报指导培训工作，使企业统计人员能够掌握投资业务知识，保证及时、准确、全面报送投资报表，并重点关注月度综合数据及重点领域投资的波动情况，及时汇报、预警投资运行情况。
