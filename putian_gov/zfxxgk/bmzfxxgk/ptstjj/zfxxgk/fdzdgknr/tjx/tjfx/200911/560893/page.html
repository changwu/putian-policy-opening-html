危机持续减弱 就业有所好转

发布时间：2009-11-09 00:00
| | |

金融危机对我市外向型经济的影响继续减弱，就业形势随经济的好转而逐渐复苏。截至2009年9月底，全市城镇从业总量同比仍有下滑，但延续了前一季度的平稳回升态势，政府经济刺激计划被证明是持续有效的，随着各项措施的陆续到位，就业容量将逐步扩展。

一、基本情况

（一）城镇就业总量保持环比微增

截至9月底全市城镇从业人员为27.27万人，较上年同期减少0.73万人，下降2.6%，其中在岗职工为26.45万人，减少0.64万人，下降2.4%，但与今年二季度末相比，基本持平，延续了二季度以来平稳微增的态势。从不同经济类型看：

1、国有单位从业人数为93561人，同比减少233人，下降0.2%，下降幅度较上季度减少0.8个百分点，主要原因是房地产回暖带来的建筑企业从业人员的流动。

2、城镇集体单位人数10641人，同比减少1073人，下降11.5%，比上季末减少788人，下降6.7%，主要原因是建筑企业人员流动性增加以及部分集体单位的改制。

3、其他所有制单位人数168470人，同比减少5724人，下降3.3%，较上季末则增加了1402人，增长0.8%，延续了二季度以来的环比增长，经济刺激措施被证明是持续有效的。其他所有制单位是吸纳劳动就业的最强载体，其发出的增容信号表明经济进一步企稳回升。但是，目前企稳回升的基础并不牢固，外围经济金融风险仍然存在，各经济体在风暴过程中不同程度受损，完全恢复尚需时日。

（二）职工工资总额持续增长

截至2009年9月底，全市从业人员前三季度劳动报酬总额为46.61亿元，比上年同期增长10.8%，其中在岗职工工资总额45.36亿元，同比增长11.6%，基本维持了上季度的增长速度，主要是由于机关及部分事业单位工资改革中阳光福利的补发，其他所有制单位由于人员增长变化较小，工资总额增长不明显。

1、国有单位在岗职工工资总额为20.83亿元，比上年同期增长22.7% 。

2、城镇集体单位工资总额为1.72亿元，比上年同期增长12.2%。

3、其他单位工资总额为22.82亿元，比上年同期增长3.2%。

（三）平均工资稳步增长

一方面受机关事业单位工资改革的影响，另一方面由于经济危机使不少企业进行了减员，前三季度平均在岗人数较大下降，从而导致平均工资的持续提高，因此，2009年全市前三季度从业人员平均报酬为17130元，同比增长15.9%；在岗职工平均工资为17249元，增长17%，平稳快速增长。

1、从国有、集体、其他单位分组来看，国有单位在岗职工平均工资为23769元，同比增长21.1%。主要由于县区机关单位及教育系统事业单位阳光福利实行，使工资水平持续保持上升势头；城镇集体单位在岗职工平均工资为16077元，同比增长11.3%，由于建筑行业低工资人员以及改制单位人员减少，造成了平均工资的相对增加；其他所有制单位在岗职工平均工资为13855元，同比增长11.8%，受金融危机影响，目前以制造业为主的其他所有制单位仍处在休整阶段，从业人数未有大幅度的回升，企业低工资人员相对减少，使得平均工资保持了一定的增长速度。

2、从企业、事业、机关单位分组来看，企业单位在岗职工平均工资为15562元，同比增长12.8%；事业单位在岗职工平均工资为21154元，同比增长25.1%；机关单位在岗职工平均工资为24573元，同比增长24%。由于机关事业单位存在阳光福利补发的情况，因此工资增速略高于其他类型单位。

3、从国民经济各行业看，除信息传输、计算机服务和软件业、租赁和商务服务业略有下降外，其他行业职工工资都有不同程度的增长。我市各行业中前三季度平均工资最高的为金融业41284元/人，其次是信息传输、计算机服务和软件业37346元/人，第三为垄断性的电力、燃气及水的生产和供应业34561元/人。而工资最低的为采矿业7827元/人，其次是住宿餐饮业10728元/人，第三为农林牧渔业13346元/人。平均工资最高行业与最低行业的差比为5.27：1，比上季末略增0.76个点。

（四）离开本单位仍保留劳动关系的职工情况

离开本单位仍保留劳动关系的职工前三季度平均生活费为2612元，较去年上升了3.2%。离岗保留劳动关系职工人数3827人，比上年同期增加327人，增长9.3%，主要是由于第三季度改制企业的增加。

二、存在问题

（一）企业吸纳就业力量仍显不足。虽然政府经济刺激计划的实施已初现成效，不少企业也陆续复工，但金融危机影响不是在短期内可以消除的，所以企业吸纳劳动力就业的力量仍然不足，需要一段时间的恢复，就业增容非一朝一夕所能完成。

（二）金融危机中劳资矛盾时有发生。由于金融危机中劳动力市场呈现供大于求的形势，部分企业利用员工不敢离职、求职者求职心切的心态，拖欠工资，克扣福利，不签署劳动合同或不按照合同办事，损害了劳动者利益，也损害了自己的用人声誉。

三、建议

（一）进一步落实就业促进计划。加大宏观调控力度，继续实行宽松的财政政策和货币政策，强化企业信心，对中小企业融资给予相应的优惠政策，尽量减轻中小企业负担，鼓励外贸出口企业积极寻找出路，利用国内市场拉动生产，稳固就业基础。

（二）保护劳动者的合法权益。积极推进社会保障制度的进一步建立和完善，规范劳动力市场秩序，及时解决劳资纠纷，帮助企业建立起长效用人、以人为本的理念，营造和谐的劳资关系，充分维护双方的合法权益。
