2006年莆田市人口状况简析

发布时间：2007-04-03 00:00
| | |
据2006年人口变动情况抽样调查资料显示，2006年我市人口状况呈现：继续保持低速增长，人口流动日趋频繁，人口密度偏高，大专及以上学历人口比重有所提高，家庭规模趋向小型化，婚姻状况稳定，人口老龄化程度进一步加大，出生人口性别比仍然失衡等特点。
一、总人口继续保持低速增长
2006年底，全市户籍总人口306.97万人，常住总人口282万人，比上年增加1万人，出生率12.8‰，死亡率6.0‰，自然增长率6.8‰，与上年相比出生率、死亡率、自然增长率分别上升0.3、0.2、0.1个千分点，仍保持低增长态势。
二、人口流动日趋频繁
随着市场经济的不断发展，人口流动日趋频繁。据2006年人口变动情况抽样调查结果显示，本调查年度内离开户籍所在地半年以上人口占总人口的比重为32.7%,比上年上升6.1个百分点。在常住总人口中，发生市内跨乡镇流动的人口所占比重为6.75%，比上年提高0.24个百分点；从市外流动来的人口所占比重为8.33%，比上年提高0.38个百分点。说明我市人口流动日趋频繁，且属于人口净流出地区。
三、人口密度偏高
截止2006年底，我市每平方公里人口数达684人，高出全省每平方公里293人的1.33倍，比2000年末增加22人。多年来，我市一直是全国、全省人口密度较高的地区之一。1990年人口普查时为637人，2000年末达到662人。较高的人口密度对于我市这样一个地域面积小、人口基数大、自然资源短缺的地区来讲，对经济社会的全面协调和可持续发展产生较大的压力。
四、大专及以上学历人口有所增加,但比重仍然偏低
2006年人口变动情况抽样调查结果显示，本调查年度内,大专及以上文化程度人口占6岁以上人口比重为3.36%，比去年提高0.72个百分点，但仍大大低于全省平均水平5.3%的1.94个百分点，主要是由于我市的产业层次较低，能够吸引较高学历人才的高新技术产业还未形成支柱产业，输送出去的莆籍大学生回乡就业的人数比重较低，而流入人口大多属于劳动密度型或劳动强度高的手工从业人员，文化程度普遍偏低。
五、家庭规模继续趋向小型化
家庭是组成社会的重要细胞。随着社会的发展和变革，家庭类型、规模和结构都在不断发生变化。调查资料显示， 2006年家庭户规模为3.28人，比2000年减少0.6人，呈逐年缩小的趋势。家庭户规模趋向小型化，两代户成为家庭户主体的格局，对今后家庭养老模式、独生子女教育、居民住房需求等将产生较大的影响。
六、人口婚姻状况稳定
2006年，全市15岁以上人口中有婚姻经历的人数所占比重为82.4%。虽然随着思想观念和生活方式的改变，人们对婚姻的看法有所变化，但总体而言，我市人口的婚姻状况稳定性较高，从2000年以来，初婚有配偶的比重始终保持在70%以上。从性别差异来看，男性未婚人口比重比女性高出4.1个百分点，这跟男性相对晚婚有很大关系；男性离婚比例比女性高0.3个百分点，这与男性在经济和社会地位中所处位置相对优势有一定关联；男女丧偶比例之间差别明显，女性高出男性7.1个百分点，这主要是由于期望寿命的性别差异引起的。

七、人口老龄化程度进一步加大
随着人民生活水平的不断提高和医疗卫生条件的改善，人的寿命不断延长，人口年龄结构逐渐趋向老化。2006年人口变动情况抽样调查结果显示，本调查年度内我市人口年龄结构为：0—14岁人口比重21.82%，比去年上升0.77个百分点，15—59岁人口比重62.91%，比去年下降3.49个百分点， 60岁以上人口比重为15.27%，比去年提高2.72个百分点，其中65岁以上人口比重11.31%，比去年提高2.16个百分点，比2000年第五次人口普查提高4.08个百分点，超过国际上老年型社会的一般标准（65岁以上人口比重超过7%）的4.31个百分点，说明我市已完全进入老年型社会。
八、出生人口性别比有所回落,但仍失衡
人口性别比有其内在规律，长期失调将会造成严重的社会问题。据2006年人口变动情况抽样调查结果显示，全市常住人口中，男性占总人口的48.24%，女性占总人口的51.76%。性别比（以女性为100，男性对女性的比例）为93.19。与去年相比，性别比提高了1.12。出生人口性别比为115.3,近几年来首次出现低于全省平均水平，低于全省平均水平118的2.7个点，比2000年第五次人口普查的出生人口性别比125.5下降10.2个点。这是我市各级党委、政府采取各种切实有效措施，打击人为造成出生人口性别比畸形的结果。但仍存在出生人口性别比失衡的问题(正常出生人口性别比为97～107)，必须引起各级政府和领导的高度重视。
                            （撰稿：黄国强）
