工业经济快速增长 运行质量明显提高

发布时间：2007-09-21 00:00
| | |
今年以来，全市上下认真落实市委、市政府提出“增幅不能降、位次不能退、序时不能慢”的目标要求，突出发展工业经济，取得良好成效。全市规模以上工业产值继续保持高速增长,工业经济运行的速度、质量及效益协调发展，成为推动全市经济增长的主要动力。
一、工业经济运行现状
1、工业经济快速增长，经济效益不断向好。1－8月份，我市工业经济在去年平稳增长的基础上加快发展， 710家规模以上工业企业实现工业增加值145.79亿元，完成序时进度66.3%，可比增长23.9%，比上半年快0.8个百分点。上半年规模工业对全市GDP贡献率达60.2%，拉动全市GDP增长9.9个百分点，成为经济发展的主旋律；1-8月份实现工业总产值408.76亿元，突破400亿元大关，完成年计划产值605亿元的67.6%，可比增长28.1%，继续保持去年以来的高速增长势头。规模以上工业用电量为11.60亿千瓦小时，比上年同期增长19.6%，与规模以上工业的增长速度基本相当。
作为全市财税重要源头之一的工业经济，其运行质量和效益也不断向好，为全市财政收入的稳定增长提供了坚实的保障。1--8月份规模以上工业企业实现综合效益指数为179.31%，比上年同期提高21.95个百分点。主营业务收入完成361.05亿元，比增37.6%。利税总额22.29亿元，比上年同期增长29.1%，其中：利润总额13.04亿元,比去年同期增长39.5%。
2、吸纳就业人数、土地产出不断提高。今年来我市规模工业经济的快速发展，形成了巨大的劳动力需求，成为劳动就业的主要渠道，社会稳定的基本因素。1－8月份规模工业企业就业人数达20.04万人，比上年同期增长11.2%。其中：涵江区5.09万人，比增6.3%，荔城区5.09万人，比增17.1%，仙游县3.00万人，比增5.8%，城厢区2.86万人，比增18.6%，秀屿区1.92万人，比增13.7%。
我市在大力发展规模经济，迅速壮大经济总量的同时，坚持走土地集约化利用路子，土地产出率不断提高。上半年我市土地每亩产出率（工业总产值/土地面积）为153万元，比上年同期高12万元，其中涵江区229万元/亩，城厢区157万元/亩，荔城区142万元/亩，仙游县128万元/亩，秀屿区83万元/亩。
3、品牌建设再创佳绩。近年来我市积极实施品牌战略，努力打造名牌产品，取得了显著成绩。金秋时节我市继“雪津”啤酒、“卡朱米”羽绒服、“三棵树”涂料、“沃特”篮球鞋之后，又有 “东南香”大米、“保兰德”箱包、“天下农庄”大米、“云敦”衬衫、“才子”衬衫等5个产品荣获2007年中国名牌产品称号。1-8月份9家中国名牌产品企业实现工业总产值24.45亿元，比上年同期增长67.2%，对规模经济的贡献率达10.4%,拉动规模以上工业增长3.1个百分点。
4、十大产业集群成为工业经济的新格局。
产业集群是我市规模经济的全新演绎。近年来特别是今年我市把培育和发展产业集群作为落实科学发展观的重要保证、提升我市经济综合竞争力的必然要求和实现我市“经济翻番、港城崛起”目标的战略决策。目前我市已形成了制鞋、林产加工、食品、电子信息、化工、能源、纺织服装、机械制造、工艺美术、医药医疗器械等十大产业集群的经济格局。1－8月份全市十大产业集群工业企业达650家，比年初增加44家，实现工业总产值387.04亿元，比上年同期增长29.3%，产值占规模工业比重达94.7%。具体产业产值完成情况见下表：

5、新经济增长点和民营企业对工业增长拉动明显。1-8月份，工业经济增长的支撑条件得到加强。主要体现在：一是全市53家省级工业新经济增长点企业共完成产值114.86亿元，比去年同期增长33.9%，新增产值29.96亿元，完成全年新增产值计划29.1亿元的102.96%，提前四个月完成全年目标任务。新增长点企业产值占全市规模工业产值408.76亿元的28.1%，对规模以上产值增长贡献率达31.8%，拉动全市规模以上工业增长8.9个百分点，促进作用继续增强。二是民营企业支撑有力。全市589家规模以上民营工业企业共完成产值272.28亿元，比增38.1%,比全市平均增幅高8.2个百分点，民营企业对全市规模工业增长的贡献率达79.9%，拉动规模工业增长23.9个百分点。
6、轻重工业协调发展，产销街接良好。
今年来我市轻重工业呈现出生产协调发展，效益同步提高，携手为莆田市工业生产和经济效益大幅增长作贡献的良好态势。1-8月份规模以上轻工业企业完成工业总产值298.77亿元,比上年同期增长30.8%;重工业企业完成工业总产值110.0亿元,比上年同期增长27.5%，呈现出同步增长的发展态势。
1-8月份,我市规模工业累计完成销售产值396.97亿元,增长30.2%，产品销售率达97.1%,比去年同期提高了1.6个百分点，产销衔接良好。
二、存在的主要问题
1、县区工业发展与用电增长不协调。1-8月份，各县（区）规模以上工业都达到两位数的增长，但工业发展与用电增长不协调。其完成的产值和按可比增长速度依次为：仙游产值50.99亿元,可比增长35.1%；城厢产值39.75亿元, 可比增长32.6%；涵江产值178.58亿元，可比增长31.6%；荔城产值77.40亿元, 可比增长25.3%；秀屿产值55.04亿元, 可比增长15.6%。规模企业用电量增长依次为；荔城区24.3%、仙游县22.2%、城厢区16.1%、涵江区17.7%、秀屿区20.8%。
2、大中型工业企业增长速度低于全市平均水平。大中型工业企业是一个地区经济发展的重要动力。但今年以来我市大中型工业企业的增长速度一直低于全市平均水平（见下表），在一定程度上制约了我市工业经济增速的进一步提升。1-8月份我市大中型工业企业实现工业总产值186.20亿元，比上年同期增长16.8%，低于全市平均水平13.1个百分点。

3、新投产企业的贡献率达不到预期。今年1－8月份我市共新增新投产企业57家，完成产值11.86亿元，仅占规模以上工业产值的2.9%，平均每家产值仅为2081万元，对规模以上工业经济贡献率为12.6%，拉动规模以上工业增长3.8个百分点。新投产工业企业中缺乏大项目，对全市工业增长的贡献、带动作用不明显。其中：城厢区新投产企业12家，完成产值1.80亿元；涵江区新投产企业12家，完成产值1.41亿元；荔城区新投产企业11家，完成产值4.51亿元；秀屿区新投产企业14家，完成产值2.17亿元；仙游县新投产企业8家，完成产值1.98亿元。
4、企业自主创新能力不强。产业层次相对较低，大量集中在一些技术简单、投资不大、易于模仿、便于进入的粗放型劳动密集型产业，技术创新能力偏弱，新产品研发力度不够，缺少国家级技术中心，工艺设备落后，产品档次低，产品科技含量低，附加值不高，高新技术企业少，低水平加工企业多，市场竞争力弱。
三、影响工业经济运行的主要因素分析及走势预测
1、国际贸易壁垒、人民币升值和出口退税政策调整等因素制约我市出口企业进一步发展。近年来，由于内部产业结构升级缓慢和人民币持续升值、出口退税率调整、贸易摩擦加剧等外部环境趋紧的双重压力，我市规模以上工业出口外向度不断下降。1-8月份累计我市工业品出口交货值增长16.9%，比销售产值增幅低13.3个百分点。工业外向度34.3%,比去年同期下降了5个百分点。主要是由于化工（-12.89%）、工艺品（-10.74%）、电子（-6.05%）、制鞋（-6.06%）、机械（-4.52%）等行业出口外向度下降较大引起的。
2、生产要素紧缺制约规模工业持续发展。（1）土地。在国家严把土地关口的情况下，全市用地指标严重不足。伴随着“十一五”规划的实施，各地新上项目积极性很高，用地紧张问题也日益显现，可用土地资源越来越少，影响了招商引资工作，部份技改项目无法开工，一些外资项目也无法实施。（2）资金。由于国家宏观调控，银根收紧，银行信贷权限的上收、企业担保条件的提高、商业银行资本充足率的限制等原因，企业资金短缺的矛盾依然存在，多数企业尤其是中小型民营企业融资难现象较为普遍，融资难已成为制约企业发展的瓶颈。一些企业因资金制约不仅生产速度受到了影响，连急于新上的项目也不得不放慢进度。（3）劳工。据许多企业反映，现阶段熟练工人相当缺乏，技术工人和管理人员也比较难找,招工难已经对我市经济进一步发展形成制约,许多企业因缺少工人而完不成订单。
综合以上分析展望全年工业经济走势，我市工业经济发展既面临着良好机遇，也面对着严峻挑战，总体上仍是有利因素居主导地位，发展的机遇大于挑战，全市上下要同心协力，把脉好规模经济，唱响这支经济的主旋律。预计全市规模工业前三季度可实现工业总产值456亿元左右，增长26%左右，全年可实现605亿元的目标任务，增长24.0%左右。
                            （撰稿：黄蓓芳）
