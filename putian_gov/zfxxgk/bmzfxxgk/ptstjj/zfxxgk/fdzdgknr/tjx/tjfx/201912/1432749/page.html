1-11月莆田市房地产运行简析

第八十期
发布时间：2019-12-13 10:12
| | |

今年以来，全市房地产在大项目的带动下，投资呈现快速增长，受市场回暖、大项目带动和上年基数低等多种因素的影响，商品房销售面积继续平稳增长，多项指标呈良好运行态势。

一、1-11月房地产开发市场基本情况

（一）房地产投资呈倒“V”型增长

从前11个月房地产投资增长曲线来看，呈倒“V”型增长。1-11月，全市房地产开发投资完成384.05亿元，增长23.6%，位居全省第三。对全市固定资产投资的贡献率为57.1%，拉动固定资产投资增长4.6个百分点，主要原因是本月有5个房地产新增项目入库，仅一个项目土地款超5亿元，其他四个项目土地款均在亿元以下，房地产项目小，后劲不足。

 

 

1-11月房地产开发投资完成情况

 

（二）商品房销售呈波浪式增长

2019年以来，在稳政策稳房价稳预期的大环境下，经过去年以来的市场观望后，再加上开发商的降价促销总基调下，我市商品房销售经过年初的低迷后反弹，开始缓慢增长，刚需得到释放。从前11个月商品房销售曲线来看，呈波浪式增长，月度波动幅度较大。1-11月，商品房销售面积395.93万平方米，增长7.8%，较上个月提高0.4个百分点，增幅位居全省第二，比上个月提升一位。商品房销售额349.20亿元，增长11.9%。主要是莆田恒大御景半岛、碧桂园天城枫城新都二期北区、莆田香盛公馆开盘热销，四个项目单月销售面积8.14万平米，拉动本月销售面积增长2.0个百分点。再加上中心城区最近推出的楼盘地理位置趋近郊区，价格较低，从而吸引了一大批消费者。

（三）商品房销售品质提升，改善型住宅仍是主流

面对市场的变化，开发商使出浑身解数，通过灵活策略、花样繁多的促销活动及不断升级的品质来俘获置业者的心。1-11月，住宅销售面积342.75万平方米，增长8.0%，占全部销售面积的86.6%。其中：90平米以下住宅销售20.82万平方米，增长27.9%；144平米以上住宅销售41.84万平方米，下降13.6%；90-144平米住宅销售280.09万平方米，增长10.9%，占全部住宅销售的比重达86.6%，改善型住宅仍是市场主流。

（四）房地产企业资金到位情况良好

1-11月，全市房地产开发本年资金来源合计381.38亿元，增长10.6%。从资金构成看，主要来源于国内贷款和自筹资金。其中国内贷款59.25亿元，增长119.7%；自筹资金200.47亿元，增长10.7%；其他资金来源53.12亿元，增长153.1%。表明房地产到位资金增长主要受商品房销售额持续增长因素的影响，房企资金回笼速度加快。

二、建议

1、进一步加强土地的供应管理，充分发挥土地供应对房地产市场的调控作用，促进房地产市场的持续健康发展。要根据当地的住宅情况，未来需求等来制定住房发展规划，增加土地供应，减少盲目性。

2、建设保障住房改善刚需需求。受城市人口增长、居民收入增加等因素影响，住房刚需和改善性需求会不断增加，这些是房地产市场健康发展的基础。要稳定预期消费，为满足房地产需求创造条件，使房地产业需求得到释放。

3、进一步落实各级政府的稳定房地产市场的主体责任，提高房地产市场的分析研判能力，协调解决房地产市场调控中重大问题，抓好金融、税收等相关政策的落实。及时对在建、在售房地产开发项目进行排查，掌握情况，防范风险。推进信息公开，及时公布商品房供应、交易和价格的走势情况，提前公布商品房的供应量和供应时序，增加市场透明度，引导购房者有序购房，提高房地产市场的稳定性。
