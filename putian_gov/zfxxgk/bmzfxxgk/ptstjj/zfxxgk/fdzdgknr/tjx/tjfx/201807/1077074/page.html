上半年莆田GDP运行简析

第三十七期
发布时间：2018-07-20 16:28
| | |
 初步核算，上半年全市实现生产总值999.44亿元，增长8.5%，增幅与上年同期持平，增幅居全省设区市第三位。其中，第一产业增加值54.55亿元，增长3.4%，增幅比上年同期提高1.4个百分点；第二产业增加值560.08亿元，增长8.4%，增幅比上年同期提高1.2个百分点，增幅居全省设区市第一位；第三产业增加值384.81亿元，增长9.4%，增幅比上年同期回落2.4个百分点，增幅居全省设区市第四位。

一、运行特点

（一）从三次产业贡献率看。第一产业贡献率为2.3％，比上年同期提高0.8个百分点；第二产业贡献率为56.5％，比上年同期提高7.9个百分点；第三产业贡献率为41.2％，比上年同期回落8.7个百分点。

（二）从三次产业拉动情况看。第一产业拉动GDP增长0.2个百分点，比上年同期提高0.1个百分点。第二产业拉动GDP增长4.8个百分点，比上年同期提高0.7个百分点。第三产业拉动GDP增长3.5个百分点，比上年同期回落0.8个百分点。

（三）农业生产增幅回升。上半年，第一产业实现增加值54.55亿元，增长3.4%，同比提高1.4个百分点。农业实现产值18.56亿元，增长1.0%；林业实现产值0.88亿元，增长4.0%；牧业实现产值12.65亿元，增长2.7%；渔业实现产值57.80亿元，增长4.8%。

（四）工业经济平稳向好。全市实现工业增加值486.45亿元，增长8.6%，增幅比一季度提高0.9个百分点，比上年同期提高1.3个百分点，对经济增长的贡献率为51.1％。全市规模以上工业增加值增长8.9%,比1-5月、1-4月和1-3月分别提高0.2个、0.7个和1.0个百分点，比2017年全年增幅8.2%高0.7个百分点。从全市规上工业33个大类行业来看，有23个行业工业增加值实现增长，增长面为69.7%。

（五）服务业发展稳中趋缓。上半年，全市服务业增加值增长9.4%，比一季度回落0.9个百分点，同比回落2.4个百分点；分别高于全市生产总值增速和规模以上工业增速0.9个和0.5个百分点。服务业占生产总值的比重由上年同期的37.2%提高到今年上半年的38.5%，对生产总值增长的贡献率由上年同期49.9%回落至41.2%。从服务业内部看，交通运输、仓储及邮政业增长缓慢，实现增加值32.99亿元，增长5.3%，低于全省平均水平3.3个百分点；批发和零售业实现增加值67.54亿元，增长7.6%，低于全省平均水平0.1个百分点；金融业实现增加值59.13亿元， 增长0.9%，低于全省平均水平2.9个百分点；房地产业实现增加值50.86亿元，增长2.9%，低于全省平均水平4.1个百分点。其他服务业发展迅速。全市其他服务业实现增加值151.94亿元， 增长18.5%，高于全省平均水平4.8个百分点。其中，营利性服务业实现增加值114.29亿元，增长21.8%，对经济增长贡献率26.1%，拉动GDP增长2.2个百分点。

（六）县区竞相发展、差距缩小。上半年，各县区呈现出竞相发展的良好势头。从GDP增速看，最高增速与最低增速相差由上年同期6.4个百分点，缩小到今年的2.2个百分点。3个县区GDP增速高于全市平均水平，GDP增速最高的城厢，增长9.4%，比增速最低的秀屿高出2.2个百分点。

二、需关注的问题

（一）停、减产企业影响仍旧明显。6月末，全市工业企业停、减产面达28.1%，比5月低2.3个点，共拉低全市工业增加值增幅8.4个百分点。其中，停产企业100家，比5月末增加3家，拉低全市工业增加值增幅6.1个百分点。减产企业243家，比5月末减少31家，拉低全市工业增加值增幅2.3个百分点。

（二）第三产业增长乏力。核算第三产业部分相关指标增幅趋缓。第三产业增加值增长9.4%，比上年同期回落2.4个百分点，影响GDP增长速度回落0.8个百分点。分行业看：除营利性服务业增加值增速高于第三产业平均水平外，其他行业增幅均低于三产平均水平。

（三）金融存贷款增长回落，非金融企业存款减少。6月末，全市金融机构人民币存贷款余额3682.75亿元，增长4.5%，同比回落2.4个百分点。存、贷款增速放缓，新增贷款主要投向住户中长期消费贷款。6月末，全市金融机构人民币存款余额1816.67亿元，增长2.1%，同比回落1.6个百分点。6月末，全市金融机构人民币贷款余额1866.08亿元，增长7.0%，同比回落3.3个百分点。6月末，全市人民币住户中长期消费贷款余额716.53亿元，增长21.9%。
