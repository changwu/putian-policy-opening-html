稳中有进 回升向好——2024年上半年莆田市经济运行情况分析

发布时间：2024-07-23 09:51
| | |

今年以来，在市委市政府的正确领导下，全市上下坚决贯彻党中央、国务院决策部署，认真落实省委省政府工作要求，把“五抓五比五看”活动作为“三争”行动重要抓手，加快建设绿色高质量发展先行市，全市经济延续“稳中有进、回升向好”态势。

初步核算，上半年全市GDP完成1597.50亿元，同比增长6.0%，增幅比上年同期提高3.5个百分点，其中：第一产业增加值75.84亿元，增长3.8%，占GDP的4.7%，拉动GDP增长0.2个百分点；第二产业增加值762.85亿元，增长6.4%，占GDP的47.8%，拉动GDP增长3.2个百分点；第三产业增加值758.81亿元，增长5.7%，占GDP的47.5%，拉动GDP增长2.6个百分点。

（一）三次产业稳步增长，产业供给支撑稳定

1、农业生产总体平稳。上半年，全市农林牧渔业总产值完成141.91亿元，同比增长3.8%。一是渔业生产持续向好。采用主体规模化养殖和套养等多种养殖新模式，拓展养殖空间，提高海水养殖产量，上半年水产品产量76.50万吨，增长4.9%，增幅比一季度提高0.2个百分点。二是农产品产量平稳增长。蔬菜产量36.35万吨，增长1.4%；园林水果产量8.39万吨，增长3.0%，其中枇杷产量7.42万吨，增长3.3%。

2、工业生产增势良好。上半年，全市规模以上工业增加值同比增长7.4%，增幅比上年同期提高5.4个百分点。一是从企业景气情况看，二季度企业景气指数为125.5，比上年同期提高8.2个点，企业家信心指数为128.7，比上年同期提高12.7个点，两项指数均保持在景气区间。二是从行业情况看，全市34个行业大类中有25个行业增加值实现增长，占比超七成，特别是规模以上黑色金属冶炼和压延加工业，化学纤维制造业，化学原料和化学制品制造业，燃气生产和供应业增加值分别增长230.6%、46.3%、28.3%和19.9%，共拉动规模以上工业增加值增长3.0个百分点。三是从企业效益看，截至5月末，企业营业收入增长7.9%；每百元营业收入中的成本、费用分别同比下降0.63元和0.31元；利润总额增长35.3%。

3、服务业较快增长。上半年，全市服务业增加值同比增长5.7%，增幅比上年同期提高1.5个百分点。一是批发和零售业贡献突出。批发和零售业增加值增长8.6%，拉动GDP增长1.3个百分点，主要是限额以上批发业、零售业商品销售额分别增长13.8%和12.8%，增幅分别比1-5月份提高4.1个和9.4个百分点。二是营利性服务业快速增长。营利性服务业增加值增长9.6%，拉动GDP增长1.1个百分点，主要是规模以上其他营利性服务业营业收入增长20.3%，增幅比一季度提高4.7个百分点。

（二）投资消费持续增长，对外贸易承压上行

1、固定资产投资提速。上半年，全市固定资产投资同比增长4.0%，增幅比1-5月份提高2.7个百分点。其中，项目投资增幅（15.0%）比1-5月份提高0.9个百分点，房地产开发投资降幅（26.8%）比1-5月份收窄7.4个百分点。一是工业投资贡献突出。工业投资延续今年以来快速增长态势，上半年增长28.4%，拉动固定资产投资增长8.3个百分点。二是大项目支撑强劲。计划总投资亿元以上投资项目（不含房地产项目）有327个，完成投资增长23.9%，投资额占固定资产投资的76.4%，拉动固定资产投资增长15.2个百分点。三是基础设施投资提速。基础设施投资增长9.7%，增幅比1-5月份提高3.8个百分点，拉动固定资产投资增长2.8个百分点。其中，电力、热力、燃气及水的生产和供应业投资增长125.6%，电信、广播电视和卫星传输服务业投资增长39.0%，互联网和相关服务增长84.7%。

2、市场消费加快回升。上半年，全市社会消费品零售总额完成991.41亿元，同比增长6.6%，增幅比上年同期提高9.1个百分点。一是网络零售快速增长。在电商企业加大“618”促消费引流力度带动下，限额以上单位网络零售额完成97.00亿元，增长20.1%，拉动社会消费品零售总额增长1.7个百分点。二是石油类商品销售火热。20个主要商品类别中有11个限额以上商品零售额实现正增长，特别是限额以上石油及制品类商品零售额增长32.0%，拉动社会消费品零售总额增长0.5个百分点。三是本地特色商品热销。依托电商渠道，莆田特色的鞋帽类和日用品类商品销售较好，限额以上服装鞋帽针织品类、日用品类商品零售额分别增长16.7%和20.8%，共拉动社会消费品零售总额增长0.8个百分点。

3、对外贸易承压上行。上半年，全市外贸进出口总额完成342.7亿元，同比增长7.4%，增幅比上年同期提高5.8个百分点。其中，出口额166.4亿元，增长9.7%，增幅比上年同期提高28.9个百分点；进口额176.3亿元，增长5.4%。特别是6月当月外贸进出口总额、出口额、进口额分别增长30.4%、20.5%和41.6%。

（三）质量效益持续提升，民生福祉日益增进

1、财政收入平稳增长。上半年，全市实现一般公共预算总收入完成146.92亿元，同比增长2.0%，增幅比一季度提高1.2个百分点，其中地方一般公共预算收入99.82亿元，增长6.5%，增幅比一季度提高3.4个百分点。一般公共预算支出124.28亿元，下降8.1%，其中教育支出增长2.2%。

2、居民收入稳步提升。上半年，全市居民人均可支配收入22210元，同比增长5.4%，增幅比上年同期提高0.4个百分点。按常住地分，城镇居民人均可支配收入27458元，增长4.7%，增幅比上年同期提高0.7个百分点；农村居民人均可支配收入15975元，增长6.9%，增幅比上年同期提高0.7个百分点。城乡居民人均可支配收入比为1.72，比一季度缩小0.10。

3、就业物价总体稳定。上半年，全市城镇新增就业1.94万人，完成序时进度的97.2%，完成率居全省首位；失业人员再就业1989人，完成序时进度的53.8%；就业困难人员实现就业274人，完成序时进度的78.3%。市区居民消费价格同比下降0.5%，八大类消费“四增四降”，其中，其他用品及服务价格上涨4.8%，教育文化娱乐价格上涨1.9%，生活用品及服务价格上涨1.0%，医疗保健价格上涨0.1%，衣着价格下降0.2%，居住价格下降0.7%，交通和通信价格下降1.1%，食品烟酒价格下降1.7%。

（四）生产要素有效保障，发展势能不断积蓄

1、金融存贷增势稳定。6月末，全市金融机构本外币各项存款余额3297.09亿元，同比增长2.8%；金融机构本外币各项贷款余额3038.28亿元，增长4.2%。其中，企（事）业单位贷款余额1213.54亿元，增长5.9%。

2、增长动能持续提升。一是高技术投资快速增长。高技术产业投资增长35.1%，增幅比固定资产投资高31.1个百分点，拉动固定资产投资增长2.8个百分点。二是消费新业态迅猛发展。大数据、人工智能等新技术催生新的消费场景，直播带货、即时配送等消费新模式不断涌现，带动限额以上单位网络零售额连续3个月增幅超20%，邮政及快递业务总量增长23.7%。

3、发展后劲不断增强。一是市场主体快速增长。上半年，全市新登记市场主体9.37万户，其中新登记企业数2.69万户，同比增长28.7%，企业数净增1.17万户，增长21.4%；新登记个体户6.68万户。二是高质量纳统有序推进。截至6月末，全市共入库纳统“四上”企业151家，其中：工业40家，建筑业11家，商贸业84家，房地产5家，服务业11家。
