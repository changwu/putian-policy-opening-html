2015年1-8月份莆田市固定资产投资运行情况简析

发布时间：2015-09-14 00:00
| | |

全市固定资产投资（不含农户，下同）完成1119.83亿元，同比增长19.3%，比全省平均水平高 1.0个百分点,增速位居全省第八位，比上个月回落一位。其中项目投资完成868.28亿元，同比增长20.4%，增速比上个月回落1.2个百分点；房地产开发投资完成251.55亿元，同比增长15.7%，增速比上个月提升3.6个百分点。

一、主要运行情况

1、在建亿元项目投资快速增长。全市160个在建亿元项目完成投资328.77亿元，同比增长40.8%，增幅分别比上年同期、全市固定资产投资高49.3和21.5个百分点。其中，45个本年新开工亿元项目完成投资121.98亿元，同比增长69.9%，增幅比项目投资平均水平高49.5个百分点。

2、新开工项目助推作用明显。全市共有500万元以上新开工项目1230个，完成投资592.70亿元，同比增长23.1%，增速比项目投资快2.7个百分点，占项目总投资的比重为68.3%，对项目总投资的贡献率高达75.6%。

3、工业投资逐步趋稳。随着涵江港临港产业园陆域形成工程、南日岛40万千瓦海上试验风电场、永荣石化年产60万已内酰胺项目、华峰新材料公司年产6.36万吨高端运动面料生产项目、湄洲湾第二发电厂、福建华锦实业有限公司年产9万吨高端纺织面料等大型工业项目的稳步推进，我市工业投资呈稳定增长态势。1-8月份我市完成工业投资325.19亿元，同比增长18.0%，增速同比提升11.5个百分点，拉动全市固定资产投资增长5.3个百分点。工业投资中制造业投资完成250.89亿元，同比增长15.8%，增速同比提升8.3个百分点，其中占比较大的化学纤维制造业、纺织业、家具制造业、其他制造业分别完成投资22.21亿元、26.51亿元、31.85亿元和38.99亿元，同比增长139.1%、65.5%、286.0%和29.4%。

4、基础设施投资快速增长。随着交通运输、电力电网、公共设施管理等项目有序推进，我市基础设施不断完善，自2月份以来增速均维持在40%以上。全市基础设施完成投资405.35亿元，同比增长40.5%，占固定资产投资的比重为36.2%，对固定资产投资增长贡献率达64.5%，比上年同期提高19.2个百分点。其中水利、环境和公共设施管理业完成投资170.95亿元，同比增长58.4%；电力、热力的生产和供应业完成73.58亿元，同比增长25.0%；交通运输、仓储及邮政业完成投资159.95亿元，同比增长32.0%。

5、民间投资作用突出。全市民间投资完成658.43亿元，同比增长23.4%，占固定资产投资的比重为58.8%，占比同比提高1.9个百分点，对固定资产投资增长的贡献率高达68.7%，拉动固定资产投资增长13.3个百分点，是投资保持平稳较快增长的主要动力。

6、投资内涵持续深化。按照转方式调结构的要求，我市更加注重利用高技术和先进技术改造提升传统产业，投资结构在调整中继续优化。1-8月份，全市工业企业增加品种及提高质量投资6.76亿元，增幅由上年同期的下降82.7%转为增长62.9倍；三废治理投资0.62亿元，增幅由上年同期的下降87.2%转为增长115.7%；节能降耗投资2.85亿元，在上年同期增长184.6%的基础上继续快速增长106.7%；改建及技术改造投资155.80亿元，同比增长137.6%，增幅同比提高125.2个百分点。

二、存在问题

1、项目储备不足。全市在建的施工项目个数1546个，比上年同期减少120个，计划总投资2262.84亿元，同比下降2.4%；其中亿元以上项目160个，比上年同期减少34个，计划总投资1576.56亿元，同比下降4.3%。

2、项目投资增速仍处于全省较低水平。全市项目投资增长20.4%，增幅比1-7月回落1.2个百分点，比全省平均水平低4.0个百分点，居全省九地市第八位；

3、民间投资意愿有所弱化，增速逐月趋缓，贡献率有所降低。今年以来，我市民间投资增速均保持在20%以上增长，但呈逐月趋缓态势；贡献率均保持60%以上，但逐月降低，1-8月份贡献率由去年的73.2%下降为68.7%，首次出现低于去年的状况。具体见下表：

4、资金来源同比增速减缓，国内贷款连续三个月下降。1-8月份，全市固定资产投资本年到位资金1275.11亿元，同比增长15.3%，增幅比上年同期和上个月分别回落7.3和0.3个百分点，比固定资产投资增速低4.0个百分点，到位资金增速放缓对投资建设的持续发展影响较大。其中，国内贷款1-6、1-7、1-8月份同比分别下降65.7%、59.4%、54.4%，1-8月份国内贷款105.85亿元，增幅比上年同期回落88.2个百分点。
