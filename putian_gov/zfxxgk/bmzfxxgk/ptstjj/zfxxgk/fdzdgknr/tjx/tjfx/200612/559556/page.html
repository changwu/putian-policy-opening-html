单位数量稳步增长发展后劲持续增强

发布时间：2006-12-12 00:00
| | |
今年以来，我市继续紧紧围绕发展这一中心任务，对内对外采取“两手抓，两手都要硬”的方针，对内继续抓好经济发展软硬环境建设，切实解决“软件不软、硬件不硬”的问题，对外则进一步加大招商引资和宣传力度，采用“政府搭台、企业唱戏”的方式，由有关市领导带队赴各地举办或参加各种形式的招商引资会，取得了良好成效。上半年，全市实现地区生产总值197.48亿元，按可比价格计算比上年同期增长16.5%，增幅居全省第一位。我市的经济总量也在上年由全省第九位前移至第七位的基础上，又前移至第五位，在海西建设中较好地发挥了拓展一线的骨干作用。我市的发展环境不断优化，“磁吸”效应增强，各种单位数量进一步增加，为我市经济的持续、快速、健康、和谐发展奠定了良好基础。据我市基本单位统计数据显示，2006年6月末，我市共有法人单位6861个，比2005年末增加326个，增长5.0%。
一、分机构类型看，企业法人撑起我市法人单位数的“半边天”，社团法人异军突起，呈现出蓬勃发展的态势。
在全部法人单位数中，企业法人3760个，占54.8%；事业法人1217个，占17.7%；机关法人424个，占6.2%；社团法人287个，占4.2%；其他法人1173个，占17.1%。企业法人增加的单位数占全部法人增加单位总数的82.2%。从增幅看，社团法人单位数比2005年末增长12.5%，增幅居第一位，其次为企业法人，增幅为7.7%，机关法人、其他法人和事业法人的增幅分别为1.7%、0.9%和0.7%。
二、分县(区)看，湄洲岛、城厢区、荔城区的企业法人单位数增长较快，发展后劲较足，而涵江区的发展后劲相对不足。
湄洲岛拥有企业法人44个，比2005年末增加5个，增长12.8%；城厢区拥有企业法人932个，比2005年末增加86个，增长10.2%；荔城区拥有企业法人724个，比2005年末增加64个，增长9.7%。湄洲岛、城厢区、荔城区企业法人单位数的增幅分别位居全市前三名，表明这三个县（区）具有较强的发展后劲，经济发展势头良好。涵江区拥有企业法人902个，仅比2005年末增加36个，增长4.2%（详见表一），增幅居全市最后一位。涵江区企业法人单位数增长缓慢，说明涵江区吸引投资创业的能力偏弱，发展后劲相对不足。而且，涵江区的企业法人单位数分别比城厢区、仙游县少30个和3个，屈居全市第三位，这与涵江区的经济总量高居全市榜首的情况很不相称。

三、分行业看，法人单位数增加最多的前三个行业分别是制造业、批发和零售业、公共管理和社会组织，有五个行业的增幅达到两位数。
6月末，全市共有制造业法人单位1842个，比2005年末增加79个；批发和零售业法人单位606个，增加76个；公共管理和社会组织法人单位1884个，增加45个。这三个行业增加的单位数占法人单位增加总数的61.3%。制造业单位数增加最多说明我市促进工业发展的各项措施取得明显成效，带动能力较强的工业仍是拉动我市经济增长的主导力量。批发和零售业单位数增加较多是由于近年来我市经济发展势头迅猛，带动了商业市场的繁荣，万家惠、永乐家电、国美电器等一些商业巨头也纷纷在我市零售业市场重新划分势力范围。公共管理和社会组织单位数增加较多是因为我市经济社会的全面发展和关于社团登记的优惠政策推动了社团单位的发展壮大。
法人单位数增幅居前五名的行业分别是信息传输、计算机服务和软件业、金融业、居民服务和其他服务业、批发和零售业、房地产业，增幅分别为52.4%、22.7%、17.2%、14.3%、10.8%（详见表二）。近年来，由于我市大力发展高新技术产业以及加强网吧管理，所以信息传输、计算机服务和软件业单位数增长很快。金融业单位数增长较快是由于随着我市金融业的改革开放，一些金融企业纷纷进驻我市。居民服务和其他服务业单位数快速增长是因为我市居民收入和消费水平明显提高带动了与居民相关的服务行业的发展。房地产业单位的较快增长是由于城市化进程加快和房价的不断攀升吸引了大量资金涌向该行业。

四、分登记注册类型看，民间投资氛围浓厚，私营企业勇挑大梁，现代企业管理制度日益受到推崇。
近几年来，我市大力实施民资回归工程，出台了一系列鼓励民间投资的优惠政策措施，大力加强投资环境建设，掀起了全市民间投资的热潮，私营企业单位数迅速增长。据统计，2006年6月末，全市拥有私营企业法人1633个，比2005年末增长10.5%。私营企业法人占全部企业法人单位数的比重达43.4%，比2005年末提高1.1个百分点。私营企业法人增加的单位数占全部企业法人增加单位数的57.8%。内资企业中具有较高经营管理水平的有限责任公司、股份有限公司共1519个，比2005年末增加184个，增长13.8%。随着私营企业主素质的提高和各项制度的完善，私营有限责任公司和私营股份有限公司单位数增势强劲，在私营企业中所占的比重越来越大，成为我市经济发展中的一个亮点。2006年6月末，全市拥有私营有限责任公司和私营股份有限公司761个，比2005年末增长15.7%（详见表三）。私营有限责任公司和私营股份有限公司在私营企业中所占的比重达46.6%，比2005年末提高2.1个百分点。
