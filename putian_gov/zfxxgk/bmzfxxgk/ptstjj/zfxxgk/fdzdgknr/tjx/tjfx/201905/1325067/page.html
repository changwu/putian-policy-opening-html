1-4月莆田市房地产运行简析

第三十二期
发布时间：2019-05-20 15:20
| | |

莆田市房地产市场回暖，房地产开发投资和销售双双增长。1-4月份，全市现有房地产企业233家，比上年同期增加6家。

一、房地产运行情况

（一）房地产开发投资持续增长

房地产开发投资连续四个月增幅在10%以上。市场回暖，房地产项目加快开工，建安投资不断增加，带动房地产开发投资持续增长。1-4月，房地产开发投资完成140.48亿元，增长16.4%，增幅居全省第五。从工程用途看，住宅投资92.47亿元，增长8.7%，占房地产开发投资的比重为65.8%；办公楼完成投资9.05亿元，增长343.1%，占房地产开发投资的比重为6.4%；商业营业用房完成投资13.37亿元，增长12.4%，占房地产开发投资的比重为9.5%；其它类型房屋完成投资25.59亿元，增长18.2%，占房地产开发投资的比重为18.2%。住宅投资仍为房地产投资主要流向。（图1）

（二）房地产销售面积首次转正

1-4月，莆田市房地产销售面积125.44万平方米，增长6.2%。增速转正，结束了连续三个月负增长的局面，增幅全省第五位。全市当月销售面积28.19万平方米，增长45.8%。

分类型看，现房销售面积26.29万平方米，增长148.1%；期房销售面积99.15万平方米，下降7.8%。从构成看，住宅销售面积103.49万平方米，增长2.8%，占全部销售面积的82.5%。其中：90平米以下住宅销售6.19万平方米，增长33.9%；144平米以上住宅销售14.17万平方米，下降22.4%；90-144平米住宅销售83.13万平方米，占全部住宅销售的比重达80.3%，改善型住宅成为市场主流。

（三）县区间发展不平衡

1-4月，莆田市房地产销售面积各县区间发展不平衡。秀屿区和北岸由于去年基数低，秀屿区国湄领秀项目上个月销售火爆，单月销售2万多平米，北岸碧桂园和世贸国风湄州由于价格适中，受消费者追捧。销售面积增速分别位于全市第一、第二。1-4月，秀屿区房地产销售面积13.46万平方米，增长127.8%；北岸房地产销售面积4.55万平方米，增长72.9%；荔城区由于保利中央公园、恒大悦府等降价促销，房地产销售面积22.88万平方米，增长35.1%，位居第三；涵江区保利五个楼盘撑起一个城，房地产销售面积35.59万平方米，增长2.8%，位居第四；仙游县由于去年基数大，虽然有永鸿文化城C地块等中低价楼盘的热销支撑，增幅略下降，房地产销售面积24.57万平方米，下降3.3%，位居第五；中心城区的城厢区由于去年政府回购安置房入库，基数比较高，下降幅度较大，房地产销售面积24.39万平方米，下降25.4%，位居第六。（见下表）

（四）待售面积持续下降

1-4月，房地产待售面积为160.43万平方米，下降10.2%。比上个月去库存1.03万平方米。其中，住宅待售面积82.02万平方米，增长6.6%。待售1-3年(含1年)面积42.84万平方米，下降51.8 %；待售3年以上(含3年)面积79.83万平方米，增长365.5%。待售面积下降，使得房地产消化库存压力变小。

二、建议

一要加强市场监管，防范市场风险。加快建立促进房地产市场健康发展的长效机制，健全房地产市场动态监管机制和推进房地产企业诚信体系建设，近期尤其要加强预售资金的监管，防止部分开发企业因资金链断裂、抽逃资金，出现烂尾，提高市场风险的防范意识和防控能力。

二要加大生活配套设施建设力度，完善房地产项目配套设施。在购买商品房的过程中，一些房地产项目的生活配套因各种原因，产生了不少遗留问题，且长期得不到很好解决，给购房者造成一定的损失和影响，也增加了许多社会矛盾与不和谐因素。相关部门应加快道路、学校、医院等与生活紧密相关配套建设，加快实现城市各区域特色功能定位，促进房地产市场平稳健康发展。
