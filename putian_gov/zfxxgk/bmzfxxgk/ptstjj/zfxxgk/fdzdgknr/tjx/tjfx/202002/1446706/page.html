2019年四季度莆田市工业景气调查分析

第五期
发布时间：2020-02-17 08:32
| | |

今年以来，莆田市坚持稳中求进工作总基调，坚持新发展理念，深化供给侧结构性改革，打好三大攻坚战，扎实做好“六稳”工作，奋力推进经济高质量发展落实赶超。从规模工业企业生产经营及景气状况专项调查看，四季度企业景气指数和企业家信心指数明显提升，其中企业家信心指数和景气指数分别为128.8和130.1，较三季度分别提高3.3个和 5.6个点，两项指数都处在较为景气区间。全市规模以上工业经济运行总体平稳，盈利状况趋势向好，但企业资金紧缺、投资意愿不强和综合生产成本增加等不利因素仍然存在，企业信心还需进一步提振。

2019年以来企业家信心指数和企业景气指数

一、工业经济运行情况

（一）企业生产能力利用率稳中有升。调查结果显示，本季度企业主要产品生产能力利用率为81%，比上季度提高1个百分点。认为本季度企业生产能力利用率比上季度“提高”或“不变”的企业占92.8%，比上季度提高4.2个百分点。市场需求大、订单增加和技术改造、生产效率提升是本季度企业生产能力利用率发挥稳定的主要原因，分别占85.3%和30.7%。

（二）企业盈利状况趋势向好。调查结果显示，本季度企业盈利比上季度“增加”和“持平”的企业占89.6%，比上季度提高4.1个百分点。87.5%的企业认为销售量增加是企业本季度盈利增加的主要原因。

（三）企业订单稳步增长。本季度企业接到的产品订货量与上季度相比，“增加”或“持平”的企业占89.3%，比上季度提高2.1个百分点。1.2%的企业认为本季度产品出口订货量增加，比上季度提高0.6个百分点。

（四）企业用工需求略有增长。本季度用工需求比上季度“上升”或“基本持平”的企业占93.9%，比上季度增加0.7个百分点。主要原因是生产任务或订单增加、季节性用工、员工流失率高和企业规模扩大，分别占71.1%、28.9%、22.2%和15.6%。

（五）惠企政策显成效。73.7%的企业认为简政放权政策显成效，69.3%的企业认为创新支持政策显成效，88.1%的企业认为减税降费政策显成效，66.2%的企业认为降低融资成本政策显成效，62.4%的企业认为化解过剩产能政策显成效，61.3%的企业认为“一带一路”建设政策显成效，60.1%的企业认为促进外贸增长政策显成效。

二、企业面临的问题

（一）企业资金依旧紧张。16.5%的企业认为资金紧张，只有2.0%的企业认为资金充裕。11.2%的企业认为融资困难，主要原因是银行贷款门槛过高、手续繁杂、条件苛刻，有效抵押资产不足，利率水平过高、企业承受力不足和企业经营状况不佳，分别占71.8%、46.2%、25.6%和20.5%。

（二）企业工业投资意愿不强。本季度企业有投资的仅占16.2%。主要原因是没有好项目、未来预期不乐观、资金不足和投资效益低，分别占63.4%、31.4%、28.3%、和17.2%。

（三）企业综合生产成本增加。本季度企业综合生产成本比上季度“上升”或“基本持平”的企业占95.1%，比上季度提高2.2个百分点。本季度企业面临的主要成本压力是原材料成本和用工成本，分别占35.5%和34.1%。

三、对策建议

（一）加大金融服务实体经济的力度。积极争取政府和金融机构的资金支持，增强融资渠道，满足生产经营所需资金；加快产品创新与业务拓展，提供专项融资服务，着力帮助企业解决发展所需资金；加大融资担保力度，鼓励银行对市场前景好、成长性好但暂时有困难的企业不断贷、不抽贷，降低融资中间环节费用；有效引导民间投资，激发民间投资活力，提振民间投资预期，加快民间投资结构优化进程。确保企业融资渠道宽，贷款效率高，融资难度和成本降低。

（二）加快传统产业升级，促进企业提质增效。一是加快传统产业的转型升级，企业主动作为，加大科研投入，提升企业产品科技含量、提高产品附加值，降低成本。二是进一步优化产业链和产品结构，政府要加强对企业的引导，在转型上谋突破，创新上谋发展，加快供给侧结构性改革，促进企业经济效益持续稳定增长。

（三）进一步减轻企业负担。要积极采取有效措施，全面落实减税降费和各项涉企收费政策，积极推进收费管理制度改革，狠抓涉企收费清理规范，降低企业运行成本，为企业发展创造良好环境。
