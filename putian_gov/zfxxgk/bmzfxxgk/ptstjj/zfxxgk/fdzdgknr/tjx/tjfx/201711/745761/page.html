2017年1-3季度莆田市农林牧渔业生产情况简析

第六十六期
发布时间：2017-10-19 15:57
| | |

今年以来，全市上下认真贯彻中央、全省农村工作会议精神，紧紧围绕推进农业供给侧结构性改革工作主线，以农业增效、农民增收、农村增绿为目标，以加强科技创新、深化农村改革为动力，着力推进农业结构调整，促进农村一二三产业融合发展，保障了我市农业农村经济运行健康稳定发展的良好态势。

一、主要运行特点

（一）农林牧渔业总产值保持稳步增长

1-3季度，全市实现农林牧渔业总产值157.38亿元，可比增长1.4%，增加值93.29亿元，可比增长1.3%。其中：农业产值51.56亿元，可比增长3.3%，增加值30.72亿元，可比增长3.2%；林业产值1.58亿元，可比下降4.2%，增加值0.86亿元，可比下降8.7%；牧业产值24.86亿元，可比下降6.3%，增加值13.31亿元，可比下降7.9%；渔业产值65.15亿元，可比增长3.2%，增加值39.92亿元，可比增长3.3%；农林牧渔服务业产值14.23亿元，可比增长5.60%，增加值8.46亿元，可比增长5.6%。

（二）农作物总播种面积及粮食播种面积呈持续下降趋势

近年来，我市农作物总播种面积及粮食播种面积呈逐年下降态势，2016年，莆田市农作物总播种面积为160.47万亩，同比下降1.7%。其中粮食作物播种面积为69.21万亩，下降2.5%；粮食产量为25.84万吨，下降4.8%。今年1-3季度，我市农作物总播种面积及粮食播种面积继续下降，粮食产量也随着播种面积的下降而下降。1-3季度，莆田市农作物总播种面积为94.79万亩，同比下降2.7%。其中粮食作物播种面积为26.40万亩，下降6.2%；粮食产量为9.28万吨，下降5.6%。在粮食作物中，其中早稻播种面积为17.28万亩，下降8.9%；早稻产量为7.38万吨，下降6.7%。

（三）园林水果增幅高达18.4%

去年由于我市园林水果受年初霜冻影响产量呈现大幅下降，今年我市没有出现极寒天气，气候总体上适宜热带水果生长，产量恢复正常，呈现恢复性的高增长态势。1-3季度，全市园林水果产量为16.12万吨，增长18.4%。其中香蕉产量为0.47万吨，增长8.2%；枇杷产量为9.58万吨，增长29.2%；龙眼产量为3.93万吨，增长0.7%；橄榄产量为0.27万吨，下降1.1%；杨梅产量为0.23万吨，与上年持平；桃产量为0.31万吨，增长4.2%；李产量为0.40万吨，增长6.1%。

（四）茶叶产量继续增加

近几年我市陆续扩大茶叶种植面积，且随着茶叶种植管理的跟进、种植技术的投入、茶树龄的增加、生产茶叶的茶树分枝增多，茶叶产量逐年增加。但随着基数的逐年抬高且种植面积没有大面积扩大的情况下，今年1-3季度我市茶叶产量增幅有所回落。1-3季度，全市茶叶产量为0.39万吨，增长2.6%，增幅比上年同期和今年上半年分别回落2.1和3.6个百分点。其中青茶产量0.32万吨，增长3.7%；红茶产量0.04万吨，下降4.5%；绿茶产量0.03万吨，增长1.9%。

（五）渔业生产继续保持较快的增长势头

近年来我市启动渔业底播增殖工程，引进南美白对虾高位池养殖，推广“购大苗养中鲍”养殖生产模式和网箱混养模式，积极发展远洋捕捞，我市渔业生产保持持续稳定较快的增长势头。1-3季度，全市水产品总产量74.47万吨，比上年同期增加2.49万吨，同比增长3.5%。其中海水产品产量70.99万吨，比上年同期增加2.42万吨，增长3.5%；淡水产品产量3.48万吨，比上年同期增加0.08万吨，增长2.1%。在海水产品产量中：牡蛎产量为29.40万吨，比上年同期增加1.31万吨，增长4.7%，对全市水产品总产量的贡献率高达52.5%；江篱产量为7.15万吨，比上年同期增加0.89万吨，增长14.2%，对全市水产品总产量的贡献率高达35.7%。

（六）蔬菜播种面积下降

由于受年初我市大宗蔬菜如花椰菜、西芹、莴苣等出现“卖难”现象，蔬菜价格季节性波动明显，直接影响了今年露地蔬菜的生产积极性。1-3季度，全市蔬菜播种面积为41.05万亩，比上年同期减少1.15万亩，同比下降2.7%；蔬菜产量为85.10万吨，比上年同期减少0.10万吨，下降0.1%；蔬菜亩产为2073公斤/亩，比上年同期增加54公斤/亩，增长2.6%。

（七）食用菌生产规模缩小

近几年来，由于受人工费用等生产成本提高影响，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其在我市的生产规模只减不增，食用菌产量受之影响呈下降趋势。1-3季度，全市食用菌产量为5.49万吨，下降4.7%。其中，蘑菇产量5.10万吨，下降3.7%；姬松茸产量0.24万吨，下降19.4%；香菇产量0.12万吨，增长2.8%。食用菌生产占用耕地面积8189亩，下降13.1%；蘑菇种植面积607.63万平方米，下降12.0%。

（八）畜牧业肉类总产量大幅下降

受去年年底的H7N9疫情影响，今年我市家禽业生产仍处于低迷状态，加上开展畜禽养殖污染整治，影响了畜禽的存出栏，受之影响全市畜牧业肉类总产量及禽蛋奶类产量也随之出现大幅下降。1-3季度，全市生猪出栏66.90万头，下降9.0%，存栏45.29万头，下降11.0%；家禽出栏1286.40万只，下降34.7%，存栏468.26万只，下降15.9%；牛出栏0.50万头，增长0.7%，存栏2.65万头，增长4.8%；羊出栏15.14万头，增长2.3%，存栏10.78万头，下降0.3%。全市肉类总产量7.30万吨，下降14.9%；禽蛋产量2.19万吨，下降1.9%；奶产量1.05万吨，下降7.4%。

二、存在的主要问题

（一）生产成本及农产品价格对农业生产影响较大。一是近几年来受我市人工费用等生产成本不断提高影响，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其在我市的生产规模只减不增，我市食用菌生产规模逐年缩小。二是去年我市蔬菜价格低，蔬菜种植户增产不增收，大部分种植户亏本，导致今年我市蔬菜种植积极性不高，蔬菜种植面积大幅下降。

（二）农作物种植面积保持有难度。一是种粮比较效益偏低，农民种粮积极性不高，粮食播种面积和产量呈逐年下降态势。二是由于农民外出务工相比在家务农收入较高，我市部分山区青壮年人口常年外出打工，家里剩下老人与小孩，耕地因缺少劳动力耕作导致抛荒。三是受征地拆迁影响，耕地面积逐渐流失，特别是南北洋适合种植水稻的大片良田流失严重。

（三）畜禽可养范围较小，仅占全市总村居数的15%。根据市政府印发的《莆田市畜禽禁养区及禁建区划定方案》、《莆田市畜牧业集约化发展规划》（莆政综〔2010〕48号）和《莆田市人民政府关于公布畜禽养殖禁养区、禁建区及可养区的通知》（莆政综〔2011〕125号），全市行政区划内有近三分之二以上区域为禁养区，其中北岸和湄洲岛全境范围禁养；我市行政区划内可养区只有146村，占全市村居委会总数的比重为15.0%，其中仙游县52个村、城厢区15个村和秀屿区79个村。

（四）龙头企业带动作用减弱。今年以来，我市农业龙头企业农业生产规模总体呈现下降态势，全市农业生产受之影响也呈现下降态势。今年1-3季度，利农农业技术(仙游)有限公司种植面积下降65.8%；莆田广东温氏家禽有限公司活家禽出栏下降44.9%，拉低全市活家禽出栏增幅33.9个百分点。

（五）海洋经济短板仍未得到改善，渔业发展空间受限。随着城市建设和工业化的发展，水域和滩涂等养殖区不断受到蚕食，水产养殖空间越来越小；湾外养殖扩展技术尚在实验阶段，技术难度大且风险高，尚需资金扶持，渔民参与积极性不高；国际渔业组织和入渔国渔业资源的管理不断加强，远洋渔业发展空间受到制约；海产品加工业发展滞后，不能有效促进渔业发展。

三、下一步建议

（一）加快农村耕地流转，扩大农作物种植规模。耕地流转是农业生产规模化的基础和前提。政府要出台相关政策引导、鼓励农村耕地流转，通过耕地流转把抛荒的耕地集中到种植大户、种植农民专业合作社和种植业龙头企业，发展适度规模的种植业生产，提高全市耕地利用率，从而扩大全市农作物种植规模。

（二）抓龙头企业农业生产。要着重抓好利农、鸿达、亿生、天怡、温氏等龙头企业的农业生产，支持和督促龙头企业扩大农业生产规模，带动全市农业经济稳定增长。
