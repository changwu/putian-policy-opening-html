2018年1-10月莆田市能源生产消费情况简析

第七十期
发布时间：2018-11-19 14:46
| | |

2018年以来我市单位GDP能耗屡增不降，节能降耗形势持续保持预警状态。由于八月过后气温下降，节能措施有效施行，全社会用电、规模以上工业综合能耗增幅均出现回落，1-3季度单位GDP能耗增势有所减缓。

一、能源消费情况

（一）全社会用电量增长放缓

1-10月我市全社会累计用电量为115.55亿千瓦时，同比增长16.5%，增速分别较前三季度回落1.0个百分点、8.8个百分点、2.2个百分点。第一产业用电量为0.74亿千瓦时，同比增长6.7%；第二产业用电量为70.97亿千瓦时，同比增长24.7%；第三产业用电量为16.22亿千瓦时，同比增长9.4%；居民用电为27.62亿千瓦时，同比增长3.3%。

 

（二）规模以上工业综合能耗增速回落

1-10月我市规模以上工业综合能源消费量为296.20万吨标准煤，同比增长53.5%，增幅分别较前三季度回落30.0个百分点、27.3个百分点、10.9个百分点。

六大高耗能行业综合能源消费量为232.96万吨标准煤，同比增长77.8%，占全市规模以上工业综合能耗的78.6%，推动作用达52.8个百分点。其中，电力、热力生产和供应业综合能源消费量为212.02万吨标准煤，同比增长88.3%，推动全市规模以上工业综合能耗增长51.5个百分点，是高耗能行业对全市规模以上能耗的主要影响力。

二、能源生产情况

1-10月我市规模以上发电量为177.86亿千瓦时，同比增长58.3%，增幅较前三季度分别回落41.9个百分点、46.0个百分点、51.3个百分点。其中火力发电量为132.99亿千瓦时，同比增长87.4%，占规模以上发电量的74.8%；水力发电量为24.75亿千瓦时，同比增长7.5%，占规模以上发电量的13.9%；风力发电量为20.12亿千瓦时，同比增长9.6%，占规模以上发电量的11.3%。

   

受用电需求减少影响，第三季度以来火、水、风电的发电计划都有不同程度的减少，其中火力发电增速回落最为明显。

三、节能形势预判

2018年前三季度我市节能工作仍保持预警的严峻形势，但单位GDP能耗的增幅逐渐回落，一季度、上半年、前三季度的单位GDP能耗增速分别为2.31%、2.04%、1.65%。预计全市全年单位GDP能耗的增幅将继续回落，主要原因：一是全社会用电量增速大幅度提高的可能性较小，二是2017年下半年新增入库的太平洋电力、华佳彩等能耗较大的企业基数作用逐渐显现。
