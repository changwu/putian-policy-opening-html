莆田市第二次全国农业普查主要数据公报(第四号)

发布时间：2008-12-29 00:00
| | |

农村居民生活条件

第二次全国农业普查对我市53.25万户农村居民的生活条件进行了调查。现将主要结果公布如下：

一、住宅

2006年末，农村居民平均每户拥有住宅面积190.86平方米。99.6%的住户拥有自己的住宅，其中，拥有1处住宅的47.5万户，占89.2 %；拥有2处住宅的5.33万户，占10.0%；拥有3处以上住宅的0.21万户，占0.4%。

住宅类型主要为楼房。其中,居住楼房的38.50万户，占72.3%；居住平房的14.54万户，占27.3%；居住其他类型住房的0.21万户，占0.4%。

住宅结构主要为砖木和砖混结构。住宅为砖木结构的19.65万户，占36.9%；砖混结构的17.47万户，占32.8%；钢筋混凝土结构的7.93万户，占14.9%；竹草土坯结构的7.77万户，占14.6%；其他结构的0.43万户，占0.8%（见表1）。

二、饮用水

有1.44万个住户反映获取饮用水存在困难，占2.7%。使用管道水的住户34.72万户，占65.2%。16.67万户的饮用水经过净化处理，占31.3%；15.55万户的饮用水为深井水，占29.2%；19.65万户的饮用水为浅井水，占36.9%；0.69万户的饮用水来源于江河湖水，占1.3%；0.37万户的饮用水为池塘水，占0.7%；0.05万户的饮用水来源于雨水，占0.1%；0.32万户的饮用水来源于其他水源，占0.6%（见表2）。

注：

1．住宅：一般指上有顶、周围有墙，能防风避雨，供人居住的房屋。按照各地生活习惯，可供居住的窑洞、竹楼、蒙古包、帐篷、毡房、船屋等也包括在内。
