莆田市第一次全国经济普查主要数据公报（第三号）

发布时间：2006-01-10 00:00
| | |

根据莆田市第一次全国经济普查结果，现将我市第三产业的主要数据公布如下：

一、交通运输、仓储和邮政业

（一）单位数和就业人员

2004年12月31日，全市交通运输、仓储和邮政业企业法人单位81个，就业人员[注1]7965人；个体交通运输经营户14684户，就业人员21755人。

在交通运输、仓储和邮政业企业法人单位数中，交通运输业[注2]占96.3%，仓储业2.5%，邮政业占1.2%；在法人单位就业人员中，交通运输业占85.5%，仓储业占1.2%，邮政业占13.3%（详见表1）。

（四）房地产业生产经营情况

2004年，全市商品房建设施工面积218.81万平方米；竣工房屋面积62.99万平方米；商品房销售面积51.27万平方米。其中，住宅销售面积47.28万平方米；商品房销售额87509万元。住宅销售额67969万元。
