莆田市统计局关于2021年度全市统计执法情况的通报

莆统〔2022〕2号
发布时间：2022-01-12 10:28
| | |

各县（区）统计局：

　2021年，全市各级统计机构深入学习贯彻习近平法治思想，严格落实中央领导关于统计工作的重要讲话指示批示精神，狠抓中央《意见》《办法》《规定》和《监督意见》的贯彻落实，积极做好统计督察迎检工作，依法开展统计执法检查，加强防范和惩治统计造假弄虚作假制度建设，强化统计法治宣传，统计法治工作取得新进展。

2021年度，全市各级统计机构共检查单位474家，立案查处统计违法案件56起，结案53起。其中：予以经济处罚52起，罚款金额232.7万元。 

今年以来，各县（区）努力克服疫情带来的不利影响，按照《莆田市统计局关于做好2021年度统计执法检查工作的通知》（莆统函〔2021〕19号）要求，加强组织领导，深入开展统计执法检查，圆满完成统计执法检查任务。但是，从实际看，统计法治工作仍存在一些不足：一是部分县（区）统计造假弄虚作假现象仍时有发生；二是个别地区统计法治基础工作比较薄弱。

　　希望各级统计机构自觉扛起主体责任，继续认真贯彻落实党中央、国务院关于统计工作各项决策部署，更加有效发挥统计监督职能作用，严格落实防范和惩治统计造假弄虚作假责任制，努力推进统计法治工作，争取获得更大的成效。
