莆田市统计局关于印发信息发布制度的通知

发布时间：2015-01-04 00:00
| | |

各科室（中心）：

现将《莆田市统计局信息发布制度》印发给你们，请认真遵照执行。

莆田市统计局

2015年1月4日

莆田市统计局信息发布制度

为加强我局统计数据信息安全管理，促进统计数据信息发布工作的制度化、规范化，保障信息发布的严肃性、及时性、准确性和权威性，依据国家有关法律、法规，结合我局实际，特制定本制度。

一、统计信息发布的原则

（一）发布内容遵循的总体原则：准确、及时地反映本单位各项工作最新动态。

（二）各专业要在省统计局数据反馈后半天内，将数据提供给综合科，同时将核算需要的省局核定数据，及时提供核算专业用于核算地区生产总值。

（三）各专业对有业务联系的相关部门定期提供本专业的常规性资料（包含数据和分析），需经局长或分管局领导审批。

（四）凡外单位或个人来咨询统计数据的，应持单位介绍信或个人身份证。一般情况下，不允许用电话向外提供统计数据。

（五）对外发布的统计调查数据，必须遵守《中华人民共和国统计法》及其实施细则规定。

二、综合统计数据信息发布内容及时间要求

（一）月度综合统计数据的发布

1、每月18日前发布全市经济运行月度分析（节假日顺延）；

2、每月19日前发布统计月报数据（节假日顺延）；

3、季后20日前发布全市经济运行季度分析。

（二）年度综合统计数据的发布

1、每年1月份起草上年度全市经济与社会发展报告；

2、每年3月份发布上年度国民经济与社会发展统计公报；

3、每年4月份出版《莆田经济与社会发展报告》；

4、每年5月份出版《莆田市统计资料手册》；

5、每年10月份出版《莆田市统计年鉴》。

三、严格执行《统计法》和《保密条例》。凡属于国家秘密、企业秘密和个人信息的，应当予以保密。凡能够识别或推断单个统计调查对象身份的资料，不得对外提供、泄露。

四、该制度自2015年1月1日起执行。以往相关制度与本制度有冲突的，以本制度为准。

五、本制度由综合科负责解释。
