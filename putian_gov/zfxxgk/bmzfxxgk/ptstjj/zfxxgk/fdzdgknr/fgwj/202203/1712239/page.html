莆田市统计局2021年法治政府建设情况总结

发布时间：2022-03-17 17:50
| | |
 

2021年，在市委、市政府的正确领导下，市统计局坚持以习近平新时代中国特色社会主义思想为指导，增强“四个意识”，坚定“四个自信”，做到“两个维护”，全面贯彻党的十九大和十九届历次全会精神，深入学习宣传贯彻习近平法治思想，认真落实党中央、国务院关于深入推进依法行政加快法治政府建设的决策部署，按照依法治国、依法执政、依法行政共同推进，法治国家、法治政府、法治社会一体建设的要求，努力以法治凝聚共识、以法治规范统计，全面推动依法统计工作，为我市高质量发展落实赶超提供坚强的统计保障。

一、2021年法治政府建设具体做法和成效

(一)提升政治站位，深入夯实依法统计基础

市统计局党组从提升政治站位入手，召开局党组会、党组中心组专题学习研讨会、各县（区）统计局长会议等，深刻学习领会习近平总书记关于统计工作的重要指示批示精神和中央《关于深化统计管理体制改革提高统计数据真实性的意见》（以下简称《意见》）、《统计违纪违法责任人处分处理建议办法》（以下简称《办法》）、《防范和惩治统计造假弄虚作假督察工作规定》（以下简称《规定》）《关于更加有效发挥统计监督职能作用的意见》（以下简称《监督意见》）等中央重要统计改革文件精神。结合““再学习、再调研、再落实”主题活动，将学习传达习近平总书记关于统计工作的重要指示批示和《意见》《办法》《规定》作为市统计局主题活动的重要内容。

4月底在市委党校处级班、科级班和军转班上举办专题讲座，邀请省统计局执法监督局二级调研员熊恒全系统解读中央《意见》《办法》《规定》和统计法律知识。11月底在市政府举办全市统计业务知识与统计法律法规专题培训班，邀请福建省统计局综合处处长叶一标和统计执法监督局二级调研员熊恒全作辅导讲座。市、县（区）人民政府（管委会）分管领导、统计局局长，各乡（镇、街道）分管领导，市直相关部门分管领导，市统计局领导和各专业人员等共110多人系统学习了习近平总书记关于统计工作的重要指示批示和《意见》《办法》《规定》《监督意见》以及统计法律法规、GDP核算知识等。全市统计系统采取集中培训和实地调研等有效措施，重点抓好各级党政领导、相关部门负责人和统计人员统计法治宣传教育，明确各级领导干部防范统计造假、弄虚作假的主要责任和主体责任，推动各级党委政府及相关部门组织有关领导干部和公职人员深入学习中央关于防惩统计造假文件精神，增强自觉性、责任心和担当意识。

（二）创新方式方法，广泛开展普法宣传活动

一是抓好领导干部统计法律法规宣传。积极推进“统计法进党校”活动。4月28日，在市委党校举办统计法律法规专题讲座，邀请省统计局执法监督局二级调研员熊恒全作《深刻领会统计发展改革新论述 依法保障统计数据质量新提升》专题讲座。二是抓好各级统计干部法治宣传。7月22日，市统计局、莆田调查队联合举办新修订的《行政处罚法》专题辅导讲座，邀请福建理策律师事务所彭晓红律师对新修订的《行政处罚法》进行全面解读。三是抓好统计调查对象学法遵法。充分统计业务培训会、年报会等载体，把统计违法典型案例、统计法律法规知识等列入必讲内容，不断提高统计调查对象依法统计的意识。四是抓好社会公众普法宣传。9月9日至10月31日期间，在莆田电视台滚动播放“热烈庆祝第十二届中国统计开放日主题宣传标语。五是认真开展统计法治动漫微视频作品征集活动。3月16日，印发了《莆田市统计局关于开展统计法治动漫微视频作品征集展示活动的通知》，在全市统计系统范围内征集统计法治动漫微视频作品，并于11月20日向省统计执法监督局选送3件作品。

（三）强化执法监督，依法规范行政权力运行

一是加强统计执法监督力量。经市委市政府研究同意，增加市统计局1个行政编制，专门用于统计执法监督岗位，进一步增强市级统计执法监督力量。二是严肃查处统计违法案件。2021年全市共立案查处统计违法企业56家，罚款232.7万元，对统计上严重失信企业进行网上公示4家，问责有关责任人43人，切实起到了“查处一案，教育一片”的效果。三是扎实开展统计数据质量检查核查工作。认真组织开展农业、工业、固定资产投资、服务业、劳工、贸易业、能源等全专业的统计数据质量核查工作，切实确保源头数据质量。四是全面清理纠正违反统计法精神的文件和做法。全市各级党委、政府和有关部门共清理2021年以来违反统计法精神文件和做法22件，其中废止11件，修改11件。五是认真做好统计违法案件通报工作。每季度通报各县(区)开展统计执法检查和查处统计违法行为的情况，并提出统计法治工作意见和要求。

二、存在的困难和薄弱环节

同全面依法治国的新形势新要求相比，同法治政府建设和依法行政的目标相比，同社会各界对统计数据质量的期望相比，我局在法治政府建设、依法统计进程上还存在一定的差距和不足。

（一）统计法治未深入人心

少数地方和企业依法统计依法治统意识不强，统计造假、弄虚作假等违法现象依然存在；虽然经过多年努力,《统计法》等相关的统计法律法规，逐渐为人们所认识,但全社会对统计法律法规的认知度总体程度不高,调查对象对统计调查工作配合还不够积极主动。

（二）统计执法监督力量明显不足

全市各级统计执法监督力量明显不足，尤其县级统计机构基本没有专职统计执法人员。

（三）统计基层基础较为薄弱

基层统计人员不足，特别是在乡镇大多没有专职的统计人员，多是兼职人员，甚至临时负责。许多企业中负责统计工作人员变动频繁，流动性大，对业务不熟，影响了源头统计数据质量。

三、2022年工作思路和工作计划

2022年，市统计局将坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届历次全会精神，深入学习宣传贯彻习近平法治思想，认真落实党中央、国务院关于深入推进依法行政加快法治政府建设的决策部署，进一步深入学习贯彻《意见》《办法》《规定》《监督意见》，加大统计法治宣传力度，不断完善统计法律制度，全面建立防范和惩治统计造假、弄虚作假责任制，加强统计执法监督力度，依法查处统计违法行为，扎实推进我市依法统计依法治统。

（一）深入宣传贯彻《统计法》《统计法实施条例》《全国经济普查条例》以及《意见》《办法》《规定》《监督意见》

重点抓好各级党政领导、相关部门负责人和统计人员宣传教育，确保将统计法律法规和中央文件精神传达到《办法》规定的相关副科级以上领导干部及与统计有关的负责人和统计人员。

（二）提升统计普法宣传效果

积极推进统计“八五”普法宣传，深入开展统计法宣传“六进”活动，把握“中国统计开放日”“12.4全国宪法日”等重要时间节点，创新法治宣传模式，提高统计法治意识，营造全社会学法、守法、用法、尊法的良好氛围。

（三）加强统计执法力量建设

进一步充实和完善市级统计执法骨干人才库，充分调动基层执法骨干的工作积极性和主动性。加强对统计执法人员的业务培训，提高基层执法人员的业务水平，规范统计执法行为。

（四）加强统计监督检查

保持高压态势落实查处统计违法案件责任制和问责制。依法依规严肃查处统计违纪违法行为，充分运用约谈、通报、告诫、曝光等措施，增强统计监督检查威慑力。
