莆田市统计局关于印发2016年度绩效管理工作方案的通知

发布时间：2016-09-21 00:00
| | |

本局各科室（中心）：

根据《中共莆田市委办公室 莆田市人民政府办公室关于印发2016年度绩效管理工作方案的通知》（莆委办〔2016〕38号）精神，结合统计工作实际，经研究，现将《莆田市统计局2016年度绩效管理工作方案》印发给你们，请结合工作实际和岗位职责，认真贯彻执行。

莆田市统计局

2016年9月21日

莆田市统计局2016年度绩效管理工作方案

为认真贯彻落实市委、市政府关于绩效管理工作的具体要求，根据《中共莆田市委办公室 莆田市人民政府办公室关于印发<2016年度绩效管理工作方案>的通知》（莆委办〔2016〕38号）精神，结合统计工作实际，拟定2016年度莆田市统计局绩效管理工作方案。

一、指导思想

以党的十八大、十八届三中、四中全会和习近平总书记系列重要讲话精神为指导，结合“三严三实”专题教育活动，深入推进绩效管理实践，促进统计部门认真履职、创新管理、转变作风、优化服务，努力提高统计能力、统计数据质量和政府统计公信力，为推动莆田科学发展、跨越发展提供统计保障。

二、组织领导

绩效管理工作在市委、市政府和市机关效能建设领导小组的领导下进行。为加强对绩效管理工作的组织领导，决定成立2016年度莆田市统计局绩效管理工作领导小组，组长由李瑞火局长担任，副组长由副组长卢庆涛担任，成员由各科室（中心）负责人组成。领导小组下设办公室，主任由卢庆涛副局长兼任。绩效管理工作领导小组具体负责绩效管理工作的组织领导、方案制定、自我评估、研究分析和督促落实等工作。

三、绩效管理指标考评内容和考评方法

市委、市政府重点考评我局贯彻落实五大新发展理念、“十三五”规划、“三去一降一补”五大任务、行动计划、2016年政府工作报告、开展“三比一看”活动、深化“马上就办”等情况，以及履职尽责、自身建设、改革创新等情况。考评采取指标考核、公众评议、察访核验相结合的方式进行。

绩效考评得分＝指标考评得分×70%＋公众评议得分×30%－察访核验扣分。

四、绩效管理实施步骤

（一）制定方案，动员部署（2016年9月1日—9月20日）

按照《2016年度莆田市绩效管理工作方案》要求，认真研究制定《莆田市统计局2016年度绩效管理工作方案》，明确目标任务和责任分工。组织全局干部职工认真学习全市绩效管理工作有关会议精神和文件规定，充分认识开展绩效管理工作的重要性和必要性，切实增强做好绩效管理工作的积极性和自觉性，扎实推动工作开展。

（二）组织实施，常态管理（2016年9月21日—12月31日）

建立绩效目标工作台账，加强日常跟踪督促，推进工作落实到位。各科室（中心）要对照《莆田市统计局绩效考核指标体系》（详见附件1）责任分工和评分标准，认真设定各自负责落实指标的年度工作目标，注意日常相关资料的收集、分类和存档，并在每个月10日之前向办公室报送各自负责指标的绩效目标工作台账（附件2）以及提升机关效能、工作绩效方面的文件通知和工作信息。对未按序时进度完成、进度不够明显的工作指标，要注意分析存在的问题及原因，及时采取有效措施加以推进，确保我局各项绩效工作指标保质保量完成。办公室要及时汇总各科室绩效目标工作台账，并于每月15日前在市政府门户网站上向社会公开。

（三）分析汇总，自我评估（2017年1月1日—1月5日）

各科室（中心）要对照绩效管理工作方案，全面系统地对各自负责落实指标工作进行自我评估和客观分析，认真收集相关迎检资料，并于2017年1月5日前报到办公室。办公室要收集、汇总各科室相关迎检材料，进行初步审核把关，形成全面、完善的迎检材料。

（四）迎接检查，完善提升（2017年1月5日—1月31日）

根据市效能办、市直机关党工委的安排，认真做好绩效迎检工作。绩效考评检查结束后，根据考核组反馈的情况，各科室（中心）要针对存在的问题和不足，及时进行深入分析，查找问题症结原因，制定整改措施，推动我局工作科学化水平进一步提升。

五、几点要求

（一）统一思想认识。树立正确的绩效价值观，把绩效管理作为行政管理的一项基本制度，增强主体责任意识，有力促进各项工作任务落到实处。各科室（中心）负责人是本科室绩效管理工作第一责任人，对本科室的绩效管理工作负总责。全局上下要继续贯彻为民、务实、高效、清廉的工作作风，共同提升效能工作，共同维护统计良好形象，全力争取在全市绩效考评中取得优秀等次。

（二）强化统筹协调。办公室要充分发挥组织协调作用，统筹协调相关科室（中心），做好各个环节的衔接，提升整体工作合力。办公室每季度要检查各科室（中心）完成绩效考评各项工作和绩效目标工作台账建设情况，及时发现问题，及时协调解决，确保绩效管理工作顺利开展。

（三）强化结果应用。各科室（中心）要以严谨细致、务实求效的作风共同做好绩效管理工作，做到资料真实完整，数据准确可靠，台账规范有序。要坚决防止和克服形式主义，坚决制止马虎应付、弄虚作假现象。市委、市政府对我局考评情况将作为年度评先、评优主要依据之一。凡受到党政纪责任追究、党政领导干部问责、效能问责的、年度考核被评为不称职（不合格）的、被省效能办、市效能办查实或通报存在作风纪律问题的和旷工人员，一律不享受绩效奖励（其中：凡是单位自查发现问题并给予诫勉教育、通报批评、效能告诫效能问责的人员，可以发放80%、70%、50%绩效奖励）。年度请病假累计超过2个月或请事假超过8个工作日的人员，从超过的工作日起，其绩效奖励按日减发。被省、市察访核验发现涉及上班做与工作无关事情的作风纪律问题，给予当事人效能告诫以上处理。

附件：1．2016年度莆田市统计局绩效考核指标体系

2．莆田市统计局2016年1- 月绩效目标工作台账
