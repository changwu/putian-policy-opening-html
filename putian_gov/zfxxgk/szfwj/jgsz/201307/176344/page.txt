附件
莆田市旅游产业发展领导小组及其办公室
工作规则
为贯彻落实中共莆田市委、莆田市人民政府《关于加快旅游产业发展的实施意见》，进一步发挥市旅游产业发展领导小组(以下简称“领导小组”
)
的组织领导和指导协调作用，特制定领导小组及其办公室工作规则。
一、领导小组工作规则
(
一)
主要职责
1.
指导全市旅游产业发展总体规划的制订和实施，加强对全市旅游产业政策、旅游重点项目的指导与协调，检查督促扶持旅游产业发展政策措施的贯彻落实。
2.
建立旅游产业发展形势研究分析制度和旅游产业运行通报制度，研究协调解决全市旅游产业发展中的重大问题，通过适当形式通报旅游产业运行情况。
3.
制定并实施旅游产业发展目标管理和考核评价制度，对领导小组成员单位和各县（区）人民政府（管委会）完成推进旅游产业发展目标任务情况进行考核。
(
二)
工作制度
1.
每年召开1次领导小组全体会议，听取工作汇报，研究决定相关重大问题。根据工作需要，可临时召开专题会议。
2.
领导小组下发的文件及会议纪要，由组长签发。
3.
授权领导小组办公室负责日常的组织协调工作，处理日常相关工作，重要事项由办公室报经领导小组组长审定后执行。
二、领导小组办公室工作规则
（一）主要职责
1.
在领导小组的领导下，承担领导小组的日常工作，做好领导小组全体会议的相关工作，组织开展旅游产业发展的协调、宣传、督导、考评及专题调研等工作。
2.
根据市委市政府及领导小组确定的工作任务，分解细化工作目标，制定工作计划，并督促协调落实。
3.
牵头组织成员单位对领导小组成员单位和各县（区）人民政府（管委会）落实旅游产业发展目标、任务措施执行情况的督查督办和考核评价工作。
4.
组织做好旅游产业发展工作成效、典型经验、重要改革举措等宣传报道，营造促进旅游产业发展的良好氛围。
5.
做好领导小组交办的其他工作。
（二）工作制度
1.
每季度召开1
次领导小组办公室会议，或根据工作需要不定期召开会议，根据议题由办公室确定参加会议的具体成员单位。
2.
领导小组办公室主任主持办公室全面工作，处理办公室日常事务，领导小组办公室的文件和会议纪要由办公室主任签发。
3.
有关重要事项须报领导小组组长审定。应由领导小组研究决定的事项，要及时提请领导小组会议研究决定。
三、成员单位职责分工
(
一)市政府办公室：
负责统筹协调全市旅游工作。
(
二)市旅游局：
负责协调落实市旅游产业发展领导小组的决定事项，做好领导小组的日常工作。
(
三)市台办：
负责指导全市对台旅游工作，对入岛宣传进行政策指导和把关，协调处理涉台旅游重大活动和突发性事件。
(
四)市发展改革委：
负责将旅游业发展列入国民经济和社会发展中长期规划的重要内容，指导旅游产业发展规划的制定和年度计划的实施；审批职责权限内的旅游资源保护和开发项目，支持将重点旅游项目列为市重点项目；制定并实施红色旅游等建设规划，争取国家、省级资金和安排市级预算内资金支持旅游基础设施建设，支持有条件的旅游企业上市融资；指导推进旅游产业信息化工作，落实相关支持政策。
(
五)市城乡规划局：
负责编制市旅游产业发展总体规划，做好旅游规划与城乡发展规划、土地利用规划、自然与人文资源保护利用规划等的衔接。
(
六)市经贸委：
负责协调发展工业旅游，促进旅游商品开发、旅游餐饮、购物、旅游装备制造业等发展；协调旅游市场食品安全工作；推动旅游企业节能改造，发展低碳旅游；负责推动游艇旅游发展。
(
七)市民族与宗教事务局：
负责旅游景区内宗教场所的管理。
(
八)市公安局：
负责加强旅游场所治安管理，保障旅游市场消防安全和道路交通秩序，为旅游者提供安全的社会环境；为旅游者出入境提供方便。
(
九)市监察局：
负责指导规范行政机关事业单位委托旅行社办理公务活动有关工作。
(
十)市民政局：
负责指导开展红色旅游工作，协调落实促进发展的相关政策。
(
十一)市财政局：
负责研究落实支持旅游产业发展的财政政策，做好市级旅游专项资金的保障与监管，协同争取省级旅游发展专项资金。
(
十二)市国土资源局：
负责做好旅游用地与土地利用总体规划的协调，做好地质公园的开发建设、保护利用管理。
(
十三)市环境保护局：
负责组织实施旅游项目环境保护评估工作，监督旅游景区行政管理部门落实环境保护工作。
(
十四)市住房和城乡建设局：
负责指导城乡旅游公共服务设施建设；做好自然遗产和风景名胜区的保护、利用和管理工作；指导名城名镇名村建设，完善城镇旅游配套设施。
(
十五)市交通运输局：
负责组织、指导全市公路网等交通专项规划修编，注重与旅游景区的连接；加快通往重点旅游景区公路的建设改造，规范公路旅游标识设置，开通旅游客运专线，构建完善的旅游交通网络；在火车站、汽车站建设旅游集散中心；依照职责加强旅游客运企业管理，保障旅游交通需求。
(
十六)市林业局：
负责制定并实施全市森林旅游发展规划；推进森林公园、湿地公园和自然保护区旅游资源合理开发、保护利用管理。
(
十七)市水利局：
负责水利风景区发展规划的制定和实施，加强水利风景区开发利用和管理保护工作。
(
十八)市海洋与渔业局：
负责制定并实施全市滨海旅游发展规划；落实旅游业发展的用海相关政策；推动无居民海岛旅游开发。
(
十九)市外经贸局：
负责旅游项目的对外招商引资，为旅游业发展吸引更多的境外投资；落实促进旅游业发展的相关口岸政策。
(
二十)市文化广电新闻出版局：
负责制定并实施文化旅游发展规划；做好文化遗产的保护利用管理；指导各级文物保护单位开展旅游活动、开发非物质文化遗产成为旅游产品；规范涉旅文化娱乐场所的经营管理。
(
二十一)市卫生局：
负责旅游酒店、旅游景区、餐饮服务单位食品安全监督检查，做好游客的伤病救治工作。
(
二十二)市农业局：
负责制定并实施全市休闲农业旅游发展规划，开展休闲农业示范创建活动，落实促进休闲农业发展的相关政策。
(
二十三)市外侨办：
负责协助开发海外华人华侨旅游市场，在各类对外交往活动中加大旅游宣传力度，加强与国际友好城市间的旅游交流与合作，协助开拓境外旅游客源市场。
(
二十四)市国资委：
负责指导市属国有企业的改革发展工作。
(
二十五)市工商局：
负责对相关旅游经营行为实施监督检查；打击旅游市场非法经营、虚假广告和购物场所的假冒伪劣商品等行为；受理旅游消费投诉案件，配合主管部门对旅游市场联合管理。
(
二十六)市质监局：
负责旅游业相关的国家标准、行业标准和地方标准的宣贯和实施；对相关旅游经营行为实施监督检查；加强旅游商品质量的监督抽查；负责游乐设施和酒店电梯安全运行；推进旅游服务品牌的创建。
(
二十七)市体育局：
负责制定实施全市体育旅游发展规划，开展体育旅游示范基地试点，落实促进发展的相关政策。
(
二十八)市安全监督局：
负责指导全市旅游行业的安全工作，监督检查旅游企业落实安全生产责任制。
（二十九）市统计局：
负责指导发布旅游统计信息；做好旅游统计和旅游抽样抽查工作，配合做好旅游经济预报预测工作。
（三十）市物价局：
负责规范旅游市场价格秩序；加强对旅游景区门票价格管理；依法查处旅游行业乱收费行为。
（三十一）市新闻办：
负责开展旅游公益形象宣传；组织境
内外新闻媒体、市级重点新闻网站开展多种形式的旅游宣传和报道。
（三十二）中国人民银行莆田中心支行：
负责引导银行业与金融机构加大金融支持旅游产业发展的力度，落实促进发展的相关政策。
（三十三）市气象局：
负责加强气象对旅游发展的相关服务工作。
（三十四）市铁路建设办公室：
负责协助做好列车及车站的旅游宣传和旅游安全工作。
（三十五）各县（区、管委会）：
负责辖区内旅游安全工作，负责推进旅游项目开发建设。
