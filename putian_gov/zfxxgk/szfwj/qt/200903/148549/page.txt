发布时间: 2009-03-10 00:00
文号: 莆政办〔2009〕48号
发布机构: 莆田市人民政府办公室
栏目: 其他
原始链接: https://www.putian.gov.cn/zfxxgk/szfwj/qt/200903/t20090310_148549.htm
正文:
各县（区）人民政府（管委会），市政府各单位、各直属机构：
经市政府同意，现将《莆田市
2009
年政府信息公开工作要点》印发给你们，请结合实际，认真贯彻执行。
二○○九年三月三十日
莆田市
2009
年政府信息公开工作要点
为推进《中华人民共和国政府信息公开条例》在我市的深入贯彻落实，把推进政府信息公开与转变政府职能结合起来，提高政府科学执政、民主执政、依法执政的能力和水平，结合我市实际，
2009
年政府信息公开重点要抓好以下工作：
一、健全完善工作机制，推进《条例》全面实施
(
一
)
强化组织建设。
各级各部门要进一步加强政府信息公开工作机构建设，明确工作任务、履行工作职责、落实工作责任，未设立政府信息公开专职机构的部门及单位要按照《条例》要求，比照市级组织形式，尽快设立或指定相应的工作机构、稳定工作人员、落实办公条件、保障办公经费。
(
二
)
制定工作计划。
各级各部门要根据《条例》规定的政府信息公开工作机构的具体职责，结合本机关工作实际，将政府信息公开作为本单位一项正常化、规范化的工作重点，明确界定主动公开、依申请公开和不予公开政府信息范围，不断充实更新政府信息公开的《指南》和《目录》，规定时限，有计划、有步骤地推进政府信息公开工作。
(
三
)
健全工作制度。
各级各部门要进一步健全信息公开工作的各项制度，严格按照省市“两个规定，五项制度”做好政府信息公开工作。
二、完善运作体系，强化政府信息公开
(
一
)
主动公开政府信息。
要按照《条例》规定“以公开为原则，以不公开为例外”的原则，准确区分政府信息的公开属性，科学界定公开和不能公开的政府信息，凡属应当公开的信息必须按照规定纳入目录，在《条例》规定的期限内予以公开，今年年底前要完成
2003
年以来政府信息的内容梳理、界定和发布工作。
(
二
)
加强保密审查工作。
各级各部门严格执行政府信息公开前保密审查制度，确保“上网信息不涉密，涉密信息不上网”，对拟公开的政府信息要严格按照“谁公开、谁审查、谁主管、谁负责”的原则进行，改进完善审查程序，对拟公开政府信息实行单签制，明确有关保密审查的职责分工、责任追究办法，保证政府信息不得危及国家安全、公共安全、经济安全和社会稳定。
(
三
)
进一步做好依申请公开政府信息工作。
及时更新依申请公开政府信息目录，规范受理申请程序，规范运行市“政府信息公开申请”网上处理系统，严格按照依申请公开政府信息的工作流程、服务方式、服务内容、操作要求和办结时限受理、处理公众提出的信息申请，确保公众的申请、咨询有人受理、按时回复，稳妥处置依申请公开政府信息工作，提高服务水平和质量。
(
四
)
畅通信息公开渠道。
各级各部门要依据《条例》要求进一步拓宽信息公开渠道，加强对政府信息查阅场所的建设，提高政府信息查阅服务能力，通过网站、广播、电视、报纸、档案馆、图书馆、宣传栏、热线等多形式公开群众需要广泛知晓的政府信息，方便公众获取政府信息。
三、加强学习培训，提高政府信息公开业务水平
(
一
)
深入开展培训。
一是加强对领导干部的培训，行政学院
(
市委党校
)
要把《条例》作为领导干部培训的重要内容
,
增强其依法行政和做好政府信息公开工作的责任意识；二是分层次
(
市政府及其工作部门、各县区、乡镇
)
、分部门
(
政府组成部门、社会服务部门、双重管理部门
)
、分系统培训，通过集中授课、座谈研讨、以会代训等方式加强业务人员对政府信息公开政策标准界定和具体操作技术运用；三是组织开展先进地区的考察培训，通过实地考察、网上探索等形式
,
学习借鉴信息公开工作起步较早、开展较好的先进地区的经验，结合我市实际，尽快提升整体工作水平。
(
二
)
注重分类指导。
一是市政府各单位在做好本部门政府信息公开工作的同时，担负起对本部门所属单位或归口管理企事业单位的信息公开工作的推进、指导、协调、监督职责；二是各县区政府要积极推进县区直部门、乡镇政府或街道办事处的政府信息公开工作，加强跟踪指导
,
及时发现问题，解决工作漏洞
,
推进《条例》在我市的全面贯彻落实。
(
三
)
加强网站建设。
各县（区、管委会）、市政府各单位、市有关单位要把政府网站作为政府信息公开的第一平台，大力推进政府网站建设
,
不断完善网站功能，充实网站内容，让政府网站真正成为为民利民便民的重要载体。一是完善政府信息公开平台，加强政府信息公开系统建设
,
做好系统技术培训工作，实现政府信息的互联互通、快捷方便、安全稳定，保障网上政府信息发布的权威、准确、完整和及时性；二是优化信息公开栏目
,
充实和丰富专栏内容，加强纵横连接，没有链接的要及时做好链接，增强服务功能；三是加强子站建设
,
充分利用市政府门户网站平台，依托其网络条件、硬件设备、软件系统和安全保障体系，推进子站建设，加强网站应用和管理，保证其安全、有效、可靠运行，充分发挥政府网站在政府信息公开、公共服务和互动交流等方面的重要作用。
(
四
)
推进公共企事业单位信息公开。
按照《条例》要求
,
各级各部门要积极推进教育、医疗卫生、计划生育、供水、供电、供气、公共交通等与人民群众利益密切相关的公共企事业单位信息公开工作。提高公共企事业单位对政府信息公开工作的认识，督促其建立健全制度，促进政府信息公开工作在这些单位有序开展。
(
五
)
做好统计分析和季年报编制工作。
各县（区、管委会）、市政府各单位要按照《条例》要求，认真落实省市政府的有关安排部署，及时上报政府信息公开季报表，为市级政府信息工作季报提供基础性信息，做好本机关实施政府信息公开有关情况的统计分析，按照统一的格式编制
2009
年政府信息公开季报表和年度报告，并按照时限要求送市政府信息公开办公室。同时，年度工作报告应在翌年
3
月
31
日前向社会公布。
(
六
)
加大工作考核监督力度。
一是各县（区、管委会）、各部门各单位要结合实际，把信息公开工作作为单位绩效考评、目标管理和干部考核的一项主要内容，建立内部监督机制和社会评议，制定政府信息公开考评细则，量化考核标准，及时推进下级归口部门的政府信息公开工作。二是各级监察部门和保密部门应依据各自的职责，加强对《条例》落实情况的监督、监察和评议。三是市政府信息公开办公室将在市政府信息公开领导小组的统一部署下，定期和不定期的组织开展政府信息公开工作检查，重点考核各部门各单位信息公开的基础工作、制度建设、信息更新、信息报送、网站建设等落实情况
,
并定期予以公开通报。
