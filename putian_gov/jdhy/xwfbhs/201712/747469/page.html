“莆田城乡一体化综合配套改革试验五周年”新闻发布会答记者问

来源:东南网 时间：2017-10-13 15:32
| | | |
 

东南网10月12日讯（本网记者 冯川叶）今日上午省政府新闻办举行“莆田城乡一体化综合配套改革试验五周年”新闻发布会。以下是新闻发布会答记者问实录：

记者：当前莆田正在积极推进美丽莆田建设，城乡一体化改革作为其中的重要内容，同时，在过去五年，莆田在城乡一体化方面也取得许多成就，请你谈谈莆田市未来如何围绕美丽莆田建设，进一步推进城乡改革的发展蓝图？

莆田市委副书记、莆田市城乡一体化工作领导小组常务副组长程强:下一步，我们将对照省委省政府对莆田的期望和要求，结合美丽莆田行动，以更高的标准、更优的状态推动建设、加快统筹发展，推动城乡一体化上新台阶。重点做好以下几个方面：

1、着力打造一个新平台。围绕传统特色产业提升和新兴产业发展，以特色小镇建设作为产业转型升级的新平台，依托特色小镇这个平台，推动资源整合、项目组合和功能融合，推动各特色小镇在有限的空间内进行优势产业和龙头企业的集聚，形成占据产业价值链顶端的产业，实现医疗养生、文化旅游、电子商务等特色产业的集聚壮大，把莆田人的产业转化为莆田市的产业。

2、继续打造一批精品示范。在巩固提升、持续推进121个“幸福家园”试点村建设的基础上，着重打造一批精品示范村，推动“文化传承、拆旧建新、以企带村、乡村旅游、土地流转”等“幸福家园”建设模式在条件相似的试点村进行复制推广，引导不同类型的试点村向更多方向进行探索，以挖掘形成更多试点建设新亮点、新经验。同时，由一村一村的试点建设向连片提升的小镇开发模式转变推进，打造产业发展连片、基础设施共享的升级版“幸福家园”。

3、继续深化一批制度改革。坚持以人为本，健全推进农业转移人口市民化的体制机制，促进“老市民”和“新市民”的和谐发展。以户籍制度改革为突破口，持续探索教育、医疗、社会保障等制度改革，逐步扩大为居住证持有人提供公共服务和便利的范围，提高服务标准，使居住证持有人逐步享有与当地户籍人口同等的就业、教育、公共卫生等基本公共服务和便利。

记者：近年来，特色小镇成为高频词汇，各地也日益掀起了建设特色小镇的高潮。刚才您在介绍中也提到了这方面的情况，能否详细介绍下莆田特色小镇的创建情况？

莆田市发改委主任王世文：特色小镇是城乡一体化的创新发展模式，完全适应我国新常态下全面小康的发展需要。莆田市委、市政府高度重视创建特色小镇，采取了“两强化、两创新、两落实”措施，推进特色小镇创建。一是强化统筹协调。以美丽莆田为平台，把11＋3特色小镇（文化名胜区）列入30项重大攻坚项目，市委书记和市长每月亲自召开协调会，研究部署协调推进。制定出台11＋3特色小镇（文化名胜区）创建文件，每个特色小镇分别由1-2名市领导挂钩，发挥“领导＋”合力，统筹推进特色小镇创建。二是强化政策扶持。出台对纳入省市特色小镇创建名单的，市里分别给予1000万元和500万元的资金补助，县区（管委会）等额配套政策。与国家小镇城中心签订100亿元新型城镇化子基金的框架协议，扶持我市特色小镇建设。三是创新工作机制。提出每个小镇“一个规划、一个管委会、一个开发公司、一个产业基金、一套政策”的“五个一”工作机制，促进各项建设提速增效。四是创新培育理念。以产业生态圈的理念推动特色小镇培育创建工作，打造产业发展的平台，把莆田人在全国的优势产业转化为莆田市的支柱产业。五是落实规划创建。4个列入全省首批特色小镇创建名录的，已通过专家评审并报省城镇化办备案。对创建市级的特色小镇，我们借智借力，对接盘古智库，为我市的特色小镇创建进行把脉。六是落实创建进度。今年以来，我市特色小镇工程包共策划项目106个，截至9月份，共完成51.6亿元，完成年度计划（67亿元）的76.9%，项目建设总体进展快、态势好。

刚才您介绍了莆田以幸福家园试点建设为抓手和突破口来以点带面推动城乡一体化建设，那么在幸福家园试点建设过程中，如果确保让农民真正得到实惠。

莆田市发改委主任王世文：习近平总书记指出：“让老百姓过上好日子是我们一切工作的出发点和落脚点”。推进城乡一体化改革，最终目的就是要让老百姓过上好日子，有更多的获得感，这是我们的工作方向。一是充分尊重群众意愿。在规划编制过程中，每个试点村我们都充分听取群众意见，把群众最想做、最迫切需要做的事情首当其冲规划好。在项目建设过程中，我们充分考虑群众需求，切实把涉及群众切身利益、群众最急需解决的问题落实好，确保群众利益得到最大化。二是配套设施有效改善。试点获批以来，我市已先后组织实施了1387个项目，完成投资72.3亿元。实现村村道路通、污水通、电讯通；村村有绿色乡村、绿色屏障、绿色河岸和绿色通道；村村配套农村公园、小学、幼儿园、卫生服务站、文化站、社区超市、银行网点、村道路灯、公交停靠站和社区服务中心，这些基础的改善，让群众切切实实感受到农村城市化的生活。三是农民收入持续提高。我们立足资源禀赋，围绕“一村一品”逐村思考产业发展方向，策划产业发展项目，宜工则工、宜农则农、宜商则商、宜游则游，有效提高农民收入。截至2016年，我市农村居民人均可支配收入由2012年的10311元，提高到15131元，增长46.7％。

莆田推进城乡一体化的进程中，如何在医疗保障政策上，实现农村和城镇居民的同等待遇？

莆田市医保局局长刘明辉：健康是广大人民群众对美好生活的共同追求，而如何保障人民健康是我们医改的出发点和最终目标。莆田市医保局成立之前，职工医保、城镇居民医保、新农合这“三保”隶属不同部门，并实行县区统筹，报销目录不统一，参保的待遇也不相同。如何消除城乡差异、实现公平，一直是我们努力的方向。2017年，莆田市委、市政府按照省委、省政府的统一部署，参照“三明医改模式”，结合莆田的实际，于今年2月14日成立莆田市医保局和莆田市医保中心，整合了卫计、民政、财政、人社、商务、物价等部门中相关职能，优化机构设置，理顺职责关系，提高行政效能。目前我们已经完成了人、财、物和职能的划转工作，并结合本地实际，加大改革力度，出台了城乡一体化医保政策，切实让群众得到实惠。归纳为“六统一”、“四提高”和“一降低”。

一是城乡居民医保实现“六统一”。也就是全市城镇居民和农村居民医保在覆盖范围、筹资政策、保障待遇、医保目录、定点管理和基金管理等方面实行“六统一”，让农村居民享受与城里人一样的医保待遇。医保基金也由原来的县（区）级统筹模式转变为市级统筹。

二是城乡居民医保待遇“四提高”。提高普通门诊补偿待遇。乡镇卫生院（社区卫生服务中心）普通门诊不设起付线，按照60％予以补偿，并将符合一体化管理条件的村卫生所纳入医保定点范围。提高重大疾病报销比例。将血友病、等9种重大疾病，报销比例从原来的50%-70%统一提高到80%。提高门诊特殊病种待遇。城乡居民医保门诊特殊病种从原来28种增加到32种。提高严重精神障碍患者住院报销比例，市内住院不设起付线，统一按90%予以报销。

三是大病报销门槛实现“一降低”。从今年开始，大病保险补偿起付线从2万元下调到1.5万元，年累计封顶线33万元。

以上城乡一体化医保惠民政策实施后，2017年度医保基金与去年相比预计增加支出4亿多元，切实让群众得到实惠。

同时，我们创新医保服务模式，在全市二级以上定点医院设置医保服务站、实行医保管办分离、医保经办服务实行“5+2”，尤其在在全省率先实现医保经办服务“就近可办、同城通办”给群众带来实实在在的便捷。2017年8月10日省委办《八闽快讯》第152期刊登了上述内容。

记者：莆田市委、市政府提出了“坚持绿色发展，打造宜居港城、建设美丽莆田，创建美丽中国的示范区”的发展目标，坚持绿色发展是其中重要内容，那么，莆田的城乡一体化建设又是如何实现绿色发展。

莆田市委副书记、莆田市城乡一体化工作领导小组常务副组长程强:1、贯彻生态保护理念。坚持“留文、留白、留绿、留脉”，以创建国家森林城市为抓手，打造百万人口“环绿大都市”。如在城市内部保留60平方公里的生态绿心，充分发挥了生态绿心的城市绿肺作用，有效防止城市的热岛效应；同步推进中心城区周边的木兰溪、延寿溪、东圳水库和壶公山、凤凰山、天马山、龟山等荔林山水资源的整治和保护；从2012年起，每年都加快建设沿江、沿河、环湖、达山、通公园的慢行廊道和景观休闲性慢行网络，计划到2020年完成1000公里的绿道网建设任务，全面串联城乡自然与人文景观；又比如在大力推进城市公园建设的同时，建设一批街头绿地、小游园、街心花园等“口袋”公园，逐步实现“步行五分钟”进绿地，打造具有莆田特色的生态“绿廊”。

2、树立绿色发展导向。进一步明确生态环境保护工作职责，加强对环境目标责任书的落实，重点突出对水质、河长制落实情况的考核。创新农村生活垃圾治理考评机制，在全省率先设立农村生活垃圾治理奖励资金。研究制定生态文明目标评价考核体系，探索在领导干部自然资源资产离任审计的基础上，建立绿色发展指标体系和生态文明目标考核的办法，采取一年一评价，五年一考核，树立绿色发展新导向。

3、倾力打造绿色产业。莆田把提升绿色制造产业工程列为重点实施的九大专项行动之首，旨在深入实施创新驱动发展战略，着力打造鞋服、工艺美术、食品加工、新能源汽车、电子信息等10大优势绿色产业体系。并出台了一系列扶持政策，鼓励、引导企业通过技术创新、设备改造和节能降耗，以及整合资源来打响品牌，切实提升市场竞争力。

记者：莆田城乡一体化试点工作中，在社会保障方面有哪些突破？取得哪些成效？

莆田市人社局副局长肖兰英：在推进我市城乡一体化试点上，几年来，社会保障领域主要围绕破除城乡二元结构、打破户籍限制、政策一体化和公共服务均等化，先行先试，作了有效的探索，取得了明显成效。

一是推进社会保障政策一体化。养老保险方面。2013年，莆田市率先在省内整合了“新农保”和城镇居民养老保险制度，建立了城乡居民一体化的养老保险制度，城乡居民在参保缴费、政府补助、待遇领取等方面实现统一，目前全市参保人数已达到155万人，缴费率达到95%以上，在全省各地市中名列前茅。在特殊群体社保方面。为打破户籍限制，进一步提高进城务工人员和特殊群体的社会保障水平，几年来，我市先后出台了将进城务工人员以灵活就业人员纳入城镇社保体系，实现与城镇居民同政策、同待遇。同时，率先将乡村医生、村级组织及社会组织从业人员等几个特殊群体纳入城镇社会保障体系，从政策上提供均等化的支持。在工伤保险方面。我市2014年被人社部列为全国工伤预防试点市，几年来，我们探索建立了“三项机制、三个平台、三道程序、三个载体”，探索建立了工伤预防、工伤治疗、工伤康复“三位一体”的工伤保障机制，特别是在进城务工人员集中的建筑领域，在省内率先建立建设项目工伤保险团体参保机制，实施建设、交通、水利等建筑领域工伤保险“同舟计划”，解决了建筑工地务工人员流动性大、参保难的问题，保障了进城务工人员的工伤保障权益。全市工伤保险参保人数已超过46万人。得到上级部门的高度肯定，并在全国试点地区工伤预防工作经验交流会上作经验交流。

二是推进人社公共服务均等化。构建城乡一体的社保服务网。我市从2013年就全面先行先试，探索建立了城乡居民养老保险“不出村”便民服务模式，在全市972个村居建立起986个便民服务点，提供参保缴费、待遇领取、政策咨询等“不出村”服务，解决服务群众“最后一公里”问题。我市的这一做法得到人社部和省里的高度重视，2013年12月，全国城乡居民养老保险经办规程研讨会在莆田举办，推广莆田的经验做法。构建常态化城乡就业服务网。我市探索建立全域就业服务网络，开发就业招聘信息系统，开展城乡常态化公益性招聘活动，促进就业扶持政策城乡一体化。每年安排公益性招聘活动80多场，促进进城务工人员实现稳定就业和更高质量就业，农村劳动力每年转移就业3万人左右。同时促进市、县区、镇街三级就业服务平台建设，建设一万平方的市级人力资源市场，规范建设城乡就业社会保障服务所，明年将完成全市54个镇街就业平台建设。为支持农村贫困人口就业，我市加大开发公益性岗位，推进城乡困难家庭“一户一就业”精准就业脱贫，今年已开发1300多个公益性岗位，城镇和农村居民的就业困难人员享受同政策，今年已发放补助1200多万元，促进城乡就业困难人员就近就地实现就业。
