莆田市公安局召开第67次新闻发布会通报经侦、创城、刑侦等工作情况

来源：本网 时间：2016-05-16 14:31
| | | |

　　5月16日上午，市局召开新闻发布会，就市公安局经济犯罪侦查工作、服务全市创城工作、打击电信网络新型违法犯罪和盗抢骗犯罪等情况进行发布。市局经侦支队支队长吴栋贵、市局办公室副主任余黎明、刑侦支队支队长郭国庆结合职能，分别就相关内容进行发布。市局新闻发言人、宣传处处长郭亮主持发布会。市局刑侦、经侦、治安、禁毒、交警支队和反诈骗中心民警参加发布会。海峡都市报、福建法治报、莆田电视台、莆田广播电台、湄洲日报、莆田侨乡时报、东南网、莆田市新媒体中心等省、市主流新闻媒体记者应邀参会。 

　　莆田市公安局新闻发布会新闻稿

　　各位新闻界朋友：

　　大家好！欢迎来到莆田市公安局新闻发布会现场。今天的新闻发布会主要向大家通报全市公安机关打击和防范经济犯罪工作、强化交通管理和打击整治黄赌毒违法犯罪助力创建全国文明城市工作和打击防范电信网络新型违法犯罪工作等三个方面的公安工作。

　　一、防范经济安全风险，护航经济发展，全市公安经侦工作有为有效

　　5月15日是我国打击和防范经济犯罪宣传日。打击和防范经济犯罪宣传日的确定，从一个侧面体现了打击经济犯罪工作的重要性和专项工作与群众生活的密切关联性。

　　（一）全市经济犯罪侦查工作取得阶段性工作成效

　　2015年以来，全市公安经侦工作以“打击非法集资”、“打击金融犯罪”、“打击假冒伪劣犯罪”、“打击银行卡犯罪”“打击假币假发票”、“猎狐2015”等专项行动为主线，把打击职能作为经侦工作的立足点和有效遏制经济犯罪的主要手段，切实加大打击力度，严厉整治各类经济犯罪活动，取得了阶段性显著成效。2015年以来，全市公安机关共查获各类经济犯罪案件482起(其中部督、省督经济案件8起)，发起集群战役4起，抓获涉案人员507人，挽回经济损失5565万元。2015年，全市经侦打假成效位居全省第一、“猎狐2015”专项行动战果位居全省第三，经侦追逃工作位居全省第三。

　　（二）当前全市经济犯罪案件主要特点

　　2015年以来，全市公安机关共立经济犯罪案件756起，其中，金融诈骗、扰乱市场秩序、生产销售伪劣商品、侵犯知识产权四类犯罪占全部经济案件数的80%。从涉案金额看，侵犯知识产权、破坏金融管理秩序、生产销售伪劣商品、扰乱市场秩序四类案件的涉案值占全市经济类案件涉案总值的90%。一是信用卡诈骗犯罪加速蔓延。2015年来，全市信用卡诈骗犯罪突出并呈蔓延态势。全市共立此类犯罪223起。其中信用卡恶意透支诈骗和伪卡、复制信用卡诈骗比较常见。信用卡恶意透支诈骗主要是犯罪嫌疑人或多个银行申请办理信用卡，逐张恶意透支，或利用虚假身份证明骗领信用卡进行恶意透支，或办卡后蓄意逃避银行授权，恶意提现进行的诈骗犯罪。伪卡、复制信用卡诈骗是犯罪嫌疑人利用持卡人不慎或非法获取客户信用卡并窃取密码后持卡行骗。二是非法集资类案件发生率持续攀升。非法集资类案件涉及面广，涉案金额大，社会影响较大。2015年以来，全市共立各类非法集资案件15起，破10起。犯罪嫌疑人组成职业化团队，目标以老年人为主，针对老年人心地善良、防范意识降低，容易上当受骗的特点，编造谎言向老年人群体吸收存款。三是生产、销售伪劣商品案件依然高发。2015年来，全市生产、销售伪劣商品案件共立148起，查获113起，涉案金额达4.3亿元。公安机关抓获涉案犯罪嫌疑人143名，捣毁制假窝点129个，缴获生产假烟机器5台，成品油78吨，各类假冒品牌箱包17126个，假冒注册商标运动鞋48万多双，商标标识47万多个、鞋面、鞋底一万余双，假药、假烟及原材料大量。2015年下半年，仙游县公安局查破一起省厅挂牌督办的生产销售伪劣商品案，查获生产假烟窝点一处，缴获假烟半成品40万支、生产设备2台，涉案金额1200万元，移送起诉8人。四是组织、领导传销活动不容忽视。传销活动是一种多发的涉众型犯罪类型，涉及人员广泛，容易派生如非法拘禁罪等犯罪行为，常造成较为恶劣的社会影响。此类犯罪多采取发放广告、网络等方式，通过发展下线人员来招募人手，具有严格的组织纪律和严密的机构组织，其组织内部管理层次分明，上下线之间联系单向，且经常更换联系方式。侦破难度较大。2015年以来，全市共立组织、领导传销类案件18起，破17起。

　　（三）增强“四种意识”防范经济犯罪陷阱

　　面对当前严峻复杂的经济犯罪形势，公安机关在加大对经济犯罪打击力度、震慑犯罪的同时，在这里也真心呼吁广大人民群众一定要加强自我防范意识，刻不容缓，至关重要。群众在自我防范方面尤其要增强“四种意识”：一要增强风险意识。树立正确的投资理念，既要有经济利益的“美好”预期，更要充分认识可能带来的经济损失等多方面的风险。特别是对社会上各种明显不靠谱的所谓的“高回报”投资，绝不可轻易相信，时刻提高警惕，保持清醒，多方甄别，理性判断，合理投资，保护好自己合法财产不受侵犯。二要增强法治意识。社会公众在进行投资、经营、理财等经济活动前，尽可能了解相关的国家法律法规政策，不参与国家法律法规政策明文禁止的非法经济活动，不做盲目投资，避免遭受财产损失。三要增强防范意识。对个人银行卡、信用卡的信息，要小心、谨慎和合理使用，用卡消费时要注意遮挡，对载有个人信息的物品、资料等未经清理不可随意丢弃。特别是对个人重大信息的使用，要慎之以慎，注意防失密、防骗密、防窃密，努力做到万无一失。四要增强维权意识。受到不法侵害后，要注意保存好相关证据资料，尽快拨打110或到当地公安机关报案，全力配合公安机关做好调查取证、查询冻结、快速止付等工作，公安机关将尽最大努力为受害群众挽回经济损失。

　　二、强化路面交通管理，严厉打击整治“黄赌毒”违法犯罪，助力莆田创建全国文明城市

　　加强路面交通管理和打击整治“黄赌毒”违法犯罪两项工作是创建全国文明城市工作的重要内容。市公安局为全力助推莆田创建全国文明城市，局党委高度重视，全警积极作为，确保工作取得实效。4月下旬，市局党委副书记、副局长凌郑平带领创城工作相关职能部门领导实地考察学习厦门经验做法，专门要求全市公安机关要认真学习借鉴厦门经验，结合莆田实际，取长补短，研究改进措施，切实提升创建全国文明城市工作的实效性。下面我就公安机关加强路面交通管理和打击整治“黄赌毒”违法犯罪两项工作目前开展的情况作个通报。

　　（一）严格路面交通管理，优化出行环境

　　全市公安交管部门大胆创新，采取视频监控和路面查纠相结合、处罚曝光和宣传教育相结合的方式，不断提升交通管理水平，全力为我市创建全国文明城市营造安全畅通文明的交通秩序环境。一是持续整治路面交通秩序。组织开展“逢六逢九”统一行动、春运、“严管生命通道”、预防重特大事故等专项整治，今年前4个月，全市共查处各类严重交通违法217194起，其中酒毒驾743起、超员超载5966起、超速1244起、涉牌涉证20080起。依托路口3000多个高清视频和全市6万多个治安探头，采取事后查纠的办法，引入“黑名单”机制，对路口车辆压线变道加塞、摩托车违法乱象、行人闯红灯、滥用远光灯、车窗抛物、不礼让斑马线、交通肇事逃逸、假套牌等各类违法和交通管理难题进行大力整治。各专项整治行动以来，战果较为突出，共查扣违法“摩的”1536辆、查纠行人闯红灯2182人次、车窗抛物264辆次、查处滥用远光灯7124起、假套牌114起，起到良好的震慑、教育效果。二是不断完善道路交通设施。今年以来，对东园路沿线交叉路口的信号灯进行升级改造，实现智能控制；对万达路口、红星美凯龙路口、新附属医院路口等6个交叉路口的交通组织进行优化调整；中心城区优化调整交通护栏4处，新增中央隔离护栏约400米、机非隔离护栏约600米；施划修复各类交通标线约5100平方米，采用超高压水射流设备清洗交通标线重叠、被覆盖60处，清理新旧标线间不协调45处，清除交通标线约1200平方米。三是大力开展交通安全宣传。在莆田电视台《今日视线》栏目和《湄洲日报》设置曝光台，曝光摩托车违法、行人闯红灯、车窗抛物、滥用远光灯、机动车不礼让斑马线等典型不文明交通事例，通过莆田“小鱼网”设立公众举报平台，鼓励群众用手机和行车记录仪等视频信息举报交通违法，共核实反馈处罚458车次。在各类媒体曝光严重交通违法行为8次、典型案例11次、终生禁驾5人、五类重点车辆逾期未检验28辆。截至4月份，通过“莆田行”、“莆田交警微发布”在微信、微博和莆田小鱼网发布各类交通安全宣传信息800余条，发送交通安全提示短信360余万条。

　　（二）严打“黄赌”违法犯罪，净化社会风气

　　针对“黄赌”顽疾，全市公安机关扎实开展扫黄打非、禁娼禁赌等专项行动，严厉打击整治，强化阵地管控，取得成效。一是严打赌博违法犯罪，侦办查获涉赌案件大幅上升。去年以来，全市公安机关共破获涉赌刑事案件243起，比升46%；查处赌博治安案件1900多起，比升18%。突出对“六合彩”、“时时彩”、“赌球”、“微信红包赌博”等网络赌博的打击力度，破获互联网赌博刑事案件18起，比升50%。由市局治安支队牵头侦破的“2015.5.5”网络赌博案中，破获公安部挂牌督办1起，省厅挂牌督办11起。打掉团伙15个，抓获涉案人员130余人（其中团伙骨干成员12人），已判决30人，涉案金额达10多亿元。二是严查涉黄违法犯罪，侦办查获的涉黄案件明显上升。去年以来，全市共破获组织、强迫、引诱、容留、介绍卖淫刑事案件42起，比升12%；查处涉黄治安案件154起，比升24%。收缴淫秽光盘2000张。2015年，市公安局两次组织采取异地用警，先后对市区一涉黄重点区域开展突击行动，共捣毁卖淫窝点16个、抓获涉案人员86人，破获刑事案件11起，治安案件22起，刑事拘留7人，治安拘留71人。同时，全市公安机关严格旅馆业、洗浴按摩场所和娱乐场所日常治安管理，每季度组织对行业场所治安情况进行暗访或交叉检查，及时通报、查处。加强旅馆业“四实”登记，破解无证家庭式旅馆管理难题。去年以来，全市共检查旅馆业逾5000家次，发出整改通知书近400份，查处违法旅馆和留宿洗浴按摩场所350多家次，停业整顿26家，依法取缔25家，全市公安机关受理发生在旅馆业、娱乐场所内的涉黄涉赌等各类案件比降25%。

　　（三）严打毒品犯罪，禁毒工作取得重大突破 

　　长年来，市公安局对禁毒工作高度重视，坚持围绕“预防好、增量少、复吸低、打击强、整治优”的总体目标，统筹推进禁毒各项工作，不断取得新成效和新突破。仅今年1至4月，全市已破获毒品案件82起（其中，公安部督办目标案件1起、省公安厅督办目标案件4起），抓获涉毒违法犯罪嫌疑人85名，缴获各类毒品3200多克，缴获涉案枪支1把。一是以打开路，开展“飓风肃毒”会战行动。为严厉打击各类现行涉毒违法犯罪，今年3月份，市公安局在全市范围内组织开展自3月20日始至9月30日止，为期6个月的“飓风肃毒”专项行动，市县（区）两级公安机关分别成立“飓风肃毒”会战行动领导机构和网络扫毒工作专班，制定会战行动方案和组建网络扫毒工作专班，建立涉毒信息网络巡查制度，规范互联网涉毒情报研判和推送查处流程，有效打击互联网涉毒违法犯罪活动。致力于“破大案、摧团伙、断网络”，不断扩大禁毒战果，市公安局要求各地公安机关要树立一盘棋的大局意识，通力协作、共同经营、联合收网、分享战果。4月15日,在市局禁毒支队指导下,涵江分安分局成功破获一起重大贩毒案,抓获7名犯罪嫌疑人，当场缴获冰毒等各类毒品共计100多克。二是立足长效，提升禁吸戒毒成效。近年来，我市不断建立健全社区戒毒社区康复工作长效机制，并取得突破性的好成效。当前，全市已经建立21个社区戒毒社区康复集中管理工作站，其中仙游4个，荔城3个，城厢8个，涵江3个，秀屿2个，北岸1个；配有专职社工32名，兼职社工11名，并积极帮助解决吸毒人员的就业安置问题。针对吸毒人员发现管控难、戒断巩固难等问题，市公安局完善动态管控机制，全面落实逢嫌必检措施，在全市范围内相继组织开展“大排查”、“大收戒”、“大管控”行动，全面提高吸毒人员发现、管控能力。今年以来，全市公安机关共抓获吸毒人员688人次，责令社区戒毒社区康复38人，看守所羁押34人，强制隔离戒毒31人。2016年1月，莆田市美沙酮药物维持治疗门诊部在市皮肤病防治院正式开诊，目前日均服药人数达到28人，目的是为了扩大治疗覆盖面和减少脱失人数。三是突出预防，创新禁毒宣传教育场所。今年以来，我市全面落实《福建省青少年毒品预防教育规划（2016—2018）》，突出青少年、在校学生的特点，引入各种技术手段，创新形式开展禁毒宣传教育。同时全市公安机关还坚持定时不定时广泛运用电视广播、报刊杂志等传统传媒和网络、QQ、微博微信、手机客户端等新兴媒介，持续深入开展禁毒宣传教育。按照全市禁毒工作规划，年内，我市将建设1所毒品预防教育示范学校和在各县区各建立1个毒品预防教育社会实践基地。

　　三、服务民生，保障发展，严打电信网络新型违法犯罪和盗抢骗犯罪

　　今年以来，针对我市电信网络新型犯罪和盗抢骗犯罪在全部刑事案件中占比较大的现实情况，市公安局出重拳严厉打击电信网络新型违法犯罪和“盗抢骗”犯罪。

　　（一）打击治理电信网络新型违法犯罪 

　　今年1至4月，全市公安机关共侦破电信网络新型违法犯罪142起，破案数同比上升21%,抓获涉案嫌疑人99名，同比上升九成。期间，全市刑侦部门攻克了一批大案。4月15日，市局刑侦支队和荔城分局联合作战，先后在福州、厦门、莆田三地捣毁一个复制信用卡进行盗刷的犯罪团伙，抓获涉案嫌疑人7名，查获POS机十余台，银行卡二十多张，破获案件二十余起，涉案金额近二百万元。4月16日，城厢分局抓获以“淘宝花呗套现”为由诈骗淘宝买家的犯罪团伙成员3名，破获案件30余起。4月17日，市局刑侦支队联手涵江分局在平潭、泉州两地抓获8名涉及网络诈骗的犯罪团伙成员，查获伪基站设备2套、电脑2台、手机十余部、银行卡十余张。市反诈骗中心成立以来，已成功冻结止付9起，止付挽损达24.8万元。4月20日，反诈骗中心对一起电信诈骗犯罪嫌疑人的邮储卡进行支付冻结，一次性为受害人挽回经济损失14万元。为有效打击电信网络新型违法犯罪，4月21日，莆田市反诈骗中心在市公安局110指挥情报中心正式挂牌成立，建立了“三大工作机制”和“三大工作格局”。“三大工作机制”分别是：全市诈骗电话通报阻断机制、全市警银协作工作机制、警企协作工作机制。“构建三大工作格局”分别是：全市统筹格局、专业作战格局、常态宣传格局。

　　（二）严打“盗抢骗”犯罪工作

　　根据公安部、省公安厅的统一部署，市公安局从2016年1月1日起开展为期三年的打击“盗抢骗”犯罪专项行动。专项行动主要以打击盗窃、抢夺、诈骗和销赃等四类多发性侵财犯罪为重点工作，同时还严厉打击入室盗窃、盗窃“三车”、扒窃、盗窃车内财物、盗窃“三电”设施、盗窃农村家禽等突出犯罪。目前专项行动取得初步成效。1至4月份，全市公安机关共破获各类盗抢骗案件1020起，破案率34.2%，抓获犯罪嫌疑人764名。2016年3月23日，涵江公安分局刑侦部门经缜密侦查，在福州市成功抓获入室盗窃犯罪嫌疑人3名，侦破系列入室盗窃案30余起，案值约50万元。查获涉案轿车一部、假车牌十多副、万能钥匙若干套及赃款赃物若干；2016年5月12日，荔城分局刑侦部门抓获汽车抵押诈骗团伙，抓捕嫌疑人2名，破获诈骗案件20余起，涉案金额400多万元。
