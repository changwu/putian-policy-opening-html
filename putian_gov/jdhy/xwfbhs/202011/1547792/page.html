莆田市体育局举行“体育产业复工复产”网上新闻发布会

来源:莆田市体育局 时间：2020-11-13 15:30
| | | |

　　11月12日，莆田市体育局举行“体育产业复工复产”网上新闻发布会，局党组成员、副局长苏德权出席网上新闻发布会上，介绍莆田市体育产业复工复产有关情况，并回答广大网友所关心的问题。

　　

　　

　　针对网友广泛关注的我市正在积极建设新兴冰雪运动项目的问题，苏德权副局长进行了详细的解答。

　　主持人：年初，受新冠疫情的影响，许多企业、工厂停工，体育产业企业是否有受到影响？当时，我们体育部门是怎么与体育企业一起抗击疫情的？

　　苏德权副局长：一场突如其来的新冠肺炎疫情对社会各行各业带来了巨大的冲击，对体育产业、体育其他工作也造成了很大的影响。但是，在新冠肺炎疫情发生后，我市体育部门按照市委市政府和上级部门的有关部署要求，积极抗击疫情，毫不懈怠把疫情防控抓紧抓实抓细抓到位，坚决贯彻落实打赢疫情防控阻击战的决策部署。

　　疫情发生后，我局迅速成立了应对疫情工作领导小组，强化体育系统疫情防控工作。一是疫情发生后，第一时间通过官方微信公众号“莆田体育”发布《关于加强全市体育行业疫情防控工作通告》，要求全市体育系统暂停举办所有聚集性体育赛事活动，全市各级公共体育场馆暂停对外服务，防止因体育活动出现聚集性传染。二是动员全市体育用品制造企业生产防疫物资，特别是生产口罩等群众急需的防疫物资。期间，我们发动全市31个体育产业企业和体育社会组织捐赠医疗物资210多万元，莆田宝得、双驰鞋业、青年之家等企业“跨界应援”，取得很好的效果。三是按照疫情防控的需要，开展“宅家战疫，运动打卡”活动等形式多样的居家运动健身，通过“莆田体育”官方微信公众号、《爱尚运动》电视专栏节目等，引导群众转变健身方式，减少人员聚集，强身健体对抗疫情。通过组织专业健身教练、社会体育指导员等录制电视专栏节目《居家健身一起动起来》10期，推出瘦身、瑜伽、太极拳等网络公益直播教学12项，自制推广亲子操、佳木斯等健身视频超百个，及在微信公众号“莆田体育”开辟专栏等，广泛宣传八段锦等居家科学健身方法，社会反响热烈。四是适时开展线上体育消费。积极开展全民健身线上健走大赛等“云”上赛事活动，引导和鼓励企业大力发展“互联网+体育服务”消费新模式，发展个性化定制培训服务等，防止因人群聚集而出现疫情，带动体育消费，推动企业复工复产。

　　主持人：随着疫情防控的常态化，复工复产也成为人们关注的问题。增强体质，提高免疫力成为了新的口号，体育运动备受青睐，面对体育企业的停摆状态，体育部门是如何帮助体育企业快速复工复产的？

　　苏德权副局长：疫情对各行各业、对体育产业企业影响巨大，从中央到地方，各级党委政府对企业复工复产高度重视，精心部署，出台了许多办法措施。我局也高度重视，采取了许多措施和应对办法。

　　一、适时发布全市体育公共场馆恢复开放的通告。根据疫情形势的变化，及时发布《关于莆田市体育场馆有序恢复开放的通告》，引导各类体育场所按照属地管理原则，在满足疫情防控措施要求情况下分项目、分区域开放，逐步恢复和激发体育市场活力；并于6月11日发布补充通告，在明确做好防控机制、人员配备、物资储备、环境消杀等方面安全保障的基础上，进一步恢复游泳馆、密闭场所或利用底下空间开设的体育健身场所，满足人民群众健身需求。

　　二是及时开展企业精准帮扶行动。根据疫情形势的变化，及时落实上级关于统筹疫情防控和经济社会发展的部署，对全市首批30个重点体育企业实施“一企一策”精准帮扶，明确挂钩服务的分管领导、联络员，开展“大走访、送政策、解难题、建机制、优环境”活动，指导企业落细落实常态化疫情防控的同时，建立企业复工复产的跟踪台账和跟踪机制，梳理体育企业解决困难和问题，帮助企业复工复产、复市复业，创造良好营商环境。

　　三是多措并举促进体育消费，提振信心。1、直播带货。针对部分体育企业产品滞销问题，紧抓公众消费需求从线下转至线上平台的变化，由市局领导现身说法，通过电商、媒体、短视频等平台亲自为企业产品作推介，助力体育企业产品销售，有效提振社会对产品的认可和信心。在“直播带货”莆田站活动当日，TV8 E直播、福建省广播影视集团海博TV等直播平台访问量超过70万人次。2、发放体育消费券。广泛动员企业参与省体育局体育消费券发放工作，鼓励引导全市42家体育服务类实体商户使用，包括运动场馆、健身服务、体育培训体育旅游服务等。活动不仅叠加商户出资让利，激发居民消费潜力，拉动了线上线下消费能力。3、举办线上活动。鼓励转型升级，引导企业发展“互联网+体育服务”消费新模式，推动个性化定制培训服务、“制造+服务”发展，策划举办“莆田市全民健走大赛”等线上活动，带动体育消费。

　　四是加大体育招商力度。按照市委市政府的“突出开放招商 强化项目带动”要求，我局积极行动，1、开展交流座谈。局主要领导马上召集县区体育行政主管部门负责人和相关人员开展“一对一”座谈交流，共同谋划体育产业招商项目，跟踪推进相关体育产业项目落地。结合莆田山海林地资源和妈祖文化、南少林文化等特色资源优势，策划年度体育产业招商项目29个，预计总投资额约64亿元。并结合招商优惠政策，编制形成《2020年度莆田市体育产业招商项目推介手册》。2、加强招商推介。利用2020年上海体育用品博览会宣传推介我市资源优势、投资环境、优惠政策和重点招商引资项目，通过这次推介会，市体育局与路越（上海）体育发展有限公司等2家公司签订项目意向合作协议，秀屿区文化体育和旅游局共签约4家公司签订项目意向合作协议。

　　主持人：如今，企业已经陆续复工复产，但疫情“后遗症”仍不容忽视，资金储备、市场环境等都发生了很大变化。体育部门有没有一些针对性的政策或者说资金方面的帮扶？

　　苏德权副局长：应该说，新冠疫情后遗症是存在的，各级政府都相继出台政策措施，甚至是资金扶持等办法，帮助企业解决疫情对企业发展的影响，作为体育主管部门，我们也想尽办法帮助企业渡过难关。一是强化惠企纾困。通过调研走访、线上解答等方式，加强政策宣传，打通惠企政策落地“最后一公里”，全力做好企业在人才招聘、租金减免、小额贷款等方面的服务与对接，引导体育企业运用政策申请项目建设资金补助、企业复工复产各类补贴等，切实化解企业经营者的困难。同时，推动《莆田市促进体育产业高质量发展的若干措施》等一系列扶持产业发展的政策措施落实落细，在此基础上，印发了《莆田市体育产业发展专项资金管理办法（试行）》。

　　二是促进增产增效。全力推动企业与惠企政策衔接，提振企业对政府管理的认同和注资增产的信心。推荐福建汉岚体育产业投资管理有限公司等4家健身体育服务业入选省级《实施一二三产业“百千”增产增效行动方案》第一批服务业企业名单。

　　三是打造优势品牌。对全市体育产业项目进行摸底，组织推荐8个体育企业申报省级体育产业基地项目。旨在发挥产业基地的集聚效应、规模效应和示范作用，打造具有区域优势的体育特色小镇及项目建设，进一步推动我市体育产业高质量发展。目前我市成功获评的有9家体育产业基地。

　　主持人：如今，体育企业复产复工都已经跑出了“加速度”，咱们莆田体育项目建设是否也有序进行。

　　苏德权副局长：是的，针对当前疫情防控形势和复工复产要求，我局科学统筹，制定详实可行的项目复工复产工作方案、安全生产和防控应急处置预案，项目建设正紧张有序地稳步推进。一是争取省级全民健身场地设施建设项目。通过前期调查摸底、发动基层申报、实地检查核验、网站公开公示等严把审核关，共向省局申报相关项目，最后落地我市的项目有：全民健身中心1个、智慧体育公园2个、笼式足球场7个，目前各项目建设均有序推进。二是推进市级为民办实事项目。2020年我市共投入资金660万元用来建设市级为民办实事全民健身场地设施建设项目。目前，已完成各县（区、管委会）全民健身场地设施建设的申报汇总及场地实地核查工作。

　　主持人：苏副局长，您刚才的介绍有提到体育消费券，这确实是一个新型的促消费方式。那接下来还有没有类似的体育消费券发放活动？

　　苏德权副局长：是的，为顺应疫情后大家对健身锻炼、健康体魄的热切需求，落实好全民健身国家战略，十一前夕，福建省体育局联合全省体育服务业企业，推出了“乐动八闽—福建省健身消费季”，面向全省人民发放1600万体育消费券，第一批500万元已经发放完毕。我市42家健身场馆、俱乐部参与发放体育消费券29.14万元，带动群众体育消费87.11万元，拉动消费资金位列全省第五。第二批消费券发放预计于十一月份中下旬开始，总共1100万元，将促进受疫情影响的线下体育服务业及相关产业链的畅通循环。大家可以提前关注下“莆田体育”微信公众号，活动开始我局会详细的公布参与企业的名单以及活动参与的方式。

　　主持人：苏副局长，我市体育产业有什么亮点？

　　苏德权副局长：我们都知道莆田是享誉中外的“中国鞋城”，但由于近年来鞋类出口门槛高等种种原因,众多传统产业工厂关闭，大量旧厂房闲置。如何利用起这些闲置的旧厂房？于是，我局结合我市体育产业的特点，坚持因地制宜、转型升级、融合发展地推进旧厂房改造体育休闲综合体项目建设，目前已初具成效。促成旧厂房改造的有力条件有：1.政策支持。我市积极响应国家关于促进全民健身和体育消费推动体育产业高质量发展的政策，先后出台《莆田市人民政府关于利用空闲用地和房屋资源举办民生服务机构的通知》等政策，鼓励和引导民营资本充分利用旧厂房、仓库等闲置资源以及现有设施，改造建设为体育健身设施项目，做好空间的二次利用。2.协同建设。通过鼓励民营企业参与旧厂房改造体育休闲综合体的方式，有效盘活存量资源，走出了一条存量资源“要效益”和强化供给“要质量”的双赢之路。3.全链条发展。布局打造“体育+旅游+娱乐休闲”的全链条体育邻里空间，实现“以项目培训带动体育发展，以休闲配套促进消费升级”的盈利模式，破解体育场馆项目投资大、回报慢、用户粘性不足等问题。

　　我市旧厂房改造体育休闲综合体项目的做法成为全省亮点，得到省体育局的充分肯定。目前全市已有旧厂房改造体育特色项目29个，其中比较典型的有：仙游四季体育休闲小镇、涵江仓篮部落等。

　　主持人：我市体育部门在探索体育产业发展良机，推动体育产业高质量发展做了很多工作。下一步，对体育产业发展，你们是怎么谋划的？

　　苏德权副局长：具体是这样的，一是高起点谋划做好体育产业“十四五”规划工作。回顾总结我市十三五时期体育发展经验，盘点“十三五”规划完成情况，掌握体育发展现状，聚焦问题，补齐短板，围绕建设冰雪运动强市和体育强市建设、健康莆田、全民健身行动，以及体医融合、体教融合等重点任务，高点定位，编制出高标准高质量的莆田市体育产业发展“十四五”规划。

　　二是强力打造体育产业示范基地。对全市体育产业项目进行再摸底，推动国家级及省级体育产业基地申报工作，着力推介双驰实业股份有限公司申报国家级示范单位，打造西天尾镇、南日镇、湄洲岛等具有区域优势的体育特色小镇及万佳国际度假村等“体医融合”示范点、体育旅游精品线路等。

　　三是加大开放招商力度。1、推动项目落地。依托现有产业优势和产业集群基础，结合《莆田市体育产业资金管理办法》等政策的推广，最大程度撬动社会资本投资体育，指导和鼓励体育旅游综合项目、体育服务业等业态发展，推进莆田冰雪小镇LNG循环经济综合利用冰雪体育场馆PPP项目、市皮划赛艇运动健身项目等大型项目开工。2、重点项目推介。大力推介项目参展2021年中国体博会、两博会、厦洽会等展会，争取莆田入选一个国家级精品项目或十佳精品项目，扩大我市体育产业项目的影响力。3、促进体育消费。加强与全国优秀体育咨询策划公司的深度合作，拓展体育健身、体育观赛、体育培训、体育旅游等消费新空间，促进健身休闲、竞赛表演产业发展。并着力通过发放莆田体育消费券、组织举办赛事活动、延长体育场馆夜间经营时间等，进一步引领群众体育消费，为经济转型贡献体育力量。

　　主持人：都说体育产业在疫情过后会迎来新的发展机遇，苏副局长，您怎么看？

　　苏德权副局长：受疫情影响，以体验式消费为主的体育产业，是受冲击最大的产业之一，但随着国家、公众健身、健康意识的提升，体育产业也将在疫情过后迎来新的发展机遇。结合当年“非典”过后健身休闲产业的发展表现来看，这次疫情过后健身休闲产业必将触底反弹，“体育+”将以各种形式走入人们的日常生活。

　　目前，市体育局已针对体育产业的复工复产和未来发展出台扶持政策，国家对于群众健康更加重视，政策利好将为体育产业发展带来良好的驱动力；公众更加重视健康，“居家健身”的意识引导，将在未来一段时间内转化为体育消费，健身需求不断扩大；体育企业在疫情期间优胜劣汰，成功渡过难关的企业，在技术手段运用、产品升级等方面的能力显著提升，练好“内功”的他们已初步做好迎接体育产业大发展的准备……长风破浪会有时，直挂云帆济沧海。市体育局将与大家一道，积极应对困难，把握发展良机，催生新的活力。让我们携起手来，统筹推进莆田体育产业高质量发展。
