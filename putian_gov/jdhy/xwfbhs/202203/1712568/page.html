莆田市人民政府新闻办公室召开莆田市新冠疫情防控工作新闻发布会

来源:莆田市人民政府新闻办公室 时间：2022-03-19 13:25
| | | |

3月19日

莆田市人民政府新闻办公室召开

莆田市新冠疫情防控工作新闻发布会

通报莆田市新冠肺炎疫情防控相关情况

 

莆田市人民政府副市长朱正扬，莆田市卫健委主任姚冰珊，仙游县人民政府县长吴海端出席发布会，介绍有关情况并回答记者提问。新闻发布会由莆田市委宣传部常务副部长唐炳椿主持。

 

自3月13日至3月19日8时，莆田市累计报告确诊病例13例（仙游县），无症状感染者1例（城厢区）。

 

一、基本情况

 

3月17日，城厢区在集中隔离点核酸检测中发现无症状感染者1例，系市外返莆人员。

 

仙游县组织对可能感染新冠肺炎重点人群进行筛查，3月18日，在县总医院发热门诊对就诊人员核酸筛查时发现2例新冠肺炎确诊病例。通过扩大核酸筛查，至3月19日8时，累计报告确诊病例13例（轻型），已“点对点”转运至定点救治医院，情况稳定。

 

二、疫情处置情况

 

发现病例后，我市及相关县区应对新冠肺炎疫情工作指挥部立即启动应急响应，激活应急指挥体系，实行扁平化运转，第一时间组织开展流调溯源、隔离管控、核酸检测、社区防控、消杀消毒等工作。

 

一是迅速开展流调。启动“三公（工）一大”协同机制，组织流调人员开展流调，排查密接、次密接人员，截至3月19日8时，全市已排查出密切接触者172人，次密切接触者686人，密接、次密接人员均已落实隔离管控措施。同时，对确诊病例的活动场所进行环境标本核酸采样和终末消毒。

 

二是扩大核酸筛查。推进全市“应检尽检”的重点人群、“适时抽检”的相关人群、“愿检尽检”的其他人群常态化核酸检测。统筹力量，在对仙游县密接、次密接人员进行核酸检测的基础上，根据流调结果进一步扩大核酸筛查范围。

 

三是加强社会面管控。压实“四方责任”，落细落实市外中高风险地区、境外入莆人员落地排查和全流程闭环管理，强化口岸管理和人、物、环境同防，严防输入防线。加强公共场所、学校等重点场所管理，强化多点触发监测预警机制。仙游县第一时间对相关涉疫场所进行管控，同时，按照科学划定、精准管控工作要求，自2022年3月18日起，将鲤城街道新海宏花园、鲤南镇柳坑社区后巷划为封控区，将清源路以南，园滨路以北，八二五中路以东，东一环、东大路以西划为管控区。

 

下一步

 

莆田市将坚持“外防输入、内防反弹”总策略和“动态清零”总方针，进一步压实“四方责任”，落实“四早”要求，突出快准严实细，从严从实开展防控工作，全力阻止疫情蔓延扩散。按照“一人一案”，对患者进行科学精准治疗。全面加快流调溯源，全面排查可能的感染者，对可能接触到的相关人员严格落实管控。对划定的风险区域严格落实分类管理，对风险区域内的居民加强服务保障。坚持人、物、环境同防，全面抓好重点场所、重点人员防控。

 

莆田将持续做好疫情信息的发布，请广大市民关注官方权威发布，不造谣、不信谣、不传谣，了解防控知识、自觉遵守防疫要求，加强自我防护，配合做好疫情防控工作。

 

记者问答

 

问题一：针对此次疫情，仙游县采取了哪些措施？

 

仙游县人民政府县长吴海端回答：感谢记者朋友的关心。

 

疫情发生后，在省市的坚强领导下，仙游县立即启动应急响应机制，成立应急指挥部和11个工作小组,开展应急处置工作，突出“快准严实细”，坚决遏制疫情传播扩散，主要还是与时间赛跑，立足于早，突出精准快干：一是快救治。第一时间用120负压救护车将确诊病例送到定点医院隔离诊治，实行“一人一案”。经诊断，均为轻型，目前病情稳定。二是快管控。实施科学精准分级分类管控，对阳性感染者居住小区进行全面管控。经专家研判，自18日起，将鲤城街道新海宏花园、鲤南镇柳坑社区划定为封控区；将清源路以南，园滨路以北，八二五中路以东，东一环、东大路以西划为管控区。同时，暂停一切文化、娱乐、体育等聚集性活动。三是快消杀。组织由85人组成的消杀队伍对涉及区域进行环境采样并全面消杀。截至3月19日8时，累计完成物体表面消毒约2000平方米、空气消毒约4500立方米。四是快保障。规范做好集中隔离场所布置，共储备隔离场所9家、房间3012间，已启用隔离场所4家、房间770间。同时，强化封控区、管控区防控物资和生活物资保障，按照一周需求量提前储备，已储备大米2300吨、食用植物油1000吨、液化气150吨，单日可调配大米153吨、面粉43 吨、肉类62吨、蛋品60吨、蔬菜87吨、水产品28吨、奶制品54吨等物资。并建立物资调配渠道，采取“点对点、无接触”的办法集中配送，全力保障封控区、管控区群众生活需求。五是快流调。第一时间组织开展流调溯源，依法高效开展流调、摸排行程轨迹。截至3月19日8时，已排查出该密切接触者136人，次密切接触者660人，已全部完成采样，其中243人核酸检测阴性，其余结果待出，相关密接者正有序转运到集中隔离点进行医学观察。六是快筛查。坚持先急后缓原则，突出重点、分级实施，立即对密接、次密接者开展核酸检测，同时扩大核酸检测范围，18日下午已对全县11个乡镇（街道）进行全员核酸检测，至18日24时止，已采集71.62万人份，完成全县80%以上人群采样。目前核酸检测仍在加快进行。同时，今天仙游县将对重点区域的重点人群进行新一轮核酸检测。

 

下一步，仙游县将严格落实国家相关规程的规定，进一步压实“四方责任”，坚持人、物、环境同防，全力做好流调溯源、核酸检测、社区管控、环境消杀、物资保障等各项工作，坚决把上级的各项要求落实落细落到位，全力保障人民群众生命健康安全。

 

问题二：疫情发生后，广大市民应该做好哪些个人防护？

 

市卫健委主任姚冰珊回答：当前国内外疫情形势复杂严峻，国内疫情呈现点多、面广、频发的特点，在此我们建议市民朋友们做好以下防护措施：

 

一、要时刻注意保持1米以上的社交距离，尽量不去或少去人群密集、空气不流通的场所。在商场、公交、电梯等密闭场所以及人群聚集的室外场所要全程规范佩戴口罩。咳嗽、打喷嚏时要用纸巾等遮挡口鼻。

 

二、要尽量避免网购境外、市外中高风险地区的商品。收取快递时要佩戴口罩及一次性手套，减少直接接触和交流。尽可能在固定地点存取，实现无接触交接。拆件时建议用消毒剂进行消毒，外包装不要拿回家中，按照生活垃圾分类进行处理。处理完包裹后及时清洗消毒双手。

 

三、要对进口冷链食品外包装进行清洗消毒；加工时要生熟分开，烧熟煮透，注意清洁双手，避免用手触摸眼、口、鼻，注意厨房通风、清洁消毒。

 

四、要自觉履行防疫责任。如非必需，不要前往中高风险地区，返回后，应主动向所在社区(村)和工作单位报备相关情况，配合当地开展核酸检测、健康监测和健康管理。重点人群、重点行业、重点场所要严格按照有关规定落实“应检尽检”“适时抽检”。

 

五、要做好个人健康监测。如有出现发热、干咳、乏力、咽痛、嗅 （味）觉减退、鼻塞、流涕等症状，要佩戴一次性医用口罩，及时到就近的发热门诊进行排查和诊疗，就医过程避免乘坐公共交通工具。

 

六、要积极接种新冠病毒疫苗。在没有接种禁忌症的情况下，符合条件的人员要及早完成全程、加强免疫接种，保护好自己和家人健康。
