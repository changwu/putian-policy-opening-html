莆田市人民政府新闻办公室召开莆田市新冠疫情防控工作第五场新闻发布会

来源:莆田市人民政府新闻办公室 时间：2022-03-23 12:42
| | | |

　　3月23日

　　莆田市人民政府新闻办公室举行

　　莆田市疫情防控工作第五场新闻发布会

　　通报莆田市新冠肺炎疫情防控相关情况

　　

　　基本情况

　　3月22日8时至3月23日8时，莆田市报告当日新增确诊病例9例（均为仙游县）、无症状感染者7例（均为仙游县）。

　　截至3月23日8时，莆田市累计报告确诊病例60例（均为仙游县）、无症状感染者12例（仙游县11例、城厢区1例）。

　　（一）流调溯源情况

　　截至3月23日8时，全市累计判定密接2137人，次密接7988人，已按要求管控到位。

　　（二）核酸检测情况

　　在完成全市第一轮全员核酸检测和仙游县第二轮全员核酸检测的基础上，3月22日0时启动仙游县第三轮全员核酸检测，共采集77.7万人份样本，已出结果51.2万人份。

　　截至3月23日8时，全市核酸采集453.3万人份样本，已出结果426.5万人份。

　　（三）风险地区管控情况

　　根据当前我市疫情防控实际情况，经专家研判，2022年3月22日11时起，对我市风险地区进行部分调整，调整后我市共有高风险地区1个，中风险地区49个，具体如下：

　　1.高风险地区（1个）：仙游县私立一中。

　　2.中风险地区：

　　鲤城街道（24个）：新海宏花园2号楼、东门社区何游121号、东门社区山中豪园3号楼1梯、紫檀南街666号宋桥花园1号楼、南桥社区大园巷5-2号、鲤中小区、香港财富二期、城内社区三宫巷21号、金井社区田厝20-1号、学府东路188号君隆财富2号楼、一中路91弄29号、一中路11号、东门社区东门街133号、东门社区东门街989号、东门社区师范路996号、东门社区东大街702号、文嵩街楼厝巷32-6号、坝垄新村兴龙路112号、后嵩巷16号、东大路385号、园滨东路453弄第2栋、学府西路龙泉保障房8号楼、师范路体委集资房2号楼1梯、玉田社区兰溪首府7号楼。

　　鲤南镇（12个）：柳坑社区后巷14号、涵井村港滨路38号、平原社区内洋小组52号、天博华府B区、兰溪新天地、八二五南街53号、皇庭美域1期5号楼、远大建材城10号楼、城南东路香江明珠3号梯、西浦张宅59号、翔城北街288号海亭嘉苑3号楼、仙安社区胜达花园B栋。

　　榜头镇（5个）：泉山社区林碑88号、莲墘社区九鲤北街583号、下昆社区广湖201号、下昆社区大路8号、下昆社区山兜30号。

　　盖尾镇（2个）：湖坂村黄畲85-1号、后井村后井92号。

　　枫亭镇（2个）：枫城新都1号门30栋、溪北村林兜60号。

　　赖店镇（2个）：土山村赖营西路252号、象岭安婆社109号。

　　大济镇（1个）：龙坂村绿阳生态采摘园。

　　郊尾镇（1个）：梅塘村东安125号。

　　经仙游县疫情防控指挥部综合研判，新增以下区域为防控区域：

　　1.新增封控区包括：鲤城街道：东门社区东大街702号、师范路体委集资房2号楼1梯。鲤南镇：玉田社区兰溪首府7号楼。榜头镇：下昆社区山兜30号。赖店镇：象岭村安婆社109号。郊尾镇：梅塘村东安125号。

　　2.新增管控区：大济镇全域。

　　其他封控、管控、防范区域不变。

　　（四）外环境消杀情况

　　截至3月23日8时，对病例活动、居住过的场所开展疫点终末消毒，累计完成物体表面消毒4.9万平方米，空气消毒4.2万立方米。

　　（五）救治情况

　　截至3月23日8时，60例确诊病例中普通型14例、轻型46例。无症状感染者12例。

　　根据专家评估意见，目前，54例在定点救治医院集中医学治疗，18例在莆阳健康驿站集中隔离管理，患者情况稳定。

　　工作开展情况

　　在继续抓好隔离转运、医疗救治等工作的基础上，重点开展以下几项工作：

　　一是推进核酸检测。采购2辆移动核酸检测车并投入使用，进一步提升检测效率。全市共采购35万份抗原自测试剂，开展线上培训，组织仙游县重点人群开展自行检测，通过抗原筛查进一步提升早发现能力。统筹核酸采样和检测医务人员力量，加快推进核酸检测工作。

　　二是做细流调溯源。利用大数据手段，结合现场流调，1小时内完成密切关系人分析报告、4小时内完成核心信息，科学判定密接和次密接人员。加强工作组之间的协作，推进流调与隔离转运、精准溯源、环境采样、消毒工作的无缝衔接。

　　三是加强社区防控。坚持分区分级差异化精准防控，对全市物业管理小区、开放式小区、农村地区，分别落实相应的防控措施。对仙游县封控区、管控区，强化卡口管理和巡逻巡查，目前，已有市、县、镇、村干部和公安民警、单元长、社会志愿者等共2.3万余人下沉仙游县网格单元一线，同时加强物防、技防，全力守住“边界”，防止疫情蔓延外溢。

　　四是做好医疗和生活物资保障。增设3个医疗防疫物资仓储点，动态掌握全市核酸采样管等物资的储备情况，加强供应储备、调度调配。通过建立微信群、设立配送点、指定专人送等办法，做好封控区群众日常生活物资保障。统筹协调做好封控区、管控区群众就医购药保障。针对我市急危重症、孕产妇、血透患者、放化疗患者等特殊人群就医需求进行再部署，保障群众基本就医需求。

　　五是强化人文关怀。加强隔离人员关怀关爱，做好已启用44个隔离点的物资保障。向隔离点青少年赠送书籍和学习文具。开通人文关怀通道，及时回应隔离人员诉求。开通心理健康咨询热线，为急需心理支持的家长及青少年提供心理疏导服务。通过强化人文关怀，做到隔离不隔爱。

　　下一步

　　莆田市将按照党中央、国务院和省委、省政府的部署要求，全面落实属地、部门、单位、个人“四方责任”，织牢织密群防群控基层防线，严格落实防控措施，更快、更实、更细做好流调排查、核酸检测、隔离管控等工作，尽快实现社会面动态清零。

　　记者问答

　　问题一：请问我市针对物业小区、开放性小区、农村等采取哪些措施做好分类防控工作？

　　答：社区是疫情联防联控的重要防线，社区防控及消毒组针对不同的社区采取分类防控的措施：

　　有物业管理的小区，由物业管理单位落实好疫情防控措施，各物业服务企业建立疫情防控期间小区出入管理制度，减少小区出入口数量，实行24小时值班、扫码测温等，发现健康码或体温异常的人员做好信息登记并及时报告社区。同时，物业服务企业做好住宅小区公共区域的楼道、电梯、垃圾桶等共用部位和设施设备的清洁消毒工作，并增加消毒频次。

　　开放式小区，发动社区干部、居民小组、楼栋长、志愿者、网格员等力量，明确每个小区责任组织、责任人。通过建造围档、设置路障等方式实施封闭，实行一门出入制度，在出入口设立测温点、健康码检测点和登记台，做好人员流动管控。

　　农村地区，参照开放式小区做法，在村主干道等主要出入口设置值守点，由镇街包片干部带领村、组干部值班值守，对出入人员车辆逐人逐车测温、验码、登记，劝导农民群众戴口罩，尽量减少外出、串门，不聚餐、不扎堆，提倡喜事缓办、丧事简办。

　　同时，充分发挥群防群治体系作用，调动各方面力量参与疫情防控。

　　问题二：仙游县近期开展了几轮全员核酸检测工作？对封控区民众、隔离人员采样时采取怎样的便民措施？请介绍一下有关情况？

　　答:疫情发生以来，莆田市其他兄弟县区医务人员和志愿者们逆行支援、争分夺秒、通宵达旦、同心抗疫 ，克服种种困难，只为早日抗疫功成，还仙游一方净土。在此，向他们的付出表示最真挚的谢意！

　　我们把核酸检测作为当前最重要的工作之一来抓，截至3月22日，我县开展了3轮18个乡镇全员核酸检测工作，特别是我们对私立一中师生员工及其关联人员开展5轮核酸检测；对中高风险地区低风险城市回仙的重点人群实施前3天2检的办法。共设置采样点1749个、统筹安排采样医务人员1377名、社区工作人员和志愿者近万名，累计检测2773970人次。核酸检测主要采取以下措施，方便群众。

　　一、“采”的方面突出有序有效。一是备足物资。采集前，以乡镇为单位，摸底测算采样管、咽拭子、封口袋、转运箱等采样物耗需求量，列出物品清单，由县指挥部统一调配，安排至各乡镇，再由各乡镇分配至各村居。二是调齐人员。我们要求各乡镇根据核酸采集范围和时限，提前制定医护人员村居配备计划，摸底医护人员需求数量，上报县指挥部统筹安排各乡镇医护人员数量和领队。再由各乡镇与领队提前对接，细化乡镇各村居医护人员分配名单，形成方案。医护人员到乡镇政府后，由各村居提前在乡镇政府等候接人至各自村居，做到无缝衔接、高效有序。三是采集有序。对防范区，发挥网格作用，强化单元配置。建好网格群、单元群，配强网格长、单元长、楼栋长，构建全民核酸采集工作组织领导架构，确保一键启动、扁平指挥；由各村居选择广场、村部、学校等宽旷场所设置2-6个采样点，各村居以网格、单元、楼栋为单位，通知错峰采集。现场工作人员通过拉警戒线、划足迹圈、设等距隔离标记物等，确保采样有序、避免聚集。同时县公安局启动无人机观察，通过空中喊话，维持秩序。对封控区以及居家隔离或没有行动能力的居民，每个村居组织2-3人的采样工作专班（村干部、网格长、医护人员等）上门采集。对采集点做好事前事后的环境消杀和涉疫垃圾清运工作，确保采样环境安全。同时，我们也关注到个别采样点存在插队、等候时间过长等问题，我们将立行立改，接下来我们也将加强此类问题督查，确保采样更有序、更有效。

　　二、“送”的方面突出从速从快。以清单管理为主线，开展链条式运送，各村居收集到一定量的采样管后登记造册，运送至乡镇集中点；乡镇汇总至一定量，由县指挥部安排专车运送至各检测点，分配各乡镇车辆负责运送。其中市内、县内检测点由乡镇直接运送到点；市外检测点由乡镇运送至中转站后，再统一运送至市外检测点。

　　三、“运”的方面突出安全安心。所有运送车辆由县指挥部转运组统一调配，实行专车专人运送。小车配备一名司机、一名押运员，大车配备一名司机、两名押运员，司机与车辆、押运员固定搭配，押运员负责搬运样本、联系对接、全程押运，有效避免样本丢失、出错，确保安全、放心。司机严格落实个人防护措施，并闭环管理，确保不被感染。

　　四、“检”的方面突出应检尽检。仙游县共设置3个实验室检测点（县疾控中心、县总医院、县妇幼），检测能力有限。在市指挥部的统一调度下，市内兄弟县区16个检测机构倾情援助，分担我们检测压力，并对接联系多个市外的检测机构，破解我县核酸检测能力不足问题。同时为提高我县自己的核酸检测能力，于21日采购了一辆日检测1万管的检测车，缓解压力，下一步拟再购置两部，进一步提升检验能力。
