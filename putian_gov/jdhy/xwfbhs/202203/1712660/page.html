莆田市人民政府新闻办公室召开莆田市新冠疫情防控工作第二场新闻发布会

来源:莆田市人民政府新闻办公室 时间：2022-03-20 19:37
| | | |

　　3月20日

　　莆田市人民政府新闻办公室召开

　　莆田市新冠疫情防控工作第二场新闻发布会

　　通报莆田市新冠肺炎疫情防控相关情况

　　

　　基本情况

　　3月19日8时至3月20日8时，莆田市报告新增确诊病例3例（均为仙游县）、无症状感染者2例（均为仙游县）。

　　截至3月20日8时，莆田市累计报告确诊病例16例（均为仙游县）、无症状感染者3例（仙游县2例、城厢区1例）。

　　（一）流调溯源情况

　　截至3月20日8时，全市累计判定密接236人，次密接1243人，已按要求管控到位。

　　（二）风险地区管控情况

　　经专家研判，自2022年3月19日8时起，将仙游私立一中列为高风险地区；将仙游县鲤南镇柳坑社区后巷14号、仙游县鲤城街道新海宏花园2号楼、仙游县鲤城街道东门社区何游121号、仙游县鲤城街道东门社区山中豪园3号楼1梯、仙游县鲤城街道香港财富二期4号楼、仙游县鲤南镇涵井村港滨路38号、仙游县鲤南镇兰溪新天地15号楼1单元、仙游县榜头镇泉山社区林碑88号、仙游县鲤城街道紫檀南街666号宋桥花园1号楼、仙游县鲤南镇平原社区内洋小组52号、仙游县鲤城街道南桥社区大园巷5-2号、仙游县鲤南镇天博小区3号楼、仙游县鲤南镇天博华府4号楼、仙游县盖尾镇湖坂村黄畲85-1号列为中风险地区。

　　根据仙游县疫情防控形势，依据相关法律法规和疫情防控有关规定，经仙游县疫情防控指挥部综合研判，2022年3月19日起，将新增阳性感染者涉及的部分区域进行分级管控，原划定的封控区、管控区保持不变（鲤城街道新海宏花园、鲤南镇柳坑社区后巷划为封控区，将清源路以南，园滨路以北，八二五中路以东，东一环、东大路以西划为管控区）。新增封控区域包括：鲤城街道：私立一中、私立第一小学、仙游县香港财富二期4号楼第一单元、东门社区何游121号、山中豪园3号楼、南桥社区大园巷5-2号、鲤中15号楼第四单元、一中街三宫巷21号。鲤南镇：玉田社区兰溪新天地15号楼第一单元、涵井村港滨路38号、平原社区内洋52号、西埔社区天博华府B区3号楼第一梯位、4号楼第一梯位。榜头镇：泉山社区林碑88号怀古典藏家具厂。盖尾镇：湖坂村黄畲85-1号。新增管控区域包括：鲤城街道东至八二五中路、西至至喜亭街、南至园滨路、北至南大路；鲤南镇柳坑社区、涵井村、平原社区、西埔社区、玉田社区；榜头镇泉山社区；盖尾镇湖坂村。除上述封控、管控区域外，仙游县内其他区域均为防范区。

　　（三）核酸检测情况

　　截至3月20日8时，全市核酸采集2970153人份样本，已出结果1294094份，其中：仙游县核酸采集1038158人份样本，已出结果614243份。

　　（四）外环境消杀情况

　　截至3月20日8时，累计对涉疫地方完成物体表面消毒6039平方米、空气消毒7602立方米。

　　（五）救治情况

　　16例确诊病例均为轻型，已在定点救治医院隔离管理治疗，病情稳定；3名无症状感染者已在定点救治医院进行隔离观察。

　　工作开展情况

　　（一）流调溯源方面。统筹调动流调队伍力量，发挥“三公（工）一大”协同作用等，聚焦重点人群，加快开展流调溯源，全力查找传播轨迹、排查隐患，对相关重点人员先行赋码。对确诊病例的活动场所进行环境标本核酸采样和终末消毒。

　　（二）隔离管控方面。快速开展转运隔离，按规定对密接、次密接人员管控到位，全力阻断传播链条。对封控区实行“区域封闭、足不出户、服务上门”，对管控区实行“人不出区、严禁聚集”。运用基层防控网络，组织党员干部下沉一线，落实各项防控措施，做好封控区、管控区和集中医学观察点等群众医疗服务工作。

　　（三）核酸检测方面。有序组织开展核酸检测，在3月18日对仙游县密接、次密接人员和重点区域、重点人群进行核酸检测的基础上，3月19日组织全市核酸检测，筛查可能的感染者。

　　（四）重点场所管理方面。加强全市重点人群、重点场所和重点机构精准防控，全市所有校外培训机构暂停线下培训。加强多点触发监测预警，督促零售药店落实“两抗一退”、止咳等相关药物监测。

　　（五）督导宣传方面。市县（区）两级联合成立督导检查组，重点对核酸检测的组织、村居疫情防控措施落实等情况开展督导检查。利用横幅标语、宣传海报、报纸电视、电子屏、村村通广播等载体宣传疫情防控最新通告、防控知识等，采用莆仙赞句、快板书、梆鼓唱、顺口溜、方言喊话等形式强化宣传效果。

　　下一步

　　莆田市将坚决贯彻落实习近平总书记重要讲话重要指示精神，认真落实全国疫情防控工作电视电话会议要求和省委、省政府部署，坚持人民至上、生命至上，坚持科学精准、动态清零，突出快准严实细，尽锐出战、决战决胜，进一步压紧压实“四方责任”，守住边界，防止疫情外溢传播，全力控制局部疫情，最大限度减少疫情对经济社会发展的影响。

　　记者问答

　　问题一：此次疫情有学生确诊，请问仙游县对学校疫情防控采取了哪些应对措施？

　　答：仙游县委县政府高度重视校园疫情防控工作，严格按照党中央国务院及省、市党委政府工作部署，从严从紧从实抓好校园疫情防控工作。

　　此次仙游县在对重点人群筛查中于18日发现仙游私立第一中学2名学生阳性病例，我们马上启动预案，即时封闭学校所在地区并通知师生居家，同时组织全校师生、工勤人员开展核酸采集检测。对确诊病例同步开展流调，即时将确诊病例送往定点医院开展救治，截至3月20日8点，确定了200名密接者和1217次密接者全部送往隔离酒店进行隔离。同时将私立一中所有师生居住地信息推送属地乡镇开展校地联控，要求其居家隔离，由属地村居提供生活保障。鉴于当前我县校园疫情防控形势严峻，时逢周末，我县研究决定，从明天开始全县各学校和培训机构暂时停止线下教学，开展线上教学。并要求全县师生、工勤人员主动向属地村居报备本人和共同居住人近14天内的泉州和其他重点风险地区旅居史。

　　对此次疫情涉及校园学生，我们深感痛心，下一步我们将在省市有力指导帮助下，集结全县所有资源，力斩传播链条，有效阻止疫情蔓延，速战速决，决战决胜，尽快恢复校园正常教学秩序。

　　问题二：仙游已划定了一些封控区、管控区，对在这些区域内的老百姓若需要紧急就医，你们采取哪些特别措施解决？

　　答：自发生疫情以来，仙游县涉及1个高风险地区和14个中风险地区，相应设置封控区、管控区，此次疫情给封控区、管控区的群众生活、就医带来许多不便。我们采取分级分层，灵活诊疗的方式，满足群众疫情防控期间正常的就医需求。

　　1.全力畅通就医通道。全县疫情期间医疗机构照常营业，对封控区的孕妇、急危重症、血液透析、肿瘤放化等患病群众，以及孤寡老人等特殊群体，设置24小时电话预约和采取专车上门接送等方式，提供“点对点”“一对一”服务。同时，开通日常购药热线，严格实行送药上门，切实保障群众日常用药需求。预约电话号码0594-8592616。

　　2.强化村居与医疗机构联动。发挥社区单元长、网格员作用，组建志愿者队伍，主动了解紧急就医人员的就医需求，建档造册，与指定的社区卫生服务中心或乡镇卫生院建立联络，提供诊疗、预防接种及药品配送等服务。进一步加强人文关怀，为孤寡老人、孕妇、婴幼、残障等特殊群体开展健康巡诊，主动提供医疗健康服务。有特殊需求的，由县疫情防控指挥部协调上门服务。

　　3．坚持“分类诊治”。各定点医疗机构严格落实疫情防控措施，规范诊疗流程，分区分类管理，对于疑似新冠肺炎相关症状的，安排相对单独区域隔离收治，抽调涵盖各个专业、与诊疗服务量相匹配、综合能力较强的医、护、技等人员参与相关工作，确保患者得到及时、有效救治。
