莆田市人民政府新闻办公室召开莆田市新冠疫情防控工作第四场新闻发布会

来源:莆田市人民政府新闻办公室 时间：2022-03-22 18:27
| | | |

　　3月22日

　　莆田市人民政府新闻办公室召开

　　莆田市疫情防控工作第四场新闻发布会

　　通报莆田市新冠肺炎疫情防控相关情况

　　 

　　基本情况

　　3月21日8时至3月22日8时，莆田市报告当日新增确诊病例7例（均为仙游县）、无症状感染者1例（仙游县）。

　　截至3月22日8时，莆田市累计报告确诊病例51例（均为仙游县）、无症状感染者5例（仙游县4例、城厢区1例）。

　　　（一）流调溯源情况

　　截至3月22日8时，全市累计判定密接1881人，次密接5789人，已按要求管控到位。

　　　（二）核酸检测情况

　　截至3月22日8时，全市核酸采集375.4万人份样本，已出结果371.3万人份。其中：

　　截至3月20日24时，全市第一轮全员核酸检测采样275.9万人份，全部已出结果。

　　3月20日0时启动仙游第二轮全员核酸检测，共采样785206人份，全部已出结果。

　　　（三）风险地区管控情况

　　经专家研判，自2022年3月21日11时起，将仙游县鲤城街道一中路91弄29号、一中路11号、东门社区东门街133号、东门社区东门街989号、东门社区师范路996号、文嵩街楼厝巷32-6号、坝垄新村兴龙路112号、后嵩巷16号、东大路385号、园滨东路453弄第2栋、学府西路龙泉保障房8号楼，仙游县鲤南镇八二五南街53号、皇庭美域1期5号楼、远大建材城10号楼、城南东路香江明珠3号梯、西浦张宅59号、翔城北街288号海亭嘉苑3号楼、仙安社区胜达花园B栋，仙游县枫亭镇枫城新都1号门30栋、溪北村林兜60号，仙游县赖店镇土山村赖营西路252号，仙游县榜头镇下昆社区大路8号，仙游县盖尾镇后井村后井92号列为中风险地区。原划定的风险区保持不变。

　　经仙游县疫情防控指挥部综合研判，新增封控区包括：鲤城街道：一中路91弄29号、一中路11号、东门社区东门街133号、东门社区东门街989号、东门社区师范路996号、文嵩街楼厝巷32-6号、坝垄新村兴龙路112号、后嵩巷16号、东大路385号、园滨东路453弄第2栋、学府西路龙泉保障房8号楼。鲤南镇：八二五南街53号、皇庭美域1期5号楼、远大建材城10号楼、城南东路香江明珠3号梯、西埔张宅59号、翔城北街288号海亭嘉苑3号楼、仙安社区胜达花园B栋。枫亭镇：枫城新都1号门30栋、溪北村林兜60号。盖尾镇：后井村后井92号。赖店镇：涂山村赖营西路252号。榜头镇：下昆社区大路8号。新增管控区包括：枫亭镇、盖尾镇2个乡镇全境。除上述封控、管控区域外，县内其他区域均为防范区。

　　（四）外环境消杀情况

　　截至3月22日8时，对病例活动、居住过的场所开展疫点终末消毒，累计完成物体表面消毒2.2万平方米，空气消毒2.6万立方米。

　　　（五）救治情况

　　截至3月22日8时，51例确诊病例中普通型12例、轻型39例。无症状感染者5例。

　　经专家评估，目前，49例在定点救治医院集中医学治疗，7例在莆阳健康驿站集中隔离管理，患者情况稳定。

　　工作开展情况

　　一是加快流调溯源。坚持快准严实细，强化信息对接，加快流调排查，科学判定密接、次密接人员，及时隔离管控到位。加快推进溯源，进一步摸排传播链条。

　　　二是推进核酸检测。对隔离点、一线工作人员、核酸检测采运检人员、医护人员等重点人群，做到每天必检；对封控区、管控区人员，加密核酸检测频次。在完成仙游县第二轮核酸检测的基础上，3月21日对仙游县相关重点人群开展核酸检测，3月22日仙游县开展第三轮全员核酸检测。

　　　三是做细隔离场所准备。通过启动储备、挖掘潜力、策划新建等渠道，抓好隔离场所准备，完善准备清单及启用各项准备。制定方舱隔离点建设方案，在全市现有3个方舱2772间的基础上，筹划再建方舱隔离场所2000间。

　　四是分类开展诊疗救治。按照新型冠状病毒肺炎诊疗方案（试行第九版），定点医院“一人一策”拟定中西医结合治疗方案，推动中医药及早介入诊疗。3月21日下午，启用莆阳健康驿站，用于轻型病例和无症状感染者隔离管理。市中医医院向仙游隔离点提供新冠肺炎预防汤药日均近3万包。

　　五是落实社会面精准防控。实行凭车辆通行证、驾驶员48小时内核酸阴性证明和健康码绿码出入管理，保障进入仙游县域的医疗防疫物资、生产生活物资运输车辆通行顺畅。为确保我市重点项目顺利推进，市行政服务中心公共资源交易招投标平台正常运行。3月21日起，全市在莆高校实行封闭式管理，中小学、中职学校、幼儿园线下教学暂停一周，有条件的高三毕业班实行封闭式管理、组织线下教学。

　　六是继续组织党员下沉一线。从26个市直单位共抽调445名干部，组成74支战疫工作队，对口支援仙游县鲤城街道、鲤南镇、榜头镇的74个村（居）协助开展社区疫情防控工作。

　　下一步

　　莆田市将按照党中央决策部署，落实国务院联防联控机制要求，在省委省政府的坚强领导下，坚定信心决心，科学精准防控，采取更加有效措施，坚决守住“边界”，防止疫情外溢，全力以赴打好这场疫情防控战。

　　记者问答

　　问题一：本轮疫情发生以来，莆田市公安机关在做好流调和社会面稳控等方面重点采取了哪些措施？

　　答：本轮局部聚集疫情发生后，莆田市公安机关第一时间启动社会治安防控一级响应，全警动员、全警参战，积极做好应对各类突发情况准备。截至目前，已派出两批次近500名警力前往仙游支援，协同当地党委政府做好核酸检测、卡口查验、社区管控等工作，并储备梯次应急力量，做好随时增援准备。

　　在流调溯源方面，莆田市公安机关认真落实“三公（工）一大”融合协同机制，抽调196名精干力量组成市县（区）两级流调工作专班，实行7*24运作运行机制，派员进驻疾控中心，做到精准研判、精准核查、精准落地，确保“一条不漏、一刻不误、一查到底”。进一步优化提速推送机制，创新实施“大数据+视频+脚板”技战法，重塑人物活动轨迹，全流程排摸密接、次密接人员。针对上级下发的指令，开展初筛阳性信息复核、评估工作的同时，公安流调专班同步先期研判，建立三步推送机制，保证在“15分钟之内推送轨迹数据信息、半个小时之内推送轨迹分析报告、1个小时之内完成密切关系人分析报告”，从而争取宝贵的流调溯源时间，有效将病毒扩散外溢风险降到最低。同时，积极与疾控中心、现场流调组沟通验证，多维度开展溯源分析，精确研判感染链条。目前，正在对流调信息全面回头看，力争不漏一人、不留死角，并通过绘制关联关系分析图表，实现病例信息、传播链条和流调档案“一张图”展示。

　　在社会面稳控方面，重点抓好三项工作：一是加强重要点位管控。莆田市公安机关累计派出警力3000余人次，全力做好各核酸采样点、集中隔离点和定点医疗机构的安全保障工作。同时，在全市封控区、管控区内设置执勤卡点21个，安排100余名警力全天候值守，严格控制人员出入，确保疫情不外溢、不扩散。加强全市行业场所管控，严防人员密集处流动交叉感染，全力减低疫情传播风险。全市娱乐场所、桑拿洗浴场所目前已全部暂停营业；仙游县82家旅馆全部暂停营业。二是加强社会治安稳控。莆田市公安机关密切关注社会治安动态，从“路面、空中、海上”三个层面全方位确保全市治安大局持续稳定。路面，通过增加巡逻频次、延长巡逻时间，加强对全市重点部位的巡逻管控，妥善接处每一起涉疫警情，最大限度降低治安风险隐患。疫情发生以来，我市110共回复群众求助咨询等330余件，妥善处置涉疫纠纷警情70余起。空中，日均派出70架次警用无人机，开展劝导劝离、卡口管控、卫生消杀、应急处突等工作，为疫情防控立体化可视化支撑保障。海上，加强全市海岸线管控，严格渔船民管理，严打海上偷私渡，坚决防止疫情经由海上通道输入我市或疫情外溢。此外，我们还打击整治拒不执行疫情防控措施、网上涉疫谣言等违法行为。3月21日，仙游警方对枫亭镇李某未落实居家隔离措施多次往返泉州的行为依法予以处罚。三是加强道路交通管理。第一时间启动道路交通应急机制，完善交通防控应急处置方案，在全市27个主要道路卡口设置查验点，其中对11个查验点实行封闭式管理、16个查验点实行检查通行管理，并进一步规范交通卡口勤务，严格卡口查验。同时，采取交通疏导、转运接驳、车辆消杀等有效措施，确保运输生产生活物资、医疗物资、“点对点”转运、就医以及特定公务等车辆人员安全顺畅通行，全力保障防疫和民生需求。

　　问题二：我市快递业采取哪些措施确保快递安全，市民在收寄快递时需要注意什么？

　　答：首先回答第一个问题。邮政快递业始终坚持“人、物、环境”同防总体策略，拧紧收寄、分拣、运输、投递全流程防控链条，统筹做好行业疫情防控和寄递服务保障工作。目前，我市未出现从业人员感染新冠肺炎病毒情况，未发生因接触快递包裹而感染新冠肺炎病毒情况，行业生产作业总体保持安全平稳运行。

　　一是加强从业人员防疫管理。加强从业人员健康排查，通过实地检查、视频巡查等方式，督促从业人员严格执行健康防护措施，落实从业人员核酸检测“适时抽检”，按要求加强核酸检测抽检频次；督促全市6000余名从业人员加快接种新冠疫苗加强针，截至目前全行业从业人员加强针接种率已达94.7%。

　　二是加强进出莆田邮件快件消毒。要求各寄递企业在处理场所安装邮件快件自动化喷雾消毒装置，对来自国内中高风险地区的进港邮件快件开展重点消杀，凡未经消杀禁止进入下一个处理环节。对国际邮件快件实行提级管控，切实强化“外防输入”，目前所有进莆国际邮件快件在进入生产处理环节时均第一时间逐件对外包装进行全覆盖消杀，落实进口国际邮件快件消毒后须分类留存静置达规定期限方可派送要求，严格分隔作业区域，确保内外不交叉，做到闭环管理。

　　三是加强生产作业环境消杀。进一步加强对全市765个邮政快递营业网点、23个邮件快件处理场所等重点场所管理，督促各寄递企业严格按照国家邮政局《疫情防控期间邮政快递业生产操作规范建议》要求，分区分级做好邮政快递营业场所、处理场所和设施设备每日定时通风消杀。落实进出莆干线运输车辆专人专职专岗专车管理，按次做好全面消杀，并做好台账登记，确保消杀工作“无死角、无盲区、全覆盖”，严防疫情通过寄递渠道传播扩散。

　　当前，国内外疫情防控形势依然严峻复杂，在此提醒广大市民：

　　在寄件时，应遵守防疫各项规定，正确佩戴口罩，主动配合网点工作人员进行测温、扫码、登记等工作；办理业务时请保持合理安全距离。

　　取件时，应加强自身防护，佩戴口罩、手套等个人防护用品，建议快递包裹外包装尽量不带回家中，可用酒精在户外对外包装进行消毒。取出内件后应及时清洗双手，更换口罩。

　　部分邮件快件寄递时效因疫情可能受到影响，请广大市民予以理解。疫情期间，广大快递小哥逆行冲锋，奔忙在一线，为广大市民做好配送生活物资保障，个别可能存在服务不够到位之处，在此呼吁广大市民给予快递小哥们更多理解和支持！

　　问题三：针对养老院、福利院等重点场所，莆田采取哪些防疫手段？

　　答：莆田市目前在运营且收住老人的养老机构42家、儿童福利机构1家、社会福利机构2家、精神卫生福利机构2家。3月12日以来，市民政局采取迅速封闭、全面排查、全员检测、严格防控、保障物资、心理疏导等措施，严防外部感染源输入，保障机构工作人员、服务对象生命安全和身体健康。

　　一、迅速实施封闭管理。各养老、儿童福利、社会福利、精神卫生福利机构实施封闭管理，暂停亲属入院探视、暂停员工出入、暂停接收新（返）入院工作人员及服务对象、暂停其他外来人员入院开展公益服务活动、暂停服务机构内的聚集性活动，禁止快递、外卖、送药人员进入。

　　二、全面排查人员情况。全面排查养老、儿童福利、社会福利和精神卫生福利机构2月28日以来，人员来访和机构工作人员、服务对象的外出旅居史情况，严格按照要求落实核酸检测和隔离观察措施。

　　三、实施全员检测。42家养老机构中工作人员559人、住院老人2028人，及福利机构工作人员和服务对象，完成全员核酸检测。仙游县重点区域养老机构完成第三轮核酸检测。截至目前，各类机构工作人员和服务对象核酸检测全部为阴性。

　　四、严格落实防控措施。要求各类机构每日对工作人员、服务对象做好2次以上体温和健康监测、场所落实2次以上消毒工作；人员用餐实行分餐制度；引导机构人员落实戴口罩、勤洗手、勤开窗、常通风、不扎堆、不聚集等防护措施。同时设置隔离室，对异常情况第一时间隔离并报告。

　　五、做好防疫物资保障。做好疫情防控物资和老年人服务专用物资的储备，储备1个月的防疫物资。

　　六、疏导服务对象心理。通过开展疫情防控宣传工作，普及新冠肺炎防控知识，帮助服务对象与家属亲人等“亲情连线”，进行线上互动，做好人员心理辅导、生活指导。
