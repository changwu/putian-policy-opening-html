市公安局召开第74次新闻发布会通报莆田“110”社会联动指挥中心的相关工作

来源:市公安局 时间：2018-01-10 08:38
| | | |

　　1月9日，市公安局召开2018年“110宣传日”专题新闻发布会，通报莆田“110”社会联动指挥中心的相关工作，市局党委委员、副局长、政治部主任陈忠到会指导。发布会由市局新闻发言人、政治部宣传处处长郭亮进行发布，市局督察、指挥情报中心、交警和消防支队部门领导参加发布会。福建日报驻莆田记者站、海峡都市报、福建法治报、湄洲日报、莆田电视台、莆田晚报、福建东南网等省、市新闻媒体记者应邀参会。

 

 

莆田市公安局新闻发布会新闻稿（全文）

（2018年1月9日）

各位新闻界朋友：

　　大家上午好！欢迎各位参加莆田市公安局2018年“110宣传日”专题新闻发布会。今年的1月10日，是全国第32个“110宣传日”，也是党的十九大胜利召开后的首个“110宣传日”，根据公安部的统一部署，今年“110”宣传活动主题是“110，守护新时代美好生活”。今天新闻发布会主要内容是向各位通报莆田“110”社会联动指挥中心的相关工作。

　　一、建设“专业、科学、高效、担当”“110”，守护新时代莆田人民群众美好生活

　　莆田“110”社会联动指挥中心成立于1997年，2004年实现110、122、119“三台合一”。21年来，莆田“110”社会联动指挥中心坚持以建设多部门一站式救助、多语言警务援助及短信报警业务等综合服务平台为主线，着力推进接处警执法行为规范化建设，在维护社会治安秩序、抢险救灾、排忧解难、优化社会风气、建设平安莆田、构建和谐社会等方面发挥了积极的作用，受到各级党政和社会各界的肯定。特别是近几年来，“110”社会联动指挥中心坚决贯彻落实副市长、公安局长李伙金提出的“专业、科学、高效、担当”要求，依托逐步成型的公安扁平化指挥体系，以快制快，严打各类现行违法犯罪，快速处理危急险重事故，为建设平安莆田作出了应有的贡献。2017年，“110”指挥中心接处警话务量总数为911405个，报警电话总数为120432个，日均接警量2497个。出动警力359011人次，出动车船144723辆（艘）次，现场抓获违法犯罪嫌疑人1110人次。

　　一是进一步健全完善应急指挥调度机制。制定《重特大敏感警情处置工作机制》，规范重特大敏感警情处置流程，建立健全与铁路公安、武警及高速交警的协作机制，第一时间指挥处置重大突发暴力案（事）件；建立中心城区街路面巡逻警力同特警、武警武装联勤的勤务制度，对极端暴力案（事）件等警情同步快速调度多种警力迅速到场处置，确保重大案（事）件应急处置工作有条不紊，确保人民群众生命财产安全得到保护。二是建立健全布控堵截卡点建设。设立中心市区布控堵截工作预案，在全市范围设立公安检查站、布控堵截点和“1、3、5分钟快速反应圈”，实现全市治安卡点（检查站）可视化和布控堵截的智能化，确保全市范围内发生重大案（事）件时多方警力召之即来、来之能战、战之能胜。2017年6月18日夜晚，荔城区林某某（男，43岁）驾驶轿车在该区西天尾镇某小区门口停车时，连人带车被犯罪团伙劫持，“110”指挥中心接到受害者家属报警后，立即开展案情分析研判，随即发现被抢轿车于当日23时在福州市永泰县岭路乡寨下出现，110”指挥中心立即指令荔城公安分局组织警力前往永泰县侦查，同时请求省公安厅、福州市公安局、永泰县公安局指挥中心对车辆进行联合拦截抓捕。19日6时许，荔城公安分局联合永泰警方在永泰县葛岭镇一举抓获持刀绑架抢劫犯罪嫌疑人杨其山等3人流窜抢劫犯罪团伙。经审讯，该团伙承认今年已先后流窜江西、龙岩、仙游等地实施抢劫作案多起，一个横跨闽赣两省流窜持刀绑架抢劫犯罪团伙被彻底摧毁。该案的快速破获得到省、市领导的充分肯定。三是预警指导各级公安着力打防工作。开展警情分析研判通报，以文件通报、每日警情短信提醒等方式指导基层所队开展打防工作，2017年，全市“两抢一盗”警情同比下降20.5%。四是在改革创新中不断发展。通过以规范110警情处置、推进110报警服务台与12345便民服务平台的对接为抓手，进一步做好非警务警情对接分流工作，着力提高“110”警情处置、服务救助的整体效能。2017年5月，市局及仙游县局已完成“110”报警服务台与莆田市12345便民服务平台的电话转接、三方通话，实现非警务警情的科学流转。同时，“110”坚持积极推进大数据时代智慧警务模式，坚持以信息化建设为主线，在加强与各联动单位积极沟通协调合作基础上，特别注重对城市管理中的热点、难点问题进行会商研究解决。通过相关警情数据分析，大力推进社会治安安全区建设，实行可防性案件及交通、火灾事故等重要指标的周提示、月预警、季考评、年奖惩的工作机制，促进部门间高效联动，不断增强城市服务管理应急联动工作能力，努力为美丽莆田建设提供安全稳定的社会治安环境。

　　此外，“110”社会联动指挥中心于2016年4月份开始，与市委文明办、市志愿者协会、东南网莆田站等部门、社会团体及网络媒体联合携手，开展“网络求真”志愿服务活动，寻求事实真相，消除流言谣言，引导社会舆论，在维护社会治安安定和社会稳定方面取得明显成效。仅2017年，“网络求真”志愿服务活动已成功救助群众41人次。市公安局指挥情报中心先后线下协同求证190余起网传信息，对“人贩子在莆田抢小孩”、“莆田二中跳楼学生的一封信”等多起网络谣言进行辟谣，发布“仙游90后男子出走未归”、“湖北女子莆田走失6天”等多起网络寻人信息，成功通过网络求真平台，帮忙寻回走失人员54名。2017年1月1日，市公安局指挥情报中心协助东南网“网络求真”栏目发布“仙游县26岁小伙走失5天未归”信息，立即得到泉州警方的响应，已走失至泉州的26岁小伙朱某当晚就得以回到仙游县枫亭镇与家人团聚。

　　二、关爱“110”，用好“110”，共同维护“110”最大化发挥守护功能

　　“110”报警服务台负责全天24小时受理公众紧急电话报警、求助、举报和对公安机关及其人民警察正在发生的违法违纪或者失职行为的投诉。

　　这里再次重申，“110”报警服务台的受理范围为：

　　（一）受理报警

　　1.刑事案件；

　　2.治安、交通案（事）件；

　　3.危及人身、财产安全或社会治安秩序的群体性事件；

　　4.自然灾害、治安灾害事故；

　　5.其他需要公安机关处置的与违法犯罪有关的报警。

　　（二）受理求助

　　1.发生溺水、坠楼、自杀等危急情况，需要公安机关紧急救助的；

　　2.老人、儿童及智障人员、精神疾病患者等人员走失，需要公安机关在一定范围内帮助查找的；

　　3.公众遇到危难，处于孤立无援的状况，需要立即救助的；

　　4.涉及水、电、油、气、热等公共社会设施出现险情，威胁公共安全、人身或财产安全和工作、学习、生活秩序，需要公安机关先期紧急处置的；

　　5.需要公安机关处理的其他紧急求助事项。

　　（三）受理投诉

　　公安机关及其人民警察正在发生的违反《中华人民共和国人民警察法》、《公安机关督察条例》等法律、法规和人民警察各项纪律规定，违法行使职权，不履行法定职责，不遵守各项执法、服务、组织、管理制度和职业道德的行为。

　　据统计，2017年“110”指挥中心接线有效报警电话120432起，而接线骚扰或无效报警电话547656起，虚假警情电话905起。骚扰、无效及虚假警情是有效警情的4.5倍多。警方再次提醒，“110”是报警求助电话，请广大群众在无警情或险情的情况下，不要随意拨打“110”，以免占用“110”有限的报警线位。随意拨打“110”，不仅无端耗费公安机关有限的警力资源，还影响“110”准确处警效率，也可能会发生他人的生命财产安全无法得到及时有效保护。“公安110，为民保安宁；12345，服务找政府。”

　　近年来，公安机关已不断加大对拨打“110”恶意扰警、虚假报警、恶意举报等违法犯罪行为的打击力度。2017年7月，违法嫌疑人蔡某（女，28岁，城厢区霞林街道人）多次拨打“110”，报称荔城区镇海街道正荣华府门口交通堵塞，但交警部门出警赶到现场后并未发现堵塞现象，蔡某因虚假报警涉嫌违法。公安机关经调查，鉴于蔡某本人身体健康原因，且蔡某已认识到错误并做出书面检讨，公安机关暂缓给予治安处罚裁决，予批评教育。2017年10月13日，犯罪嫌疑人林某青（男，42岁，城厢区华亭镇人）拨打110举报一辆载有爆炸物品的货车从市区出发，准备在莆田西上高速后前往广东。接警后，110立即启动区域协作机制。当日24时许，公安机关在龙岩闽粤收费处检查站将该车查获扣留。莆田、龙岩两地公安机关经过近15小时的安检核查，在举报车辆上并没有发现爆炸物品和易燃易爆物品。之后，公安机关通过多种研判手段，于11月1日晚在城厢霞林街道抓获涉嫌编造、故意传播虚假恐怖信息的犯罪嫌疑人林某青。通过审讯，犯罪嫌疑人林某青交待自己经营一家物流公司，因生意竞争，于10月13日晚向市局110谎报一家物流公司的货运车上运载货物中有炸药。目前，犯罪嫌疑人林某青因涉嫌编造虚假信息罪被公安机关依法刑事拘留。

　　明天就是2018年1月10日，全市公安机关将同时开展“110”系列宣传活动。仙游鲤中步行街、荔城馨宜新天地广场、金鼎广场、城厢凤凰山广场、大唐广场、万达广场、涵江恒隆财富广场、秀屿笏石汽车站，北岸忠门镇、东埔镇、山亭镇等地将多点开展“110，守护新时代美好生活”主题宣传，欢迎广大媒体记者朋友深入现场进行采访报道。

　　在此，公安机关也衷心感谢各新闻媒体及各位记者朋友多年来对“110”工作的关心支持和宣传呼吁。

　　谢谢大家！
