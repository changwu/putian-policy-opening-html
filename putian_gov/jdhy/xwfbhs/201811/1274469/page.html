市公安局召开新闻发布会通报全市公安机关打击经济犯罪、电信网络诈骗犯罪等工作

来源:市公安局 时间：2018-05-12 08:42
| | | |

　　5月11日，市公安局召开新闻发布会，通报全市公安机关打击经济犯罪、电信网络诈骗犯罪、枪爆违法犯罪工作。市局新闻发言人、政治部宣传处处长郭亮进行发布，市局指挥情报中心、出入境管理支队、刑侦支队、治安支队、经侦支队等部门同志参加发布会。福建法治报、湄洲日报、莆田晚报、莆田侨乡时报、福建东南网等省、市新闻媒体记者应邀参会。

 

莆田市公安局新闻发布会新闻稿（全文）

（2018年5月11日）

各位朋友：

　　大家上午好！欢迎各位参加莆田市公安局新闻发布会。今天新闻发布会主要内容是向各位通报全市公安机关打击经济犯罪、电信网络诈骗犯罪、枪爆违法犯罪等五个方面的相关工作情况。

　　一、2017年以来，全市公安机关打击经济领域违法犯罪取得成效

　　每年的5月15日是全国打击防范经济犯罪宣传日，今年是第九个。今年我们市宣传日活动的主题是“打击防范涉众犯罪护航经济保障民生”。活动重点是围绕非法集资、传销特别是网络传销等突出风险型经济犯罪，展现公安机关打击经济犯罪的坚定决心，努力增强人民群众识别和防范经济犯罪的意识和能力，积极推动社会各界共同参与打击和防范经济犯罪工作。“5.15”前后，市县区两级公安机关将组织实施宣传活动“五进”（进村居、进企业、进单位、进学校、进家庭）和在繁华地带设点发放宣传品接受群众咨询等活动，欢迎并感谢各媒体记者朋友帮助扩大宣传。

　　2017年，全市公安经侦部门按照公安部、省厅部署要求，强力推进“猎狐”、“云端行动”、“春雷”等系列专项行动，同步推进打击其他各类经济犯罪专项行动，重点打击非法集资、地下钱庄、银行卡、虚开骗税、证券期货、网络传销、侵权假冒等七类风险型经济犯罪，破获各类经济犯罪案件500多起（其中省厅挂牌督办案件3起），抓获犯罪嫌疑人300余人。

　　一是打击侵权假冒犯罪专项行动。全市各级公安机关成功捣毁制假售假窝点64个，立案54起，破案52起，抓获犯罪嫌疑人53人，缴获假冒注册商标运动鞋29万余双、鞋底1.9万余双、商标标识25万个、制假半成品2068件、假帽子10.5万余顶。配合查处行政案件67起，行政处罚违法行为人72人。2017年4月，荔城公安分局经侦大队在荔城区新度镇查获1个假冒运动鞋仓库，当场扣押假冒著名品牌运动鞋16300双，涉案价值1735余万元。犯罪嫌疑人被判处有期徒刑3年缓刑，并处罚金40万元。二是打击银行卡犯罪专项行动。全市公安经侦部门共立各类银行卡犯罪案件90起，破案77起，涉案金额达700余万元，挽回损失170余万元，抓获犯罪嫌疑人37人，移送起诉34人。涉嫌信用卡诈骗的犯罪嫌疑人刘某自2013年起曾在多个银行办理多张信用卡进行消费，消费欠款共计15余万元，面对相关银行催款3次还坚持拒绝还款，后被涵江公安分局抓获归案并被法院因涉嫌信用卡诈骗罪被判处有期徒刑5年，并处罚金5万元。三是打击非法传销违法犯罪。全市公安机关共立传销案件19起，破案14起，立因传销引发的非法拘禁39起，抓获犯罪嫌疑人59名，起诉47名，打掉团伙12个，摧毁窝点37个，遣返人员559名。四是打击非法集资类违法犯罪。全市经侦部门共立案15起，破案11起，其中刑拘23人，起诉28人。此外，全市公安经侦部门还在打击利用离岸公司和地下钱庄转移赃款违法犯罪中破案2起，抓获犯罪嫌疑人4人，移送起诉2人；在打击假币专项行动中收缴假币7万余元，并对犯罪嫌疑人进行了处罚。

　　从近年来我们市公安经侦部门办理的经济犯罪案件的总体情况看，涉众型和风险型的经济犯罪在所有经济犯罪案件中基本呈高占比趋势，仅2017年5月之后，全市经侦部门共梳理摸排出涉及“善心汇”、“沃客”“泛亚”等10个涉众型和风险型经济犯罪的利益受损群体总人数达2.1万余人。期间，各级公安机关虽然做了大量的宣传防范工作，但涉案及经济受损问题仍然时有发生。借用今天机会，公安机关再次提醒广大群众，要切实增强对经济领域违法犯罪案件的辨识和抵抗能力。一是要有效辨识风险。理财有风险，投资需谨慎。针对市面上各种明显不靠谱的“高回报”投资不可轻易相信，特别是针对目前常见的非法集资和传销现象，群众在投资时要充分考虑可能带来的经济损失等多方面的风险，时刻保持清醒的头脑和警惕，保护自己合法财产。二是要提升保护意识。科技高速发展带来的电子信息时代，便利了我们生活的同时也增加了风险。广大人民群众要保持高度警觉性，切实做到“三防”：防失密、防骗密、防窃密，谨慎保管个人信息，有必要注册个人信息时，要注意核对官方网站，提防非法网站获取个人信息进行违法犯罪。三是要积极配合维权。广大人民群众在财产受到不法侵害后，要尽快拨打110或到当地公安机关报案，同时要注意保存好相关证据资料，切忌盲目听信旁人，延误时机，要积极配合公安机关开展调查取证、查询冻结、快速止付等工作，公安机关将尽最大努力为受害群众挽回经济损失。

　　二、市公安局出入境管理支队四项举措落实申办出入境证件“只跑一次”新政

　　为贯彻落实国家移民局关于全面实行办理护照等出入境证件“只跑一次”制度，根据省厅出入境管理局部署和市局领导指示要求，市公安局出入境管理支队在全面执行“只跑一次”制度的基础上，出台四项措施，确保制度要求落实到位。

　　一是设立“绿色”专窗。为更好地为紧急办证人员提供加急办证服务，出入境管理支队在市局出入境办证服务大厅设立专门紧急办证“绿色通道”专窗（办理事项清单附后）。

　　二是增设自助设备。在仙游、秀屿、北岸出入境部门各增设1台自动填表机，在仙游、涵江出入境部门各增设1台签注一体机，至此全市各级出入境部门共有自动填表机5台、签注一体机3台、签注受理机2台。

　　三是遍布受理机构。新增北岸分局出入境管理科和黄石派出所、华亭派出所、湄洲派出所出入境受理点，实现了全市各县(区)公安出入境管理机构和派出所受理点全覆盖。

　　四是开通服务电话。在原有对外公布市局出入境管理支队24小时投诉监督电话的基础上，进一步完善县（区）级出入境部门“只跑一次”制度服务电话，全面完成了各级出入境部门设置24小时服务电话。

　　三、全市打击电信网络诈骗犯罪工作不断导向深入

　　2018年1至4月份，全市电信网络诈骗犯罪案件发案数442起，较去年同比下降24%，损失金额664万余元，同比下降21%，破获案件数80起，同比上升29%，抓获嫌疑人数60人，同比上升22%，基本实现“两降两升”的工作目标。1至4月份，全市反诈骗部门成功阻断正在实施电信诈骗犯罪行为电话255个次，挽回经济损失397万余元；关停涉案违法电话号码121个，拦截非法主叫号码375个，回访提醒用户3598人次；冻结涉案银行账户33个，查询涉案银行卡581个，冻结涉案银行账户金额329万余元，全力遏制电信网络诈骗犯罪。

　　2018年4月起至今年12月底，市公安局将组织开展严打电信网络诈骗犯罪专项行动。专项行动将重点打击假冒公检法类诈骗、投资返利类诈骗、兼职刷单类诈骗、网络购物类诈骗、民族资产解冻类诈骗、贷款类诈骗、网络赌博类诈骗、二维码类诈骗及侵害、贩卖个人信息行为等电信网络诈骗犯罪。

　　4月2日，市反诈骗中心联合城厢分局在相关部门的配合下，先后在江西省丰城、萍乡两地，摧毁2个电信网络诈骗犯罪窝点，抓获电信网络诈骗犯罪团伙4人，经查，该团伙自2017年通过QQ、微信等平台采取刷单诈骗的新型电信诈骗手法，通过上下线发单形式，诈骗金额近百万元，初步核查涉及诈骗案件200余起，案件还在进一步深挖审理。4月19日下午4时许，我市某公司职员苏某收到公司老板的QQ消息，要求他立即向名字“杨某”的一个工行帐户汇款20万元。接到消息后苏某立即通知公司财务汇款20万元到指定账户，并用微信将汇款截图发给公司老板。老板收到微信信息后却表示其没有通知汇款，苏某发现被骗后立即拨打110报案。接报后市反诈骗中心立即联系金融部门对该账户展开紧急处置，成功将该笔资金止付并冻结，及时阻止了受害人的经济损失。目前，市反诈骗中心正根据相关规定为受害人办理资金返还。

　　目前，电信网络诈骗犯罪已造成多名群众经济财产遭受损失，仅今年1至4月份，群众被骗经济达600余万元。借此机会，公安机关再次提醒广大群众：虽然诈骗犯罪手法更新换代，但无论诈骗手段类型如何变化，最终都是冲着骗钱的目的。只要牢记“四不原则”、“八个凡是”，就能够有效戳穿骗术，让骗子无机可乘。

　　四不原则：不轻信：遇到陌生短信电话不轻信；不透露：遇到索要验证码或其他个人信息、密码的不透露；不转账：遇到要求转账汇款的不转账；不点击：遇到陌生链接的不点击。

　　八个凡是：凡是自称公检法要求汇款的，凡是叫你汇款到“安全账户”的，凡是通知中奖、领奖要你先交钱的，凡是通知“家属”出事要先汇款的，凡是在电话中索要银行卡信息及验证码的，凡是让你开通网银接受检查的，凡是自称领导要求打款的，凡是陌生网站要登记银行卡信息的，都是骗人的，一定不能相信。

　　四、全市公安机关深入开展打击整治枪爆违法犯罪专项行动

　　为贯彻落实上级公安机关和综治部门部署，我们市自今年2月起，组织开展为期2年的打击整治枪爆违法犯罪专项行动。专项行动由市公安局牵头，22个市直成员单位组成联席会议。

　　专项行动打击重点。缉枪：主要以打击境内制贩、境外走私、网络贩卖以及、枪爆与恐黑毒赌合流犯罪以及境外走私为重点，特别是针对网络贩卖枪支弹药问题，坚持网上网下联动，强化区域部门协作，集中侦破一批案件，对重大案件、逃犯实行分级挂牌督办、督捕，依法严厉打击涉枪违法犯罪活动。治爆：主要加强民爆物品和易制爆危险化学品源头管控，对易滋生枪爆隐患的重点场所、寄递物流等重点行业，广泛发动基层力量，开展“拉网式”排查整治，加强社会面非法枪爆物品的清查收缴；联合对涉爆问题突出地区进行挂牌整治，着力加强综合治理、系统治理，全力铲除涉爆安全隐患。净网：主要开展网上枪爆违法信息清理专项行动，及时清理枪爆违法信息，重点整治一批问题突出的企业、网站，关停、封堵枪爆违法网站、论坛，主动发现查处一批枪爆犯罪线索，着力净化网络环境。

　　专项行动开展以来，全市公安机关共查获涉枪涉爆案件12起，抓获各类犯罪嫌疑人14名，其中省厅公开督捕逃犯2名，收缴了一批各类枪支子弹、及炸药、雷管、黑火药等枪爆物品。3月29日，福建省公安厅公开缉捕8名涉枪涉爆案件在逃人员，其中涉及莆田案件在逃人员3名。经公安机关走访亲友政策宣导，成功规劝其中2名在逃人员主动投案。目前，省厅公开督捕的涉枪涉爆在逃人员朱建强（男，山东曹县人，37292219980817821X）还在抓捕中。

　　五、公安机关严厉打击来电呼叫转移到110的违法行为

　　今年2月份以来，全市连续发生3起将手机来电呼叫恶意转接至110指挥中心的违法案件，严重扰乱了110指挥中心的日常工作。

　　2018年2月19日，陈某斌（男，19岁，涵江区白塘镇人）故意将因个人问题将其个人手机设置来电呼叫转移至市110指挥中心平台，致使约有800通骚扰电话拨打至市110指挥中心平台，严重扰乱市110指挥中心正常接处警工作秩序。4月4日，白塘派出所抓获违法嫌疑人陈某斌，对陈某斌处以行政拘留十日、罚款伍佰元处罚。

　　2017年3月，周某文（男，33岁，荔城区北高镇人）在某手机店购买了三部手机，和老板签订了分期付款的合同，后因债务纠纷，手机店的老板一直电话催促周某文还钱。3月25日至26日，周某文因被对方一直催款，就将其手机呼叫转移到110指挥中心和120急救中心，扰乱了110指挥中心和120急救中心的接处警和救助秩序。4月18日，北高派出所对周某文处以行政拘留十日处罚。

　　2018年2月，张某贵（男，23岁，贵州省毕节市人）交500元加入一个红包群抢红包，后发现群主抢红包作弊要求退钱并与群主发纠纷，后被群主利用软件轰炸其手机。3月11日至12日，张某贵将其个人电话转移至110指挥中心和120急救中心共通话1155通，严重扰乱110指挥中心和120急救中心的工作秩序。4月17日，拱辰派出所对张某贵处以行政拘留十日。

　　《中华人民共和国治安管理处罚法》第二十三条第一款第（一）项规定：“有扰乱机关、团体、企业、事业单位秩序，致使工作、生产、营业、医疗、教学、科研不能正常进行，尚未造成严重损失的，处警告或者200百元以下罚款；情节较重的，处5日以上10日以下拘留，可以并处500元以下罚款。”

　　“110”“120”是接受群众报警求助、处置紧急警务的公共资源，公安机关希望广大群众能够珍惜、爱护和正确使用“110”“120”。对恶意占用“110”“120”资源引发违法行为的，公安机关将予严厉查处。
