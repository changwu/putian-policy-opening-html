莆田市政府新闻办举行莆田市复工复产第十二场新闻发布会（全程实录）

来源:莆田发布 时间：2020-04-03 16:00
| | | |

　　莆田市委宣传部四级调研员周蓉:

　　各位媒体朋友，女士们、先生们，大家上午好。欢迎大家出席莆田市人民政府新闻办新闻发布会。

　　4月2日，莆田市人民政府新闻办公室举行莆田市复工复产第十二场新闻发布会，邀请莆田市文化和旅游局副局长林新钊，市文旅局市场法规科科长任斌俊，市文旅局产业发展科科长陈美弟，市文旅局公共服务科负责人林益清，解读国家、省、市出台复工复产相关扶持政策，介绍政策落实情况和发挥政策作用所取得的积极成效，并回答记者朋友的提问。

　　首先欢迎市文旅局林新钊副局长向大家介绍我市文旅行业复工复产工作开展情况。

　　莆田市文化和旅游局副局长林新钊：

　　各位记者好！大家好！我是莆田市文化和旅游局副局长林新钊，欢迎大家来参加今天的新闻发布会。大家知道，从1月底开始，受新冠疫情影响，全市文化和旅游相关企业全面停工，至今已2个多月。随着疫情形势的逐步好转，文化场馆、A级旅游景区、实体书店等文旅企业正在逐步有序复工复产。现在由我介绍我市文旅企业复工复产工作情况：

　　一、有序推进复工复产。鉴于疫情防控工作需要，根据省文旅厅、省广电局等省直主管部门和市疫情防控指挥部统一部署，目前文旅方面复工复产的范围主要是：一是图书馆、文化馆（站）、博物馆等公共文化场所、各旅游景区、实体书店、印刷企业在落实防控措施的基础上有序复工复产；目前市博物馆、图书馆和群众艺术馆已于3月28日正式对外开放，全市36个A级景区正在根据自身实际情况逐步开放，95%的书店和印刷企业实现复工复产。二是各旅行社和在线旅游企业不得经营跨省（区、市）和出入境的团队旅游业务及‘机票+酒店’旅游业务。三是演出场所、歌舞娱乐场所、上网服务场所、影剧院等人员聚集的场所暂不复业。

　　二、加大政策扶持力度。我局与市财政局联合制定了《关于应对疫情支持文化和旅游企业复工复产十条措施》，主要从金融扶持、税费减免、奖补资金兑现、入莆旅游奖励标准提高、暂退质量保证金、减免旅行社责任保险费、减免企业房租、扶持稳岗就业、开展“抗疫振旅”线上公益培训和提供法律援助等十个方面给予了政策倾斜和扶持。同时还开展了白名单企业帮扶行动，制定“白名单”企业认定条件，目前已公布了二批“白名单”企业30家，其中出版物印刷企业、旅行社、星级酒店各10家。

　　三、加强复工复产服务。一是通过微信公众号等网络新媒体扩大疫情防控知识宣传，广泛宣传各级疫情防控重大通知、预防常识、各级扶持政策等相关内容，为企业提供了资讯；二是出台《莆田市旅游景区有序开放工作指南》，印发了《公共图书馆、文化馆（站）恢复开放工作指南》《关于新冠肺炎疫情防控期间有序推进文博单位恢复开放和复工的指导意见》，指导景区和基层公共文化场馆有序开放。三是局领导分别带队深入文旅企业及公共服务场所检查安全生产隐患大排查大整治工作，重点排查整治房屋安全隐患，指导疫情防控和有序开放，确保复工复产稳妥推进。

　　下一步，我局将认真贯彻落实习近平总书记重要讲话重要指示批示精神，在做好新冠肺炎疫情防控工作的同时，进一步落实好企业帮扶政策，扩大文化和旅游企业复工复产范围，推进文化和旅游产业加快恢复。

　　周蓉:

　　感谢林副局长的介绍。

　　现在进入答记者问环节，请媒体朋友们就关心的问题进行提问。提问前请先举手示意，应邀提问时请自报身份。现在开始提问。

　　莆田侨乡时报记者：

　　刚才市文旅局林新钊副局长介绍说，对文旅企业的复工复产出台了扶持政策，能否详细介绍一下相关内容？

　　市场法规科科长任斌俊：

　　为全面贯彻落实党中央国务院、省委省政府、市委市政府关于防控新冠肺炎疫情的决策部署和相关文件精神，支持全市文化和旅游企业渡过难关有序复工复产，我局与市财政出台了复工复产十条扶持措施，具体如下：

　　一是金融政策扶持。对受疫情影响严重的住宿和旅游企业给予贷款贴息支持，贴息范围为2020年6月30日前向困难行业企业新发放的、且单户余额不超过1000万元部分的优惠利率贷款，可获得0.5个百分点贴息支持，期限不超过1年。工商银行莆田分行根据市文旅局公布的文旅企业“白名单”，由市中小企业融资再担保公司优先予以增信担保，扶持有发展前景但资金暂时困难的旅行社流动资金贷款。

　　二是相关税费减免。疫情期间，对文化和旅游中小微企业的房产税、城镇土地使用税减半征收，确有困难的，可以申请减免。对受疫情影响较大的餐饮、住宿企业免征2020年江海堤防工程维护管理费。中国电信莆田分公司免收全市互联网上网服务企业1个月网络服务费。

　　三是加快兑现奖补资金。对被评为国家、省级旅游品牌奖励以及酒店改造提升以奖代补的资金，根据实际情况加快兑现到位。

　　四是提高入莆旅游奖励标准。2020年，对接待单团10人以上（含10人）的入莆过夜游旅行社，按每人10元给予奖励，每家旅行社年度最高奖励3万元；对年组织接待入莆过夜游客3000人次以上的旅行社按实际组织接待人次，每人次奖励在2019年标准基础上提高5元，每家旅行社年度最高奖励50万元；对当年度组织接待入莆过夜游客累计人数前3名的旅行社再分别给予3万元、2万元、1万元奖励。

　　五是暂退质量保证金。对已依法交纳保证金、领取旅行社业务经营许可证的旅行社，暂退现有交纳数额的80%。被法院冻结的保证金不在此次暂退范围之内。

　　六是减免旅行社责任保险费。2020年1月24日前投保出单2020年旅行社责任保险统保示范项目的旅行社，按照文化和旅游部停止团队旅游业务和恢复团队旅游业务的通知时间，减免业务暂停期间保费。

　　七是减免企业房租。疫情期间，对承租国有资产类经营用房的文化和旅游中小微工业企业，房租给予免收，其他行业房租减半，减免房租期限原则上为2020年2月1日至4月30日。

　　八是扶持稳岗就业。2020年对不裁员或少裁员的文化和旅游中小企业，返还其上年度实际缴纳失业保险费的50%。对受疫情影响面临暂时性生产经营困难且恢复有望、坚持不裁员或少裁员、符合条件的文化和旅游参保企业，按6个月的当地月人均失业保险金和参保职工人数落实失业保险稳岗返还政策。鼓励和扶持来莆外地旅游人才，疫情前在同一家旅游企业工作半年以上，且复工后仍在莆田在岗带团的持证导游，今年内给予每人每个月500元的稳就业奖补，奖补期限半年。

　　九是开展“抗疫振旅”线上公益培训。引进“抗疫振旅”系列线上培训课程，邀请国内知名文旅专家线上授课，培训内容涵盖旅游业疫后修复和产业振兴、文旅融合、乡村振兴、疫后景区扶持政策、5G景区等行业热点，为文旅企业和从业者、管理者等提供行业指导，为文旅发展突破困境提供智力保障，为文旅行业保驾护航。

　　十是提供法律援助。由莆田市旅游协会联合福建众益律师事务所组建了文化和旅游行业法律援助团，为全市文化和旅游企业在疫情期间提供法律事务咨询和援助等服务。

　　福建日报社记者：

　　莆田市博物馆、图书馆、群众艺术馆等公共文化场馆已陆续恢复开放，请市文旅介绍一下这方面的具体情况？

　　公共服务科负责人林益清：

　　随着疫情防控工作的积极向好，为满足市民的文化需求，按照市疫情防控指挥部统一部署，市博物馆、图书馆、群众艺术馆已于3月28日恢复对外开放。各场馆制定具体方案，通过入馆人数总量控制，实名登记，检测体温，引导佩戴口罩，做好疏导、分流，加强场馆通风、消毒，做好疫情防控等措施，来切实做好恢复开馆工作。

　　市图书馆：每天开放时间9:00—17：00， 每周三下午闭馆整理内业。采用网上预约、现场扫码预约相结合方式，当日接待读者总人数不超过500人，瞬时在馆人数不超100人，达到限额后先出后进。莆阳书房开放时间另行通知。市群众艺术馆：每天开放时间8:00—12：00、14：30—17：30。市博物馆：每天开放时间9：00—16：30，每周一闭馆整理内业。采用现场实名登记方式入场，当日接待观众总人数不超过3000人，瞬时在馆人数不超500人，达到限额后先出后进。

　　在闭馆期间，市级三馆通过网站、掌上莆图APP、微信公众号等，推出《闭馆不打烊 居家看展览》精品线上系列展览、市图书馆“云”讲座、阅读推广、网络诗词大赛、抗疫文艺作品推广等数字服务，取得了良好的效果。接下来，将持续加强数字内容更新，为群众提供优质公共数字文化服务。

　　同时，我局还下发文件，指导县区（管委会）有序做好场馆恢复开放工作，县级及以下的各类公共文化场馆也将陆续开放。

　　欢迎市民们到场馆观看展览、借阅书籍，同时也希望到馆的市民能配合场馆工作人员做好实名登记、体温检测、佩戴口罩、保持安全距离等工作，共同为享受文化服务营造一个安全健康的环境。

　　莆田广播电视台记者：

　　受新冠肺炎疫情的影响，广播影视行业也面临一些困难，请问林副局长，我市关于广播影视行业复工复产有哪些具体措施？

　　林新钊：

　　一是优化行政审批服务。除涉密事项外，所有广电行政审批服务事项实行网上办理、远程审批。疫情防控期间，对企业办理的行政审批事项实行快递双向免费。为创作生产反映防疫抗疫的电视剧、网络剧开通绿色通道，加快审核审批进度。对已到期的广播电视和网络视听相关许可证，可在原办理时间要求基础上顺延2个月内申请办理延续业务，顺延期间视为有效许可证。

　　二是加大专项资金扶持力度。省广电局设立的电视剧网络剧创作生产专项资金，对反映福建防疫抗疫和支援湖北题材的优秀作品给予重点扶持补助，对剧本创作、成片拍摄、宣传推介等予以支持。对“众志成城 共同战疫”电视短纪录片、防疫抗疫题材网络影视剧优秀作品给予补助。省级广播电视发展专项资金加大对防疫公益广告的补助力度，对在防疫抗疫中发挥重要作用的媒体融合发展、科技创新等项目给予扶持。全省安排1000万元，对受疫情影响严重的电影院线、电影院给予补助，以原中央苏区和革命老区的县级和乡镇影院为重点，助力脱贫攻坚；加快拨付中央财政电影奖补专项资金；按照国家有关规定，对纳入中央补助范围的电影企业或项目进行配套资金补助；优化电影专资征缴使用，延期征缴和减免电影专资；省级电影专资安排1700多万元按年度票房收入、增长率、占有率和新开影院数等对符合要求的发行放映单位予以奖补。

　　三是优化广播电视公共服务。省级继续安排省内优秀电视剧、电影、纪录片、动画片、广播剧、公益广告和网络视听节目提供各级广播电视台公益播出。支持鼓励有条件的网络视听机构、平台继续开设在线教育、开办网络课堂，为“停课不停学”提供服务。省电影局与中影巴可（北京）电子有限公司和日本电气股份有限公司协调商定，为我省电影企业从业人员免费提供在线公益直播课，帮助电影从业人员增强业务能力。

　　湄洲日报记者：

　　目前，全国疫情得到了有效控制，但随着疫情的好转，国内很多地区的景区已经渐渐开放。那么，莆田市景区什么时候恢复开放？有哪些助力景区复工复产举措？

　　产业发展科科长陈美弟：

　　根据《莆田市应对新型冠状病毒感染肺炎疫情工作指挥部关于有序开放公共场所和经营性服务场所的通告》，从3月25日起，全市35个国家A级旅游景区室外区域有序恢复开放。我局主要采取以下措施：

　　一是指导A级景区继续做好疫情防控，督促景区落实“实名入园、体温监测、间隔距离购票；并实行限流游客入园、科学分流制度，游客的间距必须达到1.5米以上”等要求；同时，景区采取定时卫生消杀、员工健康登记管理等措施，确保游览环境安全。

　　二是全面贯彻落实党中央国务院、省委省政府和市委市政府关于防控新冠肺炎疫情的决策部署，落实《有效应对疫情支持文化和旅游企业复工复产若干措施》，有效应对疫情，重点在强化金额政策扶持、减免相关税费、延期缴纳税款和社会保险费、加大稳岗扶持力度、提供法律援助等方面支持旅游景区渡过难关，全力推进旅游企业科学有序复工复产。

　　周蓉:

　　由于时间关系,今天的现场提问就到这里，感谢记者朋友的提问和各位领导详尽的解答。媒体朋友们如果还有什么需要了解的问题，可以在发布会结束后，与莆田市文旅局联系，再进行深入采访。

　　今天的新闻发布会到此结束，谢谢大家！
