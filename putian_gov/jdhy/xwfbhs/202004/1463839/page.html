莆田市政府新闻办举行莆田市复工复产农业农村局专场新闻发布会（全程实录）

来源:莆田发布 时间：2020-04-21 09:51
| | | |

莆田市委宣传部四级调研员周蓉:

各位记者，女士们，先生们，上午好。欢迎大家出席莆田市人民政府新闻办新闻发布会。

今天是莆田市复工复产第二十四场新闻发布会，我们围绕“克服疫情影响 推进脱贫攻坚”这个主题，邀请市农业农村局副局长黄金辉，市教育局副局长戴明粦，市人社局副局长戴建忠，市民政局副局长周庆平，请他们就大家关心关注的问题做发布，并回答记者朋友的提问。

首先，请市农业农村局黄金辉副局长向大家介绍我市克服疫情影响推进脱贫攻坚工作情况。

 

市农业农村局副局长黄金辉:

各位新闻记者:大家早上好！我是莆田市农业农村局（市扶贫办）的黄金辉，按照安排，现在由我来介绍全市克服疫情影响推进脱贫攻坚工作情况。

今年是决胜全面建成小康社会、决战脱贫攻坚的收官之年。脱贫攻坚本来就有很多硬战要打，突如其来的疫情对我们工作确实产生一些影响，市委、市政府高度重视，以大战和大考统筹推进疫情防控与脱贫攻坚两项工作，着力聚焦老区苏区脱贫奔小康，积极克服新冠肺炎疫情对脱贫攻坚的影响，采取针对性的措施，精准发力，确保高质量打赢脱贫攻坚战。全市88个建档立卡贫困村和8972户28330名贫困人口在2019年底实现全部脱贫，从日常排查监测情况来看，未发现有扶贫干部、驻村第一书记、贫困户感染新冠肺炎，也未出现返贫和新增致贫贫困人口；计划务工就业贫困人口10055人，已返工务工10041人，占99.85%，同比增长104.71%；261个扶贫基地已全部复工复产，可带动2945名贫困人口稳定增收；累计新增贷款金额568.08万元，新增贷款贫困户数124户。总体上，脱贫攻坚重点工作有序推进，不会因为疫情影响脱贫攻坚目标任务的实现。在统筹推进疫情防控和脱贫攻坚工作上，我们采取的措施主要有：

一、加强督导，全面防控。疫情防控期间，莆田市领导多次下到基层一线，查访贫困村、贫困户受疫情影响情况，指导镇、村严格落实差异化疫情防控措施，优先保障贫困群众生命安全和身体健康。全市88个驻贫困村工作队和179名驻村第一书记全部入驻一线，做好驻村点的防疫和脱贫攻坚工作。同时，我市还建立了周跟踪制度，密切跟踪分析疫情对贫困对象基本生活、就业、产业和扶贫项目的影响。根据疫情防控的阶段形势和脱贫攻坚的重点任务相继研究出台《关于切实做好新型冠状病毒感染肺炎疫情防控期间脱贫攻坚有关工作的通知》、《关于疫情防控期间强化帮扶措施夯实脱贫质量的通知》、《关于进一步做好新冠肺炎疫情防控期间脱贫攻坚工作的通知》、《关于进一步强化措施积极应对新冠肺炎疫情影响决战决胜脱贫攻坚的通知》等政策文件，发出《致全市扶贫干部的倡议书》《致全市建档立卡贫困户的一封信》，全市扶贫干部和贫困对象按照部署，积极响应号召，科学防控、齐心协力、共克时艰，坚决打赢疫情防控的阻击战和脱贫攻坚战。

二、狠抓帮扶，克服影响。疫情发生后，我市迅速下达283万元脱贫攻坚疫情防控物资补助资金，专项用于贫困对象、扶贫干部疫情防控的服务保障，完成发放口罩25万余只。采取分级分类措施，引导贫困人口有序就医，充分发挥家庭医生和挂钩帮扶干部作用，及时送医送药，全力做好贫困对象就医及用药保障；强化医疗补助政策落实，下达专项资金1000万元持续实施市精准扶贫医疗综合补助，减轻贫困人口就医就诊费用。下达公益性岗位续聘补贴资金114万元，扶持261名贫困对象续聘公益性岗位；加大贫困人口就业服务，加强劳务、用工需求的学习发布，及时推送岗位信息，保障“点对点”专门运输服务保障，加大对新招和转岗务工贫困人口的技能培训，鼓励企业复工复产后优先吸纳贫困户就近就地就业，实现贫困劳动力有序返岗就业。实施扶贫小额信贷优惠政策，对受到疫情影响不能按时还款的贫困户，允许延期半年，不做不良贷款纪录，对有新贷款需求的贫困户，加快办理流程，满足生产需要。同时，在教育保障方面，协调手机、电信运营商通过赠送移动终端设备和数据流量，化解部分贫困家庭学生无法线上教育问题；在强化住房安全和饮水安全保障方面，建立排查机制，发现一户整改一户销号一户。通过不断强化帮扶措施，最大程度降低疫情对贫困人口的影响，确保稳定脱贫。

三、聚焦重点，全力攻坚。2020年我市将按照习近平总书记在座谈会上提到的六个方面重点工作和党中央、国务院和省委、省政府的工作要求，进一步推动省委办公厅、省政府办公厅关于积极应对新冠肺炎疫情影响决战决胜脱贫攻坚十九条措施在我市落细落实，聚焦老区脱贫奔小康，不断补齐“两不愁三保障”短板，持续深化产业扶贫、就业扶贫、金融扶贫、消费扶贫、低保兜底、整村推进，巩固提升脱贫质量，深化对口帮扶协作，扎实有力推进脱贫攻坚各项政策举措落地，坚决克服疫情影响，着力防止返贫致贫，实现现行扶贫标准下建档立卡贫困对象稳定脱贫，确保如期完成脱贫攻坚目标任务，确保全面建成小康社会

周蓉:

谢谢黄副局长的介绍与发布!

接下来欢迎记者朋友就关心的问题进行提问。提问前请先举手示意，应邀提问时请自报身份。现场答问现在开始。

 

莆田电视台记者：

疫情对不少农村家庭的收入造成一定的影响，请问新冠肺炎会不会造成我市贫困人口返贫或新增贫困人口？我们采取哪些措施关注这些存在返贫风险的贫困对象？

黄金辉：

感谢记者朋友的提问。脱贫攻坚以来，我们每年都有进行贫困监测，特别新冠肺炎期间，要求挂钩帮扶干部每月入户一次，落实帮扶政策，持续建立健全返贫季度监测机制，每季度组织挂钩帮扶责任人和乡村干部进村入户开展排查，对排查发现可能出现返贫和新发生的贫困人口，及时纳入帮扶范围。在防止返贫方面，我们建立了防止返贫监测和帮扶机制，坚持事前预防和事后帮扶相结合，对排查确定的453户重点帮扶对象（其中：已脱贫但不够稳定的293户，近期受疫情影响存在返贫风险的160户）实行另册单列管理、配强帮扶责任人，每户至少配有一名科级干部强化挂钩帮扶，加强落实帮扶措施，加大政策倾斜力度，确保每个重点帮扶对象均有2项以上帮扶措施。同时，我们也督促各县区扶贫部门通过定期电话问访、随机走访等方式，跟踪了解贫困户稳定脱贫情况，掌握贫困群众的需求和困难，及时帮助解决，定期对帮扶成效和贫困户脱贫稳定性进行评估，改进方式方法，强化帮扶实效，确保稳定脱贫。

 

东南网记者：

疫情期间是如何保障贫困家庭学生居家线上学习的？

 

市教育局副局长戴明粦：

各位媒体朋友，大家好，首先我代表莆田市教育局对大家多年来关心、支持贫困家庭学生工作表示衷心的感谢。

保障贫困家庭学生的基本学习生活需求，是全面贯彻党中央有关决策部署的具体体现，是教育部门责无旁贷的责任。疫情防控以来，全市各级教育主管部门和各级各类学校始终高度重视贫困家庭学生的学习生活，切实保障贫困家庭学生顺利接受线上学习，让学生感到贴心、暖心。

下面我重点介绍教育部门推进贫困学生居家线上学习工作开展情况。

一、做好线上摸底，全面掌握情况。利用线上和线下相结合的方式，开展贫困家庭学生线上学习情况全面摸排。受新冠肺炎疫情影响，2月1日，按照教育部有关文件通知，我局下发文件，要求全市各级各类学校延期开学期间启动线上教学。为实现线上学习全覆盖，让贫困家庭学生都能跟上学习节奏，力求做到“一个都不能掉队”，要求各校利用电话随访、微信、QQ等方式，对全市中小学建档立卡贫困家庭学生的线上学习情况进行了摸排，对建档立卡等家庭经济困难学生逐一核对，了解贫困学生线上学习基本情况、学习困难和思想动态，研究分类帮扶具体措施，迅速落实，为实施有效帮扶奠定基础。

二、做好网络支撑，切实解决困难。疫情防控期间 ，根据省教育厅、省通信管理局、省广播电视局有关通知要求，在全市高三、初三年级及非毕业班学生中实施“提网速，免流量”助学行动和“网络彩虹桥”计划，为贫困学生创造线上学习条件。一是协调电信、移动、联通三大运营商面向全市建档立卡贫困学生、低保家庭学生和残疾学生提供每月20G的免费流量（连续三个月）；二是协调广电网络公司为经济困难学生家庭免费配置机顶盒，并免除疫情期间收视服务费，一定程度上减轻贫困学生线上学习资费压力，确保每一位学生能够正常线上学习。城厢区教育局给9位贫困学生赠送7部手机用于网课学习，提供2台电脑用于贫困学生上网课。截止目前，全市毕业班学生共有1184人次享受优惠政策，非毕业班学生共有2137人次享受免费赠送流量及安装宽带。三是积极资助疫情期间家庭经济困难学生。本月底我市将资助一万四千多家庭经济困难学生，其中资助建档立卡学生五千三百多人。

三、做好家校联动，进行关爱指导。“停课不停学”线上教学启动以来，全市线上教学工作平稳有序推进。对网上学习条件不足的学生，各学校因地制宜，制定“一生一策”，采取“一对一”的线上学习指导，指导困难学生进行复习指导、作业批改、心理辅导，让学生感受线上学习的乐趣，保证学生线上学习乐于学、跟上学习进度；指导家长合理安排学生的学习生活，凝聚家校育人合力，让学生和家长真切感受到学校的关心和关爱。

目前，全市高三年级已于4月7日平稳有序开学。九年级也于今天全市同步开学，其他年级线上教学工作还在平稳、有序、有效开展，学生资助各项政策正在按时间节点有效落实。下一步，我局将不断调整、完善帮扶举措，加大贫困家庭学生帮扶力度，做好线上线下教学衔接，为做好全面开学前准备工作打下坚实基础。

最后，我想特别感谢各位媒体朋友长期以来对教育工作的关心和支持！希望各位媒体朋友一如既往地关爱贫困家庭学生，为树立贫困家庭学生自立自强、奋发成才营造良好的社会舆论氛围。

谢谢大家！

 

湄洲日报记者：

就业扶贫作为贫困户稳定脱贫的有力举措之一，请问，在疫情发展趋势总体向好的形势下，我市抓好贫困劳动力务工就业方面有什么安排和措施？

 

市人社局副局长戴建忠：

谢谢你的提问。为积极应对疫情影响，我局联合市扶贫办、市财政局及时出台了《关于积极应对新冠肺炎疫情影响进一步做好就业扶贫工作的通知》（莆人社文[2020]70号），全力以赴做好疫情期间就业扶贫工作。一是加强就业指导服务。征集一批符合贫困劳动力求职特点的岗位，对暂时难以外出且有就业意愿的贫困劳动力每人推送3个以上岗位信息，引导就地就近就业。截止目前，已向全市2643名有就业能力和意愿的贫困劳动力，推送岗位信息 10414条。对已落实工作岗位，跨省、跨市就业的贫困劳动力，符合农民工返岗复工“点对点”运输服务保障的，优先纳入，集中运送到岗。二是增设公益性岗位。在原有13种公益性岗位类型基础上，拓展新增一批生态管护、乡村建设、防疫消杀等类型的临时性公益性岗位，专门用于安置贫困劳动力就业，并按我市最低工资标准1570元/月予以岗位补贴。对已安置贫困劳动力就业的公益性岗位，享受补贴政策到期的，及时予以延长至2020年12月31日，今年已对261名公益性岗位补贴到期的建档立卡贫困对象予以续聘，下达补助资金114.06万元，有效巩固了脱贫成效。目前全市共开发1631个公益性岗位，其中精准扶贫对象1052人。三是组织开展贫困劳动力职业技能培训。面向贫困劳动力和贫困家庭子女开展岗前培训和岗位技能提升培训，纳入我市2019-2021年职业技能提升行动计划，并按规定给予企业、培训机构或贫困劳动力每人次500-3600元的职业培训补贴。对参加培训的女性贫困劳动力年龄可放宽至60周岁。目前正对贫困户的培训意愿进行进一步摸底调查，已安排首批6名精准扶贫对象参加技能培训。 

 

莆田晚报记者：

最近一段时间，我市通过哪些办法和措施保障受疫情影响困难群众的基本生活？ 

 

市民政局副局长周庆平：

感谢记者朋友的提问。新冠肺炎疫情发生后，全市各级民政部门认真学习贯彻落实习近平总书记重要讲话重要指示批示精神，全面落实各级党委政府决策部署，勠力同心，共克时艰，一手抓服务机构疫情防控，一手抓困难群众救助帮扶，确保服务机构、服务对象“零感染”，确保困难群众基本生活不受影响。

疫情防控期间，我市加大对受疫情影响困难群众的救助力度，新增审批低保对象1848人、事实无人抚养儿童265名，救助保护流浪乞讨人员200多人次，发放各类社会救助资金近1.2亿元。其中：一是为4.72万困难群众按照每人100元标准发放一次性临时生活补贴472万元；二是连续三个月启动物价联动机制，为4.3万名城乡低保和3700名特困对象发放物价补贴790多万元；三是发放低保金5800多万元、特困供养金1800多万元、为6000人发放临时救助资金500万元；四是为500多名孤儿、事实无人抚养儿童发放基本生活补助资金160余万元；五是为4.2万名困难残疾人发放生活补贴920多万元、护理补贴1100多万元。

全市各级民政部门通过强化“三个力”、严把“四个关”、紧抓“五个一”，着力保障困难群众基本生活。一是强化“三个力”，做到组织到位措施跟进。组织有力。第一时间成立了疫情防控领导小组，制定防控应急预案，部署疫情防控和困难群众兜底保障工作。措施得力。新制定“低保、特困保障标准和补助水平提标”、“残疾人两项补贴动态调整”等多份文件，进一步提高政策保障力度。上下合力。组织各级民政部门开展困难群众走访探视，并多次开展督导，对存在问题进行通报、督办、跟踪，逐一销号，实行闭环管理。二是严把“四个关”，做到封闭管理有序防控。把好“入口关”。对全市31家养老机构、2家儿童福利机构全面实行封闭管理，停止一切探视活动。救助机构和精神卫生机构实行关口前移开展救助、门诊。把好“监测关”。对院民、工作人员等实行每天两次以上体温监测，建立健康台账，对工作人员实行生活工作“两点一线”防控管理方式，加强外防输入。把好“消毒关”。向民政服务机构提供口罩5万个、消毒液4吨，指导机构每天两次消毒，全市在院1100名老人、儿童和400名工作人员实现“零感染”。把好“防控关”。通过微信公众号、网站宣传、张贴宣传单等方式，向困难群众宣传疫情防控知识，对机构中回家过年的特困人员、儿童，要求坚持每天居家测量体温，并如实反馈情况。三是紧抓“五个一”，做到全面排查及时帮扶。开展一轮排查。组织各级民政、镇街、村居干部，通过电话、微信、上门等多种方式，结合疫情防控排查等，查清困难对象生产、生活及防护情况。上街开展巡查流浪乞讨情况，并及时给予救助。审批一批对象。优化简化低保、事实无人抚养儿童和临时救助的审核审批程序，保证困难群众应保尽保、应救尽救。发放一批物资。筹资100余万元，采购口罩、酒精、消毒液等防疫物资，向困难群众免费发放。搭建一个平台。引导60多家社会组织参与疫情防控，收到捐助资金2300多万元及防疫物资一批，动员社工、志愿者参与疫情防控3800余人次，让困难群众感受到社会各界人士的关爱。开设一条热线。开通市、县两级救助和心理咨询热线，并向社会公布，提供照料咨询、心理辅导等服务，共接听电话670余人次。

下一步，我们将坚决贯彻落实党中央国务院、省委省政府、市委市政府关于统筹推进常态化疫情防控和复工复产等有关决策部署，通过提标扩面，加强预警监测，强化排查和信息共享，将符合条件的建档立卡贫困户等困难群众100%纳入低保和临时救助范畴，进一步加大受疫情影响困难群众兜底保障力度。

 

福建日报记者：

疫情发生以来，我们采取了哪些措施帮助贫困对象恢复生产。

黄金辉：

新冠肺炎疫情以来，我们多措并举，对产业扶贫工作作出了安排。一是进一步强化产业扶贫。通过帮扶责任人，乡、村干部，产业发展指导员帮助有条件、有产业发展意愿的贫困户制订生产计划，尽快确定产业项目。加强技术培训指导，引导挂钩帮扶责任人帮助贫困户联系代购种苗、种畜禽、化肥、农药等生产物资，市农业农村局还开展“直奔现场、直达一线、靠前服务、靠前指导、靠前监督”春季农业生产服务活动，组建6个服务组，出动65人次，深入基层服务指导。下达中央产业补助资金2267万元，省级补助资金563万元，专项用于贫困户对象购买生产资金，有效减少了贫困户的负担，确保贫困对象有信心、有计划、有技术、有资金发展生产。二是着力推动复产、满产、超产。坚持问题导向，立足实际、实效，把重点放在提升扶贫基地产能上，在全面复产的基础上，尽快实现满产超产，健全与贫困户利益联结关系，带动贫困户发展生产和稳定增收。三是促进农产品产销衔接。通过开展消费扶贫行动，多渠道帮助贫困村、贫困群众解决农产品卖难问题，推动各挂钩帮扶单位和帮扶责任人采取以购代销、网上销售的方式开展消费扶贫，拓宽贫困地区农产品销售渠道。积极推进贫困地区农产品进商超、进食堂，建立长期稳定的产销关系。当前正值我市枇杷成熟上市时期，为进一步减少疫情对枇杷销售的影响，发挥电子商务抗疫助农的积极作用，3月20日市农业农村局联合有关部门举办“壶兰耕读·莆田枇杷”线上“枇杷节”活动，当日完成成交1500件，同时，还发动多个电商平台开展枇杷等农产品线上销售活动，并同步通过直播等方式，大力带动仙游书峰乡、城厢常太镇和涵江庄边镇等主要枇杷产区的产品销售。
