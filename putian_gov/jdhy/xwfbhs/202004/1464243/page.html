莆田市政府新闻办举行莆田市复工复产涵江专场新闻发布会（全程实录）

来源:莆田发布 时间：2020-04-10 15:49
| | | |

 

　　莆田市委宣传部四级调研员周蓉:

　　各位记者朋友，上午好。欢迎大家出席莆田市人民政府新闻办新闻发布会。

　　今天是莆田市复工复产新闻发布会涵江专场，也是莆田市复工复产第十八场新闻发布会，我们邀请涵江区人民政府副区长曾剑伟，涵江区工信局局长林光海，涵江区住建局局长凌文东，涵江区卫健局局长刘一心，请他们向大家介绍国家、省、市出台复工复产相关扶持政策的落实情况和发挥政策作用所取得的积极成效，并回答记者朋友的提问。

　　首先，请曾剑伟副区长向大家介绍相关情况。

　　涵江区人民政府副区长曾剑伟：

　　大家上午好！

　　首先，非常感谢各位媒体朋友参加今天的涵江专场发布会。下面，我简要通报涵江区复工复产情况。

　　涵江是莆田的经济重区、工业大区，2019年完成地区生产总值545.22亿元，占全市的近1/4；工业总产值突破1000亿元大关，工业总量全市第一，占全市的近1/3，连续两年跻身全国工业百强区、全省外贸转型升级示范区。可以说，涵江是全市经济社会发展的重要战场和稳定器。

　　自新冠疫情发生以来，涵江区认真贯彻落实习近平总书记重要讲话和重要指示批示精神，按照国家、省、市的决策部署，以对人民群众生命健康高度负责的态度，慎终如始扎实抓好疫情防控各项工作。在坚决打赢疫情防控阻击战的同时，涵江区根据防控进展，适时转入实施分区分级、分类分时差异化防控策略，全面吹响复工复产“冲锋号”，科学应对、精准施策，最大限度降低疫情影响，努力把疫情耽误的“春光”抢回来、缺口补上来。目前，我区已实现“九个100%”，即规上工业企业、限上商贸企业、规上服务企业、外贸企业、外资企业、平台经济企业、农业产业化龙头企业、在建省重点项目、在建市重点项目100%复工，员工到岗率除规上工业企业到岗率99.4%外，也均已实现100%目标。按照国家电网公布的企业复工复产用电量统计口径，全区企业复工电力指数已从2月24日的67.84提高到4月8日的92.04。这些数据，进一步印证了涵江复工复产的情况总体是好的。我们重点从三个方面做好服务保障工作：

　　（一）健全机制，分类指导。发挥区疫情防控指挥部统筹协调作用，提前研判谋划，用心用情服务，帮助企业坚定复工复产信心。重点做到“三个全覆盖”：一是领导挂钩全覆盖。在保持区疫情指挥部9个工作组协同作战的基础上，新成立6个疫情防控和复工复产工作服务小组，建立“四个一”挂钩服务机制，即“一家企业、一名科级以上领导、一名服务专员、一名医护人员”，推行“上门服务、专班服务、联动服务”等“定制化”服务模式，指导企业落实疫情防控主体责任，因企因策解决企业复工复产过程中的“痛点”问题。二是专业指导全覆盖。建立卫健部门挂钩联系企业“直通车”制度，成立卫生技术指导分队，深入企业一线开展“点对点”疫情防控专业指导。借助“云”系统举办专业培训，为复工企业提供远程防控培训。三是宣传引导全覆盖。组建疫情防控宣传小分队，印发《企业复工复产防控指南》，免费开通防控疫情音频视频彩铃业务，创新推行“人机联防”“二维码扫描无接触登记”等“智能化”宣传，及时发布疫情防控政策和动态。

　　（二）精准施策，打通链条。坚持“疫情防控科学有力，复工复产有序”原则，聚焦企业用工难、资金难等“五难”操作链，抓重点、破难点、疏堵点，打通企业复工复产的关键链条。重点做到“三个到位”。一是员工返岗服务到位。创新企业员工返岗复工服务方式，开通“点对点”“一站式”包机、专车接送热线，累计为22家企业包机5架次、包车66车次，接回返岗员工1675人。举办“春风行动”网络招聘活动，组织285家企业提供招聘岗位907个，累计为195家区内企业推荐1332人次。拓展闽安制造服务外包用工模式，实现企业用工调剂625人。开展闽宁协作云招聘录用22人，协助宁夏籍员工包机“点对点”运输来闽142人。二是防控物资保障到位。通过“自己产、外部调、社会筹”等各种方式，强化防控物资调度保障，全力动员支持企业转产生产口罩、防护服、额温枪等防疫物资，美德医械、佩吉服饰、亿发卫生、鑫盛电子等企业分别成为全市首家医用防护服、一次性使用医用口罩、红外额温枪的扩产转产企业；全区现有防控物资生产企业37家，口罩、防护服、额温枪日产量分别达到220万片、2000件、1600支。加强调度，保障复工企业防疫物资需求。三是金融扶持落实到位。建立企业“白名单”制度，公布两批“白名单”企业192家，重点加大信贷支持、贷款贴息、融资担保等金融扶持，累计为26家企业提供1.32亿元的信贷资金、9家疫情防控企业提供5300万元的融资担保、3家企业提供2.53亿元的应急转贷周转金。

　　（三）创新方式，优化服务。推行“企业吹哨、部门报到”服务机制，创新服务方式，深化精准服务，助力企业复产达产满产。重点做到“三个优先”：一是稳企政策优先兑现。严格落实省、市出台的有关稳企优惠政策，打通政策落实“最后一公里”。区财政累计拨付各类扶持资金8700多万元专项支持企业和项目复工复产；落实阶段性减免企业社保费政策，减轻企业负担8000多万元；发放13家企业援企稳岗返还金1349万元；投入100万元，为2019年度纳税100万元至500万元的85家规模以上工业企业投保“复工复产综合保险”；上报101家2月底前复工的规上企业当月用电奖励104.46万元；推荐上报美德医械、亿发护理、佳通纸品等5家企业申报防控物资生产设备采购补助502万元。二是涉企审批优先服务。推行“网上办、掌上办、预约办”等“不见面”审批模式，开辟企业、项目审批绿色通道，采取“容缺”审批等方式，在企业注册登记、用地审批、环保审批等方面给予优先办理。目前，全区企业设立登记时限进一步压缩至1个工作日以内，今年以来新登记注册企业510家。发放疫情防控重点保障企业应急运输车辆通行证57份，开辟“返岗直通车”22条线路。三是助企项目优先保障。抢抓国家加大项目建设支持力度的政策机遇，策划上报中央投资项目70个，申请资金65.26亿元；策划对接申报地方政府专项债券项目52个，申请资金190.3亿元，其中福厦客专18亿元资金已到位；推动申报国家疫情防控重点保障企业，已向国家发改委申报“白名单”企业9家，发布贷款需求0.99亿元。

　　当前国内疫情防控形势虽然持续向好，但国外疫情却在加速扩散蔓延，我区的“外防输入、内防反弹”的压力还不小。下一步，我们将按照上级的统一部署要求，坚持“两手抓、两手硬”，持续统筹推进疫情防控和复产达产，突出开放招商，强化项目带动，全力推动经济社会平稳健康运行，确保如期完成全年目标任务。

　　谢谢大家！

　　周蓉:

　　感谢曾副区长的介绍与发布！

　　接下来欢迎记者朋友就关心的问题进行提问。提问前请先举手示意，应邀提问时请自报身份。现场答问现在开始。

　　东南网记者：

　　当前全市促复工稳增长工作正在有序推进中，请问涵江区是如何落实国家、省、市有关复工复产惠企政策?

　　区工信局局长林光海：

　　为广泛宣传国家、省、市等政府和部门为应对新冠肺炎疫情出台的战疫惠企政策，服务广大企业及时充分用足、用好有关政策文件精神来助力企业复工复产，渡过疫情后的困难期，工信局整理印发《关于做好疫情防控期间我区企业复工工作的通知暨省、市惠企政策宣传》（第六稿），全局分为4个走访组，分别由1名科级干部及2名干部组成，按日制定走访行程，结合复工复产服务，面向全区规上工业企业发放，同时通过“涵江区工业企业工作群”、“涵江区工业企业白名单群”进一步加强政策宣传力度，提高惠企政策知晓度，指导企业运用政策申报项目，从资金和政策方面给予帮扶，主要有：

　　一是鼓励工业企业复工复产，上报101家在2月底前复工的规模企业申请当月用电奖励，每千瓦时予以补助0.05元。

　　二是支持企业包车接回员工，通过“点对点”包车服务帮助员工返厂的工业企业申报职工返岗交通补助，累计从云南、四川、贵州等地接回企业员工，预计补助金额62.82万元。

　　三是提振复工复产信心，积极响应上级号召为纳税工业企业设立“复工复产综合保险”，在市财政对纳税500万以上企业投保的基础上，进一步扩大投保范围，对辖区2019年度纳税100万元至500万元规模以上工业企业进行投保，保险期限六个月，保险费用共计约100万元，由区财政全额承担，惠及1.2万名员工。

　　四是降低中小企业融资成本，创新企业“白名单”制度，区政府已公布两批“白名单”企业192家，积极为企业争取信贷支持、贷款贴息、融资担保等金融扶持政策，由市中小企业再担保公司为中小企业提供单户担保额度500万元，疫情期间为部分防疫物资生产企业单户担保额度提高到1000万元，目前已有26家企业获得1.32亿元贷款。

　　五是全力提供防疫物资保障，多渠道全面摸排工业企业复工复产必备防疫物资需求，积极拓展采购渠道，已组织企业购买约360万个口罩用于复工复产，有力的缓解了全区工业企业疫情防控应急物资需求的缺口。

　　湄洲日报记者：

　　疫情防控期间，住建部门在推动企业复工复产疫情防控方面采取了哪些具体举措，有何成效？

　　区住建局局长凌文东：

　　疫情防控期间，为全力做好企业复工复产工作，确保疫情防控和复工复产“两不误”。我局积极贯彻落实上级会议精神，本着“疫情未退，防控不停”的工作原则，建立机制、细化措施，精心指导服务，主动排忧解难，有效打通复工复产操作链，推动企业全面复工复产，取得良好成效。

　　（一）局党组成员挂钩指导服务企业，保障“四到位”

　　为全面服务指导企业复工复产工作，我局构建“1+8”服务保障工作机制，成立了涵江区住建行业企业复工复产服务领导小组和党员先锋队，下设建筑工地、房地产企业、混凝土企业、物资保障、宣传报道共8个复工复产服务小组，由局党组成员对全区56个工地、35个房地产企业、46个房地产中介及7家混凝土企业逐个挂钩联系服务，实行“一个科级领导，一个服务小组，一支党员先锋队”服务保障工作机制，确保“四到位”，即“政策宣传指导到位、防疫措施布置到位、服务协调对接到位、复工复产返岗到位”。

　　（二）精细化管理兼顾防控安全，确保“三不误”

　　根据疫情防控实际情况，我局以复工复产为目标，疫情防控为基础，安全生产为责任，从“封闭式管理”向“精细化管控”转变，严格实行分类管理，采取“清单式”排查，做到“一手抓复工复产，一手抓防疫工作，一手抓安全生产”，确保“三不误”。一是制定文件指导复工。印发《复工复产政策汇编》宣传手册，全面指导全区建筑工地、房地产等企业有效做好复工前疫情防控准备工作，分期分批有序安排员工返岗复工。二是清单排查做好防控。深入在建工地、房地产等企业现场，聚焦人员排查管控、卫生消毒防护、集体住宿管理、员工用餐管理、现场应急预案等复工复产重点环节，落实落细各项防控措施，全面把好复工复产各个关口，严防疫情防控死角。在2月底，全区35家在建在售房地产企业、56个在建工地、46家房地产中介复工复产率均达100%，位居全市第一。

　　（三）主动对接服务解决返岗复工问题，促进“两畅通”

　　局复工复产服务小组主动靠前服务，协调保障企业防控物资、用工车辆、员工宿舍、材料供应等复工复产存在的问题和困难。一是局物资保障服务组，对企业复工复产防控物资短缺需求进行摸底，采取“点对点”、“一站式”服务，积极对接联系区疫情防控物资保障组，先后为在涵179个企业申购约24万个一次性口罩和30支测温仪，有力推进复工复产工作。二是局企业服务组主动靠前掌握企业用工需求，针对部分企业员工“返岗难”、“租房难”等问题，由局领导亲自协调相关部门、乡镇、社区（村），及时采取针对性措施，统一对接上报联系专车，先后帮助建工集团、富利建筑、飞阳建筑、中核华兴等5家企业协调解决326名返岗员工居住和出入问题，保障企业外来员工住、行“两畅通”。

　　谢谢！

　　莆田电视台记者：

　　卫健局如何发挥职能优势，促进企业有序复工复产？

　　区卫健局局长刘一心：

　　涵江区卫健局在新冠肺炎疫情防控攻坚战役中，针对企业陆续复工复产，多管齐下，全方位服务企业妥善处理疫情防控和企业复工的关系，全过程指导企业抓好疫情防控工作，助推企业安全复工复产，有序步入生产正轨。

　　一是组建指导小组。区卫健局积极响应区疫情防控指挥部安排部署，共成立了65个技术指导分队，积极深入到防控一线，共192人次深入涵江区各乡镇企业，指导企业做好防控工作方案和应急处置预案，落实企业员工健康档案，指导企业规范做好厂区人员管理、工作环境防护管理及宿舍居家防护管理等工作。

　　二是加强防控宣传。区卫健局对重点区域、重点企业、人员密集、流动性大的公共场所进行现场检查指导。在指导检查的同时，发放防控宣传海报900多套、健康防护知识折页1万多张，为300多家复工企业进行云视频培训，并提供咨询热线服务，及时帮助企业解决实际困难。

　　三是精准排查指导。对区域内企业建立返岗员工健康档案，实行逐一追踪、落实重点人员“四包一”健康监测、随访管理等措施，提示所在企业对所有外地返岗人员持续监测，一旦出现异常情况立即报告并按相关程序处置。

　　海峡都市报记者：

　　受到境外国家疫情暴发的影响，国内出口鞋企受到冲击订单锐减，请问涵江区对这些外贸型鞋企有什么举措？

　　林光海：

　　疫情在全球的快速蔓延，对我区部分比较依赖欧美市场出口的外贸企业产生了明显冲击。因此针对受新冠肺炎疫情影响，外贸出口受限、订单不稳等问题，我区着力稳外贸稳外资，为外贸鞋企应对疫情冲击提供政策支持：

　　一是建立贷款贴息机制，对列入“白名单”的鞋类出口企业于2020年4月1日至12月31日新增的流动资金贷款，单户贷款余额不超过1000万元部分，在贷款利率基础上给予年息1%贴息，进一步降低企业融资成本。

　　二是支持鞋业企业在当前国际疫情蔓延的情况下，化危机为机遇，转型生产口罩等防疫物资出口国外，全力落实防疫物资生产企业设备购置补助申报工作，按照“即达即得”的原则，简化项目申报程序，在留足基础材料的基础上，予以企业快速初审上报，为5家企业申报防控物资生产设备购置补助。

　　三是引导辖区金融机构及时拓展服务思路，在原有融资成本基础上下浮不低于1个百分点，采取自动延本展期、无还本续贷等方式加大扶持力度，同时探索以鞋类出口企业仓单、现货为质押的“存货质押”、保理业务如应收账款担保贷款等创新信贷产品。

　　四是对鞋类出口企业出现资金困难的，由市再担保公司给予每家单笔不超过500万元的担保，其中列入“白名单”的企业担保额度由500万元提高到不超过1000万元，担保费用均由市财政给予补助。

　　五是稳定企业就业岗位，受疫情影响生产经营面临暂时性困难即2020年连续两个季度应征增值税销售额或出口额同比下降20%的鞋企，列入“白名单”的鞋业企业仅需同比下降15%，对坚持不裁员或少裁员、符合条件的参保企业，可返还失业保险金。
