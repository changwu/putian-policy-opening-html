市公安局召开新闻发布会通报扫黑除恶、110报警平台等工作成效

来源:市公安局 时间：2019-01-08 10:45
| | | |

　　1月4日，市公安局召开新闻发布会，通报2018年全市公安机关扫黑除恶专项斗争工作情况和110报警平台工作情况。新闻发布会由市局党委委员、副局长、政治部主任、市局首席新闻发言人陈忠进行发布，市局指挥情报中心、刑侦支队等部门同志参加发布会。福建日报莆田观察、福建法治报、湄洲日报、福建东南网、海峡都市报、莆田电视台、莆田侨乡时报、莆田网、莆田晚报等九家驻莆田和莆田的新闻媒体记者应邀参加发布会。

　 

　　

　　

莆田市公安局新闻发布会新闻稿（全文）

各位新闻界朋友：

　　下午好！我是市公安局首席新闻发言人陈忠，欢迎各位来到市公安局新闻发布会现场。今天发布会主要是向各位简要通报２０１８年我市公安机关扫黑除恶专项斗争工作情况和110报警平台工作情况。

　　一、全市公安机关扫黑除恶专项斗争取得阶段性显著成效

　　全国扫黑除恶专项斗争开展以来，全市公安机关按照“有黑扫黑、有恶除恶、有乱治乱”总要求，积极作为，持续发力，综合施策，取得阶段性显著成果。截至2018年底，全市公安机关共打掉黑恶势力犯罪团伙33个（其中黑社会性质犯罪组织6个、恶势力犯罪集团13个、恶势力犯罪团伙14个），从中破获九类涉恶案件607起，刑拘嫌疑人1359人，逮捕789人，一审判决767人。判决黑社会性质犯罪组织3起25人，恶势力犯罪集团4起29人，恶势力犯罪团伙7起49人。

　　（一）高位推进，强化责任担当。一是党政领导高度重视。市委市政府高度重视公安扫黑除恶专项斗争，多次组织专题会议研究推进专项斗争。2018年9月10日、12月24日，市委书记林宝金、市长李建辉等市领导先后深入市、县（区）两级公安机关开展工作督导，看望慰问公安民警，肯定公安扫黑除恶工作成效，并对下一步工作提出要求。市政府拨出专项经费支持扫黑除恶专项斗争。市公安局党委把扫黑除恶与落实2018年市委市政府工作主要任务和打好防范化解重大风险攻坚战等中心工作紧密结合。副市长、公安局长陈枫要求全市公安机关把扫黑除恶专项斗争放在重中之重的位置，穷尽措施手段，务求工作实效，多次组织召开党委会及专题会议研究推进扫黑除恶专项斗争，全程跟踪督导，参与专案研究。二是建立健全工作机制。在副市长、公安局长陈枫和市局党委以及市公安局“扫黑办”的全力推动下，扫黑除恶专项斗争工作高效实施全市公检法“三长”会商机制、公安机关与纪委监委案件线索双向快速移交机制、检法机关提前介入黑恶案件侦办工作机制等协作机制，同时，全市公安机关线索摸排主体和监督责任机制、包区驻点工作机制等内部长效机制逐步建立健全，有力推动黑恶案件快侦快破、快审快判。

　　（二）专常结合，强化摸排深挖。着眼于重点领域、重点行业和重点地区存在的突出问题，采取日常公安工作摸排和上级流转线索核查相结合，专业队伍分析研判和群众检举揭发相结合，讲求策略，深挖细查，有效打击了一批黑恶犯罪。2018年，全市公安机关共收到中央、公安部、省公安厅督导线索165条，全部核查到位，有效核查率达100%。全市公安机关自查深挖线索885条，目前有效核查率达92.3%。通过部督、省督线索核实，查实涉黑犯罪案件2起，涉恶犯罪案件12起，自查深挖线索查实涉黑恶案件145起，从中破获城厢林某程等涉黑案件以及涵江区李厝村把持村委会涉恶窝案等一批有影响的黑恶案件。全市公安机关坚持广泛发动群众检举揭发，共收到群众举报线索261条，发放举报有功人员17名奖励金16.5万元。

　　（三）精准发力，强化重点打击。一是强化把主攻方向瞄准群众深恶痛绝的黑恶势力和反映强烈的热点问题。全市公安机关不断夯实扫黑除恶专项斗争基础，有针对性地开展了以套路贷、砂霸、老人会把持村委会3类犯罪为重点的专项打击行动，以黑恶案件快侦快破、快诉快判为主要内容的公检法部门联动黑恶案件审理判决推进活动。2018年，市县（区）两级法院完成我市3个黑社会性质组织、4个恶势力犯罪集团、7个恶势力犯罪团伙共14个黑恶犯罪势力的审理判决工作。12月，集中完成审理判决12个。二是强化打击黑恶犯罪与反腐“拍蝇”相结合。配合协同纪委监委同步办理一批涉及“保护伞”案，与纪委监委双向移送一批涉案线索。2018年，全市公安机关配合纪委监委监视居住犯罪嫌疑人16名，刑拘90名，逮捕63名，起诉42名。目前已破获涉及农村基层村干部以及其他公职人员犯罪案件49起，查处涉案公职人员10人、村干部17人。

　　（四）综合打击，强化乱象整治。市公安局坚持打击与治理乱象相结合，主动延伸治乱，推动重点地区、行业综合治理。针对较为突出的“套路贷”犯罪、矿产领域犯罪、电信诈骗犯罪输出等区域性治安乱象问题，先后14次以函告的形式有针对性地向相关职能部门和地方党委政府提出加强管理的意见和建议。一是开展“套路贷”新型犯罪集中打击行动。打掉“套路贷”涉黑组织1个、涉恶犯罪集团2个，抓获“套路贷”犯罪嫌疑人55人。二是开展电信诈骗犯罪挂牌专项打击行动。仙游县公安局根据治乱任务较重地区整治工作方案要求，全力整治电信诈骗犯罪活动，到2018年底，仙游县全县电信网络诈骗案件破案数和打击数分别比升5.0%和10.8%。三是严厉整治境外犯罪突出问题。涵江公安分局针对江口辖区居民境外犯罪突出问题，实行“一挂两督”责任机制，摸排出江口籍居民境外受害线索6起7人，其中1起绑架案件已经由市局刑侦支队立案侦查。同时协同区镇两级党委政府和侨联、境外同乡会等组织，广泛宣传发动，强化重点人员管控，居民境外犯罪活动已明显减少。

　　2019年，全市公安机关将继续坚持利刃扫黑、铁腕除恶、重拳治乱的工作思路，把重点领域犯罪和深挖保护伞作为全年的主攻方向，努力推进扫黑除恶专项斗争取得更大成绩，用看得见的工作成效回报党和人民群众对公安工作的期待。

　　二、市公安局组织开展110系列宣传活动

　　今年1月10日是全国第33个“110宣传日”，根据公安部的统一部署，今年全国各地110宣传活动主题是“警民牵手110，共创平安迎大庆”，全市公安机关围绕这一主题也将开展系列活动。

　　（一）爱护110，最大限度发挥110功效

　　莆田110成立于1997年，2004年实现110、122、119“三台合一”，提供多部门一站式救助、多语言警务援助及短信报警业务的综合服务平台。110报警服务台24小时全天候受理公众紧急电话报警、求助、举报和对公安机关及其人民警察正在发生的违法违纪或者失职行为的投诉。目前，社会上对于110工作的职能范围仍存在认识偏差，110接报的警情中，骚扰、虚假、无效警情占了相当一部分，极大地占用了110这一宝贵的紧急公共资源。2018年，110总话务量857540起，日均接警量2349起；有效报警总数197045起，仅占总话务量22.98%；无效报警总数660495起，占总话务量77.02%。

　　近年来，我们积极与相关职能部门、媒体进行配合，加强对110报警服务台受理范围的宣传力度，明确公安职能，引导群众正确拨打110。同时加大对恶意扰警、虚假报警、恶意举报等违法犯罪行为的打击力度，将打击结果及时向社会公开，努力形成“教育一个，带动一片”的良好社会氛围，让我市的110能健康发展。

　　（二）政府主导，推进110警情分流

　　多年来，莆田110接处警以反应迅速及妥当处置赢得绝大多数群众的广泛信赖。群众遇到各种困难，第一反应就是拨打110，110因此承担大量非警务警情处置工作，给基层公安机关带来很大的工作压力。2018年，110接报有效警务警情151694起，占有效报警数的76.98%，非警务警情45351起，非警务警情占有效报警数的23.02%。

　　2016年，省政府办公厅出台《福建省12345便民服务平台监督管理办法》，立足于开展非警务警情分流处置工作，让非警务警情能得到及时、精准、高效的处置，让基层公安民警从大量的非警务警情中脱身出来，有更多精力来打击犯罪，服务群众，让政府相关部门更好地服务群众。“12345，服务找政府；公安110，为民保安宁”新理念应该早日成为全社会的共识。

　　（三）苦练内功，促进110提质增效

　　近年来，为更好地服务群众，莆田110大力加强扁平化指挥体系建设，着力构建以“全局部署为基础、协同作战为手段、快速反应为目标”的扁平化指挥模式，全面完善重大突发事件处置统一指挥调度的应急处置机制，建立与武警部队、铁路公安机关、高速交警、13支反恐作战单元等部门的日常联勤制度，在突出以快制快，严打各类现行违法犯罪等方面，取得重大成效。下一步，我们将加快110信息化建设，进一步规范接处警，完善非警务警情处置机制，促进110提质增效，在维护社会治安秩序、抢险救灾、紧急求助等方面发挥更大的作用。

　　各位新闻界朋友，110宣传日马上就要到了，1月10日10时，市公安局在全市范围内开展110宣传活动。市局在镇海街道正荣财富广场，仙游县局在鲤城街道鲤中步行街，荔城分局在拱辰街道馨宜新天地广场，城厢分局在凤凰山街道万达、凤凰山广场、龙桥街道绶溪公园广场等地同步开展，涵江分局在涵西街道隆恒财富广场开展，秀屿分局在莆田火车站开展宣传活动，北岸分局在忠门镇农商银行、东埔镇农贸市场、山亭镇市场路口等地开展宣传活动，借此机会，公安机关热忱邀请各媒体记者及社会各界到场参与。

　　借此机会，我代表莆田公安机关衷心感谢驻莆田及莆田各新闻媒体一如既往支持、监督公安工作，帮我们出主意、想办法，更好地推动公安工作创新发展，为全市公安机关更好地守护莆田新时代美好生活提供强有力的舆论支持。

　　我们今天的新闻发布会就到这里，感谢大家对莆田市公安局的支持，谢谢大家！
