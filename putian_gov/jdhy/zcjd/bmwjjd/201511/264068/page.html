《关于建立病死畜禽无害化处理机制的通知》政策解读

来源:莆田市农业局 时间：2015-08-28 17:20
| | | |

2015年4月21日，莆田市人民政府办公室印发《关于建立病死畜禽无害化处理机制的通知》（莆政办〔2015〕54号）（以下简称《通知》），根据《莆田市人民政府办公室关于加强政策解读工作的通知》（莆政办[2015]99号）要求，为深化政府信息公开，充分发挥政策效应，现将《通知》重点内容解读如下：

一、《通知》出台背景

2014年，我市生猪存栏59.7万头，出栏117万头，家禽存栏710万羽，出栏2646万羽。当前，我市畜牧业现代化水平仍不高，病死畜禽数量还较大，涉及范围较广，对病死畜禽若处理不当，不但影响畜牧业生产安全、食品安全和公共卫生安全，还会造成环境污染，甚至带来系列社会问题，因此，有效解决病死畜禽无害化处理问题已经成紧迫任务。

党中央国务院、省委省政府和市委市政府均高度重视病死畜禽无害化处理工作。2014年10月，国务院办公厅印发《关于建立病死畜禽无害化处理机制的意见》（国办发[2014]47号）、2015年1月，省政府办公厅印发《关于建立病死畜禽无害化处理机制的通知》（闽政办[2015]5号）, 为今后一个时期做好病死畜禽无害化工作指明方向；根据国家和省里文件，结合我市实际，2015年4月，我市也紧接出台《通知》，对建立我市病死畜禽无害化处理机制工作作全面部署，以保障食品安全、公共卫生安全，促进养殖业健康发展，推进生态文明建设。

二、《通知》对病死畜禽无害化机制确定的原则目标

按照市委市政府提出的“业主负责、属地管理、就地处理”的病死畜禽无害化处理原则，坚持统筹规划与属地负责相结合、集中处理与自行处理相结合、政府监管与市场运作相结合、财政补助与保险联动相结合，加快构建我市的病死畜禽无害化处理机制。《通知》要求各县（区、管委会）2015年5月底前，制定本行政区域病死畜禽无害设施建设规划，2016年底前基本实现我市各县（区、管委会）病死畜禽无害化处理。

三、《通知》对无害化处理责任的进一步明确

（一）进一步明确病死畜禽无害化处理主体责任。《通知》进一步明确，从事畜禽饲养、屠宰、经营、运输的单位和个人是病死畜禽无害化处理的第一责任人。具体主要包括：一是要及时对生产经营活动中产生的病死畜禽及时进行无害化处理，不得随意抛弃、收购、贩卖、屠宰和加工制售；二是在生产经营活动中，发现病死畜禽，要及时报告当地乡镇政府（街道办事处）和畜牧兽医部门，以便科学处置，进行疫病调查，防止疫情扩散传播。

（二）进一步明确属地管理责任。《通知》进一步明确属地管理责任的落实，各县（区）政府（管委会）、乡镇政府（街道办事处）对本地区病死畜禽无害化处理负总则，政府分管领导是具体责任人，要统筹规划、统一领导本行政区域内的病死畜禽无害化处理工作。江河、湖泊、水库等水域发现的病死畜禽，由所在地县级政府组织收集处理;在城市公共场所以及乡村发现的病死畜禽，由所在地街道办事处或乡镇政府组织收集处理。在收集处理的同时，要及时组织力量调查病死畜禽来源，做好病死畜禽的追踪溯源和依法调查处理结果的公布。

四、《通知》对推进无害化收集处理体系提出的措施

根据国家、省的精神要求，结合我市实际，《通知》就推进我市无害化收集处理体系主要提出以下措施：一是各县（区）政府(管委会)应于2015年5月底前，制定本行政区域内病死畜禽无害化设施建设规划，确保2016年底前基本实现本辖区病死畜禽无害化处理。二是所有规模养殖场（小区）、养殖专业合作社、定点屠宰厂（场）都必须建设与养殖或屠宰规模相适应的无害化处理设施，对其产生的病死畜禽及其产品实行业主负责、就地处理。三是各县(区)政府（管委会）以及乡镇政府要科学规划、合理选址，配备收集、装运、处理设施设备，建立主要针对散养病死畜禽的公益性、区域性专业集中无害化处理场所。畜禽可养乡镇以及木兰溪、萩芦溪主干流流经的乡镇政府（街道办事处）必须建设病死畜禽无害化集中处理公共设施。四是有条件的地方可探索利用现有医疗垃圾处理厂（点）、垃圾焚烧发电厂等对病死畜禽集中无害化处理。

五、《通知》对强化监管体系提出五条措施

一是强化队伍建设。《通知》要求各地要进一步调整充实病死畜禽无害化监管人员，切实加强基层执法力量；同时在强化联合执法基础上，试点推行基层农业、食药监、公安等部门综合执法。二是健全协调联动。进一步健全部门、跨地区的信息互通、隐患互排等协调联动机制，同时，加强行政执法与刑事司法的衔接，发现重大案件线索的，公安部门提前介入。三是完善工作措施。支持畜禽规模场、屠宰场、集中无害化处理场（点）等安装视频监控设备；鼓励乡村、社区（居委会）等基层群众对违法行为监督举报；对涉及病死畜禽违法企业，列入“黑名单”并公开曝光。四是加大执法打击。农业、食药监、公安、环保、工商、水利等部门要严格依照法定程序严厉打击随意抛弃病死畜禽，屠宰、加工制售病死畜禽产品等违法犯罪行为；各级行政机关发现可能涉嫌犯罪的、需要追究刑责的案件，要及时移送公安机关。五是生态文明先行。巩固近几年来我市畜禽污染整治成果，《通知》要求各县区政府（管委会）、乡镇政府对应拆除关闭而未按时拆除关闭的畜禽养殖场（户）、反弹复建的养殖场（户）要坚决全面予以拆除关闭；对于拟保留规模畜禽养殖场改造后仍不能达标排放的，也要予以拆除关闭。

六、《通知》提出的主要支持保障措施

一是对养殖环节病死猪无害化处理补助全覆盖。将2012年起实施的针对规模场（小区）养殖环节病死猪无害化处理的补助范围扩大到生猪散养户，即全市范围所有按照规定进行无害化处理的病死猪（不含强制扑杀和流产后的死胎、木乃伊等）均为补助对象。养殖场（户）产生的病死猪应及时向当地乡镇政府和畜牧兽医部门报告，经当地乡镇政府指定人员按照程序确认后，按照“谁交出（病死猪）、补贴谁，谁收集处理、补助谁”的原则，对养殖者和集中无害化处理者给予每头80元的补贴补助；二是对病死畜禽无害化处理项目补助。市级财政对取得《动物防疫条件合格证》的规模畜禽场和公共集中无害化处理场点安装视频监控设备的、县乡两级政府兴建公共集中无害化处理场（点）的，将予以项目建设补助；对投入运转的公共集中无害化处理场（点）每年还给予适当运行管理经费补助。目前的补助标准是：安装视频监控设备的给予1万元/每场（点）的一次性建设补助；兴建公共集中无害化处理场（点）（化尸窖每口容积100m3以上）的，给予一次性10万元/口的建设补助；投入运转的公共集中无害化处理场（点）给予3万元/年的运行管理经费补助。以上项目补助均实行先建后补，项目实施单位可在每年8月底前向所在地县级农业主管部门和财政部门提出资金补助申请。三是对县级财政支持保障提出明确要求。《通知》要求各县区政府（管委会）要将本辖区病死畜禽无害化处理体系建设、监管体系建设所需经费纳入本级财政预算，养殖环节病死畜禽无害化处理应承担的配套补助以及现场确认所需工作经费也应纳入本级财政预算，同时要将集中无害化处理设施设备纳入农机购置补贴范围。四是推进畜禽保险工作。按照“政府引导、市场运作、自主自愿、协同推进”原则，全面推进畜禽保险工作，落实保费补贴，扩大保险覆盖面，提高参保率，做到应保尽保。同时建立健全保险和病死畜禽无害化处理联动机制，不能确认无害化处理的，保险机构不予赔偿。五是其他配套措施。主要是在用地、用电和税收方面的优惠措施。如：无害化处理设施建设用地按照土地管理法律法规的规定，优先予以保障；从事病死畜禽无害化处理的单位和个人，按规定享受国家有关税收、用电优惠。
