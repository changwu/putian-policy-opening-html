《莆田市海上养殖设施建设技术要求（试行）》政策解读

来源:市海渔局 时间：2021-09-02 16:22
| | | |

一、主要依据

根据《莆田市海上养殖转型升级行动方案》（莆政办〔2021〕36号）和《福建省设施渔业项目建设技术要求（2018）》（闽海渔〔2018〕214号）等有关文件要求，结合我市实际制定出台《莆田市海上养殖设施建设技术要求（试行）》。

二、目标任务

推进生态渔业发展，优化产业布局，落实海洋生态环境保护要求，通过规范海上养殖设施升级改造设施原料、产品质量、检测要求、结构要求、锚固系统等标准，促进“渔旅结合”，统筹兼顾海上养殖规模发展、景观建设、安全生产，保障海上养殖转型升级行动任务目标如期完成。

三、主要内容

（一）全塑胶养殖渔排

1.结构及布局要求：包括网箱框架、浮球、网衣、固泊设施，网衣深度不小于3米或相应配套的养殖笼。网箱片区布设合理，有相应的间距，固定装置水下锚泊设施，根据实际需要配备安全指示标识等。

2.规模及数量要求：单个申请业主全塑胶养殖网箱数量不少于20口，单口网箱框架适宜面积16－100平方米。根据实际养殖情况单口面积可作适当调整，但不少于12平方米。

3.分类及技术要求：全塑胶养殖渔排分为管式塑胶渔排和板式塑胶渔排，网箱框架均为方形。如下：

⑴管式塑胶渔排:由支架、走道垫片、浮球等组成。

支架管材的外径不小于110毫米，壁厚不小于10毫米；走道垫片的宽度不小于50厘米，厚度不小于30毫米；采用圆柱形塑胶浮球，其直径不小于50厘米、长度不小于90厘米，数量配置需满足渔排整体浮力要求。

⑵板式塑胶渔排:由走道板、浮球等组成。

走道板的宽度不小于40厘米，厚度不小于75毫米，四周壁厚不小于10毫米；采用圆柱形塑胶浮球，其直径不小于50厘米、长度不小于90厘米，数量配置需满足渔排整体浮力要求。

（二）深水抗风浪养殖网箱

1.结构及辅助设施：包括网箱框架、网衣、固泊、养殖操作平台（根据实际需要而建）等，并配置相应养殖操作平台和根据实际需要配备工作船、洗网器械、发电机组、投饵和集排污等设施。

2.规模及数量要求：深水抗风浪养殖网箱框架为圆形、方形或其它多边形，建设规模4口以上，网衣深度不小于5米。

3.分类及技术要求：

⑴40米≤周长<60米:单口网箱框架内侧周长40米至60米，采用双浮力管设计，浮管外径不小于250毫米，壁厚不小于18毫米;走道安装单侧或双侧扶手(指走道内外侧)，扶手高度不低于70厘米，扶手固定桩间距不大于2米，安装双管扶手、扶手管直径不小于90毫米；走道铺设塑胶脚板，宽度不小于50厘米，厚度不小于60毫米，塑胶脚板间隙不大于20毫米。

⑵60米≤周长<90米:单口网箱框架内侧周长60米至90米,采用双浮力管设计，浮管外径不小于315毫米，壁厚不小于22毫米;走道安装单侧或双侧扶手(指走道内外侧)，扶手高度不低于70厘米，扶手固定桩间距不大于2米，安装双管扶手、扶手管直径不小于90毫米；走道铺设塑胶脚板，宽度不小于80厘米，厚度不小于60毫米，塑胶脚板间隙不大于20毫米。

⑶90米≤周长<120米:单口网箱框架内侧周长90米至120米,采用双浮管设计，浮管外径不小于355毫米，壁厚不小于22毫米;人行道安装单侧或双侧扶手(指人行道内外侧)，扶手高度不低于70厘米，扶手固定桩间距不大于2米，安装双管扶手、扶手管直径不小于90毫米；走道铺设塑胶脚板，宽度不小于80厘米，厚度不小于60毫米，塑胶脚板间隙不大于20毫米。

⑷120米≤周长<150米:单口网箱框架内侧周长120米至150米，采用双浮管设计，浮管外径不小于400毫米，壁厚不小于27毫米；走道安装单侧或双侧扶手(指人行道内外侧)，扶手高度不低于70厘米，扶手固定桩间距不大于2米，安装双管扶手、扶手管直径不小于90毫米；走道铺设塑胶脚板，宽度不小于100厘米,厚度不小于60毫米，塑胶脚板间隙不大于20毫米。

⑸养殖操作平台要求:养殖操作平台面积不小于60平方米（包括管理房和工作平台）。以塑胶浮球或浮力管提供浮力。用塑胶浮球建设的，浮球直径不小于50厘米，长度不小于90厘米；以浮力管建设的，浮力管口径不小于400毫米。平台整体浮力能够满足安全生产需要。

（三）生态养殖网箱平台

1.结构及辅助设施：由深水抗风浪养殖网箱、全塑胶养殖渔排、养殖操作平台等组合构建，根据实际需要配备工作船、管理房、活动平台和集排污等设施，除满足生态养殖功能外，还可拓展渔业休闲活动等。

2.规模及数量要求：深水抗风浪养殖网箱、全塑胶养殖渔排、养殖操作平台等组合成的总面积不小于3000平方米。

（四）筏式吊养浮球

筏式吊养浮球包括:贝类吊养（鲍鱼、牡蛎、贻贝、扇贝等）和藻类筏式吊养（海带、紫菜、龙须菜等）使用的浮球，有球形、圆柱形两种浮球，规格如下：

四、建设布局要求和质量安全技术要求

（一）海上设施建设布局要求

海上设施建设布局要符合海洋及养殖有关功能规划，预留航道，保持适宜设施密度，养殖区之间保持充足间隔，保证水流交换和船舶航行畅通等。

（二）质量安全技术要求

塑胶渔排、深水抗风浪网箱材料为高密度聚乙烯（HDPE）原材料;塑胶材料浮球为高密度聚乙烯（HDPE）、聚对苯二甲酸乙二醇酯（PET）原材料，浮球填充物不得使用聚苯乙烯(EPS)泡沫物质。

注意：产品需在主框架及浮球明显位置标注购买单位名称、出厂日期及使用期限，格式为购买单位名称+出厂日期+使用期限。

五、编制说明

本技术要求主要采纳《福建省设施渔业项目建设技术要求（2018）》（闽海渔〔2018〕214号）相关技术指标,参考有关资料，结合有关县区反馈意见和专家评审意见研究制定。
