《莆田市“十四五”现代服务业发展专项规划》政策解读

来源:市府办 时间：2022-12-05 17:15
| | | |

　　一、发展环境 

　　（一）发展基础 

　　我市现代服务业增加值占GDP比重稳步上升，产业规模不断扩大，其中生产性服务业实现了全面跃升，生活性服务业也稳步复苏。2020年全市服务业增加值达1155.98亿元，占2020年全市GDP比重43.7%，服务业增加值增幅5.8%，高于2020年全市GDP增幅2.5个百分点。 

　　（二）存在问题 

　　服务业供给能力仍待提升。2020年，莆田市服务业增加值占GDP比重43.7%，低于全省平均水平（47.5%）3.8个百分点，仍有较大的提升空间。服务业内部结构亟需优化。莆田市服务业发展总体层次不高，传统服务业占第三产业增加值比重达52%，新兴服务业比重偏低。服务业集约化水平低，企业规模偏小。莆田市目前服务业集中、集约、集聚发展水平不高，影响力大、关联度高、带动作用强的旗舰型龙头企业相对较少。服务业政策制度有待优化。现有现代服务业规划、政策更多围绕全产业做大、企业育强，重点业态培育导向性不够突出。服务业高端技术人才匮乏。受莆田市城市发展环境、产业升级空间、对外开放程度等诸多因素制约，造成莆田市人才引进难、流出多，高层次人才和技能型人才与需求相比均存在短缺，直接制约莆田市现代服务业的发展。 

　　（三）发展形势                                 

　　从地理位置看，莆田地处福建中部，是海上丝绸之路建设核心区，是承接厦门、福州以及海西地区先进制造业和服务业转移的重要节点。从社会发展趋势来看，国际分工和国内产业结构的调整、数字经济发展、新模式新业态的产生都在推动现代服务业的快速前进。 

　　同时，我市发展仍存在一些短板和弱项，产业发展所需资金、人才、技术等要素外流压力进一步加大，莆田具有全球竞争力和品牌影响力的龙头企业数量不多，现代服务业急需的国际化、高层次、复合型人才队伍不足，整体缺乏足够的市场定价权和标准话语权，国际化程度需要进一步提升。 

　　二、发展目标                    

　　“十四五”时期莆田市服务业发展总体规划目标为：到2025年，服务业增加值由2020年的1156亿元提高到2000亿元，年均增长9.5%，服务业增加值占GDP比重由2020年的43.7%提高到48.5%，提升4.8个百分点。 

　　三、优化服务业空间布局 

　　紧紧围绕莆田产业发展定位，秉承“优化空间布局、明确产业定位、创新体制机制”的发展理念，优化现代服务业区域功能性布局，引领产业协同高效发展，优化产业空间布局。承接莆田市跨溪南进的发展战略布局，培育一批具有核心竞争力的现代服务业产业集群和企业群体，走提质增效的发展道路，构建“一核两带多节点”现代服务业空间发展格局。 

　　（一）一核引领。即主城区现代服务业核心区，主要位于城厢区和荔城区，是莆田现代服务业的核心功能区。 

　　（二）两带协同。即妈祖文化服务产业发展带和北部山地服务产业发展带。 

　　（三）多节点支撑。即着力推动一批重点现代服务业产业集群化发展。包括总部经济产业集群、电子商务产业集聚区、西北部山脉景观文旅核心区、工业旅游特色集聚区、“三湾一屿”港口现代物流集群、莆田市“中国文创之都”核心区。 

　　四、创新发展生产性服务业 

　　（一）电子商务 

　　到2025年，实现全市限上电商企业数达800家，全市限上电商企业网络零售额达525亿元的目标。完成优化莆田市电子商务发展环境，大力发展农村电商、跨境电商等重要领域，积极探索培育电商新业态，加快推进莆田市电子商务服务体系提质升级等主要任务。重点推进跨境电商体系建设工程、直播新业态建设工程、农村电商体系完善工程。 

　　（二）金融服务 

　　至2025年12月末，实现金融机构存款余额达到3500亿元，贷款余额达到3300亿元。完善、规范引金机制，持续深化多元化的现代金融组织体系。加快金融业数字化发展，促进传统金融服务向移动化、智能化的金融服务转变。加强对制造业科技创新、转型升级的金融支持，特别加强对工业互联网重点项目的金融支持力度。重点落实普惠金融重心下沉工程、绿色金融体系完备工程、科技金融市场规范工程。 

　　（三）总部经济 

　　到2025年，力争实现全市新增各类总部企业25家。结合莆田基础条件和特点，分阶段确定莆田市总部经济发展的思路和目标，完善总部经济统筹规划，强化地方上下沟通联动，同时优化总部企业招商、营商环境，提升企业配套服务质量，全面推进莆田市总部经济发展。重点支持总部企业引进培育工程、总部经济发展环境提升工程。 

　　（四）现代物流 

　　到2025年，力争全市货运量突破6700万吨，港口货物吞吐量突破9400万吨，培育3-5家省级以上示范物流园区。加快构建“立足市域、辐射区域、联通周边、面向国际”的现代物流体系，推进物流港、智慧物流产业园、智能仓储物流中心等综合性物流园区建设，构建“综合性物流园区-专业物流中心-配送中心”三级配送体系。培育壮大物流市场主体。推进物流智慧化建设，加强数字物流基础设施建设，加快物流要素数字化。重点督办港口物流数字化工程、冷链物流提质扩容工程、电商物流创新协同工程。 

　　（五）科技信息创新培育工程 

　　到2025年，国家创新型城市格局初步形成，R&D经费投入年均增长率20%以上，R&D经费投入强度达到全省平均水平，国家高新技术企业达到400家。培育壮大科技信息服务主体，加强高新技术企业培育扶持，实施高新技术企业倍增计划；加快科技服务平台建设，鼓励以企业为主体牵头建设重点实验室、公共实验室及创新综合体等研发平台；加快推进信息技术服务高端化，打造一体化城市智能感知体系。重点完成公共研发服务体系建设工程、技术转移服务体系建设工程、创业孵化服务体系建设工程、科技服务集聚区打造工程。 

　　五、提升发展生活性服务业 

　　（一）商贸流通 

　　到2025年，实现社会消费品零售总额突破2200亿元，年均增长6.5%。围绕居民消费升级需要，以提升便利度和改善服务体验为导向，构建与莆田经济社会发展相匹配的便捷、安全、多元和可持续发展的现代商贸服务体系。鼓励商贸流通业态与模式创新，打造多业态聚合示范商圈，创新消费数字化新模式。加强社区和农村生活消费基础设施建设，完善社区农村消费环境，推动农村消费梯次升级。重点推动特色街区商圈建设工程，大力支持传统消费升级、培育新型消费服务工程。 

　　（二）文化旅游 

　　到2025年，旅游总收入突破350亿元，年均增长17.56%；新增3A级景区10家。统筹保护莆田市旅游资源，重点打造滨海、沿溪、名城、山脉等四大主题景观带，形成多核协调发展的莆田文旅体系。持续推进文化和旅游深度融合，打造“文旅+”跨维度融合延伸工程，探索文旅产业全新增长极。着力提升莆田文旅消费品牌知名度，促进文旅产业消费升级。推动莆田景区现代化基础设施建设、产品创新和项目升级，推进文旅产业智慧转型。重点打造滨海文化景观带、山水生态景观带、城市历史景观带等工程。 

　　（三）家政服务 

　　到2025年，培育2-3家家政服务示范企业，形成家政服务业市级知名品牌。进一步满足人民群众日益增长的家政服务多元化、个性化需求，引导和培育一批家政服务示范企业，支持家政企业进社区。建立家政服务诚信体系、健全家政服务人员培训体系、完善家政服务行业监管机制，进一步规范家政行业发展，引导更多家政企业向规范的员工制家政企业转型升级。重点落实家政服务规范化提升工程、家政服务行业信用提升工程以及家政从业人员素质提升工程。 

　　（四）健康服务 

　　到2025年，健康旅游示范基地初步建成，覆盖“全人群、全生命周期、疾病全过程”的医疗健康服务体系和特色鲜明的健康产业新格局初步建立。深入实施“健康莆田2030行动计划”，全面提升居民健康素养水平。鼓励建设高端健康服务集聚区。深入推进“三医”联动改革。助力民营医院健康规范发展。依托莆田特有的文化和历史积淀，以及中药材等独特优势，促进康养、医养多业态融合发展。重点完成高端健康医疗服务集聚工程、社区养老综合性设施提升工程，持续推动康养产业优质发展工程。 

　　（五）房地产 

　　坚持“房住不炒”定位，“十四五”期间商品房销售面积达到2500万平方米。加强政策市场双向化调控，贯彻落实中央及省委省政府关于住房和房地产重大决策部署，推广政策性租赁住房模式，通过科学规划、合理配置，充分发挥区域性特色打造精品化、精细化房地产集群，完善住宅周边公共配套，维护莆田房地产市场稳定发展。重点落实政策性人才住房工程、房价多方位监督工程，鼓励支持产业多元化发展工程，从而打造高品质、多功能、可持续的、稳步发展的莆田房地产体系。 

　　六、推动服务业高质量发展 

　　坚持创新驱动，塑造发展竞争优势。坚持创新在现代服务业发展中的核心地位，深入实施科教兴市、人才强市战略，健全创新创业体系，优化创新创造环境，形成全社会大众创业、万众创新的潮涌，打造莆田市现代服务业竞争新优势。 

　　产业融合发展，发展壮大实体经济。推动现代服务业与制造业、农业深度融合，深化服务业内部融合发展，构建交叉渗透、相融相长、耦合共生的产业生态系统。 

　　产业集聚发展，优化服务产业体系。围绕现代物流、电子商务、商贸流通、文化旅游、健康养老等领域，聚集要素资源，大力促进现代服务业集聚化发展，优化现代服务产业体系。 

　　推进对外开放，打造高质开放平台。健全开放型经济新体制，实施更大范围、更宽领域、更深层次对外开放，打造高质量开放平台，争创国际合作和竞争新优势。
