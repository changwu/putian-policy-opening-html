福建省供销社关于加快推进全省系统电子商务发展的实施意见

来源：本网 时间：2015-09-10 16:33
| | | |

各市、县（区）供销社，省社各直属单位：

为全面贯彻落实《中共中央国务院关于深化供销合作社综合改革的决定》（中发〔2015〕11号）精神，切实抓好《中华全国供销合作总社关于加快推进电子商务发展的意见》（供销经字〔2015〕1号）和《福建省人民政府关于进一步加快电子商务发展的若干意见》（闽政文[2014]157号）的贯彻落实，结合我省系统的实际，现就加快推进我省供销社系统电子商务发展，提出如下实施意见:

一、指导思想和工作目标

（一）指导思想。深入贯彻中央《决定》精神，“顺应商业模式和消费方式深刻变革的新趋势，加快发展供销社电子商务，形成网上交易、仓储物流、终端配送一体化经营，实现线上线下融合发展”。按照全国总社和省政府加快发展电子商务的总体要求，结合我省各级供销社的实际情况，坚持为农服务宗旨，树立互联网思维，掌握电商本领，本着“省社指导、设区市社推动、县级社主导、企业主体、多方参与、市场运作”的工作思路，充分发挥供销社传统产业和经营网点优势，以开拓农村电子商务和发展农产品电子商务为重点，大力培育电子商务市场主体，加快基层经营服务网点信息化改造，加强以县级社为重点的不同类型电子商务平台的建设与融合，全力构建具有供销社特色的电子商务经营服务体系。

（二）工作目标。经过3—5年的努力，在全省系统建立起以全国系统电子商务平台和区域型、专业型平台相互融合，以县级社为主导，社有企业和基层社及农民专业合作社为主体，多方参与的具有供销社特色的电子商务经营服务体系，成为深化供销社综合改革的重要内容、推进农村流通现代化的重要方式、搭建为农综合服务平台的重要支撑。全省每个县级社均要组建供销社有实际控制力的电子商务企业主体，并力争成为各地电商龙头企业，与全国总社和国内大型知名电商平台进行深度融合与合作，使其能够进行产品的线上线下交易，成为推进全省供销社电子商务发展的重要平台和支撑。在抓好全国总社首批5个电子商务示范县（市）的基础上，力争在全省系统创建10个全国总社电子商务示范县（市、区）、20个省社电子商务示范县（市、区）和30个全省系统电子商务示范企业。按照总社要求，到“十三五”期末，全系统流通企业电子商务应用率力争达到80%以上，基层经营服务网点信息化改造比例力争达到70%以上，电子商务交易规模占全系统销售总额比重力争达到40%以上。

二、主要任务

（一）突出抓好县级社电子商务发展

围绕全国总社提出的县级供销社发展电子商务“五个一”实施方案的要求，各县级社要结合实际情况，按照“积极稳妥、主动作为、需求导向、市场运作、务求实效、重在持续”的原则，明确目标，细化措施，强化落实。

1、培育一个市场主体。每个县（市、区）社要依据自身条件，整合系统内外相关资源，细化指导，组建一个供销社有实际控制力的混合所有制电子商务公司，使之成为县级供销社发展电子商务的重要抓手和依托。公司负责与全国供销社电子商务平台（以下简称全国平台）或其它电商平台进行对接，挖掘和组织本地特色产品，尤其是特色农产品，上线交易，并根据全国平台或其它电商平台的统一要求，负责产品线下包装、物流配送、售后服务等方面工作，成为当地电子商务的运营商。有条件的地方，可建立县域物流分拣配送中心，构建起由县到村的商品物流配送体系，解决制约农村电子商务发展“最后一公里”配送问题。各设区市社要按照县级社创办电商企业力争全覆盖的要求，从今年开始，要作出计划，分批分期稳步扎实推动各县级社发展电商企业，每年要负责推动落实至少2个县级社创办电商公司。

2、搭建一个服务平台。以电子商务公司为依托，引入专业人才，组建运营团队，搭建一个促进县域电子商务发展的服务平台——电子商务运营服务中心，使之成为当地电子商务的服务商。秉承“先服务后业务”的理念，通过提供优质服务，培育网商和客户，以服务带动相关业务发展。一方面为本地网商提供专业服务，输出技术和提供软硬件支持；另一方面通过人员培训、营销策划、摄影、美工等方面的服务，帮助传统企业电商化，特别是帮助专业合作社、家庭农场、种养殖大户等对接电商渠道，使当地产业（尤其是农业）通过电商受益。电子商务运营服务中心要有当地特色农产品展示厅、网下销售门店、仓储设施、便民服务窗口、信息收集和发布等经营服务场所。

3、组建一个电商协会。在县级社电子商务企业相对较强和电子商务发展较快的地方，县级社要以电子商务公司、服务平台为基础，联合本地电商企业，在当地政府支持下，发起成立电子商务协会或供销分会，通过协会引领当地电子商务的发展，使供销合作社力争成为当地电子商务发展的主导力量。充分发挥电商协会组织各类培训、整合供应商资源、规范电商市场服务与价格等作用，为会员提供仓储管理、流通加工、配货、邮件封装、代发货、寄递等一条龙服务，降低会员物流成本。

4、实施一项改造工程。对县域供销社现有基层经营服务网点实施信息化改造，重点是村级综合服务中心（社）信息化改造，使之具备开展电子商务的基本条件，充实经营服务内容，在提供便民超市、农资代销等传统服务的基础上，增加网上代买农耕用具、家电、服装、日用品等商品，网上代售农特产品、民俗工艺品等产品，网上电信缴费、快递收发、就诊预约、车票预订等新型服务功能。各县级社每年改造网点数量应不少于总网点数量的20%，改造内容主要有：增设信息设备（包括便民终端、通讯卡、台式终端、大屏电视等），人员培训（培养网络购物和信息收集技能的电商从业人员）数据通信（有线上网和无线上网相结合，开通网店、微信号）网点门面建设（改造门面招牌和背景墙，统一供销电商标识）等，同时要充分发挥省社农产品信息网和全省系统各级农产品信息服务中心队伍的作用，完善信息发布平台并向在线交易电商平台提升转型，抓好全系统“新网工程”完善提升，加强仓储物流体系建设，与网点信息化改造相配套。对基层经营服务网点资源缺失的县级社，要加强与邮政、淘宝等平台的沟通联系，建立农村网点共建共享合作机制，使之为我所用，成为供销社开放办社的农村电商综合服务站。

5、营造一个良好发展环境。一是思想认识要到位，2014年全国供销社系统有近800家电商企业开展业务，电商销售额近3000亿元，而我省系统现仅有12家电商企业开展业务，网上销售额3.2亿元，我省系统电商发展明显滞后，与全国总社要求和先进省社相比，差距很大。因此，全系统要尽快牢固树立起互联网思维，充分认识发展电子商务是深化供销社综合改革的重要途径，是供销社系统的“二次创业”，切实增强紧迫感和责任感，解决认识不足，人才紧缺、动作缓慢等问题；二是县级供销社要主动做好汇报，取得当地政府的重视和有关部门的支持，把县域电子商务发展工作交给供销社牵头来抓，营造一个当地政府重视支持、供销合作社主导、社会各方积极参与的良好发展环境，为县域电子商务的发展提供有力保障；三是积极创造条件，充分利用供销社旧仓库、厂房等闲置、低效资产，开发利用整合成电商创业园、微电商集中区，主动参与县域电子商务平台、园区和重点项目建设，争取相关政策支持；四是发挥电子商务公司、服务平台、协会的示范带动效应，加大宣传推广力度，营造一个良好的电子商务发展氛围。

（二）抓好社有企业电子商务应用

各级供销社要积极推动社有企业“触网”，抓好全系统各类规模以上流通经营主体建立企业网站，用“互联网+供销社”的思维方式，推动流通现代化、服务规模化；要立足社有流通企业的主营业务，推动流通企业在全国供销社电商平台和淘宝、京东等知名电商平台开设网店，开展农资、农产品、日用消费品等电子商务经营和网上批发交易等经营活动；按照分类指导、分级推动的要求，各级供销社要抓好本级企业发展电子商务工作的落实，省社直属企业要创造条件率先发展电子商务业务，争取各级社有企业发展电子商务有新的突破。

（三）抓好供应链整合

要以本地和周边县主导产业、特色农产品、规模优势农业为重点，加强与本地农业产业化龙头企业、各类农产品流通加工主体、农民专业合作社、农业种养殖大户的联合合作，做好上网货源组织，强化产品分类包装，打响产品品牌，形成上规模、质美价廉、有竞争力的农产品货源供应链。

（四）抓好区域型、专业型电子商务平台建设

各地供销社要结合实际，发挥熟悉当地市场、配送成本低的优势，利用实体网点资源和物流配送体系，发展以辐射本地区为主的区域性电子商务平台，以网上销售带动门店销售，以门店销售支撑网上销售，探索“线上市场”与“线下市场”互动促销的O2O经营方式。永安、连城、建瓯、尤溪、平潭等5个全国首批电子商务示范县级社，一方面要突出区域优势主导产品和特色农产品的宣传促销为目的，另一面要以方便本地群众生活服务的O2O模式为业务内容，努力打造地方特色的专业型电子商务平台。

（五）抓好与全国总社平台对接

我省首批5个电子商务示范县（市）以及已成立电商公司的县级社要在全国总社平台今年三季度开通上线时率先与之对接，设立地方特色馆，展示和销售各地特色农产品；尚未成立电商公司的市县（区）供销社也要组织特色大宗农产品资源，组织、策划、推广区域农产品上架。有条件的供销社企业可直接与总社平台对接，在总社平台设立B2B专区，开展大宗农产品或地方特色产品网上批发业务。

三、保障措施

（一）加强组织领导。各级供销社要高度重视，增强紧迫感和责任感，把加快推进电子商务发展作为当前和今后一个时期供销社深化改革、加快发展的一项重要任务，切实抓紧抓好。省社成立电子商务工作领导小组和办公室，加大组织、协调和指导力度，并将电子商务工作纳入年度综合业绩考核和“十三五”规划的重要内容；各设区市社也要成立领导机构，加强组织领导，研究制定实施意见，对发展电商的各项工作任务尤其是推进县级社“五个一”的落实提出工作要求，细化工作任务和措施，抓好督促协调指导，确保目标任务落实到位；各县（市、区）社要主动作为，立即行动，主要领导要亲自抓，班子成员要统一思想，齐心协力，尽快落实“五个一”的具体步骤和措施，积极争取同级政府及有关部门在人、财、物等方面给予供销社优先安排和重点支持，积极参与地方电子商务平台和园区、农村电子商务示范区建设，力争形成以供销社为主导的县域农村电子商务服务体系。

（二）争取政策支持。一是省社将把电子商务项目列入基层发展基金和“新网工程”财政资金支持的范围，并积极争取总社项目资金支持，对县级社发展电子商务项目给予重点倾斜，市、县（区）社也要争取地方财政资金和有关部门资金的支持。二是在各级供销社贯彻落实中发[2015]11号文件过程中，要积极争取把发展电子商务的鼓励政策和财政资金的支持写入同级地方党委政府出台的文件中。三是各级供销社要充分用好各级政府及有关部门已经出台的加快电子商务发展的各项扶持政策，加强与同级商务、财政、发改、经信等部门的沟通协调，抓好政策对接，争取地方相关部门对供销社发展电商工作的支持。

（三）加强业务培训。要加强电子商务人才的引进和培养，加大力度分期分级开展电子商务业务培训工作，从今年起，省社计划在3年内每年分2至3期分别对省、市、县（区）社机关及直属企业、电子商务企业等相关人员进行培训。各市、县（区）社每年也要组织1至2期培训班，同时要加强同当地商务、农口部门以及相关部门或协会的联系合作，多渠道全方位对供销社电商从业人员开展全员培训，做到全覆盖、无死角。各地供销社还可组织相关人员到省外先进县（市）及省内供销社电商起步较早的地方参观学习。

（四）创新工作机制。要用开放的理念发展电子商务，引进战略投资者，加强与系统外现有技术优势明显、经营管理先进、业务发展态势良好的电商企业合作，发展混合所有制经济；要立足供销社优势和特色，加大供销社系统上下贯通、共同发展的联合合作力度；要加强责任分解落实，明确主体责任，强化目标跟踪督促检查，抓好调度统计分析，落实通报制度，加强工作考核，促进目标任务落到实处；要推广先进经验，抓好示范带动，要认真总结推广我省电商工作中涌现出来的典型经验和好的发展模式，加强宣传和指导，以点带面，发挥好示范带动作用。

2015年6月26日
