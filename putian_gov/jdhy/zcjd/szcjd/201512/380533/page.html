市质监局解读莆田市贯彻国务院质量发展纲要进一步推进实施质量强市战略的意见

来源:莆田市质监局 时间：2015-12-10 11:32
| | | |

近日，莆田市人民政府按照《福建省人民政府关于贯彻国务院质量发展纲要进一步推进实施质量强省战略的意见》（闽政[2015]30号）要求，结合我市实际，制定出台《莆田市人民政府关于贯彻国务院质量发展纲要进一步推进实施质量强市战略的意见》（莆政综[2015]123号）（以下简称《实施意见》），对我市贯彻落实国务院质量发展纲要进一步推进实施质量强市战略做出具体部署，提出了指导思想、发展目标、主要任务、保障措施等具体要求，强调构建多元共治的质量工作格局，夯实质量工作基础，提升质量总体水平，促进我市经济社会科学发展跨越发展。

一、起草背景

《实施意见》是根据国务院《质量发展纲要（2011-2020年）》（国发[2012]9号）和《福建省人民政府关于贯彻国务院质量发展纲要进一步推进实施质量强省战略的意见》（闽政[2015]30号）等文件来制定的。省政府强调要进一步深入贯彻落实习近平总书记“推动中国制造向中国创造转变、中国速度向中国质量转变、中国产品向中国品牌转变”重要论述，按照《质量发展纲要（2011—2020年）》，围绕质量强省建设和产业转型升级，结合实际制定修订本地区、本部门质量发展的长远规划和年度计划，明确目标责任，加强督促检查，务求各项工作落到实处，确保实现我省质量发展各项指标。因此，我市也结合实际，制定出台相应《实施意见》，既是全面贯彻落实国务院质量发展纲要，又是对我市今后做好全市质量工作提出了更高要求。

二、发展目标

《实施意见》提出的发展目标与市委市政府印发《关于进一步加快产业转型升级的实施方案》和《莆田市实施<中国制造2025>行动计划》提出的目标相衔接，到2020年，产品质量、工程质量、服务质量的保障体系更加完善，质量强市取得明显成效，质量基础进一步夯实，质量总体水平显著提升，质量发展成果惠及全市人民。

1、产品质量目标：到2020年，产品质量保障体系更加完善，产品质量安全指标全面达到国家强制性标准要求，质量创新能力和自主品牌市场竞争力明显提高，品种、质量、效益显著改善，节能环保性能大幅提升。其中：农产品质量方面：生产的农产品获得无公害农产品、绿色食品、有机食品和地理标志产品等“三品一标”的数量2015、2020年分别达到90个、100个以上，主要种植业产品、畜禽产品质量安全监测合格率2015、2020年均稳定在96%以上；水产品获得无公害农产品的数量2015、2020年分别增加2个、10个以上，主要水产品养殖环节药物残留抽检合格率2015、2020年均稳定在96%以上。工业产品方面：工业产品质量合格率稳步提高，产品质量省级监督抽查合格率2015、2020年分别稳定在93%、95%以上，合格率排名位居全省前列，主要工业产品的质量损失率逐步下降。食品和药品方面：大中型食品企业技术装备水平达到国际先进水平，在规模以上食品企业大力推行GB/T22000或HACCP认证。重点食品、药品质量安全状况保持稳定良好，食品和药品安全水平显著提升。战略性新兴产业方面：主要产品技术质量指标处于国际先进水平，培育一批质量素质高、品牌影响力大、核心竞争力强的大企业和一批创新活力旺盛的中小企业，推动战略性新兴产业发展成为先导性、支柱性产业。

2、工程质量目标：到2020年，建设工程质量水平全面提升，竣工交付使用的工程质量达到国家标准或规范要求，工程质量水平保持全国总体平均水平之上；建设工程质量事故率控制在国家、省规定范围内，一批工程项目获“闽江杯”等省级优质工程奖和“壶山杯”市级优质工程奖，人民群众对工程质量满意度显著提高。工程质量水平方面：大中型工程项目一次验收合格率2015、2020年均达到100%，其他工程一次验收合格率均达到98%以上；人民群众对工程质量（尤其住宅质量）满意度明显提高，2015、2020年住宅工程分户验收率均达到100%，工程质量投诉率逐年下降。技术创新能力方面：在建筑、交通基础设施、清洁能源和新能源、市政等重要工程领域拥有一批核心技术，节能、环保、安全、信息技术含量显著增加。大力发展绿色建筑，住宅性能改善明显，建筑工程节能效率和工业化建造比重不断提高。

3、服务业质量目标：到2020年，服务业质量水平显著提升，全面推行国家和地方服务业质量标准，推进规模以上服务企业建立质量管理体系，建成一批国家级、省级综合服务业标准化试点，主要服务行业顾客满意度显著提高，服务业质量高于全国平均水平。生产性服务业方面：在金融保险、现代物流、信息技术、商务服务、节能环保服务、服务外包等重点生产性服务领域，建立健全服务标准体系，全面实施服务质量国家标准。建成一批服务标准化试点项目。银行业、现代物流业、移动通信业顾客满意度2015年均达到80以上，2020年在此基础上进一步提升。生活性服务业方面：基本形成专业化、品牌化、网络化经营模式，服务产品种类不断丰富，满足人民群众多样化需求。行业自律能力和质量诚信意识明显增强，零售（超市）、旅游（导游、旅行社）顾客满意度2015年分别达到76、75以上，2020年力争达到80、78以上，养老服务业（机构养老）老人满意度2015年达到75，2020年力争达到80。

三、具体措施

《实施意见》从8个方面提出实现目标的具体办法和措施。一是强化企业质量主体作用。积极开展质量兴企活动，推广卓越绩效等先进质量管理方法。督促企业严格按标准组织生产经营，引导企业加大技术创新投入，支持有条件的企业建立技术中心、工程中心和产业化基地。二是强化创新质量发展机制。以争创“全国质量强市示范城市”“全国知名品牌示范区”“全国出口质量安全示范区”等为载体，大力创建区域性品牌。继续开展市政府质量奖评选，引导有条件的企业争创各级政府质量奖，不断提升企业竞争力。三是强化质量安全监管工作。加大对重要工业品和农产品、工程建设的动态监管力度，完善质量分析报告、质量安全风险评估等机制，落实质量安全监管和责任追究等制度，严格执行行政许可等市场准入制度。四是强化持续自主品牌培育。围绕 “336”产业发展目标，推进以技术创新为基础，以名牌产品等为核心的品牌战略，加快形成一批品牌产品、品牌工程和品牌企业，形成品牌效应。五是强化推进标准化提升。开展标准化综合改革试点示范活动，构建具有莆田特色质量标准体系。着力提高科研成果的标准转化率，制定并实施一批拥有核心技术和科技创新成果的标准。进一步拓宽服务业标准化领域，在旅游等领域选择相关项目进行重点突破，建立服务质量地方标准。发挥技术检测机构在标准制订中的重要平台作用，支持有实力的企事业单位参与国内外标准化活动，提升企事业单位在国内外标准制定活动的地位。六是强化产品质量全面提升。加强工业企业质量监督管理，发挥行业协会等社会组织作用，指导企业建立健全质量管理等体系。建立战略性新兴产业重点项目库，创建战略性新业产业市级引导基金，大力培育现有101家战略性新兴企业。建设“食品放心工程”，推动农贸市场规范化、超市化管理，争取食品药品监管信息化建设纳入国家惠民信息工程试点，鼓励食品医药企业发展“实体+电商”双线营销。七是强化工程质量全面提升。完善工程质量管理体系，开展施工企业和施工项目安全生产标准化考评，建立工程质量通病治理的长效机制，推行精细化管理措施和住宅工程质量分户验收制度，抓好重大基础设施和重大产业项目及大型公共建筑等质量安全管理，确保工程质量。八是强化服务业质量重点提升。加快简政放权工作，优化项目审批工作流程。大力发展新兴服务业，大力实施“宽带莆田”战略，健全通信等重点服务业领域质量管理体系，促进服务业发展提速、比重提高、质量提升。加强莆台服务业交流合作，带动提升莆田服务业质量水平。

四、工作保障

贯彻落实好《实施意见》的目标和要求，一是加强组织领导。市质量强市工作联席会议要加强统筹协调；各县、区（管委会）、各有关部门要结合实际制定修订质量发展的长远规划和年度计划，确保实现质量发展各项指标。二是加大政策扶持。加大对质量工作的投入，将质量保障和质量发展的项目建设纳入重点支持范畴。实施质量奖励制度，积极引导企业加大资金投入。三是强化考核评价。建立健全质量工作考核机制，组织开展质量工作年度考核，考核结果作为对下一级人民政府领导班子和领导干部进行综合考核评价和实行问责的重要参考。四是加强宣传引导。努力营造政府重视质量、企业追求质量、社会崇尚质量、人人关注质量的良好社会氛围。
