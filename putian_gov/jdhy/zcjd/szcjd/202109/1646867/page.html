莆田市人民政府办公室关于《莆田市公交提升专项规划（2020-2035）年》政策解读

来源:市府办 时间：2021-09-13 17:03
| | | |

　　经市政府研究同意，近日，我市印发《莆田市公交提升专项规划（2020-2035）年》（以下简称《专项规划》），现对主要内容解读如下： 

　　一、背景依据

　　城市公共交通是重要的城市基础设施，是关系国计民生的社会公益事业，优先发展公共交通是贯彻落实党的十九大精神的具体体现。“十四五”时期是我市全方位推动高质量发展超越的关键时期。《专项规划》主要是根据《国务院关于城市优先发展公共交通的指导意见》、《莆田市国民经济和社会发展第十三个五年规划纲要》等文件编制，目的是贯彻落实党中央国务院和省委省政府、市委市政府有关决策部署，阐明新时期我市公共交通的发展目标，明确新时期我市公共交通的发展重点任务和保障措施，为我市“十四五”期间公共交通发展提供依据遵循。 

　　二、目标任务

　　坚持“以人为本，公交优先”，以建设具有新型城市水准的基础设施、服务水平和运行效率的公共交通体系为趋向，通过公共交通的新一轮改革，建立多元投入、综合管理、服务高效的良性循环机制，基本形成一个以各种交通方式协调发展，衔接便捷的多功能、网络化、一体化的公共交通体系；营造畅通、高效、易达的出行环境；最大限度满足未来增长的交通要求、人民生活质量的提高和城市生态环境的需要；促进城市发展，全面提升城市综合竞争力。在分析莆田市社会经济发展趋势、土地规划利用特点和预测未来客流分布的基础上，提出如下具体目标： 

（1）建立完善、财政可支撑、便捷的公共交通系统，打造城区半小时通勤圈、区间1小时快速公交圈。 

（2）建设合理的公交走廊及线网结构，缓解交通堵塞，改善城市交通环境，引导和支撑城市空间拓展。 

（3）结合公交换乘枢纽、公交场站，优化接驳线网及公交站点布局，打通最后一公里，实现零换乘。 

（4）建立多元投入、综合管理、服务高效的良性循环机制，明确公交发展的政策和技术保障措施。 

　　三、工作进展

　　2020年5月，我局创新开展了一系列公交规划前期工作，在前期研究的基础上抽调局内业务骨干成立专班组，并委托福建省交通规划设计院有限公司为编制单位，结合我市实际情况，召开多次编制工作讨论会，并赴各县区、市直部门征求意见，形成今天研究的《报批稿》。主要有以下三个亮点： 

一是谋划启动早。我局于2020年上半年即启动各项前期工作，积极参与“莆田公交”规划编制动员会、高质量发展总体目标、区域发展定位等多个前期研究课题会议。 

二是公交线网优化全面。现行规划范围内莆田市实际营运的公交线路共138条，通过重点分析现状线路存在的问题以及深度分析线路与重点项目、道路、场站、客流走廊的匹配程度，线路和运力的匹配度、公交线路技术指标合理性等指标，从加大公共交通线网密度注1，降低非直线系数注2、线路长度等三方面对莆田公共交通线网进行全面提升优化，共计优化调整线路56条。 

三是社会参与度高。我局通过发文收集市直有关部门以及各县区（管委会）征求意见，得到各部门、单位积极反馈，累计收到莆田市自然资源局、财政局、文旅局、住建局、城市管理局、公安交警支队、交通综合执法支队，各县（区、管委会）交通运输局，市公交集团等多个部门政策建议一百余条。为提高规划编制的科学化、专业化水平，我局邀请福建省交通规划办公室综合运输处处长程朝辉等知名专家学者，为《规划》编制进行专业指导。 

　　四、范围期限

　　规划区域范围：莆田市市区行政区域范围（不含仙游县），主要包括：荔城区、城厢区、涵江区、秀屿区和湄洲湾北岸管委会、湄洲岛管委会，陆域面积2284平方公里。 

　　规划中心城区：包括城厢区的凤凰山街道、霞林街道和龙桥街道，荔城区的拱辰街道和镇海街道，陆域面积约60.8平方公里。 

　　规划年限：2020-2035年。其中规划重点为近期规划（2021年-2025年），远期规划（2026年-2035年）作为公交系统发展前景，宏观规划重点把握公交系统方向性发展。 

　　五、主要内容

　　（一）匹配城市交通需求，加密公交线网密度，提高公交服务水平。 

　　1.公交线网优化方案合理性分析。一是分析评价莆田市城区现有公交线网与客流分布特点，保留原线网中承担主要客流量的合理线路，统筹考虑现状公交线网的固定客流，适应居民公交出行形成的习惯，保留对城市居民住地、工作地的选择已产生一定影响的线路。二是考虑公交线路与重点项目、道路建设进度、公交场站建设的匹配程度；分析公交线路技术指标（线路长度指标、非直线系数指标、线路重复系数注3、线网分布密度、站点覆盖率注4）的合理性；采纳公众需求、公众意见以及公交公司对公交线网的反映；完善公交运力与线路的匹配程度。 

　　2.实施公交需求预测，分析重要客流走廊与需求点。一是采用“交通四阶段法”注5预测莆田市公交客流，按照客流OD分布情况以及预测结果，挑选莆田市成熟主要客流走廊以及OD量较大的OD点对，作为线路优化主要的吸引源和产生源。二是统筹考虑《莆田市城市总体规划（2008-2030）》以及公众需求调研、公交公司及运管部门反馈，估测莆田市近期主要新增公交需求点，涵盖近期城市建设中主要的行政区、住宅区、工业区和科教区等潜在需求点，现状公交线路稀疏和服务空白区等公交盲点，作为本规划公交线路弥补的区域。 

　　3.分析线网不足，提出公交线路优化、加密措施。一是线路指标优化线路，采用线路拆分降低线路长度，取消线路经过的客流量不大的站点以提高线路周转效率，裁弯取直降低公交非直线系数；二是首末站优化线路，结合规划期内莆田市公交场站的建设情况，调整线路起讫点；三是需求点新增线路，针对公交稀疏和空白区及公交盲点，增加线路作为补充线网；四是旅游新增线路，考虑莆田市旅游公交线路数量较少、覆盖面较低，开通从市区火车站、汽车站等集散点通往具体景区以及串联各景区的公交线路；五是夜班新增线路，莆田市已有的夜班公交仍显紧缺，考虑涵江区、秀屿区增设夜班公交线路；六是大站快线新增线路，避免部分高频站点的客流密集而其余低频站点客流稀疏的现象，将个别线路由“站站必停”转换成“区间大站快运”模式，缩短运行时间，快速疏解部分站点拥挤的客流。 

　　4.公交线路逐年布设，逐步加密。按照“量力而行、尽力而为”原则，参照公交线路优化、新增的“轻重缓急”，采纳公众、部门意见，逐年布设公交线路。 

　　（二）服从城市总体规划，优化各级公交场站布局与服务水平。 

　　1.公交场站总体设计分析。一是分析公交场站类型，此次规划将莆田市公交场站分为：公交枢纽站、首末站两类，公交首末站包括大型公交首末站和小型公交首末站。二是提出公交场站布局原则，为了安全、方便、迅速、准点、舒适地运送乘客，公交运营不仅需要拥有和客流相适应的公交线网，同时还必须设置相应的公交场站，使线路规范，停车归场，保养有车位。线网与场站设施之间保持协调发展，才能保证高效、低耗、安全地完成客运任务。三是确定公交场站总体布局方案，规划好莆田市未来年场站建设，满足莆田市未来发展需求。 

　　2.公交枢纽站规划方案确定。为应对未来需求，公交枢纽站规划一方面结合城市旧城改造，完成老城区公交场站的外迁和升级，以旧城改造为契机，进一步完善公交枢纽系统的布局，解决老城区公交场站用地难题；另一方面，结合莆田市各功能区发展变化与人口经济增长趋势，提前谋划新增长点公交场站的规划和建设，全面提升公交枢纽站的服务功能，优化公交枢纽站发展模式。 

　　3.公交首末站规划方案确定。规划莆田市公交首末站使其数量达到供需平衡，即总体和片区层面的平衡，以各层次交通规划为依据，与各层次用地规划充分衔接。继承已有成果中的合理站点，调整不理想站点，覆盖服务盲区和薄弱点。且规划公交首末站于紧靠客流集散点和道路客流主要方向的同侧与靠近人口较集中、客流集散量较大且周围有一定空地的位置，使其与城市道路网的建设及发展相协调。 

　　（三）保障公交车辆配给，进一步优化车辆结构。 

　　1.落实公交车辆资金投入。规划期内以满足相关规范要求的每万人配备公交数为目标，保证规划期末莆田市公交运营车辆数能满足公交出行需求，提高公交线路日发车频率，扩大乘客出行自由度。 

　　2.公交车型与公交线路的服务功能相适应。综合考虑线路的功能、运输乘客的出行特点、运行道路的几何条件等因素，不同等级的公交线路根据客流需求配置不同车型的公交车辆，提高公交车辆上座率。 

　　3.推进绿色公交系统。进一步优化车辆结构，全面推广新能源和清洁能源汽车，更新淘汰传统燃料公交车，基本实现公交车纯电化，引领公交行业转型升级。 

　　（四）全方位推动公交优先战略规划 

　　1.公交专用道设置。结合近期城市发展要求、土地利用发展态势、交通发展态势以及基础设施建设动态等，按照“易于实施，效果显著，先主后次”原则，优先实施主要客流走廊的公交专用道建设，重点推动城厢—荔城主城区内形成“一横一纵”注6公交专用道网络，实现组团内、组团间的公交服务功能。 

　　2.公交信号优先系统布设。科学设置优先（专用）车道和优先通行信号系统，调整城市公交车辆与其他社会车辆的路权使用分配关系，提高公交车辆运营速度和道路资源利用率；加大市区监控和执法力度，确保公交车辆的优先或专用路权；优化公交信号优先系统的设置，减少公交车辆在道路交叉口的停留时间。 

　　3.智能公交建设。加强智能公交系统集成建设和规划设计，实现控制指挥中心对“人—车—站—道”的一体化调度、管理、监控和服务，为运营管理人员提供全线公交运行、客流组织、车站设备、票务管理、道路车况等信息，全面提升城市公交系统的营运效率。 

　　（五）强化新时代保障措施 

　　1.政策保障。加强公交立法，为公交事业有序发展创造平等竞争的经营环境；鼓励公交出行，引导交通方式转变；落实公交优先政策，把优化交通结构、提升公交服务作为城市交通发展的突破口和重点；提高服务保障水平，为乘客提供安全、便捷、舒适的乘车条件。 

　　2.规划保障。强化政府主导，落实公交优先发展措施；保障用地配套，优先安排公共交通设施建设用地，对场站用地作严格控制和预留；加强行业监管，确保公交车辆及场站有效地为公交服务。 

　　3.资金保障。提供政府财政支持，建立稳定的公共财政优先投资来源；规范财政补贴制度，实现公交补贴专款专用，使公交补贴发挥最大效益；调整公交客运价格，科学合理地核定公共交通票价，最大限度地吸引客流；实现多元化经营，积极寻求公交企业新的经济增长点，减少政府负担。 

　　4.科技保障。建设完善公交运营信息化智能调度系统，切实有效的提升公交公司的管理和服务水平；建立公交出行信息网络系统，对乘客出行进行主动而合理的引导，对管理者提供实时系统状态查询和历史数据分析服务。

　　七、关键词诠释

　　“线网密度”:指每平方千米城市用地面积上有公共交通线路经过的道路中心线长度。 

　　“非直线系数”:指公交线路起讫点间的实际交通距离与两点间空间直线距离之比。 

　　“线路重复系数”:指线路密度与线网密度的比值。 

　　“站点覆盖率”:指城市公共汽（电）车交通站点覆盖面积与城市建成区面积之比。 

　　“交通四阶段法”:以居民出行调查为基础，由交通生成、交通分布、交通方式划分、交通量分配四个阶段组成。 

　　“一横一纵”:一横为荔华东大道、莆阳路、天妃路，一纵为荔城大道。 

　　八、相关政策

　　（一）《交通强国建设纲要》 

　　推进城市公共交通设施建设，强化城市轨道交通与其他交通方式衔接。科学规划建设城市停车设施，加强充电、加氢、加气和公交站点等设施建设。优先发展城市公共交通，鼓励引导绿色公交出行，合理引导个体机动化出行。推进城乡客运服务一体化，提升公共服务均等化水平，保障城乡居民行有所乘。优化交通能源结构，推进新能源、清洁能源应用，推动城市公共交通工具和城市物流配送车辆全部实现电动化、新能源化和清洁化。 

　　（二）《关于<转发福建省乡镇综合运输服务站、港湾式客运站建设补助管理办法>的通知》 

　　1.明确项目前期工作要求 

从选址、功能、后期运营上分别对乡镇综合运输服务站和港湾式客运站项目进行了规定。提高补助资金的使用效果，避免国有资金流失，保障工作顺利开展。 

　　2.明确建设标准和验收要求 

结合《福建省运输管理局关于推进 “四好农村路”运营好工作的指导意见》（闽运管办〔2017〕34号）等文件，对乡镇综合运输服务站及一类港湾式客运站的建设标准和验收要求做了明确的规定。 

　　3.落实项目规范管理 

督促市县交通运输部门规范建立乡镇综合运输服务站项目档案。市县交通运输主管部门应做到“一项目一档案”，自觉接受上级部门及同级纪检监察部门的监督检查，并督促项目业主按照相关部门要求落实项目规范管理。 

　　（三）《关于支持新能源公交车推广应用的通知》 

　　1.提升技术水平，保障产品供给 

按照技术上应先进、质量上要可靠、安全上有保障的原则，适当提高新能源公交车技术指标门槛，重点支持技术水平高的优质产品。加快研究新能源商用车积分交易政策。 

　　2.完善财税政策，促进产品消费 

　　从2019年开始，新能源公交车辆完成销售上牌后提前预拨部分资金，满足里程要求后可按程序申请清算。在普遍取消地方购置补贴的情况下，地方可继续对购置新能源公交车给予补贴支持。落实好新能源公交车免征车辆购置税、车船税政策。 

　　3.加大支持力度，优化使用环境  

　　加快新能源公交车充电基础设施建设，满足车辆使用需求；应将除公交车外的新能源汽车地方购置补贴资金集中用于支持充电基础设施“短板”建设和配套运营服务等环节。从2020年开始，采取“以奖代补”方式重点支持新能源公交车运营。
