莆田市优化中心城区学校布局有关政策解答

来源:湄洲日报 时间：2016-11-09 08:41
| | | |

　　经市政府研究，同意实施中心城区高中迁建方案，采取“腾笼换鸟”模式，优化中心城区学校布局，拓展教育发展空间。为进一步明确政策导向，有序推进中心城区学校布局优化调整工作，现将有关政策解答如下：

　　问题1：中心城区义务教育及学前教育阶段学位情况如何？

　　答：随着新型城镇化进程加速推进以及全面放开二胎政策效应逐渐显现，全市学龄人口特别是城镇学前教育的适龄人口迎来较大增长。据统计，今年中心城区幼儿园、小学、初中在校生数分别超出公办学校标准学位10406个、3084个、15747个，学校呈现大班额现象。“十三五”期间，中心城区学位将进一步紧张，预计到2020年，扣除民办学校解决部分学位外，中心城区需分别新增公办幼儿园、小学、初中学位1.33万个、1.27万个、1.26万个，才能满足新增人口入学需求。

　　问题2：如何解决中心城区义务教育及学前教育阶段学位不足问题？

　　答：一是实施中心城区高中校搬迁工程，腾出校园，原校址用于幼儿园、小学和初中办学。二是加快实施《莆田市中小学及幼儿园布局规划（2015-2030）》（莆政办〔2016〕65号）文件中明确建设的中心城区新建、扩建中小学、幼儿园项目。三是充分利用市、区机关企事业单位办公楼、厂房等闲置资产建设幼儿园。四是在旧城改造和新建住宅小区要同步配套建设幼儿园。五是鼓励社会力量办学。

　　问题3：中心城区高中校搬迁有哪几所？

　　答：市教育局根据中心城区幼儿园、小学、初中学位不足现状，统筹考虑新型城镇化加快和全面放开二孩政策因素，通过认真调研，学习借鉴先进地市做法，提出我市中心城区高中迁建方案呈报市政府研究，确定搬迁的有莆田职业技术学校、莆田第一中学。莆田职校、电大新校园已动工建设，莆田第一中学新校园正在选址中。莆田第一中学外迁，解决现有运动场地、学生宿舍、教师周转房不足等问题，现校址置换给擢英中学办学，现擢英中学校址由莆一中举办公办九年一贯制学校（市实验小学迁入），市实验小学原址用于举办实小幼儿园。莆田电大、莆田职业技术学校及市艺校外迁，在执行市政府专题会议纪要〔2015〕43号的基础上，将三校剩余校园土地置换给城厢区兴安小学办学，并附设幼儿班。网络上传的是最早的征求意见稿，经征求意见后，做了修改，暂时没考虑莆田第四中学搬迁问题。

　　问题4：“十三五”期间，中心城区规划建设有哪几所中小学及幼儿园？

　　答：根据《莆田市中小学及幼儿园布局规划（2015-2030）的通知》，荔城区在2020年前新建、扩建中小学、幼儿园11所，其中，初中1所：莆田九中；小学3所：拱辰中心小学分校、拱辰南郊小学、东园东路小学；幼儿园7所：中海国际幼儿园、二幼荔能分园、镇海爱丁宝双语幼儿园、一幼北辰分园、正荣润景幼儿园、一幼护五幼儿园、七步小学附属幼儿园。城厢区在2020年前新建、扩建中小学、幼儿园10所，其中，九年一贯制学校2所：九华学校、顶墩学校；小学3所：太平小学、兴安小学（附设幼儿园）、泗华小学；幼儿园5所：滨溪幼儿园、电商未来城幼儿园、荔景幼儿园、金域华府幼儿园、泗华幼儿园。

　　问题5：中心城区高中校外迁有哪些现实意义？

　　答：1.有利于解决城区义务教育及学前教育阶段学位不足问题。学前教育阶段需要考虑学生接送问题，义务教育阶段实行“免试就近入学”，这两个阶段的学校布局首先要与群众就近入学需求相结合。高中阶段可以不受过多的区域限制，通过城区高中外迁，城区初中、小学、幼儿园优化调整，可以迅速缓解义务教育及学前教育阶段学校由于校园面积不足、教学空间严重缺乏而带来的学校拥挤、大班额、校园安全压力大等亟待解决的问题，促进教育教学质量的提升。

　　2.同步解决学生接送难、停车难问题。本次中心城区学校布局由政府主导，教育、规划、财政、公安等政府部门以及所在区人民政府协力推进，结合了城市总体发展规划，进一步优化学校周边交通、产业、治安等布局，随着学校优化调整，相关周边配套将同步规划、同步建设、同步投入使用，减少学生因校址变迁而带来的诸如上学路程加长、安全隐患增大、经济负担加重等问题，切实体现布局调整当中的人文关怀。

　　3.可以改善优质高中办学条件和品质。目前高中面临新高考，由于现有学校规模受限，如莆田一中现有教室70间，学校选课走班难以实施，综合实验室等无法建设，办学效益难以提升。高中校搬迁后可以进一步扩大校园面积，拓展高中教育发展空间，解决应对新高考走班制需扩大校舍面积等制约发展的关键问题，教师宿舍、学校体育设施等能够按照省级优质高中标准相应配套，能够真正发挥优质高中的引领辐射作用，从长远看，也有助于教师进一步成长。

　　4.有利于城市空间的拓展。随着新一轮城市的发展，合理规划布局城市新区域的高中学校是保证城市健康协调发展的重要前提，也是实现高中教育资源在更大范围内普及的重大契机，一方面优质高中外迁与城市新区建设结合，可以实现高中自身跨越发展，在更大范围内寻求拓展空间，另一方面，城市新区建设可以通过引进优质高中资源进驻，增加区域活力，带动周边产业发展。

　　中心城区学校布局优化调整工作的有效实施，需要政府、学校、教师、学生、家长及社会各界持续的支持和监督，使学校在后续的办学过程中不断完善办学条件，提升办学质量，巩固中心城区学校布局优化调整的良好成果，实现教育资源优化配置，切实办好人民满意教育，推动我市加快建设教育强市。
