《莆田市兴化府历史文化街区保护管理办法》解读

来源:市府办 时间：2023-09-23 10:18
| | | |

　　莆田市兴化府历史文化街区是莆田市历史文化名城的核心组成部分，有着深厚的历史底蕴和特色风貌，其不仅是莆田政治经济文化活动的重要承载地，也是传统民居完整保存的典范。为了加强莆田市兴化府历史文化街区的保护与管理，继承中华民族优秀历史文化遗产，根据《中华人民共和国文物保护法》《历史文化名城名镇名村保护条例》等法律、法规，结合本市实际，制定《莆田市兴化府历史文化街区保护管理办法》（以下简称《办法》）。

　　一、制定背景

　　2018年8月，莆田市兴化府历史文化街区被福建省人民政府认定为省级历史文化街区；2020年4月28日，《莆田市兴化府历史文化街区保护规划》获福建省人民政府批复；2020年4月，莆田市荔城区人民政府正式启动莆田市兴化府历史文化街区修缮及配套基础设施提升一期工程；2022年12月，莆田市兴化府历史文化街区景区获评为国家2A旅游景区称号。兴化府历史文化街区保护范围为：东起北大北街,南至河滨路与东大路,西至胜利街与梅峰山山体西侧,北至兴安路、小西湖及元妙观三清殿以北一带,总面积为61.71公顷,其中核心保护范围面积9.86公顷，建设控制地带面积51.85公顷。保护范围涉及不可移动文物、历史建筑、传统风貌建筑、非物质文化遗产等。街区内有着街巷格局保存完好的大路街、县巷、后街、衙后路、庙前路和坊巷等6条古街，是莆田市传统的商业繁华地段，总长约1326米，连片的明清古建筑构成了具有莆田地方传统特色的风貌区。但是，目前兴化府历史文化街区内的保护和管理还是存在如下问题：

　　第一，历史文化遗产的保护方面。一些建筑年久失修，质量普遍较差；市政基础设施不完善，线路杂乱老化，排水、消防、电力等安全隐患普遍存在；有的建筑被私自改造，街区整体风貌的完整性受到很大影响，等等。通过立法，将促使街区的保护规划方案真正落到实处，街区内不可移动文物、历史建筑、传统风貌建筑得到保护。

　　第二，业态融合和文化传承方面。街区内有的古建院落产权、管理权、使用权错综复杂，有的居住、商业与办公等功能比较混杂，传统文化逐渐散失，商业活动低迷，经济发展放缓，等等。如何在保护修缮过程中引导业态的发展？如何在传承传统文化过程中发展新业态？如何在规划发展中提高群众保护修缮意识、自我发展业态的能力？通过立法，充分发挥群众自身发展的意愿，使继承传统文化的方式更加多元化，促进街区传统文化传承和新经济新业态的融合发展。

　　第三，修缮改造和业态经营方面。目前兴化府历史文化街区保护修缮及配套基础设施提升一期工程已经完工，一期工程后的新业态新文化的发展，二期工程的不可移动文物、历史建筑、传统风貌建筑的保护修缮等，需要加强法治建设加以保护管理。如：有的房屋修缮改造还未启动，有的房屋征收腾退工作未完成，对街区的整体修缮改造和招商运营产生了一定影响；有的经营者擅自设置不符合成片整体保护要求的广告牌、灯箱、电子显示屏等户外标牌；有的商户从事无证无照经营；有的经营者商业活动诚信不够等。通过立法，制定好保护修缮、文化传承、文明经营等相关的保护管理办法，使保护管理的各种方式方法，都有法可依、有章可循，确保街区保护管理于法有据、落地见效。

　　二、制定依据

　　制定《办法》的主要依据有：

　　第一，法律。《中华人民共和国文物保护法》《中华人民共和国城乡规划法》等。

　　第二，行政法规。《历史文化名城名镇名村保护条例》《中华人民共和国文物保护法实施条例》等。

　　第三，地方性法规。《福建省历史文化名城名镇名村和传统村落保护条例》《福建省传统风貌建筑保护条例》《福建省实施<中华人民共和国城乡规划法>办法》等。

　　第四，相关规范性文件。《住房和城乡建设部办公厅关于进一步加强历史文化街区和历史建筑保护工作的通知》《福建省人民政府办公厅关于加强历史文化名城名镇名村传统村落和文物建筑历史建筑传统风貌建筑保护利用九条措施的通知》《福建省住房和城乡建设厅关于在城市更新改造中切实加强历史文化保护坚决制止破坏行动的意见》《莆田市历史文化遗产保护利用管理暂行规定》《莆田市人民政府关于在城市更新改造中进一步加强历史文化遗产保护的通知》等。

　　三、主要内容和特点

　　（一）主要内容

　　《办法》不设章节，共二十八条，其中：

　　第一部为第一条至第三条，主要内容为目的依据、适用范围、保护原则。

　　第二部分为第四条至第八条，主要内容是政府职责、部门职责、经费保障、公众参与、专家委员。

　　第三部分为第九条至第二十三条，主要内容是保护对象、保护责任人、保护责任、整体保护、建设控制地带、核心保护范围、重点保护、保护标志、征收征用、违建处理、消防安全、禁止行为、文明经营、业态引导、大型活动。

　　第四部分为第二十四条至第二十六条，主要内容是转置规定、投诉举报和履职处分的法律责任。

　　第五部分为第二十七条至第二十八条，主要内容是管理细则和施行时间。

　　（二）主要特点

　　一是明确工作责任。提出了设置兴化府历史文化街区管理机构（管理中心），赋予管理机构从事具体事务性工作等职责职能；提出鼓励支持社会团体捐赠、租赁、资助、提供技术服务等方式参与兴化府历史文化街区的保护与利用工作。

　　二是明确保护对象。区分了兴化府历史文化街区的不可移动文物、历史建筑和传统风貌建筑，以及古树名木、古寺、古牌坊、古石刻、古井等，以及各级非物质文化遗产，并重点区分了三种不同的建筑，即不可移动文物、历史建筑和传统风貌建筑，并且对他们的保护责任人、保护责任，保护标志等都进行了详细的区分。

　　三是强调重点保护。结合兴化府历史文化街区的保护规划和省政府的批复文件，强调兴化府历史文化街区要重点保护和传承由历史轴线、重要景观与建筑节点、功能特色片区共同构成的历史空间格局，在建筑的安全保护上，提出要做好防盗、防火、防虫、防电、防水、防倒等工作，并明确了由消防安全责任人，全面负责消防安全。

　　四是注重业态引导。兴化府历史文化街区范围内的经营业态以有利于传承历史文化，发展本地特色的文化旅游产业为主，鼓励经营或者开展非遗文化活动、特色美食、传统民俗活动、研学活动等，并强调兴化府历史文化街区范围内经营者应当遵循商业职业道德，依法文明诚信经营，遵守商业规范。

　　四、关键词诠释

　　（一）本《办法》适用范围：具体以经福建省人民政府批准公布的兴化府历史文化街区保护规划确定的范围为准。本市其他历史文化街区，根据历史文化遗产保护管理实际，可以参照本《办法》执行。

　　（二）历史文化街区：根据《历史文化名城名镇名村保护条例》，历史文化街区是指经省、自治区、直辖市人民政府核定公布的保存文物特别丰富、历史建筑集中成片、能够较完整和真实地体现传统格局和历史风貌，并具有一定规模的区域。

　　（三）不可移动文物：根据《中华人民共和国文物保护法》，不可移动文物是指古文化遗址、古墓葬、古建筑、石窟寺、石刻、壁画、近代现代重要史迹和代表性建筑等，是针对可移动文物而言。

　　（四）历史建筑：根据《历史文化名城名镇名村保护条例》，历史建筑，是指经城市、县人民政府确定公布的具有一定保护价值，能够反映历史风貌和地方特色，未公布为文物保护单位，也未登记为不可移动文物的建筑物、构筑物。

　　（五）传统风貌建筑：根据《福建省传统风貌建筑保护条例》是指未公布为文物、历史建筑，具有一定保护价值和建成历史，能够反映历史文化内涵和地方特色，对整体风貌形成具有价值和意义的建筑物、构筑物。
