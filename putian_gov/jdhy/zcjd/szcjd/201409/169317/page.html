解读我省高考改革10大焦点

来源:莆田晚报 时间：2014-09-08 15:25
| | | |

    备受关注的高考改革方案昨日尘埃落定。这样的改革方案对我省会有什么影响，我省高考改革何时启动？权威部门和专家为你解读高考改革的10大焦点。
焦点1：
　　我省高考改革时间表
    业内猜测2014年年底或2015年上半年

    昨日，《国务院关于深化考试招生制度改革的实施意见》中列出了全国高考改革的时间表。我省高考改革什么时候实行？
    省教育考试院明确表示目前高考改革的配套文件还未出台，我省将按照国家的部署安排积极稳妥地推进，目前正在进行前期准备工作。也就是说，福建省的具体实施方案尚无明确具体的出台时间，一旦确定，将通过媒体第一时间发布。
    不过，据权威人士透露，按照高考改革“三年早知道”的原则和高考政策三年一贯制的规律，新高考最早的实施时间是政策公布三年后。也就是说，我省新高考政策的实施不会早于2017年。换句话说，新的高考政策不会对2015年和2016年的高考考生产生影响，至于2017年的考生，则要看我省高考改革方案的公布时间。
    省教育考试院相关人士也表示，2014年、2017年、2020年是三个关键的时间点。教育部提出的2017年全面推开改革是指，从2014年到2017年，各省要先后在高一新生中实行新的会考制度。新高考方案就是往后加三年。比如，2015年试点，2018年高考实行高考新方案。
    昨日，省教育厅并没有明确给出我省高考改革的时间表。不过，从此前省教育厅透露出的各项信息来看，我省高考改革的时间表可见端倪。2014年年初，省委九届十次全会对考试招生制度改革进行了部署，将有关改革项目列入《2014年全省重点领域改革方案》。我省将根据国家教育考试招生制度改革的总体方案，研究制订我省考试招生制度改革实施方案，争取在2014年年底前正式公布。因此，业内猜测，我省高考改革方案公布的时间可能是2014年年底或是2015年上半年。
焦点2：
　　中西部招生协作
    厦大、福大等招生计划今年已“西移”

    对于继续实施支援中西部地区招生协作计划，我省的高校目前已经开始实施。
    今年地点在我省的高校中，厦大、福大已经增加了面向西部招生的计划，因此缩减了在省内的招生计划。呈现出的现象是今年厦大、福大在省内招生的分数走高。
焦点3：
　　学业水平考试有何影响
    我省将制定实施新的高中会考方案

    昨日的高考改革方案提出高中学业水平考试成绩将计入高考成绩。
    目前我省实行的是高中学业基础会考制度，目前实行的学业基础会考制度从2009年开始实施，实施的是反向会考制度。学生在校期间，可以多次参加同一科目考试，成绩按最高的一次记录。所有学生的学业基础会考成绩均由学校记入学生学籍档案（纸质与电子档案），并最终与每一位学生的综合素质评价报告并列呈现。所谓的反向会考即文理学生“反向”考，文科学生要考理科内容，反之亦然。
    虽然2015年的高中学业基础会考制度的考试大纲已经公布，但可以明确的是，我省肯定会出台新的会考改革方案，这个方案将区别于目前的常规会考方案。
    在这方面我省的实施时间是什么时候，昨日也没有明确的答复。不过，今年年初省教育厅表示将制定实施新的高中会考方案，如果进展顺利，争取从2014年秋季入学的高一新生开始，全面实行普通高中学业水平考试，为今后高校招生实行综合评价、多元录取奠定基础。
    按照这个说法，也就是说2015、2016年的高考生仍旧实行现行的会考制度。至于2017年的考生，也就是今年的新高一学生，是否实施，则要看我省的进一步安排。

焦点4：
　　文理分不分科
　  今年高二的学生仍旧分科

    高考文理不分科是新高考改革方案的亮点之一。
    在高三从事教学的王老师表示，文理分科，集中式的教学有利于“偏才”的发展。文理不分科则有利于综合素质的培养。教育部提的文理不分科，应该不是单纯的文科或理科一起学，而应该是一个相对完善的配套方案。这个方案将有别于目前实行的分科教学，更倾向于综合发展。从这个方面来看，不是学习压力增大了，而是学习的针对性增强了，学生学习的目标性增强了。
    从近年来的教育改革制度看，高中文理分科制度在改革方案出台之前就有逐步淡化甚至取消的趋势。
    那么我省的学生文理分不分科？目前普通高中学业水平考试的方案尚未公布，因此，准确地说，我省今年高二的学生文理还是会分科的，所以明年高考的学生，仍旧按照现有的模式实行。至于今年的高一学生文理分不分科，仍旧是个谜。
焦点5：
　　回归全国统一卷
　  我省是否取消自行命题仍未知

    新方案提出2015年起增加使用全国统一命题试卷的省份。
    据了解，我省目前实行的是自行命题的模式，各个科目语文、数学、英语+文综/理综实行自行命题，英语听力则用全国卷。我省的自行命题从2004年开始。2004年，实行语数英自行命题，2005年增加文科综合和理科综合的自行命题，所增加的科目涵盖政治、历史、地理和物理、化学、生物等6个学科的内容。
    那么这个实行了近10年的模式会取消吗？
    昨日，省教育考试院的回复是尚未确定。不过，从教育部提出实行回归全国统一卷的目的是要实现异地高考来看，我省目前已经实行了异地高考，如果是出于这个目的的话，我省取消的可能性不大。不过如果是出于改进评分方式，加强评卷管理，完善成绩报告、国家题库和外语能力测评体系建设等其他因素，则还是有取消的可能性。因此，我省是否取消自行命题要看教育部的决定。
焦点6：
　　自主招生如何进行
　　“三国杀”估计要绝迹

    新方案提出，2015年起推行自主招生安排在全国统一高考后进行，并取消联考和专门培训。
    据了解，目前自主招生是教育部在2003年推出的政策，一般进行自主招生的是“985”等知名重点高校，也称“小高考”。因此，自主招生成为了各大名校的生源争夺战，也衍生出类似“北约”“京都联盟”等联盟。生源争夺激烈，业内每年把自主招生的各联盟戏称为“三国杀”等等。对此，多年从事高三教学的一位老师说，取消联考和专门培训后，学生不再疲于奔命各种培训。“三国杀”的现象估计要绝迹。此外，如今自主招生调整到高考后进行，对考生而言，无疑是一种减负。
焦点7：
　　寒门学子计划
　　我省2038人已先期受益

    对于国家农村贫困地区定向招生专项计划，我省目前已经开始施行，今年首次实行的农村专项招生已经让2038名农村孩子受惠。
    从录取的结果来看，该项政策的惠民成效初显，大大提高了优质高校招收农村学生的比例，较好地实现了预期目标。
焦点8：
　  高职招考与普通高考分开
    我省率先试点高职入学考试改革

    新方案提出高职院校考试招生与普通高校相对分开，实行“文化素质+职业技能”评价方式。在此方面，我省已经率先试点高职入学考试改革。从近几年我省高考实施的政策看，福建已经在进行高招改革方面的尝试，而且一直走在全国前列。
    例如，2014年，我省就开始试点高职招考改革，其考试时间已经和普通高考区分开来。从考试方面来看，考试科目的设置也不同于普通高考，面向高中生的考试和录取均不分文理科类。
焦点9：
    取消体育、艺术等加分项目
    我省高考加分政策一直在瘦身

    新的改革提出，明年起取消体育、艺术等特长生加分项目。
    从这一点来看，近年来，我省高考的加分政策一直在瘦身。例如，省招委会在2011年就对我省中学生学科奥林匹克竞赛和部分科技类竞赛高考加分项目，以及体育特长生的加分项目作出了新的规定，其中规定，从2011年升入高中的学生开始实施，时隔3年，2011年进入高一的考生于2014年参加高考。
焦点10：
　　增加双向选择机会
　　艺术类本科实行“一档多投”全国唯一试点

    在投档录取方面，据东南快报记者了解，我省实行考后填报志愿和平行志愿已多年。2014年，我省作为全国的唯一试点，试行艺术类本科A批“一档多投”。其模式就是由计算机比对，让考生和院校双向选择。省教育考试院相关负责人在录取结束后就曾表示，通过录取进程来看，“一档多投”的计算机系统运行正常，改革实施工作平稳顺利。特别是在本科A批的录取中，考生的志愿满足率非常高，基本实现了改革的初衷。
    从这个方面来看，我省作为教育部确定的今年实施“一档多投”改革试点的唯一省份，在进行高招志愿“一档多投”试点中任重道远。而作为教育部“一档多投”网上录取管理系统研发课题专家组组长，清华大学教授刘卫东此前在接受采访时也表示，“一档多投”在技术上已经成熟。不过何时全面推开“一档多投”或其他模式投档改革则要看教育部的具体进度。
