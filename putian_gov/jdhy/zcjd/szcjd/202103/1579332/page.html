《莆田市开展企业社会责任评估工作方案（试行）》政策解读（政策已废止）

来源:市府办 时间：2021-03-02 08:39
| | | |

　　2021年2月20日，莆田市人民政府办公室印发《莆田市开展企业社会责任评估工作方案（试行）》（莆政办〔2021〕13号，以下简称《工作方案》），现将有关内容解读如下。

　　一、起草依据

　　开展企业社会责任评估，对引导和促进全市企业构建新发展理念，主动承担和履行社会责任，推动提高金融服务实体经济效率，助力企业实现健康、和谐、可持续发展，具有重要意义。开展企业社会责任评估，作为我市优化营商环境的一项具体举措，是企业融资条件的有益补充，也是责任金融赋能实体经济的有效抓手，即是一项创新性的工作，也是一项探索性的工作，符合联合国可持续发展理念，争取打造企业社会责任评估“莆田样板”。

　　二、起草过程

　　根据市政府〔2020〕81号、111号专题会议纪要精神，2020年11月，市发改委牵头会同市数字集团起草形成《工作方案》初稿，组织市直相关单位以及莆惠金服平台方进行多次修改讨论，2020年12月中旬形成讨论稿，经征求市人大、市政协、金融办、数字办、工信局、财政局、商务局、人社局、税务局、人行、银保监、海关、行政服务中心等市直相关部门意见，合理意见均已吸收采纳。2021年1月4日，市委常委、常务副市长傅冬阳召集专题会议进行研究，进一步修改完善后，形成了《工作方案》送审稿。2021年2月3日，市政府第100次常务会议研究同意印发组织实施。

　　三、主要内容

　　《工作方案》主要内容包括四个部分：

　　第一部分是总体要求，包括指导思想、基本原则、主要目标。指导思想：以习近平新时代中国特色社会主义思想为指导，贯彻落实党的十九届五中全会精神，围绕“强产业、兴城市、惠民生、优生态、保稳定、重党建”中心任务，把企业社会责任建设作为推动企业自主创新能力的重要手段，作为创新社会治理、促进社会和谐发展的重要载体，作为责任金融赋能实体经济的有效抓手，加快改革创新，推动转型升级，激发企业发展活力，为全方位推动高质量发展超越提供强大动力。基本原则：坚持企业社会责任建设与改革创新相结合，坚持企业社会责任建设与经济社会发展相适应，坚持企业社会责任建设与金融创新相统一。主要目标：探索实施试行《工作方案》，至2023年底，力争全市规模以上企业普遍参与社会责任建设，中小微企业积极参与企业社会责任建设，70%以上参与评估企业达到社会责任标准。

　　第二部分是评估流程。借鉴国际国内的有关评价标准，按照专家组评审确认的《莆田市企业社会责任评估标准》，针对企业采用71个评价指标，实行线上评估和深度入企评估的方式，评估出3星、4星、5星责任企业。

　　第三部分是结果应用。莆田市企业社会责任评估工作纳入企业信用评价体系建设的重要内容。莆田市企业社会责任评估认定委员会向获得“社会责任企业”称号（评估结果4星以上）的企业颁发认证证书，颁发之日起三年内有效。有效期满后由企业自报申请复核。获授“社会责任企业”称号的企业可优先考虑推荐参与评选五一劳动奖状，获授“社会责任企业”称号的企业负责人，可优先考虑提名党代表、人大代表候选人和推荐政协委员。

　　（一）获授“社会责任企业”称号的企业（5星），可以享受以下优惠政策：

　　1.优先列入市、县区各部门组织申报的各类专项资金扶持对象；

　　2.在同等条件下，政府在购买限额标准以下公共物品、公共服务时予以优先采购；

　　3.金融服务机构在受理融资担保、发放贷款申请、进行信用评价时给予征信加分，专项享受不超过1000万元的融资担保，免收担保费（由同级财政按年1%给予补贴），原则上由企业提供信用反担保；

　　4．根据企业评估与认定情况优先给予贷款贴息；

　　5．优先纳入政府扶持品牌建设范围，并获得相关专属权益；

　　6.在同等条件下，优先作为省、市“名、优、特”等品牌重点培育对象，可直接赋予相应分数；

　　7.在同等条件下，优先纳入莆田市重点项目或成长型企业的培育发展对象；

　　8.纳入各行业“白名单”，享受企业扶持政策；

　　9.向海关申请适用认证企业管理时予以优先开展认证工作，通过海关认证的企业适用相应的便利管理措施；

　　10.企业信息纳入“信用中国”（福建莆田）数据库。

　　（二）在线评估达到4星以上的企业，可以享受以下优惠政策：

　　1.在同等条件下，政府在购买限额标准以下公共物品、公共服务时予以优先采购；

　　2.优先纳入政府扶持品牌建设范围，并获得相关专属权益；

　　3.优先列入市、县区各部门组织申报的各类专项资金扶持对象；

　　4.在同等条件下，优先纳入莆田市重点项目或成长型企业的培育发展对象；

　　5.纳入各行业“白名单”，享受企业扶持政策；

　　6.企业信息纳入“信用中国”（福建莆田）数据库。

　　（三）在线评估达到3星以上的企业，可以享受以下优惠政策：

　　1.在同等条件下，政府在购买限额标准以下公共物品、公共服务时予以优先采购；

　　2.优先纳入政府扶持品牌建设范围，并获得相关专属权益；

　　3.企业信息纳入“信用中国”（福建莆田）数据库。

　　（四） 经复核查实，企业有下列情形之一的，经相关部门审定同意，撤销其社会责任资格，并予以通报：

　　1.评估期间以欺骗、虚报、瞒报等不当手段故意骗取企业社会责任等级的；

　　2.确定等级后，使用童工、强制劳动、恶意拖欠职工工资及对员工采取侮辱性惩罚措施，发生群体性事件、重大职业病危害事件、经认定的重大安全生产责任事故，生产、加工、销售假冒伪劣产（商）品和发生食品等产品质量安全事故，未完成当地节能主管部门下达的节能目标任务，严重污染环境，长期恶意拖欠税（费）等违反法律法规的一票否决事项的；

　　3.被莆田相关部门及金融机构列入失信企业名单的（或黑名单）。

　　4.企业被撤销社会责任建设评定等级的，经整改，自撤销之日起2年后，可以重新参加市企业社会责任建设的评估申报。

　　5.经评估社会责任建设未达到标准的企业应努力提升社会责任意识，完善企业社会责任建设体系，并根据评价规范开展对标管理，及时改进工作，参与下一轮升级评估。

　　四、工作保障

　　主要是建立制度体系、落实经费保障、推进实践创新、加大宣传力度等内容。一是建立制度体系。把企业社会责任评估工作纳入地方经济社会发展总体规划；成立莆田市企业社会责任评估认定委员会，主管部门为市发改委，由市数字集团组建工作专班组织并委托益联(莆田)企业管理有限公司实施，负责企业责任评估日常组织工作，支持和引导社会资源向积极开展社会责任建设企业倾斜，切实构建激励有效、约束有力的企业社会责任管理制度体系。企业社会责任评估情况同步推送莆惠金服平台系统使用，应用于“白名单”企业滚动管理。二是落实经费保障。 为激发企业社会责任建设主体意识，对于履行社会责任有突出表现或在专项方面作出一定贡献的企业，优先给予补助。莆田市企业社会责任评估工作补助资金一并纳入全国社会信用体系示范城市建设工作经费预算予以保障。三是推进实践创新。引进先进理念，拓宽社会责任工作的国际视野，完善企业社会责任评价体系，实现莆田标准与国际通行标准衔接互通，不断推动我市企业社会责任建设实践创新发展。发挥优秀典型企业示范带头作用，提升核心企业的企业社会责任集聚效应，引领全市企业自觉履行社会责任。四是加大宣传力度。各级各部门要大力宣传我市企业社会责任建设的先进典型和先进事迹，扩大社会影响力，积极营造舆论氛围。认真总结社会责任成功经验，开展形式多样的企业社会责任建设工作宣传交流，适时发布《莆田市企业“社会责任+金融”发展报告》，建立优秀案例传播机制，塑造莆田企业富有高度社会责任感的新形象。
