《莆田市“十三五”海洋经济发展专项规划》 政策解读

来源：本网 时间：2016-07-26 16:48
| | | |
　　一、《规划》出台背景
　　日前，市政府正式下发《莆田市“十三五”海洋经济发展专项规划》（以下简称《规划》）。《规划》以《莆田市国民经济和社会发展第十三个五年规划纲要》（以下简称《纲要》）为指导，坚持党中央提出的“创新、协调、绿色、开放、共享”五大发展理念，抓住福建省打造海丝核心区、加快建设自贸区的重大发展机遇，立足莆田海洋经济发展的比较优势，落实国家和福建省海洋经济的区域战略部署，努力把莆田市建设成为具有后发优势的现代海洋产业集聚区，具有鲜明特色的海湾海岛综合开发示范区，注重可持续发展的海洋生态文明建设先行区，实现由“海洋资源大市”向“海洋经济强市”跨越。
　　“十二五”期间，莆田市大力实施“以港兴市、产业强市”发展战略，发挥港口资源优势，出台一系列推进海洋经济发展配套政策措施，全力打造升级版的蓝色经济，取得了阶段性成效，初步形成了以临港工业、港口物流业、海洋渔业、滨海旅游业和海洋能源产业为主体的具有区域特色的海洋经济发展新格局。2015年，莆田市海洋生产总值达415亿元，约占全市地区生产总值的25.0%，“十二五”期间年均增长率达19.3%，高于全市GDP增速。海洋经济成为推动莆田市经济科学发展、跨越发展的重要支撑，为“十三五”进一步发展奠定了坚实的基础。
　　“十三五”时期是我国经济进入新常态以来的第一个五年规划，大众创业、万众创新的深入推进，供给侧改革加快，以及“中国制造2025”和“互联网+”上升为国家战略，为海洋经济创新发展提供新动能。莆田市主动融入海峡蓝色经济试验区和21世纪海上丝绸之路核心区建设，把发展海洋经济作为实施“以港兴市、产业强市”战略的重中之重。妈祖文化写入国家“十三五”规划纲要，世界妈祖文化中心的建设持续推进，妈祖文化在“一带一路”建设中发挥着积极作用。在这一背景下，《规划》的出台对莆田市加快推进海洋经济强市建设、科学利用海洋资源、拓展发展空间、推动海洋产业转型升级，实现新一轮“海上丝绸之路”共同建设发展具有重大意义。
　　二、未来五年海洋经济发展目标和空间布局
　　（一）发展目标
　　“十三五”期间，莆田市实现海洋生产总值年均增长速度高于地区生产总值增幅2个百分点左右，到2020年海洋经济空间布局和产业结构明显优化，现代海洋产业体系基本建立，海洋生产总值达750亿元，渔业经济增加值达150亿；海洋科技创新能力切实增强，实现海洋科技贡献率达63%。海洋功能区水质达标率达88%，海域一类、二类水面占比达72%，各类海洋功能区环境质量基本达标，海洋生态环境保持优良；海洋经济开放水平大幅提升，形成“北有獐子岛，南有南日岛”的海洋牧场建设示范基地，全面建成海洋经济强市。
　　（二）海洋经济空间布局优化
　　《规划》根据福建省建设海峡蓝色经济试验区、莆田市构建现代产业新格局和“336”工程建设的要求，提出“一带、两核、八园区”的海洋开发新格局。“一带”是指打造妈祖文化蓝色经济带，重点发展滨海旅游业、休闲渔业和海上风电产业，打造世界妈祖文化中心和国家级旅游度假区；“两核”是指建设湄洲湾北岸海洋经济核心区与兴化湾南岸海洋经济核心区两个海洋经济核心区，其中湄洲湾北岸海洋经济核心区重点发展临港能源、化工（纺织化纤）新材料、食品加工、港口物流等产业，兴化湾南岸海洋经济核心区重点发展临港高端装备、电子信息、节能环保、新能源汽车等新兴产业；“八园区”是指重点拓展南日岛现代生态渔业产业发展示范区、后海现代渔业产业园区、平海湾海洋渔业集聚区、石门澳工业园区、东吴临港工业园区、兴化湾南岸工业园区、莆头工业园区和东峤工业园区等八个产业园区。
　　三、未来五年规划的重点任务
　　《规划》提出莆田市海洋经济发展的五大重点任务：推进海洋产业转型升级、实施科技兴海战略、加强海洋生态文明建设、完善涉海基础设施与海洋防灾减灾体系、深化海洋经济开放与合作。
　　（一）推进海洋产业转型升级
　　《规划》提出以重大项目和龙头企业为载体，培育一批海洋经济产业示范基地，提高现代海洋渔业发展水平，集聚发展高端临港产业，培育发展海洋新兴产业，扶持发展现代海洋服务业，构建优势突出、特色鲜明、核心竞争力强的现代海洋产业体系。
　　其中现代海洋渔业重点推进南日岛海洋牧场建设，大力发展渔港经济示范区、水产品精深加工及综合利用、休闲渔业项目和渔业物流贸易产业；高端临港产业重点发展临港化工（纺织化纤）新材料业、临港食品加工业、临港能源工业、临港高端装备业和临港电子信息业；现代海洋服务业重点发展海洋生物医药与制品业、海洋工程装备业、邮轮游艇业、海水淡化与综合利用业和海洋可再生能源业；现代海洋服务业重点发展港口物流业、滨海旅游业、海洋文化创意业、涉海金融服务业和海洋信息服务业。
　　（二）实施科技兴海战略
　　《规划》提出强化科技创新对海洋经济发展的引领和支撑作用，继续深入实施“科技兴海”战略，建立健全海洋人才培养、引进、使用机制，构建海洋科技创新体系；加快海洋科技创新平台和海洋科技创新服务基地建设，推进海洋科技成果转化，创建科技成果转化承载平台，营造科技成果转化市场环境，依靠科技进步加快海洋资源的开发利用，促进海洋经济快速、持续发展。
　　（三）加强海洋生态文明建设
　　《规划》提出科学利用和保护海洋资源，合理开发利用海洋资源，创新海岸带开发模式，科学有序实施填海造地工程，加强资源利用监管；合理保护与开发海岛，创新海岛开发方式，推进无居民海岛规划建设；加强海洋与海岸环境保护，完善陆海污染综合防治体系，加强生态环境监测，推进跨区域海洋污染防治；实施生态保护工程与示范项目，加强海洋生态保护与修复，特别是加强滨海湿地生态保护。
　　（四）健全海洋基础设施与公共服务体系
　　《规划》提出根据海洋经济发展的目标要求，因地制宜、适度超前地配套建设交通、能源保障、供水、物流等基础设施；加快海岛交通设施建设，完善海岛水电气网络体系；健全海洋防灾减灾体系，建立健全海洋防灾减灾预报预警体系、海洋安全生产和海上船舶应急救助体系，加强海洋基础信息服务平台建设。
　　（五）提升海洋经济开放合作水平
　　《规划》提出深化海洋两岸海洋经济合作，提升两岸现代渔业合作水平、推进两岸临港产业深度对接、加强两岸海洋服务业合作、加强两岸海洋环境协同保护、深化两岸海洋综合管理领域合作；加强海洋经济区域协作，包括加强与周边地区海洋经济合作，以及与港澳地区海洋经济合作，加大口岸开放；实施“走出去”与“引进来”战略；积极融入海上丝绸之路建设，提升海洋经济对外开放水平，助力世界妈祖文化中心建设。
　　四、规划实施的保障措施
　　《规划》从加强组织领导和统筹协调、强化重大项目要素保障、创新海洋经济发展体制机制和健全完善监督考核评价体系提出海洋经济建设的保障措施。同时，《规划》筛选汇总84个“十三五”重大项目，总投资2150亿元左右，“十三五”计划投资1620亿元左右。这些项目涉及现代海洋渔业、海洋新兴产业与临港产业、现代海洋服务业、海洋科研平台、标准渔港建设、港口泊位与基础设施建设等方面，支撑“十三五”规划目标任务的实现。
