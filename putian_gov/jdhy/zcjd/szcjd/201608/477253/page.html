莆田市“十三五”工业转型升级规划解读

来源：本网 时间：2016-08-03 09:27
| | | |

    

一、《规划》编制背景意义

（一）背景

    “十二五”期间，面对国际国内环境的深刻变化和国际金融危机带来的重大挑战，在市委、市政府的正确领导下，我市加快工业结构调整、促进产业转型升级，工业保持平稳较快发展，工业实力明显增强，产业结构调整优化、服务体系进一步完善。“十三五”时期，随着工业大项目陆续落地，我市已基本摆脱了传统轻工产业占主导的产业发展格局；电子商务发展迅速，重点工业园区建设加快，工业转型升级已成为全市的共识，已进入产业调整优化的关键时期。

  一方面，莆田市工业面临的新机遇。经济新常态背景下，我国经济发展基本面和长期趋势没有改变，信息化、工业化、城镇化和农业现代化加快推进，新兴产业迅猛发展，《中国制造2025》战略的推进实施，“互联网+”等带来新机遇，为工业升级提供了相对有利的环境。内需主导、消费驱动的政策取向将有力地促进工业产业转型和结构调整，居民消费需求进入升级阶段，将给我市的食品加工、医疗健康、工艺美术、制鞋、电子信息、纺织服装等产业带来新契机。莆田地处沿海，南临珠三角，北接长三角，与台湾隔海相望，是联系华东、华南的纽带区域，同时又处于21世纪海上丝绸之路核心区，港口资源优势明显，随着铁路、公路、港口建设，综合交通网络等基础设施条件日臻完善，将成为海上与内陆连接的新通道，区位条件更加有利。

另一方面，面临着诸多挑战。当前中国经济转型的任务没有完成，供给侧存在产能过剩、库存严重，杠杆不利，原有比较优势逐步削弱，而新的竞争优势尚未形成，经济下行压力明显，这些会直接影响我市工业转型升级的源动力。能源、资源和环境等要素压力增大，劳动力、土地等价格上升，金融瓶颈问题突出，企业资金流动性不足，面临抽贷、压贷、资金周转困难与欠薪、欠款等诸多问题，融资难已经成为常态。一部分企业处于产业链低端的生产加工型企业，附加值低和劳动密集，产品主要以贴牌生产为主，自主品牌不多；战略性新兴产业比重较低，产业集聚度不高；带动和辐射能力强的大企业、大集团、大品牌比较少，产业链不完善；民营中小企业比例多，实行家族式管理，采用低成本、同质竞争的方式，发展方式较为粗放。我市高新技术企业偏少,企业创新主体作用尚未发挥，高端创新要素集聚水平偏低，科研开发、创新设计、职业培训、信息服务、产业总部、创意策划等公共平台，缺乏整体规划和专业服务，各种配套设施还不完善，服务集群效应小。缺少专业型、集群型工业产业园，园区特色不够突出，产业集聚程度低、同质竞争现象突出，单位面积经济总量偏少，园区产业链较短、较窄，生产性服务业滞后。

（二）意义

    加快工业转型升级，是适应经济发展新常态的必然选择，是应对市场需求变化的客观需要，是把握新一轮科技进步和产业变革难得机遇的迫切要求。编制和实施《莆田市“十三五”工业转型升级专项规划》，实现由传统工业化向新型工业化道路转变，通过技术优化、生产优化、组织优化、布局优化、模式优化、政策优化，实现工业整体水平提高，找准莆田市工业定位，抢抓新机遇，迎接新挑战，明确新导向和新任务，主动对接国家制造强国战略，确立政策措施、市场机制的着力点，实施精准发力的产业政策，促进莆田市工业转型升级具有十分重要的意义。

二、主要目标

莆田市“十三五”工业转型升级规划，突出战略性、前瞻性和操作性，全面落实党和国家的重大战略决策，以及省委、市委的重大战略部署，坚持问题导向，体现莆田市工业特色和时代特征；明确莆田市工业转型升级的基础、发展思路、目标任务、重点领域、产业布局、体制机制和政策创新。从规模效益、产业结构、创新能力、绿色发展等四个方面提出了20项指标。主要指标有：

   （一）规模效益。规模以上工业增加值年均增长12%，增加值率比“十二五”末提高约2个百分点，全员劳动生产率年均提高10%左右；工业投资年均增长15%左右。

   （二）产业结构。形成化工新材料、食品加工、工艺美术等3个1000亿元产业集群，电子信息、高端装备、医疗健康等3个500亿元产业集群。

（三）创新能力。工业企业研究与试验发展(R&D)经费占GDP比重提高到1.5%；拥有省级以上工程（技术）研究中心40个、实验室10个、企业技术中心50个、省级工业设计中心10个，院士工作站16个，每万人口发明专利拥有量2件以上；新培育6-8个国家级、省级电子商务示范基地、平台，40个省级两化融合示范企业。

（四）绿色发展。规模工业增加值单位能耗低于全省平均水平，工业固体废弃物综合利用率90%，工业废水排放100％达标，其他节能和环保指标控制在省下达指标内，大型骨干企业主要产品能耗接近国内先进水平；建成5家循环经济示范企业、3个循环经济示范园区。

 三、核心任务

“十三五”期间，做强做优3大支柱产业；培育壮大3个新兴产业；提升4个主要传统产业，转型升级的核心任务：

（一）支柱产业高端化。着力推进化工新材料、食品加工、工艺美术三类支柱产业高端化、集聚化发展，提高支柱产业占工业总量的比重，发挥更大的带动效应。

（二）新兴产业规模化。以重点企业、重大项目为抓手，以创新前沿技术、核心技术为引领，积极培育高端机械装备、医疗健康、电子信息等三个新兴产业，形成产业规模化，优化我市产业现有结构。

（三）传统产业提升化。重点对制鞋、纺织服装、能源、木材等四类传统产业，推进企业重组，创新研发设计，改造工艺流程，提升产品质量，创建知名品牌，提高先进产能，增加产品附加值，推进传统产业转型升级。

（四）工业生产服务化。引导工业企业延伸服务链，促进生产模式从以产品制造为核心，向产品、服务和整体解决方案“三位一体”转变，营销模式从提供产品和设备，向完成咨询设计、项目承接、工程施工、仓储物流、系统维护和管理运营等集成转变。到2020年，大中型制造业企业服务收入占总收入比重达25%以上。

（五）智能制造普及化。“十三五”期间，每年实施“机器换人”300台（套）以上，累计实现1500台（套）以上，有5个项目列入省级以上智能制造试点示范项目，引进和培育2-3个智能装备龙头企业。

（六）工业“互联网+”化。到2020年，建立规上企业两化融合发展水平档案，通过贯标评定的企业达到3家以上，培育2家以上省级工业物联网示范应用龙头企业。

（七）工业布局合理化。高起点、高标准建设石门澳工业园、东吴临港工业园、兴化湾南岸工业园、莆头工业园、仙港工业园、东峤工业园等6个重点拓展的园区；着力建设湄洲湾北岸临港工业基地、兴化湾南岸临港工业基地和文化创意产业基地；明确园区功能定位，实施“一区多园”的产业布局调整。

（八）工业生产绿色化。到2020年单位工业增加值能耗低于全省平均水平，工业废水达标排放，单位工业增加值二氧化碳排放量、化学需氧量和二氧化硫排放量控制在省下达基数内。

四、主要措施

一是实施龙头企业培育，带动转型升级。提出实施产业龙头引领带动专项行动计划，培育壮大一批产业龙头，促进中小企业走“专精特新”发展道路，推进兼并重组，化解过剩产能，降低生产成本，提高供给体系质量和效率，优化产业供给结构。二是实施创新工程，驱动转型升级。实施企业创新专项行动计划，培育企业创新动力、强化创新平台建设、推动重点领域创新、培育制造业众创空间。三是实施品牌质量提升，助推转型升级。实施质量品牌专项行动计划，培育一批质量水平领先、市场信誉好的产品品牌、区域品牌。四是实施产业链延伸，拉动转型升级。围绕龙头企业实施产业链延伸，通过专业分工、服务外包、订单生产等多种方式实现产业融合发展。五是实施项目对接，引导转型升级。强化项目对接、实施产业链招商，促进新型支柱产业形成。六是实施集聚式发展，推动转型升级。实施工业园区改造提升专项行动，整合、建设一批创新能力强、集约程度高、生态效益好的工业园区。七是实施节能减排，倒逼转型升级。实施业绿色制造行动，加快制造业绿色改造升级，构建绿色制造体系。八是实施工业基础能力建设，支撑转型升级。提升工业“四基”水平，加快基础设施建设，夯实工业发展基础。九是实施“两化”融合，服务转型升级。推进信息技术的应用，加强信息服务载体建设，加快电商应用，促进工业与信息化联动发展。十是实施中小企业提升工程，支持转型升级。增强中小企业活力，完善中小企业公共服务平台建设，促进中小企业成长。十一是实施产业国际合作，引导转型升级。加强产业开放合作，推动工业产业实现从产品输出向产业输出的提升。十二是实施供给侧结构性改革，激发转型升级。切实帮助企业降低成本，补齐软硬基础设施短板，扩大资金、土地等要素的有效供给。

    五、主要特点

    一是突出了主题主线。当前，我市工业和信息化发展中长期积累的深层次矛盾日益凸显，粗放型发展模式越来越难以为继。《规划》突出坚持创新、协调、绿色、开放、共享的发展理念，以工业转型升级为主题，以工业发展方式转变为主线，以科技创新和体制创新为根本动力，以实现主导产业高端化、传统产业提升化、新兴产业规模化、生产服务化、制造智能化、业态“互联网+”化、布局合理化、生产绿色安全化为重点，以打造工业产业升级版为目标，以发展临港先进制造业为支撑，以做大做强主导产业、重点园区和龙头企业为引擎。深入实施“336”工程，“抓龙头、筑平台、铸链条、建集群”，努力推进信息化与工业化深度融合、先进制造业与现代服务业互动并进，节能减排与绿色制造协调发展，形成结构优化、质量优良、竞争有力的工业体系，不断增强莆田市工业核心竞争力和可持续发展能力，为推动经济社会发展再上一个新台阶，努力建设宜业、宜商、宜居新莆田提供有力支撑。

二是明确了产业发展路径。产业层面路径。按照“做得大——培育壮大战略性新兴产业，升上去——改造提升传统制造业，发展好——龙头企业带动，淘汰掉——消除落后产能”的基本构想，明确定位，优化结构，扩大总量，提升莆田产业竞争力。企业层面路径。突出重点，分类指导，围绕重点产业链和龙头骨干企业，提高企业工艺、技术和装备水平，增强新产品开发和品牌创建能力；发展优质高效企业，提升莆田企业竞争能力。产品层面路径。加强产品的开发和创新，实施质量品牌战略，完善全员、全过程、全方位的质量管理体系，创建产品质量品牌，提高产品的知名度和美誉度，提升莆田产品竞争能力。

三是强化了可实施性和保障措施。为确保完成《规划》确定的各项目标任务，强化了组织领导、创新工作推进机制、加强规划设计和细化服务措施，同时在政策层面，加大财税支持力度，着力破解融资难题，强化要素保障、强化人才支撑、营造良好环境、构建产业联盟等十个方面具体措施为规划实施提供保障。
