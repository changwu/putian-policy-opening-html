解读《莆田市“十三五”教育发展专项规划》

来源：本网 时间：2016-08-03 10:40
| | | |

 

近日，市政府正式下发《莆田市“十三五”教育发展专项规划》（以下简称《规划》）。现就《规划》的具体内容解读如下：

一、《规划》编制过程

2015年5月8日，市政府印发《莆田市人民政府关于组织开展莆田市“十三五”专项规划编制工作的意见》，明确由市教育局牵头组织编制《莆田市“十三五”教育事业发展专项规划》，并提出具体进度要求。按此要求，市教育局由主要领导亲自抓，指定一名分管领导具体抓，明确由局办公室、计财科负责，各科室办共同做好规划编制工作，按时优质完成各阶段编制工作。2015年上半年已经完成规划总体框架编制，形成初步思路；下半年完成各县区（管委会）教育部门、市直各学校（单位）征求意见，结合全市中小学及幼儿园布局规划（2015-2030年）的编制，完成“十三五”期间教育重大项目的遴选工作；今年年初与我市国民经济和社会发展第十三个五年规划纲要相衔接，今年5月9日，省政府办公厅印发福建省“十三五”教育发展专项规划的通知，市教育局及时加以吸纳完善，形成征求意见稿，于今年7月4日征求各县（区）政府（管委会）、市直相关部门意见，本着能吸收尽量吸收的原则，认真研究、充分吸收反馈意见，再次修改形成《莆田市“十三五”教育事业发展专项规划》。

二、总体考虑

《规划》的起草，充分考虑了“十三五”时期我市教育事业发展的的趋势和要求。“十三五”时期，是国家实施全面建成小康社会、全面深化改革、全面依法治国、全面从严治党重大战略布局的关键时期，也是基本实现教育现代化、基本形成学习型社会，进入教育强国和人力资源强国行列的重要时期。

一是经济发展新常态对教育事业发展提出新的要求。新型工业化、信息化、城镇化、农业现代化孕育着巨大发展潜能，尤其是创新驱动发展、“中国制造2025”、“互联网+”、大众创业万众创新、“一带一路”等国家重大战略，以及“打造莆田产业升级版”、“莆田质造”等重大举措的推进落实，迫切需要提升国民整体素质，迫切需要培养更多的中高端技术技能人才，迫切需要为广大劳动者提供更加便利、优质和多样化的职业技能培训和提高的机会，切实提升劳动者创造附加价值的能力。

二是人口规模结构变化对教育资源配置提出新的挑战。“十三五”期间，新型城镇化进程加速推进，全面实施“全面二孩”政策，全市学龄人口特别是城镇学前教育的适龄人口将迎来较大增长，需要进一步扩大城镇幼儿园和中小学教育资源，增加基础教育容量，城乡教育资源配置，满足新增人口入学需求。此外，随着人民生活水平的提高和医疗条件的改善，加之长期低生育水平的作用，年龄结构日趋老龄化，也迫切要求完善现代教育体系，为所有人的终身学习奠定基础。

三是全社会对教育需求变化对教育质量提升带来新的机遇。国家把“全面提高教育质量”作为“十三五”期间教育发展的主题，“十三五”期间，我市将实现城乡居民收入增长和经济发展基本同步、劳动报酬增长和劳动生产率提高基本同步，居民人均可支配收入达到全省平均水平，提前比2010 年翻一番，随着人民生活水平提高，将释放出更多的对高质量教育的需求，实现有质量的公平教育，成为教育改革发展的新使命，促进人的全面而有个性的发展成为新时期教育发展的重要导向。

三、主要内容

《规划》包括发展基础和面临形势、总体战略、发展任务、实施保障4大部分。

第一部分：发展基础和面临形势。回顾“十二五”期间我市教育事业发展取得的主要成绩，办学条件明显改善；教育信息化全面推进；均衡发展基本实现；校园文化蓬勃发展；办学质量稳步提高；队伍活力不断增强。分析我市教育事业发展存在的问题和面临的机遇与挑战。

第二部分：总体战略。明确了“十三五”教育发展的指导思想，确定了战略目标：建设教育强市，办人民满意教育，按照“明确一个发展目标，加大两项资金投入，打造三个优良环境，培养四支一流队伍，做到五个亲力亲为”的要求，全面推进教育发展，努力实现高考综合成绩“保三争二”，重点大学重点专业录取率进一步提升，重要比赛成绩进一步提高，名家大师在全省的影响力进一步增强，为建设宜业、宜商、宜居莆田提供人才支撑和智力保障。

到2020年，学前三年入园率超过98%、全面解决“入园难”问题，全面推进义务教育优质均衡发展、巩固率稳定在98%以上，全面实施高中阶段免费教育、毛入学率超过96%，实现特殊教育向学前和高中阶段“两头延伸”，莆田学院建设特色鲜明的应用型大学，湄洲湾职业技术学院达到省级示范性高职院校标准，福建电大莆田分校向开放大学转型升级，全面实现“教育强县（区）”，基本满足学习型社会多样化教育需求，新增劳动力平均受教育年限达14年，劳动年龄人口平均受教育年限达12年。

第三部分：发展任务。共有12项发展任务。

一是全面提高教育质量。从加强社会主义核心价值观教育、树立教学工作的中心地位、保护和激发学习兴趣、强化实践育人、促进身心健康成长、提高审美能力与艺术修养、落实社会和家庭育人责任7个方面展开。

二是扩大普惠性学前教育资源。优化幼儿园布局结构、扩大普惠性学前教育资源、提升学前教育保教质量3个方面展开。

三是推动义务教育优质均衡发展。从落实全市中小学及幼儿园布局规划、提高县域均衡发展水平、提升农村学校办学水平。四是普及高中阶段教育。全面改善普通高中办学条件、着力推进优质高中建设、推动高中多样化特色发展3个方面展开。

五是构建现代职业教育体系。从优化职业教育布局结构、推进职业院校专业群对接产业群、提高创业就业能力、促进职业教育与行业产业企业深度融合、加强实训基地建设、提高职业教育人才培养质量6个方面展开。

六是稳步推进高等教育改革和转型发展。打造莆田学院发展升级版、支持湄洲湾职业技术学院创建省级示范校、加快推进福建广播电视大学莆田分校转型升级3个方面展开。

七是促进教育包容发展与机会公平。从提升特殊教育发展水平、大力发展终身教育、完善学生资助体系、促进入学机会公平、关爱特殊群体5个方面展开。

八是推进信息技术与教育教学的全面深度融合。从促进基础教育优质教育资源共享、加快职业教育信息化建设、增强教师信息技术应用能力3个方面展开。

九是鼓励社会力量办学。从扶持社会力量办学、促进民办学校规范办学2个方面展开。

十是打造一流的校长、教师和班主任队伍。从加强职业理想和职业道德教育、落实教师“县管校用”政策、实施乡村教师支持计划、培育和壮大名师队伍、提高教师福利待遇、提高中小学教师专业化水平6个方面展开。

十一是完善教育治理体系。从全面提升教育系统党建科学化水平、深入推进管办评分离、加快建设现代学校制度、完善教育督导评估体系、加强学校校园精细化管理、加强学校档案管理6个方面展开。

第四部分：实施保障。共有8项保障措施。从落实教育优先发展战略地位、落实推进教育改革发展的责任、全面推进重大项目建设和教育综合改革、提高教育经费保障水平、引导社会资本投入教育、推进依法治教和依法行政、切实维护教育系统和谐稳定、动员全社会共同关心支持教育改革发展8个方面展开。
