关于《莆田市人民政府关于印发深入推进新型城镇化及城乡一体化试点建设实施方案的通知》的解读

来源：本网 时间：2016-08-23 09:27
| | | |

 

8月8日，《莆田市人民政府关于印发深入推进新型城镇化及城乡一体化试点建设实施方案的通知》（莆政综〔2016〕119号，以下简称《实施方案》）印发实施，为更好落实文件精神，进一步推动我市新型城镇化和城乡一体化试点建设迈上新台阶，现对《实施方案》出台的背景过程、主要内容等进行解读：

一、《实施方案》起草背景和过程

起草背景：国务院印发了《关于深入推进新型城镇化建设的若干意见》（国发[2016]8号），提出积极推进农业转移人口市民化、全面提升城市功能、加快培育中小城市和特色小城镇、辐射带动新农村建设等四大任务。3月18日，全市新型城镇化及城乡一体化工作会议要求全市上下要统一思想，再凝共识，把加快推进新型城镇化作为事关莆田经济社会发展全局的大事、要事来抓，掀起新一轮新型城镇化和城乡一体化工作新高潮。

起草过程：按照国家批复我市新型城镇化试点的主要任务：推进农业转移人口市民化、推进多元化投融资机制改革、推进行政管理模式和社会治理创新、推进产城融合改革试验等四大任务，结合相关政策文件，起草《关于深入推进新型城镇化及城乡一体化试点建设的实施方案（初稿）》。经过3次意见征求，共征得各县、区（管委会）和新型城镇化及城乡一体化各成员单位共计33个单位的修改意见19条，采纳17条。根据各单位提出的意见进行修改，形成《实施方案（送审稿）》，6月下旬，结合省政府正式印发的《实施意见》，再次衔接修改完善。

二、总体框架与内容概要

《实施方案》分七大部分共37条。

第一部分，积极推进农业转移人口市民化。提出实行无门槛的流动人口户籍管理制度、建立转户农民权益协同保护机制、推动农业人口就地就近城镇化、推进易地扶贫搬迁与新型城镇化结合、完善财政与转移人口挂钩制度、构建多层次的住房保障供应体系、创新进城务工人员随迁子女义务教育阶段就学服务管理机制、构建覆盖城乡的公共就业服务体系、加强职业技能培训能力建设、盘活农村劳动力资源、提升生活救助水平等11个条。主要改革内容有：一是符合条件的居住证持有人，可以在居住地申请登记常住户口，鼓励有能力、有需求的转移人口整户入籍。二是保护转户农民权益，农业转移人员从农村落户城镇后，仍按农村户口享受计划生育政策，继续保留土地承包经营权、宅基地使用权、集体收益分配权。三是实施城镇建设用地新增指标与农业转移人口落户数挂钩，引导农业人口向小城镇聚集，实现就地城镇化。四是以常住人口为基数测算农业转移人口市民化过程中的支出成本，制定合理分配的成本分担机制。五是将外来务工持居住证人员纳入公积金体系。六是农业转移人口符合低保条件的家庭优先纳入低保范围，按照城市低保的标准和水平予以保障。

第二部分，全面提升城市功能。提出加快城镇棚户区、城中村和危房改造，加快城市综合交通基础设施建设，实施城市地下管网改造工程，推进海绵城市建设，推进信息惠民城市和智慧城市建设，完善提升城市公共服务功能等6条。主要内容是落实年初全市城市工作会议要求。

第三部分，优化新型城镇化布局和形态。提出优化行政区划设置、优化工业园区布局、培育发展特色小镇等3条。这其中重要工作是培育发展特色小镇。6月3日，省政府印发《关于开展特色小镇规划建设的指导意见》闽政〔2016〕23号，提出务实、分批推进特色小镇规划建设，力争通过3～5年的培育创建，建成一批特色小镇。我委于5月份起草关于培育创建特色小镇的实施方案，初步提出实施分类管理指导，“十三五”期间，在全市范围内基本建成一批特色产业鲜明、体制机制灵活、人文气息浓厚、生态环境优美、多种功能叠加、示范效应明显的特色小镇，各县（区、管委会）分别创成1个省级特色小镇。目前，已两次征求县区和部门意见，正在根据省文件精神再作修改完善，届时再提交市政府研究审定。

第四部分，推进“幸福家园”和产城融合试点建设。提出深入推进“幸福家园”试点建设、推进产城融合试点、推进农村一二三产业融合发展、积极发展农村电子商务等4条。目前，我委正在修改完善《莆田市“美丽莆田？幸福家园”试点村考评办法（试行）》和《莆田市“美丽莆田？幸福家园”试点村标准化建设工作导则》。

第五部分，推进行政管理模式和社会治理创新。提出推动强镇扩权改革、探索社区治理新机制、创新基层党组织设置等3条。主要改革内容有：一是推进榜头镇“镇级小城市”培育试点、省市级小城镇改革试点及“幸福家园”试点镇改革工作，探索强镇扩权与综合治理创新相结合的改革路径。二是推动社区管理向治理转变，持续推进基层“法治、德治、自治、共治”四位一体建设。三是继续推进“中心村”党委建设。继续探索优化组织设置方式。

第六部分，深化农村产权制度改革。提出推进集体资产股份化改革、创新集体建设用地开发利用机制、健全建设用地指标交易市场、改革和完善宅基地管理制度、完善农村产权交易服务体系等5条。主要改革内容有：一是在符合城乡建设规划和镇村土地利用总体规划的前提下，允许农村集体经济组织自主实施集体建设用地开发利用，利用已取得集体土地使用证的存量建设用地，保持集体土地性质，在符合相关规划的前提下，可参照“三旧改造”政策建设不可分割销售的标准厂房用于出租或自行经营。二是鼓励社会资本参与实施土地综合整治，节余的建设用地指标在土地有形市场公开交易、有偿使用。三是保障农户依法取得的宅基地用益物权，改革完善农村宅基地制度，探索农民住房保障新机制。探索农村宅基地有偿使用制度。探索农户自愿有偿退出宅基地机制。探索农民住房财产权抵押、担保、转让的有效途径。四是适时建立全市农村产权交易中心，优化农村产权价格发现机制。完善农村产权抵押融资中的他项权登记办法。探索农村财产权抵押资产再流转、收储、评估、处置和资产处置损益评估机制，健全农村产权抵押融资风险基金的使用机制。

第七部分，推进多元化投融资机制改革。提出充分发挥政府性资金的基础引导作用、拓宽城镇化融资渠道、推广政府和社会资本合作（PPP）模式、推进农村金融改革、完善农村金融服务体系等5条。主要改革内容有：一是强化财政资金和政策引导作用，通过财政奖补、贷款贴息等方式调动社会资本参与的积极性。二是设立新型城镇化发展基金。三是开展林权、海域使用权、农业设施抵押和农业设备等农村动产抵（质）押贷款。鼓励涉农的融资担保机构开展农村产权融资担保服务。四是在“三农”领域开展小微企业贷款保证保险试点。培育发展新型农村合作金融组织。推动农村基础金融服务全覆盖。

    同时，《实施方案》后附有莆田市“美丽莆田？幸福家园”试点村考评办法（试行）、莆田市“美丽莆田？幸福家园”试点村标准化建设工作导则。《考评办法（送审稿）》包括考评对象、考评原则、考评内容、考评实施等四个方面内容以及《考核表》附表，对全市119个幸福家园试点村规划编制、建设方案、工作机制、试点氛围、项目推进、设施改善、产业培育、村容整洁、改革突破、班子建设等方面内容考评。《工作导则（送审稿）》包括村级组织活动场所标准化建设、村级组织制度标准化建设、环境卫生标准化建设、配套设施标准化建设等四大部分共43条。
