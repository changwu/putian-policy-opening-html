旅游产业发展面临着新形势新问题

来源:莆田市旅游局 时间：2015-09-29 17:48
| | | |

一是新形势

　1、政策优势更加突显。2014年8月国务院发布《关于促进旅游业改革发展的若干意见》，从树立科学旅游观、增强旅游发展动力、拓展旅游发展空间、优化旅游发展环境、完善旅游发展政策等多个方面提出了具体要求。今年5月，省政府出台《关于进一步深化旅游业改革发展的实施意见》，这是继2012年省委、省政府出台《关于加快旅游产业发展的若干意见》后又一重要支持旅游业发展的政策性文件，《意见》从明确旅游业发展目标、加快旅游业转型升级、推进旅游改革创新、深化闽台旅游合作、优化旅游发展环境五个部分进一步明确了旅游业改革发展的方向和重点，加快推动旅游业科学发展、跨越发展。这些政策措施都为莆田市旅游业发展提供了良好的政策机遇,为旅游转型升级、多元发展提供有力依据。

2、区位优势更加明显。莆田是福建沿海中部正在崛起的新兴港口城市，临近福泉厦，与台湾仅一水之隔，距离最近处135KM，陆域面积4200多平方千米，海域面积1.1万平方千米，拥有“世界不多、中国少有”湄洲湾秀屿深水良港，湄洲、南日等150多个风情各异的大小岛屿。随着高速公路网的建设与厦深铁路、向莆铁路、合福高铁的相继开通，与长三角、珠三角、中西部城市连成一片，区域间的距离迅速缩短，交通条件更加便捷，将促进莆田旅游产业更快的发展。南部以湄洲岛为龙头，有效整合平海湾、南日岛等滨海旅游资源，打造妈祖文化朝圣中心和滨海观光旅游度假胜地；中部以宜居城市为主体，有效整合工艺美术等文化旅游品牌，打造荔林水乡生态休闲之城和海峡工艺美术购物之都；北部以九鲤湖、九龙谷为中心，有效整合菜溪岩、瑞云山等生态旅游资源，打造环山生态旅游带和康体养身天堂。

3、旅游资源开发潜力大。随着人民生活质量的不断提升和消费能力的进一步增强，旅游已经从少数人的奢侈品，发展成为大众化、经常性消费的生活方式；从外事接待型的事业，发展成为全民广泛参与就业、创业的民生产业；旅游业已成为一个新的消费增长点，蕴藏着巨大的市场潜力，成为发展最快的新兴产业之一，休闲度假旅游正在日益成为新潮流、大趋势。莆田市是八闽古府之一，历史悠久、文化昌盛，妈祖文化独一无二，南拳发源地南少林寺世界闻名，还有被称为“福建三绝的九鲤湖”和工艺之都的“工艺美术城、古典工艺博览城”等，旅游资源丰富，旅游景区景点较多，是福建最为著名的旅游目的地之一。

4、旅游市场越趋国际化。随着旅游的快速发展，旅游市场已从入境游为主,发展到入出境旅游并重。从近三年统计情况看，莆田接待入境游客总体较为平稳，其中，2012年入境游客24.6万人次，2013年入境游客25.73万人次，2014年入境游客24.81（其中接待外国人4.42万人次，增长3.7个百分点）。特别是湄洲岛国家旅游度假区金字招牌效应依然明显，对台交流逐步深化，目前正在积极申报中国特色国际旅游目的地。

二是新问题

1、旅游发展仍未突破区位洼地的瓶颈。莆田虽然区位优势明显，但其地理位置处于两大旅游城市福州和厦门之间，目前更多的是承担过境地的作用，而非真正意义上的目的地。地理区位的劣势还导致了其客源结构的单一，主要为港澳台同胞以及妈祖信众，虽然客源仍会逐年增加，但是如何拓展客源市场并将过境游客转化成目的地游客，将香客转化为度假客将是莆田旅游发展的重要挑战之一。此外莆田没有自己的机场，远程游客依赖于厦门与福州机场，入境游客受到极大限制。

在旅游交通发生较大转变的背景下，莆田旅游发展应依托“两纵两横”的高速公路网与“三纵一横三联”国省干线布局重新整合，进一步优化，以适应新时期全域化发展要求。

2、旅游发展受限于经济基础薄弱的短板。旅游的发展部分取决于其所依托的城市经济发展状况。长期以来，莆田是以农业为主的经济结构，农业劳动力为主的人力资源状况使得当地的经济基础薄弱，经济总量小，经济实力不强。2014年，莆田GDP达1502亿元，仅为厦门的1/2，接近泉州的1/4，经济能力的薄弱直接影响到旅游产业的发展力度和资金投入。不足的资金投入将直接导致旅游基础设施的配套不足，进而影响到游客的人数、重游愿望和逗留时间等方面。目前莆田旅游景区开发主要还是政府主导，旅游招商引资力度不够，民间资本参与度较低。多数景区包括湄洲岛、南少林、九鲤湖、菜溪岩等建设都缺乏社会资金投入，存在开发规模小、档次低、产品不成熟、对外影响力弱吸引力不足等问题。

莆田旅游开发应加大吸引民间资本，引进具有影响力的旅游开发集团，如港中旅、华侨城等，依托他们的运营优势和品牌优势，扩大莆田旅游的影响力。

3、旅游发展面临着同质竞争的局面。莆田有着各种类型的旅游景区，但景区发展不平衡。一方面，景区的开发重点集中在妈祖文化并以妈祖朝觐旅游为主，以湄洲岛为核心，缺少大规模和极富特色的综合性旅游产品；过分注重对湄洲岛的开发限制了莆田其他宗教型景区的发展，诸如有着一定资源优势的南少林寺遗址、祈梦文化、滨海旅游等。另一方面，除湄洲岛外，莆田其他景区与福建省其他市的旅游资源有着相似性和可替代性，各市都在发展以观光旅游为主的景区，缺乏满足游客需求的休闲度假型和体验型旅游产品；虽然这类景区的观赏价值高，但是其周边县市的服务质量和旅游资源也比较优质，因此无法吸引更多的游客。

莆田旅游丰富多元，但旅游开发上缺乏差异性，不仅没有形成合力，甚至可能会相互排斥，造成恶性竞争；莆田旅游资源优势没有得到最大效能的发挥，应加大资源整合力度，将莆田旅游资源优势发挥到最大。

二、推动旅游扶贫面临的新问题和意见建议

旅游扶贫从80年代提出至今，在国内的一些地区成效显著，一些贫困民众从中得到了脱贫，一些位于贫困区的景区景点被发现被开发；但必须正视旅游扶贫还存在一些问题。

一是旅游扶贫面临的新问题

1、对旅游扶贫的认识不够到位。目前，有的把旅游扶贫看作是单纯的扶贫或者简单将旅游扶贫等同于旅游开发，并没有把旅游扶贫资金用在旅游资源开发上和引导民众发展旅游带动脱贫致富上，造成旅游扶贫效益不高。

2、对旅游扶贫过于包揽包办。有的在旅游扶贫实践中，对旅游开发的可行性论证、开发规划、基础设施建设、投资方确定以及旅游形象设计等方面一手包揽，一定程度上打击了企业和个人的积极性，旅游扶贫效果大打折扣。

3、重视旅游忽视环境保护。有的贫困地区可能为开发旅游，自然环境就遭到破坏，一些果树可能被砍伐，田地挪作接待设施建设，一些原生态可能受到人为的改变。

4、扶贫民众出现受益不均现象。有的误把旅游扶贫作为地区的旅游发展，注重的是公共的利益，整体的发展目标。而忽视贫困民众的参与，大多贫困民众将被排在受益群体之外。

二是推进旅游扶贫的意见建议

旅游扶贫作为一项系统工程，影响扶贫效益的因素是多种多样的，做好旅游扶贫必须多方面协调，下大力解决问题。

1、建立健全旅游扶贫的工作机制。要在充分研究地区条件和外部的基础上，确定旅游扶贫的总体目标，筛选扶贫对象，成立旅游扶贫协调领导小组，明确相关部门的任务和职责，制定工作规则和相关工作机制，确保旅游扶贫和谐高效运转。

2、加强扶贫区的生态环境保护。要坚持旅游开发与环境保护并重的原则，防止不可再生的资源流失，始终把保护环境融入到旅游开发中，旅游开发科学处理生活用水、垃圾、废弃物等，制定一些规章规则限制和约束当地居民和游客，认真协调旅游开发、经济发展与环境保护的统一。

3、多渠道筹措旅游扶贫资金。要采取财政拨款、招商引资以及民众筹措政府补贴等方式组织旅游扶贫，坚持“谁投资、谁经营、谁受益”的原则，保障旅游扶贫工作的稳定发展。

4、注重培养旅游扶贫专业人才。贫困地区的旅游开发和经济发展，不单是靠扶贫资金的投入，也要靠专业人才的投入。有的贫困地区有丰富的旅游资源，但旅游规划、建设、管理等人才缺乏，制约了旅游业的发展。因此，要采取干部挂职、结对子帮扶等措施帮助扶贫对象，教育培养和带动当地的一些旅游管理人才。

三、促进旅游消费、投资和做大做强旅游业的意见建议

今年8月，国务院办公厅出台了《关于进一步促进旅游投资和消费的若干意见》，实施旅游基础设施提升计划，改善旅游消费环境、实施旅游投资促进计划，新辟旅游消费市场、实施旅游消费促进计划，培育新的消费热点、实施乡村旅游提升计划，开拓旅游消费空间、优化休假安排，激发旅游消费需求、加大改革创新力度，促进旅游投资消费持续增长。致力于解决旅游供需矛盾突出，呈现供不应求的状况，解决旅游基础设施投入不足以及潜在的旅游需求难以转化为现实的旅游消费等问题。为此，市旅游局正在积极研究推出促进旅游消费、投资等措施。

   1、扩大旅游休闲消费。结合《福建省国民旅游休闲纲要》和《国务院办公厅关于进一步促进旅游投资和消费的若干意见》，建议将带薪年休假制度落实情况纳入议事日程，作为劳动监察和职工权益保障的重要内容，督促推动机关、企事业单位加快落实职工带薪年休假制度。鼓励弹性休息，在保证每周工作40小时的法定时间内，周五下午不上班，为干部职工周五下午与周末结合外出休闲度假创造有利条件。鼓励有条件的机关单位和企事业等部门逐步实现“两天半”的小短假。

发展购物旅游，打造我市特有的美食品牌，吸收福州、厦门等地的经验，引进先进营销理念，扶持部分商家研发“旅游伴手礼”等系列旅游商品(如馅饼、素饼、即食包装海产品等)，到2020年打造5条集购物、旅游、餐饮、休闲于一体的特色美食街区，争取在有条件的地方设立购物免税店。结合妈祖文化节的开展，设计吉祥物、主题玩偶公仔等周边产品，增加旅游收入。支持特色民宿、度假酒店、主题酒店、生态农庄、汽车露营地等发展，提高来莆过夜游客比重。

建设一批研学旅行基地，鼓励旅游企业对研学旅行给予价格优惠，到2020年，全市建成不少于3处研学旅行基地，并由市教育、旅游等部门联合挂牌管理。按照教育为先、安全第一原则，以爱国主义教育、革命传统教育、乡土乡情教育为主要内容，结合莆田市非物质文化遗产传承工作，建立具有莆田特色的研学旅行体系。根据实际情况，统筹安排中小学生参加社会实践活动时间，完善研学旅行公共设施，制定完善旅行社承办研学旅行服务标准，支持旅行社开发研学旅行、夏令营、冬令营产品。

2、实施品牌引领战略。主动对接 “清新福建”品牌，加快融入构建“清新福建”旅游产品体系、营销体系和服务体系。研究建立“清新福建、妈祖故乡”服务标准规范，构建具有莆田特色的旅游服务标准体系。推动“清新福建、妈祖故乡”标识进景区、星级饭店、旅行社等旅游企业，在动车站、汽车站咨询服务中心、旅游集散中心和各种重要的文化、体育、经贸、外事活动中广泛推广使用“清新福建、妈祖故乡”标识。

3、创新旅游体制机制。推进旅游景区管理体制改革，对全市旅游景区实行分类管理，推进国有景区所有权、管理权和经营权相分离，引进各类社会资本参与国有景区营运。完善旅游景区质量等级评定和社会评价机制，推行景区流量控制、网上门票预订等管理新机制。

加强对景区门票价格监管，利用公共资源建设的景区门票以及景区内另行收费的游览场所、交通工具等项目价格要实行政府定价或者政府指导价，严格控制价格上涨，落实4A级以上景区三年不涨价倡议，落实景区对未成年人、老年人、军人、残疾人等实行门票费用减免的相关规定。

4、深化侨台合作。突出妈祖文化优势，深化莆台妈祖文化交流，大力发展妈祖文化创意产业，以祖地文化、宗亲文化为纽带，深入推动莆台文化融合；要密切两岸基层民众交流交往，积极促成莆台社会融合。

主动靠前，加快建设两岸乡村旅游试验基地，实施“台湾乡村旅游专家莆田行”“乡村旅游业主赴台培训计划”等，拓展莆台在旅游策划规划、行业管理、市场营销、文化创意等方面的交流合作，定期组织相关部门组成交流考察团赴台学习先进经验。借鉴台湾景区管理经验、经营模式和服务标准，改造、提升我市旅游景区服务水平，推动莆台旅游服务标准一体化。

与境内外国际旅行社或在线旅游平台合作，利用妈祖文化在日本、东南亚广泛传播的优势，吸引上述各地区境外游客。加强与日本、东南亚莆田籍民间组织的合作，在当地适度推广妈祖文化节等文化活动。

5、完善旅游公共服务。健全旅游交通体系，优化城市、景区间的交通衔接，实施交通干线与4A级以上景区“最后一公里”通达工程。规范全市旅游景区(点)道路指示标识，推动景区间开通旅游摆渡车、区间车，鼓励在景区间互设旅游导览图。提升A级景区服务功能，按照相关标准改造提升游客中心、旅游厕所、停车场、标识标牌等。

加强与福州、厦门等地的交通对接，实施旅游集散中心、旅游道路、旅游直通车、旅游厕所、露营地、旅游信息咨询平台建设等工程，完善“快进慢游”的全域化便捷交通服务体系。
