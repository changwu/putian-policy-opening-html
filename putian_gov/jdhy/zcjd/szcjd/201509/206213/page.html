莆田市气象局贯彻落实加快推进气象现代化建设的措施

莆政综[2015]29号文件解读
来源:莆田市气象局 时间：2015-09-01 17:37
| | | |

现阶段我市气象现代化目标是，到2018年，基本建成适应需求、结构完善、功能先进、保障有力的气象现代化体系，在台风、暴雨洪涝、局地强天气、寒冻害等预报准确率、气象防灾减灾、公共气象服务等方面达到省内同级领先水平。根据莆田市政府印发的《莆田市人民政府关于加快推进气象现代化的实施意见》（莆政综[2015]29号），结合我市气象部门现有条件，气象局采取了多项举措加快推进气象现代化建设。

一、加快推进莆田气象雷达系统建设

莆田地处沿海，天气现象复杂多变，年降水量1200-1600毫米，夏季阵性强降水频繁，灾害性天气时有发生，比如刚刚过去的13号超强台风“苏迪罗”，就是在莆田登陆。为了提高气象预测预报水平，确保防灾减灾气象服务万无一失，我市正在建设的气象雷达系统包括了风廓线雷达和X波段移动雷达，预计到2017年竣工投入业务运行。而相关的雷达预警预测中心，雷达数据处理中心，配套建设道路等基础设施将在2016年前建设完成。有了雷达这个“千里眼”的监测预警，气象雷达产品的开发应用，我市的灾害性天气预报预警能力以及防范水平将更上一层楼。

二、继续完善自动气象监测网建设

建设布局合理、网格间隔科学的自动气象站网是气象防灾减灾的必要条件，自动气象站每天无时不断地监视着温湿度、气压的变化；风向风速、太阳辐射的影响；降水量、能见度等气象要素。气象台站根据对这些数据的分析，结合气象卫星、气象雷达探测数据判断未来天气发展趋势，进行预测预报。

目前全市已初步建成覆盖所有乡镇的自动气象站网，但因各乡镇的地理环境差异较大，人口稠密不同，对于防灾减灾的需求不尽相同。因此自动气象监测网建设目标是，到2017年，建成陆地自动气象站点与点间距小于8公里，沿海地区小于6公里，重点区域小于3公里的自动气象站网。新建秀屿GNSS/MET地基水汽遥感监测站和闪电定位仪、仙游小型空间天气监测站，在全市布设6套大气电场仪。针对各种气象灾害类型以及不同服务需求建立了强雷电、山洪、地质灾害、交通气象、旅游气象、环境气象等专业气象监测网。对于已建成的区域自动气象站网进行升级改造及补充完善。

三、气象信息网络建设

气象监测网建立完善后，有了气象数据，还要求数据能及时有效地上传下达，左右贯通，以便各级气象部门根据气象要素的变化及时作出预测预警。这就需要有快捷的气象通信网络。气象通信网络建设目标是气象主干通信网络市、县（区）宽带接入将分别达到200M、80M。省内国家级自动站数据到达时间将小于1分钟，省内区域自动站和雷达数据到达时间将小于3分钟。到2017年，将和多部门建立气象信息共享机制，实现气象、水利、水文、环保、海洋、国土、交通、公安等部门间及市、县、乡四级信息的同步共享。目前已建设的国家突发事件预警信息系统可以为党中央国务院提供直通式预警快速送达服务、为各级部门提供全天候预警综合发布渠道与信息共享服务、为应急负责人提供全程跟踪预警服务、面向公众提供权威预警信息的准确发布。天气变化尤其是灾害性天气情况将直接快速地传达到各相关部门，这对于防汛办的抗旱防洪指挥，政府部门的决策指导将给予气象方面的有效协助，尽可能地减少气象灾害带来的损失，做到灾害性天气早知道、早部署、早预防。

四、海洋经济气象保障工程建设

莆田是沿海城市，结合“以港兴市、产业强市”的战略构想，我们要提高海洋经济气象保障能力。依托市级项目“莆田市海洋经济气象保障工程”，重点建设莆田海洋气象综合观测系统、精细化海洋气象灾害预报预警系统，2017年建设完成海洋气象服务系统、海洋气象灾害风险评估系统、海洋气象预报预警服务平台，以及针对港口航运、海洋渔业、滨海旅游等公共气象服务平台，加强莆田海洋经济气象保障服务能力。莆田市海洋经济气象保障工程属于莆田市基础性公益事业项目，围绕提高海洋气象保障能力建设，集综合观测、预报预警、气象服务、风险评估、服务保障为一体，基本建成设施齐备、功能先进、服务高效的海洋气象现代化体系，基本实现预报精准化、服务社会化、保障标准化。项目计划总投资约1400万元，预计2016年前完成项目一期工程。目前项目按照海洋经济气象保障工程建设进度，主要是对自动站、海洋气象观测站、演播室余下设备等的购置进行部署，并落实勘察费的公开招投标事项。

五、进一步发展精细化气象预报业务

依托“莆田市气象灾害信息预警系统”，提高高分辨率天气预报业务能力。到2016年的时候，完成精细化气象预警预报业务系统建设，全面实现气象预报精细化到城区、乡镇、景区，海区预报精细化到3公里内。尤其是完善中小河流洪水和山洪地质灾害防治的精细化预报预警。精细化预报使天气预报在时间尺度、空间尺度上都更加精细，从而为公众提供更加个性化、有针对性的预报预警服务。

六、人工影响天气标准化建设

莆田市年降水量虽然比较大，但降水时空分布不均匀，一年四季都有可能出现旱灾，各季节连旱也时有发生，给当地经济建设、工农业生产带来较大影响。水资源的短缺成为制约我市经济快速发展的主要瓶颈。

开展人工增雨作业是科学开发空中云水资源和服务“三农”的有效措施之一，对缓解莆田秋冬季水资源紧张局面将起到积极作用，特别在农业抗旱、增加水库蓄水发电和解决民众生活用水等方面将发挥着重要作用。

莆田市人工增雨工程建设主要包括莆田市人工增雨作业标准化作业基地建设和地面烟炉作业站点建设2个方面。

1、在每个县（区）及东圳水库、金钟水库等流域建立人工增雨作业标准化作业基地，配置新型高程火箭发射系统和存贮人工增雨火箭弹防爆箱。

2、地面烟炉作业主要针对空域受限无法开展火箭地面人工增雨而替代开展人工增雨的一种技术手段，因莆田空中航线密集，申请火箭增雨作业空域难度较大，为了不错过任何人工增雨作业机会，设置地面烟炉作业点开展人工增雨是一种安全、可靠的作业方式。本项目计划投资225万元。

七、强化为农气象服务体系

以“两个体系”建设为抓手，打造适应莆田现代农业、特色农业发展的气象服务体系，开展农业生产经营的直通式气象服务。加强农村气象灾害监测预警能力建设，加快推进标准化气象灾害防御乡镇建设，开展抗旱、森林防火及水库增蓄等方面的人工影响天气作业服务。完善乡镇气象信息服务平台，优化气象信息显示终端，实现气象灾害预警信息在农村地区的全覆盖，使城乡基本公共气象服务更加均等化。到2016年完成城乡一体化的公共气象服务体系建设。气象科普基地建设也将得到加强，气象局积极开展各类气象科普宣传活动，采取纵向服务横向联动方式，多渠道、多方位大力促进气象科普宣传，提高全民防灾避险能力，扩大气象灾害防御志愿者队伍。到2017年，气象科普教育将纳入中小学生“第二课堂”教育活动，气象灾害应急避险和自救互救知识普及率将达到80%。

八、加强组织领导

市政府办公室成立加快推进气象现代化工作领导小组，负责全市气象现代化工作的组织协调。各级政府把气象现代化建设作为政府公共服务体系建设的重要内容，明确分管领导，落实工作部门，健全政府主导的气象现代化建设工作机制。落实保障资金，保障气象现代化建设顺利实施。加大科技和人才支撑，组建市级科技创新团队、建设科技创新机制、加强气象应用领域合作。并且鼓励社会力量参与，促进资源共享，增强优势互补。

气象局将从以上八方面着手努力，加快推进气象现代化，为公众提供更准确的预报、更优质的服务。

 

 

                                                                         2015年9月1日
