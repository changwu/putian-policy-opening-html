关于莆田市争创国家二类语言文字规范化城市工作实施方案的解读

来源:莆田市教育局 时间：2015-09-01 09:53
| | | |

 

创建国家二类语言文字规范化城市是贯彻实施《中华人民共和国国家通用语言文字法》和《福建省实施〈中华人民共和国国家通用语言文字法〉办法》，实现“普通话初步普及”、“汉字的社会应用基本规范”和加强城市文明建设的工作要求。4月29日，市政府印发了《莆田市争创国家二类语言文字规范化城市工作实施方案》（以下简称方案），明确了此次争创工作的组织领导、评估范围、内容、程序、创建步骤以及职能部门责任分解，为创建工作奠定了基础。现解读如下：

　　一、创建工作的组织领导

　　成立市级争创国家二类语言文字规范化城市工作领导小组，组长由市政府分管副市长担任；副组长由市委办、市政府办、市人大教科文卫委、市政协科教文卫委、市委组织部、市委宣传部、市人社局、市教育局、市工商局领导担任；成员由市直机关党工委、市财政局、市经信委、市民宗局、市军分区政治部、市公安局、市交通运输局、市文化广电新闻出版局、市卫计委、市体育局、市工商局、市旅游局、市邮政管理局、市住建局、市民政局、市妇联、市执法局、湄洲日报社、莆田晚报社、市总工会、团市委、市文联等单位分管领导组成。领导小组下设办公室，办公室与莆田市语言文字工作办公室（以下简称“市语委办”）合署办公。荔城区、城厢区参照市本级相应成立领导小组。

　　二、二类语言文字规范化城市的评估范围

　　城市评估的范围:一类城市指直辖市、省会、自治区首府、计划单列市等的城区部分;二类城市指地级市城区、地区行署所在地城区、一类城市所辖地级郊区(县)政府所在城镇;三类城市指县级市城区、县和一类二类城市所辖县级郊区(县)政府所在城镇，城市评估涉及的领域有党政机关、学校、新闻媒体、主要的公共服务行业。本《方案》明确对市本级、荔城区、城厢区的四个重点领域进行评估：

　  一是党政机关：定点检查市政府办公室、荔城区、城厢区政府办公室，市教育局、市文化广电新闻出版局；随机抽查市本级、荔城区、城厢区单位，以及荔城区、城厢区社区。

二是学校：随机抽查中心城区各级各类学校。

　　三是新闻媒体：定点检查湄洲日报社、莆田电视台；随机抽查电视台任一频道节目、专题节目以及至少三条自制广告；随机抽查今年报纸任一期。

　　四是公共服务行业和公共设施：随机检查火车站、长途汽车站，一个银行（储蓄所）或邮局、医院，一个影剧院或体育馆、博物馆、公园，一个大型宾馆、商场；随机检查街道牌匾、公共交通名牌、公共设施标志牌、交通指示牌各三处。

　　三、二类语言文字规范化城市的评估内容

　　主要评估用语和用字两个方面

用语方面规定在三种情形下的不同使用要求：

    1.下列情形以普通话为基本用语（国家法律规定可以使用方言或者少数民族语言的除外）：国家机关工作人员在办公、会议、面对社会公开讲话等公务活动时的用语；学校及其他教育机构的教育教学用语；广播电台、电视台的播音、主持和采访用语，影视用语，汉语文音像电子出版物的用语；商业、旅游、文化、体育、铁路、城市交通、邮政、电信、银行、保险、医院等公共服务行业的服务用语。

　　2.下列人员的普通话水平应当分别达到相应等级标准：播音员、节目主持人和影视、话剧演员为一级乙等（92分）以上水平；教师和申请教师资格的人员为二级乙等（80分）以上水平，其中语文教师和对外汉语教学教师为二级甲等（87分）以上水平、普通话语音教师为一级乙等（92分）以上水平；国家机关工作人员为三级甲等（70分）以上水平；公共服务行业中直接面向公众服务的广播员、解说员、话务员、导游等为二级乙等（80分）以上水平。

　　3.与香港特别行政区、澳门特别行政区和台湾地区开展经济文化交流和其他交往活动，可以根据需要使用方言。

　　用字方面有四个方面的要求

　　1.下列情形应当以规范汉字为基本用字：公务用字；学校及其他机构的教育教学用字；汉语文出版物用字；影视屏幕用字；公共服务行业用字；道路、建筑物的名称标识以及公共场所的设施用字；广告、招牌用字；商品包装、说明用字；法人和其他组织的名称用字、人名用字；汉字信息技术产品的用字；网站面向公众的用字。

　　2.广告中使用的语言文字，用语应当清晰、准确，用字应当规范、标准。

　　建筑物的命名、店铺名称要遵守国家的有关规定，不得使用不科学、不规范、名不副实、格调低俗的名称。

　　3.招牌中的手书字，提倡使用规范汉字。在公共场所使用繁体字、异体字的手书招牌，应当在明显的位置配放规范汉字的招牌。

　　4.在公共场所的用字不得单独使用外国文字或者汉语拼音。需要配合使用外国文字或者汉语拼音的，应当采用规范汉字为主，外国文字或者汉语拼音为辅的形式，规范汉字的字体应当大于外国文字或者汉语拼音。

　　各类汉语文出版物不得在汉字标题或者行文中将可用汉字表达的词汇用外国文字代替，专业术语、缩略语确需使用外国文字的除外。

　　5.国家机关工作人员、教师、医务人员、编辑、记者、汉字字幕制作人员、校对人员、学生以及从事印章、牌匾、广告制作等工作的人员的汉字应用水平，应当符合国家相应的规定。

　  四、二类语言文字规范化城市的评估程序

　　评估工作主要有五个环节：一是听取受检部门、单位关于开展语言文字工作的情况汇报（自评报告）；二是查阅《莆田市迎评“国家二类城市语言文字工作达标评估”主要任务细则》中规定的文件、资料（含原始材料、图片等）；三是与受检部门、单位的有关人员进行座谈；四是按照《莆田市语言文字工作二类达标城市评估责任单位主要职责和任务指标》中规定的指标及要素，在规定的抽样范围内进行实地检查；五是汇总评分，分析认定，形成评估报告。

五、创建步骤

2015年4月月下旬开始启动，12月中、下旬，接受省二类城市语言文字工作评估，采取五个步骤完成：

　　 （一）动员部署阶段（2015年4月下旬）

1.市政府组织召开迎评工作动员大会，传达、学习城市评估政策文件精神，安排部署迎评工作任务。

2.荔城区、城厢区及各部门、各单位成立迎评领导小组，制定迎评工作方案，建立健全语言文字工作管理制度；组织干部职工认真学习《中华人民共和国国家通用语言文字法》、《福建省教育厅、省语委关于开展福建省二类城市语言文字工作检查评估的通知》（闽教语[2005]1号）。

3.市语委组织收集各单位创建工作负责人、经办人名单、联系电话等信息，召开经办人会议，进行政策、法规、业务培训；必要时组织考察观摩，学习其他城市语言文字迎评工作经验。

（二）具体实施阶段（2015年5－6月）

    1.从5月上旬起至6月底，以党政机关、学校、新闻媒体和窗口服务行业为重点，组织普通话培训、测试，使规定范围人员的普通话水平达到规定的等级。普通话培训、测试对象为年龄在55（含）周岁以下的党政机关、学校、新闻媒体和窗口服务行业的正式工作人员。培训、测试率必须达到100％。

2.各单位按照《莆田市语言文字工作二类达标城市评估责任单位主要职责和任务指标》（见附件1）逐项进行对照实施，材料要求做到完整、规范、齐全。

（三）自查整改阶段（2015年7月—9月）

1. 7月，各部门、单位对照《莆田市语言文字工作二类达标城市评估责任单位主要职责和任务指标》，进行逐项自查，制定整改方案。

2. 8月，各部门、单位根据整改方案，逐项落实整改措施；成立档案收集、整理小组，开展档案收集整理工作。

3. 9月，以系统为单位开展一次自查，并选择现场，召开一次经验交流会。

（四）检查落实阶段（2015年10月—11月）。

1. 10月，各部门、单位通过自查自评确认达到合格标准，具备接受评估条件后，向市语委提出评估验收申请，市语委组织专家小组进行抽查试评。2015年10月下旬进行阶段小结，市语委根据初查试评阶段存在的主要问题提出整改意见。

2. 11月，各部门、单位根据初查试评阶段提出的整改意见进行整改，并自主组织复查，同时完成档案收集整理工作。

（五）迎接评估阶段（2015年12月）

12月上旬，各部门、单位做好评估前的各项准备工作，包括按要求做好迎评宣传工作（制作宣传展板、宣传标语、灯箱广告）；高标准完成档案资料装订工作。市语委组织专家对重点受评对象进行一次检查，汇总、整理有关材料向市政府汇报，经批准后向省语委提出评估验收申请，并报送自查自评报告12月中、下旬，接受省二类城市语言文字工作评估。

六、责任分解

由于评估工作涉及社会生活的方方面面，是一项系统工程，各级政府及其有关职能部门必须各司其职、条块结合、齐抓共管，才能形成合力，确保评估效果。主要涉及：全市综合管理部门、党政机关、学校、新闻媒体和公共服务行业等，《方案》对这些领域进行了责任分解，确保评估工作有序进行。

　　 “综合管理”，包括组织领导、工作机构、管理措施、法制建设、宣传工作等要素。由市语委办牵头，市编办、市财政局、市人社局、市文化广电新闻出版局配合抓落实。

　　 “党政机关”，包括制度建设、普及普通话、社会用字管理等要素。由市人社局牵头，市直机关党工委配合抓落实。

　　“学校”，包括制度建设、普及普通话、社会用字管理等要素，由市教育局牵头负责抓落实。

　　 “新闻媒体”，包括制度建设、新闻媒体用字培训、广电系统普及普通话、社会用字管理等要素。由市委宣传部牵头，市文化广电新闻出版局、湄洲日报社、莆田晚报社配合抓落实。

　　“公共服务行业和公共设施”，包括制度建设、普及普通话、社会用字管理等要素。由市语委办牵头，市工商局、市经信委、市住建局、市交通运输局、市卫计委、市邮政管理局配合抓落实。

为便于量化考评，制定了《莆田市语言文字工作二类达标城市评估责任单位主要职责和任务指标》，采取量化评分的方式，对评估指标和素、评分标准和评估依据进行了明确。其中：综合管理60分，党政机关39分，新闻媒体60分，学校61分，公共服务行业和公共设施40分，共计260分。

同时，为便于被评估单位做好迎评准备，制定了《莆田市迎评“国家二类城市语言文字工作达标评估”主要任务细则》，对全市各市直部门、学校、新闻媒体、公共服务行业和各县（区）政府、管委会）需完成的任务的提供的材料进行详细说明。

                                                                                     莆田市教育局

                                                                                     2015年8月31日
