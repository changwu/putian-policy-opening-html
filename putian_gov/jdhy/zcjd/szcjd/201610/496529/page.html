解读莆田市贯彻实施质量发展纲要2016行动计划

来源：本网 时间：2016-09-12 17:08
| | | |

 

近日，莆田市人民政府办公室按照《省政府办公厅关于印发贯彻实施质量发展纲要2016年行动计划的通知》（闽政办[2016]105号），结合我市实际，制定印发了《贯彻实施质量发展纲要2016年行动计划》（莆政办[2016]143号）（以下简称《行动计划》），对我市2016年贯彻落实《质量发展纲要（2011－2020年）》的工作重点做出明确部署，强调要以提高发展质量和效益为中心，开展质量品牌提升行动，加强供给侧结构性改革，推动建设质量强市。为更好的推动《行动计划》的实施，现就该文件进一步解读如下：

      一、主要内容

     《行动计划》以十八届五中全会精神为指导，以提升质量水平和培育品牌为主线。总体框架分为五个部分十七项具体内容，从“增强质量和品牌提升的动力”、“优化质量和品牌提升的环境”、“培育质量和品牌竞争新优势”、“夯实质量和品牌提升的基础”、“实施质量和品牌提升工程”五个方面，对我市2016年质量工作进行了安排部署，以更好的发挥政府、企业、社会多元主体的重要作用，加快推动质量提升和品牌建设。

     第一部分从增强质量和品牌提升的动力角度，突出在深入开展质量提升行动、大力提高劳动者职业技能和质量素养、积极推动质量工作创新、鼓励采用先进的管理制度和先进标准、大力推动品牌建设等五个方面提出措施，具体是：大力开展改善消费品供给专项行动，组织实施消费品质量提升工程。实施国家高技能人才振兴计划，提高劳动者职业技能和质量素养，塑造精益求精、追求质量的工匠精神。广泛开展质量改进、质量攻关等多种形式的群众性创新活动，推广应用质量奖获奖者的质量管理方法和模式，推行企业产品和服务标准自我声明公开和监督制度，打造一批安全优质农产品品牌、食品品牌等知名品牌。为提升质量、培育品牌打牢根基。

  第二部分从优化质量和品牌提升的环境角度，以加快质量整治淘汰落后产能和化解过剩产能、加强重点领域质量安全监管、加快质量诚信体系建设、加快构建质量和品牌社会共治机制、加强质量工作考核、发挥新闻媒体的宣传引导和舆论监督作用六个方面对工作进行部署，具体是：加强质量整治淘汰落后产能和化解过剩产能。依法严厉打击质量违法和侵权盗版行为，加强农产品质量安全执法及成品油市场监管，深化食品药品重点领域专项整治。加快推进重要产品追溯体系建设，强化全过程质量安全管理与风险控制。建设完善信用信息共享平台，加快归集、整合包括产品质量、知识产权等在内的信用信息，实施信息信用共享交换。加快构建质量和品牌社会共治机制，深入开展政府质量工作考核，充分发挥新闻媒体的宣传监督作用。为质量和品牌的提升构筑良好的发展环境。

   第三部分从培育质量和品牌竞争新优势角度，提出推动外贸优进优出、促进电子商务产业提质升级等重要举措，具体是：降低企业进出口成本，加快通关速度，加快培育新型贸易方式，推动外贸优进优出。指导电子商务生产企业改进生产工艺，提高标准执行力，严查电商产品质量违法案件，促进电子商务产业提质升级。为质量和品牌提升提供新动力。

    第四部分夯实质量和品牌提升的基础，从充分发挥质量技术基础的支撑作用、加强质量和品牌教育及文化建设等对工作进行部署，具体是：完善质量品牌的法律法规体系，充分发挥计量、标准、认证认可、检验检测等质量技术基础的支撑作用，加强质量品牌教育和文化建设。为质量和品牌的提升保驾护航。

    第五部分实施质量和品牌提升工程，从实施质量和品牌重点工程、实施质量和品牌标杆对比提升工程等对工作进行部署，具体是：积极开展知名品牌示范区创建、品牌价值评价，实施制造业创新中心建设、智能制造、工业强基等工程开展创建社会信用体系建设示范城市、国家农产品质量安全县、质量安全示范区创建活动，为今年的质量提升和品牌建设工作明确了工作重点，并提出今后的工作目标。

二、主要特点

今年《行动计划》的制定，始终贯穿大质量工作理念，内容中充分体现了产品、工程、服务、环境领域质量工作的新要求，明确了职责分工。特别注重对大质量体制机制的建设，提出加快构建“政府主导、企业主体、部门协作、社会监督”的大质量工作格局的要求，为我市质量工作创新发展提供坚实保障。

     一是《行动计划》突出与国家战略的紧密对接。《行动计划》充分体现了质量工作要始终服务于国家的重大战略需求，加强供给侧结构性改革,开展质量提升的行动,其根本目的是为了提质增效,转变我国经济发展方式,切切实实推动质量强国建设。

　  二是《行动计划》突出质量提升。《行动计划》将质量提升放在首要的位置。质量发展进入了新的战略高度,要坚持以质量和效益为中心,必须着力在提升质量上下功夫,保持中高速增长,迈向中高端水平,把经济社会发展推向“质量时代”。只有全面质量提升才能把中国制造变为优质制造,体现“中国制造向中国创造转变,中国速度向中国质量转变,中国产品向中国品牌转变”的战略思想。

　　 三是《行动计划》强调品牌建设。《行动计划》中关于品牌建设的具体措施占有相当的比重。如创品牌,继续做好工业企业品牌培育，大力推动品牌建设;加快构建质量和品牌社会共治机制;加强质量和品牌教育及文化建设;实施质量和品牌重点工程;实施质量和品牌标杆对比提升工程等。要以质量树品牌,以品牌促质量,加快培育、提升、壮大质量品牌,着力提升质量供给水平,使人民群众对质量的“获得感”稳步提高。

四是《行动计划》体现了要积极应对新形势带来的质量挑战。《行动计划》对指导电子商务生产企业改进生产工艺,提高标准执行力；完善电子商务产品质量信息公共服务平台,实现信息融合共享；完善“风险监测、源头追溯、属地查处、信用管理”机制,加快推进电商产品质量监管制度、体制和机制建设提出具体措施。

五是《行动计划》突显了培养“精益求精”质量精神。《行动计划》中强调要大力提高劳动者职业技能,要实施国家高技能人才振兴计划,为中小企业培养专门人才;鼓励高校加快与质量品牌相关的人才培养，要塑造精益求精、追求质量的工匠精神。还充分发挥新闻媒体的宣传监督作用,大力宣传“工匠精神”,激发全社会的认同感。
