莆田市人民政府办公室关于印发莆田市自然灾害避灾点建设管理暂行办法的通知（莆政办〔2017〕11号）政策解读

来源：本网 时间：2017-01-25 08:37
| | | |

一、出台《莆田市自然灾害避灾点建设管理暂行办法》有何意义目的？ 

出台《莆田市自然灾害避灾点建设管理暂行办法》是为进一步规范我市自然灾害避灾点建设管理，提高我市自然灾害避灾点建设管理水平，切实为市民防灾避灾提供安全、规范、保障到位的自然灾害公共应急避难场所。

二、如何确定自然灾害避灾点使用条件和安置对象？

自然灾害避灾点安置因地震、洪涝、冰雹、台风、雨雪、山体滑坡、泥石流等自然灾害造成或可能造成生命财产损失等须转移安置的当地群众和外来人员。

三、自然灾害避灾点服务性质如何？

避灾点无偿提供安置救助服务。

四、我市自然灾害避灾点如何分级分类？

自然灾害避灾点分为县、乡、村三级。全市建有自然灾害避灾点1200个，其中县级20个、乡级180个、村级1000个。要求县级避灾点容量不小于300人，乡级避灾点容量不小于200人，村级避灾点容量不小于100人。避灾点分为A、B、C三类建设。其中县级、乡级避灾点要求全部建成A类；村级避灾点建设要求A类、B类至少各占三分之一，具体分布由县（区、管委会）在县域范围内安排确定。县（区、管委会）民政部门负责分类建设考评验收。

五、对自然灾害避灾点选址有何要求？

    避灾点的选址应充分考虑场地安全性要求，综合考虑地形、地貌、气象、水文、地质等条件，应避开地震断裂带和可能遭受泥石流、山体滑坡、洪涝等自然灾害威胁的区域或地段。

根据各地实际情况，按照相对集中、便于转移、就近安置、确保安全的原则，选址建设避灾点，可以新建，也可以综合利用现有公共场所设施。县级避灾点可利用现有人防工程、体育馆、影剧院、会场、学校、社会福利设施等公共建筑；乡级避灾点可利用乡镇敬老院、文化中心、学校、食堂等符合避灾安置要求的公共设施；村级避灾点可利用礼堂、村部、老人活动中心、幸福院、中小学及祖厝、祠堂等公益活动场所。

   六、对A类避灾点建设有哪些要求？

1、硬件设施

   （1）基本设施：自然灾害避灾点应设置办公室(值班室)、避灾群众男（女）宿舍、救灾物资仓库、厨房、卫生间等功能分区。县级、乡级避灾点同时应设置临时医疗点。

   （2）物资配备：避灾点平常至少应储备满足半数容量的床铺、被褥、草席等睡眠用具、锅碗瓢盆等餐饮器具、毛巾牙刷等洗漱用品以及其他日常用品等基本生活物资。食品、饮用水可以临时采购或与附近的饭店、商场、超市等业主单位签订协议提供。

（3）标志设置：避灾点建筑外墙或其他醒目位置设置自然灾害避灾点铭牌。避灾点主要进出路口的醒目位置应设置避灾点路线指示牌。

2、软件设施

（1）管理制度：自然灾害避灾点应制订避灾点管理制度、管理人员职责、避灾人员守则，做到制度健全、管理规范、责任明确、运转高效。

 避灾点救灾物资仓库应建立仓库管理制度和物资出入库登记管理帐目。

    （2）宣传设施：自然灾害避灾点应张贴悬挂防灾减灾宣传图片资料。

   七、对B类避灾点建设有哪些要求？

1、硬件设施

   （1）基本设施：自然灾害避灾点应设置办公室(值班室)、避灾群众男（女）宿舍、救灾物资仓库、卫生间等功能分区。

   （2）物资配备：避灾点平常至少应储备满足四分之一容量的床铺、被褥、草席等睡眠用具、锅碗瓢盆等餐饮器具等基本生活物资。

（3）标志设置：避灾点建筑外墙或其他醒目位置设置自然灾害避灾点铭牌。

2、软件设施

    管理制度：自然灾害避灾点应制订避灾点管理制度、管理人员职责、避灾人员守则。

避灾点救灾物资仓库应建立仓库管理制度和物资出入库登记管理帐目。

   八、对C类避灾点建设有哪些要求？

 1、硬件设施

   （1）基本设施：自然灾害避灾点应设置办公室(值班室)、避灾群众男（女）宿舍、卫生间等功能分区。

   （2）物资配备：避灾点平常可不储备物资，需要时由县（区、管委会）或乡镇（街道）民政部门临时调运提供。

   （3）标志设置：避灾点建筑外墙或其他醒目位置设置自然灾害避灾点铭牌。

 2、软件设施

    管理制度：自然灾害避灾点应制订避灾点管理制度、管理人员职责、避灾人员守则。

    九、 对避灾点日常管理有何要求？

1、预案管理。针对当地灾害特点，结合本行政区域内自然灾害避灾点分布情况，从指挥机构、灾害预警、启动机制、联系方式、转移路线、疏散引导、安置程序、物资储备和信息传输等方面，制订避灾点启用预案，每年3月底前进一步修订完善，并至少组织一次避灾点启用演练。

2、物资管理。自然灾害避灾点的储备物资应设置仓库存放，指定专人负责，并建立账目，定期进行检查，损耗物资及时维修和补充。自然灾害发生之前，应预测转移安置人数，组织应急补充适量的生活必需品。每次避灾任务结束后，避灾点工作人员应对避灾点物品进行整理、清洗、消毒、核查，重新入库，对消耗物品和所产生的费用进行登记造册报请核销。避灾点负责人要及时向业务主管单位上报避灾人次、物资消耗和需补充的各类物资等情况。

    3、场所管理。避灾点场所平常管理以权属单位为主，避灾设施维护、使用和避灾点启用管理由业务主管单位负责，业务主管单位县级为县（区、管委会）民政部门，乡级为乡镇政府（街道办事处），村级为村（居）委会。避灾点具体责任人员由业务主管单位指定人员担任。民政部门负责避灾点建设管理业务指导。 

    4、教育培训。县（区、管委会）民政部门、乡镇政府（街道办事处）要定期组织避灾点管理人员业务培训，开展转移安置组织领导演练，提高基层干部救灾操作能力；避灾点要充分利用自身条件开展减灾、救灾知识的宣传教育，提高群众防灾减灾意识及避灾自救技能。 

十、对避灾点使用管理有何要求？

    1、转移安置工作原则：对居住危房、低洼地或地质灾害监测点以及自然灾害发生后可能造成房屋倒塌或严重受损或可能危及人身安全等原因需要转移的群众，主要以投亲靠友为主，就近就便集中转移安置为辅。

    2、转移安置安排办法：对需集中转移安置的群众，由村（居）委会直接安排或协调安排，在乡（镇）、村（居）有关人员带领下及时转移至本村（居）就近的避灾点或上级避灾点进行安置，并填写转移人员村（组）别、姓名、性别、年龄、身体状况等相关资料，办理交接手续。

    3、转移安置运行流程：

    （1）当有关方面发布灾害预警时，应及时启用自然灾害避灾点。灾害预警或发生后，避灾点责任人及工作人员须坚守岗位，实行24小时值班制度，及时了解掌握自然灾害等级和危害情况，做好接收安置转移安置群众的各项准备工作。

    （2）转移安置群众到达避灾点后，避灾点工作人员要对转移安置人员进行登记造册，妥善安排好转移安置对象的基本生活，并加强避灾人员教育管理，维护好避灾点秩序。

    （3）严格规范回迁工作，禁上转移安置人员自行回迁。灾害警报解除后，避灾点管理人员在条件允许的情况下，经业务主管单位批准，及时动员转移安置人员回迁。

十一、如何开展避灾点信息化管理？

    1、避灾点互联网管理：各县（区、管委会）、乡镇（街道）民政部门应采集辖区各避灾点名称、位置、规模、服务能力等基本信息数据或变更信息数据，由省民政厅统一建立自然灾害避灾点数据库，共享使用。

    2、开展联网视频监控：有条件的县（区、管委会）结合治安视频监控网络建设，在各避灾点设置视频监控探头，在县（区、管委会）民政部门、防汛办、乡镇政府（街道办事处）设立监视节点平台随时调取实时察看。

十二  自然灾害避灾点建设管理资金如何保障？

避灾点日常维护、检测以及添置救灾物资所需资金以各级政府为主投入，列入同级财政年度预算。避灾期间避灾人员的生活保障资金从各级政府下达的自然灾害生活应急补助资金中安排，保障补助标准由市、县（区、管委会）民政、财政部门根据当地经济社会发展水平核定。
