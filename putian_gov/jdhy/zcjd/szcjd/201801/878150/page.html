市卫计委《关于加快医疗卫生事业发展的实施意见》政策解读

来源：本网 时间：2017-10-09 13:15
| | | |

一、《意见》的出台背景和作用

2016年8月3日，中共福建省委十届三次全会在福州召开。会议主要任务是，深入贯彻习近平总书记以人民为中心的发展思想和新发展理念，认真落实中央关于加快社会事业发展的决策部署，重点研究我省教育、卫生与健康、养老、城乡民生基础设施等领域补短板问题，加快提升社会事业发展水平，不断增进人民福祉，确保如期全面建成小康社会。全会审议通过了《中共福建省委 福建省人民政府关于加快医疗卫生事业发展的实施意见》。市委、市政府高度重视医疗卫生事业“补短板”工作，8月16日召开市委七届三次全会，研究通过了《中共莆田市委 莆田市人民政府关于加快医疗卫生事业发展的实施意见（送审稿）》。9月29日《中共莆田市委 莆田市人民政府关于加快医药卫生事业发展的实施意见》（莆委发[2017]13号）文件正式印发。该《意见》重在“补短板”，是未来3年及更长一段时间内发展我市医疗卫生事业的行动指南，也是制定卫生健康政策、确定卫生工作重点方向、引导健康产业发展的重要依据。

二、《意见》的主要特点

《意见》坚持以人民健康为中心，紧盯薄弱，对接需求，结合我市实际，突出“补短板”，具有以下鲜明特点：

（一）重点任务的项目内容兼具全面性和针对性。围绕“抓改革、促发展、补短板、提水平”要求，《意见》提出重点实施结构优化、学科完善、基层基础、中医固本、公共卫生促进、人才队伍建设、智慧健康、健康产业等8大工程，基本涵盖医疗卫生事业各个方面，同时对每个方面的不足薄弱之处提出具备针对性、有效性和可操作性的具体措施，做到切实可行、有的放矢。

（二）注重补齐群众急需的紧缺学科短板。重点推进儿科、产科、精神科、中医科等学科基础设施建设和服务能力提升，有效缓解相关紧缺学科“一床难求”的紧张局面。在提出行之有效的系列举措的同时，一是明确细化相应任务指标，如到2020年，全市儿科床位达到1782张，每千名儿童儿科床位数达到3张；全市有效产科床位达到1365张，实现每千分娩量产科床位数达到22.4张；全市精神卫生床位达到1890张，每万人口精神卫生床位达到6.07张，以上床位建设目标均较福建省《意见》相关指标为高。二是对任务指标进行量化分解，制定了《2017-2020年莆田市医疗卫生机构及紧缺学科发展床位任务分解表》作为《意见》的附件，将相关学科建设床位数分解到各县区（管委会），形成评价考核依据，确保紧缺学科补短板工作真正落到实处。

（三）创新实施健康产业工程。与省里《意见》相比，结合我市实际，新增实施健康产业工程内容。一是建设高端医院集聚区。加强医疗健康产业园区建设，发展一批业内领先的健康服务企业和产业集群。二是树立民办医疗品牌。通过加强行业自律、规范行业经营。在全国莆田民营医疗企业中评选“百佳示范医院”，发挥莆田健康产业总会作用，建立医疗知名品牌。三是创新人才培养模式。探索定向委培的方式，实施“订单式”的人才培养模式。制定鼓励医学专业毕业生在我市就业的优惠政策，为全市健康产业发展提供人才支撑与保障。

（四）补齐医疗卫生人才短板方面多措并举。一是以“壶兰计划”为引领，实施医药卫生人才“四大工程”（名医带动工程、实施高学历人才引才工程、人才聚集和培育工程、人才创新创业工程），全面促进我市高层次卫生人才数量有效增长。二是县（区）的二级医疗机构高级职称比例控制标准逐步提高至20%，乡镇卫生院、社区卫生服务机构提高至15%，提高基层对人才的吸引力。三是将儿科、产科、精神科、中医等相关专业人才列入紧缺人才目录，采取专项公开招聘、特设岗位招聘等方式，提高人才引进实效。四是建立公共卫生机构绩效工资动态增长机制，对公共卫生机构完成年度常规计划外的重大或临时性专项工作任务，在考核确认后增加相应的绩效工资总量。五是支持公立医疗卫生机构建设人才公寓或职工周转宿舍，并享受公共租赁住房相关优惠政策。对符合条件的公立医疗卫生机构住房困难职工，纳入当地保障性住房保障范围。

（五）明确提出创建国家卫生城市和创办东南医学院“双创”目标。一是启动开展国家卫生城市创建工作，巩固国家文明城市创建成果，通过广泛发动群众开展爱国卫生运动，建立城乡环境卫生治理长效机制，加强卫生创建技术指导和监督管理，严格评价标准，加强动态管理。到2020年，力争创成国家卫生城市，仙游县力争创成国家卫生县城。二是支持莆田学院医学类专业整合提升，独立设置医学类普通本科高校，创办东南医学院。

三、《意见》的主要内容

“健康莆田2030”行动规划主要包括总体目标、重点任务、保障措施等三个部分。

第一部分总体目标，紧扣推进健康莆田建设、加快医疗卫生事业补短板、力争提前全面建成小康社会这一主线，提出加快医疗卫生事业发展的目标要求：到2020年，城乡基本医疗卫生制度基本建立，居民主要健康指标保持在全省中上水平，人均预期寿命达到78.29岁，每千常住人口医疗机构床位达到6.08张、执业（助理）医师数达到2.5人、注册护士数达到3.14人，健康莆田建设迈上更高层次。

第二部分重点任务，重点实施八大工程。一是实施结构优化工程。完善医疗卫生资源布局，加快医疗机构床位发展，鼓励社会办医。二是实施学科完善工程。重点推进儿科、产科、精神科等紧缺学科基础设施建设和服务能力提升，建设30个市级临床重点专科，强化对区域医疗的辐射带动作用。三是实施基层基础工程。加强县域医疗机构基础设施建设，推进医联体建设，开展家庭医生签约服务，提高县域内就诊率。四是实施中医固本工程。健全完善中医医疗服务体系，拓展中医特色服务。五是实施公共卫生促进工程。加强疾病预防控制能力建设、慢性病综合防治、卫生应急体系建设、卫生计生综合监督、采供血体系建设，进一步筑牢群众健康防线。六是实施人才队伍建设工程。扩大医学人才培养规模，推进高层次人才队伍建设，创新人才下沉机制，促进紧缺人才队伍建设，充分调动公共卫生服务人员积极性。七是实施智慧健康工程。推动“互联网＋健康医疗”服务，建立健康信息化统筹协调机制，推进健康医疗大数据开发共享，依托信息化手段改善群众就医体验。八是实施健康产业工程。加强医疗健康产业园区建设，形成高端医院集聚规模，树立民办医疗品牌，创新健康产业人才培养模式。

第三部分保障措施，提出五条具体保障措施，对任务落实形成有力支撑。一是坚持规划引领。明确要求各级政府切实履行办医主体责任，将区域卫生规划、医疗机构设置规划与区域经济社会发展规划相结合，保障医疗卫生补短板项目建设需要。二是突出项目带动。重点推动紧缺学科补短板项目和基层能力提升项目，实施县级医院综合能力提升建设项目和新一轮乡镇卫生院改造提升项目。三是创新体制机制。深化医药卫生体制改革，创新资金保障投资建设机制和项目协调机制。四是出台人才政策。制定出台医疗卫生领域“引进生”引才和精准引才支持办法。五是加强监督评价。加强对医疗卫生“补短板”工作监督和评价，组织开展区域卫生规划实施进度和效果评价，开展联合督查，推动规划落实。

《意见》的制定出台，进一步凝聚了全社会对医疗卫生事业发展的共识，提振建设健康莆田的信心，保持科学合理预期，为卫生健康领域改革发展创造良好的氛围，全方位、全周期维护和保障人民健康，全面提高健康水平，改善健康公平，为打造宜居港城、建设美丽莆田，创建美丽中国的示范区提供坚实的全民健康基础。
