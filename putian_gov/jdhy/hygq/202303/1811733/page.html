如何增进民生福祉？福建五部门最新解答

来源:福建发布 时间：2023-03-24 16:52
| | | |

 

　　3月24日上午，中共福建省委宣传部召开“稳经济 促发展”系列主题新闻发布会，为增进民生福祉专场（一）。

稳就业、惠民生、促稳定

　　发布会上，福建省人社厅党组成员、副厅长童长峰介绍人社厅推进稳就业、惠民生有关工作情况，全力实施就业优先战略，持续健全社会保障体系，扎实构建和谐稳定劳动关系。

　　全力以赴稳就业、抢开局

　　2022年，全年兑现稳就业奖补25.2亿元，惠及企业37.2万家、职工596.8万人，全年全省城镇新增就业51.97万人，就业局势保持稳定。至今年2月底，各项稳就业政策支出6.11亿元，惠及企业8.8万家、职工132.27万人。

　　至农历二月初四，全省共包机包列包车338趟，输送1.55万人。监测调度显示，至农历二月初四，全省企业员工总体返岗率达到99.50%，高于去年同期，有效助力一季度“开门稳”“开门红”。

　　坚持不懈兜底线、惠民生

　　至2023年2月，基本养老保险、失业保险、工伤保险参保人数分别达3297.65万人、746.82万人、1010.96万人。去年以来企业职工基本养老保险全国统筹稳步实施，开户数目前居全国第一，调整提高城乡居民基础养老金；工伤保险三项定期待遇持续提高，超全国平均水平；失业保险省级统筹有序推进、平稳衔接；阶段性社保费缓缴9.45亿元、惠及企业1.7万家。

　　社会保障卡持卡4304万人，领用电子社保卡2513万人，覆盖率高于全国平均值，各类服务事项网上大厅应上尽上、“一网通办”“跨省通办”“一件事、一次办”加速推动，待遇资格领取实现“静默认证”，群众办事体验得到进一步优化。

　　坚定不移防风险、促稳定

　　实施“仲裁+X”调解新模式，持续推广仲裁文书集约化送达，联合打造“园区枫桥”工作新机制，调解仲裁效能持续强化。深入推进国有企业薪酬制度改革，调整最低工资标准，增长14.6%，收入分配更加有序。实施欠款欠薪“点题整治”、创建“无欠薪”项目部、欠薪“雷霆清零”等特色举措，切实保障劳动者合法权益。

发布会上相关部门还作了以下解答

　　福建省发改委：7家医院列入国家区域医疗中心项目

　　一是推进医疗卫生项目建设。按照国家发改委、卫健委等部署要求，积极推动符合条件的项目申报2023年医疗卫生领域中央预算内投资支持。

　　二是推进应急救治能力建设。申报并下达中央预算内投资支持各地开展亚（准）定点医院、三级医院可转换重症加强护理病房（ICU）升级改造工作，提高应急救治能力。

　　三是推进医疗资源优质均衡发展。经积极争取，先后共3批7家医院列入国家区域医疗中心项目，4个项目列入省级区域医疗中心。目前7个国家区域医疗中心建设项目扎实推进运行良好，截至2022年12月，6个已经投入运营的区域医疗中心项目总开放床位数4862张，占核定床位总数77.4%；2022年总诊疗量472.73万人次，较上年同期增长22.6%。累计开展新技术、新项目、新服务总数604项，其中国内首创8项。转外就医患者数同比减少33%。住院患者中省外患者占比9.6%。努力争取符合条件的医院列入第五批国家区域医疗中心建设项目，进一步扩大优质医疗资源供给。

　　福建省人社厅：省定基础养老金最低标准为每人每月150元、比全国标准高52元

　　截至2023年2月底，参保人数达1595.79万人。从2022年1月起，会同财政部门连续三年调整提高全省城乡居民基本养老保险基础养老金省定最低标准，并已连续两年纳入省委、省政府为民办实事项目。

　　截至2023年2月27日全省所有市、县（区）均已完成基础养老金调整提高，共惠及509.22万老年城乡居民，目前省定最低标准为每人每月150元、比全国标准高52元。为落实政府对城乡居民养老保险的财政支出责任，2022年省财政下达资金65.77亿元，2023年省财政预算安排72.74亿元，同比增长10.6%。

　　福建省生态环境厅：污染防治攻坚战成效国家考核福建省连续三年优秀

　　一是坚持改善民生，深入治污。2022年全省12条主要流域优良水质比例98.7%，九市一区城市空气平均优良天数比例97.8%，近岸海域优良水质比例85.8%，全省生态环境质量保持优良并持续居全国前列，污染防治攻坚战成效国家考核福建省连续三年优秀。

　　二是坚持以人为本，真督实改。截至目前，两轮中央环保督察整改任务绝大部分已完成或基本完成。坚持自我加压、刀刃向内，对福州、厦门、泉州、莆田开展省级生态环保督察，目前已完成第二轮省级督察全覆盖，督察整改总体取得阶段性成效。

　　三是坚持为民解忧，严格执法。全面落实中央《信访工作条例》，深化“静夜守护”点题整治，开展信访“治重化积”专项行动，信访平均受理和办结时间较法定时限分别缩短14天、52天，重复信访投诉量同比下降22.8%。严厉打击损害群众权益、危害群众健康的环境违法犯罪行为，全年办理行政处罚案件2833起，办理《环境保护法》四个配套办法案件624起，移送涉嫌犯罪案件59起。

　　四是坚持惠民利民，办好实事。省委省政府将海漂垃圾综合治理和农村生活污水治理纳入2022年为民办实事项目。在海漂垃圾综合治理上，省级共投入2.66亿元，清理垃圾12.14万吨，重点岸段垃圾分布密度下降57.3%，让群众享受碧海蓝天、洁净沙滩；在农村生活污水治理上，投入3亿元，完成374个村庄污水治理，累计消除52条较大面积农村黑臭水体，让群众享受和美乡村、美丽田园。

　　福建省教育厅：2023年，计划新增公办义务教育学校学位5万个

　　一是学前教育突出“优质普惠”。2023年，计划改造城区和城乡结合部公办幼儿园150所，以此推动缓解“大班额”问题。继续扶持普惠性民办幼儿园发展，多渠道补齐普惠性学前教育资源缺口。持续开展乡村学前教育巡回支教工作，推进乡村学前教育办学点标准化建设，办好老百姓家门口的幼儿园。

　　二是义务教育突出“优质均衡”。完善强校带弱校、城乡对口帮扶等办学机制，逐步缩小县域内义务教育城乡差距、校际差距。2023年，计划新增公办义务教育学校学位5万个。围绕提升教育质量，推进省级“义务教育优质均衡先行县”创建，巩固提升“双减”成效，推动义务教育从基本均衡向优质均衡迈进。

　　三是普通高中突出“优质多样”。加大对县域高中的支持力度，实施县域普通高中发展提升行动，指导示范高中对口帮扶县域高中，促进同频共振、整体提升。深入实施普通高中新课程新教材，以课程建设引领学校内涵发展。

　　福建省文旅厅：101家图书馆、博物馆、文化馆、美术馆试点错时延时开放

　　一是部署打造更高水平的基层公共文化空间。对接群众文化需求，支持建设一批“清新书苑”“城市书房”等高品质公共文化新型空间。在省级已支持建设29个的基础上，今年省级将继续支持建设14个。

　　二是持续提升公共文化场馆免费开放水平。扎实推进公共文化场馆试点错时延时开放，在2022年福州厦门60家试点的基础上，今年新增41家，共有101家图书馆、博物馆、文化馆、美术馆试点错时延时开放，覆盖9个设区市。在试点内容方面，周末和重要节假日延时开放时间不少于2个小时，其余时段以错时开放为主。

　　三是广泛组织开展群众文化活动。目前，已开展“学习宣传贯彻党的二十大精神，群众文化活动走基层”主题群众文化活动近10场。今年，还将重点组织举办好第十五届福建音乐舞蹈节、“大地欢歌”全国乡村文化活动年、“春雨工程”文化和旅游志愿服务边疆行、首届“阅读向未来”青少年演讲比赛等群众文化活动。

　　四是培育和擦亮群众文化活动品牌。持续打造福建省街头文化艺术展演、福建省“读中华经典 颂时代华章”经典诵读比赛、乡村“村晚”、“春燕行动”福建乡村音乐会、激情广场大家唱等品牌活动，为群众提供展示自我、沟通交流和文化娱乐的大舞台。进一步完善“福建百姓大舞台”文化惠民演出活动机制，目前，已印发活动方案，重点推进统一名称标识、上下三级联动、鼓励社会参与、加强线上推广、活动成果联展等，擦亮福建百姓大舞台品牌知名度。
