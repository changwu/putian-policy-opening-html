关于市八届人大一次会议第0070号建议的答复

发布时间：2022-05-13 16:33
| | |
政策解读:

林玉和代表：

　　你提出的《关于出台配套支持措施，顺利实施三孩生育政策的建议》（第0070号）收悉，现答复如下：

　　一、工作现状和进展情况

　　2021年5月31日，习近平总书记主持召开中央政治局会议，审议通过《关于优化生育政策促进人口长期均衡发展的决定》（以下简称《决定》），明确实施三孩政策及配套支持措施。《中华人民共和国人口与计划生育法》于2021年8月20日修改通过并公布。《福建省人口与计划生育条例》于2022年3月30日修改通过并公布。

　　三孩生育政策实施以来，我委会同各级各部门扎实有序开展各项工作。目前，三孩生育政策落地实施，社会抚养费遗留问题已依法依规处理，个人生育情况与各项社会事务全面脱钩，优生优育服务、生育服务管理、普惠托育服务、减轻生育医疗成本、减轻家庭教育负担、维护女职工权益等配套措施正在稳步有序地推进。

　　二、关于所提建议的答复

　　（一）关于发放生育补贴。根据省级“指导支持经济较发达地区探索建立发放生育二孩、三孩补助等制度”的部署要求，待经济较发达的兄弟地市率先探索建立发放生育二孩、三孩补助制度后，将借鉴相关经验做法，根据人口形势，研究我市发放生育补贴的可行性和必要性。

　　（二）关于奖励生育假期。《福建省人口与计划生育条例》（2022年修正）第二十四条规定：符合本条例生育子女的夫妻，女方产假延长为一百五十八日至一百八十日，男方照顾假为十五日，在其子女年满三周岁之前，每年给予夫妻双方各十天育儿假。我省女方产假在国家规定98天的基础上延长了60-82天，男方享受15天照顾假，同时符合条件的夫妻双方各享受10天育儿假。

　　（三）关于完善托育服务。目前全市提供托育服务的机构类型有在社区或周边开办的社区型托育机构、在商务楼宇周边和人群密集区域举办的托育机构、在幼儿园园内开办托育机构的托育机构-幼儿园联合体、幼儿园托班，可以提供全日托、半日托、计时托、临时托等服务，满足群众多样化的服务需求。我市鼓励幼儿园在满足3-6岁幼儿入园需求的基础上，对于尚有空余资源和学位，且有举办婴幼儿照护服务机构积极性的幼儿园开设托班，招收2-3岁幼儿。2020年起，我市开始推进普惠托育服务工作，以资金补助方式支持发展普惠性托育服务，激发企事业和社会力量积极性。按照质量有保障、价格可承受、方便可及的普惠性导向，综合考虑当地居民收入水平、服务成本、合理利润等因素，形成普惠性收费标准。目前，全市有11个提供普惠性托育服务的机构，普惠性托位1113个；到今年年底将增加至34个，预计普惠性托位达2800个。

　　（四）关于加强住房保障。将支持三孩家庭住房合理需求列入《莆田市人民政府办公室转发市住建局等部门关于莆田市房地产市场平稳健康发展长效机制工作方案》（莆政办〔2021〕64号）的内容之一。省级三孩生育政策实施方案出台后，我市将研究出台具体保障三孩生育的住房配套支持措施，如鼓励各房地产开发企业对养育三孩家庭购房在价格方面予以适当优惠；各房地产开发企业应优化商品住宅户型设计，以适合三孩家庭住房需求等。

　　（五）关于强化税费支持。根据《国务院关于设立3岁以下婴幼儿照护个人所得税专项附加扣除的通知》（国发〔2022〕8号），自2022年1月1日起实施3岁以下婴幼儿照护个人所得税专项附加扣除。纳税人照护3岁以下婴幼儿子女的相关支出，按照每个婴幼儿每月1000元的标准定额扣除。根据《财政部 国家税务总局关于生育津贴和生育医疗费有关个人所得税政策的通知》（财税〔2008〕8号），生育妇女按照县级以上人民政府根据国家有关规定制定的生育保险办法，取得的生育津贴、生育医疗费或其他属于生育保险性质的津贴、补贴，免征个人所得税。

　　三、下一步工作目标和计划

　　我委将会同有关部门，进一步贯彻落实《决定》精神，加强《中华人民共和国人口与计划生育法》《福建省人口与计划生育条例》等法律法规的宣传和贯彻，不断完善三孩生育政策配套支持措施，满足群众多元化的生育需求，切实解决群众后顾之忧，释放生育潜能，促进人口长期均衡发展。
