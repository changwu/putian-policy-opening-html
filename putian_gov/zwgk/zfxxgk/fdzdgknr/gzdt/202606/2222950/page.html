关于市政协八届五次会议第20264008号提案办理情况的答复

发布时间：2026-06-30 08:53
| | |
政策解读:

陈国仙委员：

　　你提出的《关于深化人工智能在医疗领域应用 全面推进健康莆田建设的建议》（20264008号）已收悉，现将办理情况函复如下：

　　近年来，人工智能产业发展迅速，我委牢牢把握“人工智能+医疗卫生”融合发展机遇，紧扣卫生健康数字化、智能化转型总体要求，坚持系统谋划、场景赋能、底座夯实、机制保障同步推进，推动智慧医疗体系建设落地见效。当前全市医疗人工智能总体架构持续优化，便民就医、临床诊疗等智能应用场景不断拓宽，数据资源归集、算力平台建设等数字基础支撑稳步夯实，持续赋能医疗卫生服务提质升级。

　　一、强化顶层设计，构建数字发展格局。

　　一是系统谋划布局，夯实发展顶层支撑。我市已将“数字赋能社会民生”纳入《莆田市国民经济和社会发展第十五个五年规划纲要》，在健康莆田建设板块明确全民健康信息化建设、智慧医疗发展任务，为“人工智能+医疗卫生”融

　　合发展夯实基础。二是细化专项规划，聚焦场景深度赋能。市发改委牵头编制《莆田市“十五五”基本公共服务体系建设专项规划》，拟将人工智能融入卫健领域列为重点内容，推动技术融入影像诊断、慢病管理、老年健康服务等环节，全面提升医疗服务智能化水平。三是强化项目培育，发挥示范引领作用。莆田学院附属医院申报的《基层骨质疏松症智能筛选与骨折风险管理》项目入围首批省级“人工智能+医疗卫生”应用场景创新项目培育库，以示范项目带动全市医疗AI规模化落地。

　　二、拓展应用场景，深化智能服务落地。

　　一是升级莆田“健康宝”平台。平台集成预约挂号、预防接种预约、健康档案查询、婚孕检报告查询、线上问诊等便民服务，打通市级政务信息平台并接入惠民宝APP，实现数据共享、多端服务。二是建强远程影像服务体系。依托影像医生服务基层平台，组建全市影像专家库100多名，实行抢单、指派和兜底相结合的远程会诊模式，累计辅助基层远程完成会诊130多万人次。2026年，我委也将对平台进行全面升级，搭建医学影像云平台国产化信创基座，引入AI辅助诊断，完善区域医学影像服务体系。三是深化临床智能化应用。莆田市第一医院、莆田学院附属医院、莆田涵江医院等多家医疗机构先后上线影像AI诊断、报告智能质控、处方智能审方及电子病历AI助手，筑牢诊疗与用药安全防线，部分医院还启用手术智能规划系统与手术机器人，有效提升诊疗效率、手术精准度与安全性。

　　三、夯实数字底座，激活数据要素价值。

　　一是聚焦重点领域，搭建医疗专题数据资源。依托市级公共数据汇聚共享平台，坚持需求导向、急用先行，围绕心血管疾病、糖尿病、恶性肿瘤等本地高发疾病和重点专科，有序推进医疗专题数据集建设，匹配医疗人工智能应用发展需求。二是完善标准体系，规范数据全流程管理。建立健全数据采集、清洗、标注、管理全流程标准，统一数据归集与加工规范，打造一批可共享、可复用、高质量的医疗专题数据集，为人工智能模型训练、算法验证提供坚实数据支撑。三是整合算力资源，降低智能应用落地成本。依托在建的城厢智算中心等本地算力设施，探索建立医疗可信算力共享机制，实现算力集约化利用。主动对接省级算力平台争取资源扶持，降低基层医疗机构AI训练、业务推理用算成本。深化算力、数据、场景融合，鼓励联合多方研发轻量化医疗AI应用方案，赋能智慧医疗场景落地。

　　四、健全支撑体系，筑牢长效发展保障。

　　一是深化跨域协作共建，提升区域医疗服务水平。莆田学院附属医院持续深化与北京大学肿瘤医院、北京大学口腔医院、福建医科大学附属协和医院等机构深化合作，围绕学科建设、人才培养、信息化平台等领域开展全方位共建，助力区域医疗同质化发展。二是压实安全管控举措，健全网络数据防护体系。严格执行数据脱敏脱密、去标识化等处理规范，坚守“原始数据不出域”底线，全方位保护群众健康隐私。依托区域卫生健康云平台搭建覆盖网络、主机、应用、数据、移动、安全监测的防护体系，每年常态化开展等保测评，构建网络安全防护闭环。三是推动创新技术落地，打造本土智慧医疗方案。鼓励有条件的医疗机构积极对接省内外科技企业、高等院校，立足我市基层诊疗、慢病管理、妇幼健康等需求定向开展技术攻关，因地制宜研发适配本地诊疗场景的智能医疗产品，形成贴合民生需求、可复制推广的本土特色智慧医疗解决方案。

　　下一步，我委将持续完善医疗人工智能顶层规划布局，不断丰富各类医疗智能应用场景，严守医疗数据安全底线，深化跨区域医企校协同创新，培育本土化智慧医疗应用成果，稳步推动全市“人工智能+医疗卫生”融合发展再上新台阶。
