关于市八届人大二次会议第1151号建议的答复

发布时间：2024-04-30 15:10
| | |
政策解读:

许丹代表：

　　《关于守护女性健康，增强女职工卫生保障的建议》（第1151号）由我单位会同市妇联、市总工会办理，现将有关情况汇总答复如下：

　　一、对于“增加资金投入”的建议。自2012年起，市卫健委积极联合市妇儿工委办、财政局等部门，以农村妇女、城镇低保妇女为重点，全面覆盖适龄女性，免费开展宫颈癌和乳腺癌筛查项目，人均经费分别为153元/例和80元/例，总资金投入超过7千余万元。自2022年起，由市卫健委牵头，市教育局、市妇联、市财政局共同实施适龄女性HPV疫苗免费接种项目，省、市、县三级已投入专项补助资金1639.6万元，为4.5万名适龄女性免费接种国产二价HPV疫苗，并且2024年将在我市继续实施该为民办实事项目。此外，我委也曾在2022年向上级部门积极建议将HPV疫苗纳入国家免疫规划，全面提高适龄女性接种覆盖面，降低宫颈癌疾病对女性的健康威胁。市总工会以“两癌”筛查为重点，制定健康保障工作方案，每年下拨约10万元专项资金督促用人单位对女职工定期开展免费健康体检活动，此外，每年下拨2万元专项资金推进“您的健康我关注”系列活动，邀请专家深入企业、单位开展女职工健康知识讲座、心理疏导、健康义诊等，联合人社等部门下发《关于明确女职工卫生费标准的通知》，明确有条件的用人单位可以按照每人每月30元的标准向在职女职工发放卫生用品或者费用，关爱女性健康。市妇联通过大力开展女性安康保险推广工作，引导全市广大妇女树立健康生活理念，不断扩大“两癌”救助工作的覆盖面和受益面。截止目前，全市女性安康业务参保人数为12220人，保费共计192.07万元，有效提升广大女性健康保险水平。各级妇联组织在全市开展“母亲健康1+1”公益募捐活动，截至目前，已累计募集爱心捐赠款约132.2万元，为“两癌”重症贫困母亲送上一份温暖。

　　二、对于“加强对女性健康知识的宣传教育工作”的建议。在生殖健康与“两癌”防治方面，一是市卫健委结合三八节、世界母乳喂养周等重要节点，通过莆田电视台《今日视线》、《健康生活》、《湄洲日报》、微信公众号、健康莆田视频号等新媒体及开展形式多样的宣传义诊，广泛开展宣传教育，妇幼健康专家现场提供“面对面”咨询指导；市总工会将“两癌”防治纳入公共卫生宣传和职工教育培训内容，深入企业为职工提供健康咨询服务；市妇联2023年以来开展“关爱女性健康”系列公益知识讲座11场，通过发动基层妇联干部、妇联执委、巾帼志愿者入户，制作莆仙方言版“两癌”免费筛查和救助宣传音频，在“两癌”救助申报时期利用“村村通”在全市村（社区）早晚播报，推动“两癌”免费筛查和救助宣传全覆盖，妇女生殖健康和安全教育知晓率逐步提升；二是免费提供基本避孕技术服务和避孕药具发放服务，全市共确定28家定点医疗机构为群众提供11类免费计划生育技术服务项目，注册设立药具人工发放网点943个，自动发放机62台，提高妇女自我保护意识，预防和控制非意愿妊娠，保障妇女身体健康；三是重视宫颈癌和乳腺癌两大妇女常见病早防早治，近十年，全市累计共完成34万人次35-64周岁妇女免费“两癌”检查，逾16万名妇女宫颈和乳腺问题得到指导或治疗，妇女常见病筛查率提高至92.64%，促进早发现、早诊断、早治疗和早康复，更好地维护妇女健康。今年我市新一轮免费“两癌”检查已全面启动，预计惠及妇女人群7万人次。全面实施加速消除“宫颈癌”行动计划，高效推进适龄女性HPV疫苗免费接种工作，全市共累计完成国产二价疫苗免费接种剂次达7.1万剂次，受益人群约4.4万人次，接种知情同意率100%，引导适龄女性树立自我健康管理的意识，促进早接种、早预防、早受益，筑牢宫颈癌预防第一道防线。在女性心理健康方面，一是组建市级心理专家团队。依托市精神卫生中心成立市级心理专家团队，由9位精神科医师组成，目前均具备心理治疗师或心理咨询师资格，对门诊就诊的女性心理问题开展“一对一”心理问询、评估、疏导和心理危机干预工作，加快心理健康诊疗科室建设，有效缓解精神卫生机构少、心理疾病就医难的问题。二是积极推动心理健康咨询和治疗服务。推广莆田市心理健康自测信息化平台，健全心理应急援助平台热线。开通市级心理援助热线1条，县（区）级13条共计14条心理援助热线，每日热线座席数达14个，涉及接线工作人员27名，其中心理咨询师/治疗师19人，精神科医师8人，为女性提供优质的心理援助服务。三是广泛开展心理健康宣传与教育活动。依托“世界精神卫生日”普及心理健康知识，引导广大女性朋友关注心理健康，正确面对精神心理疾病，理解、接纳精神心理障碍患者，引导女性朋友在日常生活中有意识地营造积极心态，预防不良心态，学会调适情绪困扰和心理压力。发挥新媒体力量，建立心理健康网站、微信心理问题服务平台等，通过网络平台向不同人群提供针对性服务。

　　三、对于“加强基层医疗机构医务人员的服务能力”的建议。围绕“强基层、补短板、促健康”原则，将基层医疗服务能力提升建设作为重要内容列入“十四五”卫生健康事业发展规划。2023年以来全市共实施5个乡镇卫生院（社区卫生服务中心）改造提升项目，总投资1.43亿元；2024年，将17家薄弱乡镇卫生院基础设备达标建设纳入市级为民办实事项目，争取补助资金510万元，以医疗机构基本标准为指导，进一步提升基层基础硬件设施设备水平。推进“优质服务基层行”活动，全市共有17家乡镇卫生院（社区卫生服务中心）达到服务能力推荐标准，38家乡镇卫生院（社区卫生服务中心）达到服务能力基本标准及以上，较好地提升了为女性提供健康服务的能力。

　　综上，我委始终紧紧围绕提高妇女健康水平这条主线，聚焦“为群众提供全方位全周期健康服务”要求，全面实施“妇幼健康计划”和“关爱妇女儿童健康行动”，推动全市妇女卫生健康事业持续健康发展。下一步，我委将持续深入贯彻落实省、市妇女发展纲要（2021-2030），持之以恒地落实好政府惠民实事和卫生健康保障等各项工作任务，不断丰富女性健康知识宣教方式和内容，加强部门协作配合，不断创新理念，拓展内涵，努力提升妇女健康综合服务能力，努力让广大妇女儿童获得感成色更足、幸福感更可持续、安全感更有保障。

　　衷心感谢您提出的宝贵意见和建议,欢迎您继续关心、支持卫生健康工作。
