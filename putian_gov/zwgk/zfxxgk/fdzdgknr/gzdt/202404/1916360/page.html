关于市八届人大三次会议第1180号建议的答复

发布时间：2024-04-30 08:54
| | |
政策解读:

蔡建荣代表：

　　《关于解决长期滞留患者问题的建议》（第1180号）由我单位会同市民政局、市公安局和市中级人民法院办理。现将有关情况汇总答复如下：

　　一、明确流浪乞讨人员安置责任部门

　　根据《城市生活无着的流浪乞讨人员救助管理办法》《生活无着的流浪乞讨人员救助管理机构工作规程》等相关文件要求，按照先救治后救助的原则，辖区内发现的流浪乞讨人员由医院先行治疗，符合出院标准后，本地户籍的流浪乞讨人员由户籍所在地乡镇人民政府（街道办事处）解决，相关部门协助解决，妥善安置；外地户籍的流浪乞讨人员由市民政局负责和户籍地民政部门沟通协调后，将患者护送返乡。公安部门积极配合医疗机构查找“三无”人员身份信息，做好家属、村居工作，配合医院、民政等部门帮助长期滞留患者回归家庭。

　　二、加强“医养结合”型养老工作

　　一是将居家养老的老年人纳入家庭医生签约服务重点人群，优先签约并提供健康管理和基本医疗服务。截至2023年12月底，65岁以上老年人家庭医生签约32.13万人，签约率79.43%

　　二是以基本公共卫生服务为抓手，以基层医疗卫生机构为平台，为65岁以上老年人建立居民健康档案。截至2024年3月，开展老年人体检32.02万人次，65岁以上老年人健康管理率为78.8%。

　　三是转变基层医疗卫生机构服务模式，开展社区全科医生签约和农村乡村医生签约服务，与65岁以上的老年人建立相对稳定的契约服务关系，提供约定的基本医疗与基本公共卫生服务。目前我市所有县区均已启动了社区全科医生签约和农村乡村医生签约服务。

　　四是鼓励和支持有条件的养老机构内设医疗机构，推进养老机构和医疗机构合作共建，提高养老机构开展医疗服务的能力，满足入住老年人的健康服务需求。目前全市共有5家养老机构内设医疗机构，近600名老年人入住；共有4家医疗机构内设养老机构，近200名老年人入住；共有31家养老机构与附近医疗机构签订合作协议，已建成并投入使用的养老机构通过各种形式开展医养结合工作的比例达97%以上。

　　三、加强疾病应急救助工作

　　一是明确救助基金使用范围、救助对象及种类。在莆田市行政区域内发生急危重伤病，需要急救但身份不明确或无责任承担机构（人员）以及无力支付相应费用的患者。主要依据原国家卫计委办公厅印发的《需要紧急救治的急危重伤病标准及诊疗规范》(国卫办医发〔2013〕32号)中规定的病种，以院前急救、急诊科、重症医学科及需要专科进行的紧急抢救治疗为主。

　　二是加强救助基金使用管理。救助基金的使用坚持“救急难”的原则，各县区、各单位要按照《莆田市人民政府办公室关于印发莆田市疾病应急救助管理办法的通知》（莆政办〔2015〕26号）的要求，进一步优化救助基金的申请、审核、拨付流程，明确各环节审核认定时限，医疗机构至少每季度末集中向市医保中心提交基金补助申请，市医保中心汇总资料后送市卫健委，市卫健委至少每半年组织召开公安、民政、医保、财政等部门联席会议，汇总各部门意见后报市财政部门审批。2023年我市符合条件的救助对象共31人次，从市财政专户中拨付疾病应急救助基金共136万余元。

　　四、加强医疗机构法制化氛围

　　一是加强医疗机构安全风险排查。我委与市公安局联合下发《关于医疗机构安全风险排查专项督导情况的通报》，对加强医院内部安全秩序管理、安防系统建设、应急处置等强化医院安防工作提出具体要求，部署各县区举一反三，继续深入开展医疗机构安全风险排查工作，对发现的问题隐患，及时作出处理，跟进督促整改到位，努力做到发现在早、防范在先、处置在小，全力维护我市医疗机构安全。

　　二是全市法院统一裁判尺度。要求在处理人身损害类案件中，应结合伤情着重审查是否存在过度医疗的情况，根据伤情治疗情况扣除不合理的部分或者与本案侵权行为无关的其他疾病治疗部分，尤其是超过合理天数的诊查费、床位费、与侵权行为无关的其他疾病的诊疗费等，既注重保护患者的合法权益，又兼顾医疗机构的正当权益，力求实现公平公正。

　　三是积极化解医疗纠纷。卫健部门组织医疗机构及时采取措施，防止事态扩大，并配合公安机关做好现场处置工作；积极进行政策法规宣传和教育疏导等工作，告知医疗纠纷处理法定途径及注意事项，引导医患双方选择法定途径方式解决纠纷。
