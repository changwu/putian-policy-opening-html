莆田市人民政府办公室关于印发莆田市道路交通安全综合整治三年专项行动实施方案（2019-2021年）的通知

莆政办〔2019〕35号
来源:市府办 时间：2019-06-27 15:37
| | | |

各县（区）人民政府（管委会），市道安成员单位:

　　为进一步巩固深化全市道路交通安全综合整治工作成效，更有效应对涉及道路交通安全的各类社会风险，最大限度预防和减少道路交通事故发生，经市政府研究同意，现将《莆田市道路交通安全综合整治三年专项行动实施方案（2019-2021年）》印发给你们，请结合实际认真组织实施，抓好贯彻落实。

 

　　莆田市人民政府办公室               

　　2019年5月16日               

 

莆田市道路交通安全综合整治三年专项行动实施方案（2019-2021年）

　　为深入贯彻落实习近平总书记关于安全生产的重要指示精神，按照党中央、国务院，省委、省政府关于加强道路交通安全工作的一系列决策部署，根据《中华人民共和国道路交通安全法》等法律法规，结合我市实际，特制定本方案。

　　一、 总体目标

　　到2021年，通过落实五大机制，重点实施“一局一行动”，推动全市道路交通安全工作体制机制更加健全，道路交通安全基础设施更加完善，交通安全执法管理效能明显提升，部门协作机制进一步完善，交通参与者交通安全意识显著增强，道路交通安全形势持续稳定向好。三年专项行动期间，坚决防范和遏制重特大道路交通事故，实现全市道路交通事故死亡人数年平均数与前三年（2016-2018年）的年平均数相比下降5%以上，较大及以上交通事故起数不超过省下达的目标控制数。

　　二、主要任务分工

　　（一）健全完善道路交通安全管理责任机制

　　1.严格落实监管责任。各级政府认真落实党政领导干部安全生产责任制，将道路交通安全工作与经济建设和社会发展同部署、同落实。各相关部门主动履行道路交通安全监管责任，指导本行业开展道安综合整治工作，督促安全生产主体责任落实。

　　责任单位：市道安工作领导小组各成员单位，各县（区）人民政府（管委会）

　　2.加强工作考核和督导问责。推动将道安工作成效纳入平安建设、绩效、安全生产、精神文明建设等考评体系，综合运用警示通报、约谈、挂牌督办等问责措施，压实道安工作责任。

　　责任单位：市应急局、公安局等部门，各县（区）人民政府（管委会）

　　（二）健全完善道路交通安全源头监管机制

　　3.推进营运车辆安全技术应用。推广应用“两客一危”车辆安装智能视频监控报警装置。根据公交车驾驶区域安全防护隔离设施标准，推动公交车驾驶室防护隔离设施的改造和增设工作。

　　责任单位：市交通运输局、公安局等部门，各县（区）人民政府（管委会）

　　4.强化车辆安全监管。加强机动车产品生产一致性和市场准入监管。加强电动自行车生产、销售、维修改装和使用管理。加强对低速电动车生产、销售、道路通行的安全监管。严格落实机动车检验、维修、报废等监管，严厉打击生产、销售不合标机动车、非法改装、拼装和逾期未检验、未报废等违法违规行为。

　　责任单位：市工信局、市场监管局、公安局、交通运输局等部门，各县（区）人民政府（管委会）

　　5.加强重点营运车辆动态监管。督促企业规范监控平台使用与管理。依托福建省道路运输车辆联网联控系统，实现“两客一危”、渣土车及重型货运车辆入网率达100%，“两客一危”及校车上线率、轨迹完整率和数据合格率均达95%以上。

　　责任单位：市交通运输局、市城市管理局、公安局、教育局等部门，各县（区）人民政府（管委会）

　　6.强化驾驶人教育培训。制定机动车驾驶培训机构质量信誉考核办法，建立排名通报制度。推行大型客货车驾驶人职业教育。严格落实“两个教育”工作机制，提升重点驾驶人审验率、换证率和满分学习率。

　　责任单位：市公安局、交通运输局等部门，各县（区）人民政府（管委会）

　　（三）健全完善道路交通安全隐患排查治理机制

　　7.完善道路交通安全设施。落实“三同时”制度，对新、改、扩建公路项目推广安全性评价，安全设施未验收或验收不合格的不得通车运行。到2021年，提级改造农村公路150公里以上，新改扩建城市道路240公里以上，改造普通公路危桥30座，实施公路生命防护工程100公里以上。

　　责任单位：市交通运输局、应急局、住建局、公安局等部门，各县（区）人民政府（管委会）

　　8.深化城市道路交通文明畅通提升行动计划。加强城市道路提升改造和隐患整治，制定城市交通安全管理设施管理办法，落实统一的归口管理和经费保障。完善城市建设项目交通影响评价体系，大型建设项目100%通过交通影响评价。

　　责任单位：市公安局、住建局、城市管理局、自然资源局等部门，各县（区）人民政府（管委会）

　　9.滚动排查治理道路隐患。加大对临水临崖、急弯陡坡、隧道桥梁、交叉路口的隐患排查，逐年将排查出的事故多发和危险隐患点段，按督办标准分别纳入各级政府为民办实事项目，推动隐患整治措施落到实处。

　　责任单位：市公安局、交通运输局、住建局、城市管理局等部门，省高速集团莆田管理分公司、福泉分公司，各县（区）人民政府（管委会）

　　（四）健全完善公路交通安全防范管控机制

　　10.夯实农村基层基础。完善示范村居及劝导站建设，推进劝导工作向厂区、景区及校园周边延伸。到2021年，每个村居配备不少于2名专兼职交通安全协管员，国省道沿线村居主要出入口100%建成交通安全示范劝导站，农村交叉口100%落实交通安全设施“五有工程”（有减速坎、警示牌、路中隔离、监控和路灯照明）。2019至2021年期间在原有已建成电子劝导站的基础上，各县（区、管委会）每年至少再新增2个电子劝导站，并实现与公安信息化中心联网，加强视频截屏曝光和处罚。

　　责任单位：市公安局、交通运输局等部门，各县（区）人民政府（管委会）

　　11.建设公路交通监控系统。加大高速公路、普通公路国省县道沿线和交叉口的交通监控设施建设，整合公安、交通、高速公路公司等单位道路视频监控资源和信息共享，逐步实现信号灯、电子警察、卡口监控覆盖县级以上（含）道路主要路口路段。

　　责任单位：市公安局、交通运输等部门，省高速集团莆田管理分公司、福泉分公司，各县（区）人民政府（管委会）

　　12.加强公路防控网建设。推进实施科技治超、科技治违工作，推动全市交通公安联合治超站（点）电子抓拍系统建设，引导货车主动进站接受检测。完善、优化高速公路“超限黑名单”工作机制，全面实施入口称重检测。全面建成高速公路和普通公路干线交通公安联合治超站。

　　责任单位：市交通运输局、公安局等部门，省高速集团莆田管理分公司，福泉高速公司，各县（区）人民政府（管委会）

　　13.强化路面秩序管控。组织开展“两客一危一货”、校车、渣土车、摩托车等车辆专项整治，加大公安交通集成指挥平台推广应用。加强中心城区电动车、摩托车交通违法视频图侦技术运用，打造“机非分离”严管路。国家法定节假日、周末、重大活动期间组织开展“夜查”行动，严厉查处酒醉驾、三超一疲劳及非法营运等违法违规行为。为防渣土车加高栏板和超载运输回潮，督促渣土车安装车载盲区监控视频探头，发挥渣土车监管平台预警和交通视频事后查纠处理违法作用，促进渣土车整治联勤联治常态化。

　　责任单位：市公安局、交通运输局、城市管理局、住建局、教育局等部门，各县（区）人民政府（管委会）

　　（五）健全完善道路交通安全宣传教育机制

　　14.健全交通安全宣教机制。推动新闻媒体常态化刊播交通安全公益广告。实行交通违法群众举报奖励制度。推进乡镇组建交通安全宣传队伍。落实单位、企业和农村“五长一员”（派出所所长、交警中队长、乡长、村长、中小学校校长和交通安全员）交通安全宣传责任。

　　责任单位：市道安领导小组各成员单位，各县（区）人民政府（管委会）

　　15.开展文明交通素质教育。开展交通安全宣传“七进”（进企业、校园、机关、社区、农村、家庭、公共场所）活动。严格落实各中小学交通安全教育地方课程表，确保每年不少于4个课时。在事故多发乡镇中小学周边路口建设电子劝导站，安装人脸识别系统，与公安信息化中心联网，建立家校交安微学群，发挥“小手拉大手，文明一起走”宣传效应，进行常态化警示曝光、约谈教育和视频事后查纠处罚。开展“零酒驾”乡镇（街道）、村居创建和文明交通进驾校“五个一”活动。建立交通安全信用体系，推动将严重交通违法、责任事故等信息纳入个人征信记录并提供共享服务。各县（区、管委会）每年在一个事故多发的国省道乡镇学校周边建设人脸识别系统，加强视频事后截屏曝光和处罚。

　　责任单位：市公安局、教育局、交通运输局等部门，各县（区）人民政府（管委会）

　　16.推进交通宣传载体建设。到2021年，建成1个市级综合型道路交通安全宣传教育基地，每个县（区、管委会）至少建成2个农村专项宣教基地、配备1台多功能交通安全LED流动宣传车。

　　责任单位：市公安局，各县（区）人民政府（管委会）

　　三、重点项目

　　以实施“一局一行动”项目为载体，由相关业务主管部门牵头，各有关部门配合，各地政府抓好落实，并根据实际深化行动部署。

　　（一）市教育局牵头开展校园及周边道路交通环境提升行动。加强和规范校车管理，指导各地逐年排查县道及以上公路（或城区主干道）沿线校园及周边道路安全隐患，并按照“一校一策”，制定并落实标志标线完善、交通乱象整治、上下学高峰期交通组织等交通环境提升行动方案。

　　（二）市工信局牵头开展车辆生产企业安全监管行动。按照规定编制非机动车产品目录，指导电动自行车生产企业落实《电动自行车安全技术规范》（GB17761-2018）。2019-2020年，按照低速电动车规范管理和相关技术标准要求，引导有条件的低速电动车企业转型升级。2020-2021年，按照新能源汽车安全技术标准，指导新能源汽车生产企业抓好工作落实。

　　（三）市公安局牵头开展交通文明安全意识提升行动。定期分析研判交通安全形势，紧盯重点人、车、路和重点违法行为，加强路面管控，严查严重交通违法行为。深化诚信交通专项整治工作，结合路边执勤与违法查纠工作，做细做实查纠、教育、曝光、录入等流程，将诚信交通整治向城乡结合部、农村地区推广铺开，扩大覆盖面和影响力，协调市信用办等部门推动诚信交通联合惩戒等结果应用。加强警示宣传教育，积极策划和组织文明交通系列宣传报道，推广微博、微信和手机客户端等新媒体应用，组织开展文明交通宣传作品评选活动。

　　（四）市住建局牵头城市新改建道路建设。合理规划建设快速路网，完善主次干道网，加大支路改造力度，打通断头路，增设人行天桥和渠化路口，改善交通微循环。发展慢行交通网络，进一步减少“人非共板”、“机非混行”等现象。三年内新改扩建城市道路180公里以上，每年新改扩建城市道路60公里。

　　（五）市城市管理局牵头开展城市主干道市政道路常态普查和渣土车综合监管行动。加强城市道路隐患治理，逐年优化道路网和安全防护设施。加强渣土车管控平台的监督管理和指导，抓好建设项目渣土车运输源头管理，督促工程建设、施工单位严格执行当地建筑垃圾和渣土处置管理规定。

　　（六）市交通运输局牵头开展道路运输安全提升行动。依托福建省道路运输车辆卫星定位公共服务平台，落实道路运输车辆动态监督管理和定期考核制度，规范违规和异常数据的发现、反馈、处置等闭环流程。加大打击非法营运工作力度。指导各地持续开展公路隐患治理，加强日常监管和审核验收。

　　（七）市农业农村局牵头开展“平安农机”示范创建行动。2019-2021年，持续开展“平安农机”示范创建活动，每年全市创建“平安农机”示范乡镇不少于2个。

　　（八）市文旅局牵头开展旅行社租赁旅游包车治理行动。加强旅行社购买交通服务环节的管理，加大旅游交通安全宣传和教育培训力度，督促其租赁有资质旅游车辆，为游客提供有效安全保障。

　　（九）市应急局牵头开展应急救援提升行动。指导各地开展应急演练和应急处置工作，督促修订完善各类应急预案，提高应急处置应对能力和水平。

　　（十）市市场监管局牵头开展车辆经营销售领域监管行动。2019年以电动自行车为重点、2020年以低速电动车为重点、2021年以机动车为重点，部署开展销售领域专项整治行动，严厉打击销售非法改装、拼装以及不符合国家标准产品等违法违规行为。

　　（十一）市气象局牵头开展交通气象服务提升行动。2019年，加强恶劣天气预警信息发布系统在交通领域的对接应用。2020年，建设涵盖风险预警产品、应急管理、信息发布、用户管理及监控管理于一体的交通气象服务平台。2021年，建立健全交通管制气象风险指标体系。

　　（十二）省高速集团莆田管理分公司、福泉高速公司开展高速公路通行服务提升行动。推进全市高速公路交通安全防护设施提升工作，督促司属相关单位加强高速公路沿线安全隔离设施、收费站出入口拦阻设施和服务区的巡查和管控；加强交通安全宣传教育和信息发布；探索并逐步建立地方政府负总责、属地管理、行业监管、企业参与的高速公路桥下空间治理联动机制。

　　四、工作要求

　　（一）加强组织领导。各级各有关部门要提高政治站位，5月中旬前，要根据职责分工，结合辖区工作实际，制定三年专项行动具体方案和2019年工作要点，明确目标任务和完成时限，加强组织部署，切实把三年专项行动作为“一把手工程”抓好抓实。各级各有关部门主要领导要亲自抓、亲自管，定期研究，部署推进。各级道安办要牵头各相关成员单位，定期组织召开道安办主任会议，研究部署推动工作。各地要结合实际，每年梳理一批交通亡人事故多发或安全隐患突出的乡镇（街道），列入次年重点督促整改对象，推动道路交通安全问题整改。

　　（二）健全保障机制。各级政府要进一步巩固和深化“政府主导、部门联动、社会参与”的道安合成共治机制，加强乡镇道安综治和网格化工作合力，抓实抓好农村道路交通劝导、宣传、纠违工作。要完善道安办组织架构，5月上旬前，市、县、乡三级政府须调整完善道安工作领导小组及办公室，参照省里做法，按照不少于“市级7人、县级5人、乡级3人”要求，配齐道安专职工作人员，全脱产集中办公，健全运行机制。要加大经费投入力度，切实保障道安办日常办公、交通安全设施建设、交通管理和执法队伍、装备建设等需求，同级财政要对农村交通安全劝导站、交通安全协管员和劝导员给予必要的年度财政经费保障。要建立恶劣天气、事故等突发情况应急处置预案体系，定期组织开展预案演练。市道安办要加强工作协调、指导和督促，推动各项道安工作措施落到实处。

　　（三）严格考评通报。各级政府要加强道安工作的目标考核，建立综合治理工作月通报制度，并根据通报的情况，进行跟踪督导。对工作成效明显的，要及时推广经验和做法；对工作被动应付、措施落实不力或事故多发的地区和单位，要采取通报、约谈等措施，推动工作落实。
