莆田市人民政府办公室关于印发莆田市公共建筑和城市公共照明节能改造实施方案的通知

莆政办〔2017〕164号
来源:政府办 时间：2017-11-15 09:49
| | | |

 

各县（区）人民政府（管委会），市直有关单位：

《莆田市公共建筑和城市公共照明节能改造实施方案》已经市政府研究同意，现印发给你们，请认真组织实施。

 

                           莆田市人民政府办公室                  

                        2017年11月3日                

 

莆田市公共建筑和城市公共照明节能改造实施方案

为贯彻落实《福建省人民政府办公厅关于推进公共建筑和城市公共照明节能改造七条措施的通知》（闽政办〔2016〕74号），进一步推行合同能源管理，推进我市公共建筑和城市公共照明节能改造工作，结合我市实际，制定本实施方案。   

一、改造目标。到2020年，全市完成公共建筑节能改造10万平方米，完成城市公共照明节能改造0.5万盏。各级各有关部门改造目标详按莆田市公共建筑和城市公共照明节能改造任务分解表（附件）。

二、改造重点。公共建筑重点改造达不到国家现行节能设计标准的5000平方米以上的公共机构建筑和20000平方米以上的社会投资公共建筑，主要改造空调、热水、照明等用能系统和建筑外窗。城市公共照明重点改造光源、灯罩和控制系统，加快推广应用LED照明产品，淘汰白炽灯、高压汞灯和能效未达到国家标准的高压钠灯。按示范先行、循序渐进的原则，率先启动商场超市、宾馆饭店、高校、医院和使用中央空调系统的办公建筑以及城市公共照明节能改造示范。

三、保障措施

（一）加强组织领导，明确部门分工。建立推进公共建筑和城市公共照明节能改造工作局际联席会议制度，负责指导协调督促各地各部门开展工作，联席会议办公室设在市住建局。市住建局负责城市公共照明节能改造和全市年度改造项目情况清单汇总上报；市财政局负责落实公共建筑节能改造补助资金；市经信委负责将节能改造工作纳入地方政府年度节能目标责任评价考核内容；市商务局配合做好全市商场超市建筑节能改造；市旅游局负责督促协调星级酒店公共建筑节能改造；市教育局负责组织市属学校和以市为主管理的高校公共建筑节能改造；市卫计委负责组织市属医院公共建筑节能改造，并督促指导全市医院公共建筑节能改造；市国资委负责组织协调市属国企公共建筑节能改造；市机关事务管理处负责指导协调市直机关办公建筑节能改造；国网莆田供电公司配合业主提供公共建筑和城市公共照明改造项目的计量电表用电信息；各县（区）政府（管委会）负责组织县（区）所属单位和企业及社会投资公共建筑节能改造工作。

各县(区)政府（管委会）和市直相关部门要高度重视，坚持“谁主管、谁负责”和“属地管理”的原则，切实把此项工作摆上重要议事日程，加强组织领导，制定工作方案，细分目标任务，落实改造项目，并于每年5月20日前将年度改造项目清单报市住建局。

（二）加大财政金融支持，完善财务管理制度。支持符合条件的地区、高校和医院申报财政部、住房城乡建设部公共建筑节能改造国家试点，争取中央资金支持。市级财政对市直机关、市属医院、市属高校和市属学校公共建筑节能改造项目给予补助，补助标准为：对节能率不低于20%的大型公共建筑、节能率不低于15%的其他公共建筑，给予15元/平方米补助；已获得各级财政节能减排补贴的项目，不得重复申请此项补助资金。各地政府可结合当地实际出台公共建筑节能改造补助政策。符合条件的城市公共照明节能改造项目可按《福建省合同能源管理财政奖励资金管理暂行办法》（闽财企〔2011〕42号）及当年发布的申报指南申请合同能源管理奖励资金，公共建筑节能改造项目不得再申请该奖励资金。支持金融机构发行绿色金融债券，募集资金加大节能改造支持力度。鼓励银行业金融机构开展能效信贷等绿色信贷服务，加大对节能服务公司信贷支持力度。支持符合条件的节能服务公司发行绿色债券。

各级机关单位、各学校支付给节能服务公司的费用视同能源消费，在部门公用经费中列支；企事业单位支付给节能服务公司的费用计入相关支出；城市公共照明管理机构支付给节能服务公司的费用纳入各级财政预算。公共机构实施节能改造留存的节能收益可在单位部门预算中统筹用于项目后续养护、物业管理人员奖励等支出。能源管理合同期满后，用能单位取得相关资产作为接受捐赠处理，节能服务公司作为赠与处理。

（三）优选节能服务公司，规范节能改造合同。公共机构建筑、城市公共照明节能改造一般应采用合同能源管理方式，按服务类项目进行政府采购，鼓励采用竞争性磋商采购方式择优确定节能服务公司。社会投资公共建筑鼓励采用合同能源管理方式实施节能改造，依法确定节能服务公司。鼓励物业公司参与节能改造项目，分享节能效益。引导和支持我市大型国有企业、优质企业或上市公司开展合同能源管理业务，培育一批龙头骨干企业，提升合同能源管理专业化水平。

节能改造合同应明确现有用能设备清单、改造内容和实施方案，约定能耗基准值、节能效益分享比例、合同期限、节能量认定规则和第三方节能率审核机构。能耗基准值可按照改造前1-3年能耗平均值确定，不具备能耗计量条件的项目由双方共同认可的第三方节能量审核机构检测、验证、裁定。节能效益按双方约定的比例分享，合同期一般不超过10年。公共机构建筑、城市公共照明节能改造项目节能量应委托第三方节能量审核机构进行审核，作为结算依据；社会投资公共建筑节能改造项目节能量按双方约定实施。第三方节能量审核机构可从财政部、国家发展改革委公布的目录中选择，也可从住房城乡建设部公布的民用建筑能效测评机构备案名单中选择。因经营状况、使用功能、用能方式等发生改变可能导致节能量下降的，应及时签订补充协议。

（四）强化靠前服务指导，提升节能服务质量。各级各有关主管部门要靠前服务，指导用能单位把好节能改造实施方案和项目验收关。用能单位可根据实际情况聘请工程监理等专业机构进行项目监理。节能服务公司要根据合同约定实施节能改造，做到科学管理、文明施工，尽量减少对正常办公的干扰；要对节能改造项目同步安装用电分项计量装置，强化节能设施监测、跟踪，发现异常情况及时处理；要加大对用能单位或物业公司的宣传培训，做好日常运行维护管理，促进节能降耗。
