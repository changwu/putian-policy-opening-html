莆田市人民政府办公室关于印发莆田市推动实体零售创新转型实施方案的通知

莆政办〔2017〕154号
来源:政府办 时间：2017-10-13 15:05
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　经市政府研究同意，现将《莆田市推动实体零售创新转型实施方案》印发你们，请认真抓好落实。

 

　　莆田市人民政府办公室               

　　2017年10月2日               

 

莆田市推动实体零售创新转型实施方案

　　为了推动我市实体零售创新转型，适应经济发展新常态，增强发展动力，根据《国务院办公厅关于推动实体零售创新转型的意见》（国办发〔2016〕78号）、《福建省人民政府办公厅关于印发推动实体零售创新转型实施方案的通知》（闽政办〔2016〕206号）精神，结合我市实际，制定本实施方案。

　　一、调整商业结构

　　（一）调整区域结构

　　1.按照“时尚购物在主城、区域商业有中心、便民便利社区行”的商业布局思路，盘活中心城区商务楼宇资源，引进国内外知名商贸企业入驻，培育一批新兴城市商业综合体，促进万达广场、正荣财富中心、文献步行街等城区商业圈加快集聚,提升城区商圈品质。推动商贸业融入美丽莆田行动计划，围绕“十个特色小镇、三个文化名胜区”建设，重点打造一批集文化、旅游、商贸为一体的特色产业小镇及商旅文化聚集区，提升城乡商业档次。各县（区、管委会）中心城区分别重点培育1至2个方便快捷、消费力集中的区域消费中心或特色商业街，引领带动实体零售提档升级、聚集发展。

　　责任单位：市商务局、规划局、住建局、文广局、旅游局，各县（区）人民政府（管委会）

　　2.支持永辉、新华都、凤凰百货、6+3等大型零售企业及快递领域龙头企业向农村延伸服务网络。支持淘宝、京东等知名平台铺设县（区）级服务中心或村级电商综合服务网点，完善城乡布局，打通“最后一公里”。力争每年新增智能快件（信包）箱50组以上，到2020年累计达600组。引入第三方配送公司参与农村交通综合服务站建设，争取2020年建设快递城乡综合服务站500个，实现“乡乡有网点，村村通快递”。实施农贸市场改造提升工程，力争在2020年实现辖区所有市场全部实现规范化改造或“农改超”提升。

　　责任单位：市商务局、邮政管理局、农业局，各县（区）人民政府（管委会）

　　（二）调整业态结构

　　1.引进发展商贸新业态新模式，鼓励实体零售企业深度联营，提高零售自营比例，改变引厂进店、出租柜台等传统运营模式。鼓励购物中心、百货店、综合超市等结合门店结构，探索“零售+餐饮”“零售+休闲娱乐”“零售+体验”等经营模式，引导传统销售场所向社交体验、家庭消费、时尚消费、文化消费中心转变，满足个性化消费需求。引导专业市场、行业龙头企业、行业商协会在知名电商平台建设莆田特产（色）馆。优化社区商业网点建设和业态配置，重点推动文献便民、易太、三巴旺等一批连锁化、品牌化企业，2020年前新增社区便利店2000家以上。优化社区超市、生鲜水果、医药、服装干洗等便民网点，打造“一刻钟城市便民生活服务圈”。

　　责任单位：市商务局，各县（区）人民政府（管委会）

　　2.支持零售企业与创意产业、文化艺术产业、会展业、旅游业融合发展。打造以图书连锁超市为核心，集文化展示、教育培训、动漫体验、创意文化用品销售、影剧院等功能于一体的复合型图书零售业态和文化综合体，促进其从单一的销售图书向多元化连锁体验消费转型升级。支持具有妈祖元素等旅游商品创意孵化，推动旅游商品进入线上、线下实体商店。推动烟花爆竹连锁经营，对供销社系统的烟花爆竹零售企业（点）实施连锁配送。

　　责任单位：市文广局、经信委、商务局、旅游局、安监局、供销社，各县（区）人民政府（管委会）

　　（三）调整商品结构

　　1.深入推进品牌战略建设，鼓励引导我市企业争创国家、省、市质量奖、名牌产品，共创国家级消费品工业“三品”战略示范点城市。对接全国知名电子商务平台，持续开展“莆田好鞋”活动，培育玩觅、易佰达等一批莆田鞋业核心品牌。实施“莆田老字号”振兴计划，2020年前，力争认定“莆田老字号”企业30家，对老字号企业在技术改造、品牌推广等方面给予财政支持。持续开展莆货华夏行、网上行、境外行等名特优产品展销活动，努力开拓消费市场。

　　责任单位：市商务局、经信委、质监局、工商局，各县（区）人民政府（管委会）

　　2.持续推进国家食品安全示范城市创建活动，充分利用省可追溯信息监管系统和质量安全追溯系统资源，进一步扩大肉品追溯信息监管系统覆盖面，提高追溯体系的运行效率。鼓励和引导农产品“三品一标”企业建立专卖店或销售摊位，推动可追溯作为水产品和农产品准入市场的要件之一。

　　责任单位：市商务局、农业局、海洋渔业局、质监局、食品药品监管局、工商局，各县（区）人民政府（管委会）

　　二、创新发展方式

　　（一）服务企业创新

　　1.推广快消品供应链平台服务模式，引导实体零售企业优化上游供应链，与供应商构建信息共享、利益均摊、风险共担的新型零供关系。推广使用全省寄递业实名寄递综合监管平台，支持在我市建设福州国际邮件互换局莆田分中心，待条件成熟支持建设国际快件监管中心。积极推进商贸物流标准化建设，推广使用标准化托盘，支持托盘循环共用体系和商贸物流信息平台建设。鼓励快递企业依托供应链管理优势，发展集中分拣、快件集散、统一配送为一体的“仓储配送一体化”等先进服务方式，为优化中小零售企业配送提供服务，力争2020年快递行业仓配一体化面积达到20万平方米。

　　责任单位：市商务局、质监局、邮政管理局、经信委，各县（区）人民政府（管委会）

　　2.引进中小商贸流通企业公共服务平台，全力打造华闽外贸综合服务平台、众协联鞋业产业供应链平台以及跨境通等一站式产业链平台，为企业提供信息、政策、培训、咨询等一系列服务。支持企业创新商业模式、优化管理体制、构建新型零供关系、增强服务体验等创新转型，鼓励医疗器械零售连锁化经营，鼓励在大型公共场所设置自动售药机、自动销售医疗器械机，或具有按产品温湿度单独储存空间的自动售货机销售二类、一类较低风险的家庭自用型医疗器械产品。鼓励药品连锁企业在24小时连锁便利超市设置便民药柜。

　　责任单位：市商务局、经信委、食品药品监管局，各县（区）人民政府（管委会）

　　（二）促进跨界融合

　　1.实施“互联网+”行动计划，推进电子商务与实体零售融合发展。重点建设普天药械网、找银网、中房购等一批面向全国、覆盖全产业链的行业垂直电商平台、推动零售企业信息化和大数据改造并向平台企业转型。大力推动“网货下乡”和“农产品进城”双向流通，与阿里巴巴集团合作开展农村电商，完善面向农村的网络购销和物流仓储配送服务，将莆田市打造成全国电子商务示范城市。扶持10个农业龙头企业和“菜篮子”基地建设，加快推广“超市+基地”“批发市场+基地”等农产品现代流通模式，组织大型超市同农业生产基地建立产销对接，降低农产品流通成本。

　　责任单位：市商务局、农业局，各县（区）人民政府（管委会）

　　2.支持有条件的内贸市场开展市场采购贸易试点，鼓励企业开展国际营销服务体系建设，提升国际化经营能力。鼓励具有技术、品牌、质量、服务优势的外贸企业开拓国内市场。积极推进国际贸易“单一窗口”系统，推动企业生产体系提质增效升级，促进国内标准、出口标准和国际标准的“三标并轨”，引导出口企业实现内外销“同线同标同质”，成功实现内销转型。进一步提高零售领域利用外资水平，引入资本、技术、管理。继续从贷款贴息、前期费用、资源回运、投资和人员保险等方面支持企业“走出去”。

　　责任单位：市商务局，莆田海关、莆田检验检疫局，各县（区）人民政府（管委会）

　　三、优化发展环境

　　（一）加强商业布局

　　加快编制城市商业网点专项规划，科学制定城市商业网点设置技术标准。通过由商务、住建、国土、规划、环保等部门和重点商业企业、行业协会、社区代表参与的论证会，并经专家评审后报市政府审批，确保商业布局合理、网点规范设置、商事有序发展。在镇（乡）总体规划、村庄规划编制和幸福家园、美丽乡村建设中，优化安排相关商业服务网点用地。整合存量资源、挖掘现有商业设施资源潜力，引导市场饱和度较高的购物中心、百货店等业态向新建社区、农村拓展。

　　责任单位：各县（区）人民政府（管委会），市规划局、住建局、国土局、商务局

　　（二）促进公平竞争

　　1.严厉打击制售假冒伪劣商品、侵犯知识产权、不正当竞争、商业欺诈违法等犯罪行为。健全完善公安、工商、食品药品监管、质监、知识产权等部门信息共享、办案协作、联合执法等机制，指导广大莆商企业防范知识产权犯罪，形成各方联手打假的强大合力，更好地服务全市经济发展。依法禁止以排挤竞争对手为目的的低于成本价销售行为，依法打击垄断协议、滥用市场支配地位等排除、限制竞争行为。依托政务数据汇聚平台，建立覆盖线上线下的企业及相关主体信用信息采集、共享与使用机制，并通过国家企业信用信息公示系统、信用莆田平台对外公示，健全守信联合激励和失信联合惩戒机制。

　　责任单位：市商务局、工商局、公安局、知识产权局、质监局、食品药品监管局、物价局、发改委，各县（区）人民政府（管委会）

　　2.强化连锁经营企业总部管理责任，重点检查企业总部和配送中心，减少对销售普通商品零售门店的重复检查。加强各级监管部门工作沟通，避免对同一零售门店1天内多次抽检，或者连续几天抽检，减轻超市等零售终端检查风险和压力。同等对待大型连锁企业与小微企业、个体工商户（农贸市场），杜绝抓大放小现象。对零售环节检查发现的不合格商品，在商品票证齐全且商家无过错的情况下，公开通报时合理确定生产者、经营者责任义务。

　　责任单位：市工商局、商务局、质监局、食品药品监管局、物价局，各县（区）人民政府（管委会）

　　（三）完善公共服务

　　加强家政服务业等商贸服务领域标准研究，选择基础较好、积极性高的企业开展家政服务标准化试点示范建设工作。贯彻落实福建省重点领域电子商务标准，引导企业提高标准应用水平。加强零售业统计监测和运行分析工作，整合各类信息资源，引导各类市场主体合理把握开发节奏、科学配置商业资源。发挥行业协会作用，建设多层次零售业人才队伍，提高从业人员综合能力。

　　责任单位：市商务局、质监局、统计局，莆田调查队，各县（区）人民政府（管委会）

　　四、强化政策支持

　　（一）推进简政放权

　　1.实施企业“五证合一、一照一码”、个体工商户“两证整合”改革和企业名称“自助查重、自主申报”便利化改革。深化住所登记改革，分行业、分业态释放住所（经营场所）资源，为实体零售市场主体提供低成本住所（经营场所）。放宽经营范围用语表述，允许实体零售市场主体既可以参照《国民经济行业分类》，也可以参照政策文件、行业习惯或者专业文献表述经营项目。

　　责任单位：市工商局，各县（区）人民政府（管委会）

　　2.取消投资额30万（含）以下或建筑面积300平方米（含）以下的建设工程消防设计和竣工验收消防备案；取消建筑面积300平方米（含）以下的公众聚集场所（除公共娱乐场所外）投入使用营业前消防安全检查。精简部分项目受理材料，建筑面积1000平方米（含）以下的办公场所和300平方米（含）以下的公众聚集场所（除公共娱乐场所外）装修工程，消防设计文件可采用建设单位提供由计算机制作、能真实反映工程情形的示意图。

　　责任单位：市消防支队，各县（区）人民政府（管委会）

　　3.完善城市配送车辆通行制度，为城市配送车辆通行提供便利措施。在限制通行路段和时段，经公安机关交通管理部门同意，配送车辆在确保安全的前提下，可以通行；对城市配送车辆发生的轻微交通安全违法行为，以教育为主，在违法行为得到纠正后放行；对城市配送车辆在配送途中发生道路交通事故，因调查取证需要扣留车辆的，在对车辆所载货物重量、体积进行核实后，及时通知车辆所有人自行处理车辆所载货物。

　　责任单位：市公安局，各县（区）人民政府（管委会）

　　4.进一步完善和落实允许品牌连锁便利店现场制售熟食和设置便民药柜的政策，出台实施细则。企业从事出版物批发、零售业务，不具备法人资格的直营门店不需单独办理出版物经营许可证，在依法办理分支机构工商登记并领取营业执照后15日内，持企业总部办理的出版物经营许可证正副本复印件、企业基本情况介绍材料以及该分支机构的经营场所、经营范围介绍材料到原发证机关和分支机构所在地出版行政主管部门备案。按“一照多址”模式，在快递行业推行同一县级工商登记机关（市场监管部门）管辖范围内“一照多址”模式改革，简化快递末端网点备案手续。

　　责任单位：市文广局、食品药品监管局、邮政管理局，各县（区）人民政府（管委会）

　　5.杜绝以任何形式对连锁企业设立或变更非企业法人门店和配送中心设置障碍。对连锁企业要求变更为非企业法人门店的，简化证照变更手续，其中，对仅公司名称变更的或消防安全责任人变更的，提交相关证明材料后，经书面审查，可依法核发消防安全检查合格证；对仅公司名称变更的，若建设地点、规模、性质和主要污染防治措施未发生重大变更，原环评审批、验收手续仍然有效；对仅公司名称变更的，不涉及许可条件变化的，可根据变更后的营业执照等经营证件直接换发新的《食品经营许可证》。

　　责任单位：市环保局、食品药品监管局、消防支队，各县（区）人民政府（管委会）

　　（二）依法减轻企业税费负担

　　落实好总分支机构汇总缴纳企业所得税、增值税相关规定。零售企业符合相关政策规定的，可汇总计算并缴纳企业所得税和增值税。落实高新技术企业和研发费用加计扣除所得税优惠政策，符合条件的企业可按规定享受优惠并于年度申报时向税务机关履行备案手续。落实取消税务发票工本费政策，不得以任何理由强制零售企业使用冠名发票、卷式发票，大力推广电子发票。全面落实工商用电同价政策，开展商贸企业自主选择执行行业平均电价或峰谷分时电价试点。落实国家银行卡刷卡手续费定价机制改革方案，切实减轻零售企业和商户经营成本负担。

　　责任单位：市财政局、物价局，国网莆田供电公司、市国税局、地税局、人行莆田市中心支行，各县（区）人民政府（管委会）

　　（三）加强财政金融支持

　　1.继续统筹省、市财政资金支持内贸发展，推进商贸服务业转型升级。鼓励工业企业剥离销售业务，注册独立的商贸法人企业，并纳入限上统计。促进零售企业做大做强，对新增纳入我市限上统计、以及对纳入我市限上统计年销售额同比增幅较大的企业给予支持。

　　责任单位：市商务局、财政局，各县（区）人民政府（管委会）

　　2.支持第三方支付机构在坚持小额便民原则的基础上，与零售企业合作发展二维码支付，鼓励依法合规提供网上销售支付服务。鼓励银行业金融机构在大型零售卖场布放自助终端设备，建立零售企业线上线下融合发展的良好支付环境。将实体零售创新转型纳入各级政府产融合作对接平台，引导金融机构提供贷款、债券融资、股权融资等一揽子金融服务。积极发展并购贷款，支持传统零售企业通过并购、重组等多种方式丰富经营业态，加快转型升级。积极稳妥扩大消费信贷，对符合条件的消费金融公司申请及时予以办理。

　　责任单位：市商务局、财政局、金融办，人行莆田中心支行、莆田银监局，各县（区）人民政府（管委会）

　　各级各部门要切实加强组织领导，健全部门协同和上下联动机制，找准工作着力点和突破口，抓紧制定具体实施方案，出台针对性、操作性强的配套措施。市商务局要会同市直有关部门做好业务指导和督促检查，确保实体零售创新转型取得成效。
