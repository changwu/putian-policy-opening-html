莆田市人民政府办公室关于转发莆田市城乡绿化工作实施方案的通知

莆政办〔2011〕37号
来源:市府办 时间：2011-04-15 16:46
| | | |

各县（区）人民政府（管委会）、市直有关单位：
　　市住房和城乡建设局、市委农办制定的《莆田市城乡绿化工作实施方案》已经市政府同意，现转发给你们，请认真组织实施。

莆田市人民政府办公室        
                         二〇一一年二月二十五日        

莆田市城乡绿化工作实施方案
市住房和城乡建设局  市委农办

　　为贯彻落实党的十七届五中全会精神和省委八届九次全会部署，根据《中共福建省委、省政府关于印发抓紧落实事关群众利益十项实事工作的通知》（闽委[2010]35号）和《福建省人民政府办公厅转发省住房和城乡建设厅、省农办关于加快城乡绿化建设实施方案的通知》（闽政办〔2010〕290号）及《中共莆田市委 莆田市人民政府关于印发抓紧落实事关群众利益十项实事工作方案的通知》（莆委〔2010〕82号）、《中共莆田市委 莆田市人民政府关于2011年开展为民办实事活动的通知》（莆委〔2011〕1号）精神，结合我市实际情况，制定本实施方案。
　　一、总体要求
　　深入贯彻落实科学发展观，坚持“先行先试、加快转变、民生优先、党建科学”，切实把保障和改善民生放在优先位置，努力做到事关民生的财政投入优先保证，事关民生的利益问题优先解决，事关民生的保障机制优先构建。围绕构建城景相融的“环保都市”目标和“弘扬生态文明，共建绿色莆田”主题，集中力量、突出重点、全力以赴、务求实效，争取在年底前建成见效一批、明年落实一批事关群众利益的实事项目，扎实推进城乡绿化一体化建设，把莆阳大地建成山川秀丽、环境优美的滨海宜居城市。
　　二、目标任务
　　（一）城市绿化
　　2010年目标任务：
　　2010年是我市创建国家园林城市的攻坚年，按照2010年我市大干150天小城镇战役奋战目标要求，以省运会召开为契机，结合城市建设，认真组织实施一批城乡园林绿化建设任务。2010年完成建设任务目标：
　　1．城市公园建设。完成莆田市体育公园、仙游兰溪北岸西侧公园的建设工作；完成泗华水上公园（一期）、绶溪公园（一期）、秀屿区土海湿地公园（一期）等3个城市公园的前期工作。
　　2．林荫景观道建设。完成迎宾大道（一期）、城港大道、东圳路、延寿路等4条道路绿化改造提升工程。
　　3．街头绿地建设。完成福厦铁路莆田站广场、莆田高速公路西入口绿地、黄石高速出入口绿地、体育馆游泳健身馆绿地、莆仙大剧院广场绿地、体育中心园林绿化改造、重竞技馆广场绿地、市电业局荔能小区公共绿地等22块街心绿地工程。
　　4．垂直绿化工作。完成迎宾大道立交桥、壶公大道跨线桥、东园路跨线桥、木兰溪桥、延寿山庄高架桥等5座城市桥梁的垂直绿化工作。2010年全市规划建设垂直绿化50处以上，各区建设任务为：城厢区12处，荔城区12处，涵江区12处，秀屿区7处，仙游县5处，北岸1处，湄洲岛1处。
　　2011年目标任务：
　　2011年是“十二五”规划的开局年，也是我市全面推进国家园林城市建设的关键年，按照省委、省政府“四绿”工程及《关于印发抓紧落实事关群众利益十项实事工作方案的通知》的要求，根据市委、市政府提出的城市绿化“四结合”工作思路及省建设厅创建国家园林城市的指导要求，认真落实科学发展观，以“创建国家园林城市、提升城市园林品位、打造滨海宜居城市”为工作目标，以“全面绿化与建设重点精品工程相结合”为工作思路，把握机遇，强化管理，全力推进园林绿化事业跨越发展，力争顺利通过国家园林城市的考评验收。2011年的园林绿化工作重点是实施八大园林绿化工程，全面提升园林绿化档次、品位，促进园林绿化事业跨越发展。主要任务目标：
　　1．公园建设工程：重点抓好东岩山公园、绶溪公园（一期）、九华山休闲公园、天马山休闲公园和土海湿地公园（一期）等5处公园建设，同时启动九华山植物园等规划。
　　2．城市节点绿化工程：重点实施车站、码头、高速出入口以及市区景观片区的绿地广场工程，打造莆田城市之门、城市之窗的良好形象。具体项目：涵江火车站站前广场、涵江高速公路出入口绿地、文甲码头广场等3个城市主要节点园林景观项目。
　　3．街头绿地工程：因地制宜开展建设城市小绿地、小公园、小街景等工作，2011年计划利用城市道路交叉口、河滨控制带、边角地等，按照步行10-15分钟有一块公共休闲绿地的建设目标进行规划；计划规划建设街头绿地18块，其中1000平方米以上的16块。
　　4．林荫景观道工程：重点实施迎宾大道（二期）等4条城市主干道道路绿化改造提升工程，同时大力推进城市其他道路绿化美化工作，使城市道路绿化普及率达到95％以上，展示莆田新形象。
　　5．荔枝林景观带工程：通过河道截污清淤工程重点实施木兰溪北洋水系荔枝林休闲景观带，将莆田市的公共绿地有机串联起来，逐步建成一个“水清、河畅、岸绿”、具有荔林水乡特色的绿色生态系统。计划重点建设莘郊荔枝林带（市公安局-海源大酒店）、荔浦荔枝林带（海源大酒店-汽车站）、秀水荔枝林带（荔能小区-莆田四中）等荔枝林景观带工程，同时做好其他滨河绿化带的建设。
　　6．垂直绿化工程：实施空中增绿，全方位推进立体绿化，计划将屋顶绿化纳入社区公园建设范畴，积极鼓励各社区因地制宜，规划建设屋顶绿化工程；2011年全市规划建设垂直绿化150处以上，各区建设任务为：城厢区30处、荔城区30处、涵江区15处、秀屿区15处、仙游县50处、北岸5处、湄洲岛5处。
　　7．拆墙透绿工程：积极推进临街单位拆墙透绿，市直机关单位带头实施，各县（区）要成立拆墙透绿工作指挥部，专门负责拆墙透绿工作，2011年6月份前完成任务。
　　（二）乡镇绿化
　　1．建设目标：结合社会主义新农村建设和小城镇建设以及滨海宜居城市建设，以绿化促美化、绿化促文明。到2011年，创建目标乡（镇）建成区绿化覆盖率达到18.5%以上，人均公园绿地面积达到5.5平方米以上，公园绿化面积占陆地面积的70%以上。
　　2．建设任务：选择在集镇，特别是中心镇开展绿色乡镇创建活动。2010-2011年计划创建绿色乡（镇）18个，其中仙游县、荔城区、城厢区各3个，涵江区5个，秀屿区2个，北岸和湄洲岛各1个。至2010年底，全市要完成鲤南镇、榜头镇、西天尾镇、新度镇、华亭镇、常太镇、江口镇、白塘镇、梧塘镇、白沙镇、笏石镇、东庄镇等12个创建绿色乡镇任务。2011年，要完成枫亭镇、黄石镇、东海镇、大洋乡、山亭镇、湄洲镇等6个乡镇的创建工作。所有创建绿色乡镇要按照《福建省绿色乡镇标准》和《福建省城乡一体化“四绿”工程实施方案（2010-2012年）》的要求，加强组织领导，落实园林绿化建设和养护经费，建立健全管理制度，加强古树名木，乡镇历史文化、文物古迹、自然风貌的保护、重视乡镇住宅集中区及单位庭院重视绿化美化工作，落实在乡镇规划区范围内一座公园的建设，要求公园绿化面积占陆地总面积的70%，植物配置合理，养护管理良好。乡镇建成区道路、乡镇住宅集中区及单位实现绿化、美化。
　　（三）村庄绿化
　　以各级新农村建设试点示范村和扶贫开发工作重点村为重点，选择中心村和生态区位重要的村（居委会），组织发动农民群众大力开发“四旁四地”（村旁、宅旁、水旁、路旁；宜林荒山荒地、低质低效林地、坡耕地、抛荒地）等非规划林地，种植珍贵和优良乡土树种，建设一批示范绿色村庄，以绿化促美化、绿化促文明、绿化促致富，最大程度地发挥其生态、经济和社会效益。今年底前创建“绿色村庄” 71个，2011 年底前再创建 129 个（具体任务分解见附件3），并向全市所有建制村推开，逐步实现全覆盖。今年底前创建“农民公园”10个，2011年底前再创建20个。省定第三轮9个整村推进扶贫开发重点村、省级15个新农村建设示范联系村、5个灾后重建集中安置点、3个造福工程百户以上集中安置点和市级100个新农村建设中心村，列为造林绿化先行示范村。
　　列为今明两年创建的绿色村庄，要求建设 1 处以上的公园绿地，“四旁”、“四地”基本绿化。公园绿地面积要求200平方米以上（其中“农民公园”建设要求占地2000平方米以上），新增绿地乔木片林面积占70%以上。辖区内宜林荒山绿化率达95%以上，路旁两侧、水旁宜林地段绿化率达 80%以上，农田林网控制率达 85%以上。村旁、宅旁种植名贵和优良乡土树种占 40%以上，户均每年种植5株以上；主要路旁两侧边沟以外及水旁宜绿化地段各种植2排以上优良乡土树种。
　　三、保障措施
    （一）加强组织领导。办好事关群众利益的城市绿化工作，时间紧、任务重，各县（区、管委会）和有关部门要从全局出发，统一思想、提高认识，要把办好城乡绿化实事作为当前和明年的一项重要工作，主要领导亲自抓，分管领导具体负责，强化统筹协调，加大工作力度，切实把好事办好。
    （二）明确工作责任。各县（区、管委会）和有关部门要切实落实主体工作责任，主要领导对办好十项实事之一的城乡绿化工作负总责，切实把这项工作纳入重要的议事日程，按照市委、市政府的工作部署，精心制定实施方案，明确目标任务，确保责任到位、工作到位。市直各有关部门要加强联动，形成合力。市财政局负责安排下达有关补助资金，协调督促各级财政落实资金；市发展改革委、市国土资源局按职责分工，督促指导各级部门为绿化项目的相关审批工作开通“绿色通道”；市林业局负责协调“绿色乡镇”、“绿色村庄”创建所需造林苗木生产供应，做好造林技术指导服务。市文明办负责将绿色乡镇、绿色村庄创建纳入文明乡（村）的评选内容，加强督促指导。
　　（三）资金落实保障。各县（区、管委会）要做到事关民生的财力优先保证，将办好十项实事的城乡绿化工作所需经费纳入同级财政预算予以保证，确保“十项实事”工程建设有一个稳定的资金投入渠道；各部门要依法落实部门绿化责任，特别是公路、交通、国土、建设等有关部门，要安排一定资金，专门用于部门“十项实事”城乡绿化工程建设，加大绿化建设投资力度；各乡镇（街）、行政村要落实配套资金，支持绿化工程建设；要研究制定相应的政策措施，积极鼓励多元化投入，引导、动员社会资金参与办好城乡绿化工作上来。可通过创新义务植树的方式，大力开展义务植树基地建设和林地绿地认建认养活动，落实义务植树属地管理，提高义务植树尽责率；通过开展单位庭院和住宅小区绿化美化，鼓励屋顶绿化和垂直绿化，增加城市绿量。
　　（四）加强“绿线”管理工作。为提升我市的园林绿化水平，促进园林绿化全面高标准、高水平建设，按照《城市绿线管理办法》等相关条例，加强城市园林绿化设计方案审批工作，将城市园林绿化设计方案审批工作作为建设单位办理规划、报建等手续的前置审批。新建、改建、扩建项目绿线不明确，绿化方案不明确，绿化比例不足的一律不予审批。未经园林行政主管部门审核园林绿化项目一律不准开工。加大管理检查力度，强化对侵占绿地、绿线的违规违章行为的查处力度。
　　（五）加大绿化执法力度。对违反城市绿化法律、法规、规定的部门、单位和个人要严肃处理，破坏城市绿化的要追究其责任。对各种违法违规侵占“绿线”、挤占绿地、损坏绿化成果的行为，尤其是要对城区道路两侧门前绿化带、行道树破坏行为，执法部门要进行有效的遏制；同时禁止道路卫生清扫时将垃圾、土渣倒入绿化带中；宣传、广电部门在进一步加大对破坏城市绿化行为进行曝光。
　　（六）加强宣传工作。要通过报纸电视网络等媒体，普及宣传园林绿化知识，提高市民的生活品味。组织好义务植树节活动、绿地认养活动等活动，倡导全社会建绿护绿。在延寿公园、凤凰山沿渠景观带建立市级机关公务员树木认养基地，发动广大公务员积极参与绿化美化环境活动。宣传园林绿化建设成果，积极营造全社会参与、全社会关心绿化建设的良好氛围，培养广大市民的爱绿护绿意识。
　　（七）加强监督检查。城乡绿化实事进展情况建立每旬通报、管理，逐月考核制度，各县（区、管委会）和有关部门每月11日、21日将旬报、每月2日将月报报送市住房和城乡建设局 园林处（城市绿化）、村建科（乡镇绿化）、市委农办（村庄绿化）。财政、监察、审计部门对绿化建设资金的投入使用管理，要严格把关，把有限的资金用在刀刃上，确保资金使用效率和使用安全。城乡绿化实事实行任期目标责任制，按照“属地管理原则”，纳入各县（区、管委会）、乡镇（街）政府任期目标重要考核内容。市监察局、效能办要组织开展专项监察（督查），对工作开展好、成绩突出的单位和部门进行表彰奖励；对工作不力、效果较差的单位和部门进行通报批评并问责，推动工作落实。
