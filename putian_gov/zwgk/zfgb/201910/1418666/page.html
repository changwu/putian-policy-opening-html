莆田市人民政府关于城乡供水一体化建设的实施意见

莆政综〔2019〕64号
来源:市府办 时间：2019-10-22 15:01
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　饮水安全是城乡广大群众最关心最直接最现实利益所在，是决胜全面建成小康社会实施乡村振兴的基础支撑，是落实高质量发展实现跨越赶超的题中应有之义。为进一步提高我市城乡基本公共服务均等化水平，探索推进城乡供水一体化路子，切实保障城乡广大群众饮水安全，按照省委省政府、省水利厅及莆田市委的工作要求，制定莆田城乡供水一体化建设实施意见。

　　一、指导思想

　　全面贯彻党的十九大精神和实施乡村振兴战略的决策部署，以习近平新时代中国特色社会主义思想为指导，认真落实绿水青山就是金山银山的发展理念，严格遵循“节水优先、空间均衡、两手发力、系统治理”新时期水利工作总方针，以机制改革创新为总抓手，以管理方式创新为主线，以补齐基础设施短板为基础，优化配置供水资源资产资本，促进城乡供水融合发展，切实解决城乡供水发展不平衡不充分问题，实现广大乡村群众与城市居民同等享受优质安全洁净的饮用水，并总结一套在全省可资借鉴的城乡供水一体化经验做法。

　　二、基本原则

　　（一）坚持政府主导、市场化运作。莆田市城乡供水一体化项目为重大民生水利工程，要充分发挥政府的主导作用，整合供水资源，统筹规划建设；采取集团化供水企业市场化运作，实施一次投入、一步到位、一体运营，实现城乡供水建设管理现代化、产业化、精细化。

　　（二）坚持全域推进、城乡一体。以城带乡、以大带小、以盈补亏，全市一盘棋整合全域水源、引调水、制水、配水等供水资源，以集中连片、规模化供水为主，以相对分散、简易自来水设施供水为辅，以专业化、智能化为支撑，建立城乡一体的供水保障体系。

　　（三）坚持民生至上、效率优先。要把提质、降价、保供给，服务保障城乡民生改善，摆在城乡供水建设管理运营最重要位置，全力做好节水、增效、降成本工作，提高城乡供水建设管理运营整体效益和效率。

　　（四）坚持生态产业化、产业生态化。把生态环境保护摆在更加突出位置，统筹蓄水、保水、净水，协调水生态、水环境、水安全，在促进生态改善提高生态效益锻造城乡供水全产业链。

　　（五）坚持问题导向、均衡发展。以城乡基本公共服务均等化为导向，扩大规模化大水厂管网覆盖范围，着力加强农村供水薄弱环节建设，实行一体经营管理，实现城乡供水同水质、同服务，促进全市城乡供水均衡发展。

　　三、工作目标

　　（一）指标要求

　　2022年底前，达到以下主要供水指标：

　　1.集中供水率：全市规模化水厂集中供水率达到95%以上。

　　2.供水水质：符合国家《生活饮用水卫生标准》（GB5749-2006）的106项指标。

　　3.供水保证率：日供水万吨以上的规模水厂供水保证率达到97%以上，简易自来水设施达到95%以上。

　　4.管网漏失率：全市平均力争降到12%以下。

　　（二）实现路径

　　1.全域供水一体化。在全市范围内打破行政区划限制，统一规划、统一标准、统一建设、统一管护，形成全市城乡供水统筹协调稳步推进新格局。

　　2.供水产业一体化。建立从原水、引调水、制水到配水的完整供水产业链，形成以大水源、大水厂、大管网、广覆盖为主，以分散简易自来水设施为辅的城乡供水工程体系。

　　3.建设管理一体化。以企业为主体，形成统一建设管理、统一运营维护、统一融资保障，逐步实现城乡供水“同质、同价、同服务”。

　　4.运营维护智能化。供水企业要同步建设供水运营维护自动化、信息化系统，积极推广少人值班、无人值守、在线监测、自动抄表技术，提高供水运维现代化水平。

　　四、重点任务

　　（一）制定年度实施计划并组织实施。按照“厂网布局合理、资源高效利用、优先集中供水”的原则，重点建设供水工程、规模化水厂，新建、改建、扩建配水管网，实施“一户一表”改造，加大二次供水设施改造，加快供水信息化、智能化工程建设等。根据市政府批复的规划，抓紧开展前期工作，先急后缓，制定2019-2022年实施计划，总投资25亿元，2019年投资不少于3亿元。

　　责任单位：市水务集团、水利局，各县（区）政府（管委会）

　　（二）推进民营供水企业整合工作。根据《莆田市自来水企业整合工作方案》，目前市水务集团供水区内尚有3家民营（秀屿区笏石通达水厂、北岸通达忠门水厂、东峤思源水厂）及1家合资水厂（涵江区江口镇华正水厂）未整合，仙游县4家民营水厂需要整合。各有关县（区）政府、市水务集团要抓紧推进民营自来水厂整合工作，在2019年底前完成，同时开展民营供水企业资产评估。

　　责任单位：仙游县、涵江区、秀屿区政府，北岸经济开发区管委会，市国资委、水务集团

　　（三）健全完善建设管理机制。按照“先建机制，后建工程”的要求，成立市、县合作公司，由市政府授予特许经营权，作为城乡供水一体化工程建设的唯一实施主体，负责工程建设管理和运行维护。实行统一规划、统一建设、统一管理，建立成本水价调价机制和公益性供水工程运行经费财政补贴方案等。项目建设管理按照“项目管理法人制、招投标制、监理制、合同制”的要求；运行管理要全面落实农村饮水安全管理“三个责任”，即全面落实农村饮水安全管理地方人民政府的主体责任、水行政主管等部门的行业监管责任、供水单位的运行管理责任。

　　责任单位：各县（区）政府（管委会）,市发改委、财政局、水利局、住建局、水务集团

　　（四）加强农村水源地保护。按照生态环境部《关于推进乡镇及以下集中式饮用水水源地生态环境保护工作的指导意见》（环水体函〔2019〕92号）要求，开展农村水源地环境状况调查评估，建立水源地名录和信息台账，加快推进农村饮用水水源保护区划定、保护区边界标志设立、保护区内环境问题整治，统筹做好农村供水工程水源地选址、风险源排查和水质监测。

　　责任单位：各县（区）政府（管委会），市环境保护局、自然资源局、水利局、农业农村局、林业局

　　（五）推进城乡供水信息化建设。按照“补短板，强监管”的要求，积极推进城乡供水信息化建设。通过信息化建设及时、准确提供宏观的城乡供水大数据，为政府履行饮水安全保障责任、提升行业监管能力、服务民生提供决策支撑。同时，使供水企业能够实时感知供水系统的运行状态，精准掌控供水系统的生产、管理和服务流程，提高供水企业的管理效率，降低管理成本，提高服务水平。

　　责任单位：市水务集团、数字办

　　五、保障措施

　　（一）加强组织领导。市政府成立市城乡供水一体化试点工作领导小组，各县区、有关部门要成立相应的工作小组。各县（区）政府（管委会）要落实农村饮水安全保障地方行政首长负责制，在组织协调、政策制定、资金统筹、债务评估、成本核算、项目推进等方面发挥主导作用。市、县（区）各有关部门要在当地政府统一领导下，各司其职、各负其责、通力协作、密切配合，并形成工作合力。

　　责任单位：各县（区）政府（管委会）、市发改委、财政局、水利局、自然资源局、交通运输局、住建局、生态环境局、林业局、水务集团、国网莆田供电公司

　　（二）项目属地审批监管。为加快推进项目建设，有效实施监管，项目按照属地审批原则，由县(区、管委会)发改、水利部门并联审批，工程预结算评审工作由县(区、管委会)财政部门负责，项目质量监督由县(区、管委会)水利部门负责，市发改委、财政局和水利局要指导督促项目推进。要简化项目审批手续，按照《莆田市人民政府关于进一步简化投资项目审批手续的通知》(莆政综〔2016〕17号)精神，对不涉及新增建设用地的项目，实行备案制，由市城乡供水有限公司委托设计单位直接编制施工图和工程预算送审后报市、县（区）发改、水利部门备案，备案采用纸质材料报送，备案作为控制投资、项目财审及招投标依据；对不涉及饮用水源保护区、自然保护区等环境敏感目标的项目（不包括新建水厂项目），免于办理环评手续，取消水土保持、地质灾害及雷击风险报告等审批项目。

　　责任单位:各县（区）政府（管委会）、市发改委、财政局、水利局、自然资源局、生态环境局、林业局、水务集团

　　（三）创新投融资机制。充分发挥财政资金的引导和杠杆作用，撬动金融更多投向城乡供水。市发改委、财政局、水利局、住建局等相关部门要积极争取中央、省级预算内资金补助，争取省财政厅、水利厅、住建厅对莆田市规模化水厂、供水管网及简易自来水设施项目建设给予补助及贷款贴息，争取省水利厅承诺支持木兰溪建设省级的一般债券资金。市水务集团要积极对接国家政策性银行，争取支持供水企业融资贷款。市、县（区）财政要加大城乡供水投入，建立合理的水价形成机制，按照《莆田市城乡供水企业成本规制办法》中水价补贴的核定办法将水价补贴列入各级财政预算。按照城乡居民连续5年每人80元标准补助，补贴资金按年支付给莆田市城乡供水有限公司，列入本级财政预算，其中市财政承担30%，县（区、管委会）财政承担70%，保障供水持续健康发展。《莆田市城乡供水企业成本规制办法》由市发改委、财政局、住建局、水利局、国资委、水务集团等部门联合调研制定。

　　责任单位：各县（区）政府（管委会），市发改委、财政局、住建局、水利局、国资委、水务集团

　　（四）项目建设保障措施。项目征迁赔偿工作由各县（区）政府（管委会）负责，为加快推进城乡供水一体化工程建设，各县（区）政府（管委会）应成立专项征迁机构，妥善处理好与当地群众的社会矛盾，避免因纠纷导致项目受阻，同时将工作纳入市级考核。工程陆域征迁标准按照《莆田市人民政府关于印发征地补偿安置标准的通知》（莆政综〔2013〕10号文）及《莆田市人民政府关于实施征地区片综合地价的通知》（莆政综〔2017〕37号）执行，临时用地使用年限按补偿两年过渡一年（合计三年）计算，征迁工作经费参照莆田市财政局、莆田市国土资源局《关于规范征地拆迁服务费包干有关事项的通知》(莆市财综〔2017〕129号)有关规定执行。供水企业做好项目资金投入、建设实施及项目管理。各县（区）政府（管委会）和供水企业要加强协调配合、通力合作、攻坚克难，确保城乡一体化建设项目顺利推进。“一户一表”改造项目：以镇（或村）为单位，由市水务集团通过统一招投标（甲供方式）采购水表、管材等，项目建设上由供水企业统一实施，资金筹措由供水企业及用水户各承担50%，五保户、低保户或贫困户免收费。“一户一表”改造所需费用，由乡镇政府、供水企业联合在镇村公示后执行。有关乡镇、村委会（社区居委会）负责宣传推进、统计代收全村群众出资，各县（区）政府(管委会)负责协调落实到位。

　　责任单位：各县（区）政府（管委会）、市财政局、水利局、自然资源局、住建局、林业局、水务集团

　　（五）落实国家有关优惠政策。按照财政部、税务总局《关于继续实行农村饮水安全工程税收优惠政策的公告》（公告2019年第67号），落实饮水工程建设、运营的有关税收优惠政策。根据《福建省物价局关于贯彻落实国家发展改革委适当调整电价有关问题的通知》（闽价商〔2011〕233号），落实“为支持农村饮水安全工程建设和运行，对经有权部门认定的农村饮水安全工程供水用电按居民生活用电价格执行。”

　　责任单位：市财政局、市税务局、国网莆田供电公司、市水务集团

　　（六）政府有关部门支持优惠政策。莆田市城乡供水一体化项目为重大水利项目，项目建设涉及的林耕地征用、建设用地等有关优惠政策。项目建设永久性用地涉及林地耕地，按照重大水利项目建设有关政策办理。项目涉及的生态红线，可以占用的由相关部门出具同意使用说明，无法调整的必须避让。为了加快及缩短项目设计周期，减少投资成本及亏损，市自然资源局免费提供比例1：1000及以下地形图；市交通运输局等相关部门免费提供原有道路沿线地勘及市区镇村主要道路管线规划资料等。挖掘道路赔偿费及道路占用费给予免交，由供水企业按原状恢复。

　　责任单位：市自然资源局、生态环境局、交通运输局、林业局、公路局、水务集团

 

　　莆田市人民政府               

　　2019年10月10日
