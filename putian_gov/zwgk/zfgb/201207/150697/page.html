莆田市人民政府办公室关于莆田市乡镇综合文化站建设督查情况的通报

莆政办〔2011〕237号
来源:市府办 时间：2012-03-28 15:18
| | | |

各县（区）人民政府（管委会）：
　　为全面推进我市乡镇综合文化站建设，根据市政府统一部署，由市府办、宣传部、文化广电新闻局、发展改革委、财政局等部门组成督查组，于12月2日、5日分别到仙游县枫亭镇、盖尾镇、榜头镇、度尾镇、大济镇，城厢区东海镇、灵川镇、华亭镇，荔城区西天尾镇、黄石镇、新度镇，涵江区梧塘镇、白塘镇、江口镇、国欢镇，秀屿区月塘乡、东庄镇、东峤镇、埭头镇，北岸开发区的山亭镇等6个县区20个乡镇综合文化站进行现场督查，重点检查乡镇综合文化站的设施建设、人员配置和功能设置以及在当地农村文化发展中所发挥作用等情况。现将督查情况通报如下：
　　一、当前我市乡镇综合文化站建设基本情况
　　从2007年起，省委、省政府决定用5年时间在全省范围实施乡镇综合文化站改造完善工程建设，新建一批乡镇综合文化站，改扩建不达标的文化站。2007—2011年五年时间里，通过申报，我市共有41个乡镇综合文化站立项建设，其中2007年有10个，2008年有7个，2009年有13个，2010年有3个，2011年有8个。目前我市乡镇综合文化站建设已取得明显的成效。全市已完成建设的有34个，正在建设的有6个（2009年项目1个， 2011年项目5个），未动工的有1个（2011年项目）。另外我市还有5个镇综合文化站没有申报建设。
　　（一）设施建设方面。从督查情况看，大部分乡镇通过新建、改扩建综合文化站已达到镇500平方米、乡300平方米的省定标准，其中西天尾镇新建综合文化站达1456平方米。这些乡镇综合文化站建设比较规范，位于人口聚居地方，方便群众使用。此外，还有榜头镇、大济镇、黄石镇、梧塘镇、江口镇、国欢镇等6个乡镇综合文化站没有达到省定标准。
　　（二）功能设置情况。按照省要求的设立书报刊阅览室、多功能活动厅、综合展示室、文化信息资源共享网点、教育培训室、老年青少年活动室和体育健身室等八个功能室设置，此次督查的乡镇中仅西天尾镇、山亭镇、盖尾镇等乡镇综合文化站基本完成功能设置，建立了工作制度，运转正常，管理较为规范。其余的乡镇有的仅设置3-4个功能室，个别功能设置单一，仅有老年活动室。灵川镇、华亭镇、黄石镇、白塘镇、月塘乡、东庄镇等6个乡镇至今仍未完成功能配置。
　　（三）人员配置情况。大部分乡镇综合文化站人员编制有1-2人，度尾镇、华亭镇、月塘乡、江口镇、梧塘镇等5个乡镇综合文化站没有人员编制。
　　（四）活动开展情况。已建成并投入使用的乡镇综合文化站大多能利用各自优势，履行工作职能，发挥基层文化阵地的作用，在元旦、春节、五一、国庆等节日期间，结合当地实际，配合乡镇党委政府的中心工作，举办了文艺演出、游艺活动、乒乓球、象棋比赛等，开展综治、计生等专题宣传活动，举办科技推广、宣传教育和各类知识培训等，丰富了当地人民群众的精神文化生活。荔城区西天尾镇作为首批乡镇综合文化站建设项目，投入使用至今，已接待群众2万多人次，并先后成功举办了企业文化艺术节、老人体育健身比赛、南少林书画展、红歌会等。
　　二、存在的问题
　　（一）对乡镇综合文化站建设投入部分不足。由于思想缺位和经费不足，乡镇文化设施的建设缓慢，内部设施薄弱，群众文化活动开展受到限制。
　　（二）新建综合文化站作用没有得到充分的发挥。有的乡镇综合文化站建成后仍未投入使用，有的乡镇投入使用后又被挤占、更改用途或闲置，有的乡镇综合文化站内部设施薄弱，图书和活动器材等严重缺乏，有的没有专人管理，对外开放时间随意性比较大。
　　（三）部分乡镇建设进度缓慢或没有达到省标准要求。荔城区新度镇综合文化站是2011年的项目，至今没有动工，影响全市进度；秀屿区东峤镇综合文化站是2009年的项目，项目进度缓慢，至今没有完成基建；还有的综合文化站没有达到基本面积要求或选址不当，设在办公大楼、市场内等，限制群众文化活动的开展。同时，新建的文化站普遍没有办理产权证明。
　　（四）乡镇文化站人员编制不足。全市乡镇综合文化站人员“在编不在岗、专职不专用”与“一人多岗、人员挪用”现象较普遍，专业文化人才严重匮乏。
　　（五）考核体系不完备。对乡镇综合文化站的建设、管理、运营、工作人员的管理不善，基本处于缺失状态，文化站的功能得不到应有发挥。
　　三、整改要求
　　乡镇综合文化站建设是我市贯彻落实党的十七大和十七届六中全会精神以及加强我市公共文化服务体系建设的重大举措，是实现文化强市宏伟目标的基础性工程，也是关系广大农村群众的民心工程，在我市农村文化建设中发挥主阵地重要作用。
　　（一）加快工程建设进度。县(区)、乡镇两级政府要把完成乡镇综合文化站全覆盖作为当前文化建设的一项重要任务，加强领导，切实把这项工作抓紧抓好。要根据省委宣传部、省文化厅督查组和市督查组的反馈的意见、建议，及时进行整改，研究解决问题，提出下一步工作计划。特别是没有完成建设的要促进加快建设进度，至今尚未动工的项目要重点督查，在年底前开始动工。已建成的乡镇综合文化站要尽快投入使用，对外开放。
     我市至今没有申报建设的秀屿区平海镇、笏石镇，湄洲湾北岸东埔镇、忠门镇，涵江区三江口镇等5个镇要在2012年开始动工建设，以实现全市所有乡镇都建有综合文化站的目标。
　　（二）加快设施功能完善。还没有全部完成内部功能配置的文化站，要按照省“八个有”统一标准，合理布局，安排添置设备，配好配齐内部功能，在春节前开放运行，充分发挥新建文化站的作用。
　　（三）规范综合文化站的管理。按照文化部颁布的《乡镇综合文化站管理办法》规定，加强站舍管理，坚持乡镇综合文化站及其设施、设备公益性质，对存在的租赁、挤占和挪作它用等形式改变其用途，要立即纠正。各县（区、管委会）要按照省委宣传部等七部委《贯彻落实<关于加强地方县级和城乡基层宣传文化队伍建设的若干意见>的实施意见》（闽委宣联[2010]33号）,进一步理顺乡镇综合文化站的管理体制，确定统一的名称，根据乡镇人口数量，落实乡镇综合文化站人员编制，定员定性。同时，文化站经费要纳入财政预算，专款专用，以稳定农村文化队伍，以利于农村文化事业的建设和发展。
　　（四）发挥乡镇综合文化站示范点作用。市文化广电新闻出版局要进一步对在乡镇综合文化站建设中设施齐全、功能配备较为完善，在农村文化建设中发挥积极作用的西天尾镇、山亭镇、盖尾镇、东海镇等4个乡镇综合文化站加大宣传力度，起到以点带面、全面推进的示范作用。
　　（五）加大县区政府对乡镇综合文化站建设的督查力度。各县（区）人民政府（管委会）要加强对乡镇综合文化站建设督查和指导。特别是对没有动工的2011年项目新度镇综合文化站、没有完成基建的2009年项目东峤镇综合文化站以及投入使用后又被挤占、闲置的2007年项目月塘乡综合文化站，荔城区、秀屿区人民政府要加强督促检查，限期整改。
　　同时，对未列入本次市政府督查对象的其他乡镇综合文化站应在自查的基础上，强化督查，对尚未建成、尚未开放、功能不到位、闲置挤占、发挥作用较弱的应限期整改。各县（区、管委会）将综合文化站建设的整改情况于2012年1月15日前报市政府办公室，同时抄报市发展改革委、市财政局、市文化广电新闻出版局。

莆田市人民政府办公室           
二○一一年十二月二十八日
