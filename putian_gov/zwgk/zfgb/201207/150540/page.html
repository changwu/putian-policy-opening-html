莆田市人民政府办公室关于加强乡镇敬老院建设管理的意见

莆政办〔2011〕191号
来源:市府办 时间：2011-10-28 16:43
| | | |

各县（区）人民政府（管委会），市直有关单位：
　　为进一步加强乡镇敬老院的建设和管理，不断保障和改善民生，构建和谐莆田，推动莆田科学发展，根据福建省人民政府办公厅《关于加强市县社会福利中心、乡镇敬老院和居家养老服务中心（站）建设管理的意见》（闽政办[2011]16号）精神，结合我市实际情况，经市政府同意，现就加强敬老院建设和管理提出如下意见：
　　一、以人为本，高度重视敬老院建设管理
　　乡镇敬老院主要为农村五保对象提供集中供养服务，实现生活照料、康复护理等功能。近年来，在市委、市政府的高度重视下，各级各有关部门积极行动，加大资金支持力度，我市敬老院建设取得长足发展。2007年以来全市共新（改、扩）建敬老院31所，新增床位1246床，极大改善了五保供养条件。但是，我市目前敬老院发展现状与经济社会发展要求和群众的实际需求还有一定的差距，如还存在敬老院配套设施不够完善、功能不够健全、集中供养率不高等问题。各级党委政府和各有关部门要进一步增强紧迫感和责任感，充分认识到乡镇敬老院建设是社会主义新农村建设的重要组成部分，也是贯彻国务院《农村五保供养工作条例》和实施省、市“十二五”规划的必然要求，对于保障农村五保对象合法权益，提高农村社会福利服务水平具有重要意义。要继续加大政策支持和资金扶持力度，广泛动员社会力量，加强乡镇敬老院建设与管理，完善敬老院功能，推进我市福利事业发展。
　　二、科学设计，合理规划敬老院建设
　　各地在规划建设敬老院时要注重区分五保对象、养老对象和救助对象不同的居住和生活需要，按照高起点规划、高质量建设、高水平管理，科学建设敬老院。
　　（一）明确目标任务。敬老院以五保供养为主，社会养老、社会救助为辅，是基层民政保障民生、服务民生的一个综合载体，是省委、省政府为民办实事项目和市委、市政府“民生战役工程”项目。到2015年，原则上每个乡镇建成一所以人为本、规划合理、规模合适、管理有序的敬老院，各地要根据“十二五”规划要求，站在高起点上，谋划敬老院建设目标任务。
　　（二）科学规划设计。乡镇敬老院建设项目要按照《老年人建筑设计规范》和《老年人社会福利机构基本规范》以及国家建设工程方面的规定组织设计实施。每所乡镇敬老院建设要求占地面积5亩左右，建筑面积在700平方米以上，床位在40张以上，双人间建筑面积不低于17平方米，单人间不低于12平方米，且均需设置室内卫生间，做到布局合理、环境优美、功能完备、设施齐全、交通便利，集医疗、康复、养老、娱乐等功能和服务于一体。
　　各地要充分考虑社会福利服务事业发展需要，把乡镇敬老院建设纳入城乡建设总体规划，预留建设用地。规划选址要满足供养对象的特殊要求和方便老年人活动的要求，做到环境良好、防灾避灾。
　　（三）保障建设经费。敬老院建设项目的实施，必须坚持政府主导、部门协调、社会参与的原则。建设资金采取省里补助一点、市里安排一点，县乡配套一点、政策减免一点、社会捐助一点的“五个一点”办法与资产置换盘活存量等措施相结合筹集落实。省财政对乡镇敬老院分两档给予补助：属于财政转移支付的县（区、管委会）每所补助90万元；不属于财政转移支付的县（区、管委会）每所补助80万元，补助资金一次性下拨到项目所在的县（区、管委会），由县级民政、财政部门根据项目管理的相关规定和工程建设进度分期拨付到位。市级在省级补助的基础上，对区（管委会）新建的敬老院每所从福利彩票公益金中配套补助10万元；对县新建的敬老院每所从福利彩票公益金中配套补助5万元，县本级配套5万元。
    三、健全机制，不断完善敬老院管理
　　（一）落实机构人员和管理经费。一是乡镇敬老院纳入所在乡（镇）全额拨款的事业单位机构编制，给予办理事业单位法人登记。二是每个乡镇敬老院核定1至2名事业编制的管理人员，其中乡镇辖区内五保对象人数在100以下的编制管理人员1名，100人以上的编制管理人员2名；护理人员按与院民不低于1:10比例配备，护理岗位不核定事业编制，聘用的护理人员工资待遇通过政府出资购买服务办法予以解决，但要按照不低于我市最低工资标准的1.5倍来确定，并享受养老、医疗等待遇，所需经费列入县级财政预算。三是乡镇敬老院由所在乡（镇）政府管理，接受县级民政部门的业务指导。县级政府要把乡镇敬老院工作运转和管理经费、农村五保对象的供养资金以及政府购买服务经费列入同级财政预算，同时根据社会福利和社会养老服务事业发展需要和本级财力增长情况，逐步增加经费投入，进一步提高供养对象的集中供养率和供养水平。
　　（二）规范服务管理。各地要将健全和落实乡镇敬老院的各项管理制度作为加强规范管理的前提和基础。要健全和落实院长负责制，真正赋予院长在乡镇敬老院中的领导权力和主体责任。要健全和落实岗位责任制，做到定岗定人定责，逐步建立起标准化服务体系。
　　（三）创新体制机制。在确保公益性质不改变、国有资产不流失、满足供养对象需求和确保供养水平不降低的前提下，乡镇敬老院要积极探索运行管理新机制、新办法，重点在转换机制、增强活力、改善服务等方面深化内部运行机制改革。鼓励有条件的地方采用公办民营、委托经营等方式进行管理，面向社会提供护理型养老等服务，解决失能半失能老人护理问题。无论采取何种运行管理模式和机制，都要确保乡镇敬老院及时投入使用，提高供养对象的入住率和供养水平，充分发挥公益作用和社会效益。
　　四、强化保障，扎实推进敬老院建设管理
　　（一）加强组织领导。各级政府要把乡镇敬老院建设和管理摆上重要议事日程，纳入经济社会发展“十二五”规划，坚持民生优先原则，各地由民政局、发展改革委牵头，财政、国土资源、环保、建设、规划、人防、消防等部门参与的工作机制。要明确工作责任，妥善解决征地、拆迁等问题；要开辟行政审批绿色通道，提高审批效率；要加强督促检查，对建设质量差和未按时完成建设任务的，或建成后未及时投入使用的，或管理上存在突出问题的，要实行问责。
　　（二）明确工作责任。民政部门要充分发挥在乡镇敬老院建设管理中的职能作用，加强与有关部门的沟通协调，负责牵头协调成立乡镇敬老院项目建设领导小组，建立目标管理责任制和激励约束机制，并加强项目建成后的运行管理和监督检查工作；发展改革部门负责建设项目审批，编报基本建设计划，并根据计划安排基础设施建设投资；财政部门要充分发挥公共财政的保障职能，安排落实相关经费；规划建设部门负责规划和建设等方面的指导工作；国土资源部门要优先提供和保障建设用地，并协助建设单位科学选址，避开地质灾害点；林业部门在建设项目涉及用林地时及时予以审核审批，并尽可能无偿或优惠提供绿化苗木；监察、审计部门加强项目、资金等方面的监督检查工作；机构编制、人力资源和社会保障、环保、税务、人防、消防等有关部门在各自职责范围内对乡镇敬老院建设和管理工作提供必要支持。
　　（三）落实优惠政策。各地要认真落实中央、省有关扶持社会福利事业发展的各项优惠政策。乡镇敬老院建设用地，经相关程序批准后，采用划拨方式优先供地；乡镇敬老院提供的福利性服务，以及单位和个人捐赠支持社会福利事业的款物，按照相关规定给予相应税收优惠或减免；对乡镇敬老院项目编制、土地规划、设施建设工程等收费，给予政策性倾斜和减免优惠；乡镇敬老院的用电、用水、用气等公用事业收费，按当地最优惠价格执行。经当地民政部门报请同级政府批准，乡镇敬老院可以接受社会组织和个人的捐赠，所募集的捐赠款物，必须全部用于项目建设、改善设施设备和供养人员的生活，并接受捐赠人和有关部门的监督检查。
　　（四）发动社会参与。鼓励、支持、引导社会力量以多种形式参与发展敬老院事业，满足日益增长的养老服务需求。各级政府要在制定政策、统筹规划、监督管理等方面发挥主导作用，进一步完善和落实土地供应、税费优惠、财政补助、医疗服务等方面的扶持政策，加快推进敬老院建设。具体鼓励措施可由各地根据本地区实际情况制定。

　　莆田市人民政府办公室       
　　　二〇一一年十月十七日
