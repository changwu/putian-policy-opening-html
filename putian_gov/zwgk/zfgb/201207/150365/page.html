莆田市人民政府办公室关于进一步完善中小学布局的实施意见

莆政办〔2011〕2号
来源:市府办 时间：2011-03-15 10:28
| | | |

各县（区）人民政府（管委会），市直有关单位：
　　为贯彻落实《福建省人民政府批转省教育厅关于进一步完善中小学布局的实施意见》（闽政[2010]28号，以下简称《实施意见》）精神，根据市政府专题会议纪要〔2010〕182号精神，现就进一步完善中小学布局工作提出如下实施意见：
　　一、认真学习领会《实施意见》精神，明确完善中小学布局的工作目标
　　合理规划中小学布局是优化配置教育资源、提高教育质量、促进教育公平的重要前提和基础。认真学习领会省政府文件精神，结合实际抓好贯彻落实，是当前和今后一段时间我市教育重点工作之一。各县（区）人民政府（管委会）、市直有关单位要把贯彻《实施意见》与学习贯彻第四次全国教育工作会议精神、规划我市教育发展结合起来，把各项工作任务落实好。要全面落实教育优先发展战略，按照《实施意见》提出的“方便入学、合理布局，统筹师资、县域调配，着眼质量、注重效益，规范程序、科学论证”的基本原则，结合本县（区、管委会）实际，有效完善中小学布局，促进中小学教育均衡发展，更好地满足人民群众的教育需求。要进一步明确完善中小学布局的工作目标，至2012年，中小学布局调整取得重大进展，工程建设有序推进，农村师资调整基本到位，基本保证进城务工人员子女以公办学校为主就近入学，有效缓解城市“大班额”问题，农村留守孩子关爱体系进一步完善。在此基础上，再用3年左右时间，形成比较合理的中小学布局，并建立动态管理机制，不断适应工业化、城镇化及人口流动的发展需要。
　　二、抓紧落实各项工作任务，确保完善中小学布局工作取得成效
　　（一）加快中小学校舍安全工程推进力度。各县（区）人民政府（管委会）要根据中小学布局调整要求，进一步完善校安工程建设方案，实现提高防灾能力与合理布局相结合，提高校安工程的实效。2009-2011年规划完成我市中小学无设防校舍重建面积117.7万平方米，新建校舍674幢（详见附件）。2012-2013年完成所有校舍加固工作。
　　（二）推进中小学寄宿制学校建设工程。要确保完成2008-2010年寄宿制学校建设任务，全市新建或改造学生宿舍、食堂等生活设施8.95万平方米（详见附件）。从2011年起省级寄宿制改造资金补助纳入校安工程建设统筹考虑。有条件的县（区、管委会）要进一步加快寄宿制学校建设步伐，重点加强人口转移密集区域、城乡结合部寄宿制学校和乡镇中心校寄宿生宿舍建设，扩大床位规模，进一步改善寄宿生学习、生活条件。到2012年基本消除校外租房现象。
　　进一步完善“免费营养早餐工程”的组织实施，逐步提高家庭困难寄宿生生活补助标准，确保学生健康成长。要加强寄宿制学校管理，要按照省委编办、省教育厅、省财政厅、省公务员局《关于加强普通中小学校生管教师队伍建设》（闽教人[2010]57号）规定的标准，2011年秋季开学前寄宿制学校足额配备生管人员，并指定专人负责学校食堂、宿舍卫生。开展卫生、保卫、消防等安全管理专项整治行动，切实保障学生身心健康。
　　（三）大力实施城区中小学扩容工程。各县（区）人民政府（管委会）要将城区中小学扩容摆上议事日程，科学测算进城务工人员随迁子女就学和消除“大班额”所需学位，合理布局，加大组织推动力度。要结合校安工程，推进城区和乡镇中心学校扩容建设。2011-2012年新增城区中学学位7769个，小学学位8661个，其中2011年省补助2377个学位（详见附件），推动莆田第一中学、莆田第二中学、市实验小学在新规划的城市综合体中筹建新校区，缓解新增城市居民、进城务工人员随迁子女就学和消除超大班额所需学位问题。
　　（四）积极合理配置师资。认真贯彻莆田市人民政府《关于进一步加强中小学教师队伍建设的实施意见》（莆政综[2009]99号）精神，全面落实县（区）域内公办学校教职工人事关系收归县管。要根据布局调整需要，打破校界，统筹安排县域内教师资源，实现师资队伍优化配置。全面摸清布局调整后出现的富余教师状况，并有针对性地组织富余教师经过转岗培训后，分流担任紧缺学科教师、幼儿园教师和生管人员。转岗人员的教师身份和待遇保持不变。各县（区）人民政府（管委会）于2011年1月底前，将富余教师有关情况上报市教育局。
　　（五）确保学生交通安全。各县（区）人民政府（管委会）要负责协调教育、交通、公安、运管等部门，研究解决寄宿制学校学生周末乘车难问题，结合实际，科学制定保证学生交通安全和满足实际需要的周末客车班次、运行路线等具体方案，于2011年2月底前上报市教育局。县（区）人民政府（管委会）及其有关职能部门出台相关优惠政策，鼓励和支持乡镇政府、村委会、社会人士等购买车辆，专门用于运送回家返校学生。有条件的学校配置校车，车况必须符合公安、交管等部门规定，并制定校车使用管理制度，指定专人管理。
　　（六）逐步实现班生额达标。全市中小学班生额原则上按照国家和省定标准执行，做到每班学生小学不超过45人，初中不超过50人。生源压力过大的地方，加大城区中小学扩容力度，确保到2012年基本解决新增进城务工人员随迁子女就学和消除56人以上的“大班额”，到2015年全市中小学班生额达到国家标准。
　　（七）妥善处置闲置校舍。闲置校舍优先保证教育使用，改建为幼儿园、成人学校、老年学校等，力争教育资源不流失。对农村地区不能拍卖、置换，产权属于乡镇政府、村委会的校产，可移交改建为村部、农家书屋、医疗室、文化活动场所等。对闲置校产进行公开拍卖或置换，所得资金（校产）应专项用于学校建设及其他教育事业发展。
　　（八）完善农村远程教育工程应用服务体系。2012年前，建立完善的农村远程教育工程应用服务体系，实现远程教育工程“面向学生、走进课堂、用于教学”，促进教育资源城乡共享。积极配合建设省级教育骨干网，以莆田教育网资源中心为龙头，做好本地教育资源平台的建设和共享工作，构建农村教师网络研修平台，形成全市、县区、学校各级优质教育资源共享网络体系，基本辐射到农村中小学。要按照全省标准化学校建设的配备要求，加强学校信息化基础设施建设，使所有中小学基本达到标准化配置。
　　三、加强对完善中小学布局工作的领导，强化督促检查
　　完善中小学布局事关群众利益，任务重、要求高。各级各有关部门要站在全局高度，统一思想，提高认识，进一步强化统筹协调，加大组织推动力度，切实把完善中小学布局各项工作抓紧抓好。一是要加强组织领导，主要领导亲自抓，分管领导具体负责，及时研究工作中出现的问题和困难。二是要明确工作责任。县（区）人民政府（管委会）是完善中小学布局的责任主体，要认真落实中小学校舍安全工程规划和寄宿制学校建设。要根据学生数量、寄宿条件、保障水平等情况，对布局调整进行科学论证，修订完善布局规划，制定公示调整方案，统筹协调扎实推进，确保各项工程建设按时保质保量完成。三是要增强资金保障。中小学校舍安全工程资金除省级以上补助资金外，其他由各县（区）人民政府（管委会）负责筹措，市政府采取“以奖代补”方式对县（区、管委会）给予奖励。寄宿制学校建设工程，2008-2010年所需资金按原定方案执行，2011年后所需资金纳入校安工程统筹安排。城区中小学扩容工程所需经费除省市专项补助资金外，各县（区）人民政府（管委会）应将本县区承担的资金列入年度财政预算，确保资金及时足额到位。要进一步明确义务教育阶段学校一律不得举债建设的要求。要积极将社会捐助、希望工程、定向援建等引导到完善中小学布局之中。加强工程资金管理，实行专户管理、专帐核算、集中支付、封闭运行，切实提高资金使用效益。四是要加强项目建设管理，按照校安工程“八个统一”要求，建立健全县级统筹机制。要开辟“绿色通道”，简化审批手续，积极推行项目联审联批，交叉受理、限时办结、提速提效。五是要加强督促检查。将完善中小学布局纳入民生工程考核内容，及时跟踪、定期通报。通过教育督导、行政监察、效能问责、专项审计等渠道，采取分片包干督查、专项督查、定期检查和不定期抽查相结合的方式，对工作开展情况进行全面监督检查，形成督查长效机制。
　

　莆田市人民政府办公室       
　　二〇一一年一月七日
