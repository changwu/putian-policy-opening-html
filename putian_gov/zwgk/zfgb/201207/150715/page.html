莆田市人民政府办公室关于2012年民生工程战役4月份进展情况的通报

莆政办〔2012〕80号
来源:市府办 时间：2012-09-24 11:33
| | | |

各县（区）人民政府（管委会），市直有关单位：
　　今年以来，各县（区）人民政府（管委会）、市直有关单位认真落实莆田市人民政府办公室《关于印发莆田市2012年民生工程战役实施方案的通知》（莆政办〔2012〕24号），积极推进民生工程战役。现将全市民生工程战役2012年1-4月份进展情况通报如下：
　　2012年市民生工程战役共安排医疗卫生、教育、文化体育、强农惠农、便民生活、社会保障、和谐平安和保障性安居工程等八个方面56项实事98个项目（其中：建设类项目70个，服务类项目28个；省级项目60个，市级项目38个），项目总投资120.3亿元，2012年年度计划投资39.31亿元，截止4月底，共完成投资13.2亿元，完成年度计划的33.6%（超过序时进度0.3个百分点）。目前98个项目已详细分解为1107个子项目，其中开工764个，开工率69%，竣工214个，竣工率19.3%。
　　一、从分类别完成情况看
　　市住房和城乡建设局牵头的保障性安居类项目、市教育局牵头的教育类项目、市经贸委牵头的便民生活类项目完成投资超序时进度；市民政局牵头的社会保障类项目、市综治办牵头的和谐平安类项目、市卫生局牵头的医疗卫生类项目、市文化广电新闻出版局牵头的文化体育类项目、市委农办牵头的强农惠农类项目完成投资未达序时进度。按完成序时进度从高到低排列，各类别的具体情况是：
　　（一）市住房和城乡建设局牵头的保障性安居类项目2012年年度计划投资2.95亿元，1-4月份累计完成投资2.05亿元，完成年度计划的69.5%，超过序时进度36.2个百分点；涉及的子项目数有12个，开工11个，开工率91.7%。目前未动工的项目是仙游玉井廉租住房项目，该项目完成征地，尚未投入建设，其余项目均已动工。
　　（二）市教育局牵头的教育类项目2012年年度计划投资6.16亿元，1-4月份累计完成投资2.74亿元，完成年度计划的44.5%，超过序时进度11.2个百分点；涉及的子项目数有371个，开工308个，开工率83%，其中竣工28个，竣工率8%。目前未动工的项目是：解决进城务工人员随迁子女就学项目、城厢区华林学校校区建设项目、秀屿区东庄职业中专建设项目、仙游县特殊教育学校建设项目、49个中小学校安工程项目（总任务数332个）和4所公办幼儿园建设项目（总任务数23所），其余项目均已开工建设，其中27个中小学校安项目和1所公办幼儿园已竣工。
　　（三）市经贸委牵头的便民生活类项目2012年年度计划投资16.24亿元，1-4月份累计完成投资5.67亿元，完成年度计划的34.9%，超过序时进度1.6个百分点；涉及的子项目数有143个，开工72个，开工率50.3%，其中竣工10个，竣工率7%。目前未动工的项目是：闽中污水处理厂三期工程、新增50辆出租车项目、40个便民商业网点建设项目（总任务数60个，其中25个农家店处于省下达任务阶段无法动工）、4个菜篮子基地项目、12座农村公路危桥改造（总任务数20座）、2个污水管网建设项目（总任务数7个），其余项目均已动工，其中秀屿区污水管网建设和9个便民商业网点项目已竣工。
　　（四）市民政局牵头的社会保障类项目2012年项目年度计划投资2.63亿元，1-4月份累计完成投资8057.6万元，完成年度计划的30.6%，滞后序时进度2.7个百分点；涉及的子项目数有77个，开工28个，开工率36.4%。目前未动工的项目是：农村敬老院项目（城厢区常太镇、仙游县社硎乡、北岸忠门镇）、2个县区的残疾人康复扶贫助学安居项目（秀屿区、湄洲岛）、2个管委会的“光明行动”项目（北岸、湄洲岛）、1个县的妇女创业小额贷款工程（仙游县）、社区居家养老服务中心建设工程、贫困大病患者救助工程、实施农村部分计划生育家庭奖励扶助项目、贫困大学生资助工程（除市红十字会开展此项工作外，其余部门及县区均尚未开展）、关爱农村留守流动儿童工程（市本级已开展，各县区、管委会均尚未开展），其余项目均已动工。
　　（五）市综治办牵头的和谐平安类项目2012年年度计划投资1490万元，1-4月份累计完成投资432万元，完成年度计划的29%，滞后序时进度4.3个百分点；涉及的子项目数有4个，开工3个，开工率75%。未动工的项目是：莆田公安公众服务网建设项目，该项目正处于制定方案阶段，其余项目均已动工。
　　（六）市卫生局牵头的医疗卫生类项目2012年年度计划投资2.14亿元，1-4月份累计完成投资5486万元，完成年度计划的25.7%，滞后序时进度7.6个百分点；涉及的子项目数有319个，开工200个，开工率63%，其中竣工173个，竣工率54.2%。目前未动工的项目是：市中医院、涵江平民医院综合病房大楼、秀屿区精神病防治院、秀屿区卫生监督所、105所村卫生室建设（总任务数292所）、疾病预防控制中心实验室能力建设项目、2个县区急救网络体系建设项目（仙游县、城厢区尚未投入资金），其余项目均已动工，其中173所村卫生室已竣工。
　　（七）市文化广电新闻出版局牵头的文化体育类项目2012年年度计划投资4.13亿元，1-4月份累计完成投资6440.12万元，完成年度计划的15.6%，滞后序时进度17.7个百分点；涉及的子项目数有39个，开工12个，开工率30.8%，其中竣工3个，竣工率7.7%。目前未动工的项目是：乡镇文化服务站设施完善工程（各县区、管委会均未下达配套资金），村（社区）农家书屋（图书室）建设工程（各县区、管委会完成选址，还未投入资金），农村广播电视村村通工程、农民体育建设工程、仙游影院、仙游县体育中心田径场、涵江区青少年科技活动中心、秀屿区文化馆、秀屿区少体校、秀屿区妇女儿童活动中心，其余项目均已动工，其中乡镇文化服务站设施完善工程和村（社区）农家书屋（图书室）市本级的建设工程资金已全部下达，农村有线广播村村响工程已竣工。
　　（八）市委农办牵头的强农惠农类项目2012年年度计划投资4.92亿元，1-4月份累计完成投资7178.3万元，完成年度计划的14.6%，滞后序时进度18.7个百分点；涉及的子项目数有142个，开工130个，开工率91.5%。目前未动工的项目是：6个农村饮水安全工程（总任务数16个）、东圳水库分层取水工程、湄洲岛世界妈祖文化中心供水保障工程、湄洲湾片区供水工程、木兰溪流域河道清淤护岸工程（城厢区已动工，仙游县、荔城区尚未动工）、畜禽养殖扶持发展工程，其余项目均已动工。
　　二、从分县区完成情况看
　　荔城区、涵江区、秀屿区项目完成投资超序时进度，市本级、仙游县、城厢区、北岸、湄洲岛项目完成投资未达序时进度。按完成序时进度从高到低排列，各县区的具体情况是：
　　（一）荔城区项目2012年年度计划投资2.9亿元，1-4月份累计完成投资1.93亿元，完成年度计划的66.3%，超过序时进度33个百分点，涉及的子项目数有177个，开工127个，开工率71.8%，竣工50个，竣工率28.2%。
　　（二）涵江区项目2012年年度计划投资3.38亿元，1-4月份累计完成投资1.4亿元，完成年度计划的41.6%，超过序时进度8.3个百分点，涉及的子项目数有200个，开工109个，开工率54.5%，竣工57个，竣工率28.5%。
　　（三）秀屿区项目2012年年度计划投资2.6亿元，1-4月份累计完成投资9657.7万元，完成年度计划的37.1%，超过序时进度3.8个百分点，涉及的子项目数有124个，开工87个，开工率70.2%，竣工7个，竣工率5.6%。
　　（四）城厢区项目2012年年度计划投资1.66亿元，1-4月份累计完成投资5261.65万元，完成年度计划的31.6%，滞后序时进度1.7个百分点，涉及的子项目数有140个，开工93个，开工率66.4%，竣工35个，竣工率25%。
　　（五）市本级项目2012年年度计划投资23.41亿元，1-4月份累计完成投资7.08亿元，完成年度计划的30.2%，滞后序时进度3.1个百分点，涉及的子项目数有179个，开工162个，开工率90.5%，竣工4个，竣工率2.2%。
　　（六）仙游县项目2012年年度计划投资4.17亿元，1-4月份累计完成投资1.14万元，完成年度计划的27.3%，滞后序时进度6个百分点，涉及的子项目数有232个，开工159个，开工率68.5%，竣工58个，竣工率25%。
　　（七）北岸项目2012年年度计划投资5927.44万元，1-4月份累计完成投资1620.27万元，完成年度计划的27.3%，滞后序时进度6个百分点，涉及的子项目数有40个，开工24个，开工率60%，竣工3个，竣工率7.5%。
　　（八）湄洲岛项目2012年年度计划投资6001.46万元，1-4月份累计完成投资152.58万元，完成年度计划的2.5%，滞后序时进度30.8个百分点，涉及的子项目数有15个，开工3个，开工率20%，竣工0个，竣工率0。
　　三、从分性质完成情况看
　　建设类项目70个，2012年年度计划投资33.15亿元，1-4月份累计完成投资11.77亿元，完成年度计划的35.5%，超过序时进度2.2个百分点；服务类项目28个，2012年年度计划投资6.17亿元，1-4月份累计完成投资1.45亿元，完成年度计划的23.6%，滞后序时进度9.7个百分点。
　　四、从分类型完成情况看
　　省级项目60个，2012年年度计划投资33.27亿元，1-4月份累计完成投资11.28亿元，完成年度计划的33.9%，超过序时进度0.6个百分点；市级项目38个，2012年年度计划投资6.05亿元，1-4月份累计完成投资1.94亿元，完成年度计划的32.1%，滞后序时进度1.2个百分点。
　　下阶段是抓项目促进度的黄金时期，是民生工程战役二季度能否完成“投资过半”任务的关键时期，各县（区、管委会）、市直各有关部门一定要以“等不起、慢不得”的紧迫感，不断创新战役工作方法，加大战役攻坚力度，确保上半年民生战役项目全面开工，超序时进度完成投资。


莆田市人民政府办公室
二O一二年五月七日
