莆田市人民政府关于2012年纠风工作的实施意见

莆政综〔2012〕64号
来源:市府办 时间：2012-09-24 11:16
| | | |

各县（区）人民政府（管委会），市直有关单位：
　　为贯彻落实国务院、省政府关于纠风工作的部署和市纪委五届九次全会要求，现提出2012年纠风工作实施意见。
　　一、总体要求
　　2012年的纠风工作，要全面贯彻党的十七大和十七届四中、五中、六中全会精神，以创建提升纠风惠民品牌为目标，以联动纠风、群众纠风、网络纠风为重点，以纠风专项治理目标管理为保障，大力实施“十百千万”工程，着力解决群众反映强烈的突出问题，为实现“跨越发展、宜居港城”奋斗目标提供有力的保障。
　　二、主要任务
　　（一）实施“十百千万”工程，深入开展“正风正纪保纯洁、提速提效促跨越”实践活动
　　1.十个领域重点抓。选择10个政府部门作为今年工作联系点，选择10个群众反映最强烈、问题最突出的领域，以制约和监督权力运行为核心，以完善制度机制建设为重点，作为纠风选题进行源头治理。
　　2.百个科室优服务。通过群众选、部门推、领导点等方式，选取100个与实施城乡一体化发展、与民生关联度较高的科室，通过透明权力运作、规范窗口服务、实施全方位监管、接受群众评议等方式，着力解决 “中梗阻”和行政不作为、慢作为、乱作为等难题,提高服务效能。
　　3.千户（企）走访解民忧。督促市直有关部门开展走百村访千户（企）活动，通过“面对面提问释疑、手拉手结对解困、心连心承诺沟通、背靠背评价测评、实打实督办整改”的方式，切实解决一批企业、群众最关心、最直接、最现实的利益问题。
　　4.万人评议听民声。采取在重点服务窗口设立满意度评价常规评、年终开发满意度测评软件网上评、组织评议小组深入基层现场评、通过短信平台广泛评等综合评价模式，发动群众广泛参与评议，将评判权交给群众。
　　（二）突出联动纠风、群众纠风、网络纠风，持续提升纠风惠民品牌
         1.围绕“三个品牌”创建，推动联动纠风。
         （1）着力提升综合舆论监督品牌。整合电视台《纠风在线》、广播电台《政风行风热线》、湄洲日报《民生热线》栏目为《壶兰监督》栏目，推进媒体联动，拓展监督范围，通过每期聚焦一个热点，评议一个行业，大篇幅、焦点式监督，增强监督效果。
　　（2）着力提升民生服务监督品牌。一是强化统筹功能。进一步拓宽诉求受理范围，调整监督台运作模式。二是抓好诉求办理提速。对各责任单位在民生诉求项目出警、办理的时限进一步压缩，建立“投诉快速办理机制”。三是完善行评代表工作室制度，逐步建立、不断充实行评代表人才库。
　　（3）着力提升“五位一体”民生诉求品牌。进一步完善诉求的快速办理机制、舆情分析制度，健全完善便于舆论监督和群众监督的常态纠风机制，使群众诉求有渠道、问题能解决、权益得保障。
　　2．围绕“三个载体”创建，深化群众纠风
　　（1）不断深化民主评议政风行风。继续完善“个案整改以治标，选题评议以治本”工作机制，及时调整评议主题和评议方法；进一步完善政风行风评议周评价、月报告制度，不断完善政风行风评议日常监管模式，更加注重群众参与、更加注重简便易行、更加注重解决问题。
　　（2）深入开展民主评议基层站所活动。按照“分批实施、分层组织、三年一轮转”的基层站所民主评议总体规划，在确定的10个重点部门基层站所开展民主评议活动。按照“程序提效、效率提速、服务提质”的工作目标，实行服务的标准化。对于服务对象：事前有承诺、事中有流程、现场可评价、事后有回访。对站所工作人员：身份有公示、服务有承诺、流程有规范、职权有监督、绩效有考核。
　　（3）建立覆盖广泛、反应迅速、处置高效的市、县、乡、村四级纠风网络。各县区要按照编制配齐纠风工作人员，分别选择一个乡镇级纠风工作联系点，分门别类，指定专人负责，加强对基层纠风工作的检查与指导力度。被确定为联系点的乡(镇、街道)设立纠风工作组,明确分管领导、配备兼职人员，行政村(社区)设立纠风监督员，努力形成 “县（区）有纠风办、乡（镇）有纠风组、村（社区）有监督员”的工作格局。
　　3.围绕“三个平台”创建，强化网络纠风
　　（1）民生诉求网上办理反馈平台。围绕诉求范围的扩容，诉求类别的规范、部门出警的提速、实时向投诉人反馈、公开，着力抓好民生服务监督台业务系统扩容升级，实现民生服务的快速反应；对廉政网纠风诉求平台进行升级改造，实现纠风诉求全部网上督办反馈。
　　（2）民主评议政风行风网络平台。按照“行评动态网上展示、行评业务网上跟踪、行评成效网上评议”的思路，进一步完善政风行风评议网上日常监管、验收和考评模式，切实解决“程序繁琐、业务繁杂、材料繁多”问题。
　　（3）纠风专项治理电子监察平台。进一步完善政府资金在线监控、新农合、保障性住房监管等专项治理监管平台，对专项治理的工作目标、时序安排、工作进度和责任落实进行实时、全程监控。
　　（三）探索“分级防控、目标管理”模式，认真抓好群众反映强烈问题的专项治理
　　积极探索纠风专项治理“分级防控、目标管理”模式：即一级项目牵头部门负责，纠风办指导，目标管理、重点防控；二级项目牵头部门主抓，规范运作、常态防控；三级项目牵头部门负责，重抓提升、制度防控。二级、三级项目不再列为当年度纠风责任制考评项目。今年列入一级防控项目有8项。
　　1.纠正一些行业、领域乱收费问题。一是纠正银行业金融机构乱收费问题。集中整治银行业金融机构附加贷款条件、变相提高利率、擅自增加收费项目、误导购买保险、以贷转存、存贷挂钩、以贷收费、浮利分费、借贷搭售、一浮到顶、转嫁成本等违规问题。坚决查处银保不分、银证不分，混淆概念诱使群众参加保险、证券投资的违规行为。重新确定、公开并严格执行收费项目、服务质价、效用功能和优惠政策，不断规范商业银行中间业务服务项目和标准。（牵头单位：市银监局，参加单位：市物价局、人民银行莆田支行、市政府纠风办）
　　二是纠正大型零售企业向供应商违规收费问题。落实明码标价，规范促销服务费的收取，严禁零售企业利用市场优势地位向供应商收取其他费用。完善零售商供应商商品购销规范和公平交易管理办法，严肃查处商业贿赂行为。鼓励行业协会建立信用档案，督促零售企业加强内部管理，加强与零售商沟通协调。（牵头单位：市经贸委，参加单位：市物价局、公安局、国税局、地税局、工商局、市政府纠风办）
　　三是纠正物流领域乱收费问题。规范涉路涉车执法行为，严肃查处乱收费、乱罚款。严格执行鲜活农产品“绿色通道”政策。规范物流市场秩序，完善物流政策法规体系，深化物流领域体制改革。（牵头单位：市交通运输局，参加单位：市物价局、财政局、经贸委、工商局、市政府纠风办）
　　四是纠正电信行业乱收费问题。集中整治违规收费、恶意误导消费者等突出问题，严肃查处虚假宣传、违规营销、价格欺诈、内置吸费等侵害用户合法权益的行为。加强电信资费、计费和收费管理制度建设，清理资费套餐。加强电信服务质量监管，完善消费者投诉处理机制和电信企业服务承诺制，强化社会监督措施。（牵头单位：市物价局，参加单位：莆田电信分公司、移动分公司、联通分公司，工商局、公安局、市政府纠风办）
　　五是纠正教育乱收费问题。强化教育经费拨付使用情况的监管，全面完成改制学校清理规范任务，解决义务教育阶段择校乱收费问题，加强学前教育收费行为监管，严格落实高中招收择校生“三限”政策，严禁收取与招生、入学、入园挂钩的各种费用。加强对中小学教辅材料的监管，坚决治理中小学教辅材料散滥问题。（牵头单位：市教育局、市政府纠风办，参加单位：市财政局、审计局、物价局、文化广电新闻出版局）
　　六是纠正涉农乱收费问题。全面清理涉农收费文件规定，坚决纠正向农民乱收费、乱罚款及摊派问题。深入开展农民负担专项治理，坚决纠正计划生育、农村义务教育、农民建房、农村公路修建等方面的乱收费行为。深化向农村基层组织、农村经济合作组织乱收费、乱罚款及摊派的专项清查工作，建立和完善向村级组织收费的长效监管机制。坚决纠正在农村基础设施建设、农村公共服务、农业社会化服务、惠农补贴补助等领域项农民转嫁摊派资金、强行抵扣、打车收费等违规行为。规范“一事一议”和财政奖补行为，防止变相加重农民负担。（牵头单位：市农业局，参加单位：市委农办、财政局、物价局、国土资源局、住房和城乡建设局、卫生局、水利局、人口和计生委、工商局、文化广电新闻出版局、市政府法制办、教育局、市政府纠风办）
        2.重抓“两违”专项治理。督促加快村镇规划实施步伐,扭转城乡规划滞后的局面。针对城市建设占地拆迁补偿不规范问题，督促对拆迁项目的补偿安置标准予以规范，并严格落实。严格领导责任追究制度,凡土地管理目标责任考核不合格的,违反土地利用总体规划实施管理规定的,辖区内发生“两违”案件造成严重后果的,对两违行为不制止、不组织查处的,对土地违法违规问题隐瞒不报、压案不查的,严肃追究有关负责人的责任。（牵头单位：市国土资源局、市城管执法局，参加单位：市水利局、市城乡规划局）
　　3.坚决纠正保障性住房建设、配置等环节的不正之风。把监督检查工作贯穿于保障性住房建设全过程，推动机制制度的建立和完善。在建设方面，督促政府落实责任，确保建设资金和用地及时到位；推动有关部门继续实施保障性安居工程巡查制度，全面推行质量终身责任制；严厉查处囤地圈地、违规用地、闲置浪费土地等行为。在分配方面，建立健全以住建局牵头的多部门协作配合的家庭住房和经济状况审核机制，严格准入资格审核；及时公开房源、轮候排序、配租配售结果，全程接受社会监督；优化申请审核、公示、核准登记、轮候、配租配售等环节的工作程序，完善受理条件、材料内容、完成时限等工作标准；坚决纠正骗购骗租、变相福利分房、利用职权侵占保障房以及擅自改变住房性质、违规转租转借转售和闲置保障房等行为。在管理方面，落实配租配售统计及通报制度，建立保障性住房档案管理制度，实施每年复审，实现保障性住房档案的动态管理；完善退出机制，加强对保障性住房运营、退出的监管。（牵头单位：市住房和城乡建设局、市政府纠风办，参加单位：市国土资源局、发展改革委、民政局、公安局、农业局、林业局、审计局、物价局、效能办）
　　4.规范客运市场秩序。加大执法力度，着力整治出租车市场混乱、拒载、不打表行为。继续探索客运市场城乡一体化管理模式，进一步规范客运市场的服务和收费行为，年内力争新开通1-2条城市公交线路。建立道路运输企业质量信誉评价体系，强化结果应用。（牵头单位：市交通运输局、市物价局，参加单位：市运管处、市交警支队）
　　5.坚决纠正公务员考录和企事业单位招聘中的不正之风。严格规范和完善公务员考录操作程序，积极探索建立国有企事业单位招聘统一考试制度。提高考录和招聘工作透明度，推动实行全程公开，强化报名、笔试、面试、体检、考察等重点环节的监督。严明考录和招聘工作纪律，严格实施责任追究，坚决查处和纠正违反操作规程、暗箱招录、弄虚作假、徇私舞弊、失职渎职等行为，确保考录和招聘工作的公开、公平、公正。（牵头单位：市公务员局，参加单位：市委组织部、市委编办、市人力资源和社会保障局、市国资委、市政府纠风办）
　　6.坚决纠正食品安全领域的不正之风。健全地方政府负总责、有关部门各负其责、企业履行主体责任的食品安全监管责任体系，强化综合协调机制，形成工作合力。建立健全食品安全事故责任调查和责任追究机制，依法严肃查处食品安全监管中的监管不力、推诿扯皮、失职渎职等行为。强化食品生产企业诚信体系建设，规范经营活动，加强监管。深入开展食品安全专项清理整治工作，严厉打击食品生产违法犯罪行为，消除食品安全隐患。（牵头单位：市经贸委，参加单位：市委宣传部、市发展改革委、科技局、公安局、财政局、环保局、住房和城乡建设局、农业局、海洋与渔业局、卫生局、工商局、质监局、粮食局、药监局、莆田出入境检验检疫局）
　　7.加强对强农惠农富农资金使用情况的监管。进一步探索规范强农惠农富农资金在线监管，资金配额、支出报账、国库集中支付、绩效评价四制管理，四级联动公开，“拉网式”督查等有效举措。严肃查处贪污、截留、挪用及套取资金行为，推进资金整合，充分发挥资金效能。（牵头单位：市财政局，参加单位：市农业局、市物价局、市审计局、市教育局、市水利局、市委农办、市人力资源和社会保障局、市林业局、市民政局）
　　8.坚决纠正医药购销和医疗服务中的不正之风。完善网上药品集中采购制度，继续完善和推行“两票制”运行机制。加强对集中采购工作的有效监督，落实卫生主管部门在药品集中采购和流通环节中的监管责任，严肃查处药品集中采购工作中的违规行为。完善药品电子监管制度，积极推进全部药品入网赋码，试行医疗机构诊疗用药电子监察。完善医德医风考评机制，加强公立医院廉洁风险防控。试行重点医院的医德医风测评，将测评结果与医生的评先评优和职务晋升直接挂钩，并与民评工作结果相结合。推进医药领域信用体系建设，加大对诚信企业扶持和失信行为惩戒的力度。继续强化药品安全监管，健全药品电子监管制度，加强药品不良反应监测，建立药品安全预警和应急处置机制。（牵头单位：市卫生局、市政府纠风办，参加单位：市财政局、人力资源和社会保障局、工商局、药监局、物价局）
　　继续深化庆典研讨会论坛博览会过多过滥问题、纠正违法违规强制征地拆迁问题、减轻企业负担工作、规范市场中介组织等4项列为二级防控项目；社保基金、住房公积金和扶贫、救灾救济资金监管、行业协会监管、清理规范评比达标表彰活动等5项列为三级防控目，市纠风办不再跟踪督办。
　　三、工作要求
　　（一）加强组织领导，认真落实责任。坚持“党委统一领导、各级政府主抓、部门各负其责、纠风办组织协调和监督检查、依靠人民群众积极参与”的领导体制和工作机制。各级政府要担负起全面领导本地区纠风工作的责任。各部门、各行业要坚持“谁主管，谁负责”和“管行业必须管行风”的原则，细化工作任务，严格目标考核，确保任务落实。各级纠风办要加强组织协调和监督检查，继续完善考评工作机制，督促有关部门认真履行职责。
　　（二）突出工作重点，打造精品亮点。按照“突出特点、抬高起点、强化重点、打造亮点”的思路，以群众最关心的问题为工作中心，突出重点工作、抓住重点环节，以点带面、实现突破。运用报刊、电视、网络等多种形式，精心设计一些有特色、有亮点的活动载体和办法，大力宣传宣传在实践活动中涌现出来的先进典型。
　　（三）坚持纠建并举，严查典型案件。严肃查处以权以业谋私、严重损害群众利益的大案要案，性质严重、社会影响恶劣的典型案件，顶风违纪、破坏经济发展环境的案件以及带有苗头性和倾向性的案件，形成纠风工作的震憾力。加大责任追究和曝光力度，把案件查处与情况通报结合起来，强化“纠建并举”，建立纠风案件“一案一整改”的工作机制，既纠正一批不正之风问题，查处一批典型案件，又注重在治本、预防和制度建设上下功夫、出成效，从一案一查向形成规模效应转变。


　　莆田市人民政府   
　　二〇一二年五月八日
