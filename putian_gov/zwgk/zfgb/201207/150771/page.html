莆田市人民政府办公室转发市工商局关于服务经济跨越发展的若干意见

莆政办〔2011〕102号
来源:市府办 时间：2011-06-28 08:58
| | | |

各县（区）人民政府（管委会），市直各单位：
　　市工商局制定的《莆田市工商行政管理局关于服务经济跨越发展的若干意见》已经市政府同意，现转发给你们，请认真贯彻执行。


　　莆田市人民政府办公室
　　二〇一一年五月十二日

莆田市工商行政管理局关于服务全市经济跨越发展的若干意见
莆田市工商行政管理局（二〇一一年五月九日）


　　为深入贯彻落实省委八届十次全会精神以及市委、市政府关于做大总量、优化结构、服务发展的部署,充分运用工商行政管理职能,大力推动我市各类市场主体保质增量,持续快速发展,更好地服务海峡西岸经济区建设，全面实现“跨越发展、宜居港城”的奋斗目标,现结合我市实际，提出以下若干意见：
　　一、降低门槛，放宽登记限制，营造准入宽松环境
　　（一）放宽企业经营范围自主选择权。除涉及企业登记前置许可审批项目外，企业可根据自身需要申请经营范围，允许企业经营范围跨越多个行业。对未纳入《国民经济行业分类》的新兴行业的一般经营项目，可根据企业的申请，参照该行业通常用语灵活核定能体现其行业和服务特点的经营范围。
　　（二）扩大台湾居民个体工商户的经营范围。在原有基础上，增加以下行业：计算机服务业、软件业、与道路运输相关的装卸搬运、其他运输服务业、仓储业、笔译和口译服务。
　　（三）放宽企业投资领域限制。除国家明令禁止外，凡允许国有资本、外资进入的投资领域，一律对个体私营企业开放；鼓励个体私营企业参与国有、集体企业的改组、改制，大力发展混合所有制经济；鼓励民间资本参与海洋资源勘探和开发，支持民间资本进入海洋基础设施、公用事业等领域。
　　（四）放宽企业名称登记限制。以英文字母为商号的国际知名企业，在我市设立的外商投资企业或其在大陆设立的外商投资企业在我市设立的全资或控股子公司，允许使用投资者名称中的英文字母作为字号。
　　允许在我市从事新兴行业的企业，使用新兴行业用语作为企业名称中的行业用语，不受国民经济行业用语规范的限制。
　　企业注册资本在2000万元人民币以上、企业经济活动性质分别属于国民经济行业3个以上大类、与同一工商机关核准或登记注册的企业名称中字号不相同的，其企业名称中可不使用国民经济行业类别用语表述企业所从事的行业，允许冠我市、县、区行政区域的企业，单独使用“实业”、“发展”“置业”等字样。
　　企业名称申请冠“莆田”、“莆田市”行政区划名称的，注册资本最低限额放宽为50万元人民币。
　　（五）放宽投资人身份限制。除法律、法规另有规定外，允许个人独资企业、合伙企业、民办非企业单位、社区、村委会、事业法人、社团法人、高等院校、科研机构作为投资主体，投资设立除一人有限公司外的公司制企业；内资企业的自然人投资人变更国籍（身份）的，在变更国籍（身份）后该投资人未增加投资的，除投资人要求外，不改变原企业的性质及类型。
　　（六）放宽出资方式限制。支持企业拓宽出资方式，允许企业以符合登记机关规定的债权出资，允许农民按照依法、自愿、有偿的原则，在不改变土地、林地性质和用途的前提下，以土地承包经营权、林权作价出资设立农民专业合作社。
　　（七）放宽法定代表人任职限制。企业因未年检被吊销营业执照，该企业法定代表人在企业被吊销执照前在其它企业任职的，允许其继续担任该职务。
　　放宽港澳台居民的任职限制。居住在香港、澳门、台湾的中国公民以及持有中国护照的华侨在内资企业担任法定代表人的，登记时免于提交就业证。
　　（八）放宽外国（地区）投资者主体资格证明手续。香港、澳门企业在英属维尔京群岛、开曼群岛等自由关税区设立的离岸公司来莆投资，可提交经当地公证机关公证并经中国驻当地使领馆认证的主体资格证明，也可以由香港、澳门公证机构出具公证文件。
　　未建立公证制度的国家（地区）投资者，其主体资格证明可由当地登记机关出具，并经中国驻当地使领馆认证。
　　（九）放宽农村及社区服务业创业限制。凡在住宅小区或农村有固定场所，为小区居民或村民提供自行车维修、小家电维修、缝纫修补、疏通管道和卫生保洁等服务的，可不办理营业执照，只须向所属社区居民委员会或村委会备案；农村家庭成员在自有房屋从事临时性（3个月以下）、季节性或者从业人数少于5人的小规模服装、针织、半成品鞋袜代加工的，实行向社区居民委员会或村委会备案登记。社区居民委员会或村委会已办理备案的,可暂缓办理营业执照。
　　二、帮扶企业，支持新兴产业，促进市场主体发展
　　（十）大力支持战略性新兴产业、新兴业态的发展。对投资战略性新兴产业的，支持不需要办理权属登记的技术作为上述新兴产业公司股东的首次出资。对申请从事《国民经济行业分类》未列明的新能源、新材料、新医药、节能环保、生物育种、信息网络等战略性新兴产业的企业，除国家法律有专门规定的外，企业登记机关应予以登记。
　　（十一）服务“城”、“区”促发展。“城”、“区”分别指各类商业城和各种经济园区、开发区。工商部门为支持“城”、“区”经济做大、做强，分别在各“城”、“区”成立协调领导小组，同管委会定期召开会议研究解决企业反映的问题。并在市场准入登记、融资帮扶、品牌指导服务等提供优质、高效、便捷的服务。对“城”、“区”内企业，除涉及环境影响，公共、人身安全等高危行业外，连续两年无违规和不良记录的企业，经申请和批准后，允许其每两年免予年检审查一次。
　　（十二）允许困难企业延长到资期限。对首期已到资，其余注册资本因暂时性资金困难未能按期到资的企业，经企业申请，允许其到资期限延长一年。外商投资企业首次申请出资延期的，可免于审批机关审批，直接向登记机关申请延长出资期限变更登记。
　　对2010年1月1日以后新设立登记的且属于县区级以上人民政府确定的重点外商投资企业，因客观原因首期出资无法按时全部到位的，凭当地人民政府出具的确认文件及外经部门的批准文件，允许其延长出资期限，并予以通过年检。
　　三、简政放权，推进制度改革，创造发展有利条件
　　（十三）规范市场主体登记前置许可。除国家法律、行政法规和国务院决定的事项外，其余事项不作为各类市场主体登记注册的前置条件。鉴于国家尚未出台《企业登记前置许可目录》，在目录出台前，除从事拆船业、危险废弃物、化工生产、娱乐场所经营涉及的行业外，其它行业申请登记时无须向登记机关提交环保审批文件，其中申请人属于《建设项目环境保护管理条例》规定的建设单位的，应在办理营业执照前自行向环保部门报批建设项目的环境影响评价审批手续；除娱乐场所外，消防事项的审批不作为各类市场主体登记的前置许可。待国家出台《企业登记前置许可目录》后，市场主体登记的前置许可按目录规定执行。
　　因前置许可证有效期限届满换证造成新旧证有效期不衔接的或超期的，经企业作出责任承诺后给予办理变更登记。前置许可证所载明企业负责人与营业执照负责人不一致的，企业应申请更改一致或承诺在一定期限内更改一致后，给予办理变更登记。
　　（十四）进一步下放审批权限。除法律法规规定必须由市以上工商局登记外，县、区工商局对内资企业注册登记权限不受注册资本限额的限制；对个体工商户、个人独资企业、合伙企业、农民专业合作社、食品流通许可证的登记、办理一律授权给属地工商所。
　　住所地位于仙游、涵江、秀屿的外商投资企业，可就近在所在地工商局登记。
　　（十五）实行重点项目筹建登记。凡落实市级以上各级党委政府扩大内需，促进经济增长决策确定的重点项目，对未取得法定的前置审批文件，但符合主体登记其他条件的重点项目，因建设或筹备需要办理营业执照的，根据当地政府出具的重点项目认定文件及登记材料，可给予办理登记注册，经营范围核定为某具体项目的筹建，筹建期原则上为一年。
　　（十六）试行台资企业年检免审制度。对全部到资且未有工商违法记录的台资企业，经申请核准后，年检时可免于提交审计报告、免于书式审查，免交年检费，在企业进行网上申报后，直接在其营业执照副本上加盖年检戳记。
　　四、转型升级，促进结构优化，支持主体做大做强
　　（十七）积极支持企业做大做强。支持拟上市企业申请无行政区划或冠“福建省”的企业名称、组建企业集团。支持有限公司变更为股份有限公司,对历史遗留的登记不规范问题积极帮助解决和完善，对企业改变组织形式、变更出资人或收购、兼并、改制的，除国家法律法规明令禁止的行业外，原批准的经营许可证继续有效，原批准的许可经营项目允许其继续经营，允许在折合的实收股本总额不高于评估后的净资产额的前提下，净资产折股具体数额由公司股东依法约定。
　　（十八）支持市场主体转型升级。支持个体工商户转型升级为个人独资企业，支持个体工商户、个人独资、合伙企业转型升级为有限公司。上述企业或个体工商户通过先注销再设立的方式转变企业类型或组织形式的，在原出资人、从事的行业、登记机关不变及法律法规对名称中的组织形式无特别规定的情况下允许保留原名称。转型企业经营范围涉及前置许可的，在原出资人、住所及前置许可项目未发生变动的前提下，许可文件仍可继续使用。由升级后的公司登记部门证明属于转型升级的，各政府有关部门应将主体转型视同变更予以办理相关手续，土地、房产管理部门办理转制主体涉及的土地房屋权属变更时，只收取工本费，不再收取其它费用。
　　（十九）实施商标富企战略。主动指导企业实施商标品牌战略，引导驰名著名商标企业充分发挥龙头带动作用，推动鞋革、服装、电子等传统产业转型升级，指导古典家具、木材、珠宝以及农产品商标的推广和使用力度，构建特色产业对区域经济发展的支撑。指导驰名、著名商标企业运用商标权质押贷款、商标权出资等融资手段，形成以品牌带动融资、充分体现无形资产应有价值，促进构建创新型城市建设。
　　（二十）支持广告企业发展。放宽固定印刷广告登记申请准入条件，允许企业名称中含有“文化传播”、“传媒”、“企划”等字样的广告企业申请发布固定形式印刷品广告；支持固定形式印刷品广告经营者在全市各县区设立分支机构。引导广告企业不断提高品牌策划、营销、包装、推等综合服务能力，尽快扶持一批服务品牌建设的广告经营企业，做大做强广告产业。
