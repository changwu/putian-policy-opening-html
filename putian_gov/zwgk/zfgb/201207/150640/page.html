莆田市人民政府办公室关于印发2012年莆田市小城镇改革发展战役实施方案的通知

莆政办〔2012〕37号
来源:市府办 时间：2012-07-23 16:21
| | | |

各县（区）人民政府（管委会），市直有关单位：
　　为了加快推进我市2012年小城镇改革发展战役工作步伐，经市政府研究同意，现将《2012年莆田市小城镇改革发展战役实施方案》印发给你们，请认真贯彻执行。

莆田市人民政府办公室       
二O一二年三月五日       

2012年莆田市小城镇改革发展战役实施方案

　　为深入贯彻落实市委第六次党代会和市委六届二次全会精神，继续打好小城镇改革发展战役，在更高起点上推动小城镇科学发展、跨越发展，加快建设富裕莆田、和谐莆田、文化莆田、生态莆田、幸福莆田。根据福建省发展和改革委员会、福建省住房和城乡建设局、福建省国土资源局《关于印发2012年小城镇改革发展战役实施方案的通知》（闽发改规划〔2012〕108号），结合我市的实际，特制订以下实施方案。
　　一、总体目标
　　围绕 “规划先行、功能齐备、设施完善、生活便利、环境优美、保障一体”的宜居城市综合体建设目标，加大改革建设试点工作力度，拓展战役领域和内涵，西天尾镇、江口镇、枫亭镇、埭头镇等4个省级试点镇基本建成连片、有特色、高水平的示范区，榜头镇、北高镇、华亭镇、萩芦镇、山亭镇等5个市级试点镇现代新型小城市的雏形和框架初步建立，着力打造若干具有典型示范意义的试点镇。强化试点镇产业支撑，创新投融资模式，实现投资的稳健增长，全年实施项目221个，完成投资138.7亿元。有利于试点镇健康发展的体制机制初步建立，行政管理体制、财税体制、土地经营机制、户籍管理制度等方面改革有新的突破。
　　二、重点任务
　　（一）规划设计。一是拓展规划范围。集中力量实施“点”、“线”、“面”攻坚计划。上半年，各试点镇在基本完成总体规划、专项规划和详细规划编制基础上，全面完成规划报批工作，提高详细规划的覆盖率。枫亭镇、埭头镇规划展示厅建设要在第一季度全面完成，市级试点镇规划展示厅建设要在上半年动工。二是抓好城市设计和建筑设计。重点抓好城镇主要出入口、主干道沿线、规模大的安置房小区、滨水地段、商贸街区、中心广场、园林景观项目等重点地段和节点地区的城市设计，积极开展外部空间和形体环境设计，着力提高项目设计水平。上半年，西天尾镇、江口镇要初步形成城市整体景观和效果，其它试点镇要基本完成城市设计，若干地标性项目建成并启用。三是规范的设计论证、审查机制。重点地段和节点地区的城市设计及重要建筑的设计方案，由市规划局、试点镇所在县（区、管委会）规划部门和试点镇，联合组织审查把关，并提高城市设计和建筑设计的民主参与度。（责任单位：市规划局，相关县区、管委会，各试点镇）
　　（二）示范区建设。一是各试点镇要根据发展定位和特色优势，打造城市综合体、工业、商业、住宅、文化、旅游、生态等特色鲜明、功能完善、带动效应明显的示范区。省级试点镇年内基本建成有一定规模水平、集中连片的示范区，市级试点镇上半年正式启动示范区建设。二是完善示范区基础设施和配套设施，加大历史传统街区、景观街道和历史建筑的保护力度，完善市政道路、给排水、垃圾处理设施，提高绿化档次。年内，省级试点镇示范区基础设施和配套设施基本完善，绿化覆盖率达30%以上；市级试点镇完成示范区内2个以上城镇道路、园林绿化、污水垃圾处理等项目。三是突出示范效应，增强示范区的集聚承载、综合服务和辐射带动功能，促进人口集中、产业集聚、要素集约、功能集成，年内每个试点镇要塑造2个以上可看、可学、可推广的示范典型。（责任单位：市发展改革委、市住房和城乡建设局、市规划局、市国土资源局、市林业局，相关县区、管委会，各试点镇）
　　（三）市政和公共服务设施建设。一是加快推进交通、能源、市政公用事业、信息网络和防灾减灾等重点项目建设，完善供排水、人行道、停车站亭、绿化、电力、生活垃圾处理、通信等配套设施。年内西天尾镇、江口镇镇区人均道路面积达到15平方米以上，其它试点镇镇区人均道路面积达到14.5平方米以上。二是加大民生工程建设和投入力度，提高公共服务配套水平，建成一批教育、文化、卫生、体育以及供水、排水、供气、公交、公厕等公共服务设施，大幅度提升小城镇综合承载能力和公共服务功能。各试点镇要成为区域性的教育和卫生服务中心。西天尾镇、江口镇镇区供水普及率达到100%，燃气普及率达到90%以上；枫亭镇、埭头镇镇区供水普及率达到90%以上，燃气普及率达到75%以上；市级试点镇镇区供水普及率达到80%以上，燃气普及率达到50%以上。（责任单位：市发展改革委、市住房和城乡建设局、市经贸委、市交通运输局、市教育局、市文化广电新闻局、市卫生局、市体育局，相关县区、管委会，各试点镇）
　　（四）特色产业培育。一要立足实际，合理布局符合规划和环保要求、吸纳就业、带动城镇发展的产业项目，逐步提高工业区增加值占全镇工业增加值的比重。二要培育主导产业和特色产业，因地制宜发展物流、旅游、商贸、文化等产业，打造各具特色的工业强镇、商贸重镇、旅游旺镇和历史文化名镇。三要拉长产业链，促进产业集聚发展，推动规模做大、结构优化，鼓励扩大民间投资，结合引进大企业大项目，建设特色产业基地，强化产业支撑。年内，省级试点镇有2个以上投资过亿元的重大产业项目竣工投产，市级试点镇有1个以上投资过亿元的重大产业项目竣工投产；全部或多数的制造业企业进入集聚区（工业园区）。（责任单位：市发展改革委、市经贸委、市住房和城乡建设局、市规划局、市文化广电新闻局、市旅游局，相关县区、管委会，各试点镇）
　　（五）绿化系统建设。一是结合旧城区改造和新区建设，推进公园、绿化带、街头绿地、庭院绿化建设，抓好沿河（溪）、渠、湖、海绿化整治，增加绿量，提高绿化水平。上半年，省级试点镇至少建成1个公园，市级试点镇要启动公园建设；年内各试点镇建成区人均公园绿地面积达到7平方米以上。二是开展绿道系统建设，把绿道建设列为重点项目加以推进，打造生态型、郊野型和都市型等不同类型的绿道，各试点镇年内要建成1条有特色的绿道。充分结合现有地形、水系、植被等，串联旅游区、公园、历史古迹、公共建筑等节点，构建群众生活休闲主要线路。（责任单位：市住房和城乡建设局、市林业局，相关县区、管委会，各试点镇）
　　（六）综合景观整治。一是加快推进主要街道和环境景观综合整治，对景观欠佳的沿街建筑进行立面改造，通过管线下地，拆除沿街防盗网，清理各类广告牌，改造公厕，完善人行道铺装、道路照明和绿化等措施，美化景观环境。各试点镇在已完成主要街道的景观综合整治的基础上，再着力整治1条以上主要街道。二是加快污水、垃圾处理项目建设，上半年，省级试点镇要建成污水、垃圾处理设施，市级试点镇要全部启动污水、垃圾处理设施项目建设并加快进度。（责任单位：市发展改革委、市住房和城乡建设局、市规划局，相关县区、管委会，各试点镇）
　　（七）土地整治和“三旧”改造。一是继续实施城乡建设用地增减挂钩政策。省级试点镇要完成200亩旧村复垦任务，西天尾镇、江口镇再立项实施100亩以上旧村复垦项目，市级试点镇要完成实施200亩以上规模的土地整治项目。严格执行实施步骤和工作流程，做好指标交易、村民建房、拆迁补偿、土地复垦等工作，着力打造新村建设示范区。城乡建设用地增减挂钩指标的转让收益主要用于“造福工程”的群众搬迁安置。对旧村复垦项目群众搬迁退出的旧房，参照当地重点项目建设的房屋拆迁补偿标准给予补助；除必要的工作经费外（不超过5%），其余资金用于“造福工程”项目公共配套建设。二是推进“三旧”改造。各试点镇要做好调查摸底、科学规划和深度开发，年内启动1个以上“三旧”改造示范项目，对其中涉及的土地用途变更、征地补偿等问题，要积极研究制定具体、可操作的配套政策。（责任单位：市国土资源局、市委农办、市财政局、市住房和城乡建设局、市规划局，相关县区、管委会，各试点镇）
　　（八）机制体制创新。一是推进行政管理体制改革，各试点镇所在县（区）政府（管委会）要主动会同相关部门探索在有条件的试点镇单独设立国土、规划、住房建设、综合执法、行政审批等管理机构；赋予试点镇与县级基本一致的经济类项目核准、备案等管理权限。二是进一步理顺县（区、管委会）与试点镇的财力分配关系，合理划分县、镇财权与事权，有条件的试点镇要按照“一级政府一级财政”的要求积极构建财税管理体制。三是加快推进农村集体土地所有权、宅基地使用权、集体建设用地使用权的确权登记颁证工作，探索农村集体建设用地的流转方式，推进集体经济股份制改革，推行土地承包经营权流转和入股。四是探索建立小城镇改革发展专项资金和股权投资基金，鼓励创新，扶持试点镇建设发展。五是继续推动试点镇重心下移、关口前移、强镇扩权，及时出台相关指导意见，力争在融资、就业等方面有所突破，推动小城镇综合改革向纵深推进。六是完善户籍登记和管理制度，按照“双重身份并存、双向自由流动”要求，允许登记为城镇户口的农民按本人意愿，继续保留其集体土地的承包经营权，也可有偿退还或转让，五年内继续享受农村计划生育政策；推进暂住证制度改革，暂住人口尤其是外来务工人员凭居住证在医疗、社保、教育等方面与居住地居民享受平等权益。（责任单位：市发展改革委、市国土资源局、市住房和城乡建设局、市经贸局、市财政局、市公安局、市人力资源和社会保障局、市人口计生委，相关县区、管委会，各试点镇）
　　三、保障措施
　　（一）落实责任分工。市小城镇战役办要定期组织召开战役进展情况分析会、汇报会，研究探讨工作进展情况，协调解决有关问题，加快推进战役工作的实施；战役办各挂钩试点镇领导要增强工作的主动性，加强与基层的互动，在重大项目和政策的实施上，多指导、多服务，切实协调解决基层反映的困难和问题。市直有关责任单位要逐条对照目标任务，出台相关配套政策措施，制定本部门推进小城镇改革发展工作方案及时间安排表，责任到人；要进一步增强服务意识，各司其职，密切配合，形成合力，加强对试点镇建设工作的指导和协调。试点镇所在的县区政府（管委会）是战役的纵向责任主体，要加强领导，积极对上衔接，结合本地区工作实际，及时制定实施方案；要健全机制、自加压力、突破常规，确保战役部署落到实处。各试点镇要结合目标任务，认真制定具体工作方案，周密安排，有效运作，尽快形成实物工作量，明确时间节点、责任单位和责任人。各级领导要改进作风，大力推行“一线工作法”，主要领导亲自过问、亲自协调，分管领导靠前指挥、具体调度，推动各项目标任务落到实处。
　　（二）拓宽战役领域。各试点镇要结合实际，梳理筛选一批新项目，及时把农林水利、“四绿工程”、城镇美化、造福工程、饮水安全、防灾减灾等领域的项目纳入战役实施范围，把战役实施作为突破重点难点的有力抓手、拉动内需的有效途径、增强发展后劲的长远之计、保障和改善民生的重要载体，最大限度地惠及广大群众。积极推进央企、民企、外企“三维”项目对接，加强动态跟踪和调度服务，结合规划布局和产业政策，加强项目拓展工作，引进先进管理经验和运作模式，争取更多更好的大项目、新项目。
　　（三）突出要素保障。一是服务保障。各级各部门要提高办事效率和服务质量，简化手续，为项目审批开辟“绿色通道”。二是资金保障。积极推广BT、BOT等融资模式，促进项目尽快开工建设。深化政银企合作，通过信托、融资租赁、保险债权、中期票据、债券等金融工具，解决资金难题，拓宽融资渠道。三是用地保障。坚持“遵循规划、有序释放、依法运作、注重效益”的要求，做好占补平衡，盘活土地存量，集约节约用地。推广应用和谐征迁工作法,做到主要领导“五亲自”、工作班子“五尽心”、实施方案“五到位”、补偿资金“四严格”、征迁安置“四满意”，保障人民群众合法权益。四是政策保障。要根据各试点镇不同的区位资源条件和发展基础、发展潜力，实行分类指导，在规划、项目管理、财税、投资、金融、户籍等方面实行各有侧重的政策措施，加快推进试点镇改革建设。五是质量保障。加强建设项目招投标和资金使用监管，严防工程领域腐败问题，严格执行工程建设强制性标准，确保工程质量，确保每个项目成为阳光工程、廉洁工程、安全工程。六是人才保障。配强配齐工作班子，加大专业培训力度，充实工作力量，选派一批懂管理、懂技术、懂经营的干部充实到试点镇工作一线。
　　（四）加大督查考核力度。健全完善信息报送和考核考评体系，继续实行考评通报制度，各试点镇每月30日前报送实施进展情况（项目进度表、形象进度表），并由市战役办定期进行通报。省级试点镇报送省发改委，一并报送市、所在县区；市级试点镇报送市战役办，一并报送所在县（区、管委会）。县（区、管委会）收到月报信息后应立即组织审查，发现与实际情况不符或有其他不同意见时应采取措施予以纠正，并将修改情况及时向省、市反馈。各试点镇每月同时报送2条以上综合改革建设相关信息。各县（区、管委会）每季度最后一周要组织一次自查，自查书面材料及时上报市战役办；市战役办根据各县（区、管委会）自查情况进行督查，督查情况予以通报。市战役办每半年对试点镇战役实施情况进行考核，考核情况作为年度考核的主要依据。战役实施情况列入各级各有关部门年度绩效考评内容，进一步推动比学赶超。
　　（五）加强舆论宣传。充分利用广播、电视、报刊、网络、宣传栏等多种渠道和形式，广泛宣传加快试点镇改革发展的重要意义及相关政策，激发基层干部群众的积极性、主动性和创造性，形成全社会关心支持试点镇改革的良好氛围。及时推广各地的成功经验，典型引导，示范带动，把小城镇综合改革建设试点工作引向深入。
