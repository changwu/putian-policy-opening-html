莆田市人民政府关于进一步提高行政机关办事效率的实施意见

莆政综〔2011〕178号
来源:市府办 时间：2011-10-28 16:19
| | | |

各县（区）人民政府（管委会），市政府各单位、各直属机构：
　　为进一步转变政府职能，提高行政机关办事效率，积极打造服务型政府，根据中共中央办公厅、国务院办公厅《关于深化政务公开加强政务服务的意见》及福建省人民政府《关于提高行政机关办事效率的十条意见》（闽政〔2011〕77号）精神，结合我市实际，提出如下实施意见：
　　一、加强发展服务中心自身建设。建立以市级发展服务中心为龙头、县（区、管委会）发展服务中心为主体、乡（镇、街道）便民服务中心为延伸的三级联动服务平台。各级服务中心应加强对部门自建服务中心及下一级服务中心的业务指导和监督。加快推进市发展服务中心新大楼建设，完善软硬件设施，提高服务水平。县（区、管委会）发展服务中心要加强各项制度建设，优化窗口设置和办公场所利用，扩大进驻部门的范围，不断提高和完善软硬件设施。各县（区、管委会）要加快便民服务中心建设，各乡（镇、街道）要依托城乡社区综合服务设施，推进基层便民服务，2011年确保各县（区、管委会）便民服务中心建成率超过50%，2012年底前争取全市所有乡（镇、街道）都设立便民服务中心。
　　二、加大简政放权力度。本着精减高效、重心下移、减少层次、能放则放的原则，进一步合理划分市级和县（区、管委会）级行政审批管理事权，市直部门要最大限度地梳理出一批审批管理事权直接下放或委托给县（区、管委会）。扩大县域经济投资管理决策权，除国家有明确规定的外，县（区、管委会）级政府投资的项目，全部下放由县（区、管委会）级政府投资主管部门审批；国内企业投资项目的核准、备案，凡在市级核准、备案权限内的投资项目，全部委托县（区、管委会）级政府投资主管部门核准、备案，报市政府投资主管部门备案；《企业投资项目核准目录》外的投资项目，不论规模大小，均改为备案制；总投资在1亿美元以下的鼓励类、允许类外商投资项目，全部委托项目所在地的县（区、管委会）级政府投资主管部门核准，报市政府投资主管部门备案。住房和城乡建设局、国土资源、海洋渔业、水利、林业、环保、规划、交通运输、人防、消防、工商、国税、地税等其他有审批权限的各部门要依据本实施意见制定简政放权的具体方案并及时在政府网站、湄洲日报、莆田电视台等新闻媒体上对外公布，接受效能督查和群众监督。
　　三、进一步提高审批效率。深入推进“三向并联审批”，即部门之间左右并联、市与县（区、管委会）之间上下并联、部门内设科室之间前后并联，将并联审批业务全部纳入市、县（区、管委会）两级网上审批与电子监察系统中规范运作。各有关部门要归并和前移审批权限，原则上应直接放权或委托给服务中心窗口，对前台窗口充分授权，后台科室全力保障，真正实现“部门围绕窗口转、窗口围绕百姓转”。部门应尽量专设审批科成建制进驻，建立“一个窗口对外、一个科室办理、一枚印章审批”，从机制上根本解决“前店后厂”问题。进一步简化审批环节，压缩审批承诺时限，优化工作流程，精简申报材料。原则上行政审批项目承诺时限要尽可能缩短到法定时限的60%以内，各部门要提出缩短审批时限的标准和范围，提高即办审批项目的比重。对内容相近、重复设置的审批环节予以合并，对与审批事项没有关联或关联度不大的申报材料予以取消。试行超时审批默许制度，针对部分具备条件的行政审批项目，要求该部门向发展服务中心提交书面承诺书，承诺本部门超时且不及时进行处理的业务，网上审批与电子监察系统可默认准予许可并自动办结。
　　四、创新服务方式。各部门对重点项目、灾后重建项目、重大民生项目等要开辟“企业直通车”和“项目绿色通道”，并对外公布该行政审批项目办理的条件、程序、时限。依托市、县（区、管委会）两级投资项目服务中心（招商局、工业项目办）逐步探索项目代办制，为企业免费代理代办。推广工商、国税、地税部门的“区域通办”或“同城通办”模式，市、县（区、管委会）两级部门具有同等审批权限。有条件的部门实行预约服务或上门服务制度。
　　五、整合公共资源交易平台。建立统一规范的公共资源交易平台。完善公共资源配置、公共资产交易、公共产品生产领域的市场运行机制，推进公共资源交易统一集中管理，逐步拓展公共资源市场化配置的实施范围，确保公共资源交易公开、公平、公正。严格执行《莆田市公共资源交易管理规定》，限额以上的全部进入市发展服务中心交易，其他在部门、县（区、管委会）或乡（镇、街道）平台交易。
　　六、整合电子政务资源。大力推广网上申报，扩大网上办事范围，通过网站、新闻媒体等多种方式宣传，鼓励企业主动利用网上申报平台办理业务。运用扫描、拍照、文字识别等方式将申报材料转化成电子文档，逐步推进档案卷宗电子化、数据化处理，提高申报材料的重复利用，整合电子服务资源，建立信息共享机制。实现市、县（区、管委会）、乡（镇、街道）三级网上审批与电子监察系统互联互通，尽快争取与省级网上审批受理发布平台对接。完善和改进电子监察系统功能，有针对性地解决并联审批、上下互通互联、网上申报等方面功能不足问题，破解政务网与部门专用网络之间的衔接瓶颈，实现各级服务中心的数据交换、预警、监察等功能。
　　七、规范行政许可裁量权。认真修订完善行政许可裁量权。要根据机构改革、职能变化、法律依据修改等情况，按照莆田市人民政府办公室《关于按时全面完成规范“两权”有关重点任务的通知》（莆政办明电[2011]57号）要求，认真梳理行政许可项目，修订完善后的行政许可裁量权要与省里衔接，并按程序审核后及时予以公开。
　　八、大力精简文件和会议。坚持少而精的原则，可发可不发的文一律不发，可长可短的文一定要短。对国务院、省政府的普发性文件，没有新的贯彻要求的，一般不再发文，凡属部门职权内可自行发文或几个部门联合行文能够解决的，不再以市政府名义批转或由市政府办公室转发。市政府办公室根据市政府授权可向下级政府行文，其他部门不得向下级政府发布指示性公文。部门管理的二级局、市属企业及行业协会等原则上不直接向市政府请示和报告工作，如有需要应通过主管部门向市政府报文，遇有紧急情况需直接向市政府请示或报告工作时，应同时报送主管部门。进一步规范文件、信息报送程序和范围，各级各部门自编的工作信息简报，应在本部门分发，克服多头报送和乱发乱送现象。严格控制会议次数，能合并的会议原则上合并，能通过文件、电话解决问题的就不召开会议，能以部门名义召开的就不以市政府名义召开，提倡召开电视电话会议或网络视频会议。科学安排会议议程，尽量压缩会期，提倡开短会、开小会、讲短话，减少礼仪性讲话数量，做到简单、明了、不重复。严格控制会议规模，与会人员应为会议相关单位的代表或会议直接关系者，不随意扩大与会人员，尽量减少陪会领导。健全会议审批制度，凡要求县（区）政府（管委会）主要领导或者县（区）政府（管委会）、乡（镇、街道）政府（办事处）主要领导一起参加的，按照中共莆田市委办公室、莆田市人民政府办公室《关于精简会议、文件和检查考评活动的通知》（莆委办[2006]94号）有关规定审批。
　　九、大力整治机关庸懒现象。进一步增强服务群众、服务企业、服务基层的意识，提高服务质量，积极推行便民、优质、高效、微笑、热情服务，坚决反对推诿扯皮、办事拖拉、庸懒散漫的不良作风，杜绝“门难进、脸难看、事难办”的现象。进一步健全责任体系，理清部门之间、层级之间、职级之间、个人之间、环节之间的责任，将每个职位的责任尽可能量化、细化、具体化，形成责任闭环。严格落实岗位责任制、同岗替代制、服务承诺制、首问责任制、一次性告知制、限时办结制、否定报备制、失职追究制等机关效能建设八项基本制度。开展专项整治工作，认真治理机关工作人员的庸、懒、梗、散问题，以治庸提能力、以治懒增效率、以治梗畅政令、以治散正风气。
　　十、加强行政问效问责。进一步完善督查机制，整合督查力量，充分发挥电子监察系统的作用，将其与视频监控、人工督查有机结合，形成“三位一体”全方位、多角度、广覆盖的效能监察体系。采取多种方式，着重围绕机关“效率、作风、执行力”等关键环节，定期、不定期开展效能督查，坚决制止行政审批“两头受理”、体外循环、授权不到位等现象。建立健全效能投诉办理机制，对群众反映强烈、企业投诉频繁的，要快速查办，及时回复。对通过投诉件办理和督查中发现的行政不作为、乱作为、慢作为等损害发展软环境、涉及企业和群众切身利益的机关工作人员，要依据机关工作人员效能告诫暂行办法的相关规定严肃予以责任追究；对出现机关工作人员违规被效能告诫的单位，一年内发生1人次的，对所在单位（部门）主要负责人予以诫勉谈话；一年内发生2人次以上（含2人次）的，对所在单位（部门）主要负责人予以效能告诫。

　　莆田市人民政府       
二〇一一年十月九日
