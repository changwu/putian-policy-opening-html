莆田市人民政府办公室关于开展中小学幼儿园校车和接送学生车辆安全专项督查情况的通报

莆政办〔2012〕10号
来源:市府办 时间：2012-04-26 16:56
| | | |

各县（区）人民政府（管委会），市直有关单位：
　　为了切实加强中小学幼儿园校车和接送学生车辆安全管理工作，根据市政府办公室《关于开展中小学幼儿园校车和接送学生车辆安全专项督查的通知》（莆政办[2011]90号）精神和市委、市政府领导的批示精神，12月20日至22日，由市安监局、市公安局、市教育局、市交通运输局组成联合督查组，对全市中小学幼儿园校车和接送学生车辆安全情况进行了督查。督查组采取听取汇报、个别访谈、查阅资料、现场查看等方式，对部分县（区、管委会）中小学（幼儿园）校车安全管理工作进行了督查。现将有关情况通报如下：
　　一、主要措施
　　（一）领导重视，部署迅速。甘肃正宁重大校车事故后，各级政府、各有关部门高度重视中小学幼儿园校车安全工作，立即召开专题会议进行部署，认真贯彻落实省政府安委会办公室《关于切实加强全省校车安全管理的紧急通知》（闽安委办明电[2011]26号）和市委、市政府领导的指示精神，按照《关于印发全市校车和校园周边道路交通安全专项整治工作方案的通知》（莆教[2011]安30号）文件要求，认真开展中小学幼儿园校车和接送学生车辆安全专项整治工作，全面排查校车隐患。
　　（二）明确责任，狠抓落实。各级政府、各有关部门能强化责任意识，全面落实学校交通安全管理责任制。明确了学校和幼儿园主要负责人为校车安全管理第一责任人，层层签订安全责任状，明确工作职责，使责任落实到人到岗。强化责任追究，对制度不健全、管理不到位、责任不落实导致接送学生车辆发生交通安全责任事故的，按照有关规定严肃追究相关学校和幼儿园相关人员的责任。秀屿区明确有关单位、学校的主要领导为专项行动的第一责任人，要亲自部署落实，严格落实安全生产责任，层层签订安全生产责任状。
　　（三）重视宣传，强化教育。各级政府、各有关部门能通过上好交通安全教育课、设置交通安全宣传展板、播放交通安全警示教育片、开展交通安全知识竞赛等形式，对学生进行了广泛的交通安全尤其是安全乘坐校车教育。北岸管委会共印发《致家长一封信》23500多份，召开交通安全主体班会1200多节次，组织教师家访24500多人次，开展交通安全讲座13场次，举行交通安全警示教育11场次，通过教育，提高了学生及家长的交通安全意识，养成了良好的交通习惯。
　　（四）加强排查，狠抓落实。各级政府、各有关部门在校安整治的基础上，加大工作力度开展校车、接送车辆安全的专项整治工作。荔城区加强车辆安全管理，严禁不符合安全性能的农村客运车辆从事学生客运，对不符合农村客运驾驶员条件要求的，一律取消上岗资格；涵江区政府针对家长接送、安全出行、道路交通隐患等重点环节，定期开展拉网式的学生交通安全大检查活动，排查交通安全隐患58个，已全面督促整改到位；北岸管委会今年共查获6起接送车辆违法行为，均抄告教育部门和相关学校，加强校园周边交通设施排查和完善，加强幼儿园及小学生上、下学防护。
　　二、存在的主要问题
　　（一）职责不明确，部门之间的配合、信息沟通不够。县（区）部门之间主动沟通不够，配合力度不大，各自为政，不能齐抓共管，整治合力未能形成。教育部门熟悉情况但无法管理，交警有路面执法权但无法全程监管，部分车辆采取“游击战”逃避执法部门监管，造成了个别县（区）存在“教育部门管不了，职能部门抓不着”的局面。
　　（二）排查底数不清。个别县（区）交警部门与教育部门排查的学生接送车辆底数不一致，一校一档、一车一档存在标准不一；个别县（区）教育部门对学生出行方式心中无数，排查统计就到乡镇这一块；部分学校没有按照教育部门要求认真贯彻落实排查学生上下学情况，未掌握实情，存在马虎应付现象。
　　（三）校车登记备案不乐观，大部分校车不符合标准，不具备运营资质。全市只有秀屿区有一辆专用校车通过教育、交警部门审核，市公安交警支队办理校车备案登记，申领校车标识的；大部分用于接送学生的车辆为非专用校车，都为私人租用车辆，没有安装GPS和监控设备，不能满足校车的安全技术要求，且车况不佳或未按要求统一喷涂标识，更有少数校车存在私自改装现象。
　　（四）校车驾驶员、跟车教师不具备相应资质，综合素质偏低。部分学校（幼儿园）跟车教师对自己的职责定位不清，没有认真履行相应的职责，大部分驾驶员平时兼跑其他业务，上放学时段接送学生；有的准驾年限未达三年及达到记分满分以上的驾驶员，其车辆仍被学校租用为校车。
　　（五）学校周边交通安全设施不健全。校门口占道摆摊设点，车辆随意变道行驶甚至逆行，车辆乱停放等问题较为严重；除城区学校门前公路上设有学校驻地、减速慢行交通标志、按照缓行黄闪灯和施画人行横道线等交通标识，交通比较齐全外，大部分农村学校门前公路上交通标识不完善。
　　（六）存在租用私人车辆和非法营运车辆接送学生现象，超载严重。用于接送学生车辆存在大量摩托车、自行车、小车还有部分拼装（私加动力）车、人力三轮车、面包车问题，主城区尤为严重，这些车辆超载现象比较突出。很多中小学接送学生的车辆都是学生家长租用的，由家长与车主签订协议；还有些个体车主一到上、放学时段或周末放假，就将车开到学校门口，私自接送学生。偏远山区采用农用车、拼装车接送学生的也很常见，这些车辆车况差，道路崎岖、路况复杂，驾驶员安全意识不强，超载现象特别严重。
　　（七）大量的无证办园，导致监管难度大。如荔城区2所小学没有办学资质，33所民办幼儿园只有3所幼儿园有办学资质，大部分属无证办园。这些接送幼儿的车辆个别是幼儿园自己购买的，大部分是临时租用的，车辆安全性能差，部分未贴校车标志，查处比较困难，存在很大的交通安全隐患。
　　（八）学生周末班车严重不足。由于本市交通运输的现状，学生周末班车到目前还无法开通，无法满足周末学生乘坐的要求，许多学生只能滞留在学校或是挤上其他运行车辆甚至农用车、摩的回家，特别是山区偏远的学校尤为严重。
　　三、下一步工作建议
　　（一）进一步明确各部门对校车的安全监管职责。各级政府、部门要制定出台校车安全管理的相关文件，尽快明确校车道路交通安全牵头责任单位及执法主体单位，明确成员单位的职责，确保各负其责，各司其职，相互配合，形成合力，真正把校车安全管理工作落到实处。
　　（二）进一步加大打击处理力度。公安交警部门和交通管理部门要严把参与接送学生车辆的资质条件，严格与其他车辆的管理区分开，依法查处非法校车和校车驾驶员的交通违法行为；对手续不全车辆、报废车、拼装车、农用车、三轮车等接送学生车辆进行查扣没收，不准上路，坚决杜绝上述车辆上路接送学生。同时对校车超载行为进行专项整治，严厉打击超载行为。
　　（三）进一步加强对无证办园的整治工作。各级政府要依据管理体制督促民办幼儿园改善办园条件，尽快达到办园标准，成为合规合法办学机构；要坚决取缔少数办园条件差，无视各部门监管的幼儿园；教育部门要合理妥善分流就读幼儿，确保幼儿健康成长，促进幼儿教育健康发展，同时要把接送学生车辆及校车安全管理工作作为衡量学校办学水平和管理水平的重要指标，实现安全工作的有效监管
　　（四）进一步加强交通安全宣传教育，切实增强中小学生和幼儿交通安全意识。各级政府、各相关部门应充分发挥报刊、广播、电视、网站及新闻媒体等宣传舆论导向作用，大力宣传交通安全有关知识和法律法规，采取多种形式推进道路交通安全知识进校园、进课堂、进家庭活动；各级教育部门要发挥主导作用，对中小学（幼儿园）特别是民办幼儿园的法人、园长、相关工作人员进行具有针对性的教育培训，使他们能够牢固确立“安全责任重于泰山”的观念，认真贯彻落实各级有关接送学生车辆及校车安全会议文件精神，采取有效措施，扎扎实实地抓紧抓好，抓出成效。
　　（五）进一步建立长效工作机制。各级政府、各相关部门要建立健全“政府统一领导，部门责任明确，各方齐抓共管”的工作机制，加强部门之间的协作，共同研究解决工作中的实际问题。由各级政府牵头，制定校车管理的相关政策规定；具有营运资质的运输单位或公司出资，安排专门用于接送学生上下学的校车；工商、税务、物价、运管等职能部门落实好校车相关税费减免补贴等扶持政策，降低校车运营成本，减轻农村学生家庭经济负担；交警、教育、交通等部门确定校车的行驶路线及学校、村庄站点的设置和校车资质的审核；交通和教育部门积极与客运企业联系协调，增加周末班车次数，解决寄宿制学校学生周末回家、返校乘车及交通安全问题。
　　（六）进一步完善学校周边交通设施。各级政府、各相关部门要加强协调，进一步加大对辖区学校、幼儿园门口的交通安全配套设施的投入力度，落实相关的交通安全配套设施，不断完善交通安全岗、警示标志、减速路面、斑马线等硬件保障设施；定期清除校园周边各类摊贩，进一步改善学校周边的交通安全环境，确保学生出行安全。
　　（七）进一步统一接送学生车辆的标识标记。相关部门应尽快统一专用校车外观标识和非专用校车标牌。对于登记机动车所有人为学校或幼儿园用于专门接送中小学生、幼儿上下学的车辆，或学校、幼儿园租用专门用于接送中小学生、幼儿上下学的车辆，必须是载客类汽车，一律按专用校车进行管理，喷涂粘贴全市校车统一的外观标识。
　　（八）进一步强化责任追究制度。各级政府、各相关部门要强化落实安全责任制和责任追究制，对工作敷衍，措施落实不到位，工作被动，甚至发生中小学生伤亡交通事故的，按照责任事故倒查“四不放过”的原则，坚决追究相关人员和有关领导的责任，并在新闻媒体予以曝光。

莆田市人民政府办公室       
　　　二O一二年一月五日
