莆田市人民政府办公室关于印发莆田市生态环境监测网络建设实施方案的通知

莆政办〔2016〕134号
来源:市府办 时间：2016-09-12 11:08
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　经市政府同意，现将《莆田市生态环境监测网络建设实施方案》印发给你们，请认真贯彻执行。

 

　　莆田市人民政府办公室               

　　2016年8月2日               

 

莆田市生态环境监测网络建设实施方案

　　生态环境监测是生态环境保护的基础，是生态文明建设的重要支撑。为贯彻落实《国务院办公厅关于印发〈生态环境监测网络建设方案〉的通知》（国办发〔2015〕56号）、《省政府办公厅关于印发<福建省生态环境监测网络建设工作方案>的通知》（闽政办〔2016〕15 号）精神，加快推进我市生态环境监测网络建设，结合我市实际，制定本实施方案。

　　一、总体要求

　　全面落实中央、省委、省政府关于加快推进生态文明建设的决策部署，围绕“全面设点、全市联网、自动预警、依法追责”的总体要求，组织建立政府主导、部门协同、社会参与、公众监督的生态环境监测监管体系，为加快推进我市生态文明先行示范区建设提供有力保障。到2020年，全市基本实现生态环境、重点污染源以及生态保护红线管控区的监测点位全覆盖；依托省生态环境监测大数据平台和市政务信息共享交换平台，构建信息统一发布的市生态环境信息管理与服务平台；进一步健全完善全市生态环境监测制度和测管联动、部门分工合作等工作机制；提升监测预报预警、信息化能力和保障水平；基本形成陆海统筹、天地一体、上下协同、信息共享的生态环境监测网络+互联网体系，使生态环境监测能力与生态文明建设要求相适应，为建设“美丽莆田”、“宜居莆田”提供有力的技术支撑。

　　二、建设覆盖全市、布局合理、功能明确、事权明晰的生态环境监测网络

　　（一）统一规划全市生态环境监测网络。由市环保局牵头，财政、水利、海洋与渔业、国土、农业、林业和气象等部门按各自职能分工和监管需要，在各自重点监管区域以及重要生态功能区、生态红线管控区和其它需要特别保护的生态环境区域规划布设监测（观测）点位，建设涵盖大气、水、土壤、噪声、生物、辐射等生态环境要素，覆盖全市、布局合理、功能明确、事权明晰的全市生态环境监测网络，按照统一的规范标准开展监测和评价，客观、准确反映环境质量状况。

　　1.环保部门负责在木兰溪、萩芦溪等主要流域，东圳、外度、古洋水库等乡镇级以上集中式饮用水水源地，以及重要湖泊水库、近岸海域等区域布设大气、水、噪声、土壤、辐射、农村生态环境等监测点位，开展生态环境质量评估与考核监测。

　　（1）结合我市城乡一体化建设要求，在城区5个国控环境空气自动监测站，以及已新增东庄镇、东埔镇、枫亭镇、仙游城区4个市控空气自动监测站的基础上，2016年至2017年计划新建江口镇、黄石镇、华亭镇、榜头镇、西天尾镇5个市控空气自动监测站；实施完善城区、重点集镇、主要工业园区环境空气质量监测与预报预警，开展大气降水监测和环境空气源解析工作，以及与大气环境相关的生态指标评估与考核。

　　（2）在全市主要流域、集中式饮用水水源地、重要湖泊水库、城市内河、近岸海域、入海河流等区域布设监测点位，建立和实施木兰溪和萩芦溪“两溪”流域环境监测体系、饮用水水源地监测体系、内河水环境监测体系、近岸海域环境监测体系，开展小流域水质监测，以及与水环境相关的生态指标评估与考核。

　　（3）在耕地、重点饮用水水源地、污染场地等区域布设监测点位，建立和实施土壤环境监测体系，开展污染土壤修复，以及与土壤环境相关的生态环境质量评估与考核。

　　（4）根据不同县（区）农村经济、社会、地理等区域差异，以及农业生产环境和农村生活环境特点，开展农村生态环境监测，重点监测农村村庄环境空气质量、饮用水水源地水质、农田土壤环境质量以及农村区域地表水水质。

　　（5）依据功能区环境噪声普查数据和城市环境噪声功能区分布特征,对全市原有声环境功能区划进行重新调整完善，建立和实施声环境监测体系，开展功能区噪声、道路交通噪声、区域环境噪声监测。

　　（6）在核与辐射重点项目周边陆域及海域、城市建成区、重点流域、重要集中式饮用水源地等区域布设监测点位，建立和实施辐射环境监测体系，开展空气、土壤、地表水、地下水、海水、生物等环境要素的辐射环境质量监测。

　　2.财政部门负责保障全市生态环境监测网络建设经费。

　　3.水利部门负责在水利自然保护区、重要水文地质单位等特定监管区域布设水环境质量和水文监测点位，建立和实施水质与水文监测体系，开展水功能区水质与水文、水土流失面积等与水环境相关的生态指标评估与考核监测。

　　4.海洋与渔业部门负责在近岸海域、主要海湾、海洋生态敏感区、海洋保护区、重点渔业水域以及重点海洋排污区域等重要海洋功能区布设监测点位，建立和实施海洋环境监测体系，开展海洋水环境质量、自然岸线保有率等监测，以及与海洋环境相关的生态指标评估与考核监测。

　　5.国土部门负责在重要水文地质单位、地下水污染高风险区、自然地质环境敏感区等特定监管区域布设监测点位，建立和实施地下水环境监测体系，开展地下水环境质量、地质环境等相关生态环境质量指标评估与考核监测。

　　6.农业部门负责在农产品产地等区域布设监测点位，建立和实施农产品产地土壤环境监测体系，开展与土壤相关的生态环境质量指标评估与考核监测。

　　7.林业部门负责在林地和森林、林业自然保护区、重要湿地、森林公园、农村地区、县以上城市建成区等区域布设监测点位，建立和实施森林环境监测体系，开展林地保有量、森林覆盖率、森林蓄积量、湿地保有量、森林生态服务功能、林业禁止开发区域等相关生态环境指标评估与考核监测。

　　8.气象部门负责在区域环境空气质量监测站点增设空气质量预报预警所需特定气象要素观测点，实施空气质量气象要素监测体系；配合环保部门开展空气质量预测预报。

　　实施生态环境监测的各级各部门，可结合各自工作需要和本区域本部门对生态环境质量评估与考核要求，拓展监管区域，增设监测点位，进一步完善全市生态环境监测网络，在“十三五”期间实现监管区域和监测点位的全覆盖。

　　（二）实施重点污染源监测制度。环保和农业等部门要按照各自职责分工和生态环境监管要求，落实分级管理制度，加强对工业污染源、直排海污染源、畜禽养殖、农村面源污染、生活污染源以及核与辐射重点项目的监督性监测，建立和实施重点污染源监督性监测体系，为生态环境管理提供技术保障。严格落实重点排污单位自行监测及信息公开制度，省控以上重点监控企业等重点污染源应全面安装污染物排放在线监测系统。

　　（三）实施重点生态保护红线管控区监测。环保、水利、海洋与渔业、国土、农业、林业等部门根据职责分工，通过对地观测、地面生态监测和发展无人机遥感监测等手段，实施对重要生态功能区、生态敏感区和脆弱区及各级政府确定的重点保护区域和禁止开发区域的生态监测与评估。同时，加强生物多样性、重要湿地、水源涵养区、水土流失重点治理区、自然与人文景观、生态公益林、沿海基干林带、集中式饮用水水源地等陆域生态保护红线管控区以及重要河口、特殊保护岛屿、海洋保护区、重要渔业水域等海域生态保护红线管控区的生态环境监测和评估。

　　三、构建全市生态环境信息管理与服务平台,实现生态环境监测信息全市联网、集成共享、统一发布

　　（一）构建全市统一的生态环境信息管理与服务平台。整合各级各部门现有监测终端，进一步完善各类监测数据采集网络，优化监测数据采集流程。市环保局牵头会同市直有关部门，依照统一监测规划提出建设需求，通过整合各类生态环境监测资源，依托省生态环境监测大数据平台和市政务信息共享交换平台，研究制定生态环境监测信息发布目录和发布机制，在2017年底前，完成全市生态环境信息管理与服务平台建设。市数字办负责技术指导和资源保障，协调数据汇聚。平台通过开放数据接口，为各级各部门开展创新应用提供更完整、标准化、高质量的数据供给；通过大数据综合分析，提升预测预警能力；通过政府购买服务，委托第三方运行维护，提升平台运行维护的专业化水平。

　　（二）建立生态环境监测数据汇聚共享机制。依托全市生态环境信息管理与服务平台，构建市、县（区）两级生态环境监测数据有效汇聚和互联共享机制，并与省生态环境监测大数据平台对接。市、县（区）两级环保、水利、海洋与渔业、国土、农业、林业和气象等部门，在2016年底前，建立和实施本部门的监测体系；在2017年底前，将所获取的生态环境质量、污染源、生态状况监测数据统一上传至全市生态环境信息管理与服务平台，实现全市生态环境监测信息高速汇聚、统一集成和共享应用，到2017年底实现全市环境监测数据“一网一库一平台”。

　　（三）统一发布生态环境监测信息。参照省政府将制定出台的生态环境监测信息发布目录和发布机制，通过市生态环境信息管理与服务平台、政府数据开发平台或其他法定形式，依法确定应对公众统一发布的生态环境监测信息公开事项和开放数据目录，建立统一的生态环境监测信息发布机制和工作要求，规范发布内容、流程、权限和渠道等。各县（区）政府（管委会）可参照制定。

　　四、加强自动监控、提升预报预警与环境风险防范能力

　　（一）实施生态环境质量监测预报预警。环保、水利、海洋与渔业、国土、农业、林业和气象等部门要完善生态环境质量预报预警机制，建立和实施环境空气质量和水环境质量自动监测系统体系，实施对责任管控区域和重点监管对象的大气、水、土壤等生态环境风险的监测、评估与预警。要建立部门联合会商机制，加强监测信息汇聚共享与技术协作，利用大数据技术实现环境风险联合预警和管控，提高预警信息可信度和反应速度。

　　（二）强化重点监管对象自动监控。环保和水利等部门应按照各自职责分工，进一步加强重点区域、化工园区、重点污染源、核与辐射重点项目自动监测站建设和可视化监控系统建设。主要流域、重要集中式饮用水水源地、重点湖库等重要生态功能区可由多部门联合设立多参数多功能的自动监测站点，在“十三五”期间完成全市大气、水环境自动监测全覆盖。完善重点污染源在线监测数据异常报警机制，提高污染物超标排放、在线监测设备运行异常等信息报警与处置能力。

　　（三）提升生态环境质量风险监测评估与预警能力。环保、水利、海洋与渔业、国土、农业和林业等部门要定期开展全市生态环境状况调查与评估，建立生态保护红线监管平台，对重要生态功能区人类干扰、生态破坏等活动进行监测、评估与预警。增强工业园区环境风险预警、防控与处置能力。开展生态环境现状与风险评估技术方法科研和学术交流，完善环境风险源数据库和专家库，提高环境风险防控能力。各级各部门要建立和实施生态环境应急监测体系，推进应急监测能力建设，加强应急物质储备，提升生态环境突发事件应急监测能力。

　　五、构建考核问责、测管联动、监管规范的生态环境监测机制

　　（一）为生态文明建设考核问责提供技术支撑。市直各有关部门要按各自职责分工，完善全市生态环境监测与评估指标体系，组织开展监测与评估，充分运用监测和评估结果，为党政领导生态环境保护目标责任书考核及领导干部自然资源资产离任审计提供科学依据和技术支撑。

　　（二）实施生态环境同步监测与执法。各级各部门要建立监测与监管联合执法机制，对重要生态功能区实施常态化现场同步监测与执法，对超标排放、伪造数据等违法行为现场监测、直接依法查处。建立监测监管联动快速响应机制，加大对生态环境监测数据异常区域的监测与执法频次，根据异常监测数据和自动报警信息，及时开展同步监管执法。

　　（三）加强各类生态环境监测机构监管。市直各有关部门所属生态环境监测机构要严格执行国家统一的环境监测法律、法规、技术规范和标准，健全并落实监测数据质量控制与管理制度，并对监测数据的真实性和准确性负责。各级环保部门要加大监测质量核查力度，严肃查处故意违反环境监测技术规范的行为，对篡改、伪造监测数据的监测机构，上报省质监局依法取消监测机构资质。党政领导干部指使篡改、伪造监测数据的，按照《党政领导干部生态环境损害责任追究办法（试行）》等有关规定严肃处理。市环保局负责对环境自动监测设备日常运行维护机构实施监管，督促运维机构严格按照运行维护合同运营并对监测数据承担责任；对监测数据弄虚作假的机构，按照《环境监测数据弄虚作假行为判定及处理办法》有关规定，予以严肃查处。

　　六、实施生态环境监测体制改革，构建科学有力的保障体系

　　（一）积极培育生态环境监测市场。放开服务性监测市场，鼓励社会环境监测机构参与各相关领域的生态环境监测活动。在环境自动监测站运行维护、重要生态功能区生态状况评估等基础公益性生态环境监测领域，积极推进政府购买服务。推动成立环境监测服务行业协会，构建行业自律体系，维护监测服务市场秩序、保持公平竞争、促进行业健康发展。

　　（二）提升生态监测科技创新能力。推进生态环境监测新技术和新方法研究，深入开展生态环境监测、评估和预警科研创新，借鉴监测科技先进经验，提升我市技术创新能力。

　　（三）加强生态环境监测综合能力建设。加强各领域生态环境监测队伍建设，建立健全人员培训制度，不断提高监测人员综合素质和能力水平。完善与生态环境监测网络发展需求相适应的财政保障机制，各级政府要加大对生态环境监测等基础能力建设的投入力度，完善环境保护监测岗位津贴政策，将所需建设运行经费纳入各级财政当年度预算予以保障。持续推进生态环境监测能力建设，重点加强各级各部门生态环境监测站点标准化建设、自动监测与预报预警、对地观测、发展无人机遥感监测、监测数据质量控制、环境应急监测和大数据分析、共享、应用等能力建设。

　　各县（区）人民政府（管委会）、市直有关单位要加强对生态环境监测网络建设的组织领导，制定具体工作方案，明确职责分工，确保各项工作任务落到实处。
