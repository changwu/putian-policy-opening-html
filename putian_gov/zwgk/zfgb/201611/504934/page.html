莆田市人民政府办公室关于印发莆田市家政服务业补短板实施方案的通知

莆政办〔2016〕151号
来源:市府办 时间：2016-10-10 11:19
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　为鼓励和支持我市家政服务业快速健康发展，经市政府研究同意，现将《莆田市家政服务业补短板实施方案》印发给你们，请认真贯彻落实。

 

　　莆田市人民政府办公室               

　　2016年9月14日               

 

莆田市家政服务业补短板实施方案

　　一、总体要求

　　为鼓励和支持我市家政服务业快速健康发展，以满足日益提升的群众需求。坚持“市场运作与政府引导相结合、突出重点与全面发展相结合、政策扶持与规范管理相结合”的原则，健全完善家政服务业发展政策，推动形成多层次、多形式发展的家政服务市场和经营机构，进一步增加服务有效供给、扩大服务消费需求、提升服务质量水平，促进家政服务业标准化、职业化、连锁化发展。根据《省政府办公厅关于印发家政服务业补短板实施方案的通知》（闽政办〔2016〕40 号）的规定和要求，结合我市实际，制定本实施方案。

　　二、主要任务

　　（一）培育家政服务龙头企业，推动企业上规模。鼓励家政服务企业引进先进服务业态、经营技术和管理经验，提高服务运作和经营管理水平。全市选取11家企业重点扶持培育，城厢区4家、荔城区3家，仙游县、涵江区、秀屿区、北岸各1家，要求各县（区）政府（管委会）采取措施，重点服务、重点扶持，从中培育规上服务业企业。

　　责任单位：各县（区）政府（管委会），市商务局、人社局、工商局、妇联

　　（二）打造示范性家政服务站。支持家政企业在有条件的街道、社区按照标准创建示范性家政服务站，全市拟创建7个市级示范家政服务站，城厢区、荔城区各2家，仙游县、涵江区、秀屿区各1家，对符合条件的示范性家政服务站给予重点服务和扶持。通过示范性家庭服务站，探索“准员工制”管理模式，明确雇主、雇员和经营者三方的权利和义务，引导服务机构对从业人员在身份验证、体检、签约、购买商业保险、上岗培训和服务回访等方面进行管理。

　　责任单位：各县（区）政府（管委会），市商务局、财政局、人社局、民政局、妇联

　　（三）促进家政服务业线上线下融合。支持家政服务业与互联网深度融合，依托已有电商平台或建立自有服务平台开展线上线下服务，不断提高电子商务应用水平。积极拓展服务内容和覆盖面。推动家政服务业龙头企业牵头组建“莆田市家政服务行业协会”，建立互联网服务平台，集聚我市家政服务企业信息，通过平台推动企业及加盟企业的标准化、规范化发展。

　　责任单位：市商务局、工商局、财政局、妇联

　　（四）加大职业技能培训力度。加大家政从业人员培训力度，落实职业培训补贴政策，对参加家政培训取得相关证书的按规定给予职业培训补贴。充分发挥现有职业培训资源作用，鼓励社会力量和工会、共青团、妇联等组织依托所属职业培训机构积极开展家政服务培训。发挥妇女在家政服务工作中的独特作用，建立巾帼家政培训基地，对公益性的岗前培训工作给予一定经费补助。推行专业学历教育，鼓励高等教育和高、中等职业教育增设相关专业和课程，加快培养行业人才。

　　责任单位：市人社局、教育局、财政局、商务局、总工会、团市委、妇联

　　（五）推动家政服务标准化建设。加强家政服务业标准的研究，引导企业和行业协会积极参与国家标准、行业标准和地方标准的制修订活动，发挥行业协会的作用，加强行业自律，研究制定具有莆田特色的团体标准，先行先试，进一步规范和提高莆田家政服务业的标准化和现代化水平。加大对已出台国家标准、行业标准的宣传力度，积极探索指导督促企业执行标准的有效途径和办法，扩大标准的影响面；选择基础较好、积极性高的企业开展家政服务标准化试点示范建设工作，不断提高行业规范化建设水平。按照新出台的国家标准《家政服务机构等级划分及评定》要求，开展家政服务机构等级划分及评定工作，不断提高行业规范化建设水平。

　　责任单位：市商务局、质监局、妇联

　　（六）加强行业诚信建设。大力开展行业职业道德教育、诚信教育，形成供需各方相互依赖、安全可靠的市场环境。推动家政服务机构和从业人员对接福建省家政诚信服务管理平台，力争在省家政诚信服务管理平台录入的从业人员达2000人。推广诚信服务卡的应用，引导消费者通过诚信服务卡了解从业人员相关信息，并对从业人员服务作出评价，不断推进家政服务行业诚信体系建设。

　　责任单位：市商务局、人社局、妇联

　　三、组织保障

　　（一）完善协调机制。建立促进家政服务业发展联席会议制度，联席会议成员单位由市商务局、发改委、民政局、财政局、人社局、地税局、工商局、质监局、统计局、金融办、总工会、团市委、妇联，人行莆田市中心支行组成，市商务局为召集人。通过联席会议加强部门协调配合，建立信息共享和情况交流机制，定期通报工作进展情况，分析工作中遇到的问题，研究提出解决办法。

　　责任单位：市商务局、发改委、民政局、财政局、人社局、地税局、工商局、质监局、统计局、金融办、总工会、团市委、妇联，人行莆田市中心支行

　　（二）加大资金扶持。各级各有关部门要将家政服务业作为促进现代服务业发展的支持重点，进一步加大资金支持力度。市级和各县（区）用于社会事业和民生工程的资金要将发展家政服务业纳入扶持范围。落实国家和省政府已明确的扶持家政企业发展的各项税收优惠政策和就业扶持政策。引导银行业机构有效对接家政服务业的融资需求，创新金融产品，进一步增加有效信贷投放。鼓励商业保险机构开发推行家政服务机构职业责任险、人身意外伤害保险等家政服务保险产品，防范和化解风险。针对家政服务机构为从业人员购买家政服务保险产品的，按照一定比例给予保费补贴。所需经费列入各级扶持第三产业专项资金统筹安排。由商务局提出具体资金安排和管理办法。

　　责任单位：各县（区）政府（管委会），市财政局、商务局、人社局、地税局、金融办，人行莆田市中心支行

　　（三）加强基础工作。加强莆田市家政服务行业协会建设，充分发挥行业协会在服务、协调、维权、规范和指导行业发展方面的作用。对在加强行业自律、促进行业发展、配合政府部门工作等方面表现较为突出的行业商协会给予奖励。研究建立家政服务业统计调查制度，增加经费投入，规范统计标准，完善统计调查方法和指标体系，提高统计调查的准确性和及时性，为相关决策提供服务。

　　责任单位：市民政局、商务局、统计局、财政局、妇联、工商局

　　（四）营造良好氛围。有关部门按照政务公开的要求，通过网站、新闻发布会、记者采访等形式，及时主动发布工作信息，准确解读政策措施。新闻宣传部门要积极引导舆论，加大正面宣传，组织各类媒体利用现有栏目或开设专栏，加大对家政服务业补短板工作的报道。积极开展家政服务职业技能竞赛、诚信服务机构评选、明星服务员评选等活动，展示家政服务行业的价值和风采，不断提高社会对家政服务业的认同度，增加从业人员的自豪感。　

　　责任单位：市商务局、人社局、总工会、团市委、妇联
