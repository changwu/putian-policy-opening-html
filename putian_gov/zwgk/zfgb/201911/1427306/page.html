莆田市人民政府办公室关于印发莆田市职业技能提升行动实施方案（2019-2021年）的通知

莆政办〔2019〕79号
来源:市府办 时间：2019-11-18 14:56
| | | |

各县（区）人民政府（管委会），市人民政府各部门，各直属机构：

　　《莆田市职业技能提升行动实施方案（2019-2021年）》已经市政府研究同意，现印发给你们，请认真贯彻执行。

 

　　莆田市人民政府办公室               

　　2019年11月12日               

 

莆田市职业技能提升行动实施方案

（2019-2021年）

　　为贯彻落实《福建省人民政府办公厅关于印发福建省职业技能提升行动实施方案（2019-2021年）的通知》（闽政办〔2019〕42号）精神，结合我市实际，制定本实施方案。

　　一、目标任务

　　以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中全会精神，深入贯彻落实习近平总书记对福建工作的重要批示指示精神，大力推行终身职业技能培训制度，发挥企业主体作用，职业院校（含技工院校，下同）基础作用，社会机构支持作用，面向职工、就业重点群体、建档立卡贫困劳动力（以下简称贫困劳动力）等各类劳动者，大规模开展职业技能培训，加快建设知识型、技能型、创新型劳动者大军。

　　2019年至2021年，实施十项职业技能提升工程，每年开展各类补贴性职业技能培训2万人次以上，三年共培训6万人次以上。

　　二、实施职业技能提升工程

　　面向职工、就业重点群体、建档立卡贫困劳动力等城乡各类劳动者，大规模开展职业技能培训，着力实施十项职业技能提升工程。强化职业技能、通用职业素质和求职能力等综合性培训，将职业道德、职业规范、质量意识、消防安全等相关法律法规、安全环保和健康卫生、消防知识、就业指导等内容贯穿职业技能培训全过程。

　　（一）大力开展企业职工技能培训。发挥企业的培训主体作用，落实企业培训主体责任。各类企业要制定职工培训计划，开展岗前培训、在岗培训、脱产培训、岗位练兵、技能竞赛、在线学习等活动，大力开展高技能人才培训。发挥龙头企业、规模以上企业和行业组织的作用，引导帮助中小微企业开展职工培训。每年开展企业职工补贴性培训不少于8000人次，3年开展补贴性培训25000人次以上。实施鞋业从业人员技能提升工程，发挥市鞋业行业协会和产业创新联盟的作用，引导鞋业产业链龙头企业、核心企业、“两高”和创新型企业建立职工培训中心，开展鞋业从业人员技能提升培训，培育符合鞋业发展需要的实用型技能、技术人才。每年开展鞋业从业人员补贴性培训不少于1000人次，3年开展补贴性培训3000人次以上。

　　责任单位：市工信局、国资委、总工会、人社局、财政局、教育局等，各县（区）人民政府（管委会）

　　（二）实施高危行业领域安全技能提升工程。开展化工、矿山、金属冶炼、烟花爆竹等高危行业领域的企业全员安全技能培训，特别是企业经营者和新录用员工的安全技能培训及各类特种作业人员安全操作资格培训。严格执行从业人员安全技能培训合格后上岗制度，每年至少要组织开展一次从业人员和各类特种作业人员安全技能培训，确保高危行业企业从业人员的安全技能培训覆盖率达到100%。每年开展补贴性培训不少于5000人次，3年开展补贴性培训15000人次以上。

　　责任单位：市应急管理局、工信局、人社局、住建局、交通运输局、市场监管局等，各县（区）人民政府（管委会）

　　（三）实施退役军人职业技能提升工程。组织实施退役军人全员适应性培训与就业创业技能培训，制定技能培训具体专业（工种）目录，鼓励退役军人参加职业技能鉴定并考取相关技能证书。鼓励用人单位和承训院校（机构）定期沟通衔接，探索建立退役军人定点培训基地，联合开展职业技能培训。引导退役军人积极参加职业技能培训，由我市负责接收的退役军人可选择接受一次免费（免学杂费、免住宿费、免技能鉴定费）培训，并按照规定享受培训期间生活补助。下岗失业退役军人，由本人申请，经失业登记后，市退役军人事务部门应积极推荐参加省退役军人承训机构所列项目的技能培训。每年开展补贴性培训不少于500人次，3年开展补贴性培训1500人次以上。

　　责任单位：市退役军人局、教育局、人社局，各县（区）人民政府（管委会）

　　（四）实施职业农民素质提升工程。围绕乡村振兴，鼓励和支持农业企业、农业园区、农民合作社等市场主体建立实训基地和农民田间学校，将新型农业经营主体带头人、现代青年农场主、农业职业经理人、农业社会化服务骨干和农业产业扶贫对象作为重点培育对象，以提升生产技能和经营管理水平为主要内容，培养更多爱农业、懂技术、善经营的新型职业农民。每年开展补贴性培训不少于3500人次，3年开展补贴性培训11000人次以上。

　　责任单位：市农业农村局、教育局，各县（区）人民政府（管委会）

　　（五）实施残疾人职业技能提升工程。围绕吸纳残疾人就业集中的产业行业，整合职业培训资源，依托各类职业教育培训机构，择优确定定点培训机构，建设残疾人职业培训基地。加强适合残疾人特点的盲人保健按摩、电子商务等领域技能培训，鼓励引导有就业愿望和培训需求、在法定劳动年龄内的残疾人接受相应职业培训，掌握就业技能，提升就业能力。每年开展补贴性培训不少于800人次，3年开展补贴性培训2400人次以上。

　　责任单位：市残联、人社局，各县（区）人民政府（管委会）

　　（六）实施电子商务和家政培训工程。进一步完善电子商务人才培育体系，支持行业协会、专业园区、电子商务培训机构或高职院校开展电子商务紧缺人才培训，每年由市商务局确定培训人员范围、人数，委托院校或培训机构开展公益性的电商实战培训。鼓励社会力量和工会、共青团、妇联等组织依托所属职业培训机构，组织实施“工会技能培训促就业行动”、“巾帼家政服务专项培训工程”等，积极开展家政企业职业经理人培训和家政服务人员培训。发挥妇女在家政服务工作中的独特作用，建立巾帼家政培训基地。每年开展补贴性培训不少于6000人次，3年开展补贴性培训18000人次以上。

　　责任单位：市商务局、总工会、团市委、妇联、人社局，各县（区）人民政府（管委会）

　　（七）实施养老服务队伍建设工程。通过集中培训、送教上门、轮岗轮训、以赛代练等方式，开展养老护理员培训，提升护理员职业技能水平。积极探索养老服务实训基地建设，开展养老服务从业人员职业培训。加强对养老服务机构负责人、管理人员的岗前培训及定期培训，使其掌握养老服务法律法规、政策和标准。鼓励各类院校特别是职业院校设置养老服务相关专业或开设相关课程，在普通高校开设健康服务与管理、中医养生学、中医康复学等相关专业。推进职业院校养老服务实训基地建设。每年开展补贴性培训不少于1000人次，3年开展补贴性培训3000人次以上。

　　责任单位：市民政局、教育局、人社局、卫健委，各县（区）人民政府（管委会）

　　（八）实施农民工职业技能提升工程。大力开展“春潮行动”培训计划，面向农村转移就业劳动者开展就业技能培训、岗位技能提升培训和创业培训。开展农民工“求学圆梦”学历提升行动，通过优惠政策、学费资助等方式，帮助农民工特别是新生代农民工提升学历和技能。组织开展农村建筑工匠轮训，提升全市农村建筑工匠的知识和技能水平。每年开展补贴性培训不少于1000人次，3年开展补贴性培训3000人次以上。

　　责任单位：市人社局、教育局、农业农村局、住建局，各县（区）人民政府（管委会）

　　（九）大力推行现代学徒制和企业新型学徒制。在新兴产业和传统优势产业领域中，分批分阶段选择3－5家职业院校作为试点单位，推进产教融合和校企合作，推行“校企双制、工学一体”的培养模式，进一步创新企业技能人才培养模式，为莆田经济社会发展拓宽技能人才培养渠道。每年开展补贴性培训不少于500人次，3年开展补贴性培训1500人次以上。

　　责任单位：市教育局、人社局、工信局、商务局、工商联，各县（区）人民政府（管委会）

　　（十）实施贫困劳动力脱贫培训工程。开展“雨露计划”工作，脱贫攻坚期内每年按实对农村建档立卡贫困家庭中正在接受中等职业教育、高等职业教育和技工院校教育的子女进行补助，补助标准为每学年3000元。鼓励各地通过项目制购买服务和依托科技特派员培训等方式为贫困劳动力开展职业技能培训，在培训期间按规定通过就业补助资金给予生活费（含交通费，下同）补贴。支持中等职业学校积极招收贫困家庭学生入读，对贫困家庭学生按规定落实助学金和免学费等资助政策，优先安排勤工俭学、实习实训、推荐就业。脱贫攻坚期内每年开展补贴性培训不少于3000人次。

　　责任单位：市农业农村局、扶贫办、科技局、教育局、人社局，各县（区）人民政府（管委会）

　　三、提升职业培训供给能力

　　（一）构建企业职业培训体系。鼓励各类企业特别是龙头企业、规模以上企业等吸纳就业人数较多的企业设立职工培训中心，构建我市“一产业一基地、一龙头一中心”的职业培训体系。支持企业与职业（技工）院校共建实训中心、教学工厂；支持企业设立高技能人才培训基地和技能大师工作室，企业可通过职工教育经费提供相应的资金支持，政府按规定给予补助。支持高危企业集中的县（区、管委会）建设安全生产和技能实训基地。

　　责任单位：市工信局、国资委、教育局、人社局、总工会、财政局、应急管理局等，各县（区）人民政府（管委会）

　　（二）拓展职业院校扩大培训规模。注重发挥职业院校职业培训法定职责和作用，按要求开展职工继续教育人次绝对数不低于全日制在校生数的1.2倍。深化职业教育改革，加快推进产教融合发展，启动“学历证书+若干职业技能等级证书”制度试点工作。推广高职教育“二元制”培养模式改革试点经验，扩大面向企业在职员工的招生规模。推行职业院校开展培训的激励政策，学校培训工作量可按一定比例折算成全日制学生培养工作量，探索职业院校培训量与绩效工资总量增长挂钩，在核定绩效工资总量时，向承担职业技能培训工作的单位倾斜，允许职业院校将一定比例的培训收入纳入公用经费，一定比例的培训收入作为增量部分纳入绩效工资总额，并向承担职业技能培训工作的一线教师倾斜。全市职业院校每年开展补贴性培训不少于11000人次，3年开展补贴性培训34000人次以上。

　　责任单位：市教育局、人社局、财政局，各县（区）人民政府（管委会）

　　（三）加大职业培训社会化供给。鼓励社会力量举办职业培训机构，支持省内外有资质的职业培训机构设立分支机构和开展职业技能培训。对非营利性民办职业培训学校，在设置审批、土地划拨出让、规划建设、金融扶持、项目申报和奖励评定等方面，与公办学校同等对待，按规定落实税费减免政策。

　　责任单位：市人社局、发改委、教育局、民政局、自然资源局、住建局、退役军人局、市场监管局、金融办、税务局，各县（区）人民政府（管委会）

　　（四）提升职业培训承载能力。各地各部门要统筹职业技能培训资源，支持实训基地和企业、院校、培训机构的设施设备升级改造，加强产教融合实训基地和公共实训基地建设。加强师资队伍建设，职业院校和培训机构实行专兼职教师制度，可按规定自主招聘企业技能人才任教。创新培训方式，健全完善公共就业培训服务平台，推广“互联网＋职业培训”方式。深化职业技能培训工作“放管服”改革，各地各部门要对补贴性职业技能培训实施目录清单管理，公布培训项目和培训机构目录，健全培训补贴网上经办服务平台。各地各部门可采取公开招投标等方式购买培训服务和评价服务。完善培训档案管理和统计工作，开展技能培训的企业、院校、培训机构应建立健全职业技能培训人员档案管理制度，实施补贴性培训实名制信息管理。

　　责任单位：市人社局、教育局、工信局、商务局、国资委、民政局、应急管理局、卫健委、生态环境局、农业农村局、住建局、交通运输局、总工会、团市委、妇联，各县（区）人民政府（管委会）

　　四、加大职业培训政策支持

　　（一）落实职业培训补贴政策。在我市各级公共就业人才服务机构办理求职、失业、就业等实名制登记的城乡劳动者（含省内外来莆务工人员），参加培训后取得证书（职业资格证书、职业技能等级证书、专项职业能力证书、特种作业操作证书、培训合格证书等）的，按规定给予职业培训补贴。对贫困劳动力、就业困难人员、零就业家庭成员、“两后生”中的农村学员和城市低保家庭学员，在培训期间按规定给予生活费补贴。符合条件的企业职工参加岗前培训、安全技能培训、转岗转业培训或岗位技能提升培训，按规定给予职业培训补贴或参保职工技能提升补贴。职工参加企业新型学徒制培训的，给予企业每人每年4000元以上的职业培训补贴，由企业自主用于学徒培训工作。

　　责任单位：市人社局、财政局、教育局、农业农村局、国资委、应急管理局、退役军人局、残联，各县（区）人民政府（管委会）

　　（二）落实职业培训免费政策。支持各地各部门采取公开招标项目制培训方式，对退役军人、贫困家庭子女、贫困劳动力、“两后生”、农村转移就业劳动者、下岗失业人员和转岗职工、残疾人开展免费职业技能培训，所需资金实行全额支付。

　　责任单位：市人社局、财政局、教育局、农业农村局、国资委、应急管理局、退役军人局、残联，各县（区）人民政府（管委会）

　　（三）落实培训资金筹集使用政策。从失业保险基金、就业补助资金、地方人才经费、行业产业发展经费等多种渠道筹集培训资金。其中，提取的失业保险基金，在社会保障基金财政专户中单独建立“职业技能提升行动专账”，实行分账核算、专款专用，具体筹集使用办法按照省财政厅、省人社厅规定执行。市财政局会同市人社局根据培训任务指标把培训资金按一定比例预拨给市直各行业主管部门和各县区用于开展补贴性培训，市直各行业主管部门和各县区要统筹使用上级专项资金和市级预拨资金，按规定开展培训工作，补贴资金不足可向市财政局专项申请。各县（区）人民政府（管委会）可对有关部门各类培训资金和项目进行整合，解决资金渠道和使用管理分散问题。企业要按有关规定足额提取和使用职工教育经费，其中60%以上用于一线职工培训。落实企业职工教育经费税前扣除政策，企业发生的职工教育经费支出，不超过工资薪金总额8%的部分，准予在计算企业所得税应纳税所得额时扣除，超过部分准予在以后纳税年度结转扣除。

　　责任单位：市财政局、人社局、总工会,各县（区）人民政府（管委会）

　　（四）落实职业能力培训评价政策。完善技能人才职业资格评价、职业技能等级认定、专项职业能力考核等多元化评价方式。严格执行国家职业资格目录制度，准入类职业劳动者必须经培训合格后方可上岗。实施职业技能等级认定制度，支持符合条件的企业、院校和第三方评价机构按规定开展职业技能等级评价。支持工程领域高技能人才与专业技术人才发展贯通，符合条件可互通申报职称和职业技能资格（等级）。支持用人单位特别是国有企业建立职业技能提升与岗位聘用、待遇落实挂钩机制。

　　责任单位：市人社局，市相关行业主管部门，各县（区）人民政府（管委会）

　　五、加强组织保障

　　（一）强化组织领导。在市就业工作领导小组框架下，健全工作协调机制，充分发挥行业主管部门等各方作用。人社部门承担政策制定、职业标准实施、培训机构管理、质量监管、任务分解等职责，并承担就业工作领导小组办公室日常工作。发改部门负责协调推进职业技能培训基础能力建设。教育部门负责组织职业院校承担职业技能培训任务。国资监管部门负责组织国企开展职业技能培训。财政部门要确保就业补助资金等及时足额拨付到位。十项职业技能提升工程排第一位的责任部门，要牵头制定具体实施方案，细化工作措施；相关责任部门要积极配合，分工协作，形成工作合力，共同推进职业技能提升行动。各有关部门要大力开展平台从业人员、托幼、保安等职业技能培训。支持鼓励工会、共青团、妇联等群团组织以及行业协会参与职业技能培训工作。各县（区）人民政府（管委会）要切实承担主体责任，抓紧制定具体贯彻落实措施，明确目标任务，压实工作责任，用好财政补助资金，扩大培训规模，提升培训质量，确保职业技能提升行动有效开展。

　　责任单位：市就业工作领导小组成员单位，各县（区）人民政府（管委会）

　　（二）强化政策宣传。各地各有关部门要加大政策宣传力度，提高企业、培训机构和劳动者的知晓度，用足用好政策，大力推进职业技能培训工作。

　　责任单位：市就业工作领导小组成员单位，各县（区）人民政府（管委会）

　　（三）强化资金监管。资金使用部门要定期向社会公开资金使用情况，有关部门要加强监督检查和专项审计工作，加强廉政风险防控，保障资金安全和效益，对以虚假培训等套取、骗取资金的依法依纪严惩。对培训工作中出现的失误和问题要区分不同情况对待，保护工作落实层面干事担当的积极性。

　　责任单位：市审计局、财政局、人社局，各县（区）人民政府（管委会）

　　（四）强化目标管理。建立职业技能提升行动工作情况月报制度。各县（区）人民政府（管委会）和市直各有关部门每月2日前应报送上月技能提升行动工作进展情况和《莆田市职业培训补贴资金使用情况统计表》（附件2）一式两份分别报送市人社局和市财政局。

　　责任单位：市就业工作领导小组成员单位，各县（区）人民政府（管委会）

　　附件：1.2019年职业技能提升行动分县（区）培训计划
