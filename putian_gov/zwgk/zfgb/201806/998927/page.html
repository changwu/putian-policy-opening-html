莆田市人民政府办公室关于印发2011年莆田市小城镇建设改革发展战役实施方案的通知

莆政办〔2011〕41号
来源:市府办 时间：2011-04-26 10:52
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　为了加快推进我市2011年小城镇建设改革发展战役工作步伐，经市政府研究同意，现将《2011年莆田市小城镇建设改革发展战役实施方案》印发给你们，请认真贯彻执行。

 

　　二○一一年三月三日               

 

2011年莆田市小城镇建设改革发展战役实施方案

　　为贯彻落实市委、市政府提出的“大干开局之年，奋战365天，全力打好五大战役，全力落实项目攻坚”的决策部署，更好地推进小城镇建设改革发展战役，推动莆田“跨越发展、宜居港城”发展战略的实施，根据《福建省人民政府办公厅转发省发展改革委、住房和城乡建设厅、国土资源厅关于2011年小城镇改革发展战役实施方案的通知》(闽政办〔2011〕22号)，结合我市的实际，特制定以下实施方案。

　　一、总体要求。深入贯彻落实科学发展观，以加快转变经济发展方式为主线，围绕“超千争百促跨越”的目标任务，把小城镇建设改革发展作为推动莆田跨越发展的重要抓手，作为统筹城乡发展、转变经济发展方式的有效载体。在继续抓好西天尾、江口等2个第一批省级试点镇的基础上，扎实做好枫亭、埭头等2个第二批省级试点镇的启动工作，同步推进榜头、北高、华亭、萩芦、山亭等5个市级试点镇建设步伐，力求步子更大，水平更高，成效更实。在年底前，力争第一批省级试点镇宜居城市综合体的主骨架基本形成，其它7个试点镇小城镇建设取得阶段性明显成效。

　　二、目标任务

　　（一）高起点做好规划设计。一是深化规划编制。第一批省级试点镇要在第一季度全面完成主要专项规划和近期建设用地控制性详细规划审查和审批工作。其它7个试点镇要加快规划编制，上半年完成总体规划和公共服务设施、道路工程、给水排水、电力通讯、绿地系统等主要专项规划工作，第三季度完成重要地段和节点地区城市设计成果，年底前完成启动区及近期建设用地控制性详细规划，同时建成规划展示厅。二是开展城市设计。各试点镇要选择高水平、有经验、负责任的设计队伍，引导和督促他们在设计深度、设计优化、设计特色上下功夫。第一批试点镇要在第一季度之前完成城市设计。其他试点镇要根据规划要求，做好城镇出入口、干道沿线、重要交叉口、滨水地段、商贸街区、广场等的城市设计。规模大的综合性项目，重要的公共建筑、园林景观项目，规模大的安置房小区以及景观综合整治项目，要聘请高水平的建筑、景观、园林专家做好设计，提高项目的设计水平，确保建设项目上档次、高质量。三是强化规划设计管理。严格执行规划“绿线、黄线、紫线、蓝线”四线管理制度。抓绿线管理，提高绿化指标；抓黄线管理，明确控制界线；抓紫线管理，保护历史遗存；抓蓝线管理，做到“显山露水”。实行严格规范的论证、审查机制，试点镇专项规划和近期建设用地控制性详细规划，由市规划局组织审查论证；修建性详细规划、城市设计及主要街道整治方案，由市规划局和试点镇所在县（区、管委会）规划建设主管部门以及试点镇联合组织审查。同时要禁止在建设过程中随意更改规划设计方案。（责任单位：市规划局、国土资源局、相关县区管委会，各试点镇）。

　　（二）快节奏推进项目建设。一是加快基础设施建设。西天尾、江口要基本形成宜居城市综合体的主骨架，镇区人均道路面积达到14.5平方米以上；其它7个试点镇年底前要有看得见的新地标、新面貌，镇区人均道路面积达到14平方米以上。重点抓好过境路、主要街道、镇区出入口、停车场的建设，以及沿河两侧的道路、滨河绿地及景观建设。二是提高公共服务配套水平。建成一批教育、文化、卫生、体育以及供水、排水、供气、公交、公厕等公共服务设施，大幅度提升小城镇综合承载能力和服务功能。三是强化产业支撑。各试点镇要从各自实际出发，明确产业发展重点，突出特色。全面推进项目建设，全年实施项目数324个以上，总投资超过1023.2亿元，确保年内完成投资超过129.9亿元。其中，西天尾、江口全年实施项目数分别超过55个、32个，总投资超过94.2亿元、118.1亿元，确保年内完成投资超过27.2亿元、10.6亿元；枫亭、埭头实施项目数分别超过81个、14个，总投资超过85.2亿元、18亿元，确保年内完成投资超过16亿元、9.8亿元；5个市级试点镇实施项目数超过142个，总投资超过707.7亿元，确保年内完成投资超过66.3亿。第二批省级及市级试点镇年底前至少要引进2家以上有实力、具有较大规模的企业投资兴业。各试点镇实施的重点项目要在第一季度全面推开，实现“开门红”，确保完成投资任务（责任单位：市发展改革委、市住房和城乡建设局、市经贸委、市交通运输局、市教育局、市文化广电新闻出版局、市卫生局、市体育局、相关县区管委会，各试点镇）。

　　（三）下决心实施综合整治。一是镇容镇貌整治。第一批省级试点镇要在去年完成一条以上主要街道景观综合整治的基础上，今年再实施一条以上主要街道的景观综合整治。第二批省级及市级试点镇要尽快确定一条主要街道开展景观综合整治，对影响城镇景观沿街建筑进行立面改造、平屋顶“平改坡”改造，完善路面及人行道铺装，拆围透绿增加绿化。要推进所有试点镇主要街道架空缆线下地，对规划区内的所有建设项目实施全程监管，规划区内一律停止办理零星个人建房审批。要将新建成的住宅小区、公共建筑等项目打造成试点镇的新地标。二是污水垃圾处理设施建设。第一批省级试点镇中已启动污水、垃圾处理设施建设的，要加快建设进度，今年底前建成并投入使用；正在开展前期工作的，要加快项目审批，年底前要开工建设。其它7个试点镇要积极开展项目前期工作，确保在今年底前完成项目审批，争取开工建设。在建成区要按规划和规范配置公厕、垃圾箱，今年每个试点镇要建成一座以上标准公共厕所。三是园林绿化建设。结合旧镇区改造和新区建设，加大试点镇园林绿化工作推进力度，特别要注重公园、绿化带、街头绿地、庭院绿化建设，抓好沿河（溪）、渠、湖、海绿化整治，增加绿量，提高绿化水平。年底前每个试点镇都要建成一个以上供居民休闲、观赏及文化活动的公园，建成一片以上有一定规模和档次的公共绿地，改造提升一条以上的道路绿化，建成区人均公园绿地面积达到5.5平方米以上，绿化覆盖率达18.5%以上，完成“绿色乡镇”创建任务（责任单位：市住房和城乡建设局、市规划局、市林业局、市文化广电新闻出版局、市国土资源局、相关县区管委会，各试点镇）。

　　（四）加大力落实试点政策。一是落实城乡建设用地增减挂钩和“三旧”改造政策。给予省级试点镇1000亩增减挂钩周转指标，在1000亩范围内，项目实施方案编制完成按要求报批后，可先行核定指标并上网交易。第一批省级试点镇今年内每个镇完成200亩以上新增耕地任务，第二批省级试点镇及市级试点镇今年内每个镇实施200亩以上规模的土地整治项目。各试点镇要积极推进“三旧”（旧城镇、旧厂房、旧村庄）改造工作，将土地利用效率低和不符合安全生产、生态环保要求的工业用地以及布局分散、条件落后、配套不完善、不适应发展要求的城镇和村庄建设用地列入“三旧”改造范围，开展科学规划和深度开发，提高土地的利用效率和产出效率，原则上所有退出的旧宅基地都要复垦为农田。二是落实财税管理政策。合理划分县和镇财权与事权，科学确定财税分配比例，完善财政转移支付体系，建立健全试点镇一级国库，真正做到“一级政府一级财政”。2011年省级试点镇新增地方级收入实行全留，市级试点镇新增地方级收入市区所得财力的50％留在试点镇。三是探索户籍管理新模式。根据试点镇的实际情况，采取灵活多样的户籍管理制度。原试点镇农民，转为城镇居民户口后，集体土地的承包经营权可以继续保留，也可有偿退还或转让；在试点镇居住的外地农民，有稳定职业或生活来源的人员，也可申报城镇居民户口，探索一种农民、居民“双重身份并存、双向自由流动”的新模式。同时，各试点镇所在县（区）政府（管委会）要积极探索金融、基础设施投资、房地产等扶持政策（责任单位：市国土资源局、市住房和城乡建设局、市经贸局、市财政局、市公安局、相关县区管委会，各试点镇）。

　　三、保障措施

　　（一）健全组织机构。成立2011年莆田市小城镇建设改革发展战役分指挥部，成员由市直有关部门组成（见附件1），指挥部下设办公室，挂靠在市委农办，负责日常工作。试点镇所在地的县（区）政府（管委会）要相应成立领导小组，加强对小城镇建设改革发展战役的统筹、协调和指导。

　　（二）落实责任分工。市分指挥部办公室要每月组织一次情况分析会、每二月组织一次现场会，研究探讨工作情况，协调解决有关问题，推进战役发展；办公室各挂钩试点镇领导要增强工作的主动性，加强与基层的互动，在重大项目和政策的实施上，多指导、多服务、多给力，对基层反映的实际困难和问题，想方设法协调解决。各责任单位要逐条对照目标任务抓好落实。市直各相关职能部门要根据职责要求，出台相关配套政策措施，制定本部门推进小城镇建设改革发展工作方案及时间安排表，责任到人。试点镇所在的县（区）政府（管委会）是试点组织和管理工作的责任主体，要制定具体工作方案，加强领导，真抓实干，有效运作，要根据年度实施方案的要求，严格按照时间节点，倒排工作进度，强化考核。各试点镇要结合小城镇建设总体目标任务，认真制订一年会战的具体实施方案，周密安排，尽快形成实物工作量，明确时间节点、具体举措和责任单位、责任人。

　　（三）下放管理权限。按照闽政办〔2011〕22号“赋予试点镇政府更多县级经济社会管理权限，增强试点镇综合管理社会经济的能力”要求，各试点镇所在县（区）政府（管委会）要主动会同相关部门探索下放经济社会管理权限，委托或授权试点镇政府行使县级管理职能，如在有条件的试点镇设立财政税务分局、国土资源管理分局、规划建设分局等，通过“下放事权、扩大财权”，激发小城镇政府“为民建镇”的积极性。

　　（四）加快项目审批。各责任单位要紧盯项目建设目标任务，快节奏运作，采取“并联审批、预先审批”等措施，简化审批程序，切实加强项目建设。深化行政审批制度改革，下放部分县级审批权限，为必须由省里审批的发展项目提供绿色审批通道，允许试点镇所在县（区、管委会）直接上报省直有关部门，市直相关部门审批权可委托试点镇所在县（区）政府（管委会）审批，市直相关部门见章盖章。

　　（五）加强投资保障。一是积极融资。有关县（区）政府（管委会）要指导试点镇设立政府主导的建设投资开发公司，探索建立投融资、土地收储的新途径。二是从银行机构融资。依托规范操作、可持续运转的融资平台，通过银团贷款、融资租赁、企业债券、保险债权投资计划等方式，从银行和金融机构融资，从资本市场融资，解决试点镇建设发展的资金需求。三是招商引资。要结合民营资本回归工程，综合运用各种措施，优化投资环境，吸引有实力、有品牌、有信誉的企业在试点镇投资兴业。实行“谁投资、谁经营、谁受益”，在公共基础设施和公共服务领域尽快推出一批项目，采用BT、BOT、TOT等运作模式，吸引社会资金参与建设和经营。

　　（六）畅通信息渠道。各试点镇每月16日中午12点前报送重大项目开竣工、前期突破和重要节点的完成等形象进度，次月2日中午12点前报送上月全面进展情况月报（详见附件2、3）。若报表无法全面反映试点镇的进展情况（尤其是重点推进的项目进展情况），须附必要的文字说明。省级试点镇报送省发展改革委规划处，一并报送市、所在县区。市级试点镇报送市小城镇战役指挥部办公室，一并报送所在县（区）政府（管委会）。县（区）政府（管委会）收到月报信息后应立即组织审查，发现与实际情况不符或有其他不同意见时应采取紧急措施予以纠正，并将修改情况第一时间向省、市反馈。电子表格可从省发改委或市委农办互联网站进行下载。

　　（七）强化督查工作。各试点镇要对照市“五大战役”有关文件的精神和要求，及时开展自查，认真总结项目推进工作中的经验、做法和成效，以及重点项目序时推进情况、存在主要问题。自查情况形成书面材料，于每月2日前报送战役分指挥部办公室。督查小组要定期或不定期组织抽查，负责跟踪项目动态、建设进度，收集好的做法、成效及存在的问题，及时进行通报。对督查中发现的问题，要督促限期进行整改。

　　（八）总结典型经验。通过完善信息报送和督查工作机制、召开试点工作分析会和现场会、在新闻媒体和《简报》发布信息等方式，及时对各试点镇在规划设计、项目建设、政策落实、改革探索等方面行之有效的好做法和好经验进行总结和推广，进一步营造加快小城镇建设改革发展的良好氛围。

　　办公室下设4个工作小组和指导协调组、督查组：

　　第一组：组长由姚国章兼任，副组长由荔城区分管领导担任。负责联系西天尾镇、北高镇。

　　第二组：组长由陈龙贤兼任，副组长由涵江区、城厢区分管领导担任。负责联系江口镇、萩芦镇、华亭镇。

　　第三组：组长由蔡建硕兼任，副组长由仙游县分管领导担任。负责联系枫亭镇、榜头镇。

　　第四组：组长由俞梅霖兼任，副组长由秀屿区、北岸管委会分管领导担任。负责联系埭头镇、山亭镇。

　　各工作小组职责：负责统筹协调指导、组织和督促试点镇实施好小城镇战役各项工作，协调解决工作中的困难和问题。组长负总责，副组长具体抓，成员可以从相关部门抽调人员参加。

　　指导协调组：组长由卓继祖担任，成员由分指挥部成员单位领导组成。负责研究小城镇试点工作的相关政策，指导全市小城镇建设改革发展战役的全力实施，同时，通过月例会、现场办公会和专题会议，及时统筹协调解决小城镇建设改革发展战役工作推进中遇到的困难和问题，为小城镇建设改革发展战役的全速推进扫平障碍。

　　督查组：组长由黄金辉担任。负责全市小城镇建设改革发展战役实施的日常联络工作；负责跟踪项目动态，检查督促重点项目建设进度；负责战役实施信息编写和收集，及时报道战役实施进展情况、典型经验、好做法、好成效，同时针对战役中存在的困难和问题，及时上报战役分指挥部协调解决。
