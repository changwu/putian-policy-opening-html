莆田市人民政府办公室关于印发莆田市开展零无照经营一条街创建活动工作方案的通知

莆政办〔2010〕107号
来源:市府办 时间：2010-08-16 10:29
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　为进一步推进我市查处无证无照经营工作，经市政府同意，现将《莆田市开展“零无照经营一条街”创建活动工作方案》印发给你们，请认真贯彻执行。

 

　　二〇一〇年六月三十日               

 

莆田市开展“零无照经营一条街”创建活动工作方案

　　为进一步贯彻落实福建省人民政府《关于进一步完善查处无证无照经营工作机制的通知》（闽政文〔2007〕5号）精神，维护我市公平竞争的市场交易秩序，保护广大经营者和消费者的合法权益，提升莆田城市形象，迎接省运会在我市召开，有效推进我市查处无证无照经营工作，参照《福建省工商系统“零无照经营一条街”创建活动实施方案》（闽工商企监〔2010〕186号），制订本工作方案。

　　一、指导思想

　　以党的十七大精神和科学发展观为指导，围绕服务湄洲湾港口城市建设，实现我市“经济翻番、港城崛起”的目标，加快推进我市社会经济发展，坚持疏堵结合、标本兼治的原则，完善“政府统一领导，工商行政管理部门牵头协调，相关职能部门各司其职、齐抓共管”的工作机制，以创建“零无照经营一条街”活动为载体，深入推进查处取缔无照经营工作规范化建设，以点带面，全面提高无照经营监管水平，切实维护市场经济秩序，服务海峡西岸经济区建设。

　　二、工作目标

　　在城市主干道和乡镇政府以上所在地创建“零无照经营一条街”，实现“两个100%”和“两个彻底”的目标。即实现创建街道的各类市场主体持照率、亮照率达100%；前置审批有效期届满企业抄告率达100%；彻底消除实际经营情况与《营业执照》登记事项不相符现象；彻底消除有效前置审批许可证登记事项与《营业执照》登记事项中相关登记内容不相符现象。

　　三、主要任务

　　（一）全面查处取缔无证无照经营。在我市各级政府的统一领导下，依托查处无证无照经营工作机制，充分发挥查处无证无照经营联席会议制度平台作用，组织政府相关职能部门，全面查处无证无照经营；加强部门联动，探索建立长效监管机制；实施无照经营动态监管，建立无照经营动态户口，规范监管流程。对创建街道加大查处无证无照经营行为力度，确保“零无照”经营。根据创建街道无照经营不同情况，有针对性地开展各类无照经营专项整治，对从事危害人体健康、存在重大安全隐患、威胁公共安全的无证无照经营行为，要依法严肃处理。适时开展案后回访工作，防止无照经营反复回潮现象的发生。

　　（二）建立健全信息抄告制度。查处无证无照经营工作联席会议组成单位要认真贯彻执行《福建省企业监管信息抄告管理暂行规定》，运用福建省企业监管信息抄告平台系统，及时、准确地将有关企业监督管理信息抄告给相关职能部门，加强后续跟踪、督办，并做好相关职能部门抄告信息的办理和反馈，以实现监管执法信息共享、互联互通、运行有序。

　　（三）认真实施信用分类监管。结合推进开展“诚信一条街”活动，强化落实企业信用分类监管办法。工商部门要有效应用新版企业信用分类监管系统，切实加强对各类企业和个体工商户的信用监管；开展日常巡查，重点加强对T类及扣分降级企业的巡查监管。其他职能部门要配合工商部门做好信用信息收集、信用类别认定等各项工作，落实类别化监管措施，建立健全“经济户口”动态信用监管档案。探索建立守信激励、失信惩戒机制，树立诚信示范典型，引导广大经营者诚实守信、合法经营。

　　（四）规范市场主体经营行为。各县（区、管委会）要组织相关职能部门，综合运用行政处罚、行政指导等多种手段，加强对创建街道的市场监管。加强行政指导，除涉及环境影响、公共安全、人身安全等高危行业外，市场主体首次轻微违反注册登记管理法律法规，且无主观故意并未造成不良社会后果的，首先实施行政指导。加强监管执法，依法查处商标侵权、虚假广告、欺诈消费者、不正当竞争、合同违法等违法违规经营行为，维护良好的市场秩序。

　　四、方法步骤

　　（一）2010年７月，各县（区、管委会）根据本方案，结合本地工作实际，制订或完善工作方案，对创建“零无照经营一条街”活动进行动员部署，确定创建街道，抓好宣传发动，营造创建氛围。

　　（二）2010年８月至2011年10月，按照创建工作任务和要求，开展创建活动。各县（区、管委会）至少创建1条“零无照经营一条街”。

　　（三）2011年11月至12月，由市工商局牵头，组织相关职能部门，按照评定标准，对县（区、管委会）的“零无照经营一条街”创建工作进行初评，将经初评符合评定标准的创建街道报送市查处无证无照经营工作联席会议办公室，对符合标准的创建街道，授予“零无照经营一条街”牌匾。

　　（四）2011年后，各县（区、管委会）继续开展创建活动，扩大创建范围，以此为载体，提高查处无证无照经营监管水平，逐步消除我市无证无照经营现象。

　　五、评定方式及标准

　　（一）评定方式

　　1．实地检查。对创建街道的各类市场经营主体逐一进行走访，查看其持、亮照情况，取得许可审批的情况以及依据营业执照登记事项从事经营活动的情况。

　　2．内务资料检查。对创建街道中需要取得前置许可审批的市场经营主体，运用福建红盾网网上工商应用平台企业信用分类监管系统，查看其前置审批许可证是否有效及有效前置审批许可证登记事项与《营业执照》登记事项相关内容是否相符。对前置审批许可证有效期届满的，运用福建省企业监管信息抄告平台系统，查看该前置审批许可证有效期届满的企业监管信息的抄告情况。

　　（二）评定标准

　　按照以下标准，对创建街道的各类市场经营主体逐一检查：

　　1．依法办理设立登记，取得营业执照；

　　2．在规定的营业（经营）期限内开展经营活动；

　　3．营业执照正本置于住所或营业场所的醒目位置；

　　4．营业执照未经伪造、涂改、出租、出借、转让；

　　5．住所或经营场所地址与核准登记的地址一致；

　　6．按照登记注册事项从事经营活动，没有擅自改变主要登记事项的行为；

　　7．依法应当取得前置许可审批的，其前置许可证件上的名称、经营地址、经营范围、有效期限等登记事项，与营业执照的相关登记事项内容相符；

　　8.依法应当取得前置许可审批，其前置许可审批有效期限届满的，工商行政管理机关在规定时限内，将该企业监管信息抄告有关许可部门；

　　9．按照规定参加年度检验或者验照。

　　创建街道各类市场经营主体均符合评定标准的，评定为“零无照经营一条街”；创建街道各类市场经营主体中一户未符合评定标准的，不予评定。

　　六、工作要求

　　（一）高度重视，强化领导。开展创建“零无照经营一条街”工作是推进经营规范化建设，提高我市市场监督管理工作水平的重要载体，是维护公平竞争市场秩序，促进我市社会经济建设的具体举措。我市各级政府要从切实维护群众切身利益和促进社会和谐发展的高度，提高思想认识，增强责任感和使命感，高度重视并组织领导好创建活动，以实际行动迎接省运会在我市召开。

　　（二）着眼实效，精心组织。为方便创建工作开展，我市 “零无照经营一条街”创建不再设立专项机构，而是统一依托市查处无证无照经营联席会议办公室具体组织开展。各县（区、管委会）可参照市里做法，强化对创建工作的组织领导。要在认真总结近年来查处取缔无证无照经营行为和创建“诚信一条街”经验做法的基础上，制订、完善创建方案和工作措施，明确责任分工，确保创建活动行之有效地开展。要以创建工作为契机，进一步探索长效监管机制，全面推进我市查处无证无照经营规范化建设。

　　（三）加强宣传，营造氛围。各级政府和具体工作机构要充分借助电视、广播、报纸等新闻媒体的舆论监督作用，大力宣传我市开展“零无照经营一条街”创建活动，争取经营者和消费者的支持和理解，减少工作阻力，提高经营者依法经营的法律意识。

　　（四）培育示范，稳步推进。要本着“典型引路，示范推动”的目的，认真总结创建工作中好的思路、好的做法，以点带面，全面铺开，逐步将“零无照经营一条街”创建经验推广到其他街道。各地要及时对创建工作进行总结、上报、交流、讨论，认真查找不足，采取有效措施，推进创建工作，取得良好成效。
