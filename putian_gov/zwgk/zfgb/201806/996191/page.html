莆田市人民政府关于切实抓好2013年造林绿化美化工作的通知

莆政综〔2013〕26号
来源:市府办 时间：2013-03-29 10:01
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　为认真贯彻落实党的十八大精神，切实抓好2013年造林绿化美化工作，积极创建国家森林城市，加快推进生态文明建设，现将2013年造林绿化美化工作有关事项通知如下：

　　一、深化思想认识，推进生态建设

　　党的十八大首次对建设生态文明作出了全面部署，形成了中国特色社会主义事业“五位一体”的总体布局。省第九次党代会提出了“2016年森林覆盖率保持全国首位，生态环境质量保持全国前列”的奋斗目标。市第六次党代会提出了“跨越发展、宜居港城”的总体目标，要求积极创建国家园林城市、国家森林城市和国家生态城市，加快建设环境优美、绿色生态的宜居港城；市委审时度势，近来作出了建设“美丽莆田、幸福家园”的号召，提出了更高的要求。造林绿化是推进生态文明、建设生态市和美丽莆田的根本措施。我市造林绿化虽然取得了一定成绩，但仍存在着森林资源分布不均、质量不高等问题，尤其是人口密集的沿海地区缺林少绿或森林景观不佳的问题依然突出。各级各有关部门要进一步提高认识，增强责任感和紧迫感，加快造林绿化步伐，加强生态文明建设，让莆田大地披上美丽绿装，实现生态优美、山川秀美，为科学发展、跨越发展提供生态保障。

　　二、明确目标任务，突出工作重点

　　2013年全市造林绿化任务为15.5万亩（任务分解详见附件），包括：（一）“四绿”工程建设2.9万亩。绿色城市着重抓好城市片林、城市森林公园和南北洋水系两岸荔枝林带，加大城市道路林带宽度和绿化、美化、彩化力度，加强社区（住宅区）绿化、开发区（工业园区）绿化，积极创建“国家森林城市”；绿色村镇侧重抓好幸福家园试点绿化，村镇公园（片林）建设、近村坡耕地造林、零星“四旁”植树，加强城乡接合部森林生态景观建设，积极创建“绿色乡镇”、“绿色村庄”；绿色通道注重抓好莆永高速公路、福厦高铁、向莆铁路及交通主干道两侧绿化与提升；绿色屏障重点抓好沿路、沿溪（库）、沿海、环城一重山的造林绿化和4500亩沿海防护林基干林带造林。（二）林分修复补植10万亩。重点抓好郁闭度0.2—0.4的稀疏林地及重点水土流失区的林分修复补植、荒芜经济林补植套种、人工针叶纯林改造和1800亩稀疏林地速生大苗造林补植。（三）人工造林更新2.6万亩。重点抓好2600亩生物防火林带建设和4000亩珍贵用材树种造林。各县（区）人民政府（管委会）要将任务尽快层层分解，并落实到具体山头地块。各县（区）人民政府（管委会）分解到乡（镇）的具体任务于3月10日前报市绿化委员会备案。同时突出抓好花卉苗木基地建设，为今后“四绿”工程建设奠定扎实基础。

　　三、强化有力措施，狠抓任务落实

　　一要搞好规划，落实林地。尽快组织技术力量，搞好规划设计，将造林绿化美化各类型造林地落实到山头地块。二要配套资金，提供保障。各县（区、管委会）要在省、市安排专项资金补助的基础上，预算安排配套资金，确保育林基金、森林植被恢复费和森林资源补偿费用于造林绿化美化和森林抚育。三要备足苗木，满足需求。各县（区）人民政府（管委会）要根据造林任务，认真测算造林绿化美化所需苗木的树种和数量，尽早做好苗木的调剂；针对2013年及今后我市将开展“四绿”工程建设的实际，建设十大花卉苗木基地，适时地调整苗木的组成结构，加大乡土阔叶树种苗木的培育，确保有足够的苗木供应。四要科学造林，提高成效。遵循自然规律，适地适树，分类推进。在造林更新上，要大力提倡不炼山造林，维护地力和生物多样性。在重点生态区位，要通过采取间伐、补植、套种等人工措施，加快调整树种组成，改善林分结构，促进形成树种多样、针阔混交、异龄复层的复合型林分。在非林地绿化上，要选择景观效果好、经济价值高的名贵和优良乡土阔叶树种，以丰富森林景观，提高城乡绿化美化水平。

　　四、建立目标责任，切实加强领导

　　各县（区）人民政府（管委会）要将造林绿化美化工作列为“五大战役”的重要内容抓好抓实。一要建立目标责任。层层下达造林绿化美化责任书，细化指标，明确责任。二要加强组织领导。落实造林绿化行政首长负责制，主要领导要亲自抓，分管领导要具体抓，抓部署、抓示范。三要强化宣传发动。大力宣传造林绿化对改善生态环境的重要意义和各级政府扶持政策，调动社会主体、团体和个人以各种形式参与造林绿化的积极性，营造浓厚氛围。四要搞好部门配合。实行部门责任分工，住房建设、农办、交通运输、林业部门分别负责绿色城市、绿色村镇、绿色通道、绿色屏障建设任务，其他部门密切配合，各司其职，各负其责，通力协作。五要组织抽查考评。各级绿化委员会要适时组织抽查考评，重点是“四绿”工程建设、生物防火林带建设和珍贵用材树种造林，考评结果及时进行通报。

附件2

2013年莆田市造林绿化美化方案

　　一、任务

　　总任务15.5万亩，包括：（一）“四绿”工程建设2.9万亩，其中：绿色城市0.25亩、绿色村镇1万亩、绿色通道0.55万亩、绿色屏障1.1万亩（含0.45万亩沿海防护林基干林带造林）；（二）林分修复补植10万亩（含0.18万亩稀疏林地速生大苗造林补植）；（三）人工造林更新2.6万亩（含0.26万亩生物防火林带建设和0.4万亩珍贵用材树种造林）。

　　二、类型

　　(一)绿色城市：包括市、县（区、管委会）的建成区及规划区范围绿化。重点建设城市片林、城市森林公园和南北洋水系两岸荔枝林带，加大城市道路林带宽度和绿化、美化、彩化力度，加强社区（住宅区）绿化、开发区（工业园区）绿化，积极创建“国家森林城市”。

　　(二)绿色村镇：包括全市所有乡（镇）、村、自然村绿化。重点抓好幸福家园试点绿化、村镇公园（片林）建设、近村坡耕地造林、零星“四旁”植树，加强城乡接合部森林生态景观建设，积极创建“绿色乡镇”、“绿色村庄”。

　　(三)绿色通道：包括高速公路、国省道、县乡村道和铁路两侧绿化。突出抓好莆永高速公路、福厦高铁、向莆铁路及交通主干道两侧绿化与提升，打造“带、网、片”相连的“四季皆绿、四季有花、四季变化”的森林生态景观通道。

　　(四)绿色屏障：包括全市沿路（高速公路、国省道、铁路交通主干线沿线一重山）、沿溪库（重点木兰溪、秋芦溪干流两侧和市级饮用水源保护区一重山）、沿海（临海山地一面坡，沙岸从海水高潮位起向陆地延伸200米，泥岸从海水高潮位起向陆地延伸100米）、环城（县区级以上城市周边一重山）范围内的稀疏林地（郁闭度小于0.4）和茶果园修复补植、低产低效人工针叶纯林改造以及沿海防护林基干林带造林。重点抓好县区级以上城市周边林分修复补植提升和沿海基干林带补齐加厚。

　　(五)林分修复补植：包括郁闭度0.2—0.4的稀疏林地及重点水土流失区林分修复补植、荒芜经济林补植套种和低质低效人工针叶纯林改造。对稀疏林地、重点水土流失区和荒芜经济林，补植套种当地乡土阔叶树种、珍贵树种，提高林分密度、改善林分结构，提高森林资源质量和森林景观效果；对景观生态效果较差、林分质量不高的低产低效人工针叶纯林，采用间伐、抚育、套种等方法对其进行改造，进一步优化树种结构，逐步形成混交林、复层林、异龄林，提高森林生态系统的稳定性。

　　(六)生物防火林带建设：包括在林缘田边、山脊、行政区界等地段因害设防，适地适树，营造生物防火林带。重点选择在生态公益林边缘、森林火灾易发处营造。各县（区）人民政府（管委会）森林防火部门要根据建设任务，切实抓好项目的组织、规划与实施，加强督促检查，保质保量完成建设目标。该项任务的完成情况列入省、市政府年度森林防火责任制考核。

　　(七)珍贵用材树种造林：包括荒山荒地造林、采伐迹地和火烧迹地更新，优先发展优良乡土树种，推广引种成功的外来珍贵树种，大力推进具有区域特色的珍贵树种木材战略储备基地建设。

　　(八)苗木花卉基地建设：突出抓好十大花卉苗木基地建设，为今后“四绿”工程建设奠定扎实基础。

　　三、标准

　　(一)绿色城市、绿色村镇、绿色通道标准

　　1．采用胸径≥3厘米、树高≥2米的景观树种大苗。

　　2．种植连续面积1亩以上的片林或2行以上、行距≤4米的林带，每亩合理株数≥42株，且分布均匀；零星“四旁”植树按每亩42株的标准进行折算。

　　(二)绿色屏障标准

　　1．稀疏林地、茶果园补植套种和人工针叶纯林改造采用地径≥3厘米、苗高≥1.5米的容器大苗。基干林带造林采用主要造林树种苗木质量分级（DB35/127-2004）和木麻黄水培育苗技术规程（DB35/T502-2003）中规定的I级容器苗。

　　2．稀疏林地每亩补植阔叶树≥25株，且分布均匀，人工措施到位。茶果园每亩套种阔叶树≥20株，且分布均匀，人工措施到位；如果采用“山头戴帽、山脚穿鞋”方式建设林带的，整个小班每亩平均株数不小于25株，其中均匀分布不小于10株。低产低效人工针叶纯林改造提升在间伐后需每亩补植套种阔叶树≥30株，且分布均匀，人工措施到位。临海山地一面坡基干林带株行距为2m×2m～1.5m×1.5m，沙岸、泥岸基干林带株行距为2m×2m，其中红树林株行距为1m×1m或1.3m×1.3m。

　　(三)林分修复补植标准

　　1.采用主要造林树种苗木质量分级（DB35/127-2004）中规定的阔叶树I级容器苗。

　　2．稀疏林地、重点水土流失区每亩补植阔叶树≥25株，且分布均匀，人工措施到位。茶果园每亩套种阔叶树≥20株，且分布均匀，人工措施到位；如果采用“山头戴帽、山脚穿鞋”方式建设林带的，整个小班每亩平均株数不小于25株、其中均匀分布不小于10株。低产低效人工针叶纯林改造提升在间伐后需每亩补植套种阔叶树≥30株，且分布均匀，人工措施到位。

　　(四)生物防火林带标准

　　1.采用木荷、火力楠、相思树、油茶等生长快、抗火性强树种的I级苗。

　　2.防火林带宽度（水平）15～20米，林带连续长度1公里以上。

　　3.木荷、火力楠等乔木树种造林密度为167～200株/亩，株行距为1.67m×1.67m～2m×2m；油茶造林密度为100～150株/亩，株行距为2.4m×2.8m～2.2m×2.8m。

　　(五)珍贵用材树种造林标准

　　1．采用主要造林树种苗木质量分级（DB35/127-2004）中规定的I级苗，尚未制定相关技术标准的，采用地径≥0.5cm、苗高≥35cm、侧根发达的苗木或苗高≥35cm容器苗。

　　2.选择《中国主要栽培珍贵树种参考名录》（办造字〔2006〕94号）、《福建省林业专家建议补充11个珍贵树种名录》和《福建省第一批主要栽培珍贵树种参考名录》（闽林综〔2007〕149号）中适宜本地气候特点的珍贵树种造林。

　　3．速生珍贵树种造林密度为70～110株/亩，株行距为2.8m×3.4m～2.2m×2.8m；慢生珍贵树种造林密度为167～208株/亩，株行距为1.8m×2.2m～1.6m×2m。实行沿等高线、品字型排列穴植。

　　4．提倡营造混交林，珍贵树种与一般树种混交时，珍贵树种比例要占设计造林密度的35%以上。

　　四、补助

　　(一)造林绿化

　　在省资金补助的基础上，市再安排专项资金并按以下标准补助，各县区（管委会）要按市补助标准予以配套。

　　1．绿色城市、绿色村镇、绿色屏障、绿色通道按每亩300元标准补助。

　　2.高铁、高速公路、交通主干道两侧绿化按每亩3000元标准补助。

　　3．林分修复补植按每亩40元标准补助。

　　4．稀疏林地速生大苗造林补植按每亩300元标准补助。

　　5. 生物防火林带建设按每亩500元标准补助。

　　6. 珍贵用材树种造林按每亩元250元标准补助。

　　(二)花卉苗木基地

　　扶持十大花卉苗木基地建设启动资金200万元（具体补助标准由市林业局、财政局共同制定实施）。

　　(三)其他

　　造林绿化工作经费60万元。
