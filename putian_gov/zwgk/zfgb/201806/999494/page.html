莆田市人民政府关于莆田市2010年纠风工作的实施意见

莆政综〔2010〕67号
来源:市府办 时间：2010-05-27 15:39
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　2010年全市纠风工作，要以“三个代表”重要思想为指导，深入贯彻落实科学发展观，按照 “持续完善、拓展延伸、突破创新”的工作要求和 “坚持更加注重载体运用务求实效、更加注重履职尽责协力作为、更加注重关注民生维护民益”的定位，以纠风责任制推进传导工作责任、以民生服务监督台筹建整合诉求渠道，以网上纠风平台建设强化过程管理，做大做强纠风惠民品牌，为促进我市经济平稳较快发展提供坚强保证，现就2010年纠风工作提出如下意见：

　　一、全面推进纠风工作责任制，认真落实纠风工作责任

　　制定《纠风工作责任制考评标准》, 进一步强化部门的责任，调动部门的积极性。采取条块结合、双轨分解的办法，将今年各项纠风工作任务分解到县区和市级牵头单位，厘清责任主体，明确任务、职责、权限、完成质量和具体的考核标准,强化责任传导。专项治理的牵头和主办部门要高度负责、协办单位要主动履职。要进一步分解细化责任、量化考核标准、规范考核程序，继续完善和拓展纠风专项考评制度。

　　建立“4+4”纠风工作跟踪落实机制。即，年初责任单位制定目标计划和进度安排+责任分解以层层传递工作责任、责任单位工作推进+市纠风办月评议以强化过程监控、年终部门自查+市纠风办考评（评议）以推动责任落实、市纠风办通报反馈+部门整改以改进工作。

　　加大纠风工作监督力度。对侵害人民群众利益的不正之风特别是对顶风违纪的问题，要发现一起查处一起。各县区纠风部门每年都要查处1—2件有影响的纠风案件，起到刹风整纪、以儆效尤的效果。要加强专项检查，坚持日常督查与重要时期督查相结合、常规督促检查与临时性监督检查相结合。要突出日常监管，充分调动各责任部门的积极性和主动性，依靠各级纠风部门、政风行风评议代表、人民群众，依托各种热线平台、新闻媒体、网络载体，把常态监管落到实处。

　　二、以民生服务监督台为载体，畅通“五位一体”群众诉求渠道

　　筹建民生服务监督台。以12319、968168服务热线和莆田廉政网为平台，整合纠风、效能、建设和新闻媒体的监督服务职能，为广大人民群众提供民生和发展方面投诉、建议、求助、协调服务，实现与公众、企业的零距离沟通、零距离互动、零距离服务。开发民生服务监督业务系统，通过计算机和网络系统的支持，将所有来电的意见都详细记录，并实时录音，实现全天候服务，利用电话网和网上转办系统，及时分办。部门对应建立办理机制。市纠风办、市效能办对平台反馈的办理不到位问题进行跟踪督查、协调。办理情况除涉及人员举报、涉法涉诉外，通过廉政网“民心桥”栏目及时公开；媒体主动、及时报道跟踪民生热点、焦点，强化媒体监督。

　　实现新闻媒体互动。按照“资源通融、内容兼融、宣传互融、利益共融”的工作思路，强化媒体之间的互动。在电视台和网络、《湄洲日报》专栏对行风热线节目进行预告，进一步扩大节目的影响力；在电视台《纠风在线》栏目，对上期上线单位落实群众反映问题情况进行追踪报道；探索行风热线通过电台、网站在线直播，网络、电视、报纸收集的群众问题意见实现热线解答，节目结束后，通过莆田廉政网随时点播，在报刊、电视等传媒上深化传播的有效渠道。

　　提升纠风媒体栏目质量，打造精品栏目。围绕市委、市政府工作中心、一个时期网上投诉重点，群众关注的热点专题报道，集中力量进行深度剖析，采取多部门联合上线现场解决问题，报纸、电台、电视台多家媒体集中采访报道、连续报道、系列报道和现场直播等多种报道手法，让各种媒体在各自特色的基础上发挥整体宣传合力，形成联动效应，切实提高栏目综合监督水平，增强群众的认同感，打造精品栏目。要采取有效措施切实加强对媒体生成的信息资源的开发利用和行风建设经验信息交流，使其更好地为纠风工作服务。

　　三、充分发挥网上纠风平台作用，服务和推进纠风工作

　　继续拓展纠风联网工程，由市直部门向县(区)部门和与群众联系更密切的街道、乡镇延伸，实现全市各县区纠风办、各部门、街道纠风工作网上协同办公，无纸化办公，提高工作效率，为诉求群众更快、更多、更好地解决实际问题。

　　加强网上纠风平台建设。建设投诉（个案）处理系统和实时预警督办系统。实现纠风投诉件（个案）的在线受理、分办、跟踪和督办；采取实时“红、黄、绿”灯预警、投诉件倒计时、短信催办方式，加强投诉件督办力度。建设网上评议(考评)系统。对应投诉、个案接收率、反馈率、及时率、群众满意率等关键节点，系统自动打分、考核和综合分析，并按月、季度、年度进行排名通报；加强投诉件满意度评价。回访投诉网民意见，强化责任单位解决问题意识，减少验收回访的工作量。建设纠风舆情研判系统。对突出问题、分布领域、变化规律等情况进行深层次研究和综合性分析，及时发现重点、难点、热点问题，进行趋势分析，便于领导了解群众对政府部门核心需求。

　　制定网上纠风配套制度。明确网上运行管理程序，制定预警纠错、监督问责、考核评价办法，进一步拓展网上纠风的内容和范围，完善网上纠风的考评机制。

　　四、深入推进民主评议政风行风，大力加强部门和行业政风行风建设

　　（一）着眼基层、着眼重点行业、着眼重点岗位，进一步加强部门和行业的政风行风建设。1、集中力量抓好与人民群众关系密切的部门和行业的政风行风建设。按照市纪委委员票决推荐情况，市政府决定选择30个部门和行业作为2010年重点评议对象，没有纳入重点评议对象的单位为自评单位。重点评议单位要有重点地选择1-2个群众反映最强烈或部门目前存在最突出的问题，开展选题评议，制定具体实施方案，力争在年内有明显的成效。2、以窗口单位为重点，对与群众密切相关的政府部门、公共服务行业直接面向企业或群众的服务窗口，开展“服务标准化”建设，不断提高服务质量和水平，切实解决公共服务行业利用特殊地位和管理优势限制和侵害消费者权益的问题，督促有关部门和行业制定优质规范的服务公约、加强行业自律。3、将乡镇（街道）设立的基层站（所、队）等作为重点评议对象，实行末位责任追究，加强民主评议基层站所工作，切实解决基层群众反映强烈的问题。

　　（二）完善民主评议政风行风评价体系，明确评议主体、深化评议内容、改进评议方式、增强评议效果。建立加强日常评议的制度和办法,将年终考评一锤定音的静态评议转变为动态评议,切实做到以评促纠、以评促建。进一步传承、提升个案整改以治标、选题评议以治本的工作机制，在强化网上预警督办的同时，制定个案、选题评议办理质量等次评定、二次督办制度，组织行评代表对个案逐个评议，个案办理质量区分等级，每个等级制定具体的规则和标准量化考评，考评结果作为年终考评（评议）的重要依据，并定期进行网上通报。对评议认定办理不到位的采取二次督办方式，责成部门续办，直至办理到位。二次督办将予以适当扣分。

　　五、持续深化专项治理工作, 认真查处损害群众利益的不正之风问题

　　（一）以清理强农惠农资金为重点，切实减轻农民负担。着力抓好四个方面工作：一要全面开展强农惠农资金发放、使用情况的清理和检查，坚决纠正和查处虚报、截留、挪用、套取及滞发、抵扣、贪污等行为，并健全资金管理制度，进一步规范管理。二要保障农民土地承包经营权益，坚决纠正农村土地承包、流转、征收和征用中侵害农民利益的问题，严格落实被征地农民补偿措施，完善相关社会保障机制。三要巩固涉农收费清理整顿成果，以农村义务教育、建房、计生、村级组织乱收费及土地征用补偿费兑现不到位等问题为重点，严查涉农乱收费、乱罚款和各种摊派行为；继续对各类“下乡”补贴政策落实情况进行监督检查，保证下乡产品质量，简化补贴手续，确保补贴到位。此外，继续加大对制售假劣农资坑农害农行为的打击力度。

　　（二）以清理涉企收费和集资摊派为重点，切实减轻企业负担。着力在四个方面下功夫：一要落实监管责任。建立健全各级政府负总责、有关部门各负其责的企业负担监管机制。二要全面清理涉企收费。取消不合理收费，降低过高收费标准，修订完善并公布收费目录。三要坚持分类指导。对中小企业的收费，要能免则免，能减则减，帮助其更好地应对国际金融危机的冲击；对国有大中型企业，要重点遏制地方政府、部门向企业乱摊派问题。四要加快推进涉企收费相关改革。完善行政执法部门经费保障机制，防止因利益驱动乱收费；有序推进行业协会、市场中介组织与行政主管部门“脱钩”，规范其服务和收费行为。

　　（三）以清理庆典、研讨会、论坛为重点，切实减轻基层负担。着力抓好四个环节：一要全面清理。坚决撤销铺张浪费、牵强附会、华而不实的庆典、研讨会、论坛活动。二要严格审批。未经上级主管部门批准，各级政府及其部门一律不准举办庆典、研讨会、论坛。三要严格控制经费支出。党政机关经批准举办活动的，所需经费必须纳入财政预算，接受审计监督。四要严格责任追究。严肃查处滥用财政资金、向企业和个人摊派费用或拉赞助，以及利用举办庆典、研讨会、论坛活动为单位或个人谋取私利等问题。社团、中介机构、企业举办此类活动，本级政府要正确引导，加强监管，控制规模。要严格执行清理评比达标表彰工作的政策规定，继续巩固和深化清理成果，按照规范意见的要求，严格控制和审批新增项目。

　　（四）以规范市场中介组织管理为重点，切实减轻群众和企业负担。实现全市中介组织全部“四分开”的目标，着力净化中介市场。依法综合运用各种措施，治理市场中介组织违法违规行为。严肃查处违法违纪案件，以案促规范；继续以制度建设为重点，督促行业主管部门加强配套制度建设；规范中介组织市场准入条件、中介组织及其执法人员违规违法档案等制度、完善中介组织退出机制；进一步理顺部门职能，理顺行业管理关系和行政管理权限，实现全方位监管。完善信用管理配套制度，加快市场中介组织信用信息平台建设，健全中介组织信用分类监管办法。

　　（五）纠正医药购销和医疗服务中的不正之风。继续推进四个方面的工作：一要继续配合以政府为主导、以省（区、市）为单位的网上药品集中采购工作，规范莆田片区的确标、采购行为，防范确标、采购中可能产生的腐败问题。二要继续推进公立医疗机构院务公开，加强对用药、收费行为的监管，规范诊疗服务行为。三要继续推进医德医风考评，加强医德医风建设。四要继续推进医药市场诚信体系建设，严肃查处医药卫生领域的违法违纪行为。

　　（六）治理教育乱收费。坚决纠正四个方面的问题：一要落实义务教育经费保障机制，纠正挤占、截留、挪用和骗取教育经费问题。二要大力推动义务教育均衡发展，纠正义务教育阶段因择校引发的乱收费问题。三要完善中小学教辅材料管理制度，纠正教辅材料散滥问题。四要加强对学校收费行为的监管，纠正各种名目的乱收费、高收费问题。

　　（七）治理食品药品安全突出问题。加强对食品药品生产、流通、消费环节的监管，推动建立健全食品药品安全评估、预警和应急处置体系。开展食品药品安全专项整治行动，坚决打击违法添加非食用物质和滥用食品添加剂问题，坚决打击利用互联网等媒体发布虚假广告和通过寄递等方式销售假药问题，严肃查处失职、渎职行为。

　　（八）整治客运市场秩序。治理公路和水上“三乱”行为，严格规范治理超限超载联合执法行为，加大源头监管力度，执行责任倒查制度；严格落实成品油价格和税费改革政策；依法依规设站，严格规范公路设站检查和水上执罚执收行为，建立公路和水上“三乱”的快速反应机制和公路无“三乱”一票否决制度。进一步规范出租车和客运车辆的服务和收费行为，加强对出租车行业的管理和客运市场的整顿。

　　（九）治理“四项资金”监管中的突出问题。强化对社保基金、住房公积金、扶贫资金和救灾救济资金以及政府专项资金的监督检查，纠正和查处资金分配、管理、使用过程中的违法违纪行为。建立健全强化资金监管的长效机制，加强对大额资金的实时监控，确保资金安全、高效。

　　（十）治理行业协会侵害群众和企业利益问题。继续做好各级行业协会与行政主管部门的“四脱钩”工作，规范离退休人员在行业协会的任职行为；积极推行“三项评估”工作，各业务主管部门要对行业协会进行认真梳理和筛选甄别，引导行业协会根据实际情况进行整合重组、注销登记，或依法予以撤销登记；指导行业协会加强自律管理，健全规章制度，完善自我约束机制、促进发展；坚决查处和纠正行业协会乱收费、乱摊派、垄断服务、强制服务等行为。

　　六、工作要求

　　（一）加强组织领导。各县区、各部门认真落实纠风工作责任制，切实加强组织领导。各部门、各行业要坚持“谁主管，谁负责”和“管行业必须管行风”的原则，认真落实政府主抓、行政领导主抓的责任；各级纠风部门要加强组织协调；各专项治理的牵头和主办部门要高度重视、认真负责、协办单位要主动履职。要进一步分解细化责任、量化考核标准、规范考核程序，继续完善和拓展纠风专项考评制度。

　　（二）注重制度建设。要把制度建设作为纠风工作的一项重要工作来抓，坚持用制度管事、管权、管人，把解决群众反映的突出问题与建立长效机制结合起来，推动纠风工作的法制化建设。要不断提高现有制度的执行力，强化监督，建立健全制度执行的监督机制，加大对违反制度行为的查处和问责力度，落实责任，建立重要制度执行责任制，确保制度落到实处。加强调查研究，及时发现苗头性，倾向性、源头性问题，立足从建立健全制度上预防和解决问题。

　　（三）强化队伍管理。各级纠风办要加强工作的监督指导。根据纠风工作重点，及时分解工作任务。要经常组织检查指导，确保今年纠风工作各项任务落到实处。要加强队伍建设。按照“为民、务实、清廉”的要求，有计划地组织对各级各部门纠风工作人员、行评代表进行基本技能培训，提高素质、增强本领，努力造就一支政治坚定、纪律严明、勤政廉政、开拓进取、敬业奉献的工作队伍，以纠风工作实际成果服务发展，取信于民。

 

　　二Ο一Ο年四月二十九日
