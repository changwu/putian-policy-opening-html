莆田市人民政府办公室关于印发2011年重点项目建设战役实施方案的通知

莆政办〔2011〕22号
来源:市府办 时间：2011-03-26 10:05
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　经市政府同意，现将《2011年重点项目建设战役实施方案》印发给你们，请认真组织实施。

 

　　二0一一年二月十一日               

 

莆田市2011年重点项目建设战役实施方案

　　为贯彻落实我市经济工作会议精神和省重点项目建设战役部署，坚决执行市委、市政府关于继续打好“五大战役”、大干“十二五”开局之年的决策，全力推动科学发展、跨越发展，现结合重点项目建设实际，制定《莆田市2011年重点项目建设战役实施方案》。具体方案如下：

　　一、总体要求

　　2011年是“十二五”开局之年，是站在新的起点上推动我市科学发展、跨越发展的重要一年。各级各部门要切实把思想和行动统一到市委、市政府的决策部署上来，以科学发展观为指导，深入贯彻市委五届九次、十次全会和全市经济工作会议及2011年“五大战役”暨重点项目攻坚动员会议精神，把握科学发展主题和加快转变、跨越发展主线，突出促增长、调结构，统城乡、惠民生，深改革、大开放，着力投资拉动、项目带动，凝心聚力、真抓实干，服务先行、勇于突破，全力打好重点项目建设战役的投资完成、竣工投产、开工建设和前期突破四大攻坚战，实施全市百个项目攻坚，推动全市“超千争百促跨越”目标的实现，以重点建设的新成效迎接中国共产党成立90周年，为实现“十二五”良好开局做出新的更大贡献。

　　二、主要任务

　　2011年省重点项目建设战役的投资攻坚任务以在建项目年度投资计划为考核指标，开工、竣工攻坚任务和前期突破任务以省在建、预备重点项目和全省经济工作会议项目为主要内容，我市有59个项目列入省重点建设战役项目，为衔接好全省重点建设战役，结合实施全市百个项目攻坚，2011年重点项目建设战役共安排项目230个，主要包括列入省重点项目建设战役项目、市百个攻坚项目和2011年市在建重点项目，项目总投资4010亿元。各县（区、管委会）、各部门要以“七一”、国庆、元旦为主要节点，分阶段、分级分类、分县（区、管委会）、分行业实施好投资完成、竣工投产、开工建设和前期突破四大攻坚战，确保全年完成投资不少于370亿元，竣工投产105个以上，开工建设143个以上，重点突破35个重大前期项目取得实质性进展。

　　（一）打好投资完成攻坚战。确保重点建设战役全年完成投资不少于370亿元，投资增速高于全社会固定资产投资增速，促进全市1233个各级项目全年完成投资630亿元以上，拉动全市投资超800亿元。其中上半年前投资完成突破160亿元，三季度前再完成95亿元以上，四季度前再完成115亿元以上，力争超额完成年度投资目标任务。

　　1．分级分类目标任务

　　省重点建设战役项目：省下达的任务是全年要完成投资145亿元以上，其中上半年完成62亿元以上，三季度要再完成38亿元以上，四季度再完成45亿元以上。

　　市百个攻坚项目：全年要实现投资243亿元，其中上半年完成100亿元以上，三季度要再完成60亿元以上，四季度再完成83亿元以上；35个重点跟踪项目全年要实现投资138亿元以上。

　　2．分县（区、管委会）目标任务

　　——仙游县全年要完成50亿元以上，其中上半年完成20亿元以上，三季度要再完成10亿元以上，四季度再完成20亿元以上。省重点战役项目全年要完成省定目标23亿元以上。

　　——荔城区全年要完成70亿元以上，其中上半年完成30亿元以上，三季度要再完成18亿元以上，四季度再完成22亿元以上。省重点战役项目全年要完成省定目标8亿元以上。

　　——城厢区全年要完成48亿元以上，其中上半年完成20亿元以上，三季度要再完成12亿元以上，四季度再完成16亿元以上。

　　——涵江区全年要完成58亿元以上，其中上半年完成25亿元以上，三季度要再完成15亿元以上，四季度再完成18亿元以上。省重点战役项目全年要完成省定目标1亿元以上。

　　——秀屿区全年要完成65亿元以上，其中上半年完成25亿元以上，三季度要再完成15亿元以上，四季度再完成25亿元以上。省重点战役项目全年要完成省定目标39亿元以上。

　　——北岸全年要完成48亿元以上，其中上半年完成20亿元以上，三季度要再完成10亿元以上，四季度再完成18亿元以上。省重点战役项目全年要完成省定目标33亿元以上。

　　——湄洲岛全年要完成1亿元以上，其中上半年完成0.4亿元以上，三季度要再完成0.3亿元以上，四季度再完成0.3亿元以上。

　　——市直部门主管的跨县区项目11个，全年要完成40亿元以上，其中省重点战役项目要完成省定目标38亿元以上。时序安排是上半年完成17亿元以上，三季度要再完成10亿元以上，四季度再完成13亿元以上。以上跨县区项目中，各县区应承担的任务由市交通运输局、市住房和城乡建设局、市水利局、铁路办、莆田电业局、木兰溪防洪工程管理处、莆田电信分公司等主管部门分解。

　　3．分行业目标任务

　　——农业全年要完成2亿元以上，其中上半年完成0.8亿元以上，三季度要再完成0.4亿元以上，四季度再完成0.8亿元以上。

　　——水利全年要完成7亿元以上，其中上半年完成3亿元以上，三季度要再完成2亿元以上，四季度再完成2亿元以上。其中木兰溪防洪扫尾工程全年要完成3亿元以上。

　　——铁路全年要完成10亿元以上，其中上半年完成4亿元以上，三季度要再完成3亿元以上，四季度再完成3亿元以上。

　　——公路全年要完成45亿元以上，其中上半年完成20亿元以上，三季度要再完成11亿元以上，四季度再完成14亿元以上。

　　——港口全年要完成15亿元以上，其中上半年完成6亿元以上，三季度要再完成3亿元以上，四季度再完成6亿元以上。

　　——能源全年要完成38亿元以上，其中上半年完成16亿元以上，三季度要再完成10亿元以上，四季度再完成12亿元以上。

　　——工业全年要完成90亿元以上，其中上半年完成39亿元以上，三季度要再完成23亿元以上，四季度再完成28亿元以上。

　　——服务业全年要完成21亿元以上，其中上半年完成9亿元以上，三季度要再完成2亿元以上，四季度再完成10亿元以上。

　　——社会事业全年要完成8亿元以上，其中上半年完成3亿元以上，三季度要再完成2亿元以上，四季度再完成3亿元以上。其中，教育类项目全年完成4.09亿元，体育类项目全年完成1.7亿元，卫生类项目全年完成0.9亿元。

　　（二）打好竣工投产攻坚战。确保全年建成或部分建成105个以上。其中上半年建成或部分建成10个以上，三季度前再建成或部分建成8个以上，四季度前再建成或部分建成87个以上。

　　1．分级分类目标任务

　　省重点建设战役项目：全年要建成15个以上，其中上半年建成1个以上，三季度要再建成2个以上，四季度再建成12个以上。

　　百个攻坚项目：全年要建成15个以上，其中上半年建成1个以上，三季度要再建成2个以上，四季度再建成12个以上。其中鞍钢冷轧1月-5月酸轧调试并试投产，7月连续退火调试并试产；差别化化学纤维项目9月份完成土建施工和设备安装，12月第一套生产线试生产；石城二期风电场6月份第一台机组可并网发电，12月底49台风机全部并网发电。

　　2．分县（区、管委会）竣工项目目标任务

　　——仙游县全年要建成15个以上，其中三季度要建成1个以上，四季度再建成14个以上。

　　——荔城区全年要建成19个以上，其中上半年建成3个以上，三季度要再建成3个以上，四季度再建成13个以上。

　　——城厢区全年要建成20个以上，其中上半年建成1个以上，三季度要再建成1个以上，四季度再建成18个以上。

　　——秀屿区全年要建成14个以上，其中上半年建成1个以上，三季度要再建成1个以上，四季度再建成12个以上。

　　3．分行业竣工项目目标任务：

　　——水利全年要建成2个以上，在年底前要确保完成。

　　——公路全年要建成16个以上，其中上半年建成1个以上，四季度再建成15个以上。

　　——能源全年要建成5个以上，其中三季度要建成1个以上，四季度再建成4个以上。

　　——城建环保全年要建成36个以上，其中上半年建成1个以上，三季度要再建成1个以上，四季度再建成34个以上。

　　——工业全年要建成24个以上，其中上半年建成1个以上，三季度要再建成1个以上，四季度再建成22个以上。

　　——服务业全年要建成14个以上，其中三季度要建成5个以上，四季度再建成9个以上。

　　——社会事业全年要建成8个以上，其中上半年建成2个以上，三季度要再建成3个以上，四季度再建成3个以上。

　　（三）打好开工建设攻坚战。确保全年开工建设143个以上。其中上半年开工77个，三季度再开工36个，四季度再开工30个。

　　1．分级分类目标任务

　　省重点建设战役项目：全年要开工14个以上，其中上半年开工7个以上，三季度要再开工5个以上，四季度再开工2个以上。

　　百个攻坚项目：全年要开工34个以上，其中上半年开工18个以上，三季度要再开工6个以上，四季度再开工10个以上。

　　25个申报列入全市按季开工安排的县区本级项目，一季度开工4个，二季度开工5个，三季度开工9个，四季度7个。

　　2、分县（区、管委会）开工项目目标任务

　　——仙游县全年要开工30个以上，其中上半年开工18个以上，三季度要再开工6个以上，四季度再开工6个以上。

　　——荔城区全年要开工20个以上，其中上半年开工14个以上，三季度要再开工4个以上，四季度再开工2个以上。

　　3、分行业开工项目目标任务

　　——农业项目1个，在上半年实现开工。

　　——水利全年要开工2个以上，其中上半年开工1个以上，三季度要再开工1个以上。

　　——交通全年要开工16个以上，其中上半年开工11个以上，三季度要再开工2个以上，四季度要再开工3个以上。

　　——城建环保全年要开工48个以上，其中上半年开工22个以上，三季度要再开工14个以上，四季度要再开工12个。

　　——工业全年要开工49个以上，其中上半年开工26个以上，三季度要再开工14个以上，四季度再开工9个以上。

　　——能源全年要开工9个以上，其中上半年开工8个以上，四季度再开工1个以上。

　　——社会事业全年要开工8个以上，其中上半年开工3个以上，三季度要再开工2个以上，四季度再开工3个以上。

　　（四）打好前期突破攻坚战。切实增强抓机遇、抓前期的责任感和紧迫感，主动适应和掌握项目审批的新规定、新要求，提高前期工作的质量和深度，集中力量重点推进35个重点前期项目。其中，霞林片区改造一期(万达广场）、香格里拉酒店、力宝产业园、丁基橡胶、LNG5-6#储罐、秀屿土海生态湿地公园（一期）等项目要按照当年实现开工的要求采取倒逼机制加快前期工作，木兰溪防洪仙游段和三期宁海段、宁海挡潮闸、四期防洪工程要统筹推进、争取年内开工启动，莆田核电、莆田机场、湄洲湾大型硅钢、宏利高世代液晶面板、汽车油改气生产基地、木材集散基地等18个项目要取得阶段性突破。列入省重点战役的莆田平海湾海上风电场示范项目一期、莆田丁基橡胶、金鹰林浆纸一体化、湄洲湾大型硅钢、中新石化东吴仓储等6个项目必须提前完成省定工作目标。

　　三、工作要求

　　（一）完善领导挂钩项目制度。各级单位领导要分工分片挂钩具体项目，靠前指挥。在市重点项目建设战役中，选择事关全市产业布局、必须抓紧开工的重大项目，以及必须加快推进的重点大项目，安排市五套班子领导挂钩。按照市委“横向到部门、纵向到县区、具体到项目”的要求，市直主管部门是分行业重点项目的牵头部门，市级管理重点项目中没有安排市领导挂钩的，按照市政府领导工作分工，由分管领导负责，并确定主管部门主要领导作为项目责任人。县区管理的市重点项目由各县（区、管委会）安排领导挂钩。各级挂钩领导要根据项目推进实际，定期或不定期召开重点项目协调会，及时协调解决项目推进中的困难和问题。项目责任单位和与项目相关的管理部门按旬按月按季走访项目建设单位，了解问题、解决问题，促进项目建设提速提效。

　　（二）加强项目推进的组织调度。据莆委发〔2011〕7号文件的要求，市重点项目建设战役实行项目法人责任制，项目法人对项目的策划、筹资、建设、生产经营、偿还债务和资产的保值增值等负全面责任。参与建设的勘察、设计、监理、施工单位对所承担的项目负全责。参建单位要科学倒排工期，细化节点目标，落实责任，优化施工组织。项目业主单位应制定项目年度投资目标计划和主要阶段性形象进度计划，各分级管理单位要加强与项目业主的沟通和衔接，制定具体实施方案。市发展改革委和重点办会同相关部门加强重大项目存在问题的协调会商和督促解决，为落实市政府每月协调会、市委市政府季度调度推进会和全市每季度一次的项目开竣工活动，提供各类支持和保障。属于市级解决的事项由市重点办牵头会同有关部门协调推进，属于县区级解决的事项由县（区、管委会）牵头协调推进。各级督查、效能部门要加大联手督查力度，定期督查实施方案推进情况、重大项目存在问题的解决情况、本级机关履职服务情况等。各级政府要依法依规做好征迁交地、安置群众等工作，有效推进和谐征迁，营造无障碍施工环境。

　　（三）落实资源要素有效保障。各级各部门要未雨绸缪，积极配合项目单位科学调配好本地区、本行业项目的火工油品、建材等供应，协调解决用工紧缺问题，做好重点建设人才的培养和引进服务工作。各级重点办要主动牵头会同经贸、规划、建设、国土、林业、海洋、环保、水利、海关、公安等部门在依法依规的前提下，想方设法帮助项目业主落实相关指标，优先保障重点项目建设的要素需求。要进一步落实建设资金，帮助项目建设单位拓展融资渠道，搭建银企合作平台，规范地方投融资平台运作，积极鼓励和引导社会资本进入重点建设领域，保障重点建设融资需求。

　　（四）强化项目建设的各项管理。要把安全生产作为战役攻坚的重要内容，坚持进度服从安全，统一部署、同步推进。全面落实安全生产“一岗双责”和企业主体责任，落实监理单位的安全巡视和旁站检查制度，确保参建单位“安全人员、安全预案、安全设施、安全制度”四到位。各级安全管理部门和分级管理单位要加强对重点工程安全生产情况的监管，定期或不定期组织安全隐患排查，督促整治工程质量通病，杜绝重大安全质量事故的发生。要按照标本兼治、综合治理、惩防并举、注重预防的要求，进一步完善与重点建设相适应的预防和惩治腐败体系，切实防止重点建设领域的腐败现象发生。要在加快项目建设的同时维护好社会安定稳定，把重大建设项目社会稳定风险评估工作列入绩效考评的重要内容，督促项目建设单位落实主体责任。项目所在地政府要重视和抓好建设工地及周边治安环境综合治理，对恶意阻工、破坏设施、偷盗材料等现象予以坚决依法处理。

　　（五）全面推行战役的考核评比。战役的考核评比按照《2011年重点项目管理和考评方案》组织进行。考评以各县（区、管委会）和市直主管部门为对象，2011年省、市两级重点项目全部列入考评范围，考评以项目为单位评分，各县（区、管委会）和市直各主管部门按照市委、市政府年初正式下达的目标任务，其主管责任范围内的所有项目合计得分为该单位的最终考评分数。要进一步加强考评成果应用，考评成果要与年度绩效考评挂钩，与前期经费投入挂钩，并作为干部考核管理和评先评优的依据。

　　（六）完善信息报送机制。战役实施情况由各分级管理单位（或授权部门）务必按规定时间报送市重点办，由市重点办统一汇总。每月15日上午12:00前报送当月开工、竣工及其它需要反映的相关情况；每月1日上午12:00前报送当月投资、开工、竣工、前期突破、项目储备及其它需要反映的相关情况。报送渠道：pttz2004@163.com,电话：2221639，传真：2632008。市重点办将会同相关部门按照“年初拉清单、年中年末对账单”要求，逐月、逐季围绕投资、开工、竣工、前期突破以及战役信息报送质量等主要指标，对战役实施情况进行通报，并作为战役考评的重要依据。
