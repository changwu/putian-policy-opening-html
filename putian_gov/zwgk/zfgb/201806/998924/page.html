莆田市人民政府办公室关于印发莆田市2011年新增长区域发展战役实施方案的通知

莆政办〔2011〕39号
来源:市府办 时间：2011-04-26 10:47
| | | |

各县(区）人民政府(管委会)，市直有关单位：

　　为加快推进我市2011年新增长区域发展战役工作步伐，经市政府研究同意，现将《莆田市2011年新增长区域发展战役实施方案》印发给你们，请认真贯彻执行。

 

　　二〇一一年三月一日　　            

 

莆田市2011年新增长区域发展战役实施方案

　　为认真贯彻落实省政府办公厅《关于2011年新增长区域发展战役实施方案的通知》和市委、市政府《关于印发2011年“五大战役”实施方案的通知》的战略部署，坚决执行市委、市政府关于实施2011年“五大战役”暨重点项目攻坚动员大会的重大决策，全力打好今年我市新增长区域发展战役，打造港城经济发展新引擎，推动全市“超千争百促跨越”目标的实现，今年我市将对应省里继续组织实施“五大战役”，大干“十二五”开局之年，以推动科学发展、跨越发展取得新成效。按照市政府对“五大战役”的统一分工，市经贸委为“新增长区域发展战役”的责任牵头部门。现结合我市新增长区域项目以及工业和商贸类重点项目分布情况，特制定“莆田市2011年新增长区域发展战役实施方案”。具体方案如下：

　　一、总体要求

　　根据省里对新增长区域的界定，我市的新增长区域是指湄洲湾北岸重点开发建设石门澳、东吴、东峤、秀屿等产业园和加快推进“鞍钢冷轧、LNG站址3#-4#储罐、金鹰集团差别化纤维、福人木业、国投湄洲湾煤炭码头一期工程、东吴港区泊位、妈祖文化城、金鹰集团大型林浆纸一体化、丁基橡胶、大型钢铁基地”等10个重大项目建设进程。

　　我市结合临港产业布局和提升产业结构的需要，在考虑省里对我市新增长区域界定范围的同时，一并考虑兴化湾南岸重点项目的布局。同时，遵照市委杨书记关于经贸部门应结合自身职能着重服务好全市重点工业类和商贸类项目的指示，我市2011年的新增长区域界定范围为秀屿区、北岸经济开发区、湄洲岛、仙游县的枫亭镇、涵江区的兴化湾南岸以及全市范围的重点工业类和商贸类项目。

　　按照省里对新增长区域发展战役范围的界定，我市安排与省里新增长区域发展战役对接项目72个（其中在建42个、前期18个、储备12个），涉及工业、商贸服务、能源、交通、城建环保、社会事业等行业。为确保战役纵横衔接、顺利实施，按照战役指挥长李辉龙副市长的指示，工业、商贸服务、城建环保、社会事业的38个项目由市经贸委牵头（其中6个城建环保和4个社会事业项目由市、县（区、管委会）两级相关职能部门配合跟踪），县（区、管委会）经贸（发）局为纵向牵头单位，负责项目的全面协调推进和信息报送；能源、交通类的34个项目由市发展改革委牵头，县（区、管委会）发改局为纵向牵头单位，负责项目的全面协调推进和信息报送。具体项目由市直相关部门、各县（区）政府（管委会）负责组织项目业主、建设单位实施。

　　按照我市对新增长区域发展战役范围的界定，除对接省里72个项目外，市经贸委要切实按照市委、市政府领导的要求，在涵江区的兴化湾南岸和全市范围内筛选增加30个重点工业和商贸类项目，共计102个项目。新增加的30个重点工业和商贸类项目由市经贸委牵头，县（区、管委会）经贸（发）局仍为纵向牵头单位，负责项目的全面协调推进和信息报送。

　　三、目标任务

　　（一）与省里对接的战役项目

　　战役安排与省里对接项目72个(在建项目42个、前期项目18个、储备项目12个)，总投资为2435亿元，2011年度计划投资133亿元。

　　分行业情况：工业19个，总投资956.6亿元，年度计划投资44.8亿元；商贸9个，总投资26.1亿元，年度计划投资2.9亿元；能源15个，总投资1061.3亿元，年度计划投资21.7亿元；交通19个，总投资309.6亿元，年度计划投资44.7亿元；城建环保6个，总投资48.3亿元，年度计划投资17.9亿元；社会事业4个，总投资32.9亿元，年度计划投资1.25亿元。在以上72个省战役项目中，其中重大推进项目10个，总投资981.2亿元，年度计划投资50.4亿元。分片区情况：

　　秀屿片区。36个项目(工业13个、商贸3个、能源9个、交通9个、城建环保2个)，总投资1148.5亿元，年度计划投资61.4亿元。其中重大推进项目4个，总投资84.8亿元，年度计划投资17.8亿元。

　　北岸经济开发片区。25个项目(工业4个、商贸4个、能源5个、交通6个、城建环保3个、社会事业3个)，总投资1103.7亿元，年度计划投资45.9亿元。其中重大推进项目6个，总投资896.4亿元，年度计划投资32.6亿元。

　　湄洲岛片区。4个项目(商贸2个，交通1个、社会事业1个)，总投资6.0亿元，年度计划投资1.25亿元。

　　仙游枫亭片区。4个项目(工业2个、能源1个、城建环保1个)，总投资24.9亿元，年度计划投资4.3亿元。

　　跨县区。3个项目(交通类)，总投资151.8亿元，年度计划投资20.3亿元。

　　（二）我市增加的战役项目

　　为突出经贸部门服务工贸职能，进一步发挥工贸经济在我市国民经济中的“挑大梁”地位，遵照市委领导指示，新增长区域发展战役增加安排工业和商贸类重点项目30个，其中工业20个，总投资107.5亿元，年度计划投资25.8亿元；商贸8个，总投资121亿元，年度计划投资24.1亿元；能源2个，总投资8.1亿元，年度计划投资4.1亿元。分县区情况：

　　仙游县。6个工业项目，总投资36.4亿元，年度计划投资3.9亿元。

　　荔城区。8个项目，其中工业4个，总投资15.7亿元，年度计划投资6.6亿元；商贸3个，总投资43亿元，年度计划投资11.5亿元；能源1个，总投资5.1亿元，年度计划投资2.1亿元

　　城厢区。7个项目，其中工业3个，总投资21.6亿元，年度计划投资3.8亿元；商贸4个，总投资68亿元，年度计划投资11.4亿元。

　　涵江区。9个项目，其中工业7个，总投资33.8亿元，年度计划投资11.5亿元；商贸1个，总投资10亿元，年度计划投资1.2亿元；能源1个，总投资3亿元，年度计划投资2亿元。

　　四、工作要求

　　做好新增长区域发展规划、保障建设用地供给、优化项目前期审批程序、落实好政策资金支持等一系列措施是确保我市新增长区域发展战役打出成效的关键，各级各有关部门要逐个落实战役项目建设过程中存在的问题，不轻易说“不能办”，而要主动指导项目业主“怎么办”，先行先试，有效服务，确保新增长区域发展战役粮草充足，保障有力。

　　(一)强化规划引导。湄洲湾北岸临港区域发展规划上半年要全面编制完成，并按程序批准实施。要在明确区域功能定位、土地和海域利用、基础设施建设以及产业发展的总体方向和重点的基础上，确定今年重点开发建设的片区和项目，用规划引导区域科学发展、跨越发展。

　　(二)落实用地保障。一是明确责任主体。地方政府是征迁协调、安置群众的责任主体，各县（区、管委会）主要领导要亲自挂帅，加强协调推进，营造无障碍施工环境。二是做深做细群众工作。坚持以人为本、依法依规，做到征地拆迁与群众安置同步落实。特别是要注意征地拆迁安置补偿工作的公平、公正、公开，接受社会监督，防止处置不当引发社会矛盾。三是对部分非法干扰阻工现象，项目单位要积极配合地方政府，加强与当地群众的沟通协商，妥善处置。

　　(三)优化审批服务。一是战役重点项目实行审批绿色通道，对市级权限内用地、用海、用林、环保和消防等未批项目，市直有关部门要进行梳理，一些条件不够具备、不够规范的，可采取“容缺预审”的做法，先行审批，并规定一个时限让企业补齐条件或进行整改，相关部门做好指导，加强过程监督。二是对上报国家、省审批或核准的项目，各级各部门要按照“专人服务、主动介入前置审核审批”的做法，指导各县（区、管委会）和项目业主完善项目申报材料上报，主动向上级主管部门汇报衔接，促项目早日获批。三是各重点项目业主要有紧迫感，组织熟悉项目审批程序、熟悉项目工作规律的工作团体，定人、定责、定期跟踪推进，争取尽快获批。

　　(四)强化资金供给。一是要高度重视中央、省投资导向，加大进京赴省汇报衔接项目力度，积极争取中央增投资金、国家和省投资补助资金，充分发挥财政资金对项目投资的带动效应和倍增效应。二是积极争取金融部门支持。充分发挥市国投公司等投资主体的作用，整合做大国有资产，加强与银行衔接沟通，争取更多贷款额度。指导项目业主与金融部门沟通对接，落实重点项目重点企业的资金需求，形成政银企良性互动。各家银行要加强金融产品创新，增加资金供给，全力支持战役项目建设。三是积极引入社会资金。加快健全政府投资项目代建制管理办法，采用BT、BOT、TOT等模式，解决一批项目建设资金问题。要充分挖掘民间投资的潜力，逐步形成多元化投资主体和多渠道投入格局，切实解决项目启动和推进过程中的融资问题。

　　(五)强化招商引资。根据湄洲湾北岸区域自身优势和资源禀赋、产业发展前沿技术等，通过与央企、外商、民企、台企等的深度对接，策划生成一批项目，形成投产一批、开工一批，在建一批、前期一批、策划一批等“五个一批”的项目储备机制，实现动态管理、滚动发展，确保新增长区域每年都有若干个重大产业项目落地建设。

　　五、保障措施

　　(一)加强组织领导。打好新增长区域发展战役是一项政策性强、涉及面广的系统工程，市直各有关部门要统一思想，提高认识，共同谋划，合力推进。各县（区、管委会）要成立机构，强化领导挂钩制度，靠前调度，做到“干部在一线工作、决策在一线落实、问题在一线解决”，主要领导要定期听取战役重点项目建设进展情况的汇报，加强有关督促检查，及时协调解决战役开展过程中存在的困难和问题。

　　(二)明确责任单位。各县（区、管委会）作为本辖区战役项目的责任纵向主体，要切实按照以上目标任务的具体项目分解，明确涉及战役项目的管理协调部门，逐一分解项目工作责任，明确每个战役项目的责任单位和责任人，做好本辖区内战役建设项目的全面协调推进工作。市直各有关部门要密切配合，靠前服务、加强指导、加强协调。对工作不力，进度明显缓慢影响整个战役进展的，将约谈相关的单位和责任人，严重的，将予以通报问责。

　　(三)细化实施方案。各县（区、管委会）要加强与市直相关单位的沟通和衔接，对照以上全市目标任务细化分解，细化战役工作内容，制定年度具体实施方案，明确季度和年度目标任务（投资进度、开竣工5000万元以上的项目数量、10个重大推进项目的进展情况等）。以目标倒逼进度、以督查倒逼落实，逐月、逐季稳步扎实推进，确保投资完成进度和开工、竣工、前期项目等各项目标按时序节点进度推进。各县（区、管委会）战役分指挥部要开展定期和不定期的督查，督查战役项目尤其是重大项目的进展，协调解决项目存在的问题，确保各项工作落到实处。

　　(四)加强信息报送。各县（区、管委会）要理顺工作运行机制，加强项目进度报送工作，于每月14日下午下班前报送总投资5000万元以上、半月形象进度有新进展的项目开竣工、前期突破和重要节点的完成等形象进度（附件4），于每月29日下午下班前报送当月项目全面进展情况（附件3），报送格式及项目清单附后。若报表无法全面反映本辖区的进展情况（尤其是10个重大推进项目进展情况），请附必要文字说明。报送材料包括纸质版和电子版，纸质材料以正式文件报送。各县（区、管委会）在要求时间内应先行报送电子版材料，而后传真月报负责人和填报人签名同意上报的纸质函（或在电子版打印出第一张纸上签名或盖章），并于第二天将正式文件报送至市新增长区域发展战役指挥部办公室。各县（区、管委会）要加强报送战役实施中遇到的重大事项和涌现出的好经验、好做法，便于市战役指挥部办公室及时协调解决和总结推广。信息报送情况将纳入年终战役考核内容。

　　(五)完善考核通报。按照“年初拉清单、年中年末对清单”的要求，市新增长区域发展战役指挥部办公室将对各县（区、管委会）战役项目固定资产投资完成情况、开竣工项目数量、信息报送质量等指标进行月通报、季考核，年终将参照去年特色产业提升战役的做法和《2011年重点项目管理和考评方案》进行考评、总结，并予以通报。
