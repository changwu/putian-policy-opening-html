莆田市人民政府关于仙游县人民政府2009年度教育工作督导评估情况的通报

莆政综〔2010〕73号
来源:市府办 时间：2010-06-15 16:34
| | | |

仙游县人民政府：

根据福建省人民政府办公厅《转发省教育厅关于全面开展县级人民政府教育工作督导评估意见的通知》（闽政办[2006]15号）和莆田市人民政府办公室《关于2010年教育督导工作的通知》（莆政办明电[2010]11号）要求，在你县自评的基础上，莆田市人民政府教育督导室于2010年4月12-16日对你县2009年度教育工作进行督导评估。市督导评估组通过听取汇报、查阅资料、座谈了解、抽样比对等形式，同时走访了县相关职能部门，深入到18个乡镇（街道）及70多所学校进行现场察看。现将督导评估的情况通报如下：

    一、主要做法及成效

近年来仙游县教育工作持续保持良好的发展态势。特别是2008年“双高普九”省级验收以来，全县的教育工作整体水平得到全面提升，不仅省级验收时要求整改的项目得到较好的落实，而且一些项目还取得突破性进展。

（一）切实加强领导，“教育优先”落到实处。仙游县委、县政府高度重视教育工作，始终把教育摆在优先发展的战略地位，做到教育投入优先保证、教育问题优先解决。县委、县政府多次召开会议，听取教育工作汇报，研究解决教育问题。出台了推进义务教育均衡发展、促进职业教育快速发展和组织入学、“控辍保学”等一系列规范性文件。建立了领导挂钩联系学校制度和教育工作目标管理责任制度，把工作职责分解到各有关职能部门、各乡镇（街道），同时把履职情况列入年度绩效考评。县主要领导及挂钩领导多次深入学校调研，及时解决学校办学过程中的问题和困难。各职能部门、各乡镇（街道）相互配合，认真履责，从而保证了各项工作的有效落实。

（二）完善投入机制，教育经费保障有力。县财政在保工资、保开门、保稳定的前提下，能够积极筹措和调度资金，优先保证教育经费的投入，不仅全面实现“三个增长”的法定要求，而且认真落实改善办学条件的经费。2008年“双高普九”省级验收时要求整改的资金和2009年市级指导性评估时要求追补的经费都已全部落实到位。与此同时，还多方筹措资金，通过向上争取和发动社会捐资，使教育经费得到有效补充。值得肯定的是化解义务教育债务达1.2亿元，是目前全市化债最多的县区。

（三）夯实教育基础，办学条件明显改善。把改善办学条件，推进义务教育均衡发展作为工作的重点着力攻克。一是城区学校布局调整和扩容工程取得突破性进展。县政府对城区学校的扩容工程进行了很好的规划，这些项目有的已经得到实施，这在一定程度上缓解了城区学校就学压力和班生规模过大的问题。二是农村学校办学条件得到较大改善。完成了一批寄宿制学校建设项目和抗震加固项目，校舍安全工程建设有序推进。配备了一批电脑、图书、音体美器材和教学仪器，建设了一批示范图书馆。

（四）强化责任意识，“控辍保学”成效显著。把组织入学与“控辍保学”作为工作的难点认真破解。一是强化乡镇政府保障入学的法定职责；二是建立健全文化户口滚动登记制度；三是县教育督导部门倡导的“控流六法”和“四包一保五到位”责任落实机制得到较好的推行，组织入学、“控辍保学”工作逐步实现常态化、规范化管理。组织开展“三残”儿少筛查鉴定，“三残”儿少就学形成了以特殊教育学校为骨干、中小学随班就读为主体的特殊教育网络，入学率逐年提升。

（五）重视队伍建设，教师素质不断提高。一是抓学校班子建设。引进公务员的考评办法对学校班子及校级干部进行考核，并通过调整充实，学校的管理水平明显提高。二是力促教师队伍整体素质的提高。扎实开展师风师德建设，抓好紧缺学科师资补充，对现有师资进行合理配置，认真落实支教帮扶和挂教培训、名师培养等，促进教师队伍整体素质不断提高。三是认真落实教师福利待遇。积极推进教师绩效工资改革，实行农村教师特殊津贴，进一步激发了教师的工作积极性。

（六）优化教育管理，素质教育全面推进。坚持依法治教，认真落实教育法律法规，出台了学校管理的一系列规章制度，有效地规范了学校的办学行为。全面实施素质教育，建立健全学校、家庭、社会三位一体的德育工作网络，努力创新德育教育载体。各职能部门采取有力措施开展校园周边环境整治，及时消除安全隐患，及时净化文化市场，及时规范餐饮卫生，营造了良好的校园周边环境。教育督导部门充分发挥职能作用，坚持督政督学并重，建立对学校实施素质教育常规督导和随机督导相结合的工作机制，为落实素质教育发挥了积极作用。同时按照省市统一部署及时启动对乡镇政府教育工作督导评估，并把督导结果作为乡镇政府及党政主要领导干部考核的重要依据，促进了乡镇政府教育职责的进一步落实。

二、存在的主要问题

（一）办学条件仍有较大的差距。由于历史的原因，目前全县教育的设施设备离标准化的要求还有较大差距，实现义务教育均衡发展任重道远。校舍改造工程任务繁重，配齐电脑、教学仪器等还须大量的资金。去年县里已经配置了一批电脑，但农村基层学校电脑配备还不到位，加上老化需要更新的，电脑缺口还是比较大。部份学校运动场地设施不足，从而直接影响了体育教学与体育活动的开展。校舍抗震改造建设以及城区学校扩容建设任务艰巨。城区学校班生规模过大，生均校舍、生均面积离要求差距大。一些学校土木结构、石木结构等低标准的校舍仍在使用中。

（二）教育发展的一些指标达成度有待提高。幼儿园、小学、初中的入学率、“三残”适龄儿童的入学率、高中阶段毛入学率和高中阶段普职比等指标达成度有待提高。个别农村初中学校辍学率超过3%的指标底线。

（三）教师学科结构性矛盾仍然突出。虽然这两年新招聘了一批紧缺学科的教师，但学科结构性缺编还比较严重，主要是农村学校特别是山区学校英语、计算机、音体美教师缺口较大，导致开齐开足课程无法得到保证。

三、整改意见及建议

（一）加大教育经费投入，进一步改善办学条件。一要扎实推进校舍安全工程建设。对于存在安全隐患的危房必须引起高度重视，采取果断措施予以解决。二要加快寄宿制学校建设步伐，配齐食堂及宿舍设施设备，努力改善寄宿学生的生活条件。三要加快推进学校标准化建设。省里要求你县在2017年全面实现学校标准化建设，希望县里持续加大对教育的投入，统筹安排，逐步完善并努力配齐教师用电脑及教学仪器。四要加快城区学校的扩容工程建设。随着城镇化的推进，城区人口剧增，现有的几所学校容量严重不足，大班额问题突出。对此县里已经作出很好的规划，建议加快推进，尽早实施。五要加大非义务教育阶段学校的投入。特别要加大职业教育的投入，为其配备教学、实训等设施设备，为提高职业教育的办学效益和水平，扩大招生规模，实现普通高中与职业教育招生比大体相当创造条件。同时要加大对幼儿教育的投入，为农村幼儿园配好必要的教具和玩具，让农村的幼儿与城里的孩子在同一片蓝天下共享教育发展的成果。

（二）落实“控辍保学”责任，进一步提高普及水准。“控辍保学”是动态性的工作，稍有放松就会出现反弹。建议仙游县发扬推进“双高普九”时的优良作风和工作热情，持续抓好“控辍保学”工作。要把组织入学、“控辍保学”作为对乡镇督导和绩效考评的重要内容，进一步强化乡镇政府的责任，确保这项工作落到实处。

（三）加强教师队伍建设，进一步提高师资水平。造就一支数量充足、结构合理、业务精湛、师德高尚的教师队伍是提高教育教学水平的重要保证。要根据各个学校学生变动情况及学科结构情况及时对教师进行合理调配，为开齐开足课程，保证教学的正常开展创造条件。要进一步强化教师的业务培训，特别是新课程改革的培训，引导教师确立素质教育和新课改的理念，不断提高教学能力和水平。

（四）全面推进素质教育，进一步提高办学效益。要加强实施素质教育的宣传，引导学校、社会、家庭转变教育观念，改变分数至上，以考试论质量，以升学率评价学校的错误做法，为全面实施素质教育创设良好的社会环境。要督促各学校领导牢固树立素质教育的理念，增强实施素质教育的自觉性和主动性。要教育全体教师认真学习教育理论，积极开展教学研究，深化课程改革，优化教学过程，全面提高课堂教学效率。要加强教学常规管理，严格执行省颁课程计划，保证开齐开足规定的课程。要加强学校体育工作，确保每天锻炼达一小时，让学生健康成长，快乐成长。要加强学校食堂卫生的管理，严格执行食品卫生法规，认真落实营养早餐的有关规定。要认真落实义务教育阶段学校食堂不得承包经营的规定，有关食堂工友的工资建议由县财政统一预算核拨。
