莆田市人民政府办公室关于印发全面推广应用机制砂工作方案的通知

莆政办〔2017〕94号
来源:政府办 时间：2017-06-10 15:45
| | | |

各县（区）人民政府（管委会），市直有关单位：

　　《全面推广应用机制砂工作方案》已经市政府同意，现印发给你们，请认真组织实施。

 

　　莆田市人民政府办公室               

　　2017年6月1日               

 

全面推广应用机制砂工作方案

　　为加强生态保护，落实江河防洪堤安全保护，根据省住建厅《关于进一步加强预拌混凝土管理的通知》（闽建办建〔2017〕2号）中：“莆田市自2018年1月1日起全面禁止使用河砂生产预拌混凝土”及省住建厅《建筑用净化海砂应用技术规程》中：“净化海砂不得应用于预应力混凝土结构，宜与天然砂、人工砂混合使用”的规定和《建设美丽莆田行动纲要》统一部署，解决建设用砂供需矛盾突出问题，结合莆田实际，现制定以下全面推广应用机制砂工作方案。

　　一、项目选址

　　机制砂项目选址包含机制砂配套矿山和生产用地，可按以下两种方案进行选址：

　　方案一：现持有采矿许可证的矿山可直接转型生产机制砂，无需矿山招拍挂出让手续。

　　方案二：选择符合条件的废弃矿山作为机制砂开采点，须通过招拍挂确定业主。

　　以上选址点都要配套20亩以上的用地作为生产车间及堆场，同时须满足以下5个选址原则：

　　（一）配套矿山要科学选址，合理布局，符合矿产资源总体规划和矿业权设置方案，符合环保、林业等相关规划并满足机制砂生产环境保护要求。

　　（二）要聘请有资质地堪单位对拟设置的机制砂配套矿山资源进行勘查，提交可供适用机制砂生产利用的地质勘查报告。在选址上，避免选用覆盖土层较厚、夹层含泥较多的矿山，母岩的抗压强度等指标应符合建筑石料有关规范要求，不宜使用泥岩、页岩、板岩作为机制砂配套矿山，所选矿山岩质必须符合机制砂生产建设用砂国家标准（GB/T14684-2011）的要求。

　　（三）机制砂配套矿山只能用于生产机制砂，矿山年产生规模应大于50万m3，服务年限10年以上（其中方案一矿山按原年产生规模、原采矿证年限执行）。

　　（四）项目用料用地范围无产权纠纷，严禁在自然保护区、风景名胜区、饮用水水源保护区、世界文化和自然遗产地、基本农田保护区、水土流失重点防治区等环境敏感区内新建、扩建、改建机制砂项目；应远离居民区、医院、学校等环境噪声敏感目标，并配套建设相应的除尘、隔音、降噪等环保设施。

　　（五）矿山选址须避开生态林，不能占用基干林带、军事禁区、森林公园以及Ⅱ级保护林地；严禁在木兰溪和铁路、国道、省道两侧可视范围内以及城镇周围一重山占用、征用林地。

　　原则上除北岸经济开发区和湄洲岛国家旅游度假区以外，仙游县、荔城区、城厢区、涵江区、秀屿区分别先建成2个年生产能力50万m3以上的机制砂生产企业。各县（区）政府须优先从废弃矿山中预选址。

　　2017年6月底前，各县（区）政府应将选址结果上报市机制砂生产应用推进领导小组，由市国土局牵头，会同市环保局、市林业局、市住建局、市水利局、市安监局、市质监局以及县（区）政府，对选址结果进行统一论证，并从符合机制砂生产条件的矿山中选择1-2个作为全市机制砂生产试点，先行先试，逐步实现每个县（区）建成2个机制砂生产企业的目标。

　　二、评估出让

　　由市国土局牵头，会同市环保局、市林业局、市住建局、市水利局、市安监局、市质监局以及县（区）政府，委托同一家中介机构对试点矿山采矿权价款进行统一评估。

　　试点矿山采矿权价款通过统一评估后，所在县（区）政府应于2017年9月底前完成征地、征迁、维稳、土地赔偿、机制砂生产涉及的道路配套设施等前期工作，为出让提供条件，并于2017年11月底之前按矿山的招拍挂出让工作程序完成出让工作。为积极培育机制砂生产示范企业，可由所在县（区）政府根据实际情况积极培育具备房屋建筑工程施工总承包特级、一级，或市政公用工程施工总承包一级资质的企业，以及装配式建筑企业作为试点矿山受让方，同时鼓励国有企业参与机制砂项目。

　　三、手续办理

　　各相关职能部门应对机制砂项目相关审批手续实行“绿色通道”服务机制。

　　机制砂项目业主应按照省经信委、省住建厅《关于开展机制砂生产企业名录登记和公布工作的通知》（闽经信函原料〔2014〕409号）有关规定，提交相应审批材料报市住建局，由市住建局会同有关部门对审批材料进行核实，核实通过后上报省经信委审批。

　　四、生产监管

　　（一）机制砂生产企业每年需生产50万m3以上满足质量标准要求的机制砂。

　　（二）现持有采矿许可证直接转型生产机制砂的业主单位于2017年12月底前完成机制砂生产企业建设并正式投产，满一年后，经所在县（区）政府考核合格的，可由所在县（区）政府给予50-100万元奖励。

　　（三）试点矿山出让后，受让方从采矿许可证颁发之日起6个月内完成机制砂生产企业建设并正式投产，满一年后，经所在县（区）政府考核合格的，可由所在县（区）政府给予50-100万元奖励。

　　（四）各相关职能部门要加大对违法使用河砂、海砂的检查和打击力度。

　　（五）成立莆田市机制砂生产应用推进领导小组，由市政府分管副市长任组长，分管副秘书长任副组长，成员包括市政府办、各县（区）政府、市法制办、市发改委、市国土局、市环保局、市林业局、市水利局、市公安局、市安监局、市质监局、市住建局等，领导小组下设办公室，挂靠在市住建局，主要职责是明确县（区）政府及相关职能部门职责，定期研判工作进展情况，督促各职能部门定人、定岗、定期限开展机制砂推进工作。同时，将机制砂生产应用推广任务纳入《建设美丽莆田行动》九大专项行动之城乡建设专项行动，并实施效能督查和考评，确保年度任务完成。

　　1.县（区）政府负责机制砂项目选址、日常管理等。试点矿山所在县（区）政府负责矿山出让前期工作、矿山招拍挂出让工作，负责建成年生产能力50万m3以上的机制砂生产企业，监督安全生产制度等落实情况，制定区域矿山生态恢复治理方案和土地复垦方案并报送市国土局，与矿山业主单位签订治理协议，督促限期完成治理工作；加强日常巡查监管；对以利用办理机制砂项目名义进行非法采矿的，应及时制止并上报市国土局，根据有关规定对其从重处理。

　　2.发改部门负责完成用于机制砂生产的矿山开采立项审批等工作。

　　3.国土资源部门负责组织机制砂配套矿山的采矿权招拍挂出让工作，会同有关单位对矿山开采进行监管，积极为机制砂项目提供用地支持服务。

　　4.环保部门负责机制砂项目相关环评审批及验收等工作，对机制砂生产企业污染防治设施运行情况进行监督检查，督促企业确保污染物稳定达标排放。

　　5.林业部门负责机制砂配套矿山的林地初审等工作。

　　6.公安部门负责矿山开采、爆品监管、爆破相关审批等工作。

　　7.安监部门负责矿山开采、机制砂生产等安全生产监督检查工作。

　　8.质监部门负责对机制砂生产企业的试验仪器检定或校准情况进行监督检查，会同市住建局按照福建省发布的机制砂产品标准，加强监督检查，确保机制砂产品质量。

　　9.住建部门负责机制砂行业准入条件监督检查，建立企业目录，鼓励企业应用先进技术和设备，不断提升机制砂产品质量；对机制砂进场质量、预拌混凝土生产企业机制砂混凝土生产质量以及应用机制砂预拌混凝土施工实体质量进行巡查、抽查抽测，及时公布巡查、抽查抽测情况。

　　五、退出机制

　　为全面建设绿色、环保、和谐的机制砂生产基地，保证机制砂产业的顺利发展，实行退出机制，主要有：

　　（一）各职能部门和县（区）政府应加强协作，做好监管工作。机制砂生产企业所在县（区）政府应做好日常监督检查工作，并及时向有关职能部门上报企业违法违规行为，各职能部门要根据各自的职责开展定期或不定期监督检查等工作。矿山开采及机制砂生产过程中，对机制砂生产进行有效监管，机制砂生产质量标准未达到要求的，应立即停止开采，并立即整改，直至整改到位后才可继续生产。

　　（二）试点矿山只能用于机制砂生产，市机制砂生产应用推进领导小组应组成联合督查组，实时不定期进行监督检查，经查出矿山未用于机制砂生产或在机制砂中掺杂海沙、河沙等行为的，应责令立即停止开采并进行整改，拒不整改的收回采矿权，并对生产企业进行处罚。
