莆田市人民政府办公室关于印发莆田市人民政府2015年推进依法行政建设法治政府工作要点的通知

莆政办〔2015〕40号
来源:市府办 时间：2015-04-22 16:21
| | | |

各县（区）人民政府（管委会），市政府各单位、各直属机构：

《莆田市人民政府2015年推进依法行政建设法治政府工作要点》已经市人民政府批准，现印发给你们，请结合实际，认真组织实施。实施中的有关情况和问题，请径向市政府法制办公室反映。

 

 

                                                   莆田市人民政府办公室                

                     2015年3月31日                

 

莆田市人民政府2015年推进依法行政建设法治政府工作要点

为深入贯彻党的十八届四中全会和省委九届十二次全会精神，根据《福建省人民政府办公厅关于印发福建省2015年推进依法行政建设法治政府工作要点的通知》（闽政办〔2015〕16号）的要求，紧紧围绕市委、市政府的中心任务和工作重点，制定本要点。

一、扎实筑牢法治政府建设基石

（一）提高依法行政能力。认真贯彻落实《中共莆田市委关于贯彻党的十八届四中全会精神全面推进依法治市的实施意见》，以法治精神、法治思维、法治方式推动各项工作。各级各部门要改进创新领导干部和行政机关工作人员、执法人员学法机制。坚持把学习宪法放在首位，增强宪法意识，维护宪法权威，保证宪法实施，落实依宪执政；认真学习与履行职责相关的法律法规，更好地适应依法管理经济社会事务的需要。完善依法行政考核指标体系，把依法行政作为衡量各级政府及其部门领导班子和领导干部工作实绩的重要内容，加大依法行政考核在政府绩效考核中的比重。

责任单位：市政府办公室、市法制办牵头，各县（区）人民政府（管委会）、市直有关部门负责

（二）落实依法行政工作责任。加强对推进依法行政工作的组织领导，结合自身实际，制定推进依法行政年度工作要点，落实工作责任。实行推进依法行政年度报告制度，2015年12月底前，各级各部门要及时向市政府书面报告本年度推进依法行政建设法治政府工作情况及下一年度工作安排。

责任单位：市法制办牵头，各县（区）人民政府（管委会）、市直有关部门负责

（三）加强法制机构和队伍建设。把握目前政府机构改革的契机，切实加强各级法制工作机构和队伍建设，使法制机构在政府工作部门中的定位、级别、规格和人员编制与其所承担的职责任务相适应。要加大对法制干部的培养、使用力度，重视提拔政治素质高、法律素养好、工作能力强的法制干部。

责任单位：市政府办公室、市委编办牵头，各县（区）人民政府（管委会）、市直有关部门负责

（四）营造良好法治氛围。健全普法教育机制，落实“六五”普法规划，做好“12.4”宪法日和法制宣传日工作，采取有效方法增强全民法治观念。大力开展推进依法行政、建设法治政府宣传工作，强化舆论引导，形成良好法治舆论氛围。

责任单位：市司法局牵头，各县（区）人民政府（管委会）、市直有关部门负责

二、着力提升行政决策的公信力

（五）健全科学民主依法决策机制。认真落实《莆田市人民政府重大行政决策规定》，修订完善本地区本部门重大行政决策规则和程序，明确决策范围、权限，把征求部门意见、公众参与、民主协商、专家论证、专业机构测评、成本效益分析、风险评估、合法性审查和集体讨论决定作为重大决策的重要程序。建立和完善行政机关内部重大决策合法性审查机制，重大决策必须经本单位法制机构或专家合法性审查，未经合法性审查或经审查不合法的，不得提交讨论。市政府定期对各级各部门执行重大行政决策相关制度的情况进行检查和通报。

责任单位：市政府办公室、市法制办牵头，各县（区）人民政府（管委会）、市直有关部门负责

（六）推行政府法律顾问制度。建立健全以政府法制机构为主体的政府法律顾问制度，出台《莆田市人民政府办公室关于加强政府法律顾问制度建设的意见》和《莆田市人民政府法律顾问工作规则》，有针对性地聘请专家、律师等担任法律顾问，参与政府重大行政决策的合法性论证，发挥其在重大行政决策中的参谋顾问作用。

责任单位：市政府办公室、市法制办牵头，市社科联、市司法局，各县（区）人民政府（管委会）、市直有关部门负责

（七）落实行政决策责任追究。建立重大决策终身责任追究制度及责任倒查机制，对出现重大决策失误、造成重大损失、恶劣影响的，依法追究相关人员责任。

责任单位：市政府办公室、市监察局牵头，各县（区）人民政府（管委会）、市直有关部门负责

（八）加强规范性文件管理。认真贯彻落实《福建省行政机关规范性文件备案审查办法》，出台《莆田市行政机关规范性文件管理规定》，进一步严格规范性文件制定、审查和备案程序。重点加强对规范性文件中违法增加公民、法人和其他组织义务或者减损其合法权益，涉及地方或行业保护等内容的合法性审查，建立备案审查情况通报制度，确保政府的行政行为从源头上合法、有效。按照规范性文件“二年一清理”的规定，今年各级各部门要开展规范性文件清理工作，及时修改、废止与法律、法规、规章相抵触，不符合经济社会发展要求的规范性文件。抓住立法法修改的契机，适时举办立法法知识培训班，专门学习有关立法知识、立法技能和技巧等方面业务，做好立法知识和人才储备的基础工作。

责任单位：市政府办公室、市法制办牵头，各县（区）人民政府（管委会）、市直有关部门负责

三、深化行政执法体制改革

（九）创新行政执法体制机制。建立行政综合执法机制，扩大相对集中行政处罚权工作的范围，逐渐分批推进，将多种类的执法队伍并联整合，引导综合执法和相对集中行政处罚权工作有机衔接，提高行政执法效能。各部门内部也要相对集中行政执法权，特别是行政处罚权，尽量确定一个机构统一执法，减少或避免多头执法。进一步贯彻落实《关于完善行政执法与刑事司法衔接工作机制办法》，严格案件移送标准和程序，促进各有关单位之间的协调配合，形成工作合力。加强福建省行政执法与刑事司法衔接信息共享平台的使用管理，推行网上移送、网上受理、网上监督，着力提高衔接工作效率，逐步实现行政处罚和刑事处罚无缝对接。

责任单位：市法制办、市委编办牵头，各县（区）人民政府（管委会）、市直有关部门负责

（十）严格规范行政执法行为。坚持公正文明执法，规范执法主体，明确行政执法职责，梳理执法依据，完善和落实行政裁量权基准制度。加大执法力度，严格依法查处各类违法行为，建立执法全过程记录制度。各级各部门应制定常态化执法监管方案，继续开展行政执法案卷评查、重大行政执法行为备案审查工作，完善行政执法监督检查制度和机制，强化对日常监管工作的督查考核。严格落实行政执法人员持证上岗和资格管理制度，组织2015年行政执法资格考前培训、考试和执法证件发放工作。

责任单位：市政府办公室、市法制办牵头，各县（区）人民政府（管委会）、市直有关部门负责

四、大力推进政府职能转变

（十一）继续深化行政审批制度改革。做好取消、下放和调整审批事项的落实和衔接工作，对有利于激发市场主体创造力、增强经济发展内动力的行政审批事项，要进一步加大取消和下放力度。规范行政审批程序，提高行政审批效率，加快建立常态化的监管制度，推动政府管理重心从事前审批向事中事后监管转变。加强各级行政服务中心规范化建设和运行管理，为群众办事和项目建设提供便利条件。不得在公开的目录清单外实施其他行政审批，对已取消、下放和转变管理方式的事项，不得进行变相审批，杜绝随意新设、边减边增、明减暗增等问题，对违反规定的，严肃追究相关单位和人员责任。

责任单位：市委编办、市行政服务中心管理委员会牵头，各县（区）人民政府（管委会）、市直有关部门负责

（十二）继续推行“清单”制度。推行行政权力清单、责任清单制度，公开权力运行流程，建立依法审核、发布和动态管理工作机制，确保“行政权力进清单，清单之外无权力”， 防止滥用权力。

责任单位：市委编办牵头，各县（区）人民政府（管委会）、市直有关部门负责

（十三）强化对行政权力的监督。自觉接受人大及其常委会的法律监督、政协的民主监督、司法机关的司法监督和社会的舆论监督。加强审计工作监督，保障和支持审计部门依法独立行使审计监督权。加强行政监察，完善电子监察系统，健全纠错问责机制和行政问责方式。加强机关作风和效能建设，紧紧围绕市委市政府的中心工作，强力推行“马上就办”工作制度，加大效能督查力度，持续治庸治懒治散，力破“中梗堵”。严格执行政府信息公开条例，创新公开载体和形式，主动、及时、准确公开财政预算决算、重大建设项目批准和实施、社会公益事业建设等领域的政府信息，对群众申请公开的信息及时给出答复。

责任单位：市政府办公室、市监察局、市效能办、市审计局牵头，各县（区）人民政府（管委会）、市直有关部门负责

五、依法化解社会矛盾纠纷

（十四）推进行政复议和应诉规范化建设。紧记“复议为民”的原则，积极推行便民的受理方式，着力提升案件办理效率，加大调解力度，提高办案质量。注重对新类型案件的研究和办理，认真审理重大、复杂、疑难的复议案件。探索建立行政复议委员会制度，通过机制创新，提升政府行政复议的公信力。落实2015年我市首次依法行政与行政审判良性互动机制工作会议议定事项，完善行政机关与人民法院之间的协调沟通机制，健全行政复议与行政诉讼的良性互动机制。执行行政机关工作人员和行政首长出庭应诉制度，自觉接受人民法院的司法监督。加强对新修订的《行政诉讼法》的学习和宣传，认真研究《行政诉讼法》修改后对行政复议和行政诉讼应诉工作产生的影响，尽快适应新的法律制度对行政机关特别是出庭应诉工作提出的新要求，进一步加强行政诉讼应诉队伍和能力建设，保障新修订的法律得到全面正确实施。

责任单位：市法制办牵头，各县（区）人民政府（管委会）、市直有关部门负责

（十五）健全矛盾纠纷化解机制。畅通信访渠道，推进“阳光信访”，拓展网上信访，开展信访听证，把信访纳入法治化轨道。坚持市领导信访接待日制度和“两挂钩一督导”信访工作制度，充分保障信访人合法权益。积极引导信访人通过法治方式理性解决问题、反映诉求，促进信访积案化解、初信初访案件及时办理和进京非正常访问题有效解决。依法打击非法上访行为，提倡依法上访，对违法上访过程中出现的极端违法行为予以坚决依法惩处，真正落实信访“三访终结”，体现社会公平正义，体现法律法规的严肃性、严谨性。落实社会稳定风险评估工作，加强矛盾纠纷排查化解、涉法涉诉信访等级预警，实行行政调解与人民调解、司法调解、行政复议、行政诉讼对接机制，通过巩固大调解工作体系最大限度地化解行政争议，维护人民群众合法权益和社会公共利益。

责任单位：市信访局、市司法局牵头，各县（区）人民政府（管委会）、市直有关部门负责
