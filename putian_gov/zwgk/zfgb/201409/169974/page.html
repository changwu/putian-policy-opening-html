莆田市人民政府办公室关于转发莆田市道路交通安全综合整治“三年行动”2014年工作要点的通知

莆政办〔2014〕72号
来源:市府办 时间：2014-07-25 15:56
| | | |

各县（区）人民政府（管委会），市直有关单位：

经市政府研究同意，现将莆田市道路交通安全综合整治“三年行动”工作领导小组办公室（以下简称“市道安办”）制定的《莆田市道路交通安全综合整治“三年行动”2014年工作要点》转发给你们，请认真贯彻执行。

 

 

莆田市人民政府办公室          

2014年5月23日               

 

莆田市道路交通安全综合整治“三年行动”2014年工作要点

市道安办

2014年是全市道路交通安全综合整治“三年行动”（2012年8月至2015年7月）工作“攻坚年”，全市道路交通安全综合整治工作要以党的十八届三中全会精神为指导，全面落实省、市政府关于加强道路交通安全管理工作的部署，持续深入推进道路交通安全综合整治“三年行动”各项工作，实现全市道路交通安全形势持续好转。全年全市道路交通事故死亡人数比三年平均数（即2010-2012年，下同）下降30%以上、比2013年下降10%以上，较大事故起数不超过1起，力争不发生重大以上道路交通事故。

一、强化综合整治组织保障

（一）强化各级政府在交通安全管理中的主导作用，完善“党委政府统一领导、部门协调联动作为、社会各界共同参与”工作机制，确保“三年行动”综合整治深入开展；加强各级道安办组织建设，从充实人员、给足经费、完善制度、有效运作等方面充分保障，保证各项道安工作正常有效运行。（责任单位：各级人民政府及管委会）

（二）强化道路交通安全形势分析研判，落实全市道安工作任务，提出本地区2014年度道路交通事故预防工作目标及措施。全面加强农村道路交通安全监管，落实乡镇道路交通专职协管员和村（社区）兼职交通安全员配置。（责任单位：各级人民政府及管委会）

（三）强化道路交通安全问责机制，将道路交通安全作为社会管理综合治理、精神文明创建、平安建设及绩效管理的重要内容，严格考评。严格事故责任倒查制度，严肃事故责任单位及责任人追究，督促道路交通较大以上事故整改措施落实到位。各级道安办要强化督查落实，负责建立本地区工作情况月通报制度，对整治工作措施不落实或由此引发事故的，各级安办会同同级监察部门予以通报批评、约谈或问责。（责任单位：各级人民政府及管委会，各级道安办、安办、监察局、综治办、文明办、效能办等部门）

（四）总结宣传推广各级各部门道安工作先进经验，表彰道安工作先进集体和个人，坚持典型示范、榜样引领。（责任单位：各级人民政府及管委会）

（五）加强业务培训，督促相关部门如实立案、如实统计、如实反馈、如实建档，真实反映道路交通安全集中整治工作成效。（责任单位：各级人民政府及管委会）

二、强化驾驶人和车辆安全管理

（一）由县级人民政府负责组织本辖区各乡镇（街道）及相关职能部门建立完善重点车辆摸排制度，以乡镇（街道）为单位，开展重点车辆（客车、旅游车、校车、危货车、渣土车、低速汽车、拖拉机、摩托车）和非法车辆（非法载人、非法改装、逾期未报废、逾期未年检、无牌无证、套牌假证）季度摸排工作机制。县级道安办负责建立季度通报制度。（责任单位：县、乡镇人民政府，县级道安、公安、交通运输、教育、农业、渣土办等部门）

（二）全面落实市公安局、市经贸委、市工商局、市质监局《关于加强摩托车管理指导意见的通知》（莆公综〔2013〕398号），组织开展无牌摩托车专项整治行动，健全常态管控机制。各级公安部门负责建立月通报制度。（责任单位：各级人民政府及管委会，各级公安、经贸、工商、质监、交通运输、财政等部门）

（三）全面落实全省渣土车综合整治泉州现场会和《莆田市人民政府关于进一步加强渣土车安全监管工作的实施意见》(莆政综〔2013〕140 号)的要求，组织开展渣土车（含砂石运输车）专项整治行动。各县（区）人民政府（管委会）完成安全管控信息平台建设，强化源头规范管理。市城市管理执法局负责建立月通报制度。（责任单位：各级人民政府及管委会，市城市管理执法局、公安局、交通运输局、水利局、国土局等部门）

（四）全面落实市农业局、市安监局关于转发《省农业厅省安监局<关于进一步加强拖拉机安全管理工作的意见>》（莆市农机〔2013〕46号）及《莆田市农业机械管理总站转发省农业厅、省公安厅、省安监局、省工商局<关于印发拖拉机报废回收管理办法的通知>》（莆市农机〔2013〕65号）要求，组织开展拖拉机专项整治，强化多功能拖拉机管理。市农机总站负责建立月通报制度。（责任单位：各级农机、公安、经贸、工商、安监等部门）

（五）全面落实《福建省实施<校车安全管理条例>办法》（省政府令第126号) 和《福建省校车服务方案》(闽校车联席会议〔2013〕1号)要求，组织开展校车及集中接送学生车辆专项整治。市教育局负责建立季度通报制度。（责任单位：各级教育、公安、交通运输、安监等部门）

（六）全面开展机动车安全隐患综合整治专项行动，落实公安部、工信部、交通运输部、商务部、工商总局、质检总局《关于开展机动车安全隐患大检查工作的通知》（公交管〔2013〕387号）要求，市公安局、经贸委、交通运输局、外经委、质监局按照职责强化对本辖区内的机动车生产、改装、销售、登记、检验、维修、报废等环节的全过程监管并建立季度通报制度。（责任单位：各级公安、经贸、外经委、交通运输、质监、工商等部门）

（七）全面开展旅游客车的安全整治行动，从2014年1月1日起，交通运输部门全面实行旅游包车业务的网上申请和办理，严格资质准入条件，加大联合执法力度，严厉查处旅游运输经营和道路交通安全的违法行为。市交通运输局建立月通报制度。（责任单位：各级交通运输、旅游、公安等部门）

（八）健全治理车辆超载超限工作长效机制，加快启动已经省政府批准设立、但目前尚未建成的2个治超站（仙游龙华金沙公路治超检测站、秀屿笏石公路治超检测站）建设；督促已启用涵江江口公路超限检测站执法人员到位，完善设施设备；加强重点路段巡查，强化高速公路入口监管，加强货运源头管理，推动治超工作深入开展。市治理车辆超限超载领导小组办公室（简称“市治超办”）负责建立季度通报制度。（责任单位：市治超办，各级交通运输、公安、质监等部门）

（九）全面落实莆田市公安局《关于印发<全市公安机关电动自行车登记管理指导意见>的通知》（莆公综〔2014〕49号）要求，加强电动自行车规范管理；公安、工商部门密切配合，规范电动自行车目录管理和销售。（责任单位：荔城区、城厢区人民政府，各级公安、工商等部门）

（十）严格落实驾驶人培训机构准入要求，市交通运输部门按照驾驶人培训机构准入条件加快整合驾驶人培训机构。市公安交管部门会同交通运输部门每季度向社会公开通报本辖区3年内驾龄的驾驶人交通违法率和肇事率排序前3名的驾驶培训机构，并对其提出限期整改要求。市公安局每季度对事故发生率全市排序前3名的考试机构，予以全市通报批评，限期整改。（责任单位：市交通运输、公安部门）

（十一）继续实施“道路客运安全年”，深化运输企业安全生产标准化建设。全市道路客运企业和危货运输企业安全标准化100%达标。摸清全市货运企业底数，督促货运企业全面落实安全生产主体责任，深化货运企业安全生产标准化建设，年内全市自有5辆以上货车的货运企业安全生产标准化创建达标率达到90%。市交通运输局负责建立月通报制度。（责任单位：各级交通运输、安监等部门）

（十二）严厉打击超速超员超载、疲劳驾驶、涉牌涉证、酒后驾驶、大型货车违法占道行驶、客运车辆不按规定使用安全带等严重交通违法行为，严禁三轮汽车、低速货车和拖拉机违法载人。提高城市交通管理专业化水平，开展城市交通秩序整顿行动。（责任单位：各级公安部门）

（十三）落实客货运车辆、渣土车、校车等重点车辆的动态监管，全市省（市）际班车、旅游客车、校车、出租车、危化车和渣土车的合格卫星定位装置安装率达100%，农村客车合格卫星定位装置安装率达90%以上。（责任单位：各级交通运输、公安、住建、教育、质监、渣土办等部门）

三、强化道路隐患排查治理

（一）严格落实道路建设项目安全设施“三同时”规定，各级安监部门牵头建立道路建设项目安全设施“三同时”监管半年度通报制度。（责任单位：各级安监、交通运输、住建、公安、重点办等部门）

（二）全面完成纳入2014年省委省政府为民办实事项目的道路事故多发路段和危险路段71处整治任务。市预防办建立季度通报制度。（责任单位：各级人民政府及管委会，各级公安、“预防办”、交通运输、住建等部门）

（三）全面完成农村公路安保工程400公里的建设任务（其中仙游135公里，荔城15公里，城厢55公里，涵江105公里，秀屿90公里），建成农村公路100公里（其中仙游45公里，荔城6公里，城厢5公里，涵江20公里，秀屿20公里，湄洲岛2公里，北岸2公里）。健全普通公路（含城市道路）危桥排查及整改工作机制，完成30座危桥改造工程任务（其中仙游8座，荔城5座，城厢2座，涵江12座，秀屿3座）。市交通运输局、住建局分别负责建立季度通报制度。（责任单位：各级人民政府及管委会，各级交通运输、住建部门）

（四）严格落实道路安全隐患路段排查与督办标准，继续抓好辖区道路交通安全隐患排查，提出整治计划。各级预防办建立季度通报制度。（责任单位：各级人民政府及管委会，各级预防办）

（五）全面排查道路交通标志标线和红绿灯设置情况，10月底前全面整治到位。全面排查适合设置中心隔离护栏的双向四车道路段及已呈街道化的国、省、县道路段，可以设置的10月底前全面完成。全面排查已设置中心隔离护栏但爆闪灯和夜间照明装置未设置或损坏的路段，上半年全部设置到位。（责任单位：各级人民政府及管委会，各级公安、交通运输、住建、教育等部门）

四、强化交通安全宣传教育

（一）全面落实《莆田市人民政府办公室关于转发全市道路交通安全宣传教育工作分工方案的通知》（莆政办〔2013〕195号）,健全道路交通安全公益宣传工作机制。各级人民政府继续加大道路交通安全宣传投入，督促各部门和单位积极履行宣传责任和义务。充分落实省委宣传部印发的《关于深入做好道路交通安全综合整治宣传报道的通知》（闽委宣[2014]16号）文件，以此为契机，宣传部门要积极牵头，充分利用社会资源和新闻媒体，开设交通安全宣传专栏，落实公益宣传，形成强大的宣传声势。市委宣传部负责建立月通报制度。（责任单位：各级人民政府及管委会，各级宣传及财政、公安、交通运输、教育、司法、新闻出版、广电、安监等部门）

（二）全面落实市公安局、市文明办、市教育局、市司法局、市交通运输局、市安监局《关于印发<莆田市“文明交通行动计划”实施方案（2013—2015年）> <2013年莆田市“文明交通行动计划”重点工作及责任分解表>的通知》（莆公综〔2013〕301号），健全“政府主导、部门联动、行业尽责、社会协同、全民参与”的文明交通创建工作机制。（责任单位：各级公安、文明办、教育、司法、交通运输、安监等部门）

（三）加强交通安全文化建设，积极拓展交通安全宣传渠道，各县（区）人民政府（管委会）至少建设1处交通安全宣传教育基地，开展形式多样的道路交通安全宣传教育活动。继续完善面向全市机动车驾驶人的交通安全宣传短信发送平台。落实企业交通安全宣传主体责任，抓好重点人群和重点单位宣传教育。出租汽车公司、客货运公司、公交公司从业人员受教育率达到100%。（责任单位：各级人民政府及管委会，各级宣传、公安、教育、交通运输等部门）

（四）开辟道安工作设立交流平台，在各级政务网开辟道路交通安全综合整治“三年行动”工作专栏，作为本地区工作进展、经验交流及典型示范的平台。（责任单位：各级人民政府及管委会）

（五）在“122全国交通安全日”基础上组织推广“莆田市122交通安全周”宣教活动，发动各级各单位广泛开展道路交通安全宣教行动。（责任单位：各级人民政府及管委会，各级公安部门）

（六）将道路交通安全渗透日常教育教学和综合实践，举办学生交通安全知识竞赛，开展交通安全主题宣传教育周教育活动。（责任单位：各级宣传、教育、公安、交通运输等部门）

五、强化道路交通惠民便民

（一）细化落实市道安办、市交通运输局《进一步加强农村客运安全管理实施方案的通知》（莆道安办〔2013〕50号）要求，采取多种方式提高农村客运运力，新增、更新农村客车8辆，建制村客车开通率达97%以上，增加到村班次，改善农村群众出行条件，落实农村出行安全监管措施。（责任单位：各级人民政府及管委会，各级交通运输、公安、安监等部门）

（二）细化市公安局、经贸委、工商局、质监局《关于加强摩托车管理实施方案的通知》（莆公综〔2013〕398号），落实摩托车带牌销售、注册登记、驾驶证培训等惠民便民措施。（责任单位：各级人民政府及管委会，各级公安、交通运输、工商管理、财政、国税等部门）

（三）落实市农业局、市安监局关于转发《省农业厅省安监局<关于进一步加强拖拉机安全管理工作的意见>》（莆市农机〔2013〕46号），各级农业部门将农用拖拉机驾驶人员培训列入阳光工程培训计划，推行拖拉机免费检验和拖拉机报废补贴政策。（责任单位：各级人民政府及管委会，各级农业、财政等部门）

（四）全面落实“流动车管所”等各项交通管理便民措施，在农村派出所及农机站设立交通管理服务站，推行预约服务，方便农村群众办理挂牌、办证、年检、年审、保险等业务。（责任单位：各级公安、农机、交通运输、质监等部门，市保监局）

（五）推进报废汽车、报废拖拉机回收企业在县、乡镇等基层设点开展便民服务。（责任单位：各级经贸、公安、农机等部门）

（六）完成各县（区）人民政府（管委会）城市机动车停车场（含立体式停车场、地下停车场）、渣土消纳场的建设规划，提出年度实施计划，组织查处并纠正随意变更地下停车场等停车设施用途的违规行为。（责任单位：各级人民政府及管委会、管委会，各级规划、住建、公安等部门）

（七）健全道路交通事故应急救援机制，加强道路交通事故应急救援体系建设，完善应急救援预案，配足救援设备，定期组织演练，提高施救效率。完善道路交通事故快速处理及调解等便民措施，加快建设事故快速处理中心，健全交通事故多元化调解机制，有效化解矛盾纠纷。（责任单位：各级人民政府及管委会，各级公安、交通运输、司法、法院、消防、卫计、安监等部门）

（八）继续严格落实客运车辆凌晨2至5时停止运行制度及长途客运接驳运输试点工作，做好客运车辆夜间停车休息点的服务、治安和消防管理工作。（责任单位：各级人民政府及管委会，各级公安、交通运输、公安消防等部门）

六、强化重点乡镇跟踪督办

（一）对去年我市10个发生亡人交通事故死亡7人以上的乡镇（华亭15人、霞林14人、镇海12人、黄石11人、笏石11人、拱辰10人、龙华9人 、榜头9人、枫亭8人 、江口7人，共106人，占全市总量47.96% ）进行重点督办，把这10个乡镇列入道安工作重点地区。

（二）以上10个重点乡镇要加强道路交通形势研判并采取有效措施，市县两级道安办要密切跟踪关注、及时督促落实，切实扭转交通安全严峻形势。
