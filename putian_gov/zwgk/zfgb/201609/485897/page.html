莆田市人民政府关于贯彻落实国务院计量发展规划（2013-2020年）进一步加强计量工作的通知

莆政综〔2016〕24号
来源:政府办 时间：2016-03-18 15:56
| | | |

各县（区）人民政府（管委会），市政府各单位、各直属机构，各高等院校，各大企业：

　　为深入贯彻《国务院关于印发计量发展规划（2013-2020年）的通知》（国发〔2013〕10号）、《福建省人民政府关于贯彻落实国务院计量发展规划（2013-2020年）的实施意见》（闽政〔2015〕17号），努力提升我市计量工作水平，现结合我市实际，就进一步加强计量工作通知如下：

　　一、工作目标　　

　　到2020年，计量标准和量传溯源体系更加完善，计量科技基础更加坚实，计量法制建设更加健全，产业计量、民生计量、生态计量等领域工作深入推进，计量服务保障能力基本适应我市经济及社会发展需求。

　　（一）计量保障能力显著提升。全市共建立社会公用计量标准110项，在现有基础上增加30%以上。全市量传溯源体系覆盖率达到95%以上。

　　（二）计量科研创新显著加强。争取承担省部级计量科研项目1项；争取承担国家或地方计量技术规范、标准制修订2项；申请建立省级产业计量检测中心2个，建设完成省级中小企业计量服务平台1个。初步形成适应我市产业集聚发展和转型升级需要的计量测试服务支撑体系。

　　（三）计量监管水平显著提高。国家重点管理计量器具受检率达到95%以上；生产领域重点计量器具产品质量省级监督抽查平均合格率达到90%以上，重点定量包装商品净含量抽检合格率达到95%以上，国家、省级监督抽查合格率高于全省平均水平；引导并培育200家以上诚信计量自我承诺示范单位。

　　（四）计量队伍素质显著增强。计量人才队伍总量扩大、结构进一步优化，高层次计量人才紧缺状况得到有效缓解，培养一支在国内或全省有影响力的领军人物和学科带头人队伍。到2020年，我市的省级专业计量技术委员会委员达到5人以上；法定计量检定机构和授权机构的检定人员100%取得国家规定的资质，一级注册计量师比例达到30%以上；大型企业及重点用能企业配备专兼职计量管理人员，企事业计量人员业务水平持续提升。

　　二、主要任务

　　（一）加强计量技术保障能力建设

　　1．推进量传溯源体系建设。立足我市产业结构特点，加快食品安全、安全防护、节能减排、环境保护等重点领域的市级社会公用计量标准建设，形成与我市计量法制监管、战略性新兴产业同步发展，与我市经济社会转型升级和民生保障需要相适应的量传溯源体系。新建市级社会公用计量标准25项，总数达100项。在食品安全领域，新建常用玻璃量器检定装置、液质联用仪校准装置、气质联用仪校准装置、离子色谱仪校准装置、发射光谱仪校准装置、红外测油仪检定装置、自动电位滴定仪校准装置等7项社会公用计量标准；在医疗卫生领域，新建呼吸机气体综合检测仪校准装置、血液透析机质量检测仪校准装置、输液泵质量检测仪校准装置、便携式除颤器质量检测仪校准装置、医用注射泵和输液泵校准装置、便携式血糖分析仪校准装置、电子血压计检定装置等7项社会公用计量标准；在节能减排领域，新建量热仪检定装置、定硫分析仪检定装置、工业自动分析仪检定装置等3项社会公用计量标准；在环境保护领域，新建大气采样器检定装置、粉尘采样器检定装置、硫化氢报警器检定装置、氧气报警器检定装置、一氧化碳报警器检定装置等5项社会公用计量标准；在民生等其他领域，新建水准仪检定装置、经纬仪检定装置、引伸计检定装置等3项社会公用计量标准。

　　仙游县法定计量技术机构要加强符合当地产业特点的计量检定校准能力建设，到2020年新建县级社会公用计量标准3项（天平检定装置、无创电子自动血压计检定装置、水表检定装置），总数达10项。

　　2．提升产业计量测试水平。以市级法定计量检定机构为主体，联合其他计量技术机构、高等院校、科研院所、企（事）业单位等相关机构，围绕高新技术产业、战略性新兴产业、现代服务业等领域，不断推进计量测试服务公共平台建设，为社会和企业提供实验室开放服务，为我市产业发展提供计量技术支撑和保障。依托市计量所建立省级中小企业计量检测服务平台，为我市中小企业提供管理咨询、信息化体验、技术支持、企业培训等服务；依托市计量所积极争取建立福建省鞋类计量器具检测中心，开展制鞋业专用测量、测试装置的研究开发，完善贯穿产品设计、试验、定型、生产、使用等全过程的产业计量测试服务体系，提升产品质量和效益；依托市计量所积极争取建立福建省医疗健康计量器具检测中心，为我市医疗计量器具生产、普天药械交易、医疗卫生机构使用计量器具等提供全过程、全方位的计量技术服务，提升我市医疗健康行业的综合竞争力和服务质量。

　　3．加强企业计量检测和管理体系建设。积极引导、督促生产企业特别是大、中型企业加强计量基础设施和计量检测设备的投入，建立符合要求的各类计量实验室，积极开展计量科技创新和技术攻关。引导企业积极采用计量精准化管理方法，在生产加工、工艺控制、产品检验等关键环节合理配置计量器具，应用信息化技术实现计量检测数据的远传采集、分析统计和有效运用。引导大中型企业按照国际标准建立测量管理体系，推动小型企业落实国家规定的计量检测规范要求，进一步夯实企业计量基础，提升计量管理水平，促进节能增效、提升质量、创建品牌。

　　4．促进莆台计量交流合作。充分发挥莆田对台交流交往密切的优势，通过学会、协会、同业公会等行业组织开展互访、学术研讨等活动，加强莆台在计量检测技术和方法研究、高层次计量专业人才培养、科研项目成果推广等方面的交流与合作，推进莆台计量检测校准证书互认，积极为我市台资企业提供优质的计量技术服务，扶持台资企业健康发展。鼓励计量技术机构开展海西学术交流、项目合作、量值比对，在制鞋业、机械五金、塑胶塑料、食品加工、电子通信等领域拓展合作的广度和深度，联合打造莆台两岸公共检测服务平台，促进我市外向型经济发展。

　　（二）加强计量科学技术研究

　　1．加强计量科技创新和成果转化。围绕我市支柱产业、新兴产业和传统产业发展，积极开展应用型检测技术研究攻关和成果应用，承担省部级计量科研项目，逐步提升专业计量测试水平，适应产业转型升级需求。发改、质监、经信、科技等部门要鼓励、支持计量科学技术创新，推进“产学研检”相结合的计量科技创新体系建设，促进计量技术机构与科研院所、高校、大型骨干企业计量创新成果的融合。

　　2．积极参与计量技术规范制（修）订。针对节能减排、安全防护、医疗卫生等重点领域计量技术规范空白，积极参与国家或地方计量技术规范的制修订，满足量传溯源的需要，促进科研水平的提高和对科研成果的应用。

　　（三）加强计量监督管理

　　1．强化民生计量监管。加强食品安全、贸易结算、安全防护、医疗卫生、环境监测等与群众切身利益紧密相关领域的计量监管，在集贸市场、商店超市、医院、眼镜店、加油站、公路计重收费站等领域推行计量器具强制检定结果公示制度，依法接受社会监督。对全市乡镇（街道）卫生院、社区卫生服务中心、村卫生院（所）等医疗计量器具和集贸市场衡器实行免费检定。加强对定量包装商品的监督管理，健全定量包装商品生产企业监督检查机制，对电子秤、地中衡、加油机和定量包装商品有针对性地开展计量专项检查和整治，维护人民群众合法权益。

　　2．强化安全计量监管。加强与安全相关计量器具生产、销售、维修、使用环节的监管，加大对安全用计量器具产品的监督抽查力度。加强各相关行业安全用计量器具强制检定，督促使用单位建立完善安全用计量器具的管理制度，按要求配备满足安全生产要求并经检定合格的计量器具，强化使用单位主体责任，加强检定情况通报，提高综合监管效能。

　　3．强化能源计量监管。开展能源计量数据采集、监测和应用，实现对全市年综合能耗5000吨标煤以上重点用能企业、大型公共机构等的能耗数据采集和监测。切实加强能耗数据的分析、应用，为各级政府和企事业单位加强节能管理、落实节能奖惩措施以及碳排放管理机制建立提供依据，促进节能减排目标的实现。加强对供（用）能单位能源计量器具配备、检定（校准）的监管，督促重点耗能企业按照强制性国家标准要求配备能源计量器具；鼓励计量技术机构发挥自身优势，积极为企业开展能源审计、能效检测、合同能源管理以及第三方能源审核等节能技术服务。

　　4．严厉打击计量违法行为。加强计量作弊防控和监管技术研究，完善对重大计量违法案件的快速反应和执法联动机制，各级质监、经信、公安、安监、环保、住建、卫计、交通、工商、食药监等部门要加强协作配合，加强对重点行业计量违法行为的集中整治和专项治理。严厉查处使用不合格的计量器具或者故意破坏计量器具准确度的行为；严厉查处短斤少两等损害消费者利益的违法行为；严厉查处能效标识虚标和商品过度包装行为；严厉查处重点用能单位不按规定配备、使用能源计量器具，以及不按规定开展能源计量数据在线采集、实时监测的行为。

　　5．建立诚信计量长效机制。以提升城市文明为着力点，深入开展“计量惠民生、诚信促和谐”活动，大力推进民生计量诚信体系建设，建立完善“政府部门推动、企业经营者自律、社会各界监督”三位一体的诚信计量长效运行机制，营造诚实守信、公平公正的良好市场氛围。按照依法检定和规范的要求，加强计量技术（校准）机构公信力建设，确保计量检测（校准）数据公正、准确，加强行业自律，严禁违规收费，优化计量服务环境。将诚信计量纳入社会信用体系，建立诚信计量信用信息收集与发布和计量失信“黑名单”制度，完善守信激励和失信惩戒机制。

　　三、保障措施

　　（一）加强组织领导。各级政府要重视计量工作，加强对计量工作的领导,及时研究制定支持计量发展的政策措施，解决工作中遇到的重大困难和问题。质监部门要依法履行计量行政主管部门职责，加强对计量工作的统筹协调、组织实施和督促指导。各有关部门要各司其职，加强配合，制定相应的配套措施，狠抓工作目标任务的落实。

　　（二）加强经费保障。市政府结合本区域经济社会发展实际需要，保障计量监督、技术机构能力提升等重点工作的资金投入。对全市乡镇（街道）卫生院、社区卫生服务中心、村卫生院（所）等医疗计量器具和集贸市场衡器检定所需的强制检定经费，按省、市政府出台的文件要求的免费检定项目，列入财政预算。对列入市科技计划的项目，市级科技资金给予支持。

　　（三）加强队伍建设。完善我市注册计量师和计量专家人才库，加大计量技术和管理人才的引进力度，将紧缺急需的高层次计量专业人才列入我市年度人才引进指导目录，享受人才引进的有关优惠政策和措施。支持技术骨干参加国际、国内计量技术交流以及知名计量技术机构的重要项目研究，加快计量专业学科带头人的培养。加强企事业计量人员配备和业务技能培训，提高企事业计量人员整体素质。

　　（四）加强计量宣传。采取计量走进社区（学校）、开放计量实验室等方式，倡导“度万物、量天地、衡公平”的计量文化，大力宣传计量在科技进步、经济发展、保障民生、节能减排、安全生产等方面的重要地位和作用；通过“5·20世界计量日”、“3·15国际消费者权益日”、“质量月”、“科技活动周”等活动，加强对计量基础知识的普及与宣传，提高全民科学计量意识。

 

　　莆田市人民政府              

　　2016年3月14日
