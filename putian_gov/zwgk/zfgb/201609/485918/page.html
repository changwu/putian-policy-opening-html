莆田市人民政府办公室关于做好《莆田年鉴》（2015年卷）组稿工作的通知

莆政办〔2016〕70号
来源:政府办 时间：2016-04-18 16:56
| | | |

　　各县（区）人民政府（管委会），市直各单位，莆田学院、湄洲湾职业技术学院：

　　《莆田年鉴》是逐年记载我市经济、政治、文化、社会发展情况和成就的史料性文献，具有较高的存史资政价值。为做好《莆田年鉴》（2015年卷）组稿编纂工作，现将有关事项通知如下：

　　一、要高度重视《莆田年鉴》（2015年卷）组稿编纂工作。各单位要积极配合《莆田年鉴》编辑部做好《莆田年鉴》（2015年卷）有关专题稿件的撰写工作，加强组织领导，指定专人具体负责本单位组稿编撰工作，切实按照《莆田年鉴》（2015年卷）编写大纲的要求及时完成本单位编纂工作任务。

　　二、要认真做好文稿选题工作。《莆田年鉴》（2015年卷）收录范围，原则为2015年度（即2015年1月1日至12月31日）发生在莆田或与莆田密切相关的大事、要事。个别跨年度的连续性工作，可以适当简介相关背景。各承编单位组稿工作要紧紧围绕市委、市政府的中心任务，结合本单位实际，充分反映2015年我市建设“宜业宜商宜居”莆田的生动实践，如实记述经济社会发展进程中所做的重要工作以及所取得的主要成就，彰显时代特征、年度特点和地域特色。

　　三、要按时保质保量完成撰稿任务。各承编单位要按照《莆田年鉴》（2015年卷）设定的篇目要求撰写（各单位也可根据自己的实际情况适当地增减条目内容），应做到文体正确、文字精炼通畅，注意资料的全面性、真实性、准确性和连续性，提倡写300—500字短条目，避免直接将年度工作总结报告、新闻报道等作为年鉴稿件。2016年4月30日前，将本单位承编的文稿一式两份报本单位主要领导审核签字，并加盖单位公章后，报送《莆田年鉴》编辑部。同时，将电子文稿与随文图片发至电子邮箱：ptfzw@163.com。

　　《莆田年鉴》编辑部地址：莆田市政府1号楼144室,联系人刘剑星，联系电话2761662；市政府2号楼427室，联系人程李花，联系电话2681963。
