莆田市人民政府关于进一步深化三集中三到位改革提升行政服务中心标准化建设水平的实施意见

莆政综〔2016〕58号
来源:政府办 时间：2016-05-23 16:37
| | | |

各县（区）人民政府（管委会），市政府各单位：

　　为进一步深化行政审批制度改革，加快推进政府职能转变，不断提升行政服务效能，根据《国务院办公厅关于简化优化公共服务流程方便基层群众办事创业的通知》（国办发〔2015〕86号）、《福建省人民政府关于进一步规范行政审批行为改进行政审批有关工作的通知》（闽政〔2015〕68号）等文件精神，市政府决定在全市进一步深化行政审批“三集中三到位”改革，提升行政服务中心标准化建设水平，现提出如下实施意见。

　　一、总体要求

　　深化行政审批“三集中三到位”改革工作（即部门行政审批职能向一个科室集中、承担审批职能的科室向行政服务中心集中、行政审批事项向网上办事大厅集中，做到审批事项进驻中心到位、授权到位、电子监察到位），按照审批和监管职能分离的原则，从制度上彻底改变我市现有审批运行方式，有效解决行政审批“两头审批”、“体外循环”、授权不到位等问题，实现阳光审批，进一步改善全市经济发展软环境、优化和提升区域竞争力，建设服务型政府。

　　二、工作目标

　　以持续深化行政审批“三集中三到位”为抓手，借助现代信息技术，大力推进部门审批职能相对集中、网上办事大厅建设、行政服务中心标准化和审批项目联审联办等工作，着力提升行政服务效能，推动政府相关审批部门不断优化再造审批流程。除涉密事项外，确保市级所有行政审批部门和审批服务事项（含中央及省直垂管部门），100%进驻行政服务中心及其分中心、网上办事大厅和纳入《行政服务中心标准体系》管理，部门100%审批服务事项由一个科室审批，并充分授权到位、电子监察到位，努力实现审批环节简约化、审批手续便捷化、审批过程快速化。

　　三、工作重点

　　（一）整合部门行政审批服务职能。具有行政审批职能的市直各部门应对照《莆田市人民政府关于公布市级行政许可事项目录的通知》（莆政综〔2016〕45号）和《莆田市行政审批制度改革工作领导小组办公室关于公布市级公共服务事项清单的通知》（莆审改办〔2016〕5号）文件, 在不增加内设机构、人员编制和中层职数的前提下，除法律法规明文规定或其他特殊情况外，原则上均应合理调整部门内设机构设置，将本部门行政审批职能划归到行政审批科，实现部门审批服务的职能、事项、人员相对集中；审批职能、审批事项较少或审批频率较低的，应将行政审批服务统一明确由某一业务科室承办，并加挂行政审批科牌子，并可以承担政策法规等其他职能。具体审批服务职能整合及内设科室设置意见，由部门结合工作实际提出，报市委编办按程序办理；垂直管理部门的机构调整改革或“三定”方案，应按要求报请上级主管部门作相应调整。市委编办应加强业务指导，积极争取省委编办的大力支持，分批审核各相关部门内设科室职能调整意见，重新批复“三定”方案。同时，凡不需要集体研究的审批事项，各部门原则上必须把审批的各环节（含预审、受理、审查、踏勘、公示、论证、评估、听证、审批等）全部授权给行政审批科由窗口实施；确需领导把关的审批事项，各部门要调整领导分工，将行政审批服务工作归口一名分管领导负责，确保分管领导到窗口定期值班和现场审批，形成“一般事项全部授权到位、个别重大事项集体研究”的高效审批决策机制。（牵头单位：市委编办、市行政服务中心管委会，责任单位：市直各相关部门，完成时限：2016年9月）

　　（二）确保部门对进驻窗口授权到位。按照“窗口围绕群众转，后方围绕窗口转”要求，各部门要将所有行政审批和公共服务事项进驻行政服务中心和网上办事大厅，纳入《行政服务中心标准体系》规范管理，并对进驻中心窗口充分授权，下达窗口授权书，刻制审批专用章，确保窗口独立运行、现场审批，真正实现“一个领导分管、一个科室审批、一个窗口对外、一个审批专用章办结”的窗口运行模式。完善即办制度、限时办理承诺制度和重大项目联审联办制度；一般审批服务事项，应实行“一审一核”直接办结，逐步提高当日办结率；承诺及上报事项，除集体研究外，其他审批环节必须由窗口办理；加快推进省市联合审批、部门并联审批和“多证合一”审批改革。除法律法规明确规定以及证照批复需携带至福建省外使用的情形外，批复文件或证照均应统一使用审批或业务专用章，效力等同于部门公章。（牵头单位：市行政服务中心管委会、市审改办，责任单位：市直各进驻部门，完成时限：2016年12月）

　　（三）创建行政服务标准化管理品牌。严格按照国家标准委第二批社会管理和公共服务综合标准化试点单位建设标准，以巩固中心标准化建设成果、提高标准化管理水平、塑造标准化服务新形象、提升标准化品牌价值为目标，突出重点、突破难点、提升亮点，创标准化管理新样板、立行政服务新标杆，通过标准化促进政府治理能力现代化，推动政府职能向创造良好发展环境、提供优质公共服务转变，努力建设集行政审批、公共服务、资源配置、信息公开、管理协调、投诉监督六项功能于一体的综合性政务服务平台，确保2017年国家级行政服务综合标准化试点考核验收高质量高标准通过。（牵头单位：市行政服务中心管委会，责任单位：市直各进驻窗口、外设分中心，完成时限：2016年12月前初验，2017年12月前终验）

　　（四）全面推进网上办事大厅建设。推进行政权力、公共服务、部门责任等“三张清单”全部入驻“福建省网上办事大厅”。推动网上年检、网上审批、无纸审批等新型服务模式，2016年全市90%以上的行政审批和公共服务事项要实现网上预审或办理。运用“互联网＋政务”、大数据等新模式、新技术，整合并统一面向企业、公众的互联网服务入口，打造线上线下互补的全市网上办事大厅。推进省、市、县（区）三级服务平台互联互通，推进政务服务全流程电子化和电子监察，做到数据共享、资源整合、业务协同、并联办理，构建跨部门、跨层级、跨区域的网上网下一体化政务服务体系。进一步完善法人库、人口库、电子证照库、空间地理库等基础信息库，逐步形成“一人一档”、“一企一档”。稳步推进电子签章、电子签名、个人实名认证、网上支付、审批结果邮寄等应用服务，实现政务服务的一证通办、一网通办。（牵头单位：市数字办、市行政服务中心管委会，责任单位：市直各进驻部门，完成时限：2016年12月前基本完成网上大厅建设，2017年12月前建立基础信息库和实现全流程电子监察）

　　（五）建立健全行政审批综合协调机制。主动适应经济社会发展、权力放管结合、事中事后监管等简政放权新形势的需要，进一步理顺行政审批管理体制。整合市审改办、市行政服务中心管委会、市效能办、市法制办、市发改委（数字办）的力量，建立定期会商协调机制，负责解决全市行政审批工作中出现的重大问题，统筹解决相关部门职责分工和审批监管工作，加快推进全市网上办事大厅平台建设步伐。会商协调地点设在市行政服务中心。由市审改办、市行政服务中心管委会分别安排专人值班，负责收集、处理部门服务窗口、企业、群众等提出的涉及行政审批需要协调的事项，如遇疑难复杂问题，由市效能办、市法制办、市发改委（数字办）等相关部门参与会商解决。无法协调解决的重大问题，报市政府研究并督促解决，积极营造审批流畅、运转协调、便民高效的政务服务环境。（牵头单位：市审改办、市效能办，责任单位：市法制办、市数字办、市行政服务中心管委会，完成时限：2016年6月）

　　（六）进一步规范行政审批行为。按照公布的行政权力和公共服务事项目录清单，各部门应制定本部门本系统办理事项的审查工作细则，依托审批事项标准化业务办理规程，逐项细化行政许可和公共服务事项的审查环节、审查内容、审查标准、审查要点、注意事项以及不当行为需要承担的后果等信息，同时明确不同环节审查责任，严格规范行政裁量权。由法制部门牵头每季度组织联合开展行政审批和公共服务事项案卷检查；统一执行省政府法制办《行政许可案卷评查标准》，规范《一次性告知单》、《受理承诺单》、《不予受理通知单》、《补齐补正通知单》、《准予行政许可决定书》、《不予行政许可决定书》、《否定报备登记表》、《送达回证》等审批文书，确保受理、补齐补正、审查、决定、送达等环节归档的各类审批文书完整规范。按照省效能办有关文件要求，审批服务事项若无特殊环节应转为当日办结件；没有法律法规设置依据的多层级初审环节应予以取消；确需由县（区）初审的，应由初审部门将有关申报材料直接转报市级部门审核或审批。进一步完善行政审批绩效管理，健全规范审批行为相关考核制度，定期对窗口办事人员进行培训、考核、检查和评定。（牵头单位：市审改办、市法制办、市行政服务中心管委会，责任单位：市直各相关部门，完成时限：2016年9月）

　　（七）加快建立“一张表”审批流程。加快推进我市“多规合一”试点工作，以统一的信息联动平台为技术支撑，创新审批机制，取消法律法规未明确需由县（区）初审或审查的程序，对发改、国土资源、住建、环保、交通运输、水利、林业、海洋渔业、文广、园林等部门的审批事项进行精简再造，加强中介服务机构管理，整合建设项目审批管理流程，重新打造房建、市政、交通、水利、港航、产业等六类项目联审联办机制，实现一表申报、一窗受理、并联审批的“一张表”审批流程，全力服务重点项目建设。（牵头单位：市行政服务中心管委会、市审改办、市效能办、市规划局，责任单位：市发改委、市国土局、市住建局、市环保局、市交通局、市水利局、市文广局、市林业局、市执法局、市园林局、市数字办等市直相关部门，完成时限：2016年12月）

　　（八）推进中介服务高效规范透明运作。进一步规范中介服务事项目录清单管理，今后除目录清单保留的中介服务事项外，审批部门不得以任何形式要求申请人委托中介服务机构开展服务，也不得要求申请人提供相关中介服务材料。各行业主管部门应切实加强对中介组织的监管，督促中介组织建立并严格执行服务承诺制、执业公示制、一次性告知制、合同管理制、依规收费制、执业记录制等“六制”服务。按照“谁主管、谁负责”的原则，严格规范中介服务事项的服务时限等要素，对审批过程中涉及的专题报告或设计文件设定编制、审定、修编等时限参考值。遵循“法律规范、政府监管、行业自律”的思路，健全中介行业协会组织，逐步完善中介组织准入退出、诚信档案、信用等级评价、同业互查、动态监管、通报曝光等相关管理制度，建立自律与监管有机结合的长效机制。（牵头单位：市中介办、市行政服务中心管委会，责任单位：各相关行业主管部门，完成时限：2016年12月）

　　（九）建立重点项目全程代办服务机制。筹建“投资项目代办中心”，设立专职代办员，从在编人员中选拔任用。加快完善投资项目在线审批监管平台，落实投资项目统一代码制度。实施投资项目“一个窗口”收件和审批预登记，编制“绿色通道”记录卡、代办工作流程、代办受理委托书、代办服务手册等程序文件，为省、市重点项目审批手续提供优质、高效的专人全程代办服务。代办服务内容从意向投资者资金确认到位开始，直至项目竣工验收的各阶段审批手续，并无偿提供全过程、全方位的代办或协助办理服务，变投资人跑为代办员跑，变审批事项“多次办”为“一次办”，促进省、市重点项目审批提质提速。（牵头单位：市行政服务中心管委会、市委编办，完成时限：2016年12月）

　　四、工作要求

　　（一）提高认识。“三集中三到位”是推进政府自身改革的有益探索，是深化行政管理体制、创新政府管理方式、优化服务的必然要求，是规范行政权力运行、转变机关作风、提升公共服务质量和增强政府公信力的重要举措，是推进依法行政、加强廉政建设的重要保障。各相关部门要打破传统思想观念、体制机制的束缚，大胆探索、积极创新、狠抓落实，以坚定的决心、过硬的措施、严明的纪律来确保这项工作的顺利实施。

　　（二）加强领导。由市行政服务中心管委会牵头，市审改办、效能办、法制办、数字办、中介办以及相关职能审批部门共同配合，根据各自职能推进和落实好深化行政审批“三集中三到位”改革各项重点工作。各相关部门要实行“一把手”负总责制，将“三集中三到位”改革列入本部门2016年工作重点，确保“三集中三到位”工作顺利进行。其中，市行政服务中心管委会负责总体工作的组织指导和综合协调，筹建投资项目代办中心，并提供全过程、全方位的无偿代办服务，全面推进行政服务中心标准化管理，建立健全行政服务制度，确保国家级标准化试点顺利通过验收；市委编办负责落实好“三张清单”的审核把关和动态调整，指导和审核相关部门内设科室职能的设置调整、整合归并，重新批复“三定”方案；市效能办负责工作推进情况督查；市政府法制办负责牵头定期组织案卷检查，共同做好行政审批和公共服务的监督工作；市数字办负责全市网上办事大厅的软硬件建设；市中介办负责加强对中介组织和中介服务事项的规范清理和监督管理。市直各有关部门是“三集中三到位”的实施主体，要敢于突破体制障碍，积极参与；审批部门的内设科室既要分工明确，又要加强协调配合，形成合力。

　　（三）狠抓落实。各县（区）人民政府（管委会）的推进落实情况，要及时抄送市行政服务中心管委会和市审改办。市行政服务中心管委会要将“三集中三到位”工作情况列入2016年度绩效考核“行政服务情况”指标，加大日常监督检查力度。市效能办要将“三集中三到位”推进情况列入绩效管理察访核验重要内容，加大跟踪督促力度，促进工作落实。

 

　　莆田市人民政府              

　　2016年5月6日
