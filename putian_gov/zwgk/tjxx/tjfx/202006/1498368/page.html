2020年1-5月莆田市经济运行情况分析

第三十期
第三十期
来源：本网 时间：2020-06-18 15:59
| | | |

1-5月，在市委市政府的坚强领导下，全市统筹推进疫情防控和经济社会发展成效继续显现，积极因素不断增加，生产逐步回暖企稳，经济继续呈现恢复态势，主要经济指标降幅收窄，增幅提高。具体表现在：社会消费品零售总额增幅稳居全省首位；规模以上其他营利性服务业增幅保持全省第三；规模以上工业、固定资产投资降幅逐月收窄。

一、经济运行主要特点

（一）工业经济逐步恢复。1-5月，全市规模以上工业增加值可比下降2.6%，降幅比1-4月收窄1.2个百分点。主要亮点：一是新兴产业拉动有力。全市规模以上电子信息产业、化工新材料产业增加值分别可比增长21.0%和5.4%，分别拉动规模以上工业增加值增长1.7个和0.8个百分点。二是新增工业企业贡献突出。9家新投产企业、43家转规企业对规模以上工业增加值增长的贡献率分别达133.8%和23.3%，分别拉动规模以上工业增加值增长3.5个和0.6个百分点。三是工业转型升级步伐加快。全市规模以上战略性新兴产业、高技术企业、装备制造业分别可比增长9.0%、22.1%和4.2%，分别拉动规模以上工业增加值增长2.1个、1.6个和0.6个百分点。

（二）消费市场逐步回暖。1-5月，全市社会消费品零售总额完成645.22亿元，同比下降3.5%，降幅比1-4月收窄1.8个百分点，稳居全省首位。主要亮点：一是生活必需品零售额回升。全市限额以上肉禽蛋类、饮料类商品分别实现零售额1.46亿元、2.74亿元，分别同比增长34.4%和27.4%；限额以上服装类、日用品类和文化办公用品类分别实现零售额13.50亿元、26.45亿元和1.60亿元，分别同比增长65.5%、43.9%和31.4%，共拉动限额以上零售额增长6.9个百分点。二是商品消费升级趋势明显。全市计算机及其配套产品实现零售额0.38亿元，同比增长24.3%；新能源汽车实现零售额1.86亿元，同比增长28.2%。三是满足顾客便利性需求的行业增长较快。与群众生活密切相关的限额以上食杂店和便利店零售额分别增长11.3%和42.9%。四是网上零售持续火爆。限额以上实物商品网上零售额97.85亿元，同比增长20.9%，占限额以上零售额的49.2%，比去年同期提高11.2个百分点。

（三）投资降幅逐步收窄。1-5月，全市固定资产投资同比下降15.3%，降幅比1-4月收窄1.1个百分点。主要亮点：一是制造业投资持续回升。全市制造业投资同比增长3.4%，增幅比1-4月提高2.3个百分点。二是房地产开发投资降幅收窄。全市房地产开发投资完成140.52亿元，同比下降17.9%，降幅比1-4月收窄0.4个百分点。三是基础设施投资降幅收窄。全市基础设施投资同比下降22.0%，降幅比1-4月收窄0.5个百分点，主要是水利管理业、电力、热力、燃气及水的生产和供应业分别增长4.1%和5.7%。

（四）规上其他营利性服务业经营逐步好转。1-4月，全市规模以上其他营利性服务业实现营业收入18.73亿元，同比增长10.0%，增幅分别高于1-3月、全省平均水平2.2个和7.3个百分点，居全省第三位。主要亮点：租赁和商务服务业拉动有力。1-4月，规模以上租赁和商务服务业实现营业收入14.13亿元，同比增长24.2%，拉动规模以上其他营利性服务业营业收入增长16.2个百分点。在新开业的瑞智无忧（福建）科技和云智薪共享经济信息咨询等企业带动下，规模以上人力资源服务业实现营业收入5.46亿元，增长1.3倍，拉动规模以上租赁和商务服务业增长26.9个百分点。在新开业的优之源模架租赁、松琴机械设备租赁和芷文机械租赁等企业带动下，规模以上租赁业实现营业收入1.62亿元，增长1.3倍，拉动规模以上租赁和商务服务业增长8.1个百分点。

二、经济运行存在问题

（一）工业稳增长压力较大。一是停、减产面扩大。5月末，全市规模以上工业停、减产企业614家，停减产面达52.9%，同比扩大19.8个百分点。二是工业出口形势不容乐观。受国外疫情爆发影响，1-5月，全市规模以上制鞋企业出口交货值由上年同期的增长9.5%转为下降5.5%，其中5月单月出口交货值下降15.1%。三是企业经营效益下降。1-4月，全市规模以上工业有99家企业亏损，同比增长39.4%；规模以上工业企业利润总额同比下降9.3%。

（二）消费提效能形势严峻。一是停业企业增多。5月末，全市共有280家限额以上批零企业停业。其中：受订单、资金等因素影响关停企业215家，拉低限额以上批零业销售额增长8.7个百分点；受疫情影响未营业企业65家，商品销售额同比减少32.30亿元，拉低限额以上批零业商品销售额增长4.1个百分点。二是住餐业营业收入负增长。受疫情影响，顾客消费意愿降低、客流量大幅下降、住餐企业经营成本上升，导致全市限额以上住餐业营业收入同比下降17.5%。

（三）投资强发展后劲不足。一是投资增速全省靠后。1-5月，虽然全市固定资产投资降幅有所收窄，但降幅仍超过全省平均水平9.4个百分点，位次比1-4月后移三位。其中：项目投资下降14.6%，降幅超过全省平均水平6.0个百分点，居全省第八位；房地产投资下降17.9%，降幅超过全省平均水平17.6个百分点，居全省第八位。二是新增项目后劲不足。全市亿元新开工项目计划总投资比上年同期下降37.9%，完成投资额下降39.7%。三是超五成行业投资出现负增长。全市投资涉及的16个行业门类中有9个行业投资负增长，下降面达56.2%。其中：卫生和社会工作、教育业、公共管理和社会组织、房地产业投资分别下降14.2%、32.5%、89.2%和20.7%，降幅分别比1-4月扩大2.1个、1.7个、1.6个和1.5个百分点。

（四）规上其他营利性服务业促提升动力不足。一是内部发展不平衡。规上文化、体育和娱乐业、互联网和相关服务业营业收入分别下降54.3%和13.6%，分别拉低规上其他营利性服务业营业收入增长4.7个和2.2个百分点。二是新增企业拉动力不足。2019年退库企业达93家而新增企业仅39家，且新增企业规模普遍偏小，拉动力不足，影响规上其他营利性服务业的持续增长。

三、对策建议

（一）扶持工业经济。一是积极贯彻落实国家一系列财政贴息、大规模降费、缓缴税款等政策，结合我市工业企业生产经营实际困难，实行“一企一策”，继续研究出台阶段性、有针对性减免企业税费政策措施，切实减轻企业成本费用，帮助困难企业度过难关。二是鼓励企业进行创新研发和技术改造，推动企业转型升级，改造提升制鞋、化工、工艺美术等传统优势产业，推动链式集群发展，同时紧抓互联网+、大数据、5G、绿色经济等新经济发展机遇，优化升级工业经济结构，推动数字经济、新材料、新能源汽车和零部件等新兴产业发展。三是鼓励优势企业通过兼并重组、股权转让等形式，清理盘活“僵尸企业”等闲置土地、厂房资源，盘活存量资源提高亩均产出。

（二）活跃消费市场。一是完善市场运行监测体系，加强数据分析研判，密切关注市场供需变化，及时掌握市场动态，积极帮助企业拓宽思路、创新形式，尽快恢复消费者消费习惯，活跃消费市场氛围。二是抓住5G等“新基建”发展、国产和合资新能源汽车提质升级契机和国外因疫情导致进口汽车“有价无市”的可能，积极做好新设备、新能源汽车等更新换代的引导和促进。三是鼓励住餐企业开发特色产品，增加优惠活动力度，吸引客源，同时积极拓展平台、外卖等网上销售方式提高营业收入。

（三）狠抓投资项目。一是采取有力措施加快招商引资，推动项目落地，提升项目审批效率，做好资金、土地等要素保障和后续环节服务，做到筹备一批、建设一批、储备一批，增强投资发展后劲。二是积极排查在建项目，对达到入库条件但未入库的项目，要积极对接，指导企业提供相关材料尽快入库。三是狠抓在库项目建设进度，特别是重点项目进度，积极帮助企业解决项目建设中遇到的问题，督促企业在做好疫情防控基础上加快建设进度，赶上受疫情耽搁的工期。

（四）培育服务业企业。一是继续加大政策扶持力度，注重扶持措施的针对性，特别是对部分受疫情影响较大的行业要加大政策宣传和服务力度，切实解决企业实际困难，为企业营造良好的外部发展环境，最大限度调动企业的积极性。二是鼓励企业创新管理方式和营销模式，主动对接市场，拓展服务领域，充分利用互联网提升线上交易份额，提高市场竞争力。三是强化部门联动，加强行业、产业间互联互通，优势互补，协同发展，推动服务业企业转型升级，培育服务业新的经济增长点。
