1-11月莆田市经济运行情况分析

来源:市统计局 时间：2023-12-22 16:08
| | | |

1-11月，在市委市政府的正确领导下，全市上下坚持稳中求进工作总基调，持续深入开展“深学争优、敢为争先、实干争效”行动，俯下身子抓产业、一心一意谋发展，着力推进绿色高质量发展，生产供给持续增长，投资规模持续扩大，市场消费持续恢复，财政收入持续提速，经济运行延续稳中向好态势。

一、经济运行基本情况 

（一）先行指标走势向好。1-11月，全市工业用电量（扣除抽蓄）同比增长8.3%，增幅比1-10月提高0.3个百分点。公路运输总周转量增长7.7%，增幅比1-10月提高2.4个百分点；水路运输总周转量增长12.9%，增幅比1-10月提高0.9个百分点。11月末金融机构本外币各项存款余额增长8.0%；各项贷款余额增长8.1%。

（二）工业生产持续增长。1-11月，全市规模以上工业增加值同比增长3.6%。一是七成行业正增长。全市33个行业大类中有23个行业增加值实现增长，特别是规模以上化学原料和化学制品制造业，橡胶和塑料制品业增加值分别增长17.3%和13.0%，拉动规模以上工业增加值增长1.5个百分点。二是高技术产业较快增长。规模以上高技术产业增加值增长9.6%，增幅比1-10月提高0.5个百分点，拉动规模以上工业增加值增长0.8个百分点。三是民营企业拉动有力。规模以上民营工业企业增加值增长4.2%，拉动规模以上工业增加值增长3.5个百分点。

（三）投资规模持续扩大。1-11月，全市固定资产投资同比增长1.0%。一是基础设施投资贡献突出。在电力热力燃气及水的生产和供应业投资、交通运输业投资高速增长带动下，基础设施投资增长21.7%，拉动固定资产投资增长5.7个百分点。二是工业投资较快增长。工业投资增长4.1%，增幅比固定资产投资高3.1个百分点，拉动固定资产投资增长1.3个百分点。

（四）市场消费持续恢复。1-11月，全市社会消费品零售总额完成1696.15亿元，增长2.7%，增幅比1-10月提高1.5个百分点。一是生活相关类商品增长较快。限额以上中西药品类、日用品类商品零售额分别增长117.6%和9.4%，共拉动社会消费品零售总额增长0.5个百分点。二是智能化商品持续热销。限额以上智能家用电器和音像器材类、可穿戴智能设备类商品零售额分别增长50.2%和6.5%，拉动社会消费品零售总额增长0.1个百分点。

（五）财政收入持续提速。1-11月，全市一般公共预算总收入234.76亿元，同比增长16.9%，增幅比1-10月提高1.2个百分点，居全省第2位。其中，地方一般公共预算收入150.01亿元，增长7.7%，增幅比1-10月提高2.3个百分点。一般公共预算支出247.17亿元，增长2.9%。

（六）外贸出口降幅收窄。1-11月，全市外贸进出口总额586.9亿元，同比下降3.0%。其中，进口总额291.8亿元，增长6.9%；出口总额295.1亿元，下降11.2%，降幅比1-10月收窄1.3个百分点。

（七）消费价格小幅下降。1-11月，市区居民消费价格同比下降0.2%。八大类消费“五增三降”，其中，其他用品及服务价格上涨3.0%，食品烟酒价格上涨1.0%，教育文化娱乐价格上涨0.6%，生活用品及服务价格上涨0.4%，医疗保健价格上涨0.2%，衣着价格下降0.1%，居住价格下降0.9%，交通通信价格下降3.5%。

二、需关注的问题

（一）工业经济持续回升压力较大。一是减停企业影响较大。1-11月规模以上工业企业减停产面达58.1%，拉低规模以上工业增加值增速10.2个百分点。二是制鞋业仍呈降势。受国外需求下降影响，1-11月规模以上皮革、毛皮、羽毛及其制品和制鞋业增加值下降4.0%，拉低规模以上工业增加值增速1.4个百分点。

（二）部分领域投资低迷。一是房地产投资负增长。受土地出让减少及市场因素影响，房地产开发投资下降7.0%，拉低固定资产投资增速1.7个百分点。二是部分行业投资低迷。受项目个数减少以及部分大项目完工影响，1-11月农业投资预计下降38.4%；社会领域投资下降49.1%，其中教育投资下降64.8%、卫生和社会工作投资下降50.7%。

（三）部分消费领域增长乏力。一是传统商品零售降幅较大。受消费观念转变等因素影响，限额以上服装、鞋帽、针纺织类零售额下降23.5%，拉低社会消费品零售总额增速2.2个百分点。二是汽车类零售低迷。受购置税减免政策到期等因素影响，限额以上传统燃油车零售额下降15.6%，拉低社会消费品零售总额增速0.5个百分点。

三、下一步工作建议

总的来看，1-11月全市经济运行延续稳中向好态势。但也要看到，外部不稳定不确定因素依然较多，经济持续恢复向好基础仍需巩固。下阶段，要坚持以习近平新时代中国特色社会主义思想为指导，坚持“稳中求进、以进促稳、先立后破”，认真实施“深学争优、敢为争先、实干争效”行动，以木兰溪综合治理为总抓手，俯下身子抓产业、一心一意谋发展，不断推动经济运行持续好转、内生动力持续增强、社会预期持续改善，推动经济实现质的有效提升和量的合理增长。

（一）全力稳住工业大盘。一是落实落细各级各项稳经济政策，最大限度释放政策红利，特别是加大对家具制造业、电气机械和器材制造业等持续低迷行业的纾困帮扶力度，缓解企业经营压力，提振企业发展信心。二是加强对鞋服、工艺美术等重点行业的发展动态监测，持续关注市场订单、大宗商品价格、关键零部件供给等形势变化对企业产生的影响，强化对重点企业金融、用工、用能等要素保障服务，力促企业稳产增产。三是进一步梳理减停产企业清单，逐一对接，精准施策，为企业纾困解难，促进市场供需衔接，力促企业复产复工，释放产能。 

（二）全力增强投资后劲。一是加强产业链招商、“一把手”招商、第三方招商、龙头企业招商，谋划一批产业延伸和升级项目，拓展信息服务、现代物流、社会民生等领域招商，吸引千亿工业、服务业产业项目落户我市。二是把握木兰溪综合治理列入“十四五”规划的关口，认真落实市委以木兰溪综合治理为总抓手战略谋划建设更多的木兰溪项目、水利项目、全市项目；围绕中央预算内投资、新增国债、专项债等重点支持领域，策划实施一批新基建、新城建和其他重大项目。三是坚持“要素跟着项目走”，建立健全要素保障主管部门负责制，强化部门协同联动，及时研究解决项目推进过程中遇到的地材保供、土地报征、临时用电等具体问题，扎实抓好项目前期推进工作。 

　　（三）全力促进消费扩大。一是用好恢复和扩大消费的各项政策，抢抓双十二、元旦等消费关键节点，加大促消费力度，提振汽车、家电、家居等大宗消费。二是鼓励企业创新经营模式，加快转型升级步伐，充分利用互联网+物联网，拓展无人配送、在线医疗、网上购物等消费空间，扩大网络零售规模，以高质量的供给催生创造新的市场需求。三是千方百计抓好稳就业促增收，多渠道增加居民收入，进一步提振消费信心。
