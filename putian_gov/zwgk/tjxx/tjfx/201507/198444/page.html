市司法局：第一季度全市社会矛盾纠纷化解情况分析报告

来源：本网 时间：2015-04-20 15:52
| | | |

今年以来，在市委、市政府的正确领导下，市人调办充分发挥自身职能作用，以构建“平安莆田、宜居莆田”为目标，深入扎实开展矛盾纠纷排查调处工作。据统计，1-3月全市各级人民调解组织共受理调处各类社会矛盾纠纷1383件，调处成功1374件，成功率99.35%，防止非正常死亡2件3人，防止民转刑29件121人，防止群体性上访60件359人，防止群体性械斗6 件153人，有力促进了我市社会的和谐稳定。

一、主要做法

（一）加强组织队伍建设。一是成立人民调解群众性社会团体。1月21日，组织成立人民调解员协会，充分发挥行业组织作用，促进人民调解行业自我教育、自我发展和工作交流，推动全市人民调解工作的进一步发展。二是开展“人民调解规范化建设年”活动。年初，主要领导带头深入各县区，召开基层人民调解员座谈会，开展村级人民调解工作调研，并根据调研情况，认真谋划，开展“人民调解规范年”创建活动，推进全市人民调解委员会规范化建设，力争年内全市规范化乡镇（街道）调委会达到100%，规范化村居（社区）及企事业、行业性、区域性调委会达到80%。三是进一步拓展人民调解组织。按照“成熟一个、建立一个”的原则，在巩固道路交通事故、医患纠纷、劳动纠纷等行业性调委会的同时，主动介入纠纷重点地区和行业，建立一批切合实际需求、各具地方特色的行业性调解组织。今年，又先后成立了城厢区龙桥街道环卫工人矛盾纠纷调解室、荔城区企业联合调解委员会，为企业员工提供法律帮助，维护他们的合法权益。四是加强队伍建设。继续推动专职人民调解员配备，北岸开发区面向社会聘请9名具有基层或司法工作经验的专职调解员，平均每个乡镇3名，调处化解矛盾纠纷。开展人民调解员慰问表彰，市县两级对长期扎根基层表现突出的90多名优秀人民调解员进行走访慰问，送去慰问金。仙游县举行仙游县村级人民调解工作先进集体与先进个人表彰仪式，对26个村级规范化人民调解委员会、15名金牌调解主任、47名优秀调解能手、45名优秀调解会长进行表彰，有效调动了广大人民调解员的工作积极性。

（二）加强矛盾纠纷排查。3月27日，市人调办组织召开第一季度全市矛盾纠纷排查工作例会，分析通报全市矛盾纠纷化解情况，并对下一步工作进行部署。组织开展“春节、两会”期间矛盾纠纷集中排查调处活动，组织人员进村入户，开展“拉网式”排查，并把排查的着力点放在各种社会热点难点纠纷和苗头隐患上，做到排查一起、调处一起。如秀屿区成立活动领导小组，抽调4名政策水平高、工作责任心强、农村工作经验丰富、会做群众工作的司法所长和其他司法行政干部参与重点项目纠纷的排查调处工作，促进矛盾纠纷的有效化解。1-3月，全市共排查各类民间纠纷880次，预防纠纷700件。

（三）加强矛盾纠纷化解。充分发挥镇街、村居等基层人民调解组织的第一道防线作用，化解了大量的矛盾。其中，村居调委会共调解纠纷983件，乡镇（街道）调委会共调解纠纷332件。充分发挥医患纠纷人民调解委员会作用，落实预防和处置医患纠纷“五位一体”机制建设，积极化解医患纠纷。全市医调会今年以来共受理26件，调解成功25件，成功率96.15%，调结的纠纷都做到案结事了。积极参与道路交通事故多元化调处工作，全市派驻交通事故多元化调处中心的调解室今年共参与调解纠纷214件，调解成功129件，成功率60.28%。

二、主要特点

    （一）趋势和区域情况分析。1-3月，全市各级人民调解组织共调处矛盾纠纷1383件，同比下降9.78%，其中仙游县同比下降21.85%、荔城区同比下降8.60%、城厢区同比上升38.46%、涵江区同比下降5.94%、秀屿区同比下降28.37%、北岸同比上升31.82%、湄洲同比上升30.77%。

（二）分类情况分析。邻里纠纷、婚姻家庭、房屋宅基地纠纷等是民间的主要纠纷。全市共调处邻里纠纷521件，占总量37.67%；婚姻家庭纠纷150件，占总量10.85%；房屋宅基地纠纷211件，占总量15.26%。与去年同期相比，婚姻家庭纠纷、邻里纠纷、征地拆迁等纠纷数量普遍下降，尤其是征地拆迁、婚姻家庭、环境污染纠纷下降明显，分别同比下降85.71%、 38.27%和66.67%。而房屋宅基地、损害赔偿纠纷有所上升，分别同比上升23.39%和68.75%。其主要原因：一是随着经济的不断发展，农村建房不断增多，房屋宅基地纠纷也随之增多。二是近年来我市损害赔偿调解工作成效明显，群众通过途径调解寻求赔偿的意愿明显增强，人民调解受理案件随之增多。

    三、下一步工作意见

（一）扎实开展“人民调解规范化建设年”活动。大力加强人民调解委员会规范化建设，规范组织、队伍、制度、经费等，提升全市人民调解工作水平。尤其是利用村级换届选举为契机，强化村级人民调解组织建设，选聘好村级调委会主任，加强队伍管理，使人民调解第一道防线作用得到有效发挥。

（二）加强人民调解队伍管理。探索建立人民调解员岗位目标考核制度，合理确定考核内容和指标，改进考核方式方法，推动工作落实。在全市建立星级人民调解员评定和表彰制度，对成绩显著、贡献突出的人民调解员，给予表彰奖励，调动广大人民调解组织和人民调解员的工作积极性。

（三）推动人民调解经费落实。认真落实《省两办转发省司法厅关于加强人民调解工作的实施意见的通知》关于强化经费保障的要求，督促未制订人民调解三项经费保障标准的县区在年内制定出台相关文件；已出台文件的县区落实经费保障，提升基层人民调解组织化解纠纷的能力。
