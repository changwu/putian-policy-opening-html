1-2月全市规上服务业回升向好

第13期
第13期
来源:市统计局 时间：2024-04-03 08:14
| | | |

今年以来，全市上下认真贯彻落实市委、市政府工作要求，坚持稳中求进工作总基调，深化拓展“深学争优、敢为争先、实干争效”行动，服务业经济开局总体平稳，指标增速回升向好。1-2月，全市规模以上服务业实现营业收入54.16亿元，增长1.1%,增速比上年同期提高0.7个百分点。其中，规上其他营利性服务业增速明显回升，实现营业收入20.83亿元，由2023年的下降6.8%转为增长15.6%。

一、运行亮点

（一）科学研究和技术服务业拉动显著。1-2月，全市规模以上科技服务业增势强劲，实现营业收入3.06亿元，增长86.3%，比2022年提高68.3个百分点，拉动其他营利性服务业增长7.9个百分点，成为拉动全市其他营利性服务业增长的主要动力。主要支撑：受合利安项目管理和平行在线设计院两家企业快速增长拉动，专业技术服务业快速增长，实现营业收入2.91亿元，增长96.0%，拉动该行业增长86.5个百分点。

（二）互联网和相关服务、软件和信息技术服务业保持较快增长。受趣播播网络科技和谨诚信息科技两家新增企业拉动，全市规模以上互联网和相关服务、软件和信息技术继续保持较快增长。1-2月，该行业实现营业收入2.49亿元，增长26.9%，增幅同比提高1.9个百分点，拉动其他营利性服务业增长2.9个百分点。

（三）租赁和商务服务业增速明显回升。受荔辰管理咨询、威锐信息科技和创苏网络技术等新增企业拉动影响，1-2月，全市规上租赁和商务服务业止降回升，实现营业收入13.24亿元，增长9.3%，增速比2023年提高21.7个百分点，拉动其他营利性服务业增长6.3个百分点。

（四）重点交通运输业快速回升。1-2月，全市规模以上其他交通运输业实现营业收入1.92亿元，由上年同期的下降19.9%转为增长26.1%，主要受罗屿港口、国投湄洲湾港口、薪壹代（福建）企业服务和八方物流等重点企业较快增长拉动。

（五）新增企业贡献突出。2023年2月以来，全市新增规上其他营利性服务业企业42家，累计实现营业收入5.16亿元，增长4.6倍，对全市其他营利性服务业营业收入增长的贡献率高达150.5%，拉动全市其他营利性服务业增长23.6个百分点。

二、主要问题

（一）交通运输、仓储和邮政业下降明显。受物泊物流业务量大幅下滑的影响，1-2月，全市规上交通运输、仓储和邮政业实现营业收入25.02亿元，下降9.1%，降幅比上年同期扩大2.9个百分点，拉低全市规上服务业营业收入增速4.7个百分点。

（二）生活性服务业负增长。1-2月，全市规模以上居民服务业、修理和其他服务业实现营业收入1.06亿元，下降0.8%，主要原因是缺乏新增企业拉动，且负增长面较大，三成的企业负增长，拉低该行业营业收入增速13.8个百分点；文化体育娱乐业实现营业收入0.98亿元，下降20.3%，主要原因是缺乏新增企业拉动，且该行业规模小容易受退库企业影响而出现较大波动，仅3家退库企业拉低该行业营业收入增速22.2个百分点。

（三）退库企业影响突出。1-2月，全市规上16家停业、注吊销其他营利性服务业企业上年同期营业收入合计2.42亿元，拉低全市其他营利性服务业营业收入增速13.5个百分点。

（四）各县区发展不平衡。近年来，我市规上其他营利性服务业主要靠新增企业拉动，但各县区新增入库情况差异较大。1-2月，荔城、秀屿和仙游其他营利性服务业增速高于全市平均水平，分别为53.1%，49.3%和28.8%；而城厢、涵江、湄洲岛和北岸受停业、退库企业影响，且缺乏新增长点支撑，增速乏力，明显低于全市平均水平，其中城厢仅增长0.4%，涵江增长11.0%，湄洲岛增长4.9%，北岸下降76.7%。

三、建议

（一）抓新增聚合力，统筹推进培育纳统工作。目前我市服务业各行业主管部门对培育纳统工作重视不足，尚未形成有效的工作合力，高质量纳统工作成效还不明显。建议各县（区、管委会）要重视和加强服务业新增长点的招商、培育和纳统工作，由党政主要领导亲自抓，分管领导具体抓，乡镇、街道明确一级责任人；市直各行业牵头部门和具体行业主管部门要加强与市三产办的协调配合，明确责任分工，充分利用五经普调查成果，加大力度推动达规企业新增入库纳统和“大个体转企”工作；对于“准规”后备企业各县区和行业主管部门要加强跟踪培育，重点落实“一对一”帮扶措施，确保年度达规及时入库。

（二）抓重点挖潜力，多措并举提升发展层次。2023年3月-2024年2月，全市规模以上服务业新增入库单位数仅72家，居全省第七位，发展后劲不足，做大增量基础不牢。从行业结构和企业规模、单位数以及区域分布看，我市规上服务业企业数量少、规模小，行业结构不优，新增企业主要集中在租赁和商务服务业。互联网和软件信息技术服务业、科学研究和技术服务业、文化体育娱乐业、居民服务修理和其他服务业、卫生和社会工作行业、教育业等行业新增较少，新增长点支撑不足。大力发展互联网相关行业、科学研究、居民服务、文体娱乐等事关民生改善、创新能力强、高附加值的行业，培育壮大我市薄弱领域的发展规模，进一步优化行业结构。

（三）抓帮扶解难点，精准施策激发企业活力。鼓励在库企业做大做强，分行业精准施策，主动向有需求的重点服务业企业开展帮扶，帮助企业拓展业务范围，扩大产业规模，延长产业链，助力企业发展；对恢复较慢、经营困难的企业开展调研摸排，分类施策，确保企业本地业务不流失，惠企政策效用有效发挥。
