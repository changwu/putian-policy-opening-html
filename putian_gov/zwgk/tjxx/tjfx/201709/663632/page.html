2017年上半年莆田市就业形势分析

来源:莆田市统计局 时间：2017-07-24 00:00
| | | |

截至2017年6月底，我市就业总体保持平稳略增的态势，劳动力市场供求大致平衡。

据一套表联网直报汇总数据显示，2017年6月底，全市共有“四上”单位从业人员47.72万人，较上年同期增加0.86万人，增长1.8%，其中在岗职工45.95万人，同比增长2.3%。按专业分，工业从业人员27.36万人，同比增长3.1%；建筑业从业人员13.97万人，同比下降5.8 %；贸易业从业人员3.50万人，同比增长14.0%；房地产业从业人员6603人，同比下降10.5 %；重点服务业从业人员2.23万人，同比增长31.8%。

从人社部门了解到，劳动力市场供需基本保持平衡，截至6月底全市城镇新增就业11479人，比上年同期减少1086人，实现再就业1581人，与上年同期基本持平，城镇登记失业率约2.48%，比上年同期高0.29个百分点。重点企业岗位监测数据显示，目前全市共有178家重点企业纳入岗位监测，性质主要为有限责任公司、私营、港澳台及外商投资等非公企业，行业分布主要为鞋服制造加工、木材加工等劳动密集型制造业企业，这些企业监测建档期期末从业人数为87896人，至6月底从业人数为87570人，净减少326人，下降0.37%，期间用人单位解除劳动合同的有85人，劳动者解除劳动合同的509人，双方协商解除劳动合同的705人，劳动合同终止的251人。

从本季度主要行业景气调查的情况来看，企业对本季自身经营状况评价普遍认为一般，但较上季度整体评价略高，对下季经营状况预期仍较为保守，持谨慎乐观态度，目前企业用工成本基本保持稳定，工资性支出并非造成企业资金紧张的主要因素，企业本季用工量与上季基本持平，下季度的用工需求并不旺盛，总体保持供求平衡状态，招工难问题仍然存在但影响甚微，本季企业用人需求主要集中在经营管理人员、高级及普通技工，而仍有相当部分企业认为各类人员均不缺。相关数据如下：

1、本季度资金紧张的主要原因前三位分别为：“货款回笼慢”、 “融资难”以及“存货资金占用较多”，选填该项的企业分别为93家、73家、60家，而“工资等刚性支出较多”仍居第五位，选填企业为44家。

2、认为本季度用工需求比上季度上升的企业仅134家，占填报企业的14.5%；认为本季度用工需求与上季度持平的企业有676家，占填报企业的73.0%；认为本季度用工需求比上季度下降的企业有116家，占填报企业的12.5%。

3、在是否存在招工难的问题上，认为不存在的有319家，认为存在但不严重的有207家，认为存在且比较严重的有30家，认为存在且非常严重的仅3家。

4、招工难主要原因前三位分别为：“求职者对薪酬期望过高”、“符合岗位要求应聘者减少”以及“总体求职者人数减少”，选填该项的企业分别有153家、139家和44家。

5、下季度用工计划比本季度增加的企业有97家，减少的企业有99家，而用工计划持平的企业有830家。

6、企业最需要和缺少的人员类型前三位分别为：经营管理人员、高级技工和普通技工，分别有146家、125家和93家企业选填。而选填各类人员均不缺的企业则达到180家。

7、企业对本季经营状况的综合评价，认为良好的有271家，认为一般的有580家，认为不佳的有75家，分别占填报该项企业的29.3%、62.6%和8.1%，总体好于上季度。

8、企业对下季经营状况的预期，认为乐观的有269家，认为一般的有580家，认为不乐观的有77家，分别占填报该项企业的29.0%、62.6%和8.3%。

从企业用工调查的情况来看，上半年抽样的大部分企业经营状况基本稳定，但部分企业利润减少，从业人员数量没有出现大起大落，呈平稳略增趋势，而招工难问题在一定程度上存在但并不严重，主要用工缺口集中在普通用工及高级技工上，未来的用工趋势将处于持平或微增的状态，员工薪酬保持平稳上涨态势，给企业带来一定压力，但不会造成太大影响。

截至报告期（2017年6月15日）我市20家抽样企业利润总额比上年同期增加的仅2家，减少的有7家，另有11家为持平。20家企业共有从业人员4896人，调查期间（2017年1月1日至6月15日）招录员工319人，流失员工358人。调查期间从业人员增加的企业有4家，主要原因前三位为：生产任务或订单增加、季节性用工及企业规模扩大；人员减少的企业有8家，主要原因前三位为：员工因个人原因辞职、生产任务不足以及生产成本上升、经营困难；人员持平的有8家。在薪酬方面，近期所招普通技工（或销售人员、普通服务人员）的月底薪低于2000元的仅2家，处于2000-3000元的占多数，有12家，而3000元以上的有6家，抽样企业中月底薪最低的1700元，最高的3500元。与上年同期相比，底薪不变的有14家，上涨5%以下的有5家，上涨5%-10%的有1家。底薪上涨企业中1家认为底薪增长使得压力明显增大，4家认为底薪上涨有压力但能消化，1家认为压力较小。对于企业用工预期，有2家认为会增加，17家认为持平，4家认为会减少。在用人缺口方面，有7家企业缺少的人员为普通技工（或销售人员、普通服务人员），8家缺少高级技工等技术人员，4家缺少经营管理或科研人员。在招工难问题上，13家认为存在招工难，但不太严重，5家认为不存在，仅2家认为非常严重。而招工难主要原因有7家认为是符合岗位要求的应聘者减少，11家认为求职者对薪酬期望过高，认为总体求职者人数减少和招聘渠道不畅的各1家。

总体而言，根据以上了解到的情况，2017年上半年我市就业基本延续了一季度平缓发展的趋势，劳动力市场供需仍基本保持平衡。“四上”单位就业总量稳中略增,就业总体没有大幅度的波动，但增长速度不如上年同期，各行业各有起落，职工薪酬保持平缓增长，对企业成本不造成太大压力。房地产行业因不少项目扫尾，从业人员增速持续走低，与此同时建筑业从业人员增速持续回落，成为本季减人的主要行业。而本季制造业、贸易业及重点服务业就业人数增速则呈上升趋势，尤其重点服务业增幅有明显提升，长远来看就业增长与否的关键在于第三产业。预计经济下行压力对我市就业发展影响略有减弱迹象，下季度就业增速将保持平稳间或略有波动的趋势。

                                    撰稿：曾莉莎
