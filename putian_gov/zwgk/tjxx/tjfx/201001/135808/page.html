2009年莆田市经济运行形势相关因素分析

来源:调查队 时间：2010-01-31 15:50
| | | |

2009年是新世纪以来我国经济发展最为困难的一年。全市上下在市委、市政府的坚强领导下，深入贯彻落实科学发展观，紧紧围绕党中央国务院、省委省政府关于海西建设的战略部署，主动融入海西发展大局，坚持“四用发展”和“三个持续”要求，大力实施“以港兴市、工业强市”发展战略，积极应对国际金融危机挑战，扎实推进湄洲湾港口城市建设，经济发展呈现“止跌回升、企稳回暖、逐月向好、持续巩固”的良好态势。

一、2009年经济运行的主要特点

（一）民生物价方面：收入稳步增长、就业形势向好、价格稳步回升

1.城镇居民收入平稳增长。据调查资料显示：2009年，全市城镇居民人均可支配收入 17308元，比上年增长10.1%，增幅比全省平均水平高出1.1个百分点，位居九设区市第二位。从城镇居民收入来源渠道看，呈“三增一降”态势。2009年，全市城镇居民人均工资性收入为13207元，比上年增长13.1%，占人均家庭总收入的69.7%，对家庭总收入贡献率为82.4%，拉动家庭总收入增长8.9个百分点；人均转移性收入为2167元，比上年增长12.8%，其中人均养老金或离退休金收入1562元，增长21.7%，占转移性收入的72.1%；人均财产性收入2357元，比上年增长9.8%，其中人均利息收入75元，增长15.2%，人均出租房屋收入2257元、增长12.5%；人均经营性净收入1222元，比上年下降9.7%。

2.农民收入持续增加。据调查资料显示：2009年，全市农民人均纯收入为6921元，比上年增长7.5%，扣除价格因素的影响，实际增长8.6%。主要表现：一是工资性收入较快增长、拉动明显。2009年，全市农民人均工资性收入为3137元，比上年增长13.9%，对农民纯收入增长的贡献率达79.0%，拉动农民收入增长6.0个百分点。二是农民家庭经营纯收入稳步增长。2009年，全市农民人均家庭经营纯收入为2320元，比上年增长3.5%，其中农民人均从家庭经营非农产业得到的纯收入为1062元，比上年增长7.0%。三是财产性收入增长明显。2009年，农民人均财产性收入为155元，比上年增长25.8%，其中农民人均从土地征用得到的补偿收入35 元，增长3.5倍；农民人均租金收入为46元，增长21.6%。

3.农村劳动力就业形势总体向好。一是农村劳动力继续向二、三产业转移。2009年，在被监测调查的农村劳动力中，主要从事第一产业的139人，占农村从业劳动力的35.1%，比上年下降3.9个百分点；从事第二产业的129人，占32.6%，比上年提高0.5个百分点；从事第三产业的128人，占32 .3%,比上年提高3.4个百分点。二是农村劳动力就业地域不断拓展。2009年，在被列入监测调查的农村从业劳动力中有140人外出从业，其中在省内就业的91人、比上年增长2.2%，占农村外出劳动力的65%；在省外、国外从业的49人、比上年增长2.1%，占农村外出劳动力的35%。三是农村劳动力从业收入水平稳步提高。2009年，农民家庭人均从事本地非农自营收入为701元，比上年增长10.6%；人均从事非农务工收入为1897元，比上年增长2.1%；人均外出从业收入为4020元，比上年增长16%。

4.市场价格逐步回升.一是居民消费价格总水平下降幅度逐步缩小。据调查资料显示：2009年，全市居民消费价格总水平比上年下降0.9%，但降幅比前三季度缩小0.9个百分点，其中城市下降0.8%、农村下降1.0%。从调查的八大类居民消费价格变动情况看，呈“四降四升”态势，具体是：衣着类价格下降2.7%、交通和通信类价格下降2.9%、娱乐教育文化用品及服务类价格下降2.5%、居住类价格下降5.1%、食品类价格上涨1.8%、烟酒及用品类价格上涨1.5%、家庭设备用品及维修服务类价格上涨1.7%、医疗保健和个人用品类价格上涨1.7%。二是工业品出厂价格指数前期走低、后期企稳回升。据调查资料显示：2009年，莆田市工业品出厂价格比上年下降0.7%。但从各月份工业品出厂价格指数运行轨迹看，自1月份、2月份的100.7跌落到9月份 98.3的谷底后，10月份开始企稳回升，12月份回升到100.2，运行轨迹与全省基本相似，但波动幅度相对平稳（如图所示）。三是农产品价格总体水平呈回升态势。据调查资料显示：2009年，全市农产品生产价格比上年下降6.4%。但从各季度变动情况看，第一季度至第三季度分别比上年同期下降17.4%、7.1%和3.2%，第四季度比上年同期上涨11.2%，总体呈现逐季回升态势。四是农资价格总水平降幅逐季收窄。据调查资料显示：2009年，全市农资价格总水平比上年下降8.1%，但降幅比前三季度缩小0.5个百分点，其中产品畜类价格下降22.0%、化学肥料类价格下降18.0%、其它农业生产资料类价格下降6.8%、农用机油类价格下降6.0%、饲料类价格下降0.2%、农药及农药械类下降0.2%、半机械化农具类价格下降0.1%、农业生产服务类价格上涨10.7%、农用手工工具类价格上涨8.1%、机械化农具类价格上涨1.8%。

（二）生产与需求方面：规模以下工业生产增速加快、农户投资稳步增长、限额以下商业发展较快

1.规模以下工业增速加快。2009年，莆田市规模以下工业企业生产逐季向好、增速加快，整体形势稳步回暖。据调查资料显示：2009年，全市规模以下工业实现总产值100.92亿元，按可比价计算比上年增长8.1%，增幅分别比前三季度、上半年提高1.4个百分点和3.0个百分点。主要表现在：一是主要行业发展较快。据规模以下样本村个体户调查资料显示：2009年，全市规模以下样本村个体工业户纺织服装及鞋帽制造、皮革和毛皮制品、工艺品制造业、食品制造业完成产值分别为1.64亿元、1.91亿元、0.43亿元、0.09亿元，分别比上年增长20.5%、10.4%、18.0%、9.1%。二是企业营业利润率上升。据规模以下工业目录企业调查资料显示：2009年，全市规模以下工业目录企业产值平均利润率为5.8%，比上年提高0.8个百分点。三是企业经营规模不断扩大。据规模以下工业目录企业调查资料显示：2009年，全市规模以下工业企业不断发展壮大，目录企业平均资产额比上年增长13.5%，其中固定资产净值增长9.5%。

2.农户固定资产投资稳步增长。据调查资料显示：2009年，全市农户固定资产投资完成18.15亿元，比上年增长14.9%。主要表现：一是住宅投资稳定增长。受新农村示范建设、重点工程动迁、建房档次和造价提高等因素拉动，有力促进农户建房投资。2009年，全市农户住宅投资额为16.49亿元，比上年增长18.5%,占农户固定资产投资额的90.8%。二是非生产性投资增长快于生产性投资。2009年，全市农村居民用于非生产性固定资产投资为16.49亿元，比上年增长15.9%；农村居民的生产性投资1.66亿元，比上年增长6.4%，增幅慢于非生产性投资9.5个百分点。三是生产设备购置呈现亮点。2009年，全市农户生产设备购置5136万元，比上年增长40.1%，主要是由于农机补贴资金增加、农户大型机具购置多。如全市乘座式插秧机由上年1台增加到52台，占全省的70%以上。

3.限额以下消费品零售额增长较快。据调查资料显示：2009年，全市限额以下商贸企业及个体户实现消费品零售总额189.81亿元，比上年增长16.3％，占全社会消费品零售总额比重达78.9％。主要表现：一是批发和零售业作为消费品市场的主力军，市场规模效应明显。2009年，全市限额以下批发和零售业消费品零售额为165.31亿元，比上年增长16.1％，占全市限额以下商贸业消费品零售额的87.1%。二是住宿餐饮业增长较快。随着莆田市旅游业的发展和城乡居民生活水平稳步提高以及生活节奏加快，住宿和餐饮业持续较快增长。2009年，全市限额以下住宿餐饮业零售额24.51亿元，比上年增长18.4 %，增幅比限额以下批发零售业高出2.3个百分点。

（三）经济运行质量方面：企业家信心指数、企业景气指数稳步提高

1.企业家信心不断增强。据企业景气监测结果显示：2009年第四季度，企业家信心指数为115.6，分别比第三季度和上年同期上升4.0和4.7点。分行业看：第四季度，工业和建筑业企业家信心指数分别为115.3和126.7，分别比第三季度上升8.5和6.7点。分注册类型看：第四季度，股份合作制企业和外商及港台企业家信心指数分别为133.3和113.0，分别比第三季度上升33.3和8.4点。分规模看：第四季度，大型企业的企业家信心指数为123.2、比第三季度上升3.9点。

2.企业综合景气稳步向好。随着国家一系列政策效应的不断显现，全市企业综合景气指数稳中趋升。据企业景气监测结果显示：2009年第四季度，全市企业景气指数为120.3，分别比第三季度和上年同期上升2.6和11.4点，运行于“中度景气区间”。一是工业企业景气持续提升。第四季度，工业企业景气指数为119.4，分别比第三季度和上年同期上升4.1和5.4点。二是建筑业企业景气度明显提升。第四季度，建筑业企业景气指数为113.3，分别比第三季度和上年同期上升6.7和23.3点。三是房地产企业景气指数大幅上升。第四季度，房地产业企业景气指数为136.4，分别比第三季度和上年同期上升9.1和45.5点，运行于“中度景气区间”。四是批发零售企业景气度高位回落。第四季度，批发和零售业企业景气指数为136.3，比第三季度下降11.8点，但仍在“中度景气区间”运行。

二、当前经济运行值得关注的主要问题

1.城乡居民收入差距不断扩大。城乡居民之间收入差距依旧悬殊，两极分化日益突出。低收入群体生活状况虽然在“保民生”政策的阳光普照下有所改善，但仍不容乐观。据调查资料显示：2009年，莆田市城乡居民收入比由2008年的2.44：1扩大到2.50：1，城镇居民高低收入户人均可支配收入比由2008年的4.66：1扩大到4.71：1.。

2.中小型企业资金紧张问题仍然突出。2009年，在央行实行较宽松的货币政策下，企业流动资金紧张状况有所改善。据企业景气监测结果显示：第四季度，我市企业流动资金和企业融资景气指数分别为109.2和99.2，分别比第三季度上升5.1和6.0点。但中小型企业流动资金和企业融资景气指数分别为87.3和77.3，分别比第三季度下降4.0和2.7点，且分别比大型企业低41.3和38.1点。

3.企业生产成本压力加大。受能源及原材料价格上升、用工成本增加等不利因素的影响，企业生产成本有所上升。据企业景气监测结果显示：第四季度，我市工业、建筑业、交通运输仓储邮政业、批发零售业和信息传输计算机服务软件业企业的生产成本景气指数分别为70.8、66.7、62.5、88.2和17.3，分别比第三季度下降4.6、26.7、25.0、11.8和140.5点，均在“不景气区间”运行。

4.农村养老保险参保率低。据监测摸底调查资料显示：2009年,在被调查的16岁以上农村居民中，只有3.5%参加农村社会养老保险、4.7%参加城镇基本养老保险，有88.4%的农村居民没有参加任何养老保险。

三、2010年经济工作相关因素对策建议

1.多渠道增加居民收入。一是着力提高企业职工工资水平。建立企业职工工资正常增长和保障机制,进一步健全最低工资制度，着力提高企业退休人员基本养老金水平。二是多渠道增加农民收入。建立保证农民收入稳定增长的长效机制,如稳定农产品价格,建立健全粮食储备调节机制;增加国家对农业的投入,改善农业生产条件，切实减轻农民负担。三是消除劳动力与生产要素自由流动的制度化障碍,为城乡居民提供追求自身发展的机会和条件。

2.全力扶持企业发展。各级各部门要切实加强做好企业服务工作，帮助企业解决重点问题，督促各项政策措施落到实处。一是积极落实好国家出口退税政策，提高出口退税的工作效率，全面实施增值税转型，切实减轻企业负担。二是有关部门要牵线搭桥，加强银企合作，为有生产能力、产品有市场的企业提供资金保障。特别针对当前中小企业融资难的问题，采取财政完全担保、适当补贴等方式，支持中小企业融资，简化融资担保手续，完善符合中小企业情况的信贷管理机制，创新中小企业融资产品，大胆推行小额贷款公司、中小企业集资债券和短期融资券试点工作。三是深入企业加强调研，针对各企业遇到的特殊问题，切实做好“保姆式”、“心贴心”的有效服务，促进企业健康有序发展。

3.关注民生、促进就业。一是积极引导农民工就业。积极引导农民工就地就近转移就业；加强与规模大、实力强、受金融危机影响小的企业对接，帮助农民工转移；落实全民创业优惠政策，鼓励农民工返乡创业。二是千方百计增加就业岗位。以劳动力市场和社区劳动保障工作站为平台，深入了解企业用工需求，定期举办用工求职洽谈会，为求职人员提供就业机会。同时，采取缓交各项社会保险基金、降低部分社保金缴费比例等措施，帮助企业实现正常产能，促进员工返岗就业。三是大力扶持全民创业。认真落实全民创业实施意见，严格执行税费减免等优惠政策，鼓励农民工返乡创业，支持下岗失业人员创办各类经济实体。加大对外出务工农民、城镇下岗失业人员培训力度，促使就业观念转变、提高工作技能、掌握创业本领、适应市场需求。
