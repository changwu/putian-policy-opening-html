2009年莆田市工业品出厂价格变动情况分析

来源:调查队 时间：2010-01-21 15:46
| | | |

据调查资料显示：2009年，莆田市工业品出厂价格比上年下降0.7%。但受经济企稳回暖及部分原燃材料价格上涨影响，12月份全市工业品出厂价格比上月上涨0.5%、比上年同期上涨0.2%，是2009年3月份以来首次出现上涨。

一、工业品出厂价格变动的主要特征

从各月份变动情况看，莆田市工业品出厂价格各月指数自1月份的100.7下降到9月份的98.3，10月份开始企稳回升，12月份回升到100.2，运行轨迹与全省基本相似,但波动幅度相对平稳（如图所示）。

从轻重工业品价格变动情况看，2009年重工业产品价格比上年下降20.7%，降幅较大；轻工业产品价格比上年微降0.1%，相对稳定。在重工业产品中，原料类、加工类产品价格分别比上年下降11.1%、23.5%。在轻工业产品中，以农产品为原料的产品价格比上年下降0.8%，以非农产品为原料的产品价格比上年上涨2.5%。

从各部类产品价格变动情况看，2009年生活资料产品价格比上年下降0.1%，生产资料产品价格比上年下降 4.6%，其中原料类、加工类产品价格分别比上年下降3.3%、4.7%，成为带动生产资料价格下降的主导因素。

从主要行业大类产品价格变动看，黑色金属冶炼及压延加工产品、有色金属冶炼及压延加工产品、食品制造产品、化学原料及化学制品、通用设备制造产品价格分别比上年下降24.6%、12.5%、8.1%、6.1%、5.6%。

二、值得关注的几类产品价格

1.金属类产品出厂价格有所回升，但仍较低迷。据调查资料显示：虽然12月份，莆田市黑色金属冶炼及压延加工产品、有色金属冶炼及压延加工产品价格分别比上月上涨2.8%、3.5%。但2009年，莆田市黑色金属冶炼及压延加工产品、有色金属冶炼及压延加工产品价格分别比上年下降24.6%、12.5%；与之密切相关的通用设备、金属制品、交通运输设备、专用设备产品价格分别比上年下降5.6%、4.5%、2.6%、1.3%。

2.食品类产品出厂价格降幅比较明显。据调查资料显示：受部分农产品原料价格降低、出口需求减少以及2008年食品类价格处于相对高位等因素影响，2009年莆田市食品制造、农副食品加工产品价格分别比上年下降8.1%、4.9%。食品类产品价格下降给食品类生产企业经营造成一定影响。据统计资料显示：2009年，莆田市规模以上食品产业产值147.26亿元，比上年增长4.8%，增幅比上年回落15.7个百分点。

3.化学原料及化学制品类出厂价格降幅扩大。据调查资料显示：2009年，莆田市化学原料及化学制品类价格比上年下降6.1%，降幅比前三季度扩大2个百分点。从成本角度看，由于国际油价降幅比较明显，使下游化工原料的生产成本明显降低，为化学原料及化学制品降价提供空间。从需求角度看，尽管当前经济企稳回升，部分化工产品市场需求有所回暖，但市场总体仍显疲软。从价格走势上看，2008年上半年油价高居不下，部分化工产品生产成本比上年同期上升约12%，2008年7月部分企业提高产品出厂价格。但2008年下半年油价下行，至2009年1月部分化工产品生产成本比上年同期下降约20%，部分企业调低产品出厂价格约10%-15%。成本、需求、“一高一低”价格走势等多重因素交织作用，导致化学原料及化学制品类价格跌幅仍呈扩大态势。

4.部分行业产品出厂价格上涨幅度较大。据调查资料显示：受原材料价格、人工费等上涨影响，导致部分行业生产经营成本上升。特别是部分文教体育用品制造企业在2009年初提高了产品出厂价格，虽然后各月产品出厂价格保持稳定，但受产品出厂价格提价翘尾影响，2009年，莆田文教体育用品出厂价格比上年上涨8.7%；非金属矿物制品产品出厂价格比上年上涨6.6%。

5.服装鞋帽、皮革毛皮羽绒产品出厂价格稳中有升。部分企业积极应对金融危机造成的出口需求减少以及人民币升值等造成的影响，及时转变单一外销策略，加强生产经营管理，服装鞋帽、皮革毛皮羽绒产品出厂价格稳中有升。据调查资料显示：2009年，莆田市服装鞋帽、皮革毛皮羽绒产品价格分别比上年上涨0.5%、1.3%，对我市工业品出厂价格止跌回升具有重要带动作用。

三、影响莆田市工业品出厂价格变动的主要原因

1.工业品出厂价格总体水平比上年低的主要原因。一是成本下降推动。自2008年第三季度开始，国际市场上原油、有色金属、铁矿石、农产品等资源性产品价格出现了深度下跌，引起下游相关产品价格的连锁反应，推动各种基础生产原料价格持续向低。虽受经济企稳回升影响，近期部分原材料价格有所回升，但资源性产品价格仍然降幅较大，导致企业生产成本降低，为产成品价格降低腾出空间。据调查资料显示：2009年1-11月，福建省原材料、燃料、动力产品购进价格比上年同期下降7.7%，降幅大于工业品出厂价格降幅2.8个百分点。二是受金融危机影响，市场需求不旺，客观上造成工业品出厂价格比较低迷。2009年1-11月，莆田市实现进出口总值21.1亿美元，比上年同期下降1.3%，其中出口15.2亿美元，比上年同期下降3.2%。三是受上年价格基数较高影响。2008年，由于经济持续增长的惯性，加上原材料、燃料、动力购进价格高位运行，工业品出厂价格处于相对高位。2008年1月，全市工业品出厂价格指数为102.2，且呈平稳向上趋势，至2008年8月份达到最高值102.5。2008年同期价格较高是2009年价格指数回落的重要因素之一。

2.价格回稳主要来自经济向好的发展和预期。2009年，莆田市认真贯彻落实中央和全省应对国际金融危机的一揽子政策措施，保增长、调结构成效显著，总体形势持续向好。一是工业生产持续好转。2009年，全市规模以上工业产值959.26亿元，比上年增长20.7%；工业产销衔接状况良好，产品销售率98.6%；2009年1-11月，工业经济效益综合指数为208.9%，比上年同期提高16.0个百分点。二是投资持续较快增长。2009年，全市城镇以上固定资产投资完成302.04亿元，比上年增长23.9%。三是消费保持平稳增长。2009年，全市社会消费品零售总额为240.56亿元，比上年增长15.8%。经济持续向好为工业品出厂价格回稳提供了有力支撑。
