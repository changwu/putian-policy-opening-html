总体平稳 结构优化——2014年莆田市经济运行情况分析

来源：本网 时间：2015-01-28 15:23
| | | |

第五期

今年以来，在世界经济缓慢复苏，国内经济由高速增长转向中高速增长的“新常态”宏观环境下，莆田市委、市政府主动作为，积极采取一系列“稳增长、促发展”政策措施，全市经济运行总体平稳，GDP、规模以上工业增加值、第三产业增加值等主要经济指标增速居全省前列。据初步核算，2014年，全市GDP实现1502.07亿元，同比增长11.1%，增幅位居全省九设区市第二位。其中，第一产业增加值109.85亿元，增长3.4%，对经济增长的贡献率为2.2%；第二产业增加值866.76亿元，增长11.9%，对经济增长的贡献率达63.4%；第三产业增加值525.46亿元，增长11.4%，对经济增长的贡献率为34.4%。

一、运行主要亮点

（一）总体平稳，结构优化

平稳增长是2014年我市经济运行的一个显著特征。1-3、1-6、1-9、1-12月，全市GDP增幅分别为11.3%、11.0%、10.6%、11.1%，季度之间增长比较均衡。一、二、三次产业对经济增长的贡献率分别为2.2%、63.4%和34.4%，分别拉动GDP增长0.2、7.1和3.8个百分点。产业结构不断优化，转型升级初见成效。三次产业结构由2013年的8.5：58.4：33.1调整为2014年的7.3：57.7：35.0,一产、二产比重下降，三产比重进一步提高。2014年，农、林、牧、渔、服务业产值结构优化由上年的36.2:2.1:17.9:36.4:7.4调整为38.0:2.7:16.2:35.5:7.6。全市高新产业投资增幅由上年的下降18.7%转为增长66.5%；科学研究和技术服务业投资增长1.6倍；高耗能行业投资增幅由上年的增长29.1%转为下降27.5%；工业节能降耗投资增幅由上年的下降41.5%转为增长171.1%，投资结构继续优化。

（二）三次产业全面发展

1、农业生产总体平稳。2014年，第一产业增加值109.85亿元，可比增长3.4%，增幅比上年提高0.5个百分点；全市农林牧渔业总产值199.93亿元，可比增长3.5%，增幅比上年提高0.3个百分点。主要特点：一是设施农业发展较快。全市推广利农模式，促进土地流转，新建大棚果蔬8000亩, 比上年增长40.0%。二是生态养殖业取得进展。今年我市首次推动楼房养猪和大棚养禽，新增生猪3.4万头、家禽80万羽。三是渔业生产增势良好。加快推进后海现代渔业产业园、南日岛闽台渔业产业园等园区建设，南日岛荣获“中国海钓基地”，“南日鲍”荣获国家生态原产地产品保护。全市水产品总产量83.74万吨，增长6.2%。其中海水产品79.53万吨，增长6.3%，淡水产品4.21万吨，增长3.6%。四是园林水果量价齐增。全市园林水果产量22.95万吨，增长14.0%。其中，枇杷产量10.18万吨，增长6.0%；龙眼产量3.83万吨，增长34.0%。园林水果生产价格上涨，同比上涨3.1%。五是农业龙头企业稳步增长。闽中有机食品、华林蔬菜等38家省级以上农业产业化龙头企业实现销售收入150.85亿元,比上年增长5.9%。

2、工业生产稳中放缓。2014年，随着赛得利差别化纤维、滨海化工、祥恒包装、亿发工贸园等一大批富有莆田特色的工业项目建成投产，工业发展后劲增强。全市规模以上工业实现工业总产值2269.93亿元，可比增长13.3%；实现工业增加值696.23亿元，可比增长13.0%。工业总产值与增加值增幅虽然比上年分别回落2.1个、2.3个百分点，但均比全省平均水平高，稳居全省第三位。主要特点：一是亿元企业快速增长。503家产值超亿元企业实现工业总产值2009.17亿元，增长16.9%，增幅比全市平均水平快3.6个百分点，占规模以上工业总产值比重达88.5%，比上年提高1.0个百分点。其中，LNG产值突破百亿元。二是产业集中度进一步提高。鞋服、木材浆纸、食品、电子信息、工艺与创意等十大产业集群实现产值2176.98亿元，比上年增长14.0%，占规模以上工业总产值比重达95.9%。其中，纺织鞋服产业产值644.46亿元，对规模以上工业经济增长的贡献率达31.7%，拉动规模以上工业经济增长4.2个百分点；工艺与创意产业产值279.08亿元，增长18.1%，对规模以上工业增长经济的贡献率达16.1%，拉动规模以上工业经济增长2.1个百分点。三是主要产品增势良好。全市工业产品主要以鞋、服装、家具、涂料、钢材等加工产品为主，2014年鞋产量3.53亿双，增长15.2%；服装6549.96万件，增长11.1%；家具63.99万件，增长27.0%；涂料24.20吨，增长32.6%；钢材107.05万吨，增长127.3%。

3、建筑业快速增长。2014年，全市建筑业增加值完成165.63亿元，比上年增长12.5%，建筑业增加值占GDP的比重为10.9%，比上年提高0.1个百分点。按注册地计算，全市建筑企业（不含劳务分包）完成建筑业总产值480.37亿元，增长29.4%，增幅比全省平均水平快6.9个百分点，居全省九设区市第二位。主要特点：一是十强企业支撑作用明显。我市建筑业综合实力十强企业累计完成产值215.95亿元，比上年增长15.8%，拉动全市资质以上建筑业总产值增长7.9个百分点，十强企业总产值占全市资质以上建筑业总产值的44.9%，近半壁江山。二是新增企业拉动较为明显。35家新增企业完成建筑工程产值16.44亿元，对资质以上建筑业总产值增长的贡献率为15.0%，拉动资质以上建筑业总产值增长4.4个百分点。

4、服务业发展势头良好。2014年，第三产业实现增加值525.46亿元，比上年增长11.4%，增幅稳居全省九设区市第一位。营利性服务业、金融业和批发业增加值分别完成99.42、77.35和61.97亿元，分别增长28.7%、20.4%和12.6%，对第三产业增加值增长的贡献率为40.1%、23.5%和13.6%，分别拉动第三产业增加值增长4.6、2.7和1.6个百分点。今年我市大力开展“以服务换数据，以服务促发展”电子商务与服务外包统计公共平台建设工作，全市已有 130家电商企业入驻正统网，入驻企业数居全省第五位，电商企业在扩大社会消费、增加经济总量、促进莆田产业升级等方面起到了积极的作用。新增九鲤湖、中国古典工艺博览城2个4A级景区、2家5A级旅行社，获得“中华美食名城”荣誉称号。全年预计接待游客1725万人次，增长18%，旅游总收入预计134.50亿元，增长18%。

（三）“三驾马车”拉动有力

1、投资稳中提质。2014年，全市固定资产投资（不含农户）1423.68亿元，比上年增长22.3%，增幅高于全省平均水平3.3个百分点，居全省第三位。主要特点：一是市政建设投资增长迅速。全市市政建设完成投资117.90亿元，比上年增长82.5%，比固定资产投资增速快60.2个百分点。其中，公共设施管理业项目完成投资102.34亿元，增长108.1%；水的生产和供应业项目完成投资11.45亿元，同比增长10.0%。二是新开工项目助推作用明显。全市共有500万元以上新开工项目1589个，比上年增加388个，完成投资771.98亿元，增长43.5%，增速比项目投资快21.3个百分点，占项目总投资的比重为71.7%，对项目总投资的贡献率高达119.6%。三是第三产业投资动力增强。全市第三产业完成投资979.90亿元，增长34.1%，占固定资产投资的比重为68.8%，比上年提高6.0个百分点，对固定资产投资增长的贡献率为96.1%，比上年提高44.0个百分点。四是基础设施投资贡献明显提升。全市基础设施完成投资444.52亿元，增长36.4%，占固定资产投资的比重为31.2%，对固定资产投资增长贡献率达45.8%，比上年提高20.7个百分点。其中：交通运输、仓储及邮政业完成投资203.41亿元，增长51.1%；水利、环境和公共设施管理业完成投资160.05亿元，增长75.2%。五是民间投资主导作用突出。全市民间投资完成804.11亿元，增长31.1%，占固定资产投资的比重为56.5%，对固定资产投资的贡献率高达73.6%，比上年提升17.4个百分点，拉动固定资产投资增长16.4个百分点。

2、消费市场平稳运行。2014年，全市实现社会消费品零售总额480.33亿元，比上年增长12.1%；全市批发零售业销售额完成1338.68亿元，增长18.1%；住宿餐饮业营业额完成54.70亿元，增长8.7%。主要特点:一是批发业快速增长。全市批发业实现商品销售额859.06亿元，增长22.4%，增幅居全省第二位。其中，限额以上批发业商品销售额增长25.4%。二是网上销售增势强劲。全市100家限上企业通过互联网累计实现商品销售额84.38亿元，增长65.5%；实现零售额27.62亿元，增长166.6%，占限额以上零售额的比重为15.8%。网商发展指数位列全国百强城市第18位，零售网商密度第5位，快递业务量和业务收入在全国地级以上城市分别排名第40位和39位。三是亿元企业拉动凸显。131家亿元以上批发零售企业累计实现商品销售额669.71亿元，增长22.6%，对限额以上批发零售业商品销售额增长的贡献率高达86.7%，拉动限额以上批发零售业商品销售额增长17.9个百分点。四是吃穿用类消费回升明显。限上粮油食品饮料烟酒类、服装鞋帽针纺织品类商品零售额同比分别增长43.2%和118.8%，增幅比上年分别提高25.2个和12.9个百分点。

3、出口形势有所好转。2014年，全市外贸出口额33.12亿美元，比上年增长5.0%，增幅比1-11月高1.9个百分点，扣除1月份，为今年最高点。其中12月当月出口3.30亿元，增长13.6%。一般贸易出口20.79亿美元，增长10.6%；加工贸易出口12.32亿美元，下降5.1%。一般贸易出口好于加工贸易出口。全市380家有出口实绩的企业中，佳通轮胎、富力进出口、协丰鞋业等76家出口超千万美元的企业出口额26.85亿美元，增长13.6%，占全市出口总值81.1%。从主要出口市场看，占全市出口总额五成的对美出口额16.58亿美元，增长7.0%；对欧盟出口额4.90亿美元，增长0.8%。从主要出口商品看，占我市出口总额近六成的鞋类出口19.53亿美元，增长14.9%。

（四）经济发展质量向好

1、财政税收较快增长，支出结构优化。2014年，全市财政总收入175.08亿元，增长14.3%，增幅高出全省平均水平2.7个百分点,居全省首位。其中，地方级财政收入110.30亿元，增长16.2%，增幅比全省平均水平高4.7个百分点，高出财政总收入1.9个百分点，居全省首位。地方级收入占财政总收入的比重为63.0%，分别比全省平均水平和上年提高1.3和1.0个百分点。全市财政支出累计完成158.77亿元，同比增长10.1%，涉及民生的教育、文化体育与传媒、医疗卫生与计划生育、住房保障支出分别增长14.2%、55.5%、37.6%、85.2%。

2、工业经济效益综合指数向好。工业生产稳步增长的同时，运行质量得到进一步提升。2014年，规模以上工业经济效益综合指数为292.14，比上年提高8.0个点，工业运行 “稳中提质”。

（五）经济运行保障有力

1、金融运行稳健有序。2014年年末，全市金融机构本外币各项存款余额1450.18亿元，比年初增加155.48亿元，同比增长12.0%，增幅位居全省第二位；其中，人民币存款余额1432.30亿元，增长12.1%。金融机构本外币各项贷款余额1331.44亿元，比年初增加236.61亿元，同比增长21.6%，增幅位居全省第一位，其中，人民币贷款余额1315.32亿元，增长23.3%。

2、利用外资继续向好。2014年，全市共审批利用外资项目25个。按验资口径，合同外资1.27亿美元，比上年下降54.5%；全市实际利用外资（验资口径）3.41 亿美元，增长13.0 %，增幅居全省第三位。

（六）民生建设力度加大

1、物价总体稳定。2014年，全市CPI同比上涨2.0%，涨幅温和，与全省平均水平持平，居全省九设区市第六位，顺利完成年初制定的3.0%的控价目标。八大类商品消费价格“七涨一跌”，食品类价格上涨3.5%，衣着类上涨1.6%，家庭设备用品及维修服务类上涨0.8%，医疗保健和个人用品类上涨0.5%，交通和通信类上涨0.1%，娱乐教育文化用品及服务类上涨2.4%，居住类上涨1.7%；烟酒类下跌0.7%。

2、农村居民收入增速快于城镇。2014年，全市城镇居民人均可支配收入26871元，比上年增长9.0%。其中，工资性收入增长8.9%，拉动可支配收入增长4.7个百分点，贡献率达52.8%；转移净收入增长10.8%，财产净收入增长11.3%，经营净收入增长6.1%。农村居民人均可支配收入12829元，增长10.7%，增幅快于城镇居民人均可支配收入1.7个百分点，城乡居民收入差距进一步缩小。其中，工资性收入增长14.3%，拉动可支配收入增长6.8个百分点，贡献率达63.3%；经营净收入增长7.2%，财产净收入增长15.1%，转移净收入增长7.2%。

二、需关注的问题

（一）工业回升基础不稳。一是工业企业减、停产现象依然严重。我市工业企业主要以劳动密集型和粗放型为主，竞争力总体低下，特别是在当前经济转型升级阶段，工业企业面临内外市场低迷、生产成本加大、融资难、劳动力短缺等问题，导致企业盈利水平下降，停、破产企业增多。近期对379家规模以上工业企业总产值增幅低于10%的调查显示，57.0%的企业反映当前企业用工成本上升,43.0%的企业反映当前企业招工难；53.8%的工业企业反映资金短缺、融资困难；24.5%的企业反映产品销售价格下降。2014年末，全市减产企业仍有185家，占全市规模以上工业企业数近五分之一，累计减产60.2亿元，其中减产超过1000万的规上企业有94家，累计减产56.7亿元，占总减产量的94.2%。另有69家企业停产，影响全市工业产值74.08亿元。减停产企业共拉低全市规模以上工业产值增幅3.7个百分点。二是工业经济结构单一。2014年，我市规模以上高技术产业工业总产值仅占全部规模以上工业总产值比重的7.5%，比上年低0.6个百分点，工业经济市场竞争能力和抗风险能力减弱。全市10家新投产规模工业企业中仅赛得利纤维一家产值超十亿元，工业发展后劲不足。三是企业利润空间继续缩小。受LNG、佳通轮胎、中海燃气发电等大企业利润增速下滑及鞍钢冷轧、赛得利纤维、君合集团等亏损企业亏损额加大的影响，2014年，我市规模以上工业企业利润总额增幅由上年同期增长12.8%转为下降0.2%，比全省平均水平低10.7个百分点，居全省末位。利润的减少影响企业生产的积极性，也将导致2014年增加值及2015年下半年工业增加值率的走低。

（二）消费不旺，内需仍显不足。一是零售业销售额低位增长。2014年全市零售业销售额增长11.2%，增幅居全省末位。其中，限额以上零售业商品销售额仅增5.4%。中石化森美公司等51家限额以上零售业企业销售出现负增长，累计下降额达39.00亿元，拉低全市零售业商品销售额增幅9.0个百分点。二是部分消费热点降温，新的消费热点尚未形成。2014年，全市石油及制品类、汽车类等主要消费领域均呈回落态势，其中石油及制品类零售额增幅同比下降13.6%，汽车类回落同比增长3.7%，增幅比上年回落9.1个百分点。三是房地产市场持续低迷。受购房者观望情绪浓厚、居民收入增速减缓和去年同期基数较高等因素影响，2014年全市商品房销售面积、销售额和本年新开工面积分别下降10.3%、12.3%和18.4%。根据近期我市47家房地产开发企业的问卷调查显示，有93.6%的企业认为商品房销售情况与预期相比“放缓”，有95.7%的企业认为商品房销售情况与去年同期相比“放缓”。

（三）投资增速回落，后劲有所不足。2014年，全市全社会固定资产投资完成1452.44亿元，增长21.9%，增幅比上年回落6.1个百分点。一是工业投资增速放缓。全市工业投资完成406.61亿元，增幅由上年的增长43.6%转为下降0.2%。其中，75个在建亿元工业项目完成投资173.55亿元，同比下降20.5%；制造业投资325.77亿元，增长5.7%，增幅比上年回落28.9个百分点。这在一定程度上说明工业生产后劲在减弱，企业家扩大再生产的意愿不足。二是在建亿元项目支撑乏力。全市在建亿元项目200个，仅占全部施工项目比重9.3%，完成投资343.15亿元，增幅由上年的增长13.6%转为下降14.3%，占项目投资比重31.9%，比上年回落13.6个百分点。其中，本年新开工亿元项目67个，占项目总数比重仅为3.1%；计划总投资295.60亿元，同比下降49.3%，平均每个项目投资规模4.4亿元，只有上年的一半，比全市在建亿元项目平均规模少3.9亿元；累计完成投资126.47亿元，同比下降20.8%。在建亿元项目投资规模逐步缩小，占比也在回落，投资进度缓慢，直接影响经济发展的后劲和质量。三是资金来源同比增速减缓。全市固定资产投资本年到位资金1621.58亿元，增长24.2%，增幅比上年回落0.4个百分点，到位资金增速放缓对投资建设的持续发展影响较大。其中，国内贷款316.42亿元，增长16.7%，增幅比上年回落56.3个百分点，主要受银根持续紧缩影响。

2014年，莆田国民经济取得较快发展的良好成绩，为2015年的进一步发展奠定了基础。但在经济发展中，还存在一些不容忽视的矛盾和问题。2015年，我们要认真贯彻落实党的十八大、十八届三中、四中全会、中央经济工作会议以及省、市一系列工作部署，坚持稳中求进，以改革促发展、促民生改善，推动经济社会持续健康发展。
