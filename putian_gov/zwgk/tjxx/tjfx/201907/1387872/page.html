经济运行稳健 发展预期向好——1-6月莆田市经济运行分析

第三十八期
第三十八期
来源：本网 时间：2019-07-16 15:32
| | | |

今年以来，全市上下积极践行新发展理念，紧紧围绕经济增长预期目标，全力推进经济高质量发展。上半年，全市GDP完成1122.15亿元，可比增长8.1%。

一、经济运行稳健，发展预期向好

1-3月、1-6月全市GDP增幅分别为8.3%和8.1%，增幅保持在8%以上稳中向好区间内，居全省第三位，比1-3月前移一位，经济总体运行稳健，高质量发展态势逐步显现。多数主要经济指标增幅继续在全省“走前头”，其中：固定资产投资、规模以上其他营利性服务业营业收入（错月）、规模以上非营利性服务业营业收入（错月）、实际利用外资四个指标增幅均居全省首位；第一产业增加值、农林牧渔业总产值、农林牧渔业增加值、房地产投资四个指标增幅均居全省第二位；地区生产总值、第三产业增加值二个指标增幅均居全省第三位。

（一）农业生产有序推进。上半年，全市第一产业实现增加值58.09亿元，可比增长3.7%，增幅同比提高0.3个百分点。其中，渔业经济高质量发展，水产品产量稳步增加。全市持续推广“投大苗、养中鲍”等新模式和“鲁龙1号”龙须菜等新品种，进一步提升海带、紫菜、牡蛎、花蛤等传统大宗水产品和鲍鱼等名优特色品种养殖,促进渔业经济高质量发展。上半年，全市水产品总产量61.38万吨，同比增长5.3%，增幅比一季度提高0.4个百分点。

（二）工业经济大盘稳定。上半年，全市规模以上工业增加值可比增长8.4%，增幅虽分别比上年同期、1-5月回落0.5个和0.1个百分点，总体仍保持在8%稳中向好区间内。三大重点产业拉动力提高。上半年，全市规模以上化工新材料、食品加工业、高端装备三大产业分别拉动全市规模以上工业增长2.2个、1.1个和1.0个百分点，均分别比1-5月提高0.1个百分点。工业生产后劲增强。全市74家新增规模企业共拉动规模以上工业增加值增长2.0个百分点。其中，18家去年以来新投产企业拉动规模以上工业增加值增长1.7个百分点；56家2018年底“下转上”企业拉动规模以上工业增加值增长0.3个百分点。

（三）服务业发展良好。上半年，全市第三产业实现增加值459.24亿元，可比增长8.6%，增幅居全省第三位。规模以上服务业贡献突出。1-5月，全市规模以上其他营利性服务业营业收入增长24.8%，增幅高出全省平均水平3.0个百分点，居全省第一位，对全市第三产业增长的贡献率为44.3%。金融业增加值增速提高。上半年，全市金融业增加值64.45亿元，可比增长6.5%，增幅比1-3月提高2.9个百分点，拉动第三产业增长0.9个百分点，比1-3月提高0.2个百分点。其中，全市金融机构人民币存贷款余额（错月）增长7.3%，增幅比2月末提高2.1个百分点；证券交易额（错月）增长23.0%，增幅比2月末提高24.5个百分点。

（四）市场销售稳中有升。上半年，全市实现社会消费品零售总额416.25亿元，同比增长10.3%，增幅比1-5月高0.5个百分点。消费结构升级态势明显。全市限额以上单位商品零售额中，可穿戴智能设备零售额增长230.6%；新能源汽车增长99.5%；智能手机增长31.4%。网上零售额快速增长，限上贸易单位网上零售额92.47亿元，同比增长17.3%，比全市社会消费品零售总额高7.0个百分点。部分有店铺零售业绩较好。限上食杂店、便利店实现商品零售额分别增长31.7%和34.2%。餐饮收入保持两位数增长。今年来全市餐饮收入均保持在15%以上，上半年全市限上住宿餐饮业营业收入增长20.4%，增幅快于社会消费品零售总额10.1个百分点。

（五）投资增幅创年内最高。上半年，全市固定资产投资同比增长10.6%，增幅虽同比回落6.1个百分点，但分别比1-2月、1-3月、1-4月、1-5月提高1.5个、7.9个、9.6个和0.3个百分点，创年内新高，比全省平均水平高3.6个百分点。在建亿元项目高速增长。全市199个在建亿元项目投资同比增长67.9%，增幅分别比上年同期、全市固定资产投资高80.1和57.3个百分点。房地产开发投资快速增长。全市房地产开发投资同比增长27.3%，增幅分别比1-5月、上年同期提高3.1个和33.4个百分点，拉动全市固定资产投资增长5.0个百分点；占全市固定资产投资的比重为22.3%，同比提高2.8个百分点。工业投资快速增长。全市工业投资同比增长14.2%，增幅分别比1-5月、上年同期提高5.0个和6.4个百分点，拉动全市固定资产投资增长3.7个百分点；占全市固定资产投资的比重为28.6%，同比提高0.8个百分点。其中制造业投资同比增长21.7%，增速比1-5月提高7.8个百分点。

二、民生保障有力，人民幸福感增强

（一）物价温和上涨。上半年，全市市区居民消费价格同比上涨1.5%，涨幅比1-3月回落0.3个百分点。八大类价格呈“七升一降”态势，食品烟酒类上涨2.9%、教育文化和娱乐类上涨2.5%、其他用品和服务类上涨1.8%、生活用品及服务上涨1.5%、衣着类上涨1.2%、医疗保健类上涨0.8%、居住类上涨0.5%，交通和通信类下降0.3%。

（二）居民收入继续增加。上半年，全市城镇居民人均可支配收入21509元，同比增长8.1%，增幅比1-3月提高0.1个百分点；农村居民人均可支配收入10999元，增长9.0%，增幅虽比1-3月回落0.1个百分点，但快于城镇居民人均可支配收入0.9个百分点。

（三）就业保持稳定。尽管部分行业受市场影响就业压力有所加大，但在积极就业政策作用下，以及创业创新带动就业的影响下，就业总体保持稳定。据人社部门提供数据显示，截至6月底全市城镇新增就业0.82万人，同比增加0.36万人；实现再就业0.05万人，同比增加0.02万人。城镇登记失业率1.95%，同比下降0.54个百分点，总体保持基本稳定。

三、主要问题

（一）停产减产企业增多，实体经济基础不牢。农业方面，受环保整治影响，上半年，全市生猪养殖企业缩减为50家。工业方面，6月末，全市停、减产面达32.7%，共拉低全市规模以上工业增加值增长8.5个百分点。其中停产企业145家，拉低全市工业增幅4.8个百分点；减产企业247家，拉低全市工业增幅3.7个百分点。商贸方面，114家企业关停零上报，共拉低全市商品销售额增长1.3个百分点；121家销售额（营业额）累计负增长, 共拉低全市商品销售额增长3.1个百分点。服务业方面，18家规模以上其他营利性服务业企业停业，拉低规模以上其他营利性服务业营业收入增长3.8个百分点；62家营业收入累计负增长，拉低规模以上其他营利性服务业营业收入增长18.2个百分点。

（二）工业增速不断靠后，高新技术产业规模偏小。上半年，全市规模以上工业增加值同比增速居全省第7位，位次比1-3月后移3位、比1-5月后移1位。全市高技术企业共74家,仅占全市规模以上工业总数的6.1%，实现工业增加值占全市规模以上工业增加值比重为7.4%，低于全省平均水平5.4个百分点。

（三）基础设施投资负增长，民间投资低位增长。上半年，全市基础设施投资同比下降6.1%，降幅分别比1-5月、上年同期扩大3.1个和18.3个百分点。其中交通运输业投资同比下降17.7%；电力、热力、燃气及水的生产和供应业投资下降19.9%；水利管理业投资下降10.2%。 全市民间投资同比仅增7.6%，增幅同比回落38.2个百分点，低于全省平均水平3.8个百分点，其中项目民间投资增速同比回落69.7个百分点；工业民间投资增速同比回落22.3个百分点。

四、对策建议

（一）力促实体经济稳定增长。在要素保障上，深入贯彻国家、省、市促进工业稳增长政策和服务业发展若干意见，用好用活中小企业融资担保基金和应急转贷资金，深化政银企合作，着力缓解企业融资难。在生产环节上，强化企业科技创新和品牌意识，坚持高标准生产，降低生产成本，提升产品质量，提高自身产品竞争力。在实体培育上，出台培育“四上”企业奖励措施，抓好企业进规入库工作，责任部门每月要对新投产、技改扩规以及规下企业常态梳理，形成储备一批、培育一批、申报一批、入库一批的良性循环，不断壮大实体经济“底盘”。

（二）增强科技创新能力。积极运用新技术、新业态、新模式，加快推进食品、制鞋、工艺等传统产业升级改造，努力提升传统产业发展质效。解决产业结构性问题，推动加工制造业特别是战略性新兴产业、高新技术产业加快发展，切实提升全市经济的整体素质。

（三）继续加大招商引资力度。加强项目储备，提高项目落地率，保证投资项目的接续入库；加快新项目开工建设进度，协调帮助项目单位解决各种困难和问题，促其尽快动工，防止重大投资项目出现断档现象；对部分进展缓慢的重点项目，实行责任到人，月度监督，及时有效解决项目存在的问题，确保项目尽快落地开工。
