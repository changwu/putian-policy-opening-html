前三季度莆田GDP运行简析

第六十九期
第六十九期
来源:市统计局 时间：2021-10-22 11:09
| | | |

初步核算，前三季度，全市实现生产总值2286.10亿元，增长6.6%，增幅比上半年回落5.1个百分点。其中，第一产业增加值95.51亿元，增长3.0%;第二产业增加值1150.77亿元，增长5.2%;第三产业增加值1039.83亿元，增长8.7%。

一、运行特点

（一）从三次产业贡献率看。第一产业贡献率为1.9％，比上半年提高1.0个百分点;第二产业贡献率为39.5％，比上半年提高0.3个百分点;第三产业贡献率为58.6％，比上半年回落1.3个百分点;。

（二）从三次产业拉动情况看。第一产业拉动GDP增长0.1个百分点，与上半年持平。第二产业拉动GDP增长2.6个百分点，比上半年回落2.0个百分点。第三产业拉动GDP增长3.9个百分点，比上半年回落3.1个百分点。

（三）农业生产整体向好。前三季度，第一产业实现增加值95.51亿元，增长3.0%，增幅比上半年提高0.9个百分点。农业产值37.00亿元，增长1.1%；林业产值1.59亿元，增长7.6%；牧业产值27.14亿元，增长5.8%；渔业产值96.68亿元，增长3.8%；农林牧渔服务业产值15.93亿元，增长5.4%。

（四）第二产业稳中趋缓。前三季度，第二产业实现增加值1150.77亿元,增长5.2%，增幅比上半年回落3.6个百分点。全市规模以上工业增加值增长8.4%，增幅比上半年回落5.6个百分点;分三大门类看，采矿业增加值下降2.6%，制造业增加值增长7.7%，电力、燃气、水的生产和供应业增加值增长20.8%。建筑业实现增加值219.95亿元，增长7.7%,增幅比上半年回落6.1个百分点。

（五）第三产业稳步增长。前三季度，第三产业实现增加值1039.83亿元，增长8.7%，增幅比上半年回落7.3个百分点。从第三产业内部看，交通运输、仓储及邮政业实现增加值48.98亿元，增长7.5%，低于全省平均水平8.5个百分点;批发和零售业实现增加值322.69亿元，增长16.0%，低于全省平均水平1.8个百分点;金融业实现增加值120.47亿元，增长5.7%，低于全省平均水平1.1个百分点;房地产业实现增加值137.89亿元，增长11.2%，高于全省平均水平4.9个百分点;营利性服务业实现增加值196.97亿元，增长4.5%，低于全省平均水平4.4个百分点；非营利性服务业实现增加值168.75亿元，增长1.1%，低于全省平均水平3.1个百分点。

二、需关注的问题

（一）工业企业增长后劲不足。停减产面扩大。受疫情影响，歇业企业增加。截至9月末，全市规模以上停、减产企业达399家，停减产面达35.3%，比1-6月扩大11.8个百分点，影响全市规上工业增加值增长4.3个百分点。小微企业增长缓慢。占全市规模以上工业企业数80.1%的规模以上小微工业企业增加值仅增长3.4%，增幅分别低于全市规模以上工业和规模以上大中型企业5.0个和9.2个百分点。

（二）经济增长支撑乏力。支撑GDP增长的多数指标增长缓慢，位次靠后。规模以上工业增加值增长8.4%，比上半年回落5.6个百分点，影响GDP回落1.52个百分点。建筑业总产值增长10.9%，比上半年回落8.5个百分点;建筑安装投资增长23.1%，比上半年回落6.2个百分点;二者影响GDP回落0.4个百分点。批发业销售额增长40.5%，比上半年回落13.9个百分点，影响GDP回落0.44个百分点。零售业销售额增长15.8%，比上半年回落16.9个百分点，影响GDP回落0.87个百分点。房地产销售面积增长28.4%，比上半年回落20.4个百分点，影响GDP回落0.59个百分点。其他营利性服务业营业收入增长15.5%，比上半年回落19.0个百分点，影响GDP回落0.56个百分点。

三、建议

（一）加强工业的主导作用。工业仍是全市经济发展重要的支撑力量，加快传统产业升级，进一步增强全市工业发展后劲。围绕实体企业做实、存量企业做强、小微企业做大的目标，既要促进传统产业更新换代、转型升级，更要引进培育高增加值率企业。强化重点企业的预警监测，加强企业产销衔接和市场开拓，充分激发存量工业产能。

（二）加快发展第三产业。第三产业逐渐成为经济增长的主动力，努力改造传统服务业，提升商贸流通业，引进品牌商家，增强核心商圈聚集功能，推动商贸繁荣发展。发展新兴服务业，积极引导企业发展互联网经济，增强电子商务创业园集聚地功能，打造莆田经济发展新引擎。

（三）提高监测预警服务水平。GDP核算，需要国民经济各行业的统计数据支撑。各相关行业主管部门要各负其责，做好支撑GDP基础指标的月度监测工作，做到早监测、早预警、早报告，及时掌握全市各项基础指标发展情况，预报预警其指标支撑情况及发展差距，为市委、市政府准确研判经济形势及时提供重要参考。
