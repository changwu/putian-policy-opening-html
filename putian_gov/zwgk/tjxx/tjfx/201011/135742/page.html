2009年莆田市儿童监测报告

来源:统计局 时间：2010-11-11 16:07
| | | |

2009年是《莆田市儿童发展纲要2001-2010年》贯彻实施的第九年，在市委市政府的正确领导下，通过各成员单位的积极参与、实践及推动，莆田市儿童发展纲要目标总体进展良好，儿童事业在趋于优化的社会大环境中持续发展，“儿童优先发展”原则得到进一步改善和落实，儿童事业呈现良好的发展态势。

第一部分 分领域进展情况

一、儿童与健康

（一）实施干预措施，努力提高出生人口素质。

1、切实开展科学婚检工作。2009年继续推进免费婚检，不断提高婚检率和婚前保健服务水平，全年共婚检52934人，婚前医学检查率100%（城市、农村均为100%），比上年提升3.16%。同时检出疾病9509人，患病率18.03%，检出HIV阳性4人（男女各2人）。

2、实施预防艾滋病母婴传播工作。为有效控制和降低艾滋病母婴传播的发生率，保护广大妇女儿童的健康，扎实开展预防艾滋病母婴传播，2009年全市婚前/孕前保健检测HIV的妇女人数达到30444人，检出HIV阳性5人，成功实施母婴阻断2例，其中还为1例流动人口艾滋病孕妇进行免费咨询指导、孕期检查和终止妊娠。

3、开展2009年“世界母乳喂养周”的宣传活动。并对全市23家爱婴医院（卫生院）进行专项督查和质量评价，进一步巩固爱婴成果。全市婴儿母乳喂养率达到93.33%，比上年提高0.51个百分点。

4、加强新生儿疾病、听力筛查。2009年县级以上医疗保健机构开展新生儿代谢性疾病、听力筛查工作，共筛查30197例新生儿，筛查弱阳性患儿329例，召回率81.76%；听力筛查17864人，经复查确诊未发现听力障碍者。

5、启动增补叶酸预防神经管缺陷项目。根据项目要求，为我市农村育龄妇女（包括流动人口）孕前3个月和育早期3个月约33894人免费补服叶酸。

（二）加强系统管理，儿童医疗救治水平进一步提高。

1、积极开展儿童保健工作。2009年我市7岁以下儿童保健覆盖率为89.27%，体弱儿筛查率为1.84%，管理率为100%。对0-7岁儿童进行了健康体检，共体检226064名儿童，对筛查的体弱儿童进行专案管理，定期复查，确保儿童身心健康。同时对全市129所托幼机构进行卫生保健指导，指导率100%。2009年传染病发生率为3.62%，体重小于二个标准差比例仅0.99，身高小于二个标准差比例仅1.01，在园儿童的生长发育水平逐年提高。2009年婴儿死亡率为6.46‰，其中城市为6.27‰，农村为6.82‰，同比下降0.66‰、0.66‰和0.65‰。5岁以下儿童死亡率为9.02‰，同比下降0.14‰，其中城市上升0.17‰，农村下降0.72‰。

2、加强儿童医疗救治体系建设。依照省委、省政府的布署，根据我市实际，市卫生局和市财政局联合制定了《莆田市儿童医疗救治体系建设为民办实事工作实施计划》确定2家医院为市级儿童医疗救治分中心、县级儿童重症监护室建设单位，各级投入230万，单位自筹230万，从设备配置、基础设施和人才培养三方面加强项目建设，以提高儿童救治整体功能。

（三）儿童健康趋好，相关指标城乡差距进一步缩小。从监测情况来看，婴儿死亡率从2008年的7.12‰下降至2009年的6.46‰；新生儿死亡率从2008年的7.12‰下降到2009年的4.53‰。3岁以下儿童保健系统管理率为88.34%。2009年婴儿死亡率城市与农村相差基本持平。 5岁以下儿童死亡率城市与农村相比，由2008年相差1.17‰，下降到0.28‰；5岁以下儿童中、重度营养不良患病率城市与农村相比，由2008年相差0.62%，下降为0.58%。低出生体重儿发病率为2.79%，同比略有上涨，幅度为0.03%，城市与农村相比，由2008年相差0.86%下降到0.34%。

（四）抓住工作重点，有效控制孕产妇死亡率。各级卫生行政部门和各级卫生保健机构重视孕产妇系统保健管理工作，把降低孕产妇死亡作为工作重点，落实《关于加强孕产期保健，降低孕产妇死亡率通知》的各项措施，加强孕产妇尤其是高危孕产妇、流动人口孕产妇系统保健工作，孕产期保健工作质量有明显的提高，2009年孕产妇系统保健覆盖率达99.99%，孕产妇系统管理率为83.6%，同比上升0.63%，其中城市为84.31%、农村为82.27%，分别比上年增长0.32%和1.21%。孕产妇产前医学检查率为97.18%，其中城市为96.68%、农村为98.14%，分别比上年提高1.19%、0.85%和1.86%。产后访视率达94.01%，住院分娩率达到99.99%，其中农村孕产妇住院分娩率达到99.98%，农村高危孕产妇住院分娩率达到100%。高危孕妇的筛查率和管理率逐年提高，全市孕产妇系统保健工作步入良性循环轨道。同时积极发挥围产保健协助组作用，抓好业务指导，提高产儿科医务人员的基本技能、应急能力、危重症抢救和转诊能力，提高产儿科医疗保健水平，并加大了对母婴保健助产服务的行政干预力度，分析当年度孕产妇死亡、围产儿死亡病例，提出针对性的干预措施。2009年孕产妇死亡率为19.5/10万，仍在控制范围之内。

（五）儿童计划免疫工作落实。2009年全市继续推进适龄儿童免疫工作，卡介苗、脊灰疫苗、百白破三联制剂、麻疹疫苗接种率分别达到99.9%、99.61%、99.71%和99.2%。乙肝疫苗接种率达到99.6%，同比上涨0.81%。

（一）教育投入加大。2009年我市进一步加大对教育的投入，国家财政性教育经费达到21.68亿元，占地区生产总值的比例从2008年的2.7%提高到3.1%。全市义务教育阶段公办学校全部免除学杂费，对农村义务教育阶段公办学校和城市低保家庭的学生免费提供教科书，享受免费教科书学生的比例从2008年的84.4%提高到今年的87.2%。将中小学生均公用经费标准提高到小学350元/生年、初中生550元/生年。

（二）全面普及义务教育。2009年小学学龄儿童净入学率已连续三年达到100%，其中男女童均为100%。小学六年巩固率达96.83%，其中男童为98.65%，女童为94.68%。小学辍学率为0.28%，其中男童为0.28%，女童为0.27%，均在省定控制范围内。初中阶段毛入学率为109.31%，其中男女生均为109.31%。初中辍学率为1.19%，其中男生1.39%，女生0.97%，均在省定控制范围内。初中三年巩固率为94.2%。做好残疾儿童少年随班就读，全市普通中小学残疾儿童在校学生数2488人，其中女生576人；特殊教育学校在校生442人。残疾儿童入学率达96%。

（三）做强做大优质的高中教育。按照大力发展城市和农村中心集镇普高的既定方针，2009年我市继续鼓励和支持高中阶段学校升级扩容，做大做强优质高中教育，全市普通高中在校生达73080人，高中阶段毛入学率达78.52%，其中男生75.34%，女生82.4%，分别比上年同期增长3.52%、2.37%和5.82%。中等职业学校在校生达51146人。

（四）统筹安排流动人口子女入学。为切实保障流动人口子女接受义务教育的权利，2009年，各县区（管委会）教育局（事务办）都按照“免试就近入学”的原则，明确规定农民工子女义务教育阶段就读学校并对社会公示，同时严格规范对流动人口子女教育教学工作的管理，切实做到“两同等，两优先”,一是在教育教学上同等待遇,二是在学校管理上同等待遇,三是在助学帮困上优先安排,四是在家校联系上优先考虑。依法保障流动人口子女接受义务教育的权益，流动人口子女义务教育阶段入学水平达到我市义务教育阶段入学水平。目前在我市义务教育阶段学校就读的流动人口子女有29418人，其中小学21162人、初中8256人。

（五）努力办好家长学校。为了提高家庭教育水平，全市建立起了多元化的家长学校办学网络，已使90%以上的城镇中小学、幼儿园和80%的农村小学、幼儿园办起了家长学校。通过发放《给全市中小学（幼儿园）家长一封信》、邀请知心姐姐来我市学校给家长做家庭教育知识讲座等形式普及家庭教育知识，使学生家长的家庭教育知识知晓率达到85%以上。

    三、儿童与法律保护

    （一）严厉打击拐卖儿童、涉校等犯罪活动，优化儿童少年发展的社会环境。近年来，我市对打击儿童犯罪一直持高压态势。2009年，通过“打拐”专项行动，共破获拐卖妇女儿童案件56起，解救被拐卖儿童数9人。为严厉打击犯罪，2009年全市共采集并录入疑似被拐儿童及被拐儿童父母的血样1949份进行DNA检验比对。针对侵犯中小学生和幼儿园儿童人身、财产安全的违法犯罪行为，集中警力，落实责任，专案专办。进一步推动校园“八条措施”的贯彻落实，加大涉校未破刑事案件的侦破工作力度，确保全市校园及周边治安稳定，全市对2004年以来未破的涉校刑事案件重新梳理，从中筛选出10起案件列为市局督办案件，重点攻坚，集中力量，限期破案。

    （二）抓好“青少年法制教育基地”建设，普及表少年法律知识。为从源头上做好对未成年人的教育工作，市公安局立足监所自身的资源优势，于2005年9月30日成立莆田市青少年法制教育基地，基地主要由法制教育图片展、在押人员现身说法、法律知识讲座、参观监区、警校共建、法制教育图片巡回展等6部分构成。法制教育基地向社会开放，目的是促使青少年接受深刻的法制教育，为预防青少年违法犯罪有着积极的作用。2009年未成年人刑事案件作案成员占全部刑事案件作案成员的比重由2008年的11.6%下降到10.1%。人民法院判决的未成年人犯罪人数从2008年的268人减少为2009年的231人，人民法院判决的未成年人犯罪人数占同期犯罪人数的比例从2008年的12.42%下降到2009年的10.49%。完善法律援助机构，2009年妇女儿童法律援助机构数有8个，得到援助的妇女儿童有580人。

    （三）大力加强未成年人保护工作。开展创建“平安校园”活动，对学校及周边治安实行综合整治。全市中小学普遍开展法律知识教育，积极开展“校园普法十个一”活动，每个学校都聘请一位兼职的综治副校长或法制辅导员，通过举办图片巡回展、观看影视节目、召开讲座、报告会、知识竞赛等丰富多彩的活动，引导广大青少年增强遵纪守法观念，依法履行义务、行使权利、提高学法、用法、护法的意识和能力，促进青少年学生法律素质的养成，实现预防和减少青少年学生违法犯罪的综合治理目标，减少在校生犯罪。

    （一）儿童生活环境得到改善。2009年我市城市空气环境质量达到二级标准，污染指数API平均为56。今年以来加大对木兰溪、秋芦溪水环境综合整治工作，完成两溪流域污染源普查工作，加大力度保护饮用水源，全面落实省下达给我市的饮用水源为民办实事项目工作任务。

第二部分    儿童事业的难点和问题

一、当年出生婴儿性别比仍处于高位。《莆田市儿童纲要2001-2010年》实施以来，婴儿性别比在2004年达到146.7%的最高值后，逐渐回落，2006- 2009年仍在110%-120%间波动，2009年为116.9%。出生婴儿性别比例失调，主要原因是人们“重男轻女”的思想在作怪。在这种思想的引导下，出现了计划外生育，超生现象在一定程度存在；同时，有人就钻制度的漏洞，进行胎儿性别鉴定。长期的性别比例失调会产生诸多的社会问题，应当引起家庭、社会的高度重视。

    二、出生缺陷发生数增多。出生缺陷发生数从2001到2002年在小幅下降后每年有所增长，2009年达到363例，同上年增长30.1%，出生缺陷发生率为8.9‰，接近省定范围9‰。出生缺陷发生有诸多因素作用，如环境污染加重，遗传因素、人的精神（压力），以及现有的医疗水平有限而且成本高等。如何减少缺陷发生，对于家庭、社会都很重要。

    三、基层卫生机构妇幼保健人员配备不足。从监测的数据来看，2007-2009年乡镇卫生院和社区卫生服务中心专职妇幼保健人员配备率不到40%，2009年为38.6%。村级妇幼保健人员配备率为68.2%。以上两个指标与省定目标相比，还相差61.4%和26.8%。

第三部分    策略措施

一、加大对出生婴儿性别比整治力度。首先，要从法律制度上着手开展“两非”专项行动。2009年在市卫生局牵头的开展“两非”专项治理工作以来，共进行专项检查95次，已查处卫技人员“两非”案件21起，共查处案例23例，涉及非法使用B超鉴定胎儿性别案件11例，非法选择性别终止妊娠案件12例，取得一定成效。在此基础上，还要强化监管，继续加大母婴保健执法检查力度，提高产科质量，巩固禁止非医学需要鉴定胎儿性别和选择性别终止妊娠的专项治理成果。其次落实完善计划生育制度，把妇检制度落实到人，建议政府每年结合妇检时举行妇科病检查，以此来宣传计生政策营造宣传的良好氛围。再次完善计划生育户的奖励制度，以好带差，以点带面，逐渐铺开。

二、加大人口出生缺陷干预力度。首先加大宣传力度，提高妇女自身保健意识，尤其在孕期要尽可能不接触有毒有害物质，保持身心健康。其次继续推进婚前医学检查，提高婚前保健服务质量。继续抓好新生儿疾病筛查和新生儿听力筛查、诊断等工作，并争取市妇幼保健院通过省级产前诊断机构验收并投入运行。推进我市农村育龄妇女（包括流动人口）孕前3个月和育早期3个月补服叶酸预防神经管缺陷项目的落实。加大农村、城镇合作医疗保障范围。再次政府有关部门要督促企事业单位落实女工劳动保护的各项措施，特别是对女工的孕期保护，尽量为女工创造良好的工作环境。

三、要充实基层卫生院/社区服务中心、村一级的妇保人员。首先加强农村乡镇卫生院妇幼保健等公共卫生管理，配强配齐妇幼保健人员，提高专职妇幼保健人员的配备率，强化技能培训，全面提高业务水平。加强农村乡镇卫生院产儿科建设，强化技能培训。其次在经费上要对这些基层一线的妇保人员倾斜，要留得住人。

                                                                        撰稿：方青
