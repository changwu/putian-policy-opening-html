人口保持低速增长 社会抚养负担沉重——2014年人口发展情况简析

第十五期
来源：本网 时间：2015-03-10 11:01
| | | |

2014年，莆田市委市政府深入贯彻落实党的十八大“坚持计划生育基本国策，提高出生人口素质，逐步完善政策，促进人口长期均衡发展”的人口政策，采取适当调整生育政策，取消合法二胎生育间隔，全市人口保持在低生育水平的增长，城镇人口继续增加，社会养老体系不断健全，人口发展保持良好的态势。

一、2014年我市人口发展主要特点

（一）人口总量保持惯性增长，呈低速平稳态势

2014年人口变动抽样调查结果显示，全市常住人口285万人，比2013年净增2万人。人口出生率13.2‰，死亡率6.6‰，自然增长率6.6‰，分别比2013年提高1.6、0.3和1.3个千分点，人口总量仍呈低速平稳增长态势。由于人口生育政策调整和人们生育观念转变的双重作用，人口总量将会继续保持低速平稳增长。

（二）人口老龄化严重，社会抚养负担加重

近年来，随着人民生活水平的提高和医疗条件的改善，加之长期低生育水平的作用，老年人口比重迅速提高，年龄结构日趋老龄化。2014年全市0-14岁人口占常住人口比重为19.28%，比2013年提高0.68个百分点；15-64岁人口占比70.54%，比2013年提高0.24个百分点；65岁及以上人口占比10.18%，虽然比2013年下降0.92个百分点，但大大超过国际老龄化7.0%的标准。少儿抚养比(每100名劳动年龄人口要负担的14岁以下少儿人口数)27.33%，老年抚养比(每100名劳动年龄人口要负担的65岁以上老年人口数)达到14.43%，总抚养比达41.76%，远高于全省32.4%的平均水平。随着2014年人口政策的调整，“单独”两孩政策的放开，势必会带来新一轮生育潮。在老年、少儿抚养比双重增加的作用下，社会抚养负担将日益加重。

（三）人口文化素质不断提升

随着科教兴市和人才强市战略的实施，莆田市教育事业协调发展，人口受教育程度持续提高，文化素质不断提升。2014年全市6岁及以上人口平均受教育年限8.56年，比2010年提高0.21年。其中，男性平均受教育年限9.14年，女性8.16年；20-59岁受高等教育人口占常住人口的比重8.06%，比2010年提高0.02个百分点，其中，男性占9.12%，占比下降0.23个百分点，女性占7.10%，占比提高0.3个百分点。

（四）家庭结构简单，规模趋小型化

随着经济社会不断发展和生活水平的提高，人们的思想观念在不断转变，住房条件不断改善，人口迁移流动速度加快，按照人口发展的一般规律，少生优育逐步成为现代家庭组合的导向，使得小型化家庭户主体越来越明显。2014年全市家庭户平均每户3.37人，两人户成为家庭规模主体，两代户模式成为家庭户主体格局。其中一代户占比为32.69%，比2013年降低6.37个百分点；二代户占比为38.0%，比2013年提高4.57个百分点；三代户占比27.37%。一代户家庭比重降低表明老年人口形成“空巢家庭”减少。

（五）推进城乡一体化建设，城镇化水平稳步提高

近年来莆田市全面实施城乡一体化综合配套改革，积极推进城乡一体化建设，逐步实现城乡一体、生态宜居、农村社区协调发展；实现城乡基础设施一体化和公共服务均等化；实现城市等级规模不断提高，城市聚集、辐射功能和城市的承载力不断增强；实现城乡经济社会全面发展、共同富裕，城镇化水平稳步提高。2014年末全市常住人口中，城镇人口157.6万人，比2013年增加了5.9万人，乡村人口127.4万人，比2013年减少了3.9万人。全市常住人口城镇化率达55.3%，比2013年提高了1.7个百分点。

（六）人口性别比治理效果显现

2014年，全市常住人口中，男性为140.5万人，占总人口的49.3%；女性为144.5万人，占总人口的50.7%，常住人口总性别比为97.28%，出生人口性别比91.7%，比2013年提高4.3个百分点。

（七）社会养老、医疗保障日趋完善

随着新型农村社会养老保险、城镇居民社会养老保险和新型农村合作医疗、城镇居民基本医疗保险制度的全面推开，社会养老医疗保障制度进一步完善，参加社保、医保人数不断增加。据调查，2014年末15岁以上常住人口中，有88.2%的人口参加各类社会养老保险，增加2.5个百分点，其中参加新型农村社会养老保险的占78.4%，提高0.7个百分点；有98.8%的人口参加各类社会医疗保险，其中参加新型农村合作医疗保险的占89.7%。

二、人口发展面临的主要问题

（一）人多地少仍是莆田面临的重要问题

尽管目前人口增长已进入稳定低增长阶段，但由于上世纪80年代初人口出生高峰产生惯性作用还在持续，加上人口生育政策，“单独”两孩的放开，必将带来新一轮生育高峰，因此今后若干年人口总量仍将继续保持增长态势，这给本就地少资源匮乏的社会环境带来沉重负担，在当今工业化、城镇化快速发展的背景下，不断增长的人口势必会对自然环境造成巨大压力，对社会承载力提出严峻挑战。

（二）老龄化程度日趋严重，社会保障体系支撑能力不足

人口老龄化是我市人口与社会经济发展中面临的另一个严重问题。随着社会经济不断发展，人们的生活条件不断改善，老年人口迅速增长。自上世纪90年代后，莆田市人口老龄化速度明显快于全省平均水平。2000年全市65岁及以上老年人口比重7.23%，比全省高0.64个百分点，2010年比重8.74%，比全省高0.85个百分点，2014年比重10.18%，比全省高出1.8个百分点。目前经济发展水平尚不够发达，工业化进程尚未完成，而老龄化社会提前到来，是典型的“未富先老”。随着“单独”、“双独”家庭的增多，“421”家庭模式使得越来越多的家庭无力承担养老责任。越来越多传统的家庭养老功能已经难以应对老龄化的挑战。受经济发展水平、财政体制等因素的影响，社会保障体系还不够完善、发展不均衡、保障模式单一等问题，很多实惠制度、优惠政策还处在探索发展阶段，农村单一的家庭养老模式和薄弱的社会保障体系已无法满足农村老人的养老需求。

（三）劳动人口整体文化素质不高

随着我市教育事业的不断发展以及吸纳鼓励高学历人才回莆就业,全市常住人口受教育程度有了一定的提高，但是总体劳动者文化水平仍是初中、小学教育程度占大多数。劳动年龄人口平均受教育年限仅达到初中毕业水平，远远不能满足莆田经济社会发展的需要。同时，全市高层次人才数量不足、地区分布不均衡。20-59岁劳动年龄拥有大专及以上学历的人口8.06%，其中城厢17.6%、涵江13.1%、荔城8.5%、秀屿3.1%、仙游6.0%，高层次人才更多的集中在经济发达地区，人才缺乏成为制约经济相对落后地区经济社会发展的重要因素。

三、促进我市人口健康发展的对策建议

（一）稳定低生育水平，合理调控人口结构

全面落实各项计划生育措施，继续完善现行计划生育政策，稳定低生育水平，控制人口总量增长，提高人口素质，调整人口结构，充分考虑人口变化对经济社会发展的长期性、基础性影响。在人口总量稳定发展的基础上，统筹解决人口素质、结构、分布问题，促进人口、资源、环境协调发展，为我市人口与经济社会协调发展创造良好的人口环境。

（二）积极应对人口老龄化，建立健全社会养老体系

以满足老年人养老服务需求为目标，加快体制机制创新，加大公共财政投入力度，全面构建与我市人口老龄化进程相适应、与经济社会发展水平相协调，以居家为基础，社区为依托，机构为支撑，资金保障与服务保障相匹配，基本服务与选择性服务相结合，政府主导、政策扶持、社会参与、市场运作，机构、社区、家庭、个人相互协调联动，覆盖城乡的全社会养老服务体系，实现老年人老有所养、老有所依，共享经济社会发展成果。

（三）提高劳动者素质，促进经济社会进步

在巩固九年义务教育成果的基础上，进一步扩大高中阶段和高等教育规模，大力发展职业技术教育和成人教育，进而形成更加完善的现代国民教育体系，多举措吸引高层次人才。要通过营造和优化人才环境，制定各种优惠政策吸引人才、培养人才、留住人才，为人才的流动提供各种服务平台，制定并实施相关政策，鼓励各类人才向基层一线、经济发展重点领域、人才资源供求矛盾突出的地区流动，从而推进我市经济快速发展，社会全面进步。
