上半年莆田市商贸业运行情况简析

来源:统计局 时间：2013-07-20 21:15
| | | |

上半年，全市加快发展现代商贸流通业，市场运行总体保持有序、快速、健康的发展态势。1－6月，全市批发零售业实现商品销售总额538.68 亿元，同比增长34.1%，增幅比上年同期上升7.0个百分点；住宿餐饮业实现营业额24.53亿元，增长7.9%，增幅比上年同期回落6.8个百分点；全市实现社会消费品零售总额210.50亿元，增长15.4%，增幅居九设区市第二位。商品销售总额、营业额及社会消费品零售额增幅情况如下表所示。

一、商贸市场运行特征

（一）从商品销售总额、营业额增幅看

今年来，全市商贸业发展态势良好，批发业、零售业商品销售额增幅及住宿业营业额增幅均居全省首位，其中批发业、零售业商品销售额累计增幅连续5个月居全省第一位，住宿业营业额累计增幅连续2个月居全省第一位。

1、批发业高位增长，支撑商贸业快速发展。在批发、零售、住宿和餐饮四个行业中，批发业体量最大，比第二大行业的零售业商品销售额多89.20亿元，而且，今年来各月累计增幅除1－2月增幅为37.9%外，其余月份均保持在40.0%以上。1-6月，全市批发业商品销售额313.94亿元，增长40.2%，增幅分别高于上年同期、全省平均水平9.5个和23.0个百分点，比1-5月小幅回落0.5个百分点。

2、零售业增速放缓，但发展仍快于全省其他设区市。1-6月，全市零售业商品销售额224.74亿元，增长26.4%，增幅分别高于上年同期、全省平均水平3.6个和11.2个百分点，比1-5月回落7.5个百分点。

3、住宿业表现突出，后来居上。1-6月，全市住宿业营业额3.59亿元，增长22.4%，增幅比1-5月提升8.2个百分点，分别高于上年同期、全省平均水平14.5个和16.7个百分点。分限额标准看，限额以下住宿业近2个月较快增长，拉升整个行业快步发展。1-6月，限额以下住宿业营业额2.75亿元，增长23.6%，拉动住宿业增长17.9个百分点。

（二）从限额以上商品销售额增幅看

1、限额以上批发业表现给力，推动行业快速发展。1－6月，限额以上批发业商品销售额224.62亿元，占整个批发行业商品销售额的比重超7成，达71.5%，增长54.6%。今年来，限额以上批发业各月商品销售额累计增幅均在46.0%以上，限额以上批发业占比大，发展快，从而推动行业快速发展。全市限额以上有5家批发企业贡献率超2.5%，商品分布在石油及制品类、钢材类及服装鞋帽类，4家为总部经济型企业，1家为外贸企业。其中，中石化炼油销售（福建）有限公司和中海石油气电集团有限责任公司福建贸易分公司业绩突出，拉动限额以上批发业商品销售额增长35.6个百分点。

2、限额以上零售业受基数影响，增幅回落。1－6月，限额以上零售业商品销售额88.02亿元，占整个零售行业商品销售额的比重近4成，为39.2%，增长53.8%，增幅高于上年同期10.4个百分点，低于1－5月26.4个百分点。6月份限额以上零售业商品销售额基数比5月份大增7亿，是导致限额以上零售业商品销售额增幅回落的直接原因。主要影响企业是中石化森美莆田分公司，其基数大，且当月业务量减少（本月联营单位有1亿元的商品销售额被划归泉州统计）。

（三）从社会消费品零售总额增幅看

1－6月，全市社会消费品零售总额增幅为15.4%，比全省平均水平高1.8个百分点，居全省九设区市第二位。

1、零售业发挥主导作用。分行业看，零售业实现消费品零售额174.35亿元，占社会消费品零售总额的82.8%，增长17.1%，增幅快于全市平均水平1.7个百分点，拉动社会消费品零售总额增长14.0个百分点，对社会消费品零售总额增长的贡献率高达90.7%，分别比批发业、住宿业和餐饮业高85.9个、90.6个和86.4个百分点。

2、城镇与乡村发展差距进一步缩小。1－6月，城镇消费品零售额187.45亿元，增长15.4%，乡村消费品零售额23.05亿元，增长15.3%。城镇增幅高于乡村0.1个百分点，差距进一步缩窄。

3、限额以上批发零售业消费品零售额增幅保持在30.0%以上。分商品类别看，在19类商品中，有5类商品累计增速下降，其中包括家用电器和音像器材类（1－6月零售额4.13亿元，下降2.5%）。大宗商品中，石油及制品类商品影响力被削弱，本月零售额仅实现个位数增长，1－6月零售额24.56亿元，增长61.4%，增幅比1－5月下调10.5个百分点，对限额以上批发零售业消费品零售额增长的贡献率从1－5月的63.0%回落至1－6月的59.1%，回落的主要原因是中石化森美莆田分公司未开展联营单位零售；有别于石油及制品类商品销售，汽车类商品消费则得到进一步释放，部分商家销售路虎揽胜等高档车型汽车，本月零售额增幅回升，零售额达2.57亿元，增长20.7%， 1－6月零售额14.32亿元，增长9.8%，增幅比1－5月提升2.2个百分点。

（四）从限额以上商贸企业注册资本及分布地域看

1、分注册类型看：（1）批发零售业中，外商投资企业发展最快。1－6月，外资企业实现商品销售额45.67亿元，增长97.1%，实现零售额21.16亿元，增长74.9%；发展最慢的是港、澳、台商投资企业，其实现商品销售额16.17亿元，下降7.5%，实现零售额0.46亿元，增长3.6%；居中的内资企业，实现商品销售额250.80亿元，增长55.0%，实现零售额44.71亿元，增长17.8%，其中，国有企业实现商品销售额68.27亿元，增长134.2%，实现零售额0.23亿元，增长72.5%。（2）住宿餐饮业中，内资企业发展最快。1－6月，内资企业实现营业额3.31亿元，增长10.9%，外资企业发展最慢，实现营业额0.26亿元，下降6.3%，居中的是港、澳、台商投资企业，其实现营业额0.29亿元，增长4.4%。

2、分地域看：各县区都有自己的主打牌。城厢区依托零售业中石油及制品类企业提升自身商品销售额增速；涵江区较为集中在服装鞋帽、建材、食品、汽车等销售上；荔城区引入石油及制品类总部企业使其受益非浅；秀屿区集中在建材、服装鞋帽、金银珠宝销售上；仙游县则依靠石油及制品类总部企业快速发展；北岸经济城中钢材、建材企业发挥主力军作用，主导北岸商贸业良性发展。各县区限额以上商贸业运行情况见表2和表3。

二、商贸业运行的不利因素

（一）新增限额以上零售业企业少。1－6月，商品零售价格同比下降0.1%，对全市消费品零售市场有一定的抑制作用。从全国范围看，今年促进消费的国家政策已全面结束，如没有新的消费热点来支撑，零售市场将表现平淡。从表1中可见，今年来，全市社会消费品零售总额高开，一季度增幅达到最高的20.0%，之后逐月回落，下行压力逐渐增大。促进零售市场活跃发展的有效途径之一就是新增企业来补充。2013年以来，全市新增43家零售业企业，退出22家，净增21家。新增43家零售业企业中，有35家是从限额以下转限额以上的；而从3月份起全市则未新增零售业企业，下半年零售市场发展后劲不足。

（二）限额以上餐饮市场疲软。在目前消费结构不尽合理的情况下，餐饮市场过分依赖政府公款消费，由中央“八项规定”等相关政策的落实效应可见一斑。6月份，婚庆、重要节日等大众消费相对较少，导致餐饮企业业绩下滑。1－6月，全市餐饮企业实现营业额20.95亿元，增长5.7%，增幅分别比上年同期、1－5月回落10.0个和0.5个百分点。分限额标准看，限额以上营业额3.02亿元，增长6.6%，比1－5月回落3.2个百分点；限额以下营业额17.93亿元，增长5.5%，比1－5月回落0.1个百分点。

三、建议

1、加大电子商务（网贸）企业申报力度。网贸企业经营范围广，可延伸至全国各地甚至国外，大大弥补本地消费的不足。全市的限额以上网贸企业统计处于起步阶段。1-6月，全市有24家限额以上网贸企业（其中2家已停报）实现商品销售额1.96亿元，增长4.1倍，实现零售额1.33亿元，增长3.4倍。兄弟城市已加快网贸企业培育申报力度。本市应立足实际，落实相关优惠政策，引导网贸个体户转注为法人企业。

2、制定相关政策，让新入驻商贸项目的商家在我市注册为法人企业。依据现有统计制度规定，只有在本地注册的商贸法人企业才能申报入库，纳入限额以上统计；在本地注册的产业活动单位则不属于本地统计，由产业活动单位所属的法人企业统计。基于以上原因，有关部门要制定优惠政策，鼓励、积极引导外来或本地商家入驻商贸项目时注册为法人企业（即工商登记为独立法人企业），这样，既可增加本地税收，提高财政收入，又可纳入本地统计，真实反映全市商贸市场运行情况。
