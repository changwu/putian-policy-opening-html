2017年莆田市全社会综合能源生产消费情况分析

第四期
来源：本网 时间：2018-01-26 15:17
| | | |

2017年我市经济继续保持稳健发展的良好态势，全社会各行业电力消费增速始终位于全省前列。其中工业作为经济的重要支撑力量，伴随火电厂二期、华佳彩、云度等大项目的投产，发展后发动力较为强劲。与此同时工业也作为主要的能源消费力量，这些高耗能企业的投产将导致我市年度节能降耗目标任务无法完成，影响不容小觑。

一、全社会用电量情况

2017年我市全社会电力消费量为123.17亿千瓦时，同比增长10.2%，增速较上年回落5.0个百分点，增幅保持在全省第二位的水平。

（一）分产业看，第一产业用电量为0.97亿千瓦时，同比增长4.8%；第二产业用电量为76.31亿千瓦时，同比增长10.4%；第三产业用电量为15.77亿千瓦时，同比增长11.0%；生活电力消费量为30.12亿千瓦时，同比增长9.5%。

（二）工业用电量占全社会用电重头。2017年我市工业用电量为74.67亿千瓦时，占全社会用电量的60.6%，同比增长10.6%，增幅较上年缩小7.4个百分点，位居全省第二。

二、规模以上工业能源消费现状

2017年我市规模以上工业综合能源消费量为246.73万吨标准煤，同比增长24.3%，扣除火力发电行业，同比增长8.2%。全市规模以上工业企业实现工业增加值928.80亿元，可比增长8.2%，单位工业增加值能耗增长14.9%，与2016年下降10.5%的趋势比，增长较为迅猛。

（一）轻工业能耗稳步发展，重工业能耗增势凸显

2017年我市轻工业企业综合能源消费量为69.04万吨标准煤，同比增长3.0%，增速较上年下降0.2个百分点，对规模以上工业综合能源消费的推动作用保持在1.0个百分点；重工业企业综合能源消费量为177.70万吨标准煤，同比增长35.1%，对规模以上工业综合能源消费量的推动作用为23.3个百分点。

从重、轻工业能源消费占规模以上工业综合能源消费比重看，重工业由上年66.2%增至72.0%，轻工业由上年33.8%降至28.0%，重工业比重进一步扩大。

（二）六大高耗能行业能耗增幅、比重均有所提高

2017年全市六大高耗能行业综合能源消费量为168.52万吨标准煤，同比增长36.0%，增幅提高了43.6个百分点，占规模以上工业能源消费量比重为68.3%，提高了5.8个百分点。

1、电力、热力生产和供应业综合能源消费增势扩大。2017年1-4季度我市电力、热力生产和供应业综合能源消费量增速分别为34.2%、14.2%、24.1%、39.1%，全年各月均呈较高速的增长状态。从比重看，该行业综合能源消费量占规模以上工业综合能源消费量比重始终保持50%以上，对全市规模以上综合能源消费量走势影响较大。

2、黑色金属冶炼和压延加工业能耗增速由负转正。2016年该行业受市场影响，生产大幅减少，综合能源消费量随之减少，全年保持降幅90%以上的趋势，今年鞍钢冷轧恢复生产推动该行业能耗由年初下降22.1%转为增长1034.3%。

3、化学原料和化学制品制造业能耗增速放缓。2017年不再受中锦新材料新增入库的影响，化学原料和化学制品制造业1-4季度增速分别为-6.1%、-4.8%、11.7%、30.0%，增速较上年明显放缓。

（三）原煤消费量转降为增，天然气消费量持续下降

2017年我市规模以上工业原煤消费量338.33万吨，同比增长49.0%，增速较上年提高51.9个百分点。从工业分行业看，原煤消费量较大的行业主要包括电力、热力生产和供应业（264.62万吨），化学纤维制造业（30.98万吨），化学原料和化学制品制造业（12.85万吨）。其中，造成全市规模以上工业原煤消费量增长的主要因素在于火电二期的投产。

与原煤消费量趋势相反的是天然气的消费量，2017年我市规模以上工业天然气消费量为5.38亿立方米，同比下降2.4%，持续了上年的下降趋势。从工业分行业看，电力、热力生产和供应业是我市天然气消费主体，全年消费量为4.74亿立方米，同比下降7.4%，主要受燃气电厂发电量较上年减少影响。另外，非金属矿物制品业天然气消费量增加，全年天然气合计消费0.35亿立方米，同比增长15.3%。

三、规模以上工业企业能源生产现状

2017年我市规模以上发电企业发电量为143.33亿千瓦时，同比增长31.1%。其中，火力发电量为90.42亿千瓦时，同比增长39.3%；水力发电量为28.08亿千瓦时，同比增长5.6%；风力发电量为24.84亿千瓦时，同比增长39.1%。

（一）规模以上火力发电高速增长，占比再提高。2015年和2016年我市规模以上火力发电均为下降，2017年因国投云顶湄洲湾电力有限公司的投产，火力发电由下降变为增长，且增速高达39.3%。从占比看，火力发电量占全市规模以上发电量的63.1%，比上年提高3.1个百分点。

（二）规模以上水力发电增速放缓明显。2017年我市规模以上水力发电量一改高速的增长态势，1-10月发电量同比均呈下降趋势。

（三）规模以上风力发电规模逐渐扩大。2017年我市规模以上风电企业有10家，较上年新增2家，发电量同比增长39.1%，增速提高40.4个百分点；发电量占规模以上工业发电量比重为17.3%，扩大1.8个百分点。

四、节能形势预测和分析

2017年1-3季度我市GDP能耗下降率为4.02%，节能降耗形势有所好转。但从当前用电量及规上工业能耗情况看，2017年单位GDP能耗下降4.94%的目标完成难度较大。

（一）电是最主要能耗，增速高影响大。2012-2016年我市电力消费占全社会能耗的比重呈现逐年扩大的趋势，由2012年的51.8%提高到2016年的64.4%，平均比重为56.9%，是影响全社会能耗的主要因素。在这样的形势下，用电量增长越快，对全社会能耗的拉动就越大，单位GDP能耗下降就越困难。

从GDP能耗下降率和全社会用电量增速的走势关系看，用电量增速高，单位GDP能耗下降就少。2017年我市全社会用电量同比增长10.7%，增幅高于前三季度，预计单位GDP能耗下降率将不超过4.0%，要完成4.94%的降幅比较困难。

（二）新增规上工业企业能耗高，增加值却不高。2017年我市新增火电二期、华佳彩、华锦、云度等规模较大的规上工业企业，基数为0，全年能耗合计为51.30万吨标准煤，占规上工业综合能耗的20.8%，能耗增量拉动全市规上工业综合能耗25.8个百分点。然而，这些企业对工业总产值（现价）的拉动仅为10.3个百分点，初步计算对工业增加值的拉动低于11个百分点，这将直接影响规模以上工业增加值能耗的下降率，进而影响单位GDP能耗的下降率。

（三）燃煤发电效率低，煤耗大。火力发电煤耗是我市计算全社会能耗的系数，发电煤耗越高，等价值的能耗就越大。从我市火力发电结构看，发电煤耗较高的燃煤发电始终占全市发电的主要地位，导致了我市平均发电煤耗居高难下，进而影响了单位GDP能耗的下降率。
