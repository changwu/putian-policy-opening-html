从资源型文化产业到可持续型文化产业——“文化莆田”战略方向初探

来源:统计局 时间：2012-05-22 18:04
| | | |

近年来，我市文化产业在市委、市政府的高度重视下，取得了长足的发展，具体表现为产业规模的不断壮大以及经济体量的稳步增加。自2010年以来，我市文化产业增加值已连续两年稳居全省第四位，与漳州地区并居福建省文化产业第二梯队；2010年、2011年文化产业增加值占地区生产总值比重分别为6.4%、7.7%，均为全省首位。特别是2012年第一季度，我市文化产业发展再度显现强劲势头，共创造文化产业增加值20.61亿元，居全省第四位；占地区生产总值比重为8.5%，继续领衔全省九地市，并提前达到“十二五”终期目标，成为本地区的新型支柱产业。然而，我们也要清醒地注意到，当前我市文化产业正面临着结构严重失衡的问题。2010年，我市核心层、外围层以及相关层增加值分别为5.28亿元、4.95亿元、44.04亿元，分别比2008年增长52.2%、116.2%、213.0%；三个成分的比例由2008年的17.5:11.6:70.9变成2010年的9.7:9.1:81.2，全省排名分别为第九位、第九位、第一位，结构失衡可见一斑。无独有偶，占据工艺美术行业主导地位的古典家具制造、“仙游石”雕刻等行业，因产业本身受到木材、石材等生产资源的约束，虽然在今后一段时期内仍将在发展我市文化产业中扮演着至关重要的角色，但长远发展则面临着“无源之水”的隐患，令人担忧。

市第六次党代会以来，市委、市政府高瞻远瞩，提出了“文化莆田”的战略口号。“文化莆田”的提出，既契合了中共十七届六中全会“推动社会主义文化大发展大繁荣”的决策部署，也坚定了我市做大做强发展文化产业的决心。但在高速发展与结构矛盾的尴尬处境之间，如何正确规划我市文化产业发展方向，最终寻求质与量的双重提升，成为了亟待解决的首要问题。基于此，本文拟从“资源型文化产业”与“可持续型文化产业”这两个概念的提出与对比中，初步探讨我市文化产业发展的方向性问题，为党政领导作抛砖引玉之效。

一、概念的提出

为了更直观、全面、准确地反映该产业的发展状况，国家统计局在《文化及相关产业分类》中将文化产业定义为“为社会公众提供文化、娱乐产品和服务的活动，以及与这些活动有关联的活动的集合”，从而进一步明确了文化产业的范畴。按照各类文化活动的特征和同质性，我们将全部文化产业活动进一步划分为核心层、外围层和相关层。其中，核心层包括新闻服务、出版发行和版权服务、广播、电视、电影服务、文化艺术服务；外围层包括网络文化服务、文化休闲娱乐服务和其他文化服务；相关层包括文化用品、设备及相关文化产品的生产和销售。

当前，我市已在近一千五百年的历史变迁中荣膺全国“戏曲之乡”、“民间绘画之乡”、“摄影之乡”、“中国木雕之城”、“银饰之乡”、“古典工艺家具之都”、“田径之乡”和“篮球城市”等一系列称号，并已形成以妈祖文化、传统工艺、民俗文化和文献名邦等为主体的文化序列，文化资源极为丰富。然而，在福建省统计局公布的全省十大产业中，我市仅凭借工艺美术行业在孤军维系，核心层、外围层均难以形成竞争力。这两种不相匹配的因果关系发人深思。

为了更好地说明问题，笔者拟引入两个新的概念，即“资源型文化产业”与“可持续型文化产业”。所谓资源型文化产业，即生产中必须较大程度地依赖某种或某类特定的生产原料的文化产业，如我市的古典家具制造业和“仙游石”雕刻业等；而除此之外的其他文化产业，如文化旅游业、出版发行业、演艺娱乐业、广播影视业、广告业、油画业等，都可称之为可持续型文化产业。

二、模式的论证

（一）资源型文化产业的特点与问题

近年来，我市文化产业增加值占地区生产总值的比重一直居全省首位，一个最重要的原因就是古典家具制造业的强势拉动；此外，仙游石的兴起及前景，也一度为投资人士看好。以上述两种产业为例，我们不难看出，资源型文化产业具备以下三种特点：

一是特定的生产原料。我市的古典家具制造业主要原材料为红木。根据国家标准，红木的范围确定为5属8类，33个主要品种：5属是以树木学的属来命名的，即紫檀属、黄檀属、柿属、崖豆属及铁刀木属；8类则是以木材的商品名来命名的，即紫檀木类、花梨木类、香枝木类、黑酸枝类、红酸枝木类、乌木类、条纹乌木类和鸡翅木类。同时，红木是指这5属8类木料的心材，心材是指树木的中心、无生活细胞的部分，除此之外的木材制作的家具都不能称为红木家具。而仙游石的雕刻原料目前仅发现存在于仙游园庄镇、赖店镇、社硎乡、游洋镇、石苍乡等五个乡镇。因此，人无我有，人有我优的生产原料是上述两个行业保持独特性和竞争力的关键性因素。

二是特别的加工工艺。我市古典家具制造可以追溯到北宋时期，具有明显的历史传承工艺色彩，产品融合传统国画艺术与雕刻艺术，特殊、精湛的加工工艺是“仙作”产品得以流传的基础。此外，现代科技成果如数控机床、榫卯结构新技术在古典家具制造中的应用也是该行业迅速发展的关键。

三是特殊的消费群体。因红木家具、仙游石的收藏价值大于实用价值，替代效应不明显，所以符合奢侈品的定性，其本身的价格弹性也较高，消费群体带有相当的局限性。因此，一旦原材料由于产量减少、贸易壁垒等原因导致价格攀升，势必影响成品的出厂价进而影响销量。

与此同时，当前我市资源型文化产业也面临着以下几个问题：

一是生产原料的长期供应捉襟见肘。当前我市的古典家具制造业主要原料为红木，而红木本身具有生长年限长、产量少、运输成本高、过度依赖进口等制约性因素，随着该行业的高速发展，产业拓宽与原材料短缺间的矛盾必将日益凸显。又如仙游石雕刻行业，因之前有“寿山石模式”可供借鉴而为文化人士寄予厚望，但如今寿山石所面临的石料短缺、生态破坏等一系列后遗症很有可能将成为日后仙游石雕塑业所不可规避的覆辙。

二是产业同质化的苗头初现端倪。2011年，我市共有文化产业单位数3829个，其中规模以上工业文化产业单位有321家，占总数的8.38%；个体经营户2456家，占总数的64.14%。然而，就增加值来看，规模以上工业文化产业单位共创造文化产业增加值64.10亿元，占全市文化产业增加值的79.28%；而个体经营户创造的增加值仅为5.14亿元，占全市文化产业增加值的6.36%。作为我市文化产业主体的古典家具制造业，增加值与单位数之间不相匹配的关系亦折射出当前该行业所面临的产业同质化困境，即多数企业以粗放型、家族型管理为主，尚未形成其独特的核心竞争力。

三是龙头企业的培育缺乏力度。一个优秀的龙头企业能够对同行业的其他企业具有很深的影响力、号召力和示范力，并对该区域的经济社会做出突出贡献。而当前我市古典家具制造业中，龙头企业的稀缺也是资源供需关系紧张、产销存产业链难以进一步拓展的主要原因。

（二）可持续型文化产业的特点与瓶颈

根据定义，可持续型文化产业与资源型文化产业不同，涵盖文化产业的核心部分，摒弃了对特定生产资源的依赖，因此它具备以下几种特点。

一是产业发展条件具备普遍性。正因为可持续型文化产业没有特定的生产资源限制，因此只要配备完善的基础设施，每个区域都有发展的条件。也正因如此，突出某种可持续型文化产业的特色是确立其竞争力的决定性因素。

二是产业发展与其他产业渗透性好。可持续型文化产业所包含的创意、文化部分可以很好地附加在几乎所有的产品上，对其进行文化包装。一方面既提升了各种产品的市场竞争力，一方面也为产业间的互利渗透创造了可能性。。

三是产业发展投入小回报大。可持续型文化产业回避了对特定生产资源的分配，具有投入小的特点，而高回报也是该产业中各种行业间的共性。

通过对可持续型文化产业特色的认识与对照，不难发现当前我市文化产业核心层、外围层难以有效“突围”的瓶颈在于以下几个方面。

一是资源开发程度不高。按照增加值排名，2011年我省文化产业十大行业分别是工艺美术业、演艺娱乐业、文化旅游业、出版发行业、广告业、广播影视业、报刊服务业、动漫游戏业、文化会展业和创意业，其中发展速度较快的有文化会展业、报刊服务业和工艺美术业。就我市而言，除了在工艺美术业上具有一定影响力之外，其他行业资源均未得到有效的开发与利用。

二是基础设施有待完善。我市的文化产业因发展起步晚，造成了底子差、基础薄的现状。2010年，全市仅有艺术表演场所3个，与厦门并列全省第6位；拥有文化馆、艺术馆6座，居全省末位；拥有公共图书馆3座，居全省末位；拥有博物馆2座，居全省末位。大力推进文化基础设施建设是解决我市文化产业后天不足的关键。

三是产业特色不够明显。突出产业特色是凸显产业竞争力的关键，是该行业在某个区域中保持辨识度的必要条件。可以说，产业特色是一个行业的关键词。而当前我市的各种可持续型文化产业中，除了妈祖文化之外，其余标签都尚未得到其他地方的认同。

三、方向的探讨

建设“文化莆田”，必须兼顾对具有代表性的资源型文化产业的巩固以及对可持续型文化产业的挖掘，适当调整战略重心，提升文化产业软硬实力，提高我市文化产业竞争水平，最终实现质与量的双重跨越。

（一）巩固特色文化产业，壮大县域经济基础。

一是巩固古典工艺产业。培育一批龙头企业，对本区域内的同行业单位形成带动效应，促进行业平稳发展；建立若干功能齐全、辐射力广的物流集散基地，积极服务企业营销；由政府引导，为行业发展营造良好的舆论宣传氛围，收集业内动态，帮助中小型企业走出生存困境。

二是凸显妈祖文化品牌。以妈祖文化为基点，带动文化旅游、广播影视、演艺娱乐等产业全面发展，拓展产业链条，丰富产业形式，构建湄洲岛妈祖文化城，使之成为莆田文化产业具有相当竞争力的一张名片。

（二）调整产业战略重心，提升核心竞争力。

一是大力发展广播影视业。以《妈祖》、《芦花寨》来莆拍摄为契机，结合当前全市旅游资源整合，打造一批人文丰富、生态优良的影视拍摄基地，使莆田成为海西广播影视业的重要阵营。

二是大力发展文化会展业。以“中国·湄洲妈祖文化旅游节”、中国（莆田）海峡艺博会等大型会展活动为平台，培育一批会展企业，推动本地区会展业强势发展。

三是大力发展演艺娱乐业。培育一批实力雄厚的经纪公司，依托市体育馆等大型表演场所，延续第十四届省运会、歌星演唱会的余热，引入更多的演艺项目，推动本地区旅游、贸易业发展；整合剧团资源，保护好莆仙戏这个活化石，并结合当下全市剧团“事改企”帮助剧团改变经营无力的局面。
