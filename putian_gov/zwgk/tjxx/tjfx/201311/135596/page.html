1-10月份莆田市经济运行态势分析

来源: 时间：2013-11-19 10:58
| | | |

    前10个月，全市经济运行总体呈现稳中有进、稳中提质的态势，经济增速保持在平稳增长区间，调结构、促转型、惠民生的成效逐步显现，经济增长质量和效益得到提升。初步核算，1-10月份，全市完成生产总值1073.01亿元，增长12.5%。其中：第一产业增加值88.43亿元，增长3.1%，对经济增长的贡献率为1.8%，拉动经济增长0.2个百分点；第二产业增加值658.62亿元，增长14.1%，对经济增长的贡献率为71.7%，拉动经济增长9.0个百分点；第三产业增加值325.96亿元，增长11.4%，对经济增长的贡献率为26.5%，拉动经济增长3.3个百分点。多数主要经济指标增幅居全省前列。其中，增幅居全省第一位的有6个指标：分别是第三产业增加值、批发业商品销售额、财政总收入、地方级财政收入、财政支出、金融机构本外币贷款余额；增幅居全省第二位的有1个指标：GDP；增幅居全省第三位的有4个指标：分别是规上工业产值、规上工业增加值、固定资产投资额、房地产开发投资额。同时，经济运行中存在的一些矛盾和问题仍较突出，部分经济指标增幅回落，经济下行压力加大。

一、经济运行的主要特点

（一）工业保持平稳增长，效益提升

1-10月份，全市规模以上工业企业实现工业总产值1676.28亿元，完成年度计划的84.7%，超序时进度1.4个百分点，可比增长15.3%，增幅高于全省平均水平0.6个百分点；实现工业增加值510.02亿元，可比增长15.2%，增幅高于全省平均水平2.1个百分点。工业总产值与增加值已连续四个月维持15.3%和15.2%增速，增幅稳居全省第三位。主要亮点：①亿元企业贡献突出。1-10月份超亿元以上规模企业达399家，占规模以上工业企业数的41.9%。亿元以上工业企业实现工业总产值1422.89亿元，可比增长17.7%，占规模以上工业总产值的84.9%，对规模以上工业经济增长的贡献率为96.3%，拉动规模以上工业经济增长14.7个百分点。②规下升规上企业成为工业经济新增长点。今年全市新增规下转规上企业148家，1-10月份共完成工业总产值58.27亿元，比上年同期增长82.7%，对规模以上工业总产值增长的贡献率为11.8%，拉动全市规模以上工业总产值增长1.8个百分点。③工业运行效益改善。1-9月份，规模以上工业经济效益综合指数为292.30%，同比提高17.51个百分点；实现利润总额70.60亿元，同比增长34.0%，增幅比上半年提高13.8个百分点；亏损企业42个，同比下降32.3%；亏损企业亏损额1.57亿元，同比下降47.9%；作为经济晴雨表的工业用电量连续六个月保持两位数增长，增速连续七个月居全省第二位；此外，就业增长也显示了工业经济形势好转，1-9月份全市规模以上工业企业吸纳就业人员数23.97万人，同比增长6.6%。

（二）投资快中趋缓，增幅位次回升

1-10月份，全市固定资产投资（不含农户）完成979.71亿元，增长31.6%，增幅比1-9月回落0.5个百分点，但高出全省平均水平9.0个百分点，增幅在全省的位次由8、9月份的第四位重新进入第三位。主要亮点：①新开工项目投资增势强劲。1-10月，我市共有500万元以上新开工项目1125个，比上年同期增加281个；新开工项目完成投资442.12亿元，增长67.1%，增速比项目投资快38.4个百分点，占项目总投资的比重为59.2%，对项目总投资的贡献率高达106.8%。②技改投资力度加大，有利于优化投资结构。1-10月，改建和技术改造项目完成投资74.07亿元，增长80.6%，增速比项目投资快51.9个百分点，占项目投资的比重为9.9%，同比提高2.8个百分点。③城乡一体化助推民生工程投资快速增长。随着我市城乡一体化的稳步推进，水利建设、环境治理、公共设施建设、居民服务与保障等关乎民生的投资呈高速增长态势。1-10月，水利管理业完成投资32.78亿元，增长1.0倍；生态保护和环境治理业完成投资2.83亿元，增长3.5倍；公共设施管理业完成投资41.33亿元，增长55.1%；居民服务和其他服务业完成投资2.89亿元，增长3.1倍。④民间投资主导作用进一步增强。1－10月，全市民间投资514.95亿元，增长35.5%，增幅高于固定资产投资3.9个百分点，占固定资产投资的比重为52.6%，同比提高1.6个百分点，对固定资产投资的贡献率高达57.4%。

（三）财政高位增长，民生保障加强

地方级收入增速明显高于总收入。1-10月份，全市实现财政总收入133.12亿元，增长20.5%，增幅较1-9月提高1.1个百分点，比全省平均水平高5.2个百分点。其中，地方级收入82.21亿元，增长27.1%，增幅超过总收入6.6个百分点。财政支出104.12亿元，增长20.2%。民生支出得到有力保障，共支出72.96亿元，占财政支出比重达70.1%。其中，城乡社区事务、医疗卫生、社会保障和就业、教育支出分别增长104.6%、9.2%、21.2%、10.9%。财政总收入、地方级财政收入和财政支出增速均居全省第一位。

（四）信贷投入有力，但存款位次下滑

10月末，全市金融机构本外币贷款余额1084.29亿元，增长22.2%，增幅居全省第一位。从境内贷款投向看，短期贷款增长13.8%；中长期贷款增长34.3%，增幅比上半年和前三季度分别提高0.7、0.8个百分点。其中，个人贷款增长48.0%，单位贷款增长20.3%。金融机构本外币存款余额1269.09亿元，增长21.5%。存款增幅虽然保持高位，但比上月末回落1.8个百分点，增幅位次在9月份下滑到全省第三位后，10月份又下滑至第四位。

二、当前需要关注的主要问题

（一）工业经济回升基础不稳。一是新投产工业企业少，支撑力不足。1-10月份全市仅有11家新投产规模工业企业，实现工业产值6.11亿元，占规上工业产值的比重仅为0.4%，户均产值仅5555万元。由于增量份额少，难以支撑工业快速增长。二是部分行业生产下降。1-10月份，规模以上工业中有3个行业（大类）产值出现负增长，分别是：非金属矿采选业（-29.7%），水的生产和供应业（-15.5%），其他运输设备制造业（-23.7%）。三是我市第一大主导产业——制鞋业增长乏力，低于规上工业总产值增速。1-10月，全市制鞋产业完成产值376.45亿元，增长15.1%，增幅较1-9月回落0.5个百分点，低于规上工业总产值0.2个百分点，其中，10月份当月增速仅11.7%，比9月回落6.4个百分点，比当月规上工业总产值低3.5个百分点。四是部分主要产品当月产量明显下降。10月份，轻革下降56.0%，家具（不含古典红木家具）下降40.2%，表下降35.5%，盐下降29.8%，模具下降27.8%。五是产能利用率偏低。三季度全市249家大中型和部分小微型工业企业的景气专项调查显示，被调查工业企业生产能力平均利用率仅为80.32%，需求和劳动力供应不足是影响产能利用率提高的主要因素。

（二）消费增长动力不足。社会消费品零售总额增长乏力，累计增速持续下滑，由一季度的20%持续回落到1-10月的13.4%，在全省的排位由年初的第一位降至1-10月的第五位，其中，10月当月限额以上社会消费品零售额只实现个位数增长，仅增长8.0%。零售业发展形势严峻，商品销售额增速直线下滑。1-10月，全市零售业商品销售额363.62亿元，增幅由一季度的35.9%下滑至12.2%，比1-8月、1-9月分别回落6.0、3.3个百分点，在全省位次由第一位降至第八位，其中，10月当月销售额出现负增长，下降10.5%，创近年来的新低。主要原因：一是总部经济型企业总部核算和上年基数抬高的滞后影响逐步显现。对全市限上零售业影响较大的中石化森美（福建）石油有限公司莆田分公司已从6月份开始带上年大幅增加的联营业务及油料批发的基数，同时8月起联营单位业务停止致使该企业商品销售额同比出现6.89亿元逆差，对全市限上零售业商品销售额增幅影响较大。二是受市场等因素影响部分限上企业销售下滑或停业无销售额。10月当月全市共有82家限额以上零售企业商品销售额出现不同程度的下降，另外还有11家当月未营业，占限上零售业企业数的一半。三是新增限上企业少，缺少大型企业拉动。3－9月，全市共新增限上商贸企业15家，其中零售业6家，与全省比，占比明显偏低，仅分别占全省的4.3%和4.5%；与上年同期比，新增企业数明显减少，上年3－9月新增商贸企业20家，其中零售业14家。

（三）投资增长后劲亟待增强。虽然我市固定资产投资一直保持较快的增长态势，但投资质量不高，投资持续较快增长动力不足。一是亿元在建项目支撑乏力。1－10月，全市共有亿元在建项目175个，比去年同期减少12个，共完成投资304.65亿元，增速仅为13.8%，比项目投资低14.9个百分点。二是全市十大开工项目进度滞后。截至10月底，全市十大开工项目只有6个项目实现开工，累计完成投资51.17亿元，仅完成年度计划的57.0%，滞后于序时进度26.3个百分点。三是部分重大项目前期工作有待加强。如：莆田差别化纤维及高端运动系列网生产项目因征地拆迁问题而推迟开工；莆田金鹰林浆纸一体化项目因国际经济大环境尚未好转，该行业还存在严重亏损等，而推迟开工；莆田市丁基橡胶生产项目因行业还存在严重亏损，可研报告上报中海油未获审批，前期工作无法进一步开展。

（四）出口形势有所好转但仍不乐观。1-10月，全市出口总额26.62亿元，增长8.2%，增幅较1-9月提高1.8个百分点，但较上半年回落3.3个百分点，低于全省平均水平2.1个百分点。从出口市场看，对东盟、日本出口分别下降9.7%和11.4%。  

（五）部分经济指标完成情况滞后于序时进度。1-10月，全市地区生产总值1073.01亿元，完成年度计划（1370亿元）78.3%，慢于序时进度5个百分点；社会消费品零售总额344.96亿元，完成年度计划（438亿元）78.8%，慢于序时进度4.5个百分点；进出口总额39.86亿美元，完成年度计划（48.5亿美元）82.2%，慢于序时进度1.1个百分点；进口总额13.24亿美元，完成年度计划（17.3亿美元）76.5%，慢于序时进度6.8个百分点。

三、若干工作建议

（一）稳工业。一是帮扶支柱产业止跌回升。针对部分主导行业持续下滑的问题，政府要有针对性地实施“一企一策”、“一行一策”，切实帮助企业排忧解难，全方位支持企业发展。二是加大优惠政策落实力度，确保已出台的各项政策措施真正落实到位，尤其是针对广大中小企业的税费减免政策一定要落实到位，发挥中小企业在经济发展中的支撑作用。三是加强对产业链深入分析，有针对性地对战略性新兴产业开展招商活动，培育既符合国家产业政策又能发挥莆田优势，具有广阔市场前景且能提升工业发展质量的重大工业项目，努力增强工业发展后劲。四是促进企业提升竞争力。要引导企业围绕产业转型升级，加大新产品的研发；加快技术创新，推动技术改造升级，不断提高产业核心竞争力。积极开拓国内市场，组织企业广泛参加各类产品展销会、洽谈会等活动，提高市场占有率；努力拓展国外市场，企业要主动“走出去”，寻找更大市场机遇，积极融入世界经济，进一步扩大海外市场空间。五是引导园区工业错位发展。在大力推进工业向园区集中聚集的同时，要坚持特色立园，实施错位发展，进一步明确每个园区的功能定位、产业导向，优化园区规划布局，按照规模化、集约化的原则，实现园区推进产业集聚发展，提高园区的单位土地产出率。

（二）强投资。一是加大项目的引进力度。积极策划和推出一批科技含量高、市场前景好、发展潜力大、带动效应强的好项目、大项目，进一步加强项目储备，优化投资结构。创新方式抓项目招商，坚持科学招商、理性招商、优质招商，实施差别化招商，对重大项目要舍得让利、敢于变通，实行个性化服务；实施专业化招商，各个县（区）、各个园区都要有一批熟悉市场规律、掌握技术要点、懂得国际惯例的项目服务团队。二是加大项目的攻坚力度。进一步强化重点项目跟踪服务和督查督办，对未按计划开工的项目要查找难点和关键节点，分解落实推进责任，力争早日开工；对进度较慢的实施项目，梳理制约项目推进的困难和问题，分层协调解决。三是加大技改投入力度。以国家产业政策为指导，结合我市实际，加快技改投入，以高新技术和先进技术改造和提升我市传统工业产业，增强我市经济发展后劲。

（三）扩内需。消费作为扩内需的主要方面，有利于提高经济增长的稳定性和可持续性，在当前外需放缓的情况下，增强消费对经济增长的拉动作用显得尤为重要。一是适当提升城乡居民收入，提高居民购买力。二是深挖农村市场消费潜力，扩大消费需求。农村是消费一大阵地，随着农民人均收入的逐步增加，农民生活水平的不断提高，对消费的需求也在提升。有关部门应适度引导企业向农村市场进军，刺激农村市场消费，形成多样化的消费产业链。三是进一步培育消费热点，加快现有城市综合体配套设施建设，以进一步聚集人气，形成消费增长极。四是推动消费升级，加快发展网络消费和电子商务等新兴商业业态。

（四）促出口。一是加大出口促进政策的力度。提高我市主要出口商品鞋服等劳动密集型产品和高附加值机电产品的出口退税率，完善相关配套措施，加大对出口企业的信贷支持，鼓励和帮助企业克服困难，开发适销对路产品，拓展新的市场。二是认真落实出口信用保费、重点展会补助、重点商品结构优化等常规性政策扶持资金。三是调整进口产品结构，以进口促出口。积极鼓励和引导企业利用和发展加工贸易等机会，加快对国外先进技术和设备的进口，促进传统产业结构优化升级，提升我市加工贸易的产业层次。
