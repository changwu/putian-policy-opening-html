消费市场蓬勃发展 民生工程成效斐然——2010年莆田市消费品市场分析

来源:统计局 时间：2011-03-04 14:46
| | | |

在市委、市政府加快转变经济发展方式、加大改善民生工程建设的方针指引下，消费品市场一派繁荣，2010年共完成社会消费品零售总额2903654.0万元，增幅达18.0%，比上年14.5%的增幅提高了3.5个百分点。分行业看：批发与零售业实现零售额2590431.0亿元，同比增长18.5%；住宿与餐饮业实现零售额313223.0万元，同比增长13.9%。

全市共完成商品销售总额和营业额合计6021924.5万元，同比增长16.8%。其中：批发与零售业实现销售额5658808.6万元，同比增长16.9%；住宿与餐饮业完成营业额363115.9万元，同比增长14.6%。

一、消费品市场运行特点

（一）限上比重稳步提高。一是限上(指限额以上，下同)单位的销售额和营业额占总量比重提高了3.2个百分点。限上单位销售额和营业额从2009年的1407070.8万元增加到2010的1836446.5万元，占全市总量的比重从2009年的27.3%提高到2010年的30.5%，比重提高了3.2个百分点；限下单位和个体户占比重相应从72.7%下降到2010年的69.5%。二是限上单位零售额占总量比重提高4.3个百分点。限上单位的零售额由2009年的455151.2万元增加到2010年的661941.8万元，占总量比重从2009年的18.5%提高到2010年的22.8%，提高了4.3个百分点。限下单位和个体户占比重则从81.5%下降到77.2%。

（二）限上单位贡献较大。一是限上单位2010年销售额和营业额合计1836446.5万元，占总量比重的30.5%，但对总量增幅16.8%的贡献率占49.6%，约占贡献总量16.8个百分点的一半，拉动销售额和营业额总量增幅8.3个百分点；限下单位虽然销售额和营业额4185477.9万元，占总量比重69.5%，是限上单位的2.3倍，对总量的贡献率为50.4%，只比限上单位多贡献0.8个百分点，拉动总量增幅8.5个百分点。二是限上单位2010年零售额661941.8万元，占总量2903654万元的22.8%，它对总量的贡献率为46.8%，（拉动总量增幅8.4个百分点）；限下单位零售额虽然占总量77.2%，是限上单位的3.4倍，它对总量的贡献率为53.3%，只比限上单位高1.2个百分点，（拉动总量增幅9.6个百分点）。由上可知，虽然限上单位的销售额和营业额与零售额两个指标占总量的比重不足三分之一，但由于限上、限下单位的销售额和营业额增幅分别为30.5%与 11.6%，限上、限下单位的零售额增幅分别为45.4%与11.7%，限上单位的较大增幅弥补了比重小的不足，两个因素共同作用的结果使限上与限下单位的贡献接近（具体数据见表一和表二）。

（三）新增限上单位贡献较大。一是在限上单位中，本年新增限上单位的销售额和营业额319280.1万元，只占总量的5.3%，但对销售额和营业额总量增长的贡献达19.4%，（占限上单位销售额和营业额增长贡献率的39.1%）。二是本年新增限上单位零售额总量80974.9万元，只占零售额总量2.8%，但对零售额总量增长的贡献达11.2%，（占所有限上单位零售额增长贡献率的24.9%）。

（四）批发和零售业成为主力。一是批发和零售两个行业全年销售额合计为5658808.5万元，占总量的94.0%，而住宿和餐饮业的营业额仅占总量的6.0%；在新增的865187.7万元销售额中，批发和零售业占818993.1万元，住宿和餐饮业占46194.6万元，两者占新增总量的比重分别为94.7%和5.3%。二是批发和零售两个行业全年零售额合计为2590431.0万元，占总量的89.2%，而住宿和餐饮业的零售额仅占总量的10.8%；在新增的442343.7万元零售额中，批发和零售业占404039.7万元，住宿和餐饮业38304.1万元，两者占新增总量的比重分别为91.3%和8.7%(见表三)。

（五）行业结构保持稳定。一是从销售额和营业额看：批发业销售额占总量比重由2009年52.2%下降到2010年的51.6%、零售业占销售额比重由41.6%提高到42.4%、住宿和餐饮业营业额占比重6.2%下降到6.0%。二是从零售额看：批发业零售额占总量比重从2009年的10.4%下降到2010年10.1%、零售业零售额占总量比重从2009年的78.5%提高到2010年79.1%、住宿和餐饮业零售额占总量比重从2009年的11.2%下降到2010年10.8%。由上可知，一年间各行业的销售额(营业额)与零售额两项指标占总量比重增减变化均不超过一个百分点，两年间各行业的比例保持稳定态势。

（六）衣、食、用、行消费提升较快。居民生活质量提高也可从消费结构的改变体现，从限上单位批发和零售两个行业的销售额分类消费总额看，七类与居民生活质量提高有关的衣食用行商品消费快速增长：一是食品、饮料、烟酒类消费393604万元，增长21.0%；二是衣服及日用品类消费18520万元，同比增长82.4%；三是家用电器和音像器材类消费57780万元，增长51.5%；四是汽车类消费172284万元，增长65.2%；五是石油及制品类消费347370万元，增长54.2%；六是建筑及装潢材料类消费46837万元，增长82.6%；七是五金、电料类消费36443万元，增长55.7% 。以上的一至三类主要是日常生活用品及家庭电器，说明日常生活及用品质量的提高和家电的更新换代较快；四至五类是家庭及集团购买汽车、摩托车和汽油的消费，使出行更加方便；六至七类主要是用于改善居民居住条件的建房及装修材料，反映出住房条件的改善进程加快。

（七）民生工程成效斐然。城乡差别长期扩大化趋势对经济发展和社会稳定的不利因素，如何有效缩小城乡居民的收入差距是各级政府解决民生问题的一个重要的一个重要指标。一年来，通过各部门努力，取得较好的成绩，城镇居民可支配收入由2009年的人均17303元提高到2010年的19068元，增长10.2 %；农民人均纯收入从2009年的6921元提高到2010年的7663元，增长10.7%，农民收入快于城镇0.5个百分点。城乡居民收入的平稳较快发展，加上社会保障逐步完善，特别让农民多年被压抑的消费能力得到释放。城镇居民的消费支出从2009年的11558元/人提高到2010年的12621元/人，增长9.2%，（其中商品消费支出从2009年的9206元/人提高到2010年的9860元/人，增长7.1%）；农民消费支出从2009年的5131元/人提高到2010年的5679元/人，增长10.7%，比城镇快1.5个百分点，说明扩大长期消费不足的农民收入，对拉动消费增长具有加倍的效应。（其中商品消费支出从2009年的3787元/人提高到2010年的4247元/人，增长12.1%，比城镇居民多5个百分点）。

二、主要问题及建议

（一）新增限上单位规模偏小。2010年新增57家限上单位的整体特点是规模偏小，主要体现在：一是平均销售额（营业额）5601.4万元，只占原有限额以上单位户均销售额(营业额)15021.5万元的37.3%。二是新增限上单位平均零售额为1299.7万元，只占原有限额以上单位户均完成零售额5586.7万元的23.3%。虽然其在新增的当年度对增长拉动作用较大，但第二年当其增长较正常时，将受其本身规模较小的限制，对总量增幅拉动能力较小。应积极培养或引进大型商贸企业，以提升限上单位的比重来加大拉动商贸发展的力量。

（二）专业市场品类不全。一是家具市场种类不够全面。我市现有全友、富豪、金日、陈桥家具等的普通家具品牌，古典家具市场主要有连天红品牌，但还没有形成大型专业品牌家具市场，家具市场产品种类较为单调，无法满足不同阶层购买者的需求，许多居民宁愿舍近求远到广东等地的专业家具市场，挑选款式新颖质优价廉的家具，造成我市的购买力大量外流，尽快本市补齐家具市场的空白是许多人的共识。二是药品及农资农药专业批发市场规模偏小，这是造成药品和农资价格虚高的一个重要原因，同时存在监督困难和产品质量不安全的隐患。应规划建设大规模的药品及农资农药专业批发市场，同时在工艺美术城等地组织举办商品展览展销活动，不断做大做强药品及农资农药专业批发市场。
