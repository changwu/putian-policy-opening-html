2009年上半年莆田市经济运行相关因素分析

来源:莆田调查队 时间：2009-07-31 17:02
| | | |

今年以来，莆田市委、市政府紧紧围绕“十百千”目标，抓住国务院支持福建省加快建设海峡西岸经济区的有利时机，以“海西应先行、港城当崛起”为载体，坚定信心，抓住机遇，先行先试，采取有效措施积极应对金融危机，努力化解不利因素，着力保增长、保民生、保稳定，呈现出企业经济稳步发展、居民收入持续增长、消费品市场繁荣发展、市场价格总体下降、农户固定资产投资稳定增长的良好发展势头。

一、经济运行主要特征

1、城乡居民收入平稳增长。据调查资料显示：上半年，全市城镇居民人均可支配收入 9464 元，比上年同期增长12.8%;城镇居民人均消费支出5957 元，增长11.7%。农民人均现金收入4139元，比上年同期增长9.2%；农民人均生活消费支出2386元，增长8.1%。一是从城镇居民收入来源渠道看，呈“三增一降”态势。上半年，全市城镇居民人均工资性收入为7177元，比上年同期增长15.8%，占城镇居民家庭总收入的比重为69.4%，对城镇居民可支配收入增长的贡献率达90.9 %，拉动可支配收入增长11.7个百分点;城镇居民人均转移性收入为1210元，增长16.7%;城镇居民人均财产性收入1270元，增长11.1%。受经济大环境不景气、市场竞争激烈以及商品价格回落等诸多因素影响，个体经营收益减少。上半年，城镇居民人均经营净收入691元，比上年同期下降7.1%，下拉城镇居民可支配收入0.6个百分点。二是从农民收入来源渠道看，呈全面稳步增长态势。上半年，全市农民人均工资性收入为1588元,比上年同期增长15.8%，对农民增收的贡献率达62.4%，拉动农民现金收入增长5.7个百分点；农民人均家庭经营收入为1685元，增长2.6%；农民人均转移性收入为766元，增长9.8%；人均财产性收入为91元，增长27.2%。

2、消费品市场保持良好发展态势。据调查资料显示：上半年，全市限额以下商业消费品实现零售额87.5亿元，比上年同期增长17.0%，占全市社会消费品零售总额的79.8%，对全市社会消费品零售总额增长的贡献率为93.5%。主要表现：一是城乡消费市场同步繁荣。上半年，城市限额以下商业消费品零售额75.4亿元，比上年同期增长17.3%；农村限额以下商业消费品零售额12.1亿元，比上年同期增长15.6%。二是批发和零售业平稳发展。上半年，我市限额以下批发和零售业消费品零售额76.5亿元，比上年同期增长16.7%，增幅比上年同期提高0.4个百分点，占全市限额以下商业消费品零售总额的87.4%，对全市限额以下商业消费品零售额增长的贡献率为85.7%，拉动限额以下商业消费品零售额增长14.6百分点。三是餐饮市场持续活跃。上半年，我市限额以下餐饮业延续上年良好发展态势，实现零售额 10.6亿元，比上年同期增长20.0%，高于同期全市限额以下消费品零售总额平均增幅3.0个百分点，占全市限额以下消费品零售总额的 12.1%，对全市限额以下商业消费品零售额增长的贡献率为13.9%，拉动限额以下消费品零售额增长2.4个百分点。四是亿元市场零售额稳步增长。近年来，随着现代新型商业业态不断扩张，连锁超市、便利店、购物广场、大卖场等吸引了大量的顾客，传统市场虽受到极大的冲击，但仍保持稳步发展态势。上半年，全市亿元市场实现零售额6.7亿元，比上年同期增长14.2%。

3、市场价格总体下降。一是居民消费价格持续走低。据调查资料显示：上半年，莆田市居民消费价格总水平比上年同期下降2.1%。从月份变动情况看，各月与上年同月对比：1月份下降0.5%、2月份下降3.7%、3月份下降2.8%、4月份下降2.1%、5月份下降1.7%、6月份下降1.8%，价格总水平呈现持续下降态势。从地域看，上半年，城市居民消费价格比上年同期下降2.2%、农村居民消费价格比上年同期下降1.5%。从八大类商品价格变动情况看，上半年，食品类价格比上年同期下降0.9%、衣着类价格下降4.9%、交通和通信类价格下降3.2%、娱乐教育文化用品及服务类价格下降3.0%、居住类价格下降5.4%、烟酒及用品类价格上涨1.7%、家庭设备用品及维修服务类价格上涨2.7%、医疗保健和个人用品类价格上涨2.6%。二是农产品生产价格总体趋降。据调查资料显示：上半年，莆田市农产品生产价格比上年同期下降9.4%，其中农业产品生产价格上涨0.6%、林业产品生产价格上涨4.0%、畜禽产品生产价格下降22.9%、鱼业产品生产价格下降6.8%。三是农资价格总水平继续下降。据调查资料显示：上半年，全市农业生产资料价格总水平比上年同期下降7.0%，其中产品畜类价格下降32.0%、化学肥料类价格下降11.4%、农用机油类价格下降6.8%、其它农业生产资料类价格下降5.9%、饲料类价格下降1.4%、农业生产服务类价格上涨12.5%、农用手工工具类价格上涨7.7%、机械化农具类价格上涨3.6%、半机械化农具类价格上涨2.5%、农药及农药械类上涨2.4%。

4、企业家信心指数和企业景气指数双回升。据企业景气监测调查资料显示：第二季度，我市企业家信心指数和企业景气指数分别为102.6和111.6，分别比第一季度上升16.4点和19.0点，均从第一季度的“不景气”区间回归“景气”区间运行。一是从八大行业企业家信心指数看：第二季度房地产业企业家信心指数为127.3，比第一季度上升36.4点，回升幅度居八大行业之首；工业、批发零售业、社会服务业、信息传输计算机服务软件业的企业家信心指数分别为101.3、118.7、100、142.3，分别比第一季度上升21.9、5.9、33.3、32.7点；交通运输仓储邮政业企业家信心指数为87.5，与第一季度持平；建筑业、住宿和餐饮业企业家信心指数分别为86.7、78.6，分别比第一季度下降13.3、21.4点。二是从八大行业企业景气指数看：社会服务业企业景气指数大幅回升，第二季度企业景气指数为100.0，比第一季度上升33.3点；工业企业景气指数触底反弹，第二季度企业景气指数为113.8，比第一季度上升29.5点，进入“低度景气”区间运行；在政府相关帮扶政策发挥效应和购房刚性需求释放的双重利好因素影响下，商品房销售回暖，第二季度房地产业景气指数为109.1，比第一季度上升9.1点；随着政府相关利好政策的出台和整体经济的回暖，第二季度批发零售业企业景气指数为122.9，比第一季度上升4.2点，运行于中度景气区间；建筑业、交通运输仓储邮政业企业景气指数平稳，第二季度建筑业、交通运输仓储邮政业景气指数均为100.0，与第一季度持平；住宿和餐饮业相对淡季，景气指数回落较大，第二季度住宿和餐饮业企业景气指数为64.3，比第一季度下降35.7点，运行于不景气区间；信息传输计算机服务软件业企业景气指数为142.3，比第一季度下降32.7点。

5、农户固定资产投资稳步增长。据调查资料显示：上半年，全市农户完成固定资产投资为8.1亿元，比上年同期增长22.5%。主要表现在：一是建房投资稳步增长。随着钢材价格下降和涉及重点工程的动迁与安置户增多，农户建房积极性与投资额持续扩大。上半年，全市农户建房投资额为7.6亿元，占农户固定资产投资额的93.7%，比上年同期增长19.5%。二是生产设备投资大幅增长。随着农机购置补贴政策的有效实施，我市农民农机投资积极性明显增强。上半年，全市农户用于生产设备投资0.45亿元，比上年同期增长3.8倍。三是第三产业仍成为农户投资的主要领域。上半年，全市农户用于第一产业投资4248万元,比上年同期增长19.5%；用于第二产业投资372万元,增长54.0%；用于第三产业投资76260万元,增长22.6%。农户投向一、二、三产业的投资结构比例为5.3：0.5：94.2,第三产业仍成为农户投资活动的主要领域。

二、经济运行需要关注的几个问题

1、农民增收困难较大。一是农民工转移难度加大。当前我市企业多属于劳动密集型的，也是吸纳农村富余劳动力的主力军。但受金融危机影响，许多中小企业特别是高度依赖出口的中小企业陷入困境，增加农民工就业转移难度。二是农业生产困难重重。受金融危机影响，国际市场需求减少，国内消费能力下降，导致农产品销售困难，农民收入受到较大影响。如我市蘑菇生产主要销往国外，受国际金融危机的影响，国外市场蘑菇需求骤减，蘑菇出口受阻，产品大量积压，价格持续下降。同时，受动物疫情和自然灾害的影响。如规模化猪场疫病和甲型H1N1流感的暴发，致使猪肉产品消费严重下滑；且近期南日海域出现大面积赤潮，南日鲍鱼品质受到影响导致价格大幅下降。

2、城镇居民高低收入户差距扩大。一是城镇居民低收入户收入下降。据调查资料显示：上半年，我市城镇居民最低收入户人均可支配收入仅3346元，比上年同期下降2.9%，其中人均经营净收入765元，下降2.9%；人均财产性收入90元，下降75.6%，导致城镇居民低收入户收入增幅低于消费增幅14.3个百分点，生活面临许多困难压力。二是高低收入户差距扩大。上半年，我市城镇居民最高收入户人均可支配收入17342元，比最低收入户人均可支配收入高出13996元，高低收入户人均可支配收入比例由上年同期的4.57：1扩大到5.18：1，拉大61个百分点。

3、中小企业融资难问题依然存在。一是货款拖欠问题仍未得到有效解决。第二季度，货款拖欠景气指数为94.5，比第一季度下降1.2点。认为第二季度应收未收的到期货款比第一季度减少的企业仅占15.6%，比第一季度减少3.7个百分点；认为到期货款与第一季度持平的占63.3%，增加6.2个百分点。特别是建筑业企业因工程款不到位，造成资金周转困难，承接建筑工程更加困难，货款拖欠景气指数为100.0，比第一季度下降26.7点。二是资金偏紧状况仍未改善。第二季度，企业流动资金景气指数为99.5，比第一季度下降0.2点，处于不景气区间；企业融资景气指数为95.1，虽比第一季度上升7.0点，但仍位于景气临界点下，处于不景气区间。

4、农村劳动力就业保障仍有待加强。一是农村劳动力养老保险程度低。据农民工监测调查资料显示：第二季度，在农村从业劳动力中，参加农村社会养老保险的只占4.2%，参加城镇基本养老保险的也只有4.2%，而没有参加任何养老保险的则占87.6%；在本地非农务工的农村劳动力中，单位或雇主为农民工上养老保险的仅为9.3%，在外出从业劳动力中也仅占14.3%。二是劳动力外出组织化程度不高。第二季度，农村外出劳动力由政府或单位组织的只占4.8%，由中介组织介绍的仅占0.8%；而由亲朋好友介绍的则占63.7%，盲目的自发外出的占28.2%。三是劳动力合同签约率低。第二季度末，在农村本地非农务工劳动力中，农民工与用人单位未签订劳动合同占59.3%、签订无固定期限合同的只占9.3%、签订一年及以上合同的占16.3%、签订一年以下合同的占8.1%。

三、下阶段经济工作的对策建议

1、切实加大农民增收的工作力度。一是继续加强农资、农产品价格的监管，持续稳定农资市场价格，解决好农业生产成本增长过快对农民增收带来不利的影响。二是加强市场建设，搞好农产品流通。要着力解决流通渠道不畅、销售困难、信息不灵等问题，积极发挥农业协会和组织作用，及时解决农产品卖难、卖贱问题。三是转移农村劳动力，发展非农产业。要进一步推进城镇化建设，吸纳农村人口向城镇转移，大力发展非农生产，进一步拓展农民增收空间。

2、采取切实可行措施，增加低收入阶层居民收入。扩大就业是增加城镇居民收入的根本措施，也是拉动城镇居民消费的前提。特别对低收入的弱势群体，不但要进行“输血”，更要进行“造血”，采取各种有效措施为他们提高劳动技能，创造更多就业机会，使低收入群体不断增加收入；要加快社会保障制度建设，扩大保障范围、提高保障水平，重视完善收入分配制度，缩小收入差距，着力提高低收入群体收入水平。同时，应加大扶持非公有经济发展力度，特别是个体经营经济发展，尽力减轻个体经营者的税赋，增加个体经营者收入。

3、解决中小企业融资难题，促进中小企业健康发展。中小企业是莆田经济的重要支撑。要加快莆田经济的快速发展，首先要加快中小企业的发展。从目前的情况来看，中小企业的发展面临诸多困难，特别突出的是中小企业融资难。因此，要创新思维，创新方法，多途径、多渠道帮助中小企业解决融资难的问题，努力促进中小企业的健康发展。

4、建立和健全农村劳务保障体系建设。一是加强对用人单位劳动用工的监管，建立和完善农民工的社会保障体系,做好农民工的劳动保障工作，提升农民工的合同签约率，加大对农民工的劳动保障，解除他们的后顾之忧。二是加强劳务市场管理，不断提高劳务市场组织化程度，广泛收集用工信息，努力拓宽就业的空间。三是强化农村劳动力职业技能培训，提高转移能力和速度。要重视和不断加强对农民的职业技能培训工作，整合城乡教育资源，开展农民技能培训，使农民掌握科技兴农或非农实用技术，提高农民转移就业的能力，努力推进农村剩余劳动力向二、三产业转移。
