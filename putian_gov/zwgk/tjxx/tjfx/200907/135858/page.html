莆田市2009年上半年房地产市场运行形势分析

来源:市建设局 时间：2009-07-31 09:24
| | | |

随着一系列促进房地产市场健康发展政策的呈效, 上半年，我市房地产完成投资出现回升，商品房新开工及销售面积增加，二手房交易活跃，土地出让市场回暖等特征。现将我市2009年上半年房地产市场运行形势汇报如下：

一、房地产开发投资持续回升，土地购置费上升明显:

今年1-6月份，全市房地产开发完成投资32.78亿元，较去年同期比降8.89%，其降幅较第一季度（-17.78%）回升近9个百分点(各月份投资额对比见图1)。在房地产投资中，建安投资下降，土地购置投资上升，其中建安投资完成19.15亿元，占投资总额的58.42%，比降25.66%；土地购置费11.19亿元，占34.14%，比增36.63%；其他费用2.44亿元，占7.44%，比增20.20%。

 

从不同区域投资情况看，设区市本级降幅较小，仙游县同比下降较多，投资额所占的比例同上年基本持平。上半年设区市本级（含荔城、城厢、涵江、秀屿四区）完成投资28.27亿元，占86.24%，比降7.61%；仙游县完成投资4.51亿元，占13.76%，比降15.58%。

二、商品房供求面积皆呈上升，空置面积尚余较大：

上半年全市各类商品房施工面积为632.04万m2，较去年同期比增10.25%，其中新开工面积66.87万m2，同比下降61.73%，较一季度（-76.84%）回升15个百分点（各季度新开工面积见图2）。从去年至今年各季度的新开工面积看，2008年由于房地产市场低迷，新开工面积逐季下降，至今年一季度降至最低谷，随着房市的回暖，第二季度出现回升现象，说明开发商对市场信心的恢复。

 

    由于新开工面积的回升，批准商品房预售面积也随之上升。1-6月份全市批准商品房预售面积70.62万M2，较去年同期比降36.16%，较一季度（-67.02%）回升近31个百分点，其中第一季度为19.80万M2，第二季度为50.82万M2。

上半年全市销售商品房面积58.80万m2，较去年同期比增5.63%，其中第一季度销售25.88万m2、比增26.43%；第二季度销售32.92万m2，比增0.67%，增幅减缓但销售面积不断增加（见图3）。从2008年至今各季度的销售量看，经过去年第四季度的最低谷后，今年的销售面积已经出现回升态势。

 

    另外从不同区域看，设区市本级商品房销售面积比增较大，其中住宅商品房销售增幅达38.70%，而仙游县的商品房销售仍为比降，下降幅度为43%（见表1）。

三、二季度商品房售价同比上升，新开楼盘价位普遍上调：

据统计，全市商品房的平均销售价格为3919元/ M2，同比上升12.58%，其中住宅商品房3859元/ M2，同比上升18.16%。从各季度看，第一季度全市商品房均价3734元/ M2（其中住宅均价3672元/ M2），第二季度商品房均价4067元/ M2（其中住宅均价4010元/ M2），全市均价首超4000元/ M2（见表3）。从对部分有代表性楼盘房价动态跟踪情况看，一季度期间，大部分楼盘的售价基本都维持在去年开盘时的价位，到第二季度，随着新开楼盘价位的提高，部分在售楼盘的销售价格也取消原来的打折优惠跟着上调价位，幅度每平方米在200元左右，促使全市商品房价位的上升。

四、二手房交易面积逐季上升，交易均价涨幅较大：

在一系列税费优惠政策的支持下，我市二手房交易呈不断上升趋势。上半年，全市二手房交易面积36.89万m2，比增83.35%；成交金额102765万元，比增238.79%；均价2786元/m2，上升83.65%（见图4）。由于近年一些新建商品房进入二手房流通领域，促使二手房交易均价的大幅上调。

 

在二手房交易中，设区市本级交易量上升较大，交易面积呈成倍比增，交易金额比增达2倍以上（见表4）。

    五、土地出让市场升温,设区市本级供应量比增明显：

上半年，随着房市的持续回暖，土地出让市场也呈不断升温态势，特别是近期我市推出一些地段较好的地块，在拍卖中经几十回的竞价后才中标。1-6月份国土部门通过招拍挂新供应经营性房地产项目用地18宗38.5098公顷，折合约577.65亩，与去年同期（622.26亩）比降7.17%；总价款89497万元，平均每亩154.93万元，较去年同期（80.26万元/亩）上升93.04%。在所供应的18宗地块中，其中市本级11宗33.4067公顷，比增357.13%，总价款66690万元，平均每亩133万元，比增27.88%；仙游县7宗5.1031公顷，比降85.07%，总价款22807万元，平均每亩298万元，比增297.33%，其所出让的地块主要位于城关，故价位较高。

   六、房地产资金来源同比略增，除银行信贷外，其他资金同比下降：

本年资金来源合计62.91亿元，比增12.62%，其中2008年末结余资金18.53亿元，2009年资金来源44.38亿元，比增0.86%。在1-6月份资金来源中，国内贷款9.63万元、占21.70%，比增20.22%；自筹资金18.65亿元、占42.02%，比降5.95%；其他资金来源（定金、预售款及个人按揭贷款等）16.10亿元、占36.28%，比降0.37%。

总之，上半年随着国家整体经济的回升以及相关政策的促进下，我市房地产市场供求双方信心逐步恢复，房地产投资、商品房新开工及销售、二手房交易、土地出让等各项指标皆呈上升趋势，整个房地产市场表现为持续回缓态势。
