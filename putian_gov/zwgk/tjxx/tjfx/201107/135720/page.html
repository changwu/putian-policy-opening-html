投资持续高位运行 有力支撑莆田经济发展——2011年上半年莆田市固定资产投资运行情况分析

来源:统计局 时间：2011-07-24 11:07
| | | |

投资是今年我市经济运行的最大亮点，也是经济发展的最强有力支撑，关系着莆田发展的未来。今年以来，全市上下紧紧抢抓《海峡西岸经济区发展规划》颁布的重大历史机遇，继续保持攻坚克难的劲头，以“追”和“赶”的姿态，以“拼”和“闯”的决心，继续打好“五大战役”、大干开局之年，凝心聚力抓建设，心无旁骛谋发展，促进投资持续高速增长，有力支撑莆田经济快速发展。

今年上半年，全市共完成全社会固定资产投资353.31亿元，比去年同期增长62.4%，增速比上年加快39.6个百分点。其中，城镇以上固定资产投资315.85亿元，增长70.2%，增速加快46.1个百分点，其中城镇项目完成投资236.18亿元，增长65.4%；房地产开发完成投资79.67亿元，增长86.0%。

一、投资运行的主要特点

（一）投资持续高位运行，增幅稳居全省首位。年初以来，我市固定资产投资持续高速增长，投资增幅稳居全省首位，明显高于全省平均水平和上年同期。2月至6月，我市全社会投资同比累计增幅分别为59.5%、55.2%、57.1%、55.5％和62.4%，各月投资累计增速分别比全省平均水平高23.7、20.6、21.8、20.6、31.1个百分点，分别比上年同期高40.8、36.8、38.6、34.6、39.6个百分点。其中城镇以上各期投资增幅分别为67.4%、65.1%、66.9%、64.6%和70.2%，分别比上年同期高47.0、45.3、46.1、41.2、46.1个百分点。

（二）各县(区)投资形势喜人，区域增长协调性增强。从分县(区)看：上半年我市全社会投资除了湄洲岛下降外，其他各县(区)的增速均保持在40%以上。县(区)间的增速差异明显缩小，增长协调性有所增强，县区间的增速差距从去年同期的353.4个百分点缩小为今年的165.9个百分点。北岸增速继续保持领先优势，增速比全市快90.8个百分点，比排在第二位的涵江区快87.6个百分点。对全市全社会投资贡献率达到20%以上的有2个县(区)：荔城区和涵江区，对全市全社会投资的贡献率分别达到了22.3%和21.5%。

（三）三次产业投资增速全面加快，投资增速均在60%以上。上半年，在全市固定资产投资总量保持持续高速增长的同时，三次产业投资增速全面加快，投资增速均在60%以上。上半年 ，一产投资6.14亿元，增长78.9%，增速比上年同期加快44.6个百分点，占全社会投资的比重为1.7%，比上年同期提升0.1个百分点；二产完成投资126.40亿元，增长61.0%，增速比上年同期加快43.0个百分点，占全社会投资的比重为35.8%，比上年同期回落0.3个百分点；三产完成投资220.77亿元，增长62.7%，增速比上年同期加快37.4个百分点，占全社会投资的比重为62.5%，比上年同期提升 0.2个百分点，对全社会投资的贡献率达62.7%。

（四）三大投资主体投资增速全面加快，外资投资增速领先，民间投资成为拉动投资增长的主动力。上半年，国有、外资、民间三大投资主体投资增速全面加快，增速分别比去年同期加快1.6、137.5、55.2个百分点。外资投资增速高达1.5倍，继续保持领先优势，分别比同期全社会投资快86.8个百分点，分别比国有、民间快111.7个和76.3个百分点。外资企业投资的高增长主要得益于海峡国际商贸城和差别化化学纤维的强劲拉动。民间投资增势强劲，增速高达72.9%，比同期全社会投资高10.5个百分点，占全社会投资的比重为50.1%，分别比国有、外资高11.4个和38.9个百分点，投资比重比上年同期提升3.1个百分点，拉动全社会投资增长34.3个百分点，成为拉动投资增长的主动力；对全社会投资的贡献率达到54.9%，继续成为我市投资的主角。

（六）亿元项目投资增势强劲，带动作用明显。上半年，全市共有在建亿元及以上项目(不含房地产开发项目)162个，比上年同期增加39个，计划总投资达1254.61亿元，增长53.1%，1-6月累计完成投资184.15亿元，增长71.9%，增速同比加快18.1个百分点，增速比同期500万元以上项目快16.9个百分点，占500万元以上项目总投资的比重为75.0%，比上年同期提升7.4个百分点，对500万元以上项目的贡献率达88.3%；占同期全社会投资的比重为52.1%，对全社会投资的贡献率达56.7%。

（七）房地产开发投资持续高速增长，商品房销售面积小幅增长。今年上半年，我市房地产开发投资一直在高位运行，2-6月投资增速分别为62.5%、40.6%、63.9%、68.0%、86.0%。上半年全市房地产开发完成投资79.67亿元，增长86.0%，同比加快55.3个百分点。其中建安工程完成投资49.77亿元，增长102.5%，对房地产开发总投资的贡献率达68.4%；其他费用完成投资29.63亿元，增长64.5%，在其他费用中土地购置费完成投资25.37亿元，增长102.8%，对房地产开发总投资的贡献率达34.9%。在建商品房屋施工总面积为1169.89万平方米，增长57.4%；其中本年新开工面积为391.89万平方米，增长112.9%。全市商品房销售面积为81.65万平方米，增长8.9%，增幅比上期提升1.9个百分点，其中本月销售11.21万平方米，增长22.4%，环比增长30.7%；商品房总销售额为46.03亿元，增长24.9%，增速比同期商品房销售面积快15.3个百分点。

（八）建设资金较为充足，自筹资金依然是资金来源的主要渠道，利用外资成倍增长，银行贷款出现下降。上半年，我市建设资金仍然较为充足，为全市投资建设快速推进提供了有力保障，全市建设单位累计到位资金459.70亿元，增长42.0%，建设资金是投资额的1.3倍。其中，自筹资金到位273.12亿元，增长41.5%，占建设资金总额的59.4%，自筹资金依然是资金来源的主要渠道。受海峡国际商贸城和差别化化学纤维两个项目影响，利用外资大幅度增加，为28.31亿元，增幅高达4.1倍。受国家宏观调控政策影响，随着存款准备金率不断上调，银根收缩，银行贷款开始下降，上半年国内贷款46.60亿元，下降14.0%，下降幅度比一季度缩小1.7个百分点。

二、上半年我市投资运行态势较好，但当前投资运行中仍存在不容忽视的问题：

1、基础设施投资缺乏新的增长点，增长乏力。今年以来，随着一些大型基础设施项目建设陆续投产、进入扫尾阶段，由于缺少新的大型项目支撑，我市基础设施投资缺乏新的增长点而增长乏力。上半年我市基础设施建设完成投资82.57亿元，增长8.5%，增速同比放慢11.9个百分点，占全社会投资的比重为23.4%，同比下降11.6个百分点。其中：电力、燃气及水的生产和供应业完成投资27.28亿元，由上年同期的增长24.5%转为今年的下降3.8%；市政建设完成投资10.34亿元，由上年同期的增长68.6%转为今年的下降37.8%；水利、环境和公共设施管理业完成投资15.09亿元，增长6.0%，增速同比放慢53.4个百分点。

2、社会事业投入明显不足，占全社会投资的比重仅为7.4%。今年以来，我市社会事业投资明显不足，上半年仅完成投资26.26亿元，增长7.2%，增速同比放慢28.8个百分点，占同期全社会投资的比重仅为7.4%，同比下降3.9个百分点。其中卫生、社会保障和社会福利业完成投资0.74亿元，由上年同期的增长1.2倍转为今年的下降77.3%；文化、体育和娱乐业完成投资1.58亿元，由上年同期的增长11.5%转为今年的下降34.1%；公共管理和社会组织完成投资1.37亿元，下降52.3%，降幅扩大48.9个百分点。

3、工业投资外延性扩张明显，投资质量下降。今年上半年，我市工业投资的外延性扩张特点表现依然较为突出，投资仍以新扩建为主，改建和技术改造项目投资占比仍然偏低，设备工器具购置投资比重明显下降，投资外延性扩张明显，投资质量下降。上半年在工业投资中：新扩建项目投资大幅增长，占工业项目总投资的比重高达95.9%，同比提高15.1个百分点，而改建和技术改造项目投资下降17.0%，占工业总投资的比重仅1.9%，同比下降1.7个百分点；其中设备工器具购置投资增速放缓，仅增长19.1%，同比回落33.6个百分点，比同期工业投资慢42.6个百分点，占工业总投资的比重为31.0%，同比下降11.1个百分点。
