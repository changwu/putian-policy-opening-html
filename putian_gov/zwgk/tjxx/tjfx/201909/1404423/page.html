1-8月莆田市经济运行情况分析

第六十期
第六十期
来源：本网 时间：2019-09-18 08:15
| | | |

1-8月，受规模以上其他营利性服务业增速回落、位次后移影响，全市经济呈总体平稳、稳中趋缓的运行态势。

一、经济运行主要特点

（一）工业生产稳步回升。1-8月，全市规模以上工业增加值可比增长8.5%，增幅比1-7月回升0.1个百分点，居全省第五位，增幅位次比1-7月前移两位。主要亮点：一是重点产业贡献突出。全市规模以上化工新材料、电子信息、高端装备三大产业分别拉动全市规模以上工业增加值增长2.1个、1.1个和0.9个百分点。二是工业生产后劲增强。全市75家新增规模企业共拉动全市规模以上工业增加值增长2.0个百分点。其中，19家去年以来新投产企业拉动全市规模以上工业增加值增长1.7个百分点；56家2018年底“下转上”企业拉动全市规模以上工业增加值增长0.3个百分点。三是“三新”工业经济快速增长。全市战略性新兴产业工业增加值可比增长11.3%，高技术企业工业增加值可比增长13.2%，装备制造业工业增加值可比增长15.1%。

（二）市场销售稳中趋缓。1-8月，全市社会消费品零售总额实现545.81亿元，同比增长9.7%，增幅分别比1-7月、上年同期回落0.2个和2.7个百分点。主要亮点：一是新增企业拉动有力。2018年以来新入库的533家企业实现零售总额44.21亿元，增长121.7%，拉动全市社会消费品零售总额增长4.9个百分点。二是网络消费保持两位数增长。全市限额以上网络零售额125.01亿元，同比增长14.3%，增幅高于全市社会消费品零售总额4.6个百分点。三是品质类商品零售涨幅较大。如可穿戴智能设备零售额增长173.2%；新能源汽车增长97.5%；智能手机增长17.2%。四是部分有店铺零售业绩较好。限上便利店、食杂店、百货店实现商品零售额同比分别增长30.2%、19.6%和18.0%。五是住餐业较快增长。1-8月，全市限额以上住餐业营业额增长21.7%，主要是下半年以来企业宴会收入逐步增加拉动。

（三）固定资产投资增速有所回落。1-8月，全市固定资产投资同比增长9.2%，增幅比1-7月回落0.8个百分点,居全省第二位。主要亮点：一是在建亿元项目高速增长。全市222个在建亿元项目完成投资增长54.3%，增幅分别比上年同期、全市固定资产投资高66.8个和45.1个百分点，其中，89个本年新开工亿元项目完成投资同比增长119.4%。二是房地产投资拉动明显。全市房地产业投资同比增长29.4%，增幅比上年同期高33.9个百分点，对全市固定资产投资增长的贡献率为57.9%，拉动全市固定资产投资增长5.3个百分点。三是工业投资增速提升。全市工业投资同比增长8.3%，增幅同比上年同期高3.6个百分点，占全市固定资产投资的比重为29.3%，对全市固定资产投资增长的贡献率为26.8%，拉动全市固定资产投资增长2.5个百分点。

（四）房地产销售有所回升。1-8月，在稳政策稳房价稳预期大环境下，经过去年以来的市场观望后，今年购房需求开始逐步重新释放，同时在限价房政策推动下，市场交易趋于活跃，房地产市场总体保持稳步回升的发展态势，商品房销售面积完成295.85万平方米，同比增长5.5%，增幅比1-7月回升0.6个百分点，主要是中海国际单月销售火爆拉动。

三、主要问题

（一）工业回暖基础还不牢。一是中美贸易摩擦因素影响后期逐步显现。制鞋业关税的加征，直接影响制鞋企业的订单量。据企业主反映存在后期订单不敢接，对鞋业加征关税直接挤压企业利润，导致企业亏损。二是减停产面居高不下。8月末，全市规模以上工业停、减产面达32.1%，共拉低全市规模以上工业增加值增幅6.6个百分点。三是降成本任重道远。1-7月，全市规上工业企业主营业务成本同比增长10.7%，高出全市规上工业主营业务收入增速0.7个百分点；每百元主营业务收入中的成本为88.72元，同比增加0.55元；全市规模以上工业利润总额同比仅增8.0%，增幅低于全省平均水平2.0个百分点。

（二）部分商品销售疲软。一是鞋帽类商品零售持续回落。1-8月，全市限上鞋帽类商品零售额80.38亿元，同比增长6.0%，增幅比1-7月回落2.3个百分点，其中8月当月下降7.9%。主要是部分实体店受电商企业冲击以及电商企业关闭影响。二是粮油、食品类商品个位数增长。1-8月，限上粮油、食品类商品零售额仅增4.9%，增幅同比回落14.6个百分点，其中8月当月仅增0.3%。三是家电类商品消费饱和。家电更新换代较慢，又恰逢淡季，1-8月，家电类商品零售额下降20.0%，主要受家电更新换代较慢，恰逢淡季影响。

（三）投资需求领域压力较大。一是项目个数减少，投资额下降。1-8月，全市在库项目1526个，同比减少552个，特别是5000万以下项目1241个，同比减少592个，投资额同比下降45.2%。二是基础设施投资持续降势。1-8月，全市基础设施投资同比下降6.3%，增速比上年同期回落16.9个百分点。其中交通运输业投资同比下降22.2%，降幅比1-7月扩大1.8个百分点；电力、热力、燃气及水的生产和供应业投资下降15.9%；水利管理业投资下降12.3%。三是民间投资回落明显。1-8月，全市民间投资同比仅增4.5%，增幅分别比1-7月、上年同期回落1.2、35.2个百分点，其中项目民间投资增速回落61.0个百分点，工业民间投资增速回落23.4个百分点。

（四）规上服务业位次后移明显。1-7月，全市规模以上其他营利性服务业营业收入同比增长22.3%，增幅分别比1-6月、1-5月回落1.3个和2.5个百分点，居全省第6位，比1-6月后移5位，预计第三季度乃至全年可能继续回落到20%以下，将会拉低全市第三产业增加值增速1.1个百分点左右。主要原因：一是秀屿区医疗咨询行业受省税务局核查事件影响增速明显下滑，拉低全市其他营利性服务业营业增幅5.4个百分点。二是缺乏新增长点支撑，截止8月底全市尚未有新增入库企业，持续增长后劲堪忧。

四、对策建议

（一）激发工业发展活力。狠抓激励政策落地落实，着力降低企业成本，解决企业融资难融资贵问题，营造公平竞争环境，培育和扩大消费市场，切实增强企业加快生产的信心和动力。建立工业企业问题清单制度，采取“一企一策”，有针对性帮助重点困难企业解决发展瓶颈制约问题，扶持重点停产企业尽快复工复产。

（二）扶持消费品市场发展。要积极落实国家、省、市各项扩大居民消费政策措施，结合市场实际，进一步放宽服务消费领域市场准入，完善促进实物消费结构升级政策体系，加快推进重点领域产品和服务标准建设，优化促进居民消费的配套保障，加强消费宣传和政策引导。鼓励城市连锁和超市向农村延伸，鼓励零售企业下乡，积极开拓农村消费市场。

（三）加大重点项目推进力度。要进一步梳理重点项目推进情况，加强重点项目要素保障，继续加大招商引资力度，积极谋划一批优质民生社会事业项目以PPP模式向社会资本招商，激发民间资本活力，缓解政府资金压力；对未按时开工或推进缓慢的项目，分析存在的问题，及时提出解决措施，尽快整改落实到位；对推进顺利的项目，在确保安全和质量的前提下，加快施工进度。

（四）培育规上服务业新增长点。各行业相关主管部门一方面要加强与市三产办的协调配合，形成有效的工作合力，重点要加强对联网直报企业的调研和跟踪监测，确保应统尽统、应统必统，另一方面要积极督促各县区配合统计部门做好入库入统工作，尤其是单位数较少、存在空白行业的县区和相关行业主管部门要加强企业培育，将达到规模标准的企业尽快纳入规上服务业统计范围。
