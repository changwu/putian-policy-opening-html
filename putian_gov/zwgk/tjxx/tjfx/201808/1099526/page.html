2018年上半年莆田市农林牧渔业生产情况简析

第四十一期
第四十一期
来源：本网 时间：2018-08-02 09:37
| | | |
 年初以来，市委、市政府坚持以习近平新时代中国特色社会主义思想为指引，认真贯彻落实中央、省委一系列决策部署，以“创新、协调、绿色、开放、共享”新理念引领农业新发展，以“提质增效转方式、稳粮增收可持续”为工作主线，扎实推进农业供给侧结构性改革，加快发展特色现代农业，大力提升农业质量效益，持续加强农业生态建设，促进农业绿色发展，保障我市农业农村经济保持健康可持续发展。

一、主要运行特点

（一）农林牧渔业总产值稳步增长，增幅有所提升

2018年上半年，全市实现农林牧渔业总产值98.02亿元，按可比价计算，比上年同期增长3.6%，增幅比一季度提升3.3个百分点。其中，农业产值18.56亿元，可比增长1.0%；林业产值0.88亿元，可比增长4.0%；牧业产值12.65亿元，可比增长2.7%；渔业产值57.80亿元，可比增长4.8%；农林牧渔服务业8.13亿元，可比增长5.4%。

（二）蔬菜生产情势良好，产量稳步增加

自去年底以来，我市各级统筹推进“菜篮子”工程建设，积极发展现代设施蔬菜，蔬菜播种面积不断扩大，产量稳步增加。2018年上半年,全市蔬菜播种面积为16.80万亩，播种面积比上年同期扩大19498亩,增长13.1%；产量为30.21万吨，比上年同期增加8681吨，增长3.0%。

（三）枇杷受灾严重，产量减半

今年初，我市出现低温和强冷空气，部分山区甚至出现下雪的极寒天气，枇杷幼果受冻，特别是早钟等早熟品种受冻严重，部分农户甚至颗粒无收。2018年上半年,全市园林水果产量为6.74万吨，比上年同期减少62874吨，下降48.7%。其中枇杷产量为5.84万吨，比上年同期减少62827吨，下降51.8%。

（四）茶叶种植面积不断扩大，产量逐年增加

近几年我市陆续扩大茶叶种植面积，且随着茶叶种植管理的跟进、种植技术的投入、茶树龄的增加、生产茶叶的茶树分枝增多，茶叶产量逐年增加。上半年，全市茶叶产量为0.20万吨，增长7.9%。其中红茶产量为232吨，增长23.4%；绿茶产量为152吨，增长8.6%；青茶产量为1657吨，增长5.9%。

（五）食用菌生产效益下降，生产规模不断萎缩

近几年来，由于受人工费用等生产成本提高影响，我市食用菌生产效益不断下降，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其他仍在我市的食用菌生产大户生产规模也只减不增，食用菌产量受之影响呈逐年下降趋势。2018年上半年，全市食用菌产量为3.36万吨，比上年同期净减1.83万吨，下降35.3%，降幅比上年同期扩大30.9个百分点。其中，蘑菇产量3.19万吨，下降35.0%；姬松茸产量0.05万吨，下降65.2%；香菇产量0.08万吨，下降20.6%。食用菌生产占用耕地面积5470亩，比上年同期减少1997亩，下降26.7%；蘑菇种植面积373.07万平方米，比上年同期减少234.56万平方米，下降38.6%；蘑菇单产为每平方米8.6公斤，增长5.8%。

（六）木材采伐量扭转下降态势，呈现大幅增长

今年以来，我市开始在全市范围内开展大造阔叶树、改造桉树行动计划，该行动计划可增加林业采伐量和造林数量。受此行动影响，今年上半年全市木材采伐量扭转下降态势，呈现大幅增长。2018年上半年，全市木材采运量为4.63万立方米，比上年同期增加0.64万立方米，增幅从一季度的下降42.6%转为增长16.0%。其中原木采运量为4.59万立方米，比上年同期增加0.62万立方米，增长15.7%。在原木采运量中，杉木采运量为0.52万立方米，下降15.8%；松木采运量为0.35万立方米，下降54.7%；杂木采运量为3.72万立方米，增长44.6%。

（七）生猪出栏价格有所回升，畜牧业肉类总产量增幅由负转正

今年一季度全国生猪价格持续下跌，全国性的恐慌大甩卖导致市场的最终饱和，我市生猪养殖户也争先出栏，但因生猪市场达到饱和很多养殖户无法出栏，导致我市生猪出栏大幅下降。今年二季度生猪出栏的价格有所回升（据农情调查，最低生猪出栏价格为10.4元/公斤，目前为13.6元/公斤，猪肉当季增长8.18%），家禽经过一年多的亏损，从去年7月份开始盈利。随着畜牧业养殖基本面整体向好，畜禽养殖户开始积极补栏，出栏数也在不断增加，肉类总产量也相应增加。2018年上半年，全市生猪出栏41.92万头，同比下降4.5%，降幅比一季度收窄8.6个百分点；生猪肉产量为3.35万吨，下降2.2%，降幅比一季度收窄9.3个百分点。

家禽出栏1384.63万只，由一季度的下降17.2%转为增长19.5%。其中：大型养殖场户出栏696.67万只，增长23.8%；中小型养殖场户出栏137.60万只，增长23.2%；散户出栏550.36万只，增长13.6%。家禽肉产量为1.63万吨，由一季度的下降15.1%转为增长15.8%。

全市肉类总产量5.03万吨，由一季度的下降12.2%转为增长3.0%；禽蛋产量1.52万吨，下降2.1%；奶产量0.16万吨，下降6.5%。

（八）渔业生产有序推进，水产品产量稳步增长

近年来，我市加快开发设施渔业，积极推进南日岛东部现代海洋渔业综合开发示范区建设，持续推广生态养殖模式，启动渔业底播增殖工程，引进南美白对虾高位池养殖，推广“购大苗养中鲍”养殖生产模式和网箱混养模式，积极发展海洋捕捞，有力促进了我市渔业生产科学持续良性发展。2018年上半年，全市水产品总产量达58.28万吨，产量比去年同期净增2.74万吨，同比增长4.9%。其中海水产品产量56.46万吨，产量比去年同期净增2.65万吨，增长4.9%；淡水产品产量1.83万吨，产量比去年同期净增0.08万吨，增长4.9%。在海水产品产量中：牡蛎产量为22.40万吨，产量比去年同期净增0.83万吨，增长3.8%，对全市水产品总产量的贡献率高达30.3%；江篱产量为6.57万吨，产量比去年同期净增0.92万吨，增长16.3%，对全市水产品总产量的贡献率高达33.7%。

二、存在的主要问题

（一）生产成本及农产品价格对农业生产影响较大。一是近几年来受我市人工费用等生产成本不断提高影响，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其在我市的生产规模只减不增，我市食用菌生产规模逐年缩小。二是畜牧业生产受价格影响大，今年一季度我市生猪受全国生猪价格下跌影响存出栏均呈现大幅下降态势，二季度随着生猪价格的逐步回升，存出栏也由下降转为增长。

（二）农作物种植面积保持有难度。一是种粮比较效益偏低，农民种粮积极性不高，粮食播种面积和产量呈逐年下降态势。二是由于农民外出务工相比在家务农收入较高，我市部分山区青壮年人口常年外出打工，家里剩下老人与小孩，耕地因缺少劳动力耕作导致抛荒。三是受征地拆迁影响，耕地面积逐渐流失，特别是南北洋适合种植水稻的大片良田流失严重。

（三）畜禽可养范围较小，仅占全市总村居数的15%。根据市政府印发的《莆田市畜禽禁养区及禁建区划定方案》、《莆田市畜牧业集约化发展规划》（莆政综〔2010〕48号）和《莆田市人民政府关于公布畜禽养殖禁养区、禁建区及可养区的通知》（莆政综〔2011〕125号），全市行政区划内有近三分之二以上区域为禁养区，其中北岸和湄洲岛全境范围禁养；我市行政区划内可养区只有146村，占全市村居委会总数的比重为15.0%，其中仙游县52个村、城厢区15个村和秀屿区79个村。

（四）海洋经济短板仍未得到改善，渔业发展空间受限。随着城市建设和工业化的发展，适宜养殖发展的水域和滩涂等养殖区不断受到蚕食，水产养殖空间越来越小；湾外养殖扩展技术尚在实验阶段，技术难度大且风险高，尚需资金扶持，渔民参与积极性不高；海产品加工业发展滞后，不能有效促进渔业发展。

三、下一步建议

（一）以市场为导向，强化政策引导，提高农民农业生产积极性。要全面了解我市农业生产基本情况，摸清全市农业产业基本构架，分析预测农产品市场需求，有针对性地出台激励政策，提高农民农业生产积极性，尽可能避免耕地抛荒。

（二）加快农村耕地流转，扩大农作物种植规模。耕地流转是农业生产规模化的基础和前提。政府要出台相关政策引导、鼓励农村耕地流转，通过耕地流转把抛荒的耕地集中到种植大户、种植农民专业合作社和种植业龙头企业，发展适度规模的种植业生产，提高全市耕地利用率，从而扩大全市农作物种植规模。

（三）抓龙头企业农业生产。要着重抓好利农、鸿达、亿生、天怡、温氏等龙头企业的农业生产，支持和督促龙头企业扩大农业生产规模，带动全市农业经济稳定增长。
