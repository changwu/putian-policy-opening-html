2018年莆田市建筑业发展情况分析

第七期
第七期
来源：本网 时间：2019-01-25 08:25
| | | |

2018年，莆田市建筑业企业面对复杂严峻的宏观经济形势，主动适应新形势新常态，我市建筑业总体呈“缓中有稳、稳中有忧”的发展趋势。

一、总体运行情况

建筑业总体增速较去年明显回落。2018年,莆田市建筑业企业（指具有资质等级的总承包和专业承包建筑业企业，不含劳务分包建筑业企业，下同）完成建筑业总产值716.95 亿元,比上年同期增长9.4%，增速较1-11月提高2.4个百分点，较上年同期回落14.2个百分点。增速回落的原因：今年全市大型PPP或EPC项目几乎都被央企中标，而反观本地企业，行业整体规模小，承包工程范围窄，项目中标概率低，现状堪忧，严重影响全市建筑业产值增长。

2018年实现建筑业增加值250.79亿元，可比价增长6.8%，增速较1-11月提高0.5个百分点，超过全省平均水平，占全市GDP比重高达11.2%，比重较去年同期提高0.8个百分点，对莆田市经济增长的贡献率8.6%，拉动GDP增长0.7个百分点，在各行业中贡献居第3位，建筑业支柱产业地位依然巩固。

 
 

由于招投标市场的全面开放，本地企业综合竞争力不强，今年建筑行业压力加大，建筑业总产值增速从 2018年初起呈现逐月回落的态势，8月增速放缓至个位数，9月增速滑落至最低点仅6.0%，之后有缓慢回暖趋势，但明年增速下行压力依然存在。

 
 

2009-2018年，资质建筑业企业总产值年均增长26.6%。2014年以前，建筑业总产值保持高位增长，增速都在30%以上。2015年增速下滑至最低点，仅0.9%，几乎与上年持平。之后增速呈上升趋势，但2018年，建筑行业压力再次凸显，增速仅9.4%。

其他主要经济指标情况。全市建筑工程产值完成 686.76亿元，增长8.6%，较上年同期回落15.8 个百分点，占总产值比重高达95.8%，较上年同期回落0.7个百分点。装饰装修产值完成7.24 亿元，同比下降39.3%，比上年回落18.8个百分点，占总产值比重仅0.6%，较上年回落0.5个百分点。

二、亮点及问题

亮点一：大型企业拉动产值增长作用明显

2018年，中交建宏峰、巨岸建设等9家大型企业产值均超过20亿，合计完成产值333.81亿元，占比不到2.0%的企业完成全市产值的46.6%，贡献率达56.2%，拉动建筑业总产值增长5.3个百分点。大型建筑企业将经营的触角逐步伸向建筑行业的各个领域，随着供给侧改革的逐步推进，这些思变进取的企业实力将不断增强，在建筑行业发挥更大的作用。

亮点二：新增企业个数将近去年的六成

截止2018年底，全市共有建筑业企业495家，比 2017年增加185家，同比增长59.7%，新增企业将近去年的六成，其中有工作量的企业 449 家，比2017年同期增加149家。新增建筑企业合计完成产值14.30亿元，贡献率达23.2%，拉动建筑业总产值增长2.2个百分点。从事建筑业活动的平均人数24.66万人，比上年末增加2.27万元，增长10.1%。建筑业在吸纳农村转移人口、推进新型城镇化建设和维护社会稳定等方面继续发挥显著作用。按建筑业总产值计算的劳动生产率为29.07万/人，同比下降0.6%，几乎与去年持平。

亮点三：外拓工程几乎覆盖全国各省（区、市）

2018年，全市建筑业在外省完成产值263.07亿元，下降0.8%，增速同比回落24.6个百分点，占总产值比重36.7%，比重下降3.8个百分点。尽管外拓产值缓慢下降，外省完成产值依然发挥重要作用。在省外承揽工程施工已覆盖 29 个省（区、市），仅在西藏未承建工程，在江西、广东、重庆等三省（市）完成产值均超过三十亿，合计111.28亿元，占全部外拓产值的42.3%，占比较去年提高4.9个百分点。

问题一：房屋施工面积及竣工面积增速均有不同程度的回落

2018年，全市建筑业企业房屋施工面积4780.33万平方米，同比增长0.8%，增速较上年同期回落6.9个百分点。房屋竣工面积1305.25万平方米，同比增长1.8%，增速较上年同期回落16.2个百分点。从全市建筑业企业房屋竣工面积构成情况看，住宅竣工面积
956.25万平方米，占最大比重，为73.3%。厂房及建筑物竣工面积占16.0%，科研、教育、医疗用房屋竣工面积占7.4%，其他种类房屋竣工面积占比均在2.0%以下。

问题二：建筑业发展后劲严重不足

2018年，全市建筑业企业签订合同额 1280.54 亿元，比上年增长9.9%，增速较上年同期、1-11月分别回落17.0个和12.0个百分点，其中本年新签合同额 813.91亿元，同比下降2.1%，增速较上年同期、1-11月分别回落36.6个和9.8个百分点。本年新签合同额占签订合同额比重为63.6%，较上年同期下降7.7个百分点。较之上半年，建筑业总产值增速回落至个位数，新签合同额下降。行业规模总量发展增速明显放缓，发展后劲严重不足，建筑行业发展前景不容乐观。

问题三：1-3季利润增速回落，利润率略有下降

2018年1-3季度，全市建筑业企业实现利润19.14亿元，比上年同期增加0.71亿元，同比增长3.9%，增速较上年同期回落20.4个百分点。1-3季度产值利润率3.9%，较上年同期回落0.1个百分点。

问题四：新开工面积连续两年下降

2018年全市建筑业企业房屋建筑施工面积4780.33万平方米，比上年增长0.8%，增速较上年回落6.9个百分点。其中，本年新开工面积1337.31万平方米，下降9.9%，增速较上年提高5.5个百分点，增速连续两年下降。本年新开工面积占全部建筑施工面积的比重为28.0%，比上年回落 3.3个百分点，占比连续两年回落。新开工面积下降，反映出建筑业市场中房建工程量减少。

三、各县区建筑业企业生产情况

从注册地产值数据来看，2018年荔城、城厢两区建筑业依然领跑全市，建筑业总产值分别为196.89亿元、178.91亿元，增速分别为持平、2.5%，两区产值合计占全市总产值的52.4%，占比下降4.3个百分点，超过半壁江山。从增速来看，湄洲岛增速最高、仙游增速第二，分别达52822.2%、30.1%。湄洲岛增速猛增原因：1.基数很小。2.年度新增企业17家，合计完成产值0.96亿元，贡献率达84.4%，拉动湄洲岛产值增长48000个百分点。仙游县主要得益于当地基建的拉动，如仙游建工、中浩市政、联发建筑等六家企业产值均达10亿以上，合计完成产值57.57亿元，约占全县总产值的六成。

四、对策建议

从整体数据来看，由于建筑业总产值的统计口径是按注册地统计，尽管全市加大投资力度，但几乎大项目都由央企承建。也就是说，所有这些大型项目的建筑业总产值将统计到央企的注册所在地，同时本地企业中不到标，不少企业面临濒临倒闭的状态。尽管今年住建部门已在2016年实施意见的基础上出台《莆田市人民政府关于促进建筑业发展壮大的实施意见》，但成效还未显现。建议各县区政府在引进项目的同时，重点扶持市内龙头企业，提高与央企抗衡的实力，争取2019年本地企业的大型项目中标率提高，纳入本地建筑业总产值统计范围。

从龙头企业数据来看，防止大型建筑企业外迁十分重要，这不仅仅影响产值，也造成税收收入的流失，更是人才的外流。住建部门及各县区要采取各种有效手段，防止本地龙头企业外迁。建议：一要提升服务。政府的服务质量是关键。要变管理为服务，让企业感受到本地发展的环境和空间会越来越好。同时要深入了解企业需求，在引导企业提高实力的基础上，切实解决实际困难。二要适时变通。当企业做到一定规模，对信息政策资源的要求越来越高，本地已不能满足时，可以和企业商讨折衷的做法，如，大城市为主要经营地或设立办事机构，而企业注册地设在本地。这样既可以吸收大城市的信息政策优势，又能防止产值、税收等数据的减少。三是减少内耗。各县区不要引进本市其他县区的建筑企业，市内企业迁来迁去，造成市内资源内耗，对本市建筑企业长期发展不利。

从新增企业数据来看，适当新增有工程量的企业是必要，但把所有小企业甚至空壳企业都纳入统计一套表库不是必须。建议各县区住建局做到：一要定期跟踪。及时跟进小企业的承接工程情况，如有工程应及时通知企业向各县区统计局申报材料，尽快入库。二要量体裁衣。根据企业自身情况，引导中小企业制定未来发展方向。或资源整合多家企业抱团取暖，做大做强；或探索一细分领域、有发展空间领域，做专做细。

从外拓企业数据来看，外拓工程不仅仅要靠大型企业的打拼，更需要政府的服务支持。具体来讲，一是多渠道助力企业定位。如何锁定工程多、竞争少的外拓区域，如何锁定竞争少又稀缺的细分领域，引导中小企业走专业化、差异化特色之路。我市以中小建筑企业居多，只要企业坚持用自身有限的资源做专做精，同样可以在专业领域形成足够的竞争优势。建议政府及相关部门多方获取信息资源，为企业指引未来努力的方向。二是多渠道助力企业融资。去年9月底，市统计局做过一项建筑企业营商环境调查，调查数据显示，建筑企业对本市的投融资环境满意度偏低。建筑业企业融资难是行业内的普遍现象。建议：一要强化政府监督职能，健全法律制度，对长期拖欠工程款的业主，制定相应的制约政策。二是根据中小企业抵押物少的情况，制定完整的建筑企业信用评价体系，出台针对该类企业的灵活贷款政策。根据企业信用分的高低，可采取投资补助、基金注资、担保补贴、贷款贴息等多种不同的助力方式。
