2018年莆田市消费品市场运行稳中趋缓

第五期
第五期
来源：本网 时间：2019-01-22 15:38
| | | |

2018年，全市在习近平新时代中国特色社会主义思想指导下，认真学习贯彻党的十九大精神，按照推动高质量发展要求，坚持稳中求进工作总基调，坚定践行新发展理念，继续深化供给侧结构性改革，大力发展新产业、新业态和新商业模式，努力改善消费环境，加快培育新消费增长点，提振消费信心，进一步扩大内需，优化消费结构，但在宏观经济增长放缓的大环境下，全市消费品零售市场运行总体平稳，增速有所放缓。

一、全市消费品零售市场运行状况及特点

（一）消费市场运行高开低走，增速放缓

初步统计，2018年全市社会消费品零售总额763.42亿元，比上年增长9.8%（名义增长，下同），增幅比上年回落1.8个百分点，比全省平均水平低1.0个百分点，增幅居九设区市第六位。从各月实现的总量看，全年月均零售额达63.62亿元，比上年增加5.67亿元。从各季累计增幅看，一季度与二季度在12.0%－12.7%间波动，三季度在11.5%－12.4%间波动， 四季度在9.7%-10.2%间波动。全市各季累计增幅见下表。

按消费形态分，商品零售保持两位数增长，餐饮收入维持个位数增长，但增幅均比上年回落。2018年，全市实现商品零售额703.35亿元，增长10.5%，增幅比上年回落1.5个百分点；餐饮收入60.07亿元，增长2.4%，增幅同比回落4.7个百分点。

（二）消费品市场结构调整

1、零售业贡献率提升。从批发业、零售业、住宿业和餐饮业实现的消费品零售额对全市社会消费品零售总额增长的贡献率看，2018年零售业较快增长，贡献率88.5%，比上年提升5.9个百分点，批发业（9.3%）、住宿业（0）和餐饮业（2.1%）分别比上年回落2.8个、0.2个和2.9个百分点。

2、限额以上消费品市场占比过半。 2018年，全市限额以上企业（单位）实现消费品零售额405.50亿元，增长11.9%，增幅高于全市社会消费品零售总额2.1个百分点，占社会消费品零售总额的比重由2016年的44.8%、2017年的49.9%提升至今年的53.1%，对社会消费品零售总额增长贡献率达63.5%，拉动全市社会消费品零售总额增长6.2个百分点。

分经营地看，乡村消费潜力得到进一步释放，市场较快发展。2018年，限额以上乡村单位实现商品零售额16.09亿元，增长21.6%，同比加快0.6个百分点，比城镇快10.0个百分点。

（三）新业态等较快增长，转型成效初现

1、网络零售较快增长。在市电商十条措施的有利带动下及相关配套硬件和软环境不断完善，全市电商贸易仍呈较快发展态势。2018年，全市限额以上批发和零售企业通过公共网络实现零售额148.60亿元，同比增长18.2%，增幅虽比上年回落9.9个百分点，但比全市社会消费品零售总额快8.4个百分点。12月末，限额以上网上零售市场占全市消费品零售总额的比重达19.5%，同比提升3.3个百分点，比全省平均水平高6.0个百分点，对全市消费品零售总额的贡献率达33.6%，拉动其增长3.3个百分点。其中，累计网络零售额超亿元的企业有36家，比上年增加13家。

2、传统零售业继续回暖。超市、专卖店等传统零售业态与电商平台不断融合，呈现出较好发展态势。2018年，全市限额以上大型超市零售额增长16.4%，增幅同比提高19.1个百分点；便利店零售额增长38.4%，增幅同比提高2.3个百分点；百货店零售额增长29.4%，增幅同比提高7.4个百分点。

（四）居民消费升级加快

一是居民基本生活类商品消费稳步增长。受全年食品零售价格同比上涨1.7%的影响，全市限额以上粮油食品类商品零售额增长19.9%，增幅同比提高3.4个百分点；饮料类增长20.8%，增幅同比提升3.3个百分点。

二是限额以上单位品质类商品热销。2018年，化妆品类商品增长120.2%，中西药品类增长74.4%，通讯器材类增长42.9%，书报杂志类增长50.1%。

三是家装类消费活跃。2018年，全市限额以上单位实现家具类商品零售额增长18.3%，五金、电料类增长24.7%，增幅分别高于全市限额以上消费品零售额6.4个和12.8个百分点。

四是石油及制品类商品零售额增速回升。2018年全市限额以上石油及制品类商品实现零售额33.40亿元，增长4.7%，增幅同比提高3.7个百分点，占全市限上消费品零售额的比重为8.2%，拉动限额以上消费品零售额增长0.4个百分点，同比提高0.3个百分点。

二、消费品市场发展应注意的问题

一是整体市场消费环境不容乐观。初步核算，2018年全市地区生产总值2242.41亿元，增长8.3%，同比回落0.1个百分点。受经济大环境需求减弱影响，批发零售业增加值增长5.9%，增幅同比回落0.5个百分点，住宿餐饮业增加值由上年的增长3.8%转为下降3.1%。

二是商圈集聚能力有限。全年只有天博广场达到城市综合体标准，2017年全市综合体实现商户销售额（营业额）8282万元，同比增长7.2%，万达广场、金鼎广场、正荣时代、正荣财富中心、联创等未能达到统计标准。亿元商品交易市场仅13个，受红木家具交易额减少影响，2017年亿元市场实现商品成交额185.20亿元，下降15.3%。在综合体、商品交易市场内入驻的单位以个体户、产业活动单位居多，法人企业较少，市场主体呈“小、弱、散”状态，缺少引领行业发展的大型商贸企业。平台经济仍处于起步阶段，初步统计，2018年入驻找银网、众鞋联、普天药械网及智慧能源等平台的限额以上企业实现商品销售额近50亿元。

三是部分大宗商品预期消费不理想。2018年，受中低端汽车消费疲软影响，限额以上单位汽车类商品零售额增长6.4%，增幅同比回落0.7个百分点，比全省平均水平低1.3个百分点。

四是部分企业停业影响。2018年，陆续有114家限额以上批发零售企业停业,累计零售额同比减少4.36亿元，拉低全市社会消费品零售总额增幅0.6个百分点。

三、2019年消费品市场发展建议

2018年全市社会消费品零售总额增长12.2%的目标未能完成， 2019年市场预期压力仍较大，但在进一步推进特色小镇建设、实施乡村振兴战略，培育消费新增长点等积极因素带动下，消费市场发展的不利因素将逐步克服，消费的基础性作用将得到进一步发挥。现就做好2019年消费市场提出如下建议。

（一）继续推进传统零售业转型。在消费者主权渐占主导，消费行为模式发生深刻变化时，传统零售面临深刻挑战。从传统零售业发展看，零售业经历了单渠道零售、多渠道零售、跨渠道零售、全渠道零售后，新零售甚至共享零售也顺应信息化时代需求，渐渐为人们所熟知和接受。从目前部分企业运行来看，大型超市与京东、淘宝等网络平台合作开展网上下单，店内送货服务，能有效提高企业运营效率，对传统零售业有一定的借鉴作用。

（二）继续做大做强电商产业。今年以来，全市部分限额以上电商企业零售额增速回落，与企业业务量转移、申请不到奖励补贴、运营成本不断提高及电商法颁布等因素有关。因而，对内而言，电商企业要建立自身品牌，走自主品牌道路，才能可持续发展；对外而言，有关部门要进一步完善电商企业的奖励方法，搞活市场机制，引导电商企业做大做强。

（三）进一步拓展消费空间。针对收入群体不同、消费观念不同，企业应以人为核心，开展多样化服务，实行差别化销售。如以本地优势产业如鞋服、红木家具、金银珠宝、工艺品等为依托，顺应个性化消费需求，实现定制服务、精准服务，不断加大享受型、发展型、健康型、智能型等消费品的供给力度，提升服务水平，实现消费更好地带动经济发展。
