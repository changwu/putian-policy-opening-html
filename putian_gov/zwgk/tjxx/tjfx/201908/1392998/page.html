2019年上半年经济运行情况分析

来源:发改委 时间：2019-07-25 15:56
| | | |

一、上半年经济运行的主要特点

今年以来，全市上下深入开展“聚焦项目比质量，争先进位比赶超”活动，大力培育电子信息、医疗健康等新兴产业，持续推动传统产业转型升级，加快建设美丽莆田。上半年，全市经济运行总体稳中有进、稳中向好。

（一）转型升级成效显现。深化供给侧结构性改革，大力实施创新驱动发展战略，推动制造业高质量发展。一是“三新”工业经济快速增长。今年以来，全市大力支持龙头企业牵头组建技术联盟和产业联盟，构建“互联网+先进制造业”服务体系，加快高新技术产业集聚发展。战略性新兴产业、高技术企业、装备制造业等增加值均增长13%以上，增幅均高于全市工业增加值5个百分点以上。二是平台经济加速崛起。积极采取“优势产业+平台”新模式，着力打造众协联、智慧能源、药械网、无车承运等平台经济，取得较好成效。截至目前，44家平台已累计实现交易额657.5亿元，税收近7亿元，其中，今年上半年新增交易额154亿元，税收3.4亿元。三是重点企业增势良好。列入2018年省级龙头的22家规模工业企业产值336亿元，增长11.4%。3家特级资质建筑业企业支撑作用明显，产值占全市的27.2%，贡献率达37.1%。第一产业中占75%的渔业和种植业，在南日海域深海鲍鱼养殖装备等渔业升级项目有力推进以及积极发展现代设施蔬菜等带动下，生产形势良好。

（二）有效投资企稳回升。今年以来，全市固投一度下滑严重，1-3月增长2.7%，增幅全省第8位，1-4月增长1%，增幅是历年来最低的一次。从5月份开始，市各套班子领导齐发力，集体驻基层解难题、梳堵点，县区（管委会）主动配合，加强了项目入库入统力度，固投增幅回升明显。1-5月，增长10.3%，居全省第三位；1-6月，增长10.6%，居全省首位。一是制造业投资恢复增长。在电子信息、化工（纺织化纤）新材料等行业投资有力拉动下，全市制造业投资由1－4月份的下降9.8%转为1－5月的增长13.9%、1－6月的增长21.7%，扭转了今年以来持续负增长的不利局面。二是房地产投资比增27.3%，较一季度提高12.2个百分点，今年以来呈加快增长的态势，为固投增长提供了有力支撑。三是199个在建亿元项目投资增长67.9%，增幅同比提高80.1个百分点，形成强力贡献。

（三）市场活力有效激发。出台全市关于完善促进消费体制机制进一步激发消费潜力的实施方案，进一步优化供给推动消费。一是港口经济增长基础进一步夯实。湄洲湾30万吨级主航道正式投用，罗屿作业区9-10#泊位通过验收，可安全可靠地服务大型散货船，将有效提高全市港口综合竞争力。同时，水路货运周转量近两年基本保持两位数的增长，占交通货运周转量比重达26.2%、同比提高1.7个百分点。二是营商环境持续优化。开展优化营商环境提升年，成立了十个专项工作小组，全省率先委托第三方机构针对各县区现状精准制定优化提升目标举措。深入推进“放管服”改革，全面梳理公布四批次1393项“一趟不用跑”和“最多跑一趟”办事清单事项，633项社会事务类、经济综合类事项实行“一窗受理、集成服务”，正在推进“全程网办”和“秒批”。三是部分消费品市场较活跃。去年以来新入库的513家零售企业快速增长，限额以上网络零售额保持15%以上较快增长，消费结构有所优化，可穿戴智能设备零售额增长2倍，新能源汽车增长1倍，智能手机增长31.4%。

（四）生态文明深入推进。积极践行习近平总书记治理木兰溪的重要理念，全面提升生态环境质量。一是木兰溪流域治理再发力。在木兰溪全流域统筹实施陆域污染治理和流域生态修复，率先全省试点创建“污水零直排区”，深入开展流域汇水区域不达标水体水质提升，三江口断面平均水质达到Ш类标准，比去年明显改善。二是污染防治攻坚战再提升。上半年，空气质量达标天数比例97.8%，污染天数4天、同比减少13天。加快枫慈溪等5条水质不达标小流域综合整治工程，主要流域水质优良比例达90%。推进60个地块污染详查，全省率先完成信息采集工作。三是生态文明重点项目再推进。生态文明专项行动22项重点任务和46个重点项目进展较好，累计完成投资72.71亿元，占年计划54.5%，超序时项目20个。四是上级资金争取再突破。上半年生态文明领域共获得补助资金5.22亿元。其中，木兰溪防洪工程获中央预算内投资2亿元，蓝色海湾整治项目获得3亿元中央财政项目补助。五是生态文明建设模式再完善。“变害为利 造福人民”专题授课两次进入厅局级干部培训讲堂，广受好评，木兰溪流域治理经验和做法被遴选为全国干部教育案例，更大程度提高知名度。莆田成功跻身全国水生态文明城市，为打造生态文明木兰溪样本提供更高平台。

（五）民生事业持续改善。持续加快补齐民生短板，不断增进民生福祉。一是“美丽莆田·文化繁荣和全域旅游”两大专项行动有效实施。共推进项目106个，完成投资17.73亿元、占年计划54.2%。开展“妈祖爱·元宵长”文化旅游月、“全福游、有全福”“妈祖圣地·美丽莆田”工艺之旅等活动，成功创建一批文旅活动品牌。南少林、九鲤湖等文旅融合发展示范基地的打造进展顺利。二是社会保障不断深化。城镇新增就业人数8153人，完成省下达任务的51%。组织实施大学生“十百千”就业创业行动计划，新认定11家就业见习基地、全市达57家。常住人口基本养老保险参保率已达92.5%，预计全年可完成95%的目标。三是教育体制机制改革全面推进。制定普惠性民办幼儿园认定管理及政府购买服务实施办法，创新开展民办幼儿园定级评估、提高办学质量。出台了编外合同教师管理办法、加快培育高层次基础教育人才办法，促进教师队伍建设。四是医疗卫生服务项目进展顺利。16个医疗卫生服务项目完成投资4.25亿元，占年计划的57%。莆田学院附属医院肺科病房大楼、福建国药东南医院一期正在内部装修，仙游县第一医院已完成三通一平。五是立体化社会治安防控体系得到完善。公安部门建立完善了陆空巡逻“防控网”、社区网格“治理网”、行业单位“内控网”、公共安全“管控网”等“四张网”，形成整体防控格局。全市列入今年全省5个社会治安防控体系建设标准化城市之一。

二、存在的主要问题

一是工业下行压力加大。上半年，全市减停产企业392家，影响产值142亿元。传统产业制鞋业贡献减弱，主要是受外需不足、中美贸易战等因素影响，部分企业出现客户订单不敢下、企业订单不敢接现象，增加值从一季度的8.5%逐月回落至1－6月的5.4%。工业用电量受雷州星搬迁基数影响，上半年负增长6.4%，影响了规模工业增加值评估。二是服务业部分行业增长低迷。第三产业六大行业发展不平衡，增长主要靠营利性服务业拉动，其他行业增长均低于第三产业增加值增幅，特别是非营利性服务业负增长1.8%，以及占三产比重均在15%左右的批发零售业、金融业、房地产业三大行业低增长，对三产增长产生较大影响。三是畜牧业跌幅明显。非洲猪瘟对生猪产能负面影响仍在持续，上半年全市生猪存栏14.6万头，下降75%，出栏26.6万头、下降50%，肉蛋奶总产量5.5万吨、下降33%。四是投资后劲仍显不足。制造业项目接续不畅，华佳彩、钜能HDT、雪津迁建、CPL、华峰一揽子项目等重大项目已基本建成，而目前落地开工的大项目不多，乙烷制乙烯目等一批投资额大的重大项目尚未落地、入统，华佳彩二期等一批增资扩建项目也未能取得实质性进展。五是财政增收压力较大。在减税降费力度范围加大、新税源点匮乏、一次性收入不足等因素影响下，全市税收收入100.44亿元，下降1.8%，占预算47.4%、慢序时2.6个百分点，一些纳税大户出现较大减收，房地产业税收减收6.7亿元，工业税收仅增长0.7%，给下半年补缺口造成较大压力。六是民生事业和生态建设部分领域仍有待加快。新增医疗床位数仅完成全年任务的11.8%，部分片区普惠性幼儿园和小学的学位不足，节能环保产业培育有待加快，“两无”企业排查摸底不够彻底等。

三、下半年工作措施

从上半年主要指标完成情况看，全年要实现赶超，下半年的任务加重，GDP增速仍低于预期目标 0.9个百分点，500个市重点项目下半年还要再完成投资542亿元以上。各级各部门要持续深入开展“聚焦项目比质量，争先进位比赶超”活动，紧盯年初既定目标，奋战180天，确保全市主要指标增幅在全省争先进位。

（一）推动产业集聚发展。把推动制造业高质量发展作为重中之重任务，出台百亿企业培育方案，实施千亿产业集群培育计划，其中，电子信息产业抓紧高起点编制5G产业规划，加快建成新型显示、集成电路、智能终端产业链条；化工新材料产业积极推动永荣科技、华锦实业和三棵树涂料等新入库企业释放产能，延伸辐射上下游企业，确保全年产值超过500亿元；医疗健康产业围绕妈祖国际健康城建设，加快招商入驻和项目落地建设，对接落实好两岸医疗健康产业合作试验区申报工作；高端装备制造业加快推进云度汽车与中国一汽的合作进程；工艺美术产业推动传统产业与智能化、数字化、网络化的深度融合，加快创新转型升级，力争全年产值超过500亿元。落实新一轮促进龙头企业改造升级行动计划，通过改造升级一批、培育发展一批、招商引进一批，促进龙头企业做优做强。加快组建产业联盟、产学研创新战略联盟，联动开展产品推介、核心技术攻关和创新研究等，带动产业链上下游协同发展。引导中小企业走专业化、精细化、特色化、新颖化发展之路，鼓励企业嫁接个性化定制、众筹众包等创新模式，拓展新兴市场，提升附加值，形成龙头企业引领、中小企业协作配套的集聚发展格局。

（二）加快创新创业创造。大力实施创新驱动发展战略，不断增强经济创新力和竞争力。一是提升企业创新能力。大力培育“双高”企业和“专精特新”的隐形冠军，力争年内新增高新技术企业30家以上、高长成企业30家以上。二是激发企业创新活力。把科技投入作为战略性投资，作为提高科技创新能力、提升核心竞争力的重要保障，持续加大财政奖补力度，落实好创新激励与企业财税贡献、产出、研发投入等绩效挂钩机制，力争全市研发经费投入增长20%以上，R&D经费投入强度达1.2%以上。三是全力优化创业环境。借助黑马城市学院、投石智库等创新孵化平台，系统开展企业家培养、创业创新等服务。推进科研领域放管服改革，优化科研项目和经费管理办法，激发科研人员创造活力。

（三）创建平台经济示范区。平台经济是坚持高质量发展落实赶超的重要引擎，全年力争交易额突破1000亿，全力创建全省平台经济示范区。一是出台相关配套政策。积极对接国家和省里支持平台经济政策，抓紧出台全市《关于加快平台经济发展的若干意见》；推动数字中国研究院与互联网巨头在莆成立平台经济研究院，加强平台政策和技术研究；大力引进创投机构，尽快出台全市平台经济创投引导基金，引导社会资本更多投向平台新产业、新业态、新模式。二是完善平台管理机制。推动国有企业控股或参股平台建设，制订高效运营管理机制，推动平台运行效率不断提升。培育和引进一批与全市平台经济发展相配套的孵化培育、营销策划、产品检测、人才培训、仓储物流等第三方服务机构，提升配套功能，形成便捷高效的第三方服务体系，构建平台经济产业生态圈。三是做好平台经济运行监测和统计分析。抓紧建立平台经济主体数据库和统计指标体系，年内完成平台经济统计指标设计工作，启动统计分析试点。

（四）力促投资稳定增长。以“五个一批”项目推进为抓手，抓好签约、开工、投产等重点环节，促进项目投资攻坚有力。一是抓好招商工作。落实好招商引资攻坚年活动各项工作，重点围绕电子信息、化工新材料、高端装备等产业链填平补齐延伸，坚持“一把手”招商、产业招商、重点区域招商、委托招商等多形式并举，争取引进一批大项目、好项目，为落实赶超任务、建设美丽莆田增强后劲。二是继续抓好项目开竣工，下半年重点推进秀屿无醛木业、北岸电商物流园、南日岛海上风电场二期、福莆宁城际铁路F2线、宁海闸及配套工程、莆田一中迁建工程等43个重点项目实现开工；仙游绿色纤维产业园、京东互联网+新经济、泰盛新材料、莆田学院迁建等71个重点项目实现竣工。三是贯彻实施各项惠企政策，拓展民间投资领域，强化政银企对接配合，加强项目要素保障，持续激发民间有效投资活力。四是抓好工程包建设。围绕基础设施、民生事业等领域进一步梳理、策划一批工程包。

（五）持续优化营商环境。持续开展优化营商环境提升年行动，推动重点领域和关键环节改革取得明显突破。一是聚焦重点领域改革。进一步简政放权，坚决做到该放的权力放下去，能取消的尽量取消；深入推进新型城镇化建设，加快特色小镇培育创建，重点推进莆田妈祖航空小镇列入全省航空运动产业及航空营地规划布局；深入探索“诚信建设+”信用监管模式，推动全国信用体系建设示范城市加快创建；深化国企国资改革，加快国有资产布局优化和结构调整；持续贯彻财税体制改革，有效落实减税降费政策。二是深化“放管服”改革。对标对表深圳、厦门等先进地区改革典型经验，在全市推行90项“一件事情”套餐式集成服务；持续推进“多证合一”“证照分离”，再造简化审批流程，推广“互联网+政务”“一趟不用跑”“最多跑一趟”，实现100%，努力让企业办事像网购一样方便。

（六）补齐生态领域短板。深入贯彻落实习近平总书记治理木兰溪的重要理念，深度融入福建省国家生态文明试验区建设，全力做好中央环保督察迎检工作。一是持续打造生态文明木兰溪样本。积极对接争取将木兰溪下游水生态修复与治理工程项目列入全国十个重点流域水生态修复综合治理示范项目。深入开展木兰溪水质提升攻坚行动，持续推进打造木兰溪水资源、水生态、水环境、水灾害“四水统筹”治理新亮点。二是加大力度创新完善体制机制。不断总结提升生态文明建设莆田模式经验，并加以复制推广，最大程度释放改革成果效益，打造宜居港城的莆田故事。进一步完善生态管护机制，加快出台城市生态绿心保护条例，有序实施《湄洲岛保护管理条例》。持续推进重点生态区位商品林赎买试点。三是打赢污染防治攻坚战。推进“莆田水环境（湖库）综合管理平台”建设，深化生态云平台应用。加快城市黑臭水体治理；进一步强化制鞋、家具等涉VOCs行业提升改造、“散乱污”治理、施工扬尘管控等，加快推进工业固体废物综合处置二期填埋项目前期工作。
