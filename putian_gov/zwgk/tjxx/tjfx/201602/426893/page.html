2015年莆田市固定资产投资运行分析

第五期
来源：本网 时间：2016-01-19 08:25
| | | |

2015年，我市紧紧围绕“莆田科学发展、跨越发展”的奋斗目标，持续实施“五大战役”建设，贯彻落实“三比一看”活动精神，推行重大项目“两周一调度”工作机制成效显现,全市固定资产投资平稳较快发展。

一、固定资产投资运行主要特点

（一）总体增速平稳，规模再创新高

2015年，全市全社会固定资产投资规模总量突破1760亿元，实现投资1765.10亿元，2011-2015年五年总量累计达6064亿元，年均增长28.9%，超计划完成“十二五”全社会固定资产投资年均增长25%、五年累计5000亿元的目标。全市固定资产投资（不含农户，下同）完成1733.60亿元，同比增长21.8%，增幅位居全省第三位，比全省平均水平高4.4个百分点。在固定资产投资中：项目投资完成1317.65亿元，同比增长22.4%；房地产开发投资完成415.94亿元，同比增长19.9%。从运行的态势上看，全年固定资产投资整体呈现平稳增长趋势。

 

（二）在建亿元项目投资快速增长

全市172个在建亿元项目完成投资481.39亿元，同比增长40.3%，增幅分别比上年同期、全市固定资产投资高54.6和18.5个百分点。其中，56个本年新开工亿元项目完成投资200.17亿元，同比58.3%，增幅比项目投资平均水平高35.9个百分点。

（三）基础设施投资高速增长

随着交通运输、电力电网、公共设施管理等项目有序推进，我市基础设施不断完善，全年增速均维持在40%以上。我市基础设施完成投资638.56亿元，同比增长43.7%，占固定资产投资的比重为36.8%，对固定资产投资的贡献率达到62.6%,比上年同期提高16.8个百分点。其中：交通运输、仓储及邮政业完成投资254.59亿元，同比增长25.2%；电力、热力、燃气及水的生产和供应业完成投资113.67亿元，同比增长41.4%；水利、环境和公共设施管理业完成投资268.11亿元，同比增长67.5%。

（四）民间投资作用突出

在三大投资主体中，民间投资占固定资产投资的份额最大，对固定资产投资的贡献率也最高，成为拉动我市投资增长的主动力，在固定资产投资中继续保持主导地位。2015年全市民间投资完成994.10亿元，同比增长23.6%，占固定资产投资的比重为57.3%，对固定资产投资的贡献率高达61.3%，拉动固定资产投资增长13.4个百分点，是投资保持平稳较快增长的主要动力。

（五）三产投资增长和占比均快于二产，产业结构进一步优化

2015年，我市积极调整优化产业结构，加快经济发展转型，产业投资结构呈现积极变化。全市固定资产投资中，第一产业投资完成32.42亿元，同比增长24.8%；第二产业投资完成477.70亿元，同比增长14.3%，增速比2014年提升12.6个百分点；第三产业投资完成1223.48亿元，同比增长24.9%，增幅比同期全市固定资产投资高3.1个百分点，比第二产业投资高10.6个百分点；第三产占全市投资的比重为70.6%，同比提高1.8个百分点，比第二产业占比高43.1个百分点。三次产业投资结构由上年的1.8:29.3:68.9调整为1.9:27.5:70.6，产业结构进一步优化。

（六）市政建设投资增长迅速

今年以来市委市政府高度重视民生投入，持续加大市政设施建设的投资力度，使得我市市政设施建设快速推进。2015年，我市市政建设共完成投资226.75亿元，同比增长92.3%，比同期固定资产投资快70.5个百分点。其中公共设施管理业项目完成投资201.62亿元，同比增长97.0%；水的生产和供应业项目完成投资18.55亿元，同比增长62.0%；城市公共交通业项目完成投资1.64亿元，同比增长131.0%；生态保护和环境治理业项目完成投资4.95亿元，同比增长44.9%。

（七）房地产开发投资快速增长

2015年，我市房地产开发投资快速增长，累计完成投资415.94亿元，同比增长19.9%，比全省平均水平高22.0个百分点，增速连续四个月位居全省第一位，较第二位厦门市高10.0个百分点。房地产开发投资占全市固定资产投资的比重为24.0%，对固定资产投资增长的贡献率为22.3%，拉动全市固定资产投资增长4.9个百分点。

二、存在的问题

（一）项目储备较少，投资后劲不足

全市在建的施工项目个数1932个，比上年同期减少74个，计划总投资2547.55亿元，同比仅增长2.1%；其中亿元以上项目172个，比上年同期减少28个，计划总投资1658.88亿元，同比仅增长0.1%。

（二）项目投资增速仍处于全省较低水平

全市项目投资同比增长22.4%，增幅虽然比上个月提升1.3个百分点，但仍比全省平均水平低1.6个百分点，增速仅高于福州、宁德，居全省九地市第七位。

（三）制造业投资增长后劲有所减弱

从7月份开始我市制造业投资增速分别是17.0%、15.8%、15.4%、13.4%、10.4%、9.1%，增速逐月回落，在全省的位次也从7月份的第六位下滑至12月份的第八位，这在一定程度上说明制造业投资后劲在减弱，企业家扩大再生产的意愿不足。

（四）投资的外延性扩张特点较为突出，内涵型投资占比较低

固定资产投资投资仍以代表外延型投资的新扩建为主，改建和技术改造项目投资占比偏低，投资外延性扩张明显，投资质量有待提高。2015年，在项目投资中，我市新扩建项目完成投资1028.97亿元，占项目投资的比重为78.1%，而内涵型的改建和技术改造项目仅完成投资222.79亿元，占项目投资的比重仅为16.9%，虽然较2014年的13.5%有所提高，但是远远低于新扩建项目，其中项目投资中含金量最高的设备工器具购置完成投资186.54亿元，占项目投资的比重仅为14.2%。

（五）资金来源同比增速减缓，国内贷款连续七个月同比下降

2015年，在经济下行、货币政策趋紧的大背景下，企业融资环境严峻，资金链紧张，投资意愿减弱，全年固定资产投资到位资金1913.92亿元，同比增长18.0%，增幅比上年同期回落6.2个百分点，比固定资产投资增速低3.8个百分点。其中，国内贷款从六月份开始同比分别下降65.7%、59.4%、54.4%、42.7%、34.1%、29.0%、24.5%，1-12月份国内贷款238.85亿元，增幅比上年同期回落41.2个百分点，到位资金增速放缓对投资建设的持续发展影响较大。

三、几点建议

 （一）加强项目储备工作

针对项目储备不足的情况，抓好招商引资工作，拓宽项目开发渠道，努力争取符合国家产业政策和发展方向的重点产业、民生工程和基础设施建设等重大新项目的引进，增强项目储备力量，形成储备一批、开工一批、投产一批的有序滚动发展机制。

（二）鼓励创新投资，推动企业加快技术改造

继续加大经济结构调整力度，通过简政放权，消除机制障碍，打造良好的市场环境，鼓励企业创新发展；在鼓励企业创新发展的同时，依托现有资源禀赋和产业优势大力推进重点技改项目投资，积极完善落实固定资产加速折旧、企业研发费用加计扣除、技改贴息贷款、产业转型引导基金设置等优惠政策，支持传统产业通过技术革新、升级改造来实现产业的更新换代、增量做优，促进企业向智能制造、绿色制造发展。

（三）积极拓宽融资渠道

一是充分发挥政府桥梁纽带作用,加强与金融部门的衔接、沟通和协调,选出好的项目向银行推荐,争取银行加大支持固定资产投资；二是加强政银合作，通过“政府投资+金融资本”的模式引导金融机构积极参与收益稳定、回收期长的基础设施建设等项目融资服务；加强政府与民间资本的合作，通过“政府投资+民间资本”等模式撬动更多社会资本投入重点领域。
