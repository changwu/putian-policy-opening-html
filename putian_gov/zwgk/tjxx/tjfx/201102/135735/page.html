投资总量再创新高 投资结构继续改善——2010年莆田市固定资产投资运行情况分析

来源:统计局 时间：2011-02-22 11:25
| | | |

2010年，莆田市在市委、市政府的领导下，紧紧围绕发展第一要务，紧紧围绕国家鼓励东部地区率先发展和支持福建加快建设海峡西岸经济区的战略部署，紧紧围绕“经济翻番、港城崛起”的奋斗目标，大力启动“六大战役”，大干150天，狠抓工作落实，全年固定资产投资总体运行情况较好，建设总水平迈上了一个新的台阶，为国民经济全面、协调、可持续发展作出了积极贡献。

一、投资运行的主要特点

（一）投资建设稳步推进，投资总量再创历史新高。2010年，莆田市投资建设稳步推进，投资总体上保持着稳步增长的态势。全年完成全社会固定资产投资496.52亿元，比去年同期增长36.9%，增速比上年加快16.7个百分点，增幅位居全省第三位，增幅比全国全省平均水平分别高13.1个百分点和6.9个百分点。投资总量比去年同期净增133.82亿元，总量再创历史新水平。其中，城镇以上固定资产投资429.44亿元，增长42.2%，增速加快18.3个百分点；农村固定资产投资67.09亿元，增长10.6%，增速加快6.3个百分点。

（二）各县(区)投资实现全面增长。其中：城厢区完成全社会投资81.80亿元，增长37.5%；涵江区完成全社会投资88.55亿元，增长33.0%；荔城区完成全社会投资101.66亿元，增长26.2%；秀屿区完成全社会投资88.90亿元，增长22.9%；北岸完成全社会投资41.96亿元，增长3.2倍；湄洲岛完成全社会投资3.12亿元，增长40.6%；仙游县完成全社会投资82.03亿元，增长29.7%；市直完成全社会投资8.48亿元，增长2.1%。

（三）投资结构得到继续改善。2010年，全市投资在保持较快增长的同时，投资结构得到继续改善。

1、三次产业投资呈现全面增长的态势，三产比重进一步提升。第一产业投资增速基本保持稳定，完成投资5.88亿元，增长12.0%，占全社会投资的比重为1.2%，比上年同期回落0.2个百分点。第二产业投资明显加快，全年完成投资162.41亿元，增长28.8%，增速同比加快19.7个百分点，占全社会投资比重为32.7%，同比下降2.1个百分点。其中电力、燃气及水的生产和供应业完成投资48.53亿元，增长8.2%，增速同比回落13.4个百分点；制造业完成投资113.24亿元，增长42.6%，增速同比加快40.7个百分点。第三产业投资比重进一步提升，完成投资328.24亿元，增长41.8%，增速快于全社会投资4.9个百分点，占同期全社会投资的比重为66.9%，比上年同期提升2.3个百分点，继续保持较高的投入强度。主要得益于基础设施的高投入和房地产业投资的高速增长。2010年，我市房地产开发完成投资87.91亿元，增长38.8%；50万元以上项目中拆迁安置房建设投资47.42亿元人，增长66.7%；交通运输、仓储及邮政业投资101.42亿元，增长43.8%；水利、环境和公共设施管理业投资27.28亿元，增长57.2%；批发和零售业投资8.46亿元，增长1.1倍。

2、三大投资主体增速全面加快，结构进一步调整。2010年，在莆田市全社会投资中，国有、外资、民间三大投资主体投资增速全面加快，分别比去年同期加快4.6、6.3、19.8个百分点，投资结构也进一步调整，国有投资比重进一步提升，民间投资比重继续回落，投资比重由上年的42.2：8.1：49.7调整为今年的45.3：9.1：45.6。

国有投资增势强劲，比重加大。2010年，央企继续加大对我市的投资，基础设施建设继续加大投入，全市国有投资在去年高速增长的基础上增长势头依然强劲，呈现出投资总量攀升，比重加大的趋势，对全市投资增长的拉动作用进一步提高。从总量来看，2010年完成国有投资224.88亿元，占全社会投资比重达45.3%，比2009年提高3.1个百分点，其中投资增量达72.00亿元，占全社会投资增量的比重为53.8%，拉动全市全社会投资增长19.9个百分点；从增速来看，2010年全市国有投资在去年高速增长的基础上又创新高，达到47.1%，增速比上年快4.6个百分点，比同期全社会投资增速高10.2个百分点。

3、建设资金充足，自筹资金依然是资金来源的主要渠道。2010年，我市建设资金充足，为全市投资快速增长提供了有力保障，全市建设单位累计到位资金565.07亿元，增长42.2%，本年投入资金540.71亿元，增长44.0%。其中，自筹资金到位328.27亿元，增长40.5%，占建设项目累计到位资金的58.1%，比上年回落0.7个百分点，自筹资金依然是资金来源的主要渠道；国家预算内资金29.12亿元，增长24.6%；国内贷款99.09亿元，增长62.4%；利用外资17.53亿元，增长55.2%；其他资金66.705亿元，增长44.9%。

（四）重大项目建设进展顺利，支撑有力。2010年，全市总投资5000万元及以上在建项目335个（不含房地产开发），完成投资238.87亿元，增长58.2%，增幅较全社会投资高21.3个百分点，占全社会投资总量的48.1%，对全社会投资增长的贡献率达到65.7%。总投资亿元及以上项目162个，完成投资184.15亿元，增长71.9%，增幅较全社会投资高35.0个百分点，占全社会投资总量的37.1%，对全社会投资增长的贡献率达到57.5%。

（五）在建项目投资规模扩大，新开工项目投资规模快速扩张。2010年，全市在建项目1253个，在建项目投资规模为1523.06亿元，比上年增长40.6%，增速同比回落5.9个百分点。其中，新开工项目908个，新开工项目投资规模为396.25亿元，增长71.8%，增速同比回落9.7个百分点。新开工项目投资规模占施工项目投资规模的比重由上年的21.3%提高到26.0%，新开工项目平均投资规模为4364万元/个，增长54.2%。新开工项目完成投资126.05亿元，比上年增长87.7%，占全社会投资的比重为25.4%，对全社会投资增长的贡献率达到44.0%。

（六）房地产开发投资高位运行。2010年，全市房地产开发投资一直在高位上运行，投资增幅一直在30%以上，全年完成房地产开发投资87.91亿元，比上年增长38.8%，占全社会投资的比重为17.7%，与上年提升0.2百分点，基本持平，占第三产业投资的比重为26.8%。房地产开发投资对全社会投资、第三产业投资增长的贡献率分别达到18.4%和25.4%。

新开工面积快速增长。2010年，全市商品房房屋施工面积889.76万平方米，同比增长26.1%，比上年同期提高17.1个百分点。其中新开工面积334.61万平方米，同比增长1.5倍，比上年同期提高196.8个百分点。

商品房销售情况良好。2010年，全市商品房销售164.12万平方米，同比增长19.0%，增幅比上年回落35.1个百分点。其中：住宅销售147.87万平方米，增长15.3%；商业营业用房销售12.13万平方米，增长34.8%。全市商品房销售额达79.55亿元，增长37.1%，增幅较同口径销售面积高18.1个百分点。其中：住宅销售额64.65万平方米，增长23.4%，增幅较同口径销售面积高8.1个百分点；商业营业用房销售额13.13万平方米，增长1.5倍，增幅较同口径销售面积高111.9个百分点。

二、“十一五”莆田市固定资产投资回顾

2010年，作为“十一五”的收官之年，全市固定资产投资整体上保持了平稳健康的运行态势。回顾整个“十一五”，全市以前所未有的大手笔在经济建设的蓝图上留下了浓墨重彩的一笔。2006年以来，全市上下依靠与时俱进的创新意识，坚持全面、协调、可持续的科学发展观，以扎实苦干的精神面貌，壮大经济实力，提升发展水平。五年来，全市进行了大规模的固定资产投资，成果丰硕，实现了总量快速扩张，投资结构逐步改善，一大批工业项目和基础设施项目先后建成投产，促进了国民经济各行业的发展，提高了人民的物质文化水平，圆满完成了“十一五”规划目标。

2006—2010年，全市累计完成全社会固定资产投资1567.17亿元，于2009年提前一年实现“十一五”规划提出的千亿目标，是“十一五”以前23年投资总和的2.2倍。“十一五”以来，投资总量年年跃上新台阶。2006年完成全社会固定资产投资165.18亿元； 2007年完成全社会固定资产投资240.93亿元；2008年完成全社会固定资产投资301.83亿元；2009年完成全社会固定资产投资362.70亿元；2010年完成全社会固定资产投资496.52亿元，是2005年的4.3倍，年均增长速度33.9%，比“十一五”规划目标的25.0%高8.9个百分点。随着投资规模的逐年扩大，投资率也逐年提高。全社会投资占GDP的比重从2006年的38.6%逐年提升到2010年的60.8%，“十一五”期间全市总投资率为51.1%。

三、当前投资运行中需要关注的几个问题

1、投资质量不高，投资外延性扩张明显，高耗能投资比重加大，高新技术产业投资滞后。2010年，全市改建和技术改造项目投资21.55亿元，下降15.0%，仅占50万元以上项目投资的5.6%，比上年同期下降3.4个百分点；而新扩建项目投资占50万元以上项目投资的比重达到87.8%，全市项目投资的外延性扩张特点表现依然较为突出。50万元以上项目中高耗能项目完成投资64.92亿元，增长82.1%，比去年同期加快66.9个百分点，比同期50万元以上项目增速快4.7个百分点。50万元以上项目中新高技术产业完成投资13.28亿元，增长12.0%，在上年下降7.8%的基础上实现恢复性增长，增速低于50万元以上项目投资25.4个百分点，占50万元以上项目投资的比重为3.4%，比上年同期下降0.8个百分点，高新技术产业投资放慢、完成投资占比偏低的现状，说明以粗放型经营为特征的传统产业投资在我市仍有相当比重，我市产业结构升级和调整步伐尚需进一步加快。

2、民间投资行为更为谨慎，行业分布依然较窄。2003年我市实施“民营回归”战略以来，莆田市民间投资较为活跃，投资增幅远高于国有投资。2008年民间投资增长37.0%，比国有投资增速高28.0个百分点。2009年以来受国际金融危机的影响，盈利前景的不确定性，民间投资行为更为谨慎，民间投资增速放缓。2009年仅增长5.8%，比国有投资增速低36.7个百分点；2010年增幅虽有所回升，增长25.6%，但仍比国有投资增速低21.5个百分点。民间投资占全社会投资的比重由2008年的61.3%回落到2010年的45.6%。民间投资行业分布依然较窄。在民间投资中，房地产业、批发零售贸易餐饮业、采掘业和制造业等传统行业占据主导地位，而通信、交通等有较好市场前景和可观收益的行业，还存在各种行业垄断障碍。水利环境和公共设施管理业民间投资介入程度更低。

3、第三产业投资结构不尽合理。2010年，莆田市第三产业投资虽呈现快速增长态势，但需要关注的是，在第三产业投资中，投资增长主要是依赖房地产业、交通运输仓储和邮政业、水利环境和公共设施管理业、住宿餐饮业和批发零售业等行业投资增长拉动，而用于租赁和商务服务业、居民服务和其他服务业、科技、教育、文化、卫生、信息传输、计算机服务和软件业、公共管理和社会组织等方面的投资则显不足。2010年房地产业、交通运输仓储和邮政业、水利环境和公共设施管理业、住宿餐饮业和批发零售业等行业完成投资283.67亿元，增长46.9%，拉动第三产业投资增长39.1个百分点，占第三产业投资的比重为86.4%；而科技、教育、文化、卫生等其他第三产业完成投资44.57亿元，增长16.4%，仅占第三产业投资的比重为13.6%。

4、商品房供求结构性矛盾依然突出。今年以来，全市商品房开发结构得到较大调整，但结构性矛盾依然突出，90平方米及以下住宅所占比重仍显偏低。2010年，全市90平方米及以下住宅投资12.58亿元，同比增长6.7%，占住宅投资的比重为28.3%，施工面积177.70万平方米，占住宅施工面积的26.7%，新开工面积33.88万平方米，占住宅新开工面积的13.4%，距70%的目标还有很大差距。
