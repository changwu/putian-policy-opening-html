疫情下建筑业外拓产值保持平稳增长

第十七期
第十七期
来源：本网 时间：2020-04-20 15:03
| | | |

受疫情影响，一季度我市多数建筑业企业经营成本加大、返工延迟，特别是现金流不足、经营管理能力弱的中小企业受到较大冲击，使得整个建筑行业面临较大的挑战，但建筑业外拓产值保持增长。

一、发展特点

（一）建筑业总产值、收入大幅下降。截止一季度末，全市总专包资质建筑业企业496家，较上年同期增加6家。莆田市一季度总专包企业完成建筑业总产值138.64亿元，下降22.0%，增速较去年同期回落39.4个百分点；一季度营业收入107.15亿元，下降22.5%，增速较去年同期回落34.0个百分点。从企业数据看，龙头企业中交建宏峰产值减少20.45亿元，下降66.4%，拉高全市建筑业总产值降幅11.5个百分点。

（二）外拓产值保持平稳增长。一季度资质建筑企业在外省完成产值71.40亿元，同比增长7.5％，增速较上年同期回落1.1个百分点，增速位居全省第一。外拓范围涉及28个省，其中广东、江西、河北产值均超过8亿，合计33.28亿元，占全部外拓产值的46.6%。涵城建设、雄盛建筑、顺安建筑等５家企业一季度在外省完成的产值均超过５亿元，拉高在外省完成的产值增速26.7个百分点，新签的外省大项目主要有：南昌县街上村安置房工程、仁怀市棚户区改造项目、河北等省市多个保利房地产开发工程。

（三）中小建筑企业整体受疫情影响较大。

从资质等级看，３家特级企业产值合计29.79亿元，同比减少42.3%，主要是由于中交建宏峰产值下降超6成;32家一级企业产值合计65.61亿元，同比增长5.2％；77家二级企业产值合计22.66亿元，同比减少31.4％；384家三级企业产值合计20.58亿元，同比减少31.6%。统计数据显示，除一家特级企业外，资质二三级企业整体回落幅度较大型企业更为显著。

二、主要问题

（一）新签合同下降，发展后劲不足。一季度全市资质建筑企业新签合同额152.14亿元，同比下降19.3％，增速较上年同期回落20.4个百分点，主要是由于中交建宏峰新签合同减少22.53亿元，拉高全部新开工面积降幅11.9个百分点。房屋建筑新开工面积342.55万平方米，同比下降23.0%，增幅较上年同期回落57.4个百分点，主要是联发建筑、飞阳建设等6家企业一季度新开工面积同比减少均超过20万平方米，合计减少171.10万平方米，拉高全部新开工面积降幅38.5个百分点。受疫情影响，无论是基建新项目招标，还是项目发包速度，均近乎停滞，发展后劲不足。

（二）工程进展缓慢，经营成本加大。因疫情原因，４月前招投标开标时间延迟，大量企业无标可中，一季度资质建筑企业新签合同下降近2成。部分新中标项目由于疫情影响，征地拆迁进度较慢，造成工程进展延缓或停滞。同时一些企业也存在人员流失、外来人员返岗率不足现象。这些都对工程进展造成较大影响。其次，疫情快速蔓延，供需端受到冲击的房地产行业，资金到位不及时。疫情前期部分建材由于物流运输限制、采购货源紧缺等原因，到货时间跨度长，导致工期延迟或材料涨价。再加上固定人员、固定租金等，这些都造成经营成本加大。

（三）本地扶持力度小，扶持政策落地难。本地大部分大项目都被中字头企业中标，这种情况很大程度上压低了建筑行业的利润，本地企业最多分一杯残羹。龙岩等其他地市，保护政策明朗，而莆田放开招投标市场，对以中小企业为主的莆田市建筑企业来讲，生存困难加大。近年来，尽管有不少扶持文件下发，却存在政策空转落地难的尴尬局面。3月份莆田出台《关于有效应对疫情有序推进建筑业复工复产的实施意见》，文件中提出疫情期间农民工补助一天60元,较难落实。

三、发展建议

（一）解企业中标困难。建议各县区加快发标速度，减少企业“无米下锅”的局面。预计下一步全国都会加大发标力度，建议主管部门引导企业在做好防疫的基础上，积极参与外地竞标，抢占国内其他市场。同时，建议主管部门鼓励中小企业“抱团发展”，促进开放合作加快转型。

（二）破企业融资困难。要强化监督，对长期拖欠工程款的业主，制定相应的制约措施。根据不同项目情况，可采取投资补助、基金注资、担保补贴、贷款贴息等方式，放大财政资金撬动社会资本的作用。同时考虑中小企业可抵押物少的实际情况，出台针对中小企业的灵活贷款可行性政策。

（三）关注中小项目进度。由于本地大多为中小建筑企业，建议各县区下一步除了关注大项目的工程进度，也要采取措施帮扶中小项目，如防疫物资和紧缺建材协调到位、外来人员组织到岗等，进一步加快工程进度。

（四）提高扶持政策的实效性。针对本地企业，建议主管部门可以着力了解国内建筑市场上哪些区域哪些行业紧缺，引导企业结合自身实际，做细做专，不要一味往房建市政工程扎堆，这是一条长期可持续、不需要地方保护、提高企业竞争力的发展途径。

同时，建筑企业不像房地产，可以打一枪换一个地方，建企是可以源源不断地为地方政府带来产值税收的企业，是需要政府切实为其营造良好发展环境的企业。建议主管部门加大出台扶持政策。
