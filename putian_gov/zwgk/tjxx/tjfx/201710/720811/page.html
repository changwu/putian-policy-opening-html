1-9月份全市经济运行呈四大亮点

第六十八期
来源：本网 时间：2017-10-19 15:54
| | | |

1-9月，全市经济呈“增长趋稳、需求趋旺、效益趋好、转型趋快”四大亮点。

主 要 亮 点

“增长趋稳”

一、经济运行总体平稳。初步核算，1-9月，全市GDP完成1438.54亿元，可比增长8.2%，增幅虽比1-8月回落0.3个百分点，但仍居全省第三位。其中，第一产业增加值84.83亿元，增长0.9%；第二产业增加值814.98亿元，增长7.3%;第三产业增加值538.74亿元，增长10.7%。主要经济指标增速仍居全省前三位分别为：零售业商品销售额、项目投资、财政总收入、地方级财政总收入、外贸进出口总额、进口总额、第二产业增加值、农村居民人均可支配收入、GDP、固定资产投资增幅等等。

1、农业生产基本稳定。1-9月，全市农林牧渔业总产值157.38亿元，可比增长1.4%，增幅比上年同期提高0.3个百分点；增加值93.29亿元，可比增长1.3%，增幅比上年同期提高0.2个百分点。主要特点：一是园林水果快速增长。今年以来，气候总体上适宜热带水果生长，全市产量恢复正常，呈现恢复性的增长态势。全市园林水果产量为16.12万吨，增幅由上年同期下降21.7%转为增长18.4%。其中，枇杷产量9.58万吨，增长29.2%。二是茶叶产量稳步增长。全市茶叶产量为0.39万吨，增长2.6%，增幅分别比上年同期、上半年回落2.1个和3.6个百分点。其中青茶产量0.32万吨，增长3.7%。三是渔业生产继续保持较快增长势头。全市水产品总产量74.47万吨，同比增长3.5%。其中，海水产品产量70.99万吨，增长3.5%；淡水产品产量3.48万吨，增长2.1%。在海水产品产量中，牡蛎产量29.40万吨，增长4.7%，对全市水产品总产量的贡献率高达52.5%；江篱产量7.15万吨，增长14.2%，对全市水产品总产量的贡献率高达35.7%。

2、工业生产稳中有升。1-9月，全市规模以上工业实现工业增加值706.92亿元，可比增长8.0%,增幅分别比1-8月、1-7月提高0.1个和0.2个百分点，高于全省平均增速0.1个百分点，居全省第四位。主要特点：一是先行指标不断向好。全市制造业工业用电量明显回升，制造业工业用电量同比增长12.6%，增幅分别比1-8月、1-7月、1-6月回升2.9个、4.8个和4.4个百分点；工业增值税降幅逐月收窄，全市工业增值税下降9.7%，降幅分别比1-8月、1-7月和1-6月收窄2.4个、3.2个和3.1个百分点。三季度，工业企业景气指数，企业家信心指数分别为123.1和122.2，均持续保持在“较为景气”区间。二是传统制鞋产业转型加快。全市规模以上制鞋产业实现工业增加值182.32亿元，增长14.5%，对规模以上工业经济增长的贡献率为37.6%，拉动规模以上工业经济增长3.0个百分点。鑫龙、双驰、永丰、力奴、辉特等62家市级鞋业龙头企业实现工业增加值82.61亿元，增长20.2%，占全市制鞋产业总量的45.3%，拉动制鞋产业增长8.2个百分点。鞋业供应链服务平台正式运营，加快我市制鞋资源的整合，为企业降本增效提供有力平台保障，目前该平台已入驻企业200多家。三是园区工业贡献近七成。全市园区规模以上工业企业752家，占全市规模以上工业企业数的59.4%，实现工业增加值492.39亿元，增长7.5%，占全市规模以上工业增加值的69.7%，对规模以上工业经济增长的贡献率为67.2%，拉动规模以上工业经济增长5.4个百分点。四是亿元企业增势强劲。全市超亿元以上规模企业共527家，同比增加33家，占规模以上工业企业数的41.6%。实现工业增加值612.77亿元，占规模以上工业增加值比重为86.7%，增长15.2%，增幅高于全市规模以上工业平均水平7.2个百分点，对规模以上工业经济增长的贡献率为129.7%，拉动规模以上工业增加值增长10.4个百分点。

3、第三产业稳步增长。1-9月，全市第三产业增加值同比增长10.7%，增幅高于全省平均水平0.8个百分点。主要特点：一是其他营利性服务业贡献突出。全市299家规模以上其他营利性服务业企业实现营业收入29.81亿元，同比增长57.5%，增幅比全省平均水平高26.1个百分点，居全省第四位，对全市第三产业增加值增长的贡献率为41.9%。中电网络科技、闽安制造服务外包、东方星海广告、莆田标准红木交易市场等192家商务服务业实现营业收入21.00亿元，增长51.8%，对规模以上其他营利性服务业营业收入增长的贡献率为65.9%，拉动规模以上其他营利性服务业营业收入增长37.9个百分点。二是商品房销售面积增速回升。全市商品房销售面积309.61万平方米，同比增长11.2%，增幅比1-8月提高1.3个百分点，拉动全市第三产业增加值增长0.4个百分点，比1-8月提高0.05个百分点。其中，住宅销售面积259.09万平方米，增长11.5%；办公楼15.39万平方米，增长18.4%。

二、物价平稳运行。1-9月，全市居民消费价格同比上涨0.8%，涨幅与1-8月持平。八大类价格呈“七升一降”态势，其他用品和服务类上涨6.8%、教育文化和娱乐类上涨2.0%、医疗保健类上涨1.9%、交通和通信类上涨1.8%、居住类上涨1.8%、衣着类上涨1.0%、生活用品及服务上涨0.4%、食品烟酒类下降1.6%。

三、就业保持稳定。尽管部分行业受市场影响就业压力有所加大，但在积极就业政策作用下，以及创业创新带动就业的影响下，就业总体保持稳定。据人社部门提供数据显示，截至9月底全市城镇新增就业15566人，同比减少1159人；实现再就业2096人，同比基本持平。城镇登记失业率约2.44%，虽同比上升0.29个百分点，但仍在可控目标3%以内，总体保持基本稳定。

“需求趋旺”

一、消费品市场销售趋旺。1-9月，全市实现社会消费品零售总额498.50亿元，比上年同期增长11.2%，增幅比上年同期提升0.2个百分点。主要特点：一是鞋帽类商品零售保持较快增长。在古奇天伦、新达等企业增长带动下，全市限额以上鞋帽类商品零售额60.21亿元，增长18.9%，增幅比全市限额以上零售额快2.3个百分点，占全市限额以上零售额的24.5%，占比居限额以上商品类首位,比第二位的汽车类高9.5个百分点。二是汽车消费增长明显。全市限额以上汽车类商品零售额36.87亿元，增长10.2%，增幅比1-8月提高1.1个百分点。其中，9月份零售额增长17.9%，创全年单月增幅最高。三是生活类商品快速增长。全市限额以上企业商品零售类别中，日用品类增长112.5%，化妆品类增长23.7%，增幅分别比社会消费品零售额高101.3个和12.5个百分点。四是建筑及装潢材料类商品销售趋旺。全市建筑及装潢材料类商品零售额8.21亿元，增长37.8%，增幅比限额以上消费品零售额快21.2个百分点。其中，9月份实现零售额0.80亿元，增长21.6%。

二、投资增幅同比回升明显。1-9月，全市固定资产投资完成1686.53亿元，比上年同期增长17.0%，增幅同比提高7.6个百分点，比全省平均水平高3.4个百分点，居全省第三位。主要特点：一是项目投资增速仍居全省首位。全市项目投资完成1426.05亿元，增长22.5%，增幅快于全市固定资产投资5.5个百分点，连续四个月居全省首位。二是工业投资稳步增长。全市工业投资完成510.24亿元，增长17.4%，增幅同比提高2.5个百分点。其中，制造业投资完成391.53亿元，增长25.1%，增速同比提高16.5个百分点。三是交通运输、仓储和邮政业投资高速增长。全市交通运输、仓储和邮政业完成投资252.73亿元，增长30.5%，增速同比提高22.0个百分点。其中，道路运输业完成207.91亿元，同比增长39.0%，增速同比提高24.4个百分点。四是民间投资增幅、贡献率双提高。全市民间投资完成983.09亿元，增长16.8%，增幅同比提高8.0个百分点；对全市固定资产投资增长的贡献率为57.6%，同比提高2.4个百分点。

三、出口形势好转。1-9月，全市外贸出口额157.39亿元，同比增长3.1%，增幅分别比1-3月、1-6月提高9.4个和2.6个百分点。其中，佳通轮胎、富力进出口、荔丰鞋业等55家出口超千万美元的企业实现出口17.70亿美元，增长20.4%，占全市出口总值77.0%。

“效益趋好”

一、财政增收良好。1-9月，全市实现财政总收入158.18亿元，比上年同期增长15.3%，增幅高于全省平均水平6.1个百分点，居全省第一位。其中，地方级财政收入104.66亿元，增长16.9%，增幅高于全省平均水平10.5个百分点，居全省首位。

二、居民收入继续增加。1-9月，全市城镇居民人均可支配收入26874元，同比增长8.0%，增幅比上半年提高0.1个百分点；农村居民人均可支配收入13020元，增长9.0%，增幅比上半年提高0.2个百分点，快于城镇居民人均可支配收入1.0个百分点。

“转型趋快”

一、产业结构不断优化。1-9月，服务业增加值占全市生产总值的比重达37.5%，比上年同期提高0.6个百分点；完成投资1144.92亿元，占全市固定资产投资比重达67.9%，分别比1-3月、1-6月提高2.6个和1.7个百分点。

二、工业新动能积极孕育。1-9月，全市规模以上战略性新兴产业实现工业增加值158.76亿元，可比增长13.6%，增幅快于全市平均水平5.6个百分点；高技术企业实现工业增加值52.15亿元，增长8.8%，增幅快于全市平均水平0.8个百分点；全市高成长和省级龙头企业实现工业增加值168.66亿元，增长24.3%，增幅快于全市平均水平16.3个百分点。

三、新兴业态快速增长。“互联网+”、“中国制造”催生的新产业、新产品、新业态、新模式迅猛发展，新的增长点不断孕育成长。1-9月，酷鱼爱尚、布依信等296家限额以上电商企业实现网上零售额77.75亿元，占全市限额以上消费品零售市场的31.6%，同比增长31.1%，增幅比全市限额以上零售额快 14.5个百分点，远高于实体零售店增速。1-8月，规模以上软件和信息技术服务业营业收入同比增长91.4%。

四、部分短板领域投入大幅增长。1-9月，全市固定资产投资中，居民服务和其他服务业投资增长121.4%，卫生和社会工作投资增长86.8%，文化、体育和娱乐业投资增长82.8%，水利、环境和公共设施管理业投资增长23.4%。全市公共财政预算支出中用于城乡社区支出增长138.9%。

五、待售面积持续下降。1-9月，全市房屋待售面积为195.35万平方米，下降11.2%。其中，住宅待售面积84.75万平方米，下降15.9%。待售面积下降，使得房地产消化库存压力变小。

存 在 问 题

一、农业增产增效制约因素较多。一是食用菌种植面积减少。近几年来，受我市人工费用等生产成本不断提高影响，我市食用菌生产大户已逐渐在云南等经济相对较不发达地区建立新的生产基地，其在我市的生产规模逐年缩小。1-9月，全市食用菌生产占用耕地面积8189亩，同比下降13.1%；食用菌产量5.49万吨，下降4.7%。二是农作物种植面积保持有难度。由于农业生产成本走高和农产品价格低迷，农民外出务工收入较高，导致农民种植农作物积极性降低，同时受拆迁征地影响，耕地面积逐渐流失，特别是南北洋适合种植水稻的大片良田流失严重。1-9月，全市农作物总播种面积94.79万亩，同比下降2.7%。其中，粮食作物播种面积26.40万亩，下降6.2%；粮食产量9.28万吨，下降5.6%。三是畜牧业肉类总产量大幅下降。受上年年底H7N9疫情影响，加上畜禽养殖污染整治，影响畜禽的存出栏，导致全市畜牧业肉类总产量大幅下降。1-9月，全市生猪出栏下降9.0%，存栏下降11.0%；家禽出栏下降34.7%，存栏下降15.9%。全市肉类总产量下降14.9%，禽蛋产量下降1.9%，奶产量下降7.4%。

二、工业下行压力加大。一是停、减产企业面不断扩大。9月末，全市停、减产面达29.4%，比8月末扩大0.3个百分点，共拉低全市规模以上工业增加值增幅4.9个百分点。停产企业145家，比8月末增加22家，影响工业增加值35.59亿元，拉低全市规模以上工业增加值增幅3.6个百分点；减产企业228家，影响工业增加值12.96亿元，拉低全市规模以上工业增加值增幅1.3个百分点。二是工艺与创意产业不景气。1-9月，全市规模以上工艺与创意产业增加值仅增0.1%，增幅同比回落10.6个百分点。受行业不景气和石雕企业整治影响，9月末，全市工艺与创意产业停产企业45家，比8月末增加11家。三是工业大项目投产、入库进度偏慢。华佳彩、云度新能源汽车等企业都未入库。鞍钢冷轧虽恢复生产，但设备还处于调试期，产量较少，产能尚未正常发挥。四是工业经济效益有所下滑。1-8月，全市工业经济效益综合指数349.42，分别比1-7月、1-6月和1-5月低4.13个、9.39个和8.44个百分点。利润总额115.42亿元，仅增5.6%，增幅低于全省平均水平11.5个百分点，这些工业经济效益指标下滑将直接影响明年的工业增加值率。

三、商贸业发展仍面临制约因素。一是停业（注吊销）企业影响较大。截止9月末，全市停业（注吊销）的批零企业达55家，影响全市批发零售业商品销售额增长1.5个百分点，影响社会消费品零售总额增长1.3个百分点。二是传统实体商场仍经营困难。1-9月，全市限额以上超市零售额13.37亿元，同比下降4.0%。其中，城厢下降5.3%，荔城下降8.1%。主要受超市竞争激烈，大部分超市经营业态、商品趋于同质化及微商冲击、海外代购等因素共同影响。三是家具、珠宝等本地特色行业拉动减弱。1-9月，全市限额以上家具类商品零售额、金银珠宝类商品零售额对全市社会消费品零售总额增长贡献率分别为0.5%和0.2%，同比分别回落2.3个和2.9个百分点。

四、投资增长后劲不足。一是项目投资特别是工业项目投资存量不足。1-9月，全市5000万以上项目累计已完成投资占计划总投资的77.2%左右，同比提高14.5个百分点；5000万以下项目累计已完成投资占计划总投资的88.5%，同比提高6.1个百分点；而占项目投资35.8%的工业投资累计完成投资占计划总投资的79.7%。大项目接近完工扫尾、投资工程存量不足将影响第四季度和明年的投资增幅。二是资金到位情况不理想。1-9月，全市建设资金到位1722.56亿元，同比仅增2.7%，增速比固定资产投资低14.3个百分点。其中，国内贷款191.60亿元，同比下降8.0%。三是房地产投资增幅靠后。1-9月，全市房地产开发投资完成260.48亿元，同比下降6.0%，降幅虽比1-8月收窄3.4个百分点，但仍低于全省平均水平8.4个百分点，居全省第七位。

五、服务业增长逐月回落。1-9月，全市第三产业增加值增长10.7%，增幅分别比1-3月、1-6月、1-8月回落1.2个、1.1个和0.5个百分点，呈逐月回落态势。主要原因：一是规模以上其他营利性服务业营业收入增幅高位逐月回落影响，1-8月增长57.5%（错月值），增速分别比1-7月、1-6月、1-4月回落4.3个、7.8个和13.2个百分点。二是水上运输总周转量降幅不断扩大。1-9月，全市水上运输总周转量同比下降54.0%，降幅分别比1-8月、1-7月、1-6月扩大4.2个、9.1个和15.6个百分点，居全省第九位。三是财政一般公用等八项支出增速回落。全市财政一般公用等八项支出同比增长18.7%，增幅分别比1-8月、1-7月、1-6月回落2.8个、4.8个和0.4个百分点。四是人民币贷款余额增幅逐月回落。全市人民币贷款余额增长10.1%，增幅分别比1-8月、1-7月、1-6月回落0.4个、1.9个和0.2个百分点。

对 策 建 议

一、强化经济运行调节，推动三次产业共同发力。抓好农业生产，优化产业结构，加快农业供给侧结构性改革，大力推进农业产业化经营，发展壮大新型农业经营主体。加大对工业运行的督导和帮扶力度，特别要关注“降成本”，缓解企业成本负担和压力，要在精准上下功夫，紧盯重点地区、重点行业和重点企业，分类指导，精准施策。加快发展服务业，利用制造业基础，重点培育发展现代物流、电子商务、检验检测、标准计量、节能服务、软件与信息技术服务等生产性服务业，提升服务水平，促进制造业的服务化、智能化转型升级；以精细化、品质提升、消费升级为导向，着力扩大生活性服务业有效供给。大力培育新的市场主体，持续深化放管服改革，完善减税降费举措，营造良好的发展环境，增强经济发展活力。

二、扩大有效投资，增强三大需求拉动力。坚持以项目建设作为转型升级的强大支撑，加大项目引进、谋划力度，及时协调解决重点项目建设中存在的问题。进一步拓展民间投资空间，鼓励和引导民营资本参与基础设施、能源、教育、市政公用事业等领域建设，促进公私合营模式健康快速发展。积极争取国家预算和中央建设资金，加大金融机构对企业的支持力度，拓宽资金渠道。加强房地产市场监管，坚持因城施策、精准调控。合理引导消费，加快发展商贸新业态，促进传统零售企业转型升级。增强消费对经济增长拉动作用。充分发挥自身优势，优化招商环境，扩大引资和出口规模，加快聚集区和开发区建设，进一步提升对外开放水平。

三、推动转型升级，释放经济增长新动力。以创新推动转型升级。紧紧抓住增强自主创新能力中心环节，大力推进原始创新、集成创新和引进消化吸收再创新，突破关键核心技术，加速传统产业转型升级步伐。创新企业组织模式、管理模式和销售模式，着力提升企业内力。大力支持现代服务业、高新技术产业、战略性新兴产业、高端装备制造业等新动能产业发展，加大企业研发投入力度，让传统产业通过技术改造尽快升级，形成推动经济增长的新动力。
