莆田市节能现状及影响单位GDP能耗的因素分析

第六十三期
来源：本网 时间：2017-10-16 16:05
| | | |

一、总结“十二五”节能工作，迎接“十三五”新的挑战

（一）“十二五”节能指标顺利完成

从整体看，我市“十二五”期间GDP能耗下降16%的目标已经完成。这一方面是依靠主观因素，即调整结构、转型升级，我市政府、行业和各企业为此做了大量工作和努力；另一方面是客观因素影响，即“十二五”后期经济形势下行、高耗能行业产能下降等。

回看“十二五”节能工作，节能政策的制定和实施发挥了必不可少的作用，如强化目标责任制、优化产业结构、实施节能重点工程等，以及相应的法制建设、资源税改革等。此外，节能技术进步、产品开发应用，以及相应的宣传教育，都让节能、低碳、绿色发展的理念，逐步深入民心，并形成了良好的社会氛围。

（二）“十三五”节能任务更新要求

2015年3月，中央将“绿色化”加入原来的“四化”，明确提出“五化”。而十八届五中全会也将“绿色发展”作为“十三五”五个发展理念之一明确提出。这些都表明，绿色、生态，将是我国未来经济社会发展的一条重要主线，和经济结构转型、产业结构优化调整、发展方式转变密切相关，是实现这些目标的重要抓手和着力点。

“十三五”节能任务有了更新更高的要求，即从能效指标和强度指标两方面进行控制，简称“双控”。我市“十三五”的“双控”目标为，期间新增能耗总量控制在170万吨标准煤以内，单位GDP能耗下降14%。

二、能源消费情况

2016年我市能源消费总量为522.51万吨标准煤，较上年增加38.3万吨标准煤，万元GDP能耗为0.464吨标准煤/万元，同比降低率为0.96%，完成了年初制定的能源消费增量控制在40万吨标准煤以内、单位GDP能耗同比保持下降的总量和强度“双控”目标任务。

（一）分产业看，第二产业是能源消费主体

2016年，第一产业能源消费总量为8.16万吨标准煤，同比增长6.5%，占全社会能源消费总量的1.6%；第二产业能源消费总量为282.93万吨标准煤，同比增长12.8%，占全社会能源消费总量的54.1%，其中工业能源消费量为276.41万吨标准煤，同比增长13.3%，占全社会能源消费总量的52.9%；第三产业能源消费总量为101.65万吨标准煤，同比增长2.4%，占全社会能源消费总量的19.5%；居民生活用能为127.24万吨标准煤，同比增长2.4%，占全社会能源消费总量的24.4%。可见，第二产业能源消费总量占全社会能源消费总量一半以上。

（二）全社会用电量增幅趋缓，工业用电全省第一

2016年我市全社会电力消费量为111.76亿千瓦时，同比增长15.2%，增幅较上年回落1.5个百分点，增幅居全省第二。

从产业看，第一产业用电量为0.93亿千瓦时，同比增长1.7%；第二产业用电量为69.13亿千瓦时，同比增长17.2%；第三产业用电量为14.21亿千瓦时，同比增长15.0%；生活电力消费为27.50亿千瓦时，同比增长11.2%。

其中，工业用电量占全社会用电重头。2016年我市工业用电量为67.52亿千瓦时，占全社会用电量的60.4%，同比增长18.0%，增幅较上年缩减10.0个百分点，但仍居全省第一。

（三）规模以上工业能耗影响全市能耗走势

规模以上工业综合能源消费量为198.15万吨标准煤，同比下降3.2%，扣除火力发电行业，同比增长6.8%，单位工业增加值能耗下降10.5%。（注：规模以上工业综合能源消费量均为当量值。）

1、六大高耗能行业能耗对节能降耗影响大

2016年我市六大高耗能行业综合能源消费量为123.89万吨标准煤，同比下降7.6%，降幅比上年减少3.3个百分点，占规模以上工业能源消费量的比重为62.5%。

2、综合能耗较上年增长的行业占50%

2016年我市现有32个规模以上工业行业中综合能耗较上年增长的共有16个，比重为50.0%，其综合能耗为59.51万吨标准煤，同比增长21.8%，对全市规模以上工业综合能耗的影响为5.2个百分单。其中，增速超过30%的行业有2个（其他制造业、化学原料和化学制品制造业）、增速小于30%大于10%的行业有11个（木材加工和木、竹、藤、棕、草制品业，农副食品加工业，水的生产和供应业，燃气生产和供应业，印刷和记录媒介复印业，仪器仪表制造业，家具制造业，橡胶和塑料制品业，专业设备制造业，食品制造业，金属制造业）。

3、火力发电单耗小幅下降，其他产品单耗不降反升

火力发电作为我市的能源消费大户，2016年能源消费量占全市规模以上工业能耗的46.1%，其单耗的高低对我市节能工作有重要的影响，单耗越低越节能。2016年我市火力发电标准煤耗由上年的268.99克标准煤/千瓦时下降为265.92克标准煤/千瓦时。

另外，我市粘胶纤维综合能耗（短纤）由上年的822.52千克标准煤/吨增加到828.30千克标准煤/吨，印染布综合能耗由上年的4496.01千克标准煤/万米增加到4640.16千克标准煤/万米，可见我市的部分工业行业存在一定的节能空间。

三、当前节能工作存在的问题

（一）经济增长对能源消费的依赖增强，重工业化的进程使结构节能不能发挥积极的效应。我市正进入工业化快速发展和产能扩张阶段，这一阶段对能源消费的依赖较强，加之我市工业经过多年的发展，重工业比重逐渐增加，这更加剧了对能源的依赖。从三次产业构成来看，2016年我市工业增加值占生产总值的比重为46.8%，而工业的能耗占全社会的比重为52.9%，这表明我市工业发展对能源的依赖性较强。加之“十三五”规划年耗能在5000吨标准煤以上项目计35个，项目年综合能耗共计880.5万吨标准煤，其中已开工或建成的湄洲湾第二发电厂2台1000MW超超临界、中锦新材料PA6、华佳彩高世代面板等20个项目，预计新增总能耗在242万吨，能耗增量超出我市“十三五”新增能耗控制目标较多。

（二）工业能耗比重大，下降难。高耗能行业集中度高，能耗水平居高不下。从能源消费结构看，2016年我市第一产业、第二产业、第三产业及居民生活用能构成为1.56:54.15:19.45:24.35，其中工业用能的比重为52.9%，而我市生产总值的三次产业结构为6.45:56.72:36.83，其中工业增加值仅占地区生产总值的46.8%。从工业内部看，石油加工、炼焦及核燃料加工业，化学原料及化学制品制造业，非金属矿物制品业，黑色金属冶炼及压延加工业，有色金属冶炼及压延加工业及电力、热力的生产和供应业六大高耗能行业当量值能源消费量123.89万吨标准煤，占规模以上工业能源消费量比重为62.5%，其创造的增加值为94.20亿元，约占规模以上工业增加值的11.8%。可见，高耗能产业对能耗影响力远大于对生产总值的影响力，造成了工业能耗下降难度大的情况。

（三）电力消费对我市节能降耗影响巨大。电力是我市主要的能源消费品种，其在全社会能源消费中所占比重大，对我市节能形势有至关重要的影响。2016年我市电力消费为336.37万吨标准煤，占全社会能耗的64.4%，较2015年增加了43.46万吨标准煤，对我市全社会能耗的推动作用为9.0个百分点，高于全社会能耗7.9%的增速。由此可见，电力消费的增长，压缩了节能空间，对我市节能降耗影响巨大。引起我市电力消费增长的主要因素：

2、三产、居民生活电力消费保持较快增长。2016年第三产业、居民生活电力消费增速分别为15.0%、11.2%，对全社会用电量影响为5.0个百分点。

四、影响我市单位GDP能耗下降的因素

（一）全社会用电总量的扩大、幅度的增长是影响节能降耗工作的重要因素之一。单位GDP能耗核算时，需采用本地区的发电煤耗系数，因此我市电力消费量的增长，势必带来能源消费的大量增长，使完成节能目标任务的难度进一步加大，对我市节能降耗工作将产生巨大影响。2016年我市全社会用电量增速始终保持较高水平，电力消费约占全社会能源消费总量的64.4%，明显是制约我市单位GDP能耗下降的重要因素之一。

（二）部分企业生产扩大及新增企业的加入产生影响。2016年我市规模以上工业企业中工业总产值同比增长的企业有877家，增长面达69.7%，其中福建中锦新材料有限公司、福建华峰新材料有限公司、赛得利（福建）纤维有限公司、莆田市鑫龙鞋业有限公司等产值超十亿元企业增势较好，推动我市规模以上工业企业向好发展。从工业企业景气问卷调查结果看，2016年四季度我市工业景气指数为115.15，比三季度、二季度回升2.03、1.69个百分点；企业家信息指数为114.32，比三季度、二季度回升1.09、0.02个百分点，企业家对市场景气、信心指数双双回升，企业景气“相对景气”，与之前连续下滑的局面比，企业对市场的态度逐渐乐观，可见企业生产将有进一步的提高，对单位GDP能耗的下降势必有影响。

同时，2016年度我市新建投产入库企业23家，加上2017年预备投产的湄洲湾火电厂二期、华佳彩高世代面板等大项目，新增能耗总量大，将影响单位GDP能耗下降目标及能耗总量增量控制目标的完成。

（三）“发电煤耗”指标对全社会能耗总量的影响。按照国家下发的单位GDP能耗测算方法，能源总量的测算需以等价值来计算，电力消费量必须乘以等价系数来计算标准量。我市采用的等价系数由火力发电煤耗水平来决定，因此，火力发电煤耗越高，等价系数就越高，相同的电力消费量计算出的能耗总量就越高，因此发电煤耗的变化对单位GDP能耗影响较大。2016年我市电厂火力发电标准煤耗略有下降，由268.99克标准煤/千瓦时减少为265.92克标准煤/千瓦时，主要是受太平洋电力发电较大幅度减少影响，其在火力发电中比重由58.5%下降为54.3%，一定程度上减轻了单位GDP能耗下降的压力。但随着湄洲湾火电二厂的投产，燃煤发电在火力发电中将大比重增加，发电煤耗只增不减，对我市节能降耗工作形成了较大的压力。

五、下一步节能工作的建议——坚持绿色发展理念

坚持绿色发展理念，走绿色低碳循环发展之路，是突破资源环境瓶颈制约、消除党和人民“心头之患”的必然要求，是调整经济结构、转变发展方式、实现可持续发展的必然选择。

（一）科学规划，引导和规范绿色发展。把推进绿色发展纳入国民经济和社会发展“十三五”总体规划，落实到各地各部门的经济社会发展规划、城乡建设规划、土地利用规划、生态环境保护规划以及各专项规划中，科学布局绿色发展的生产空间、生活空间和生态空间。充分发挥规划的引领和规范作用，强化绿色发展的刚性约束，扎实有效地抓好落实，形成特色鲜明、布局合理的功能分区，实现资源与项目的最佳配置。

（二）推动转型，加快生产方式和消费模式绿色转变。生产方式和消费模式绿色转型，是绿色发展的核心。一方面，大力推动生产方式的绿色化，改变高污染、高耗能的传统生产模式，加快产业结构调整和优化升级，构建绿色产业体系，努力实现生产过程的绿色化，提高经济绿色发展程度。另一方面，积极倡导和大力推行绿色消费，推广使用节能节水设备、节能家电、节能与新能源汽车和节能住宅等产品，发展城市绿色交通，推进生活垃圾分类收集处理，鼓励和引导公众在生活方式上加快向绿色消费转变，构建文明、节约、绿色、低碳的消费模式和生活方式。

（三）强化法治，保障绿色改革推行。建立具有强制力、权威性和高效率的规则体系，用法治来调整利益格局、规范行为秩序，保障绿色发展。适应绿色发展的要求，抓紧制定、修改和完善生态建设、环境保护、清洁生产与发展循环经济等方面的法律法规。要加强对绿色发展重大决策和相关法律法规实施情况的法律监督和工作监督，确保绿色发展的法律法规有效实施及重大决策部署贯彻落实。要加强对环境资源、生态建设的司法保护，依法惩治污染环境、破坏生态建设的犯罪行为。

（四）加强宣传，培育全社会绿色文化。把绿色发展、生态文明知识纳入国民教育体系和继续教育体系，采取多种有效方式，广泛开展生态文明、绿色文化宣传教育，使绿色发展理念深入人心。要组织、鼓励和引导社会组织、志愿者和广大群众积极参与绿色发展的公益活动和全民行动计划，积极开展生态文明创建活动，进一步普及绿色政绩观、绿色生产观、绿色消费观，引导人民群众崇尚节约、低碳生活，在全社会形成尊重自然环境、建设生态文明的浓厚文化氛围。
