前三季度莆田市城镇居民收支状况分析

来源:莆田调查队 时间：2010-10-20 00:00
| | | |

今年以来，莆田市委、市政府认真贯彻落实胡锦涛总书记视察福建时的重要讲话精神，紧紧围绕“保八超十、全面完成十一五规划”的目标任务，大力实施“以港兴市、工业强市”战略,全市经济保持稳步较快发展，城镇居民收入持续稳步增长，生活质量再上新台阶。

一、城镇居民收入增速持续加快

据调查资料显示：今年以来，我市城镇居民可支配收入增速呈低开高走、逐月提升的态势。前三季度，全市城镇居民人均可支配收入达到14576元，比上年同期增长9.5%，增幅分别比第一季度和上半年高出5.8和2.1个百分点。

1、工资性收入稳步增长。我市从今年3月1日起调整最低工资标准及非全日制用工小时最低工资标准，确保了效益差的企业职工和临时工的经济利益，再加上各县区公务员、教师第二次津补贴政策落实，促使工资性收入稳步增长。据调查资料显示：前三季度，全市城镇居民人均工资性收入10861元，比上年同期增长7.1%，拉动可支配收入增长5.4个百分点。

2、惠民政策拉动城镇居民转移性收入持续增长。受今年企业退休人员养老金调整的影响，城镇居民转移性收入继续保持两位数增长。据调查资料显示：前三季度，全市城镇居民人均转移性收入1906元，比上年同期增长12.5%，拉动可支配收入增长1.5个百分点。其中人均养老金或离退休金1408元，增长21.5%，占转移性收入73.9%，对转移性收入增长的贡献率大。

3、投资多元化拉动财产性收入大幅增长。我市城镇居民投资比较活跃，投资渠道日益多元化，主要包括合伙投资、出租固定资产等，促进了财产性收入大幅增长。据调查资料显示：前三季度，全市城镇居民人均财产性收入2201元，比上年同期增长23.4%，拉动可支配收入增长3.1个百分点。其中人均利息收入84元，增长23.5%，拉动财产性收入增长0.9个百分点；人均股息与红利收入138元，增长5.3倍，拉动财产性收入增长6.5个百分点；出租房屋收入1971元，增长16.7 %，拉动财产性收入增长15.8个百分点。

4、经营净收入平稳增长。今年以来，我市经济保持平稳较快发展态势，城镇居民经营状况逐步好转，经营净收入平稳增长。据调查资料显示：前三季度，全市城镇居民人均经营净收入1001元，比上年同期增长 4.5%。 

二、城镇居民消费水平继续提高

据调查资料显示：前三季度，全市城镇居民人均消费性支出9675元，比上年同期增长12.1%，增幅比上年同期提高3个百分点。

1、食品消费呈结构性增长。据调查资料显示：前三季度，全市城镇居民食品支出3986元，比上年同期增长10.7%，扣除价格上涨因素后实际增长4.3%。其中人均粮油类支出增长12.8%、人均蔬菜类支出增长17.7%、人均糖烟酒饮料类支出增长14.8%、人均干鲜瓜果类增长14.2%、人均糕点奶及奶制品增长22.9%、人均在外饮食增长31.3%。

2、家庭设备用品及服务消费保持强劲增长。伴随着城镇居民收入水平的提高及消费观念的转变，家庭服务社会化程度越来越高，家用电器消费品位不断提升，城镇居民家庭耐用消费品更新换代加快。据调查资料显示：前三季度，全市城镇居民人均家庭设备用品及服务消费支出675元，比上年同期增长23.5%,拉动消费性支出增长1.5个百分点，其中人均耐用消费品支出336元，增长16.4%；人均家庭服务支出37元，增长57.2%。

3、医疗保健支出大幅增长。随着城镇居民健康意识的增强，城镇居民在医疗保健方面的投入逐步增加，尤其注重疾病的预防和保健养生。据调查资料显示：前三季度，全市城镇居民人均医疗保健支出355元，比上年同期增长16.8%，其中人均药品费支出222元，增长24.5%；人均滋补保健品支出48元，增长40.5%。 

4、网络消费快速增长，信息化程度不断提高。截至9月末，城镇居民家庭每百户家用电脑拥有量达91台，每百户接入互联网的家用电脑达到79台；随着手机功能及服务的不断拓展，手机上网渐成时尚，每百户接入互联网的移动电话达18部，信息化程度不断提高。据调查资料显示：前三季度，全市城镇居民人均通过互联网购买的商品及服务支出28元，比上年同期增长9.5倍。

5、文化生活日益丰富，旅游消费尤为突出。随着生活水平不断提高，城镇居民重视并加大对教育的投入，精神文化生活向健康型和知识型发展，旅游、健身、娱乐已成为居民家庭业余生活的主流。据调查资料显示：前三季度，全市城镇居民人均教育支出493元，比上年同期增长38.8%，其中人均成人教育费支出93元，增长43.9%；人均家教费支出79元，增长1.2倍；人均培训支出74元，增长28.3%。全市城镇居民人均文化娱乐服务支出399元，比上年同期增长93.2%，其中人均团体旅游花费支出269元，增长94.7%。

6、居住消费持续快速增长。随着城镇居民收入的不断增加，居民对居住环境的要求越来越高，住房消费成为当前带动居民消费结构升级的主导产品。据调查资料显示：前三季度，全市城镇居民人均居住消费支出1243元，比上年同期增长21.2%，拉动消费性支出增长2.5个百分点。

7、服务性消费成为新的增长点。随着居民生活水平的提高，消费观念的转变，城镇居民家庭服务社会化趋势愈来愈明显，居民对服务性消费需求不断上升。据调查资料显示：前三季度，全市城镇居民人均服务性消费支出2287元，比上年同期增长24.2％。

三、当前城镇居民家庭生活存在的主要问题

1、食品价格上涨对低收入居民家庭影响较大。据调查资料显示：前三季度，全市居民消费价格比上年同期上涨2.9%，其中食品类价格上涨6.1%。由于城市低收入居民收入水平低，消费能力弱，只保障日常食品类消费为主，而今年物价上涨又突出表现在粮油、肉禽蛋等日常主要消费的食品上，因此食品价格的上涨对低收入居民家庭影响较大。据调查资料显示：前三季度，全市最低收入户城镇居民家庭人均食品消费多支出154元。

2、消费两极分化依然突出。据调查资料显示：前三季度，最高收入户的人均消费支出13475元，最低收入户家庭的人均消费支出4667元，最高收入户人均消费是最低收入户的2.9倍。最高收入户家庭的消费趋向于享受型和高档型，而最低收入家庭主要限于吃、穿，占其消费性支出的56.4%，而最高收入户占43.2%。

3、城镇居民高低收入户差距依然较大。虽然我市城镇居民收入水平和生活质量得到较大提高，但收入差异过大的问题依然突出。据调查资料显示：前三季度，我市城镇居民最高收入户人均可支配收入为24536元，最低收入户人均可支配收入为5334元,高低收入比为4.60:1。城镇居民收入差距成为收入分配领域和经济发展中值得关注的重要民生问题。

四、对策与建议

1、加大调控力度，稳定市场物价。市场物价的过快上涨，对少数低收入家庭来说，负面影响已日益显现，各级政府应加大调控力度，稳定市场物价，减轻低收入家庭生活负担，特别是与居民生活息息相关的菜蓝子价格，保证居民最终收入的增加不因物价上涨而抵消，确保低收入居民家庭生活水平不因涨价而受到较大影响。

2、健全补贴机制和适度提高低保标准。适时根据居民消费价格指数和生活必需品价格上涨情况，结合低收入群体家庭的承受能力，建立健全价格补贴机制，实行必要的价格补贴措施。同时，要根据市场物价水平及时调高低保标准，或建立与市场物价指数相关联的低保机制，减小物价上涨对低收入居民生活的影响。

3、切实提高低收入家庭收入水平。扩大低收入居民就业，增加他们的收入，是减小低收入家庭生活受物价上涨冲击的最有效途径。要采取鼓励用人单位尽可能多招录低收入人员的优惠政策，为吸纳低收入人员就业的企业给予相应的鼓励政策。各级工会、劳动主管部门要进一步加强对有劳动能力的低收入居民的就业技能培训，扩大他们就业的机会和空间。

4、大力调整收入分配格局。收入分配制度的不完善，一直是制约居民收入增长的一个重要因素，在国家“调结构、扩内需”政策指导下，调整不合理的收入分配格局是确保居民收入稳定增长的基础。首先要大幅度提高最低工资保障水平，让更多的人享受经济发展带来的实惠。其次是加大财政对低收入群体转移力度和范围，不断提高低保标准，缩小社会贫富差距。

五、全年城镇居民收入趋势展望 

根据前三季度我市城镇居民收入变化情况，预计全年我市城镇居民收入仍将保持持续稳步增长。主要原因：一是我市经济仍将保持较快发展，城镇居民收入也随经济较快增长而呈现稳步增长态势。二是以保障和改善民生为重点的各项公共政策的设计与执行，必将进一步提高城镇居民的未来收入预期。三是社会保障力度加大。随着政府提高最低工资标准和失业人员补贴等措施的进一步落实以及医疗、养老保险、社会救济与捐助范围的不断扩大，将成为增加城镇居民收入的有利条件。初步预计，今年我市城镇居民人均可支配收入可达19000元左右。
