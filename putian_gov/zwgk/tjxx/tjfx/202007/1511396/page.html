上半年我市经济回升势头明显

第三十六期
第三十六期
来源：本网 时间：2020-07-17 16:19
| | | |

上半年，在市委市政府的坚强领导下，全市上下统筹推进疫情防控和经济社会发展，不断加大“六稳”工作力度，全面落实“六保”任务，经济回升势头明显。1-6月，全市GDP完成1306.41亿元，比上年同期下降0.5%，降幅比一季度收窄5.5个百分点。

一、经济运行特点

（一）生产领域明显复苏

1、农业生产稳步增长。上半年,全市农林牧渔业总产值111.02亿元，可比增长2.9%，增幅比一季度提高1.6个百分点。主要亮点：一是春粮扩种增产。2020年,全市春收粮食播种面积为1.94万亩，增长19.0%；产量为0.62万吨，增长16.5%，其中谷物、薯类和豆类分别增长31.5%、13.0%、16.3%。二是蔬菜瓜果生产情势良好。上半年，全市蔬菜播种面积产量达31.96万吨，增长3.3%；瓜果类产量0.22万吨，增长106.7%。三是茶叶水果喜获丰收。上半年，全市茶叶产量为0.19万吨，增长4.6%；园林水果产量为7.39万吨，增长8.3%，其中枇杷产量为6.58万吨，增长9.1%，对园林水果的贡献率高达96.1%。四是生猪产能呈恢复态势。上半年，全市生猪存栏20.30万头，增长26.3%，增幅比一季度提高13.6个百分点；出栏25.54万头，下降30.6%，降幅比一季度收窄6.7个百分点。五是水产品产量增幅有所回升。上半年，全市水产品总产量63.21万吨，增长3.0%，增幅比一季度高0.8个百分点。其中，海水产品产量61.36万吨，增长3.1%，增幅比一季度提高0.8个百分点。

2、工业、建筑业生产加快复苏。上半年，全市规模以上工业增加值下降0.7%，降幅较一季度收窄5.2个百分点。主要亮点：一是行业增长面不断提高。上半年，全市规上工业中16个行业工业增加值实现正增长，增长面为48.5%，比一季度提高15.2个百分点。二是重点产业贡献突出。上半年，全市规上电子信息产业工业增加值增长22.6%，对规上工业经济增长的贡献率为254.0%，拉动全市规上工业增加值增长1.8个百分点；化工新材料产业工业增加值增长6.5%，对规上工业增加值增长的贡献率为145.2%，拉动全市规上工业增加值增长1.0个百分点。三是新增工业企业贡献突出。上半年，9家去年以来新投产企业对规上工业增加值增长的贡献率为495.8%，拉动规上工业增加值增长3.5个百分点；43家去年年底转规企业对规上工业增加值增长的贡献率为88.7%，拉动规上工业增加值增长0.6个百分点。四是建筑业总产值降幅收窄。上半年，全市总专包企业完成建筑业总产值353.31亿元，同比下降5.6%，降幅比1-3月收窄16.4个百分点。

3、服务业实现正增长。上半年，全市第三产业增加值增长1.0%，增幅比一季度（-2.7%）提高3.7个百分点。主要亮点：一是批发业商品销售额增幅强劲回升。上半年，全市批发业商品销售额完成992.06亿元，增长3.9%，增幅比一季度提高20.1个百分点，拉动第三产业增加值增长0.3个百分点，比一季度提高1.8个百分点。二是规上服务业营业收入增幅居全省首位。1-5月，全市规模以上服务业营业收入87.96亿元，增长37.7%，增速比1-2月提高35.2个百分点，比全省平均水平高38.1个百分点，居全省第一位。其中，交通运输、仓储和邮政业增长102.1%，拉动规模以上服务业营业收入增长38.3个百分点；租赁和商务服务业增长16.0%；科学研究和技术服务业增长11.6%。三是零售业商品销售额、道路客运货总周转量、商品房销售面积降幅逐步收窄。上半年，全市零售业商品销售额、道路客货运总周转量、商品房销售面积分别同比增长-3.5%、-0.9%、-11.1%，降幅分别比一季度收窄12.7个、13.1和19.0个百分点。

（二）两大内需逐步好转

1、消费市场逐步回暖。上半年，全市实现社会消费品零售总额793.27亿元，同比下降2.3%，降幅分别较1-2月、1-3月、1-4月和1-5月收窄3.3个、4.9个、3.0个和1.2个百分点。主要亮点：一是刚性需求增势稳定。全市限上肉禽蛋类与服装类零售额延续今年以来增长势头，分别增长34.6%和65.8%，分别高于社会消费品零售额36.9和68.1个百分点。二是便民业态逆市增长。全市限上食杂店、便利店零售额增长16.3%和38.3%。三是汽车消费逐月走强。全市限上汽车类零售额下降8.6%，较1-3月收窄7.0个百分点。四是外卖送餐表现抢眼。住宿餐饮企业创新营销适应“宅经济”发展，加大外卖、半成品和原材料配送，限额以上外卖送餐服务收入增长886.1%。

2、投资降幅明显收窄。上半年，全市固定资产投资同比下降1.6%，降幅分别比1-3月、1-5月收窄26.5个和13.7个百分点。主要亮点：一是大项目贡献较大。上半年，全市亿元及以上项目257个，同比增加58个，投资额同比增长22.1%，增幅比1-5月提升21.1个百分点。二是制造业投资回升。上半年，全市制造业投资同比增长20.9%，增幅比1-5月提高17.5个百分点。三是基础设施投资降幅持续收窄。上半年，全市基础设施投资下降10.6%，降幅比1-5月收窄11.4个百分点，其中交通运输业投资同比下降26.8%，比1-5月收窄15.7个百分点。四是房地产开发投资降幅逐步收窄。上半年，全市房地产开发投资下降10.4%，降幅比1-5月收窄7.5个百分点，其中住宅投资下降12.2%，降幅比1-5月收窄4.3个百分点。

（三）新经济新动能较快成长

1、工业新动能加速集聚。上半年，全市规上工业高技术企业增长23.5%，拉动规上工业增加值增长1.8个百分点；规上战略性新兴产业增长9.4%，拉动规上工业增加值增长2.2个百分点；规上装备制造业增长6.6%，拉动规上工业增加值增长1.0个百分点。

2、线上消费持续发力。上半年，全市限上实物商品网上零售额124.91亿元，增长21.7%，比1-3月提高3.2个百分点；占限额以上零售额的比重为49.1%，同比提高10.6个百分点，拉动限额以上零售额增长8.9个百分点。

3、高端制造业投资快速增长。上半年，全市装备制造业增长40.7%，增幅比1-5月提高16.6个百分点，高于全市固定资产投资增幅42.3个和百分点；先进制造业增长35.2%，增幅比1-5月提高17.4个百分点，高于全市固定资产投资增幅36.8个百分点。

（四）民生不断改善

1、物价总体回落。上半年，全市市区居民消费价格总水平同比上涨2.6%，涨幅比一季度回落0.9个百分点。其中，八大类商品和服务价格呈“六涨二降”态势。食品烟酒类上涨8.1%，其他用品和服务类上涨4.7%，医疗保健类和衣着类均上涨1.1%，教育文化和娱乐类上涨0.8%，生活用品及服务类上涨0.4%、居住类下降0.6%、交通和通信类下降2.4%。

2、居民收入有所提高。上半年，全体居民人均可支配收入16902元，增长2.2%，增幅比一季度提高1.3个百分点，居全省第4位，比一季度前移1位；城镇居民人均可支配收入21663亿元，增长0.7%；农村居民人均可支配收入11258亿元，增长2.4%，农村居民人均可支配收入增速快于城镇1.7个百分点。

二、存在主要问题

（一）生产下行压力加大

1、海产品出口订单较少，水产品价格总体下降。受新型冠状病毒国外疫情仍未好转影响，南日鲍等我市高端海产品出口订单较少。同时受疫情影响，我市除海带价格略升外，其他均呈下降态势，其中鲍鱼价格同比下降20%-30%。

2、工业出口形势及盈利情况不容乐观。上半年，全市规上制鞋企业出口交货值由上年同期增长21.4%转为下降5.4%。1-5月，规上工业实现利润总额同比下降8.4%，其中88家亏损企业，亏损企业增长31.3%。

3、规上其他营利性服务业发展后劲不足。2019年末，全市新增入库规上其他营利性服务业企业40家，比上年减少33家。截止5月底全市无月度新增入库企业，发展后劲不足，随着上年同期基数不断加大，其他营利性服务业增速提升进位压力较大。

（二）内需驱动仍有隐忧

1、消费品市场进一步增长压力加大。受疫情影响， 6月末全市停业未复产的限上批发和零售企业仍有19家，拉低限上商品零售额增长0.2个百分点； 255家停业关闭带基数企业拉低限上商品零售额增长10.6个百分点；277家零售额下降企业拉低限上商品零售额增长12.3个百分点。

2、有效投资需求仍不足。本月新增项目80个，同比减少70个。本年累计在库项目764个，同比减少527个，其中5000万以下项目同比减少581个；本年亿元新开工项目80个，完成投资额同比下降4.6%；民间投资下降12.0%,降幅高于全省平均水平10.0个百分点；第三产业投资同比下降11.3%，拉低全市固定资产投资增速8.1个百分点。

三、若干建议

（一）稳工业。一是加强经济监测重视龙头企业。围绕扎实做好“六稳”工作，全面落实“六保”工作，加强民生物资的生产。重点关注全市优势传统产业，重点扶植龙头企业，扩大产业链条，提高龙头企业的拉动作用，并促进微型企业上数量、小型企业上规模、中型企业上层次。二是加快产业转型升级步伐。培育壮大高端装备制造业、数字产业等标志性、引领性产业集群，在先进制造业发展方面迈出新的更大步伐。三是多渠道增加企业订单。加强对企业产品销售的帮助力度，支持企业网上洽谈、网上办展，主动抓订单、促合作，协调寻找下游产业需求方，同时大力开拓省外市场，推动企业全面达产达效。

（二）促投资。一是加大施工力度。利用投资旺季加大项目施工力度，加强项目用工、用地、用能、资金等要素保障，抢抓工期、赶超进度，推动项目建设开工达产、落地见效。二是着眼补短板、强弱项，要发挥重大投资项目带动作用，加快5G 网络、数据中心、工业互联网等新型基础设施建设进度；加快补齐这次疫情暴露出的公共卫生体系方面的短板弱项，加大公共卫生服务、应急物资保障领域投入。三是继续加快发展现代服务业，要重点发展为制造业配套的生产性服务业，使三次产业的内部结构不断优化。

（三）扩消费。一是精准落实国家、省、市各项促消费政策，确保政策红利惠及每家企业；超前谋划促消费活动，继续发挥消费券“杠杆作用”，激发和释放居民疫情期间被抑制的消费潜力。二是推动传统商贸企业转型升级，实现线上线下融合，把疫情期间兴起的网络消费、直播带货、无接触式配送，套餐生鲜社区统一定点配送等新型销售模式进一步规范化、系统化，促进消费市场持续回暖。三是鼓励引导居民在省内出游，创新文旅产品和服务，逐步有序恢复文化旅游市场。
