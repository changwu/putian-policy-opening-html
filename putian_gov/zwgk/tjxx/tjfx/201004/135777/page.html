一季度莆田市经济运行相关因素分析

来源:调查队 时间：2010-04-20 00:00
| | | |

今年以来，全市上下认真贯彻落实胡锦涛总书记视察福建时的重要讲话精神和中央、省、市经济工作会议精神，紧紧围绕“保八超十、全面完成十一五规划”的目标任务，大力实施“以港兴市，工业强市”的发展大略，积极应对复杂多变的宏观经济形势，坚定信心，落实责任，有效推进，经济发展持续了“回升向好”的良好势头，基本实现“开门红”。

一、一季度经济运行的相关因素特征

1、企业家信心指数和企业景气指数稳步提高

企业家信心继续增强。据企业景气监测结果显示：一季度，全市企业家信心指数为125.5，分别比上年第四季度和上年同期上升9.8和39.3点，进入“中度景气”区间运行，创金融危机以来的新高。分行业看，除建筑业和信息传输计算机服务业的企业家信心指数与上年第四季度基本持平外，其余行业企业家信心指数均有不同程度上升。特别是住宿餐饮业企业家信心指数为133.3，比上年第四季度上升61.9点，上升幅度居八大行业之首。分注册类型看，集体企业企业家信心指数为100.0，比上年第四季度上升33.3点；私营企业企业家信心指数为140.0，比上年第四季度上升20.0点；有限责任公司企业家信心指数为133.3，比上年第四季度上升17.8点。分企业规模看，大型企业企业家信心指数为143.3，比上年第四季度上升20.1点；中小型企业企业家信心指数为125.2，比上年第四季度上升22.7点。

企业景气指数稳步上升。据企业景气监测结果显示：一季度，全市企业经营状况总体持续向好，景气指数为120.7，分别比上年第四季度和上年同期上升0.4和28.1点。分企业类型看，工业企业景气指数为111.2，虽受春节放假停工季节性因素影响，比上年第四季度回落8.3个百分点，但比上年同期上升26.9点；建筑业企业景气指数为126.7，分别比上年第四季度和上年同期上升13.3和26.7点；交通运输、仓储及邮政业景气指数为125.0，分别比上年第四季度和上年同期上升12.5和25.0点；房地产业景气指数为127.3，比上年同期上升27.3点；住宿餐饮业景气指数为150.0，分别比上年第四季度和上年同期上升71.4和50.0点。

2、规模以下工业增势平稳。据调查资料显示：一季度，全市规模以下工业总产值18.47亿元，按可比价计算比上年同期增长6.0%，增幅位居全省九设区市第2位。一是设备利用率提高。据调查资料显示：一季度，目录企业平均设备利用率为72%，比上年同期提高0.2个百分点。二是生产能耗降低。据调查资料显示：一季度，目录企业每万元产值用电量240.7度，比上年同期下降4.9%；个体工业经营户每万元产值用电量121.7度，比上年同期下降2.7%。三是规模工业拉动作用明显。据调查资料显示：一季度，莆田市从事工艺品制造、纺织鞋服加工、纺织业的个体工业户创造产值分别增长速度分别为19.4%、7.1%、33.2%，实现规模以下工业产值贡献率分别为18.8%、16.7%、11.4%。

3、农户固定资产投资开局良好。据调查资料显示：一季度，全市农户固定资产投资完成额为37811万元，比上年同期增长26.5%，增幅位居全省九设区市第1位。一是设备工器具购置继续增加。一季度，全市农户设备工器具购置投资5555万元，比上年同期增长8.3%，其中投资文化、体育和娱乐业的设备1434万元，占设备工器具购置总投资的25.8%。二是第三产业成为农户投资的主要方向。一季度，全市农户用于第一产业方面投资2422万元，比上年同期增长35.4%；用于第二产业方面投资223万元，增长20.8%；用于第三产业方面投资35014万元，增长25.6%。农户投向一、二、三产业的投资比例为6.4：1.0：92.6，第三产业成为农户投资的重点领域。

4、城乡居民收入持续增加。据调查资料显示：一季度，全市城镇居民人均可支配收入5703元，比上年同期增长3.7%；农村居民人均现金收入2495元，比上年同期增长7.7%。从城镇居民收入来源渠道看：一季度，全市城镇居民人均工资性收入4132元，比上年同期增长1.0%；人均转移性收入824元，比上年同期增长9.5%；人均财产性收入822元，比上年同期增长19.4%；人均经营净收入414元，比上年同期下降2.4%，降幅比上年同期缩小7.3个百分点，表明金融危机对居民经营活动的负面影响正在逐步减弱。从农民收入来源渠道看：一季度，全市农民人均工资性现金收入为1033元，比上年同期增长13.5%；人均家庭经营现金收入866元，比上年同期增长1.8%；人均财产性现金收入70元，比上年同期增长9.8％；人均转移性现金收入为526元，比上年同期增长7%。

5、限额以下消费品市场持续活跃。据调查资料显示：一季度，全市限下商业实现消费品零售额54.61亿元，比上年同期增长11.8%。主要表现在：一是批发零售业仍发挥主导作用。一季度，限额以下批发零售业实现零售额47.66亿元，比上年同期增长11.4%，占全市限下商业消费品零售总额的87.3%，成为推动全市限额以下消费品市场繁荣活跃的主导力量。二是餐饮业增幅居各行业之首。一季度，全市限额以下餐饮业实现零售额6.7亿元，比上年同期增长15.0%，高出全市限额以下消费品零售总额增幅3.2个百分点。三是消费结构升级加快。随着城乡居民收入增加和文化素养提升，人们的消费观念逐步转变，新型、时尚、文化、旅游消费逐渐引领市场潮流，消费档次不断提高，以食品、服装、金银珠宝、文化用品等为代表的吃、穿、用商品全面热销。

6、市场价格总水平有涨有稳

居民消费价格总水平涨幅变动平稳。据调查资料显示：一季度，莆田市居民消费价格总水平比上年同期上涨4.0%，其中1月份同比上涨3.9%、2月份同比上涨4.3%、3月份同比上涨3.9%。从地域看，城市上涨4.2%、农村上涨3.0%。从调查的八大类居民消费价格变动情况看，食品类价格上涨7.7%、衣着类价格上涨6.3%、居住类价格上涨5.5%、医疗保健和个人用品类价格上涨1.1%、烟酒及用品类价格上涨0.8%、家庭设备用品及维修服务类价格上涨0.5%、交通和通信类价格上涨0.4%，娱乐教育文化用品及服务类价格下降1.4%。

农产品生产价格总水平上涨明显。据调查资料显示：一季度，全市农产品生产价格比上年同期上涨13.1%，其中农业产品生产价格上涨29.6%、林业产品生产价格下降1.0%、畜牧业产品生产价格下降6.8%、渔业产品生产价格上涨17.5%。

农资价格总水平相对平稳。据调查资料显示：一季度，莆田市农资价格总水平与上年同期持平，其中农用机油类价格上涨12.8%、饲料类价格上涨8.4%、农用手工工具类价格上涨3.6%、农业生产服务类价格上涨2.8%、产品畜类价格上涨2.1、其它农业生产资料价格上涨0.9%；化肥类价格下降7.8%、农药及农药器械类价格下降3.1%。

工业品出厂价格总水平小幅上涨。据调查资料显示：一季度，莆田市工业品出厂价格比上年同期上涨1.3%。从轻重工业品价格变动情况看，一季度重工业产品价格比上年同期上涨2.0%；轻工业产品价格比上年同期上涨0.4%；从主要行业大类产品价格变动看，工艺品及其他制造产品、塑料制品、农副食品加工产品、黑色金属冶炼及压延加工产品、纺织产品价格分别比上年同期上涨9.8%、5.9%、4.9%、3.3%、2.4%。

二、当前经济运行值得注意的几个因素

1、农户种粮意向下降。据农户农作物种植意向调查资料显示：2010年，莆田市农户户均耕地面积1.89亩，预计全年农户户均农作物播种面积3.88亩，将比上年下降0.3%，其中户均粮食播种面积2.51亩，将比上年下降2.3％；粮食播种面积与非粮食播种面积结构比例将由上年的66.2：33.8调整为64.8：35.2，粮食种植意向将呈下降趋势。

2、中小企业融资难问题突出。据调查资料显示：一季度，企业流动资金和企业融资景气指数分别为105.4和96.8，分别比上年第四季度下降3.8和2.4点。大多数中小企业缺乏有效抵押资产，信誉度不高，贷款门槛高，手续繁、时间慢，融资瓶颈难以突破，制约中小企业发展。如福建仙游强龙木工艺品有限公司缺口资金约300万元，难于按期扩建展厅；福建省康辉食品有限公司拟在仙游县赖店镇新建一条饮料生产线，但由于融资难，难于按期投产。

3、影响农民增收的不利因素依然存在。一方面，生猪价格持续低迷影响农民增收。据调查，一季度生猪平均生产价格仅为12.13元/公斤，比上年同期下降14.2%，特别是春节过后，生猪价格已跌破10元/公斤。当前，生猪养殖没有利润空间，极大地影响养殖户的积极性。另一方面，蘑菇有价无量影响农民收入。据调查，一季度蘑菇的平均价格达6.7元/公斤，比上年同期上涨72.0%。但是，受连续两年蘑菇价格持续低迷的影响，菇农的积极性受到严重打击，蘑菇种植规模大幅度萎缩，影响农民的收入。

三、几点建议

1、多渠道调动农民种粮积极性。一是抓住春耕生产有利时机，着力抓好粮食等主导农产品种植计划的落实，确保粮食面积稳定、单产提高、总产增长。二是继续抓好种养结构调整，大力发展特色产业。三是加强市场、技术信息指导，引导农民生产适销对路、价格看好的农产品，积极发展“订单农业”，进一步拓宽农产品销售市场。四是抓好农业生产资料的调剂、调运和供应，特别要搞好优质专用良种的供应。五是从源头上加强农业生产资料价格的监管，严厉打击出售假冒伪劣生产资料的行为，严防坑农害农事件的发生，保障春耕生产顺利进行。六是完善支农惠农政策，加大对生猪、奶牛、油料扶持力度，适度提高粮食收购价格。七是加强农村基础建设，加大农村水、电、路、沼气等基础设施投入力度，继续推进村容村貌整治。八是加大信贷支农力度，放宽农业小额贷款审批条件，减化贷款手续，保证农民生产急需资金。

2、创新思路解决中小企业融资难题。一是加大政府主导的银企对接力度，完善政、银、企三方合作互动平台，把信誉好、产品市场好、企业家诚信度高的企业推介给金融机构，以解决银企信息不对称造成的企业融资难题。二是加强政府搭建金融支持的融资担保等平台建设。三是充分利用莆田市作为全省贯彻国家宽松货币政策和金融支持中小企业发展的两个试点城市优势，积极发展地方银行和小额贷款公司等地方性金融机构，发挥地方性金融机构机制灵活、操作简便的优势，为中小企业提供及时有效的金融服务。四是积极引进创投、风投机制，支持、培育成长型中小企业在创业板上市。五是引入商业保险机制，破解中小企业融资难题，鼓励保险机构积极为中小企业办理服务的保险产品，对为我市中小工业提供履约保证保险的保险公司，参照担保公司的政策予以风险补偿。

3、保持合理的农产品价格，保护农民切身利益。合理的农产品价格，将有效调动农民生产经营的积极性。一方面，过低的农产品价格，会影响农民的收入，带来增收的困难；另一方面，过高的产品价格将给居民生活消费带来影响。因此，要客观把握农产品价格走势，降低生产成本，合理控制产品价格涨跌，保护农民切身利益。
