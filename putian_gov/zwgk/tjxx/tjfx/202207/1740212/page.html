1-5月全市规模以上服务业总体平稳 后劲不足亟需关注

第三十五期
第三十五期
来源:市统计局 时间：2022-07-07 15:21
| | | |

1-5月，全市规模以上服务业总体恢复向好，但发展层次不高、企业规模偏小、部分重点行业拉动力减弱、后劲不足等问题需引起重点关注。全市规模以上服务业营业收入131.03亿元，下降1.8%，降幅分别比1-4月和1-2月收窄4.1和9.0个百分点，从两年平均增速看，年均增长9.1%。

一、总体情况

（一）信息传输、软件和信息技术服务业增速明显回升。1-5月，全市规模以上信息传输、软件和信息技术服务业实现营业收入20.37亿元，增长17.4%，增幅比1-2月提高11.9个百分点，主要受电信、广播电视和卫星传输服务快速增长拉动，营业收入增长24.6%，增幅比1-2月提高16.4个百分点，高于全省平均水平16.3个百分点。主要原因是豆讯科技、聚合网络增值电信业务量增加。

（二）居民服务业增势强劲。1-5月，全市规模以上居民服务、修理和其他服务业实现营业收入2.74亿元，增长37.5%，增幅比1-2月提高20.4个百分点，高于全省平均水平17.4个百分点，对全市其他营利性服务业营业收入增长的贡献率为20.1%，拉动其他营利性服务业营业收入增长2.3个百分点。

（三）文化体育娱乐业恢复性快速增长。文化体育娱乐业受疫情影响逐渐减弱，增速逐月回升，呈恢复性较快增长态势。1-5月，全市规模以上文化、体育和娱乐业营业收入增长27.1%，增速分别比1-2月、1-3月和1-4月提高个8.7、18.8和12.1百分点，高于全省平均水平29.0个百分点。

（四）交通运输、仓储和邮政业降幅逐月收窄。1-5月，全市规模以上交通运输、仓储和邮政业营业收入74.0亿元，下降7.9%，降幅分别比1-4月、1-3月和1-2月收窄 6.7、11.0和12.4个百分点。主要原因是仙游物泊、胜北物流等新增企业业务量快速增长拉动，道路运输业营业收入降幅收窄，较1-2月收窄15.0个百分点。

（五）新增企业支撑作用显著。全市规模以上其他营利性服务业增长主要靠新增企业拉动，2021年5月以来新入库的31家其他营利性服务业企业实现营业收入4.33亿元，对其他营利性服务业营业收入增长的贡献率为45.0%，拉动其他营利性服务业营业收入增长5.3个百分点。

二、存在问题

1-5月，全市规模以上其他营利性服务业实现营业收入35.62亿元，增长11.7%，增幅虽小幅回升，但比1-2月回落5.6个百分点，低于全省平均水平12.4个百分点。

（一）租赁和商务服务业支撑力不足。1-5月，占规模以上其他营利性服务业的比重达72.1%的租赁和商务服务业增速回落明显，增长10.9%，增速比1-2月回落7.4个百分点，低于全省平均水平14.0个百分点，拉低其他营利性服务业营业收入增速5.2个百分点，主要受商务服务业增速明显回落影响。商务服务业营业收入增长12.0%，增速比1-2月回落8.1个百分点，主要原因是负增长企业增加和退库企业影响加大，其中瑞智无忧、仙游弹好工、特洛特人力资源等28家负增长企业拉低该行业营业收入增速10.5个百分点,忠门正泰、大爱妈祖等13家退库企业拉低该行业营业收入增速9.0个百分点。

（二）数字经济核心产业降幅扩大。我市数字经济相关服务行业基础仍较薄弱，发展层次不高，增长乏力。1-5月，全市规模以上互联网和相关服务业、软件和信息技术服务业户均规模仅998万元，营业收入下降13.4%，降幅较1-2月扩大5.7个百分点，低于全省平均水平45.1个百分点，主要原因：一是退库企业影响突出，找银网、也买银、中房购等8家退库企业共拉低该行业营业收入增速27.8个百分点；二是缺乏新增大企业拉动，全市新增入库企业仅5家，且规模均较小。

（三）发展后劲不足。入库企业少，退库企业多，退库企业对全市其他营利性服务业增速影响较大。2021年2月以来，全市新入库其他营利性服务业企业仅33家，退库企业达101家，其中64家退库带基数企业拉低全市其他营利性服务业营业收入增速13.7个百分点。截止目前，全市无月度新增企业。

（四）其他交通运输业增长乏力。全市规模以上其他交通运输业单位数少、规模小、后劲不足，增长乏力。1-5月，全市该重点行业实现营业收入5.73亿元，增长3.2%，增速虽比1-4月提高2.0个百分点，但比1-2月回落9.7个百分点，低于全省平均水平21.8个百分点，主要原因是国投湄洲湾港口、八方物流和顺丰速运等重点企业增长乏力。其中，多式联运和运输代理业营业收入增长6.4%，增幅比1-2月回落26.6个百分点。

三、对策建议

（一）加快产业数字化转型。以数字化服务引领服务业经济创新发展是优化服务业结构、提升服务业效益、增强服务业实力，推动服务业经济高质量发展的重要抓手。激发“互联网+”助推服务业倍增效应，积极探索运用互联网资源，鼓励发展互联网医院、数字图书馆、数字博物馆、互联网+物流等产业，推进大数据、云计算、人工智能、物联网等新一代信息技术产业在社会服务领域的应用，培育社会服务平台，通过各类平台有效链接社会服务主体，推动医养结合、文教结合、文旅融合，加快推进传统物流行业转型升级，全面发展养老服务和医疗服务业。

（二）做强文化品牌和文旅融合经济。一是强化品牌效应。一手抓妈祖文化特色，打造妈祖文化传承创新区，讲好妈祖故事；一手抓文化底蕴、农业特色、生态优势、康养资源，打造文旅农康融合发展试验区。二是强化全域旅游。促进全域旅游资源一体化谋划包装推进，打好文化底牌，做强旅游景区，保护名城名镇名村，举办一批重大节会活动，打造一批示范性研学基地、旅游基地，培育旅游新增长点。三是强化产业主体。引进培育综合性文旅企业集团，培育文旅新产品新业态。四是强化基础建设。加快景区基础设施建设，完善“景区管委会+旅游开发公司”运营机制，提高从业人员服务质量。

（三）凝聚合力培育新增长点。市直各行业相关主管部门要积极主动作为，加大服务业招商引资力度，针对性培育新增长点，尤其是单位数较少、存在空白行业的县区和相关行业主管部门要加强企业培育，提升发展后劲。城厢、秀屿、北岸退库企业多、入库企业少，缺乏大企业支撑，需引起重点关注，加大力度积极培育新增长点，确保其他营利性服务业持续健康发展。同时进一步加大“小升规”企业培育服务力度，通过与工商、税务企业库的比对、摸排，多渠道建立“准规企业库”，在财政资金、税费政策、金融等方面予以重点扶持，助力小微企业成长，全面提高企业转规积极性。

 

签发：黄光华
