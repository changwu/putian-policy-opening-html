莆田市电商发展现状分析

第八十七期
来源：本网 时间：2015-12-29 16:18
| | | |

根据阿里研究院今年5月份发布的《2014年中国电子商务示范城市发展指数报告》，莆田市发展指数为14.661，位居全国第13位。在福建省内仅次于厦门(第6位，指数为15.854)。网商指数为9.365，位居全国第19位；网购指数为19.958，位居全国第7位。这些数据都说明，电子商务将成为莆田未来经济发展的一大助力。

莆田市是重要的运动鞋生产基地，莆田的工艺美术城是中国最大的工艺品专业交易市场。这里拥有健全的生产配套设施、大量的设计人才、电商运营人才，这里还是知名的跨境电商卖家聚集中心，全市拥有20万以上网商从业者，超过100家快递服务商在这里设点。分析我市当前电商整体的发展状况，引导发挥莆田在供应链、运营等方面的优势，借助电子商务在莆田市的发展推动莆田经济腾飞是一个重要课题。

一、莆田电商发展状况

目前，我市电子商务主要依托鞋革服装、工艺美术等特色行业，历经起步之初，从以学生街、个体网店为主的自发发展阶段，到2009年—2011年扩大规模为主的规范发展阶段，再到现在鼓励自创品牌、打造自主平台为主的转型升级阶段，已步入快速增长期，正由电商强市向电商名城逐步迈进。

“店铺很小、仓库很大、网络很畅、销售很远、附加值很高”。这是对莆田电商形象的描述。作为国内电子商务起步最早的城市之一，莆田这个“鞋都”依靠本土的产业优势，开疆拓土，打造出属于自己的电商天地。

目前，以安福电商商务城为代表的莆田电子商务产业发展态势良好，安福电商商务城总规划用地面积约1500亩，核心区已入驻莆田各自主品牌商户335家，经营国内外品牌500多个，行业涵盖鞋革、服装、箱包、油画、银饰、红木小件等。

据不完全统计，今年11月11日当天莆田市网络销售额达11.3亿元，比增24.2%，“双十一”首次突破10亿元。全市包裹收件量55.67万件（不含大宗物流），比增18.6%，投递量16.37万件，比增23.54%。

物流方面，全市现有注册快递企业35家，备案的分支机构50家，已登记备案末端网点132个，从业人员3500人。经营的快递品牌有28个，主要企业包括市邮政速递物流有限公司（EMS）、顺丰、申通、圆通、中通、汇通、韵达、宅急送、天天、全一、速尔、DHL（中外敦豪）、UPS（鼎佳国际货运）等。目前，我市快递行业呈现出国有、民营、外资竞争发展态势，行业机械化、信息化水平大幅提升，与网络零售协同效应更加突出。

2014年，莆田市邮政企业和规模以上快递服务企业业务总量累计完成18.14亿元,在全省排名第4位；业务收入累计完成11.28亿元，在全省排名第4位。其中，莆田市规模以上快递服务企业业务量累计完成6531.42万件，全国排名第41位；快递业务收入累计完成8.25亿元，全国排名第40位。

同时，在政府层面，莆田市采取了多种措施，鼓励和促进电子商务的发展。加快安福电子商务城基地建设；建设莆田网商创业园，为电商提供集仓储、培训、融资等为一体的综合性服务平台；利用黄石区位优势，打造网贸仓储物流园。会同省鞋业出口基地商会创建莆田鞋类国家示范基地电子商务资讯平台汇鞋网，为企业提供电商指导、进出口代理、企业信息化等服务。举办电商发展研讨会、电商自主品牌展销会、政银企对接研讨会等，推介优秀自主品牌。引导本地传统线下著名品牌、各类驰名商标企业与本土电商运营商对接，参与线上电子商务。

二、莆田电商现状分析

1、中国质造推动发展，让有条件的企业先富起来。3月29日当天，在淘宝和聚划算上，莆田市市长翁玉耀亲自为“中国质造·莆田好鞋”代言，并表示，“要用超越国际的标准做出中国好鞋。”据淘宝官方统计，短短4天时间有超过1000万人通过淘宝、聚划算等多个渠道关注到莆田好鞋。淘宝巨大的流量效应盘活了莆田鞋业，推动力一批高质量、高标准的自主品牌快速成长。

以思威琪为例，思威琪原本只是福建莆田一个不知名的运动鞋品牌。在2015年3月29日这天，老板喜出望外，他们家的一款轻量跑鞋在网店上线不到两天，就立马销出去了2万双。除了销量上的增加，变化最明显的还是有更多的分销商找上门来，分销渠道由于有淘宝的引导变得“互联网化”。据老板介绍，亮相“中国质造”后，日产提升近50%，半个月内，思威琪的分销商从原先100家发展到400多家。

同期上线淘宝“中国质造”频道的共有17家莆田本地品牌，总计17万双莆田鞋。借助“中国质造”的热度，4天就销售一空，是所有品牌过去4年所有线上销量总和。这个漂亮的销售数字是淘宝“中国质造”项目首日在莆田试点的战绩。

2、竞争力度加剧，自主品牌获得成功。经营自主品牌的一些企业在中国质造的帮助下，提升了竞争力，在销售额上实现了突破。

以2015年双十一为例，对比往年，出现“三升两降”：一是鞋类品牌独占鳌头。我市自主品牌AU&MU、古奇天伦、莫蕾蔻蕾、盾狐、莱卡金顿等5家销售额超千万，中国质造中玩觅、沃特等品牌挤入运动户外类目前100名；二是传统产业电商销售增长快速。华昌珠宝入驻淘宝嘉年华主会场，银饰产业销售额也比平时增长1至2倍。铭天下、大德等红木家具电商当日销售同比增长超一倍，红木产业电商销售额超2000万元。油画产业触网，天顶山等油画电商销售额超1000万元。方家铺子、闽中等农副产品电商销售额超千万；三是移动端成为主要流量入口，移动支付比例超过60%，市商务局提前布局移动端，古奇天伦、莫蕾蔻蕾等品牌移动端流量占比80%以上；四是阿里游戏规则变化，影响我市电商交易额。古奇天伦、莫蕾蔻蕾虽然销售额超千万，但女鞋类目排名有所下滑；五是鞋类电商利润下降。我市思威琪、沃特等鞋企，前期存货量大，以低价清现货为主。

3、部分小微电商企业处境艰难，产品劣质低价。我市电子商务企业基本上以小微企业为主，更多的仍以个人店为主要模式在淘宝、百度等第三方电子商务平台上从事网上产品销售。根据正统网数据，我市目前入驻电商企业400余家，电子商务销售金额千万以上仅占三分之一。400余家入驻企业从业人员合计约1.6万人，仅占20万电商从业大军的8%。另外，我市有大量的电商个体户，从业人员参差不齐，再加上大部分中小企业主们普遍缺少品牌意识，于是，低门槛、易复制、同质化等这些存在已久的问题在网销行业越发严重。同时，在淘宝网上，莆田和“高仿”、“假货”等字眼有紧密联系。据不完全统计，仅在2014年，淘宝查封的莆田卖家账号就超过12万个，其中屡次售假的卖家达到3.2万个。产品的仿冒瑕疵，消费者的不信任，共同导致了部分小微电商企业及电商个体户的困难处境。正如此次淘宝上线的“中国质造”，其中的“质”并非错别字，而是意在改变部分产品乃至中国传统制造业总是劣质低价的尴尬局面。

4、电子商务支撑体系不够完善。目前，虽然我市有着一些自主品牌电商企业发展势头良好，但是，缺少集采购、仓储、配送、客服、培训、融资、技术支撑为一体的综合性有核心竞争力的大规模企业，缺少现代仓储现代物流配送基地、专业的电商销售系统软件、懂得操盘的高级技术人才与管理人才。在网络基础设施、支付体系、投融资服务体系、物流配送、政企对接等方面，我市也都未能突出显著优势。同时，我市在电子商务平台设计、网站美化优化、产品营销策划等方面，面临着第三方专业企业数量少、创新不足的困境，难以提升我市电子商务行业的整体档次。可以说整体上我市电子商务的应用广度和深度仍有提高空间。

三、意见与建议

1.规划发展，为莆田电商企业提供发展优势。坚持规划建设集电商运营分销、数据处理、指数发布、展示会展、交易结算等功能配套于一体的电商总部区； 建立智能化电商配套仓储中心，实现订单管理、仓储管理、配送管理、金融服务等一体化服务，多方面降低电商物流成本，提高配送时效，增强竞争力。以“一带一路”、“福建自贸区”两个热点话题为契机，推动闽台电商合作，增加跨境电商发展机会，带动跨境电商升级转型；完善产业链，发展新型电子支付业务，引进国内先进的第三方支付平台，建设网上交易结算中心；应积极鼓励传统型鞋服企业与安福电商城对接，组织走访活动和对接会，交流信息，互利发展。

2. 创建品牌，走品牌之路。继续深化与阿里巴巴的紧密合作，引导当地的产能转变为生产原创品牌，以质取胜，走健康的道路，走品牌的道路。在安福电商城为广大电商搭建产品展示和销售的平台，在进一步提高安福品牌的品牌知名度的同时，为我市电商企业发展提供宣传便利。围绕安福，定期举办安福品牌特卖会、宣传会、对接会等，打造“安福盛会”，集聚电商企业规模化发展。

对于莆田电商的发展，阿里巴巴淘宝行业事业部品牌保护与创新资深总监倪良在接受采访时说道：“品牌之路是莆田电商发展之路”。培育出一批原创的民族品牌，让他们有尊严地生产经营，才是最佳选择。

3. 培育人才，引进人才。政府应该主导建立电子商务人才培养机制，结合社会各方力量，进行各层次人才培养，为产业提供源源不断的电子商务技术、管理人才。可以根据企业用人需求，鼓励高校，定向培养企业需要的实用型人才；充分发挥当地高校与咨询公司的力量，与大中型企业合作，培养高层次的技术和管理人才；利用政府所属的人才培训机构，培养中层技术和管理人才；利用政府劳动力培训机构，以及民间职业培训机构，进行操作型人才培训；鼓励企业办学，鼓励企业内部人才培训，对企业内部人才培训给予资金扶持；对引进的或经过培训的人才的安居乐业，提供优惠条件。

4. 完善法律法规，鼓励电商发展的同时加强监管。市政府积极出台相应的地方性法规，对电子商务人才培养与引进、电子商务科研项目立项及推广，进行政策倾斜与资金扶持；对电子商务企业设立、电子商务投资开通绿色通道；对电子商务企业提供税费方面的优惠以及融资的便利，积极引导、鼓励当地的产能转变为生产原创品牌；完善电子商务统计制度，为政府决策提供数据支持；各部门在对电子商务企业提供一站式优质服务的同时加强监管，共同推动莆田电商整个产业的升级完善。
