经济运行总体平缓 下行压力继续加大——1-9月我市经济运行情况分析

第六十八期
第六十八期
来源：本网 时间：2019-10-21 08:40
| | | |

今年以来，外部环境更趋严峻复杂，国内经济下行压力加大，全市上下坚持稳中求进工作总基调，千方百计稳增长,全市经济运行呈总体平稳、稳中趋缓态势。1-9月，全市GDP完成1744.85亿元，可比增长7.6%，增幅分别比上年同期、1-6月回落0.1个和0.5个百分点。

一、经济运行主要特点

（一）农业生产基本稳定，特色农业增长较快。1-9月，我市农林牧渔业总产值农林牧渔业总产值152.22亿元，可比增长3.1%，增幅虽比上半年回落0.7个百分点，但仍保持在3%以上。主要亮点：一是园林水果生产形势良好。全市园林水果产量10.58万吨，增长3.2%，其中枇杷产量6.04万吨，增长3.4%。二是家禽养殖业快速发展。针对非洲猪瘟疫情，我市积极引导转产转业，家禽养殖业快速发展。全市家禽出栏2547.86万只，增长29.1%；存栏738.71万只，增长11.0%；禽肉产量3.39万吨，增长28.2%。三是海洋渔业生产有序推进。全市海水产品产量77.19万吨，增长5.2%。其中，牡蛎产量31.18万吨，增长6.0%，对全市水产品总产量的贡献率高达45.7%；江篱产量10.54万吨，增长19.6%，对全市水产品总产量的贡献率高达44.9%。

（二）工业经济稳中有升，重点产业贡献突出。1-9月，全市规模以上工业增加值可比增长8.6%，增幅比1-6月提高0.2个百分点。主要亮点：一是民营经济贡献突出。占全市规上工业增加值总量81.1%的民营企业实现工业增加值可比增长7.0%，对规模以上工业增加值增长的贡献率为69.3%，拉动规模以上工业增加值增长6.0个百分点。二是化工新材料等重点产业拉动有力。全市规模以上化工新材料、食品加工产业、电子信息、高端装备四大产业分别拉动全市规模以上工业增加值增长2.1个、1.2个、1.0个和0.9个百分点。三是工业生产后劲增强。19家去年以来新投产企业对规模以上工业增加值增长的贡献率为20.7%，拉动规模以上工业增加值增长1.8个百分点。四是“三新”工业经济快速增长。其中，战略性新兴产业工业增加值可比增长10.1%，高技术企业增长11.8%，装备制造业增长14.3%。

（三）建筑业较快增长,龙头企业生产良好。1-9月，全市建筑业增加值169.98亿元，同比增长6.7%。资质以上建筑企业实现总产值562.52亿元，增长14.6%，增幅比上年同期提高8.6个百分点；产值超10亿元建筑企业有15家，共完成建筑产值353.46亿元，同比增长20.0%，拉动全市资质以上建筑企业总产值增长12.0个百分点。

（四）商品房销售良好，库存减少。1-9月，全市商品房销售面积331.98万平方米，比上年同期增长11.4%，增幅分别比上年同期、1-6月提高15.2个和11.2个百分点。其中建工ECO、碧桂园天成、香港财富中心悦城三个项目开盘销售良好，共拉动全市商品房销售面积增长3.3个百分点。9月末，全市商品房待售面积147.02万平方米，下降10.9%。

（五）消费市场稳步增长，结构优化升级。1-9月，全市社会消费品零售总额同比增长10.0%，增幅虽比1-6月回落0.3个百分点，但比1-8月回升0.3个百分点。主要亮点：一是消费结构不断优化升级。全市部分升级类商品消费增势强劲，其中可穿戴智能设备零售额增长154.1%，新能源汽车增长73.0%，智能家用电器和音像器材增长45.9%，电子出版物及音像制品类增长37.9%。二是新兴零售快速增长。全市限上批发零售业网上商品零售额增长15.3%，增幅快于全市社会消费品零售总额5.3个百分点。三是餐饮收入回升明显。全市限上餐饮收入增长12.6%，增幅比上年同期高7.5个百分点。

（六）投资增幅仍居全省前列，亿元项目高速增长。1-9月，全市固定资产投资同比增长9.7%，增幅虽比1-6月回落0.9个百分点，但仍居全省第二位。主要亮点：一是在建亿元项目高速增长。全市235个在建亿元项目完成投资增长50.3%，增幅分别比上年同期、全市固定资产投资高61.2个和40.6个百分点，其中，102个本年新开工亿元项目完成投资同比增长112.7%。二是房地产投资拉动明显。全市房地产业投资同比增长29.8%，增幅比上年同期高35.0个百分点，对全市固定资产投资增长的贡献率为58.2%，拉动全市固定资产投资增长5.6个百分点。三是工业投资增速提升。全市工业投资同比增长9.6%，增幅比上年同期高8.4个百分点，占全市固定资产投资的比重为28.8%，对全市固定资产投资增长的贡献率为28.5%，拉动全市固定资产投资增长2.8个百分点。 

（七）消费价格温和上涨，城乡居民稳步增收。1-9月，全市市辖区居民消费价格比上年同期上涨1.9%，涨幅比全省平均水平低0.3个百分点。其中，食品烟酒价格上涨4.1%，衣着上涨1.1%，居住上涨0.4%，生活用品及服务上涨1.7%，交通和通信下降0.7%，教育文化和娱乐上涨2.6%，医疗保健上涨1.3%，其他用品和服务上涨2.6%。全市城镇居民人均可支配收入31233元，同比增长7.6%；农村居民人均可支配收入15543元，增长9.3%，增幅快于城镇居民人均可支配收入1.7个百分点。

二、经济运行存在问题

（一）一产增加值增幅位次后移。1-9月，全市第一产业增加值82.73亿元，可比增长2.9%，增幅分别比上年同期、1-6月均回落0.8个百分点，居全省第7位，分别比上年同期、1-6月后移3位和5位。与上半年比，拉低全市GDP增长0.06个百分点。主要原因：一是受非洲猪瘟影响，生猪养殖呈断崖式下降。1-9月，全市生猪出栏45.22万头，同比下降27.1%；存栏13.69万头，下降65.6%；猪肉产量3.58万吨，下降27.4%。二是由于种粮比较效益偏低，农民种粮积极性不高，早稻产量同比下降5.5%。

（二）工业生产持续增长压力较大。一是工业发展后劲不足。截止9月底，全市仅有2家新投产企业。二是中美贸易摩擦因素影响后期逐步显现。制鞋业关税的加征，直接影响制鞋企业的订单量，据企业主反映存在后期订单不敢接，对鞋业加征关税直接挤压企业利润，导致企业亏损。三是重点企业贡献不足。HTD、云度新能源企业增长乏力。四是工业用电量增长依然低迷。1-9月，全市工业用电量同比下降5.4%，降幅比1-8月扩大0.1个百分点，居全省第八位。其中，制造业用电量下降2.4%。

（三）规模以上其他营利性服务业营业收入增速下滑明显。1-9月，全市规模以上其他营利性服务业营业收入（错月）同比增长5.6%，增幅分别比上年同期、1-6月回落22.3个和19.2个百分点。与上半年比，分别影响全市GDP、第三产业增加值增长0.4个和1.1个百分点。主要受豆讯科技与秀屿区医疗咨询行业影响，共拉低全市规模以上其他营利性服务业营业收入增长16.7个百分点。

（四）投资稳增长基础不牢固。一是在库项目储备不足。截止9月底，全市在库项目1600个，同比减少500个，其中500-5000万元在库项目1300个，同比减少550个。二是民间投资回落明显。1-9月，全市民间投资同比仅增6.8%，增幅分别比1-6月、上年同期回落0.8、27.1个百分点，其中项目民间投资增速同比回落48.7个百分点，工业民间投资增速回落11.1个百分点。 

三、下阶段经济健康运行对策建议

（一）抓产业促进实体经济发展。围绕供给侧结构性改革，大力抓好产业经济，全面提升高质量发展水平。一是稳定农业压舱石。进一步落实种粮奖补政策，积极做好粮食生产技术指导，确保全年粮食增产增收；严控非洲猪瘟等重大动物疾病，进一步加强生猪生产和市场监测，从供需两端推动生猪市场健康发展。二是全力以赴稳工业。对停产减产企业实施“一企一策”、“一对一”帮扶，把停产减产面降下来，把工业增加值提上去；持续推动传统制造业新旧动能转换，提升工业设计能力和相关产业价值链。三是大力发展现代服务业。落实好加快服务业发展政策措施，在服务贸易、设计咨询、电子商务、新兴消费等领域培育发展一批特色集聚区和产业集群，保持服务业对经济增长的拉动作用。

（二）抓项目扩大有效投资规模。紧扣项目建设年目标，继续加大招商引资力度，实现新的增量。一是做好重大项目的引进工作。加强与国家部委沟通衔接，瞄准中央各类资金支持重点和方向，加强重大项目规划、储备、实施，加快培育创新型、引领型、效益型投资新增长点。二是加大在建项目的建设力度。做好项目建设服务保障工作，及时帮助解决项目建设过程中遇到的困难和问题，提高招商引资项目的落地率和开工率。三是加强项目投融资对接。进一步放宽市场准入，鼓励民间资本、外商资本参与国有企业改革，加快混合所有制经济推进步伐。积极引进多元投资主体，引导支持银行、保险、基金等社会资本向重大产业项目聚焦。

（三）抓服务有效应对贸易摩擦。按照中央应对中美贸易摩擦的统一部署，全面把握国家关于“中美贸易摩擦总体可控”的判断，做好贸易摩擦常态化准备，精准服务企业，提升发展信心，积极应对，化危为机。一是密切关注事态发展。强化对美贸易往来重点行业和企业的运行监测，通过实地调研，点对点、面对面深入了解企业受影响情况和企业诉求，及时分析研判中美贸易摩擦对全市经济带来的影响，分类精准制定措施。二是指导企业有效应对。加强与重点企业互动，有针对性地组织企业参加各种经贸活动和境外展会，引导企业开展产品注册认证和国际认证咨询，增强产品国际竞争力，支持企业拓展非美销售渠道。
