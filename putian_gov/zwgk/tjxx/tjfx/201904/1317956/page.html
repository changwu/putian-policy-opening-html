首季开局良好 经济质量提升——全市一季度经济运行分析

第十八期
第十八期
来源：本网 时间：2019-04-18 09:37
| | | |

今年以来，全市上下按照市委、市政府关于开展“聚焦项目比质量、争先进位比赶超”活动的部署要求，积极作为、精准调度，全市经济首季开局良好，经济质量不断提升。

一、经济运行开局良好

1-3月，全市实现地区生产总值630.14亿元，可比增长8.3%，增幅同比提高0.2个百分点。主要经济指标增速位居全省前列，其中：增幅居全省第二位有5个指标，分别为第一产业增加值、农林牧渔业总产值、农林牧渔业增加值、零售业商品销售额、实际利用外资；居全省第三位有2个指标，分别为第三产业增加值、金融机构本外币存款余额。

（一）一产提速增效，主要农产品较快增长。全市认真贯彻落实中央“三农”决策部署，以实施乡村振兴为主线，农业生产稳中有升。一季度，全市第一产业实现增加值25.67亿元，可比增长3.6%，增幅同比提高3.7个百分点。主要亮点：一是优质农副产品供应基地建设加快，种植结构调整迈出了实质性步伐。全市蔬菜产量15.98万吨，增长6.4％；园林水果产量0.17万吨，增长3.4%。二是外部环境总体上适宜渔业生产，水产品产量明显增加。全市水产品产量26.13万吨，增长4.9%，其中，海水产品24.98万吨，增长5.0%。三是家禽养殖规模不断扩大，禽肉市场需求量增加。全市家禽出栏838.90万羽、增长15.2%，存栏771.15万羽、增长7.0%；禽肉产量1.11万吨、增长20.6%。

（二）二产稳中有升，工业发展继续提速。1-3月，全市第二产业实现增加值330.32亿元，可比增长8.7%，增幅同比提高1.2个百分点。

1、工业发展继续提速。1-3月，全市规模以上工业增加值增长8.9%,增幅同比提高1.0个百分点。主要亮点：一是工业企业景气指数和企业家信心指数“双上升”。一季度，我市工业企业景气指数为130.8，同比提高2.7个点，继续运行在“较为景气”区间；企业家信心指数为130.7，同比增加1.7个点，景气指数和信心指数“双上升”，表明我市工业生产经营总体向好、预期乐观。二是龙头企业贡献突出。全市226家产值超亿元以上规模工业企业实现增加值同比增长15.6%，增速比全市规模以上工业平均增速高6.7个百分点，对规模以上工业经济增长的贡献率为95.0%，拉动规模以上工业增加值增长8.5个百分点。

2、建筑业增速回升明显。1-3月，全市建筑业增加值完成32.75亿元，同比增长10.0%，增幅分别比上年同期、1-2月提高5.1个和5.2个百分点，拉动全市GDP增长0.5个百分点，比1-2月提高0.3个百分点。

（三）三产增速位居全省前列, 金融业拉动力提高。1-3月，全市第三产业实现增加值274.15亿元，可比增长8.3%，增幅虽比上年同期回落2.0个百分点，但仍居全省第三位。主要特点：一是金融业拉动力提高。1-3月，全市金融业实现增加值53.82亿元，同比增长3.6%，增幅比1-2月提高2.0个百分点，拉动全市第三产业增长0.7个百分点，比1-2月提高0.4个百分点。二是规模以上其他营利性服务业贡献突出。全市规模以上其他营利性服务业企业实现营业收入（错月）同比增长27.7%，增幅高出全省平均水平4.9个百分点，对全市第三产业增长的贡献率为44.3%，拉动第三产业增长3.7个百分点。

（四）消费市场总体有序，房地产投资快速增长。1-3月，全市实现社会消费品零售总额216.58亿元，同比增长10.4%，增幅虽同比回落2.3个百分点，但比1-2月提高0.4个百分点，居全省第4位，比1-2月前移4位，消费市场总体有序。今年以来，全市房地产投资出现恢复性增长，扭转了从去年6月份开始持续下滑的局面，全市房地产开发投资完成110.93亿元，增长15.1%，增幅同比提高6.8个百分点，快于全市固定资产投资增速12.4个百分点，连续两个月增速保持10%以上。

二、高质量发展积极有效

（一）转型升级再现新成效。1-3月，全市三次产业结构由上年同期的5.1:55.8:39.1调整为4.1:52.4:43.5，服务业比重同比提高4.4个百分点，主引擎作用进一步凸显。投资结构明显优化，全市服务业投资增长12.8%，高于全市固定资产增速10.1%，占固定资产投资比重为70.9%，同比提高6.4个百分点。

（二）工业企业转型升级稳步推进。1-3月，全市战略性新兴产业增长12.7%，对规模以上工业经济增长的贡献率为17.7%，拉动规模以上工业增加值增长1.6个百分点；全市高技术产业增长20.8%，对规模以上工业经济增长的贡献率为11.5%，拉动规模以上工业增加值增长1.0个百分点；装备制造业增长19.7%，对规模以上工业经济增长的贡献率为23.2%，拉动规模以上工业增加值增长2.1个百分点。

（三）现代服务业发展壮大。1-3月，软件和信息技术服务业、互联网和相关服务业等重点行业营业收入（错月）同比分别增长3.3倍、74.0%；电商交易持续扩大，全市实物商品网上零售额40.29亿元，同比增长21.8%，对限额以上单位零售额的贡献率为52.8%，同比提高16.3个百分点；快递业蓬勃发展，全市快递业务总量增长36.6%。

（四）绿色发展成果显著。一是节能降耗成效初显。1-3月，全市规模以上工业企业综合能源消费量92.76万吨标准煤，同比增长2.6%，增幅同比回落80.9个百分点。二是绿色消费的新产品增势良好。1-3月，全市可穿戴智能设备、新能源汽车、智能手机零售额分别同比增长87.5%、46.9%和35.8%。

（五）质量效益稳步提升。1-3月，全市财政总收入66.4亿元，完成全年预算的27.2%，超序时进度2.2个百分点，增长1.5%，其中地方级财政收入42.6亿元，完成全年预算28.8%，超序时进度3.8个百分点，增长1.4%。税收收入52.2亿元，占财政总收入的比重为78.6%，同比提高1.0个百分点。

三、存在问题

（一）受非洲猪瘟影响，畜牧业产值下降。去年底因非洲猪瘟导致我市生猪养殖规模大幅下降，使本就不景气的畜牧业生产雪上加霜。一季度，我市畜牧业产值6.90亿元，同比下降0.6%。其中，生猪出栏17.61万头，下降11.5%；生猪季末存栏16.51万头，下降61.5%；生猪肉产量1.37万吨，下降13.5%。

（二）工业生产经营风险加剧，大项目产能释放受限。一是停、减产企业影响明显。3月末，全市停、减产面为27.5%，共拉低规模以上工业增加值4.3个百分点。二是大项目产能释放尚需时日。华佳彩因库存积压以及订单不足影响、云度新能源汽车因国家政策及公司决策调整、HDT太阳能电池因生产线还在调试阶段，产能未能完全发挥。三是规模以下工业增加值增速靠后。1-3月，全市规模以下工业增加值同比增长4.1%，增幅居全省九设区市末位。

（三）投资增幅回落较大，新开工项目偏少。1-3月，全市固定资产投资仅增2.7%，增速同比下滑14.7个百分点。一是新开工项目减少。截止3月末，全市新开工项目237个，同比下降49.6%。二是民间投资出现负增长。受工业民间投资下滑影响，全市民间投资由上年同期的高速增长转为下降0.5%，同比回落53.6个百分点。其中，工业民间投资增速由上年同期的增长34.7%转为下降8.9%。

（四）部分三产相关指标月度波动明显，且呈放缓之势。一是商品房销售降幅扩大。全市商品房销售面积97.26万平方米，下降1.6%，降幅比1-2月扩大0.9个百分点，居全省第六位。二是财政八项支出增速回落明显。1-3月，全市财政八项支出同比增长3.2%，增幅比1-2月回落5.9个百分点。

四、对策建议

（一）加强生产领域监测。一是农业方面重点关注非洲猪瘟对畜牧业负面影响，进一步完善政策措施，探索财政补助的有效途径，扩大牛羊家禽养殖规模，填补因非洲猪瘟造成的生猪出栏下降；同时着力改变生猪生产方式，搞好品种改良，推动我市现代畜牧业快速发展。二是工业方面要关注重点行业和重点企业的生产经营情况，加强要素保障，着力促使技术先进、产品竞争力强、有市场需求的企业加快生产，推动企业充分释放产能。同时促进传统产业技术改造升级，引导和支持中小微企业向“专精特新”发展。

（二）着力增加有效投资。一是围绕制造业高质量发展、扩大内需潜力和美丽莆田建设，引进一批投资规模大、综合效益好、带动能力强的重大项目。二是加强项目进展情况的跟踪，督促已开工且达到入库标准的项目及时申请入库。三是持续激发民间有效投资活力，落实各项产业扶持政策，加强民间项目建设要素保障，加快项目投资进度，尽快形成有效投资量。

（三）加快服务业发展。提升传统服务业品质，发展现代物流、电子商务、健康养老、家政服务、物业管理等产业，培育融资租赁、众创众筹等新业态，采取“一对一”企业扶持措施，加快培育新增限上贸易业及限上服务业企业，并积极做好新增企业申报工作，及时纳入统计范围。
