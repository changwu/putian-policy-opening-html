1-11月莆田市消费品市场运行情况简析

第七十八期
第七十八期
来源：本网 时间：2018-12-21 09:23
| | | |

前11个月，全市消费品市场运行呈回落态势，全市消费品零售额增速从1-3月的12.7%、1-10月的10.2%回落至1-11月的9.7%，增幅同比回落1.6个百分点，居九设区市第七位。其中，11月份实现社会消费品零售额65.77亿元，增长4.5%。

按消费形态分，1-11月，全市实现餐饮收入53.18亿元，增长2.3%，实现商品零售额635.45亿元，增长10.3%，两者增幅比上年同期分别回落4.2个和1.4个百分点。按限额标准分，1-11月，全市限上实现357.28亿元，增长11.3%，增幅同比回落5.5个百分点，限下实现331.34亿元，增长8.0%，增幅同比提升1.6个百分点。

一、限上消费品市场运行亮点

1、限上住宿餐饮业餐饮收入保持较快增长。11月份，住宿餐饮业实现餐饮收入增长31.3%，累计增长29.3%，增幅比上年同期高22.3个百分点。宴会、接待团体客增多等因素推动餐饮收入增速走高。

2、品质类消费品热销。1-11月，化妆品类商品零售额增长122.3%，中西药品类商品零售额增长19.7%，书报类增长54.3%，通讯器材类增长47.7%。

    3、17年度以来入库企业贡献率过半。1-11月，全市17年度以来新增批零企业实现零售额37.55亿元，增长94.8%，拉动限上消费品零售额增长5.7个百分点，对限上消费品零售额增长的贡献率为50.5%，贡献率同比提升6.3个百分点。

二、消费品市场应关注的问题

   （一）限上消费品零售额增速回落

    从9月份起，连续3个月限上消费品零售额微增长或下降，9月份增长1.8%，10月份下降5.9%，11月份下降1.7%，受三个月拖累，1-11月，全市限上消费品零售额增长11.3%，创今年限上消费品零售额最低增幅。

    1、限上破产（注、吊销）、停产企业影响。11月末，全市破产（注、吊销）、停产企业有163家企业（其中电商36家），1-11月这些企业零售额同比减少8.10亿元，拉低限上零售额2.5个百分点，其中，停业企业拉低限上零售额1.0个百分点。因达不到奖励标准不能申请补贴、经营不善老板跑路、搬迁、注销及资金压力等原因导致这些企业停业。

     2、限上部分企业零售额增长乏力。11月份全市133家企业零售额下滑,累计零售额减少量从上年同期的19.56亿元扩大至21.54亿元，拉低限上消费品零售额增幅6.7个百分点。其中，同比减少5000万元以上的企业有12家，累计零售额同比减少10.47亿元。从累计减少量分县区看，涵江和仙游超2亿元，荔城和城厢超8亿元。分行业看，电商和汽车企业累计零售额下降较大，分别下降25.8%和21.8%，分别拉低限上消费品零售额增幅1.7个和2.0个百分点。

（二）部分商品类别零售增速放缓或下降

1、网上零售增速放缓。11月份，全市限上贸易单位实现网上零售额12.96亿元，下降1.2 %，降幅较上月收窄6.1个百分点，累计零售额129.83亿元，增长16.4%，增幅比1-10月回落2.3个百分点，比上年同期回落12.6个百分点。网上零售额回落的原因为部分企业停业及企业减产。

2、汽车类、石油及制品类商品零售当月下降。11月份汽车类商品零售额延续8月份下降态势，从8月份下降1.4%、9月份下降 3.7%、10月份下降4.0%，到11月份的下降7.8%，1-11月汽车类商品零售额增长6.4%，增幅同比回落3.1个百分点；11月份，石油及制品类商品零售额延续下降态势，但降幅较上月收窄5.2个百分点，同比下降1.1%，受当月影响，1-11月，零售额增长5.6%，增幅比1-10回落0.7个百分点。

三、发展建议

1、加强对电商企业的引导。1-11月，全市限上贸易单位网上零售额增长16.4%，占限上消费品零售额的比重达36.3%，增幅比全省平均水平低4.1个百分点。今年以来，限上电商企业零售额增速回落，与企业业务转移、申请不到奖励补贴及电商企业本身运营的高风险等因素有关。因而，对内而言，电商企业要建立自身品牌，走自主品牌道路，才能可持续发展；对外而言，有关部门要进一步完善电商企业的奖励方法，搞活市场机制，引导电商企业做大做强。

2、培育市场，抓好企业入库工作。2018年度，全市新增入库企业502家，其中批发业302家，零售业190家，住宿业4家，餐饮业6家。从户均规模来看，缺少较大型企业，行业集中在电商、木材、建材、钢材、医疗用品等。退出企业167家，将带商品销售额基数106亿元，零售额基数13亿元，这些企业对明年相关指标增速将有一定影响。因而，有关部门仍要加大力度，培育壮大市场体量，做好新增企业入库审核工作。
