1—5月我市外经贸市场回暖明显

来源:统计局 时间：2012-07-05 11:06
| | | |

在全球经济受欧债危机大环境影响下，我市各级各部门和企业界共同寻找办法，克服困难，化解不利因素，使市场信心趋稳，外商投资企业生产经营取得一定的成绩，但成本上涨压力和小微企业融资难问题仍然比较突出，出口企业面临困难较多，虽然目前从美国和日本等国传来经济回暖现象，但断言已排脱危机仍为之过早。今年1-5月份，我市外贸进出口174267万美元，同比增长7.3%，增幅居全省第四位。其中，外贸进口61564万美元，增长3.7%，增幅居全省第四位；外贸出口112703万美元，同比增长9.4%，增幅居全省第六位。利用外资1-5月共有项目18项，比上年下降41.9%，合同外资21756万美元，同比下降27.8%，实际到资14355万美元，同比增长37.9%。从外贸进出口和利用外资实际到资增长的形势看，均比1-4月有所好转，增幅分别提高1.1和5.5个百分点。

一、主要特征

（一）新批项目的合同利用外资成倍增加。5月份新批项目合同利用外资13081万美元，是1-4月累计8675万美元的150.8%，一改前四个月的低迷景象。从1至4月新增项目合同外资分别为3618美元、257美元、3901美元、899万美元。

（二）5月份进出口比上月增长较大。5月份进出口4.05亿美元，比上月增长25.0%，增长幅度高出全省14.8个百分点。其中进口1.45亿元，增长4.1%，比4月份进口1.27亿美元环比增长14.2%；出口2.6亿美元，同比增长15.2%，比4月份1.97亿美元提高32.0%。

（三）私营企业对出口增长贡献最大。1-5月私营企业出口额54358万美元，增长19.8%，增幅高于全市平均增幅的10.4个百分点，拉动全市出口增长8.7个百分点。

（四）鞋类企业占出口总量51.6%。分商品构成中，鞋类产品完成出口58143万美元，占全市出口总量的51.6%，比上年同期增长6.1%，低于全市平均增幅3.3个百分点。

（五）美国是第一大出口地。从出口的国别看，出口美国52280万美元，占出口总量的46.4%，同比增长11.6%，高于全市平均增幅2.2个百分点；第二位是出口欧盟16882万美元，占比重15.0%，同比增长1.9%。

（六）机电产品引领出口增长。1-5月机电产品出口12817万美元，同比增长24.2%，是分产品类增幅最高的一类，比全市平均增幅高14.8个百分点。一是我市机电行业科技含量较高，在当前的欧债危机中受冲击较少；二是在经济处于恢复或危机后阶段许多企业产品更新换代或进行转型升级购置设备带动的生产性需求所致。

（七）进出口与东盟各国联系增强。1-5月从东盟进口35010万美元，占总量56.9%；出口东盟7307万美元，增长31.9%，是出口增幅最高的地区，比全市平均增幅高22.5个百分点。东盟在本次欧债危机中受冲击比较轻，我市许多企业也从东盟及其它一些国家和地区打开许多新的销售渠道。从美国和日本分别进口4046万美元和751万美元，占全市比重分别为6.6%和1.2%。

（八）部分企业打开国内销售渠道。在出口形势较为不利情况下，部分产品性价比占有一定优势的企业，走国内销售的渠道，以改变完全依靠出口的单一销售渠道来渡过目前困难。

二、存在主要问题

国内燃料、石油等原材料持续上升和人工费的提高，使企业成本上升，一些较长期的订单风险较大企业不敢接，部分订单流失到人工成本较低的东盟等国家，这些情况使近期的外贸企业总体上不景气。主要存在下面现象。

（一）劳动密集型企业人工成本费上涨使企业负担加重。由于我市的鞋业、电子、服装等劳动密集型企业所占比重较大，自2011年7月1日起实施《社会保障法》明确规定，“综保”和“镇保”人员将统一纳入“城保”范围，仅此一项，企业人工费增加5%左右，这对劳动密集型企业成本提高幅度较大，为此，一些订单或生产车间转到中西部地区或人工费较低的国家，影响我市出口规模。

（二）生产资料价格上涨严重影响企业利润。原材料普遍涨价，幅度在5-30%，但多数订单价格没有相应提高，为了保住客户和技术工人，许多企业是微利甚至是亏本生产，这种情况使企业生产规模缩小。

（三）贴牌生产企业经营难度较大。一些没有自主商标权的企业，成为商标所有权法人的一个“生产车间”，在决定生产（加工）价格中没有话语权，处于弱势和被动地位，受到冲击较大。

（四）小微企业银行融资较困难。小企业的资质评估低，使其资金提供渠道比大企业难度增加，如果得不到银行较低利息的支持，靠从民间的较高利息融资，在目前经济整体不景气环境下，经营难度加大。

三、建议

每一轮经济危机后，都淘汰了许多高耗能的落后产业，产生和壮大一些新的科技含量高的新兴产业，促进了产业结构的升级换代。企业只有提升产品和服务质量，才能在市场中走得更远，这也是十二五规划中要求企业提升自身内功的重要内容。建议部分出口企业在当前全环经济将要冲出欧债危机的阴霾时机，关注两个方面的事：

（一）借助电子商务开拓新的市场。一些企业要改变过去大批量的生产模式，尝试定制化生产，从专门的产品加工制造逐步走向服务、品牌和创新，提升产品的附加值。

（二）开拓对新兴市场国家贸易出口业务。对以巴西、俄罗斯、南非等目前与我国贸易数量增长较快的新兴市场国家，商品需求量增长潜力较大，我们可以紧跟这些新兴市场的发展需求抢占先机，积极打造市场业务。
