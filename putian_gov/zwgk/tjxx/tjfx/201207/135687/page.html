2012年1－5月莆田市固定资产投资平稳增长

来源:统计局 时间：2012-07-05 11:00
| | | |

今年我市投资在上年高增长的基础上继续保持平稳的增长态势。今年1-5月，全市共完成全社会投资345.84亿元，增长32.5%，增幅位居全省第三位，比1-4月提升0.8个百分点，比全省平均水平高3.3个百分点。其中固定资产投资（不含农户，下同）完成337.49亿元，增长33.0%，增幅位居全省第二位，比1-4月提升0.9个百分点，比全省平均水平高3.4个百分点。在固定资产投资中：项目完成投资263.99亿元，增长34.3%，增幅位居全省第三位，比全省平均水平高6.4个百分点；房地产开发投资73.51亿元，增长28.7%，增幅位居全省第七位，比全省平均水平低6.5个百分点。

一、投资运行的主要特点

（一）各县(区)呈现全面增长的态势。从分县(区)看：各县(区)呈现全面增长的态势。投资增幅比全市平均水平高的有4个（县）区，分别为北岸、仙游县、城厢区和湄洲岛，分别增长55.8%、54.8%、33.7%、33.1%。除了湄洲岛和市直外，各县(区)对全市全社会投资贡献率均达到10%以上。其中仙游县对全市全社会投资贡献率最高，达到22.6%；其次为北岸，贡献率达到19.6%；荔城区、秀屿区、城厢区和涵江区对全市全社会投资的贡献率也分别达到了18.3%、14.1%、13.9%和11.5%。

（二）三次产业投资全面增长。今年以来，我市三次产业投资保持全面增长的态势，其中第一产业投资成倍增长，第二产业投资大幅回落，第三产业投资比重进一步提升。1-5月，第一产业完成投资11.71亿元，增长166.9%，增速在去年同期增长1.1倍的基础上继续加快57.2个百分点，增速比同期二、三产业投资增速分别快147.5个百分点和129.5个百分点。

第二产业完成投资111.16亿元，增长19.4%，增幅比上年同期回落46.8个百分点。其中工业完成投资110、68亿元，增长18.9%，增幅比上年同期回落49.4个百分点。在工业投资中：制造业完成投资92.48亿元，增长26.1%，增幅比上年同期回落90.2个百分点；电力、热力、燃气及水的生产和供应业完成投资17.97亿元，增速在上年同期下降8.2%的基础上今年继续下降8.1%。

第三产业完成投资214.61亿元，增长37.4%，增幅比上年同期快11.8个百分点，比同期固定资产投资快4.4个百分点，占固定资产投资的比重为63.6%，投资比重比上年同期提升2.0个百分点，投资比重进一步提升。

（三）民间投资继续保持高增长态势。今年以来，我市自主性较强的民间投资继续保持高增长态势，在三大投资主体中：民间投资占固定资产投资的份额最大，增速最快，对固定资产投资的贡献率也最高，成为拉动我市投资增长的主动力，在固定资产投资中继续保持主导地位，我市投资的自主性进一步增强。

1-5月，我市民间投资共完成174.90亿元，在上年同期增长56.0%的基础上继续快速增长47.8%，比同期固定资产投资增速快14.8个百分点，比同期国有、外资增速分别快20.3和52.3个百分点，占固定资产投资的比重为51.8%，对固定资产投资的贡献率达到67.5%。在民间投资中：其中项目完成投资111.98亿元，增长65.7%，拉动民间投资增长37.5个百分点；房地产开发完成投资62.93亿元，增长24.0%，拉动民间投资增长10.3个百分点。

（四）基础设施投资快速增长。1-5月，我市基础设施完成投资89.49亿元，增长41.3%，增速比同期固定资产投资快8.3个百分点，比上年同期加快34.3个百分点，占固定资产投资的比重为26.5%，投资比重比上年同期提升1.5个百分点，对固定资产投资的贡献率达到31.2%。其中：交通运输、仓储及邮政业完成投资48.41亿元，增长47.2%，增速同比加快19.0个百分点，对基础设施投资的贡献率达59.3%；水利、环境和公共设施管理业完成投资22.09亿元，增长120.7%，增速由上年同期的下降12.8%转为今年的成倍增长，对基础设施投资的贡献率达46.3%。

（五）社会事业投资成倍增长，民生工程投资力度加大。今年来，我市加大对民生工程的投资力度，社会事业投资成倍增长。1-5月，我市社会事业项目完成投资39.43亿元，增长125.5%，增速比同期固定资产投资快92.5个百分点。其中：水利、环境和公共设施管理业完成投资22.09亿元，增长120.7%；教育事业完成投资6.78亿元，增长42.6%；卫生、社会保障和社会福利业完成投资1.90亿元，增长306.3%；文化、体育和娱乐业完成投资4.99亿元，增长228.0%；公共管理和社会组织完成投资3.69亿元，增长401.4%。

（六）房地产开发投资增速平稳，商品房销售仍然较为清淡。1-5月全市房地产开发共完成投资73.51亿元，增长28.7%，增速比上期快3.2个百分点，比上年同期回落39.3个百分点。其中建安工程完成投资45.79亿元，增长41.5%；其他费用完成投资27.44亿元，增长11.8%。在其他费用中土地购置费21.87亿元，增长3.2%。

从市场销售情况看，在宏观调控政策的持续作用下，商品房销售仍然比较清淡，但从年初以来降幅有明显收窄现象。1-5月，全市销售商品房54.25万平方米，下降23.0%，比1-4月收窄10.6个百分点；其中，住宅销售48.54万平方米，下降25.9%，比1-4月收窄11.9个百分点。全市商品房销售额36.62亿元，下降5.1%；其中，住宅销售额31.26亿元，下降10.5%。

随着楼市的不景气，我市商品房待售面积大量增加。至今年5月底，我市共有商品房待售面积81.80万平方米，增长90.7%，比2011年12月底增加36.54万平方米。其中住宅待售面积38.91万平方米，增长75.5%，比2011年12月底增加19.83万平方米。

二、存在问题

今年前5个月我市投资运行态势良好，但投资运行中仍存在不容忽视的问题：

1、投资增幅大幅回落。1-5月我市全社会投资增幅比上年同期回落23.0个百分点。从分行业看：制造业投资增幅回落90.2个百分点，房地产开发投资回落39.3个百分点，批发和零售业从上年同期的增长2.9倍转为今年的下降64.6%，居民服务和其他服务业从上年同期的增长98.6%转为今年的下降86.0%，住宿和餐饮业在上年同期下降0.5%的基础上今年继续下降10.3%，电力、热力、燃气及水的生产和供应业在上年同期下降8.2%的基础上今年继续下降8.1%。今年投资增幅大幅回落的主要原因有：一是今年的投资形势不容乐观。今年以来，全球经济尚未回暖，投资形势还不容乐观，全省乃至全国投资都出现不同程度的回落。二是去年同期增幅较高。今年投资增幅的回落是属于高基数的低增长。三是缺乏新的增长点。鞍钢冷轧项目、LNG站线建设3＃4＃储罐和燃气电厂3＃4＃机组等大项目在去年底投产竣工，南日风电四期、后海风电二期和石城风电二期等大项目今年上半年已进入扫尾阶段，而今年初以来，没有新的大项目开工，投资因缺乏新的增长点而增长乏力。

2、慢序时进度。从历年1－5月投资完成序时进度看：1－5月都不能按序时进度完成，原因有：一是上半年特别是第一季度受春节放假、雨季等原因影响，投资建设不能按正常进度完成，投资建设的建设高峰期是在下半年；二是国有投资特别是央企上半年受计划下达影响投资进度较慢；三是今年的投资形势不容乐观；四是缺乏新的增长点。

3、投资增长缺乏后劲。今年1－5月，在建500万元以上项目计划总投资由上年同期的增长23.8%转为今年的下降2.6%，其中亿元项目计划总投资下降9.5%，亿元新开工项目计划总投资下降45.7%，亿元新开工项目投资额下降25.0%。亿元新开工项目个数仅为17个，比去年同期减少3个，而且没有一个项目计划总投资有超过5亿的。今年我市投资因缺乏新的大项目支撑而缺乏增长后劲，这将影响上半年仍至全年的投资形势。

三、上半年投资走势

今年上半年，我市投资将继续保持平稳的增长态势，初步预计：上半年全市有望完成465亿元左右，比上年同期增长约31.7%。
