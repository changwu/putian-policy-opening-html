1-4月份莆田市经济运行情况分析

来源：本网 时间：2014-05-16 12:39
| | | |

　　1-4月，全市经济运行总体平稳，多数主要经济指标增幅居全省前列，但经济下行压力加大，消费增长乏力，投资后劲不足等问题依然存在。据初步核算，1-4月份，全市完成生产总值419.76亿元，按可比价格计算，比上年同期增长11.4%，增幅比一季度提高0.1个百分点，但比上年同期回落1.3个百分点，居全省第二位。其中，第一产业增加值33.36亿元，增长3.2%，增幅居全省第六位；第二产业增加值286.40亿元，增长12.8%，增幅居全省第三位；第三产业增加值100.00亿元，增长10.0%，增幅较一季度回落0.2个百分点，居全省第一位。三次产业对经济增长的贡献率分别为2.1%、75.4%和22.5%，分别拉动经济增长0.2、8.6和2.6个百分点。 

　　一、主要经济指标增幅居全省位次情况 

　　多数主要经济指标增幅居全省前列。其中，增幅居全省第一位的有5个指标：分别是第三产业增加值、地方级财政收入、项目投资、批发业商品销售额、实际利用外资；增幅居全省第二位的有4个指标：GDP、财政总收入、金融机构本外币贷款余额、工业用电量；增幅居全省第三位的有6个指标：分别是第二产业增加值、工业增加值、规模以上工业总产值、规模以上工业增加值、固定资产投资额、出口额。同时，经济运行中存在的一些矛盾和问题仍较突出，部分经济指标增幅回落，财政支出、社会消费品零售总额、零售业销售额、房地产开发投资额及公路、水路运输总周转量等指标增幅在全省位次靠后。 

　　二、经济运行的总体情况 

　　（一）生产运行总体平稳 

　　1.工业生产稳中趋缓。1-4月，全市规模以上工业企业实现工业总产值774.45亿元，按可比价格计算，比上年同期增长13.8%，增幅分别比一季度、1-2月和上年同期回落0.1、0.4和2.0个百分点，但仍高出全省平均水平1.2个百分点；实现工业增加值233.72亿元，可比增长13.5%，增幅增幅分别比一季度、1-2月和上年同期回落0.1、0.4和2.1个百分点，但仍高出全省平均水平1.3个百分点。工业总产值和工业增加值增速逐月回落，但总体上保持平稳态势。主要特点：一是重点企业贡献突出。全市产值超亿元规模以上工业企业达213家，共实现工业总产值523.91亿元，增长15.5%，比规模以上工业产值增幅高1.7个百分点，对规模以上工业经济增长的贡献率为74.5%，拉动规模以上工业经济增长10.3个百分点。二是新增企业成为工业经济新增长点。全市新增规下转规上企业109家，实现产值18.64亿元，比上年同期增长1.8倍，对规模以上工业总产值增长的贡献率为12.7%，拉动全市规模以上工业总产值增长1.8个百分点。18家新投产工业企业实现产值12.77亿元，对全市规模以上工业经济增长贡献率为13.6%，拉动规模以上工业经济增长1.9个百分点，其中今年新投产的赛得利纤维拉动作用较为明显。三是制鞋业增速回升明显。全市制鞋产业产值178.44亿元，增长16.2%，增幅比1-3月份提高1.5个百分点，比规模以上工业产值增速高2.4个百分点，其中4月当月增长18.8%，增幅比3月份提高5.5个百分点，比规模以上工业产值当月增速高5.9个百分点，对规模以上工业经济增长的贡献率为26.4%，拉动规模以上工业经济增长3.6个百分点。主要原因: 一是今年以来广东等地订单外移，我市制鞋业订单量大幅增加。二是华丰工贸、永丰鞋业等部分制鞋企业快速增长。四是工业用电量保持较快增长。全市工业用电量继续保持两位数增长，增长19.8%，增幅与一季度持平，高出全省平均水平12.6个百分点，其中4月份当月增长19.7%，增幅高出全省平均水平12.7个百分点，居全省第三位。五是工业品产销两旺。全市规模以上工业实现销售产值758.65亿元，比上年同期增长14.2%，比规模以上工业总产值增幅高0.4个百分点，产销率达97.96%，比上年同期高0.30个百分点。其中，内销产值达627.50亿元，比上年同期增长15.4%，占全部销售产值的比重达82.7%，分别比上年同期、2012年1-4月和2011年1-4月高0.9、2.4和3.4个百分点，呈逐年上升的趋势。 

　　2.建筑业高位增长。1-4月，全市建筑企业（不含劳务分包）完成建筑业总产值105.00亿元，增长42.2％，增幅比一季度提高1.5个百分点，比上年同期提高2.2个百分点。外省入闽企业累计完成建筑业产值32.15亿元，同比增长69.8%。 

　　3.第三产业稳步发展。在批发业、电子商务、邮电业及营利性服务业等相关产业快速发展的带动下，我市第三产业增加值增幅自去年下半年以来持续保持在全省九设区市首位。一是批发业继续保持全省领先优势。在中石化炼油销售（福建）有限公司、仙游县燃料有限公司、中通南方木业及天喔实业等企业的有力拉动下，1-4月，全市批发业继续保持较快的增长态势，累计实现商品销售额259.92亿元，增长33.3%，增幅较一季度提高0.2个百分点，居全省第一位，其中限额以上批发业商品销售额增长38.6%。二是电子商务发展迅速。4月底全市共有76家电商企业（扣除市烟草公司）纳入限上统计，累计实现商品销售额8.28亿元，零售额5.35亿元，分别比去年同期增长2.3倍和2.2倍。三是规模以上其他营利性服务业增势强劲。受基数低的影响，我市规模以上其他营利性服务业营业收入增长41.8%，增幅居全省第一位。四是邮电业发展较快。1-4月，邮政业务总量3.69亿元，增长90.5%，增幅居全省第一位；电信业务总量9.71亿元，增长12.0%，增幅比一季度提高5.0个百分点，增幅居全省第二位。 

　　（二）投资稳中提质 

　　1-4月，全市固定资产投资（不含农户）427.74亿元，增长26.0%，增幅高出全省平均水平高5.2个百分点。主要特点：一是第三产业投资增速回升。全市第三产业投资275.84亿元，增长21.7%，增幅较一季度提高3.7个百分点，占固定资产投资的比重为64.5%，对固定资产投资的贡献率为55.8%。二是轻工业投资增势强劲，活力增强。全市轻工业投资88.63亿元，增长43.2%，增幅较去年同期提高34.6个百分点，占工业投资的比重为69.2%，比上年同期提高10.2个百分点。三是投资内涵深化。全市高新产业投资11.54亿元，增幅由上年同期的下降1.6%转为增长31.3%；科学研究和技术服务业投资6706万元，增长69.7%；高耗能行业投资18.01亿元，增幅由上年同期的增长43.6%转为下降28.5%；工业节能降耗投资7244万元，增幅由上年同期的下降64.6%转为增长228.4%。四是基础设施投资贡献持续提升。全市基础设施投资121.73亿元，增长32.2%，占固定资产投资的比重为28.5%，比上年同期提高1.4个百分点，对固定资产投资的贡献率达33.7%，分别比1-2月份、1-3月份和上年同期提高25.1、10.2和1.5个百分点。 

　　（三）经济运行保障有力 

　　1.金融信贷运行稳健。4月末，全市金融机构本外币存款余额1373.26亿元，增长11.3%，增幅居全省第四位；金融机构本外币贷款余额1174.46亿元，增长17.9%。全市金融机构存贷比为85.5%，比上年同期提高4.8个百分点，比全省平均水平低6.4个百分点。

　　2.利用外资形势良好。1-4月份，全市实际利用外资（验资口径）1.79亿美元，增长39.6%，增幅比上年同期提高20.5个百分点，比全省平均水平高35.9个百分点。 

　　3.物价涨幅逐步回落。受翘尾因素减弱的影响，1-4月全市居民消费价格总水平同比上涨2.4%，涨幅分别较1-2月和一季度回落0.7和0.4个百分点。其中，消费品价格上涨2.2%，服务项目价格上涨3.0%；城市上涨2.3%，农村上涨2.7%。从调查的八大类居民消费价格变动情况看，呈“七升一降”的态势:食品类价格上涨3.1%；衣着类价格上涨5.4%；家庭设备用品及维修服务类价格上涨1.1%；医疗保健和个人用品类价格上涨1.4%；交通和通信类价格上涨0.2%；娱乐教育文化用品及服务类价格上涨2.0%；居住类价格上涨2.9%；烟酒类价格下降1.6%。从当月看，4月当月全市居民消费价格总指数上涨1.3%，环比回落0.8个百分点，其中，食品和衣着类价格回落明显，食品类上涨1.9%，环比回落1.9个百分点；衣着类上涨1.4%，环比回落2.6个百分点。 

　　（四）经济发展质量向好 

　　1.财政收入保持较快增长，支出结构优化。1-4月份，全市财政总收入68.35亿元，增长20.0%，增幅比上年同期提高0.4个百分点，高出全省平均水平7.9个百分点。其中，地方财政收入42.97亿元，增长26.4%，增幅高出全省平均水平12.4个百分点。财政支出39.71亿元，增长6.2%。从结构看，优先保障民生、生产性服务项目支出。其中，粮油物资储备、节能环保、交通运输和资源勘探信息等支出快速增长，增幅分别达32.0%、46.9%、118.3%和91.7%。 

　　2.企业经营效益回升。1-3月份，全市规模以上工业经济效益综合指数为312.84%，居全省第四位，较1-2月回升了一位，比上年同期提高16.09个百分点，比1-2月份提高44.09个百分点，其中，劳动生产率30.86万元/人，比上年同期提高3.39万元/人，比1-2月提高6.93万元/人；实现利润总额24.57亿元，增长11.1%，增幅较1-2月提高13.6个百分点；亏损企业68家，亏损面6.6%，比1-2月缩小0.6个百分点，比上年同期缩小0.1个百分点。 

　　3.居民收支保持较快增长。一季度，全市城镇居民人均可支配收入8435元，同比增长9.3%，增幅比上年同期提高0.4个百分点；城镇居民人均消费支出4645元，增长9.1%，增幅比上年同期提高5.3个百分点。全市农民人均现金收入4269元，同比增长11.6%，增幅上年同期回落0.9个百分点；农民人均生活消费支出2472元，增长12.1%，增幅比上年同期提高1.8个百分点。 

　　三、值得关注的问题 

　　（一）工业回升基础不稳 

　　1.部分企业经营困境未见缓解，减、停产现象依然严重。截止4月末，全市减产企业仍有255家，占全市规模以上工业企业数的24.9%，累计减产近35亿元，其中减产超过千万的规上企业有73家，比3月末增加12家，减产近30亿元，约占总减产量的85%。另有30家企业停产，比3月末增加7家，影响全市工业产值二十多亿元。 

　　2.工业生产者出厂价格指数（PPI）仍处低位。今年以来，我市PPI持续保持99.1%的较低水平，同比下降0.9%，降幅较2013年扩大0.2个百分点，表明我市工业需求仍未得到有效恢复。 

　　3.出口交货值增速继续回落。受外需疲软影响，1-4月份我市规模以上工业出口交货值131.15亿元，比上年同期增长8.6%，增幅分别比1-3月和1-2月回落2.1和0.5个百分点。 

　　（二）第三产业增幅回落 

　　1.零售业销售额连续三个月负增长。1-4月，全市零售业商品销售额153.27亿元，下降1.1%，增幅比上年同期回落36.6个百分点，其中，限额以上零售业商品销售额下降20.7%，增幅比上年同期回落107.3个百分点。主要原因：一是全市共有71家限额以上零售企业销售额同比出现不同程度的下降，下降面高达28.6%；二是受上年高基数以及中石化森美（福建）石油有限公司莆田分公司联营业务停止的影响。

　　2.房地产市场大幅降温。1-4月，全市商品房销售面积下降11.1%，增幅分别比一季度和上年同期回落20.4和104.0个百分点。 

　　3.交通运输业发展缓慢。1-4月，全市公路运输总周转量119407万吨公里，增长12.4%，增幅比一季度提高1.5个百分点；水路运输总周转量150101万吨公里，增长9.5%，增幅比一季度提高1.3个百分点。虽然公路运输总周转量和水路运输总周转量增速有所回升，但在全省位次靠后，分别居全省末位和第八位。

　　（三）投资后劲有待增强 

　　1.工业投资增速放缓。全市工业投资128.16亿元，增长22.1%，增幅分别比1-2月份和1-3月份回落34.6和11.7个百分点，增幅居全省第三位，较一季度回落了一位。其中，制造业投资103.79亿元，增长24.2%，增幅分别比1-2月份和1-3月份回落60.1和16.2个百分点。 

　　2.民间投资贡献有所弱化。全市民间投资完成230.09亿元，增长21.4%，增幅比固定资产投资低4.6个百分点，比一季度和上年同期回落4.3和18.3个百分点，占固定资产投资的比重为53.8%，比上年同期回落2.0个百分点，对固定资产投资的贡献率46.0%，分别比1-2月份和1-3月份回落17.3和5.5个百分点。 

　　3.房地产投资增速继续下滑。全市房地产开发投资83.27亿元，与上年同期持平，增幅比1-3月回落4.8个百分点，比上年同期回落50.2个百分点，低于全省平均水平22.8个百分点，居全省末位。分县区看，除仙游县和涵江区分别增长79.0%和42.9%外，其他县区均呈负增长。 

　　（四）出口形势不容乐观 

　　由于欧美经济复苏缓慢，新兴经济体受美联储退出量化宽松政策影响，国际市场需求总体疲软，再加上国内劳动力等生产要素成本上升的影响，我市外贸出口增长压力空前。1-4月份，全市出口增速继续回落，仅增长0.7%，增幅较一季度回落1.3个百分点，创近年来新低，其中4月当月下降3.1%。从出口市场看，对美出口额4.92亿美元，增长4.2%，增幅较一季度回落了2.3个百分点；对欧盟出口额1.50亿美元，增长2.3%；对东盟出口额0.16亿美元，下降6.7%；对日本出口额0.11亿美元，下降18.5%。从出口商品看，占我市出口总额近六成的鞋类出口额5.71亿美元，增长10.9%；轮胎、机电和服装则分别下降12.8%、14.7%和12.4%。
