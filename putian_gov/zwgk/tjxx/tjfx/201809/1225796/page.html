莆田市“全面两孩”政策实施效果调研报告

第五十五期
第五十五期
来源：本网 时间：2018-09-26 09:55
| | | |

为了及时反映2018年上半年出生人口和育龄妇女生育情况，了解和评估“全面两孩”政策实施效果。近期，根据省统计局、省卫计委关于开展全面两孩政策实施效果调研工作的通知精神，我局联合市卫计委在全市范围内部分医院或助产机构、村居委员会开展重点调研。现将调研情况报告如下：

一、调查基本情况

此次调查对象包括7家接生量大的医院或助产机构，12个按城乡比例、人口规模较大的村居委会。调研采取问卷形式，对全面放开两孩政策后的2017年、2017上半年和2018上半年出生人口情况进行入户访问，并分析全面两孩政策实施后对莆田人口发展的效应。

（一）村居基本情况

1、在12个村居委会中，按城乡分类，3个属于主城区，3个属于城乡结合区，1个属于乡镇结合区，5个属于乡村。按城乡属性分，7个属于城镇，5个属于乡村。4个社区居委会没有农业用地，8个村委会还有农业用地。9个村居主要从事非农业，2个从事农业，1个从事农业和非农业各半。12个村居委会共有工作人员145人，平均每个村居委会12人，并且都有专人负责日常人口迁移流动和出生死亡记录。

2、在12个村居委会中，年末户籍人口共93047人，常住人口99934人，净流入6887人。12村居委会中，每个村居的计生台账都可以分出出生孩子的胎次，有10个村居的出生人口登记情况较详细，有个案信息，这些信息来源大部分由计生人员上门统计。

3、在12村居委会中，实施“全面两孩”政策之前，4个居委会执行的是一孩生育政策，6个村委会执行一孩半政策，2个村委会执行2孩生育政策。

（二）医院或助产机构基本情况

7家医院中，2家为市级5家为县级，妇产科床位共有682个，工作人员484人。7家医院都建立了出生孩子与父母的电子信息档案，能够区分出出生孩子的胎次，并实现了出生人口的个案信息在全市范围内联网。

二、出生人口情况

（一）村居委会出生人口情况

1、12个村居委会2017年出生人口1355人，出生率达13.6‰，其中，上半年出生757人，占全年的55.9%。2018年上半年出生643人，比上年同期减少114人，同比下降了17.7个百分点。据调查，这12个村居委会目前怀孕人数407人，假设全部在年内出生，那么2018年出生人口为1050人，比2017年还是减少305人，下降22.5%。

2、从分胎次出生情况看，2017年出生一胎466人，二胎786人，三胎及以上103人，一胎占34.4%，二胎占58.0%，三胎占7.6%；2018年上半年一胎223人，二胎366人，三胎及以上54人，三胎次分别占34.7%、56.9%、8.4%。二胎占比下降了1.1个百分点，

（二）医院或助产机构出生人口情况

2017年7家医院共接生25290人，占全市49.1%，其中，上半年接生13016人，占全年的51.5%。2018年上半年共接生10133人，同比减少2883人，下降22.1%。从分胎次情况看，2017年接生一胎8973人，二胎13878人，三胎及以上2439人；三胎次分别占35.5%、54.9%、9.6%；2017年上半年接生一胎4612人，二胎7229人，三胎及以上1175人，分别占35.4%、55.5%、9.0%；2018年接生一胎3626人，二胎5432人，三胎及以上1075人，分别占35.8%、53.6%、10.6%。二胎率比上年同期下降了1.9个百分点。

上述情况表明，2018上半年村居委会的出生人口和医院或助产机构的接生人口都下降，下降的幅度超二成；从分胎次情况看，一胎保持稳定，二胎下降1-2个百分点。按城乡区域分，2018年上半年的出生率城镇的高于乡村，城镇的二孩率下降大于乡村。

三、实施全面两孩政策的积极效应

实施全面两孩生育政策是从我国战略全局出发作出的重大决策部署。全面两孩政策实施有利于更好地满足群众的生育意愿，促进家庭幸福和社会和谐，有利于优化人口年龄结构，减缓老龄化压力，增加劳动力供给，带动了新生儿需求产品产业提升，从而促进社会经济持续健康发展。从目前看两孩政策总体是好的，得到社会、家庭的支持和响应。

（一）人口出生率快速上升。实行两孩生育政策两年来，莆田市总常住人口增加3万人。2017年出生率达14.9‰，比2015年提高1.3个千分点。2018年全市人口出生率仍将有望保持在14.5‰左右。这是新政出台前，一胎政策和不符合“单独两孩”政策时期累积的“两孩”生育群体，必然会在实施“全面两孩”政策后的几年内得到释放，生育的意愿也特别强烈，妇女时期生育水平迅速提高，出生人口增加。

（二）二胎出生人口增加。全面两孩政策进一步助推了人口生育。从调查数据来看，2016年、2017年和2018上半年医院、助产机构接生儿和村居委会新生儿二胎占比比2015年均有提高，均超过50%。城镇地区二胎占比提高更明显。但2018上半年的二胎占比与2017年、2017上半年的均有回落。预期全面两孩政策效果在2018年将达到顶峰，今后将逐步趋向正常化。

（三）劳动力资源供给增加。生育政策调整直接影响出生人口规模，从而影响未来劳动力资源的供给。实施“全面两孩”生育政策，育龄妇女生育水平得到提高，出生人口增加。当新出生的人口在未来进入劳动力市场后，不仅可以有效改变人口年龄结构，而且还能增加未来劳动年龄人口数量，补充莆田市劳动力资源供给。

四、实施全面两孩政策的负面效应

在走访、座谈中，也了解到一些二孩生育人群的意愿不强。原因表现在少儿抚养负担压力加大。一是生育成本高。从备孕到托幼前，孕妇营养品、各种婴儿品需求量极大，而且价格昂贵，这对年轻夫妇来说是一笔不小的负担。二是教育成本高。子女的教育问题始终是父母的第一要事。孩子们除了在学校正常上课外，还要参加各种辅导班、兴趣爱好培训班等等，因为每个家长都不愿意自己的小孩输在起跑线上。三是就学难度大。教育质量的好坏也是父母的关注热点。由于中小学的师资力量、教学条件等分布不均衡，差异很大，家长都希望自己的孩子往好的学校送，不惜重金想尽办法挤，给学校招生发难，学校就可能增设一些不必要的门槛，使就学问题成为家长一种很大负担。这些负担在一定程度上平抑着二孩生育人群的生育意愿。

五、相关政策建议

（一）加强生育知识宣传引导。不符合原生育政策和“单独两孩”政策下所积累的生育势能，在“全面两孩”政策实施后几年内得到释放，二孩生育水平明显提高,特别是高龄孕产妇会明显增加。如何保障母婴健康安全，有效防止发生孕产期合并症、并发症的风险，是一个值得重视的问题。为此，要增加妇幼保健或助产机构的服务能力供给，加强技术人员的培训；要加强咨询指导，增强孕产妇自我保健能力；要加强孕期和优生优育知识的诠释和宣传，引导广大育龄妇女在最佳生育期生育，减少出生缺陷。

（二）健全改善公共服务设施。要提高生育健康、妇幼保健、托幼等公共服务水平，以满足目标人群在孕前、孕期、产前、产后各个时期的不同需求。要加快构建配套的服务设施体系，健全完善医疗、托育、教育、社保等保障体系，减轻家庭养儿育儿社会成本和经济成本，加快妇女服务体系建设，保障女性就业、假期等合法权益。
