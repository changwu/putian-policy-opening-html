莆田市建筑业企业营商环境调查报告

第五十七期
第五十七期
来源：本网 时间：2018-09-28 09:47
| | | |

莆田地处闽中沿海中部，交通发达，区位优势独特，但与其他沿海城市相比，经济体量偏小。营商环境就像一根扁担的两头，一头担着城市的发展，一头担着企业的未来。为进一步了解企业对本市营商环境的意见建议，2018年9月中旬，莆田市统计局开展了资质建筑企业（以下数据口径均为本市资质建筑企业）营商环境调查，共323家联网直报建筑业企业参与了该项调查，调查率超9成。在此基础上，今年以来我局对部分建筑企业进行调研，同时与这些企业进行了深度座谈。结合调查及调研结果，提出了改善莆田市建筑业企业营商环境的建议。

一、总体满意度

从注册地看，1-8月全市资质内联网直报建筑业企业（含总承包和劳务分包））共有341家，共完成建筑业总产值435.51亿元，同比增长9.2%，增速分别比上年同期、1-7月回落22.4个和1.2个百分点，建筑业发展稳中趋缓。

调查结果显示，78%的被调查企业对我市的建筑业营商环境总体满意。反映营商环境的8个方面中，满意度从高到低分别为：开办企业环境76.8%，经营环境76.8%，纳税环境76.8%，公共服务平台与政策扶持76.5%，法律环境75.5%，用工和人才环境71.5%，扶持企业外拓环境70.3%，投融资环境70.3%。

二、四个方面比较满意

1、开办企业的环境

该调查显示，97.9%的被调查企业对我市开办企业环境满意或基本满意，满意度较高。为进一步深化“放管服”改革和优化营商环境，提升我市开办企业服务效率，我市逐步推行企业开办“一窗受理”全程代办服务。目前，企业开办“一窗受理”全程代办服务以行政服务中心为平台，对工商、公安、人行、税务、人社等部门现有证照审批（备案）流程进行重新梳理，通过材料再精简、流程再优化、环节再整合，试行“一窗受理、内部流转、集成服务”审批机制，实现企业开办“一次采集、一套材料、集中出证”的目标。“一窗受理”服务实行以来，只要跑一个窗口就可以同时办理多项手续，缩短了不少办事时间。该模式完善了服务体系、提高了服务效能，提升了群众和企业的获得感。

2、经营环境

据调查显示，96.9%的被调查企业对建筑业经营环境表示满意或基本满意。尽管调查显示建筑企业对经营环境满意度较高，但从实地走访及座谈企业反映来看，建筑行业乱象较多，企业压力大，主要体现在：1、过分倚重资质为市场准入门槛。2、行业市场秩序不规范，过度竞争。3、业主方较为强势，建筑企业利润空间压缩，压力大。在调查之后对部分企业的走访了解到，经营环境满意度高主要和近年来政府大力扶持建筑行业，出台一系列相关扶持文件，无形中降低了企业部分压力有关。

3、纳税环境

2016年5月建筑业行业进行全面“营改增”，税务部门的讲解有实质性作用、对企业帮助很大。调查结果显示：95.7%的被调查企业对我市的纳税环境表示满意或基本满意，4.3%表示一般满意或不满意。座谈企业也表示本市纳税环境良好，没有乱收费现象。谈及“营改增”后税负变化，企业间差别较大，大部分建筑企业在“营改增”初期由于对新环境的不适应，没有认识到提供发票的作用，加上能开票的供应商较少等原因，税负普遍增加，随着留抵税额的增加，部分企业税负率低于税改前，实现了真正的减负。

4、公共服务平台与政策扶持

据调查显示，95.0%的被调查企业对我市建筑业公共服务平台与政策扶持环境表示满意或基本满意，5.0%表示一般满意。走访了解，2017年我市住建部门结合省厅以及我市近两年出台的规范性文件，组织修订了《莆田市场房屋建筑和市政基础设施工程施工招标文件范本》（2017年版），进一步规范了招标投标市场行为。配合省厅积极推广最新的招投标政策，推行在线投标和开评标，全面实施全省统一的电子招投标系统和行政监管系统。同时制定《莆田市人民政府关于促进建筑业发展壮大的实施意见》（莆政综〔2016〕158号），并积极落实。

三、四个方面有待完善

1、投融资环境：建筑业企业普遍资金短缺，中小企业融资难

据调查显示，70.3%的被调查企业对我市建筑业投融资环境表示满意，21.7%表示基本满意，7.7%表示一般满意，1家企业表示不满意。通过与部分受访企业座谈得出，相比于其他行业，建筑业企业融资更为困难，原因在于：一是银行信贷歧视以及抵押现象严重，即建筑企业一般都是非国有，规模小，不动产也少，银行担心资金很可能无法收回；二是建筑业企业信用度低且大多规模不大，即近年来，中小企业不良贷款率较高，而银行贷款时会看中企业的规模、信用；三是建筑企业缺乏核心竞争力，即需要高盈利能力、高素质人才、高技术创新，而建筑企业这些都较欠缺。

2、扶持企业外拓市场环境：开拓省外市场政策扶持作用减弱

2015年底起，我市住建部门就积极鼓励建筑业企业从“单打独斗”走向“抱团发展”，发挥各自优势，鼓励多家实力雄厚的企业去外省拓展业务，取得了明显的成效。特别是2016年在外省完成的建筑产值增速高达85.6%。但是近两年该指标数据增速逐年下降。2018年1-8月全市在外省完成的产值160.20亿元，同比仅增3.1%，增速分别较上年同期、1-7月回落29.7个和3.1个百分点，占全部产值的36.8%，比重较上年同期下降2.2个百分点。据调查显示，70.3%的被调查企业对我市扶持企业外拓环境表示满意，21.4%表示基本满意，8.0%表示一般满意，1家企业表示不满意。

3、用工和人才环境：部分企业用工紧缺，人才流失

据调查显示，71.5%的被调查企业对我市用工和人才环境表示满意，23.5%表示基本满意，5.0%表示一般满意。在走访企业中了解到，企业岗位证较为缺乏。对于建筑业行业来说，“工资待遇缺乏竞争力”以及“企业发展上升空间小”是企业人才流失的最主要原因，大部分企业对此表示认同。

4、法律环境

调查结果显示，75.5%的被调查企业对我市法律环境表示满意，19.8%表示基本满意，4.6%表示一般满意。被调查企业对本市的法律环境比较满意，但仍有小部分企业认为我市建筑行业法律环境还有待提高，诉讼是解决法律纠纷最有效的途径。从纠纷内容看，主要集中在合同法、企业间纠纷以及与企业员工的劳资纠纷。走访的建筑企业表示近年纠纷在本市通过诉讼途径均能圆满解决，判决和执行都能到位。

四、几点建议

良好的营商环境有利于提高一个城市的综合竞争力，加强营商环境建设和构建“亲”“清”新型政商关系对拉动经济发挥出不可小觑的作用。针对被调查企业反映最需要解决的问题，提出以下建议：

1、多渠道助力企业融资。一是强化政府监督职能，健全法律制度，对长期拖欠工程款的业主，制定相应的制约政策。二是根据不同项目情况，政府可采取投资补助、基金注资、担保补贴、贷款贴息等方式，放大政府资金撬动社会资本的作用。三是考虑中小企业可抵押物少的实际情况，出台针对中小企业的灵活贷款政策。

2、增强企业外拓市场竞争力。加大力度研究完善外地工程的金融体系，健全服务体系，给予企业融资信保、法律和安全等方面的有力支持。简化各类审批程序，实现政府精准服务，为企业“走出去”开启绿色通道。加大业务培训、政策研究、人才培养力度，探索放宽建筑业企业承包工程范围。放开市场，促进本地企业更快成长，提高综合竞争力。
