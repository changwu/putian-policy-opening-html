2012年上半年莆田市商贸运行情况分析

来源:统计局 时间：2012-08-18 17:19
| | | |

今年来，我市各级各有关部门围绕市委市政府提出的经济发展目标，积极改进商品流通环境，培育新的经济增长点，商贸市场持续较快发展。上半年，全市实现商品销售额（营业额）424.51亿元，同比增长26.3%，增幅比上年同期上升2.9个百分点;全社会完成社会消费品零售总额182.43亿元，同比增长15.9%，增幅比上年同期回落0.6个百分点。

一、主要特征

（一）商贸业是推动第三产业发展的中坚力量。上半年，全市商贸业（批发、零售、住宿及餐饮业）实现增加值49.36亿元，可比增长11.2%，占第三产业增加值的比重达28.7%，对第三产业增加值增长的贡献率达35.8%，拉动第三产业增加值增长3.2个百分点，同时拉动全市地区生产总值增长1.0个百分点。

（二）商品销售额（营业额）快速增长。从分限额以上及限额以下看，限上企业快速增长，限下企业稳中有升。上半年，限上企业实现商品销售额（营业额）200.06亿元，增长42.1%，增幅比上年同期回落0.9个百分点；限下企业实现商品销售额（营业额）224.44亿元，增长15.0%，增幅比上年同期上升2.2个百分点。在四个行业中，批发和零售业完成商品销售额401.76亿元，增长27.1%，增幅比上年同期提升3.2个百分点；住宿和餐饮业完成营业额22.75亿元，增长14.7%，增幅与去年同期相比回落0.4个百分点。

（三）批发业对销售额（营业额）增长的贡献最大。从批、零、住、餐四个行业看，虽然6月份批发业销售额受基数增大的影响，增速有所回落，但其实现销售额所占比重仍最大，增速在四个行业中最高，对销售额（营业额）增长的贡献最大。上半年，批发业实现销售额223.96亿元，增长30.7%，增速居全省第一位，对商品销售额（营业额）增长的贡献率达59.4%；零售业实现销售额177.80亿元，增长22.8%，增速居全省第1位，对商品销售额（营业额）增长的贡献率达37.3%；餐饮业的贡献率为3.0%，住宿业为0.2%。批发业、零售业、住宿业及餐饮业分别拉动商品销售额（营业额）增长15.7个、9.8个、0.1个及0.8个百分点。从限上限下分组看，限上批发业一枝独秀，对商品销售额（营业额）增长的贡献率高达47.6%，拉动总量增长12.5个百分点。（具体见表1）。

（四）限上零售业销售额增速首超批发业。限上及限下分组中，限上四个行业实现的商品销售额（营业额）在各自行业中所占比重分别为：批发业63.2%、零售业30.7%、住宿业17.9%，餐饮业17.4%。从增速看，限上零售业销售额增速最高，其次为限上批发业，增速分别43.4%及42.4%，分别比限下该行业高28.0个、27.8个百分点。

（五）社会消费品零售总额增幅排全省第6位，比全省平均水平高0.1个百分点。上半年，全市完成社会消费品零售总额增幅在全省排第6位，排名比去年同期前移3位，比5月份前移1位。从分行业看，零售业完成零售额最多，为148.91亿元，增长16.6%；其次为餐饮业，完成18.66亿元，增长15.2%；排在第三位的是批发业，完成14.08亿元，增长11.0%；而住宿业仅为0.77亿元，增长1.6%。在四个行业中，零售业对社会消费品零售总额增长的贡献最大，达84.6%。从分限上限下看，只有限上零售业及餐饮业销售额（营业额）增速大于限下，分别多12.6及3.2个百分点。

二、增长因素

限上企业实现商品销售额（营业额）所占比重为47.1%，低于限下企业5.8个百分点，但其实现商品销售额（营业额）对总量增长的贡献率达67.0%，高于限下34.0个百分点，拉动商品销售额（营业额）增长17.6个百分点，比限下多8.9个百分点。其中，限上批发零售业对销售额（营业额）增长的贡献率高达66.3%。

（一）从商品分类看，石油及制品类对限上批发零售业增长贡献最大。从我市已有的23类商品实现销售额看，各类商品增速出现极端值，煤炭及制品类增长224.0%、金银珠宝类增长217.1%，这两类商品因量较小，贡献率不大；书报杂志类及家具类增速出现负增长。推动限上批发零售业增长主要是三大类商品，其一是石油及制品类，实现销售额40.19亿元，对限上批发零售业增长的贡献率最大，达30.1%，拉动限上批发零售业增长12.8个百分点；其二是服装、鞋帽、针纺织品类，实现销售额42.03亿元，贡献率达17.5%，拉动7.5个百分点；其三是木材及制品类，实现销售额15.74亿元，贡献率达11.8%，拉动5.0个百分点（具体见表2）。

三、当前存在问题

（一）限上社会消费品零售总额比重全省最低。1－6月，全市限上企业（含个体户）实现社会消费品零售总额占全市社会消费品零售总额的比重为28.0%，为全省九地市最低，比第一位的厦门低28.3个百分点。

（二）社会消费品零售总额增速县区间差距加大。上半年，从各县区完成社会消费品零售总额增速看，北岸增幅最高，为280.8%；最低为涵江区，仅为3.0%，两者相差277.8个百分点。而1－5月份消费品零售总额同比增速最高为186.5%，最低为5.3%，相差181.2个百分点。

四、建议

（一）鼓励发展壮大网上商贸企业。传统的实体店受地理位置、交通、营业时间等的限制，随着年轻群体消费观念的不同、现代计算机技术的快速发展，新型的电子商务企业应运而生，网上购物消费已成为生活的一部分。我市可依托于市电子商务行业协会，提高行业自律，进一步规范电子商务企业行为，积极为企业排忧解难，做大做强电子商务企业，拓展我市商贸市场发展空间。

（二）培育新增限上企业。因去年限上商贸的高速发展，去年新增的限上企业将陆续在下半年带基数，加之制度原因，有的企业还不能统计进来，从而增速将放缓。新增企业对全市限上企业销售额（营业额）增长的拉动作用是最有效的，有关部门应高度重视发展新增限上企业，提高我市限上企业的发展后劲。

（三）完善商贸流通网络。有关部门要根据我市现有流通网络，科学规划和调制，营造商贸健康发展的环境，在城区倡导发展专卖、专业连锁店及大型综合性购物中心（超市），在城镇要加大各类专业市场的产业升级，在乡村合理布点，完善“万村千乡市场工程”。
