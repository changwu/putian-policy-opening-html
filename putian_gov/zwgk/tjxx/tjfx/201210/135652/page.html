投资超序时完成　 增幅居全省前列——1－9月莆田市固定资产投资运行情况简析

来源:统计局 时间：2012-10-23 18:37
| | | |

自年初以来，全市各级各部门积极响应市委、市政府的号召，紧紧围绕“实现一二三一五、突破项目促跨越”的工作目标，凝心聚力抓项目，全力打好“五大战役”，促进固定资产投资平稳快速增长。

一、投资运行的主要特点

（一）投资超序时完成年度计划，增幅稳居全省前三位。今年以来，我市固定资产投资在去年高增长的基础上继续保持快速的增长态势，投资超序时完成年度计划，增幅稳居全省前三位。1－9月，全市共完成全社会投资691.08亿元，完成年度计划的75.1%，超序时进度0.1个百分点，同比增长34.8%，增幅比上月提升1.8个百分点，投资增幅位居全省第三位，比全省平均水平高出7.2个百分点。其中固定资产投资（不含农户，下同）完成668.91亿元，增长35.7%，增幅比上月提升1.9个百分点，投资增幅位居全省第三位。在固定资产投资中：项目投资完成517.44亿元，增长37.5%；房地产开发投资151.48亿元，增长29.8%。

（二）各县区投资增势喜人，出现全面增长的良好态势。今年以来，我市各县区党委政府紧紧围绕市委市政府工作任务，认真部署，加强调度，强化措施，奋力攻坚，力促项目提速，促进固定资产投资快速增长，各县区投资增势喜人，出现全面增长的良好态势。今年以来，北岸经济开发区得益于大型临港项目的强劲拉动，投资一直保持高速的增长态势，投资增幅稳居全市首位，对全市投资的贡献率居各县区之首，高达21.4%（见表一）。

（三）第一产业投资高速增长，第三产业投资比重进一步提升。今年以来，我市第一产业投资在上年高增长的基础上继续保持高速增长；而第二产业投资今年因缺乏新的大项目支撑增幅出现大幅回落；第三产业投资继续保持较快的增长态势，投资比重进一步提升。1－9月，我市第一产业完成投资19.03亿元，增长91.0%，投资增速在上年同期增长2.9倍的基础上继续保持高速增长，增速比同期二、三产业投资分别快67.3个百分点和50.2个百分点。

第三产业完成投资432.09亿元，增长40.8%，增幅比同期固定资产投资快5.1个百分点，占固定资产投资的比重为64.6%，投资比重比上年同期提升2.3个百分点，对固定资产投资的贡献率高达71.1%。在第三产业投资中：项目完成280.61亿元，增长47.5%；房地产开发投资151.48亿元，增长29.8%（见表二）。

（四）民间投资继续保持快速增长，投资自主性进一步增强。今年以来，我市投资自主性较强的民间投资继续保持快速增长态势，投资比重进一步提升。在三大投资主体中，民间投资的增速最快，占固定资产投资的份额最大，对固定资产投资的贡献率也最高，成为拉动我市投资增长的主动力，在固定资产投资中继续保持主导地位，我市投资的自主性进一步增强。

1－9月，我市民间投资共完成341.71亿元，增长45.7%，比同期固定资产投资增速快10.0个百分点，比同期国有、外资增速分别快11.7和44.3个百分点，占固定资产投资的比重为51.1%，对固定资产投资的贡献率达到60.9%。在民间投资中：其中项目完成投资208.99亿元，增长54.9%，对民间投资的贡献率达69.2%；房地产开发完成投资132.72亿元，增长33.1%，对民间投资的贡献率达30.8%。

（五）商品房销售面积小幅增长，待售房源大量积压。1－9月，全市商品房销售面积为139.20万平方米，增长4.2%，比上月回落4.5个百分点。其中，商品住宅销售面积为119.52万平方米，由上月的增长0.6转为本月的下降5.7%。

今年以来楼市的不景气，导致今年我市可售房源大量积压。至9月底，我市共有商品房待售面积85.88万平方米，同比增长90.5%，总量比上月净增3.3万平方米。其中1年以内的商品房待售面积28.51万平方米，下降13.0%；1年以上的商品房待售面积57.37万平方米，增长3.7倍。

（六）建设资金来源较为充足，有力保障了投资建设快速推进。1－9月全市固定资产投资口径本年资金来源总额为825.50亿元，是同期同口径投资额的1.2倍，较为充足的资金为我市投资的快速增长提供了有力的资金保障。在本年到位资金中：国家预算内资金为49.83亿元，增长66.0%；国内贷款为120.26亿元，增长1.0倍；利用外资33.97亿元，下降18.9%；自筹资金468.35亿元，增长31.8%；其他类资金89.36亿元，增长45.0%。

二、存在问题

今年1－9月我市投资运行态势总体良好，但投资运行中仍存在不容忽视的问题：

1、投资增长缺乏后劲。一是亿元项目明显减少。1－9月，本年新增亿元项目纪录个数仅为10个，比上年同期减少9个，亿元本年新增项目投资额下降30.5%，亿元新开工项目计划总投资下降15.7%，亿元新开工项目投资额下降2.4%。二是房地产开发本年新开工面积出现下降。1－9月房地产开发本年新开工面积为371.85万平方米，增幅由上年同期的增长99.6%转为今年的下降23.1%。三是投产项目占比偏高。至9月底，我市项目已累计投产451个，占施工项目总个数的35.2%，比上月提高4.2个百分点，比上年同期提高15.3个百分点。

2、投资结构不合理，投资外延性扩张明显，投资质量下降。今年以来，我市固定资产投资的外延性扩张特点表现依然较为突出，投资仍以新扩建为主，改建和技术改造项目投资占比仍然偏低，设备工器具购置投资比重明显下降，投资外延性扩张明显，投资质量下降。1－9月，在500万元以上项目投资中，我市新扩建项目完成投资453.97亿元，占500万元以上项目投资的比重为87.7%，而改建和技术改造项目完成投资32.78亿元，占500万元以上项目投资的比重仅7.3%，远远低于新扩建项目；按投资构成分，其中500万元以上项目中含金量最高的设备工器具购置完成投资76.72亿元，增长19.8%，增幅比同期500万元以上项目投资慢17.7个百分点，占500万元以上项目投资的比重仅为14.8%，投资比重同比回落2.2个百分点。

3、工业投资大幅回落。今年，随着鞍钢冷轧、LNG站线建设、燃气电厂的陆续竣工投产，又缺乏新的大项目支撑，我市工业投资呈现大幅回落的态势。1－9月，我市工业完成投资217.09亿元，增长23.9%，增幅比上年同期回落35.2个百分点。在工业投资中，制造业完成投资175.32亿元，增长27.9%，增幅比上年同期回落56.8个百分点；电力、热力、燃气及水的生产和供应业完成投资40.88亿元，增长8.7%，增速比上年同期回落12.2个百分点。

三、全年投资形势预测

根据1－9月我市投资运行情况分析和调查研究，初步预计：全年全市全社会投资有望完成930亿元，增长28.2%，完成年度计划的101.1%，快序时进度1.1个百分点。
