新形势下莆田市农业农村经济发展面临的问题及对策

来源:统计局 时间：2013-09-05 17:11
| | | |
【内容提要】农业是国民经济的基础。本文分析了莆田市农业农村经济社会发展现状，阐述了2012年莆田市农业农村经济发展取得的成就，着重指出新形势下农业农村经济社会发展面临的几个深层次问题，探索了促进农业农村经济社会可持续发展的若干对策，旨在为农业农村经济的可持续发展提供理论支撑和操作建议。
【正文】农业是一个国家稳定的基础，也是其他产业的支柱，农村的繁荣稳定也是国家繁荣稳定的基础，是关系到整个社会的稳定和发展的全局性问题。近年来，在党和政府的大力推动下，中央连续十年出台指导农业和农村工作的一号文件，大力促进农业农村经济社会发展。在市委、市政府的高度重视下，全市的农业、农村经济取得了巨大成就。当前，虽然全市农业和农村经济总体上保持较好的发展态势，但是作为弱势产业，农业仍是国内经济发展中最为薄弱的环节，尤其是不利因素和深层次问题非常突出，因此要保持农业经济高速、持续发展，必须充分了解新形势下农村经济社会发展的特点，采取及时有效的应对之策，确保农业农村经济的可持续发展。
一、莆田市农业农村经济的基本发展状况
2012年，全市认真贯彻落实中央和省、市一系列支农惠农政策，切实加强“三农”工作，稳步推进社会主义新农村建设，实现了农民收入突破性增长、现代农业发展步伐加快、农业综合生产能力进一步增强的目标，保持了农业和农村经济的较快发展。全市农林牧渔业总产值178.77亿元，可比增长3.9%。实现农林牧渔业增加值107.24亿元，增长3.8%。农民人均纯收入达10311元，增长13.7%。农业和农村经济发展的特点是：
（一）优化结构促发展，现代农业发展步伐加快。我市以农业结构调整优化为主线，出台扶持现代农业发,7展政策，在稳定粮食生产的基础上，把水产、水果、畜牧、食用菌、蔬菜等农业主导产业作为重点，农业产业结构得到不断优化，促进了现代农业加快发展。2012年粮食面积75.02万亩，比上年下降5.6%。粮食产量28.47万吨，比上年下降5.5%。园林水果产量20.33万吨，比上年增长24.5%，创历史新高。食用菌产量7.31万吨，比上年下降3.6%。蔬菜面积52.09万亩，比上年增长0.3%。蔬菜产量110.73万吨，比上年增长1.7%。以肉类、禽蛋和奶类为主的畜产品产量分别达13.18万吨、4.49万吨和1.51万吨，其中肉类产量比上年增长6.7%，禽蛋和奶类分别比上年下降3.1%和4.9%。水产品产量74.74万吨，比上年增长2.8%。以蔬菜为主的设施农业规模达2.49万亩，大棚蔬菜效益明显增加。
（二）农业产业化经营加快发展。2012年末，莆田市农业产业化龙头企业138家，其中国家级农业产业化龙头企业4家，省级农业产业化龙头企业22家，市级农业产业化龙头企业112家。2012年,全市农业产业化龙头企业实现销售额达196.55亿元，出口创汇17365万美元，全市农业产业化企业带动农户数61.8万户，带动基地规模191.2万亩，牲畜饲养量183万头，禽类饲养量2986万只，水产养殖面积28万亩，农户从产业化组织中获得收益39亿元。我市各类种养、农机、营销等农民专业合作社发展迅猛，至2012年底，全市合作社达761家。
（三）农业科技创新水平得到提升。2012年，2个龙眼新品种通过国家热带作物品种审定委员会初评；4个新品种通过省农作物新品种审定委员会审定； 2项新品种成果通过6.18平台与我市相关龙头企业成果对接，加速了科技成果转化。
（四）农业机械化水平快速提高。一是农机装备水平明显提高。新增大型拖拉机74台，乘坐式插秧机60台，粮食烘干机24台，多功能拖拉机1132台，其他农业机械5000多台，预计农业机械总动力将超过78万千瓦时。二是购机补贴资金明显增长。完成各级补贴资金1500多万元，购置补贴机具4000多台套，全年完成购机补贴专项资金达2670万元，直接受益农户5000多户。三是机械化综合水平提高显著。全年机耕面积超过75万亩，水稻机插面积超过12万亩，水稻机收面积超过16万亩，水稻耕种收综合水平达到42%，比去年增长3个百分点。四是农机服务三农成效显著。实施水稻、水果、蔬菜三个省级机械化示范区建设，建设三个省级农机维修示范点，新建8个农机专业合作社，合作社规模和经济效益都走在全省前列。
（五）新农村建设步伐加快。今年以来，全市上下以“产业带动、宜居生态、新村集聚、休闲旅游、和谐文明”等五个类型村主抓9个的特色村示范村。实行市直单位挂钩和财政支持措施， 9个特色村以项目建设为抓手，9个特色村以项目建设为抓手，立足村情筛选重点建设项目，共生成项目43个，至年底已完成投资7107.5万元。
（六）莆台农业工作迈上新台阶。加大对台农业招商引资力度，以仙游国家级台湾农民创业园为平台，2012年全市共批办台资农业项目7个，总投资2000多万美元，合同利用台资500多万美元。台湾农民创业园管委会进一步加强与台商协会、台湾产业协会和农业大户经常性联系，新注册成立6家企业，主要从事甜柿等农产品的种植和销售，总投资达500多万元。举办首届甜柿文化交流节，创造条件服务台商，进一步拓展了两岸交流合作的范围和空间，在农业、旅游、文化等方面加强对接交流。
（七）农民收支水平显著提高。2012年，莆田市农民人均纯收入10311元，比上年增长13.7%；农民人均生活消费现金支出7733元，比上年增长14.6%。农民收入以工资性收入为主，占59.6%；家庭经营收入和转移性收入为辅，分别占22.3%和15.5%；财产性收入较少，占2.6%。一是工资收入增长是农民增收的主要推力。2012年，莆田市农民人均工资性纯收入为6141元，比上年增长19.3%，工资性收入对纯收入增长贡献率达79.9%,拉动纯收入增长11.0个百分点。二是农民家庭经营纯收入稳中有增。2012年，莆田市农民人均家庭经营纯收入2298元，比上年增长1.3%。三是财产性纯收入稳步增长。2012年，莆田市农民人均财产性纯收入269元，比上年增长15.0%。四是转移性纯收入持续增长。2012年，莆田市农民人均转移性纯收入1603元，比上年增长13.2%。
二、当前农业农村经济发展面临的问题
（一）农业产业化程度、组织化水平和品牌水平较低。农业产业化是生产力发展的迫切要求，是现代农业发展的必然趋势。长期以来，受财力、传统习惯、全市农村小规模生产经营方式及资金、技术、人才、信息等多方面条件的制约，农业产业化与工业产业相比发展严重滞后。农业生产规模化、机械化进展缓慢。基地建设规模小，速度慢。受长期以来以家庭为单位进行联产承包生产经营的传统模式影响，导致产业规模小而分散，很难形成种养大户，客观上制约了产业化发展，不利于形成规模，形成基地。在近几年，以土地流转为主要形式的种植大户，主要种植以蔬菜为主要品种的大户、联合体。农产品加工企业规模小，农产品初级加工多、深加工少、产品增值率低。龙头企业少，农业龙头企业实力不强，缺乏带动力强的农业产业化龙头企业，产业化水平、标准化生产仍然处于初级阶段。上规模、运行比较规范的专业合作经济组织较少，且农民经纪人大部分文化层次低，素质低，销售渠道不畅，造成丰产不增收等现象，不同程度上挫伤了农民发展农业产业化的积极性。龙头企业虽然日趋规模化，产业化，但是缺少自主品牌、品牌辐射范围小、销售渠道不够畅通，市场抗风险能力低，销售价格很难掌控，极易出现大起大落现象。
（二）农业生产“二老化”现象严重。一是农业水利设施老化。农业靠天吃饭的状况没有得到根本性改变。虽然国家对农业投入较大，但由于农业基础设施投入面广，特别是小水利设施严重老化，对农业生产影响大。二是劳动力不断转移，造成农业生产者年龄老龄化现象严重，制约着农业结构调整的步伐。尽管国家不断出台惠农扶农政策，由于种田要靠天帮忙存在一定风险，而外出打工比种田收入多、来得快、有保障，导致绝大部分农村青壮年劳力离开种植业。而从事农业生产的多半是老弱劳力，有的地方比例高达80%至90%以上，文化水平、科技素质、生产能力相对偏低，生产活动多呈现随意性、盲目性和习惯性，农村土地常年性抛荒和季节性抛荒时有发生，增加了科技推广应用的难度，制约了农业产业结构调整的步伐，也降低了土地的使用效率，削减了农民种粮收益。
（三）经济建设占用部分耕地。据有关部门资料显示：2010年批准用地2.09万亩，其中耕地面积1.26万亩；2011年批准用地2.84万亩，其中耕地面积1.18万亩；2012年1-10月批准用地1.2万亩，其中耕地面积0.63万亩。由于项目建设等用地，宜粮耕地面积不断减少，要稳住粮食种植面积难度越来越大。
（四）项目用海导致滩涂养殖面积减少。石门澳、莆头作业区等工程项目的开工，全市滩涂面积大幅减少，传统的滩涂水产养殖业进一步萎缩，海水产品养殖业发展后劲不足。
（五）农民增收难度不断加大。近年来，由于工业的大力发展，一定程度使环境受到污染，水土面积流失，耕地质量下降。加之我市农村家庭经营规模小，劳动生产率低，难以形成适度的经营规模。同时农村劳动力综合素质偏低，劳动力转移受到制约，人力资源要素难以开发利用，影响了农民收入的提高。
（六）农业成本持续上涨，种养效益空间压缩。农资价格长期高位运行，劳动力成本上升，目前劳资成本一般占种植业成本的比例超过五成。2012年，莆田市豆粕平均价格4133元/吨，比上年同期上涨31.2%。玉米价格平均2705元/吨，比上年同期上涨4.4%。饲料原料价格的持续上涨迫使饲料全面提价，养殖户的生产成本不断增加。农业生产成本的不断增长弱化惠农政策的实施效果，且会抵消农产品价格上涨给农民带来的收益，在很大程度上影响了农民农业生产投入的积极性。
（七）农业服务体系不健全。多年来，农业科技、信息、标准化生产、防疫体系建设以及农产品检测等方面的投入严重不足，农村经济体系十分脆弱，农民生产的盲目性未得到根本改变，自然风险与市场风险对农业和农村经济的冲击较大。
（八）农民贷款受到限制，影响经济的更快发展。随着农村经济快速发展，农民对贷款的需求量越来越大。但目前银行贷款额度有限，根本满足不了农民发展生产的需要。农村小额贷款是农民贷款的主要方式，但一般农户贷款并不容易，且手续繁杂。贷款难很大程度上限制了农民发展生产的积极性，影响了农村经济的更快发展。
三、农业农村经济发展问题的对策
（一）加快农业基础设施建设。在耕地面积减少、农村劳动力大量转移、土地和劳动力等要素价格逐渐上升的情况下，只有加快提高农业基础设施现代化水平，提高土地产出率和劳动生产率，改善农业生产物质条件，巩固提高农业综合生产能力，才能提高粮食和农业生产比较效益。因此，在加大对农业投入的同时，要调整结构、突出重点，加强农田水利基础设施建设，加大土地开发整合力度，改造中低产田，建设高标准农田。要加快转变农业发展方式，加快改善农业装备条件，加大对农业机械化的支持力度，快速推进社会主义新农村建设。
（二）积极推进农业产业信息化建设，加强对农业的引导和服务。农产品价格大起大落，无法保障农民持续增收，也影响市场平稳运行。要结合农村实际，在有条件的地方，逐步建立农村计算机网络。通过计算机把农业科研成果、农业生产技术、市场前景、品种预期、经济效益、产品市场容量、供需状况、价格趋势等方面信息的前期调查和预测传递给农业生产者、经营者和消费者。同时要积极开展生产、加工、销售各环节的产前、产中、产后服务，更好地为农民提供及时准确的农产品供求信息，减少农民生产经营的盲目性。
（三）继续优化农业产业结构。针对莆田市 “七海二山一分田”的自然环境特点，按照“山区学利农、沿海建牧场”的思路，积极、稳妥地搞好结构调整，继续以提高农业效益为主，大力推广“利农”模式，促进鲍鱼、花蛤、巴西菇等特色农业发展，开展全国“海洋牧场”试点，因地制宜向高效农业、特色农业、绿色农业推进，提高农产品的科技含量，增强市场竞争力。
（四）大力发展龙头企业。通过龙头企业，引导农民有组织地走向市场，有效克服农民小生产与大市场的矛盾。一是把发展龙头企业与培育区域主导产业结合起来。二是企业必须确定立足农业谋求发展的经营思路。使龙头企业向大（带动面大）、高（技术含量高）、长（产业链长）的层次发展。三是以工业化的经营理念谋发展，运用工业生产的方法管理农业企业，以市场引导生产，以流通带动生产。按照谁有能力当龙头就扶持谁的原则，实行定点培植，重点引进，尽快培育一批特色农业龙头企业。四是抓特色产业培育，扩大生产基地规模。要坚持“发挥优势，突出特色，相对集中，高产高效”的原则，因地制宜，积极推行“公司+基地+农户”的产业化经营模式，以优惠的政策，准确的落点，大力发展农业产业化龙头企业。以提高质量，优化结构为重点，走品牌化发展道路，使农业产业结构优化，规模做大，推动农业产业化不断向深度进军。
（五）继续加大农村金融贷款支农力度。当前，农村中一些能人大户不断涌现，对促进农村经济发展，带动农民增收起着非常重要的示范带头作用。特别是一些外出务工的青壮年，他们在外学到一技之长后，纷纷回乡创业，但通常会陷于资金紧张的状况。因此，要加大金融支农力度，让更多的人实现成功创业。
（六）继续增加农业投入，完善各项补贴政策。稳定发展粮食和生猪生产，完善粮食补贴政策，增加良种补贴标准和农机补贴总量，建立和完善生猪储备调节体系。加强农业支持保护，继续坚持“多予少取放活”的方针，加快建立以工促农、以城带乡的长效机制。加大财政奖励和产业化建设项目扶持力度，大幅度增加对农村地区公共服务建设项目的投入。
（七）多渠道促进农民增收。大力推进农业产业化经营，增加农民家庭经营性收入。发展农村服务业，为农民创造更多的就业机会，加大农村劳动力培训和转移力度，对有市场潜力的农林牧渔业产品实行精深加工，延长农业产业链，促进农业增值增效。
