2021年莆田社会发展和谐稳定

第六十八期
第六十八期
来源:市统计局 时间：2022-10-28 09:15
| | | |

2021年，在省委省政府和市委市政府的坚强领导下，莆田市各级各部门积极贯彻落实“俯下身子抓产业、一心一意谋发展”工作部署，努力克服疫情影响，全方位推进高质量发展超越，社会各项事业稳步发展，实现了“十四五”良好开局。

一、人居环境更加宜居

党的十八大以来，莆田深入贯彻落实习近平总书记治理木兰溪的重要理念和保护好湄洲岛的嘱托，坚决打好污染防治攻坚战，不断打造生态宜居家园。

（一）生态质量提升。2021年，全年有效监测365天，达标天数比例为98.9%，同比上升3.0个百分点。其中空气质量优、良和轻度污染天数比例分别为47.1%、51.8%和1.1％。全年环境空气质量综合指数为2.69。木兰溪、萩芦溪两大流域国省控断面水质优良比例为95%，高于全国平均水平10.1个百分点。木兰溪国省控劣Ⅴ类断面全部消除，流域水质达到历年最好水平。县级以上集中式饮用水源地水质达标率稳定保持100%。2021年城市空气质量达标天数比例为98.9%，高于全国平均水平11.4个百分点。受污染耕地安全利用率及污染地块安全利用率均达100%。累计创建“绿盈乡村”713个，占比达78.6%。

（二）生活环境优化。2021年，全市森林覆盖率逐年提高，达到60.17%。全年植树造林总面积2981.6公顷。其中，人工造林51.2公顷(含非规划林地造林45.2公顷)；更新造林面积1378.3公顷，低产低效林改造面积1552.1公顷。全市新增绿地面积413.61公顷，人均公园绿地面积15.66平方米，绿地率40.7%。市县生活垃圾无害化处理率 100%，市县污水处理率97.62%。全市共建立省级自然保护区2个，总面积208.56平方公里。有风景名胜区4处，其中，国家级风景名胜区1处、省级3处，风景名胜区总面积120.6平方公里（含海域面积）/79.7平方公里（不含海域面积）。

（三）城乡面貌更加靓丽。绶溪片区综合开发模式全省推广，木兰溪南岸土地综合整治全面推进，高铁城市新区加快建设，城市功能空间有序拓展。开工棚改2.8万套、居全省第一，有效处置重大安全隐患房屋4525栋、四类农村在建房屋3378栋，改造提升老旧小区70个；新改扩建城乡道路164公里，新增公共车位5000个、绿道40公里，城市居住更加安全、出行更加便利。完成兴化府历史文化街区一期保护修缮，绶溪公园晋级国家4A级旅游景区，新增国家级传统村落2个、省级名村16个，城市配套更加完善、内涵更加凸显。

二、教育事业齐头并进

教育强市持续推进，2021年，全市共有各级各类学校1191所，比上年增加11所；各级各类学历教育在校生69.18万人，比上年增长了3.1%；专任教师5.13万人，比上年增长了28.3%。

（一）学前教育实现普及普惠。全市共有在园幼儿12.01万人，其中公办在园幼儿7.51万人，占比达62.5%，学前三年入园率达到98.95%，基本普及学前三年教育；认定普惠性民办幼儿园240所，在园人数11.03万人，占比达91.8%。新组建15个学前教育“总园+”集团，涵盖47个幼儿园，普惠性幼儿园覆盖率达91.82%。

（二）义务教育优质均衡发展。全市已全面通过“义务教育发展基本均衡县”国家评估认定，共有201所中小学通过省级义务教育管理标准化学校验收。现有义务教育阶段学校666所，其中小学564所，初中97所，特殊教育学校5所。小学学龄人口入学率达100％，小学毛入学率100.38%。初中学龄人口入学率99.78％，初中毛入学率104.33%。九年义务教育巩固率105.92%。

（三）高中教育质量有效提升。全市普通高中在校生达74520人，高中阶段毛入学率达到96.63%。我市大力推进普通高中全达标工作，努力培育和推进我市创建高中课程改革基地建设学校，打造一批教育教学改革品牌，示范引领我市高中多样化特色发展。

（四）高教职教多点开花。首次采取互动直播的形式进行展现启动仪式，超过125万人次的观众观看直播；举办中华妈祖“恒丰华创”中职奖教奖学金颁奖仪式，营造大力发展职业教育良好氛围。深化产教融合，12家企业入围省级产教融合型企业。全市职业院校8个项目入选“福建省高水平职业院校和专业建设计划”立项建设单位名单。

（五）高等教育迈进新阶段。莆田市2所高校在校生46736人，比上年增长了18.6%，招生数15882人，专任教师1679人。成立东软现代产业学院，莆田学院首获3个硕士学位授予点，湄职院获得3项全省智能制造大赛第一名。打造“工医占优势，文管显特色”的综合性大学学科布局,建有10个省级重点（应用型）学科。

三、卫生事业稳步发展

2021年，莆田市扎实推进卫生健康事业，强化公共卫生服务，不断提升群众健康保障水平。

（一）基层卫生机构配置不断完善。年末共有各级各类医疗卫生机构1372个，其中医院63个，卫生院49个，村卫生室856个。年末共有卫生技术人员18363人，其中，执业（助理）医生6743人，注册护士8074人。年末共有医疗机构床位17692张，乡村医生和卫生员1622人。每千人口卫生技术人员5.7人，每千人口医疗卫生机构床位数5.05张，高于全省平均水平。

（二）卫生健康体系建设卓有成效。健康事业加快发展，深化“三医联动”，推进分级诊疗，提升医技人才技术水平，设立莆籍在外名医“师带徒”工作室30个，创成国家卫生乡镇3个，新冠疫苗接种突破600万人次。全市全年共报告法定甲乙类传染病发病数10284例，报告发病率320.3/10万。婴儿死亡率、5岁以下儿童死亡率分别控制在1.59‰、2.28‰，分别比上年降低0.64个和1.19个千分点；儿童免疫接种率持续在高水平，连续十一年达99%以上。百日咳、乙脑、流脑等疫苗可预防传染病发病率大幅降低，乙肝疫苗接种率达99.9%，有效地减少了儿童传染疾病的发生。

四、文化事业蓬勃发展

莆田市突出抓好艺术精品创作、公共服务效能提升、非遗保护传承等工作，扎实推动文化事业迈出新步伐。

（一）优秀艺术精品竞相涌现。一是庆祝建党百年主题系列活动成功举办。成功承办莆田市庆祝中国共产党成立100周年大型文艺晚会，莆仙戏经典折子戏亮相“梨园百花颂党恩”福建省庆祝中国共产党成立100周年戏曲晚会。二是艺术精品创作出新出彩。莆仙戏《踏伞行》获得第35届田汉戏剧优秀剧目奖，莆仙戏经典剧目《叶李娘》列入文旅部中国戏曲像音像工程；莆仙戏演员黄艳艳凭借《踏伞行》中精湛的演技，荣获第30届中国戏剧梅花奖。三是打造莆仙戏演艺新业态。在三清殿设立“莆仙戏传习所”，开展莆仙戏实景演出、文旅研学等各类实景互动活动，三清殿莆仙戏传习所元宵游园活动选入“学习强国”平台进行展播。

（二）文旅惠民公共服务水平不断提高。一是推进公共文化场馆对标提升。市群众艺术馆、荔城区文化馆、秀屿区文化馆获评国家一级馆，市博物馆晋级国家二级博物馆。二是服务效能不断提升。市博物馆累计接待观众60万人次，开展讲解服务334次；市图书馆累计借还图书141万册次，接待读者108万多人次；市群艺馆开设培训课程20多项，年均培训学员近10万人次，举办各类文化活动100多场次，服务群众约20万人次。三是乡村文化振兴有序推进。推进全域生态旅游小镇培育、金牌旅游村培育、乡村传统文化保护与开发、基层公共文化服务设施建设等工作，促进乡村文化旅游发展。

（三）文化遗产保护利用卓有成效。一是文物保护措施全面增强。全市56处革命文物列入福建省第一批革命文物目录；全年共争取各级文物保护专项补助资金718万元，发动民间力量自筹2000多万元，实施了2处国保、5处省保、15处市保单位的维修、安消防和环境整治工程。二是做好妈祖文化遗产保护。申请设立国家级妈祖文化（莆田）生态保护区。配合做好第六届世界妈祖文化论坛，举办“妈祖文化生态保护与传承论坛”和“海神妈祖”剪纸艺术作品展。三是完善非遗项目名录体系。30个项目获批第八批市级非物质文化遗产代表性项目名录，推荐申报省级第七批非物质文化遗产项目25个。积极开展非遗传承示范项目工作，新建仙游古典家具制作技艺黄福华传习所和三清殿莆仙戏传习所。

五、民生福祉保障更加殷实

莆田市全力以赴，坚决打赢三大攻坚战，补齐民生短板，办好民生实事，人民生活再上新水平。

（一）防范化解重大风险攻坚战取得突破。化解一批信贷风险，不良贷款率从峰值5.52%降至1%左右；深入开展危化品、道路交通、房屋安全等专项整治，安全事故死亡人数持续下降；扫黑除恶专项斗争圆满收官，全链条打击电信网络新型违法犯罪，社会大局更加和谐稳定。脱贫攻坚战取得全面胜利，农村建档立卡贫困人口全部脱贫、贫困村全部摘帽，提前一年实现脱贫。对口帮扶、山海协作任务全面完成。

（二）民生福祉不断增强。每年新增财力70%以上用于民生支出，累计投入845亿元。城镇累计新增就业10万人，居民人均可支配收入年均增长8%。建成农村幸福院580个，新增养老床位5000张，领取养老金人数突破60万人。人均体育场地面积由1.68平方米提高至2.32平方米。建成“党建+”邻里中心103个、“综治+”治理中心58个。荣膺全国双拥模范城“六连冠”。
