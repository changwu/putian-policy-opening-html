2021年莆田市建筑业发展情况分析

第九期
第九期
来源:市统计局 时间：2022-01-28 09:03
| | | |

2021年，我市建筑业企业面对复杂严峻的国内外环境，克服困难，坚持在常态化疫情防控中紧跟步伐、寻找机遇，主动开拓市场，推动建筑行业保持健康发展。

一、总体运行情况

建筑业总体增速较前三季度有所回落。根据快报统计，截止12月底，全市总专包资质建筑业企业511家，同比增加17家。2021年,莆田市建筑业企业（指具有资质等级的总承包和专业承包建筑业企业，不含劳务分包建筑业企业，下同）完成建筑业总产值839.99亿元，同比增长9.2%，增幅位居九地市第七，增幅较前三季度回落1.7个百分点。增速回落的原因：招投标市场开放以来，全市大型PPP或EPC项目几乎都被央企中标，而反观本地企业，行业整体规模小，承包工程范围窄，项目中标概率低，现状堪忧，严重影响全市建筑业产值增长。

图1  各季度建筑业总产值及增速

 

从2021年各季度建筑业产值发展情况（图1）来看，受新冠疫情及本地企业中标难影响，今年建筑行业压力加大，建筑业总产值增速从首季起呈现逐月回落的态势。由于2020年初受新冠疫情影响大，2021年1季度产值基数小，产值增速高达33.5%。1-2季度产值增速回落14.1个百分点，1-3季度受本地突发新冠疫情影响，产值增速较1-2季继续回落8.5个百分点，特别是仙游县身处疫情中心影响最大，秀屿区也受波及较大，产值增速分别仅为1.2%、2.1%。尽管突发疫情在短期内有效控制，但是2021年本地企业中标情况不理想，全市公共资源进场交易工程建设项目中，外地企业中标数量和金额占全市总量的比重分别为80%、91.4%，本地企业发展后劲小，新签合同额普遍下滑，全年产值增速较前三季度微降至9.2%。

其他主要经济指标情况。全市建筑工程产值完成807.19亿元，增长8.9%，增速较上年提高12.3个百分点，占总产值比重高达96.1%，较上年回落0.3个百分点。装饰装修产值完成4.22亿元，同比下降11.6%，比上年回落49.9个百分点，占总产值比重仅0.5%，较上年回落0.1个百分点。从行业分类来看，2021年，房屋建筑业资质企业完成建筑业总产值706.92亿元，同比增长11.4%；土木工程建筑业完成产值121.04亿元，同比下降0.6%；建筑安装业完成产值1.19亿元，同比增长39.4%；建筑装饰、装修和其他建筑业完成产值10.84亿元，同比下降10.8%。从各行业占比来看，2021年，房屋建筑业完成建筑业总产值占比84.2%，较上年提高1.7个百分点；土木工程建筑业占比14.4%，较上年下降1.4个百分点；建筑安装业占比0.14%，较上年提高0.03个百分点；建筑装饰、装修和其他建筑业1.3%，较上年下降0.3个百分点。

二、亮点及问题

亮点一：特级企业拉动产值增长作用明显

2021年，涵城建设、巨岸建设及中交建宏峰3家特级企业产值均超过50亿元，合计完成产值188.59亿元，占比0.6%的企业数完成全市产值的22.5%，贡献率35.6%，拉动建筑业总产值增长3.3个百分点。大型建筑企业将经营的触角逐步伸向建筑行业的各个领域，随着企业改革的逐步推进，这些企业实力将不断增强，在建筑行业发挥更大的作用。

亮点二：外拓工程几乎覆盖全国各省（区、市）

2021年，全市建筑业在外省完成产值485.84亿元，增长17.7%，增速同比回落20.1个百分点，占总产值比重57.8%，比重提高3.8个百分点。尽管外拓产值增速同比回落大，但占比有所提高，外省完成产值依然发挥重要作用。在省外承揽工程施工已覆盖30省（区、市），仅西藏未承建工程，在江西、广东、浙江三省完成产值均超过50亿，合计256.90亿元，占全部外拓产值的52.9%，占比较去年提高10.3个百分点。

问题一：建筑业发展后劲明显不足

2021年全市资质建筑企业新签合同额957.15亿元，同比下降6.2％，增幅较上年回落31.1个百分点。承建的房屋建筑新开工面积2066.45万平方米，同比下降5.2%，增幅较上年回落18.2个百分点。从县区来看，仙游县、荔城区及北岸本年新签合同额下降幅度较大，分别下降43.0%、34.1%及24.8%。从企业来看，由于仙游建工、凡士建设等5家企业2021年度新签合同额较上年大幅减少，少签合同均超过20亿元，合计减少209.50亿元，占全市新签合同额的21.9%。同时仙游建工、中建华鸿等4家企业2021年度新开工面积较上年大幅减少，减少量均超过60万平方米，合计减少356.58万平方米，占全部新开工面积的17.3%。建筑行业发展后劲不足，发展前景不容乐观。

问题二：倒闭(停业）企业比重较上年大幅上升

2021年度全市有58家建筑企业产值为0，占全部企业数的11.4%,比重较上年提高6.1个百分点。受整体经济大环境及招投标市场全面开放影响，市场竞争日趋激烈，本地中小企业综合实力不如外来央企、国企，承揽新项目特别是大型项目的难度不断加大。加上国内多地拉闸限电措施的进一步执行，供应端进一步收紧，建筑业原材料价格涨势汹涌，市场资源也愈发紧张，部分本地建企面临倒闭的风险。

问题三：全年行业利润下降，利润率略有下滑

2021年，全市建筑业企业营业收入648.32亿元，同比增长2.5%，实现利润25.92亿元，同比下降0.2%。产值利润率3.1%，较上年同期回落0.3个百分点（去年数据用年报数代替）。

三、各县区建筑业企业生产情况

从注册地产值数据来看，2021年荔城、涵江两区建筑业依然领跑全市，建筑业总产值分别为200.45亿元、199.77亿元，增速分别为6.1%、9.4%，两区产值合计占全市总产值的47.6%。从增速来看，增速较高的县区有湄洲岛、北岸及城厢，分别达117.9%、22.6%及16.0%。

四、对策建议

从整体数据来看，由于建筑业总产值的统计口径是按注册地统计，尽管全市加大投资力度，但几乎大项目都由央企承建。也就是说，所有这些大型项目的建筑业总产值将统计到央企的注册所在地，同时本地企业中不到标，不少企业面临濒临倒闭的状态。建议各县区政府在引进项目的同时，重点扶持市内龙头企业，提高与央企抗衡的实力，争取2022年本地企业的大型项目中标率提高，纳入本地建筑业总产值统计范围。同时，从统计数据来看，2021年全市在统计库“白名单”建筑企业产值同比增长5.6%，增速较全市资质建筑业总产值低3.6个百分点。尽管我市住建部门按照市委市政府部署要求，积极开展“白名单”企业帮扶行动，但从统计数据来看，成效并不显著。建议各县区主管部门了解企业运营及利用帮扶政策情况，适时调整原有“白名单”企业相关规定。

从龙头企业数据来看，防止大型建筑企业外迁十分重要，这不仅仅影响产值，也造成税收收入的流失，更是人才的外流。住建部门及各县区要采取各种有效手段，防止本地龙头企业外迁。建议：一要提升服务。政府的服务质量是关键。要变管理为服务，让企业感受到本地发展的环境和空间会越来越好。同时要深入了解企业需求，在引导企业提高实力的基础上，切实解决实际困难。二要适时变通。当企业做到一定规模，对信息政策资源的要求越来越高，本地已不能满足时，可以和企业商讨折衷的做法，如，大城市为主要经营地或设立办事机构，而企业注册地设在本地。这样既可以吸收大城市的信息政策优势，又能防止产值、税收等数据的减少。三是减少内耗。各县区不要引进本市其他县区的建筑企业，市内企业迁来迁去，造成市内资源内耗，对本市建筑企业长期发展不利。

从外拓企业数据来看，外拓工程不仅仅要靠大型企业的打拼，更需要政府的服务支持。具体来讲，一是多渠道助力企业定位。如何锁定工程多、竞争少的外拓区域，如何锁定竞争少又稀缺的细分领域，引导中小企业走专业化、差异化特色之路。我市以中小建筑企业居多，只要企业坚持用自身有限的资源做专做精，同样可以在专业领域形成足够的竞争优势。建议政府及相关部门多方获取信息资源，为企业指引未来努力的方向。二是多渠道助力企业融资。市统计局做过的建筑企业营商环境调查数据显示，建筑企业对本市的投融资环境满意度偏低。建筑业企业融资难是行业内的普遍现象。建议：一要强化政府监督职能，健全法律制度，对长期拖欠工程款的业主，制定相应的制约政策。二是根据中小企业抵押物少的情况，制定完整的建筑企业信用评价体系，出台针对该类企业的灵活贷款政策。根据企业信用分的高低，可采取投资补助、基金注资、担保补贴、贷款贴息等多种不同的助力方式。

从新增企业数据来看，适当新增有工程量的企业是必要的，但把所有小企业甚至空壳企业都纳入统计一套表库不是必须。建议各县区住建局做到：一要定期跟踪。及时跟进小企业的承接工程情况，如有工程应及时通知企业向各县区统计局申报材料，尽快入库。二要量体裁衣。根据企业自身情况，引导中小企业制定未来发展方向。或资源整合多家企业抱团取暖，做大做强；或探索优势细分领域、有发展空间领域，做专做细。
