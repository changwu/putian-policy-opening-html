2016年莆田市房地产运行情况分析

第一期
来源：本网 时间：2017-01-19 08:47
| | | |

我市房地产业在去库存的主基调下，实行供给侧改革，推出多项利好政策，房屋销售形势有所好转，库存压力有所缓解，但县区间分化现象仍较为突出，房地产开发项目减少，土地购置费用下降，房地产投资增速回落，成为我市房地产业喜中存忧的关键问题，亟需我们重点关注。

一、喜的方面

1. 利好政策刺激掀起销售潮。2015年来，从降低首套房首付比例，到下调契税，从提升公积金贷款额度，到降准降息，房地产利好政策频出，为房地产行业吹来阵阵暖风。2016年伊始，房地产销售情况便呈现一幅欣欣向荣的景象。1-12月，我市商品房销售面积为385.03万平方米，同比增长30.2%。本月商品房销售面积38.85万平方米，保利城二期、香港财富中心吉第（B地块）、青山官邸、南兴国贸中心、正荣府、骏乘华府、华永天澜城二期、万科城G地块、碧桂园浪琴湾、莆田富力尚悦居10个项目本月商品房销售面积超过1万平方米，合计19.6万平方米，占本月商品房销售面积的50.5%。是商品房销售面积增长的主要动力。

其中住宅销售面积324.93万平方米，增长23.5%；办公楼19.11万平方米，增长112.1%；商业营业用房29.36万平方米，增长80.9%；其他房屋11.64万平方米，增长60.6%。住宅销售面积占商品房销售面积的84.4%，其中90平方米以下16.78万平方米，增长8.6%；144平方米以上54.93万平方米，下降8.4%。反映出现阶段面积较小的户型受到消费者的热捧。

2016年我市房地产销售情况


单位：万平方米

2. 供给侧改革化解库存压力。化解房地产库存是2016年国家经济工作的五大任务之一，在供给侧改革的大潮中，政府积极引导房地产企业顺应市场规律，调整投资销售策略，推出适应市场需求的优质房源，同时鼓励企业兼并重组，提高产业集中度，保障房屋品质。这些举措将进一步缓解库存压力。1-12月，房屋待售面积为211.63万平方米，同比下降30.8%。其中，住宅待售面积94.03万平方米，同比下降35 %。待售1-3年(含1年)面积111.67万平方米，下降24.2 %；待售3年以上(含3年)面积16.78万平方米，下降19.4%。待售面积减少，使得房地产消化库存压力变小。

3. 棚户区改造释放刚性需求。随着我市棚户区、城中村改造和旧住宅小区综合整治力度不断加大，货币化补偿方式让更多的人进入房地产市场自由选择，无论是首套房购置还是改善性住房需求，惠及面如此巨大的政策，进一步降低了购房门槛，使得此前部分持观望态度的潜在置业者果断出手，刚性需求也得到显著释放。

二、忧的方面

 1. 新增项目减少，投资情况低迷。房地产投资销售呈现冰火两重天，房地产销售快速增长，而房地产投资却出现负增长。1-12月份，房地产开发投资完成353.31亿元，同比下降15.1%，增速较上月下降0.7个百分点，低于全省平均水平17.8个百分点，增速居全省第7位。

按工程用途分 ，1-12月，全市住宅投资232.04亿元，下降6%。其中90平方米以下投资37.43亿元，下降2.7%；144平方米以上投资47.67亿元，增长28.2%。办公楼投资29.65亿元，下降0.6%；商业营业用房投资42.18亿元，下降34.4%，其他用房投资49.43亿元，下降34.1%。

从构成看， 1-12月，建筑工程投资237.21亿元，下降19%；安装工程投资31.42亿元，增长10.9%；设备器具购置投资5.72亿元，下降8.4%；其他费用78.96亿元，下降10.8%。

房地产业1-12月份新增项目5个，5个新增项目计划总投资28.94亿元，其中只有一个仙游县鲤城的香港财富中心计划总投资超过10亿元；其次城厢区南兴国贸中心计划总投资5亿元，仙游县万晨伯爵山计划总投资4亿元，城厢区凤达豪园三期计划总投资3.6亿元，城厢区宏基现代城计划总投资0.28亿元。而作为莆田中心老城区的荔城区没有一个新增项目。新增项目减少，规模较小也成为房地产投资低迷的主要原因。

从各县区的房地产开发投资情况看（按项目属地统计原则），所有的县区都呈不同程度的比降，其中城厢区完成投资115.77亿元，下降15.2%；涵江区完成投资61.92亿元，下降4.9%；荔城区完成投资106.7亿元，比降15.2%；秀屿区完成投资8.14亿元，下降25.5%；；仙游县完成投资52.16亿元，比降23.9%；北岸完成投资8.61亿元，下降3%。我市房地产开发投资主要集中在城厢区和荔城区，两个县区合起来房地产开发投资占全市房地产开发投资超过六成，达到62.9%。虽然涵江、秀屿、仙游和北岸增速较快，但与中心城区相比仍有较大差距，有待于加大自身发展力度，吸引更多房地产投资。

2．房屋新开工面积和竣工面积下降明显

1-12月，房屋新开工面积为429.11万平方米，同比下降26.8%。其中住宅新开工290.73万平方米，同比下降15.1%；商业营用房33.38万平方米，同比下降62.9%；其他房屋新开工85.46万平方米，同比下降33.1%。

1-12月，房屋竣工面积为131.50万平方米，同比下降39.3%。其中，住宅竣工面积73.35万平方米，同比下降53.6%；商业营用房13.45万平方米，同比下降48.5%；其他房屋竣工面积27.06万平方米，同比下降15.8%。由于竣工面积可以作为衡量短期内新增供应量的指标，这表明中短期内商品房市场供给将有所减少。

3．商品房批准预售降幅收窄

由于商品房新开工面积下降，批准预售面积也随之比降。2016年全市商品房批准预售面积308.87万m2，较去年同期比降27.2%，降幅较上半年（-45.8%）回升近19个百分点；其中批准商品住房面积253.90万m2，比降9.8%，降幅较上半年（-22.2%）回升约12个百分点。按季度分，第一季度为101.49万m2，第二季度为43.41万m2，第三季度为87.56万m2，第四季度为76.41万m2。

从各县区的批准预售面积看，除仙游县同比增长外，其他县区都呈不同程度的比降，荔城及秀屿同比下降超过50%。其中仙游71.40万㎡，比增26.1%；城厢83.20万㎡，比降11.1%；涵江70.19万㎡，比降14.2%；荔城69.88万㎡，比降52.6%；秀屿（含北岸）14.20万㎡，比降68.3%。

4.到位资金下降，土地购置费减少。1-12月全市房地产开发土地购置费57.4亿元，同比下降20%。从资金方面，1-12月，本年资金来源425.46亿元，同比下降7.8%。从资金来源来看，国内贷款为43.85亿元，同比下降29.4%；自筹资金为220.37亿元，同比下降6.3%，其中自有资金68.15亿元，同比下降39.9%；其他资金来源161.25亿元，同比下降16.1 %，其中定金及预收款77.4亿元，同比增长11.2%，个人按揭贷款48.44亿元，同比下降13%。

5．高资质企业少，整体竞争力偏弱。房地产开发企业门槛低，我市项目型房地产公司较多，企业规模小，资质等级普遍不高，综合竞争力较弱。截至2016年底，我市220家房地产开发企业中一级资质的企业没有1家；二级62家，占28.2%；三级10家，占4.5%；四级及以下资质企业148家，占67.3%。高资质企业少，行业集中度低的情况在供给侧改革中亟需改变。

四、若干建议

1. 优化供给侧资源配置，提高项目投资效率。房地产项目是保持固定资产投资增长和增强发展后劲的重要力量，今年是“十三五”开局之年，面对经济新常态，机遇与挑战共存，建议各县（市、区）针对自身不同困难和矛盾的实际，从远期着手积极谋划，围绕总量和区域分布优化布局，进一步强化对供给侧各投资要素的支持和保障，不断加快结构调整步伐，提高项目投资效率，为投资转型升级和可持续发展奠定扎实基础。

2. 进一步完善公共交通，加强基础设施建设。在引导房地产供给侧结构调整的同时，继续推进公共交通建设，进一步提高郊区出行便捷程度，并完善相应的配套基础设施，提升郊区房地产软实力，增强置业吸引力。同时，改善存量房楼盘交通条件及其周边公共产品和服务设施建设、环境景观建设等方面，加快城市工商业产业的集聚，形成工商业产业集群，通过“大众创业，万众创新”提高城市就业人口的吸纳能力，以更多的、相对稳定的就业岗位吸引新市民，为房地产业持续发展提供持久动力。

3. 积极引导消化存量房，促进行业转型升级。一是落实国家金融、税收、住房公积金等政策，加大个人购房贷款支持力度，优先满足自住和改善性住房的信贷需求，增强购房者支付能力。二是鼓励和引导滞销用房向社区养老、医疗、职工社区等新兴业态转化。三是加快培育和发展住房租赁市场，实现销售模式及空置房管理办法的多样化，培育专业化、规模化的住房租赁经营企业，采取“以租代售”、“租售两全”等新的租售模式，形成商品房买卖和租赁齐步发展的房地产市场格局。

4. 培育房地产资质企业，加强监管防范风险。房地产业属于投资密集型产业，大型企业资金来源相对稳定，在目前商品房市场调整期，资金回笼周期加大的状况下，大型房地产企业占市场主要份额能起到稳定市场的作用，建议引导企业转变观念，树立形象及品牌效应，通过兼并重组等方式培育高资质房地产企业。同时，金融部门也应强化区域性房地产市场及信贷风险的监测和预警，定期开展风险评估，加大对开发企业资金链的排查力度，防控企业资金链断裂造成的社会问题，及时防范和化解房地产金融风险。
