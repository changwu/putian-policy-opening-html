文化热背后的冷思考

来源:统计局 时间：2012-01-13 09:57
| | | |

2011年10月，党的十七届六中全会审议通过了《中共中央关于深化文化体制改革推动社会主义文化大发展大繁荣若干重大问题的决定》，从而将发展文化产业的紧迫性、重要性提上了一个新的高度。《决定》的产生，对近年来我市市委、市政府对于各项文化事业发展一以贯之的关注和重视而言，起到了承上启下的作用。

2010年，我市共有文化产业单位数3291个，居全省第五位，较2008年第二次全国经济普查时增长29.9%；共有从业人员5.43万人，居全省第五位，增长62.1%；资产总计103.17亿元，居全省第六位，增长160.3%；创造主营业务收入173.47亿元，居全省第四位，增长127.6%；实现文化产业增加值54.27亿元，居全省第四位，增长173.8%；占当年地区生产总值的比重为6.6%，较2008年上升三位，居全省首位。2011年上半年，我市文化产业发展再传捷报。1-6月份共实现文化产业增加值39.31亿元，居全省第四位；占同期地区生产总值的8.0%，居全省第一位，并远远高出全省4.7%的平均水平。

在肯定成绩的同时，我们也要清醒地看到，当前我市的文化产业存在着一些亟待解决的问题，如管理体制尚未健全、三层结构比例失衡、产业同质化隐患初显等。这些问题都在一定程度上制约着我市文化产业的长足发展，基于此，本文意从浅析当前我市文化产业发展的瓶颈出发，探求破解发展难题的对策，为党政领导的下一步决策作抛砖引玉之效。

一、成立专门领导小组是引导文化产业发展的基础

作为时下最炙手可热的一个概念，文化产业的定义是：按照工业标准，生产、再生产、储存以及分配文化产品和服务的一系列活动，它涵盖了包括文艺、科技、旅游、演艺、传媒、互联网等诸多领域。在当前混合经济的大背景下，这些领域因其主管部门的不同，在统筹规划上面临着行业跨度大、涉及部门多的实质性难题。

纵观我省九个地市，已经成立文化产业发展专项领导小组的有厦门、福州、三明等地，而且随着文化产业在各地战略地位的不断提高，政府统一引导将成为今后一个时期的普遍趋势。因此，成立专门的文化产业领导小组，是引导我市文化产业进一步发展的必然要求。

一是健全机制，统筹规划。成立由市政府领衔、各部门共同参与的领导机构，不仅能从政策、人力、后勤上加以保障，还能实现部门间资源共享，提高办事效率。加快落实各项文化基础配套设施的建成，特别是大型文化场馆、乡镇文化站的建立，为文化产业的良性发展提供丰富的载体。

二是明确分工，落实责任。各成员单位根据自身的工作特点，统一部署，明确职责，落实责任，既能避免权利交叉，也可以杜绝推诿扯皮现象的发生。

三是服务企业，引进人才。作为引导产业发展的专项机构，领导小组同时还应担负起服务企业和引进人才的双重责任。一方面，帮助企业树立品牌、分析行业发展现状、指导企业走出困境是从“莆田产品”到“莆田出品”转变的必要流程；另一方面，只有以积极、优惠的政策吸引人才扎根莆田、服务莆田，文化产业发展才能真正摆脱“无源之水”的窘境。

二、挖掘核心层和外围层是均衡文化产业结构的前提

文化产业按照各类文化活动的特征和同质性，可以划分为核心层、外围层与相关层，也即传统产业、新兴产业和相关产业。2010年，我市核心层、外围层以及相关层分别为5.28亿元、4.95亿元、44.04亿元，分别比2008年增长52.2%、116.2%、213.0%；三个成分的比值由2008年的17.5:11.6:70.9变成2010年的9.7:9.1:81.2，全省排名分别为第九位、第九位、第一位，结构失衡可见一斑。无独有偶，2010年我省文化产业中，十大文化产业增加值占总增加值的68.7%，其中，工艺美术、演艺娱乐、出版发行、文化旅游等行业分别以185.12亿元、49.74亿元、42.2亿元、40.08亿元位列前四位。而在我市的文化产业结构中，除工艺美术行业占据主导地位外，位于核心、外围层次的旅游、演艺、出版、广告、动漫等行业均难以在全省范围内形成竞争力。因此，在确保以古典家具生产和珠宝销售为代表的相关层占据主要战略位置的同时，我们也要深入挖掘文化产业的核心层和外围层，激发这两者的潜力，避免文化产业竞跑彻底沦为工业、贸易业的博弈，从而推动我市文化产业更好更快发展。

一是繁荣文艺创作，浓郁文化氛围。加大财政投入，帮助文艺团体摆脱经费捉襟见肘的尴尬局面；主办各类活动，加大对本土文艺家特别是青年文艺家的挖掘和鼓励力度，形成浓厚的文艺氛围；定期投入专项资金，用于扶持优秀文艺工作者的专著出版和课题研究，重点推出在省内乃至国内都具备一定影响力的本土文化名人，提高地区知名度。积极扶持民间性质的文艺活动，关注那些常年在外塑造“无兴不成商，无莆不成市”的莆田形象而又心系桑梓的“儒商”及其发起的民间文艺活动，如被福建电视台和人民网等先后报导的张坚诗歌奖，在办好政府性文艺活动的同时适当地分一瓢羹给民间活动，树增民间文艺发展的信心和空间。主动与其他地区交流，以“映像·仙游”、“映像·莆阳”等采风活动为前奏，积极与省内外文艺名家合作，共同策划一系列具有影响力的文艺活动，使莆田文艺界打破“自娱自乐”的现状，塑造莆田文化新品牌。积极发展报刊发行业，创办一批时代感强、生活性强的综合性刊物，并以动车为载体，走近旅客，走出莆田，成为对外宣传莆田的一个窗口。

二是整合旅游资源，给力旅游经济。加大旅游开发力度，以湄洲岛国家旅游度假区、工艺城、南少林、妈祖新城、九鲤湖、九龙谷等为重点开发对象，重点跟进湄洲岛、莆田工艺美术城申报国家5A级旅游区的工作进度；挖掘整合旅游资源，依托“莆田三十六景”评选，开辟沿兴化湾、平海湾、湄洲湾的滨海旅游风景线以及闽中革命纪念红色旅游线路，开发仙水洋、龟山寺等自然、人文景观，重新策划一批旅游精品线路，助力旅游营销；进一步完善旅游食、住、行、游、购、娱等配套设施建设，引进大型酒店、购物中心、娱乐场所、旅行社等项目落户莆田；加大宣传推介力度，依托“中国·湄洲妈祖文化旅游节”树立妈祖文化旅游品牌，借力电视剧《妈祖》的拍摄和放映，积极开拓国内外客源市场；加强区域旅游合作，对接全省“五区二带”旅游发展格局，进一步加强与省内周边城市和华东四省区域间的旅游协作，延伸旅游线路，加快与其他地区旅游交流与合作步伐，持续扩大莆田旅游的影响力和竞争力；进一步深化闽台“五缘”联系，打好“对台牌”，通过举办“湄洲妈祖·海峡论坛”、“天下妈祖回娘家”、妈祖文化旅游节等活动，积极推动两岸通航，拓展两岸人员往来，为两岸经贸、旅游、文化交流与合作提供新平台。

三是提升娱乐品位，发展演艺事业。大力扶持莆仙戏演艺事业，充分发挥巴黎中国戏剧节载誉而归的余热，加强对民营剧团生存现状的调研，解决民营剧团的后顾之忧，使“活化石”更好地为市民服务；鼓励大型经纪公司落户莆田，积极发展演艺经纪服务，承办各类个唱、商演，为“文化莆田”注入新的生机；依托莆仙大剧院、莆田市体育场为载体，以闽台“五缘”为基础，吸引大型对台节庆晚会、台湾歌手演唱会等文艺、商演活动来莆举行，打造内地对台文化交流第一平台，积极推动演艺和旅游事业。

三、确立地域品牌特色是避免文化产业同质化的关键

自2010年起，我市文化产业稳居全省第四名，与漳州同位于文化产业第二梯队。一方面，产业增加值已远远拉开与位于第三梯队的三明、宁德、龙岩、南平等地的距离；另一方面，与福厦泉等第一梯队城市相比尚有一大截差距。特别是今年来，受全球经济不景气影响，我市文化产业的主要组成部分之一——古典家具制造业也受到了冲击。首先，木材原料的减少以及木材原价的攀升，使得供给曲线一再左移；其次，作为价格弹性高的商品之一，出厂价的拔高也对需求量产生了一定的制约因素；最后，粗放性管理和家族性管理也是我市古典家具企业难以做大做强的重要原因，产业同质化的苗头已初现端倪。2011年9-11月份，我市规模以上工业家具制造量分别为14210件、14100件、16515件，同比分别下降4.2%、12.7%、10.7%；1-11月份木制品累计出口4263万美元，同比下降22.34%。如何再次提升文化产业，实现质与量的双重跨越，是今后一个时期应该重点思考的问题。

一是制定行业规划，引导产业发展。通过制定行业规划，对具备竞争力的产业予以政策倾斜，加大对企业自主知识产权的保护力度。加强对规模以下企业、个体户的调研和统计监测，发现每个行业存在的问题，积极探究解决途径。加强市场监管，引导行业良性竞争，保护好“莆田品牌”的权威性和纯洁度。

二是打造产业基地，凸显集聚效应。充分发挥我市的行业资源优势，因地制宜，打造一批具备一定规模的文化产业基地，发展文化产业总部经济，不断扩展产业链。建成一批带动性强的文化产业项目，积极推动文化产业成为支柱产业。建立功能齐全的行业标准认定、营销、物流及信息共享平台，助推企业做大做强。鼓励企业自主创新，提高文化产业的创意附加值，巩固和扩展产品的市场空间。

三是确立地域特色，发挥品牌效应。以“一县（区）一特色，各县（区）共发展”为核心，重点发展仙游县古典家具制造业、秀屿区金银珠宝加工业、荔城区工艺美术销售业以及湄洲岛文化旅游业，由文化资源丰富的县区带动文化资源稀缺的县区共同发展。扩大中国木雕之城、中国古典家具之都等品牌效应，推动全市文化产业集聚发展。
