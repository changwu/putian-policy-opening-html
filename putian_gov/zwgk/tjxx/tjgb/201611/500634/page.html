2015年莆田市国民经济和社会发展统计公报

来源：本网 时间：2016-03-11 11:12
| | | |
 

莆田市统计局

国家统计局莆田调查队

2016年3月7日

一、综合

人口保持低速平稳增长。年末全市常住人口287.0万人，比上年末增加2.0万人，增长0.7%，增幅与上年持平。其中，城镇常住人口162.4万人，占总人口比重为56.60%，比上年末提高1.3个百分点。全年人口出生率为13.6‰；死亡率为6.4‰；自然增长率为7.2‰。

国民经济稳定增长。初步核算，全年实现地区生产总值1655.16亿元，比上年增长10.5%。其中，第一产业增加值115.12亿元，增长2.0%；第二产业增加值949.33亿元，增长10.5%；第三产业增加值590.71亿元，增长12.1%。人均地区生产总值57873元，比上年增长9.7%。第一产业增加值占地区生产总值的比重为6.9%，第二产业增加值比重为57.4%，第三产业增加值比重为35.7%。

产业结构优化。“十二五”期间，全市地区生产总值年均增长12.2%，低于“十二五”计划目标3.8个百分点。其中三次产业年均分别增长2.7%、14.2%和11.2%。三次产业结构由2010年的10.3∶56.1∶33.6调整为2015年的6.9∶57.4∶35.7。

 

战略性新兴产业发展良好。全年全市规模以上工业中战略性新兴产业实现增加值104.94亿元，比上年增长9.4%，占地区生产总值的比重为6.3%。

电子商务交易保持活跃。初步统计，全年全市电子商务交易总额676亿元，比上年增长45.7%。限额以上批发和零售企业实现网上零售额51.95亿元，增长56.5%。“正统网”入驻电子商务企业421家。

就业继续增加。全年城镇新增就业2.22万人，有2535人下岗人员实现了再就业。年末城镇登记失业率为2.19%，比上年末上升0.20个百分点。

 

居民消费价格温和上涨。全年居民消费价格比上年上涨1.5%，其中食品价格上涨2.8%。工业生产者出厂价格下降0.5%。

一般公共预算收入平稳增长。全年一般公共预算总收入185.20亿元，比上年增长5.8%，其中，地方一般公共预算收入115.65亿元，增长4.8%；一般公共预算支出188.20亿元，增长19.2%。全市国税总收入（含海关代征）104.13亿元，增长1.7%；全市地税系统组织各项收入109.84亿元，增长5.1%。

“十二五”期间，一般公共预算总收入累计达到745.75亿元，地方一般公共预算收入累计达到462.24亿元，一般公共预算支出累计达到703.47亿元，分别是“十一五”时期的2.7倍、2.9倍和2.9倍，年均增速分别为18.8%、19.4%和18.9%。

二、农业

农业生产总体较好。全年农林牧渔业完成总产值209.93亿元，比上年增长2.2%。粮食种植面积70.99万亩，比上年减少1.44万亩，其中稻谷面积39.57万亩，减少1.56万亩；油料种植面积24.62万亩，增加0.25万亩；蔬菜种植面积59.24万亩，增加3.91万亩。

全年粮食产量27.14万吨，比上年减少0.62吨，下降2.2%。其中，稻谷产量16.79万吨，减产0.72万吨，下降4.1%。

三、工业和建筑业

工业生产稳定增长。全年全部工业增加值782.87亿元，比上年增长10.3%。规模以上工业增加值增长10.8%。在规模以上工业中，分经济类型看，国有控股企业下降0.4%；国有企业下降13.4%，集体企业下降3.3%，股份制企业增长14.4%，外商及港澳台商投资企业增长1.9%；私营企业增长21.2%。分轻重看，轻工业增长11.7%，重工业增长8.6%。分门类看，采矿业下降20.5%，制造业增长11.4%，电力、热力、燃气及水生产和供应业增长4.5%。工业产品销售率98.65%，比上年下降0.29个百分点。

规模以上工业的33个行业大类中有16个增加值增速在两位数。其中，化学原料和化学制品制造业增长84.4%，文教、工美、体育和娱乐用品制造业增长43.7%，纺织服装、服饰业增长16.5%，电力、热力生产和供应业增长11.2%，木材加工和木、竹、藤、棕、草制品业增长24.4%，非金属矿物制品业增长24.8%。规模以上工业十大产业集群实现增加值767.62亿元，增长11.1%。其中，制鞋产业实现增加值184.60亿元，增长10.1%；木材浆纸实现增加值46.80亿元，增长15.6%；食品医药产业实现增加值101.44亿元，增长10.1%；电子信息产业实现增加值59.00亿元，增长9.3%；化工产业实现增加值73.10亿元，增长20.8%；能源产业实现增加值58.98亿元，增长4.5%；纺织服饰产业实现增加值52.49亿元，增长18.3%；机械装备制造业实现增加值66.59亿元，增长6.1%；工艺与创意产业实现增加值112.86亿元，增长16.9%；金属冶炼及压延加工业实现增加值11.76亿元，下降25.4%。高技术产业实现增加值60.79亿元，比上年增长10.8%。

全年规模以上工业企业实现利润139.03亿元，比上年增长24.9%；其中国有控股企业22.58亿元，下降1.6%；国有企业0.22亿元，下降8.3%，集体企业0.07亿元，增长16.7%，股份制企业97.47亿元，增长3.1%，外商及港澳台商投资企业36.89亿元，增长12.3%；私营企业21.37亿元，增长70.8%。规模以上工业企业每百元主营业务收入中的成本为86.99元，主营业务收入利润率为5.51%。

“十二五”期间，全市工业增加值年均增长13.3%，建筑业增加值年均增长17.9%。

五、国内贸易

市场销售平稳较快增长。全年社会消费品零售总额558.85亿元，比上年增长12.2%。按经营地统计，城镇消费品零售额492.82亿元，增长12.7%；乡村消费品零售额66.03亿元，增长8.5%。按消费形态统计，商品零售额509.46亿元，增长12.4%；餐饮收入额49.39亿元，增长10.5%。

在限额以上企业商品零售额中，体育、娱乐用品类零售额比上年增长5.2%，服装鞋帽针纺织品类增长38.7%，金银珠宝类增长100.6%，家具类增长44.7%，通讯器材类零售额比上年增长55.1%，粮油食品类增长21.8%，日用品类增长14.1%，家用电器和音响器材类增长27.6%，化妆品类增长2.0%，汽车类增长9.6%，石油及制品类下降24.5%。

“十二五”期间，全市累计实现社会消费品零售总额2233.62亿元，相当于“十一五”时期的2.1倍，五年间社会消费品零售总额年均增长14.0%。

六、对外经济

进出口总额下降。全年进出口总额297.04亿元人民币，比上年下降7.7%；以美元计价为47.95亿美元，比上年下降7.7%。其中，出口196.17亿元人民币，下降3.6%，以美元计价为31.65亿美元，下降3.6%；进口100.87亿元人民币，下降14.9%，以美元计价为16.30亿美元，下降14.9%。进出口顺差95.30亿元人民币，以美元计价为15.35亿美元，比上年增加1.53亿美元。

九、人民生活和社会保障

居民收入继续增加。全年全市居民人均可支配收入21691元，比上年增长8.6%；扣除价格因素，实际增长7.0%。按常住地分，农村居民人均可支配收入13882元，比上年增长8.2%，扣除价格因素，实际增长7.1%；城镇居民人均可支配收入29272元，比上年增长8.9%，扣除价格因素，实际增长7.2%。全市居民人均生活消费支出16124元，比上年增长7.9%，扣除价格因素，实际增长6.3%。按常住地分，农村居民人均生活消费支出11952元，增长7.5%，扣除价格因素，实际增长6.4%；城镇居民人均生活消费支出20210元，增长8.5%，扣除价格因素，实际增长6.8%。

年末参加城镇基本养老保险人数32.91万人，比上年减少2.08万人。其中参保职工27.89万人，参保的离退休人员5.02万人。全市企业参加基本养老保险离退休人员为4.23万人，全部实现养老金按时足额发放。全市参加城镇基本医疗保险人数55.65万人，其中参保职工33.12万人，参保的城镇居民22.53万人。全市参加新型农村合作医疗保险人数276.08万人，比上年增加3.27万人。全市参加失业保险人数26.60万人，增加1.28万人。

年末全市领取失业保险金人数1758人，比上年增加411人；全市纳入城市最低生活保障的居民6991人，减少999人；纳入农村最低生活保障的居民 79292    人，减少1851人；“五保”供养对象6635人。

年末全市养老机构床位数增至1.14万张，每千名老人拥有养老床位30.4张。全市建立各类社区服务机构152个，其中社区服务中心（站）86个。全年销售社会福利彩票3.01亿元，筹集福利彩票公益金0.90亿元。

十、教育和科学技术

教育和科技事业持续发展。全年普通高等教育招生5629人，在校生22552人，毕业生5198人。高校毕业生就业率为92.5%。中等职业教育（不含技工校）招生12160人，在校生33072人，毕业生14320人。成人高等教育招生3025人，在校生10110人，毕业生3029人。全市普通高中招生21750人，在校生63949人，毕业生21193人。全市普通初中招生33975人，在校生100220人，毕业生33977人。普通小学招生44052人，在校生242066人，毕业生34057人。特殊教育在校生1356人（含随班就读）。幼儿园在园幼儿109127人。

全年研究与试验发展（R&D）经费支出预计16.90亿元，比上年增长10.4%，占全市生产总值的1.02%。全市新增4个省重点实验室、2个省级（企业）工程技术研究中心、4个科技企业孵化器、2个众创空间。目前，全市有国家级、省级创新型（试点）企业 49 家；高新技术企业 37家；重点实验室9个、（企业）工程技术研究中心29个、科技企业孵化器 11家。新认定省级企业技术中心1家。全市专利申请受理3449件，专利授权2331件，分别比上年增长4.0%和7.2%。其中，发明专利申请502件，增长59.9%，发明专利授权127件，同比增长182.2%。截至2015年底，全市共拥有有效发明专利324件，比上年增长61.2%；每万人口发明专利拥有量1.137件，比上年增加0.427件。

年末全市共有55项产品荣获2015年度福建省名牌产品称号，全市累计拥有福建省名牌产品143项。年末全市现有产品检测实验室39个，国家级产品质量监督检验中心1个，省级产品质量监督检验中心3个。全市共有法定计量技术机构2个，全年强制检定工作计量器具4.95万台（件）。全年制订行业标准2项、省地方标准5项，累计全市共制订国家标准54项、行业标准37项、省地方标准109项。

年末全市共有国家级地面气象观测站3个。全市共有专业地震监测台站（网）17个，其中综合台（网）2个，前兆台4个，测震台1个，强震台2个，烈度速报台6个，GPS观测站2个。共有36个海洋环境监测站位、4个重点监测区域、4个重点海域的4个生物质量样品。

十一、文化、卫生和体育

文化和卫生事业不断进步。年末全市文化系统共有艺术表演团体4个，全市共有公共图书馆3个，文化馆6个，博物馆2个。文化系统各类艺术表演团体演出0.09万场，本年度首演剧目12个，观众68.3万人次，其中：政府采购公益性观众5.8万人次；各级公共图书馆组织各类讲座187次，书刊文献外借32.39万册，总流通人数31.95万人次；各级文化馆组织举办展览55次，组织文艺活动75次、培训班1030期和公益性讲座32次，共有35.42万人次参加；博物馆共举办2个基本陈列和7个展览，共有31.5万人次参观，其中：未成年人参观16万人次。

年末共有影院13个，银幕68块，年度电影票房9132.79万元。广播电视台1座。有线电视用户45.8万户，有线数字电视用户45.8万户。年末广播节目综合覆盖率为98.1%；电视节目综合覆盖率为98.9%。

全年出版报纸5种（不含校报、副牌），总印数0.3亿份；期刊5种，总印数0.06亿册。年末全市共有6个综合档案馆，1个专门档案馆。

年末全市共有各级各类医疗卫生机构1321个，其中医院51个，卫生院50个，村卫生室956个。年末共有卫生技术人员13517人，其中医生4749人，注册护士5698人。年末共有医疗机构床位12633张，乡村医生和卫生员371人。

全年我市运动员在世界三大赛中共获得1金；在全国最高级别比赛中获得13金10银7铜。投资1143.17万元建有6个折装式游泳池、23个城市多功能运动场、3个城市社区健身房和40个农民体育健身工程。全年销售体育彩票5.45亿元。

十二、资源、环境和安全生产

初步核算，全年能源消费总量489.04万吨标准煤，比上年增长12.0%。其中，全社会用电量增长31.3%。万元地区生产总值能耗下降5.9%。

全年植树造林总面积7.89万亩，其中，人工荒山造林2.54万亩(含非规划林地造林1.18万亩)；人工迹地更新1.43万亩（含人工促进天然更新0.43万亩），低产低效林改造2.67万亩。全市森林覆盖率59.8%。全市城市新增绿地面积 107.96 公顷，绿地率38.42%；全市城市新增公园绿地面积85公顷，人均公园绿地面积12.67平方米。

全市共有国家级生态乡镇（街道）22个；省级生态县（区）4个、生态乡镇（街道）51个、生态村164个。共建立省级自然保护区2个，自然保护区总面积2.09万公顷。有风景名胜区4处，其中国家级风景名胜区1处、省级3处，风景名胜区总面积1.43万公顷，占全市土地面积的3.5%。

木兰溪水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为83.3%，水质状况良好。与上年相比，水质功能达标率与Ⅰ～Ⅲ类水质达标率均保持不变，水质保持稳定。萩芦溪水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为100%，水质状况优。与上年相比，水质功能达标率和Ⅰ～Ⅲ类水质达标率保持不变，水质保持稳定。

全年我市环境空气质量总体良好。全市环境空气质量有效监测天数为359天，达标天数比例为97.5%，其中优、良、轻度污染和中度污染天数比例分别为50.7%、46.8%、2.2%和0.3%。环境空气质量综合指数为3.26，首要污染物为细颗粒物。与上年相比，环境空气质量有所好转。

市县生活垃圾无害化处理率98.5%，市县污水处理率86%。

全市共发生森林火灾3起，过火面积56.4公顷，受害面积27.8公顷；森林火灾发生率、受害率分别为1.3次/十万公顷和0.12‰，没有发生扑火人员伤亡事故。全年海洋灾害造成直接经济损失约6.89亿元。全年未发生（现）海洋赤潮。

全市各类生产安全事故共878起，比上年下降6.2%；死亡113人，下降6.6%；受伤878人，下降6.2%；直接经济损失657万元，下降26.6%。未发生各类较大事故，未发生重大事故。亿元生产总值生产安全事故死亡人数为0.068人，下降11.7%。
