2010年莆田市国民经济和社会发展统计公报

来源:统计局 时间：2011-03-09 08:54
| | | |

2010年，是“十一五”规划的最后一年。全市上下以科学发展观为指导，深入贯彻落实胡锦涛总书记等中央领导来闽考察重要讲话精神，全力打好“六大战役”，全力实现“五大突破”，全力落实“两大保障”，全市经济社会发展步伐加快，全面完成了“保八超十”的年度目标任务，“十一五”规划的主要目标任务基本实现，为“十二五”的发展奠定了良好基础。

一、综合

初步核算，全年实现地区生产总值816.98亿元，按可比价格计算比上年增长15.2%。其中，第一产业增加值87.90亿元，增长3.9%；第二产业增加值462.29亿元，增长20.4%；第三产业增加值266.80亿元，增长10.1%。人均地区生产总值28466元，比上年增长14.4%。

产业结构继续调整。第一产业、第三产业有所调减，第二产业比重上升。三次产业比例由上年的11.1:54.2:34.7调整为10.8:56.6:32.6。

居民消费价格总水平比上年上涨3.2%（见表1），其中服务价格上涨0.3%，消费品价格上涨4.0%。工业品出厂价格上涨1.9%，农业生产资料价格上涨3.9%。

城镇新增就业人数22000人，完成省下达指标的104.8%。城镇下岗失业人员再就业2015人，完成省下达指标的100.7%。“4050”人员再就业227人，完成省下达指标的113.5%。年末城镇登记失业率为2.56%，比上年末提高0.02个百分点，控制在预期目标3%以内。

　　财政总收入78.29亿元，比上年增长24.0%，其中，地方级财政收入47.63亿元，增长25.7%；财政支出79.09亿元，增长26.4%。全年财政用于农林水、医疗卫生、环境保护、城乡社区事务、社会保障和就业投入25.94亿元，增长14.3%，占财政支出的比重为32.8%。全市国税总收入(含海关)46.89亿元，增长27.1%，其中税收收入(含海关)46.87亿元，增长27.2%；全市地税系统组织各项收入43.51亿元，增长33.5%，其中税收收入32.80亿元，增长32.0%。

　　经济和社会发展中存在的主要问题是：经济总量仍然较小，产业结构有待优化；服务业发展基础偏弱，供给能力不足，发展滞后；高新技术产业比重不高；物价上涨压力加大；港口优势尚未充分体现，临港产业还不发达；土地、资源、资金、人才等要素制约趋紧等。

　　在全社会投资中，第一产业完成投资5.88亿元，增长12.0%，比上年回落1.8个百分点；第二产业完成投资162.41亿元，增长28.8%，提高19.7个百分点；第三产业完成投资328.24亿元，增长41.8%，提高14.4个百分点。

五、贸易

全市批发和零售业商品销售额565.88亿元，比上年增长16.9%。净增限额以上贸易企业31家，限额以上贸易企业实现商品销售额178.47亿元，比上年增长30.4%。住宿和餐饮业营业额36.31亿元，比上年增长14.6%。实现社会消费品零售总额290.37亿元，比上年增长18.0%，扣除物价因素，实际增长13.5%。分城乡看，城镇消费品零售额260.79亿元，增长19.1%；乡村消费品零售额29.58亿元，增长9.0%。

在限额以上批发和零售业商品零售额中，食品、饮料、烟酒类增长76.6%，服装、鞋帽、针纺织品类增长66.8%，化妆品类增长62.2%，日用品类增长87.4%，体育、娱乐用品类增长35.0%，家具类增长68.6%，汽车类增长63.2%。

七、交通、邮电和旅游

全市交通运输、仓储和邮政业实现增加值42.08亿元，比上年增长9.9%。公路货物运输周转量27.21亿吨公里，增长16.4%，水路货物运输周转量29.95亿吨公里，增长27.8%。公路旅客运输周转量54.77亿人公里，增长2.3%，水路旅客运输周转量0.12亿人公里，增长16.2%。港口完成货物吞吐量1756万吨，比上年增长13.9%。

接待国内外游客793.18万人次，比上年增长22.5%，实现旅游总收入63.58亿元，增长28.6%。其中境外游客18.47万人次，增长18.9%，创汇1.29亿美元，增长77.3%；接待国内游客774.71万人次，增长22.6%，实现国内旅游收入54.81亿元，增长23.3%。

普通高等教育招生4944人，在校生16571人，毕业生4566人。各类中等职业教育招生20439人，在校生51666人，毕业生15877人。全市普通高中招生23597人，在校生69861人，毕业生25969人。全市初中招生40110人，在校生132039人，毕业生45540人。小学707所，小学招生38562人，在校生211571人，毕业生43430人。小学适龄儿童入学率100%，初中毕业生升学率（含中职）96.7%。特殊教育在校生2201人。幼儿园在园幼儿89431人。全市义务教育阶段公办学校全部免除学杂费，春季受益学生31.40万人，秋季受益学生30.41万人。春季享受免费教科书人数为27.39万人，秋季为26.19万人。对农村寄宿生进行生活补助，春季受益寄宿生3.50万人，秋季受益寄宿生2.61万人，寄宿生生活补助资金941万元。

全市培育国家级高新技术企业6家、省级创新型试点企业9家，省自主创新产品5个，省级企业工程技术研究中心5家，省级企业技术中心3家，市级企业技术中心11家。一大批科技成果转化为现实生产力，一大批具有自主知识产权的产品或品牌投放市场。全市共获授权专利426项，其中发明7项，实用新型191项，外观设计228项。有7项科技成果获省科技进步奖，其中二等奖2项，三等奖5项。

年末共有国家级质量技术检测中心1个，省级质量技术检测中心3个，法定计量技术机构2个，法定产品质量检验机构1个。

十、文化、卫生和体育

全市年末共有专业艺术表演团体3个，剧场、影剧院3个，群众艺术馆1个，文化馆5个，公共图书馆3个，博物馆2个。文化系统各类艺术表演团体艺术演出1349场, 观众241万人次；剧场、影剧院演（映）出2599场次。“妈祖信俗”申报世遗成功。年末全市共有调频广播发射台和转播台1座，广播综合人口覆盖率98.1%；电视台1座，一千瓦以上电视发射台1座，电视节目2套，电视综合人口覆盖率98.3%。全市有线电视用户31.92万户，有线广播电视网络干线总长2028公里。全年报纸7种，总印数0.20亿份；期刊5种，总印数6万册。

全面开展新型农村合作医疗，全市参合人数249.38万人，参合率98.4%。全年累计支出新农合补偿3.19亿元，人均补偿2003元。加强围产保健工作，全市孕产妇系统管理率为84.27%，孕产妇死亡率为12.42/10万，婴儿死亡率为6.76‰。农村卫生服务体系建设不断深化，共选派138名医师帮扶基层医疗机构。促进农村改水改厕，农村改水累计受益人口271.43万人，受益率99.9%，农村自来水受益率97.1%，累计农村改厕55.1万户，无害化卫生厕所普及率89.8%。

市综合体育馆、游泳健身馆、羽毛球馆等“七馆六场一基地”建成并投入使用。承办了福建省第十四届运动会，组织田径、武术、游泳等24个项目锦标赛，派出328位运动员参加22个大项目的省常规性比赛，取得79.5金、88银、84.5铜、总分2811分的成绩。在全市建有青少年校外体育活动中心6个、青少年校外体育活动场所40个、省级乡（镇）农民体育健身活动中心5个、行政村农民体育健身工程192个、健身路径26条。获得国家体育总局表彰的全民健身活动优秀组织奖1个、全民健身活动先进单位2个。获得省体育局表彰的全民健身活动优秀组织奖3个、全民健身活动先进单位4个。

十一、人民生活和社会保障

农民人均纯收入7663元，增长10.7%，扣除价格因素，实际增长6.6%；城镇居民人均可支配收入19068元，增长10.2%，扣除价格因素，实际增长6.9%。农民人均生活消费支出5679元，增长10.7%；城镇居民人均消费性支出12621元,增长9.2%。农村居民家庭恩格尔系数（即居民家庭食品消费支出占家庭消费总支出的比重）为46.6%，比上年提高0.3个百分点；城镇居民家庭恩格尔系数为42.4%，比上年提高1.0个百分点。农村居民人均住房面积67.5平方米，城镇居民人均住房建筑面积40.4平方米。

年末参加企业基本养老保险人数24.08万人，征收基本养老保险基金41044万元。参加机关事业单位养老保险在职人数3.43万人，收缴养老保险费7224万元。参加城镇职工基本医疗保险23.91万人，征收基金40769万元，其中统筹基金收入14078万元，个人账户26691万元。参加城镇居民基本医疗保险37.21万人,征收基金1729万元。失业保险参保人数15.97万人，征收失业金3911万元。企业工伤保险参保职工15.28万人,征收基金2666万元。事业单位工伤保险参保人数1.55万人。参加生育保险13.50人。年末全市企业领取基本养老保险金的离退休人员3.08万人，全部实现了养老金按时足额发放。年末全市领取失业保险金人数0.28万人，领取失业保险金1268万元。受理工伤认定案件1526件，受理劳动能力鉴定案件361件。全市共有城市居民最低生活保障对象13744人，农村居民最低生活保障对象88780人。

年末各类社会福利机构床位2480张。全年销售社会福利彩票10212万元，筹集社会福利资金3574万元。全市民政部门累计接收支援灾区捐款49万元。

十二、资源、环境和安全生产

全市拥有省级自然保护区2个、国家级森林公园1个、省级森林公园7个、省级有机食品基地4个、省级生态乡镇8个、全国环境优美乡镇1个。城区环境空气质量良好，二氧化硫、二氧化氮、可吸入颗粒物年均值皆达到和优于GB3095-1996《环境空气质量标准》中二级标准，空气污染指数API平均为56。木兰溪水质功能达标率为94.4%，萩芦溪水质功能达标率为87.5%，城市内河水质功能达标率为75.0%。饮用水源地古洋水库、东圳水库和外度水库水质达标率分别为100.0%、100.0%和29.6%。

城市垃圾无害化处理率96.5%，城市污水处理率78.5%，农村垃圾无害化处理率80%，城市建成区绿化覆盖率43.1%。

全年受1次台风、2场暴雨袭击或影响，32.15万人受灾，房屋倒塌1534间，直接经济损失7.54亿元；农作物洪涝受灾面积24.02千公顷，其中成灾13.59千公顷，成灾面积中绝收1.33千公顷，减收粮食3.37万吨；水产养殖受灾1.51千公顷，损失0.58万吨。全年降雨量在1807-1935毫米之间。

发生各类安全生产事故1339起，比上年下降6.8%；生产安全事故死亡155人，比上年下降3.7%；受伤人数1290人，下降13.7%。其中，发生工矿商贸企业生产安全事故6起，死亡12人；发生道路交通事故989起，造成139人死亡、1282人受伤。亿元GDP生产安全事故死亡人数为0.21人，下降16.0%。工矿商贸就业人员10万人生产安全事故死亡率为0.92人/10万人，道路交通万车死亡率为3.44人/万车。
