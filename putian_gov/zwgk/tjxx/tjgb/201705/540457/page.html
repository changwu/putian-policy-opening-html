来源：本网 时间：2017-03-09 10:10
| | | |

莆　田　市　统　计　局

国家统计局莆田调查队

 

2017年3月9日 

一、综合

初步核算，全年实现地区生产总值1823.43亿元，比上年增长8.9%。其中，第一产业增加值126.67亿元，增长1.0%；第二产业增加值1022.45亿元，增长7.8%；第三产业增加值674.31亿元，增长12.4%。第一产业增加值占地区生产总值的比重为6.9%，第二产业增加值比重为56.1%，第三产业增加值比重为37.0%。人均地区生产总值63313元，比上年增长8.2%。

 

全年规模以上工业战略性新兴产业实现增加值151.29亿元，比上年增长21.1%，占地区生产总值的比重为8.3%。

初步统计，全年全市电子商务交易总额1048亿元，比上年增长55.0%。限额以上批发和零售企业实现网上零售额81.78亿元，增长35.3%。“正统网”入驻电子商务企业495家。

年末全市常住人口289万人，比上年末增加2万人，增长0.7%，增幅与上年持平。其中，城镇常住人口167.9万人，占总人口比重为58.1%，比上年末提高1.5个百分点。全年出生率为14.5‰；死亡率为6.5‰；自然增长率为8.0‰。

二、农业

全年农林牧渔业完成总产值230.54 亿元，比上年增长1.3%。粮食种植面积 69.21万亩，比上年减少1.78万亩，其中稻谷面积37.78万亩，减少1.80万亩；油料种植面积24.86万亩，增加0.23万亩；蔬菜种植面积 58.14万亩，减少1.10万亩。

全年粮食产量25.84万吨，比上年减少1.31万吨，下降4.8%。其中，稻谷产量15.41万吨，减少1.38万吨，下降8.2%。

三、工业和建筑业

全年全部工业增加值843.21亿元，比上年增长7.8%。规模以上工业增加值增长8.2%。在规模以上工业中，分经济类型看，国有及国有控股企业下降15.5%；国有企业增长2.2%，集体企业下降6.5%，股份制企业增长25.8%，外商及港澳台商投资企业增长0.6%；私营企业增长28.1%。分轻重看，轻工业增长7.6%，重工业增长9.8%。分门类看，采矿业增长21.3%，制造业增长9.7%，电力、热力、燃气及水生产和供应业下降12.0%。工业产品销售率98.86%，比上年增加0.20个百分点。

 

规模以上工业的33个行业大类中有23个行业增加值增速实现正增长。其中，化学原料和化学制品制造业比上年增长82.2%，纺织业增长35.9%，文教、工美、体育和娱乐用品制造业增长26.5%，食品制造业增长14.8%，非金属矿物制造业增长12.2%，皮革、毛皮、羽毛及其制品和制鞋业增长5.7%。规模以上工业十大产业集群实现增加值805.98亿元，增长8.1%。其中，制鞋产业实现增加值199.30亿元，增长6.2%;木材浆纸产业实现增加值44.37亿元，增长9.6%；食品医药产业实现增加值98.42亿元，增长1.7%；电子信息产业实现增加值60.64亿元，增长9.0%；化工产业实现增加值90.36亿元，增长38.1%；能源产业实现增加值47.07亿元，下降12.0%；纺织服装业实现增加值63.06亿元，增长20.1%；机械装备制造业实现增加值72.95亿元，增长4.1%；工艺与创意产业实现增加值125.20亿元，增长9.6%；金属冶炼及压延加工业实现增加值4.61亿元，下降54.7%。高耗能行业实现增加值112.97亿元，比上年增长18.6%，占规模以上工业增加值的比重为13.4%。高技术制造业实现增加值62.18亿元，增长9.0%，占规模以上工业增加值的比重为7.4%。装备制造业实现增加值124.18亿元，增长6.2%，占规模以上工业增加值的比重为14.7%。

四、固定资产投资

全年固定资产投资1938.08亿元，比上年增长11.8%。

从含跨区项目情况看，第一产业投资增长44.7%；第二产业投资增长24.6%，其中，工业投资增长26.0%；第三产业投资增长6.2%。基础设施投资834.72亿元，增长30.7%，占固定资产投资的比重为43.1%。民间投资1106.52亿元，增长11.3%，占固定资产投资的比重为57.1%。高技术产业投资90.70亿元，增长895.5%，占固定资产投资的比重为4.7%。从到位资金情况看，全年到位资金2095.55亿元，比上年增长9.5%。其中，国家预算资金增长71.2%，国内贷款增长16.4%，利用外资下降77.7%，自筹资金增长5.4%，其他资金下降13.5%。

五、国内贸易

全年社会消费品零售总额623.13亿元，比上年增长11.5%。按消费形态统计，商品零售额569.58亿元，增长11.9%；餐饮收入额53.55亿元，增长7.8%。

全年交通运输、仓储和邮政业实现增加值67.61亿元，比上年增长3.8%。公路通车里程6388.27公里，比上年增长2.7%。其中高速公路通车里程262.60公里，与上年持平。

全年沿海港口完成货物吞吐量2789万吨，比上年下降8.6 %。其中外贸货物吞吐量1024.12万吨，增长1.3%。集装箱吞吐量15262标箱，增长42.3%。

年末全市汽车保有量26.04万辆（含三轮汽车和低速货车），比上年末增长19.3%，其中私人汽车保有量23.58万辆，增长21.5%。全市轿车保有量15.10万辆，增长18.8%，其中私人轿车保有量14.12万辆，增长20.1%。

全年完成邮电业务总量51.92亿元，比上年增长16.6%。其中，邮政业务总量2.41亿元，增长17.0%；电信业务总量49.52亿元，增长16.5%。邮政业全年完成邮政函件业务470.16万件，包裹业务3.5万件，快递业务量126.31万件。年末全市电话用户总数329.80万户，其中：固定电话用户57.90万户；移动电话用户271.90万户，其中4G电话用户163.86万户，净增62.62万户。全市互联网用户224.01万户，增加23.94万户。

 

全年接待入境游客31.14万人次，比上年增长15.4%。其中，接待外国人6.00万人次，增长21.9%；台湾同胞15.58万人次，增长12.9%；港澳同胞6.56万人次，增长16.9%。在入境旅游者中，过夜游客31.14万人次，增长15.4%。国际旅游外汇收入2.71亿美元，增长14.6%。全年接待国内旅游人数2315.67万人次，增长18.8%；国内旅游收入186.01亿元，增长28.6%。旅游总收入203.97亿元，增长28.1%。

八、金融

年末全市金融机构本外币各项存款余额1712.39亿元，比上年末增长6.5%；金融机构本外币各项贷款余额1654.16亿元，增长12.8%。

全年农村合作金融机构人民币各项贷款余额176.75亿元，比上年末增长12.6%。中资金融机构人民币个人消费贷款余额473.86亿元，比上年末增长26.3%。

全年内外资保险公司保费收入45.15亿元，比上年增长10.6%，其中：财产险保费收入15.35亿元；寿险保费收入（含健康险和意外伤害险保费收入）29.80亿元。支付各类赔款及给付22.43亿元，增长24.3%。

 

九、人民生活和社会保障

全年全市居民人均可支配收入 23623元，比上年增长8.9%，扣除价格因素，实际增长7.5%。按常住地分，农村居民人均可支配收入15131元，比上年增长9.0%，扣除价格因素，实际增长7.3%；城镇居民人均可支配收入31818元，比上年增长8.7%，扣除价格因素，实际增长7.8%。全市居民人均生活消费支出17335元，比上年增长7.5%，扣除价格因素，实际增长6.1%。按常住地分，农村居民人均生活消费支出12932元，增长8.2%，扣除价格因素，实际增长6.5%；城镇居民人均生活消费支出21584元，增长6.8%，扣除价格因素，实际增长6.0%。

 

年末参加城镇基本养老保险人数39.70万人，比上年增加6.79万人。其中参保职工32.46万人，参保的离退休人员7.24万人。全市企业参加基本养老保险离退休人员为4.47万人，全部实现养老金按时足额发放。全市参加城镇基本医疗保险人数63.09万人，其中参保职工34.19万人，参保的城镇居民28.90万人。全市参加新型农村合作医疗保险人数278.82万人，比上年增加2.50万人。全市参加失业保险人数27.28万人，增加0.68万人。

年末全市领取失业保险金人数3638人，比上年增加66人；全市纳入城市最低生活保障的居民2827人，减少4164人；纳入农村最低生活保障的居民52542人，减少26750人；“五保”供养对象5820人。全年全市脱贫20145人，“造福工程”搬迁1.1万人。

年末全市养老机构床位数增至1.64万张，每千名老人拥有养老床位31张。全市建立各类社区服务机构225个，其中社区服务中心（站）120个。全年销售社会福利彩票28110万元，筹集福利彩票公益金8296万元。

十、教育和科学技术

全年普通高等教育招生5719人，在校生21005人，毕业生5676人。高校毕业生就业率为94.2%。中等职业教育（不含技工校）招生11928人，在校生31185人，毕业生13553人。成人高等教育招生2025人，在校生9398人，毕业生3172人。全市普通高中招生21928人，在校生63832人，毕业生20887人。全市普通初中招生38202人，在校生104242人，毕业生34550人。普通小学招生43905人，在校生248685人，毕业生38074人。特殊教育在校生1229人（含随班就读）。学前教育在园幼儿115995人。

 

全年研究与试验发展（R&D）经费支出预计 19.58 亿元，比上年增长15.9%，占全市生产总值的1.18%。全市已布局建设3个省级产业技术重大研发平台、3个产业技术公共服务平台。新增2个省级（企业）工程技术研究中心、2个科技企业孵化器备案、6个众创空间。目前，全市拥有国家级、省级创新型（试点）企业49家；高新技术企业48家；重点实验室7个、（企业）工程技术研究中心31个、科技企业孵化器备案8家（其中省级一家）。新认定省级企业技术中心1家，市级企业技术中心8家。全市专利申请受理3451件，比上年增长0.06%；专利授权2179件，比上年下降6.52%。其中，发明专利申请419件，比上年下降16.53%，发明专利授权220件，同比增长73.2%。截至2016年底，全市共拥有有效发明专利529件，比上年增长63.3%；每万人口发明专利拥有量1.843件，比上年增加0.706件。

 

年末全市现有产品检测实验室31个，国家级产品质量监督检验中心1个，省级产品质量监督检验中心3个。全市共有法定计量技术机构2个，全年强制检定工作计量器具6.85万台（件）。全年制定国家标准5项、行业标准5项、省地方标准6项，累计全市共制定国家标准61项、行业标准50项、省地方标准118项。

年末全市共有国家级地面气象观测站6个。共有专业地震监测台网（站）17个，其中综合台（网）2个，前兆台4个，测震台1个，强震台2个，烈度速报台6个，GPS观测站2个。共有36个海洋环境监测站位、4个重点监测区域、4个重点海域的4个生物质量样品。

 

十一、文化、卫生和体育

年末全市文化系统共有艺术表演团体4个，全市共有公共图书馆3个，文化馆6个，博物馆2个。文化系统各类艺术表演团体演出0.2万场，本年度首演剧目12个，观众187.4万人次，其中：政府采购公益性观众6.1万人次；各级公共图书馆组织各类讲座66次，书刊文献外借33.1万册，总流通人数64.88万人次；各级文化馆组织举办展览55次，组织文艺活动130次、培训班70期和公益性讲座30次，共有0.55万人次参加；博物馆共举办2个基本陈列和12个展览，共有32.5万人次参观，其中：未成年人参观15万人次。

年末共有影院14个，银幕77块，2016年电影票房1.11亿元。广播电台1座，电视台1座。有线电视用户45.85万户，有线数字电视用户45.85万户，付费数字电视用户27.36万户。年末广播节目综合覆盖率为99.01%；电视节目综合覆盖率为98.60%。

全年出版报纸7种（不含校报、副牌），总印数2200万份；期刊8种，总印数10万册。年末全市共有5个综合档案馆，1个专门档案馆。

年末全市共有各级各类医疗卫生机构1335个，其中医院54个，卫生院49个，村卫生室958个。年末共有卫生技术人员14029人，其中医生5117人，注册护士5703人。年末共有医疗机构床位13968张，乡村医生和卫生员2195人。

 

  

全年我市运动员在世界三大赛中共获得2金；在全国最高级别比赛中获得16金12银8铜。2016年全市共投资2098.6万元，新建城市社区多功能运动场15个、室内健身房15个、笼式足球场6个、拆装式游泳池6个及60套室外健身器材。全年销售体育彩票6.4亿元。

十二、资源、环境和安全生产

初步核算，全年能源消费总量532.35万吨标准煤，比上年增长10.0%。其中，全社会用电量增长16.1%。万元地区生产总值能耗下降0.96%。

 

全年植树造林总面积3.72万亩，其中，人工造林0.85万亩(含非规划林地造林0.25万亩)；更新造林面积1.39万亩，低产低效林改造面积1.48万亩。全市森林覆盖率59.83%。商品材产量19.70万立方米，同比增长35.3%。全市城市新增绿地面积108 公顷，绿地率38.89%；全市城市新增公园绿地面积38公顷，人均公园绿地面积12.7平方米。

全市共有国家级生态乡镇（街道）22个；省级生态县（区）4个、生态乡镇（街道）51个、生态村164个。共建立省级自然保护区2个，自然保护区总面积20855.9公顷。有风景名胜区4处，其中国家级风景名胜区1处、省级3处，风景名胜区总面积1.43万公顷，占全市土地面积的3.5%。

木兰溪水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为83.3%，水质状况良好；与上年相比，水质功能达标率提高16.7%，Ⅰ～Ⅲ类水质达标率与上年持平，水质保持稳定。萩芦溪水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为100%，水质状况优；与上年相比，水质功能达标率提高25.0%，Ⅰ～Ⅲ类水质达标率比上年提高25.0%，水质保持稳定。

全年全市有效监测天数为352天，空气质量达到二级及以上的共339天，占全年的96.3%，比上年下降1.2%，与省里要求的97.9%有较大差距；PM2.5等六项指标均达到二级标准，其中PM2.5均值为0.029mg/m3，比上年下降6.5%； 环境空气质量综合指数为3.04，比上年下降0.22，环境空气质量有所提高。

市县生活垃圾无害化处理率98.8%，市县污水处理率88.0%。

全年海洋受台风影响造成直接经济损失约7434.5万元。全年未发生（现）海洋赤潮。

全市共发生生产安全事故253起，死亡85人，其中生产性道路交通方面共发生事故245起，死亡76人。工矿商贸方面未发生事故8起，死亡9人。生产性火灾方面、农业机械、渔业船舶、水上交通方面（单列统计）方面未造成人员死亡。全市未发生较大生产安全事故。亿元生产总值生产安全事故死亡率0.047。

2.本公报莆田市地区生产总值、各产业增加值按现价计算，增长速度按可比价格计算。
