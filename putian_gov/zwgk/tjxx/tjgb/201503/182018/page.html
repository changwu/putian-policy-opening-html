莆田市2014年国民经济和社会发展统计公报

发布单位：莆田市统计局 国家统计局 莆田调查队
来源：本网 时间：2015-03-04 11:00
| | | |

2014年，面对复杂多变的国内外经济环境，全市各级各部门在中共莆田市委、市政府的坚强领导下，深入学习贯彻党的十八大、十八届三中、四中全会和习近平总书记系列重要讲话精神，全力抓好稳增长、调结构、促改革、惠民生等各项工作，经济社会平稳健康发展。 

一、综合 

年末全市常住人口285万人，比上年末增加2万人，其中城镇常住人口157.6万人，占总人口比重为55.3%，比上年末提高1.7个百分点。全年出生人口3.75万人，出生率为13.2‰；死亡人口1.87万人，死亡率为6.6‰；自然增长率为6.6‰。

国民经济平稳增长。初步核算，全年实现地区生产总值1502.07亿元，比上年增长11.1%。其中，第一产业增加值109.85亿元，增长3.4%；第二产业增加值866.76亿元，增长11.9%；第三产业增加值525.46亿元，增长11.4%。人均地区生产总值52890元，比上年增长10.3%。第一产业增加值占地区生产总值的比重为7.3%，第二产业增加值比重为57.7%，第三产业增加值比重为35.0%。 

 

 

就业持续增加。全年城镇新增就业2.27万人，有2386个下岗人员实现了再就业。年末城镇登记失业率为2.0%，与上年末持平。 

 

价格基本稳定。全年居民消费价格比上年上涨2.0%，其中食品价格上涨3.5%。市辖区商品零售价格上涨1.0%。工业生产者出厂价格下降0.3%。农业生产资料价格上涨0.1%。

财政收入稳定增长。全年公共财政总收入175.08亿元，比上年增长14.3%，其中，地方公共财政收入110.30亿元，增长16.2%；公共财政支出158.77亿元，增长10.1%。全市国税总收入（含海关代征）102.41亿元，增长12.7%；全市地税系统组织各项收入104.55亿元，增长14.6%。 

 

电子商务交易活跃。初步统计，全年全市电子商务交易总额57.92亿元，比上年增长194.5%。限额以上企业实现网上零售额27.62亿元，增长166.6%。 “正统网”入驻电子商务企业140家。 

二、农业 

农业生产形势较好。全年农林牧渔业完成总产值199.93亿元，比上年增长3.5%。粮食种植面积72.43万亩，比上年减少1.47万亩，其中稻谷面积41.13万亩，减少1.63万亩；油料种植面积24.37万亩，增加0.16万亩；蔬菜种植面积55.33万亩，增加0.81万亩。 

全年粮食产量27.77万吨，比上年减少0.39万吨，下降1.4%。其中，稻谷产量17.51万吨，减产0.52万吨，下降2.9%。

 全年肉蛋奶总产量17.56万吨，比上年下降7.3%。肉类总产量12.71万吨，下降4.8%。其中，猪肉产量8.90万吨，下降5.4%；牛肉产量0.06万吨，增长9.5%；羊肉产量0.24万吨，下降0.1%。年末生猪存栏59.73万头，下降18.3%；生猪出栏116.98万头，下降6.4%。牛奶产量1.37万吨，下降2.3%。

三、工业和建筑业 

工业生产稳定增长。全年全部工业增加值713.05亿元，比上年增长11.7%。规模以上工业增加值增长13.0%。在规模以上工业中，分经济类型看，国有及国有控股企业增长19.1%；国有企业增长19.2%，集体企业增长5.2%，股份制企业增长15.0%，外商及港澳台商投资企业增长8.8%；私营企业增长14.3%。分轻重看，轻工业增长15.5%，重工业增长7.9%。分门类看，采矿业增长15.3%，制造业增长13.4%，电力、热力、燃气及水生产和供应业增长8.5%。工业产品销售率98.94%，比上年下降0.21个百分点。 

 

 

规模以上工业的33个行业大类中有19个增加值增速在两位数。其中，化学纤维制造业比上年增长2245.4%，黑色金属冶炼和压延加工业增长116.8%，通用设备制造业增长51.2%，食品制造业增长32.6%，木材加工和木、竹、藤、棕、草制品业增长27.0%，电气机械和器材制造业增长22.7%，纺织业增长21.2%，汽车制造业增长19.8%。规模以上工业中十大产业集群实现增加值665.85亿元，增长12.9%。其中，金属冶炼及压延加工业实现增加值15.85亿元，增长49.5%；化工产业实现增加值59.62亿元，增长19.9%；工艺与创意产业实现增加值91.81亿元，增长17.5%。高技术产业实现增加值51.74亿元，比上年增长6.1%。

全年规模以上工业企业实现利润106.58亿元，比上年下降0.2%；其中国有及国有控股企业18.72亿元，下降31.9%；国有企业0.62亿元，增长21.0%，集体企业0.06亿元，下降21.1%，股份制企业68.98亿元，下降7.0%，外商及港澳台商投资企业33.22亿元，增长13.3%；私营企业86.88亿元，增长10.9%。规模以上工业企业每百元主营业务收入中的成本为87.12元，主营业务收入利润率为5.02%。 

全年全社会建筑业实现增加值165.63亿元，比上年增长12.5%。全市具有资质等级的总承包和专业承包建筑业企业完成建筑业总产值480.37亿元，增长29.4%。

五、国内贸易 

市场销售平稳增长。全年社会消费品零售总额480.33亿元，比上年增长12.1%。按经营地统计，城镇消费品零售额428.08亿元，增长11.7%；乡村消费品零售额52.25亿元，增长15.1%。按限额标准统计，限额以上商品零售额174.37亿元，增长19.5%，限额以下商品零售额305.96亿元，增长8.3%。 

 

 

在限额以上企业商品零售额中，服装鞋帽针纺织品类比上年增长118.8%，家具类增长104.1%，通讯器材类零售额增长71.8%，粮油食品饮料烟酒类增长43.2%、其中食品类增长20.6%，化妆品类增长41.7%，体育、娱乐用品类增长37.1%，金银珠宝类增长35.8%，日用品类增长25.1%，家用电器和音响器材类增长13.3%，汽车类增长3.7%，石油及制品类下降13.6%。 

六、对外经济 

进出口平稳增长。全年进出口总额320.81亿元人民币，以美元计价为52.42亿美元，比上年增长9.8%。其中，出口202.65亿元人民币，以美元计价为33.12亿美元，增长5.0%；进口118.16亿元人民币，以美元计价为19.30亿美元，增长20.5%。进出口顺差84.49亿元人民币，以美元计价为13.81亿美元，比上年减少1.70亿美元。

九、人民生活和社会保障 

城乡居民收入继续增加。全年全市居民人均可支配收入19980元，比上年增长9.5%；扣除价格因素，实际增长7.4%。其中，农村居民人均可支配收入12829元，比上年增长10.7%，扣除价格因素，实际增长8.3%；城镇居民人均可支配收入26871元，比上年增长9.0%，扣除价格因素，实际增长7.0%。农村居民食品烟酒消费支出占消费总支出的比重为42.1%，城镇居民为34.9%。 

年末参加城镇基本养老保险人数31.01万人，比上年减少8964人。其中参保职工26.28万人，参保的离退休人员4.73万人。全市企业参加基本养老保险离退休人员为3.98万人，全部实现养老金按时足额发放。全市参加城镇基本医疗保险人数63.26万人，其中参保职工32.67万人，参保的城镇居民30.59万人。全市参加新型农村合作医疗保险人数272.81万人，同比增加5.36万人。全市参加失业保险人数25.33万人，同比增加1.2万人。 

年末全市领取失业保险金人数3145人，比上年减少1213人；全市纳入城市最低生活保障的居民7990人，减少1982人；纳入农村最低生活保障的居民81143人，减少1079人；“五保”供养对象6615人。 

年末全市养老机构床位数增至10938张，每千名老人拥有养老床位29.2张。全市建立各类社区服务机构152个，其中社区服务中心（站）86个。全年销售社会福利彩票2.75亿元，筹集福利彩票公益金0.82亿元。 

十、教育和科学技术 

教育科技文化事业持续发展。普通高等教育招生6596人，在校生20644人，毕业生4309人。高校毕业生就业率为88.97%。中等职业教育（不含技工校）招生12338人，在校生36397人，毕业生14617人。成人高等教育招生4108人，在校生11252人，毕业生1828人。全市普通高中招生20827人，在校生64510人，毕业生22137人。全市普通初中招生31100人，在校生99780人，毕业生34601人。普通小学招生42862人，在校生231299人，毕业生31591人。特殊教育在校生1202人。幼儿园在园幼儿104425人。 

 

全年研究与试验发展（R&D）经费支出预计15.20亿元，比上年增长24.5%，占全市生产总值的1.0%。全市新增2个省级企业重点实验室、4个省级企业工程技术研究中心、3个科技企业孵化器、新布局建设 1个产业技术公共服务平台。目前，全市有国家级、省级创新型（试点）企业49家；高新技术企业36家；重点实验室5个、工程技术研究中心27个、科技企业孵化器5家。新认定省级企业技术中心2家。全市专利申请受理3317件，专利授权2175件，分别比上年增长3.6%和27.6%。其中，发明专利申请314件，增长12.1%，发明专利授权45件，同比下降11.8%。截至2014年底，全市共拥有有效发明专利201件，比上年增长29.7%；每万人口发明专利拥有量0.710件，比上年增加0.158件。全年共登记技术合同4项，技术合同成交金额2755万元。 

 

 

全市88项产品荣获2014年度福建省名牌产品称号，全市累计拥有福建省名牌产品151项。年末全市共有产品检测实验室43个，国家级产品质量监督检验中心1个，省级产品质量监督检验中心3个。全市共有法定计量技术机构2个，全年强制检定工作计量器具7.2万台（件）。全年制修订国家标准4项、行业标准6项、省地方标准7项，累计全市共制订国家标准53项、行业标准34项、省地方标准106项。 

年末全市共有国家级地面气象观测站3个。共有地震前兆台站（点）18个，其中综合台站2个；前兆测台站4个；测震台站1个，强震动观测台站（点）3个；烈度速报台6个；GPS观测站2个。共有36个海洋环境监测站位、4个重点监测区域、4个重点海域的4个生物质量样品。 

十一、文化、卫生和体育 

文化和卫生事业不断进步。年末全市文化系统共有艺术表演团体4个，公共图书馆3个，文化馆6个，博物馆2个。文化系统各类艺术表演团体演出0.11万场，本年度首演剧目8个，观众63.42万人次，其中：政府采购公益性观众2.65万人次；各级公共图书馆组织各类讲座173次，书刊文献外借23.28万册，总流通人数25.36万人次；各级文化馆组织举办展览37次，组织文艺活动69次、培训班515期和公益性讲座14次，共有6.78万人次参加；博物馆共举办2个基本陈列和15个展览，共有71万人次参观，其中：未成年人参观12万人次。 

年末共有影院6个，银幕26块，年度电影票房6377.45万元。广播电视台1座。有线电视用户42.86万户，有线数字电视用户42.86万户。年末广播节目综合覆盖率为98.1%；电视节目综合覆盖率为98.3%。 

全年出版报纸5种（不含校报、副牌），总印数0.3亿份；期刊5种，总印数0.06亿册。年末全市共有6个综合档案馆，1个专门档案馆。 

年末全市共有各级各类医疗卫生机构1335个，其中医院53个，卫生院1294个。年末共有卫生技术人员13721人，其中医生5093人，注册护士5667人。年末共有医疗机构床位12347张，乡村医生359人。 

     

全年我市运动员在世界三大赛中共获得1金2银3铜；在仁川亚运会上，我市共有4名运动员参赛，其中3人次获得金牌，1人次获得铜牌；在全国最高级别比赛中获得4金6银6铜。投资1188.8万元建有8个折装式游泳池、12个城市多功能运动场、3个城市社区健身房和22个农民体育健身工程。全年销售体育彩票4.55亿元。 

十二、资源、环境和安全生产 

初步核算，万元地区生产总值能耗上升0.16%。全社会用电量增长11.0%。 

全年植树造林总面积7.75万亩，其中，人工荒山造林3.46万亩(含非规划林地造林1.34万亩)；人工迹地更新0.31万亩，人工促进天然更新1.39万亩，低产低效林改造2.53万亩。全市森林覆盖率59.8%。全市城市新增绿地面积181.4公顷，绿地率39.9%；全市城市新增公园绿地面积81公顷，人均公园绿地面积12.74平方米。 

全市共有国家级生态乡镇（街道）22个；省级生态县（区）4个、生态乡镇（街道）49个、生态村164个。共建立省级自然保护区2个，自然保护区总面积2.09万公顷。有风景名胜区4处，其中国家级风景名胜区1处、省级3处，风景名胜区总面积1.2万公顷，占全市土地面积的1‰。 

2014年木兰溪水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为83.3%，水质状况良好。与上年相比，水质功能达标率与Ⅰ～Ⅲ类水质达标率均保持不变，水质保持稳定；萩芦溪水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为100%，水质状况优。与上年相比，水质功能达标率和Ⅰ～Ⅲ类水质达标率保持不变，水质保持稳定。 

2014年城区环境空气质量良，二氧化硫、二氧化氮、可吸入颗粒物年均值皆达到和优于《环境空气质量标准》（GB3095-1996）中二级标准，综合污染指数为1.02。其中一级优的天数163天、二级良好的天数201天、三级轻微污染的天数1天，城区环境空气质量在二级标准以上天数占99.7%。与2013年相比，环境空气质量基本保持稳定。 

市县生活垃圾无害化处理率98.1%，市县污水处理率85%。 

全市共发生森林火灾6起，过火面积120.6公顷，受害面积56.1公顷；森林火灾发生率、受害率分别为2.61次/十万公顷和0.24‰。全年海洋灾害造成直接经济损失约6091万元，减少76.1%。全年发生（现）海洋赤潮1次，累计赤潮面积600平方公里。 

全市各类生产安全事故共937起，比上年下降8.9%；死亡115人，下降3.4%；受伤946人，下降1.6%；直接经济损失894万元，下降18.6%。各类较大事故1起，死亡4人，未发生重大事故。亿元生产总值生产安全事故死亡人数为0.077人，下降13.5%。
