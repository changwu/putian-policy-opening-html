2018年莆田市国民经济和社会发展统计公报

来源：本网 时间：2019-03-16 09:32
| | | |

一、综合

初步核算，全年实现地区生产总值2242.41亿元，比上年增长8.3%。其中，第一产业增加值116.27亿元，增长2.4%；第二产业增加值1179.91亿元，增长8.5%；第三产业增加值946.23亿元，增长8.6%。第一产业增加值占地区生产总值的比重为5.2%，第二产业增加值比重为52.6%，第三产业增加值比重为42.2%。全年人均地区生产总值77325元，比上年增长8.1%。

 

 

全市限额以上批发和零售企业实现网上零售额148.60亿元，增长18.2%。

年末全市常住人口290.0万人，与上年末持平。其中，城镇常住人口176.9万人，占总人口比重（常住人口城镇化率）为61.0%，比上年末提高1.4个百分点。全年出生人口3.8万人，出生率为13.2‰；死亡人口1.9万人，死亡率为6.7‰；自然增长率为6.5‰。年末全市户籍人口360.3万人，比上年末增加5.6万人。

三、工业和建筑业

全年全部工业增加值934.96亿元，比上年增长8.9%。规模以上工业增加值增长9.1%。在规模以上工业中，分经济类型看，国有控股企业增长27.5%；国有企业下降32.1%，集体企业增长28.7%，股份制企业增长10.6%，外商及港澳台商投资企业增长6.6%；私营企业增长6.5%。分轻重看，轻工业增长7.5%，重工业增长13.2%。分门类看，采矿业下降9.6%，制造业增长8.5%，电力、热力、燃气及水生产和供应业增长20.7%。工业产品销售率99.00%，比上年增加0.04个百分点。

 

规模以上工业的33个行业大类中有11个增加值增速在两位数。其中，计算机、通信和其他电子设备制造业增长32.3%，专用设备制造业增长11.2%，皮革、毛皮、羽毛及其制品和制鞋业增长10.8%，纺织业增长32.4%。工业战略性新兴产业增长16.2%，占规模以上工业增加值的比重为17.1%。高技术制造业增长21.7%，占规模以上工业增加值的比重为6.9%。装备制造业增长13.4%，占规模以上工业增加值的比重为13.0%。

全年规模以上工业企业利润总额比上年下降1.3%。其中国有控股企业下降88.4%；国有企业下降73.2%，集体企业增长50.0%，股份制企业下降3.4%，外商及港澳台商投资企业增长5.1%；私营企业增长4.3%。规模以上工业企业资产负债率53.03%，比上年下降0.51个百分点；每百元主营业务收入中的成本为87.83元，主营业务收入利润率为5.6%。 

全年全社会建筑业实现增加值250.79亿元，比上年增长6.8%。全市具有资质等级的总承包和专业承包建筑业企业完成建筑业总产值716.95亿元，增长9.4%。

 

四、固定资产投资

全年固定资产投资比上年增长12.6%。

在固定资产投资中，第一产业投资增长47.3%；第二产业投资增长0.1%，其中，工业投资下降0.8%；第三产业投资增长17.7%。基础设施投资增长20.2%，占固定资产投资的比重为38.9%。民间投资增长27.1%，占固定资产投资的比重为63.1%。从到位资金情况看，全年到位资金比上年下降7.7%。其中，国家预算资金下降43.4%，国内贷款下降12.0%，利用外资下降100.0%，自筹资金下降2.3%，其他资金与上年持平。

五、国内贸易

全年全市社会消费品零售总额763.42亿元，比上年增长9.8%。按消费形态统计，商品零售额703.35亿元，增长10.5%；餐饮收入额60.07亿元，增长2.4%。

 

  

在限额以上企业商品零售额中，建筑及装潢材料类零售额比上年增长6.9%，粮油食品类增长19.9%，服装鞋帽针纺织品类增长10.7%,金银珠宝类增长10.3%，家具类增长18.3%，文化办公用品类增长13.0%，化妆品类增长120.2%，石油及制品类增长4.7%，日用品类增长14.4%，家用电器和音响器材类增长8.3%，汽车类增长6.4%，体育、娱乐用品类下降24.7%，通讯器材类增长42.9%。

八、金融

年末全市金融机构本外币各项存款余额1803.12亿元，增速与上年持平；金融机构本外币各项贷款余额1857.51亿元，增长3.4%。

全年农村合作金融机构人民币各项贷款余额219.85亿元，比上年末增长12.3%。中资金融机构人民币个人消费贷款余额713.28亿元，比上年末增长14.3%。

年末境内A股上市公司2家，与上年持平，总市值73.25亿元，同比下降30.7%；新三板挂牌企业4家，与上年持平。

全年内外资保险公司保费收入58.64亿元，比上年增长9.8%，其中：财产险保费收入16.13亿元；人身险保费收入42.51亿元（寿险保费收入33.59亿元，健康险和意外伤害险保费收入8.92亿元）。

九、人民生活和社会保障

全年全市居民人均可支配收入27954元，比上年增长8.8%；按常住地分，农村居民人均可支配收入17991元，比上年增长9.1%，扣除价格因素，实际增长 7.6%；城镇居民人均可支配收入37169元，比上年增长7.8%，扣除价格因素，实际增长6.3%。

全市居民人均生活消费支出19808元，比上年增长8.0%。按常住地分，农村居民人均生活消费支出14982元，增长6.7%，扣除价格因素，实际增长5.2%；城镇居民人均生活消费支出24271元，增长8.1%，扣除价格因素，实际增长6.6%。 

 

 2018年末全市参加保险人数22.26万人，比上年末减少10.29万人；年末全市领取失业保险金人数3755人，增加263人；年末城镇新增就业19177人，再就业2550人，登记失业率2.19%，下降0.31个百分点。

年末全市纳入城市最低生活保障的居民1104人，比上年末减少346人；纳入农村最低生活保障的居民29413人，减少7005人；城乡特困供养对象3862人，减少357人。

年末全市养老机构床位数增至2万张，每千名老人拥有养老床位35.86张。全市共有居家社区养老服务照料中心32个，其中新建20个。全市共销售福利彩票2.92亿元，共筹集公益金0.87亿元。

十、教育和科学技术

全年普通高等教育招生6237人，在校生20602人，毕业生5426人。中等职业教育（不含技工校）招生6052人，在校生15999人，毕业生4124人。成人高等教育招生2252人，在校生5160人，毕业生1956人。全市普通高中招生22027人，在校生63784人，毕业生19675人。初中招生37860人，在校生116021人，毕业生34602人。普通小学招生49473人，在校生268422人，毕业生37051人。特殊教育在校生1410人（含随班就读）。幼儿园在园幼儿125743人。

  

 

全年研究与试验发展（R&D）经费支出预计26.15亿元，比上年增长10.0%，占全市生产总值的1.16%。全市共建设省级众创空间10家。科技企业孵化器备案8家，孵化面积9.78万平方米，在孵企业110家，创造就业岗位0.08万个。新认定高新技术企业31家，总数72家；新认定省级企业技术中心3家；新认定省科技小巨人领军企业11家，总数69家。全市专利申请6148件，比上年增长74.0%，增幅居全省首位；其中发明专利申请820件，增长109.2%。全市专利授权2912件，比上年增长53.8%，增幅居全省第3位；其中发明专利授权158件，下降3.4%。全市共拥有有效发明专利802件，比上年增长17.8%；每万人口发明专利拥有量2.77件，增加0.41件。全年共登记技术合同1项，成交额976.20万元。

 

 

 

年末全市共有产品检测实验室36个，国家级产品质量监督检验中心1个，省级产品质量监督检验中心3个。全市共有法定计量技术机构2个，全年强制检定工作计量器具11.38万台（件）。全年制定国家标准7项、行业标准5项、省地方标准3项，累计全市共制定国家标准76项、行业标准73项、省地方标准128项。

年末全市共有国家级地面气象观测站3个，国家天气站8个。共有专业地震监测台（网、站）57个，其中综合台（网）2个，前兆台4个，测震台1个，强震台2个，烈度速报台6个，GPS观测站2个，烈度速报一般站40个。共有48个海洋环境监测站位，其中湄洲岛国家海洋公园周边海域6个站位，南日岛养殖区12个站位，后海垦区1个站位，平海湾7个站位，莆田秀屿区港城污水处理有限公司排污口1个站位，莆田市华科环保工程有限公司排污口2个站位，莆田灵川镇太湖垦区排污口2个站位，兴化湾17个站位。

十一、文化、卫生和体育

年末全市文化系统共有艺术表演团体4个，公共图书馆3个，文化馆6个，博物馆7个。文化系统各类艺术表演团体演出0.08万场，本年度首演剧目2个，观众57.75万人次，其中：政府采购公益性演出120场，观众14.8万人次；各级公共图书馆组织各类讲座64次，书刊文献外借97.12万册，总流通人数146.05万人次；各级文化馆组织举办展览45次，组织文艺活动83次、培训班138期和公益性讲座36次，共有23.57万人次参加；博物馆共举办15个基本陈列和50个展览，共有342.44万人次参观，其中：未成年人参观131.76万人次。

年末共有影院16个，银幕92块，年度电影票房1.22亿元。广播电台1座，电视台1座。有线数字电视用户39.38万户，付费数字电视用户32.95万户。年末广播节目综合覆盖率为98.97%；电视节目综合覆盖率为98.73%。

全年出版报纸7种（不含校报、副牌），总印数2200万份；期刊8种，总印数10万册。年末全市共有5个综合档案馆，1个专门档案馆。

年末全市共有各级各类医疗卫生机构1364个，其中医院61个，卫生院49个，村卫生室962个。年末共有卫生技术人员15555人，其中医生5801人，注册护士6964人。年末共有医疗机构床位15364张，乡村医生和卫生员1890人。

 

 

全年全市运动员在世界级比赛中获得6金1铜，在亚洲级别比赛中获得1金3银3铜，在全国级别以上赛事中共获得44金48银34铜的成绩。全年共投资1718万元，新建多功能运动场22个、门球场4个、室内健身房14个、笼式足球场11个、室外健身器材50套。全年销售体育彩票10.05亿元。

十二、资源、环境和安全生产

初步核算，全年能源消费总量605.56万吨标准煤，比上年增长7.1%；万元地区生产总值能耗下降1.1%。全社会用电量增长16.1%。 

 

 

全年植树造林总面积5.64万亩，其中，人工造林0.37万亩(含非规划林地造林0.04万亩)，更新造林面积4.67万亩，低产低效林改造面积0.6万亩。全市森林覆盖率59.83%。全市商品材产量19.70万立方米，比上年增长35.3%。全市城市新增绿地面积269.75公顷，建成区绿地率40.26%，人均公园绿地面积14.21平方米。

全市共建立省级自然保护区2个，总面积20855.9公顷。有风景名胜区4处，其中国家级风景名胜区1处、省级3处，含海域风景名胜区总面积120.3平方公里，不含海域风景名胜区总面积79.4平方公里。

木兰溪水质良好。水质功能达标率为100%，I～III类水质比例为83.3%，同比均持平。萩芦溪水质优。水质功能达标率为100%，I～III类水质比例为100%，同比均持平。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        

莆田市区有效监测天数为365天，达标天数比例为89.9%，比上年下降0.8%，其中一级、二级达标天数比例分别为37.0%、52.9%。六项污染物平均浓度均达标；环境空气质量综合指数为3.23，同比下降0.08，首要污染物为臭氧。

市县生活垃圾无害化处理率预计为98.9%，市县污水处理率预计为92.0%。

全市共发生森林火灾2起，过火面积16公顷，受害面积10.3公顷；森林火灾发生率、受害率分别为0.87次/十万公顷和0.05‰，未发生扑火人员伤亡事故。全年未发生（现）海洋赤潮。

全市共发生生产安全事故163起，死亡54人，分别比上年下降2.4%和14.3%，其中较大以上事故1起、死亡5人，分别下降0.0%和66.7%；未发生重特大事故。亿元地区生产总值生产安全事故死亡人数0.024人，比上年下降22.6%。
