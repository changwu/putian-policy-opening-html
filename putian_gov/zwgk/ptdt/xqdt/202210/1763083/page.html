秀屿区：多措并举提升城市管理精细化水平

来源:湄洲日报 时间：2022-10-28 08:22
| | | |

　　秀屿探索环卫改革新路子，将11项工作纳入环卫一体化承包服务范围，在全市率先尝试市场化运作垃圾分类。扎实推进市政管养提档升级，补齐短板弱项。深入推进物业小区公共收益“点题整治”等工作，增强群众获得感和幸福感。

　　党的二十大报告提出，要“增进民生福祉，提高人民生活品质”。干净、整洁、优美的人居环境是重要的民生福祉。党的十八大以来，秀屿区城市管理行政执法局坚持以人民为中心的发展思想，落实“城市管理应该像绣花一样精细”的要求，全力打造宜居宜业富美秀屿，人民群众的满意度、获得感、幸福感不断增强。

　　创新举措优化环境

　　凌晨4时，天未亮，在秀屿城区，一辆辆洗扫车便驶上各主干道作业，赶在早高峰到来前，扮靓城市道路。这种机械化的环卫清扫模式，不仅为一线环卫工人减负，还提升了道路精细化保洁水平。

　　“机械化作业率达到95%，这是过去不曾想到的。”秀屿区环卫处主任陈金海介绍，以前，由于环卫设备分散在各镇村，存在设备老化、更新不及时、调度慢等问题，加上各镇村自行聘用的环卫工人年龄结构偏大、业务水平参差不齐，导致城市环境“脏乱差”的局面难以彻底改变。

　　对此，秀屿积极探索环卫改革新路子，按照“政府花钱买服务，企业市场化运作”的思路，2020年起，实施环境卫生保洁一体化项目，将全区的农村环境卫生整治、城区道路卫生保洁、道路绿化养护、公厕管理、海漂垃圾治理、河道整治、交通设施维护、垃圾屋建设等11项工作全部纳入环卫一体化承包服务范围，从而全面实现“管干分离”。

　　据介绍，该项目承包期限采用“3+5”方式，年承包金额采取递增方式，实行每年一调整，避免企业因成本上升降低服务质量。环卫作业市场化后，设备资源得到整合，环卫队伍得到重整，作业方式得到进一步优化。

　　得益于此，埭头镇2个小岛村和南日镇4个小岛村的垃圾也实现日产日清。由承包企业每日上岛收一次生活垃圾，用垃圾运输船统一送往压缩站，最后送进圣元垃圾焚烧发电厂。而以往，小岛的保洁作业是由岛上各村自行负责，受航班限制，一周只能集中清运一次生活垃圾，其中不便可想而知。

　　结合海岸线长的地域特征，该区依托第三方公司组建一支130余人的海上环卫队伍，配备6部压缩车，保障海漂垃圾常态化清理打捞作业。去年，还增加配备3艘海面打捞船，与原有的7艘近岸小型机动船舶组成海面垃圾打捞船队，实现与陆上环卫无缝对接。

　　针对农村垃圾问题，主要采用“日常保洁、每周整治、突击处置”模式，即各村环卫工人负责日常道路垃圾清扫、清运工作；以2个村至3个村为一个片区，采取每周一整治；在各镇成立一支环卫突击队，用于应对春节等节点垃圾量暴增、建筑垃圾倾倒、大件垃圾处理等问题。

　　值得一提的是，该区在全市率先尝试市场化运作垃圾分类，涉及11个小区、13个企事业单位、20个学校的垃圾分类设施配建、宣传、收运、管理等。截至目前，秀屿区建成垃圾分类屋52座、分类亭120个，投用12部垃圾分类收运车辆。按照每500户配1名垃圾分类管理员，目前共聘用垃圾分类管理员50人，居民参与率、知晓率、分类投放率逐步提高。

　　完善设施精细管理

　　夜幕降临，走在秀屿城区，只见一盏盏路灯点亮了街头巷尾，既照亮了群众回家路，也为夜晚增添了暖意。

　　小路灯关系大民生。按照“城市建设到哪里，照明设施就配套安装到哪里”的工作思路，该区所有城市道路、街巷、公园、广场配套安装了照明设施，建城区现有4000多盏路灯。

　　部分路灯受线路老化、天气等方面影响，有不同程度的损坏。针对这一情况，秀屿区城管执法局依托城区网格化管理平台，建立路灯维护长效运行管理机制，并组织维护人员对路灯缺损情况进行拉网式排查，登记建档，逐一修缮，保障了亮灯率。

　　眼下，结合建设节能减排、新型智慧城市部署，该区着手实施城区路灯节能、智能改造工程。首批改造计划将清塘大道、福屿街、荔港大道秀屿段等3条主干道上缺亮的灯头，更换为瓦数更高、照明效果更佳的LED灯头，预计可节电40%以上，11月底完成改造任务。

　　结合常态化创城，秀屿区城管执法局积极推进市政管养提档升级，因地制宜补齐短板弱项。通过采取沿路整修、见破即修、划片维修相结合方式，限期整改解决路面破损、坑洼不平、井盖缺失等问题。同时，在毓秀路、福屿街创建精细化管理示范路线。

　　该区着力提升道路绿化水平，在绿地内种植时令花卉，并做好日常养护，扮靓道路景观。

　　盯紧群众身边的“急难愁盼”问题，该区加大公厕建设、改造提升力度，转变过去的“脏臭”现象，在实施“厕所革命”三年行动期间新建66座公厕，专人专管，更加方便洁净。

　　回应关切办好实事

　　10月24日早上6时30分，秀屿区城管执法局的3名执法人员来到大众路值守巡逻，对占道经营、流动摊点进行规范、劝导，确保道路通畅。

　　这条长200多米、宽十几米的大众路是通往笏石农贸市场的必经之路，也曾是秀屿老城区占道摆摊最为严重的地段之一，成为群众投诉的热点。

　　为根治这种现象，该局将大众路列入区级严管示范路，牵头联合多个部门开展执法，并在农贸市场进场路口设置公共视频，安排人员流动值守。疏堵结合，在市场周边建设流动摊贩经营点，引导占道经营摊贩搬入规范经营。

　　城市管理工作涉及面广，事关群众切身利益。该局将巩固“我为群众办实事”成果与城管行政执法有机融合，努力提高城市治理水平。

　　10月25日上午，秀屿区公园湾1号小区的物业负责人来到银行，将小区公共收益剩余的16.4万余元存入市物业专项维修资金专户。至此，该区23个存在公共收益的小区全部完成交存工作。

　　算好“明白账”，切实维护业主利益。随着城市化进程加快，秀屿区实施物业管理的住宅小区日益增多，现有27个住宅小区实施专业化物业管理。根据法律规定，住宅小区公共收益归全体业主所有。今年以来，按照上级部署要求，秀屿区持续深入推进物业服务企业侵占住宅小区业主公共收益“点题整治”工作，回应群众关切。

　　该区聘请第三方审计机构，进驻小区开展物业企业公共收益账目专项审计全覆盖，逐一核实各小区的公共收益。在区城管执法局的指导下，各小区物业企业配合整改，进一步规范公共收益的管理。为提高群众对此项整治的知晓率和参与率，该局还在各小区张贴相关宣传海报，并敦促物业企业“晒账单”，变“糊涂账”为“明白钱”。

　　自去年初正式承担物业行政管理职责后，区城管执法局认真落实行业监管职能，有序开展各项工作，全面提升物业服务企业的管理水平，实现精细化管理，改善居民生活环境。

　　燃气安全关系千家万户。为保障燃气安全生产，该局推动建立燃气管线地理信息系统，开展在用管线全面普查建档，完善燃气管道设施标志。目前已完成辖区内高中压管道普查建档，新增各类管位标志桩、标志牌、道路标志钉等约2300余个。开展“地毯式、全覆盖、无缝隙、零死角”燃气安全隐患排查整治，坚决防范遏制各类燃气事故发生，规范燃气市场秩序，消除安全隐患。

　　站在新起点，奋进新征程。秀屿区城管执法局将全力推动党的二十大精神落地生根，坚持“人民城市人民建，人民城市为人民”的理念，结合文明城市常态化创建工作，着力解决群众在城市管理方面的“急难愁盼”问题，不断开创城市管理高质量发展新局面。（记者 林英 戴立钦 通讯员 林清霞）
