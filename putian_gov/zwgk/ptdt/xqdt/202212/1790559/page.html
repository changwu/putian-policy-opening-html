城厢区：立足资源禀赋促文旅产业高质量发展

来源:湄洲日报 时间：2022-12-21 07:43
| | | |

　　城厢区依山、滨溪、向海，生态环境优美，文化底蕴深厚，旅游资源丰富。近年来，城厢区委、区政府以创建省级全域生态旅游示范区为抓手，把文旅经济列入10条重点产业链之一，全力做好文旅融合，加快推进文旅经济高质量发展。

　　“山水格局、人文宜居”，山水是城厢的颜值，人文是城厢的气质，田园山水之间，风光正好。城厢区委、区政府立足特色资源禀赋，坚持点线面结合，统一规划布局，创新体制机制，整合各类资源，融入全市“山水诗画生态韵城”规划，坚持以文塑旅、以旅彰文，构建“东有绶溪休闲、西有钟潭工艺、南有木兰陂世遗、北有东圳生态、中有广化寺文化”的五大文旅发展新格局，稳步推进全域生态旅游示范区创建，促进文旅产业高质量发展。

　　顶层设计 下好文旅“一盘棋”

　　物华天宝、人杰地灵。城厢区拥有千年水利木兰陂、千年古刹广化寺等各类文物保护单位76处，国家4A级旅游景区2个、3A级旅游景区3个、国家森林公园1个、全国农业旅游示范点1个以及多个各级乡村旅游村。这是一座千年古城，是开莆来学的发源地、莆田文化的肇始之地，出过175位进士，史有“十室九书堂”之别称，也是闽中地区革命的摇篮。同时，木雕、油画等工艺美术文化蜚声海内外。

　　满眼皆山水，处处有人文，如何立足这一资源禀赋，推动文旅融合发展？城厢区文旅局局长许淑珍介绍，区委区政府通过强化顶层设计，突出全域旅游产业定位，在《莆田市城厢区国民经济和社会发展第十三个五年规划纲要》中把旅游业确立为重点发展的五大产业之一，并高标准制定《城厢区“十三五”旅游发展专项规划》，对旅游业发展进行了详细规划，列入每年国民经济和社会发展计划重要建设任务。“十四五”期间，城厢区紧紧围绕市委“俯下身子抓产业、一心一意谋发展”的工作要求，把文旅经济列入10条重点产业链之一，全力做好文旅融合发展大文章。

　　千年岁月沉积出深厚的文化底蕴，用好自身优势，发展文旅经济，城厢区积极出实招、求实效。

　　近年来，随着旅游业发展品质持续提升，城厢文旅基础设施更加完善，配套设施日益齐全。全区逐年加大资金保障力度，并落实旅游土地用地和政策保障，基础配套功能增强，公共服务体系也不断优化。

　　随着大数据、云计算、物联网等现代信息技术的应用，城厢区“智慧旅游”方兴未艾。在绶溪公园、九龙谷景区、御庄园温泉度假区等景区，可实时对客流信息进行采集。全区A级以上景区通信信号畅通、实现免费WiFi、公共视频全覆盖，4A级以上景区还提供智能导游、电子讲解等服务，已初步建立“一张图”大数据平台。

　　深耕浓郁底色，下好“文旅一盘棋”，“靓”出发展新画卷。

　　文旅融合 细绘发展“工笔画”

　　每到周末，不少家长带着孩子在位于常太镇岭下村的一亩芸生态园研学。“发挥自然和文化资源优势，以‘新文旅+新田园+生态园’为核心，发展登山、露营、民宿等。”项目负责人蔡雅红介绍，将建设生态环境优良、综合效益显著的绿色生态旅游带，“食、行、游、娱、学”一应俱全。

　　眼下，正值草莓采摘时节，常太镇下莒村10座草莓采摘园温室棚迎来了大批的市民。草莓园负责人李龙焰说，草莓园每年吸引游客1万余人次观光采摘。

　　近日，位于莆田文献广场的“文献夜市”项目完成建设，琳琅满目的小吃、烧烤、饮料，统一规划、干净整洁的小摊，整齐排放的桌椅等，无一不散发着浓郁的“烟火气”。

　　文旅融合，赋予青山绿水、文化资源新的内涵和希望。用心用情绘好文旅融合这幅“工笔画”，激活了文旅发展一池“春水”。

　　据介绍，城厢区以打造“一核二轴、四区八园”文旅产业发展格局为路径，全力谋划一批能落地、效益好、可持续发展的优质文旅项目，大力发展“文化+旅游”“乡村+旅游”“智慧+旅游”等，策划推出青山绿水之旅、非遗探索之旅、名人故里之旅、禅修森林之旅和生态文化游等5条主题线路，同时探索“文化+文物+非遗+民俗+旅游”等文旅叠加模式。

　　厚重博大的文化底蕴、历久弥新的文化传承，绚丽丰富的旅游“富矿”，让人文城厢精彩“出圈”，光芒闪耀。依托莆田国际油画城探索油画交易市场向“油画艺术+文化旅游”特色文化平台发展，提升城市文化艺术氛围；依托常太镇、华亭镇开发一系列美丽乡村游、绿色花卉游、农业采摘游等旅游项目，形成半浮生文创园、忘忧谷露营地等一批具有特色的乡村旅游品牌，发展以田园采摘、民俗体验、生态休闲等为主体的乡村体验综合体；推动庄严苑、春晖木雕、台兴食品、复茂食品等企业朝观光工厂转化；植入特色文化产业，培育旅游+工艺美术，推进鞋艺小镇建设。通过云端旅游推介、平台直播带货、云端认养枇杷树等，创新旅游经营模式，助力全域生态旅游发展。

　　区重点产业日常调度组干部张与望介绍，该区还强化产业项目支撑，明年文旅经济重点推进木兰溪十里风光带、钟潭工艺小镇、泗华郊野公园、凤凰“福道”等12个文旅项目建设，塑造“多彩城厢”品牌，以禀赋资源为墨，借项目建设之劲，挥笔写下新时代的文旅发展新篇章。

　　绽放新色 擘画山水“新蓝图”

　　12月17日，在常太镇“这不措文创园”，工人们忙着室内装修，预计年底前完工。文创园将建成高端民宿集群，配套建设露营基地、采摘基地等，打造生态旅游综合体。

　　连日来，在木兰溪十里风光带一期工程项目“八二一”大桥北两侧堤外滩地建设现场，沿线风光节点“八二一”人民广场（左岸段）加快建设，目前已完成土地平整，将对硬化地进行改造，通过引水工程形成景观水塘。

　　站在新起点，展现新作为，以文旅项目丰富业态、补齐短板、焕新城市空间。城厢区将以成功创建省级全域生态旅游示范区为新起点，立足文旅资源禀赋和产业发展方向，融合提升区域品质能级，进一步加大招商力度，为实现“满眼皆山水 处处有人文”的全域旅游大格局努力奋斗。

　　许淑珍表示，全区持续加强民生工程建设，强化智慧体育公园、新建图书馆分馆、文化馆分馆等，并策划举办品牌特色活动，加速带动文旅经济消费能力，精心策划推出精品路线，让游客“走进来”“留下来”“住下来”。

　　为确保招商项目持续有为，下一步城厢区将邀请专家对文旅资源融合创新进行指导，精准规划产业发展，创建特色文旅IP，打造独特性、标杆性的文旅产品。凤凰福道植物园、悠然栖梦特色小镇等文旅融合项目将落地，集合“光影+演艺+游船”的方式，打造绶溪夜游场景；盘活乡村旅游资源，规范民宿经营管理，持续培育打造金牌旅游村等省、市级文旅品牌。同时，通过拓展融合发展工艺美术产业、沉浸式体验消费等，发展富有特色的全链条文旅业态，形成集赏、游、购、研、学于一体的文旅全业态，打造木兰溪畔文化和旅游融合发展的亮丽名片。

　　洋溢着古韵今风的城厢散发出无穷的活力与魅力。2016年-2019年，城厢区游客数量保持年均18%以上增长，2021年游客接待量居全市第一。

　　文旅谱新篇，今朝更好看。以文为笔，以旅为墨，城厢文旅的幸福图景必将更精彩。（记者 林晓玲 通讯员 蔡新添）
