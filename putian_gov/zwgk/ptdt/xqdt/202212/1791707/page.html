涵江区：加快构建现代产业体系推动经济社会高质量发展

来源:湄洲日报 时间：2022-12-29 08:47
| | | |
　　这一年，涵江区高效统筹疫情防控和经济社会发展，统筹发展和安全，各项事业取得新成效。跻身全市唯一获评“平安中国建设示范县（区）”“2022年中国工业百强区”，还获评省级数字经济核心产业集聚区。
 
　　12月27日，涵江区突出经济贡献企业表彰大会召开，为今年以来纳税超500万元以上的78家企业颁奖，进一步激励士气、鼓舞信心，在全区上下持续营造尊重企业家、尊重纳税人的浓厚氛围。这是涵江重视工业、服务企业的客观印证，更是广大企业家拥抱涵江、深耕涵江的选择证明。
 
　　2022年是党的二十大召开之年。涵江区深入学习宣传贯彻党的二十大精神，高效统筹疫情防控和经济社会发展，统筹发展和安全，各项事业取得新成效。跻身全市唯一获评“平安中国建设示范县（区）”“2022年中国工业百强区”，还获评省级数字经济核心产业集聚区。
 
　　这一年，涵江站位大局，坚守实业，提升城市品质，夯基惠民增福祉。涵江区委书记、莆田高新技术产业开发区党工委书记连向红说：“我们坚持把发展经济的着力点放在实体经济上，加快传统产业转型升级，新兴行业全面布局，四大经济融合发展，努力推动经济实现质的有效提升和量的合理增长；坚持融入全省区域经济发展和全市‘东拓滨海、南进临港’城市布局，推进教育、科技、人才三位一体发展，建设现代化滨海产业新城；坚持以人民为中心的发展思想，建设绿色高质量发展先行区，不断提升人民群众获得感、幸福感、安全感。”
 
　　数字赋能培优育新强链
 
　　从涵江滨海产业新城上空俯瞰，百威雪津啤酒有限公司两座相连的蓝色巨大厂房与不远处的海天连成一线，气势磅礴。这座世界级智慧低碳工厂把“绿色”渗透到生产的每个环节，创造性地降低了总体能耗，不仅节约大量成本，也为企业增添国际竞争力。
 
　　就在上个月，百威雪津啤酒有限公司成功上榜国家重点用水企业水效领跑者。
 
　　时间往前推，今年7月，百威莆田精酿啤酒工厂正式投产。这是福建省首家精酿工厂，建筑面积约5500平方米，产能1万吨/年，主要出产世界级高质量精酿啤酒。
 
　　作为百威致力于创新、高端化的又一个里程碑，该公司坚持走扩规模、增效益、铸特色、延链条的高质量发展之路，在供给侧结构性改革和传统产业转型升级上作出了示范、树立了标杆。
 
　　这一年，百威雪津还将年产能提升至200万吨，入列2022年全省百强企业名单。
 
　　云度新能源汽车有限公司位于涵江区江口镇。走进冲压车间，眼前的自动化“产房”正在输出车壳。利用世界先进的机器人设备，该公司书写着利用人工智能技术进行生产的新篇章。
 
　　云度已形成拥有300多人的研发团队，人才结构涵盖汽车行业、无线通信、智能网联等领域。数据显示，国家知识产权局已受理该公司申请专利745项。其中，已授权538项，包括106项发明专利、350项实用新型专利和82项外观专利。
 
　　在科研的加持下，今年云度还引入战略合作方，年产销量超2000辆，其中，全新智能座舱车型实现量产。眼下，订单已经排到明年。
 
　　此外，国圣食品成为全国最大的即食海带生产基地，百威东南销售、合力泰分别入选全省服务业、制造业、战略性新兴企业百强榜单，6家企业入选省重点上市后备企业名单。威诺数控、全冠机械分别列入全国、省内首台（套），华佳彩、钜能电力等2家企业获评全省数字经济领域“瞪羚”创新企业，山河药业等2家企业技术成果分别获省科技进步奖、专利奖三等奖。
 
　　百尺竿头，更进一步。接下来，涵江区将继续坚持把发展经济的着力点放在实体经济上，突出龙头带动、链式发展，切实提升产业链供应链韧性和安全水平，招大引强补链；深入实施创新驱动战略，以莆田国家级高新区“一区多园”发展统揽新涵工业集中区、城北工业园等园区标准化提升，打造“一园一品牌”，转型升级延链；继续大力发展数字经济、海洋经济、绿色经济、文旅经济，建设四大经济融合发展区，培优育新强链。
 
　　全力打造生态宜居新城
 
　　上个月，“萩山来信·崇福”露营基地开营。这是涵江区主动融入我市文旅产业、打造可复制的循环生态旅游模式的诠释。
 
　　萩芦镇崇福村素来以独特的乡村资源和生态优势闻名。眼下，该村以年轻化业态引流消费。引进莆田市思博文化旅游有限公司与萩芦文旅产业投资有限公司共同运营露营基地，探索“国有企业＋民营企业＋村集体”模式，通过挖掘崇福村的乡村文化价值、生态价值和经济价值，为当地村民提供更多的就业机会，拓宽“五彩萩芦”特色农产品销售渠道。
 
　　涵江区紧扣市委市政府“莆阳开春，开河、开街、开村”部署要求，注重科学统筹和整体谋划，以系统性思维、项目化思路、特色化路径，深入挖掘特色文化资源，做活做足水文章，精心策划打造特色品牌。同时，结合“水上巴士”工程，稳妥推进沿岸景观提升、河道水系治理保护、文旅融合发展等工作，加强基础设施建设，提升公共配套水平，丰富文化服务供给，切实满足市民游客旅游休闲需求。
 
　　当前，全区正在积极推进“莆阳开春”工作。实现“水上巴士”全线通航，双福村获评中国美丽休闲乡村，大洋乡列入省级“全域生态旅游小镇”名单，白塘湖、东方红水库、苏洋陂入选省第一批河湖文化遗产。
 
　　内外兼修、补齐短板。过去一年，涵江区多措并施为城乡品质提档升级。主动融入闽东北协同发展区和福州都市圈建设，高标准编制滨海新城发展规划，联十一线萩芦溪大桥、G228滨海风景道涵江段等一批重大交通节点项目加快建设；统筹推进旧城更新，完成老旧小区改造15个，开工建设棚改房近4300套，水环境综合治理等2个项目列入省级十大样板工程。
 
　　此外，引进万达投资集团，对接洽谈涵江万达综合体，推动欧亚达家具城落地，创办省内首个泛家居城市商业综合体；与省高速集团合作开发赤港服务区双开放项目，投资超百亿元打造“福建特色、全国领先”的交文旅融合发展示范区；加快推进三江口特大桥、紫霄大道、高林街北伸等项目建设，新改扩建片区配套路网10公里，“外联内畅”的交通网络逐步形成。
 
　　夯基惠民增进民生福祉
 
　　24小时不打烊、业务快速办结、矛盾调解不出小区……今年以来，涵江公安分局涵东派出所通过推动警力下沉、警务前移，做强做实做优“夜间警务”，引领“苍然、顶铺、后度‘三合一’”警务室建设提档升级，打造“老百姓家门口的平安驿站”。
 
　　同时，依托智慧安防小区建设，该所“三合一”警务室精准投放巡防警力，采取“派出所＋商铺”联勤模式，共同维护商圈治安秩序，以实际行动让警务更高效、群众更满意。
 
　　在国欢镇上，网格“红管家”服务群众贴心入微，智能平台闪亮登场守护家园，基层调解各显身手巧解乱麻……这些看得见的服务，摸得着的幸福，是该镇以党建引领基层治理，激活“神经末梢”，为民生福祉加码的生动体现。
 
　　今年，国欢镇以省级实绩突出村黄霞村、乡村治理试点村码头村为契机，成立黄霞中心村党委。其中，中心村党委打造黄霞村便民警务室和“综治+”社区治理中心，开设跨村“一站式”综合服务窗口，方便群众、企业办理业务，搭建起一个“全方位”服务平台，实现警务服务事项一网通办。据介绍，这是一个跨村联建模式的有力探索，进一步推动村与村向抱团发展转变，实现1+1+1>3的叠加效应。
 
　　过去一年，涵江区聚集财力，全面完成46个为民办实事项目，推进民生三个“十大工程”，交出民生支出增长25.3%的答卷。
 
　　特别是在深入实施“党建引领、夯基惠民”工程方面，涵江区成立全市首家“情指勤舆”一体化实战中心，首推“食安创城＋网格”模式，深化公安基层基础、涉侨纠纷“一站式”多元化解、“网格＋消防”等经验做法获得省市肯定，涵江网格化中心获评“全国119消防先进集体”，全市率先完成民用船舶北斗系统应用全覆盖。
 
　　值得一提的是，今年涵江区还入选省级青年发展型城市（县域）建设试点名单，为全市唯一。（记者 蔡晨晖 通讯员 林亦霞）
