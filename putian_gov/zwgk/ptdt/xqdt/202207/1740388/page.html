涵江区：加快建设滨海新城助力海洋经济崛起

来源:湄洲日报 时间：2022-07-21 08:12
| | | |

　　涵江区累计完成投资约30亿元，实施涵江临港产业园陆域形成一期围填海工程；加快发展海洋经济，累计完成各类基础设施投资超百亿元。

　　蔚蓝的兴化湾，海阔天空。

　　与秀屿港、湄洲湾港不同，南岸的涵江有着风平浪静的港区环境和清爽湿润的宜人气候，具备了开放发展得天独厚的优势与禀赋，发展海洋经济潜力巨大。

　　向海挖潜力、要质量、求效益，涵江区深入学习贯彻习近平总书记关于海洋强国建设的重要论述，紧抓省市发展海洋经济、建设“海上福建”“海上莆田”的难得契机，落实省委“提高效率、提升效能、提增效益”行动部署，俯下身子抓产业、一心一意谋发展，进一步优化港口功能布局，集聚发展临港产业，积极培育“蓝色”增长点，全力构建港产城联动发展新格局。

　　挖掘潜力 全域统筹

　　依海逐梦，向海而兴。早在唐朝贞观年间，涵江先民围海造田，筑涵排涝，宋代便形成小集镇，是莆田一带的交通枢纽。到明清时期，涵江雄踞全省沿海四大名镇之一，成为商埠重镇，三江口港曾设海关、河泊所，有“小上海”“东方威尼斯”之称。可以说，涵江自古以来就是莆田的商业重镇。

　　把握时代脉搏，向海图强，不断打开海洋经济发展的新天地，是涵江区委、区政府的奋斗目标。在深耕蓝海的大潮中，涵江区把港产城联动放在更高的位置，坚持全域统筹、陆海联动，大力推进涵江滨海新城建设。

　　涵江港区建设服务中心主任李滨介绍，涵江滨海新城规划总面积5563公顷，东与福州江阴港隔萩芦溪相望，北临沈海高速公路，西至木兰溪北岸，南抵湄洲湾港兴化港区港口前沿线，背靠莆田高新区，紧邻涵江城区，是我市融入福州都市圈建设的“桥头堡”，区位优势明显。不仅如此，其北侧的福厦铁路、福厦高铁、沈海高速、莆炎高速及国、省干线等贯穿后方，交通优势十分明显。

　　顺应时代潮流的重大战略决策，目前全区累计完成投资约30亿元，实施涵江临港产业园陆域形成一期围填海工程，已开发利用原有滩涂海域形成围海面积约1600公顷，形成陆域面积约1000公顷，累计完成各类基础设施投资超百亿元，开发腹地优势明显。

　　7月18日，记者驱车来到围填海工程现场，可见江阴港与涵江港仅隔着一个入海口，不远处的蓝色海湾人水和谐。大型运输车来回穿梭，脚下的堤岸向海里直线延伸。不久的将来，新的绿色产业园区拔地而起，高科技“智囊团”集聚，拉动的是海洋经济发展的新增长极。

　　要实现海洋经济快速、健康发展，首先规划要先行，绝不能各顾各发展。

　　前不久，涵江区委托编制的《涵江区滨海新城战略规划和产业规划》新鲜出炉，战略定位、产业体系、实施保障、开发策略等一目了然。“借势港口经济和福州都市圈、厦漳泉都市圈经济的双重驱动，紧抓蓝色经济和绿色经济的双重引擎，坚持脚踏实地、精准定位、开放创新、主动协同，推动区域高质量发展，将涵江滨海新城建设成为零碳智造湾区……”整个滨海新城的发展轮廓越来越清晰，港产城融合发展潜力巨大。

　　产业集聚 形成规模

　　“向海时代”乘风起。

　　发展海洋经济，产业是核心。涵江区找准在全国全省的坐标定位，自觉把临港产业和港口发展放在发展海洋经济、推动港产城联动的全局高度，系统谋划，重点发展科技含量高、技术进步快、产业关联度强、附加值高的装备制造、食品加工、电子信息、新材料、海洋生物产业及现代港口物流等，形成国内龙头产业化集聚效应，高质量建设好滨海新城。

　　从“一纸规划”到项目“多点开花”，涵江区已先后建成亚洲单体最大的啤酒基地百威雪津、亚洲单体规模最大的印花玻璃生产基地长城华兴玻璃、国家新能源产业创新示范区核心基地HDT高效异质结太阳能电池、拥有全球领先易拉罐制造工艺的中粮制罐、全国最大即食海带生产基地国圣食品产业园、普洛斯物流园、通号5G产业园等食品加工、高端装备、新能源产业的龙头项目，以龙头项目及延链补链强链项目，带动形成产业向“高端化、低碳化、集群化”发展。

　　傍水而生，涵江临港产业正踏着浪花的节奏，借助莆田高新区的优惠政策叠加、产业技术辐射，铿锵绽放。眼下，百威雪津175万吨扩200万吨产能的生产线、长城华兴玻璃2号炉15万吨产能生产线等一批项目相继启动建设，粮食联合储备库项目已投产，总投资13.06亿元的福建龙源风力发电一期项目已完成全区屋顶分布式光伏项目备案。HDT高效异质结太阳能电池项目约7.6万平方米标准化厂房也已投入使用，实现年产800MW生产线的建设，打造莆田新能源产业创新示范区。对接国家数字经济创新发展试验区（福建）工作要求，联合央企通号建设集团共同打造含标准化厂房、研发大楼、总部办公楼、生活配套等总建筑面积约70万平方米的创新平台体系相对完善和较强数字经济产业链的临港5G新基建产业园。通过产业园平台建设，实现招商引资的产业迅速聚集落地，形成产业规模。

　　今年以来，涵江区海洋经济产业领导小组梳理形成了28家规上企业纳入全市发展清单。上半年，28家规上企业实现产值106.96亿元，增长14.4%。

　　经略海洋，向海取经，涵江一直在努力探索，发展气场升腾，势如破竹。“尽管困难重重，但实现海洋经济发展目标，我们有条件有信心。”这份信心源于涵江多年发展海洋经济打下的坚实基础，源于干群不仅有敢于梦想的激情，更有善于圆梦的担当。

　　产业园区在建项目及后续工程建设资金缺口较大，影响项目建设进度。涵江区发改局紧盯国家政策导向，提前谋划，配合完成项目前期审批手续，全力争取专项债券资金，共争取专项债券项目3项，下达额度14.58亿元，用于莆田新能源产业创新示范区涵江临港标准化厂房及周边配套基础设施项目、沈海高速涵江互通及接线工程、福建（莆田）国家新能源产业创新示范区（涵江核心区）基础设施及公共服务平台建设等项目建设。

　　完善设施 引凤还巢

　　海洋是涵江高质量发展的潜力所在、希望所在、未来所在。发展海洋经济，港口设施建设是基础。

　　涵江滨海新城南侧的湄洲湾港兴化港区涵江作业区可规划港口岸线8.4千米，可规划建设3-10万吨级泊位28个，启动区可规划岸线5.5千米，可布局18个3-10万吨级通用泊位，港口优势明显。为全面融入“海西港口群”，涵江区已累计完成投资约9亿元，紧锣密鼓推进1-3号泊位建设。

　　对接货运铁路，做优“海港”“陆港”集疏运体系，涵江区加快启动江涵大桥、萩芦溪大桥、三江口特大桥等，并已累计完成投资约28亿元，新建后郭路、锦岚大道、联十一线连接线、联十一线涵江段、东港路、港前路等配套道路基础设施。累计完成投资约4亿元，建成一座日处理能力3.5万吨的污水处理厂、一座110KV变电站及日供水10万吨自来水专管的市政配套基础设施，正全力推进涵江滨海新城内陆域形成、市政路网、防洪水利等配套设施建设，达到“栽好梧桐引凤来，归雁阵阵凤还巢”的目的。

　　以海为媒，涵江正以时不我待、只争朝夕的奋斗精神，劈波斩浪，按下海洋经济发展的“加速键”，为打造现代产业强区、建设宜居生态涵江加码。（记者 蔡玲 通讯员 林亦霞）
