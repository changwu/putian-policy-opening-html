秀屿区：积极招商引资奋力推进高质量发展超越

来源:湄洲日报 时间：2022-05-13 09:38
| | | |

　　秀屿区一季度共洽谈对接项目34个，总投资额约381.1亿元。其中，正在洽谈对接22个项目，总投资额226.8亿元；实现签约落地项目12个，总投资额约154.3亿元。

　　重点项目加快建设，厂房车间生产忙碌……今年以来，秀屿区各条产业链发展及招商引资工作持续推进。

　　招商引资是经济发展的源头活水。秀屿区深入贯彻落实省委“提高效率、提升效能、提增效益”行动要求，紧扣市委市政府部署要求，俯下身子抓产业、一心一意谋发展，始终把招商引资作为经济发展的主抓手、强引擎，坚持“一把手招商”，科学谋划、统筹推进，以高质量招商引资推动经济社会高质量发展，为奋力答好谱写“福建篇章”的莆田答卷贡献秀屿力量。

　　立足产业 精准招商

　　4月26日，秀屿区召开全区重点产业发展暨招商工作推进会，对相关工作进行再谋划、再部署、再落实，确保二季度结果好、上半年“双过半”。

　　眼下，全市重点发展12条产业链，秀屿区涉及10条，既有“顶天立地”的超百亿化工新材料、纺织新面料、新能源等战略性新兴产业，也有“铺天盖地”的鞋服、工艺美术等传统产业。其中，新型功能材料产业年产值突破320亿元，引领全市新型功能材料产业集群跻身“国家队”，列入国家发改委首批66个战略性新兴产业名单；新能源产业年产值超240亿元，为实现“双碳”目标作贡献；海洋经济做优做强，水产品产量及渔业产值居全市第一、全省第二；生命健康、鞋服、工艺美术、食品等产业与数字、绿色、文旅等经济风生水起，也取得了亮眼成绩。

　　围绕港产城联动发展主线，今年以来，秀屿区按照“一条产业链，一个牵头部门，一个工作专班”思路，全面落实“链长制”。各产业发展小组专班依据产业链“全景图”，出实招、出硬招，进一步量化目标任务、细化阶段安排、明确项目支撑，推动产业集群集聚发展。

　　发展靠产业，产业靠项目，项目靠招商。一直以来，秀屿区高度重视招商引资工作，将其与产业发展同步谋划、同步推进。秀屿区招商服务中心主任黄亚强介绍，该区围绕产业链延链补链强链，审慎处理好招商与选资、收入准入投入、生产生活生态等关系，强化项目用地用林用海资金等要素保障，注重保基本惠民生，紧盯“开竣投”，狠抓项目落实，有效激发经济发展新动能。

　　值得一提的是，该区招商引资推行“一二三四五”，即一年建成、亩均税收至少20万元、投资强度不少于300万元、工业产值400万元、50亩左右以下用地，旨在招好商、招大商、招强商，推进经济高质量发展。

　　在“一把手招商”的引领下，秀屿区坚持专业化招商、小分队招商，加强精细化招商，突出产业链招商，抓好存量二次招商，通过整合产业链、创新链、投资链、服务链、人才链等多维要素资源，不断为招商引资赋能提效，构建更加有利于产业发展的生态环境。

　　今年一季度，该区领导带领招商小分队分别前往北京、河南、浙江等地进行招商考察、对接项目，先后召开或参与各级招商专题会议40余次，举办或参加产业链招商项目集中签约活动3场。据统计，一季度共洽谈对接项目34个。

　　谋划项目 加固链条

　　当前，秀屿区正大力实施“科教兴区、海洋富区、工业强区、物流活区、新城旺区”战略，坚持把加强重大项目建设作为稳增长的关键抓紧抓实，以项目带动加固产业链条。

　　在新型功能材料产业方面，秀屿区以石门澳产业园作为国家级新型功能材料产业集群核心承载园区为依托，着力凸显产业集聚优势，全力抓龙头、铸链条、建集群。目前，该区共落地永荣CPL、中锦PA6、丙烷制丙烯、50万吨华峰再生功能性纤维等32个省、市、区重点项目。围绕强链延链补链扩链，招商方面主攻涤纶、锦纶、丙烯、尼龙66、新型涂料、轮胎等6条产业链条。

　　在开春举行的全市民营经济暨产业发展大会上，作为重大项目签约落地的己二腈一体化项目，是尼龙66及产业链配套项目的重要组成部分，将突破特种材料“卡脖子”原料己二腈对产业链的限制。建成后，也将延伸新材料产业链，产生综合叠加效应。

　　生命健康产业是关系国计民生的重要产业。作为“民营医疗之乡”，秀屿区主动承接莆田海峡两岸生技和医疗健康产业合作区政策外溢，积极招商、引才、纳智，先后落地了新昶多肽园、药械网、宏宝药械产业综合体、栢合冷链物流园等项目，仓储、研发、制造、配送、销售全产业链业态初具雏形，起跑腾飞。在今年2月8日举行的秀屿区生命健康产业暨招商推介会上，6个项目集中签约，涉及生物制药、医疗器械、医养、供应链平台、产业协作等内容，总投资约18亿元。其中，一个项目已转为在建项目。

　　5月7日，秀屿区召开海洋经济发展调研座谈会，邀请中科院海洋所研究员李钧、博士林承刚与市海洋与渔业局、水产科学研究所等专家，座谈把脉秀屿海洋经济发展。该区去年实现海洋生产总值200亿元，占GDP比重高，但也面临港产联动不足、产出效益不高等问题，亟须通过项目带动，做大做强龙头企业，打造海洋经济新增长点。

　　深海网箱养殖融合漂浮式海上风电示范项目是秀屿区海洋经济产业招商的亮点，同样作为重大项目在全市民营经济暨产业发展大会上集中签约。该项目投资7亿元，计划在南日岛海上风电场一期项目场区周边海域建设浮体平台，作为海上立体养殖科技示范基地。

　　据介绍，该项目是国家能源集团“十四五”十大重点科技攻关项目之一，将探索发展出一套漂浮式风电融合深海养殖的技术方案，在南日岛海域利用风机浮体平台作为养殖基地进行海上立体养殖，以电养鱼、以渔养电，助推提升产业协同，促进海洋经济发展。

　　强化服务 蓄积后劲

　　“五一”节后，秀屿区重点产业发展暨招商工作日常调度和督查考评工作专班人员忙着调度收集各产业链及各责任单位产业的相关数据，并督促相关单位将产业发展各环节推进情况同步上传至全市统一的产业发展云平台，依托大数据进行深度分析，科学统筹推进各项工作。

　　据介绍，该专班于3月成立以来，主要职责是围绕区重点产业发展和招商工作目标任务，进行“月调度、季通报、年总评”，重点考评重大产业项目推进情况，包括促签约、促开工、促竣工、促投产项目等。

　　为促进签约项目落地，秀屿区按照《秀屿区重点项目推进工作制度》进行管理，实行“一个项目，一套推进工作方案，一个处级领导挂钩推进，一个责任单位具体负责，一个服务专班全力服务”的“五个一”工作模式。通过成立前期服务中心，做好用海、用林、用地等前期要素保障工作，并建立招商项目代理代办机制，设立审批代办服务窗口和网上特设专栏，为投资者提供“量身定制、全程代办”的服务，全力提供政策咨询、报批指导、协办帮办、接力代办等线上线下服务。在企业融资方面积极搭台，做好银企对接。

　　常态化疫情防控下，招商不停步。秀屿区探索和完善网络招商、云端互动模式，“面对面”变为“屏对屏”“键对键”，通过线上线下两条腿走路，确保项目对接不断线、招商服务不断联。协同市里充分运用市场化招商模式，引进第三方专业招商机构，开展中介招商、平台招商、园区招商、代理招商，创建专业化招商新机制。注重用好莆籍在外乡贤资源，激发莆资莆能莆智活力，抓好节会招商。

　　为蓄积充足发展后劲，秀屿区正全面加强项目招引储备。黄亚强介绍，按照“龙头企业-产业链-产业集群-制造基地”的思路，该区以招大招强为着力点，瞄准与该区产业发展契合度高的行业领军企业，通过“一企一策”量身定制招商专案，精准匹配落地要素，重点围绕10个重点产业规划，加大招商对接力度，紧盯大企业、大项目，着力引进一批产业链主导型企业、行业龙头企业、“隐形冠军”“独角兽”及专精特新“小巨人”企业，力争形成集聚上下游产品、降低综合配套成本、拉长产业链条、培育优势支柱产业的产业集群发展格局。（记者 林英 通讯员 吴志军）
