仙游县：扎实推进创城常态化提升城市品质

来源:湄洲日报 时间：2022-09-05 08:28
| | | |

　　仙游县把提升城市品质融入省级文明县城常态化创建，完善基础设施建设，营造城区整洁环境，在落实细节中堵塞漏洞、在完善细节中打造亮点、在提升细节中形成特色，充分展示城区良好形象，不断满足人民群众对美好生活的向往，让文明创建惠及于民。

　　“创城不是‘技术活’，而是责任心，要各方协调联动，凝聚动力合力，以抓铁有痕的举措抓创建。”夏秋之交，仙游县召开创建省级文明县城常态化工作推进会，增强干部责任感和紧迫感，把创建文明县城的成果巩固好、提升好。

　　以长效机制促常态管理，仙游县把功夫下在平时，把工作做在日常，着眼群众关心关注的突出问题，持续改善城市环境面貌，提升城市形象和品质，高质高效推进省级文明县城创建，增强群众的幸福感、获得感和安全感。

　　完善设施撑起硬实力

　　从玉井大桥至榜头坝下大桥，25公里的景观步道，沿线融入仙游当地文化元素。漫步其间，风光旖旎，不时可见居民悠闲健身。

　　如今，仙游主城区“一溪两岸”建成区面积达27.4平方公里，城镇化率达48.9%。8月，对照省、市城市品质提升评分标准，仙游县考评综合排名全市靠前，城建项目进度排名全市第二。

　　在创建中提升，以提升赋能创建。仙游县从惠民利民便民角度出发，持续加大基础设施配套建设，完善18个乡镇综合文化站内功能设施建设，完成全县324个村居综合文化服务中心建设，建成德孝文化主题公园、圣泉廉政文化主题公园等，城区旧貌换新颜，也提升居民精神文化生活质量。

　　暑期，众多市民慕名来到仙游县四季体育休闲小镇，健身房、篮球、羽毛球等场馆“动感十足”。而这家上规模的体育小镇，竟是以旧厂房改造而成。

　　仙游县是著名的体育之乡，民间运动氛围浓厚。该县创新思路，瞄准城市“金角银边”，以闲置的旧厂房、旧仓库、旧建筑物改造健身场馆。四季体育休闲小镇、温泉体育休闲中心、阳光建设俱乐部等一批体育休闲综合体陆续投用，不但解决运动场馆稀缺问题，也完善该县体育设施服务体系，释放群众健身热情。

　　今年，仙游县把落实县委县政府“1299”工作部署，融入省级文明县城常态化创建，持续提升城市品质。

　　记者从县住建局了解到，该县从提升城市宜居水平、 打造城市风貌特色、历史文化保护利用、城市夜景照明、井盖杆线整治、无障碍设施改造提升、城市生活垃圾处理、城市精细化管理、保障性安居工程等9个方面实施65个项目，年度计划完成投资26.32亿元。目前完成投资21.98亿元，占年度计划投资的83.51%，超序时推进。

　　在新区拓展方面，加快对高铁片区、坝垅片区的地块开发建设，展示仙游城市形象。围绕城市生态屏障区建设、城市生态廊道建设、城市公园建设方面，共实施9个项目，奋力营造生态连绵环境。

　　统计数据显示，仙游县今年新增城区停车泊位1137个，投放公共自行车5845辆，群众出行更便捷。为促进交通通达，该县围绕城市道路建设、完善公共交通、增设公共停车设施、慢行系统建设、开展交通整治等方面，共实施17个项目。此外，推进排水防涝、保障城市供水、城市生活污水处理提质、强化燃气安全监管、强化房屋专项行动等，以文明创建常态化实现惠民长效化。

　　环境整洁擦亮新名片

　　8月下旬，仙游县城市管理局联合鲤城街道、鲤南镇等部门对城区沿街市容市貌展开专项整治，助力省级文明县城创建。

　　沿街商铺将商品或杂物摆放在店外公共区域，不但影响市民通行，还不整洁美观。执法人员与商户沟通，帮助他们清理门前杂物，引导流动摊贩到指定的划线便民服务摊点内经营，督促各店铺商家履行“门前三包”职责，对屡劝不改者，按照相关法律法规依法处理。

　　对标对表，补齐短板弱项，确保不留死角、不留漏洞、全面达标。5月以来，该县对紫檀南街沿街店面人行道杂物进行清理整治，清除石块、违规广告牌、乱堆废弃木椅子、木框等。对主次干道流动摊点、占道经营、店外经营、私搭乱建、乱堆乱放等现象清理整治，确保沿街店面干净整洁。

　　车辆乱停乱放不仅给城区添堵，更影响道路交通安全。仙游交警结合夏季整治“百日行动”助力创城。行动中，交警、城管部门对城区内机动车、非机动车乱停乱放等不文明现象开展专项整治；对八二五大街、解放路、池头圆圈、金石中学门口等路段展开巡查，处置随意停靠的电动车、摩托车等，从严治理车辆乱停乱放行为。

　　县里推行城乡一体的路面保洁制度，明确道路冲洗、洒水频次，控制城市郊区道路扬尘。加强对运渣车撒漏、车容脏乱、带泥上路、无证运输和不按规定线路行驶等监督执法，要求使用全密闭的运渣车并安装卫星定位系统。定车辆、定线路、定渣场，确保城区道路交通环境安全、畅通、文明、和谐、有序、整洁。

　　治理从地面向空中延伸。8月26日， 鲤南镇联合县城市管理局、电力公司对多处新增的楼顶违建，展开专项清理行动。当天依法拆除3处楼顶违建，督促整改20余宗违建，促成自行整改4处。

　　治理也从地面向地下伸展。县里开展水质监测，夯实城乡污水收集处置设施，提高污水收集处置率，全面消除城市建成区黑臭水体。落实控源、截污、清淤、活流措施，推进城镇合流制和混流制排水系统雨污分流改造，老旧污水管网普查修复，对主干管渗漏、错位、破损以及小区接主干管的通道错接、漏接情况进行排查整治。

　　创建为民、创建惠民、创建靠民。在创建过程中，市民文明意识悄然提升，思想上主动从“要我做”到“我要做”转变。

　　数字赋能提升新品质

　　“进入生活垃圾分类指挥平台，就可看见各个垃圾分类屋的位置分布。”在仙游县环境卫生管理所，工作人员林利丽通过大屏幕查看垃圾分类投放情况。

　　仙游县分类办副主任、县环卫所主任黄伟建介绍，该县在全市率先建成生活垃圾分类指挥平台。该平台可以监督分类屋周边环境卫生整洁情况以及居民落实垃圾不落地的情况。遇到不规范分类的，通过探头喊话及时纠正。

　　今年以来，仙游县城市管理局构建平台，推进数字化城市管理，共享公安交警、治安等公共视频资源，设立5名专职稽查员实时管理，及时发现破坏城区市容市貌和环境卫生等违规情况。在公共视频设备中加入智能分析算法，对无照经营游商、占道经营、店外经营、乱扔垃圾等违法违规行为进行智能识别、智能抓拍、智能预警，推动城市管理工作向自动化、智能化转变。

　　以高质量发展为主线，仙游县加强新型基础设施投入，加快智慧城市建设，建设宜业宜商之城。发展在线经济、线上服务、数字民生服务，加快人工智能和实体经济的深度融合，推动城市经济实体智能化转型。

　　县发改局数字中心主任郑建胜说，数字化成为联结商家与消费者的核心中枢，保证产销链持续不断。下一步，仙游县将通过产业与金融、物流、交易市场、社交网络等跨界融合，构建“生产服务+商业模式+金融服务”多业态，形成数字经济新实体，让千年古邑更有烟火气，提升居民幸福感。

　　全力冲刺，强力推进，仙游县以势在必胜的决心抓创建，不断刷新县城新“颜值”，交上一份让人民满意的民生答卷。（记者 黄凌燕 通讯员 郑志忠）
