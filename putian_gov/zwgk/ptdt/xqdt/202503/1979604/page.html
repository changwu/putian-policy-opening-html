涵江区：加快推动全领域数字经济发展

来源:湄洲日报 时间：2025-03-20 08:26
| | | |

　　涵江区推动传统制造业智能化升级，打造电商新业态集群，深化校企合作，构建“理论+实践”人才培育模式，为数字经济注入持续动能。

　　发展数字经济是把握新一轮科技革命和产业变革新机遇的战略选择。涵江区加快推动全领域全行业全产业链数字赋能，优化数字产业生态，放大园区平台集聚效应，持续丰富数字经济业态，挖掘和拓展数字技术应用场景，培养留住数字人才，为涵江数字经济发展注入新动能、开辟新空间。

　　数字赋能创新创造

　　近年来，涵江区深耕“数字+”，推动产业数字化和数字产业化，加快建设省级数字经济核心产业集聚区，为我市全力打造国家数字经济创新发展试验区（福建）重要承载区注入强劲动能。

　　食品产业是涵江传统产业，啤酒制造更是闪亮的一颗明珠。近年来，百威雪津啤酒有限公司着力推动数字化改造，赋能传统产业，激发提质增效新动能。

　　走进百威雪津啤酒有限公司的世界级低碳智慧工厂，一条机器狗在酿造生产区代替人工进行每班次85分钟的日常繁琐巡检。该公司接连投用了自动解膜机、自动解带机、自动标签检测机等一系列生产制造“黑科技”，使用“高速摄像+AI技术”进行玻璃品自动化检测，每年节约大量人力成本。其中，智能在线检测、能耗数据检测和设备故障诊断与预测项目入选国家智能制造优秀场景。

　　在福建威诺数控有限公司，记者看到，车间虽不见一人，但生产却井然有序。在智能工厂指挥中心内，生产过程中的实时参数在屏幕上一目了然，制造过程实现自动化、智能化和信息化。去年，该公司的国内首台套重大技术装备WN-DB2015Z×2动柱双面铣镗加工中心，荣获国产数控机床最高奖“春燕奖”。

　　据了解，去年涵江区以科技为先导，数字为驱动，持续夯实数字基础设施，强化基础保障，提升服务供给质量，全方位推动产业发展数字化转型。全区数字经济产业链22家规上企业，实现产值124.35亿元，占全区总产值17.1%；用电量3.15亿千瓦时，总量位居全市第三名；税收8.61亿元，总量位居全市第一名。

　　该区以“智改数转”为抓手，深入推进产业数字化转型。积极培育百威雪津、荣兴机械、飞阳光电等工业互联网应用企业，2024年制造数字转型诊断完成47家，完成率达117.5%，位居全市第二。以“新型基建”为支撑，全面筑牢数字发展底座，扎实推进“5G战略领先”与“信号升格”专项行动，新建5G基站287个，超额完成任务，5G网络覆盖广度与深度得到显著拓展。同时，积极推动数字基础设施建设，北斗卫星导航产品联合实验室已签订协议。该实验室建成后，将面向广大企业，提供产品质量检测、问题诊断等全方位专业技术服务，助力企业数字化升级。

　　电商产业集群集聚

　　涵江自古是商贸重镇，素有“小上海”美誉。近年来，该区更是抢抓数字经济风口，立足商贸服务业优势，积极推动电商产业集聚化、园区化发展，数字经济实现蓬勃发展。

　　3月17日，记者来到位于涵西街道苍口安置区的尚书数字经济创业园启动区。启动区内有30万平方米住宅，3万平方米裙楼街区，方圆1.5公里范围内，辐射楼盘小区30余个，常住人口约20万人，是涵江主城区商贸集中区、创业集中地。

　　走进尚书数字经济创业园的亿珊莱名品展厅，鞋服箱包一应俱全，销售员正在一台补光灯下，直播讲解其品牌的爆款商品。作为去年底刚入驻园区的一家小微电商企业，亿珊莱瞅准鞋服作为涵江区传统产业所具备的供应链优势，在这里开启了电商创业征程。凭借创业园电商集聚的平台优势，亿珊莱快速实现了业绩的突破，一季度至今营业额已近百万元。

　　一墙之隔，三木沐跨境电子商务有限公司内，数十名运营人员正在平台上对新上架的产品开展测试。作为最早入驻创业园的电商企业，三木沐在亚马逊日本市场拥有多个自有品牌，已成长为园区内的头部电商之一。“选择入驻这个创业园，看中的便是这里良好的区位和完善的配套条件。”三木沐跨境电子商务有限公司总经理刘丽雯说道。

　　“尚书数字经济创业园充分利用盘活安置区裙楼楼宇空间，通过引进运营服务商、供应链服务商等专业服务机构，搭建起汇集多功能数字经济公共服务平台。”涵西街道有关负责人告诉记者，创业园为涵江商业企业、工业企业、实体商家店铺等，提供电商人才培训、网络营销、信息交流、产品展示等相关服务，发挥创业孵化功能，吸纳青年人才，推动数字技术和实体经济深度融合。

　　记者了解到，创业园一期重点引进电商企业，目前已入驻电商企业142家，二期也已启动招商，招商面积达2万平方米，提供多种面积的办公空间，满足不同企业的需求，拟策划围绕健身美妆达人直播、tiktok跨境直播等打造企业专区，打造电商产业集群，推动直播电商、跨境电商等新经济、新业态、新模式发展。

　　校企合作育才留才

　　数字人才作为创新的主体之一，是支撑数字经济的基础，其创新创业活动有助于培育新的经济增长点和发展动力。在涵江，当地着力开展校企合作育才留才，保障数字经济发展后劲。

　　3月17日，一批湄洲湾职业技术学院大二学生在教师陈辰君的带领下，来到涵江电商产业园开展就业指导课。学生们参观了产业园企业，近距离了解电商行业的新动向。“电子商务推陈出新变化极快，实地参观能有效补充课堂之外的学习。”学生们说道。

　　“举办这样一节就业指导课，我只需通过学院创业中心，便可联系产业园对接。”陈辰君告诉记者，湄洲湾职业技术学院与涵江电商产业园建立了良好的互动机制，校企间的合作密切且通畅。

　　涵江电商产业园位于梧塘镇，是集电子商务、创新创业、人才培养、企业孵化、供应链整合等多功能于一体的综合性电子商务产业园。自去年8月产业园建成并投入试运营以来，已入驻电商企业67家，对接鞋服、皮具箱包、黄金珠宝、农特产品等供应链企业上百家，产品超4000种。园区投运以来已完成产值1.69亿元，正成为涵江电子商务的新高地。不久前，涵江区才聚职业技能培训学校在园区内设立，开辟涵江电商人才的培育新路径。

　　3月12日，由涵江区电商产业园和莆田学院商学院、新电商现代产业学院联合举办的涵江校企合作直播电商产创班开班，62名学子通过理论与实践相结合的教学模式，开启为期8周的直播电商技能实训之旅。

　　“我们带着项目开展培训，学生可以在学习中实现一定营收，经过培训的学生人才也更有意愿留莆创业。”涵江区才聚职业技能培训学校有限公司运营总监卢家炜告诉记者，高校学生创造力强，校企合作能帮助他们在毕业前就掌握真实就业环境中所需的技能和能力，实现“毕业即就业，到岗即可用”。

　　涵江电商产业园总经理彭林海介绍，目前产业园和莆田高校展开协同育人合作，为莆田学院、湄职院等电商专业学生提供电商实操实训课程，已在专业课共建、学生第二课堂、校内创业实训班以及毕业前实训等方面达成合作。（记者 周凌瀚 通讯员 林亦霞）
