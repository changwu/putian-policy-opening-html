涵江区：全力破解不动产登记历史遗留问题

来源:湄洲日报 时间：2025-03-27 08:28
| | | |

　　把办证处搬进居民区，全区安置房首登率达91.2%；开设“助企绿色通道”，成立工作专班，为企业解难题；创新服务“五证同发”，助力项目高效建设……涵江深化“放管服”改革，让“登记难”不再难。

　　涵江区聚焦全社会关注关切的不动产登记历史遗留问题，深化“放管服”改革，对“证”施策，打通“证”结，以持续优化的不动产登记服务“软环境”，提升高质量发展“硬实力”。

　　为民解忧暖民心

　　“盼了这么久，我终于领到房屋的不动产权证，心里踏实了，真是太高兴了！”3月初，涵西街道港头片区拆迁自建房群众郑春英解了“心结”，她立即与在外地工作的子女分享喜悦。

　　港头片区为20世纪90年代拆迁自建房，因前期建设审批手续不齐全等历史遗留问题，导致不动产“登记难”，给群众安居乐业带来诸多不便。郑春英告诉记者，她花大半辈子积蓄建起的房子却办不了“房产证”，不能抵押贷款、不能买卖，就连给孩子办理户籍、就近上学都被卡。

　　不动产变成“不能动”的房产，群众忧心忡忡。

　　尽快摸清情况，明晰产权，为群众办理不动产登记，刻不容缓。涵江区迎难而上、主动作为，听民声、察民意，办实事、求实效，在全市率先破解拆迁自建房办证难题。

　　这天，涵江区不动产登记中心联合税务等多部门及涵西街道办事处，把拆迁自建房遗留问题办证工作现场搬进港头片区，为群众提供面对面服务，现场受理、审核、登记，受到群众好评。

　　以点带面，破局开路。经前期摸排，全区现有首批群众拆迁自建房171户，涉及涵西港头片区、白塘梧桥片区、福厦拓宽改造安置房、国欢高林街片区、江口高速路口迎宾路片区等。涵江区不动产登记中心首登业务负责人吴晋雄介绍，该区以港头片区为试点，通过全面梳理、统筹协调、分类施策、简化流程、优化服务等举措，从紧从细从实推动“办证”问题早日高效解决，确保群众合法权益得到保障。

　　近年来，涵江区重点项目不断落地，随之带来大量征迁，伴生了安置房不动产登记的历史遗留问题。涵江区自我加压，多次组织召开专题推进会、联席会议，组建工作专班，有针对性地制定具体可行的解决方案，明确办事具体流程，全面提升工作质效。截至目前，全区已办理12个项目7155套安置房的首次登记，首登率达91.2%。

　　乐有所居，见“证”幸福。安置房成为安心房，群众的获得感、幸福感和安全感进一步增强。

　　助企纾困解难题

　　不动产权证，困住的不只是老百姓，也困住了企业。涵江区从企业需求出发，通过服务前置，主动与企业沟通对接，了解企业办理堵点，不断创新服务模式，千方百计为企业排忧解难，进一步释放经济发展活力。

　　“感谢贵中心多次到公司指导，积极协调处理办理过程中遇到的各种困难。”3月初，涵江区不动产登记中心收到一封来自福建长城华兴玻璃有限公司的感谢信。信中赞扬该中心优质暖心高效的惠企利企服务，彰显了涵江区持续优化营商环境、破解不动产登记历史遗留问题的力度与担当。

　　福建长城华兴玻璃有限公司在整体迁建时，未能完成不动产首次登记，直接影响企业融资与发展。涵江区政府得知这一情况后，立即启动“助企绿色通道”，成立工作专班，通过“一企一策”精准帮扶等措施，采取现场勘查与收集资料同步的受理方式，跑出不动产登记惠企利企“加速度”，提前4.5天办结完成，为企业高质量发展提供有力保障。该企业相关负责人表示，政府惠企利企的高效服务增强了企业发展的信心，将全力盘活资产，在求高求新、推进“四链融合”中奋勇争先，把企业做优做强。

　　被“红本本”束了手脚的还有冠盖金属包装有限公司。先前，该公司1号、3号厂房项目因历史遗留原因，无法正常竣工验收办理不动产权证。在严把消防和建筑质量的前提下，涵江区工信局、自然资源局、住建局、不动产登记中心等，实行“一站式”“套餐”服务，全力打通“证结”，帮助企业下活“一盘棋”。

　　千难万难，真心为企业就不难。涵江区不动产登记中心联动区住建局、自然资源局等组建专班，经过多轮调研，系统集成全省各地涉企不动产登记的创新举措，建立问题台账，打破部门壁垒，实现信息共享与协同办公，切实做到急企业之所需、解企业之所难，助力企业卸下“包袱”加快产业跃升。

　　“五证同发”促发展

　　在发展的过程中，涵江区着力破解“证”结中梗阻问题，全力以赴践行“保护产权、登记为民”的生动实践。

　　昨日，记者在莆田模具产业园17号、18号厂房项目现场看到，运输车、挖掘机忙碌作业，抓紧进行土地平整施工。

　　产业园采用“定制化厂房+并联审批”等模式，引进总投资约3亿元的万博机械公司，为海天精工、伊之密等业内知名企业提供精密制造配件，预计年产量达1万吨，达产后可实现年税收1500万元以上。

　　过去，企业从拿地到项目开工，依次办理证件涉及多个审批阶段、审批环节和审批流程，需要多部门往返多次跑动，办理时间至少要两三个月，影响项目进展。为加快推进项目建设，涵江区建立“政府全力推进、部门协力服务、企业密切配合”一体推进机制，创新“提前介入+细心指导+一站服务”工程建设审批模式，部门联动高效办成一件事，从“等企业上门办”变为“下企业帮助跑”，推进“五证同发”审批改革提速，促进项目早开工、早建设、早投产。

　　施工方中建海峡项目生产经理王志强告诉记者，得益于涵江“五证同发”高效审批服务，产业园于2月底启动相关办证工作，3月中旬拿齐“五证”，有力保障项目第一时间开工建设，并计划在120天内完成建设、150天内验收交付企业使用。

　　在保护历史文化街区方面，由于历史原因，萝苜田部分古民居在不动产登记方面存在诸多遗留问题，不仅影响户主的合法权益，也对街区的整体保护利用带来挑战。为防止国有资产流失，涵江区利用卫星定位加快对古民居的现状勘察及测绘建档，确保数据的稳定性，为后续办证提供基础保障，有效盘活并活化利用古民居特色资源，促进城市建设与文化遗产保护的协调发展。

　　秉初心，谋远图。涵江区以敢啃硬骨头的勇气、功成在我的担当和务求实效的作风，千方百计把历史遗留问题解决在当下，造福于民、推动发展。（记者 蔡玲 通讯员 林亦霞）
