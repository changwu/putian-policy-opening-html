秀屿区：强化服务全力保用工助“开门稳”“开门红”

来源:湄洲日报 时间：2023-02-10 08:03
| | | |
　　秀屿区通过举办专场招聘会、拓展直播带岗、多渠道推送招聘信息、落实稳岗稳工政策、构建和谐劳动关系等举措，全力服务保障好企业用工。
　　开春以来，秀屿区人社局落实省委、市委“深学争优、敢为争先、实干争效”行动要求，聚焦保障企业用工，积极搭建平台，落实惠企政策，开展“春风送真情，援助暖民心”系列招聘活动，全力做好“开门稳”“开门红”用工要素保障，全方位推进绿色高质量发展。
　　提早部署 拓展用工渠道
　　2月5日至6日，秀屿区春季首场大型招聘会暨2023年“春风送真情，援助暖民心”服务企业用工专场招聘会在秀屿万达广场举行。
　　此次活动中，55家重点用工企业设置招聘展位，提供了2500多个岗位。创新招聘形式，现场进行抖音直播，打破了时间和地域的限制，实现就业服务“零距离”。活动共收到求职登记476份，初步达成就业意向290人左右；抖音直播总曝光量达51.49万次，观看人数达17万多人次。
　　“直播带岗、精准投放，实现双向精准对接，提升企业招聘的效率。”秀屿区百寿康医院有限公司党支部常务副书记陈加宁告诉记者，招聘会前，区人社局就主动对接，充分掌握企业用工需求，收集岗位信息，形成岗位需求台账。通过此次招聘会，公司收到近百份求职简历，符合要求近40人，参加复试22人，有效缓解缺工困境。
　　节后是企业招聘用工的高峰期。为做好春节前后服务企业用工，该区人社局提早部署，做好用工情况摸底调查。
　　秀屿区人社局局长陈游介绍，春节前，该局就组织人员主动深入企业，摸排企业员工返乡过年及节后用工、缺工等情况，摸清用工现状。并充分运用微信群等企业交流平台，建立联系企业的长效机制，抓好企业用工信息的收集、筛选和发布，为企业提供人力资源支持。
　　1月28日，节后上班第一天，该区人社局领导班子成员深入重点企业，全面掌握企业复工情况及用工需求。秀屿区人力资源市场、莆田海峡人才市场秀屿工作站开展常态化招聘，开展人岗匹配等服务，促进用工和就业的无缝衔接。
　　值得一提的是，该局还充分运用各镇LED就业保障信息发布系统，广泛宣传造势，实时推送用工招聘等信息，推动就业信息发布全域共享，努力做到家喻户晓。
　　“就业信息发布系统都是设在村镇的重点路口、人员密集处，让广大求职者足不出村就可挑选到心仪的就业岗位，实现就近就地就业，还可满足企业用工需求。”陈游说，对于重点企业用工需求，他们还会携企业下沉乡镇开展送岗下乡宣传活动，进村张贴海报，让居民在家门口了解就业信息。
　　目前，该区已通过相关工作群发布26家企业的招聘信息，涉及2283个工作岗位，为用工企业和就业人群“牵红线”。
　　落实政策 强化用工支撑
　　截至2月8日，50家重点企业已开工49家，员工返岗率90.32%，其中规上企业35家、员工返岗率90.88%；今年已新招用员工225名，现报告还缺工710人……该局对50家重点用工企业开展节后用工监测，实行每日一报，全面精准掌握企业员工返岗情况。
　　围绕扩岗留工稳生产稳就业工作重点，该区人社局压实工作责任，认真执行市里出台的《关于2023年进一步服务企业稳岗稳工促“开门红”八条措施的通知》等文件，全面宣传解读春节期间连续生产等新一轮稳岗稳工政策，开展“政策找人”服务，进一步扩大覆盖面，助力企业健康稳定发展。
　　根据政策，对春节期间保持连续生产的企业，按员工每人300元标准，给予企业最高不超过30万元的一次性稳定就业奖补；针对返岗员工，对农历正月初七前返岗的补贴交通费50%，对农历正月十六前返岗的补贴交通费25%；对省内外人力资源服务机构为该区企业引进人才和劳动力且稳定就业3个月以上的，给予一次性每人800元的用工服务补贴，每年补贴不超过20万元；各类企业新招用员工且稳定就业满3个月的，给予500元到1500元用工补贴，稳定就业满6个月的再增加500元补贴。
　　“去年，春节期间省外员工留莆过年稳就业奖补资金达120.3万元，‘两节’期间连续生产的工业企业稳定就业奖补资金达137.16万元。今年全区约有20家企业春节期间连续生产。”秀屿区人社局就业中心主任陈永锋说，春节前，他们就将相关政策文件发给企业经办人，并对补助对象、标准、申报所需材料及注意事项进行解读，指导企业及时做好各项用工补助申报，让企业充分享受到“政策红利”。
　　“不仅有稳岗补贴，还有就业见习补贴等政策，为我们开工稳产注入了一针强心剂。”福建永荣科技有限公司相关负责人表示，去年该公司向区人社局申请春节期间省外员工留莆过年稳就业奖补、春节期间连续生产稳定就业奖补、就业见习补贴、企业吸纳就业补贴、一次性扩岗补助等各项政策补贴金额达368.82万元。今年他们正在积极准备申报材料，用好惠企政策。
　　精准服务 构建和谐关系
　　借力2023年度秀屿区企业用工服务专场招聘会的东风，2月5日至6日，秀屿区劳动保障监察大队工作人员走进招聘会现场，开展“保障劳动者合法权益 促进稳定就业”普法宣传活动，为劳动者和企业献上法治“大礼包”。
　　活动现场，工作人员积极向群众宣传劳动与社会保障法律法规、政策，主动了解群众的求职疑惑和维权诉求，予以耐心解答，帮助群众增强法律意识，避免落入用工陷阱，懂得运用法律武器维护自身的合法权益。
　　“我们对55家参会企业招聘信息的有关内容进行核查，向到场的企业代表强调用人单位的主体责任，切实保障劳动者各项权益，引导企业依法规范用工、依法用工，营造良好用工环境，为助力企业‘开门红’献计献策。”秀屿区劳动保障监察大队负责人傅荣生表示，他们还深入企业，深入项目工地，当好劳动保障法律、法规政策“引导员”“宣传员”，当好劳动用工管理“维护员”“服务员”，抓精准服务，促规范用工，全力助推全区劳动关系和谐稳定。
　　创建和谐劳动关系是企业内生需求。春节前后，该区还开展根治欠薪“雷霆清零”行动，深入排查欠薪隐患、及时化解欠薪案件，重点对建设施工领域、小作坊、小型加工户、曾发生过拖欠工资行为和存在拖欠工资隐患的企业进行排查，进一步规范企业用工行为，切实维护劳资双方合法权益。加强就地过年务工人员服务保障，依法查处招聘中的虚假欺诈现象，严厉打击就业歧视、非法中介等行为。健全劳动关系协调机制，全面推行劳动合同制度，重点解决非公有制中小企业和农民工劳动合同签订率偏低的问题。深入开展和谐劳动关系创建活动，累计有4家企业获评和谐劳动关系企业，1个园区获评和谐劳动关系工业园区，1个镇获评和谐劳动关系乡镇。
　　“和谐的劳动关系，不仅能使企业形成向心力，还能使企业形成创新力，迸发强有力的竞争力。”荣获全国和谐劳动关系创建示范单位的福建省华峰新材料有限公司不断丰富企业文化，创造更和谐的工作和生活环境，解决员工的后顾之忧，留住员工的心，为务工人员工作生活提供看得见、摸得着的便利条件，有力促进了公司蓬勃发展。
　　陈游表示，下一步，该局将重点紧盯区内规模以上用工企业需求，开展精准用工需求对接，及时落实稳就业相关政策措施，全力帮助企业保岗稳岗，确保实现一季度开好局、起好步。（记者 傅梅香）
