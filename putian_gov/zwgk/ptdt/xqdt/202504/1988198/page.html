荔城区：全力推动一季度经济实现良好开局

来源:湄洲日报 时间：2025-04-01 08:20
| | | |

　　荔城区认真贯彻落实中央、省委、市委经济工作会议部署要求，坚持稳字当头、稳中求进，抢先抓早、谋定快干，持续深化拓展省委“深学争优、敢为争先、实干争效”行动，聚焦“巩固和增强经济回升向好态势”任务，印发出台关于实现一季度经济社会发展良好开局23条措施及相关配套政策，推动一季度经济取得新成效。

　　塔吊挥舞长臂勾勒出城市天际线，智能机械臂在数字化车间精准作业，“链长”服务专班步履匆匆解企忧……今年一季度，荔城区以“俯下身子抓产业、一心一谋发展”的实干劲头，交出一份含金量足的答卷。

　　积蓄发展新势能

　　3月27日，在荔城经济开发区西天尾片区的双通鞋业智能智造产业园项目，一栋栋楼体拔地而起，工人们正在紧张施工。

　　双通鞋业智能智造产业园由双驰实业股份有限公司投资建设，包含研发中心、智能观光线、办公楼等各类建筑设施18幢。其中，一期占地面积约1.47万平方米，总建筑面积约5.1万平方米；二期占地面积约5.87万平方米，总建筑面积约15万平方米。“1号厂房11层，目前已建成6层。2号厂房8层，已建成4层。3号厂房3层，已建1层。”双通鞋业智能智造产业园负责人陈国强介绍。

　　眼下，荔城区各重点项目正加快建设。重点项目是经济发展的“动力源”，更是高质量发展的“强支撑”。荔城区成立重点项目前期及重大项目招商工作指挥部，下设办公室（简称“大前期办”），整合原有的前期办、重点办、招商办、督查办、金融办和链长办，推动“六办合一”，进一步打通从项目策划到项目投产的各个环节，形成了项目全生命周期服务、全流程工作闭环体系，助推项目建设提速增效。

　　开春以来，荔城区组织推动30个项目参与全市一季度项目集中开竣工活动；今年360个区重点项目完成投资75.4亿元，其中在建项目完成投资69.2亿元；实现荔城区鞋服纺织产业升级智能智造项目等15个项目开工，莆田中胜物流园、铭鑫鞋业等16个项目竣工。

　　荔城区抢抓一季度国家政策性资金投放“窗口期”，聚焦“两重”“两新”战略导向，精准对接超长期特别国债、专项债、预算内投资等政策工具，谋划并向上申报各类项目总投资约500亿元。其中，中央预算内投资补助项目莆田第十六中学建设工程获批补助资金2600万元。

　　该区把握“两节”招商良机，开展5场小分队外出招商活动，强化与在外荔城籍企业家、商协会负责人及知名学者的联系，拓宽招商路径。挂牌成立驻杭州招商分中心，精准捕捉招商动态与投资意向，扩大区域经济合作领域。

　　今年以来，荔城区新增对接洽谈耿氏香产业文化园、中正药业中药饮片生产等项目23个，计划投资213.58亿元，签约项目10个，协议投资38.18亿元。成功谋划30亿元以上项目5个，计划总投资额达185亿元。

　　激活转型新引擎

　　位于荔城经济开发区西天尾片区的福建东瑞制药有限公司生产车间内，机器高速运转，泡罩包装的药品在输送带上流转，进入装盒机。

　　“今年一季度全面完成任务，产量刷新历史新高，同比增长10%以上。”福建东瑞制药有限公司总经理林明聪介绍，公司共有内包装、外包装、瓶装线生产线13条，引进德国先进设备，每小时能生产45万片药，年产量可达30亿片。

　　福建东瑞制药有限公司是国家高新技术企业，也是省专精特新中小企业，产品主要涉及心脑血管领域，拥有滴丸剂、片剂等7大类药品，生产的阿托伐他汀钙片是国家集中采购药品的一个中标品种。近年来，公司立足主业，聚焦心脑血管领域用药的研发、生产和销售，加大研发投入，进行技术创新，不断丰富产品管线，增强企业发展后劲。

　　产业一线的繁忙景象，是荔城区一季度经济良好开局的有力证明。荔城区紧扣全省县域重点产业链战略布局，以产业链、创新链、人才链、资金链“四链融合”为牵引，构建产业高质量发展生态圈。

　　今年以来，荔城区常态化推行挂钩服务机制，实地走访、精细对接，匹配申报工业领域设备更新项目5个、省重点技改项目5个。加快“智改数转”，推动数字化转型提速增效。“双驰鞋业大规模个性化定制”“双源鞋业智能精益车间”获评“数字三品”应用场景典型案例，双驰“鞋类C2M大规模个性化定制解决方案”项目入选国家电商科技创新应用案例。

　　荔城区推动园区载体升级，重构产业发展空间，引入万存科技城项目，打造标准化厂房，目前已完成土地挂牌及方案设计，对接洽谈意向企业15家。推行“亩均效益”评价机制，今年计划盘活闲置厂房10.08万平方米以及闲置土地和低效用地57亩以上。同时，荔城经济开发区循环化改造实施方案通过省里初审。

　　明方向，定措施，出实招。荔城区发改局副局长许力介绍，今年，该区将紧抓全省县域重点产业链试点机遇，集中力量主攻优势产业链，加快新旧动能转换，持续推进产业高端化、智能化、绿色化发展。

　　激发服务新效能

　　连日来，位于荔城区北高镇鞋材加工集中区的万存科技城加紧建设。该项目占地约13.3万平方米，计划投资32亿元，建设33万平方米标准化厂房。项目达产后，预计年新增产值16亿元以上。

　　不久前，万存科技城启动招商签约，获得8家金融机构提供的16亿元授信额度。“荔城区招商服务中心和工信局是大前期办的成员单位，多方对接协调，帮助万存达成融资目标。”大前期办综合协调组副组长张香告诉记者。

　　服务企业就是服务发展，而精准高效的服务是企业发展的“良方”。近年来，荔城区坚持以数字化改革为牵引，构建便捷政务服务新生态，全力打造能办事、快办事、办成事的“便利荔城”。

　　荔城区深度融入全市“一张图”数字系统，创新“一中心两端联动”机制，推行全流程无纸化事项办理，实现“线下只进一门、线上一网通办”。该区持续深化流程再造，推行“联审联批”模式，对民生事项，实行全程在线、同步会审、联合踏勘，累计开展“多测合一”项目9个、告知承诺制项目112个，联合踏勘项目4个，联合验收项目20个。

　　企业是产业链的基本单元和最基础的支撑。确保企业引得进、留得住、发展好，是实现产业链稳定发展的前提和基础。荔城区深化“政银企”对接破解融资难题，为130家“白名单”企业融资担保5.67亿元；促成3家银行与7家重点企业达成授信协议，落地放款15.14亿元。

　　今年以来，全区新增各类市场主体8804户，增长15.69%；新增资本金额18.34亿元，增长45.67%。

　　厚植发展沃土的荔城，正奏响加快高质量发展主旋律，着力以一季度良好开局引领带动“全年旺”。（记者 朱建婷）
