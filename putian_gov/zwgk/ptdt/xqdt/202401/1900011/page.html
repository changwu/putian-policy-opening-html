荔城区：奋力推动中国式现代化荔城实践取得新突破

来源:湄洲日报 时间：2024-01-23 07:21
| | | |
　　初步安排区重点项目350个，实施重点技改项目30个以上，新改造老旧小区9个，加快推进“水上巴士”沿线生态修复、景观提升和村庄更新，加快13个教育类项目建设进度……今年，荔城区在产业发展、城乡建设、民生保障等方面加大工作力度，奋力开创各项工作新局面。
　　近日，荔城区委书记杨兴斌前往黄石镇、北高镇、西天尾镇等，开展企业走访调研活动，详细了解企业生产经营情况及存在的困难和问题，鼓励企业做大做强，要求各级各部门进一步提升服务意识，为企业发展提供全过程服务和全方位保障。荔城区区长刘基棠来到玉湖片区等地调研，就相关问题进行指导，要求全面践行人民城市理念，持续推动城乡融合、区域协调发展，让城市建设更加惠及民生。
　　新年新气象，实干开新局。区委经济工作会议和区两会进一步明确今年工作目标任务，眼下，全区上下以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十大和二十届二中全会精神，认真落实中央和省委、市委工作部署，紧扣“强产兴城、幸福荔城”总体目标，坚定信心、开拓奋进，加快推进绿色高质量发展，奋力推动中国式现代化荔城实践取得新突破。
　　夯实发展基础
　　昨日，在高铁新城新度片区棚改项目（一期）施工现场，12幢安置房主体工程建设和室内装修已完成，工人们正抓紧进行小区道路、绿化等室外配套扫尾施工。
　　干字当头，奋力攻坚。刚刚过去的2023年，荔城区扎实开展主题教育，实施“深学争优、敢为争先、实干争效”行动，落实市委“一五二三四”工作部署，推动区委“六大提升工程”。省市重点项目均超额完成全年任务，实现68个项目开工、71个项目竣工，获评全省县区二季度项目工作正向激励综合考评第3名。
　　服务提质，产业提效。荔城区运动休闲鞋产业获评“福建省中小企业特色产业集群”。新增省市级“专精特新”企业15家，恒而达新材料、双源鞋业获评“福建省新一代信息技术与制造业融合发展新模式新业态标杆企业”，祥恒包装获批省级“绿色工厂”。全社会研究与试验发展经费投入9.34亿元，总量与增速均居全市第二。第三产业增加值占比首次突破50%，跨境电商云产业园入驻商户53家，硕合才储、豆讯等2家平台企业入选“福建省数字经济核心产业领域创新企业名单”。荔城经济开发区综合发展水平跃升至全省第26名。
　　今年，该区将聚焦实体经济，全力打造现代化产业体系。在提振主导产业新优势上，加快鞋服配套集中加工区和大型综合性鞋服仓储配送交易中心建设，实现恒而达智能装备与高强韧金属材料产业园一期竣工投产，加快推进欧亚牛奶区域总部及仓储物流基地等项目投产，推动三棵树绿色建材供应链平台吸引更多下游企业入驻，推动豆讯云计算数据中心等重点项目建成投产。在打造第三产业新高地上，全年新增限上商贸业企业、规上服务业企业140家。在提升现代农业新水平上，创建农业科技示范基地2个，培育家庭农场38家、农民合作社217家，新增高标准农田1000亩、改造提升2000亩。在拓展产业平台新空间上，聚焦“一区五园”规划建设，同步推进产业综合体、创新综合体、生活配套和综合服务中心建设，打造集约型高品质产业空间。
　　记者了解到，今年，该区初步安排区重点项目350个；全年力争完成招商对接项目计划总投资300亿元以上。
　　提升城乡颜值
　　上周末，兴化府历史文化街区内熙熙攘攘，游客们看古厝、观非遗、品美食，老街区焕发新活力。该街区成为央视《非遗里的中国》（福建篇）拍摄地，获评“省级旅游休闲街区”，入围2023年中国旅游产业影响力案例。
　　1月17日，荔城区召开老城更新与风貌提升工作推进会，提出在历史文化的挖掘、保护和传承上下足功夫，提升城市功能品质，实现人文、商业、旅游聚合共生。
　　精雕细琢，下好“绣花”功夫，荔城区城乡面貌加速更新。去年以来，紫霄片区入选全省城市片区综合开发建设样板工程，联十一线天马安置区实现回迁，潭头桥片区、林峰二期、沙坂片区棚改二期等15个安置区开工建设。完成老旧小区改造9个，建成棚改项目2个2001套，新开工棚改项目9个4194套，居全市第一。八二一街南伸（荔二路至壶公路）主车道实现全线贯通，打通莆田一中新校区周边路网、秀水路等市政道路。主要流域木兰溪国控三江口断面和省控延寿溪口断面优良水质比例均达100%。木兰溪绶溪片区项目（绶溪公园）入选国家级生态环境导向开发模式试点名单。推动莆阳开春、爽夏、赏秋系列文旅活动，北大、吴江、东阳等村落成为热门打卡地。
　　城市软环境也在持续优化。全区行政许可事项“即办件”占比62.29%，“一趟不用跑”占比84.90%，“全程网办”占比75.72%，平均缩短时限比例达85.56%，“政企直通车”“亲清惠企平台”诉求件办结率达100%。与广东四会、厦门同安等地实现65项审批事项网上异地办理。全年新增各类市场主体3.64万户，增长19.54%。
　　今年是习近平总书记亲自擘画木兰溪治理25周年。新起点上，该区将聚焦绿色发展，全力推进城市蝶变升级。
　　围绕提升生态环境颜值，坚定践行木兰溪治理理念，持续推进木兰溪流域生态环境保护治理提升三年行动，加快南北洋河湖生态廊道、延寿溪玉湖段整治工程、荔城区农村污水提升治理（二期）等项目建设，大力实施绿心保护利用工程，持续打好污染防治攻坚战。聚焦赓续历史文化脉络，推动兴化府历史文化街区创建国家级旅游休闲街区和3A级旅游景区，持续丰富非遗一条街业态，激活“荔林水乡”生态绿心价值。在加快城市更新行动方面，加快推进紫霄片区、高铁新城、绶溪片区等新区建设，实施潭头桥片区安置房、区综合档案馆新馆等重点项目85个，新改造老旧小区9个、城市危旧房2111套，加快推进“水上巴士”沿线生态修复、景观提升和村庄更新，加快湖滨南路等城市主次干道建设。同时，有力有效推进乡村全面振兴，建设宜居和美乡村。
　　增进民生福祉
　　今年1月起，荔城区城乡居民基本养老保险待遇人员的基础养老险每人每月增加10元，调整后的基础养老金标准提高到每人每月175元，位居全省前列。预计全年区财政需增加投入1100多万元，惠及约9.19万名“城乡居民保”待遇人员。
　　增进民生福祉是实施“强产兴城、幸福荔城”的落脚点。过去一年，区财政投入资金28.36亿元用于民生事业，占本级支出81.8%，42个为民办实事项目超额完成投资。出台稳岗稳工8条措施。新建各类养老服务场所6所，新增养老床位171张。莆田八中新校区、中山中学玉湖校区等10个教育类项目如期投用，新增优质学位6960个，获评福建省“智慧教育试点区”“科研协同创新基地”“课后服务信息化管理工作试点区”和“莆田市初中教育先进县区”。高分通过国家级健康区建设省级终期评估验收，区中医院获评二级甲等中医医院。
　　社会治理成效凸显。荔城区基层治理实践入选全国社会治理创新案例，开展矛盾纠纷大排查大化解大察访“百日攻坚”行动，成功化解信访积案109件，拱辰街道物业纠纷“一站式”调处工作法入选全省“枫桥经验”案例库。
　　人民对美好生活的向往，就是奋斗目标。新的一年，荔城区将聚焦民生实事，全力绘就美好生活画卷。
　　抓好重点群体就业创业工作，稳步提高社保待遇水平，新建长者食堂6个；实现4个总建筑面积35.5万平方米安置房项目回迁，开工玉湖新城新溪片区安置房、紫霄片区东星安置区等7个项目；加快推进区级社会福利中心建设；加快区实验学校、西天尾中心幼儿园紫霄分园等13个教育类项目建设进度，确保中山中学绶溪校区、黄石中心小学附设沙坂幼儿园等3个项目年内投用，新增学位3330个；深入推进国家卫生城市、国家级健康区、慢性病综合防控示范区创建工作，推动荔城中医院项目主体封顶；纵深推进“党建引领、夯基惠民”工程，推进基层综治中心规范化建设……新部署、新目标，回应群众关切，令人期待。
　　锚定奋斗目标、凝聚奋进力量，全区上下心往一处想、劲往一处使，以新气象新作为推动各项工作打开新局面。（记者 朱金山）
