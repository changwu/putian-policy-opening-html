市委市政府决定今年开展48项为民办实事活动

来源:湄洲日报 时间：2022-03-28 09:07
| | | |

　　市委、市政府日前发出通知，决定2022年继续开展48项为民办实事活动，要求各级各单位进一步增强效率意识、效能意识、效益意识，对号入座、主动认领，第一时间把工作布置下去，把责任落实下去，把压力传导下去，确保早推进、早落实、早见效。

　　一、实施幼儿园学位扩容工程。通过新建、改扩建，扶持街道（乡镇）及国有企事业单位举办等方式新增公办幼儿园学位3000个，新建、改扩建公办幼儿园15所。

　　二、实施义务教育薄弱环节改善与能力提升工程。重点推进义务教育阶段主城区、城乡结合部和县中心区义务教育阶段公办学校扩容建设，新增学位6000个。

　　三、实施近视防控教室照明改造工程。计划按照国家标准，改造照明卫生标准不达标的公办中小学校教室2000间。

　　四、提高人均基本公共卫生服务项目政府补助标准。2022年基本公共卫生服务项目政府补助标准，从2021年每人每年79元提高到每人每年84元，并逐级落实到位。

　　五、提高困难群体高血压、糖尿病门诊指定用药报销比例。将低保对象、特困人员和低保边缘家庭成员等困难群体高血压、糖尿病门诊指定用药报销比例提高到100%。

　　六、实施女性人乳头瘤病毒（HPV）疫苗免费接种项目试点。科普宫颈疾病防控知识，免费对具有莆田市试点区域（城厢区）学籍或户籍、未接种过人乳头瘤病毒（HPV）疫苗且年龄在13周岁—14周岁半的女性开展HPV疫苗自愿接种。

　　七、完善AED应急救护体系建设。在全市重点公共场所和学校区域配备AED（自动体外除颤器）140台。开展应急救护普及培训100场、人数20000人次以上；培训救护员15000人次。

　　八、开展中高级职称医师下基层服务。从县级以上医院抽调高年资中级以上职称医师进入全市49家社区卫生服务中心、乡镇卫生院进行医疗帮扶，每月最少在基层工作一天，全年达500人次以上。

　　九、建设普惠性托育园。新增普惠性托位1370个。

　　十、开展职业技能培训。全年计划开展各类补贴性职业技能培训2万人次。

　　十一、实施高素质农民培训工程。新增培训8500人次。

　　十二、资助在校生和大中专毕业生创业。对在校生和毕业5年内在莆创业的全日制普通大中专毕业生创业项目进行评选扶持，择优给予3—10万元不等的资助。

　　十三、实施“三支一扶”工程。全市“三支一扶”（大学生在毕业后到农村基层从事支农、支教、支医和帮扶乡村振兴工作）计划招募70名、服务社区计划招募10名。

　　十四、提高城乡居民基本养老保险基础养老金标准。2022年1月1日起全市城乡居民基本养老保险基础养老金标准每人每月提高10元。

　　十五、建设长者食堂。在居家社区养老服务设施内建设长者食堂25个。

　　十六、全面落实残疾人“两项补贴”政策。将困难残疾人生活补贴由每人每月92元提高到100元，困难一级重度残疾人护理补贴由每人每月120元提高到125元，困难二级重度残疾人护理补贴由每人每月92元提高到100元。

　　十七、改造提升市政道路无障碍设施。推进城市重点公共服务场所和重要公共建筑的无障碍设施改造提升，打造荔城区为无障碍设施改造提升示范区；改造提升市政道路无障碍设施，实施东圳路人行道、仙游县城区主次干道人行道、北岸经济开发区学府路人行道等3个项目。

　　十八、建设全民健身场地设施。全市计划新建2个智慧体育公园、5个游泳池。

　　十九、举办全民健身运动会。2022年3月至12月在全市各地科学、安全、有序开展全民健身赛事活动。

　　二十、治理“餐桌污染”、建设“食品放心工程”。加强食品和食用农产品安全监管。推进国家食品安全示范城市创建工作。开展专项行动，严厉查处食品安全违法违规行为。推进食品安全示范建设。推进食品安全“一品一码”全过程追溯体系建设。

　　二十一、建设城区生活垃圾分类屋（亭）。计划建设145座。

　　二十二、创建城区生活垃圾分类示范区。计划在荔城区主城区创建省级生活垃圾分类示范区建设。

　　二十三、综合治理海漂垃圾。常态化清理海漂垃圾。完善海上环卫建设。健全海漂垃圾综合治理长效机制。加强“数字化”监管。

　　二十四、市政生活污水管网建设。新建或改造城镇生活污水管网60公里。

　　二十五、农村生活污水提升治理。启动实施50个村庄农村生活污水提升治理，完成20个以上村庄农村生活污水治理。

　　二十六、实施保障性安居工程。继续推进城镇棚户区改造，攻坚改造老城区内脏乱差的棚户区，重点安排改造50户以上的集中成片棚户区，新开工改造7500套以上。

　　二十七、城镇老旧小区改造。实施改造城镇老旧小区项目49个，涉及3000户。

　　二十八、城乡福道建设。新建和改造提升福道35公里（包括城乡绿道、森林步道、登山步道、自行车道等），其中市本级（东圳水库坝头至木兰陂沿渠福道）18公里。

　　二十九、整治提升传统村落。整治和改善提升2个传统村落。其中，仙游县游洋镇兴山村修复整治上宫老街、美林古村落及周边传统风貌建筑8处，修复整治四角土楼1栋；涵江区江口镇东大村修缮保护和活化利用古建筑5栋。

　　三十、实施安全应急保障提升工程。在全市范围内打造10个安全主题公园示范点，配套建设10个应急避灾示范点、配强10个应急物资储备站、设置10个微型消防站、提升10个安全宣教体验场所。

　　三十一、建设“四好农村路”。建设与改造农村公路40公里，改造危桥15座，提升农村公路安保30公里。

　　三十二、道路交通安全隐患点整治。全市计划完成35处道路交通安全隐患整治。

　　三十三、城乡供水一体化建设。建设城厢区莒溪、党城2处农村规模化水厂，对仙游县龙华镇，荔城区新度镇，城厢区华亭镇、东海镇、灵川镇，涵江区萩芦镇等辖区内的农村进行“一户一表”改造，铺设管网200公里，受益人口10万人。

　　三十四、开展水土流失综合治理。完成水土流失综合治理6处，面积4.61万亩。

　　三十五、实施新时代电力“双满意”工程。持续推进电网升级。改造25万只及以上智能电表。全面推行供电网格服务。推广配电网不停电作业，建成1个“零计划停电示范区”。实施城乡配电网巩固提升工程。

　　三十六、电动汽车公共充电桩建设。计划新建电动汽车公共充电桩200个（标准桩）以上。

　　三十七、5G基站建设。全市新建5G基站1388个以上，进一步深化重点人员聚集区、产业核心区5G覆盖，实现100%乡镇地区和重点行政村全覆盖。

　　三十八、木兰溪流域河道整治、十里风光带及安全生态水系建设。新建防洪堤1.2公里，穿堤建筑物1座，治理河长24.3公里。

　　三十九、实施企溪至白塘湖、玉湖水上岸上连通工程，开通“水上巴士”。对企溪至白塘湖、玉湖实施河道连通、新（改）建桥梁、两岸整治等工程，完善水陆接驳设施，开通绶溪公园至白塘湖、玉湖的“水上巴士”。计划新（改）建桥梁10座、拆除旧桥2座、连通河道3处，新开挖河道260米，推进两岸提升整治8处。

　　四十、泗华溪水环境整治及泗华郊野公园建设。开展泗华溪沿溪入河排污口“全口径”排查整治，完成各类水质超标排污口溯源治理和泗华溪清淤工程。

　　四十一、实施易涝点整治工程。计划对全市26个易涝点进行整治。其中，雨污网管分流改造7处、河道清淤疏浚9处、市政排水系统改造10处。

　　四十二、乡村振兴试点示范项目建设。推动70个省级乡村振兴试点村的基础设施与公共服务提档升级。

　　四十三、应急广播体系建设。计划联网行政村190个、建设广播点1900个。

　　四十四、实施“一十百千万”防骗宣传。积极构建打防结合、以防为主、以打促防的工作格局，进一步加强源头防范。

　　四十五、“党建+”乡村邻里中心建设。在建成59个“党建+”乡村邻里中心的基础上，年内新建30个以上，实现全市每个乡镇“党建+”乡村邻里中心全覆盖。

　　四十六、“综治+”社区治理中心建设。在第二批58个试点村居（社区）建成集综治网格、治安防控、矛盾纠纷调解、法律服务、平安支援服务、应急处置等为一体的“综治+”社区治理中心。

　　四十七、实施基层网格化运营保障工程。计划对全市976个村（社区）基础网格站建设和运营提供必要运营经费保障。

　　四十八、特殊困难或高龄老年人适老化改造。全市实施特殊困难或高龄老年人适老化改造1000户。
