行稳致远势如虹——看我市着力推动产业做优做强加速腾飞实现高质量发展

来源:湄洲日报 时间：2022-03-25 08:17
| | | |

 

图为我市食品产业龙头企业亚明食品公司繁忙生产车间。蔡昊 摄

　　不负春光开新局。我市统筹疫情防控和经济社会发展，服务企业开足马力生产，12条产业链招商引资持续发力，产业发展风头正劲，奋力向前。

　　一年来，我市深入贯彻习近平总书记来闽考察重要讲话精神，敢于探索、勇于创新，坚持俯下身子抓产业、一心一意谋发展，加快传统产业转型升级和新兴产业发展，在服务和融入新发展格局中展现更大作为。

　　产业振翅奋向前

　　连日来，位于秀屿区笏石工业园区的栢合冷链集配物流园项目抓紧施工赶进度。一期食品智能化冷链仓储物流集散中心建设加紧收尾，预计4月份启用，建成后将成为全市单体库容量最大的食品冷库。

　　该公司总经理任国民介绍，栢合冷链集配物流园项目占地2.8公顷，是我市打造物流产业的重点工程。项目分三期建设，一期建设库容量5万吨的食品低温库，装满肉制品即可保障全市4个多月的肉品供应，是名副其实的“城市大冰箱”。

　　电子信息产业以科技为引擎，创新不止步。长80厘米、单根4.2千克，却能“四两拨千斤”，测量最大1500千克的重量，通过蓝牙和小程序，将测试结果实时同步到手机上并打印结果，这是锐马（福建）电气制造有限公司新推的产品之一“条条称”。“条条称”充电2个小时，即可使用360个小时左右，因携带和使用方便，广泛应用在快递行业和物流行业。该公司董事长林金田介绍，2021年公司产值8925万元，比增90.0%。目前，公司已拥有30多个发明专利，并入选国家高新技术企业、福建省科技小巨人领军企业、国家标准起草单位等。

　　对支柱产业、看家产业鞋服产业来说，2021年6月“莆田鞋”集体商标的正式发布，展示我市实施品牌培育战略、推动鞋业转型升级的决心。2021年，全市鞋服产业取得了亮眼的成绩单，完成规模产值1310.5亿元、比增15.9%，实现高质量发展。

　　多个产业同频共振，产业发展蓝图愈发清晰。今年，我市根据产业优势及特点，成立12个重点产业发展暨招商工作专项领导小组，由市领导分别担任各产业链链长及副链长，形成推进产业发展的磅礴力量，推动鞋服、工艺美术、食品等传统产业转型升级，做好数字经济、海洋经济、绿色经济、文旅经济“四篇文章”，推动新型功能材料、电子信息产业、新能源产业、高端装备产业、生命健康产业等新兴产业发展。

　　眼下，7000多家工艺美术企业30万从业人员奋力打造千亿产业集群；高端装备产业形成了汽车摩托车零部件、数控机床、专用机械设备、专用车、金属制品等多个产业，产业集聚初步凸显；电子信息产业初步构建“一中心两基地”的产业格局，产业发展层次、水平不断提升；生命健康产业、新能源产业等新兴产业，次第开花、蓝海无限……

　　精准招商强链条

　　招商引资是经济发展的“生命线”。今年2月8日，在秀屿区生命健康产业暨招商推介会上，生物制药原材料生产基地等6个项目集中签约，涉及生物制药、医疗器械、医养、供应链平台、产业协作等内容，总投资约18亿元。

　　近年来，秀屿区主动承接莆田海峡两岸生技和医疗健康产业合作区政策外溢，积极招商、引才、纳智，先后落地了新昶多肽园、药械网、宏宝药械产业综合体、栢合冷链物流园等项目，仓储、研发、制造、配送、销售全产业链业态初具雏形、起跑腾飞。

　　“去年5月，占地约6.7公顷、总建筑面积近11万平方米的仙游县鞋业标准化厂房开工建设，目前该项目已基本完工，预计6月份投用。”仙游经济开发区管委会负责人陈瑞回说，开发区不断优化营商环境，持续推进标准化厂房建设，为优质企业扩容和中小企业集聚提供空间，为大项目落地、大产业形成奠定基础。眼下，已有10多家企业意向入驻，仙游经济开发区管委会正全力推进招商引资工作，嫁接优质资源，培育鞋服产业新增长点。

　　一体布局、一体谋划，条条指导、块块落实。为引来一只只“金凤凰”，我市持续加大项目攻坚力度，以集群为路径，以平台为支撑，加强项目招引力度，不断引进一批好项目、优项目落户，推动项目建设提速增效，打造未来经济发展新增长极。

　　今年开春之际，我市举行民营经济暨产业发展大会，会上签约项目共20个，计划总投资506.23亿元。截至目前，意向项目2个，计划投资额16亿元；协议项目7个，计划投资额208亿元；合同项目2个，计划投资额7亿元；前期项目9个，计划投资额275.23亿元。2月8日签约以来，已有11个项目实现“转段”。

　　主动服务促发展

　　铆足干劲，奋力奔跑。3月22日，位于华林经济开发区内的亚明食品有限公司，8条生产线繁忙运转，努力实现“开门红”。

　　“生产线已全部达产满产，4月份将再增加2条生产线，设备已经进场了，正在调试。” 该公司副总裁张丽芬介绍，目前公司生产的面点出口国外，国内布局了7家加盟店，市内有1家直营店，4月份将再增一家，此外还开通了线上交易平台。

　　作为我市食品产业的“领头羊”之一，今年该公司谋划建设中餐标准化智能厂房，总投资1亿元，扩征建设中餐标准化生产厂房24万平方米。项目全部达产后，预计新增年产值2亿元。

　　“为进一步营造良好营商环境，我市各个部门主动靠前服务，建立专班，实行‘一企一档’，助力食品产业稳定持续发展。”市工信局投资和规划科邓建庭表示，预计一季度，食品产业完成产值130亿元，为全市规上工业企业贡献产值增量16亿元，比增14%以上。2022年，我市力争食品产业规上企业产值达560亿元以上、同比增长20%以上。

　　数字经济是我省推动高质量发展的“四篇文章”之一，也是我市12条重点产业链之一。2月7日，我市推荐总投资30亿元的豆讯云计算数据中心项目参加全省第一季度重大项目视频连线集中开工活动。福建豆讯科技有限公司总经理郑丽煌表示，项目主要为央企提供优质CDN节点，计划投入5000个机柜、10万台服务器，建成后，将辐射省内周边城市，带动商业计算、电子政务、电子商务等领域发展。今年4月底之前将进行桩基施工，7月底之前完成整个地下室工程，12月底之前完成主体结构，争取在2024年5月投产使用。

　　为当好“服务员”，我市围绕数字赋能产业发展和工业互联网的推广应用，建立了“专班一周一部署，抓基础、抓执行；领导小组两周一调度，抓决策、促落实”的工作机制，找准堵点求突破，精准帮扶服务，培育壮大新兴数字产业。

　　主动作为、真情服务，电子商务、平台经济等新模式不断涌现，数字经济发展水平全面提档加速。市发改委数字经济发展科负责人陈铸洪介绍，目前我市已有物泊科技等3家平台已列入全省重点平台，豆讯科技等3家企业入选省数字经济未来“独角兽”企业，国投云信等4家企业入选省数字经济未来“瞪羚”企业，为数字经济发展和传统产业转型注入了新动力，2022年，数字经济规模力争增长20%。

　　把握发展黄金期、上升机遇期，着眼“提高效率、提升效能、提增效益”工作目标，我市俯下身子抓产业、一心一意谋发展，主动当好“店小二”，把脚踩在泥土里、踩到硬地上，为企业搭建施展才华的舞台、厚植成就事业的沃土、打造安心创业的家园。

　　产业撑起经济发展的“脊梁”，我市牢记嘱托，感恩奋进，汇聚起产业发展的磅礴力量。（记者　林晓玲）
