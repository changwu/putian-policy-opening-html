关于政协八届一次会议以来提案工作情况的报告

——2023年1月2日在政协第八届莆田市委员会第二次会议上
来源:侨乡时报 时间：2023-01-03 08:38
| | | |
　　一
　　市政协八届一次会议以来，全市政协各参加单位和全体政协委员，坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记重要讲话重要指示精神，学习贯彻中央、省委、市委政协工作会议精神，紧紧围绕推动新时代莆田高质量发展履职建言，提出提案283件，立案240件，其中委员提案174件，单位提案66件，立案率84.8%，经分解形成916件分办件，按照归口管理、分级负责的原则，交由82家承办单位办理，提案办理回复率100%，提案者满意和基本满意率为99.2%。
　　在政治建设方面，围绕推进法制建设、矛盾纠纷调解、加强人才引进、推进乡村振兴等，提出提案14件，占立案提案总数5.8%。如关于化解农村矛盾纠纷的提案，相关部门制定矛盾纠纷化解百日行动方案，开展排查，建立台帐，成立固定专班，包案责任到人，限时调解；加强邻里纠纷预测预警和风险研判，健全完善机制，做好人民调解员与村法律顾问的有效衔接和联动，及时化解纠纷。关于推进国防教育“六进”建设的提案，相关部门持续开展群众性国防教育，推进省级国防教育基地建设，修建“双拥主题公园”，组织第五届“爱我国防”全省大学生演讲比赛；开设“绿色军营”“双拥花开”电视专栏，推出系列国防教育报道。
　　在经济建设方面，围绕有关港口发展、扶持发展实体经济、推动产业转型升级、转变发展方式等，提出提案71件，占总数的29.6%。如关于提升莆田市鞋服产业传统优势的提案，相关部门发力鞋业品牌打造，成功注册“莆田鞋图形”集体商标，组建莆田名品品牌管理有限公司，负责品牌运营；加快创新主体培育，推荐4家鞋服企业申报省级“专精特新”企业、6家鞋服企业申报国家高新技术企业；出台稳经济一揽子措施政策，加大对鞋服企业支持力度。关于重点扶持和培育我市“专精特新”民营小巨人企业的提案，相关部门出台《莆田市扶持“专精特新”企业发展倍增行动计划（2022年—2024年）》，制订《莆田市“专精特新”中小企业认定管理办法》，受到省政府办公厅通报表扬；组织开展2022年“专精特新”中小企业认定申报工作，4家企业获得国家级专精特新“小巨人”企业认定。
　　在文化建设方面，围绕推进历史文化名城建设、健全公共文化服务网络、弘扬莆仙优秀文化、发展体育事业等，提出提案32件，占总数的13.3%。如关于促进湄洲岛高质量高颜值发展的提案，相关部门向上申请设立国家级妈祖文化(莆田)生态保护实验区；携手鞋业品牌开展“打卡莆田”活动，拍摄文旅微电影，举办大型展销会，宣传推介湄洲岛；打造海上养殖旅游观光带，支持做强“水乡渔村”品牌；培养海洋体育文化IP，举办健身赛事活动33场，推介湄洲岛旅游体育资源。关于保护和出版闽中画派画家作品的提案，相关单位成立“闽中画派”发展与传承研究团队，建立研究中心，开展闽中画派史料保护、整理、研究等工作。
　　在社会建设方面，围绕稳就业、办好人民满意的教育、提高保障和改善民生水平、城市功能品质提升等，提出提案107件，占总数的44.6%。如关于加快推进老旧小区改造的提案，相关部门开展老旧小区情况普查，制定房屋改造技术指导要点，明确整治内容和标准；2022年老旧小区改造项目共49个，涉及5867户，总投资18697万元，截止11月底完成投资15169万元，占比81%。关于发展普惠式托育的提案，相关部门支持、推进18个省级婴幼儿照护普惠服务项目、5个市级普惠托育点建设，新增托位1693个。关于完善环卫工人休息小屋设施建设的提案，相关部门制定实施方案，2022年完成新建20座休息屋的任务。
　　在生态文明建设方面，围绕生态环境整治、健全生态文明制度、建设生态文明城市等，提出提案16件，占总数的6.7%。如关于推广屋顶绿化，改善大气质量的提案，部分意见建议被吸纳入《莆田市城市园林绿化管理条例》（2022年11月福建省人大常委会审议通过），立法推进，相关部门结合城乡建设品质提升工作，在市政基础设施上先行推广，2022年全市各县区共完成25处立体绿化。关于尽快排查和消除城市噪音的提案，相关部门联合印发夜间噪声污染综合整治工作方案，建立执法协作联动机制，2022年共出动执法人员1136人次，组织开展联合执法13次，联合约谈4次，责令整改企业39家，取缔1家，有效改善我市声环境质量。
　　二
　　过去的一年，常委会紧紧围绕市委、市政府中心工作，把握质量导向、强化服务意识、创新工作方法，稳步推动提案工作提质增效。
　　（一）把握关键环节，努力夯实质量基础
　　把提高质量作为提案工作的第一要务，贯穿提案形成、审查、交办、办理等各个环节，着力提升提案质量和办理质量。
　　1、强化委员培训，提升履职能力。因本届新委员占比53.6%，市政协在八届一次全会期间举办提案知识培训讲座、政协云提案管理系统运用培训讲座，帮助新委员明确提案怎么写，提案履职怎么做，帮助老委员运用好提案系统，为撰写高质量提案打好基础。安排提案委干部为县区政协、民主党派作提案知识讲座4场，帮助县区政协委员、党派成员提升提案履职能力。
　　2、严格立案交办，提高提案质量。全会期间，严格按照程序，对提案进行“三审”立案，即提案组工作人员初审、提案委二审、提案审查委员会成员会议三审之后立案，从源头把好提案质量关。2022年4月，召开自市政协成立以来的首场提案协商交办会，市政协主要领导主持会议，对提案工作提出“提得好、交得明、办得实”的明确要求；通过多方协商，妥善处理各单位提出的改办申请120条，涉及承办单位27家、提案86件，使交办更为精准。
　　3、推进办后自查，提高办理质量。年底商请市政府督查室发文，请各承办单位开展办后“回头看”自查，以更有力举措，进一步推动提案落实。经自查梳理，有202件分办件的答复类别由B（提案所提问题正在采取措施解决或列入规划逐步解决）转化为A（提案所提问题已经解决或基本解决），使答复类别为A的分办件达到465件，占总数的50.8%，与往年同期相比有较大提升。
　　（二）推进全程协商，切实增强工作实效
　　把协商作为提高提案办理质量的重要抓手，融入提案工作全过程，通过多种方式加强协商，增强工作实效。
　　1、加强重点协商，发挥示范引领。遴选确定12件重点提案，得到市委市政府主要领导批示12件次，这些提案被列入市委市政府年度协商计划重点推进。2022年6月，市政协开展“重点提案协商督办月”活动，市政协主席会议成员会同市政府分管领导，分工跟踪督办重点提案，以此带动整体提案办理质量提升。市政协主要领导亲自领衔督办2022001号重点提案《关于提升莆田市鞋服产业传统优势的建议》，对我市鞋服产业发展起积极推动作用。
　　2、推进广泛协商，增进办理共识。建立全市提案工作微信群，实时交流办理工作进展，协商处理相关问题；与市委市政府督查室、各承办单位保持经常性的沟通联动，引导“提”“办”双方、提案各分办单位之间、主协办单位之间加强办理过程中的协商，凝聚办理合力、增进办理共识，提高办理质量。
　　3、首创“开门协商”，增强办理实效。创新开展“开门办提案”活动，挑选整治城市噪音污染、打造智慧交通、加强基层中医医疗服务这三件民生热点提案，请新闻媒体跟踪拍摄提案提出、“提”“办”双方协商办理、征求群众意见、推动进一步落实的全过程，形成专题片，通过媒体向公众公开，让提案办理从幕后走到台前，接受群众监督，带动民生类提案更好落实。
　　（三）加大保障力度，着力提升服务水平
　　坚持以优质服务为提案工作提供保障，多措并举拓宽服务领域，提高服务水平。
　　1、创新数字赋能，提高工作效率。积极响应市委提出的“全市一张图、全域数字化”的要求，加强提案工作信息化建设，在实现提案全流程“云上走”和“掌上提案”的基础上，进一步提出提案“一张图”、查询“一键式”的构想，已请专业人员设计方案，开展资料收集整理、打印等前期工作。
　　2、强化自身建设，奠定履职基础。根据新形势新情况，加强制度建设和队伍建设，修订《莆田市政协提案工作细则》，完善《莆田市政协提案协商工作实施细则》，提高工作制度化、规范化、程序化水平；按照专业化、年轻化要求，选齐配强提案委员会成员，为做好提案工作奠定基础。
　　3、加强工作宣传，扩大社会影响。开展提案故事征集活动，加强提案工作宣传，经验文章《创新提案工作，落实“三提三效”》、提案故事《小小“口袋”，大大幸福》刊登于2022年《政协天地》，提案故事《凝心聚力谱写妈祖文化新篇章》《小小“口袋”，大大幸福》《破解公厕小事，办好民生大事》入选第十二届福建省政协提案故事集，对我市政协工作起较好的宣传作用。
　　（四）延伸成果链条，充分发挥提案作用
　　以汇编形式总结提案工作成果、展现政协履职特色，为市委市政府及相关部门决策提供依据，进一步发挥提案作用。
　　1、汇编办理范例，提供工作借鉴。收集七届市政协具有代表性的提案30件，编写《七届市政协提案办理范例汇编》，为委员撰写高质量提案，承办单位办理好提案提供参考，调动委员撰写提案的积极性，促进承办单位加大办理力度，破解发展难题，切实解决群众关心的突出问题。
　　2、汇编专题提案，发挥资政作用。认真收集市政协三十年来有关木兰溪综合治理、港口湾区建设的所有提案，编辑《感恩奋进-莆田市政协30年木兰溪综合治理提案汇编（1991年-2021年）》《莆田市政协关于港口湾区提案汇编》；有关港口的汇编得到市委书记付朝阳的肯定批示，提案中有关助推木材产业发展的建议等，被吸纳入我市2022年海洋经济发展行动方案。
　　3、编纂文史资料，展现提案作为。从历年有关民营经济的提案中精选12件，把提案内容及其办理答复件，编入市政协主编的文史资料《莆田市民营经济四十年》一书，展现我市政协和政协各参加单位、历届市政协委员在民营经济发展进程中的积极作为，作为建市四十周年献礼。
　　在总结工作成效的同时，我们也清醒地看到，政协提案工作与形势发展、人民群众的要求还有一定的差距，主要体现在：有的委员与界别群众联系不够紧密，提案调研不够深入，提案质量不够高；有的承办单位与提案人的沟通协商不够，办理成效不够明显等。这些问题，有待在今后的工作中加以改进。
　　三
　　新的一年，市政协常委会将全面学习贯彻党的二十大精神，在建言资政和凝聚共识双向发力中，充分发挥提案积极作用，让提案在政协工作全局中的特色更加鲜明，成效更加突出，在服务全面建设莆田高质量绿色发展先行市中，作出新的更大贡献。
　　（一）强化政治引领，把握提案工作正确方向
　　要健全完善党对政协提案工作领导的体制机制，把握提案工作正确方向，始终把提案工作纳入市政协党组重要议事日程，坚持和完善市委、市政府、市政协领导领衔督办重点提案制度，继续将提案办理协商纳入市委年度协商计划，将提案办理工作纳入市委市政府年度督查计划。积极引导全市各级政协提案工作者和提案承办人员，认真学习贯彻落实党的二十大精神，持之以恒用党的最新理论成果武装头脑、指导实践、推动工作，切实把党的二十大精神贯彻落实到政协提案工作的全过程，更好地肩负起新时代赋予提案工作的新使命。
　　（二）强化大局意识，发挥优势助力莆田发展
　　要强化大局意识，发挥提案优势作用，积极引导全市各党派团体和政协委员，紧紧围绕市委提出“以木兰溪综合治理为总抓手，扎实做好产业发展、城乡建设、基层治理、民生保障、港口崛起‘五篇文章’”这一发展大局和人民群众关心的热点、难点问题，如就业、住房、教育、医疗、养老、托育、交通、生态环境等，深入调查研究，积极建言献策。探索建立提案审查立案新机制，在提案提交前，由各提案委员会成员分工联系各界别委员，对他们提交的提案进行预审；提交后，组织部分提案承办大户的业务骨干，对提案从内容真实性、问题精准性、建议可行性等方面进行更加严格的审查，确保提案质量。
　　（三）强化协商主业，多措并举提升办理实效
　　要发挥人民政协专门协商机构作用，加强提案办理协商，完善协商平台，丰富协商内容，优化协商流程，推进提案办理提质增效。要加强“提”“办”双方协商，在协商“百分百”、办复“百分百”的基础上，争取做到满意“百分百”。要积极会同市委、市政府督查室，召集“提”“办”双方，现场开展提案协商办理和督办工作；积极探索市、县（区）两级政协联动督办提案的工作方式，发挥政协整体效能。要及时开展提案“回头看”，办后“回访”工作，对提案答复中承诺要解决的事项，进行跟踪落实，对协商办理中的重点、难点问题，通过调研视察或座谈进行回访，提高办理成效。
　　（四）强化履职为民，开门办理服务民生改善
　　要坚持人民至上、履职为民，把服务民生改善、增进民生福祉作为提案工作的最终目标。在全会之前一个月开展“提案线索征集月”活动，借助媒体，向公众发布线索征集公告，拓宽提案来源渠道，使提案更加贴近民生；要引导委员广泛深入联系界别群众，及时反映群众的愿望和要求，在重点提案选择上，加大民生类提案的占比。要精心挑选民生关注的热点提案，继续组织好“开门办提案”委员履职活动，不断总结活动经验、丰富活动内容，把“开门办提案”打造成八届市政协工作的金名片，成为发挥委员作用，助力民生热点问题解决的重要平台。
　　党的二十大绘就了全面建设社会主义现代化强国的宏伟蓝图，凯歌奋进正当时，让我们紧密团结在党的旗帜下，踔厉奋发、勇毅前行，通过提案资政建言，以扎实的履职成效庆祝建市四十周年，为助力答好谱写全面建设社会主义现代化国家福建篇章的莆田答卷作出新的更大贡献！
