践行初心担使命 聚力发展谱新篇——我市扎实开展『不忘初心、牢记使命』主题教育综述

来源:湄洲日报 时间：2020-01-17 09:58
| | | |

　　这是一次深刻的思想政治洗礼，这是一次为民服务的初心践行，这是一次刀刃向内的自我革命，也是一次干事创业精气神的极大提振。

　　不忘初心，方得始终。在全党开展“不忘初心、牢记使命”主题教育，是党的十九大作出的重大决策。主题教育开展以来，市委坚持以学习贯彻习近平新时代中国特色社会主义思想为主线，围绕“守初心、担使命，找差距、抓落实”总要求，紧扣“理论学习有收获、思想政治受洗礼、干事创业敢担当、为民服务解难题、清正廉洁作表率”具体目标，把学习教育、调查研究、检视问题、整改落实贯穿主题教育全过程，推动主题教育有序开展、取得实效。中央主题教育《简报》专期刊发我市经验做法。

　　扛起政治责任 高位部署推动

　　按照中央和省委部署，市委精心谋划、周密安排，高站位引领，高起点推进，确保主题教育高质量开展。研究制订实施方案等文件，成立市委主题教育领导小组，推动工作落实。

　　高标准示范。坚持从市委常委班子抓起严起，带头学习教育、调查研究、检视问题、整改落实，用“关键少数”带动“绝大多数”。市委常委同志带头深入重点项目、生态环保、乡村振兴一线开展调查研究，形成高质量调研报告；带头以党员身份参加所在支部“悟初心、守初心、践初心”主题党日活动；带头围绕“六个聚焦”“六个检视”讲好专题党课；带头查摆检视问题，撰写检视剖析材料；带头落实领导包案制，直插现场一线推动问题整改420个、难题积案化解84件，为全市广大党员干部作出示范。

　　紧盯根本任务，强化理论武装。牢牢把握学习贯彻习近平新时代中国特色社会主义思想这一根本任务，推动广大党员系统学习必读书目，跟进学习习近平总书记最新重要讲话精神，深入学习党章党规、党史、新中国史，持续学习习近平总书记对福建、莆田工作的重要指示批示精神，筑牢增强“四个意识”、坚定“四个自信”、做到“两个维护”的思想根基。

　　深入研讨学。全市各级各单位围绕“践行初心使命”“牢记为民宗旨”等专题，采取集中学习、专家辅导、研讨交流等形式，开展集中学习研讨，理论学习有了新收获，思想认识有了新提升。市级班子带头赴闽中革命司令部纪念园举办为期3天专题读书班，带动各级组织开展专题研讨5500多场次，举办各类读书班、辅导班、学习交流会6400多场次。

　　形式多样学。开展百集“不忘初心、牢记使命”先进典型微视频展播，推出“党建之声FM”音频党课、“初心讲堂”“初心路线”，增强了学习的针对性、感染力。举办5期“莆田大讲堂”，累计吸引全市35万多人次党员线上收听收看。开展“十百千”理论宣讲进基层活动，组建先锋模范队、优秀支书队等10支宣讲小分队，组织理论工作者、党务工作者等100名成员，开展1000场宣讲活动，取得了良好的社会效应。

　　突出特色学。编写木兰溪生态文明建设实践案例，精心打造木兰溪干部教育培训基地，作为主题教育的重要教材和实践课堂。市委常委班子把践行习近平总书记治理木兰溪重要理念融入到专题研讨中，带头到木兰溪防洪工程奠基点，实地感受习近平生态文明思想在木兰溪的先行探索，并深入开展研讨交流。

　　找透问题症结 狠抓整改落实

　　主题教育启动以来，我市突出问题导向，从一开始就改起来，奔着问题去、盯着问题改。

　　我市坚持开门抓教育，深入开展调研，广泛征求意见，深刻查摆反思，努力把问题找准查实、剖深析透、检视到位。深入调研查问题，组织各级各单位开展“下基层、找症结，强担当、促落实”调研活动，采取“四不两直”方式，蹲点解剖、开出药方。以住村夜访、一线调查为主要形式，开展“下基层、进村居、入企业、解难题”蹲点调研活动。全市各级各单位开展调查研究10875次，形成调研报告3023篇，召开调研成果交流会505场，查摆问题24051条并建立清单。敞开大门听意见，通过召开“面对面、解难题”民情恳谈会、建立“百姓意见簿”等方式，收集群众反映的意见建议。每个月定期梳理归纳意见建议，按领导班子、班子成员及其他党员干部三个层面，分层认领，分别制定问题清单和整改措施。目前，全市各级各单位共开展征求意见座谈会2827场次，收集到群众反映的意见建议19097条。同时，校准标尺找差距，对标对表习近平总书记对福建工作的重要指示批示精神和治理木兰溪重要理念，系统梳理党中央重大决策部署在莆田的贯彻落实情况，强化跟踪督促。全市各参加单位全部召开专题民主生活会、组织生活会，党员干部普遍感到经受了一次深刻的思想洗礼和党性锤炼。

　　我市坚持问题导向和实践导向相结合，建立问题清单、责任清单、整改清单，边学边查边改，真刀真枪解决问题，以实际成效取信于民。

　　突出重点抓整改。集中力量推进“8+7+1”专项整治，挂图式作战、项目化推进。全市各参加单位共查找专项整治具体问题3007个问题，完成整改1867个，阶段性完成并长期坚持1107个，正在整改33个。排查7个方面民生难题积案101件，已化解99件，正在推进化解2件。查找木兰溪流域系统治理专项行动问题118个，完成整改60个，阶段性完成并长期坚持58个。木兰溪流域内的东圳水库水质从Ⅲ-Ⅳ类提高到Ⅱ类标准，下游150万人喝上放心水。木兰溪园头桥站获选全国首批“最美水站”，莆田荣获全国第三批城市黑臭水体治理示范城市、国家蓝色海湾整治项目城市。大气污染热点网格监管模式获评全国十佳“2019年度智慧环保创新案例”，优良天数比例由89.9%提高至97.8%。

　　聚焦民生解难题。以基层呼声为导向，下更大决心和力度解决好人民群众在就医、就学、就业、出行、养老等方面的操心事、烦心事、揪心事。针对安置房办证难问题，成立工作专班，集中力量攻坚，全市265个历史遗留安置房办证项目11.3万套完成首次登记8.14万套。针对部分县区“入学难、入园难”问题，在深入调研基础上列出“教育短板”清单，新增普惠性民办幼儿园155所、基础教育学位1.4万个、省级示范校54所。针对群众“看病难”问题，实施医院改造提升工程，新增病床位1700张以上，千人均病床位达到6张以上，改造提升100家村卫生所，完成28家基层“中医馆”建设，对接150多名在外莆田籍医学专家返乡义诊，受众5000多人次。

　　建章立制固长远。坚持“当下改”与“长久立”相结合，制定实施“六项制度”，扎实推进整改落实特别是专项整治工作，巩固深化主题教育成果。出台园区高质量发展9条措施，实施园区改造提升“十个一”工程，增强园区高端优质服务供给能力。出台稳鞋企促升级新10条、稳外贸15条等惠企政策，把主题教育实际成效转化为推动高质量发展落实赶超、建设美丽莆田的实际成果。同时，坚持边改边建，对一时解决不了的问题，明确阶段目标，持续抓好整改，健全监督机制，堵塞制度漏洞。

　　加强督促指导 注重统筹兼顾

　　主题教育开展以来，省委第6巡回指导组对我市主题教育全程参与、悉心指导，在“督”上尽责任、在“导”上显水平。市委主题教育领导小组和各巡回指导组从严从实指导，确保主题教育不走形式、不出偏差。

　　我市注重计划引导。制定工作计划，量化目标要求，明确规定动作，细化方法步骤，把中央和省委部署要求转化为“施工图”“任务书”。建立“三计划两提醒”机制，制订学习研讨、调研检视、整改落实3个计划，每周发出市级领导、市委巡回指导组2份提醒单。制定基层党支部“十个一”总体任务清单和7个党建领域主题教育个性清单，让各领域基层党支部可操作、能执行、好落实。

　　抓实巡回指导。15个市委巡回指导组按照省委“六个不放过”工作要求，通过实地调研、随机抽查、个别访谈、座谈交流等形式，真督真导、严督实导。在工作指导过程中，注意把握分寸、掌握节奏力度，做到重要会议必须列席、集中学习研讨必须到场、专题调研必须跟随、征求意见会必须参加、专题党课必须旁听、重要方案和重要材料必须审阅，把指导督导工作做扎实、抓到位。

　　在强化宣传舆论方面，依托湄洲日报、莆田广播电视台等市直主要媒体及所属网站、“两微一端”和莆阳先锋、莆田发布等新媒体平台，开设专题专栏，形成全方位、多角度和全媒体矩阵立体宣传格局，营造浓厚氛围。突出莆田特色，宣传以木兰溪流域系统治理统揽美丽莆田建设，教育引导全市党员干部深刻领会习近平总书记治理木兰溪重要理念；宣传我市组建理论宣讲小分队，开展1000场理论宣讲进基层活动，推动党的理论飞入寻常百姓家；结合庆祝新中国成立70周年，集中开展一系列爱国主题宣传教育活动，激发爱党爱国爱社会主义热情；结合开展“找差距、抓落实、解难题、化积案”行动，宣传我市在全国首推“自己‘批’网上办”审批服务新模式等一批着力破解群众最急最忧最盼问题，深入挖掘报道我市主题教育特色经验做法；注重典型示范激励作用，大力宣传一批先进典型，引领广大党员干部对标先进，不忘初心砥砺前行，为推动高质量发展落实赶超、加快建设美丽莆田而不懈奋斗。

　　我市始终坚持两手抓两促进，把开展主题教育同做好稳增长、促改革、调结构、惠民生、防风险、保稳定各项工作结合起来，同当前正在做的事结合起来，切实把主题教育实际成效转化为推动高质量发展落实赶超、建设美丽莆田的实际成果，促进经济发展稳中向好，产业转型步伐加快，营商环境持续优化。

　　不忘初心、牢记使命是加强党的建设的永恒课题，是党员干部锤炼党性的终身课题。站在新起点，各级党组织和广大党员干部将深入学习贯彻习近平新时代中国特色社会主义思想、习近平总书记重要讲话重要指示批示精神和治理木兰溪重要理念，自觉增强“四个意识”、坚定“四个自信”、做到“两个维护”，高举旗帜、对标对表，突出招商、项目带动，齐心协力推动高质量发展落实赶超，以“赶考”的心态向党和人民交出一份份满意的答卷。
