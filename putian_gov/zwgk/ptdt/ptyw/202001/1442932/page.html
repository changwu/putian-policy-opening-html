莆田市人民检察院工作报告

——2020年1月5日在莆田市第七届人民代表大会第四次会议上
来源:湄洲日报 时间：2020-01-24 21:42
| | | |

莆田市人民检察院检察长 许志鹏

各位代表：

　　现在，我代表莆田市人民检察院，向大会报告工作，请予审议，并请各位政协委员和其他列席同志提出宝贵意见。

　　2019年是新中国成立70周年，是全面建成小康社会和坚持高质量发展落实赶超的关键之年。检察机关完成内设机构重塑性改革，以崭新面貌开启新时代检察工作新征程。一年来，全市检察机关在市委、省检察院正确领导和市人大及其常委会的有力监督下，在市政府、市政协及社会各界的关心支持下，坚持以习近平新时代中国特色社会主义思想为指导，认真贯彻落实党的十九大和十九届二中、三中、四中全会精神，紧紧围绕莆田高质量发展落实赶超大局，坚持“务实稳进、精业提质”工作思路，全面履行法律监督职责，各项检察工作持续健康发展。全年共受理各类案件13088件，其中审查逮捕各类案件2867件4061人，审查起诉各类案件4251件5722人，办理刑事、民事、行政诉讼监督案件5869件，办理公益诉讼案件101件。

　　一、围绕中心大局，在服务高质量发展中凸显检察作为

　　全市检察机关坚持讲政治顾大局，细化实化检察环节服务保障措施，为高质量发展落实赶超提供有力司法保障。

　　全方位保障美丽莆田建设。坚持以习近平总书记治理木兰溪理念为指引，制定《检察机关服务“双比”活动实施意见》，出台《木兰溪全流域生态环境和资源保护公益诉讼实施方案》，构建务实高效的服务保障机制。综合运用立案监督、公益诉讼等方式，开展了木兰溪全流域治理、湄洲岛及其附近海域非法采砂治理、城市内河黑臭水体整治等专项监督，针对突出问题提出检察建议35份，督促清理污染和非法占用的河道1.98公里，督促拆除违规养殖场51处，督促关停非法采砂点9处。依法打击破坏生态环境犯罪，起诉非法采砂、走私象牙制品等犯罪79件127人。依托河长制工作站和生态文明建设基金模式，督促缴纳生态修复金105万元，补植复绿153.4亩，助力打好蓝天、碧水、净土保卫战。

　　多举措护航民营经济发展。贯彻习近平总书记在民营企业座谈会上的讲话精神，制定莆田市检察院服务民营经济健康发展“六个一”专项行动方案，以“医疗、鞋革、红木、珠宝、加油站”五大传统行业为样本开展重点调研，探索建立服务莆田民营经济健康发展长效机制。联合市工商联召开民营企业家座谈会，建立健全沟通联络机制，上门走访企业56家，开展法律服务、法治宣讲90余次。坚持平等保护理念，依法严惩侵害民营企业利益犯罪，批捕职务侵占、泄露商业秘密、侵犯知识产权等犯罪嫌疑人56人，起诉109人。准确把握法律政策界限，慎用刑事强制措施，审慎办理民营企业家涉罪案件，依法对38起涉民企案件作出不捕或不诉处理，坚决避免办了一个案子，倒了一家企业。

　　全身心守护民生民利。坚决防范和化解金融风险，积极参与打击非法集资、恶意逃废债及互联网金融风险等专项整治，提前介入涉案犯罪嫌疑人达117人的“9·11”菲律宾特大电信网络诈骗案，及时引导公安机关侦查取证。批捕“套路贷”犯罪42人，起诉非法吸收公众存款、集资诈骗等犯罪15人。聚焦脱贫攻坚，将司法救助融入精准脱贫，积极救助生活陷入困境的涉诉群众，为刑事被害人及近亲属发放救助金54万元。围绕保障千家万户舌尖上的安全，开展“四个最严”专项行动，起诉制售假药、有毒有害食品犯罪6人，市检察院办理的刘某“毒白粿”案是我市首例食品领域民事公益诉讼案件，涵江区检察院针对办案发现的问题提出检察建议，推动相关行政机关开展了为期半年的食品加工专项整治行动，在共护民生上凝聚了合力。

　　依职权参与反腐败斗争。坚持在反腐败斗争中充分发挥职能作用。落实检察机关提前介入、指定管辖、适用强制措施等衔接监察工作机制，确保监检衔接顺畅。受理监察机关移送职务犯罪案件28件36人，审查后决定逮捕14件14人，退回补充调查3件8人，已起诉23件31人。依法履行修改后刑事诉讼法赋予检察机关对司法工作人员相关职务犯罪的侦查权，组建专门侦查机构，全面摸排侵犯公民权利、损害司法公正的犯罪线索，调查核实案件线索12条，立案侦查司法人员相关职务犯罪2件2人。

　　二、强化综合治理，在创建平安莆田中展现检察担当

　　回应人民群众新需求，积极参与和推进美丽莆田治理现代化，不断增强人民群众的幸福感、获得感、安全感。

　　以高度的责任担当推进扫黑除恶专项斗争。围绕转段之年工作要求，切实扛起扫黑除恶专项斗争的检察责任。全年共提前介入涉黑涉恶案件38件，批捕39件89人，起诉46件215人，其中涉恶案件37件166人、涉黑案件9件49人。摸排移送黑恶线索37条，发出整治检察建议13份。通过检察长带头办案、重大案件挂钩指导、“三长”会商等机制，合力推进案件攻坚。检察长直接办理黑恶案件15件，出庭公诉13件。紧盯“破网打伞”，起诉黑恶势力“保护伞”2件2人。坚持不枉不纵，是黑恶犯罪一个不放过，不是黑恶犯罪一个不凑数，依法排除涉黑涉恶认定25件，追加认定17件，对李某等人组织、领导、参加黑社会性质组织一案，依法改变定性为恶势力，确保专项斗争打实打准。

　　以温情的法治担当提升社会治理效能。践行新时代“枫桥经验”，将心比心对待群众信访，重在化解矛盾、案结事了。落实“群众来信件件有回复”要求，办理群众来信来访1832件，能够答复的100%完成“七日内程序回复”“三个月内办理过程或结果答复”。探索第三方参与化解疑难涉检信访案件，邀请律师48人次参与接访，增强矛盾化解合力。荔城区检察院释法说理和人文关怀并举，以真心换信任，以诚心赢民心，成功化解了一起23年信访积案，取得和解谅解。重视对农民工等特殊群体的权益保护，起诉拒不支付劳动报酬罪9人，帮助追回欠薪198.8万元。

　　以强烈的使命担当倾情呵护未成年人。坚决贯彻“一号检察建议”，落实未成年人司法保护政策，对涉嫌轻微犯罪并有悔罪表现的未成年人，不批捕42人、不起诉24人，提供法律援助40人次，封存犯罪记录134人。依法严惩性侵、拐卖、故意伤害等侵害未成年人犯罪，批捕161人，起诉169人。积极参与校园周边安全整治，全面推进检察长兼任法治副校长工作，常态化开展各类校园普法活动40余场。“莆阳未检”团队获莆田“十佳好青年”称号，城厢区检察院推动构建了“家、村、校、检”等社会力量共同参与的未检保护格局，持续擦亮莆田未检工作品牌。

　　三、立足四大检察，在维护公平正义中作出检察贡献

　　秉持检察官客观公正立场履行检察职责，以求极致精神努力提供优质的法治产品、检察产品。

　　着力做优刑事检察工作。坚持“在监督中办案、在办案中监督”理念，加强刑事立案和侦查活动监督，紧盯有案不立、有罪未究和不当立案等问题，监督公安机关立案37件，撤案9件，纠正漏捕108人，追诉漏犯70人，发出纠正违法通知书19件。加强审判活动监督，发挥抗诉案件的刚性监督和类案指导作用，实现抗诉一件，规范一片的司法效果。对认为确有错误的刑事裁判提出抗诉22件，法院已审结16件，改判9件，改判率56.25%。秀屿区检察院提出抗诉的三起盗刷信用卡定性争议案件，经市中院逐级请示最高人民法院后采纳抗诉意见，促成全市该类案件执法尺度统一。提出量刑建议1605人，法院采纳1294人，采纳率80.62%。加强刑事执行和监管活动监督，办理羁押必要性审查360人，办理减刑、假释、暂予监外执行案件1560件，监督裁定特赦罪犯69人。

　　着力做强民事检察工作。综合运用抗诉、检察建议、违法调查等多元监督方式，突出抓好生效裁判监督、执行监督、审判人员违法行为监督、虚假诉讼监督工作。与市中院会签《关于办理民事行政再审检察建议的若干意见》，着力提升再审检察建议质效。办理各类民事诉讼监督案件265件，提请抗诉和再审检察建议45件，提出诉讼违法和执行监督检察建议69件，移送拒不执行判决、裁定案件线索20件，公安机关已立案18件，助力法院破解执行难问题。发挥刑事、民事一体化办案机制，办理虚假诉讼案件29件。涵江区检察院在办理一批涉恶“套路贷”刑事案件中排查出20个虚假诉讼案件线索，向法院发出再审检察建议，依法维护19名受害者利益，让“迟到”的正义重新回归。

　　着力做实行政检察工作。围绕维护司法公正、促进依法行政的共同法治目标，积极履行行政检察监督职能。办理各类行政检察监督案件73件，其中办理生效裁判结果监督案件38件，行政执行监督案件23件。深入开展行政非诉执行专项监督活动，强化与法院协作配合，发出非诉执行检察建议12件，共同推动解决行政处理决定“白条化”问题。探索开展“违章建筑处置不规范”监督活动，建议相关部门依法处置两起已收归国有的违章建筑被侵占问题，涉及占用土地面积 3954平方米。

　　着力做好公益诉讼工作。以市人大常委会对全市检察机关公益诉讼工作开展视察为契机，强化与行政机关协作配合，善用公益诉讼回头看、诉前圆桌会议等方法强化检察建议刚性，促进公益损害问题解决，尽最大努力让违法者为受损公益买单。收集公益诉讼案件线索104件，立案101件，发出诉前检察建议93件，推动行政机关采取整改措施63件，向法院提起公益诉讼6件，审结案件诉讼请求得到法院全部支持。仙游县检察院开展的“关爱木兰溪·保护母亲河”公益诉讼专项监督经验做法在全国公益诉讼检察理论与实践研讨会上作交流发言。加强英烈权益保护，针对闽中革命烈士陵园场所被侵占、娱乐化等现象，依法向主管部门发出诉前检察建议，督促整改到位，用法律手段捍卫英烈尊严。

　　四、注重质效提升，在深化司法改革中凝聚检察智慧

　　聚焦国家治理体系和治理能力现代化，持续深化改革创新，为坚持和完善中国特色社会主义法治体系打造检察样本。

　　全面落实认罪认罚从宽制度。发挥检察主导作用，稳步推进刑事诉讼法规定的认罪认罚从宽制度落实落地。会同公安、法院、司法、国安等部门制定认罪认罚从宽制度工作实施细则，细化量刑建议标准，实现案件繁简分流。协同政法各部门出台法律援助律师制度，落实律师参与认罪认罚值班经费保障，全面保障犯罪嫌疑人诉讼权利。全年对1470名真诚悔罪认罚的犯罪嫌疑人和被告人适用该制度，其中适用简易程序和速裁程序840名，占比57.14%，促进社会关系修复。加强“案-件比”指标实践转化应用，落实检察业务态势分析机制，倒逼提升司法办案质效。

　　完成检察机关内设机构改革。全市检察机关内设机构改革顺利完成，构建了符合司法规律、科学规范高效的检察机关内设机构体系。按照“捕诉一体”办案机制，市检察院设立七个检察部和相关内设机构，五个县区检察院共设置内设机构47个，全市精简内设机构28个。完善司法办案内部监督，定期开展案件质量评查，将评查结果纳入业绩考核评价，权责明晰的检察权运行新机制基本形成。发挥“关键少数”示范效应，入额领导带头办理重大疑难复杂案件，两级检察长列席法院审判委员会60件。

　　积极探索监督方式创新。开展对公安机关的派驻监督试点，把监督触角延伸到办案一线。对驻监检察实行“巡回+派驻”工作模式，组成巡回组对莆田监狱开展专项检察，促进提高刑罚执行和监管质量。推动“公安机关执法办案管理中心48小时醉驾速裁”制度试点工作，秀屿区检察院成功办理了全省首例48小时内完成诉讼全流程的刑事犯罪案件，一名醉驾犯罪嫌疑人在被抓获后37小时内即告宣判，打造了高效率、可复制的“简案快办”新机制。

　　五、坚定政治站位，在强化自身建设中提升检察公信

　　认真落实新时代党的建设总要求，牢记初心使命，全面从严治检，不断推进检察队伍革命化、正规化、专业化、职业化建设。

　　扎实开展主题教育。坚持把“不忘初心、牢记使命”主题教育贯穿队伍建设始终，抓实学习教育、调查研究、检视问题、整改落实四项重点措施。落实“8+7+1”治理，结合检察实际，查找45个问题和制定52条整改措施，明确清单集中发力，整改效果明显。落实意识形态工作责任制，牢牢把握思想理论武装这个根本，开展政治素养培训16场，把学习贯彻习近平新时代中国特色社会主义思想和党的十九大、十九届四中全会精神，与学习贯彻习近平总书记对福建、对检察工作重要指示精神贯通起来，做到真学真懂真信真用，引领莆田检察始终沿着正确政治方向前进。

　　强化专业能力建设。注重队伍职业素能提升，开展大规模的教育培训，组织参加高检院、复旦大学、中检网院等各类素能培训4176人次。紧贴检察实务，开展认罪认罚及速裁程序制度、木兰溪流域生态保护、非法采砂及海岛司法保护等专题实证研究，积极破难题、出实招。加强课题申报，1项获最高人民检察院检察应用理论研究课题立项，1项获省人大理论研究课题立项，2项获省法学会重点课题立项，城厢区检察院撰写的一篇调研成果获省人大常委会课题一等奖。全年共发表调研文章227篇，获省级以上奖项71篇，国家级20篇。有20个集体和72名个人获省级以上表彰，7个集体和16名个人获国家级表彰。

　　推进全面从严治检。坚决落实管党治党主体责任，努力践行更高标准、更严要求。自觉接受省检察院党组政治巡视，立行立改存在问题，制定整改措施180条，完善各项规章制度19项。坚持问题导向，开展被法院列入失信人员情况自查自纠回头看、因私违规出国、违规经商办企业等问题专项整治，全覆盖集中填报过问或干预、插手检察办案等重大事项情况。不断改进文风会风，力戒形式主义、官僚主义。坚持严管就是厚爱，着力整治队伍作风，开展“检察人员八小时以外”行为规范查纠整顿活动，签署承诺书513份，查处违纪违法问题3件3人。

　　持续打造阳光检察。坚持以公开立公信。依托案件信息公开网、广播电视、报刊杂志和“一网两微五端”平台，公开生效文书、推送工作动态、评析典型案例、讲解法律知识、展示干警风采，让检察好声音、好故事“飞入寻常百姓家”。原创拍摄的《莆检说法》《以公益之名，守护木兰溪》等普法短视频被推介登上学习强国平台。1部作品在国家级新媒体评选活动中获奖，“莆田检察”新媒体被评为第六届全国检察系统最具影响力新媒体奖。

　　党的领导、人大监督是做好检察工作的根本保证。一年来，全市检察机关始终坚持党对检察工作的绝对领导，认真落实《中国共产党政法工作条例》，坚持全面工作定期报告、重大部署主动报告、重要事项及时报告。认真贯彻人大及其常委会决议、决定，配合人大开展执法检查和视察调研。认真办结并反馈人大代表意见建议3件，收集市七届人大三次会议期间代表提出的意见建议，并细化为全市检察工作要点抓好落实。重视与代表的经常性联系，邀请代表、人民监督员参加主题检务活动、公开听证会和观摩庭等145人次。自觉接受政协民主监督，向各民主党派、工商联和无党派人士通报检察工作，广泛听取意见建议。定期寄送《检察日报》《检察工作简报》，让检察走进群众，让群众了解检察。

　　各位代表，过去一年检察工作取得的点滴进步，是党委坚强领导，人大及其常委会有力监督，政府、政协大力支持，代表、委员和社会各界关心帮助的结果。在此，我代表全市检察机关表示崇高的敬意和衷心的感谢！

　　同时，我们清醒地认识到，检察工作还存在一些问题和不足：一是对标高质量发展落实赶超任务，服务大局的精准度、实效性有待提升；二是对标人民群众对公平正义的新期待，法律监督效果需进一步强化；三是对标优质高效检察产品，推进改革创新的手段仍不够丰富；四是对标“四大检察”全面协调充分发展要求，检察队伍专业结构和专业素能有待进一步优化。对此，我们将紧紧依靠市委领导，在人大监督和各方面支持下，认真加以解决。

　　2020年，是实现全面建成小康社会和“十三五”规划的收官之年。我们的总体思路是：坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的十九大和十九届二中、三中、四中全会精神，坚决落实中央和省委、市委决策部署，坚持新发展理念，坚持全面深化改革创新，牢牢把握正确政治方向，忠实履行宪法法律赋予的法律监督职责，践行“双赢多赢共赢”理念，持续增强检察履职能力，推动新时代莆田检察再上新台阶。

　　一是以“务实”为理念，在服务发展大局上担当新作为。坚持党对检察工作的绝对领导，深入学习贯彻党的十九届四中全会精神，按照美丽莆田建设治理现代化新要求，以木兰溪流域系统治理为抓手，进一步深化细化检察服务保障措施。落实平等保护政策，依法打击侵害民营企业合法权益的违法犯罪，完善服务保护机制，推进“六个一”落地见效，在营造莆田法治化营商环境中体现检察温度。坚持把打击犯罪、维护稳定与化解风险、促进发展统筹起来，纵深推进扫黑除恶专项斗争，服务打好三大攻坚战，为大局服务，为人民司法，不断满足人民群众司法新需求。

　　二是以“稳进”为基调，在强化法律监督上谋求新发展。聚焦法律监督主责主业，持续做优刑事检察、做强民事检察、做实行政检察、做好公益诉讼，努力实现“四大检察”全面协调充分发展。按照“捕诉一体”办案机制，探索形成具有莆田检察特点的全流程、立体化刑事诉讼监督机制。强化对司法活动的监督，依法查办司法工作人员相关职务犯罪。加大对民事、行政生效裁判监督力度，常态化开展虚假诉讼和执行活动等领域违法问题监督，维护司法公正和法治权威。突出办理生态环境和食品安全等领域公益诉讼案件，守护民生法治底线。

　　三是以“精业”为要求，在建设高素质队伍上激发新活力。牢记习近平总书记“四个铁一般”队伍建设要求，把政治建设放在首位，不断增强“四个意识”，坚定“四个自信”，做到“两个维护”。落实意识形态工作责任制，坚定不移推进全面从严治检，持之以恒抓好纪律作风建设，不断提高检察人员的政治素质、业务素质和职业道德素质。加快知识更新、素能培训、岗位练兵、实践锻炼，进一步夯实检察事业发展人才支撑。扎实推进“典型引路”工程，广泛开展学先进活动，激励广大检察干警在新时代展现新作为。

　　四是以“提质”为目标，在深化改革创新上回应人民新期盼。坚持优化、改革、创新、提质，全面推进群众来信件件有回复、认罪认罚从宽制度适用、检察建议参与社会治理等工作，以更高效的司法运行机制促进治理体系和治理能力现代化。落实司法责任制综合配套改革，充分释放改革新动能。深化检务公开，推进12309检察服务中心升级改造，打造智能化平台，提升阳光检察形象。主动接受人大监督，用心办好代表建议和交办事项，做精做细做实代表联络工作，始终在人大的监督支持下做好检察工作。

　　各位代表，行者方致远，奋斗路正长。在新的一年里，全市检察机关将更加紧密地团结在以习近平同志为核心的党中央周围，紧紧依靠市委的坚强领导、市人大的有力监督，认真贯彻落实本次大会的各项决议决定，勇于担当，奋力作为，推动新时代我市检察工作实现新发展，为全面建成小康社会、加快推进美丽莆田建设作出新的更大贡献。
