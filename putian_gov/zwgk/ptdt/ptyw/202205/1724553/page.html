厚植家国情怀 彰显青春担当——习近平总书记在庆祝中国共产主义青年团成立100周年大会上的重要讲话在我市广大青年中引起强烈反响

来源:湄洲日报 时间：2022-05-12 08:24
| | | |

　　百年征程铸辉煌，青春聚力心向党。5月10日，习近平总书记在庆祝中国共产主义青年团成立100周年大会上发表的重要讲话在我市共青团和广大青年中引起强烈反响。大家表示，习近平总书记的重要讲话思想深刻、内涵丰富、语重心长、情真意切，我们一定要始终牢记习近平总书记的殷殷嘱托，坚持守正创新、踔厉奋发，在不断学习中激发信仰、汲取力量，进一步坚定听党话、跟党走的决心，树立为祖国为人民赤诚奋斗的理想，做有理想、敢担当、能吃苦、肯奋斗的新时代好青年，用青春的智慧和汗水为奋力答好谱写“福建篇章”的莆田答卷而打拼。

　　“习近平总书记在庆祝中国共产主义青年团成立100周年大会寄予广大团员青年殷殷期望，让人深受鼓舞、倍感振奋。同时，对共青团工作提出明确要求，为做好团的工作指明了前进方向、提供了根本遵循。”团市委副书记方宇说，作为共青团干部，他将着力增强引领力、组织力、服务力，更好地把青年团结起来、组织起来、动员起来，带领广大团员青年勇做新时代的弄潮儿，争当伟大理想的追梦人，争做伟大事业的生力军。尤其是立足莆田发展实际，引导广大团员青年主动融入“俯下身子抓产业、一心一意谋发展”这个干事创业的大舞台，聚焦12条产业链发展、木兰溪“十里风光带”建设、港产城联动及“党建引领、夯基惠民”等市委工作大局，各尽其才、各展所能、同向而行，用青春的智慧和汗水打拼出一个更加美好的未来。

　　团市委组织部部长梁弨彬说，习近平总书记强调，“坚定不移跟党走，为党和人民奋斗，是共青团的初心使命”。作为新时代的团干部，我们要坚定政治信仰，牢记“党有号召、团有行动”的初心，接续奋斗把五四精神的火炬传递好，充分发挥党联系服务青年的桥梁和纽带作用，引领和动员全市团员青年在青春赛道上奋力奔跑，让青春因梦想而激扬，让青春因拼搏而精彩，让青春因奉献而厚重。

　　回望百年，青春向党。百年恰是风华正茂，青春正当奋进前行。荔城团区委书记徐毅龙表示，作为这伟大历史时刻的见证者、践行者，荔城共青团将深入学习贯彻习近平总书记关于青年工作的重要思想，坚定政治属性，发挥育人作用，坚持从严治团，为党和国家的蓬勃发展培养坚强有力的“助手”和“后备军”。同时，坚持把创新作为共青团工作的灵魂，聚焦主责主业，开拓共青团工作新阵地、延伸工作新触角、创新工作新机制，提升服务青年功能，凝聚青年工作合力，引导广大青年再立新功。

　　习近平总书记指出，党的奋斗主题就是团的行动方向。共青团紧扣党在不同历史时期的中心任务，团结带领广大团员青年积极投身人民群众的壮阔实践，在民族复兴征程上勇当先锋、倾情奉献，发挥生力军和突击队作用。涵江团区委书记黄滨认为，国家、社会的繁荣进步，永远与广大青年的砥砺奋进、开拓创新息息相关。当前，我市正处于全方位推进高质量发展超越的关键时期，需要各方面的青年积极参与。共青团要紧跟时代步伐，学会“青年style”，以青年喜闻乐见的方式激发活力，发动广大青年积极投身经济社会发展大局。

　　“习近平总书记的重要讲话进一步激发团员青年的奋斗激情及为党和国家奉献青春的理想信念。”秀屿团区委书记周春雨说，秀屿各级共青团组织一定积极响应党的号召，围绕秀屿区委、区政府“科教兴区、海洋富区、工业强区、物流活区、新城旺区”建设，充分发挥各类“青”字号典型选树，引领青少年担当作为，凝聚青春“正能量”；组织开展疫情防控、文明创城、生态环境保护等志愿服务行动，彰显青春“践行者”；对接青年就业创业项目、深入开展“我为群众办实事”实践活动等，引导青年建功立业，争当青春“排头兵”。

　　湄洲镇团委书记黄雄茂说，作为一名基层团委书记，他将持续做好本职工作。牢记团的根本任务、政治责任、工作主线这三个根本性问题，牢记引领凝聚青年、组织动员青年、联系服务青年这三项基本职责，在工作中培养担当能力，真正展现新时代团干部的绝对忠诚与使命担当，激励更多青年参与推进湄洲岛高质量发展的进程，为海岛建设提供强大的青年力量支撑，共同扛起“保护好湄洲岛”政治责任。

　　莆田学院当天组织师生收听收看直播大会。“习近平总书记在讲话中肯定了广大团员青年喊出‘把青春献给祖国’的响亮口号，向科学进军，向困难进军，向荒原进军。这让我备受鼓舞。”该校药学与医学技术学院金楠博士说，她所负责的“莆田学院纳米抗菌抗病毒药物研发团队”改进了中药饮片，促进了中药产业高质量发展。将台湾地区精致农业模式、高质量作物在福建乡村进行试点推广。未来，我们将以身作则，通过科技特派，让科研人员下沉地方企业、田间地头，把更多科研成果进行有效转化，为地方经济发展作出贡献。

　　厚植家国情怀，彰显青春担当。青春孕育无限希望，青年创造美好明天。我市广大青年和共青团员纷纷表示，青春心向党，奋进的集结号已经吹响，我们要以青春之热血、青春之干劲，肩负起国家民族的希望，在中国共产党的领导下，与时代同心同向同行，不断前进。（记者　吴伟锋　郭文渊）
