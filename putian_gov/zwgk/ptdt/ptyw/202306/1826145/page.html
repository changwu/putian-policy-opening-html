我市开展村党组织书记“练兵比武”交叉拉练活动

来源:湄洲日报 时间：2023-06-19 07:20
| | | |
　　炎炎夏日，灼灼初心。近日，全市村党组织书记“练兵比武”交叉拉练活动火热进行。村党组织书记代表和“两代表一委员”分成两组，由市委组织部领导带队，顶着烈日、冒着酷暑深入16个村看变化、听思路、找差距、比干劲，共话乡村振兴发展成果，共绘和美乡村新画卷。
　　从“看现状”转为“看进步”
　　此次接受交叉拉练的村，都是去年来通过村党组织书记“练兵比武”活动，进入优秀行列或取得明显进步的村。现场掌声与压力同在，大家在“看、听、问、答、思、议”过程中，比进步、比变化、比增量，看到了差距，找到了标杆，达到学以致用、转化运用、发挥作用的目的。
　　两组观摩人员一路走、一路看、一路评，看基层党组织是否坚强有力，看农村党员先锋模范作用发挥是否充分，看党建引领乡村治理是否有效，看村财村民是否“双增收”，看乡村建设、村容村貌是否提升；比产业旺不旺，比人才优不优，比文化兴不兴，比生态美不美，比组织强不强，检验“练兵比武”活动成果。
　　“蔗坑瀑布、桃溪步道、绿缘漂流、南坛温泉……目前，我们正推进‘萩山来信—南坛温泉’和‘萩山来信—桃源’项目。”2021年换届时刚上任的萩芦镇南下村党支部书记游文耀介绍，南下村借力公共区域品牌“五彩萩芦”，着力打造新业态下的“金牌旅游村”。
　　毗邻南少林寺的荔城区西天尾镇林山村也迎来新变化。“换届以来，我们解决了群众取快递难、就医难、饮水难等‘三大难’问题。在‘党支部+旅游+产业’模式带动下，去年村集体经济收入达到48万元，今年预计再翻一番！”村党支部书记林燕和信心满满。
　　涵江区江口镇海星村开发“海星一家人”微信小程序，带动党员群众主动参与基层治理，营造侨乡“邻里一家亲”的良好氛围。秀屿区笏石镇苏塘村成立“惠民银行”，村民通过参加公益活动获取“惠点”并向村股份经济合作社兑换现金，参与乡村治理的热情高涨……“党建引领、夯基惠民”工程纵深推进、全面提升。
　　蝶变也发生在山区乡村。仙游县书峰乡书峰村聘请乡贤、中国园艺学会枇杷分会会长林顺权教授为产业顾问，建设现代枇杷产业园区，打造150亩核心产区，同步完善智慧物联产业配套设施。涵江区白沙镇广山村党支部领办农文旅发展公司，建设“有田有地共享田野”“有山有水露营基地”等项目，增加村财收入27万元，并为群众提供220个就业岗位。
　　“村看村，户看户，群众看干部。”涵江区大洋乡坝头村“两委”班子充分征集群众意见，实施净化、美化、亮化工程，村民饮水用水困难、龙江溪支流堤坝薄弱、排洪不畅等问题得到解决，去年软弱涣散村党组织顺利转化，得到了群众的认可。秀屿区平海镇石塘村党支部书记林朝阳带领“两委”一班人，从群众反映最强烈的问题抓起，发动乡贤建成农村公益图书馆，成立通信合作社、经济合作社，原来基础设施落后、村貌脏乱差的软弱涣散村正朝着秀美富足强村转变。
　　聆听、拍照、感叹、讨论……“围观”引发了大家的思考。“一路走来，所见所闻让人振奋，收获满满。现在想得最多的就是下一步我们村该怎么做。”市党代会代表、北岸东埔镇何山村“80后”女党支部书记郑美香在拉练中，频频拿出手机拍摄。
　　从“会议室”走向“田间地头”
　　“这样的交叉拉练观摩，创新、务实、高效、开放，有互动、有思考，收获很大。”“一路观摩、一路学习，工作理念、工作思路上都受到了触动。”大家纷纷表示，通过看实景、听实话、察实情，看到了亮点，取到了“真经”。
　　在仙游县游洋镇河星村农特产品展示厅，一位篾匠正在把竹片加工成竹筛。“这是我们村流传下来的手艺。这两年村党支部引进‘秋天妈妈’等网红，通过直播带货帮助我们把竹制品卖出去，销路一下子打开了。”村党支部从过去的“等靠要”转向“闯改创”，推动乡村“农文旅商”融合发展。
　　“党支部书记和党员一定要带头‘吃螃蟹’，群众才会、才敢跟着干。”北岸经开区山亭镇蒋山村党支部书记林国辉站在紫菜育苗基地上，和大家分享经验。近年来，蒋山村党支部通过领办合作社，组织村里党员带头，做优做强紫菜特色产业，并发动全村200余户村民参与紫菜养殖，年产值达6000多万元，每年为村集体增收超90万元。
　　“这里是岭下村的枇杷示范园区，总面积240亩。”城厢区常太镇岭下村党支部书记陈敏指着一片茵茵树林介绍道。岭下村曾是省定贫困村。近年来，村党支部用好移民、幸福家园、美丽乡村建设等政策，村容村貌焕然一新，还筹集4000多万元开展枇杷改良换种、衍生产品加工、研学基地、直播带货等，打响岭下枇杷品牌，枇杷年产值超1400万元。
　　跟着党支部书记的步伐，参加拉练的人员感受到，在“头雁”带领下，群众日子越过越红火。仙游县社硎乡白洋村发动党员担任乡村美化宣传员、先锋员、督导员，推动“乡村颜值”和“富民价值”同步提升。湄洲岛湄洲镇宫下村积极打造“党建+民宿”品牌，致力打造湄洲岛风情渔村，村民腰包鼓了，集体经济也强起来……一幅集历史文化、农耕体验、休闲旅游、生态观光于一体的魅力乡村新画卷正在莆阳大地徐徐展开。
　　“不看不比感觉良好，一看一比差距不小。回去后，要好好消化吸收，结合我们村实际，做好转化运用工作。”2021年换届时新任城厢区灵川镇太湖村党支部书记陈海英的笔记本上记满了“干货”。
　　从“你说我听”到“望闻问切”
　　一天时间连轴转，大家当面听、现场看、直接问、当场评，相互学习、取长补短、共同提高。
　　“你们把‘村企共建’作为整顿转化软弱涣散村党组织的重要举措，除了土地入股、吸收村民就业外，还有没有其他的思路？如何吸引企业积极参与乡村振兴、乡村治理？”在荔城区黄石镇沙堤村，市委组织部领导现场提问党支部书记张庆山。省人大代表、秀屿区东庄镇厝头村党支部书记詹雪梅指出，现在村党组织要统一领导本地区基层各类组织和各项工作，要把村一级党组织建强，发挥堡垒作用，通过党建联建促村企联结，让村集体经济、群众收入和企业发展“三方共赢”。在场的观摩人员也为沙堤村如何加强村企联建出点子、支实招。
　　“去年村集体经济收入有多少？具体包含哪几块？下一步如何培育新的增长点？”十四届全国人大代表、秀屿区笏石镇岐厝村党支部书记曾云英同城厢区华亭镇后塘村党委书记许剑航深入交流、出谋划策，通过算清经济账、生态账，帮助后塘村理清抓党建促乡村振兴、促共同富裕的思路。
　　“象星村红色研学基地具体有哪些内容呢？我们村一名党员办了旅行社，旗下有几个研学基地，下一步可以寻找‘山海’合作机会。”秀屿区南日镇鳌屿村党支部书记吴庆兰主动加了仙游县菜溪乡象星村党支部书记岳炳候的微信。
　　“练得好不好，不能纸上谈兵，要评一评才知道。”拉练观摩结束后，大家围绕乡村五个振兴和现场讲演6个方面，对16位村党支部书记进行打分，并交流心得体会。大家表示，一定要把参加这次活动的收获带回去，把学到的宝贵经验化作源源不断的动力，将学到的实招妙招结合自己村的实际进行探索实践。
　　秀屿区埭头镇石城村党总支书记林高成认为，书峰村克服交通不便等困难，深入挖掘本土人才、引才回乡，构建起现代化特色果业发展新模式，值得学习借鉴。省党代会代表、荔城区黄石镇惠下村党支部书记吴金贵在分享了“服务365”工作法后表示，一路所见所闻让他倍感压力，惠下村要进一步提升标杆，做实做强玉雕玉器等产业，发展新型农村集体经济，持续赋能乡村振兴。
　　市委常委、组织部部长袁素玲在参加涵江区白沙镇广山村拉练观摩互动交流后指出，开展村党组织书记“练兵比武”活动，是贯彻落实党的二十大精神、大抓基层鲜明导向的重要举措，也是践行“深学争优、敢为争先、实干争效”行动、实施“党建引领、夯基惠民”工程的具体行动。要以此次活动为契机，持续推深做实，让村党组织书记主动对标先进找差距、正视问题抓落实，切实提高解决实际问题的能力，为乡村振兴夯基础、添活力、增动力。要大兴调查研究，摸清村情民意，解决好群众急难愁盼问题，切实增强群众获得感、幸福感和安全感。要突出抓班子带队伍，全面增强村党组织政治功能和组织功能，为建设绿色高质量发展先行市提供坚强保证。 林凤闺蓉
