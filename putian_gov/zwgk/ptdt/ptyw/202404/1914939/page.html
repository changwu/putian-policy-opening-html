蓄势聚能勇向前——看我市延链强链打造新能源产业高地

来源:湄洲日报 时间：2024-04-22 07:23
| | | |

图为福建LNG接收站建成6座16万立方米的LNG储罐。杨怡玲 摄

　　莆田新能源规上企业36家，2023年实现产值350亿元、增幅8%，缴纳税金总额11.38亿元，其中10家分别纳税5000万元以上；固定资产投资同比增加137.9%，居全市产业链第一；新能源总发电量122.8亿度，光伏发电量达4.44亿度，同比上涨201.2%……

　　一组组沉甸甸的数据，充分展现莆田新能源产业强劲的发展态势。乘势而上、顺势而为，我市坚持强龙头、补链条、聚集群，持续抓好新能源产业延链补链强链，统筹推进“风、光、水、气”等资源开发布局，拓展提升“风、光、锂”等新能源制造产业，激活新能源产业的“资源属性”和“制造属性”，聚力打造新能源产业发展新高地。

　　特色资源 优势凸显

　　4月17日，从巴布亚新几内亚莫尔兹比港运载15万立方米液化天然气（LNG）的“库尔赫斯基”轮，在中国海油湄洲湾“绿能港”福建LNG接收站专用码头顺利卸载后驶离。福建LNG接收站投用以来，截至目前顺利完成724船的接卸，为我省及周边地区供应天然气超过630亿立方米，为莆田经济社会发展提供“绿色动能”。

　　福建LNG建有全省首座液化天然气接收站，也是目前省内最大的天然气供应商，承担全省70%以上的天然气供应。已建成6座16万立方米的LNG储罐、372公里的长输天然气管线。今年内，将开工建设一座全球单罐容量最大的27万立方米地面全容式LNG储罐。

　　“在进口运输过程中，LNG通常是在零下162摄氏度的环境下以液态储存。”福建LNG接收站运行部经理边远表示，与福建LNG配套的冷能空分项目以空气为原材料，利用LNG在气化过程中释放出来的冷能将空气中的氮、氧、氩分离，制成最终产品，有效减少二氧化碳排放。

　　目前，我市初步形成中海油、哈纳斯“双气源”发展格局。哈纳斯LNG接收站项目已获得国家发改委核准，年接收能力最大可达565万吨/年，总投资52.6亿元，主体工程计划今年内开工。建成后，可为闽粤浙赣四省增加天然气年供应量80亿立方米，同时通过西气东输管道气置换，为宁夏中长期天然气应急提供储备，进一步提升闽宁合作水平。

　　近年来，我市积极聚焦国家能源战略，立足新能源产业基础和资源优势，从“链”上发力招大引强，加速优势产业集群成势，为高质量发展注入强大动能，推动实现“双碳”目标。

　　产业集群 融合发力

　　走进位于仙港工业园瑞峰片区的仙游紫京新能源三元前驱体项目现场，只见该项目一期主体结构全部完工，进入装修及室外工程阶段，部分生产设备准备进场，项目二期工程也在同步推进。该项目计划总投资110亿元，用地面积350亩，其中一期投资30亿元，规划建设年产3万吨三元前驱体和1万吨正极材料生产线。项目工程部经理郑建程告诉记者，紫京科技坚持绿色、环保、低碳的发展理念，此次进场的设备处于目前国内外领先水平。项目预计今年第三季度陆续投用，将打造成为锂离子电池三元材料全球供应商。

　　作为新能源汽车动力电池产业领域的高精尖技术产业化项目，紫京与仙游已落地的和拓、国城等项目互为产业链上下游，形成动力锂电池新材料完整链条。

　　去年以来，我市围绕动力电池、储能、氢能等新能源赛道，引进一批链主企业铸链条、建集群，积极抢占新能源材料新赛道，打好产业转型升级、经济高质量发展组合拳，积极实现经济效益与环境保护双赢。

　　延链招商 服务护航

　　眼下，集中式光伏发电新能源产业发展迅速，而项目开工手续涉及部门多，市场变化快，对企业来说，时间就是生命线，越快并网发电就越早收益。

　　连日来，在涵江兴化湾南岸湾顶滩涂海域上，创能涵江兴化湾100兆瓦渔光互补光伏电站项目工程建设如火如荼，工人利用机械设备有序进行打桩作业、搭建光伏支架。

　　海域使用权证作为项目推进的核心要素，是影响工期的关键节点。该项目作为全市首家开工的集中式光伏发电项目，涉及用海约1670亩，办证前需要进行大量勘测和试桩工作，以确保项目土地集约化、项目施工技术合理化。市新能源产业链各小组协调自然资源局、港口集团、海事局等相关部门、单位，讨论细化方案，确保如期出证。

　　“海域使用权证办理下来，真正打消我们的疑虑。在项目建设过程中，每件事产业链工作人员都会关注，及时跟进，解决我们的后顾之忧。”项目负责人何晓辉说，项目从立项到开工，短短半年时间，感受到“莆田速度”的背后离不开高效贴心的服务保障。目前，项目累计打桩22504根，占总数71.57%，110千伏外送线路已全线贯通。项目建成后，预计每年将提供1.3亿千瓦时的清洁能源。

　　市新能源产业链党员干部扑下身子、沉到一线，聚焦经济发展和项目建设需求，广泛了解企业所思所想所盼，建立健全清单台账，着力破解企业反映的痛点、难点、堵点问题，为招商引资企业在公司注册登记、企业迁入变更、项目申报备案等方面提供“一站式”服务，营造尊商亲商安商的浓厚氛围。

　　栽好“梧桐树”，引来“金凤凰”。

　　去年2个平海湾海上风电场DE区和湄洲湾外海海上风电项目相继完成核准和竞配，为下一步近百亿元投资奠定基础。同时，木兰抽蓄近90亿元项目已开工建设，“随着越来越多新能源产业项目落户，产业间的关联性将更加凸显，产业集聚效应将进一步放大，将为莆田高质量发展增添新引擎。”市发改委副主任、新能源产业链综合组组长林楠说。

　　培育提升新能源产业链，资源有优势、企业成规模、产业有集群、市场前景好……我市将在绿色低碳转型、培育新能源支柱产业的过程中奋发作为、铿锵前行，力争实现2024年新能源产业产值385亿元，同比增长10%。（记者 陈艳艳）

　　短评

　　追“新”逐“绿”强动能

　　我市拥有丰富的风电、光伏资源，且有天然气等重要能源项目落户，发展新能源产业优势得天独厚。我市出台推进新能源产业高质量发展行动方案，建立重点项目表，围绕陆上风电、海上风电、抽水蓄能、渔光互补、天然气等领域，绘好产业链全景图，明晰现有产业环节，不断延伸上下游，推动新能源产业尽快成为支柱产业。

　　加快形成新质生产力，新能源产业大有可为。要重视中长期前瞻性布局，在符合国土空间规划等相关要求前提下，保障新能源产业发展合理空间需求。优化项目服务，保障项目建设与运营。紧盯前沿，加大招商引资、招才引智力度，引进一批领军企业、关联企业和配套企业，培育一批成长性好的企业，推进我市新能源产业高质量发展。
