凝心聚力举旗帜 昂首阔步新征程——2021年全市宣传思想工作综述

来源:湄洲日报 时间：2022-02-22 08:27
| | | |

　　2021年，是具有里程碑意义的一年。隆重庆祝中国共产党成立100周年，开展党史学习教育，“十四五”规划实施，踏上全面建设社会主义现代化国家新征程。

　　一年来，全市宣传思想文化战线自觉承担起“举旗帜、聚民心、育新人、兴文化、展形象”的使命任务，坚持围绕中心、服务大局，唱响主旋律、凝聚正能量，巩固和发展了全市意识形态领域良好态势，各项工作取得新进展新成效，为奋力答好谱写“福建篇章”莆田答卷提供了强大的思想保证和精神力量。

　　高擎思想之旗

　　深化理论武装

　　理论创新每前进一步，理论武装就要跟进一步。一年来，全市宣传思想文化战线始终坚持把准“定星盘”，把学习贯彻习近平新时代中国特色社会主义思想作为首要政治任务，在学懂弄通做实上持续用力，推动党的创新理论落地生根。

　　过去一年，市委坚持系统学、深入学、跟进学，先后组织理论学习中心组集体学习习近平总书记“七一”重要讲话和来闽考察重要讲话精神等29次，带动全市各中心组学习3800多场次。加强学习调度，推动中心组学习巡听旁听工作落实落细，不断提升中心组学习制度化规范化水平。及时跟踪督促各级党委（党组）中心组学习研讨党的十九届六中全会和省第十一次党代会精神等重点学习内容的情况，推动新思想学习抓在经常、融入日常，引领和带动全市广大党员干部用党的创新理论武装头脑、指导实践、推动工作。

　　快板、梆鼓唱、莆仙赞句……极具莆仙特色的方言宣讲，在微信公众号、抖音号、“学习强国”学习平台、视频网站等渠道广泛宣传，大白话阐明大道理，让党的创新理论、路线政策和传统文化从“纸面”走向“云端”，走进千家万户。

　　党的创新理论只有真正被干部群众知晓、明白，才能迸发出强大力量。一年来，我市宣传思想文化战线不断创新方式方法，安排部署各层面的宣讲工作，组建学习贯彻党的十九届六中全会精神市委宣讲团和学习贯彻省第十一次党代会精神市委宣讲团，深入县区（管委会）、市直系统、民主党派开展集中宣讲36场，营造浓厚氛围。按照“多级联动、分众化宣讲”工作目标，分门别类设置宣讲“微专题”，通过“故事会”“微宣讲”等接地气、有活力的宣讲方式，全年宣讲3000多场次，受众20多万人，推动学习宣讲热在基层、热在群众，扩大理论学习覆盖面。值得一提的是，微宣讲专题《生态文明的木兰溪样本》入选福建省“学党史、悟思想”党史故事巡回宣讲目录并在我省各地及新疆昌吉州巡回宣讲。

　　精准发力、润物无声的思想引领，犹如一盏盏精神之灯，照亮了发展新征程，夯实了全市党员干部群众团结奋进的共同思想基础。

　　激荡爱党深情 筑牢初心使命

　　百年征程波澜壮阔，百年初心历久弥坚。党史学习教育开展以来，全市宣传思想文化战线认真贯彻落实习近平总书记重要指示精神和党中央、省委决策部署，持续在学史明理、学史增信、学史崇德、学史力行上下功夫，用功“学党史”，用心“悟思想”，用情“办实事”，用力“开新局”，让伟大建党精神照亮奋进之路。

　　这是一次为民办事的生动实践——

　　将开展“再学习、再调研、再落实”活动作为特色载体有机融入党史学习教育，全市同步梳理形成14692个“为民办实事”项目清单，现已办结14682项，办结率99.93%。拓展“12345+社区邻里中心”“网格+民呼我应”等服务联动机制，全市建立3444个党员先锋岗、责任区，2.6万多名在职党员到社区、小区报到服务，活动总时长达7万多小时。

　　这是一片红色土地的全景展示——

　　挖掘我市第一个中共地方组织——中共莆田党团混合支部旧址（哲理钟楼）这一红色资源，举办“哲理钟声 闽中火种”对外展览，承办“囊萤星火 扬才先锋”校地联动党史学习教育，重温闽中第一个党支部红色故事。打造“白鸽木兰——莆田英烈伉俪薛介民姚明珠尘封半个多世纪的事迹”陈列，巡回开展“讲好党史故事 弘扬东圳精神——追忆原鲁山同志”主题巡回宣讲，开展“小戏唱党史·红色融文明”红色文明小戏巡演。全市56处革命文物列入福建省第一批革命文物目录，策划生成8个主题15条“百年奋进·红耀莆田”建党百年红色旅游精品线路。充分利用莆田“木兰溪治理”“保护好湄洲岛”等特色资源，推出木兰溪治理展示馆等12个省级、13个市级参观学习点，接待党员干部71.2万多人次。

　　这是一场凝心聚力的浓情高歌——

　　全市366支宣讲小分队，深入基层开展宣讲活动4348场次，受众30.7万余人；开展72场次网络宣讲，受众450.1万人次；制作558个网络宣讲微视频、微音频，累计播放量超1918.2万次。先后举办“明理、增信、崇德、力行”“奋斗百年路 建功新时代”两次主题网络知识竞赛活动，累计已有1303万多人次参与，社会各界反响热烈。举行“永远的旗帜——庆祝中国共产党成立100周年”主题系列展览，开展“百课、百歌、百画”致敬辉煌百年主题网络征集展示活动，“党史上的今天”“千媒万屏”联动浏览点击量超6321.54万次。

　　壮大主流舆论 讲好莆田故事

　　市委中心工作布局到哪，全市宣传思想文化战线就及时跟进到哪、主动服务到哪。去年以来，全市宣传思想文化战线聚焦宏伟目标，围绕中心、服务大局，把莆田声音传唱得更响亮，把莆田能量传递得更强劲。

　　重大主题宣传澎湃有力，奏响发展强音。开展党的十九届六中全会、省市党代会等重大主题宣传，开设“学习访谈录”“六中全会精神解读”等相关专栏，策划创作一批融媒体产品，在“两微一端”上广泛推送。开设“奋斗百年路 启航新征程”栏目，共刊发新闻报道1300多条。精心策划“《秋实》——百版照片百次回眸·这五年”大型图片展，受到广泛好评。创新举办党史学习教育系列专题新闻通气会14场次，开展新闻界“百年看百村，奋进新征程”主题联合采访、“再学习、再调研、再落实”联合采访、“一壶兰”网络采风和建党百年“百村百场图片巡展”活动。有条不紊推进政法队伍教育整顿宣传工作，传统媒体刊播相关新闻报道1000余篇，新媒体报道超过2000篇次，其中50多篇新闻报道被中央级媒体采用。

　　去年9月，新冠肺炎疫情突袭莆田，我市积极向各级媒体提供疫情防控的好做法、好经验，先后举行19场专题新闻发布会、19场“新闻会客厅”，中央、省、市各级媒体累计刊播相关报道1.1万余篇（条）次，其中央视《新闻联播》播出相关新闻10条。

　　浓墨重彩强化对外宣传，讲好莆田故事。组织开展“疫情防控宅在家 扫码线上看元宵”和“五一”打卡莆田元宵活动，多渠道推送27篇精彩微信推文。去年4月，启动“这就是莆田”系列微信推文的制作筹备工作，发动600多名摄影工作者供图，征集照片超2.8万张，组织近百名干部、专家学者、新媒体制作人员参与主题策划、史料挖掘等工作。经过8个月的努力，制作图片美、视频短、文字精、信息量大的系列微信推文41篇，最权威、最全面、最完整地呈现了千年莆田、独特莆田的历史文化、特色产业、非遗民俗。系列微信推文陆续发出后，在海内外引发热烈反响，宣传的乘数效应进一步彰显，莆田城市文化形象愈发凝练丰满。

　　外宣内宣联动发力，新闻舆论传播有声有色。一篇篇分量十足、鲜活生动的主题报道，经中央和省、市媒体“发酵”，让海内外听到了一个个有“温度”的莆田故事。成功举办第六届世界妈祖文化论坛及妈祖文化生态保护与传承分论坛等配套活动，被海内外主流媒体报道。在斯洛伐克大使馆举行“世界妈祖 瓷路天下”工艺作品展，17个国家驻华大使、100名驻华文化参赞参加。过去一年，各级主流媒体对我市进行密集式报道，省级以上重点媒体共刊登涉莆稿件近5000篇，中央媒体共刊登涉莆报道1200余篇。

　　坚持守正创新 擦亮文化名片

　　去年5月21日，第30届中国戏剧梅花奖颁奖仪式在江苏南京举行。福建省莆仙戏剧院副院长、国家一级演员黄艳艳凭借现场竞演剧目莆仙戏《踏伞行》的精彩演绎，摘得梅花奖，成为本届我省唯一获该奖项的演员。这是继市艺术学校校长、国家一级演员王少媛于2000年以莆仙戏《叶李娘》夺得莆田首个梅花奖后，时隔21年我市又添一朵“梅花”，展现了“宋元南戏活化石”莆仙戏的独特魅力。

　　悠久深厚、意蕴丰富的莆仙文化，为全方位推进高质量发展超越提供了最充沛的养分、最深沉的力量。过去的一年，我市大力推动文化繁荣发展，积极培育和践行社会主义核心价值观，丰富了群众精神文化生活，进一步提升莆田“软实力”。

　　一年来，庆祝建党百年文艺精品不断涌现。“奋斗百年路 启航新征程”庆祝中国共产党成立100周年文艺晚会、书画展、摄影展，“党啊，我想向您说”主题短视频大赛，“颂歌献给党”歌咏比赛，“百年伟业 匠心传承”莆田市非遗传统工艺精品展，“艺心向党”百名大师工艺美术展等系列活动陆续开展，在全社会大力唱响共产党好、社会主义好、改革开放好、伟大祖国好、各族人民好的高昂旋律。

　　一年来，莆仙特色文艺创作好戏连台。我市参与拍摄的电视连续剧《山海情》在全国6大卫视播出，收视率创出新高，荣获第27届电视节“最佳中国电视剧”等四大奖项。37集电视连续剧《六和堂》（原名《大国匠师》）完成拍摄，获得发行许可证。木雕《桃花源》获第十三届中国民间文艺“山花奖”。中华诗词学会城镇诗词工作委员会在莆田成立。出版发行全省第一部地级市通史《莆田通史》。

　　一年来，文化旅游深度融合多点开花。制定出台《莆田文化产业高质量发展超越行动方案（2021-2025年）》，福建省三福古典家具有限公司和福建腾晖工艺有限公司获第十届“福建省文化企业十强”提名企业。开展“圣地妈祖·美丽莆田”全媒体推介，推出“莆田文旅一卡通”，打造集“吃住行游购娱”于一体的文旅产业服务平台经济。完善提升现有17个“党建+”邻里中心莆阳文化驿站；国家历史文化名城申报工作持续推进；历史文化名城规划和两个历史文化街区的保护规划获批复；绶溪公园成功创建4A级景区。

　　一年来，文明和谐新风吹遍大街小巷。落实《莆田市礼遇帮扶好人实施办法》，持续开展“我推荐、我评议身边好人”活动，全市3人入选中国好人榜，9人入选福建好人榜，1人入选第七届省“孝老爱亲”道德模范，1人当选为全省岗位学雷锋标兵。湄洲岛“两岸一家亲”妈祖义工队被评为全国学雷锋志愿服务“四个100”最佳志愿服务项目。创立全省首创公益组织——莆田市未成年人“爱特”服务中心，打造“15分钟服务圈”。扎实推进新时代文明实践中心建设，建立849个志愿服务驿站，开展活动2863场，参与人次约12万，受惠群众近44.6万人次。一个个荣誉、一串串数字，为文明莆田写下最温暖的注脚。

　　栉风沐雨铸辉煌，百尺竿头再攀登。

　　站在新的历史起点上，全市宣传思想文化战线将踔厉奋发、勇毅前行，不断开创宣传思想工作新局面，为全方位推进高质量发展超越凝聚奋进磅礴力量，以优异成绩迎接党的二十大胜利召开。（记者 陈祖强）
