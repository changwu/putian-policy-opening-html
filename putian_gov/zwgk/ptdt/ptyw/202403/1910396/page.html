市委市政府今年为民办实事项目确定

实施8类工程共60项
来源:湄洲日报 时间：2024-03-27 07:28
| | | |
　　市委、市政府日前发出关于开展2024年为民办实事活动的通知，指出项目进展情况实行月报制度，各主办单位要会同县区（管委会）、相关部门进一步明确目标任务、细化方案措施，压紧压实责任、加强统筹协调，项目化、清单化加快推进，按期保质保量完成任务，把实事办好，让群众满意。
　　一、实施教育惠民工程
　　1.新增义务教育公办学校学位。2024年全市新增义务教育阶段公办学校学位2000个，新增校舍面积20000平方米。
　　2.开展近视防控教室照明改造。按照国家标准改造照明卫生标准不达标的公办中小学校教室1364间。
　　3.实现全市中小学班级多媒体教学设备全覆盖。全市配置595套多媒体设备。
　　4.推进城镇公办幼儿园结构优化与质量提升。通过新建、改扩建、修缮及保教保育设施更新配置等形式，提高15所城镇公办幼儿园办学质量。
　　5.建设北京大学附属中学莆田学校。2024年9月建成投用。
　　6.建设莆田中山中学新校区。2024年建成投用，计划增加学位2700个。
　　7.建设荔城区实验学校。2024年完成主体结构建设，建成后计划增加小学学位2160个、初中学位1500个。
　　二、实施健康惠民工程
　　8.提高人均基本公共卫生服务项目政府补助标准。从2023年每人每年89元提高到2024年每人每年94元。
　　9.提升薄弱乡镇卫生院服务能力。支持17所乡镇卫生院配齐基本设备。
　　10.开展中高级职称医师下基层服务。从县级以上医院抽调50名（其中市属医院医师占30%以上）高年资中级以上职称医师进入全市50家社区卫生服务中心、乡镇卫生院进行医疗帮扶。
　　11.开展适龄女性人乳头瘤病毒（HPV）疫苗免费接种。为具有我市学籍或户籍的13—14周岁适龄女性继续开展自愿免费国产二价HPV疫苗接种。完成2023年项目对象的第二剂次疫苗接种，对2024年项目对象进行第一剂次疫苗接种。
　　12.建设省级区域医疗中心。建设莆田学院附属医院省级区域医疗中心，新建急重症诊疗中心大楼一栋。2024年实现主体封顶。
　　13.建设荔城区中医院新院区。开工建设门诊综合楼、急诊医技病房楼、连廊及配套工程。
　　三、实施生活惠民工程
　　14.续建城乡供水一体化项目。开工建设农村水厂2处，推进莆田市第二水厂迁建主体工程建设；实施荔城区北高镇至秀屿区埭头镇供水主管网联通工程；对荔城区黄石镇（一期）及涵江区白塘镇、国欢镇、梧塘镇、三江口镇实施一户一表改造，铺设供水管网200公里。
　　15.新改建莆阳福道。新建和改造提升福道24.5公里。
　　16.改造老旧小区。开工改造6000户。
　　17.创建闽台乡建乡创合作样板集镇。在仙游县园庄镇、北岸山亭镇打造闽台乡建乡创合作样板集镇。
　　18.创建省级乡村振兴示范村。创建省级乡村振兴示范村28个。
　　19.治理“餐桌污染”建设“食品放心工程”。培育绿色有机农产品10个，积极组织申报福建省农产品区域公用品牌、福建名牌农产品和全国名特优新农产品5个，创建省级“互联网+明厨亮灶”示范单位10家以上。持续推进食品安全“一品一码”信息追溯工作。整治中小学配餐及食堂食品安全问题。
　　20.新改建工会驿站。在全市新建或改建提升25个工会驿站。 
　　21.改造提升电力“双满意”项目。完成10个老旧小区电力设施、10座高层住宅（大中型小区）双电源改造，推进10个地下易涝配电站房整治工作。新建、改造205个农村配电网台区。推动全市新建600个公共及居民个人充电桩。持续做好分布式光伏并网和结算服务。
　　22.新建5G基站。新建5G基站1130个以上。
　　23.保障基层网格化运营。继续对全市976个村（社区）基础网格站建设和运营提供必要经费保障。
　　24.建设口袋公园。建成口袋公园10个。
　　25.新改建一批农贸市场。新改建10个农贸市场。
　　26.建设村级寄递物流综合服务站。建设100个村级寄递物流综合服务站。
　　四、实施道路畅通提升工程
　　27.建设“四好农村路”。建设与改造农村公路30公里、改造危桥6座。
　　28.推进高速公路配套连接工程建设。建成莆炎高速白沙服务区，加快莆炎高速涵江江口互通及接线工程项目建设。
　　29.续建莆田学院附属医院立体停车场。建设急重症诊疗中心大楼地下二层停车场，规划新增停车泊位192个；在门诊西侧停车场建设地下立体停车场，建设三层机械停车位，规划新增停车泊位476个。
　　30.建设玉湖新城荔浦立体停车场。新增停车泊位100个。
　　31.建设泗华郊野公园立体停车场。停车泊位200个。
　　32.建设凤凰福道植物园立体停车场。停车泊位234个。
　　五、实施生态环境提升工程
　　33.开展水土流失综合治理及木兰溪支流生态治理。开展水土流失综合治理2.7万亩，综合治理河流长度6.8公里。开展城厢区延寿溪支流院里溪、涵江区萩芦溪支流萩芦段河道治理工程。
　　34.新改建城市污水管网。新建、改造城镇生活污水管网60公里。
　　35.提升村庄生活污水治理。推进全市55个村庄生活污水治理设施开工建设。
　　36.综合治理海漂垃圾。加强海上环卫队伍建设。
　　37.持续推进木兰溪防洪工程建设。持续推进木兰溪防洪工程盖尾段B1标段建设，实施木兰溪港利水闸拆除重建工程。新建堤防1.96公里，开工建设水闸1座、穿堤箱涵及穿堤管4处。
　　六、实施社会保障提升工程
　　38.开展多渠道保障就业行动。2024年新增城镇就业1.8万人、城镇失业人员再就业3500人、就业困难人员就业350人。统筹实施高校毕业生基层服务项目，招募“三支一扶”人员70名。资助一批大中专毕业生优秀创业项目。
　　39.开展职业技能提升行动。实施2024年度万人职业技能培训计划。开展各类补贴性职业技能培训1万人次。
　　40.开展高素质农民培训。培训农民8500人次。
　　41.开展养老护理员培训。培训养老护理员不少于1000人次。
　　42.提高城乡居民基本养老保险基础养老金标准。2024年1月1日起，全市各县区（管委会）城乡居民基本养老保险基础养老金标准每人每月提高10元，全市统一标准同步实施。调整后的基础养老金市定最低标准为每人每月175元（比省定最低标准高15元）。
　　43.落实残疾人“两项补贴”政策。困难残疾人生活补贴标准从每人每月110元提高到117元；困难一级重度残疾人护理补贴标准从每人每月135元提高到144元；困难二级重度残疾人护理补贴标准从每人每月110元提高到117元。
　　44.提高孤儿基本生活最低养育标准。集中养育孤儿和社会散居孤儿基本生活最低养育标准从每人每月1800元和1400元提高到2100元和1700元，从2023年7月1日起补发。在此基础上，从2024年7月1日起，我市孤儿基本生活最低养育标准按照省级标准执行。事实无人抚养儿童基本生活补贴标准参照执行。
　　45.建设长者食堂及嵌入式养老服务机构。建设示范性长者食堂50处。建设嵌入式养老服务机构5处。
　　46.开展“平安通”服务试点工程及特殊困难或高龄老年人适老化改造。
　　47.打造无障碍设施样板区。
　　七、实施文化体育提升工程
　　48.建设全民健身场地设施。建设多功能运动场4个，社区智慧“运动角”3个。
　　49.扩大向社会开放学校体育场地范围。建设“莆田校园健身智慧云平台”，以预约方式有序向社会开放。
　　50.错时延时向社会开放公共文化场馆。
　　51.整治和改善提升传统村落。整治提升游洋镇龙山村传统村落。
　　52.举办全民篮球联赛（村BA）。
　　53.启动兴化府历史文化街区二期修缮项目。2024年进一步完善街区消防及公共服务配套设施，更新街区内城市水、电、雨、污管网，推进传统街区立面改造；开工建设街区地下停车场。
　　八、实施安全防范提升工程
　　54.提升公共安全应急保障水平。2024年组织7场防灾减灾演练，提档升级7个基层应急避灾点（地震避难场所），打造7个基层应急物资储备站，组建7个基层应急指挥服务站，建设7个安全文化宣教基地。推动全市学校防灾避险演练100%覆盖。
　　55.完善AED应急救护体系。在全市重点公共场所和学校、社区配置AED（自动体外除颤器）70台；开展应急救护普及培训200场、20000人次以上；培训救护员7000人。
　　56.整治道路交通安全隐患。完成全市42处道路交通安全隐患整治。
　　57.打造交通安全教育实践基地。在荔城区、涵江区各打造1处。
　　58.完善中小学校园周边及内部道路交通安全设施。提升完善全市209所中小学校园周边及内部道路交通安全设施。
　　59.建设农村地区微型消防站。在消防救援队伍辖区面积之外且未建立乡镇（街道）专职消防队的行政村（260个）建立有人员、有器材、有制度的微型消防站（志愿消防队）。
　　60.新建和维护治安视频探头。
