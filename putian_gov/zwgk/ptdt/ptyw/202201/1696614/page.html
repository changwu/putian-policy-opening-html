在市政协八届一次会议闭幕会上沈萌芽同志的讲话

来源:湄洲日报 时间：2022-01-09 07:55
| | | |

各位委员、同志们：

　　市政协八届一次会议在市委的坚强领导下，在全体委员和与会同志的共同努力下，圆满完成了各项议程，即将胜利闭幕。

　　这次大会是在全市上下全面贯彻落实习近平新时代中国特色社会主义思想和十九届六中全会精神、省第十一次党代会和市第八次党代会精神，昂首阔步开启新征程、谱写新篇章的新形势下召开的。这次大会得到了市委的高度重视，得到了市人大、市政府和市级老领导、市直部门、社会各界的大力支持。付朝阳书记、林旭阳市长等市领导，出席开闭幕会、听取大会发言、深入界别小组，与委员们共话发展、共商大计、共谋良策，充分肯定了过去五年的市政协工作，高度评价了委员们在全市经济社会发展中的积极作用，给予我们极大的鼓舞和鞭策。特别是刚才付朝阳书记代表市委发表的重要讲话，充分体现了市委对政协工作的殷切期望，为全市政协工作指明了方向，我们一定要认真学习、深刻领会，全面贯彻落实到政协各项工作中去。在此，让我们以热烈的掌声，对各位领导表示衷心的感谢，并致以崇高的敬意！

　　这次大会回顾过去、总结经验，立足当下、放眼长远，全面部署今后五年工作，顺利完成了各项选举任务。会议开得圆满成功，是一次高举旗帜、对标对表的大会，是一次发扬民主、凝心聚力的大会，是一次承前启后、团结鼓劲的大会，大会充分彰显了专门协商机构的独特优势，生动展现了社会主义民主政治的盎然生机和蓬勃活力。会议期间，各位委员积极履职，列席会议的同志大力支持，新闻工作者和全体工作人员为大会圆满成功付出了辛劳、作出了贡献。在此，我谨代表市政协常委会，向大家表示衷心的感谢！

　　大会选举产生了八届市政协主席、副主席、秘书长和常务委员，这充分体现了组织的关心厚爱和各位委员的信任支持。在此，我谨代表市政协班子成员和各位常务委员向大家表示衷心的感谢！向新当选的八届市政协副主席、秘书长、常务委员，表示热烈的祝贺！

　　过去五年，在林庆生主席、周青松主席的带领下，七届市政协认真贯彻中央和省委、市委关于加强和改进人民政协工作的部署要求，始终坚持团结和民主两大主题，紧紧围绕全市工作大局，认真履行政治协商、民主监督、参政议政职能，为推动全市经济社会发展作出了积极贡献，也为我们新一届市政协工作积累了宝贵经验、奠定了扎实基础。这次换届，由于提名年龄等原因，林素琼同志不再担任市政协副主席、陈剑华同志不再担任市政协秘书长，市七届政协常务委员、委员中也有一部分同志不再连任。这些同志在在职期间，认真履职、勤勉工作，为莆田经济社会发展作出了积极贡献，他们的政治品德、工作作风、工作业绩，留在了莆田政协事业的光荣榜上，刻在了政协事业的历史之中。让我们用热烈的掌声，向他们致以真挚的谢意和崇高的敬意！

　　这次大会选举我为市政协主席，我深知每一张选票都凝聚着委员们的信任和托付，饱含着委员们的厚望和期盼。此时此刻，我感慨万千，千言万语难以表达，莆田是我的第二故乡，在这里我工作、生活了33年，和在座的很多同志一样，参与、见证了莆田的变化发展。33年来，我深切地感受到莆阳大地山川秀美、人杰地灵；深切地感受到莆仙历史文化的厚重和璀璨；深切地感受到兴化儿女朴实善良、勤劳智慧；深切地感受到莆田干部心齐劲足、务实进取；深切地感受到市四套领导班子带领广大干部群众，一任接着一任干，兴化大地发生了翻天覆地的变化。莆田的每一点进步、每一次变化，都感动和激励着我尽心尽力为莆田的发展、为莆田的美好去认真履职、去努力工作。当下的莆田，海晏河清、欣欣向荣，展现出强劲的发展势头，我们对莆田的未来充满信心、充满期望。

　　今天接过市政协主席的接力棒，我耳旁响起的是“一命而偻，再命而伛，三命而俯”的告诫，眼前看到的是市第八次党代会擘画的未来莆田的美好蓝图，心中想到的是人民政协为人民的责任和担当。风好正是扬帆时，不待扬鞭自奋蹄。八届市政协任期的五年，正处于我们与全国人民一道向第二个百年奋斗目标进军的重要时期，今年又将喜迎党的二十大胜利召开，我们也将迎来莆田市政协成立40周年。前不久召开的市委八届二次全会暨市委经济工作会议，为今年工作指明了方向，提供了遵循，市委提出“俯下身子抓产业、一心一意谋发展”。我将在市委的坚强领导下，与市政协班子成员一道，不驰于空想、不骛于虚声，紧紧依靠全体委员，发挥集体智慧，坚持“致广大而尽精微”，登高望远、胸怀大局，落细落实、积微成著，勤勉工作、忠实履职，俯下身子做好新一届政协各项工作，不辜负市委的重托、不辜负组织的信任、不辜负大家的期望。努力在新时代新征程中实现政协新作为、展示政协新气象，奋力书写新一届政协高质量的履职答卷。

　　各位委员、同志们：

　　我们要以新思想领航定向。“船的力量在帆上，人的力量在思想”。习近平新时代中国特色社会主义思想，是引领中华民族伟大复兴的旗帜，是我们奋进新征程的灯塔。人民政协是政治组织，我们要旗帜鲜明讲政治，坚定不移用习近平新时代中国特色社会主义思想武装头脑指导实践，深入学习贯彻习近平总书记关于加强和改进人民政协工作的重要思想，深学细照笃行，牢记“两个确立”、坚决做到“两个维护”。要坚持党对政协工作的全面领导，强化党建引领从党的百年奋斗中吸取力量，弘扬伟大的建党精神，不断提高政治判断力、政治领悟力、政治执行力，做到观察问题站稳政治立场、谋划工作把握政治大局、推动履职追求政治效果，始终与市委同心同德、同频共振、同向奋进，确保我市政协事业始终沿着正确方向坚毅前行。

　　我们要以新发展凝心聚力。“人心是最大的政治，共识是奋进的动力”。实现新目标、续写新辉煌，需要全市各界人士的共同努力。我们要聚焦市委中心工作，充分发挥专门机构协商作用，充分发挥政协同心同向的政治优势、凝聚共识的团结优势、协调关系的功能优势、联系广泛的渠道优势，组织开展好各项协商议政活动，多建睿智之言、多献务实之策；积极开展团结联谊工作，不忘老朋友、广交新朋友，多交挚友、诤友，扩大“朋友圈”，画好“同心圆”，为美丽莆田建设汇集正能量、汇聚新合力。

　　我们要以新担当服务人民。“人民政协为人民”。政协委员来自人民，依靠人民，为了人民。我们要始终把人民放在心中最高位置，“民之所忧，我必念之；民之所盼，我必行之”，践行以人民为中心的发展思想，把实现人民对美好生活的向往作为政协履职的出发点和落脚点，不管是在民生期待中，还是民意诉求里，都能听到委员的声音、看到政协的身影，架好党委政府和群众的“连心桥”，让人民群众的获得感成色更足、幸福感更可持续、安全感更有保障。围绕人民群众关心关注的重点热点难点问题，深入田间地头、工厂车间、农村农户，倾听民意、收集民声，政为民所议、言为民所建、计为民所献。坚持“有事好商量，众人的事情由众人商量”， 做到协商为民、协商于民、协商惠民，延伸协商链条，培育协商文化，让协商更接地气、更有灵气、更聚人气，把关乎人民美好生活的大事小事协商好，让政协履职更有民生温度、更具民生厚度。

　　我们要以新作为树好形象。“懂政协、会协商、善议政，守纪律、讲规矩、重品行”，这是习近平总书记对政协委员提出的要求。委员是政协工作的主体，是各领域、各行业的代表人士，社会知名度、关注度比较高，一言一行都很有影响力和示范性，成为一名政协委员，既是荣誉、更是责任。我们要倍加珍惜时代际遇、倍加珍视委员平台，以自觉的政治担当、昂扬的精神风貌、务实的工作作风，不断提高政治把握能力、调查研究能力、联系群众能力、合作共事能力。要涵养想干事的自觉，淬炼能干事的本领，提高做成事的实效；坚持守正创新，以改革的思维、创新的理念、开放的视野，让各项工作始终能跟上时代步伐，进一步推动政协工作活起来、实起来。要加强市政协机关建设，坚持宽严相济、严管厚爱，进一步改进工作作风，强化委员服务管理，全面提升工作质量，着力建设“书香政协”、打造模范机关，为政协工作提质增效、创新发展提供有力保证。

　　各位委员、同志们：

　　新的蓝图鼓舞人心，新的使命催人奋进，新的征程任重道远。让我们更加紧密地团结在以习近平同志为核心的党中央周围，在中共莆田市委的坚强领导下，踔厉奋发、笃行不怠，为奋力答好谱写全面建设社会主义现代化国家福建篇章的莆田答卷，贡献政协智慧和力量！以优异成绩迎接党的二十大胜利召开！让我们一起加油，向未来！

　　虎年新春即将到来，我们真诚地向各位领导、各位委员、各位来宾和全体工作人员拜个早年，祝大家在新的一年里，身体健康，工作顺利，万事胜意！
