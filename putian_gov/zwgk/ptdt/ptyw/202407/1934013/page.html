我市全力以赴防抗台风“格美”

来源:湄洲日报 时间：2024-07-26 08:15
| | | |

　　7月25日19时50分前后，今年第3号台风“格美”在我市秀屿区沿海登陆。

　　面对这场台风，我市深入学习贯彻习近平总书记关于防汛救灾工作的重要指示精神，按照省委省政府工作部署，启动防台风I级应急响应和防暴雨Ⅱ级应急响应，精准部署、科学调度，上下同心、担当作为，坚持“人民至上、生命至上”，全面加强灾害防范应对，全力保障人民群众生命财产安全。

　　精准调度 一线显担当

　　台风“格美”7月20日生成后，逐渐发展为今年首个超强台风，并于7月24日14时左右达到强度峰值（17级，58米/秒）。

　　面对来势汹汹的台风“格美”，我市坚持预防在先、化解在早，以“时时放心不下”的责任感，对以往路径相似的“杜苏芮”“苏迪罗”台风防抗工作进行复盘，按最极端情况做好防范，抓实抓细各项防御措施。针对暴露出的薄弱环节精准施策，消除隐患源。第一时间激活指挥体系，各级防指牵头抓总、各成员单位各司其职，市、县、乡和网格单元随时连线、调度和抽查。依托“全市一张图”，加密会商研判风情、水情、雨情、浪潮情，及时跟进调整管理措施，发出加强重点区域防御工作提示函3期。

　　“全市上下齐心协力，共同守护百姓平安。”市主要领导通过大数据调度指挥平台，远程察看渔港、水库、易涝点等部位防御措施落实情况，在线随机调度检查。

　　我市还落实临灾预警“叫应”和跟踪反馈等机制，及时把最新动态信息预警到乡、到村、到户、到人，给基层落实工作争取主动。建立“实地督导+电话抽查+12345平台涉防汛诉求联动督办”机制，对发现问题督促即知即改，确保责任到位、工作到位。

　　一个党员就是一面旗帜，一个支部就是一座堡垒。市委组织部发出通知，动员全市基层党组织和广大党员干部在防汛救灾抢险工作一线争优争先争效，让党旗在一线高高飘扬。

　　此次台风影响期，正是早稻收获的关键期。我市农业农村部门组织党员干部奔赴田间地头，调度收割机，发挥专业合作社的力量，帮助农户加紧收割水稻，并运往烘干中心进行烘干，确保颗粒归仓，保障粮食安全。

　　7月25日18时许，在荔城区新度镇郑坂社区乌桥边值班值守的党员干部发现，上涨的水位淹过了日常通行的桥面。镇、社区干部立即行动，设置围挡，夜间安排党员在附近值守，确保第一时间处置险情。

　　行胜于言，冲锋在前。挂钩领导、各级干部下沉到位，累计下沉11810余人次。抽调200名市直机关党员干部组建应急预备小分队，强化机动力量。

　　紧绷起来 织密安全网

　　“阿婆，跟我们走，一起到村部去。”7月24日晚，城厢区常太镇展开了一场转移安置行动，党员干部、网格员、志愿者入户，转移高陡边坡户特别是孤寡老人。截至昨日，该镇高陡边坡涉及的52户91人已全部转移。

　　为坚决果断做好转移避险工作，我市严格落实“三个提前”要求（即提前下沉干部、提前转移老弱妇幼和行动不便人员、提前转移危险区域全部人员），分领域分区域逐船、逐点、逐人建档，将转移责任匹配到人、方案匹配到户，做到应转尽转早转、不漏一人。台风登陆前，全市应转尽转人员12612名全部转移到位（其中，海上渔船、乡镇船舶船员及养殖渔排上人员11149名，陆上危险区域人员1463名）。155艘海事船舶、636艘渔船、11596艘乡镇船舶全部在港避风、9997名船员全部撤离上岸，1152名沿海养殖渔排人员全部撤离上岸。对市内跨县区停泊的24艘渔船、50艘乡镇船舶和在外地市停泊的4艘渔船、19艘乡镇船舶均落实有效监管。

　　在秀屿区平海一级渔港，渔船均已回港避风。船尾安有北斗定位器，以数字技术推广应用，确保渔船回港人员撤离。

　　利用台风来临前的“窗口期”，我市结合“党建引领、夯基惠民”工程，发挥网格长、单元长作用，全面排查重点部位、薄弱环节，更新台账、专人跟踪、补齐短板。全市水库216座、山塘200座、江海堤防179条、水闸228座等重点部位全部纳入管控，“三大责任人”（行政责任人、技术责任人、巡查责任人）到岗履职，并根据实际情况实时调度。排查出施工围堰8处、山洪灾害点19处、地灾点30处、高陡边坡763处、危旧房377处、危病桥10座等风险点位，向社会公布116处易堵易涝点，逐一落实预案措施。农村在建农房1087栋全部停工，并做好塔吊等重要部位检查加固。70个景区景点全部关闭，湄洲岛、南日岛上的滞留游客得到妥善安置。324个在建工地全部停止施工，组织转移工棚人员3469名。

　　在强化应急准备上，我市同样下足功夫。全面点验物资装备，备好冲锋舟、橡皮艇、抽水泵，储备编织袋、救生衣、被类、帐篷、卫星电话等。落实基层个人防护“五小件”14643套，要求基层一线人员执行救援任务时，必须穿戴整齐、确保安全。对1152个现有避灾点逐一明确权属、指定专人管理。加强军地救援队伍联动，组建电力、交通、城管等防汛抢险队伍145支4218人，消防救援队伍、部队官兵提前预置、随时出动。

　　7月24日19时，市防指决定提升防台风应急响应为Ⅰ级。当晚，市防指发布防御第3号台风“格美”动员令，决定从7月25日7时起至防台风Ⅰ级应急响应结束前，在全市实行“三停一休”，即停工（业）、停产、停课、休市，确保人民群众生命财产安全。

　　为进一步提高公众防范意识，我市加强宣传科学引导，除了在报、台、网、端、微全矩阵加大宣传力度外，还通过网络电视开机广告、电视底栏游字、电台广播、“村村通”大喇叭、LED显示屏、流动宣传车、公益短信等多种载体滚动台风预警信息、防汛提醒和安全度汛知识，动员广大市民共同做好防范台风工作。

　　预防在先 做足提前量

　　7月23日，涵江区住建局组织人员深入各路段，提前对城区雨污水管道、雨水蓖进行清淤，对存在安全隐患的行道树进行剪枝，筑牢防汛“安全网”。

　　做足提前量，打好主动战。针对城区易涝点问题，我市相关部门在雨前对道路易积水路段周边的排水通道、雨水口和检查井再检查、再清疏，确保排水通畅。对67处可能产生的易涝点、15处可能产生严重积涝的点，提前预置抢险人员，提前打开窨井盖，组织机动抽水泵进行强排，及时降低积涝水位。设置警示标志，禁止车辆和人员通行，减少次生灾害。

　　木兰溪流域有96座水库，总库容5.57亿立方米。围绕保障木兰溪防洪安全，我市通过科学调度流域水库拦洪削峰，尽量降低木兰溪洪峰水位和洪峰流量。组建6支堤坝巡查队伍，落实河湖长制，加强木兰溪全线值守巡查，发现隐患及时处置。

　　在防范南北洋受淹方面，加强东圳水库拦洪调度，利用低潮位时段错峰排洪。依托东圳干渠、外度引水渠道拦山洪水、高水高排，通过泄洪闸引排至木兰溪、延寿溪，避免山洪直接冲击南北洋平原。加强南北洋沿线21座排洪闸调度，利用外江低潮位能排则排、应排尽排。同时，提前腾空南北洋河道库容。

　　为防范萩芦溪下游江口段河道漫堤，我市对该段河道的防浪墙加高60厘米，将该段防洪标准由10年一遇提高至20年一遇。科学调度萩芦溪流域28座水库，总库容8959万立方米，发挥拦洪削峰作用，降低洪峰水位，有效防范萩芦溪流域受淹。

　　在防范地质灾害方面，我市采取“人防+技防”相结合，在全市地质灾害点安装探头32个，在高陡边坡安装探头44个，已接入“一张图”平台59个。我市还加强山区公路、桥梁、涵洞等隐患排查整治，加强户外广告牌加固，强化塔吊现场检查，防止高空坠物。

　　在风情、雨情预警精准度方面，我市研发智能网格算法预报产品，时空分辨率提高到1小时和2.5公里，提升预报的精准度。强化省市县协同和部门联动，应急期间加密会商频次，提高预报针对性和有效性，有力支撑了台风防抗工作科学有序开展。

　　昨晚，台风登陆后，减弱为强热带风暴级。我市广大党员干部继续在岗在位，密切关注台风动向，严防台风登陆后可能带来的强降雨、地灾、山洪等灾害，防止渔船、海上养殖人员和转移安置人员回流，全力以赴做好灾后抢险恢复各项工作，努力将台风造成的影响降到最低，力争在应对台风的大考中交出一份令市民满意的答卷。
