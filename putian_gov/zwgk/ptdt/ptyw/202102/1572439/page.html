莆田市人民检察院工作报告

2021年1月14日在莆田市第七届人民代表大会第五次会议上
来源:湄洲日报 时间：2021-02-02 10:10
| | | |

莆田市人民检察院检察长 许志鹏

各位代表：

　　现在，我代表莆田市人民检察院，向大会报告工作，请予审议，并请各位政协委员和其他列席同志提出宝贵意见。

　　2020年，是全面建成小康社会和“十三五”规划的收官之年。一年来，全市检察机关在市委、省检察院正确领导和市人大及其常委会的有力监督下，在市政府、市政协及社会各界的关心支持下，坚持以习近平新时代中国特色社会主义思想为指导，认真贯彻落实党的十九大和十九届二中、三中、四中、五中全会精神，紧扣“双轮”驱动战略，秉持“务实稳进、精业提质”工作思路，讲政治、顾大局、谋发展、重自强，全面履行法律监督职责，各项检察工作稳进、落实、提升。全年共办理各类案件10420件，其中审查逮捕案件1873件，审查起诉案件3592件，办理刑事、民事、行政诉讼监督案件4825件次，办理公益诉讼案件130件。

　　一、厚植大局思维，全力保障社会安定稳定

　　坚持平安导向，统筹做好常态化疫情防控和各项检察工作，在保稳定促发展上担使命，投身更高水平的平安莆田建设。

　　坚决服务疫情防控大局。在法治轨道上推进疫情防控工作。出台全省检察机关首个防控方案，建立涉疫案件提前介入、上报一级审核等办案机制，制发办案指引，依法从快严惩涉疫物资诈骗、妨害公务等犯罪52人，办理涉口罩等防疫物资监管、野生动物保护等领域公益诉讼5件。仙游县检察院在疫情期间提起一起非法狩猎野生麻雀刑事附带民事公益诉讼，被告人被判令赔偿并登报道歉。用好“云端”等现代技术载体，切实做到防控期间检察服务、司法办案不停滞。200多名党员干部积极投身战“疫”，28名干警进驻集中医学观察点、厦门机场等地参与一线防控，市检察院原第四检察部主任、四级高级检察官李望厦同志牺牲在疫情防控前沿，用法与情书写检察抗疫篇章。

　　精准打击各类刑事犯罪。坚决维护国家政治安全和社会秩序，落实“捕诉一体”办案机制，批捕各类刑事犯罪2394人，起诉4634人。严惩危害群众生命健康和财产安全犯罪，起诉故意杀人、绑架等严重暴力犯罪90人，起诉“两抢一盗”犯罪1096人。加大惩治新型电信网络诈骗犯罪力度，起诉207人；参与禁毒专项整治，起诉毒品犯罪119人。坚持少捕慎诉理念，对涉嫌犯罪但无逮捕必要的不批捕178人，对犯罪情节轻微、依法可不判处刑罚的不起诉546人，对不需要继续羁押的建议取保候审51人。

　　攻坚深化扫黑除恶收官。坚持“是黑恶犯罪一个不放过，不是黑恶犯罪一个不凑数”，批捕涉黑涉恶犯罪58人，起诉185人，对侦查机关移送的涉黑涉恶案件，依法排除认定11件，依法追加认定9件，追捕、追诉13人，检察环节清结率100%。坚持“打伞破网”“打财断血”一体推进，发现并移送线索12条，起诉“保护伞”犯罪7人；督促将2000多万元涉案财产上缴国库，一件财产执行检察建议获评全国精品案件，三件案件获评全省优秀诉讼监督案例。坚持边打边建，制发规范重点行业领域整治检察建议32件，回复率94%，高质效完成收官年“六清”任务。

　　依职尽责推进反腐斗争。坚持在保护公民权利、维护司法公正和反腐败斗争新格局中发挥检察机关应有作用。完善与监委的衔接配合机制，受理监委移送职务犯罪25件28人，审查后决定逮捕7件8人，退回补充调查5件7人，已起诉19件22人。依法履行检察机关对司法工作人员相关职务犯罪的侦查权，立案侦查司法人员相关职务犯罪4件4人，其中立案侦查了一起司法人员充当恶势力“保护伞”徇私枉法案件。

　　二、聚焦双轮驱动，助力优化法治营商环境

　　坚持“法治是最好的营商环境”，紧紧围绕“突出开放招商、强化项目带动”任务，持续提升检察服务发展的供给能力。

　　尽心落实检察护企政策。突出服务保障市场主体健康发展主线，持续开展服务民营经济“六个一”专项行动，出台服务中小微企业“检十条”，发布检察机关服务保障民营企业首批十个案例。加快五大特色民营产业专题调研成果转化，稳步推进服务民营企业法治宣传基地建设。畅通检企联络渠道，设立5家涉台检察联络室，依法保障台胞台企合法权益；与市工商联建立八项沟通联席机制，联办“护航民企发展”检察开放日活动，打造窗口建在工商联、联络设在商会、服务面向企业的检察服务阵地。

　　平等办案传递法治温度。树立谦抑审慎、主动服务理念，依法严惩侵害企业合法权益刑事犯罪339人，开展涉企刑事诉讼“挂案”专项清理，已监督撤销“挂案”5件。重视产权司法保护，依法打击制假售假等侵犯知识产权案件155人。审慎办理企业家涉罪案件，坚决做到慎捕慎诉慎押，妥善办理健康产业园部分企业虚开增值税发票案件，对11名涉企人员作不捕或不诉处理。依法稳妥办理社会关注的建筑工程领域蔡某某等人串通投标系列案，追缴违法所得6217万元，并对涉案不诉企业专题回访，从法治层面引导行业加强自律，营造公平诚信的市场秩序。

　　多措并举规范市场秩序。防范金融风险，落实最高检“三号检察建议”，与银监部门建立打击防范金融犯罪联动机制，批捕非法吸收公众存款、集资诈骗等金融领域犯罪31人，起诉28人，涉案金额5.8亿余元。开展“套路贷”、反洗钱等违法犯罪专项治理，起诉“套路贷”犯罪54人，办理了全市首例洗钱罪案件，涉案金额900万元。常态开展送法入企、党团共建活动36场，邀请非公经济人士等走进检察机关，面对面了解司法需求，合力破解发展难题，增强市场主体发展信心。

　　三、立足四大检察，聚力维护社会公平正义

　　秉持客观公正立场，在监督中办案、在办案中监督，努力让人民群众在每一个司法案件中感受到公平正义。

　　持续做优刑事检察。加强立案和侦查活动监督，依法监督公安机关立案23件、撤案39件，纠正漏捕41人，追诉漏犯70人。加强审判活动监督，对认为确有错误的裁判提出抗诉10件，法院已改判、发回重审3件。对违法取证、适用强制措施不当等提出书面纠正意见28件。提出量刑建议3571人，法院采纳3368人，采纳率94.3%。加强刑事执行和监管活动监督，办理羁押必要性审查55人，办理减刑、假释、暂予监外执行案件1067件，对刑事执行违法活动提出纠正意见55件。深化“派驻+巡回”检察改革，对莆田监狱、第二看守所开展巡回检察，维护高墙内公平正义。

　　持续做强民事检察。综合运用抗诉、检察建议等监督方式，办理民事检察案件331件，同比上升14.9%。提请、提出抗诉29件，同比上升81.3%；提出再审检察建议31件，法院已裁定再审（含积案）45件，同比上升200%。办理审判违法和执行监督案件127件，发出检察建议46件，法院已采纳（含积案）48件；专项开展民事执行案件评查等工作，移送拒不执行判决、裁定案件线索10件，公安机关已立案10件，促进执行活动规范。大力整治虚假诉讼，对虚假诉讼案件提请抗诉12件，发出再审检察建议23件，法院已裁定再审15件，进一步维护司法权威。

　　持续做实行政检察。发挥行政检察“一手托两家”作用，围绕维护司法公正、促进依法行政的共同法治目标，办理行政检察案件94件，其中办理生效裁判结果监督27件，行政执行监督9件。推进诉讼活动中行政处罚法律监督试点工作，向行政机关发出检察建议58件，督促行政机关对60人、2家单位进行行政处罚。办理行政争议实质性化解案件17件，居全省前列。市检察院发出一份政府信息公开领域执行监督检察建议，推动行政机关依法公开拆迁安置信息。

　　持续做好公益诉讼。牢记检察官作为公共利益代表的神圣职责。贯彻落实市委深改委《关于支持检察机关依法开展公益诉讼工作意见》，善用检察建议、诉前圆桌会议等形式助力行政机关依法履职，提出诉前检察建议125件，推动行政机关整改103件；提起公益诉讼5件，诉讼请求得到法院全部支持。打造“一院一品”工程，开展木兰溪全流域保护、湄洲岛及周边海域非法采砂、黑臭水体整治等专项监督，督促清理被污染和非法占用的河道5.5公里、清除处理各类违法堆放垃圾9.5吨，督促修复被毁耕地林地156亩，督促关停非法采砂点7处。市人大常委会专题视察并听取审议公益诉讼工作报告，给予有力监督支持。

　　四、筑牢人民立场，倾力打造优质检察产品

　　坚持人民至上理念，以求极致精神办好群众身边的“小案”，不断增强群众的获得感、幸福感、安全感。

　　倾情回应民生关切。改造建成“一站式”12309检察服务中心。不折不扣做到“群众来信件件有回复”，2505件群众来信能够办理的均做到“7日内程序性回复，3个月内办理过程或结果答复”。落实领导接访常态化机制，检察长带头接访76场，省市区三级检察长联合包案化解一件跨时44年的历史遗留信访积案，既解“法结”，更化“心结”。深化涉法涉诉信访改革，推进律师代理申诉制度，开展检察公开听证26场，推动群众诉求在法治轨道上解决。关注农民工等弱势群体权益保护，起诉拒不支付劳动报酬罪4人，帮助追回欠薪1269万元；向因案致贫的刑事被害人或近亲属发放司法救助金83.8万元。积极协调挂钩贫困村建立村卫生所、茶籽油种植项目等，助力精准脱贫。

　　倾力保障舌尖安全。落实“四个最严”要求，批捕危害食品药品安全犯罪18人，起诉48人，依法办理“4·23”非法贩运、屠宰生猪系列案。积极用好“两法衔接”机制，督促将4起危害食药安全行为线索移送公安机关，督促主管部门对37名食药犯罪前科人员列入监管“黑名单”。市检察院对一起销售有毒、有害食品案件提起民事公益诉讼，通过惩罚性赔偿增加违法者成本。荔城区、涵江区检察院开展城市二次供水卫生安全专项监督，促进有关部门强化监管，确保生活饮用水安全。

　　倾心呵护祖国未来。一以贯之落实最高检“一号检察建议”，不断健全未成年人司法保护体系。起诉性侵、拐卖、虐待等侵害未成年人犯罪230人，同比上升32.2%。深化教育、感化、挽救工作，对未成年犯罪嫌疑人不批捕33人，不起诉23人。强化未成年被害人综合救助，与市妇联建立儿童权益保护联动机制，前移保护关口。创新开展临界预防、亲职教育，落实帮教措施50人。涵江区检察院实行涉罪未成年人帮教成果审查制度，城厢区检察院建成未成年被害人“一站式”取证办案场所，市检察院在市第二实验小学筹划建立莆田市首个未成年人法治教育基地。两级院检察长全部兼任法治副校长，开展法治进校园活动55场，传播法治种子，促进少年强、奉法者强、法治国家强。

　　五、厉行法治精神，奋力推进市域现代治理

　　主动融入法治莆田建设，积极发挥检察职能，努力以高效、优质的司法运行机制促进治理现代化。

　　更实举措提升刑事诉讼质效。深化认罪认罚从宽制度，发挥检察主导责任，加强释法说理，引导犯罪嫌疑人自愿认罪、退赃退赔，最大努力化解矛盾对立，修复社会关系。全年共适用该制度审结4157人，适用率81.6%，量刑建议采纳率96.8%，同比分别上升208%、239%。全面推行“48小时醉驾速裁”制度，秀屿区检察院办理了全省首例“48小时醉驾速裁”案件，该案入选全国检察机关适用速裁程序典型案例；荔城区检察院首次在全省实现“48小时醉驾速裁”规模化适用，醉驾案件平均办理时长从77天降至42.5小时，经验做法被省检察院全省转发。全市检察机关“案-件比”指标由2.23降至1.55，当事人讼累有效降低。

　　更大力度参与生态文明建设。依法打击破坏生态环境资源犯罪，与市法院、莆田海警局会签《关于建立莆田市涉海案件联合办公若干机制的意见》，联合有关部门开展贩卖野生动物专项清查行动，起诉非法采砂、走私象牙制品等犯罪210人。发挥生态文明建设基金等机制实践运用，开展补植复绿47.3亩，追缴生态修复金30.5万元。荔城区检察院在办理某城隍庙非法占用林地一案中采用“异地修复”模式开展补植复绿，持续完善“专业化法律监督+恢复性司法实践+社会化综合治理”生态保护模式。

　　更广视野促进共建共治共享。注重将办案职能向社会治理领域延伸，针对社会治理疏漏问题发出检察建议17件。落实最高检“四号检察建议”，联合有关部门推进窨井盖安全问题治理，保障人民群众“脚底下安全”。研判疫情期间监管场所稳定问题，形成《关于监管场所检察监督工作情况报告》得到市委主要领导批示，及时化解防控风险隐患。城厢区检察院结合办案制发规范“三非”外籍人员管控建议，促进主管部门开展行业整治。落实“谁执法谁普法”责任制，打造线上线下普法产品，原创栏目《莆检说法》获评全省检察机关十佳新媒体品牌；开展学习宪法、《民法典》等普法活动，努力让法治阳光照进乡村社区的每一个角落。

　　六、提升政治站位，蓄力激发队伍担当作为

　　坚持抓党建带队伍促业务，以更严要求加快推进革命化、正规化、专业化、职业化建设，努力锻造“四个铁一般”检察队伍。

　　把牢检察工作政治方向。把党的政治建设摆在首位，坚持用习近平法治思想武装头脑，严格贯彻执行《政法工作条例》，深化“不忘初心、牢记使命”主题教育成果，锤炼绝对忠诚的政治品格。用好《习近平谈治国理政》《习近平在福建》等理论文献，用活“学习强国”“检答网”等教育平台，举行学习十九届五中全会精神演讲比赛，不断提高政治能力和政治素养。牢牢把握意识形态工作主动权，增强“四个意识”、坚定“四个自信”、做到“两个维护”，引领莆田检察始终沿着正确政治方向前进。

　　狠抓检察纪律作风建设。坚持严的基调，强化“两个责任”落实，进一步把全面从严治党融入管检治检全过程。严格执行中央八项规定、检察人员八小时外监督管理规定，加强对检察权运行的内部监督，全面开展检察机关失信人员排查、“一家两制”情形督察，落实“三个规定”及重大事项记录报告制度，深化运用监督执纪“四种形态”，针对苗头性倾向性问题开展谈心谈话48人次，党纪立案1件1人。

　　夯实检察专业队伍根基。稳步推进检察官业绩考评，综合用好大数据管案、业务态势分析、列席审判委员会等机制，坚守案件质量生命线，入额院领导办理案件751件。紧贴检察实务，持续打造莆田检察理论研究品牌，7项课题获省级以上理论研究课题立项。坚持正确选人用人导向，进一步优化两级院班子和干部队伍结构。注重榜样引领，持续激发干警担当作为。全市检察机关有11个集体和25名个人获省级以上表彰，有5个集体和15名个人获国家级表彰，城厢区检察院获评第六届全国文明单位。

　　一年来，我们认真贯彻市七届人大四次会议精神，全面梳理代表意见建议，精心办结人大代表提出的建议4件，走访人大代表375人次，邀请189名人大代表、政协委员、人民监督员视察检察工作、参与案件评议、公开听证等工作。自觉接受政协民主监督，向各民主党派、工商联和无党派人士通报检察工作，广泛听取意见建议。向代表寄送《检察日报》《检察工作简报》等资料，为代表更好履职提供服务。深化检务公开，通过“一网两微五端”、门户网站及时发布案件信息990条，主动接受社会各界监督。

　　各位代表，过去一年检察工作取得的点滴进步，是党委坚强领导，人大及其常委会有力监督，政府、政协大力支持，代表、委员和社会各界关心帮助的结果。在此，我代表全市检察机关表示崇高的敬意和衷心的感谢！

　　同时，我们也清醒认识到，全市检察工作仍有一些弱项和短板：服务全市经济社会高质量发展超越的水平有待提高，检察产品供给还不够丰富；对促进社会治理现代化的贡献率还需再提升，结合办案推动源头治理做得还不够到位；法律监督职能发挥还不协调不充分；检察队伍素质能力、纪律作风建设还需进一步加强。对此，我们将坚持问题导向，认真加以解决。

　　2021年，是中国共产党成立100周年，是贯彻落实党的十九届五中全会精神、实施“十四五”规划的开局之年。我们的总体思路是：坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻习近平法治思想，深入学习贯彻党的十九大和十九届二中、三中、四中、五中全会精神，坚决落实中央和省委、市委决策部署，自觉把增强“四个意识”、坚定“四个自信”、做到“两个维护”体现在履职尽责上，努力以高质量的检察工作为实施“双轮”驱动、全方位推动高质量发展超越提供坚强的法治保障。

　　一、坚定政治自觉，以更高站位服务中心大局。旗帜鲜明讲政治。坚决维护国家政治安全，坚持党对检察工作的绝对领导，推动学习贯彻习近平法治思想和党的十九届五中全会精神持续落深落细落实。围绕市委七届十一次全会部署和“强产业、兴城市、惠民生、优生态、保稳定、重党建”中心任务，秉持“务实稳进、精业提质”工作思路，持续做好服务保障“六稳”“六保”工作，统筹做好常态化疫情防控和各项检察工作，努力以办好案履好职的实际行动，确保检察工作与莆田经济社会发展同频共振。

　　二、坚定法治自觉，以更强担当融入市域治理。认真贯彻实施《民法典》，围绕群众对美好生活的新期待，积极运用监督智慧维护公平正义，通过法治引领促进经济社会发展。贯彻落实习近平总书记治理木兰溪重要理念，持续守护莆田绿水青山。紧扣一流营商环境要求，加大产权司法保护力度，用法治为民营企业发展创造更好的营商环境。依法严惩各类刑事犯罪，常态化推进扫黑除恶专项斗争，围绕“六建”任务，大力推进“综治+”市域治理，助力提升地方法治竞争力。

　　三、坚定检察自觉，以更优质效深化监督主业。坚持在办案中监督，在监督中办案，促进“四大检察”“十大业务”全面协调充分发展。持续强化刑事诉讼活动监督，依法查办司法工作人员相关职务犯罪。加强民事行政检察监督，深化对虚假诉讼、民事执行、行政实质性化解等专项监督。稳妥拓展公益诉讼新领域范围，更好维护国家利益和社会公共利益。不断推进来信件件有回复、认罪认罚从宽、“48小时醉驾速裁”、未成年人司法保护等制度适用，推动社会公平正义进一步彰显。

　　四、坚定纪律自觉，以更高标准打造过硬队伍。自觉践行“四个铁一般”要求，巩固“不忘初心、牢记使命”主题教育成果，用伟大的抗疫精神激励全体检察干警守初心，担使命。扎实开展政法队伍教育整顿活动，严格落实“三个规定”报告制度，始终把纪律规矩挺在前面。落实意识形态工作责任制，持之以恒推进全面从严治检，努力打造一支让党放心、人民满意的新时代检察队伍。全面推进检察官业绩考评，加快构建以办案质量和效果为核心的考评管理体系，不断推进检察履职能力现代化。

　　各位代表，实干成就梦想，奋斗赢得未来。新的一年，全市检察机关将更加紧密团结在以习近平同志为核心的党中央周围，坚持以习近平新时代中国特色社会主义思想为指导，紧紧依靠市委的坚强领导、市人大的有力监督，认真贯彻落实本次大会各项决议决定，忠实履行宪法和法律赋予的法律监督职责，为实施“双轮”驱动、全方位推动高质量发展超越作出新的更大贡献，以优异成绩庆祝建党100周年！
