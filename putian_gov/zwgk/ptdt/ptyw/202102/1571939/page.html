莆田市中级人民法院工作报告

2021年1月14日在莆田市第七届人民代表大会第五次会议上
来源:湄洲日报 时间：2021-02-01 09:43
| | | |

莆田市中级人民法院院长 苏建平

各位代表：

　　现在，我代表莆田市中级人民法院向大会报告工作，请予审议，并请各位政协委员和其他列席人员提出意见。

　　2020年是全面建成小康社会和“十三五”规划收官之年。在市委领导、市人大监督和省法院指导下，全市法院坚持以习近平新时代中国特色社会主义思想为指导，认真学习贯彻习近平法治思想，全面贯彻党的十九大和十九届二中、三中、四中、五中全会精神，认真落实中央、省委、市委决策部署和市七届人大四次会议决议，依法履行职责，坚持司法为民，全面从严治院，主动接受监督，各项工作取得新进展。共受理各类案件77354件、同比下降1%，办结72002件、上升0.6%，员额法官年人均办案数259.5件，位居全省第三；其中，市法院受理10020件、下降5.9%，办结9441件、下降3.6%。全市法院有24个集体、117人次获得市级以上表彰，涌现出“全国法院先进集体”等一批先进典型。

　　一、依法履行职责，服务保障强产业、兴城市发展大局

　　全市法院认真做好“六稳”工作、落实“六保”任务，紧紧围绕市委决策部署，统筹常态化疫情防控和经济社会发展司法保障工作，为我市高质量发展超越营造良好法治环境。

　　致力优化营商法治环境。制定为项目带动提供司法保障、进一步推进优化营商环境等工作意见，加强金融审判工作，促进经济健康发展。疫情防控期间还出台司法助力中小微企业、妥善处理劳动争议、强化善意执行3个工作意见，推动复工复产。一审审结金融借款、民间借贷等借款合同纠纷10153件，标的总额74.7亿元。加强产权平等保护，落实保护民营企业家10条举措，制作民营企业常见法律风险提示书，深入企业园区普法，服务民营经济发展。城厢区法院与区检察院联合开展“保市场主体，护民营经济”专项行动，为纾困惠企提供法律服务。防范化解金融风险，妥善处置“正大”房地产系列案件，保障了396户业主正当权益，追缴欠税和土地闲置费1.16亿元，该系列案件入选“全国法院服务保障疫情防控期间复工复产典型案例”。加快完善破产审判机制，推动成立莆田市府院联动协调破产工作领导小组，建立破产税费减免、破产费用援助等机制，审结破产案件34件。贯彻落实习近平总书记关于保护好湄洲岛的重要嘱托，稳妥办理“金港公司破产重整案”，推动烂尾六年的湄洲岛“莲池花园”项目成功重整。烂尾楼司法处置“莆田经验”被省委决策参考刊物《八闽快讯》采用，被最高法院主要领导批示推广。保障创新创业创造，审结知识产权案件1287件，同比上升40.2%；2个集体被国家版权局确定为2019年度查处重大侵权盗版案件有功单位。服务更高水平对外开放，一审审结涉台港澳侨案件117件；涵江区法院作为全国13家法院之一，在全国人民法庭工作会议上介绍涉侨审判工作经验。

　　决战决胜扫黑除恶专项斗争。克服涉黑恶案件案情复杂、涉案人数多、庭审时间长、审判任务紧迫等种种困难，主动加强与侦查机关、检察机关的沟通对接，全力以赴攻案件。为适应疫情防控需要，市法院还在两个看守所建设网络审判辅助系统和“方舱法庭”，保质保量完成涉黑恶案件审判工作。专项斗争开展以来，全市法院一审审结涉黑犯罪案件16件97人，涉恶犯罪案件97件418人，涉黑恶“保护伞”案件10件10人；有131名被告人被判处五年以上有期徒刑，重刑率达25%。坚决铲除黑恶势力经济基础，对黑恶势力财产开展全方位执行攻坚，执行到位6.2亿元，执行到位率95.2%。提前谋划建章立制，在办案过程中围绕依法严惩、深挖彻查、助推治理等方面提前制定了15项工作机制，确保扫黑除恶长效常治。创新开展司法建议工作，针对基层政权、校园安全、生态资源等领域存在的问题发出司法建议书64份，并通过座谈、会商、普法等方式，推动完善社会综合治理。司法建议工作得到中央督导组的高度肯定，并作为重点经验在全国、全省法院专题会上交流，有2份司法建议获评全省十佳司法建议。

　　依法惩治各类犯罪。严厉打击危害国家安全和社会治安犯罪，审结各类刑事案件5217件。一审审结故意杀人、故意伤害等侵犯公民人身权利、民主权利犯罪案件385件，盗窃、诈骗等侵犯财产犯罪案件858件，交通肇事、危险驾驶等危害公共安全犯罪案件1058件，“黄赌毒”、寻衅滋事等妨害社会管理秩序犯罪案件742件，不断增强群众安全感。依法有力惩治经济犯罪，一审审结生产销售伪劣产品、非法经营等破坏市场经济秩序犯罪案件238件。审结的全市首例口罩诈骗案，入选福建法院服务保障疫情防控十大典型案例。依法惩治腐败犯罪，一审审结贪污、贿赂等职务犯罪案件23件。贯彻宽严相济刑事政策，判处缓刑、管制等非监禁刑1323人。依法办理减刑假释案件1027件，做好监外执行等工作。积极参与打击涉枪涉爆、毒品等犯罪活动，试点开展认罪认罚危险驾驶罪48小时速裁工作，推进社会治安综合治理。市法院连续六年获评市级一类平安单位。

　　持续深化生态司法保护。深入贯彻习近平总书记治理木兰溪的重要理念，积极参与象牙走私重点整治、打击食用野生动物违法行为、打击非法开采海砂等行动，一审审结环境资源案件139件。推广生态司法协同机制，与生态环境、林业、水利、海警等部门开展履职协作、联合打击、普法宣传等工作，共创平台、共享资源、共建生态。推进生态司法与领导干部自然资源资产离任审计衔接工作，在全市6个乡镇试行，强化领导干部生态保护意识，推动绿色发展。创新生态司法修复工作，以河长制工作站、木兰溪工作点、生态教育基地等站点为依托，推行补植复绿、增殖放流、从业禁止、巡山护鸟令等多元修复模式，护航生态文明建设。秀屿区法院大力整治非法采矿、采砂行为，收缴修复资金，推动山体环境和海域生态有效修复；仙游县法院生态教育基地入选福建生态环境司法十大体验基地，“固坝填石”河道修复入选十大修复模式，市法院审理的象牙走私案入选十大典型案例。省法院在全国法院生态环境专题座谈会上介绍我市生态审判工作经验，省人大专题调研视察给予肯定。

　　不断强化民生权益保障。坚持民生保障优先，一审审结涉及家事、医疗、教育、劳动、住房等各类民事案件31584件。加大对妇女儿童保护力度，创新完善离婚冷静期、家事调查员、家事修复、心理干预等家事审判工作机制，一审审结婚姻家庭和抚养继承纠纷案件3744件。妥善审理涉及土地、房屋等纠纷案件，一审审结商品房预售等房地产纠纷案件1622件。密切关注劳动者维权，一审审结劳动争议案件519件。市法院与仲裁机构衔接化解劳动争议机制，被《中国改革报》、《人民法院报》、最高法院司法改革专刊等专题推广报道。“一站式”高效处置交通事故纠纷，试点开展人身损害赔偿标准城乡统一工作，办结交通事故民事赔偿案件1796件，调撤率54.5%。

　　积极推动行政争议化解。依法保护行政相对人合法权益，支持促进法治政府建设，审结各类行政诉讼案件1312件，办结行政非诉执行案件326件。推动行政争议多元化解，协调化解涉及土地资源、社会保障、城市公共服务与管理、安全生产等民生类型行政案件，促进行政争议实质性化解。我市法院协助化解一起涉荔城区重点项目的253人征地赔偿系列案，最高法院第三巡回法庭专门致信感谢。完善府院良性互动机制，深化福、莆、宁三地的府院良性互动和司法协作互动，召开府院联席会议，编发行政审判白皮书，推动互动工作项目化、清单化，共同提升行政执法和行政审判水平。

　　综合治理执行难问题。巩固“基本解决执行难”成果，办结执行案件28347件，执行到位金额103.6亿元。制定依法服务保障民企健康发展执行措施，推广“善执惠商”机制，“正鼎”房地产系列案件入选最高法院“善意文明执行典型案例选编”。进一步推动完善综合治理执行难工作格局，提请市委研究制定《关于加强综合治理从源头切实解决执行难问题的实施方案》。会同市公安局联合制定了《关于依法规范人民法院执行和公安机关协助执行工作的意见（试行）》，由公安机关协助查人、找物、扣车、限制出境、打击拒执罪等，进一步加强执行联动和威慑机制建设。健全联合惩戒、司法拍卖辅助、失信名单管理等机制，深化执行指挥中心、“点对点”网络执行查控系统等信息化建设成果的运用，切实兑现群众合法权益。开展做好“六稳”工作、落实“六保”任务专项执行行动，加大对涉民生、职务犯罪刑事涉财等5类案件的执行力度，执结2121件，执行到位金额3亿元。

　　二、坚持司法为民，不断提升司法公信力

　　全市法院坚持以人民为中心，继续开展“1+2+N”司法为民品牌创建工作，积极融入和推动市域社会治理现代化。

　　依法助力脱贫攻坚。依法审理涉及精准脱贫、乡村振兴各类案件，加强司法便民、挂钩扶贫、驻村任职、志愿服务、司法救助等工作，为打赢脱贫攻坚战提供有力司法服务保障。加强司法救助，完善司法救助保险机制，救助刑事案件困难被害人、交通事故困难受害人等8类案件101件180人，发放救助款382.5万元。探索“联动式、驻村式、结对式、消费式、产业式”挂钩扶贫工作模式，五年来市法院牵头水利、交通等9家单位筹集扶贫资金684万元，选派3名干警驻村服务，与贫困家庭结对开展捐款、慰问，送去帮扶资金62.1万元，帮助发展扶贫产业，鼓励消费扶贫产品，推动完善交通、卫生、饮水、灌溉等基础设施建设，精准助推帮扶村脱贫攻坚。市法院在全省法院脱贫攻坚推进会上作典型发言。

　　切实推进审判高质量发展。积极回应群众对司法公正高效的期盼，加强审判监督管理，完善审限管理、繁简分流、案件评查、末位鞭策等机制，切实提升审判质效。全市法院案件审结率93.1%，一审案件简易程序适用率73.4%，民事案件调撤率30.4%。强化审级监督，审结二审案件4617件，申诉、再审案件576件。探索建立法律文书集约送达机制，依托邮政网络优势，成立集约送达服务中心，探索电子送达、网格送达、公证送达等模式，提高送达效率。完善人民陪审员选任及管理机制，各县区法院提请人大常委会任命223名陪审员，对7名履职不力和1名被处分的陪审员提请免职，举办新任陪审员岗前培训与任职宣誓仪式，促进司法民主。

　　全面推行“一站式”便民工作。坚持和发展新时代“枫桥经验”，大力推进一站式多元解纷和诉讼服务体系建设。完善诉讼服务中心建设，深化立案登记、调解速裁、申诉信访、跨域立案、自动退费、打印生效证明、12368服务热线等工作，共登记立案34265件，跨域立案269件，努力做到“马上办、就近办、一次办”。全面推进诉非联动中心建设，进一步加强与人民调解、行政调解、行业调解等调解组织的联动对接，坚持把非诉讼纠纷解决机制挺在前面。全市法院均成立诉非联动中心和特色诉非联动工作站，市法院与市银保监分局成立金融纠纷诉非联动中心，各县区法院先后建立旅游纠纷调处中心、消费类纠纷调处中心、涉港澳台侨诉非联动中心、食品产业诉调工作站等，推动矛盾纠纷多元共治、一站式化解。荔城区法院构建区、镇、村三级诉非联动网络，推动各镇街诉非联动工作情况纳入综治考评范畴，诉源治理成效明显。

　　不断加强司法智能服务。深化“智慧法院”建设，打造智能化办案平台，加强电子卷宗随案生成和应用，用现代科技赋能办案质效。结合疫情防控需要，全面推广网上诉讼服务中心、律师服务平台、调解平台、“移动微法院”等线上平台，广泛开展“云调解”“云庭审”“云执行”等工作，方便诉讼活动“网上办、掌上办”。共受理网上立案17056件，网上缴费27467件，网上调解20445次，线上办理信访、咨询等各类诉讼事项1.7万件次。市法院首次采用网络视频方式对“海峡商贸城公司”破产重整案召开第一次债权人会议，1239位债权人通过现场和网络直播方式参与会议。深化阳光司法，完善审判流程、庭审活动、裁判文书、执行信息公开平台，及时上网公开裁判文书6.2万份，直播庭审与执行6924场。

　　三、全面从严治院，持续建设新时代高素质法院队伍

　　全市法院以市委巡察为契机，坚持全面从严治党、从严治院，推进法院队伍革命化、正规化、专业化、职业化建设，努力建设一支党和人民信得过、靠得住、能放心的法院铁军。

　　突出政治引领。毫不动摇地把党的政治建设摆在首位，坚持以习近平新时代中国特色社会主义思想为指导，认真学习贯彻习近平法治思想，突出抓好党的十九届五中全会精神的学习研讨，扎实开展“两个坚持”专题教育，通过领导宣讲、专家授课、政治轮训、讨论辨析、检视问题等形式，增强“四个意识”，坚定“四个自信”，做到“两个维护”。加强机关党的建设，落实“一岗双责”，推进基层党组织组织力提升工程，组织开展纪念建党99周年系列活动和支部达标创星活动，增强队伍凝聚力战斗力。严格落实意识形态工作责任制，坚持每半年向市委专题汇报制度，大力弘扬司法主旋律，建好用好法院“一站两微五端”，在“学习强国”平台推出《民法典》系列普法小视频14期，宣传作品被长安网、人民法院报等省级以上平台采用1019篇，市法院被人民法院新闻传媒总社授予“司法宣传和通联工作先进单位”称号。

　　着力人才培养。落实司法责任制，强化“让审理者裁判、由裁判者负责”要求，深化司法体制综合配套改革，完善主审法官会议、专业法官会议、审判委员会等制度，加强案例指导、改判发回重审案件分析等工作，提升法官审判能力和水平。坚持人才强院，认真落实职务职级并行制度，完善干部培养、选拔、管理、使用工作机制，建立青年干警人才库，强化业务能力培训，推动优秀年轻干部梯次培养。着力培养干警担当精神，完善激励关爱和职业保障机制，为有作为、敢作为的干警撑腰鼓劲。疫情防控期间，全市法院有334名党员干警参加社区志愿服务，其中16名深入防疫一线。市法院专题组织“携手战疫心向党”事迹分享会，表彰抗疫先锋，鼓励干警的忠诚和担当。

　　持续正风肃纪。认真落实全面从严治党主体责任和监督责任，抓好市委巡察整改工作，强化司法巡查和纪律作风督查。坚决贯彻中央八项规定精神及其实施细则，整饬司法作风，积极创建省级文明单位，推动机关风貌不断向好。认真开展“以案释德、以案释纪、以案释法”警示教育活动，落实审判案件评查和执行案件“一案双查”制度，运用身边人身边事以案示警。加强日常监督，建立机关全体干警职工廉政档案，开展落实“三个规定”专项整治，全面开展廉政风险排查防控工作，细化梳理廉政风险点、风险等级和防控措施，确保纪律作风督察常态化。坚持从严监督执纪问责，用好监督执纪“四种形态”，共谈话提醒、批评教育22人，诫勉谈话5人，查处违纪违法7人。

　　四、主动接受监督，不断加强和改进法院工作

　　全市法院依法接受人大及其常委会监督，坚持大会报告和专项报告制度，认真落实决议决定，支持并执行市人大制定的《莆田市城市生态绿心保护条例》和《莆田市文明行为促进条例》。自觉保持与人大代表的常态化沟通联络，坚持每半年定向联络和集中走访，高质量办理和反馈代表意见建议。适时邀请代表参与监督法院工作，邀请代表集中视察、旁听庭审、参与调解、见证执行，方便代表履职监督。自觉接受政协民主监督，向各民主党派、工商联和无党派人士通报法院工作，与民营企业家、律师等召开优化营商环境专题座谈会。市法院以服务保障民营经济、生态司法保护、宪法宣传日等为主题，邀请代表、委员等开展专项视察；办复代表建议7件、委员提案1件。积极接受监察监督、检察监督和新闻媒体、社会各界的监督，改进法院工作。

　　各位代表，过去一年法院工作的发展进步，离不开市委的坚强领导和人大的有力监督，离不开政府的大力支持、政协的民主监督，离不开社会各界的关心帮助。在此，我代表全市法院表示衷心的感谢和崇高的敬意!

　　同时，我们也清醒地认识到，法院工作仍然存在问题和不足。一是全方位推动高质量发展超越对法院工作提出了更高要求，司法服务保障水平需要进一步提升；二是审判监督管理、解决执行难等工作还有短板，还不能很好满足人民群众对司法工作的新需求新期盼；三是司法改革创新、诉源治理减量等工作仍需深化，推动市域社会治理现代化还有短板弱项；四是案多人少矛盾依然突出，队伍素质能力建设还有薄弱环节，个别干警作风不正，违纪违法现象仍然存在。对此，我们将采取有力措施切实加以解决。

　　2021年，是“十四五”规划的开局之年。全市法院将以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平法治思想，全面贯彻党的十九大和十九届二中、三中、四中、五中全会精神，紧紧围绕中央、省委、市委和上级法院决策部署，坚持稳中求进工作总基调，坚持新发展理念，坚持司法工作目标主线，在莆田经济社会发展大局中展现更大司法作为。

　　一要始终坚持法院工作的正确方向。深入学习贯彻习近平新时代中国特色社会主义思想，增强“四个意识”，坚定“四个自信”，做到“两个维护”。坚持党对司法工作的绝对领导，紧紧围绕市委“强产业、兴城市、惠民生、优生态、保稳定、重党建”中心任务，强化司法服务保障工作，确保市委决策部署在全市法院得到不折不扣贯彻落实。坚持全面从严治党，加强法院党的建设和意识形态工作，推进司法体制改革、信息化建设和队伍建设，谋划推进全市法院“十四五”时期各项工作。

　　二要依法服务保障新时代美丽莆田建设。认真落实市委“突出开放招商、强化项目带动”的决策部署，积极服务保障招商引资及产业项目建设，深化民营经济服务保障行动，加大产权和企业家合法权益保护力度，依法服务保障扩大投资和消费升级，推动建设更高水平的市场化法治化国际化营商环境。深入学习贯彻习近平生态文明思想和治理木兰溪的重要理念，探索“自然原生态+文化原生态”司法保护品牌，积极构建多元共治格局，继续打造生态司法保护“莆田样本”。加强知识产权审判工作，为创新创业创造营造良好法治环境。加强涉台港澳侨审判，服务高水平对外开放。

　　三要积极推动更高水平的平安法治建设。牢固树立总体国家安全观，依法惩治各类刑事犯罪，巩固深化扫黑除恶专项斗争成果，坚决维护国家政治安全、经济安全，保障人民生命安全，维护社会稳定和安全。主动融入党委领导的社会治理体系和共建共治共享的基层社会治理格局，积极参与社会治安综合治理，深化“1+2+N”司法为民品牌创建工作，深入推进一站式多元解纷和诉讼服务体系建设，推动市域社会治理现代化。坚持人民至上，认真实施《民法典》，加强府院良性互动，强化民生司法保障，推动化解行政争议，健全执行长效机制，不断增强人民群众获得感、幸福感、安全感。

　　各位代表，新的一年，我们将更加紧密地团结在以习近平同志为核心的党中央周围，在市委领导、人大监督下，认真落实本次大会决议，更好地发挥人民法院职能作用，为实施强产业、兴城市“双轮”驱动，全方位推动高质量发展超越作出新的更大贡献，以优异成绩向中国共产党成立100周年献礼。
