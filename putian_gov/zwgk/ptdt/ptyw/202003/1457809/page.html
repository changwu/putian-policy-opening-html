2019年莆田市国民经济和社会发展统计公报

莆田市统计局 国家统计局莆田调查队 2020年3月18日
来源:湄洲日报 时间：2020-03-27 09:48
| | | |

　　一、综合

　　2020年3月18日

　　根据国家统计局2019年12月最新核算方法，全年实现地区生产总值2595.39亿元，比上年增长6.6%（以第四次全国经济普查总量为基数）。其中，第一产业增加值123.65亿元，增长2.8%；第二产业增加值1377.98亿元，增长7.3%；第三产业增加值1093.76亿元，增长6.2%。三次产业增加值占地区生产总值的比重，第一产业为4.8%，第二产业为53.1%，第三产业为42.1%。全年人均地区生产总值89342元，比上年增长6.4%。

　　全年限额以上批发和零售企业实现网上商品零售额205.44亿元，增长17.1%。

　　年末常住人口291万人，比上年末增加1万人。其中，城镇常住人口179.5万人，占总人口比重（常住人口城镇化率）为61.7%，比上年末提高0.7个百分点。全年出生人口3.8万人，出生率为13.0‰；死亡人口1.9万人，死亡率为6.5‰；自然增长率为6.5‰。年末户籍人口数为363.5万人，比上年末增加3.24万人。

　　二、农业

　　三、工业和建筑业

　　全年全部工业增加值1094.55亿元，比上年增长8.5%。规模以上工业增加值增长8.6%，其中，国有控股企业增长8.3%。在规模以上工业中，分经济类型看，国有企业增加值增长9.0%，集体企业下降35.3%，股份制企业增长10.6%，外商及港澳台商投资企业增长2.1%；私营企业增长10.0%。分轻重工业看，轻工业增长6.7%，重工业增长13.2%。分工业门类看，采矿业下降3.6%，制造业增长8.9%，电力、热力、燃气及水生产和供应业增长3.9%。工业产品销售率98.77%，比上年下降0.21个百分点。

　　规模以上工业的38个行业大类中有13个增加值增速在两位数。其中，纺织业增长26.9%，计算机、通信和其他电子设备制造业增长24.2%，化学原料和化学制品制造业增长22.3%，酒、饮料和精制茶制造业增长14.7%。规模以上工业中三大主导产业增加值增长12.7%。其中，机械装备产业增长5.9%；电子信息产业增长24.2%；石油化工产业增长12.2%。六大高耗能行业增长13.0%，占规模以上工业增加值的比重为14.4%。工业战略性新兴产业增长7.8%，占规模以上工业增加值的比重为14.8%。高技术制造业增长9.8%，占规模以上工业增加值的比重为7.5%。装备制造业增长12.8%，占规模以上工业增加值的比重为14.4%。

　　四、固定资产投资

　　全年固定资产投资（含铁路）比上年增长6.3%。其中，固定资产投资（不含跨区项目）增长6.0%。

　　在固定资产投资中，第一产业投资下降4.9%；第二产业投资增长12.7%，其中，工业投资增长14.7%；第三产业投资增长3.6%。基础设施投资下降11.2%，占固定资产投资的比重为32.6%。民间投资增长5.5%，占固定资产投资的比重为62.8%。高技术产业投资增长80.0%，占固定资产投资的比重为6.9%。从到位资金情况看，全年到位资金比上年增长18.4%。其中，国家预算资金下降49.5%，国内贷款下降9.8%，自筹资金增长36.2%，其他资金下降3.8%。

　　全年接待入境游客55.47万人次，比上年增长18.4%。其中，接待外国人7.07万人次，增长0.3%；台湾同胞36.93万人次，增长22.8%；港澳同胞11.47万人次，增长17.8%。在入境旅游者中，过夜游客55.47万人次，增长18.4%。国际旅游外汇收入4.89亿美元，增长18.6%。全年接待国内旅游人数3921.55万人次，增长17.2%；国内旅游收入406.93亿元，增长25.7%。旅游总收入440.73亿元，增长25.6%。

　　九、人民生活和社会保障

　　全年居民人均可支配收入30520元，比上年增长9.2%。按常住地分，农村居民人均可支配收入19687元，比上年增长9.4%；城镇居民人均可支配收入40065元，比上年增长7.8%。

　　全年居民人均生活消费支出21721元，比上年增长9.7%。按常住地分，农村居民人均生活消费支出16251元，增长8.5%；城镇居民人均生活消费支出26541元，增长9.4%。

　　年末，全市纳入城市最低生活保障的居民1706人，比上年末增加602人；纳入农村最低生活保障的居民41723人，比上年末增加12310人；城乡特困供养对象3683人，比上年末减少179人。参加失业保险23.99万人，比上年末增加1.73万人；年末领取失业金人数3245人，比上年末增加23人。

　　年末全市养老机构床位数增至4200张，每千名老人拥有养老床位7.1张。全市建立各类社区服务机构582个，其中社区服务中心（站）86个。莆田市福利彩票发行中心全年共销售福利彩票2.52亿元，共筹集福彩公益金7700万元。

　　十、教育和科学技术

　　全年普通高等教育招生10198人，在校生25072人，毕业生5263人。中等职业教育（不含技工校）招生7267人，在校生17008人，毕业生4859人。成人高等教育招生2249人，在校生5294人，毕业生862人。全市普通高中招生24567人，在校生66812人，毕业生20173人。全市普通初中招生44095人，在校生122223人，毕业生38776人。普通小学招生50431人，在校生276975人，毕业生43559人。特殊教育在校生1772人（含随班就读）。学前教育在园幼儿125713人。

　　全年全市共建设省级众创空间14家。科技企业孵化器备案8家，省级科技孵化器1家，孵化面积5.05万平方米，在孵企业72家、创造就业岗位854个。新认定高新技术企业37家，总数91家；新认定省级企业技术中心2家；新认定省科技小巨人领军企业4家，总数70家。

　　全年全市专利申请5252件，居全省第6位，同比下降14.6%。其中，发明专利申请778件，居全省第7位，同比下降5.1%；实用新型专利申请2536件,同比下降24.5%；外观设计专利申请1938件,同比下降1.5%。全年全市专利授权3512件，居全省第6位，比上年增长20.6%，增幅居全省第1位。其中，发明专利授权117件，比上年下降26.0%；实用新型专利授权1974件，比上年增长26.7%；外观设计专利授权1421件,比上年增长18.8%。截至2019年底，全市共拥有有效发明专利883件，比上年增长10.1%；每万人口发明专利拥有量3.045件，比上年增长10.1%。

　　年末全市文化系统共有艺术表演团体4个，公共图书馆3个，文化馆6个，博物馆7个。文化系统各类艺术表演团体演出0.09万场，观众61.99万人次，其中：政府采购公益性观众8.03万人次；各级公共图书馆组织各类讲座97次，书刊文献外借121.49万册，总流通人数281.71万人次；各级文化馆组织举办展览60次，组织文艺活动149次、培训班183期和公益性讲座20次，服务 32.54万人次；博物馆举办14个基本陈列和66个展览，共有345.87万人次参观，其中：未成年人参观60.45万人次。

　　年末共有数字影院21家，银幕124块，年度电影票房1.22亿元。全市现有电视台1家、广电网络公司1家。有线电视用户36.44万户（全部为有线数字电视用户），付费数字电视用户19.33万户，高清用户23.32万。年末广播节目综合覆盖率为95.00%；电视节目综合覆盖率为80.00%。

　　全年出版的主要报纸有《湄洲日报》1906.15万份、《莆田晚报》737.10万份、《仙游今报》217.09万份，《油画》杂志7800份。

　　年末全市共有各级各类医疗卫生机构1339个，其中医院53个，卫生院49个，村卫生室917个。年末共有卫生技术人员16016人，其中医生6088人，注册护士7268人。年末共有医疗机构床位17064张，乡村医生和卫生员2017人。

　　全年我市运动员在世界级比赛中共获得3金3银3铜，在亚洲级别比赛中获得1金1铜，在全国级别以上赛事中共获得20金20银18铜的成绩。为民办实事项目共投入资金1933万元，建多功能运动场18个、门球场1个、室内健身路径83套、室外乒乓球桌125台等。全年销售体育彩票8.15亿元。

　　十二、资源、环境和安全生产

　　全年全社会用电量下降0.5%。

　　全年植树造林总面积4.24万亩，占任务的136.5%，其中，人工造林0.16万亩(含非规划林地造林0.059万亩)；更新造林面积3.38万亩，低产低效林改造面积0.7万亩。全市森林覆盖率60.17%。商品材产量10.8万立方米，同比增长9.4%。城市新增绿地面积303.26公顷，绿地率40.57%，人均公园绿地面积15.02平方米。

　　全市共建立省级自然保护区2个，总面积20855.9公顷。有风景名胜区4处，其中国家级风景名胜区1处、省级3处，风景名胜区总面积120.3平方公里（含海域面积）/79.4平方公里（不含海域面积）。

　　木兰溪水质良好，水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为83.3%，同比均持平。萩芦溪水质状况优，水质功能达标率为100%，Ⅰ～Ⅲ类水质达标率为100%，同比均持平。

　　全年全市有效监测天数为365天，达标天数比例为97.8%，同比上升6.0个百分点，其中一级、二级达标天数比例分别为44.4%、53.4%。环境空气质量综合指数为2.98，同比上升0.19，首要污染物为臭氧。

　　全市城镇生活垃圾无害化处理率预计为99.5%，市县污水处理率预计为93.5%。

　　全市共发生森林火灾1起，过火面积8.6公顷，受害面积2.14公顷；森林火灾发生率、受害率分别为0.43次/十万公顷和0.01‰，没有发生扑火人员伤亡事故。全年海洋灾害造成直接经济损失约7万元。全年发生（现）海洋赤潮1次，较上年增加1次：累计赤潮面积1平方公里，比上年增加1平方公里。

　　发生各类生产安全事故85起，死亡49人，分别比上年下降47.9%和9.3%，未发生较大以上生产安全事故。亿元地区生产总值生产安全事故死亡人数0.019人，比上年下降20.83%。
