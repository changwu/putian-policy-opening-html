确保困难群众保障不漏一人——我市聚焦“漏保”“漏救”问题推进“点题整治”工作

来源:湄洲日报 时间：2022-09-12 08:06
| | | |

　　困难群众保障工作，关系群众基本生活和衣食冷暖，事关促进社会公平和维护社会稳定。整治困难群众“漏保”“漏救”问题，加强低保、特困、孤儿、事实无人抚养儿童等困难群众基本生活保障，被列入省纪委监委“点题整治”项目。

　　我市共有常住人口321万人，低保特困对象5.5余万人，社会救助占人口总数的1.7%。如何防止困难群众“漏保”“漏救”？在市纪委监委的监督推动下，今年以来，我市各级民政部门大力推进该项“点题整治”工作，进一步提升社会救助精准化水平，努力让困难群众保障不漏一人。

　　■实打实帮助群众解难题

　　秀屿区东峤镇霞西村村民林淑容今年56岁，患有肢体二级残疾，行动不便，生活不能自理，与86岁的父亲相依为命，生活困难。她虽符合低保条件，可纳入兜底保障范围，但因其户口问题，迟迟无法办理。霞西村民政协管员林春洪告诉记者，办理低保要有户口，如果没有户口，就无法办理。

　　结合今年“点题整治”工作要求，东峤镇民政办组织人员深入探讨，决定对其进行特事特办，联合派出所户籍科等相关部门，通过走访调查、摸清实情，为其开通绿色通道办理户口。今年8月，林淑容被纳入低保保障，还办理了残疾证。“感谢大家的帮助，让我们的生活有了保障。”如今，她每月能领到补助金660元。东峤镇民政办负责人戴薇表示，接下来，他们将进一步关注解决群众的各项实际困难，做到应保尽保。

　　得益于我市正在开展的困难群众“漏保”“漏救”“点题整治”工作，8月底，城厢区华亭镇隆兴村村民林杏红收到一笔3.5万元的临时救助金。

　　林杏红和丈夫王春贵靠干农活、卖果苗为生。2020年11月，林杏红在从娘家回来的路上，不慎摔伤，导致下半身瘫痪，需要一大笔医疗费。突如其来的变故，无疑让原本并不宽裕的家庭雪上加霜。不得已，去年4月，其女儿在网上发布了众筹帖。

　　“农村人爱面子，家里的事不愿外传，他不说，我们根本不知道。”隆兴村村委会副主任林志高说，他们得知此事后第一时间进行排查，帮助林杏红收集资料，尽可能快地上报平台办理低保。不仅如此，村委会还为其儿子提供每年3000元助学金。

　　王春贵说，他原本并不知道政府有临时救助这一政策，也不知道自己能不能符合救助条件。现在好了，这笔临时救助金缓解了妻子住院治疗费用压力。如果没有各级政府、部门的帮助，他们的小家庭就垮了。

　　■“大数据+铁脚板”主动“防漏”

　　记者了解，该项“点题整治”的重点主要有三方面：对符合低保、特困、孤儿、事实无人抚养儿童等困难群众主动发现不到位、实施救助不及时；低保金、特困供养金、孤儿和事实无人抚养儿童基本生活保障金等未及时足额发放到位等问题；部分基层经办人员业务水平不高、服务意识不强、政策落实不精准、不担当不作为等问题。

　　据介绍，过去，我市各级民政部门只能靠人海战术，本着“应保尽保”的动态管理原则，对照低保申请条件，按照“每户必入、入户见人”的工作原则，逐一排查、核查。这样工作基数大、任务重、难度大、效率低、效果差。

　　面对庞大的群众基数和动态变化的社情民意，困难群众保障该如何“防漏”？

　　今年以来，在市纪委监委推动下，民政部门充分发挥“智慧平台”赋能作用，完善“大数据+铁脚板”预警监测主动发现机制，将现有的社会救助对象名单与全市4-7月新增残疾人名单进行碰撞，产生出一份2399名未纳入兜底保障的残疾人名单，通过平台转发至各县区、镇街进行事前研判，疑似符合条件的转入问题清单，符合条件的则按程序纳入社会救助，让数据多跑腿、兜底更有力。

　　市民政局社会救助和社会福利科科长陈建豹介绍，针对困难群众保障如何“防漏”，主要采取了两个措施。一个是地毯式的排查，一个是智慧式比对。地毯式排查，主要是将重残重病等十类人员的名单进行梳理，今年共梳理出8.94万条，下发给各县区、镇街，要求民政干部、镇村干部对每一条问题线索都要入村入户，每一条信息都要比对到位，排查出“漏保”“漏救”的困难群众户，并及时纳入保障。

　　“堵漏”最关键的一环在基层。以华亭镇隆兴村来说，现有户籍人口2500多人，全村仅有一名民政协理员。如今，有了平台的数据，他们查缺补漏就更有针对性。林志高表示，接下来将根据今年市、区下达的名单，如果属于监测对象，第一时间会去入户调查；如果没有，也会在全村走动，或者在微信群通知，以这种方式尽量做到应保尽保、不漏一户。

　　■“政策找人”精准救助

　　市民政局副局长郭国辉表示，目前社会救助工作已由“人找政策”向“政策找人”转变，由“救穷”到“救弱”“救急”延伸。专项点题整治行动中，民政部门采取“线上比对+线下核查”“入户排查+上门服务”等方式，做到精准救助“兜准底”，主动作为“兜牢底”，完善机制“兜好底”。

　　截至8月底，全市保障城乡低保对象51270人、特困人员4167人、孤儿136人、事实无人抚养儿童1778人，已累计发放城乡低保金19553.65万元、特困供养金6387.66万元、事实无人抚养儿童补助金1752万元。

　　下一步，市民政局将紧紧围绕“点题整治”重点，找准问题症结，打通“下情上达，上情下达”卡点，进一步健全分层分类的社会救助体系，深化“资金+服务+物资”社会救助方式，兜准兜住兜好民生底线，推动“民生普惠，共享小康”的莆田社会救助实践。（记者 蔡玲）
