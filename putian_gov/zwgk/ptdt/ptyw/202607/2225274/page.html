向新而行增动能

——看我市加快打造新型功能材料千亿产业集群
来源:湄洲日报 时间：2026-07-13 07:13
| | | |

图为在中裕新材料检测室，工作人员对皮革样品进行拉力测试。林罗晓 摄
　　莆田新型功能材料产业是首批国家级战略性新兴产业集群之一，核心承载区石门澳产业园联动东峤、枫亭、木兰溪口三大产业节点，构建起“一核三园”产业空间体系。新型功能材料产业不断延链强链，形成以新型化学纤维、功能纺织材料、新型涂料为三大支柱的产业链条。
　　数据显示，近3年，莆田新型功能材料产业增加值年均增速稳定在20%以上，2025年增幅达21.8%。
　　龙头引领 撑起产业脊梁
　　前不久，位于石门澳产业园内的永荣科技3万吨/年己内酰胺制己二胺项目全线贯通，一次开车成功并产出优质己二胺产品。这一项目顺利投产，在打破国外长期技术垄断、保障国内尼龙产业链安全上迈出了关键一步，也为我市打造国家级新型功能材料千亿产业集群再添新动能。
　　据介绍，己二胺是生产尼龙66的关键中间体，长期以来，其上游核心技术被海外企业垄断。福建永荣科技有限公司生产高级总监、安全总监张泽渐告诉记者，永荣科技前瞻性地采用“己内酰胺直接制备己二胺”这一创新工艺，一举打破了对己二胺原料的技术依赖，拥有更安全、更高效、更经济的优势。
　　“此次己二胺项目自投料试车至全线贯通，全程刷新行业纪录，呈现出打通全流程用时短、产出即优品、起步即达产三大亮点。”福建永荣科技有限公司常务副总经理、总工程师瞿亚平表示，项目于2025年启动设计与建设；今年4月底氨基己腈装置先行投料，5月14日己二胺装置进料，5月19日顺利产出精己二胺，从进料到产成品全流程平稳贯通，用时不到一个月。
　　就近关联配套，形成补链强链。该项目产出的己二胺，就近供给石门澳产业园内规划建设的尼龙66及特种功能性材料项目，与永荣科技CPL装置、福建中锦新材料PA6聚合装置形成“苯—己内酰胺—尼龙6/尼龙66”的短距离产业链闭环，推动园区从单一尼龙6链条升级为“尼龙6与尼龙66双链驱动”格局。
　　目前，华峰、三棵树、海安、永荣、赛得利等龙头企业在莆田扎根生长，以技术硬实力支撑起产业发展的脊梁。
　　强链补链 加速集群发展
　　产业的竞争力，源于链条的完整性。我市聚焦新型功能材料产业链强链补链，全力推进重大项目招商落地。
　　投资98亿元的循环绿色低碳产业园在涵江区木兰溪口产业新城开工以来，施工单位正按序时推进。项目采用全球领先的“纺织品—纺织品”再生技术，建成后年产25万吨再生纤维、10万吨高端面料，建设具有示范引领效应的再生纤维、高端面料生产基地。
　　在石门澳产业园，三棵树产业园一期二阶段总投资7.8亿元，设计年产能为溶剂型涂料5万吨、胶黏剂类4万吨及水性涂料9万吨。这是三棵树首次布局汽车涂料、船舶涂料产线，实现从建筑涂料向工业涂料的全品类覆盖。
　　高性能轮胎智能化产业园项目落地秀屿区，总投资43亿元，将建设2条半钢子午线轮胎生产线和1条全钢子午线轮胎生产线，打造现代化、绿色化的智能工厂，强化产业链下游配套能力。
　　重大项目是产业集群扩张的重要支撑。我市精心绘制产业链全景图及招商图谱，立足各地资源禀赋，科学布局项目。秀屿区依托石门澳产业园、东峤工业园，重点发展尼龙、绿色再生纤维及高端功能性面料；仙游县依托枫亭经开区，重点发展橡胶轮胎、轻量化聚合物材料；涵江区依托木兰溪口产业新城，重点发展循环再生纤维；湄洲重点发展粘胶纤维……
　　从“单点突破”到“链式协同”，一个以绿色、智能、循环为底色的新型功能材料千亿集群正加速形成。 
　　技术创新 激发内生动力
　　连日来，在福建中裕新材料技术有限公司生产车间，7条生产线全速运转，不断产出一片片生态功能性聚氨酯合成革。在样品检验室，工作人员对抽样的产品进行耐挠、耐磨、破裂强度、拉力等多道工序检验。
　　“我们的材料标准远高于国标。比如，国标要求耐折5万次、耐磨400转、剥离强度80N，我们的材料基本上能达到耐折15万次、耐磨2000转、剥离强度120N。”福建中裕新材料技术有限公司研发中心负责人黄娇说。正是因为对产品品质的极致追求，该公司成功与阿迪达斯、耐克、彪马、斐乐、安踏、特步等国内外一线运动品牌建立了长期战略合作关系，产品远销海外市场。
　　“环保为先、绿色制造”贯穿于企业的产品研发与生产工艺之中。该公司聚焦行业前沿，加强绿色高新材料研发，并在清洁生产、回收再生及功能性材料等领域不断突破。在材料端，公司广泛应用再生化纤、生物基纤维及树脂、可降解纤维等环保原料；在工艺端，成功突破无溶剂聚氨酯、水性聚氨酯的力学性能瓶颈，大幅减少了生产过程中有机溶剂的参与及逸散。目前，公司已拥有13项发明专利，多项专利技术成功转化应用，取得良好经济效益。
　　“今年以来，公司生产线平稳运转，产值同比略有增长。”黄娇表示，公司新组建国际品牌部，下一步将继续开拓海外市场，寻求与国际品牌深化合作。
　　从一家普通的合成革生产商蝶变为国家高新技术企业、国家级专精特新“小巨人”企业，并拥有国家级博士后科研工作站，中裕新材料的成长是新型功能材料产业蓬勃发展的一个缩影。
　　目前，全市新型功能材料产业覆盖化工新材料、纺织功能材料、鞋服配套材料、电子陶瓷材料、环保再生材料等领域，现有规上工业企业97家。

　　行而不辍，未来可期。莆田将新型功能材料纳入战略性新兴产业重点发展方向，在园区建设、技术研发、设备更新、融资信贷、人才引进等方面给予全方位支持，持续壮大产业规模，加快建设匠心智造产业新城。 (记者 朱建婷)
