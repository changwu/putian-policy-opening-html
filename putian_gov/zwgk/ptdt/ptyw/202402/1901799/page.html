莆田市人民检察院工作报告

——2024年1月10日在莆田市第八届人民代表大会第三次会议上
来源:湄洲日报 时间：2024-02-02 07:20
| | | |
莆田市人民检察院检察长 许志鹏
各位代表：
　　现在，我代表市人民检察院向大会报告工作，请予审议，并请市政协委员和列席会议的同志提出意见。
　　过去的一年，全市检察机关在市委和省检察院领导、市人大及其常委会监督、市政府、市政协及社会各界关心支持下，坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平法治思想，全面贯彻党的二十大精神，全面落实《中共中央关于加强新时代检察机关法律监督工作的意见》及省委实施意见，深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”，紧扣市委工作部署和市人大各项决议，践行新时代新征程“四大检察”一体履职、综合履职、能动履职新要求，为大局服务、为人民司法、为法治担当，共受理各类案件及事项18090件，法定期限内办结率100%，务实稳进、精业提质，为加快建设绿色高质量发展先行市提供有力司法保障。
　　一、厚植对党忠诚检察自觉，同频共振护航发展要务
　　旗帜鲜明讲政治、顾大局，聚焦服务保障高质量发展首要任务能动履职，推进更多检察元素融入发展要素。
　　坚定正确政治方向。牢记检察机关是党绝对领导下的政治机关、法律监督机关和司法机关，擦亮坚定拥护“两个确立”、坚决做到“两个维护”鲜明政治底色。把握“学思想、强党性、重实践、建新功”总要求，扎实开展学习贯彻习近平新时代中国特色社会主义思想主题教育，突出服务经济、维护稳定、保障民生等领域，确定26个大兴调查研究课题，制定36项举措，已取得阶段性成效23项。对标市委“一五二三四”工作部署，出台服务民营经济强市战略18条措施、服务乡村振兴10项行动等文件，深学争优、敢为争先、实干争效，始终紧扣党委中心工作能动履职。
　　积极优化营商环境。坚持法治是最好的营商环境，依法惩治严重经济犯罪，起诉非法经营、串通投标等扰乱市场秩序犯罪545人，起诉洗钱、非法集资等破坏金融监管秩序犯罪20人，起诉虚拟货币等新类型犯罪30人。开展营商环境领域行政检察专项监督，督促职能部门纠正市场准入门槛等违法情形33件。强化知识产权综合司法保护，在市鞋业协会、高新区等地设立检警联动示范岗，开展鞋服行业知识产权恶意诉讼专项监督，实行“一案四查”机制，办理制假售假、恶意诉讼等案件275件，引导工艺美术企业登记外观设计专利权9项，维护“莆田质造”声誉。
　　平等保护市场主体。紧跟全市重点产业链发展，开展问需于企等活动65场次，畅通涉企案件绿色通道，动态清零涉企挂案，起诉职务侵占、商业贿赂等侵害企业权益犯罪12人。推进涉案企业合规整改刑事诉讼全流程适用，建立涉案中小微企业“简式合规”办案机制，探索异地合规监管模式，适用合规政策办案5件。邀请民企、台企等参访检察服务民营经济平台11批次，开展医美、建筑等行业预防性合规辅导，助力提升可持续发展能力。建立涉企民事监督案件检察和解机制，荔城区检察院促成两家鞋企和解1000万余元的民事执行纠纷，因企施策，助企纾困。
　　服务美丽莆田建设。融入生态文明建设大格局，协同整改环保督察反馈问题，与市生态环境局共建生态检测实验室，办理生态环保领域公益诉讼案件208件，东圳库区水环境保护等4个案件获评全市十大司法护水案例。坚持用最严密法治保护生态，起诉破坏生态环境资源犯罪67人，与林业等部门建立“检察+碳汇”机制，督促违法犯罪人员以购买碳汇等方式，承担生态修复赔偿责任107万元，秀屿区检察院办理的王某绿等人非法采矿案入选最高检典型案例。在木兰溪、湄洲岛、城市绿心等地，建成木兰溪源、红树林、古荔古厝等司法保护实践基地8个，构筑“壶山兰水检察蓝”法治屏障，保护生态多样性。检察履职守护“母亲河”碧水安澜、延续泛舟木兰、品赏荔林乡愁记忆等工作做法，在人民网、学习强国、检察日报等媒体多次刊发。
　　二、砥砺司法为民检察宗旨，同心共情守护美好生活
　　筑牢人民立场，聚焦人民群众的安危冷暖、急难愁盼能动履职，不断提升人民群众的安全感幸福感获得感。
　　惩治犯罪守平安。依法履行捕诉职能，共批捕1821人、起诉4192人。常态化推进扫黑除恶斗争，起诉36人，高质效办结刘某光、侯某华等一批上级交督办的重大黑恶犯罪案件。严惩危害社会安定、人民安宁犯罪，起诉故意杀人、抢劫等严重暴力犯罪422人，办结林某扬故意杀人案等群众关注的案件；起诉涉枪涉爆、黄赌毒犯罪798人；起诉涉缅北、老挝电信诈骗及关联的掩饰隐瞒犯罪所得、帮助信息网络犯罪等853人，追赃挽损3403万元。密切监检衔接，受理监委移送审查起诉职务犯罪26件29人，已办结17件19人，持续在反腐败斗争中贡献力量。
　　办好实事惠民生。部署“民检守心”为民办实事活动，开展治理“餐桌污染”等专项监督，起诉危害食品药品安全犯罪65人，追索惩罚性赔偿金279万元，守护群众“舌尖上”安全。开展住宅维修基金专项监督，督促28个住房项目规范使用；深化燃气、电力、供水等领域公益诉讼监督，共办案25件，保障群众住行安全。加强老年人、残疾人、讨薪农民工等群体权益保障，依法支持起诉85件736万元，为78名困难当事人发放司法救助金133万元。省市区三级检察院接力办理一起跨度十年的刑事申诉案件，依法监督改判被申诉人有罪，坚决维护群众权益。
　　关爱少年护成长。健全未成年人检察综合履职机制，严惩侵害未成年人犯罪90人；以宽容不纵容理念挽救罪错少年，起诉严重犯罪未成年人90人，附条件不起诉77人，不起诉133人。积极促进“六大保护”同向发力，开展家庭教育指导211人次，制发督促监护令658份，让家庭监护常伴成长；推动建成涉案未成年人专门学校，保障涉案少年学有所教；法治巡讲进山区校、侨乡校等66场次，“未”爱走遍每个角落；办理文身、娱乐场所违规接纳未成年人等公益诉讼案件54件，2个案件获评全省春蕾安全员机制优秀案例，“未检闽e站·莆阳未检”团队通过全国青少年维权岗复核，携手各方共护孩子们成长的法治蓝天。
　　便捷服务增亲和。坚持求极致精神，持续提效12309检察服务品质，畅通群众信、访、网、电等诉求表达渠道，第一时间告知已受理、谁在办，共办理群众控告申诉、举报投诉、咨询查询等3230件次，办结律师辩护代理、阅卷等事项2011件次。充分用好“益心为公”检察志愿者云平台，122名社会公益人士、基层干部群众注册成为检察公益志愿者，参与监督办案18件次。落实谁执法谁普法责任制，动态发布各类案件信息、办案数据等检察资讯732件次，原创推出“莆检故事汇”“莆检说法”等案例访谈74期，以群众身边常见的案，普及群众关心的法。
　　三、坚守良法善治检察使命，同题共答融助市域治理
　　着眼共筑长治久安基石，聚焦构建共建共治共享的社会治理共同体能动履职，促进治罪与治理并重、治标与治本统筹。
　　检村联动助力基层治理。传承“四下基层”优良传统，积极融入“党建引领、夯基惠民”工程，落实“三官一律”机制，已与405个村居建立检察官挂钩联系服务机制，协助调处纠纷、推进项目等604件次。聚焦粮食安全，持续开展农用地保护专项监督，办案28件，监督复垦挽回耕地128余亩。专项开展农产品质量、传统村落保护等监督工作，仙游县检察院联合属地政府、主管部门，共同支持果农依法维权“书峰枇杷”地理标志。发挥党建纽带作用，引导因地制宜发展特色产业、改善村容村貌，服务乡村振兴，挂钩帮扶的伍狮村入选省文联诗歌创研基地。
　　宽严相济深化轻罪治理。贯彻宽严相济刑事政策，依法对情节轻微的犯罪不批捕349人，不起诉566人，释放司法善意，消弭社会对立面。全面实行量刑协商同步录音录像等机制，确保认罪认罚、和解谅解自愿真实、量刑建议合法恰当，规范适用认罪认罚从宽制度办结3952人，一审服判率96%，被告人上诉、被害方申诉案件大幅减少。持续探索教育预防、行政处罚、刑事惩治综合治理机制，以公益服务、集中训诫等方式引导违法者转变为普法者，源头预防和减少“醉驾”等轻罪类案。简案快办效能再提升，“48小时速裁”机制列入全省首批轻罪治理创新实践试点。
　　定纷止争推动诉源治理。践行新时代“枫桥经验”，推进检察环节信访工作法治化，领导干部包案办理群众信访133件，2656件群众来信来访均严格做到“件件有回复”两个100%，“百日攻坚”“治重化积”等专项行动案件办结率100%，化解率94%。注重预防在前、调解优先，对当事人争议大的案件，坚持应听证尽听证，邀请人大代表、政协委员、人民监督员等参与听证评议193件，解法结、化心结。积极推广“民转刑”案件提前介入、实地走访、调解、听证、回访等“五合一”机制，促成刑事和解112件，以群众愿意听、能接受的方式把矛盾纠纷化解在田间地头。
　　检察建议赋能社会治理。积极发挥检察建议促进抓源治本作用，聚焦典型个案、多发类案背后的社会治理新情况，加强实据论证、法核把关，确保问题找得准、对策建议行得通，制发社会治理类检察建议57件，涉及金融监管、物流寄递、安全生产等18个领域。推动社会治理类检察建议落实情况纳入党政绩效、综治考核体系，协助被建议单位抓好落实，检察建议“两个月”内办复率100%。对“三非”外国人滋扰治安问题，督促职能部门对非法入境、居住、劳务介绍等开展专项整治，该案获评全省十佳社会治理类检察建议、入选全省检察机关第十六批典型案例。
　　四、深耕法律监督检察职责，同向共赢维护公平正义
　　坚持法定职责必须为，聚焦努力让人民群众在每一个司法案件中感受到公平正义能动履职，高质效办好每一个案件。
　　刑事监督更高效。实质化运行侦查监督与协作配合机制，监督侦查机关立案260件、撤案59件，纠正漏捕漏诉401人，涵江区检察院提前介入侦查的曾某飞妨害传染病防治案获评全国检察机关首届优秀法律文书。坚持罪刑法定、疑罪从无，对不构成犯罪或证据不足的不批捕349人、不起诉32人，对认为确有错误的刑事判决抗诉13件。深化“派驻+巡回”检察机制，办理监管活动和刑罚执行监督案件1319人，纠正违法违规“减假暂”、社区矫正脱漏管等情形228件。依法履行检察侦查职能，立案侦结司法工作人员徇私枉法等职务犯罪3件4人，捍卫司法公正。
　　民事监督更有力。加强对民事生效裁判、审判活动和执行活动全流程监督，共办理民事诉讼监督案件522件，对认为确有错误的生效裁判抗诉11件、发出再审检察建议21件；纠正民事立案、审判、执行等程序违法情形188件。持续深化虚假诉讼专项监督，办理“套路贷”等类型虚假诉讼案件22件，涉案金额1054万元；加大拒不执行生效裁判案件办理力度，移送犯罪线索46件50人，涉案金额2695万元，维护当事人权益。积极运用检察和解机制定纷止争14件，秀屿区检察院促成一件军属历时两年未得到人身损害赔偿的案件和解结案，实现案结事了人和。 
　　行政监督更规范。加强府检联动，专项开展土地执法、道路交通安全、社会抚养费征收等领域行政检察监督，督促职能部门规范履职63件，纠正行政非诉执行违法情形30件，助力法治政府建设。落实检察监督与行政执法双向衔接制度，加大行刑反向衔接力度，向行政执法部门制发检察意见41件，形成司法执法合力。把实质性化解行政争议贯通检察履职全过程，办理不服生效行政裁判监督案件55件，化解产权登记、行政赔偿、行政协议履行等行政争议34件。对办案中发现的多名群众身份信息被冒用登记婚姻情况，听证核查事实，督促撤销登记，促进依法行政。
　　公益诉讼更精准。扛牢公共利益代表神圣职责，办理公益诉讼案件432件，“4+10”法定领域保护力度持续加大，新领域案件稳步拓展。加强国有财产、国有土地公益诉讼监督，督促征缴入库土地出让金等1143万元，盘活闲置土地123亩。专项开展涉台、涉侨和省级以上文物古迹公益诉讼监督，共办案30件，督促文保单位修缮与活化利用37处，用法治力量护卫历史文化名城。综合用好磋商、圆桌会议、特邀检察官助理参与办案等机制，促成绝大多数公益受损情形解决在诉前。涵江区检察院、荔城区检察院召集军地圆桌会议，合力清障军事航道70余海里，把公益诉讼案件做成一堂生动的国防安全和法治教育课。
　　五、淬炼担当实干检察品格，同源共流锻造过硬形象
　　牢记法治重托，聚焦打造一支高素质检察队伍能动履职，让求真务实、担当实干成为新时代新征程检察人员的鲜明特征。
　　政治建检铸魂明志。强化政治机关意识，严格贯彻《中国共产党政法工作条例》，严格执行重大事项请示报告等制度，自觉接受政治监督。抓实政治忠诚教育和职业精神培育，深化“党建红+检察蓝”机制，党组表率示范，建强支部堡垒，开展“旗帜鲜明讲政治、依法能动履好职”专项政治督察、国家宪法日宣誓等活动，用好莆检青年课堂等载体，学习身边榜样，争当先进典型。全市检察机关70个集体、188人次获得市级以上表彰，其中，省级表彰110次、国家级表彰25次，涵江区检察院骆志峰在全国检察机关第十次“双先”表彰中荣记一等功。
　　素能强检培元固本。着力人人皆可成才、人人尽展其才，开展“争先争优争效、评案评庭评选”、检律论辩赛、法律文书练赛评选、同堂培训等训赛练考活动3081人次，分层分类提升检察人员业务能力，年内10个案例入选省级以上优秀或典型案例。鼓励思行结合、一专多能，立项省级以上调研课题9项，撰写调研文章118篇，获省级以上奖项46篇，再次斩获全省检察理论年会一等奖，23人次在海峡法治论坛等平台交流学术成果。检察人才队伍持续壮大，12名干警入选全省检察机关人才库，3名入选最高检人才库，涵江区检察院姚舟获评第五批全国检察业务专家。
　　科学管检争先创优。坚持全员全面全时考核，完善案件质量与检察人员业绩有机衔接的考核体系，两级院领导干部直接办案1012件，“案-件比”指标持续优于最高检通报值，3项工作经验在全省检察机关推广。发挥基层院建设评价体系导向作用，打造基层检察工作品牌矩阵，仙游县检察院“木兰守护”机制、城厢区检察院“检察官驿站”机制获评全省检察机关首届“一院一品”优秀典型事例。积极实践数字检察，全省政法跨部门大数据办案平台全面上线运行，涵江区检察院“毒品犯罪洗钱线索法律监督模型”获评全省检察机关首届大数据建模竞赛优秀奖。
　　从严治检正风肃纪。扛起全面从严管党治检责任，完善廉政教育、检察人员家属禁业清单、年轻干部监督管理等机制，严格落实新时代政法干警“十个严禁”铁规禁令。严格落实司法责任制，坚持有问必录、逢案必倒查，全市检察人员填报记录“三个规定”事项262件次，专项开展执法司法突出问题查纠整改等工作，织密防范廉洁风险制度笼子。健全与驻院纪检监察组专题会商等工作机制，运用监督执纪“四种形态”问责违纪违法检察人员4人，始终以严的基调、实的举措促进检察队伍风清气正。
　　铭记人民检察向人民负责、受人民监督。向市人大常委会专项报告优化营商环境等工作，配合开展专题调研、立法咨询、执法检查等工作，扎实办好代表意见议案，自觉接受人大监督。定期向民主党派、工商联和无党派人士通报检察工作，自觉接受民主监督。完善挂钩联系人大代表、政协委员机制，邀请观摩评议庭、参加检察开放日、公诉人论辩赛等活动52场168人次，召开听取意见建议座谈会11场，在工作互动中汲取真知灼见，践诺全过程人民民主庄严承诺。
　　各位代表，过去的2023年是莆田建市40周年，也是市检察院建院40周年，我们在日新月异的城市进步中与有荣光、倍增自豪！全市检察工作一路走来、稳步向前，是在市委和上级检察院坚强领导、市人大及其常委会有力监督、市政府关心帮助、市政协民主监督和人大代表、政协委员及社会各界大力支持下团结奋斗得来的。在此，我代表市检察院表示衷心感谢和崇高敬意！ 
　　同时，我们也清醒看到差距：学习贯彻习近平法治思想还需走深做实；服务保障绿色高质量发展的质效仍需进一步提升；检察为民实事的广度深度有待拓展；“四大检察”发展不协调不充分情形亟须攻克补强；检察权运行监督制约机制仍需织密筑牢。问题就是责任，我们将紧抓不放，努力把工作做得更好。
　　2024年是新中国成立75周年，是实施“十四五”规划的关键一年。全市检察机关将坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平法治思想，胸怀国之大者，高质效履行法律监督职责，为加快建设绿色高质量发展先行市、奋力答好谱写中国式现代化福建篇章的莆田答卷贡献检察智慧和力量。
　　一、坚持大局为重，服务高质量发展建新功。久久为功贯彻习近平总书记关于治理木兰溪的重要理念和保护好湄洲岛的重要嘱托，发挥“生态检察+公益诉讼”职能，服务生态文明建设。始终秉持服务经济、善意司法理念，深化合规改革、知识产权保护等工作，更有力服务民营经济强市战略。聚焦两岸融合发展等新部署新要求，不断跟进优化检察法治产品，提升服务保障质效。
　　二、坚持稳定为基，保障高水平安全建新功。树牢总体国家安全观，常态化推进扫黑除恶斗争，依法打击整治严重危害社会安定、人民安宁的犯罪，维护社会安定稳定。贯彻宽严相济刑事政策，加大轻罪类案规律研究，持续推动轻罪治理，最大努力修复受损社会关系、增进和谐内生因素。注重抓前端、治未病，充分用好用实检察建议等法治方式，促进溯源治理、综合治理。
　　三、坚持民生为本，增进高品质福祉建新功。深度融入“党建引领、夯基惠民”工程，畅通服务基层最后一公里。规范落实群众信访件件有回复、未检综合履职、特殊弱势群体权益保障等机制，将心比心办好群众的操心事揪心事烦心事。加大食药、住行、网络等民生领域监督办案力度，拓展深化为民办实事系列活动，不断做实人民群众可感受、能体验、得实惠的检察为民。
　　四、坚持公正为要，提升高质效监督建新功。充分发挥“四大检察”一体履职、综合履职效能，进一步强化法律监督，维护司法公正，促进依法行政，守护公共利益。加强与其他执法司法机关协作配合，高质效办好每一个案件，努力让人民群众在每一个司法案件中感受到公平正义。积极融入“全市一张图、全域数字化”部署，促进数字检察实践转化，赋能法律监督提质增效。
　　五、坚持严实为标，塑造高素质队伍建新功。擦亮检察机关政治底色，浓厚一切检察工作从政治上着眼、法治上着力的政治文化氛围。持之以恒抓基层打基础，培养更多领军人才，培树更多先进典型，推动两级检察院工作质效整体提升。统筹抓实政治建设、业务建设和职业道德建设，一体推进从严管理监督和鼓励担当作为，锤炼过硬队伍，在新征程伟大实践中展现检察风采。
　　各位代表，千川汇海阔，风好正扬帆！全市检察机关将更加紧密团结在以习近平同志为核心的党中央周围，紧紧依靠市委领导、市人大及其常委会监督、市政府、市政协及社会各界支持帮助，认真落实本次大会决议，担当实干，努力为加快建设绿色高质量发展先行市、奋力答好谱写中国式现代化福建篇章的莆田答卷作出新的更大检察贡献，以优异成绩献礼新中国成立75周年！
