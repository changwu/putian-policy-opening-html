我市多方位推进“无废城市”建设

来源:湄洲日报 时间：2024-01-11 08:00
| | | |
　　变废为“能”，生活垃圾开启“奇幻”之旅。垃圾焚烧产生的热能转化为高温蒸汽，推动汽轮机转动，使发电机产生电能；焚烧后产生的炉渣，则以制作环保建材等形式循环利用……冬日时节，走进位于秀屿区东庄镇的莆田市圣元环保电力有限公司，高耸的烟囱顶端被打造成咖啡厅，边喝咖啡边看风景，令人耳目一新。
　　无废小区、无废村落、无废酒店、无废景区、无废商场、无废学校、无废机关……如今，行走在莆田，随处可见“无废细胞”。
　　2022年4月，莆田市入选“十四五”时期“无废城市”建设名单。市委、市政府高度重视，先后成立“无废城市”建设工作领导小组、建设工作专班，立足莆田市经济社会发展和生态环境保护实际，印发《莆田市“十四五”时期“无废城市”建设实施方案》，全面启动“无废城市”建设工作，持续聚焦工业、农业渔业、生活垃圾、再生资源和危险废物等各领域固体废物污染防治难点。同时，我市还印发《莆田市“无废细胞”建设指南》《莆田市“无废鞋业”建设指南》《莆田市“无废啤酒业”建设指南》《莆田市“无废轮胎业”建设指南》等具有本土特色的“无废细胞”建设指南，推动减污降碳协同增效，全力推进固废治理体系和治理能力现代化，为加快建设绿色高质量发展先行市贡献力量。
　　A
　　培育“无废细胞”　厚植“无废城市”理念
　　如果把城市看作人体，工厂、小区、学校、酒店、商场、景区等，就可以看成是其“细胞”。建设“无废城市”，最基本的工作是从培育“无废细胞”开始。“无废细胞”是“无废城市”建设工作的重要载体，也是社会生活中各个充分运用“无废”理念的组成单元。
　　去年7月份，我市在省内率先印发《莆田市“无废细胞”建设指南》，以“无废村落”“无废物业住宅小区”“无废机关”“无废工厂”“无废学校”“无废酒店”“无废商场”“无废景区”等八大领域作为“无废细胞”建设重点，全面启动“无废细胞”创建工作，以点带面，发挥示范引领效应。
　　作为产废的“主力军”，工厂企业在“无废城市”建设当中担当着重要角色，必须成为践行绿色发展方式的先行者。市生态环境局结合本地行业特点,与福建荔丰鞋业有限公司、百威英博雪津啤酒公司、福建佳通轮胎有限公司等代表性企业共同打造出三个具有本市特色亮点的“无废细胞”建设指南——《莆田市“无废鞋业”建设指南》《莆田市“无废啤酒业”建设指南》《莆田市“无废轮胎业”建设指南》。
　　来到百威雪津啤酒有限公司，一条条生产线开足马力运转，这里年产200万吨啤酒，生产过程中自然会产生出各种各样的废料，主要包括酵母、玻璃、纸箱、易拉罐、塑料、污泥硅藻土等。结合企业绿色发展需求，在市生态环境局的指导下，去年10月，百威雪津完成省内首家“无废啤酒业”创建。
　　目前，工厂使用的啤酒纸箱85%以上由再生纸浆制成，55%以上的玻璃啤酒瓶由回收玻璃瓶制成，25%以上的易拉罐由回收易拉罐制成。在啤酒生产、罐装过程中，百威雪津通过探索新工艺、新技术，合理利用资源，减少生产过程中原辅料的损耗，逐年降低废弃物的产生量。
　　推进“无废城市”建设，就是要在生产、收集、转移、利用、处置每个环节，圈出更多“变废为宝”的闭合曲线。
　　在“无废啤酒业”创建中，建设指南要求最大比例地使用再生资源。如工厂使用的啤酒纸箱，85%以上须由再生纸浆制成、55%以上的玻璃啤酒瓶须由回收玻璃瓶制成、25%以上的易拉罐须由回收易拉罐制成。
　　在“无废鞋业”创建中，建设指南要求制鞋全流程源头减量。如面材主材是真皮的鞋型的鞋面边料固废标准须少于 165 克/双、非真皮的鞋型的鞋面边料固废标准须少于 144 克/双。对于其他各制程产生的其他固废，如废塑料线芯、废塑料栈板、废木栈板、包装纸箱、纸板纸筒等废纸类等也有严格的减量标准。
　　在“无废轮胎业”创建中，建设指南要求不断优化生产工艺，在生产工程中减少废弃物产生，如全钢子午轮胎生产线每单位产品废胶、废尼龙帘等产生量要求不多于0.2千克。
　　“无废城市”建设给生态环境带来改变的同时，也给固废处理市场带来巨大发展空间。我市印发《莆田市再生资源回收体系建设2023年工作要点》，成立市商务局再生资源回收体系建设领导小组，引导生产工厂、商铺与回收企业签订长期回收协议，回收企业定期上门回收，有效促进低价值可回收物工作开展，减少环境污染。
　　截至目前，全市已申报创建“无废村落”30家、“无废小区”10家、“无废机关”16家、“无废工厂”20家、“无废学校”11家、“无废酒店”4家、“无废商场”2家、“无废景区”4家，共计96个“无废细胞”，努力营造“无废城市”共建共享的良好氛围。
　　B
　　践行垃圾分类　让绿色低碳深入人心
　　走进荔城区拱辰街道立丰·左岸蓝湾生活小区，只见垃圾分类屋和周围环境相得益彰。内墙陈设垃圾分类小知识等，以图文结合的形式让居民理解如何进行垃圾分类，提高民众对垃圾分类的重视度。
　　漫步小区内还可看到，精心建设的环保驿站，设置了废品回收区、垃圾分类科普宣传墙、共享图书角、变废为宝手工作品展示区、闲置物品互换区等，俨然是一座寓教于乐的垃圾分类宣传基地，也将“无废”理念传达给群众。
　　“无废城市”建设是推动绿色低碳、循环发展的重要举措，其中推广垃圾分类、完善收集、转运、处理体系是其中的重要一环。我市在推进“无废城市”建设过程中，按照“政府主导，共同参与、因地制宜，科学实施、教育引导，示范引领、源头减量，系统治理”的原则，积极推广垃圾分类，不断完善收集、转运、处理体系，取得了显著成效。
　　在城区全面推行生活垃圾分类工作，居民知晓率达95.1%，参与率达89.5％，回收利用率达36%以上。在住建部对全国生活垃圾分类工作的每季度系统评估中，我市在中等城市中位居第二档，成效初显，超全国同类城市七成以上。2023年，我市在首届全国城市生活垃圾分类宣传周“垃圾分类新时尚、全民参与齐点亮”活动中，荣获全国城市生活垃圾分类全民活动城市组三等奖。
　　持续推进分类屋建设。150座分类屋（亭）建设列入市委、市政府为民办实事项目，已全部完工。目前全市共建有分类屋（亭）841座，设置有害垃圾暂存点12座、厨余垃圾集中点8个；加强餐厨垃圾处置。截至目前，全市共摸底餐厨垃圾产生单位8454家，共投入2048万元，设102条餐厨垃圾收运路线，已收运处置餐厨垃圾32974吨，近期日餐厨垃圾收运量约达105吨。全市餐厨废弃油脂实行市场化模式收运和政府公益性模式收运，共收运废弃油脂约2383吨，餐厨垃圾处置场处置餐厨垃圾产生粗油脂1820.6吨，发电量4894704千瓦时，无害化处理率达100%。
　　在末端分类处理上，我市将其他垃圾运至圣元生活垃圾焚烧发电厂或仙游兴鸿生活垃圾焚烧发电厂处理；有害垃圾进入市固体废物综合处置厂处理；可回收物依托再生资源回收和利用体系由6家回收企业处理；大件垃圾由收集破解处置厂进行分类破碎处理后，再转交再生资源回收企业进行二次加工实现资源化利用或运往圣元生活垃圾焚烧发电厂进行焚烧发电；厨余垃圾转运至圣元厨余垃圾处置场处置，谱写创建绿色城市的新篇章。
　　C
　　健全绿色体系　源头减量促循环发展
　　在“无废城市”的建设中，源头减量是至关重要的一环。
　　在工业领域，我市加快推动鞋服、电子信息、新型功能材料、高端装备等重点行业企业开展绿色化改造，鼓励工业企业、园区创建绿色工厂和绿色工业园区，构建高效、清洁、低碳、循环的绿色制造体系。湄洲湾国投经开区、华林经开区等2个园区和赛隆科技、才子服饰等6家企业入围省级绿色制造名单；赛隆科技、祥恒包装2家企业进入工信部绿色工厂公示名单，湄洲湾国投经开区进入工信部绿色工业园区公示名单。我市现有国家级绿色工厂10家，国家级绿色工业园区2家，拥有省级绿色制造品牌26家。
　　同时，我市强化资源循环利用。按照减量化、再利用、资源化原则，通过推动园区循环化改造，示范带动工业企业绿色、循环化改造，实现资源利用最大化、废水循环利用、固废资源化和无害化利用。高新区、华林经开区、石门澳产业园3个园区循环化改造实施方案通过省级评审。2023年3月13日，市发改委、市场监管局联合推荐“聚酯瓶高值化回收循环利用标准化试点”上报2023年国家循环经济标准试点示范项目。
　　农业领域，我市推进畜禽养殖粪污资源化利用。根据《莆田市畜禽养殖标准化示范创建活动方案（2021-2025）》，我市分阶段分地区推动规模化养殖场粪污收集处理设施升级，逐场排查规模化畜禽养殖场粪污收集和处理设备安装与运行情况，全市累计完成24家省级以上标准示范场创建，占全部畜禽养殖场的11.7%。截至2023年11月底，莆田市畜禽粪污综合利用率达97%，全市规模养殖场粪污处理设施装备配套率达100%。组织开展农药包装废弃物回收宣传工作，依法加强对农药包装废弃物回收工作的日常监督与管理。2023年，全市农药包装废弃物回收95.93吨，回收率达52.59%，发放宣传资料7290份。
　　渔业方面，我市全面落实海上养殖设施转型升级。大力推进木质渔排、泡沫浮球等渔业设施更新改造，推广应用环保型塑胶材料，扎实推进《莆田市海上养殖转型升级行动方案》和《莆田市海上养殖设施建设技术要求（试行）》等文件要求。截至目前，已超额完成省下达我市海上养殖转型升级建设任务。
　　建筑领域，我市严格执行《福建省绿色建筑发展条例》,全面实行《福建省绿色建筑设计标准》,大力推动我市绿色建筑的发展。2023年，我市新增民用建筑设计项目248个，总建筑面积1041.7万平方米，均为绿色建筑面积，设计绿色建筑面积占民用建筑面积比例达100%;民用建筑竣工项目79个，建筑面积为346.05万平方米，均为绿色建筑面积，城镇绿色建筑占新建建筑比重为100%,超过省住建厅要求占比达93%的年度目标。
　　建设“无废城市”是为了优化资源利用，实现城市可持续发展，让人民群众生活更美好。下一步，我市将持续加强宣传引导，将“无废”理念融入居民日常生活，通过健全制度保障、推进重点任务、实施重点工程，将莆田市打造为理念先进、特点突出、全民参与、成效显著的“无废城市”建设典范，助力深入打好污染防治攻坚战、建设美丽莆田、推动绿色低碳高质量发展，为福建省和全国提供可复制可推广的经验借鉴。
　　倡议书
　　“无废城市”是以“创新、协调、绿色、开放、共享”理念为引领，通过推动形成绿色发展方式和生活方式，持续推进固体废物源头减量和资源化利用，将固体废物环境影响降至最低的城市发展模式。当前，莆田市“无废城市”建设的冲锋号已经吹响，为深入贯彻《莆田市“十四五”时期“无废城市”建设实施方案》和市委、市政府工作部署要求，营造“无废城市”共建共享、社会参与的良好氛围，在此我们倡议：
　　一、争当“无废城市”建设的传播者
　　主动承担起传播“无废城市”理念的使命，全面增强生态文明意识，把“无废城市”建设作为深入践行“两山”理念的具体行动，积极倡导生态优先、绿色发展、文明生活的生产生活方式，号召更多人关注和宣传“无废城市”的理念，科普“无废城市”知识，讲好莆田“无废城市”建设故事，动员广大亲朋好友成为莆田“无废城市”建设的宣传者、传播者。
　　二、争当“无废城市”建设的推动者
　　“无废城市”建设是一项系统工程，需要凝聚各方共识和力量，形成工作合力。每一家企事业单位、每一位莆田人，都应积极参与到莆田“无废城市”建设中，推动更多人参与到“无废小区”“无废村落”“无废工厂”“无废学校”“无废酒店”“无废景区”等“无废细胞”的创建中，引领和带动广大市民携手共创绿水青山、生态宜居的美丽家园，形成全社会共同参与的良好氛围。
　　三、争当“无废城市”建设的践行者
　　“无废城市”建设依靠人民，“无废城市”建设成果人民共享。让我们携起手来，从我做起，从现在做起，把“无废城市”建设融入到工作生活中，主动使用可循环利用物品，减少购买过度包装商品及一次性用品，最大限度减少固废产生；主动正确地进行垃圾分类，倡导绿色、低碳、环保的生活方式；创新技术攻坚，持续推进固废源头减量和资源化利用，协同促进产业结构转型升级、淘汰落后产能，形成源头减量和资源循环利用体系，让节约降碳的生活方式成为社会的新时尚。
　　市民朋友们，美好宜居、景色宜人的生活环境是我们全市人民的共同期盼，也是我们共同的责任和义务。让我们积极行动起来，共建生态文明，共享绿色未来，厚植“无废”理念，崇尚“无废”生活，推进“无废”发展，用我们的智慧和力量为莆田市“无废城市”建设和建设绿色高质量发展先行市作出自己应有的贡献！

　　本版组稿：陈磊　蔡昊　陈斌
