我市市场物价公众评议工作阶段性提升显成效

来源:湄洲日报 时间：2023-08-15 07:00
| | | |

　　2023年市场物价公众评议提升工作由市发改委牵头，市农业农村局、商务局、市场监管局等多部门共同参与，各部门按照《莆田市2023年度省对市绩效管理市场物价公众评议工作提升方案》要求，密切配合，认真落实“菜篮子”市长负责制，做好整改提升工作，现将整改提升工作阶段性落实情况公布如下：

　　稳固农副产品生产能力方面

　　提高蔬菜生产能力。突出区域优势，扩大优势蔬菜生产规模，强化田间管理，进一步提高蔬菜生产能力，增加绿色优质蔬菜供应。据调查，1-7月全市蔬菜播种面积21.44万亩，产量39.88万吨，比上年同期增长6%。蔬菜产销发展总体平稳，蔬菜生产发展方式不断转变。稳固生猪产能。制定《莆田市生猪产能调控实施方案》（暂行），明确任务分配，定期通报能繁母猪存栏量及产能预警研判稳定市场预期，科学调整生产布局，加强生猪产能调控。制定对应的领导挂钩机制，由各县区农业农村局领导直接挂钩全市在养生猪规模养殖场，了解跟踪各养殖企业的难点痛点，帮助养殖户解决具体技术难题，对应政策解析，助力生猪稳产保供。根据畜牧产业监测数据预计：截止2023年7月，全市生猪规模场数量为110个，能繁母猪数量3.64万头。（责任单位：市农业农村局）

　　保障市场供应充足方面

　　持续推进农贸市场标准化改造。印发《为民办实事活动农贸市场改造提升项目实施方案》，细化农贸市场改造提升建设参考标准，明确2023年度市场改造计划。截至目前，全市共有农贸（批发）市场约60家。加强生活必需品市场监测，制定出台《莆田市商务局生活必需品应急保供工作方案》，发挥市、县（区）联动工作机制，建立健全生活必需品应急保供监测机制，强化对重点保供企业的跟踪监测，指导各县（区、管委会）引导重点保供企业及重点副食品调控基地根据市场需要，适时加大物资采购调动频次和储备力度，市场供应充足稳定。加强城市副食品基地建设。建立省级城市副食品调控基地11家，1-7月份出栏生猪2.4万头，上市蔬菜2.9万吨，上市蛋品3500吨，上市肉禽255万羽，已完成200吨冻猪肉储备入库任务，主要储备品种为冻猪大排肌肉、冻五花肉、冻腿肉等。继续深化粮食产销协作。与无锡市、三明市、江西省粮油集团公司签订了粮食产销协作框架协议，组织了市内15家粮食企业参加第十八届粮洽会，签订10.5万吨粮食购销意向协议，进一步拓宽入莆粮源。组织各粮油企业积极引粮入莆，1-7月累计从市外调入粮食39万吨，有效保障了市内粮油供需总量平衡。（责任单位：市商务局、发改委）

　　引导市场价格合理运行方面

　　强化重要民生商品价格监测预警。1-7月份累计采集、发布上报各类监测信息693条和粮油价格监测周报28期，及时发布各类价格信息，引导和稳定市场预期。适时启动平价商店销售机制。春节期间全市启动平价商店49家，通过政府补助和企业让利相结合的形式，以相对优惠的价格销售粮、油、肉、蛋、菜等平价商品300多吨，引导和促进市场价格保持基本平稳。 严格落实社会救助和保障标准与物价上涨挂钩联动机制。及时向困难群众发放价格临时补贴，今年以来已发放价格临时补贴556.859万元，惠及群众18.33万人次，切实缓解困难群众因物价上涨而造成的影响。（责任单位：市发改委）

　　维护市场价格秩序良好方面

　　加强告诫提醒。关口前移，提前通过微信公众号、微信群、媒体报道等方式发出《关于规范市场经营者价格行为重要提醒》和《规范市场经营者价格行为提醒函》、《关于规范“五一”节日期间旅游市场价格行为提醒告诫书》等，提醒各经营者严格遵守《价格法》等法律法规，要求其不得囤货居奇、哄抬物价、牟取暴利以及散布涨价谣言，积极落实主体责任，加强价格自律，并引导群众合理消费。及时回应社会关切。畅通12315、12345投诉举报渠道，建立健全投诉举报快速受理、快速核实、快速处理机制，及时处理、有效反馈群众价格诉求，及时回应社会关切。强化价格检查。强化与相关部门的协调和联系，开展联合检查，特别是对供应偏紧、价格上涨较快的商品，加大检查频次。密切关注重要民生商品市场价格和舆情动态，开展春节、五一节前民生商品、旅游市场价格专项检查，确保重要节点市场价格基本稳定。加大市场巡查力度，坚持日常监管与重点抽查相结合的方式，加大重要节点和日常对商超、农贸市场、药店等重要场所价格巡查频次，今年以来我市市场监管系统共出动执法人员7128人次，检查经营点6625家次，立案价格案件19起，有力维护了我市价格秩序的稳定。（责任单位：市市场监督管理局）

　　合理引导市场预期方面

　　进一步深化政务公开，加大政解读，加强正面宣传报道，释放良好预期。各部门通过报纸、网站、电视台、移动新媒体等多种方式大力宣传全力做好市场供应保障、平价商店、农业抗台救灾减灾和灾后复产指导等保供稳价、稳固生产能力的工作举措和工作成效，通过积极正面的宣传报道，提振群众对政府保供稳价的信心，树立了正确的舆论导向。同时，通过《湄洲日报》、政府网站公布2023年提升方案，接受群众监督。（责任单位：市发改委、农业农村局、商务局、市场监督管理局）
