莆田市人民检察院工作报告

——2025年1月8日在莆田市第八届人民代表大会第五次会议上
来源:湄洲日报 时间：2025-01-29 08:38
| | | |
莆田市人民检察院检察长 李峻
各位代表：
　　现在，我代表市人民检察院向大会报告工作，请予审议，并请市政协委员和列席会议的同志提出意见。
　　过去的一年，全市检察机关在市委和省检察院领导、市人大及其常委会监督、市政府、市政协及社会各界关心支持下，坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十大和二十届二中、三中全会精神，深入学习贯彻习近平总书记在福建考察时的重要讲话精神，紧扣市委决策部署和市人大各项决议，从政治上着眼、从法治上着力，把“高质效办好每一个案件”作为基本价值追求，实事求是、稳进争优，依法忠实履行法律监督职责，为加快建设绿色高质量发展先行市提供有力司法保障。一年来，共受理各类案件和事项17462件，法定期限内办结率100%；5个案件获评全国检察机关优秀典型案例，16个获评全省检察机关优秀典型案例，均创近年新高；68个集体、254人次获得市级以上荣誉，比增24%，其中国家级荣誉51次、省级荣誉115次，各项检察工作取得新进展。
　　一、坚定不移为大局服务，护航发展要务
　　服务保障高质量发展是检察履职重大政治使命，坚持检察政策与宏观政策取向一致性，旗帜鲜明讲政治、顾大局。
　　坚持党的绝对领导。提高政治判断力，深学细照笃行习近平总书记在福建考察时的重要讲话精神，高标准、严要求开展党纪学习教育，坚定拥护“两个确立”、坚决做到“两个维护”。提高政治领悟力，实现对全市检察机关政治督察、检察人员政治轮训两个全覆盖，坚持党的中心工作推进到哪里，检察工作就跟进到哪里。提高政治执行力，对标市委“一五二三四”工作部署、“五抓五比五看”活动，确定30项落实要点，细化“检察护企”“检护民生”专项行动等52项举措，向市委请示报告33件次，坚决做到检察工作方向由党指引、原则由党确定、决策由党统领。
　　优化法治营商环境。跟进服务重点产业链发展，在园区延伸设立20个检企联络点，有呼即应、无事不扰，“厂门口”高效办复涉企服务141件，比增26%，“一产业链一检察服务专班”机制获评全省“检察护企”专项行动优秀事例。积极服务新质生产力发展，先后同华峰华锦等企业建立亲清检企共建机制，发挥检察法治“智库”作用，协同依法保护商业秘密等核心竞争力。助力提升可持续发展能力，聚焦企业常见的12类法治风险，制作“检护企航”系列法治宣传视频合集，在“天下莆人”等莆商莆侨交流平台转载共享，阅读量超1.3万次，打造涉企法治服务新样板。
　　维护市场经济秩序。严惩严重经济犯罪，对侵犯各种所有制经济产权和合法利益行为实行同责同罪同罚，起诉走私、合同诈骗等破坏市场经济秩序犯罪475人；起诉制假售假等侵犯知识产权犯罪146人；起诉职务侵占、挪用资金等企业内部人员犯罪27人，追赃挽损541万元。防范化解重大风险，会同税务等7部门会签备忘录，稳妥办理涉税、黄金期货等案件25人，涉案金额2.3亿元；严惩利用“空壳公司”实施集资诈骗等经济金融犯罪23人，涉案金额167亿元。营造公平竞争环境，深化行政检察护航营商环境专项监督，督促职能部门整治不正当竞争等情形61件，比增84%，做实一视同仁对待、依法平等保护各类经营主体。
　　助力企业纾困发展。坚持以让企业发展有信心、能放心、更安心为目标，高质效办理涉企案件，规范涉企刑事案件监督，联合公安机关专项整治趋利性执法司法情形，依法稳慎适用强制措施，健全清理涉企挂案等机制，监督撤案一起长达17年的涉企挂案。加大对侵害企业权益案件执行监督力度，依法督促执行生效刑事裁判876件、涉及金额5.17亿元。会同社矫机关规范流程、简化手续，依法批准涉企社矫对象外出从事经营活动55人次。加强涉企民商事案件检察和解、行政争议实质性化解机制适用，荔城区检察院促成某企业经营场地“入驻难”行政争议实质性化解，该案获评全省检察机关服务民营经济强省战略十大优秀案例。
　　二、坚定不移为治理赋能，助推良法善治
　　维护社会安定、人民安宁是检察履职重大政治责任，全面贯彻总体国家安全观，融入共建共治共享社会治理制度建设。
　　全力守护平安莆田。贯彻宽严相济刑事政策，该严则严，批捕各类犯罪2325人、起诉4058人。严惩危害社会稳定犯罪，起诉故意杀人、涉黑恶等严重暴力犯罪177人，起诉黄赌毒等妨害社会管理秩序犯罪719人。依法履行惩治腐败职能，一体抓实监检衔接和检察侦查工作，起诉国家工作人员职务犯罪案件36件39人，协同推进受贿行贿一起查，城厢区检察院起诉的杨某文行贿等罪一案获评全国检察机关惩治行贿犯罪典型案例；市检察院设立查办司法工作人员相关职务犯罪专门机构，立案侦结全市首例“机动侦查权”案件，坚决落实党中央反腐败决策部署。
　　务实推进轻罪治理。坚持依法当宽则宽，对情节轻微、主观恶性和社会危险性不大的，不批捕296人、不起诉421人，减少对抗、增进和谐。规范适用认罪认罚从宽制度，严格落实量刑协商同步录音录像等机制，3672名犯罪嫌疑人在检察环节认罪认罚，一审服判率超过97%。深化探索“全流程速裁”轻罪治理创新实践省级试点，适用罪名增至34个，持续推进繁简分流、轻重分离、快慢分道。协同各方治理轻罪，会同公法司等机关严格贯彻“两高两部”办理醉驾案件新规，形成教育惩戒、行政处罚与刑事追究衔接的治理体系，醉驾案件起诉数量降至5年来最低。
　　深入化解矛盾纠纷。践诺群众来信来访必复，落实信访法治化“路线图”，2604件群众信访均严格做到“件件有回复”两个100%，实现权责明、底数清、依法办、秩序好。注重实质化解矛盾纠纷，一案一策推动重复信访等案件罢诉息访122件，重复信访比降31%。强化源头定分止争，践行“枫桥经验”，开展“化解矛盾风险、维护社会稳定”专项治理等工作，204名检察官融入镇街综治中心、挂钩结对村居，在萝苜田等地建立邻里检察听证室，探索“和风细屿”等检调衔接机制，对当事人争议大、有心结的案件，组织听证235件，比增21%，促进事心双解和为贵。
　　积极促进综合治理。发挥检察建议促治作用，融入“党建引领、夯基惠民”工程，制发社会治理类检察建议49件，涉及易制毒、易燃易爆物品等23个公共安全领域，全部得到被建议单位“两个月”内办复。市检察院制发规范民俗活动“黑火药”安全监管的检察建议获评年度全省十佳。开展检护质量安全行动，加大枇杷、文旦柚等农特产品地理标志司法保护力度，服务乡村振兴战略。方言俚语讲述群众身边法治故事，仙游县检察院携手鲤声剧团编演防治校园欺凌莆仙戏短剧、邀请方言主持人制作“秋生说故事”系列法治节目，受众超15万人次，多维融合传播法治风尚。
　　三、坚定不移为人民司法，保障民生福祉
　　人民群众对美好生活的向往是检察履职的初心和方向，坚持民有所呼、检有所应，把心贴近人民，如我在诉践行司法为民。
　　服务灵秀莆田建设。久久为功贯彻落实习近平总书记关于治理木兰溪的重要理念和保护好湄洲岛的重要嘱托，健全“生态检察+公益诉讼”机制，起诉破坏生态环境资源犯罪65人，办理涉“山水林田湖湿地”公益诉讼案件146件。密切跨部门生态修复协作，会同6个镇街等单位共建碳汇林590亩，联合水利等5部门建成湿地、红树林等司法保护实践基地9个，督促当事人认购碳汇1.1万吨，促进碳汇修复机制精准落地。凝聚跨市域生态司法合力，联合环戴云山“四市六县”共建木兰溪源生态检察联盟，织密“壶山兰水检察蓝”矩阵，共同保护“母亲河”碧水安澜。
　　保障群众身边安全。守护“钱袋子”安全，严打电诈及其关联犯罪545人，“查冻扣”涉案款物996万元。守护“看病钱”安全，依法打击“假病人”“假医嘱”等骗取医社保行为，起诉16人，追赃挽损483万元。守护“指尖上”安全，起诉利用网络等侵犯公民个人信息犯罪12人，追缴赔偿金61万元。守护“头顶上”“脚底下”安全，督促整治公共道路安全等隐患75处。守护“舌尖上”安全，起诉危害食药安全犯罪33人，办理刑事附带民事公益诉讼50件，追缴惩罚性赔偿金180万元，督促主管机关将34人列入食药领域严重失信黑名单，让违法者“痛到不敢再犯”。
　　关爱未成年人成长。深化“木兰守护”未检机制，严惩侵害未成年人犯罪180人，妥善做好被害人“一站式”取证、心理疏导等综合救助。坚持惩治也是挽救，起诉严重犯罪未成年人124人。融促“六大保护”同向发力，向失责缺位“甩手家长”制发督促监护令297件，办理娱乐场所违规接待未成年人等公益诉讼案件42件。涵江区检察院促建留守侨童保护体系，获评全国检察机关保护侨胞权益五大典型案例。着力预防就是保护，检察官新增兼任57所山区校、海岛校法治副校长，汇编制作25集“木兰守护”未检法治教育视频合集，联合市教育局全覆盖向全市1165所中小学赠送，受众师生近60万人，引导少年有梦、法不可违。
　　办好暖心惠民实事。健全涉台检察“一室多员”机制，聘任21名台胞为检察工作联络员，维护台胞合法权益。加大支持起诉工作力度，支持讨薪农民工、交通事故受害人等弱势群体维权起诉99件，比增28%，帮助实现合法权益620万元。坚持应救助尽救助即救助，为53名困难当事人发放司法救助金106万元。开展无障碍环境公益诉讼监督活动，督促完善有关公共场所配套设施53处，有“爱”无碍保障残疾人权益。加强老年人权益保障，涵江区检察院推动建立养老机构从业人员入职查询等制度，禁止有虐待等侵害老年人权益的前科劣迹人员入职养老机构，获评最高检落实“十一号检察建议”十大典型案例，法护“夕阳红”。
　　四、坚定不移为法治担当，维护公平正义
　　法律监督是检察本职本源，坚持敢于监督、善于监督，努力在实体上确保实现公平正义、在程序上让公平正义更好更快实现、在效果上让人民群众在每一个司法案件中感受到公平正义。
　　持续做优刑事检察。坚持依法追诉犯罪，规范运行侦查监督与协作配合机制，监督立案100件、撤案179件，纠正漏捕漏诉386人。贯彻证据裁判原则，对不构成犯罪或证据不足的，不批捕449人、不起诉39人；对认为确有错误的刑事裁判提出抗诉12件。注重人权司法保障，纠正非法取证、超期羁押等情形145件。强化刑罚执行监督，深化“派驻+巡回”检察机制，办理监管活动和刑罚执行监督案件1212件，纠正违法违规“减假暂”、社区矫正脱漏管等情形98件，全过程参与、全流程监督刑事诉讼。
　　持续做强民事检察。注重监督纠错与维护既判力并重，办理民事检察案件477件，对认为确有错误的民事生效裁判提出抗诉或再审检察建议19件，纠正审判程序违法情形21件。加强对当事人的权利救济，纠正“套路贷”等类型虚假诉讼案件9件391万元；移送“拒执”犯罪线索26人，涉案金额3190万元。规范执行活动全程监督，开展终本执行等重点案件评查，提出检察建议119件。秀屿区检察院联合多部门以调促执，帮助罹患重病当事人及时获偿38万元，入选全省“检护民生”专项行动典型案例。
　　持续做实行政检察。坚持以行政诉讼监督为重心，自觉担起维护司法公正、促进依法行政的双重使命，办理行政检察案件236件。强化行政诉讼监督，对行政审判和执行活动违法情形提出检察建议25件。着力案结事了政和，结合办案向有关行政机关制发督促履职检察意见84件，协同推进征迁安置等行政争议实质性化解53件，比增50%。密切行刑双向衔接，依法督促行政执法机关移送涉嫌犯罪案件9件，防止以罚代刑；对被不起诉人应处以行政处罚的，移送主管机关罚当其错155人，共护法治权威。
　　持续做好公益诉讼。牢记“公共利益代表”职责，办理公益诉讼案件360件，其中“4+11”法定领域案件356件，知识产权保护等新领域案件4件。开展文物和文化遗产保护专项监督，督促文保单位修缮“台湾公”吴英文物遗存等9处，守护两岸文缘相承。注重办案效果，统筹用好磋商、检察建议等方式与行政机关充分沟通，绝大多数公益受损问题在诉前妥善解决，19个公益诉讼案件获评全省高质效案例。市检察院以制发磋商意见方式促成全市旅游景区规范落实军人军属优待政策，浓厚爱国拥军氛围。
　　五、坚定不移为事业强基，锻造检察铁军
　　全面从严管检治检是检察履职的重要保障，以永远在路上的坚韧和执着，淬炼求真务实、担当实干的过硬检察队伍。
　　强化政治能力。坚持抓党建强队建促业务，以深化党支部达标创星活动建强战斗堡垒，以“薪火相传”机制赓续检察红色基因，以“莆检书香”读书社厚植法治信仰，进一步完善“党旗红+检察蓝”机制，抓实理想信念和职业道德教育，让检察履职有灵魂有方向。践行“忠诚、为民、担当、公正、廉洁”新时代检察精神，开展“匠心砺检”“廉洁润心”等系列活动，提振争优、争先、争效精气神。党建引领效应持续显现，涌现出全省最美女检察官等一批新的先进榜样，诠释党心所向就是检心所往。
　　提升专业素能。聚焦提升高质效办案能力，开展优秀公诉人练赛、“评庭评案评选”等实战化练兵活动，分层分类进行全员训赛练考。强化比学赶超，组织基层院同福州、泉州两地5个优秀县区院结对共建，开展“检控前沿”疑难实务公、检、法、律等法律共同体同堂研讨48场次，互学互鉴、共同提升。注重思行互促，发挥检察理论调研源于司法实践、反哺履职办案作用，立项省级以上课题14项，调研文章获国家级奖项32篇次、省级54篇次，检察理论调研工作持续位列全省前茅。
　　夯实基层基础。坚持人才强基，加大“领军型”检察人才培育力度，新增3名全国检察机关人才库成员、3名全省检察业务专家、6名全省检察业务标兵能手。坚持选优任能，推动两级院业务骨干上下交流、轮岗锻炼，推荐选任2名县区院检察长，配强中层岗位11人，提任晋级41人，激励检察人员在办案一线勇担当、拼实绩。坚持为基层减负，注重基础设施建设与信息科技赋能并重，推动解决荔城区检察院“两房”选址难题，在全市推广应用4个大数据法律监督模型，助力检察履职提质增效。
　　严实检察管理。扛牢全面从严管检治检责任，抓实新时代政法干警“十条禁令”、防止干预司法“三个规定”等铁规禁令，制定《检风检纪督察实施办法》，持续加强队伍监督管理。坚持刀刃向内，健全检纪会商机制，“零容忍”查处违纪违法检察人员3人。强化检察权运行内部监督制约，构建“两书”制度与“三个管理”衔接机制，坚持定期研判业务态势与抽查评查案件质效相结合，动态纠正流程不规范、质效有瑕疵等情形68件，贯通管案管事管人，把司法责任制落实到每一个案件、每一名检察官。
　　六、坚定不移为履职聚力，自觉接受监督
　　检察权由人民赋予，必须向人民负责、受人民监督、让人民满意。自觉接受人大监督。向市人大常委会专题报告检察建议工作情况，围绕审议意见制定和落实16项改进举措。认真学习贯彻地方性法规，积极配合人大常委会开展立法咨询、专题调研、执法检查等工作。修订完善联络代表机制，两级院领导干部常态化走访代表283人次，邀请视察检察工作、参加检察开放日、听证会等活动96人次，真诚倾听意见、认真办理答复27件。承办市人大常委会交办的代表建议意见5件，满意率均为100%，2件主办件均获评办理工作优秀事例。自觉接受民主监督。定期向各民主党派、工商联和无党派人士通报工作，密切日常走访联络和工作衔接，逐一办复反馈5件意见建议。自觉接受各界监督。落实最高检、司法部、全国律协联合制定的十条意见，尊重和保障律师依法执业。深化检务公开，通过“两微一端”等媒介发布检察资讯1075条，保障社会各界知情权监督权，践行全过程人民民主。
　　各位代表，过去一年检察工作取得的新发展新进步，是市委和上级检察院坚强领导、市人大及其常委会有力监督、市政府关心帮助、市政协民主监督和人大代表、政协委员及社会各界大力支持的结果。在此，我代表市检察院表示衷心感谢和崇高敬意！
　　我们清醒认识到，检察工作还有不少薄弱环节：运用习近平法治思想指导检察履职仍需加强；服务发展、司法为民等措施还需更加精准实效；“四大检察”发展不协调不充分等情形仍存；检察管理还需改进和加强；队伍专业化水平还需持续提升。下一步，我们将直面问题，针对性改进措施，把工作做得更扎实更到位。
　　2025年是“十四五”规划收官、谋划“十五五”规划之年，是深入贯彻落实党的二十届三中全会和习近平总书记在福建考察时的重要讲话精神的关键之年。全市检察机关将坚持以习近平新时代中国特色社会主义思想为指导，紧扣市委“一五二三四”工作部署，落实市人大及其常委会各项决议，依法忠实履行法律监督职责，为加快建设绿色高质量发展先行市、奋勇争先推进中国式现代化莆田实践贡献检察智慧和力量。
　　一、持之以恒答好服务大局“发展卷”。坚持和落实“两个毫不动摇”，贯彻新时代民营经济强市战略，高质效办好每一个涉企案件，发挥监督办案基础性保障作用。跟进重点产业链、新质生产力发展，加大涉企违法犯罪预防和治理力度，服务赋能法治化营商环境建设。敏锐关注经济金融领域风险，加强经济影响评估等机制应用，善用法治思维和法治方式护航高质量发展。
　　二、持之以恒答好维稳促和“责任卷”。深刻把握“发展是基础、安全是底线、稳定是前提”，宽严相济惩治犯罪，维护社会安定稳定。坚持和发展新时代“枫桥经验”，在办案全过程各环节推动矛盾纠纷法治化实质性化解，促进健全社会治理体系。注重治罪与治理并重、治标与治本统筹，协同推进公共安全治理机制和社会治安整体防控体系建设，共筑长治久安基石。
　　三、持之以恒答好司法为民“初心卷”。牢记检察工作也是群众工作，健全12309检察便民利民机制，畅通群众诉求反映渠道，更实回应民生关切。进一步拓展检察为民触角载体，完善保障未成年人、老年人等特定群体合法权益工作机制。精准对接就业、社会保障等民生领域改革部署，注重办好具有示范引领意义的案件、做好更多顺民意、暖民心、惠民生的检察实事。
　　四、持之以恒答好守护公正“法治卷”。坚持敢于监督、善于监督与依法监督、规范监督有机统一，推动“四大检察”全面协调充分发展。加强数字检察实践应用，完善重大监督事项办案程序，推进法律监督提质增效。落实执法司法相互配合、相互制约机制，进一步密切府检、监检、检警、检法等良性互动，努力办出更多让群众有感受、社会有共鸣、法治有回响的高质效案件。
　　五、持之以恒答好自我革命“赶考卷”。深入贯彻习近平法治思想，彰显坚定拥护“两个确立”、坚决做到“两个维护”的鲜明政治底色。坚持不懈抓基层打基础，育优业务骨干，建强办案组织，提升专业素能，以“三个善于”引领“高质效办好每一个案件”。改进和加强检察管理，抓实政治建设、业务建设和职业道德建设，以“自身净”“自身硬”锻造忠诚干净担当的检察铁军。
　　各位代表，风好正是扬帆时，重任千钧再启航！全市检察机关将更加紧密团结在以习近平同志为核心的党中央周围，紧紧依靠市委领导、市人大及其常委会监督、市政府、市政协及社会各界支持帮助，“实”字当头、“干”字为先，把抓落实作为最重要的工作理念和工作方式，为加快建设绿色高质量发展先行市、奋勇争先推进中国式现代化莆田实践作出新的更大贡献！
