莆田市住房公积金2022年年度报告

来源:湄洲日报 时间：2023-03-30 07:26
| | | |
　　根据国务院《住房公积金管理条例》和住房和城乡建设部、财政部、人民银行《关于健全住房公积金信息披露制度的通知》（建金〔2015〕26号）的规定，经住房公积金管理委员会审议通过，现将莆田市住房公积金2022年年度报告公布如下：
　　一、机构概况
　　（一）住房公积金管理委员会：莆田市住房公积金管理委员会有23名委员，2022年召开3次会议，审议通过的事项主要包括：莆田市住房公积金2021年年度报告；2021年度住房公积金缴存使用计划执行情况及2022年度预算；调整住房公积金业务政策；关于购买新建商品住房职工提取住房公积金追加购房款的实施细则等。
　　（二）住房公积金管理中心：莆田市住房公积金管理中心为直属莆田市人民政府不以营利为目的的事业单位，设6个科，4个管理部。从业人员62人，其中，在编42人，非在编20人。
　　二、业务运行情况
　　（一）缴存：2022年，新开户单位1482家，净增单位517家；新开户职工2.73万人，净增职工0.72万人；实缴单位6869家，实缴职工23.12万人，缴存额36.79亿元，分别同比增长8.14%、3.21%、5.87%。2022年末，缴存总额307.72亿元，比上年末增加13.58%；缴存余额117.49亿元，同比增长7.29%。受委托办理住房公积金缴存业务的银行6家。
　　（二）提取：2022年，8.1万名缴存职工提取住房公积金；提取额28.81亿元，同比增长13.6%；提取额占当年缴存额的78.31%，比上年增加5.33个百分点。2022年末，提取总额190.23亿元，比上年末增加17.85%。
　　（三）贷款
　　1.个人住房贷款：单缴存职工个人住房贷款最高额度45万元，双缴存职工个人住房贷款最高额度60万元。生育、抚养二孩及以上的缴存职工家庭申请住房公积金贷款且符合其他申请条件的，最高贷款额度在我市现行最高贷款额度的基础上上浮10万元（即双缴存职工70万元，单缴存职工55万元）。
　　2022年，发放个人住房贷款0.32万笔13.87亿元，同比分别下降28.36%、23.76%。
　　2022年，回收个人住房贷款10.93亿元。
　　2022年末，累计发放个人住房贷款5.61万笔175.25亿元，贷款余额99.39亿元，分别比上年末增加6.06%、8.60%、3.05%。个人住房贷款余额占缴存余额的84.60%，比上年末减少3.48个百分点。受委托办理住房公积金个人住房贷款业务的银行7家。
　　2.异地贷款：2022年，发放异地贷款204笔8899.6万元。2022年末，发放异地贷款总额9214万元，异地贷款余额9049.19万元。
　　3.公转商贴息贷款：2022年，未发放公转商贴息贷款，当年贴息额925.36万元。2022年末，累计发放公转商贴息贷款8125笔361298.60万元，累计贴息11368.22万元。
　　4.住房公积金支持保障性住房建设项目贷款：2022年，本中心未开展住房公积金支持保障性住房建设项目贷款。
　　（四）购买国债：2022年，本中心未购买国债，国债余额0亿元。
　　（五）资金存储：2022年末，住房公积金存款20.62亿元。其中，活期0.03亿元，1年（含）以下定期16.15亿元，其他（协定、通知存款等）4.44亿元。
　　（六）资金运用率：2022年末，住房公积金个人住房贷款余额、项目贷款余额和购买国债余额的总和占缴存余额的84.60%，比上年末减少3.48个百分点。
　　三、主要财务数据
　　（一）业务收入：2022年，业务收入35805.22万元，同比增长6.97%。其中，存款利息3822.24万元，委托贷款利息31979.91万元，其他3.07万元。
　　（二）业务支出：2022年，业务支出19230.99万元，同比增长8.48%。其中，支付职工住房公积金利息17167.57万元，归集手续费818.07万元，委托贷款手续费782.59万元，其他462.76万元。
　　（三）增值收益：2022年，增值收益16574.23万元，同比增长5.25%。增值收益率1.46%，比上年减少0.05个百分点。
　　（四）增值收益分配：2022年，提取贷款风险准备金1176.23万元，提取管理费用1075.38万元，提取城市廉租住房（公共租赁住房）建设补充资金14322.62万元。
　　2022年，上交财政管理费用1000万元。上缴财政城市廉租住房（公共租赁住房）建设补充资金11237.58万元。
　　2022年末，贷款风险准备金余额39755.74万元。累计提取城市廉租住房（公共租赁住房）建设补充资金92657.4万元。
　　（五）管理费用支出：2022年，管理费用支出1075.38万元，同比增长7.22%。其中，人员经费729.25万元，公用经费59.58万元，专项经费286.55万元。
　　四、资产风险状况
　　（一）个人住房贷款：2022年末，个人住房贷款逾期额109.86万元，逾期率0.11‰。个人贷款风险准备金余额39755.74万元。2022年，使用个人贷款风险准备金核销呆坏账0万元。
　　（二）支持保障性住房建设试点项目贷款：2022年，本中心未开展支持保障性住房建设试点项目贷款。
　　五、社会经济效益
　　（一）缴存业务
　　缴存职工中，国家机关和事业单位占38.42%，国有企业占14.76%，城镇集体企业占1.73%，外商投资企业占9.16%，城镇私营企业及其他城镇企业占31.75%，民办非企业单位和社会团体占2.19%，灵活就业人员占0.66%，其他占1.33%；中、低收入占98.52%，高收入占1.48%。
　　新开户职工中，国家机关和事业单位占16.07%，国有企业占10.39%，城镇集体企业占1.51%，外商投资企业占9.25%，城镇私营企业及其他城镇企业占54.63%，民办非企业单位和社会团体占4.07%，灵活就业人员占0.69%，其他占3.39%；中、低收入占99.82%，高收入占0.18%。
　　（二）提取业务
　　提取金额中，购买、建造、翻建、大修自住住房占18.62%，偿还购房贷款本息占54.32%，租赁住房占2.42%，支持老旧小区改造占0.01%，离休和退休提取占16.95%，完全丧失劳动能力并与单位终止劳动关系提取占4.71%，其他占2.97%。提取职工中，中、低收入占97.8%，高收入占2.2%。
　　（三）贷款业务
　　1.个人住房贷款：2022年，支持职工购建房39.46万平方米（含公转商贴息贷款），年末个人住房贷款市场占有率（含公转商贴息贷款）为10.65%，比上年末减少0.19个百分点。通过申请住房公积金个人住房贷款，可节约职工购房利息支出25527.07万元。
　　职工贷款笔数中，购房建筑面积90（含）平方米以下占6.70%，90-144（含）平方米占87.06%，144平方米以上占6.24%。购买新房占90.55%（其中购买保障性住房占0%），购买二手房占9.45%。
　　职工贷款笔数中，单缴存职工申请贷款占56.89%，双缴存职工申请贷款占43.01%，三人及以上缴存职工共同申请贷款占0.1%。
　　贷款职工中，30岁（含）以下占25.86%，30岁-40岁（含）占48.75%，40岁-50岁（含）占19.49%，50岁以上占5.90%；购买首套住房申请贷款占93.08%，购买二套及以上申请贷款占6.92%；中、低收入占97.34%，高收入占2.66%。
　　2.支持保障性住房建设试点项目贷款：2022年，本中心未开展支持保障性住房建设试点项目贷款。
　　（四）住房贡献率
　　2022年，个人住房贷款发放额、公转商贴息贷款发放额、项目贷款发放额、住房消费提取额的总和与当年缴存额的比率为96.72%，比上年减少14.39个百分点。
　　六、其他重要事项
　　（一）应对新冠肺炎疫情采取的措施，落实住房公积金阶段性支持政策情况和政策实施成效。
　　1.支持政策情况。受疫情影响的企业可按规定申请疫情期间缓缴住房公积金，到期后进行补缴，缓缴期间缴存时间连续计算，不影响职工正常提取和申请住房公积金贷款。对因感染新冠肺炎住院治疗或隔离人员、因疫情防控需要隔离观察但未住院隔离人员、参加疫情防控工作人员在疫情防控期间因疫情影响未能及时偿还住房公积金贷款的，经相关机构认定，不作逾期记录报送。
　　2.政策实施成效。2022年因受疫情影响申请延迟缴存住房公积金的企业共有22家，涉及职工共312名，为企业办理缓缴金额共51.21万元，切实减轻了企业负担；在纾困期间，贷款逾期不作处理的有280笔，贷款余额8301.11万元，未还款本金36.38万元。自提高房租提取额度后，有7518名职工通过中心微信网厅、闽政通、惠民宝等服务渠道“零材料”办理租房提取业务，提取金额4511.43万元。
　　（二）租购并举满足缴存人基本住房需求，加大租房提取住房公积金支持力度等情况。
　　认真落实上级部门提出的“租优于购”精神，自2022年6月10日起提高住房公积金租房提取额度。职工家庭在我市行政区域内无自有住房且租赁自住住房的，租房提取限额由每人每年5400元提高至7200元。
　　（三）当年机构及职能调整情况、受委托办理缴存贷款业务金融机构变更情况。
　　新增中国银行秀屿支行、中国银行城厢支行、中国银行荔城支行、中信银行莆田分行作为承办住房公积金贷款网点。
　　（四）当年住房公积金政策调整及执行情况。
　　1.2022年缴存基数限额及确定方法、缴存比例等缴存政策调整情况。
　　2022年月缴存工资基数上限：单位及其职工最高月缴存基数为2021年莆田市社平工资6668元的3倍为20004元，住房公积金月缴存额上限为4800元；月缴存工资基数下限：全市辖区单位及其职工的最低月缴存工资基数为1810元，住房公积金月缴存额下限为182元。缴存比例为5％-12%。
　　2.2022年住房公积金提取政策调整情况。
　　（1）职工与非直系亲属共同购买二手房的，提取住房公积金时需持有该房屋不动产权证满6个月，已办理住房贷款的除外。
　　（2）职工、配偶及产权共有人在本省内购买自住住房申请住房公积金提取时，不再提供购房所在地的户籍证明。
　　（3）职工有未结清住房公积金贷款的，申请办理提取公积金业务时，职工、配偶及产权共有人的公积金账户不再留存近6个月的月汇缴金额。
　　（4）购买新建商品住房职工（含共有产权人）及配偶可申请提取公积金账户内的住房公积金，用于补充购房首付款。
　　3.2022年个人住房贷款最高贷款额度、贷款条件等贷款政策调整情况。
　　（1）增加公积金个人住房贷款变更还款方式的业务事项。
　　（2）职工第二次申请使用住房公积金贷款时，首付款比例调整为不低于30%。
　　（3）夫妻双方均有缴存住房公积金，贷款最高额度为60万元。
　　（4）已使用过住房公积金贷款购建房的，由原来须结清住房公积金贷款满12个月后，调整为须结清住房公积金贷款满6个月后，方可再次使用住房公积金贷款。
　　4.住房公积金存贷款利率执行标准。
　　(1)存款利率。职工住房公积金账户存款利率为一年期定期存款基准利率，即1.5%。
　　(2)贷款利率。2022年10月1日前，首次申请住房公积金贷款的，5年以下（含5年）和5年以上住房公积金贷款利率分别为2.75%和3.25%；第二次申请住房公积金贷款的，利率上浮10%。2022年10月1日起，首套个人住房公积金贷款利率执行5年以下（含5年）2.6%和5年以上3.1%；第二套个人住房公积金贷款利率执行5年以下（含5年）3.025%和5年以上3.575%。
　　5.支持老旧小区改造政策落实情况。
　　2022年共办理3笔城市既有住宅增设电梯提取公积金业务，提取金额40.99万元，有效帮助职工完善既有住宅使用功能、改善居住生活品质。
　　（五）当年服务改进情况。
　　1.“跨省通办”推进情况。在全国率先开展公积金业务“跨省通办”，并持续扩大服务事项，2022年年底前住房公积金汇款、住房公积金补缴、提前部分偿还住房公积金贷款三个事项实现“跨省通办”，提前高标准完成住房公积金“跨省通办”任务。
　　2.服务创新情况。持续深化“放管服”改革，信息化建设继续走在全省同行业前列，窗口总办件量、即办率和全程网办率皆位居全市前列。一是数字赋能，全省首家实现贷款线上预审。深化大数据应用赋能，推进与不动产数据信息在住房公积金贷款子系统的应用，让房产数据在线自动比对查询，积极推行住房公积金贷款线上预审。贷款申请成功后，借款人即可把贷款材料送交办事窗口进行签约，实现“一次签约即审批办结”；二是强力合作，全省率先开通“省内跨中心冲还贷”业务。根据省住建厅工作部署，中心主动作为，联合省直和福州公积金中心在全省率先开通“省内跨中心冲还贷”业务。开通后在省直或福州公积金中心办理住房公积金（组合）贷款并开通“冲还贷”业务的职工，其配偶或共同还款人在莆田公积金中心缴存公积金的，均可携办理材料到莆田住房公积金各服务大厅现场办理“省内跨中心冲还贷”业务；三是打破界限，携手共建都市圈住房公积金联盟。与福州、南平、宁德住房公积金中心及平潭综合实验区行政服务中心建立都市圈“协同联盟”，共同签署《福州都市圈住房公积金“协同联盟”战略合作协议》，推出第一批离职提取、购房提取等36项公积金高频服务事项都市圈内通办，打破办理事项属地化限制，为全省住房公积金业务政策规范化、标准化提供了平台；四是惠民暖心，提升公积金政务服务能力。充分利用官方网站、微信公众号等网络媒体和报纸、LED显示屏等载体积极宣传住房公积金政策、业务办理流程等，有效加强职工对住房公积金惠民政策的了解。认真制定了《“惠民公积金、服务暖人心”莆田市住房公积金管理中心服务提升三年行动实施方案（2022-2024年）》等文件，强化窗口服务管理，推进住房公积金服务标准化规范化便利化，持续提升管理服务水平，不断增强人民群众的获得感、幸福感、安全感。
　　（六）当年信息化建设情况。
　　一是全省首家完成人民银行征信报送系统的接入。通过住建部总对总的方式接入中国人民银行二代征信查询系统，在全省首家完成人民银行征信报送系统的接入，提升了公积金放贷效率，及时推送征信数据，有力加强了公积金信用体系建设，防范信贷风险，更好服务缴存职工。二是提供有力的网络安全保障。完善《莆田市住房公积金管理中心网络安全应急预案》，委托第三方网络安全运维公司每周对公积金网上办事大厅、微信公众号、H5链接进行安全自查，及时发现整改系统安全漏洞。按照市网安办要求举行网络安全攻防演练，结合实际制订了详细具体的工作措施，确保演练时反应快速、报告及时、措施得力、操作准确，最后较好地完成了网络安全攻防演练活动。
　　（七）当年住房公积金管理中心及职工所获荣誉情况。
　　被市委市政府评为一类平安单位，公积金窗口荣获市政务服务中心“群众满意窗口”和“流动红旗窗口”，多名干部职工被评选为优秀窗口负责人、服务之星、服务标兵、党员示范岗等。
