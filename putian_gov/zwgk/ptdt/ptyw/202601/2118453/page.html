政府工作报告

——2026年1月13日在莆田市第八届人民代表大会第六次会议上
来源:湄洲日报 时间：2026-01-24 07:25
| | | |
莆田市人民政府市长 戴龙成
　　各位代表：
　　现在，我代表市人民政府，向大会报告政府工作，请予审议，并请市政协委员和列席人员提出意见。 2025年和“十四五”时期工作回顾
　　一年来，我们坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大和二十届历次全会精神，深入学习贯彻习近平总书记在福建考察时的重要讲话精神，在市委坚强领导下，扎实开展深入贯彻中央八项规定精神学习教育，持续深化拓展“三争”行动，铆足干劲，奋勇争先，“一五二三四”工作部署全面起势，绿色高质量发展先行市建设取得亮眼成绩。
　　初步预计，地区生产总值增长5.2%，社会消费品零售总额增长5.5%，固定资产投资持平，实际利用外资增长69%，出口总额下降4%，一般公共预算总收入增长5.1%，一般公共预算收入增长8.2%，居民人均可支配收入增长5.5%，居民消费价格基本平稳。
　　重点抓了以下七项工作：
　　一、高效攻坚，项目建设的进程推得有力又有效。千方百计破解难题，创新开展“高效攻坚一件事”行动，有力解决了中铁妈祖城、华阳公司股权收购、月塘南片区等历史遗留问题1081个。千思万虑盘活资源，挖潜合众天成、宝胜地块、台兴实业等低效用地2124亩，唤醒城北产业园、会展中心、两岸生技园等闲置资产23.5万平方米，处置抽水蓄能、洋西片区、威高地块等批而未供土地6345亩。千军万马招商引资，实施“招商奋战年”行动，华峰、佳通、海安等产业链项目相继落地，深中华、隆晖、京鼎等企业入驻世界莆商中心，德濠、万存、联东等产业园区运营商落子莆田，“一单位一楼宇”入驻率达100%，签约亿元以上产业类项目233个、总投资超1500亿元，其中30亿元以上项目超30个，再次入选中国投资热点城市。千辛万苦推进项目，全省首创“五即”改革，开工办理时限缩短67%，“五证同发”做法全国推广，争取超长期特别国债13.3亿元、地方政府专项债110.7亿元，新增贷款突破300亿元，首贷企业突破3000家，全国最大容量LNG储罐、火电厂三期、力恒新材料等100个重点项目开工，鞋服科技产业园、优星欧派新型建材、李宁智造基地等102个重点项目竣工。抓项目建设，付出的是汗水，提振的是信心，凝聚的是力量，赢得的是未来。
　　二、高质赋能，产业转型的动能蓄得充足又充沛。坚持高端化引领，组建创新创造专班，设立木兰实验室，新增国家级专精特新重点“小巨人”企业3家、高新技术企业80家，新认定高层次人才1417人，新选派“科技副总”30人。坚持智能化改造，开展数字化转型重点项目100个、“智改数转”企业905家，“北斗多源融合数据集建设”入选国家首批试点。坚持绿色化生产，百威雪津入选国家智慧低碳5G工厂，莆田高新区列入国家碳达峰试点。坚持品牌化提升，集聚优化10条重点产业链，海安集团主板上市，三棵树蝉联中国品牌价值500强、行业唯一，莆田鞋、三福古典家具入选首批中国消费名品，荣获全国活力城市、中国百强城市、中国啤酒制造之城。抓产业转型，变革的是思维，锤炼的是筋骨，激活的是动能，赢得的是主动。
　　三、高维突破，改革开放的步伐迈得坚定又坚实。改革之路“敢为人先”，湄洲岛岸实现历史性圆满整合；全省首创服务企业“110”机制，政务服务“一件事”套餐时限压减82.6%、电子证照应用率达95%，上榜中国最佳地级城市营商环境50强；释放“园区20条”效应，湄洲湾国投经开区入选全国推进新型工业化典型案例，5个开发区跻身全省30强；推进国企改革深化提升行动，园林集团获AA+信用评级，市属国企资产总额增长10%。开放之门“海纳百川”，第十届世界妈祖文化论坛得到“广受好评，史上最佳”的赞誉，首次设立11个海内外分会场，发布全国首颗海风海浪探测卫星“妈祖号”；开通“加拿大—莆田—印度”煤炭转口航线，莆田港至宁波舟山港实现直航。融合之势“情暖两岸”，开工“我在娘家有间房”两岸融合社区，新增省级闽台乡建乡创项目6个，天下妈祖回娘家、两岸同胞迎中秋等活动越办越亲，越来越多台胞感叹“在莆田收获了家一般的温暖”。
　　四、高位推动，城乡融合的画卷铺得舒展又舒畅。城市更加精致，聚焦“六个更”目标，高起点谋划木兰溪新区建设，学园中街等8条精致街全新升级，城厢联创等9条夜市步行街焕新升级，动车站广场等26个特色城市IP提档升级，治理积水易涝点10处、交通易堵点8处，新改建雨污管网72公里；完成老旧小区改造41个，推行房票安置，回迁安置房1.9万套；新改建城市道路60公里，莆阳福道凤凰段全线贯通、累计建成185公里，新增公共停车泊位3000个，市民翘首以盼的木兰大道城区段、八二一街南延顺利通车。乡村更加和美，仙游县、秀屿区获评国家新型城镇化潜力地区试点，黄石镇入围国家农业产业强镇，新增全国名特优新农产品6个、共富工坊55个，省对市乡村振兴实绩考核首次跃居第一，城乡居民收入比1.78、均衡化程度全省第二，山与海、城与乡各美其美、美美与共。
　　五、高品打造，文体消费的场景燃得火热又火爆。文旅“出新”，兴化府街区入选国家级旅游休闲街区，鱼牙顶街区入选省级历史文化街区，莆阳御史文化馆建成投用，大型木雕《京杭大运河》江南卷实现首展，莆仙戏《蔡襄》成功首演，新增省级以上非遗代表性传承人20名，湄洲岛游客接待量达323.23万人。 
　　演艺“出众”，“魅力山海 灵秀莆田”演唱会、亚太音乐节唱响莆阳大地，8万多乐迷嗨翻银河左岸音乐节，好评如潮，圈粉无数，“莆田很会”“莆田真棒”。活动“出圈”，“全到莆田过大年”“状元楼上争状元”“穿越北大上北大”精彩纷呈，“购在中国·全闽乐购”莆田优品焕新消费季暨央视总台系列活动霸屏全网。赛事“出彩”，我市运动健儿全运会成绩创历史最佳，举办“莆马”“仙马”、海峡两岸大学生篮球赛、市运会，莆超联赛独领风骚、燃爆全城，“一元钱办成一件大事”撬动消费热潮，“一张票玩转一座城”升腾烟火莆田。
　　六、高标引领，生态文明的样本立得鲜明又鲜活。绿水青山底色更亮，全国首个幸福河湖研学基地开馆，木兰溪流域国省控断面优良水质比例连续三年保持100%、为历史最好水平，木兰溪治理写入水利部《深入学习贯彻国家“江河战略”》，蓝色海湾整治案例获联合国海洋生态保护修复大赛最高荣誉，湄洲岛绿化覆盖率提升至63.7%；见筋见骨抓好污染防治，空气质量达标率97.8%，近岸海域国省控点位优良水质面积比例达97.9%、全省第一，完成“无废城市”建设任务。金山银山成色更足，“海洋蓝碳开发及价值实现机制”入选省级改革试点，仙游县获评全国生态文明建设示范区，“依托水上巴士打通生态产品价值转换新路径”做法全国推广。在我们莆田，“莆阳福道揽山水，一片绿心向玉湖”，这方灵秀之地，叫人如何不眷恋、如何不向往！
　　七、高频响应，民生改善的实事办得走心又走实。社会事业办得更好，城镇新增就业完成率全省第一，职业技能培训2.2万人次，“壶兰工匠”技能人才培育、全链条保障稳岗促就业做法全国推广；组建“总园+”集团4个，市第二实验小学和泗华小学试点“总校制”办学；全省率先实现市域医学检查检验结果互认，仙游县总医院新院区建成投用，省协和医院妈祖院区开业运营、成为东南沿海首个国产重离子治疗中心，莆田学院附属医院急重症救治中心、6个新改建院前急救站投入运行，急救“生命通道”更畅通。社会保障兜得更牢，防督联治欠薪治理、老年友好型社区创建做法全省推广，“一碗面·温暖一座城”认捐超40万碗，向上向善蔚然成风。社会治理抓得更实，升级“全市一张图”赋能基层治理，全域推行农村建房线上审批，信访总量下降45.2%，生产安全事故起数、死亡人数“双下降”。
　　一年来，我们坚决抓好中央生态环保督察、省委巡视等反馈问题整改，全面完成30项为民办实事项目，办好市人大代表建议394件、市政协提案217件，12345热线获评“全国巾帼文明岗”，国防动员、民族宗教、侨务、档案、工青妇、残疾人和红十字等事业取得新成效，荣膺全国双拥模范城“七连冠”。我们纵深推进群众身边不正之风和腐败问题集中整治，抓好“校园餐”等专项整治，解决群众急难愁盼问题2.1万个，涉企检查、社会事务进校园次数“双下降”，做到干部清正、政府清廉、政治清明。
　　各位代表！过去五年，是莆田发展历程中极为重要、极不平凡、极具考验的五年，我们经受住世纪疫情的严重冲击，经受住史上最大的降雨考验，经受住严峻复杂的风险挑战，地区生产总值突破3500亿元，人均GDP跨过10万元大关，成绩来之不易。
　　五年来，我们聚力产业发展篇，突出总量与质量并重，一体推进三大战略和两大支撑，经济发展富有活力、动力、实力。龙头企业取得标志性成效，建成全球单体最大的啤酒制造基地、全球单体产能最大的锦纶聚合基地，新增上市企业3家，规上工业企业突破1200家。科技创新取得实质性进步，运营市科技成果转移转化公共服务平台，上榜全国人才吸引力百强城市。数字赋能取得跨越式升维，创新“链长制+云平台”，新增国家级智能制造、工业互联网示范项目24个。营商环境取得关键性突破，设立“莆田企业家日”，上线“亲清惠企”“天下莆人”平台，市场主体较五年前增长77%。如今的莆田，10条重点产业链强核提质、上拓下展、链链相促，全国先进制造业百强、中国鞋都、中国食品产业名城实至名归，一张张“国字号”新名片，彰显出匠心智造产业新城的强劲动能、硬核实力。
　　五年来，我们聚力城乡建设篇，突出精致与精细并行，统筹推进老城更新和新区建设，城乡环境尽显宜居、宜业、宜游。城市格局塑起来，八二一街、木兰大道等主干道初步构建，玉湖新城华丽蝶变，大学城、绶溪片区加速崛起，建成区面积扩大到170平方公里。城市品质优起来，兴化府街区绽放新彩，沟头、龙德井片区面貌一新，水上巴士畅行绿心，泗华郊野公园游客如织。城市生态美起来，“实施木兰溪综合治理”写入国家“十四五”规划，木兰溪流域获评全国“绿水青山就是金山银山”实践创新基地；湄洲岛、南日岛入选全国首批“和美海岛”，湄洲岛绿色低碳发展案例亮相联合国气候变化大会。乡村振兴旺起来，新增国家农业产业强镇4个、中国传统村落4个，度尾文旦柚入选全国“土特产”推介名录，南日鲍荣获中欧互认互保产品。如今的莆田，中国美好宜居典范城市、全国生态文明与环境治理百强城市熠熠生辉，山水诗画生态韵城得天独厚、风华独具。
　　五年来，我们聚力基层治理篇，突出共建与共治并进，协同推进党建引领和数字赋能，社会大局保持安全、安定、安宁。社会治理更加稳固，全省率先开发“全市一张图、全域数字化”大数据调度指挥平台，开发应用场景492个，“数字赋能基层新路径”做法获国务院大督查通报表扬。风险屏障更加坚固，接报违法犯罪警情数、刑事案件立案数逐年下降，警用无人机实战应用、“五联防”岸海综合治理做法全国推广。安全防线更加牢固，获评国家食品安全示范城市，生产安全事故起数、死亡人数较五年前分别下降50%‌、73.5%。如今的莆田，“党建引领、夯基惠民”工程全域提升，“全市一张图”平台全面赋能，社会大局安定稳定，这份触手可及的安全感，筑牢了千家万户的幸福根基。
　　五年来，我们聚力民生保障篇，突出惠民与富民并举，扎实推进群众增收和民生实事，群众生活满载暖心、舒心、安心。八成财政支出用于民生社会事业，城镇新增就业10.5万人，居民收入年均增长6.2%。社会保障提标扩面，基本实现养老保险、医疗保险全覆盖，残疾人两项补贴标准连续五年增长，建成全国示范性老年友好型社区7个。教育强市提质增效，北大附中莆田学校、福师大仙游附属学校、莆田一中新校区等优质校实现招生，湄职院新校区全面启用，莆田学院新增硕士点13个。健康莆田提档升级，全省率先试点“联合病房”，省级区域医疗中心、市口腔医院建成投用，国家临床重点专科建设实现零的突破。文体事业提级扩能，成功举办全国射击冠军赛、气步枪奥运选拔赛，莆仙戏《踏伞行》斩获文华大奖，妈祖文化跨越山海、远播五洲。如今的莆田，国家历史文化名城韵味悠长，妈祖故里文化名城魅力尽显，老百姓日子越过越殷实、越过越精彩、越过越红火。
　　五年来，我们聚力港口崛起篇，突出提速与提效并施，系统推进设施升级和功能优化，港口势能愈发强大、强力、强劲。集疏运体系全面贯通，投用全省首个40万吨级码头，实现世界最大的矿砂船、LNG船、煤炭船常态化靠泊接卸，对台铁矿石中转量连续六年大陆第一。港产城联动全面协同，全球首个海水提钾产业化工程开工，全球首个漂浮式风渔融合项目投产，全省首个百兆级渔光互补项目并网发电。功能性生态全面提质，全省口岸智慧转关货物直通模式在莆落地，莆台集装箱班轮跨境电商出口顺利首航，与“一带一路”沿线20个国家58个港口实现通航。如今的莆田，港口货物吞吐量较五年前翻了一番，海铁联运、水水中转量稳居全省第一，通江达海战略港城破浪前行、扬帆逐梦。

　　2026年工作安排
　　今年经济社会发展的主要预期目标是：地区生产总值增长5%—5.5%，固定资产投资增长3%，社会消费品零售总额增长5.5%，出口总额增长3%，一般公共预算收入增长3%，居民消费价格涨幅2%左右，居民收入增长和经济增长同步，粮食产量18.9万吨以上。实现上述目标，我们要上下同欲、内外联动，项目为王、实干为要，以“闯”的精神、“拼”的劲头、“干”的状态，奋力做好“七抓七促”工作。

　　我们将在市委坚强领导下，坚持实字当头、干字为先、民生为大，建设法治政府、创新政府、廉洁政府和服务型政府。
　　1.锤炼绝对可靠、绝对纯洁的政治品质。怀着特殊感情、带着特殊责任，坚持不懈用习近平新时代中国特色社会主义思想凝心铸魂，大力传承弘扬习近平总书记开创的重要理念和重大实践，跟着总书记学思想、学理念、学方法，更加坚定拥戴核心、忠诚核心、跟随核心、捍卫核心。时时处处从政治上看问题、找出路，不入小局入大局，不算小账算大账，离开小我到大我，做到执行不打折、不变形、不走样，确保市委各项部署要求落地见效。
　　2.锤炼敢为人先、敢于突破的创新品质。敢想，破除思想坚冰，接受新理念、拥抱新事物，在工作中常抓常新、在方法上推陈出新。敢闯，善用有解思维，敢蹚改革深水区，敢涉发展无人区，以创新精神发现问题，以创新思维研究问题，以创新举措解决问题。敢拼，涵养状元思维，勇于与优者对标、强者比拼、快者赛跑，打造“一单位一品牌”，争创示范标杆、全国试点。
　　3.锤炼勇于担当、勇挑重担的实干品质。高效干事，弘扬“马上就办、真抓实干”作风，要实打实、不要空对空，要用心干、不要用心眼干，坚决做到“三个三”：专题会议三天出纪要、请示事项三天给答复、重大项目三天督进度。大胆干事，敢挑“重担子”、敢啃“硬骨头”、敢接“烫山芋”，不避难、不推责、不退缩，做到问题不见底不放过、解决不彻底不松手、整改不到位不罢休。激情干事，把工作标准调到最高，把工作状态调到最佳，把工作力度调到最大，干就干最好，争就争第一。
　　4.锤炼一心为民、一心奉公的赤诚品质。问需于民，换位思考，将心比心，办好为民实事，坚持政府过紧日子，困难再多、任务再重，为民尽责的立场一丝不移，为民增利的支出一分不少，为民办事的力度一点不减。问计于民，“四下基层”走出去，“四个万家”走进去，把群众“心上事”作为政府“上心事”，紧抓快办、办就办好。问效于民，把评判权交到群众手中，主动接受人大、政协、纪检监察和司法监督，加强审计、财会、统计等监督，广泛接受群众监督，让政府权力始终在阳光下运行。
　　5.锤炼不图私利、不徇私情的廉洁品质。常怀律己之心，坚决履行全面从严治党主体责任，严格落实中央八项规定及其实施细则精神，攻坚提升群众身边不正之风和腐败问题集中整治，真管真严、敢管敢严、长管长严。常思贪欲之害，做人要纯粹、做事更要纯粹，反对特权思想和特权现象，心有所畏、言有所戒、行有所止，坚决做到“三个不”：不拿群众一针一线、不费光阴一朝一夕、不谋个人一私一利，以一身正气行走在天地之间。
　　各位代表！山海寻梦，不觉其远；前路迢迢，阔步而行。让我们更加紧密地团结在以习近平同志为核心的党中央周围，坚持以习近平新时代中国特色社会主义思想为指导，在市委坚强领导下，拿出跃马扬鞭的勇气，激发万马奔腾的活力，保持马不停蹄的干劲，加快建设绿色高质量发展先行市，共同谱写无愧于历史、无愧于时代、无愧于人民的精彩篇章！
