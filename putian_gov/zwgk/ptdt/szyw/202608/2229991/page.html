习近平生态文明思想引领美丽中国建设谱新篇——写在全国生态日暨生态环境法典施行之际

来源:新华社 时间：2026-08-15 08:51
| | | |

　　新华社北京8月13日电 题：习近平生态文明思想引领美丽中国建设谱新篇——写在全国生态日暨生态环境法典施行之际

　　新华社记者

　　8月15日，在第四个全国生态日到来之际，《中华人民共和国生态环境法典》正式施行，宣告我国生态环境保护开启“法典化”时代。这部法典以习近平生态文明思想为魂和纲，对于以高水平法治守护绿水青山具有重大而深远的意义，为共建清洁美丽的地球家园提供中国方案、贡献中国智慧。

　　“生态文明建设功在当代、利在千秋。”习近平总书记深刻指出。

　　法护山河，典泽千秋。从制度建设到法治保障，从体制改革到绿色发展，在习近平生态文明思想指引下，我国的生态环境保护治理开启新阶段，绿色低碳发展步履愈发坚定，持续奏响人与自然和谐共鸣的时代乐章。

　　思想之光：“推动绿色发展，建设生态文明，重在建章立制”

　　一部法典，标记生态文明建设的里程碑时刻——

　　2026年3月12日下午，北京人民大会堂。十四届全国人大四次会议表决通过的《中华人民共和国生态环境法典》，成为继民法典后我国第二部以“法典”命名的法律。

　　承载着亿万人民守护美好家园的殷殷期盼，生态环境法典首次把习近平生态文明思想写入法律，将其核心要义转化为具有普遍约束力的法律规范，更好在法治轨道上推进生态文明建设。

　　思想之光，照亮人与自然和谐共生之路。

　　习近平生态文明思想是中国共产党不懈探索生态文明建设的理论升华和实践结晶，是马克思主义基本原理同中国生态文明建设实践相结合、同中华优秀传统生态文化相结合的重大成果。这一重要思想来源于实践又指导实践，为新时代推进生态文明建设提供根本遵循和行动指南。

　　在青海，中学教师新文退休后，主动报名成为一名“民间河长”，常年骑着三轮摩托车穿梭在海拔4500多米的沱沱河畔。

　　“沱沱河是我们的母亲河，守护它是我分内的事。”他说，生态环境持续向好，是所有一线护河人共同的心愿。

　　今年是全面推行河湖长制10周年。青海通过河湖长制层层压实江河保护责任，一条条河流、一个个湖泊拥有了专属的巡护守护者。一处处美丽河湖丰盈了美景，点亮了生活。

　　河湖长制的推行，是我国生态文明制度体系日趋完善的生动缩影。

　　经国序民，正其制度。制度是关系党和国家事业发展的根本性、全局性、稳定性、长期性问题，生态文明建设尤其如此。

　　“推动绿色发展，建设生态文明，重在建章立制”；

　　“只有实行最严格的制度、最严密的法治，才能为生态文明建设提供可靠保障”；

　　“要加快制度创新，增加制度供给，完善制度配套，强化制度执行，让制度成为刚性的约束和不可触碰的高压线”；

　　…………

　　习近平总书记的谆谆嘱托，宣示了生态文明建设要严格用制度管权治吏、护蓝增绿的坚定决心。

　　以“制”促“治”，筑牢基石。党的十八大以来，我国着力构建、完善生态文明制度体系，不断筑牢生态环境保护根基。

　　新时代以来，一系列制度护航美丽中国建设，《关于加快推进生态文明建设的意见》和《生态文明体制改革总体方案》两个重要文件相继出台，形成生态文明体制的纲领性架构，生态文明顶层设计和制度体系建设加快推进。

　　建立实施生态文明建设目标评价考核制度、生态环境损害责任终身追究制、生态环境分区管控制度、排污许可制等制度机制，严格落实生态环境保护“党政同责”和“一岗双责”，党委领导、政府主导、企业主体、社会组织和公众共同参与的责任体系更加严密健全。

　　2026年，中办、国办印发《美丽中国建设成效考核办法》，提高对党中央生态文明建设决策部署的执行力，以考核促进生态环境质量改善和相关工作落实，压实生态环境保护责任。

　　以“法”促“治”，强化保障。党的十八大以来，我国生态环境法治建设开启了立法力度最大、监管执法尺度最严、法律制度实施效果最为显著的时期。

　　在2018年的一次座谈会上，习近平总书记曾谈到一家企业，是当地纳税大户，但也是排污大户，“这两年环保部门动真格严查，开出2700多万元的长江流域‘史上最大环保罚单’”。

　　这家企业就是位于长江湖北石首段的楚源集团。从曾经的排污大户，到如今的绿色标杆，转折点正是企业2016年因违法排污收到“天价罚单”。企业加大投入治理污染、转型升级，一步步走上绿色发展的路子。

　　思想引领改革，改革完善法治。通过不断补齐重点领域法治短板，环境保护制度之网越织越密。

　　我国把生态文明写入宪法，确立生态文明的宪法地位；引入按日连续罚款、查封扣押、限产停产等硬措施，出台“史上最严环保法”；聚焦人民群众反映强烈的生态环境问题，制修订大气、水、土壤、固体废物、噪声、海洋等一批污染防治领域的专门法律；创新流域、区域生态环境立法，专门制定长江保护法、黄河保护法、青藏高原生态保护法、黑土地保护法等法律……

　　新时代以来，我国生态环境领域法律制度与时俱进，基本形成了覆盖全面、务实管用、科学严密的生态环境法律体系，但依然存在制度分散、衔接不畅、协同不足等问题。

　　法典，诸法之总汇、制度之集成。

　　生态环境法典将党的十八大以来生态文明建设理论、制度、实践成果以法典化的方式确定下来，是30多部生态环境法律、100余件行政法规、1000多件地方性法规等的“集大成者”，为实现人与自然和谐共生的现代化筑牢更强法治根基。

　　——体现以人民为中心的发展思想，法典聚焦群众反映强烈的痛点、难点、堵点问题，回应人民群众日益增长的优美生态环境需要。

　　——突出生命共同体的系统观念，法典按照生态系统的整体性、系统性及其内在规律，推动构建覆盖全要素、全流域、全链条的生态保护体系。

　　——指明绿色低碳的发展路径，法典开创性设立绿色低碳发展编，推动发展方式与生活方式全面绿色转型。

　　“从污染防治到生态保护、再到绿色低碳发展，生态环境法典内容系统全面，为生态环境保护立下了‘总规矩’，标志着我国生态环境治理逻辑实现了从‘分要素、分环节、分部门’的碎片化管理，向‘全过程、全地域、全要素’系统治理的历史性转变。”武汉大学环境法研究所所长秦天宝说。

　　治理之道：“用最严格制度最严密法治保护生态环境”

　　一块桨板，见证“华北明珠”重绽光彩的巨变——

　　在河北雄安，白洋淀上正在兴起一项新潮的水上运动——桨板。穿行于无边的荷花海，桨板下是清晰可见的“水下森林”，苇荡中不时有水鸟掠过。白洋淀水质从劣Ⅴ类提升并稳定保持在Ⅲ类，良好的生态环境不仅让青头潜鸭、彩鹮等296种野生鸟类在此栖息，也吸引了众多游客体验打卡。

　　变化的背后，离不开制度法规的力量。《白洋淀生态环境治理和保护条例》等出台实施，强化了区域协同治理机制，“九龙治水”变成“一股绳”，上下游、左右岸合力治理污染，将华北水乡的自然之美还给百姓。

　　从“看GDP”到“看PM2.5”，从“闻异味色变”到“查排污源头”，身边的蓝天碧水净土，成为人民群众更加关注的大民生。

　　习近平总书记要求，既要创造更多的物质财富和精神财富以满足人民日益增长的美好生活需要，也要提供更多优质生态产品以满足人民日益增长的优美生态环境需要。

　　党的十八大以来，以习近平同志为核心的党中央带领亿万人民坚决打响史无前例、规模巨大的污染防治攻坚战。“大气十条”“水十条”“土十条”接连出台，集中攻克身边的突出生态环境问题，让老百姓实实在在感受到生态环境质量改善。

　　生态环境法典明确坚持良好生态环境是最普惠的民生福祉，将保障公众健康和生态环境权益作为立法目的之一，在结构安排上把同人民群众健康密切相关的污染防治编放在突出位置。

　　污染防治编不仅涉及大气污染、水体黑臭等传统污染治理，还延伸到具有长期性、隐蔽性危害的新污染物治理，将光污染、电磁辐射污染等新情况新问题写入。

　　针对近年来群众反映集中的噪声、餐饮油烟、恶臭异味等烦心事，法典专章规定“社会生活噪声污染防治”，进一步加强建筑施工噪声污染防治；同时增加选址等要求，推动油烟污染从末端整治转向源头防控。

　　美丽城市、诗意乡村，美丽中国建设的壮阔实践，正让华夏大地焕发勃勃生机，让人民群众在绿水青山中共享自然之美、生命之美、生活之美。

　　前不久，辽宁长山群岛候鸟栖息地正式纳入世界自然遗产，将过去看似分散的保护区域，顺着候鸟的飞行轨迹连接成一条完整生命廊道。

　　当地将保护视野拓展到陆海统筹、区域协同的宏大格局，统筹推进湿地修复、岸线治理、联合巡护和数字监测。沿海地区还持续开展退养还湿、潮沟疏通、盐沼植被修复和入海污染管控，推动遗产地保护与海岸带综合治理相互衔接。

　　生态是统一的自然系统，是相互依存、紧密联系的有机链条。

　　“要坚持系统观念，扎实推进山水林田湖草沙一体化保护和系统治理”“要从系统工程和全局角度寻求新的治理之道”……循着习近平总书记重要指示，我国努力构建从山顶到海洋的保护治理大格局。

　　在建设世界最大的国家公园体系过程中，实行整体保护、系统修复、综合治理；围绕重要生态安全屏障，部署实施50多个山水林田湖草沙一体化保护和修复工程，更好守护绿水青山；“三北”工程区坚持系统观念，因地制宜，努力构筑功能完备、牢不可破的北疆绿色长城……

　　翻开法典生态保护编，法律对森林、草原、湿地、江河湖泊、荒漠等生态系统保护作出规定，对长江、黄河、青藏高原等重要流域、区域保护单独设立章节。

　　“法典生态保护编遵循不同生态系统的自然规律，坚持统筹协同、整体治理，推动从单一要素保护转向全域生态系统保护。”天津大学法学院教授孙佑海说，以刚性法治筑牢生态安全屏障，彰显了新时代生态文明的法治追求。

　　以法为纲，循法而治。习近平总书记指出：“必须始终坚持用最严格制度最严密法治保护生态环境，保持常态化外部压力。”建立生态环境保护督察制度，正是其中关键一招。

　　夏日秦岭，群山含翠，草木葳蕤。

　　曾经，秦岭北麓违建别墅是绿水青山间的“伤疤”。2018年7月，一场雷厉风行的专项整治行动展开。专项整治期间，秦岭北麓西安境内共清查出1194栋违建别墅，其中依法拆除1185栋，依法没收9栋并改造用于公共事业；累计收回国有土地4557亩、退还集体土地3257亩，所有拆除区域全部完成复绿复耕。

　　2020年春天，习近平总书记赴陕西考察，亲自“验收”整改成效，叮嘱当地领导干部“当好秦岭生态卫士”。

　　生态环境部今年3月发布的《秦岭地区生态保护蓝皮书（2025年）》显示，自2018年以来，秦岭地区森林和湿地等关键生态系统面积稳步提升，超过50%的重要生态空间呈现恢复趋势，超过60%的区域生态质量不同程度好转。

　　广东练江告别“墨汁河”，乌梁素海生态功能逐渐恢复、成为百鸟乐园，祁连山重新披绿……中央生态环境保护督察推动解决了一些地方的生态环境“顽疾”，成为督促地方落实生态环境保护责任的硬招实招。

　　以法治之力为督察利剑淬火加钢。法典将生态环境保护督察制度写入，对组织开展全面督察、整改等作出详细法律规定，将推动督察在法治轨道上走深走实，为美丽中国建设提供更加有力的制度保障。

　　发展之路：“走出一条生态优先、绿色发展的新路子”

　　一张证书，蕴含着绿水青山向金山银山的转化之道——

　　2025年底，浙江开化县池淮镇石门村村民方国华接过了全国首张山林股权证，标志着浙江省集体林权制度改革从“确权”迈入了“股权分红”的新阶段，让林农的绿色资产有了更清晰、更可预期的收益保障。

　　开化县地处钱塘江源头。早在2018年，当地就率先启动集体林地地役权改革，通过经济补偿换取林地的统一监管，让农民从“砍树变现”到“护林生金”。

　　人不负青山，青山定不负人。习近平总书记强调，“完善生态保护补偿制度和生态产品价值实现机制，真正让保护者、贡献者得到实惠”“走出一条生态优先、绿色发展的新路子”。

　　生态环境法典作出明确规定，国家健全生态产品价值实现机制，形成多元化的生态产品价值实现路径，推进生态产业化和产业生态化。

　　落地碳汇交易，让山林草木成为可量化的绿色资产；探索生态补偿机制，让守护绿水青山的地方和群众收获生态红利；发展林下种养，凭借生态优势让农产品实现优质优价……各地完善生态产品价值实现机制，探索生态系统生产总值核算，逐步走上一条生态保护与经济发展的“双赢”之路。

　　在内蒙古呼和浩特中环产业园，一座总投资40多亿元的智慧工厂已顺利投产，工厂内一个个机械臂正精准组装光伏板。

　　2023年6月，习近平总书记来到中环产业园考察，强调坚持绿色发展是必由之路，叮嘱能源建设不能光靠传统产业，要大力发展新能源、清洁能源，努力实现碳达峰碳中和，建设绿色中国。

　　言语谆谆，期许殷殷。

　　今年5月中旬，世界首条以输送新能源为主的特高压通道——青豫特高压工程累计输送电量突破1000亿千瓦时。

　　“西电东送”是我国能源发展的重大战略。在“双碳”目标推动下，源源不断的绿电，正助力东部地区能源结构调整。

　　“十四五”时期，我国构建了全球最大、发展最快的可再生能源体系，能源消费“含绿量”持续提升，全国万元国内生产总值能耗累计降低16.1%。

　　“十五五”时期是实现碳达峰的关键期、攻坚期。“十五五”规划纲要部署加快经济社会发展全面绿色转型，专章部署积极稳妥推进和实现碳达峰，释放出绿色低碳发展方向不变、力度不减的强烈信号。

　　立法回应时代命题。生态环境法典开创性设置绿色低碳发展编，区别于传统环境立法侧重末端污染治理的模式，将法治关口前移，从源头规范发展方式转变。相关规定将有利于推动生产生活方式绿色化、低碳化，走向高质量发展、高品质生活、高水平保护相统一的新境界。

　　良好的生态环境是世界人民的共同追求，中国始终是绿色发展的坚定行动派、重要贡献者。

　　2025年9月，习近平总书记在联合国气候变化峰会发表视频致辞时，郑重宣布中国新一轮国家自主贡献。

　　“到2035年，中国全经济范围温室气体净排放量比峰值下降7%-10%”“非化石能源消费占能源消费总量的比重达到30%以上”“新能源汽车成为新销售车辆的主流”“气候适应型社会基本建成”……一组涵盖减排力度、能源结构、行业转型、气候韧性等多个方面的系统性目标，在国际社会引发积极反响。

　　大国有大格局，大国有大担当。助力发展中国家实现绿色低碳发展，中国在行动。

　　在毛里塔尼亚，中国援建的畜牧业技术示范中心在这片土地扎根，黄沙漫卷处生出连片新绿。当地居民生活换了模样，也认识到保护环境和发展畜牧业并不矛盾。

　　在非洲中部，中国援助的“非洲光带”项目将为乍得、布隆迪等非洲国家数万户无电贫困家庭点亮灯火，帮助非洲走上绿色低碳发展之路。

　　“习近平生态文明思想是送给全世界的珍贵礼物。”联合国前副秘书长埃里克·索尔海姆由衷赞叹。而今，这一思想的智慧光芒闪耀在生态环境法典的字里行间，为携手各方书写全球生态文明建设新篇章提供指引。

　　法典专门规定了国际条款，提出国家加强生态环境领域的国际合作，履行中华人民共和国缔结或者参加的国际条约规定的义务，并对开展应对气候变化领域国际合作等作出规定。

　　“法典不仅立足于中国特色社会主义基本国情和中国式现代化伟大实践，更以负责任的态度，将《巴黎协定》等条约规定的国际法义务转化为国内法规范，秉承人类命运共同体的理念，为世界生态环境治理贡献中国智慧和中国方案。”生态环境部法规与标准司司长赵柯说。

　　法治为笔，山河为卷。在习近平生态文明思想科学指引下，在生态环境法典护航下，驰而不息、久久为功，我们必将书写出美丽中国建设的崭新篇章。（记者 齐中熙、高敬、黄垚、魏弘毅）
