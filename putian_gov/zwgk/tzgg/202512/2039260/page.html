中共莆田市委关于制定莆田市国民经济和社会发展第十五个五年规划的建议

（2025年11月27日中国共产党莆田市第八届委员会第十次全体会议通过）
来源:市委改革办 时间：2025-12-24 15:04
| | | |

　　中国共产党莆田市第八届委员会第十次全体会议，认真学习贯彻党的二十届四中全会和省委十一届九次全会精神，紧密结合莆田实际，就制定莆田市国民经济和社会发展第十五个五年规划提出以下建议。

　　一、“十五五”时期是莆田在中国式现代化建设中奋勇争先的关键时期

　　1. “十四五”时期莆田发展取得显著成就。“十四五”时期是莆田发展具有里程碑意义的五年。五年来，面对错综复杂的国际形势和艰巨繁重的改革发展稳定任务，市委坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记重要讲话重要指示批示精神和党中央决策部署，在省委坚强领导下，团结带领全市人民接续奋斗、砥砺前行，经受住世纪疫情严重冲击，有效应对一系列重大风险挑战，推动绿色高质量发展先行市建设取得更大成效。综合实力明显提升，地区生产总值突破3000亿元，年均增长5.1%，居民人均可支配收入达到4.35万元，年均增长6.3%，获评“国家历史文化名城”“中国投资热点城市”“全国先进制造业百强市”“国家产融合作试点城市”“中国最具人才吸引力城市100强”，上榜中国最佳地级城市营商环境50强。产业发展加快转型，实体经济根基稳固，获评“中国鞋都”“中国食品产业名城”“世界美酒特色产区·中国啤酒制造之城”“中国夜间经济繁荣度TOP100城市”。城乡融合发展步伐加快，城市中的现代农村、人与自然和谐共生的现代化城市建设全面推进，兴化府历史文化街区、绶溪公园、“莆阳福道”“水上巴士”、大型木雕《京杭大运河》文旅融合项目、莆田元宵、莆田龙舟等成为城市靓丽名片。生态文明亮点凸显，实施木兰溪综合治理作为党的百年奋斗历程成果亮相中国共产党历史展览馆，木兰溪综合治理工程入选全国“人民治水·百年功绩”治水工程，木兰溪流域获评全国“绿水青山就是金山银山”实践创新基地，湄洲岛入选国际“零碳岛屿”标准试点。改革开放纵深推进，湄洲岛和北岸一体化发展实现历史性破局，高质量办好世界妈祖文化论坛、湄洲妈祖文化旅游节、海峡论坛·妈祖文化活动周，高规格举办世界兴安同乡恳亲大会暨世界莆商大会，高水平开展“天下妈祖回娘家”“湄洲妈祖巡天下”等活动，区域品牌影响力不断扩大，莆台融合不断深化。社会事业全面进步，“三大惠民工程”滚动实施，基本公共服务更加均衡可及，共同富裕路径稳步探索，获评中国“美好宜居典范城市”“年度‘美好文化’城市”及“国家食品安全示范城市”，蝉联三届全国文明城市，荣获全国双拥模范城“七连冠”。平安莆田、法治莆田建设持续深化，“全市一张图、全域数字化”“党建引领、夯基惠民”等工作模式被国务院办公厅通报表扬，在全国抓党建促乡村振兴推进会上作交流，社会大局安定稳定，群众安全感满意度持续提升。全面从严治党向纵深推进，良好政治生态持续巩固发展。莆田在新时代改革开放中迈出新的坚实步伐，在第二个百年奋斗目标新征程中实现良好开局。这些重大成就，从一个市域充分彰显了“两个确立”的决定性意义，生动诠释了习近平新时代中国特色社会主义思想的真理伟力和实践伟力。

　　2. “十五五”时期是实现“和美莆田、共同富裕”新愿景、推进中国式现代化莆田实践的重要阶段。“十五五”时期是承前启后、继往开来的关键时期，必须紧紧围绕我国二〇三五年基本实现社会主义现代化的战略安排，结合我省部署要求，扭住目标不放松、一张蓝图绘到底，为“十六五”攻坚冲刺提供坚实支撑。“十五五”时期是夯实基础、全面发力的关键时期，必须把握高质量发展爬坡过坎的特征，最大化释放港口、民营经济、生态等比较优势，补齐产业发展、科技创新、资源环境及民生社会事业等突出短板，推动事关全局、事关长远的战略任务取得突破性进展。“十五五”时期是奋勇争先、再上台阶的关键时期，必须聚焦在中国式现代化建设中奋勇争先，以更高站位、更大格局、更宽视野谋划推进工作，持续拉高标杆、争先进位，推动各项事业发展迈上新的更高台阶，进一步彰显莆田在全国全省发展大局中的定位、担当和作用。

　　3. “十五五”时期莆田发展环境面临深刻复杂变化。当前和今后一个时期，世界之变、时代之变、历史之变正以前所未有的方式展开，莆田发展处于战略机遇和风险挑战并存、不确定难预料因素增多的时期。从国际看，世界百年变局加速演进，国际力量对比深刻调整，新一轮科技革命和产业变革加速突破，同时，世界变乱交织、动荡加剧，国际经济贸易秩序遇到严峻挑战，世界经济增长动能不足，大国博弈更加复杂激烈。从国内看，我国经济基础稳、优势多、韧性强、潜能大，长期向好的支撑条件和基本趋势没有变，中国特色社会主义制度优势、超大规模市场优势、完整产业体系优势、丰富人才资源优势更加彰显。在推进现代化建设中，莆田既面临推进绿色高质量发展的新机遇，也面临不进则退、慢进亦退的区域发展态势。从自身看,“十四五”时期取得的发展成就为我市新一轮发展奠定基础、积蓄力量，全市10条重点产业链聚链强核、延链成势，新业态新模式新动能厚积薄发，经济发展后劲潜力可期。尤其是党中央赋予福建探索海峡两岸融合发展新路、建设两岸融合发展示范区的重大战略使命，也是莆田千载难逢的重大历史机遇。同时，仍然存在产业链发展水平不高，创新动能接续不足，资源环境容量不够，区域发展还不均衡，重点领域还有风险隐患等短板和弱项。

　　变局蕴含机遇，挑战激发斗志。要深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”，保持战略定力，增强必胜信心，准确识变、科学应变、主动求变，敢于斗争、善于斗争，集中力量办好自己的事，善于在危机中育先机、于变局中开新局，奋力开创中国式现代化莆田实践新局面。

　　二、“十五五”时期莆田经济社会发展的总体要求和主要目标

　　4. “十五五”时期莆田经济社会发展的总体要求。坚持马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观，全面贯彻习近平新时代中国特色社会主义思想，深入贯彻党的二十大和二十届历次全会精神，全面落实习近平总书记对福建工作的重要讲话重要指示批示精神，紧紧围绕在中国式现代化建设中奋勇争先，按照新福建建设宏伟蓝图，统筹推进“五位一体”总体布局，协调推进“四个全面”战略布局，统筹国内国际两个大局，完整准确全面贯彻新发展理念，坚持稳中求进工作总基调，聚焦“和美莆田、共同富裕”新愿景，以经济建设为中心，以推动高质量发展为主题，以改革创新为根本动力，以满足人民日益增长的美好生活需要为根本目的，以全面从严治党为根本保障，以木兰溪综合治理为总抓手，做好产业发展、城乡建设、基层治理、民生保障、港口崛起文章，强化人才、营商环境支撑，实施创新、数字、品牌战略，建设妈祖故里文化名城、山水诗画生态韵城、匠心智造产业新城、通江达海战略港城，推动经济实现质的有效提升和量的合理增长，推动人的全面发展、全体人民共同富裕迈出坚实步伐，确保基本实现社会主义现代化取得决定性进展。

　　5. “十五五”时期经济社会发展的主要目标。坚持党的全面领导，坚持人民至上，坚持高质量发展，坚持全面深化改革，坚持有效市场和有为政府相结合，坚持统筹发展和安全，加快建设和美莆田，推动共同富裕取得突破性成果，开创中国式现代化莆田实践新局面，实现闽中崛起。今后五年全市发展要实现以下主要目标。

　　——高质量发展迈上新台阶。经济增长保持在合理区间，全要素生产率稳步提升，发展质量和效益跻身全省前列，内需拉动经济增长主动力作用持续增强，10条重点产业链迈向中高端水平，发展新质生产力、服务和融入新发展格局、建设现代化经济体系取得重大突破，迈入国家创新型城市行列，成为具有全国影响力的新型工业化强市。

　　——高水平开放构筑新优势。市场经济体制机制更加完善，市场化、法治化、国际化、便利化营商环境达到更高水平，新时代民营经济强市基本建成，全社会投资创业活力充分激发，重点领域和关键环节改革取得新突破，莆台融合发展成果更加丰硕，国家级跨境电子商务综合试验区、国内一流亿吨大港等建设取得更大成效，更高水平开放型经济新体制基本形成。

　　——高能级城市塑造新格局。木兰溪新区加速崛起，东拓滨海、南进临港的城市框架全面拉开，城市综合承载力不断增强，现代综合交通枢纽体系更加完备，和美乡村更加宜居宜业，创新、宜居、美丽、韧性、文明、智慧的现代化人民城市建设达到更高水平。

　　——高颜值生态展现新面貌。生态文明建设走在全国、全省前列，“木兰溪样本”、湄洲岛“近零碳岛屿”建设样本全国推广，形成从山顶到海洋的全流域、全系统、全生命周期的生态文明建设大格局，经济社会全面绿色转型，清洁低碳安全高效的新型能源体系更加完备，碳达峰目标顺利实现。

　　——高品质生活取得新成果。高质量充分就业取得新进展，居民收入增长和经济增长同步、劳动报酬提高和劳动生产率提高同步，分配结构得到优化，中等收入群体持续扩大，公共服务均等化、普惠化、便捷化水平明显提高，共同富裕取得突破性进展。

　　——高品位文化焕发新风采。文化自信更加坚定，主流思想舆论不断巩固壮大，社会主义核心价值观广泛践行，文化产品和服务供给能力显著提高，妈祖文化、莆仙戏等特色文化繁荣发展，国家历史文化名城影响力全面提升，成为国内一流的旅游和消费目的地，更高水平文化强市和旅游强市建设迈出坚实步伐。

　　——高效能治理实现新提升。市域治理体系和治理能力现代化水平显著提升，法治莆田、平安莆田、信用莆田等制度更加健全完善，国家安全体系和能力进一步加强，重点领域风险得到有效防范化解，社会治理和公共安全治理水平明显提高，发展安全保障更加有力，社会更加安定和谐。

　　在此基础上再奋斗五年，到二〇三五年全市经济实力、科技实力、综合竞争力大幅跃升，人民生活更加幸福美好，在基本实现社会主义现代化中走在前列。

　　三、以新质生产力引领高质量发展，巩固壮大实体经济根基，着力打造匠心智造产业新城

　　6. 加快构建具有莆田特色优势的现代化产业体系。旗帜鲜明发展实体经济，坚持智能化、绿色化、融合化发展方向，因地制宜发展新质生产力，建设先进制造业强市。持续深化“链长制+云平台”工作机制，完善产业图谱，构建链长链主协同机制，以龙头带动产业强核提质、延链补链、集中集聚。优化提升传统产业，巩固提升鞋服、工艺美术、食品等产业在全国产业分工中的地位和竞争力，加快制造业数智化转型，发展智能制造、绿色制造、服务制造，加速产业发展模式和组织形态变革。实施战略性新兴产业融合发展工程，推进新技术新产品新场景大规模应用，加快新型功能材料、电子信息、新能源、高端装备、生命健康等新兴产业集群发展。前瞻布局未来产业，建立未来产业投入增长和风险分担机制，推动海水综合利用、低空经济、未来能源、量子科技、生物制造等未来产业成为新的经济增长点。加强工业园区标准化建设，系统推进园区高水平开发。实施服务业扩能提质行动，大力发展电子商务、商务服务、健康养老、金融服务等服务业，分领域推进生产性服务业向专业化和价值链高端延伸，促进生活性服务业高品质、多样化、便利化发展。

　　7. 奋力推进科技创新和产业创新深度融合。深入实施创新战略，完善区域创新体系，推进莆田高新区“一区多园”建设，谋划建设莆田科创集中区，争取承接国家重大科技发展战略布局，打造创新创造之都。深入实施“一产业链一研究院”工程，筹建一批技术创新公共平台。强化企业创新主体地位，构建企业创新活力凸显的产业科技创新体系，支持科技型领军企业和龙头企业联合上下游产学研力量共建创新联合体，更多承担科技攻关任务。实行高新技术企业后备培育工程，培育一批独角兽企业、单项冠军、链主企业。完善专精特新中小企业全周期培育体系，推动中小企业融通创新。加快各种创新资源向高新技术企业、科技型企业集聚，构建微成长、小升高、高壮大的梯次培育机制。强化科技成果转化运用，加快建设全市科技成果转移转化公共服务平台，围绕重点产业链建设行业类中试平台、产业类共性技术平台、产业化中试基地。加强技术经理人队伍建设。全面开展职务科技成果赋权改革。加强创新创业孵化载体建设，推动成立市创新创业协会，推动创业孵化资源集成服务。完善知识产权保护体系，促进知识产权高质量创造、运用和保护。

　　8. 全域推进数字莆田建设。深入实施数字战略，一体推进数字经济、数字政府、数字社会建设，推进城市全域数字化转型，打造数字中国建设综合试点重要承载地。建成集数据自动抓取、智能分析研判、指令精准送达等功能为一体的升级版“全市一张图”平台，构建全局互联互通、全量数据汇聚、全域业务协同的运行体系。健全信息基础设施统筹规划、整体布局和协调联动的体制机制，适度超前建设新型基础设施。健全促进实体经济和数字经济深度融合机制，做大做强数字经济核心产业。实施工业互联网创新发展工程，在重点行业打造“5G+工业互联网”场景应用，推动龙头企业开展数字化集成应用创新，建设一批数字化转型标杆企业、智能工厂。优化中小企业数字化转型供给体系，探索形成促进中小企业数字化转型长效机制。开展“人工智能+”行动，加强人工智能同产业发展、文化建设、民生保障、社会治理相结合，全方位赋能千行百业。推动平台经济创新和健康发展。

　　七、以党的领导凝聚奋进力量，充分调动全社会积极性主动性创造性，奋勇争先推动各项任务落地见效

　　30. 坚持和加强党的全面领导。持续用党的创新理论统一思想、统一意志、统一行动，完善推动习近平总书记重要讲话重要指示批示精神和党中央重大决策部署落实机制，不折不扣推动党中央决策部署在莆田落地生根、开花结果。树立和践行正确政绩观，完善推动绿色高质量发展考评激励办法，增强数字赋能干部政绩考核的实效，对各级领导班子和领导干部精准画像、精确到人，推进干部能上能下常态化。强化教育培训和实践锻炼，全面提高干部现代化建设能力。坚持严管和厚爱结合、激励和约束并重，激发干部队伍内生动力和整体活力。统筹推进各领域基层党组织建设，深化近邻党建和产业链党建，深入推进新兴领域“两个覆盖”集中攻坚行动，增强党组织政治功能和组织功能。锲而不舍落实中央八项规定及其实施细则精神，健全数字赋能为基层减负长效机制，推进作风建设常态化长效化。保持反腐败永远在路上的清醒坚定，坚持风腐同查同治、存量增量一起查，推动反腐败斗争向基层延伸、向群众身边延伸。深化以案促改促治，推进科技赋能监督工作，强化对权力运行的制约和监督。进一步丰富御史文化等特色廉洁资源供给，不断厚植清廉土壤。深化容错纠错机制探索运用，引导党员干部在遵规守纪中改革创新、干事创业。

　　31. 深化拓展全过程人民民主实践。坚定不移走中国特色社会主义政治发展道路，坚持党的领导、人民当家作主、依法治国有机统一。坚持好、完善好、运行好人民代表大会制度，支持和保证人大及其常委会依法行使立法权、监督权、决定权、任免权，确保国家机关依法行使权力、履行职责，确保人民群众民主权利、合法权益得到维护和实现。健全吸纳民意、汇集民智工作机制，加强代表工作能力建设，落实常态化联系代表和群众工作制度，推动代表联系群众活动室建设提质增效，深化民生实事项目人大票决工作。坚持和完善中国共产党领导的多党合作和政治协商制度，坚持党的领导、统一战线、协商民主有机结合，坚持发扬民主和增进团结相互贯通、建言资政和凝聚共识双向发力。发挥人民政协作为专门协商机构作用，完善知情明政、调研视察、协商议政、民主监督、成果转化环环相扣工作机制。健全委员联系界别群众制度，持续擦亮富有莆田特色的“委员履职活动日”“开门办提案”“莆事好商量”等履职品牌，推进协商民主广泛多层制度化发展。发挥工会、共青团、妇联等群团组织联系服务群众的桥梁纽带作用，推进产业工人队伍建设改革，进一步推动青年发展型城市建设。完善大统战工作格局，巩固和发展最广泛的爱国统一战线，发挥党外知识分子和新的社会阶层人士优势作用。以铸牢中华民族共同体意识为主线，扎实推进民族团结进步创建工作走深走实。坚持我国宗教中国化方向，加强宗教事务治理法治化。

　　32. 深化法治莆田建设。全面推进科学立法、严格执法、公正司法、全民守法。全面贯彻实施宪法，维护宪法权威。深化立法领域改革，科学编制立法规划计划，推进重点领域、新兴领域立法，加强“小切口”“小快灵”立法实践。强化法治政府建设，全面落实行政规范性文件备案审查，完善实质性化解行政争议机制。深化法治社会建设，加强刑满释放人员、严重精神障碍患者、严重不良行为未成年人和“三失一偏”人员等重点群体教育管理，完善社会矛盾纠纷多元预防调处化解综合机制。深入推进依法行政，深化行政执法体制改革，完善基层综合执法体制机制。深入推进数字政法建设，强化跨部门执法司法协同和监督。规范司法权力运行，完善司法公正实现和评价机制。强化检察监督，加强公益诉讼。依法保障人身权、财产权、人格权，健全规范涉企执法长效机制，防止和纠正违规异地执法、趋利性执法。健全执行工作机制，有效解决“执行难”问题。加快涉外法治体系和能力建设，推动形成涉外法治大协同工作格局。加强领导干部依法办事监督检查，完善综合性法治评价工作机制。

　　33. 健全规划制定和落实机制。坚决贯彻党中央决策部署和省委工作要求，按照本次全会精神，制定“十五五”规划纲要及专项规划，形成定位准确、边界清晰、功能互补、统一衔接的规划体系。强化规划实施监测评估和监督，健全政策协调和工作协同机制，确保市委关于“十五五”规划部署落到实处。贯彻尊重劳动、尊重知识、尊重人才、尊重创造的方针，充分调动各方面的积极因素，激发全社会干事创业、创新创造活力，形成人尽其才、才尽其用、万众一心、勠力进取的生动局面。

　　全市上下要更加紧密地团结在以习近平同志为核心的党中央周围，在省委坚强领导下，扭住目标不放松，一张蓝图绘到底，牢记嘱托、勇毅前行，锐意进取、真抓实干，为加快实现“和美莆田、共同富裕”新愿景、在中国式现代化建设中奋勇争先不懈奋斗！
