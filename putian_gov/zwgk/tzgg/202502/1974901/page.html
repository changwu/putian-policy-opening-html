中共莆田高新技术产业开发区工作委员会关于巡察整改进展情况的通报

来源:莆田市委巡察办 时间：2025-02-17 17:40
| | | |
 

根据莆田市委巡察工作统一部署，2023年6月5日至2023年7月21日，市委巡察一组对莆田高新区党工委开展了巡察，并于2024年1月3日反馈了巡察意见。按照党务公开原则和巡察工作有关要求，现将巡察整改情况予以公布。

一、坚决扛起巡察整改政治责任

莆田高新区党工委认真贯彻落实党中央、省委、市委关于巡察整改的部署要求，坚决把抓好整改工作作为重要政治任务，以高度的政治自觉和强烈的责任担当，扎实推进各项整改工作。

一是强化思想认识，增强整改自觉。第一时间召开党工委（扩大）会议，传达有关文件、会议精神，全面部署整改工作。集中整改期内，党工委组织学习新修订的《中国共产党巡视工作条例》等，精准把握整改要求，确保不折不扣推进落实。召开学习贯彻习近平新时代中国特色社会主义思想主题教育暨巡察整改专题民主生活会，班子和班子成员深入对照查摆，严肃开展批评和自我批评，进一步深挖根源、找准病灶，凝聚共识、促进整改。党工委深刻认识到必须以最坚决的态度、最有力的行动、最扎实的措施，全力以赴抓好整改工作。

二是强化组织领导，聚力推进整改。党工委坚决担负起整改的主体责任，研究制定《关于落实市委巡察一组巡察莆田高新区党工委反馈意见整改方案》，提出151条具体整改举措，逐项明确责任领导、责任部门、整改措施、整改时限等；集中整改期间，党工委先后8次召开专题会议，研究解决整改过程中的困难问题，有力协调推动整改工作。党工委主要负责同志坚决扛牢巡察整改第一责任人责任，带头认领问题，牵头负责5个整改事项，经常性与班子成员就整改事项进行研究讨论，确保扎实推进；班子成员认真落实“一岗双责”，抓好分管领域的整改落实工作；各局（办）、中心全面落实整改措施，确保有力推进；纪工委不定期监督检查，确保整改工作落地见效。

三是强化建章立制，提升整改质量。把巡察整改工作与开展学习贯彻习近平新时代中国特色社会主义思想主题教育、党纪学习教育、深化拓展“深学争优、敢为争先、实干争效”行动等相结合，深入研究巡察发现问题背后的普遍性、倾向性、深层次问题，坚持举一反三，标本兼治，着力查找制度漏洞、监管盲点，把整改过程转变为解决问题、建章立制、堵塞漏洞、推动工作的过程，从源头上防止类似、重复的问题发生。推动建章立制18项，探索建立莆田高新区全方位融入涵江区绿色高质量发展和统筹推进“一区多园”工作制度，更好推动巡察整改与完善制度、深化改革、促进发展相结合，做到既治标又治本，为加快推进高新区绿色高质量发展提供强大动力。

二、巡察反馈问题的整改情况

（一）聚焦党中央各项决策部署及省委、市委工作要求在基层的落实情况

1.高水平科技自立自强发力不够，高新技术企业不够多、研发强度不够高。

整改情况：一是提升思想认识。党工委组织学习习近平总书记关于科技创新和高科技园区的重要论述，深刻领悟到科技创新是发展新质生产力的核心要素，要坚持以科技创新为引领，以原创性、颠覆性技术创新开辟高新区发展新领域新赛道、塑造高新区发展新动能新优势。二是推进问题整改。针对“高水平科技自立自强发力不够。高新技术企业不够多”问题，通过举办培训会、跟踪指导、建立培育库、组织参加科技成果对接会等方式推动解决。自巡察以来，组织召开业务培训会1场，40余家企业列入高新技术企业培育库进行跟踪辅导，组织企业参加中科院金属所科技成果对接会，促成产研合作项目1项，推荐29家企业获得高新技术企业认定。2024年以来，完成两批次共39家企业申报。2023年，莆田高新区火炬统计入库统计高新技术企业204家，占全市51.91%，较2022年上升了4.61%。针对“研发强度不够高”问题，通过指导申报科技惠企补助、开展培训等方式解决，自巡察以来，开展业务培训1场，指导企业争取各类科技补助1988.74万元。根据2023年火炬统计高企汇总的数据显示，2023年高新技术企业研发费用投入与营业收入的比例为7.8%，较2022年有提升。三是推动常态长效。配合涵江区出台《涵江区创新驱动发展战略行动方案（2023-2025年）》（涵政办〔2023〕31号），进一步推动创新链、产业链、资金链、人才链深度融合，增强创新竞争力。

2.战略性新兴产业占比较低，数字经济创新企业数量不多。

整改情况：一是加大招商引资。出台《莆田高新技术产业开发区产业项目准入办法（试行）》，明确电子信息、装备制造、新能源等新兴产业作为园区主导方向。突出长三角、粤港澳等重点地区开展专题招商，前往昆山、苏州、上海、合肥、深圳、佛山、东莞等地招商。二是建设小微产业园。推进标准产业园建设，布局建设国投·城北专精特新产业园、国投·食品产业园、国投·新能源汽车配套产业园、5G通号专精特新产业园和联东U谷·海峡智造产业谷。国投·城北专精特新产业园一期已有16家企业进驻产业园；国投·新能源汽车配套产业园围绕云度新能源汽车整车制造，引进上下游产业链企业5家；2024年开工建设联东U谷·海峡智造产业园；5G通号专精特新产业园完成项目一期陆域形成、五通一平、现场项目部建设及安全标准化施工建设；开工莆田德濠智造谷项目。三是培育战略性新兴产业。推荐福建省安特微电子有限公司“六英寸半导体芯片制造项目”等战新领域项目列入省、市重点技改项目库；2个项目入选2024年度省数字经济重点项目。2023年，高新区战略性新兴产业营业收入占高新区全部营业收入的比重为23.29%，较上年提高4.88%。四是培育“独角兽”、“瞪羚”创新企业。通过走访动员、线上宣传等途径，筛出4家企业进行跟踪培育。2024年，新增福建省数字经济核心产业领域“瞪羚”创新企业2家，占全市15.4%，比例有提升。

3.龙头品牌培育还需提升。

整改情况：一是健全优质中小企业梯度培育机制。根据企业税收贡献情况，建立规上企业单项冠军、龙头企业培育库，现有在库企业41家；根据企业生产经营情况，建立省级专精特新企业培育库，现有在库企业75家。二是加强政策宣传引导。加大扶持力度，制定惠企政策汇编，多部门联合开展宣传走访活动，引导税赋高、成长性好的企业树立做大做强的意识，积极参与创牌活动。三是加强重点企业培育。上榜全国“专精特新”高新区百强榜单；现有省级制造业单项冠军4家（新增1家）、省级工业龙头企业4家、省级工业龙头培育企业13家（新增2家），分别占全市的25%、25%、21.3%，较上年上升1.9%、1.5%、1.7%。现省级、市级“专精特新”企业各有31家、25家，分别占园区企业数的7.1%、5.7%，较上年上升3%、2.9%；2家企业获评国家级专精特新“小巨人”企业，实现零的突破。

4.科技、人才、政策等要素配置组合还有差距，科技服务能力还需提升，在孵企业知识产权数不够多。

整改情况：一是提高思想认识。自巡察以来，党工委组织集中学习相关内容2次，不断增强班子成员和园区干部对知识产权的认识，并结合全员挂钩企业机制等引导企业加强知识产权保护。二是提升孵化能力。2023年以来，组织开展企业知识产权申请、保护业务专题培训讲座1场。2023年，创业企业获得知识产权授权增至256项。莆田高新区科技企业孵化器引进并服务孵化项目11个，毕业项目5个。现有在孵企业88家，拥有知识产权企业28家，比例提至31.8%。三是强化“内培外引”。联合湄洲湾职业技术学院产学研合作处，落地产学研合作项目1个（省级技能大师陈威项目）；引进知识产权服务机构1家（博深专利事务所）。

5.引才留才、产教融合成效不够明显。

整改情况：一是提升思想认识。党工委组织学习习近平总书记关于人才工作的重要论述和《职业教育产教融合赋能提升行动实施方案（2023—2025年）》，高新区班子成员及各局（办）、中心负责人进一步树牢“科技是第一生产力、人才是第一资源”的发展意识，增强引导区内企业与高校、职业院校进行人才联合培育、产学研合作等的主动意识和业务能力。二是加强合作交流。莆田高新区领导多次带队前往湄洲湾职业技术学院就双方合作事宜进行商讨，并于2024年6月同湄洲湾职业技术学院签订共建共管协议。同时，莆田高新区分管领导带队到市人才集团等社会机构就可合作事宜进行交流，于2024年9月同市人才集团签订人才战略合作协议。三是注重引才留才。通过职业培训、技能竞赛、政策宣传、举办人才活动等方式，浓厚引才留才氛围。自巡察以来，开展职业培训班7期，约440人次参与；开展电工职业技能竞赛1场，40人参与；组织高层次人才座谈会1次。2023年以来，莆田高新区新增的13名高层人才均未离职，离职率较2020-2022年有明显下降。

6.意识形态工作责任制落实不够到位，学习贯彻新思想不够深入。

整改情况：一是强化思想认识。党工委组织学习《涵江区落实党委（党组）意识形态工作责任制实施方案》等2个文件，高新区班子成员和各局（办）、中心负责人进一步领悟了党的创新理论的强大力量，切实增强全面系统、及时跟进学习的主动意识，进一步增进了政治认同、思想认同、理论认同、情感认同。二是及时查缺补漏。经自查，党工委理论学习中心组共遗漏重点学习内容5项。党工委理论学习中心组通过开展4次专题学习，完成对遗漏重点学习内容的补学。三是完善制度建设。经自查，发现2020年度党工委理论学习中心组成员仅1人撰写调研报告。对此，主要领导高度重视，牵头完善相关制度，明确中心组成员调研任务。2023年10月，印发《关于开展大兴调查研究工作的通知》，明确中心组成员调查研究选题方向。2023年11月，8名中心组成员共完成调研报告8篇，并召开调查研究成果交流会。印发《中共莆田高新技术产业开发区工作委员会工作规则》和《关于贯彻落实莆田市党委（党组）理论学习中心组学习实施细则的实施意见》，要求中心组成员每年撰写学习心得、调研报告或者理论文章不少于1篇。

7.对意识形态工作极端重要性的认识还需提升，制度还需进一步健全完善。

整改情况：一是强化理论学习。自巡察以来，党工委理论学习中心组开展意识形态工作相关专题学习2次、专题辅导报告1次，进一步提高了高新区班子成员对意识形态工作极端重要性的认识，掌握学习了意识形态工作责任制、党委（党组）理论学习中心组学习要求和公共领域宣传载体管理等方面的重要内容。二是健全工作制度。2024年3月，修订本单位贯彻落实意识形态工作责任制文件1份，制定意识形态工作约谈制度1份。三是开展自查工作。2024年1月下旬，对落实意识形态工作责任制情况开展全面自查，形成自查报告1篇。四是对标查缺补漏。及时开展自查，发现5位班子成员未就意识形态工作责任制方面存在的问题在民主生活会对照检查材料中进行查摆；2位班子成员2020年11月和2021年2月民主生活会个人对照检查材料中，意识形态工作方面查摆的问题相同；2021年度、2022年度，有3名班子成员未把意识形态工作责任制情况纳入述职报告；有2名班子成员未把意识形态工作责任制情况纳入2021年述责述廉报告。针对自查发现问题，相关班子成员及时进行补缺补漏，均已整改到位。巡察后，班子和班子成员严格落实要求，把意识形态工作作为重要内容纳入学习贯彻习近平新时代中国特色社会主义思想主题教育暨巡察整改专题民主生活会对照检查材料、2023年度述职报告、2023年度述责述廉报告等材料。

8.公共领域宣传载体管理还需加强。

整改情况：一是加强业务学习。自巡察以来，党工委理论学习中心组开展相关内容专题学习1次、专题辅导报告1次，党政办公室组织业务学习1次，增强班子成员和高新区干部意识形态工作阵地管理意识，切实提升公共领域宣传载体管理水平。二是开展自查自纠。巡察反馈会后，党政办公室立即组织人员对“‘三级审签’落实不规范”问题进行自查，发现不规范表格10份，立即落实整改。三是规范审签流程。通过邀请专家开展专题辅导报告，引导全体干部严格落实“三级审签”制度，执行“分级审核、先审后发”程序。2024年以来，微信公众号信息审签113次，公共领域宣传载体审签4次，均按规定落实。四是开设主题专栏。在“莆田高新”公众号开设“学习贯彻党的二十大精神”“学习贯彻习近平新时代中国特色社会主义思想”主题专栏。

（二）聚焦群众身边腐败问题和不正之风以及群众反映强烈的问题情况

9.存在形式主义、官僚主义现象，部署工作未体现时限。

（二）未完成的问题

1.推动新技术应用、新产业集聚还有差距。数字化转型程度不够高。

整改情况：一是组织理论学习。党工委组织学习习近平总书记关于新质生产力的重要论述，班子成员和各局（办）、中心负责人深刻体悟到要以科技创新推动产业创新，深化数字赋能转型，积极培育新兴产业和未来产业。二是强化指导培训。通过组织培训、入企服务、平台建设等鼓励企业进行数字化转型。邀请企业参加“数字工匠”职业培训和工业互联网赋能企业转型论坛，举办涵江区合力抓工业产融对接暨企业数字化转型专题讲座，组织区内相关企业积极参加莆田市鞋服产业数字化转型专题培训班，联合工信部门全面启动数字专员入企行动和“智改数转”诊断服务行动，专程参访省工业互联网研究院、凯邦绵伦等数字示范工厂学习典型企业经验。三是推进数字转型。抓好国家中小企业数字化转型城市试点工作部署落实，“点对点”发力，市、区、乡镇三级联动实现规上企业数字评测和诊断共计340家，完成总数全市第一；推荐18个项目列入市级产业数字化转型重点项目库，天天向上数字化工厂等5个项目申报2024年福建省新一代信息技术与制造业融合发展项目，福联申报人工智能典型应用示范场景；引导464家企业入驻福建省供需对接平台，332家企业入驻莆田市“亲清惠企平台”，组织实施33个省重点技改项目，拟引进数字化、智能化自动生产线设备58条以上。巡察以来，园区190家规上企业中，新增43家（共126家）企业配置智能化设备，新增9家（共27家）企业布置工业互联网云平台实现业务数字化管理，新增22家（共33家）企业做到环节实现各类数据汇聚及应用,新增35家（共47家）企业在生产计划环节实现数字化。四是加大政策扶持。出台《涵江区制造业数字化转型行动方案（2023-2025）》，聚焦鞋服、食品、电子信息、高端装备、新能源等重点行业，主攻智能制造，推动工业互联网创新应用，促进制造业数字化转型，提升制造业竞争力，进一步推进企业数字化转型，实现经济绿色高质量发展。

未完成整改原因及下一步措施：加大惠企政策宣传和争取，帮助企业降低转型成本；坚持标杆引领，宣传数字化转型典型案例，引导更多企业看到转型带来的竞争优势和经济效益，增强转型意愿；坚持目标导向，利用诊断服务协助企业设定清晰的数字化转型战略目标和路径，指导企业将数字化转型纳入长期发展规划，形成长效机制，力争2025年6月取得阶段性成效。

2.土地集约利用水平不够高。

整改情况：一是出台准入办法。印发《莆田高新技术产业开发区产业项目准入办法（试行）》，建立“亩产准入门槛”机制，意向投资企业报名竞前须签订《项目投资意向协议书》，竞得后须签订《工业用地履约监管协议书》，严把工业项目投资强度、产值和税收等。二是优化产业布局。落实《莆田市人民政府关于印发莆田市深入实施园区标准化建设促进绿色高质量发展三年行动方案（2024-2026年）的通知》（莆政规〔2024〕2号），进一步摸清园区企业用地情况，统筹规划小微产业园建设，推动园区标准化建设，国投·城北专精特新产业园、国投·新能源汽车配套产业园、联东U谷·海峡智造产业谷、临港标准化厂房等标准化厂房有序推进；加快麦芽生产加工、热电联产等亩均产出较高项目的建设进度，进一步提高土地集约水平。三是盘活低效用地。委托福州城建设计研究院拟定《莆田高新技术产业开发区国土空间规划》（征求意见稿），通过“腾笼换鸟”、“新建扩建”、“工改工”、“招商合作开发”等形式盘活海峡纺织、守鸿工贸等低效企业用地562亩，不断提高企业亩均税收，提升单位面积土地资源的产出率。2023年，高新区436家企业中新增亩均税超过20万元的有9家，新增亩均产值高于400万元的有1家。

未完成整改原因及下一步措施：持续挖掘土地使用潜力，加大工业产业园区标准化建设力度，通过“工业上楼”“工业梯田”等方式，集约化使用土地，盘活存量、优化增量；联合区直相关职能部门，持续深化推进“亩均论英雄”改革，进一步加大低效用地改造提升、综合评价结果运用和部门协同配合力度，持续支持引导企业提高土地资源要素利用效率；力争2025年6月取得阶段性成效。

3.推动科技创新政策落地不够到位。

整改情况：一是积极拓宽资金渠道，通过加强税收和非税收入征管、加大土地出让力度和土地增值税清算力度、盘活国有资产等方式增加财政收入。二是对相关资金进行梳理，制定支出方案，已拨付科技类奖补资金160.53万元。三是统筹财力和资金安排，整改资金已列入年度预算。

未完成整改原因及下一步举措：积极筹措资金，力争2025年12月前逐步拨付到位。

四、下一步计划

下一步，莆田高新区党工委将全力以赴、扎实有序做好巡察整改后续各项工作，以巡察整改为契机推进莆田高新区绿色高质量发展。

一是筑牢政治忠诚。巩固拓展学习贯彻习近平新时代中国特色社会主义思想主题教育成果，严格落实“第一议题”制度，深化拓展“深学争优、敢为争先、实干争效”行动，坚定落实习近平总书记关于科技创新、高新区发展等重要论述重要指示批示精神，引导园区上下深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”，推动党中央决策部署和省委、市委、区委工作要求在高新区不折不扣落实。

二是持续抓好整改。坚决落实习近平总书记关于巡视工作的重要论述，坚决落实党中央关于巡视巡察整改的最新决策部署，深入贯彻《关于加强巡视整改和成果运用的意见》等要求，坚决履行巡察整改主体责任，以钉钉子精神持续抓好问题整改。对已整改事项，党工委将适时组织开展“回头看”；对基本整改事项和未完成整改事项加大攻坚力度，确保尽快高质量整改到位；对需要长期整改的任务，明确目标任务和工作举措，抓好跟踪督办落实，形成长效化。

三是从严管党治党。坚持严字当头抓班子、带队伍，实施能力提升和制度完善年行动，持之以恒纠“四风”树新风，纵深推进全面从严治党，持续完善制度建设，织紧制度笼子；强化制度执行和刚性约束，加强日常监督，及时纠正查处违反制度的行为，防止问题反弹回潮，以长效机制推动整改工作常态化、整改成果长效化。

四是推动绿色高质量发展。加强班子建设，大兴调查研究，弘扬“四下基层”“真抓实干、马上就办”工作作风，坚定落实市园区“20条”各项任务要求，统筹推进园区标准化建设、重点产业链培育、“一区多园”发展、优化营商环境等重点工作，全力推进园区绿色高质量发展，在全市“一五二三四”工作大局中发挥应有作用。用好巡察整改成果，激励干部担当作为，激发园区发展活力。
