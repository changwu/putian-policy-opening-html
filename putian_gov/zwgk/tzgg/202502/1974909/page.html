中共莆田市委台湾工作办公室关于巡察整改进展情况的通报

来源:莆田市委巡察办 时间：2025-02-17 17:49
| | | |
 

根据莆田市委巡察工作统一部署，2023年6月5日至7月21日，市委巡察三组对市委台港澳办开展了巡察，并于2024年1月5日反馈了巡察意见。按照党务公开原则和巡察工作有关要求，现将巡察整改情况予以公布。

一、高站位、高标准推进巡察整改工作

市委台办高度重视巡察整改工作，切实将巡察整改工作作为一项重大政治任务，摆上重要议事日程，认真抓紧抓实抓细，确保整改工作有力推进。

一是照单全收，立即部署落实。市委巡察三组巡察市委台港澳办情况反馈会召开后，主要领导第一时间主持召开会议，学习市委付书记在听取本轮巡察情况汇报时的强调意见，传达市委巡察三组巡察市委台港澳办反馈会精神，并部署巡察整改工作，要求认真制订整改方案，落细整改措施，严格按照规定的时间节点抓好整改。

二是强化领导，压实整改责任。市委台办切实担负起巡察整改的主体责任，成立由主要领导为组长，其他处级（办）领导干部为副组长的巡察整改工作领导小组，统筹抓好整改工作。主要领导作为第一责任人，对巡察整改工作负总责，其他分管领导认真履行“一岗双责”， 抓好分管科室整改工作的组织领导和协调督促工作。同时，认真研究制定整改方案，细化整改措施，明确责任领导、责任科室和整改时限，确保问题整改到位。

三是定期研究，扎实推进整改。主要领导高度重视整改措施的落实，巡察反馈会召开后，主要领导定期召开室务会议，听取巡察整改工作进展情况汇报，专题研究推进整改措施，深入讨论巡察整改有关的具体工作、建章立制等内容，有力推进整改工作保质保量、按进度有序推进。同时，各分管领导定期对分管科室整改落实情况进行监督指导，盯紧抓实，逐项对账销号，巩固落实。

四是建章立制，形成长效机制。着眼建立长效机制，推动建章立制，坚持举一反三，集中精力抓好巡察整改“后半篇文章”，提升整改实效。巡察整改期间，重新修订完善了涉及财务管理、议事规则、学习、意识形态等方面的制度，有效巩固了巡察整改工作成效。

二、巡察反馈问题的整改情况

（一）聚焦党中央各项决策部署及省委、市委工作要求在基层的落实情况

1.学习贯彻习近平总书记关于对台港澳工作的重要论述不够深入。

（1）落实“第一议题”制度不够及时。

整改情况：一是提高思想认识。中心组组织学习《中国共产党党组工作条例》、《莆田市党委（党组）理论学习中心组学习实施细则》等内容，坚持把理论学习作为一项重要任务摆在更加突出的位置。二是落实整改。中心组专题学习习近平总书记在纪念辛亥革命110周年大会上的重要讲话精神。同时，坚持边巡边改，理论学习中心组成员围绕党的二十大报告中关于“坚持贯彻新时代党解决台湾问题总体方略”内容开展专题研讨。三是制定学习计划。召开室务会议研究拟订2024年中心组学习计划，将习近平总书记重要讲话精神作为学习的首要内容，第一时间跟进学习习近平总书记重要讲话重要指示批示精神，确保“第一议题”制度落实到实处。2024年4月，根据市委有关通知精神，对2024年中心组学习计划进行修订完善。四是完善制度机制。召开室务会议研究修订《中共莆田市委台港澳办理论学习中心组学习制度》，并将修订后的制度印发中心组成员和各科、站、中心学习。

（2）港澳工作落实不够到位。

整改情况：一是提高思想认识。中心组组织专题学习习近平总书记关于对港澳工作的重要论述，充分认识做好港澳工作的重要性。二是研究部署港澳工作。召开室务会议，研究港澳工作。全市外事（港澳）工作座谈会传达上级有关精神，提出贯彻落实举措。三是进一步完善港澳工作资料。形成港澳工作相关资料手册，包括在莆港澳同胞人数、在莆港澳企业登记情况等9项内容。四是主动走访对接。赴福州拜访香港特别行政区政府驻福建联络处、澳门特别行政区招商投资促进局福州代表处。协调省港澳办邀请澳门特别行政区政府参与联合举办第九届世界妈祖文化论坛。

2.“以通促融”成效不够明显。

（3）吸引台商力度不足。

整改情况：一是加强学习。组织集体学习我市2024年一季度扩消费稳外贸稳外资若干措施等内容，提升业务能力。二是发挥作用。协同有关部门邀请台企台商来莆考察，2024年以来，已邀请6批次。三是加强跟踪。向有关部门了解2023年全市引进台商实际落地投资额。走访有关部门，动态跟踪了解我市招商重点和政策，提升业务能力。以举办第十五届海峡论坛·妈祖文化活动周等为平台，协调有关部门组织签约涉台项目5个。支持仙游台创园深化对台农业合作。四是深入走访。召开莆台融合发展暨台商台青代表座谈会，会上宣传并解读中共中央、国务院《关于支持福建探索海峡两岸融合发展新路建设两岸融合发展示范区的意见》（以下简称中央《意见》）以及省“15条”。深入走访调研海峡两岸生技和医疗健康产业合作区、秀屿台湾青年创业就业基地和台企台胞，向台胞台商宣传解读中央、省、市惠台政策。

3.“以惠促融”落实不够到位。

（4）学习相关政策不够深入。

整改情况：一是认真组织学习。组织集体学习省《实施意见》等政策。二是及时跟踪收集。2023年以来，中央和国家有关部委陆续出台支持两岸融合发展示范区建设的政策措施，我办安排专人负责收集，并做好与对应市直部门的对接联系，推动政策落实。同时，印发《各级惠台政策汇编》给各县区台办及台企台胞。三是创新惠台政策。积极推动落实台胞子女就学相关政策。创新出台鼓励台胞畅游妈祖故里政策，已于2024年10月29日在福建省贯彻落实中央《意见》系列新闻发布会（第四场）上发布。

（5）惠台政策宣传覆盖面不够广。

整改情况：一是加强惠台政策的学习。组织集体学习中共福建省委、福建省人民政府《关于贯彻落实〈中共中央、国务院关于支持福建探索海峡两岸融合发展新路建设两岸融合发展示范区的意见〉的实施意见》（以下简称省《实施意见》）等政策。二是借助媒体宣传惠台政策。通过东南网宣传中央《意见》、我省落实中央《意见》出台的首批15条配套措施。三是通过走访台企调研、召开座谈会等多形式宣传解读惠台政策。四是通过协会微信公众号扩大宣传。指导台商协会通过协会微信公众号宣传惠台政策。借助台商台胞微信群，将惠台政策及时送到台商台胞中。

（6）台胞就业创业岗位不够充足。

整改情况：一是加强政治学习，提高思想认识。中心组组织学习习近平总书记关于对台工作的重要论述及年度对台工作会议精神。二是积极对接。对接有关单位，征集企事业单位台青实习实训、就业岗位，我市2024年春季事业单位招聘计划设置岗位招收台胞；近年来我市积极征集发布台湾青年就业岗位。

（7）服务台商不够主动。

整改情况：一是加强政治学习，提升政治站位和担当意识。深入学习习近平新时代中国特色社会主义思想。集体学习新时代党解决台湾问题的总体方略。二是深入走访。走访仙游台创园等有关台企，了解情况，鼓励引进台企台胞；协助举办“在莆台胞元宵节联谊”活动；召开在莆台商台青代表座谈会，收集台胞台商意见建议，并积极推动解决。三是协助吸引台企台青。协助吸引台企台青入驻秀屿青创园，2024年7月，新引进2家台企完成注册。四是强化政策支持。联合有关单位开展新一批台企台胞金融信用证书颁证工作，2023年以来全市新增25家台企和48位台胞获颁金融信用证书。五是建立工作机制。建立办领导挂钩县区台办及办领导挂钩重点企业工作机制，并要求各县（区）台办相应建立挂钩其辖区内台企机制，会同县区台办主动服务台商。

4.“以情促融”还有差距。

（8）对台宣传力度不够。

整改情况：一是加强对台宣传。依托相关媒体、平台加大对台宣传力度，营造积极的舆论导向。二是指导更新网站。走访有关民间机构，指导及时更新网站内容，深化妈祖文化宣传。三是指导加大对台宣传力度。指导民间交流机构通过所辖的网站、微信公众号等平台开展宣传活动，加大对莆台融合发展、莆台妈祖文化交流活动等的宣传推广。

（9）指导基层开展工作不够到位。

整改情况：一是发挥示范点作用。深入走访示范点，开展调研指导。二是拟订交流方案。指导县区台办做好业务工作，拟订交流活动方案。三是建立机制。研究制定走访我市涉台交流基地、中心、示范点的工作机制。四是加强示范点工作的跟踪。2024年以来，各县区已收集整理辖区内交流活动100余场。

（10）交流活动管理不够到位。

整改情况：一是研究制定流程。研究制定了相关工作规范。二是加强活动管理。三是加强实地指导。走访民间机构，宣传政策，做好业务指导工作。

（11）推动民间交流力度不够。

整改情况：一是邀请台胞参加活动。邀请台胞来莆参加第十六届海峡论坛·妈祖文化活动周等活动。二是推动莆台姓氏宗亲交流活动。林姓宗亲会等来莆参访，前往湄洲岛开展妈祖文化及莆台姓氏宗亲交流活动。邀请同乡会组织乡亲回乡走访谒祖。推动莆台吴妈、五帝等民间信仰交流，以及莆台妇女、两岸婚姻家庭互动。三是推动弘扬妈祖文化。2023年以来共推动举办莆台妈祖文化交流120多场次。成功举办海峡论坛˙妈祖文化活动周。2023年首次承办中央台办两岸同胞迎中秋联谊活动，配合湄洲岛首次举办海峡两岸同胞护驾湄洲妈祖金身巡安莆田活动。四是对接有关部门。办领导走访市直有关部门，进一步推动莆台佛教交流。

5.意识形态工作责任制落实不够到位。

（12）理论学习不够到位。

整改情况：一是提高思想认识。坚持把理论学习摆在更加突出的位置，严格落实“第一议题”制度。2024年以来，共组织15次中心组学习、29次集体学习，及时跟进学习习近平总书记重要讲话和重要指示批示精神。二是针对巡察指出的问题，积极落实整改。中心组组织学习习近平生态文明思想、习近平总书记关于安全生产重要论述、习近平总书记治理木兰溪的重要理念。组织全体干部学习习近平总书记关于对台工作的重要论述。三是完善制度机制。室务会研究通过《中共莆田市委台港澳办理论学习中心组学习制度》，进一步落实落细“第一议题”制度，动态跟进学习习近平总书记重要讲话重要指示批示精神。

（13）意识形态工作方案制定不够规范。

整改情况：一是提高思想认识。组织集体学习中共莆田市委办公室关于印发的有关通知文件。二是积极落实整改。结合我办工作实际，从适用范围、工作机构、工作原则、工作流程、工作要求五个方面研究制定了我办的工作机制，明确了相关工作流程。三是抓好贯彻落实。将文件印发给本办各科、站、中心，督促认真贯彻落实。四是举一反三，形成常态。对上级的相关工作要求，第一时间研究制定本办相应方案。

（14）意识形态内容表述不够规范。

整改情况：一是加强学习。中心组组织班子成员学习习近平总书记关于意识形态工作的重要论述及我市有关实施方案等文件精神。组织集体学习习近平总书记对宣传思想文化工作作出的重要指示。二是加强提醒。向班子成员发出提醒单，督促班子成员规范述责报告、述职报告中关于意识形态工作内容的表述。三是开展政治监督谈话。办主要领导对分管领导开展政治监督谈话，再次作出提醒。四是组织培训。邀请市委宣传部有关人员来我办作意识形态工作专题讲座。

二、聚焦群众身边腐败问题和不正之风以及群众反映强烈的问题情况

1.工作作风不够严实。

（15）调研指导不够深入。

整改情况：一是加强学习，改进作风。中心组深入学习习近平总书记关于力戒形式主义、官僚主义重要讲话和重要指示批示精神、习近平总书记关于调查研究的重要论述，不断加强作风建设。二是建立工作档案。下发建立有关工作档案的通知，指导县区台办抓好落实。三是健全机制，加强走访。研究制定走访交流基地、中心、示范点的相关工作机制，并制定走访计划，深入走访了湄洲妈祖祖庙、贤良港天后祖祠等涉台交流基地。走访调研有关院校，指导推动莆台高校青年交流活动；走访有关机构，指导推动莆台青年妈祖文化交流；推动有关部门举办2024年海峡两岸师生妈祖文化研习夏令营等活动。

（16）跟踪县区台办开展走访工作情况不够到位。

整改情况：一是提高认识。组织集体学习福建省弘扬“马上就办、真抓实干”优良传统作风的有关规定，不断改进工作作风。二是组织学习。组织县区台办对有关通知精神进行再学习。三是定期收集。督促县区台办每季度报送相关工作开展情况。四是强化跟踪落实。推动各县区台办之间加强相互学习借鉴，促进工作提质增效。

（17）企业情况掌握不够到位。

整改情况：一是加强学习。中心组组织学习习近平总书记关于加强作风建设的重要论述、习近平总书记关于力戒形式主义、官僚主义重要讲话和重要指示批示等精神。二是主动对接。主动对接有关部门，了解我市台资企业变动情况，掌握准确数据。三是建档完善。收集了解台企经营情况。

2.维护台胞权益不够靠前。

（18）诉求办理工作机制不够健全。

（一）基本完成整改的问题

1.吸引台胞力度不够。

整改情况：一是加强学习领会。集体学习中央《意见》、我省《实施意见》。二是积极谋划推动。认真贯彻落实中央《意见》和省实施意见，牵头拟订我市的工作清单。三是深化莆台交流。积极推动县区（管委会）和有关部门开展交流活动。四是鼓励台青来莆实习就业创业。通过走访相关经济园区、台青创业就业基地，推动台青来莆实习就业创业。2024年，我市共新增台青实习就业106人，其中合作区共新增台青实习实训11人、就业创业5人。

需进一步整改的原因及下一步措施：该工作需要进一步巩固提升。下一步，我办将进一步推动县区（管委会）和有关部门举办活动，吸引更多台胞来莆参加交流，吸引更多台青来莆实习实训、就业创业。力争2025年6月底前完成。

2.吸引台资项目力度不够。

整改情况：一是加强对接，了解情况。对接有关部门和相关县（区），配合推动合作区和台创园招商引资工作，2023年，合作区签约台资项目3个，已全部落地；台创园签约台资项目3个，已全部落地。2024年，合作区签约台资项目3个，正在推动中；台创园签约台资项目3个，已全部落地。二是积极配合，搭建平台。配合有关单位举办海峡两岸口腔医学专题研讨会、闽台健康产业融合发展论坛等活动，助力海峡两岸生技和医疗健康产业交流合作。三是加强学习，提升能力。对接有关产业主管部门，学习做好项目服务的业务知识。组织业务人员学习扩消费稳外贸稳外资若干措施等内容。四是加强跟踪，走访宣传。一方面，通过走访，深入宣传两岸融合发展相关政策。另一方面，通过走访涉台园区，有关台企，了解莆台产业融合情况。

需进一步整改的原因及下一步措施：该工作需要进一步推进。下一步，我办将继续督促县区（管委会）对接引进台资项目。力争2025年6月底前完成。

3.预算执行率不够高。

整改情况：一是加强学习。组织财务人员学习《中华人民共和国预算法》及其实施条例、《福建省人民政府关于深化预算管理制度改革的实施意见》；组织相关人员学习有关规定。二是举一反三。严格按照《中华人民共和国预算法》及其实施条例、《福建省人民政府关于深化预算管理制度改革的实施意见》规定，注重预算编制的准确性和预算的执行率，2023年11月编制了本单位2024年全年预算支出。三是建立制度。我办已会同有关部门拟订有关资金管理办法。

需进一步整改的原因及下一步措施：下一步，我办将认真执行有关资金管理办法，进一步提升预算编制的准确度和执行率。力争2025年6月底前完成。

（二）未完成整改的问题

1.台资项目落地跟踪力度不足。

整改情况：一是跟踪了解情况。一方面，深入了解签约台资项目进展情况，积极探讨未落地项目下一步落地可能、中断生产经营项目恢复营业可能。另一方面，积极走访联系台商，了解情况、收集诉求，并及时反馈协调，助力推进台资项目落地。二是加强对项目工作业务学习。2024年2月，对接有关产业主管部门，学习项目工作业务知识，提升跟踪项目的能力。组织集体学习我市出台的相关政策措施。三是建立工作机制。建立市、县区台办领导挂钩台资企业工作机制，并推动各县（区）台办相应建立挂钩其辖区内台企的机制。协同属地县区台办走访台资企业，做好台资项目服务工作。

未完成整改的原因及下一步措施：鉴于项目签约与落地需要一段时间，需要持续跟踪。下一步，我办将继续跟踪2023年、2024年签约项目进展情况，及时反馈协调、督促推进。力争2025年6月底前完成。

四、下一步计划

市委台办将按照市委的部署要求，在市委巡察办的指导监督下，继续抓好后续的工作。一是持续加强政治建设。深刻领会习近平总书记关于巡视工作的重要指示精神，学习贯彻习近平新时代中国特色社会主义思想主题教育，不断提高政治领悟力、政治判断力、政治执行力，增强“四个意识”，坚定“四个自信”，做到“两个维护”。二是继续抓好整改落实。坚决扛起全面从严治党政治责任，加强对巡察整改工作的政治领导、组织领导和思想领导，对尚未完全整改到位的，按照时间节点，倒排工作计划，扎实抓好落实。对已完成的整改事项，经常“回头看”，确保巡察整改工作落到实处。三是持续加强作风建设。大力弘扬“真抓实干、马上就办”的优良作风，以贯彻落实中央《意见》和我省《实施意见》为重点，抓好市工作清单的落实，全力推进莆台全域融合发展。四是持续巩固整改成效。综合运用巡察整改成果，既巩固“当下改”的举措，又形成“长久立”的机制。对本次修订完善的规章制度，班子成员以身作则带头执行，并认真督促全体干部职工抓好落实。总结巡察工作中的经验和做法，以制度的形式确定下来，并举一反三，进一步促进机关的规范化建设。
