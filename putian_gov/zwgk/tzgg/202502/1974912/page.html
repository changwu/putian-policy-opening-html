中共莆田市审计局党组关于巡察整改进展情况的通报

来源:莆田市委巡察办 时间：2025-02-17 17:53
| | | |
 

根据莆田市委巡察工作的统一部署，2023年6月5日至7月21日，市委巡察四组对中共莆田市审计局党组开展了巡察，并于2024年1月3日反馈了巡察意见。按照党务公开原则和巡察工作有关要求，现将整改情况予以公布。

一、坚决扛起政治责任，不折不扣落实问题整改

（一）局党组履行主体责任情况

局党组坚持把巡察整改工作作为重要政治任务抓紧抓实。一是坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻党的二十大关于巡视巡察工作的部署要求和习近平总书记关于巡视工作系列重要论述，提高思想认识、坚定政治方向，全面贯彻落实市委和市委巡察工作领导小组要求。二是成立以局党组书记、局长为组长，党组成员、总审计师为常务副组长，各分管领导为副组长，各科室（中心）负责人为成员的整改工作领导小组，强化组织领导，压实工作责任。三是及时召开专题民主生活会，逐条对照反馈意见指出的问题和提出的意见建议，主动认领责任，深入剖析检视、查找问题根源、严肃开展批评与自我批评，明确整改措施和方向，一体推进问题整改。

（二）党组书记履行第一责任人责任情况

局党组书记认真履行第一责任人责任，带头履责，以上率下，压紧压实巡察整改责任。一是及时主持召开党组（扩大）会议，认真组织学习贯彻市委巡察组对我局巡察情况及专项检查的反馈意见，把落实巡察整改作为检验增强“四个意识”的试金石，扎实做好巡察“后半篇文章”。二是主持起草巡察反馈问题整改方案，按照“一个问题、一名牵头领导、一抓到底”的工作机制，逐条逐项对照问题，亲自审定整改措施，及时督促领导班子成员、其他分管领导认真履行“一岗双责”，推进各分管领导切实担负起整改责任。三是主动沟通汇报整改方案，及时掌握并明确整改要求和方向；紧盯整改任务，把握时间节点，跟踪督促各分管领导落实落细整改措施，推进巡察问题整改。

（三）班子其他成员履行“一岗双责”情况

班子其他成员严格按照党组的工作部署，主动对号入座、主动认领问题，做到巡察问题个个有人抓，整改措施件件有着落。一是及时召集分管科室（中心），明确具体工作内容、责任人和联络人，确保党组各项具体部署、具体要求，及时有效落实到位。二是坚持从政治思想、具体事例、举一反三、建章立制等层面入手，及时召集分管科室（中心）干部，系统学习相关政治理论、各项规章制度，严格执行现有制度，不断建立健全规范机制。三是严格按照以巡促改、以巡促建、以巡促治的总体要求，把落实此次巡察问题整改与述责述廉、民主生活会对照检查等各类问题整改相融合，与审计日常业务相融合，联动推进各领域问题整改，扎实巩固拓展巡察整改成果。

（四）强化机制保障，巩固提升巡察成果

局党组坚持把巡察整改落地见效与建立长效机制相结合，在落实“当下改”的同时，进一步完善“长久立”机制，整改期间先后修订了《中共莆田市审计局党组工作规则》《中共莆田市审计局党组理论学习中心组学习制度》《中共莆田市审计局党组关于印发党员领导干部联系基层党组织工作制度的通知》等7项制度，进一步扎紧扎实制度笼子，规范权力运行，持续巩固巡察成果。2024年结合巡察整改科学谋划制定年度审计项目计划，2024年审计项目数量比2023年增加22%，项目重点涵盖省市重点项目、科技创新、粮食安全、医疗社保、职业教育、国资运营、资源生态等领域，扎实推进审计监督全面覆盖，以巡察整改促进提高审计工作质效。

二、巡察反馈问题的整改情况

（一）聚焦党中央各项决策部署及省委、市委工作要求在基层的落实情况

1.班子学习引领不够突出。

整改情况：一是强化思想认识。及时召开党组（扩大）会议，学习《中共中央关于加强党的政治建设的意见》，强化局领导班子的思想认识，增强落实“第一议题”制度意识，把思想和行动统一到党中央部署和要求上来。二是落实“第一议题”制度。坚持把学习习近平新时代中国特色社会主义思想和党的二十大精神、习近平总书记重要论述重要讲话重要指示批示精神、习近平总书记对审计工作的重要讲话重要指示批示精神等内容，作为党组会“第一议题”，第一时间组织传达学习。三是科学制定计划。根据市委宣传部、市委组织部印发的2024年全市党委（党组）理论学习中心组专题学习重点内容安排，拟定2024年党组中心组理论学习计划，明确学习重点、研读必要科目、研讨要求等，落实常态化学习研讨交流要求。四是修订学习制度。研究修订并印发《中共莆田市审计局党组理论学习中心组学习制度》，明确每个月开展学习不少于1次，集体学习研讨每季度不少于1次。五是加强理论学习。党组中心组系统组织学习全面从严治党主体责任规定和意识形态工作责任制等文件；围绕学习《习近平谈治国理政》第三卷、《习近平在福建》开展专题研讨；组织学习习近平法治思想等4方面内容，持续推动以上率下带动全局大兴学习之风。

2.党的二十大精神宣讲不够深入。

整改情况：一是坚持立行立改。局党组结合第二批主题教育，深入开展了“十百千”宣讲活动，组成以党组书记为组长、其他党组成员为组员的宣讲小分队，围绕乡村振兴发展、基层党建工作等相关主题，深入到度尾镇砺山村、鲤城街道洪桥社区等农村、社区开展宣讲，切实提高基层干部群众对党的二十大精神的知晓率，助力基层治理和乡村振兴。二是建立联系点制度。研究出台《中共莆田市审计局党组关于印发党员领导干部联系基层党组织工作制度的通知》（莆市审党〔2024〕17号），由党员领导干部结合分管工作，确定1-2个基层党组织作为自己的党建工作联系点，以党课、专题报告或宣讲等方式宣传党的创新理论、路线方针政策等。三是严格制度落实。各班子成员和其他党员领导干部及时学习党中央、国务院和省委省政府、市委市政府决策部署，强化理论武装。今年围绕宣讲主题，密切融合审计工作实际，前往联系的局机关各支部，县区审计局、挂钩的镇街、村居宣传党的创新理论、方针政策，推进党中央、国务院、省委省政府、市委市政府的决策部署落实。

3.践行习近平总书记关于治理木兰溪的重要理念和保护好湄洲岛的重要嘱托不够到位。

整改情况：一是加强理论学习。组织党员观看《变害为利 造福人民——习近平生态文明思想在福建木兰溪的先行探索》，会上党员干部结合审计工作实际，谈如何在审计工作中贯彻落实习近平生态文明思想。召开经济责任专题学习会议和党组（扩大）会议，学习习近平总书记关于治理木兰溪的重要理念、习近平总书记关于保护好湄洲岛的重要嘱托和《莆田市湄洲岛保护管理条例》，不断强化审计人员思想认识，强化责任担当，把思想和行动统一到党中央部署和要求上来。二是安排实施相关审计项目。印发《2024年全市审计项目计划实施方案》，安排木兰溪流域治理工程项目推进实施情况专项审计、保护湄洲岛专项资金审计和湄洲岛管委会湄洲镇党政领导干部经济责任审计和自然资源资产审计。木兰溪流域治理工程项目推进情况专项审计于2024年5月完成；保护湄洲岛专项资金审计于2024年6月完成。三是取得一定实效。出具木兰溪流域治理工程项目推进实施情况审计报告，审计揭示了5个方面37个问题，撰写的木兰溪流域治理工程项目推进实施情况审计专题报告，受到市委市政府主要领导肯定性批示，并督促相关部门出台《关于强化重点项目挂钩机制的通知》等项目管理制度，有效促进了木兰溪流域治理工程项目建设进度。出具保护湄洲岛专项资金管理使用情况审计报告，审计揭示3个方面16个问题。针对审计指出的问题，湄洲岛管委会高度重视，立即组织相关部门逐条逐项落实问题整改。

4.市委审计办参谋助手作用发挥不够充分。

整改情况：一是加强理论学习。召开党组（扩大）会议，深入学习中共中央印发的《深化党和国家机构改革方案》，强化对党中央在新的历史起点上深化党和国家机构改革的重要意义的认识，切实加强党中央对审计工作的领导，充分发挥审计监督作用。二是落实立行立改。及时召开2023年莆田市委审计委员会成员单位联络员会议，传达学习习近平在二十届中央审计委员会第一次会议上的讲话，通报了2022年度市本级预算执行和其他财政支出审计情况及2021年度预算执行审计未整改到位问题。会上，各成员单位就审计办运行情况及明年项目计划等方面进行深入的沟通交流，提出了3个方面10条宝贵的工作意见和建议，发挥了成员单位工作协调机制和联络员制度优势，形成工作合力。三是加大督察督办力度。2023年，市委审计委员会领导共对8份审计要情专报作出批示，市委审计办将领导批示的7个方面事项落实情况列为审计监督重大事项督察督办内容，向8个市直单位、4个县区、1个管委会发出督办通知书，督促相关单位落实整改任务。2024年，增设了2个信息报告载体，即以审计专题报告的方式，向委员会主任、副主任报告审计揭示的综合性、系统性重要问题，以审计重要信息报送的方式，向市委、市政府分管领导报告审计揭示的单项重要问题。2024年，共向委员会报送4份审计专题报告、2份审计要情专报、1份审计重要信息，涉及上级转移支付资金管理使用、国有资产管理使用等多个领域的问题。委员会主任、副主任均在第一时间作出肯定性批示。

5.对县区党委审计办督促指导不够到位。

整改情况：一是提高思想认识。组织审计干部专题学习习近平总书记对审计工作的重要讲话重要指示批示精神、2024年全国审计工作会议精神等，深刻领会习近平总书记亲自谋划、亲自部署、亲自推动审计领域重大工作的深层次含义，强化上级审计机关对下级审计机关的领导。二是深入贯彻落实。加强对县区党委审计委员会工作的领导。2023年10-11月由局长带队，赴各县区审计办、审计局开展调研，了解县区审计委员会及其办公室运行情况。调研形成了《做实研究型审计的市域探索与实践》《从四个维度推进党委审计委员会有力有效运行》2篇调研报告，其中《做实研究型审计的市域探索与实践》得到省审计厅主要领导的肯定性批示。三是强化调研推进。调研中，重点关注巡察指出的相关问题，向各县区反馈了解相关情况，要求各县区严格按照有关要求主动向组织部门提出年度经济责任审计项目计划建议名单，将预算执行和其他财政支出情况审计报告提交党委审计委员会会议审议，并要求建立健全审计委员会机构设置、加强人员配备。2023年底前，5个县（区）均将预算执行和其他财政支出情况审计报告提交党委审计委员会会议审议。2024年5个县区在年度项目计划安排中，均主动商组织部门提出经济责任审计项目计划建议名单；5个县（区）均设置了秘书股并已配备专人负责相关工作。

6.联动协同机制运行成效不够明显。

整改情况：一是加强业务学习。召开专题学习及工作碰头会议，学习《关于建立生态司法与审计衔接机制的意见》（莆委审办〔2019〕3号）文件精神，加深对生态司法与审计衔接机制的认识和领会。二是落实立行立改。2023年8月18日，市审计局发函至市法院，收集了2023年度被审计乡镇领导干部任期内有关生态审判的刑事、民事及行政等案件的判（裁）决书，提供审计组参考运用，加强与生态司法的信息衔接。三是加强协同联动。强化与生态司法的问题共享，与市法院召开“生态司法+审计”联席会议，通报2023年衔接机制的工作情况，交流探讨2024年衔接机制的工作思路。四是强化贯通协同。认真研究与市纪委监委、市委巡察办建立常态化对口联系机制，共同规划我市“审巡纪”联动框架,参与市纪委监委、市委巡察办贯通协同实施细则起草。根据监督贯通协调相关要求，制定21条落实措施，明确责任领导和责任人，确保各个环节有人对接、有措施落实。就“审巡纪”贯通协同审计部分工作8个方面操作程序进行规范。五是科学制定计划。2024年度审计项目计划与市委组织部、市委巡察办进行多轮会商，拟定领导干部经济责任审计、自然资源资产审计项目，列出先审后巡、边审边巡、先巡后审3个类型项目框架。

7.推进重点领域专项审计仍有不足。

整改情况：一是提高思想认识。组织学习《习近平生态文明思想研究与实践》专刊2023年第2期《习近平在全国生态环境保护大会上强调 全面推进美丽中国建设 加快推进人与自然和谐共生的现代化》、第3期《推进生态文明建设需要处理好几个重大关系》，提高对自然资源资产管理和生态环境保护监督重要性的认识，进一步厚植“两山”理念。二是突出审计重点。2024年度，围绕深入推进生态文明建设、实施创新驱动发展战略目标、提升粮食安全保障能力和水平等方面内容，安排林业专项资金管理和使用情况审计调查、科技创新发展专题审计、仙游县粮食安全相关政策落实与资金使用情况审计等重点领域审计项目；围绕促进市属国有资本规范运作，提高资本回报，维护资本安全，安排3个国有企业的资产、负债、损益审计。三是推进项目审计。截至目前，已完成林业专项资金管理和使用情况审计调查、仙游县粮食安全相关政策落实与资金使用情况审计、省水利重点项目建设情况审计、木兰溪流域治理工程项目推进实施情况专项审计、市重点项目推进实施情况跟踪审计、莆田国有资产运营集团有限公司资产、负债、损益审计。

8.推进审计向基层延伸还有短板。

需进一步整改的原因及下一步措施：各项目组在实际利用大数据审计方面的效果，继续待2025年参与具体项目实施归纳总结后再进一步评估,力争2025年12月份完成。

2.推进审计“全面覆盖”要求还有差距。

整改情况：一是提高思想认识。组织召开专题学习会议，学习习近平总书记对审计工作的重要讲话重要指示批示精神以及《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》，不断强化对领导干部经济责任审计的思想认识。二是科学制定计划。科学统筹安排经济责任审计项目，按照“全面覆盖”要求，对任职满5年且未接受经济责任审计的领导干部分批安排进行审计。2024年已安排秀屿区审计局、凤凰山街道、市公积金办、市委党史办、市信息中心等单位5位领导干部经济责任审计。三是落实立行立改。2023年完成市水利局和市木兰溪防洪工程建设管理处领导干部开展经济责任和自然资源资产审计。2024年完成市农业农村局原局长(原主任)林某某经济责任审计和自然资源资产审计，将国有资源开发利用和生态环境保护等情况作为领导干部经济责任和自然资源资产审计的重要内容，促进资源节约集约利用和生态文明建设。四是提高经济责任任中审计比例。在每年经济责任审计计划安排中重点优先安排任中审计，不断提高任中审计所占比例。2024年确定市管领导干部经济责任审计对象共40人，任中审计占19人，占比47.5%。

需进一步整改的原因及下一步措施：经济责任审计需要分年度、分批次、分行业科学规划，且由于2024年度审计任务较重，项目数比往年增长22%，有关审计项目计划2025年起继续安排实施。力争2025年12月份完成。

（二）未完成整改的问题（共1个）

1.应收款项催缴不够及时。

整改情况：2023年4月、2024年2月我局分别发函商请城厢区住建局支付征收补偿款，对方回函房屋货币补偿款由城厢区政府统筹安排，因近年项目多、资金压力大，目前该项目涉及的19家市直单位的征迁补偿款均未支付到位。

未完成整改的原因及下一步措施：我局将继续与城厢区住建局对接，督促补偿款尽快支付到位。力争2025年12月份完成。

四、下一步计划

我局将严格落实市委巡察工作要求，扎实抓好巡察反馈意见整改，下一步，持续加强理论武装、强化责任担当、不断巩固拓展整改成果，不折不扣落实全面从严治党各项要求，为推进我市审计事业高质量发展提供坚强的政治和纪律保障。

（一）强化理论武装，提高政治站位。坚持以习近平新时代中国特色社会主义思想为指导，通过党组会学习、党组理论学习中心组学习、集中学习研讨等方式，跟进学习习近平总书记最新重要讲话和重要指示批示精神，深入贯彻落实习近平总书记关于党的自我革命的重要思想，强化理论武装，提高思想认识和政治站位，深刻领悟“两个确立”的决定性意义，以高度的思想自觉和行动自觉切实增强“四个意识”、坚定“四个自信”、做到“两个维护”，坚决扛起巡察整改政治责任，继续加大力度推进问题整改。

（二）强化责任担当，确保全面整改。始终把落实巡察反馈问题整改作为局党组推进全面从严治党向纵深发展的有力抓手，坚持目标不变、力度不减，对巡察整改工作紧抓不放，对基本完成和未完成的整改任务，将加强协调沟通，久久为功，抓细抓实，引导和推动审计机关和审计干部自觉忠诚履职尽责、主动担当作为，以更加务实的作风、更加有效的举措全面完成好整改任务，做到问题不清零不放过、整改不到位不放过，做深做实巡察“后半篇文章”。

（三）强化结果运用，提升巡察成效。坚持把巡察整改与落实习近平总书记对福建、对审计工作的重要讲话重要指示批示精神，与审计机关加强党的集中统一领导、推进机制制度创新、党风廉政建设和干部队伍能力素质提升相结合、相统一，努力将巡察整改成果转化为推动审计工作的强大动力，解决审计实际工作中遇到的各类问题、各种难题，以扎扎实实的成效，巩固拓展以巡促改、以巡促建、以巡促治的成果。
