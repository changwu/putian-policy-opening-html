中共莆田市红十字会党组关于巡察整改进展情况的通报

来源:莆田市委巡察办 时间：2025-02-17 17:42
| | | |
 

根据莆田市委巡察工作统一部署，2023年6月6日至7月21日，市委巡察二组对市红十字会党组开展了巡察，并于2024年1月4日反馈了巡察意见。按照党务公开原则和巡察工作有关要求，现将巡察整改情况予以公布。

一、党组及主要负责人组织整改落实情况

（一）会党组承担巡察整改落实主体任务的情况

市红十字会党组始终把抓好巡察整改作为重要政治任务，坚持以巡促改、以巡促建、以巡促治，以鲜明的政治态度和强烈的政治担当，全力做好巡察整改的“后半篇文章”。一是提高政治认识，迅速传达部署。会党组在反馈会后立即召开党组（扩大）会议，专题学习反馈会议精神及有关要求，进一步端正思想认识，专题部署整改落实工作。会党组认真对照，主动认领，定期研究任务分解、细化整改措施、听取进度汇报、协调解决问题、推进整改落实，把抓好巡察整改作为贯彻落实党的二十大精神、优化政治生态、加强党性锻炼、改进工作作风、推动工作开展、检验工作成效的重要举措。认真召开党组巡察整改专题民主生活会，党组成员带头认领问题，从思想和政治上深刻反思，深入查摆剖析存在的问题和不足，进一步增强全面整改的政治自觉、思想自觉和行动自觉。二是压实政治责任，从严从实抓整改。会党组第一时间成立巡察整改工作领导小组，由主要领导任组长，班子其他负责同志任副组长，领导小组下设办公室，负责组织指导、综合协调、反馈情况，有序推进巡察问题整改工作。对市委巡察反馈的三个方面37项问题，以“清单化”形成细化制定103项整改措施，逐项明确整改要求、责任领导、责任单位、责任人员和整改时限。在整改期间，先后召开部署会5次、党组（扩大）会议3次、专题汇报会3次，部署推进整改落实工作。三是运用整改成果，抓好建章立制。在抓好整改、解决问题的同时，从思想、制度、机制层面找原因、堵漏洞、除病根，把巡察整改贯穿到市红十字会工作各领域、各方面、全过程，深化成果运用，注重举一反三、建章立制，共制定或修订会党组会议规则、理论学习制度、“三重一大”等制度10项，确保问题“不反弹”“不回潮”。切实用整改落实的实际成果促进干部作风转变，促进履行管党治党责任落实、推动全面从严治党向纵深发展。

（二）会党组书记承担巡察整改第一责任人责任的情况

一是坚持以上率下，坚决扛起政治责任。会党组书记蔡军切实扛起政治责任、主体责任和第一责任，坚持“新官理旧账”，团结带领班子成员严格落实巡察整改要求，以最严的标准、最实的作风、最硬的纪律推进巡察整改各项工作。二是坚持问题导向，带头推进整改工作。第一时间成立由本人任组长的巡察整改领导小组，对照反馈的37项问题，研究细化提出103条具体整改措施，逐一明确问题清单、措施清单、责任清单，带头领办17项重难点问题、牵头负责57项整改措施，亲自部署推进问题整改落实工作。三是坚持真督实改，有力推动整改质效。坚持以巡促改、以巡促建、以巡促治，对整改落实情况开展集中检查与督导，全程紧盯、一抓到底，定期会商难点堵点问题，提出改进意见和工作要求，高质量推动问题整改。将巡视反馈意见整改与选人用人、意识形态等两个专项检查同部署、同研究、同整改，进一步提高整体整改成效，有效推动整改成果转化为红十字事业发展实效。

二、巡察反馈问题的整改情况

（一）聚焦党中央各项决策部署及省委、市委工作要求基层的落实情况

1.深学细研质效不够高

整改情况：一是提高认识。巡察整改以来，市红十字会坚持把学习习近平新时代中国特色社会主义思想和习近平总书记关于红十字事业的重要讲话批示精神作为会党组理论学习中心组学习内容，市红十字会党组理论学习中心组累计学习习近平总书记重要讲话精神10次，开展专题研讨2次，深入学习习近平总书记关于红十字工作的重要指示批示精神、习近平总书记关于进一步做好困难群体及社会弱势群体兜底保障等工作的重要讲话、《中共中央办公厅、国务院办公厅印发关于改革完善社会救助制度的意见》和《中国红十字会志愿服务管理办法》。2024年1月11日，会党组会议就做好2024年春节期间开展“红十字博爱送万家”活动慰问困难群体进行部署，活动累计为2400多户困难群众发放价值190多万元慰问物资及款项。二是立行立改。将党组理论学习中心组与全体党员和干部职工政治理论学习区分开来，进一步规范党组理论学习，党组中心组理论学习每个月至少安排1场专题学习会，每季度集体研讨不少于一次，坚持依规管理、从严治学，确保理论学习中心组学习质量；全体党员干部职工政治理论学习固定每周二开展政治理论和业务工作学习，推动党员干部职工学习制度化、常态化。三是发挥牵头作用。进一步规范党组理论学习，重新修订《中共莆田市红十字会党组理论学习中心组学习制度》，印发《中共莆田市红十字会党组2024年理论学习计划》，严格按照学习计划的内容组织学习，充分发挥党组理论学习中心组“领头羊”作用。

2.应急救护培训工作存在短板

整改情况：一是健全考评制度。建立健全对市红十字万康应急救护培训中心考评制度，由赈济救护科负责平时考核，定期组织对红十字万康应急救护培训中心培训情况进行督查，做到月督促、季检查、年总评，考评情况在会党组会议上通报。2024年累计组织督查培训情况12次，发现问题4个已督促整改到位。二是规范培训标准。2024年1月在万康应急救护培训中心召开了应急救护师资座谈会，总结应急救护培训工作经验，组织市红十字万康应急救护培训中心全体职工认真学习《中国红十字会总会关于进一步推进红十字应急救护工作的指导意见》《红十字应急救护培训规范》，进一步明确红十字应急救护员培训标准，严格按照培训规范开展培训，做到规范办班规模及培训标准，配足师资及考测员，并安排学员进行AED（心脏除颤仪）实际操作训练。三是全面完成任务。2023年底已全面完成任务，实现市直机关应急救护培训全覆盖（含救护员培训和普及培训），全年完成救护员培训3608人（其中行政机关单位834人、企事业单位2774人）。

3.人道救助工作开展不够扎实

整改情况：一是加强业务学习。组织全体干部职工认真学习《莆田市红十字会应急救助暂行办法（试行）》，严格按照规定标准发放救助金，开展2024年“红十字博爱送万家”活动人道救助2400多户发放物资资金合计190多万元，均严格按照“99公益日”规定标准发放慰问金。二是组织募捐宣传。组织各县区红十字会参加省红十字会举办的网络筹资业务培训，切实提高筹资能力水平，利用市红会网站、公众号等媒体集中开展网络募捐筹资线上项目宣传，不断加大宣传力度，营造“人人参与慈善”的良好社会氛围。三是创新网络募捐。积极开展互联网筹资，使用省红十字会“红博云”平台及腾讯公益“99公益日”网络募捐平台、组织网络义卖等方式，在红博云平台新上线“爱助学”项目，进一步创新募捐手段、拓宽募捐渠道。2023年通过腾讯公益平台开展“99公益日”网络募捐活动共筹得216.29万元，市本级筹集非定向捐赠资金60万元。四是发展爱心伙伴。主动沟通走访爱心单位及人士，会党组班子成员充分利用春节走访的时机，与爱心企业、爱心人士深入交流提升筹资、“三献”工作等社会动员能力的事宜，积极协调企业向市本级捐款捐物，新发动名都集团、亚明食品、力奴鞋业、大川实业等多家企业成为市红十字会爱心伙伴。

4.应急救援能力建设不够到位

整改情况：一是加强联动合作。加强与市安委会各成员单位联动，积极配合市应急局各项工作，2023年12月主动与应急、气象等部门对接，及时落实联动机制，完善修订《莆田市红十字会应对今冬明春低温雨雪冰冻灾害应急方案》，定期组织蓝天救援队、水上救援队和应急救护员参加培训和演练。二是建设应急队伍。出台《莆田市红十字会应急救援救护队伍建设方案》，参考省红十字会模式，成立莆田市红十字会应急救援救护队，人员由市、县区红十字会、蓝天搜救队、水上救援队共同组成，组织队员参加省红会全省应急队演练，定期组织队员开展应急培训工作。三是加强仓库管理。修订完善备灾救灾中心（仓库）管理制度，安排专人负责仓库管理，更换大门钥匙、失效灭火器和维修监控设备，加强仓库日常管理，每月定期开展维护检查工作。

5.统筹推进“三献”工作不够有力

整改情况：一是加强教育管理。2024年1月以来，累计已开展2023年度协调员考核和再学习培训2场，提升协调员业务能力，走访红十字生命接力志愿服务队和造血干细胞及献血志愿服务队，明确新年度目标任务和队伍建设工作，3月份向省红会申请一名协调员培训名额参训，进一步强化服务队开展“三献”工作的宣传力度和深度广度。自巡察整改以来，新登记人体器官遗体捐献登记人数1005人，实现人体器官遗体捐献15例。二是培训足量劝捐员。组织劝捐员培训课程，邀请参与人体器官与遗体捐献见证较多、经验丰富的协调员进行授课，进一步传播人体器官与遗体捐献无私高尚理念，累计完成志愿服务队培训劝捐员30人次。三是起草优待意见。牵头起草“三献”人员优待政策，联合市卫健委、市财政局等7部门于2024年10月印发《关于落实莆田市无偿献血优待对象“三免一优先”等优待政策的通知》，对无偿献血及捐献造干优待对象，实施基本健康体检、公交优待、景区优待、优先用血等政策。

6.基层组织建设面不够广

整改情况：一是加强业务培训。2024年1月29日事业发展科认真组织学习《中国红十字会总会关于加强红十字会基层组织建设的指导意见》，有效提升指导红十字基层组织建设的业务能力和理论水平。二是认真发展培育。科学安排基层组织发展计划，将基层组织发展计划列入2024年莆田市红十字会工作要点，新成立30家红十字基层组织，推动红十字基层组织进一步向乡镇、农村纵深发展。

7.指导县区红十字会工作不够有力

整改情况：一是加强业务培训。2023年10月份组织全体干部职工认真学习《莆田市红十字会应急救助暂行办法（试行）》，加强对救助标准及审批程序的熟悉程度，进一步提升指导县区红会开展救助的业务能力。二是完善流程审批。修订《莆田市红十字会人道救助申请流程》，对市红十字会接收的所有办理人道救助的事项，明确服务要素标准、流程标准和服务方式标准，公开办事流程图，加强县区红会人道救助业务指导，进一步规范服务行为，做到咨询一次写清、表格一次发清、材料一次收清、内容一次审清。针对困难群体救助申请开展容缺式预审核，后续缺少材料补充可通过邮寄送达，做到“最多跑一趟”。2024年2月26日下午召开年度部署会，将以会代训的方式，对全市红会工作人员进行业务辅导。三是加强工作宣传。加强县区红十字会信息工作，定期收集各县区红十字会工作动态，莆田市红十字会公众号开设“县区动态”新闻宣传专栏，及时更新报道县区红十字会有关活动，已累计刊发县区工作动态新闻报道30余篇，有效提升基层红十字宣传工作。

8.红十字会基层阵地作用发挥不足

整改情况：一是加强业务培训。2024年2月26日召开全市红十字会工作会议，会上通报市委巡察办《印发市委巡察二组〈关于巡察市红十字会党组反馈的反馈意见〉》中红十字会基层阵地作用发挥不足问题，组织各县区红十字会认真学习福建省红十字会 福建省财政厅《关于建立红十字博爱驿站的通知》（闽红〔2019〕33号），提升县区红十字博爱驿站的管理水平。二是推动发挥功效。仙游、荔城、涵江博爱驿站设置不甚合理，已重新选址。仙游县红十字会联合仙游义工协会红十字会设置临街人流量大的店面作为驿站窗口，荔城区驿站新址设在阔口社区，涵江区博爱驿站已迁移至涵江青少年宫，秀屿区驿站已正常运行，各个县区博爱驿站都每个月与周边社区、小区联合开展至少一次应急救护普及、困难帮扶、义务劳动、反诈宣传、普法宣传等便民服务活动，充分发挥博爱驿站积极参与基层社会治理的作用。针对博爱驿站普遍存在经费保障的问题，市红十字会每年每个驿站安排2000元保障经费，县区红十字会再自筹部分，保障每个博爱驿站能运转、有活动。

9.履行意识形态工作全面领导责任还有差距
