中共莆田市委老干部局关于巡察整改进展情况的通报

来源:莆田市委巡察办 时间：2025-02-17 17:50
| | | |
 

根据市委巡察工作的统一部署，2023年6月5日至7月21日，市委巡察三组对市委老干部局开展了巡察，并于2024年1月4日反馈了巡察意见。按照党务公开原则和巡察有关工作要求，现将巡察整改进展情况予以公布。

一、推进整改工作进展情况

    （一）统一思想认识，推动整改落实。认真学习习近平总书记关于巡视工作的重要论述，坚决落实党中央关于巡视巡察整改的最新决策部署，把抓好巡察整改作为重要政治任务抓紧抓实。巡察反馈会后，市委老干部局第一时间召开巡察整改专题会议，认真学习领会巡察反馈会议精神，通报巡察反馈的问题，研究部署巡察整改工作，明确整改工作的方向，并多次召开局务（扩大）会议研究部署巡察整改工作，切实提高政治站位，进一步增强全局党员干部做好巡察整改工作的思想自觉和行动自觉。

   （二）加强组织领导，严格落实责任。局领导班子高度重视巡察整改工作，成立由局长任组长，局领导班子成员任副组长的巡察整改工作领导小组，统筹抓好巡察整改工作。制定《莆田市委老干部局关于市委巡察三组反馈意见的整改方案》，细化整改措施，明确责任领导、责任单位和整改时限。局主要领导认真履行第一责任人责任，亲自研究部署、亲自抓落实，主动带头认领整改任务；其他班子成员认真履行职责，立行立改，共同落实整改责任。

（三）统筹推进工作，拓展整改成果。召开巡察整改相关会议7次，将整改落实过程与加强全面从严治党、推进队伍作风建设、营造良好干事氛围紧密结合起来。紧盯重点难点问题，注重举一反三、建章立制，共制定完善各项规章制度7项，以整改严纪律、正作风，以整改解难题、聚人心，以整改建机制、促发展，以整改的成效推动我市老干部工作高质量发展。

二、巡察反馈问题的整改情况

（一）贯彻落实党的路线方针政策和中央重大决策部署情况

1.学习贯彻习近平总书记关于老干部工作的重要论述和系列重要讲话指示批示精神不到位。

（1）学思践悟不够深

整改情况：一是加强理论学习。持续深入学习习近平新时代中国特色社会主义思想，特别是习近平总书记关于老干部工作的重要论述和重要指示精神，2023年主题教育期间，编印《习近平总书记在福建工作期间的尊老敬老故事》《党的十八大以来习近平总书记对老干部工作的重要指示精神》宣传册供老干部工作者学习，进一步增强做好新时代老干部工作的使命感、责任感。二是制定学习计划。将习近平总书记关于老干部工作的重要论述和重要指示精神以及上级关于老干部工作的部署要求列入每年度理论中心组学习计划。2023年12月，局务会理论学习中心组学习习近平总书记关于老干部工作的重要指示精神，并进行了交流研讨。2024年3月6日，局务会理论学习中心组、局务会（扩大）会议及时传达学习全国、全省老干部局长会议精神，并结合我市实际提出贯彻意见；3月15日，召开全体干部职工会议，传达学习市委常委会听取老干部工作汇报时的指示精神并提出我市“把准政治方向”“聚焦主题主线”“加强自身建设”等三条贯彻落实措施。

（2）学用结合不够实。

整改情况：一是强化理论武装。组织引导老党员老干部深入学习贯彻习近平总书记对全国老干部工作作出的重要指示精神。2023年10月19日至21日，举办离退休干部党组织书记培训班，全市90位离退休党组织书记参加培训，采取专家授课、业务辅导、分组讨论、参观教学等方式，不断加强离退休干部党组织战斗堡垒作用。二是组织引导老干部担任基层治理重要角色。组织引导老干部、老党员担任网格（小区）、单元党组织书记，网格（单元）长，推动离退休干部在近邻党建中发挥作用，如：向群众宣传方针政策，收集群众意见和问题、帮助解决矛盾纠纷、参与卫生整治等。三是建立银发人才库。按照党建党务、科教文卫、基层治理、体育艺术、农业农村等10个领域，建立银发人才库，吸纳银发人才600多名，引导老同志根据自己专业特长，积极围绕中心大局发挥作用。四是加大老党员工作室建设力度。截至2024年5月底，全市共建立66个老党员工作室，新增58个。

（3）指导基层不够多。

整改情况：一是提高政治站位。坚持以习近平总书记关于老干部工作的重要论述为遵循，认真贯彻落实中央的决策部署和省委、市委的工作要求，2024年3月6日，局务会理论中心组深入学习贯彻全国老干部局长会议精神、省委老干部工作领导小组会议暨全省老干部局长会议精神，以更宽视野、更高标准创新推进离退休干部党建、引导发挥老干部优势作用等主责主业。二是组织互学互鉴。我局将2023年定为“离退休干部党组织建设提升年”，通过组织外出参观学习、基层现场观摩和加大基层调研的方式，进一步加大对基层老干部工作的指导力度。在学习考察福州、泉州离退休干部党建工作先进经验的基础上，2023年7月20日在仙游县和涵江区，12月20日在城厢区、荔城区和秀屿区，分别举办基层离退休干部党建工作现场观摩活动，让大家互学互评互促。三是指导基层解难题。2023年主题教育期间，大力传承弘扬“四下基层”优良作风，由局领导分别带队深入各县区、部分镇街、村居和市直单位开展调研，形成7篇调研报告，并对调研中发现基层存在的困难和问题及时进行指导和帮助。2023年5月、6月、10月，市关工委赴各县区开展做好义务教育课后服务、关爱助学、种子工程等专题调研。2023年12月12日-20日，组织优质教师资源开展“送教下基层、办实贴心事”活动，指导县（区）老年大学和社区教学点提质见效。

2.用心用情精准服务有差距。

（4）个性化精准服务不够到位。

整改情况：一是统一思想认识。按照习近平总书记提出的“要用心用情、精准服务，努力在平凡的岗位上创造出不平凡的业绩”要求，充分认识做好老干部工作的重要意义，2024年2月22日，认真组织全体干部职工学习《关于进一步做好离休老干部精准服务工作的通知》和本局出台《服务老干部工作制度》等，对照精准服务和老干部工作制度要求，自觉查找差距和不足，做到精心精细精准做好老干部服务保障工作。二是落实看病就医措施。目前，离休干部平均年龄94.7岁，已进入“双高期”，主要的需求是就医就诊方面，2024年2月26日，召开服务保障工作务虚会；2024年3月，与市卫健委沟通，对接市第一医院、附属医院为老干部提供健康体检对接、就医预约陪诊、药品申领、上门健康随访等精准服务；对提出申请的9名离休干部每月给予500元医疗护理费。三是制定个性化服务方案。建立服务台账，完善17名离休干部“一人一策”情况表，精准掌握每一名离休干部的困难和需求，依托“闽善行 桑榆情”智能助老服务站，将离休干部服务项目制成清单，根据实际需求进行点单服务。四是常态化开展走访慰问。建立“月询访、季走访”联系和挂钩结对离休干部联络员制度，加强常态化联系，及时掌握情况妥善解决诉求，2024年以来，共计电访85人次，走访166人次，协调解决老干部抚恤金、就医、医保等方面5件诉求。

（5）走访慰问不够深入。

整改情况：一是提高思想认识。2024年3月6日，局务会理论学习中心组、局务会（扩大）会议及时传达学习全国、全省老干部局长会议精神，并结合我市实际提出贯彻意见；3月15日，召开全体干部职工会议，传达学习市委常委会听取老干部工作汇报时的指示精神，组织引导全体干部职工充分认识老干部工作是党的组织工作和干部工作的重要组成部分，承载着党中央关心爱护广大老同志的重要任务。二是开展走访慰问。落实“下基层、进家门”要求，着力从上门入户到位、掌握诉求到位、慰问关怀到位、解决问题到位“四个到位”上下功夫，做到走访慰问“见人见物见心”。2023、2024年慰问均严格落实上门走访慰问。2024年元旦春节期间，全市老干部门共慰问老干部、遗属及困难老党员181人次，发放慰问金及慰问品30万余元。三是落实落细制度。健全完善离休干部精准服务挂钩安排表，建立“月询访、季走访”联系制度，及时帮助他们解决实际困难。2023年10月，对全市56名离休干部及167名遗属进行摸底，将3个离休干部、7个离休干部遗属上报省局申请困难补助，获得补助标准为离休干部5000元/人，遗属3000元/人。四是提升服务温度。健全完善“五个必访”制度。对生病住院的老干部和离世老干部家属及时进行慰问，重阳节期间举行老干部集体祝寿等活动，2024年两节慰问离休干部、“5.12”退休干部及遗属、厅级老领导，病困老党员等分别由市四套班子和局领导班子带队上门走访慰问，让老党员老干部感受到党和政府关怀和温暖。

（6）安排外出活动有欠缺。

整改情况：一是加强理论学习。2023年12月4日，认真组织学习习近平总书记关于全国老干部工作的重要指示精神和在福建工作期间的尊老敬老故事，切实提高思想认识，强化用心用情服务的工作意识、责任意识。二是认真制定计划。根据老同志身心特点，2023年9月，召开班委会研究制定厅级班秋季学习实践活动计划。三是精心安排活动。2023年12月，在充分征求班委意见的基础上，科学制定了“学思践悟新思想 接续奋斗看蝶变”参观学习活动方案，安排3个参观点，路线设计合理，服务贴心周到，受到老同志们的广泛点赞。

3.发挥老干部独特优势和积极作用不够明显。

（7）引导老干部建言献策不够。

整改情况：一是加强学习。2023年12月，组织全体干部职工深入学习领会《关于加强新时代离退休干部党的建设工作意见》等文件精神，组织引导离退休干部为党和人民事业增添正能量。二是建立制度。建立5步工作法：从会前预通知、了解身体状况、沟通发言准备情况、会后整理意见建议、意见反馈等五个方面，引导老干部建言献策。三是充分发动。通过会前沟通协调，充分调动老干部的积极性，建言献策氛围更加浓厚。2023年7月25日，召开厅级退休干部2023年上半年通报会，共有20名厅级老领导参加，7人发言；2024年1月30日，召开厅级退休干部2023年度通报会，共有18名厅级老领导参加，6人发言。四是长期坚持。已建立5步工作法措施，将老干部的发言建议和意见及时整理后向市委办报告，由市委办转发市直相关单位整改落实，向老干部们反馈，并与市委办畅通相关机制，后续整改工作每半年向老干部通报一次。通过5步工作法，工作推动更加合理。

（8）统筹推进关心下一代工作力度不足。

整改情况：一是认真组织学习。2月26日上午，召开市关工委主任办公会议，组织学习习近平新时代中国特色社会主义思想和习近平总书记关于关心下一代工作的重要指示批示精神，深刻领悟内涵，自觉提高政治站位。二是加强建章立制。2023年11月27日印发《莆田市关心下一代工作委员会成员单位职责及联席会议议事规则的通知》；2024年3月25日印发《关于调整充实莆田市关心下一代工作委员会成员的通知》，形成社会各界广泛参与关心下一代工作的机制。三是加强队伍建设。广泛动员政治素质高、热心公益事业、具有奉献精神的老同志参加关工委工作,及时把新退出领导岗位、身体健康、热爱青少年工作的老同志充实进关工委领导班子。2023年8月11日，湄洲湾北岸经济开发区工作委员会印发《关于调整充实北岸经开区关心下一代工作委员会组成人员的通知》；2024年3月28日，湄洲岛工委组织部印发《关于调整充实湄洲岛关心下一代工作委员会组成人员的有关事宜》。四是推进民营企业关工委建设。严格按照《关于加强新时代关心下一代工作委员会工作的实施方案》（莆委办发〔2022〕5号）文件精神及省关工委2024年全体委员会议提出的“继续推进在机关企事业单位、学校、离退休干部党组织、老年大学和涉老团体建立关工委”要求，主要是积极探索民企关工委成立的工作，进一步推进关心下一代工作深入开展。目前，全市共建立民营企业关工委46家，仙游县14家、荔城区7家、城厢区11家、涵江区8家、秀屿区6家。五是积极开展理论宣讲。2023年10月-12月，组织市关工委宣讲团走进涵西街道历史文化街区、秀屿区埭头镇英田社区、莆田学院、荔城区老年大学开展习近平总书记来闽考察重要讲话精神和在闽工作期间的重要理念、重大实践的宣讲。2024年4月，召开市关工委全委会，会议就市关工委宣讲团工作展开业务培训，并部署“中华魂”主题教育活动。5月，组织各级关工委宣讲团开展习近平总书记来闽考察重要讲话精神和在闽工作期间的重要理念、重大实践的宣讲进学校、进农村、进社区。六是实施种子工程攻坚行动。2023年9月21日，召开市关工委主任办公会议，专题研究“种子工程”推进事宜，把“种子工程”推进工作列入中心工作计划。2023年10月8日至12日，组织对仙游县、荔城区、城厢区、秀屿区、北岸“种子工程”基地建设情况展开调研。2024年，分别在荔城区、秀屿区举办省市区“种子工程”珍稀中药材苗木繁育种植技术和南日鲍、双壳贝类、海带种苗繁育技术培训班，积极融入乡村产业发展和人才振兴，引导和帮扶更多群众共同致富。

（9）为老干部宣传不够。

整改情况：一是宣传先进典型。在“莆田老干部”公众号开设“身边的榜样”专栏，分期分批宣传关心下一代先进工作者、最美老干部等先进典型，营造尊重老同志、关爱老同志、学习老同志、重视老同志作用发挥的良好氛围。2023年10月以来，共宣传先进典型30余人。二是完善信息宣传机制。2024年3月制定《市委老干部局信息宣传工作管理办法》，每半年进行信息通报。建立信息宣传员队伍共13人，2024年4月30日，举办信息宣传摄影培训班，共30多人参加，不断提升信息宣传工作水平。2024年1月，我市3篇调研报告在2023年度全省老干部工作调研文章评选中获奖；1人获评全省评选宣传工作表现突出个人。

3.老年活动阵地建设有短板    

（10）老年活动阵地思想政治引领功能弱化。

未完成整改的原因及下一步措施：仙游县和涵江区的财政运转困难，支出难度大。将继续加强与仙游县和涵江区的沟通和督导，积极争取县区主要领导的重视和支持，推动党建工作经费落实，力争在2025年10月底前完成。

（42）干部队伍年龄结构相对老化。

整改情况：一是加强业务学习。2024年4月，组织办公室人员认真学习《党政领导干部选拔任用工作条例》，进一步熟悉选人用人工作规范。二是探索转型路径。根据省、市委关于加强新时代离退休干部党的建设工作的相关文件精神，积极探索干休所机构、职能、编制向离退休干部党建工作转型的途径和办法，干休所部分工作人员承担离退休干部党建工作；离退休干部工委原挂牌老年活动中心，其中4个编制承担离退休干部党建工作，所以下属部分干部合署办公。三是加强轮岗锻炼。加强年轻干部锻炼培养，进行内部交流轮岗，为干部成长打好基础，多方位培养锻炼干部。

未完成整改的原因及下一步措施：目前局机关仍满编，无法调入年轻干部，平均年龄仍然偏大。下一步根据工作需要和岗位职数情况，加强年轻干部锻炼培养，进行内部交流轮岗，为干部成长打好基础，多方位培养锻炼干部，力争在2025年12月底前完成。

四、下一步计划

（一）持续提升政治站位。坚持以习近平新时代中国特色社会主义思想为指导，持续强化理论武装，深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、坚决做到“两个维护”。始终把党的政治建设摆在首位，巩固拓展主题教育成果，发挥理论学习中心组的领学促学作用，落实各项学习制度，持续掀起“大学习”的热潮。

（二）持续抓好后续整改。紧扣市委巡察三组的反馈意见，持之以恒抓实抓细整改，不断巩固整改成果。定期跟踪落实巡察整改后续各项工作有序开展，保持目标不变、标准不降、力度不减，坚决防止“回潮”和“反弹”，确保问题整改到位，取得实效。着力构建整改长效机制，在抓好整改的同时，更加注重治本，更加注重预防，更加注重制度建设。

（三）持续抓好成果运用。以巡察整改为契机，把巡察整改与日常工作提升、提振党员干部干事创业精气神、破解制约老干部工作发展难题结合起来，把巡察整改作为吸取教训、总结经验、推进工作、促进发展难得的良机，持续高效推动我市老干部工作高质量发展。
