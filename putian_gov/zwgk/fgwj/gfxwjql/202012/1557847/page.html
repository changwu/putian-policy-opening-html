莆田市人民政府关于公布行政规范性文件清理结果的通知

来源:市府办 时间：2020-12-31 16:47
| | | |

　　各县（区）人民政府（管委会），市直有关单位：

　　根据国务院《关于加强市县政府依法行政的决定》（国发〔2008〕17号）的精神和要求，进一步提高行政机关依法行政水平，确保行政规范性文件与法律、法规、规章的一致性和协调性，维护法制的高度统一,营造积极良好的法治环境。市政府组织对2020年前（不含2020年）以市政府及市政府办公室名义印发的各类行政规范性文件进行全面清理。清理意见已经市政府常务会议讨论通过，现予以公布。宣布废止或宣告失效的行政规范性文件，自本决定公布之日起不再施行。

　　一、《莆田市人民政府关于市区渣土和砂石运输车辆实行密闭式加盖的通告》（莆政〔2008〕20号）等433件行政规范性文件继续有效（具体目录详见附件1）。

　　二、《莆田市人民政府办公室关于印发莆田市全面推行科学婚检预防出生缺陷工作实施方案的通知》（莆政办〔2007〕217号）等8件继续有效需适时修改的行政规范性文件（具体目录详附件2）。

　　三、《莆田市人民政府关于修改莆田市测绘管理办法的决定》（莆政〔2009〕36号）等116件宣布予以废止或宣告失效的行政规范性文件（具体目录详见附件3）。

　　附件：1.继续有效的市政府及市政府办公室的行政规范性文件目录（共433件）

　　2.继续有效并需适时修改的市政府及市政府办公室的行政规范性文件目录（共8件）

　　3.宣布废止或宣告失效的市政府及市政府办公室的行政规范性文件目录（共116件）
