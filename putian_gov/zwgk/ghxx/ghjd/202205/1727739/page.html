关于《莆田市妇女发展纲要（2021-2030年）》和《莆田市儿童发展纲要（2021-2030年）》的政策解读

来源:市府办 时间：2022-05-20 11:34
| | | |

　　

　　一、编制依据

　　妇女儿童事业是党和人民事业的重要组成部分，妇女儿童工作关系千家万户，关系国家和民族发展。党的十八大以来，以习近平同志为核心的党中央高度重视妇女儿童事业发展，坚持男女平等基本国策，坚持儿童优先原则，统筹推进妇女儿童事业和经济社会发展。市委市政府高度重视妇女儿童工作，先后制定实施了三个周期的妇女、儿童发展纲要，保障妇女儿童权利的法规政策体系进一步完善，党委领导、政府主责、妇女儿童工作委员会（以下简称“妇儿工委”）协调、多部门合作、全社会参与的妇女儿童工作机制进一步健全，妇女儿童和家庭的发展环境进一步优化。

　　未来十年，是莆田基本实现全方位高质量发展超越，建设成为繁荣宜居智慧的现代化滨海城市的关键时期，科学谋划和编制好新一周期的莆田市妇女儿童发展纲要，简称“新两纲”，是贯彻落实党的十九大和十九届历次全会精神的重要任务，是部署做好全市未来十年妇女儿童事业发展的重大举措，对全方位推动高质量发展超越具有重要意义。依据宪法和民法典、妇女权益保障法等有关法律法规，根据《中国妇女发展纲要（2021-2030年）》《中国儿童发展纲要（2021-2030年）》《福建省妇女发展纲要（2021-2030年）》《福建省儿童发展纲要（2021-2030年）》和《莆田市国民经济和社会发展第十四个五年规划和二〇三五年远景目标纲要》，结合我市妇女儿童事业发展实际，制定了莆田市“新两纲”。

　　二、主要内容

　　“新两纲”坚持把习近平总书记关于妇女儿童工作的重要论述作为主线贯穿全篇。“新两纲”均分为“指导思想、基本原则和总体目标”“发展领域、主要目标和策略措施”“组织实施”“监测评估”四个部分。

　　序言部分主要阐述上一轮妇女儿童发展纲要取得的工作成效及当前面临的机遇和挑战。上一轮两纲的目标任务圆满完成，多项指标实现度处于全省领先水平。

　　第一部分是指导思想、基本原则和总体目标。主要阐述未来十年妇女儿童事业发展的指导思想，新“妇纲”提出坚持党的全面领导、妇女事业与经济社会同步协调发展、男女平等、妇女全面发展、共建共治共享等五项原则，新“儿纲”提出坚持党的全面领导、儿童发展优先保障、儿童全面发展、儿童平等发展、鼓励儿童参与等五项基本原则。

　　第二部分是发展领域、主要目标和策略措施。其中，新“妇纲”共设置健康、教育、经济、参与决策和管理、社会保障、家庭建设、环境、法律8个领域，提出81项主要目标和99项策略措施，对比上一轮纲要，增设1个“妇女家庭建设”领域，增加主要目标31项；新“儿纲”共设置健康、安全、教育、福利、家庭、环境、法律保护7个领域，提出74项主要目标和94项策略措施。对比上一轮纲要，增设“儿童与家庭”“儿童与安全”2个领域，增加主要目标26项。

　　第三部分是组织实施。从坚持党的全面领导、落实纲要实施责任、加强纲要与经济社会规划衔接、完善工作机制、加强经费支持、鼓励广泛参与等十一个方面压实两纲实施责任，合力推进各项目标任务落实。

　　第四部分是监测评估。着重从强化制度建设、强化组织领导、加强统计监测、提升监测评估能力和水平、有效利用监测评估成果等五个方面提出具体要求。

　　三、特色优势

　　我市“新两纲”除了与省级纲要相关内容保持一致外，还根据市委市政府全方位推进高质量发展超越要求和现有工作基础，对“新两纲”目标设置和策略措施进行了优化调整。

　　一是突出坚持党对妇女儿童工作的全面领导。“新两纲”把贯彻习近平总书记来闽考察重要讲话精神和对莆田工作的重要讲话重要指示批示精神及关于妇女儿童工作与家庭建设的重要论述作为主线，贯穿于纲要组织实施、贯穿于妇女儿童事业发展的全过程。

　　二是积极回应民生关切。比如为落实支持三孩政策，提出托育机构和托位数量持续增加、公办园在园幼儿比例保持在55%以上、公办园和普惠性民办园在园幼儿比例保持在90%以上，降低家庭生育、养育、教育成本；探索在乡镇（街道）及有条件的城乡社区建立家庭综合服务中心，加大家庭公共服务支持力度等目标措施。

　　三是强调均衡高质量发展。“新两纲”聚焦短板弱项，面向发展需求，强调加强公共服务体系和制度机制建设，强调重点保障特殊困难妇女儿童群体权益，强调缩小妇女儿童发展的城乡、区域、群体差距，强调家庭、学校、社会和网络对儿童全方位全过程的综合保护。强调妇女儿童关爱服务的专业化建设，打造并推广具有莆田特色的关爱妇女儿童服务品牌。

　　四是注重妇女儿童事业更高水平开放。“新两纲”提出把传承和弘扬妈祖文化融入“海丝”建设，加快世界妈祖文化中心建设，打造国际化对外开放窗口；全力保护好湄洲岛，做大做强妈祖健康城，打造台胞台企登陆第一家园“首选地”；实施便利港澳侨居民在莆发展的政策措施，拓展莆港澳侨妇女儿童交流深度广度。

　　五是推进将生态优势转化为妇女儿童发展优势。强调以习近平生态文明思想为统领，深入贯彻落实习近平总书记治理木兰溪的重要理念，落实习近平总书记关于“保护好湄洲岛”的重要嘱托，巩固提升生态文明建设的木兰溪样本，打造全国海岛生态文明样板，推进生态环境保护工作走在全国、全省前列，让妇女儿童及家庭充分享受到蓝天白云、繁星闪烁，清水绿岸、鱼翔浅底，鸟语花香、田园风光。

　　六是助力全方位推进高质量发展超越。“新两纲”设立了8项高于省新“两纲”的量化标准，比如高级专业技术人才中女性比例达40%左右、街道及中心城区乡镇日料中心覆盖率达到100%。对16项省“新两纲”中没有量化要求的指标，明确了量化标准，率先提出县级以上人民政府全部开通全国统一的妇女权益保护热线。
