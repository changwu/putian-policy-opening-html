莆田市体育局关于2021年法治政府建设情况的报告

来源:市体育局 时间：2022-01-11 17:33
| | | |

　　2021年，在市委、市政府的正确领导下，莆田市体育局认真贯彻落实党的十九大和十九届二中、三中、四中、五中、六中全会精神，深入学习贯彻习近平法治思想和习近平总书记在福建考察时的重要讲话精神，以及中央、省、市关于法治政府建设的决策部署，结合体育工作实际，扎实开展依法行政各项工作，取得了积极的成效，现将2021年度工作开展情况报告如下：

　　一、2021年法治政府建设主要情况

　　（一）强化组织领导，明确工作责任。我局高度重视法制政府建设工作，贯彻落实《党政主要负责人履行推进法治建设第一责任人职责规定》，局主要领导认真履行推进法治建设第一责任人职责，把法治政府建设工作和普法工作列入局重要工作计划，对年度法治政府建设工作亲自部署、重大问题亲自过问、重点环节亲自协调、重要任务亲自督办。要求机关工作人员特别是领导干部要带头树立依法行政理念，切实提高运用法治精神、法治思维、法治方式推动各项工作。

　　（二）强化理论学习，开展普法宣传。积极开展法治宣传，把学法、用法、遵法纳入干部考核的重要内容，组织干部职工认真学习习近平法治思想、《宪法》《民法典》《安全生产法》《行政处罚法》等法律法规以及体育法律、法规、规章等，切实把习近平法治思想传达到体育系统每一名干部职工。充分利用“宪法宣传周”、公众微信号“莆田体育”、LED显示屏等途径开展法制宣传，广泛宣传《宪法》《体育法》《公共文化体育管理办法》《福建省体育经营活动管理条例》《福建省公共游泳场所管理办法》等法律法规，将法治宣传落实到体育工作的各个环节，促进我市体育事业法制化、规范化和科学化发展。

　　（三）强化教育培训，提升执法水平。一是为提高体育系统工作人员的法律素质，提升依法行政能力和水平，推进依法治体进程，将体育系统工作人员的法治教育培训作为普法工作的重要内容，12月2日—3日，在莆田市体育训练基地举办了2021年莆田市体育系统行政执法培训班，邀请专家为参训人员作《行政处罚法》《体育法》《安全生产法》专题讲座，全面提高体育部门干部法治思维和依法行政能力。二是严格落实“谁执法谁普法”的普法责任制，将执法过程变成普法过程，使体育行政执法人员在执法普法实践中提高自身法治素养和执法能力。7月13日-7月23日，由我局牵头，联合莆田市市场监督管理局和莆田市卫健委组建全市游泳场所跨部门联合执法检查组，按照原则上不低于5%的抽查比例，抽取了19家游泳场所，开展“双随机、一公开”实地抽查工作，对于发现问题的游泳场所，当场开具限期整改通知书，要求在规定时间内整改到位，所有问题均已整改到位，并按照“谁抽查、谁采集”、“谁检查、谁录入、谁公开”的原则将检查结果在莆田市政府网站上公开。

　　（四）强化深化改革，优化审批服务。建立体育部门权力清单和责任清单动态调整机制，在法律依据、实施主体、职责权限等事项变更后，及时调整并向社会公示。深化体育行政审批和公共服务制度改革，做好已取消和下放体育行政审批事项的落实和衔接，强化放管结合，重点加强体育赛事活动、高危险性体育项目经营活动等事中事后监管。规范行政审批和公共服务流程，持续推进政务服务“马上办、网上办、就近办、一次办、自助办”，严格执行“证照分离”改革举措，能使用电子证照的一律调用电子证照，我局经营高危险性体育项目许可（潜水、攀岩、人工滑雪）、二级运动员技术等级授予、二级社会体育指导员技术等级称号认定等7项审批事项实现全程网办，4项为即来即办项。

　　（五）强化决策机制，完善公开制度。一是推进“互联网+政府服务”。在政务服务大厅设立综合服务窗口，通过网上公开运行，规范各类证照，取消了无谓的盖章环节和繁琐程序，不断提升公共服务水平和群众满意度。截止目前，我局共审批二级运动员技术等级19件、二级社会体育指导员技术等级186件、经营高危险性体育项目许可（潜水、攀岩、人工滑雪）1件。规范各类证照，取消了无谓的盖章环节和繁琐程序，不断提升公共服务水平和群众满意度。加强政务热线12345建设，目前办结事项197件，及时答复率和回访满意率均实现了百分百。二是做好政府信息公开工作。按照“公开是原则，不公开是例外”政务公开要求和局政务信息公开制度，我局及时对政策法规、行政审批程序、“双随机、一公开”检查结果和普法责任清单等在官方网站上进行公开。利用政务公开栏、政府信息平台、爱尚运动电视栏目、莆田体育微信公众号等形式实施政务公开，力求做到公开内容全面具体、通俗易懂，及时有效，进一步增强了单位内部事务的公开性和透明度。三是通过实施《莆田市体育局规范行政自由裁量权工作的实施方案》《莆田市体育局行政处罚自由裁量权制度》《莆田市体育局规范行政处罚自由裁量案件责任追究制度》《莆田市体育局行政自由裁量权集体讨论决定制度》等制度，从制度上保证了依法行政工作的正常运行。

　　二、2022年法治政府工作安排

　　（一）深化法治政府建设。2022年，我局将以习近平新时代中国特色社会主义思想为指导，深入学习习近平法治思想，全面贯彻落实《法治政府建设实施纲要（2021—2025年）》和中央、省、市关于法治政府建设的部署和要求，结合我局职能，科学谋划推进全年法治政府建设各项工作，推动法治政府建设工作有序开展。

　　（二）深化法治宣传教育。落实领导干部学法制度，带头学法、守法、用法，做好表率。举办2022年全市体育系统依法行政培训班，不断提升全体干部职工、体育行政执法人员的法治思维和依法行政能力。贯彻落实“谁执法谁普法”的普法责任制，做好2022年普法工作，营造法治宣传工作新氛围。

　　（三）深化依法行政执法。健全完善依法行政的制度体系，加强法治队伍的建设，推进行政执法“三项制度”全面落实，加大执法监管力度，加强事中事后监管，规范执法行为，扎实开展公共游泳场所“双随机、一公开”监管工作。
