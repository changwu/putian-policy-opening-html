莆田市审计局关于2023年度法治政府建设情况的报告

来源:市审计局 时间：2024-02-02 17:26
| | | |

2023年，在市委市政府的正确领导下，我局坚持以习近平新时代中国特色社会主义思想为指导，认真学习贯彻党的二十大精神，深入践行习近平法治思想，将法治政府建设与审计工作紧密结合，全面履行审计监督职责，大力推进审计法治建设，现将具体情况报告如下：

一、主要工作开展情况

（一）坚持党的领导，推动法治建设

我局始终坚持把法治宣传教育纳入议事日程，坚持带头尊法学法，对全局法治政府建设工作进行安排部署，年度多次组织集体学法，教育引导审计干部自觉学法、遵法、守法、用法，提升干部法律素养，全面依法履行审计监督职责。

1.坚持理论指引。始终坚持党对法治政府建设的领导，通过中心组学习会、干部集中学习会、专题研讨等形式，深入学习贯彻党的二十大报告中关于法治政府建设的有关论述，学习贯彻习近平法治思想，坚持党对审计工作的集中统一领导，适应新时代新要求，紧紧围绕党和国家工作大局，全面依法履行审计监督职责。在法律法规学习宣传贯彻上发挥领导干部示范带头作用，教育引导审计干部自觉学法、遵法、守法、用法，在宪法宣传周组织审计干部学习习近平总书记在第十个国家宪法日之际做出的重要指示精神，开展了“贯彻党的二十大精神 自觉维护宪法权威”的普法专题宣传，推动审计人员增强宪法法律意识。

2.加强组织领导。落实主要负责人履行推动法治建设第一责任人职责，在全局形成主要领导负责抓，分管领导具体抓，审理法规科负责，各科室（中心）配合的工作局面，将法治政府建设与业务工作同谋划、同部署、同落实。结合审计工作特点和实际，成立规范行政处罚自由裁量权、规范行政强制自由裁量权和规范行政权力运行领导小组、审计执法过错责任追究领导小组、依法治理工作领导小组、“八五”普法工作领导小组，明确分工要求，层层压实责任，确保法治政府建设工作落到实处。

3.推进法治建设。一是认真贯彻落实《法治政府建设实施纲要（2021-2025年）》及省、市方案部署任务，结合审计机关实际，聚焦重点任务，明确职责部门，适时开展自查，督促任务有序进展。二是落实“谁执法谁普法”责任，2023年初成立市审计局“蒲公英”志愿服务队，年内结合工作实际，以审计项目进点会、审计报告征求意见碰头会和经济责任审计反馈会等为载体，深入审计现场宣传审计法律法规和有关财经法规，将审计工作与“蒲公英”志愿服务有效结合。三是落实法律顾问制度，聘请2名律师对有关行政决策、规范性文件、协议合同等提供法律顾问服务，发挥法律顾问在重大行政执法以及制度建设等工作中的积极作用。四是落实领导干部任职前法律考试和干部年度述法制度，今年8月组织2名新任领导干部任前法律考试，局领导班子和领导干部在年度考核述职中围绕法治学习情况、依法履职情况进行述法，促进领导干部增强运用法治思维和法治方式的意识和能力。

（二）聚焦主责主业，严格审计执法

2023年，严格按照省审计厅的工作部署和市委、市政府的工作要求，立足经济监督定位，聚焦财政财务收支真实合法效益主责主业，坚持以法治思想指导审计工作，全年共安排了5个板块41个项目。截至12月底，共完成41个项目，查出主要问题金额95.28亿元，审计处理金额48.23亿元。非金额计量问题1055个，移送处理事项5项，涉及金额4456万元，提出审计建议135条，被采纳128条，促进被审计单位健全完善规章制度14项。

1.从严规范审计执法行为。一是坚持依法履行职责。在当前法治建设的新形势、新任务、新要求下，找准法治建设和审计工作着力点、结合点，督导审计组和审计人员做到审计程序合法，审计揭示问题定性准确、事实描述清楚、处理意见恰当。二是坚持廉洁从审理念。坚持把审计一线作为廉政防控的主阵地、第一线，督促审计人员严格遵守审计“四严禁”工作要求和审计“八不准”工作纪律。三是推行执法三项制度，严格执行行政执法公示制度、行政执法全过程记录制度和重大执法决定法制审核制度，主动在网站公示权责清单和审计执法人员名单等信息，增强行政执法的透明度，提升审计工作的公信力。

2.发挥制度作用严格把控审计质量。一是落实请示报告制度，对审计项目实施过程中发现和发生的如损害审计独立性或者干预审计工作的行为等重大情形事项，实行审计组长负责制，逐级上报，并将重大事项报告执行情况列入科室（中心）年度绩效考评。二是落实质量分级管控，以审计项目“两复核、一审理、一审定”制度为抓手，对方案编制执行、证据底稿、结果文书、程序执行等方面严格把好质量关，全过程审查审计行为的合法合规性。

3.扎实做好审计整改“下半篇文章”。强化做好审计整改“下半篇文章”意识，把督促审计整改作为日常监督的抓手，在实施项目审计时，同步跟踪督促审计查出问题的整改工作。将审计反映的所有问题全部纳入整改范围，实行台账管理、销号管理。开展2020年至2022年组织实施项目审计整改“回头看”，对已整改到位的问题按20%比例抽查核实，审查是否存在敷衍整改、虚假整改或整改不全面不彻底问题。

（三）锤炼干部队伍，提升执法能力

1.强化学习教育。第二批主题教育开展以来，创新学习形式，通过搭建每周二、四晚的理论课堂，组织全体党员干部加强理论学习，扎实做到读原著、学原文、悟原理、知原义；通过青训班平台，打造青年课堂，引导青年审计干部增强争先意识、精品意识；通过开辟审计项目“一线课堂”，将主题教育理论学习从“会场”向“现场”延伸，树立学以致用的理念，进一步提高审计干部的业务水平。

2.多样化锤炼干部能力。一是实施“师带徒、徒助师”干部互帮工程，通过优秀年长审计干部带审计理念、审计方法、工作作风，年轻干部助政策法规汇集、审计事项承办、计算机技能运用，提升审计干部工作能力。二是搭建年轻干部成长工程平台，举办“阅见未来，与智同行”系列交流会、开展技能“大比拼”活动，提高年轻干部能查、能写、能说本领。三是以“乡镇党政领导干部自然资源资产离任（任中）审计的探索”和“领导干部经济责任审计常见问题及‘精准画像’的实践探索”为主题，开展2期审计业务主题沙龙活动，深化学习交流业务理论。

3.注重执法资格管理。组织审计干部参加行政执法资格审计法律知识和综合法律知识的培训与考试2次，通过以考促学，促使审计干部熟练掌握执法法律法规，为审计人员依法履行审计职责夯实基础。

二、2024年工作计划

2023年，虽然在推进法治建设工作中取得了一定成效，但与市委市政府的要求相比，还存在一些不足和差距，主要表现为：一是组织理论学习还不够全面系统，理论结合工作实际转化成效不明显；二是对县区审计局的业务指导不够，审计项目质量检查的整改跟踪不够及时；三是普法工作措施落实有待提高等。作为行政执法单位，法律法规的学习运用尤为重要，下一步我局将继续加强理论武装，坚持用学习掌握的理论知识和法律法规指导审计工作实践，主要做到：

（一）加强理论学习。继续以习近平新时代中国特色社会主义思想为引领，通过中心组学习会、集中学习例会、专题研讨等方式深入学习贯彻党的二十大精神和习近平法治思想，引导审计干部树立法治思想，将理论学习与审计工作实践有效结合，做到学以致用。

（二）加大业务督导。督促审计干部严格遵循审计执法程序，按照《中华人民共和国国家审计准则》规范实施审计，做到审计问题描述事实清楚、证据确凿、定性准确、处理合法、处罚适当。加大对县区审计工作的业务指导，督促县区局对审计项目质量检查通报的问题认真研究，逐项整改，举一反三，开展自查自纠，防范屡查屡犯。

（三）提高普法实效。推进“谁执法，谁普法”工作走深走实，引导审计干部在审计工作实践中自觉学习运用和宣传国家法律和党内法规，利用审计进点会、审计报告征求意见、审计结果反馈会等环节向被审计单位以及有关人员宣传审计、财经等法律法规知识，同时壮大“蒲公英”普法志愿队伍，面向公众开展多样化的宣传活动。
