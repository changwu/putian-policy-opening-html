莆田市人民政府关于PS拍－2025－49号（荔城区下店路南侧地块B）有偿出让方案的批复

莆政土〔2026〕20号
时间：2026-02-27 09:28
| | | |
  • 全真版
  • 文字版
文件下载
市自然资源局：
　　你局《关于PS拍-2025-49号（荔城区下店路南侧地块B)有偿出让方案的请示》（莆自然资〔2026〕27号）及有关材料悉。经研究，现批复如下： 
　　一、同意从《莆田市人民政府关于同意收储原莆田市双驰投资有限公司地块的批复》(莆政土〔2025〕290号) 划出国有建设用地使用权15559.10平方米进行公开拍卖出让。该宗地位于莆田市荔城区城东分区单元(350304-04)B-30等地块详细规划范围内（具体位置范围见用地红线图），宗地编号：PS拍-2025-49号。
　　二、该宗地土地用途为居住用地-城镇住宅用地(二类城镇住宅)，国有建设用地使用权出让年限70年，自《国有建设用地使用权出让合同》约定的日期起算。
　　三、该宗地出让规划条件以《莆田市自然资源局关于下达荔城区下店路南侧地块B规划条件的通知》(莆自然资审〔2025〕73号)为准。该宗地无偿配建的党建+邻里中心竣工验收合格后无偿移交并首次登记给莆田市荔城区人民政府拱辰街道办事处。该宗地配建的公共配套服务设施应与住宅首期建设项目同步设计、同步施工、同步验收、同步交付使用。
　　四、该宗地以权属净地并采取“竞地价”方式公开拍卖出让，拍卖起始价2.68亿元，加价幅度300万元，按价高者得原则确定竞得人。
　　五、该宗地土地出让金不含城市基础设施配套费、场地平整费等。
　　六、国有建设用地使用权出让的具体工作，由你局委托有拍卖资质机构实施。
　　七、该宗地按省政府调控措施要求,竞买申请人应提交使用合规自有资金、合法合规用地等承诺书。
　　八、《荔城区下店路南侧地块B无偿配建公共配套服务设施协议书》在土地出让公告时一并公告，具体内容以《莆田市荔城区人民政府关于商请荔城区下店路南侧地块B无偿配建公共配套服务设施的函》（荔政函〔2025〕317号）为准。土地竞得人在签订《国有建设用地使用权出让合同》的同时，应与莆田市荔城区人民政府拱辰街道办事处签订《荔城区下店路南侧地块B无偿配建公共配套服务设施协议书》。
　　九、该宗地新建楼盘房户，适龄子女已落户的可纳入荔城区第一实验小学和莆田市中山中学绶溪校区划片范围。
　　十、该宗地土地出让金契税由竞得人在签订《国有建设用地使用权出让合同》10日内按规定向税务部门缴纳。
 
　　莆田市人民政府                              

　　2026年2月3日
