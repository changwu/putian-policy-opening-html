莆田市文化和旅游局关于开展全市文旅行业安全生产大检查的通知

莆文旅〔2022〕32号
来源:莆田市文化和旅游局 时间：2022-04-18 09:10
| | | |
 各县区文旅局，湄洲岛旅游文体局，北岸党工委宣传部，机关各科室，局属各单位：

为贯彻落实习近平总书记、李克强总理重要指示批示精神和全国全省全市有关安全生产会议精神，经研究，决定在全市文旅行业开展安全生产大检查，全面排查整治安全隐患，坚决防范化解重大安全风险，牢牢守住安全生产底线。现就有关要求通知如下:

一、检查内容

按照刘鹤副总理在3月31日全国安全生产电视电话会议上提出的15条硬措施，一是严格落实地方党委安全生产责任，二是严格落实地方政府安全生产责任，三是严格落实部门安全监管责任，四是严肃追究领导责任和监管责任，五是企业主要负责人必须严格履行第一责任人责任，六是立即深入扎实开展全国安全生产大检查，七是牢牢守住项目审批安全红线，八是严厉查处违法分包转包和挂靠资质行为，九是切实加强劳务派遣和灵活用工人员安全管理，十是重拳出击开展“打非治违”，十一是坚决整治执法检查宽松软问题，十二是着力加强安全监管执法队伍建设，十三是重奖激励安全生产隐患举报，十四是严肃查处瞒报谎报迟报漏报事故行为，十五是统筹做好经济发展、疫情防控和安全生产工作的要求，对标对表开展全市文旅行业安全生产大检查。

二、检查分工

根据局安全生产工作领导小组职责分工，机关各科室要结合各自行业领域特点修订完善安全生产检查内容，于4月20日前报送局安办，以便汇总形成全市文旅行业安全检查重点，作为各行业安全生产督查检查的依据。

三、工作要求

（一）迅速行动排查隐患。各县区（管委会）文旅部门、机关各科室和局属各单位要认真研究制定具体细化方案，立即组织开展文旅行业领域安全生产大检查。按照市安办《安全生产工作提醒单》要求，局领导要带队深入基层开展督导检查，有力传导责任和压力，机关各科室要立即开展一次安全检查，各县区（管委会）文旅部门要对辖区内文旅行业开展全覆盖不间断检查。各县区（管委会）文旅部门、机关各科室和局属各单位要及时解决本行业领域存在的安全隐患，逐一落实责任人员、明确管控措施。需协调解决的重大问题，请第一时间收集上报。4月29日前要将本行业领域安全检查情况（以图文信息形式报送）和安全隐患清单（详见附件）上报局安办（邮箱：pt2696660@163.com）。

（二）开展消防、用电安全专项整治行动。针对春季火灾多发特点，组织开展全市文旅行业消防、用电安全专项整治行动，重点整治电线裸露线头、老化和乱搭乱接，配电室脏乱差，无专业电工且未持证上岗，违规使用易燃可燃材料装饰装修，违规动火动焊，占堵疏散通道，损坏消防设施等问题。4月底前，市局将组织专家对全市文旅行业消防、用电安全工作开展指导检查。

（三）运用大数据开展安全技防。加快智慧文旅平台、“云游莆田”智慧文旅小程序开发建设，推动景区、景点、民宿、星级酒店、文化场馆、文物、非遗、网吧、KTV、印刷企业、书店等文旅要素“上云”，推进文旅行业用数赋智，实现“一张地图、一部手机、一码通行、一键投诉”。机关各科室和局属各单位要主动对接局数字办，抓紧录入要素数据，梳理安全生产三年整治行动等安全专项行动措施成效，动态管理2022年的安全生产目标任务。

（四）加大安全生产宣传教育。要充分利用官网、微信公众号、抖音、LED显示屏、宣传栏等多种渠道，广泛开展安全宣传活动。市局微信公众号开辟安全生产专栏，加大安全生产宣传报道，发挥舆论导向作用，引导广大干部群众职工广泛关注、支持参与安全生产工作，大力营造良好舆论氛围。

（五）组织开展消防、用电安全培训。4月底前，市局将邀请专家通过线上培训的方式开展全市文旅行业消防、用电安全培训，全面提高全市文旅行业从业人员的安全意识，掌握安全生产知识，增强自我防护能力，坚决防范各类安全事故发生。各县区（管委会）文旅部门和机关各科室要尽快采集全市文旅行业从业人员信息，以便推送通知、培训等信息。
