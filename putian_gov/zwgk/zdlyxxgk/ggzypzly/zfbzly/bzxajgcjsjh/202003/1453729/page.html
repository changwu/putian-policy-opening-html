莆田市保障性安居工程协调小组转发关于固化2019年棚改项目清单和公布2020年棚改项目清单的通知

莆保障房[2020]1号
来源:莆田市住房与城乡建设局 时间：2020-03-12 10:32
| | | |

各县（区）人民政府，市园林集团公司：

    为加快推进棚改项目建设，全面落实2020年度棚改目标任务，在去年末各县（区）政府、市直相关单位申报2020年棚改计划的基础上，经省、市政府研究确认后纳入2020年国家保障性安居工程建设目标任务。根据《福建省住房和城乡建设厅关于固化2019年棚改项目清单和公布2020年公租房棚改项目清单的通知》（闽建住函[2019]37号），现将经省住建厅公布确认的2019、2020年棚改项目清单转给你们，并就有关事宜通知如下，请一并抓好贯彻落实。

    一、加快推进2020年度棚改项目。各县（区）、市直相关单位要按照闽建住函[2019]37号要求，加强棚改项目目标责任管理，逐个项目明确开工目标、时间要求和责任单位、责任人，建立项目责任清单。请督促你县（区）相关部门和棚改实施单位，在已明确年度棚改任务基础上，加快落实项目征迁、用地报批、方案设计、预算招标、规划许可及施工许可等前期工作。2020年棚改项目要求在第一季度前落实选址、立项、用地和规划报批工作，上半年完成征迁、实现开工过半，最迟7月底前全面完成设计，8月底前完成预算和招标，确保9月底前实现全面完成年度任务。

二、加快项目建设进度。要围绕首季度“开门红”目标，全面加快当年度棚改开工和存量项目建设进度。对列入2020年棚改任务还未开工的项目，要充分利用雨季来临前时期，全面加快征迁、规划设计或地块出让等前期工作，对个别因征迁不到位、资金有缺口、用地或规划报批未完成而影响项目进度的实行全时调度，确保项目按时开工。同时，对于往年开工还未建成的续建项目，要在确保工程质量、安全和当前疫情防控的前提下，抓紧复工复产，上足财力、物力、人力，加快主体建设、竣工验收和配套建设，及早组织回迁，切实提高棚改整体建成率和使用率。

三、用好用足棚改财税政策支持。要严格执行保障性安居工程的专项补助、专项债券及相关财税减免政策，在去年末提前下达2020年中央专项补助和申报第一批棚改专项债券计划的基础上，进一步抓紧对接项目手续资料、申报对接和资金下达。市、县（区）住建、财政部门要严格执行棚改专项债券管理的程序、要素、时限等要求，认真做好棚改专项债券的计划、核实、申报、安排、发行、下达使用和资金监管，加强专项资金绩效目标管理和日常监控，避免资金闲置、挤占和挪用。

四、加快推进“十大棚户区”。按照市委、市政府“突出开放招商，强化项目带动”战略部署，继续以推进2019年“十大棚户区”为抓手，加快促进城乡棚户区片区改造和旧城有机更新。各县（区）和市直相关责任单位要在确保完成年度任务的同时，分别安排不少于2-3个新的片区或旧城改造计划，全力推进征迁和报批，抓紧项目投融策划和意向投资方对接工作，全面推行货币化安置、地块出让回购商品房、PPP模式在棚改建设中的运用。对于符合棚改政策范围标准、且条件成熟的，要及时对接做好2021年棚改计划或“十四五”储库库调整更新，积极争取纳入国家棚改和财税金融政策支持范围。

五、加强督导确保责任落实。按照“任务清单化、清单项目化、项目责任化”机制要求，市、县（区）相关主管部门要建立健全保障性安居工程目标责任和督促考评机制。依托市保障性安居工程协调小组，由市住建局会同相关部门，结合城建环保重点工作、专项巡查、资金绩效和用地监管等工作，对棚改任务及十大棚户区推进情况开展专项督查，适时从棚改任务量、时效目标、进度目标等完成量方面开展综合评价，纳入年末效能运用和资金分配的重要依据。根据上级反馈，2020年末将集中开展2018-2020三年保障性安居工程跟踪审计，请各县（区）和相关部门加强自查和整改，往年审计还未整改到位的问题要求在第一季度末全面整改到位。

    六、按要求做好信息公开。各县（区）要按照通知要求，督促相关部门及时做好本级2020年棚改项目的信息公开，主动接受社会监督。

 莆田市保障性安居工程协调小组

                            2020年2月25日

关于固化2019年棚改项目清单和公布

2020年棚改项目清单的通知

 

各设区市建设局、房管局，平潭综合实验区交通与建设局：

    为落实棚改年度目标任务，加快推进棚改项目建设，现将固化后的2019年棚改项目清单和2020年公租房和棚改项目清单予 以公布，有关事宜通知如下：

一、关于 2019 年棚改项目清单

2019年棚改项目清单，我厅曾以闽建住 2019〕1号文进行 公布。在实施过程中，一些市、县根据实际情况调整了部分棚改项目，调整后，全全省2019年棚改项目129个6.4万套。现将调整后的项目清单予以固化，各地要进一步采取有效措施，加快棚改续建项目建设，做好施工组织和项目管理，力争早日竣工交付使用。

二、关于2020年棚改项目清单

根据住建部等5部门的统一部署，各市县积极申报2020年棚改计划，编制棚改项目清单。经省直5部门联合会审，并报经省政府同意，确定2020年公租房和棚改项目92个6.47万套，现予公布。2020年公租房和棚 改项目实行目标责任管理，各地要继续坚持行之有效的项目推进机制，落实责任单位和责任人，明确开工时间节点，抓紧项目审批，尽快完成项目立项、规划许可、土地使用、施工许可等审批手续，实现早开工。已经开工的项目，要上足施工力量，精心组织，加快项目进度。对前期工作滞后项目、进度滞后项目要分析原因，查找问题，有针对性的提出解决措施和办法，促进项目实施。力争实现2020年首季“开门红”，确保2020年9月底前全面开工。
