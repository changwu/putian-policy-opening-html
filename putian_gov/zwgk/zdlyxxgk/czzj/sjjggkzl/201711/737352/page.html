莆田市发展和改革委员会关于林金波任期经济责任审计报告提出问题整改落实情况

来源：本网 时间：2017-09-25 17:19
| | | |
     一、预算执行管理方面

关于预算执行率偏低问题。今后我委及市LNG筹建办将认真执行《预算法》相关规定，在编报预算草案时，对项目支出按实际需求编报预算，确保不再出现财政存量资金闲置和预算执行率偏低问题。同时，将加强对预算支出的管理，按照预算规定的支出用途使用资金，并加快预算执行进度，提高预算执行率。

二、项目前期经费管理方面

1. 关于项目前期业务经费和管理经费支出结构不合理，管理经费支出比例较大问题。我委2013-2015年项目前期管理经费主要是用于招商引资、争取项目补助资金、重大项目前期工作推进等工作，通过发改系统共争取中央、省级预算内补助资金项目579个，补助金额18.32亿元；湄洲湾第二发电厂、南日岛海上40万千瓦风电项目等一些重大项目先后获得国家发改委的核准批复；积极做好与中核建集团、庆华能源集团、国家开发投资公司、中粮集团、和润集团、华映科技等一批企业来莆考察和投资的相关项目洽谈会务接待服务工作，造成项目前期管理经费支出比例较大。下一步，我委将严格执行项目前期经费管理规定，严格按业务经费和管理经费的科目明确进行分类，控制管理经费支出，使支出结构更加合理。

2.关于挤占项目经费购买车辆问题。2013年9月，经省控办批准，我委和市重点办分别购买公务车辆1部，每部车辆车身费用为17.975万元，其中重点办购买的1部公务车辆主要用于协调推进重点项目有关事宜，平时深入项目现场，督促进度，我委原认为是符合《莆田市市级项目前期工作经费管理暂行规定》的，所以在项目前期经费中列支。今后，我委将认真遵守有关规定，确保项目前期经费专款专用，杜绝挤占现象。

3.关于未按规定对市级项目前期经费进行考核、验收和监督、定性评审问题。按照《莆田市市级项目前期工作经费管理暂行规定》，项目业主和主管部门对项目前期经费使用负全部责任，并自觉接受同级审计部门依法审计和稽察部门的监督。由于项目前期经费每年安排的单位和项目较多，而且本委专业财务人才相对缺乏，如果要实行全面监督和管理确实难度较大，但是每年我委会组织相关科室抽查部分项目，查看前期经费的使用情况。

目前，我委已开始着手修订项目前期经费管理规定，结合2013年出台的《福建省省级专项资金管理办法》规定并征询财政、审计及相关部门意见，对《莆田市市级项目前期工作经费管理暂行规定》进行修订和完善。同时，建议由审计部门牵头组织，联合财政、发改委及相关行业主管部门对项目前期经费进行验收、监督，以切实提高财政资金运行的安全性、规范性和有效性，力争使项目前期经费安排的更加合理、监督激励机制更加完善。   

三、其他财政财务管理方面

1.关于单位银行账户未按规定清理问题。目前原市物价局基本户已销户，我委市拨前期经费、省拨经费2个银行账户已销户，风电资金专户由于开户行兴业银行不同意销户，目前暂时无法销户，我委将继续跟踪协调。而原市粮食局基本户目前是市直粮食企业经审计认定的政策性亏损财务挂账贴息贷款户，在贷款未清偿前，该账户暂不能注消；原市粮食局军粮差价补贴专户是根据《军粮差价补贴款专户管理办法》规定而开立的专门核算军粮差价补贴款的账户，已按规定报财政同意保留。

2.关于非税性（利息）收入未上缴财政问题。我委2016年一般基本户等银行存款非税性（利息）收入24673.36元，风电专户银行存款利息滚存收入544247.33元，已于6月9日上缴国家金库莆田市中心支库。

3.关于未按规定进行财政资金结余结转清理问题。我委结余的2014年及以前的省级预算内资金、项目前期经费、省级重点项目检查费等省级财政性资金480838.01元，已于6月9日上缴市财政。市LNG筹建办结余2015年度以前的市本级财政专项经费354332.29元，已于6月9日上缴市财政。

4.关于项目资金结余长期挂账，未清理上缴问题。我委其他应付款科目挂账莆田燃气电厂前期费用结余35.9万元、北洋供水工程周转金19万元，财政资金结余合计54.9万元已上缴财政。

四、 “三公经费”支出方面

1.关于我委2016年度公务用车维护费支出超预算问题。由于统计口径不同（经市财政同意，2015年度我委服务重点项目前期工作的5部车的运行维护费支出不作为“三公经费”统计），造成我委2016年车辆运行费实际支出数（44.56万元）超出财政下达预算，但与2015年实际支出（含市粮食局、物价局、市城乡一体化办车辆支出）同比下降了21%。今后，我委将严格执行财政预算，杜绝超预算安排支出。

2.关于我委2016年列支粮食局购茶叶费用、发放司机安全奖及包干洗车费问题。购茶叶费用、发放司机安全奖问题我委已在贵局审计发现问题前主动自查自纠，整改到位，于2017年３月31日收回购买茶叶款和４位司机安全奖计11900元。针对包干洗车费问题，在从严治党主体责任检查及审计组进驻审计前，我委已自行整改，从2017年1月开始严格按规定对洗车费问题进行规范，实行定点洗车，按实统一结算，转账支付洗车费用。

3.关于多餐接待苏州绿地公司问题。2016年1月，苏州绿地土壤修复科技有限公司来我市了解并探讨我市现有的污泥处理工艺，并与我市相关部门就环境保护项目投资进行洽谈，由我委安排商务接待3餐。由于各级相关部门对于商务接待方面没有出台细化的规定，对商务接待未明确不能多餐安排，故我委因招商引资等工作需要时安排多餐商务接待。我委对商务接待经费管理方面一直是比较严格的，我们始终坚持注重实际效益，加强审批，强化管理，控制经费总额。2016年下半年以来，已杜绝多餐接待。

五、落实审计提出的问题整改不到位方面

对于我委2008年向市铁路公司暂借款30万元，我们已于2017年8月10日将款项归还莆田市交通能源投资开发有限公司（市铁路公司更名后的公司名称），已整改到位。
