莆田市审计局关于2018年度市本级预算执行和其他财政收支的审计结果公告

来源：本网 时间：2019-08-29 15:54
| | | |

　　2019年8月29日，市审计局黄锦华局长受市政府委托，向市七届人大常委会第十九次会议作了《关于我市2018年度市本级预算执行和其他财政收支的审计工作报告》，现将审计结果公告如下：

　　2018年，在以习近平同志为核心的党中央坚强领导下，我市各级各部门树牢“四个意识”，坚定“四个自信”，坚决做到“两个维护”，深入贯彻落实省、市党委政府决策部署，坚持稳中求进工作总基调，把高质量发展与落实赶超有机统一起来真抓实干，扎实推进经济社会健康持续发展。从审计情况看，市本级财政预算执行总体情况较好。

　　——注重政策措施落实，服务保障经济有力。一是实施减税降费，全面落实增值税税率调整等各项减税政策，继续降低社会保险费率，为企业减免税费负担10亿元以上，促进减税降费政策措施贯彻落实；二是兑现扶持政策，累计共支持重点产业和经济发展方面资金7亿元。

　　——注重三大战役攻坚，防范化解风险有序。一是打好精准脱贫攻坚战。筹集资金3.6亿元，全力推进精准扶贫、精准脱贫工作；二是打好防范化解金融风险攻坚战。截止2018年底，市本级政府债务余额控制在省政府核定限额内；三是打好污染防治攻坚战。深入践行治理木兰溪宝贵经验，推进生态环境建设，筹措专项资金2.8亿元，支持生态保护和污染整治等水环境保护建设。

　　——注重群众所急所需，补齐民生短板有为。关注人民群众普遍关心的民生问题，持续加大民生短板投入，促进保障和改善民生。市本级涉及民生方面支出36.7亿元，占一般公共预算总支出的比重为61.9%。

　　——注重预算绩效管理，财政资金使用有度。一是实行预算编制精细化管理。加强项目储备与中期财政规划的衔接，推进按经济分类科目编制预算项目，分地区、分项目编制转移支付预算；二是关注预算绩效管理工作在市效能建设中的运用，增强部门绩效意识，提高财政管理水平。

　　——注重审计问题整改，建章立制防范有效。对上一年度审计查出的问题，市审计局多次研究部署整改工作，要求相关部门单位落实主体责任、制定整改方案、建立整改台帐、明确整改时限，对存在问题逐条逐项落实整改，不断建立健全制度。

　　一、财政管理审计情况

　　市审计局采取全市统一部署、统一方案、市县（区）联动、同步实施开展，统筹整合审计资源，树立数据先行理念，对市直258个有编制项目支出的预算单位实施全覆盖审计。从审计情况看，市本级财政预算执行情况和决算草案编制总体较好，财政收支管理总体较好。但也存在一些问题：

　　（一）财政预算绩效管理仍较薄弱。一是财政部门尚未建立健全跟踪监控绩效运行、评价结果应用及绩效问责等机制，“花钱必问效，无效必问责”的要求未能有效落实；二是基金预算等未纳入绩效目标管理，且仅有22个试点部门编制整体支出绩效目标，整体支出绩效管理全覆盖尚未实现；三是开展绩效评价时间滞后于当年度预算编报时间，导致评价结果无法作为改进预算管理和安排预算的重要依据；四是项目绩效目标设置不合规。按规定不得下达查办经济违法违章案件的数量和罚没款指标，有的部门却把它作为绩效目标。

　　（二）市级专项资金管理不够规范。一是部分专项未执行。市级关心关爱专项经费、黄标车提前报废补助资金等5个专项资金均未执行，涉及金额8772万元；二是旅游发展专项资金、共建美丽乡村专项资金等6个专项资金未纳入清单管理，涉及金额8510万元。

　　（三）转移支付资金管理有待加强。一是提前下达县区转移支付预计数比重不足。2018年市财政对县区转移支付预算安排8.8亿元，提前下达比例仅34.5%，其中有18个部门单位专项转移支付全部未提前下达；二是部分上级转移支付资金执行进度较慢。有40笔9680万元的上级转移支付资金，未能在规定的30日内下达到县（区）政府或本级预算单位。

　　二、市直部门单位预算执行审计情况

　　审计部门加大大数据审计力度，首次对市直258个有编制项目支出的预算单位实施全覆盖审计。按照年初计划重点审计了原市工商行政管理局、原市质量技术监督局、原市食品药品监督管理局、原市知识产权局、市总工会和市财政局6个部门及所属单位。结合财政管理审计，延伸审计了相关部门及所属单位。审计结果表明，预算执行情况整体较好，但也存在年初预算编制质量亟待提高、工程标后管理不够到位、部分单位内控管理不够规范等问题。市审计局还对湄洲岛管委会2018年度财政管理情况进行审计。

　　三、重大政策措施落实跟踪审计情况

　　审计重点关注清欠民营企业中小企业账款、减税降费、“五个一批”（谋划一批、签约一批、开工一批、投产一批、增资一批）和赶超项目、“乡村振兴”等国家重大政策措施落实情况。审计结果表明，总体上各有关单位对国家重大政策贯彻落实认真及时、推进有力，但也存在一些问题。

　　（一）在清欠民营企业中小企业账款方面。我市各级政府部门和国有企业按照上级有关文件精神，积极清理被拖欠的民营企业中小企业账款。截止2018年12月底，全市共拖欠民营企业中小企业账款3.38亿元，至2019年4月共清偿2.64亿元，清偿进度78.2%。

　　（二）在减税降费政策落实方面。主要存在涉企保证金未能及时清理退回、车辆检测业务收费不规范、个别部门履职不到位等问题。

　　（三）在“五个一批”和赶超项目（服务业和制造业）跟踪审计方面。主要存在预（结）算未送财政评审规避财审监督、挪用经费用于其他项目建设、未见可行性报告却支付编制费用等问题。

　　（四）在乡村振兴战略落实方面，主要存在部分救助对象没有享受补助、列为危房改造重点救助群体享受危房改造救助比例偏低、惠农补贴“一卡通”管理不够到位“一户多卡”、项目资金滞留闲置申报材料不实、个别项目未按规定执行政府采购或招投标程序验收不严格等问题。

　　四、重点领域专项审计情况

　　围绕扶贫攻坚等8项专项审计，涉及资金总额9103万元，审计和调查单位94个，抽查项目106个。

　　（一）“扶贫专项资金”方面，本次审计涉及2018年市本级支出的1481万元，审计发现：全市投保“意外伤害及医疗补充保险”的贫困人员存在纳入国扶系统管理不够及时或不够精准现象。截止2017年底，有275人新增贫困人员还未纳入国扶系统统一管理；2018年第一批投保对象中有105人未在2017年末建档立卡、稳定脱贫名单中。

　　（二）“居家养老服务照料中心建设”项目，为我市2018年为民办实事项目。审计发现：部分工程建设未达到养老设施要求，有6个挂牌的“老年人日间照料中心”未达到规定标准。

　　（三）“基层医疗机构服务能力建设”项目，为我市2018年为民办实事项目。审计发现：有的县区卫健局没有按规定进行资金跟踪管理；有的单位违规把资金拨付给村委会；个别县区配套资金120万元没有到位。

　　（四）“科技专项经费”方面。审计发现：一是科技计划项目安排重点不突出、存在“撒胡椒面”现象；二是科技计划项目验收不及时，结题率较低；三是企业研发经费投入不足，县区财政配套经费不够落实。此外，还存在部分科技项目经费被调剂使用、科技计划项目经费下达不够及时等问题。

　　（五）“省级工业企业技改专项资金”方面，2018年省级下达4388万元,至2019年4月10日结余1197万元，存在项目资金未及时分配、未及时下拨等问题；“省级数字经济专项资金”方面，全省共下达各设区市专项资金1.63亿元，而我市仅争取500万元补助，且获取资金的企业未能按照要求实行专账核算管理； “2018年度市级互联网经济发展扶持资金”方面，年初预算600万元，当年仅支出299万元，且大部分资金集中在年底支出；“2018年度企业上市和场外市场挂牌融资项目补助资金”方面，年初预算600万元，实际只拨付13万元。

　　五、市属国有企业审计情况

　　主要审计了市交投集团、水务集团、城投集团、湄控公司、国投公司等5家市属国有企业。审计结果表明，被审计企业能够贯彻落实《公司法》相关规定，不断完善法人治理结构，提高经营管理水平。审计发现重点项目推进不够有力、企业经营管理不够规范、财务信息不够准确完整、未按规定提取坏账准备等问题。

　　六、审计建议

　　（一）进一步推动重大政策措施的贯彻落实。一是重点关注减税降费政策措施的落实，特别是涉企降费政策方面，关注涉企收费目录清单执行情况，坚决制止明令取消、停征、免征或未经批准自立的收费项目，切实减轻企业负担；二是继续清欠民营企业、中小企业账款，兑现清偿计划，防止继续发生新增拖欠账款；三是坚持高质量落实赶超，持续深化“放管服”改革，大力优化营商环境，发挥财政职能作用，把保障重大决策、重点支出、重大项目实施作为重中之重任务，为美丽莆田建设提供坚强支撑。

　　（二）进一步加强财政预算绩效管理。贯彻落实市《关于全面实施预算绩效管理的实施意见》文件精神，进一步规范和加强市级项目支出预算管理，提高财政资金使用效益。一是构建全方位预算绩效管理格局，将各级政府、部门和单位收支预算全面纳入绩效管理；二是建立全过程预算绩效管理链条，实施预算申请、编制、执行、决算全过程管理，将全面预算绩效管理推进到资金使用“最后一公里”；三是完善全覆盖绩效管理体系，将一般公共预算、政府性基金预算、国有资本经营预算、社会保险基金预算全部纳入绩效管理。

　　（三）进一步巩固“三大攻坚战”成果。坚持问题导向，以更高标准打好防范化解重大风险、精准脱贫、污染防治攻坚战。一是强化扶贫资金安全绩效管理，建立健全促进稳定脱贫和防止返贫长效机制，确保如期实现“两不愁、三保障”；二是建立完善地方政府和国有企业债务风险监测预警、应急处置机制；三是深入践行“两山”理念，加大大气治理、土壤污染修复、污水防治力度，严格环境执法，加快美丽莆田建设。

　　（四）进一步加大国有企业改革力度。一是实行国有企业分类改革，加大整合力度，将市属国有企业分为公益性企业和竞争性企业，实施分类指导、分类监管，确保国有资产安全完整、提质增效；二是推进混合所有制改革。市属竞争性国有企业可以在国有控股前提下，引进创新型、补短板的朝阳产业，增强“造血”功能；三是加强国有企业财务管理，坚决制止财务信息不真的行为，盘活国有资产存量，确保国有资产保值增值。

　　（五）进一步增强审计监督整体效能。一是着力构建审计整改长效机制。各单位要依法自觉接受审计监督,认真整改审计查出的问题；二是着力建立健全内部审计制度。加强对单位财务收支、经济活动、内部控制、风险管理等方面的内部审计和监管,强化审计结果运用,发挥内审风险防范作用；三是着力建立大数据协作机制。构建以审计机关主导、主管部门自审为基础、社会审计为补充的审计全覆盖工作机制,增强审计监督效能。

　　单位负责人：黄锦华  联系人：戴义瑞  电话：2294530

　　莆田市审计局

　　2019年8月29日
