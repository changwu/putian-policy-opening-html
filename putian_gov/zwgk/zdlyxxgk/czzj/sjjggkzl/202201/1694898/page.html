2020年度市本级预算执行及其他财政收支审计反映问题整改落实情况的公告

来源:市审计局 时间：2022-01-04 08:25
| | | |

2021年12月20日，市政府向市人大常委会报告了2020年度市本级预算执行及其他财政收支审计工作报告指出问题的整改落实情况，现将审计整改情况公告如下。

一、总体情况

市委、市政府高度重视审计查出问题的整改工作，市委书记、市长多次对有关问题作了批示。市政府召开专题会议研究部署整改工作，要求相关部门认真落实审议意见，严肃对待审计指出的问题，深入分析产生问题的原因，制定整改措施，建立整改台账，对账销号，限时办结，把审计揭示的问题整改落实好。市直各部门、单位和县区（管委会）按照市委、市政府的部署要求，认真执行市人大审议意见，全面落实加强审计整改工作强化审计成果运用的十条措施，推动整改工作取得明显成效。截至2021年11月30日，审计查出的102个主要问题，已整改81个、尚未整改到位21个，整改率80%。审计促进19个部门、单位出台了36个规范性文件。审计提出意见建议55条，被采纳48条。移送问题线索10条。

二、整改落实情况

（一）财政管理方面。针对决算草案收入数据不够完整问题，市财政局进一步加强非税收入的日常监管，督促非税收入及时足额缴入国库，确保决算草案收入数据完整准确，对少计的款项已按规定缴入国库。针对部分财政结转资金支出率偏低问题，市财政局适时通报结转资金支出较慢的部门单位，定期对结转到期的资金进行清理统筹。针对11个专项资金预算调整比例大于50%的问题，市直各专项资金业务主管部门不断加强预算通盘部署与谋划，市财政局加大绩效评价结果应用，促进提高预算编制的精准度，情况比去年有所改观。针对预算绩效管理方面问题，市财政局加强预算绩效管理体系建设，印发部门预算绩效事前评估管理办法，及时监控绩效情况并调减或撤销不符合绩效管理要求的项目。2021年年初预算安排278家预算单位的1277个项目，全部开展了绩效目标管理。针对新增政府债券资金使用方面问题，市财政局建立债券资金支出进度每月通报制度，督促项目主管部门及项目单位加快债券资金支出进度。截至11月底，还有3.07亿元未形成支出。针对存量资金盘活方面问题。市财政局建立存量资金资产定期清理盘活机制，相关部门及时组织排查落实，大部分存量资金已清理盘活。

（二）市直部门单位预算执行方面。针对部分单位预算编制不够精准问题。市财政继续加大预算绩效结果运用力度，同时建立按月向市人大报告预算执行情况机制，并抄送市审计局，倒逼各单位规范编制和审核预算，不断提高预算执行率。2021年9月，市财政局印发《预算绩效监控结果运用的通知》，加大绩效结果运用，对调整后项目支出预算全年实际支出率低的扣减项目绩效评价分数。针对资金支出较慢问题，市财政局采取对市本级预算资金原则上已不再结转、对上级转移支付补助资金，按照预算管理规定允许部门结转，加强预算执行督促，及时掌握预算执行动态，加大对重点单位、重点资金、重点项目特别是各类建设项目的监控力度，对有关单位存在的执行不力问题，适时通报并及时收回资金统筹使用，按照年中年末定期清理机制，对结转到期的资金一律及时清理统筹。针对资产管理存在薄弱环节问题，相关单位已完成契税缴纳，正在协调安置房土地证办理，对资产情况进行全面清查并整改。针对湄洲岛管委会预算管理方面问题。审计指出后，管委会立即研究落实整改措施，规范管理，审计反映的主要问题均已整改。

（三）重大政策措施落实跟踪方面

1.乡村振兴政策实施方面问题。城厢区印发了8个规范性文件，涵江区印发了10个规范性文件。城厢区已联合施工单位对农村人居环境整治项目验收，任务已完成。涵江区经省生态环境厅核定，179个村已通过验收127个，治理率70.95%，已达标。涵江区共拆除或关闭养殖场55处。土地确权登记信息差错率超过20%的问题，城厢区已组织核实并更正到位，同时重新对全区数据库中户面积10亩以上进行筛查核实，未发现类似问题。涵江区结合乡村振兴发展需求，适时调整产业发展项目规划，确保乡村振兴规划项目科学、有序推进。涵江区出台《涵江区现代农业产业集聚发展实施方案》，提出建设目标和措施。城厢区今年推荐申报市级以上龙头企业10家。

2.闲置土地方面问题。市自然资源局组织开展批而未供土地清理专项行动，将批而未供土地在招商底图上进行落位，认真查找批而未供土地产生的原因，分门别类制定处置方案，指导各县区按市政府《加快盘活处置批而未供土地有关问题的通知》简化供地手续，加快批而未供土地处置进度。

3.稳外贸稳外资政策落实问题。相关部门单位积极落实惠企政策，促进增资扩产。扶持龙头企业不断壮大、产业集聚，帮扶中小微企业转型升级，提升综合实力。全市外贸进出口不平衡，进口居全省第1位、出口居全省第7位的问题，今年1-10月出口完成250亿元，同比增长41.6%，提前完成全年任务。

    4.行政事业单位经营性国有资产集中统一监管政策实施方面问题。2020年5月，市财政局、市国资委、市机关事务管理处联合出台文件，对市级行政事业单位经营性国有资产集中统一监管下达任务清单，采取8种不同方式对394宗经营性国有资产进行处置和分类监管。截至2021年11月30日，已完成340宗，尚有54宗未完成处置。

    （三）重点基金和民生资金方面

1.基本养老保险基金审计方面。针对居民养老保险个人缴费财政补贴累计未到位131万元的问题，秀屿区政府已于今年3月拨付到位。针对部分职业年金存款未执行优惠利率问题，市人社局联合市财政局下发文件通知，进一步明确重申对职业年金活期存款实行按三个月整存整取定期存款基准利率计息的政策，目前少计的利息已全部收取到位。

    2.基本医疗保险基金审计方面。县区财政补助医保资金未到位问题，目前已全部到位。违规在医疗保险基金中报销应由社会保险公司支付的费用26.7万元，至5月已全额追回相关费用。违规分解住院多结算医保基金20.7万元的问题，5家医疗机构因分解住院多结算的职工医保已通过年度结算予以扣回，4家医疗机构多报职工医保基金也已追回。

3.市委市政府为民办实事项目实施审计方面。城市公共停车设施建设项目省级以奖代补资金支出问题，除了荔城区、北岸外，其他县区均已支出。市卫健委等部门已联合下发通知，明确了“肝净行动”计划任务数、补助标准。道路通畅工程中，相关工程资金已拨付或已完成结算、正在申请拨款。

针对2020年度市本级预算执行和其他财政收支情况审计发现尚未整改到位的21个问题，市审计局将进一步贯彻落实市委、市政府工作要求，按照市人大常委会的审议意见要求，督促有关部门和单位以及县区政府整改责任主体进一步采取有效措施，强力推动尚未整改到位问题的解决。对一些典型性的问题，列入审计监督重大事项督察督办内容。加强与其他相关监督部门联合督查力度，合力推进整改。持续推动有关单位建立健全审计查出问题整改长效机制，更好地发挥审计监督在推进莆田高质量发展超越中的作用。
