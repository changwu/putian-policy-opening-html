市机关运动配套设施建设竞争性磋商公告

来源:莆田市机关事务保障中心 时间：2026-01-26 10:56
| | | |
 项目概况

莆田市机关事务保障中心已根据政府采购相关法律法规，经相应程序确定采用竞争性磋商方式组织市机关运动配套设施建设 （以下简称：“本项目”）的政府采购活动，现欢迎国内合格的供应商前来参加。

各潜在供应商应在莆田市城厢区龙桥街道荔城中大道2580号四楼获取采购文件，并于2026年2月6日9点00分（北京时间）前提交响应文件。

二、申请人的资格要求：

1.符合《中华人民共和国政府采购法》第二十二条第一款规定的条件；

2.落实政府采购政策需满足的资格要求：

进口产品：无

节能产品：适用于本项目采购包1，按照《关于印发节能产品政府采购品目清单的通知》财库〔2019〕19号执行，或最新公布的品目清单执行

环境标志产品：适用于本项目采购包1，按照《关于印发节能产品政府采购品目清单的通知》财库〔2019〕19号执行，或最新公布的品目清单执行

促进中小企业发展的相关政策：

采购包1：不专门面向中小企业

3.本项目的特定资格要求：

资格审查要求概况

评审点具体描述

资格承诺函

采用资格承诺制的供应商，须根据投标(响应)格式文件要求提供资格承诺函，否则，视为未按照招标文件规定提交投标人的资格及资信文件，按资格审查不合格处理。

相关资质

供应商须备有效的建设行政主管部门核发的建筑工程施工总承包承包三级及以上（不分主、增项差别）资质和有效的《施工企业安全生产许可证》； 

项目负责人

供应商拟担任本招标项目的项目负责人应具备有效的不低于二 级建筑工程(专业)注册建造师执业资格，并持有安全生产考核合格证书B证。

三、获取采购文件

1、时间：2026年1月26日至2026年2月2日，每天上午8:00至12:00，下午14:30至17:30。（北京时间，法定节假日除外）

2、地点：莆田市城厢区龙桥街道荔城中大道2580号四楼

3、方式：

①上门报名：供应商直接到莆田市信成造价咨询有限公司购买招标文件，报名地址：莆田市城厢区龙桥街道荔城中大道2580号四楼；

②转账方式报名：即供应商先将标书费转账到指定的账户，再将转账的银行回单、报名人全称、地址、电话、传真、联系人、手机、E-mail、报名项目编号、项目名称等发送至我司邮箱PTXC2025@163.com，我司再将招标文件通过电子邮件方式发送给报名人； 

③标书费：纸质招标文件或电子版招标文件售价100元。

四、响应文件提交

1、截止时间：2026年2月6日9点00分（北京时间）

2、地点：莆田市城厢区龙桥街道荔城中大道2580号六层

五、开启

1、时间：2026年2月6日9点00分（北京时间）

2、地点：莆田市城厢区龙桥街道荔城中大道2580号六层

六、公告期限

自本公告发布之日起3个工作日。

报名费、代理服务费缴纳账户：开户名—莆田市信成造价咨询有限公司；开户行—光大银行莆田分行；账号—79880188000047251。
