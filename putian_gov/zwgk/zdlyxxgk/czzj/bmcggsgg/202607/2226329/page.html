莆田市东圳水库大坝安全监测自动化试点项目监理服务（二次）询价公告

来源:PTSSLJ--莆田市水利局 时间：2026-07-20 11:06
| | | |
 

本项目已经批准实施，询价单位：莆田市东圳水库管理局。现采用询价组织莆田市东圳水库大坝安全监测自动化试点项目监理服务（二次）（以下简称：“本项目”）的政府采购活动，欢迎合格的报价人前来参与报价。

一、项目概况和招标范围

1、项目名称：莆田市东圳水库大坝安全监测自动化试点项目监理服务（二次）；

2、业主单位：莆田市东圳水库管理局；

3、建设地点：福建省莆田市东圳水库；

4、项目规模：项目预算约138万元。

5、询价范围和内容：莆田市东圳水库大坝安全监测自动化试点项目（包括但不限于：测量机器人等设备采购及安装、观测房等土建施工等内容，本项目具体内容于2026年06月02日在福建省政府采购网上发布磋商公告，报价人可自行查阅）。

6、质量标准：符合本项目的采购文件要求及相关规程规范合格标准等。

7、监理总工期：施工前15天+施工工期+工程竣工验收合格且竣工资料存档备案完成+工程保修期，监理人监理总工期以外的善后服务须随时到位，监理服务期从合同签订之日起至保修期满为止。

8、合同签订时间：自中标通知书发出之日起10个工作日。

9、付款方式：莆田市东圳水库大坝安全监测自动化试点项目完工验收合格及相关内业资料提供完整后，一次性付清。

二、报价人的资格要求：

（1）报价人须在中国境内注册并具有独立法人资格，提供三证合一的企业法人营业执照复印件并加盖公章。

（2）报价人代表必须经报价人的法定代表人授权参与本项目报价，请提供法定代表人授权投标代表的授权委托书原件(报价人代表是法定代表人则无需提供)，法定代表人和投标代表的身份证复印件并加盖公章。

（3）报价人参加本次询价的前三年内，在经营活动中没有重大违法记录。

（4）本项目要求报价人须具备有效的不低于水利行政主管部门颁发的水利工程施工监理乙级资质。

（5）本项目报价人至少应配备总监1名，专监1名，监理员1名，拟担任本项目的总监理工程师应具备有效的水利部颁发的水利工程施工监理专业监理工程师注册证书和总监理工程师聘任文件和水利水电相关专业中级工程师及以上职称。并在其他人员及试验检测仪器设备方面具有相应的监理能力。

（6）本次询价不接受联合体报价。

 

三、报价要求

1、本项目监理服务费参照发改价格【2007】670号标准、发改价格【2011】534号标准及闽价服【2013】260号标准文件执行，本项目监理服务费的报价最高限价为：（118.5215×40%+20.05）×16.5÷500收费基价×0.9专业调整系数×1.0工程复杂程度调整系数×1.0高程调整系数=2.0035万元。

本次报价人报价以最高限价×（1-下浮率%）即可，示例:

假如下浮率%为20%，报价=2.0035×（1-下浮率%）=2.0035×（1-20%)=1.6028万元；

2、报价下浮率范围：0≤下浮率%＜100%，否则报价无效。监理服务费用包干，中标（成交）后不再调整。

四、时间安排

询价公告时间:2026年07月20日～2026年07月23日，每天上午8：30-11：30，下午15：00-17：00（北京时间）。询价相关文件自行下载。

报价文件递交截止时间：2026年07月24日09时00分，逾期收到的或不符合规定的报价文件将被拒绝。

五、提交的材料

1、提供报价人合格有效的营业执照(副本)的复印件。

2、提供法定代表人授权报价人代表的授权委托书原件(报价人代表为法定代表人时无需提供)，法定代表人和报价人代表的身份证复印件。

3、报价人参加本次询价的前三年内，在经营活动中没有重大违法记录书面声明。

4、具备有效的不低于水利行政主管部门颁发的水利工程施工监理乙级资质，提供有效证书复印件。

5、报价人拟担任本招标项目的总监理工程师应具备有效的水利部颁发的水利工程施工监理专业监理工程师注册证书和总监理工程师聘任文件和水利水电相关专业中级工程师及以上职称。拟派总监理工程师必须为报价人的本企业在岗人员，以注册监理工程师注册执业证书上的注册单位为准，报价时需提供有效证书复印件、总监理工程师聘任文件。

在其他人员及试验检测仪器设备方面具有相应的监理能力。报价时候对此提供书面承诺函，格式自拟，内容明确。

其他要求：项目机构成员均应为本单位人员，应提供近三个月:2026 年04月01日至2026年06月30日社保缴纳凭证。【注：社保由上级单位统筹缴纳的，应提供上级单位出具的统筹缴纳证明；属于离(退)休人员的，应提供社保部门的离(退)休证明和本单位聘用合同。】投标时提供总监理工程师的相关证明材料即可，其他人员可在中标后签订合同时一同提供。

6、报价函。

（注:上述营业执照、证书、证件等均须在有效期内或经年检有效，所有复印件均需加盖报价人单位公章。）

六、报价文件递交方式及地点

1.本次询价报价人递交报价文件方式：送达或邮寄。

2.报价文件形式：报价人应提交纸质报价文件两份及电子版报价文件一套（光盘或其他闪存介质），纸质文件与电子介质一同密封。电子版报价文件须为纸质报价文件加盖公章后的扫描件。报价人须根据询价公告要求进行报价，并密封提交。纸质报价文件须在密封袋骑缝处加盖报价人公章，密封袋封面应注明项目名称、报价人全称、联系人及联系电话。

3.所有纸质报价文件应胶装成册，并逐页加盖报价人公章；未胶装成册的报价将被拒绝。

4.纸质报价文件递交地点：莆田市东圳水库管理局（莆田市城厢区常太镇松峰村东圳21号），联系人：林先生，联系电话:15060365566。

七、报价须知

1、本次报价结果将作为确定成交人的依据。

2、报价人所报的价格应满足项目内容及要求，报价只报下浮率。响应报价应对莆田市东圳水库大坝安全监测自动化试点项目监理服务（二次）所涉及的有关项目的所有费用进行报价，包括但不限于：相关伴随服务合同期间所可能发生的一切费用。

3、报价人必须响应项目内容及要求，所有报价材料须加盖公章及骑缝章并密封，否则报价无效。

4、报价人在报价单上必须填写完整且有效的报价单位联系人、联系号码和公司详细地址，报价人应对所递交的报价文件以及与报价有关的证明和资料的真实性负责，若以弄虚作假给询价单位造成损失的，依法承担赔偿责任。

5、本次报价过程的所有费用自理。

6、询价单位将公布相关报价内容和询价结果，报价人请及时关注。询价单位不承担可能发生的一切法律责任、费用和后果。报价人自行考虑是否参加本次报价。

八、发布公告、澄清及修改的媒介

询价公告及文件如有澄清和修改，我单位将在莆田市人民政府网上发布本次报价项目的相关信息，请各报价单位及时关注，报价单位若没有在以上网站上查询相关信息而影响报价的，报价单位自行承担相关责任。

评审办法

一、报价文件的审查：

1.报价人资格性、符合性在询价评议前由询价小组审查；

2.询价小组成员对报价文件是否完整，是否有计算错误，文件是否恰当地签署进行检查。

3.询价小组对报价文件进行实质性审查，发生重大偏离的将被拒绝。

二、本批采购确定成交人的办法：

1.在全部满足询价文件实质性要求前提下，依据上述监理费统一的报价下浮率进行评定，优惠力度（即下浮率）最大的即选定为中标（成交）人。

2.下浮率相同的，则采取随机抽取的方式确定成交候选人。

3.有效报价不足三家的，本次询价活动终止，除采购任务取消情形外，询价人将依法重新组织采购或者采取其他方式采购。
