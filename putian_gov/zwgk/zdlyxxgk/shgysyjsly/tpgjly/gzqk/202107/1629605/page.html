策论福建 | 坚持抓好六个“突出” 奋力谱写莆田乡村振兴新篇章

来源:学习强国 时间：2021-07-19 17:23
| | | |

　　今年政府工作报告和“十四五”规划纲要都对三农工作、全面实施乡村振兴战略做出重要部署，为我们进一步在新时代做好“三农”工作指明了方向。作为基层农业农村党员干部，要认真学习贯彻全国两会精神和中央农村工作、福建省委农村工作会议精神，结合开展“再学习、再调研、再落实”活动，扎实做好“三农”工作，全面实施乡村振兴战略，全力推动“十四五”农业农村工作开好局、起好步。

　　脱贫攻坚取得胜利后，要全面推进乡村振兴，这是“三农”工作重心的历史性转移，须臾不可放松、务必抓紧抓实。围绕实现“农业高质高效、乡村宜居宜业、农民富裕富足”，要坚持抓好六个“突出”：

　　一、突出巩固拓展，推动脱贫攻坚同乡村振兴有效衔接 

　　“十三五”期间，莆田现行标准下建档立卡贫困户全部脱贫、贫困村全部摘帽。要按照党中央决策部署，在5年衔接过渡期间内，严格落实“四个不摘”，保持主要帮扶政策总体稳定，并健全防止返贫机制。“十三五”期间，莆田对口协作的宁夏西吉县退出贫困县序列。我们将持续深化闽宁协作，更加注重发挥两地优势，进一步拓展合作领域，推动由扶贫协作转为全面合作。

　　二、突出压实责任，牢牢把住粮食安全主动权 

　　粮食安全是战略问题。莆田“十四五”期间粮食生产面积、总产量要稳定在45.8万亩、18.5万吨。同时，强化耕地保护，坚决遏制耕地“非农化”、防止“非粮化”。今年，莆田将新建5万亩高标准农田建设，“十四五”期间完成15万亩。同时，把种子作为农业现代化的基础，依托莆田“四大名果”“四大贝苗”等具有区域特色、品质优良的农产品，抓好种质资源保护和利用。

　　三、突出高质高效，大力发展特色现代农业 

　　产业兴旺，是解决农村一切问题的前提。福建山海平原兼备，农业资源丰富，要围绕把优势资源转化为特色产业，做大做强龙头企业，大力发展农产品精深加工，把产业链主体留在农村、把价值链收益主要留给农民。尤其要通过规范引导农村土地经营权有序流转，让耕地更多地向新型农业经营主体集中，发展多种形式的适度规模经营、专业化生产。莆田市木兰溪治理实现“变害为利、造福人民”目标，要着力激活木兰溪生产力，加快农村一、二、三产业融合发展，带动一产往后延、二产两头连、三产走高端，全力打通“绿色青山”向“金山银山”的转换通道。

　　四、突出宜居宜业，加快实施乡村建设行动 

　　我们要坚持规划引领，加快明确村庄布局分类，坚持谋定后动、高位策划，严格按照规划管控要求进行建设，不贪大求快，不违背农民意愿，不搞大拆大建。尤其要保护好传统村落和乡村特色风貌。在乡村建设过程中，要注重从农民最迫切需求入手，重点解决“有没有”问题，既要尽力而为，也要量力而行。

　　五、突出改革创新，推动城乡融合发展见到实效 

　　全面推进乡村振兴，必须用好改革这个“关键一招”。一方面，要深化农村改革，落实第二轮土地承包到期后再延长三十年不变政策，稳定和完善农村土地承包关系，稳慎推进农村宅基地改革、深化农村集体产权制度改革等。另一方面，要推动城乡融合，强化以工补农、以城带乡、城乡融合，把该打开的“城门”打开，促进农业转移人口市民化。

　　六、突出强基固本，全面提升乡村治理水平 

　　乡村要振兴，必须夯实乡村治理这个根基。今年是集中换届年，要早做谋划、采取措施，选优配强村“两委”成员特别是村党组织书记。要全面加强精神文明建设，培育文明乡风、良好家风、淳朴民风。要全面加强基层能力建设。莆田聚焦基层治理和服务两个能力提升，全面推进“党建+”乡村邻里中心、“综治+”治理中心建设，整合资源、融合功能、协同力量，创出了经验模式，受到群众广泛好评。

　　进入新阶段、贯彻新理念、构建新格局，我们要以永不懈怠的精神状态和一往无前的奋斗姿态，知责于心、担责于身、履责于行，奋力谱写新时代“三农”工作新篇章，以优异成绩庆祝中国共产党成立100周年。

【作者为中共福建省委党校、福建行政学院第60期中青年干部培训班一班学员，莆田市农业农村局（农办）党组书记、局长（主任）】
