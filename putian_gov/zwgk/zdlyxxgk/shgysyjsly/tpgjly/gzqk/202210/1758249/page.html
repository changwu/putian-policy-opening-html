榜头镇：党建引领乡村振兴提质增效

来源:仙游组工、榜头镇 时间：2022-10-09 20:04
| | | |

　　近年来，榜头镇始终坚持把党建引领作为推动乡村振兴的“红色引擎”，通过抓党建、强堡垒、兴产业、促经济、优生态、育文明，把基层党建融入乡村振兴各环节、全链条，助力乡村振兴高质量发展。

　　强化组织 夯实堡垒

　　汇聚乡村振兴“新动能”

　　强化党员分类管理，开展有针对性并且形式多样的党组织活动，采取集中“领学”、个人“自学”方式，通过“线上、线下”多种方式不定期推送学习内容，常抓党员学习教育。推行“固定党日+自选动作”模式，固定党日不固定形式，广泛开展党组织和党员“双承诺”、无职党员设岗定责、新时代文明实践等活动，树强党员先锋模范形象，形成“支部引领、党员带头、群众参与”的工作格局，为实现乡村振兴奠定坚实组织保障。实施“双推双选”“四培双带”工程，储备年轻有能力有素养的优秀人才，鼓励参与村级事务管理，有效改善党员队伍结构，提高基层党组织创造力、凝聚力、战斗力，为乡村振兴提供人才支撑。

　　“榜头镇下辖村居众多，聚焦‘山、水、林、田、木’等多种资源禀赋，将发展目标相近的村居串珠成链，连线成面，创新打造集农业产业、乡村漫游、农旅观光、文化体验等为一体的榜头乡村振兴示范综合区。”榜头镇党委书记张春志表示，想要做大做强榜头农业就必须做好顶层设计，从打造完整产业链上下功夫，推进当地一二三产业深度融合发展。

　　榜头镇以仙作品牌为抓手，推动乡村振兴，打造“乡村休闲、生态仙溪、仙作工艺、乡村治理、红色记忆、产教研创”6条“仙作+乡村振兴”示范带建设。6条示范带建设涵盖全镇39个村居，10个单位。

　　除了后坂村、光埔村、后南溪村等，多数村居在发展“仙作+乡村振兴”示范带过程中都存在资金短板、发展思路不够明晰、积极性不高等问题。针对这些问题，全镇村（社区）党组织“以结果说话，以成绩论英雄”，在建设中找差距、做对比、树典型、立标杆，各村（社区）根据PK交流会排名情况，加大资源倾斜力度，递次分配资源，促进示范带协调发展。

　　扮靓“面子” 做实“里子”

　　展现乡村振兴“新风貌”

　　榜头镇积极推进网格化管理，破解乡村治理难题，大力实施“党建引领 夯基惠民”工程。每个季度，榜头镇各村居推出“星级党员、星级文明户、优秀单元长、优秀网格长、优秀志愿者”等评选，获奖者可在发展党员、后备干部、代表推荐和子女参军就学等方面享有优先权。另外，在物质上提供乡村特色农产品或其他生活用品作为物质奖励，鼓励本辖区商家、商场给予星级文明户商品消费打折优惠等。通过与群众切身利益相挂钩的形式，大大提高了群众参与基层治理的积极性。

　　在全镇创新推行“1+3+39”机制，实行党政每周1次矛盾纠纷排查分析会；优化派出所“初心调解工作室”、法庭“诉调衔接室”及司法所“巡回调解工作室”3支调解队伍建设；39个村居调解委员会一线矛盾调处，促进矛盾纠纷早化解早处置。光埔村、后南溪村因在乡村治理中成效突出而被评为“省级乡村治理示范村”，走出了一条切实管用的乡村治理路径模式。

　　此外，针对群众强烈反映的农村污水整治问题，积极筹措资金，开展污水管网项目建设。在榜头镇污水管网项目建设试点村之一的后南溪村，可以看到村里的污水管网工程建设正在紧锣密鼓地推进中。预计到明年，榜头镇将完成39个村居的污水管网建设任务。

　　三产融合 强产富民

　　探索乡村振兴“新模式”

　　乡村振兴，民生为本。榜头镇围绕群众最关心最直接最现实的利益问题，抓重点、补短板、强弱项，千方百计增加农民收入，不断增强农民群体的获得感、幸福感、安全感。

　　榜头镇拥有各类工艺企业近2000家，从业人员达6万人，其中76家规模以上工艺企业产值超100亿元。通过搭建“艺都仙作云上榜头”平台，整合榜头镇优秀红木产业资源，加大特色产业曝光度；从榜头实际出发，制定文旅+农业惠农政策，将榜头特色产业融入三日游规划，促进乡村振兴；创新发展美丽田园，助推以何麓庆加家庭农场为代表的一批农业种植大户发展，多措并举促进农民增收。

　　大力培育壮大香文化产业。推进奇楠沉香种植，初步摸底榜头镇适宜种植地块约7800亩，已种植面积约1500亩。加大支持沉香企业种苗力度，提高农民种植的积极性。

　　盘活提升闲置资产。利用博览城、石艺城、油画城、福绵绵、海凌仙艺等闲置标准化厂房进行“腾笼换鸟”，加大招商引资力度，引导工艺美术行业企业入驻，在税收、租金上给予优惠政策，促进产能提升。

　　培育发展新型业态。依托工艺博览城、坝下古典工艺家具一条街、佛珠小件一条街等工艺美术特色阵地，创新“一业带百业”运行模式，发展夜间经济、直播经济、文创经济。

　　“榜头镇通过探索数字化在镇村产业及经济社会发展中的应用，走出了仙作工艺美术产业的发展和转型之路。”张春志表示，榜头镇以中国古典工艺博览城、京东?仙游数字经济产业园、环球工艺城等为核心，围绕红木古典家具特色产业，努力打造全国最大红木古典家具生产基地、红木文化创意基地、红木电商核心区、工艺旅游示范区。

　　产业兴，则乡村兴。生态美，则百姓富。榜头镇不断夯实“仙作+乡村振兴”示范带基石，激发乡村治理内生动力和发展密码，不断提升群众的获得感、幸福感和安全感，努力走出了一条具有莆田特色、仙游样板的榜头乡村振兴之路。
