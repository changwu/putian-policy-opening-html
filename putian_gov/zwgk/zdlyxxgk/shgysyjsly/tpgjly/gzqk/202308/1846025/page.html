莆田援同工作队：跨越山海寄深情

来源:福建日报 时间：2023-08-18 23:49
| | | |

　　20多年前，一场跨越山海的东西部扶贫协作“接力长跑”开启。如今，闽宁协作已从单向扶贫，拓展到两地经济社会建设全方位多层次、全领域广覆盖的深度协作。

　　去年，中组部、教育部等八部门启动国家乡村振兴重点帮扶县教育人才组团式帮扶工作。在此基础上，莆田市自提目标，按照“同心所需，莆田所能”的帮扶原则，不断拓展协作深度，创新协作方式，优化协作机制，对宁夏回族自治区吴忠市同心县开展支医支教组团式精准帮扶，通过“传帮带”，为同心县留下一支薪火相传、专业技能优秀的队伍。

　　数据显示，近年来，莆田援同工作队共统筹社会帮扶资金3960万元，援助同心县实施8个民生社会类项目，其中投向组团式帮扶的资金合计3356万元，占比84.7%，助推组团式帮扶效果最大化。

　　全方位帮扶薄弱校

　　“刚从宁夏回来一个月，就接到不少电话，邀请我们下学期再去。”谈起今年赴宁支教的经历，莆田市援同初中教育人才帮扶团队队长、南门学校副书记吴国辉告诉记者，“当地人豪爽热情，两地教师队伍融合得不错，帮扶成效也比较明显。”

　　南门学校是莆田公立初中校的“排头兵”，有着60多年办校经验和成熟的师资队伍。去年8月，南门学校与同心县第六中学签订结对帮扶协议，决定从学校管理水平、教师队伍能力、教育质量提升、学生综合素质等方面对同心六中进行嵌入式的全方位帮扶。

　　“这是莆田市首次在初中教育帮扶中尝试参照组团式帮扶模式，告别以往支教教师分布分散、难以形成合力的局面。”吴国辉告诉记者，“我们通过参与学校教育教学管理，梳理一系列针对性建议，尝试把先进的管理理念、教学理念带到同心六中。”

　　莆田援同初中教育人才帮扶团队以南门学校为“大后方”，把“一研一听二学三备四统一”的集体教研模式带去同心六中，共同打造“一师一优课、一课一名师”，帮助同心六中提升教育质量。

　　为充分实现资源共享，打破校际交流屏障，南门学校通过云上平台，线上开展名师讲座，直播示范课、精品课，展开互动教研。同心六中的教师们还可以实现课件、试卷、习题库一站式下载。

　　“豫海中学是当地三个高中之一，生源不是很好，基础薄弱，教师队伍也比较年轻，缺乏经验。”8月12日，莆田第一中学高三语文教师刘细平再次出发前往同心县，“希望能够通过帮扶，把科学的、优质的教学经验拓展输出，帮助当地教师更好地掌握合适的教学方法。”

　　除了参加教育教学工作外，在豫海中学，所有支教教师均参与“一对三”师徒结对，让豫海中学的青年教师迅速“强起来”。

　　组团式帮扶，效果如何？今年，豫海中学交出了一份漂亮答卷：该校改变高一招生录取分数线全县最低的历史状况，创造了2023年高考奇迹——本科上线329人，比去年增加了174人；组建科技教育教师团队，指导学生赢得2023年全市青少年机器人竞赛第一名。

　　博士团队改造盐碱地

　　“出村往外瞧，一片白面瓢。”时隔半年，莆田学院环境与生物工程学院党委副书记许荔仙仍记得初次踏上这片土地时看到的场景。

　　大片的盐碱地，覆盖着斑白的盐渍。抵达宁夏的第一个月，大家下到田里，对当地的土壤、水源进行采样，在采集了100多个样本之后，成功分析出土地盐碱成因，并初步规划了12种不同改良模式。

　　“项目目前基本达到预期目标，后期会根据土壤检测结果、三种不同耐盐作物的长势和产量等不断调整盐碱地治理措施，通过连续有效的土壤改良，最终让盐碱地变为可耕种的良田。”许荔仙说。

　　今年2月，莆田学院环境与生物工程学院发起一支由10名博士为主力的科研团队，来到同心县韦州镇，与当地政府联合进行甘沟村盐碱地治理试验项目，开展第一期200亩重度盐碱地土壤改良与作物种植研究。

　　改漫灌为滴灌、研制土壤改良剂……科研团队在盐碱地里挥洒汗水，尝试用不同的生物、化学方法唤醒抛荒十余年的盐碱地。6月初，筛定选出的3类耐盐碱作物种植试产，仅一周时间，全部出苗！

　　眼下，甘沟村广阔的田野里，长出了油葵、湖南稷子、碱蓬。曾经的“不毛之地”，有了新的颜色。“村民们都很高兴，作物一天天长高，下月初就能收割了。油葵的种子还能用于榨油，秸秆可喂食滩羊……莆田来的高校团队为我们解决了大难题！”甘沟村党支部副书记赵建泽兴奋地说道。

　　不间断培育青年医师

　　“现在不担心了，科里有两个医生已经可以独立承担大部分常规冠脉介入诊疗手术……”8月10日晚10点20分，刚刚完成一台手术回到家中的许开祖，同记者聊起了去年在同心县支医帮扶的经历。

　　许开祖是莆田学院附属医院心血管内科副主任医师，去年1月8日，他跟随工作队去往宁夏，在同心县人民医院刚刚成立一年多的介入科开展精准帮扶。

　　因饮食过咸、偏油腻，以及生活习惯的不同，宁夏地区冠心病发病率相对较高，尤其急性心梗患者数量多。

　　“急性心肌梗死起病急、病情重、死亡率高，在无支医专家在场时，同心县没条件开展心梗急诊介入手术，往往要把患者送到200多公里外的银川市就诊，耽搁一两个小时，很多病人错过黄金救治期。”支医期间，许开祖一边全力救治心梗患者，一边倾尽所能开展“传帮带”，最忙时，他在不到48小时的时间里救治了5个急性心肌梗死患者，连续两个凌晨为心梗患者实施急诊介入手术。在同心县人民医院的6个月里，许开祖完成了冠脉介入诊疗手术140多场，挽救急性心肌梗死患者58例。

　　“本以为要开腹手术，已经打算好了去银川，没想到还没出县城，福建医生就帮我把病治了。”患者吴阿伯感慨道，他在同心县中医院接受了该院首例结肠巨大息肉黏膜剥离术，免去舟车劳顿之苦的同时，也省了一笔不小的费用。

　　为他完成治疗的，是来自莆田市第一医院消化内镜室的主任医师郭朝书。“原先这里的内镜室只负责常规检查，尚不能开展内镜下治疗，业务比较滞后。”到同心县中医院后，郭朝书带去了丰富的临床经验和先进的技术手段，全院普及胃肠镜检查和内镜下治疗基本知识，开设急性重症胰腺炎、急性上消化道出血等系列课程，同时对科室医生进行消化道早期癌的识别、诊断与治疗重点培训。

　　“他通过手术示范、开设课程等方式，不断帮我们提升技术水平，现在我已经可以独立完成内镜下息肉黏膜剥切术等一些三级手术。”同心县中医院内镜室青年医生李小花说，“郭医生严谨负责的工作态度对我产生了很大的影响。”

　　数据显示，今年以来，莆田支医团队累计诊疗门急诊病人5000余人次，完成手术300余台，挽救疑难危重病人126人，开展疑难危重病例会诊200多例，培训医务人员1000余人次。

　　山海情缘没有断点。今年，莆田市共选派10名医师重点帮扶同心3家医院5个科室，目前，由莆田市急救中心副主任医师郭海泉带队的新一批支医队伍正在同心县开展工作，确保全年支援不间断。
