莆田：聚“五美”之力，夯乡村振兴之基

来源:中国网 时间：2023-01-03 17:28
| | | |

　　福建省莆田市按照全省乡村“五个美丽”建设的部署要求，主动作为、先行先试，从组织领导、因地制宜、健全机制等三个维度狠下功夫，以“三动、五抓、四化”持续推进“五个美丽”建设，有效提增生态产业价值，为乡村全面振兴打下了坚实的基础，相关经验做法得到国家乡村振兴局领导的高度肯定。我市今年计划打造“五个美丽”建设点3365个，已完成建设3405个，完成率101．19％，其中，完成建设美丽乡村庭院2327个、美丽乡村微景观861个、美丽乡村小公园140个、美丽田园46个、美丽乡村休闲旅游点31个，累计完成投资17859．54万元。

　　一、注重“三动”，着力形成整体推进格局

　　“五个美丽”建设是一项系统工程，我市立足市情，结合资源禀赋，充分发挥市级在组织领导、资源配套、整体推进等方面的统筹作用。

　　一是专班推动。市委、市政府高度重视，主要领导亲自谋划、亲自部署，把“五个美丽”建设作为乡村建设的关键一环，与实施乡村振兴战略一体部署、一体推进，成立以市政府分管领导为组长，市直有关部门负责同志为成员的工作专班，统筹协调推进建设工作。

　　二是奖补驱动。每年从市级财政衔接推进乡村振兴补助资金中安排2000万元专款用于“五个美丽”建设。补助资金不搞均等化、不撒胡椒面，对建设成效明显、工作推进扎实和被入选全省建设典型的建设主体，采取“以奖代补”的形式予以资金奖励；对推进不力、进度缓慢、效果不明显的予以通报，适度调减年度乡村振兴衔接市级补助资金。目前，已下拨第一批市级奖补资金500万元。

　　三是典型带动。召开全市“三农”暨乡村振兴现场推进会，组织各县区党政分管领导和乡镇主要领导现场参观学习“五个美丽”建设，发挥先进典型的示范引领作用，进一步加快全市“五个美丽”建设进程。指导县区制作微视频，展示各县区工作成效和做法。如，仙游县“五个美丽建设宣传视频”被福建省农业农村厅选用，作为优秀作品展播。通过现场看、现场比、现场学，推动互学互鉴、互促共进。

　　二、突出“五抓”，因地制宜打造特色亮点

　　“五个美丽”建设涉及乡村面貌、生态景观、区域文化等因素，我市在统筹兼顾、通盘规划的基础上，因地制宜、挖掘特色、打造亮点，力争打造出一个具有“莆田特色”的美丽乡村建设之路。

　　一是抓“一院一景”，美丽庭院赋值。积极引导广大群众以庭院为载体，突出“布局设计协调、居室整齐清洁、庭院净化绿化、家庭和谐家风、产业致富生活”，打造“一院一景”，扮靓庭院。坚持宜产则产，深挖“庭院经济”，让美丽庭院赋值乡村产业。如，在湄洲岛充分发挥旅游景区优势，将美丽庭院同民宿发展相结合，建设了湄屿南巷、湄屿时光等一批特色民宿。

　　二是抓“就地取材”，美丽微景观提颜。鼓励利用房前屋后的闲置土地砌筑花台、搭建栅栏，积极实施小节点景观化打造工程，极大提升了村容村貌。如，在仙游县枫亭镇铺头社区依托枫慈溪沿岸风景，建设“口袋公园”，对枫慈溪上坅坝边的路面进行美化彩绘，融合民俗活动、传说典故和特色美食，充分展示枫亭的传统文化。

　　三是抓“就势造景”，美丽小公园赋能。利用乡村四旁闲置地、边角地块，因地制宜打造生态环境优化、文化底蕴浓厚、文旅休闲的美丽小公园，不仅有多种绿化，还为群众提供可休闲活动场所，让小公园展现“大功能”。如，在北岸经开区结合“一人认植一棵树、一村一花一水果，同心共践港城梦”，在西乌垞村建设主题为“百果园”的村级公园。

　　四是抓“抛荒整治”，美丽田园增值。结合撂荒地整治和高标农田建设，修田间小路、修池塘沟渠、修节水水闸、修休憩廊亭，让“田成方、路相通、渠相连、车到田、人可息”，让村民的“小田”变“大田”，“碎田”变“整田”，并通过“农旅融合”实现产业提质升级。如，在涵江区大洋乡结合撂荒地整治，加快“美丽田园”建设，开展“我在大洋有亩田”共享稻田认领活动，举办“插秧文化节”等系列体验活动，让撂荒地变美丽田园，既保障粮食生产安全，又带动休闲农业发展。

　　五是抓“文旅融合”，美丽乡村休闲旅游点添彩。坚持把美丽休闲旅游点建设和保护生态环境、文化传承结合，通过合理布局，积极谋划项目发展乡村旅游，如，在城厢区常太镇岭下村实施以“立谷听涛，乡野岭下”为主题的生态乡村休闲旅游建设，建成了独具特色的岭下24景，叫响了岭下村乡村旅游品牌，越来越多的村民实现在家门口就业；又如荔城区西天尾镇后黄村，依托当地“侨”优势，侨村浓郁的南洋风情，逐步盘活“乡愁资源”，成为莆田一张崭新的文化旅游名片。

　　三、推行“四化”，创新机制常态推动落实

　　创新推行任务“清单化”、督导“一线化”、会商“定期化”、考评“严格化”，将“五个美丽”建设各项目标任务抓到细处、做到深处、落到实处。

　　一是任务“清单化”。指导各县区将建设任务层层落实到乡、到村、到具体建设点，逐项明确任务内容、目标要求、进度情况和完成时限。

　　二是督导“一线化”。市里督促各县区强化工作落实、要求各县区对“五个美丽”建设情况进行一线督导，对督导过程中发现的问题，现场提出解决思路、完成时限，确保问题整改到位，工作推动到位。

　　三是会商“定期化”。建立健全工作联合会商制度，工作专班定期开会协商，加强“五个美丽”工作调度，及时协调解决建设过程中遇到的有关问题，推动建设活动深入开展。

　　四是考评“严格化”。把“五个美丽”建设工作作为“三农”重点工作评价的重要内容，同农村人居环境整治、农村建设品质提升、乡村振兴等工作一同考核，倒逼各项工作任务落实。
