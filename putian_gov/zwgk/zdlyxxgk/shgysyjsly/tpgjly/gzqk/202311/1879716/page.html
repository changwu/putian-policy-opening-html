“跨”出乡村共富路，仙游县大济镇创建“善化里·农文旅”示范片区

来源:仙游报道 时间：2023-11-08 20:35
| | | |

　　仙游县大济镇探索实施“跨村联建”新模式，创建“善化里·农文旅”示范片区，6个联建村抱团发展，把乡村振兴由“单打独斗”向“合力作战”转变，实现资源效益最大化，共同“跨”出共富之路。

　　深秋时节，木兰溪上游大济镇，创建“善化里·农文旅”示范片区，成为主题教育一大亮点。

　　地处仙游县城西部的大济镇古称为善化里，是一个历史悠久、人杰地灵的古镇。创建的乡村振兴示范片区，纳入溪口村、溪车村、古濑村、龙坂村、乌石村、西南村六个行政村，总面积约28.17平方公里，总户数8743户。

　　这些村庄主导产业为文旦柚、皮蛋、粮食种植等，村民大多外出经营小吃店或劳务输出等，人均年可支配收入约2.6万元，每年各村集体经济收入约15万元。

　　如何破解乡村振兴同质化发展难题？大济镇立足现状，加强党建引领、开拓创新，确定“创建文旅名镇，打造工艺重镇”发展目标，构建“一心两轴三带四产五民生”布局，打造一种文化、一片产业、一条大道、一个园区等项目，一体推进产业发展、乡村建设与乡村治理，高质量创建莆田市乡村振兴示范片区，促进农业增效、农民增收、农村繁荣。

　　产业联兴，迸发“共富能量”

　　莆永高速大济出口与县道X242仙度路在大济镇溪口村交接。大济镇党委书记林振滔指着高速路口处说，这里将建大济片区小微企业园，建成后将成为国际木材交易中心，引领大众化红木产业快速发展。

　　溪口村是南宋名臣叶颙的故乡。叶颙一生为官清廉、刚正不阿，以“清廉公忠”闻名于世，入《宋史》列传。目前，叶颙文化园项目落地建设，提升建设叶颙文化馆、新建贤母堂、多功能厅、叶氏先贤祠等配套建设。

　　大济素有“宰相故里、状元之乡”美称，历史名人璀璨。林振滔介绍，该镇发挥得天独厚的历史资源，打造大济特色的“廉”文化名片。一期以叶颙廉洁文化为抓手，重点推进廉洁文化公园、叶颙文化馆等五大项目，发扬叶颙廉洁文化。二期深入挖掘郑远、余立丰、郑照、方公衮等廉官史实故事，对郑远故居、余立丰祠、郑照祠堂等人文古迹进行修缮，连点成线。到2025年，创建省级廉洁文化示范基地，让“廉”文化深入人心。

　　大济镇党委把主题教育同强化项目带动、文旅产业发展相结合，积极同企业、学校共建对接。先后邀请福建神旅文化产业集团，华侨大学美术学院、旅游学院调研叶颙宗祠、松坂溪生态公园、三禅寺、宋代龙泉窑遗址等乡村振兴项目，充分挖掘各村居亮点优势，细化文旅产业创建内容。

　　为提升旅游业品质，在原有龙坂双桂岩、乌石天鹅湖的基础上，该镇策划一批文旅项目，对溪口战斗遗址弥峰寨、宋代古刹三禅寺、宋代石桥金马桥、唐朝古刹南林寺等依照原貌修缮提升，对松坂溪、大帽山、溪口国有林场等自然风光进行美化亮化，连点串线全镇景点，打造“红色教育+廉洁文化、自然人文风光深体验、文创+农特产品+研学”一日游等精品旅游线路，绘制大济镇全域旅游一张图。

　　完善设施，提升“幸福指数”

　　要致富，先修路。

　　在大济镇溪古线道路仙游段项目现场，工程车来来往往，施工一片繁忙。

　　施工现场负责人介绍，溪古线道路仙游段总里程约3.7公里，其中新建路线长约3.4公里，采用四级公路标准建设，为水泥混凝土路面。项目建成后将缩短仙游县至泉州永春县路程距离，改善交通出行环境，惠及周边20多万群众，带动周边镇村旅游发展、产业联通、群众致富。

　　增进民生福祉是发展的根本目的。木兰溪支流松坂溪安全生态水系工程，治理河道长度8.21千米，新建生态护岸1.14千米、鱼鳞坝1座、过水汀步2座、保水堰5座，以及防洪堤、溪畔公园、南北广场等公共设施。不仅修复河道生态功能，贯穿水系两岸的生态园道和景观，也进一步改善农村人居环境。

　　以主题教育为契机，大济镇坚定不移走生态优先、绿色低碳、高质量发展之路，扎实推进“蓝天”“碧水”“绿地”三大保卫战，健全人居环境管护长效机制，弘扬乡村生态文化，完善乡村振兴各项基础设施，解决群众急难愁盼，保障创建“善化里·农文旅”示范片区顺利落实落地。

　　教育是最大的民生。大济镇片区内有6所小学、1所九年一贯制学校、1所幼儿园。该镇计划分两期提升片区学校，一期提升硬件设施，配套多媒体设备等教学设施，对宿舍、操场、校道等设施环境进行提升，安装安防监控等；二期与省校共建，邀请优秀教师开展结对交流，让师生通过线上互动学习，共享宝贵经验。

　　针对农村留守老人多问题，大济镇提升改造原有养老院，建设嵌入式养老服务机构。在溪口村养老院项目建设现场，大型机械来回穿梭，工地上处处是忙碌的身影。

　　据介绍，新建养老院按照“四区、八有”标准，新增100张养老床位，配备标准化食堂、餐厅、办公室、会议室、档案室、活动区等功能区。构建“日间照料中心＋养老互助点”片区服务阵地，提供义诊、理疗、理发、精神慰藉等就近养老服务。项目建成后，可辐射周边超过5000人，满足老年人“家门口养老”美好愿景。

　　针对群众普遍关心的就业、教育、医疗、住房等民生问题，该镇通过群众视角找“痛点”，从衣食住行的小事入手，采取有针对性的措施，一件一件抓落实，一个一个解决好，让群众获得感、幸福感、安全感更加充实、更有保障、更可持续。

　　人才联享，凝聚“共享智慧”

　　人才是片区发展的核心动力。

　　大济镇营造良好环境，提供完善的政策支持软环境、良好的人才成长硬环境，想方设法拓宽渠道，吸引优秀人才，激发人才活力，凝聚“共享智慧”。

　　该镇与华侨大学共建，委托华侨大学经济与金融学院、旅游学院、建筑学院、美术学院、工商管理学院、化工学院等6个学院专业师生团队，协助完善6个重点村村庄规划，推进空间规划编制，进一步优化生产、生活、生态空间，促进空间科学有序高效利用。该镇还计划投资300万元，建设电商直播基地人才公寓新楼，为华侨大学等专业团队人才提供科研基地及住宿、办公、学习等场所，服务校地共建项目，推动实现合作共赢。

　　开展特色“田间课堂”，建立蔬菜教学研学实践基地。该镇同党校、企业、机关单位等签订共建协议，结合“田间课堂”开展相关技能培训。提前收集党员、群众需求，邀请相关专家每周定期下乡讲授“田间课程”，针对农民“用得上”“离不开”的果树栽培、中草药种植、粮食高产、电商等专业技术，有效开展农业培训。

　　产业兴旺、生态宜居、乡风文明、治理有效、生活富裕。眼下大济镇正朝着这一目标接续奋斗，力争早日把美好蓝图变成现实，将“善化里·农文旅”片区打造成为宜业、宜居、宜游的品质乡村，通过跨村联建，实现产业、生态、文化、人才、组织全面振兴，书写“绿水青山就是金山银山”的美好答卷。
