仙游书峰乡三产融合打造乡村振兴新引擎

来源:仙游报道 时间：2023-02-21 11:42
| | | |

　　仙游县书峰乡深入贯彻落实省委、市委“深学争优、敢为争先、实干争效”行动部署，强化党建引领，推动枇杷、青黛两大特色产业升级，促进三产融合发展，打造“五福”乡村振兴品牌。

　　春风拂面，书峰乡漫山遍野飘溢着淡淡的枇杷清香，本地枇杷进入成熟期，预计本月底至下月初可上市。

　　地处仙游县西北部的书峰乡素有“枇杷之乡”的美誉，枇杷不仅是当地群众赖以生存的经济果，也寄托着浓浓的乡愁。书峰乡党委政府明确“郊野书峰”发展定位，主动融入北部山区旅游示范带，突出特色产业优势，三产融合，孵化出以福果、福礼、福技、福忆、福地为主题的“五福”乡村振兴品牌。

　　党建引领赋能“五福”

　　书峰乡党委书记张杰介绍，“五福”临门中的“福果”聚焦品牌维护，提升种植技术、改善枇杷品种、延长枇杷果期，实现枇杷价格连年攀升。书峰乡发挥党员模范作用，带动村民精细种植，在育好原有品种的基础上，增加枇杷新品种，推行无农害管理，种出品质果、放心果和致富果。

　　“福礼”聚焦枇杷、青黛产业链拓展和延伸，进一步打响“书峰枇杷水果之乡”“书峰青黛中药之乡”品牌知名度，让游客“有的看、留得下、待得住、带得走、想再来”，优化旅游体验感。党组织牵头联络在外乡贤、企业开展枇杷、青黛等深加工产品的研发，围绕枇杷膏、枇杷饼、枇杷棒棒糖、枇杷罐头以及青黛手工皂等枇杷青黛深加工产品制定规范化标准细则，打造书峰枇杷青黛伴手礼产品。

　　“福技”聚焦青黛打蓝、印染技艺等，丰富产业文化内涵，与旅游、研学相结合，实现技艺推广与经济收入双丰收。由党小组带头，定期邀请专家、农户就青黛种植技术、打蓝工艺进行研究实验，提升书峰打蓝制蓝技艺。

　　“福忆”深入挖掘乡愁记忆，传承红色文化，忆苦思甜，充分展现书峰人民的勤劳、智慧和勇敢，也教育年轻一代珍惜当下来之不易的幸福生活。由党支部牵头，结合红色党建、乡村振兴、产业发展以及非遗文化等元素，改造提升了书峰大类战斗遗址、四黄乡村记忆体验馆、李秀珠故居以及知青文化园等。深入挖掘各景点历史文化底蕴，引进第三方公司运营。结合书峰“二日游”目标和“宿营、研学”两大旅游特色，打造乡村旅游发展样板，使书峰全域游成为游客的美好回忆。

　　“福地”聚焦宜居宜业最美乡村建设，围绕乡村振兴战略总要求，稳步提升书峰枇杷、青黛产业的品牌效应；有序推动乡村基础设施配套建设和生态宜居工程；有力打造新时代文明实践高地，培育文明乡风、良好家风、淳朴民风；有效带动人才回归、项目回牵、资金回流，确保农业稳产增产、农民稳步增收、农村稳定安宁，接续全面推进乡村振兴。

　　张杰表示，该乡将进一步以“两大产业支撑、三产融合发展以及四项行动”为抓手，催生“五福”成效持续提升，奋力建设乡村振兴示范乡镇。

　　提质两大特色产业

　　“枇杷不仅酸甜可口，而且还有清热解暑、润肺止咳的功效……”

　　2月1日，在“深学笃行二十大、党群联建促振兴”公益助农暨枇杷预售活动上，书峰乡党委副书记、乡长李双忠为本乡特色名果代言。

　　当天预售活动现场，18家单位现场认购书峰枇杷，其中早钟6号枇杷礼盒装共认购5500盒，贵妃白枇杷礼盒装共认购2000盒。

　　书峰乡有枇杷园1333.33公顷，种植早钟6号、长虹3号、解放钟、贵妃白等枇杷品种。该乡聘请乡贤、中国园艺协会枇杷分会原会长林顺权教授，莆田学院环境与生物工程学院原院长、枇杷分会副会长吴锦程及其团队作为产业顾问。通过改良现有长虹、解放钟等品种，引进早佳5号等优良品种，延长书峰枇杷成熟果期。

　　为让枇杷在市场销售中抢占先机，书峰乡发展“枇杷现代科学种植”技术。由村集体打造，企业运营，规划建设250公顷枇杷现代产业园，园内建设高品质枇杷种植示范区，枇杷优质苗穗基地、观光采摘基地，配套水肥一体化喷灌、山地轨道运输工具等设备，还搭建1200平方米的温室大棚，能实时监控枇杷生长状况。

　　目前，有3家企业认购3片枇杷林，共约1000棵枇杷树。书峰村党支部书记黄宗建介绍，过去认养枇杷通常是“按棵认养”，如今打破传统模式，实行“企业参与，共同管理”新方式，推出“枇杷树成片认养活动”，企业可将认养的枇杷林作为产业基地，通过线上体验生产种植，亦可参与线下种植管理。

　　该村还通过股经社与企业、枇杷种植专业合作社、枇杷种植户等合作，统一生产标准、果相标准等，提高果农的经济收入。同时，引进福建省艾林生物科技有限公司、浙江台州经销商等枇杷深加工企业，联合开发枇杷酥饼、枇杷果酱等系列产品。

　　前不久，全市首张枇杷叶茶、枇杷花茶的食品生产许可证落户书峰乡兰石村的润芝昌食品有限公司。

　　“特色农产品要想打出品牌，争取市场认可是必不可少的一环。此次枇杷叶茶、枇杷花茶的食品生产许可证核发将助力当地农业产业高质量发展，赋能乡村振兴。”兰石村村委会主任李元权说，该村引进这个农副产品加工项目，采用台湾逢甲大学纳米远红外线烘焙技术，生产枇杷叶茶、枇杷花茶，延伸兰石村枇杷产业链条。

　　青黛，俗称“马兰”，既是染料，也是一味传统中药材。书峰种植青黛历史悠久，品质为福建最佳。该乡不断探索，走出一条青黛“规模化种植、标准化管理、品牌化经营、产业化融通”的发展之路。

　　为激活青黛产业发展活力，书峰乡结合旅游、研学，充分展示青黛传统提炼及扎染文化，把农文旅作为产业振兴的新引擎。提升四黄新村“晒蓝”景观工程，通过乡贤回归、资金回流，建设青黛产业园，邀请专家团队入驻，对青黛种植、轮作、初加工等技艺进行研究，为全乡青黛高质量种植、加工树立标杆和参考。

　　二三产业融合发展

　　当前，书峰乡以旅游、研学为动力，二产深加工产品丰富三产内涵，助推一产转型升级，形成三产融合模式。

　　书峰旅游资源得天独厚。该乡打造“享趣、研学”两大旅游特色。以享趣自然艺术营地为旅游龙头，整合各村景点资源，叫响“乡村旅游+”特色品牌，形成“名贵兰石、传奇百松、休闲锦峰、风情鲤岭、生态书峰、经典四黄”的“一村一品”全域旅游新格局。目前，已聘请专家团队对全乡6个村进行乡村联编，用好各村历史文化资源，建立大学生产学研用融合基地，助力乡村振兴。

　　挖掘自然资源和人文底蕴，推出“书峰二十四景”旅游精品路线。引进峰上研学专业研学团队，开发“传承遗产”“开心田园”“快乐染屋”“难忘乡愁”“多姿舞台”等研学劳动创意课程，年均带动2万人次的学生、游客参与体验。

　　旅游火了、研学旺了，带动二产深加工发展，打开了伴手礼销路。该乡深挖青黛印染文化内涵，打造印染展示馆，推广印染DIY产品，丰富“吃住玩娱购”内容。

　　市非遗青黛扎染传承人黄碧红，曾荣获国家级“乡村文化和旅游能人”荣誉称号。她成立书峰黛乡印染工作室，开通抖音直播间，大力宣传青黛文化、展现扎染非遗魅力，直播间高峰期在线人数达1万余人。

　　进农户、去田间、住农宿、带农货，提振农户发展信心，做强乡村产业集群，推动一产提质增效、转型升级，书峰乡不断积聚乡村振兴发展新势能。
