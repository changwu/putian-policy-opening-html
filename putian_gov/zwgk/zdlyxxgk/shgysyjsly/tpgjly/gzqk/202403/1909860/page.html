沃野春潮涌　“耕”新正当时——荔城区细化任务落实举措推动农业生产“开门红”

来源:湄洲日报 时间：2024-03-22 23:15
| | | |

　　

    在农技人员指导下，黄石镇华中村水稻集中育秧基地采用河泥浆技术播种育秧。

 

　　荔城区农业农村局工作人员到农资经营店了解农资储备情况。

　　30多名党员农技人员一线提供技术服务指导；组织19家种子销售店和51家农药经营门店，备好备足农用物资；提前培训农机手，做好农机调试、保养，推广应用“无人机”等新型农机……荔城区全力抓好春耕生产，保障粮食安全。

　　一年之计在于春，春耕生产正当时。荔城区把握农时、不误农事，早安排、早部署、早谋划，细化目标任务，全力服务好春耕生产，努力实现农业生产“开门红”。全区计划春播早稻、旱粮面积3.52万亩。

　　细化任务 有序推进

　　3月13日，荔城区农业农村局党员农技人员郑碧海来到黄石镇和平村沟边农机合作社种植基地，指导春耕备耕工作。秧苗田里，整畦、施肥、盖膜，忙而有序。

　　今年春耕生产中，沟边农机合作社计划种植早稻面积5000亩。合作社首次使用营养土进行育秧，每亩秧苗田可以节约成本200多元，100亩秧苗田可节约2万多元。

　　“农技人员现场指导，让我进一步了解到营养土农技知识，掌握了科学种植本领，增强了种好地、夺丰产的信心。”沟边农机合作社负责人说道。

　　荔城区农业农村局党组书记局长吴光磊介绍，今年一开春，该局组织30多名党员农技人员，组成服务队，分别深入田间地头，提供技术服务指导，助力春耕生产。

　　农业生产关乎“菜篮子”“米袋子”。荔城区将有关任务细化到镇、村，重点做好化肥、种子、农药等生产资料储备，组织区、镇、村党员农技员深入田间地头，引导村民抢抓农时，抓好春播春种，做好防寒防冻等工作。

　　为进一步提高农民种粮积极性，荔城区农业农村局组织党员干部，广泛宣传强农惠农好政策和春耕生产知识等。印发了《莆田市荔城区农业农村局关于推荐2024年适宜种植粮油作物良种的指导性意见》，为农户推荐水稻、甘薯、玉米、大豆、花生等适宜种植的粮油作物品种。

　　备足农资 调好农机

　　春耕备耕，农资先行。为确保春耕生产开好局、起好步，荔城区提前安排部署，深入调查研究，做好农用物资的储备、调运工作。

　　荔城区组织19家种子销售店和51家农药经营门店，备好备足种子、化肥、农药、农膜等农用物资。据不完全统计，已备供种子15.6万公斤。其中，杂交水稻种子5万公斤，花生种子5万公斤，大豆种子1万公斤，玉米种子0.6万公斤，救灾备荒储备种子4万公斤。

　　如今，机械化作业在农业生产中唱“主角”。为此，荔城区大力推广智能化农机，让耕作“事半功倍”。未雨绸缪，提前培训农机手，做好农机调试、保养，推广应用“无人机”等新型农机，推动播种、植保上“云”用“数”，更好发挥“智慧农业”作用，进一步提高效率，为抓春耕、抢农时赢得时间和主动。

　　3月10日，笔者在荔城区黄石镇的丰隆农机合作社看到，区农业机械管理总站技术人员忙着指导农户做好农机具的保养、调试和维修。连日来，在春耕生产的热潮中，该区农业机械管理总站组织6名党员技术人员，深入农机专业合作社、农户家中，开展技术指导，确保各类农机具以良好的状态迎战春耕生产。

　　荔城区进一步落实农机“不安全、不出门”的要求，组织人员深入乡村开展隐患排查，加强安全宣传，加快变型拖拉机淘汰清零和老旧农机报废更新，提高广大农户和农机手的安全防范意识。

　　随着天气回暖，荔城区各农机专业合作社纷纷开始检修拖拉机、插秧机，为下田作业做好准备。截至目前，共检修农机具2130台，包括插秧机、拖拉机、农用水泵、植保机械等。

　　目前，荔城区农机专业合作社共36家，拥有大中型拖拉机、高性能插秧机、植保机械、联合收割机、粮食烘干机以及配套农机具，全部进入保养维修阶段，3月中旬开始全面播种，预计今年机插播种面积达2.5万亩左右。

　　据了解，今年荔城区首次引进水稻播种精量育秧流水线，不仅可以实现节约种子50%、提高工作效率50%、节约用工成本50%，还可以提高水稻单产5%。此外，还引进植保无人机5架、辅助驾驶插秧机6台，投入今年春耕生产。

　　荔城区加强机具调度，搞好整地工作和适时播种。特别是对一些农时紧、劳动力紧缺的地方，发挥生产性服务组织的作用，开展“代耕代种”“代育代插”等服务，确保播种任务高质量完成。

　　做好服务 全力护航

　　农资直接关系到粮食安全、农产品质量安全和农民的切身利益。为规范农资市场秩序，确保农资买得放心、用得安心，开春以来，荔城区加大对种子、化肥、农药等农资的监管力度，组织党员干部扎实开展“农资打假护春耕”行动，深入各镇街详细了解农资储备情况，全面检查种子、化肥、农药、农膜等经营店的经营资质，仔细查看农资有效期限、标识标签、产品价格等，从严从重查处售假等违法行为，坚决杜绝伪劣农资产品坑农害农现象发生，为春耕生产保驾护航。

　　荔城区结合“三下乡”“学雷锋”等活动，深入基层一线开展形式多样的宣传活动，大力宣传种子法、农药管理条例等相关法律法规，营造诚信经营的浓厚氛围，增强经营主体的守法意识和群众的维权意识。

　　春耕生产期间，荔城区14个供销农资经营点、48家农药经营门店和6所“庄稼医院”均推出了电话、微信等预约购买服务方式，延长营业时间，并提供统一配送服务，全力打通农资采购服务春耕生产的“最后一公里”。“一个电话打过去就会送货上门，非常方便。”黄石镇一家农业合作社负责人说道。

　　荔城区全力做好农资储备、调运、销售等工作，严把质量关，提前采购适销对路农用物资，满足春耕生产多层次、多样化的需求，确保服务到位。同时推行线上订购、线下配送、送货上门等模式，组织专门配送车辆将农资配送到各供销站点，依托惠农服务中心、“庄稼医院”等，为农民提供技术推广等便民服务。供销部门携手农资生产厂家、供应企业，做到品种齐、数量足、质量优、结构合理。

　　连日来，在荔城区黄石镇的田间，许多农户开始浸种，有的拖拉机正在耕田，做好育秧前的准备工作。党员农技人员则奔走在田间，为农民进行现场技术指导，给种粮大户测土配方。

　　“大田有了测土配方，就知道这以后怎么如何施肥了。”走访中，多位种粮大户如是说。

　　原来，在春耕生产之前，许多党员农技人员为农田全面“体检”，分析成分，为科学施肥、保障丰收提供技术支撑。

　　粮食要想夺高产，田间管理是关键。该区党员农技人员现场向农户详细讲解施肥、保水、病虫害防治等知识，指导农户解决种植中遇到的实际问题和困难。为了让农田吃上“营养餐”，该区积极推广应用测土配方施肥技术，指导种植户“增产施肥、经济施肥、环保施肥”，全面提高科学施肥水平，达到“减肥”又“增产”的效果。

　　粮食安全乃“国之大者”。荔城区将坚决贯彻落实习近平总书记关于“三农”工作的重要论述和重要指示精神，按照中央、省委、市委农村工作会议部署，扛牢粮食安全政治责任，聚准方向、落实举措，抓好农业生产各项工作，千方百计把“米袋子”扎得更紧，“菜篮子”拎得更好。
