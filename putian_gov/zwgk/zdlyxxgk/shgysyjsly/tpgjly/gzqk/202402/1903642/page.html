果树茶叶应对持续雨雪天气及灾后管理技术指导意见

来源:农业农村部种植业管理司、全国农业技术推广服务中心 时间：2024-02-08 16:31
| | | |

　　近日，我国中东部遭遇了今冬最强雨雪天气过程，给局部地区水果、茶叶生产带来不利影响，尤其是冻雨对树体和防护设施损伤较大。气象部门预计南方大范围雨雪仍将持续，除夕之后南方将明显回暖。为做好冰冻雨雪天气应对和灾后恢复生产，农业农村部种植业管理司组织全国农业技术推广服务中心、农业农村部果树和茶叶专家指导组、国家柑橘和茶叶产业技术体系，研究制定《果树茶叶应对持续雨雪天气及灾后管理技术指导意见》。

　　一、果树

　　（一）持续做好强降雨雪天气应对

　　1.覆盖。可用薄膜、无纺布、草帘等保温材料覆盖树体，减少树冠与雨雪直接接触，建议采取单株或单行覆盖，利于冻雨从覆盖物顺流而下和积雪清理，以防压垮树体。

　　2.设施加固。加固避雨棚、简易大棚等支撑结构较弱的防护设施，增加支撑密度，以防短时强降雨雪压垮设施结构。垮塌风险较大的设施，应优先保护大棚骨架结构，必要时提前割破薄膜或防护网，减轻顶部载重。

　　3.适时加温。设施内高价值柑橘、草莓等水果，可采用多种措施实施临时加温，短时降雪量较大时，在保障人员安全前提下，及时巡查设施承雪情况，清除过多积雪。此外，可视情况采取熏烟措施，加强果园长波光逆辐射，提高果园温度，减轻低温影响。

　　（二）雨雪灾后及时采取恢复措施

　　1.除雪和土壤管理。大雪或霜冻过后，及时清理树上和树盘下的积雪或霜。及时全园或树盘浅耕松土（切忌伤根），改善土壤通气，促发新根。

　　2.树体管理。已被冻雨影响树体结冰的，不宜强制除冰，以防树体和枝叶二次机械损伤和伤口感染。劈折树枝的伤口进行清理和防护，对折断或冻伤枝条进行修剪、清园和无害化处理。

　　3.及时修剪。尽早摘除受冻萎蔫不能复原或枯焦未落的叶片，在春季升温后截掉受冻枝梢，尽量多保留树冠内部和下部枝梢。对大的剪（锯）口要削平滑、用合适的保护剂保护伤口。对于直接暴露在强烈阳光下的骨干枝，应涂白或绑缚遮阳网防晒。

　　4.肥水管理。气温回升后，按照“勤施、薄施”原则，及时追施2—3次高氮低钾或其他优质商品水溶肥。未落叶的受冻树，及时用0.1%尿素和0.3%—0.5%磷酸二氢钾进行叶面喷肥，间隔15—20天连续喷施2—3次。

　　5.病虫害防治。受冻修剪完毕后要及时清理枯枝落叶进行销毁。及时用石硫合剂、松酯酸钠或矿物油+杀螨剂+杀菌剂+杀虫剂等进行全园彻底消毒，防止病虫为害。新梢抽生过程中，及时喷药防治病虫害、保护新梢。

　　二、茶叶

　　（一）持续做好雨雪冰冻天气应对

　　1.设立风障防护。对于伴随大风的低温天气，可在茶园北面、西面风口处搭建风障，风障材料以稻草帘等为佳，也可使用塑料薄膜、多层遮阳网等材料。

　　2.强化树冠防寒。寒潮来临前，成龄茶园可通过搭架或直接在茶树蓬面上覆盖无纺布、编织袋、薄膜或遮阳网等材料，也可就地取材用稻草、作物秸秆、松枝等覆盖。注意寒潮结束后尽快移除覆盖物。

　　3.做好行间铺草。根据当地条件，用稻草、麦秆、豆秸、油菜秆、绿肥、麦壳、豆壳、菜籽壳、落叶、树皮、木屑或野草等覆盖茶行土壤，覆盖物厚度一般应达10cm以上，以不露土为宜。

　　4.加强厂房管理。茶叶加工厂要切实树立安全意识，遇雨雪天气要加强巡查，厂房特别是简易厂房屋顶出现较厚积雪的应立即组织清除，下暴雪时应随下随扫，防止厂房垮塌。

　　（二）加强灾后茶园管理

　　1.及时清除树冠积雪。在积雪融化前，及时清除树冠面上积雪，防止积雪压断生产枝和已发芽枝条或造成冻害。可用吹雪机吹除或扫帚、树枝侧面敲打等方式清除树冠积雪，或气温高于0度时，利用喷灌设备冲洗积雪。

　　2.适时进行修剪。待气温回升后，对于受冻严重的茶树，可在枯死部位以下1—2cm处将已枯死的枝条剪去，为新芽萌发做准备。

　　3.加强养分供应。受到冰雪危害的茶树应加强土壤养分管理，应早施春季催芽肥，成龄生产茶园每亩施用10—20公斤18-8-12（N-P2O5-K2O）配方的茶树专用复合肥，幼龄茶园每亩施用5—10公斤15-15-15（N-P2O5-K2O）配方的复合肥，并可配合施用叶面肥。对于根系受冻茶树，可在新发枝上叶片成熟后进行根外追肥。气温回升后，及时中耕除草改善土壤透气状况，增强茶树根系吸收活力。
