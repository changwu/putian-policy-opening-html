莆田市秀屿区人民政府 湄洲岛国家旅游度假区管理委员会 莆田市住房和城乡建设局 莆田市文化和旅游局关于湄洲岛全域历史文化遗产普查认定结果的公示

来源:莆田市文旅局 时间：2022-06-12 09:06
| | | |
 广大市民朋友们：

为进一步加强我市历史文化遗产保护，湄洲岛管委会组织开展了湄洲岛全域历史文化遗产普查，经现场踏勘、征求意见、专家评估认定，拟推荐9处为历史建筑、21处为传统风貌建筑、11处为历史环境要素、22处为一般建筑。现根据《中华人民共和国文物保护法》《福建省历史文化名城名镇名村和传统村落保护条例》等法律法规有关规定，将以上普查认定情况进行公示，征求公众意见，欢迎广大市民朋友积极参与监督。

公示时间为2022年6月13日至2022年6月19日止。

在公示期限内，市民若有意见，可来电或来信反映。

来信请邮寄：湄洲岛国家旅游度假区建设交通局（收），邮政编码351154。联系电话：0594-5092776。
