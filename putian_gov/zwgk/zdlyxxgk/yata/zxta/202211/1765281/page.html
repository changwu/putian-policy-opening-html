莆田市农业农村局关于市政协八届一次会议第2022016号提案办理情况的答复

来源:莆田市农业农村局 时间：2022-07-28 00:13
| | | |

林玉燕委员：

你提出的《关于快速振兴我市乡村产业对策建议的提案》（2022016号）已收悉，现将办理情况函复如下：

　　一、乡村产业发展有龙头带动

　　（一）壮大发展龙头企业

一是持续实施市级龙头企业培育工程。2021年3月10日，印发《关于组织申报新一轮莆田市农业产业化市级龙头企业的通知》（莆委农办〔2021〕8号），组织各县区开展新一轮莆田市农业产业化市级龙头企业评定工作。二是培育国家级、省级龙头企业。鼓励农业企业做强做大，支持农业企业申报国家级、省级农业产业化龙头企业，对当年度新获得国家级、省级的农业产业化龙头企业，一次性分别给予奖励20万元、5万元。2022年6月，推荐福建金溪茶叶有限公司和莆田市海发水产开发有限公司等2家企业申报第十次农业产业化国家重点龙头企业递补。截至目前，我市市级及以上农业产业化龙头企业154家，其中：国家级3家，省级49家，市级102家。三是扶持农业“白名单”企业。建立农业企业“白名单”滚动认定制度，公布农业“白名单”企业2批次79家，取消农业“白名单”企业1批次1家。

　　（二）培育农业产业化联合体

充分发挥龙头企业的牵头引领作用，引导龙头企业与合作社、家庭农场等组织农业产业化联合体，带动小农户发展现代农业。组织各县区开展农业产业化联合体培育情况摸底、财政资金项目储备申报和拟补助农业产业化联合体情况核实等工作，推荐莆田宏耕枇杷产业联合体申报2021年福建省农业产业化联合体补助项目。截止目前，我市共有省级农业产业化联合体8家。

　　二、乡村产业发展有融合互动

　　用工业化理念发展农业、用先进适用技术提升农业、用现代经营方式拓展农业，形成“一产接二连三”的互动融合发展模式，促进传统农业向现代特色农业转变，助推产业转型升级。

　　（一）发展农产品产地初加工

　　支持新型农业经营主体新建或改造农产品产地初加工中心，优先扶持农民专业合作社和家庭农场建设蔬菜、水果、食用菌、茶叶、粮食等主要农产品产地初加工中心，减少产后损失，提升产业效益。2019年以来，共建设并完成验收农产品产地初加工中心51个。2022年，计划完成新建或改造农产品产地初加工中心10个。

（二）推进休闲农业发展

提升休闲农业档次，推动我市休闲农业的品牌升级，我局积极动员各县区申报美丽休闲乡村，组织经营主体申报全国、全省休闲农业示范点。2021年仙游县石苍乡济川村获评2021年度中国美丽休闲乡村（国家级），涵江区白塘镇双福村等3个乡村获评福建省美丽休闲乡村、仙游县金湖格生态茶庄园等2家农业主体获评省级休闲农业示范点。

（三）产业发展新兴业态

积极推进直播新业态助力乡村振兴，拓宽农产品“上行”渠道。涵江区庄边镇萍湖村、城厢区常太镇等地组织开展“云端枇杷节”活动，通过“平台基地直采+直播带货”的方式，推动农村特色产业发展，把枇杷通过“零接触式”配送到全国各地消费者手里，从而提升枇杷品牌价值，推动农村特色产业发展。荔城区“靠莆生活”电商直播平台携手各平台网站通过线上、线下方式，帮助西天尾九华基地销售枇杷约五万斤、帮助澄渚北大果农销售荔枝约六万斤、帮助西天尾镇象峰村果农销售龙眼约十万斤等。仙游县与京东、抖音等电商平台签订电子商务人才引进培养框架协议，实施“带货网红主播培训计划”“村播计划”。荔城区开展“农产品电子商务培训班”等电商培训课堂，提升涉农电商群体创业能力，更好服务“三农”，为乡村振兴助力。

三、乡村产业发展有育人举措

　　（一）组织实施新型职业农民培育工程

2016年开始，我市启动实施新型职业农民培育工程，对从事或有意愿从事农业生产、经营和服务的务农农民和返乡入乡创新创业者，以提升农民生产经营水平和综合素质为目标，按照“市抓特色培训、县抓产业培训”的工作思路，扎实推进分层培训,促进农民创新创业。截止2021年，中央和省级财政累计安排补助资金3203万元支持新型职业农民培育，全市培训新型职业农民近2万人。2022年全市计划新增培训高素质农民8500人次。

（二）抓好新型职业农民素质提升工程

　　根据省委一号文件精神，2013年开始，我市组织实施新型职业农民素质提升工程。每年选送一批青壮年农民和有志从事农业生产经营的农村高中毕业生、返乡农民工、退役士兵等，参加专科学历教育和农业职业技能培训。截止2021年，共累计选送993人参加福建农林大学、福建农业职业技术学院、厦门海洋职业技术学院等院校新型职业农民专科学历教育班学习，对录取的学员免学费、免杂费、免书本费、免农业职业资格证书报名考试费。集中学习期间免住宿费，并给予一定的生活费用补助。

　　四、乡村产业发展有科技支撑

（一）开展科技服务，推行科技特派员制度

积极探索科技人才服务农业农村发展的新途径、新方法，创新科技特派员工作机制，把科技特派员联系协调工作直接延伸到农村基层，形成区乡一体、上下联动、左右贯通的组织管理体系。2022年，推荐省级个人科技特派员230名，团队科技特派员43家，法人科技特派员2家；选认市级科技特派员236名。依托莆田市乡村振兴综合服务平台（壶兰乡村），建设“莆田市科技特派员服务平台”，至目前，平台总访问量达31000多人次，制作农技培训视频98条，展示成果37项，注册科特派专家500多人。平台实现了科技特派员在线管理、科技信息线上发布、农业技术线上指导等功能，提高科特派管理效率和服务质量。

（二）深化产学研融合，赋能产业转型升级

推动校地合作取得突破。建立产学研合作机制，推进福建师范大学、集美大学、江夏学院设立产学研合作办公室，集聚更多科研人才，促进更多科研成果在莆落地转化。加强与厦门大学、集美大学、福州大学等省内高校开展产业技术合作，拓展在科技特派员工作站、创新创业基地、产业研究院等方面开展产学研深度合作。去年以来，集美大学领导和专家4批24人次来莆调研指导我市农业类科技型企业，与企业多次召开座谈会进行技术对接。集美大学在我市开展牡蛎壳粉土壤调理剂示范试验，我市有7家企事业单位参与。市农科所开展的《牡蛎壳粉土壤调理剂在蔬菜栽培中的应用研究》项目，已取得较好成效，为下一步我市推广应用该科研成果提供科研技术基础。

（三）组织开展“农业专家八闽行”活动

自2019年起，农业系统持续开展“科技助力乡村振兴千万行动”“农业专家八闽行”等活动。2022年从市、县两级农业系统中选派73名中级职称以上农业专家，深入农业生产一线，通过科技项目的桥梁和纽带作用，在我市农业主产区，针对当地农业产业特点，对接服务50个镇、146个行政村，为企业及有需求村点对点、面对面解决农业生产问题，加快农业五新推广应用。2022年截止6月份，对接服务的经营和服务主体数量220个，建立科技示范基地数量 34个，推广农业“五新”数量72项（次），科技示范带动人数2355个，培训15期473人次，技术咨询服务1002人次，发放各项技术资料4365份，通过以点带面，扩大辐射，提高我市农业生产的科技水平，促进我市农业稳定发展、农民持续增收。　　

（四）推进科技特派员服务农村基层活动

　　积极推动科技特派员服务农村基层，为农村引进实用新技术和农业新品种，开发农业科技新项目，建立农业科技示范基地，推动科技与经济、科技人员与农户和基层经济组织的结合，促进了农业和农村经济的发展。持续落实科技特派员制度，2021年，我市共有220名个人科技特派员、5家法人科技特派员和33组团队科技特派员被认定为省级科技特派员，236名科技特派员被认定为市级特派员。其中农业系统我局省级科技特派员原瑞芬2021年被评为莆田市优秀科技特派员，带领团队远赴新疆，在新疆建立莆田农业援疆示范基地，开展南果北种等科技成果推广，成绩斐然。

五、乡村产业发展有品牌培育

　　（一）“三品一标”稳步发展

一是认证数量不断增加。截至目前，全市通过 “三品一标”认定认证产品共35个，其中：绿色食品15个（新增14个），无公害农产品20个（新增15个）。新培育“三标一品”农产品29个。二是奖励政策有效落实。3月28日，联合市财政局下达2022年度质量认证和品牌建设奖励资金144万元，其中：仙游县85万元，荔城区8万元、城厢区13万元、涵江区14万元、秀屿区23万元，北岸1万元。三是宣传活动有序推进。6月16日，组织3家绿色食品生产经营主体前往福州参加2022年度全国绿色食品宣传月福州站活动，参与线下展销和线上直播，介绍并展示我市部分特色优质绿色食品。　　

（二）农业品牌有序发展

2022年4月，我市共有3家企业、3个产品获得“福建名牌农产品”授牌和荣誉证书，其中：莆田市中天现代农业发展有限公司的“中闽中天牌胡萝卜”产品荣获“2021年度福建名牌农产品”，福建金溪茶业有限公司的“仙溪乌龙茶”和福建省仙游县度尾仙溪果业专业合作社的“仙溪文旦柚”产品通过“2018年度福建名牌农产品”复评。

六、乡村产业发展有信息助力

积极推进信息进村入户工程建设，构建乡村电商服务体系。截至目前，已建成1个市级运营中心、5个县级运营中心、8个邻里中心、658个村级益农信息社，并同步选聘信息员。在益农信息社建设过程中，通过加强同电信、邮政储蓄、农商行等部门的合作，利用这些单位的村居业务点、普惠金融点等资源，实现资源整合、共建共享，推动农村基层服务站点联合挂牌，形成市、县、村上下联动、涉农部门共同推动的良好局面。截止目前，我市依托益农信息社或平台开展的电子商务累计成交额达1763.31万元。
