关于市政协八届一次会议第2022113号提案办理情况的答复

来源:莆田市文化和旅游局 时间：2022-07-14 15:35
| | | |
 陈暄：

你提出的《以建设研学旅游基地为抓手，加快莆田活化历史文化保护利用的建议》（2022113号）已收悉，现将办理情况函复如下：

近年来，研学旅行作为一种崭新的旅行方式逐渐进入公众视野，越来越受人们关注。莆田作为闽中文化名城，历史悠久，文化灿烂，素有“文献名邦”“海滨邹鲁”之美誉。莆田旅游资源丰富，域内山海兼备，自然风光甜美秀丽、人文古迹厚重辉煌、工艺美术精湛卓越、妈祖文化独占鳌头。旅游资源八大主类莆田基本都有，155种旅游资源类型莆田具备90多种。全市现有国家旅游度假区1个，国家A旅游景区42家，国家森林公园1个、全国水利风景区2个，世界非物质文化遗产1个、国家非物质文化遗产2个、全国重点文物保护单位7处，发展研学旅行基础条件成熟。

一、关于加强组织领导，完善制度保障机制的建议

我局积极配合市教育局编制出台《莆田市研学教育实践规划2019-2025》，明确研学旅行垢指导思想、发展目标、发展战略，为推动莆田市研学旅行提供了决策依据。并配合教育部门先后制定出台《关于推进全市中小学生研学旅行工作的实施意见》《关于推进全市中小学生研学实践教育工作的通知》《关于印发〈莆田市研学实践教育发展规划（2019-2025年）〉的通知》等意见措施，进一步完善研学旅行社会组织参与的规范标准、准入资格制度、税收优惠、政策扶持等，鼓励积极参与研学旅行活动。举办“莆田市中小学研学实践教育工作推进会”，各县区教育、文旅部门及部分中小学校长代表参加了会议，会上邀请专家解读中小学研学实践教育政策，指导研学旅行发展和创建培育。大力支持研学旅行示范基地培育项目建设，鼓励支持具有条件的景区发展研学旅行，对九龙谷、中旅逸林被评为第二批福建省中小学生研学实践教育基地营地，争取省级文旅融合发展补助资金各30万元。

下一步，我局将进一步支持配合教育部门做好遴选莆田市研学实践教育工作指导专家库建设，发展培养一批本土优秀的研学实践教育方面的专家，指导推动我市中小学研学实践教育工作全面均衡发展。同时，根据《关于开展莆田市中小学生研学实践教育基地申报工作的通知》精神，继续支持指导打造研学旅行示范基地培育项目，根据莆田自然和文化旅游资源，遴选推荐一批安全适宜的中小学生研学旅行基地，指导研学旅行基地创建培育工作，打造一批示范性研学旅行精品线路，并积极推荐申报省级旅游专项资金补助。

二、关于充分挖掘地方资源，建设综合实践基地的建议

我市充分发挥文化遗产资源，建立文化交流基地和群众益智场所，为民生改善和经济发展服务。一是利用元妙观三清殿、古谯楼、翁氏民居等作为莆阳书房、书院、莆仙戏传习所，以及绘画、摄影等作品展览场所，作为弘扬传承优秀传统文化的中心。二是利用仙游文庙、涵江江氏民居、澳柄宫革命旧址、陈国柱故居、珠江林氏宗祠、英田林氏宗祠、南日岛烈士纪念碑等文保单位开辟为爱国主义和廉政教育基地，挖掘整理历代人文典故，弘扬历代先贤的先进事迹和爱国爱乡的崇高精神。三是利用涵江区“九祖大厝”“关永光宅”“万发大厝”等活化利用为家风家训馆。四是利用汀港特色民居建设汀港民俗馆，展示汀港村的风土人情，展现农耕文明向现代农业文明转变的历史节点。

三、关于打造具有“本土特色”的体系化研学实践课程的建议

你提出“深入挖掘生态、历史、文化、地理、红色、方言、科技、美丽乡村等特色资源，打造出贴切生活的研学实践课程”的建议，对学生来说，可以亲近自然、锻炼动手能力、学习传统非遗工艺，学到课本以外的知识和技能。对学校而言，既拓展了教学空间、丰富了教学内容，也让老师和学生一起走进乡村社会、走进自然，真正实现了学校、家庭、社会三位一体的教学。同时，研学活动也带动乡村文旅，更好传承了我市非遗传统文化，达到多方共赢。

为助力我市乡村振兴，践行研学教育。一是湄洲湾职业技术学院研学旅行管理与服务专业学生自主设计的“玉米少年在行动”研学活动走进秀屿区东庄妈祖文化生态园，四十余名小学生参加，通过实地采摘玉米，制作玉米果冻，品尝玉米等环节，提高学生动手能力，让他们感受劳动的辛苦、收获的喜悦，从而更加珍惜粮食。组织学生走进田厝村，该村是莆田传统手工线面加工的专业村，让学生现场感受田厝村的历史人文，体验传统手工线面制作，并结合田厝村旅游资源开发研学线路。二是莆田中国旅行社积极开发研学旅行产品，研发出涵盖小学至初中总共5套成系列的莆田地方文化研学主题课程，自然科学、户外生存、劳动实践等研学课程开发日趋完善，共服务莆田城区与各县区中小学生1万多人次，收获良好的社会口碑与反响；先后与市群众艺术馆一起完成民俗文化夏令营部分研学课程，承办莆田市综合文化站站长培训会议非遗研学课程观摩活动、“舌尖上的莆阳”莆田市非遗食品节活动、莆田市“匠心传承”竹艺文化嘉年华等非遗研学活动，取得明显成效。

四、关于加强对研学实践人才的规范性培养的建议

研学旅行是“旅游+”概念下的新模式。它延续和发展了古代游学“读万卷书，行万里路”的教育理念和人文精神，成为素质教育的新方式。当下研学旅游市场火热，研学旅行已然成为各地旅游发展创新增长点，但专业人才稀缺。2020年，湄洲湾职业技术学院研学旅行管理与服务专业成立，是全国首批开设该专业的32所院校之一，也是福建省首批研学1+X证书制度试点及考点。依托校内外实训基地，构建工学交替，院企共建，一专多能的“2+1”的人才培养模式。专业课程主要开设有研学旅行课程开发、研学旅行市场营销、中小学生认知与学习、研学旅行资源学、研学项目策划设计、研学旅行计调实务、研学旅行政策法规、研学旅行文化创意、研学旅行教育与引导、研学旅行安全管理、研学旅行线路设计、研学旅行营地规划与设计、研学旅行服务语言艺术等。截至2022年6月已成功申报福建省唯一的省级研学专业教学资源库，建设并在智慧职教上开课的精品课程有5门，在建精品课程4门。现有在校生173人：2020级91人，2021级82人。学生素质良好，曾参加2020年导游技能省级职业技能大赛，荣获三等奖1项；2021年导游技能省级职业技能大赛，荣获二等奖1项，三等奖1项，餐厅服务省级技能大赛获团队优秀奖；2021年湄洲湾职业技术学院第七届中国国际“互联网+”大学生创新创业大赛校级决赛铜奖1项，2022年湄洲湾职业技术学院第八届中国国际“互联网+”大学生创新创业大赛校级决赛金奖1项。2020年12月，首届学生参加全国首批研学旅行策划与管理（EEPM初级）专业1+X考证，考证通过率高达98.3%。目前，已有不少学生与我市旅行社、研学机构签约，就业前景良好。

今年，湄洲湾职业技术学院研学旅行管理与服务专业组织91名学生先后前往东大村研学实践基地、207团革命旧址、白沙镇田厝村、百威啤酒博物馆省级研学实践基地、儒意研学基地等地开展实训活动，内容涵盖了传统文化、革命传统、国情教育、自然生态、国防科工、劳动教育等6大板块，全方位提高学生研学旅行服务与管理的理论素养和实操技能。通过这个实践，通过到企业、下企业，由企业的导师负责给学生讲解、指导、示范，学生可以从中感受到这个职业的岗位能力需求，职业要求规范等，为今后更好地适应企业的岗位要求，还有企业的要求，适应社会，适应市场。莆田中国旅行社积极组织导游人员参加研学旅行辅导师培训，目前已经有8人获得研学辅导师资格。下一步我局将加强与湄洲湾职业技术学院沟通协调，研究探索我市导游研学业务培训和“学校+社会”的研学实践课题，以研学带动相关文旅产业发展，促进文旅经济的发展。
