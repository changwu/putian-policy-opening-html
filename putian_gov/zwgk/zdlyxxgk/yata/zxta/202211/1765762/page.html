关于市政协八届一次会议第2022132号提案办理情况的答复

来源:莆田市海洋与渔业局 时间：2022-08-01 17:30
| | | |

韩仙宝委员：

你提出的“大力提升水产立体养殖科技水平、助推我市现代化渔业高质量发展”（2022132号）已收悉，我局分办意见如下：

一、关于大力推广生态立体高效养殖模式

海洋渔业部门深入贯彻落实习近平“两山”理念，按照市委、市政府的决策部署，坚持生态优先、绿色发展，按照合理分工、集聚发展、发挥优势的原则，重点建设南日岛现代海洋渔业产业发展示范区、后海现代渔业产业园区、平海湾生态渔业集聚区、湄洲岛休闲渔业产业园区等四个海洋渔业集聚区。我局研究制定《2022年莆田市水产绿色健康养殖技术推广“五大行动”实施方案》（莆海渔〔2022〕23号），结合实际，推广适合我市的生态健康养殖技术4项（多营养层级综合养殖、工厂化循环水养殖、深水抗风浪网箱养殖和离岸大型设施化养殖），养殖尾水治理模式6项（人工湿地尾水处理技术模式、工厂化循环水处理技术模式、池塘底排污尾水处理技术模式、海水高位池养殖尾水综合处理技术模式、池塘工程化循环水尾水治理模式和连片池塘养殖尾水治理技术模式）；坚持以防为主、防治结合的原则，争取在骨干基地实现水产养殖用兽药使用量同比减少5%以上，抗生素类兽药使用量同比减少10%以上。开展水产绿色健康养殖“五大行动”，加大水产养殖投入品监管力度，加强水产养殖精准减量规范用药指导和专业技术人员培训，推进养殖尾水深度治理，有效改善渔业养殖生态。海洋渔业部门与龙源风电合作，在南日东北侧海域风电区开展贝藻类多层立体化生态养殖；在福建省鸿康水产科技有限公司开展“可控生态水产精养新技术”试点应用；按照“因地制宜、一企一策”原则，采用沉淀池、生物净化、沙石滤坝等治理措施，实现木兰溪流域100家水产养殖场尾水全部达标排放；推进建设工厂化循环水养殖模式项目2个；标准化池塘改造面积105亩；试点推广红鳌虾稻虾综合种养150亩。

二、关于积极打造现代渔业种业体系

我局扎实推进第一次全国水产种质资源普查工作，印发《莆田市开展第一次全国水产养殖种质资源普查工作方案（2021-2023年）》（莆农综〔2021〕71号），普查主体305个，完成率100%。我市海洋渔业部门加强“四大贝苗”以及对虾、海带、紫菜、龙须菜等本地优质种源保护和利用，加大三倍体牡蛎（生蚝）、真蛸等水产新品种繁育技术研发和产业化养殖技术攻关，推进水产苗种繁育与种业创新工程；支持秀屿区平海湾海丝双壳贝类苗种繁育基地、城厢区“北苗南育”苗种基地、书峰贝类工厂化繁育基地等项目建设。积极遴选推介水产优良品种、组织骨干基地开展良种良法技术集成和水产新品种（系）试验示范推广，推动水产优良品种的推广普及；支持鲍鱼、花蛤、牡蛎、仿刺参和淡水名优养殖品种等种业创新与产业化工程建设，培育水产种业龙头企业；应用省水产苗种产地检疫电子出证系统，助力水产种业创新工程；开展养殖主导品种选育、水生动物重大疫病防控、健康养殖等关键技术联合攻关，建设一批育繁推一体化良种繁育基地，逐步打造我市现代渔业种业体系；完成省级原良种场规模种业基地建设项目5个、省级特种水产苗种基地项目1个、市级特种水产苗种基地项目1个；在北岸罗屿、秀屿筶杯海域建设牡蛎3倍体养殖繁育基地2个；出台《2022年莆田市市级水产良种场资格认定工作实施方案》，组织市级水产原良种场评定工作。

三、关于科学引导发展湾外养殖

我局严格落实《莆田市养殖水域滩涂规划（2018-2030年）》制度，进一步优化水产养殖空间布局，扎实推进莆田市海上养殖转型升级行动，利用两年时间（2021-2022年）完成泡沫浮球、老旧渔排更新改造，应用推广全塑胶养殖网箱、深水抗大网箱等新型环保型养殖设施和大型智能型养殖装备，计划投入资金7亿元以上，改造建设渔排3.8万口以上，改造筏式吊养浮球海域面积5.7万亩以上，新建深水大网箱100口以上，建设完成生态养殖网箱平台项目5个以上，争取引进深远海养殖平台1组以上，以南日岛周边海域为重点打造海洋牧场立体生态养殖示范基地。制定相关扶持政策，引导养殖由近海向远海、由湾内向湾外、由浅海向深海发展，逐步实现水产养殖蓝色转变。截至目前，全市筏式吊养浮球已改造海域面积5.57万亩，占全市总任务的93.3%；建设环保型塑胶渔排2.84万口，占全市总任务的74.74%；新建深水大网箱57口，占全市总任务的57%。同时，已清退拆除老旧渔排设施近2万口、筏式吊养浮球4.79万亩。

四、关于推进海洋水产加工产业转型升级

海洋渔业部门持续推进水产加工业优化升级，支持水产加工企业增资扩产，上新线、出精品，加大产品研发和品牌创建，深度推进鲍鱼、对虾、花蛤、海带等水产品的精深加工。遴选培育领军型水产加工企业，鼓励企业进园区，推动产业集群化、规模化发展，积极打造水产加工产业县。组织渔业企业参加福州渔博会、厦门“9·8”投洽会、“宁夏特色农产品展销会”等各类展会，加大我市渔业品牌宣传推介力度。推进水产品现代冷链物流体系建设，开展以海洋生物蛋白、多糖多肽及其衍生物、海洋天然及合成小分子、海洋中药（复方）等具有自主知识产权、市场前景广阔的海洋创新药物和生物制品为重点的研发和应用项目建设，拓展网上物流配送平台和电子商务平台。2020年，市海渔局与市财政联文下达县区省级渔业结构调整专项资金共150万元，完成先进水产品加工生产线建设3条；扶持福建海岸上贸易有限公司水产加工冷链物流工程（厂房及配套设施建设）项目，已建成集水产品冷冻、加工、批发电子配送于一体的综合工程，实际完成总投资1613.59万元。2021年，全市引进水产加工新设备、自动生产线或智能生产线5台/条，培育市级以上产业化龙头企业10家，创建渔业品牌2个。2022年，下达资金255万元，支持秀屿、涵江建设水产品冷藏保鲜设施、设备8台套以上。

五、关于切实加大立体生态养殖政策扶持力度

海洋渔业部门将全面梳理、系统分析全国现有渔业发展政策，按照渔业供给侧结构性改革的要求，制定现代渔业扶持政策，加快淘汰落后产能、资源破坏性生产方式，培育渔业发展新动能，不断拓展产业链中下游及消费市场，加快渔业转型升级。组织渔业科研技术人员与渔企开展“1+N”挂钩服务，加强技术指导帮扶和科研成果推广应用。积极争取中央、省级财政资金，统筹市、县财政资金配套，协调金融机构支持，拓展渔业保险险种，加大金融保险扶持力度。充分利用市财政现代渔业发展专项资金，大力支持海上养殖生态治理、养殖垃圾整治、设施渔业升级改造、渔业品牌创建以及水产品精深加工等方面建设。鼓励企业自主发展的同时予以一定的资金补助，减轻企业压力和负担，引导企业向规范化、规模化、集群化方向转型升级，推动现代渔业绿色高质量发展。

感谢你对海洋渔业发展的关心和支持，在下一步工作中，我局将认真落实“三提三效”要求，务实作风、夯实基础，发挥龙头企业引领带动作用，大力推进科技成果应用转化，培育“繁育推”一体化良种繁育基地，发展深远海养殖，推动产业集群化规模化发展，打造我市现代渔业发展高质量新格局。
