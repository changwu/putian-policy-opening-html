莆田市农业农村局关于市政协八届一次会议第2022006号提案办理情况的答复

来源:莆田市农业农村局 时间：2022-07-20 23:37
| | | |

农工党莆田市委会：

你们提出的《关于健全村级人才培育机制助推乡村振兴的建议的提案》（2022006号）已收悉，现将办理情况函复如下：

    一、健全新型村级治理人才培育

近年来，我市坚持抓党建促乡村振兴，深入推进巩固拓展脱贫攻坚成果同乡村振兴有效衔接，持续加强乡村人才队伍建设，全方位培养、引进、用好人才，为助推乡村振兴提供坚强组织保障和智力支撑。

（一）选优配强干部队伍。坚持把选优配强村级组织“带头人”队伍作为乡村振兴的重要支撑，结合村（社区）“两委”换届选举，通过好中选优“留”一批、就地取材“选”一批、广开门路“引”一批、因地制宜“派”一批等方式，1363名致富能手、634名大学毕业生、286名退役军人、1140名外出务工经商返乡人员进入党组织班子，班子结构优化，整体功能增强。持续选派215名第六批驻村第一书记，通过高位嫁接将机关企事业单位的理念、资源、政策、要素等精准导入农村，助推乡村振兴高质量发展。

（二）多元培育乡村人才。实施“智汇乡村”专家人才服务乡村振兴行动，共组织专家人才服务基层817人次。大力发展职业教育，引进东软等国内知名教育集团落地办学，与东软教育、四川希望教育集团签署职业教育合作办学协议，东软现代产业学院首次招生1360名，着力发展一批本土人才。创新“高校+村党支部”模式，从莆田学院选派14个乡村规划服务队伍开展挂钩合作，建成22个科技特派员工作站，选派省、市科技特派员514名，助力乡村振兴。加强农村实用人才培育力度，开展新型职业农民培训，着力培育一批爱农业、懂技术、善经营的新型职业农民，为乡村振兴注入“新鲜血液”。

（三）强化激励管理。强化政治激励，对示范作用好、带富能力强、群众认可度高的乡村人才，优先纳入发展党员、村级后备干部培养和评优推优对象。完善乡村人才政策激励机制，如仙游县针对符合条件的新型职业农民，选送到大中专院校进行系统的学习培训，免费参加各类技术培训。扶持自主创业，对首次创办企业的高校毕业生、就业困难人员、返乡创业人员等给予5000-10000元的一次性创业补贴。开展创业资助项目评选，对市级优秀创业项目给予3-10万元资助。

下一步，我市将坚持抓党建促乡村振兴，持续加强乡村人才队伍建设，创新培养机制、完善服务体系、健全激励保障，为全面推进乡村振兴提供坚强组织保证和干部人才支持。

    二、强化新型职业农民培育

（一）大力开展高素质农民培训。2016年开始，我市启动实施新型职业农民培育工程，对从事或有意愿从事农业生产、经营和服务的务农农民和返乡入乡创新创业者，以提升农民生产经营水平和综合素质为目标，按照“市抓特色培训、县抓产业培训”的工作思路，扎实推进分层培训,促进农民创新创业。截止2021年，中央和省级财政累计安排补助资金3203万元支持新型职业农民培育，全市培训新型职业农民近2万人。2022年全市计划新增培训高素质农民8500人次。

（二）加强调查，选准培育对象。我市高度重视农民培训需求摸底调研工作，组织各县区积极做好农民需求的对接，以县区为单位对辖区内培育对象进行调查摸底，摸清县区内有意愿参加培训的农民底数及需求，并根据需求分层分类开展培训。

（三）制定方案，明确培训内容。按照省厅高素质农民培训项目实施方案要求，统筹制定我市高素质农民培训项目实施方案，结合我市现代农业发展的特点和农民的需求，确定培训内容、设计培训课程，创新培训方式，明确具体要求。

（四）提高效果，创新培训方式。我市积极推行灵活有效的高素质农民培训方式，努力提高培训质量和效率。采用课堂理论授课学习、线上学习、基地观摩、实习实训等培训方式提升培训效果，在培训过程中，各地组织农民学员到现代农业园区、农业企业、家庭农场、农民合作社等基地实操演练、观摩交流，帮助农民学员拓展视野、转变发展观念、提升能力水平，取得良好效果。这些好经验、好做法分别在福建日报、莆田电视台、湄洲日报、中国网 海峡频道、中国农业信息网、中国三农网等主流媒体宣传报道，也极大提高了广大农民参与培训的积极性和主动性，营造全社会重视支持高素质农民培育的良好氛围。

三、加强乡村专业人才培育

（一）加快乡村医生培养

近年，市卫健委认真落实市委、市政府工作部署，多措并举推动乡村医学人才培育和保障机制建立健全，乡村医生紧缺问题得到有效缓解，有关情况如下：

一是实施乡村医学人才定向培养。2012年起，我市率先采取“订单定向”方式，委托莆田卫生学校每年培养100余名农村医学专业中专生，培养期三年。截至2021年底，全市共培养928人，为乡村医学队伍输送一批“新鲜血液”。

二是实施乡村医生培训提升工作。2005年起，每年委托莆田卫校和仙游县卫生进修学校乡医培训点，采取集中面授、远程教学和临床跟班相结合的方式，对全市1500余名乡村医生开展规范化培训，保证乡村医生每年至少接受不少于两周的免费培训，进一步提升服务能力。同时，鼓励乡村医生学历提升，支持50岁以下在岗中专及以下学历村医参加学历提升教育，对取得“中职升高职”毕业证书的乡村医生，可参照人社部门“见证补助”方式申请学费补助。

三是落实乡村诊所医生工作补助。全市所有行政村卫生所全面配备使用国家基本药物，逐步推行药品零差率销售改革，按服务人口数人均8元的标准，落实村卫生所基本药物零差率销售专项补助，市财政每年补助约125万。在保证每位乡村医生每月100元政策补助津贴足额发放的基础上，按照权责一致的原则，将基本公共卫生服务项目40％左右的工作量下移给村卫生所承担，并从基本公共卫生服务经费中预留相应的经费专项用于乡村医生服务补助，经绩效考核后下发，市财政每年下达省市补助资金220万元。2009年开展基本公共卫生服务以来，各级财政投入了补助资金约14.6亿元，统筹用于开展基本公共卫生服务项目。2021年人均基本公共卫生服务经费由每人每年74元提高到每人每年79元，未来新增的基本公共卫生服务补助资金继续向乡村医生倾斜。

四是出台乡村医生养老保险办法。我市在全省首家出合了《莆田市乡村医生参加养老保险暂行办法》（莆政办〔2014〕167号），经卫健部门认定的劳动年龄段内的乡村医生可以选择参加城镇企业职工养老保险或城乡居民养老保险，2013-2021年市财政累计下达约2.13亿元用于补助乡村医生参加养老保险所需经费。在城镇企业职工养老保险方面，市县两级财政每人每年补助合计由2015年3024元增至2021年初5184元，目前个人每月缴纳216元（按最低基数2700元，缴交比例8％统计）；城乡居民养老保险方面，市县两级财政每人每年补助合计3000元。乡村医生达法定退休年龄后将享受职工或城乡居民养老待遇。

五是增强乡村医疗机构风险防控。由于乡村医疗机构对医疗风险的抗击力差，发现、自纠、自救和管控能力薄弱，在当前社会矛盾突出、医患关系紧张的情况下，加强乡村医疗机构医疗风险管理尤为重要。为此，我市推行村卫生所医疗风险责任保险，医疗风险基金设立标准由2013年的500元提高至2021年的800元，财政给予每所的补助相应由300元提高至500元，每年累计赔偿限额提高到20万元。2021年共有808家村卫生所自愿参加，市财政每年补助约16万元，进一步提高村卫生所医疗风险保障力度。

六是推行乡村卫生一体化管理。将村卫生所纳入卫生院统筹管理，人员统一调配，保障空白村、海岛村、“幸福家园”试点村和乡医老龄化需更新村的人才需求，乡村医生人力资源得到较好配置。

下一步，结合提案建议，我们将进一步创新乡村医学人才培育机制，落实《福建省2021-2023年加强基层医疗卫生人才队伍建设实施方案的通知》（闽政办［2021]36号）》，依托福建卫生职业技术学院、厦门医高专等高校预计为全市乡镇卫生院定向培养医学人才168名，按照乡村一体化管理模式，实行“乡聘村用”，定向生可派驻到一体化村卫生所执业。定向生毕业后5年内未取得执业助理医师资格的，也可根据定向毕业生意愿，转聘到一体化村卫生所执业。

（二）扶持培养一批农业职业经理人、乡村工匠、非物质文化遗产传承人

加强乡村专业人才培育,扶持培养一批农业职业经理人、乡村工匠、非物质文化遗产传承人等，充分发挥他们的带动作用，盘活当地的自然资源和历史文化资源，打造具有乡土气息的文化产业和旅游产业。传承人是非遗的重要承载者和传递者，他们掌握并承载着非遗的知识和精湛技艺，既是非遗活的宝库，又是非遗代代相传的代表性人物。近年来，我市加强乡村专业人才培育，积极助推乡村文化振兴振兴。

一是加强挖掘和培养。注重搞好艺术普及教育工作，尊重民间自发性传承方式，全力挖掘尚存的传承地和传承人，加强对掌握非遗技艺技能的艺人的调查登记，积极发现辅导培养民间艺人，先后培养了一大批优秀的民间文化传承人，并通过举办文化协管员培训班，—方面培训了一批基层非遗保护工作骨干，另一方面也培训培养了一批民间艺术的传承人，有力地推动了民间文化的传播和发展。同时，努力扩大乡村代表性传承人队伍。在认定非遗代表性传承人时，重点考虑增补乡村代表性传承人数量，优化传承人队伍结构，形成合理梯队。今年，市文旅局正在第七批市级非遗代表性传承人申报评选工作，目前正在前期发动县区推荐申报，乡村非遗代表性传承人队伍将进一步扩大。

二是开展校企合作办学。莆田留青竹刻项目与莆田学院工艺美术学院合作开设竹刻课程选修，培养学生53名，同时举办了培训成果作品展览、课件PPT及拍摄专题和创作课题成果作品。土陶制作技艺项目和福建省艺术职业学院合作创办研学基地，达到了资源共享、优势互补、工学结合和合作共赢的目的。福建伟达装饰有限公司作为彩绘技艺的研学基地。通过校企联合办学，整合艺术资源，强化独特文化优势，展承非遗独特文化艺术之魅力，打造具有乡土气息的文化产业和旅游产业。

三是创建各类非遗传习中心。近年来，市文旅局积极协助企业做好生产性保护工作，支持协助申报国家级和省级非遗生产性保护示范基地，我市木雕项目获得国家级非遗生产性保护示范基地称号，福建省三福古典家具有限公司和海慧艺术品有限公司获批省级非遗生产性保护示范基地，福建省莆仙戏剧院有限公司和福建省三福古典家具有限公司入选首批福建省非遗生产性保护重点传承单位。此外，仙作古典家具协会和善艺李氏有限公司先后被文化部公布为国家级非遗保护研究基地。同时，我市举办了创建非遗传承基地（传习所）活动，共公布两批62个市级非遗传承基地（传习所），活态传承乡村技艺，努力盘活当地的自然资源和历史文化资源。

四、创新科技特派员服务机制

推行科技特派员制度对促进实施乡村振兴战略具有十分重要的作用。2021年我市共有经选认的省级个人科技特派员250名，省级团队科技特派员35个，省级法人科技特派员5个；选认市级科技特派员236名；选认县（区、管委会）级科技特派员288名。

一是推行“科技特派员+平台”模式。依托莆田市乡村振兴综合服务平台（壶兰乡村），开发、推广“莆田市科技特派员服务平台”，引导企业发布技术需求，为科技特派员开展精准服务、远程服务提供技术支撑，并通过平台及时发布成果、人才、市场等方面信息，提供“菜单式”服务供给模式。至目前，平台总访问量达31000多人次，制作农技培训视频98条，展示成果37项，注册科特派专家500多人。平台实现了科技特派员在线管理、科技信息线上发布、农业技术线上指导等功能，提高科特派管理效率和服务质量。

二是推行“科技特派员+研究所”模式。组织开展法人科技特派员选认工作，鼓励高校、科研院所等主体与当地政府、企业建立合作关系，围绕我市优势特色产业开展全产业链创业和技术服务。如福建省农业科学院作物研究所作为省级法人科技特派员，与我市企业合作的科技计划项目《茄果类蔬菜品种选育引进及嫁接育苗技术集成示范》，获省科技厅2021年立项，争取到30万元经费资助。

三是推行“科技特派员+团队”模式。组织开展团队科技特派员选认工作，将科技特派员后补助项目列入市级科技计划项目指南，鼓励个人科技特派员围绕当地产业链需求、组团进行科研攻关服务，助力乡村振兴、产业振兴。组织申报省级、市级科技特派员后补助项目，2018年以来共立项26项，补助经费384万元。

四是推行“科技特派员+专家”模式。进一步强化供需对接，围绕“建设一个工作站，对接一批专家，培育特色产业，开展技术培训，带动服务覆盖”的总体思路建设乡镇（街道）科技特派员工作站，负责收集当地技术需求，对接科技特派员的技术特长。目前已实现全市54个乡镇（街道）科技特派员工作站全覆盖。

今后，我市将深入实施科技特派员制度，坚持“双向选择”推荐选派各类人才服务乡村振兴发展战略，与基层生产经营主体和农户“点对点、面对面”开展科技指导服务，我们将在科技特派员服务和科技项目方面给予大力扶持。

五、完善返乡人才创业机制

（一）大力扶持返乡人才自主创业

强化创业担保贷款支持，创新优化担保制度，降低贷款担保门槛，今年以来为34人发放贷款，发放贷款金额808万元。筹集贷款担保金1325万元。开展创业资助项目评选，对市级优秀创业项目给予3-10万元资助，对省级资助项目，在省级补助的基础上予以1:1等额配套补助。截止目前，共19个项目入选2022年市级高校毕业生创业资助项目，省级资助项目已完成书面评审和实地考察，共向省里推荐9个项目，对获得省级创业项目资助的，市级财政按1:1予以配套补助。

（二）完善农村电子商务服务体系

近年来，市商务局认真贯彻落实市委、市政府关于人才工作的部署安排，始终高度重视商务领域人才培育体系建设，把人才培育工作放在推动商务领域各项工作发展的突出位置。我市作为国家电子商务示范城市和跨境电子商务综合试验区，近年来电子商务和区域产业加快融合发展，电子商务发展软硬件环境持续优化，已依托行业协会、龙头企业、专业机构等开展电商专题培训活动超百场，先后举办了第四届和第五届中国电商讲师大赛总决赛活动。同时，经积极对接争取，2021年我市仙游县获批创建国家级电子商务进农村示范县，将按照“分阶段、分层次、分对象”的模式，有针对性地对返乡农民工、大学生、退伍军人、合作社社员等，重点围绕直播电商、跨境电商等领域开展电子商务实战培训，为助力乡村振兴输送电子商务人才。

下一步，市商务局将围绕上级关于人才工作的有关要求，立

足高质量发展需要和电子商务行业发展需求，不断完善提升我市电子商务人才体系，积极为电商人才创新创业搭建平台、创造条件，推进各类电商人才协调发展，以人才要素的发展引领和支撑电子商务健康稳定发展。
