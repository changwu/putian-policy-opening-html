莆田市农业农村局关于市八届人大一次会议第0105号建议的答复

来源:市人大常委会 时间：2022-07-26 09:34
| | | |

郭雄新代表：

您提出的《关于休闲农业和乡村旅游发展的建议》（0105号）已收悉，现将办理情况答复如下：

一、统筹规划，科学合理布局

（一）识别城郊村庄区域，引导城郊型村庄在休闲农业上的合理定位。一是已批复的216个村庄规划中城郊型共34个村庄，定位为休闲农业如山亭镇蒋山村打造以“渔+紫菜”为主题的特色休闲村落；华亭镇云峰村以生态为基地、以农业为支撑、以大健康产业为发展导向，打造集乐活村居、康养度假、文化体验、休闲观光等功能于一体的转型融合城郊村庄；度尾镇洋坂村以文旦为特色，以艺雕为内涵，集艺雕产业、文旦柚基地、乡村文旅等功能为一体，影响莆仙地区、辐射闽中区域的宜居宜游的城郊村。二是强化调研指导即将启动编制的城郊型村庄，摸底各自的休闲农业资源，识别各自特色的城郊休闲产业，引导其对休闲农业的合理定位和配套保障。

（二）督导各县区加快乡镇国土空间总体规划编制，引领特色休闲农业规模化和集聚化。一是结合市级国土空间规划“双评价”、三线划定最新成果及永久基本农田核实整改补足工作，督促各县区（管委会）进一步完善分区层面《村庄发展研究及布局规划》编制工作，重点研究各辖区范围内村庄各类用地布局优化调整，统筹考虑城镇化发展趋势和乡村振兴实际需要，顺应城镇化过程中村庄建设用地总规模减量发展的趋势，同时为正在编制及即将开展的乡镇国土空间总体规划编制做好指导及衔接工作。二是督促各县区（管委会）在开展乡镇国土空间总体规划编制时，结合乡镇发展实际，深入挖掘自然禀赋等资源优势，引领特色休闲农业规模化和集聚化，创新开发和保护方式，加快资源优势向经济优势转变，打造乡村振兴样板，推动形成生产空间集约高效、生活空间宜居适度、生态空间山清水秀的特色城镇。

（三）结合《莆田市村庄规划编制技术与管理》编制，引领休闲农业在空间上可持续健康发展。结合正在开展的《莆田市村庄规划编制技术与管理》，充分挖掘莆田文化特征（莆仙文化、滨海文化、华侨文化）、景观特征（山、溪、海、林）、产业特征（木雕、石雕、海产品）、区位特征、人口特征等，将莆田村庄进行特色分区，做到因文制宜、因景制宜、因产制宜。指导村庄实现发展重点有条理、管控重点有方向、强制性规定有依据的目的，引领休闲农业在空间上可持续健康发展。

二、政策扶持，营造乡村旅游发展良好环境

（一）继续实施乡村旅游品牌奖励政策。对乡村旅游村被评为国家4A级、3A级旅游景区，分别给予一次性奖励100万元、50万元；被评为省级全域生态旅游小镇和三星级休闲集镇，分别给予一次性奖励60万元、40万元；被评为省级金牌旅游村和三星级旅游村，分别给予一次性奖励30万元、20万元，重点扶持旅游村编制旅游规划和旅游基础设施项目建设，大力提升乡村旅游公共服务水平。

（二）提高省级休闲农业示范点奖励力度。我市从2015年开始，将省级休闲农业示范点奖励列入现代农业发展专项资金补助，2021年进一步加大政策扶持力度，将省级休闲农业示范点列入《莆田市人民政府办公室关于印发推进农业产业高质量发展的若干措施的通知》（莆政办〔2021〕54号）政策扶持范围，暨对当年度新获得省农业农村厅确认的省级休闲农业示范点，给予一次性奖励20万元，进一步推进示范带动休闲农业产业发展。

（三）加大休闲农业和乡村旅游产业发展的资金扶持。近年来，根据福建省《乡村旅游“百镇千村”三年行动计划》，全市共打造乡村旅游村107个，每个村均获得省级旅游专项资金补助20万元，用于乡村旅游规划和基础设施项目建设。目前，省文旅厅正在推进乡村旅游升级，大力培育全域生态旅游小镇、金牌旅游村，对获评全域生态旅游小镇称号给予20万元奖励，获评金牌旅游村给予10万元奖励，同时，市级专项资金也将给予另行奖励，大力扶持乡村旅游项目建设。

（四）加大休闲农业和乡村旅游设施投入。积极向上争取补助资金，推动我市中小河流治理、安全生态水系建设以及水系连通及水美乡村建设试点县等农村水系治理项目。其中：仙游县累计争取上级补助资金12350万元。2019-2020年已实施仙水溪支流后坑段、园庄集镇段、枫慈溪支流后溪、延寿溪九鲤湖段、枫慈溪大埔段、九溪西苑仙水洋段等6个整治工程，完成治理河长27.3公里；2021-2022年度，将加快推进菜溪乡粗溪象山段、游洋镇粗溪桥光段及度尾镇中岳溪一二期中小河流治理项目，进一步改善当地农业生产条件，完成水生态、休闲景观一体建设，助推发展休闲农业和乡村旅游。

三、树立品牌，推进乡村旅游提质升级

（一）突出区域特色，整合乡村旅游资源特色。积极推动全国乡村旅游重点村、省级全域生态旅游小镇和金牌旅游村培育创建工作，并评定一批三星级旅游村，鼓励发展乡村民宿旅游、A级旅游景区创建等，推进乡村旅游因地制宜，发展特色休闲旅游农业。

（二）打造特色品牌，提升休闲农业档次。一是支持将现代农业项目、农产品加工、生态农业发展项目与乡村旅游等项目融合，对形成旅游条件的项目，鼓励申报市级观光工厂、职工疗休养基地。二是积极组织申报国家、省级美丽休闲乡村、省级休闲农业示范点，推动我市休闲农业的品牌升级。2021年仙游县石苍乡济川村获评2021年中国美丽休闲乡村；新培育仙游县金湖格生态茶庄园等2家省级休闲农业示范点和涵江区白塘镇双福村等3个福建省美丽休闲乡村。

四、加强人才培训，加快休闲农业和乡村旅游产业发展

近年来，我市高度重视乡村旅游人才培训工作，先后选送乡村旅游村干部30多人次参加省、国家组织的乡村旅游业务培训班，市里每年举办一期乡村旅游专题培训班，组织乡村旅游经营户、乡村旅游带头人、乡村旅游管理人、乡村旅游讲解员等各类实用人才培训，帮助乡村旅游村干部转变思想观念，提升文化素质和知识水平，提高乡村旅游管理服务能力。

五、规范化管理，提高服务水平

推动文旅市场治理、服务重心和执法资源向乡村下移，为乡村提供精准化、精细化旅游服务，指导各乡村旅游村规范旅游市场秩序，实施行政许可和行政处罚“双公示”，建立乡村旅游市场主体信用“红黑榜”，营造不敢失信、不能失信、不想失信的乡村旅游管理氛围，不断优化净化乡村旅游管理秩序，提高乡村旅游管理人员的服务意识和服务水平。

六、加大宣传力度，促进产业发展

高度重视文旅宣传，加强莆田旅游资讯服务，以网络为平台，加强资信宣传，为疫后散客游、自驾游提供准确的休闲农业和乡村旅游产品信息。同时，加强与其他设区市文旅局微信公众号、旅游网站、12306等平台合作，开展莆田休闲农业和乡村旅游产品宣传推广，拓宽莆田休闲农业和乡村旅游产品的营销渠道。一是积极主动走出去拓展市场，组织休闲农业和乡村旅游经营单位参加第十八届海峡旅游博览会和2022福建旅游生活展，把休闲农业和乡村旅游产品作为在省外主要客源地举办的莆田文旅推介会重点推介内容；二是组织休闲农业和乡村旅游经营单位参加厦门海峡休闲旅游博览会；参加闽东北协同区域组织的市场促销活动，将休闲农业和乡村旅游为重要营销产品，不断扩大休闲农业和乡村旅游产品的知名度。
