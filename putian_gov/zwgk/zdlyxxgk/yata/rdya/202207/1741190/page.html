关于市八届人大一次会议第0088号建议的答复

来源:市人大常委会 时间：2022-07-26 09:30
| | | |

刘华兰代表：

您提出的关于推进“三医联动”实现莆田市医疗卫生事业健康发展的建议收悉，现答复如下：

近年，我市各有关部门根据《深化医药卫生体制改革2021年重点工作任务》（国办发〔2021〕20号）、《中共莆田市委办公室 莆田市人民政府办公室关于深化“三医联动”改革的实施意见的通知》（莆委办发〔2019〕42号）等文件精神，认真落实有关医改工作的决策部署，为全面推进“三医联动”实现莆田市医疗卫生事业健康发展，在学习、借鉴和推广“三明经验”方面开展了大量的工作。

一、工作开展具体情况

（一）进一步推广三明市医改经验，加快推进医疗、医保、医药联动改革。

1.深化公立医院改革，推动公立医院高质量发展。始终坚持公立医院公益性，推动市属公立医院管理委员会高效有序运行，定期召开全体会议研究市属公立医院工资总额、绩效考核、院长年薪及医疗服务价格调整、医保支付方式改革等相关事务。并将医疗服务收入占比、按病种付费出院人数占比、基层医疗卫生机构诊疗量占比等医改指标纳入政府绩效考核体系中全力推动落实。全市10家县级以上公立医院建立院长考核评价体系，实行医院院长年薪制，由同级财政全额支付院长年薪；建立医院工资总额管理制度，对所有试行薪酬制度改革的公立医院实行工资总额一年一核定，体现医疗行业特点；建立医院内部绩效分配制度，绩效工资按照医院内部工分制绩效分配办法执行，有效激发医院内部活力，推动公立医院高质量发展。

2.推进药品耗材集中采购。常态化制度化开展药品集中采购，根据我省医药卫生体制改革工作总体部署和《福建省医疗保障管理委员会办公室关于开展以医保支付结算价为基础的药品联合限价阳光采购工作的通知》（闽医保办〔2017〕16号）有关精神，为充分发挥市场机制作用，挤压药品价格虚高空间，按照“按需而设、为用而采、去除灰色、价格真实”和“公开公正、公平竞争、诚实守信、全程监管”的原则，对我市各级各类医保定点医疗机构使用的药品（耗材），实施以医保支付结算价为基础的联合限价阳光采购；根据《福建省医疗保障局 福建省财政厅关于落实国家和省组织药品集中采购和使用中医保基金结余留用有关工作的通知》（闽医保〔2020〕77号）规定，落实国家和省集中组织药品采购和使用中医保基金结余留用；加大力度推进国家医保谈判药品落地使用。2021年我市完成国家医保药品、医用耗材分类与编码的贯标工作，推进医疗器械唯一标识在监管、医疗、医保等领域的衔接应用。

3.推进医疗服务价格改革。市医保局自成立以来，严格按照“总量控制，结构调整、有升有降，逐步到位”的原则，在调价评估的前提下，共调整医疗服务价格项目三次，其中新增105个医疗服务项目，调增866个项目，调减415个项目，规范522个项目，取消33个项目，核定我市二级及以下医疗机构未定价格项目约1400项，增加800多项少儿加收项目，有效体现了医务人员的技术劳务价值，进一步优化了医疗服务价格项目收费结构和比价关系。

4.深化医保支付方式改革。实行门诊特殊病种总额控制，为提高医保基金使用绩效，保障参保人员权益，确保医保基金运行安全，对市医保定点医疗机构实行基本医疗保险基金付费总额控制，定点医疗机构年度门诊特殊病种统筹基金发生额超总额控制指标部分，医保基金不予支付，由定点医疗机构自行承担；在12家二级及定点公立医疗机构开展按病种收付费工作，引导公立医疗机构加强管理、规范医疗服务行为、有效控制医疗费用不合理增长，减轻参保群众负担。按照国家统一部署要求，全面深入推进DIP付费改革工作，激发定点医疗机构规范医疗服务行为和控制服务成本，提升医保精细化管理服务水平，推进医疗保障和医药服务高质量协同发展。

（二）促进医疗资源合理均衡布局，加快分级诊疗建设。

1.实施医疗“创双高”建设，大力扶持社会办医。全力支持市级三甲医院发展，莆田学院附属医院2021年被省里确定为首批四家省级区域医疗中心建设项目之一，项目投资约13.76亿元，一期拟建设急重症诊疗中心，计划与国内高水平医院开展深度合作，争取打造具有省内先进水平、国内影响力的区域医疗技术高地。市第一医院新院区项目拟选址秀屿区峻兴管桩地块（310亩），计划投资30亿元，编制床位1500张，努力打造高水平的市级区域医疗中心、突发公共卫生事件指挥中心、传染病防治医疗保障中心，区域医疗中心建设。同时先后建成省级重点专科3个，市级重点专科18个，设立医疗质量控制中心24个，全市共获得4项省级科研成果，33项技术填补我市空白，开展149项新技术新业务。积极鼓励社会资本办医，鼓励引导社会力量提供多层次多样化医疗服务。一是完善准入审批。优化规范各项审批的条件、程序和时限，精简整合审批环节。二是放宽规划限制。政府对社会办医区域和专业不做规划限制。三是优化职称评审。社会办医专业技术人员与公立医疗机构专业技术人员一视同仁参加职称评审，且不受岗位比例限制。四是提升人才服务。支持社会办医与公立医院开展人才培养、学科建设等合作。五是积极为社会办医申请财政补助。2021年全市共新建3家民营医疗机构，全市共有各类民营医院57家，其中综合医院20家、专科医院28家、新业态医院9家。为12家医疗机构申请省级社会资本举办医疗机构财政补助资金共计621.916万元，为国药东南医院申请市级社会资本举办医疗机构财政补助资金1200万元。

2.加快分级诊疗建设。以慢性病管理为切入点，注重加强大医院和基层医疗机构分工协作，全面实施“基层首诊、双向转诊、急慢分治、上下联动”的分级诊疗制度。各县区通过建立慢病专科门诊、双向转诊绿色通道、家庭医生签约服务、免费送医送药等措施，积极引导群众自愿到基层首诊，全市建立家庭医生服务团队600个，常住人口签约1170872人，覆盖率达36.47%；重点人群签约565641人，覆盖率达到61.29%。全市设置开放联合病房8个，实现县区全覆盖，截至2021年12月底，全市联合病房总共收治1411余人次，其中三级医院下转860人次，人均医疗费用降低达到30%。推动两个城市医疗集团和仙游县县域医共体良性运行，推进基层医疗机构一院一品特色专科建设，完成300个村卫生所（社区卫生服务站）的标准化改造，建成38个“党建+”社区邻里中心卫生服务点，推动优质医疗资源纵向延伸，有效夯实基层卫生服务网底。

3.完善医保制度。完善职工医保个人账户管理。拓宽个人账户使用功能，推行个人账户家庭共济，个人账户可在定点零售药店支付购买药品（准字号药品、中药饮片）、医疗器械（食药监械字、药监械字）和消毒用品（卫消字），每月支付最高限额为1500元，购买次数不限，进一步提升个人账户使用效益，满足参保人员多层次医疗保障需求；逐步提高基本医疗保障水平。在我市执行全省统一的基本医疗保险药品目录、诊疗项目目录和医疗服务设施标准的“三目录”标准基础上，及时将新增医保可支付的诊疗项目纳入医保报销范围，并根据我市医保基金收支情况，逐步提高我市基本医疗保障水平，2022年3月我市进一步完善职工基本医疗保险门诊共济保障机制，进一步提高职工医保门诊待遇，其中职工医保普通门诊年度起付标准从1500元降低为700元，最高支付限额提高到医保政策范围内17000元。医保基金支付比例从50%-60%提高到75%-80%，在基层医疗机构就诊的支付比例分别再增加10个百分点，进一步减轻参保群众医疗负担。

（三）加强监管，强化部门合作。

1.强化集采中选药械质量安全监管。市市场监管局采取县区局巡查、市局督查的方式，加大对药品零售企业、医疗机构的监督检查力度，强化集采中选品种的质量安全监管。与“两节”期 间疫情防控、药械质量监管工作有机结合，组织开展国家药品监督抽检工作，先后抽样41批次药品，其中国家集中采购中选品 种9批次；制定了2022年省级药品监督抽检计划实施方案，拟监督抽检药品500批次以上，其中药品集采中选品种列入专项抽 检，充分发挥药械监督抽检的技术支撑作用，确保群众用药用械 安全、有效。

2.加大打击欺诈骗保力度，维护医保基金安全。2021年，我局通过日常稽核、智能稽核、跨部门双随机检查、打击“三假”专项整治等多种方式，加大欺诈骗保的打击力度。一是3月份组织召开公安、卫健、市场监管以及纪检组等部门工作联席会议，研究分析基金监管形势任务；二是6月份，联合市公安局、卫健委出台《莆田市医疗保障局 莆田市公安局 莆田市卫生健康委员会关于开展医保监管领域“假病人、假病情、假票据”等欺诈骗保行为专项整治的工作方案的通知》，并成立“三假”专项整治联合工作专班，部署开展打击“三假”专项整治工作；通过综合治理，全年共追回违规医保基金约2610.38万元，暂停10家定点零售药店服务协议，取消2家定点医疗机构和2家定点零售药店服务协议。通过高压严打，倒逼定点医药机构遵章守法、规则意识、契约精神及诚信意识的养成，确保医保基金安全。

3.加强部门协作配合。紧密围绕医改大局，市卫健委、市医保局和市市场监管局三部门加强沟通交流与协作配合，2021 年3家部门已联合出台了《关于进一步加强处方药销售使用管理的实施意见》，坚持医疗、医保、医药“三医联动”，促进医疗机构处方合理流出，推进医药分开，完善处方有序流转、共享机制；落实《关于加快药学服务高质量发展的意见》（国卫医发〔2018〕45 号）要求，对于高血压、糖尿病等疾病诊断明确、病情稳定、需要持续用药及管理依从性好的慢性病，对评估后符合要求的慢性病患者，一次可开具12周以内相关药品，探索慢性病长期处方管理，有效保障群众用药便利、可及。

二、下一步工作措施

（一）继续以推进“健康莆田”建设为引领，认真学习借鉴“三明经验”。进一步深化公立医院薪酬制度改革，统筹公立医院绩效管理、综合改革效果评价以及目标年薪制考核等，将考核结果与财政补助、项目、医院工资总额核定等相挂钩，着力推动公立医院高质量发展。进一步做深做实“联合病房”试点，加强县域医共体和社区医院建设，健全“党建+”社区卫生服务站常态化运行机制，推动2家市级三甲医院在“党建+”社区邻里中心设置便民门诊部，安排4个县区二级医院与辖区社区卫生服务机构开展结对帮扶，以专科服务联盟等方式实现“一站一特色”模式，促进优质医疗资源下沉和有序就医，逐步提高县域就诊率和基层医疗机构就诊率。

（二）继续采取有效的工作措施，加大监管力度。一是持续强化“三医联动”。贯彻落实《福建省深化医药卫生体制 2022 年重点任务及分工方案》精神，配合相关部门全力推进“三医一张网”建设，持续深入推进“三医联动”，统筹实施零售企业分级分类和零售企业统一标识等重点工作，加强分级分类结果运用，持续提升零售企业规范化管理水平，增强社会公众对零售企业的认知度，方便群众购药。二是持续强化药械监管。持续推进药品信息化追溯，逐步实现药品全品种、全链条的可追溯；坚持重点监管与随机抽查相结合的原则，采取“双随机一公开”、联合检查、飞行检查等行之有效的监管方式，运用风险分级、管理分类的方法，加强药械日常监督检查，灵活运用约谈、告诫、责令整改等措施，狠抓问题处置，督促企业（单位）排查并及时消除药械质量安全风险隐患。三是持续开展医保基金监管。围绕国家DIP改革工作，组织开展日常运行监测和智能稽核，对DIP付费模式下基金监管进行事前、事中、事后全流程监测和稽核；对医疗服务相关行为和费用（高套分值、诊断与操作不符、结算清单质量和日常诊疗行为、付费标准的合理性、参保人住院行为等）开展监测和稽核，加大对定点医疗机构稽核检查力度，不断加强过程控制，确保医保基金支付安全有效合理。

（三）继续深化药品耗材集中带量采购制度改革。巩固扩大全面落实跟进国家、省药品和医用耗材集中采购和使用试点成效，督促医疗机构按时完成国家和省药械集中带量采购基础量和使用比例“两落实”的任务，并对“两落实”的情况定期进行通报。做好药械货款统一结算支付工作和加强药械配送企业履约管理工作和短缺药品监测工作。通过药品耗材集采工作，不断减轻参合患者就医负担。

（四）继续完善各项改革工作机制。一是持续完善联席会议制度，加强与财政、卫健等部门的沟通协调，凝聚深化改革工作合力；二是建立健全集体协商谈判机制，加强与定点医疗机构的沟通协商，在各项改革工作及政策制定中，充分征求定点医疗机构意见，努力构建多方参与、相互协商、公平公正公开和共治共享的医保治理新格局。

    我市将继续结合本地实际情况，积极挖掘和汲取三明医改成功经验，通过三医联动，不断深化我市医改工作，使我市医改工作更上一个台阶。在此也十分感谢您对医改工作的关心，希望今后能继续得到您的关心和支持。
