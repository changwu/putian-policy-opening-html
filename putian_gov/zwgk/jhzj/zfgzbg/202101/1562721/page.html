2001年政府工作报告

2001年1月8日在莆田市第四届人民代表大会第一次会议上
来源:市府办 时间：2001-01-15 15:23
| | | |

各位代表：

　　现在，我代表莆田市人民政府向大会作政府工作报告，请各位代表连同《莆田市国民经济和社会发展第十个五年计划纲要（草案）》一并审议，并请政协委员和其他列席人员提出意见。

　　自1994年7月到现在，本届政府历时六年多时间。六年来，我市各级政府在省委、省政府和市委的领导下，高举邓小平理论伟大旗帜，认真贯彻党的十五大和江泽民总书记一系列重要讲话精神，团结全市人民，解放思想，实事求是，勤奋工作，开拓进取，基本实现了市三届人大一次会议和“九五”计划确定的主要奋斗目标，有力地推进了我市改革开放和现代化建设的进程。

　　经济综合实力明显壮大。2000年，全市预计国内生产总值200亿元，比1994年翻了一番多，年均增长12.1%，超过全省平均水平。规模以上工业产值由“九五”初期全省第8位上升为第6位，并接近第5位水平；农林牧渔总产值由第8位上升为第7位；财政总收入14.25亿元，年均递增18.1%，消除市本级财政历史滚存赤字9181万元，连续6年实现当年度财政收支平衡；6年完成全社会固定资产投资250.9亿元，是建市后前12年投资总和的3.29倍；社会消费品零售总额达到68.50亿元，比1994年增长1.2倍；全市金融各项存款和贷款余额分别达到146亿元和99亿元，比1994年分别增长4.2倍和2.9倍。

　　经济运行质量不断提高。经济结构战略性调整取得初步成效，三次产业比例由24.8：51.4：23.8调整为19.1：48.3：32.6。农业基础设施建设得到加强，产业化进程明显加快，水产、水果、畜牧、蔬菜、食用菌等产业呈较快增长势头，其产值占农业总产值的比重达到79.3%；农业开始朝着效益农业的方向发展。工业化水平明显提高，轻纺、食品、机电三个主导产业不断壮大，其产值占规模以上工业总产值76.5%；电子信息，化工和现代生物与医药等高新技术产业初露锋芒，其产值占规模以上工业总产值10.8%；规模以上工业效益逐年提高，近三年利税总额年均增长30.4%。金融、商贸、交通、通讯、旅游、信息、咨询、房地产等产业迅速崛起，第三产业在国内生产总值中的比重比“八五”期末提高了8.8个百分点，标志着国民经济朝现代化方向推进了一大步。六年来财政收入年均增长18.1%，增幅比国内生产总值年均增长率高出4.6个百分点；财政收入占国内生产总值的比重由1994年的5.7%提高到7.1%。

　　改革开放迈出新的步伐。国有企业改革逐步深化，中小企业改革面达到80%；国有工业近三年消化历史潜亏4862万元，顺利实现三年脱困目标；国有资产重组盘活了存量资产2亿多元，吸纳了10亿多元不同经济成份增量资产的投入，促进了企业经营机制的创新。社会保障体系不断完善，养老保险金实现百分之百社会化发放，成为全省先进典型。职工医疗保险被列为全国试点城市，初步探索出一些成功经验。再就业工程顺利推进，再就业率达78.78%。调整所有制结构步伐加大，非公有制经济成为推动经济发展的重要力量。党在农村的基本政策进一步得到落实，土地延包工作走在全省前列。土地使用权流转取得一些成功经验。利用外资呈现跨国公司投资、外国政府贷款、国际金融市场融资、BOT项目投资、代理招商等多元化局面，先后有4家企业在香港、新加坡上市。六年间实际利用外资14.33亿美元，是建市后前12年总和的2.2倍，”三资”企业已成为经济发展的重要力量。”九五”期间，外贸出口总额31.4亿美元，年出口总量保持在全省第四位，劳务出口创汇近1亿美元，居全省领先地位。

　　湄洲湾开发实现重大突破。六年间，北岸开发区完成总投资近百亿元。新建各类码头10个，新增货物吞吐能力294万吨。秀屿港通过国家一类口岸验收，正式对外籍船舶开放，实现与27个国家和地区的50个港口通航，2000年港口吞吐量达到200万吨，比”八五”期末翻了一番。建成北岸供水一期工程、疏港公路、新文公路等基础设施，海陆交通体系框架基本成型，发展港口经济的基本条件渐趋成熟，投资环境明显改善。佳通轮胎厂、湄洲湾火电厂、3.5万吨码头、中央直属粮库等一批重大项目相继建成陆续投产，临海工业和港口经济初露端倪，湄洲湾北岸已成为我市经济发展的增长极。湄洲岛国家旅游度假区开发建设步伐加快，各类旅游设施不断完善，接待能力和服务水平明显提高，六年来累计接待游客600多万人次，成为我市旅游产业的一大亮点。

　　城乡面貌发生显著变化。全市六年累计完成基础设施建设投资66.8亿元。“公路先行工程”、“村村通公路”工程和福泉高速公路莆田段相继完成，公路密度达到经济发达地区水平，通讯设施超前发展，电源充足，供水条件明显改善，木兰溪下游防洪一期工程开工，进展顺利，基础设施建设实现由制约型向基本适应型的转变。城市建设步伐加快，新建、改建市政道路20公里，中心城市路网框架逐步形成，先后改造了梅园路、胜利路、涵西、涵东等旧城片区，城市建成区面积拓展了5平方公里；环境保护和绿化建设进一步加强，集中整治了城区内河污染，污水处理厂和垃圾处理场相继开工建设。新增城区绿化覆盖面积218公顷，绿化覆盖率提高了6个百分点，初步树立起城市新形象。积极推进小城镇和新村建设，实施了“双十百万”工程，取得了阶段性成果。莆田县荣获“全国村镇建设先进县”称号。

　　精神文明建设取得新成效。“九五”期间，全市共取得科技成果136项，获省科技进步奖12项，民营科技企业迅速发展，高新技术产业开发区建设取得新突破，科技进步对经济增长的贡献率6年间提高了9.2个百分点。教育改革和发展步伐明显加快，投资渠道不断拓宽，素质教育得到重视，“两基”达标走在全省前列。创办了福建医大莆田分校，莆田学院正在迎接国家评估验收。我市荣获”福建省历史文化名城”称号，先后有一大批文艺作品获得国家级、省级奖项，妈祖文化对台交流不断深入，《莆田市志》完成编纂。广播电视事业迅速发展，开工建设莆田市广电中心，实现了村村通广播电视，全市电视、广播覆盖率分别达97.03%和95.48%。大力发展全民健身运动，我市荣获“全国篮球城市”称号，莆田、仙游两县连续保持“全国体育先进县”称号，并蝉联五届全国“田径之乡”，全市六年来共获得国内外各种体育比赛金牌224枚。打好“卫生发展三年翻身仗”，初级卫生保健全面达标。计生工作成效明显，完成人口控制计划。环境保护实现了“一控双达标”，鞋革“三苯”有机废气治理获得省专项优秀奖。群众性精神文明创建活动引向深入，荣获“全国双拥模范城”、“省级卫生城市”称号；仙游县荣获全省“创建文明县城活动一级达标县城”称号，涵江区、城厢区荣获全省“创文明城区活动一级达标城区”称号。建成国际SOS儿童村，接收来自4省（市）儿童106名。对口支援西藏、宁夏、三峡工作卓有成效，得到好评。弘扬伟大的抗洪精神，战胜了9914号台风洪涝灾害，创造了100天完成重建家园的奇迹，奏响了一曲精神文明建设的凯歌。

　　人民生活质量明显改善。城乡居民收入水平逐年增长，六年间城镇居民人均可支配收人增长1.19倍，农民人均纯收入翻了近一番。扶贫攻坚取得历史性成效，人民生活基本实现小康，部分地区开始向宽裕型小康迈进。进一步拓宽劳动就业渠道，市场导向就业机制初步形成。居民消费结构得到改善，文化、教育、旅游、保健等消费支出逐年增加，居住条件不断改善。认真开展“三五”普法教育，全面推进依法治市进程，建立健全社会治安综合治理责任制，深入开展“严打”专项斗争，严厉打击各种严重犯罪活动，坚决铲除“黄、赌、毒”等社会丑恶现象，积极妥善地处理好人民内部矛盾，增强了群众的安全感，维护了社会的安定稳定，人民群众安居乐业。

　　回顾过去六年的政府工作，我们在提高驾驭经济工作能力和如何加快莆田发展方面进行了积极探索，有些经验需要认真总结，以利于在今后的工作中不断加以完善和发展。

　　只有坚持解放思想，才能有新的发展思路。解放思想是改革开放的先导，工作创新的前提。几年来，我们坚持以邓小平理论为指导，依靠解放思想，促进观念更新，带动工作创新，用改革的办法解决发展中的困难和问题。在谋划国企脱困、运筹资产重组、改善投资环境、开拓内需市场、培育个私经济、组织项目推介，盘活行政资源等诸多方面，进行了有益的探索，不断推出适应社会主义市场经济规律的新思路，赢得了我市经济社会的新发展。

　　只有坚持追赶战略，才能有新的发展态势。发展是硬道理，解决莆田所有问题的关键在于加快发展。几年来，根据我市的基本市情，大胆提出并积极实施追赶战略，把壮大经济实力，提升区域竞争力，增强环境吸引力作为经济工作主题。进行大规模经济结构调整，在发展中调整，在调整中发展；坚持以港兴市的既定方针，大力发展港口经济；加强项目前期工作，扩大固定资产投资规模，积极培育新的经济增长点，大力推进两个根本性转变，从而把莆田的发展推向快车道，为未来的更快发展奠定了一个良好基础。

　　只有坚持追赶战略，才能有新的发展态势。发展是硬道理，解决莆田所有问题的关键在于加快发展。几年来，根据我市的基本市情，大胆提出并积极实施追赶战略，把壮大经济实力，提升区域竞争力，增强环境吸引力作为经济工作主题。进行大规模经济结构调整，在发展中调整，在调整中发展；坚持以港兴市的既定方针，大力发展港口经济；加强项目前期工作，扩大固定资产投资规模，积极培育新的经济增长点，大力推进两个根本性转变，从而把莆田的发展推向快车道，为未来的更快发展奠定了一个良好基础。

　　只有坚持依法行政，才能有新的工作机制。在社会主义市场经济条件下，法律是规范和调整社会经济生活的重要手段。依法行政，是适应市场经济运行机制的必然要求，也是推进依法治市的重要内容。市政府制订了《关于依法行政的实施规划》，认真开展“三五”普法教育，审查清理规范性文件，从严规范行政执法主体，认真落实行政执法责任制，依法办理政复议案件，大力加强政纪、审计、财政等专项监督。特别是切实加强与市人大、市政协及各民主党派、人民团体的联系，保证政府工作始终处于法律监督和民主监督之下。不断提高依法行政水平，促进政府工作机制逐步走向规范化、法制化，保证了社会经济生活的公正、公平和有序运行。

　　只有坚持群众路线，才能有好的工作作风。人民利益高于一切，是政府工作的最高准绳。各级政府把关心人民群众生活，维护人民群众利益作为一切工作的出发点和归宿。深入基层调查研究，与基层干部群众共商发展大计。全面推行政务、厂务、村务、校务公开，开辟政府网站，集中群众的经验和智慧。认真解决群众关心的热点难点问题，做好为民办实事、减轻农民负担、造福工程、社会再就业工程、“三条保障线”落实、电力“两改一同价”、农村合作基金会和城市信用社清理整顿等工作，使人民群众得到实惠，合法权益得到保护，低收入居民、困难企业职工和特困人员的基本生活得到保障。并注意把人民群众的积极性、创造性引导好、维护好、发挥好，凝聚全市人民力量共襄伟业。

　　只有坚持从严治政，才能有好的政府形象。几年来，我们坚持从严治政，努力建设廉洁勤政务实高效的政府。认真贯彻民主集中制，凡属重大决策、重要项目安排和大额度资金使用，一律由集体讨论决定，充分发挥班子的整体战斗力。认真落实党风廉政责任制，廉洁自律，管好自己、管好家属、管好身边工作人员；深入开展纠正行业不正之风工作，认真组织各种专项治理；坚决查办违法违纪案件，六年查处案件2031起，处理2091人。率先开展机关效能建设，形成以七项基本制度为核心的效能管理体系。加强了政府自身建设，努力塑造人民政府的良好形象。

　　各位代表，过去的六年是莆田取得可喜成就的六年，是莆田发生巨大变化的六年。这期间，我市经受住亚洲金融风波、国内外市场供求变化和特大自然灾害的考验，基本实现了“九五”计划的主要目标，是来之不易的。这些成绩的取得，是由于省委、省政府和市委的正确领导，是由于历届市委市政府打下的良好工作基础，是由于市人大、市政协的监督和支持，是由于全市人民的勤劳和智慧。也离不开省直各部门和兄弟地市的关心和支持，离不开驻莆解放军和武警部队的大力支持，离不开港澳同胞、台湾同胞、海外侨胞和国际友人的广泛参与。也是各级政府同心同德、努力奋斗的结果。在此，我谨代表莆田市人民政府，向所有关心、参与和支持莆田发展的同志们、朋友们，表示崇高的敬意和衷心的感谢！

　　在肯定成绩的同时，我们也清醒地看到，我市经济社会发展过程中，仍面临着不少矛盾和困难，政府工作中也有缺点和不足。主要是：经济规模相对较小，经济总量和人均水平仍居全省后列；财政困难、经济结构不合理的状况尚未根本改变，新经济增长点不多，一些群众的生活还比较困难；改革的力度不够，企业经营机制和政府职能转变还不能适应市场经济的要求，企业和产品竞争力不强；行政区划不合理，历史长期积累的一些矛盾还没有从根本上得到解决；城镇化水平较低，城市规划、建设、管理的水平不高，功能不配套、不完善；人口、资源和环境的压力较大，社会事业某些方面发展相对滞后；科技创新能力弱，高新技术产业成长缓慢，教育、卫生改革起步较迟；政风、行风、社会风气还有不少问题，腐败现象仍然不同程度存在，一些地方社会治安状况不容乐观，安全生产存在不少隐患；部分政府工作人员的素质和工作能力与新世纪的发展要求不相适应，政府工作中仍然存在着文山会海、形式主义、官僚主义的问题。这些问题需要我们高度重视，采取切实有力的措施加以解决。

　　三要勤政为民，提高为人民服务的质量。各级政府要强化公仆意识，树立以民为本观念，“常怀为民之心，常思为民之策，常兴为民之举”，始终把一切为了群众、一切依靠群众作为一切工作的出发点和落脚点，时刻把人民群众的冷暖安危放在心头。坚持每年为民办几件实事好事。要以深厚的感情，关心群众生产、生活困难，努力为民排忧解难。坚持群众观点，善于从群众的赞扬和鼓励声中寻找差距，善于从群众的批评和怨言声中反思过错，不断改进工作。对一些不符合群众利益的事，决不能放任自流，要敢抓、敢管，敢于为民说话，多做便民利民、民喜民乐的事，绝不做坑民害民的事，以实际行动赢得人民的拥护和支持，同心同德，共创伟业。

　　四要廉洁奉公，树立清正廉洁的政府形象。继续贯彻落实党风廉政建设责任制，把严格要求干部同关心干部相结合，管好班子，带好队伍，抓好风气，严肃责任考核，狠抓责任追究。切实加强领导干部廉洁自律工作，严格执行廉政准则等有关规定，坚决落实领导班子成员关于严禁赠送收受礼金、礼品和“三个管好”承诺。落实领导干部任期经济责任审计制度，着力从源头上预防和治理腐败。严肃查处违纪违法案件，对重大案件要一查到底，决不姑息迁就。坚决纠正部门和行业不正之风，突出专项治理，及时解决群众关心和反映强烈的热点、难点问题。

　　各位代表，人类历史已进入新的世纪。回首往昔，我们已经在20世纪末叶，缔造了前所未有的业绩；展望未来，我们必将在21世纪初叶，开创出更加辉煌的成就。让我们紧密团结在以江泽民同志为核心的党中央周围，在省委、省政府和市委的正确领导下，坚定不移地实践”三个代表”的重要思想，全面贯彻落实市第四次党代会精神，动员全市人民，加快建设新兴港口城市，同在一方热土，共创美好明天！
