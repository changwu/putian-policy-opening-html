2004年政府工作报告

2004年2月10日在莆田市第四届人民代表大会第六次会议上
来源:市府办 时间：2004-02-18 15:46
| | | |

莆田市人民政府市长詹 毅

各位代表：

现在，我代表莆田市人民政府向大会作政府工作报告，请予审议，并请市政协各位委员和其他列席人员提出意见。

迎难而上、富有成效的2003年

2003年，全市上下坚持以邓小平理论和“三个代表”重要思想为指导，认真贯彻落实党的十六大和十六届三中全会精神，按照聚精会神搞建设、一心一意谋发展的要求，围绕推进新型工业化、农业产业化和城市化，强化环境建设和项目建设，着力树立良好政府形象的工作思路，团结拼搏，迎难而上，克服了非典疫情和连续干旱等带来的不利影响，经济社会发展取得新成绩，完成了市四届人大四次会议提出的各项目标和任务。

（一）经济结构不断优化，综合实力明显提升。据初步统计，

2003年国内生产总值完成262.70亿元，增长12.3%；财政总收入20.48亿元，同口径增长15.2%，地方级财政收入9.55亿元，同口径增长11.4%，财政支出15.3亿元，增长8.0%；全社会固定资产投资额完成59.30亿元，增长21.8%。一、二、三产业增加值分别增长4.0%、17.5%、9.3%，产业比例由上年的16.4：47.4：6.2调整为15.5：49.9：34.6。农村经济稳定增长。农业产业化水平明显提高，新增5家省级农业产业化龙头企业和12家市级农业产业化龙头企业，36家规模以上龙头企业年产值达25亿元。农林牧渔业总产值达到66.15亿元，增长4.4%。工业经济快速增长。完成工业总产值312.48亿元，同口径增长20.1%.其中，规模以上工业产值达219.18亿元，增长26.3%，占工业总产值的70.2%，成为工业发展的主导力量。工业经济效益综合指数比上年提高14.5个百分点，利税总额增长39.5%。第三产业平稳发展。交通运输、邮电通信、商贸流通、旅游服务和房地产业均有不同程度的发展。全市社会消费品零售总额87.19亿元，增长13.7%；港口货物吞吐量达到600万吨，增长25%。开展创建中国优秀旅游城市活动，提升了城市旅游功能。

(二)园区建设取得突破，重点项目进展顺利。制定出台《关于加快工业园区建设的意见》。规划、整合8个省、市级园区总面积98.38平方公里，新增落地项目109个，总投资25.6亿元；签约项目87个，计划总投资31.6亿元。莆田高新技术产业园区列为全省20个重点开发区之一。全市28个重点建设项目完成投资14.5亿元，一批重大项目工作取得实质性突破，LNG秀屿接收站填海工程、南日岛风力发电场、木兰溪郑坂段防洪工程、澄峰围垦工程、仙游抽水蓄能电站进站道路实现开工；莆田--秀屿高速公路支线、湄洲湾十万吨航道疏浚工程、福厦铁路莆田段、金钟水利枢纽工程、沥青项目等一批事关莆田发展的战略性项目前期工作有了不同程度的进展。市级储备255个大中型项目，总投资600多亿元，奠定了加快发展的基础。

(三)发展环境继续改善，招商引资力度加大。围绕推进“环境建设年”，出台《关于对损害经济发展投资软环境的行为实施责任追究的暂行规定》、《关于改革企业注册登记办法的实施意见》、《关于实施项目带动加大投资项目工作力度的若干意见》、《关于加快乡镇经济发展若干意见》等文件。成立市行政服务中心和投资项目服务中心。市直25个部门的行政审批进驻中心，受理审批事项45164件，办结率97.6%，提高了办事效率和服务质量。推进政务、村务、厂务、校务、院务等办事公开制度，落实反腐倡廉长效机制，进一步抓好领导干部廉洁自律、查处大案要案、纠正部门和行业不正之风的工作。主动出击招商引资，先后在厦门、北京、上海、广州等地招商，市庆期间举办投资项目推介会，累计签订项目214个，总投资85.7亿元，外资3.65亿美元。全年合同利用外资2.09亿美元，增长13.7%；实际利用外资2.51亿美元，增长4.2%；外贸出口8.21亿美元，增长6.9%。

（四）体制创新步伐加快，各项改革不断深化。改革土地管理体制，用活土地政策，全年报批各类建设用地12196亩，盘活闲置土地4200亩。全面推进农村税费改革，农民人均税费负担减负率89.75%。开展集体林权制度改革。理顺广电管理体制。推动企业制度创新，列入全省第一批企业改革计划的7家企业，已有3家企业完成股份制改造，众和股份有限公司完成上市辅导期，并上报国家证监委。实施品牌战略，沃特运动鞋、才子西服、才子衬衫、金威世家西服、闽中汽车电机、三棵树内外墙涂料、三源铝合金建筑型材等7个产品获得国家免检产品，总量居全省第二位，实现创国家免检产品零的突破。积极构建地方经济与金融的互动双赢机制，全市年末存款余额224.77亿元，增长19.5%；贷款余额144.66亿元，增长20%。扩大准入范围，激活民间资金，全市民营个体固定资产投资比上年增长了3倍，有力地推动经济发展。

（五）城市建设稳步推进，城乡面貌明显改观。组织实施城乡规划编制年工作，完成市域城镇体系规划、莆田市城市发展战略规划等专项规划，引导城市有序建设。树立经营城市理念，多方筹集城建资金，全年完成城建投资3.33亿元，增长30.5%。通过经营城市土地收入投资建设荔园路一期工程、荔涵大道城厢段工程。建成市政广场、市体育中心等一批市政设施和社会事业项目。莆阳路改造、天九湾拆迁、荔园小区经济适用房建设、涵江旧城区西区改造和城市管道燃气建设等项目进展较快。着力加强城市管理，城市面貌有了改观。小城镇和新村建设完成投资2.26亿元，白沙镇坪盘小区被评为省级村镇住宅优秀小区。新增农村公路598.8公里，开通70条乡村客运线路，覆盖302个村，有效解决农民乘车难问题，得到了省政府表彰。

（六）社会事业全面发展，人民生活得到改善。顺利通过创建“全国科技进步先进城市”考核，成功举办中科院--莆田科技项目推介会和莆田二十年科技成就展，获得国家专利152项。巩固提高“两基”教育，素质教育全面推进，高中和高等教育得到进一步加强，完成了莆田一中新校址迁建，莆田学院教育资源整合工作基本完成，湄洲湾职业技术学院通过省高校设置专家组考评。高考录取新生16413人，增长71.7%。人口自然增长率5.98‰，低于全省平均水平。生态建设和环境保护稳步推进，木兰溪防洪一期工程完成投资1.92亿元，郑坂段防洪工程建设步伐加快，市长环保目标责任制年度任务基本完成。加强公共卫生和疾病预防控制体系建设，实现非典零感染和无疑似病例。文化事业进一步繁荣。成功举办了第五届妈祖文化旅游节和“莆田文学节”，编写出版《莆田文化丛书》，莆仙戏《江上行》获得全国“五个一工程”奖，省级历史文化名城保护规划已经市人大常委会原则通过，广电中心主体工程顺利竣工。荣获“中国木雕之城”称号。竞技体育水平提高，全民健身活动广泛开展。组织实施《公民道德建设实施纲要》，加快“诚信莆田”建设，精神文明取得了新成效，获得全省创建文明城市工作先进城市的称号。全力维护社会安定稳定，深化“严打”整治斗争，全面落实加强社会治安综合治理各项措施。大力整治信访秩序，无序上访现象得到遏制。开展安全生产专项整治百日会战，安全生产形势明显好转。进一步推进国防动员工作，深入开展“双拥共建”活动，再次荣获“双拥模范城”称号。妇女儿童、外事侨务、民族宗教、档案、地方志、防震减灾、老龄、残疾人等工作取得新成绩。人民生活水平得到提高。城镇居民人均可支配收入8948元，增长7.4%；农民人均纯收入3761元，增长5.6%。全市共安置城镇失业人员6600人，城镇登记失业率为2.5%。城市低保对象实现应保尽保，农民低保对象比上年增长2.6%。

各位代表，过去一年的成绩来之不易，这是全市人民智慧和力量的结晶。在此，我代表市政府向为改革和建设事业作出贡献的全市人民，向给予政府工作大力支持与有效监督的人大代表、政协委员和各民主党派、工商联、群众团体、无党派人士，向为莆田改革发展稳定作出积极贡献的驻莆机构、驻莆部队、武警官兵、公安政法干警，向所有关心、支持莆田发展的台港澳同胞、海外侨胞和各界朋友，表示衷心的感谢和崇高的敬意！

我们也清醒地看到，经济社会生活中还存在许多困难和问题。经济总量小，产业结构不合理的状况尚未根本改变；工业化程度和水平不高，产业链不够完善；农业产业化水平偏低，农民增收难度大；城市功能不够完善，城市管理不尽人意；就业压力大和急需人才短缺的问题并存；部分群众生活仍较困难；财政依然困难，地方级收入所占比重较低；社会治安形势不容乐观，影响社会稳定的因素仍然存在；一些机关工作人员思想不解放，责任心不强，行政效率不高，消极腐败现象依然存在等等。面对这些问题，我们要保持清醒的头脑，克服困难，采取有效措施加以解决。

提速奋进，实现追赶战略的新跨越

2004年是全面贯彻落实党的十六大、十六届三中全会精神的重要一年，是完成“十五”计划的关键年，也是我市“项目工作落实年”。今年政府工作总的指导思想是：以邓小平理论和“三个代表”重要思想为指导，全面贯彻落实中央、省委、省政府和市委的决策部署，树立全面、协调、可持续的发展观，按照“稳定政策、适度调整，深化改革、扩大开放，把握全局、解决矛盾，统筹兼顾、协调发展”的要求，高举发展的旗，攻克发展的关，办好发展的事，大力实施项目带动战略，以项目保增长，以项目促发展。切实把工作重点转到调整经济结构、转变增长方式、提高增长质量和效益上来。正确处理改革发展稳定的关系，切实加强民主法制建设、精神文明建设，促进三个文明共同进步和经济社会协调发展。

今年全市国民经济和社会发展的预期调控目标建议为：莆田市生产总值增长13%，向300亿元的目标冲刺；全社会固定资产投资额增长26.5%；工业增加值增长14.5%；财政总收入同口径增长11.5%，其中地方级财政收入增长12.7%；实现利用外商直接投资1.5亿美元，外贸出口增长10.8%；社会消费品零售总额增长12.4%；城镇居民人均可支配收入增长7%；农民人均纯收入增长5%；城镇登记失业率控制在3.2%以内；人口自然增长率控制在7‰以内。实现今年的各项目标，对于实施追赶战略，具有十分重要的意义。当前，我市面临新的发展机遇，具备较好发展条件，我们要充分利用一切有利条件，调动一切积极因素，齐心协力，真抓实干，乘势而上，努力在建设对外开放、协调发展、全面繁荣的海峡西岸经济区中发挥应有的作用。

实现上述目标，必须做好以下六个方面工作：

（一）进一步调整产业结构，加快提升综合竞争力

推进新型工业化。坚持走工业立市道路，滚动实施“2311”工程，重点培植生物制药、服装纺织、制鞋、电子、化工、机械等20个年可新增产值3000万元以上新工业经济增长点，力争规模以上工业增加值增长20%以上。着力发展电子信息、生物制药、新材料及光机电一体化等高新技术产业。促进珍奥核酸单核苷酸、德信数字传真和程控电话、新世纪覆铜箔层压板、佳通全钢子午胎、荣兴摩托车制动器等项目开工建设，提高产业集中度。扶持佳通轮胎、雪津啤酒、德信电子、安特半导体、兴安药业、才子集团等10家成长型企业，培植行业龙头企业。加快制造业信息化建设步伐，提升制造业水平。实施品牌战略，扶持、奖励创名牌产品的企业，争取在服装制鞋、食品药品、电子信息等领域创立一批国内知名品牌。

推进农业产业化。巩固壮大闽中蔬菜、中源食品、华港油脂、东南香米业、华林蔬菜、新美蔬菜、兴泰果园等农业产业化龙头企业，以龙头企业培育，带动农产品基地建设，形成度尾文旦柚基地、常太和书峰名优枇杷基地、萩芦绿色食品标准化园区、大洋万亩反季节蔬菜基地、新县牛肉基地等。完善农产品市场流通体系，建设水产、水果、蔬菜、畜牧、食用菌等大宗农产品专业批发市场。发展农村合作经济组织，充分发挥同业协会作用，扶持发展农产品购销大户和农村经纪人，提高农民组织化程度。健全农产品检验检测体系，推进农业标准化生产。建立优质无公害农副产品生产基地，组织温氏、实达、鸿达、协生、亿松等养殖场申报无公害基地。切实重视动植物疫情防治，严防高致病性禽流感。引进名特优水产新品种，发展水产生态养殖。加强农村基础设施建设，实施100个山地水利工程、100村农民饮水工程、

100公里河道清水工程、100名农技专家下乡、100家农业生产经营大户等百个农业发展项目。加大农村公路建设力度，扩大和深化乡村客运试点工作，改善农村生产生活条件。

发展现代服务业。围绕创建中国优秀旅游城市目标，有效整合旅游资源，制定旅游项目开发规划，加快湄洲岛、九鲤湖等景区配套设施建设，鼓励发展旅游服务业，大型服务性项目可视同工业项目，享受优惠政策，尽快形成莆田旅游服务网络，创新促销手段，拓展旅游市场，力争实现旅游收入增长20%以上。积极推广物流配送、连锁经营、电子商务等新型流通业态，选择涵江商贸城、国货商业集团等5家企业推行电子商务试点，继续抓好凤凰百货、绿洲超市等6家“农改超”项目试点。新建续建城厢龙桥社区农贸市场、南门名特优产品商业城、仙游商贸市场三期等7个市场项目；改造升级涵江闽中蔬菜批发市场、闽中水产品批发市场、秀屿笏石农贸市场等传统产业市场。继续发展会展经济，引导企业参加省内外大型商品展销活动，提高莆货知名度，拓展莆货市场空间，举办莆田首届国际鞋展。推进房地产业发展，放开房地产二级市场，规范物业管理，培育房地产消费热点。进一步推进社区建设，完善社区服务功能，扩大服务覆盖面。大力发展金融、保险、电信、法律、会计等服务业。

建设为民、务实、清廉的政府

政府工作的核心是对人民负责。对人民负责就要自觉学习实践“三个代表”重要思想，弘扬求真务实精神，大兴求真务实之风，建设为民、务实、清廉的政府。

为民要坚持民主决策、依法行政。把人民的需要作为政府决策的第一信号，从群众最不满意的事情抓起，从群众最困难的事情办起，从群众最期望的事情做起，把最广大人民群众的根本利益实现好、维护好、发展好。推行与群众利益密切相关的重大事项公示制度、听证制度、专家咨询制度和决策责任制度，健全决策、执行、监督体系，提高决策的科学化、民主化水平。加强政府法制建设，严格按照法律规定的权限和程序行使权力、履行职责，提高依法行政的能力和水平。增强行政行为透明度，实现行政行为规范化和经济、社会事务管理法制化。

务实要坚持开拓创新、优质高效。与时俱进，以创新的思维、创新的胆略、创新的举措，冲破一切妨碍发展的思想观念，改变一切束缚发展的做法规定，革除一切影响发展的体制弊端，按照市场经济规律办事，在开拓创新中加快发展。树立正确的政绩观，

力戒官僚主义和形式主义，把主要精力放在工作落实上，把注意力用在解决问题上，把政绩建立在实现群众利益上。健全政府工作目标管理办法，形成分工负责、狠抓落实的责任体系。继续规范和精简公文，压缩会议，减少检查，真正把时间和精力集中到

营造环境、发展经济上。加强行政效能建设，强化效能监察，推广“一次性告知”、“一条龙服务”的联合办公制，提高办事效率和服务质量。推进政务公开和电子政务建设，及时把政府的决策、服务程序、办事方式向社会公布，为群众提供公开、透明、高效的公共服务。

清廉要坚持从严治政、严于律已。牢记“两个务必”，保持谦虚谨慎、不骄不躁的作风，保持艰苦奋斗的作风。坚持从政府机关抓起，加强对全体政府工作人员的教育管理，常怀爱民之心，恪守为民之责，善谋富民之策，多办利民之事，真正为人民掌好权、用好权。落实反腐倡廉“六个机制”，坚持不懈地抓好政风建设，进一步抓好领导干部廉洁自律、查处大案要案、纠正损害群众利益的不正之风等工作。强化审计监督。建立市招投标中心，完善招投标运行机制，构建建设工程招投标、国有土地与采矿权出让拍卖、政府采购和产权交易的公平竞争平台，从源头上预防和治理腐败。认真落实政府廉政建设责任制，逐步建立与社会主义市场经济相适应的教育、制度、监督并重的惩治和预防腐败体系，以清廉的政风取信于民。

建设对人民负责的政府，要落实到每个人的身上，具体到每一项工作上。各级领导干部特别是政府班子成员要率先垂范，敢于负责，在重点工作、难点事务、关键问题上勇挑重担，靠前指挥，只要对大局有利、对发展有利、对人民有利的事情，敢闯敢试，敢抓敢管，敢做敢当，绝不能遇到问题绕道走，有了矛盾就上交，碰到风险就退缩。政府工作人员要增强事业心和责任感，同心同德，尽职尽责，把莆田的事情办好，对莆田人民负责，为加快莆田发展做出应有的贡献。要强化政府责任、部门责任和个人责任，认真落实工作责任制和责任追究制度。加强对政府决策、部署执行情况的督促检查，确保政令畅通、令行禁止。切实解决不思进取、推诿扯皮、办事拖拉、故意刁难和扰民侵民等群众反映强烈的问题，防止行政不作为和行政乱作为，使敢负责、办实事、抓落实蔚然成风。要旗帜鲜明地支持和保护想干事、能干事、干成事的干部，让干事业的人少受委屈，努力营造谋事、干事、成事的良好氛围。

各位代表，在新的一年里，让我们高举邓小平理论伟大旗帜，以“三个代表”重要思想为指导，紧紧团结在以胡锦涛为总书记的党中央周围，认真贯彻落实党的十六大和十六届三中全会精神，在省委、省政府和市委的领导下，继往开来，与时俱进，为全面

建设小康社会而努力奋斗！
