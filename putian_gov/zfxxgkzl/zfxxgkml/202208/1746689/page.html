关于市八届人大一次会议第0063号建议的答复

发布时间：2022-08-17 21:57
| | | |
政策解读:

林素平代表：

您提出的《关手乡村路灯开支列入财政预算的建议》（第 0063号）收悉，现答复如下：

近年来，湄洲岛始终牢记习近平总书记“保护好湄洲岛”的重要嘱托，深入实施乡村振兴战略，立足区情实际，充分发挥各级各类资金参与乡村建设的撬动作用。我区从2018年开始，村级运转经费年预算600多万元，其中用于村级路灯电费、维修费等办公经费支出每村每年14多万元。此外，我区积极利用各级乡村振兴资金，2021年宫下村〈省级乡村振兴实绩突出村）利用省级补助资金，实施宫下村村庄美化亮化路灯建设工程，建设包括 137盏6米高灯杆照明路灯及配套设施：2021年后巷村（省级乡村振兴实绩突出村）通过后巷新区老旧路灯更换及新建项目，对全村路灯进行提升改造，亮化、美化修缮和新建约225 盏照明路灯。截止目前，湄洲岛全岛11个行政村共有2665盏村级路灯，全区村级路灯基本实现村道全覆盖，大大改善村民的夜间出行。

下一步，我区将进一步加快乡村公共基础设施建设，持续改善农村生产生活条件，逐步提高群众的幸福感和获得感。
