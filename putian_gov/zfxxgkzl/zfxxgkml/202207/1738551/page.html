关于市政协八届一次会议第2022003号提案办理情况的答复

发布时间：2022-07-01 10:52
| | | |
政策解读:

致公党莆田市委员会：

你们提出的《关于进一步促进湄洲岛高质量高颜值发展的建议》（2022003号）已收悉，现将办理情况函复如下：

一直以来，湄洲岛始终牢记习近平总书记的殷切嘱托，认真按照上级部署要求，紧紧围绕生态环境保护、妈祖文化传播、文旅业态发展等方面，深化保护好湄洲岛各项举措，全面推动文旅产业优化升级，全力推进湄洲岛高质量高颜值发展。

一、推动生态环保底色擦得更亮

我们着重从三个方面强化：

一是坚持规划引领。委托编制《莆田市湄洲岛国土空间分区规划（2021-2035年）》，立足习近平总书记嘱托和省市战略部署，融入区域协同发展，明确发展定位，优化国土空间开发和保护总体格局，系统提出全域国土空间开发、利用、保护、修复和治理的目标、任务和措施，明确管控规则，制定实施保障措施，为湄洲岛经济社会全面协调可持续发展提供空间保障，形成国土空间开发保护“一张图”，不断拓展绿色发展空间。

二是统筹推进生态保护。科学开展山水林田湖草沙礁综合保护，依法严厉打击非法采砂、非法围填海等破坏海岛风貌和生态环境违法行为；实施生态水系综合整治，稳步实施“绿满城乡、花样湄洲”三年行动，同时对全岛主要道路、景区、公园、重要节点、校园等（包含码头交通组织周边、集散广场、环岛西路景观工程，东环景观带、环岛南路等）进行绿化和景观提升改造，逐步提高全岛绿化覆盖率和绿化品质，岛上的绿化覆盖率已提升到60.66%。

三是绿色低碳发展。推进减污降碳协同增效，始终坚持污水全收集全覆盖全处理全达标全利用；宫下码头风雨廊分布式光伏项目已完工，造林绿化碳汇示范项目已完成林业碳汇本底调查与固碳潜力评估，报告已通过专家评审。2022年计划通过推进北斗海岛综合应用、分布式光伏、明厨亮灶、电动自行车、新能源电动汽车等项目逐步实现全岛电气化，形成低碳、环保、节能发展模式，打造人与自然和谐共生的和美海岛。

二、推动妈祖文化弘扬传得更远

近年来，湄洲岛立足优势，以“三个推动”为抓手，持续打好叫响妈祖文化牌。

一是推动活动谋划。顺应疫情防控形势变化，适时调整世界妈祖文化论坛会议规模以及分论坛、配套活动（包括项目招商签约活动）具体内容，确保各项筹备工作有序推进。创新举办海峡两岸妈祖宫庙携手抗疫线上祈福、海峡两岸妈祖文创精英对话、两岸青年歌手赛、“共植两岸同愿林”等特色交流活动内容，有力深化了两岸一家亲理念。下一步我们将深入挖掘妈祖36次朝廷褒封和47个国家分灵的生动事迹，积极探索妈祖文化新时代内涵元素发展新模式。

二是推动保护传承。接续推进“海上丝绸之路·中国史迹”世界文化遗产和国家级妈祖文化生态保护实验区申报工作，开展妈祖祖庙史迹点保护管理。以《妈祖信俗》人类非物质文化遗产传承为抓手，连续举办湄洲女发髻技艺表演赛等，多形式深化妈祖文化传播。编辑出版妈祖文献史料汇编等系列文献资料，联合莆田学院开办“妈祖文化传播人才培养特色班”，推进妈祖文化创造性创新性发展。

三是推动对外交流。坚持“引进来”“走出去”，成功举办六届世界妈祖文化论坛，持续打响“妈祖下南洋·重走海丝路”交流品牌，推动湄洲妈祖金身巡安新加坡、马来西亚、菲律宾、泰国等海丝沿线国家和地区，在当地侨界及华人社区持续掀起“妈祖热”，有力深化与“海丝”沿线国家和地区民心相通、文化互鉴。《台湾百家妈祖宫庙湄洲谒祖进香团》照片在国家博物馆庆祝改革开放40周年大型展览上亮相。2016年以来，妈祖文化传播分布从38个国家和地区增加到47个。启动对台直航前期工作，持续实施台胞入岛免门票、在岛领取台胞居住证政策，赋予台胞“岛民待遇”。

三、推动文旅业态发展走得更实

我们围绕“处处是五A景点”的目标，以“三个提升”为抓手，有力推动文旅业态发展。

一是提升引客力度。秉承“月月有活动、季季有盛事”的原则，不间断地举办新春祈年典礼、春秋祭妈祖大典、天下妈祖回娘家、湄洲妈祖巡天下、夏季沙滩音乐季、海峡论坛·妈祖文化活动周、湄洲妈祖文化旅游节及世界妈祖文化论坛等大型节事活动，以及风筝节、彩虹跑、自行车环岛游等系列微旅游文化体验活动，丰富了妈祖文化旅游业态。

二是提升旅游体验。按照“微改造、精提升”的思路，有效规划湄洲岛各个景区及网红打卡点。围绕让游客“慢下来、停下来、留下来、住下来”，全面实施业态丰富、特色风貌整治、影视基地、规模酒店和民宿提升、渔港休闲工程等旅游配套带动莲池沙滩音乐餐饮广场常态化运营，促成“鹅岛主题餐厅”、马蹄铁餐饮和鹅尾醉美时光海岛风情项目落地，不断拓展延伸旅游产业链，真正做到快旅慢游。

三是提升旅游环境。建成1000吨滚装码头、入岛游客集散广场，推进轮渡码头第二通道扩容、对台游轮停靠点等工程建设，为台湾妈祖敬仰者和海内外游客提供“空港式”通航环境。完成鹅尾神化石景区游客服务中心整改提升项目，着力推进文甲游客集散服务中心、宫下码头游客服务中心及风雨廊建设，按标准设置影视、咨询、导服等服务功能，提升游客中心内部文化氛围。

四、推动智慧设施配套建得更好

我们围绕打造“处处有5G服务”的目标，加快海岛一张图及北斗导航旅游地图应用，打造全域人、车、路、平台智能网联智慧岛。

一是聚焦高水平服务。充分利用湄洲岛作为“国家北斗办的北斗系统军转民用试点”的契机，升级改造“智汇湄洲”平台，打通轮渡票务、公安、民宿、城管等系统壁垒，做到“一个平台管湄洲、一个屏幕看湄洲、一部手机游湄洲”，打造“数字湄洲”品牌。北斗终端已完成船舶596艘、车辆268辆终端安装部署。

二是聚焦高效能治理。全面实施禁止新增燃油车辆进岛，扎实开展燃油车汰换工作，投放新能源分时租赁汽车、公共自行车、电助力车，打造全域人、车、路、平台智能网联智慧。高质量通过住建部“智慧城市基础设施及机制建设”试点验收，投用东环路、湖石淉5G无人驾驶基站和试验道路，实现无人驾驶汽车试运行，研发生成“智慧的路”+“聪明的车”+“5G云指挥中心”无人驾驶汽车检测体系标准。

三是聚焦高质量发展。做好妈祖文化“数字文章”，丰富妈祖文化保护发展路径，建立湄洲妈祖祖庙史迹电子档案数据库，计划建设云上妈祖文化博物馆，以数字化推进妈祖文化的保护、传播、转化、创新，加强妈祖文化遗产保护。持续开展疫情下两岸民众线上交流活动，让台胞常来常往、越走越亲越亲。

下一步，湄洲岛将牢记嘱托，深入贯彻落实省委“提高效率、提升效能、提增效益”行动和市委“俯下身子抓产业、一心一意谋发展”要求，主动融入全市发展大局，用心用情保护好、高质高效建设好、全面全力发展好，全力做好空气、碧水、海岸、湖渠、金沙、土地、绿林、文物八篇文章，打造“处处是5A景点、处处是5A服务点、处处是网红打卡点”，推动90后、00后群体“游客成香客”、中老年“香客成游客”，最终成终生常客，全面建设高品质国际旅游度假岛。
