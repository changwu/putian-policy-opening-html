关于市八届人大一次会议第0054号建议的答复

发布时间：2022-04-20 17:14
| | |
政策解读:

莆发改〔2022〕120号

答复类别：B类

 

袁敏代表：

你提出的关于全方位推动莆田数字经济高质量发展的建议收悉，现答复如下：

近年来，我市积极推动数字经济发展，电子商务、平台经济等新业态、新模式不断涌现，数据赋能城市管理、安全监管、产业发展等不断加快，推动全市数字经济产业取得一定成效。2021年全市数字经济规模达1395亿元、增长13%。

一、加强组织领导。成立莆田市数字经济产业发展暨招商工作专项领导小组，由市领导担任组长，下设综合协调、企业协会、专家政策、金融支撑、属地推进等五个小组开展数字经济产业的招商和发展。通过全市统筹，建立工作协调机制，开展产业发展情况调研，制定产业发展规划，谋划组织开展招商引资活动。

二、加快平台经济发展。研究制定《莆田市平台经济集聚区实施方案》、《莆田市重点平台建设实施计划》等政策措施，完善与平台经济规范健康持续发展相适应的集群注册、分类管理、税务征收、规范监管等服务管理机制，推动平台经济快速发展。2021年列入跟踪平台企业67家，累计交易额3038.4亿元，累计纳税58.8亿元；2021年实现交易额1211.6亿元、税收23.1亿元。物泊科技互联网智慧物流平台、莆田智慧能源平台（智慧U站）、福建海丝木材与木制品交易中心平台等3家平台已列入全省20大重点平台。

三、培育壮大创新企业。2021年，我市着力培育4家未来独角兽企业和7家瞪羚企业，独角兽企业分别是物泊科技有限公司、福建豆讯科技有限公司、福建点钢科技有限公司、福建省威诺数控有限公司；瞪羚企业分别是福建莆田电商投资管理股份有限公司、莆田国投云信科技有限责任公司、中电望辰科技有限公司、福建华佳彩有限公司、福建钜能电力有限公司、福建屹立智能化科技有限公司、福建采木工业互联网科技有限公司。

四、产业集聚带动发展。引导重点园区培育壮大特色产业、完善创新体系、优化发展环境，打造新技术新产品的“试验场”、新业态新模式的“孵化器”，加快打造一批我省数字经济发展的综合性载体。全市现已形成涵江高新技术园区、仙游(京东)数字经济产业园、城厢大唐5G产业园、市政南广场平台经济集聚区等4大产业集聚区。

下一步，我委将持续围绕数字技术与实体经济深度融合，建设大数据调度指挥中心，强化数字化治理，努力打造国内一流的全域数字化治理标杆城市；重点培育一批数字龙头企业，提高数字化产品和服务供给质量，培育更多独角兽和瞪羚企业；充分发挥平台集聚作用，系统整合产业、莆商、人才等优势资源，积极招引培育一批集聚示范性好、发展融合度高、产业带动性强的优质平台企业。
